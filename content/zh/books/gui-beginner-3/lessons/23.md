# 画饼图与柱状图：分类占比、月度趋势

> 上一课学会了把图嵌进窗口，这一课真正画两种最常用的统计图形：饼图看分类占比、柱状图看月度趋势。数据都来自第 21 课的聚合函数。

## 饼图：分类占比

**饼图适合展示"各部分占整体的比例"——比如钱都花在哪。**

```python
def draw_pie(fig, ax, conn):
    ax.clear()
    rows = logic.summarize_by_category(conn, "支出")
    if not rows:
        ax.text(0.5, 0.5, "暂无数据", ha="center", va="center", fontsize=14, color="gray")
        ax.axis("off")
        return

    cats = [r[0] for r in rows]
    totals = [r[1] for r in rows]
    colors = ["#4C8BF5", "#F5654C", "#4CCF8B", "#F5C14C", "#9B6BF5", "#F56CB5"]

    wedges, texts, autotexts = ax.pie(
        totals,
        labels=cats,
        autopct="%1.1f%%",        # 自动算百分比并显示
        startangle=90,
        colors=colors[:len(cats)],
    )
    ax.set_title("支出分类占比")
```

**`autopct="%1.1f%%"` 是饼图最实用的参数**：它让每块自动显示百分比（保留一位小数）。有了它，用户一眼看出"餐饮占了 32%"。

**`startangle=90` 让第一块从正上方开始**，比默认的从右侧开始更符合阅读习惯。

## 饼图的坑：太多种类会糊成一团

**如果你有 20 个分类，饼图会被切成 20 个小三角，标签互相重叠、看不清。**

**解决方案：**

1. **只显示前 N 名**（比如前 6），其余合并成"其他"；
2. 或者用柱状图替代（柱状图对类别多更友好）。

```python
def draw_pie(fig, ax, conn):
    ax.clear()
    rows = logic.summarize_by_category(conn, "支出")
    if not rows:
        ax.text(0.5, 0.5, "暂无数据", ha="center", va="center", fontsize=14, color="gray")
        ax.axis("off")
        return

    top_n = 6
    if len(rows) > top_n:
        top = rows[:top_n]
        other = sum(r[1] for r in rows[top_n:])
        cats = [r[0] for r in top] + ["其他"]
        totals = [r[1] for r in top] + [other]
    else:
        cats = [r[0] for r in rows]
        totals = [r[1] for r in rows]

    ax.pie(totals, labels=cats, autopct="%1.1f%%", startangle=90,
           colors=["#4C8BF5","#F5654C","#4CCF8B","#F5C14C","#9B6BF5","#F56CB5","#AAAAAA"])
    ax.set_title("支出分类占比")
```

**"其他"这一项保证了饼图永远只有 7 块以内**，既清晰又有完整性。

## 柱状图：月度趋势

**柱状图适合展示"随时间变化的趋势"——比如每个月花了多少。**

```python
def draw_bar(fig, ax, conn):
    ax.clear()
    rows = logic.summarize_by_month(conn, "支出")
    if not rows:
        ax.text(0.5, 0.5, "暂无数据", ha="center", va="center", fontsize=14, color="gray")
        ax.axis("off")
        return

    months = [r[0] for r in rows]        # ["2026-07","2026-08","2026-09"]
    totals = [r[1] for r in rows]

    bars = ax.bar(months, totals, color="#4C8BF5", width=0.6)
    ax.set_title("月度支出趋势")
    ax.set_ylabel("金额（元）")

    # 柱顶标数字
    for bar, v in zip(bars, totals):
        ax.text(bar.get_x() + bar.get_width()/2, v + max(totals)*0.01,
                f"{v:,.0f}", ha="center", fontsize=9)

    # 让 X 轴标签不挤
    ax.tick_params(axis="x", rotation=30)
```

**柱顶标数字 `ax.text(...)` 是个小细节**，但用户不用盯着 Y 轴刻度估数字，体验提升明显。

## 一张 Figure 放两个子图

**饼图和柱状图想一起显示？一个 Figure 可以放多个子图：**

```python
fig = Figure(figsize=(10, 4), dpi=100)
ax1 = fig.add_subplot(121)      # 1 行 2 列，第 1 个
ax2 = fig.add_subplot(122)      # 1 行 2 列，第 2 个

draw_pie(fig, ax1, conn)
draw_bar(fig, ax2, conn)
```

**`add_subplot(121)` 三个数字分别是：行数、列数、位置编号。** 这个技巧让你在一个页面并排展示多种图表。

## 让图表跟着数据实时更新

**结合第 19 课的观察者模式：数据一变，图表自动重绘。**

```python
def _on_data_changed(action, rid):
    if current_page() == "chart":
        draw_pie(fig, ax1, db.get_conn())
        draw_bar(fig, ax2, db.get_conn())
        canvas.draw()

observer.subscribe(_on_data_changed)
```

**注意要先判断"当前在不在图表页"**——不在图表页就别浪费 CPU 重绘。更精细的做法是：不在图表页时打个"脏标记"，切过去时再重绘一次。

## 翻车现场一：饼图百分比显示成 0.3% 而不是 30%

**症状**：`autopct` 显示的数字特别小，比如 `0.3%`。

**原因**：`autopct` 默认把数值除以总和。如果你的数据存的是"分"（整数分），那占比确实是千分之几。或者数据本身很小。

**解决**：确认数据单位。`autopct` 接收的必须是"元"单位。若数据单位没问题，检查是不是聚合时 SUM 算错了。

## 翻车现场二：柱状图 X 轴标签重叠

**症状**：月份标签 `"2026-07"` 挤在一起互相重叠，看不清。

**原因**：标签太长、太密，默认水平排列放不下。

**解决**：`ax.tick_params(axis="x", rotation=30)` 旋转 30 度，或者只取后 4 位 `"07"` 缩短标签。

## 翻车现场三：同一个 ax 反复画，图形重叠

**症状**：切换几次数据后，图上旧的柱子还在，新的叠在上面，一片乱麻。

**原因**：`ax.bar(...)` 是"追加绘制"，不清空已有内容。

**解决**：每次绘制前 `ax.clear()`。这就是第 25 课要讲的内存/重绘问题的起点。

## 小结

- 饼图看占比（ax.pie + autopct 自动百分比），柱状图看趋势（ax.bar）
- 饼图种类多要合并"其他"，保持 7 块以内
- 柱状图柱顶标数字、X 轴标签旋转，提升可读性
- add_subplot(121/122) 一页放多图
- 结合观察者模式，数据一变图表自动重绘
- 每次绘制前 ax.clear()，否则图形叠加

```quiz
type: local
q: 画一个饼图 + 一个柱状图，用假数据：分类 ["餐饮","交通","购物","居住","娱乐","医疗","其他"]，金额 [1280,340,856,1500,420,200,180]。要求饼图只显示前 6 名、其余合并成"其他"，两个图用 add_subplot 并排放在一个 Figure 里。注意：需要 matplotlib，窗口程序网页里跑不了，请点"在 VS Code 里打开"运行。
starter: |
  import tkinter as tk
  import matplotlib
  matplotlib.use("TkAgg")
  from matplotlib.figure import Figure
  from matplotlib.backends.backend_tkagg import FigureCanvasTkAgg

  root = tk.Tk()
  root.geometry("900x450")

  fig = Figure(figsize=(9,4), dpi=100)
  ax1 = fig.add_subplot(121)
  ax2 = fig.add_subplot(122)

  data = [("餐饮",1280),("交通",340),("购物",856),("居住",1500),("娱乐",420),("医疗",200),("其他",180)]

  # 饼图：前 6 + 其他
  top = data[:6]
  other = data[6][1]
  ax1.pie([v for _,v in top]+[other], labels=[n for n,_ in top]+["其他"],
          autopct="%1.1f%%", startangle=90)
  ax1.set_title("支出分类占比")

  # 柱状图
  ax2.bar([n for n,_ in data], [v for _,v in data], color="#4C8BF5")
  ax2.set_title("各类支出")

  canvas = FigureCanvasTkAgg(fig, master=root)
  canvas.draw()
  canvas.get_tk_widget().pack(fill="both", expand=True)
  root.mainloop()
checklist:
- 饼图合并了"其他"项
- 饼图用了 autopct 显示百分比
- 柱状图柱顶或标签清晰
- 两个图用 add_subplot 并排
- 正确嵌入 tkinter（FigureCanvasTkAgg）
```

```quiz
type: local
exam: true
q: 画"收支对比柱状图"：用分组柱状图（grouped bar）同时显示每个月的收入和支出。假数据：月份 ["7月","8月","9月"]，收入 [8000,8000,12000]，支出 [3200,2560,3976]。要求同一月份两根柱子并排、加图例、柱顶标数字、加标题。注意：需要 matplotlib，网页里跑不了，请点"在 VS Code 里打开"运行。
starter: |
  import tkinter as tk
  import numpy as np
  import matplotlib
  matplotlib.use("TkAgg")
  from matplotlib.figure import Figure
  from matplotlib.backends.backend_tkagg import FigureCanvasTkAgg

  root = tk.Tk()
  root.geometry("700x450")
  fig = Figure(figsize=(7,4), dpi=100)
  ax = fig.add_subplot(111)

  months = ["7月","8月","9月"]
  income = [8000,8000,12000]
  expense = [3200,2560,3976]
  x = np.arange(len(months))
  w = 0.35

  b1 = ax.bar(x - w/2, income, w, label="收入", color="#4CCF8B")
  b2 = ax.bar(x + w/2, expense, w, label="支出", color="#F5654C")
  ax.set_xticks(x)
  ax.set_xticklabels(months)
  ax.legend()
  ax.set_title("月度收支对比")

  # 柱顶标数字
  for bar in list(b1)+list(b2):
      ax.text(bar.get_x()+bar.get_width()/2, bar.get_height()+50,
              f"{bar.get_height():.0f}", ha="center", fontsize=8)

  canvas = FigureCanvasTkAgg(fig, master=root)
  canvas.draw()
  canvas.get_tk_widget().pack(fill="both", expand=True)
  root.mainloop()
checklist:
- 收入和支出两根柱子并排
- 有图例区分收入/支出
- 柱顶标了数字
- 有标题
- 正确嵌入 tkinter
```
