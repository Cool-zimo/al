# 空状态与提示：没有数据时显示什么

> 一个常被忽略的细节：软件第一次启动、数据库里一条记录都没有时，表格是一片空白。空表格不会说话，用户只会困惑——这一课教你怎么处理"空状态"。

## 空表格的尴尬

**首次启动你的记账本，表格里什么都没有。** 用户看到的是一个带列标题、但没有一行的表格，心里会想：

- "这软件坏了？"
- "我是不是没打开对文件？"
- "记录去哪了？"

**好的软件会"主动解释"这个状态**：告诉用户"还没有记录，快去录第一笔吧"，甚至直接指引他去哪儿录。

## 方案：空状态时显示占位 Frame

**思路很简单：表格有数据时显示 Treeview，没数据时显示一段提示文字。用一个容器 Frame 和两个子控件，按需切换。**

```python
list_container = tk.Frame(root)

self.tree = ttk.Treeview(list_container, columns=cols, show="headings")
self.tree.pack(fill="both", expand=True)

self.empty_label = tk.Label(list_container,
                            text="还没有任何记录\n\n点击底部录入区，记录你的第一笔收支吧",
                            justify="center", fg="#999", font=("", 12))
# 默认先隐藏，等刷新时决定显示哪个
```

**关键在 `refresh_table` 里做判断：**

```python
def refresh_table(tree, empty_label, conn):
    rows = db.get_all(conn)
    if len(rows) == 0:
        tree.pack_forget()              # 隐藏表格
        empty_label.pack(fill="both", expand=True, pady=80)
    else:
        empty_label.pack_forget()       # 隐藏提示
        tree.pack(fill="both", expand=True)
        # 清空重填
        for iid in tree.get_children():
            tree.delete(iid)
        for r in rows:
            tree.insert("", "end", iid=str(r["id"]), values=(...))
```

**`pack_forget()` 是"暂时隐藏"控件的标准做法**，它不销毁控件，只是从布局里移除，下次 pack 还能回来。别用 `destroy()`，那是真的删掉、要重建。

## 顺手做的两个小提示

**除了空状态，还有两处该给用户反馈：**

1. **录入成功提示**：存完后右下角闪一下"已保存"。用 `messagebox` 太重（要点确定），可以用状态栏文字或 `after` 定时清除。
2. **操作失败提示**：校验不通过时用 `showerror`。

**状态栏的实现（承接第 11 课的 status Frame）：**

```python
self.status_var = tk.StringVar(value="就绪")
tk.Label(status_bar, textvariable=self.status_var, anchor="w").pack(side="left", padx=8)

# 录入成功后
self.status_var.set(f"已保存 · 共 {len(rows)} 条记录")
root.after(3000, lambda: self.status_var.set("就绪"))   # 3 秒后恢复
```

**`root.after(3000, func)` 是 tkinter 的"定时执行"**，3000 毫秒后跑一次 func。用它做"临时提示自动消失"，比弹窗友好得多。

## 删除前的确认

**删除是不可逆操作，一定要二次确认。** 用 `askyesno`：

```python
def on_delete():
    sel = tree.selection()
    if not sel:
        mb.showwarning("提示", "请先选中一条记录")
        return
    rid = int(sel[0])
    ok = mb.askyesno("确认删除", "确定要删除这条记录吗？此操作不可恢复。")
    if not ok:
        return
    db.delete_record(conn, rid)
    refresh_table(tree, empty_label, conn)
```

**三件事都做了**：没选中时提示、删除前确认、删除后刷新。这一套是"防误删"的标准动作。

## 翻车现场一：空表格不提示，用户以为坏了

**症状**：首次启动界面空白，用户发来一句"你的软件跑不起来"。

**解决**：加空状态占位 Label，明确告诉用户"这里还没有数据"并指引操作。

## 翻车现场二：用 destroy 隐藏控件，结果再也显示不回来

```python
if empty:
    tree.destroy()          # 错误：真的删掉了
    empty_label.pack()
# 下次有数据时...
tree.pack(fill="both", expand=True)    # AttributeError: 'NoneType' object has no attribute 'pack'
```

**症状**：`AttributeError`，因为 tree 已经被销毁。

**原因**：`destroy()` 把控件从内存里移除，引用还在但对象已死。

**解决**：用 `pack_forget()` 只隐藏不销毁。要恢复时重新 pack 就行。

## 翻车现场三：刷新时忘记切换状态，表格和提示叠在一起

```python
def refresh_table(tree, empty_label, conn):
    rows = db.get_all(conn)
    if not rows:
        empty_label.pack(...)      # 显示提示
    # 忘记 else，也没 pack_forget tree
    for iid in tree.get_children():
        tree.delete(iid)
    for r in rows:
        tree.insert(...)
    tree.pack(...)                 # 结果提示和表格叠在一起
```

**症状**：界面上提示文字和表格互相重叠、错乱。

**原因**：两个控件都 pack 了，上下叠放。

**解决**：无论哪种状态，都要先 `pack_forget` 另一个控件。`if/else` 两条分支各自管理显隐，保证同一时刻只有一个可见。

## 小结

- 首次启动表格是空的，要用占位 Label 主动解释并指引操作
- 切换显隐用 pack_forget，别用 destroy（destroy 是真删除）
- if/else 两个分支各自显隐，保证同一时刻只有一个控件可见
- 成功提示用状态栏 + after 定时清除，比弹窗友好
- 删除是不可逆操作，必须用 askyesno 二次确认
- 空状态、成功提示、错误提示、确认对话框，四种反馈都要有

```quiz
type: local
q: 做一个带空状态切换的小界面：一个按钮"添加一条"（每点一次往列表里加一条假数据，列表用 Listbox 即可），一个按钮"清空"。Listbox 有数据时显示 Listbox，没有时显示 Label "暂无数据，点击添加一条"。用 pack_forget 切换。注意：窗口程序网页里跑不了，请点"在 VS Code 里打开"运行。
starter: |
  import tkinter as tk

  root = tk.Tk()
  root.geometry("400x300")

  container = tk.Frame(root)
  container.pack(fill="both", expand=True)

  listbox = tk.Listbox(container)
  empty_lbl = tk.Label(container, text="暂无数据\n\n点击添加一条", fg="#999", justify="center")

  count = [0]
  def add_one():
      count[0] += 1
      listbox.insert("end", f"记录 {count[0]}")
      # 切换显隐
  def clear_all():
      listbox.delete(0, "end")
      # 切换显隐

  tk.Button(root, text="添加一条", command=add_one).pack(side="left", padx=8, pady=8)
  tk.Button(root, text="清空", command=clear_all).pack(side="left", pady=8)

  root.mainloop()
checklist:
- 用 Listbox 做列表
- 空状态有占位 Label
- 用 pack_forget 切换显隐，没用 destroy
- 添加时显示列表、清空后显示提示
- 同一时刻只有一个控件可见
```
