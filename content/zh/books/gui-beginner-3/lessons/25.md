# 让图表跟着数据自动刷新

> 你改了一笔账，切到统计页，饼图还是旧数据——因为图只画了一次。这一课把聚合、绘图、刷新串成一条链，让图表在增删改后自动重算重画。这是统计页从"能看"到"能用"的最后一步。

## 现状：图是死的

**现在 `app.py` 里统计页的绘制大概是这样：**

```
root = tk.Tk()
...
stats = StatsFrame(notebook, db)
stats.pack(fill="both", expand=True)
stats.refresh()        # 启动时画一次
root.mainloop()
```

**问题**：`refresh()` 只在启动时调用一次。你录了一笔新的餐饮 ¥128，Treeview 里立刻出现了，但饼图毫无反应——它不知道数据变了。

**这不是 matplotlib 的毛病，是调用时机的问题。** 图只在你说"画"的时候画，没人告诉它重画。

## 思路：把"画"抽成一个方法

**第一步，把绘图代码从 `__init__` 挪进 `refresh()`：**

```
class StatsFrame(ttk.Frame):
    def __init__(self, master, db):
        super().__init__(master)
        self.db = db
        self.fig = Figure(figsize=(6, 4), dpi=100)
        self.canvas = FigureCanvasTkAgg(self.fig, master=self)
        self.canvas.get_tk_widget().pack(fill="both", expand=True)
        self.refresh()

    def refresh(self):
        self.fig.clear()
        ax = self.fig.add_subplot(111)
        rows = self.db.sum_by_category("支出")
        labels = [r[0] for r in rows]
        values = [r[1] for r in rows]
        ax.pie(values, labels=labels)
        self.fig.tight_layout()
        self.canvas.draw()
```

**关键点：`self.fig.clear()` 清空旧图，然后重新 `add_subplot`。** 如果忘了 clear，新旧图会叠在一起变成一团乱麻。

## 在增删改之后触发刷新

**现在的问题是：谁调用 `refresh()`？**

**答案是任何改动数据的地方。** 记账本有三类操作会改数据：新增、编辑、删除。每一处做完之后都要通知统计页重画。

**最简单的做法：让 `App` 持有统计页引用，操作完成后调用：**

```
class App:
    def __init__(self, root):
        ...
        self.stats = StatsFrame(notebook, self.db)
        self.entries = EntryFrame(notebook, self.db, on_changed=self.on_data_changed)
        ...

    def on_data_changed(self):
        self.stats.refresh()
```

**`EntryFrame` 的按钮回调里，做完 insert/update/delete 之后调用 `self.on_changed()`：**

```
def on_save(self):
    self.db.insert(category=self.category.get(), amount=self.amount.get(), ...)
    self.on_changed()      # 通知上层：数据变了
```

**这一下就把数据层和视图层解耦了**：录入页不认识统计页，它只管喊一声"我改了"，至于谁要刷新、怎么刷新，它不管。

## 翻车现场一：忘了 fig.clear()，图越画越乱

**症状**：每改一次数据，饼图的扇区越叠越多，最后全是重复的扇区和标签。

**原因**：`refresh()` 里直接 `self.fig.add_subplot(111)`，等于往同一个 Figure 上不停地叠加 Axes。Figure 不会自动清空。

**错误写法：**

```
def refresh(self):
    ax = self.fig.add_subplot(111)    # 每次都新增一个 Axes，旧的还在
    ax.pie(...)
    self.canvas.draw()
```

**正确写法：**

```
def refresh(self):
    self.fig.clear()                  # 先清空
    ax = self.fig.add_subplot(111)
    ax.pie(...)
    self.fig.tight_layout()           # 清完之后重新布局
    self.canvas.draw()
```

**`canvas.draw()` 和 `fig.clear()` 是一对**：清旧图、画新图、然后告诉画布重绘。

## 翻车现场二：数据变了但忘了通知，图永远是旧的

**症状**：录入页的保存按钮明明执行了，数据库里也有新记录，但饼图不更新。得手动关掉窗口重开才变。

**原因**：保存回调里只调了 `self.db.insert(...)`，没有调用 `self.on_changed()`。统计页根本不知道发生了什么。

**错误写法：**

```
def on_save(self):
    self.db.insert(...)
    self.tree.insert(...)    # 只刷新了列表，忘了统计页
```

**正确写法：**

```
def on_save(self):
    self.db.insert(...)
    self.tree.insert(...)
    self.on_changed()        # 别忘了这行
```

**排查这类 bug 的思路**：在 `refresh()` 第一行加 `print("refresh called")`，看保存后有没有输出。没输出说明是通知链断了，有输出说明是绘图逻辑本身有问题。

## 翻车现场三：refresh 里读数据库卡住界面

**症状**：账本有上万条记录时，点保存之后整个窗口卡两三秒，期间点什么都不响应。

**原因**：`db.sum_by_category()` 是同步的 SQL 查询，跑在主线程里。GUI 主线程被它占着，界面就冻住了。

**本课先记住结论：耗时操作要放到后台线程。** 下一课（第 26 课）讲异常处理时再展开，这里给个架子：

```
import threading

def on_data_changed(self):
    threading.Thread(target=self._reload_stats, daemon=True).start()

def _reload_stats(self):
    rows = self.db.sum_by_category("支出")   # 在子线程查
    self.after(0, self._redraw, rows)        # 回到主线程画

def _redraw(self, rows):
    self.fig.clear()
    ...
    self.canvas.draw()
```

**记住一条铁律：tkinter 的控件只能在主线程操作。** 子线程算完数据，必须用 `widget.after(0, callback)` 把绘制调度回主线程，否则直接崩溃。

## 小结

- 图表默认只画一次，数据变了不会自动刷新
- 把绘图逻辑封装成 `refresh()`，每次数据变动后调用
- `refresh()` 必须 `fig.clear()` 再重画，否则图形叠加
- 用回调 `on_changed` 解耦：录入页喊一声，统计页自己刷新
- 排查刷新 bug 先 print 看 refresh 有没有被调用
- 大数据量时查询要放子线程，绘制必须回主线程

type: local
exam: true

starter: |
  import tkinter as tk
  import tkinter.ttk as ttk
  import matplotlib
  matplotlib.use("TkAgg")
  from matplotlib.figure import Figure
  from matplotlib.backends.backend_tkagg import FigureCanvasTkAgg

  class StatsFrame(ttk.Frame):
      def __init__(self, master, get_rows):
          super().__init__(master)
          self.get_rows = get_rows
          self.fig = Figure(figsize=(5, 4), dpi=100)
          self.canvas = FigureCanvasTkAgg(self.fig, master=self)
          self.canvas.get_tk_widget().pack(fill="both", expand=True)
          self.refresh()

      def refresh(self):
          self.fig.clear()
          ax = self.fig.add_subplot(111)
          rows = self.get_rows()
          if not rows:
              ax.text(0.5, 0.5, "暂无数据", ha="center", va="center", fontsize=16)
          else:
              ax.pie([r[1] for r in rows], labels=[r[0] for r in rows])
          self.fig.tight_layout()
          self.canvas.draw()

  root = tk.Tk()
  store = []
  sf = StatsFrame(root, get_rows=lambda: list(store))
  tk.Button(root, text="加一条餐饮 200",
      command=lambda: (store.append(("餐饮",200)), sf.refresh())).pack()
  tk.Button(root, text="加一条交通 50",
      command=lambda: (store.append(("交通",50)), sf.refresh())).pack()
  root.mainloop()
checklist:
- 点击按钮能新增数据并触发刷新
- 无数据时饼图位置显示"暂无数据"文字

- 每次刷新都先 clear 再重画
