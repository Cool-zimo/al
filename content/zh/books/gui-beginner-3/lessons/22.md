# matplotlib 嵌入 tkinter：FigureCanvasTkAgg

> 聚合结果算出来了，这一课把它画成图表。matplotlib 是第三方库，但它能原生嵌入 tkinter 窗口——关键是用 `FigureCanvasTkAgg`，**绝对不能**用 `plt.show()`。

## 先装 matplotlib

**matplotlib 是本项目唯一必须引入的图表库：**

```bash
pip install matplotlib
```

**验证安装：**

```python
import matplotlib
print(matplotlib.__version__)   # 3.7.2
```

**嵌入 tkinter 要用到两个东西：**

```python
from matplotlib.figure import Figure
from matplotlib.backends.backend_tkagg import FigureCanvasTkAgg
```

## 为什么不能用 plt.show()

**`plt.show()` 是 matplotlib 的"独立窗口模式"**：它会开一个新的 GUI 窗口（用的是 Tk、Qt 或 Mac 原生后端），**阻塞**当前程序，直到你把那个窗口关掉。

**在 tkinter 应用里调 `plt.show()` 会发生什么：**

- 弹出一个独立的图表窗口，和你自己的界面是两个窗口，体验割裂；
- `plt.show()` 会**阻塞主线程**，你的主窗口卡住、按钮点不动；
- 某些平台下会报 `RuntimeError: main thread is not in main loop`。

**所以：凡是嵌入 tkinter，一律用 FigureCanvasTkAgg 把图"画进"一个 Canvas 控件里。**

## 三步嵌入一个图表

**完整流程：建 Figure → 建子图 axes → 画 → 包进 Canvas → 放进窗口。**

```python
import tkinter as tk
import matplotlib
matplotlib.use("TkAgg")                    # 必须在导入 pyplot 之前设置后端
from matplotlib.figure import Figure
from matplotlib.backends.backend_tkagg import FigureCanvasTkAgg

root = tk.Tk()
root.title("图表嵌入示例")
root.geometry("700x500")

fig = Figure(figsize=(6, 4), dpi=100)     # 图本身（不是控件）
ax = fig.add_subplot(111)                 # 子图（坐标系）
ax.bar(["餐饮","交通","购物"], [1280, 340, 856])
ax.set_title("各分类支出")
ax.set_ylabel("金额（元）")

canvas = FigureCanvasTkAgg(fig, master=root)   # 把图包成 tkinter 控件
canvas.draw()                                 # 必须 draw 才显示
canvas.get_tk_widget().pack(fill="both", expand=True)

root.mainloop()
```

**四个对象各司其职：**

| 对象 | 是什么 |
|---|---|
| `Figure` | 一张"画布"，图的整体 |
| `Axes` (ax) | 画布上的一个"坐标系"（一张图可有多个子图） |
| `FigureCanvasTkAgg` | 把 Figure 渲染到 tkinter 的桥梁 |
| `canvas.get_tk_widget()` | 真正的 tkinter 控件，能 pack/grid |

**`canvas.draw()` 是必须的**，它触发渲染。改了数据后想刷新，也是重新 `draw()`。

## matplotlib.use("TkAgg") 的时机

**`matplotlib.use(...)` 必须在 import pyplot 之前调用**，且只能调一次。作用是"指定后端"。

**本项目直接用 Figure API**（上面那种），不经过 pyplot，所以其实可以省略 `use("TkAgg")`——但保险起见写上，或者干脆**完全不 import pyplot**，避免不小心用了 `plt.show()`。

**反例（错误）：**

```python
import matplotlib.pyplot as plt     # 先 import 了 pyplot
matplotlib.use("TkAgg")            # 太晚了，后端已经初始化过
```

**正确：要么在 import pyplot 前 use，要么干脆不 import pyplot。**

## 从聚合数据画图

**把第 21 课的聚合结果喂给图表：**

```python
import logic

def draw_category_chart(fig, ax, conn):
    ax.clear()
    rows = logic.summarize_by_category(conn, "支出")
    if not rows:
        ax.text(0.5, 0.5, "暂无数据", ha="center", va="center", fontsize=14, color="gray")
        ax.axis("off")
        return
    cats = [r[0] for r in rows]
    totals = [r[1] for r in rows]
    ax.bar(cats, totals, color="#4C8BF5")
    ax.set_title("各分类支出（元）")
    ax.set_ylabel("金额")
    for i, v in enumerate(totals):
        ax.text(i, v + max(totals)*0.01, f"{v:,.0f}", ha="center", fontsize=9)
```

**空数据处理很重要**：聚合结果为空时直接 `ax.bar([])` 会画出一个空坐标系，用户看不懂。不如显示一行"暂无数据"。

## 图表页与主页面的切换

**在顶部加一个 Notebook 标签页，把"列表页"和"统计页"分开：**

```python
nb = ttk.Notebook(root)
list_page = tk.Frame(nb)
chart_page = tk.Frame(nb)
nb.add(list_page, text="记录列表")
nb.add(chart_page, text="统计图表")
nb.pack(fill="both", expand=True)
```

**`ttk.Notebook` 是最适合"多页面"的控件**——顶部有标签页，点哪个显示哪个 Frame。把列表放一个 Frame、图表放另一个，互不打扰。

**图表页的 Canvas 在 build 时就创建好，切换标签页时重绘：**

```python
def on_tab_changed(event):
    idx = nb.index("current")
    if idx == 1:          # 切到统计页
        draw_category_chart(fig, ax, db.get_conn())
        canvas.draw()

nb.bind("<<NotebookTabChanged>>", on_tab_changed)
```

## 翻车现场一：用了 plt.show()，主窗口卡死

```python
import matplotlib.pyplot as plt
plt.bar(cats, totals)
plt.show()                # 阻塞！主窗口卡死
```

**症状**：主窗口失去响应，按钮点不动，直到关掉弹出的图表窗口才恢复。

**原因**：`plt.show()` 启动了 matplotlib 自己的主循环，阻塞了 tkinter 的主循环。

**解决**：用 FigureCanvasTkAgg 嵌入，不用 pyplot 的交互模式。

## 翻车现场二：忘了 canvas.draw()，图表一片白

```python
fig = Figure(figsize=(6,4), dpi=100)
ax = fig.add_subplot(111)
ax.bar(cats, totals)
canvas = FigureCanvasTkAgg(fig, master=chart_page)
canvas.get_tk_widget().pack(fill="both", expand=True)
# 忘记 canvas.draw()
```

**症状**：窗口上什么都没有，一块白（或一块灰）。

**原因**：只创建了画布和控件，没有触发渲染。

**解决**：每次要显示/刷新时调 `canvas.draw()`。

## 翻车现场三：切换页面后图表不更新

**症状**：你在列表页新增了一条记录，切到统计页，饼图还是旧数据。

**原因**：图表只在 build 时画了一次，之后没重绘。

**解决**：绑 `<<NotebookTabChanged>>` 事件，每次切到统计页都重绘。这就是第 19 课观察者模式能大显身手的地方——数据一变就通知图表页重绘。

## 小结

- 嵌入 tkinter 用 FigureCanvasTkAgg，绝对不能用 plt.show()
- 四件套：Figure → Axes → FigureCanvasTkAgg → canvas.draw()
- matplotlib.use("TkAgg") 必须在 import pyplot 之前
- 聚合数据通过逻辑层函数取得，图表只管画
- 多页面用 ttk.Notebook，切换时重绘
- 空数据要显示"暂无数据"，别画空坐标系
- 每次刷新必须 canvas.draw()
