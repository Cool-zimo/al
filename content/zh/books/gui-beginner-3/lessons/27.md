# 配置与偏好：记住窗口大小、上次打开的文件

> 你关掉记账本，重新打开，窗口变成默认 800×600，统计页的选中状态全丢了，上次打开的账本文件也得重新找一遍。这些"记忆"就是配置。这一课讲配置文件该放哪（跨平台路径）、存什么、怎么读，以及为什么不该用 pickle 存偏好。

## 需求：三件要记住的事

**记账本至少有三类偏好值得保存：**

| 配置项 | 说明 | 存什么 |
|---|---|---|
| 窗口几何信息 | 用户拖好的大小、位置 | `"1200x700+120+60"` |
| 上次打开的文件 | 重新打开时直接加载 | `/Users/x/记账/2026.db` |
| 界面偏好 | 上次选中的标签页、是否显示合计行 | `last_tab=1, show_total=true` |

**`configparser` 是标准库里专门为这种"小节 + 键值"配置文件设计的模块**，读出来就是一个 `.ini` 文件，人能直接看懂、能手动改。

## 配置文件放哪：跨平台路径

**Windows、Mac、Linux 三家的用户配置目录都不一样，硬编码路径是大忌。**

| 平台 | 正确位置 | 示例 |
|---|---|---|
| Windows | `%APPDATA%` | `C:\Users\x\AppData\Roaming\Ledger\config.ini` |
| macOS | `~/Library/Application Support/` | `~/Library/Application Support/Ledger/config.ini` |
| Linux | `~/.config/` | `~/.config/ledger/config.ini` |

**Python 3.5+ 提供了 `appdirs` 的精神继承者——用 `pathlib` 配合环境变量判断即可，也可以装第三方 `appdirs`。记账本用一个函数搞定：**

```
import os, platform
from pathlib import Path

def config_dir() -> Path:
    app = "Ledger"
    sysname = platform.system()
    if sysname == "Windows":
        base = os.environ.get("APPDATA")
    elif sysname == "Darwin":
        base = os.path.expanduser("~/Library/Application Support")
    else:  # Linux / BSD
        base = os.environ.get("XDG_CONFIG_HOME") or os.path.expanduser("~/.config")
    p = Path(base) / app
    p.mkdir(parents=True, exist_ok=True)
    return p
```

**`parents=True` 让父目录不存在时一起创建，`exist_ok=True` 让目录已存在时不报错。** 这一行就是标准写法，记下来。

**数据库文件放哪？** 用户账本属于"文档数据"，不该和业务配置混一起：

| 数据类型 | 位置 |
|---|---|
| 配置文件 `config.ini` | 上面算出来的 config_dir |
| 账本数据库 `ledger.db` | 用户自选，默认放"文档"目录 |

## 用 configparser 读写

**存配置：**

```
import configparser

def save_config(cfg_path, geometry, last_file, last_tab):
    cp = configparser.ConfigParser()
    cp["Window"] = {"geometry": geometry}
    cp["Recent"] = {"last_file": last_file, "last_tab": str(last_tab)}
    with open(cfg_path, "w", encoding="utf-8") as f:
        cp.write(f)
```

**读配置，带默认值：**

```
def load_config(cfg_path):
    cp = configparser.ConfigParser()
    cp.read(cfg_path, encoding="utf-8")          # 文件不存在也不报错，返回空
    return {
        "geometry": cp.get("Window", "geometry", fallback="1000x650+100+100"),
        "last_file": cp.get("Recent", "last_file", fallback=""),
        "last_tab": cp.getint("Recent", "last_tab", fallback=0),
    }
```

**`fallback` 参数是重点**：首次运行时配置文件根本不存在，`cp.read()` 静默返回空列表，全靠 fallback 给出默认值，程序照样能跑。

**用的时候：**

```
cfg = load_config(config_dir() / "config.ini")
root = tk.Tk()
root.geometry(cfg["geometry"])            # 恢复窗口大小
notebook.select(cfg["last_tab"])         # 恢复上次标签页
```

## 保存时机：什么时候写配置

**三种常见策略，记账本用第一种：**

1. **退出时保存一次**（最简单）：绑定 `root.protocol("WM_DELETE_WINDOW", on_close)`；
2. 每次改动保存（实时性高，但有 I/O 开销）；
3. 定时保存（适合编辑器类）。

**退出时保存的完整写法：**

```
def on_close():
    cfg_path = config_dir() / "config.ini"
    save_config(cfg_path,
        geometry=root.geometry(),
        last_file=current_db_path,
        last_tab=notebook.index(notebook.select()),
    )
    root.destroy()

root.protocol("WM_DELETE_WINDOW", on_close)
```

**`root.geometry()` 无参数调用时返回当前几何信息字符串**，格式正是 `"1200x700+120+60"`，可以直接存、可以直接用。

**`WM_DELETE_WINDOW` 是唯一能拦截窗口关闭事件的方式**，点右上角 × 时先走你的 on_close，而不是默认直接销毁。

## 翻车现场一：把账本数据库放进 AppData 的坑

**症状**：Windows 上用户找不到账本文件，重装系统或清理磁盘软件把 AppData 当缓存清了，数据全没。

**原因**：AppData/Roaming 本意是放"跟随用户漫游的配置"，有些企业域环境会定期清理。把用户数据塞这里等于冒险。

**正确做法：账本 `.db` 默认放"文档"目录，让用户自己选。**

```
from pathlib import Path
def default_ledger_path() -> Path:
    if platform.system() == "Windows":
        base = os.path.expandvars("%USERPROFILE%\\Documents")
    else:
        base = os.path.expanduser("~/Documents")
    p = Path(base) / "Ledger"
    p.mkdir(parents=True, exist_ok=True)
    return p / "ledger.db"
```

**配置是配置，数据是数据，别混。**

## 翻车现场二：configparser 的键区分大小写，读取自己拼的字符串踩坑

**症状**：`cp["window"]` 写进去，`cp["Window"]` 读出来是空的。

**原因**：`configparser` 的 section 名在 3.x 默认是**保留原大小写**的（和老 Python 2 不同）。key 是大小写无关的，但 section 名要一致。

**错误写法：**

```
cp["window"] = {"geometry": "1000x650"}
print(cp["Window"]["geometry"])    # KeyError: 'Window'
```

**正确写法：统一大写，或用 `cp.has_section` 判断：**

```
if not cp.has_section("Window"):
    cp["Window"] = {}
geometry = cp["Window"].get("geometry", "1000x650+100+100")
```

## 翻车现场三：用 pickle 存配置，版本升级后打不开

**症状**：你改了配置结构，老用户的配置文件一读取就 `AttributeError`，程序起不来。

**原因**：`pickle` 序列化的是 Python 对象，结构一变就反序列化失败。配置文件的使命是"人能读、跨版本稳定"。

**错误做法：**

```
import pickle
pickle.dump({"geometry": "1000x650", "last_tab": 1}, open("config.pkl", "wb"))
```

**正确做法：坚持用 `configparser`（或 JSON/YAML）。** 文本格式改字段时旧配置读不到就走 fallback，绝不会崩。配置不是缓存，不要用二进制格式存。

## 小结

- 窗口大小、上次文件、界面偏好三件事值得记住
- 配置文件路径按平台取：Windows APPDATA、macOS ~/Library、Linux ~/.config
- `configparser` + `fallback` 参数，首次运行也能正常启动
- 保存时机选"退出时一次"，绑定 WM_DELETE_WINDOW
- 账本数据库放文档目录，不要塞 AppData
- 配置用文本格式（ini/json），不要用 pickle
