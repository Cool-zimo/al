# 按分类汇总：用 SQL GROUP BY

> 从这一课开始做统计。需求 F3 是"看出钱花在哪"，第一步是把数据按分类聚合成"各类花了多少"。我们有两条路：SQL 的 GROUP BY 和 pandas。这一课讲 SQL 方案——标准库自带，零依赖。

## 需求：各类支出占比

**用户想知道：这个月花了多少钱、都花在哪。** 结果应该长这样：**

```
餐饮   1280.50
交通    340.00
购物    856.00
居住   1500.00
```

**有了这张表，才能画饼图、柱状图。** 所以"聚合"是统计的基石。

## GROUP BY：一行 SQL 搞定

**按分类求和：**

```python
cur.execute("""
    SELECT category, SUM(amount) AS total
    FROM records
    WHERE type = '支出'
    GROUP BY category
    ORDER BY total DESC
""")
rows = cur.fetchall()
for cat, total in rows:
    print(f"{cat:6s} {total:>10.2f}")
```

**结果：**

```
居住     1500.00
餐饮     1280.50
购物      856.00
交通      340.00
```

**四个关键字各司其职：**

| 子句 | 作用 |
|---|---|
| `WHERE type='支出'` | 只看支出（排除收入） |
| `GROUP BY category` | 按分类分组，同类的金额被聚到一起 |
| `SUM(amount)` | 对每组求和 |
| `ORDER BY total DESC` | 金额从大到小，方便看主要开销 |

## 为什么不用 pandas

**你可能听过 pandas，它是数据分析神器，一行 `df.groupby('category')['amount'].sum()` 就能出结果。但我们这一课不用它，理由是：**

1. **pandas 不是标准库**，要 `pip install pandas`，打包体积会暴增几十 MB；
2. **我们的数据量极小**（个人记账几百条），SQL 几毫秒出结果，用不上 pandas 的性能；
3. **用 SQL 能复习并真正掌握 GROUP BY**，这是所有数据库的通用技能。

**引入第三方库要讲"必要性"。** 图表（matplotlib）我们不得不引，因为 tkinter 画不出饼图；但聚合 SQL 本身就够用，没必要多一个依赖。

## 按月汇总：DATE 也能分组

**看每个月的支出：**

```python
cur.execute("""
    SELECT substr(date, 1, 7) AS month, SUM(amount) AS total
    FROM records
    WHERE type = '支出'
    GROUP BY month
    ORDER BY month
""")
# 结果：
# 2026-07   3200.00
# 2026-08   2560.00
# 2026-09   3976.50
```

**`substr(date, 1, 7)` 取出 `YYYY-MM` 前 7 个字符**，这就是分组的键。这再次印证了第 2 课"日期存 `YYYY-MM-DD`"的正确性——大单位在前，子串截取天然就是"按月"。

**如果用的是 `27/09/2026`，就得先把字符串拆开重排才能按月分组，麻烦得多。**

## 同时算收入和支出

**一张表同时看收入和支出：**

```python
cur.execute("""
    SELECT category,
           SUM(CASE WHEN type='收入' THEN amount ELSE 0 END) AS income,
           SUM(CASE WHEN type='支出' THEN amount ELSE 0 END) AS expense
    FROM records
    GROUP BY category
""")
# 结果：
# category   income   expense
# 工资       8000.00     0.00
# 餐饮          0.00  1280.50
# 交通          0.00   340.00
```

**`CASE WHEN` 是 SQL 里的"条件表达式"**，它让 SUM 只对满足条件的行累加。这一招在做交叉统计时极常用。

## 把聚合封装成函数

**逻辑层负责聚合：**

```python
# logic.py
def summarize_by_category(conn, rtype="支出"):
    cur = conn.cursor()
    cur.execute("""
        SELECT category, SUM(amount) AS total
        FROM records
        WHERE type = ?
        GROUP BY category
        ORDER BY total DESC
    """, (rtype,))
    return cur.fetchall()           # [(分类, 总额), ...]

def summarize_by_month(conn, rtype="支出"):
    cur = conn.cursor()
    cur.execute("""
        SELECT substr(date,1,7) AS month, SUM(amount) AS total
        FROM records
        WHERE type = ?
        GROUP BY month
        ORDER BY month
    """, (rtype,))
    return cur.fetchall()
```

**界面层拿到这个列表就能画图。** 聚合逻辑放在逻辑层，图表层和列表层都能复用。

## 翻车现场一：GROUP BY 选了非聚合列

```sql
SELECT category, date, SUM(amount)
FROM records
GROUP BY category;
```

**症状**：SQLite 不报错（这是 SQLite 的"特性"，其他数据库如 MySQL、PostgreSQL 会直接报错），但 `date` 列显示的是"组内任意一行的值"，不可预测。

**原因**：GROUP BY 之后，每行代表"一组"，非聚合列的值是不确定的。SQLite 默认宽松模式允许这种写法，结果却没意义。

**解决**：SELECT 里只放"分组列"和"聚合函数"。想要组内第一条，用子查询或窗口函数。

## 翻车现场二：SUM 对空表返回 None

```python
cur.execute("SELECT SUM(amount) FROM records WHERE type='支出'")
total = cur.fetchone()[0]
print(total + 100)      # TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'
```

**症状**：表为空时 `total` 是 None，参与运算直接崩。

**原因**：聚合函数无匹配返回 None，不是 0。

**解决**：`total = cur.fetchone()[0] or 0`。聚合函数一律要兜底。

## 翻车现场三：日期存成 "27/09/2026" 导致按月分组失败

```sql
SELECT substr(date, 1, 7) ... GROUP BY substr(date,1,7)
-- 结果按 "27/09/2" 分组，完全错误
```

**症状**：按月分组出来的结果乱七八糟，每月的数据被拆得到处都是。

**原因**：日期格式是日/月/年，前 7 位是 `"27/09/2"`，根本不是月份。

**解决**：回到第 2 课的约定，统一用 `YYYY-MM-DD`。这是数据模型决策影响后续所有功能的典型案例。

## 小结

- 聚合用 GROUP BY + SUM，标准库自带、零依赖、够快
- 四个子句：WHERE 过滤、GROUP BY 分组、SUM 聚合、ORDER BY 排序
- 按月汇总靠 substr(date,1,7)，前提是日期存 YYYY-MM-DD
- CASE WHEN 可做条件聚合，同时算收入/支出
- GROUP BY 后 SELECT 只放分组列和聚合函数
- SUM 无匹配返回 None，记得 `or 0` 兜底

```quiz
type: local
exam: true
q: 用 CASE WHEN 写一个函数 summarize_income_expense(conn)，返回每个分类的收入合计和支出合计两列（见本课 CASE WHEN 示例）。打印结果表格。再写一个总览函数 total_summary(conn)，返回 (总收入, 总支出, 结余)。注意：网页里跑不了，请点"在 VS Code 里打开"运行。
starter: |
  import sqlite3

  conn = sqlite3.connect("ledger.db")

  def summarize_income_expense(conn):
      cur = conn.cursor()
      cur.execute("""
          SELECT category,
                 SUM(CASE WHEN type='收入' THEN amount ELSE 0 END) AS income,
                 SUM(CASE WHEN type='支出' THEN amount ELSE 0 END) AS expense
          FROM records
          GROUP BY category
      """)
      return cur.fetchall()

  def total_summary(conn):
      cur = conn.cursor()
      cur.execute("SELECT SUM(CASE WHEN type='收入' THEN amount ELSE 0 END), SUM(CASE WHEN type='支出' THEN amount ELSE 0 END) FROM records")
      inc, exp = cur.fetchone()
      return (inc or 0, exp or 0, (inc or 0) - (exp or 0))

  for cat, inc, exp in summarize_income_expense(conn):
      print(f"{cat:6s} 收入{inc:>8.2f} 支出{exp:>8.2f}")
  print("总览:", total_summary(conn))
  conn.close()

- 每个分类返回收入和支出两列
- total_summary 返回三个数字
- SUM 结果做了 None 兜底
- 打印格式整齐
```
