# 主窗口与三层布局

> 数据层写完，从这一课开始搭界面。这一课只做一件事：把主窗口建出来，用 pack 切成上中下三层，先不管里面放什么控件。骨架对了，后面添砖加瓦才顺。

## 从 main.py 开始

**入口文件应该有多简单？越简单越好：**

```python
import tkinter as tk
import db
import ui

def main():
    root = tk.Tk()
    root.title("记账本 Ledger")
    root.geometry("800x600")

    db.init_global_conn("ledger.db")
    db.ensure_schema()               # 建表（如果不存在）

    app = ui.build(root)             # 把界面搭在 root 上

    def on_close():
        db.close_conn()
        root.destroy()
    root.protocol("WM_DELETE_WINDOW", on_close)

    root.mainloop()

if __name__ == "__main__":
    main()
```

**`main.py` 的职责**：创建根窗口、初始化数据层、把界面交给 `ui.build`、处理关闭清理。**它不创建任何 Label、不写任何 SQL。**

## 三层布局用 pack 三刀切

**`pack` 是最适合这种"上下分块 + 中间撑满"的布局管理器：**

```python
import tkinter as tk
import tkinter.ttk as ttk

def build(root):
    # 顶部工具栏
    toolbar = tk.Frame(root, height=40, bg="#e8e8e8")
    toolbar.pack(side="top", fill="x")

    # 底部录入区
    form = tk.Frame(root, height=80, bg="#f5f5f5")
    form.pack(side="bottom", fill="x")

    # 中间主体（先放一个占位 Frame，第 12 课换成 Treeview）
    body = tk.Frame(root, bg="white")
    body.pack(side="top", fill="both", expand=True)

    # 在各层里放点占位的说明文字
    tk.Label(toolbar, text="工具栏：统计 | 导出 | 设置", bg="#e8e8e8").pack(side="left", padx=8)
    tk.Label(form, text="录入区：日期 金额 分类 备注 [记一笔]", bg="#f5f5f5").pack(side="left", padx=8)
    tk.Label(body, text="记录列表区（Treeview 将在第 12 课放入）", fg="#999").pack(pady=40)

    return {"toolbar": toolbar, "form": form, "body": body}
```

**为什么用 pack 而不是 grid 或 place？**

- **pack 适合"分块"**：上中下三块边界清晰，三行 pack 就完事；
- **grid 适合"对齐"**：录入区里几个控件要对齐时再用 grid；
- **place 几乎不用**：绝对坐标，窗口缩放时控件不会跟着动。

**原则：外层用 pack 切块，内层用 grid 对齐。**

## expand=True 的意义

**中间 body 的 `fill="both", expand=True` 是这一课的关键：**

- `fill="both"`：控件在分配到的空间内横向纵向都撑满；
- `expand=True`：窗口变大时，剩余空间**分配**给这个控件。

**没有 `expand=True` 的话，你把窗口从 600 拉到 1000 高，表格还是原来的高，底下空一大片。**

**顺序有讲究**：pack 按代码顺序分空间。`side="top"` 的工具栏先拿走 40px，再轮到底部表单拿走 80px，**最后剩下的全给 body**（因为 body 有 expand=True）。

## 窗口尺寸与最小尺寸

**`geometry("800x600")` 设初始大小，但用户能随意拖。** 用 `minsize` 防止拖得过小导致控件挤爆：

```python
root.geometry("800x600")
root.minsize(640, 480)
```

**高分辨率屏建议**：别写死像素，让布局靠 `expand` 自适应。用户在大屏上放大窗口，表格跟着变大，这是桌面应用的基本素养。

## 翻车现场一：三个 Frame 都忘了 expand，中间空白

```python
toolbar.pack(side="top", fill="x")
form.pack(side="bottom", fill="x")
body.pack(side="top", fill="both")   # 少了 expand=True
```

**症状**：body 只有"刚好包住内容"那么高，窗口放大后中间一大片空白。

**原因**：没设 `expand=True`，剩余空间没人要，就被丢弃了。

**解决**：body 加 `expand=True`。

## 翻车现场二：side 顺序搞错，布局错乱

```python
body.pack(side="top", fill="both", expand=True)
toolbar.pack(side="top", fill="x")    # 后 pack 的工具栏跑到 body 下面去了
```

**症状**：工具栏出现在中间 body 的下方，而不是顶部。

**原因**：pack 的 side 决定"贴哪条边"，先 pack 的先占位置。body 先占了 top，toolbar 后 pack 时 top 已经被 body 的 expand 吃满了，只能挤到下面。

**解决**：按"从上到下"的自然顺序写 pack——toolbar 先、body 中间、form 最后（side="bottom" 会贴底边，不受顺序影响）。

## 翻车现场三：Frame 没指定高度就不显示

```python
toolbar = tk.Frame(root)         # 没设 height，也没放任何子控件
toolbar.pack(side="top", fill="x")
```

**症状**：toolbar 高度为 0，看不见。

**原因**：空 Frame 默认按"刚好包住内容"的尺寸，没内容就没高度。pack 的 `fill` 只在 Frame 有东西时才撑开。

**解决**：要么设 `height=40`（配合 `pack_propagate(False)` 防止被子控件撑变），要么往里放至少一个控件。

## 小结

- main.py 只负责启动：建窗口、初始化数据层、挂关闭清理
- 三层用 pack 切：toolbar(side=top) / body(side=top,expand) / form(side=bottom)
- 外层 pack 切块、内层 grid 对齐
- body 必须 fill="both",expand=True，否则窗口放大中间留白
- pack 顺序要按视觉从上到下排，side=bottom 的可以放最后
- 空 Frame 要设 height 或用 pack_propagate(False)

  import tkinter as tk

  def build(root):

      # body: fill both, expand True
      # form: side bottom
      # 三个按钮 + 提示回调
