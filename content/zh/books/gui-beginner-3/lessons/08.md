# 增删改 CRUD：INSERT / SELECT / UPDATE / DELETE

> 表建好了，这一课把四条核心操作（增查改删，简称 CRUD）一次讲完。它们是数据层的全部基本功，后面所有界面操作本质上都是调这四个。

## C 增：INSERT

**插入一条记录。** id 和 created_at 让数据库自动填：

```python
import sqlite3
from datetime import datetime

conn = sqlite3.connect("ledger.db")
cur = conn.cursor()

cur.execute("""
    INSERT INTO records(amount, category, date, note, type, created_at)
    VALUES (?, ?, ?, ?, ?, ?)
""", (38.5, "餐饮", "2026-09-27", "午餐", "支出", datetime.now().isoformat(timespec="seconds")))

conn.commit()
print("新记录的 id:", cur.lastrowid)   # 刚插入的 id
conn.close()
```

**两个要点：**

1. **`?` 占位符 + 参数元组**：千万别拼字符串（下一课专门讲为什么），占位符让 SQLite 自己做转义和类型处理；
2. **`cur.lastrowid`**：插入后立刻能拿到这条记录的自增 id，删改时要靠它定位行。

## R 查：SELECT

**查询最常用，按需求 F2 我们要"按时间倒序看全部记录"：**

```python
cur.execute("""
    SELECT id, amount, category, date, note, type
    FROM records
    ORDER BY date DESC, id DESC
""")
rows = cur.fetchall()
for r in rows:
    print(r)
```

**三个取结果的方法：**

| 方法 | 返回 |
|---|---|
| `fetchone()` | 一条（元组）或 None |
| `fetchmany(n)` | 最多 n 条 |
| `fetchall()` | 全部，列表 |

**`ORDER BY date DESC, id DESC`**：先按日期倒序，同一天的按 id 倒序，保证新录入的排在前面。

**配合 `row_factory = sqlite3.Row`**，返回的行能按列名取值：`r["amount"]`、`r["category"]`。

## 带条件的查询

**按分类看、按月看、看收入：**

```python
# 看"餐饮"分类
cur.execute("SELECT * FROM records WHERE category = ?", ("餐饮",))

# 看 2026 年 9 月（用 LIKE 前缀匹配）
cur.execute("SELECT * FROM records WHERE date LIKE ?", ("2026-09%",))

# 看收入，算总收入
cur.execute("SELECT SUM(amount) FROM records WHERE type = ?", ("收入",))
total_income = cur.fetchone()[0] or 0   # 注意：没有记录时 SUM 返回 None
```

**`SUM` 没匹配到行时返回 `None`**，不是 0。这是个常见坑，务必用 `or 0` 兜底。

## U 改：UPDATE

**修改一条已有记录，靠主键 id 定位：**

```python
cur.execute("""
    UPDATE records
    SET amount = ?, category = ?, date = ?, note = ?
    WHERE id = ?
""", (42.0, "餐饮", "2026-09-27", "午餐改", 1))   # 最后一个 1 是 id

conn.commit()
```

**`WHERE id = ?` 是必须的。** 忘了 WHERE，会把全表每一行的 amount 都改成 42.0——而且 SQLite 默认没有"确认提示"，直接生效。

## D 删：DELETE

**删除同样靠 id 定位：**

```python
cur.execute("DELETE FROM records WHERE id = ?", (1,))
conn.commit()
print("删了", cur.rowcount, "行")   # rowcount 告诉你影响几行
```

**`cur.rowcount` 是删改语句影响的行数。** 你删 id=999 但这种记录不存在，`rowcount` 就是 0，可以据此提示"没找到这条记录"。

## 把 CRUD 封装成函数

**数据层的任务就是把这四条操作包装成好调用的函数，界面层只跟这些函数打交道：**

```python
def add_record(conn, amount, category, date, note="", rtype="支出"):
    cur = conn.cursor()
    cur.execute("""
        INSERT INTO records(amount, category, date, note, type, created_at)
        VALUES (?,?,?,?,?,?)
    """, (amount, category, date, note, rtype, datetime.now().isoformat(timespec="seconds")))
    conn.commit()
    return cur.lastrowid

def get_all(conn):
    cur = conn.cursor()
    cur.execute("SELECT id,amount,category,date,note,type FROM records ORDER BY date DESC, id DESC")
    return cur.fetchall()

def update_record(conn, rid, amount, category, date, note):
    cur = conn.cursor()
    cur.execute("""
        UPDATE records SET amount=?, category=?, date=?, note=?
        WHERE id=?
    """, (amount, category, date, note, rid))
    conn.commit()

def delete_record(conn, rid):
    cur = conn.cursor()
    cur.execute("DELETE FROM records WHERE id=?", (rid,))
    conn.commit()
    return cur.rowcount
```

**这四个函数就是界面层需要的一切。** 界面层从此不需要知道 SQL 长什么样。

## 翻车现场一：UPDATE / DELETE 忘了 WHERE

```python
cur.execute("UPDATE records SET amount = 0")
# 或者
cur.execute("DELETE FROM records")
conn.commit()
```

**症状**：表里所有数据瞬间清零或被清空，没有报错、没有确认。

**原因**：少了 `WHERE`，作用范围变成全表。

**解决**：写 UPDATE/DELETE 时养成习惯，先把 WHERE 子句写好再填 SET。或者在开发阶段用一个"确认"包装函数，涉及全表的操作打日志告警。

## 翻车现场二：SUM 返回 None 直接拿去做除法

```python
cur.execute("SELECT SUM(amount) FROM records WHERE type='支出'")
total = cur.fetchone()[0]
ratio = 100 / total    # TypeError: unsupported operand type(s) for /: 'int' and 'NoneType'
```

**症状**：表为空时 `total` 是 None，下一行除法直接崩。

**原因**：聚合函数没匹配到行返回 None，不是 0。

**解决**：`total = cur.fetchone()[0] or 0`。同理 `COUNT` 不会返回 None（它返回 0），但 `SUM`/`AVG`/`MAX`/`MIN` 都会。

## 翻车现场三：fetchall 之后又 fetchone

```python
cur.execute("SELECT * FROM records")
all_rows = cur.fetchall()
first = cur.fetchone()   # None！游标已经走到末尾
```

**症状**：`fetchone()` 返回 None，你以为查询没结果。

**原因**：`fetchall()` 把游标耗尽了，再取就没东西了。

**解决**：想拿第一条，用 `fetchone()`；想拿全部，用 `fetchall()`。两者不要对同一游标混用。需要多次遍历，就把结果存进变量。

## 小结

- C 增 `INSERT ... VALUES(?,?,...)`，用 `cur.lastrowid` 拿新 id
- R 查 `SELECT ... ORDER BY date DESC, id DESC`，用 fetchone/many/all 取结果
- U 改 `UPDATE ... WHERE id=?`，务必带 WHERE
- D 删 `DELETE ... WHERE id=?`，用 rowcount 判断影响行数
- SUM 无匹配返回 None，记得 `or 0` 兜底
- 四条操作封装成函数，界面层只调函数、不写 SQL
