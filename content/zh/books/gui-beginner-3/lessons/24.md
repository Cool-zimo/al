# 中文字体：图表里中文显示方框的解决办法

> 你在图表里写中文标题，结果看到的是 `□□□` 一堆方块。这不是 bug，是字体没找到中文字形。这一课彻底解决这个问题，并顺带讲清楚 matplotlib 的字体配置。

## 问题：中文变成方块

**症状：**

```python
ax.set_title("各分类支出")     # 图上显示 "□□□□"
ax.set_xlabel("月份")          # 显示 "□□"
```

**原因**：matplotlib 默认字体（通常是 DejaVu Sans）不含中文字形。渲染时找不到对应的字，就用方块占位。

**这是 Windows / Linux / Mac 三平台都常见的问题**，只是默认字体不同。

## 三种解决办法

**从最推荐到最不推荐：**

### 方法一：rcParams 全局设置（推荐）

**在程序入口（main.py）设置一次，全局生效：**

```python
import matplotlib
matplotlib.use("TkAgg")
from matplotlib import rcParams

rcParams["font.sans-serif"] = ["Microsoft YaHei"]   # Windows 微软雅黑
rcParams["axes.unicode_minus"] = False              # 让负号正常显示
```

**常用中文字体名：**

| 平台 | 字体名 |
|---|---|
| Windows | `Microsoft YaHei`（微软雅黑）、`SimHei`（黑体）、`KaiTi`（楷体） |
| Mac | `PingFang SC`、`STHeiti`、`Arial Unicode MS` |
| Linux | `WenQuanYi Micro Hei`、`Noto Sans CJK SC` |

**`axes.unicode_minus = False` 这行别漏**：不设的话，负数坐标轴上的负号会显示成方块。

### 方法二：FontProperties 单次指定

**只给某个文字元素换字体：**

```python
from matplotlib.font_manager import FontProperties
fp = FontProperties(family="Microsoft YaHei", size=14)

ax.set_title("各分类支出", fontproperties=fp)
ax.set_xlabel("月份", fontproperties=FontProperties(family="SimHei"))
```

**适合混排场景**（比如标题用黑体、标签用楷体）。

### 方法三：指定字体文件路径

**字体名可能在不同机器上不一样，最稳妥是带一个字体文件：**

```python
from matplotlib.font_manager import FontProperties
fp = FontProperties(fname="assets/msyh.ttc", size=14)
ax.set_title("各分类支出", fontproperties=fp)
```

**缺点**：`.ttc`/`.ttf` 文件几 MB 到十几 MB，打包时要一起带上，体积变大。

## 跨平台方案

**记账本要发给别人用，字体名在不同系统上不一样。最稳妥的做法：**

```python
import platform
from matplotlib import rcParams

def setup_font():
    sysname = platform.system()
    if sysname == "Windows":
        rcParams["font.sans-serif"] = ["Microsoft YaHei"]
    elif sysname == "Darwin":          # macOS
        rcParams["font.sans-serif"] = ["PingFang SC", "STHeiti"]
    else:                              # Linux
        rcParams["font.sans-serif"] = ["WenQuanYi Micro Hei", "Noto Sans CJK SC"]
    rcParams["axes.unicode_minus"] = False

# main.py 里最早调用
setup_font()
```

**`platform.system()` 返回 `"Windows"` / `"Linux"` / `"Darwin"`**（Darwin 就是 macOS）。

**这套写法能保证你打包的 exe 在别人 Windows 上、你的 Linux 开发机上都能显示中文。**

## 验证字体是否生效

**想知道当前用的是哪个字体：**

```python
from matplotlib import rcParams
print(rcParams["font.sans-serif"])
# ['Microsoft YaHei']

# 查看某个字符能否被当前字体渲染
from matplotlib.font_manager import FontProperties
fp = FontProperties(family=rcParams["font.sans-serif"][0])
print(fp.get_name())
```

**如果还是方块，先确认字体名拼写对不对、系统里到底有没有这个字体。**

## 翻车现场一：设了字体但负号变成方块

**症状**：中文正常了，但图表里出现负数时，`-100` 显示成 `□100`。

**原因**：缺了 `rcParams["axes.unicode_minus"] = False`。

**解决**：补上这行。这是设置中文字体时必配的一行，永远成对出现。

## 翻车现场二：字体名拼错，静默回退

**症状**：写了 `"Microsoft YaHei"` 但拼成了 `"Microsoft YaHei "`（末尾多了空格），结果中文还是方块，也不报错。

**原因**：matplotlib 找不到这个字体就**静默回退**到默认字体，不打任何提示。

**解决**：用 `print(rcParams["font.sans-serif"])` 确认值，或直接指定 `fname` 指向一个存在的字体文件。

## 翻车现场三：打包后字体失效

**症状**：开发机上中文正常，PyInstaller 打包后别人的机器上又是方块。

**原因**：打包时 matplotlib 的字体缓存（fontlist）没被正确包含，或者目标机器没有你指定的那个字体。

**解决**：

1. 用跨平台的 `setup_font()` 探测方案（上面写的），运行时按系统选字体；
2. 或者用 `fname` 指向自带的 `.ttf` 文件，并在打包时通过 `--add-data` 把字体文件打进去。

**第 28 课讲打包时会再提 `--add-data`。**

## 小结

- 中文变方块是因为默认字体不含中文字形
- 推荐 rcParams 全局设置 font.sans-serif + axes.unicode_minus=False
- 常用字体：Windows 微软雅黑、Mac PingFang、Linux 文泉驿
- 跨平台用 platform.system() 探测，运行时选字体
- 字体名拼错会静默回退，不报错——用 print 确认
- 打包后要确保字体能被找到：要么探测方案，要么 --add-data 带字体文件

```quiz
type: local
exam: true
q: 用 FontProperties 给同一个图的不同元素指定不同字体：标题用 SimHei、X 轴标签用 KaiTi、图例用 Microsoft YaHei（没有该字体就跳过，用 try 判断）。打印每个 FontProperties 的 family。注意：需要 matplotlib，网页里跑不了，请点"在 VS Code 里打开"运行。
starter: |
  import matplotlib
  matplotlib.use("TkAgg")
  from matplotlib import rcParams
  from matplotlib.font_manager import FontProperties

  rcParams["axes.unicode_minus"] = False

  def make_fp(family):
      try:
          fp = FontProperties(family=family)
          fp.get_name()        # 触发解析，确认字体存在
          return fp
      except Exception as e:
          print(f"字体 {family} 不可用，跳过:", e)
          return None

  title_fp = make_fp("SimHei")
  label_fp = make_fp("KaiTi")
  legend_fp = make_fp("Microsoft YaHei")

  for name, fp in [("标题",title_fp),("标签",label_fp),("图例",legend_fp)]:
      print(name, fp.get_name() if fp else "None")
checklist:
- 三种字体分别尝试
- 用了 try/except 容错
- 打印了每个 FontProperties 的实际 family
- 不可用的字体能优雅跳过而不是崩溃
```
