# Treeview 表格：列定义与数据填充

> 这一课把中间的占位 Frame 换成真正的表格——ttk.Treeview。它是 tkinter 里最接近"专业软件界面"的控件，记账本的记录列表全靠它。

## Treeview 是什么

**Treeview 是一个"既能做树又能做表格"的控件。** 我们只用它的"表格模式"：若干列、若干行，支持滚动条、排序、选中行。

```python
import tkinter as tk
import tkinter.ttk as ttk

root = tk.Tk()
root.geometry("800x400")

cols = ("date", "amount", "category", "note", "type")
tree = ttk.Treeview(root, columns=cols, show="headings")

# 定义列标题
tree.heading("date", text="日期")
tree.heading("amount", text="金额")
tree.heading("category", text="分类")
tree.heading("note", text="备注")
tree.heading("type", text="类型")

# 定义列宽和对齐
tree.column("date", width=120, anchor="center")
tree.column("amount", width=100, anchor="e")     # 金额右对齐
tree.column("category", width=100, anchor="center")
tree.column("note", width=280, anchor="w")
tree.column("type", width=80, anchor="center")

tree.pack(fill="both", expand=True)
root.mainloop()
```

**`show="headings"` 的意思是：只显示列标题，不显示最左边那棵树的"树列"。** 只做表格时一定要加，否则会多出一条空白树列。

## 插入行：insert 与 iid

**`tree.insert(parent, index, iid, values)` 插入一行：**

```python
tree.insert("", "end",
            iid="1",                              # 用数据库 id 当 iid，方便定位
            values=("2026-09-27", "38.5", "餐饮", "午餐", "支出"))
```

**四个参数：**

| 参数 | 含义 |
|---|---|
| parent | 表格模式填 `""`（表示顶层） |
| index | `"end"` 表示追加到末尾 |
| iid | 这行的唯一标识，建议用数据库 id |
| values | 各列的值，按 cols 顺序 |

**iid 是本课的命门**，务必用数据库主键 id 来设——后面删除、修改时要靠它反查"用户选中了哪条记录"。

## 金额与日期的格式化

**数据库里存的是 `38.5` 和 `"2026-09-27"`。界面上想显示得更好看：**

```python
def fmt_amount(v):
    return f"{v:,.2f}"          # 38.5 → "38.50"，千分位：1234.5 → "1,234.50"

def fmt_date(s):
    # 2026-09-27 → 2026/09/27，或按需要显示
    return s.replace("-", "/")
```

**在插入前格式化，而不是直接把数据库原始值塞进表格：**

```python
for r in db.get_all(conn):
    # r 是 Row 对象：id, amount, category, date, note, type
    tree.insert("", "end", iid=str(r["id"]),
                values=(fmt_date(r["date"]),
                        fmt_amount(r["amount"]),
                        r["category"],
                        r["note"] or "",
                        r["type"]))
```

**金额显示两位小数、加千分位，是"专业感"的关键细节。** 用户看到 `1,234.50` 而不是 `1234.5`，会觉得这软件靠谱。

## 加滚动条

**记录多了必须能滚动。** 滚动条要包一层 Frame，用 `grid` 让 Treeview 和 Scrollbar 贴合：

```python
wrap = tk.Frame(root)
wrap.pack(fill="both", expand=True)

tree = ttk.Treeview(wrap, columns=cols, show="headings")
vsb = ttk.Scrollbar(wrap, orient="vertical", command=tree.yview)
tree.configure(yscrollcommand=vsb.set)

wrap.grid_rowconfigure(0, weight=1)
wrap.grid_columnconfigure(0, weight=1)
tree.grid(row=0, column=0, sticky="nsew")
vsb.grid(row=0, column=1, sticky="ns")
```

**`tree.configure(yscrollcommand=vsb.set)` + `Scrollbar(command=tree.yview)`** 这一对互相绑定，让滚动条和表格联动。只写一边，滚动条就成了摆设。

## 刷新表格：先清空再重填

**数据变了要刷新，最简单可靠的做法是"全量刷新"：**

```python
def refresh_table(tree, conn):
    # 先清空
    for iid in tree.get_children():
        tree.delete(iid)
    # 再重填
    for r in db.get_all(conn):
        tree.insert("", "end", iid=str(r["id"]),
                    values=(fmt_date(r["date"]), fmt_amount(r["amount"]),
                            r["category"], r["note"] or "", r["type"]))
```

**`tree.get_children()` 返回所有行的 iid 列表。** 全量刷新在记录几千条以内都够快，第 20 课再讲增量更新的取舍。

## 翻车现场一：忘了设 iid，无法定位选中行

```python
tree.insert("", "end", values=(...))    # 没传 iid
# 之后想拿选中行对应的数据库 id
sel = tree.selection()[0]
print(tree.item(sel)["values"])         # 只能拿到 values，拿不到 id
```

**症状**：你拿到了选中行的 values，但 id 不在 values 里（你没把 id 作为一列显示），于是不知道该改哪条记录。

**原因**：没设 iid，Treeview 自动生成一串类似 `"I001"` 的随机 iid，和数据库 id 对不上。

**解决**：插入时 `iid=str(r["id"])`。之后 `int(tree.selection()[0])` 就直接是数据库 id。

## 翻车现场二：没加 show="headings"，左边多出空白树列

**症状**：表格最左边多出一列空白（树列），挤占了其他列的空间，看起来很别扭。

**原因**：Treeview 默认 `show="tree headings"`，既显示树列也显示标题。只做表格时树列是多余的。

**解决**：`ttk.Treeview(..., show="headings")`。

## 翻车现场三：插入数据前忘了定义列

```python
tree = ttk.Treeview(root)        # 没传 columns
tree.insert("", "end", values=("2026-09-27", "38.5", "餐饮"))
# 只显示第一列，其余值被忽略
```

**症状**：明明插了三列数据，界面上只显示第一列，另外两列是空的。也不报错。

**原因**：没在创建时声明 `columns=("date","amount","category")`，Treeview 不知道有几列。

**解决**：创建时把 columns 元组传全，并为每列配 heading 和 column 设置。

## 小结

- Treeview 的表格模式要设 show="headings" 隐藏树列
- 插入行用 insert，iid 务必用数据库主键 id，便于反查
- 金额要格式化：两位小数、千分位，提升专业感
- 滚动条要双向绑定：yscrollcommand + Scrollbar command
- 刷新 = 先 get_children 清空，再循环 insert 重填
- 列要在创建时声明 columns，并为每列配 heading
