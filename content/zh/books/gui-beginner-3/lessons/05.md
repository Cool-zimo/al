# 技术选型：为什么用 SQLite

> 这一册的全部技术栈都要在这一课定下来：数据存哪儿、用什么库画图、要不要装第三方包。定完这一课，后面五章就是在填满这套选型的细节。

## 候选方案对比

**单机记账本存数据，至少有四种思路：**

| 方案 | 优点 | 致命缺点 |
|---|---|---|
| 纯文本 / CSV | 不用学新东西，记事本能看 | 改一行要读全文件重写；没有类型；多行文本里含逗号就崩 |
| JSON 文件 | 能存嵌套结构 | 同 CSV，改一条要读全文件；不能排序筛选 |
| Excel | 用户熟、能自己改 | 依赖第三方库 openpyxl；文件被用户打开时程序读不了 |
| **SQLite** | 标准库自带、单文件、能 SQL 查询排序 | 几乎找不到 |

**结论：SQLite 是单机桌面应用的默认答案。** 它是真正的数据库（支持 SQL、索引、事务），但整个库就一个文件，不需要装服务器。

## 为什么不用纯文本文件

**你可能想："数据就这么点，用 CSV 不行吗？" 可以，但你要自己解决三件事：**

1. **改一条就要读全文件重写**：删一条 = 读 1000 行、跳过那一行、写回 999 行。SQLite 一条 `DELETE` 搞定。
2. **没有类型**：CSV 里全是字符串，`"12.5"`、`"2026-09-27"` 都要你自己转。SQLite 有 REAL、TEXT、DATE 类型，查出来就是数字。
3. **筛选和排序要自己写循环**：想"看 9 月的餐饮"，CSV 你要写循环 + 条件判断 + 手动排序。SQLite 一句 `SELECT ... WHERE category='餐饮' AND date LIKE '2026-09-%' ORDER BY date DESC`。

**用文本文件等于自己重写一个粗糙的数据库。** 既然标准库里就有现成的，何必呢。

## 为什么不用 Excel

**Excel 看着诱人：用户能直接打开看、能自己改。** 但有三个硬伤：

1. **依赖第三方**：`openpyxl` 或 `xlrd` 都不在标准库里，打包时要额外处理；
2. **文件锁**：用户双击打开这个 xlsx，你的程序就读不了、写不了，报权限错误；
3. **并发写入**：SQLite 有写锁机制，多个操作排队；Excel 文件没有。

**本项目要求"标准库够不够"这条选型原则，Excel 直接出局。**

## 标准库够不够

**列一下这一册要用到的东西，看标准库能不能覆盖：**

| 需求 | 用到的库 | 是否标准库 |
|---|---|---|
| 界面 | tkinter + ttk | ✅ 是 |
| 表格 | ttk.Treeview | ✅ 是 |
| 数据库 | sqlite3 | ✅ 是 |
| 图表 | matplotlib | ❌ 第三方 |
| 打包 | PyInstaller | ❌ 第三方 |

**只有图表和打包两项需要装第三方。** 这正是我们的安排：第 2~4 章完全用标准库，把项目骨架搭起来；第 5 章才引入 matplotlib 画图；第 6 章才引入 PyInstaller 打包。

**为什么要这样分阶段引入第三方？** 因为每多一个依赖，打包体积就大一圈、出问题的概率就多一分。先把"能离线、零依赖"的部分做完，最后才加必要的两个。

## matplotlib 为什么可以接受

**图表是这一册的亮点，自己画太麻烦。** matplotlib 是科学计算的事实标准，几乎所有学 Python 的人迟早要装，引入它的代价很低。而且它原生支持嵌入 tkinter（第 22 课讲 `FigureCanvasTkAgg`），不用来 `plt.show()` 弹独立窗口。

## 技术栈一览

**把选型和版本意识写下来，方便以后查：**

```

tkinter / ttk        （标准库）

```

## 翻车现场：把数据存进被 PyInstaller 打包进 exe 的文件

**有些新手把 `ledger.db` 放在源码目录里，以为打包后会一起打进 exe。**

**症状**：打包后的 exe 首次运行报 `sqlite3.OperationalError: unable to open database file`，或者数据怎么都存不进去。

**原因**：PyInstaller 打包的文件在运行时会解压到一个临时目录（`sys._MEIPASS`），这个目录是**只读**的。你往里写数据库等于往只读区写文件。

**解决**：数据库文件放在用户数据目录（第 27 课讲 `appdirs` 或用 `os.path.expanduser("~/.ledger/ledger.db")`），运行时判断是否存在、不存在就新建。

## 小结

- 数据存 SQLite：单文件、标准库、能 SQL，单机应用的默认答案
- 纯文本/CSV 要自己重写数据库功能，不值得
- Excel 依赖第三方且文件锁问题多，出局
- 标准库覆盖界面、表格、数据库；只有图表和打包需要第三方
- 第三方分两波引入：第 5 章 matplotlib、第 6 章 PyInstaller
- 数据库文件要放用户目录，别放打包后的只读区
