# 最近公共祖先 LCA

> 最近公共祖先（Lowest Common Ancestor）是树题里最经典的"返回节点"问题：给定两个节点 p、q，找它们 deepest 的公共祖先。它的解法极其优雅——几行递归，却藏着精妙的分治思想。

## 问题定义：什么是 LCA

**最近公共祖先：对于有根树的两个节点 p、q，它们的公共祖先是所有"同时是 p 的祖先和 q 的祖先"的节点；其中"最深"的那个，就是 LCA。**

```
        3
      /   \
     5     1
    / \   / \
   6   2 0   8
      / \
     7   4
```

p=5、q=1 的 LCA 是 3（3 是 5 和 1 的共同祖先，且没有更深的）。
p=5、q=4 的 LCA 是 5（5 是 4 的祖先，也是自己的祖先）。

**LCA 有个非常实用的性质：如果 p、q 分别在某个节点的左右两侧，那个节点就是它们的 LCA。**

## 思路：分治 + 短路

**核心思路：递归处理左右子树，返回"这一支里是否找到了 p 或 q"。**

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def build(vals):
    if not vals or vals[0] is None:
        return None
    nodes = [None if v is None else TreeNode(v) for v in vals]
    for i in range(len(nodes)):
        if nodes[i] is None:
            continue
        left, right = 2 * i + 1, 2 * i + 2
        if left < len(nodes) and nodes[left] is not None:
            nodes[i].left = nodes[left]
        if right < len(nodes) and nodes[right] is not None:
            nodes[i].right = nodes[right]
    return nodes[0]

def lowest_common_ancestor(root, p, q):
    if root is None or root is p or root is q:
        return root                    # 找到了 p 或 q，直接返回
    left = lowest_common_ancestor(root.left, p, q)
    right = lowest_common_ancestor(root.right, p, q)
    if left and right:
        return root                    # 左右各找到一个，当前节点即 LCA
    return left or right               # 只在一侧找到，往上传递
```

**逐句理解：**

- `if root is None or root is p or root is q: return root` —— 空节点返回 None；找到了 p 或 q，返回这个节点。注意用 `is`，因为我们要比的是"同一个对象"，不是"值相等"。
- `if left and right: return root` —— 左子树找到了一个、右子树找到了另一个，说明 p 和 q 分居两侧，当前节点就是 LCA。
- `return left or right` —— 只在一侧找到，把那个结果往上传递。

```python
t = build([3, 5, 1, 6, 2, 0, 8, None, None, 7, 4])
p = t.left          # 5
q = t.right         # 1
print(lowest_common_ancestor(t, p, q).val)   # 3

p2 = t.left.right.left   # 7
print(lowest_common_ancestor(t, p, p2).val)  # 5
```

## 翻车现场：用值比较 `root.val == p.val` 而不是 `is`

```python
# WRONG：用值相等来判断，遇到重复值时出错
def lowest_common_ancestor_wrong(root, p, q):
    if root is None or root.val == p.val or root.val == q.val:  # ← 值比较
        return root
    left = lowest_common_ancestor_wrong(root.left, p, q)
    right = lowest_common_ancestor_wrong(root.right, p, q)
    if left and right:
        return root
    return left or right

t2 = build([3, 5, 1, 5, 2])   # 左子树里有两个值为 5 的节点
p = t2.left          # 第一个 5
q = t2.left.left     # 第二个 5
print(lowest_common_ancestor_wrong(t2, p, q).val)  # 可能返回 3，错误！
```

**当树里存在重复值时，`root.val == p.val` 会误判"找到 p"。** LCA 的定义基于"节点身份"，不是"节点值"。

**正确做法：用 `root is p` 判断是否是同一个对象。** 在算法题里，p、q 通常直接作为节点引用传入，用 `is` 天然正确。

## 翻车现场：p 或 q 本身就是祖先

**"一个节点是另一个节点的祖先"这种情况要单独处理吗？** 不用——上面的算法天然覆盖。

```python
t = build([3, 5, 1, 6, 2, 0, 8, None, None, 7, 4])
p = t.left        # 5
q = t.left.right  # 2
print(lowest_common_ancestor(t, p, q).val)   # 5
```

**为什么对？** 递归进入 5 的子树时，`lowest_common_ancestor(5, 5, 2)` 第一行就命中 `root is p`，返回 5。往上回到 5 的父节点 3 时，左子树返回 5、右子树返回 None，于是 `left or right` 返回 5。**结果是 5，正是正确答案**——因为 5 本身就是 2 的祖先，也是自己的祖先，LCA 就是 5。

**这个性质让 LCA 的实现异常简洁：不用分类讨论"是否互为祖先"。**

## BST 的 LCA：利用有序性，O(h) 不用递归两支

**如果树是 BST，LCA 可以用有序性大幅简化：比较当前节点值和 p、q 的值，决定往左还是往右。**

```python
def lca_bst(root, p, q):
    if root is None:
        return None
    # p、q 都在左子树
    if root.val > p.val and root.val > q.val:
        return lca_bst(root.left, p, q)
    # p、q 都在右子树
    if root.val < p.val and root.val < q.val:
        return lca_bst(root.right, p, q)
    # 分居两侧（或当前节点就是 p/q），当前节点即 LCA
    return root

t = build([6, 2, 8, 0, 4, 7, 9, None, None, 3, 5])
print(lca_bst(t, t.left, t.right).val)              # 6  (2 和 8 的 LCA)
print(lca_bst(t, t.left.right, t.left.right.right).val)  # 4  (4 和 5 的 LCA)
```

**关键判断：`if (p.val <= root.val <= q.val) or (q.val <= root.val <= p.val)` 也可以。** 只要 p、q 分居两侧（或其中之一是根），根就是 LCA，直接返回。

**BST 版是 O(h) 且只走一条路径，而普通二叉树版是 O(n) 且几乎遍历整棵树。** 因为 BST 的有序性提供了"方向感"，普通树没有。

## LCA 的应用：找两个节点的距离

**两个节点 u、v 的距离 = depth(u) + depth(v) - 2*depth(LCA(u,v))。** 只要你能算深度和 LCA，距离就有了。

```python
def depth(root, target, d=0):
    if root is None:
        return -1
    if root is target:
        return d
    return depth(root.left, target, d+1) or depth(root.right, target, d+1) or -1

def distance(root, u, v):
    lca = lowest_common_ancestor(root, u, v)
    return depth(root, u) + depth(root, v) - 2 * depth(root, lca)

t = build([3, 5, 1, 6, 2, 0, 8, None, None, 7, 4])
u = t.left          # 5
v = t.right         # 1
print(distance(t, u, v))   # 2  (5->3->1)
```

**`depth` 返回从根到 target 的边数。** 距离公式的几何意义：u 到 LCA 是 `depth(u)-depth(lca)`，v 到 LCA 是 `depth(v)-depth(lca)`，相加即得。

## 小结

- LCA 定义：p、q 的所有公共祖先中"最深"的那个
- 普通二叉树 LCA：`if left and right: return root; return left or right`，O(n)
- **用 `is` 比较节点身份，不能用 `==` 比值**——重复值会导致误判
- 算法天然覆盖"一个节点是另一个的祖先"的情况，无需分类讨论
- BST 版利用有序性，只走一条路径，O(h)：p、q 分居两侧时当前节点即 LCA
- 距离公式：`depth(u) + depth(v) - 2*depth(LCA)`
