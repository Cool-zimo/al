# 二维 DP：最长公共子序列 LCS

> 一维 DP 只用一个索引就能描述状态，二维 DP 需要两个索引。本课以最长公共子序列（LCS）为例，讲清二维 DP 的 dp 数组含义、填表顺序和边界处理。

## LCS 问题描述

**给定两个字符串 text1 和 text2，返回它们最长公共子序列的长度。子序列不要求连续，但必须保持相对顺序。**

例如：`text1 = "abcde"`, `text2 = "ace"` → LCS 是 `"ace"`，长度为 3。

## dp[i][j] 的含义

> `dp[i][j]` = **text1 的前 i 个字符**与 **text2 的前 j 个字符**的最长公共子序列长度

**注意"前 i 个字符"意味着考虑的是 `text1[0:i]`（左闭右开），即下标 0 到 i-1。**

**这种定义方式的好处是：dp[0][j] 表示空串与 text2 前 j 个字符的 LCS = 0，天然处理了空串边界。**

## 转移方程

**考虑 `text1[i-1]` 和 `text2[j-1]`（因为 dp[i] 对应前 i 个字符，最后一个字符是下标 i-1）：**

```
如果 text1[i-1] == text2[j-1]：
    dp[i][j] = dp[i-1][j-1] + 1     # 两个字符匹配，LCS 长度 +1
否则：
    dp[i][j] = max(dp[i-1][j], dp[i][j-1])  # 不匹配，取删掉其中一个字符后的最大值
```

**为什么不匹配时取 `max(dp[i-1][j], dp[i][j-1])`？**

- `dp[i-1][j]`：不考虑 text1 的第 i 个字符（相当于从 text1 中删掉它）
- `dp[i][j-1]`：不考虑 text2 的第 j 个字符（相当于从 text2 中删掉它）

**两者取最大，就是"至少舍弃一个字符"后能获得的最大 LCS。**

## 完整实现与填表过程

```python
def longest_common_subsequence(text1, text2):
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    
    return dp[m][n]

print(longest_common_subsequence("abcde", "ace"))   # 3
print(longest_common_subsequence("abc", "abc"))    # 3
print(longest_common_subsequence("abc", "def"))    # 0
```

**以 `text1 = "abcde"`, `text2 = "ace"` 为例，填表过程：**

```
      ""  a   c   e
""    0   0   0   0
a     0   1   1   1
b     0   1   1   1
c     0   1   2   2
d     0   1   2   2
e     0   1   2   3
```

**读表方式：**

- 第 0 行和第 0 列全为 0（空串与任何串的 LCS 都是 0）
- `dp[1][1]`：text1 前 1 个字符 "a" 与 text2 前 1 个字符 "a" → 匹配 → `dp[0][0] + 1 = 1`
- `dp[3][2]`：text1 前 3 个字符 "abc" 与 text2 前 2 个字符 "ac" → 匹配 c → `dp[2][1] + 1 = 2`
- `dp[5][3]`：最终答案 3

## 填表顺序：为什么按行从左到右、从上到下

**计算 dp[i][j] 需要三个子问题：dp[i-1][j-1]（左上）、dp[i-1][j]（上方）、dp[i][j-1]（左方）。**

```
        j-1    j
      ┌──────┬─────┐
 i-1  │  ↖  │  ↑  │
      ├──────┼─────┤
  i   │  ←  │ dp[i][j]
      └──────┴─────┘
```

**按行从左到右、从上到下遍历，保证左上、上方、左方都已在之前计算完毕。**

```python
for i in range(1, m + 1):       # 从上到下
    for j in range(1, n + 1):  # 从左到右
        # 此时 dp[i-1][j-1]、dp[i-1][j]、dp[i][j-1] 都已算好
        ...
```

**如果反过来从右下往左上填，依赖项还没算，结果全错。**

## 翻车现场：dp 数组只开 m×n，没有多出来的那一行/列

**忘记给空串预留位置，导致处理第一行/第一列时索引越界。**

```python
# WRONG：dp 开成 m × n，没多开一行一列
def lcs_wrong(text1, text2):
    m, n = len(text1), len(text2)
    dp = [[0] * n for _ in range(m)]    # 只有 m 行 n 列，没有 0 行 0 列
    for i in range(m):
        for j in range(n):
            if text1[i] == text2[j]:
                # 需要 dp[i-1][j-1]，i=0 或 j=0 时越界
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m - 1][n - 1]

# IndexError: list index out of range
```

**修复：dp 开成 `(m+1) × (n+1)`，索引整体右移一位，用 `text1[i-1]` 和 `text2[j-1]` 访问字符：**

```python
def lcs_correct(text1, text2):
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]  # 多开一行一列
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:    # 用 i-1 和 j-1 访问字符
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]
```

**"多开一格"技巧：dp 数组大小比输入长度多 1，用第 0 行/列存放 base case（通常为 0），代码更简洁、不易出错。**

## 翻车现场：字符串比较时用了 text1[i] 而不是 text1[i-1]

**这是索引偏移问题：dp[i][j] 对应"前 i 个字符"，最后一个字符的下标是 i-1，不是 i。**

```python
# WRONG：用 text1[i] 和 text2[j] 比较
def lcs_bad_index(text1, text2):
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i] == text2[j]:    # IndexError! i 可能等于 m
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]

# IndexError: string index out of range
```

**当 i = m 时，`text1[i]` 访问的是 `text1[m]`，越界了。** 正确的应该是 `text1[i-1]`。

**记住口诀："dp 的索引比字符串的索引多 1"。** dp[i][j] 处理的是 text1[i-1] 和 text2[j-1]。

## 翻车现场：不匹配时只取了 dp[i-1][j]，忘了 dp[i][j-1]

**LCS 不匹配时需要同时考虑"删 text1 的字符"和"删 text2 的字符"两种情况，只取一个会漏解。**

```python
# WRONG：不匹配时只取了 dp[i-1][j]
def lcs_incomplete(text1, text2):
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = dp[i - 1][j]    # 只考虑了删 text1 的字符
                # 忘了 max(dp[i-1][j], dp[i][j-1])
    return dp[m][n]

print(lcs_incomplete("abcde", "ace"))   # 结果偏小或错误
```

**为什么必须取 max？** 因为 `dp[i-1][j]` 和 `dp[i][j-1]` 代表两种不同的"舍弃策略"，哪一个能得到更长的公共子序列是不确定的，必须取最大。

## 小结

- **LCS 的 dp[i][j]**：text1 前 i 个字符与 text2 前 j 个字符的 LCS 长度
- **匹配时**：`dp[i][j] = dp[i-1][j-1] + 1`
- **不匹配时**：`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`
- **填表顺序**：按行从左到右、从上到下，确保依赖项已算
- **"多开一格"技巧**：dp 开成 (m+1)×(n+1)，第 0 行/列天然为 0，处理空串边界
- **索引口诀**："dp 的索引比字符串的索引多 1"，用 text1[i-1] 和 text2[j-1]
- 常见坑：数组大小开错、索引偏移、不匹配时只取一个方向
