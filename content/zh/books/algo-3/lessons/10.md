# 堆与优先队列：完全二叉树的数组表示、heapq

> 堆（Heap）是一种特殊的完全二叉树：父节点的值总是"不大于/不小于"子节点。它的杀手级应用是优先队列——随时能 O(1) 拿到最大/最小元素。这一课讲清它的数组表示和 Python 的 heapq。

## 完全二叉树：堆的物理结构

**完全二叉树（Complete Binary Tree）是"从上到下、从左到右填满"的二叉树。** 除了最后一层，其他层都是满的；最后一层的节点全部靠左。

```
        10
      /    \
     7      9
    / \    / \
   5   6  3   8
  /
 2
```

**完全二叉树的最大好处：可以用数组紧凑存储，不用指针。** 下标从 0 开始，节点 i 的左儿子是 `2i+1`、右儿子是 `2i+2`、父节点是 `(i-1)//2`。

```python
heap = [10, 7, 9, 5, 6, 3, 8, 2]
# 下标 0:10, 1:7, 2:9, 3:5, 4:6, 5:3, 6:8, 7:2
print(heap[1], heap[2*1+1], heap[2*1+2])   # 7 5 6  (节点 7 的左右儿子)
print(heap[(5-1)//2])                       # 9  (节点 3 的父节点)
```

**`2i+1` 和 `(i-1)//2` 是堆的命脉。** 堆的插入、删除、下沉、上浮，全部靠这两个公式在数组里定位父子，不涉及任何指针操作。

## 堆的性质：父节点不大于子节点

**最大堆（Max Heap）：父节点的值 ≥ 两个子节点。** 最小堆（Min Heap）：父节点的值 ≤ 两个子节点。

**堆的根就是全局最大（或最小）元素，O(1) 可取。** 这是堆的核心价值。

```python
max_heap = [100, 80, 90, 50, 60, 70, 85]
print(max_heap[0])   # 100，最大值，O(1)
```

**堆是"局部有序"的，不是"全局有序"的。** 父 ≥ 子，但左兄弟和右兄弟之间没有大小关系。所以堆不能像 BST 那样做二分查找（找某个具体值要 O(n)）。

**这个区别很重要**：BST 有序所以能查、能删任意值；堆不保证有序，但它能让"取最大/最小"保持 O(log n)。两者优化的是不同的操作。

## heapq：Python 的最小堆

**Python 标准库 `heapq` 实现的是最小堆。** 所有操作都作用于普通列表。

```python
import heapq

h = []
heapq.heappush(h, 5)
heapq.heappush(h, 1)
heapq.heappush(h, 3)
heapq.heappush(h, 2)
heapq.heappush(h, 4)

print(h)            # [1, 2, 4, 5, 3]  ← 注意：不是完全排序的
print(heapq.heappop(h))   # 1
print(heapq.heappop(h))   # 2
print(heapq.heappop(h))   # 3
```

**`heapq.heappush(h, x)` 把 x 加入堆并维护堆性质，O(log n)。**
**`heapq.heappop(h)` 弹出并返回最小值，O(log n)。**

**`h` 看起来没排序，但满足堆性质。** 打印 `h` 得到 `[1, 2, 4, 5, 3]`，确实不是升序。但 `heappop` 每次都正确返回当前最小值——这就是"局部有序够用了"。

## heapify：把普通列表变成堆

**`heapq.heapify(lst)` 可以把任意列表原地变成堆，O(n)。** 比一个一个 push 快（总 O(n log n)）。

```python
import heapq

a = [5, 1, 3, 2, 4]
heapq.heapify(a)
print(a)   # [1, 2, 4, 5, 3]

# 依次弹出
while a:
    print(heapq.heappop(a), end=' ')   # 1 2 3 4 5
```

**`heapify` 之后反复 `heappop` 就能得到升序序列——这就是堆排序。** 时间 O(n log n)，空间 O(1)（原地），但不稳定。

## 翻车现场：heapq 是最小堆，想取最大要取反

```python
# WRONG：直接用 heapq 想得到"最大值优先"，结果得到最小值
import heapq
h = []
for x in [5, 1, 3, 2, 4]:
    heapq.heappush(h, x)
print(heapq.heappop(h))   # 1，不是 5
```

**`heapq` 永远是最小堆，没有"参数改成最大堆"的选项。**

**想要最大堆，存负数：**

```python
import heapq
h = []
for x in [5, 1, 3, 2, 4]:
    heapq.heappush(h, -x)        # 存负数
print(-heapq.heappop(h))         # 5  ✓
```

**存负数后，"最小负数"对应"最大正数"。** 这是用最小堆模拟最大堆的标准技巧。Top-K 大元素、Dijkstra 等场景都要用到。

## 堆的插入：先放末尾，再上浮

**插入步骤：把新元素放到数组末尾，然后不断和父节点比较，如果比父节点"更优"就交换，直到满足堆性质。**

```python
def heap_push(heap, x):
    heap.append(x)
    i = len(heap) - 1
    while i > 0:
        parent = (i - 1) // 2
        if heap[i] < heap[parent]:    # 最小堆：子 < 父 就交换
            heap[i], heap[parent] = heap[parent], heap[i]
            i = parent
        else:
            break

h = []
for x in [5, 1, 3, 2, 4]:
    heap_push(h, x)
print(h)   # [1, 2, 4, 5, 3]
```

**上浮最多走树高 h = O(log n) 步，所以插入是 O(log n)。**

## 堆的弹出：取根，末尾补上，再下沉

**弹出步骤：保存根（最小值），把末尾元素移到根，然后不断和两个子节点中更优的那个交换，下沉到正确位置。**

```python
def heap_pop(heap):
    if not heap:
        raise IndexError("pop from empty heap")
    ans = heap[0]
    last = heap.pop()
    if not heap:           # 弹出后变空
        return ans
    heap[0] = last
    i = 0
    n = len(heap)
    while True:
        left = 2 * i + 1
        right = 2 * i + 2
        smallest = i
        if left < n and heap[left] < heap[smallest]:
            smallest = left
        if right < n and heap[right] < heap[smallest]:
            smallest = right
        if smallest == i:
            break
        heap[i], heap[smallest] = heap[smallest], heap[i]
        i = smallest
    return ans

h = [1, 2, 4, 5, 3]
print(heap_pop(h))   # 1
print(h)             # [2, 3, 4, 5]
```

**下沉也最多走 O(log n) 步。** 整个堆的核心操作——push、pop、上浮、下沉——都是 O(log n)。

## 堆的应用：求第 K 大元素

**Top-K 问题：用大小为 K 的堆维护"目前最小的 K 个"或"目前最大的 K 个"。**

```python
import heapq

def kth_largest(nums, k):
    """返回第 k 大的元素。"""
    heap = []
    for x in nums:
        heapq.heappush(heap, x)
        if len(heap) > k:
            heapq.heappop(heap)      # 保持堆大小为 k
    return heap[0]

print(kth_largest([3, 2, 1, 5, 6, 4], 2))   # 5
```

**堆里始终保存"最大的 K 个元素"，堆顶是这 K 个里最小的，也就是第 K 大。** 时间 O(n log k)，空间 O(k)。比排序 O(n log n) 更省，尤其在 k 很小的时候。

**若 k 很大（接近 n），排序反而更简单。** 选算法要看数据范围（第 26 课会系统讲这个思路）。

## 翻车现场：heapify 之后误以为列表已完全排序

```python
import heapq
a = [5, 1, 3, 2, 4]
heapq.heapify(a)
print(a)                # [1, 2, 4, 5, 3]
print(a[1] < a[2])      # True，但整体不是升序
```

**`heapify` 之后 `a` 不是升序列表。** 它只保证"父 ≤ 子"。想拿到完全排序的结果，必须反复 `heappop`。

**`heapq` 不提供"排序列表"这个操作，只提供"取最小"的能力。** 如果你需要完整排序，直接用 `sorted()` 即可（Timsort，通常更快）。

## 小结

- 完全二叉树用数组存储：左儿子 `2i+1`、右儿子 `2i+2`、父 `(i-1)//2`
- 最大堆父 ≥ 子，最小堆父 ≤ 子；根即全局最值，O(1) 可取
- **堆是局部有序，不能二分查找**；BST 全局有序但取最值要 O(log n)
- `heapq` 是最小堆：`heappush`、`heappop`、`heapify` 都是 O(log n)/O(n)
- 需要最大堆就存负数 `-x`
- 插入=放末尾上浮，弹出=末尾补根下沉，都是 O(log n)
- Top-K 用大小为 K 的堆，O(n log k)
