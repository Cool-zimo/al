# 收官：一道综合题从暴力 → 优化 → 最优

> 本课用"最大子数组和"这道题，完整展示从最朴素的暴力到分治再到最优解法的演进过程。学会这种"逐步优化"的思维，你就能独立攻克新题。

## 题目：最大子数组和

**问题：** 给定一个整数数组 nums，找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

**示例：**

```
nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
最大子数组是 [4, -1, 2, 1]，和为 6
```

**为什么选这道题？** 它足够简单（人人都看得懂），又足够丰富（有 4 种解法，从 O(n^3) 到 O(n)）。完整走一遍，你就能体会"优化"是怎么一步步发生的。

## 第一层：暴力枚举 O(n^3)

**最朴素的思路：枚举所有子数组的起点和终点，逐个求和。**

```python
def max_subarray_bruteforce(nums):
    n = len(nums)
    ans = float('-inf')
    for i in range(n):
        for j in range(i, n):
            s = 0
            for k in range(i, j + 1):    # 逐个求和
                s += nums[k]
            ans = max(ans, s)
    return ans

print(max_subarray_bruteforce([-2, 1, -3, 4, -1, 2, 1, -5, 4]))   # 6
```

**复杂度 O(n^3)。** n=10^4 时就跑不动了。

**问题在哪？** 内层循环每次都重新从 i 加到 j，做了大量重复计算。

## 第二层：优化枚举 + 前缀和 O(n^2)

**优化思路：枚举起点 i，然后一边扩展终点 j 一边累加，避免重复求和。**

```python
def max_subarray_n2(nums):
    n = len(nums)
    ans = float('-inf')
    for i in range(n):
        cur = 0
        for j in range(i, n):
            cur += nums[j]          # 累加，不需要重新从 i 开始
            ans = max(ans, cur)
    return ans

print(max_subarray_n2([-2, 1, -3, 4, -1, 2, 1, -5, 4]))   # 6
```

**复杂度 O(n^2)。** 比 O(n^3) 好，但 n=10^5 时还是超时。

**进一步：用前缀和把求和降到 O(1)。**

```python
def max_subarray_prefix(nums):
    n = len(nums)
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i + 1] = prefix[i] + nums[i]
    
    ans = float('-inf')
    for i in range(n):
        for j in range(i, n):
            s = prefix[j + 1] - prefix[i]    # O(1) 求和
            ans = max(ans, s)
    return ans

print(max_subarray_prefix([-2, 1, -3, 4, -1, 2, 1, -5, 4]))   # 6
```

**还是 O(n^2)，只是常数更小。** 能不能更好？

## 第三层：分治 O(n log n)

**分治思路：最大子数组要么在左半边，要么在右半边，要么跨越中点。**

```python
def max_subarray_divide(nums):
    def helper(left, right):
        if left == right:
            return nums[left]
        
        mid = (left + right) // 2
        
        # 左半边和右半边递归
        left_max = helper(left, mid)
        right_max = helper(mid + 1, right)
        
        # 跨越中点的情况
        # 从中点向左找最大后缀和
        left_sum = 0
        left_best = float('-inf')
        for i in range(mid, left - 1, -1):
            left_sum += nums[i]
            left_best = max(left_best, left_sum)
        
        # 从中点+1 向右找最大前缀和
        right_sum = 0
        right_best = float('-inf')
        for i in range(mid + 1, right + 1):
            right_sum += nums[i]
            right_best = max(right_best, right_sum)
        
        cross_max = left_best + right_best
        return max(left_max, right_max, cross_max)
    
    return helper(0, len(nums) - 1)

print(max_subarray_divide([-2, 1, -3, 4, -1, 2, 1, -5, 4]))   # 6
```

**复杂度 O(n log n)。** 递归深度 log n，每层遍历 O(n)。

**比 O(n^2) 好很多，但还能更好吗？**

## 第四层：Kadane 算法 O(n) —— 最优解

**核心洞察：如果以某个位置 j 结尾的最大子数组和是负数，那它只会拖累后面的子数组。不如从 j+1 重新开始。**

```python
def max_subarray(nums):
    n = len(nums)
    cur = nums[0]        # 以当前位置结尾的最大子数组和
    ans = nums[0]
    
    for i in range(1, n):
        cur = max(nums[i], cur + nums[i])   # 要么从当前元素重新开始，要么接上前面
        ans = max(ans, cur)
    
    return ans

print(max_subarray([-2, 1, -3, 4, -1, 2, 1, -5, 4]))   # 6
```

**这叫 Kadane 算法，O(n) 时间，O(1) 空间。**

**直觉理解：**

```
遍历到位置 i：
  如果 nums[i] 自己单独一个数，比 "前面的和 + nums[i]" 还大
  → 说明前面那段是负的，果断抛弃，从 nums[i] 重新开始
  否则 → 接上前面的
```

**四种解法对比：**

| 方法 | 时间 | 空间 | 核心思想 |
|---|---|---|---|
| 暴力 | O(n^3) | O(1) | 枚举所有子数组 |
| 前缀和 | O(n^2) | O(n) | 避免重复求和 |
| 分治 | O(n log n) | O(log n) | 左右 + 跨越中点 |
| Kadane | O(n) | O(1) | 负数前缀果断丢弃 |

## 优化的通用方法论

**从这道题的演进，提炼出通用的优化思路：**

```
Step 1: 写最朴素的暴力 → 确认理解题意
Step 2: 找重复计算 → 用前缀和/记忆化消除
Step 3: 找决策结构 → 分治？DP？
Step 4: 找贪心机会 → 能否局部最优推出全局最优？
Step 5: 验证正确性 → 找反例
```

**具体到这道题：**

1. 暴力枚举所有子数组 → O(n^3)
2. 发现重复求和 → 前缀和 → O(n^2)
3. 发现"负数前缀应该丢弃" → 贪心 → Kadane → O(n)

**每一步优化都源于一个具体的观察。**

## 翻车现场：Kadane 初始化为 0，全负数数组翻车

**最常见的错误——把 cur 和 ans 初始化为 0。**

```python
# WRONG：初始化为 0
def max_subarray_wrong(nums):
    cur = 0
    ans = 0
    for x in nums:
        cur = max(x, cur + x)
        ans = max(ans, cur)
    return ans

print(max_subarray_wrong([-2, -1, -3]))   # 输出 0，正确答案应该是 -1！
```

**为什么错？** 如果数组全是负数，最大子数组和应该是一个负数（选最大的那个负数）。但 ans 初始化为 0，导致返回了 0（相当于选了空数组）。

**修复：初始化为 nums[0]，或者处理"全负数"的特殊情况。**

```python
def max_subarray_fixed(nums):
    cur = nums[0]
    ans = nums[0]
    for i in range(1, len(nums)):
        cur = max(nums[i], cur + nums[i])
        ans = max(ans, cur)
    return ans

print(max_subarray_fixed([-2, -1, -3]))   # -1
```

## 翻车现场：分治法忘了处理"跨越中点"，结果错误

**分治时只处理了左右两边，漏掉了跨越中点的情况。**

```python
# WRONG：分治漏了跨越中点的情况
def helper_wrong(nums, left, right):
    if left == right:
        return nums[left]
    mid = (left + right) // 2
    return max(helper_wrong(nums, left, mid),
               helper_wrong(nums, mid + 1, right))
    # 漏了跨越中点的情况！

# nums = [2, -1, 2]
# 左半 [2,-1] 最大=2，右半 [2] 最大=2
# 但跨越中点的 [2,-1,2]=3 更大，被漏掉了
```

**修复：补上跨越中点的计算。**

```python
def helper_fixed(nums, left, right):
    if left == right:
        return nums[left]
    mid = (left + right) // 2
    left_max = helper_fixed(nums, left, mid)
    right_max = helper_fixed(nums, mid + 1, right)
    
    # 跨越中点
    left_sum = 0
    left_best = float('-inf')
    for i in range(mid, left - 1, -1):
        left_sum += nums[i]
        left_best = max(left_best, left_sum)
    
    right_sum = 0
    right_best = float('-inf')
    for i in range(mid + 1, right + 1):
        right_sum += nums[i]
        right_best = max(right_best, right_sum)
    
    return max(left_max, right_max, left_best + right_best)
```

## 翻车现场：返回最大和的同时还要返回区间，只返回了和

**有时候题目不仅要最大和，还要对应的子数组。**

```python
# WRONG：只返回了和，没有记录区间
def max_subarray_no_range(nums):
    cur = nums[0]
    ans = nums[0]
    for i in range(1, len(nums)):
        cur = max(nums[i], cur + nums[i])
        ans = max(ans, cur)
    return ans    # 不知道是哪个子数组

# 如果需要返回子数组本身，需要额外记录起点
```

**修复：用两个变量记录最优区间的左右端点。**

```python
def max_subarray_with_range(nums):
    cur = nums[0]
    ans = nums[0]
    start = end = 0
    temp_start = 0    # 当前段的起点
    
    for i in range(1, len(nums)):
        if nums[i] > cur + nums[i]:
            cur = nums[i]
            temp_start = i        # 从 i 重新开始
        else:
            cur += nums[i]
        
        if cur > ans:
            ans = cur
            start = temp_start
            end = i
    
    return ans, nums[start:end + 1]

print(max_subarray_with_range([-2, 1, -3, 4, -1, 2, 1, -5, 4]))
# (6, [4, -1, 2, 1])
```

## 小结

- **最大子数组和**有四种解法：暴力 O(n^3)、前缀和 O(n^2)、分治 O(n log n)、Kadane O(n)
- **Kadane 算法**：`cur = max(nums[i], cur + nums[i])`，负数前缀果断丢弃
- **优化的通用路径**：暴力 → 消除重复计算 → 分治/DP → 贪心
- 每一步优化都源于一个具体的观察，不是凭空来的
- 常见坑：Kadane 初始化为 0（全负数翻车）、分治漏掉跨越中点、只返回和没记录区间
- **学会"逐步优化"的思维，比记住某个具体算法更重要**
