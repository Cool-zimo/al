# 状态与转移方程：怎么定义 dp 数组

> "dp[i] 表示什么？"——这是动态规划最难的的一步。很多同学会写代码但不知道 dp 数组到底代表什么含义。本课手把手教你怎么定义状态、怎么写出转移方程。

## 第一步：用一句话说清 dp[i] 的含义

**定义 dp 数组是 DP 的灵魂。** 你必须能用一句话说清楚："`dp[i]` 表示……"。含糊的定义必然导致错误的转移方程。

**以爬楼梯为例，正确的定义是：**

> `dp[i]` = 到达第 i 阶台阶的**方法总数**

**注意几个要点：**

- **"到达"** 是关键——不是"从第 i 阶出发"，而是"走到第 i 阶"
- **"方法总数"** 是具体量——不是模糊的"某种值"
- 有了这个定义，才能推导出 `dp[i] = dp[i-1] + dp[i-2]`

**如果定义含糊，比如"dp[i] 表示第 i 阶的情况"，你根本无法写出转移方程。**

## 第二步：找出状态转移方程

**状态转移方程描述"大问题如何由小问题构成"。** 找转移方程的三步法：

1. **考虑最后一步**：到达第 i 阶的最后一步做了什么？
2. **分类讨论**：最后一步有哪些可能？
3. **写出等式**：把每种可能的方法数加起来

**以爬楼梯为例：**

```
到达第 i 阶的最后一步：
  方案A：从第 i-1 阶迈 1 步 → 有 dp[i-1] 种方法到达第 i-1 阶
  方案B：从第 i-2 阶迈 2 步 → 有 dp[i-2] 种方法到达第 i-2 阶

∴ dp[i] = dp[i-1] + dp[i-2]
```

**再看一个例子：最小路径和。** 给定一个 m×n 的网格，每个格子有数字，每次只能向右或向下走，求从左上到右下的最小路径和。

```
dp[i][j] = 到达 (i, j) 的最小路径和

到达 (i, j) 的最后一步：
  方案A：从上方 (i-1, j) 走下来 → dp[i-1][j]
  方案B：从左方 (i, j-1) 走过来 → dp[i][j-1]

∴ dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
```

## 第三步：确定 base case

**base case 是递推的起点，必须手动初始化。** 通常是最简单、不需要任何转移就能确定的状态。

```python
# 最小路径和：初始化第一行和第一列
def min_path_sum(grid):
    m, n = len(grid), len(grid[0])
    dp = [[0] * n for _ in range(m)]
    
    dp[0][0] = grid[0][0]          # 起点
    
    # 第一行：只能从左边来
    for j in range(1, n):
        dp[0][j] = dp[0][j - 1] + grid[0][j]
    
    # 第一列：只能从上面来
    for i in range(1, m):
        dp[i][0] = dp[i - 1][0] + grid[i][0]
    
    # 填充其余格子
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j]
    
    return dp[m - 1][n - 1]

print(min_path_sum([[1, 3, 1], [1, 5, 1], [4, 2, 1]]))  # 7
```

**base case 的作用是"给递推提供起点"。** 没有正确的 base case，递推就是空中楼阁。

## 第四步：确定填表顺序

**填表顺序必须保证"计算 dp[i] 时，它所依赖的子问题已经算完了"。**

- 一维 DP：通常从左到右（从小到大）
- 二维 DP：通常按行从左到右，从上到下
- 特殊 DP：可能需要按对角线、按长度等顺序

**以最小路径和为例：计算 dp[i][j] 需要 dp[i-1][j]（上方）和 dp[i][j-1]（左方）。** 所以按行从左到右、从上到下填，就能保证依赖项已计算。

## 翻车现场：dp 数组含义定义不清，导致转移方程全错

**这是最典型的 DP 失败模式：没想清楚 dp[i] 到底表示什么，就开始写代码。**

```python
# WRONG：dp[i] 含义模糊，转移方程写错
def house_robber_wrong(nums):
    # 想解决"打家劫舍"：不能偷相邻房屋
    # dp[i] 到底表示什么？没想清楚就写了
    dp = [0] * len(nums)
    dp[0] = nums[0]
    dp[1] = max(nums[0], nums[1])
    for i in range(2, len(nums)):
        # 以为 dp[i] 是"前 i 个房子的最大收益"
        # 但转移时漏了"不偷第 i 个"的情况
        dp[i] = dp[i - 1] + nums[i]   # 错！这样可能偷相邻
    return dp[-1]

print(house_robber_wrong([2, 7, 9, 3, 1]))  # 期望 12，实际更大或报错
```

**正确思路：`dp[i]` 应该定义为"偷到第 i 个房子为止（含第 i 个）能获得的最大金额"。** 转移方程：

```
dp[i] = max(dp[i-1], dp[i-2] + nums[i])
          ↑不偷第i个     ↑偷第i个（则第i-1个不能偷）
```

**关键：转移方程必须覆盖"做"与"不做"两种情况，取最大值。**

## 翻车现场：base case 只初始化了一个，导致索引越界

**递推中经常需要访问 dp[i-2]，如果只初始化了 dp[0]，i=1 时就会访问 dp[-1]。**

```python
# WRONG：只初始化了 dp[0]，没初始化 dp[1]
def rob_wrong(nums):
    n = len(nums)
    if n == 0: return 0
    dp = [0] * n
    dp[0] = nums[0]
    # 忘了 dp[1] = max(nums[0], nums[1])
    for i in range(1, n):           # 从 1 开始
        prev = dp[i - 2] if i >= 2 else 0  # 用三元表达式补救
        dp[i] = max(dp[i - 1], prev + nums[i])
    return dp[-1]

# 虽然能跑通，但逻辑绕，容易错
# 正确做法：明确初始化 dp[0] 和 dp[1]
```

**正确写法：**

```python
def rob(nums):
    n = len(nums)
    if n == 0: return 0
    if n == 1: return nums[0]
    dp = [0] * n
    dp[0] = nums[0]
    dp[1] = max(nums[0], nums[1])
    for i in range(2, n):
        dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
    return dp[-1]

print(rob([2, 7, 9, 3, 1]))   # 12
```

**明确的 base case 比绕来绕去的三元表达式清晰得多，也更容易排查 bug。**

## 小结

- **DP 四步法**：定义状态 → 写转移方程 → 确定 base case → 确定填表顺序
- **dp[i] 的含义必须能用一句话说清**，包含"到达/选择/包含"等关键词和具体量
- **转移方程要覆盖所有选择**（做/不做、选哪个），取最值或求和
- **base case 是递推的起点**，多开一格数组（大小 n+1）能大幅简化边界处理
- 填表顺序必须保证依赖的子问题已计算
- 常见坑：dp 含义含糊、base case 不全、转移漏情况
