# 拓扑排序：依赖关系，入度表 + 队列

> 拓扑排序解决的是"有依赖关系的任务怎么排顺序"。穿袜子才能穿鞋、写完前置课才能学进阶课——把这种"先→后"关系排成一列，就是拓扑排序。它只在有向无环图（DAG）上存在。

## 什么是拓扑排序

**拓扑排序（Topological Sort）是把 DAG 的顶点排成一列，使得所有有向边 u→v 都满足 u 在 v 前面。**

```
课程依赖：
  数据结构 → 算法
  算法   → 图论
  离散数学 → 数据结构
  离散数学 → 算法
```

**合法的拓扑序要满足：前驱排在后继前面。** 上面的依赖可以有多种合法排序，比如 `[离散数学, 数据结构, 算法, 图论]` 或 `[离散数学, 算法, 数据结构, 图论]`。

**拓扑排序不是唯一的一列。** 只要满足"前驱在前"，任何合法排列都是拓扑序。

## 思路：每次选"没有前驱"的节点

**一个节点如果没有未处理的入边（入度为 0），说明它依赖的所有东西都已经排好了，可以把它放到结果里。**

算法（Kahn 算法）：

1. 计算每个节点的入度（有多少边指向它）。
2. 把所有入度为 0 的节点放进队列。
3. 出队一个节点 u，加入结果；把 u 的所有出边"删掉"（邻居 v 的入度减 1）。
4. 如果某邻居 v 入度变成 0，入队。
5. 重复直到队列空。

```python
from collections import deque

def topo_sort(n, edges):
    """n 个节点 0~n-1，edges 是有向边列表 [[u,v], ...]"""
    adj = [[] for _ in range(n)]
    indeg = [0] * n
    for u, v in edges:
        adj[u].append(v)
        indeg[v] += 1

    q = deque([i for i in range(n) if indeg[i] == 0])
    ans = []
    while q:
        u = q.popleft()
        ans.append(u)
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return ans

print(topo_sort(4, [[0,1],[0,2],[1,3],[2,3]]))   # [0, 1, 2, 3] 或 [0, 2, 1, 3]
print(topo_sort(3, [[0,1],[1,2],[0,2]]))          # [0, 1, 2]
```

**"入度减 1 后变 0"意味着它的最后一个前驱已经排好了，可以加入队列。**

## 翻车现场：有环的图，拓扑排序不存在

```python
# 有环：A→B→C→A
print(topo_sort(3, [[0,1],[1,2],[2,0]]))
# 输出: []
```

**输出空列表。** 因为三个节点入度都是 1，没有一个入度为 0 的节点能入队，队列一开始就是空的。

**`len(ans) != n` 说明图有环，拓扑排序不存在。** 这是拓扑排序的经典应用：**检测有向图是否有环。**

```python
def has_cycle_directed(n, edges):
    adj = [[] for _ in range(n)]
    indeg = [0] * n
    for u, v in edges:
        adj[u].append(v)
        indeg[v] += 1
    q = deque([i for i in range(n) if indeg[i] == 0])
    seen = 0
    while q:
        u = q.popleft()
        seen += 1
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return seen != n     # True 表示有环

print(has_cycle_directed(3, [[0,1],[1,2],[2,0]]))   # True
print(has_cycle_directed(4, [[0,1],[1,2],[0,2]]))   # False
```

## 拓扑排序的 DFS 写法

**另一种拓扑排序用 DFS：按"完成时间"倒序输出。** 一个节点所有后继都处理完（递归返回）之后，它才入结果栈。

```python
def topo_sort_dfs(n, edges):
    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)

    visited = [0] * n      # 0=未访问, 1=访问中, 2=已完成
    stack = []
    has_cycle = [False]

    def go(u):
        visited[u] = 1
        for v in adj[u]:
            if visited[v] == 1:        # 遇到访问中的节点，有环
                has_cycle[0] = True
                return
            if visited[v] == 0:
                go(v)
        visited[u] = 2
        stack.append(u)                # 完成后入栈

    for i in range(n):
        if visited[i] == 0:
            go(i)
    if has_cycle[0]:
        return []
    return stack[::-1]                # 反转后即为拓扑序

print(topo_sort_dfs(4, [[0,1],[0,2],[1,3],[2,3]]))   # [0, 1, 2, 3]
print(topo_sort_dfs(3, [[0,1],[1,2],[2,0]]))          # []
```

**`visited` 用三色而不是布尔值，是为了检测"回边"（访问中的节点再次出现 = 有环）。**

**栈里是"完成时间从晚到早"，反转后就是拓扑序。** 直觉：一个节点要等所有后继都排好才能排它自己，所以它应该排在后面。

## 两种写法对比

| 维度 | Kahn（入度表+队列） | DFS+栈 |
|---|---|---|
| 检测环 | `len(ans)!=n` | 遇到回边 |
| 实现难度 | 简单直观 | 需要三色标记 |
| 空间 | O(n+m) | O(n+m) |
| 输出 | 按"入度为 0"的顺序，不唯一 | 按完成时间倒序，不唯一 |

**工程上 Kahn 更常用**，因为写起来更直白，且能自然地给出"哪一批节点可以同时做"（队列里同一批入度为 0 的节点互相独立，可并行）。

## 拓扑排序的应用：课程表

**LeetCode 207/210 课程表问题：给定课程数和先修关系，判断是否可能完成全部课程。**

```python
def can_finish(numCourses, prerequisites):
    adj = [[] for _ in range(numCourses)]
    indeg = [0] * numCourses
    for u, v in prerequisites:      # u 是 v 的前置，即 u→v
        adj[u].append(v)
        indeg[v] += 1
    q = deque([i for i in range(numCourses) if indeg[i] == 0])
    seen = 0
    while q:
        u = q.popleft()
        seen += 1
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return seen == numCourses

print(can_finish(2, [[1, 0]]))          # True   (0 是 1 的前置)
print(can_finish(2, [[1, 0], [0, 1]]))  # False  (互相依赖，有环)
```

**"能否完成"等价于"图中是否有环"。** 没有环就能排拓扑序，有环就必然有循环依赖。

## 小结

- 拓扑排序把 DAG 排成"前驱在前"的序列，结果不唯一
- Kahn 算法：入度表 + 队列，每次取入度为 0 的节点，删它的出边
- **`len(ans) != n` 说明图有环**，拓扑排序不存在
- 检测有向环：Kahn 看 `seen!=n`，DFS 看是否遇到"访问中"的节点
- 邻接表用列表的列表 `[[] for _ in range(n)]`，避免 KeyError
- 课程表问题的本质就是判断有向图是否有环
