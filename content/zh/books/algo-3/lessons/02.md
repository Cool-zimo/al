# 二叉树与遍历：前序 / 中序 / 后序

> 遍历就是把一棵树里所有节点都访问一遍。二叉树只有"左、根、右"三个位置，改变它们的访问顺序，就得到三种经典遍历——前序、中序、后序。它们不只是考试题，更是后面所有树题的骨架。

## 为什么需要遍历

**访问"每个节点各一次"，是一切树算法的起点。** 求节点数、求最大深度、求路径和、序列化、复制整棵树……全都要先把树走一遍。所以"怎么走"这个问题，是后面 20 多课的基础。

树没有下标，只能靠"跟着指针走"。而指针有三条：`.left`、`.right`、以及"回到父节点"。但 `TreeNode` 里没有 `parent` 指针，所以你只能**向下走**，靠递归的返回过程完成"向上"。

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def build(vals):
    if not vals or vals[0] is None:
        return None
    nodes = [None if v is None else TreeNode(v) for v in vals]
    for i in range(len(nodes)):
        if nodes[i] is None:
            continue
        left, right = 2 * i + 1, 2 * i + 2
        if left < len(nodes) and nodes[left] is not None:
            nodes[i].left = nodes[left]
        if right < len(nodes) and nodes[right] is not None:
            nodes[i].right = nodes[right]
    return nodes[0]
```

**遍历的通用框架只有一句话：先决定"根"什么时候被访问，再递归处理左右。** 三者的区别，只是"根"插在哪个位置。

## 前序遍历：根 → 左 → 右

**前序遍历先访问根，再访问左子树，最后访问右子树。** "前"的意思是"根在前"。它最直观的用途是"复制/序列化一棵树"——因为你总是先处理当前节点，再下去处理孩子。

```python
def preorder(root):
    if root is None:
        return []
    return [root.val] + preorder(root.left) + preorder(root.right)

t = build([1, 2, 3, 4, 5, 6, 7])
print(preorder(t))   # [1, 2, 4, 5, 3, 6, 7]
```

走一遍：`1` 先输出，然后递归进左子树 `2`，`2` 先输出，再进它的左子树 `4`，`4` 输出，左右都空，退回 `2`，进右子树 `5`……

**前序序列能唯一确定"树的结构"吗？** 不能。光有前序序列，你不知道哪里该分叉、哪里是叶子。要还原一棵树，至少需要"前序 + 中序"两种序列（第 09 课专门讲）。

## 中序遍历：左 → 根 → 右

**中序遍历先访问左子树，再访问根，最后访问右子树。** "中"的意思是"根在中间"。它最大的特点是：**在二叉搜索树里，中序遍历的输出是严格递增的**。

```python
def inorder(root):
    if root is None:
        return []
    return inorder(root.left) + [root.val] + inorder(root.right)

print(inorder(t))   # [4, 2, 5, 1, 6, 3, 7]
```

**这是验证一棵 BST 是否合法的最常用方法。** 合法 BST 的中序序列必须非降序。不过注意，单纯把中序结果收集起来再判断一遍，是 O(n) 空间；如果要求 O(h) 空间（h 是树高），就得用"中序遍历找逆序对"的 Morris 遍历，那是进阶内容。

## 后序遍历：左 → 右 → 根

**后序遍历先访问左子树，再访问右子树，最后访问根。** "后"的意思是"根在后"。它最典型的应用是"先算孩子的信息，再用孩子的信息算根"——比如求树的高度、求左右子树的状态再决定当前节点的颜色。

```python
def postorder(root):
    if root is None:
        return []
    return postorder(root.left) + postorder(root.right) + [root.val]

print(postorder(t))   # [4, 5, 2, 6, 7, 3, 1]
```

**"根在最后"这个位置很关键。** 如果一道题要求你"先处理完左右子树，再处理根"（例如：删除树中值为 x 的节点、计算以每个节点为根的子树信息），那它几乎一定是后序遍历。

## 三种遍历的对比

| 遍历 | 根的位置 | 典型用途 |
|---|---|---|
| 前序 | 根在左子树前 | 复制树、序列化、先处理父再处理子 |
| 中序 | 根在左右之间 | BST 取值（递增）、表达式树的中缀 |
| 后序 | 根在右子树后 | 先汇总孩子再算根、释放资源、求高度 |

```python
t = build([1, 2, 3, 4, 5, 6, 7])
print("pre :", preorder(t))
print("in  :", inorder(t))
print("post:", postorder(t))
```

输出：

```
pre : [1, 2, 4, 5, 3, 6, 7]
in  : [4, 2, 5, 1, 6, 3, 7]
post: [4, 5, 2, 6, 7, 3, 1]
```

**三种遍历的输出共享同一个"集合"，只是顺序不同。** 如果你把三个结果各自排个序，得到的列表完全一样。利用这个性质可以在调试时检查你的遍历实现是否漏了节点。

## 翻车现场：None + 列表，TypeError 警告

```python
# WRONG：递归分支里写了 +，但忘了 None 返回的是列表
def preorder(root):
    if root is None:
        return None          # ← 返回了 None 而不是 []
    return [root.val] + preorder(root.left) + preorder(root.right)

print(preorder(build([1, 2, 3])))
```

报错：

```
TypeError: can only concatenate list (not "NoneType") to list
```

**`[root.val] + preorder(left)` 要求 `preorder(left)` 一定是个列表。** 你让空分支返回 `None`，那 `[root.val] + None` 就是类型错误。

**统一约定：遍历函数永远返回列表，空分支返回 `[]`。** 同理，`to_list`、收集路径、收集叶子……所有"收集型"递归，空分支都返回 `[]`，非空分支都返回列表。这个约定能避免 90% 的树递归类型错误。

## 翻车现场：漏掉 None 判断，访问 None.val

```python
# WRONG：没判断 root 是否为 None 就取 .val
def inorder(root):
    return inorder(root.left) + [root.val] + inorder(root.right)

print(inorder(build([1, 2, 3])))
```

报错：

```
AttributeError: 'NoneType' object has no attribute 'val'
```

**递归函数的第一行必须是边界判断。** 写树的递归时，养成这个肌肉记忆：`def f(node): if node is None: return ...`。任何不先判断 None 的树递归，都会在叶子节点的下一层炸掉。

## 递归遍历的统一模板

把三种遍历放在一起看，差别只有一行：

```python
def traverse(root, order):
    """order: 'pre' / 'in' / 'post'"""
    if root is None:
        return []
    left = traverse(root.left, order)
    right = traverse(root.right, order)
    if order == 'pre':
        return [root.val] + left + right
    if order == 'in':
        return left + [root.val] + right
    return left + right + [root.val]

print(traverse(build([1,2,3,4,5]), 'pre'))   # [1, 2, 4, 5, 3]
print(traverse(build([1,2,3,4,5]), 'in'))    # [4, 2, 5, 1, 3]
print(traverse(build([1,2,3,4,5]), 'post'))  # [4, 5, 2, 3, 1]
```

**这就是"分治"在树上的样子：先让左右子树把它们的答案算好，我再决定怎么把它们和根拼起来。** 区别在于——根是在拼接之前、之中、还是之后被加入。第 06 课会把这套思想推广成"树递归通用解题法"。

## 迭代版：用栈模拟递归（了解即可）

递归的本质是调用栈。你可以自己维护一个栈，把"下一步该做什么"压进去。

```python
def preorder_iter(root):
    if root is None:
        return []
    ans, stack = [], [root]
    while stack:
        n = stack.pop()
        ans.append(n.val)
        if n.right:
            stack.append(n.right)   # 右儿子后访问，先压栈
        if n.left:
            stack.append(n.left)    # 左儿子先访问，后压栈
    return ans

print(preorder_iter(build([1, 2, 3, 4, 5])))   # [1, 2, 4, 5, 3]
```

**栈是"后进先出"的，所以想让左儿子先出来，就得把右儿子先压栈。** 这个细节是迭代版最容易写错的地方。中序和后序的迭代写法更复杂（要用到"访问标记"或 Morris 遍历），面试中递归写法是主流，掌握递归就够用。

## 小结

- 三种遍历的核心区别是"根什么时候被访问"：前序（根先）、中序（根中）、后序（根后）
- 前序用于"先父后子"（复制、序列化），中序在 BST 中输出递增序列，后序用于"先孩子后父"（求高度、汇总子树）
- **遍历函数统一返回列表，空分支返回 `[]`**，否则 `+` 会 TypeError
- **递归树函数第一行必判 None**，否则叶子下一层 `AttributeError`
- 三种遍历的输出是同一批节点的不同排列，排序后完全一致
- 迭代版用栈模拟，理解"右儿子先压栈"这个细节
