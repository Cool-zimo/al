# 并查集：连通性判断，路径压缩

> 并查集（Disjoint Set Union，DSU）是处理"动态连通性"的神器：判断两点是否连通、把两个集合合并。它的两个优化——按秩合并和路径压缩——能把每次操作压到近乎 O(1)。

## 问题：动态连通性

**并查集解决的是这类问题：有一堆元素，初始各自独立；不断告诉你"a 和 b 连通"，随时问你"c 和 d 连通吗"。**

典型场景：社交网络里的"两人是否认识（通过朋友链）"、岛的数量、Kruskal 最小生成树（第 20 课后半部分用到）。

**核心操作只有两个：**
- `find(x)`：x 属于哪个集合（找老大）
- `union(x, y)`：把 x 和 y 所在的集合合并成一个

```python
class DSU:
    def __init__(self, n):
        self.parent = list(range(n))     # 自己是自己的父节点，各自独立
        self.rank = [0] * n              # 秩（树高上界），用于按秩合并

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])   # 路径压缩
        return self.parent[x]

    def union(self, x, y):
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return False                 # 已经连通，无事可做
        # 按秩合并：矮的树挂到高的树上
        if self.rank[rx] < self.rank[ry]:
            self.parent[rx] = ry
        elif self.rank[rx] > self.rank[ry]:
            self.parent[ry] = rx
        else:
            self.parent[ry] = rx
            self.rank[rx] += 1
        return True
```

## 路径压缩：find 时顺手拉平

**`find(x)` 沿着 parent 链一路往上找，找到根后，把沿途所有节点的 parent 直接指向根。** 下次再 find 就是 O(1)。

```python
def find(self, x):
    if self.parent[x] != x:
        self.parent[x] = self.find(self.parent[x])   # 递归：先找到根，再让 x 的父指向根
    return self.parent[x]
```

**注意递归顺序：`self.find(parent[x])` 先执行，返回的是根；然后才把 `parent[x]` 设为根。** 这就是"路径压缩"——`parent[x]` 原来指向某个中间节点，现在直接指向根。

```python
dsu = DSU(6)
dsu.union(0, 1)
dsu.union(1, 2)
dsu.union(3, 4)
print(dsu.find(0) == dsu.find(2))   # True
print(dsu.find(0) == dsu.find(3))   # False
print(dsu.find(4) == dsu.find(3))   # True
dsu.union(2, 4)
print(dsu.find(0) == dsu.find(4))   # True
```

## 按秩合并：把矮树挂到高树上

**如果总是"随便挂"，树可能退化成链表，find 退化成 O(n)。** 按秩合并保证树高有界。

**规则：秩小的树挂到秩大的树下；秩相等时随便挂一个，并把它的秩加 1。**

```python
if self.rank[rx] < self.rank[ry]:
    self.parent[rx] = ry          # 矮挂高
elif self.rank[rx] > self.rank[ry]:
    self.parent[ry] = rx
else:
    self.parent[ry] = rx          # 相等：挂到 rx 下
    self.rank[rx] += 1            # rx 的树高 +1
```

**路径压缩 + 按秩合并，单次操作均摊 O(α(n))**，α 是反 Ackermann 函数，增长极慢，n=10^600 时 α(n) 也只有 5。实际中当 O(1) 用。

## 翻车现场：find 写成死循环

```python
# WRONG：find 不更新 parent，退化成链表
def find(self, x):
    while self.parent[x] != x:
        x = self.parent[x]         # 找到了根，但没压缩，下次还是慢
    return x
```

**这个写法"能跑"，但没有任何压缩。** 最坏情况（每次 union 都把高树挂到矮树）会退化成 O(n)。

**真正的坑是这种：**

```python
# WRONG：路径压缩写错，造成循环引用
def find_wrong(self, x):
    if self.parent[x] != x:
        self.parent[x] = self.find_wrong(self.parent[x])
    return self.parent[x]   # 看起来对，但...

# 如果初始 parent 里存在环（比如 parent[1]=2, parent[2]=1），就无限递归
```

**如果 `parent` 数组里存在环（初始化错误、或某次 union 写错），`find` 会无限递归直到栈溢出。** 所以用并查集前必须确认 `parent[i] = i` 初始化正确。

## 翻车现场：union 忘了先 find

```python
# WRONG：直接把 x 的父节点指向 y，没考虑各自的根
def union_wrong(self, x, y):
    self.parent[x] = y      # ← 直接改 x 的父，没有经过 find

dsu = DSU(5)
dsu.union_wrong(0, 1)
dsu.union_wrong(1, 2)
print(dsu.find(0))   # 1，但其实 0,1,2 应该在一个集合里
```

**`union` 必须合并"两个集合的根"，不是随便连两个节点。** 直接 `parent[x]=y` 会把 x 挂到 y 下面，破坏了"同一个集合共享一个根"的结构。

**正确写法永远是 `rx = find(x); ry = find(y)`，然后操作 `parent[rx]` 和 `parent[ry]`。**

## 应用：连通分量个数

**图被分成几个"连通块"，就是并查集的活。** 把每条边 union 起来，最后统计有多少个不同的根。

```python
def count_components(n, edges):
    dsu = DSU(n)
    for u, v in edges:
        dsu.union(u, v)
    roots = set()
    for i in range(n):
        roots.add(dsu.find(i))
    return len(roots)

print(count_components(5, [[0,1],[1,2],[3,4]]))   # 2
print(count_components(4, [[0,1],[1,2],[2,3]]))   # 1
```

**注意要 `find(i)` 而不是看 `parent[i]`**——因为路径压缩可能没发生，`parent[i]` 未必是根。只有 `find(i)` 才能保证返回根。

## 应用：判断加边是否会成环

**"这条边会不会让图产生环？"等价于"它的两个端点是否已经在同一个集合里"。**

```python
def has_cycle(n, edges):
    dsu = DSU(n)
    for u, v in edges:
        if dsu.find(u) == dsu.find(v):    # 已经连通
            return True                    # 再加这条边就成环
        dsu.union(u, v)
    return False

print(has_cycle(4, [[0,1],[1,2],[2,3]]))        # False
print(has_cycle(4, [[0,1],[1,2],[2,3],[3,0]]))  # True
```

**这正是 Kruskal 算法的核心**：按权重从小到大加边，用并查集判断"加这条边会不会成环"，不会成环才加入 MST。

## 小结

- 并查集两个操作：`find(x)` 找根、`union(x,y)` 合并两个集合
- **路径压缩**：find 时把沿途节点的 parent 直接指向根，下次 O(1)
- **按秩合并**：秩小的树挂到秩大的树下，保持树矮
- 两者结合，单次操作均摊 O(α(n))，实际当 O(1)
- union 必须合并"根"：`rx=find(x); ry=find(y)`，不能直接连两个节点
- 应用：连通块计数、判环、Kruskal 最小生成树
