# 一维 DP：打家劫舍与最长递增子序列

> 一维 DP 是最常见、最基础的 DP 形式。本课用两个经典问题——打家劫舍和最长递增子序列——带你吃透一维 DP 的思考方式。

## 打家劫舍：不能偷相邻的两家

**问题描述：** 你是一个小偷，沿街有若干房屋，每间房有一定金额。相邻的房屋装有防盗系统，如果同一晚偷了相邻的两间就会触发报警。**求在不触发报警的前提下能偷到的最大金额。**

### dp[i] 的含义

> `dp[i]` = 偷到第 i 间房子（含第 i 间）时，能获得的最大金额

### 转移方程

**偷第 i 间房时，第 i-1 间不能偷；不偷第 i 间时，最大金额等于偷到第 i-1 间的最大金额。**

```
dp[i] = max(
    dp[i-1],           # 不偷第 i 间，保持之前的
    dp[i-2] + nums[i]  # 偷第 i 间，加上前 i-2 间的最优解
)
```

```python
def rob(nums):
    n = len(nums)
    if n == 0: return 0
    if n == 1: return nums[0]
    if n == 2: return max(nums[0], nums[1])
    
    dp = [0] * n
    dp[0] = nums[0]
    dp[1] = max(nums[0], nums[1])
    for i in range(2, n):
        dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
    return dp[-1]

print(rob([2, 7, 9, 3, 1]))   # 12
print(rob([1, 2, 3, 1]))      # 4
```

**执行过程（nums = [2, 7, 9, 3, 1]）：**

```
dp[0] = 2
dp[1] = max(2, 7) = 7
dp[2] = max(7, 2+9) = 11
dp[3] = max(11, 7+3) = 11
dp[4] = max(11, 11+1) = 12
```

**答案为 12：偷第 0 间（2）+ 第 2 间（9）+ 第 4 间（1）= 12。**

### 空间优化

**注意到 dp[i] 只依赖 dp[i-1] 和 dp[i-2]，只需要两个变量：**

```python
def rob_optimized(nums):
    prev2 = 0      # dp[i-2]
    prev1 = 0      # dp[i-1]
    for x in nums:
        cur = max(prev1, prev2 + x)
        prev2 = prev1
        prev1 = cur
    return prev1

print(rob_optimized([2, 7, 9, 3, 1]))   # 12
```

**空间从 O(n) 降到 O(1)。** 这是一维 DP 最常见的优化手段——"滚动变量"。

## 最长递增子序列（LIS）

**问题描述：** 给定一个整数数组，找到其中最长严格递增子序列的长度。子序列不要求连续。

### dp[i] 的含义

> `dp[i]` = **以第 i 个元素结尾**的最长递增子序列的长度

**为什么强调"以第 i 个结尾"？** 因为这样定义才能让转移方程成立——要判断新元素能不能接在之前的子序列后面，必须知道之前子序列的"最后一个元素"是什么。

### 转移方程

**对于 dp[i]，遍历所有 j < i：如果 nums[j] < nums[i]，说明 nums[i] 可以接在以 nums[j] 结尾的递增子序列后面。**

```
dp[i] = max(dp[j] + 1)  for all j < i and nums[j] < nums[i]
```

**如果找不到任何 j 满足条件，dp[i] = 1（以自己开头）。**

```python
def length_of_lis(nums):
    if not nums:
        return 0
    n = len(nums)
    dp = [1] * n          # 每个元素至少可以单独构成一个子序列
    for i in range(n):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)

print(length_of_lis([10, 9, 2, 5, 3, 7, 101, 18]))  # 4
```

**执行过程（nums = [10, 9, 2, 5, 3, 7, 101, 18]）：**

```
i=0: dp[0] = 1         (只有 [10])
i=1: dp[1] = 1         (只有 [9]，10 > 9 不能接)
i=2: dp[2] = 1         (只有 [2])
i=3: dp[3] = 2         (2 < 5 → dp[2]+1 = 2)
i=4: dp[4] = 2         (2 < 3 → dp[2]+1 = 2)
i=5: dp[5] = 3         (5 < 7 → dp[3]+1 = 3)
i=6: dp[6] = 4         (7 < 101 → dp[5]+1 = 4)
i=7: dp[7] = 4         (3 < 18 → dp[4]+1 = 3, 7 < 18 → dp[5]+1 = 4)

最大值是 4，对应子序列 [2, 5, 7, 101] 或 [2, 3, 7, 101]
```

**时间复杂度 O(n²)，空间 O(n)。**

## 翻车现场：打家劫舍漏了 n=2 的情况

**直接用 dp[1] = max(nums[0], nums[1]) 的前提是数组至少有 2 个元素。如果忘了处理短数组，会索引越界。**

```python
# WRONG：没处理 n < 2 的边界
def rob_short(nums):
    dp = [0] * len(nums)
    dp[0] = nums[0]
    dp[1] = max(nums[0], nums[1])    # IndexError! len(nums) 可能只有 1
    for i in range(2, len(nums)):
        dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
    return dp[-1]

# IndexError: list index out of range
```

**修复：在函数开头处理 `n == 0` 和 `n == 1` 的情况：**

```python
def rob_safe(nums):
    n = len(nums)
    if n == 0: return 0
    if n == 1: return nums[0]
    dp = [0] * n
    dp[0] = nums[0]
    dp[1] = max(nums[0], nums[1])
    for i in range(2, n):
        dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
    return dp[-1]
```

## 翻车现场：LIS 里把 dp 全初始化成 0 而不是 1

**LIS 中每个元素至少可以单独构成长度为 1 的子序列，所以 dp 数组应全部初始化为 1。如果初始化为 0，最终结果会变成 0。**

```python
# WRONG：dp 初始化为 0
def lis_wrong(nums):
    n = len(nums)
    dp = [0] * n          # 错！应该是 [1] * n
    for i in range(n):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)

print(lis_wrong([1, 2, 3]))   # 0，错！应该是 3
```

**为什么输出 0？** 因为 dp 全是 0，`max(dp[j] + 1)` 虽然能算出值，但如果某个元素前面没有任何比它小的（比如第一个元素），它的 dp 值永远是 0。最终 `max(dp)` 也可能返回错误结果。

**修复：把 `dp = [0] * n` 改成 `dp = [1] * n`。**

## 翻车现场：LIS 转移条件用了 <= 而不是 <

**题目要求"严格递增"，如果用了 `<=` 就会把相等的元素也算进递增序列。**

```python
# WRONG：用 <= 导致非严格递增
def lis_nonstrict(nums):
    n = len(nums)
    dp = [1] * n
    for i in range(n):
        for j in range(i):
            if nums[j] <= nums[i]:    # 用 <= 而不是 <
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)

print(lis_nonstrict([1, 2, 2, 3]))   # 4，但题目可能要求严格递增
```

**如果题目要求严格递增（LIS 标准定义），用 `<=` 会多算。** 如果题目允许非严格递增（Longest Non-decreasing Subsequence），才用 `<=`。**审题时务必确认是严格还是非严格。**

## 小结

- **打家劫舍**：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`，核心是不偷/偷两种选择取最大
- **LIS**：`dp[i] = max(dp[j] + 1)` for `j < i` and `nums[j] < nums[i]`，O(n²)
- **一维 DP 的共同模式**：定义 dp[i] → 找转移（通常依赖前面若干个 dp 值）→ 确定 base case
- **空间优化**：只依赖有限个前驱时用滚动变量，O(n) → O(1)
- **常见坑**：短数组越界、dp 初始化值错误、严格/非严格条件混淆
