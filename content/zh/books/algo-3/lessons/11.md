# 图是什么：邻接矩阵 vs 邻接表

> 数组是一对一、树是一对多，图是多对多。这一课讲清图的基本要素，以及两种最主流的存储方式——邻接矩阵和邻接表，各自适合什么场景。

## 图的定义：节点和边

**图（Graph）由顶点（Vertex）集合 V 和边（Edge）集合 E 组成，记作 G=(V,E)。** 相比树，图去掉了两个限制：可以有环，节点可以有多个父节点。

```python
# 一个无向图的例子：4 个城市之间的道路
# 城市用编号 0,1,2,3 表示
graph = {
    0: [1, 2],       # 城市 0 连通城市 1 和 2
    1: [0, 2, 3],    # 城市 1 连通 0,2,3
    2: [0, 1],       # 城市 2 连通 0,1
    3: [1],          # 城市 3 只连通 1
}
```

**图的分类，看边有没有方向、有没有权重：**

| 类型 | 含义 | 表示 |
|---|---|---|
| 无向图 | 边没有方向，A-B 即 B-A | `graph[a]` 含 b 则 `graph[b]` 含 a |
| 有向图 | 边有方向，A→B 不等于 B→A | 邻接表只单向记录 |
| 带权图 | 边上有权重（距离、代价） | 邻接表存 `(邻居, 权重)` 元组 |

## 邻接表：最常用

**邻接表（Adjacency List）用一个列表/字典，每个节点存它所有邻居的列表。** 这是算法题和工程里的主流表示。

```python
# 无向无权图
adj = {
    0: [1, 2],
    1: [0, 2, 3],
    2: [0, 1],
    3: [1],
}

# 有向带权图：边上有距离
weighted = {
    0: [(1, 4), (2, 3)],
    1: [(3, 5)],
    2: [(1, 2), (3, 6)],
    3: [],
}
```

**遍历 0 的所有邻居：`for nb in adj[0]:`。** 无向图的邻接表里，每条边会出现两次（a 的列表里有 b，b 的列表里有 a）；有向图只出现一次。

**带权图的 `weighted[0]` 给出 `(邻居, 权重)` 的元组。** 后面 Dijkstra（第 15 课）就吃这种格式。

## 邻接矩阵：空间换查询速度

**邻接矩阵是一个 n×n 的二维数组 `g[i][j]`，表示 i 到 j 是否有边（或边的权重）。**

```python
# 4 个节点的无向图，用邻接矩阵表示
n = 4
g = [[0]*n for _ in range(n)]
def add_edge(u, v, w=1):
    g[u][v] = w
    g[v][u] = w          # 无向图：对称

add_edge(0, 1)
add_edge(0, 2)
add_edge(1, 2)
add_edge(1, 3)

for row in g:
    print(row)
```

输出：

```
[0, 1, 1, 0]
[1, 0, 1, 1]
[1, 1, 0, 0]
[0, 1, 0, 0]
```

**`g[i][j] == 0` 表示没有边，`g[i][j] == 1` 表示有边。** 带权图里用 `g[i][j] = w`，无边用 `inf` 或 `0`（约定 0 表示无边时，权重不能为 0）。

## 邻接矩阵 vs 邻接表

| 维度 | 邻接矩阵 | 邻接表 |
|---|---|---|
| 空间 | O(n²) | O(n + m) |
| 判断两点是否相邻 | O(1) | O(deg(u))（度数） |
| 遍历某点的所有邻居 | O(n) | O(deg(u)) |
| 适合场景 | 稠密图、Floyd-Warshall、需要快速查边 | 稀疏图、DFS/BFS、大多数算法题 |

**稀疏图（边少，m ≈ n）用邻接表省空间；稠密图（边多，m ≈ n²）两者差不多。**

**邻接矩阵在 n=10^5 时是致命的**：`n×n = 10^10` 个整数，约 40 GB，直接爆内存。所以大图一律邻接表。

## 翻车现场：邻接矩阵的"0 表示无边"撞上权重为 0

```python
# WRONG：用 0 同时表示"无边"和"权重为 0"
n = 3
g = [[0]*n for _ in range(n)]
g[0][1] = 0     # 想表示"边 0-1 的权重是 0"
print(g[0][1] == 0)   # True，但这是"没有边"还是"权重 0"？
```

**无法区分。** 这是邻接矩阵表示带权图时的经典坑。

**修复：用 `float('inf')` 表示"没有边"。**

```python
n = 3
INF = float('inf')
g = [[INF]*n for _ in range(n)]
for i in range(n):
    g[i][i] = 0          # 到自己是 0
g[0][1] = 0              # 权重 0 是合法的
print(g[0][1])           # 0，确实是权重 0
print(g[0][2])           # inf，确实没有边
```

## 有向图和无向图的处理差别

**无向图每条边存两次，有向图只存一次。** 这个差别会直接影响遍历和算法。

```python
# 无向图加边：双向
def add_undirected(adj, u, v):
    adj[u].append(v)
    adj[v].append(u)

# 有向图加边：单向
def add_directed(adj, u, v):
    adj[u].append(v)

adj = {0: [], 1: [], 2: []}
add_undirected(adj, 0, 1)
add_directed(adj, 1, 2)
print(adj)   # {0: [1], 1: [0, 2], 2: []}
```

**拓扑排序（第 13 课）和强连通分量只在有向图上定义；连通分量、最小生成树在无向图上定义。** 做题第一件事：看清是有向还是无向。

## 图的表示约定：节点编号从 0 开始

**算法题里图的节点通常编号 0~n-1。** 邻接表用列表的列表 `adj = [[] for _ in range(n)]`，下标即节点编号，比字典更高效。

```python
n = 5
adj = [[] for _ in range(n)]
edges = [[0, 1], [0, 2], [1, 3], [1, 4]]
for u, v in edges:
    adj[u].append(v)
    adj[v].append(u)

print(adj)
# [[1, 2], [0, 3, 4], [0], [1], [1]]
```

**`adj` 是"列表的列表"，`adj[u]` 是节点 u 的邻居列表。** 这种格式是 LeetCode 的 `List[List[int]]` 标准输入。

## 图的基本量：度数、路径、环

**度数（Degree）**：无向图中一个节点连接的边数。有向图分入度（in-degree）和出度（out-degree）。

```python
def degree(adj, u):
    return len(adj[u])

adj = [[1, 2], [0, 2, 3], [0, 1], [1]]
print(degree(adj, 1))   # 3
print(degree(adj, 3))   # 1
```

**路径**：依次经过的边构成的序列。**环**：起点和终点相同的路径。**连通**：两个节点间存在路径。

**树就是"无环连通图"。** 图 = 树的推广（允许环、允许多父）。所以后面 DFS/BFS 的写法，和树的遍历几乎一样，只是多了"visited 集合"防止绕环。

## 翻车现场：遍历图不记录 visited，无限循环

```python
# WRONG：有环的图上 DFS 不记录 visited，无限递归
adj = {0: [1], 1: [2], 2: [0]}   # 三角形，有环

def dfs(u):
    print(u)
    for v in adj[u]:
        dfs(v)

dfs(0)   # 0 1 2 0 1 2 0 1 2 ... 直到 RecursionError
```

**树不会绕回祖先，所以树的 DFS 不需要 visited。图有环，必须记录。**

**正确写法：**

```python
def dfs(u, visited):
    if u in visited:
        return
    visited.add(u)
    print(u)
    for v in adj[u]:
        dfs(v, visited)

dfs(0, set())   # 0 1 2
```

**`visited` 是图和树遍历的唯一本质区别。** 记住这句话就不会忘。

## 小结

- 图 = 顶点 + 边；按方向分有向/无向，按权重分带权/无权
- 邻接表：空间 O(n+m)，遍历邻居 O(deg(u))，稀疏图首选
- 邻接矩阵：空间 O(n²)，查边 O(1)；稠密图、Floyd 用
- **邻接矩阵表示带权图，用 `inf` 表示无边，不能用 0**
- 无向图加边双向，有向图加边单向
- **遍历图必须记录 visited**，否则遇到环会无限递归
