# DFS 与 BFS：两种遍历的骨架与区别

> 图的遍历只有两种：深度优先 DFS 和广度优先 BFS。DFS 靠递归（栈）一头钻到底，BFS 靠队列一层层展开。这一课把两种骨架写熟，并讲清各自适合什么场景。

## DFS：递归 + visited

**DFS（Depth-First Search）沿着一条路径走到头，再回溯尝试别的路。** 实现用递归（本质是调用栈）。

```python
def build_adj(n, edges):
    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)
        adj[v].append(u)
    return adj

adj = build_adj(5, [[0,1],[0,2],[1,3],[1,4]])

def dfs(u, visited):
    visited.add(u)
    print(u, end=' ')
    for v in adj[u]:
        if v not in visited:
            dfs(v, visited)

dfs(0, set())   # 0 1 3 4 2  （一种可能的顺序）
```

**递归的"返回"就是回溯。** 当 `adj[u]` 里所有邻居都访问完，函数自然返回上一层，这就是"回溯"。

**遍历顺序取决于邻接表里邻居的排列顺序，不唯一。** 只要保证每个节点只访问一次就行。

## BFS：队列 + visited

**BFS（Breadth-First Search）一层一层地展开，先访问距离起点为 1 的所有节点，再距离 2 的……** 实现用队列（第 03 课的层序遍历就是 BFS）。

```python
from collections import deque

def bfs(start, adj):
    visited = {start}
    q = deque([start])
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in adj[u]:
            if v not in visited:
                visited.add(v)
                q.append(v)
    return order

print(bfs(0, adj))   # [0, 1, 2, 3, 4]
```

**队列保证"先入队的先处理"，所以同一层的节点连续出现。**

## 翻车现场：DFS/BFS 忘了 visited，图有环就死循环

```python
# WRONG：没记录 visited
def dfs_no_visited(u):
    print(u, end=' ')
    for v in adj[u]:
        dfs_no_visited(v)

# adj = build_adj(5, [[0,1],[1,2],[2,0]])  # 三角形有环
# dfs_no_visited(0)  ->  0 1 2 0 1 2 0 ... 无限递归
```

**树不会有环，所以树的遍历不用 visited。图有环，必须 visited。**

**`visited` 要"在入队/递归前就标记"，不要"处理完再标记"。** 否则同一个节点可能被多个邻居同时发现、多次入队。

```python
# 正确：发现就标记
visited = {start}
q = deque([start])
while q:
    u = q.popleft()
    for v in adj[u]:
        if v not in visited:
            visited.add(v)      # ← 入队前就标记
            q.append(v)
```

**如果"处理完再标记"，一个节点可能被它的多个邻居重复入队多次**，虽然最终结果对，但时间会退化。

## DFS vs BFS 的本质区别

| 维度 | DFS | BFS |
|---|---|---|
| 数据结构 | 栈（递归/显式栈） | 队列 |
| 探索顺序 | 一条路走到黑 | 一层层铺开 |
| 空间 | O(h)，h 为最深路径 | O(w)，w 为最大宽度 |
| 找最短路径 | 无权图上不一定最短 | 无权图上保证最短 |
| 适合 | 连通性、环检测、拓扑排序、回溯 | 最短路径、分层、扩散类 |

**DFS 的空间是路径深度，BFS 的空间是层宽。** 在一棵又高又瘦的树（链表）上 BFS 空间很小；在一棵宽而浅的树（星型）上 DFS 空间很小。

## BFS 求无权图最短路径

**BFS 第一次遇到目标节点时，走过的边数就是最短距离。** 因为 BFS 是按距离递增顺序遍历的。

```python
def shortest_path(adj, start, target):
    if start == target:
        return 0
    visited = {start}
    q = deque([(start, 0)])      # (节点, 距离)
    while q:
        u, d = q.popleft()
        for v in adj[u]:
            if v == target:
                return d + 1
            if v not in visited:
                visited.add(v)
                q.append((v, d + 1))
    return -1     # 不可达

adj = build_adj(6, [[0,1],[0,2],[1,3],[2,3],[3,4],[4,5]])
print(shortest_path(adj, 0, 5))   # 3  (0->1->3->4->5 或 0->2->3->4->5)
print(shortest_path(adj, 0, 0))   # 0
```

**队列里存 `(节点, 距离)`，第一次到达 target 就返回。** 为什么第一次就是最短？因为 BFS 先处理距离 d 的所有节点，才处理距离 d+1 的节点，绝不会"先到远处的再绕回来"。

## 翻车现场：BFS 把距离加在节点上而不是边上

```python
# WRONG：用邻接表存"层数"但每层都加 1，遇到加权边就错
def shortest_path_wrong(adj, start, target):
    q = deque([start])
    dist = {start: 0}
    while q:
        u = q.popleft()
        for v in adj[u]:
            if v not in dist:
                dist[v] = dist[u] + 1     # ← 假设每条边权重都是 1
                q.append(v)
    return dist.get(target, -1)
```

**在无权图上这没错，但一旦边有权重（比如地图距离），BFS 就失效了。** `+1` 只在"每条边权重相同"时成立。

**带权最短路径要用 Dijkstra（第 15 课），它用优先队列而不是普通队列。**

## DFS 的迭代写法：显式栈

**递归 DFS 受 Python 递归深度限制（默认 1000）。节点很多时要改成显式栈。**

```python
def dfs_iter(start, adj):
    visited = set()
    stack = [start]
    order = []
    while stack:
        u = stack.pop()        # 栈：后进先出
        if u in visited:
            continue
        visited.add(u)
        order.append(u)
        for v in adj[u]:
            if v not in visited:
                stack.append(v)
    return order

print(dfs_iter(0, adj))   # [0, 2, 1, 4, 3] （顺序与递归略有不同）
```

**`stack.pop()` 取出最后入栈的，实现"深度优先"。** 注意这里要先判 visited 再处理，否则同一个节点会被它的多个邻居重复压栈。

**迭代 DFS 的顺序和递归 DFS 不完全一样**（因为递归 DFS 总是先处理"列表里第一个邻居"），但都正确访问了所有节点。

## 判断连通性

**从任意节点出发 DFS/BFS，能访问到的节点集合就是它所在的连通分量。** 如果全图都能访问到，图是连通的。

```python
def is_connected(adj):
    if not adj:
        return True
    visited = set()
    start = 0
    stack = [start]
    while stack:
        u = stack.pop()
        if u in visited:
            continue
        visited.add(u)
        for v in adj[u]:
            if v not in visited:
                stack.append(v)
    return len(visited) == len(adj)

print(is_connected(build_adj(4, [[0,1],[1,2],[2,3]])))   # True
print(is_connected(build_adj(4, [[0,1],[2,3]])))         # False
```

**`len(visited) == n` 说明所有节点都能从起点到达。** 这是判断图连通性的标准做法。

## 小结

- DFS 用栈/递归，一条路走到黑；BFS 用队列，一层层铺开
- **图有环，必须 visited**；且要在"入队/入栈前"就标记
- BFS 在无权图上第一次到达 target 即最短路径，O(n+m)
- DFS 递归写法受递归深度限制，节点多时改用显式栈
- DFS 空间 O(h)、BFS 空间 O(w)；根据图形选合适的遍历
- 判断连通性：从一点出发遍历，看是否访问到所有节点
