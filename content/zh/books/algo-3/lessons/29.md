# 前缀和 + 哈希 + 滑动窗口的组合

> 前缀和、哈希表、滑动窗口是三个基础工具，单独用很简单。但真正难的题，需要把它们组合起来。本课通过一道经典题，展示三者如何配合。

## 三个工具的定位

**先回顾每个工具解决什么问题：**

| 工具 | 解决的核心问题 |
|---|---|
| 前缀和 | 区间求和：把 O(n) 的区间查询降到 O(1) |
| 哈希表 | 快速查找：O(1) 判断"有没有"或"在哪" |
| 滑动窗口 | 双指针维护区间：在 O(n) 内处理"满足条件的子数组" |

**组合拳的核心思路：**

> 前缀和负责"算区间和"，哈希表负责"记住前缀和的位置"，滑动窗口负责"维护区间的边界条件"。

## 经典题：和为 K 的子数组

**问题：** 给定整数数组 nums 和目标值 k，求和为 k 的连续子数组的个数。

**暴力 O(n^2)：枚举所有起点和终点，求和。**

```python
def subarray_sum_bruteforce(nums, k):
    n = len(nums)
    count = 0
    for i in range(n):
        s = 0
        for j in range(i, n):
            s += nums[j]
            if s == k:
                count += 1
    return count

print(subarray_sum_bruteforce([1, 1, 1], 2))   # 2
```

**O(n^2)，n=10^5 时必超时。**

### 优化：前缀和 + 哈希表

**前缀和 prefix[i] = nums[0] + ... + nums[i-1]。**

**子数组 nums[j..i-1] 的和 = prefix[i] - prefix[j]。**

**我们要 prefix[i] - prefix[j] == k，即 prefix[j] == prefix[i] - k。**

**用哈希表记录每个前缀和出现了几次，遍历时查找 prefix[i] - k 出现了几次。**

```python
def subarray_sum(nums, k):
    from collections import defaultdict
    count = 0
    prefix_count = defaultdict(int)
    prefix_count[0] = 1        # 空前缀和为 0，出现 1 次
    cur = 0
    
    for x in nums:
        cur += x               # 当前前缀和
        count += prefix_count[cur - k]   # 查找有多少个前缀和 == cur - k
        prefix_count[cur] += 1            # 记录当前前缀和
    
    return count

print(subarray_sum([1, 1, 1], 2))   # 2
print(subarray_sum([1, 2, 3], 3))   # 2（[1,2] 和 [3]）
print(subarray_sum([1, -1, 0], 0))  # 3
```

**时间复杂度 O(n)，空间 O(n)。**

## 滑动窗口：处理"最长/最短"子数组

**问题：** 给定正整数数组和整数 S，求"和 ≥ S"的最短连续子数组的长度。

**因为数组全是正数，窗口的和具有单调性：扩大窗口和增大，缩小窗口和减小。这就可以用滑动窗口。**

```python
def min_subarray_len(S, nums):
    n = len(nums)
    left = 0
    cur = 0
    ans = float('inf')
    
    for right in range(n):
        cur += nums[right]
        while cur >= S:               # 满足条件，尝试缩小
            ans = min(ans, right - left + 1)
            cur -= nums[left]
            left += 1
    
    return ans if ans != float('inf') else 0

print(min_subarray_len(7, [2, 3, 1, 2, 4, 3]))   # 2（[4,3]）
```

**为什么单调性重要？** 如果数组有负数，扩大窗口和不一定增大，缩小窗口和不一定减小，滑动窗口就失效了——这时候得用前缀和 + 二分或前缀和 + 哈希。

## 三者的组合：无重复字符的最长子串

**问题：** 求字符串中不含重复字符的最长子串长度。

**这是"滑动窗口 + 哈希表"的组合：**

```python
def length_of_longest_substring(s):
    n = len(s)
    left = 0
    max_len = 0
    last_pos = {}          # 哈希表：字符 -> 最近出现的位置
    
    for right in range(n):
        c = s[right]
        if c in last_pos and last_pos[c] >= left:
            left = last_pos[c] + 1     # 收缩左边界到上次出现位置的右边
        last_pos[c] = right
        max_len = max(max_len, right - left + 1)
    
    return max_len

print(length_of_longest_substring("abcabcbb"))   # 3（"abc"）
print(length_of_longest_substring("bbbbb"))       # 1
print(length_of_longest_substring("pwwkew"))      # 3（"wke"）
```

**滑动窗口维护"无重复"的区间，哈希表记录每个字符最后出现的位置，O(n) 解决。**

## 进阶组合：和为 K 且长度最长的子数组（含负数）

**问题：** 数组含负数，求和为 k 且长度最长的子数组。

**前缀和 + 哈希表，但这次哈希表记录"每个前缀和最早出现的位置"：**

```python
def longest_subarray_sum_k(nums, k):
    prefix_first = {}       # 前缀和 -> 最早出现的下标
    prefix_first[0] = -1    # 空前缀
    cur = 0
    max_len = 0
    
    for i, x in enumerate(nums):
        cur += x
        target = cur - k
        if target in prefix_first:
            max_len = max(max_len, i - prefix_first[target])
        if cur not in prefix_first:     # 只记录第一次出现（最早）
            prefix_first[cur] = i
    
    return max_len

print(longest_subarray_sum_k([1, -1, 5, -2, 3], 3))   # 4
print(longest_subarray_sum_k([1, 2, 3], 3))            # 2
print(longest_subarray_sum_k([-2, -1, 2, 1], 1))       # 2
```

**因为要"最长"，所以哈希表只记录前缀和第一次出现的位置。这样找到的 j 最小，i-j 最大。**

## 翻车现场：前缀和 + 哈希，忘了初始化 prefix[0]=1

**这是最高频的错误——漏掉空前缀。**

```python
# WRONG：忘了初始化 prefix_count[0] = 1
def subarray_sum_wrong(nums, k):
    from collections import defaultdict
    count = 0
    prefix_count = defaultdict(int)
    # 漏了 prefix_count[0] = 1
    cur = 0
    for x in nums:
        cur += x
        count += prefix_count[cur - k]
        prefix_count[cur] += 1
    return count

print(subarray_sum_wrong([1, 1, 1], 2))   # 漏算了从下标 0 开始的子数组
```

**为什么错？** 当 `cur - k == 0` 时（即当前前缀和恰好等于 k），我们需要 `prefix_count[0]` 为 1 来计数"从下标 0 开始的子数组"。没初始化就是 0，漏算了。

**修复：加上 `prefix_count[0] = 1`。**

## 翻车现场：求最长子数组时，哈希表记录了"最后"位置而不是"最早"

**"最长和"问题中，应该记录前缀和第一次出现的位置，而不是最后一次。**

```python
# WRONG：记录的是最后一次出现的位置
def longest_wrong(nums, k):
    last_pos = {}
    cur = 0
    max_len = 0
    for i, x in enumerate(nums):
        cur += x
        target = cur - k
        if target in last_pos:
            max_len = max(max_len, i - last_pos[target])  # 用最后的位置，差更小
        last_pos[cur] = i          # 覆盖了之前的位置
    return max_len

# [1, 2, 3], k=3
# prefix: 1, 3, 6
# 当 cur=6, target=3, last_pos[3]=1（被覆盖了，但恰好只出现一次）
# 如果 prefix 中 3 出现多次，就会被覆盖成后面的，得到更短的区间
```

**修复：只在 key 不存在时才记录（保留最早的位置）。**

```python
def longest_fixed(nums, k):
    first_pos = {}
    first_pos[0] = -1
    cur = 0
    max_len = 0
    for i, x in enumerate(nums):
        cur += x
        target = cur - k
        if target in first_pos:
            max_len = max(max_len, i - first_pos[target])
        if cur not in first_pos:       # 只记录第一次
            first_pos[cur] = i
    return max_len
```

## 翻车现场：滑动窗口用于含负数的数组，结果错误

**滑动窗口的正确性依赖单调性。如果数组有负数，窗口和不是单调的。**

```python
# WRONG：对含负数的数组用滑动窗口求"和>=S"
def min_len_wrong(S, nums):
    left = 0
    cur = 0
    ans = float('inf')
    for right in range(len(nums)):
        cur += nums[right]
        while cur >= S:
            ans = min(ans, right - left + 1)
            cur -= nums[left]
            left += 1
    return ans if ans != float('inf') else 0

print(min_len_wrong(3, [1, -1, 5, -2, 3]))   # 可能返回错误结果
# 问题在于：缩小时 cur 可能反而变大（如果减去的是负数）
```

**为什么错？** 如果 nums[left] 是负数，减去它会让 cur 变大，while 循环的判断 `cur >= S` 就不可靠了。

**修复：如果数组含负数，改用前缀和 + 二分或前缀和 + 哈希。滑动窗口只适用于元素同号（或窗口大小固定）的场景。**

## 小结

- **前缀和**：把区间求和从 O(n) 降到 O(1)，核心公式 `sum(i,j) = prefix[j+1] - prefix[i]`
- **哈希表**：记录前缀和出现次数/位置，把查找从 O(n) 降到 O(1)
- **滑动窗口**：双指针维护区间，适用于元素同号（窗口和单调）的场景
- **和为 K 的子数组**：前缀和 + 哈希表，O(n)，注意初始化 `prefix[0]=1`
- **最长子数组**：哈希表记录"最早"出现位置
- **无重复子串**：滑动窗口 + 哈希表记录字符最后位置
- 常见坑：漏初始化 prefix[0]、最长问题记录了最后位置、含负数用滑动窗口
