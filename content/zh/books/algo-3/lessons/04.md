# 二叉搜索树 BST：左小右大，查找 O(h)

> BST 是"有序"真正进入树结构的方式。它规定：左子树所有值小于根，右子树所有值大于根。这个简单规则，让查找、插入、删除都能沿着一条路径走到底，只要树别太歪，就是 O(log n)。

## BST 的定义：左小右大

**二叉搜索树（Binary Search Tree）是一棵二叉树，满足：对任一节点，其左子树所有节点的值都小于它，右子树所有节点的值都大于它。** 更严谨的说法是"左子树 ≤ 根 < 右子树"或"左 < 根 ≤ 右"，具体取哪种取决于实现（是否允许重复）。这里采用"左 < 根，右 > 根，不允许重复值"。

```
        8
      /   \
     3     10
    / \      \
   1   6      14
      / \    /
     4   7  13
```

**中序遍历 BST，得到的一定是递增序列。** 这是 BST 最重要的性质，也是验证一棵树是不是 BST 的最直观方法。

```python
def inorder(root, ans):
    if root is None:
        return
    inorder(root.left, ans)
    ans.append(root.val)
    inorder(root.right, ans)

def is_sorted(lst):
    return all(lst[i] < lst[i+1] for i in range(len(lst)-1))

root = build([8, 3, 10, 1, 6, None, 14, None, None, 4, 7, None, None, 13])
ans = []
inorder(root, ans)
print(ans)                 # [1, 3, 4, 6, 7, 8, 10, 13, 14]
print(is_sorted(ans))      # True
```

**注意：build 用的是层序列表，构造出的树结构和你预期一致需要你手动确认。** 上例的层序序列严格对应上面的图。

## 查找：每次砍掉一半

**BST 查找的思路是"比大小，走一边"。** 当前节点就是要找的，返回它；目标比它小，走左边；比它大，走右边。

```python
def search(root, key):
    if root is None:
        return None            # 没找到
    if root.val == key:
        return root
    if key < root.val:
        return search(root.left, key)
    return search(root.right, key)

t = build([8, 3, 10, 1, 6, None, 14, None, None, 4, 7, None, None, 13])
print(search(t, 6).val if search(t, 6) else None)   # 6
print(search(t, 9))                                  # None
```

**找一次最多走一条从根到叶子的路径，长度等于树的高度 h。** 所以查找是 O(h)。平衡 BST（如 AVL、红黑树）h = O(log n)，查找就是 O(log n)；如果树歪成链表，h = n，查找退化成 O(n)。

**这正是 BST 的"阿喀琉斯之踵"：性能全看平衡。** 插入顺序会影响树形——同样 1,2,3,4,5 按顺序插入，会变成一条右斜链。后面要学的平衡树（AVL、红黑树）就是专门治这个问题的，Python 标准库没有内置平衡 BST。

## 插入：找到位置，挂上去

**插入不需要移动元素，只需要找到"该挂在哪片叶子上"。** 逻辑和查找几乎一样，只是碰到空位就新建节点。

```python
def insert(root, key):
    if root is None:
        return TreeNode(key)
    if key < root.val:
        root.left = insert(root.left, key)
    elif key > root.val:
        root.right = insert(root.right, key)
    # key == root.val：这里选择忽略重复值
    return root

def inorder_vals(root):
    ans = []
    def go(n):
        if n is None: return
        go(n.left); ans.append(n.val); go(n.right)
    go(root)
    return ans

t = None
for x in [5, 3, 7, 1, 4, 6, 8]:
    t = insert(t, x)
print(inorder_vals(t))   # [1, 3, 4, 5, 6, 7, 8]
```

**`insert` 返回新节点，并让父节点接住它：`root.left = insert(root.left, key)`。** 这是递归插入的标准写法——空位处创建新节点，返回给父节点，父节点把自己的 left/right 重新指向它。

**为什么必须写 `root.left = insert(...)`？** 因为 Python 里对参数的重新赋值不会影响到调用者。你必须在返回值里把新节点"挂回去"，否则新节点建好了却没人引用，等于白插。

## 翻车现场：插入时忘了把返回值挂回去

```python
# WRONG：insert 建了新节点，但父节点没有接住
def insert(root, key):
    if root is None:
        return TreeNode(key)
    if key < root.val:
        insert(root.left, key)      # ← 返回值被丢弃了
    else:
        insert(root.right, key)
    return root

t = None
for x in [5, 3, 7]:
    t = insert(t, x)
print(inorder_vals(t))   # [5]  ← 3 和 7 都丢了！
```

**输出只有 `[5]`。** 3 和 7 的确被创建成了 `TreeNode`，但没人引用它们——父节点的 `left/right` 还是 `None`，这些新节点随后被垃圾回收。

**修复：左边就写 `root.left = insert(root.left, key)`，右边就写 `root.right = insert(root.right, key)`。** 同理，删除操作也经常需要"把子树的返回值挂回父节点"。

## 翻车现场：判断 BST 只看相邻父子

```python
# WRONG：只检查"父 > 左儿子 && 父 < 右儿子"
def is_bst_wrong(root):
    if root is None:
        return True
    if root.left and not root.left.val < root.val:
        return False
    if root.right and not root.right.val > root.val:
        return False
    return is_bst_wrong(root.left) and is_bst_wrong(root.right)

# 构造一个"相邻对都合法但整体不是 BST"的树：
#       5
#      / \
#     3   8
#        /
#       2          <- 8 的左儿子是 2，合法；但 2 < 5，违反 BST
bad = TreeNode(5, TreeNode(3), TreeNode(8, TreeNode(2)))
print(is_bst_wrong(bad))   # True  ← 错误！
```

**输出 `True`，但它明明不是 BST**（因为 2 在 5 的右子树里，却小于 5）。

**错误根源：BST 的约束是"左子树所有节点 < 根"，不是"左儿子 < 根"。** 只查父子关系漏掉了"孙子违反约束"的情况。

**正确做法：给每个节点一个合法值区间 `(lo, hi)`。** 根没有限制；往左走时上界收紧为 `root.val`；往右走时下界收紧为 `root.val`。

```python
def is_bst(root, lo=float('-inf'), hi=float('inf')):
    if root is None:
        return True
    if not (lo < root.val < hi):
        return False
    return is_bst(root.left, lo, root.val) and is_bst(root.right, root.val, hi)

print(is_bst(bad))    # False  ✓
```

**区间下推是 BST 题的万能思路**：验证、找最近公共祖先、统计某个范围内的节点数，全都能用。

## 删除：三种情况

**删除是 BST 里最麻烦的操作，分三种情况：**

1. **叶子节点**：直接删（父节点的指针置 None）。
2. **只有一个子节点**：让父节点绕过它，直接指向那个子节点。
3. **有两个子节点**：找到右子树的最小节点（或左子树的最大节点）替换它，再删掉那个替身。

```python
def find_min(n):
    while n.left:
        n = n.left
    return n.val

def delete(root, key):
    if root is None:
        return None
    if key < root.val:
        root.left = delete(root.left, key)
    elif key > root.val:
        root.right = delete(root.right, key)
    else:   # 找到要删的节点
        if root.left is None:
            return root.right          # 情况 1/2：左空
        if root.right is None:
            return root.left           # 情况 2：右空
        # 情况 3：左右都不空，用右子树最小值替换
        root.val = find_min(root.right)
        root.right = delete(root.right, root.val)
    return root
```

**"用右子树最小值替换"为什么对？** 因为右子树的最小值一定比左子树所有节点大、比右子树其余节点小，替换后 BST 性质依然保持。这个最小值节点最多只有一个右儿子，删它又退化成情况 1/2。

**删除在面试里不常要求手写，但理解"第三种情况的替换"很有必要**——它体现了 BST 有序性的利用。

## BST 的应用：找第 k 小元素

**既然 BST 中序是递增的，那"第 k 小"就是中序序列的第 k 个。** 为了省空间，可以在中序递归里计数，找到就停。

```python
def kth_smallest(root, k):
    ans = [None]
    def go(n):
        if not n or ans[0] is not None:
            return
        go(n.left)
        k[0] -= 1
        if k[0] == 0:
            ans[0] = n.val
        go(n.right)
    k = [k]
    go(root)
    return ans[0]

t = build([5, 3, 7, 2, 4, 6, 8])
print(kth_smallest(t, 3))   # 4
```

**这个写法是"中序 + 计数"，找到第 k 个就提前退出。** 更通用的做法是用"节点带 size 的 BST"（平衡树如 AVL 常用），可以在 O(log n) 内查任意第 k 小。这是 LeetCode 230 题，面试出现频率极高。

## 小结

- BST 性质：**左子树全部 < 根 < 右子树全部**；中序遍历必为递增序列
- 查找、插入、删除都沿一条路径走，复杂度 O(h)；平衡时 h=O(log n)
- 插入必须 `root.left = insert(root.left, key)` 挂回返回值，否则新节点丢失
- **判断 BST 不能只看父子**，要用区间 `(lo, hi)` 下推，或用中序递增验证
- 删除三种情况：叶子直接删、单子节点绕过、双子节点用右子树最小值替换
- 中序 + 计数可以在 O(k) 内找第 k 小元素
