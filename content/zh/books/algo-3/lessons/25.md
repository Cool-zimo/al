# 背包问题：01 背包与完全背包

> 背包问题是动态规划的经典应用场景。本课讲两种最基础的背包：01 背包（每件物品只能用一次）和完全背包（每件物品可以无限用）。核心在于理解"为什么 01 背包要倒序遍历"。

## 01 背包：每件物品只能用一次

**问题描述：** 有一个容量为 W 的背包和 n 件物品，第 i 件物品的重量为 `weight[i]`，价值为 `value[i]`。**每件物品最多选一次**，求能装进背包的最大价值。

### dp 数组的定义

**经典的 01 背包用二维 dp：**

> `dp[i][j]` = 考虑前 i 件物品，在容量为 j 的背包中能获得的最大价值

### 转移方程

**对于第 i 件物品（下标从 1 开始），有两种选择：**

```
不选第 i 件：dp[i][j] = dp[i-1][j]
选第 i 件（前提是 j >= weight[i]）：dp[i][j] = dp[i-1][j-weight[i]] + value[i]

dp[i][j] = max(dp[i-1][j], dp[i-1][j-weight[i]] + value[i])
```

```python
def knapsack_2d(W, weights, values):
    n = len(weights)
    dp = [[0] * (W + 1) for _ in range(n + 1)]
    
    for i in range(1, n + 1):
        for j in range(W + 1):
            dp[i][j] = dp[i - 1][j]    # 不选第 i 件
            if j >= weights[i - 1]:    # 容量够，可以尝试选
                dp[i][j] = max(dp[i][j],
                               dp[i - 1][j - weights[i - 1]] + values[i - 1])
    return dp[n][W]

print(knapsack_2d(4, [1, 2, 3], [15, 20, 30]))   # 35
```

### 空间优化：一维 dp + 倒序遍历

**注意到 dp[i][j] 只依赖 dp[i-1][...]（上一行），可以用一维数组滚动优化：**

```python
def knapsack_1d(W, weights, values):
    n = len(weights)
    dp = [0] * (W + 1)
    
    for i in range(n):
        for j in range(W, weights[i] - 1, -1):   # 倒序！从 W 到 weight[i]
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i])
    
    return dp[W]

print(knapsack_1d(4, [1, 2, 3], [15, 20, 30]))   # 35
```

### 为什么 01 背包要倒序遍历？

**这是本课的核心。**

**一维 dp[j] 的含义：`dp[j]` = 容量为 j 的背包当前能获得的最大价值。**

**当我们考虑第 i 件物品时，更新 `dp[j]` 需要用到"上一轮"的 `dp[j - weights[i]]`。**

- **如果正序遍历**（j 从小到大）：当更新 dp[j] 时，`dp[j - weights[i]]` 可能已经被第 i 轮更新过了 → 意味着第 i 件物品被**重复使用了**
- **如果倒序遍历**（j 从大到小）：更新 dp[j] 时，`dp[j - weights[i]]` 还没被本轮更新 → 保证第 i 件物品只用了一次

```
正序（错误）：dp[j] 依赖的 dp[j-w] 可能已经被本轮覆盖
  dp = [0, 0, 0, 0, 0]
  考虑物品 weight=2, value=15：
  j=2: dp[2] = max(0, dp[0]+15) = 15 → dp = [0, 0, 15, 0, 0]
  j=3: dp[3] = max(0, dp[1]+15) = 0
  j=4: dp[4] = max(0, dp[2]+15) = 30 ← dp[2] 已经是本轮的 15 了！物品被用了两次！

倒序（正确）：
  dp = [0, 0, 0, 0, 0]
  考虑物品 weight=2, value=15：
  j=4: dp[4] = max(0, dp[2]+15) = 15 → dp = [0, 0, 0, 0, 15]
  j=3: dp[3] = max(0, dp[1]+15) = 0
  j=2: dp[2] = max(0, dp[0]+15) = 15 → dp = [0, 0, 15, 0, 15]
  → 每件物品只被用了一次
```

**一句话总结：倒序保证 `dp[j - w]` 是"上一轮"的值，正序会导致"本轮"的值被复用 → 物品重复选取。**

## 完全背包：每件物品可以无限用

**完全背包与 01 背包的唯一区别：每件物品可以选无限次。**

**这恰好意味着——我们可以正序遍历！**

```python
def unbounded_knapsack(W, weights, values):
    dp = [0] * (W + 1)
    
    for i in range(len(weights)):
        for j in range(weights[i], W + 1):    # 正序！从 weight[i] 到 W
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i])
    
    return dp[W]

print(unbounded_knapsack(4, [1, 2, 3], [15, 20, 30]))   # 60（选 4 个重量1的）
```

**为什么完全背包用正序？** 因为正序时 `dp[j - w]` 可能已经被本轮更新过，意味着**允许再次选择同一物品**——这正是完全背包的需求。

**对比：**

| | 01 背包 | 完全背包 |
|---|---|---|
| 物品次数 | 最多 1 次 | 无限次 |
| 遍历方向 | **倒序**（W → w） | **正序**（w → W） |
| 本质 | 用上一轮的值 | 允许用本轮的值 |

## 翻车现场：01 背包用了正序遍历，物品被重复选取

**这是 01 背包最高频的错误——把遍历方向写错了。**

```python
# WRONG：01 背包用正序遍历
def knapsack_wrong(W, weights, values):
    n = len(weights)
    dp = [0] * (W + 1)
    for i in range(n):
        for j in range(weights[i], W + 1):   # 正序！错了！
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i])
    return dp[W]

print(knapsack_wrong(4, [2], [10]))   # 期望 10，实际 20！
```

**为什么输出 20？** 只有一个重量 2、价值 10 的物品，容量为 4 时：

```
正序遍历：
  j=2: dp[2] = max(0, dp[0]+10) = 10 → dp = [0, 0, 10, 0, 0]
  j=3: dp[3] = max(0, dp[1]+10) = 0
  j=4: dp[4] = max(0, dp[2]+10) = 20 ← dp[2] 已经是 10 了！物品被用了两次！
```

**同一个物品被用了两次，违反了"每件物品最多一次"的约束。** 修复：把遍历方向改成倒序 `range(W, weights[i] - 1, -1)`。

## 翻车现场：dp 数组只开到 W，但访问了 dp[j - weights[i]] 导致越界

**内层循环从 `weights[i]` 开始，但如果 weights[i] 比 W 大，循环不会执行（这是对的）。但如果写成 `range(1, W+1)` 且不加判断，就会越界。**

```python
# WRONG：内层循环从 1 开始，没判断容量是否够
def knapsack_bad(W, weights, values):
    n = len(weights)
    dp = [0] * (W + 1)
    for i in range(n):
        for j in range(1, W + 1):           # 从 1 开始，没有判断 j >= weights[i]
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i])  # j < weights[i] 时越界
    return dp[W]

# IndexError: list index out of range
```

**修复：内层循环从 `weights[i]` 开始：`for j in range(weights[i], W + 1)`（完全背包正序）或 `range(W, weights[i] - 1, -1)`（01 背包倒序）。**

## 翻车现场：初始化 dp 为 1 而不是 0，导致所有价值被错误放大

**dp 数组应该初始化为 0（容量为 0 时最大价值为 0）。如果初始化成 1，会导致所有计算结果偏大。**

```python
# WRONG：dp 初始化为 1
def knapsack_init_wrong(W, weights, values):
    n = len(weights)
    dp = [1] * (W + 1)    # 错！应该是 [0] * (W + 1)
    for i in range(n):
        for j in range(W, weights[i] - 1, -1):
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i])
    return dp[W]

print(knapsack_init_wrong(4, [1, 2, 3], [15, 20, 30]))  # 结果偏大
```

**`dp[0] = 1` 意味着"容量为 0 时已经有价值 1"，这是错误的。** 容量为 0 时什么也装不了，价值必然是 0。

**注意：如果是"恰好装满"的变体，初始化方式不同——`dp[0] = 0`，其余 `dp[j] = -inf`（表示不可达）。**

## 小结

- **01 背包**：每件物品最多选一次，转移 `dp[j] = max(dp[j], dp[j-w] + v)`，**倒序遍历**
- **完全背包**：每件物品无限选，转移相同，但**正序遍历**
- **倒序的本质**：保证 `dp[j-w]` 是上一轮的值，物品不被重复选
- **正序的本质**：允许 `dp[j-w]` 是本轮更新后的值，物品可重复选
- **初始化 dp 全为 0**：默认"不要求恰好装满"，`dp[0] = 0` 表示空背包价值 0
- 常见坑：遍历方向写反、循环起始位置错误、dp 初始化值不对
