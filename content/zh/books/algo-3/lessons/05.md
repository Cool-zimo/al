# 实战：求树的深度、节点数、判断平衡

> 前三课学了遍历，这一课用三个"量"把它们串起来：最大深度、节点总数、是否平衡。三者都是"左右子树结果 + 根的加工"，区别只在加工方式。

## 三个量，一个骨架

**"求树的某个整体量"这类题，几乎都能写成：`f(root) = combine(f(left), root, f(right))`。** 三者的骨架完全相同：

| 问题 | 终止条件 | 左右结果怎么合并 |
|---|---|---|
| 节点数 | 空树返回 0 | `1 + left + right` |
| 最大深度 | 空树返回 0 | `1 + max(left, right)` |
| 最大宽度 | 空树返回 0 | BFS 各层 size 的最大值 |

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def build(vals):
    if not vals or vals[0] is None:
        return None
    nodes = [None if v is None else TreeNode(v) for v in vals]
    for i in range(len(nodes)):
        if nodes[i] is None:
            continue
        left, right = 2 * i + 1, 2 * i + 2
        if left < len(nodes) and nodes[left] is not None:
            nodes[i].left = nodes[left]
        if right < len(nodes) and nodes[right] is not None:
            nodes[i].right = nodes[right]
    return nodes[0]
```

## 最大深度：自底向上，先要孩子的答案

**最大深度 = 1 + 左右子树深度的较大者。** 注意是"自底向上"——你得先知道左右子树的深度，才能算自己的。

```python
def max_depth(root):
    if root is None:
        return 0
    left = max_depth(root.left)
    right = max_depth(root.right)
    return 1 + max(left, right)

print(max_depth(build([3, 9, 20, None, None, 15, 7])))   # 3
print(max_depth(build([1, 2, 3, 4, 5])))                 # 3
print(max_depth(None))                                    # 0
```

**终止条件 `None -> 0` 决定了空树深度为 0。** 这个约定和"高度"的定义一致：叶子高度为 0，空树为 -1。注意"深度"和"高度"在叶子处都是 0，但对空树深度常取 0、高度常取 -1，不同教材说法不一，写代码时先明确约定。

## 节点数：1 + 左 + 右

**节点数 = 1（根）+ 左子树节点数 + 右子树节点数。** 这是"左右结果 + 根"句式最简单的例子。

```python
def count_nodes(root):
    if root is None:
        return 0
    return 1 + count_nodes(root.left) + count_nodes(root.right)

print(count_nodes(build([1, 2, 3, None, None, 4, 5])))   # 5
print(count_nodes(None))                                   # 0
```

**这个写法和层序遍历得到的节点数是同一个数。** 它说明"遍历"和"统计"是同一件事的两面：遍历是把节点取出来，统计是把节点数累加。

## 平衡二叉树：高度差不超过 1

**平衡二叉树（Balanced Binary Tree）的定义是：左右子树的高度差不超过 1，且左右子树本身也都是平衡的。** 注意这是"每个节点都要满足"，不只是根节点。

```python
def is_balanced(root):
    def height(n):
        if n is None:
            return 0
        return 1 + max(height(n.left), height(n.right))
    if root is None:
        return True
    left_h = height(root.left)
    right_h = height(root.right)
    return abs(left_h - right_h) <= 1 and is_balanced(root.left) and is_balanced(root.right)

t1 = build([3, 9, 20, None, None, 15, 7])
t2 = build([1, 2, 3, 4, 5, None, None])
print(is_balanced(t1))   # True
print(is_balanced(t2))   # False  (右子树高度为 2，左子树为 0)
```

**这个写法正确但效率不高：每个节点都重新算一遍高度，整体 O(n²)。** 在歪斜树上尤其慢。面试要求往往是 O(n)。

## 翻车现场：is_balanced 写成 O(n²)

上面那种"每个节点都重算高度"的写法，问题在于**同一个高度被重复算了无数次**。看一条右斜链 `[1, None, 2, None, 3, None, 4]`：

```
height(1): 还要算 height(2)、height(3)、height(4)
height(2): 还要算 height(3)、height(4)
height(3): 还要算 height(4)
```

**4 个节点算高度，height(4) 被算了 4 次、height(3) 被算了 3 次……** 总调用次数约 n(n+1)/2 = O(n²)。n=10000 时就是五千万次调用，直接超时。

**修法是"一次遍历同时带回高度和平衡信息"**——这就是下一节的 O(n) 写法。

## O(n) 判平衡：一次遍历带回高度和平衡标志

**核心思想：让递归函数同时返回"子树高度"和"子树是否平衡"。** 一旦发现某处不平衡，整条链都返回不平衡。

```python
def is_balanced_fast(root):
    def go(n):
        if n is None:
            return 0, True          # 高度 0，且空树平衡
        lh, lb = go(n.left)
        if not lb:
            return -1, False        # 左子树已不平衡，短路
        rh, rb = go(n.right)
        if not rb:
            return -1, False
        if abs(lh - rh) > 1:
            return -1, False        # 当前节点不平衡
        return 1 + max(lh, rh), True
    return go(root)[1]

t2 = build([1, 2, 3, 4, 5, None, None])
print(is_balanced_fast(t2))   # False
print(is_balanced_fast(build([3, 9, 20, None, None, 15, 7])))   # True
```

**返回 `-1` 是约定的"错误码"。** 一旦某处返回 `-1`，所有上层都跟着返回 `-1`，整条链短路。每个节点只访问一次，O(n)。

**这种模式叫"后序遍历 + 返回多个信息"。** 后面 LCA、直径、路径和都会用到——凡是"要先知道孩子的情况才能决定自己"的题，都是后序。

## 树的直径：后序带回两个信息

**直径（Diameter）是"树上最远两个节点的距离"（边数）。** 它有两种可能：要么经过根，等于左右深度之和；要么完全在左子树或右子树里。所以每到一个节点，都要同时更新"经过当前节点的最大距离"和"自己的深度"。

```python
def diameter(root):
    ans = [0]                       # 用列表装，方便在闭包里改
    def go(n):
        if n is None:
            return 0
        l = go(n.left)
        r = go(n.right)
        ans[0] = max(ans[0], l + r)   # 经过当前节点的最远路径
        return 1 + max(l, r)          # 返回自己的深度
    go(root)
    return ans[0]

print(diameter(build([1, 2, 3, 4, 5])))            # 3  (路径 4-2-1-3 或 4-2-1-5)
print(diameter(build([1, 2, None, 3, None, 4])))   # 3  (路径 4-3-2-1)
print(diameter(None))                               # 0
```

**这里又一次"返回深度 + 更新全局答案"。** 直径问题的关键洞察是：最远路径**一定**是某节点"左深度 + 右深度"。所以遍历每个节点算一次 `l + r`，取最大值即可。

## 翻车现场：直径只算"经过根"的那条

```python
# WRONG：只算左深度 + 右深度，忽略了最远路径完全在某一侧子树里
def diameter_wrong(root):
    if root is None:
        return 0
    left_d = max_depth(root.left)
    right_d = max_depth(root.right)
    return left_d + right_d

t = build([1, 2, None, 3, None, 4, None, 5])  # 一条左斜链，直径应是 3
print(diameter_wrong(t))   # 0  ← 错了！左子树为空
```

**输出 0，而正确答案是 3。** 因为最远路径 5-4-3-2 完全在左子树里，根本不经过根。

**教训：凡是"全局最优"问题，必须遍历每个节点考虑"以它为转折点"，不能只看根。**

## 翻转二叉树：交换左右

**翻转（Invert / Mirror）就是"对每个节点，交换它的左右子树"。** 这是一个很好的后序/前序练习。

```python
def invert(root):
    if root is None:
        return None
    root.left, root.right = invert(root.right), invert(root.left)
    return root

def to_list(root):
    if root is None:
        return []
    from collections import deque
    ans, q = [], deque([root])
    while q:
        n = q.popleft()
        if n is None:
            ans.append(None)
        else:
            ans.append(n.val)
            q.append(n.left)
            q.append(n.right)
    while ans and ans[-1] is None:
        ans.pop()
    return ans

t = build([4, 2, 7, 1, 3, 6, 9])
invert(t)
print(to_list(t))   # [4, 7, 2, 9, 6, 3, 1]
```

**交换必须在递归之后（后序）或之前（前序）都行，只要两边都处理过。** 前序写法：`root.left, root.right = invert(root.right), invert(root.left)`，先交换再递归，效果一样。

## 小结

- 求树的量 = `combine(左结果, 根, 右结果)`：节点数 `1+left+right`，深度 `1+max(left,right)`
- **平衡树要求每个节点左右高度差 ≤1**，不只是根节点
- 朴素判平衡是 O(n²)，O(n) 写法是"一次遍历同时返回高度和平衡标志"，不平衡用 `-1` 短路
- **直径必须考虑"经过每个节点"**，不能只看根；套路是返回深度 + 更新全局最大值
- 翻转二叉树就是交换每个节点的左右子树，前序后序都行
