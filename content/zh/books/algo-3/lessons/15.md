# 最短路径：Dijkstra 的思路

> 有权图上怎么找两点间最短路径？BFS 只适用于无权图。Dijkstra 是答案——它用"每次选当前距离最小的节点"这个贪心策略，逐步确定每个节点的最短距离。这一课讲清直觉，不讲证明。

## 无权图用 BFS，有权图用 Dijkstra

**BFS 能求无权图最短路径，因为每条边权重相同（都是 1）。一旦边有权重（比如道路距离、时间、费用），BFS 就失效了。**

Dijkstra 处理的是**带非负权重的图**：给定起点 s，求出 s 到所有其他节点的最短距离。

```python
# 带权有向图：邻接表存 (邻居, 权重)
adj = {
    0: [(1, 4), (2, 1)],
    1: [(3, 1)],
    2: [(1, 2), (3, 5)],
    3: [],
}
```

**边权必须非负。** 如果有负权边，Dijkstra 会给出错误答案，那种情况要用 Bellman-Ford 或 SPFA。

## 贪心直觉：每次确定"当前离起点最近"的节点

**Dijkstra 的核心直觉：已经确定最短距离的节点，不会再被更新。**

假设起点 s 到某节点 u 的当前距离是 `dist[u]`，且 u 是所有"未确定"节点中距离最小的。那么 `dist[u]` 就是 s 到 u 的最短距离——因为任何一条"绕道别的未确定节点"的路径，第一步就要走一条边，总距离必然 ≥ 那条边的权重 + 别的节点的距离 ≥ `dist[u]`。

```python
import heapq

def dijkstra(n, adj, start):
    dist = [float('inf')] * n
    dist[start] = 0
    pq = [(0, start)]           # 最小堆：(当前距离, 节点)

    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:         # 过期的条目，跳过
            continue
        for v, w in adj[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist

n = 4
adj = [[] for _ in range(n)]
for u, v, w in [(0,1,4),(0,2,1),(1,3,1),(2,1,2),(2,3,5)]:
    adj[u].append((v, w))

print(dijkstra(n, adj, 0))   # [0, 3, 1, 4]
```

**从 0 出发：到 2 最短是 1；到 1 最短是 0→2→1 = 3（比直连的 4 更短！）；到 3 最短是 0→2→1→3 = 4。**

**关键洞察：先到 1 的直连路是 4，但"绕道 2"只要 3。** Dijkstra 的贪心会先处理距离小的 2，再借 2 更新 1，最终得到 3。

## 翻车现场：忘记跳过过期条目，结果重复处理

```python
# WRONG：没有 `if d > dist[u]: continue`，同一个节点被多次处理
def dijkstra_wrong(n, adj, start):
    dist = [float('inf')] * n
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        # 忘了跳过
        for v, w in adj[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist
```

**`dist[v]` 可能被多次更新，同一个节点会被多次入队。** 虽然最终结果正确，但堆里会积累大量"过期条目"，每个节点可能被处理多次，时间退化到 O(m log m)。

**修复：`if d > dist[u]: continue`** —— 如果弹出的距离比已知的还大，说明这是一条旧记录，直接跳过。

## 为什么用最小堆

**Dijkstra 要"每次取出距离最小的未确定节点"。** 这个"动态取最小值"的操作，堆是标配，O(log n) 一次。

**朴素实现不用堆，每次线性扫描找最小值，O(n²)。** 堆优化版 O((n+m) log n)。

```python
# 对比：朴素版（适合稠密图、n 较小）
def dijkstra_naive(n, adj, start):
    dist = [float('inf')] * n
    dist[start] = 0
    visited = [False] * n
    for _ in range(n):
        u = min((i for i in range(n) if not visited[i]), key=lambda i: dist[i])
        visited[u] = True
        for v, w in adj[u]:
            dist[v] = min(dist[v], dist[u] + w)
    return dist
```

**`heapq` 是最小堆，正好符合"取最小"。** 如果用最大堆需要存负数（第 10 课讲过）。

## 翻车现场：把 dist 当堆元素排序键，结果距离不变就不更新

```python
# WRONG：只比较节点，不比较距离，导致更新不到
def relax(u, v, w, pq, dist):
    nd = dist[u] + w
    if nd <= dist[v]:         # 用 <= 会把"相等距离"也当成更新
        dist[v] = nd
        heapq.heappush(pq, (nd, v))
```

**`nd <= dist[v]` 当 nd == dist[v] 时会重复入队一个相同的条目。** 虽然不致命（会被"过期跳过"处理掉），但浪费堆空间。

**用 `<` 就好：`if nd < dist[v]`。**

## 判断可达性

**如果某个节点到不了，`dist` 里就是 `inf`。**

```python
dist = dijkstra(4, adj, 0)
print(dist[3])          # 4，可达
print(dist[0])          # 0，起点自己

# 判断能否到达
def reachable(dist, target):
    return dist[target] != float('inf')

print(reachable(dist, 3))   # True
```

**初始化 `dist = [inf] * n`、起点为 0，是标准写法。** `inf + w` 还是 `inf`，所以不可达的节点会一直保持 `inf`。

## 单源 vs 多源

**单源：一个起点。** 上面都是单源。

**多源：多个起点，求每个节点到"最近起点"的距离。** 把堆的初始状态设成"所有起点都是距离 0"即可。

```python
def multi_source(adj, starts):
    n = len(adj)
    dist = [float('inf')] * n
    pq = []
    for s in starts:
        dist[s] = 0
        heapq.heappush(pq, (0, s))
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in adj[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist
```

**多源最短路径 = "把所有起点同时塞进堆"。** 典型应用：求每个房子到最近消防站的距离。

## 小结

- Dijkstra 求单源最短路径，要求边权非负
- 核心贪心：每次选"当前距离最小"的未确定节点，它的距离已确定
- 堆优化 O((n+m) log n)；朴素版 O(n²)，适合稠密图
- **必须跳过过期条目：`if d > dist[u]: continue`**
- 多源最短路径 = 把所有起点距离置 0 一起入堆
- 负权边场景 Dijkstra 失效，要用 Bellman-Ford
