# 二分答案 + 判定的组合拳

> 有些题问的是"最优值是多少"，直接求很难；但如果问"值能不能 ≤ X"，却很好判断。二分答案就是把"求最优"转成"判定可行"的经典套路。

## 二分答案的核心思想

**二分答案适用于这样一类问题：**

> 要求一个"最大/最小"的最优值，直接算很困难；但如果给定一个候选值 X，判断"答案能否 ≤ X（或 ≥ X）"很容易。

**思路：**

```
1. 确定答案的范围 [left, right]
2. 在范围内二分查找
3. 每次取 mid，写一个判定函数 check(mid)
4. 如果 check(mid) 为真，说明答案可以更小/更大，缩小范围
5. 如果 check(mid) 为假，说明答案必须更大/更小，缩小范围
6. 最终收敛到最优解
```

**关键：check 函数的编写。它要把"答案 ≤ mid 是否可行"判断出来。**

## 经典例子：最小化最大值

**问题：** 把 n 本书分给 k 个人，每本书有页数 pages[i]。每个人分到的书必须是连续的。求"分配方案中最多的那个人分到的页数"的最小值。

**直接求很难，但判定很容易：**

```python
def check(pages, k, limit):
    """判断：能否在每人最多读 limit 页的限制下，用 k 个人分完所有书"""
    people = 1
    cur = 0
    for p in pages:
        if cur + p <= limit:
            cur += p
        else:
            people += 1
            cur = p
            if people > k:
                return False
    return True
```

**判定逻辑：** 贪心地从左到右分书，当前人读满了 limit 就换下一个人。如果最终用了不超过 k 个人，说明 limit 可行。

**然后二分：**

```python
def min_max_pages(pages, k):
    left = max(pages)          # 最少也要读最多的那一本
    right = sum(pages)         # 最多一个人全读完
    
    while left < right:
        mid = (left + right) // 2
        if check(pages, k, mid):
            right = mid          # 可行，尝试更小
        else:
            left = mid + 1       # 不可行，必须更大
    return left

print(min_max_pages([12, 34, 67, 90], 2))   # 113
```

**时间复杂度：O(n log sum)，二分 log(sum) 次，每次 check O(n)。**

## 单调性是二分答案的命脉

**二分答案成立的前提是：check 函数具有单调性。**

> 如果答案 ≤ X 可行，那么答案 ≤ X+1 一定也可行（对"最小化"问题）。

**直观理解：** 限制越宽松（limit 越大），越容易分配。所以从某个临界点开始，check 从 False 变成 True，且之后全是 True。

```
limit:   50  60  70  80  90  100  110  120
check:   F   F   F   F   F    F    T    T
                              ↑ 临界点 = 答案
```

**二分就是在找这个从 F 到 T 的临界点。**

## 二分答案的模板

**最小化（找最小的满足条件的 X）：**

```python
left = 下界
right = 上界
while left < right:
    mid = (left + right) // 2
    if check(mid):
        right = mid          # mid 可行，答案可能更小
    else:
        left = mid + 1       # mid 不可行，答案必须更大
return left
```

**最大化（找最大的满足条件的 X）：**

```python
left = 下界
right = 上界
while left < right:
    mid = (left + right + 1) // 2    # 注意 +1，避免死循环
    if check(mid):
        left = mid          # mid 可行，答案可能更大
    else:
        right = mid - 1     # mid 不可行，答案必须更小
return left
```

**注意：最大化时 mid 要取上整 `(left+right+1)//2`，否则可能死循环。**

## 更多二分答案的经典题

**以下都是二分答案的常见应用：**

1. **在 D 天内送达包裹的能力**：最小化船的载重量 → check: 能否在 D 天内运完
2. **分割数组的最大值**：最小化子数组和的最大值 → check: 能否分成 m 段且每段和 ≤ limit
3. **木材加工**：最大化能切出的等长木材数 → check: 给定长度能切出多少段
4. **找出第 K 小的数对距离**：最小化第 K 小的距离 → check: 有多少对距离 ≤ mid

**共同点：问"最小/最大的那个值是多少"，直接算难，判定易。**

## 翻车现场：判定函数单调性搞反，二分方向写错

**这是二分答案最高频的错误——check 函数写对了，但二分方向搞反了。**

```python
# WRONG：最小化问题，但 check 返回 True 时却往大了走
def min_max_pages_wrong(pages, k):
    left = max(pages)
    right = sum(pages)
    while left < right:
        mid = (left + right) // 2
        if check(pages, k, mid):
            left = mid + 1       # WRONG！应该往小走
        else:
            right = mid           # WRONG！应该往大走
    return left

# 返回错误答案
```

**为什么错？** check(mid) 为 True 说明 mid 可行，答案可以更小，应该 `right = mid` 而不是 `left = mid + 1`。

**修复：check 为 True 时缩小上界，为 False 时缩小下界。**

```python
def min_max_pages_fixed(pages, k):
    left = max(pages)
    right = sum(pages)
    while left < right:
        mid = (left + right) // 2
        if check(pages, k, mid):
            right = mid
        else:
            left = mid + 1
    return left

print(min_max_pages_fixed([12, 34, 67, 90], 2))   # 113
```

## 翻车现场：最大化问题忘了 mid 取上整，死循环

**最大化时如果 mid 取下整，可能出现 left == right 永远不成立的情况。**

```python
# WRONG：最大化，mid 取下整导致死循环
def maximize_wrong(check_func, left, right):
    while left < right:
        mid = (left + right) // 2     # WRONG！应该 +1
        if check_func(mid):
            left = mid                # left=mid, 如果 right=mid+1 就死循环
        else:
            right = mid - 1
    return left

# 当 left=3, right=4, mid=3:
# check(3) 为 True → left=3, right=4 → 无限循环！
```

**修复：最大化时 mid 取上整。**

```python
def maximize(check_func, left, right):
    while left < right:
        mid = (left + right + 1) // 2    # +1 避免死循环
        if check_func(mid):
            left = mid
        else:
            right = mid - 1
    return left
```

**原理：当区间只剩两个元素 [left, left+1] 时，取下整 mid=left，如果 check 为 True，left 不变，死循环。取上整 mid=left+1，left 会更新，循环收敛。**

## 翻车现场：check 函数的边界条件漏掉

**check 函数的边界没写对，导致判定结果错误。**

```python
# WRONG：check 没处理"单本书就超过 limit"的情况
def check_wrong(pages, k, limit):
    people = 1
    cur = 0
    for p in pages:
        if cur + p <= limit:
            cur += p
        else:
            people += 1
            cur = p          # 如果 p > limit，这里 cur=p 也超过了 limit！
            if people > k:
                return False
    return True

# pages=[100, 1, 1], k=2, limit=50
# 第一本书 100 > 50，cur=100，但只算了 1 个人
# 实际不可能用 2 个人分完（100 一本书就超了），但函数返回 True
```

**修复：加入对单本书超过 limit 的判断。**

```python
def check_fixed(pages, k, limit):
    if max(pages) > limit:       # 单本书超过限制，不可能
        return False
    people = 1
    cur = 0
    for p in pages:
        if cur + p <= limit:
            cur += p
        else:
            people += 1
            cur = p
            if people > k:
                return False
    return True
```

**这也和二分的范围设定呼应：left 应该设为 max(pages)，因为单本书不可能拆开。**

## 小结

- **二分答案**：把"求最优值"转成"判定可行性"，在答案范围内二分查找
- **核心：check 函数**——判断"答案 ≤ X 是否可行"，要写对单调性和边界
- **最小化模板**：check 为 True → right=mid；check 为 False → left=mid+1
- **最大化模板**：mid 取上整 `(left+right+1)//2`；check 为 True → left=mid
- **单调性**是二分答案的前提：限制越宽松越容易满足
- 常见坑：二分方向搞反、最大化忘了 +1 死循环、check 边界漏掉
