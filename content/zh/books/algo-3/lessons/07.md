# 路径问题：根节点到叶子的路径和

> "路径"是树题的第二大类。这一课讲最基础的两种：根到叶子的路径和、以及"是否存在一条路径和等于 target"。核心是把"当前路径状态"作为参数一路传下去。

## 根到叶子的路径：前序遍历 + 传参

**"根到叶子"要求你从根一路走到某个叶子。** 做法：前序遍历，把"当前累加和"作为参数往下传；到达叶子时检查是否等于目标。

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def build(vals):
    if not vals or vals[0] is None:
        return None
    nodes = [None if v is None else TreeNode(v) for v in vals]
    for i in range(len(nodes)):
        if nodes[i] is None:
            continue
        left, right = 2 * i + 1, 2 * i + 2
        if left < len(nodes) and nodes[left] is not None:
            nodes[i].left = nodes[left]
        if right < len(nodes) and nodes[right] is not None:
            nodes[i].right = nodes[right]
    return nodes[0]

def has_path_sum(root, target):
    if root is None:
        return False
    target -= root.val                  # 传递"剩余目标和"
    if root.left is None and root.right is None:
        return target == 0             # 到达叶子
    return has_path_sum(root.left, target) or \
           has_path_sum(root.right, target)

print(has_path_sum(build([5, 4, 8, 11, None, 13, 4, 7, 2]), 22))   # True
print(has_path_sum(build([5, 4, 8, 11, None, 13, 4, 7, 2]), 20))   # False
```

**关键技巧：`target -= root.val`，把"还差多少"往下传。** 这样到叶子时只需检查 `target == 0`，不用维护一个全局累加变量。

## 翻车现场：把"空节点"当成"叶子"

```python
# WRONG：没判断叶子，在空节点处检查 target == 0
def has_path_sum_wrong(root, target):
    if root is None:
        return target == 0          # ← 错误！空节点不是叶子
    target -= root.val
    return has_path_sum_wrong(root.left, target) or \
           has_path_sum_wrong(root.right, target)

t = build([1, 2])   # 只有一条路径 1->2，和为 3
print(has_path_sum_wrong(t, 1))   # True  ← 错误！路径和 3，却判为 True
```

**为什么错？** 走 `1->2` 后到叶子 2，再往左走到空节点：此时 `target = 1 - 1 - 2 = -2`。空节点的 `target == 0` 是 False，看似没事——但如果你在某条"实际不存在"的半路上恰好凑出 target，就会误判。

**真正的坑在这里：**

```python
t2 = build([1, 2, 3])
# 路径有 1->2(和3) 和 1->3(和4)
print(has_path_sum_wrong(t2, 1))   # False，没事
print(has_path_sum_wrong(t2, 3))   # True  ← 错误！3 是"1->2"的和，但也可能被误认为"1->空"凑出
```

**正确写法：只有"同时是叶子且 target==0"才算。** 在空节点处返回 False（除非题目明确允许"任意节点结尾"，见后文 257 路径总和 II 的变体）。

## 返回所有符合条件的路径

**如果要求"返回所有路径"，就用列表收集，把当前节点值 append 进去，回退时 pop。**

```python
def path_sum_paths(root, target):
    ans = []
    def go(n, cur, rem):
        if n is None:
            return
        cur.append(n.val)
        rem -= n.val
        if n.left is None and n.right is None and rem == 0:
            ans.append(cur.copy())      # 必须 copy！
        go(n.left, cur, rem)
        go(n.right, cur, rem)
        cur.pop()                       # 回退
    go(root, [], target)
    return ans

print(path_sum_paths(build([5, 4, 8, 11, None, 13, 4, 7, 2]), 22))
# [[5, 4, 11, 2]]
```

**`cur.copy()` 是必须的。** 如果你写 `ans.append(cur)`，append 进去的是同一个列表对象的引用，后面 `cur.pop()` 会把它的内容也改掉，最终 ans 里全是空列表。

## 翻车现场：append 同一个列表引用，结果全错

```python
# WRONG：忘了 copy
def path_sum_paths_wrong(root, target):
    ans = []
    def go(n, cur, rem):
        if n is None:
            return
        cur.append(n.val)
        rem -= n.val
        if n.left is None and n.right is None and rem == 0:
            ans.append(cur)           # ← 同一个列表对象
        go(n.left, cur, rem)
        go(n.right, cur, rem)
        cur.pop()
    go(root, [], target)
    return ans

t = build([1, 2, 3])
print(path_sum_paths_wrong(t, 3))
# 实际得到 [[], []] 或类似内容，取决于遍历顺序
```

**append 的是引用，pop 改的是同一个对象。** 这是"回溯"类题最容易犯的错，Python 里尤其常见——因为 `list.append` 不会复制。

**固定写法：凡是"收集路径"的回溯，append 时用 `cur.copy()`（或 `cur[:]`）。**

## 任意节点结尾的路径和

**LeetCode 437（路径总和 III）放宽了要求：路径不必从根开始、不必到叶子结束，只要向下走就行。** 这时"传参"就不够用了，需要用两个递归：

```python
def path_sum_any(root, target):
    def from_node(n, rem):
        """以 n 为起点的所有向下路径中，和为 target 的有几条"""
        if n is None:
            return 0
        rem -= n.val
        return (1 if rem == 0 else 0) + from_node(n.left, rem) + from_node(n.right, rem)

    def dfs(n):
        """遍历每个节点，把它当作起点"""
        if n is None:
            return 0
        return from_node(n, target) + dfs(n.left) + dfs(n.right)

    return dfs(root)

print(path_sum_any(build([10, 5, -3, 3, 2, None, 11, 3, -2, None, 1]), 8))   # 3
```

**外层 `dfs` 枚举起点，内层 `from_node` 枚举从起点出发的路径。** 时间 O(n²)，在树形较歪时偏慢，进阶做法是用前缀和+哈希（第 29 课会讲）。

## 最大路径和：任意两点间

**LeetCode 124（二叉树中的最大路径和）要求"树上任意两点间路径的最大和"。** 路径可以不经过根，此时"返回值和更新全局答案"的套路又要上场。

```python
def max_path_sum(root):
    ans = [float('-inf')]
    def go(n):
        if n is None:
            return 0
        l = max(go(n.left), 0)     # 负数就不要了（不选这条支路）
        r = max(go(n.right), 0)
        ans[0] = max(ans[0], l + n.val + r)   # 经过当前节点的最大路径
        return n.val + max(l, r)              # 只能选一边往上走
    go(root)
    return ans[0]

print(max_path_sum(build([1, 2, 3])))            # 6  (1+2+3)
print(max_path_sum(build([-10, 9, 20, None, None, 15, 7])))  # 42  (15+20+7)
```

**`max(l, 0)` 是关键：子路径和为负就丢弃，相当于"不走这条支路"。** 这是"求最大和"题的标准技巧——负值只会拖累总和。

**返回值和全局更新用的是不同逻辑**：返回时"只能选一边往上接"（因为路径不能分叉），更新答案时"左右都取"（以当前节点为转折点）。

## 翻车现场：返回值也把左右都加进去，导致路径分叉

```python
# WRONG：返回时也把左右都加上，路径出现分叉
def max_path_sum_wrong(root):
    ans = [float('-inf')]
    def go(n):
        if n is None:
            return 0
        l = max(go(n.left), 0)
        r = max(go(n.right), 0)
        ans[0] = max(ans[0], l + n.val + r)
        return n.val + l + r          # ← 错误！返回了分叉路径
    go(root)
    return ans[0]
```

**路径在树里不能分叉**（一条路径是一条链）。往上返回时必须"选左或选右"，用 `max(l, r)`；只有"以当前节点为转折点、到此为止"的那条完整路径才把两边都算上。

## 小结

- 根到叶子路径：前序遍历 + `target -= root.val` 传参，到叶子检查 `target == 0`
- **叶子才是终点，空节点不是**；只在 `left/right 都为空 且 target==0` 时算成功
- 收集所有路径：回溯 `append + pop`，**append 时必须 `cur.copy()`**
- 任意节点结尾的路径（437）：外层枚举起点、内层枚举向下路径
- 任意两点路径和（124）：返回 `n.val + max(l, r)`，更新答案用 `l + n.val + r`；负数支路用 `max(.., 0)` 丢弃
