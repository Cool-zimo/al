# 递归解树的通法：把问题拆成"左子树 + 根 + 右子树"

> 树题看起来千变万化，其实解法都长一样：先想"左右子树各给我什么"，再想"我怎么用它们的答案"。这一课把这套思维固化成一个模板。

## 一句话概括：所有树递归都是"左右 + 根"

**树的递归解题，本质是把问题拆成三块：左子树的结果、右子树的结果、根节点自己的贡献。** 第 26 课里我们讲过递归三要素（终止条件、递推关系、返回值），放到树上就是：

1. **终止条件**：节点为 `None` 时返回什么？（几乎总是 0、0、空列表、True 之类）
2. **递推关系**：先递归处理左、右子树，拿到它们的答案。
3. **返回值**：把左右答案和根的贡献合并，返回给上一层。

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def build(vals):
    if not vals or vals[0] is None:
        return None
    nodes = [None if v is None else TreeNode(v) for v in vals]
    for i in range(len(nodes)):
        if nodes[i] is None:
            continue
        left, right = 2 * i + 1, 2 * i + 2
        if left < len(nodes) and nodes[left] is not None:
            nodes[i].left = nodes[left]
        if right < len(nodes) and nodes[right] is not None:
            nodes[i].right = nodes[right]
    return nodes[0]
```

**这个"左右 + 根"的模板，上一课的节点数、深度、直径都用过了。** 区别只在"合并方式"不同。

## 模板一：返回单一数值

**当问题是"整棵树的一个数"（节点数、深度、路径和）时，返回一个数。** 合并用算术运算。

```python
def tree_sum(root):
    """返回整棵树的节点值之和。"""
    if root is None:
        return 0
    return root.val + tree_sum(root.left) + tree_sum(root.right)

def max_depth(root):
    """返回树的最大深度。"""
    if root is None:
        return 0
    return 1 + max(max_depth(root.left), max_depth(root.right))

print(tree_sum(build([1, 2, 3, 4, 5])))   # 15
print(max_depth(build([1, 2, 3, 4, 5])))   # 3
```

**这两段代码的结构一模一样，只有"合并那一行"不同。** 记住这个模式：终止条件 → 递归左右 → 合并返回。

## 模板二：返回多个值

**当一个节点需要同时向上传递"多个信息"（比如"是否平衡"和"高度"），就用一个元组打包返回。** 这是上一课 `is_balanced_fast` 的思路，也是树题的高频套路。

```python
def balanced_and_height(root):
    if root is None:
        return True, 0             # 空树：平衡，高度 0
    lb, lh = balanced_and_height(root.left)
    if not lb:
        return False, -1           # 左子树已不平衡，短路
    rb, rh = balanced_and_height(root.right)
    if not rb or abs(lh - rh) > 1:
        return False, -1
    return True, 1 + max(lh, rh)
```

**返回元组让"一次遍历拿到多个信息"成为可能。** 凡是"既要判断又要算值"的题（平衡、BST 合法性验证、直径、路径和），都用这招。

## 模板三：返回列表（收集路径/节点）

**当问题要求"收集所有满足条件的路径/节点"时，返回值是一个列表。** 合并用 `+`。

```python
def collect_leaves(root):
    """收集所有叶子节点的值。"""
    if root is None:
        return []
    if root.left is None and root.right is None:
        return [root.val]                    # 叶子：返回包含自己的列表
    return collect_leaves(root.left) + collect_leaves(root.right)

print(collect_leaves(build([1, 2, 3, 4, 5, 6, 7])))   # [4, 5, 6, 7]
```

**叶子节点返回 `[root.val]`，内部节点返回左右列表相加。** 这就是"收集型"递归的标准写法。

## 翻车现场：None 和 0 混淆，空节点被当成"值为 0"

```python
# WRONG：把空节点当成"值存在但为 0"，合并时用 +
def tree_sum_wrong(root):
    # 忘了判断 None，直接取 root.val
    return root.val + tree_sum_wrong(root.left) + tree_sum_wrong(root.right)

print(tree_sum_wrong(build([1, 2, 3])))
```

报错：

```
AttributeError: 'NoneType' object has no attribute 'val'
```

**每一个树递归函数的第一行，必须是 `if root is None: return ...`。** 返回什么取决于问题：求和返回 0，计数返回 0，找路径返回 `[]`，判断返回 True/False。这个"基准值"必须和你的合并运算匹配（0 对应 `+`，`[]` 对应 `+`，True 对应 `and`）。

## 翻车现场：该返回布尔值却返回了数字

```python
# WRONG：递归函数有时返回 True/False，有时返回数字，上层用 and 连接时报错
def has_path_sum(root, target):
    if root is None:
        return 0                 # ← 空节点返回 0，但上层要用 and 判断
    if root.left is None and root.right is None:
        return root.val == target
    return has_path_sum(root.left, target - root.val) or \
           has_path_sum(root.right, target - root.val)

# 当某条路径中途遇到空节点时，会用 0 参与 `or` 判断：
# 0 在 Python 里是"假值"，会污染逻辑
```

**返回类型必须一致。** 要么全返回 bool，要么全返回数字。`or`/`and` 连接布尔值，`+` 连接数字，`+` 连接列表。混用会在某条路径上出错，而且错误信息往往很迷惑。

## 怎么想：从"问题要求什么"反推返回类型

**拿到一道树题，先回答三个问题：**

1. **我要返回什么？** 一个数、一个布尔、一个列表、还是一个元组？
2. **空节点返回什么基准值？** 求和 0、计数 0、路径 `[]`、判断 True/False。
3. **怎么用左右结果和根算出我的答案？**

```python
# 例子：判断树是否对称
def is_symmetric(root):
    def check(a, b):
        if a is None and b is None:
            return True
        if a is None or b is None:
            return False
        if a.val != b.val:
            return False
        return check(a.left, b.right) and check(a.right, b.left)
    if root is None:
        return True
    return check(root.left, root.right)

print(is_symmetric(build([1, 2, 2, 3, 4, 4, 3])))     # True
print(is_symmetric(build([1, 2, 2, None, 3, None, 3])))  # False
```

**对称的判断是"左子树的左 vs 右子树的右"——这正是"根的贡献"所在。** 这里 `check` 的返回类型是 bool，合并用 `and`。

## 镜像判断 vs 对称判断

**"判断两棵树是否完全相同"和"判断一棵树是否对称"是同一套路，只是比较方式不同。**

```python
def is_same_tree(a, b):
    if a is None and b is None:
        return True
    if a is None or b is None:
        return False
    if a.val != b.val:
        return False
    return is_same_tree(a.left, b.left) and is_same_tree(a.right, b.right)

t1 = build([1, 2, 3])
t2 = build([1, 2, 3])
t3 = build([1, 2, None, None, 3])
print(is_same_tree(t1, t2))   # True
print(is_same_tree(t1, t3))   # False
```

**`is_same_tree` 是"左比左、右比右"，`is_symmetric` 是"左比右、右比左"。** 区别仅在 `check` 里的两行递归参数顺序。

## 小结

- 树递归通法：**终止条件（返回基准值）→ 递归左右 → 合并返回**
- 三种返回类型：单一数值（`+`/`max`）、布尔值（`and`/`or`）、列表（`+`）
- **返回类型必须一致**，不能一会儿返回数字一会儿返回布尔
- 需要多个信息时，用元组打包（如 `(是否平衡, 高度)`），不平衡用 `-1` 短路
- 解题三问：返回什么？空节点返回什么？左右 + 根怎么合并？
- `is_same_tree` 是"左比左右比右"，`is_symmetric` 是"左比右右比左"
