# 实战：人流统计（多次区间叠加，一次还原）

> 这一课把差分数组用在一个真实场景：**统计每个时段的人流量**——多次区间叠加，最后统一还原。

## 问题场景

**商场有 n 个时段（编号 0~n-1）。每笔交易记录了一个顾客在 [start, end] 时段在场。求每个时段在场的总人数。**

```python
# n = 6 个时段
# 顾客 A：时段 [1, 3] 在场
# 顾客 B：时段 [2, 4] 在场
# 顾客 C：时段 [0, 5] 在场（全场都在）
# 求每个时段在场人数

intervals = [(1, 3), (2, 4), (0, 5)]
n = 6
# 答案：时段 0:1人, 时段1:2人, 时段2:3人, 时段3:3人, 时段4:2人, 时段5:1人
```

**这就是"区间覆盖计数"问题**——每个时段被多少个区间覆盖。

## 用差分数组解决

每来一个顾客 `[start, end]`，就对 `[start, end]` 加 1。所有顾客处理完后统一还原。

```python
def people_count(intervals, n):
    """intervals: [(start, end), ...]，n: 时段总数"""
    diff = [0] * (n + 1)

    for start, end in intervals:
        diff[start] += 1           # 从 start 开始，在场人数 +1
        if end + 1 < n:
            diff[end + 1] -= 1     # 从 end+1 开始，离场了，-1

    # 还原：前缀和
    result = [0] * n
    result[0] = diff[0]
    for i in range(1, n):
        result[i] = result[i - 1] + diff[i]

    return result

intervals = [(1, 3), (2, 4), (0, 5)]
print(people_count(intervals, 6))
# [1, 2, 3, 3, 2, 1]
```

## 手跑一遍

`intervals = [(1,3), (2,4), (0,5)]`，`n = 6`

```
初始 diff = [0, 0, 0, 0, 0, 0, 0]

顾客 A [1, 3]:
  diff[1] += 1 → diff[1] = 1
  diff[4] -= 1 → diff[4] = -1

顾客 B [2, 4]:
  diff[2] += 1 → diff[2] = 1
  diff[5] -= 1 → diff[5] = -1

顾客 C [0, 5]:
  diff[0] += 1 → diff[0] = 1
  end+1=6, 6<6 不成立 → 不操作

最终 diff = [1, 1, 1, 0, -1, -1, 0]

还原：
  result[0] = 1
  result[1] = 1 + 1 = 2
  result[2] = 2 + 1 = 3
  result[3] = 3 + 0 = 3
  result[4] = 3 + (-1) = 2
  result[5] = 2 + (-1) = 1

result = [1, 2, 3, 3, 2, 1] ✓
```

**时段 2 和 3 有 3 个人在场（A、B、C 都在），时段 0 和 5 只有 C 一个人在。**

## 时间复杂度

| 步骤 | 复杂度 |
|---|---|
| 处理 m 个顾客 | O(m) |
| 还原 n 个时段 | O(n) |
| **总计** | **O(m + n)** |

**对比朴素做法**（每个顾客遍历区间，O(mn)），差分快了几个数量级。

## 变体一：求峰值人数

如果只关心"最多有多少人同时在场"：

```python
def max_people(intervals, n):
    diff = [0] * (n + 1)
    for start, end in intervals:
        diff[start] += 1
        if end + 1 < n:
            diff[end + 1] -= 1
    # 求前缀和过程中的最大值
    cur = 0
    max_val = 0
    for i in range(n):
        cur += diff[i]
        max_val = max(max_val, cur)
    return max_val

print(max_people([(1,3), (2,4), (0,5)], 6))   # 3
```

**在还原的同时求最大值，不需要额外遍历。**

## 变体二：航班预订统计

**题目**：有 n 个航班，第 i 次预订 `bookings[i] = [first, last, seats]`，表示从航班 first 到 last 预订了 seats 个座位。返回每个航班的最终预订座位数。

```python
def corp_flight_bookings(bookings, n):
    diff = [0] * (n + 1)
    for first, last, seats in bookings:
        diff[first - 1] += seats        # 题目是 1-indexed，转成 0-indexed
        if last < n:
            diff[last] -= seats
    # 还原
    result = [0] * n
    result[0] = diff[0]
    for i in range(1, n):
        result[i] = result[i - 1] + diff[i]
    return result

bookings = [[1, 2, 10], [2, 3, 20], [2, 5, 25]]
n = 5
print(corp_flight_bookings(bookings, n))
# [10, 55, 45, 25, 25]
```

**注意**：题目给的是 1-indexed（航班编号从 1 开始），要转成 0-indexed：

- `first - 1` 是 0-indexed 的起点
- `last` 是 0-indexed 的终点后一位（因为 last 那个航班也要加）

## 变体三：最少要开的会议室数量

**题目**：给定多个会议的起止时间，求同一时刻最多有多少个会议同时进行。

这和"人流统计"是同一个问题！把每个会议的开始时间 +1、结束时间 -1（差分），然后求前缀和的最大值。

```python
def min_meeting_rooms(intervals):
    """intervals: [(start, end), ...]"""
    if not intervals:
        return 0
    # 找到最大时间点
    max_time = max(end for _, end in intervals)
    diff = [0] * (max_time + 1)
    for start, end in intervals:
        diff[start] += 1
        diff[end] -= 1       # 注意这里 end 本身不加，因为会议在 end 时刻结束
    # 求前缀和的最大值
    cur = 0
    max_rooms = 0
    for i in range(max_time + 1):
        cur += diff[i]
        max_rooms = max(max_rooms, cur)
    return max_rooms

print(min_meeting_rooms([(0, 30), (5, 10), (15, 20)]))   # 2
```

## 常见错误

### 错误一：区间端点理解错误

不同题目的区间定义不同：

| 题目 | 区间含义 | 差分操作 |
|---|---|---|
| 人流统计 | [start, end] 在场 | diff[start]+=1, diff[end+1]-=1 |
| 航班预订 | [first, last] 包含两端 | diff[first-1]+=seats, diff[last]-=seats |
| 会议室 | [start, end) 左闭右开 | diff[start]+=1, diff[end]-=1 |

**关键是理解"end 时刻是否包含在内"。**

### 错误二：忘记处理 end+1 == n 的情况

```python
# 错误：没有判断 end+1 < n
diff[end + 1] -= 1    # end=n-1 时 end+1=n，越界！
```

**必须加判断**：`if end + 1 < n`。

## 小结

- 差分数组适合"区间覆盖计数"问题
- 核心：每个区间 `[s, e]` 对应 `diff[s]+=1, diff[e+1]-=1`
- 还原后就是每个位置的覆盖次数
- 在还原过程中可以同时求最大值（峰值）
- 注意不同题目的区间端点定义（闭区间 vs 左闭右开）

**第 3 章到此结束。** 接下来第 4 章讲**二分查找**——利用单调性在 O(log n) 时间里找到答案。
