# 字符串双指针：反转、翻转单词、压缩

> 数组的双指针套路，字符串同样能用。这一课把三个经典题讲透：**反转、翻转单词、压缩**。

## 字符串不可变怎么办

**上一课讲过：字符串不可变，不能直接 `s[i] = s[j]`。**

**解法：先转成列表，用双指针操作，最后 join 回来。**

```python
# 反转字符串
def reverse_string(s):
    chars = list(s)          # 转列表
    left, right = 0, len(chars) - 1
    while left < right:
        chars[left], chars[right] = chars[right], chars[left]
        left += 1
        right -= 1
    return "".join(chars)    # 拼回来

print(reverse_string("hello"))    # "olleh"
print(reverse_string("上海"))     # "海上上"  → "海上" ✓
```

**时间 O(n)，空间 O(n)**（列表的开销）。

## 实战一：反转字符串

```python
# 原地反转（用列表）
def reverse_in_place(chars):
    left, right = 0, len(chars) - 1
    while left < right:
        chars[left], chars[right] = chars[right], chars[left]
        left += 1
        right -= 1
    return chars

chars = ["h", "e", "l", "l", "o"]
reverse_in_place(chars)
print("".join(chars))    # "olleh"
```

**注意**：Python 里传列表才能"原地"修改。传字符串做不到。

## 实战二：翻转字符串里的单词

**题目**：把字符串里的单词反转顺序，但单词内部不变。

```python
s = "the sky is blue"
# 反转后是 "blue is sky the"
```

**思路**：先按空格切分，再反转列表，最后用空格 join。

```python
def reverse_words(s):
    words = s.split()           # 按空格切分（自动处理多余空格）
    words.reverse()            # 反转列表
    return " ".join(words)     # 用空格拼接

print(reverse_words("the sky is blue"))        # "blue is sky the"
print(reverse_words("  hello   world  "))      # "world hello"（多余空格被去掉）
```

**`split()` 不传参数时，会自动按任意数量的空白字符切分并去掉首尾空白。**

### 不用 split 的手动实现

如果想手动实现（面试中更显功力）：

```python
def reverse_words_manual(s):
    # 先反转整个字符串
    chars = list(s)
    chars.reverse()
    # 再反转每个单词
    result = []
    i = 0
    while i < len(chars):
        if chars[i] != ' ':
            # 找到一个单词
            j = i
            while j < len(chars) and chars[j] != ' ':
                j += 1
            # chars[i:j] 是一个单词，反转它
            word = chars[i:j]
            word.reverse()
            result.extend(word)
            i = j
        else:
            i += 1
    return "".join(result)

print(reverse_words_manual("the sky is blue"))
# 先整体反转 "eulb si yks eht"
# 再反转每个单词 "blue is sky the"
```

## 实战三：压缩字符串

**题目**：把连续相同的字符压缩成"字符+出现次数"的形式。

```python
chars = ["a", "a", "b", "b", "c", "c", "c"]
# 压缩后是 ["a", "2", "b", "2", "c", "3"]
```

**用双指针**：`i` 遍历，`j` 找连续相同字符的结束位置。

```python
def compress(chars):
    if not chars:
        return 0
    
    result = []
    i = 0
    while i < len(chars):
        ch = chars[i]
        j = i
        # 找到连续相同字符的末尾
        while j < len(chars) and chars[j] == ch:
            j += 1
        count = j - i
        result.append(ch)
        if count > 1:
            result.extend(list(str(count)))   # 数字可能有多位
        i = j

    # 原地修改 chars（按题目要求）
    for k in range(len(result)):
        chars[k] = result[k]
    
    return len(result)

chars = ["a", "a", "b", "b", "c", "c", "c"]
length = compress(chars)
print(chars[:length])    # ['a', '2', 'b', '2', 'c', '3']
```

**手跑一遍** `["a","a","b","b","c","c","c"]`：

```
i=0: ch='a', j 走到 2（连续 a 结束）, count=2
  result = ['a', '2']

i=2: ch='b', j 走到 4, count=2
  result = ['a', '2', 'b', '2']

i=4: ch='c', j 走到 7, count=3
  result = ['a', '2', 'b', '2', 'c', '3']

结束，返回 6
```

## 对比三种双指针用法

| 题目 | left/right 含义 | 操作 |
|---|---|---|
| 反转字符串 | 对撞：两头夹 | 交换 |
| 翻转单词 | 先整体反转，再逐词反转 | 分段处理 |
| 压缩字符串 | i 遍历，j 探路 | 计数+拼接 |

**虽然都是"两个位置变量"，但用法完全不同。**

## 常见错误

### 错误一：直接对字符串用下标赋值

```python
s = "hello"
s[0] = "H"    # TypeError: 'str' object does not support item assignment
```

**必须转成列表操作。**

### 错误二：压缩时数字只写了第一位

```python
# 错误：count 可能有多位
count = j - i
result.append(ch)
result.append(str(count))    # count=12 时只写了 '12'... 等等这个是对的

# 真正错误的情况：
result.append(count)    # 错误！应该 append str(count)
```

**`count` 是数字，要转成字符串才能 append 进字符列表。**

### 错误三：忘记处理 count == 1 的情况

```python
# 错误：count=1 时也写了数字
if count >= 1:          # 应该是 > 1
    result.extend(list(str(count)))
# "a" 压缩后变成 "a1"，但题目通常要求 "a"
```

**单个字符不写数量**（或者题目要求写也行，看具体要求）。

## 双指针在字符串上的优势

**和数组一样，双指针能把 O(n²) 降到 O(n)：**

| 问题 | 暴力 | 双指针 |
|---|---|---|
| 反转 | 用切片 O(n) 但不原地 | 原地 O(n) |
| 翻转单词 | 多重循环 | 一次遍历 |
| 压缩 | 嵌套循环 | 一次遍历 |

**关键是"只遍历一次"——把 O(n) 的空间和时间都用满。**

## 小结

- 字符串不可变 → **先转列表，操作完 join 回来**
- 反转：对撞指针交换
- 翻转单词：整体反转 + 逐词反转（或 split + reverse + join）
- 压缩：i 遍历 + j 探路计数
- 注意：压缩时数字是多位要转字符串；count==1 不写数量
