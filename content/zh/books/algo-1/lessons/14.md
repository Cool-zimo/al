# 差分数组：区间加减从 O(n) 到 O(1)，最后还原

> 前缀和回答"区间求和"。这一课讲它的逆运算：**差分数组**——把"区间加减"从 O(n) 降到 O(1)。

## 问题场景

**题目**：有一个数组，反复对区间 [l, r] 的所有元素**加上一个值 v**，最后输出最终数组。

```python
# 初始数组
nums = [0, 0, 0, 0, 0, 0]
# 操作 1：对 [1, 3] 加 2 → [0, 2, 2, 2, 0, 0]
# 操作 2：对 [2, 4] 加 3 → [0, 2, 5, 5, 3, 0]
# 操作 3：对 [0, 5] 加 1 → [1, 3, 6, 6, 4, 1]
```

朴素做法：每次操作遍历 [l, r] 加 v，**每次 O(n)**。如果 m 次操作，总复杂度 O(mn)。

**用差分数组：每次操作 O(1)，最后还原 O(n)，总复杂度 O(m + n)。**

## 差分的核心思想

**定义差分数组** `diff`：

```
diff[i] = nums[i] - nums[i-1]   （规定 diff[0] = nums[0]）
```

**关键性质**：如果对 `nums[l..r]` 都加上 v，那么差分只有两个位置变化：

```
diff[l] += v          # 从 l 开始"多了 v 的差值"
diff[r+1] -= v        # 从 r+1 开始"差值恢复正常"
```

**其他位置的差分不变！**

## 为什么只有两个位置变化

看一个例子：`nums = [1, 2, 3, 4, 5]`

```
diff[0] = 1 - 0 = 1
diff[1] = 2 - 1 = 1
diff[2] = 3 - 2 = 1
diff[3] = 4 - 3 = 1
diff[4] = 5 - 4 = 1
diff[5] = 0 - 5 = -5   （多开一位，diff[5] = 0 - nums[4]）
```

对 [1, 3] 都加 2：

```
nums = [1, 4, 5, 6, 5]
diff[0] = 1 - 0 = 1        不变
diff[1] = 4 - 1 = 3        +2 ← l=1
diff[2] = 5 - 4 = 1        不变
diff[3] = 6 - 5 = 1        不变
diff[4] = 5 - 6 = -1       -2 ← r+1=4
diff[5] = 0 - 5 = -5       不变
```

**只有 diff[1] 和 diff[4] 变了！**

## 代码实现

```python
def range_add(nums, l, r, v):
    """用差分数组对 [l, r] 加 v，返回最终数组"""
    n = len(nums)
    diff = [0] * (n + 1)    # 多开一位，防止 r+1 越界

    # 先把 nums 转成差分数组
    diff[0] = nums[0]
    for i in range(1, n):
        diff[i] = nums[i] - nums[i - 1]
    # diff[n] 已经是 0

    # 执行区间加 v
    diff[l] += v
    if r + 1 < n:
        diff[r + 1] -= v

    # 从差分还原数组
    result = [0] * n
    result[0] = diff[0]
    for i in range(1, n):
        result[i] = result[i - 1] + diff[i]

    return result

print(range_add([0,0,0,0,0,0], 1, 3, 2))
# [0, 2, 2, 2, 0, 0]
```

## 优化：直接在原数组上操作

实际上我们不需要"先转差分再还原"——可以直接用 diff 数组记录所有操作，最后统一还原。

```python
def range_add_optimized(nums, operations):
    """operations 是 [(l, r, v), ...] 的列表"""
    n = len(nums)
    diff = [0] * (n + 1)

    # 先转成差分
    diff[0] = nums[0]
    for i in range(1, n):
        diff[i] = nums[i] - nums[i - 1]

    # 执行所有区间加操作（每次 O(1)）
    for l, r, v in operations:
        diff[l] += v
        if r + 1 < n:
            diff[r + 1] -= v

    # 统一还原（O(n)）
    result = [0] * n
    result[0] = diff[0]
    for i in range(1, n):
        result[i] = result[i - 1] + diff[i]

    return result

nums = [0, 0, 0, 0, 0, 0]
ops = [(1, 3, 2), (2, 4, 3), (0, 5, 1)]
print(range_add_optimized(nums, ops))
# [1, 3, 6, 6, 4, 1]
```

## 复杂度对比

| 方案 | 每次操作 | 还原 | 总复杂度 |
|---|---|---|---|
| 朴素 | O(n) | — | O(mn) |
| 差分 | O(1) | O(n) | O(m + n) |

当 m=10 万、n=1000 时：

```
朴素: 10万 × 1000 = 1 亿次
差分: 10万 + 1000 = 10.1 万次
差距约 10000 倍
```

## 手跑一遍完整流程

`nums = [0,0,0,0,0,0]`，操作：`(1,3,2), (2,4,3), (0,5,1)`

```
初始 nums = [0, 0, 0, 0, 0, 0]
diff = [0, 0, 0, 0, 0, 0, 0]   （长度 7）

操作 (1,3,2):
  diff[1] += 2 → diff[1] = 2
  diff[4] -= 2 → diff[4] = -2
  diff = [0, 2, 0, 0, -2, 0, 0]

操作 (2,4,3):
  diff[2] += 3 → diff[2] = 3
  diff[5] -= 3 → diff[5] = -3
  diff = [0, 2, 3, 0, -2, -3, 0]

操作 (0,5,1):
  diff[0] += 1 → diff[0] = 1
  r+1=6, n=6, 6<6 不成立 → 不操作 diff[6]
  diff = [1, 2, 3, 0, -2, -3, 0]

还原：
  result[0] = diff[0] = 1
  result[1] = result[0] + diff[1] = 1 + 2 = 3
  result[2] = result[1] + diff[2] = 3 + 3 = 6
  result[3] = result[2] + diff[3] = 6 + 0 = 6
  result[4] = result[3] + diff[4] = 6 + (-2) = 4
  result[5] = result[4] + diff[5] = 4 + (-3) = 1

result = [1, 3, 6, 6, 4, 1] ✓
```

## 常见错误

### 错误一：忘记 r+1 < n 的判断

```python
# 错误：r+1 可能等于 n，越界
def range_add_buggy(nums, l, r, v):
    n = len(nums)
    diff = [0] * n          # 长度 n，不是 n+1
    ...
    diff[r + 1] -= v        # r=n-1 时 r+1=n，越界！
```

**diff 数组要多开一位**（长度 n+1），并且只在 `r+1 < n` 时才减。

### 错误二：还原时忘记用前缀和

```python
# 错误：直接把 diff 当结果返回
return diff    # 错！diff 是差分数组，不是原数组
```

**差分还原 = 前缀和**：`result[i] = result[i-1] + diff[i]`。

### 错误三：混淆"区间加减"和"区间求和"

| 操作 | 用什么 |
|---|---|
| 区间求和（查询） | 前缀和 |
| 区间加减（修改） | 差分数组 |
| 既要查询又要修改 | 树状数组 / 线段树 |

**前缀和和差分是互逆的**：前缀和加速"区间求和"，差分加速"区间修改"。

## 差分的更多用途

### 1. 航班预订统计

**题目**：有 n 次预订，每次预订 [first, last] 个座位的 count 个位置，求每趟航班的最终座位数。

这就是差分的经典应用——每次预订是一次区间加。

### 2. 涂油漆 / 区间染色

对区间 [l, r] 加 1（表示涂了一次），最后看每个位置被涂了几次。

### 3. 统计"被覆盖次数"

给定多个区间，求每个点被多少个区间覆盖。

```python
def count_coverage(intervals, n):
    """intervals 是 [(l,r), ...]，求每个点被覆盖的次数"""
    diff = [0] * (n + 1)
    for l, r in intervals:
        diff[l] += 1
        if r + 1 < n:
            diff[r + 1] -= 1
    # 还原
    cov = [0] * n
    cov[0] = diff[0]
    for i in range(1, n):
        cov[i] = cov[i - 1] + diff[i]
    return cov

print(count_coverage([(1,3), (2,4), (0,5)], 6))
# [1, 2, 3, 3, 2, 1]
```

## 小结

- 差分是前缀和的逆运算：加速"区间修改"
- 对 [l, r] 加 v：`diff[l] += v`，`diff[r+1] -= v`（仅两个操作 O(1)）
- diff 数组长度 n+1，r+1 == n 时不减
- 还原数组 = 对 diff 求前缀和
- 总复杂度 O(m + n)，远好于朴素的 O(mn)

```quiz
options:
- 因为 l 和 r 是随机选的
- 因为区间加 v 只影响"从 l 开始的增量"和"从 r+1 开始的恢复"，差分只需改这两个位置
- 因为 Python 下标从 0 开始
- 为了节省空间
answer: 1
explain: 差分 diff[i] = nums[i] - nums[i-1]。区间加 v 时，l 处产生了 v 的"阶跃"（diff[l]+=v），r+1 处阶跃消失（diff[r+1]-=v）。中间所有位置的差分不变 —— 所以只需 O(1) 两次操作，还原时前缀和自动把 v 传播到整个区间。
```
