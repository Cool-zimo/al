# 回文的三种判定：中心扩展、双指针、反转比较

> 回文是面试高频题。这一课讲三种判定方法，并分析各自的优劣。

## 什么是回文

**回文**：正读反读完全一样的字符串。

```python
"aba"      # 回文
"abba"     # 回文
"上海自来水来自海上"   # 回文
"hello"    # 不是回文
```

## 方法一：双指针（对撞）

**从两端往中间比，任何一对不相等就不是回文。**

```python
def is_palindrome_two_pointers(s):
    left, right = 0, len(s) - 1
    while left < right:
        if s[left] != s[right]:
            return False
        left += 1
        right -= 1
    return True

print(is_palindrome_two_pointers("aba"))          # True
print(is_palindrome_two_pointers("abba"))         # True
print(is_palindrome_two_pointers("hello"))        # False
```

**时间 O(n)，空间 O(1)**——最优解。

**边界情况**：

| 输入 | left | right | 结果 | 原因 |
|---|---|---|---|---|
| `""` | 0 | -1 | True | 循环不执行，直接返回 True |
| `"a"` | 0 | 0 | True | `left < right` 不成立 |
| `"aba"` | 0→1, 2→1 | — | True | 中间 b 自己比，跳过 |

**空字符串和单字符都是回文**（没有不相等的对）。

## 方法二：反转比较

**回文反转后和原串相同。**

```python
def is_palindrome_reverse(s):
    return s == s[::-1]

print(is_palindrome_reverse("aba"))     # True
print(is_palindrome_reverse("hello"))  # False
```

**时间 O(n)，空间 O(n)**（切片新建了字符串）。

**优点**：一行搞定，代码最短。
**缺点**：占 O(n) 空间。

## 方法三：中心扩展

**以每个位置（和每两个位置之间）为中心，向两边扩展。**

这个方法主要用于"找最长回文子串"（下一课讲），但也可以用来判定。

```python
def is_palindrome_expand(s):
    n = len(s)
    for center in range(n):
        # 以 center 为中心的奇数长度回文
        left = right = center
        while left >= 0 and right < n and s[left] == s[right]:
            left -= 1
            right += 1
    # 这里只展示了扩展过程，判定还需要额外逻辑
    ...
```

**方法三单独用来"判定"不如双指针直接**，它的价值在于"找最长回文"。下一课会详细讲。

## 三种方法对比

| 方法 | 时间 | 空间 | 推荐度 |
|---|---|---|---|
| 双指针 | O(n) | O(1) | ⭐⭐⭐ 最推荐 |
| 反转比较 | O(n) | O(n) | ⭐⭐ 简洁但占空间 |
| 中心扩展 | O(n) | O(1) | ⭐ 适合找最长回文 |

**面试推荐双指针**——展示了"原地操作"的能力。

## 实战：验证回文串（忽略大小写和非字母数字）

**题目**：判定一个字符串是否是回文，**忽略大小写**，只保留字母和数字字符。

```python
"A man, a plan, a canal: Panama"
# 清理后："amanaplanacanalpanama" → 回文

"race a car"
# 清理后："raceacar" → 不是回文
```

```python
def is_palindrome_valid(s):
    # 先清理：只保留字母和数字，转小写
    cleaned = ""
    for ch in s:
        if ch.isalnum():           # isalnum: 是字母或数字
            cleaned += ch.lower()  # 转小写

    # 双指针判定
    left, right = 0, len(cleaned) - 1
    while left < right:
        if cleaned[left] != cleaned[right]:
            return False
        left += 1
        right -= 1
    return True

print(is_palindrome_valid("A man, a plan, a canal: Panama"))   # True
print(is_palindrome_valid("race a car"))                       # False
```

## 常见错误

### 错误一：忘记处理空字符串

```python
def is_palindrome_buggy(s):
    left, right = 0, len(s) - 1
    while left < right:       # 空字符串时 len(s)-1 = -1
        ...                   # left=0, right=-1, 循环不执行
    return True               # 空字符串返回 True ✓ 这是正确的
```

**空字符串返回 True 是正确的**（没有不相等的对）。但要注意 `len(s)-1 = -1` 时 `0 < -1` 是 False，循环不执行。

### 错误二：反转比较时用了 str.reverse()

```python
# 错误：str 没有 reverse 方法
s.reverse()         # AttributeError!

# 正确
reversed_s = s[::-1]
```

**字符串没有 `reverse()` 方法**，列表才有。用切片 `[::-1]`。

### 错误三：中心扩展的边界判断漏了

```python
# 错误：少了 left >= 0 或 right < n 的检查
while s[left] == s[right]:    # 可能越界！
    left -= 1
    right += 1
```

**扩展时必须检查 `left >= 0` 和 `right < n`。**

## 中心扩展的真正用途

**中心扩展的价值不在"判定回文"，而在"找最长回文子串"。**

思路：以每个位置 i 为中心，向两边扩展，记录能扩展的最大长度。

```python
def longest_palindrome(s):
    if not s:
        return ""
    
    def expand(left, right):
        while left >= 0 and right < len(s) and s[left] == s[right]:
            left -= 1
            right += 1
        return right - left - 1    # 回文长度
    
    start, max_len = 0, 1
    for i in range(len(s)):
        # 奇数长度：以 i 为中心
        len1 = expand(i, i)
        # 偶数长度：以 i 和 i+1 之间为中心
        len2 = expand(i, i)
        curr_max = max(len1, len2)
        if curr_max > max_len:
            max_len = curr_max
            start = i - (curr_max - 1) // 2
    
    return s[start:start + max_len]

print(longest_palindrome("babad"))    # "bab" 或 "aba"
print(longest_palindrome("cbbd"))     # "bb"
```

## 小结

- 三种判定方法：双指针（最优）、反转比较（简洁）、中心扩展（适合找最长）
- 双指针：O(n) 时间 O(1) 空间，面试推荐
- 反转比较：`s == s[::-1]`，O(n) 空间
- 验证回文串：先清理（isalnum + lower），再双指针
- 中心扩展的真正用途是"找最长回文子串"
