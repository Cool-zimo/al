# 二分答案：把"求最优解"变成"判定可行"

> 前两课二分的是"位置"。这一课升级：**二分答案**——如果答案本身有单调性，也可以二分。

## 核心思想

**很多最优化问题有这样的性质**：

- 如果"答案是 x"可行
- 那么"答案是 x+1"（更大的答案）一定也可行

**这就是单调性！可以用二分来找临界值。**

典型场景：
- 木头切割：切出 k 段，每段最长能多长？
- 吃巧克力：k 个人分，每人最多能分多少？
- 最小化最大值：把数组分成 m 段，每段和的最大值最小是多少？

## 木头切割问题

**题目**：有 n 根木头，长度分别为 `lengths`。要切成 k 段**等长**的小木头，求每段的最大可能长度。

```python
lengths = [232, 124, 456, 234]
k = 7
# 能切成 7 段，每段最长多长？
# 232 -> 2 段 116
# 124 -> 1 段 116（余 8）
# 456 -> 3 段 116（余 108）
# 234 -> 2 段 116（余 2）
# 总共 2+1+3+2 = 8 段 >= 7，可行！
# 试试 117：232->1(余115), 124->1(余7), 456->3(余105), 234->1(余117) = 6 < 7，不行
# 答案是 116
```

**暴力**：从 1 试到 max(lengths)，O(max × n)。太慢。

**二分答案**：答案范围是 [1, max(lengths)]。对每个候选值 `mid`，检查能否切出 k 段。

```python
def can_cut(lengths, k, L):
    """每段长 L，能否切出 k 段"""
    count = 0
    for length in lengths:
        count += length // L
    return count >= k

def max_cut_length(lengths, k):
    left, right = 1, max(lengths)
    ans = 0
    while left <= right:
        mid = (left + right) // 2
        if can_cut(lengths, k, mid):
            ans = mid              # 可行，记录答案
            left = mid + 1         # 试试更大的
        else:
            right = mid - 1        # 不可行，试试更小的
    return ans

print(max_cut_length([232, 124, 456, 234], 7))   # 116
```

## 为什么答案是单调的

**关键观察**：

- 如果每段切 100 能切出 7 段
- 那每段切 50 一定能切出 **更多** 段（7 段以上）

**切得越短，段数越多。** 这就是单调性。

```
段长:  1   50  100  116  117  200
段数:  10+ 8+   7    8    6    4

找最大的段长，使得段数 >= 7
答案是 116
```

## 二分答案的通用模板

```python
def binary_search_answer(check_func, left, right):
    """
    check_func(x) 返回 True 表示答案 >= x 可行
    找最大的可行值
    """
    ans = left    # 最小可能值
    while left <= right:
        mid = (left + right) // 2
        if check_func(mid):
            ans = mid           # 记录
            left = mid + 1      # 找更大的
        else:
            right = mid - 1     # 找更小的
    return ans
```

**三个要素**：

1. **搜索范围**：答案可能的最小值和最大值
2. **判定函数**：`check(x)` 判断答案 x 是否可行
3. **单调性**：x 可行时 x-1 也一定可行（或反过来）

## 常见错误

### 错误一：check 函数的逻辑反了

```python
def can_cut_buggy(lengths, k, L):
    count = sum(length // L for length in lengths)
    return count <= k   # 错了！应该是 >= k
```

**要的是"能切出至少 k 段"，不是"最多 k 段"。**

### 错误二：ans 的初始值

```python
ans = 0    # 如果所有值都不可行，返回 0 可能不是正确语义
# 应该用 left（最小值）作为初始值
ans = left
```

**或者处理"完全切不出来"的情况。**

### 错误三：搜索范围搞错

```python
left, right = 0, max(lengths)   # left=0 时 count = sum(l//0) 会 ZeroDivisionError!
```

**段长不能为 0，left 从 1 开始。**

## 什么时候用二分答案

**判断标准**：能否把问题改写成"判定可行性"？

| 原问题 | 判定版本 | 单调方向 |
|---|---|---|
| 最大段长 | 段长 L 时能切出 k 段吗 | 段长越小，段数越多 |
| 最小最大值 | 每段和不超过 M 时能分 m 段吗 | M 越大，越容易分 |
| 最快速度完成 | 速度 V 时能在 T 时间内完成吗 | 速度越快，越容易 |

**如果有单调性，就能二分答案。**

## 小结

- 二分答案：二分的是**答案本身**，不是数组下标
- 三要素：搜索范围、判定函数、单调性
- 木头切割：段长越小段数越多，找最大可行段长
- `can_cut` 判定函数 O(n)，二分 O(log max_len)，总 O(n log max_len)
- 适用条件：答案有单调性，能写出判定函数
