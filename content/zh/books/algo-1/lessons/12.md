# 一维前缀和：构造、查询、为什么留一个前导 0

> 上一课我们知道了前缀能加速区间查询。这一课把细节全部补齐：**怎么构造、怎么查询、怎么处理边界**。

## 完整构造过程

**给定数组 `nums`，构造前缀和数组 `prefix`**：

```python
nums = [3, 1, 4, 1, 5, 9, 2, 6]
```

**构造公式**：`prefix[i+1] = prefix[i] + nums[i]`，初始 `prefix[0] = 0`

```python
def build_prefix(nums):
    n = len(nums)
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i + 1] = prefix[i] + nums[i]
    return prefix

prefix = build_prefix([3, 1, 4, 1, 5, 9, 2, 6])
print(prefix)
# [0, 3, 4, 8, 9, 14, 23, 25, 31]
```

**手算验证**：

```
prefix[0] = 0
prefix[1] = 0 + 3 = 3
prefix[2] = 3 + 1 = 4
prefix[3] = 4 + 4 = 8
prefix[4] = 8 + 1 = 9
prefix[5] = 9 + 5 = 14
prefix[6] = 14 + 9 = 23
prefix[7] = 23 + 2 = 25
prefix[8] = 25 + 6 = 31
```

**规律**：`prefix[i]` 就是 `nums[0..i-1]` 的所有元素之和。

## 查询公式的推导

**目标**：求 `nums[l..r]` 的和（闭区间，包含 l 和 r）。

```
prefix[r+1] = nums[0] + nums[1] + ... + nums[l-1] + nums[l] + ... + nums[r]
prefix[l]   = nums[0] + nums[1] + ... + nums[l-1]
```

两式相减：

```
prefix[r+1] - prefix[l] = nums[l] + nums[l+1] + ... + nums[r]
```

**这就是区间 [l, r] 的和。**

```python
def query_sum(prefix, l, r):
    return prefix[r + 1] - prefix[l]

prefix = [0, 3, 4, 8, 9, 14, 23, 25, 31]
print(query_sum(prefix, 2, 5))   # 4+1+5+9 = 19 → prefix[6]-prefix[2] = 23-4 = 19 ✓
print(query_sum(prefix, 0, 0))   # 3 → prefix[1]-prefix[0] = 3-0 = 3 ✓
print(query_sum(prefix, 7, 7))   # 6 → prefix[8]-prefix[7] = 31-25 = 6 ✓
```

## 边界情况完整处理

### 情况一：l == 0

```python
query_sum(prefix, 0, 3) = prefix[4] - prefix[0] = 9 - 0 = 9
# nums[0..3] = 3+1+4+1 = 9 ✓
```

`prefix[0] = 0` 保证了正确性。

### 情况二：l == r（单元素区间）

```python
query_sum(prefix, 5, 5) = prefix[6] - prefix[5] = 23 - 14 = 9
# nums[5] = 9 ✓
```

### 情况三：l == 0 且 r == n-1（整个数组）

```python
query_sum(prefix, 0, n-1) = prefix[n] - prefix[0] = prefix[n] - 0
# 就是所有元素的和 ✓
```

**这就是为什么 prefix 要开 n+1 的长度**——`prefix[n]` 必须有位置存。

## 常见错误

### 错误一：prefix 长度开成 n 而不是 n+1

```python
# 错误：长度不够
def build_prefix_buggy(nums):
    n = len(nums)
    prefix = [0] * n          # 应该是 n+1！
    for i in range(n):
        prefix[i + 1] = prefix[i] + nums[i]   # i=n-1 时 prefix[n] 越界！
    return prefix
```

**IndexError: list assignment index out of range** —— `i=n-1` 时 `prefix[i+1]` 访问 `prefix[n]`，但数组只有 `n` 个元素（下标 0~n-1）。

### 错误二：查询时写成 prefix[r] - prefix[l-1]

这是另一种常见写法（竞赛常用），但容易在 `l=0` 时访问 `prefix[-1]`。

```python
# 另一种写法：prefix 下标从 1 开始存
prefix = [0] + [0]*n
for i in range(n):
    prefix[i+1] = prefix[i] + nums[i]
# 查询 [l, r] = prefix[r] - prefix[l-1]
# l=0 时访问 prefix[-1]，是最后一个元素！错误！
```

**如果要写 `prefix[r] - prefix[l-1]`，必须特判 l==0**：

```python
def query_sum_v2(prefix, l, r):
    left_val = prefix[l - 1] if l > 0 else 0
    return prefix[r] - left_val
```

**推荐写法：`prefix[r+1] - prefix[l]`，天然不需要特判。**

### 错误三：忘记初始化 prefix[0] = 0

```python
prefix = [0] * (n + 1)   # 全是 0，OK
# 如果写成：
prefix = [0] + [0]*n     # 也是全 0，OK
# 但如果：
prefix = []              # 空列表
prefix.append(0)         # OK，prefix[0]=0
for i in range(n):
    prefix.append(prefix[-1] + nums[i])   # 这也是对的！
```

三种写法都行，只要保证 `prefix[0]=0` 即可。

## 前缀和的高级用法

### 1. 前缀和 + 哈希表：求和为 k 的子数组个数

**题目**：统计有多少个子数组的和等于 k。

思路：用哈希表记录"前缀和出现次数"。如果 `prefix[j] - prefix[i] = k`，说明 `nums[i..j-1]` 的和是 k。

```python
def subarray_sum(nums, k):
    from collections import defaultdict
    cnt = defaultdict(int)
    cnt[0] = 1          # 空前缀和为 0
    prefix = 0
    ans = 0
    for x in nums:
        prefix += x
        ans += cnt[prefix - k]   # 有多少个之前的前缀和等于 prefix-k
        cnt[prefix] += 1
    return ans

print(subarray_sum([1, 1, 1], 2))   # 2: [1,1] 和 [1,1] 两个
```

### 2. 前缀和判断子数组和是否被 k 整除

如果 `prefix[j] % k == prefix[i] % k`，则 `nums[i..j-1]` 的和能被 k 整除。

## 复杂度再确认

| 操作 | 复杂度 | 说明 |
|---|---|---|
| 构造前缀和 | O(n) | 一次遍历 |
| 单次查询 | O(1) | 两次访问 + 一次减法 |
| 空间 | O(n) | 多开一个数组 |

**如果查询次数 m 远大于 n，前缀和是唯一合理的选择。**

## 小结

- `prefix[i]` = `nums[0..i-1]` 的和，`prefix[0] = 0`
- 构造：`prefix[i+1] = prefix[i] + nums[i]`，长度 n+1
- 查询 [l, r]：`prefix[r+1] - prefix[l]`，O(1)
- **推荐 `prefix[r+1]-prefix[l]` 写法**，天然不需要特判 l==0
- 进阶：前缀和 + 哈希表可以做"子数组和等于 k"等问题
