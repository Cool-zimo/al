# 对撞指针：左右夹逼，反转数组与回文判断

> 上一课我们认识了双指针的基本形态。这一课把它用透：**从两端向中间逼近**，一次扫描搞定反转和回文。

## 对撞指针的完整套路

**定义**：两个指针 `left` 和 `right` 分别从序列的**左端**和**右端**出发，每次根据条件移动其中一个或两个，直到相遇。

```python
left = 0
right = len(arr) - 1

while left < right:
    # 处理 arr[left] 和 arr[right]
    ...
    # 根据条件移动指针
    left += 1
    right -= 1
```

**循环结束条件**：`left < right`。当 `left == right` 时，中间的那个元素已经不需要再比了（自己和自己比没意义）。

## 实战一：反转数组

**题目**：原地反转一个数组，不能新建数组。

**最直观的解法**：交换 `left` 和 `right` 位置的元素，然后两边往中间走。

```python
def reverse_in_place(arr):
    left = 0
    right = len(arr) - 1
    while left < right:
        # 交换
        arr[left], arr[right] = arr[right], arr[left]
        left += 1
        right -= 1
    return arr

print(reverse_in_place([1, 2, 3, 4, 5]))   # [5, 4, 3, 2, 1]
print(reverse_in_place([1, 2, 3, 4]))       # [4, 3, 2, 1]
```

**手跑一遍** `[1, 2, 3, 4, 5]`：

```
初始：[1, 2, 3, 4, 5]   left=0, right=4
交换 arr[0] 和 arr[4]：[5, 2, 3, 4, 1]   left=1, right=3
交换 arr[1] 和 arr[3]：[5, 4, 3, 2, 1]   left=2, right=2
left == right，循环结束
```

正好交换了 2 次（n//2 次），**时间 O(n)，空间 O(1)**。

**对比切片做法**：`arr[::-1]` 会**新建一个数组**（O(n) 空间），不是原地修改。

```python
a = [1, 2, 3, 4, 5]
b = a[::-1]          # 新建了一个列表，a 本身没变
a.reverse()          # 原地修改，不新建
```

> 💡 如果题目说"原地修改"，就必须用双指针或 `list.reverse()`，不能切片。

## 实战二：回文判断

**题目**：判断一个列表（或字符串）是否是回文——正读反读一样。

```python
def is_palindrome(items):
    left = 0
    right = len(items) - 1
    while left < right:
        if items[left] != items[right]:
            return False
        left += 1
        right -= 1
    return True

print(is_palindrome([1, 2, 3, 2, 1]))   # True
print(is_palindrome([1, 2, 3]))          # False
print(is_palindrome([]))                 # True
print(is_palindrome([7]))                # True
```

**边界情况处理**：

| 输入 | left | right | 结果 | 原因 |
|---|---|---|---|---|
| `[]` | 0 | -1 | True | 循环不执行，直接返回 True |
| `[7]` | 0 | 0 | True | `left < right` 不成立，循环不执行 |
| `[1,2,1]` | 0,2 → 1,1 | — | True | left 追上 right，结束 |

**空列表和单元素天然是回文**——循环根本不执行，直接走到 `return True`。

### 字符串版回文

Python 字符串支持直接用下标访问，写法一模一样：

```python
def is_palindrome_str(s):
    left = 0
    right = len(s) - 1
    while left < right:
        if s[left] != s[right]:
            return False
        left += 1
        right -= 1
    return True

print(is_palindrome_str("上海自来水来自海上"))   # True
print(is_palindrome_str("hello"))              # False
```

## 对比三种回文判断写法

| 写法 | 时间 | 空间 | 点评 |
|---|---|---|---|
| 双指针（本课） | O(n) | O(1) | 最优，面试推荐 |
| 反转比较 `s == s[::-1]` | O(n) | O(n) | 简洁但占空间 |
| 递归 | O(n) | O(n) | 栈空间，不推荐 |

```python
# 切片版：简洁但新建了字符串
def is_palindrome_slice(s):
    return s == s[::-1]

print(is_palindrome_slice("abcba"))   # True
```

**面试时优先写双指针版**——它展示了你对"原地操作"和"指针控制"的掌握。

## 常见错误

### 错误一：left 和 right 都移动，但忘记交换

反转数组时如果只移动不交换，什么都不会变：

```python
# 错误：没有交换！
def reverse_buggy(arr):
    left = 0
    right = len(arr) - 1
    while left < right:
        left += 1      # 只移动
        right -= 1     # 只移动
    return arr

print(reverse_buggy([1, 2, 3]))   # [1, 2, 3] ← 没反转！
```

### 错误二：循环条件是 left <= right

反转时如果是 `<=`，中间那个元素会和自己做交换（不影响结果但多做一次）；回文判断时可能访问越界或误判。

```python
# 反转用 <= 其实不影响正确性（自己和自己交换）
# 但回文判断用 <= 就错了
def palindrome_buggy(items):
    left = 0
    right = len(items) - 1
    while left <= right:        # 错了！
        if items[left] != items[right]:
            return False
        left += 1
        right -= 1
    return True
# 对于 [1,2,3,2,1]，当 left=2,right=2 时比较 nums[2]!=nums[2] → False
# 但 2!=2 是 False，所以不会误判... 不过多余
```

**结论：统一用 `left < right` 最安全。**

## 为什么要学这个

你可能会问："反转用 `list.reverse()` 一行就完了，为什么还要写双指针？"

因为**对撞指针是后面很多题的骨架**：

- 接雨水（左右最高柱）
- 盛最多水的容器（两端逼近求面积）
- 三数之和（外层定一个，内层对撞两个）
- 反转链表（虽然是链表，思路一样）

**理解了"从两端逼近"这个动作，后面这些题就是它的变体。**

## 小结

- 对撞指针：`left` 从 0，`right` 从末尾，条件用 `left < right`
- 反转数组：交换 + 双向逼近，**O(n) 时间 O(1) 空间**
- 回文判断：两端逐对比较，任何一对不等就 False
- 空列表和单元素**天然是回文**（循环不执行）
- 对比切片 `s[::-1]`：简洁但 O(n) 空间，面试推荐双指针
