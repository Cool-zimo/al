# 二维前缀和：子矩阵求和与容斥原理

> 一维前缀和能查区间和。这一课把它升到二维：**子矩阵求和**——用容斥原理一次查完。

## 问题定义

**给你一个矩阵 `matrix`，反复查询"左上角 (r1, c1) 到右下角 (r2, c2) 的子矩阵元素之和"。**

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
# 查询 (0,0) 到 (1,1) 的子矩阵和：
# 1 + 2 + 4 + 5 = 12
```

朴素做法：双重循环累加，每次 O(mn)。用二维前缀和可以做到 O(1) 查询。

## 二维前缀和数组

**定义**：`prefix[i][j]` 表示**以 (0,0) 为左上角、(i-1,j-1) 为右下角**的矩形和。

即：`prefix[i][j]` = 矩阵中第 0~i-1 行、第 0~j-1 列的所有元素之和。

**和一维一样，多留一圈前导 0。**

## 构造：递推公式

**核心公式**（容斥原理）：

```
prefix[i][j] = prefix[i-1][j] + prefix[i][j-1] - prefix[i-1][j-1] + matrix[i-1][j-1]
```

**为什么要减 `prefix[i-1][j-1]`？** 因为 `prefix[i-1][j]` 和 `prefix[i][j-1]` 都包含了左上角那一块，加在一起算了两次，要减去一次。

```python
def build_prefix_2d(matrix):
    m = len(matrix)
    n = len(matrix[0]) if m > 0 else 0
    prefix = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            prefix[i][j] = (prefix[i - 1][j]
                          + prefix[i][j - 1]
                          - prefix[i - 1][j - 1]
                          + matrix[i - 1][j - 1])
    return prefix

matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
prefix = build_prefix_2d(matrix)
for row in prefix:
    print(row)
# [0, 0, 0, 0]
# [0, 1, 3, 6]
# [0, 5, 12, 21]
# [0, 12, 27, 45]
```

**手算几个验证**：

```
prefix[1][1] = prefix[0][1] + prefix[1][0] - prefix[0][0] + matrix[0][0]
            = 0 + 0 - 0 + 1 = 1 ✓

prefix[2][2] = prefix[1][2] + prefix[2][1] - prefix[1][1] + matrix[1][1]
            = 6 + 5 - 1 + 5 = 15
# 但等等，应该是 1+2+4+5=12
# 让我重新算：prefix[1][2]=6(第一行和), prefix[2][1]=5(第一列和)
# prefix[1][1]=1, matrix[1][1]=5
# 6+5-1+5 = 15... 不对
```

**等等，让我重新推导。** 实际上：

```
prefix[2][2] 应该是 (0,0) 到 (1,1) 的矩形和 = 1+2+4+5 = 12
```

让我重新计算：

```
prefix[1][1] = 0+0-0+matrix[0][0] = 1
prefix[1][2] = prefix[0][2]+prefix[1][1]-prefix[0][1]+matrix[0][1] = 0+1-0+2 = 3
prefix[1][3] = 0+3-0+3 = 6
prefix[2][1] = prefix[1][1]+prefix[2][0]-prefix[1][0]+matrix[1][0] = 1+0-0+4 = 5
prefix[2][2] = prefix[1][2]+prefix[2][1]-prefix[1][1]+matrix[1][1] = 3+5-1+5 = 12 ✓
prefix[2][3] = prefix[1][3]+prefix[2][2]-prefix[1][2]+matrix[1][2] = 6+12-3+6 = 21
prefix[3][1] = prefix[2][1]+prefix[3][0]-prefix[2][0]+matrix[2][0] = 5+0-0+7 = 12
prefix[3][2] = prefix[2][2]+prefix[3][1]-prefix[2][1]+matrix[2][1] = 12+12-5+8 = 27
prefix[3][3] = prefix[2][3]+prefix[3][2]-prefix[2][2]+matrix[2][2] = 21+27-12+9 = 45
```

所以正确结果是：

```
[0, 0,  0,  0]
[0, 1,  3,  6]
[0, 5, 12, 21]
[0, 12, 27, 45]
```

## 查询：子矩阵和

**查询从 (r1, c1) 到 (r2, c2) 的子矩阵和**：

```
ans = prefix[r2+1][c2+1]
    - prefix[r1][c2+1]
    - prefix[r2+1][c1]
    + prefix[r1][c1]
```

**容斥原理**：减掉上面多出来的 + 减掉左边多出来的 + 加回被减了两次的左上角。

```python
def query_2d(prefix, r1, c1, r2, c2):
    return (prefix[r2 + 1][c2 + 1]
          - prefix[r1][c2 + 1]
          - prefix[r2 + 1][c1]
          + prefix[r1][c1])

prefix = build_prefix_2d(matrix)
print(query_2d(prefix, 0, 0, 1, 1))   # 1+2+4+5 = 12 ✓
print(query_2d(prefix, 1, 1, 2, 2))   # 5+6+8+9 = 28 ✓
print(query_2d(prefix, 0, 0, 2, 2))   # 全部 = 45 ✓
```

## 画图理解容斥

查询 (1, 1) 到 (2, 2) 即元素 [5, 6, 8, 9]：

```
整个 prefix[3][3] = 45（全部元素）
要减去：
  - prefix[1][3] = 6（第 0 行：1,2,3）
  - prefix[3][1] = 12（第 0 列：1,4,7）
但 (0,0) 位置的 1 被减了两次，要加回来：
  + prefix[1][1] = 1

45 - 6 - 12 + 1 = 28 ✓
```

## 复杂度

| 操作 | 复杂度 |
|---|---|
| 构造 | O(mn) |
| 查询 | O(1) |
| 空间 | O(mn) |

**m 行 n 列的矩阵，查询任意子矩阵都是 O(1)。**

## 常见错误

### 错误一：下标偏移搞混

`prefix[i][j]` 对应的是 `matrix[i-1][j-1]`，不是 `matrix[i][j]`。

```python
# 错误：下标没有偏移
prefix[i][j] = prefix[i-1][j] + prefix[i][j-1] - prefix[i-1][j-1] + matrix[i][j]
# matrix[i][j] 会越界（当 i=m 或 j=n 时）
```

**记住**：prefix 多了一行一列，所以访问 matrix 时要减 1。

### 错误二：容斥公式符号写错

```python
# 错误：最后一项应该是 + 不是 -
return prefix[r2+1][c2+1] - prefix[r1][c2+1] - prefix[r2+1][c1] - prefix[r1][c1]
# 应该是 + prefix[r1][c1]
```

**画个图就不容易错**：被减两次的左上角要加回来。

### 错误三：处理空矩阵

```python
def build_prefix_2d(matrix):
    m = len(matrix)
    n = len(matrix[0]) if m > 0 else 0   # 空矩阵 n=0
    prefix = [[0] * (n + 1) for _ in range(m + 1)]
    ...
```

**必须判断 `m > 0`**，否则 `matrix[0]` 会 IndexError。

## 二维前缀和能做什么

| 问题 | 前缀和能否解决 |
|---|---|
| 子矩阵和 | ✅ |
| 子矩阵最大值 | ❌ |
| 子矩阵元素个数（计数） | ✅ |
| 子矩阵异或和 | ✅ |

**只要操作满足"可加减性"，就能用前缀和。**

## 小结

- 二维前缀和：`prefix[i][j]` 是 (0,0) 到 (i-1,j-1) 的矩形和
- 构造用容斥：`pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + mat[i-1][j-1]`
- 查询也用容斥：四步加减
- **多留一圈 0**，下标访问 matrix 时减 1
- 构造 O(mn)，查询 O(1)

- 因为矩阵元素都是正数
- 因为左上角那块区域在前面两次减法中被减了两次，要加回来一次

- 为了让结果变成奇数
answer: 1
explain: prefix[r2+1][c2+1] 减 prefix[r1][c2+1] 减 prefix[r2+1][c1] 时，左上角 (0,0) 到 (r1-1,c1-1) 那块区域被减了两次。加回 prefix[r1][c1] 就是把它补回来。这是容斥原理的标准操作。
