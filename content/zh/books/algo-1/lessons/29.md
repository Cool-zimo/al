# 窗口 + 计数：最小覆盖子串

> 固定窗口维护"和"，可变窗口维护"集合"，这一课维护的是**计数器**。用 Counter 精确追踪窗口内字符的出现次数，解决"最小覆盖子串"这类精确匹配问题。

## 问题定义

给定字符串 `s` 和 `t`，在 `s` 中找出**最短**的子串，使得这个子串**包含 t 中的所有字符**（包括重复次数）。

```python
s = "ADOBECODEBANC"
t = "ABC"
# 最小覆盖子串是 "BANC"

s = "a"
t = "a"
# 最小覆盖子串是 "a"

s = "a"
t = "aa"
# 无解，返回 ""
```

**注意**：t 中可能有重复字符，比如 t="AABC" 时，窗口里必须至少有 2 个 'A'、1 个 'B'、1 个 'C'。

## 暴力思路

枚举所有子串，检查每个子串是否包含 t 的所有字符。检查用 Counter 比对：

```python
from collections import Counter

def min_window_bruteforce(s, t):
    need = Counter(t)
    n = len(s)
    min_len = float('inf')
    min_left = 0

    for i in range(n):
        for j in range(i, n):
            window = Counter(s[i:j+1])
            # 检查 window 是否包含 need
            if all(window[c] >= need[c] for c in need):
                if j - i + 1 < min_len:
                    min_len = j - i + 1
                    min_left = i

    return "" if min_len == float('inf') else s[min_left:min_left + min_len]

print(min_window_bruteforce("ADOBECODEBANC", "ABC"))  # "BANC"
```

复杂度 O(n² × |t|)，太慢了。

## 滑动窗口 + 双 Counter 的思路

核心思想：

1. **`need`**：记录 t 中每个字符需要出现几次
2. **`window`**：记录当前窗口中每个字符出现了几次
3. **`required`**：t 中不同字符的种类数
4. **`formed`**：当前窗口中已经"达标"的字符种类数

当 `formed == required` 时，说明窗口**已经覆盖**了 t 的所有字符。

```python
from collections import Counter

def min_window(s, t):
    if not t or not s:
        return ""

    need = Counter(t)
    window = Counter()
    required = len(need)
    formed = 0

    left = 0
    min_len = float('inf')
    min_left = 0

    for right in range(len(s)):
        # 1. 把 s[right] 加入窗口
        c = s[right]
        window[c] += 1

        # 2. 如果当前字符达标了，formed++
        if c in need and window[c] == need[c]:
            formed += 1

        # 3. 当窗口已经覆盖 t，尝试收缩左边界
        while formed == required:
            # 更新答案
            if right - left + 1 < min_len:
                min_len = right - left + 1
                min_left = left

            # 收缩：移除 s[left]
            left_c = s[left]
            window[left_c] -= 1
            if left_c in need and window[left_c] < need[left_c]:
                formed -= 1
            left += 1

    return "" if min_len == float('inf') else s[min_left:min_left + min_len]

print(min_window("ADOBECODEBANC", "ABC"))  # "BANC"
print(min_window("a", "a"))               # "a"
print(min_window("a", "aa"))              # ""
```

## `formed` 的精妙之处

`formed` 跟踪的是"**达标种类数**"，不是"窗口大小"也不是"字符总数"。

```python
# 假设 need = {'A':2, 'B':1}
window = {'A':1, 'B':1}
# formed = 1 （只有 B 达标，A 还差1个）

window = {'A':2, 'B':1}
# formed = 2 （A和B都达标了！）

window = {'A':3, 'B':1}
# formed = 2 （还是2，A多出来不影响）
```

**关键**：当 `window[c] == need[c]` 时 `formed++`，当 `window[c] < need[c]` 时 `formed--`。这样 `formed` 精确反映了"当前窗口是否完全覆盖了 t"。

## 翻车现场一：忘记在收缩时检查 `formed--`

```python
from collections import Counter

def buggy_min_window(s, t):
    need = Counter(t)
    window = Counter()
    required = len(need)
    formed = 0
    left = 0
    min_len = float('inf')

    for right in range(len(s)):
        c = s[right]
        window[c] += 1
        if c in need and window[c] == need[c]:
            formed += 1

        # 错误：while 里忘记检查 formed 是否需要减少
        while formed == required:
            min_len = min(min_len, right - left + 1)
            # 忘记 window[left_c] < need[left_c] 的检查！
            window[s[left]] -= 1
            left += 1
            # formed 永远是 required，无限循环！

    return min_len
```

这段代码会**死循环**！因为 `formed` 永远是 `required`，`while` 永远不会退出。

**正确写法**：收缩时必须判断 `if left_c in need and window[left_c] < need[left_c]: formed -= 1`。

## 翻车现场二：用 `set` 代替 `Counter`

```python
def wrong_use_set(s, t):
    need = set(t)          # 错误！丢失了重复次数信息
    window = set()
    left = 0
    min_len = float('inf')

    for right in range(len(s)):
        window.add(s[right])
        while need.issubset(window):
            min_len = min(min_len, right - left + 1)
            window.remove(s[left])  # 错误！如果 s[left] 在窗口出现多次，一次 remove 就全没了
            left += 1

    return min_len

print(wrong_use_set("aaabc", "aabc"))  # 可能出错
```

**问题**：t="aabc" 需要 2 个 'a'，但 `set(t)` = {'a','b','c'}，丢失了 'a' 需要出现 2 次的信息。`set` 只能表达"有没有"，`Counter` 才能表达"有多少个"。

## 翻车现场三：收缩条件写错

```python
# 错误：在 formed == required 时才收缩，但收缩条件判断反了
while formed >= required:   # 这个其实没问题
    ...
```

真正容易错的是：**什么时候开始收缩**？必须在 `formed == required` 时立即开始收缩，找到以当前 `right` 结尾的**最短**覆盖子串。

```python
# 正确逻辑流程：
for right in range(len(s)):
    加入 s[right]
    更新 formed
    while formed == required:      # 窗口合法，尽力收缩
        记录答案
        移除 s[left]
        更新 formed
        left += 1
```

**口诀**：扩张要贪心（能加就加），收缩要尽力（能缩就缩）。

## 变体：判断字符串排列

窗口+计数的另一个经典应用：**判断 s2 是否包含 s1 的排列**。

```python
from collections import Counter

def check_inclusion(s1, s2):
    need = Counter(s1)
    window = Counter()
    required = len(need)
    formed = 0
    left = 0

    for right in range(len(s2)):
        c = s2[right]
        window[c] += 1
        if c in need and window[c] == need[c]:
            formed += 1

        if formed == required:
            return True

        # 窗口大小超过 len(s1) 时，必须收缩
        if right + 1 >= len(s1):
            left_c = s2[left]
            window[left_c] -= 1
            if left_c in need and window[left_c] < need[left_c]:
                formed -= 1
            left += 1

    return False

print(check_inclusion("ab", "eidbaooo"))  # True ("ba" 是 "ab" 的排列)
print(check_inclusion("ab", "eidboaoo"))  # False
```

和最小覆盖子串的区别：这里窗口大小**固定**为 `len(s1)`，一旦 `formed == required` 就可以立即返回 True。

## 小结

- 最小覆盖子串 = 可变窗口 + Counter 精确计数
- `need` 记录 t 的需求，`window` 记录当前窗口状态
- `formed` 跟踪"达标种类数"，达到 `required` 就尽力收缩
- 收缩时必须判断 `window[left_c] < need[left_c]` 才减少 `formed`
- 排列判断是固定窗口版本，窗口大小 = len(s1)

## 随堂练习

找出 s 中**最短**的子串，使得其中每个字符的出现次数都**不超过** t 中对应字符的出现次数。

```quiz
type: function
q: 实现 shortest_valid_window(s, t)：返回 s 中最短的子串，使得对于 t 中的每个字符，该子串中该字符的出现次数不超过 t 中该字符的出现次数。如果 t 中有字符 'A':2，那子串中 'A' 最多出现2次。不存在返回 ""。
func: shortest_valid_window
starter: |
  from collections import Counter

  def shortest_valid_window(s, t):
      # 思路：窗口内每个字符的计数都不能超过 t 中的限制
      # 用 need 记录 t 中每个字符的允许上限
      # 当窗口内某个字符超限时，收缩左边界
      need = Counter(t)
      count = Counter()
      left = 0
      min_len = float('inf')
      min_left = 0

      for right in range(len(s)):
          count[s[right]] += 1
          # 收缩：只要当前字符超限就收缩
          while count[s[right]] > need.get(s[right], 0):
              count[s[left]] -= 1
              left += 1
          # 检查窗口是否合法（所有字符都不超限）
          # 实际上因为我们只在超限时收缩，到这里一定合法
          if right - left + 1 < min_len:
              min_len = right - left + 1
              min_left = left

      return "" if min_len == float('inf') else s[min_left:min_left + min_len]
cases: |
  "ADOBECODEBANC", "ABC" -> "A"
  "a", "b" -> "a"
  "aa", "a" -> "a"
hint: 对于 t 中有的字符，窗口内不能超过其计数；对于 t 中没有的字符，窗口内不能超过0（即不能出现）。所以 need.get(c, 0) 就是上限。
explain: "ADOBECODEBANC" 中 t="ABC" 允许A:1,B:1,C:1。最短合法窗口是 "A"（索引0），只有1个字符，当然不超限。
```

```quiz
type: function
exam: true
q: 实现 count_complete_windows(s, t)：返回 s 中有多少个长度恰好为 len(t) 的连续子串，包含 t 的所有字符（考虑重复次数）。
func: count_complete_windows
starter: |
  from collections import Counter

  def count_complete_windows(s, t):
      # 固定窗口，窗口大小 = len(t)
      # 用 Counter 检查每个窗口是否包含 t 的所有字符
      need = Counter(t)
      window = Counter()
      count = 0

      for right in range(len(s)):
          window[s[right]] += 1
          if right >= len(t):
              left_c = s[right - len(t)]
              window[left_c] -= 1
              if window[left_c] == 0:
                  del window[left_c]
          if right >= len(t) - 1:
              if all(window[c] >= need[c] for c in need):
                  count += 1

      return count
```
