# 实战：三数之和的思路拆解

> 三数之和是面试高频题，也是双指针最经典的实战。这一课把思路一层层拆开：**先排序，再定一找二**。

## 题目

**给你一个整数数组 `nums`，找出所有**和为 0 **的三元组 `[nums[i], nums[j], nums[k]]`，且 `i < j < k`。答案不能包含重复的三元组。**

```python
nums = [-1, 0, 1, 2, -1, -4]
# 所有不重复的三元组：
# [-1, -1, 2]
# [-1, 0, 1]
```

## 第一步：排序

为什么要排序？因为**排序后可以用双指针**，而且排序能把"相等的元素"聚在一起，方便去重。

```python
nums.sort()   # [-4, -1, -1, 0, 1, 2]
```

**排序代价 O(n log n)**——比暴力 O(n³) 小得多。

## 第二步：定一个，找两个

暴力是三重循环 O(n³)。优化的核心思路：

> 先固定一个数 `nums[i]`，然后在 `i` 后面的部分里**找两个数，使它们的和等于 `-nums[i]`**。

**找两个数**——这正是第 06 课讲的两数之和！只不过现在数组有序，可以用**对撞指针** O(n) 完成。

```python
for i in range(n):
    target = -nums[i]          # 要在 i 后面找两个数，和为 -nums[i]
    left = i + 1               # 左指针从 i+1 开始
    right = n - 1              # 右指针从末尾开始
    while left < right:
        s = nums[left] + nums[right]
        if s == target:
            # 找到一个三元组
            ...
        elif s < target:
            left += 1
        else:
            right -= 1
```

**外层 O(n)，内层 O(n) → 整体 O(n²)。**

## 第三步：去重

这是最棘手的部分。题目要求**不重复的三元组**。

### 去重 i

如果 `nums[i] == nums[i-1]`，说明当前元素和上一个一样。那么以它为"定"的那个数，能找到的三元组一定和上一轮完全相同 → 跳过。

```python
if i > 0 and nums[i] == nums[i - 1]:
    continue
```

### 去重 left 和 right

找到一个有效三元组后，left 和 right 可能指向和刚才相同的元素。要跳过它们。

```python
if s == target:
    result.append([nums[i], nums[left], nums[right]])
    # 去重 left
    while left < right and nums[left] == nums[left + 1]:
        left += 1
    # 去重 right
    while left < right and nums[right] == nums[right - 1]:
        right -= 1
    # 正常移动
    left += 1
    right -= 1
```

## 完整代码

```python
def three_sum(nums):
    nums.sort()
    n = len(nums)
    result = []

    for i in range(n - 2):                          # i 最多到 n-3
        # 去重 i
        if i > 0 and nums[i] == nums[i - 1]:
            continue
        # 小优化：如果 nums[i] > 0，后面都是正数，和不可能为 0
        if nums[i] > 0:
            break

        target = -nums[i]
        left = i + 1
        right = n - 1

        while left < right:
            s = nums[left] + nums[right]
            if s == target:
                result.append([nums[i], nums[left], nums[right]])
                # 去重 left 和 right
                while left < right and nums[left] == nums[left + 1]:
                    left += 1
                while left < right and nums[right] == nums[right - 1]:
                    right -= 1
                left += 1
                right -= 1
            elif s < target:
                left += 1
            else:
                right -= 1

    return result

print(three_sum([-1, 0, 1, 2, -1, -4]))
# [[-1, -1, 2], [-1, 0, 1]]
```

## 手跑一遍

`nums = [-1, 0, 1, 2, -1, -4]` → 排序后 `[-4, -1, -1, 0, 1, 2]`

```
i=0: nums[0]=-4, target=4
  left=1, right=5: nums[1]+nums[5]=-1+2=1 < 4 → left++
  left=2, right=5: -1+2=1 < 4 → left++
  ... 找不到，right 一直缩到 left==right

i=1: nums[1]=-1, target=1
  left=2, right=5: -1+2=1 == 1 → 找到 [-1,-1,2]！去重 left/right
  left=3, right=4: 0+1=1 == 1 → 找到 [-1,0,1]！

i=2: nums[2]==nums[1](-1==-1) → 跳过（去重）

i=3: nums[3]=0>0 → break（后面都>0，和不可能为0）
```

## 复杂度分析

| 步骤 | 复杂度 |
|---|---|
| 排序 | O(n log n) |
| 外层循环 i | O(n) |
| 内层双指针 | O(n) |
| **总计** | **O(n log n) + O(n²) = O(n²)** |

**从暴力的 O(n³) 降到 O(n²)**，n=1000 时差距是 1000 倍。

## 常见错误

### 错误一：忘记排序

双指针的前提是有序。不排序直接双指针会漏答案。

```python
# 错误：没排序
def three_sum_buggy(nums):
    n = len(nums)
    for i in range(n - 2):
        left = i + 1
        right = n - 1
        while left < right:
            s = nums[i] + nums[left] + nums[right]
            if s == 0:
                ...
            elif s < 0:
                left += 1
            else:
                right -= 1
```

如果 `nums = [3, 0, -1, -2, 1, 1, 2]`，不排序时双指针的判断逻辑完全失效。

### 错误二：去重条件写错位置

```python
# 错误：去重写在 append 之前
if nums[left] == nums[left + 1]:
    left += 1
# 这样会把有效元素跳过！
```

**去重必须在"记录答案之后"进行。**

### 错误三：i 的循环范围写成 range(n)

```python
# 错误：i 会越界
for i in range(n):        # i=n-1 时 left=n，right=n-1，left<right 不成立还行
                          # 但 i=n-2 时 left=n-1, right=n-1，也不成立
```

**i 最多到 n-3**（后面至少要留 left 和 right 两个位置）。

## 这道题的通用套路

三数之和的解法可以推广到**很多"找几个数满足条件"的题**：

1. **排序**（让双指针可用 + 方便去重）
2. **定一找二**（把 k 数之和降成 k-1 数之和）
3. **双指针找两数**（O(n)）
4. **去重**（跳过重复元素）

**四数之和**：定两个，双指针找两个 → O(n³)。
**k 数之和**：递归定 k-2 个，最后用双指针 → O(n^(k-1))。

## 小结

- 三数之和：先排序，再"定一个找两个"
- "找两个数和为 target"用对撞指针 O(n)
- 外层定 i，整体 O(n²)，远好于暴力 O(n³)
- 去重是关键：i 去重 + 找到后 left/right 去重
- 套路可推广：排序 + 定 k-2 个 + 双指针

**第 2 章到此结束。** 接下来第 3 章讲**前缀和**——另一种把 O(n) 降到 O(1) 的预处理技巧。
