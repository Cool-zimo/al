# 可变窗口：无重复字符的最长子串

> 固定窗口长度不变，可变窗口则根据条件动态收缩。这一课用"无重复字符的最长子串"作为主战场，彻底讲清 **HashMap + 左边界推进** 的套路。

## 问题定义

给定一个字符串 `s`，找出**最长**的没有重复字符的**连续子串**的长度。

```python
s = "abcabcbb"
# 最长无重复子串是 "abc"，长度为 3

s = "pwwkew"
# 最长无重复子串是 "wke" 或 "kew"，长度为 3

s = "bbbbb"
# 最长无重复子串是 "b"，长度为 1
```

**注意**：是子串（连续），不是子序列（可以不连续）。

## 暴力解法为什么慢

暴力做法是枚举所有子串，逐个检查是否有重复字符：

```python
def longest_substring_bruteforce(s):
    n = len(s)
    max_len = 0
    for i in range(n):
        seen = set()
        for j in range(i, n):
            if s[j] in seen:
                break
            seen.add(s[j])
            max_len = max(max_len, j - i + 1)
    return max_len

print(longest_substring_bruteforce("abcabcbb"))  # 3
```

外层循环 O(n)，内层最坏 O(n)，检查重复 O(1)——总复杂度 **O(n²)**。

能不能更快？可以。用可变窗口，把内层循环"消化"掉。

## 可变窗口的核心思路

想象有一个**弹性橡皮筋**，左端 `left` 固定，右端 `right` 不断向右拉伸。只要当前字符没在窗口里出现过，`right` 就继续走。一旦碰到重复字符，就从左边收缩，直到重复消失。

```python
s = "abcabcbb"
char_set = set()
left = 0
max_len = 0

for right in range(len(s)):
    # 关键：如果 s[right] 已经在窗口里，收缩左边界
    while s[right] in char_set:
        char_set.remove(s[left])
        left += 1
    # 加入新字符
    char_set.add(s[right])
    # 更新答案
    max_len = max(max_len, right - left + 1)

print(max_len)  # 3
```

**为什么是 `while` 不是 `if`？** 因为可能要移出**多个**字符才能消除重复。虽然在这个具体问题里 `while` 里每次只移出一个，且移出后必定消除重复（因为移出的就是上次出现的位置之前的），但用 `while` 是更安全的写法。

## HashMap 记录索引：更强大的版本

用 `set` 只能判断"在不在"，用 `dict` 记录"上次出现在哪"可以直接跳到正确位置：

```python
s = "abcabcbb"
char_index = {}   # 字符 -> 最后出现的索引
max_len = 0
left = 0

for right in range(len(s)):
    if s[right] in char_index and char_index[s[right]] >= left:
        # 这个字符在当前窗口里出现过！
        # 直接把 left 跳到上次出现位置的下一位
        left = char_index[s[right]] + 1
    char_index[s[right]] = right
    max_len = max(max_len, right - left + 1)

print(max_len)  # 3
```

**HashMap 版本的优势**：`left` 可以**直接跳转**，而不用一个一个地移出字符。两种写法复杂度都是 O(n)，但 HashMap 版本的实际运行步数更少。

## 手跑一遍 "abba"

```
初始化: char_index={}, left=0, max_len=0

right=0, s[0]='a':
  'a' 不在 char_index 中 → 不更新 left
  char_index={'a':0}
  max_len = max(0, 0-0+1) = 1

right=1, s[1]='b':
  'b' 不在 char_index 中 → 不更新 left
  char_index={'a':0, 'b':1}
  max_len = max(1, 1-0+1) = 2

right=2, s[2]='b':
  'b' 在 char_index 中, 且 char_index['b']=1 >= left=0 → 重复！
  left = 1 + 1 = 2
  char_index={'a':0, 'b':2}
  max_len = max(2, 2-2+1) = 2

right=3, s[3]='a':
  'a' 在 char_index 中, 但 char_index['a']=0 < left=2 → 不在当前窗口！
  （这是关键！索引0的'a'已经被挤出窗口了）
  不更新 left
  char_index={'a':3, 'b':2}
  max_len = max(2, 3-2+1) = 2

最终: max_len = 2
```

**关键细节**：`char_index[s[right]] >= left` 这个判断必不可少。字符可能在窗口**之外**出现过（比如上面的 'a' 在索引 0），那不算重复。

## 翻车现场一：忘记写 `>= left` 检查

```python
s = "abba"
char_index = {}
max_len = 0
left = 0

for right in range(len(s)):
    if s[right] in char_index:   # 错误！没有检查 >= left
        left = char_index[s[right]] + 1
    char_index[s[right]] = right
    max_len = max(max_len, right - left + 1)

print(max_len)  # 错误输出：3
```

**为什么会错**：到 `right=3` 时，'a' 确实在 `char_index` 里（索引 0），但那个 'a' 已经不在当前窗口 `[2, 3]` 里了。代码却把 `left` 跳到了 1，导致窗口变成了 `[1, 3]` = "bba"，长度 3——这是一个**有重复字符**的窗口！

正确写法是 `if s[right] in char_index and char_index[s[right]] >= left`。

## 翻车现场二：left 跳转时忘了 +1

```python
s = "abba"
char_index = {}
max_len = 0
left = 0

for right in range(len(s)):
    if s[right] in char_index and char_index[s[right]] >= left:
        left = char_index[s[right]]   # 错误！应该是 +1
    char_index[s[right]] = right
    max_len = max(max_len, right - left + 1)

print(max_len)  # 错误输出：4
```

到 `right=3` 时，'a' 上次出现在索引 0，`left` 被设为 0（而不是 1）。窗口 `[0, 3]` = "abba"，长度 4——满篇重复字符！

**教训**：`left` 要跳过那个重复的字符本身，所以必须 `char_index[s[right]] + 1`。

## 翻车现场三：用 set 但只移出一个字符

```python
s = "abcbda"
seen = set()
left = 0
max_len = 0

for right in range(len(s)):
    if s[right] in seen:
        seen.remove(s[left])   # 只移出一个！
        left += 1
    seen.add(s[right])
    max_len = max(max_len, right - left + 1)

print(max_len)  # 错误输出：5？让我们看看
```

当 `right=4`（字符 'd'）时没问题。到 `right=5`（字符 'a'）时：'a' 在 seen 里，代码只 `remove(s[left])` 即移出 'a'（left=0），然后 `left=1`。但此时 seen 里还有 'b'、'c'、'd'，窗口变成了 `[1, 5]` = "bcbda"，里面 'b' 重复了吗？没有。但窗口 `[1,5]` 实际上包含了 left=1 到 right=5 的所有字符，而 'a' 已经被重新加入了。让我重新检查……

实际上这个例子可能碰巧正确。换一个更明显的反例：

```python
s = "abcadef"
seen = set()
left = 0
max_len = 0

for right in range(len(s)):
    if s[right] in seen:
        seen.remove(s[left])   # 只移出一个
        left += 1
    seen.add(s[right])
    max_len = max(max_len, right - left + 1)
    print(f"right={right}, char={s[right]}, seen={seen}, left={left}, max_len={max_len}")

# right=4, char='a': 'a'在seen中, remove(s[0]='a'), left=1, add 'a', seen={'b','c','a'}
# 窗口 [1,4]="bcad", 无重复 ✓ 碰巧对
```

实际上对于这个问题，`while` 和 `if` 在 `set` 版本里效果一样，因为每次移出一个字符后，那个重复的字符必然被移除了。所以用 `set` + `if` 也能过。但用 `dict` 记录索引时，`while` 和 `if` 就有区别了——`if` + 直接跳转更高效。

## 完整实现 + 返回子串

```python
def longest_substring(s):
    char_index = {}
    max_len = 0
    max_left = 0
    left = 0

    for right in range(len(s)):
        if s[right] in char_index and char_index[s[right]] >= left:
            left = char_index[s[right]] + 1
        char_index[s[right]] = right
        if right - left + 1 > max_len:
            max_len = right - left + 1
            max_left = left

    return s[max_left:max_left + max_len]

print(longest_substring("abcabcbb"))  # "abc"
print(longest_substring("bbbbb"))     # "b"
print(longest_substring("pwwkew"))    # "wke"
print(longest_substring(""))          # ""
```

## 复杂度分析

| 方面 | 复杂度 | 说明 |
|---|---|---|
| 时间 | O(n) | 每个字符被 right 访问一次，left 也只增不减 |
| 空间 | O(min(n, m)) | m 是字符集大小（ASCII 128，Unicode 更大） |

`left` 和 `right` 都只向右移动，总共最多各走 n 步。所以无论内层 `while` 还是 `if`，摊还下来都是 O(n)。

## 小结

- 可变窗口 = 右指针扩张 + 左指针条件性收缩
- `set` 版本：用 `while` 逐个移出，直到重复消除
- `HashMap` 版本：记录上次出现位置，`left` 直接跳到 `last_index + 1`
- **必须检查 `>= left`**，否则会把窗口外的旧记录当成重复
- 两种写法都是 O(n)，HashMap 版本实际步数更少

## 随堂练习

用可变窗口思想，找出字符串中**最多包含 k 种不同字符**的最长子串长度。

```quiz
type: function
q: 实现 longest_substring_k_distinct(s, k)：返回最多包含 k 种不同字符的最长子串长度。
func: longest_substring_k_distinct
starter: |
  from collections import Counter

  def longest_substring_k_distinct(s, k):
      # 用可变窗口 + Counter 维护窗口内字符的出现次数
      # 当不同字符数 > k 时，收缩左边界
      count = Counter()
      left = 0
      max_len = 0
      for right in range(len(s)):
          count[s[right]] += 1
          while len(count) > k:
              count[s[left]] -= 1
              if count[s[left]] == 0:
                  del count[s[left]]
              left += 1
          max_len = max(max_len, right - left + 1)
      return max_len
cases: |
  "eceba", 2 -> 3
  "aa", 1 -> 2
  "abc", 0 -> 0
hint: Counter 的 len() 就是不同字符的数量。当 len(count) > k 时，从左边收缩：减计数，如果减到0就删除该键，然后 left+=1。
explain: "eceba" k=2: 窗口扩张到 "eceb" 时有 e,c,b 三种字符，超过2种，收缩左边界到 "ceb"，还是3种，继续收缩到 "eb"，2种，长度2。最终最大是 "ece" 长度3。
```

  def all_unique_substrings_count(s):
      # 用可变窗口的思路：对每个 left，找到最远的 right 使得 [left, right] 无重复
