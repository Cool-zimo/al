# 综合实战：双指针、前缀和、滑动窗口的融会贯通

> 前面几课分别学了双指针、前缀和、滑动窗口。这一课把它们放在一起，做一道需要**多技巧组合**的综合题，并教你如何判断该用哪种工具。

## 三把武器的适用场景

| 技巧 | 解决的问题 | 关键特征 |
|---|---|---|
| 双指针 | 两数之和、三数之和、对撞找答案 | 指针独立移动，关注"两元素之和" |
| 前缀和 | 区间求和、子数组和查询 | 预处理 O(n)，查询 O(1) |
| 滑动窗口 | 子数组/子串最值、满足条件的最短区间 | 维护区间状态，指针只增不减 |

**但现实中的题不会告诉你"这题用滑动窗口"。** 你需要自己判断。

## 综合题：最短子数组（LeetCode 209）

**题目**：给定一个正整数数组 `nums` 和一个正整数 `target`，找出**和 >= target** 的**最短**连续子数组的长度。如果不存在，返回 0。

```python
nums = [2, 3, 1, 2, 4, 3]
target = 7
# 最短子数组是 [4, 3]，长度 2，和为 7
```

### 为什么用滑动窗口？

- 答案是**连续区间** → 满足窗口的前提
- 要求**最短** → 可变窗口（满足条件时收缩左边界）
- 数组是**正数** → 窗口和单调递增，收缩有确定性

**如果数组有负数，滑动窗口就不行了**（收缩后和可能反而变大）。

### 解法

```python
def min_subarray_len(nums, target):
    left = 0
    window_sum = 0
    min_len = float('inf')

    for right in range(len(nums)):
        # 右指针扩张：加入 nums[right]
        window_sum += nums[right]

        # 左指针收缩：只要和 >= target，就尽力缩小
        while window_sum >= target:
            min_len = min(min_len, right - left + 1)
            window_sum -= nums[left]
            left += 1

    return min_len if min_len != float('inf') else 0

print(min_subarray_len([2, 3, 1, 2, 4, 3], 7))   # 2
print(min_subarray_len([1, 4, 4], 4))              # 1
print(min_subarray_len([1, 1, 1, 1, 1], 11))       # 0
```

### 手跑一遍

## 变体：和 >= target 的最长子数组

如果数组**全是正数**，最长子数组就是整个数组（和最大）。但如果有**负数**，就不一样了：

```python
nums = [1, -1, 5, -2, 3]
target = 3
# 最长子数组是 [1, -1, 5, -2, 3]，长度5，和6 >= 3
```

这个题用滑动窗口就**不行**了（有负数），需要用前缀和 + 单调队列或 TreeMap，属于进阶内容。

## 综合题二：最长子串，最多替换 k 个字符

**题目**：给你一个字符串 `s` 和一个整数 `k`。你可以**最多**替换 k 个字符，使得替换后的子串中所有字符都相同。求能获得的最长子串长度。

```python
s = "ABAB", k = 2
# 替换后变成 "AAAA"，长度 4

s = "AABABBA", k = 1
# 替换后变成 "AAAABBA" 或 "AABBBBA"，最长 4
```

### 思路

窗口内的字符，替换掉**非多数**的那些字符。如果窗口长度为 `len`，出现最多的字符频率为 `max_freq`，那么需要替换 `len - max_freq` 个字符。只要 `len - max_freq <= k`，这个窗口就是合法的。

```python
from collections import Counter

def character_replacement(s, k):
    count = Counter()
    left = 0
    max_len = 0
    max_freq = 0

    for right in range(len(s)):
        count[s[right]] += 1
        max_freq = max(max_freq, count[s[right]])

        # 需要替换的字符数 = 窗口长度 - 最高频字符数
        while (right - left + 1) - max_freq > k:
            count[s[left]] -= 1
            left += 1
            # 重新计算 max_freq（这一步可以优化，但不影响正确性）
            max_freq = max(count.values()) if count else 0

        max_len = max(max_len, right - left + 1)

    return max_len

print(character_replacement("ABAB", 2))     # 4
print(character_replacement("AABABBA", 1))  # 4
```

**精妙之处**：`max_freq` 只增不减——我们只在 `len - max_freq > k` 时才收缩，所以 `max_freq` 不需要精确维护最小值，只需要在收缩后更新。

## 翻车现场一：忘记更新 max_freq

```python
from collections import Counter

def buggy_replacement(s, k):
    count = Counter()
    left = 0
    max_len = 0
    max_freq = 0

    for right in range(len(s)):
        count[s[right]] += 1
        max_freq = max(max_freq, count[s[right]])

        while (right - left + 1) - max_freq > k:
            count[s[left]] -= 1
            left += 1
            # 错误：没有更新 max_freq！
            # 收缩后 max_freq 可能变小了，但我们还在用旧值
        max_len = max(max_len, right - left + 1)

    return max_len

print(buggy_replacement("AABABBA", 1))  # 可能返回错误结果
```

**为什么会错**：收缩左边界后，`max_freq` 可能变小了（比如移出的是当前最高频字符），但我们还在用旧的 `max_freq` 值，导致 `len - max_freq` 的计算偏大，窗口应该继续收缩但没有。

正确做法是在收缩后重新计算 `max_freq = max(count.values())`。

## 翻车现场二：混淆"最短"和"最长"的收缩逻辑

```python
nums = [2, 3, 1, 2, 4, 3]
target = 7

# 求最短子数组：和 >= target 时收缩
def shortest(nums, target):
    left = 0
    window_sum = 0
    min_len = float('inf')
    for right in range(len(nums)):
        window_sum += nums[right]
        while window_sum >= target:  # >= 时收缩
            min_len = min(min_len, right - left + 1)
            window_sum -= nums[left]
            left += 1
    return min_len

# 求最长子数组：和 <= target 时收缩
def longest(nums, target):
    left = 0
    window_sum = 0
    max_len = 0
    for right in range(len(nums)):
        window_sum += nums[right]
        while window_sum > target:   # > 时收缩（注意是 > 不是 >=）
            window_sum -= nums[left]
            left += 1
        max_len = max(max_len, right - left + 1)
    return max_len

print(shortest([2, 3, 1, 2, 4, 3], 7))  # 2
print(longest([2, 3, 1, 2, 4, 3], 7))   # 4 ([3,1,2,4] 或 [1,2,4,3])
```

**关键区别**：
- **最短** → 条件满足时（`>=`）收缩，找"刚好不满足"的边界
- **最长** → 条件不满足时（`>`）收缩，找"刚好满足"的边界

符号的方向决定了你是找最短还是最长。

## 决策流程图

遇到数组/字符串区间问题，按以下顺序判断：

```
1. 答案是连续区间吗？
   ├─ 否 → 可能是组合/双指针（两数之和、三数之和）
   └─ 是 → 继续
2. 区间是固定长度吗？
   ├─ 是 → 固定窗口（O(n)）
   └─ 否 → 继续
3. 要求满足条件的最短/最长区间？
   ├─ 是 → 可变窗口（需判断单调性）
   │  ├─ 全正数 → 滑动窗口
   │  └─ 有负数 → 前缀和 + 其他技巧
   └─ 只是查询区间和 → 前缀和 O(1) 查询
```

## 复杂度对比

| 方法 | 时间 | 空间 | 适用条件 |
|---|---|---|---|
| 暴力枚举所有子数组 | O(n³) | O(1) | 无 |
| 前缀和 + 哈希表 | O(n) | O(n) | 有负数也可以 |
| 滑动窗口 | O(n) | O(1)~O(k) | 通常要求单调性 |

## 小结

- 双指针、前缀和、滑动窗口各有适用场景，综合题需要灵活组合
- 最短子数组和 >= target：右扩左缩，`>=` 时收缩
- 最长子数组和 <= target：右扩左缩，`>` 时收缩
- 字符替换题：`len - max_freq <= k` 是合法条件
- 收缩后记得更新维护的变量（max_freq 等）
- 有负数时滑动窗口通常失效，需改用前缀和

  def num_subarrays_with_sum(nums, k):
