# 快慢指针：原地删除重复元素与移除指定值

> 对撞指针是"两头夹"。这一课讲另一种形态：**快慢指针**——两个指针同向走，一个探路、一个"记录答案"。

## 为什么需要快慢指针

很多题目要求**原地修改数组**（不能新建数组），还要返回"有效部分的长度"。

典型场景：
- 有序数组去重（每个元素只留一个）
- 移除所有等于某个值的元素
- 把零移到末尾

如果允许新建数组，这些都很简单。但**要求 O(1) 额外空间**时，就得靠快慢指针。

## 核心思想

- **慢指针 `slow`**：指向"下一个可以放答案的位置"
- **快指针 `fast`**：一路往前探，找"有用的元素"

凡是 `fast` 发现的有用元素，就放到 `slow` 的位置上，然后 `slow` 前进一格。

```python
slow = 0
for fast in range(n):
    if 条件满足:           # fast 指向的是"有用"的元素
        arr[slow] = arr[fast]
        slow += 1
# 最终 slow 就是有效长度
```

## 实战一：移除所有等于 val 的元素

**题目**：给定 `nums` 和 `val`，原地移除所有等于 `val` 的元素，返回新长度。

```python
nums = [3, 2, 2, 3, 4, 5, 3]
val = 3
# 移除 3 后，有效元素是 [2, 2, 4, 5]，返回 4
```

**思路**：`fast` 遍历所有元素，`slow` 记录"下一个可以放的位置"。遇到不是 `val` 的就留下来。

```python
def remove_element(nums, val):
    slow = 0
    for fast in range(len(nums)):
        if nums[fast] != val:          # fast 指向的不是要删的
            nums[slow] = nums[fast]    # 把它搬到 slow 的位置
            slow += 1                  # slow 前进
    return slow                        # slow 就是新长度

nums = [3, 2, 2, 3, 4, 5, 3]
length = remove_element(nums, 3)
print(length)                # 4
print(nums[:length])         # [2, 2, 4, 5]
```

**手跑一遍** `nums = [3, 2, 2, 3, 4]`，`val = 3`：

```
slow=0, fast=0: nums[0]=3 == val → 跳过
slow=0, fast=1: nums[1]=2 != val → nums[0]=2, slow=1
slow=1, fast=2: nums[2]=2 != val → nums[1]=2, slow=2
slow=2, fast=3: nums[3]=3 == val → 跳过
slow=2, fast=4: nums[4]=4 != val → nums[2]=4, slow=3
结束，返回 slow=3
nums 前 3 个：[2, 2, 4] ✓
```

**时间 O(n)，空间 O(1)**——只用了两个指针变量。

## 实战二：有序数组去重

**题目**：给定有序数组，原地删除重复元素，每个元素只保留一个，返回新长度。

```python
nums = [1, 1, 2, 2, 2, 3, 4, 4]
# 去重后有效部分：[1, 2, 3, 4]，返回 4
```

**思路**：第一个元素一定保留。从第二个开始，如果和前一个不同，就加入答案区。

```python
def remove_duplicates(nums):
    if not nums:                    # 空列表直接返回 0
        return 0
    slow = 1                        # 第 0 个已经保留
    for fast in range(1, len(nums)):
        if nums[fast] != nums[fast - 1]:   # 和前一个不同 → 是新元素
            nums[slow] = nums[fast]
            slow += 1
    return slow                     # 有效长度

nums = [1, 1, 2, 2, 2, 3, 4, 4]
length = remove_duplicates(nums)
print(length)                # 4
print(nums[:length])         # [1, 2, 3, 4]
```

**手跑一遍** `[1, 1, 2, 2, 3]`：

```
slow=1, fast=1: nums[1]==nums[0] (1==1) → 跳过
slow=1, fast=2: nums[2]!=nums[1] (2!=1) → nums[1]=2, slow=2
slow=2, fast=3: nums[3]==nums[2] (2==2) → 跳过
slow=2, fast=4: nums[4]!=nums[3] (3!=2) → nums[2]=3, slow=3
返回 3，前 3 个：[1, 2, 3] ✓
```

### 边界情况

| 输入 | 处理 | 结果 |
|---|---|---|
| `[]` | 空列表判断返回 0 | 0 |
| `[5]` | slow=1, fast 从 1 开始不进循环 | 1 |
| `[1,1,1]` | 只有第一个保留 | 1 |

**空列表必须单独处理**——否则 `nums[0]` 会 IndexError。

## 常见错误

### 错误一：忘记返回 slow

很多同学只做了赋值，忘了返回长度。

```python
# 错误：没有 return
def remove_duplicates_buggy(nums):
    slow = 1
    for fast in range(1, len(nums)):
        if nums[fast] != nums[fast - 1]:
            nums[slow] = nums[fast]
            slow += 1
    # 缺 return slow → 返回 None
```

### 错误二：用 `nums.append` 而不是覆盖

`append` 会**在末尾加元素**，而不是覆盖前面的——结果是数组变长了。

```python
# 错误：用了 append
def remove_buggy(nums, val):
    slow = 0
    for fast in range(len(nums)):
        if nums[fast] != val:
            nums.append(nums[fast])   # 错！数组越来越长
            slow += 1
    return slow
```

**必须覆盖**：`nums[slow] = nums[fast]`。

### 错误三：去重时比较 nums[fast] 和 nums[slow]

```python
# 错误：比较对象错了
def dedup_buggy(nums):
    slow = 1
    for fast in range(1, len(nums)):
        if nums[fast] != nums[slow]:   # 错！slow 在变，逻辑混乱
            nums[slow] = nums[fast]
            slow += 1
    return slow
```

**去重要比较"当前元素和前一个元素"**：`nums[fast] != nums[fast - 1]`。

## 为什么这招这么通用

快慢指针的本质是**"压缩"**：把"有用的"往前挪，覆盖掉没用的。

它适用于所有这类题目：

| 题目 | 条件 |
|---|---|
| 移除指定值 | `nums[fast] != val` |
| 有序去重 | `nums[fast] != nums[fast-1]` |
| 移动零到末尾 | 先把非零往前挪，最后补零 |
| 按奇偶分离 | 按条件分流到不同位置 |

**套路一样，条件不同。学会一次，通吃一片。**

## 小结

- 快慢指针：**slow 记录答案位置，fast 探路**
- 原地操作，不新建数组 → **空间 O(1)**
- 移除元素：`nums[fast] != val` 时搬到 slow
- 有序去重：`nums[fast] != nums[fast-1]` 时搬到 slow
- 注意边界：空列表、单元素、返回 slow
