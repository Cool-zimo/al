# 标准二分：闭区间写法，mid 的计算与死循环

> 上一课我们理解了二分的前提。这一课给一套**不会出错的闭区间模板**，并解释每一步为什么这样写。

## 闭区间模板（最推荐）

**核心**：搜索区间是 `[left, right]`（闭区间），包含 left 和 right 本身。

```python
def binary_search(nums, target):
    left, right = 0, len(nums) - 1    # 闭区间 [left, right]

    while left <= right:               # 区间非空时继续
        mid = left + (right - left) // 2

        if nums[mid] == target:
            return mid                 # 找到了
        elif nums[mid] < target:
            left = mid + 1             # 丢掉 mid，去右边找
        else:
            right = mid - 1            # 丢掉 mid，去左边找

    return -1                          # 区间为空，没找到
```

**为什么 `while left <= right`？** 因为区间是闭的，`left == right` 时区间内还有一个元素没检查。只有 `left > right` 时区间才真正为空。

**为什么 `left = mid + 1`？** 因为 `nums[mid]` 已经和 target 比较过了，它不是答案，可以从搜索区间中去掉。

## 四种 mid 计算方式

| 写法 | 含义 | 适用场景 |
|---|---|---|
| `(left + right) // 2` | 向下取整 | 通用 |
| `left + (right - left) // 2` | 向下取整 | 避免溢出（其他语言） |
| `(left + right + 1) // 2` | 向上取整 | 找右边界 |
| `left + (right - left + 1) // 2` | 向上取整 | 避免溢出 + 找右边界 |

**在 Python 里四种都能用**（整数不会溢出），但**向下取整是最常用的默认选择**。

## 死循环的两种经典场景

### 场景一：left = mid

```python
while left < right:            # 注意是 <
    mid = (left + right) // 2
    if nums[mid] < target:
        left = mid             # 错误！应该是 mid + 1
    else:
        right = mid

# 当 left=0, right=1 时：mid=0
# nums[0] < target → left = mid = 0
# 区间还是 [0, 1]，无限循环！
```

**原因**：`left = mid` 后区间没有缩小（`[0, 1]` → `[0, 1]`）。

**修复**：`left = mid + 1`。但如果 right 也是 `mid`，问题可能出在另一边。

### 场景二：left = mid, right = mid 同时出现

```python
while left < right:
    mid = (left + right) // 2   # 向下取整
    if condition:
        left = mid              # 不 +1
    else:
        right = mid             # 不 -1

# left=2, right=3 时：mid=2
# condition 为真 → left=mid=2
# 区间还是 [2, 3]，死循环！
```

**这是最经典的二分死循环。** 原因：`mid` 向下取整时 `mid == left`（当区间长度为 2 时），`left = mid` 导致区间不缩小。

**两种修复方案**：

```python
# 方案一：mid 向上取整
while left < right:
    mid = (left + right + 1) // 2   # 向上取整
    if condition:
        left = mid                  # 现在 mid 不会等于 left 了
    else:
        right = mid - 1             # 配合 left=mid，right 要 -1

# 方案二：检查后无条件移动
while left <= right:
    mid = (left + right) // 2       # 向下取整
    if nums[mid] == target:
        return mid
    elif nums[mid] < target:
        left = mid + 1              # +1
    else:
        right = mid - 1             # -1
```

## 为什么模板推荐 `left <= right`

| 写法 | 搜索区间 | 终止条件 | mid 计算 | 是否容易死循环 |
|---|---|---|---|---|
| `left <= right` | 闭区间 [l, r] | `left > right` | 向下取整 | 否 |
| `left < right` | 左闭右开 [l, r) | `left == right` | 向上取整（找右） | 容易 |

**闭区间 + 向下取整 + `<=` 是最不容易出错的模板。**

## 手跑一遍完整流程

`nums = [1, 3, 5, 7, 9, 11]`，找 `target = 7`：

```
初始：left=0, right=5, 区间 [0, 5]
mid = (0+5)//2 = 2, nums[2]=5 < 7 → left = 3

left=3, right=5, 区间 [3, 5]
mid = (3+5)//2 = 4, nums[4]=9 > 7 → right = 3

left=3, right=3, 区间 [3, 3]
mid = (3+3)//2 = 3, nums[3]=7 == 7 → 返回 3 ✓
```

找 `target = 4`（不存在）：

```
初始：left=0, right=5
mid=2, nums[2]=5 > 4 → right=1

left=0, right=1
mid=0, nums[0]=1 < 4 → left=1

left=1, right=1
mid=1, nums[1]=3 < 4 → left=2

left=2, right=1 → 循环结束，返回 -1 ✓
```

## 常见错误

### 错误一：循环条件写成 `while left < right`

```python
# 闭区间但用了 <
while left < right:         # 区间 [left, right] 里还有一个元素没检查
    mid = (left + right) // 2
    ...
# left=0, right=0 时循环不执行，但 nums[0] 没检查！
```

**如果搜索区间是闭区间 `[left, right]`，循环条件必须是 `<=`。** 或者改成左闭右开 `[left, right)` 用 `<`。

### 错误二：left/right 忘记 ±1

```python
# 只移动，不 +1/-1
if nums[mid] < target:
    left = mid      # 错了！应该是 mid + 1
```

**会死循环**（场景一）。

### 错误三：返回时忘记检查边界

```python
def binary_search_buggy(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return mid    # 错了！mid 可能超出范围
```

**没找到时应该返回 -1（或其他哨兵值），不是 mid。**

## 标准模板的记忆口诀

> **闭区间，<=
> mid 向下取整，
> 大了 right-1，小了 left+1，
> 找到就返回，没找到返回 -1。**

**把这个模板背下来，80% 的二分题都能套。**

## 小结

- 最推荐：**闭区间 `[left, right]` + `while left <= right`**
- `mid = (left + right) // 2`（向下取整）
- 收缩时 `left = mid + 1` 或 `right = mid - 1`（去掉已判断的 mid）
- 死循环根源：区间没缩小 → 检查 ±1
- 找到返回 mid，没找到返回 -1
