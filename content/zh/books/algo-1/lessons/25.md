# 最长回文子串：从暴力到中心扩展

> 上一课我们看到中心扩展是干一件事的利器：**找最长回文子串**。这一课一步步推导出这个算法。

## 问题定义

**给定一个字符串 `s`，找出最长的回文子串。**

```python
s = "babad"
# "bab" 是回文（"aba" 也是），任意一个都是合法答案

s = "cbbd"
# "bb" 是最长回文子串

s = "racecar"
# 整个字符串就是回文，答案是 "racecar"
```

**子串是原串中连续的一段**——不能重新排列字符。

## 尝试一：暴力枚举

**思路**：枚举所有可能的子串，逐个判断是否回文，记录最长的。

```python
def longest_palindrome_brute(s):
    n = len(s)
    best = ""
    for i in range(n):                # 起始下标
        for j in range(i, n):         # 结束下标
            sub = s[i:j+1]
            if sub == sub[::-1]:      # 回文判断
                if len(sub) > len(best):
                    best = sub
    return best
```

**有多慢？**

- 子串数量：**O(n²)**
- 每个子串用 `== sub[::-1]` 判断：**O(n)**
- 总计：**O(n³)** 时间

**对于稍微长一点的字符串就太慢了。** 我们可以做得更好。

## 尝试二：把判断优化到 O(1)

**观察**：如果已知 `s[i+1:j]` 是回文，那么 `s[i:j+1]` 是回文**当且仅当** `s[i] == s[j]`。

```python
def longest_palindrome_dp(s):
    n = len(s)
    if n == 0:
        return ""
    
    # dp[i][j] = True 表示 s[i:j+1] 是回文
    dp = [[False] * n for _ in range(n)]
    start, max_len = 0, 1
    
    # 长度为 1 的回文
    for i in range(n):
        dp[i][i] = True
    
    # 长度为 2 的回文
    for i in range(n - 1):
        if s[i] == s[i + 1]:
            dp[i][i + 1] = True
            start, max_len = i, 2
    
    # 长度 3 及以上
    for length in range(3, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            if s[i] == s[j] and dp[i + 1][j - 1]:
                dp[i][j] = True
                if length > max_len:
                    start, max_len = i, length
    
    return s[start:start + max_len]
```

**复杂度**：**O(n²)** 时间，**O(n²)** 空间。比 O(n³) 好，但空间还能再压吗？

## 尝试三：中心扩展 — O(n²) 时间，O(1) 空间

**核心洞察**：每个回文都有一个**中心**。从中心出发，只要两端字符相等就向外扩展。

- 奇数长度回文（`"racecar"`）有一个中心字符
- 偶数长度回文（`"abba"`）的中心**在**两个字符之间

```python
def longest_palindrome(s):
    if not s:
        return ""
    
    def expand(left, right):
        # 两端相等就继续扩展
        while left >= 0 and right < len(s) and s[left] == s[right]:
            left -= 1
            right += 1
        # 循环结束时，s[left:right+1] 已经不是回文了
        # 真正的回文是 s[left+1:right]
        return right - left - 1
    
    start, max_len = 0, 1
    for i in range(len(s)):
        # 奇数长度：以 i 为中心
        len_odd = expand(i, i)
        # 偶数长度：以 i 和 i+1 之间为中心
        len_even = expand(i, i + 1)
        
        curr = max(len_odd, len_even)
        if curr > max_len:
            max_len = curr
            # 长度为 L、中心在 i 的回文，起点是 i - (L-1)/2
            start = i - (curr - 1) // 2
    
    return s[start:start + max_len]
```

**手跑一遍** `s = "babad"`，`i = 1`（字符 `'a'`）：

```
从中心 i=1 的奇数扩展：
  left=1, right=1  -> 'a'==='a'，扩展：left=0, right=2
  s[0]='b', s[2]='b' -> 匹配，扩展：left=-1, right=3
  left < 0，停止
  长度 = 3 - (-1) - 1 = 3  -> 回文 "bab"

从 i=1 和 i=2 之间的偶数扩展：
  left=1, right=2 -> s[1]='a', s[2]='b' -> 不匹配
  长度 = 0
```

**所以在 `i=1` 处找到的最佳结果是长度为 3 的 `"bab"`。**

## 复杂度分析

**对于 n 个中心，每个最多扩展 n/2 步。**

- 时间：**O(n²)**（n 个中心 × 每个最多 n 次扩展）
- 空间：**O(1)**（只有几个变量）

| 方法 | 时间 | 空间 |
|---|---|---|
| 暴力（所有子串 + 反转判断） | O(n³) | O(1) |
| 动态规划 | O(n²) | O(n²) |
| 中心扩展 | O(n²) | O(1) |

**中心扩展是最佳平衡点：线性空间下的最优时间，代码也最简单。**

## 常见错误

### 错误一：只处理奇数长度回文

```python
# 错误：只从单个字符开始扩展
for i in range(n):
    length = expand(i, i)    # 会漏掉 "abba"、"bb"、"noon" 等
```

**你还必须从两个字符之间开始扩展**，才能捕获偶数长度回文。

### 错误二：计算起点时差一错误

```python
# 错误
start = i - max_len // 2    # 奇数长度时出错

# 正确
start = i - (max_len - 1) // 2
```

**长度为 3、中心在 `i` 时，`(3-1)//2 = 1`，所以 `start = i - 1`。长度为 4 时，`(4-1)//2 = 1`，所以 `start = i - 1`——偶数长度也是正确的。**

### 错误三：返回了错误的切片

```python
# 错误
return s[left:right]    # 这些是扩展停止时的下标

# 正确
return s[start:start + max_len]
```

**`left` 和 `right` 是扩展失败时的下标。真正的回文右端在 `right-1`。**

## # 错误 — 当扩展停止时

**最常见的 bug 是搞错 `expand` 返回后 `left` 和 `right` 的含义：**

```python
# 错误
def longest_palindrome_buggy(s):
    def expand(left, right):
        while left >= 0 and right < len(s) and s[left] == s[right]:
            left -= 1
            right += 1
        return left, right    # 返回的是停止时的下标
    
    best = ""
    for i in range(len(s)):
        l1, r1 = expand(i, i)
        l2, r2 = expand(i, i + 1)
        # 试图用停止时的下标切片
        cand = s[l1:r1 + 1]      # r1 已经越过右端了！
        if len(cand) > len(best):
            best = cand
    return best

print(longest_palindrome_buggy("babad"))
# 实际输出："babad"  <- 太长了，甚至不是回文！
```

**哪里错了？** 当 `expand` 停止时，`left` 已经被减到了回文左边界**之外**，`right` 已经被加到了右边界**之外**。用 `s[l1:r1+1]` 切片就会包含不属于回文的字符——对于 `"babad"`，它直接返回了整个 5 字符字符串，这不是回文。

正确版本从 `expand` 返回**长度**，然后用整数运算推导起点：

```python
# 正确
def longest_palindrome(s):
    if not s:
        return ""
    def expand(left, right):
        while left >= 0 and right < len(s) and s[left] == s[right]:
            left -= 1
            right += 1
        return right - left - 1     # 回文长度
    start, max_len = 0, 1
    for i in range(len(s)):
        odd = expand(i, i)
        even = expand(i, i + 1)
        curr = max(odd, even)
        if curr > max_len:
            max_len = curr
            start = i - (curr - 1) // 2
    return s[start:start + max_len]

print(longest_palindrome("babad"))   # "bab"
print(longest_palindrome("cbbd"))    # "bb"
```

**关键区别**：返回长度而不是下标，每个中心只计算一次 `start`，用 `(curr - 1) // 2`。这一个表达式对奇数和偶数长度都适用。

## 完整算法

**把整个算法放在一起：**

```python
def longest_palindrome(s):
    if not s:
        return ""
    
    def expand(left, right):
        while left >= 0 and right < len(s) and s[left] == s[right]:
            left -= 1
            right += 1
        return right - left - 1
    
    start, max_len = 0, 1
    for i in range(len(s)):
        len_odd = expand(i, i)
        len_even = expand(i, i + 1)
        curr = max(len_odd, len_even)
        if curr > max_len:
            max_len = curr
            start = i - (curr - 1) // 2
    
    return s[start:start + max_len]

# 示例
print(longest_palindrome("babad"))         # "bab"（或 "aba"）
print(longest_palindrome("cbbd"))          # "bb"
print(longest_palindrome("racecar"))       # "racecar"
print(longest_palindrome("a"))             # "a"
print(longest_palindrome("ac"))            # "a"（或 "c"）
```

## 小结

- 暴力法 O(n³)——枚举所有子串再反转判断
- 动态规划 O(n²) 时间但 O(n²) 空间
- 中心扩展：O(n²) 时间，**O(1)** 空间——最佳实用选择
- 从每个字符（奇数）**和**每两个字符之间（偶数）扩展
- `expand` 返回长度；起点用 `i - (length-1)//2` 计算
