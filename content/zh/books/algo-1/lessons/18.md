# 边界二分：找第一个/最后一个满足条件的位置

> 标准二分只回答"在不在"。这一课解决更常见的问题：**有序数组中第一个/最后一个满足条件的元素在哪**。

## 问题场景

**题目**：在有序数组中，找某个值**第一次**出现的位置和**最后一次**出现的位置。

```python
nums = [1, 2, 2, 2, 2, 3, 4, 5]
# 2 第一次出现在索引 1
# 2 最后一次出现在索引 4
```

为什么要找边界？因为：

- 求某个值出现了几次 = `last_pos - first_pos + 1`
- 找"第一个 >= target"的位置（lower_bound）
- 找"第一个 > target"的位置（upper_bound）

## 左边界二分（lower_bound）

**目标**：找**第一个 >= target** 的位置。

```python
def lower_bound(nums, target):
    left, right = 0, len(nums)          # 注意 right 初始是 len(nums)
    while left < right:                  # 注意是 < 不是 <=
        mid = (left + right) // 2        # 向下取整
        if nums[mid] < target:
            left = mid + 1               # mid 太小，去右边
        else:
            right = mid                  # mid 可能就是答案，不去右边
    return left
```

**为什么 `right = mid` 而不是 `right = mid - 1`？** 因为 `nums[mid] >= target` 时，`mid` 本身可能是第一个满足条件的位置，不能丢掉。

**为什么 `while left < right`？** 因为终止时 `left == right`，那个位置就是答案。

```python
nums = [1, 2, 2, 2, 2, 3, 4, 5]
print(lower_bound(nums, 2))   # 1
print(lower_bound(nums, 3))   # 5
print(lower_bound(nums, 6))   # 8（超出范围，说明所有元素都 < 6）
```

## 右边界二分（upper_bound）

**目标**：找**第一个 > target** 的位置（即最后一个 == target 的下一个位置）。

```python
def upper_bound(nums, target):
    left, right = 0, len(nums)
    while left < right:
        mid = (left + right) // 2
        if nums[mid] <= target:
            left = mid + 1               # mid 太小或相等，去右边
        else:
            right = mid                  # mid 太大，mid 可能是答案
    return left
```

```python
nums = [1, 2, 2, 2, 2, 3, 4, 5]
print(upper_bound(nums, 2))   # 5（索引 5 是 3，第一个 > 2 的）
print(upper_bound(nums, 3))   # 6
print(upper_bound(nums, 1))   # 1
```

## 用 lower/upper 求出现次数

```python
def count_occurrences(nums, target):
    return upper_bound(nums, target) - lower_bound(nums, target)

nums = [1, 2, 2, 2, 2, 3, 4, 5]
print(count_occurrences(nums, 2))   # 5 - 1 = 4 ✓
print(count_occurrences(nums, 3))   # 6 - 5 = 1 ✓
print(count_occurrences(nums, 6))   # 8 - 8 = 0 ✓（不存在）
```

**时间 O(log n)**——比线性扫描的 O(n) 快得多。

## 手跑一遍 lower_bound

`nums = [1, 2, 2, 2, 2, 3, 4, 5]`，找 `target = 2`：

```
初始：left=0, right=8, 区间 [0, 8)
mid=4, nums[4]=2 >= 2 → right=4

left=0, right=4, 区间 [0, 4)
mid=2, nums[2]=2 >= 2 → right=2

left=0, right=2, 区间 [0, 2)
mid=1, nums[1]=2 >= 2 → right=1

left=0, right=1, 区间 [0, 1)
mid=0, nums[0]=1 < 2 → left=1

left=1, right=1 → 循环结束，返回 1 ✓
```

## 两种写法的对比

| 特征 | lower_bound | upper_bound |
|---|---|---|
| 找什么 | 第一个 >= target | 第一个 > target |
| `< target` 时 | left = mid + 1 | left = mid + 1 |
| `== target` 时 | right = mid | left = mid + 1 |
| `> target` 时 | right = mid | right = mid |
| 返回值 | 第一个满足条件的位置 | 第一个不满足的位置 |

**区别只在一个地方**：遇到 `nums[mid] == target` 时，lower_bound 往左走（可能还有更小的），upper_bound 往右走（找比 target 大的）。

## 常见错误

### 错误一：把两种模板混用

```python
# 错误：lower_bound 的循环体 + upper_bound 的返回值
def buggy(nums, target):
    left, right = 0, len(nums)
    while left < right:
        mid = (left + right) // 2
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid
    # 然后期望返回 last occurrence
    return left   # 返回的是 first occurrence，不是 last！
```

**两个模板的条件分支不同，不能混用。**

### 错误二：right 初始值搞错

```python
# 错误：right 初始是 len(nums)-1
left, right = 0, len(nums) - 1
while left < right:
    ...
# 这样 right 永远到不了 len(nums)
# 当 target 比所有元素都大时，应该返回 len(nums)，但返回不了
```

**边界二分中 `right` 初始为 `len(nums)`（开区间右端点）。**

### 错误三：mid 用向上取整导致死循环

```python
while left < right:
    mid = (left + right + 1) // 2   # 向上取整
    if nums[mid] < target:
        left = mid                  # 死循环！mid 不会变
    else:
        right = mid
```

**左边界模板用向下取整 `(left+right)//2`，右边界模板才用向上取整。**

## 为什么 Python 自带 bisect 模块

Python 标准库提供了 `bisect` 模块，就是干这个的：

```python
import bisect

nums = [1, 2, 2, 2, 2, 3, 4, 5]
print(bisect.bisect_left(nums, 2))   # 1（lower_bound）
print(bisect.bisect_right(nums, 2))  # 5（upper_bound）

# 插入元素
bisect.insort(nums, 2)
print(nums)   # [1, 2, 2, 2, 2, 2, 3, 4, 5]
```

**面试时建议手写二分**（展示理解），实际工程中用 `bisect`。

## 小结

- **lower_bound**：找第一个 >= target，`nums[mid] >= target` 时 `right = mid`
- **upper_bound**：找第一个 > target，`nums[mid] <= target` 时 `left = mid + 1`
- 两种模板只差一个 `=` 号
- 出现次数 = `upper_bound - lower_bound`
- Python 有 `bisect` 模块，面试手写

answer: 1
explain: nums[mid] >= target 说明 mid 是一个候选答案（可能就是第一个满足条件的），但左边可能还有更早的满足条件的元素。所以去 [left, mid] 继续找，保留 mid。如果写成 right=mid-1，就可能漏掉 mid 这个正确答案。
