# 实战：在旋转/近似有序里找东西

> 标准二分要求完全有序。这一课看一个经典变体：**旋转排序数组**——大部分有序，但有"断点"。

## 问题：搜索旋转排序数组

**题目**：整数数组 `nums` 原本升序，但在某个位置旋转了（把前面的若干元素搬到了末尾）。

```python
# 原本是 [1, 2, 3, 4, 5, 6, 7]
# 旋转 3 个位置后变成 [4, 5, 6, 7, 1, 2, 3]
# 或旋转 2 个位置 [6, 7, 1, 2, 3, 4, 5]

nums = [4, 5, 6, 7, 1, 2, 3]
# 找 target=2，返回下标 5
```

**它整体不是有序的，但"局部是有序的"。** 这正是可以利用的地方。

## 关键观察

**旋转数组的性质**：从中间切开，**[left, mid] 和 [mid, right] 中至少有一个是完全有序的。**

```
nums = [4, 5, 6, 7, 1, 2, 3]
left=0, right=6, mid=3
nums[mid] = 7

左边 [4, 5, 6, 7] → 有序！
右边 [7, 1, 2, 3] → 无序
```

**利用这个有序的一半来做判断。**

## 算法思路

1. 取 `mid = (left + right) // 2`
2. **判断哪一半有序**
3. **在有序的那一半里判断 target 是否在范围内**
   - 在范围内 → 去那一半继续二分
   - 不在范围内 → 去另一半

```python
def search_rotated(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid

        # 判断左半是否有序
        if nums[left] <= nums[mid]:
            # 左半有序
            if nums[left] <= target < nums[mid]:
                right = mid - 1      # target 在左半
            else:
                left = mid + 1       # target 在右半
        else:
            # 右半有序
            if nums[mid] < target <= nums[right]:
                left = mid + 1       # target 在右半
            else:
                right = mid - 1      # target 在左半

    return -1

print(search_rotated([4, 5, 6, 7, 1, 2, 3], 2))   # 5
print(search_rotated([4, 5, 6, 7, 1, 2, 3], 8))   # -1
```

## 手跑一遍

`nums = [4, 5, 6, 7, 1, 2, 3]`，找 `target = 2`：

```
left=0, right=6, mid=3, nums[3]=7
7 != 2
左半 [4,5,6,7] 有序（nums[0]<=nums[3]）
target=2, 2 不在 [4, 7] 范围内 → 去右半
left=4

left=4, right=6, mid=5, nums[5]=2
2 == 2 → 返回 5 ✓
```

找 `target = 6`：

```
left=0, right=6, mid=3, nums[3]=7
7 != 6
左半有序，6 在 [4, 7) 范围内 → 去左半
right=2

left=0, right=2, mid=1, nums[1]=5
5 != 6
左半 [4,5] 有序，6 不在 [4, 5) 范围内 → 去右半
left=2

left=2, right=2, mid=2, nums[2]=6
6 == 6 → 返回 2 ✓
```

## 为什么一定有至少一半有序

**直觉**：旋转数组是从有序数组中"切一刀"再拼起来的。切一刀后，必然有一段是完整的升序。

```
原始:  [1, 2, 3, 4, 5, 6, 7]
切在 4 后面: [5, 6, 7 | 1, 2, 3, 4]
             右半完整    左半完整
```

不管怎么切，**总有一段是连续升序的**。我们的算法每次都利用这段升序来缩小搜索范围。

## 复杂度

**时间 O(log n)**——和标准二分一样，每次排除一半。

**空间 O(1)**——只用几个变量。

**关键是：它不是完全有序的，我们仍然能用二分！** 这就是"局部有序"的力量。

## 变体：找旋转数组的最小值

**题目**：找到旋转数组中的最小元素。

```python
nums = [4, 5, 6, 7, 1, 2, 3]
# 最小值是 1，在索引 4
```

**思路**：最小值就是"断点"——那个比左边邻居小的元素。

```python
def find_min(nums):
    left, right = 0, len(nums) - 1
    while left < right:
        mid = (left + right) // 2
        if nums[mid] > nums[right]:
            # mid 在左半（较大的那半），最小值在右半
            left = mid + 1
        else:
            # mid 在右半（较小的那半），最小值在 mid 或 mid 左边
            right = mid
    return nums[left]

print(find_min([4, 5, 6, 7, 1, 2, 3]))   # 1
print(find_min([3, 1, 2]))                # 1
print(find_min([1, 2, 3, 4, 5]))          # 1（没旋转）
```

**手跑一遍** `[4, 5, 6, 7, 1, 2, 3]`：

```
left=0, right=6, mid=3, nums[3]=7, nums[right]=3
7 > 3 → mid 在左半，最小值在右半 → left=4

left=4, right=6, mid=5, nums[5]=2, nums[right]=3
2 <= 3 → mid 在右半，最小值在 mid 或左边 → right=5

left=4, right=5, mid=4, nums[4]=1, nums[right]=2
1 <= 2 → right=4

left=4, right=4 → 结束，返回 nums[4]=1 ✓
```

## 常见错误

### 错误一：直接用标准二分

```python
# 错误：旋转数组不是完全有序
def search_buggy(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

# nums=[4,5,6,7,1,2,3], target=2
# mid=3, nums[3]=7 > 2 → right=2
# 但 2 在右半，被错误地排除了！
```

**旋转数组不能直接用标准二分**，必须先判断哪半有序。

### 错误二：nums[left] <= nums[mid] 的等号

```python
# 错误：少了等号
if nums[left] < nums[mid]:     # 应该是 <=
    ...
```

**当 `nums[left] == nums[mid]` 时（比如只有一个元素或所有元素相等），应该认为左半有序。** 少了等号会漏情况。

### 错误三：范围判断用错了符号

```python
# 错误：应该是 <= target < nums[mid]
if nums[left] < target < nums[mid]:    # 漏了等于
    ...
```

**target 可能等于 `nums[left]`，要包含等号。**

## 这道题的本质

**旋转数组二分的核心技巧**：不是"整体有序才能二分"，而是"**只要有局部有序，就能用二分缩小范围**"。

这个思想可以推广到很多变体：

- 山脉数组中的峰值（L33 搜索）
- 有序矩阵中查找
- 部分有序的数组中查找

## 小结

- 旋转数组：整体无序，但**至少有一半有序**
- 算法：判断哪半有序 → 在有序半中判断 target 范围 → 缩小搜索
- 找最小值：比较 nums[mid] 和 nums[right] 决定去哪半
- 时间 O(log n)，空间 O(1)
- 本质：**局部有序即可二分**
