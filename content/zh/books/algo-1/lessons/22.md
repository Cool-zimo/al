# 计数与哈希：字符统计、异位词判断

> 字符串题最常考的操作就是**计数**——数一数每个字符出现了几次。这一课讲透它。

## 用字典计数

**最简单的计数方式：遍历一遍，用字典记录频率。**

```python
def char_count(s):
    count = {}
    for ch in s:
        count[ch] = count.get(ch, 0) + 1
    return count

print(char_count("banana"))
# {'b': 1, 'a': 6, 'n': 2}

print(char_count("上海自来水来自海上"))
# {'上': 2, '海': 2, '自': 1, '来': 2, '水': 1, '来': ...}
```

**`dict.get(key, default)` 是关键**——取不到时返回默认值 0，不用写 if 判断。

## 用 collections.Counter（更简洁）

Python 标准库有专门的计数工具：

```python
from collections import Counter

print(Counter("banana"))
# Counter({'a': 3, 'n': 2, 'b': 1})

print(Counter("hello world"))
# Counter({'l': 3, 'o': 2, 'h': 1, 'e': 1, ' ': 1, 'w': 1, 'r': 1, 'd': 1})
```

**Counter 支持很多实用操作：**

```python
c = Counter("aabbccc")

# 最常见的 2 个
print(c.most_common(2))   # [('c', 3), ('a', 2)]

# 计数相加
c2 = Counter("cccddd")
print(c + c2)             # Counter({'c': 6, 'd': 3, 'a': 2, 'b': 2})

# 减法（保留正数）
print(c - Counter("ab"))   # Counter({'a': 1, 'b': 1, 'c': 3})
```

## 实战：异位词判断

**题目**：判断两个字符串是否是**异位词**（由相同字符、相同数量组成，顺序可以不同）。

```python
s1 = "listen"
s2 = "silent"
# 是异位词

s1 = "hello"
s2 = "world"
# 不是异位词
```

### 解法一：排序法

```python
def is_anagram_sort(s1, s2):
    if len(s1) != len(s2):
        return False
    return sorted(s1) == sorted(s2)

print(is_anagram_sort("listen", "silent"))   # True
print(is_anagram_sort("hello", "world"))    # False
```

**复杂度**：排序 O(n log n)，空间取决于排序实现。

### 解法二：计数法（哈希表）

```python
def is_anagram_count(s1, s2):
    if len(s1) != len(s2):
        return False
    count = {}
    for ch in s1:
        count[ch] = count.get(ch, 0) + 1
    for ch in s2:
        if ch not in count:
            return False
        count[ch] -= 1
        if count[ch] == 0:
            del count[ch]
    return len(count) == 0

print(is_anagram_count("listen", "silent"))   # True
print(is_anagram_count("hello", "world"))    # False
```

**或者直接用 Counter 相减：**

```python
from collections import Counter

def is_anagram(s1, s2):
    return Counter(s1) == Counter(s2)

print(is_anagram("listen", "silent"))   # True
```

**复杂度**：O(n) 时间，O(n) 空间。

## 两种解法的对比

| 特征 | 排序法 | 计数法 |
|---|---|---|
| 时间 | O(n log n) | O(n) |
| 空间 | O(1) 或 O(n) | O(n) |
| 代码行数 | 1 行 | 5-8 行 |
| 适用场景 | 字符集小、追求简洁 | 面试要求最优解 |

**面试推荐计数法**（O(n) 更优），实际写代码排序法更快。

## 实战：找第一个不重复的字符

**题目**：在字符串中找到**第一个**只出现一次的字符的下标。

```python
s = "leetcode"
# 'l' 出现 1 次，是第一个 → 返回 0

s = "loveleetcode"
# 'v' 是第一个只出现一次的 → 返回 2
```

```python
def first_uniq_char(s):
    count = {}
    for ch in s:
        count[ch] = count.get(ch, 0) + 1
    for i, ch in enumerate(s):
        if count[ch] == 1:
            return i
    return -1

print(first_uniq_char("leetcode"))      # 0
print(first_uniq_char("loveleetcode"))  # 2
```

**两次遍历**：第一次计数，第二次找第一个计数为 1 的。

## 实战：同构字符串

**题目**：判断两个字符串是否是**同构**的——s 中的字符可以唯一映射到 t 中的字符。

```python
s = "egg"
t = "add"
# e->a, g->d，是一一映射 → True

s = "foo"
t = "bar"
# f->b, o->a, o->r → o 映射到了两个不同字符 → False
```

```python
def is_isomorphic(s, t):
    if len(s) != len(t):
        return False
    map_st = {}
    map_ts = {}
    for a, b in zip(s, t):
        if a in map_st and map_st[a] != b:
            return False
        if b in map_ts and map_ts[b] != a:
            return False
        map_st[a] = b
        map_ts[b] = a
    return True

print(is_isomorphic("egg", "add"))    # True
print(is_isomorphic("foo", "bar"))    # False
```

**需要两个映射表**——既要检查 s→t 唯一，也要检查 t→s 唯一。

## 常见错误

### 错误一：用数组下标代替字典，但忘了字符范围

```python
# 如果只有小写字母，可以用长度为 26 的数组
def is_anagram_array(s1, s2):
    if len(s1) != len(s2):
        return False
    count = [0] * 26
    for ch in s1:
        count[ord(ch) - ord('a')] += 1
    for ch in s2:
        count[ord(ch) - ord('a')] -= 1
    return all(c == 0 for c in count)

# 但如果字符串里有大写或中文，就会下标越界
# is_anagram_array("Hello", "olleH")  → IndexError!
```

**用数组的前提是字符集已知且连续（如只有小写字母）。通用场景用字典。**

### 错误二：忘记先检查长度

```python
def is_anagram_buggy(s1, s2):
    count = {}
    for ch in s1:
        count[ch] = count.get(ch, 0) + 1
    for ch in s2:
        count[ch] = count.get(ch, 0) - 1
    return all(v == 0 for v in count.values())   # 漏了长度检查也能对，但多算了

# 但这个函数对 "a" 和 "aa" 会返回 True！
```

**先检查长度可以避免不必要的遍历，也能处理一些边界。**

### 错误三：字典的 get 写成 []

```python
# 错误
count = {}
for ch in s:
    count[ch] += 1      # KeyError！ch 不存在时不能 +=

# 正确
count[ch] = count.get(ch, 0) + 1

# 或者用 defaultdict
from collections import defaultdict
count = defaultdict(int)
for ch in s:
    count[ch] += 1
```

## 什么时候用计数

**判断标准**：如果题目问"有多少个"、"是否相同"、"第几次出现"，基本都需要计数。

| 问题 | 是否用计数 |
|---|---|
| 异位词判断 | ✅ |
| 找第一个不重复字符 | ✅ |
| 最长回文子串 | ❌（用中心扩展） |
| 字符串反转 | ❌（用双指针） |
| 同构字符串 | ✅ |
| 最长无重复子串 | ✅（滑动窗口 + 计数） |

## 小结

- 字符串计数用**字典**或 `collections.Counter`
- `count.get(ch, 0) + 1` 是标准写法
- 异位词判断：排序法 O(n log n) vs 计数法 O(n)
- 同构字符串需要**双向映射**
- 先检查长度可以提前剪枝
