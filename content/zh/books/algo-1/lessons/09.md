# 滑动窗口雏形：长度最小的连续子数组

> 快慢指针是"一快一慢"。这一课把它升级成**滑动窗口**：两个指针之间维护一个"区间"，根据条件"扩张"和"收缩"。

## 先看暴力解法的代价

**题目**：给定一个正整数数组和一个目标值 `target`，找**和 ≥ target 的、长度最小的连续子数组**，返回它的长度。

```python
nums = [2, 3, 1, 2, 4, 3]
target = 7
# [4, 3] 和为 7，长度 2；[2,3,1,2] 和为 8，长度 4
# 最短的是 [4, 3]，返回 2
```

**暴力做法**：枚举所有起点，再枚举所有终点。

```python
def min_subarray_brute(nums, target):
    n = len(nums)
    ans = float('inf')
    for i in range(n):              # 起点
        s = 0
        for j in range(i, n):       # 终点
            s += nums[j]
            if s >= target:
                ans = min(ans, j - i + 1)
                break               # 找到了以 i 为起点的最短的
    return ans if ans != float('inf') else 0

print(min_subarray_brute([2, 3, 1, 2, 4, 3], 7))   # 2
```

**时间 O(n²)**。n=10 万时就超时了。

## 滑动窗口的思路

暴力解的问题是：**每次起点右移一格，都要从头累加**。但新区间和旧区间有大量重叠，可以复用。

**滑动窗口的做法**：

- `left`：窗口左边界
- `right`：窗口右边界（不断扩张）
- `window_sum`：当前窗口内元素的和

**两步操作**：

1. **扩张**：`right` 右移，把 `nums[right]` 加入窗口和
2. **收缩**：当窗口和 ≥ target 时，记录长度，然后 `left` 右移，把 `nums[left]` 从窗口和里减去

```python
def min_subarray_len(nums, target):
    n = len(nums)
    left = 0
    window_sum = 0
    ans = float('inf')

    for right in range(n):
        window_sum += nums[right]        # 扩张：加入右边界

        while window_sum >= target:      # 满足条件，尝试收缩
            ans = min(ans, right - left + 1)
            window_sum -= nums[left]     # 收缩：去掉左边界
            left += 1

    return ans if ans != float('inf') else 0

print(min_subarray_len([2, 3, 1, 2, 4, 3], 7))   # 2
```

## 为什么是 O(n)

**关键点**：`left` 和 `right` 都只往前走，从不回头。

- `right` 从 0 走到 n-1：最多 n 步
- `left` 从 0 走到 n-1：最多 n 步

**两个指针加起来最多走 2n 步 → O(n)。**

对比暴力的 O(n²)，这是质变。

## 手跑一遍

`nums = [2, 3, 1, 2, 4, 3]`，`target = 7`：

```
right=0: sum=2, <7, 不收缩
right=1: sum=5, <7
right=2: sum=6, <7
right=3: sum=8, >=7 → ans=min(inf,4)=4, sum-=2, left=1, sum=6
right=4: sum=10, >=7 → ans=min(4,4)=4, sum-=3, left=2, sum=7
                  sum=7, >=7 → ans=min(4,3)=3, sum-=1, left=3, sum=6
right=5: sum=9, >=7 → ans=min(3,3)=3, sum-=2, left=4, sum=7
                 sum=7, >=7 → ans=min(3,2)=2, sum-=4, left=5, sum=3
结束，返回 2
```

**窗口的变化过程**：

```
[2, 3, 1, 2]      sum=8  长度 4
   [3, 1, 2, 4]   sum=10 长度 4 → [3,1,2,4] 收缩 → [1,2,4] 长度 3
      [1, 2, 4]   sum=7  长度 3 → 收缩 → [2,4] 长度 2
         [2, 4, 3] sum=9  长度 3 → 收缩 → [4,3] 长度 2
            [4, 3] sum=7  长度 2 ← 最短
```

每次收缩都在问："去掉左边那个元素，还满足条件吗？"——如果满足，说明还能更短。

## 三个关键细节

### 细节一：为什么用 while 而不是 if

`window_sum >= target` 时可能要连续收缩多次。

```python
# 如果写成 if，只收缩一次
if window_sum >= target:       # 错了！可能还能继续收缩
    ...

# 必须用 while，收缩到不满足条件为止
while window_sum >= target:    # 正确
    ...
```

**if 会漏掉"收缩多次"的情况**，导致答案偏大。

### 细节二：初始值用 float('inf')

因为要求"最小值"，初始值必须是一个**比任何答案都大**的数。

```python
ans = float('inf')     # inf 比任何数都大，min 一定能更新它
ans = min(ans, length) # 第一次一定能更新
```

**最后要判断**：如果一次都没更新过（找不到满足条件的子数组），返回 0。

### 细节三：求和用变量维护，别每次重新算

```python
# 错误：每次重新求和，退化成 O(n²)
for right in range(n):
    for left in range(right):      # 重新算窗口和
        ...
```

**维护 `window_sum` 变量**才是 O(n) 的关键。

## 和快慢指针的区别

| 特征 | 快慢指针 | 滑动窗口 |
|---|---|---|
| 指针方向 | 同向 | 同向 |
| 核心动作 | 覆盖/搬运 | 扩张+收缩 |
| slow 的含义 | 答案位置 | 窗口左边界 |
| 典型场景 | 去重、移除 | 满足某条件的区间 |

**滑动窗口是快慢指针的"升级版"**——slow 不再只管搬运，而是动态调整窗口大小。

## 小结

- 滑动窗口：**right 扩张，left 收缩**，维护窗口内的信息
- 扩张加入、满足条件就收缩——每一步都在找"最短的满足条件的"
- `left` 和 `right` 都只往前走 → **O(n)**
- 用 `while` 收缩（不是 if）、用 `float('inf')` 初始化最小值
- 维护窗口和变量，别每次重新算
