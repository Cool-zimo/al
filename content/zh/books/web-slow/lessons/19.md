# 作用域：变量住在哪一层

> 为什么函数里定义的变量，外面用不了？为什么外面定义的变量，函数里能用？这一课把"作用域"讲清楚，从此不再被 `ReferenceError` 搞懵。

## 函数内的变量外面看不见

```js
function demo() {
    let secret = "我是函数里的秘密";
    console.log(secret);   // 没问题
}

demo();
console.log(secret);       // 报错：secret is not defined
```

`secret` 是在函数 `demo` 里面用 `let` 声明的，它的"家"就在 `demo` 内部。**出了这个函数的花括号，它就不存在了。**

这就是**局部作用域**：函数体是一个封闭的小房间，里面声明的变量只在房间里有效。

## 全局变量：在外面声明的

```js
let globalMsg = "我是全局变量";

function demo() {
    console.log(globalMsg);   // 函数里能读到全局变量
}

demo();                       // "我是全局变量"
console.log(globalMsg);       // 外面也能读到
```

**在函数外面用 `let` 声明的变量是"全局变量"，函数内外都能用。**

规则一句话：**里面的能看见外面的，外面的看不见里面的。**

```js
let outside = "外面的";

function demo() {
    let inside = "里面的";
    console.log(outside);    // 可以，函数里能看外面
}

console.log(inside);         // 报错，外面看不到里面
```

## 同名遮蔽：离得近的说了算

```js
let name = "全局张三";

function demo() {
    let name = "局部李四";     // 和全局同名
    console.log(name);        // "局部李四"
}

demo();
console.log(name);            // "全局张三"
```

**当内外有同名变量时，函数里取的是"离得近的那个"——也就是自己内部的。**这叫"遮蔽"：局部变量把全局变量遮住了。

注意：函数里并没有修改全局的 `name`，它只是**新声明了一个同名局部变量**。全局那个还在，出去之后读到的还是它。

## 翻车现场一：忘记用 let，意外改了全局变量

```js
let count = 0;

function add() {
    count = count + 1;   // 没用 let，用的是全局 count，反而改了它
}

add();
console.log(count);      // 1
```

这段代码能跑，但**函数悄悄改了外面的全局变量**。项目一大，你根本不知道谁在改 `count`，bug 极难查。更好的写法是把 `count` 作为参数传进去，`return` 结果出来。

## 翻车现场二：在循环里声明的变量被循环外误用

```js
function printNumbers() {
    for (let i = 0; i < 3; i++) {
        console.log(i);
    }
    console.log(i);   // 报错：i is not defined
}

printNumbers();
```

后果：`let i` 是在 `for` 的圆括号里声明的，**它的作用域就在 for 那对花括号里**，循环结束 `i` 就消失了。想在外面用，就得在外面用 `let` 先声明。

## 作用域的嵌套

```js
let a = "全局a";

function outer() {
    let b = "outer 的 b";
    function inner() {
        let c = "inner 的 c";
        console.log(a);   // 全局a：可以，往上找
        console.log(b);   // outer 的 b：可以，再往上找
        console.log(c);   // inner 的 c：自己就有
    }
    inner();
    console.log(c);       // 报错：outer 里看不到 inner 的 c
}

outer();
```

**作用域像洋葱，一层套一层。找变量时从里往外一层层找，找到了就停下；出去了就再也看不到里面的。**

## 小结

- 函数内部 `let` 的变量是局部的，外面用不了。
- 函数外面的变量是全局的，里面能用。
- 内外同名时，近的那个说了算（遮蔽）。
- 规则：里面的看得见外面的，外面的看不见里面的。

## 随堂练习

```quiz
type: js
q: 写一个函数 double，接收一个数字 n，返回 n * 2。要求函数里不要声明任何会污染全局的变量。
func: double
starter: |
  function double(n) {
      // 在这里写
  }
cases: |
  3 -> 6
  10 -> 20
  -4 -> -8
hint: 直接用 return n * 2，不需要额外变量
explain: 参数是局部变量，return 直接把计算结果送出去，全程不碰全局。
```
