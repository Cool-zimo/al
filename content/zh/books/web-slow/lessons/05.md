# 输出与调试：让程序告诉你它在干什么

> 这一节解决"代码写错了怎么知道"的问题。学会看报错信息、用 console.log 和 alert 输出，你就能自己解决大部分问题。

## 三种"说话"方式

程序跑起来后，你怎么知道它内部发生了什么？有三种常用方式跟程序"对话"：

| 方式 | 写法 | 在哪里看到 | 适合场景 |
|---|---|---|---|
| 控制台打印 | `console.log(...)` | 浏览器 Console 面板 | 日常调试，打什么都行 |
| 弹窗 | `alert(...)` | 浏览器弹出对话框 | 快速提醒、测试 |
| 页面上显示 | 操作 DOM | 网页本身 | 正式给用户看的内容 |

## `console.log`：最常用的调试工具

前面几课一直在用。它能在控制台打印任何东西：

```js
console.log("一条消息");
console.log(123);
console.log(true);

let name = "张三";
console.log(name);

let user = { name: "李四", age: 20 };
console.log(user);
```

最后一个会打印出整个对象的结构，非常方便看复杂数据。

**调试技巧**：代码不按预期工作时，在关键位置加 `console.log` 看看值对不对：

```js
let price = "50";
let count = 3;
console.log("price 的值是：", price);  // 看看 price 到底是什么
console.log("count 的值是：", count);
let total = price * count;  // 这里可能出问题
console.log("total =", total);
```

## `alert`：弹一个框

```js
alert("操作成功！");
```

会在浏览器弹出一个对话框，用户必须点"确定"才能继续。它**会卡住页面**，所以不适合在循环里用，也不适合正式产品里频繁使用。

但在你初学阶段，它有个好处：**不用开控制台就能看到结果**。写个小页面双击打开，加一行 `alert` 就能验证代码跑了没有。

## 看报错信息的第一行

代码写错了，浏览器会在控制台报红色错误。学会读报错信息，你就成功了一半。

举个���：

```js
let name = "张三";
console.log(nam);  // 少打了一个 e
```

报错信息：

```
Uncaught ReferenceError: nam is not defined
    at index.html:5
```

关键信息就三个：

1. **`ReferenceError`** → 类型：引用错误（找不到这个变量）
2. **`nam is not defined`** → 原因：nam 没有被定义
3. **`at index.html:5`** → 位置：index.html 第 5 行

**第一行的错误信息就是你最好的线索。** 它告诉你"什么错了"和"大概在哪一行"。

## 常见报错速查表

| 报错信息 | 意思 | 常见原因 |
|---|---|---|
| `xxx is not defined` | 变量没声明就用 | 拼写错、忘记 let/const |
| `Unexpected token` | 语法写错了 | 少分号、括号不配对 |
| `Cannot read properties of null` | 找不到元素 | DOM 操作的对象不存在 |
| `xxx is not a function` | 当函数调用的东西不是函数 | 变量名冲突、拼写错 |

## 翻车现场一：拼写错误导致 `is not defined`

```js
let userName = "张三";
console.log(usreName);  // 拼错了！
```

后果：报 `ReferenceError: usreName is not defined`。检查报错指向的那一行，看看变量名是不是拼错了。**这种低级错误占了新手 bug 的一大半**，养成仔细看变量名的习惯。

## 翻车现场二：alert 放在循环里

```js
for (let i = 0; i < 100; i++) {
    alert(i);  // 弹 100 次！
}
```

后果：页面卡死，你必须点 100 次"确定"才能恢复。alert 会**阻塞**代码执行。调试循环时应该用 `console.log` 而不是 `alert`。

## 小结

- `console.log()` 打印到控制台，是日常调试主力。
- `alert()` 弹窗提醒，会卡住页面，初学方便但别滥用。
- 报错信息第一行告诉你"什么错了"和"在哪一行"，学会读它。
- 代码不工作时，在关键位置加 `console.log` 逐段排查。

```quiz
type: js
q: 写一个函数 debugValue，接收参数 x，用 console.log 打印"值是："加上 x，然后返回 x 本身。
func: debugValue
starter: |
  function debugValue(x) {
      // 在这里写
  }
cases: |
  42 -> 42
  "hello" -> "hello"
hint: console.log("值是：" + x); return x;
explain: console.log 负责打印，return 负责返回原值。
```
