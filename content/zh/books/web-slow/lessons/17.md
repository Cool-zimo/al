# 参数：让函数能换着用

> 上一课的函数每次都干一模一样的事。这一课学参数，让函数能"吃进去不同的数据，做出不同的结果"——这是函数真正好用的地方。

## 形参和实参

```js
function sayHi(name) {          // name 是"形参"（定义时占个位）
    console.log("早上好，" + name);
}

sayHi("王老师");                // "王老师"是"实参"（调用时真给的值）
sayHi("李四");
```

- **形参**：定义函数时小括号里的名字，相当于一个"占位符变量"。
- **实参**：调用函数时真正传进去的值。

调用时，实参的值会赋给对应的形参，函数体里就能用这个名字。

## 多个参数

形参之间用逗号隔开，调用时实参也用逗号隔开：

```js
function introduce(name, age, city) {
    console.log("我叫" + name + "，今年" + age + "岁，来自" + city);
}

introduce("张三", 20, "北京");
// 我叫张三，今年20岁，来自北京

introduce("李四", 25, "上海");
// 我叫李四，今年25岁，来自上海
```

**位置对应**：第一个实参给第一个形参，第二个给第二个。顺序不能乱。

## 参数没传就是 undefined

```js
function greet(name) {
    console.log("你好，" + name);
}

greet();            // 没传参数
// 你好，undefined
```

实参没传时，形参的值是 `undefined`。这个坑在第 2 课见过——任何变量没赋值就是 `undefined`。所以函数里用到参数前，最好先判断一下：

```js
function greet(name) {
    if (name === undefined) {
        name = "游客";
    }
    console.log("你好，" + name);
}

greet();            // 你好，游客
greet("张三");      // 你好，张三
```

更省事的写法是用**默认值**，直接在形参后面写 `= 默认值`：

```js
function greet(name = "游客") {
    console.log("你好，" + name);
}

greet();            // 你好，游客
greet("张三");      // 你好，张三
```

`name = "游客"` 的意思是：如果调用时没传 `name`，就自动用 `"游客"`。

## 翻车现场一：形参和实参个数对不上

```js
function add(a, b) {
    return a + b;
}

add(3);     // b 没传，是 undefined，结果是 NaN
```

后果：`3 + undefined` 等于 `NaN`。**参数个数对不上不会报错，但结果会莫名其妙，这是最难查的 bug 之一。**

## 翻车现场二：把形参当成了"全局变量"

```js
function setName(name) {
    name = "改不了";      // 这里改的是形参的副本
}

let myName = "张三";
setName(myName);
console.log(myName);      // 还是"张三"
```

**基本类型（数字、字符串）传进函数后，函数里改它不影响外面。**想改外面的值，得 `return` 出来再重新赋值（下一课讲）。

## 参数默认值的高级用法

默认值可以是任意表达式，甚至依赖别的形参：

```js
function makeMenu(main, side = "米饭") {
    console.log(main + " + " + side);
}

makeMenu("红烧肉");        // 红烧肉 + 米饭
makeMenu("牛排", "意面");  // 牛排 + 意面
```

注意：有默认值的参数通常写在后面。如果写在前面，调用时想用默认值就得显式传 `undefined`：

```js
function makeMenu(side = "米饭", main) { ... }

makeMenu(undefined, "红烧肉");   // 必须这么写才能用默认值，很别扭
```

## 小结

- 形参是定义时的占位变量，实参是调用时传进去的真值。
- 多个参数用逗号隔开，按位置一一对应。
- 实参没传时形参是 `undefined`，结果往往是 `NaN`。
- 用 `形参 = 默认值` 可以避免 `undefined` 的尴尬。
