# 比较：让程序会判断

> 这一节解决"程序怎么判断对不对"的问题。比较运算符是 `if` 语句的基础，而 `=` 和 `===` 的区别是新手必踩的超级大坑。

## 比较就是"做判断题"

生活里你经常做判断：

- 今天气温 **高于** 30 度吗？
- 我的余额 **够不够** 买这个东西？
- 这两个人 **是不是** 同一个人？

程序里用**比较运算符**来做这些判断，结果永远是 `true`（对）或 `false`（错）：

| 运算符 | 意思 | 例子 | 结果 |
|---|---|---|---|
| `>` | 大于 | `5 > 3` | `true` |
| `<` | 小于 | `5 < 3` | `false` |
| `>=` | 大于等于 | `5 >= 5` | `true` |
| `<=` | 小于等于 | `3 <= 2` | `false` |
| `===` | 严格等于 | `5 === 5` | `true` |
| `!==` | 严格不等于 | `5 !== 3` | `true` |

```js
console.log(10 > 5);   // true
console.log(10 < 5);   // false
console.log(10 === 10); // true
console.log(10 !== 5);  // true
```

**注意结果是 `true` 或 `false`**——布尔值。比较的本质就是"出一道判断题，回答对还是错"。

## `===` 是"严格等于"，`=` 是"装进去"

这是**超级大坑**，务必记牢：

```js
let x = 5;   // 把 5 装进 x（赋值）
console.log(x === 5);  // 判断 x 是不是等于 5（比较）→ true
```

| 写法 | 叫什么 | 干什么 | 例子 |
|---|---|---|---|
| `=` | 赋值运算符 | 把右边的值装进左边的变量 | `let a = 3` |
| `===` | 严格等于 | 判断左右两边是否相等，返回 true/false | `3 === 3` → true |
| `!==` | 严格不等于 | 判断左右两边是否不相等 | `3 !== 4` → true |

**生活类比**：`=` 就像往盒子里放东西，`===` 就像拿两个东西放天平上比一比。

```js
let age = 20;       // ✅ 赋值：把 20 装进 age
console.log(age === 20);  // ✅ 比较：age 等于 20 吗？true
console.log(age === 30);  // ✅ 比较：age 等于 30 吗？false
```

## 为什么是三个等号？

JS 里还有个 `==`（两个等号），它会"自作聪明"地帮你转换类型：

```js
console.log(5 == "5");   // true（"5" 被偷偷转成了数字）
console.log(5 === "5");  // false（类型不同：number vs string）
```

`===` 更严格：值和类型都必须一样。`"5"` 是字符串，`5` 是数字，所以 `===` 说它们不相等。

**写代码时一律用 `===`，不要用 `==`。** 这是行业共识，能帮你避开无数隐蔽 bug。

## 比较的结果是布尔值

```js
let isAdult = age >= 18;  // 如果 age 是 20，isAdult 就是 true
console.log(isAdult);     // true
```

比较表达式的结果是 `true` 或 `false`，可以直接装进变量里。这在下一课的 `if` 语句里会大量用到。

## 翻车现场一：把 `=` 当成"等于"来比较

```js
let score = 80;
if (score = 60) {  // 错！这里把 60 装进了 score，结果是 60（真值）
    console.log("及格了");
}
```

后果：**条件永远为真**。`score = 60` 是赋值，赋值表达式的结果是 60，60 在 if 里被当作 true。这段代码不管 score 原来是多少，都会打印"及格了"。正确写法：`score === 60`。

## 翻车现场二：用 `==` 导致类型转换坑

```js
console.log("" == 0);      // true（空字符串被转成了 0）
console.log(null == undefined);  // true
console.log("0" == false);  // true
```

后果：这些结果违反直觉，导致逻辑错误。比如 `"" == 0` 是 true，你本意是"空字符串不等于 0"。**永远用 `===`，这些坑自动消失。**

## 小结

- 比较运算符：`>` `<` `>=` `<=` `===` `!==`，结果永远是 `true` 或 `false`。
- `=` 是赋值（装进去），`===` 是比较（判断是否相等）。
- 永远用 `===` 不用 `==`，避免类型自动转换的坑。
- 比较的结果可以装进变量，是布尔值。
