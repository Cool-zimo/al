# 且或非：组合多个条件

> 这一节解决"怎么把多个判断合在一起"的问题。就像生活里说"便宜**而且**好用"——要同时满足两个条件才行。

## 生活里的组合判断

你网购时会想：

- 价格 < 100 **而且** 评分 > 4.5 → 买！（两个条件都要满足）
- 是 VIP **或者** 今天打折 → 免运费（满足一个就行）
- 库存 **不是** 0 → 可以下单（反过来想）

程序里用三个符号来表达：

| 符号 | 名称 | 生活说法 | 规则 |
|---|---|---|---|
| `&&` | 逻辑与（AND） | "而且" | 两边都 true 才为 true |
| `||` | 逻辑或（OR） | "或者" | 有一个 true 就为 true |
| `!` | 逻辑非（NOT） | "不是" | true 变 false，false 变 true |

## `&&` 逻辑与：两边都要对

```js
let price = 80;
let rating = 4.8;

if (price < 100 && rating > 4.5) {
    console.log("买它！");
}
// price < 100 → true, rating > 4.5 → true, true && true → true
```

| 左边 | 右边 | `&&` 结果 |
|---|---|---|
| true | true | **true** |
| true | false | false |
| false | true | false |
| false | false | false |

**只有两个都 true，结果才是 true。** 像"便宜**而且**好用"——有一个不满足就不买。

## `||` 逻辑或：满足一个就行

```js
let isVip = false;
let isSale = true;

if (isVip || isSale) {
    console.log("免运费！");
}
// false || true → true
```

| 左边 | 右边 | `||` 结果 |
|---|---|---|
| true | true | **true** |
| true | false | **true** |
| false | true | **true** |
| false | false | false |

**只要有一个 true，结果就是 true。** 像"VIP**或者**打折"——满足一个就免运费。

## `!` 逻辑非：反过来

```js
let isSoldOut = false;

if (!isSoldOut) {
    console.log("可以下单");
}
// !false → true
```

`!` 就是"取反"。`!true` 是 false，`!false` 是 true。

常见用法：判断"不是空"：

```js
let name = "";
if (!name) {
    console.log("名字不能为空");
}
```

## 短路：聪明的偷懒机制

`&&` 和 `||` 有个有趣的特性叫**短路**：

- `&&`：左边为 false 时，**右边不用看了**，结果一定是 false
- `||`：左边为 true 时，**右边不用看了**，结果一定是 true

```js
true || console.log("不会执行");
// 左边已经是 true 了，右边不执行

false && console.log("不会执行");
// 左边已经是 false 了，右边不执行
```

这个特性在实际代码里经常用来写"安全判断"：

```js
let user = null;
console.log(user && user.name);  // null，不会报错
// 如果 user 是 null，左边就是 null（假值），右边不执行，不会报错
```

## 组合起来用

```js
let age = 25;
let hasTicket = true;
let isVip = false;

if (age >= 18 && hasTicket || isVip) {
    console.log("可以入场");
}
```

理解优先级：`&&` 比 `||` 先算。上面相当于 `(age >= 18 && hasTicket) || isVip`。

**建议加括号让意图更清晰：**

```js
if ((age >= 18 && hasTicket) || isVip) {
    console.log("可以入场");
}
```

## 翻车现场一：把 `&&` 和 `||` 混用没加括号

```js
if (age >= 18 && hasTicket || isVip) {
    // 意图：18岁以上且有票，或者VIP也可以
}
```

后果：虽然这里结果碰巧对，但逻辑可读性极差。别人（包括一周后的你自己）读不懂。**多个条件组合时一定加括号明确优先级。**

## 翻车现场二：连续比较没用 `&&`

```js
let score = 85;
if (60 <= score <= 100) {  // 数学写法，JS 不支持！
    console.log("有效分数");
}
```

后果：报错或结果不对。JS 不支持数学里的连写。正确写法：

```js
if (score >= 60 && score <= 100) {
    console.log("有效分数");
}
```

## 小结

- `&&`（且）：两边都为 true 才为 true。
- `||`（或）：有一个为 true 就为 true。
- `!`（非）：取反，true 变 false，false 变 true。
- `&&` 和 `||` 有短路特性。
- 多条件组合时**加括号**让意图清晰。
