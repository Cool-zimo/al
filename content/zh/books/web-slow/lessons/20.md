# 数组方法入门：forEach / map / filter

> 第 13 课我们学 for 循环遍历数组。这一课学三个"自带轮子"的数组方法，写起来更短、更好读。先建立直觉，不用纠结细节。

## forEach：替你跑每一遍循环

以前用 for 遍历数组：

```js
let fruits = ["苹果", "香蕉", "橙子"];

for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}
```

用 `forEach` 可以写成：

```js
fruits.forEach(function (item) {
    console.log(item);
});
```

**`forEach` 的意思是"对数组里的每一个元素，都执行一次这个函数"。**你只要告诉它"每个元素要干什么"，它负责跑遍整个数组。

`item` 就是当前这一遍的元素，第 1 遍是 `"苹果"`，第 2 遍 `"香蕉"`，第 3 遍 `"橙子"`。

## map：把每个元素变一变，得到新数组

`map` 也是跑遍每个元素，但它会**收集每次的返回值，拼成一个新数组**返回给你：

```js
let nums = [1, 2, 3];

let doubled = nums.map(function (n) {
    return n * 2;
});

console.log(doubled);   // [2, 4, 6]
console.log(nums);      // [1, 2, 3]，原数组没变
```

**`map` 是"一对一映射"：每个元素按规则变一下，出来一个新数组。**原数组不会被改动。

把学生名字抽出来：

```js
let students = [
    { name: "张三", score: 85 },
    { name: "李四", score: 92 }
];

let names = students.map(function (s) {
    return s.name;
});

console.log(names);   // ["张三", "李四"]
```

## filter：按条件筛出想要的元素

`filter` 跑遍每个元素，你返回 `true` 表示"留下"，返回 `false` 表示"丢掉"：

```js
let scores = [55, 82, 97, 60, 43];

let passed = scores.filter(function (n) {
    return n >= 60;
});

console.log(passed);   // [82, 97, 60]
```

筛出及格的：

```js
let students = [
    { name: "张三", score: 85 },
    { name: "李四", score: 55 },
    { name: "王五", score: 92 }
];

let passed = students.filter(function (s) {
    return s.score >= 60;
});

console.log(passed);
// [{ name: "张三", score: 85 }, { name: "王五", score: 92 }]
```

**`filter` 不会改变原数组，只返回一个新数组。**

## 三个方法对比

| 方法 | 作用 | 返回值 |
|---|---|---|
| forEach | 每个元素执行一遍（用来做事） | undefined |
| map | 每个元素变一下 | 新数组 |
| filter | 按条件筛选 | 新数组 |

**什么时候用哪个**：只是打印或改外部状态 → `forEach`；想得到一个变换后的数组 → `map`；想挑出一部分 → `filter`。

## 翻车现场一：以为 forEach 会返回新数组

```js
let nums = [1, 2, 3];

let result = nums.forEach(function (n) {
    return n * 2;     // forEach 会忽略 return 的值
});

console.log(result);   // undefined，不是 [2, 4, 6]
```

后果：`result` 是 `undefined`。**想拿到新数组就要用 `map`，`forEach` 的返回值永远是 `undefined`。**

## 翻车现场二：map 里忘了写 return

```js
let nums = [1, 2, 3];

let doubled = nums.map(function (n) {
    n * 2;            // 算了，但没 return
});

console.log(doubled);   // [undefined, undefined, undefined]
```

后果：数组长度对，但每一项都是 `undefined`。**`map` 必须 return 出这一项的新值，否则拿不到东西。**

## 箭头函数的简写（预习）

现在先用 `function` 写法，后面还会学更短的箭头函数。先知道有这回事：

```js
// 现在这么写
let doubled = nums.map(function (n) { return n * 2; });

// 以后会这么写（更短）
let doubled = nums.map(n => n * 2);
```

**含义一模一样**，只是写法不同。慢班先吃透 `function` 写法，以后遇到箭头函数不会懵。

## 小结

- `forEach` 遍历做事，不返回值。
- `map` 变换每一项，返回新数组。
- `filter` 按条件筛选，返回新数组。
- 三个方法都**不改变原数组**。
- 最容易忘的是 `map` 和 `filter` 里必须 `return`。

## 随堂练习

```quiz
type: js
q: 用 map 把数组 [1, 2, 3, 4] 每一项变成它的平方（n * n），返回新数组。
func: squareAll
starter: |
  function squareAll(arr) {
      // 在这里写，用 map
  }
cases: |
  [1,2,3,4] -> [1,4,9,16]
hint: arr.map(function(n){ return n * n; })
explain: map 负责跑遍每一项并把 return 的值收集成新数组。
```
