# while 循环与什么时候用哪个

> 这一节解决"什么时候用 while 而不是 for"的问题。两种循环各有适用场景，理解它们的区别能帮你写出更合适的代码。

## while：只要条件满足就一直做

`while` 循环的逻辑很简单：**只要条件为 true，就一直重复。**

```js
let count = 1;

while (count <= 5) {
    console.log("第 " + count + " 次");
    count++;
}
```

输出：

```
第 1 次
第 2 次
第 3 次
第 4 次
第 5 次
```

**语法：**

```js
while (条件) {
    // 条件为 true 时重复执行
}
```

和 `for` 的区别：`while` 只有"条件"这一个部分，`for` 有"初始化 + 条件 + 更新"三个部分。`while` 更简洁，但需要你自己在循环体里更新条件变量。

## for vs while：什么时候用哪个？

| 场景 | 用 for | 用 while |
|---|---|---|
| 知道要跑多少次 | ✅ 比如"数到 10" | 也行但麻烦 |
| 知道明确的结束条件 | ✅ 比如"遍历 5 个元素" | ✅ |
| 不知道要跑多少次 | 不太方便 | ✅ 比如"一直问到答对为止" |
| 条件依赖外部事件 | 不太方便 | ✅ 比如"等到用户点按钮" |

**经验法则：**

- **知道循环次数** → 用 `for`
- **不知道循环次数，只知道停止条件** → 用 `while`

```js
// 知道次数 → for
for (let i = 0; i < 10; i++) {
    console.log(i);
}

// 不知道次数 → while
let answer = "";
while (answer !== "北京") {
    answer = prompt("中国的首都是哪里？");  // 一直问直到答对
}
```

## 死循环：永远停不下来

如果 `while` 的条件永远为 true，循环就永远不会结束——这叫**死循环**：

```js
let i = 1;
while (i <= 5) {
    console.log(i);
    // 忘记写 i++ 了！
}
```

后果：这段代码会**永远**打印 1，浏览器卡死，只能强制关闭标签页。**死循环是新手最常见的错误之一。**

**为什么停不下来？** 条件是 `i <= 5`，但 i 永远是 1，永远满足 `<= 5`，所以永远不会停。

**避免死循环的三条铁律：**

1. 确保循环条件**最终会**变成 false
2. 确保循环体里**有代码**能让条件变量往"停止方向"变化
3. 写完后问自己："这个条件最终会不会变 false？"

```js
// 正确：i 在增长，最终会超过 5
let i = 1;
while (i <= 5) {
    console.log(i);
    i++;  // i 在变化，最终 i 会变成 6，循环结束
}
```

## 用 while 做"猜数字"游戏

```js
let secret = 42;
let guess = 0;

while (guess !== secret) {
    guess = Number(prompt("猜一个数字："));
    if (guess < secret) {
        console.log("太小了");
    } else if (guess > secret) {
        console.log("太大了");
    }
}
console.log("猜对了！");
```

这里你**不知道**用户要猜几次才能猜对，所以无法用 for（for 需要知道次数）。这就是 while 的用武之地。

## do...while：至少跑一次

还有一种变体叫 `do...while`：先执行一次，再判断条件：

```js
let input = "";
do {
    input = prompt("请输入密码：");
} while (input !== "123456");
```

和普通 while 的区别：do...while **至少执行一次**，因为条件判断在后面。

## 翻车现场一：while 里忘记更新条件变量（死循环）

```js
let count = 0;
while (count < 3) {
    console.log("hello");
    // 忘了 count++！count 永远是 0
}
```

后果：无限打印 "hello"，浏览器卡死。**每次写 while，都要确认循环体里有让条件变量变化的代码。**

## 翻车现场二：用 for 但场景其实不知道次数

```js
// 想读取文件直到结束，但不知道有多少行
for (let i = 0; ???; i++) {  // 条件写不出来
    // ...
}
```

后果：写不出合适的终止条件。这种场景应该用 while：`while (hasNextLine()) { ... }`。**不知道次数时，别硬用 for。**

## 小结

- `while (条件) { ... }`：条件为 true 就一直重复。
- **知道次数用 for，不知道次数用 while**。
- 死循环是因为条件永远为 true，通常是因为忘记更新变量。
- do...while 至少执行一次，条件判断在后面。

## 随堂练习

```quiz
type: js
q: 写一个函数 countdown，接收参数 n，用 while 循环从 n 打印到 1（每次减 1），最后返回 "发射"。
func: countdown
starter: |
  function countdown(n) {
      // 在这里写
  }
cases: |
  3 -> "发射"
  1 -> "发射"
hint: while (n > 0) { console.log(n); n--; } return "发射";
explain: while 循环条件依赖 n 的变化，n-- 让循环最终停止。
```
