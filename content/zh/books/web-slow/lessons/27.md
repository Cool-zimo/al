# 搭结构与样式：先把壳搭起来

> 上一课定好了数据和函数。这一课先把页面的"骨架"和"样子"搭出来——输入框、按钮、列表容器。逻辑先留空，结构先跑通。

## HTML 结构

```html
<div class="todo-app">
  <h1>我的待办清单</h1>

  <div class="input-area">
    <input id="todo-input" placeholder="添加新任务...">
    <button id="add-btn">添加</button>
  </div>

  <ul id="todo-list"></ul>
</div>
```

**三个关键元素，各自有明确分工：**

- `#todo-input`：用户输入新任务的输入框。
- `#add-btn`：点击后把输入的内容加进列表。
- `#todo-list`：`<ul>` 列表容器，任务项都挂在这里。

## 基础样式

```css
.todo-app {
  width: 400px;
  margin: 40px auto;
  font-family: sans-serif;
}

.input-area {
  display: flex;
  gap: 8px;
  margin-bottom: 16px;
}

#todo-input {
  flex: 1;
  padding: 8px;
  font-size: 16px;
}

#add-btn {
  padding: 8px 16px;
  font-size: 16px;
}

#todo-list {
  list-style: none;
  padding: 0;
}

#todo-list li {
  display: flex;
  justify-content: space-between;
  padding: 8px;
  border-bottom: 1px solid rgb(238, 238, 238);
}
```

**结构 + 样式先把"壳"撑起来，列表部分先空着。**下一步才是用 JS 把数据渲染成 `<li>`。

## 先在 JS 里拿到元素

```js
let input = document.querySelector("#todo-input");
let addBtn = document.querySelector("#add-btn");
let list = document.querySelector("#todo-list");

let todos = [];
```

**把要操作的元素一次性取好存进变量，别每次用都查一遍。**这是慢班最重要的代码组织习惯之一。

## 翻车现场一：input-area 用了 flex 但子元素没设 flex:1

```css
.input-area { display: flex; }
/* 忘了给 input 设 flex: 1 */
```

后果：输入框挤在左边，按钮和输入框宽度差不多，布局很丑。**flex 布局里想让某个子元素"撑满剩余空间"，必须给它 `flex: 1`。**

## 翻车现场二：ul 的默认圆点忘了去掉

```css
/* 忘了写 #todo-list { list-style: none; } */
```

后果：每个任务前面都带个小黑点，很丑。**做自定义列表几乎都要先 `list-style: none` 清掉默认样式。**

## 为什么先搭结构再写逻辑

1. **能看到效果**：结构搭起来刷新就有东西显示，反馈快、有成就感。
2. **元素 id 定了，JS 才能对号入座**：`#todo-input`、`#add-btn`、`#todo-list` 这三个 id 就是 JS 和 HTML 之间的"约定"。
3. **样式一次写好，后面不用反复调**：渲染逻辑只管往容器里塞元素，不用担心样式。

## 小结

- 三个关键元素：输入框、按钮、列表容器，各司其职。
- 先搭结构 + 样式，让页面"看起来像个待办清单"。
- 元素 id 是 JS 和 HTML 之间的约定，写 JS 前先定好。
- 把常用元素一次性取好存进变量。

  }

  }

  }
