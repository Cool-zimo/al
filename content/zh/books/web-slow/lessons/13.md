# 对象：给数据贴上多个标签

> 这一节解决"怎么描述一个具体的东西"的问题。数组只能存一堆同类的东西，对象能把一个东西的多个属性（名字、年龄、城市）打包在一起。

## 数组的局限

数组适合存"一堆同类东西"：

```js
let students = ["张三", "李四", "王五"];  // 一堆名字
```

但如果我想存张三的**所有信息**呢？名字、年龄、城市、爱好……用数组就很别扭：

```js
let zhangsan = ["张三", 20, "北京", "篮球"];  // 谁是谁？顺序一乱就全错
```

`"北京"` 是城市还是爱好？`20` 是年龄还是编号？看着就乱。

## 对象 = 一个东西的"信息卡"

对象用 `{}` 创建，里面是**键值对**（key-value pair）：

```js
let zhangsan = {
    name: "张三",
    age: 20,
    city: "北京",
    hobby: "篮球"
};
```

| 键（key） | 值（value） |
|---|---|
| `name` | `"张三"` |
| `age` | `20` |
| `city` | `"北京"` |
| `hobby` | `"篮球"` |

**生活类比**：对象就像一张填好的登记表。表上每个格子有标签（姓名、年龄、城市），你在格子里填对应的值。

## 用点号取值

想拿对象的某个属性，用**点号**：

```js
let zhangsan = {
    name: "张三",
    age: 20,
    city: "北京"
};

console.log(zhangsan.name);   // "张三"
console.log(zhangsan.age);    // 20
console.log(zhangsan.city);   // "北京"
```

`对象.属性名` 就是"从对象里拿出这个属性的值"。

## 修改和添加属性

```js
let zhangsan = { name: "张三", age: 20 };

// 修改已有属性
zhangsan.age = 21;
console.log(zhangsan.age);  // 21

// 添加新属性
zhangsan.email = "zhangsan@example.com";
console.log(zhangsan.email);  // "zhangsan@example.com"
```

用 `=` 赋值就行。属性存在就改，不存在就新增。

## 为什么要用对象？

**因为真实世界的数据都是"一个东西有多个属性"的结构。**

比如一个商品：

```js
let product = {
    name: "无线鼠标",
    price: 99,
    stock: 50,
    inStock: true
};
```

比如一个订单：

```js
let order = {
    id: "A001",
    items: ["鼠标", "键盘"],
    total: 299,
    status: "已付款"
};
```

如果你用数组存这些信息，代码会变成噩梦。用对象，属性名一目了然，不容易出错。

## 对象里也可以装数组

```js
let student = {
    name: "张三",
    scores: [85, 92, 78, 96],  // 属性值可以是一个数组
    friends: ["李四", "王五"]
};

console.log(student.scores[0]);  // 85（先取 scores 数组，再取下标 0）
```

**取值时可以连着写**：`对象.属性` 拿到数组，再用 `[下标]` 取数组元素。

## 翻车现场一：用数组下标取对象属性

```js
let zhangsan = { name: "张三", age: 20 };
console.log(zhangsan[0]);  // undefined
```

后果：返回 `undefined`。对象是按键名取值的，不是按下标。`zhangsan[0]` 是错的，要写 `zhangsan.name`。**对象和数组的取值方式不同，别混了。**

## 翻车现场二：键名加引号后忘了怎么取

```js
let obj = {
    "first-name": "张",
    "last name": "三"
};

console.log(obj.first-name);  // 报错！
```

后果：键名里有特殊字符（横杠、空格）时，不能用点号，必须用方括号：

```js
console.log(obj["first-name"]);  // "张" ✅
console.log(obj["last name"]);   // "三" ✅
```

**规则**：键名是纯字母数字（不含空格和特殊字符）时用点号；有空格或横杠时用方括号。

## 小结

- 对象用 `{}` 创建，里面是键值对，描述一个东西的多个属性。
- 取值用点号：`对象.属性名`。
- 修改/添加属性用 `=` 赋值。
- 真实数据都是"一个东西有多个属性"的结构，用对象最自然。
- 属性名有空格/横杠时，用方括号 `对象["属性名"]` 取值。
