# 改样式：classList 和直接改 style

> 这课讲两种改样式的方式：推荐用 `classList` 开关 class，应急时用 `style` 直接改。掌握前者，样式就不容易失控。

## classList：给元素加、删、切换 class

```html
<style>
  .red { color: rgb(255, 0, 0); }
  .big { font-size: 24px; }
</style>
<p id="text">一段文字</p>
```

```js
let p = document.querySelector("#text");

p.classList.add("red");      // 加上 class="red"，文字变红
p.classList.add("big");      // 再加上 class="big"，字号变大
p.classList.remove("red");   // 去掉 red，文字恢复
p.classList.toggle("big");   // 有就删、没有就加（切换）
```

**`classList` 是最推荐的改样式方式**：样式规则写在 CSS 里，JS 只负责"开关 class"，结构清晰、好维护。

## toggle 的妙用：点击切换高亮

```html
<button id="btn">点我</button>
```

```js
let btn = document.querySelector("#btn");

btn.addEventListener("click", function () {
    btn.classList.toggle("active");   // 每次点击在"加/删 active"之间切换
});
```

配合 CSS：

```css
.active { background: rgb(33, 150, 243); color: white; }
```

**`toggle` 一句代码就实现了"点一下开、再点一下关"的效果。**

## 直接改 style：应急时用

```js
let box = document.querySelector("#box");

box.style.color = "rgb(255, 0, 0)";
box.style.fontSize = "24px";
box.style.backgroundColor = "rgb(227, 242, 253)";
```

注意两点：

1. **CSS 里的 `font-size`、`background-color` 写成 JS 时去掉横杠，改成驼峰：`fontSize`、`backgroundColor`。**
2. **值的类型是字符串，必须带单位。**`box.style.fontSize = 24` 不生效，要写 `"24px"`。

## 读回样式：getComputedStyle

```js
let box = document.querySelector("#box");

// 读"最终计算出来的样式"
let color = getComputedStyle(box).color;
console.log(color);   // "rgb(255, 0, 0)"
```

**`el.style.xxx` 只能读到内联样式（写在标签 style 里的），读不到 CSS 类的样式。**要读真正生效的值，用 `getComputedStyle(el).xxx`。

## 翻车现场一：颜色写成十六进制，判分读不出来

```js
box.style.backgroundColor = "#e3f2fd";
console.log(getComputedStyle(box).backgroundColor);   // "rgb(227, 242, 253)"
```

后果：你以为写的是 `#e3f2fd`，但浏览器计算后存的是 `rgb(227, 242, 253)`。**凡是写样式判分，写 `rgb(R, G, B)` 格式最稳，逗号后面要留空格。**

## 翻车现场二：font-size 写成 fontSize 却忘了驼峰

```js
box.style["font-size"] = "24px";   // ✗ 不报错，但不生效
box.style.fontSize = "24px";       // ✓
```

后果：第一种写法在 JS 里是给对象加了个奇怪的属性名，不是 CSS 属性。**带横杠的 CSS 属性转成 JS 要用驼峰。**

## classList 的方法小结

| 方法 | 作用 |
|---|---|
| `add("x")` | 加一个 class |
| `remove("x")` | 删一个 class |
| `toggle("x")` | 有就删、没有就加 |
| `contains("x")` | 判断是否包含某个 class，返回 true/false |

```js
if (box.classList.contains("active")) {
    console.log("当前是高亮状态");
}
```

## 小结

- 推荐用 `classList.add / remove / toggle` 开关 class。
- 直接改 `style` 应急，属性名用驼峰、值带单位。
- `el.style.xxx` 只读内联样式，读真实值用 `getComputedStyle`。
- 颜色判分写 `rgb(R, G, B)` 格式最稳。
