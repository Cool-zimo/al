# 综合练习：做一个学生名单

> 这一节把前面学过的所有知识串起来。你会做一个小项目：用数组和对象管理学生名单，实现添加、遍历、筛选、统计等功能。

## 项目目标

做一个"班级学生管理系统"的小程序，功能包括：

1. 存储所有学生信息（对象数组）
2. 打印全班名单
3. 统计及格人数
4. 筛选某个城市的学生
5. 计算全班平均分

## 第一步：定义数据结构

```js
let students = [
    { name: "张三", age: 20, city: "北京", score: 85 },
    { name: "李四", age: 19, city: "上海", score: 92 },
    { name: "王五", age: 21, city: "北京", score: 78 },
    { name: "赵六", age: 20, city: "广州", score: 55 },
    { name: "钱七", age: 22, city: "上海", score: 96 }
];
```

每个学生是一个对象，所有学生组成数组。这就是我们第 14 课学的"对象数组"。

## 第二步：遍历打印全班名单

```js
function printRoster(students) {
    console.log("===== 全班名单 =====");
    for (let i = 0; i < students.length; i++) {
        let s = students[i];
        console.log((i + 1) + ". " + s.name + " | " + s.age + "岁 | " + s.city + " | 分数:" + s.score);
    }
}

printRoster(students);
```

输出：

```
===== 全班名单 =====
1. 张三 | 20岁 | 北京 | 分数:85
2. 李四 | 19岁 | 上海 | 分数:92
3. 王五 | 21岁 | 北京 | 分数:78
4. 赵六 | 20岁 | 广州 | 分数:55
5. 钱七 | 22岁 | 上海 | 分数:96
```

**用到了**：for 循环遍历、对象属性取值、字符串拼接。

## 第三步：统计及格人数

```js
function countPass(students) {
    let passCount = 0;
    for (let i = 0; i < students.length; i++) {
        if (students[i].score >= 60) {
            passCount++;
        }
    }
    return passCount;
}

console.log("及格人数：" + countPass(students));  // "及格人数：4"
```

**用到了**：遍历 + if 条件判断 + 计数器累加。

## 第四步：筛选某个城市的学生

```js
function getStudentsByCity(students, city) {
    let result = [];
    for (let i = 0; i < students.length; i++) {
        if (students[i].city === city) {
            result.push(students[i]);
        }
    }
    return result;
}

let beijingStudents = getStudentsByCity(students, "北京");
console.log(beijingStudents);
// [{ name: "张三", age: 20, city: "北京", score: 85 }, { name: "王五", age: 21, city: "北京", score: 78 }]
```

**用到了**：遍历 + 条件筛选 + push 到新数组。这是第 14 课的经典模式。

## 第五步：计算全班平均分

```js
function calcAverage(students) {
    let total = 0;
    for (let i = 0; i < students.length; i++) {
        total = total + students[i].score;
    }
    let avg = total / students.length;
    return avg;
}

console.log("全班平均分：" + calcAverage(students));  // "全班平均分：81.2"
```

**用到了**：遍历累加 + 除法求平均。

## 全部代码汇总

```js
// 数据
let students = [
    { name: "张三", age: 20, city: "北京", score: 85 },
    { name: "李四", age: 19, city: "上海", score: 92 },
    { name: "王五", age: 21, city: "北京", score: 78 },
    { name: "赵六", age: 20, city: "广州", score: 55 },
    { name: "钱七", age: 22, city: "上海", score: 96 }
];

// 打印名单
function printRoster(list) {
    for (let i = 0; i < list.length; i++) {
        let s = list[i];
        console.log((i + 1) + ". " + s.name + " | " + s.age + "岁 | " + s.city + " | 分数:" + s.score);
    }
}

// 统计及格人数
function countPass(list) {
    let count = 0;
    for (let i = 0; i < list.length; i++) {
        if (list[i].score >= 60) count++;
    }
    return count;
}

// 按城市筛选
function getByCity(list, city) {
    let result = [];
    for (let i = 0; i < list.length; i++) {
        if (list[i].city === city) result.push(list[i]);
    }
    return result;
}

// 计算平均分
function calcAvg(list) {
    let total = 0;
    for (let i = 0; i < list.length; i++) {
        total += list[i].score;
    }
    return total / list.length;
}
```

这 60 行代码用到了**变量、数组、对象、for 循环、if 判断、函数**——前 14 课学的全在这里了。

## 翻车现场一：遍历条件用 `<=` 导致报错

```js
for (let i = 0; i <= students.length; i++) {
    console.log(students[i].name);  // 最后一次 i=5，students[5] 是 undefined
}
```

后果：`students[5]` 是 `undefined`，`undefined.name` 报错。**记住：条件是 `< length`，不是 `<= length`。**

## 翻车现场二：在遍历过程中往数组 push 导致死循环

```js
for (let i = 0; i < students.length; i++) {
    students.push({ name: "新人", score: 60 });  // 数组长度一直在涨！
}
```

后果：length 不断增长，i 永远追不上，死循环。**遍历时不要往原数组里加元素，改用新数组存结果。**

## 小结

- 对象数组是真实项目中最常见的数据结构。
- 遍历 + 条件判断 + 计数器/新数组 是三种核心操作模式。
- 统计用累加器（count++ / total +=），筛选用 push 到新数组。
- 遍历时不要修改原数组长度。
