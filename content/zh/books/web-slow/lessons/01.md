# 代码是什么

> 这一节解决"我写的文字为什么能变成程序"的问题。理解了浏览器怎么跑代码，后面写错了才知道去哪儿找原因。

## 一行一行的命令

你用手机点外卖，其实是在操作一个程序。程序里写满了"如果…就…"的规则。但你不用写那些规则也能用手机——因为程序员已经写好了。今天起，你要学会自己写。

JavaScript（后面简称 JS）是一种**编程语言**。你可以把它理解成你跟浏览器说话的方式。你写一句，浏览器做一件���。

看这个例子：

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8">
    <title>我的第一个程序</title>
  </head>
  <body>
    <script>
      console.log("你好，世界");
    </script>
  </body>
</html>
```

把上面这段保存成 `index.html`，用浏览器打开。然后按 F12（Mac 上是 Cmd+Option+I），切到 Console（控制台）面板，你会看到一行字：

```
你好，世界
```

**这就是你的第一个程序。** 它做了一件很简单的事：让浏览器在控制台里打印了一句话。

## `<script>` 标签是代码的容器

在 HTML 里，`<script>` 标签的作用就像是一个"通知牌"，告诉浏览器："接下来这段不是网页内容，是代码，你要执行它。"

```html
<script>
  console.log("这是代码");
</script>
```

浏览器从上往下读 HTML，读到 `<script>` 就停下来，把里面的代码**一行一行**执行完，再继续往下读。

**放在哪里有讲究：**

| 位置 | 效果 | 推荐度 |
|---|---|---|
| `<head>` 里 | 页面还没显示内容时代码就跑了 | ⚠️ 有时候有问题 |
| `<body>` 最末尾 | 页面内容先出来，代码最后跑 | ✅ 推荐 |
| 单独 `.js` 文件 | 用 `<script src="app.js">` 引入 | ✅ 正式项目用 |

**为什么推荐放 body 末尾？** 因为 JS 经常要操作页面上的元素（比如按钮、文字）。如果代码跑的时候按钮还没被浏览器读到，那就找不到它，会报错。放末尾就保证"页面元素都准备好了，代码再跑"。

## 代码是一行一行往下跑的

这是编程里最重要的一条规则：**代码从第一行开始，一行一行往下执行。**

```js
console.log("第一句");
console.log("第二句");
console.log("第三句");
```

浏览器会依次打印：第一句、第二句、第三句。顺序不会乱，也不会跳过。

想想你煮泡面：烧水 → 放面 → 等三分钟 → 加调料。每一步依赖上一步的结果，顺序不能颠倒。代码也一样。

## `console.log` 是你的嘴巴

`console.log(...)` 的意思是"把括号里的内容打印到控制台"。它是你跟程序对话最常用的工具。

```js
console.log("今天天气不错");
console.log(123);
console.log("我叫张三，今年20岁");
```

打开控制台就能看到输出。**写代码时遇到任何问题，先用 `console.log` 把东西打出来看看**，这是最基础的调试手段。

## 翻车现场一：`<script>` 放错位置导致找不到元素

```html
<!DOCTYPE html>
<html>
  <head>
    <script>
      // 想操作下面的按钮，但按钮还没被读到！
      document.querySelector("button").addEventListener("click", function() {
        alert("点了");
      });
    </script>
  </head>
  <body>
    <button>点我</button>
  </body>
</html>
```

后果：代码报错 `Cannot read properties of null`。因为代码跑的时候 `<button>` 还不存在。解决方法：把 `<script>` 移到 body 末尾，或者用 `window.onload`。

## 翻车现场二：把 JS 代码直接写在 HTML 标签外面

```html
<!DOCTYPE html>
<html>
  <body>
    console.log("你好");  <!-- 错了！没有 script 标签 -->
    <button>点我</button>
  </body>
</html>
```

后果：浏览器以为 `console.log("你好");` 是一段普通文字，直接显示在页面上，代码完全不会执行。浏览器只认 `<script>` 标签里的代码。

## 小结

- JS 是跟浏览器对话的语言，**一行一行往下执行**。
- `<script>` 标签用来告诉浏览器"这是代码"，推荐放 body 末尾。
- `console.log()` 是最基本的输出工具，写代码时随时用它看结果。
- 代码跑的顺序和你写的顺序一模一样，不会乱。

```quiz
type: js
q: 写一个函数 sayHi，用 console.log 打印"你好"，然后返回字符串"done"。
func: sayHi
starter: |
  function sayHi() {
      // 在这里写
  }
cases: |
  -> "done"
hint: console.log 负责打印，return 负责返回值
explain: console.log 是"说出来"，return 是"交出去的结果"
```
