# 找元素：querySelector / querySelectorAll

> 上一课学了 `document` 是入口。这一课学"怎么在 DOM 树里找到一个元素"——这是后面所有操作的前提。

## querySelector：按 CSS 选择器找一个

```js
// 找一个 id 为 title 的元素
let title = document.querySelector("#title");

// 找一个 class 为 active 的元素
let active = document.querySelector(".active");

// 找第一个 <p>
let firstP = document.querySelector("p");
```

**`querySelector(选择器)` 返回第一个匹配到的元素。**它用的是你写 CSS 时的选择器语法：

- `#id名` 找 id
- `.class名` 找 class
- 标签名 找标签

## id 用 #，class 用 .，别搞反

```html
<h1 id="main">标题</h1>
<p class="intro">介绍</p>
```

```js
document.querySelector("#main");     // ✓ 找到 h1
document.querySelector("p.intro");   // ✓ 找到 p
document.querySelector(".intro");    // ✓ 也行
```

**这个 `#` 和 `.` 跟 CSS 里一模一样**，忘掉就会找不到：

```js
document.querySelector("main");   // ✗ 这是找 <main> 标签，不是找 id="main"
```

## querySelectorAll：找所有匹配的

```html
<p class="item">苹果</p>
<p class="item">香蕉</p>
<p class="item">橙子</p>
```

```js
let items = document.querySelectorAll(".item");
console.log(items.length);   // 3

// 可以像数组一样遍历
for (let i = 0; i < items.length; i++) {
    console.log(items[i].textContent);
}
```

**`querySelectorAll` 返回的是一个"类数组"的集合，有 `length`，可以用下标取，但还不是真正的数组。**通常够用了，需要数组方法时可以用 `Array.from(items)` 转换。

## 找不到时返回 null

```js
let el = document.querySelector("#不存在的");
console.log(el);   // null
```

**找不到元素时 `querySelector` 返回 `null`，不是报错，也不是 undefined。**这个细节很重要，因为它决定了你下一步能不能安全地取属性。

## 翻车现场一：找不到的元素还想取属性

```js
let el = document.querySelector("#不存在");
console.log(el.textContent);   // 报错：Cannot read properties of null
```

后果：浏览器报错，后面代码全停。**先判断存不存在再操作：**

```js
let el = document.querySelector("#title");
if (el !== null) {
    el.textContent = "新标题";
}
```

## 翻车现场二：id 选择器忘了写 #

```js
document.querySelector("title");   // 想找 id="title"，却写成了找 <title> 标签
```

后果：返回 `null`，因为页面上没有 `<title>` 标签被匹配到（`<title>` 在 `<head>` 里，且不是想要的元素）。**找 id 必须 `#id`，找 class 必须 `.class`。**

## 选择器的组合用法

```html
<div class="card">
  <p class="name">张三</p>
  <p class="age">20岁</p>
</div>
<div class="card">
  <p class="name">李四</p>
</div>
```

```js
// 找第一个 card 里的 name
let name = document.querySelector(".card .name");
console.log(name.textContent);   // "张三"

// 找所有 card 里的 name
let names = document.querySelectorAll(".card .name");
```

**选择器可以像 CSS 一样组合、嵌套、用逗号并列。**只要你会写 CSS 选择器，就能找元素。

## 小结

- `querySelector(选择器)` 返回第一个匹配的元素。
- `querySelectorAll(选择器)` 返回所有匹配的元素集合。
- id 用 `#`，class 用 `.`，和 CSS 一样。
- 找不到返回 `null`，取属性前要先判断。
