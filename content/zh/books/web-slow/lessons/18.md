# 返回值：函数的"出货口"

> 前面学的函数都是自己 `console.log`。但真实项目里，我们更需要的是"算出一个结果交给外面用"。这一课学 `return`。

## return 是什么

```js
function add(a, b) {
    return a + b;        // 把 a+b 的结果"送出去"
}

let result = add(3, 5);
console.log(result);     // 8
```

`return 表达式` 的意思是：**把这个表达式的值作为函数的执行结果，交还给调用者。**调用者可以把结果存进变量、打印、或者继续参与运算。

对比一下有 return 和没 return 的区别：

```js
function add1(a, b) {
    return a + b;
}
function add2(a, b) {
    console.log(a + b);   // 只是打印，没有 return
}

let x = add1(1, 2);   // x 是 3，可以继续用
let y = add2(1, 2);   // 打印了 3，但 y 是 undefined
console.log(x + 10);   // 13，没问题
console.log(y + 10);   // NaN，因为 y 是 undefined
```

**`console.log` 只是显示在控制台，`return` 才是把结果交给外面。**这是慢班最容易混淆的两个东西。

## 没有 return 就是 undefined

```js
function nothing() {
    let a = 1;
}

console.log(nothing());   // undefined
```

**任何函数，只要执行流程走到结束都没遇到 `return`，它的返回值就是 `undefined`。**这和第 2 课学的"没赋值的变量是 undefined"是同一个逻辑。

## return 后面的代码不再执行

```js
function check(age) {
    if (age >= 18) {
        return "成年人";
    }
    return "未成年人";
}

console.log(check(20));   // "成年人"
console.log(check(15));   // "未成年人"
```

`return` 一执行，函数立刻结束，后面的代码全部跳过：

```js
function demo() {
    return 1;
    console.log("你看不到我");   // 永远不会执行
    return 2;                    // 永远不会执行
}

console.log(demo());   // 1
```

这是"早返回"技巧：**条件满足就直接 return 掉，省得套一层层 if-else。**

## 翻车现场一：写了 return 却没给值

```js
function getScore() {
    let score = 95;
    return;            // 忘了写 score
    score;
}

console.log(getScore());   // undefined
```

后果：返回值是 `undefined`。**`return` 后面必须跟上要返回的东西，否则就等于 `return undefined`。**

## 翻车现场二：在 if 里 return，外面忘了兜底

```js
function getLevel(score) {
    if (score >= 90) return "优秀";
    if (score >= 60) return "及格";
    // 这里忘了写 return
}

console.log(getLevel(50));   // undefined，不是"不及格"
```

后果：小于 60 分时函数走到结尾也没 return，返回 `undefined`。**凡是有 return 的分支函数，想清楚"所有情况都有返回值吗"。**

## 一个函数可以 return 任何东西

```js
function getFirst(arr) {
    return arr[0];        // 返回数组第一个元素
}

function makeUser(name, age) {
    return { name: name, age: age };   // 返回一个对象
}

function isAdult(age) {
    return age >= 18;     // 返回一个布尔值 true / false
}
```

返回布尔值的函数在 if 里特别好用：

```js
function isAdult(age) {
    return age >= 18;
}

if (isAdult(20)) {
    console.log("可以进");
}
```

## 小结

- `return 值` 把结果交给外面；`console.log` 只是打印。
- 没写 return 或 return 后面没值，返回 `undefined`。
- return 执行后函数立刻结束，后面的代码不跑。
- 每个分支都要想清楚：return 到了吗？

## 随堂练习

```quiz
type: js
q: 写一个函数 isEven(n)，如果 n 是偶数返回 true，否则返回 false。
func: isEven
starter: |
  function isEven(n) {
      // 在这里写
  }
cases: |
  2 -> true
  3 -> false
  0 -> true
hint: 用取余运算 n % 2 === 0
explain: 偶数除以 2 余数为 0，判断结果本身就是布尔值，可以直接 return。
```
