# 第 4 章 函数（16-20）

# 函数是什么：把一段代码打包起来

> 前面 15 课你写的代码都是"从上往下一条条执行"。从这一课开始，我们学函数：它能把一段代码打包，想用的时候喊一声名字就跑一遍。这是编程里最值钱的习惯之一。

## 为什么要用函数

先看一段没用函数的代码。张三每天都要跟老师打招呼：

```js
console.log("早上好，王老师");
console.log("早上好，李老师");
console.log("早上好，张老师");
```

如果全班有 40 个老师，就要写 40 行。更要命的是，哪天张三想改口说"老师好"，得一行一行改。

用函数就能打包：

```js
function sayHi(name) {
    console.log("早上好，" + name);
}

sayHi("王老师");
sayHi("李老师");
sayHi("张老师");
```

**同样的招呼，三行写完。**以后想改成"老师好"，只要改函数里面那一处，三句招呼全部跟着变。

函数的三个好处，记住这三句就够：

1. **不用复制粘贴**：同一段逻辑只写一次，到处喊它。
2. **好改**：要改逻辑只改一个地方。
3. **好读**：看到 `sayHi("王老师")`，一眼就知道这句在干什么。

## 函数的定义与调用

定义函数的固定写法：

```js
function 函数名(参数) {
    函数体：要执行的代码
}
```

- `function` 是关键字，照抄。
- 函数名起个能看懂的：`sayHi`、`calcTotal`、`findMax`。
- 参数用小括号包起来，没参数就写空括号 `()`。
- 函数体用花括号 `{}` 包起来。

**定义完不会自动跑**，必须"调用"才执行：

```js
function greet() {
    console.log("你好呀");
}

greet();   // 调用：喊名字 + 括号，这一行才会打印"你好呀"
console.log("我还没跑函数");
greet();   // 可以再喊一次，又打印一次"你好呀"
```

调用就是 `函数名()`。可以调用无数次，每调一次函数体就完整跑一遍。

## 翻车现场一：只写定义不调用

```js
function hello() {
    console.log("我会打印吗？");
}

hello   // ← 忘记写 ()
```

后果：什么都不会打印。**函数名后面没加 `()`，就不是调用，只是一个名字，JS 看一眼就过去了。**

记住：`()` 是"执行"的信号。不加括号，函数就不会跑。

## 翻车现场二：函数写在调用后面

```js
sayHi();   // 这里调用

function sayHi() {
    console.log("你好");
}
```

这段**反而能正常运行**。原因是函数声明会被"整体提升"到当前作用域顶部，所以不管写在上面还是下面都能调到。但这个规则**只对 `function` 声明成立**，第 20 课后会学的函数表达式就不行。现在先记住：为了可读性，尽量把函数写在调用之前。

## 定义和调用的位置关系

推荐顺序：**先定义，后调用**，从上往下读最顺：

```js
function printMenu() {           // 1. 定义
    console.log("1. 登录");
    console.log("2. 注册");
    console.log("3. 退出");
}

printMenu();                     // 2. 调用
```

如果有两个函数互相调用也没关系，只要都定义过就行：

```js
function start() {
    console.log("开始");
    end();       // end 虽然在下面，但也是函数声明，能调到
}

function end() {
    console.log("结束");
}

start();
```

## 小结

- 函数 = 一段代码的名字。用 `function 名字() { ... }` 定义。
- 定义不会执行，必须 `名字()` 调用才执行。
- 同一个函数可以调用很多次，避免复制粘贴。
- 最容易忘的是 `()`：想让它跑就一定要加括号。

## 随堂练习

```quiz
type: js
q: 写一个函数 sayHello，调用它会打印"Hello, world!"。
func: sayHello
starter: |
  function sayHello() {
      // 在这里写
  }
checks:
- (function(){ const logs = []; const orig = console.log; console.log = function (...a) { logs.push(a.join(' ')); }; sayHello(); console.log = orig; return logs.length === 1 && logs[0] === 'Hello, world!'; })()
hint: 在函数体里用 console.log 打印那句话
explain: 定义函数后调用它，函数体里的 console.log 就会执行。
```
