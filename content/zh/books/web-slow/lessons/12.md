# 数组增删改：操作一排盒子

> 这一节解决"怎么往数组里加东西、删东西、改东西"的问题。push、pop、splice 是数组最常用的操作方法，配合遍历几乎能搞定所有列表需求。

## 往数组里加东西：`push`

`push` 的意思是"往数组末尾加一个新元素"：

```js
let fruits = ["苹果", "香蕉"];
fruits.push("橙子");
console.log(fruits);  // ["苹果", "香蕉", "橙子"]
```

`push` 就像在队伍最后面排了一个新的人。加完之后数组长度 +1。

```js
let numbers = [1, 2, 3];
numbers.push(4);
numbers.push(5);
console.log(numbers);  // [1, 2, 3, 4, 5]
```

## 从数组里取东西：`pop`

`pop` 的意思是"把数组最后一个元素拿出来，并从数组中删除"：

```js
let fruits = ["苹果", "香蕉", "橙子"];
let last = fruits.pop();
console.log(last);     // "橙子"（被取出来的元素）
console.log(fruits);   // ["苹果", "香蕉"]（橙子已经被删了）
```

`pop` 做两件事：返回最后一个元素，并且把它从数组里删掉。

> 联想记忆：`push` 是"推入"（往里放），`pop` 是"弹出"（往外取）。

## 在任意位置删/改：`splice`

`splice` 更强大，能在指定位置删除、插入、替换元素。最常用的是"删除"：

```js
let fruits = ["苹果", "香蕉", "橙子", "葡萄"];
fruits.splice(1, 1);  // 从下标 1 开始，删除 1 个元素
console.log(fruits);   // ["苹果", "橙子", "葡萄"]
```

`splice(起始下标, 删除个数)`：

```js
let nums = [10, 20, 30, 40, 50];
nums.splice(2, 2);    // 从下标 2 开始，删 2 个
console.log(nums);    // [10, 20, 50]
```

`splice` 也可以用来插入：

```js
let fruits = ["苹果", "橙子"];
fruits.splice(1, 0, "香蕉");  // 下标1，删0个，插入"香蕉"
console.log(fruits);  // ["苹果", "香蕉", "橙子"]
```

## 遍历数组：把每个元素都看一遍

前面学过用 for 循环遍历。这里再看几个常见场景：

**场景一：打印所有元素**

```js
let students = ["张三", "李四", "王五"];

for (let i = 0; i < students.length; i++) {
    console.log(students[i]);
}
```

**场景二：把每个元素加工后存到新数组**

```js
let numbers = [1, 2, 3, 4];
let doubled = [];

for (let i = 0; i < numbers.length; i++) {
    doubled.push(numbers[i] * 2);
}
console.log(doubled);  // [2, 4, 6, 8]
```

**场景三：统计符合条件的元素个数**

```js
let scores = [85, 92, 78, 96, 63];
let passCount = 0;

for (let i = 0; i < scores.length; i++) {
    if (scores[i] >= 60) {
        passCount++;
    }
}
console.log("及格人数：" + passCount);  // "及格人数：5"
```

## 修改数组中的元素

直接用下标赋值就能改：

```js
let fruits = ["苹果", "香蕉", "橙子"];
fruits[1] = "葡萄";  // 把下标 1 的元素改成"葡萄"
console.log(fruits);  // ["苹果", "葡萄", "橙子"]
```

就像"打开 1 号柜子，把里面的东西换成葡萄"。

## 翻车现场一：push 的返回值不是新数组

```js
let arr = [1, 2, 3];
let result = arr.push(4);
console.log(result);  // 4（不是 [1,2,3,4]！）
```

后果：`push` 返回的是**新数组的长度**（这里是 4），不是新数组本身。想拿到新数组直接用 `arr` 就行。

## 翻车现场二：遍历时修改数组导致混乱

```js
let arr = [1, 2, 3, 4, 5];
for (let i = 0; i < arr.length; i++) {
    arr.push(arr[i] * 10);  // 在遍历时往数组里加东西！
}
console.log(arr);  // [1, 2, 3, 4, 5, 10, 20, 30, 40, 50]（长度变了！）
```

后果：数组长度在遍历过程中不断变化，可能导致无限循环或逻辑混乱。**遍历数组时尽量不要修改数组长度。** 如果需要修改，先存好原始长度或操作副本。

## 小结

- `push(元素)` → 往末尾加元素，返回新长度。
- `pop()` → 取出并删除最后一个元素。
- `splice(下标, 个数)` → 从指定位置删除元素。
- 修改元素：`arr[下标] = 新值`。
- 遍历标准写法：`for (let i = 0; i < arr.length; i++)`。
- 遍历时避免修改数组长度。
