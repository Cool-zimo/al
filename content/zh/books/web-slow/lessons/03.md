# 数据类型：盒子里的东西有不同种类

> 这一节解决"变量里能装什么"的问题。数字、文字、对错——不同的数据种类决定了你能对它做什么操作。

## 三种最基本的类型

盒子（变量）里可以装不同种类的东西。就像冰箱里能放蔬菜、肉、饮料，但你会用不同的方式处理它们——肉要解冻，饮料直接喝。程序里的数据也一样，分种类：

| 类型 | 叫法 | 举例 | 是什么 |
|---|---|---|---|
| 数字 | `number` | `100`、`3.14`、`-5` | 用来算账、计数 |
| 字符串 | `string` | `"你好"`、`'abc'` | 一段文字 |
| 布尔 | `boolean` | `true`、`false` | 对或错（真或假） |

```js
let price = 9.9;          // 数字
let productName = "泡面";  // 字符串
let isAvailable = true;   // 布尔值
```

## 怎么看一个数据的类型：`typeof`

想知道盒子里装的是什么类型，用 `typeof`：

```js
console.log(typeof 100);       // "number"
console.log(typeof "你好");     // "string"
console.log(typeof true);      // "boolean"
console.log(typeof "123");     // "string"（注意！加了引号就是字符串）
```

`typeof` 后面跟一个值或变量名，它会告诉你这个东西是什么类型。

## 字符串是"被引号包住的文字"

字符串的写法是用单引号 `'...'` 或双引号 `"..."` 把文字包起来：

```js
let greeting = "你好";
let name = '张三';
```

单引号和双引号效果一样，选一种坚持用就行。但**必须配对**——开头用单引号，结尾也得用单引号。

## 字符串拼接：把文字接起来

用 `+` 可以把两个字符串接在一起：

```js
let firstName = "张";
let lastName = "三";
let fullName = firstName + lastName;
console.log(fullName);  // "张三"
```

这就像把两段胶带粘在一起。`+` 在数字里是"加法"，在字符串里是"拼接"。

再来个实用的：

```js
let product = "泡面";
let price = 5;
console.log(product + "的价格是" + price + "元");
// 输出：泡面的价格是5元
```

**注意**：`price` 是数字，但和数字混在字符串拼接里时，JS 会自动把它转成字符串。"5" 被接上去，不是做加法。

## 翻车现场一：该用字符串却忘了加引号

```js
let name = 张三;  // 没加引号！
console.log(name);
```

后果：浏览器报 `ReferenceError: 张三 is not defined`。因为没加引号的 `张三` 会被当成"变量名"，浏览器去找一个叫 `张三` 的变量——找不到就报错。**字符串必须加引号。**

## 翻车现场二：引号不配对

```js
let msg = "他说：'你好"';  // 引号乱了
```

后果：语法错误 `SyntaxError`。浏览器读到第二个引号就以为字符串结束了，后面的内容它看不懂。**开头用哪种引号，结尾就用哪种。**

正确写法：

```js
let msg = "他说：'你好'";  // 双引号包单引号，OK
let msg2 = '他说："你好"';  // 单引号包双引号，也OK
```

## 小结

- 三种基本类型：**数字**（用来算）、**字符串**（一段文字，必须加引号）、**布尔**（true/false）。
- `typeof` 可以查看一个值的类型。
- 字符串用 `+` 拼接，把两段文字接在一起。
- 字符串必须用引号包起来，且要配对。
