# 收官：代码组织、常见 bug 复盘与指路

> 这是《网页制作 · 零基础 JavaScript（慢班）》的最后一课。这一课把整个项目的代码组织梳理一遍，复盘三个高频 bug，并告诉你下一步该学什么。

## 完整代码一览

```js
// ===== 数据 =====
let todos = [];

// ===== 元素 =====
let input = document.querySelector("#todo-input");
let addBtn = document.querySelector("#add-btn");
let list = document.querySelector("#todo-list");

// ===== 渲染 =====
function render() {
    list.innerHTML = "";                    // 先清空，防止累加

    todos.forEach(function (todo) {
        let li = document.createElement("li");

        let span = document.createElement("span");
        span.textContent = todo.text;        // 用 textContent，防 XSS
        li.appendChild(span);

        let delBtn = document.createElement("button");
        delBtn.textContent = "删除";
        delBtn.addEventListener("click", function () {
            deleteTodo(todo.id);
        });
        li.appendChild(delBtn);

        list.appendChild(li);
    });
}

// ===== 添加 =====
function addTodo(text) {
    todos.push({
        id: Date.now(),
        text: text,
        done: false
    });
    render();                               // 改数组 → 必 render
}

// ===== 删除 =====
function deleteTodo(id) {
    todos = todos.filter(function (todo) {
        return todo.id !== id;
    });
    render();                               // 改数组 → 必 render
}

// ===== 事件绑定 =====
addBtn.addEventListener("click", function () {
    let text = input.value;
    if (text === "") return;
    addTodo(text);
    input.value = "";
});

render();   // 首次渲染
```

**代码组织的原则：从上往下是"数据 → 元素 → 函数 → 事件绑定"。**看代码的人一眼就能找到每一块在哪。

## 三个高频 bug 复盘

### bug 一：改了数组忘了重新渲染

```js
function addTodo(text) {
    todos.push({ id: Date.now(), text: text, done: false });
    // 忘了 render()
}
```

**症状**：数据变了，页面不动。
**口诀**：凡改 todos，必 render。

### bug 二：= 写成 ===

```js
input.value = "abc";    // 赋值：正确
input.value === "abc";  // 比较：返回 true/false，不会改值
```

**症状**：想改值却写成比较，输入框纹丝不动。
**口诀**：赋值时一个 `=`，判断时三个 `===`。

### bug 三：下标从 0 开始算错

```js
let first = todos[1];   // 以为是第一个，其实是第二个
let first = todos[0];   // 这才对
```

**症状**：取错项、循环条件写错，报 `undefined`。
**口诀**：下标从 0 开始，循环条件写 `< length`，不是 `<= length`。

## 可以再加的功能（进阶练习）

1. **标记完成**：给每条加个复选框，勾选后加 `done` 样式（用 `classList.toggle`）。
2. **持久化**：用 `localStorage.setItem("todos", JSON.stringify(todos))` 存，`JSON.parse` 读，刷新还在。
3. **编辑功能**：双击文字变成输入框，回车保存。
4. **筛选**：全部 / 未完成 / 已完成三个 tab。

这些都不用学新知识，用前面 30 课的内容就能做出来。**能不能独立完成这几个功能，就是你这一册学没学扎实的试金石。**

q: 下面哪个是"赋值"而不是"比较"？

- a === b
- a = b
- a !== b
- a < b
answer: 1
explain: 一个等号 = 是赋值，三个等号 === 才是严格比较。
