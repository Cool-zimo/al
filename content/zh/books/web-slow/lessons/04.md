# 数字与字符串的区别

> 这一节解决"为什么 '3' + '4' 等于 '34'"的问题。这是 JS 里最经典的坑，搞明白它能帮你避开大量 bug。

## 一个震惊新手的实验

打开控制台，输入这两行：

```js
console.log(3 + 4);     // 7
console.log("3" + "4"); // "34"
```

第一行是数字相加，结果是 7。没问题。

第二行是**字符串拼接**，结果是 "34"——不是 7，是两个字符粘在一起。

**这是 JS 里最经典的坑。** 很多人写了几百行代码后还在踩。

## 为什么 "3" + "4" 不是 7？

因为 `+` 这个符号有两种含义：

- 两边都是**数字**时 → 做加法
- 两边有**字符串**时 → 做拼接

```js
console.log(3 + 4);      // 7（两边都是数字，加法）
console.log("3" + "4");  // "34"（两边都是字符串，拼接）
console.log("3" + 4);    // "34"（一边是字符串，JS 把 4 也当字符串拼起来）
```

第三条最阴险。`"3"` 是字符串，JS 看到字符串在旁边，就"好心"地把数字 4 也转成了字符串 "4"，然后拼接成 "34"。

## 如何把字符串转成数字：`Number()`

如果拿到的是字符串形式的数字（比如从网页输入框读来的值），想做数学运算，要先转成数字：

```js
let str = "100";
let num = Number(str);  // 转成数字 100
console.log(num + 50);  // 150 ✅
```

`Number(...)` 就是把括号里的东西"变成数字"的工具。

```js
console.log(Number("3") + Number("4"));  // 7 ✅
```

## 如何把数字转成字符串：`String()`

反过来，如果你想把数字变成字符串（比如要在网页上显示）：

```js
let age = 20;
let msg = "我今年" + String(age) + "岁";
console.log(msg);  // "我今年20岁"
```

其实这里不写 `String()` 也行，因为 `+` 遇到字符串会自动把数字转成字符串。但显式写 `String()` 更清晰，别人读你的代码一看就知道你是有意的。

## 什么时候会碰到这种问题？

最常见的场景是从网页输入框取值：

```html
<input id="price" value="50">
```

```js
let inputVal = document.querySelector("#price").value;
// inputVal 是字符串 "50"，不是数字！
console.log(inputVal + 10);  // "5010" ❌ 不是 60
console.log(Number(inputVal) + 10);  // 60 ✅
```

输入框读出来的值**永远是字符串**，哪怕你输入的是数字。想算数学，必须先 `Number()` 转换。

## 翻车现场一：忘记转换直接算

```js
let price1 = "29.9";
let price2 = "15.1";
let total = price1 + price2;
console.log(total);  // "29.915.1" ❌
```

后果：本该是 45 的账单算成了 "29.915.1"，用户看到这个价格肯定蒙。正确写法：`Number(price1) + Number(price2)`。

## 翻车现场二：以为 `Number()` 什么都能转

```js
console.log(Number("你好"));  // NaN
```

后果：`Number("你好")` 得到 `NaN`（Not a Number，不是数字）。`NaN` 再做任何运算结果还是 `NaN`。如果你不确定一个值能不能转，可以先判断：

```js
let result = Number("你好");
if (isNaN(result)) {
    console.log("转换失败了");
}
```

## 小结

- `"3" + "4"` 等于 `"34"`，因为 `+` 遇到字符串就做拼接。
- 想做数学运算，先用 `Number()` 把字符串转成数字。
- 输入框取出来的值永远是字符串，要算数必须先转换。
- `Number("不是数字")` 得到 `NaN`，表示转换失败。
