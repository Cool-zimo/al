# 对象数组：真实数据长这样

> 这一节解决"怎么存一堆结构相同的数据"的问题。真实项目里，你拿到的数据几乎都是"对象的数组"——一个数组，里面每个元素都是一个对象。

## 真实数据是什么样？

打开任何一个网站的后台接口，返回的数据长这样：

```json
[
  { "name": "张三", "age": 20, "city": "北京" },
  { "name": "李四", "age": 25, "city": "上海" },
  { "name": "王五", "age": 30, "city": "广州" }
]
```

**这就是"对象数组"**：一个数组，里面每个元素都是一个对象。

生活类比：数组像一张**表格**，每个对象是一**行**，对象的属性是**列**：

| name | age | city |
|---|---|---|
| 张三 | 20 | 北京 |
| 李四 | 25 | 上海 |
| 王五 | 30 | 广州 |

## 创建对象数组

```js
let students = [
    { name: "张三", age: 20, city: "北京" },
    { name: "李四", age: 25, city: "上海" },
    { name: "王五", age: 30, city: "广州" }
];
```

这就是一个数组，长度 3，每个元素是一个对象。

## 取数据：先取下标，再取属性

**两层操作**：先用数组下标取出一个对象，再用点号取出对象的属性。

```js
console.log(students[0]);        // { name: "张三", age: 20, city: "北京" }
console.log(students[0].name);   // "张三"
console.log(students[1].city);   // "上海"
console.log(students[2].age);    // 30
```

**读法**：`students[0]` 拿到第一个对象，`.name` 从这个对象里取 name 属性。

可以连着写很多层：

```js
let orders = [
    { id: "A001", items: ["鼠标", "键盘"], total: 299 },
    { id: "A002", items: ["显示器"], total: 1500 }
];

console.log(orders[0].items[1]);  // "键盘"
// orders[0] → 第一个订单对象
// .items → 它的 items 数组
// [1] → 数组的第二个元素
```

## 遍历对象数组

这是**最核心的操作**。你拿到一堆数据，要把每个人/每件商品的信息展示出来：

```js
let students = [
    { name: "张三", age: 20, city: "北京" },
    { name: "李四", age: 25, city: "上海" },
    { name: "王五", age: 30, city: "广州" }
];

for (let i = 0; i < students.length; i++) {
    console.log(students[i].name + "，" + students[i].age + "岁，来自" + students[i].city);
}
```

输出：

```
张三，20岁，来自北京
李四，25岁，来自上海
王五，30岁，来自广州
```

**关键**：`students[i]` 是当前那个对象，然后 `.name`、`.age`、`.city` 取它的属性。

## 在对象数组中做筛选

```js
let students = [
    { name: "张三", age: 20, city: "北京" },
    { name: "李四", age: 25, city: "上海" },
    { name: "王五", age: 30, city: "北京" },
    { name: "赵六", age: 18, city: "广州" }
];

// 找出所有来自北京的学生
let beijingStudents = [];
for (let i = 0; i < students.length; i++) {
    if (students[i].city === "北京") {
        beijingStudents.push(students[i]);
    }
}
console.log(beijingStudents);
// [{ name: "张三", age: 20, city: "北京" }, { name: "王五", age: 30, city: "北京" }]
```

**模式**：遍历 + 条件判断 + push 到新数组。第 15 课会大量用到这个模式。

## 翻车现场一：忘记先取下标就直接用属性

```js
let students = [
    { name: "张三", age: 20 },
    { name: "李四", age: 25 }
];

console.log(students.name);  // undefined
```

后果：返回 `undefined`。`students` 是数组，数组本身没有 `name` 属性。要先取下标：`students[0].name`。**对象数组要"先下标、再点号"。**

## 翻车现场二：遍历条件写错导致漏掉最后一个

```js
let students = [
    { name: "张三", age: 20 },
    { name: "李四", age: 25 },
    { name: "王五", age: 30 }
];

for (let i = 0; i <= students.length; i++) {  // 多写了 =
    console.log(students[i].name);  // 最后一次 i=3，students[3] 是 undefined，报错！
}
```

后果：最后一次循环 `i = 3`，`students[3]` 是 `undefined`，`undefined.name` 直接报错。**条件应该是 `i < students.length`，不是 `<=`。**

## 小结

- 对象数组 = 一个数组，每个元素是一个对象。真实数据几乎都是这种结构。
- 取值要"先下标，再点号"：`数组[下标].属性名`。
- 遍历对象数组的标准写法：`for (let i = 0; i < arr.length; i++)`，循环体里用 `arr[i].属性`。
- 筛选模式：遍历 + if 判断 + push 到新数组。
