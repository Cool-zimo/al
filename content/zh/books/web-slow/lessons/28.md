# 渲染列表：把数组变成网页上的元素

> 上一课搭好了壳。这一课实现 `render()`：把 `todos` 数组的每一项，变成页面上的一条 `<li>`。这是整个项目最核心的一步。

## render 的思路

```js
function render() {
    // 1. 先清空容器
    list.innerHTML = "";

    // 2. 遍历 todos，每一项创建一个 <li>
    for (let i = 0; i < todos.length; i++) {
        let todo = todos[i];

        let li = document.createElement("li");
        li.textContent = todo.text;

        list.appendChild(li);
    }
}
```

**三步走：清空容器 → 遍历数组 → 创建元素挂上去。**每次 render 都是"全量重绘"——不管改了多少，都从头重新画一遍。

## 连调两次 render 要先清空

这是判分环境和真实项目都会遇到的坑。假设 `todos = ["苹果", "香蕉"]`：

```js
function render() {
    // 忘写清空
    for (let i = 0; i < todos.length; i++) {
        let li = document.createElement("li");
        li.textContent = todos[i];
        list.appendChild(li);
    }
}

render();   // 页面：苹果 香蕉
render();   // 页面：苹果 香蕉 苹果 香蕉 ← 重复了！
```

**没清空就重绘，元素会累加。**所以 render 的第一句永远是清空容器：

```js
function render() {
    list.innerHTML = "";   // ← 这句不能少
    // ...
}
```

## 带删除按钮的渲染

```js
function render() {
    list.innerHTML = "";

    for (let i = 0; i < todos.length; i++) {
        let todo = todos[i];

        let li = document.createElement("li");

        let span = document.createElement("span");
        span.textContent = todo.text;
        li.appendChild(span);

        let delBtn = document.createElement("button");
        delBtn.textContent = "删除";
        li.appendChild(delBtn);

        list.appendChild(li);
    }
}
```

**一条任务 = 文字 + 删除按钮，用 span 和 button 两个子元素装在 li 里。**结构清晰，后面给删除按钮绑事件也方便。

## 渲染的本质：数据 → 界面

```
todos = [{id:1,text:"买菜"}, {id:2,text:"写代码"}]
                ↓  render()
页面上：
  <li>买菜  [删除]</li>
  <li>写代码 [删除]</li>
```

**界面永远是数据的投影。**改数据不会自动反映到界面上，必须再调一次 render。这条规律是后面所有 bug 的根源，也是所有 bug 的解药。

## 翻车现场一：忘了清空容器导致元素累加

```js
function render() {
    // 这里忘了 list.innerHTML = ""
    todos.forEach(function (todo) {
        let li = document.createElement("li");
        li.textContent = todo.text;
        list.appendChild(li);
    });
}
```

后果：每次 render 都在已有元素后面追加，**列表越来越长、越来越重复。**第一句必须是清空。

## 翻车现场二：渲染时把 text 用 innerHTML 插进去

```js
li.innerHTML = "<span>" + todo.text + "</span>";   // todo.text 来自用户输入
```

后果：如果用户输入了 `<script>`，脚本会被执行。**渲染用户内容用 `textContent`，永远不要用 `innerHTML` 拼接。**

## 用 forEach 重写 render

```js
function render() {
    list.innerHTML = "";

    todos.forEach(function (todo) {
        let li = document.createElement("li");
        li.textContent = todo.text;
        list.appendChild(li);
    });
}
```

跟 for 循环完全等价，只是更短。**慢班两种都会写，实际项目里 `forEach` / `map` 更常见。**

## 小结

- render 三步走：清空 → 遍历 → 创建挂上。
- **清空容器是 render 的第一句**，否则会累加。
- 界面是数据的投影，改数据后必须重新 render。
- 用户内容用 `textContent`，别用 `innerHTML` 拼接。
