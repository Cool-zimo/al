# if / else：让程序做选择

> 这一节解决"怎么让程序在不同情况下做不同的事"的问题。if/else 是编程里最基础的分支结构，就像生活里的"如果…就…否则…"。

## 生活里的"如果"

你每天出门前都会想：

> 如果下雨，就带伞；否则，不带伞。

程序里用 `if / else` 来表达这种逻辑：

```js
let isRaining = true;

if (isRaining) {
    console.log("带伞出门");
} else {
    console.log("不用带伞");
}
```

**语法结构：**

```js
if (条件) {
    // 条件为 true 时执行这里的代码
} else {
    // 条件为 false 时执行这里的代码
}
```

`if` 后面的括号里放一个条件（一个能算出 true/false 的表达式），如果为 true，执行第一个大括号里的代码；否则执行 `else` 后面大括号里的代码。

## 一次判断：if 不带 else

有时候你只想在条件成立时做点什么，不成立就什么都不做：

```js
let score = 85;

if (score >= 60) {
    console.log("及格了！");
}
// score 不够 60 时，什么都不做，跳过
```

## 多个分支：else if

如果一个判断有三种以上情况：

```js
let score = 85;

if (score >= 90) {
    console.log("优秀");
} else if (score >= 60) {
    console.log("及格");
} else {
    console.log("不及格");
}
```

执行顺序是**从上往下**，命中第一个满足条件的分支后就不再往下看了：

1. score >= 90？85 >= 90 → false，跳过
2. score >= 60？85 >= 60 → **true**，执行"及格"，然后**整个 if 结束**
3. else 不会被执行

## 缩进是为了人看的

```js
if (score >= 60) {
    console.log("及格");
    console.log("恭喜");
}
```

花括号 `{}` 里的内容通常**缩进两个或四个空格**。缩进不是给浏览器看的（浏览器不 care 缩进），是**给你自己和其他人看的**——一眼就能看出"这些代码属于这个 if 分支"。

```js
// 不缩进也能跑，但很难读
if (score >= 60) {
console.log("及格");
console.log("恭喜");
}

// 缩进后清晰多了
if (score >= 60) {
    console.log("及格");
    console.log("恭喜");
}
```

## 大括号不能省

新手经常写：

```js
if (score >= 60)
    console.log("及格");
    console.log("恭喜");  // 这行永远会执行！不管 score 多少
```

**只有紧跟着 `if` 的第一行**属于 `if`。第二行 `console.log("恭喜")` 不管条件如何都会执行。

**安全写法：永远加大括号**，哪怕只有一行：

```js
if (score >= 60) {
    console.log("及格");
}
```

这样永远不会搞错"哪些代码属于 if"。

## 翻车现场一：条件里用 `=` 而不是 `===`

```js
let status = "vip";

if (status = "normal") {  // 错！这是赋值
    console.log("普通用户");
} else {
    console.log("VIP用户");
}
```

后果：`status = "normal"` 把 "normal" 装进了 status，同时赋值表达式的值是 "normal"（真值），所以条件永远为真，永远打印"普通用户"。正确写法：`status === "normal"`。

## 翻车现场二：多个条件顺序写反

```js
let score = 95;

if (score >= 60) {
    console.log("及格");  // 命中这里就结束了
} else if (score >= 90) {
    console.log("优秀");  // 永远不会被执行！
}
```

后果：95 分打印"及格"而不是"优秀"。因为 95 >= 60 先命中，程序就不往下看了。**多分支时要从最严格的条件写起。**

## 小结

- `if (条件) { ... } else { ... }` 是最基本的选择结构。
- 条件为 true 走 if 分支，false 走 else 分支。
- 多个分支用 `else if`，从上往下匹配，命中即止。
- **永远加大括号**，缩进只是为了可读性。

## 随堂练习

```quiz
type: js
q: 写一个函数 grade，接收分数 score，>=90 返回"优秀"，>=60 返回"及格"，否则返回"不及格"。
func: grade
starter: |
  function grade(score) {
      // 在这里写
  }
cases: |
  95 -> "优秀"
  75 -> "及格"
  45 -> "不及格"
hint: if...else if...else 从上往下判断
explain: 先用 >=90 判断优秀，再用 >=60 判断及格，其余不及格。
```
