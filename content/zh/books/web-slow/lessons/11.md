# 数组：一排编号的盒子

> 这一节解决"怎么一次存一堆东西"的问题。变量只能装一个值，数组能装一堆值，而且是按顺序排好的。

## 一个变量不够用了

你有个需求：存 5 个同学的名字。

**笨办法：**

```js
let name1 = "张三";
let name2 = "李四";
let name3 = "王五";
let name4 = "赵六";
let name5 = "钱七";
```

5 个名字要 5 个变量，50 个呢？500 个呢？显然不行。

**正确做法：用数组。**

## 数组 = 一排编号的盒子

想象一排储物柜，每个柜子都有编号：1 号柜、2 号柜、3 号柜……你可以往每个柜子里放东西，想取的时候报编号就行。

JS 里的数组就是这样：

```js
let students = ["张三", "李四", "王五", "赵六", "钱七"];
```

| 编号 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 内容 | "张三" | "李四" | "王五" | "赵六" | "钱七" |

**用方括号 `[]` 创建数组**，元素之间用逗号分隔。

## 下标从 0 开始！

这是**新手最容易踩的坑**。数组的编号（专业叫"下标"或"索引"）**从 0 开始**，不是从 1。

```js
let students = ["张三", "李四", "王五"];
// 下标:           0        1        2

console.log(students[0]);  // "张三"（第 1 个元素）
console.log(students[1]);  // "李四"（第 2 个元素）
console.log(students[2]);  // "王五"（第 3 个元素）
```

**生活类比**：这就像楼层编号，国外很多建筑的一楼叫 "Ground Floor"，二楼才叫 "1st Floor"。你习惯了从 1 开始数，但程序员的数组从 0 开始。

**取元素用方括号加下标：**

```js
let fruits = ["苹果", "香蕉", "橙子"];
console.log(fruits[0]);  // "苹果"
console.log(fruits[2]);  // "橙子"
```

## `length`：数组有多长

想知道数组有几个元素，用 `.length`：

```js
let fruits = ["苹果", "香蕉", "橙子"];
console.log(fruits.length);  // 3
```

`length` 就是"元素的个数"。

**用 length 配合循环遍历数组：**

```js
for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}
```

这里 `i < fruits.length` 就是 `i < 3`，所以 i 取 0、1、2，正好把三个元素都取到了。**这是遍历数组的标准写法。**

## 数组可以装不同类型

```js
let mixed = [1, "hello", true, 3.14];
console.log(mixed[0]);  // 1
console.log(mixed[1]);  // "hello"
```

数组里可以混着装数字、字符串、布尔值。不过在实际项目中，通常一个数组里装同一种类型的东西。

## 翻车现场一：下标从 1 开始数

```js
let fruits = ["苹果", "香蕉", "橙子"];
console.log(fruits[1]);  // 以为这是第一个？错了，是"香蕉"
```

后果：取错了元素。以为是第一个，实际拿到第二个。**永远记住：第一个元素是 [0]，不是 [1]。**

## 翻车现场二：下标越界

```js
let fruits = ["苹果", "香蕉", "橙子"];
console.log(fruits[5]);  // undefined
```

后果：不会报错，但返回 `undefined`（"什么都没有"）。如果你接着用这个值做运算：

```js
let total = fruits[5] + "个";  // "undefined个"
```

得到莫名其妙的结果。**访问前先确认下标在范围内：`下标 < 数组.length`。**

## 小结

- 数组用 `[]` 创建，元素用逗号分隔，能装一堆值。
- **下标从 0 开始**：第一个元素是 `[0]`，第二个是 `[1]`。
- `.length` 返回元素个数。
- 遍历数组的标准写法：`for (let i = 0; i < arr.length; i++)`。
- 越界访问返回 `undefined`，不会报错但要小心。
