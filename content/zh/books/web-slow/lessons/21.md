# 第 5 章 网页与 DOM（21-25）

# 网页是棵树：DOM 是什么

> 前面 20 课写的 JS 都跑在"控制台"里。从这章开始，JS 要跟网页上的真实元素打交道——点击按钮、修改文字、增删列表。这一切都靠 DOM。

## HTML 其实就是一棵树

浏览器拿到 HTML 后，会把它解析成一棵"节点树"。比如这段 HTML：

```html
<html>
  <body>
    <h1>你好</h1>
    <div>
      <p>一段文字</p>
    </div>
  </body>
</html>
```

在浏览器眼里是这样一棵树：

```
html
 └─ body
     ├─ h1
     └─ div
         └─ p
```

**这种"树形结构"就叫 DOM（Document Object Model，文档对象模型）。**网页上每一个标签都是树上的一个"节点"。

为什么叫"树"：有一个最顶端的 `html`（根），往下分叉出子节点，像一棵倒过来的树。

## document 是所有操作的入口

JS 想操作网页，就要通过一个全局对象 `document`——它就是这棵树的"根"：

```js
console.log(document);          // 整个文档
console.log(document.title);   // 当前网页标题
```

**记住这句话：`document` 是 JS 和网页之间的桥梁，所有"找元素、改元素"的操作都从它开始。**

## 用 JS 创建一个元素并加进页面

```js
// 1. 创建一个 <p> 元素（此时它还在"空中"，页面上看不到）
let p = document.createElement("p");

// 2. 给它塞文字
p.textContent = "我是通过 JS 加进来的";

// 3. 把它挂到 body 下面，这下页面上能看到了
document.body.appendChild(p);
```

三步走：**创建 → 设置内容 → 挂到树上**。第 3 步挂到树上之后，元素才真正出现在页面里。

## 元素之间的关系

```html
<div id="box">
  <h1>标题</h1>
  <p>段落</p>
</div>
```

- `div` 是 `h1` 和 `p` 的**父节点**（parent）。
- `h1` 和 `p` 是 `div` 的**子节点**（children）。
- `h1` 和 `p` 互为**兄弟节点**（siblings）。

JS 里可以这样访问：

```js
let box = document.querySelector("#box");
console.log(box.children);          // 子节点集合：h1、p
console.log(box.children.length);   // 2
console.log(box.firstElementChild); // 第一个子节点：h1
```

## 翻车现场一：元素还没创建就想操作

```js
let p = document.createElement("p");
p.textContent = "你好";
// 忘了 appendChild，页面上什么都看不到
```

后果：代码不报错，但页面上什么变化都没有。**创建了元素必须挂到树上（appendChild 到某个已存在的节点），否则它只是"飘在内存里"。**

## 翻车现场二：把文本当成元素去取属性

```html
<div id="box">一段文字</div>
```

```js
let box = document.querySelector("#box");
console.log(box.children.length);   // 0，因为"一段文字"是文本节点不是元素节点
```

文本"一段文字"属于**文本节点**，不是元素节点。`children` 只算元素子节点，所以长度是 0。想取文本内容要用 `textContent`（下一课讲）。

## 为什么 DOM 是"对象"

DOM 里每个元素都是一个 JS 对象，有很多属性可以读、可以改：

```js
let h1 = document.querySelector("h1");
h1.textContent = "新标题";     // 改文字
h1.style.color = "red";        // 改样式
h1.id = "main-title";          // 改属性
```

**所以 DOM 的"O"是 Object——每个标签在 JS 里都是一个对象，可以读写它的属性。**这解释了为什么 `document.body.appendChild` 这种写法能成立：`body` 是个对象，上面挂着 `appendChild` 这个方法。

## 小结

- HTML 在浏览器里被解析成一棵 DOM 树。
- `document` 是所有操作的入口。
- 创建元素三步走：createElement → 设置内容 → appendChild 挂到树上。
- 每个标签都是对象，可读写它的属性。
