# 变量：给数据贴个标签

> 这一节解决"程序怎么记住东西"的问题。变量就是你给数据起的名字，记住这个名字就能随时拿出来用。

## 变量 = 贴了标签的盒子

想象你桌上有一个盒子，盒子上贴了张标签写着"零花钱"。里面放了 100 块钱。下次你想用这笔钱，不用打开所有盒子一个个找，直接看标签"零花钱"就知道了。

程序里的**变量**就是这个"贴了标签的盒子"：

```js
let pocketMoney = 100;
```

这句话的意思是：造一个叫 `pocketMoney` 的盒子，里面装 100。

- `let` 是"我要造一个盒子"的关键字
- `pocketMoney` 是盒子的标签名（变量名）
- `=` 是"把右边的东西装进左边的盒子"
- `100` 是装在里面的数据

以后想用这个数，直接写 `pocketMoney` 就行：

```js
let pocketMoney = 100;
console.log(pocketMoney);  // 打印 100
console.log(pocketMoney + 50);  // 打印 150
```

## `=` 不是"等于"，是"装进去"

这是新手最容易踩的坑。`=` 在数学里是"等于"，但在编程里是"赋值"——把右边的值装进左边的盒子。

```js
let age = 20;  // 造一个盒子叫 age，装进 20
age = 21;      // 把 age 盒子里的值换成 21
```

第二行不是"age 等于 21"这个陈述，而是"把 21 装进 age 这个盒子"。用生活话说就是"把盒子里原来的东西倒掉，换新东西"。

那"等于"怎么表示？用 `===`（三个等号），第 06 课会讲。

## `let` 和 `const`：可变 vs 不变

`let` 造的盒子**可以换内容**：

```js
let score = 80;
score = 95;  // 没问题
console.log(score);  // 95
```

`const` 造的盒子**不能换内容**（"常量"，constant 的缩写）：

```js
const pi = 3.14159;
pi = 3.14;  // 报错！不能改
```

什么时候用哪个？**先看这个东西会不会变**。比如圆周率不会变，用 `const`；比如你的分数可能会变，用 `let`。

> 💡 经验法则：不确定就用 `const`，后面发现要改再改成 `let`。很多团队默认都用 `const`，除非确实需要改。

## 变量命名规则

名字不能乱起，有几条规矩：

| 规则 | ✅ 可以 | ❌ 不行 |
|---|---|---|
| 只能用字母、数字、下划线、`$` | `myName`、`_count`、`$price` | `my-name`（减号不行） |
| 不能以数字开头 | `age2` | `2age` |
| 不能用关键字 | `myLet`、`myFunction` | `let`、`const`、`function` |
| 区分大小写 | `name` 和 `Name` 是两个不同的变量 | — |

推荐用"驼峰命名法"：`myFirstName`、`totalPrice`、`userAge`。多个单词拼在一起，第一个单词小写，后面每个单词首字母大写。

## 先声明再使用

**变量必须先"造"出来，才能用。** 就像你要先有盒子，才能往里面放东西。

```js
console.log(myName);  // 报错！myName 还没造出来
let myName = "张三";
```

正确的顺序是：

```js
let myName = "张三";  // 先声明（造盒子 + 装东西）
console.log(myName);  // 再用
```

这就像你要先买个杯子，才能往里面倒水。没买杯子就倒水，水就洒了。

## 翻车现场一：忘记声明就直接用

```js
score = 100;  // 没写 let / const
console.log(score);
```

后果：在严格模式下直接报错。即使不报错，这个变量会变成"全局变量"，可能在其他地方被意外修改，导致很难排查的 bug。**每次用变量都要先声明。**

## 翻车现场二：用 `const` 声明后想改值

```js
const userName = "张三";
userName = "李四";  // TypeError: Assignment to constant variable
```

后果：浏览器报红色错误，代码停在这一行不再往下跑。如果你确实需要改这个值，把 `const` 改成 `let`。

## 小结

- 变量 = 贴了标签的盒子，`let 名字 = 值` 就是造盒子 + 装东西。
- `=` 是"装进去"（赋值），不是"等于"。
- `let` 可改，`const` 不可改，不确定就先用 `const`。
- 变量必须先声明再使用，命名有规则（驼峰、不能数字开头、不能用关键字）。
