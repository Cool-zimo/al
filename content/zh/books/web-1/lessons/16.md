# display 三种形态：block、inline、inline-block

> 这一节解决"为什么有些元素占一整行，有些元素并排还改不了宽高"的问题。display 决定一个元素在文档流里的存在方式，是所有布局的起点。

## 三种 display 行为

每个 HTML 元素都有一个默认的 display 值。你学过的 `<div>` 默认是 `block`，`<span>` 默认是 `inline`，而 `<img>` 则是 `inline-block`。这三种行为决定了元素怎么占空间。

```html
<div class="box block">我是 block</div>
<div class="box block">我也是 block</div>
<span class="box inline">我是 inline</span>
<span class="box inline">我也是 inline</span>
<span class="box inline-block">我是 inline-block</span>
<span class="box inline-block">我也是 inline-block</span>
```

```css
.box {
  width: 200px;
  height: 60px;
  padding: 10px;
  margin: 5px;
  background: #e0f0ff;
  border: 1px solid #4a90d9;
}
.block { display: block; }
.inline { display: inline; }
.inline-block { display: inline-block; }
```

三种行为的核心差异：

| 行为 | 是否占满整行 | 能否设置宽高 | 能否设上下 margin |
|---|---|---|---|
| block | 是，独占一行 | 能 | 能 |
| inline | 否，并排排列 | 不能 | 上下 margin 无效 |
| inline-block | 否，并排排列 | 能 | 能 |

## block：独占一行的大块头

`block` 元素默认宽度撑满父容器（不设 width 时等于 100% 父宽），前后自动换行。常见的块级元素有 `<div>`、`<p>`、`<h1>`~`<h6>`、`<section>`、`<li>`。

```css
div {
  display: block; /* 默认值，可省略 */
  width: 300px;
  height: 100px;
  margin: 20px;
}
```

因为块级元素独占一行，所以两个 div 上下堆叠，各占一整行宽度。

## inline：与文字同流

`inline` 元素的宽高由内容决定，不能手动设置 `width` 和 `height`，左右 margin 有效但上下 margin 不起作用。常见的行内元素有 `<span>`、`<a>`、`<strong>`、`<em>`。

```css
span {
  display: inline; /* 默认值，可省略 */
  width: 200px;    /* 无效！ */
  height: 60px;    /* 无效！ */
  margin-top: 20px; /* 无效！ */
}
```

翻车现场一：想给一个 span 设宽高，发现怎么设都不生效。

```css
span.badge {
  width: 100px;
  height: 40px;
  background: red;
  color: white;
}
```

后果：span 的宽度仍由文字撑开，设的 100px 和 40px 完全被忽略。页面上 badge 挤成一团，文字溢出。解决方法：改成 `display: inline-block` 或 `display: block`。

## inline-block：既要并排又要尺寸

`inline-block` 结合了两者的优点：对外像 inline 一样可以和文字、其他元素并排，对内像 block 一样可以设宽高和上下 margin。导航菜单、按钮组、卡片网格都是它的典型用法。

```css
.menu-item {
  display: inline-block;
  width: 120px;
  height: 40px;
  line-height: 40px;
  text-align: center;
  margin: 0 5px;
  background: #4a90d9;
  color: white;
}
```

这样每个菜单项定宽定高、并排排列，完美。

翻车现场二：inline-block 元素之间出现莫名间隙。

```html
<nav>
  <a href="#">首页</a>
  <a href="#">关于</a>
  <a href="#">联系</a>
</nav>
```

```css
nav a {
  display: inline-block;
  width: 100px;
  background: #4a90d9;
}
```

后果：每个 a 之间有大约 4px 的空白间隙。这不是 bug，而是 inline-block 元素之间的**换行符被当成空格**处理了。解决方法是给父元素设 `font-size: 0`，再给子元素恢复字号；或者用 Flex 布局（第 19 课会讲，根本不存在这个问题）。

## display 是布局的地基

所有高级布局（float、position、flex、grid）都是在修改元素的 display 行为。理解这三种基础形态，后面遇到的布局现象都能追根溯源到这里。

## 小结

- `block` 独占一行，可设宽高和全部 margin。
- `inline` 与内容同流，宽高不可设，上下 margin 无效。
- `inline-block` 对外行内、对内块级，既能并排又能定尺寸。
- inline-block 元素之间的换行会产生空白间隙，是常见坑。

## 随堂练习

```quiz
type: css
q: 让 span.item 变成 inline-block，宽度 120px、高度 40px，背景色蓝色（#4a90d9）。
html: |
  <span class="item">前端</span><span class="item">后端</span>
starter: |
  .item {
  }
checks:
- getComputedStyle(document.querySelector('.item')).display === 'inline-block'
- getComputedStyle(document.querySelector('.item')).width === '120px'
- getComputedStyle(document.querySelector('.item')).height === '40px'
- getComputedStyle(document.querySelector('.item')).backgroundColor === 'rgb(74, 144, 217)'
hint: 用 display 改成 inline-block，再设 width 和 height。
explain: inline-block 允许行内元素同时拥有可设定的宽度和高度。
```
