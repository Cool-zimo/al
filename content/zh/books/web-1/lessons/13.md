# 图片：img 的 src、alt 与宽高

> 这一节解决"为什么我的图片显示不出来、为什么页面会抖动"的问题。路径和尺寸是图片最常见的两个坑。

## 基本用法

```html
<img src="photo.jpg" alt="张三在北京大学门口的毕业照">
```

`<img>` 是自闭合标签（不需要 `</img>`）。两个必备属性：

- `src`：图片路径或 URL。
- `alt`：替代文本。内容性图片必须写清楚描述。

## 指定宽高能避免页面抖动

```html
<img src="photo.jpg" alt="风景" width="400" height="300">
```

浏览器在图片下载前就**不知道**这张图多大。如果没给宽高，图片加载完成后浏览器才补上尺寸，下面的内容会被往下挤——用户正读到一半，页面突然跳一下。

给了 `width` 和 `height` 之后，浏览器会**提前留出空间**，图片加载完直接填进去，页面不再抖动。现代浏览器还会按 width/height 的比例自动处理响应式缩放。

翻车现场一：宽高比和原图不一致。

```html
<img src="photo.jpg" alt="照片" width="400" height="400">
```

后果：原图是 4:3 的横图，硬设成 400×400 就变成正方形，人物被拉伸变形。正确做法是保持宽高比：`width="400" height="300"`。

## 路径最容易错在哪

假设目录结构：

```
my-site/
├── index.html
├── about.html
├── images/
│   └── photo.jpg
└── pages/
    └── detail.html
```

从 `index.html` 引用图片：

```html
<img src="images/photo.jpg" alt="照片">
```

从 `pages/detail.html` 引用同一张图片：

```html
<img src="../images/photo.jpg" alt="照片">
```

注意 `../` 表示**上一级目录**。因为在 `pages/` 里，要先回到 `my-site/` 才能进 `images/`。

| 写法 | 从 index.html | 从 pages/detail.html |
|---|---|---|
| `images/photo.jpg` | ✅ | ❌ 找不到 |
| `../images/photo.jpg` | ❌ 多了一层 | ✅ |

翻车现场二：在子目录文件里用了相对当前文件的错误路径。

```html
<!-- 这是 pages/detail.html -->
<img src="images/photo.jpg" alt="照片">
```

后果：浏览器实际请求的是 `pages/images/photo.jpg`，这个路径不存在，图片破图。张三的简历里 `about.html` 和 `index.html` 都在根目录，图片路径都写 `images/photo.jpg`；后来加了 `pages/blog.html`，忘记改成 `../images/photo.jpg`，整页图片全挂。

## 用 CSS 控制图片尺寸

```css
img {
  max-width: 100%;
  height: auto;
}
```

`max-width: 100%` 表示图片最大不超过其父容器宽度，超了就缩放；`height: auto` 保持宽高比。这是让图片**响应式**的标准写法，图片在手机上不会撑破页面。

翻车现场三：图片撑破布局。

```css
img {
  width: 800px;
}
```

后果：手机屏幕只有 375px 宽，800px 的图片直接撑出横向滚动条。改用 `max-width: 100%; height: auto` 就解决了。

## 小结

- img 是自闭合标签，src 和 alt 必备。
- 指定 width/height 能避免页面抖动，但要保���原图比例。
- 路径相对于**当前文件**；子目录文件用 `../` 回到上一级。
- 用 `max-width: 100%; height: auto` 让图片响应式、不撑破布局。
