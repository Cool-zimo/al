# 表格：table、tr、td、th

> 这一节解决"怎么展示行列对齐的数据"的问题。表格只该用在表格数据上，不该用来做页面布局。

## 一个完整的表格

```html
<table>
  <thead>
    <tr>
      <th>姓名</th>
      <th>城市</th>
      <th>月薪</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>张三</td>
      <td>北京</td>
      <td>¥25000</td>
    </tr>
    <tr>
      <td>李四</td>
      <td>上海</td>
      <td>¥22000</td>
    </tr>
  </tbody>
</table>
```

各标签的分工：

| 标签 | 含义 |
|---|---|
| `<table>` | 表格容器 |
| `<tr>` | 一行（table row） |
| `<th>` | 表头单元格（table header） |
| `<td>` | 普通单元格（table data） |
| `<thead>` | 表头区域 |
| `<tbody>` | 表体区域 |
| `<tfoot>` | 表尾区域（可选） |

## 表头用 th，不是 td

```html
<thead>
  <tr>
    <th>姓名</th>
    <th>城市</th>
  </tr>
</thead>
```

`<th>` 默认**加粗并居中**，更重要的是它有语义：告诉浏览器和读屏软件"这是列标题"。读屏用户按列浏览时，能听到"姓名列、北京、上海……"，上下文清楚。

翻车现场一：表头用 td。

```html
<tr>
  <td>姓名</td>
  <td>城市</td>
</tr>
```

后果：视觉上你可以用 CSS 把 td 加粗居中，看着一样。但语义上这些单元格就是普通数据格，读屏软件不会当作表头处理，可访问性丢了。多写两个字符用 th，收益是实实在在的。

## thead / tbody 让结构更清晰

即使不写 thead 和 tbody，浏览器也会自动补上。但**显式写出来**有几个好处：

1. 样式好控制——可以单独给 thead 加背景色、给 tbody 加隔行变色。
2. 打印时长表格能自动重复表头。
3. 代码更好读，一眼看出哪部分是表头。

## 表格不该用来布局

早年网页没有 flex、grid，前端工程师用表格（`table > tr > td`）来拼出多栏布局。这种做法现在**已经废弃**：

```html
<!-- 反面教材 -->
<table>
  <tr>
    <td>左侧栏</td>
    <td>主内容</td>
    <td>右侧栏</td>
  </tr>
</table>
```

后果：语义上这是一个"表格"，但实际上放的是布局内容。读屏软件会按表格朗读，用户听到"表格，三列"，完全误导。而且改动布局要动 HTML 结构，维护成本高。

什么时候该用表格？**数据是表格形态的时候**：成绩单、价格表、日程表、参数对比。判断标准很简单——如果把内容转成 Excel，是否合理？合理就用表格，否则用 flex/grid 布局。

翻车现场二：用 div 手写"伪表格"却不加表格语义。

```html
<div class="row">
  <div>姓名</div>
  <div>城市</div>
</div>
```

如果只是展示表格数据，这种写法不如直接用 `<table>`——你重新发明了轮子，还丢了表头语义。数据就是表格，就用 table。

## 小结

- table > tr > (th/td)，层级清晰：表格 → 行 → 单元格。
- 表头用 `<th>`，语义明确、默认加粗居中。
- thead/tbody 显式写出，便于样式控制与阅读。
- 表格只用于表格数据，不要用它做页面布局。

## 随堂练习

```quiz
type: html
q: 写一个表格，thead 里一行两个 th："商品"和"价格"；tbody 里一行两个 td："笔记本"和"¥5000"。
starter: |
  <table>
  </table>
checks:
- document.querySelectorAll('table').length === 1
- document.querySelectorAll('th').length === 2
- document.querySelectorAll('td').length === 2
- document.querySelector('th').textContent.trim() === '商品'
- document.querySelectorAll('td')[1].textContent.trim() === '¥5000'
hint: thead 里放 th 那一行，tbody 里放 td 那一行。
explain: thead 包含表头行 th，tbody 包含数据行 td，结构完整。
```
