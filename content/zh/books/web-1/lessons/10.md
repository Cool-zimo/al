# 文本样式：字体、行高、对齐

> 这一节解决"为什么我的文字看着不好看"的问题。字号、行高、字间距这几个属性，决定了页面的阅读体验。

## 常用文本属性

```css
p {
  font-size: 16px;          /* 字号 */
  font-weight: bold;        /* 字重：normal / bold / 100~900 */
  line-height: 1.8;         /* 行高，无单位，相对字号 */
  text-align: center;       /* 对齐：left / center / right / justify */
  letter-spacing: 2px;      /* 字间距 */
  font-family: "PingFang SC", "Microsoft YaHei", sans-serif;
}
```

## font-size：字号

推荐用 rem 作为字号单位，这样整个页面的字号有统一基准，用户缩放时整体跟着变。

## font-weight：字重

```css
.title {
  font-weight: 700;   /* 等于 bold */
}
.light {
  font-weight: 300;   /* 细体 */
}
```

数值从 100 到 900，步长 100。不是所有字体都支持全部字重，中文字体通常只有 400（常规）和 700（粗体）两个档位。张三想给标题用 500 字重，结果浏览器就近取了 400，看起来和正文一样——因为字体没提供 500 这个字形。

## line-height：行高，最影响阅读体验的属性

`line-height: 1.8` 表示行高是字号的 1.8 倍。网页正文通常设在 **1.5~1.8** 之间。

翻车现场一：行高太小。

```css
p {
  line-height: 1;
}
```

后果：多行文字挤在一起，行间几乎贴住，长文读几行就累。这是新手最常犯的错——觉得"紧一点省空间"，实际是牺牲了可读性。

翻车现场二：用 px 写死行高。

```css
p {
  font-size: 16px;
  line-height: 24px;
}
```

后果：字号改成 24px 后，行高还是 24px，比例就乱了。用无单位的倍数（如 `1.8`）会**自动跟随字号**，这才是推荐写法。

## text-align：对齐

```css
h1 { text-align: center; }
p { text-align: justify; }   /* 两端对齐，常用于中文正文 */
```

`justify` 会让每行文字两端贴齐，中间自动加空隙。西文里它会让单词间距忽大忽小，所以多用于中文正文。

## letter-spacing：字间距

```css
h1 {
  letter-spacing: 4px;
}
```

适合给标题、Logo、英文缩写拉开间距，提升设计感。正文字间距一般不动，用默认值最好。

## font-family：字体栈

```css
body {
  font-family: "PingFang SC", "Microsoft YaHei", sans-serif;
}
```

浏览器会从左到右尝试：有 PingFang SC 就用它，没有就试微软雅黑，都没有就用系统默认无衬线字体。这叫**字体栈**，是为了兼容不同操作系统（macOS、Windows、Linux）。

翻车现场三：只写一个字体名。

```css
body {
  font-family: "PingFang SC";
}
```

后果：Windows 用户没有 PingFang SC，浏览器回退到默认字体，页面看起来和预期完全不同。务必提供多个备选。

## 小结

- 字号用 rem，行高用无单位倍数（1.5~1.8），字重按需取。
- 行高直接影响可读性，不要用 px 写死。
- text-align 控制对齐，letter-spacing 拉开字距。
- font-family 写字体栈，多备几个备选兼容不同系统。

## 随堂练习

```quiz
type: css
q: 让 p 的字号为 18px、行高为 1.6、文字居中对齐。
html: |
  <p>一段需要排版的文字</p>
starter: |
  p {
  }
checks:
- getComputedStyle(document.querySelector('p')).fontSize === '18px'
- getComputedStyle(document.querySelector('p')).lineHeight === '28.8px'
- getComputedStyle(document.querySelector('p')).textAlign === 'center'
hint: 三个属性分别是 font-size、line-height、text-align。
explain: 18px × 1.6 = 28.8px 是计算后的行高；text-align 控制对齐方式。
```

- line-height 不会影响元素的实际高度
- 行高越大文字越小
answer: 1
explain: 无单位倍数会相对当前字号计算，字号变化时行高自动跟随；px 写死则失去弹性。
