# Flex 布局基础：弹性盒的一维排列

> 这一节解决"怎么让几个元素在主轴方向上均匀分布"的问题。Flex 是现代布局的主力，一行 CSS 就能搞定过去要写一堆 float + clearfix 才能做的事。

## Flex 的基本概念

Flex 布局的核心是**主轴**和**交叉轴**。主轴是子元素排列的方向，交叉轴垂直于它。

```css
.container {
  display: flex;
}
```

只要给父元素设 `display: flex`，它就成了 Flex 容器，所有**直接子元素**自动变成 Flex 项目。默认主轴是水平方向（从左到右），交叉轴是垂直方向。

```html
<div class="container">
  <div class="item">前端</div>
  <div class="item">后端</div>
  <div class="item">运维</div>
</div>
```

```css
.container {
  display: flex;
  border: 2px solid #4a90d9;
  padding: 10px;
}
.item {
  width: 100px;
  height: 60px;
  background: #e0f0ff;
  margin: 5px;
  display: flex;
  align-items: center;
  justify-content: center;
}
```

三个 item 不再各占一行，而是并排排列在主轴上。注意它们仍然是块级尺寸（100px 宽），只是不再换行独占。

## justify-content：主轴对齐

`justify-content` 控制子元素在**主轴**上的分布方式。

```css
.container {
  display: flex;
  justify-content: space-between; /* 两端对齐，中间等距 */
}
```

常见取值：

| 取值 | 效果 |
|---|---|
| flex-start | 靠主轴起点（默认左对齐） |
| center | 主轴居中 |
| flex-end | 靠主轴终点（右对齐） |
| space-between | 两端贴边，中间等距 |
| space-around | 每个项目两侧间距相等 |
| space-evenly | 所有间距完全相等 |

## align-items：交叉轴对齐

`align-items` 控制子元素在**交叉轴**上的对齐方式。

```css
.container {
  display: flex;
  height: 200px;
  align-items: center; /* 垂直居中 */
}
```

常见取值：

| 取值 | 效果 |
|---|---|
| stretch | 拉伸填满交叉轴（默认） |
| flex-start | 靠交叉轴起点 |
| center | 交叉轴居中 |
| flex-end | 靠交叉轴终点 |

翻车现场一：align-items 不生效，以为是写错了。

```css
.container {
  display: flex;
  align-items: center;
}
```

```html
<div class="container">
  <div class="item">A</div>
  <div class="item">B</div>
</div>
```

后果：A 和 B 并没有垂直居中。原因：`.container` 没有设固定高度（或 `height` 没有被撑开），交叉轴没有多余空间，居中无从谈起。解决：给容器一个明确高度，比如 `height: 200px`。

## 一行代码做水平居中

过去用 `margin: 0 auto` 做水平居中，要求元素是 block 且有固定宽度。用 Flex 只需要两行：

```css
.container {
  display: flex;
  justify-content: center; /* 水平居中 */
  align-items: center;     /* 垂直居中 */
  height: 200px;
}
```

无论子元素是什么尺寸，都能精准居中。这是 Flex 最常见的用法之一。

翻车现场二：把 justify-content 写成 text-align。

```css
.container {
  display: flex;
  text-align: center; /* 无效 */
}
```

后果：text-align 控制的是**行内内容**的对齐，对 Flex 项目不起作用。Flex 容器要用 justify-content 和 align-items。

## Flex 的默认行为

不设任何对齐属性时，Flex 也有默认表现：

- `flex-direction: row`（主轴水平，从左到右）
- `justify-content: flex-start`（项目靠左）
- `align-items: stretch`（项目拉伸填满交叉轴）
- `flex-wrap: nowrap`（不换行，项目被压缩）

## 小结

- `display: flex` 把父元素变成 Flex 容器，直接子元素自动成项目。
- 主轴是排列方向，交叉轴垂直于主轴。
- `justify-content` 管主轴分布，`align-items` 管交叉轴对齐。
- 居中只需要 `justify-content: center` + `align-items: center`，比 margin auto 优雅。
- align-items 要生效，交叉轴必须有空间（容器需有高度）。

## 随堂练习

```quiz
type: css
q: 让 .box 用 flex 布局，子元素水平居中（justify-content: center），垂直居中（align-items: center），容器高度 200px。
html: |
  <div class="box">
    <span>居中内容</span>
  </div>
starter: |
  .box {
  }
checks:
- getComputedStyle(document.querySelector('.box')).display === 'flex'
- getComputedStyle(document.querySelector('.box')).justifyContent === 'center'
- getComputedStyle(document.querySelector('.box')).alignItems === 'center'
- getComputedStyle(document.querySelector('.box')).height === '200px'
hint: 先设 display: flex，再设 justify-content 和 align-items 为 center，最后给高度。
explain: Flex 的双 center 是经典居中方案，justify-content 管水平、align-items 管垂直。
```
