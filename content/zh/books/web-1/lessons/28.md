# 写 CSS 样式：统一的设计系统

> 这一节解决"怎么让整个页面的间距和颜色保持一致"的问题。答案是：**用 CSS 变量统一管理，一次定义，全局复用**——这就是设计系统的雏形。

## CSS 变量：一次定义，全局复用

CSS 变量（Custom Properties）用 `--` 定义，用 `var()` 引用：

```css
:root {
  --color-primary: #2c3e50;
  --color-accent: #4a90d9;
  --color-bg: #f8f9fa;
  --color-card: #ffffff;
  --color-text: #333333;
  --color-muted: #888888;

  --space-sm: 8px;
  --space-md: 16px;
  --space-lg: 24px;
  --space-xl: 48px;

  --radius: 8px;
  --shadow: 0 2px 8px rgba(0,0,0,0.08);
}

body {
  background: var(--color-bg);
  color: var(--color-text);
}

.card {
  background: var(--color-card);
  border-radius: var(--radius);
  box-shadow: var(--shadow);
  padding: var(--space-lg);
}
```

好处：想改主题色？只改 `--color-primary` 一行，全站生效。

翻车现场一：颜色值写得到处都是。

```css
h1 { color: #2c3e50; }
h2 { color: #2c3e50; }
.nav a:hover { color: #2c3e50; }
.footer { border-top: 2px solid #2c3e50; }
```

后果：产品经理说"主色改成深蓝色"，你得全局搜索 `#2c3e50` 一个个改，还怕漏改。用 CSS 变量，一行搞定。

## 设计系统的雏形

"设计系统"听起来很高大上，本质就是：**把颜色、间距、圆角、字号这些基础值统一定义，全站复用**。

```css
:root {
  /* 颜色 */
  --color-primary: #2c3e50;
  --color-accent: #4a90d9;
  --color-bg: #f8f9fa;
  --color-card: #ffffff;
  --color-text: #333333;
  --color-muted: #888888;

  /* 间距 */
  --space-xs: 4px;
  --space-sm: 8px;
  --space-md: 16px;
  --space-lg: 24px;
  --space-xl: 48px;

  /* 圆角 */
  --radius-sm: 4px;
  --radius-md: 8px;
  --radius-lg: 16px;

  /* 字号 */
  --font-sm: 0.875rem;
  --font-md: 1rem;
  --font-lg: 1.25rem;
  --font-xl: 1.5rem;
  --font-xxl: 2rem;
}
```

这样写出来的 CSS 非常一致：

```css
h1 { font-size: var(--font-xxl); color: var(--color-primary); margin-bottom: var(--space-lg); }
h2 { font-size: var(--font-xl); color: var(--color-primary); margin-bottom: var(--space-md); }
.card { padding: var(--space-lg); border-radius: var(--radius-md); }
```

## 简历页的完整样式

```css
/* ===== 基础重置 ===== */
* { margin: 0; padding: 0; box-sizing: border-box; }

body {
  font-family: -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif;
  font-size: var(--font-md);
  line-height: 1.6;
  color: var(--color-text);
  background: var(--color-bg);
}

/* ===== 布局容器 ===== */
.container {
  max-width: 900px;
  margin: 0 auto;
  padding: var(--space-xl) var(--space-md);
}

/* ===== 头部 ===== */
.site-header {
  text-align: center;
  padding: var(--space-xl) 0;
  border-bottom: 2px solid var(--color-accent);
  margin-bottom: var(--space-xl);
}

.site-header h1 {
  font-size: var(--font-xxl);
  color: var(--color-primary);
}

.site-header .title {
  font-size: var(--font-lg);
  color: var(--color-muted);
  margin: var(--space-sm) 0;
}

.social {
  display: flex;
  justify-content: center;
  gap: var(--space-lg);
  margin-top: var(--space-md);
}

.social a {
  color: var(--color-accent);
  text-decoration: none;
}

.social a:hover {
  text-decoration: underline;
}

/* ===== 区块 ===== */
section {
  margin-bottom: var(--space-xl);
}

section h2 {
  font-size: var(--font-xl);
  color: var(--color-primary);
  border-left: 4px solid var(--color-accent);
  padding-left: var(--space-md);
  margin-bottom: var(--space-lg);
}

/* ===== 经历卡片 ===== */
.job {
  background: var(--color-card);
  border-radius: var(--radius-md);
  padding: var(--space-lg);
  box-shadow: var(--shadow);
  margin-bottom: var(--space-md);
}

.job h3 {
  font-size: var(--font-lg);
  color: var(--color-primary);
}

.job time {
  display: block;
  font-size: var(--font-sm);
  color: var(--color-muted);
  margin: var(--space-xs) 0 var(--space-sm);
}

/* ===== 底部 ===== */
.site-footer {
  text-align: center;
  padding: var(--space-lg) 0;
  border-top: 1px solid #ddd;
  color: var(--color-muted);
  font-size: var(--font-sm);
}
```

翻车现场二：忘记 `box-sizing: border-box`。

```css
* { margin: 0; padding: 0; }
/* 漏了 box-sizing: border-box */
```

后果：设了 `width: 100%` + `padding: 16px` 的元素会超出父容器，因为默认 `content-box` 下 padding 加在 width 外面。加了 `box-sizing: border-box` 后 padding 包含在 width 内，布局可预测。

## 小结

- CSS 变量（Custom Properties）用 `--` 定义、`var()` 引用，实现一次定义全局复用。
- 设计系统 = 统一管理的颜色、间距、圆角、字号。
- 好处：改主题只需改几行变量，全站同步更新。
- `* { box-sizing: border-box }` 是布局可预测的基础，别忘了。

type: css

  <div class="card">内容卡片</div>
