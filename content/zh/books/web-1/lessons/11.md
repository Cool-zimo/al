# 列表：ul、ol、dl

> 这一节解决"怎么把一组并列的内容组织起来"的问题。导航菜单为什么要用列表？因为它本来就是"一组并列选项"。

## 三种列表

```html
<!-- 无序列表 -->
<ul>
  <li>苹果</li>
  <li>香蕉</li>
  <li>橙子</li>
</ul>

<!-- 有序列表 -->
<ol>
  <li>打开浏览器</li>
  <li>输入网址</li>
  <li>按回车</li>
</ol>

<!-- 描述列表 -->
<dl>
  <dt>HTML</dt>
  <dd>网页的结构语言</dd>
  <dt>CSS</dt>
  <dd>网页的样式语言</dd>
</dl>
```

- `<ul>` 无序列表：顺序不重要，前面是小圆点。
- `<ol>` 有序列表：顺序重要，前面是数字。
- `<dl>` 描述列表：一组"术语—解释"对，适合做名词表、参数说明。

## li 才是列表的真正成员

```html
<ul>
  <li>第一项</li>
  <li>第二项</li>
</ul>
```

只有 `<li>` 能直接放在 `<ul>` / `<ol>` 里。写别的标签在规范上是不合法的，浏览器虽然会渲染，但结构不干净。

翻车现场一：列表项里直接写文字，不用 li。

```html
<ul>
  苹果
  香蕉
  橙子
</ul>
```

后果：浏览器会显示，但 `<ul>` 里只有文本节点、没有 li 元素，语义上它不是一个列表。读屏软件不会按列表朗读，CSS 选择器也选不到"列表项"。

## 导航为什么要用 ul

导航的本质是什么？是"一组并列的跳转链接"。这正好符合列表的语义。

```html
<nav>
  <ul class="menu">
    <li><a href="/">首页</a></li>
    <li><a href="/about">关于</a></li>
    <li><a href="/contact">联系</a></li>
  </ul>
</nav>
```

用 `<ul>` + `<li>` 的好处：

1. **语义正确**：读屏用户听到"列表，共 3 项"，知道这里是一组选项。
2. **结构清晰**：每个链接被 li 包住，可以单独控制样式、加分隔线。
3. **天然层级**：子菜单可以继续嵌套 ul，结构分明。

翻车现场二：导航用一堆 div。

```html
<nav>
  <div><a href="/">首页</a></div>
  <div><a href="/about">关于</a></div>
  <div><a href="/contact">联系</a></div>
</nav>
```

后果：看着差不多，但语义上只是一堆 div。读屏软件无法告诉用户"这里有 3 个导航项"。而且 div 是块级元素，默认占一整行，要做横向菜单得写更多 CSS 去覆盖。

## 嵌套列表

```html
<ul>
  <li>水果
    <ul>
      <li>苹果</li>
      <li>香蕉</li>
    </ul>
  </li>
  <li>蔬菜
    <ul>
      <li>白菜</li>
      <li>西红柿</li>
    </ul>
  </li>
</ul>
```

子列表放在父级 li 的**内部**。注意：子 ul 是嵌在 li 里面，不是和 li 平级。

## 小结

- `<ul>` 无序、`<ol>` 有序、`<dl>` 描述，各有适用场景。
- 列表项必须用 `<li>`，不能裸写文字。
- 导航用 ul 是语义正确的选择，结构清晰、可访问性好。
- 嵌套列表时子 ul 放在父 li 内部。

## 随堂练习

```quiz
type: html
q: 写一个有序列表，包含三项：北京、上海、广州，内容分别在三个 li 里。
starter: |
  <ol>
  </ol>
checks:
- document.querySelectorAll('ol').length === 1
- document.querySelectorAll('li').length === 3
- document.querySelectorAll('li')[0].textContent.trim() === '北京'
- document.querySelectorAll('li')[1].textContent.trim() === '上海'
- document.querySelectorAll('li')[2].textContent.trim() === '广州'
hint: 在 ol 内写三个 li，内容依次为三个城市名。
explain: ol 包裹三个 li，li 的顺序和内容决定有序列表的呈现。
```

- 用 ul 写起来更快

  </ul>

hint: 第一个 ul 三个 li，其中第一个 li 内部再放一个 ul。
