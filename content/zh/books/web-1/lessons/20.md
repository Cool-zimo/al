# Flex 进阶：方向、换行与弹性分配

> 这一节解决"怎么让 Flex 项目纵向排列、自动换行、按比例分配空间"的问题。flex-direction、flex-wrap、flex 这三个属性能覆盖绝大多数日常布局需求。

## flex-direction：改变主轴方向

默认主轴是水平的（row）。用 `flex-direction` 可以改成垂直方向。

```css
.container {
  display: flex;
  flex-direction: column; /* 主轴变成从上到下 */
}
```

取值有四种：

| 取值 | 效果 |
|---|---|
| row | 主轴水平，从左到右（默认） |
| row-reverse | 主轴水平，从右到左 |
| column | 主轴垂直，从上到下 |
| column-reverse | 主轴垂直，从下到上 |

翻车现场一：用了 flex-direction: column，justify-content 却还是水平居中。

```css
.container {
  display: flex;
  flex-direction: column;
  justify-content: center; /* 现在是垂直居中 */
}
```

这是**正确理解**——因为主轴变了，justify-content 就沿垂直方向排列。很多人混淆"justify-content 永远管水平"，其实它管的是**主轴**，主轴方向由 flex-direction 决定。

## flex-wrap：允许换行

默认 `flex-wrap: nowrap`，所有项目挤在一行，即使溢出容器也会被压缩。设成 `wrap` 允许换行。

```css
.container {
  display: flex;
  flex-wrap: wrap;
}
```

```html
<div class="container">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
  <div class="item">4</div>
</div>
```

```css
.container { width: 360px; display: flex; flex-wrap: wrap; }
.item { width: 100px; height: 60px; margin: 5px; background: #4a90d9; }
```

容器 360px 宽，每个 item 100px+10px margin，一行放不下 4 个，wrap 后第 4 个自动换到第二行。

## flex：弹性分配的核心

`flex` 是 `flex-grow`、`flex-shrink`、`flex-basis` 的简写。最常用的是 `flex: 1`。

```css
.sidebar {
  flex: 0 0 200px; /* 不放大、不缩小、基准 200px */
}
.main {
  flex: 1; /* 占满剩余空间 */
}
```

这样 `.sidebar` 固定 200px，`.main` 自动填满剩下的宽度。页面无论多宽，比例始终如此。

```html
<div class="layout">
  <aside class="sidebar">侧边栏</aside>
  <section class="main">主内容</section>
</div>
```

```css
.layout { display: flex; height: 300px; }
.sidebar { flex: 0 0 200px; background: #e0f0ff; }
.main { flex: 1; background: #f0f0f0; }
```

翻车现场二：多个项目都写了 flex: 1，却期望一个固定一个弹性。

```css
.item-a { flex: 1; }
.item-b { flex: 1; }
```

后果：a 和 b 各占一半。如果只想让 b 弹性、a 固定，应该写成 `.item-a { width: 120px; }` 和 `.item-b { flex: 1; }`。

## Flex 做居中的完整对比

回顾三种居中方案：

```css
/* 方案 A：margin auto，要求固定宽度 */
.center-a {
  width: 200px;
  margin: 0 auto;
}

/* 方案 B：Flex，不要求固定宽度 */
.center-b {
  display: flex;
  justify-content: center;
  align-items: center;
}

/* 方案 C：绝对定位 + transform */
.center-c {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

Flex 方案最优雅：不依赖固定尺寸、不脱离文档流、一个容器搞定两个方向。

## 小结

- flex-direction 改变主轴方向，row 是默认、column 是纵向。
- justify-content 始终沿主轴对齐，主轴变了方向它也跟着变。
- flex-wrap: wrap 允许项目换行，避免溢出压缩。
- flex: 1 让项目弹性占满剩余空间，flex: 0 0 200px 做固定尺寸。
- Flex 居中（双 center）是最常用、最优雅的居中方案。

## 随堂练习

```quiz
type: css
q: 让 .container 用 flex 布局，flex-direction 为 column（纵向排列），justify-content 为 center（垂直居中），容器内三个 div 纵向居中排列。
html: |
  <div class="container">
    <div>一</div>
    <div>二</div>
    <div>三</div>
  </div>
starter: |
  .container {
  }
checks:
- getComputedStyle(document.querySelector('.container')).display === 'flex'
- getComputedStyle(document.querySelector('.container')).flexDirection === 'column'
- getComputedStyle(document.querySelector('.container')).justifyContent === 'center'
- document.querySelectorAll('.container > div').length === 3
hint: display: flex 开启弹性盒，flex-direction: column 改纵向，justify-content: center 居中。
explain: 主轴变为纵向后，justify-content: center 沿垂直方向居中排列子元素。
```

```quiz
type: choice
exam: true
q: 关于 flex-wrap 的作用，下列说法正确的是？
options:
- flex-wrap: nowrap 时项目超出容器会自动换行
- flex-wrap: wrap 时项目超出容器会自动换到下一行
- flex-wrap 只能用于 flex-direction: column
- flex-wrap 决定项目在主轴上的对齐方式
answer: 1
explain: flex-wrap: wrap 允许 Flex 项目在空间不足时换行排列；nowrap 是默认值，项目会被压缩而不换行。主轴对齐由 justify-content 决定。
```
