# 属性与链接：href、target、alt

> 这一节解决"标签上的那些额外信息怎么写"的问题。属性是标签的"参数"，链接和图片都离不开它。

## 属性写在开始标签里

```html
<a href="https://www.python.org">Python 官网</a>
<img src="photo.jpg" alt="张三的照片">
<p class="intro">一段介绍</p>
```

格式是 `属性名="值"`。属性提供标签本身无法表达的额外信息：`a` 标签需要靠 `href` 知道"链接到哪儿"，`img` 需要靠 `src` 知道"图片在哪儿"。

## 链接：a 标签

```html
<a href="https://www.example.com">访问示例网站</a>
```

`href` 可以是网址，也可以是站内文件路径，还可以是页面内的锚点。

```html
<a href="#section2">跳到第二章</a>
<h2 id="section2">第二章</h2>
```

`href="#section2"` 表示"跳到 id 为 section2 的元素"。这在长页面做目录导航时很常用。

## target：在哪里打开

```html
<a href="https://www.example.com" target="_blank">新窗口打开</a>
```

`target="_blank"` 让链接在新标签页打开。不加的话，默认在当前页跳转。给外部链接加 `_blank` 是常见做法，但要注意：新窗口里的页面可以通过 `window.opener` 访问原页面，存在安全隐患。规范写法是同时加 `rel="noopener"`：

```html
<a href="https://www.example.com" target="_blank" rel="noopener">新窗口打开</a>
```

## 相对路径 vs 绝对路径

假设目录结构是这样：

```
my-site/
├── index.html
├── about.html
└── pages/
    └── contact.html
```

从 `index.html` 链接到 `about.html`：

```html
<a href="about.html">关于</a>            <!-- 同级，直接写文件名 -->
<a href="pages/contact.html">联系</a>    <!-- 子目录，加路径 -->
<a href="pages/contact.html">联系我们</a>
```

| 路径写法 | 含义 |
|---|---|
| `about.html` | 同级目录下的文件 |
| `pages/contact.html` | 当前目录的 pages 子目录 |
| `../images/photo.jpg` | `..` 表示上一级目录 |
| `/style.css` | 从网站根目录开始（绝对路径） |

绝对路径以 `/` 开头，表示从网站根目录算起；相对路径不带 `/`，从当前文件位置算起。张三把站点部署到 `https://zhangsan.com/resume/` 子目录下时，如果用绝对路径 `/style.css`，浏览器会去找 `https://zhangsan.com/style.css`——很可能 404。这种时候用相对路径更稳妥。

## alt 属性为什么必须有

```html
<img src="zhangsan.jpg" alt="张三在北京大学门口的毕业照">
```

`alt` 是图片的**替代文本**。它有三个用途：

1. 图片加载失败（路径写错、网络断了）时，显示这段文字。
2. 读屏软件会读出 alt 内容，视障用户才知道这里有什么图。
3. 搜索引擎靠 alt 理解图片内容。

翻车现场一：alt 留空但图片是内容性的。

```html
<img src="chart.png" alt="">
```

后果：alt 为空时读屏软件会**直接跳过**这张图。如果这是一张重要的图表，视障用户就完全错过了信息。只有装饰性图片（纯美化用、没有信息量）才适合留空 alt。

翻车现场二：路径写错。

```html
<img src="images/photo.jpg">
```

后果：文件实际在 `img/photo.jpg`，路径写成了 `images/`，页面上就是一个破图图标。相对路径是相对于**当前 HTML 文件**的位置，不是相对于你写代码时想当然的位置。张三的简历里图片放 `assets/` 目录，但代码里写 `../assets/photo.jpg`，多了一层 `..`，图片就找不到了。

## 小结

- 属性写在开始标签里，格式 `name="value"`。
- `href` 决定链接目标，可以是网址、文件路径或 `#id` 锚点。
- 新窗口打开要写 `target="_blank" rel="noopener"`。
- 相对路径相对于当前文件，绝对路径以 `/` 从根目录算起。
- `alt` 必须有；内容性图片写清楚描述，装饰性图片才留空。

## 随堂练习

```quiz
type: html
q: 写一个 a 标签，href 为"https://www.python.org"，target 为"_blank"，rel 为"noopener"，链接文字是"Python"。
starter: |
  <a href="https://www.python.org">Python</a>
checks:
- document.querySelectorAll('a').length === 1
- document.querySelector('a').getAttribute('href') === 'https://www.python.org'
- document.querySelector('a').getAttribute('target') === '_blank'
- document.querySelector('a').getAttribute('rel') === 'noopener'
hint: 在 a 标签上继续加 target 和 rel 两个属性。
explain: a 标签需要同时具备 href、target、rel 三个属性才符合要求。
```
