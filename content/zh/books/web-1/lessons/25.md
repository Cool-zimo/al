# 过渡与动画：让页面动起来

> 这一节解决"怎么让按钮 hover 时平滑变色"和"怎么做一个加载动画"的问题。CSS 动画不需要 JavaScript，浏览器用 GPU 加速，性能好。

## transition：过渡

`transition` 让属性变化不再是"瞬移"，而是有一个过渡过程。

```css
.button {
  background: #4a90d9;
  padding: 10px 20px;
  color: white;
  border: none;
  border-radius: 4px;
  transition: background 0.3s ease;
}

.button:hover {
  background: #357abd;
}
```

鼠标移上去，背景色在 0.3 秒内平滑地从浅蓝变深蓝，而不是瞬间跳变。

`transition` 的完整语法：

```css
transition: 属性名 时长 缓动函数 延迟;
transition: background 0.3s ease 0s;
```

四个值：
- **属性名**：监听哪个属性变化。`all` 表示所有可动画属性。
- **时长**：0.3s、300ms。
- **缓动函数**：ease（默认）、linear、ease-in、ease-out、ease-in-out。
- **延迟**：等多少秒后开始。

翻车现场一：过渡不生效，属性值没变。

```css
.box {
  transition: width 0.5s;
}
```

```html
<div class="box">内容</div>
```

后果：没有任何过渡效果。原因：transition 监听的是**属性值变化**——`.box` 的 width 从没被改变过（没有 hover、没有 class 切换）。transition 不会凭空产生动画，它需要触发条件。

翻车现场二：想过渡 display 属性。

```css
.dropdown {
  display: none;
  transition: display 0.3s;
}
.dropdown.show {
  display: block;
}
```

后果：过渡不生效。display 是离散属性，无法插值。`none` 到 `block` 只能瞬切。要动画显示隐藏，应该用 `opacity` + `visibility` 或 `max-height`。

## transform：位移、缩放、旋转

`transform` 可以在不改变布局的情况下移动、缩放、旋转元素。

```css
.card {
  transition: transform 0.2s ease;
}
.card:hover {
  transform: translateY(-4px); /* 上移 4px */
}
```

```css
.zoom:hover {
  transform: scale(1.05);  /* 放大 5% */
}
.rotate {
  transform: rotate(45deg); /* 旋转 45 度 */
}
.skew {
  transform: skewX(10deg);  /* 水平倾斜 */
}
```

## transform 比改 left/top 性能好

改 `left` 和 `top` 会触发布局重算（reflow），而 `transform` 和 `opacity` 只触发合成（composite），由 GPU 处理，不重排不重绘。

翻车现场三：用 left/top 做移动动画，页面卡顿。

```css
.box {
  position: relative;
  left: 0;
  transition: left 0.5s;
}
.box:hover {
  left: 100px; /* 触发 reflow */
}
```

更好的写法：

```css
.box {
  transform: translateX(0);
  transition: transform 0.5s;
}
.box:hover {
  transform: translateX(100px); /* GPU 加速，不触发 reflow */
}
```

## @keyframes：关键帧动画

`transition` 只能做"一个状态到另一个状态"的过渡。`@keyframes` 可以做多关键帧的复杂动画。

```css
@keyframes pulse {
  0%   { transform: scale(1); }
  50%  { transform: scale(1.1); }
  100% { transform: scale(1); }
}

.loading {
  animation: pulse 1.5s ease infinite;
}
```

```html
<div class="loading">加载中…</div>
```

`pulse` 定义了三个关键帧：初始大小 → 放大 10% → 回到初始。`infinite` 表示无限循环。

翻车现场四：动画播放完就消失了。

```css
.tip {
  animation: slideIn 0.5s ease;
}
```

后果：动画播放完后元素回到初始状态（transform: none）。如果希望动画结束后停在最后一帧，加 `forwards`：

```css
.tip {
  animation: slideIn 0.5s ease forwards;
}
```

## 小结

- `transition` 让属性变化有过渡效果，需要触发条件。
- transition 监听的属性必须是可插值的（display 不行）。
- `transform` 做位移/缩放/旋转，GPU 加速不触发重排。
- 移动动画优先用 transform 代替 left/top。
- `@keyframes` 定义多关键帧动画，`forwards` 保持结束状态。
