# 相对单位与流式布局

> 这一节解决"为什么不要写死宽度"和"rem、em、%、vw 到底该怎么选"的问题。选对单位，布局才能跟着屏幕一起"流动"。

## 为什么不要写死宽度

写死 `width: 1200px` 意味着：你的布局只在 1200px 及以上的屏幕上正常，其余尺寸下要么溢出、要么大片留白。

流式布局的思路是：**让尺寸跟着父容器或视口走**。

```css
/* 写死：不灵活 */
.container-fixed {
  width: 1000px;
}

/* 流式：跟随父容器 */
.container-fluid {
  width: 100%;
  max-width: 1200px;  /* 设上限，超大屏不失控 */
  margin: 0 auto;     /* 居中 */
}
```

`max-width: 1200px` 是个好习惯：窄屏时 100% 填满，宽屏时最多 1200px 并居中，两全其美。

## 百分比：相对父元素

```css
.child {
  width: 50%; /* 父元素宽度的一半 */
}
```

百分比总是相对于**父元素的对应属性**。width: 50% 相对父元素的 width，padding-top: 50% 也相对父元素的 width（没错，连垂直方向的百分比 padding 也是相对宽度算的）。

翻车现场一：百分比高度不生效。

```css
.child {
  height: 50%; /* 可能不生效 */
}
```

后果：`.child` 高度为 0。原因：百分比高度依赖父元素有明确的高度，如果父元素高度是 `auto`（由内容撑开），子元素的 `height: 50%` 就无从参考。解决：给父元素设固定高度，或用 `min-height`。

## rem 和 em：相对字体

- `rem`：相对**根元素（html）**的字体大小。根字号默认 16px，所以 `1rem = 16px`，`1.5rem = 24px`。
- `em`：相对**当前元素**的字体大小。

```css
html {
  font-size: 16px; /* 根字号 */
}

.box {
  font-size: 1.2rem;  /* 19.2px，相对根元素 */
  padding: 1rem;      /* 16px */
  margin: 0.5em;       /* 相对自身 font-size = 9.6px */
}
```

翻车现场二：嵌套元素中 em 层层放大。

```css
body { font-size: 16px; }
.level-1 { font-size: 1.2em; }   /* 19.2px */
.level-2 { font-size: 1.2em; }   /* 23.04px！ */
.level-3 { font-size: 1.2em; }   /* 27.65px！ */
```

后果：每嵌套一层，em 就相对上一层放大，越嵌套越大，很快失控。解决：统一用 rem，只相对根字号，不会层层叠加。

## vw / vh：相对视口

- `vw`：视口宽度的 1%。`100vw` = 满屏宽。
- `vh`：视口高度的 1%。`100vh` = 满屏高。

```css
.hero {
  width: 100vw;
  height: 100vh;        /* 占满整个屏幕 */
  font-size: 4vw;       /* 字号随屏幕宽度变化 */
}
```

翻车现场三：100vw 导致横向滚动条。

```css
body {
  margin: 0;
}
.full {
  width: 100vw; /* 包含滚动条宽度！ */
}
```

后果：100vw 包含浏览器滚动条的宽度，可能导致页面出现横向滚动条。解决：用 `width: 100%` 代替。

## 流式布局的实际应用

```css
img {
  max-width: 100%;
  height: auto; /* 保持宽高比缩放 */
}

.container {
  width: 100%;
  max-width: 1200px;
  margin: 0 auto;
  padding: 0 16px;
}

.card {
  flex: 1 1 300px; /* 基准 300px，可放大可缩小 */
}
```

三个技巧：
1. 图片 `max-width: 100%` + `height: auto` 保证不溢出且不变形。
2. 容器 `max-width` + `margin: auto` 兼顾窄屏和宽屏。
3. Flex 项目用 `flex: 1 1 300px` 做流式卡片网格（配合 flex-wrap）。

## 小结

- 写死宽度不灵活，流式布局让尺寸跟随容器或视口。
- `max-width` 兼顾窄屏填满和宽屏限制。
- rem 相对根字号，不会层层叠加；em 嵌套会放大，慎用。
- vw/vh 相对视口，100vw 可能包含滚动条宽度。
- 图片用 `max-width: 100%; height: auto` 弹性缩放。

## 随堂练习

```quiz
type: css
q: 让 .container 宽度为 100%，最大宽度 1000px，水平居中（margin: 0 auto），左右内边距 20px。
html: |
  <div class="container">内容区域</div>
starter: |
  .container {
  }
checks:
- Math.abs(parseFloat(getComputedStyle(document.querySelector('.container')).width) - document.body.clientWidth) < 3
- getComputedStyle(document.querySelector('.container')).maxWidth === '1000px'
- getComputedStyle(document.querySelector('.container')).marginLeft === getComputedStyle(document.querySelector('.container')).marginRight
- getComputedStyle(document.querySelector('.container')).paddingLeft === '20px'
- getComputedStyle(document.querySelector('.container')).paddingRight === '20px'
hint: width: 100% 填满，max-width 设上限，margin 左右 auto 居中。
explain: 流式容器用 width: 100% + max-width 上限 + margin auto 居中，兼顾各尺寸屏幕。
```
