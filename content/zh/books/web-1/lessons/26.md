# 项目设计：规划一个个人简历页

> 这一节解决"拿到一个页面需求，从哪里开始"的问题。好的前端开发不是上来就写代码，而是先想清楚结构、配色和信息层级。

## 先想结构，再想样式

很多初学者拿到需求就打开编辑器开始写 `<div>`，写到一半发现结构乱了，返工重来。正确的做法是**先画草图，再写代码**。

我们的项目是"个人简历页"，包含这些内容：

| 区块 | 内容 | 用什么标签 |
|---|---|---|
| 头部 | 姓名、职位、联系方式 | `<header>` |
| 关于我 | 一段自我介绍 | `<section>` |
| 技能 | 技能列表（语言/框架） | `<section>` + `<ul>` |
| 工作经历 | 时间线形式 | `<section>` + `<ul>` |
| 项目经验 | 项目卡片 | `<section>` + `<article>` |
| 底部 | 版权/社交链接 | `<footer>` |

## 语义化结构的好处

```html
<header>
  <h1>张三</h1>
  <p>前端工程师</p>
</header>
<section>
  <h2>关于我</h2>
  <p>5 年 Web 开发经验……</p>
</section>
```

用 `<header>`、`<section>`、`<footer>` 而不是一堆 `<div>`：

1. **SEO 友好**：搜索引擎能理解页面结构。
2. **可访问性好**：读屏软件能按区块导航。
3. **代码可读**：半年后回来看，一眼知道每个区块是干什么的。

## 配色方案

简历页不需要花哨，选 2~3 个主色就够了：

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 | `#2c3e50` | 标题、强调文字 |
| 辅色 | `#4a90d9` | 链接、按钮、时间线标记 |
| 背景 | `#f8f9fa` | 页面底色 |
| 卡片 | `#ffffff` | 卡片背景 |
| 正文 | `#333333` | 正文文字 |

翻车现场一：用了一堆高饱和度颜色，页面像彩虹。

后果：视觉噪音大，用户不知道该看哪里。简历是信息型页面，配色要克制，用颜色引导视线而不是分散注意力。

## 信息层级

简历页的信息有主次之分，用字号和间距建立层级：

- **姓名**：最大字号（2rem ~ 2.5rem），主色
- **区块标题**（关于我、技能、经历）：1.5rem，主色，加粗
- **正文**：1rem，正文色，行高 1.6
- **辅助信息**（时间、地点）：0.875rem，灰色

```css
:root {
  --color-primary: #2c3e50;
  --color-accent: #4a90d9;
  --color-bg: #f8f9fa;
  --color-card: #ffffff;
  --color-text: #333333;
  --color-muted: #888888;
}

h1 { font-size: 2rem; color: var(--color-primary); }
h2 { font-size: 1.5rem; color: var(--color-primary); }
body { font-size: 1rem; color: var(--color-text); line-height: 1.6; }
```

注意这里的 `--color-*` 写法——这是 **CSS 变量**（Custom Properties），定义一次，全局复用。后面第 28 课会详细讲。

## 布局规划

简历页整体用以下布局策略：

- **页面容器**：`max-width: 900px`，居中
- **区块间距**：`margin-bottom: 48px`，区块之间留出呼吸空间
- **卡片**：白底、圆角 8px、轻微阴影
- **移动端**：单列堆叠；`>= 768px`：某些区块可以两列

## 小结

- 做页面先想结构再写代码，画草图比直接开写效率高。
- 语义化标签（header/section/footer）提升 SEO 和可访问性。
- 配色克制，2~3 个主色足够，颜色引导视线。
- 字号和间距建立信息层级，用户一眼看出重点。
- CSS 变量统一管理颜色和间距，方便后续调整。

## 随堂练习

```quiz
type: html
q: 写一个简历页的头部结构：header 里放一个 h1（内容为"张三"），h1 后面放一个 p（内容为"前端工程师"），p 后面放一个 nav，nav 里放三个 a 链接：邮箱、GitHub、掘金。
starter: |
  <header>
  </header>
checks:
- document.querySelector('header h1').textContent.trim() === '张三'
- document.querySelector('header p').textContent.trim() === '前端工程师'
- document.querySelector('header nav') !== null
- document.querySelectorAll('header nav a').length === 3
- Array.from(document.querySelectorAll('header nav a')).map(a => a.textContent.trim()).join(',') === '邮箱,GitHub,掘金'
hint: header 内依次放 h1、p、nav，nav 内放三个 a。
explain: header 包含个人信息和社交链接导航，是简历页的头部区块。
```
