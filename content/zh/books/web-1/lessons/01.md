# 浏览器、HTML、CSS 各管什么

> 这一节解决"我写的文本为什么能变成网页"的问题。理解了分工，后面写错样式才知道去哪儿找。

## 一个页面是三个人合作的

你已经学过 Python：写代码，解释器一行行执行，最后打印结果。前端也是"写文本、让机器处理"，但这次的机器是**浏览器**，而且它手里有三份文件，各管一摊事。

把做一个网页想成盖房子：

| 角色 | 前端对应 | 管什么 |
|---|---|---|
| 结构工人 | **HTML** | 哪里是墙、哪里是门、几间房 |
| 装修队 | **CSS** | 墙面刷什么色、地板铺多宽 |
| 电工/智能设备 | **JavaScript** | 灯怎么亮、门铃按了会怎样 |

张三买了块地，先画结构图（HTML）：这里一间卧室、那里一个客厅。结构图里**不会**写"墙刷米色、地板用橡木"——那是装修队（CSS）的事。同样，HTML 里也不该写"这个字是红色的"，颜色归 CSS。

## 浏览器是翻译官

你写的 `.html` 文件，本质就是纯文本。双击打开后，浏览器读到的第一件事是一个字符串：

```html
<!DOCTYPE html>
<html>
  <head>
    <title>张三的主页</title>
  </head>
  <body>
    <h1>你好</h1>
    <p>这是我的第一个页面。</p>
  </body>
</html>
```

浏览器做三件事：

1. **解析**：把这段文本拆成节点，生成一个树状结构，叫 **DOM**（Document Object Model）。
2. **计算样式**：给每个节点算出"最终长什么样"。
3. **绘制**：把结果画到屏幕上。

你在 Python 里操作过字典、列表这样的数据结构。DOM 也是一棵数据结构——只是它不是你手动建的，而是浏览器根据你写的 HTML **自动**建的。你写 `<h1>你好</h1>`，浏览器就造出一个 h1 节点，内容是"你好"。

**DOM 是前端一切操作的对象。** 后面写 CSS 选中元素、写 JS 改文字，本质都是在跟这棵树打交道。理解这一点，比背标签名重要得多。

## HTML 只描述"是什么"，不描述"长什么样"

```html
<h1>张三的简历</h1>
<p>我是一名前端开发工程师。</p>
```

这里 `<h1>` 的意思是"这是一个一级标题"，`<p>` 的意思是"这是一段正文"。你**没有**说它多大、什么字体、什么颜色。那些事归 CSS。

有人会问：可是我看到 h1 默认就很大啊？那是因为浏览器自带了一份"出厂样式表"（叫 user agent stylesheet），它给 h1 加了默认字号。那是浏览器给的，不是 HTML 给的。你可以、也应该在自己的 CSS 里把它改成你想要的样子。

## CSS 只负责"长什么样"

```css
h1 {
  color: #2c7a7b;
  font-size: 32px;
}
```

这段 CSS 的意思是：所有 h1 用这个青色、字号 32 像素。注意它**没有**改变 h1 是"一级标题"这件事——语义仍然是 h1，变的只是外观。

## 翻车现场一：用标签来"凑外观"

有人想要大字，就这么写：

```html
<h1>副标题，但我想要大一点</h1>
<h1>另一个副标题</h1>
```

后果：页面上字是大了，但搜索引擎、屏幕阅读器、浏览器大纲都会以为这是两个一级标题。张三的简历在搜索结果里会出现两个"主标题"，视障用户用读屏软件听到的是"一级标题、一级标题"——结构乱了。正确做法是 `<h2>` + CSS 调字号。

## 翻车现场二：把样式写进 HTML

```html
<p style="color: red; font-size: 20px; margin: 10px;">一段文字</p>
<p style="color: red; font-size: 20px; margin: 10px;">另一段</p>
<p style="color: red; font-size: 20px; margin: 10px;">又一段</p>
```

后果：三处要改颜色，得改三遍；想让全站的段落统一，得搜遍所有文件。样式散落在结构里，后面维护就是灾难。后面第 06 课会讲为什么**外链 CSS**才是正解。

## 一个最小可运行页面

新建一个 `index.html`，内容如下，双击用浏览器打开：

```html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8">
    <title>张三的主页</title>
    <style>
      h1 { color: #2c7a7b; }
    </style>
  </head>
  <body>
    <h1>你好，我是张三</h1>
    <p>这是我的第一个网页。</p>
  </body>
</html>
```

`<meta charset="UTF-8">` 告诉浏览器用 UTF-8 解码，中文才不会变成乱码。先记住要写，第 02 课会逐个解释每个标签。

## 小结

- 前端三件套的分工：**HTML 是结构，CSS 是样式，JavaScript 是行为**。
- 浏览器把 HTML 解析成 **DOM 树**，之后所有样式和交互都是对这棵树的操作。
- 标签表达的是**语义**（是什么），不是外观（长什么样）。
- 别用错标签凑外观，别把样式写进 HTML 结构里。

## 随堂练习

```quiz
type: html
q: 写三个空的结构标签：一个 h1、一个 p、一个 div，顺序不限，都直接放在 body 里。
starter: |
  <h1></h1>
checks:
- document.querySelectorAll('h1').length === 1
- document.querySelectorAll('p').length === 1
- document.querySelectorAll('div').length === 1
hint: 标签直接并列写即可，不需要嵌套。
explain: h1、p、div 都是块级结构标签，各自独立成节点。
```
