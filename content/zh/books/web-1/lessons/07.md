# 选择器：标签、类、id

> 这一节解决"我写的样式到底会作用到谁身上"的问题。选得准，样式才好维护。

## 三种基础选择器

```css
/* 标签选择器：选中所有该标签 */
p {
  line-height: 1.8;
}

/* 类选择器：选中所有带这个 class 的元素 */
.highlight {
  background-color: yellow;
}

/* id 选择器：选中唯一一个元素 */
#main-title {
  font-size: 36px;
}
```

用法：

```html
<h1 id="main-title">张三的简历</h1>
<p class="highlight">这一段需要高亮</p>
<p>这一段是普通段落</p>
```

## 什么时候用 class，什么时候用 id

这是新手最常问的问题。判断标准很实在：

| 场景 | 用 |
|---|---|
| 多个元素共享同一种样式 | **class** |
| 某个元素独一无二，全页只有一个 | **id** |
| 样式可能需要复用 | **class** |
| 需要页面内锚点跳转（`#xxx`） | id |

class 可以重复使用，一个元素可以有多个 class；id 在一个页面里**只能出现一次**，且一个元素只有一个 id。

```html
<p class="intro highlight">既是一段介绍，又需要高亮</p>
```

翻车现场一：用 id 做通用样式。

```html
<h1 id="title">标题一</h1>
<h1 id="title">标题二</h1>
```

后果：两个元素用了同一个 id。HTML 规范规定 id 必须唯一，浏览器不会报错，但 JavaScript 的 `getElementById` 只会返回第一个，读屏和锚点跳转也只认第一个。样式上两个都生效了，但这是"碰巧"，不是"正确"。

翻车现场二：滥用标签选择器。

```css
p {
  color: blue;
}
```

后果：页面里所有段落都变蓝，包括你想保持默认的那些。标签选择器作用范围太广，容易"误伤"。实际项目中，多用 class 选择器精准控制。

## 组合与层级

```css
/* 后代选择器：选中 article 里所有的 p */
article p {
  color: #444;
}

/* 直接子元素选择器 */
.menu > li {
  list-style: none;
}

/* 多个选择器共用规则 */
h1, h2, h3 {
  font-family: "PingFang SC", sans-serif;
}
```

`article p` 和 `.menu > li` 的差别：前者选 article 里**所有层级**的 p，后者只选 `.menu` 的**直接子元素** li。张三写导航菜单，用 `>` 可以精准控制一级菜单项，而不影响嵌套的子菜单。

## 优先级

```css
p { color: black; }          /* 1 分 */
.intro { color: blue; }      /* 10 分 */
#main { color: red; }        /* 100 分 */
```

分值高的胜出。同分时，后写的覆盖先写的。

```html
<p class="intro" id="main" style="color: green;">文字是什么颜色？</p>
```

内联样式 `style` 优先级最高，所以是绿色。但**不要为了覆盖去堆 id 或用 `!important`**——`!important` 会破坏优先级规则，一旦用了就很难再被覆盖，维护起来很痛苦。

## 小结

- 标签选择器作用广，class 可复用，id 唯一。
- 通用样式用 class；独一无二的元素、需要锚点跳转时用 id。
- 后代选择器选所有层级，直接子元素选择器 `>` 只选一层。
- 优先级：id > class > 标签；尽量别用 `!important`。

## 随堂练习

```quiz
type: css
q: 让 class 为"note"的元素背景色变成浅黄 rgb(255, 248, 225)，文字颜色变成深棕 rgb(120, 90, 40)。
html: |
  <p class="note">这是一条备注</p>
starter: |
  .note {
  }
checks:
- getComputedStyle(document.querySelector('.note')).backgroundColor === 'rgb(255, 248, 225)'
- getComputedStyle(document.querySelector('.note')).color === 'rgb(120, 90, 40)'
hint: 类选择器以英文句点开头，设置两个属性即可。
explain: .note 选中带 note 类的元素，分别设置背景色与文字色。
```
