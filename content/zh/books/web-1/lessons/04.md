# 文本标签：strong、em 与 span、div

> 这一节解决"怎么给一段文字加重点"的问题。判断标准只有一个：**你想表达的是意思还是样子**。

## 语义标签 vs 外观标签

这一课的关键是分清两对：

| 语义标签 | 外观标签 | 区别 |
|---|---|---|
| `<strong>` | `<b>` | strong = 重要，b = 加粗 |
| `<em>` | `<i>` | em = 强调，i = 斜体 |

`<strong>` 说"这段内容很重要"；`<b>` 只说"请把这段字加粗"。浏览器默认都会把 strong 渲染成粗体、把 em 渲染成斜体，所以**看起来一模一样**。差别在于机器怎么理解。

```html
<p>请注意：<strong>明天北京的会议改到下午三点</strong>。</p>
<p>这是一句<em>需要强调</em>的话。</p>
<p>这本书的书名是<i>《前端基础》</i>。</p>
```

第三句里书名用 `<i>` 是合适的：书名字体样式上常用斜体，这里强调的是**外观**而非语气强调。而"明天会议改时间"是重要信息，用 strong。

## 为什么语义重要

读屏软件读到 `<strong>` 时，可能会改变语调、加重语气，提醒用户"这是重点"。读到 `<b>` 时不会——因为 b 只是样式，没有语义分量。

搜索引擎也会给 strong 里的词更高权重。张三在简历里写"我精通 `<strong>`Python`</strong>`"，比写"我精通 `<b>`Python`</b>`"在关键词判断上更明确。

**判断方法**：把 CSS 全部去掉（想象页面只显示纯文本），这段文字仍然需要"强调"吗？如果需要，用 strong/em；如果只是想让字好看，用 b/i，或者直接交给 CSS。

## span：给文字打标记

`<span>` 是行内元素的"无名标签"。它没有语义，纯粹是为了**方便选中一段文字加样式**。

```html
<p>张三在<span class="highlight">这次项目</span>中负责前端开发。</p>
```

```css
.highlight {
  background-color: yellow;
}
```

没有 span，你就没法只给"这次项目"四个字加黄底——p 是整段，没法精确到其中几个字。span 让你可以把样式挂到任意一段文本上。

## div：块级容器

`<div>` 是块级元素的"无名标签"。它把一组元素包成一个整体，方便整体布局、整体加样式。

```html
<div class="card">
  <h3>项目一</h3>
  <p>一个用 Python 写的爬虫工具。</p>
</div>
```

div 默认独占一行（块级），span 默认不换行（行内）。这是它们的核心区别。

## 翻车现场一：整段用 strong

```html
<strong>张三，男，28 岁，现居北京。毕业于北京大学计算机系。熟悉 Python、JavaScript。曾参与多个 Web 项目开发，包括电商后台、数据可视化平台等。</strong>
```

后果：整段都加粗，等于没有重点。strong 的价值在于**对比**——多数文字是普通粗细，重要的那一句是粗的，读者一眼扫到重点。全粗 = 全不粗。

## 翻车现场二：用 div 代替 span 做行内标记

```html
<p>关键词是<div>前端</div>开发。</p>
```

后果：div 是块级元素，会在"关键词是"和"开发"之间强制换行，把句子打断了。行内标记只能用 span。

## 小结

- `<strong>` 表重要、`<em>` 表强调，是语义；`<b>`、`<i>` 只表外观。
- 判断是否用语义标签：去掉 CSS 后这段内容还需要强调吗？
- `<span>` 是行内容器，`<div>` 是块级容器，别混用。

## 随堂练习

```quiz
type: html
q: 写一个 p，内容是"张三精通"，中间用 strong 包住"Python"两个字，后面接"和 JavaScript"。要求 p 的纯文本连起来是"张三精通Python和 JavaScript"（注意空格）。
starter: |
  <p>张三精通</p>
checks:
- document.querySelectorAll('p').length === 1
- document.querySelectorAll('strong').length === 1
- document.querySelector('strong').textContent.trim() === 'Python'
- document.querySelector('p').textContent.replace(/\s+/g, '').includes('张三精通Python和JavaScript')
hint: strong 嵌在 p 内部，p 里 strong 之后继续写文字。
explain: strong 是 p 的子元素，前后的文字仍在 p 内，组成完整句子。
```

explain: strong 表达语义上的重要性，读屏软件会据此加重语气；b 只表示加粗外观，无语义分量。

  <div class="card">
  </div>

- document.querySelectorAll('.card').length === 1
- document.querySelector('.card > h3') !== null
- document.querySelector('.card > p') !== null
- document.querySelector('.card > h3').textContent.trim() === '项目'
- document.querySelector('.card > p').textContent.trim() === '描述'
hint: h3 与 p 是 card 的直接子元素，并列放在 div 内。
explain: card 作为块级容器，直接包含 h3 与 p 两个子元素。
