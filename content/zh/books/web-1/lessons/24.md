# Grid 布局入门：二维网格系统

> 这一节解决"怎么同时控制行和列"的问题。Flex 是一维的（一次只能管一行或一列），Grid 是二维的（同时管行和列），两者互补而非替代。

## Grid 的基本概念

Grid 布局把容器划分成**行（row）和列（column）**组成的网格，子元素可以精确放到某个格子或跨越多格。

```css
.grid {
  display: grid;
  grid-template-columns: 200px 1fr 200px; /* 三列：固定 200px、弹性、固定 200px */
  grid-template-rows: auto 1fr;            /* 两行：内容高度、弹性 */
  gap: 16px;                               /* 行列间距 */
}
```

```html
<div class="grid">
  <header>头部</header>
  <nav>导航</nav>
  <main>主内容</main>
  <footer>底部</footer>
</div>
```

`grid-template-columns` 定义列宽，`grid-template-rows` 定义行高，`gap` 定义间距。就这么简单。

## fr 单位：按比例分空间

`fr`（fraction）是 Grid 特有的单位，表示"剩余空间的几分之几"。

```css
.grid {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr; /* 总宽分成 4 份：1:2:1 */
}
```

中间那列占一半，两侧各占四分之一。`fr` 让比例分配变得极其直观。

## Grid vs Flex 的分工

| 场景 | 用 Grid | 用 Flex |
|---|---|---|
| 整体页面骨架（头部/侧栏/内容/底部） | 二维网格 | 不太适合 |
| 一排导航链接 | 一维排列 | 适合 |
| 卡片网格（每行固定数量） | 适合 | 也行 |
| 内容自然流动的一行 | 不太适合 | 适合 |

经验法则：
- **布局整体结构** → Grid
- **对齐一组元素** → Flex
- 两者嵌套使用是最常见的组合

```css
/* 外层 Grid 搭骨架 */
.page {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-rows: 60px 1fr 40px;
  min-height: 100vh;
}

/* 内层 Flex 对齐 */
.header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
```

## gap：告别 margin 坍塌

Grid 用 `gap` 统一设置间距，不需要算 margin。

```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr); /* 三列等宽 */
  gap: 20px; /* 行间距和列间距都是 20px */
}
```

也可以分别设置：

```css
gap: 16px 24px;  /* 行间距 16px，列间距 24px */
row-gap: 16px;
column-gap: 24px;
```

翻车现场一：Grid 项目之间用 margin 代替 gap。

```css
.grid-item {
  margin: 10px; /* 不推荐 */
}
```

后果：grid 容器边缘的项目会多出外边距，导致容器和项目之间有 10px 空隙，布局不整齐。用 `gap` 则只在网格线之间产生间距，边缘干净。

## repeat 简化写法

```css
/* 等价于 1fr 1fr 1fr 1fr */
grid-template-columns: repeat(4, 1fr);

/* 混合写法 */
grid-template-columns: 200px repeat(2, 1fr) 100px; /* 200px 两等分 100px */
```

翻车现场二：Grid 项目超出网格，自动生成隐式行。

```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}
```

```html
<div class="grid">
  <div>1</div><div>2</div><div>3</div>
  <div>4</div><div>5</div>  <!-- 第 4 个自动换到第二行 -->
</div>
```

后果：前 3 个占第一行，第 4、5 个自动创建第二行（隐式行，高度由内容决定）。这不一定是 bug——很多时候这正是你想要的行为。但如果需要精确控制行高，要用 `grid-template-rows`。

## 小结

- Grid 是二维布局系统，同时控制行和列。
- `fr` 单位按比例分配剩余空间，极其直观。
- Grid 适合搭整体骨架，Flex 适合对齐一组元素，两者嵌套是标配。
- `gap` 统一网格间距，比 margin 干净。
- `repeat()` 简化等宽列/行的写法。

type: css
q: 让 .grid 用 Grid 布局，三列等宽（repeat(3, 1fr)），行间距 16px，列间距 16px。

    <div>1</div><div>2</div><div>3</div>

  .grid {
  }
