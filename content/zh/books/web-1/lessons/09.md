# 盒模型：每个元素都是盒子

> 这一节解决"我设的宽度为什么不是我看到的宽度"的问题。盒模型是 CSS 里最基础也最容易被坑的一块。

## 四个部分，从内到外

每个元素在浏览器里都是一个矩形盒子，由四层组成：

```
┌─────────────────────────┐  ← margin（外边距，盒子之外）
│  ┌───────────────────┐  │
│  │  ┌─────────────┐  │  │  ← border（边框）
│  │  │   content   │  │  │  ← content（内容区，真正装文字的地方）
│  │  │  内容区     │  │  │
│  │  └─────────────┘  │  │
│  │     ↑ padding      │  │  ← padding（内边距，内容与边框之间）
│  └───────────────────┘  │
└─────────────────────────┘
```

```css
.box {
  width: 200px;
  padding: 20px;
  border: 2px solid #333;
  margin: 10px;
}
```

默认情况下（`box-sizing: content-box`），元素的**实际占用宽度**是：

`width + padding-left + padding-right + border-left + border-right` = `200 + 20 + 20 + 2 + 2` = **244px**

这就是"我设了 200px 但看到的比 200px 宽"的原因。

## box-sizing: border-box 改变算法

```css
* {
  box-sizing: border-box;
}
```

加上这句之后，`width: 200px` 就表示**整个盒子（含 padding 和 border）加起来 200px**，内容区会被压缩到 176px。这是现代开发的事实标准，几乎所有项目都会在第一行写这句。

翻车现场一：不设 box-sizing，算不清宽度。

```css
.card {
  width: 100%;
  padding: 20px;
}
```

后果：100% 的宽度再加上 40px 的 padding，盒子总宽超过父容器，出现横向滚动条。加上 `box-sizing: border-box` 就解决了。

## margin 折叠（经典坑）

两个**上下相邻**的块级元素，它们的垂直 margin 会**合并成一个**，取较大的那个值，而不是相加。

```html
<p style="margin-bottom: 30px;">第一段</p>
<p style="margin-top: 20px;">第二段</p>
```

你以为两段之间的间距是 50px，实际是 **30px**。这就是 margin 折叠（margin collapse）。

```css
/* 只有 margin-bottom 生效，margin-top 被"折叠"掉了 */
```

什么时候会折叠：

- 相邻兄弟元素的上下 margin
- 父元素与其第一个/最后一个子元素的 margin

什么时候**不会**折叠：

- 水平方向的 margin（左右会相加）
- 浮动元素、绝对定位元素的 margin
- flex 和 grid 布局容器里的子元素

翻车现场二：用 margin-top 给子元素"顶开"父元素。

```html
<div class="parent">
  <p class="child">文字</p>
</div>
```

```css
.parent { margin-top: 20px; }
.child { margin-top: 30px; }
```

后果：你以为父元素距上方 20px、子元素在父元素里再往下 30px。实际是父元素被"带着"一起往下 30px，父子之间的 margin 折叠到了父元素外边。解决办法：用父元素的 `padding-top` 代替子元素的 `margin-top`。

## 小结

- 盒子四层：content、padding、border、margin，由内到外。
- 默认 `content-box`：`width` 不含 padding 和 border，实际更宽。
- 现代做法：`* { box-sizing: border-box; }`，width 就是总宽。
- 上下相邻块级元素的垂直 margin 会折叠，取较大值；padding 不会折叠。

## 随堂练习

```quiz
type: css
q: 让 p 有 20px 的内边距、2px 的实线灰色 rgb(158, 158, 158) 边框，并设置 box-sizing 为 border-box。
html: |
  <p>带边框的文字</p>
starter: |
  p {
  }
checks:
- getComputedStyle(document.querySelector('p')).paddingTop === '20px'
- getComputedStyle(document.querySelector('p')).borderTopWidth === '2px'
- getComputedStyle(document.querySelector('p')).boxSizing === 'border-box'
hint: 三个属性分别是 padding、border、box-sizing。
explain: padding 设置内边距，border 设置边框，box-sizing 改变宽度计算方式。
```
