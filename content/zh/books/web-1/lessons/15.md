# 表单基础：form、input、label、button、textarea、select

> 这一节解决"怎么让用户输入信息并提交"的问题。重点是 label 的关联方式——它关系到每个用户能不能顺利点击和填写。

## 一个完整的小表单

```html
<form action="/submit" method="post">
  <div>
    <label for="name">姓名</label>
    <input type="text" id="name" name="name">
  </div>
  <div>
    <label for="city">城市</label>
    <select id="city" name="city">
      <option value="beijing">北京</option>
      <option value="shanghai">上海</option>
      <option value="guangzhou">广州</option>
    </select>
  </div>
  <div>
    <label for="msg">留言</label>
    <textarea id="msg" name="msg" rows="4"></textarea>
  </div>
  <button type="submit">提交</button>
</form>
```

| 标签 | 作用 |
|---|---|
| `<form>` | 表单容器，`action` 是提交地址，`method` 是提交方式 |
| `<label>` | 输入框的说明文字 |
| `<input>` | 单行输入框，type 决定类型 |
| `<textarea>` | 多行文本输入 |
| `<select>` + `<option>` | 下拉选择 |
| `<button>` | 按钮 |

## label 的 for 与可访问性

```html
<label for="name">姓名</label>
<input type="text" id="name">
```

`label` 的 `for` 值必须**等于** input 的 `id` 值，这样就建立了关联。关联之后：

1. **点击文字也能聚焦输入框**——单选框、复选框尤其重要，点击那个小方块很难点准，点击旁边的文字就能选中，体验好得多。
2. **读屏软件会读出 label 的内容**作为该输入框的说明，视障用户知道该填什么。

翻车现场一：label 的 for 写错。

```html
<label for="username">姓名</label>
<input type="text" id="name">
```

后果：`for="username"` 但 `id="name"`，对不上，关联没建立。点击"姓名"文字不会聚焦输入框，读屏也读不出说明。张三写了十个输入框，其中三个 for 写错，用户反馈"点文字没反应"。

翻车现场二：不用 label，只用 placeholder。

```html
<input type="text" placeholder="请输入姓名">
```

后果：placeholder 是**示例提示**，不是标签。两个问题：一是用户开始输入后提示就消失了，不知道这栏要填什么；二是 placeholder 颜色浅，读屏软件常常不把它当作正式说明。label 才是正解。

## input 的常见类型

```html
<input type="text" name="name">        <!-- 单行文本 -->
<input type="email" name="email">      <!-- 邮箱，移动端会弹出对应键盘 -->
<input type="password" name="pwd">     <!-- 密码，内容隐藏 -->
<input type="number" name="age">       <!-- 数字 -->
<input type="checkbox" name="hobby">   <!-- 复选框 -->
<input type="radio" name="gender">     <!-- 单选框 -->
<input type="date" name="birthday">    <!-- 日期选择器 -->
```

## 用 name 分组单选框

```html
<p>性别：</p>
<input type="radio" name="gender" id="male" value="male">
<label for="male">男</label>
<input type="radio" name="gender" id="female" value="female">
<label for="female">女</label>
```

`name` 相同的 radio 是一组，同一组只能选一个。如果 name 写成了不一样的，两个就能同时选中，逻辑就错了。

## textarea 与 select

```html
<textarea name="intro" rows="4" cols="40"></textarea>
```

`<textarea>` 有独立的开始和结束标签，内容写在标签之间（而不是像 input 那样靠 value 属性）。

```html
<select name="city">
  <option value="">请选择</option>
  <option value="beijing">北京</option>
  <option value="shanghai">上海</option>
</select>
```

`<option>` 的 `value` 是提交时实际发送的值，`<option>` 和 `</option>` 之间的文字是给用户看的。

## 小结

- form 是表单容器，input/textarea/select 收集输入，button 触发提交。
- label 的 `for` 必须对应 input 的 `id`，才能建立关联。
- 关联带来点击聚焦和读屏说明，是可访问性的基本要求。
- placeholder 不能代替 label；name 相同的 radio 构成一组。
- textarea 的内容写在标签之间，select 的选项用 option。

## 随堂练习

```quiz
type: html
q: 写一个 label，for 为"email"，文字为"邮箱"；再写一个 input，type 为"email"、id 为"email"、name 为"email"。两者形成关联。
starter: |
  <label for="email">邮箱</label>
checks:
- document.querySelector('label').getAttribute('for') === 'email'
- document.querySelector('input').getAttribute('type') === 'email'
- document.querySelector('input').getAttribute('id') === 'email'
- document.querySelector('input').getAttribute('name') === 'email'
- document.querySelector('label').textContent.trim() === '邮箱'
hint: label 的 for 与 input 的 id 保持一致，input 还需 type 与 name 属性。
explain: label 通过 for 与 input 的 id 关联，input 的 type 与 name 分别指定类型和提交时的键名。
```
