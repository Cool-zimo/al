# 颜色与单位

> 这一节解决"颜色怎么写、尺寸用什么单位"的问题。选对单位，页面才能在不同屏幕上自适应。

## 颜色的三种写法

```css
h1 {
  color: red;              /* 命名色 */
  color: #2c7a7b;          /* 十六进制 */
  color: rgb(44, 122, 123); /* RGB */
}
```

三种写法都合法。命名色只有一百多种，够用但不够精确；十六进制和 RGB 能表示所有颜色，两者等价：

`#2c7a7b` = `rgb(44, 122, 123)`（红 44、绿 122、蓝 123）。

带透明度的写法：

```css
.box {
  background-color: rgba(44, 122, 123, 0.5);  /* 最后一位是透明度，0~1 */
}
```

判断练习题时一律用 `rgb(...)` 形式写期望值，这样学生写 `red`、`#f00` 还是 `rgb(255,0,0)` 都算对——浏览器算出来都是同一个值。

## px：像素，绝对单位

```css
p {
  font-size: 16px;
}
```

px 是最直观的单位，1px 约等于屏幕上一个物理像素点。它的问题是**不随用户设置变化**：视力不好的用户把浏览器默认字号调大，px 写的字号不会跟着变大，用户会觉得"字太小改不了"。

## em：相对当前元素的字号

```css
.box {
  font-size: 16px;
  padding: 1em;   /* 16px */
}
.box p {
  font-size: 1.2em; /* 19.2px，相对于父元素的 16px */
}
```

`1em` = 当前元素的字号。它的特点是**会嵌套放大**：

```html
<div style="font-size: 1.2em">
  <div style="font-size: 1.2em">
    <p>这里的字号是 16 × 1.2 × 1.2 ≈ 23px</p>
  </div>
</div>
```

翻车现场一：嵌套 em 导致字号失控。

后果：张三给导航菜单的每一项用 `font-size: 1.2em`，结果子菜单相对父菜单再放大 1.2 倍，三级菜单的字号一路膨胀到离谱。解决办法是用 rem 或直接在每层写 px。

## rem：相对根元素 html 的字号

```css
html {
  font-size: 16px;
}
.box {
  font-size: 1rem;   /* 16px */
  padding: 1.5rem;   /* 24px */
}
```

`1rem` 永远等于根元素（html）的字号。它**不会**因为嵌套而累加，所以是最推荐的字体单位。用户把浏览器默认字号调大，rem 会跟着变，页面整体缩放。

## %：相对父元素的尺寸

```css
.container {
  width: 80%;
}
```

`80%` 表示父元素宽度的 80%。常用于让内容居中、留出边距。

## 什么时候用哪个

| 单位 | 适用 |
|---|---|
| px | 边框粗细、固定尺寸的小图标 |
| rem | 字号、间距、大多数布局尺寸 |
| em | 与自身字号相关的内边距（如按钮） |
| % | 相对父元素的宽度、响应式布局 |

## 小结

- 颜色用命名色、十六进制或 rgb，三者等价；判断题期望值写 `rgb(...)`。
- px 绝对、不随用户设置变化；em 相对自身字号、会嵌套放大。
- rem 相对根元素，不会嵌套失控，是最推荐的字体单位。
- % 相对父元素，适合响应式布局。

## 随堂练习

```quiz
type: css
q: 让 p 的字号变成 1.5rem（假设根元素字号 16px，即 24px），文字颜色为深青 rgb(0, 121, 107)。
html: |
  <p>一段文字</p>
starter: |
  p {
  }
checks:
- getComputedStyle(document.querySelector('p')).fontSize === '24px'
- getComputedStyle(document.querySelector('p')).color === 'rgb(0, 121, 107)'
hint: 1.5rem 对应 24px，颜色用 color 属性。
explain: rem 相对根元素字号，24px 是期望值；color 设置文字色。
```
