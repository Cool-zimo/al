# 第一个 HTML 文档：骨架要写对

> 这一节解决"为什么我的页面在浏览器里看着怪怪的"的问题。根子在骨架：doctype、html、head、body，一个都不能少。

## 一个 HTML 文档的骨架

```html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8">
    <title>张三的主页</title>
  </head>
  <body>
    <h1>你好</h1>
  </body>
</html>
```

这五个东西，每个都有用：

| 标签 | 作用 |
|---|---|
| `<!DOCTYPE html>` | 声明这是 HTML5，让浏览器用标准模式解析 |
| `<html lang="zh-CN">` | 根元素，`lang` 告诉浏览器页面主要语言是中文 |
| `<head>` | 放"给浏览器看"的信息，不显示在页面上 |
| `<title>` | 标签页标题，也用于搜索结果和收藏夹 |
| `<body>` | 放"给用户看"的内容，一切可见元素都在这里 |

## DOCTYPE 不是标签

`<!DOCTYPE html>` 写在最前面，前面不能有空行、不能有空格。它是一条**指令**，告诉浏览器"请按 HTML5 标准来渲染"。少了它，浏览器会进入"怪异模式"（Quirks Mode），盒模型的计算方式会回到 1990 年代的旧规矩，你写的 `width` 可能算出来不是你想要的那个值。

顺便提一句：Python 里缩进错了会报错。HTML 里多几个空格、缩进乱一点**不会报错**——浏览器很宽容。但这不等于可以随便写。缩进是你的，可读性是给半年后的自己看的。

## head 里的东西不显示在页面上

`<head>` 里放元数据：字符编码、标题、样式表链接、视口设置等。这些东西用户看不到，但它们决定页面能不能正常显示。

```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>张三的简历</title>
  <link rel="stylesheet" href="style.css">
</head>
```

`<meta charset="UTF-8">` 解决中文乱码。`<meta name="viewport">` 让页面在手机上能正确缩放，没有它，手机浏览器会把页面按桌面宽度渲染再缩小，字小到看不见。

## 标签要闭合

HTML 的标签分两种：

- **成对标签**：`<p>...</p>`、`<div>...</div>`、`<h1>...</h1>`。有开始就有结束。
- **自闭合标签**：`<img>`、`<br>`、`<hr>`、`<input>`。它们没有内容，不需要闭合标签。

## 翻车现场一：忘记写闭合标签

```html
<div>
  <p>第一段
  <p>第二段
</div>
```

后果：浏览器会"猜"你漏了闭合，多数情况下能自动补上，页面看起来正常。**但**一旦结构变复杂，猜错的代价就来了：张三写了个 `<div class="card">`，里面套了三层 div，只在最外层关了一个 `</div>`，结果卡片的边框横跨了整个页面。浏览器把后面的内容都当成卡片内部了。养成随手闭合的习惯，比事后调试省事一百倍。

## 翻车现场二：标签嵌套错乱，交叉嵌套

```html
<p>这是<b>加粗的文字</p></b>
```

后果：`<p>` 里面套 `<b>`，但 `</p>` 写在 `</b>` 前面，成了交叉。浏览器解析时可能把 `<b>` 提到 `<p>` 外面，DOM 结构跟你写的完全不一样，CSS 选择器也就选不中。正确写法是 `<p>这是<b>加粗的文字</b></p>`。

## 注释

```html
<!-- 这是一段注释，浏览器不显示，给人看 -->
```

注释不会出现在页面上，写注释说明"为什么这么写"比"写了什么"更有价值。

## 小结

- 骨架四件套：`<!DOCTYPE html>` + `<html>` + `<head>` + `<body>`。
- DOCTYPE 必须写在第一行，它决定浏览器用标准模式还是怪异模式。
- `<head>` 放元数据，`<body>` 放可见内容，两者不能混。
- 成对标签要闭合，且不能交叉嵌套。

## 随堂练习

```quiz
type: html
q: 写一个完整的最小 HTML 骨架：doctype、html、head、body。head 里放一个 title，内容是"我的页面"。
starter: |
  <!DOCTYPE html>
  <html>
  </html>
checks:
- document.querySelectorAll('head').length === 1
- document.querySelectorAll('body').length === 1
- document.querySelectorAll('title').length === 1
- document.querySelector('title').textContent.trim() === '我的页面'
hint: html 里要包含 head 和 body 两个子元素，title 放在 head 里。
explain: 标准骨架要求 head 与 body 并列作为 html 的直接子元素，title 在 head 内。
```
