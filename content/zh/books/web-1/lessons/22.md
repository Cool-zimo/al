# viewport 与媒体查询

> 这一节解决"为什么手机上我的网页被缩小成了整个页面的缩略图"和"怎么针对不同屏幕写不同 CSS"的问题。

## viewport：手机渲染的开关

在 `<head>` 里加这一行，是每一个移动端网页的第一步：

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

不加这行会怎样？

翻车现场一：忘记写 viewport meta 标签。

后果：手机浏览器会假设你的网页是为 980px 宽的桌面屏幕设计的，于是把页面缩小到能装进手机屏幕——整个页面变成了一个缩略图，文字小到看不见。用户需要手动放大才能阅读。

加了 `width=device-width` 后，浏览器用设备的真实宽度（比如 iPhone 的 375px 或 414px）作为视口宽度，页面按实际尺寸渲染。

`initial-scale=1.0` 表示初始缩放比例为 1，禁止浏览器自动缩放。

## 媒体查询的语法

```css
@media (条件) {
  /* 满足条件时生效的 CSS */
}
```

最常见的条件是**宽度**：

```css
@media (max-width: 767px) {
  .sidebar {
    display: none; /* 手机上隐藏侧边栏 */
  }
}

@media (min-width: 768px) and (max-width: 1023px) {
  .card {
    width: 50%; /* 平板上一行两张 */
  }
}

@media (min-width: 1024px) {
  .card {
    width: 33.33%; /* 电脑上一行三张 */
  }
}
```

## 断点怎么选

断点不应该由某个特定设备决定（因为设备尺寸一直在变），而应该由**你自己的内容**决定。

当你的布局在某个宽度下"挤了"或"太空了"，那就是该加断点的地方。

常见的参考断点：

| 断点 | 典型场景 |
|---|---|
| 480px | 小屏手机 |
| 768px | 平板竖屏 / 手机横屏 |
| 1024px | 平板横屏 / 小笔记本 |
| 1200px | 桌面显示器 |

翻车现场二：断点设得太死，只覆盖特定机型。

```css
@media (width: 375px) {
  /* 只有 iPhone 刚好 375px 才生效 */
}
```

后果：换个尺寸的手机（比如 390px 或 360px）就完全不匹配。正确做法是**用范围**（`min-width` / `max-width`），而不是精确值。

## 手机优先的断点写法

推荐用 `min-width` 从窄到宽逐步增强：

```css
/* 默认：所有屏幕都生效（手机样式） */
.nav { flex-direction: column; }

/* 小屏以上 */
@media (min-width: 600px) {
  .nav { flex-direction: row; }
}

/* 中等屏以上 */
@media (min-width: 900px) {
  .nav { justify-content: space-between; }
}
```

每个断点只写**增量**——在默认基础上新增或修改的属性。这样代码更短、更好维护。

## 媒体查询还能查什么

除了宽度，媒体查询还能检测：

```css
/* 横屏 / 竖屏 */
@media (orientation: landscape) { ... }

/* 打印时 */
@media print { .no-print { display: none; } }

/* 深色模式 */
@media (prefers-color-scheme: dark) { body { background: #222; } }
```

翻车现场三：在媒体查询里重复写大量相同代码。

```css
.card {
  padding: 16px;
  margin: 8px;
  background: white;
  border-radius: 8px;
}
@media (min-width: 768px) {
  .card {
    padding: 16px;
    margin: 8px;
    background: white;
    border-radius: 8px;
    width: 50%;  /* 只想改这一条 */
  }
}
```

后果：代码冗余、难以维护。解决：默认样式写完整，媒体查询里**只覆盖需要改变的属性**。

## 小结

- viewport meta 标签是移动端网页的必备，不加页面会被缩略显示。
- 媒体查询用 `@media (条件)` 包裹条件性 CSS。
- 断点由内容决定，用范围（min/max-width）而非精确值。
- 手机优先策略用 min-width 逐步增强，每个断点只写增量。

## 随堂练习

```quiz
type: css
q: 写媒体查询：当屏幕宽度 >= 768px 时，让 .box 的宽度变为 50%、字体大小变为 18px。
html: |
  <div class="box">响应式盒子</div>
starter: |
  .box {
    width: 100%;
    font-size: 14px;
  }
checks:
- getComputedStyle(document.querySelector('.box')).fontSize === '18px'
- Math.abs(parseFloat(getComputedStyle(document.querySelector('.box')).width) - document.body.clientWidth * 0.5) < 3
hint: 用 @media (min-width: 768px) 包裹宽屏下的样式覆盖。
explain: 默认窄屏样式先写，媒体查询在宽屏断点处覆盖需要变化的属性。
```
