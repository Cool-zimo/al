# 加点交互：深色模式切换与导航高亮

> 这一节解决"怎么用 JavaScript 让页面真正动起来"的问题。这是本册第一次写 JS——你学过 Python，会发现它的语法非常亲切。

## JavaScript 是什么

HTML 是结构，CSS 是样式，**JavaScript 是行为**。它让页面能响应用户操作：点击、输入、滚动。

在网页里引入 JS 有两种方式：

```html
<!-- 方式一：内联脚本 -->
<script>
  console.log("Hello, World!");
</script>

<!-- 方式二：外部文件 -->
<script src="app.js"></script>
```

## 深色模式切换

先看效果，再拆解代码。HTML 部分加一个切换按钮：

```html
<header>
  <h1>张三</h1>
  <button id="theme-toggle">🌙 深色模式</button>
</header>
```

JS 部分：

```javascript
const button = document.getElementById('theme-toggle');
const body = document.body;

button.addEventListener('click', function() {
  body.classList.toggle('dark-mode');
  if (body.classList.contains('dark-mode')) {
    button.textContent = '☀️ 浅色模式';
  } else {
    button.textContent = '🌙 深色模式';
  }
});
```

三步走：

1. **获取元素**：`document.getElementById('theme-toggle')` 拿到按钮。
2. **监听事件**：`addEventListener('click', ...)` 在按钮被点击时执行函数。
3. **修改状态**：`classList.toggle('dark-mode')` 切换 body 上的 CSS 类。

CSS 配合：

```css
body.dark-mode {
  --color-bg: #1a1a2e;
  --color-text: #e0e0e0;
  --color-card: #16213e;
  --color-primary: #e0e0e0;
}

body {
  background: var(--color-bg);
  color: var(--color-text);
  transition: background 0.3s, color 0.3s;
}
```

因为用了 CSS 变量，切换深色模式只需要**重新赋值几个变量**，整个页面自动响应。

翻车现场一：getElementById 写错了 ID。

```javascript
const btn = document.getElementById('Theme-Toggle'); // 大小写错误
```

后果：`btn` 是 `null`，后面调用 `btn.addEventListener` 直接报错 `Cannot read properties of null`。JS 是区分大小写的，`theme-toggle` ≠ `Theme-Toggle`。

翻车现场二：脚本放在 head 里，元素还没加载。

```html
<head>
  <script>
    document.getElementById('theme-toggle').addEventListener('click', ...);
    // 报错！此时 body 还没解析到
  </script>
</head>
```

后果：`getElementById` 返回 null，报错。解决：把脚本放到 `</body>` 之前，或用 `DOMContentLoaded` 事件包裹。

## 导航高亮

另一个常见需求：页面滚动时，当前可见区块对应的导航项高亮。

```html
<nav class="nav">
  <a href="#about" class="nav-link">关于我</a>
  <a href="#skills" class="nav-link">技能</a>
  <a href="#projects" class="nav-link">项目</a>
</nav>

<section id="about">...</section>
<section id="skills">...</section>
<section id="projects">...</section>
```

```javascript
const sections = document.querySelectorAll('section');
const navLinks = document.querySelectorAll('.nav-link');

window.addEventListener('scroll', function() {
  let current = '';
  sections.forEach(function(section) {
    const sectionTop = section.offsetTop;
    if (window.scrollY >= sectionTop - 100) {
      current = section.getAttribute('id');
    }
  });

  navLinks.forEach(function(link) {
    link.classList.remove('active');
    if (link.getAttribute('href') === '#' + current) {
      link.classList.add('active');
    }
  });
});
```

CSS：

```css
.nav-link.active {
  color: var(--color-accent);
  font-weight: bold;
  border-bottom: 2px solid var(--color-accent);
}
```

翻车现场三：scroll 事件触发太频繁，页面卡顿。

```javascript
window.addEventListener('scroll', function() {
  // 每次滚动都执行大量计算
  sections.forEach(...);
  navLinks.forEach(...);
});
```

后果：滚动时每秒触发几十次，每次都遍历 DOM，低端设备上明显卡顿。解决：用**防抖（debounce）**或 `IntersectionObserver`（更现代的方式，第 2 册会讲）。

## 用 localStorage 记住用户选择

用户选了深色模式，刷新后变成浅色——体验很差。用 localStorage 记住：

```javascript
const button = document.getElementById('theme-toggle');
const body = document.body;

// 读取上次保存的偏好
if (localStorage.getItem('dark-mode') === 'true') {
  body.classList.add('dark-mode');
  button.textContent = '☀️ 浅色模式';
}

button.addEventListener('click', function() {
  body.classList.toggle('dark-mode');
  const isDark = body.classList.contains('dark-mode');
  localStorage.setItem('dark-mode', isDark);
  button.textContent = isDark ? '☀️ 浅色模式' : '🌙 深色模式';
});
```

`localStorage` 是浏览器提供的存储，5MB 左右，存字符串。这里存了一个布尔值 `'true'` 或 `'false'`。

## 小结

- JS 负责页面的交互行为，通过操作 DOM 修改页面状态。
- `getElementById` / `querySelector` 获取元素，`addEventListener` 监听事件。
- 深色模式用 CSS 变量 + class 切换实现，一次定义全局生效。
- 脚本要放在 body 之后，或包在 DOMContentLoaded 里。
- localStorage 可以持久化用户偏好。
