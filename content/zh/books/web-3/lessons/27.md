# 搭结构与样式：HTML 骨架与 CSS 布局

> 这一节把上一节的草图落成真实的 HTML 和 CSS，重点是语义化结构和状态切换。

## 骨架：语义化 + 留状态钩子

```html
<main class="app">
  <header class="app__header">
    <h1>天气与汇率查询</h1>
  </header>

  <section class="card">
    <label class="field">
      <span class="field__label">城市</span>
      <input id="cityInput" type="text" placeholder="输入城市名，如 北京" />
      <button id="searchBtn" type="button">查询</button>
    </label>
  </section>

  <section id="status" class="status" hidden></section>

  <section id="weather" class="card weather" hidden>
    <h2 id="wCity"></h2>
    <p class="weather__temp"><span id="wTemp"></span> ℃</p>
    <p id="wCondition"></p>
    <p>湿度：<span id="wHumidity"></span>%</p>
    <p>风速：<span id="wWind"></span> m/s</p>
  </section>

  <section class="card">
    <label class="field">
      <span class="field__label">汇率</span>
      <select id="baseSel"><option>CNY</option><option>USD</option></select>
      <span>→</span>
      <select id="targetSel"><option>USD</option><option>CNY</option></select>
      <button id="rateBtn" type="button">换算</button>
    </label>
    <p id="rateResult"></p>
  </section>
</main>
```

每个数据字段都是独立的 `span`，方便 JS 精准填值。`hidden` 属性控制显隐，比 `display:none` 的 class 更直白。

## 状态区：用 data 属性切换

四种状态（空/加载/错误/成功）用一个容器加 `data-state` 属性来控制显示：

```html
<section id="status" class="status" data-state="idle">
  <p class="status__loading" data-show="loading">⏳ 加载中…</p>
  <p class="status__error" data-show="error"></p>
</section>
```

```css
.status [data-show] { display: none; }
.status[data-state="loading"] [data-show="loading"] { display: block; }
.status[data-state="error"]   [data-show="error"]   { display: block; }
```

JS 只改 `data-state`，CSS 决定显示什么。这样状态逻辑和样式彻底分开。

翻车现场一：用 `innerHTML` 直接塞用户输入进页面。

```javascript
// ❌ 用户输入 <script> 就被执行
status.innerHTML = '查询 ' + city + ' 失败';   // XSS 风险

// ✅ 用 textContent，内容只当文本
status.textContent = '查询 ' + city + ' 失败';
```

后果：`innerHTML` 会解析 HTML 标签。用户输入里若含 `<script>` 或 `<img onerror>`，就是 XSS 漏洞。凡是显示用户/接口内容，一律 `textContent`。

## 布局：flex 撑起表单行

```css
.app {
  max-width: 640px;
  margin: 0 auto;
  padding: 24px 16px;
  font-family: -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif;
}

.card {
  background: #fff;
  border-radius: 12px;
  padding: 20px;
  margin-bottom: 16px;
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.06);
}

.field {
  display: flex;
  align-items: center;
  gap: 12px;
  flex-wrap: wrap;
}

.field input,
.field select {
  flex: 1 1 160px;
  min-width: 0;
  padding: 8px 12px;
  border: 1px solid #ccc;
  border-radius: 8px;
  font-size: 16px;
}

button {
  padding: 8px 18px;
  border: none;
  border-radius: 8px;
  background: rgb(33, 150, 243);
  color: #fff;
  cursor: pointer;
}

.weather__temp {
  font-size: 48px;
  font-weight: 700;
  color: rgb(33, 150, 243);
}
```

`flex: 1 1 160px` 让输入框在宽屏占满、窄屏自动换行。`min-width: 0` 是关键，否则 flex 子项会撑破容器。

## 响应式：一道媒体查询收尾

```css
@media (max-width: 480px) {
  .app { padding: 16px 12px; }
  .field { gap: 8px; }
  .weather__temp { font-size: 36px; }
}
```

手机上只是把间距和字号收一收，布局结构不用动——这就是 flex 的好处。

翻车现场二：input 的 padding 让元素比预期宽，撑破布局。

```css
/* ❌ width 写死 100%，再加 padding 就超出父容器 */
input { width: 100%; padding: 8px 12px; }   /* 实际宽 = 100% + 24px */

/* ✅ 用 box-sizing 统一 */
*, *::before, *::after { box-sizing: border-box; }
```

后果：默认 `box-sizing: content-box`，padding 和 border 会加在 width 之外，横向出现滚动条。`border-box` 让 width 包含 padding 和 border，布局可预测。

## 小结

- 每个数据字段用独立 `span`，方便 JS 精准填值；用 `hidden` 控显隐。
- 状态切换只改 `data-state`，样式交给 CSS 的 `[data-show]` 匹配。
- 用户输入一律 `textContent`，禁止 `innerHTML` 拼接。
- flex 布局 `flex:1 1 160px` + `min-width:0` 兼顾宽窄屏。
- 全局 `box-sizing: border-box`，避免 padding 撑破宽度。
