# 常用数组新特性：flat / flatMap / Object.fromEntries / at

> 这一节讲几个"写出来短、读起来爽"的数组与对象新方法。

## flat：把嵌套数组拍平

```javascript
const arr = [1, [2, 3], [4, [5, 6]]];

arr.flat();        // [1, 2, 3, 4, [5, 6]]  默认只拍平一层
arr.flat(2);       // [1, 2, 3, 4, 5, 6]    拍平两层
arr.flat(Infinity); // 全部拍平
```

**去空位**：`flat` 会自动去掉数组里的"空位"：

```javascript
[1, , 3].flat();   // [1, 3]  中间的空位被去掉了
```

翻车现场一：以为 `flat()` 默认会无限拍平，结果还有嵌套。

```javascript
// ❌ 默认只拍一层
const data = [1, [2, [3, [4]]]];
data.flat();   // [1, 2, [3, [4]]] —— 以为拍平了，其实还有两层

// ✅ 明确指定深度
data.flat(Infinity);  // [1, 2, 3, 4]

// 或者明确知道是两层
data.flat(2);  // [1, 2, 3, [4]]
```

后果：`flat()` 默认深度是 1，不传参会漏掉更深层的嵌套。如果数据结构深度不确定，用 `flat(Infinity)`。

## flatMap：先 map 再 flat(1)

`flatMap` = `map` + `flat(1)`，常用于**把"每个元素展开成多个元素"**：

```javascript
const sentences = ['你好 世界', '前端 后端'];

// 传统写法：map 再 flat
sentences.map(s => s.split(' ')).flat();
// ['你好', '世界', '前端', '后端']

// flatMap：一步到位
sentences.flatMap(s => s.split(' '));
// ['你好', '世界', '前端', '后端']
```

经典场景：把一组对象里的子数组**摊平合并**。

```javascript
const groups = [
  { name: 'A', items: [1, 2] },
  { name: 'B', items: [3, 4] }
];

groups.flatMap(g => g.items);  // [1, 2, 3, 4]
```

## at：按索引取值，支持负数

`at()` 让"从末尾取元素"不再需要 `arr[arr.length - 1]` 这种别扭写法：

```javascript
const arr = ['a', 'b', 'c'];

arr.at(0);   // 'a'
arr.at(-1);  // 'c'  ← 最后一个
arr.at(-2);  // 'b'  ← 倒数第二个

// 对比旧写法
arr[arr.length - 1];  // 'c'
```

## Object.fromEntries：把键值对数组变回对象

`Object.entries` 把对象变成 `[key, value]` 数组，`Object.fromEntries` 是它的**逆向操作**：

```javascript
const entries = [['name', '张三'], ['age', 28]];

Object.fromEntries(entries);
// { name: '张三', age: 28 }
```

结合使用可以优雅地做"对象 → 处理 → 对象"：

```javascript
const user = { name: '张三', age: 28, score: 95 };

// 需求：把对象所有数字字段翻倍
const updated = Object.fromEntries(
  Object.entries(user).map(([key, value]) => [
    key,
    typeof value === 'number' ? value * 2 : value
  ])
);
// { name: '张三', age: 56, score: 190 }
```

翻车现场二：`Object.fromEntries` 遇到重复键会怎样？

```javascript
// ❌ 重复的键会被后面的覆盖
Object.fromEntries([
  ['name', '张三'],
  ['name', '李四']     // 重复键
]);
// { name: '李四' } —— 只保留最后一个

// ✅ 先处理掉重复，或明确知道不会有重复
```

后果：如果有重复键，`fromEntries` 会**保留最后一个**，前面的被覆盖且不报错。这种静默行为可能掩盖数据问题，用之前要确认键唯一。

## 四个方法一览

| 方法 | 作用 | 典型场景 |
|---|---|---|
| `flat(depth)` | 拍平嵌套数组 | 合并多层列表 |
| `flatMap(fn)` | map + 拍平一层 | 展开子数组 |
| `at(index)` | 支持负数索引取值 | 取最后一个元素 |
| `Object.fromEntries` | 键值对数组 → 对象 | 对象转换 |

## 与 Python 的对比

Python 没有 `flat`/`flatMap`/`at` 这些内置方法，需要 `itertools.chain` 或列表推导：

```python
# Python：拍平用列表推导
flat = [x for sub in arr for x in sub]

# 取最后一个
arr[-1]   # Python 原生支持负数索引，比 at() 更早
```

```javascript
// JS
arr.flat();
arr.at(-1);
```

Python 的负数索引是语言级特性，JS 需要 `at()` 方法才能支持。

## 小结

- `flat(depth)` 拍平嵌套数组，默认深度 1；不确定深度用 `flat(Infinity)`。
- `flatMap(fn)` = `map` + `flat(1)`，适合把子数组展开合并。
- `at(-1)` 取最后一个元素，支持负数索引。
- `Object.fromEntries` 是 `Object.entries` 的逆向，适合做对象转换。
- `fromEntries` 遇到重复键会**静默保留最后一个**。
