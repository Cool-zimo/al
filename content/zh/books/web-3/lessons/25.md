# 实战：用 Canvas 画一个简易柱状图

> 这一节把前面的知识串起来：坐标轴、刻度、柱子、标签，全部用 Canvas 手动画出来。

## 先想清楚：画布空间怎么分配

画一个柱状图，首先要规划画布的"留白"。通常给左侧留纵轴标签区、底部留横轴标签区、右边和上边留边距。

```javascript
const canvas = document.querySelector('#chart');
const ctx = canvas.getContext('2d');
const W = canvas.width, H = canvas.height;

const padL = 50, padB = 40, padT = 20, padR = 20;
const plotW = W - padL - padR;   // 绘图区宽度
const plotH = H - padT - padB;   // 绘图区高度
```

所有柱子和坐标都画在这个 `plotW × plotH` 的矩形里，这样横轴、纵轴位置就固定了：`x = padL`、`y = padT + plotH`。

## 画坐标轴

坐标轴就是两条线：纵轴从 `(padL, padT)` 到 `(padL, padT + plotH)`；横轴从 `(padL, padT + plotH)` 到 `(padL + plotW, padT + plotH)`。

```javascript
function drawAxes() {
  ctx.beginPath();
  ctx.moveTo(padL, padT);                    // 纵轴起点（上端）
  ctx.lineTo(padL, padT + plotH);            // 纵轴终点（下端）
  ctx.lineTo(padL + plotW, padT + plotH);    // 横轴终点（右端）
  ctx.strokeStyle = '#666';
  ctx.lineWidth = 1;
  ctx.stroke();
}
```

记住 `beginPath()` + `moveTo` + `lineTo` + `stroke()` 的固定套路。

## 把数据值映射到像素高度

数据可能是 `[30, 80, 55, 120]`，而绘图区高度只有 200px。需要一个映射函数把"数值"转成"像素高度"：

```javascript
function valueToHeight(v, max) {
  return (v / max) * plotH;   // 占比 × 绘图区高度
}
```

柱子的顶边 y 坐标就是 `padT + plotH - valueToHeight(v, max)`——因为 Canvas 的 y 轴**向下**增长，所以要拿绘图区底部减去柱子高度。

翻车现场一：忘记 Canvas y 轴朝下，柱子从顶部往下长。

```javascript
// ❌ 直接拿高度当 y，柱子从画布顶部往下长
ctx.fillRect(x, 0, w, valueToHeight(v, max));

// ✅ 从横轴往上画：起点 = 横轴 y - 柱子高度
const h = valueToHeight(v, max);
ctx.fillRect(x, padT + plotH - h, w, h);
```

后果：不减去，柱子顶部永远贴着画布上边，数值越大柱子越长但方向反了。加上 `padT + plotH - h` 才是"从横轴向上长"。

## 画柱子和标签

假设数据是 `[{label:'北京', value:80}, {label:'上海', value:120}, {label:'广州', value:55}]`：

```javascript
function drawBars(data, max) {
  const n = data.length;
  const gap = 20;
  const barW = (plotW - gap * (n + 1)) / n;   // 每根柱宽

  data.forEach((d, i) => {
    const h = valueToHeight(d.value, max);
    const x = padL + gap + i * (barW + gap);
    const y = padT + plotH - h;

    ctx.fillStyle = 'rgb(33, 150, 243)';
    ctx.fillRect(x, y, barW, h);

    // 横轴标签
    ctx.fillStyle = '#333';
    ctx.font = '12px sans-serif';
    ctx.textAlign = 'center';
    ctx.fillText(d.label, x + barW / 2, padT + plotH + 18);
  });
}
```

柱宽要扣除间隙：`(绘图区宽 - 所有间隙) / 柱子数`。每根柱子的 x 起点是 `起点 + 左边间隙 + i × (柱宽 + 间隙)`。

## 画纵轴刻度

纵轴刻度是从 0 到 max 的几个均匀刻度，每个刻度画一条短横线加一个数字：

```javascript
function drawTicks(max) {
  ctx.fillStyle = '#666';
  ctx.font = '11px sans-serif';
  ctx.textAlign = 'right';
  const steps = 4;
  for (let i = 0; i <= steps; i++) {
    const v = (max / steps) * i;              // 刻度对应数值
    const y = padT + plotH - valueToHeight(v, max);  // 对应 y
    ctx.fillText(Math.round(v), padL - 6, y + 4);
    // 可选：画浅色网格线
    ctx.beginPath();
    ctx.moveTo(padL, y);
    ctx.lineTo(padL + plotW, y);
    ctx.strokeStyle = '#eee';
    ctx.stroke();
  }
}
```

注意 `fillText` 的 y 要微调（这里 +4）让数字纵向居中对齐。

翻车现场二：刻度数字用 `ctx.textAlign = 'center'` 却画在纵轴左边。

```javascript
// ❌ 居中对齐后数字右半截压到轴上
ctx.textAlign = 'center';
ctx.fillText('100', padL - 6, y);

// ✅ 纵轴标签用右对齐，紧贴轴左侧
ctx.textAlign = 'right';
ctx.fillText('100', padL - 6, y);
```

后果：`textAlign` 决定文字相对于 `(x, y)` 的对齐方式。纵轴标签要右对齐才贴得住轴，否则会错位。

## 全部串起来

```javascript
const data = [{label:'北京',value:80},{label:'上海',value:120},{label:'广州',value:55}];
const max = 150;
drawAxes();
drawTicks(max);
drawBars(data, max);
```

完整流程：**算留白 → 画轴 → 画刻度 → 画柱子 → 画标签**。每一层都是独立的函数，想改颜色、间距只动一处。

## 小结

- 先规划留白区，所有绘制限定在 `plotW × plotH` 里。
- 数值映射 `valueToHeight(v, max) = v/max * plotH`。
- y 轴朝下，柱子顶边 = `padT + plotH - 高度`。
- 柱宽 = `(绘图区宽 - 间隙总和) / 柱子数`，x 起点按 `i*(柱宽+间隙)` 递增。
- 标签对齐：`textAlign='center'` 放横轴下，`'right'` 放纵轴左。
