# Canvas 基础：getContext、坐标系与矩形

> 这一节建立 Canvas 的基本直觉：它是一块画布，所有绘图都靠一个"绘图上下文"对象。

## Canvas 是什么

`<canvas>` 是 HTML5 提供的一块**位图画布**。你用 JS 拿到它的"绘图上下文"对象，然后调用方法在上面画。

```html
<canvas id="board" width="400" height="300"></canvas>
```

```javascript
const canvas = document.querySelector('#board');
const ctx = canvas.getContext('2d');  // 拿到 2D 绘图上下文

// 画一个填充矩形
ctx.fillStyle = 'rgb(33, 150, 243)';
ctx.fillRect(50, 50, 100, 80);  // x, y, 宽, 高
```

翻车现场一：用 CSS 设置 canvas 尺寸，导致画面模糊失真。

```html
<!-- ❌ 用 CSS 把 canvas 拉大 -->
<canvas id="board" style="width:800px; height:600px;"></canvas>
<!-- 实际画布仍是默认的 300×150，被 CSS 拉伸 → 模糊 -->
```

```html
<!-- ✅ 用 HTML 属性设置实际像素尺寸 -->
<canvas id="board" width="800" height="600"></canvas>
```

后果：canvas 有两个"尺寸"概念——**绘图缓冲区尺寸**（HTML 的 width/height）和**显示尺寸**（CSS 的 width/height）。只用 CSS 拉伸显示尺寸会让画面**模糊变形**，因为绘图分辨率没变。永远用 HTML 属性设置真实像素，CSS 只用来布局。

## 坐标系：左上角为原点

Canvas 的坐标系**左上角是 (0, 0)**，向右 x 增大，向下 y 增大：

```
(0,0) ──────────→ x
  │
  │
  │
  ↓ y
```

```javascript
ctx.fillRect(0, 0, 50, 50);    // 左上角画一个 50×50 方块
ctx.fillRect(350, 250, 50, 50); // 右下角画一个（假设画布 400×300）
```

## 矩形三连

| 方法 | 作用 |
|---|---|
| `fillRect(x, y, w, h)` | 画一个**填充**矩形 |
| `strokeRect(x, y, w, h)` | 画一个**描边**（边框）矩形 |
| `clearRect(x, y, w, h)` | **清除**一块区域（变透明） |

```javascript
// 填充矩形
ctx.fillStyle = 'rgb(244, 67, 54)';
ctx.fillRect(20, 20, 80, 60);

// 描边矩形
ctx.strokeStyle = 'rgb(76, 175, 80)';
ctx.lineWidth = 4;
ctx.strokeRect(120, 20, 80, 60);

// 清除一块区域
ctx.clearRect(40, 30, 40, 40);  // 在红色方块上挖掉一块
```

`fillStyle` / `strokeStyle` 设置颜色，`lineWidth` 设置线条粗细。

翻车现场二：先设样式后画，但样式被后续绘制复用，导致颜色"串了"。

```javascript
// ❌ 样式会持续生效，影响后面的绘制
ctx.fillStyle = 'rgb(244, 67, 54)';
ctx.fillRect(0, 0, 50, 50);
ctx.fillRect(60, 0, 50, 50);   // 也是红色！忘了改 fillStyle

// ✅ 每次绘制前明确设置样式
ctx.fillStyle = 'rgb(244, 67, 54)';
ctx.fillRect(0, 0, 50, 50);

ctx.fillStyle = 'rgb(33, 150, 243)';
ctx.fillRect(60, 0, 50, 50);   // 蓝色
```

后果：canvas 上下文的状态（fillStyle、strokeStyle、lineWidth 等）是**持久化的**——设置一次后，后续所有绘制都用它，直到再次修改。忘了重新设样式，就会出现"颜色串了"的 bug。封装成函数、每次绘制前设样式是好习惯。

## 画布清空与重绘

Canvas 没有"修改某个图形"的能力，它是**位图**。要动起来，通常是**清空整块画布再重绘**：

```javascript
// 动画循环里的标准套路
function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);  // 清空
  // ... 重新画所有东西
}
```

## 小结

- Canvas 是位图画布，用 `getContext('2d')` 拿到绘图上下文。
- 坐标系**左上角为原点**，右为 x 正、下为 y 正。
- 尺寸用 **HTML 属性**设置，用 CSS 拉伸会模糊。
- `fillRect` / `strokeRect` / `clearRect` 是三个基础矩形方法。
- 上下文样式（fillStyle 等）**会持久化**，要养成每次绘制前重设的习惯。
