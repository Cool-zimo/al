# fetch 基础：GET 请求与 Response 对象

> 这一节讲浏览器原生 API `fetch` 的基本用法，重点是 `Response` 对象怎么取值。

## fetch 是什么

`fetch` 是现代浏览器提供的**发起网络请求**的 API，返回一个 Promise。它比老式的 `XMLHttpRequest` 简洁得多。

```javascript
// 最基本的 GET 请求
fetch('/api/users')
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error('请求失败：', error));
```

第一个参数是 URL，默认发起的就是 **GET** 请求。

## Response 对象

`fetch` 返回的 Promise **resolve 的是一个 `Response` 对象**，不是直接的数据。你需要调用它的方法把响应体"读出来"：

| 方法 | 说明 |
|---|---|
| `res.json()` | 把响应体解析成 JSON，返回 Promise |
| `res.text()` | 读成文本字符串 |
| `res.blob()` | 读成二进制大对象（如图片） |
| `res.formData()` | 读成 FormData |

```javascript
fetch('/api/user/1')
  .then(res => {
    console.log(res.status);     // 状态码，如 200
    console.log(res.ok);         // true 表示 200~299
    console.log(res.headers);    // 响应头
    return res.json();           // ⚠️ 返回的是 Promise，不是解析好的数据
  })
  .then(data => console.log(data));
```

翻车现场一：以为 `res.json()` 同步返回解析好的数据，直接当值用。

```javascript
// ❌ 常见错误
fetch('/api/users')
  .then(res => {
    const data = res.json();   // data 是个 Promise，不是数组！
    console.log(data.length);  // undefined
  });

// ✅ 正确：return 出去，下一环再取
fetch('/api/users')
  .then(res => res.json())
  .then(data => {
    console.log(data.length);  // 正常
  });
```

后果：`res.json()` 返回的是一个 Promise，不是解析好的 JSON 对象。直接访问它的属性会得到 `undefined`，且不会报错，非常难排查。**必须 await 或 .then 一层**才能拿到真数据。

## async/await 写法

配合 await，fetch 的写法更直观：

```javascript
async function getUsers() {
  const response = await fetch('/api/users');
  const data = await response.json();  // await 才是真数据
  console.log(data);
}
```

注意是**两次 await**：一次等响应回来（`fetch`），一次等响应体解析完（`json()`）。

## 用 text() 读文本响应

不是所有接口都返回 JSON，有些返回纯文本或 HTML：

```javascript
const res = await fetch('/api/version');
const version = await res.text();
console.log('当前版本：', version);  // 字符串
```

## 查询参数

GET 请求带查询参数，要把参数拼到 URL 上：

```javascript
const params = new URLSearchParams({
  city: '北京',
  lang: 'zh'
});
const url = `/api/weather?${params}`;
// → /api/weather?city=%E5%8C%97%E4%BA%AC&lang=zh

const res = await fetch(url);
const data = await res.json();
```

`URLSearchParams` 会自动做 URL 编码，比手动拼字符串安全。

翻车现场二：手动拼 URL 没做编码，中文或特殊字符导致 404。

```javascript
// ❌ 手动拼，中文没编码
const city = '北京';
fetch(`/api/weather?city=${city}`);  // URL 含未编码的中文，可能报错

// ✅ 用 URLSearchParams
const params = new URLSearchParams({ city });
fetch(`/api/weather?${params}`);  // 自动编码成 %E5%8C%97%E4%BA%AC
```

后果：未编码的特殊字符（空格、中文、&、#）会破坏 URL 结构，请求要么 404，要么参数被截断。养成用 `URLSearchParams` 的习惯。

## 与 Python 的对比

Python 的 `requests` 库是**同步**且直接返回解析结果：

```python
# Python requests
import requests
r = requests.get('/api/users')
data = r.json()  # 直接拿到字典
```

JS 的 fetch 是异步的，且 `.json()` 还要再 await 一层。这个"两次等待"是 JS fetch 最容易被 Python 程序员吐槽的地方。

## 小结

- `fetch(url)` 默认发起 GET 请求，返回 Promise<Response>。
- Response 对象不是数据本身，要调 `json()`/`text()` 等方法读取。
- **`res.json()` 返回 Promise**，必须 await 或 .then 才能拿到真数据。
- GET 参数用 `URLSearchParams` 拼装，自动做 URL 编码。
- 常见流程：`await fetch()` → `await res.json()`。
