# 解构、展开运算符进阶与可选链、空值合并

> 这一节讲几个让代码"变短变稳"的语法糖：解构、展开、`?.`、`??`。

## 解构赋值进阶

基础解构你已经会了，这里讲几个进阶用法。

**嵌套解构：**

```javascript
const user = {
  name: '张三',
  address: { city: '北京', zip: '100000' }
};

// 嵌套解构
const { name, address: { city } } = user;
console.log(name);  // '张三'
console.log(city);  // '北京'
// address 这个变量本身不会被声明
```

**解构 + 重命名 + 默认值：**

```javascript
const { name: userName = '匿名', age = 18 } = getUser();
// userName 是重命名后的变量，age 有默认值 18
```

**函数参数的解构默认值：**

```javascript
function createUser({ name = '游客', age = 18, city = '上海' } = {}) {
  return `${name}，${age}岁，来自${city}`;
}
createUser();              // '游客，18岁，来自上海'
createUser({ name: '李四' });  // '李四，18岁，来自上海'
```

注意参数默认值是 `{}`，这样**调用时不传参也不会报错**。

翻车现场一：函数参数解构但没给默认值，调用时传 `undefined` 或空参就崩。

```javascript
// ❌ 没给参数默认值
function draw({ width, height }) {
  console.log(width, height);
}
draw();        // TypeError: Cannot destructure property 'width' of 'undefined'
draw(undefined);  // 同样报错

// ✅ 给参数默认值为空对象
function draw({ width, height } = {}) {
  console.log(width, height);  // undefined undefined，不报错
}
draw();  // 安全
```

后果：解构 `undefined` 或 `null` 会直接抛 TypeError。函数参数解构时**必须给参数一个 `= {}` 默认值**，否则调用方不传参就崩。

## 展开运算符进阶

**数组展开：合并、复制、插入**

```javascript
const a = [1, 2];
const b = [3, 4];

[...a, ...b];        // [1, 2, 3, 4] 合并
[0, ...a, 3];        // [0, 1, 2, 3] 插入
[...a];              // [1, 2] 浅拷贝

// ⚠️ 展开只做浅拷贝
const nested = [[1, 2]];
const copy = [...nested];
copy[0].push(3);
console.log(nested[0]);  // [1, 2, 3] —— 嵌套数组仍是同一个引用
```

**对象展开：合并、覆盖**

```javascript
const base = { name: '张三', age: 28 };
const extra = { ...base, age: 30, city: '北京' };
// { name: '张三', age: 30, city: '北京' } —— 同名属性靠后覆盖

// 对象浅拷贝（等价 {...obj}）
const copy = { ...base };
```

翻车现场二：用展开运算符以为做了深拷贝，结果嵌套对象还是共享引用。

```javascript
// ❌ 以为 {...obj} 是深拷贝
const a = { user: { name: '张三' } };
const b = { ...a };
b.user.name = '李四';
console.log(a.user.name);  // '李四' —— 被污染了

// ✅ 需要深拷贝时用 structuredClone 或 JSON 技巧
const c = structuredClone(a);
c.user.name = '王五';
console.log(a.user.name);  // '张三'
```

后果：`...` 展开只复制**第一层**属性，嵌套对象是引用共享。想深拷贝要用 `structuredClone` 或 `JSON.parse(JSON.stringify())`。

## 可选链 `?.`

`?.` 让你在访问深层属性时**不必层层判空**：

```javascript
const user = { profile: { name: '张三' } };

// 传统写法
const city = user && user.profile && user.profile.address && user.profile.address.city;

// 可选链
const city = user?.profile?.address?.city;  // undefined，不报错
```

遇到 `null` 或 `undefined` 就**短路返回 undefined**，不会抛错。

```javascript
// 可选链配合函数调用
const result = obj?.someMethod?.();  // 方法不存在也不会报错

// 可选链配合下标
const first = arr?.[0];
```

## 空值合并 `??`

`??` 在**左侧是 `null` 或 `undefined` 时**才用右侧兜底：

```javascript
const a = 0 ?? 100;       // 0（0 不是 null/undefined，保留 0）
const b = '' ?? '默认';    // ''（空字符串保留）
const c = null ?? 100;    // 100
const d = undefined ?? 100;  // 100
```

**`??` 和 `||` 的区别**是这一节最重要的知识点：

```javascript
// || 会把 0、''、false 都当成"假值"覆盖掉
const count = 0 || 10;        // 10  ❌ 0 被覆盖了
const name = '' || '匿名';    // '匿名' ❌ 空字符串被覆盖

// ?? 只在 null/undefined 时才覆盖
const count = 0 ?? 10;        // 0  ✅ 保留了 0
const name = '' ?? '匿名';    // ''  ✅ 保留了空字符串
```

翻车现场三：用 `||` 设置数量默认值，把合法的 0 覆盖了。

```javascript
// ❌ 用 || 兜底
function setLimit(limit) {
  const n = limit || 10;   // 用户传 0 时变成 10，逻辑错误
  return n;
}
setLimit(0);  // 期望 0，实际 10

// ✅ 用 ?? 兜底
function setLimit(limit) {
  const n = limit ?? 10;   // 0 被正确保留
  return n;
}
setLimit(0);   // 0 ✅
setLimit();    // 10（undefined 触发兜底）
```

后果：表单里的"数量 0"、"空备注"、"是否开启：false"都是合法值，用 `||` 兜底会被误判成"没填"而覆盖掉。这类 bug 表现为"**用户的 0 变成了默认值**"，非常隐蔽。

## 与 Python 的对比

Python 3.8+ 有海象运算符 `:=`，但没有可选链。取深层属性通常用 `dict.get` 链式或 `try/except`：

```python
# Python 常用 get 链式，或用第三方库如 glom
city = user.get('profile', {}).get('address', {}).get('city')
```

```javascript
// JS 可选链一步到位
const city = user?.profile?.address?.city;
```

`??` 则类似 Python 的 `x if x is not None else y`。

## 小结

- 函数参数解构要写 `= {}` 默认值，防止不传参崩掉。
- `...` 展开只做**浅拷贝**，嵌套对象仍共享引用。
- 可选链 `?.` 在 `null`/`undefined` 处短路，避免层层判空。
- **`??` 只认 null/undefined，`||` 会覆盖所有假值（含 0、''、false）**。
- 设置数量/开关类默认值时优先用 `??`，避免把合法值覆盖掉。
