# 类与模块：class 与 ES Module

> 这一节讲两个组织代码的工具：`class` 的面向对象写法，和 `import/export` 的模块化拆分。

## class：更清晰的构造函数写法

ES6 的 `class` 本质是基于原型的语法糖，但写起来更直观：

```javascript
class User {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  // 原型方法
  greet() {
    return `你好，我是${this.name}`;
  }

  // getter
  get isAdult() {
    return this.age >= 18;
  }
}

const user = new User('张三', 20);
console.log(user.greet());    // '你好，我是张三'
console.log(user.isAdult);    // true
```

**静态方法**用 `static`，挂在类本身上，不用实例：

```javascript
class MathUtil {
  static add(a, b) {
    return a + b;
  }
}

MathUtil.add(1, 2);  // 3，不用 new
```

翻车现场一：class 的方法之间不要加逗号，否则语法错误。

```javascript
// ❌ 加了逗号，语法错误
class User {
  greet() {
    return 'hi';
  },                    // ← 这里的逗号是错的！
  walk() {
    return 'walking';
  }
}

// ✅ 方法之间不加逗号，和对象字面量不同
class User {
  greet() {
    return 'hi';
  }
  walk() {             // 没有逗号
    return 'walking';
  }
}
```

后果：class 体内**方法之间不能加逗号**（这点和对象字面量 `{ }` 不同）。加了逗号会直接报语法错误，整个文件无法执行。

## 继承：extends 与 super

```javascript
class Animal {
  constructor(name) {
    this.name = name;
  }
  speak() {
    return `${this.name} 叫了一声`;
  }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name);       // 必须调用 super，否则 this 不可用
    this.breed = breed;
  }
  speak() {
    return `${this.name} 汪汪叫`;  // 重写父类方法
  }
}

const dog = new Dog('旺财', '柯基');
console.log(dog.speak());  // '旺财 汪汪叫'
```

翻车现场二：子类构造函数忘了 `super()`，直接报 ReferenceError。

```javascript
class Dog extends Animal {
  constructor(name) {
    this.name = name;   // ❌ ReferenceError: Must call super before accessing 'this'
  }
}

// ✅ 先 super 再 this
class Dog extends Animal {
  constructor(name) {
    super(name);        // 先调用父类构造
    this.breed = '柯基';
  }
}
```

后果：子类构造函数里**必须先 `super()` 才能用 `this`**，这是 ES6 的硬性规定。忘了 `super` 会直接抛 ReferenceError。

## ES Module：import / export

把代码拆成多个文件，用 `export` 导出、`import` 导入：

```javascript
// utils.js
export function formatDate(date) {
  return date.toISOString().slice(0, 10);
}

export const VERSION = '1.0.0';

// 默认导出（一个模块只能有一个 default）
export default class User { /* ... */ }
```

```javascript
// main.js
import User, { formatDate, VERSION } from './utils.js';
//        ↑ 默认导出            ↑ 具名导出

console.log(formatDate(new Date()));
console.log(VERSION);
```

**注意：`import` 路径通常是相对路径，要带 `.js` 后缀（浏览器环境）**。

## 浏览器里跑模块：type="module"

直接在浏览器里用 ES Module，**`<script>` 必须加 `type="module"`**：

```html
<!-- ❌ 普通 script，浏览器不认识 import/export -->
<script src="./main.js"></script>

<!-- ✅ 加 type="module" -->
<script type="module" src="./main.js"></script>
```

`type="module"` 的额外特性：

1. **自动严格模式**（不用手动写 `'use strict'`）
2. **延迟执行**（类似 `defer`，等 DOM 解析完再执行）
3. **跨域限制**：模块文件需通过 HTTP 服务加载，**不能直接 `file://` 双击打开**

翻车现场三：双击 HTML 用 `file://` 打开，`import` 直接失败。

```html
<!-- ❌ file:// 协议下模块加载被 CORS 拦截 -->
<script type="module" src="./main.js"></script>
<!-- 控制台：Access to script at '.../main.js' from origin 'null' has been blocked by CORS policy -->

<!-- ✅ 用本地服务器打开 -->
<!-- npx serve .   或   python3 -m http.server -->
```

后果：用 `file://` 直接打开带 `type="module"` 的页面，浏览器会因 CORS 拦截模块文件，import 全部失败。开发模块化项目**必须用本地 HTTP 服务**（如 `npx serve`、`python3 -m http.server`）打开。

## 与 Python 的对比

Python 的模块系统 `import` 是全局的、自动搜索 `sys.path`；JS 的 ES Module 是**静态的、路径显式**，且浏览器里必须走 HTTP：

```python
# Python：import 自动搜索路径
import utils
from utils import format_date
```

```javascript
// JS：路径必须显式，浏览器里要 type="module"
import { formatDate } from './utils.js';
```

## 小结

- `class` 是更清晰的构造函数写法，方法之间**不加逗号**。
- `extends` 继承，`super()` 必须在子类构造函数里先调用。
- 模块用 `export` 导出、`import` 导入；默认导出一个，具名导出多个。
- 浏览器用模块要 `<script type="module">`，且**需要 HTTP 服务**，不能 `file://` 打开。
- `type="module"` 自动严格模式 + 延迟执行。
