# Canvas 文字与图片：fillText / drawImage / 中文字体 / measureText

> 这一节讲怎么在 Canvas 上写字、画图片，以及绕不开的"中文不显示"和"文字排版"问题。

## 在画布上写字：fillText

Canvas 里写文字主要靠 `fillText(text, x, y)`：在坐标 `(x, y)` 处填充文字。第二个常用的是 `strokeText`，只描边不填充。

```javascript
const canvas = document.querySelector('#board');
const ctx = canvas.getContext('2d');

ctx.fillStyle = 'rgb(33, 150, 243)';
ctx.font = '24px sans-serif';          // 先设字体，再写
ctx.fillText('你好，Canvas', 30, 60);  // (30, 60) 是文字基线起点
```

注意 `fillText` 的 `(x, y)` 指的是**文字基线的左下角**，不是文字框的左上角。文字会往上"长"，所以 y 写 20 时，你看到的字可能只露出一半。

## 字体怎么设：font 属性

`ctx.font` 是一个字符串，语法和 CSS 的 `font` 简写一致：`[样式] [粗细] 字号/行高 字体族`。

```javascript
ctx.font = '16px Arial';              // 最小写法：字号 + 字体族
ctx.font = 'bold 20px "Microsoft YaHei", sans-serif';
ctx.font = 'italic 14px serif';
```

翻车现场一：先 fillText 后设置 font，结果字体没生效。

```javascript
// ❌ 顺序写反
ctx.fillText('张三', 10, 50);   // 用默认字体 10px sans-serif 渲染
ctx.font = '30px sans-serif';   // 这句已经太晚了

// ✅ 先设样式，再绘制
ctx.font = '30px sans-serif';
ctx.fillText('张三', 10, 50);
```

后果：Canvas 是**即时模式**——`fillText` 调用那一刻就把当前样式"印"到画布上，之后改 `font`、`fillStyle` 都不会影响已经画上去的像素。记住顺序：设样式 → 绘制 → 再设下一个样式。

## 中文字体：中文为什么会显示成方框

中文显示成方框/豆腐块，几乎都是同一个原因：**当前 font 指定的字体族在运行环境里不存在**。

```javascript
// ❌ 只写了一个不存在的字体
ctx.font = '24px 某某艺术字';   // 找不到该字体，退回方块

// ✅ 用通用族名兜底，或者用系统常见中文字体
ctx.font = '24px "PingFang SC", "Microsoft YaHei", "WenQuanYi Micro Hei", sans-serif';
```

写字体族时，用**逗号分隔的候选列表**。运行环境会从左到右挑第一个它有的字体；最后放一个通用族名（如 `sans-serif`）兜底，保证任何情况下都有可用字体。在判分环境里，常见的中文候选字体：`"Microsoft YaHei"`、`"SimHei"`、`"WenQuanYi Micro Hei"`。

注意：Canvas 里用 `ctx.font` 指定的字体必须是**已经加载完成**的字体。用 `@font-face` 自定义字体时，要等 `document.fonts.ready` 之后再画，否则画上去的还是默认字体。

## 测量文字宽度：measureText

`ctx.measureText(text)` 返回一个 `TextMetrics` 对象，里面最常用的是 `width`——这串文字渲染出来有多宽。

```javascript
ctx.font = '20px sans-serif';
const w = ctx.measureText('北京').width;   // 比如 40
console.log(w);                            // 数字，单位 px
```

它解决的是**居中、对齐、自动换行**问题。比如让文字在画布水平居中：

```javascript
function drawCenterText(ctx, text, canvasWidth, y) {
  ctx.font = '24px sans-serif';
  const w = ctx.measureText(text).width;
  const x = (canvasWidth - w) / 2;   // 起点 = (画布宽 - 文字宽) / 2
  ctx.fillText(text, x, y);
}
```

`measureText` 返回的对象在较新浏览器里还带 `actualBoundingBoxAscent`（上伸高度）、`actualBoundingBoxDescent`（下伸高度）等，用来做精确垂直居中。

翻车现场二：用文字个数乘一个固定值算宽度。

```javascript
// ❌ 用长度硬猜宽度
const guess = text.length * 14;      // 汉字、英文、数字宽度各不相同

// ✅ 让浏览器实际测量
const real = ctx.measureText(text).width;
```

后果：Canvas 是等宽字体下才成立。中文字符通常是英文字符的两倍宽，混排时硬乘会严重错位，`measureText` 才是唯一靠谱的办法。

## 画图片：drawImage

`drawImage` 有三种重载，最常用的是把整张图按原尺寸画上去：

```javascript
const img = new Image();
img.src = 'avatar.png';
img.onload = () => {
  ctx.drawImage(img, 10, 10);          // 原尺寸画在 (10, 10)
  ctx.drawImage(img, 10, 10, 80, 80);  // 缩放画到 80x80
};
```

**关键：图片必须等 onload 之后再 drawImage**，否则画布上是空白。`drawImage` 的完整参数：`drawImage(image, dx, dy, dWidth, dHeight)`。

## 小结

- 写字用 `fillText(text, x, y)`，`(x, y)` 是文字基线左下角。
- 字体顺序很重要：**先设 `ctx.font` 和 `ctx.fillStyle`，再 `fillText`**。
- 中文字体用逗号分隔的候选列表 + 通用族名兜底，避免方框。
- 文字宽度用 `measureText(text).width`，别用长度硬乘。
- 图片必须 `onload` 之后再 `drawImage`，否则画布空白。
