# Canvas 路径与图形：beginPath / moveTo / lineTo / arc / fill / stroke

> 这一节讲 Canvas 的"路径"机制——它是画任意形状（线、圆、多边形）的基础。

## 路径（Path）是什么

**路径是一组"笔尖移动轨迹"的集合**。你用 `moveTo`/`lineTo`/`arc` 描述轨迹，然后用 `fill` 或 `stroke` 把它渲染出来。

```javascript
const canvas = document.querySelector('#board');
const ctx = canvas.getContext('2d');

// 画一条线段
ctx.beginPath();        // 开始一条新路径（清空旧的）
ctx.moveTo(50, 50);     // 笔尖移到起点
ctx.lineTo(150, 100);   // 画到终点
ctx.strokeStyle = 'rgb(33, 150, 243)';
ctx.lineWidth = 3;
ctx.stroke();           // 描边渲染
```

四步口诀：**beginPath → 描述轨迹 → 设置样式 → stroke/fill**。

## beginPath 的必要性

`beginPath()` 的作用是**开启一条全新的路径**。如果不调用，新的轨迹会**叠加到旧路径上**。

```javascript
// ❌ 忘记 beginPath，两条线串成一条
ctx.moveTo(10, 10);
ctx.lineTo(50, 50);
ctx.stroke();           // 画第一条线

ctx.moveTo(60, 60);     // 没 beginPath，这条线的起点会和上面连起来
ctx.lineTo(100, 100);
ctx.stroke();           // 实际画了三条线段！

// ✅ 每次画新图形前 beginPath
ctx.beginPath();
ctx.moveTo(10, 10);
ctx.lineTo(50, 50);
ctx.stroke();

ctx.beginPath();        // 关键！切断和上一笔的联系
ctx.moveTo(60, 60);
ctx.lineTo(100, 100);
ctx.stroke();
```

翻车现场一：在动画循环里忘了 beginPath，每帧都把旧轨迹重画一遍，画面越来越乱。

```javascript
// ❌ 动画里没 beginPath，路径不断累积
function draw() {
  // 没清空也没 beginPath
  ctx.moveTo(x, 100);
  ctx.lineTo(x + 10, 100);
  ctx.stroke();   // 每一帧都重新描所有历史轨迹，越来越卡、越来越粗
  x += 2;
  requestAnimationFrame(draw);
}

// ✅ 先清空画布 + beginPath
function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);  // 清空
  ctx.beginPath();                                    // 新路径
  ctx.moveTo(x, 100);
  ctx.lineTo(x + 10, 100);
  ctx.stroke();
  x += 2;
  requestAnimationFrame(draw);
}
```

后果：不 `beginPath` 时，所有 `moveTo`/`lineTo` 都累积在同一条路径上，每次 `stroke` 都会把**整条历史路径重画一遍**。动画跑久了不仅画面错乱，性能也会直线下降。

## 画三角形和多边形

```javascript
// 三角形
ctx.beginPath();
ctx.moveTo(100, 50);
ctx.lineTo(150, 120);
ctx.lineTo(50, 120);
ctx.closePath();        // 自动连回起点
ctx.fillStyle = 'rgb(255, 152, 0)';
ctx.fill();

// 五角星、任意多边形同理，就是多写几个 lineTo
```

`closePath()` 会从当前点**画一条直线回到路径起点**，形成闭合图形。

## 画圆：arc

```javascript
ctx.beginPath();
ctx.arc(100, 100, 40, 0, Math.PI * 2);  // 圆心(100,100), 半径40, 从0到2π（整圆）
ctx.fillStyle = 'rgb(156, 39, 176)';
ctx.fill();
```

`arc(x, y, radius, startAngle, endAngle)` 的角度用**弧度**。`Math.PI * 2` 是整圆，`Math.PI` 是半圆。

```javascript
// 半圆弧（只描边）
ctx.beginPath();
ctx.arc(100, 100, 40, 0, Math.PI);  // 上半圆
ctx.stroke();
```

翻车现场二：以为 arc 的角度用角度制，结果画出来的图形不对。

```javascript
// ❌ 误用角度制
ctx.arc(100, 100, 40, 0, 360);   // 期望画整圆，实际只画了很小一截

// ✅ 用弧度
ctx.arc(100, 100, 40, 0, Math.PI * 2);   // 整圆
ctx.arc(100, 100, 40, 0, Math.PI / 2);  // 四分之一圆
```

后果：`arc` 的起止角是**弧度**。`360` 弧度约等于 206 圈，远大于 `2π`，画出的是"绕了很多圈的乱线"。记住：`π 弧度 = 180°`。

## 路径小结

| 方法 | 作用 |
|---|---|
| `beginPath()` | 开启新路径，切断与之前的联系 |
| `moveTo(x, y)` | 移动笔尖（不画线） |
| `lineTo(x, y)` | 画直线到目标点 |
| `arc(...)` | 画圆弧/圆 |
| `closePath()` | 连回起点，闭合图形 |
| `fill()` | 填充当前路径 |
| `stroke()` | 描边当前路径 |

## 与 Python 的对比

Python 常用 `matplotlib`、`PIL/Pillow` 或 `turtle` 绘图，概念类似：

```python
# Pillow（PIL）：也有"创建绘图对象 → 画形状 → 保存"的流程
from PIL import Image, ImageDraw
img = Image.new('RGB', (200, 200))
draw = ImageDraw.Draw(img)
draw.rectangle([10, 10, 100, 100], fill='red')
```

Canvas 是**即时模式**的位图绘制，和 PIL 的 `ImageDraw` 思路最接近。

## 小结

- 路径四步：**beginPath → 描述轨迹 → 设样式 → stroke/fill**。
- `beginPath()` 必须每次画新图形前调用，否则轨迹累积、画面混乱。
- `moveTo` 移笔尖、`lineTo` 画线、`closePath` 闭合、`arc` 画圆。
- `arc` 角度用**弧度**，`Math.PI * 2` 是整圆。
- 动画循环要 `clearRect` + `beginPath` 双清。
