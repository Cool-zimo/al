## 标准库：装好 Python 就自带

Python 的强大很大程度来自它庞大的标准库——**装好 Python 就自带**，不用装任何东西。

```python
import random
import math
import json
import os
import datetime
```

这些模块提供了随机数、数学运算、JSON 处理、操作系统交互、日期时间等能力。你写的每一行代码几乎都在用它们。

## import 的几种写法

```python
import random                    # 1. 全量导入，用 模块名.功能
print(random.randint(1, 10))

from random import randint       # 2. 只导入一个功能，直接用名字
print(randint(1, 10))

from random import randint as ri # 3. 导入并起别名
print(ri(1, 10))

import numpy as np               # 4. 第三方库的标准起别名
```

**什么时候用哪种？**

- 模块名短、用得少：`import math`，用 `math.sqrt`
- 只用一个函数、且名字不长：`from math import sqrt`，直接用 `sqrt`
- 名字太长或会冲突：起别名 `as`

> 别用 `from random import *`——把模块里所有名字倒进当前空间，容易和你自己的变量撞名，可读性也差。

## random 和 math：最常用的两个模块

```python
import random
import math

# random
print(random.randint(1, 100))        # 1~100 的整数（包含两端）
print(random.random())               # 0~1 的随机小数
print(random.choice(["红", "蓝", "绿"]))   # 随机选一个
print(random.sample([1,2,3,4,5], 3))       # 不放回抽 3 个
random.shuffle([1,2,3,4,5])               # 原地打乱

# math
print(math.pi)                       # 3.141592653589793
print(math.sqrt(16))                 # 4.0
print(math.floor(3.9))               # 3  向下取整
print(math.ceil(3.1))                # 4  向上取整
print(math.log(100, 10))             # 2.0  以 10 为底
```

`random.choice` 在写抽卡、抽签、随机问候时极好用；`math.floor`/`ceil` 是取整的标准工具。

## 翻车现场：名字被自己的变量盖掉

```python
from random import randint
randint = 10        # 不小心用 randint 做了变量名
print(randint(1, 5))   # ❌
```

```
TypeError: 'int' object is not callable
```

**为什么**：你把 `randint` 这个名字重新指向了数字 10，原来那个函数被覆盖了。Python 里函数就是个普通对象，名字被复用就找不回来了。

**怎么防**：别用模块名、函数名做变量名。写之前先确认这个名字没被占用。

## pip 装第三方包

标准库之外，Python 社区有几十万个第三方包。**pip 是装它们的工具**，装好 Python 就自带。

```bash
pip install requests
pip install pandas
pip install flask
```

```python
import requests

resp = requests.get("https://api.github.com")
print(resp.status_code)     # 200
print(resp.json())          # 响应内容解析成字典
```

装完后和用标准库一样 `import`。`requests` 是 Python 里做 HTTP 请求的事实标准。

> 如果 pip 提示"找不到命令"，回到第 1 课检查 Python 的 PATH 配置。

## 自己写模块

你也能把代码拆成模块。比如建一个 `utils.py`：

```python
# utils.py
def format_name(first, last):
    return f"{last}, {first}"

PI = 3.14159
```

另一个文件 `main.py` 就能导入它：

```python
# main.py
import utils

print(utils.format_name("三", "张"))    # 张, 三
print(utils.PI)                        # 3.14159
```

`import` 的本质就是**把另一个文件当作模块加载进来**。把相关的函数放一个文件里，就是你自己做的"库"。

## 小结

- 标准库随 Python 自带：`random`、`math`、`json`、`os`、`datetime` 等
- 导入四式：`import x`、`from x import y`、`as` 起别名、别用 `*`
- `random` 做随机、`math` 做数学，是日常最常用的一对
- 别用模块名/函数名做变量名，会覆盖掉导入的东西
- 装第三方包：`pip install 包名`，装完直接 import
- 自己的代码也能模块化：一个 `.py` 文件就是一个模块
