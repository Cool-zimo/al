# 变量与三种数据

> 这一课学完，你能用变量存数字、文字、真假，并看懂 Python 怎么给它们分类。

## 程序为什么需要"记住东西"

上一课的 hello world 是一次性的——跑完就结束，什么都没留下。

但真实程序要记住状态：用户的名字、购物车里的商品、游戏里角色的血量。Python 用**变量**干这件事：给数据贴个标签，以后用标签来指代它。

```python
name = "张三"
age = 18
print(name, "今年", age, "岁")
```

**变量不是盒子，更像"贴标签"。** 这是 Python 和其他语言的一个重要差别。你把 `18` 放进内存，在它上面贴一张写着 `age` 的标签；再让 `score = age`，等于把 `score` 这张标签也贴到同一个东西上。不是复制了一份，是两个名字指向同一块数据。

初学阶段先记住用法，后面讲列表时再回头细说。

## `=` 不是"等于"，是"放进去"

数学里 `x = 5` 是说"x 就是 5"。Python 里 `x = 5` 是说"**把 5 放进去叫 x 的标签**"。

所以这段代码在数学里无解，在 Python 里天天写：

```python
x = 5
x = x + 1
print(x)      # 6
```

顺序是：**先算右边，再存左边**。右边 `x + 1` 算出 6，再把 6 存进 `x`，原来那个 5 被覆盖丢掉。

## Python 的三种基本数据

| 类型 | 存什么 | 例子 | 判断类型 |
|---|---|---|---|
| int / float（数字） | 数值，能算 | `18`、`1.75` | `type(18)` → `int` |
| str（字符串） | 文字，只能拼 | `"张三"`、`'hello'` | `type("a")` → `str` |
| bool（布尔） | 真假，用来判断 | `True`、`False` | `type(True)` → `bool` |

**用 `type()` 查类型**——忘了就问它：

```python
print(type(18))        # <class 'int'>
print(type(1.75))      # <class 'float'>
print(type("张三"))    # <class 'str'>
print(type(True))      # <class 'bool'>
```

### 数字：整数和小数

```python
age = 18          # int，整数
height = 1.75     # float，带小数点
score = -5        # 可以是负数
```

整数叫 `int`，带小数点的叫 `float`。**只要一个数带了小数点，它就是 float**：

```python
print(type(3))      # int
print(type(3.0))    # float，虽然值一样
```

### 字符串：包在引号里的文字

```python
name = "张三"
city = '北京'          # 单引号也行，和双引号完全等价
text = "他说：\"你好\"" # 内容里有引号时，用反斜杠转义
```

**单引号双引号随便选**，但一个字符串里必须前后一致。内容里要出现引号时，外面用单、里面用双，就不用转义了：

```python
s = '他说："你好"'     # 比转义写法清爽
```

多行字符串用三引号：

```python
poem = """床前明月光，
疑是地上霜。
举头望明月，
低头思故乡。"""
print(poem)
```

### 布尔：只有两个值

`True` 和 `False`。注意**首字母大写**——写 `true` 会报错。

```python
is_student = True
is_logged_in = False
```

它俩通常不用你手写，而是**算出来的**。`18 > 10` 的结果就是 `True`，`18 < 10` 就是 `False`。下一课讲判断时会大量用到。

## 起名字：规则与品味

**硬性规则**（违反直接报错）：

- 只能字母、数字、下划线，不能数字开头：`score2` ✅、`2score` ❌
- 区分大小写：`age` 和 `Age` 是两个变量
- 不能用关键字：`if`、`for`、`class`、`print` 都不能当变量名

**品味**（好不好读的区别）：

```python
a = 18              # 糟糕：没意义
age = 18            # 好
user_age_years = 18 # 更好：带单位，无歧义
```

## 一次给多个变量赋值

```python
x, y, z = 1, 2, 3
print(x, y, z)      # 1 2 3
```

左右一一对应。**交换两个变量**时这招最漂亮，别的语言还要临时变量：

```python
a = 10
b = 20
a, b = b, a         # 一行搞定
print(a, b)         # 20 10
```

右边先算出 `(20, 10)` 这个整体，再分别放进 `a` 和 `b`。

## 动态类型：变量本身没有类型

Python 不需要事先声明类型。`age` 这会儿装数字，下句装字符串，完全合法：

```python
age = 18
age = "十八岁"
print(age)
```

这叫**动态类型**——类型是"值"的属性，不是"变量"的属性。好处是写得快；代价是类型错了不会在写代码时报错，要等跑到那行才炸。

## 翻车现场：变量没赋值就用

```python
print(message)
```

```
NameError: name 'message' is not defined
```

**为什么**：你让 Python 去取一个叫 `message` 的标签，但这个标签从来没被创建过。Python 宁可直接报错，也不猜一个值给你。

**怎么修**：用之前先赋值。排查三板斧：拼错了？用了中文标点？还没赋值就用了？

## 小结

- 变量 = 给数据贴标签，`=` 是"放进去"，不是"等于"
- 先算右边再存左边：`x = x + 1` 合法
- 三种基本类型：`int`/`float`（数字）、`str`（字符串）、`bool`（True/False）
- `type()` 随时查类型；忘了引号规则就回想"前后一致"
- 变量名要有意义、带单位、用下划线连接
- Python 是动态类型，变量可以随时换装不同类型的值
