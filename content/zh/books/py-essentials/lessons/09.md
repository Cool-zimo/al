# for 与 range：知道要跑几遍

> 这一课学完，你能用 `for` 精确控制循环次数，并学会"终点取不到"这个必须记住的规则。

## for 比 while 更适合"数得清"的循环

上一课说了，while 适合"不知道跑几遍"。如果你**明确知道要跑 10 遍**，用 `for` 更清爽：

```python
for i in range(5):
    print(i)
```

```
0
1
2
3
4
```

## range 的三条规则

`range` 生成一串整数，**语法是 `range(起点, 终点, 步长)`**，全部可选，默认起点 0、步长 1。

| 写法 | 产生的序列 | 说明 |
|---|---|---|
| `range(5)` | 0,1,2,3,4 | 终点取不到 |
| `range(2, 6)` | 2,3,4,5 | 从 2 到 5 |
| `range(0, 10, 2)` | 0,2,4,6,8 | 步长 2，隔一个取一个 |
| `range(5, 0, -1)` | 5,4,3,2,1 | 倒着数 |

### 铁律：终点取不到

`range(5)` 是 **0 到 4**，不是 0 到 5。这条规则贯穿整个 Python，必须刻进肌肉记忆：

```python
for i in range(5):
    print(i)      # 打印 0 1 2 3 4，共 5 个数
```

好处是**首尾相减就是个数**：`range(2, 6)` 有 `6-2=4` 个数。如果你想要 1 到 10，写 `range(1, 11)`——终点写 11，因为 11 取不到。

## 翻车现场：把终点当成包含

```python
# WRONG：想打印 1 到 10
for i in range(1, 10):
    print(i)
```

实际输出是 1 到 9，少了 10。

**怎么修**：终点加一：`range(1, 11)`。

> 这条坑在"遍历下标"时最要命。一个长度为 5 的列表，合法下标是 0~4，刚好对应 `range(5)`，所以**遍历下标时直接用 `range(len(x))`**，天然对得上。

## for 能遍历任何"可迭代"的东西

`range` 只是其中一种。字符串、列表、元组、字典都能直接扔给 `for`：

```python
for ch in "你好":
    print(ch)
# 你
# 好

for fruit in ["苹果", "香蕉", "橙子"]:
    print(fruit)
# 苹果 香蕉 橙子
```

`for` 会自动一个一个取出来，不用你管下标。这种"不用下标"的遍历是 Python 里最常见的用法。

## enumerate：既要内容又要下标

遍历列表时如果**既想要元素又想要它的位置**，用 `enumerate`：

```python
fruits = ["苹果", "香蕉", "橙子"]
for index, fruit in enumerate(fruits):
    print(index, fruit)
```

```
0 苹果
1 香蕉
2 橙子
```

`enumerate` 返回的是"下标 + 元素"的配对。需要打印序号、找位置时用它，比自己维护一个 `i += 1` 干净。

## 遍历字符串

字符串本质就是一串字符，`for` 直接拆：

```python
for ch in "Python":
    print(ch)
# P y t h o n
```

统计元音字母的个数：

```python
text = "hello world"
count = 0
for ch in text:
    if ch in "aeiouAEIOU":
        count += 1
print(count)      # 3
```

`ch in "aeiouAEIOU"` 是后面才正式讲、但现在就能用的判断：字符是否在这串里。

## 小结

- `for i in range(n):` 是"数得清"循环的首选
- **`range(终点)` 终点取不到**：`range(5)` 是 0~4
- `range(起点, 终点, 步长)`：三个参数都有默认值
- 想打印 1~10 就写 `range(1, 11)`——终点永远多写 1
- `for` 能遍历字符串、列表、元组等一切可迭代对象
- 既要下标又要元素：`enumerate`
- 字符串遍历就是逐个取字符，`in` 判断是否在里面
