# 字典的常用操作

> 这一课学完，你能遍历字典、从字典里安全地取删改，并读懂"字典套字典"这种真实数据结构。

## 遍历字典的三招

字典比列表多一个维度（键值对），所以遍历有三种姿势：

```python
person = {"name": "张三", "age": 18, "city": "北京"}

# 遍历键（默认就是键）
for key in person:
    print(key)
# name / age / city

# 遍历值
for value in person.values():
    print(value)
# 张三 / 18 / 北京

# 键和值一起取
for key, value in person.items():
    print(key, "=", value)
# name = 张三
# age = 18
# city = 北京
```

`person.items()` 返回的是"键值对"的可遍历对象，配合解包 `key, value` 用最方便。

> 💡 `for x in 字典` 默认遍历的是**键**。需要值用 `.values()`，都需要用 `.items()`。

## 安全的删法：pop 带默认值

上一课讲了 `del` 和 `pop`。`pop` 有个额外优势——**可以带默认值，删不到也不报错**：

```python
scores = {"语文": 90, "数学": 95}

# del 删不到就报错
# del scores["英语"]      # KeyError

# pop 带默认值，安全
value = scores.pop("英语", 0)
print(value)              # 0（没删到，返回默认值）
print(scores)             # {'语文': 90, '数学': 95}
```

**凡是"不确定有没有"的删除，都用 `pop(key, 默认值)`。**

## keys、values、items 都是可遍历的

```python
scores = {"语文": 90, "数学": 95, "英语": 88}

print(list(scores.keys()))     # ['语文', '数学', '英语']
print(list(scores.values()))   # [90, 95, 88]
print(list(scores.items()))    # [('语文', 90), ('数学', 95), ('英语', 88)]
```

套一层 `list()` 就能把结果变成列表。比如"找出所有及格的科目"：

```python
passed = []
for subject, score in scores.items():
    if score >= 60:
        passed.append(subject)
print(passed)      # ['语文', '数学', '英语']
```

## 翻车现场：遍历时往字典里加键

和列表一样，遍历时改结构有坑。删键相对安全，但**新增键会报错**：

```python
# WRONG
scores = {"语文": 90, "数学": 95}
for subject in scores:
    if scores[subject] < 60:
        scores[subject + "_补考"] = True   # 遍历中新增键
```

```
RuntimeError: dictionary changed size during iteration
```

**怎么修**：遍历它的副本（转成列表）：

```python
for subject in list(scores.keys()):
    if scores[subject] < 60:
        scores[subject + "_补考"] = True
```

`list(scores.keys())` 先拿到一份键的快照，遍历快照就不会报错。

## 嵌套字典：真实数据的样子

真实项目里的字典几乎都是嵌套的——字典里的值又是字典、列表：

```python
students = {
    "张三": {"语文": 90, "数学": 95, "英语": 88},
    "李四": {"语文": 78, "数学": 82, "英语": 91},
    "王五": {"语文": 60, "数学": 70, "英语": 65},
}

# 查张三的数学分
print(students["张三"]["数学"])      # 95

# 遍历所有人
for name, scores in students.items():
    total = 0
    for subject, score in scores.items():
        total += score
    print(name, "总分", total, "平均", round(total / len(scores), 1))
```

`students["张三"]["数学"]` 这种**链式取值**就是字典嵌套的标准用法，一层一层往里钻。

## 合并字典

```python
a = {"name": "张三", "age": 18}
b = {"city": "北京", "age": 20}

# 法一：update，把 b 合并进 a（同键会被 b 覆盖）
a.update(b)
print(a)      # {'name': '张三', 'age': 20, 'city': '北京'}

# 法二：{**a, **b}，生成新字典，不改原
c = {**a, **b}
```

`update` 是改原字典，`{**a, **b}` 是生成新字典。后出现的会覆盖先出现的同键。

## 统计场景：字典当计数器

字典是做词频统计的最佳工具：

```python
words = ["苹果", "香蕉", "苹果", "橙子", "香蕉", "苹果"]
count = {}

for w in words:
    count[w] = count.get(w, 0) + 1

print(count)      # {'苹果': 3, '香蕉': 2, '橙子': 1}
```

`count.get(w, 0) + 1` 这句是精髓：**查不到就默认 0，再 +1**。这是字典计数最经典的一行写法。

## 小结

- 遍历三招：`for key`、`for v in d.values()`、`for k, v in d.items()`
- 默认 `for x in 字典` 遍历的是**键**
- 删除用 `pop(key, 默认值)`，不确定有没有时用它
- 遍历中新增键会 `RuntimeError`，用 `list(d.keys())` 取快照
- 嵌套字典用链式取值：`d["a"]["b"]`
- 合并：`update()`（改原）或 `{**a, **b}`（新字典）
- `count[k] = count.get(k, 0) + 1` 是字典计数模板
