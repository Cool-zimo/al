# 安装与第一个程序

> 这一课学完，你能从零装好 Python 和 VSCode，写出并运行人生第一个 `hello.py`。

## 为什么不直接在网页里写

你可能会问：前面那些示例都能直接点运行，为什么这课还要让你装东西？

因为**网页里的 Python 是"沙盒版"（Pyodide）**——它够用来学语法，但它没有文件系统、没有真实网络、没有 GUI。等你学到文件读写、装第三方库，就必须有一台真正的 Python 环境。

这课只做四件事：装 Python、装 VSCode、写 hello world、跑起来。做完，你的电脑就有了写任何 Python 程序的能力。

## 装 Python：去官网下，别用应用商店

**第一步，确认有没有装过。** 打开终端（Windows 叫"命令提示符"或 PowerShell，Mac 是"终端"，Linux 就是终端），输入：

```bash
python --version
```

如果显示 `Python 3.x.x`，说明已经装了，直接跳到下一节。如果显示"找不到命令"，往下走。

**第二步，下载安装包。** 访问 [python.org/downloads](https://www.python.org/downloads)，页面会自动推荐最新版（写这篇时是 3.13）。点那个黄色的 **Download Python 3.x.x**。

**第三步，安装时务必勾一个框。**

这是新手最容易翻车的一步。Windows 安装界面底部有个选项：

```
☐ Add Python 3.x to PATH      ← 必须勾上！
```

**不勾这个，你以后在终端敲 `python` 会被告知"找不到命令"。** 勾上它，安装程序才会把 Python 的路径注册到系统环境变量里。装过没勾的，卸载重装一次，勾上就行。

**第四步，验证。** 重新打开一个终端，输入：

```bash
python --version
```

看到版本号，说明装好了。再确认一下 pip（装第三方库的工具）也在：

```bash
pip --version
```

## 翻车现场：装了却提示"找不到命令"

```bash
C:\> python --version
'python' 不是内部或外部命令，也不是可运行的程序
```

**为什么**：99% 是因为装的时候没勾 "Add to PATH"。

**怎么修**：两个办法，任选一个。

1. **重装**（推荐）：卸载 Python，重新跑安装包，这次一定勾上 Add Python to PATH。
2. **手动改 PATH**：把 Python 安装目录（一般在 `C:\Users\你的用户名\AppData\Local\Programs\Python\Python313`）和里面的 `Scripts` 目录，加到系统环境变量 PATH 里。

装好后**必须重开一个终端窗口**再试——老终端不会自动刷新环境变量。

## 装 VSCode：编辑器，不是 Python

VSCode（Visual Studio Code）是写代码的编辑器。它**本身不是 Python**，但它装上插件后写 Python 非常舒服。

1. 访问 [code.visualstudio.com](https://code.visualstudio.com)，下载安装
2. 打开 VSCode，点左侧第五个方块图标（扩展 Extensions）
3. 搜索 **Python**，装微软官方那个（下载量最高，带 Pylance 的那个）
4. 再搜 **Chinese**，装上中文语言包，重启就是中文界面

> 编辑器不是唯一选择。PyCharm、Sublime、甚至记事本都能写 Python。但 VSCode 免费、轻量、插件生态好，是初学者的甜点区。

## 第一个程序：hello.py

在电脑上新建一个文件夹，比如 `D:\learn_python`（路径里**别用中文和空格**，后面会讲为什么）。

在 VSCode 里：`文件 → 打开文件夹`，选中这个文件夹。然后 `新建文件`，命名为 `hello.py`。

`.py` 是 Python 文件的后缀，告诉系统和编辑器"这是 Python 代码"。

敲入这行：

```python
print("你好，世界")
```

保存（`Ctrl+S` 或 `Cmd+S`），然后运行。

## 怎么运行：两种方式

**方式一：点运行按钮（最简单）**

VSCode 里打开 `hello.py`，右上角有个 ▷ 三角按钮，点它。下方会弹出"终端"面板，输出 `你好，世界`。

**方式二：在终端里手动跑（必须会）**

```bash
cd D:\learn_python      # 先进入文件所在目录
python hello.py         # 再跑
```

`cd` 是"切换目录"。如果你不先 `cd` 到文件所在的文件夹，Python 会找不到 `hello.py`。

> 记住这两步流程：**先 cd 进目录，再 python 文件名**。这个动作后面会重复上千次。

## print 到底做了什么

`print` 是 Python 里最基础的函数：把括号里的东西**打印到屏幕上**。

```python
print("你好，世界")
print(123 + 456)
name = "张三"
print("我叫", name)
```

```
你好，世界
579
我叫 张三
```

**括号里可以放多个东西，用逗号隔开**，Python 会自动在中间加空格。

> 💡 第一句里的 `"你好，世界"` 两边是英文双引号。这是**字符串**——一串文字。下一课会详细讲。

## 翻车现场：引号用成中文的

```python
print("你好")
```

```
  File "hello.py", line 1
    print("你好")
          ^
SyntaxError: invalid character '“' (U+201C)
```

**为什么**：中文引号 `"` `"` 和英文引号 `"` 在 Python 眼里是**完全不同的字符**。Python 只认英文的。

**怎么修**：删掉中文引号，打英文的。养成习惯：写代码时把输入法切成英文标点模式。

顺带一提，这三个符号也常被打错：中文逗号 `，`、中文冒号 `：`，以及中文括号 `（）`。看到 `SyntaxError` 又找不到原因，先检查是不是标点中英文混了。

## 小结

- Python 官网下载，安装时**务必勾 Add to PATH**
- 验证：`python --version` 和 `pip --version` 都要能跑
- VSCode + 官方 Python 扩展，是初学者的标准配置
- 运行程序 = `cd` 到目录 + `python 文件名.py`
- `print()` 打印内容到屏幕，多个值用逗号隔开
- 引号、逗号、冒号、括号都要用英文标点

- assert "岁" in __out
