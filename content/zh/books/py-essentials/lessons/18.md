# 作用域：局部变量与全局变量

> 这一课学完，你能分清变量在哪能用、在哪用不了，并知道 `global` 只在什么情况下才该写。

## 函数里的变量外面看不见

```python
def calc():
    result = 10 + 20

calc()
print(result)
```

```
NameError: name 'result' is not defined
```

**为什么**：`result` 定义在 `calc` 里面，是**局部变量**——只在函数内部存在。函数跑完，`result` 就消失了。

**作用域（scope）** 就是"变量能起作用的范围"。Python 按 **LEGB** 规则查找变量：

1. **L**ocal：当前函数内部
2. **E**nclosing：外层函数（闭包时才有）
3. **G**lobal：整个文件（模块）级别
4. **B**uilt-in：Python 内置（`print`、`len`、`range` 等）

找不到就一层层往外找，到 Built-in 还找不到就 `NameError`。

## 函数能读外面的变量

```python
tax_rate = 0.1       # 全局变量

def calc_price(price):
    return price * (1 + tax_rate)   # 能读到 tax_rate

print(calc_price(100))     # 110.0
```

读全局变量是允许的。问题出在**写**。

## 翻车现场：想改全局却创建了局部

```python
count = 0

def increment():
    count = count + 1     # ❌

increment()
```

```
UnboundLocalError: local variable 'count' referenced before assignment
```

**为什么**：Python 看到 `count = ...` 这一行的**赋值**，就认定 `count` 是这个函数里的局部变量。于是等号右边的 `count + 1` 在"局部还没赋值"时就被读取了，报错。

**这不是 bug，是规则**：**函数里给一个变量赋值，它就成了局部变量，覆盖掉外面的同名变量。**

**两种修法**：

```python
# 法一（推荐）：把值当参数传进去，结果当返回值
count = 0
def increment(n):
    return n + 1

count = increment(count)

# 法二：确实要改全局，用 global 声明
count = 0
def increment():
    global count        # 声明：我要用的是外面的那个 count
    count = count + 1

increment()
print(count)            # 1
```

## global 什么时候才该用

**原则：能用参数和返回值就别用 `global`。**

`global` 让函数偷偷修改外部状态，用多了代码会变得难以追踪——你不知道是谁改了这个值。这叫"副作用"。

那什么时候用？**真正需要共享状态时**：

- 游戏里的得分、开关、配置
- 统计"这个函数被调用了几次"的计数器
- 脚本里全局唯一的配置开关

```python
call_count = 0

def greet(name):
    global call_count
    call_count += 1
    print(f"第{call_count}次问候：你好，{name}")

greet("张三")
greet("李四")
# 第1次问候：你好，张三
# 第2次问候：你好，李四
```

这种"函数被调用次数"的场景用 `global` 是合理的。

## 变量同名不冲突

```python
def func():
    x = 10        # 局部
    print(x)

x = 100           # 全局
func()            # 10
print(x)          # 100
```

函数里用的是局部 `x`，外面的全局 `x` 没被动。两个 `x` 是不同东西，互不影响。

## 小结

- 作用域 = 变量能起作用的范围，查找顺序 LEGB
- 函数内能**读**全局变量，但**赋值**会让它变成局部变量
- `UnboundLocalError` = 想读局部却还没赋值，就是"赋值即局部"规则的结果
- 改全局用 `global` 声明，但**优先用参数 + 返回值**
- `global` 只适合共享状态：计数器、开关、全局配置
- 同名局部和全局是不同变量，互不影响

```quiz
type: code
q: 写一个函数 add_log(text)，往全局列表 logs 里追加一条带序号的记录（"1: xxx"），用 global 实现
starter: |
  logs = []

  def add_log(text):
      # 用 global 声明 logs，然后 logs.append 一条带序号的记录
      pass

  add_log("程序启动")
  add_log("连接数据库")
  print(logs)
tests:
- assert "程序启动" in __out
- assert "1" in __out
- assert "2" in __out
hint: global logs，然后 logs.append(f"{len(logs)+1}: {text}")。序号就是当前长度+1。
explain: 全局日志列表是 global 最典型的正当用途之一，记录系统运行痕迹。
```
