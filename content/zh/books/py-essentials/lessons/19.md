# 字符串方法大全

> 这一课学完，你能用字符串方法完成切分、拼接、清理、替换、格式化，不再手写一堆循环。

## 字符串是不可变的

先记住一条：`strip`、`replace`、`upper` 这些方法**都不改动原字符串**，而是返回一个新字符串。

```python
name = "  张三  "
clean = name.strip()
print(name)       # "  张三  "  原字符串没变
print(clean)      # "张三"
```

想让原变量"变干净"，得把结果重新赋值回去：

```python
name = name.strip()
```

## split / join：切和拼

上一课提过，这里展开讲。

```python
text = "苹果,香蕉,橙子,葡萄"
fruits = text.split(",")        # ['苹果', '香蕉', '橙子', '葡萄']
print(fruits)

# 不指定分隔符时，默认按"任意空白"切（空格、换行、Tab 都算）
line = "a   b\tc\nd"
print(line.split())             # ['a', 'b', 'c', 'd']

# 限制切几刀
print("2026-09-27".split("-", 1))   # ['2026', '09-27']
```

`join` 是 `split` 的反向操作，记住调用者是"连接符"：

```python
words = ["我", "爱", "Python"]
print("".join(words))           # 我爱Python
print("-".join(words))          # 我-爱-Python
print("\n".join(words))         # 每个一行
```

## strip：清理首尾空白

```python
name = "  张三  \n"
print(name.strip())             # "张三"
```

`strip()` 常用于**处理用户输入**——用户多打了空格和回车，先 strip 再处理：

```python
choice = input("继续吗(y/n)：").strip().lower()
if choice == "y":
    print("继续")
```

链式调用 `strip().lower()` 一行搞定"去空白 + 转小写"。`lower()` 把字符串全变小写，`upper()` 全变大写。

## replace：替换

```python
text = "我喜欢吃苹果，苹果很好吃"
new = text.replace("苹果", "香蕉")
print(new)          # 我喜欢吃香蕉，香蕉很好吃

# 限制替换次数
print(text.replace("苹果", "香蕉", 1))
# 我喜欢吃香蕉，苹果很好吃   只换第一个
```

`replace` 返回新字符串，原字符串不变。

## format 与 f-string：把变量塞进字符串

**f-string（最推荐）**——在字符串前加 `f`，变量用 `{}` 包起来：

```python
name = "张三"
age = 18
print(f"{name}今年{age}岁")         # 张三今年18岁

# 格式化控制
pi = 3.1415926
print(f"圆周率：{pi:.2f}")          # 圆周率：3.14   保留两位
print(f"百分制：{0.856:.1%}")       # 百分制：85.6%  百分比
print(f"{123:>5}")                 # "  123"        右对齐补空格
print(f"{123:<5}")                 # "123  "        左对齐
```

`{变量:格式}` 的冒号后面写格式：`.2f` 两位小数、`.1%` 百分比、`<`/`>` 对齐。初学掌握 `:.2f` 就够应付大多数场景。

**format 方法**（f-string 出现之前的写法）：

```python
print("{}今年{}岁".format(name, age))
print("{0}今年{1}岁，{0}喜欢Python".format(name, age))  # 下标复用
```

能用 f-string 就用 f-string，它更直观。

## 翻车现场：忘了 f 前缀

```python
name = "张三"
print("{name}今年{age}岁")     # 忘记写 f
```

输出是字面量的 `{name}今年{age}岁`，变量根本没被替换。

**怎么修**：在引号前加 `f`：`print(f"{name}今年{age}岁")`。

> 这种错不会报错，只是输出不对，反而更隐蔽。养成"要嵌变量先写 f"的肌肉记忆。

## 查找与判断

| 方法 | 作用 | 例子 |
|---|---|---|
| `startswith(s)` | 是否以 s 开头 | `"hello".startswith("he")` → `True` |
| `endswith(s)` | 是否以 s 结尾 | `"hello".endswith("lo")` → `True` |
| `find(s)` | 找 s 的位置，找不到返回 -1 | `"hello".find("e")` → `1` |
| `count(s)` | s 出现几次 | `"hello".count("l")` → `2` |
| `isdigit()` | 是否全是数字 | `"123".isdigit()` → `True` |

```python
filename = "report.pdf"
if filename.endswith(".pdf"):
    print("是 PDF 文件")

text = "hello world"
print(text.find("world"))      # 6
print(text.find("python"))     # -1
```

> 判断"在不在"用 `in`（返回 True/False），找"在第几个"用 `find`（返回下标或 -1）。

## 小结

- 字符串**不可变**，方法都返回新字符串，要"改"就得重新赋值
- `split()` 切，`"连接符".join(列表)` 拼；`strip()` 清首尾空白
- `replace(旧, 新)` 替换，可限次数
- f-string 是首选：`f"{变量:.2f}"`；`{:.2f}` 保留两位小数
- 忘了 f 前缀是最隐蔽的低级错误，输出字面量而不是变量
- 查找判断：`startswith`、`endswith`、`find`、`count`、`isdigit`
- `in` 判断在不在，`find` 找位置
