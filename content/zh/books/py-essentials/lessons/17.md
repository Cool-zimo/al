# 参数进阶：默认、关键字与可变参数

> 这一课学完，你能写出"可选项很多"的函数，并搞清位置参数和关键字参数的顺序。

## 默认参数：带默认值的参数

很多函数有些参数**大部分时候用一个固定值**，只在少数情况才改。默认参数就是为它设计的：

```python
def greet(name, greeting="你好"):
    return f"{greeting}，{name}"

print(greet("张三"))            # 你好，张三       用默认值
print(greet("Alice", "Hi"))    # Hi，Alice        自己指定
print(greet("李四", greeting="早上好"))  # 早上好，李四  用关键字
```

`greeting="你好"` 就是默认参数。**调用时没传，就用默认值。**

这让函数调用变得轻量，只在需要时多写一个参数。

## 翻车现场：默认参数是可变对象

这是一个经典的"深坑"：

```python
# WRONG
def add_item(item, lst=[]):
    lst.append(item)
    return lst

print(add_item(1))      # [1]
print(add_item(2))      # [1, 2]   ??? 不是应该 [2] 吗
```

第二次调用居然带上了上一次的数据！

**为什么**：默认参数的值在**函数定义时**就被算出来一次，之后一直复用同一个列表对象。它不是每次调用都新建一个空列表。

**标准修法**：默认用 `None`，函数体内再创建：

```python
def add_item(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst

print(add_item(1))      # [1]
print(add_item(2))      # [2]   正确
```

> 记这条规则：**默认参数不要写可变对象（列表、字典、集合）**，用 `None` 代替。

## 关键字参数：调用时显式说名字

```python
def create_user(name, age, city):
    return f"{name}，{age}岁，住{city}"

# 位置参数：靠顺序对应
create_user("张三", 18, "北京")

# 关键字参数：靠名字对应
create_user(name="张三", city="北京", age=18)
```

关键字参数的好处是**顺序无所谓**，代码还更可读——一眼看出哪个值对应哪个参数。

**两者可以混用，但位置参数必须在前**：

```python
create_user("张三", age=18, city="北京")     # ✅ 位置在前，关键字在后
# create_user(name="张三", 18, "北京")       # ❌ 位置参数不能在关键字之后
```

## *args：接收任意多个位置参数

有时候你不知道会传进来几个参数，`*args` 把多出来的位置参数收进一个**元组**：

```python
def average(*args):
    return sum(args) / len(args)

print(average(80, 90, 75))          # 81.666...
print(average(100, 60, 88, 92, 77)) # 83.4
```

`*args` 名字里的 `*` 是语法，`args` 只是约定俗成的名字（你写 `*numbers` 也行）。函数体内它就是一个元组。

```python
def show_scores(title, *scores):
    print(title, "的成绩：")
    for s in scores:
        print(s)

show_scores("张三", 90, 85, 92)
# 张三 的成绩：
# 90
# 85
# 92
```

`title` 吃第一个参数，剩下的全进 `*scores`。

## 参数顺序的铁律

一个函数里同时出现多种参数，**顺序固定**：

```
位置参数 → 默认参数 → *args
```

```python
def f(a, b=2, *args):
    print(a, b, args)

f(1)             # a=1, b=2, args=()
f(1, 3)          # a=1, b=3, args=()
f(1, 3, 4, 5)    # a=1, b=3, args=(4, 5)
```

**记错顺序会直接 SyntaxError**，所以按这个顺序记牢就行。

## 解包调用：用 * 把列表拆开传

`*` 不只是收参数，也能在**调用时**把列表拆开：

```python
def add(a, b, c):
    return a + b + c

nums = [1, 2, 3]
print(add(*nums))      # 等价于 add(1, 2, 3)  → 6
```

`*nums` 把列表拆成三个独立参数。`**` 也能拆字典（关键字参数），不过初学阶段记住 `*` 就够用。

## 小结

- 默认参数：`def f(x, y=10):`，调用时可省
- **默认参数别用可变对象**，用 `None` + 函数体内创建
- 关键字参数 `f(name="张三")`：顺序无所谓，可读性好
- 位置参数必须在关键字参数之前
- `*args` 收集多余位置参数成一个元组，调用时 `*` 也能拆开列表
- 参数顺序：位置 → 默认 → `*args`，写错就 SyntaxError
