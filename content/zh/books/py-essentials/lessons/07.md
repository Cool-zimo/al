# and / or / not 与真假规则

> 这一课学完，你能把多个条件组合起来，并搞清 Python 里"什么算真、什么算假"。

## 一个条件不够用

上一课的 `if age >= 18` 只能判断一件事。现实里常常是组合判断：

- "满 18 岁 **并且** 有身份证"才能注册
- "是 VIP **或者** 消费满 200"才能免运费
- "**不是** 会员"才显示广告

Python 用三个逻辑运算符连接条件：

| 运算符 | 含义 | 规则 |
|---|---|---|
| `and` | 并且 | 两边**都**为真，结果才真 |
| `or` | 或者 | 两边**有一个**为真，结果就真 |
| `not` | 取反 | 真的变假，假的变真 |

```python
age = 20
has_id = True

if age >= 18 and has_id:
    print("可以注册")
else:
    print("条件不满足")
```

`and` 要求两个都为真，才打印"可以注册"。

## 短路：聪明的偷懒机制

Python 求 `and` 和 `or` 时会**短路**——能确定结果就提前停：

```python
# and：左边为假，右边不用看了
if False and (1 / 0 > 0):
    print("不会执行")
# 不会报错，因为右边根本没被求值

# or：左边为真，右边不用看了
if True or (1 / 0 > 0):
    print("不会执行")
```

`1 / 0` 本该触发 `ZeroDivisionError`，但因为短路，它根本没被执行。这个机制常被用来写"安全访问"：

```python
if name and len(name) > 3:    # name 为空时不会去求 len(name)
    print("名字够长")
```

## 运算符优先级

一句话记牢：**`not` 最高，`and` 次之，`or` 最低**。比较运算符（`>`、`==`）比逻辑运算符还高。

```python
if not age > 18 and has_id:       # 先算 not，再算 and
    ...

if age > 18 or score >= 60 and is_vip:   # and 先算
    ...
```

拿不准就加括号，比记优先级可靠：

```python
if (age > 18 or score >= 60) and is_vip:
    ...
```

## 翻车现场：连写比较的陷阱

数学里 `18 <= age <= 60` 是通顺的，Python 也支持这种**链式比较**：

```python
if 18 <= age <= 60:
    print("适龄")
```

**但下面这种写法是错的**：

```python
# WRONG：以为这样能判断 age 在 18 和 60 之间
if age >= 18 and <= 60:      # 语法错误
    print("适龄")
```

`and` 两边必须都是完整的条件，右边 `<= 60` 缺了左边，Python 看不懂。

```python
# 正确写法
if age >= 18 and age <= 60:
    print("适龄")
```

> 另一个常见坑：想判断"不等于多个值"时写成 `if x != 1 or 2 or 3`。这是错的，`or` 不这么用。正确写法是 `if x != 1 and x != 2 and x != 3`，或后面学的 `if x not in (1, 2, 3)`。

## 真假规则：哪些值算假

`if` 后面的条件不一定要是 `True`/`False`，**任何值都能被当成真假来用**：

```python
if "张三":
    print("执行了")      # 会执行
```

因为**非空字符串算真**。完整规则：

| 算 **假** 的值（少数） | 算 **真** 的值（其余都是） |
|---|---|
| `False` | 非空字符串 `"a"` |
| `None` | 非零数字 `1`、`-1` |
| `0`、`0.0` | 非空容器 `[1]`、`{"a": 1}` |
| `""` 空字符串 | |
| `[]` 空列表、`{}` 空字典、`()` 空元组、`set()` 空集合 | |

**口诀：空的和零的都算假，其余都算真。**

这条规则非常好用：

```python
name = input("名字：")      # 用户直接回车，得到 ""
if name:
    print("你好，", name)
else:
    print("你没输入名字")
```

`if name:` 就是"如果 name 非空"。检查列表有没有元素：`if my_list:` 等价于 `if len(my_list) > 0:`。

## not 的用法

`not` 把真假反过来：

```python
is_logged_in = False

if not is_logged_in:
    print("请先登录")

# 结合 in
if "admin" not in users:
    print("没有管理员")
```

`not in` 是"不在里面"的常用写法。

## 小结

- `and`（都真才真）、`or`（有真就真）、`not`（取反）用来组合条件
- 短路机制：`and` 遇假停、`or` 遇真停，能避免不必要的报错
- 优先级：`not` > `and` > `or`，拿不准就加括号
- 链式比较 `18 <= age <= 60` 合法；`and <= 60` 非法
- **空的和零的算假**：`""`、`0`、`[]`、`{}`、`None`、`False`
- `if name:` 就是判断"非空"，写起来比 `len(name) > 0` 清爽
