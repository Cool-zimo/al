# 元组与字典：什么时候用哪个

> 这一课学完，你能分清元组和列表，并会用字典按"名字"查数据。

## 先认识元组

**元组（tuple）** 是"不能改的列表"。用圆括号，元素逗号分隔：

```python
point = (3, 5)
rgb = (255, 128, 0)

print(point[0])     # 3
print(rgb[1])       # 128
```

下标、切片、遍历——列表能用的大部分操作，元组都能用。但**不能增删改元素**：

```python
point = (3, 5)
point[0] = 10       # ❌ 报错
```

```
TypeError: 'tuple' object does not support item assignment
```

**元组的意义就在于"不可变"**。你写了一个坐标、一个 RGB 颜色、一个日期，这些值不该被中途改动。用元组，Python 会在你不小心改它时报错拦住你——这是一层保护。

**什么时候用元组，什么时候用列表？**

| | 列表 list `[]` | 元组 tuple `()` |
|---|---|---|
| 可变性 | 可变，能增删改 | **不可变**，创建后不能改 |
| 典型用途 | 一堆同类数据：成绩、任务列表 | 固定结构：坐标、颜色、记录 |
| 能不能当字典的键 | 不能（可变） | **能**（不可变） |

> 经验法则：**数据会变 → 列表；数据是一组固定属性 → 元组。**

## 打包与解包

元组有个非常顺手的特性——**自动打包**和**解包**：

```python
# 打包：多个值赋给一个变量，自动变成元组
point = 3, 5        # 等价于 (3, 5)

# 解包：一个元组拆给多个变量
x, y = (3, 5)
print(x)            # 3
print(y)            # 5
```

这就是第二课讲的"交换两个变量"的秘密：`a, b = b, a` 右边先打包成元组，再解包给左边。

解包还能用来**优雅地忽略不需要的值**：

```python
name, age, _ = ("张三", 18, "北京")
print(name, age)    # 张三 18
```

下划线 `_` 是约定俗成的"我不用这个值"的占位符。

## 字典：按名字查数据

列表用数字下标取元素。但很多时候你需要**用"名字"来取**：

```python
# 用列表存一个人：得记住 0 是名字、1 是年龄……
person = ["张三", 18, "北京"]

# 用字典存：直接用名字取
person = {
    "name": "张三",
    "age": 18,
    "city": "北京"
}
print(person["name"])    # 张三
print(person["age"])     # 18
```

**字典（dict）** 存的是"键值对"：`{键: 值, 键: 值}`。键是索引，值是内容。查找时是**按名字找**，不用记位置。

字典的键**必须是不可变类型**（字符串、数字、元组都行），值可以是任何东西。

## 字典的增删改查

```python
person = {"name": "张三", "age": 18}

# 查
print(person["name"])        # 张三
print(person.get("city", "未知"))   # 未知（键不存在时用默认值，不会报错）

# 改
person["age"] = 19           # 有这个键就改
print(person["age"])         # 19

# 增
person["city"] = "上海"      # 没这个键就新增
print(person)                # {'name': '张三', 'age': 19, 'city': '上海'}

# 删
del person["age"]            # 删除一个键值对
print(person)                # {'name': '张三', 'city': '上海'}

person.pop("city")           # 另一种删法，返回被删的值
print(person)                # {'name': '张三'}
```

### 三种查法，安全程度不同

```python
scores = {"语文": 90, "数学": 95}

# 1. 中括号：键不存在就 KeyError
print(scores["英语"])        # ❌ KeyError

# 2. get：键不存在返回 None 或你指定的默认值
print(scores.get("英语"))            # None
print(scores.get("英语", 0))         # 0

# 3. in：先判断在不在，再取值
if "英语" in scores:
    print(scores["英语"])
```

**查字典最稳的写法是 `get(键, 默认值)`**——它永远不会报错，还能给个合理的默认。

## 翻车现场：字典查不存在的键

```python
scores = {"语文": 90, "数学": 95}
print(scores["英语"])
```

```
KeyError: '英语'
```

**为什么**：字典里没有 "英语" 这个键，`[]` 查法遇到不存在的键就直接报错。

**怎么修**：三选一：

```python
# 法一：先 in 判断
if "英语" in scores:
    print(scores["英语"])
else:
    print("暂无成绩")

# 法二：用 get + 默认值（推荐）
print(scores.get("英语", "暂无成绩"))

# 法三：setdefault，查不到就先写入默认值再返回
scores.setdefault("英语", 0)
```

## 小结

- **元组 `()` 不可变**，列表 `[]` 可变；数据不该被改时用元组
- 元组能打包/解包：`x, y = (3, 5)`；`_` 表示不用的变量
- **字典 `{键: 值}` 按名字查**，不用记下标，适合"有名字的属性"
- 字典键必须是不可变类型；查值三种写法：`[]`、`get()`、`in`
- **`get(键, 默认值)` 最稳**，不会 KeyError
- 元组能当字典的键，列表不能
