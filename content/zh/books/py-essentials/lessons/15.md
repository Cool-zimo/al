# 集合：去重与集合运算

> 这一课学完，你能用集合去重、求交集并集，并知道什么时候该用它。

## 一个列表里有重复元素怎么办

```python
votes = ["苹果", "香蕉", "苹果", "橙子", "香蕉", "苹果"]
```

想知道一共有几种水果、投过票的都有谁——用列表写很啰嗦。集合天生就能搞定：**集合（set）里的元素不重复，且顺序不定。**

```python
fruits = {"苹果", "香蕉", "橙子", "苹果", "香蕉"}
print(fruits)      # {'橙子', '苹果', '香蕉'}  顺序不定，重复被去掉
```

集合用**花括号 `{}`**（没有键值对的那种）。注意：空集合不能写 `{}`（那是空字典），得用 `set()`。

## 去重：一行搞定

把列表转成集合再转回来，重复就消失了：

```python
votes = ["苹果", "香蕉", "苹果", "橙子", "香蕉", "苹果"]
unique = list(set(votes))
print(unique)       # 顺序不定，但每个只出现一次
```

`len(set(votes))` 直接给出"有多少种不同的票"。

> 顺序不定是集合的特性。如果你需要"保持原顺序去重"，得换个写法：

```python
seen = set()
result = []
for v in votes:
    if v not in seen:
        seen.add(v)
        result.append(v)
print(result)       # ['苹果', '香蕉', '橙子']  顺序保住了
```

## 增删查

```python
s = {"苹果", "香蕉"}

s.add("橙子")        # 增
print(s)             # {'橙子', '香蕉', '苹果'}

s.remove("香蕉")     # 删，键不存在会 KeyError
print(s)             # {'橙子', '苹果'}

s.discard("西瓜")    # 删，键不存在也不报错（推荐）
print(s)

print("苹果" in s)   # True，成员判断极快
print(len(s))        # 2

s.clear()            # 清空
print(s)             # set()
```

**`remove` 和 `discard` 的区别**：删不到时，`remove` 报错，`discard` 安安静静。不确定在不在就用 `discard`。

## 集合运算：交并差

这是集合最拿得出手的本事——**交集、并集、差集、对称差**，像做数学题一样直接：

| 运算 | 写法 | 含义 | 例子 |
|---|---|---|---|
| 交集 | `a & b` | 两者都有 | 共同好友 |
| 并集 | `a | b` | 合起来去重 | 全部标签 |
| 差集 | `a - b` | a 有 b 没有 | 专属权限 |
| 对称差 | `a ^ b` | 只在一边有 | 非共同 |

```python
frontend = {"Alice", "Bob", "Charlie", "David"}
backend = {"Bob", "David", "Eve", "Frank"}

print(frontend & backend)    # {'Bob', 'David'}         都会
print(frontend | backend)    # {'Alice', 'Bob', ...}    所有人（去重）
print(frontend - backend)    # {'Alice', 'Charlie'}     只会前端
print(backend - frontend)    # {'Eve', 'Frank'}         只会后端
print(frontend ^ backend)    # {'Alice', 'Charlie', 'Eve', 'Frank'}  只在一边的
```

**这套运算在数据比对、权限判断、标签分析里极其实用**，比写 for 循环清爽得多。

## 翻车现场：写错成空字典

```python
s = {}          # 这是空字典，不是空集合
s.add("苹果")   # ❌
```

```
AttributeError: 'dict' object has no attribute 'add'
```

**为什么**：`{}` 在 Python 里是空字典的写法。空集合必须用 `set()`。

**怎么修**：

```python
s = set()               # 正确的空集合
s.add("苹果")
print(s)                # {'苹果'}
```

> 顺带一提，`{1, 2, 3}` 因为有元素，Python 能判断它是集合；只有空的才分不清，所以要 `set()`。

## 子集与超集

判断包含关系：

```python
a = {1, 2, 3}
b = {1, 2, 3, 4, 5}

print(a.issubset(b))    # True   a 是 b 的子集
print(b.issuperset(a))  # True   b 是 a 的超集
print(a <= b)           # True   符号版
print(a < b)            # True   真子集（不能相等）
```

## 什么时候用集合，什么时候用列表

| | 列表 list | 集合 set |
|---|---|---|
| 有序 | 有顺序 | **无顺序** |
| 重复 | 允许 | **自动去重** |
| 查找 | 慢（要遍历） | **快**（哈希） |
| 典型用途 | 要保序、要改 | 去重、交并差、快速判断在不在 |

经验：**要保序或要改 → 列表；要去重或做集合运算 → 集合。**

## 小结

- 集合用 `{}`（空集合必须写 `set()`，别写 `{}`）
- 集合**无序、元素不重复**
- 去重：`list(set(列表))`；保序去重要手动写
- 增：`add()`；删：`remove()` 报错、`discard()` 安静
- 集合运算：`&` 交集、`|` 并集、`-` 差集、`^` 对称差
- 子集判断：`issubset()` 或 `<=`
- 去重/交并差/快速 in 判断用集合，保序用列表
