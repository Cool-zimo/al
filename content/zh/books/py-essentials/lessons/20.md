# 文件读写

> 这一课学完，你能把数据存进文件、从文件读出来，程序从此有了"记忆"。

## 数据不存文件，重启就没了

到上一课为止，程序的数据都存在内存里——关掉程序，一切归零。文件就是程序和外存之间的桥梁。

Python 用内置函数 `open()` 打开文件，核心操作就三个：**打开 → 读写 → 关闭**。

```python
f = open("notes.txt", "w", encoding="utf-8")
f.write("今天学了文件读写\n")
f.write("第二行内容\n")
f.close()
```

`open` 的三个关键参数：

- **文件名**：`"notes.txt"`
- **模式**：`"w"` 写入、`"r"` 读取、`"a"` 追加
- **encoding**：强烈建议显式写 `encoding="utf-8"`，尤其处理中文时

## 三种模式

| 模式 | 含义 | 文件不存在 | 文件存在时 |
|---|---|---|---|
| `r` | 只读（默认） | 报错 | 打开 |
| `w` | 写入 | 新建 | **清空后写入** |
| `a` | 追加 | 新建 | 在末尾接着写 |
| `r+` | 读写 | 报错 | 打开 |

> ⚠️ **`"w"` 模式会直接清空原文件**。用错了数据就没了，所以写文件前先想清楚是要覆盖还是追加。

## with 语句：最推荐的写法

手写 `open` + `close` 有个隐患：如果读写时出错，后面的 `close()` 可能执行不到，文件一直开着不释放。

**`with` 语句自动帮你关**：

```python
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
    f.write("第二行\n")
# 出了这个缩进块，文件自动关闭，无论有没有报错
```

`with` 是 Python 里处理"需要善后"的资源的标准写法。**文件、网络、数据库全都用它。** 记住这个模板，以后不用 `close()`。

## 读文件的三种方式

```python
# 一次读全部
with open("notes.txt", "r", encoding="utf-8") as f:
    content = f.read()
print(content)

# 按行读成列表（每行一个元素，含换行符）
with open("notes.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()
print(lines)      # ['第一行\n', '第二行\n']

# 逐行遍历（最常用，内存友好）
with open("notes.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())   # strip 去掉每行末尾的换行
```

**逐行遍历**处理大文件时最省内存——一次只在内存里放一行，而不是整个文件。

## 追加写日志

```python
with open("app.log", "a", encoding="utf-8") as f:
    f.write("2026-09-27 10:00 用户登录\n")
    f.write("2026-09-27 10:05 用户下单\n")
```

用 `"a"` 模式，每次都在末尾接着写，不会覆盖历史记录。这就是日志文件的标准做法。

## 翻车现场：没写 encoding 读出乱码

```python
# WRONG（在 Windows 上尤其常见）
with open("notes.txt", "r") as f:
    print(f.read())
```

输出一堆乱码 `浣犲ソ` 或者直接 `UnicodeDecodeError`。

**为什么**：Windows 默认编码是 GBK，而你的文件是 UTF-8 存的。没指定 `encoding`，Python 就用系统默认去解码，对不上就乱码或报错。

**怎么修**：读写两端都显式指定 `encoding="utf-8"`。这是跨平台开发的一条铁律。

## 翻车现场：读不存在的文件

```python
with open("不存在的文件.txt", "r") as f:
    print(f.read())
```

```
FileNotFoundError: [Errno 2] No such file or directory
```

**怎么防**：用 `try/except` 兜底（第 21 课正式讲异常处理，这里先看一个最小用法）：

```python
try:
    with open("不存在的文件.txt", "r", encoding="utf-8") as f:
        print(f.read())
except FileNotFoundError:
    print("文件不存在，跳过")
```

## 一个完整例子：通讯录存文件

```python
# 写入通讯录
with open("contacts.txt", "w", encoding="utf-8") as f:
    f.write("张三,13800138000\n")
    f.write("李四,13900139000\n")

# 读取并解析
with open("contacts.txt", "r", encoding="utf-8") as f:
    for line in f:
        name, phone = line.strip().split(",")
        print(f"{name} 的电话是 {phone}")
```

`split(",")` 把一行按逗号切开，`name, phone = ...` 解包给两个变量。这个"写 CSV → 读 CSV"的模式是真实业务里最基础的数据持久化手段。

## 小结

- 打开 → 读写 → 关闭；`open(文件名, 模式, encoding="utf-8")`
- 三种模式：`r` 读、`w` 写（会清空）、`a` 追加
- **`"w"` 会清空原文件**，用前想清楚
- **用 `with` 语句自动关闭文件**，这是标准写法
- 读三法：`read()` 全部、`readlines()` 成列表、逐行遍历（最省内存）
- 读写都显式指定 `encoding="utf-8"`，跨平台不出乱码
- 不存在的文件会 `FileNotFoundError`，可用 try/except 兜底
