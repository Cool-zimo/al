# 四则运算与字符串拼接

> 这一课学完，你能用 Python 当计算器，并搞清"加号"在数字和字符串身上是两种完全不同的活。

## 程序最擅长的事就是算

计算器能干的事，Python 一行就搞定。先看六个运算符：

| 运算符 | 含义 | 例子 | 结果 |
|---|---|---|---|
| `+` | 加 | `3 + 5` | `8` |
| `-` | 减 | `10 - 3` | `7` |
| `*` | 乘 | `4 * 6` | `24` |
| `/` | 除 | `10 / 4` | `2.5` |
| `//` | 整除 | `10 // 4` | `2` |
| `%` | 取余 | `10 % 4` | `2` |
| `**` | 幂 | `2 ** 10` | `1024` |

```python
print(3 + 5)        # 8
print(10 / 4)       # 2.5   普通除法，结果永远是 float
print(10 // 4)      # 2     整除，砍掉小数
print(10 % 4)       # 2     余数
print(2 ** 10)      # 1024  2 的 10 次方
print(9 ** 0.5)     # 3.0   开平方
```

> 💡 日常算钱、算时间，多想想 `//` 和 `%`。比如 `137 分钟 = 2 小时 17 分钟`：`137 // 60` 得小时，`137 % 60` 得分钟。

## 运算顺序：和数学一样

Python 遵守数学里的运算优先级：**先乘除后加减，幂运算最高，括号最优先**。

```python
print(2 + 3 * 4)      # 14，不是 20
print((2 + 3) * 4)    # 20，括号改变顺序
print(2 ** 3 ** 2)    # 512，幂运算从右往左：2 ** (3**2) = 2**9
```

记不住优先级？**加括号**。括号比记忆力可靠。

## 翻车现场：`-2 ** 2` 不是 4

```python
print(-2 ** 2)
```

很多人以为是 4。实际输出是 `-4`。

**为什么**：幂运算 `**` 的优先级**高于**负号。Python 把它理解成 `-(2 ** 2)`，先算 `2**2=4`，再取负。

```python
print((-2) ** 2)    # 4，加括号才是"负二的平方"
print(-(2 ** 2))    # -4，这才是上面那句的原意
```

**凡是带负号的幂运算，一律加括号。** 这是 Python 和数学书写习惯最容易打架的地方。

## `+` 是两面人

同一个加号，作用在**数字**上和**字符串**上，干的是两码事：

```python
print(3 + 5)        # 8       数字相加
print("3" + "5")    # "35"    字符串拼接
```

**数字相加是算数，字符串相加是拼接。** 把两个字符串"粘"在一起，就是拼接：

```python
first = "张"
last = "三"
print(first + last)     # 张三
```

而 `*` 对字符串是"重复"：

```python
print("ha" * 3)         # hahaha
print("-" * 20)         # --------------------
```

那个 `print("-" * 20)` 在做分隔线时非常好用。

## 翻车现场：数字和字符串不能相加

```python
age = 18
print("我今年" + age + "岁")
```

```
TypeError: can only concatenate str (not "int") to str
```

**为什么**：`+` 要求两边类型一致。左边是字符串 `"我今年"`，右边是整数 `18`，Python 拒绝猜。

**两种修法**：

```python
# 法一：把数字转成字符串
print("我今年" + str(age) + "岁")

# 法二（推荐）：用逗号，让 print 自己拼接
print("我今年", age, "岁")

# 法三（最爽）：f-string，在字符串前加 f，变量用 {} 包起来
print(f"我今年{age}岁")
```

第三种 `f-string` 是最常用的写法，变量嵌进字符串里，读起来像一句话。下一课讲判断时会大量用到。

> 💡 三个工具各有场合：纯拼接用 `+`，混排用逗号，要在字符串里嵌变量用 f-string。

## 常用内置函数

| 函数 | 作用 | 例子 | 结果 |
|---|---|---|---|
| `round(x, n)` | 保留 n 位小数 | `round(3.14159, 2)` | `3.14` |
| `abs(x)` | 绝对值 | `abs(-7)` | `7` |
| `min(a,b,c)` | 最小值 | `min(3, 1, 5)` | `1` |
| `max(a,b,c)` | 最大值 | `max(3, 1, 5)` | `5` |
| `sum(list)` | 求和 | `sum([1,2,3])` | `6` |

```python
score = 87.586
print(round(score, 1))        # 87.6
print(abs(-20) + min(3, 9))   # 23
```

## 小结

- 六个运算符：`+ - * / // % **`，`/` 永远返回 float
- 优先级：幂最高，乘除次之，加减最低，括号优先
- **`-2 ** 2` 是 `-4`**，幂运算优先于负号，要加括号
- `+` 对数字是相加，对字符串是拼接，`*` 对字符串是重复
- 数字和字符串混排：用逗号、`str()` 转换，或 f-string
- `round / abs / min / max / sum` 是天天用的内置函数
