# if / elif / else：让程序会判断

> 这一课学完，你能写出"如果……否则……"的逻辑，让程序根据输入走不同的路。

## 为什么需要判断

到上一课为止，你的程序都是一条直线：从上往下，一句不落。

但现实不是这样。外卖 App 要看你有没有登录；考试程序要看分数定等级。**程序必须会"看情况办事"**，这靠 `if`。

```python
age = int(input("你多大了？"))

if age >= 18:
    print("可以注册")
else:
    print("还不行，再等等")
```

`age >= 18` 这部分叫**条件表达式**，算出来的结果是 `True` 或 `False`。是 `True` 就走 `if` 下面的代码，否则走 `else`。

## 语法骨架

```python
if 条件:
    条件成立时执行
else:
    条件不成立时执行
```

三个地方最容易写错：

1. **`if` 后面必须有冒号 `:`**——中文冒号不行，少了必报错
2. **下一行必须缩进**（4 个空格）——Python 靠缩进来认"这是 if 内部"
3. **`else` 后面也要冒号**

## 缩进：Python 的身份证

很多语言用大括号 `{}` 划分代码块，Python 用**缩进**。同一级别的代码缩进必须一致：

```python
age = 20

if age >= 18:
    print("成年人")
    print("可以投票")      # 这两行缩进相同，都属于 if 内部
print("这句话永远会执行")   # 没缩进，不属于 if
```

```
成年人
可以投票
这句话永远会执行
```

缩进是 Python 最鲜明的特征。**统一用 4 个空格**，别用 Tab，别混用。

## 多分支：elif

三个及以上分支用 `elif`（else if 的缩写）：

```python
score = int(input("分数："))

if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

`elif` 从上往下依次判断，**一旦命中一个，剩下的就不看了**。

> 顺序很重要。如果把 `score >= 60` 放第一个，95 分也会被判成"及格"——因为它先满足了 60 的条件就直接走了。

## 比较运算符

| 运算符 | 含义 | 例子 |
|---|---|---|
| `==` | 等于 | `age == 18` |
| `!=` | 不等于 | `age != 18` |
| `>` `>=` | 大于 / 大于等于 | `score > 60` |
| `<` `<=` | 小于 / 小于等于 | `score <= 100` |

**特别注意 `==` 和 `=` 的区别**：一个等号是"赋值"（放进去），两个等号是"比较"（问相等吗）。

```python
age = 18       # 赋值
if age == 18:  # 比较
    print("刚好成年")
```

## 翻车现场：把赋值写成比较

```python
# WRONG
if age = 18:
    print("成年")
```

```
SyntaxError: invalid syntax
```

**为什么**：`if` 后面只能放**表达式**（能算出真假的东西），而 `age = 18` 是赋值语句，不是真假判断。Python 直接拒绝。

**怎么修**：改成 `age == 18`。

> 这个坑在 C/Java 转过来的人身上尤其高发，因为它们的语法允许这种写法。Python 干脆让它报错，逼你分清赋值和比较。

## 更实用的写法：三元表达式

只在一个地方用 if-else、逻辑又很短时，可以写成一行：

```python
# 完整写法
if age >= 18:
    status = "成年"
else:
    status = "未成年"

# 一行版（三元表达式）
status = "成年" if age >= 18 else "未成年"
```

读起来是"前面 if 成立就取前面，否则取后面"。适合简单赋值，别嵌套太多层，否则可读性会崩。

## 一个完整的判断程序

```python
import random
secret = random.randint(1, 100)
guess = int(input("猜一个 1~100 的数："))

if guess == secret:
    print("猜中了！")
elif guess < secret:
    print("太小了，再大点")
else:
    print("太大了，再小点")
```

`random.randint(1, 100)` 会生成一个 1 到 100 之间的随机整数。这个小游戏的核心逻辑就这几行。

## 小结

- `if / elif / else` 让程序分岔，根据条件走不同路
- 语法要点：`if` 后跟条件+冒号，下一行**缩进 4 空格**
- `==` 是比较，`=` 是赋值，千万别混
- 多个分支用 `elif`，从上往下命中即停
- 顺序决定结果：范围判断要把更严格的放前面
- 简短的 if-else 可写成一行三元：`a if 条件 else b`
