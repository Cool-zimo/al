# 实战：一个能用的通讯录

> 这一课学完，你会把前面 23 课的知识拼成一个能增删改查、能存文件的通讯录程序。

## 这次要把所有东西串起来

单独看每个知识点都很小，但**真实程序就是它们的组合**。这个通讯录会用到：

- 字典存联系人、列表存所有人
- 函数封装每个操作
- 循环 + 条件做菜单
- 文件读写做持久化
- 异常兜底防崩溃

## 数据结构设计

一个联系人用字典存，所有人的列表就是"通讯录"：

```python
# 单个联系人
contact = {"name": "张三", "phone": "13800138000", "email": "zhangsan@example.com"}

# 通讯录
contacts = [
    {"name": "张三", "phone": "13800138000", "email": "zhangsan@example.com"},
    {"name": "李四", "phone": "13900139000", "email": "lisi@example.com"},
]
```

**为什么用字典列表而不是"名字做键的字典"？** 因为一个人可能有重名，且我们要遍历、要排序、要按位置删——列表更自然。

## 第一步：增——添加联系人

```python
def add_contact(contacts):
    name = input("姓名：").strip()
    phone = input("电话：").strip()
    email = input("邮箱：").strip()

    contacts.append({
        "name": name,
        "phone": phone,
        "email": email
    })
    print("已添加：", name)
```

`strip()` 清掉首尾空白，这是处理用户输入的标配。

## 第二步：查——列表和搜索

```python
def list_contacts(contacts):
    if not contacts:
        print("通讯录是空的")
        return

    print(f"{'序号':<4} {'姓名':<8} {'电话':<15} {'邮箱'}")
    print("-" * 45)
    for i, c in enumerate(contacts, start=1):
        print(f"{i:<4} {c['name']:<8} {c['phone']:<15} {c['email']}")
```

`enumerate(contacts, start=1)` 从 1 开始编号，比自己维护 `i += 1` 清爽。`f"{i:<4}"` 是左对齐占位，让列对齐。

**按名字搜索**：

```python
def search_contact(contacts):
    keyword = input("搜索关键字：").strip().lower()
    results = []

    for c in contacts:
        if keyword in c["name"].lower() or keyword in c["email"].lower():
            results.append(c)

    if not results:
        print("没找到")
        return

    print(f"找到 {len(results)} 条：")
    for c in results:
        print(f"  {c['name']}  {c['phone']}  {c['email']}")
```

`keyword in c["name"].lower()` 实现"不区分大小写的模糊匹配"。

## 第三步：改与删

```python
def delete_contact(contacts):
    list_contacts(contacts)
    if not contacts:
        return

    try:
        idx = int(input("要删除第几个（输入序号）：")) - 1
        if 0 <= idx < len(contacts):
            removed = contacts.pop(idx)
            print("已删除：", removed["name"])
        else:
            print("序号超出范围")
    except ValueError:
        print("请输入数字")
```

**这里用了三个知识点**：`try/except` 兜底非法输入、列表下标删除、`if` 判断边界。这就是"学完就忘"和"学会组合"的区别。

```python
def update_contact(contacts):
    list_contacts(contacts)
    if not contacts:
        return

    try:
        idx = int(input("要修改第几个：")) - 1
        if not (0 <= idx < len(contacts)):
            print("序号超出范围")
            return
    except ValueError:
        print("请输入数字")
        return

    c = contacts[idx]
    print(f"当前：{c['name']}  {c['phone']}  {c['email']}")

    name = input(f"新姓名（留空保持「{c['name']}」）：").strip()
    phone = input(f"新电话（留空保持「{c['phone']}」）：").strip()
    email = input(f"新邮箱（留空保持「{c['email']}」）：").strip()

    if name:
        c["name"] = name
    if phone:
        c["phone"] = phone
    if email:
        c["email"] = email

    print("已更新")
```

"留空就保持不变"这个交互细节，用 `if 值:` 判断非空就够了。

## 第四步：存文件与读文件

存成 JSON 格式——一种通用的文本格式，Python 内置 `json` 模块支持读写：

```python
import json

def save_contacts(contacts, filename="contacts.json"):
    with open(filename, "w", encoding="utf-8") as f:
        json.dump(contacts, f, ensure_ascii=False, indent=2)
    print("已保存到", filename)

def load_contacts(filename="contacts.json"):
    try:
        with open(filename, "r", encoding="utf-8") as f:
            return json.load(f)
    except FileNotFoundError:
        return []      # 文件不存在就返回空列表，当新通讯录用
```

`json.dump(..., ensure_ascii=False)` 让中文正常显示，不加的话中文会变成 `\u5f20\u4e09` 这种转义。`indent=2` 让文件带缩进、可读。

## 第五步：菜单串起来

```python
def show_menu():
    print("\n===== 通讯录 =====")
    print("1. 添加联系人")
    print("2. 查看所有")
    print("3. 搜索")
    print("4. 修改")
    print("5. 删除")
    print("6. 保存并退出")
    return input("请选择：")

def main():
    contacts = load_contacts()

    while True:
        choice = show_menu()

        if choice == "1":
            add_contact(contacts)
        elif choice == "2":
            list_contacts(contacts)
        elif choice == "3":
            search_contact(contacts)
        elif choice == "4":
            update_contact(contacts)
        elif choice == "5":
            delete_contact(contacts)
        elif choice == "6":
            save_contacts(contacts)
            print("再见")
            break
        else:
            print("没有这个选项")

main()
```

**`while True` + `if/elif` + `break`**，这就是命令行程序的标准骨架。第 6 个选项里先 `save` 再 `break`，保证退出前存盘。

## 翻车现场：菜单输入不转 int 的后果

```python
choice = input("请选择：")   # "2"
if choice == 2:              # 字符串 "2" 不等于整数 2
    ...
```

字符串 `"2"` 和整数 `2` 不相等，`if` 永远不会命中。

**修法二选一**：

```python
# 法一：和字符串比（推荐，input 本来就是字符串）
if choice == "2":

# 法二：转成 int（但要 try 兜底，因为用户可能输入字母）
try:
    num = int(choice)
    if num == 2:
        ...
except ValueError:
    print("请输入数字")
```

菜单比较**和字符串比最简单**，转 int 反而多一层风险。

操作完后选 6，退出前自动存盘。下次运行 `load_contacts()` 会把数据读回来。**这就是一个真正"有记忆"的程序。**

## 小结

- 数据结构：联系人用字典，通讯录用列表装字典
- 五个操作各写一个函数：增删改查 + 存文件
- 搜索用 `keyword in str.lower()` 做模糊不区分大小写匹配
- 存文件用 `json.dump`（ensure_ascii=False 保中文），读用 `json.load`
- 文件不存在时 `return []`，当新通讯录用
- 菜单用 `while True` + `if/elif` + `break`，退出前先 save
- 菜单选项和字符串比，别和整数比
