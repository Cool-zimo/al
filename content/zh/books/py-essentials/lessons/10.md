# break / continue 与嵌套循环

> 这一课学完，你能在一个循环里"跳出去"或"跳过一轮"，并把循环套循环解决二维问题。

## break 和 continue 的精确含义

上一课提过，这里把细节补齐。

**`break`**：立刻跳出**整个**循环，后面不管还有几轮都不跑了。

```python
for i in range(10):
    if i == 3:
        break
    print(i)
```

```
0
1
2
```

**`continue`**：跳过本轮剩下的代码，直接进入**下一轮**。

```python
for i in range(5):
    if i == 2:
        continue
    print(i)
```

```
0
1
3
4
```

2 被跳过了。

> 区别一句话记牢：**break 是"我不干了"，continue 是"这轮不算，下一轮继续"。**

## break 的常见用法：找到就停

在列表里找一个数，找到就报告位置：

```python
nums = [3, 7, 1, 9, 4]
target = 9
found = False

for i in range(len(nums)):
    if nums[i] == target:
        print("找到了，位置在", i)
        found = True
        break

if not found:
    print("没找到")
```

找到 9 在第 3 个位置（下标 3），命中 `break` 立刻跳出，不会白跑剩下的轮次。**搜索场景用 break 是标配。**

## 翻车现场：continue 放错位置

```python
# WRONG：想跳过偶数
i = 0
while i < 5:
    if i % 2 == 0:
        continue
    print(i)
    i += 1
```

你以为会打印 1 和 3。实际跑起来直接卡死——**死循环**。

**为什么**：`i` 是 0 时遇到 `continue`，跳过了 `i += 1`。`i` 永远是 0，条件永远成立。

**怎么修**：把更新语句放到 `continue` 前面：

```python
i = 0
while i < 5:
    i += 1              # 先更新
    if i % 2 == 0:
        continue
    print(i)
```

> 顺带一提，`continue` 在 `for` 里没这个坑——`for` 的变量更新是自动的。这坑是 `while` 专属。

## 嵌套循环：循环套循环

两个循环一层套一层，用来处理**二维**数据——最典型的是九九乘法表：

```python
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}×{i}={i*j}", end="\t")
    print()     # 内层跑完换一行
```

外层 `i` 控制行（从 1 到 9），内层 `j` 控制每行打印几项。注意内层是 `range(1, i+1)`——第 i 行就打印 i 项。`end="\t"` 用制表符对齐，`print()` 不带参数就是只换行。

## 嵌套里的 break 只跳一层

`break` 只跳出**它所在的那一层**循环：

```python
for i in range(3):
    for j in range(3):
        if j == 1:
            break
        print(i, j)
```

```
0 0
1 0
2 0
```

内层 `j` 到 1 就 break，但外层 `i` 还在继续。这是很多新手以为"会全停"的误解点。

**想从深层一次跳出多层**，常见办法是设个标记：

```python
found = False
for i in range(3):
    for j in range(3):
        if matrix[i][j] == target:
            found = True
            break
    if found:
        break
```

两层都检查 `found`，外层命中就跟着停。

## 一个实用的例子：打印棋盘

```python
for row in range(8):
    for col in range(8):
        if (row + col) % 2 == 0:
            print("■", end="")
        else:
            print("□", end="")
    print()
```

`(row + col) % 2` 决定黑白交替。内外层各控制一个维度，是嵌套循环最典型的分工。

## 小结

- `break`：跳出整个循环；`continue`：跳过本轮进下一轮
- `break` 是"我不干了"，`continue` 是"这轮不算"
- 搜索场景找到就 break，避免白跑
- `while` 里用 `continue` 必须保证更新语句在它之前，否则死循环
- 嵌套循环处理二维数据，外层管行、内层管列
- 嵌套里 `break` 只跳一层，要全停得用标记变量
- `end="\t"` 用制表符对齐输出
