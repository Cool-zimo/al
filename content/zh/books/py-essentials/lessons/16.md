# 函数：把代码打包

> 这一课学完，你能用 `def` 定义自己的函数，知道为什么要写函数。

## 为什么要有函数

假设你写了三段几乎一样的代码：

```python
# 算张三的 BMI
weight1 = 70
height1 = 1.75
bmi1 = weight1 / (height1 ** 2)
print("张三的 BMI：", round(bmi1, 1))

# 算李四的 BMI
weight2 = 85
height2 = 1.80
bmi2 = weight2 / (height2 ** 2)
print("李四的 BMI：", round(bmi2, 1))

# 算王五的 BMI
weight3 = 60
height3 = 1.65
bmi3 = weight3 / (height3 ** 2)
print("王五的 BMI：", round(bmi3, 1))
```

**三段几乎一模一样，只有数据不同。** 这正是函数要解决的问题：把"动作"定义一次，用不同的数据反复调用。

```python
def calc_bmi(weight, height):
    bmi = weight / (height ** 2)
    return round(bmi, 1)

print("张三的 BMI：", calc_bmi(70, 1.75))
print("李四的 BMI：", calc_bmi(85, 1.80))
print("王五的 BMI：", calc_bmi(60, 1.65))
```

同样的动作只写一次，数据换成参数传进去。**函数 = 给一段代码起名字，方便反复调用。**

## 定义与调用

```python
def 函数名(参数1, 参数2):
    # 缩进块：函数体
    return 结果
```

- `def` 是定义的关键字
- 函数名后必须带括号和冒号
- 参数写在括号里（可以没有）
- `return` 把结果"交回来"

**调用时就是写函数名加括号**：

```python
def greet(name):
    return f"你好，{name}"

msg = greet("张三")
print(msg)       # 你好，张三
```

## return 的两个作用

`return` 既**返回结果**，又**结束函数**：

```python
def check_age(age):
    if age >= 18:
        return "成年"
    return "未成年"      # 上面命中 return 后这句不会执行

print(check_age(20))     # 成年
print(check_age(15))     # 未成年
```

`return` 执行的那一刻，函数立刻结束。所以**`if` 两个分支各写一个 `return`，不用 `else`** 是很常见的写法。

### 没有 return 会怎样

```python
def say_hi(name):
    print("你好，", name)

result = say_hi("张三")
print(result)        # None
```

没写 `return`，函数默认返回 `None`。这类函数靠"做动作"（打印、写文件）产生效果，不产出值。

## 翻车现场：参数顺序错了

```python
def calc_bmi(weight, height):
    return round(weight / (height ** 2), 1)

print(calc_bmi(1.75, 70))     # 这回把身高和体重写反了
```

输出 `0.0`——因为代码按位置把 1.75 当体重、70 当身高算了。不会报错，但结果错得离谱，**这种 bug 最难找**。

**怎么防**：调用时指定参数名（关键字参数）：

```python
print(calc_bmi(weight=70, height=1.75))   # 明确告诉函数谁是谁
```

参数多了以后，用关键字调用能彻底避免这种错误。第 17 课会细讲。

## 多个返回值

Python 函数可以"返回多个值"——本质是返回一个元组，再自动解包：

```python
def stats(numbers):
    return min(numbers), max(numbers), sum(numbers) / len(numbers)

low, high, avg = stats([80, 90, 75, 88])
print(low, high, avg)      # 75 90 83.25
```

`low, high, avg = ...` 就是解包，和元组的打包/解包是同一套机制。

## 函数也是变量

Python 里函数是一等对象，可以赋值、可以传参：

```python
def double(x):
    return x * 2

f = double          # 函数也能贴标签
print(f(5))         # 10
```

现在先认识就行，等你学到高阶用法（比如 `map`、`sorted` 的 `key`）会再见面。

## 小结

- **函数 = 把动作定义一次，用不同数据反复调用**，消除重复代码
- 定义：`def 函数名(参数):`，参数可有可无
- `return` 返回结果并立即结束函数；多个返回值本质是返回元组再解包
- 没写 `return` 的函数默认返回 `None`
- 调用时**用关键字参数 `name=value`** 能避免参数顺序错乱
- `if-return` 不用 else 的写法很常见，记住 return 就结束
