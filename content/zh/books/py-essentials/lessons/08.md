# while 循环：条件满足就一直做

> 这一课学完，你能写出"只要条件成立就反复执行"的循环，并知道死循环怎么破。

## 重复的事交给循环

想打印"你好" 10 遍，没人会写 10 行 print。循环就是干这个的：

```python
count = 0
while count < 10:
    print("你好")
    count = count + 1
```

`while` 后面的条件为真时，就反复执行缩进块。**每轮结束回到条件再判断一次**，条件变假才跳出。

## 三要素

写 `while` 必须想清楚三件事，缺一个就可能死循环：

1. **循环变量初始值**：`count = 0`
2. **循环条件**：`count < 10`
3. **循环变量更新**：`count = count + 1`

三者配合，保证循环**有起点、有边界、会收敛**。

> 常用自增写法：`count += 1`。`+=` 是"加完再存回自己"的简写，`count = count + 1` 的语法糖。

## 猜数字游戏

把前面学的串起来，写一个能真正玩的小游戏：

```python
import random

secret = random.randint(1, 100)
guess = 0

while guess != secret:
    guess = int(input("猜一个数："))
    if guess < secret:
        print("太小了")
    elif guess > secret:
        print("太大了")
    else:
        print("猜中了！")
```

**循环条件 `guess != secret` 是"没猜中就不停"**。猜中了条件变假，循环结束。这就是 while 的典型用法：**不知道要跑多少轮，只知道什么时候停**。

## 翻车现场：忘记更新循环变量

```python
# WRONG
count = 0
while count < 5:
    print("还没到5")
    # 忘记 count += 1
```

**为什么**：条件永远是 `0 < 5`，永远为真。循环一轮接一轮地跑，永远不会停。

**怎么破**：
- **Ctrl + C** 强行中断（通用办法）
- VSCode 的运行面板上有个红色方块 ⏹，点它停止
- 根本解法：补上 `count += 1`

**死循环的调试技巧**：在循环里打印循环变量，看它是不是按预期变化：

```python
while count < 5:
    print("count =", count)   # 加上这行，立刻看到问题
    # count += 1
```

## 主动跳出：break

`break` 是"立刻跳出整个循环"，不管条件还成不成立：

```python
while True:                 # 故意写成死循环
    cmd = input("输入命令（quit 退出）：")
    if cmd == "quit":
        break               # 命中就跳出
    print("你输入了：", cmd)
print("再见")
```

`while True:` 是死循环的标准起手式，配合 `break` 用。这种模式在"持续等用户操作"的程序里极其常见，比如聊天机器人、命令行工具。

## 跳过本轮：continue

`continue` 是"跳过本轮剩下的，直接进入下一轮"：

```python
count = 0
while count < 5:
    count += 1
    if count == 3:
        continue            # 跳过 3，不打印
    print(count)
```

```
1
2
4
5
```

注意 `count += 1` 放在 `continue` 前面——如果放后面，遇到 3 时变量没更新，又死循环了。

## 小结

- `while 条件:` 条件为真就反复执行，靠缩进划定范围
- 三要素：**初值、条件、更新**，缺一就可能死循环
- `count += 1` 是 `count = count + 1` 的简写
- 死循环按 **Ctrl+C** 中断；排查办法是在循环里打印循环变量
- `break` 跳出整个循环；`continue` 跳过本轮进下一轮
- `while True:` + `break` 是"持续运行直到某条件"的常用套路
