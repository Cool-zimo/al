# 收官：下一步学什么

> 这一课不是结束，是给你指路——Python 学完基础，有四条路可以走，选一条开始往下挖。

## 你已经拿到了什么

25 课，150 分钟 × 25 天。你已经会：

- 写变量、用数据类型、做运算和字符串处理
- 用 `if`、`for`、`while` 控制流程
- 用列表、字典、元组、集合装数据
- 用函数把代码打包复用
- 用文件读写、模块导入、异常处理做出"能跑、能存、能兜底"的程序

这已经是一个**能写工具脚本的入门程序员**了。但 Python 真正厉害的地方在于它的生态——下面四条路，每条都能让你把基础变成生产力。

## 路线一：数据分析

**关键词**：`pandas`、`numpy`、`matplotlib`、Jupyter

如果你的目标是"用数据说话"——分析销售、做报表、画图表，这是最直接的路。

```python
import pandas as pd

df = pd.read_csv("sales.csv")          # 一行读入表格
print(df.head())                       # 看前几行
print(df.groupby("地区")["销量"].sum()) # 按地区汇总销量

df["销量"].plot(kind="bar")            # 一行出图
```

学什么：**pandas 数据框**（Excel 的 Python 版）、**numpy 数值计算**、**matplotlib / seaborn 画图**。建议先读《利用 Python 进行数据分析》，边读边在自己的数据上练。

适合人群：运营、市场、财务、科研、任何"每天和表格打交道"的人。

## 路线二：算法与刷题

**关键词**：LeetCode、数据结构、复杂度

如果你想进大厂、做后端、深入理解计算机，这条路是绕不开的。

```python
# 经典：两数之和
def two_sum(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        if target - n in seen:
            return [seen[target - n], i]
        seen[n] = i
```

学什么：**时间复杂度/空间复杂度**、链表、栈、队列、树、图、动态规划、二分、滑动窗口。LeetCode 从"简单"难度开始，每天一题，比看十本书管用。

适合人群：想做后端、架构、基础架构、算法工程师的人。

## 路线三：桌面应用 / 自动化

**关键词**：`tkinter`、`PyQt`、`selenium`、`pyautogui`

想做个能双击运行的窗口程序，或者让电脑替你重复点鼠标、填表格——走这条路。

```python
import tkinter as tk

root = tk.Tk()
root.title("我的第一个窗口")
label = tk.Label(root, text="你好，世界")
label.pack()
root.mainloop()
```

学什么：`tkinter`（Python 自带，入门最快）或 `PyQt`（更专业）；自动化方向看 `selenium`（浏览器）、`pyautogui`（键鼠）、`openpyxl`（Excel）。

适合人群：想给自己和同事做小工具的人、测试、运维、行政。

## 路线四：工程化与 Web

**关键词**：`flask`、`django`、`pytest`、Git、Linux、Docker

如果你想做网站、做后端服务、把代码部署到线上，走这条路。

```python
from flask import Flask
app = Flask(__name__)

@app.route("/")
def hello():
    return "你好，世界"

app.run()
```

学什么：先 `flask`（轻量，能跑起来就有成就感），再 `django`（全栈框架）；配套学 **Git**（版本管理）、**Linux 常用命令**、**pytest**（测试）、**Docker**（部署）。

适合人群：想做产品、做服务、进互联网公司的人。

## 下一步的通用建议

无论选哪条路，这几件事都值得现在就做：

1. **养成用 Git 的习惯**。写代码第一天就用 Git，哪怕只是本地提交。比"代码丢了哭一场"强一万倍。
2. **读别人的代码**。去 GitHub 上找你感兴趣方向的开源项目，从读代码开始，比硬啃文档快。
3. **写一个自己真要用的东西**。通讯录是你第一个，下一个做个记账本、待办清单、自动填表脚本——**真要用的项目学得最快**。
4. **接受"看不懂"**。每个方向都有一段"明明每个字都认识但连起来就不懂"的时期，这是从入门到进阶的必经之路，熬过去就通了。

## 这 25 课之外你还该知道什么

| 主题 | 一句话说明 | 什么时候学 |
|---|---|---|
| 类与面向对象 | 把数据和行为打包成"对象" | 想写大项目时 |
| 装饰器 | 不改原函数给它加功能 | 读框架源码时 |
| 生成器 `yield` | 惰性产生数据，省内存 | 处理大数据时 |
| 异步 `async/await` | 并发处理 IO 密集型任务 | 写网络服务时 |
| 类型注解 | 给变量标类型，让编辑器帮你查错 | 写工程代码时 |
| 虚拟环境 `venv` | 给每个项目隔离依赖 | 装第二个第三方包时 |

这些**不用现在学**，等你撞到具体问题时再回头查，效率最高。

## 小结

- 数据分析：`pandas` + `numpy` + `matplotlib`，适合处理表格和图表
- 算法刷题：LeetCode + 数据结构与复杂度，适合后端和进阶
- 桌面/自动化：`tkinter`/`PyQt` + `selenium`，适合做工具和办公自动化
- Web 工程：`flask`/`django` + Git + Linux + Docker，适合做网站和服务
- 通用习惯：用 Git、读开源、写自己要用的东西、接受看不懂的阶段
- 类、装饰器、生成器、异步、类型注解、虚拟环境——撞到需求再学

  def parse_csv(csv_text):

      return []
