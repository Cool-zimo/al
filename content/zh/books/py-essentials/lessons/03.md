# 让程序有输出有输入

> 这一课学完，你能让程序"问一句话、等用户回答、再回应"——程序终于能和人对上话了。

## 只输出不输入的程序是广播

上一课的程序像广播：程序说，你听。它没有等你回应。

真实程序要互动。比如：你打开银行 App，它问"多少金额？"，你输入，它算。这靠两个函数配合：

- **`print()`**：程序往外说
- **`input()`**：程序停下，等你往里输

```python
name = input("你叫什么名字？")
print("你好，", name)
```

运行后，程序会先打印"你叫什么名字？"，然后**停住等你敲键盘**。你输入完按回车，它才往下走，打印"你好，XXX"。

## input 永远是字符串

这是本课最核心的一条，值得单独强调：**`input()` 返回的东西，永远是字符串（str）**，哪怕你输入的是数字。

```python
age = input("你多大了？")
print(type(age))
```

你输入 `18`，`type` 出来的结果是 `str`——字符串 `"18"`，不是数字 `18`。

**差别在哪？** 字符串能拼接，不能跟数字直接算：

```python
age = input("你多大了？")   # 假设输入 18
next_year = age + 1         # ❌ 报错
```

## 翻车现场：拿 input 的结果直接算

```python
age = input("你多大了？")
print("明年你就", age + 1, "岁了")
```

```
请输入年龄：18
TypeError: can only concatenate str (not "int") to str
```

**为什么**：`age` 是字符串 `"18"`，`1` 是整数。Python 不知道你想"把文字18和文字1拼起来"，还是"把数字18加1"，于是拒绝猜。

**怎么修**：用 `int()` 把字符串转成整数，用 `float()` 转成小数：

```python
age = input("你多大了？")
age = int(age)              # 字符串 "18" → 数字 18
print("明年你就", age + 1, "岁了")
```

一行写完更常见：

```python
age = int(input("你多大了？"))
print("明年你就", age + 1, "岁了")
```

> 转换是按**从外到内**的顺序算的：`input()` 先执行，拿到字符串，再交给 `int()` 转数字。

## print 的三个小技巧

**多个值用逗号隔开**，Python 自动加空格：

```python
print("我叫", "张三", "今年", 18, "岁")
# 我叫 张三 今年 18 岁
```

**`sep` 自定义分隔符**——逗号之间的连接物默认是空格，可以换：

```python
print("2026", "09", "27", sep="-")
# 2026-09-27

print("a", "b", "c", sep="")   # 空字符串 = 无缝拼接
# abc
```

**`end` 自定义结尾符**——print 默认打印完换行，改成别的就不换：

```python
print("加载中", end="")
print("完成")
# 加载中完成    （同一行）

print("a", end=" ")
print("b", end=" ")
print("c")
# a b c
```

`end=""` 在做进度提示、同一行累加输出时特别有用。

## 一个能对话的小程序

把 print 和 input 串起来，做一个 BMI 计算器：

```python
name = input("你的名字：")
height = float(input("身高（米）："))
weight = float(input("体重（公斤）："))

bmi = weight / (height ** 2)
print(name, "的 BMI 是", round(bmi, 1))
```

注意 `height` 用 `float()` 转——身高可能是 1.75 米，带小数，用 `int` 会丢精度。`round(bmi, 1)` 是保留一位小数，不然会打出一长串。

## 转义字符：在字符串里放特殊符号

想在一个字符串里换行、打引号、打反斜杠本身，要用**转义字符**——反斜杠 `\` 开头的一串：

```python
print("第一行\n第二行")        # \n 换行
print("他说：\"你好\"")        # \" 打出英文双引号
print("路径：C:\\Users")       # \\ 打出一个反斜杠
print("tab\there")             # \t 制表符（一个 Tab）
```

```
第一行
第二行
他说："你好"
路径：C:\Users
tab	here
```

> 不想记这些转义规则？字符串前面加个 `r`，变成"原始字符串"，反斜杠不当特殊字符：

```python
print(r"C:\Users\name")    # 原样输出，不用双写反斜杠
```

## 小结

- `print()` 往外说，`input()` 停下来等输入
- **input 永远返回字符串**，要算数就得 `int()` 或 `float()` 转一下
- 转换顺序：从外到内，`int(input())` 先取输入再转数字
- `print` 的 `sep` 改分隔符、`end` 改结尾符（默认空格、换行）
- `\n` 换行、`\"` 引号、`\\` 反斜杠；不想转义就在前面加 `r`
