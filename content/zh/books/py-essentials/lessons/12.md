# 列表常用操作

> 这一课学完，你能对列表排序、拼接、统计，并避开"边遍历边改"这个新手最易踩的坑。

## 几个天天用的操作

上一课讲了增删改查，这一课补齐最常用的一批工具。

| 操作 | 写法 | 说明 |
|---|---|---|
| 排序（原地） | `list.sort()` | 直接改原列表，返回 None |
| 排序（不改原） | `sorted(list)` | 返回新列表，原列表不动 |
| 反转（原地） | `list.reverse()` | 改原列表 |
| 计数 | `list.count(值)` | 某元素出现几次 |
| 查位置 | `list.index(值)` | 某元素第一次出现的下标 |
| 拼接 | `list1 + list2` | 返回新列表 |
| 重复 | `list * n` | 重复 n 次 |
| 清空 | `list.clear()` | 等价于 `list[:] = []` |

```python
nums = [3, 1, 4, 1, 5, 9, 2]
nums.sort()
print(nums)                 # [1, 1, 2, 3, 4, 5, 9]

print(sorted([3, 1, 2]))    # [1, 2, 3]，原列表不变
print([1, 2] + [3, 4])     # [1, 2, 3, 4]
print([0] * 5)              # [0, 0, 0, 0, 0]
print([1, 2, 2, 3].count(2))  # 2
```

> 💡 `sort()` vs `sorted()`：要**改原列表**用 `sort()`；要**保留原列表**拿一个新排好的，用 `sorted()`。

## 翻车现场：以为 sort 会返回列表

```python
nums = [3, 1, 2]
result = nums.sort()
print(result)
```

```
None
```

**为什么**：`list.sort()` 是**原地排序**，它直接把 `nums` 本身改了，函数本身返回 `None`。很多人误以为它返回一个排好的新列表。

**两种修法**：

```python
# 法一：用 sort()，接受它改原列表
nums = [3, 1, 2]
nums.sort()
print(nums)                 # [1, 2, 3]

# 法二：用 sorted()，要新列表就用它
nums = [3, 1, 2]
result = sorted(nums)
print(nums)                 # [3, 1, 2]，没动
print(result)               # [1, 2, 3]
```

## 字符串和列表的互转

`split()` 把字符串按分隔符切成列表，`join()` 把列表拼回字符串——**这俩是文本处理的左右手**。

```python
text = "苹果,香蕉,橙子"
fruits = text.split(",")    # ['苹果', '香蕉', '橙子']
print(fruits)

# 拼回去
joined = "-".join(fruits)   # '苹果-香蕉-橙子'
print(joined)
```

`join` 的写法要适应一下：**它是字符串的方法**，调用者是"用什么连接"，参数是被连接的列表。

```python
words = ["我", "爱", "Python"]
sentence = "".join(words)
print(sentence)             # 我爱Python

lines = ["第一行", "第二行", "第三行"]
text = "\n".join(lines)
print(text)
```

## 列表推导式（先点个卯，第 23 课细讲）

有一个简洁写法，能一行生成列表：

```python
squares = [x**2 for x in range(1, 6)]
print(squares)              # [1, 4, 9, 16, 25]
```

读起来是"把 range(1,6) 里每个 x 的平方，装进一个新列表"。现在先认识它，第 23 课会展开。

## 复制列表：这是个坑

```python
a = [1, 2, 3]
b = a               # 这样写是"两个名字指向同一个列表"
b.append(4)
print(a)            # [1, 2, 3, 4]   a 也被改了！
```

**为什么**：变量是"标签"。`b = a` 只是给同一个列表多贴了一张标签，没复制内容。

**怎么真正复制**：

```python
a = [1, 2, 3]
b = a.copy()        # 法一：copy()
b = a[:]            # 法二：切片（常用，简洁）
b = list(a)         # 法三：用 list() 重新构造
b.append(4)
print(a)            # [1, 2, 3]，a 没变
print(b)            # [1, 2, 3, 4]
```

> 这是 Python 和很多语言的重要差异点。第二课讲"变量是标签不是盒子"时埋的伏笔，在这里兑现。

## 翻车现场：边遍历边改列表

这是新手最容易中招的坑：

```python
# WRONG：想在遍历时删掉所有偶数
nums = [1, 2, 3, 4, 5, 6]
for n in nums:
    if n % 2 == 0:
        nums.remove(n)
print(nums)
```

你以为会得到 `[1, 3, 5]`。实际是 `[1, 3, 4, 5]`——**4 被漏掉了**。

**为什么**：遍历过程中列表在变短，下标在往后走，元素被往前挪，于是下一个元素被跳过了。

**三种修法**：

```python
nums = [1, 2, 3, 4, 5, 6]

# 法一：遍历副本，改原件
for n in nums.copy():
    if n % 2 == 0:
        nums.remove(n)

# 法二：列表推导式（最推荐）
nums = [n for n in nums if n % 2 != 0]

# 法三：从后往前删（下标不影响前面的元素）
for i in range(len(nums) - 1, -1, -1):
    if nums[i] % 2 == 0:
        nums.pop(i)
```

**记住这条军规：遍历列表时不要增删它，要改就遍历副本或用推导式。**

## 小结

- `sort()` 改原列表返回 None；`sorted()` 返回新列表不改原
- `split()` 切字符串成列表，`"连接符".join(列表)` 拼回去
- `count()` 计数、`index()` 查位置、`+` 拼接、`*` 重复
- `b = a` 只是多贴标签，不是复制；要复制用 `copy()` 或切片 `[:]`
- **遍历时别增删原列表**：用 `copy()` 遍历、用推导式、或从后往前删
- 列表推导式 `[表达式 for x in 可迭代]` 是 Python 的标志性写法
