# 定义与调用：def、参数、return 和缩进

> 上一课讲了"为什么要有函数"。这一课把"怎么写一个函数"讲透：**def 怎么写、参数怎么传、return 返回什么、缩进怎么管**。
>
> 这一课有三个坑，都是新手必踩的：**缩进错、参数个数对不上、忘了写 return**。

## 一、定义：def 三件套

一个函数由四部分组成：`def` 关键字、函数名、括号里的参数、冒号后面的缩进块。

```python
def add(a, b):
    """返回两个数的和"""
    return a + b
```

- `def` 告诉 Python：我要定义一个函数了
- `add` 是函数名，起名要有意义（见名知义）
- `(a, b)` 是参数，调用时你要把两个数传进来
- 冒号 `:` 后面必须缩进（通常 4 个空格），缩进里的内容就是函数体

调用：

```python
result = add(3, 5)
print(result)        # 8
```

⚠️ **翻车：冒号后面忘了缩进。**

```python
def add(a, b):
print(a + b)        # ✗ IndentationError: expected an indented block
```

Python 靠**缩进**来识别"哪些代码属于这个函数"。忘了缩进，解释器直接报错。`return` 也必须在缩进块里，否则不属于函数。

## 二、参数：函数要"吃"的东西

参数是函数和外部沟通的入口。多个参数用逗号隔开：

```python
def make_name(first, last):
    return first + "·" + last

print(make_name("张", "三"))          # 张·三
print(make_name("Bill", "Gates"))    # Bill·Gates
```

调用时传进去的值叫**实参**（实际的值 3、"张三"），定义时写的 `a`、`first` 叫**形参**（形式上的名字）。

⚠️ **翻车：参数个数对不上。**

```python
def add(a, b):
    return a + b

add(3)              # ✗ TypeError: add() missing 1 required positional argument: 'b'
add(1, 2, 3)        # ✗ TypeError: add() takes 2 positional arguments but 3 were given
```

少传一个、多传一个都会 `TypeError`。**调用时的实参个数必须和定义的形参个数一致**（后面第 23、26 课会讲可变参数，现在先记这条铁律）。

## 三、return：函数的"出口"

`return` 是函数把结果交回来的方式。调用 `add(3, 5)` 时，那个"8"就是 `return` 交回来的。

```python
def square(n):
    return n * n

x = square(4)        # x 是 16
```

`return` 之后，函数**立刻结束**，后面的代码不会再执行：

```python
def divide(a, b):
    if b == 0:
        return "除数不能为 0"
    return a / b

print(divide(10, 0))        # 除数不能为 0
print(divide(10, 2))        # 5.0
```

一旦命中第一个 `return`，函数就"退货走人"了，下面的 `return a / b` 不会被执行。这个特性特别适合"先做判断、再算结果"的场景。

## 四、经典坑：没有 return 就返回 None

这是新手第一坑，必考。

```python
def add(a, b):
    result = a + b        # 算了，但没 return

x = add(3, 5)
print(x)                  # None
print(x + 1)              # ✗ TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'
```

`add(3, 5)` 算出了 8，但**没有 `return`，所以这个"8"被丢掉了**，函数返回的是默认的 `None`。然后你拿 `None + 1`，就炸了。

⚠️ **翻车：在函数里 print 却忘了 return，以为拿到了结果。**

```python
def double(n):
    print(n * 2)          # 打印了，但没 return

x = double(5)             # 打印 10
print(x)                  # None —— 拿不到 10
```

`print` 只是把东西显示到屏幕上，**不会把值交回来**。想让调用者拿到结果，必须写 `return`。

⚠️ **翻车：以为函数会自动返回最后一个表达式的值（这是别的语言的习惯）。**

```python
def add(a, b):
    a + b                 # 没有 return，也没有赋值

print(add(3, 5))          # None
```

Python 不会"自动返回最后一行的值"。**没有 `return` 就等于返回 `None`**——这是铁律，没有任何例外。

## 五、缩进决定"属于谁"

同一个缩进级别 = 同一块代码。看这个例子：

```python
def classify(score):
    if score >= 60:
        result = "及格"        # 属于 if
    else:
        result = "不及格"      # 属于 else
    return result              # 属于函数
```

`return result` 和 `if` 对齐，说明它属于函数、不管走哪个分支都会执行。

⚠️ **翻车：return 缩进错，放进了 if 里。**

```python
def classify(score):
    if score >= 60:
        result = "及格"
        return result      # 只在及格时返回

zhangsan = classify(55)
print(zhangsan)            # None
```

55 分没进 `if`，于是 `return` 没被执行，函数默认返回 `None`。**这种"某个分支漏了 return"的 bug，调试起来非常隐蔽**——你测 90 分一切正常，测 55 分就拿到 None。

## 六、一个完整的小例子

写一个"算总价"的函数：商品单价、数量、是否会员（会员 9 折）。

```python
def total_price(price, quantity, is_vip):
    amount = price * quantity
    if is_vip:
        amount *= 0.9
    return round(amount, 2)

print(total_price(100, 2, False))        # 200（不是 200.0 —— round 对整数返回整数）
print(total_price(100, 2, True))         # 180.0
```

一个函数只做一件事，参数就是它需要的所有外部信息，最后用 `return` 交回结果——这就是**好函数的样子**。

⚠️ **翻车：在函数里直接改全局变量，而不是返回结果。**

```python
result = 0

def add(a, b):
    result = a + b          # 这是个局部变量，没改到外面的 result

add(3, 5)
print(result)               # 0 —— 外面没变
```

这里 `result = a + b` 创建的是函数内部的**局部变量** `result`，和外面那个同名但不是同一个。**函数要"交回结果"，靠的是 `return`，不是靠改外面的变量**（第 25 课细讲作用域）。

## 小结

- 函数定义四件套：`def`、名字、参数括号、冒号后缩进块
- 参数个数必须严格对齐：少传多传都 `TypeError`
- `return` 是函数的出口，一旦执行函数立刻结束
- **没有 `return` 就返回 `None`**——新手第一坑，必考
- `print` 只是显示，不返回值；Python 不会自动返回最后一行
- 缩进决定归属，return 漏写某个分支会返回 None
