# 返回值：一个、多个和"提前跑路"

> 上一课讲了参数怎么传进来。这一课讲函数怎么把结果**交回去**：`return` 能返回一个值、多个值（其实是元组）、能提前结束函数，以及如何判断"是不是 None"。
>
> 这一课的核心：**多返回值只是语法糖，底层是元组解包**。

## 一、返回一个值

最基础的用法：算完一个结果，`return` 交回去。

```python
def celsius_to_fahrenheit(c):
    return c * 9 / 5 + 32

f = celsius_to_fahrenheit(100)
print(f)        # 212.0
```

调用者拿到的是 `return` 后面的那个值，可以赋给变量、可以放进列表、可以直接当参数传给另一个函数。

## 二、返回多个值：其实是元组

Python 允许你 `return` 多个值，用逗号隔开：

```python
def split_name(full_name):
    parts = full_name.split("·")
    return parts[0], parts[1]        # 两个值

first, last = split_name("张·三")
print(first)        # 张
print(last)         # 三
```

看起来像"返回了两个值"，其实**只返回了一个：一个包含两个元素的元组**。

```python
result = split_name("张·三")
print(result)        # ('张', '三') —— 就是一个元组
print(type(result))  # <class 'tuple'>
```

`first, last = ...` 那一步是**元组解包**（第 6 课学过）：把元组里的两个元素分别赋给两个变量。函数本身从来没"返回过两个东西"，它只返回了一个元组。

⚠️ **翻车：以为返回了多个值，用下标去取却取错了。**

```python
def get_point():
    return 3, 5

x = get_point()
print(x[0])        # 3 —— 其实 x 是个元组
print(x[1])        # 5
```

这不算错，但容易让人误以为"返回了多个东西"。记住：**`return a, b` 等价于 `return (a, b)`**。

## 三、接收方式：解包 vs 当元组用

```python
def stats(numbers):
    return min(numbers), max(numbers), sum(numbers) / len(numbers)

# 方式一：解包成三个变量
lo, hi, avg = stats([10, 20, 30, 40])
print(lo, hi, avg)        # 10 40 25.0

# 方式二：整体接收一个元组
result = stats([10, 20, 30, 40])
print(result)             # (10, 40, 25.0)
```

⚠️ **翻车：变量个数对不上。**

```python
lo, hi = stats([10, 20, 30])      # ✗ ValueError: too many values to unpack (expected 2)
```

`stats` 返回 3 个值的元组，你只给了 2 个变量去接，解包失败。**元组有几个元素，就得有几个变量**（除非用 `*` 收集，后面会讲）。

## 四、提前 return：满足条件就"跑路"

`return` 一旦执行，函数立刻结束，后面的代码不再运行。这个特性常用来做"早退"：

```python
def safe_divide(a, b):
    if b == 0:
        return "除数不能为 0"        # 命中就立刻结束
    return a / b                    # 否则才到这里

print(safe_divide(10, 0))        # 除数不能为 0
print(safe_divide(10, 2))        # 5.0
```

这种"先处理异常情况、再算正常逻辑"的写法，叫**卫语句（guard clause）**，比嵌套的 if/else 清爽得多：

```python
# 不推荐：嵌套地狱
def safe_divide(a, b):
    if b != 0:
        if a > 0:
            if b < 100:
                return a / b
    return "不行"

# 推荐：逐个排除
def safe_divide(a, b):
    if b == 0:
        return "除数不能为 0"
    if a <= 0:
        return "被除数要大于 0"
    if b >= 100:
        return "除数太大"
    return a / b
```

⚠️ **翻车：以为 return 之后还会继续执行。**

```python
def process(x):
    if x < 0:
        return "负数"
    print("这行还会执行吗？")

process(-1)        # 只返回"负数"，不打印
```

`return "负数"` 执行后函数就结束了，`print` 永远不会跑。这不是 bug，是特性——**但如果你误以为下面还会执行，就会写出"死代码"（永远不会跑到的代码）**。

## 五、None 的判断

没有 `return` 的函数返回 `None`。判断一个函数返回的是不是 `None`，用 `is`：

```python
def find_user(users, name):
    for u in users:
        if u["name"] == name:
            return u
    # 没找到，走到这里，返回 None

zhangsan = find_user([{"name": "张三"}], "李四")
if zhangsan is None:
    print("没找到这个人")
else:
    print("找到了")
```

⚠️ **翻车：用 `==` 判断 None。**

```python
if zhangsan == None:        # 能跑，但不推荐
    print("没找到")
```

`is` 判断的是"是不是同一个对象"，`==` 判断的是"值是否相等"。`None` 是单例，习惯上**一律用 `is None` / `is not None`**。

⚠️ **翻车：用 if 判断返回值时，把 0、空字符串、空列表当成"没找到"。**

```python
def get_score(name):
    scores = {"张三": 0, "李四": 95}
    if name in scores:
        return scores[name]
    return None

s = get_score("张三")
if not s:                  # ❌ 张三的分数是 0，也被当成"没找到"
    print("没找到")
```

张三的分数是 0，`not 0` 是 True，于是被误判成"没找到"。**当返回值可能是 0、空字符串、空列表这类"假值"时，不能用 `if not s`，必须用 `if s is None`**。

## 六、一个综合例子：算订单金额

```python
def calc_order(price, quantity, discount=0, vip=False):
    if price <= 0 or quantity <= 0:
        return None, "价格或数量不合法"

    amount = price * quantity
    amount -= amount * discount
    if vip:
        amount *= 0.9
    return round(amount, 2), "成功"

total, msg = calc_order(100, 2, discount=0.1, vip=True)
print(total, msg)        # 162.0 成功

total, msg = calc_order(-10, 2)
print(total, msg)        # None 价格或数量不合法
```

返回 `(结果, 提示信息)` 两个值：正常时给结果 + "成功"，异常时给 `None` + 错误原因。调用者同时拿到"算出来的东西"和"对结果的说明"。

⚠️ **翻车：只接一个值，丢了提示信息。**

```python
total = calc_order(100, 2, discount=0.1, vip=True)
print(total)        # (162.0, '成功') —— 拿到的是整个元组，msg 丢了
```

你以为 `total` 是数字，其实是 `(162.0, '成功')`。**接几个值、对应几个返回值，别漏**。

## 小结

- `return a, b` 其实返回的是一个元组 `(a, b)`，多返回值是语法糖
- 接收方式两种：解包成多个变量，或整体接收一个元组
- 解包时变量个数必须和元组元素数一致
- `return` 提前结束函数是"卫语句"的核心技巧
- 判断 None 用 `is None`，不用 `==`
- 返回值可能是 0/空串/空列表时，别用 `if not x`，要用 `if x is None`
