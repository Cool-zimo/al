# 函数也是对象：能赋值、能装进列表、能当参数

> 前几课把函数当成"一段被打包的代码"。这一课升级认知：**函数本身也是一个对象**——可以赋给变量、可以放进列表、可以当成参数传给另一个函数。
>
> 理解这一点，就打开了"高阶函数"的大门。

## 一、函数是对象，有名字也有身份

在 Python 里，函数跟数字、字符串、列表一样，都是**对象**，存在内存里，`def` 只是给它绑了个名字。

```python
def greet(name):
    return f"{name}，你好"

print(greet)                 # <function greet at 0x...>
print(type(greet))           # <class 'function'>
print(id(greet))             # 一串数字，说明它确实有"身份"
```

`greet` 是个变量名，指向内存里那个函数对象。`type` 和 `id` 都能用在它身上——这就是"对象"的铁证。

⚠️ **翻车：忘了写括号，把函数本身当成了结果。**

```python
def get_greeting():
    return "你好"

print(get_greeting)          # <function get_greeting at 0x...>  ← 没调用！
```

`get_greeting` 是函数对象本身，`get_greeting()` 才是调用。少了那对括号，你拿到的是"函数"，不是"它的返回值"。

## 二、把函数赋值给另一个变量

既然函数是对象，就能把它赋给另一个变量，新变量同样能调用：

```python
def square(n):
    return n * n

calc = square            # 把函数对象绑给 calc，没加括号
print(calc(5))           # 25
print(square(5))         # 25 —— 两个名字指向同一个函数
```

`calc = square` 后面**没括号**，意思是"把那个函数给我，我也要一个名字"，不是"调用它"。

⚠️ **翻车：赋值时不小心加了括号，立刻调用了。**

```python
def square(n):
    return n * n

calc = square(5)         # 立刻调用，calc 变成了 25（一个数字）
print(calc(6))           # ✗ TypeError: 'int' object is not callable
```

`square(5)` 是调用，返回 25。`calc` 于是成了整数 25，再当函数调用就炸了。**不加括号 = 传函数本身；加了括号 = 传它的返回值**。

## 三、把函数装进列表：一组"动作"随取随用

函数能放进列表、字典，于是可以**批量管理一组行为**：

```python
def add(a, b):
    return a + b

def sub(a, b):
    return a - b

def mul(a, b):
    return a * b

ops = [add, sub, mul]        # 列表里装的是函数对象

for op in ops:
    print(op(10, 3))
# 7
# 7
# 30
```

`ops` 是个"函数列表"，遍历它就能依次执行每个运算。这在写"计算器"或"菜单驱动"的小程序时特别顺手。

⚠️ **翻车：把函数存进列表时加了括号，存进去的是返回值。**

```python
ops = [add(10, 3), sub(10, 3), mul(10, 3)]
print(ops)        # [13, 7, 30] —— 列表里是数字，不是函数
```

这里存进去的是**调用结果**（数字），列表里就只是普通的数字了，再也调不动了。**想存"函数"本身，括号必须省**。

## 四、函数当参数：传给另一个函数

把函数作为参数传进去，是"高阶函数"的核心：

```python
def apply_twice(func, value):
    """把 func 对 value 执行两次"""
    return func(func(value))

def add_five(x):
    return x + 5

print(apply_twice(add_five, 10))        # 20
```

`apply_twice` 不知道 `func` 具体干了什么，它只知道"拿到 func 就调用它"。这种"函数接受函数"的写法，让代码**极其灵活**。

⚠️ **翻车：传参数时不小心调用了。**

```python
apply_twice(add_five(10), 20)   # ✗ TypeError: 'int' object is not callable
```

`add_five(10)` 返回 15（整数），`apply_twice` 拿到 15 想当函数调用，就炸了。**传函数本身，不要传它的返回值**。

## 五、函数当返回值：工厂模式

函数还能返回函数——这是"闭包"的雏形：

```python
def make_multiplier(factor):
    def multiply(x):
        return x * factor
    return multiply            # 返回函数对象

double = make_multiplier(2)
triple = make_multiplier(3)

print(double(10))              # 20
print(triple(10))              # 30
```

`make_multiplier(2)` 返回了一个"记住了 factor=2"的函数 `double`。外层函数成了"函数工厂"：喂不同的参数，产出不同行为的函数。

⚠️ **翻车：返回时加了括号，变成返回调用结果。**

```python
def make_multiplier(factor):
    def multiply(x):
        return x * factor
    return multiply()          # ✗ TypeError: multiply() missing 1 required positional argument: 'x'

print(make_multiplier(2))
```

`return multiply()` 是"立刻调用 multiply"，但没给参数，于是报错。**想返回函数本身，return 后面不加括号**。

## 六、用字典做"命令分发"：实战

通讯录小工具经常需要根据用户输入执行不同操作，用"函数字典"最清爽：

```python
def do_add(name):
    return f"添加 {name}"

def do_del(name):
    return f"删除 {name}"

def do_find(name):
    return f"查找 {name}"

menu = {
    "1": do_add,
    "2": do_del,
    "3": do_find,
}

cmd = "2"
name = "张三"
print(menu[cmd](name))        # 删除 张三
```

用户选 "2"，从 `menu` 里取出 `do_del` 函数，再传参调用。**不用写一堆 if/elif，加新功能只要在字典里加一行**。

⚠️ **翻车：把函数调用结果存进字典。**

```python
menu = {
    "1": do_add("张三"),       # 立刻执行了！存进去的是字符串
}
print(menu["1"])              # 添加 张三（早就执行过了）
```

字典里存的是 `do_add("张三")` 的返回值——字符串。你失去了"以后想调用"的能力。**命令分发模式必须存函数本身**。

## 七、为什么这很重要

**把函数当对象**，本质上就是"**行为也能被传递**"。这让你可以：

- 把"做什么"作为参数传进去（`map`、`filter`、`sorted(key=...)` 全是这个套路）
- 把"一组操作"装进容器统一管理（菜单、插件、路由表）
- 动态生成函数（工厂、装饰器，后面会讲）

一旦你习惯"函数可以到处传"，代码的灵活度会上一个台阶。

## 小结

- 函数在 Python 里是**一等对象**：有身份、能赋值、能存容器、能传参、能返回
- `函数名` = 函数本身；`函数名()` = 调用
- 存函数、传函数、返回函数时**一律不加括号**
- 函数列表适合"批量管理一组行为"
- 函数字典适合"命令分发"，替代冗长的 if/elif
- 传参时不小心加了括号，是最常见的错误
