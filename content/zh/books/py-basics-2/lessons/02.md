# 索引：按位置把东西取出来

> 列表能装一堆东西了。但光装进去没用 —— 你得能**把其中一个拿出来用**。
>
> 比如：取出第 3 个学生的成绩、把最后一个元素改掉、看看第一个是不是空的。
>
> 这一课讲的就是列表的**取件码：索引**。

## 一、为什么需要索引

列表长这样：

```python
scores = [87, 92, 78, 95, 61]
```

现在你想单独打印第二个成绩 92。怎么写？

**不能写 `scores(2)`** —— 列表不是函数。取元素要用中括号：

```python
scores = [87, 92, 78, 95, 61]
print(scores[1])
```

```
92
```

注意这里的关键：`scores[1]` 拿到的是 **92**，也就是"第二个"元素。

## 二、索引从 0 开始（这是新手第一道坎）

```
scores  →  ┌────┬────┬────┬────┬────┐
           │ 87 │ 92 │ 78 │ 95 │ 61 │
           └────┴────┴────┴────┴────┘
索引:        0    1    2    3    4
第几个:      第1  第2  第3  第4  第5
```

**索引从 0 数起，不是从 1。** 所以"第 3 个"的索引是 2。

为什么这么反人类？因为索引的准确含义是**偏移量**：

> `scores[0]` = 从开头往后数 0 格 → 第一个
> `scores[1]` = 从开头往后数 1 格 → 第二个

起点本身偏移 0 格，所以第一个是 0。这是几乎所有编程语言的惯例（C、Java、JavaScript 都一样），习惯之后你会发现它其实更自洽。

⚠️ **最常见的翻车：数着数着就差一个。**

```python
scores = [87, 92, 78, 95, 61]
print(scores[5])      # ✗ IndexError: list index out of range
```

列表有 5 个元素，索引是 **0 到 4**，`scores[5]` 越界了。

**记法**：最后一个元素的索引永远是 `len(列表) - 1`。

```python
scores = [87, 92, 78, 95, 61]
print(scores[len(scores) - 1])     # 61，最后一个
```

## 三、负索引：从末尾倒着数

每次写 `len(scores) - 1` 太啰嗦。Python 给了个更爽的写法：

```python
scores = [87, 92, 78, 95, 61]

print(scores[-1])     # 61，倒数第一个
print(scores[-2])     # 95，倒数第二个
print(scores[-5])     # 87，倒数第五个（也就是第一个）
```

**负索引从 -1 开始**，-1 是最后一个，越往前越小。

```
           ┌────┬────┬────┬────┬────┐
           │ 87 │ 92 │ 78 │ 95 │ 61 │
           └────┴────┴────┴────┴────┘
正索引:      0    1    2    3    4
负索引:     -5   -4   -3   -2   -1
```

**为什么负索引从 -1 而不是 -0？** 因为 `-0` 就等于 `0`，两个索引会撞在一起，谁也分不清是第一个还是最后一个。所以规定最后一个是 -1。

⚠️ 负索引同样会越界：

```python
scores = [87, 92, 78, 95, 61]
print(scores[-6])     # ✗ IndexError，只有 5 个元素
```

最小的合法负索引是 `-len(列表)`。

### 什么时候用负索引

**取最后一个（或最后几个）元素时**，负索引明显更清爽：

```python
# 啰嗦
print(scores[len(scores) - 1])

# 清爽
print(scores[-1])
```

## 四、索引不只是"取"，还能"改"

列表是可变的（第 1 课说过），所以索引可以放在赋值号左边：

```python
scores = [87, 92, 78, 95, 61]

scores[0] = 100          # 把第一个改成 100
print(scores)
```

```
[100, 92, 78, 95, 61]
```

这行读作：**把 100 放进 scores 的第 0 号柜子。**

同样的写法也能用在负索引上：

```python
scores[-1] = 0
print(scores)
```

```
[100, 92, 78, 95, 0]
```

⚠️ 但对**不存在的索引赋值**同样是报错，不会自动帮你加长：

```python
scores = [87, 92]
scores[5] = 100     # ✗ IndexError: list assignment index out of range
```

想在末尾加东西，得用第 3 课要讲的 `append`。**索引只能改已经存在的位置。**

## 五、越界是怎么回事，怎么防

看一下这个报错的完整样子：

```python
scores = [87, 92, 78]
print(scores[3])
```

```
IndexError: list index out of range
```

意思是"列表索引超出范围"。你申请了第 3 号柜子，但这个列表只有 0、1、2。

**新手最常踩的两种越界：**

**① 循环时多跑了一轮。**

```python
scores = [87, 92, 78]
for i in range(4):          # range(4) 给 0,1,2,3 —— 多了一个 3
    print(scores[i])        # 最后一轮崩
```

改成 `range(len(scores))` 就不会：

```python
scores = [87, 92, 78]
for i in range(len(scores)):
    print(scores[i])
```

**② 空列表还去取元素。**

```python
bag = []
print(bag[0])      # ✗ IndexError，一个元素都没有
```

拿之前先看一眼长度，是个好习惯：

```python
bag = []
if len(bag) > 0:
    print(bag[0])
else:
    print("袋子是空的")
```

## 六、一个容易搞混的对比

| 写法 | 含义 |
|---|---|
| `scores[0]` | 取第一个元素，得到 `87` 这个**数字** |
| `scores[0:1]` | 切片（第 4 课），得到 `[87]` 这个**列表** |

一个给值，一个给列表 —— 差一个冒号，类型完全不同。

```python
scores = [87, 92, 78]

print(scores[0])       # 87
print(scores[0:1])     # [87]
print(type(scores[0]))      # <class 'int'>
print(type(scores[0:1]))    # <class 'list'>
```

这个区别会在第 4 课切片时变得非常重要。

```quiz
type: code
q: 有一个列表 `scores = [87, 92, 78, 95, 61]`。请打印它的**最后一个**元素（用负索引），再打印它的**第一个**元素
starter: |
  scores = [87, 92, 78, 95, 61]

  # 打印最后一个（用负索引）

  # 打印第一个

tests:
- assert "61" in __out
- assert "87" in __out
hint: 倒数第一个的索引是 -1。第一个的索引是 0（不是 1）。分开写两行 print。
explain: 答案是 print(scores[-1]) 和 print(scores[0])。这里两个坑一起考：负索引从 -1 开始（不是 -0），正索引从 0 开始（不是 1）。写成 scores[-5] 虽然也能拿到 87，但题目要求的是「第一个」，用 0 更直白也更不容易错。
```

## 本节测验

```quiz
type: choice
exam: true
q: `letters = ["a", "b", "c", "d"]`，`letters[-2]` 是什么？
options:
- "b"
- "c"
- "d"
- 报错，负索引不存在
answer: 1
explain: 负索引从 -1 起倒着数：-1 是 d，-2 是 c，-3 是 b，-4 是 a。所以 letters[-2] 是 "c"。正索引 2 也是 "c" —— 两者指向同一个元素，只是数法相反。
```

```quiz
type: code
exam: true
q: 列表 `data = [10, 20, 30]`。请做两件事：把第 2 个元素（20）改成 99，然后打印整个列表
starter: |
  data = [10, 20, 30]

  # 把第二个元素改成 99

  print(data)
tests:
- assert "[10, 99, 30]" in __out
hint: 「第二个」的索引是几？记住索引从 0 数起。改元素用 data[索引] = 新值 的写法。
explain: 补的是 data[1] = 99。第二个元素的索引是 1 而不是 2 —— 这是本课最容易错的地方。写 data[2] = 99 会把 30 改成 99，得到 [10, 20, 99]，测试就过不了。这个测试专门用来确认你数对了。
```
