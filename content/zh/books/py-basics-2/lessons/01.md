# 一次装很多个：列表

> 到目前为止，你的程序一次只能记住**一个**东西 —— 一个成绩、一个名字、一个数字。
>
> 但真实世界里，东西总是成堆出现的：一整个班的成绩、购物车里的十件商品、一周七天的气温。
>
> 这一课解决的就是：**怎么用一个变量，装下一整堆数据。**

## 一、先看没有列表的世界有多难受

假设你要记录 5 个同学的成绩，然后求平均分。用你现在会的知识，只能这样写：

```python
s1 = 87
s2 = 92
s3 = 78
s4 = 95
s5 = 61

total = s1 + s2 + s3 + s4 + s5
print("平均分:", total / 5)
```

能跑。但问题马上就来了 ——

**如果班上有 50 个人呢？**

你得写 50 个变量、50 行加法。更糟的是：如果人数是用户输进来的、你事先根本不知道呢？**你连变量该写几个都定不下来。**

这就是"一个变量装一个值"的根本局限：

> **变量的个数必须在你写代码的时候就定死，而现实中的数据量往往要等程序运行起来才知道。**

## 二、列表：一排带编号的储物柜

列表就是来解决这个的。它让**一个变量装一整排数据**：

```python
scores = [87, 92, 78, 95, 61]
print(scores)
```

运行：

```
[87, 92, 78, 95, 61]
```

`scores` 只是一个变量，但它里面装着 5 个数字。

打个比方：普通变量是**一个盒子**，列表是**一排带编号的储物柜**。

```
scores  →  ┌────┬────┬────┬────┬────┐
           │ 87 │ 92 │ 78 │ 95 │ 61 │
           └────┴────┴────┴────┴────┘
             0    1    2    3    4      ← 编号，叫「索引」
```

每个柜子有固定编号，你按编号存取。这个编号叫**索引（index）**，下一课细讲。

## 三、怎么创建列表

用中括号 `[]`，元素之间用逗号隔开：

```python
numbers = [1, 2, 3, 4, 5]
names = ["小明", "小红", "小刚"]
mixed = [87, "小明", True, 3.14]     # 什么类型都能装
empty = []                            # 空列表，一个元素都没有
```

三个要点：

**① 什么类型都能装，还能混着装。** 数字、字符串、布尔值，甚至另一个列表，全都行。

**② 空列表是合法的，而且特别有用。** 就像你先推一辆空购物车，之后边逛边往里放东西。

**③ 元素是有顺序的。** `[87, 92]` 和 `[92, 87]` 是**两个不同的列表** —— 顺序本身就是信息（比如"第一次考了多少、第二次考了多少"）。

### 顺手记一个：从字符串拆成列表

```python
chars = list("hello")
print(chars)
```

```
['h', 'e', 'l', 'l', 'o']
```

`list()` 会把一个字符串拆成"单个字符组成的列表"。

## 四、列表有多长：len()

不用自己数，用 `len()` 问它：

```python
scores = [87, 92, 78, 95, 61]
print(len(scores))
```

```
5
```

`len` 是 "length"（长度）的缩写，它是 Python 内置函数，几乎能数所有"装东西的容器"。

**这一句为什么重要？** 因为它让你的程序**不再需要提前知道有多少数据**：

```python
scores = [87, 92, 78, 95, 61]
print("一共", len(scores), "个成绩")
```

以后列表变成 5 个还是 500 个，这行代码一个字都不用改。

⚠️ **最常见的翻车现场：把 `len` 当属性去调用。**

```python
scores.len()      # ✗ AttributeError: 'list' object has no attribute 'len'
```

`len()` 是**函数**，要把它包在外面；它不是方法，不能跟在后面用点调用。

| 写法 | 对不对 | 说明 |
|---|---|---|
| `len(scores)` | ✅ | len 是函数，包围着它 |
| `scores.len()` | ❌ | 列表没有 .len() 这个方法 |

**记法**：`len` 是"外人"来数的，所以站在括号外面；方法是"自己人"，才跟在后面。

## 五、列表最重要的能力：它可以变

这点要提前说，因为它决定了列表的用途：

```python
scores = [87, 92, 78]
scores.append(95)          # 往末尾加一个
print(scores)
```

```
[87, 92, 78, 95]
```

**列表可以在程序运行中长大、缩小、被改写。** 这意味着你不需要提前知道会有多少数据 —— 用户填一个，你就 `append` 一个。

这正是它解决开头那个困境的方式：**数据有多少，运行时说了算。**

（添加、删除的完整写法在第 3 课。这里你只要先记住"它能变"就够了。）

```quiz

```

## 六、回到开头的问题

用列表重写一开始那个"求平均分"：

```python
scores = [87, 92, 78, 95, 61]

total = 0
for s in scores:
    total = total + s

print("平均分:", total / len(scores))
```

```
平均分: 82.6
```

看出来了吗 —— **这段代码跟"有几个成绩"完全无关。**

- 加一个成绩：往列表里加个数，代码一个字不改
- 减一个成绩：同理
- 换成 50 个人：照样跑

这就是列表真正的价值：**它把"数据的数量"从代码里拿掉了。**

（`for s in scores` 叫遍历，第 5 课细讲。这里你先感受它的意思：把列表里每个元素拿出来做一遍。）

## 七、什么时候该用列表

给你一条简单的判断标准：

| 场景 | 用什么 |
|---|---|
| 一个用户的名字 | 普通变量 |
| 一个班 40 个学生的名字 | **列表** |
| 一个固定的税率 | 普通变量 |
| 一周七天的气温 | **列表** |

判据就一句：**当你在写代码时说不出"到底会有几个"，就该用列表。**
