## 第一部分 · 选择题

检验这章的概念有没有真正记住。

```quiz
type: choice
q: '`d = {"a": 1, "b": 2}`，执行 `d["c"] = 3` 之后 `d` 变成什么？'
options:
- '报错 KeyError'
- '{"a": 1, "b": 2, "c": 3}'
- '{"c": 3}'
- 'None'
answer: 1
explain: 中括号赋值对字典是"有则改、无则加"。c 不存在就新增一条。这跟列表"索引越界赋值报错"不一样。
```

```quiz
type: choice
q: '`d = {"a": 1}`，哪个能安全地在键不存在时返回 0、且不改变字典？'
options:
- 'd["b"]'
- 'd.get("b", 0)'
- 'd.setdefault("b", 0)'
- 'd.pop("b")'
answer: 1
explain: get 找不到就返回默认值 0，且不改字典。setdefault 虽然也返回默认值，但会把 "b": 0 写进字典，不符合"不改变字典"。pop 不传默认值会报错。
```

```quiz
type: choice
q: 遍历字典时删除键会发生什么？
options:
- '静默忽略，什么都不删'
- '有时成功、有时 RuntimeError'
- '一定报错 KeyError'
- '自动复制一份再删'
answer: 1
explain: Python 禁止遍历时改结构，但检测时机不确定 —— 有时循环提前撞上就报错，有时循环结束前没出问题就蒙混过去。稳妥做法是遍历 keys() 的列表副本，或先收集再删。
```

```quiz
type: choice
q: '下面哪个能成功当作字典的键？'
options:
- '[1, 2, 3]'
- '{"a": 1}'
- '(1, 2, [3, 4])'
- '(1, 2, 3)'
answer: 3
explain: 前三个都含可变对象（列表、字典），不可哈希；只有 (1, 2, 3) 是纯不可变组合，可以当键。特别注意第三个：元组里嵌了列表也不行。
```

```quiz
type: choice
q: '`count = {"a": 3, "b": 3, "c": 1}`，`max(count, key=count.get)` 会怎样？'
options:
- '报错 ValueError'
- '返回 "a"（先遇到的最大值）'
- '返回 ["a", "b"]'
- '返回 "c"'
answer: 1
explain: max 只返回一个值。有多个并列最大时，返回遍历中先遇到的那个。要拿所有并列第一得自己筛一遍。
```

## 第二部分 · 动手题

光记住概念不够，得能写出来。

```quiz
type: code
q: 字典 `scores = {"张三": 92, "李四": 78, "王五": 55, "赵六": 100}`。请遍历字典，打印**不及格**（<60）的同学，格式为 `XX 不及格`，并把他们的名字收集到列表 `failed` 里，最后打印 failed
starter: |
  scores = {"张三": 92, "李四": 78, "王五": 55, "赵六": 100}
  failed = []

  # 遍历并打印不及格的，收集到 failed

  print(failed)
tests:
- assert "王五 不及格" in __out
- assert "['王五']" in __out
- assert "张三 不及格" not in __out
hint: 用 items() 同时拿到姓名和成绩，判断 < 60 时打印并 append 到 failed。
explain: 答案：for name, s in scores.items(): if s < 60: print(f"{name} 不及格"); failed.append(name)。只有王五 55 分不及格。考的是 items() 遍历和按条件筛选收集。
```

```quiz
type: function
q: 写一个函数 `invert_dict`，接收一个字典，返回"键值互换"的新字典：原字典的值当新字典的键，原字典的键当新字典的值。题目保证所有值都是可哈希的、且互不重复
func: invert_dict
starter: |
  def invert_dict(d):
      return {}
cases: |
  {"a": 1, "b": 2} -> {1: "a", 2: "b"}
  {"张三": "北京", "李四": "上海"} -> {"北京": "张三", "上海": "李四"}
hint: 遍历 d.items()，对每个 k, v，在新字典里写 result[v] = k。
explain: 答案：r = {}; for k, v in d.items(): r[v] = k; return r。考的是字典遍历和"反向映射"的构建。因为值互不重复，不会有键冲突。
```
