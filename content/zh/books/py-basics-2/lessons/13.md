# 字典的遍历与常用操作

> 前面学会了字典的单条增删改查。这一课讲"批量"操作：怎么把一个字典的键、值、键值对都过一遍，以及遍历时那个**必踩的报错**。

## 一、`keys`、`values`、`items`：三个视图

字典提供了三个方法，分别让你拿到键、值、键值对：

| 方法 | 拿到什么 | 遍历时每次拿到 |
|---|---|---|
| `d.keys()` | 所有键 | 一个键 |
| `d.values()` | 所有值 | 一个值 |
| `d.items()` | 所有键值对 | 一个 `(键, 值)` 元组 |

```python
scores = {"张三": 92, "李四": 78, "王五": 100}
```

### 遍历键：`keys()`

```python
for name in scores.keys():
    print(name)
```

```
张三
李四
王五
```

其实**直接 `for name in scores` 就行**，`keys()` 可以省略：

```python
for name in scores:
    print(name)        # 效果完全一样
```

### 遍历值：`values()`

```python
for s in scores.values():
    print(s)
```

```
92
78
100
```

### 遍历键值对：`items()`（最常用）

```python
for name, score in scores.items():
    print(f"{name}: {score}")
```

```
张三: 92
李四: 78
王五: 100
```

`items()` 返回的是 `(键, 值)` 元组，配合上一章学的**元组解包**，就能一次拿到键和值。这是字典遍历**最推荐的写法**。

⚠️ **翻车：想在遍历时同时拿到键和值，却没用 items。**

```python
for name in scores:
    print(name, scores[name])       # 能用，但啰嗦
```

能用，但每次还得回字典里查一次。用 `items()` 既清楚又少一次查找。

⚠️ **翻车：把 items 的结果当成了列表。**

```python
print(scores.items())      # dict_items([('张三', 92), ('李四', 78), ('王五', 100)])
```

在 Python 3 里，`keys()`、`values()`、`items()` 返回的不是列表，而是**视图对象**。它长得像列表、能遍历，但不能按下标取、也不能 `append`。

要列表就显式转换：

```python
names = list(scores.keys())
print(names)               # ['张三', '李四', '王五']
```

## 二、经典报错：遍历时不能增删

这一条是本章**最高频的坑**，务必记住。

先看一个**看起来没问题**的例子：

```python
d = {"a": 1, "b": 2, "c": 3}
for k in d:
    if d[k] < 2:
        del d[k]
print(d)          # {'b': 2, 'c': 3} —— 蒙对了
```

再看一个**同样写法**的例子：

```python
d = {"a": 1, "b": 0, "c": 1}
for k in d:
    if d[k] < 1:
        del d[k]
print(d)          # RuntimeError: dictionary changed size during iteration
```

为什么有时蒙对、有时报错？因为 Python **不允许在遍历字典的同时修改它的结构**（增或删键）。运气好时没撞上、运气差时就直接抛异常。

⚠️ **经典翻车现场：边遍历边删除。**

```python
scores = {"张三": 92, "李四": 78, "王五": 100, "赵六": 55}
for name in scores:
    if scores[name] < 60:
        del scores[name]      # ✗ RuntimeError
```

**正确做法：遍历字典的副本，或者收集要删的键、遍历完再删。**

### 方法一：遍历 keys 的副本

```python
for name in list(scores.keys()):
    if scores[name] < 60:
        del scores[name]
print(scores)      # {'张三': 92, '李四': 78, '王五': 100}
```

`list(scores.keys())` 先做出一个**独立的列表**，遍历它不会影响字典本身，删字典就安全了。

### 方法二：先收集、后删除

```python
to_remove = []
for name, score in scores.items():
    if score < 60:
        to_remove.append(name)

for name in to_remove:
    del scores[name]
```

先记下来要删谁，遍历结束再动手。这个思路在列表里同样适用（回想第 3 课那个"边遍历边删会漏元素"的坑，解法一模一样）。

**记住这条原则：遍历一个容器的时候，不要增删它的键/元素。** 要改就遍历副本，或者先收集、后动手。

## 三、字典排序

字典本身是无所谓顺序的（Python 3.7+ 会保留插入顺序，但**逻辑上不要依赖它排序**）。当你想"按值排序"或"按键排序"时，用 `sorted`。

### 按键排序

```python
scores = {"张三": 92, "李四": 78, "王五": 100}
for name in sorted(scores):
    print(name, scores[name])
```

```
张三 92
李四 78
王五 100
```

`sorted(scores)` 等价于 `sorted(scores.keys())`，返回排好序的**键的列表**。

### 按值排序

用 `sorted` 的 `key` 参数指定"按什么排"：

```python
scores = {"张三": 92, "李四": 78, "王五": 100}
for name in sorted(scores, key=lambda k: scores[k]):
    print(name, scores[name])
```

```
李四 78
张三 92
王五 100
```

`key=lambda k: scores[k]` 的意思是：排序时比较的是**每个键对应的值**。

⚠️ **翻车：直接 `sorted(scores.items())` 是按键排序的。**

```python
scores = {"张三": 92, "李四": 78}
print(sorted(scores.items()))      # [('张三', 92), ('李四', 78)] —— 按键排
```

想按值排，必须给 `key`：

```python
print(sorted(scores.items(), key=lambda item: item[1]))
# [('李四', 78), ('张三', 92)]
```

`item` 是 `(键, 值)` 元组，`item[1]` 就是值。

## 小结

- `keys()`、`values()`、`items()` 分别遍历键、值、键值对
- 遍历键值对用 `for k, v in d.items()`，最推荐
- **遍历时不能增删字典的键**，会 RuntimeError；遍历副本或先收集再删
- `sorted(d)` 按键排序；按值排要写 `key=lambda k: d[k]`
- 三个视图方法返回的不是列表，要列表用 `list()` 包一层
