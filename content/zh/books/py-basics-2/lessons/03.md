# 添加与删除：让列表长出来、缩回去

> 索引只能改**已经存在**的位置。但真实程序往往是边跑边收集数据的 —— 用户每提交一次，就多一条。
>
> 这一课讲列表的**增删**：怎么往里加、怎么从里去掉，以及几个必须记住的坑。

## 一、先认四个方法

列表自带的"动作"叫**方法**，写法是在列表后面加个点：

```python
bag = []
bag.append("书")      # 末尾添加一个
```

| 方法 | 干什么 | 改的是谁 |
|---|---|---|
| `append(x)` | 在**末尾**加一个 | 原列表 |
| `insert(i, x)` | 在**指定位置**插一个 | 原列表 |
| `pop(i)` | 删除指定位置，**并把它返回给你** | 原列表 |
| `remove(x)` | 删除**第一个值等于 x 的** | 原列表 |

四个方法**都直接改原列表**，不返回新列表（只有 `pop` 会返回被删掉的那个元素）。

## 二、append：最常用的一个

```python
bag = []
bag.append("书")
bag.append("笔")
bag.append("本")
print(bag)
```

```
['书', '笔', '本']
```

**append 一次只加一个元素**，加在末尾。

⚠️ **翻车：想一次加好几个。**

```python
bag = []
bag.append("书", "笔")     # ✗ TypeError: append() takes exactly one argument
```

`append` 只收一个参数。想一次加多个，用第 4 课要讲的 `extend`（或者写多行 append）。

⚠️ **另一个翻车：拿返回值。**

```python
bag = ["书"]
result = bag.append("笔")
print(result)      # None
```

`append` **没有返回值**（返回 `None`），它只是默默改了 `bag`。想要结果就打印 `bag` 本身：

```python
bag = ["书"]
bag.append("笔")
print(bag)         # ['书', '笔']
```

**判断方法**：需要"拿回点什么"的方法才会返回东西（比如 `pop`）；只是"做个动作"的方法一律返回 `None`。

## 三、insert：插到指定位置

`append` 只能加在末尾。想插到中间用 `insert`：

```python
queue = ["小明", "小红"]
queue.insert(0, "小刚")     # 插到最前面
print(queue)
```

```
['小刚', '小明', '小红']
```

`insert(位置, 值)` —— 注意**位置在前，值在后**，顺序别搞反。

插完之后，"小刚"是第 0 个，原来的人依次往后挪。

⚠️ 插到超出长度的位置不会报错，Python 会当成"加到末尾"处理：

```python
queue = ["小明", "小红"]
queue.insert(99, "小刚")
print(queue)      # ['小明', '小红', '小刚'] —— 不报错，但也不在 99 号
```

这跟索引赋值不一样（索引赋值越界会崩），**insert 很宽容**。但别指望它给你补一堆空位。

## 四、pop：删掉，并且把被删的给你

```python
scores = [87, 92, 78]
last = scores.pop()        # 不写位置 = 删最后一个
print(last)                # 78
print(scores)              # [87, 92]
```

**pop 是唯一会"还给你东西"的删除方法**：它返回被删掉的那个元素。

这就是它和 `remove` 最大的区别 —— 有时候你不仅要删，还要**用**被删的那个值：

```python
tasks = ["写作业", "看书", "运动"]
doing = tasks.pop(0)       # 取出第一个，从列表里去掉
print("现在做:", doing)
print("还剩:", tasks)
```

```
现在做: 写作业
还剩: ['看书', '运动']
```

这个"取出并移除"的动作在编程里有个专门的名字叫**出队**，写任务队列时非常常用。

⚠️ 空列表 pop 会报错：

```python
bag = []
bag.pop()      # ✗ IndexError: pop from empty list
```

## 五、remove：按"值"删，不按位置

前面三个都是按位置操作的，`remove` 不一样 —— 你告诉它**要删什么内容**：

```python
names = ["小明", "小红", "小刚"]
names.remove("小红")
print(names)
```

```
['小明', '小刚']
```

你不需要知道"小红"在第几个。

⚠️ **必踩的坑：remove 只删第一个匹配的。**

```python
nums = [1, 2, 3, 2, 2]
nums.remove(2)
print(nums)      # [1, 3, 2, 2] —— 只删了第一个 2
```

后面还有两个 2，但它不管。**remove 一次只删一个。**

⚠️ **另一个坑：删不存在的东西会报错。**

```python
names = ["小明", "小红"]
names.remove("小刚")      # ✗ ValueError: list.remove(x): x not in list
```

所以稳妥的写法是先问一句在不在（`in` 是第 5 课的内容，这里先见一面）：

```python
names = ["小明", "小红"]
if "小刚" in names:
    names.remove("小刚")
else:
    print("查无此人")
```

## 六、del：按位置删，不要返回值

还有一个写法是用 `del` 语句（不是方法，不加括号）：

```python
scores = [87, 92, 78]
del scores[0]
print(scores)      # [92, 78]
```

`del scores[0]` 和 `scores.pop(0)` 效果一样，**区别是 del 不返回被删的值**。

| 想要什么 | 用哪个 |
|---|---|
| 删掉就行，不用它 | `del scores[i]` |
| 删掉，还要拿这个值用 | `scores.pop(i)` |
| 知道内容，不知道位置 | `scores.remove(x)` |

## 七、一个真正常见的错误：边遍历边删

这个坑现在提，是因为太多人踩。等第 5 课讲完遍历，你会更明白。

先看一个**看起来对**的例子：

```python
nums = [1, 2, 3, 4, 5]
for n in nums:
    if n % 2 == 0:
        nums.remove(n)
print(nums)      # [1, 3, 5] —— 正是想要的
```

再看一个**同样写法**的例子：

```python
nums = [2, 4, 6, 8]
for n in nums:
    if n % 2 == 0:
        nums.remove(n)
print(nums)      # [4, 8] —— 漏了两个！
```

为什么第一个蒙对了、第二个露馅了？

原因是：**删掉元素后，后面的元素会整体往前挪一格，而遍历的指针照样往后走一格** —— 于是每次删除都会跳过一个元素。

| 轮次 | 指针位置 | 拿到的 n | 删完之后的列表 |
|---|---|---|---|
| 1 | 0 | 2 | `[4, 6, 8]` |
| 2 | 1 | **6**（4 被跳过了） | `[4, 8]` |
| 3 | 2 | 已经没了，结束 | `[4, 8]` |

**正确做法**：不要在遍历的同时修改这个列表，而是**建一个新列表装要留下的**：

```python
nums = [2, 4, 6, 8, 9]
kept = []
for n in nums:
    if n % 2 != 0:
        kept.append(n)
print(kept)      # [9]
```

遍历原列表、往新列表里加 —— 这样每个元素都会被检查到，一个不漏。

**记住这条原则：遍历的时候不要修改正在遍历的那个列表。** 要删就装新的。

```quiz
type: code
q: 空列表开始，依次 append 加入 5、10、15，然后用 pop() 删掉最后一个，最后打印列表
starter: |
  nums = []
  nums.append(5)
  nums.append(10)
  nums.append(15)

  # 删掉最后一个

  print(nums)
tests:
- assert "[5, 10]" in __out
hint: pop() 不写位置就是删最后一个。它是个动作，直接改原列表，不需要再赋值给谁。
explain: 补的是 nums.pop()。两个要点：pop 不写参数默认删最后一个；它直接改原列表，所以不用写 nums = nums.pop() —— 那样反而会把 nums 变成被删掉的那个数字。
```
