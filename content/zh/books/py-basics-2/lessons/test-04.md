## 第一部分 · 选择题

检验这章的概念有没有真正记住。

```quiz
type: choice
q: '`s = {}`，`type(s)` 是什么？'
options:
- '<class ''set''>'
- '<class ''dict''>'
- '报错'
- 'None'
answer: 1
explain: {} 在 Python 里表示空字典，不是空集合。要建空集合必须写 set()。这是最反直觉的一点。
```

```quiz
type: choice
q: '`a = {1, 2, 3}`，`b = {2, 3, 4}`，`a - b` 和 `b - a` 分别是什么？'
options:
- '{1} 和 {4}'
- '{1, 2, 3} 和 {2, 3, 4}'
- '{1, 4} 和 {1, 4}'
- '{4} 和 {1}'
answer: 0
explain: 差集是"在左边、不在右边"。a - b = {1}，b - a = {4}。差集不对称，方向不同结果不同。
```

```quiz
type: choice
q: 数据量很大、且需要频繁判断"某个元素在不在里面"时，为什么推荐用集合而不是列表？
options:
- '集合会自动排序，所以更快'
- '集合用哈希表，算一次就能定位，不用逐个比对'
- '集合的元素更少，所以更快'
- '列表的 in 操作会报错'
answer: 1
explain: 集合靠哈希表 —— 算一次元素的哈希值就能直接跳到对应位置查看，绝大多数情况一次命中。列表只能从头到尾逐个比对，元素越多越慢。
```

```quiz
type: choice
q: '需求：存一批"不允许重复"的城市名，且要频繁判断"某个城市在不在里面"。该选哪个容器？'
options:
- '列表，因为最灵活'
- '元组，因为不可变'
- '字典，因为按键取值快'
- '集合，去重且 in 判断快'
answer: 3
explain: 两个信号都指向集合：不允许重复（集合元素唯一）、频繁 in 判断（哈希表飞快）。字典虽然查找也快，但这里没有"值"要存，用字典浪费。
```

```quiz
type: choice
q: '`count = {"a": 3, "b": 2, "c": 1}`，`list(count.keys())` 和 `set(count)` 的关系最接近哪种说法？'
options:
- '两者完全相同，都是列表'
- '前者是键的列表，后者是键的集合（去重且无序）'
- '前者会报错，后者可以'
- '两者都只包含值，不包含键'
answer: 1
explain: count.keys() 是字典的键视图，list() 后变成键的列表；set(count) 则是把字典转成集合 —— 集合的元素正是字典的键（键本来就唯一），且集合无序。两者内容元素一致、顺序和类型不同。
```

## 第二部分 · 动手题

光记住概念不够，得能写出来。

```quiz
type: code
q: 有两个名单列表 `group_a = ["张三", "李四", "王五", "赵六"]` 和 `group_b = ["李四", "王五", "钱七"]`。请用集合运算找出：1) 两拨都有的（交集）；2) 只在 A 不在 B 的（差集）。各打印一行
starter: |
  group_a = ["张三", "李四", "王五", "赵六"]
  group_b = ["李四", "王五", "钱七"]

  set_a = set(group_a)
  set_b = set(group_b)

  # 求交集和差集并打印
tests:
- assert "{'李四', '王五'}" in __out or "'王五', '李四'" in __out
- assert "{'张三', '赵六'}" in __out or "'赵六', '张三'" in __out
hint: 交集用 &，差集（只在 A）用 -。集合顺序不固定，断言已兼容两种顺序。
explain: 答案：print("共同:", set_a & set_b) 和 print("只在A:", set_a - set_b)。考的是交集和差集两个运算符号，以及"集合无序"导致输出顺序不固定的事实。
```

```quiz
type: function
q: 写一个函数 `unique_ordered`，接收一个列表，返回**去重且保持原顺序**的列表。要求内部用集合辅助判断
func: unique_ordered
starter: |
  def unique_ordered(items):
      return []
cases: |
  [1, 2, 2, 3, 1] -> [1, 2, 3]
  ["a", "b", "a", "c", "b"] -> ["a", "b", "c"]
hint: seen = set(); result = []; 遍历 items，没见过就 add 进 seen 并 append 进 result。
explain: 答案：seen=set(); r=[]; for x in items: if x not in seen: seen.add(x); r.append(x); return r。这是"集合负责去重判断（O(1)快）+ 列表负责保序存储"的标准写法。
```
