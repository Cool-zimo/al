# 元组解包：一次给多个变量赋值

> 上一课说"元组的标志是逗号"。这一课讲这个逗号带来的最大便利 —— **把一个元组的多个值，同时交给多个变量**。
>
> 它是 Python 里最优雅的语法之一，也是"函数返回多个值"这件事能成立的原因。

## 一、一次给多个变量赋值

学过的基础写法是一个个来：

```python
x = 116.46
y = 39.92
```

但如果这两个数字本来就打包在一起，Python 允许你**一次性拆开**分别交给变量：

```python
x, y = (116.46, 39.92)
print(x)       # 116.46
print(y)       # 39.92
```

等号左边写**多个变量**，右边写一个**可拆的东西**（元组、列表都行），Python 会按顺序一一对应地赋值。

括号其实可以省略 —— 因为元组本来的标志就是逗号：

```python
x, y = 116.46, 39.92       # 完全等价于上一例
print(x, y)                # 116.46 39.92
```

⚠️ **翻车：两边数量对不上。**

```python
a, b, c = (1, 2)          # ✗ ValueError: not enough values to unpack (expected 3, got 2)
```

报错说得很清楚：你期待 3 个，但只给了 2 个。反过来多了也会报错：

```python
a, b = (1, 2, 3)          # ✗ ValueError: too many values to unpack (expected 2)
```

**左边变量的个数必须和右边元素个数完全一致。** 这是元组解包的硬性规则。

## 二、交换两个变量：最经典的用法

其他很多语言要交换两个变量的值，得**借一个临时变量**：

```python
# C / Java 风格
temp = a
a = b
b = temp
```

Python 一行就够：

```python
a = 10
b = 20
a, b = b, a
print(a, b)          # 20 10
```

怎么理解？等号右边 `b, a` 先被 Python 打包成一个元组 `(20, 10)`，**然后再拆开**分别赋给 `a` 和 `b`。

关键在于：**Python 是先算完右边整个元组，才动手改左边。** 所以不会出现"改了 a 之后 b 拿到的是新 a"这种自欺欺人的情况。它是**同时**完成的。

⚠️ **翻车：想当然地用一个中间变量写出 bug。**

有人以为 Python 的交换"只是语法糖"，于是手写成：

```python
a = 10
b = 20
a = b          # a 变成 20
b = a          # b 也变成 20 —— 完蛋，原来的 10 没了
print(a, b)    # 20 20
```

老老实实用 `a, b = b, a` 吧，Python 帮你保证正确性。

## 三、函数返回多个值

这是元组解包最实用的场景，也为第 5 章讲函数埋下伏笔。先看用法：

```python
def divide(n, d):
    quotient = n // d
    remainder = n % d
    return quotient, remainder       # 返回一个元组

q, r = divide(17, 5)
print("商:", q)      # 商: 3
print("余:", r)      # 余: 2
```

`return a, b` 在 Python 里**其实就是返回一个元组 `(a, b)`**，只是你没看见括号。上面的调用等价于：

```python
result = divide(17, 5)
print(result)        # (3, 2) —— 真的是个元组
print(type(result))  # <class 'tuple'>
```

这就是为什么函数能"返回多个值" —— 它并不是真的返回了多个，而是**打包成一个元组**返回，调用方再解包接住。

一个更贴合实际的例子：

```python
def analyze(nums):
    return min(nums), max(nums), sum(nums) / len(nums)

low, high, avg = analyze([87, 92, 78, 65, 100])
print(low, high, avg)      # 65 100 84.4
```

⚠️ **翻车：只用一个变量接住"多返回值"。**

```python
def divide(n, d):
    return n // d, n % d

r = divide(17, 5)
print(r[0])          # 3 —— 能拿到，但写法别扭
print(r)             # (3, 2) —— 它是一个元组，不是两个分开的数
```

用**一个**变量接住时，那个变量就成了整个元组。功能上没问题，但如果你**以为**它是商、却拿去当数字用，就错了：

```python
r = divide(17, 5)
print(r + 1)        # ✗ TypeError: can only concatenate tuple and int
```

所以习惯上：函数返回多个值，就用多个变量接住。实在只想取其中一个，记得它是个元组、按索引取。

## 四、`*` 收集剩余：把剩下的打包

有时你只想拿走前几个，剩下的"有多少算多少"一起收下：

```python
first, *rest = (10, 20, 30, 40, 50)
print(first)        # 10
print(rest)         # [20, 30, 40, 50] —— 注意是列表
```

`*rest` 把"剩下的全部"收进一个**列表**里。

`*` 也能放在中间或末尾：

```python
a, *middle, z = (1, 2, 3, 4, 5)
print(a)            # 1
print(middle)       # [2, 3, 4]
print(z)            # 5
```

```python
a, b, *rest = (1, 2, 3, 4)
print(a, b)         # 1 2
print(rest)         # [3, 4]
```

⚠️ **翻车：`*` 变量没收到东西，变成空列表。**

```python
a, *rest = (7,)          # 只有 1 个元素
print(rest)              # [] —— 空的列表，不报错
```

不报错，但 `rest` 会是空列表 `[]`。写代码时要意识到这一点 —— 别以为 `rest` 里一定有东西。

⚠️ **翻车：一个赋值里写两个 `*` 变量。**

```python
*a, *b = (1, 2, 3)      # ✗ SyntaxError: multiple starred expressions
```

Python 不知道"剩下的"该归谁，所以一个赋值里**只能有一个 `*` 变量**。

## 小结

- 元组解包：`a, b = (x, y)`，左边变量数必须等于右边元素数
- 交换变量用 `a, b = b, a`，一行搞定，Python 保证同时完成
- 函数"返回多个值"就是返回元组，调用方用多个变量接住
- `*` 变量收集剩余元素，装进**列表**，一个赋值里只能有一个 `*`

explain: 答案就是 a, b = b, a。这是 Python 最优雅的语法之一 —— 右边先算成 (20, 10) 这个元组，再拆开赋给 a、b，所以是"同时"的，不会互相覆盖。
