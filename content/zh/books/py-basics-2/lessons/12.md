# 字典的增删改查

> 上一课学会了创建字典和按键取值。这一课把它当成一个可变的容器来用 —— 加一条、改一条、删一条、查一条，以及几个专门为了"省心"设计的方法。

## 一、查：按键取值

最基本的方式是中括号：

```python
scores = {"张三": 92, "李四": 78}
print(scores["张三"])        # 92
```

但这种方式有个硬伤 —— **键不存在就报错**：

```python
print(scores["王五"])        # ✗ KeyError: '王五'
```

⚠️ **翻车：没检查就直接取值。**

这是字典最常见的错误来源。想安全一点，有两种办法。

### 办法一：先用 `in` 判断

```python
if "王五" in scores:
    print(scores["王五"])
else:
    print("没有这个人的成绩")
```

`in` 在字典里检查的是**键在不在**，不是值。

### 办法二：用 `get`，给个默认值

```python
value = scores.get("王五", "查无此人")
print(value)                # 查无此人
```

`get(键, 默认值)` 的规矩是：**键存在就返回对应的值，键不存在就返回你给的那个默认值**。

```python
print(scores.get("张三", 0))     # 92 —— 存在，返回真实值
print(scores.get("王五", 0))     # 0 —— 不存在，返回默认值
```

**不写默认值的时候，`get` 返回 `None`：**

```python
print(scores.get("王五"))        # None
```

⚠️ **翻车：把 `get` 的默认值当成"会写入字典"。**

```python
v = scores.get("王五", 0)
print(scores)        # {'张三': 92, '李四': 78} —— 字典没变！
```

`get` **只读**，它不会把"王五: 0"这条写进字典。它只是"找不到时返回个备胎给你"，字典本身一字未改。

## 二、增与改：中括号赋值

字典里**加一条**和**改一条**，写法完全一样 —— 都是中括号赋值：

```python
scores = {"张三": 92}
scores["李四"] = 78        # 键不存在 → 新增
scores["张三"] = 100       # 键已存在 → 修改
print(scores)              # {'张三': 100, '李四': 78}
```

**判断标准只有一个：键在不在。** 在就改，不在就加。

⚠️ **翻车：以为"新增"和"修改"是两种方法。**

不用记两套。记住一句话：**中括号赋值，有则改、无则加。** 一个写法通吃。

## 三、`setdefault`：找不到就先写进去

这是一个很实用、也很"贴心"的方法。场景是：

> 我想取某个键的值；如果它不存在，就先给它一个默认值，再取。

普通写法是 `if` 判断加赋值，两行：

```python
words = {}
word = "apple"
if word not in words:
    words[word] = 0
words[word] += 1
```

用 `setdefault` 一行搞定：

```python
words = {}
word = "apple"
words.setdefault(word, 0)
words[word] += 1
print(words)          # {'apple': 1}
```

`setdefault(键, 默认值)` 的逻辑：**键存在就什么都不做、返回已有的值；键不存在就写入"键: 默认值"，返回默认值。**

再跑一次同样的代码：

```python
words.setdefault("apple", 0)      # apple 已存在，不动，返回 100（已有的值）
words["apple"] += 1
print(words)                       # {'apple': 101}
```

注意它返回的是**字典里实际存的值**，不一定是你的默认值。

⚠️ **翻车：给 setdefault 的默认值是个可变对象，且被反复使用。**

```python
d = {}
d.setdefault("tags", []).append("python")
d.setdefault("tags", []).append("java")
print(d)          # {'tags': ['python', 'java']}
```

这个例子**碰巧能用**，因为每次 `setdefault` 发现键已存在就返回同一个列表。但如果你先拿到这个列表、再用别的名字改它，就可能绕开 `setdefault`：

```python
lst = d.setdefault("tags", [])
lst.append("go")
print(d)          # {'tags': ['python', 'java', 'go']}
```

读的时候没问题，写的时候要清楚：**setdefault 只在"键不存在"时才创建默认值**，存在时就原样返回。

## 四、更新：`update`

要把一个字典的内容合并进另一个，用 `update`：

```python
prices = {"苹果": 5.5, "牛奶": 8.0}
prices.update({"牛奶": 7.5, "面包": 3.5})
print(prices)      # {'苹果': 5.5, '牛奶': 7.5, '面包': 3.5}
```

已有的键会被覆盖，没有的键会被加进来。相当于"批量赋值"。

⚠️ **翻车：以为 `update` 会保留两边的值、或者会合并成列表。**

```python
a = {"x": 1}
a.update({"x": 2})
print(a)           # {'x': 2} —— 直接覆盖，不是合并
```

`update` 就是覆盖式赋值，同键后面的赢。它不会把两个值凑成列表，也不会报错。

## 五、删：`pop` 与 `del`

### `pop(键)`：删掉并返回

```python
scores = {"张三": 92, "李四": 78}
score = scores.pop("张三")
print(score)        # 92
print(scores)       # {'李四': 78}
```

`pop` 返回被删掉的值 —— 这一点和列表的 `pop` 类似。

⚠️ **翻车：pop 不存在的键会报错。**

```python
scores.pop("王五")      # ✗ KeyError: '王五'
```

想安全，给个默认值：

```python
v = scores.pop("王五", None)
print(v)               # None —— 不报错
```

`pop(键, 默认值)` 和 `get` 的脾气一样：**找不到就返回默认值，且字典不变。**

### `del`：删掉、不要返回值

```python
del scores["张三"]
print(scores)          # {'李四': 78}
```

`del` 只是删，不返回什么。键不存在同样报错：

```python
del scores["王五"]     # ✗ KeyError: '王五'
```

| 想做的事 | 用哪个 |
|---|---|
| 删掉并返回值 | `d.pop(键)` |
| 删掉就行 | `del d[键]` |
| 安全删除、别报错 | `d.pop(键, 默认值)` |

⚠️ **翻车：写成 `d.pop()` 不传参数。**

```python
d = {"a": 1}
d.pop()                 # ✗ TypeError: pop expected at least 1 argument
```

字典的 `pop` **必须指定键**（它不像列表的 `pop()` 默认删最后一个，因为字典"最后一个"的概念并不可靠）。

## 小结

- 查：中括号 `d[k]` 找不到就报错；`d.get(k, 默认值)` 找不到返回默认值、且不改字典
- 增与改：`d[k] = v`，有则改、无则加
- `setdefault(k, v)`：键不存在才写入默认值，返回字典里的实际值
- `update`：批量合并，同键覆盖
- 删：`pop` 返回被删的值，`del` 只删不返；都不传默认值时会 KeyError
