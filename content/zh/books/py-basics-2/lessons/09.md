# 字符串格式化：把数据塞进字符串里

> 前面的课里你大概写过这样的代码：
>
> ```python
> print("总价是 " + str(price) + " 元，打了 " + str(discount) + " 折")
> ```
>
> 一堆 `+` 和 `str()` 混在一起，看着就累。这一课讲**格式化** —— 用更干净的方式把变量塞进字符串。

## 一、`%` 格式化：老办法，已经过时

这是最早的办法，写起来像 C 语言的 `printf`：

```python
name = "张三"
age = 28
s = "我叫 %s，今年 %d 岁" % (name, age)
print(s)          # 我叫 张三，今年 28 岁
```

`%s` 表示"这里放字符串"，`%d` 表示"这里放整数"，最后用 `%` 接一个元组提供值。

它有两个明显的问题：

1. **记符号**：`%s`、`%d`、`%f`、`%r`……一大堆占位符，用错就报错
2. **顺序死板**：值的顺序必须和占位符一一对应，插一个新值要重新数位置

```python
"总价 %.2f 元，折扣 %d 折" % (128.567, 8)
# 总价 128.57 元，折扣 8 折
```

`%.2f` 表示"浮点数保留 2 位小数"。能干活，但写起来别扭。

⚠️ **翻车：占位符和值的数量对不上。**

```python
"我叫 %s，今年 %d 岁" % ("张三",)
# ✗ TypeError: not enough arguments for format string
```

右边少给一个值就报错。这种错误很常见，尤其是在字符串里插了很多变量、又反复调整文案的时候。

**结论：`%` 能用，但不推荐。** 老代码里还会见到，自己写新代码请用后面两种方法。

## 二、`str.format`：中间的方案

`format` 用 `{}` 当占位符，用 `.format()` 提供值：

```python
name = "张三"
age = 28
s = "我叫 {}，今年 {} 岁".format(name, age)
print(s)          # 我叫 张三，今年 28 岁
```

比 `%` 干净一些：占位符统一是 `{}`，不用记 `%s`、`%d`。

还能给占位符编号，调整顺序：

```python
"{} 今年 {} 岁，{} 是男生".format("张三", 28, "他")
# 张三 今年 28 岁，他是男生

"{0} {0} {1}".format("嗨", "呀")
# 嗨 嗨 呀 —— 同一个位置可以重复使用
```

也能用**命名参数**：

```python
"我叫 {name}，来自 {city}".format(name="李四", city="上海")
# 我叫 李四，来自 上海
```

这种方式在模板类字符串里可读性很好。

⚠️ **翻车：大括号忘了写 format。**

```python
s = "我叫 {}，今年 {} 岁"
print(s)          # 我叫 {}，今年 {} 岁 —— 大括号原样留下
```

`{}` 只是占位符，**必须**跟 `.format()` 才会被替换。忘了调用就原样打印了。

## 三、f-string：现在最推荐的写法

Python 3.6 引入的 f-string，是目前最常用、最直观的方式。只要在字符串前加个 `f`，就能直接在 `{}` 里写**变量名**：

```python
name = "张三"
age = 28
s = f"我叫 {name}，今年 {age} 岁"
print(s)          # 我叫 张三，今年 28 岁
```

变量名直接写进 `{}`，不用再在末尾摆一堆值。**可读性是最好的**，变量和它在字符串里的位置一眼对应。

⚠️ **翻车：忘了加 f 前缀。**

```python
name = "张三"
s = "我叫 {name}"      # 没加 f
print(s)               # 我叫 {name} —— 原样输出
```

这是最高频的错误。养成习惯：**字符串里一旦出现 `{}`，前面一定加 `f`。**

## 四、f-string 的常用写法

### 1. 放表达式

`{}` 里**不只能放变量，还能放任意表达式**：

```python
price = 128.5
count = 3
print(f"总价 {price * count} 元")       # 总价 385.5 元
print(f"翻倍 {count * 2}")             # 翻倍 6
```

```python
name = "alice"
print(f"大写：{name.upper()}")          # 大写：ALICE
```

⚠️ **翻车：在 {} 里写赋值语句。**

```python
n = 10
f"{n = }"        # 这是 Python 3.8+ 的"调试表达式"，输出 'n = 10'
f"{n = 20}"      # ✗ SyntaxError
```

普通的 `{}` 里只能放表达式，不能放 `n = 20` 这种赋值。想改变量得在 f-string 外面做。

### 2. 对齐和宽度

做表格输出时很有用：

```python
names = ["张三", "李四", "王五"]
scores = [92, 78, 100]
for n, s in zip(names, scores):
    print(f"{n:4} {s:4}")
```

```
张三   92
李四   78
王五   100
```

`{n:4}` 表示"占 4 个字符宽，右对齐"。想左对齐就加个 `<`：

```python
print(f"{'张三':<4}|")      # 张三  |
print(f"{'张三':>4}|")      #    张三|
```

`<` 左对齐、`>` 右对齐、`^` 居中。中间的数是**总宽度**（按字符数算，中文占 2 个宽度时会略显不齐，这点要心里有数）。

### 3. 小数位

```python
pi = 3.1415926
print(f"圆周率约等于 {pi:.2f}")      # 圆周率约等于 3.14
print(f"{pi:.4f}")                   # 3.1416
```

`:.2f` 表示"按浮点数显示，保留 2 位小数"。这是 f-string 里最常用的一个格式说明符。

还能同时指定宽度和小数位：

```python
price = 12.5
print(f"¥{price:>8.2f}")      # ¥   12.50
```

⚠️ **翻车：对整数用 `:.2f`。**

```python
n = 100
f"{n:.2f}"        # '100.00' —— 不报错，但加了两位小数
```

不会报错，但结果变成了 `100.00`，可能不符合预期。想保留小数位，得先确认那个变量**本来就是浮点数**。

### 4. 千分位分隔

```python
n = 1234567
print(f"{n:,}")          # 1,234,567
print(f"{n:_}")          # 1_234_567
```

逗号或下划线都能当千分位分隔符，处理金额、大数字时很实用。

## 五、三种方式怎么选

| 方式 | 写法 | 推荐度 |
|---|---|---|
| `%` 格式化 | `"%s %d" % (a, b)` | 已过时，不推荐 |
| `str.format` | `"{} {}".format(a, b)` | 还行，老代码常见 |
| **f-string** | `f"{a} {b}"` | **首选** |

日常写代码，无脑选 f-string 就行。它的好处是**变量和占位符在同一个地方**，改文案时不用在字符串和 `.format()` 的参数列表之间来回跳转。

⚠️ **翻车：f-string 里想放一个真的 `{` 字符。**

```python
f"字典的键用 {{ 和 }} 包裹"      # 正确：用两个 { 表示一个 {
# 输出：字典的键用 { 和 } 包裹
```

`{{` 会被解释成一个字面量的 `{`。这在写 JSON、模板类文本时很常见。

## 小结

- `%` 格式化已过时，占位符符号多、顺序死板
- `str.format` 用 `{}` 占位，可读性一般，老代码常见
- **f-string** 是首选：字符串前加 `f`，`{}` 里直接写变量或表达式
- 常用格式：`:<4` 左对齐、`:>8.2f` 右对齐保留 2 位小数、`:,` 千分位
- 想输出字面的 `{` 要写成 `{{`
