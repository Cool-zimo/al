# 遍历与常用操作：把列表真正用起来

> 前面四课解决了"怎么装、怎么取、怎么改"。这一课解决最后一件事：**怎么对整堆数据批量干活**。
>
> 学完这课，你就能写出"录入一堆成绩 → 统计 → 排名"这种真正有用的程序了。

## 一、遍历：把每个元素拿出来做一遍

假设要打印班上每个人的成绩，挨个写是这样的：

```python
scores = [87, 92, 78]

print(scores[0])
print(scores[1])
print(scores[2])
```

三个还能忍，三百个就写不完了。**遍历**解决这个问题：

```python
scores = [87, 92, 78]

for s in scores:
    print(s)
```

```
87
92
78
```

读法很直白：**对于 scores 里的每一个 s，做下面的事。**

`s` 是你自己起的名字，每一轮它会变成列表里的下一个元素。叫 `score`、`x`、`item` 都行。

```
第 1 轮:  s = 87  → print(87)
第 2 轮:  s = 92  → print(92)
第 3 轮:  s = 78  → print(78)
（列表走完了，循环结束）
```

**循环的次数 = 列表的长度**，你不用写 `range(len(...))` 去数。这也是它在基础 1 第 23 课之后又一次出现 —— 只不过那次数的是数字，这次走的是列表。

⚠️ **翻车：忘了冒号或忘了缩进。**

```python
for s in scores      # ✗ SyntaxError: expected ':'
    print(s)
```

```python
for s in scores:
print(s)             # ✗ IndentationError: expected an indented block
```

这两个错在基础 1 第 16 课讲过，写循环时依然是最常见的两个。

## 二、遍历时做点正经事

光打印没意思。遍历的价值在于**对每个元素做处理**：

```python
scores = [87, 92, 78]

total = 0
for s in scores:
    total = total + s

print("总分:", total)
print("平均分:", total / len(scores))
```

```
总分: 257
平均分: 85.66666666666667
```

这就是第 1 课开头那段代码的完整版。注意 `total = 0` **必须在循环外面** —— 写进循环里的话每轮都清零，最后只剩最后一个数。

**累加套路**（基础 1 第 21 课学过，这里用在列表上）：

```python
total = 0            # ① 循环外，准备容器
for s in scores:     # ② 遍历
    total = total + s    # ③ 往里加
```

## 三、in：问一句"在不在"

```python
names = ["小明", "小红", "小刚"]

print("小明" in names)      # True
print("小李" in names)      # False
```

`in` 判断一个元素**在不在列表里**，结果是布尔值 `True` / `False`。

配合 `not` 可以反过来问：

```python
if "小李" not in names:
    print("查无此人")
```

**什么时候用 `in`？** 典型的两个场景：

**① 防止重复录入。**

```python
names = ["小明", "小红"]

new_name = "小明"
if new_name in names:
    print("已经存在了")
else:
    names.append(new_name)
```

**② 删除前先确认存在**（第 3 课说过：直接 `remove` 不存在的东西会 `ValueError`）。

⚠️ **`in` 对列表是"逐个比对"**，列表越长越慢。现在数据量小无所谓，等你处理几万条数据时，就该用第 3 章的集合或字典了 —— 那是它们存在的主要理由之一。

## 四、四个不用自己写的统计函数

这些活儿 Python 已经给你做好了：

```python
scores = [87, 92, 78, 95, 61]

print(len(scores))      # 5     有几个
print(sum(scores))      # 413   加起来是多少
print(max(scores))      # 95    最大的是几
print(min(scores))      # 61    最小的是几
```

| 函数 | 作用 | 空列表会怎样 |
|---|---|---|
| `len(x)` | 元素个数 | 返回 0 |
| `sum(x)` | 求和 | 返回 0 |
| `max(x)` | 最大值 | ⚠️ **报错** ValueError |
| `min(x)` | 最小值 | ⚠️ **报错** ValueError |

注意最后两个：**对空列表求最大值会崩**。所以不确定有没有数据时先判一下：

```python
scores = []
if len(scores) > 0:
    print("最高分:", max(scores))
else:
    print("还没有成绩")
```

⚠️ `max` / `min` 要求元素之间**能比大小**。混装数字和字符串会报错：

```python
mixed = [87, "小明"]
print(max(mixed))      # ✗ TypeError: '>' not supported between 'str' and 'int'
```

## 五、排序：sort 与 sorted（本课最大的坑）

两个都能排序，但行为**完全不同**：

```python
scores = [87, 92, 78]

scores.sort()          # 方法：直接改原列表
print(scores)          # [78, 87, 92]
```

```python
scores = [87, 92, 78]

ordered = sorted(scores)     # 函数：返回一个新列表
print(ordered)               # [78, 87, 92]
print(scores)                # [87, 92, 78]  ← 原列表没变
```

| | 写法 | 改原列表吗 | 返回值 |
|---|---|---|---|
| `sort()` | 方法，跟在后面 | ✅ **改** | `None` |
| `sorted()` | 函数，包在外面 | ❌ 不改 | 排好的**新列表** |

⚠️ **翻车之王：拿 sort() 的返回值。**

```python
scores = [87, 92, 78]
result = scores.sort()
print(result)      # None  ← 什么都没有！
print(scores)      # [78, 87, 92]  ← 排序结果在原列表里
```

`sort()` 像 `append()` 一样，**只干活不还东西**。想拿到排序结果就用 `sorted()`，或者 sort 完打印原列表。

**怎么选？**

- 想保留原来的顺序 → `sorted(scores)`
- 不需要原顺序了，直接排 → `scores.sort()`

### 倒序

两个都支持 `reverse=True`：

```python
scores = [87, 92, 78]

print(sorted(scores, reverse=True))     # [92, 87, 78]  从大到小
```

```python
scores = [87, 92, 78]
scores.sort(reverse=True)
print(scores)      # [92, 87, 78]
```

⚠️ 注意 `reverse=True` 是**排序的倒序**，而第 4 课讲的 `[::-1]` 是**把现有顺序整个反过来** —— 两者在处理"未排序的列表"时结果完全不同：

```python
nums = [3, 1, 2]
print(nums[::-1])                    # [2, 1, 3]  ← 只是倒过来
print(sorted(nums, reverse=True))    # [3, 2, 1]  ← 真正从大到小排
```

## 六、实战：成绩单统计器

把这一课的东西串起来。需求：

> 有一堆成绩，输出：人数、总分、平均分、最高分、最低分，以及从高到低的排名。

```python
scores = [87, 92, 78, 95, 61, 88]

print("人数:", len(scores))
print("总分:", sum(scores))
print("平均分:", round(sum(scores) / len(scores), 1))
print("最高分:", max(scores))
print("最低分:", min(scores))

ranked = sorted(scores, reverse=True)
print("排名:", ranked)
```

```
人数: 6
总分: 501
平均分: 83.5
最高分: 95
最低分: 61
排名: [95, 92, 88, 87, 78, 61]
```

（`round(x, 1)` 是保留 1 位小数，纯粹为了好看，不影响逻辑。）

**这段代码最好的地方是：它跟有多少个成绩完全无关。** 往 `scores` 里加十个数，一个字都不用改。

再加一个实用功能 —— 找出**不及格**的：

```python
scores = [87, 92, 78, 95, 61, 88]

failed = []
for s in scores:
    if s < 60:
        failed.append(s)

print("不及格人数:", len(failed))
print("不及格的分数:", failed)
```

这是本课程反复出现的核心套路：**遍历 → 判断 → 装进新列表**。筛选数据全靠它。

（第 3 课讲过：别在遍历时删原列表，要建新的。这里就是这个原则的正用。）

## 七、本课速查表

| 想干什么 | 怎么写 |
|---|---|
| 每个元素做一遍 | `for x in 列表:` |
| 有几个元素 | `len(列表)` |
| 加起来 | `sum(列表)` |
| 最大 / 最小 | `max(列表)` / `min(列表)` |
| 在不在里面 | `x in 列表` |
| 排序（改原列表） | `列表.sort()` |
| 排序（要新列表） | `sorted(列表)` |
| 从大到小 | 加 `reverse=True` |

```quiz
type: code
q: 列表 `nums = [4, 7, 1, 9, 3]`。请打印其中的最大值和最小值（各占一行）
starter: |
  nums = [4, 7, 1, 9, 3]

  # 打印最大值
  print(max(nums))

  # 打印最小值

tests:
- assert "9" in __out
- assert "1" in __out
hint: max 是最大，min 是最小。两个都是函数，把列表包在括号里。
explain: 补的是 print(min(nums))。这两个名字最容易记反 —— 记法：min 是 minimum（最小），max 是 maximum（最大），都只有 3 个字母的缩写但含义相反。另外别写成 nums.max()，它们是函数不是方法。
```

## 本节测验

```quiz
type: choice
exam: true
q: 关于 `sort()` 和 `sorted()`，说法正确的是？
options:
- 两者都直接修改原列表，都不返回新列表
- sort() 修改原列表并返回 None；sorted() 不改原列表，返回排好序的新列表
- sorted() 修改原列表；sort() 返回新列表
- 两者完全一样，只是写法不同
answer: 1
explain: 这是本课最容易踩的坑。sort() 是「就地排序」，改的是原列表自己，所以返回 None —— 拿 result = scores.sort() 只会得到 None。sorted() 是「复印一份再排」，原列表纹丝不动。想保留原顺序就用 sorted()。
```
