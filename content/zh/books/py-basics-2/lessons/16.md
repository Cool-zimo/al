# 集合是什么：去重、判断、无序

> 前面学了列表、元组、字典。这一课讲第四种内置容器 —— **集合（set）**。
>
> 它的三个特性是：**元素不重复、查找飞快、没有顺序**。搞清这三点，你就知道什么时候该用它。

## 一、创建集合

集合用花括号，元素之间用逗号：

```python
nums = {1, 2, 3, 4}
print(nums)          # {1, 2, 3, 4}
print(type(nums))    # <class 'set'>
```

看起来和字典一样用 `{ }`，但**集合没有冒号、没有键值对**。

⚠️ **翻车：用 `{}` 想建空集合。**

```python
s = {}
print(type(s))      # <class 'dict'> —— 它是空字典！
```

`{}` 表示的是**空字典**。要建空集合得用 `set()`：

```python
s = set()
print(type(s))      # <class 'set'>
print(len(s))       # 0
```

记住：**`{}` 是字典，`set()` 才是集合**。这是 Python 最反直觉的一点。

### 从其他序列转换

```python
s1 = set([1, 2, 2, 3, 3, 3])
print(s1)               # {1, 2, 3}

s2 = set("hello")
print(s2)               # {'h', 'e', 'l', 'o'} —— 注意 l 只剩一个
```

`set(序列)` 会**去掉重复元素**，这就是集合最经典的用途 —— **去重**。

## 二、特性一：元素不重复

集合里**同一个元素只能出现一次**。你加十次，它还是只有一个：

```python
s = {1, 2, 3}
s.add(2)            # 2 已存在，什么也不发生
s.add(2)
print(s)            # {1, 2, 3}
```

`add(元素)` 是往集合里加一个元素。已存在就忽略，不报错。

⚠️ **翻车：以为 add 和列表的 append 一样会允许重复。**

```python
s = set()
s.add("北京")
s.add("北京")
print(len(s))       # 1 —— 不是 2
```

集合天然去重。所以如果你需要"允许重复的一批东西"，用列表；需要"每个只留一份"，用集合。

## 三、特性二：查找飞快

集合最厉害的地方是 **`in` 判断极快** —— 不管集合里有一百个还是一百万个元素，判断"在不在"几乎一样快。

```python
blocked = {"spam", "ads", "virus"}
print("spam" in blocked)       # True
print("hello" in blocked)      # False
```

这个"飞快"背后的原理是第 18 课的重点。现在先记住**用法和体感**：用它做"白名单""黑名单""已访问过"这种判断非常合适。

```python
vip = {"张三", "李四", "王五"}
name = "张三"
if name in vip:
    print("欢迎 VIP 用户")
else:
    print("普通用户")
```

⚠️ **翻车：用列表装"黑名单"做判断。**

```python
blocked = ["spam", "ads", "virus", ...]   # 一万个
"target" in blocked                       # 要逐个比对，很慢
```

元素一多，列表的 `in` 就变慢（第 18 课讲原因）。这种场景换成集合立刻变快。

## 四、特性三：没有顺序

集合里的元素**没有位置概念** —— 你不能按下标取值：

```python
s = {10, 20, 30}
print(s[0])          # ✗ TypeError: 'set' object is not subscriptable
```

集合不支持索引、切片、也没有"第一个"。它的元素只是"在里面"或"不在里面"。

⚠️ **翻车：以为集合会保持插入顺序。**

```python
s = {3, 1, 4, 1, 5, 9, 2, 6}
print(s)             # {1, 2, 3, 4, 5, 6, 9} —— 顺序不确定！
```

打印出来的顺序不保证和插入顺序一致（在部分 Python 版本/实现里可能看起来有序，但**逻辑上绝不能依赖**）。

想按顺序处理，先转成列表再排序：

```python
s = {3, 1, 4, 1, 5}
print(sorted(s))     # [1, 3, 4, 5] —— 排好序的列表
```

⚠️ **翻车：对集合下标赋值或切片。**

```python
s = {1, 2, 3}
s[0] = 10           # ✗ TypeError
s[1:3]              # ✗ TypeError
```

集合**既不能按下标改，也不能切片**。需要这些操作时，用列表。

## 五、什么时候该用集合

| 你的需求 | 用哪个 | 理由 |
|---|---|---|
| 一批东西，允许重复、有顺序 | 列表 | 需要 append、下标、切片 |
| 一批东西，每个只留一份 | **集合** | 自动去重 |
| 快速判断"在不在" | **集合** | in 极快 |
| 键值映射 | 字典 | 集合只有"在不在"，没有"对应的值" |

一个真实场景：统计网站 UV（独立访客），同一个用户多次访问只算一次：

```python
visitors = set()
visitors.add("192.168.1.1")
visitors.add("192.168.1.2")
visitors.add("192.168.1.1")      # 重复，忽略
visitors.add("192.168.1.3")
print(len(visitors))             # 3 —— 独立访客 3 个
```

如果换成列表，`len` 会算成 4，就错了。

⚠️ **翻车：想保留"第一次出现的顺序"却用了集合。**

```python
items = ["苹果", "香蕉", "苹果", "橙子"]
seen = set()
result = []
for x in items:
    if x not in seen:
        seen.add(x)
        result.append(x)
print(result)          # ['苹果', '香蕉', '橙子']
```

想"既去重又保序"，得用集合辅助、列表存结果。纯集合做不到保序。

## 小结

- 集合用 `{1, 2, 3}` 创建；**`{}` 是空字典，`set()` 才是空集合**
- 三大特性：元素不重复、查找飞快、没有顺序
- 集合不能按下标取值、不能切片
- 最典型用途：去重、黑名单/白名单判断、独立访客统计
- 集合的键也必须可哈希（同字典），所以列表不能放进集合
