# 序列的共性：list、tuple、str 是一家人

> 前面四课分别学了列表、元组、字符串。你大概已经感觉到它们"很像" —— 都能按下标取值、都能切片、都能算长度。
>
> 这一课把它们**统一起来**讲：这三种类型都属于"序列"，共享一套操作。学会这套共性，你一次就掌握了三样东西。

## 一、什么是"序列"

Python 把"一排有序的元素"抽象成一种概念，叫**序列（sequence）**。列表、元组、字符串都是序列的具体类型。

判断一个东西是不是序列，看它**支不支持这几件事**：按下标取值、切片、求长度、判断是否包含。

```python
a = [10, 20, 30]          # 列表
b = (10, 20, 30)          # 元组
c = "102030"              # 字符串
```

这三种东西，下面的操作**全都能用**。

## 二、共同的六件事

### 1. 按下标取值 `[i]`

```python
print([10, 20, 30][0])        # 10
print((10, 20, 30)[1])        # 20
print("hello"[4])             # o
```

都从 0 开始，都支持负索引（-1 是最后一个）。

### 2. 切片 `[start:stop]`

```python
print([10, 20, 30, 40][1:3])      # [20, 30]
print((10, 20, 30, 40)[1:3])      # (20, 30)
print("hello world"[6:])          # world
```

切片"前闭后开"的规则三者完全一致。注意：**切出来的类型还是原来的类型** —— 列表切片是列表，元组切片是元组，字符串切片是字符串。

### 3. 求长度 `len()`

```python
print(len([10, 20, 30]))      # 3
print(len((1, 2)))            # 2
print(len("北京"))            # 2
```

`len` 是**函数**，不是方法，所以写法永远是 `len(x)`，不是 `x.len()`。

### 4. 成员判断 `in`

```python
print(20 in [10, 20, 30])         # True
print("北" in "北京")             # True
print(5 in (1, 2, 3))             # False
```

⚠️ **翻车：字符串里的 `in` 是"子串"判断。**

```python
print("cd" in "abcdef")       # True —— 子串存在
```

字符串的 `in` 检查的是"有没有这个子串"，而不是"有没有这个字符"。这跟列表里"检查某个元素在不在"略有差别，别混了。

### 5. 拼接 `+`

```python
print([1, 2] + [3, 4])        # [1, 2, 3, 4]
print((1, 2) + (3, 4))        # (1, 2, 3, 4)
print("ab" + "cd")            # abcd
```

**类型必须一致**：列表只能和列表拼，不能和元组拼，也不能和字符串拼。

```python
[1, 2] + (3, 4)          # ✗ TypeError: can only concatenate list to list
"1" + 2                  # ✗ TypeError: can only concatenate str to str
```

要拼接不同类型的，先转成同一个类型：

```python
[1, 2] + list((3, 4))    # [1, 2, 3, 4]
str(1) + "2"             # "12"
```

### 6. 重复 `*`

```python
print([0] * 4)           # [0, 0, 0, 0]
print("ab" * 3)          # ababab
print((1, 2) * 2)        # (1, 2, 1, 2)
```

`*` 把序列重复若干次。**注意**：列表重复时，元素是**同一个对象**被重复引用，这点在元素是可变对象时会埋雷：

```python
rows = [[]] * 3
rows[0].append(1)
print(rows)              # [[1], [1], [1]] —— 三个子列表其实是同一个！
```

三个 `[]` 是同一个列表对象，改一个，三个都变。想建"互不相干"的多行，用列表推导式：

```python
rows = [[] for _ in range(3)]
rows[0].append(1)
print(rows)              # [[1], [], []]
```

⚠️ **翻车：用 `[[]] * n` 建二维列表。**

这是 Python 经典陷阱。列表推导式 `[[] for _ in range(n)]` 每次循环都新建一个 `[]`，才是你真正想要的效果。

## 三、三者怎么选

共性讲完，该讲**差异**了 —— 因为正是差异决定了"该用谁"。

| 特性 | list 列表 | tuple 元组 | str 字符串 |
|---|---|---|---|
| 可不可改 | 能 | 不能 | 不能 |
| 存什么 | 同类/异类都行 | 异类字段 | 字符 |
| 有 `append` 吗 | 有 | 没有 | 没有 |
| 能当字典的键吗 | 不能 | 能 | 能 |
| 字面量 | `[ ]` | `( )` | `" "` |

给一个判断流程：

1. **装的是字符文本？** → 用 `str`
2. **数据需要增删改？** → 用 `list`
3. **数据是固定的字段、不该被改、可能要当键？** → 用 `tuple`
4. **不确定？** → 默认 `list`，它最灵活

三个真实场景：

```python
# 场景一：购物车里的商品，随时会加会删
cart = ["苹果", "牛奶", "面包"]      # list

# 场景二：一条坐标记录，创建后不该变
point = (116.46, 39.92)             # tuple

# 场景三：一句话
greeting = "你好，欢迎光临"          # str
```

再补一个常见的组合用法 —— 列表里装元组，既灵活又有结构：

```python
# 一个班级的成绩表：每个学生是 (姓名, 分数) 的元组，整体是可增删的列表
students = [("张三", 92), ("李四", 78), ("王五", 100)]
students.append(("赵六", 85))
print(students[0][1])      # 92
```

外层 `list` 负责"可增删"，内层 `tuple` 负责"每条记录结构固定"。这是 Python 里非常常见、非常地道的数据组织方式。

## 小结

- 列表、元组、字符串都是**序列**，共享 `[i]`、切片、`len`、`in`、`+`、`*` 六类操作
- 切片出来还是原来的类型；`len` 是函数不是方法
- 类型一致才能拼接：`[1]+[2]` 可以，`[1]+(2,)` 报错
- 用 `[[]]*n` 建二维列表是经典陷阱，用 `[[] for _ in range(n)]`
- 选类型：字符用 str，要改的用 list，固定字段/要当键的用 tuple
