# 作用域：函数里的变量外面看不见

> 前面几课我们零零散散提到了"局部变量"。这一课把**作用域**讲透：**变量在哪能看见、在哪看不见、函数里能不能改外面的变量**。
>
> 这一课的核心是：Python 有三条查找规则（**LEGB**），以及 `global` 这个"不得已才用"的开关。

## 一、局部变量：函数内部的"私人用品"

函数里定义的变量，只在函数内部有效，外面看不到：

```python
def calc():
    result = 10 + 20        # result 是局部变量
    return result

print(calc())               # 30
print(result)               # ✗ NameError: name 'result' is not defined
```

`result` 是 `calc` 的**局部变量**，函数执行完就"消失"了。函数外面根本不知道有这么个东西。

⚠️ **翻车：以为函数里定义的变量外面还能用。**

```python
def greet():
    message = "你好"

greet()
print(message)              # ✗ NameError: name 'message' is not defined
```

这是新手最常见的误解之一。**函数的作用就是"隔离"**：里面的东西外面看不到，外面的东西（默认）能看到（见下节）。

## 二、能读到外面的变量（但不能随便改）

函数**可以读**外部变量：

```python
tax_rate = 0.13

def calc_price(price):
    return price * (1 + tax_rate)        # 读到了外面的 tax_rate

print(calc_price(100))        # 113.0
```

但**不能随便改**：

```python
counter = 0

def increment():
    counter += 1            # ✗ UnboundLocalError: local variable 'counter' referenced before assignment

increment()
```

为什么？因为 Python 看到 `counter += 1` 里有"对 `counter` 赋值"，就判定 `counter` 是**局部变量**。而这一行要先读 `counter` 再加 1，局部变量此时还没赋值——于是 `UnboundLocalError`。

⚠️ **翻车：只读不报错，一赋值就炸。**

```python
counter = 0

def show():
    print(counter)          # 能读，正常打印 0

def add():
    counter += 1            # 报错
```

同一个名字 `counter`，只读时当外部变量用，一赋值就被当成局部变量。**Python 这条规则的判断依据是"函数体内有没有对它的赋值"，不是"你心里怎么想"**。

## 三、global：明确声明"我要改外面的那个"

想在函数里改全局变量，用 `global` 声明：

```python
counter = 0

def increment():
    global counter          # 声明：我要用的是外面的那个 counter
    counter += 1

increment()
increment()
print(counter)              # 2
```

`global counter` 的意思是："别给我新建局部变量，我要用的是全局那个。"

⚠️ **翻车：忘了写 global，结果改了个寂寞。**

```python
counter = 0

def increment():
    counter = 1             # 这是新建了一个局部变量，不是改全局的

increment()
print(counter)              # 0 —— 全局的没变
```

函数里 `counter = 1` 只是创建了一个局部变量，全局的 `counter` 还是 0。**这种 bug 最坑：不报错、逻辑也"看起来对"，只是外面毫无反应**。

## 四、global 能不用就不用

`global` 能解决问题，但**强烈不建议多用**。原因：

1. **可读性差**：你在一个函数里改了 `counter`，但在文件另一头看代码的人完全不知道
2. **难调试**：任何函数都可能改它，出 bug 时要逐个排查所有函数
3. **难测试**：函数的结果依赖外部状态，无法独立测试

```python
# 不推荐：靠全局变量传状态
total = 0

def add_price(p):
    global total
    total += p

add_price(100)
add_price(200)
print(total)        # 300
```

**推荐：把状态当参数传进去、把结果 return 回来。**

```python
def add_price(total, p):
    return total + p

total = 0
total = add_price(total, 100)
total = add_price(total, 200)
print(total)        # 300
```

一样的逻辑，但这个版本：`add_price` 的输入和输出都**明明白白**，谁都能看懂，也能单独测试。

⚠️ **翻车：多人协作时两个函数都在改同一个全局变量。**

```python
cart = []

def add_item(item):
    global cart
    cart.append(item)

def clear_cart():
    global cart
    cart = []          # 清掉了！

add_item("苹果")
clear_cart()
add_item("香蕉")
print(cart)            # ['香蕉'] —— 购物车只剩香蕉，但调用者以为还有苹果
```

全局变量是**共享状态**，一处改动影响所有使用者。项目一大，这种 bug 追都追不到。**99% 的情况，用 return 把结果交回来都比 global 干净**。

## 五、LEGB：Python 找变量的四条规则

Python 找名字的顺序是 **LEGB**：

- **L**ocal：先在自己函数里找
- **E**nclosing：再在"包着我的函数"里找（嵌套函数，第 26 课会讲）
- **G**lobal：再在全局找
- **B**uilt-in：最后是内置（`len`、`print`、`max` 等）

```python
x = "全局"

def outer():
    x = "外层"
    def inner():
        # x = "内层"          # 如果取消注释，打印"内层"
        print(x)              # 打印"外层"
    inner()

outer()
```

`inner` 里没有 `x`，往上找 `outer` 的 `x`，再往上才是全局。**就近原则，找到就停**。

⚠️ **翻车：不小心"遮蔽"了内置名。**

```python
id = 123        # 覆盖了内置函数 id()

obj = {"a": 1}
print(id(obj))  # ✗ TypeError: 'int' object is not callable
```

`id` 是 Python 内置函数（用来拿对象标识），你把它当变量名用了，内置的 `id` 就被"遮蔽"了。之后想调用内置 `id()` 就报错了。**不要用 `id`、`list`、`str`、`sum` 这些内置名当变量名**。

## 六、实战例子：购物车

**用全局变量版（不推荐）：**

```python
cart = []

def add(item):
    global cart
    cart.append(item)

def total(prices):
    global cart
    return sum(prices[i] for i in cart)

add("苹果")
add("香蕉")
```

**用 return 版（推荐）：**

```python
def add_item(cart, item):
    cart = cart + [item]          # 返回新列表
    return cart

def calc_total(cart, prices):
    return sum(prices[item] for item in cart)

cart = []
cart = add_item(cart, "苹果")
cart = add_item(cart, "香蕉")
```

第二种写法里，每个函数**输入是什么、输出是什么**一清二楚，没有任何"暗箱操作"。

## 小结

- 函数内部定义的变量是**局部变量**，外面看不见
- 函数能**读**外部变量，但**不能随便改**（赋值就被当成局部变量）
- 想改全局变量要写 `global`，但**能不用就不用**
- 不用 global 的替代方案：把状态当参数传进去，用 `return` 交回结果
- 全局变量是共享状态，多人协作时极易出 bug
- 变量查找顺序：**LEGB**（局部 → 外层 → 全局 → 内置），别用内置名当变量名
