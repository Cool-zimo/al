# 集合运算：交集、并集、差集、对称差集

> 集合最迷人的地方是它自带"数学课上的集合运算" —— 交集、并集、差集，一行搞定。
>
> 这一课把这些运算讲清楚，以及它们对应的方法写法。

## 一、交集 `&`：两拨人都有的

交集是"**两个集合里都有的元素**"。

```python
a = {"张三", "李四", "王五"}
b = {"李四", "王五", "赵六"}
print(a & b)        # {'李四', '王五'}
```

符号是 `&`（和按位与是同一个符号，但用在集合上就是交集）。

现实场景：找出两门课都选了的学生。

```python
math = {"张三", "李四", "王五", "赵六"}
english = {"李四", "王五", "钱七"}
both = math & english
print("两门都选的:", both)       # 两门都选的: {'李四', '王五'}
```

⚠️ **翻车：用列表做交集。**

```python
["张三", "李四"] & ["李四", "王五"]      # ✗ TypeError: unsupported operand type(s)
```

`&` 只认集合。列表要做交集得先转：用集合、或者列表推导式。

## 二、并集 `|`：两拨人加起来（去重）

并集是"**两个集合里所有的元素，重复只算一次**"。

```python
a = {"张三", "李四"}
b = {"李四", "王五"}
print(a | b)        # {'张三', '李四', '王五'}
```

符号是 `|`（竖线）。注意"李四"只出现一次 —— 并集自动去重。

现实场景：合并两个来源的用户名单。

```python
vip_2025 = {"张三", "李四"}
vip_2026 = {"李四", "王五", "赵六"}
all_vip = vip_2025 | vip_2026
print("所有 VIP:", all_vip)      # 所有 VIP: {'张三', '李四', '王五', '赵六'}
```

⚠️ **翻车：用 `+` 合并两个集合。**

```python
{"张三"} + {"李四"}      # ✗ TypeError: unsupported operand type(s) for +
```

集合不用 `+`，用 `|`。`+` 是列表/元组的拼接，两个语义不一样：拼接允许重复，并集去重。

## 三、差集 `-`：你有、我没有的

差集 `a - b` 是"**在 a 里、但不在 b 里**的元素"。

```python
all_students = {"张三", "李四", "王五", "赵六"}
paid = {"张三", "王五"}
unpaid = all_students - paid
print("还没缴费的:", unpaid)      # 还没缴费的: {'李四', '赵六'}
```

现实场景：**黑名单过滤**。

```python
all_users = {"alice", "bob", "charlie", "david"}
banned = {"bob", "david"}
active = all_users - banned
print(active)                   # {'alice', 'charlie'}
```

⚠️ **翻车：差集的顺序搞反。**

```python
a = {"张三", "李四"}
b = {"李四", "王五"}
print(a - b)        # {'张三'}
print(b - a)        # {'王五'} —— 方向不同，结果不同！
```

差集**不对称的**：`a - b` 和 `b - a` 是两码事。想想"谁减谁"再写。

## 四、对称差集 `^`：只在一边、不在两边的

对称差集是"**在 a 或 b 里、但不在两者里**的元素" —— 也就是"只出现一次"的那些。

```python
a = {"张三", "李四", "王五"}
b = {"李四", "王五", "赵六"}
print(a ^ b)        # {'张三', '赵六'}
```

现实场景：找出"只选了一门课"的学生（两门都选的、一门没选的都排除）。

```python
math = {"张三", "李四", "王五"}
english = {"王五", "赵六", "钱七"}
only_one = math ^ english
print("只选了一门的:", only_one)       # 只选了一门的: {'张三', '李四', '赵六', '钱七'}
```

`^` 可以理解为：**并集减去交集**，或者 `(a - b) | (b - a)`。

## 五、四个运算一览

| 运算 | 符号 | 含义 | 例子 `a={1,2,3}, b={2,3,4}` |
|---|---|---|---|
| 交集 | `&` | 都在 | `a & b` → `{2, 3}` |
| 并集 | `|` | 全都要，去重 | `a | b` → `{1, 2, 3, 4}` |
| 差集 | `-` | 在左不在右 | `a - b` → `{1}` |
| 对称差集 | `^` | 只在其中一边 | `a ^ b` → `{1, 4}` |

⚠️ **翻车：分不清差集和对称差集。**

```python
a - b       # {1}     —— 只在 a
a ^ b       # {1, 4}  —— 只在 a 或只在 b
```

差集是单向的，对称差集是双向的。记住"对称"两个字 = 两边都算。

## 六、对应的方法写法

除了符号，集合还提供了方法形式的运算（参数可以是任意可迭代对象，不一定是集合）：

| 运算 | 符号写法 | 方法写法 |
|---|---|---|
| 交集 | `a & b` | `a.intersection(b)` |
| 并集 | `a | b` | `a.union(b)` |
| 差集 | `a - b` | `a.difference(b)` |
| 对称差集 | `a ^ b` | `a.symmetric_difference(b)` |

```python
a = {1, 2, 3}
print(a.intersection([2, 3, 4]))      # {2, 3} —— 参数可以是列表
print(a.union("abc"))                 # {1, 2, 3, 'a', 'b', 'c'}
```

⚠️ **翻车：以为方法会修改原集合。**

```python
a = {1, 2, 3}
a.intersection([2, 3, 4])
print(a)          # {1, 2, 3} —— 没变
```

`intersection` 等方法**返回新集合**，不动原集合。想原地修改，用带 `update` 后缀的版本：

```python
a = {1, 2, 3}
a.intersection_update([2, 3, 4])
print(a)          # {2, 3} —— 改了原集合
```

原地版本：`intersection_update`、`update`（并集）、`difference_update`、`symmetric_difference_update`。

## 小结

- 交集 `&`：都在；并集 `|`：全都要去重；差集 `-`：在左不在右；对称差集 `^`：只在其中一边
- 差集是**不对称**的，`a - b` ≠ `b - a`
- 方法形式：`intersection`、`union`、`difference`、`symmetric_difference`
- 不带 update 的方法返回新集合，不改动原集合
- 这些运算让"名单对比、黑白名单、共同好友"这类需求写起来非常优雅
