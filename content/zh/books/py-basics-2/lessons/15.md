# 实战：统计与分组

> 前面四课把字典的基本功讲完了。这一课做两件**字典最擅长的事**：计数（统计每个东西出现多少次）和分组（按某个字段把数据归到一起）。
>
> 这两个套路在真实项目里几乎天天用。

## 一、计数：统计每个元素出现多少次

场景：一堆投票、一堆单词、一堆城市，你想知道**每个出现了几次**。

### 思路

用字典当"计数器"：键是元素，值是次数。

```python
cities = ["北京", "上海", "北京", "广州", "上海", "北京"]
count = {}

for city in cities:
    if city in count:
        count[city] += 1        # 见过，加一
    else:
        count[city] = 1         # 没见过，记成 1

print(count)        # {'北京': 3, '上海': 2, '广州': 1}
```

逻辑很清楚：见过就加一，没见过就记成 1。

⚠️ **翻车：没见过的键直接加一。**

```python
count = {}
for city in cities:
    count[city] += 1        # ✗ KeyError: '北京'（第一次遇到时还不存在）
```

第一次遇到"北京"时 `count["北京"]` 根本不存在，直接加一就 KeyError 了。必须先判断在不在。

### 用 `get` 写得更短

```python
count = {}
for city in cities:
    count[city] = count.get(city, 0) + 1
```

`count.get(city, 0)` 的意思是"取当前次数，没有就当 0"，再加一写回。一行完成判断和累加。

### 用 `setdefault` 也一样

```python
count = {}
for city in cities:
    count.setdefault(city, 0)
    count[city] += 1
```

`setdefault(city, 0)` 保证键一定存在且初始为 0，后面放心加一。

### 一个完整的例子

```python
votes = ["苹果", "香蕉", "苹果", "橙子", "香蕉", "苹果", "葡萄"]
count = {}
for v in votes:
    count[v] = count.get(v, 0) + 1

# 找出得票最多的
winner = max(count, key=count.get)
print("最多的是:", winner)          # 最多的是: 苹果
print("票数:", count[winner])      # 票数: 3
```

`max(count, key=count.get)` 的意思是：在 `count` 的键里挑一个，挑的标准是"它对应的值最大"。

⚠️ **翻车：直接用 `max(count)` 找最大。**

```python
max(count)          # '葡萄' —— 按字母/插入顺序挑最大的键，不是最大的值
```

`max` 默认比较的是键本身。要"按值挑"，必须给 `key` 参数。

## 二、分组：按某个字段把数据归到一起

场景：一堆学生记录，想**按班级分**、按城市分、按分数段分。

### 思路

键是"分组依据"，值是"属于这一组的元素列表"。

```python
students = [
    ("张三", "一班"),
    ("李四", "二班"),
    ("王五", "一班"),
    ("赵六", "三班"),
    ("钱七", "二班"),
]

groups = {}
for name, cls in students:
    if cls not in groups:
        groups[cls] = []          # 这组还没建，先建个空列表
    groups[cls].append(name)

print(groups)
# {'一班': ['张三', '王五'], '二班': ['李四', '钱七'], '三班': ['赵六']}
```

逻辑：组不存在就建个空列表，然后往里加名字。

⚠️ **翻车：忘了先建列表就 append。**

```python
groups = {}
for name, cls in students:
    groups[cls].append(name)      # ✗ KeyError: '一班'
```

第一次遇到"一班"时 `groups["一班"]` 还不存在，直接 append 就崩。得先判断、先建。

### 用 `setdefault` 写得更短

```python
groups = {}
for name, cls in students:
    groups.setdefault(cls, []).append(name)
```

`setdefault(cls, [])` 返回"cls 对应的那个列表"（不存在就先建一个空列表），然后直接 `.append(name)`。

⚠️ **翻车：把 `setdefault` 的默认值写成 `[]` 字面量却担心被复用。**

其实这里不用担心 —— `setdefault` 只在键不存在时**创建一次**这个列表，之后都返回同一个已存在的列表，不会反复新建。

### 一个贴近实际的例子：按分数段分组

```python
scores = [("张三", 92), ("李四", 78), ("王五", 55), ("赵六", 88), ("钱七", 45)]

def level(s):
    if s >= 90: return "优秀"
    if s >= 60: return "及格"
    return "不及格"

groups = {}
for name, s in scores:
    groups.setdefault(level(s), []).append(name)

print(groups)
# {'优秀': ['张三'], '及格': ['李四', '赵六'], '不及格': ['王五', '钱七']}
```

分组依据可以是个函数算出来的结果 —— 这让分组变得非常灵活。

## 三、两个套路的小结

| 套路 | 字典长什么样 | 写法 |
|---|---|---|
| 计数 | `{元素: 次数}` | `count[x] = count.get(x, 0) + 1` |
| 分组 | `{类别: [元素, ...]}` | `groups.setdefault(类别, []).append(元素)` |

这两个套路**覆盖了大部分"整理数据"的需求**。再重复一遍，形成肌肉记忆：

- 计数：`d[k] = d.get(k, 0) + 1`
- 分组：`d.setdefault(k, []).append(v)`

⚠️ **翻车：把两个套路混用。**

```python
# 想分组，却写成了计数
groups = {}
for name, cls in students:
    groups[cls] = groups.get(cls, 0) + 1     # 得到的是每班人数，不是名单
```

结果是个"各班人数统计"，不是分组。想分组，值就必须是列表、用 append；想计数，值就是数字、用加一。两个套路别搞混。

## 小结

- 计数套路：`count[x] = count.get(x, 0) + 1`
- 分组套路：`groups.setdefault(k, []).append(v)`
- 两个套路覆盖了绝大多数"整理数据"的需求
- 计数找最大要用 `max(count, key=count.get)`，不能只写 `max(count)`
- 分组依据可以是个函数算出的结果，非常灵活
