# 实战：词频统计

> 这是本书最后一个"课本里的例子"——把第 3、4 章的字典和集合综合起来用。
>
> 目标是：统计一段文本里每个词出现多少次，找出**出现最多的词**，以及**去重后的词汇表**。

## 一、任务拆解

输入是一段文本：

```python
text = "Python 是 最 好 的 语言 Python 最 好 学"
```

要得到：

1. **词频表**：每个词出现几次 → `{词: 次数}` 的字典
2. **出现最多的词** → 从词频表里挑值最大的那个键
3. **去重后的词汇表** → 词频表里的所有键（或直接用集合）

拆成三步，每一步都是学过的套路。

## 二、第一步：统计词频

词频是"计数"套路：键是词，值是次数。

```python
text = "Python 是 最 好 的 语言 Python 最 好 学"
words = text.split()        # 按空白切词
count = {}

for w in words:
    count[w] = count.get(w, 0) + 1

print(count)
# {'Python': 2, '是': 1, '最': 2, '好': 2, '的': 1, '语言': 1, '学': 1}
```

两行核心：`split()` 把字符串切成列表，`count.get(w, 0) + 1` 完成计数。

⚠️ **翻车：文本里标点没处理。**

```python
text = "我爱Python，Python真好"
print(text.split())
# ['我爱Python，Python真好'] —— 整段成了一个词
```

这里 `split()` 是按空白切的，中文没有空格，整段成了一个词。真实项目里要先用正则或 `jieba` 分词。本课简化：**假设输入已经是用空格分开的单词**。

## 三、第二步：找出出现最多的词

有了词频表，要找"值最大"的键，用 `max` 加 `key`：

```python
winner = max(count, key=count.get)
print("出现最多的词:", winner)          # 出现最多的词: Python
print("次数:", count[winner])          # 次数: 2
```

`max(count, key=count.get)` 在 `count` 的键里挑，标准是"键对应的值最大"。

⚠️ **翻车：直接 `max(count)`。**

```python
max(count)         # '语言' —— 按字符串比较挑最大键，不是按次数
```

必须给 `key=count.get`，否则 `max` 比较的是**键本身**（字符串），而不是次数。

### 平局怎么办

如果"Python"和"好"都是 2 次，`max` 会返回**先遇到的那个** —— 行为确定但不一定符合你的预期。真实项目里一般这样写"找所有并列第一"：

```python
max_count = max(count.values())
winners = [w for w, c in count.items() if c == max_count]
print(winners)         # ['Python', '最', '好'] —— 所有出现 2 次的
```

⚠️ **翻车：以为 `max` 会返回所有并列第一。**

```python
max(count, key=count.get)      # 只返回一个
```

`max` 只返回一个值。要"所有并列第一"得自己筛一遍。

## 四、第三步：去重后的词汇表

去重后的词汇表，就是"出现过哪些不同的词"。两种做法：

### 做法一：词频表的键就是去重结果

```python
vocab = list(count.keys())
print(vocab)         # ['Python', '是', '最', '好', '的', '语言', '学']
```

字典的键天然不重复。

### 做法二：直接用集合

```python
words = text.split()
vocab_set = set(words)
print(vocab_set)     # {'Python', '是', '最', '好', '的', '语言', '学'}
```

⚠️ **翻车：用列表去重却丢了顺序。**

```python
list(set(words))     # 顺序不保证，每次可能不同
```

集合无序。想要"去重且保持第一次出现顺序"，用第 16 课那个套路：

```python
seen = set()
vocab = []
for w in words:
    if w not in seen:
        seen.add(w)
        vocab.append(w)
print(vocab)         # ['Python', '是', '最', '好', '的', '语言', '学']
```

## 五、完整代码

把三步合起来：

```python
text = "Python 是 最 好 的 语言 Python 最 好 学"
words = text.split()

# 1. 词频统计
count = {}
for w in words:
    count[w] = count.get(w, 0) + 1

# 2. 找出出现最多的词
winner = max(count, key=count.get)

# 3. 去重词汇表（保序）
seen = set()
vocab = []
for w in words:
    if w not in seen:
        seen.add(w)
        vocab.append(w)

print("词频:", count)
print("出现最多:", winner, count[winner], "次")
print("词汇表:", vocab)
```

输出：

```
词频: {'Python': 2, '是': 1, '最': 2, '好': 2, '的': 1, '语言': 1, '学': 1}
出现最多: Python 2 次
词汇表: ['Python', '是', '最', '好', '的', '语言', '学']
```

⚠️ **翻车：把"计数"和"找最大"的顺序写反。**

```python
winner = max(count, key=count.get)      # count 还是空的！
count = {}
```

先统计完，才能找最大。顺序错了，count 是空字典，`max` 会报 `ValueError: arg is an empty sequence`。

## 六、一个综合一点的例子：按词频排序输出

把词频表按次数从高到低打印：

```python
# 词频统计（同上）
count = {}
for w in words:
    count[w] = count.get(w, 0) + 1

# 按次数从高到低
ranked = sorted(count.items(), key=lambda item: item[1], reverse=True)
for w, c in ranked:
    print(f"{w}: {c} 次")
```

```
Python: 2 次
最: 2 次
好: 2 次
是: 1 次
的: 1 次
语言: 1 次
学: 1 次
```

`sorted(count.items(), key=lambda item: item[1], reverse=True)` —— 按"值"从高到低排，这是第 13 课的内容。

## 小结

- 词频统计用字典计数：`count[w] = count.get(w, 0) + 1`
- 找出现最多的词用 `max(count, key=count.get)`，`key` 不能省
- 去重词汇表可用 `set` 或"集合辅助 + 列表保序"
- 找"所有并列第一"要自己筛 `values` 的最大值
- 这是字典（计数）+ 集合（去重判断）的经典组合用法
