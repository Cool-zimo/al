# 可变参数：`*args` 与 `**kwargs`

> 前面的函数参数个数都是固定的。这一课学"参数数量不确定"时怎么办：`*args` 收集任意多个**位置参数**，`**kwargs` 收集任意多个**关键字参数**。
>
> 学完还能顺手解决"**参数解包**"——把列表、字典一键展开成参数。

## 一、`*args`：收集任意多个位置参数

函数不知道要收几个参数时，用 `*args`：

```python
def total(*args):
    return sum(args)

print(total(1, 2))              # 3
print(total(1, 2, 3, 4, 5))     # 15
print(total())                  # 0
```

`*args` 把调用时传进来的所有位置参数**打包成一个元组**。`args` 就是那个元组，名字习惯上叫 `args`，但前面那个 `*` 才是关键，名字可以自己起。

⚠️ **翻车：以为 args 是列表，想 append。**

```python
def show(*args):
    args.append(4)          # ✗ AttributeError: 'tuple' object has no attribute 'append'

show(1, 2, 3)
```

`*args` 收集来的是**元组**，元组不可变，不能 append。想增删得先转成列表：`list(args)`。

## 二、`**kwargs`：收集任意多个关键字参数

关键字参数也能被收集，用两个星号：

```python
def print_info(**kwargs):
    for k, v in kwargs.items():
        print(f"{k} = {v}")

print_info(name="张三", city="北京", age=20)
# name = 张三
# city = 北京
# age = 20
```

`**kwargs` 把关键字参数**打包成一个字典**，`kwargs` 是那个字典。名字习惯叫 `kwargs`，但 `**` 才是关键。

⚠️ **翻车：传位置参数给 `**kwargs`。**

```python
print_info("张三", "北京")      # ✗ TypeError: print_info() takes 0 positional arguments but 2 were given
```

`**kwargs` **只收关键字参数**，位置参数塞不进去。反过来，纯位置参数用 `*args`。

## 三、组合使用：`def f(a, b, *args, **kwargs)`

三者可以共存，但**顺序有铁律**：

```python
def f(a, b=2, *args, **kwargs):
    print(f"a={a}, b={b}, args={args}, kwargs={kwargs}")

f(1)                        # a=1, b=2, args=(), kwargs={}
f(1, 3, 4, 5, name="张三")   # a=1, b=3, args=(4, 5), kwargs={'name': '张三'}
```

**顺序必须是：位置参数 → 默认参数 → `*args` → `**kwargs`**。

⚠️ **翻车：把 `**kwargs` 写在 `*args` 前面。**

```python
def f(**kwargs, *args):     # ✗ SyntaxError
    pass
```

顺序反了直接语法错误。**记不住就背：普通参数在前，`*` 开头的中间，`**` 开头的最后**。

## 四、什么时候需要可变参数

**典型场景一：参数数量真的未知。**

```python
def average(*numbers):
    if not numbers:
        return 0
    return sum(numbers) / len(numbers)

print(average(80, 90, 100))        # 90.0
print(average(70, 80, 90, 100))    # 85.0
```

成绩数量不定，用 `*args` 最自然。

**典型场景二：包装/转发参数。**

```python
def log_and_call(func, *args, **kwargs):
    print(f"调用 {func.__name__}，参数 {args}，关键字 {kwargs}")
    return func(*args, **kwargs)

def add(a, b):
    return a + b

log_and_call(add, 3, 5)        # 调用 add，参数 (3, 5)，关键字 {}
# 返回 8
```

`log_and_call` 自己根本不知道要传哪些参数，用 `*args, **kwargs` 全收下再原样转发。这是"装饰器"和"中间件"的雏形。

⚠️ **翻车：包装函数漏了 `**kwargs`，把关键字参数丢了。**

```python
def log_and_call(func, *args):          # 没写 **kwargs
    return func(*args)

log_and_call(add, a=3, b=5)     # ✗ TypeError: add() got an unexpected keyword argument 'a'
```

转发参数时，`*args` 和 `**kwargs` **必须成对被写上**，否则关键字参数无处安放。

## 五、参数解包：反过来把容器"摊开"

`*` 和 `**` 用在**调用侧**，作用是"解包"：

```python
def add(a, b, c):
    return a + b + c

nums = [1, 2, 3]
print(add(*nums))              # 6 —— 等价于 add(1, 2, 3)

info = {"name": "张三", "city": "北京"}
def greet(name, city):
    return f"{city}的{name}"

print(greet(**info))           # 北京的张三 —— 等价于 greet(name="张三", city="北京")
```

`*nums` 把列表"摊开"成位置参数，`**info` 把字典"摊开"成关键字参数。

⚠️ **翻车：解包时数量对不上。**

```python
nums = [1, 2]
add(*nums)              # ✗ TypeError: add() missing 1 required positional argument: 'c'
```

`add` 要 3 个参数，列表里只有 2 个，摊开后还差一个。**解包出来的数量必须和函数形参数量一致**（除非函数本身用了可变参数）。

⚠️ **翻车：用 `*` 解包字典。**

```python
greet(*info)            # ✗ TypeError: greet() missing 1 required positional argument: 'city'
```

`greet(*info)` 摊开的是**字典的键**（`"name"`, `"city"`），按顺序对应 `name` 和 `city` 两个参数——恰好对上了其实能跑，但语义是错的（你拿到的是两个字符串键）。**字典该用 `**` 解包成关键字参数**。

## 六、综合例子：拼 SQL 的简易版

```python
def make_insert(table, **fields):
    cols = ", ".join(fields.keys())
    vals = ", ".join(str(v) for v in fields.values())
    return f"INSERT INTO {table} ({cols}) VALUES ({vals})"

print(make_insert("users", name="张三", age=20, city="北京"))
# INSERT INTO users (name, age, city) VALUES (张三, 20, 北京)
```

列名和值的数量都不确定，用 `**fields` 一把收下，再分别取 keys 和 values。

⚠️ **翻车：把用户输入直接拼进 SQL——虽然课上是教学演示，但真实项目里这是注入漏洞。**

```python
name = "张三'; DROP TABLE users; --"
make_insert("users", name=name)
# INSERT INTO users (name) VALUES (张三'; DROP TABLE users; --)
```

⚠️ 郑重提示：上面是**错误示范**。真实项目绝不能用字符串拼接 SQL，必须用参数化查询（`cursor.execute(sql, params)`）。这一课只讲语法，`**kwargs` 的真实用途更多是配置项、参数转发，而不是拼 SQL。

## 小结

- `*args` 收集任意多个**位置参数**，打包成**元组**
- `**kwargs` 收集任意多个**关键字参数**，打包成**字典**
- 顺序铁律：位置参数 → 默认参数 → `*args` → `**kwargs`
- 反向用法：`*列表` 解包成位置参数，`**字典` 解包成关键字参数
- 解包后数量要和函数形参对上
- 真实项目里 `*args/**kwargs` 多用于参数转发，别用它拼 SQL
