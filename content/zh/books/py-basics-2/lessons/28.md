# lambda 与高阶函数：一行写完的小函数

> 这一课讲"匿名函数" `lambda`，以及三个最实用的**高阶函数**：`map`、`filter`、`sorted(key=...)`。
>
> 学会这一课，你就有了 Python 里最常用、最"函数式"的一套工具。

## 一、lambda：没有名字的小函数

`lambda` 用来写**只有一行逻辑**的小函数，不用 `def` 起名：

```python
square = lambda x: x * x
print(square(5))        # 25
```

`lambda x: x * x` 读起来是"接收 x，返回 x*x"。它和下面这个完全等价：

```python
def square(x):
    return x * x
```

区别只是 `lambda` **没有名字**（匿名）、**只能有一行表达式**。

⚠️ **翻车：在 lambda 里写多行或赋值语句。**

```python
f = lambda x: (            # ✗ SyntaxError: invalid syntax
    y = x + 1
    y * 2)
```

lambda 只能写一个**表达式**，不能写赋值、不能写 if 的多分支语句块（三元表达式 `a if c else b` 可以）。逻辑复杂就老老实实用 `def`。

⚠️ **翻车：以为 lambda 后面不用写参数。**

```python
nums = [1, 2, 3]
list(map(lambda: x * 2, nums))      # ✗ NameError: name 'x' is not defined
```

`lambda:` 后面没写参数，但表达式里用了 `x`。**参数列表不能省**：`lambda x: x * 2`。

## 二、map：把一个函数作用到每个元素

`map(func, 可迭代)` 把 `func` 依次作用到每个元素上：

```python
nums = [1, 2, 3, 4]
squares = list(map(lambda x: x * x, nums))
print(squares)        # [1, 4, 9, 16]
```

等价于列表推导式 `[x*x for x in nums]`。`map` 返回的是迭代器，要 `list()` 一下才能看到结果。

⚠️ **翻车：忘了 list()，拿到的是个迭代器。**

```python
result = map(lambda x: x * 2, [1, 2, 3])
print(result)         # <map object at 0x...> —— 不是列表
```

直接打印只能看到"map 对象"。想要列表就 `list(result)`。

## 三、filter：只留下满足条件的

`filter(func, 可迭代)` 用 `func` 判断每个元素，只保留返回"真"的：

```python
nums = [1, 2, 3, 4, 5, 6]
evens = list(filter(lambda x: x % 2 == 0, nums))
print(evens)        # [2, 4, 6]
```

`lambda x: x % 2 == 0` 是判断函数，返回 True 的元素被留下。

⚠️ **翻车：判断函数返回了 None（忘了写 return 式的表达式）。**

```python
list(filter(lambda x: x > 0, [-1, 2, 3]))   # 能跑，但逻辑依赖"真值"
list(filter(lambda x: print(x > 0), [1, 2]))  # ✗ 逻辑全错
```

lambda 主体必须是一个**返回布尔值的表达式**。`print(...)` 返回 None，会被当成"假"过滤掉。**filter 的判断函数必须返回真值**。

## 四、最实用：`sorted` 的 `key` 参数

`sorted` 的 `key` 参数接受一个**函数**，用来决定"按什么排序"：

```python
words = ["banana", "apple", "pear", "kiwi"]
by_length = sorted(words, key=lambda w: len(w))
print(by_length)        # ['pear', 'kiwi', 'apple', 'banana']
```

`key=lambda w: len(w)` 意思是："排序时别比字符串本身，比它们的长度"。

⚠️ **翻车：把 key 写成调用结果。**

```python
sorted(words, key=len(words))      # ✗ TypeError
```

`key` 要的是**一个函数**（`len`），不是 `len(words)` 这个结果。写成 `key=len` 才对。

## 五、按对象的某个字段排序：真实场景

处理字典列表时，`key` 的威力最明显：

```python
students = [
    {"name": "张三", "score": 92},
    {"name": "李四", "score": 78},
    {"name": "王五", "score": 100},
]

by_score = sorted(students, key=lambda s: s["score"])
print(by_score)
# [{'name': '李四', 'score': 78}, {'name': '张三', 'score': 92}, {'name': '王五', 'score': 100}]
```

`key=lambda s: s["score"]` 取出每个学生的分数作为排序依据。**这比手写排序算法清爽一万倍**。

⚠️ **翻车：key 函数返回值类型不一致。**

```python
mixed = [{"name": "张三", "score": 92}, {"name": "李四"}]
sorted(mixed, key=lambda s: s["score"])      # ✗ KeyError: 'score'
```

第二个字典没有 `score` 键，`s["score"]` 会 `KeyError`。**确保所有元素都有 key 函数需要的键**，或者用 `s.get("score", 0)` 给个默认值。

## 六、综合例子：购物车排序

```python
cart = [
    {"item": "苹果", "price": 5.5, "qty": 3},
    {"item": "牛奶", "price": 8.0, "qty": 1},
    {"item": "面包", "price": 3.5, "qty": 5},
]

# 按总价（单价 × 数量）从高到低
by_total = sorted(
    cart,
    key=lambda g: g["price"] * g["qty"],
    reverse=True,
)
for g in by_total:
    print(g["item"], g["price"] * g["qty"])
# 苹果 16.5
# 牛奶 8.0
# 面包 17.5
```

`key` 函数算出了"每件商品的总价"作为排序依据，`reverse=True` 表示降序。

⚠️ **翻车：用了 sort（原地排序）却期待返回新列表。**

```python
cart = [{"price": 5}, {"price": 3}]
result = cart.sort(key=lambda x: x["price"])
print(result)        # None —— sort 是原地排序，返回 None
```

`list.sort()` 是**原地排序、返回 None**；`sorted(list)` 是**返回新列表、不改原列表**。要拿到新列表用 `sorted`，要改原列表用 `list.sort()`。

## 七、lambda vs def：怎么选

| 场景 | 用哪个 |
|---|---|
| 逻辑只有一行、用完就丢 | `lambda` |
| 逻辑复杂、要写多行 | `def` |
| 要复用、要起名字 | `def` |
| 当 `key`、`map`、`filter` 的参数 | `lambda`（最常见） |

```python
# lambda：一次性、作为参数
sorted(students, key=lambda s: s["score"])

# def：要复用
def by_score(s):
    return s["score"]

sorted(students, key=by_score)
sorted(teachers, key=by_score)
```

⚠️ **翻车：lambda 里用 `=` 赋值。**

```python
lambda x: x = x + 1        # ✗ SyntaxError
```

lambda 主体只能是表达式。想赋值就写 `lambda x: x + 1`。

## 小结

- `lambda 参数: 表达式` 是没有名字的单行小函数
- lambda 只能有表达式，不能写赋值或多行语句
- `map(func, 序列)` 把 func 作用到每个元素
- `filter(func, 序列)` 只保留 func 返回"真"的元素
- `sorted(序列, key=func)` 按 key 函数的返回值排序，最实用
- `map`/`filter` 返回迭代器，要 `list()` 才看得到
- key 要传**函数本身**，不要传调用结果
