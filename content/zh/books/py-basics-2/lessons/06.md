# 元组：不能改的列表

> 列表能随时增删改，可有些数据**天生就不该变** —— 北京上海的经纬度、一个人的姓名、一年有 12 个月。
>
> 这一课讲**元组（tuple）**：它跟列表几乎一样，唯独**改不了**。学会它，你才知道什么时候该"锁死"数据。

## 一、为什么要有"改不了"的列表

列表很自由：`append`、`remove`、`[i]=` 随便用。但自由是有代价的：

```python
point = [116.46, 39.92]      # 北京的经纬度
point[0] = 0                 # 一不小心改成了原点
```

经纬度的数字不该被改。如果你把这样一个列表当作函数的参数传来传去，任何一段代码都可能悄悄把它改坏，而你很难追踪是谁动的。

**元组的价值就是"不可变"**：一旦创建，里面的元素就**谁也改不了**。这带来两个好处：

1. **安心**：你知道它不会被别的代码偷偷改动
2. **能用它当字典的键**（第 3 章会讲 —— 列表不行，元组可以）

⚠️ **翻车：以为元组只是"只读的列表"。**

有人觉得"元组 = 列表去掉增删改"，这是个有用的直觉，但它**不是列表的子类**，两者是并列的两种类型。判断一个东西该不该用元组，看的是"它**代表什么**"，而不是"我暂时想不想改它"。

## 二、创建元组

把列表的方括号 `[ ]` 换成圆括号 `( )` 就是元组：

```python
rgb = (255, 128, 0)
print(rgb)              # (255, 128, 0)
print(rgb[0])           # 255
print(type(rgb))        # <class 'tuple'>
```

元组也支持下标和切片（因为它是"序列"）：

```python
rgb = (255, 128, 0)
print(rgb[1])           # 128
print(rgb[0:2])         # (255, 128) —— 切片出来还是元组
print(len(rgb))         # 3
```

可以省略括号，Python 靠**逗号**就能认出元组：

```python
point = 116.46, 39.92       # 合法，等价于 (116.46, 39.92)
x, y = point
print(x, y)                 # 116.46 39.92
```

⚠️ **经典大坑：单元素元组必须加逗号。**

这是 Python 新手被绊倒最多的一处。你想创建一个"只装一个元素的元组"：

```python
a = (5)            # 这是什么？
print(type(a))     # <class 'int'>  ← 它只是个整数！
print(a)           # 5
```

**括号在数学里表示"优先运算"，在 Python 里也表示"分组"。** `(5)` 只是把 5 括起来强调一下，结果还是 5。

```python
a = (5,)           # 加上逗号，才是单元素元组
print(type(a))     # <class 'tuple'>
print(a)           # (5,)
```

记住这条铁律：**元组的标志是逗号，不是括号。** 一个元素的元组必须写成 `(5,)`，那个尾巴上的逗号不能省。

```python
b = 5,              # 不加括号、只加逗号，也是单元素元组
print(type(b))      # <class 'tuple'>
```

反过来，空元组就是 `()` 或者 `tuple()`：

```python
empty = ()
print(type(empty))      # <class 'tuple'>
print(len(empty))       # 0
```

用 `tuple()` 还能把列表、字符串等"序列"转换成元组：

```python
t1 = tuple([1, 2, 3])
print(t1)          # (1, 2, 3)

t2 = tuple("北京")
print(t2)          # ('北', '京')
```

## 三、元组"改不了"是什么意思

元组里的元素不能增、不能删、不能改：

```python
rgb = (255, 128, 0)
rgb[0] = 100       # ✗ TypeError: 'tuple' object does not support item assignment
```

报错信息说得很直白 —— 元组不支持"按位置赋值"。同样，它没有 `append`、`remove`、`pop` 这些方法。

⚠️ **一个微妙之处：元组"不可变"≠ 它里面装的东西不能变。**

这条最容易让人误解。看下面这个例子：

```python
data = (1, [2, 3])
data[1].append(4)        # 竟然没报错！
print(data)              # (1, [2, 3, 4])
```

**元组保证的是"那几个位置上的引用不变"，不是"引用指向的对象不变"。** 上例中 `data[1]` 始终指向同一个列表，只是这个列表**自己**变了。

| 操作 | 元组允许吗 | 说明 |
|---|---|---|
| `t[0] = 1` | 否 | 不能换掉某个位置上的元素 |
| `t[1].append(x)` | 可以 | 列表自己改，元组管不着 |
| `t.append(x)` | 否 | 元组没有这个方法 |

所以元组能当字典的键，前提是它**里面的元素也都是不可变的**（比如数字、字符串、元组）。如果里面嵌了列表，就又用不了了 —— 这一点第 14 课还会再讲。

## 四、什么时候该用元组

给一个可操作的判断标准：

| 情况 | 用哪个 | 理由 |
|---|---|---|
| 装的是**几个不同的字段**（如经纬度、姓名+年龄） | 元组 | 字段是固定的，语义明确 |
| 装的是**一批同类的东西**（如购物车、成绩表） | 列表 | 需要增删、需要排序 |
| 这组数据**不该被改**（如配置、常量） | 元组 | 不可变即安全 |
| 要当**字典的键** | 元组 | 列表不可哈希，元组可以 |

一句话总结：**字段用元组，集合用列表。**

现实中的例子：

```python
# 通讯录里一条记录 —— 姓名、电话、邮箱，三个不同字段
contact = ("张三", "13800138000", "zhangsan@example.com")

# 一个班级的成绩表 —— 一批同类的分数
scores = [87, 92, 78, 65, 100]
```

前者用元组，因为每个位置都有明确含义（第 0 位一定是姓名）；后者用列表，因为你会想往里加成绩、算平均分、排序。

## 小结

- 元组用 `( )` 创建，支持下标、切片、`len`，和列表一样是"序列"
- **单元素元组必须写成 `(5,)`** —— 元组的标志是逗号，不是括号
- 元组**不能增删改**，也没有 `append` 等方法，改了就 `TypeError`
- 元组"不可变"指的是位置上的引用不变，里面装的列表照样能自己变
- 字段用元组，集合用列表；需要当字典键时只能用元组

## 随堂练习

```quiz
type: code
q: 创建一个单元素元组 `t`，里面只装数字 42，并打印它的类型和内容
starter: |
  # 创建一个只含 42 的元组 t

  print(t)
  print(type(t))
tests:
- assert "(42,)" in __out
- assert "tuple" in __out
hint: 单元素元组的逗号不能省，写成 (42,) 而不是 (42)。
explain: 答案就是 t = (42,)。只写 (42) 的话 type 会显示 int —— 因为 Python 把括号理解成"分组"，只有逗号才让 Python 知道这是元组。
```
