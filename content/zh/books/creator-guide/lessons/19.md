# 19 程序题：跑整段代码

> 考 print、考流程，用 assert 判。

## 和函数题的区别

| | 函数题 | 程序题 |
|---|---|---|
| 考什么 | 一个函数的返回值 | 整段代码的输出或副作用 |
| 判分 | 比对返回值 | 用 `assert` 断言 |

程序题适合考「打印出什么」「循环执行了几次」这类没法用返回值表达的东西。

## 写法

```
type: code
q: 打印 1 到 5，每行一个
starter: |
  for i in range(1, 6):
      print(i)
tests: |
  assert __out.count("1") == 1
  assert "5" in __out
hint: __out 里是完整输出
```

## __out 是什么

`__out` 是这段代码的**完整标准输出**，一个字符串。

所以断言可以这么写：

```
assert "5" in __out              输出里包含 5
assert len(__out.strip().split("\n")) == 5    有 5 行
assert __out.count("1") == 1     1 只出现一次
```

## 断言要宽容一点

读者的写法千奇百怪，输出格式可能有细微差别。所以：

```
assert "5" in __out           好，宽容
assert __out == "1\n2\n3"      不好，太严格（末尾换行就可能不一样）
```

**用 `in` 和 `count`，别用 `==`。**

## 别忘了判「没做」

和函数题一样，检查 starter 原样提交能不能过。如果 starter 就是正确答案，这题没意义。

## 小结

- `tests:` 里写 assert
- `__out` 是完整输出字符串
- 用 `in` / `count`，别用 `==`
- starter 要能跑但结果不对
