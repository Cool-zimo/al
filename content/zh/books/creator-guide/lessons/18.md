# 18 随机结果题

> 掷骰子、洗牌这类没法用精确值比对，用区间。

## 问题在哪

如果让读者写 `roll_dice()` 返回 1~6 的随机整数，你没法写：

```
cases: |
  -> 3
```

因为正确答案每次都不一样。

## 两种特殊语法

```
*30 -> 1..6
```

- `*30`：把这个用例**重复调用 30 次**
- `1..6`：每次结果都要落在 `[1, 6]` 区间内

合起来就是「掷 30 次骰子，每次都得是 1 到 6」。

带参数的话：

```
*20, 6 -> 0..5
```

`*20` 后面跟逗号和参数。

## 只判范围还不够

考虑这个答案：

```python
def roll_dice():
    return 3
```

每次都返回 3，**永远在 1~6 里**。只判范围的话它就蒙混过关了。

所以区间用例还会检查**结果是否真的出现了多种不同的值**：

- 整数区间且跨度不超过 10（骰子、硬币这类）：要求**每个值都出现过**
- 其它情况：至少出现 5 种不同结果

## 实测过的几个例子

| 写法 | 结果 |
|---|---|
| `randint(1, 6)` | 通过，1~6 每个值都出现 |
| `return 3` | 不通过，只有 1 种结果 |
| `randrange(1, 6)` | 不通过，掷不出 6 |
| `randint(1, 7)` | 不通过，有越界 |

`randrange(1, 6)` 这个坑特别值得写进 hint —— 它看起来和 `randint` 一模一样，但右边界是开区间。

## 小结

- `*N` 重复调用，`a..b` 区间期望
- 还会检查取值是否真的多样
- `randint(a, b)` 是闭区间，`randrange(a, b)` 不含 b

## 随堂练习

```quiz
type: function
func: roll_dice
q: 写 roll_dice()，返回 1 到 6 的随机整数
starter: |
  import random

  def roll_dice():
      return 0
cases: |
  *30 -> 1..6
hint: 用 random.randint(1, 6)，注意两端都包含
explain: *30 表示调用 30 次，1..6 表示每次都要落在区间内。只返回固定值会被判为「像固定值」。
```
