# 11 quiz 块的骨架

> 所有题都是同一个壳，只是 type 不同。

## 长什么样

一道题就是一个带 `quiz` 标记的代码块：

```quiz 这是示意，不是真题目
type: choice
q: 题干
options:
- 选项 A
- 选项 B
answer: 0
```

**开头必须是 ` ```quiz `，结尾必须是独占一行的 ` ``` `**。这两个缺一个，整道题读不出来。

## 字段的写法

格式是极简的 YAML：

```
key: value              单行值
key: |                  多行块，下面缩进两格
  第一行
  第二行
key:                    列表，下面用 - 开头
- 第一项
- 第二项
```

常见错误是缩进不对：

```
starter: |
def add(a, b):        ← 没缩进，不会被算进块里
    return 0
```

块内容**必须缩进至少两格**。

## 必填和选填

| 字段 | 必填 | 说明 |
|---|---|---|
| `type` | 是 | 题型 |
| `q` | 是 | 题干 |
| `exam` | 否 | `true` 表示算本节测验 |
| `hint` | 否 | 提示，点一下才出现 |
| `explain` | 否 | 做完之后显示的解释 |

不同题型的必填字段不一样，后面几课逐个讲。

## 结束围栏必须独占一行

这一条值得单独强调。结束的 ` ``` ` 必须**顶格、独占一行**。

如果题干里要放代码，**不要用 ``` 围栏**，用 `code:` 字段：

```
type: choice
q: 下面这段代码输出什么？
code: |
  print(1 + 1)
options:
- 1
- 2
answer: 1
```

题干里直接敲三个反引号，解析器会在那里就认为块结束了，后面的 `options` 和 `answer` 全部读不到 —— 表现为页面上渲染出一道**没有选项的选择题**。

## 小结

- 开头 ` ```quiz `，结尾顶格的 ` ``` `
- 多行块缩进两格
- 题干放代码用 `code:` 字段

## 随堂练习

```quiz
type: choice
answer: 0
q: 一道题的结束围栏必须怎么写？
options:
- 顶格独占一行
- 缩进两格
- 和内容同一行
- 前面空两格
hint: 顶格
explain: 结束的 ``` 必须顶格独占一行，否则解析会提前截断。
```

## 本节测验

```quiz
type: choice
exam: true
answer: 0
q: 题干里要放一段代码，正确的做法是？
options:
- 用 code: 字段
- 直接敲三个反引号
- 用行内代码
- 放到 q: 后面同一行
explain: 题干里直接敲围栏会让解析器以为块结束了，后面的字段全丢。
```

```quiz
type: choice
exam: true
answer: 0
q: starter 是多行块，里面的内容要怎么写？
options:
- 缩进至少两格
- 顶格写
- 缩进一格
- 用引号包起来
explain: key: | 后面的块内容必须缩进至少两格，否则不会被算进去。
```
