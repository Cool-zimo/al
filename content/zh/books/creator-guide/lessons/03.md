# 03 toc.json：目录怎么写

> 目录错了，书读不出来 —— 这是最常见的新手问题。

## 两种写法都认

**简写版**（推荐，第三方作者用它）：

```
{
  "book": "my-first-book",
  "chapters": [
    {
      "title": "第 1 章 · 开始",
      "lessons": ["01", "02", "03", "04", "05"],
      "test": "test-01"
    },
    {
      "title": "第 2 章 · 进阶",
      "lessons": ["06", "07", "08", "09", "10"],
      "test": "test-02"
    }
  ]
}
```

**完整版**（官方教材用它，每课多一个标题和摘要）：

```
{
  "chapters": [
    {
      "title": "第 1 章 · 开始",
      "test": "test-01",
      "items": [
        { "id": "01", "title": "第一课", "summary": "这一课讲什么" }
      ]
    }
  ]
}
```

两种都会被正确读取。区别在于：简写版没写每课标题，站上会**自动打开课文抓 `# 标题` 和第一句引言**填进去。

所以懒得写摘要就用简写版 —— 只要课文第一行是 `# 标题`，目录照样好看。

## 三个必须对齐的地方

这是最容易出错的：**toc 声明的** 和 **实际存在的** 必须一一对应。

```
toc 写了 "03"，但 lessons/ 下没有 03.md   → 报错
lessons/ 下有 07.md，但 toc 没列           → 报错
```

两边少一个多一个都不行。校验器会明确告诉你缺哪个文件。

## test 字段可以省略

不是每章都要有章测。如果某章没有 `test-01.md`，那就别写 `"test": "test-01"` —— 写了却没文件，一样报错。

## 课号要不要连续

不连续只是一条**警告**，不是错误。比如你有 `01 02 03 07`，会提示「课号不连续，缺 04, 05, 06」，但书照样能发。

不过为了读者看着舒服，建议还是连上。

## 小结

- 简写版和完整版都认
- toc 声明的课必须有对应文件，反之亦然
- 没有章测就别写 test 字段
- 课号不连续只是警告
