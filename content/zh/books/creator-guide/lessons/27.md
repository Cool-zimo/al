# 27 一键发布

> 四步，全程自动，你只要选可见性。

## 发布流程

编辑器里点「发布到 GitHub」，会走四步：

```
1. 校验内容        ← 有错误就停在这
2. 创建仓库        ← 不存在就建，存在就复用
3. 并发推文件      ← 一次提交，要么全成要么全不成
4. 打上 topic      ← al-book，机器人靠它发现
```

## 可见性

发布时选**公开**或**私有**：

- **公开**才会被机器人收录、进书城
- **私有**适合还没写完、或者只给自己看的

发布之后随时能在管理平台里改可见性 —— 私有转公开，公开转私有，都能一键做。

## 文件是一次提交

用的是 Git Tree API：**建 blob → 建 tree → 建 commit**，一次完成。

好处是不会出现「推了一半断网，仓库里是残缺的书」这种情况。要么全成，要么全不成。

## 仓库名

默认用 `al-book-{id}`。想改的话在「书籍信息」里改仓库名那一项。

注意：**改名不会自动迁移已经发布的旧仓库**。旧仓库还在，新名字会建一个新仓库。

## 发布之后

内容是从**你的仓库直读**的，不是复制进主站的。所以：

- 你在 GitHub 上改了课文，读者立刻看到新版
- 你在开发者平台里改了再发布，也是推到同一个仓库

## 小结

- 四步全自动
- 公开才被收录
- 一次提交，不会留半截
- 内容从你的仓库直读
