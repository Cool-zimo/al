# 04 课文文件与命名

> 文件名错了，前面全白做。

## 课号：两位数字

```
01.md  02.md  03.md  ...  09.md  10.md  ...  30.md
```

一位数必须补零。`1.md` 不会被识别为第 1 课 —— 读取器只认两位数字加 `.md`。

## 章测：test-NN.md

```
test-01.md   第 1 章的章测
test-02.md   第 2 章的章测
```

读取器靠 `test-` 前缀区分「这是章测」还是「这是正式课文」。

如果你把章测写成 `06.md`（接在 5 课后面），它会被当成第 6 课 —— 而章测和课文的判分规则不一样（课文要求 1 随堂 + 2 测验，章测要求至少 5 题），混了就会报错。

## 一篇课文长什么样

```markdown
# 切片：一次取出一整段

> 引言：这一节解决什么问题

## 小标题

正文。

## 小结

- 要点

## 随堂练习

（一道不带 exam 的题）

---

## 本节测验

（两道带 exam: true 的题）
```

第一行必须是 `# 标题`，第二行建议是 `> 引言`。

## 别用中文文件名

```
第一课.md      不行
01 切片.md     不行（有空格）
01-slice.md    不行（不是纯数字）
```

就 `01.md`，干干净净。

## 小结

- 课号两位数字，补零
- 章测用 `test-NN.md`，靠前缀识别
- 第一行 `# 标题`，第二行 `> 引言`
- 文件名只放课号，别加别的

## 随堂练习

```quiz
type: choice
answer: 0
q: 第 1 课的文件名应该是什么？
options:
- 01.md
- 1.md
- lesson-01.md
- 01-第一课.md
hint: 两位数字
explain: 必须是两位数字，1.md 不会被识别。
```

## 本节测验

```quiz
type: choice
exam: true
answer: 0
q: 把章测写成 06.md 会怎样？
options:
- 被当成第 6 课
- 报错说找不到章测
- 自动识别为章测
- 两边都算
explain: 章测靠 test- 前缀识别，写成 06.md 就成了正式课文，判分规则不同会报错。
```

```quiz
type: choice
exam: true
answer: 0
q: 课文第一行应该写什么？
options:
- # 标题
- > 引言
- ## 小标题
- 正文
explain: 目录靠第一行的 # 标题，第二行建议写 > 引言。
```
