# 24 写小说、写笔记：kind 字段

> 不是每本书都要有题目。

## 为什么有这个字段

最早这套格式只想着教材，于是强制：每课 1 随堂 + 2 测验、一道题都没有就报错。

但有人想用同一套格式写**小说**、写**笔记**。那些东西本来就没有题，硬卡着就写不了。

于是有了 `kind`：

```
"kind": "textbook"    教材（默认），要求题目数量
"kind": "novel"       小说，不要求
"kind": "notes"       笔记 / 随笔，不要求
"kind": "other"       其它
```

## 不写就是教材

`kind` 是可选字段。不写的话按 `textbook` 处理，也就是**严格要求**。

## 非教材时放宽什么

| 检查 | 教材 | 小说 / 笔记 |
|---|---|---|
| 一课至少一道题 | 必须 | 不要求 |
| 每课 2 道 exam 题 | 必须 | 不要求 |
| 章测至少 5 题 | 警告 | 不要求 |
| 中英题数一致 | 必须 | 不要求 |
| **题目本身是否合法** | 检查 | **照样检查** |

最后一行是关键：**不强制数量，但写了的题必须是合法的。**

选择题 `answer` 越界、函数题 `cases` 用空格分隔 —— 这些在非教材书里照样报错。有题就得是能判分的题。

## 未知值按宽松处理

如果你把 `kind` 拼错了（比如写成 `textbok`），校验器会给一条警告，然后按**宽松**处理。

这是故意的：宁可放过一本奇怪的书，也别因为拼写错误拦住一本正经教材。

## 小说的目录长什么样

```
content/zh/lessons/01.md    第一章
content/zh/lessons/02.md    第二章
```

一课就是一章，没有章测（toc 里不写 `test` 就行）。

## 小结

- `kind` 决定要不要卡题目数量
- 不写就是 `textbook`，严格
- 非教材也有题的话，题照样要合法
