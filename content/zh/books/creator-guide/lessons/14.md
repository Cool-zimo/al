# 14 填空题

> 最适合考「记住这个词」这类事实。

## 写法

```quiz 示意
type: fill
q: Python 里定义函数用什么关键字？
answer: def
placeholder: 在这里填
hint: 三个字母
explain: def 后面跟函数名和参数列表。
```

## 判分：忽略大小写和空格

读者填 `def`、`DEF`、` def ` 都算对。所以不用担心大小写。

## 多个可接受答案用竖线

```quiz 示意
type: fill
q: 求列表长度用什么函数？
answer: len|length|size
```

有些概念在不同语境下叫法不同，把能接受的都写上。

但要小心：填得太宽就失去意义了。如果 `answer: a|b|c|d`，那基本填什么都对。

## 适合和不适合

适合考：关键字、函数名、报错类型、命令名 —— 答案是**一个确定的词**。

不适合考：需要解释的概念、有多种说法的东西、代码（用 `function` 题型考）。

## 别忘了 placeholder

`placeholder` 是输入框里的灰色提示。写清楚要填什么：

```
placeholder: 填一个函数名       好
placeholder: 在这里输入         一般
```

## 小结

- 判分忽略大小写和空格
- `|` 分隔多个可接受答案
- 适合考确定的词
- 写清 placeholder

## 随堂练习

```quiz
type: choice
answer: 0
q: 填空题想接受多个答案，正确的写法是哪个？
options:
- answer: len|length
- answer: len, length
- answer: len length
- answer: [len, length]
hint: 用哪种符号不会被当成别的含义
explain: 多个可接受答案用竖线分隔。逗号会被切分逻辑吃掉，空格也不行。
```
