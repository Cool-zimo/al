# 12 选择题

> 最常用，也最容易写错答案下标。

## 完整写法

```quiz 示意
type: choice
q: Python 里哪个函数能求列表长度？
options:
- len()
- length()
- size()
- count()
answer: 0
hint: 想想你见得最多的那个
explain: len() 是内置函数，直接传列表进去。
```

## answer 是下标，从 0 开始

这是最容易搞错的地方：

```
options:
- 选项 A     下标 0
- 选项 B     下标 1
- 选项 C     下标 2
```

正确答案是第三个，就写 `answer: 2`，不是 `3`。

写错了（比如 `answer: 5` 但只有 4 个选项）校验器会直接报错，不会让你发出去。

## 选项数量

至少 2 个。建议 3 ~ 4 个 —— 两个选项等于二选一，蒙对概率 50%，没什么区分度。

## 干扰项要像真的

好的选择题，错误选项应该**像真的**：

```
q: 下面哪个能求列表长度？
- len()        ← 正确
- length()     ← 像真的（很多语言确实是这个）
- size()       ← 像真的
- count()      ← 像真的（字符串有 count 方法）
```

不好的：

```
- len()        ← 正确
- 苹果
- 红色
- 天空
```

一眼就能看出答案的题，等于没出。

## 小结

- `answer` 是 0 开始的下标
- 3 ~ 4 个选项
- 干扰项要像真的

## 随堂练习

```quiz
type: choice
answer: 0
q: 正确答案是第三个选项，answer 应该写几？
options:
- 2
- 3
- 1
- 0
hint: 从 0 开始数
explain: 下标从 0 开始，第三个是 2。
```

## 本节测验

```quiz
type: choice
exam: true
answer: 0
q: 一道选择题有 4 个选项，answer: 4 会怎样？
options:
- 校验报错
- 自动取最后一个
- 算作全错
- 静默通过
explain: answer 越界会被校验器拦下。
```

```quiz
type: choice
exam: true
answer: 0
q: 好的干扰项应该是怎样的？
options:
- 像真的，让读者需要真的想一下
- 明显荒谬，一眼排除
- 和正确答案一样长
- 按字母顺序排列
explain: 干扰项要像真的才有区分度，一眼能排除的等于没出。
```
