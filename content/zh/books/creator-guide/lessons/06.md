# 06 Markdown 速成

> 写课文只需要 Markdown 里的一小部分，五分钟够用。

## 你只需要会这些

| 写法 | 效果 |
|---|---|
| `# 标题` | 一级标题（课文名） |
| `## 小标题` | 二级标题 |
| `**粗体**` | 粗体 |
| `> 引用` | 引用块（写引言、强调） |
| 行内用一个反引号 | 行内代码 |
| `- 项` | 无序列表 |
| `1. 项` | 有序列表 |
| `[文字](网址)` | 链接 |

就这些。表格、脚注、任务列表那些花活儿，写教材基本用不上。

## 代码块：带语言 vs 不带语言

**带语言标记**的，读者可以点运行：

```python
print("hello")
```

**不带语言**的，用来放输出或示意：

```
hello
```

这个区别很重要：带 `python` 的块会在浏览器里真跑（Pyodide），不带的就是一段普通文本。

所以你想展示「这段代码会输出什么」，应该写**两个块**，第二个不带语言标记。

## 别把输出写进同一个块

新手常犯的错误是把代码和输出塞进一个 `python` 块里。这样点运行会报错 —— 输出不是合法代码。

## 小结

- 标题、粗体、列表、代码块，够用了
- 带语言标记才能运行
- 输出单独写一个不带语言的块
