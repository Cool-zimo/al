# 26 评审报告怎么看

> 发布前点一下，省得发出去才发现。

## 报告里有什么

编辑器里点「评审报告」，会跑一遍完整校验，给出：

```
错误 3 条
  [zh] 07.md: 选择题 answer=4 越界（共 4 个选项）
  [zh] 12.md: cases 里 "1 2 -> 3" 的参数要用逗号分隔
  albook.json 缺必需字段：desc

警告 5 条
  [zh] 03.md: 只有 42 行，可能是占位内容
  [zh] 课号不连续，缺 08, 09

统计：30 课 · 6 章测 · 138 题
```

## 错误 vs 警告

| | 后果 |
|---|---|
| **错误** | 不修就发不出去 |
| **警告** | 能发，但通常说明有问题 |

警告不是 ignore 的理由。「只有 42 行，可能是占位内容」通常意味着你那一课真的还没写完。

## 常见错误和原因

| 报错 | 怎么修 |
|---|---|
| `answer 越界` | 数错下标了，从 0 开始 |
| `cases 参数要用逗号分隔` | 把 `1 2 -> 3` 改成 `1, 2 -> 3` |
| `func 在 starter 里找不到定义` | `func` 和 `def` 后面的名字不一致 |
| `toc 声明了 X.md 但找不到` | 缺文件，或者文件名写错 |
| `中英题数不一致` | 两边题目数量不一样 |
| `quiz 块没有闭合` | 末尾缺独占一行的结束围栏 |

## 统计那一行要看

```
30 课 · 6 章测 · 138 题
```

如果「题」的数量明显少于你预期的，说明有些 quiz 块**没被解析出来** —— 通常是围栏问题。

## 小结

- 错误必须修，警告也要看
- 统计里的题数对不上，先查围栏
- 发布前跑一次
