# 07 标题与引言的两个约定

> 这两个约定不遵守，目录和书城就不好看。

## 约定一：第一行是 `# 标题`

站上打开课文文件，抓第一个 `# ` 开头的行当标题。抓不到就退回显示课号。

所以：

- 第一行**必须**是 `# ...`
- 前面不要有空行、注释、YAML 头
- 一篇课文只有一个 `#`，小节用 `##`

## 约定二：第二行是 `> 引言`

这个引言会出现在三个地方：书城的课文列表、左侧目录、课文开头。

写好引言的标准：**读完这一句，就知道这一课值不值得看。**

反例：

```
> 这一课讲切片
```

太干。正例：

```
> 切片看着简单，但负索引和步长混在一起时最容易写错。这一课把它们拆开讲。
```

## 用一个空行隔开

标题和引言之间、引言和正文之间都要空一行，否则 Markdown 会把它们粘成一段。

## 小结

- 第一行 `# 标题`，前面不许有东西
- 第二行 `> 引言`，说清这一课解决什么
- 之间空一行
