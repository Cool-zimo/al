# 28 可见性与收录

> 发布之后还能改，不用推倒重来。

## 改可见性

管理平台里每本书都有「改可见性」按钮：

```
公开  →  私有     从书城下架，机器人下次扫描会移除
私有  →  公开     重新上架
```

改名、改描述这些也一样，改完再发布一次就行。

## 收录需要多久

机器人的扫描周期是**每 6 小时**一次。所以发布之后最长可能要等 6 小时才出现在书城。

不过有个更快的办法：**登录状态下打开书城，会用你的 token 实时搜一遍**，新书立刻出现。

## 三个标记都要有

机器人认三个东西，缺一个就扫不到：

```
1. 仓库名 al-book- 开头
2. topic: al-book
3. 根目录 albook.json 里 format 精确等于 al-book
```

**最容易忘的是 topic。** 仓库名和 format 都对，但没打 topic，就完全扫不到。

发布流程会自动打上 topic，所以走一键发布的话不用担心。手动建仓库才需要注意这条。

## 未通过的书也会列出来

索引站里，未通过校验的书会**显示错误原因**，让作者知道要改什么。不是静默消失。

## 小结

- 可见性随时能改
- 机器人 6 小时扫一次，登录可实时搜
- 三个标记缺一不可，最容易忘 topic
- 未通过会列出原因
