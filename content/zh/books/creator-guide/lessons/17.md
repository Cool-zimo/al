# 17 cases 的两个坑

> 这两个坑我都踩过，写出来让你别踩。

## 坑一：参数必须用逗号分隔

参数只按逗号切分。写空格的话：

```
cases: |
  1 2 -> 3
```

整段 `1 2` 会被当成**一个参数**，调用时变成 `add("1 2")`，读者看到的是「缺少参数 b」这种莫名其妙的报错。

正确写法：

```
cases: |
  1, 2 -> 3
```

校验器会拦下「有空格但没逗号、也不是引号或括号包起来」的用例行，不用你自己记。

## 坑二：单参数字符串里有空格是正常的

反过来，这些写法是**对的**，别被上一条吓到：

```
cases: |
  "hello world" -> 5      单参数字符串，里面本来就有空格
  [1, 2, 3] -> 6          列表参数（含逗号）
  -> 3                    无参
```

规则是：参数段里有空格，但既没逗号、也没被引号或括号包起来 —— 那才可疑。

## 期望值怎么写

```
cases: |
  1, 2 -> 3               数字
  "a" -> 1                字符串要加引号
  [1,2] -> [2,4]          列表
  "abc" -> True           布尔值首字母大写
```

注意 Python 字面量：`True` / `False` / `None` 首字母大写，字符串要引号。写 `true` 会变成未定义变量。

## 用例要有反例

至少要有一条能挡住常见错误写法的用例。比如考绝对值：

```
cases: |
  5 -> 5
  -5 -> 5        ← 挡住"直接返回原值"
  0 -> 0
```

没有 `-5 -> 5` 这条，`return n` 就能蒙混过关。

## 小结

- 参数用逗号
- 字符串参数里的空格是正常的
- 期望值用 Python 字面量写法
- 每条用例都要想：它能挡住哪种错误写法

## 随堂练习

```quiz
type: function
func: is_even
q: 写一个函数 is_even(n)，偶数返回 True，奇数返回 False
starter: |
  def is_even(n):
      return False
cases: |
  2 -> True
  3 -> False
  0 -> True
  -7 -> False
hint: 用 n % 2 == 0
explain: 取模等于 0 就是偶数，直接返回这个判断结果。
```
