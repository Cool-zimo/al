# 15 题干里放代码

> 用 code: 字段，不要敲围栏。

## 为什么需要这个字段

很多题要问「这段代码输出什么」「这个函数哪里错了」。最直觉的写法是在题干里敲围栏：

```
type: choice
q: 下面这段代码输出什么？
```
  print(1 + 1)
```
options:
- 1
- 2
answer: 1
```

**这是错的。** 解析器遇到题干中间的 ` ``` ` 就认为块结束了，后面的 `options` 和 `answer` 全部读不到。

页面上表现为：一道**没有选项的选择题**。读者只能干瞪眼。

## 正确写法：code 字段

```
type: choice
q: 下面这段代码输出什么？
code: |
  print(1 + 1)
options:
- 1
- 2
answer: 1
```

`code:` 是一个多行块，内容会**只读展示**在题干下方，不会被执行，也不会干扰解析。

## 缩进别忘了

```
code: |
  def f(x):
      return x * 2
```

两格是块的基础缩进，函数体再缩进两格 —— 也就是四格。写错缩进，代码会显示得乱七八糟。

## 展示多个片段

`code:` 只能放一段。要对比两段代码，就放在 `q:` 里用文字描述，或者拆成两道题。

## 小结

- 题干放代码一律用 `code:`
- 直接在题干敲围栏会让后面的字段全丢
- 注意多行块的缩进

## 随堂练习

```quiz
type: choice
answer: 0
q: 在题干里直接敲三个反引号放代码，会发生什么？
options:
- 解析器认为块提前结束，后面的字段全丢
- 正常显示
- 代码被执行
- 报错不让发布
hint: 解析器找的是第一个结束围栏
explain: 题干里的围栏会被当成结束标记，options 和 answer 读不到，页面显示成没有选项的题。
```

## 本节测验

```quiz
type: choice
exam: true
answer: 0
q: code: 字段里的代码会被执行吗？
options:
- 不会，只做只读展示
- 会执行，结果作为题干
- 会执行并判分
- 取决于语言
explain: code 字段只展示。要考运行结果就用题型的判分机制，比如 code 题的 tests。
```

```quiz
type: choice
exam: true
answer: 0
q: code: 块里写函数，函数体应该缩进几格？
options:
- 相对块基础缩进再多两格（共四格）
- 两格
- 不用缩进
- 八格
explain: 块基础缩进两格，Python 函数体再缩进两格，所以是四格。
```
