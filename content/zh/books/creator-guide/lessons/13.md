# 13 多选题

> 加一行 multi: true，答案用逗号分隔。

## 写法

和单选题几乎一样，只多一行 `multi: true`：

```quiz 示意
type: choice
multi: true
q: 下面哪些是可变类型？
options:
- list
- dict
- tuple
- str
answer: 0, 1
```

**`multi: true` 决定了渲染成复选框还是单选框。** 少了这一行，即使 answer 写了多个，也只会渲染成单选 —— 读者根本没法选两个。

## answer 用逗号分隔多个下标

```
answer: 0, 1       选第 1 和第 2 个
answer: 0,2        空格可有可无
```

每个下标都会单独检查越界。`answer: 0, 5` 但只有 4 个选项，会报错。

## 判分是「全对才对」

多选题的判分规则是：**选中的集合必须和答案集合完全一致**。少选一个、多选一个都算错。

所以在题干里最好写明有几个正确答案：

```
q: 下面哪些是可变类型？（多选，2 个）
```

不写明数量的话，读者会纠结「我是不是漏了」。

## 什么时候用多选

多选题适合考「哪些属于某一类」这种集合概念：哪些是可变类型、哪些是标准库、哪些写法会报错。

不适合考有唯一答案的东西 —— 那种用单选。

## 小结

- 必须有 `multi: true`
- `answer` 用逗号分隔下标
- 必须全选对才得分
- 题干里写明有几个正确答案

## 随堂练习

```quiz
type: choice
answer: 0
q: 少了 multi: true 这一行，会怎样？
options:
- 渲染成单选框，读者没法选多个
- 自动识别为多选
- 报错
- 不显示这道题
hint: 看 answer 有几个值没用
explain: multi 决定渲染形态。没有它就渲染成单选，即使 answer 写了多个值。
```

## 本节测验

```quiz
type: choice
exam: true
answer: 0
q: 多选题的判分规则是什么？
options:
- 选中的集合必须和答案完全一致
- 选对任意一个就算对
- 按比例给分
- 多选不判分
explain: 少选、多选都算错，所以题干最好写明有几个正确。
```

```quiz
type: choice
exam: true
answer: 0
q: 答案有 4 个选项，正确答案是第 1 和第 3 个，answer 怎么写？
options:
- 0, 2
- 1, 3
- 0,2,
- 1 3
hint: 下标从 0 开始，用逗号分隔
explain: 第 1 个是下标 0，第 3 个是下标 2，所以写 0, 2。
```
