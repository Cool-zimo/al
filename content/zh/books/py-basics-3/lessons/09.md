# CSV 文件

> 表格数据最通用的交换格式。Excel 能打开，pandas 能读，Python 也能处理。

## CSV 长什么样

```
姓名,年龄,城市
张三,18,北京
李四,20,上海
王五,19,广州
```

**规则很简单**：
- 一行一条记录
- 字段之间用**逗号**分隔（CSV = Comma-Separated Values）
- 第一行通常是**表头**

**它本质上就是个文本文件**——用记事本也能打开。

## 用 csv 模块读

```python
import csv

with open('people.csv', 'r', encoding='utf-8') as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)
```

```
['姓名', '年龄', '城市']
['张三', '18', '北京']
['李四', '20', '上海']
['王五', '19', '广州']
```

**每一行是一个列表**。

**注意：所有值都是字符串**——`'18'` 不是数字 18。

```python
age = row[1]              # '18'
age = int(row[1])         # 18  ← 要自己转
```

## 跳过表头

```python
import csv

with open('people.csv', 'r', encoding='utf-8') as f:
    reader = csv.reader(f)
    header = next(reader)          # 读掉第一行
    print("表头：", header)
    for row in reader:
        print(f"{row[0]} 今年 {row[1]} 岁")
```

**`next(reader)` 取下一行**，用来吃掉表头。

## DictReader：按列名取（推荐）

```python
import csv

with open('people.csv', 'r', encoding='utf-8') as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row['姓名'], row['年龄'])
```

**`DictReader` 把每行变成字典**，用表头当键：

```
{'姓名': '张三', '年龄': '18', '城市': '北京'}
```

**比 `row[0]` 清楚多了**——不用记第几列是什么。

## 写 CSV

```python
import csv

data = [
    ['姓名', '年龄', '城市'],
    ['张三', 18, '北京'],
    ['李四', 20, '上海'],
]

with open('out.csv', 'w', encoding='utf-8', newline='') as f:
    writer = csv.writer(f)
    writer.writerows(data)
```

> ⚠️ **`newline=''` 必须加！** 否则在 Windows 上每行之间会多一个空行。

**原因**：csv 模块自己写 `\r\n`，而 Windows 的文本模式会把 `\n` 再转成 `\r\n`，于是变成 `\r\r\n`。

## 一行一行写

```python
with open('out.csv', 'w', encoding='utf-8', newline='') as f:
    writer = csv.writer(f)
    writer.writerow(['姓名', '年龄'])       # 写一行
    writer.writerow(['张三', 18])
```

**`writerow` 写一行，`writerows` 写多行。**

## DictWriter：按列名写

```python
import csv

with open('out.csv', 'w', encoding='utf-8', newline='') as f:
    fieldnames = ['姓名', '年龄', '城市']
    writer = csv.DictWriter(f, fieldnames=fieldnames)

    writer.writeheader()                              # 写表头
    writer.writerow({'姓名': '张三', '年龄': 18, '城市': '北京'})
    writer.writerow({'姓名': '李四', '年龄': 20, '城市': '上海'})
```

**`writeheader()` 写表头**，然后每行传字典。

## 一个必踩的坑：字段里有逗号

如果某个值本身包含逗号，直接拼字符串会错位：

```python
# ❌ 手写的话，"北京,朝阳" 会被当成两列
line = f"{name},{city}"
```

**csv 模块会自动加引号处理**：

```python
import csv
with open('t.csv', 'w', encoding='utf-8', newline='') as f:
    w = csv.writer(f)
    w.writerow(['张三', '北京,朝阳'])      # 自动加引号
```

写出来是：

```
张三,"北京,朝阳"
```

**这就是要用 csv 模块而不要手写拼接的原因。**

## 实战：成绩单

```python
import csv

scores = [
    {'姓名': '张三', '语文': 80, '数学': 90},
    {'姓名': '李四', '语文': 95, '数学': 88},
    {'姓名': '王五', '语文': 78, '数学': 92},
]

# 写入
with open('scores.csv', 'w', encoding='utf-8', newline='') as f:
    writer = csv.DictWriter(f, fieldnames=['姓名', '语文', '数学'])
    writer.writeheader()
    writer.writerows(scores)

# 读回并算平均分
with open('scores.csv', 'r', encoding='utf-8') as f:
    rows = list(csv.DictReader(f))

for r in rows:
    avg = (int(r['语文']) + int(r['数学'])) / 2
    print(f"{r['姓名']}：平均 {avg}")
```

```
张三：平均 85.0
李四：平均 91.5
王五：平均 85.0
```

## csv vs pandas

学完数据分析 2 你会知道 pandas 的 `read_csv` 更好用：

```python
import pandas as pd
df = pd.read_csv('scores.csv')      # 一行搞定，还自动识别类型
```

**但 csv 模块也有它的价值**：
- 标准库，不用装任何东西
- 处理超大文件时更省内存（逐行流式）
- 逻辑简单时代码更少

## 小结

| 需求 | 写法 |
|---|---|
| 读（列表） | `csv.reader(f)` |
| 读（字典） | `csv.DictReader(f)` ← 推荐 |
| 写（列表） | `csv.writer(f)` + `writerow(s)` |
| 写（字典） | `csv.DictWriter(f, fieldnames=...)` |
| **写文件时** | **必须加 `newline=''`** |
| 跳过表头 | `next(reader)` |
| 值的类型 | **全是字符串**，要自己转 |
