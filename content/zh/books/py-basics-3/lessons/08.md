# os 模块：操作文件与文件夹

> 除了读写，你还需要"创建、删除、改名、遍历"——这些都在 os 模块里。

## 先导入

```python
import os
```

## 创建文件夹

```python
os.mkdir('new_folder')          # 创建单个文件夹
os.makedirs('a/b/c')            # 创建多层（父目录不存在也一并建）
```

**区别**：

```python
# ❌ 如果 a 不存在，mkdir 会报错
os.mkdir('a/b')

# ✅ makedirs 会把 a、a/b 都建出来
os.makedirs('a/b')
```

> ⚠️ **文件夹已存在时会报错**（FileExistsError）。

**安全的写法**：

```python
os.makedirs('logs', exist_ok=True)      # 已存在也不报错
```

**`exist_ok=True` 是常用的防御**，避免每次运行都崩。

## 删除

```python
os.remove('a.txt')         # 删文件
os.rmdir('empty_dir')      # 删空文件夹（不空会报错）
```

> ⚠️ **`os.remove` 不会进回收站，删了就没了。** 操作前最好确认一下。

删非空文件夹要用 `shutil`：

```python
import shutil
shutil.rmtree('folder')        # 连内容一起删
```

**这个更危险，用之前务必确认路径。**

## 改名 / 移动

```python
os.rename('old.txt', 'new.txt')

# 移动到另一个文件夹
os.rename('a.txt', 'backup/a.txt')
```

**改名和移动是同一个操作**——都是改路径。

## 列出目录内容

```python
print(os.listdir('.'))        # 当前目录下有什么
```

```
['main.py', 'data.txt', 'logs']
```

**`listdir` 返回名字的列表**（不含路径）。

要遍历子文件夹：

```python
for root, dirs, files in os.walk('.'):
    print(f"目录：{root}")
    print(f"  文件夹：{dirs}")
    print(f"  文件：{files}")
```

**`os.walk` 会递归走遍所有子目录**，找文件时很有用：

```python
# 找出所有 .py 文件
for root, dirs, files in os.walk('.'):
    for name in files:
        if name.endswith('.py'):
            print(os.path.join(root, name))
```

## 用 pathlib 更清爽

```python
from pathlib import Path

p = Path('logs')
p.mkdir(exist_ok=True)              # 创建

# 遍历某类文件
for f in Path('.').glob('*.py'):
    print(f)

# 递归遍历
for f in Path('.').rglob('*.py'):
    print(f)
```

**`glob('*.py')` 匹配当前目录，`rglob('*.py')` 递归所有子目录。**

比 `os.walk` 简洁得多。

## 查看文件信息

```python
import os
from datetime import datetime

stat = os.stat('data.txt')
print(stat.st_size)                                  # 大小（字节）
print(datetime.fromtimestamp(stat.st_mtime))         # 最后修改时间
```

**`st_mtime` 是时间戳**（从 1970 年起的秒数），要用 `datetime.fromtimestamp` 转成能读的时间。

## 实战：整理下载文件夹

把一堆文件按扩展名归类：

```python
import os
import shutil

folder = 'downloads'
types = {
    '.jpg': 'images', '.png': 'images', '.gif': 'images',
    '.mp4': 'videos', '.mov': 'videos',
    '.pdf': 'docs',  '.txt': 'docs',
}

for name in os.listdir(folder):
    src = os.path.join(folder, name)
    if not os.path.isfile(src):
        continue                       # 跳过文件夹

    _, ext = os.path.splitext(name)
    target_dir = types.get(ext.lower(), 'others')

    dst_dir = os.path.join(folder, target_dir)
    os.makedirs(dst_dir, exist_ok=True)

    shutil.move(src, os.path.join(dst_dir, name))
    print(f"{name} → {target_dir}")

print("整理完成")
```

**这个脚本用到了**：`listdir` 遍历、`isfile` 判断、`splitext` 取扩展名、`makedirs` 建目录、`shutil.move` 移动。

## 一个安全习惯

**涉及删除和覆盖的操作，先打印、后执行**：

```python
# 先看看会删什么
to_delete = [f for f in os.listdir('.') if f.endswith('.tmp')]
print("将被删除：", to_delete)

# 确认没问题再真删
# for f in to_delete:
#     os.remove(f)
```

**先注释掉危险的那几行，跑一遍看看清单对不对**，再取消注释。

## 常用函数速查

| 需求 | 写法 |
|---|---|
| 建文件夹 | `os.makedirs(p, exist_ok=True)` |
| 删文件 | `os.remove(p)` |
| 删空目录 | `os.rmdir(p)` |
| 删非空目录 | `shutil.rmtree(p)` |
| 改名/移动 | `os.rename(a, b)` / `shutil.move(a, b)` |
| 列目录 | `os.listdir(p)` |
| 递归遍历 | `os.walk(p)` / `Path(p).rglob('*')` |
| 当前目录 | `os.getcwd()` |
| 拼接 | `os.path.join(a, b)` |
| 判断 | `os.path.exists` / `isfile` / `isdir` |
