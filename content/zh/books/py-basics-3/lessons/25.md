# 实战：一个学生管理系统

> 把类和文件持久化结合起来，做一个真正有结构的项目。

## 要做什么

一个**学生管理系统**：

- 添加学生（姓名、学号、成绩）
- 查看全部
- 按姓名搜索
- 算班级平均分
- 保存到 JSON / 从 JSON 加载

**关键**：用类来组织，而不是一堆散装函数。

## 设计类

先想清楚"有哪些东西"：

| 类 | 负责什么 | 属性 | 方法 |
|---|---|---|---|
| `Student` | 一个学生 | name, sid, scores | add_score, average |
| `Classroom` | 一个班级 | name, students | add, find, average, save, load |

**两个类，各管一层**——这叫"分层设计"。

## Student 类

```python
class Student:
    """一个学生"""

    def __init__(self, name, sid):
        self.name = name
        self.sid = sid
        self.scores = []

    def add_score(self, score):
        if not 0 <= score <= 100:
            raise ValueError(f"成绩必须在 0~100，收到 {score}")
        self.scores.append(score)

    @property
    def average(self):
        if not self.scores:
            return None
        return sum(self.scores) / len(self.scores)

    def to_dict(self):
        """转成字典，方便存 JSON"""
        return {'name': self.name, 'sid': self.sid, 'scores': self.scores}

    @classmethod
    def from_dict(cls, d):
        """从字典还原对象"""
        s = cls(d['name'], d['sid'])
        s.scores = d['scores']
        return s

    def __str__(self):
        avg = self.average
        avg_text = f"{avg:.1f}" if avg is not None else "无成绩"
        return f"{self.name}（{self.sid}）平均 {avg_text}"

    def __repr__(self):
        return f"Student(name='{self.name}', sid='{self.sid}')"
```

**几个要点**：

- **`average` 用 `@property`**——它是"算出来的属性"，不是动作
- **`to_dict` / `from_dict`**——对象和 JSON 之间转换的标准做法
- **`@classmethod`**——`cls` 是类本身，用于"造一个本类的对象"

## Classroom 类

```python
import json


class Classroom:
    """一个班级"""

    def __init__(self, name):
        self.name = name
        self.students = []

    def add(self, student):
        if self.find(student.sid):
            raise ValueError(f"学号 {student.sid} 已存在")
        self.students.append(student)

    def find(self, sid):
        for s in self.students:
            if s.sid == sid:
                return s
        return None

    def search(self, keyword):
        return [s for s in self.students if keyword in s.name]

    @property
    def average(self):
        avgs = [s.average for s in self.students if s.average is not None]
        if not avgs:
            return None
        return sum(avgs) / len(avgs)

    def save(self, filename):
        data = [s.to_dict() for s in self.students]
        with open(filename, 'w', encoding='utf-8') as f:
            json.dump(data, f, ensure_ascii=False, indent=2)

    def load(self, filename):
        try:
            with open(filename, 'r', encoding='utf-8') as f:
                content = f.read()
        except FileNotFoundError:
            return          # 第一次运行，没有文件很正常

        if not content.strip():
            return

        try:
            data = json.loads(content)
        except json.JSONDecodeError:
            print("文件损坏，以空班级启动")
            return

        self.students = [Student.from_dict(d) for d in data]

    def __str__(self):
        return f"{self.name}：{len(self.students)} 名学生"
```

## 主程序

```python
FILE = 'classroom.json'


def add_student(cls_room):
    name = input("姓名：").strip()
    if not name:
        print("姓名不能为空")
        return
    sid = input("学号：").strip()

    student = Student(name, sid)
    try:
        cls_room.add(student)
    except ValueError as e:
        print(f"  ✗ {e}")
        return

    print("输入成绩（直接回车结束）：")
    while True:
        raw = input("  > ").strip()
        if not raw:
            break
        try:
            student.add_score(float(raw))
        except ValueError as e:
            print(f"    {e}")

    print(f"  ✓ 已添加 {student}")


def show_all(cls_room):
    if not cls_room.students:
        print("还没有学生")
        return
    for i, s in enumerate(cls_room.students, 1):
        print(f"{i}. {s}")


def main():
    room = Classroom("高三(1)班")
    room.load(FILE)
    print(room)

    while True:
        print("\n1.添加  2.查看  3.搜索  4.班级平均  5.保存  6.退出")
        choice = input("选择：").strip()

        if choice == '1':
            add_student(room)
        elif choice == '2':
            show_all(room)
        elif choice == '3':
            key = input("关键词：").strip()
            found = room.search(key)
            if found:
                for s in found:
                    print(" ", s)
            else:
                print("没有找到")
        elif choice == '4':
            avg = room.average
            if avg is None:
                print("还没有成绩")
            else:
                print(f"班级平均：{avg:.1f}")
        elif choice == '5':
            room.save(FILE)
            print("  ✓ 已保存")
        elif choice == '6':
            room.save(FILE)
            print("再见")
            break
        else:
            print("请输入 1~6")


if __name__ == "__main__":
    main()
```

## 为什么用类之后更好

**对比"散装函数"版本**：

```python
# 不用类
students = [{'name': '张三', 'sid': '001', 'scores': []}]
def add_score(students, sid, score): ...
def find(students, sid): ...
def average(students): ...
```

**问题**：
- 每个函数都要传 `students`
- `students` 的结构靠约定
- 想加个"班级名字"字段，所有地方都要改

**用类之后**：
- `room.add(s)` —— 数据在自己身上
- 结构写在类里，一目了然
- 加字段只改类

## 一个关键设计：`to_dict` / `from_dict`

**JSON 只能存基本类型，存不了对象。**

```python
# ❌ 不行
json.dump(room.students, f)      # TypeError: Object of type Student is not JSON serializable
```

**所以要来回转换**：

```python
# 存：对象 → 字典 → JSON
data = [s.to_dict() for s in students]
json.dump(data, f)

# 读：JSON → 字典 → 对象
data = json.load(f)
students = [Student.from_dict(d) for d in data]
```

**这是所有"对象持久化"的标准套路**——数据库 ORM 也是这个思路。
