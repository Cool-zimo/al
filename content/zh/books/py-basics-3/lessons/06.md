# with 语句：再也不用 close

> 忘记 `close()` 是文件操作最常见的错误。`with` 让这件事彻底消失。

## 问题：close() 总会忘

```python
f = open('note.txt', 'w', encoding='utf-8')
f.write("重要数据")
# ... 中间如果报错，下面这行就执行不到
f.close()
```

**只要中间出任何错，`close()` 就不会执行**，数据可能丢失、文件一直被占用。

更糟的是，**写完立刻忘了 close** 的情况非常普遍：

```python
def save(data):
    f = open('data.txt', 'w', encoding='utf-8')
    f.write(data)
    # 忘了 close()
    return "保存成功"    # 实际上可能还没写到硬盘
```

## with 的写法

```python
with open('note.txt', 'w', encoding='utf-8') as f:
    f.write("重要数据")

# 到这里，文件已经自动关闭了
print("文件已关闭")
```

**格式**：

```python
with open(...) as 变量名:
    对这个变量做操作
# 缩进结束 → 自动关闭
```

**离开 `with` 块时，Python 保证文件被关闭**——哪怕块里出了错。

## 为什么能保证？

`with` 背后是一个叫"上下文管理器"的机制，简单说就是：

1. 进入 `with` 块时，自动做"准备工作"（打开文件）
2. **无论块内正常结束还是报错**，都会自动做"收尾工作"（关闭文件）

```python
with open('a.txt', 'w', encoding='utf-8') as f:
    f.write("数据")
    raise ValueError("出错了！")     # 故意报错

# 即便报错，文件也已经关闭了
```

**这就是 `with` 的价值：把"一定会执行"的事交给语言，不靠你的记性。**

## 验证一下

```python
f = open('t.txt', 'w', encoding='utf-8')
with f:
    f.write("内容")
    print("块内 closed?", f.closed)      # False

print("块外 closed?", f.closed)          # True
```

**`f.closed` 是文件对象的属性**，True 表示已关闭。

## 同时打开多个文件

```python
with open('src.txt', 'r', encoding='utf-8') as src, \
     open('dst.txt', 'w', encoding='utf-8') as dst:
    dst.write(src.read())
```

**一行 `with` 打开两个文件**——复制文件就这么简单。

也可以写成：

```python
with (
    open('src.txt', 'r', encoding='utf-8') as src,
    open('dst.txt', 'w', encoding='utf-8') as dst,
):
    dst.write(src.read())
```

（括号写法需要 Python 3.9+，更清晰。）

## 实战：复制文件

```python
# 复制文本
with open('a.txt', 'r', encoding='utf-8') as src, \
     open('b.txt', 'w', encoding='utf-8') as dst:
    dst.write(src.read())

# 复制图片（二进制）
with open('photo.jpg', 'rb') as src, \
     open('copy.jpg', 'wb') as dst:
    dst.write(src.read())
```

**大文件逐行复制**（避免一次读入内存）：

```python
with open('big.txt', 'r', encoding='utf-8') as src, \
     open('copy.txt', 'w', encoding='utf-8') as dst:
    for line in src:
        dst.write(line)
```

## with 不止用于文件

**任何需要"用完必须收尾"的东西都适合 `with`**：

```python
# 数据库连接
with connect() as conn:
    conn.execute(...)
# 自动断开

# 线程锁
with lock:
    修改共享数据
# 自动释放
```

现阶段你只要记住：**打开文件就用 `with`。**

## 一个对比

| 写法 | 会不会忘关 | 出错时 |
|---|---|---|
| `f = open(); ...; f.close()` | **容易忘** | 出错就关不掉 |
| `with open() as f:` | **不可能忘** | 出错也保证关闭 |

**结论：永远用 `with`。** 手写 `open()` + `close()` 的写法，只在极少数需要长期持有文件时才用。

## 小结

- **`with open(...) as f:`** —— 离开缩进块自动关闭
- **出错也保证关闭**（这是手写 close 做不到的）
- 可以一行打开多个文件
- **大文件复制用逐行写入**
- 打开文件就想到 `with`，不要手写 `close()`
