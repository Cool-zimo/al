# else 与 finally

> `try` 的完整形态有四个部分。后两个不常用，但用对了代码会干净很多。

## 完整形态

```python
try:
    可能出错的代码
except 错误类型:
    出错了怎么办
else:
    没出错才执行
finally:
    无论如何都执行
```

**四个部分，只有 `try` 是必需的。**

## else：没出错才执行

```python
try:
    n = int("42")
except ValueError:
    print("转换失败")
else:
    print(f"转换成功：{n}")        # 只在没出错时执行
```

**为什么要单独有个 `else`？** 直接写在 `try` 里不行吗？

```python
# ❌ 混在一起的问题
try:
    n = int(user_input)
    print(f"转换成功：{n}")        # ← 这行如果出错，会被下面的 except 抓走
except ValueError:
    print("转换失败")
```

**区别在于**：`try` 里所有代码的错误都会被 `except` 捕获。如果你只想让"转换"这一步受保护，其他代码不该被误抓，就用 `else`：

```python
# ✅ 只有 int() 受保护
try:
    n = int(user_input)
except ValueError:
    print("转换失败")
else:
    # 这里的错误不会被上面的 except 抓走 —— 会正常报出来
    print(f"转换成功：{n}")
    save_to_db(n)                  # 万一这里有 bug，你能看见真正的报错
```

> 💡 **`else` 让"受保护的范围"更精确**，避免掩盖其他 bug。

## finally：无论如何都执行

```python
try:
    f = open('data.txt', 'r', encoding='utf-8')
    content = f.read()
except FileNotFoundError:
    print("文件不存在")
finally:
    print("这一步一定会执行")
```

**`finally` 里的代码，无论是否出错、无论有没有 `return`，都会执行。**

### 经典的用法：资源清理

```python
f = None
try:
    f = open('data.txt', 'r', encoding='utf-8')
    content = f.read()
    print(content)
except FileNotFoundError:
    print("文件不存在")
finally:
    if f:
        f.close()          # 无论如何都关掉
        print("文件已关闭")
```

**这就是 `with` 语句背后的原理**——`with` 本质上就是 `try/finally` 的语法糖。

> 💡 既然有了 `with`，文件操作基本不需要手写 `finally`。但**网络连接、数据库连接**这些没有 `with` 的场景，`finally` 依然是标准做法。

### finally 连 return 都拦不住

```python
def demo():
    try:
        return "从 try 返回"
    finally:
        print("finally 执行了")      # return 之前先执行这里

print(demo())
```

```
finally 执行了
从 try 返回
```

**即便 `try` 里有 `return`，`finally` 也会先执行完再返回。**

## 三个可选部分的对比

| 部分 | 什么时候执行 |
|---|---|
| `except` | **出错时** |
| `else` | **没出错时** |
| `finally` | **无论如何** |

```
try 里的代码
    ├─ 出错 → except → finally
    └─ 没出错 → else → finally
```

## 实战：一个健壮的读取函数

```python
import json


def load_config(path):
    """读配置文件，任何情况下都不会崩"""
    try:
        with open(path, 'r', encoding='utf-8') as f:
            config = json.load(f)
    except FileNotFoundError:
        print(f"[警告] {path} 不存在，使用默认配置")
        return {}
    except json.JSONDecodeError:
        print(f"[错误] {path} 格式不是合法 JSON")
        return {}
    except PermissionError:
        print(f"[错误] 没有权限读取 {path}")
        return {}
    else:
        print(f"[成功] 已加载 {len(config)} 项配置")
        return config


config = load_config('config.json')
print(config)
```

**这个函数无论遇到什么情况都会返回一个字典**——调用它的人完全不用操心。

## 什么时候用 else？

**只有当你想"缩小 try 的保护范围"时才用。**

大多数情况下，把代码都放 `try` 里就够了：

```python
# 常见写法（够用）
try:
    n = int(input("数字："))
    print(f"结果是 {n * 2}")
except ValueError:
    print("不是数字")
```

**`else` 是给"我只要保护这一行"的精细场景准备的。**

## 小结

- **`except`**：出错时执行
- **`else`**：**没出错**时执行（缩小保护范围时用）
- **`finally`**：**无论如何**都执行（清理资源）
- `with` 就是 `try/finally` 的语法糖
- `finally` 连 `return` 都能拦住
