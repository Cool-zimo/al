# 定义类与创建对象

> 上一课看了长什么样，这一课把每个部分拆开讲。

## 类的定义

```python
class 类名:
    def 方法名(self, 参数):
        ...
```

**最简形式**：

```python
class Dog:
    pass          # 什么都不做，合法
```

**`pass` 是占位符**——语法上需要一条语句，但你还不想写内容时用。

## 创建对象的语法

```python
class Dog:
    def bark(self):
        return "汪"

d = Dog()          # ← 创建对象（实例化）
print(d.bark())
```

**`类名()` 就是"造一个对象"**，像调用函数一样。

## 一个完整的类

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        return f"{self.name}：汪！"

    def get_human_age(self):
        return self.age * 7


d1 = Dog("小黑", 3)
d2 = Dog("小白", 5)

print(d1.bark())              # 小黑：汪！
print(d2.bark())              # 小白：汪！
print(d1.get_human_age())     # 21
```

**两个对象各有各的数据**（名字、年龄不同），但**共享同一套方法**。

## `__init__`：构造方法

```python
def __init__(self, name, age):
    self.name = name
    self.age = age
```

**`__init__` 在创建对象时自动调用**，用来"初始化"对象的属性。

**名字两边各有两根下划线**（`__init__`），这种叫**魔术方法 / 特殊方法**——Python 会在特定时机自动调用它们。

```python
d = Dog("小黑", 3)
#     ↓ 等价于
# d = Dog.__init__(d, "小黑", 3)
```

**你从不直接调用 `__init__`**——`Dog("小黑", 3)` 时 Python 自动调用。

## `self` 是什么

**`self` 指代"这个对象自己"。**

```python
class Dog:
    def bark(self):
        return f"{self.name}：汪！"     # self.name = 这只狗的名字
```

**为什么需要它？** 因为方法被很多对象共享，方法内部需要知道"现在是哪个对象在调用我"。

```python
d1 = Dog("小黑", 3)
d2 = Dog("小白", 5)

d1.bark()     # Python 实际执行：Dog.bark(d1)  → self 是 d1
d2.bark()     # Python 实际执行：Dog.bark(d2)  → self 是 d2
```

**这就是 `self` 的全部秘密**：调用 `d1.bark()` 时，Python 自动把 `d1` 作为第一个参数传进去。

> 💡 **所以方法第一个参数必须写 `self`**（名字可以改，但千万别改——所有人都在用 `self`）。**调用时不用传它。**

## 属性：对象的变量

```python
class Dog:
    def __init__(self, name):
        self.name = name        # ← 定义属性
```

**`self.xxx = 值` 就是给对象添加一个属性。**

**属性可以随时加**（不一定要在 `__init__` 里）：

```python
d = Dog("小黑")
d.color = "黑色"        # 后加的，合法
print(d.color)
```

> ⚠️ **但不推荐这么做**——属性散落各处会很难维护。**最好在 `__init__` 里把所有属性都定义好**，哪怕先设为 None：

```python
class Dog:
    def __init__(self, name):
        self.name = name
        self.color = None        # 先占位，之后赋值
        self.tricks = []         # 先给个空列表
```

## 访问和修改属性

```python
d = Dog("小黑", 3)
print(d.name)          # 读
d.name = "大黑"        # 写
print(d.name)          # 大黑
```

**Python 的属性是公开可改的**——没有真正的"私有"（那是 Java/C++ 的概念）。

**约定**：单下划线开头表示"内部用，别从外面改"：

```python
class BankAccount:
    def __init__(self):
        self._balance = 0        # 约定：内部用
```

（第 26 课会讲 `@property` 提供更优雅的控制。）

## 方法就是类里的函数

```python
class Calculator:
    def add(self, a, b):
        return a + b

    def multiply(self, a, b):
        return a * b
```

**除了第一个参数是 `self`，方法定义和普通函数完全一样。**

**如果一个方法不用到 self**，可以这么写：

```python
class MathUtils:
    @staticmethod
    def add(a, b):          # 没有 self
        return a + b

print(MathUtils.add(1, 2))      # 不用创建对象就能调用
```

**`@staticmethod`** 表示"这是挂在类上的普通函数，不需要对象"。（进阶内容，了解即可。）

## 一个完整的例子

```python
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("存款必须大于 0")
        self.balance += amount
        return self.balance

    def withdraw(self, amount):
        if amount > self.balance:
            raise ValueError("余额不足")
        self.balance -= amount
        return self.balance

    def __str__(self):
        return f"{self.owner} 的账户，余额 {self.balance}"


acc = BankAccount("张三", 100)
acc.deposit(50)
print(acc.balance)        # 150
acc.withdraw(30)
print(acc)                # 张三 的账户，余额 120
```

**`__str__`** 是另一个魔术方法——定义 `print(对象)` 时显示什么。（第 26 课细讲。）

## 小结

| 概念 | 写法 |
|---|---|
| 定义类 | `class 类名:` |
| 构造方法 | `def __init__(self, ...)` —— 创建时自动调用 |
| `self` | 指代"这个对象"，**调用时不用传** |
| 属性 | `self.xxx = 值`，建议在 `__init__` 里定义 |
| 方法 | 类里的函数，第一个参数是 `self` |
| 创建对象 | `类名(参数)` |
