# 为什么需要模块

> 一个文件装 2000 行代码会怎样？会很糟糕。模块就是"把代码分文件"这件事。

## 一个文件写到底的问题

假设你写了个小工具，功能越来越多：

```python
# app.py —— 现在 800 行了
def read_config(): ...
def connect_db(): ...
def add_task(): ...
def show_tasks(): ...
def delete_task(): ...
def format_date(): ...
def validate_email(): ...
# ...还有 30 个函数

while True:
    ...
```

**问题**：
1. **找东西难**——想改 `validate_email`，得滚半天
2. **命名冲突**——两个功能都想用 `parse()` 这个名字
3. **没法复用**——想在另一个项目里用 `format_date`，只能复制粘贴
4. **协作困难**——两个人同时改这一个文件，必然冲突

## 模块就是"一个 .py 文件"

**在 Python 里，一个 `.py` 文件就是一个模块。**

```
project/
├── app.py           ← 主程序（也是一个模块）
├── config.py        ← 配置相关
├── database.py      ← 数据库相关
└── utils.py         ← 通用小工具
```

**每个文件管一块事**，需要的时候互相导入。

## 用 import 把模块拿进来

```python
# app.py
import utils

utils.format_date(...)      # 用 utils 里的函数
```

**就这么简单**——`import 模块名`，然后用 `模块名.函数` 调用。

## 模块的三个层次

| 层次 | 是什么 | 例子 |
|---|---|---|
| **模块 module** | 一个 `.py` 文件 | `utils.py` |
| **包 package** | 一个**装模块的文件夹** | `utils/` |
| **库 library** | 一堆包的集合 | requests、pandas |

**现在你只需要知道：模块 = 一个 .py 文件。**

## 模块的三种来源

```python
import math                 # ① 标准库（Python 自带，装好就能用）
import pandas as pd         # ② 第三方库（pip install 装的）
import my_utils             # ③ 你自己写的
```

**这一章三种都会讲到。**

## 先看标准库

Python 自带了非常多的模块，**不用装任何东西**：

```python
import math
print(math.pi)              # 3.141592653589793
print(math.sqrt(16))        # 4.0

import random
print(random.randint(1, 10))    # 1~10 的随机整数

import datetime
print(datetime.date.today())    # 今天的日期
```

> 💡 **写 Python 的一大优势就是"标准库很全"**。遇到需求先查查标准库有没有，别急着装第三方库。

## 一个重要的概念：命名空间

```python
import math

pi = 3        # 你自己的变量
print(pi)         # 3
print(math.pi)    # 3.14159...
```

**`math.pi` 和你的 `pi` 是两个不同的东西**，互不干扰。

**这就是模块的价值之一**——它给了代码一个"姓"（`math.`），避免名字打架。

## 模块的另一个好处：缓存

```python
import math
import math        # 第二次导入不会重新执行
import math        # 再多次也一样
```

**Python 只会执行一次模块的代码**，之后重复使用缓存。

（这意味着：如果模块里有 `print`，它只打印一次。）

## 小结

- **模块 = 一个 `.py` 文件**
- 大程序拆成多个模块：**好找、不冲突、能复用、好协作**
- `import 模块名` → `模块名.函数()` 使用
- 三种来源：标准库、第三方库、自己写的
- **模块提供命名空间**，避免名字冲突

## 随堂练习

用标准库。

```quiz
type: code
q: 用 math 模块求 16 的平方根并打印
starter: |
  import math
  
  # math.sqrt(16) 应该是 4.0
  
  print("在这里改")
tests:
- assert "4" in __out
hint: print(math.sqrt(16))。import math 后用 math.函数名 调用 —— 模块名就是命名空间前缀。
explain: import 之后用"模块名.函数"调用，这样 math.sqrt 和你自己的 sqrt 不会冲突。这就是模块作为命名空间的价值。
```
