# 方法与属性控制

> 这一课讲几个让类更好用的技巧：`__str__`、默认参数、`property`。

## `__str__`：让 print 输出好看

```python
class Dog:
    def __init__(self, name):
        self.name = name

d = Dog("小黑")
print(d)        # <__main__.Dog object at 0x000001...>
```

**默认输出很难看**。加个 `__str__`：

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def __str__(self):
        return f"狗：{self.name}"

d = Dog("小黑")
print(d)        # 狗：小黑
```

**`__str__` 定义"把这个对象转成字符串时得到什么"**——`print()`、`str()`、f-string 都会用它。

> 💡 **写类时养成加 `__str__` 的习惯**——调试时能看到有意义的信息，而不是一串内存地址。

## `__repr__`：给开发者看的

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __str__(self):
        return f"狗：{self.name}"

    def __repr__(self):
        return f"Dog(name='{self.name}', age={self.age})"

d = Dog("小黑", 3)
print(str(d))        # 狗：小黑          ← 给用户看
print(repr(d))       # Dog(name='小黑', age=3)  ← 给开发者看
```

**区别**：
- `__str__`：**给用户看**，友好
- `__repr__`：**给开发者看**，应该能看出怎么重建这个对象

在列表里打印对象时用的是 `__repr__`：

```python
dogs = [Dog("小黑", 3), Dog("小白", 5)]
print(dogs)
# [Dog(name='小黑', age=3), Dog(name='小白', age=5)]
```

> 💡 只写一个的话，写 `__repr__`——`__str__` 没定义时会退回到它。

## 默认参数

```python
class Dog:
    def __init__(self, name, age=0, color="黑色"):
        self.name = name
        self.age = age
        self.color = color

d1 = Dog("小黑")                      # age=0, color="黑色"
d2 = Dog("小白", 5)                   # color="黑色"
d3 = Dog("小黄", 2, "黄色")
```

**和方法一样，参数可以有默认值**——灵活很多。

> ⚠️ **默认值不要用可变对象**（列表、字典）：

```python
# ❌ 和类属性那个坑同理
def __init__(self, name, tricks=[]):
    self.tricks = tricks      # 所有实例共享同一个列表！

# ✅ 用 None 作哨兵
def __init__(self, name, tricks=None):
    self.tricks = tricks if tricks is not None else []
```

## 方法返回 self：链式调用

```python
class Counter:
    def __init__(self):
        self.value = 0

    def add(self, n):
        self.value += n
        return self          # ← 返回自己

    def show(self):
        print(self.value)
        return self

c = Counter()
c.add(1).add(2).add(3).show()      # 6
```

**`return self` 让方法可以连着写**——像 jQuery 或 pandas 那样。

## property：把方法当属性用

**问题**：你想在赋值时做检查。

```python
class Student:
    def __init__(self, name):
        self.name = name
        self.score = 0

s = Student("张三")
s.score = 999        # ❌ 分数不该超过 100，但拦不住
```

**办法一：用方法**（但用起来啰嗦）

```python
class Student:
    def set_score(self, value):
        if not 0 <= value <= 100:
            raise ValueError("分数必须在 0~100")
        self._score = value

    def get_score(self):
        return self._score

s.set_score(95)
print(s.get_score())
```

**办法二：用 `@property`**（推荐）

```python
class Student:
    def __init__(self, name):
        self.name = name
        self._score = 0

    @property
    def score(self):
        return self._score

    @score.setter
    def score(self, value):
        if not 0 <= value <= 100:
            raise ValueError("分数必须在 0~100")
        self._score = value


s = Student("张三")
s.score = 95          # ← 看起来像普通属性赋值
print(s.score)        # 95
s.score = 999         # ValueError: 分数必须在 0~100
```

**用起来像属性，实际上走了检查逻辑**——两全其美。

**三个装饰器**：

```python
class C:
    @property
    def x(self):          # 读
        return self._x

    @x.setter
    def x(self, value):   # 写
        self._x = value

    @x.deleter
    def x(self):          # 删
        del self._x
```

## 只读属性

**只写 getter 不写 setter**，就是只读：

```python
class Circle:
    def __init__(self, radius):
        self.radius = radius

    @property
    def area(self):
        return 3.14159 * self.radius ** 2


c = Circle(5)
print(c.area)        # 78.54
c.area = 100         # ❌ AttributeError: can't set attribute
```

**面积是算出来的，不该被直接改**——只读属性正好。

## 一个完整的类

```python
class BankAccount:
    """银行账户"""

    bank_name = "Python 银行"        # 类属性

    def __init__(self, owner, balance=0):
        self.owner = owner
        self._balance = balance

    @property
    def balance(self):
        return self._balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("存款必须大于 0")
        self._balance += amount

    def withdraw(self, amount):
        if amount > self._balance:
            raise ValueError("余额不足")
        self._balance -= amount

    def __str__(self):
        return f"{self.owner} 的账户：¥{self._balance}"

    def __repr__(self):
        return f"BankAccount(owner='{self.owner}', balance={self._balance})"


acc = BankAccount("张三", 100)
acc.deposit(50)
print(acc)              # 张三 的账户：¥150
print(acc.balance)      # 150（只读，不能直接改）
```

**用到了**：类属性、实例属性、`property`、参数校验、`__str__`、`__repr__`。

## 小结

| 技巧 | 作用 |
|---|---|
| `__str__` | `print(对象)` 显示什么（给用户） |
| `__repr__` | 开发者视角的表示 |
| 默认参数 | `def __init__(self, name, age=0)` |
| `return self` | 支持链式调用 |
| `@property` | 用起来像属性，实际走检查逻辑 |
| 只读属性 | 只写 getter，不写 setter |
