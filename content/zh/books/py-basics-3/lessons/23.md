# 类属性 vs 实例属性

> 一个容易混淆的点：数据到底是"每个对象一份"还是"全类共享一份"。

## 实例属性：每个对象一份

```python
class Dog:
    def __init__(self, name):
        self.name = name        # ← 实例属性

d1 = Dog("小黑")
d2 = Dog("小白")

print(d1.name)      # 小黑
print(d2.name)      # 小白
```

**`self.name` 是实例属性**——每个对象有自己的一份，互不干扰。

```python
d1.name = "大黑"
print(d1.name)      # 大黑
print(d2.name)      # 小白    ← 没变
```

## 类属性：全类共享一份

```python
class Dog:
    species = "犬科"        # ← 类属性（写在类里，不在 __init__ 里）

    def __init__(self, name):
        self.name = name

d1 = Dog("小黑")
d2 = Dog("小白")

print(d1.species)      # 犬科
print(d2.species)      # 犬科
```

**类属性写在类的缩进里，但不在任何方法里**——所有对象共享同一个值。

**也可以通过类名访问**：

```python
print(Dog.species)      # 犬科
```

## 区别在哪

```python
class Counter:
    count = 0                  # 类属性（共享）

    def __init__(self, name):
        self.name = name       # 实例属性（各自一份）
        Counter.count += 1     # 每造一个对象，共享计数 +1


a = Counter("a")
b = Counter("b")

print(Counter.count)     # 2   ← 两个对象共同贡献
print(a.name)            # a
print(b.name)            # b
```

**类属性适合放"所有同类对象都一样的东西"**：

```python
class Config:
    VERSION = "1.0"
    MAX_SIZE = 100
    DEBUG = False
```

## 一个经典的坑

```python
class Dog:
    tricks = []              # ❌ 类属性，所有狗共享同一个列表！

    def __init__(self, name):
        self.name = name

    def learn(self, trick):
        self.tricks.append(trick)


d1 = Dog("小黑")
d1.learn("坐下")

d2 = Dog("小白")
print(d2.tricks)        # ['坐下']  ← 小白什么都没学，却也会了！
```

**为什么会这样？**

`self.tricks.append(...)` 中，`self.tricks` 找不到实例属性，就往上找到**类属性**，然后往那个共享列表里加。

**结果：所有狗共享同一个 tricks 列表。**

> ⚠️ **可变对象（列表、字典、集合）绝对不要当类属性的默认值。**

**正确写法**：

```python
class Dog:
    def __init__(self, name):
        self.name = name
        self.tricks = []         # ✅ 每只狗一个空列表

    def learn(self, trick):
        self.tricks.append(trick)
```

## 属性查找顺序

```python
d.name
```

**Python 的查找顺序**：

1. 先找**实例**有没有这个属性
2. 没有 → 找**类**有没有
3. 还没有 → 找**父类**（第 26 课讲继承）
4. 都没有 → `AttributeError`

```python
class Dog:
    species = "犬科"

    def __init__(self, name):
        self.name = name


d = Dog("小黑")
print(d.name)        # 小黑   —— 实例属性
print(d.species)     # 犬科   —— 类属性
print(d.color)       # AttributeError
```

## 给实例"覆盖"类属性

```python
d = Dog("小黑")
d.species = "猫科"        # 给这个实例加了同名实例属性

print(d.species)          # 猫科    ← 实例属性优先
print(Dog.species)        # 犬科    ← 类属性没变
```

**`d.species = ...` 是给 d 加了实例属性，没有改类属性。**

**要改类属性，必须通过类名**：

```python
Dog.species = "新值"      # ✅ 改类属性
```

## 什么时候用哪个

| | 类属性 | 实例属性 |
|---|---|---|
| 定义位置 | 类里，方法外 | `__init__` 里的 `self.x` |
| 共享性 | **所有对象共享** | **每个对象一份** |
| 适合 | 常量、计数器、默认值 | 对象的状态数据 |
| 可变对象 | ❌ **危险** | ✅ 正常 |

**经验法则**：**拿不准就用实例属性。** 只有确定"所有对象都一样且不变"时才用类属性。

## 查看属性

```python
d = Dog("小黑")

print(d.__dict__)         # {'name': '小黑'}   ← 实例属性字典
print(Dog.__dict__.keys())  # 类里定义的所有东西
```

**`__dict__` 是属性字典**，调试时很有用。

```python
print(hasattr(d, 'name'))      # True   有这个属性吗
print(getattr(d, 'name'))      # 小黑   取属性值
setattr(d, 'name', '大黑')      # 设置属性值
```

**这三个内置函数在"动态处理属性"时有用**（比如从配置里读字段名）。

## 小结

- **实例属性**（`self.x`）：每个对象一份，放状态数据
- **类属性**（类里直接写）：全类共享，放常量和计数器
- **可变对象别当类属性默认值**——会所有对象共享同一个列表
- 查找顺序：实例 → 类 → 父类
- 改类属性要用 `类名.属性 = ...`

## 随堂练习

区分类属性与实例属性。

```quiz
type: code
q: 定义类：类属性 kind = "动物"，实例属性 name；创建实例，打印这两个属性
starter: |
  class Animal:
      kind = "动物"          # 类属性
      
      def __init__(self, name):
          self.name = name   # 实例属性
  
  a = Animal("猫")
  # 打印 a.kind 和 a.name
  
  print("在这里改")
tests:
- assert "动物" in __out and "猫" in __out
hint: print(a.kind, a.name)。类属性写在类里方法外，所有实例共享；实例属性在 __init__ 里用 self.x 定义，每个实例一份。
explain: 访问 a.kind 时，实例上没有，Python 就往上找到类的 kind。而 a.name 是实例自己的数据 —— 这就是为什么两个属性都能用 a. 访问，性质却不同。
```
