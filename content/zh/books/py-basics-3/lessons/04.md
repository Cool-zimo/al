# 写文件与换行

> 读是"拿进来"，写是"送出去"。这一课讲怎么写，以及写文件时最容易出错的地方。

## 最基本的写

```python
with open('note.txt', 'w', encoding='utf-8') as f:
    f.write("今天学了文件写入")
```

**`write()` 接收一个字符串，把它写进文件。**

**注意：`write()` 不会自动换行。**

```python
with open('a.txt', 'w', encoding='utf-8') as f:
    f.write("第一行")
    f.write("第二行")
    f.write("第三行")
```

读出来是：

```
第一行第二行第三行
```

**三行挤成了一行**——因为你在 `write()` 里没写 `\n`。

## 换行必须自己加

```python
with open('a.txt', 'w', encoding='utf-8') as f:
    f.write("第一行\n")
    f.write("第二行\n")
    f.write("第三行\n")
```

现在读出来就是三行了。

> 💡 **`write()` 和 `print()` 不一样**：`print()` 默认会加换行，`write()` 完全按你给的字符串来，一个字符都不多加。

## write() 的返回值

```python
with open('a.txt', 'w', encoding='utf-8') as f:
    n = f.write("你好")
    print(n)      # 2
```

**返回写入的字符数**。中文"你好"是 2 个字符，所以返回 2。

（如果是二进制模式，返回的是字节数。）

## 一次写多行：writelines()

```python
lines = ["第一行\n", "第二行\n", "第三行\n"]

with open('a.txt', 'w', encoding='utf-8') as f:
    f.writelines(lines)
```

**`writelines()` 接收一个字符串列表**，把它们依次写进去。

> ⚠️ **名字有误导性：它同样不会自动加换行！** 列表里每个字符串必须自己带 `\n`。

```python
# ❌ 这样三行会挤在一起
f.writelines(["第一行", "第二行", "第三行"])

# ✅ 正确
f.writelines(["第一行\n", "第二行\n", "第三行\n"])

# ✅ 或者用列表推导补上
f.writelines(line + "\n" for line in ["第一行", "第二行", "第三行"])
```

## 只能写字符串

```python
# ❌ 报错：write() argument must be str, not int
f.write(42)

# ✅ 转成字符串
f.write(str(42))
f.write(f"数量：{42}")      # f-string 更好
```

**写文件时类型转换是家常便饭**，用 f-string 最顺手：

```python
name, score = "张三", 95
with open('report.txt', 'w', encoding='utf-8') as f:
    f.write(f"{name} 的成绩是 {score}\n")
```

## 追加：'a' 模式

前面讲过，复习一下：

```python
# 每次运行都往末尾加一行，历史全保留
with open('log.txt', 'a', encoding='utf-8') as f:
    f.write("程序运行了一次\n")
```

**这就是日志的基本原理。**

## 什么时候真正写到硬盘？

**Python 有缓冲**：`write()` 之后，数据可能还在内存缓冲区里，没真正落到硬盘。

三种情况会真正写入：

1. **文件关闭时**（`close()` 或 `with` 块结束）
2. **缓冲区满了**
3. **主动 `flush()`**

```python
f = open('a.txt', 'w', encoding='utf-8')
f.write("重要数据")
f.flush()      # 立刻写到硬盘（文件还开着）
# ... 继续写
f.close()
```

> ⚠️ **如果程序在 `close()` 之前崩溃，没 flush 的数据可能丢失。**  
> 这就是为什么**强烈推荐用 `with`**（第 06 课）——它保证文件一定被关闭。

## 一个实战：保存用户输入

```python
name = input("姓名：")
score = input("成绩：")

with open('students.txt', 'a', encoding='utf-8') as f:
    f.write(f"{name},{score}\n")

print("已保存")
```

**这个小程序有了"记忆"**——每次运行都会把新记录加进去，关掉再打开，以前的记录还在。

（用逗号分隔的格式叫 CSV，第 09 课会讲。）

## 小结

| 需求 | 写法 |
|---|---|
| 写字符串 | `f.write("内容")` |
| **换行** | **必须自己写 `\n`** |
| 写多行 | `f.writelines(列表)`（同样要自带 `\n`） |
| 写数字 | `str(42)` 或 f-string |
| 追加 | 模式用 `'a'` |
| 立刻落盘 | `f.flush()` |
