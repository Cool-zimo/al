# 读文件的三种方式

> `read()`、`readline()`、`readlines()`——名字很像，行为完全不同。选错了要么卡死，要么结果不对。

## 先准备一个文件

```python
with open('poem.txt', 'w', encoding='utf-8') as f:
    f.write("春眠不觉晓\n处处闻啼鸟\n夜来风雨声\n花落知多少\n")
```

## 方式一：read() —— 一次全读进来

```python
with open('poem.txt', 'r', encoding='utf-8') as f:
    content = f.read()

print(content)
print(type(content))      # <class 'str'>
```

**`read()` 把整个文件读成一个字符串**，包括里面的换行符 `\n`。

**适合**：文件不大（几 MB 以内），你想整体处理。

```python
# 想知道文件里有没有某个词
if "风雨" in content:
    print("找到了")
```

> ⚠️ **别用它读几个 G 的大文件**——会把内存撑爆。

### 可以指定读多少

```python
with open('poem.txt', 'r', encoding='utf-8') as f:
    first_10 = f.read(10)      # 只读前 10 个字符
print(first_10)
```

## 方式二：readline() —— 一次读一行

```python
with open('poem.txt', 'r', encoding='utf-8') as f:
    line1 = f.readline()
    line2 = f.readline()

print(repr(line1))      # '春眠不觉晓\n'   ← 注意末尾有 \n
print(repr(line2))      # '处处闻啼鸟\n'
```

**每次调用读一行，包括行尾的换行符 `\n`**。读到文件末尾时返回空字符串 `''`（这就是"读完了"的信号）。

**适合**：想一行一行精细控制，或文件大到不能一次读完。

```python
# 读到空字符串就停
with open('poem.txt', 'r', encoding='utf-8') as f:
    while True:
        line = f.readline()
        if line == '':        # 空字符串 = 读完了
            break
        print(line, end='')   # line 自带 \n，所以 end=''
```

## 方式三：readlines() —— 读成列表

```python
with open('poem.txt', 'r', encoding='utf-8') as f:
    lines = f.readlines()

print(lines)
print(len(lines))         # 4
```

```
['春眠不觉晓\n', '处处闻啼鸟\n', '夜来风雨声\n', '花落知多少\n']
```

**得到一个列表，每个元素是一行**（同样带 `\n`）。

**适合**：想按行号访问、想知道总行数。

```python
print(lines[0])           # 第一行
print(len(lines))         # 总行数（就是 len）
```

## 最推荐的写法：直接 for 循环

其实**遍历文件对象本身**是最 Pythonic 的方式：

```python
with open('poem.txt', 'r', encoding='utf-8') as f:
    for line in f:
        print(line, end='')
```

**优点**：
- 内存友好（一次只在内存里放一行）
- 代码最简洁
- 不用自己判断什么时候结束

> 💡 **日常写 `for line in f:` 就够了**。它兼顾了简洁和内存效率，是三种方式里最该先想到的。

## 三种方式对比

| 方法 | 返回 | 适合场景 |
|---|---|---|
| `read()` | 一个字符串（全文） | 文件小，要整体处理 |
| `readline()` | 一行字符串 | 逐行精细控制 |
| `readlines()` | 行的列表 | 要按行号取、要数行数 |
| **`for line in f`** | 逐行迭代 | **最常用，内存友好** |

## 一个必踩的坑：换行符

**读进来的每一行末尾都带着 `\n`**，直接打印会出现多余空行：

```python
with open('poem.txt', 'r', encoding='utf-8') as f:
    for line in f:
        print(line)        # ❌ 每行之间多一个空行
```

```
春眠不觉晓
              ← 多出来的空行
处处闻啼鸟
```

**三个解法**：

```python
print(line, end='')            # ① print 不追加换行
print(line.rstrip())           # ② 去掉右侧空白（推荐）
line = line.strip()            # ③ 去掉两侧空白（适合要处理内容时）
```

**`rstrip()` 只删右边**，`strip()` 两边都删。

## 实战：统计一个文件

```python
with open('poem.txt', 'r', encoding='utf-8') as f:
    lines = f.readlines()

print(f"总行数：{len(lines)}")
print(f"总字符数：{sum(len(line) for line in lines)}")

# 找出包含"风"的行
for i, line in enumerate(lines, 1):
    if "风" in line:
        print(f"第 {i} 行：{line.rstrip()}")
```

```
总行数：4
总字符数：24
第 3 行：夜来风雨声
```

## 小结

- **`read()`** 全读成字符串；**`readline()`** 读一行；**`readlines()`** 读成列表
- **日常用 `for line in f:`** —— 简洁又省内存
- **每行末尾都带 `\n`**，用 `rstrip()` 或 `print(line, end='')` 处理
- 大文件别用 `read()` 一次性读完
