# 实战：一个能记事的日记本

> 把前四课串起来，做一个真能用的东西。这是第 1 章的综合练习。

## 要做什么

一个命令行日记本，能：

1. **写新日记**（追加到文件）
2. **查看全部**（读出来显示）
3. **退出**

**关键是：关掉程序再打开，以前的日记还在。**

## 先想清楚结构

```
while True:
    显示菜单
    让用户选
    如果选 1 → 写日记
    如果选 2 → 看日记
    如果选 3 → 退出
```

这个结构你已经在基础 1 第 4、5 章学过——**判断 + 循环**。现在只是把"写日记"换成文件操作。

## 第一版：能跑起来

```python
FILE = 'diary.txt'

while True:
    print("\n=== 我的日记本 ===")
    print("1. 写日记")
    print("2. 看日记")
    print("3. 退出")

    choice = input("请选择（1/2/3）：")

    if choice == '1':
        text = input("今天想说点什么：")
        with open(FILE, 'a', encoding='utf-8') as f:
            f.write(text + "\n")
        print("已保存")

    elif choice == '2':
        with open(FILE, 'r', encoding='utf-8') as f:
            content = f.read()
        print("\n--- 日记内容 ---")
        print(content)

    elif choice == '3':
        print("再见")
        break

    else:
        print("请输入 1、2 或 3")
```

**这个文件一关，日记还在 `diary.txt` 里。** 下次运行选 2，全都能看到。

## 它现在有什么问题

**问题 1：第一次运行选"看日记"会崩溃**

```python
# 文件还不存在时就读 → FileNotFoundError
with open(FILE, 'r', encoding='utf-8') as f:
```

**问题 2：看不出每篇是哪天写的**

所有日记挤在一起，没有时间。

**问题 3：没有分隔**

读出来一长串，分不清哪段是哪次写的。

## 改进一：处理"文件不存在"

最简单的办法是**先判断文件在不在**：

```python
import os

if os.path.exists(FILE):
    with open(FILE, 'r', encoding='utf-8') as f:
        content = f.read()
    print(content)
else:
    print("还没有写过日记")
```

**`os.path.exists(路径)` 返回 True/False**，用它避开崩溃。

（第 12 课会讲更优雅的 `try/except` 写法。）

## 改进二：加上时间

```python
from datetime import datetime

now = datetime.now().strftime("%Y-%m-%d %H:%M")
```

**`strftime` 把时间格式化成字符串**：

| 占位符 | 含义 | 例子 |
|---|---|---|
| `%Y` | 四位年份 | 2026 |
| `%m` | 两位月份 | 09 |
| `%d` | 两位日期 | 27 |
| `%H` | 小时（24 小时制） | 14 |
| `%M` | 分钟 | 30 |

写日记时带上时间：

```python
with open(FILE, 'a', encoding='utf-8') as f:
    f.write(f"[{now}] {text}\n")
```

读出来就是：

```
[2026-09-27 14:30] 今天学了文件读写
[2026-09-27 15:10] 又学了这个日记本
```

## 改进三：显示行号

```python
with open(FILE, 'r', encoding='utf-8') as f:
    lines = f.readlines()

if not lines:
    print("还没有写过日记")
else:
    for i, line in enumerate(lines, 1):
        print(f"{i}. {line.rstrip()}")
```

**`if not lines`** 处理空文件——`readlines()` 得到空列表，判断一下。

## 完整版

```python
import os
from datetime import datetime

FILE = 'diary.txt'


def write_diary():
    text = input("今天想说点什么：")
    if not text.strip():
        print("内容不能为空")
        return
    now = datetime.now().strftime("%Y-%m-%d %H:%M")
    with open(FILE, 'a', encoding='utf-8') as f:
        f.write(f"[{now}] {text}\n")
    print("已保存 ✓")


def read_diary():
    if not os.path.exists(FILE):
        print("还没有写过日记")
        return
    with open(FILE, 'r', encoding='utf-8') as f:
        lines = f.readlines()
    if not lines:
        print("还没有写过日记")
        return
    print("\n--- 日记内容 ---")
    for i, line in enumerate(lines, 1):
        print(f"{i}. {line.rstrip()}")


while True:
    print("\n=== 我的日记本 ===")
    print("1. 写日记")
    print("2. 看日记")
    print("3. 退出")

    choice = input("请选择（1/2/3）：").strip()

    if choice == '1':
        write_diary()
    elif choice == '2':
        read_diary()
    elif choice == '3':
        print("再见")
        break
    else:
        print("请输入 1、2 或 3")
```

## 为什么要拆成函数

上面把"写"和"读"各自封装成了 `write_diary()` 和 `read_diary()`。

**好处**：
- `while` 循环里只有 3 行，一眼看懂流程
- 想改"写日记"的逻辑，只动那一个函数
- 函数可以单独测试

**这是"把代码打包"的思路**，第 18 课会系统讲。
