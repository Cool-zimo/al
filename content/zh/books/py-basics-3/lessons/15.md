# 实战：一个打不垮的程序

> 把异常处理的全部知识用上，写一个"怎么乱输入都不会崩"的程序。

## 目标

一个**成绩管理器**，功能：
- 添加学生成绩
- 查看全部
- 计算平均分
- 保存到文件 / 从文件加载

**要求：用户输入任何奇怪的东西都不崩溃。**

## 先看"脆弱版"

```python
# ❌ 到处都是崩溃点
students = {}

while True:
    print("1.添加  2.查看  3.平均  4.退出")
    choice = input("选择：")

    if choice == '1':
        name = input("姓名：")
        score = int(input("成绩："))        # 输入字母就崩
        students[name] = score
    elif choice == '2':
        for n, s in students.items():
            print(n, s)
    elif choice == '3':
        print(sum(students.values()) / len(students))   # 空字典时除零崩
    elif choice == '4':
        break
```

**三个崩溃点**：
1. `int(input())` —— 输入非数字
2. 平均分 —— 没人时 `len(students)` 为 0
3. 加载文件 —— 文件不存在

## 逐个补强

### 补强 1：数字输入

```python
def input_number(prompt, min_val=None, max_val=None):
    """反复要求输入，直到拿到合法数字"""
    while True:
        raw = input(prompt).strip()
        try:
            n = float(raw)
        except ValueError:
            print("  ✗ 请输入数字")
            continue

        if min_val is not None and n < min_val:
            print(f"  ✗ 不能小于 {min_val}")
            continue
        if max_val is not None and n > max_val:
            print(f"  ✗ 不能大于 {max_val}")
            continue

        return n
```

**这个"输入助手"函数值得背下来**——任何需要读数字的地方都能用。

### 补强 2：空数据的除法

```python
def average(scores):
    if not scores:
        return None            # 没数据就返回 None，不崩
    return sum(scores) / len(scores)

avg = average([])
if avg is None:
    print("还没有成绩")
else:
    print(f"平均分：{avg:.1f}")
```

**原则：可能为空时，用 `if not ...` 提前返回**，而不是让它崩。

### 补强 3：文件读写

```python
import json
import os


def load(filename):
    try:
        with open(filename, 'r', encoding='utf-8') as f:
            content = f.read()
    except FileNotFoundError:
        return {}                       # 第一次运行，没有文件很正常
    except PermissionError:
        print("没有权限读取，以空数据启动")
        return {}

    if not content.strip():
        return {}                       # 空文件

    try:
        return json.loads(content)
    except json.JSONDecodeError:
        print("文件格式损坏，以空数据启动")
        return {}


def save(filename, data):
    try:
        with open(filename, 'w', encoding='utf-8') as f:
            json.dump(data, f, ensure_ascii=False, indent=2)
        return True
    except OSError as e:                # 磁盘满、没权限等
        print(f"保存失败：{e}")
        return False
```

**注意这里有三层防护**：文件不存在、文件为空、内容不是合法 JSON。

## 完整版

```python
import json

FILE = 'students.json'


def input_number(prompt, min_val=None, max_val=None):
    """反复要求输入直到拿到合法数字"""
    while True:
        raw = input(prompt).strip()
        try:
            n = float(raw)
        except ValueError:
            print("  ✗ 请输入数字")
            continue
        if min_val is not None and n < min_val:
            print(f"  ✗ 不能小于 {min_val}")
            continue
        if max_val is not None and n > max_val:
            print(f"  ✗ 不能大于 {max_val}")
            continue
        return n


def load():
    try:
        with open(FILE, 'r', encoding='utf-8') as f:
            content = f.read()
    except FileNotFoundError:
        return {}
    except PermissionError:
        print("没有权限读取")
        return {}

    if not content.strip():
        return {}
    try:
        return json.loads(content)
    except json.JSONDecodeError:
        print("文件损坏，以空数据启动")
        return {}


def save(data):
    try:
        with open(FILE, 'w', encoding='utf-8') as f:
            json.dump(data, f, ensure_ascii=False, indent=2)
        return True
    except OSError as e:
        print(f"保存失败：{e}")
        return False


students = load()
print(f"已载入 {len(students)} 名学生")

while True:
    print("\n1.添加  2.查看  3.平均分  4.保存  5.退出")
    choice = input("选择：").strip()

    if choice == '1':
        name = input("姓名：").strip()
        if not name:
            print("  ✗ 姓名不能为空")
            continue
        score = input_number("成绩：", 0, 100)
        students[name] = score
        print(f"  ✓ 已添加 {name}")

    elif choice == '2':
        if not students:
            print("  还没有学生")
        else:
            for n, s in students.items():
                print(f"  {n}: {s}")

    elif choice == '3':
        if not students:
            print("  还没有成绩")
        else:
            avg = sum(students.values()) / len(students)
            print(f"  平均分：{avg:.1f}")

    elif choice == '4':
        if save(students):
            print("  ✓ 已保存")

    elif choice == '5':
        save(students)
        print("再见")
        break

    else:
        print("  请输入 1~5")
```

## 这个程序"打不垮"在哪

| 用户的骚操作 | 程序的反应 |
|---|---|
| 成绩输入 `abc` | "请输入数字"，重新要 |
| 成绩输入 `-5` 或 `200` | "不能小于 0" / "不能大于 100" |
| 姓名直接回车 | "姓名不能为空" |
| 还没录入就点"平均分" | "还没有成绩" |
| 菜单输入 `99` | "请输入 1~5" |
| 第一次运行（无文件） | 正常启动，0 名学生 |
| 文件被改坏了 | "文件损坏"，空数据启动 |

**每一条都考虑到了**——这就是专业和业余的区别。

## 异常处理的三个层次

回顾这一章：

| 层次 | 做什么 | 用在哪 |
|---|---|---|
| **不让它发生** | 预先检查（`if not ...`） | 自己能控制的逻辑 |
| **发生了接住** | `try/except` | 外部输入、文件、网络 |
| **主动说不行** | `raise` | 参数校验，告诉调用者 |

**好的代码三层都会用到。**
