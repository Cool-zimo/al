# 标准库巡礼与 pip

> Python 自带了几百个模块。这一课挑最常用的介绍，顺便讲怎么装第三方库。

## 先说 pip

**pip 是 Python 的包管理器**，用来安装第三方库。

```bash
pip install requests          # 装一个库
pip install requests==2.31.0  # 装指定版本
pip uninstall requests        # 卸载
pip list                      # 看装了什么
pip show requests             # 看某个库的详情
```

> 💡 **国内用 pip 慢的话，可以换镜像源**：

```bash
pip install requests -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**装完就能 import**：

```python
import requests
```

## requirements.txt

**项目用了哪些库，写进这个文件**：

```
requests==2.31.0
pandas==2.2.0
```

**别人拿到项目后一键安装**：

```bash
pip install -r requirements.txt
```

**生成这个文件**：

```bash
pip freeze > requirements.txt
```

> 💡 **每个正经项目都该有 requirements.txt**——不然别人拿到你的代码跑不起来。

## 常用标准库（按用途）

### 1. 数学与数字

```python
import math

print(math.pi)               # 3.14159...
print(math.sqrt(16))         # 4.0
print(math.ceil(3.2))        # 4   向上取整
print(math.floor(3.8))       # 3   向下取整

import random
print(random.randint(1, 10))      # 1~10 随机整数
print(random.choice(['a','b']))   # 随机选一个
print(random.shuffle(lst))        # 打乱列表（就地）
```

### 2. 时间与日期

```python
import datetime

now = datetime.datetime.now()
print(now.strftime("%Y-%m-%d %H:%M"))     # 格式化成字符串

d = datetime.date(2026, 9, 27)
print(d + datetime.timedelta(days=7))     # 加 7 天

import time
time.sleep(1)          # 暂停 1 秒
```

**`strftime`** 格式化、`strptime` 解析：

```python
s = "2026-09-27"
d = datetime.datetime.strptime(s, "%Y-%m-%d")     # 字符串 → 日期
```

### 3. 文件与系统

```python
import os
import shutil

os.path.join('a', 'b')          # 拼接路径
os.makedirs('x/y', exist_ok=True)
os.listdir('.')                  # 列出目录
shutil.copy('a.txt', 'b.txt')    # 复制文件
```

### 4. 数据格式

```python
import json
import csv

json.dumps({'a': 1})             # 转字符串
json.loads('{"a": 1}')           # 解析
```

### 5. 字符串与正则

```python
import re

# 找出所有数字
print(re.findall(r'\d+', 'a1b22c333'))      # ['1', '22', '333']

# 判断是不是手机号
if re.match(r'1\d{10}', phone):
    print("是手机号")
```

> 💡 **正则是个大话题**，知道有 `re` 模块能解决"从文本里提取模式"这类问题就够了。

### 6. 系统参数与命令行

```python
import sys

print(sys.argv)          # 命令行参数列表
print(sys.version)       # Python 版本
sys.exit(0)              # 退出程序
```

### 7. 复制与数据结构

```python
import copy

a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)     # 深拷贝（嵌套的也复制）
```

```python
import collections
from collections import Counter

print(Counter(['a','b','a']))        # Counter({'a': 2, 'b': 1})
```

**`Counter` 数次数特别方便**：

```python
words = ['apple', 'banana', 'apple']
c = Counter(words)
print(c.most_common(1))        # [('apple', 2)]
```

### 8. 函数式工具

```python
import itertools

# 排列组合
print(list(itertools.combinations([1,2,3], 2)))     # [(1,2),(1,3),(2,3)]
```

### 9. 测试

```python
import unittest

class TestAdd(unittest.TestCase):
    def test_add(self):
        self.assertEqual(1 + 1, 2)
```

## 一个练习：用标准库做个小工具

统计一个文本文件里的词频：

```python
from collections import Counter
import re

with open('article.txt', 'r', encoding='utf-8') as f:
    text = f.read()

words = re.findall(r'\w+', text.lower())
top = Counter(words).most_common(10)

for word, count in top:
    print(f"{word}: {count}")
```

**三个标准库模块配合**（`re` + `collections` + 文件读写），十几行搞定词频统计。
