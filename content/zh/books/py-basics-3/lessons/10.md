# JSON 文件

> 想保存列表、字典这样的结构？JSON 是最通用的选择。

## 为什么需要 JSON

CSV 只能存"表格"——一层行和列。但如果你想存这个：

```python
user = {
    'name': '张三',
    'age': 18,
    'hobbies': ['编程', '读书'],
    'address': {'city': '北京', 'street': '朝阳'}
}
```

**有嵌套、有列表，CSV 就无能为力了。**

**JSON 能原样保存这种结构**，而且：
- 所有编程语言都认识它
- 网页 API 用的就是它
- 配置文件常用它

## JSON 长什么样

```json
{
  "name": "张三",
  "age": 18,
  "hobbies": ["编程", "读书"],
  "address": {"city": "北京", "street": "朝阳"}
}
```

**和 Python 的字典几乎一模一样**。区别：

| | Python | JSON |
|---|---|---|
| 布尔 | `True` / `False` | `true` / `false` |
| 空值 | `None` | `null` |
| 字符串 | 单引号双引号都行 | **只能双引号** |

## 四个函数就够了

```python
import json

# Python 对象 → JSON 字符串
json.dumps(obj)              # dump string

# JSON 字符串 → Python 对象
json.loads(text)             # load string

# Python 对象 → 写入文件
json.dump(obj, f)

# 从文件读 → Python 对象
json.load(f)
```

**记忆方法：带 `s` 的是处理"字符串"，不带 `s` 的是处理"文件"。**

## 存进文件

```python
import json

user = {'name': '张三', 'age': 18, 'hobbies': ['编程', '读书']}

with open('user.json', 'w', encoding='utf-8') as f:
    json.dump(user, f, ensure_ascii=False, indent=2)
```

**两个重要参数**：

| 参数 | 作用 |
|---|---|
| `ensure_ascii=False` | **让中文正常显示**，否则变成 `\u5f20\u4e09` |
| `indent=2` | 格式化缩进，方便人读 |

> ⚠️ **`ensure_ascii=False` 一定要加**，否则文件里全是 `\u5f20\u4e09` 这种转义，虽然能读回来，但人看不懂。

写出来的 `user.json`：

```json
{
  "name": "张三",
  "age": 18,
  "hobbies": [
    "编程",
    "读书"
  ]
}
```

## 从文件读

```python
import json

with open('user.json', 'r', encoding='utf-8') as f:
    user = json.load(f)

print(user['name'])          # 张三
print(user['hobbies'])       # ['编程', '读书']
```

**读回来就是一个普通的 Python 字典**，该怎么用怎么用。

## 类型对应关系

| Python | JSON |
|---|---|
| `dict` | object `{}` |
| `list` / `tuple` | array `[]` |
| `str` | string |
| `int` / `float` | number |
| `True` / `False` | `true` / `false` |
| `None` | `null` |

**注意：tuple 存进去会变成 list**。读回来不再是元组。

```python
json.dumps((1, 2))        # '[1, 2]'
json.loads('[1, 2]')      # [1, 2]  ← 是 list 不是 tuple
```

## 不是什么都能存

```python
# ❌ 报错：Object of type set is not JSON serializable
json.dumps({1, 2})

# ❌ 函数、类实例也存不了
json.dumps(lambda x: x)
```

**JSON 只支持上面那张表里的基本类型。**

存 set 要先转成 list：

```python
data = {'tags': list({'a', 'b'})}
json.dumps(data)
```

## 实战：一个能记住数据的程序

```python
import json
import os

FILE = 'tasks.json'


def load_tasks():
    """读任务列表；文件不存在或为空都返回空列表"""
    if not os.path.exists(FILE):
        return []
    with open(FILE, 'r', encoding='utf-8') as f:
        content = f.read().strip()
    if not content:                  # 空文件
        return []
    return json.loads(content)


def save_tasks(tasks):
    with open(FILE, 'w', encoding='utf-8') as f:
        json.dump(tasks, f, ensure_ascii=False, indent=2)


tasks = load_tasks()
tasks.append({'title': '学 JSON', 'done': False})
save_tasks(tasks)

print(f"共 {len(tasks)} 个任务：")
for t in tasks:
    mark = '✓' if t['done'] else ' '
    print(f"  [{mark}] {t['title']}")
```

**关掉程序再运行，任务会继续增加**——这就是"持久化"。

## 和 CSV 怎么选

| 场景 | 选 |
|---|---|
| 表格数据、要给 Excel 看 | **CSV** |
| 有嵌套结构、配置、要跨语言 | **JSON** |
| 要人来编辑 | JSON（可读性更好） |
| 数据量超大 | CSV（更紧凑） |

## 一个常见的错误

```python
# ❌ 覆盖了原文件，但写入中途失败 → 文件损坏
with open('data.json', 'w', encoding='utf-8') as f:
    json.dump(data, f)

# ✅ 更安全：先写临时文件，成功了再替换
import os
with open('data.json.tmp', 'w', encoding='utf-8') as f:
    json.dump(data, f)
os.replace('data.json.tmp', 'data.json')     # 原子操作
```

**重要数据用这个写法**——写入中途崩溃也不会损坏原文件。

q: json.dump 时为什么推荐加 ensure_ascii=False？

answer: 1
explain: 默认情况下 json 会把非 ASCII 字符转义成 \uXXXX。数据能正确读回来，但文件打开全是转义码，没法人工检查。加上 ensure_ascii=False 就直接存中文。
