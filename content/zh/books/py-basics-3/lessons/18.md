# 写自己的模块

> 导入别人的模块看完了，现在写自己的——顺带解决"导入时代码被执行"这个坑。

## 最小例子

建两个文件，放在**同一个文件夹**里：

```python
# mytools.py
def double(n):
    return n * 2

def greet(name):
    return f"你好，{name}"
```

```python
# main.py
import mytools

print(mytools.double(21))        # 42
print(mytools.greet("张三"))      # 你好，张三
```

**就这么简单**——同目录下 `import mytools` 就能用。

## 模块名就是文件名

```python
import mytools        # 找 mytools.py
```

**模块名 = 文件名（去掉 .py）**。

**命名规则**和变量一样：
- 小写字母、数字、下划线
- 不能用中划线（`my-tools.py` 不行）
- 不要和**标准库重名**！

```python
# ❌ 千万别这么干
# json.py     ← 会让你 import json 导入到自己的文件
# random.py   ← 同上
# string.py   ← 同上
```

> ⚠️ **这是新手最常踩的坑之一**：给自己的文件起名 `json.py`，然后 `import json` 导入的是自己的空文件，标准库反而用不了了。

## 一个必踩的坑：导入时代码会执行

```python
# mytools.py
def double(n):
    return n * 2

print("模块被导入了")        # ← 这行在导入时就会执行！
```

```python
# main.py
import mytools
print("主程序开始")
```

运行 `main.py`：

```
模块被导入了          ← 先执行
主程序开始
```

**`import` 会把模块文件从头到尾执行一遍**，包括里面的 `print`、循环、甚至 `input()`。

**这对"既想当模块用、又想单独运行"的文件是个问题。**

## 解决方案：`if __name__ == "__main__"`

```python
# mytools.py
def double(n):
    return n * 2


def main():
    print("测试：", double(21))


if __name__ == "__main__":
    main()          # 只有直接运行本文件时才执行
```

**`__name__` 是 Python 自动设置的变量**：
- **直接运行这个文件** → `__name__` 是 `"__main__"`
- **被 import** → `__name__` 是模块名（`"mytools"`）

**所以 `if __name__ == "__main__":` 的意思是"只有我被直接运行时才做下面的事"。**

> 💡 **这是 Python 里极其常见的写法**，看到它就知道：这个文件的"入口"在这里。

### 为什么叫"main"？

很多语言都有"主函数"的概念（C、Java 都有 `main()`）。Python 没有强制要求，但这个约定让代码更清楚：

```python
def main():
    """程序的入口"""
    ...

if __name__ == "__main__":
    main()
```

## 模块里可以放什么

```python
# config.py

# 常量
MAX_RETRY = 3
DEFAULT_NAME = "匿名用户"

# 函数
def get_default():
    return DEFAULT_NAME

# 类（第 21 课讲）
class User:
    pass

# 模块级变量
_cache = {}
```

**函数、类、变量、常量都能放**。

**约定**：常量用**全大写**：

```python
MAX_SIZE = 100
API_URL = "https://example.com"
```

## 私有约定：下划线开头

```python
# mytools.py
def public_func():
    return "可以被外部用"

def _internal():
    return "内部辅助，不希望被外部用"
```

**单下划线开头的名字表示"内部用"**，但 Python **不会真的阻止**你导入它：

```python
from mytools import _internal      # 能导入，但不该这么做
```

**这是约定，不是强制**——就像"请不要踩草坪"的牌子。

## 实际的项目结构

```
myapp/
├── main.py           ← 入口，负责启动
├── config.py         ← 配置
├── database.py       ← 数据操作
└── utils.py          ← 通用工具
```

**`main.py` 里**：

```python
import config
import database
from utils import format_date

def main():
    ...

if __name__ == "__main__":
    main()
```

## 模块找不到怎么办

```python
import mytools
# ModuleNotFoundError: No module named 'mytools'
```

**常见原因**：

1. **文件不在同一目录** —— Python 只在这些地方找：
   - 当前运行目录
   - 标准库目录
   - `PYTHONPATH` 指定的目录
   - 第三方库安装目录

2. **文件名拼错**（大小写也要注意）

3. **和标准库重名**（被标准库"挡住"了）

**最简单的验证**：

```python
import sys
print(sys.path)        # 看看 Python 会在哪些目录里找
```

## 小结

- **一个 `.py` 文件就是一个模块**，模块名 = 文件名
- **别用标准库已有的名字命名文件**
- **import 会执行整个模块文件**
- **`if __name__ == "__main__"`** 区分"被导入"和"直接运行"
- 常量全大写，内部函数用 `_` 开头
