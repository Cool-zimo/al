# open() 与三种模式

> 打开文件只有一步，但"以什么方式打开"决定你能做什么、会毁掉什么。

## open() 的基本形态

```python
f = open('note.txt', 'r', encoding='utf-8')
content = f.read()
f.close()          # ← 别忘了这一步
print(content)
```

**三个参数**：

| 参数 | 意思 |
|---|---|
| 第一个 | 文件路径 |
| 第二个 | 模式（怎么打开） |
| `encoding` | 文字编码（强烈建议总是写） |

**`open()` 返回一个"文件对象"**，你通过它读或写。用完必须 `close()`。

## 三种最常用的模式

| 模式 | 含义 | 文件不存在时 | 会清空原内容吗 |
|---|---|---|---|
| `'r'` | **读**（read） | **报错** FileNotFoundError | 不会 |
| `'w'` | **写**（write） | 新建 | **会！** 一打开就清空 |
| `'a'` | **追加**（append） | 新建 | 不会，写在末尾 |

> ⚠️ **`'w'` 是最危险的一个**。它一旦打开文件，立刻把原来的内容全部抹掉——**哪怕你最后什么都没写**。

```python
# ❌ 这一行执行完，note.txt 已经空了！
f = open('note.txt', 'w', encoding='utf-8')
# 如果你这时忘了 f.write(...)，数据就没了
```

**记住**：想保留原内容用 `'a'`，想重写才用 `'w'`。

## 感受三种模式的区别

```python
# 准备一个文件
with open('demo.txt', 'w', encoding='utf-8') as f:
    f.write("第一行\n")

# 'a' 追加：内容加在后面
with open('demo.txt', 'a', encoding='utf-8') as f:
    f.write("第二行\n")

# 'r' 读：看看现在有什么
with open('demo.txt', 'r', encoding='utf-8') as f:
    print(f.read())
```

```
第一行
第二行
```

**如果把 `'a'` 换成 `'w'`**，结果只剩"第二行"——第一行在打开的瞬间就没了。

## 读一个不存在的文件会报错

```python
f = open('不存在的文件.txt', 'r', encoding='utf-8')
# FileNotFoundError: [Errno 2] No such file or directory: '不存在的文件.txt'
```

**这是好事**——它明确告诉你"没有这个文件"，而不是默默给你空内容。

第 12 课会教你用 `try/except` 优雅地处理这种情况。

## 还有两个不常用但要知道的模式

| 模式 | 含义 |
|---|---|
| `'r+'` | 读写（文件必须存在） |
| `'x'` | 新建并写（文件**已存在则报错**，防止误覆盖） |

`'x'` 在"我不想覆盖已有文件"时很有用：

```python
# 如果 log.txt 已存在，这里会报错，避免误删
with open('log.txt', 'x', encoding='utf-8') as f:
    f.write("新的日志")
```

## 文本模式 vs 二进制模式

上面全是**文本模式**（默认），读写的是字符串。

加一个 `b` 就是**二进制模式**，读写的是字节：

```python
# 二进制读（图片、音频、视频必须用这个）
with open('photo.jpg', 'rb') as f:
    data = f.read()

# 二进制写
with open('copy.jpg', 'wb') as f:
    f.write(data)
```

> 💡 **复制图片/音频/视频，必须用 `'rb'` / `'wb'`**。用文本模式打开会损坏文件。

**二进制模式不要加 `encoding`**——字节没有编码这一说。

## 忘记 close() 的后果

```python
f = open('note.txt', 'w', encoding='utf-8')
f.write("重要数据")
# 忘了 f.close()
```

后果：
1. **数据可能还没真正写到硬盘**（Python 有缓冲，攒够一批才写）
2. 文件被占用，别的程序打不开
3. 程序运行久了会耗尽"文件句柄"

**所以一定要 `close()`**——或者用第 06 课讲的 `with` 语句，它会自动关。

## 小结

- **`'r'` 读**：文件不存在会报错
- **`'w'` 写**：**会清空原内容**，危险
- **`'a'` 追加**：加在末尾，安全
- 图片等二进制文件用 `'rb'` / `'wb'`
- **用完必须 `close()`**，否则数据可能丢失

## 随堂练习

用追加模式保留原内容。

```quiz
type: code
q: 先写"第一行"，再用追加模式写"第二行"，最后读出来打印总行数
starter: |
  with open('t.txt', 'w', encoding='utf-8') as f:
      f.write("第一行\n")
  
  # 用 'a' 追加"第二行\n"
  # 再读出来，用 .splitlines() 得到行列表
  
  print("TODO：把这行改成你要打印的结果")
tests:
- assert "2" in __out
hint: with open('t.txt','a',encoding='utf-8') as f: f.write("第二行\n")；然后读出来 print(len(f.read().splitlines()))。'a' 追加不会清空原内容，'w' 会。
explain: 'a' 是追加模式，内容加在文件末尾，原内容保留 —— 写日志就用它。如果用 'w'，"第一行"在打开瞬间就被抹掉了，最后只剩 1 行。
```
