# 路径：相对与绝对

> "找不到文件"是新手最常见的报错。九成是因为没搞懂路径。

## 两种路径

```python
# 相对路径：从"当前目录"出发
open('note.txt')

# 绝对路径：从盘符/根目录出发，写全
open('C:/Users/me/note.txt')        # Windows
open('/home/me/note.txt')           # macOS / Linux
```

**相对路径**就像说"在隔壁房间"，**绝对路径**就像说"XX 市 XX 区 XX 号楼 302"。

## 相对路径相对于谁？

**相对于"当前工作目录"**——也就是你运行程序时所在的目录。

```python
import os
print(os.getcwd())      # current working directory
```

**这是最容易出问题的地方**：

```
项目/
├── main.py
└── data.txt
```

在 `项目/` 目录下运行 `python main.py`，`open('data.txt')` 能找到。

但如果你在别的目录运行 `python 项目/main.py`，**当前目录变了**，`open('data.txt')` 就找不到文件了！

> ⚠️ **相对路径依赖"你在哪运行"，不依赖"代码文件在哪"。** 这是无数"明明文件就在旁边却找不到"的根源。

## 路径分隔符的坑

Windows 用反斜杠 `\`，Mac/Linux 用正斜杠 `/`。

```python
# ❌ 在 Python 字符串里 \n 是换行、\t 是制表符
open('C:\new\table.txt')      # 会被解释成奇怪的东西
```

**三种解法**：

```python
# ① 用正斜杠（推荐，Windows 也认）
open('C:/new/table.txt')

# ② 双反斜杠转义
open('C:\\new\\table.txt')

# ③ 原始字符串（前面加 r）
open(r'C:\new\table.txt')
```

> 💡 **永远用正斜杠 `/`** —— Python 在 Windows 上也能正确处理，还不用转义。

## 拼接路径：os.path.join

**别用字符串拼接**：

```python
# ❌ 容易多一个/少一个斜杠
path = folder + '/' + filename

# ✅ 交给 os.path.join
import os
path = os.path.join(folder, filename)
```

**`os.path.join` 会自动用当前系统正确的分隔符**：

```python
import os
print(os.path.join('data', 'log', 'app.txt'))
# Windows: data\log\app.txt
# Mac/Linux: data/log/app.txt
```

**跨平台必备。**

## pathlib：更现代的写法

Python 3.4+ 推荐用 `pathlib`，路径变成对象，用 `/` 拼接：

```python
from pathlib import Path

p = Path('data') / 'log' / 'app.txt'
print(p)

# 读写也能直接用
p.write_text("内容", encoding='utf-8')
print(p.read_text(encoding='utf-8'))
```

**对比一下**：

| 需求 | os.path | pathlib |
|---|---|---|
| 拼接 | `os.path.join('a','b')` | `Path('a') / 'b'` |
| 是否存在 | `os.path.exists(p)` | `p.exists()` |
| 读文本 | `open(p).read()` | `p.read_text()` |
| 写文本 | `open(p,'w').write(s)` | `p.write_text(s)` |

**两者都行，`pathlib` 更现代、更好读。** 本课两种都展示，你挑顺手的用。

## 常用的路径判断

```python
import os

p = 'data.txt'

print(os.path.exists(p))      # 存在吗（文件或文件夹都算）
print(os.path.isfile(p))      # 是文件吗
print(os.path.isdir(p))       # 是文件夹吗
print(os.path.getsize(p))     # 大小（字节）
```

**`exists` 和 `isfile` 的区别**：

- `exists('data')` → 只要有个叫 data 的东西（文件或文件夹）就是 True
- `isfile('data')` → 必须是**文件**才 True

**读文件前用 `isfile` 更严谨**——因为"存在但是个文件夹"也会导致打开失败。

## 获取文件信息

```python
import os

print(os.path.basename('data/log/app.txt'))    # 'app.txt'   文件名
print(os.path.dirname('data/log/app.txt'))     # 'data/log'  目录部分
print(os.path.splitext('app.txt'))             # ('app', '.txt')  拆后缀
```

**`splitext` 在"改扩展名""判断类型"时很有用**：

```python
name, ext = os.path.splitext('photo.jpg')
print(ext)        # '.jpg'

if ext.lower() in ('.jpg', '.png', '.gif'):
    print("这是图片")
```

## 实战：安全地读文件

```python
import os

def read_file(path):
    """安全地读文件，返回内容；读不到就返回 None"""
    if not os.path.isfile(path):
        print(f"找不到文件：{path}")
        return None
    with open(path, 'r', encoding='utf-8') as f:
        return f.read()


content = read_file('data.txt')
if content:
    print(content)
```

**这个模式很常见**：先判断，再打开，避免崩溃。

## 小结

| 概念 | 说明 |
|---|---|
| 相对路径 | 相对于**当前工作目录**（你运行程序的地方） |
| 绝对路径 | 从盘符/根目录写全 |
| 分隔符 | **统一用 `/`**，别用 `\` |
| 拼接 | `os.path.join()` 或 `pathlib` 的 `/` |
| 判断 | `exists` / `isfile` / `isdir` |
