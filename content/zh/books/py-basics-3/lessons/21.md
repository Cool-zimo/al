# 为什么需要类

> 函数能打包"操作"，但数据呢？类把**数据和操作打包在一起**。

## 先看一个越来越乱的例子

用字典表示学生：

```python
student = {
    'name': '张三',
    'age': 18,
    'scores': [80, 90, 85]
}
```

再加几个函数：

```python
def get_average(student):
    return sum(student['scores']) / len(student['scores'])

def add_score(student, score):
    student['scores'].append(score)

def is_adult(student):
    return student['age'] >= 18
```

**用起来**：

```python
s = {'name': '张三', 'age': 18, 'scores': []}
add_score(s, 90)
print(get_average(s))
```

## 这样有什么问题

**1. 数据和操作是分开的**

`s` 和 `add_score(s, ...)` 之间只有"约定"——你必须记得这个字典该有哪些键。

**2. 容易写错键名**

```python
student['score'] = 90        # ❌ 拼错了，应该是 'scores'
# 不报错，但数据悄悄错了
```

**3. 每个函数都要重复写 `student` 参数**

`add_score(student, ...)`、`get_average(student)`、`is_adult(student)`……

**4. 没有"类型"的概念**

```python
def add_score(student, score):
    ...
```

这个 `student` 到底是什么结构？只能靠猜或查文档。

## 类怎么解决

**把数据和操作打包成一个东西**：

```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age
        self.scores = []

    def add_score(self, score):
        self.scores.append(score)

    def average(self):
        return sum(self.scores) / len(self.scores)

    def is_adult(self):
        return self.age >= 18
```

**用起来**：

```python
s = Student('张三', 18)
s.add_score(90)
s.add_score(85)
print(s.average())        # 87.5
print(s.is_adult())       # True
```

**对比一下**：

| | 字典 + 函数 | 类 |
|---|---|---|
| 调用 | `add_score(s, 90)` | `s.add_score(90)` |
| 数据在哪 | 散在字典里 | **在对象里** |
| 拼错键名 | 静默出错 | **属性不存在会报错** |
| 结构约定 | 靠文档 | **写在类里** |

## 三个核心概念

| 概念 | 是什么 | 类比 |
|---|---|---|
| **类 class** | 一个"模板"/"图纸" | 房子的设计图 |
| **对象 object** | 按模板造出来的具体东西 | 按图纸盖的一栋房 |
| **实例 instance** | 对象的另一个说法 | 同上 |

```python
class Student:          # ← 类（图纸）
    ...

s1 = Student('张三', 18)    # ← 对象（按图纸造的）
s2 = Student('李四', 19)    # ← 另一个对象
```

**一个类可以造无数个对象**，每个对象有自己的数据，但共享同一套方法。

## 类里有什么

```python
class Student:
    # 属性（数据）
    name
    age
    scores

    # 方法（操作）
    add_score()
    average()
```

- **属性 attribute**：对象**存的数据**（变量）
- **方法 method**：对象**能做的事**（函数）

**在类里面，函数叫"方法"**——本质一样，只是叫法不同。

## 什么时候该用类

| 情况 | 建议 |
|---|---|
| 只有一两个数据 + 简单操作 | 用函数就够了 |
| **一组数据 + 一组相关操作** | **用类** |
| 需要多个"同结构"的东西 | **用类** |
| 想表达"这是一个 XX" | **用类** |

**判断标准**：如果你发现自己写的函数**都要传同一个数据结构**，那就该用类了。

```python
# 信号：每个函数都传 student
def a(student): ...
def b(student): ...
def c(student): ...

# → 改成类
student.a()
student.b()
student.c()
```

## 一个生活化的例子

**没有类**：

```python
# 汽车的数据
car = {'brand': 'Toyota', 'speed': 0, 'fuel': 100}

def accelerate(car):
    car['speed'] += 10
    car['fuel'] -= 5
```

**有类**：

```python
class Car:
    def __init__(self, brand):
        self.brand = brand
        self.speed = 0
        self.fuel = 100

    def accelerate(self):
        self.speed += 10
        self.fuel -= 5


my_car = Car('Toyota')
my_car.accelerate()
print(my_car.speed)      # 10
```

**"汽车能加速"比"对汽车执行加速操作"自然多了。**

## 小结

- **类 = 图纸，对象 = 按图纸造出来的东西**
- 类把**数据（属性）和操作（方法）打包在一起**
- 好处：结构清晰、拼错会报错、不用反复传同一个参数
- **信号**：一堆函数都传同一个数据结构 → 该用类了
