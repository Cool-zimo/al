# import 的四种写法

> 同一个模块有好几种导入方式，用对了代码能短一半。

## 准备一个模块

假设有个 `tools.py`：

```python
# tools.py
def add(a, b):
    return a + b

def greet(name):
    return f"你好，{name}"

VERSION = "1.0"
```

## 写法一：import 模块名

```python
import tools

print(tools.add(1, 2))          # 3
print(tools.greet("张三"))       # 你好，张三
print(tools.VERSION)            # 1.0
```

**特点**：用的时候要带 `tools.` 前缀。

**优点**：**来源一目了然**，不容易搞混。

> 💡 **这是最推荐的写法**。看代码时 `tools.add()` 一眼就知道来自哪个模块。

## 写法二：import 模块 as 别名

```python
import tools as t

print(t.add(1, 2))
```

**模块名太长时起个短名字**。

**最常见的例子**：

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
```

**这三个别名是行业惯例**——大家都这么写，看到 `np.` 就知道是 numpy。

> ⚠️ 别乱起别名。`import pandas as p` 会让别人（和三个月后的你）看不懂。

## 写法三：from 模块 import 名字

```python
from tools import add, greet

print(add(1, 2))          # 不用写 tools.
print(greet("张三"))
```

**只导入需要的几个，用的时候不用前缀**。

**什么时候用**：某个函数你会用几十次，每次写前缀太啰嗦。

```python
from math import sqrt, pi
print(sqrt(16))         # 比 math.sqrt(16) 短
print(pi)
```

## 写法四：from 模块 import *

```python
from tools import *        # 导入所有（不以下划线开头的）

print(add(1, 2))
print(greet("张三"))
```

> ⚠️ **强烈不推荐！**

**问题**：你不知道到底导入了什么，很容易覆盖掉已有的名字：

```python
from math import *
from numpy import *

print(sqrt(16))        # 这是 math 的还是 numpy 的？取决于导入顺序
```

**更糟的情况**：

```python
def add(a, b):          # 你自己定义的
    return a + b

from tools import *     # 把你的 add 覆盖了！
print(add(1, 2))        # 调用的其实是 tools.add
```

**原则：永远不要用 `import *`。**

## 四种写法对比

| 写法 | 调用方式 | 推荐度 |
|---|---|---|
| `import tools` | `tools.add()` | ⭐⭐⭐ **最推荐** |
| `import tools as t` | `t.add()` | ⭐⭐⭐ 名字长时用 |
| `from tools import add` | `add()` | ⭐⭐ 高频使用单个函数时 |
| `from tools import *` | `add()` | ❌ **别用** |

## 导入多个名字

```python
from math import sqrt, pi, floor, ceil
```

**逗号分隔**，一次导入好几个。

## 一个容易忽略的点

```python
from tools import VERSION

VERSION = "2.0"          # ← 这只改了你自己这里的变量
```

**`from ... import` 是"复制一个引用过来"**，不是建立连接。你在自己文件里改 `VERSION`，不会影响 `tools.py` 里的 `VERSION`。

对比：

```python
import tools
tools.VERSION = "2.0"    # ← 这个真的改了模块里的值
```

**所以想修改模块里的变量，要用 `import 模块名` 的形式。**

## 导入时的错误

```python
import nonexistent        # ModuleNotFoundError: No module named 'nonexistent'
from tools import nope    # ImportError: cannot import name 'nope'
```

**两种报错**：
- `ModuleNotFoundError` —— **模块不存在**（名字写错，或者没安装）
- `ImportError` —— 模块存在，但**里面没有你要导入的那个名字**

## 循环导入

```python
# a.py
import b

# b.py
import a        # ← 互相导入，会出问题
```

**避免这种设计**。如果确实需要，把公共部分抽到第三个模块。

## 小结

| 写法 | 用途 |
|---|---|
| `import m` | **默认推荐**，来源清晰 |
| `import m as x` | 名字太长；`np` `pd` 是行业惯例 |
| `from m import f` | 单个函数高频使用时 |
| `from m import *` | **不要用** |
