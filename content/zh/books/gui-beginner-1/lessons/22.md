# 打开与保存文件：`filedialog`

> 不能打开文件的"文本编辑器"根本不算编辑器。`tkinter.filedialog` 给你的就是你在每个桌面程序里都见过的"打开文件"和"另存为"窗口——用户浏览文件夹、挑一个文件，你的代码拿回一个路径字符串。

## 对话框返回什么

**`askopenfilename` 弹出标准的"打开"对话框，返回用户选中的完整路径；用户取消则返回空字符串。** 有这个字符串，用 Python 自带的文件工具读文件就够了。

```
import tkinter as tk
from tkinter import filedialog

root = tk.Tk()

def open_file():
    path = filedialog.askopenfilename()
    print(repr(path))      # 例如 '/home/zhangsan/笔记.txt'  或  ''

tk.Button(root, text="打开...").pack(command=open_file)

root.mainloop()
```

**点"打开"，浏览到某个文件，点确定，路径就落到你的变量里。** 取消或关掉对话框，你得到的是 `''`。这个空字符串就是"什么都没选"的信号，所以在尝试打开任何东西之前先判断它。

## 用户挑完之后自己读文件

**对话框只负责挑路径，打开和读取文件仍然要你自己做。**

```
import tkinter as tk
from tkinter import filedialog

root = tk.Tk()

text = tk.Text(root, width=50, height=15)
text.pack()

def open_file():
    path = filedialog.askopenfilename()
    if not path:
        return
    with open(path, encoding="utf-8") as f:
        content = f.read()
    text.delete("1.0", tk.END)
    text.insert("1.0", content)

tk.Button(root, text="打开...").pack(command=open_file)

root.mainloop()
```

**`Text.delete("1.0", tk.END)` 先把旧内容清掉**，这样新内容不会叠在旧内容上面。`insert("1.0", ...)` 再把新文本插到最开头。这个"先清空、再插入"的两步套路，是刷新 Text 控件的标准做法。

## 翻车现场一：忘记处理取消

```
def open_file():
    path = filedialog.askopenfilename()
    with open(path) as f:        # WRONG: 用户取消时会崩
        ...
```

**用户取消时 `path` 是 `''`，把它传给 `open()` 会抛出 `FileNotFoundError`。** 用户只觉得自己关了个对话框，却看到报错，一头雾水。用 `if not path: return` 守住。

## 用 `filetypes` 过滤文件类型

**`filetypes` 决定对话框下拉框里显示哪些文件。** 它是一个由 `(标签, 通配)` 元组组成的列表，通配可以是一个字符串，也可以是一组扩展名。

```
path = filedialog.askopenfilename(
    filetypes=[
        ("文本文件", "*.txt"),
        ("Python 文件", "*.py"),
        ("所有文件", "*.*"),
    ]
)
```

**列表里的第一个元组就是下拉框默认选中的那一项。** `"*.txt"` 只匹配以 `.txt` 结尾的文件；`"*.*"` 匹配所有文件。你也可以把多个扩展名归在同一个标签下：

```
("图片", "*.png *.jpg *.gif")
```

**保存那一侧，`asksaveasfilename` 用法一样，但它会警告覆盖。** 如果用户挑了一个已经存在的文件，对话框会在返回路径之前自己问一句"是否替换"，你不必手写这个判断。

## 翻车现场二：扩展名漏写点

```
filetypes=[("文本文件", "txt")]    # WRONG: 只会匹配一个名叫 txt 的文件
```

**不带开头的 `*.`，你就不是在写通配模式，而是在要一个全名就是 `txt` 的文件。** 对话框会显得空空如也。永远写成 `"*.txt"`、`"*.py"` 这样。

## 用 `initialdir` 设定起始文件夹

**`initialdir` 让用户从合理的文件夹出发，而不是听操作系统的心情。**

```
import os

path = filedialog.askopenfilename(
    initialdir=os.path.expanduser("~"),
    filetypes=[("文本文件", "*.txt"), ("所有文件", "*.*")],
)
```

**`os.path.expanduser("~")` 在各操作系统上都会解析成当前用户的家目录。** 这比从程序安装目录或某个随机的最近位置启动友好得多。你也可以记住用户上次访问的文件夹，下次再传回去。

## 保存流程

**保存需要两样东西：对话框挑目的地，以及你自己的代码真正把字节写下去。**

```
def save_file():
    path = filedialog.asksaveasfilename(
        defaultextension=".txt",
        filetypes=[("文本文件", "*.txt"), ("所有文件", "*.*")],
    )
    if not path:
        return
    content = text.get("1.0", tk.END)
    with open(path, "w", encoding="utf-8") as f:
        f.write(content)
```

**`defaultextension=".txt"` 会在用户没写扩展名时悄悄补上 `.txt`。** 没有它的话，用户输入 `报告` 得到的就是一个真的叫 `报告`、没有任何类型后缀的文件。这是一个小细节，却能省掉之后的很多困惑。

## 翻车现场三：编码不对，读文件炸了

```
with open(path) as f:          # WRONG: Windows 上很多文件会 UnicodeDecodeError
    content = f.read()
```

**Windows 的默认编码往往不是 UTF-8**，于是 Mac 或 Linux 上写的文件一读就炸。钉死 `encoding="utf-8"`（如果你想对真正未知的数据更保守，再加 `errors="replace"`）。写文件时也一样。

## 综合示例：迷你记事本

**下面这套打开/保存骨架，就是后面几课会继续扩充的版本。**

```
import tkinter as tk
from tkinter import filedialog

root = tk.Tk()
root.title("迷你记事本")

text = tk.Text(root, wrap="word")
text.pack(fill="both", expand=True)

def open_file():
    path = filedialog.askopenfilename(filetypes=[("文本文件", "*.txt"), ("所有文件", "*.*")])
    if not path:
        return
    with open(path, encoding="utf-8") as f:
        text.delete("1.0", tk.END)
        text.insert("1.0", f.read())

def save_file():
    path = filedialog.asksaveasfilename(defaultextension=".txt",
                                        filetypes=[("文本文件", "*.txt"), ("所有文件", "*.*")])
    if not path:
        return
    with open(path, "w", encoding="utf-8") as f:
        f.write(text.get("1.0", tk.END))

tk.Button(root, text="打开").pack(side="left", command=open_file)
tk.Button(root, text="保存").pack(side="left", command=save_file)

root.mainloop()
```

**注意顺序：对话框返回一个字符串，你决定拿它干什么，再去更新控件。** 对话框从来不会直接碰你的 Text 控件——这个分工贯穿整本书。

## 小结

- `askopenfilename` 返回路径字符串，用户取消则返回 `''`
- 打开前一定判断 `if not path: return`
- `filetypes` 是 `(标签, "*.扩展名")` 元组的列表，第一个是默认项
- `asksaveasfilename` 会警告覆盖，还支持 `defaultextension`
- `initialdir` 设定对话框从哪开始；`os.path.expanduser("~")` 是个稳妥的选择
- 读写两侧都钉死 `encoding="utf-8"`
