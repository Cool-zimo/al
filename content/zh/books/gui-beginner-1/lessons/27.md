# 界面搭建：Frame 分区 + grid 布局

> 上一课我们画好了界面草图，列出了函数清单。这一课动手把界面搭出来。核心技巧是：用 Frame 把界面分成几个区域，每个区域内部用 grid 精确对齐。这是 tkinter 里最实用的布局组合。

## 为什么用 Frame 分区

**直接把控件全 pack 到 root 上，界面会越来越难管理。**

回忆一下第 5 课：我们做了一个简单的打招呼程序，所有控件都 pack 到 root 上。那只有 4 个控件，问题不大。但我们的文本统计工具至少有：1 个输入标签 + 1 个 Text + 3 个按钮 + 1 个结果标签 + 1 个结果 Text = 7 个控件。如果以后再加菜单栏、状态栏、设置面板，控件数量会轻松突破 20 个。

**20 个控件全 pack 到 root 上，你根本记不住谁在上谁在下。**

**Frame 的作用就是"分组装盒"**：把相关的控件装进一个 Frame，然后只管理 Frame 和 Frame 之间的关系。这样界面就变成了一个树形结构，层次清晰。

```
root
├── input_frame        (输入区)
│   ├── Label "请输入文本"
│   └── Text (输入框)
├── button_frame       (按钮区)
│   ├── Button "开始统计"
│   ├── Button "清空"
│   └── Button "保存结果"
└── result_frame       (结果区)
    ├── Label "统计结果"
    └── Text (结果显示)
```

**这个树形结构就是我们的布局蓝图。** 接下来照着它写代码。

## 用 grid 布局对齐控件

**grid 是"表格布局"，适合需要对齐的场景。** pack 只能上下左右堆叠，grid 可以把控件放到指定的行和列，精确控制位置。

**先看最基本的 grid 用法：**

```
widget.grid(row=0, column=0)   # 放在第 0 行第 0 列
widget.grid(row=0, column=1)   # 放在第 0 行第 1 列
widget.grid(row=1, column=0)   # 放在第 1 行第 0 列
```

**grid 的三个核心参数：**

| 参数 | 作用 |
|---|---|
| `row` | 行号，从 0 开始 |
| `column` | 列号，从 0 开始 |
| `columnspan` | 跨几列（合并单元格） |
| `padx`, `pady` | 外边距 |
| `sticky` | 对齐方式：`"w"` 左对齐、`"e"` 右对齐、`"n"` 上、`"s"` 下，可组合如 `"ew"` 左右拉伸 |

**`sticky="ew"` 是个高频用法**：让控件在水平方向上填满整个单元格。我们的 Text 输入框希望左右铺满，就用它。

## 完整界面搭建代码

**下面是照着蓝图写的完整界面代码：**

```
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.title("文本统计工具")
root.geometry("600x500")

# ========== 输入区 ==========
input_frame = ttk.LabelFrame(root, text="输入区")
input_frame.grid(row=0, column=0, padx=10, pady=5, sticky="ew")

input_label = ttk.Label(input_frame, text="请粘贴或输入文本：")
input_label.grid(row=0, column=0, sticky="w")

text_input = tk.Text(input_frame, height=10, wrap="word")
text_input.grid(row=1, column=0, sticky="ew", padx=5, pady=5)

# ========== 按钮区 ==========
button_frame = ttk.LabelFrame(root, text="操作区")
button_frame.grid(row=1, column=0, padx=10, pady=5, sticky="ew")

btn_count = ttk.Button(button_frame, text="开始统计")
btn_count.grid(row=0, column=0, padx=5, pady=5)

btn_clear = ttk.Button(button_frame, text="清空")
btn_clear.grid(row=0, column=1, padx=5, pady=5)

btn_save = ttk.Button(button_frame, text="保存结果")
btn_save.grid(row=0, column=2, padx=5, pady=5)

# ========== 结果区 ==========
result_frame = ttk.LabelFrame(root, text="统计结果")
result_frame.grid(row=2, column=0, padx=10, pady=5, sticky="ew")

result_label = ttk.Label(result_frame, text="点击"开始统计"查看结果")
result_label.grid(row=0, column=0, sticky="w")

text_result = tk.Text(result_frame, height=8, wrap="word", state="disabled")
text_result.grid(row=1, column=0, sticky="ew", padx=5, pady=5)

# 让第 0 列可拉伸，窗口变大时输入框和结果框自动变宽
root.columnconfigure(0, weight=1)
input_frame.columnconfigure(0, weight=1)
result_frame.columnconfigure(0, weight=1)

root.mainloop()
```

**逐段拆解：**

1. **`ttk.LabelFrame`** 是带标题的边框容器，比裸 Frame 更美观，用来给每个区域一个明确的视觉边界。
2. **`wrap="word"`** 让 Text 按单词边界换行，不会出现一个词被切成两半的情况。
3. **`state="disabled"`** 让结果区只读，用户不能乱改。
4. **`columnconfigure(0, weight=1)`** 是关键：它告诉 grid"第 0 列可以随窗口拉伸"。如果不加这行，窗口放大时控件不会跟着变宽，右边会空出一大块。
5. **`sticky="ew"`** 配合 `weight=1`，实现"窗口变宽、输入框也变宽"的效果。

## `columnconfigure` 和 `rowconfigure` 详解

**这两个函数是"响应式布局"的核心。** 不理解它们，窗口一拉伸就丑。

```
root.columnconfigure(0, weight=1)
```

**`weight` 的含义是"分配比例"。** 如果有两个列，列 0 的 weight=1，列 1 的 weight=2，那么窗口多出来的空间会按 1:2 分配给这两列。

**常见的配置模式：**

| 场景 | 配置 |
|---|---|
| 单列铺满 | `columnconfigure(0, weight=1)` |
| 左右固定、中间铺满 | `columnconfigure(1, weight=1)`，列 0 和列 2 不设 weight |
| 行铺满 | `rowconfigure(1, weight=1)` |

**我们的界面是单列布局，所以只给列 0 设 weight=1 就够了。** 但如果你想让"结果区"在窗口变高时也自动变高，还需要：

```
root.rowconfigure(2, weight=1)        # 结果区所在行可拉伸
result_frame.rowconfigure(1, weight=1) # 结果 Text 所在行可拉伸
text_result.grid(row=1, column=0, sticky="nsew")  # 四向拉伸
```

**`sticky="nsew"` = 上下左右都贴边 = 填满整个单元格。**

## 翻车现场一：pack 和 grid 混用

**这是 tkinter 最常见的错误之一，没有"之一"。**

```
import tkinter as tk

root = tk.Tk()

label = tk.Label(root, text="Hello")
label.pack()           # ← 用 pack

button = tk.Button(root, text="Click")
button.grid(row=0, column=0)  # ← 用 grid

root.mainloop()
```

**报错：**

```
_tkinter.TclError: cannot use geometry manager grid inside . which already has slaves managed by pack
```

**原因**：同一个父容器（这里是 root）里，不能有的子控件用 pack，有的用 grid。tkinter 的几何管理器是互斥的。

**修复**：统一用一种。如果界面需要 grid 的精确对齐，就把 label 也改成 grid：

```
label.grid(row=0, column=0)
button.grid(row=1, column=0)
```

**记忆法**：一个容器只用一种布局管理器。Frame A 用 pack，Frame B 用 grid，这完全 OK——因为它们是不同的容器。但只要混在同一个容器里就炸。

## 翻车现场二：忘了 columnconfigure，窗口拉伸后控件不动

**症状**：运行程序，窗口正常。但把窗口拉大后，输入框和结果框还是原来那么宽，右边空了一大块。

**原因**：没有设置 `columnconfigure(0, weight=1)`，grid 不知道哪一列该拉伸。

**修复**：

```
root.columnconfigure(0, weight=1)
input_frame.columnconfigure(0, weight=1)
result_frame.columnconfigure(0, weight=1)
```

**口诀**：凡是用 grid 且希望随窗口拉伸的控件，它的父容器一定要配 `columnconfigure` 或 `rowconfigure`。

## 翻车现场三：Text 控件高度设太大，把按钮挤到看不见

**症状**：运行后只看到输入框，按钮和结果区被挤出窗口可视区域。

**原因**：`Text(root, height=20)` 把输入框设了 20 行高，加上结果区又设了 15 行，总高度远超窗口默认尺寸。

**修复**：

1. 减小 height：`Text(root, height=8)`
2. 给窗口设合理初始尺寸：`root.geometry("600x500")`
3. 用 `rowconfigure` 让区域可拉伸，而不是写死高度

**经验值**：Text 控件的 height 设为 8~12 行，在 500~600px 高的窗口里比较舒适。

## 翻车现场四：LabelFrame 的 text 参数忘了写

**症状**：区域边框画出来了，但上面没有标题文字，看起来像裸 Frame。

**原因**：`LabelFrame` 的 `text` 参数是可选的，不写也不会报错，只是少了标题。

**修复**：

```
ttk.LabelFrame(root, text="输入区")   # ✓ 有标题
ttk.LabelFrame(root)                   # ✗ 没标题，和 Frame 一样
```

**LabelFrame 的标题是用户体验的一部分**——用户一看就知道这个区域是干什么的。

## 为什么用 ttk 而不是 tk

**代码里混用了 `ttk.LabelFrame` 和 `tk.Text`。为什么不全用 ttk？**

**ttk（Themed Tk）是 tkinter 的主题组件库**，外观更现代、更统一。但 ttk 不是所有控件都有：

| 控件 | ttk 有吗？ | 说明 |
|---|---|---|
| Label | ✓ | |
| Button | ✓ | |
| Entry | ✓ | |
| Frame | ✓ | |
| LabelFrame | ✓ | |
| Text | ✗ | 只有 tk.Text |
| Listbox | ✗ | 只有 tk.Listbox |
| Canvas | ✗ | 只有 tk.Canvas |
| Menu | ✗ | 只有 tk.Menu |

**原则：能用 ttk 的就用 ttk（外观好），ttk 没有的就用 tk（功能全）。**

**`from tkinter import ttk` 是标准导入写法。** 注意 ttk 控件创建时第一个参数是父容器，和 tk 一样：

```
ttk.Button(parent, text="确定")   # ✓
tk.Button(parent, text="确定")    # ✓
```

## 小结

- **Frame 分区**把界面变成树形结构，20 个控件也不乱
- **grid** 适合需要精确对齐的布局，核心参数是 row/column/sticky
- **`columnconfigure(weight=1)`** 让列随窗口拉伸，是响应式布局的关键
- **`sticky="ew"`** 让控件水平铺满单元格；`"nsew"` 四向铺满
- **pack 和 grid 不能混用**在同一个容器里，否则报 `_tkinter.TclError`
- **ttk 优先**，但 Text、Listbox、Canvas、Menu 只有 tk 版本
- **LabelFrame 的 text** 是用户体验的一部分，别忘了写
