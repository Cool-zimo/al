# grid 的权重：为什么窗口放大控件不动

> 这是 tkinter 里最容易让人抓狂的问题：你把窗口拉大，控件却死死缩在原地。这一节讲清 `rowconfigure` / `columnconfigure` 和 `weight` 权重，学会后界面就能随窗口缩放。

## 现象：窗口放大，控件不动

**先复现这个经典问题：**

```
import tkinter as tk

root = tk.Tk()
root.geometry("400x300")

tk.Label(root, text="姓名：").grid(row=0, column=0)
tk.Entry(root).grid(row=0, column=1)
tk.Label(root, text="年龄：").grid(row=1, column=0)
tk.Entry(root).grid(row=1, column=1)

tk.Button(root, text="提交").grid(row=2, column=0, columnspan=2)

root.mainloop()
```

**运行后把窗口从 400x300 拉大到 800x600——你会发现控件们仍然挤在左上角，右边的空白越来越大。**

**这就是"控件不动"的问题。**

## 原因：每列每行的权重默认是 0

**grid 把空间分配看成一个"分蛋糕"问题。** 窗口变大了，多出来的蛋糕分给谁？默认谁都不给（权重都是 0），所以控件保持原样，多余空间被扔在右边和底边。

**解决：用 `columnconfigure` 和 `rowconfigure` 告诉 grid "这一列/行有权重，分蛋糕时给我一份"。**

```
import tkinter as tk

root = tk.Tk()
root.geometry("400x300")

root.columnconfigure(1, weight=1)   # 第 1 列有权重
root.rowconfigure(2, weight=1)      # 第 2 行有权重

tk.Label(root, text="姓名：").grid(row=0, column=0)
tk.Entry(root).grid(row=0, column=1, sticky="ew")
tk.Label(root, text="年龄：").grid(row=1, column=0)
tk.Entry(root).grid(row=1, column=1, sticky="ew")
tk.Button(root, text="提交").grid(row=2, column=0, columnspan=2, sticky="ew")

root.mainloop()
```

**现在拉大窗口：第 1 列（输入框所在列）会跟着变宽，第 2 行（按钮所在行）会跟着变高。**

## weight 是什么

**`weight`（权重）决定"额外空间怎么分"。** 它的值是个整数：

| 情况 | 分配结果 |
|---|---|
| 所有行列 weight=0 | 没人要空间，多余空间全扔右边/底边 |
| 只有一列 weight=1 | 那一列拿走全部多余空间 |
| 两列 weight=1 和 weight=2 | 第二列拿两倍于第一列的空间 |
| 两列 weight=1 和 weight=1 | 两列平分空间 |

**权重是比例，不是像素。** `weight=1` 和 `weight=100` 在一个只有两个竞争者的场景里效果一样（都表示"我也要分一份"）。

**多列按比例分空间：**

```
root.columnconfigure(0, weight=1)
root.columnconfigure(1, weight=2)
root.columnconfigure(2, weight=1)
# 窗口变宽时，三列按 1:2:1 分空间
```

## rowconfigure 同理

**行也有权重：**

```
root.rowconfigure(0, weight=1)   # 第 0 行随窗口变高
root.rowconfigure(1, weight=2)   # 第 1 行变高速度是第 0 行的两倍
```

**常见套路**：让"主体内容区"所在的行 weight=1，让它随窗口拉伸；按钮所在的行保持自然高度（weight=0）。

```
tk.Label(root, text="编辑区", bg="lightblue").grid(row=0, column=0, sticky="nsew")
tk.Button(root, text="按钮").grid(row=1, column=0)

root.rowconfigure(0, weight=1)   # 编辑区行撑满
root.rowconfigure(1, weight=0)   # 按钮行不动
root.columnconfigure(0, weight=1)
```

## sticky 必须配 weight 才有意义

**很多人只写 `sticky="ew"` 却忘了 `columnconfigure(weight=1)`，发现控件还是不撑满。**

**这两个必须同时做：**

```
root.columnconfigure(1, weight=1)           # 告诉 grid：这一列有权重
tk.Entry(root).grid(row=0, column=1, sticky="ew")  # 告诉控件：在这个格子里横向撑满
```

**缺了前者**：格子本身不会变大，控件想撑也撑不起来。
**缺了后者**：格子变大了，但控件保持自然尺寸缩在格子中间。

**记忆口诀：weight 让格子变大，sticky 让控件填满格子。两者缺一不可。**

## uniform：让多列/多行等宽等高

**`uniform` 能让多行或多列严格等宽/等高：**

```
root.columnconfigure(0, weight=1, uniform="group1")
root.columnconfigure(1, weight=1, uniform="group1")
root.columnconfigure(2, weight=1, uniform="group1")
```

**三列等宽，不管内容多少。** 同一个 `uniform` 字符串（名字任意）的列会被强制分成等宽。

**适合场景**：计算器按钮、等分面板。

## minsize：给行列设最小尺寸

**`minsize` 保证某行/列至少多大：**

```
root.columnconfigure(1, weight=1, minsize=100)  # 这一列至少 100 像素
root.rowconfigure(0, minsize=50)                 # 这一行至少 50 像素
```

**即使窗口被缩得很小，这一列也不会小于 100 像素。**

## 一次配置多个：循环写法

**列多了一个个写太累，用循环：**

```
for c in range(4):
    root.columnconfigure(c, weight=1)

for r in range(3):
    root.rowconfigure(r, weight=1)
```

**配合计算器键盘很好用：**

```
import tkinter as tk

root = tk.Tk()
buttons = [str(i) for i in range(1, 10)] + ["0"]

for c in range(3):
    root.columnconfigure(c, weight=1, uniform="col")

for r in range(4):
    root.rowconfigure(r, weight=1, uniform="row")

r = c = 0
for b in buttons:
    tk.Button(root, text=b).grid(row=r, column=c, sticky="nsew", padx=2, pady=2)
    c += 1
    if c > 2:
        c = 0
        r += 1

root.mainloop()
```

**`sticky="nsew"` + 行列都设 weight + uniform 等宽等高 = 一个随窗口缩放、按钮永远正方形的计算器。**

## 翻车现场一：weight 设了但 sticky 没设

```
root.columnconfigure(1, weight=1)
tk.Entry(root).grid(row=0, column=1)   # 忘记 sticky
```

**拉大窗口，格子变宽了，但输入框缩在中间没动。** 补上 `sticky="ew"` 即可。

## 翻车现场二：sticky 设了但 weight 没设

```
tk.Entry(root).grid(row=0, column=1, sticky="ew")
# 忘记 columnconfigure(1, weight=1)
```

**格子不变大，sticky 无空间可撑，等于没写。**

## 翻车现场三：weight 设在错的行列上

```
root.columnconfigure(0, weight=1)   # 标签列有权重
tk.Label(root, text="姓名：").grid(row=0, column=0)
tk.Entry(root).grid(row=0, column=1)  # 输入框列没权重
```

**拉大窗口，变宽的是标签列（"姓名："被拉宽），输入框不动——这通常是反的，你希望输入框变宽。**

**修法**：把 weight 设到输入框所在的第 1 列。

## 翻车现场四：用了 grid 却期待 pack 的自动拉伸

**pack 的 `fill="both", expand=True` 自动撑满；grid 必须显式配置 weight。** 从 pack 转到 grid 时最容易忘。

## 一个对照表

| 想要的效果 | 必须写的代码 |
|---|---|
| 某列随窗口变宽 | `columnconfigure(c, weight=1)` + 该列控件 `sticky="ew"` |
| 某行随窗口变高 | `rowconfigure(r, weight=1)` + 该行控件 `sticky="ns"` |
| 控件占满整个格子 | `sticky="nsew"` |
| 多列等宽 | `columnconfigure` 用同一个 `uniform` 值 |
| 行列最小尺寸 | `minsize=N` |

## 小结

- 窗口放大控件不动，是因为**行列权重默认是 0**
- `columnconfigure(c, weight=1)` 让第 c 列有权重，能分空间
- weight 是比例：1:2 表示分空间 1:2；weight=0 表示不要空间
- **weight 让格子变大 + sticky 让控件填满格子，缺一不可**
- `uniform` 让多列/多行等宽等高；`minsize` 设最小尺寸
- 列多了用循环 `for c in range(N): columnconfigure(c, weight=1)`
