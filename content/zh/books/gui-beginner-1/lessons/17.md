# lambda 与参数传递

> command 只能接"无参函数"，可回调偏偏常常需要参数。这一节专门讲 lambda 这个工具，以及 functools.partial 这个备选方案。学完就能给任何回调传参。

## 为什么需要 lambda

**问题场景：三个按钮，点击分别打印不同的名字。**

```
def greet(name):
    print(f"你好，{name}！")

tk.Button(root, text="张三", command=greet).pack()   # 缺参数，错
```

**`command=greet` 没给参数，greet 需要 name，点击会报 `missing 1 required positional argument`。**

**`command=greet("张三")` 又错**（立即执行）。

**怎么办？需要一个"包装"：创建一个无参函数，它内部调用 `greet("张三")`。**

## lambda 写法

**`lambda` 就是用来现场造一个"小函数"的：**

```
tk.Button(root, text="张三", command=lambda: greet("张三")).pack()
tk.Button(root, text="李四", command=lambda: greet("李四")).pack()
```

**`lambda: greet("张三")` 读作"一个没有参数的函数，体是 `greet('张三')`"。**

**点击按钮时，按钮调用这个 lambda，lambda 再去调用 `greet("张三")`。**

## lambda 的基本语法

**回顾一下 lambda：**

```python
# 普通函数
def add(a, b):
    return a + b

# 等价的 lambda
add = lambda a, b: a + b

print(add(2, 3))   # 5
```

**`lambda 参数: 表达式`。** 冒号后面只能是一个表达式（有返回值），不能写多行语句。

## 在 tkinter 里传多个参数

```
def set_text(text, color):
    label.configure(text=text, fg=color)

tk.Button(root, text="红字", command=lambda: set_text("警告", "red")).pack()
tk.Button(root, text="黑字", command=lambda: set_text("正常", "black")).pack()
```

**lambda 内部可以传任意多个参数给真正干活的函数。**

## 用 lambda 传"控件自己"

**循环创建按钮时，让每个按钮知道自己对应哪个数据：**

```
fruits = ["苹果", "香蕉", "橙子"]

for f in fruits:
    tk.Button(root, text=f, command=lambda name=f: print(f"选了 {name}")).pack()
```

**`lambda name=f: ...` 中的 `name=f` 是默认参数**，把循环变量 `f` 的当前值"冻结"进 lambda。这招很关键，下面翻车现场会细讲。

## functools.partial：lambda 的替代

**`functools.partial` 也能把参数"固定"进一个函数：**

```
from functools import partial

def greet(name):
    print(f"你好，{name}！")

tk.Button(root, text="张三", command=partial(greet, "张三")).pack()
tk.Button(root, text="李四", command=partial(greet, "李四")).pack()
```

**`partial(greet, "张三")` 返回一个新函数，调用它就等于 `greet("张三")`。**

**lambda 和 partial 效果一样，选哪个都行。** lambda 更轻量、能写多行逻辑时用，partial 语义更清晰。

## 翻车现场一：lambda 循环里的经典坑

**这是 tkinter 里最著名的坑之一：**

```
buttons = []
for i in range(3):
    btn = tk.Button(root, text=f"按钮{i}", command=lambda: print(f"我是按钮{i}"))
    btn.pack()
```

**点击任何一个按钮，打印的都是"我是按钮2"。**

**原因**：三个 lambda 共享同一个变量 `i`。循环结束时 `i` 已经是 2，之后点击时它们读到的都是 2。

**修复：用默认参数把当前值冻结进去：**

```
for i in range(3):
    btn = tk.Button(root, text=f"按钮{i}", command=lambda idx=i: print(f"我是按钮{idx}"))
    btn.pack()
```

**`lambda idx=i:` 把 `i` 的当前值作为默认参数 `idx` 固定下来。** 这样每个 lambda 各自保存了自己的 `idx`。

**或者用 partial：**

```
from functools import partial
for i in range(3):
    btn = tk.Button(root, text=f"按钮{i}", command=partial(print, f"我是按钮{i}"))
    btn.pack()
```

## 翻车现场二：lambda 里用 Listbox 的 curselection 时机

```
lb = tk.Listbox(root)
lb.pack()
lb.insert("end", "A", "B", "C")

# 错误：立即求值
tk.Button(root, text="显示", command=lambda: print(lb.curselection()[0])).pack()
```

**问题不是 lambda，而是 `curselection()[0]` 在点击时才会执行——如果用户没选中，会 IndexError。** 要在回调里判断。

## 翻车现场三：lambda 体里写多条语句

```
# 错误：lambda 体只能是一个表达式
btn = tk.Button(root, text="点",
                command=lambda: print("1"); print("2")).pack()
```

**修复：抽出成普通函数。**

```
def on_click():
    print("1")
    print("2")

btn = tk.Button(root, text="点", command=on_click).pack()
```

**经验法则：逻辑超过两行就别硬塞 lambda，写成普通函数。**

## lambda 传"事件对象"

**用 `bind` 绑定的回调会接收事件对象 `event`，lambda 要能接住它：**

```
def on_click(event):
    print("点击坐标：", event.x, event.y)

btn = tk.Button(root, text="点我")
btn.bind("<Button-1>", on_click)
```

**这里 `on_click` 定义了 `event` 参数，bind 调用时会自动传入。** 第 18 课细讲。

## lambda 的默认参数技巧总结

**冻结循环变量的标准写法：**

```
# 通用模板
lambda 形参=循环变量: 表达式

# 例子
lambda i=i: do_something(i)
lambda name=f: greet(name)
lambda idx=index: select(idx)
```

**把循环变量的值"钉"进 lambda 的默认参数，每个 lambda 各有一份拷贝。**

## 实战：动态生成菜单按钮

```
import tkinter as tk

root = tk.Tk()
root.title("动态菜单")

def action(name):
    label.configure(text=f"执行了：{name}")

label = tk.Label(root, text="请选择功能")
label.pack(pady=10)

items = ["新建", "打开", "保存", "另存为", "退出"]
for item in items:
    tk.Button(root, text=item, command=lambda name=item: action(name)).pack(fill="x", padx=20)

root.mainloop()
```

**五个按钮共用一个回调，靠 lambda 冻结各自的 `name`。**

## 小结

- command 只能接无参函数，要传参必须用 lambda 或 partial 包一层
- `lambda: func(参数)` 创建一个"延迟执行"的小函数
- **循环创建控件时，用 `lambda 形参=循环变量:` 冻结当前值**，否则全部共享最后一个值
- `functools.partial(func, 参数)` 是 lambda 的替代，语义更清晰
- lambda 体只能是一个表达式，逻辑多就写成普通函数
- 事件回调会收到 `event` 对象，要定义对应参数
