# tkinter 在哪、怎么 import

> 上一节你见过了 `import tkinter as tk`。这一节把 import 这件事讲透——为什么有 `tkinter` 和 `tkinter.ttk` 两套东西、`Tk()` 到底返回了什么、`mainloop()` 为什么非写不可。

## 验证 tkinter 是否可用

**tkinter 是标准库，自带的不代表一定装好了。** Linux 上尤其容易出现"Python 装了但 tkinter 没装"的情况。

```python
# 这几行可以在网页里跑，不用窗口
import tkinter
print(tkinter.__name__)      # 'tkinter'
print(tkinter.TkVersion)     # 8.6
print(tkinter.Tk, type(tkinter.Tk))  # <class 'tkinter.Tk'>
```

**如果 import 报错 `ModuleNotFoundError: No module named 'tkinter'`**，说明 Python 安装时没带 tcl/tk：

- **Windows / macOS**：重装官方 Python（python.org 下载的版本都自带）
- **Ubuntu / Debian**：`sudo apt install python3-tk`
- **CentOS / Fedora**：`sudo dnf install python3-tkinter`

**Linux 用户请注意**：很多最小安装的服务器、Docker 镜像、WSL 精简版，Python 都是"裸"的，tkinter 默认缺失。装好后 `python3 -c "import tkinter; print('ok')"` 验证一下。

## 两种 import 写法

**写法一：只 import 模块名（推荐）**

```
import tkinter as tk

root = tk.Tk()
btn = tk.Button(root, text="按钮")
```

**写法二：直接导入类**

```
from tkinter import Tk, Button, Label

root = Tk()
btn = Button(root, text="按钮")
```

| 对比 | `import tkinter as tk` | `from tkinter import *` |
|---|---|---|
| 可读性 | 高，`tk.Button` 一看就知道来源 | 低，名字从哪来不清楚 |
| 命名冲突 | 不会，名字前面有 `tk.` | **会**，和标准库/自己写的同名 |
| 官方推荐 | ✅ 推荐 | ❌ 不推荐 |

**强烈建议用第一种 `import tkinter as tk`。** 理由很实在：`tkinter` 里有大量名字（`Label`、`Frame`、`StringVar`、`END`）容易和你自己的变量撞车，`tk.` 前缀一眼能分辨。

**千万避开 `from tkinter import *`**。这会把 tkinter 里几百个名字倒进你的命名空间，一旦你写了个 `Label = ...`，后面 `tkinter.Label` 就全废了，报错还不好查。

## 顺带提一句 ttk

**tkinter 里其实有两套控件**：`tkinter` 和 `tkinter.ttk`（Themed Tk）。

```
import tkinter as tk
import tkinter.ttk as ttk

root = tk.Tk()

# 两套都能用
old_btn = tk.Button(root, text="老式按钮")     # 复古外观
new_btn = ttk.Button(root, text="新式按钮")    # 跟随系统主题
```

**现阶段你只要知道 ttk 存在。** 第 15 课会专门讲 ttk 的 Combobox、Spinbox、Scale 这些 tkinter 没有的控件，也会讲为什么推荐用 ttk。现在统一用 `tk.` 前缀就够。

## Tk() 返回了什么

**`tk.Tk()` 返回的是一个窗口对象**，它是整个程序的"根"。

```
root = tk.Tk()
print(type(root))   # <class 'tkinter.Tk'>
```

**这个对象能干什么？** 几乎全部窗口操作都在它身上：

| 操作 | 方法/属性 |
|---|---|
| 设标题 | `root.title("标题")` |
| 设大小 | `root.geometry("400x300")` |
| 改背景色 | `root.configure(bg="lightblue")` |
| 收尾退出 | `root.destroy()` / `root.quit()` |

**约定俗成的叫法是 `root`、`master` 或 `win`。** 社区里 90% 的教程都叫 `root`，跟着叫能减少读别人代码时的困惑。

## 子控件必须"认祖归宗"

**每个控件创建时，第一个参数必须是它的"父控件"**（它挂在谁身上）。

```
import tkinter as tk

root = tk.Tk()

# 第一个参数是父控件
label = tk.Label(root, text="我挂在 root 上")
button = tk.Button(root, text="我也挂在 root 上")

root.mainloop()
```

**如果不传父控件，控件就没地方显示：**

```
label = tk.Label(text="忘记写父控件了")
label.pack()
root.mainloop()
```

**这段代码有时能跑（Label 会自动挂在默认根窗口上），但行为不可靠，千万别这么写。** 永远显式地传父控件，这是好习惯。

## mainloop 再深挖：它到底是什么

**`mainloop()` 启动的是一个"事件循环"**。可以把它想象成一个永远在跑的 `while True`：

```python
# 伪代码，帮助理解，不是真实实现
def mainloop():
    while 窗口没被关闭:
        看看有没有事件（用户点了按钮？按了键？鼠标动了？）
        如果有，就调用对应的回调函数
        把界面重画一遍
```

**这就是为什么窗口能"一直显示着"**：它在循环里不停地刷新自己。你在循环里写的那些"当按钮被点击时……"的回调，就是这个循环在事件发生时去调用的。

**为什么必须 mainloop？** 没有它，Python 执行完 `tk.Tk()` 就把控制权交还给了操作系统，窗口既没被画出来，也没人去监听鼠标键盘，于是就"闪退"了。

## 翻车现场一：把 tkinter 拼错

```
import Tkinter as tk     # 报错！
```

**Python 3 里模块叫 `tkinter`（全小写）。** `Tkinter`（首字母大写）是 Python 2 的写法。如果你照着十年前的老教程抄，第一行就会报错 `ModuleNotFoundError`。

**另外**：`tkinter.messagebox`、`tkinter.filedialog` 这些**必须单独 import**，不像你想的"import 了 tkinter 就都有了"。

```
import tkinter as tk
tk.messagebox.showinfo("标题", "内容")   # AttributeError! messagebox 没被导入
```

正确写法：

```
import tkinter as tk
import tkinter.messagebox as mb

mb.showinfo("标题", "内容")
```

**记住：import 到哪一级，就能用哪一级。** `import tkinter` 只让你用 `tkinter.Tk`、`tkinter.Label` 这一层；`tkinter.ttk`、`tkinter.messagebox`、`tkinter.filedialog` 都要再 import 一次。

## 翻车现场二：import 顺序导致的"先有鸡还是先有蛋"

```
from tkinter import messagebox
import tkinter as tk

root = tk.Tk()
mb.showinfo("hi", "hello")   # 有时报错：no display / 根窗口还没创建
```

**`messagebox` 之类的对话框依赖已经存在的根窗口。** 正确做法是：先 `import tkinter as tk`，再创建 `root = tk.Tk()`，最后才 import/使用 messagebox。稳妥的写法是把所有 import 集中在文件开头。

## 翻车现场三：把控件存进变量又没用到

```
tk.Label(root, text="提示").pack()          # 没存变量，没问题
label = tk.Label(root, text="提示").pack()  # 坑！
print(label)                                 # None
```

**`pack()` / `grid()` / `place()` 这三个布局方法都返回 `None`。** 所以上面 `label` 其实是 `None`，你后面想 `label.configure(text="新文字")` 就会 `AttributeError: 'NoneType' object has no attribute 'configure'`。

正确写法分两行：

```
label = tk.Label(root, text="提示")
label.pack()
# 之后才能用 label 变量
```

**这个坑后面讲布局时还会遇到，提前记住。**

## 看看 Tk 自己的属性

**`Tk()` 对象身上有一堆好用的属性：**

```
import tkinter as tk

root = tk.Tk()
print(root.title())          # 当前标题，没设过就是 ''
print(root.geometry())       # 当前几何尺寸，如 '400x300+100+100'
print(root.winfo_screenwidth(), root.winfo_screenheight())  # 屏幕分辨率
print(root.winfo_width(), root.winfo_height())              # 窗口当前尺寸
```

**`winfo_*` 系列方法能问出各种"当前状态"**：屏幕尺寸、窗口位置、控件尺寸。**做"窗口居中"时必须用它**（下一课会用到）。

## 小结

- tkinter 是标准库，`import tkinter as tk` 最稳妥；避开 `from tkinter import *`
- tkinter 分 `tkinter` 和 `tkinter.ttk` 两套，ttk 控件外观更现代
- `tk.Tk()` 返回根窗口对象，约定叫 `root`；它是整个程序的"根"
- 每个控件第一个参数必须是**父控件**，别漏
- `mainloop()` 是事件循环，窗口程序的"终点站"，必须写且必须最后写
- `pack()`/`grid()`/`place()` 都返回 `None`，别把它们的返回值存进变量
- `messagebox`、`filedialog`、`ttk` 要**单独 import**
