# Checkbutton 与 Radiobutton

> 多选和单选怎么做？这一节讲 Checkbutton（复选框）和 Radiobutton（单选按钮），以及它们背后的 IntVar / StringVar / BooleanVar——为什么必须用变量类。

## Checkbutton：多选

**Checkbutton 就是复选框，可以多选：**

```
import tkinter as tk

root = tk.Tk()
root.title("多选")

tk.Checkbutton(root, text="苹果").pack(anchor="w")
tk.Checkbutton(root, text="香蕉").pack(anchor="w")
tk.Checkbutton(root, text="橙子").pack(anchor="w")

root.mainloop()
```

**现在三个框都能勾，但程序不知道用户勾了哪些——因为没有变量绑定。**

## Checkbutton 绑定 BooleanVar

**用 `variable` 参数绑定一个变量类，才能读出勾选状态：**

```
import tkinter as tk

root = tk.Tk()

var_apple = tk.BooleanVar()
var_banana = tk.BooleanVar()
var_orange = tk.BooleanVar()

tk.Checkbutton(root, text="苹果", variable=var_apple).pack(anchor="w")
tk.Checkbutton(root, text="香蕉", variable=var_banana).pack(anchor="w")
tk.Checkbutton(root, text="橙子", variable=var_orange).pack(anchor="w")

def show():
    fruits = []
    if var_apple.get(): fruits.append("苹果")
    if var_banana.get(): fruits.append("香蕉")
    if var_orange.get(): fruits.append("橙子")
    print("选中了：", fruits)

tk.Button(root, text="确认", command=show).pack()

root.mainloop()
```

**勾选后点"确认"，终端打印选中的水果。**

**`var.get()` 返回 `True`/`False`。**

## onvalue / offvalue：自定义值

**Checkbutton 默认勾选是 `True`、未勾选是 `False`。可以自定义：**

```
var = tk.BooleanVar()
tk.Checkbutton(root, text="启用", variable=var,
               onvalue="yes", offvalue="no").pack()

# var.get() 返回 "yes" 或 "no"
```

**常见用法**：把 `onvalue=1, offvalue=0` 配合 IntVar 用。

## Radiobutton：单选

**Radiobutton 是单选按钮，同一组里只能选一个：**

```
import tkinter as tk

root = tk.Tk()

var = tk.StringVar(value="北京")

tk.Radiobutton(root, text="北京", variable=var, value="北京").pack(anchor="w")
tk.Radiobutton(root, text="上海", variable=var, value="上海").pack(anchor="w")
tk.Radiobutton(root, text="广州", variable=var, value="广州").pack(anchor="w")

def show():
    print("选中了：", var.get())

tk.Button(root, text="确认", command=show).pack()

root.mainloop()
```

**关键点：`variable` 是同一个 `var`，`value` 各不相同。**

**因为 `variable` 是同一个变量，勾选任何一个按钮都会把 `var` 设成对应的 `value`——这就实现了"单选"。**

## 同一变量 = 同一组

**多个 Radiobutton 共用一个 `variable`，它们就是一组，互斥。**

```
var = tk.StringVar(value="男")
tk.Radiobutton(root, text="男", variable=var, value="男").pack()
tk.Radiobutton(root, text="女", variable=var, value="女").pack()

# 想做第二组（比如年龄段），必须用另一个变量
var2 = tk.StringVar(value="青年")
tk.Radiobutton(root, text="青年", variable=var2, value="青年").pack()
tk.Radiobutton(root, text="中年", variable=var2, value="中年").pack()
```

**`var` 和 `var2` 是两组，互不干扰。**

## 为什么必须用变量类

**翻车现场：用普通变量绑定 Checkbutton：**

```
checked = False
tk.Checkbutton(root, text="同意", variable=checked).pack()   # 无效或报错
```

**`variable` 参数要求传 tkinter 的变量类对象（BooleanVar/IntVar/StringVar/DoubleVar）。** 普通 `bool`、`int`、`str` 没有 tkinter 需要的接口，绑不上。

**为什么 tkinter 要搞这套变量类？** 因为普通 Python 变量改了值，tkinter 不知道；变量类是"带通知"的，值一变界面就刷新，界面改了值也跟着变。这是 tkinter 的"数据绑定"机制。

## command 回调

**Checkbutton 和 Radiobutton 都支持 `command`，状态一变就触发：**

```
def on_change():
    print("当前：", var.get())

tk.Radiobutton(root, text="选项A", variable=var, value="A", command=on_change).pack()
tk.Radiobutton(root, text="选项B", variable=var, value="B", command=on_change).pack()
```

**切换选项时自动打印当前值。** 不用等按钮点击，实时响应。

**注意**：command 不加括号，`command=on_change`；想传参数用 `lambda`（第 17 课讲）。

## 用 IntVar 做 Radiobutton

**选项对应数字时用 IntVar：**

```
var = tk.IntVar(value=1)

tk.Radiobutton(root, text="小", variable=var, value=1).pack()
tk.Radiobutton(root, text="中", variable=var, value=2).pack()
tk.Radiobutton(root, text="大", variable=var, value=3).pack()

# var.get() 返回 1 / 2 / 3
```

**适合：尺寸、等级、评分这类"离散数值选项"。**

## indicatoron：做成按钮样式

**`indicatoron=False` 可以把 Radiobutton 做成"按下凹陷"的按钮样式：**

```
var = tk.StringVar(value="A")

tk.Radiobutton(root, text="A", variable=var, value="A",
               indicatoron=False, width=5).pack(side="left")
tk.Radiobutton(root, text="B", variable=var, value="B",
               indicatoron=False, width=5).pack(side="left")
tk.Radiobutton(root, text="C", variable=var, value="C",
               indicatoron=False, width=5).pack(side="left")
```

**看起来像一排按钮，选中那个会凹陷。** 做工具栏式的单选很实用。

## 翻车现场一：Radiobutton 共用变量但没设 value

```
var = tk.StringVar()
tk.Radiobutton(root, text="A", variable=var).pack()   # 没写 value
tk.Radiobutton(root, text="B", variable=var).pack()
```

**没设 `value`，两个按钮的 value 都是空字符串，点哪个都表现异常。**

**修复**：每个 Radiobutton 必须写 `value=...`，且同一组内各不相同。

## 翻车现场二：Radiobutton 用了两个不同变量

```
var1 = tk.StringVar()
var2 = tk.StringVar()
tk.Radiobutton(root, text="A", variable=var1, value="A").pack()
tk.Radiobutton(root, text="B", variable=var2, value="B").pack()
```

**两个不同变量 = 两组 = 不互斥，两个都能同时选中。** 忘记单选了。

**修复**：同一组用同一个 `variable`。

## 翻车现场三：Checkbutton 读不到状态

```
var = tk.BooleanVar()
cb = tk.Checkbutton(root, text="同意", variable=var)
cb.pack()

print(var.get())   # 依赖默认初始值 False
```

**Checkbutton 绑定变量后，变量初始值是 `False`（未勾选）。** 想默认勾选：`var.set(True)`。

## 翻车现场四：select()/deselect() 与变量的关系

**Checkbutton 可以用代码勾选/取消：**

```
cb.select()      # 勾上
cb.deselect()    # 取消
```

**这些方法和变量同步**：`select()` 等价于 `var.set(True)`。改哪个都行。

## 实战：一个设置面板

**Checkbutton 多选 + Radiobutton 单选组合：**

```
import tkinter as tk

root = tk.Tk()
root.title("设置")

tk.Label(root, text="通知方式（可多选）：").pack(anchor="w")
notify_email = tk.BooleanVar()
notify_sms = tk.BooleanVar()
tk.Checkbutton(root, text="邮件", variable=notify_email).pack(anchor="w")
tk.Checkbutton(root, text="短信", variable=notify_sms).pack(anchor="w")

tk.Label(root, text="主题：").pack(anchor="w")
theme = tk.StringVar(value="浅色")
tk.Radiobutton(root, text="浅色", variable=theme, value="浅色").pack(anchor="w")
tk.Radiobutton(root, text="深色", variable=theme, value="深色").pack(anchor="w")

def save():
    methods = []
    if notify_email.get(): methods.append("邮件")
    if notify_sms.get(): methods.append("短信")
    print("通知：", methods, "主题：", theme.get())

tk.Button(root, text="保存", command=save).pack()

root.mainloop()
```

## 小结

- **Checkbutton** 多选，绑 `BooleanVar`，`get()` 返回 True/False
- **Radiobutton** 单选，**同一组共用一个 variable，各 value 不同**
- 变量类有 BooleanVar / IntVar / StringVar / DoubleVar
- `command` 让状态变化时自动触发回调（不加括号）
- `onvalue/offvalue` 自定义 Checkbutton 的勾选值
- `indicatoron=False` 把 Radiobutton 做成按钮样式
- `select()`/`deselect()` 代码控制勾选
