# 三种布局管理器概览

> 控件创建出来是"飘着的"，必须放进窗口里才有位置、有大小。干这件事的有三个工具：pack、grid、place。这一节讲清它们各自的性格，帮你选对工具。

## 布局是什么

**布局（Geometry Management）= 决定每个控件"在哪、多大"。** tkinter 里没有布局，控件就隐形。

**三个布局管理器：**

| 管理器 | 中文名 | 思路 | 一句话评价 |
|---|---|---|---|
| `pack()` | 包装 | 按上下左右"贴边"排 | 简单但管不了精确位置 |
| `grid()` | 网格 | 像表格一样按行按列放 | 最常用、最灵活 |
| `place()` | 定位 | 指定绝对/相对坐标 | 最自由也最容易乱 |

**三个管理器不能同时混用在同一父控件上**（关键！后面翻车现场细讲）。但可以在**不同**父控件上各用各的。

## pack：贴边排队

**pack 的逻辑是"找个方向贴边，依次排开"。**

```
import tkinter as tk

root = tk.Tk()
tk.Label(root, text="顶部").pack()
tk.Label(root, text="中间").pack()
tk.Label(root, text="底部").pack()
root.mainloop()
```

**三个 Label 默认从上到下排列**（side 默认是 "top"）。

**pack 的参数：**

| 参数 | 作用 |
|---|---|
| `side` | 贴哪边：`"top"`/`"bottom"`/`"left"`/`"right"` |
| `fill` | 沿哪个方向填满：`"x"`/`"y"`/`"both"`/`"none"` |
| `expand` | 有额外空间时是否扩展：`True`/`False` |
| `padx` / `pady` | 外边距（控件与控件之间） |
| `ipadx` / `ipady` | 内边距（控件内部留白） |
| `anchor` | 在分配到的空间里靠哪边：`"n"`/`"s"`/`"e"`/`"w"`/`"center"` |

**pack 适合的场景**：控件排成一行或一列的工具条、简单表单、快速原型。

**pack 不擅长的场景**：想让两个输入框对齐、想做"标签在左、输入框在右"的整齐表单——这时候该用 grid。

## grid：表格思维

**grid 把父控件想象成一张表格，每个控件占一个格子。**

```
import tkinter as tk

root = tk.Tk()
tk.Label(root, text="姓名：").grid(row=0, column=0)
tk.Entry(root).grid(row=0, column=1)
tk.Label(root, text="年龄：").grid(row=1, column=0)
tk.Entry(root).grid(row=1, column=1)
root.mainloop()
```

**结果：一个整齐的"标签 + 输入框"两列表单。** 这是 GUI 里最常见的布局。

**grid 的参数：**

| 参数 | 作用 |
|---|---|
| `row` / `column` | 第几行第几列（从 0 开始） |
| `rowspan` | 纵向跨几行 |
| `columnspan` | 横向跨几列 |
| `sticky` | 贴格子的哪边：`"n"`/`"s"`/`"e"`/`"w"` 或组合如 `"ew"` |
| `padx` / `pady` | 外边距 |
| `ipadx` / `ipady` | 内边距 |

**grid 适合的场景**：表单、计算器、棋盘、任何"对齐"需求。它是最常用的布局管理器。

## place：指定坐标

**place 直接指定控件的 x、y 坐标和宽高。**

```
import tkinter as tk

root = tk.Tk()
tk.Button(root, text="左上").place(x=10, y=10)
tk.Button(root, text="正中").place(x=100, y=80, width=80, height=30)
root.mainloop()
```

**参数：**

| 参数 | 作用 |
|---|---|
| `x` / `y` | 绝对坐标（像素） |
| `relx` / `rely` | 相对坐标（0.0~1.0，相对父控件） |
| `width` / `height` | 绝对尺寸 |
| `relwidth` / `relheight` | 相对尺寸 |
| `anchor` | 锚点：`"nw"` 表示控件左上角对齐到 (x,y) |

**place 适合的场景**：叠加层（浮层、水印）、画布类应用、需要像素级精确的自定义控件。

**place 不适合的场景**：常规表单、需要随窗口缩放的界面——它不管缩放，窗口一拉大就错位。

## 三选一：怎么选

| 你的界面 | 用哪个 |
|---|---|
| 简单一排按钮、从上到下一列控件 | `pack` |
| 表单、计算器、对齐需求 | `grid`（首选） |
| 浮层、叠加、像素级自定义 | `place` |
| 复杂界面 | `Frame` 分区，每区各用 pack 或 grid（推荐） |

**经验之谈**：新手最爱 pack，因为它最简单；熟练后你会发现 **grid 才是主力**，80% 的界面用它搞定；place 用得最少，但偶尔不可替代。

## 翻车现场一：pack 和 grid 混用

**在同一父控件上既 pack 又 grid，直接报错。**

```
import tkinter as tk

root = tk.Tk()
tk.Label(root, text="a").pack()
tk.Label(root, text="b").grid(row=0, column=0)   # 报错！
root.mainloop()
```

**报错信息：**

```
_tkinter.TclError: cannot use geometry manager grid inside . which already
has slaves managed by pack
```

**原因**：一个父控件只能由一种布局管理器统一管理。一旦你给它的某个子控件用了 pack，它就"被 pack 接管了"，再 grid 就会冲突。

**修复**：同一个父控件上的所有子控件用同一个管理器。想混用就把控件放进不同的 Frame，每个 Frame 各自用一种。

## 翻车现场二：只创建不布局

**这是第 4 课讲过的坑，布局章节再强调一次：**

```
label = tk.Label(root, text="看不见")
# 没有 pack/grid/place
```

**窗口空白。** 任何布局管理器都不调用，控件就隐形。

## 布局之外的"隐形布局"：控件自己的尺寸

**即使布局对了，控件也可能挤成一团或散得离谱。** 因为控件有自己的"自然尺寸"：

- `width`/`height`：字符数/行数
- `padx`/`pady`：外边距
- `ipadx`/`ipady`：内边距

```
tk.Button(root, text="宽按钮", width=20, padx=10).pack()
```

**`width=20` 是按钮文字宽 20 个字符；`padx=10` 是左右再各留 10 像素空白。** 两者叠加。

## 一个完整对照：三种方式做同一件事

**用 pack 做两列表单（要靠技巧）：**

```
tk.Label(root, text="姓名：").pack(anchor="w")
tk.Entry(root).pack(fill="x")
tk.Label(root, text="年龄：").pack(anchor="w")
tk.Entry(root).pack(fill="x")
```

**左对齐得靠 `anchor="w"`**，否则 Label 会居中。这已经有点别扭了。

**用 grid 做两列表单（自然）：**

```
tk.Label(root, text="姓名：").grid(row=0, column=0, sticky="e", padx=5, pady=5)
tk.Entry(root).grid(row=0, column=1, padx=5, pady=5)
tk.Label(root, text="年龄：").grid(row=1, column=0, sticky="e", padx=5, pady=5)
tk.Entry(root).grid(row=1, column=1, padx=5, pady=5)
```

**整齐、对齐、带边距，grid 完胜。**

**用 place 做两列表单（累死）：**

```
tk.Label(root, text="姓名：").place(x=10, y=10)
tk.Entry(root).place(x=80, y=10, width=150)
```

**每个控件都要手算坐标，改一个全得改。** 别这样。

## 混合布局的正确姿势：Frame 分区

**想在界面上既用 grid 又用 pack？用 Frame 切分：**

```
import tkinter as tk

root = tk.Tk()

top = tk.Frame(root)          # 顶部区
top.pack(fill="x")

body = tk.Frame(root)         # 主体区
body.pack(fill="both", expand=True)

# 顶部用 pack 排一排按钮
tk.Button(top, text="保存").pack(side="left")
tk.Button(top, text="取消").pack(side="left")

# 主体用 grid 做表单
tk.Label(body, text="姓名：").grid(row=0, column=0)
tk.Entry(body).grid(row=0, column=1)

root.mainloop()
```

**Frame 是"容器控件"，本身不可见，专门用来分区。** 每个 Frame 各自选一个布局管理器，互不干扰。这是做复杂界面的标准套路。

## 小结

- 三个布局管理器：**pack**（贴边排队）、**grid**（表格对齐）、**place**（坐标定位）
- **同一父控件只能用一种布局管理器**，混用直接报错
- pack 简单、grid 最常用、place 只在特殊场景用
- 复杂界面用 **Frame 分区**，每区选一种布局
- 控件不布局 = 看不见；`width`/`padx` 等控制尺寸和留白
