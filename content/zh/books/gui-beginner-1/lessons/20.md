# 变量追踪 trace：输入框一变就更新

> 想让界面"实时"响应变化——不用点按钮，输入的同时就更新。这一节讲 `trace`，以及用它做一个简易计算器。

## trace 是什么

**`trace` 是 tkinter 变量类（StringVar/IntVar 等）提供的"值变化通知"机制。** 变量一变，就自动调用你指定的函数。

```
import tkinter as tk

root = tk.Tk()

var = tk.StringVar()

def on_change(*args):
    print("值变了：", var.get())

var.trace("w", on_change)   # 监听写操作

var.set("你好")   # 触发 on_change，打印"值变了：你好"
```

**`var.trace("w", callback)` 表示：变量被写入（write）时调用 callback。**

## trace 的三种模式

| 模式 | 触发时机 |
|---|---|
| `"r"` | 读取值时（read） |
| `"w"` | 值被写入时（write） |
| `"u"` | 变量被删除时（unset） |

**最常用的是 `"w"`——值变了就通知。**

## trace 回调的签名

**trace 回调会被传入三个参数：`name`、`index`、`mode`（旧接口），或 `(var_name, index, mode)`（新接口）。**

**稳妥写法：用 `*args` 吃掉多余参数，只读自己需要的：**

```
def on_change(var_name, index, mode):
    print(f"{var_name} 被 {mode}，新值：{var.get()}")

var.trace("w", on_change)
```

**也可以只关心新值：**

```
def on_change(*args):
    print("新值：", var.get())

var.trace("w", on_change)
```

## 实战：简易计算器

**用 trace 做一个"输入即计算"的计算器：**

```
import tkinter as tk

root = tk.Tk()
root.title("简易计算器")

tk.Label(root, text="数字1：").grid(row=0, column=0)
tk.Label(root, text="数字2：").grid(row=1, column=0)
tk.Label(root, text="结果：").grid(row=2, column=0)

v1 = tk.StringVar()
v2 = tk.StringVar()
result = tk.StringVar()

tk.Entry(root, textvariable=v1).grid(row=0, column=1)
tk.Entry(root, textvariable=v2).grid(row=1, column=1)
tk.Label(root, textvariable=result).grid(row=2, column=1)

def calc(*args):
    try:
        a = float(v1.get() or 0)
        b = float(v2.get() or 0)
        result.set(a + b)
    except ValueError:
        result.set("输入无效")

v1.trace("w", calc)
v2.trace("w", calc)

root.mainloop()
```

**在两个输入框里敲数字，结果框**实时**显示求和，不用点任何按钮。**

**关键**：`v1.trace("w", calc)` 和 `v2.trace("w", calc)`——两个变量的任何变化都会触发 `calc`。

## trace 的常见坑

**`trace` 的回调是"被 tkinter 调用的"，不是被你调用的。** tkinter 会按它自己的签名传参。

**翻车现场一：回调参数不匹配**

```
def calc():   # 没定义参数
    print(var.get())

var.trace("w", calc)
# 报错：calc() takes 0 positional arguments but 3 were given
```

**修复**：用 `*args` 接收：

```
def calc(*args):
    print(var.get())
```

## 翻车现场二：trace 绑到普通字符串

```
name = ""
name.trace("w", on_change)   # AttributeError: 'str' object has no attribute 'trace'
```

**只有 tkinter 变量类（StringVar/IntVar/DoubleVar/BooleanVar）才有 trace。** 普通 `str`/`int` 没有。

## 翻车现场三：反复 trace 导致回调被调用多次

```
var.trace("w", func)   # 第一次绑定
var.trace("w", func)   # 又绑定一次
var.set("x")           # func 被调用两次！
```

**同一回调绑定多次会触发多次。** 调试时容易踩到——改一处代码结果回调执行了两遍。

**解除绑定用 `trace_remove`：**

```
trace_id = var.trace("w", func)
var.trace_remove("w", trace_id)
```

## trace 与 bind 的区别

**什么时候用 trace，什么时候用 bind？**

| 场景 | 用 |
|---|---|
| 变量值变了要响应 | `trace`（数据驱动） |
| 用户点了/按了/动了控件 | `bind`（事件驱动） |
| Entry 内容变化 | 两者都能，trace 更语义化 |
| 键盘按键 | bind |
| Scale/Spinbox 值变 | bind 的虚拟事件或 trace |

**经验**：绑定变量变化用 trace；绑定用户动作（点击、按键、鼠标）用 bind。

## 用 trace 做"输入实时校验"

**边输入边提示格式是否正确：**

```
import tkinter as tk

root = tk.Tk()

var = tk.StringVar()
entry = tk.Entry(root, textvariable=var)
entry.pack()

label = tk.Label(root, text="")
label.pack()

def check(*args):
    val = var.get()
    if val.isdigit():
        label.configure(text="✓ 都是数字", fg="green")
    else:
        label.configure(text="✗ 请输入数字", fg="red")

var.trace("w", check)
root.mainloop()
```

**输入"123"显示绿色对勾；输入"12a"显示红色提示。**

## 一个更完整的计算器

**支持加减乘除：**

```
import tkinter as tk

root = tk.Tk()
root.title("计算器")

tk.Label(root, text="第一个数").grid(row=0, column=0)
tk.Label(root, text="运算").grid(row=1, column=0)
tk.Label(root, text="第二个数").grid(row=2, column=0)
tk.Label(root, text="结果").grid(row=3, column=0)

v1 = tk.StringVar()
op = tk.StringVar(value="+")
v2 = tk.StringVar()
result = tk.StringVar()

tk.Entry(root, textvariable=v1).grid(row=0, column=1)
ops = tk.OptionMenu(root, op, "+", "-", "*", "/")
ops.grid(row=1, column=1, sticky="ew")
tk.Entry(root, textvariable=v2).grid(row=2, column=1)
tk.Label(root, textvariable=result).grid(row=3, column=1)

def calc(*args):
    try:
        a = float(v1.get() or 0)
        b = float(v2.get() or 0)
        o = op.get()
        if o == "+": r = a + b
        elif o == "-": r = a - b
        elif o == "*": r = a * b
        elif o == "/" and b != 0: r = a / b
        else: r = "除数不能为0"
        result.set(r)
    except ValueError:
        result.set("输入无效")

v1.trace("w", calc)
v2.trace("w", calc)
op.trace("w", calc)

root.mainloop()
```

**`OptionMenu` 是 tkinter 里的下拉菜单控件（绑定 StringVar）。** 改运算符、改数字，结果都实时更新。

## trace 的"过度触发"问题

**`trace("w")` 每次写入都触发，哪怕值没变：**

```
var.set("abc")
var.set("abc")   # 值一样，但 trace 照样触发
```

**如果回调里有耗时操作，频繁触发会卡界面。** 解决思路：回调里用标志位、或改用"失焦时校验"（bind `<FocusOut>`）。

## 小结

- `trace("w", callback)` 监听变量写入，值一变就调回调
- 三种模式：`"r"` 读、`"w"` 写、`"u"` 删除
- 回调签名要用 `*args` 兼容 tkinter 传入的参数
- 只有变量类（StringVar 等）才有 trace，普通变量没有
- trace 适合"数据变化响应"；bind 适合"用户动作响应"
- `trace_remove("w", trace_id)` 解除绑定
