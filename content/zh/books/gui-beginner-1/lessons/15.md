# Combobox / Spinbox / Scale：ttk 控件

> tkinter 的控件长得比较"复古"。这一节讲 ttk（Themed Tk）里更现代、更漂亮的几个控件：Combobox 下拉框、Spinbox 微调框、Scale 滑块。顺便搞清为什么推荐用 ttk。

## ttk 是什么

**ttk 是 tkinter 的主题化子模块**，提供外观跟随操作系统的控件。

```
import tkinter as tk
import tkinter.ttk as ttk

root = tk.Tk()

ttk.Button(root, text="新式按钮").pack()
ttk.Label(root, text="新式标签").pack()

root.mainloop()
```

**对比：**

| tkinter 控件 | ttk 控件 |
|---|---|
| 复古外观、Windows 95 风格 | 跟随系统主题，现代 |
| `tk.Button` | `ttk.Button` |
| `tk.Label` | `ttk.Label` |
| `tk.Entry` | `ttk.Entry` |
| `tk.Checkbutton` | `ttk.Checkbutton` |
| `tk.Radiobutton` | `ttk.Radiobutton` |
| `tk.Frame` | `ttk.Frame` |

**怎么选**：能用 ttk 就用 ttk，外观更好；但 ttk 有几个限制（颜色不好改、没有 FloatVar 绑定细节差异），必要时退回 tkinter。

## 为什么推荐 ttk

**三个理由：**

1. **外观现代**：跟系统风格一致，macOS 上圆角、Windows 上扁平。
2. **多了几个 tkinter 没有的控件**：Combobox、Spinbox、Treeview、Notebook、Progressbar、Separator。
3. **切换主题**：`ttk.Style()` 能改整体风格。

**设置主题：**

```
import tkinter.ttk as ttk

style = ttk.Style()
print(style.theme_names())   # ('winnative', 'clam', 'alt', 'default', 'classic', 'vista', 'xpnative')
style.theme_use("clam")      # 换主题
```

**常见主题**：`clam`（跨平台一致）、`vista`/`xpnative`（Windows）、`aqua`（macOS）。

## Combobox：下拉框

**Combobox 是"输入框 + 下拉列表"的组合：**

```
import tkinter as tk
import tkinter.ttk as ttk

root = tk.Tk()

cb = ttk.Combobox(root, values=["苹果", "香蕉", "橙子", "葡萄"])
cb.pack(padx=10, pady=10)
cb.set("请选择")   # 设置当前显示的值

root.mainloop()
```

**`values` 是下拉选项列表；`set()` 设置/读取当前值。**

## Combobox 读取值

**两种方式读：**

```
# 方式一：直接 get（读当前输入框的文字）
print(cb.get())

# 方式二：绑定 StringVar
var = tk.StringVar()
cb = ttk.Combobox(root, textvariable=var, values=["A", "B", "C"])
print(var.get())
```

**Combobox 的 `get()` 返回当前显示的字符串**——用户可以选，也可以自己手打（除非设置 `state="readonly"`）。

## Combobox 只读模式

**`state="readonly"` 让用户只能从下拉里选，不能手打：**

```
cb = ttk.Combobox(root, values=["男", "女"], state="readonly")
cb.set("男")
```

**做表单时常用，避免用户输入乱七八糟的值。**

## Combobox 事件：选中即响应

```
def on_select(event):
    print("选中：", cb.get())

cb.bind("<<ComboboxSelected>>", on_select)
```

**`<<ComboboxSelected>>` 是 Combobox 的虚拟事件**，一选中就触发。

## Spinbox：微调框

**Spinbox 是带上下箭头的输入框，在限定范围内步进：**

```
sb = tk.Spinbox(root, from_=0, to=100, increment=1)
sb.pack()

print(sb.get())   # 当前值（字符串）
```

**参数：**

| 参数 | 作用 |
|---|---|
| `from_` | 最小值（注意是 from_，下划线） |
| `to` | 最大值 |
| `increment` | 步长 |
| `values` | 指定可选列表（代替 from_/to） |
| `wrap` | True 时到边界循环 |
| `state` | `"normal"`/`"readonly"`/`"disabled"` |

**`from_` 要写成 `from_`**，因为 `from` 是 Python 关键字。

**用 values 指定离散选项：**

```
sb = tk.Spinbox(root, values=["小", "中", "大", "特大"])
```

**Spinbox 也能绑定变量：**

```
var = tk.StringVar(value="1")
sb = tk.Spinbox(root, from_=1, to=10, textvariable=var)
```

## Scale：滑块

**Scale 是滑动条，适合"大致取值"：**

```
scale = tk.Scale(root, from_=0, to=100, orient="horizontal")
scale.pack()

print(scale.get())   # 当前数值（整数）
```

**参数：**

| 参数 | 作用 |
|---|---|
| `from_` / `to` | 范围 |
| `orient` | `"horizontal"`(水平) / `"vertical"`(竖直) |
| `resolution` | 步长（如 0.1） |
| `tickinterval` | 刻度间隔 |
| `length` | 滑块长度（像素） |
| `showvalue` | 是否显示当前值 |
| `variable` | 绑定 IntVar/DoubleVar |

**`resolution=0.1` 让滑块能选小数。**

## Scale 绑定变量与回调

```
var = tk.DoubleVar(value=50.0)
scale = tk.Scale(root, from_=0, to=100, resolution=0.1,
                 variable=var, orient="horizontal")

def on_change(var_name, idx, op):
    print("当前值：", var.get())

var.trace("w", on_change)   # 值变化时触发
```

**`trace` 的用法第 20 课细讲，这里先看结论。**

## 翻车现场一：ttk 控件用 tkinter 的变量类没问题，但外观配置不同

**ttk 控件配颜色要用 Style，不能直接 `bg=`：**

```
ttk.Label(root, text="x", bg="red").pack()   # 可能无效
```

**ttk 忽略很多 tkinter 的直接属性。** 要改 ttk 外观得用 `Style`：

```
style = ttk.Style()
style.configure("Red.TLabel", foreground="red", background="white")
ttk.Label(root, text="红色文字", style="Red.TLabel").pack()
```

**这套 Style 系统稍复杂，现阶段知道"ttk 控件不能直接用 bg/fg，要用 Style"就行。**

## 翻车现场二：Combobox 没设 values

```
cb = ttk.Combobox(root)   # 没有下拉选项
cb.pack()
```

**下拉是空的。** 记得传 `values=[...]`。

## 翻车现场三：Spinbox 的 from_ 写成 from

```
sb = tk.Spinbox(root, from=0, to=10)   # SyntaxError!
```

**`from` 是 Python 关键字，必须写 `from_`。**

## 翻车现场四：Scale 的 orient 写错

```
scale = tk.Scale(root, orient="horizontal")   # 正确
scale = tk.Scale(root, orientation="horizontal")  # 错！参数名是 orient
```

**参数名是 `orient`（不是 `orientation`）。**

## 三种控件的选择建议

| 场景 | 用 |
|---|---|
| 从固定列表里选一个，选项不多 | Combobox / OptionMenu |
| 在连续范围内取值，要精确 | Spinbox（步进） |
| 在连续范围内取值，要大致感觉 | Scale（滑块） |
| 选项很多、要搜索/滚动 | Listbox |
| 开关/多选 | Checkbutton |
| 互斥单选 | Radiobutton |

## 实战：一个参数面板

**Combobox 选模式 + Spinbox 设数量 + Scale 设强度：**

```
import tkinter as tk
import tkinter.ttk as ttk

root = tk.Tk()
root.title("参数设置")

tk.Label(root, text="模式：").grid(row=0, column=0, sticky="e")
mode = ttk.Combobox(root, values=["快速", "标准", "精细"], state="readonly")
mode.set("标准")
mode.grid(row=0, column=1, sticky="ew")

tk.Label(root, text="数量：").grid(row=1, column=0, sticky="e")
count = tk.Spinbox(root, from_=1, to=100, increment=1)
count.grid(row=1, column=1, sticky="ew")

tk.Label(root, text="强度：").grid(row=2, column=0, sticky="e")
power = tk.Scale(root, from_=0, to=100, orient="horizontal")
power.grid(row=2, column=1, sticky="ew")

def show():
    print(f"模式={mode.get()}, 数量={count.get()}, 强度={power.get()}")

ttk.Button(root, text="确认", command=show).grid(row=3, column=0, columnspan=2)

root.mainloop()
```

## 小结

- ttk 是主题化控件，`import tkinter.ttk as ttk`，外观更现代
- **Combobox**：下拉框，`values` 设选项，`state="readonly"` 禁止手打
- **Spinbox**：步进输入框，`from_`/`to`/`increment`（注意 `from_` 带下划线）
- **Scale**：滑块，`orient`/`resolution`/`variable`
- ttk 控件改外观要用 `Style`，不能直接 `bg=`
- 读值统一用 `控件.get()` 或绑定变量类的 `get()`
