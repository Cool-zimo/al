# 键盘与鼠标：焦点、快捷键、拖动

> 这一节把键盘和鼠标的高级玩法讲透：焦点管理、快捷键、拖动的实现思路，以及事件绑定的几个实用技巧。

## 焦点（Focus）：谁在听键盘

**键盘事件只会发给"当前有焦点"的控件。** 焦点就是"光标现在停在哪"。

```
import tkinter as tk

root = tk.Tk()

e1 = tk.Entry(root)
e1.pack()
e2 = tk.Entry(root)
e2.pack()

root.mainloop()
```

**程序启动后，焦点在某个 Entry 上（通常是第一个）。点击另一个 Entry，焦点就移过去。只有有焦点的 Entry 才会响应键盘输入。**

## focus_set / focus_get

**`focus_set()` 把焦点设给某个控件：**

```
e1.focus_set()   # 程序启动后光标直接停在 e1
```

**`focus_get()` 查当前焦点是谁：**

```
w = root.focus_get()
print(w)   # 当前有焦点的控件
```

**`focus_set()` 是个高频实用技巧**：程序一打开就让用户输入框获得焦点，不用先点一下。

## 快捷键：键盘绑定

**用 bind 实现快捷键：**

```
import tkinter as tk

root = tk.Tk()

def save(event=None):
    print("保存文件")

def open_file(event=None):
    print("打开文件")

root.bind("<Control-s>", lambda e: save())
root.bind("<Control-o>", lambda e: open_file())

tk.Label(root, text="按 Ctrl+S 保存，Ctrl+O 打开").pack()
root.mainloop()
```

**`<Control-s>` 表示 Ctrl+S。**

**注意：给回调的 event 参数设默认值 `event=None`**，这样同一个函数既能当 bind 回调（收 event），也能当按钮的 command（不收 event）。

## 组合快捷键

```
root.bind("<Control-Shift-s>", lambda e: print("另存为"))  # Ctrl+Shift+S
root.bind("<Alt-F4>", lambda e: print("尝试关闭"))         # Alt+F4
```

**常用快捷键约定：**

| 快捷键 | 习惯动作 |
|---|---|
| Ctrl+N | 新建 |
| Ctrl+O | 打开 |
| Ctrl+S | 保存 |
| Ctrl+Shift+S | 另存为 |
| Ctrl+Z | 撤销 |
| Ctrl+C / Ctrl+V | 复制/粘贴 |
| Delete | 删除 |
| F5 | 刷新 |
| Esc | 取消/关闭 |

## 拦截系统快捷键

**`return "break"` 阻止事件继续传播，能"吃掉"系统快捷键：**

```
def on_alt_f4(event):
    print("拦截到 Alt+F4，不做任何事")
    return "break"

root.bind("<Alt-F4>", on_alt_f4)
```

**这个技巧用来做"确认是否退出"的弹窗**（第 21 课讲 messagebox 后就能实现）。

## 鼠标事件全表

| 事件 | 触发时机 |
|---|---|
| `<Button-1>` | 左键按下 |
| `<ButtonRelease-1>` | 左键松开 |
| `<Double-1>` | 左键双击 |
| `<Triple-1>` | 左键三连击 |
| `<Motion>` | 鼠标移动（任意键） |
| `<B1-Motion>` | 左键按住并移动 |
| `<B2-Motion>` / `<B3-Motion>` | 中/右键按住并移动 |
| `<Enter>` | 鼠标进入控件 |
| `<Leave>` | 鼠标离开控件 |

## 拖动（Drag）的雏形

**拖动 = 按下 + 移动 + 松开。用三个事件配合实现：**

```
import tkinter as tk

root = tk.Tk()
root.title("拖动方块")

canvas = tk.Canvas(root, width=400, height=300, bg="white")
canvas.pack()

rect = canvas.create_rectangle(50, 50, 100, 100, fill="blue")

def on_press(event):
    # 记录按下的位置
    canvas._drag_data = {"x": event.x, "y": event.y}

def on_drag(event):
    # 算出移动了多少，移动方块
    dx = event.x - canvas._drag_data["x"]
    dy = event.y - canvas._drag_data["y"]
    canvas.move(rect, dx, dy)
    canvas._drag_data = {"x": event.x, "y": event.y}

def on_release(event):
    # 松开，清理
    canvas._drag_data = None

canvas.bind("<ButtonPress-1>", on_press)
canvas.bind("<B1-Motion>", on_drag)
canvas.bind("<ButtonRelease-1>", on_release)

root.mainloop()
```

**思路**：

1. **按下**时记录起始坐标
2. **拖动**时算位移 `dx/dy`，移动方块，更新记录
3. **松开**时清理

**这就是 GUI 里"拖动"的通用模式。**

## 翻车现场一：拖动时位移越拖越飞

**常见错误：每次 move 都传绝对坐标而不是增量。**

```
def on_drag(event):
    canvas.move(rect, event.x, event.y)  # 错！event.x 是绝对坐标，越移越远
```

**`canvas.move(item, dx, dy)` 的参数是**相对位移**，不是绝对坐标。** 必须用 `event.x - last_x` 算出增量。

## 翻车现场二：忘记在控件上 bind，绑到了 root

```
canvas = tk.Canvas(root, ...)
root.bind("<Button-1>", on_press)   # 错！绑到 root 了
```

**想监听 Canvas 上的鼠标，要绑到 Canvas 上（除非你确实想监听整个窗口）。**

## 鼠标悬停效果

**用 `<Enter>` 和 `<Leave>` 做"鼠标悬停"效果：**

```
def on_enter(event):
    btn.configure(bg="lightblue")

def on_leave(event):
    btn.configure(bg="SystemButtonFace")

btn = tk.Button(root, text="按钮")
btn.bind("<Enter>", on_enter)
btn.bind("<Leave>", on_leave)
```

**这能做出网页里常见的"鼠标悬停变亮"效果。**

**注意：ttk 控件改颜色要用 Style，直接 `bg=` 可能无效。**

## 事件绑定到类里的方法

**在类里组织事件回调：**

```
import tkinter as tk

class App:
    def __init__(self, root):
        self.label = tk.Label(root, text="移动鼠标")
        self.label.pack(padx=30, pady=30)
        root.bind("<Motion>", self.on_motion)

    def on_motion(self, event):
        self.label.configure(text=f"({event.x}, {event.y})")

root = tk.Tk()
App(root)
root.mainloop()
```

**方法自带 `self`**，bind 调用时会把 event 作为第二个参数传入，正好对应 `self, event`。

## 绑定多个事件到同一回调

**一个回调处理多个事件：**

```
def on_any(event):
    print(f"事件：{event.type}，坐标：({event.x}, {event.y})")

root.bind("<Button-1>", on_any)
root.bind("<Button-3>", on_any)
root.bind("<Motion>", on_any)
```

**`event.type` 是事件类型编号。** 想区分具体事件，用 `event.widget` 或分开写不同回调。

## bind_all / bind_class

**`bind_all` 全局绑定（任何控件上触发都生效）：**

```
root.bind_all("<Control-q>", lambda e: root.destroy())
```

**`bind_class` 绑定到某类控件的所有实例：**

```
root.bind_class("Button", "<Enter>", lambda e: print("鼠标进了某个按钮"))
```

**这两个高级，了解即可，日常用 `bind` 就够。**

## 小结

- **焦点**决定键盘事件发给谁；`focus_set()` 主动给焦点
- 快捷键用 bind：`<Control-s>`、`<Control-Shift-s>`、`<Alt-F4>`
- `return "break"` 阻止事件传播，可拦截系统快捷键
- 拖动三步：**按下记录 → 移动算增量 → 松开清理**
- `canvas.move(item, dx, dy)` 的参数是**相对位移**
- `<Enter>`/`<Leave>` 做鼠标悬停效果
