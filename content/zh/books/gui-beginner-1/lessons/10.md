# place：绝对定位与相对定位

> place 是 tkinter 里最"原始"的布局方式——直接指定坐标。这一节讲它怎么用、为什么通常不推荐、以及那些确实非它不可的场景。

## place 的基本用法

**`place` 直接给控件指定 x、y 坐标（像素）和宽高：**

```
import tkinter as tk

root = tk.Tk()
root.geometry("400x300")

tk.Label(root, text="左上角", bg="red").place(x=0, y=0, width=80, height=30)
tk.Label(root, text="中间", bg="green").place(x=150, y=120, width=100, height=40)

root.mainloop()
```

**两个 Label 就精确地钉在指定坐标上。**

**place 的核心参数：**

| 参数 | 作用 |
|---|---|
| `x` / `y` | 绝对坐标（像素），控件**左上角** |
| `relx` / `rely` | 相对坐标（0.0~1.0），相对父控件尺寸 |
| `width` / `height` | 绝对尺寸（像素） |
| `relwidth` / `relheight` | 相对尺寸（0.0~1.0） |
| `anchor` | 锚点：`"nw"` 表示控件锚点在左上角 |

## 绝对定位 vs 相对定位

**绝对定位用 `x`/`y`/`width`/`height`，值是像素：**

```
label.place(x=10, y=20, width=100, height=30)
```

**相对定位用 `relx`/`rely`/`relwidth`/`relheight`，值是 0~1 的比例：**

```
label.place(relx=0.5, rely=0.5, relwidth=0.5, relheight=0.5, anchor="center")
```

**这个 Label 会在父控件正中央，宽高是父控件的一半。**

**相对定位的好处：窗口缩放时控件位置按比例跟着变。** 这是 place 唯一能"响应式"的方式。

## anchor：锚点

**`anchor` 决定控件的"哪个点"对齐到 (x, y)：**

| 值 | 含义 |
|---|---|
| `"nw"` | 控件左上角（默认） |
| `"n"` | 控件上边中点 |
| `"ne"` | 控件右上角 |
| `"w"` | 控件左边中点 |
| `"center"` | 控件中心 |
| `"e"` | 控件右边中点 |
| `"sw"` | 控件左下角 |
| `"s"` | 控件下边中点 |
| `"se"` | 控件右下角 |

**用 anchor 把控件"钉"在窗口右下角：**

```
tk.Label(root, text="右下角").place(relx=1.0, rely=1.0, anchor="se")
```

**`relx=1.0, rely=1.0` 是父控件右下角；`anchor="se"` 表示控件的右下角对齐到那个点——于是控件就贴在右下角。**

## 让控件始终居中

**结合 relx/rely 和 anchor：**

```
tk.Label(root, text="正中").place(relx=0.5, rely=0.5, anchor="center")
```

**窗口多大，它都在正中间。** 拉大窗口它会跟着移动保持居中。

## 一个实用场景：水印 / 浮层

**place 做"叠加层"很方便——把文字盖在图片上方：**

```
import tkinter as tk

root = tk.Tk()

# 底部图片（用纯色块模拟）
canvas = tk.Label(root, text="", bg="gray", width=400, height=300)
canvas.place(x=0, y=0, relwidth=1, relheight=1)

# 浮在上面一行水印文字
tk.Label(root, text="© 2026 我的软件", bg="white").place(relx=1.0, rely=1.0, anchor="se", x=-10, y=-10)

root.mainloop()
```

**`x=-10, y=-10` 是"微调"**：相对定位定到大方向后，再用像素做小偏移。

**这种"控件叠控件"的效果，用 pack/grid 很难做，place 天生擅长。**

## 另一个实用场景：自定义仪表盘

**想做一个圆形按钮、斜排的文字、不规则布局？place 最合适：**

```
import tkinter as tk

root = tk.Tk()
root.geometry("300x300")

tk.Button(root, text="A", width=6).place(x=20, y=20)
tk.Button(root, text="B", width=6).place(x=120, y=80)
tk.Button(root, text="C", width=6).place(x=60, y=160)
tk.Label(root, text="不规则布局", bg="yellow").place(x=180, y=180, width=100, height=40)

root.mainloop()
```

**坐标全由你定，想怎么摆就怎么摆。**

## 为什么不推荐 place

**place 有三个致命弱点：**

1. **不随窗口缩放（除非用 rel*）**：绝对坐标下窗口一拉大，控件错位、留白。
2. **改一个要改一串**：加个控件进去，后面所有坐标都要重算。
3. **对齐靠手算**：pack/grid 自动对齐，place 全靠你算像素，累且易错。

**对比一下：**

| 需求 | pack | grid | place |
|---|---|---|---|
| 随窗口缩放 | 容易 | 容易 | 必须写 rel* |
| 加控件 | 改一处 | 改一处 | 可能重算所有坐标 |
| 对齐 | 自动 | 自动 | 手算 |
| 像素级控制 | 无 | 无 | 有 |

**结论：能用 grid 就用 grid，能用 pack 就用 pack，只有需要"叠加/精确定位"时才用 place。**

## 翻车现场一：place 的控件不随窗口缩放

```
label.place(x=10, y=10, width=100, height=30)
```

**窗口从 400x300 拉到 800x600，label 还钉在 (10,10) 不动。** 要随动必须写 `relx`/`rely`/`relwidth`/`relheight`。

## 翻车现场二：relx=1.0 但没设 anchor，控件跑出窗口

```
tk.Label(root, text="右边").place(relx=1.0)
```

**`relx=1.0` 是父控件右边缘，控件锚点默认 `"nw"`（左上角）**，所以控件左上角在右边缘——整个控件跑到窗口外面去了，看不见。

**修复**：加 `anchor="ne"` 或 `"e"`，让控件的右边缘对齐到父控件右边缘。

## 翻车现场三：width/height 和 relwidth/relheight 混用混乱

**`width` 是像素、`relwidth` 是比例，两者都写时以 `width` 为准（如果都生效会有冲突）：**

```
label.place(relwidth=0.5, width=200)   # 实际以 width=200 为准
```

**别同时写，选一种方式用。**

## 翻车现场四：用 place 做表单，累死还错

```
tk.Label(root, text="姓名：").place(x=10, y=10)
tk.Entry(root).place(x=80, y=10, width=150)
tk.Label(root, text="年龄：").place(x=10, y=40)
tk.Entry(root).place(x=80, y=40, width=150)
```

**看着还行，但窗口一缩放就露馅，而且加个字段要改四个坐标。** 这种表单用 grid 三行代码搞定。

## place 的高级参数：bordermode

**`bordermode` 控制坐标是相对于父控件的"外部"还是"内部"：**

```
label.place(x=0, y=0, bordermode="outside")   # 包含父控件的边框
label.place(x=0, y=0, bordermode="inside")    # 不含边框（默认）
```

**绝大多数情况不用管它，默认就行。**

## 什么时候非用 place 不可

**三种场景：**

1. **叠加层/水印/浮层**（控件要叠在别的控件上面）
2. **画布类应用**（绘图、自定义控件、游戏界面）
3. **需要精确像素位置**（仪表盘、自定义仪表）

**除此之外，优先 grid。**

## 小结

- place 用 `x`/`y`/`width`/`height` 绝对定位，用 `relx`/`rely`/`relwidth`/`relheight` 相对定位
- `anchor` 决定控件的哪个点对齐到坐标，`"nw"` 默认
- 想随窗口缩放必须写 `rel*` 系列参数
- 不推荐 place 做常规布局：不随动、改一个动一串、对齐靠手算
- place 适合：叠加层、水印、画布类、像素级自定义
