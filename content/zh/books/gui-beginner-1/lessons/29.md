# 加上文件读写：把统计结果存下来

> 上一课我们把逻辑和界面分开了。这一课加两个功能：从文件读取文本（不用手动粘贴），把统计结果保存成文件。同时引入异常处理，让程序在出错时不会崩溃。

## 为什么需要文件读写

**目前我们的工具只能手动粘贴文本，结果也只能在窗口里看。** 两个痛点：

1. **要统计的文本在一个 txt 文件里**（比如一篇文章、一段日志），每次都要打开文件 → 全选 → 复制 → 粘贴，太麻烦。
2. **统计结果想留个存档**，或者发给别人看。窗口一关就没了。

**解决这两个痛点，就需要文件读写。**

## tkinter 的文件对话框

**tkinter 自带文件对话框模块 `tkinter.filedialog`，不用自己画窗口：**

```
from tkinter import filedialog

# 打开文件对话框（选择已有文件）
filepath = filedialog.askopenfilename(
    title="选择文件",
    filetypes=[("文本文件", "*.txt"), ("所有文件", "*.*")]
)

# 保存文件对话框（选择保存位置和文件名）
filepath = filedialog.asksaveasfilename(
    title="保存结果",
    defaultextension=".txt",
    filetypes=[("文本文件", "*.txt")]
)
```

**`askopenfilename` 和 `asksaveasfilename` 的区别：**

| 函数 | 用途 | 用户选了取消 |
|---|---|---|
| `askopenfilename` | 打开已有文件 | 返回空字符串 `""` |
| `asksaveasfilename` | 另存为新文件 | 返回空字符串 `""` |

**重点：用户点"取消"时返回 `""`，不是 `None`，也不是抛异常。** 这是个容易踩坑的细节。

## 从文件读取文本

**在界面上加一个"打开文件"按钮，点击后弹出对话框，选中文件后把内容读进输入框：**

```
def on_open():
    filepath = filedialog.askopenfilename(
        title="选择文本文件",
        filetypes=[("文本文件", "*.txt"), ("所有文件", "*.*")]
    )
    if not filepath:        # 用户取消了
        return

    with open(filepath, "r", encoding="utf-8") as f:
        content = f.read()

    text_input.delete("1.0", "end")
    text_input.insert("1.0", content)
```

**关键细节：`encoding="utf-8"`。** 如果不指定编码，Windows 上默认用 `gbk`，读一个 UTF-8 编码的文件就会报 `UnicodeDecodeError`。

**`with open(...) as f` 是 Python 的标准写法**，文件用完自动关闭，不需要手动 `f.close()`。

## 保存结果到文件

**"保存结果"按钮的回调：弹出另存为对话框，把统计结果写进文件。**

```
def on_save():
    # 先确保有结果可保存
    result_content = result_text.get("1.0", "end-1c")
    if not result_content.strip():
        status_label.configure(text="没有可保存的结果，请先统计")
        return

    filepath = filedialog.asksaveasfilename(
        title="保存统计结果",
        defaultextension=".txt",
        filetypes=[("文本文件", "*.txt")]
    )
    if not filepath:        # 用户取消了
        return

    with open(filepath, "w", encoding="utf-8") as f:
        f.write(result_content)

    status_label.configure(text=f"已保存到：{filepath}")
```

**`defaultextension=".txt"`** 的作用是：用户如果只输入了文件名没输后缀，自动补上 `.txt`。

**保存成功后给用户一个反馈**——用状态栏 Label 显示"已保存到：xxx"。用户需要知道操作成功了，否则会困惑"到底存没存上"。

## 异常处理：别让程序崩溃

**文件操作有太多可能出错的地方：**

- 文件不存在（`FileNotFoundError`）
- 编码不对，读不了（`UnicodeDecodeError`）
- 文件被其他程序占用（`PermissionError`）
- 磁盘满了写不进去（`OSError`）
- 路径太长（`OSError`）

**如果不处理，任何一个错误都会让整个程序崩溃退出。** 用户体验极差。

**用 try-except 兜住：**

```
def on_open():
    filepath = filedialog.askopenfilename(
        title="选择文本文件",
        filetypes=[("文本文件", "*.txt"), ("所有文件", "*.*")]
    )
    if not filepath:
        return

    try:
        with open(filepath, "r", encoding="utf-8") as f:
            content = f.read()
    except UnicodeDecodeError:
        status_label.configure(text="错误：文件编码不是 UTF-8，无法读取")
        return
    except FileNotFoundError:
        status_label.configure(text="错误：文件不存在")
        return
    except PermissionError:
        status_label.configure(text="错误：没有权限读取该文件")
        return
    except OSError as e:
        status_label.configure(text=f"错误：无法读取文件（{e}）")
        return

    # 读取成功才更新界面
    text_input.delete("1.0", "end")
    text_input.insert("1.0", content)
    status_label.configure(text=f"已加载：{filepath}")
```

**异常处理的原则：**

1. **try 块里只放可能出错的代码**，不要一大坨全包进去。
2. **except 精确捕获**，先写具体的异常（UnicodeDecodeError），最后用 OSError 兜底。
3. **出错了要告诉用户**，用状态栏或弹窗显示错误信息，而不是默默失败。
4. **出错后不要继续执行**后续逻辑（用 return 提前返回）。

## 加上状态栏

**状态栏是个好东西，它给用户反馈。** 我们的界面顶部加一个状态栏 Label：

```
status_label = ttk.Label(root, text="就绪", relief="sunken", anchor="w")
status_label.grid(row=3, column=0, sticky="ew", padx=5, pady=2)
```

**`relief="sunken"`** 让 Label 有个凹陷的边框，看起来像一条独立的状态栏。

**`anchor="w"`** 让文字左对齐（west）。

**`sticky="ew"`** 让它水平铺满。

**状态栏的更新时机：**

| 操作 | 状态栏提示 |
|---|---|
| 程序启动 | "就绪" |
| 打开文件成功 | "已加载：xxx.txt" |
| 打开文件失败 | "错误：xxx" |
| 统计完成 | "统计完成" |
| 保存成功 | "已保存到：xxx.txt" |
| 保存失败 | "错误：xxx" |

## 翻车现场一：忘了 encoding，Windows 上读 UTF-8 文件报错

```
with open(filepath, "r") as f:    # ← 没指定 encoding
    content = f.read()
```

**报错（Windows 上）：**

```
UnicodeDecodeError: 'gbk' codec can't decode byte 0x8f in position 2: illegal multibyte sequence
```

**原因**：Windows 默认编码是 `gbk`，读 UTF-8 文件时遇到非 ASCII 字符就炸。

**修复**：永远显式指定 `encoding="utf-8"`：

```
with open(filepath, "r", encoding="utf-8") as f:
    content = f.read()
```

**经验法则：文件读写一律显式指定编码，不要依赖默认值。** Windows 是 gbk，Linux/Mac 是 utf-8，跨平台代码必须写死。

## 翻车现场二：用户点取消，filepath 是空字符串，直接打开报错

```
filepath = filedialog.askopenfilename(...)
with open(filepath, "r", encoding="utf-8") as f:  # ← filepath 可能是 ""
    content = f.read()
```

**报错：**

```
FileNotFoundError: [Errno 2] No such file or directory: ''
```

**修复**：加个判断：

```
filepath = filedialog.askopenfilename(...)
if not filepath:      # ← 用户取消了
    return
with open(filepath, "r", encoding="utf-8") as f:
    content = f.read()
```

**这是 GUI 文件操作的固定套路，记住就行。**

## 翻车现场三：保存时 result_text 是 disabled 状态，get 也读不到

**症状**：保存的文件是空的，但界面上明明显示了统计结果。

**原因**：以为 `state="disabled"` 会让 `get()` 也失效。实际上——

**`get()` 不受 `state` 影响。** disabled 只阻止修改（insert/delete/键入），读取（get）始终可以。

**所以如果你的保存结果是空的，问题不在 disabled，而在别处。** 常见原因：

1. 还没点"开始统计"，result_text 是空的
2. 保存的是另一个 Text 控件
3. get 的范围写错了，比如写了 `"1.0", "1.0"`

**保存前先检查有没有内容：**

```
result_content = result_text.get("1.0", "end-1c")
if not result_content.strip():
    status_label.configure(text="没有可保存的结果，请先统计")
    return
```

## 翻车现场四：文件很大，一次性 read() 把内存撑爆

**症状**：选了一个 500MB 的日志文件，程序卡了几秒，然后内存飙升。

**原因**：`f.read()` 一次性把整个文件读进内存。500MB 的文本在 Python 里可能占 1GB 内存（Unicode 字符串更占空间）。

**解决方案（思路，本课不要求实现）：**

```
# 逐行读取，避免一次性加载
line_count = 0
char_count = 0
with open(filepath, "r", encoding="utf-8") as f:
    for line in f:
        line_count += 1
        char_count += len(line)
```

**`for line in f` 是逐行迭代**，每次只把一行加载到内存，500MB 的文件也能处理。

**第 30 课会讲"大文件"的完整处理方案**，包括进度反馈和多线程。

## 完整代码：加上文件读写和异常处理

```
import tkinter as tk
from tkinter import ttk, filedialog
from collections import Counter

# ==================== 业务逻辑层 ====================

def count_chars(text: str) -> int:
    return len(text)

def count_lines(text: str) -> int:
    if not text.strip():
        return 0
    return len(text.split("\n"))

def count_word_freq(text: str, top_n: int = 5) -> list:
    chars = [c for c in text if c.strip()]
    if not chars:
        return []
    return Counter(chars).most_common(top_n)

def format_result(chars: int, lines: int, freq: list) -> str:
    parts = [f"总字符数：{chars}", f"总行数：{lines}", f"词频 Top {len(freq)}："]
    for char, count in freq:
        parts.append(f"  「{char}」：{count} 次")
    return "\n".join(parts)

# ==================== 界面层 ====================

def create_app():
    root = tk.Tk()
    root.title("文本统计工具")
    root.geometry("600x550")

    # ---- 输入区 ----
    input_frame = ttk.LabelFrame(root, text="输入区")
    input_frame.grid(row=0, column=0, padx=10, pady=5, sticky="ew")

    text_input = tk.Text(input_frame, height=10, wrap="word")
    text_input.grid(row=0, column=0, sticky="ew", padx=5, pady=5)

    # ---- 按钮区 ----
    button_frame = ttk.LabelFrame(root, text="操作区")
    button_frame.grid(row=1, column=0, padx=10, pady=5, sticky="ew")

    def on_open():
        filepath = filedialog.askopenfilename(
            title="选择文本文件",
            filetypes=[("文本文件", "*.txt"), ("所有文件", "*.*")]
        )
        if not filepath:
            return
        try:
            with open(filepath, "r", encoding="utf-8") as f:
                content = f.read()
        except UnicodeDecodeError:
            status_label.configure(text="错误：文件编码不是 UTF-8")
            return
        except OSError as e:
            status_label.configure(text=f"错误：无法读取（{e}）")
            return

        text_input.delete("1.0", "end")
        text_input.insert("1.0", content)
        status_label.configure(text=f"已加载：{filepath}")

    def on_count():
        text = text_input.get("1.0", "end-1c")
        if not text.strip():
            status_label.configure(text="输入为空，无法统计")
            return

        chars = count_chars(text)
        lines = count_lines(text)
        freq = count_word_freq(text, top_n=5)
        result = format_result(chars, lines, freq)

        result_text.configure(state="normal")
        result_text.delete("1.0", "end")
        result_text.insert("1.0", result)
        result_text.configure(state="disabled")
        status_label.configure(text="统计完成")

    def on_save():
        result_content = result_text.get("1.0", "end-1c")
        if not result_content.strip():
            status_label.configure(text="没有可保存的结果，请先统计")
            return

        filepath = filedialog.asksaveasfilename(
            title="保存统计结果",
            defaultextension=".txt",
            filetypes=[("文本文件", "*.txt")]
        )
        if not filepath:
            return

        try:
            with open(filepath, "w", encoding="utf-8") as f:
                f.write(result_content)
        except OSError as e:
            status_label.configure(text=f"错误：无法保存（{e}）")
            return

        status_label.configure(text=f"已保存到：{filepath}")

    ttk.Button(button_frame, text="打开文件", command=on_open).grid(row=0, column=0, padx=5, pady=5)
    ttk.Button(button_frame, text="开始统计", command=on_count).grid(row=0, column=1, padx=5, pady=5)
    ttk.Button(button_frame, text="保存结果", command=on_save).grid(row=0, column=2, padx=5, pady=5)

    # ---- 结果区 ----
    result_frame = ttk.LabelFrame(root, text="统计结果")
    result_frame.grid(row=2, column=0, padx=10, pady=5, sticky="ew")

    result_text = tk.Text(result_frame, height=8, wrap="word", state="disabled")
    result_text.grid(row=0, column=0, sticky="ew", padx=5, pady=5)

    # ---- 状态栏 ----
    status_label = ttk.Label(root, text="就绪", relief="sunken", anchor="w")
    status_label.grid(row=3, column=0, sticky="ew", padx=5, pady=2)

    # 可拉伸
    root.columnconfigure(0, weight=1)
    input_frame.columnconfigure(0, weight=1)
    result_frame.columnconfigure(0, weight=1)

    return root

if __name__ == "__main__":
    app = create_app()
    app.mainloop()
```

## 小结

- **`filedialog.askopenfilename`** 打开文件，**`asksaveasfilename`** 保存文件
- **用户取消返回 `""`**（不是 None），一定要判断 `if not filepath: return`
- **文件读写一律指定 `encoding="utf-8"`**，别依赖平台默认值
- **`with open(...) as f`** 自动关闭文件，是标准写法
- **try-except 兜住文件异常**：UnicodeDecodeError、FileNotFoundError、PermissionError、OSError
- **disabled 的 Text 不影响 get()**，只阻止修改
- **大文件用逐行迭代** `for line in f`，别一次性 read()
- **状态栏给用户反馈**，每一步操作都要有提示
