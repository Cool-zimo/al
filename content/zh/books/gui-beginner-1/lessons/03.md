# 窗口的属性

> 一个光秃秃的灰窗口太丑了。这一节讲怎么打扮它：标题、大小、能不能改大小、最小尺寸、图标，以及最常用的"窗口居中"技巧。

## 标题：title()

**`title()` 管标题栏文字。** 不设置的话会显示默认名字（Windows 上常是 "tk"）。

```
import tkinter as tk

root = tk.Tk()
root.title("记账本 1.0")
root.mainloop()
```

**标题栏是用户第一眼看到的东西，务必写清楚你的程序是干什么的。** 别留默认的 "tk"。

## 大小与位置：geometry()

**`geometry()` 用一个字符串同时设宽度、高度和位置：**

```
root.geometry("400x300")        # 宽400 高300，位置由系统定
root.geometry("400x300+100+50") # 宽400 高300，左上角在屏幕(100, 50)
```

**格式是 `宽x高+X+Y`，注意是字母 `x` 不是乘号 `*`。** 这是新手最常写错的地方：

```
root.geometry("400*300")   # 报错：bad geometry specifier
root.geometry("400×300")   # 报错：用了全角乘号
root.geometry("400x300")   # 正确
```

**读取当前值：**

```
print(root.geometry())   # 如 '400x300+100+50'
```

**把 geometry 拆开读也很方便：**

```
geo = root.geometry()        # '400x300+100+50'
w, h = geo.split('+')[0].split('x')   # w='400', h='300'
print(w, h)                 # 400 300
```

**这里有个小知识点值得记住**：字符串 `'400x300+100+50'` 里，`+` 前面的 `400x300` 是尺寸，`+100+50` 是位置。用 `split('+')` 会得到 `['400x300', '100', '50']`。

## 能不能改大小：resizable()

**`resizable(w, h)` 控制用户能不能拖动改变窗口大小。** 两个布尔值，分别对应宽度和高度。

```
root.resizable(True, True)   # 默认：宽高都能改
root.resizable(False, False) # 宽高都锁死，变成固定窗口
root.resizable(True, False)  # 宽能改、高不能改
```

**什么场景要锁死？** 工具类小程序（比如一个单位换算器），界面布局固定，放大反而留白难看，就该锁死。

```
import tkinter as tk

root = tk.Tk()
root.title("固定窗口")
root.geometry("300x200")
root.resizable(False, False)   # 用户拖不动边框
root.mainloop()
```

**锁死的同时，系统通常会把"最大化"按钮也置灰。**

## 最小尺寸：minsize() 与最大尺寸：maxsize()

**`minsize(w, h)` 和 `maxsize(w, h)` 给窗口设一个可拖动的区间。**

```
root.minsize(300, 200)   # 不能再小了
root.maxsize(800, 600)   # 不能再大了
```

**这两个方法和 `resizable` 的区别**：`resizable(False, False)` 是彻底锁死（拉都拉不动），`minsize/maxsize` 是给一个范围（还能在范围内自由拖）。

**实战用法**：设一个 `minsize` 防止用户把窗口缩到控件挤成一团，这是好习惯。

```
root.minsize(400, 300)   # 再小就难看了，干脆禁止
```

**注意**：`maxsize` 单独用容易踩坑——如果用户屏幕本身就比 `maxsize` 小，窗口可能显示不全。一般只用 `minsize`。

## 图标：iconphoto() 与 iconbitmap()

**图标是标题栏左上角那个小图。** 有两种做法：

```
# 方式一：iconphoto，跨平台，用 PNG
root.iconphoto(False, tk.PhotoImage(file="icon.png"))

# 方式二：iconbitmap，Windows 专用，用 .ico
root.iconbitmap("icon.ico")
```

| 方法 | 平台 | 图片格式 |
|---|---|---|
| `iconphoto()` | 跨平台 | PNG/GIF/PPM |
| `iconbitmap()` | 主要 Windows | ICO |

**`iconphoto` 的第一个参数是 `True` 或 `False`**：`True` 表示给所有未来创建的 Toplevel 窗口也用这个图标，`False` 只给当前根窗口用。一般写 `False` 即可。

**翻车现场**：图片路径写错了会报错，或者干脆不显示图标但不报错（最烦）。

```
root.iconphoto(False, tk.PhotoImage(file="没这个文件.png"))
# 报错：_tkinter.TclError: couldn't open "没这个文件.png"
```

**用绝对路径或确认工作目录**：图标文件要跟脚本放在同一目录，或者用绝对路径 `C:/.../icon.png`。建议用 `os.path` 拼路径，避免出错：

```
import os
icon_path = os.path.join(os.path.dirname(__file__), "icon.png")
if os.path.exists(icon_path):
    root.iconphoto(False, tk.PhotoImage(file=icon_path))
```

**现在 macOS 和多数 Linux 桌面环境已经不显示传统图标了，但写上无害，Windows 上仍然有效。**

## 窗口居中：一个超实用技巧

**程序启动时窗口常常出现在屏幕左上角，很丑。** 自己算居中坐标：

```
import tkinter as tk

root = tk.Tk()
root.title("居中窗口")
root.geometry("400x300")

# 屏幕尺寸
screen_w = root.winfo_screenwidth()
screen_h = root.winfo_screenheight()

# 窗口尺寸
win_w, win_h = 400, 300

# 居中坐标
x = (screen_w - win_w) // 2
y = (screen_h - win_h) // 2

root.geometry(f"400x300+{x}+{y}")
root.mainloop()
```

**核心公式就一句：`x = (屏幕宽 - 窗口宽) // 2`。** 先减后整除，得到左上角该在的坐标。

**翻车现场：先居中再改尺寸，白算了。** 如果你后面又 `root.geometry("600x400")` 改了尺寸，之前算好的居中就作废了。正确做法是：所有 `geometry` 相关的设置集中在一段里写完。

## 其他常用属性一览

| 属性/方法 | 作用 |
|---|---|
| `root.title("...")` | 标题栏文字 |
| `root.geometry("WxH+X+Y")` | 尺寸与位置 |
| `root.resizable(w, h)` | 能否拖动改大小 |
| `root.minsize(w, h)` | 最小尺寸 |
| `root.maxsize(w, h)` | 最大尺寸 |
| `root.iconphoto(False, img)` | 设置图标 |
| `root.configure(bg="颜色")` | 背景色 |
| `root.attributes("-topmost", True)` | 窗口置顶 |
| `root.attributes("-alpha", 0.8)` | 透明度（0~1） |
| `root.state("zoomed")` | 启动时最大化（Windows） |
| `root.overrideredirect(True)` | 去掉标题栏（无边框窗口） |
| `root.destroy()` | 销毁窗口、退出程序 |
| `root.quit()` | 退出 mainloop（窗口仍在） |

**`destroy()` 和 `quit()` 的区别值得记**：`destroy()` 把窗口销毁，程序彻底结束；`quit()` 只是跳出 mainloop，窗口还在内存里。一般关闭程序用 `root.destroy()`，或者让系统默认行为处理。

## 背景色与全屏

**`configure` 是最通用的"改属性"方法：**

```
root.configure(bg="#f0f0f0")        # 浅灰背景
root.configure(cursor="watch")      # 改鼠标光标样式（"arrow"/"watch"/"cross"）
```

**`attributes` 能改很多"窗口级别"的属性，参数很多，这里列两个实用的：**

```
root.attributes("-topmost", True)   # 窗口永远在最前面
root.attributes("-alpha", 0.8)      # 半透明
```

**透明窗口做浮窗小工具很好用。** 注意 `alpha` 范围 0.0（全透明）到 1.0（不透明）。

## 翻车现场一：geometry 用乘号

```
root.geometry("400*300")   # TclError: bad geometry specifier
```

**只能用字母 `x`。** 这是因为 geometry 字符串是 Tcl/Tk 的老格式，沿用至今。

## 翻车现场二：resizable 参数顺序搞反

```
root.resizable(False, True)   # 你以为"不能改宽、能改高"
# 实际上是：宽=False，高=True
```

**顺序就是 `(宽, 高)`，别想太多。** 想两个都锁死就 `resizable(False, False)`。

## 翻车现场三：设置图标但忘了 PhotoImage 引用

```
root.iconphoto(False, tk.PhotoImage(file="icon.png"))
# 某些情况下图标不显示
```

**虽然 `iconphoto` 内部会保持引用，但在复杂程序里图片对象被垃圾回收会导致图标消失。** 稳妥做法是把图片存进变量：`icon = tk.PhotoImage(file="icon.png"); root.iconphoto(False, icon)`。

## 翻车现场四：单位搞混

**tkinter 里所有尺寸都是像素，没有厘米、没有英寸。** `geometry("400x300")` 就是 400 像素宽、300 像素高。做跨平台时要留意：高 DPI 屏上同样像素会显得小。

## 小结

- `title()` 设标题；`geometry("WxH+X+Y")` 设尺寸位置，用字母 `x`
- `resizable()` 锁死大小；`minsize()` 给一个下限，一般只用 `minsize`
- 图标用 `iconphoto()`（跨平台 PNG）或 `iconbitmap()`（Windows ICO）
- **居中公式**：`x = (屏幕宽 - 窗口宽) // 2`
- `configure()` 改背景色等；`attributes()` 改置顶、透明度等窗口属性
- `destroy()` 销毁窗口，`quit()` 只跳出循环
