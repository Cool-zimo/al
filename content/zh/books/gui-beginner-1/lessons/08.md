# grid：行列、rowspan/colspan、sticky

> grid 是 tkinter 最常用、最灵活的布局管理器。这一节把它讲透：行和列、跨行跨列、sticky 贴边、边距。学会 grid，80% 的界面你都能做。

## grid 的基本思路

**grid 把父控件想象成一张表格。** 每个控件用 `row`（行）和 `column`（列）指定它占哪个格子，行列从 0 开始。

```
import tkinter as tk

root = tk.Tk()
tk.Label(root, text="姓名").grid(row=0, column=0)
tk.Entry(root).grid(row=0, column=1)
tk.Label(root, text="年龄").grid(row=1, column=0)
tk.Entry(root).grid(row=1, column=1)
root.mainloop()
```

**结果是一个整齐的两行两列表单。** 标签在左列，输入框在右列，两列上下对齐。

**这就是 grid 的核心价值：对齐。** pack 做不到的列对齐，grid 天生支持。

## row / column 不必连续

**你可以跳着用行号、列号，不一定要 0、1、2 连续：**

```
tk.Label(root, text="跳过").grid(row=0, column=0)
tk.Label(root, text="第5行").grid(row=5, column=0)   # 中间 1-4 行留空
```

**留空的行会占用空间（高度很小，但确实存在）。** 实际写界面时一般按顺序排，跳号主要用于"预留区域"。

## rowspan / columnspan：跨行跨列

**一个控件可以占多个格子。**

**`columnspan=2` 表示横向占两列：**

```
tk.Label(root, text="标题").grid(row=0, column=0, columnspan=2)
tk.Label(root, text="姓名").grid(row=1, column=0)
tk.Entry(root).grid(row=1, column=1)
```

**"标题"横跨两列，看起来像表头。**

**`rowspan` 表示纵向跨行：**

```
tk.Label(root, text="侧栏", width=8, bg="lightyellow").grid(row=0, column=0, rowspan=3)
tk.Label(root, text="内容1").grid(row=0, column=1)
tk.Label(root, text="内容2").grid(row=1, column=1)
tk.Label(root, text="内容3").grid(row=2, column=1)
```

**"侧栏"纵跨 3 行，像一个侧边栏。**

## sticky：贴格子的哪边

**`sticky` 决定控件在它的格子里朝哪个方向贴、是否撑满。**

| 值 | 效果 |
|---|---|
| `""`（默认） | 居中，保持自然尺寸 |
| `"w"` | 左贴 |
| `"e"` | 右贴 |
| `"n"` | 上贴 |
| `"s"` | 下贴 |
| `"ew"` | 左右撑满（横向） |
| `"ns"` | 上下撑满（纵向） |
| `"nsew"` | 四个方向都撑满 |

```
tk.Label(root, text="左贴", bg="red").grid(row=0, column=0, sticky="w")
tk.Label(root, text="右贴", bg="green").grid(row=0, column=1, sticky="e")
tk.Label(root, text="撑满", bg="blue").grid(row=1, column=0, columnspan=2, sticky="ew")
```

**stricky 是最容易被低估的参数。** 默认居中的 Label，在格子变大时会缩在中间显得很怪；加了 `sticky="w"` 就左对齐、`sticky="ew"` 就横向撑满。

## padx / pady：格子里的外边距

**和 pack 一样，grid 也支持 `padx`/`pady`：**

```
tk.Label(root, text="带边距").grid(row=0, column=0, padx=10, pady=5)
```

**`padx=(左, 右)` 和 `pady=(上, 下)` 也支持。**

**做表单时，标签右边留点边距、上下留点行距，看起来就舒服多了：**

```
tk.Label(root, text="姓名：").grid(row=0, column=0, sticky="e", padx=5, pady=5)
tk.Entry(root).grid(row=0, column=1, padx=5, pady=5)
tk.Label(root, text="年龄：").grid(row=1, column=0, sticky="e", padx=5, pady=5)
tk.Entry(root).grid(row=1, column=1, padx=5, pady=5)
```

## 一个完整的计算器界面

**grid 做计算器键盘最合适——天然网格：**

```
import tkinter as tk

root = tk.Tk()
root.title("计算器")

# 显示区
tk.Entry(root, justify="right", font=("Arial", 20)).grid(row=0, column=0, columnspan=4, sticky="ew", padx=5, pady=5)

# 按钮
buttons = [
    "7", "8", "9", "/",
    "4", "5", "6", "*",
    "1", "2", "3", "-",
    "0", ".", "=", "+",
]
row, col = 1, 0
for b in buttons:
    tk.Button(root, text=b, width=5, height=2).grid(row=row, column=col, padx=2, pady=2)
    col += 1
    if col > 3:
        col = 0
        row += 1

root.mainloop()
```

**4 列按钮排成矩阵，显示区用 `columnspan=4` 横跨全部列。** 这就是 grid 的强项。

## 翻车现场一：格子没被"撑开"

```
tk.Label(root, text="很长的文字内容").grid(row=0, column=0)
tk.Entry(root).grid(row=0, column=1)
```

**窗口很宽，但 Label 缩在中间、Entry 也缩在中间，两边大片空白。** 因为它们没被要求撑满。

**修复**：给控件加 `sticky="ew"`。但这还不够——还得告诉 grid "这一列应该随窗口变大"，这就要用到 `columnconfigure`（下一课讲）。

## 翻车现场二：column 超出忘了检查

**用循环生成 grid 控件时，`column` 写错会导致控件跑到意料之外：**

```
for i, t in enumerate(["A", "B", "C", "D", "E"]):
    tk.Label(root, text=t).grid(row=0, column=i)
```

**5 个标签挤在第 0 行、列 0~4。** 如果你想"每 3 个换一行"：

```
for i, t in enumerate(["A","B","C","D","E","F"]):
    tk.Label(root, text=t).grid(row=i//3, column=i%3)
```

**`i//3` 是行号，`i%3` 是列号（0~2）。** 这是一个常用技巧。

## 翻车现场三：rowspan 后行列错位

**跨行/跨列时，被"压住"的格子不能再放控件：**

```
label = tk.Label(root, text="侧栏")
label.grid(row=0, column=0, rowspan=2)   # 占了 (0,0) 和 (1,0)

tk.Label(root, text="误放").grid(row=1, column=0)   # (1,0) 已被占！
```

**症状**：控件显示错乱、重叠，或报 `cannot place child, slave is already managed`。

**修复**：被 rowspan/columnspan 占掉的格子，不要再单独 grid 控件进去。

## 翻车现场四：grid 和 pack 混用

**同一父控件上既 grid 又 pack 直接报错**（第 6 课讲过）。记住：**一个父控件一个管理器。**

## ipadx / ipady 与 grid

**grid 也支持内边距：**

```
tk.Button(root, text="大按钮").grid(row=0, column=0, ipadx=10, ipady=5)
```

**控件本身变大**——适合做"强调"按钮。

## 小技巧：grid 的 `in_` 参数

**`in_` 可以指定父控件（少用但有用）：**

```
frame = tk.Frame(root)
frame.pack()
tk.Label(in_=frame, text="我在 frame 里").grid()   # 不写 in_ 默认是 root
```

**一般不用 `in_`，直接把父控件写成第一个参数更清楚：**

```
tk.Label(frame, text="我在 frame 里").grid()
```

## grid 万能公式

**做表单的标准模板，记住这个就够：**

```
# 标签右对齐 + 输入框撑满
tk.Label(root, text="字段名：").grid(row=N, column=0, sticky="e", padx=5, pady=5)
tk.Entry(root).grid(row=N, column=1, sticky="ew", padx=5, pady=5)

# 按钮横跨整行
tk.Button(root, text="提交").grid(row=LAST, column=0, columnspan=2, sticky="ew", pady=10)
```

**标签 `sticky="e"` 右对齐、输入框 `sticky="ew"` 撑满、按钮 `columnspan` 跨列——三个套路记住就能排版出大多数表单。**

## 小结

- grid 把父控件当表格，`row`/`column` 指定格子（从 0 开始）
- `rowspan`/`columnspan` 跨行跨列，做侧栏、表头、跨列按钮
- `sticky` 控制贴哪边：`"w"` 左、`"ew"` 横向撑满、`"nsew"` 全撑满
- `padx`/`pady` 边距让表单好看
- 循环生成网格用 `row=i//cols, column=i%cols`
- 同一父控件只能用一个布局管理器
