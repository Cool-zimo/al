# 只问一个值：`simpledialog`

> 有时候你并不需要一整个表单，只想让用户打个名字、输个数字，或者填个密码。`tkinter.simpledialog` 是最快的办法：弹一个单输入框，直接拿回一个值。

## 三个函数

**`askstring`、`askinteger`、`askfloat` 各自弹一个小对话框，带一句提示和一个输入框；差别只在返回给你的类型。**

| 函数 | 返回 |
|---|---|
| `askstring(title, prompt)` | `str`，取消则返回 `None` |
| `askinteger(title, prompt, ...)` | `int`，取消则返回 `None` |
| `askfloat(title, prompt, ...)` | `float`，取消则返回 `None` |

```
import tkinter as tk
from tkinter import simpledialog

root = tk.Tk()

name = simpledialog.askstring("名字", "你叫什么名字？")
print(repr(name))

root.mainloop()
```

**打个名字、点确定，`name` 就是那个字符串。点取消或 X，它就是 `None`。** 这个 `None` 是它跟普通 Entry 控件最大的不同——你不用自己接线按钮、再读 `.get()`，对话框自己搞定并把答案直接返回。

## 安全地读取数字

**`askinteger` 和 `askfloat` 自带校验：填非数字根本没法确认。**

```
import tkinter as tk
from tkinter import simpledialog

root = tk.Tk()

def get_age():
    age = simpledialog.askinteger("年龄", "你多大了？", minvalue=0, maxvalue=150)
    if age is None:
        print("取消了")
    else:
        print(f"你今年 {age} 岁")

tk.Button(root, text="输入年龄").pack(command=get_age)

root.mainloop()
```

**`minvalue` 和 `maxvalue` 会把范围外的输入挡掉，并让对话框保持打开，直到用户改正。** 这种情况你不用写 `try/except`，对话框自己处理了。其他常用的关键字参数有 `initialvalue`（预填字段）和 `parent`（把对话框钉在你的窗口上）。

## 翻车现场一：拿可能为 None 的结果跟数字比

```
count = simpledialog.askinteger("数量", "要几个？")
if count > 0:           # WRONG: 用户取消时 TypeError (None > 0)
    print("正数")
```

**用户取消时 `count` 是 `None`，`None > 0` 会抛 `TypeError`。** 修法跟别处一样：先判断 `None`，再做比较。

```
count = simpledialog.askinteger("数量", "要几个？")
if count is None:
    return
if count > 0:
    print("正数")
```

## 翻车现场二：某些系统上忘了 `parent=`

```
simpledialog.askstring("名字", "你的名字？")   # 看着没问题……有时候
```

**不带 `parent`，对话框在 macOS 和某些 Linux 环境上会跑到主窗口背后**，用户搞不清为什么程序卡住了。传 `parent=root`，它就贴在上面并居中。

```
simpledialog.askstring("名字", "你的名字？", parent=root)
```

## 用返回值更新控件

**常见套路是：在按钮回调里弹对话框，然后立刻把答案塞进 Label 或 Entry。**

```
import tkinter as tk
from tkinter import simpledialog

root = tk.Tk()

label = tk.Label(root, text="(还没名字)")
label.pack()

def rename():
    name = simpledialog.askstring("改名", "新的标签文字：", parent=root)
    if name:
        label.configure(text=name)

tk.Button(root, text="改名").pack(command=rename)

root.mainloop()
```

**注意这个真值判断 `if name:`——它同时处理了 `None`（取消）和空字符串（用户什么都没填就点了确定）。** 如果你更愿意把"空字符串"当作一个正经答案，就用 `is None` 显式判断。

## 问密码

**`simpledialog` 能让输入打码，但真正的密码提示在较新版本里 `tkinter` 有单独的助手——而用带 `show="*"` 的 Entry 手动写一个，是跨版本通用的兜底方案。**

```
import tkinter as tk

root = tk.Tk()

entry = tk.Entry(root, show="*")
entry.pack()

def reveal():
    print(entry.get())

tk.Button(root, text="提交").pack(command=reveal)

root.mainloop()
```

**`show="*"` 会把屏幕上打出的每个字符都换成星号，而真正的字符串还好好待在控件里。** 这个套路要记住：`simpledialog` 图的是方便，但主界面里要放密码框，就该用带 `show=` 的 Entry。

## 翻车现场三：对话框必须被回调触发

```
import tkinter as tk
from tkinter import simpledialog

root = tk.Tk()
name = simpledialog.askstring("名字", "名字？")   # WRONG: 启动时立刻弹出
root.mainloop()
```

**如果你在模块级调用 `askstring`，它会在主窗口出现之前就弹出来，把启动过程卡住。** 一定要把调用放进某个 Button 或菜单命令触发的函数里。这条规则同样适用于 `messagebox` 和 `filedialog`。

## 综合示例：迷你设置面板

**几个对话框就能顶替一整个设置窗口，只要这些值足够简单。**

```
import tkinter as tk
from tkinter import simpledialog, messagebox

root = tk.Tk()
root.title("设置")

config = {"title": "我的程序", "width": 400}

def set_title():
    new = simpledialog.askstring("标题", "窗口标题：", initialvalue=config["title"], parent=root)
    if new:
        config["title"] = new
        root.title(new)

def set_width():
    w = simpledialog.askinteger("宽度", "窗口宽度：", initialvalue=config["width"],
                                minvalue=100, maxvalue=2000, parent=root)
    if w:
        config["width"] = w
        messagebox.showinfo("已更新", f"宽度设为 {w}")

tk.Button(root, text="改标题").pack(fill="x", command=set_title)
tk.Button(root, text="改宽度").pack(fill="x", command=set_width)

root.mainloop()
```

**`initialvalue` 用当前设置预填字段，让用户去改而不是重新打一遍。** 结果写进一个普通字典里——数据跟控件分开，这就是第 28 课的主题。

## 小结

- `askstring`、`askinteger`、`askfloat` 返回输入的值，取消则返回 `None`
- 用之前一定判断 `is None`（或用真值判断）
- `minvalue`/`maxvalue` 帮你校验数字；`initialvalue` 预填字段
- 传 `parent=root`，对话框才会贴在上面
- 绝不在模块级调用对话框——只在回调里调
- 主界面里要密码框，用 `Entry(show="*")`
