# Listbox 与 Scrollbar

> 选项一多，按钮就不够用了。这一节讲 Listbox（列表框）和 Scrollbar（滚动条）：怎么加选项、怎么读选中项、怎么把滚动条绑上去。

## Listbox：选项列表

**Listbox 显示一个可滚动的列表，用户能单选或多选：**

```
import tkinter as tk

root = tk.Tk()
root.title("列表框")

lb = tk.Listbox(root)
lb.pack(padx=10, pady=10)

for city in ["北京", "上海", "广州", "深圳", "杭州"]:
    lb.insert("end", city)

root.mainloop()
```

**`insert(index, item)` 添加选项。** `"end"` 表示追加到末尾。

**常用参数：**

| 参数 | 作用 |
|---|---|
| `selectmode` | `"browse"`(单选，默认) / `"single"` / `"multiple"` / `"extended"`(可多选) |
| `height` | 可见行数 |
| `width` | 宽度（字符数） |
| `fg` / `bg` / `selectbackground` / `selectforeground` | 颜色 |

## 读选中项

**`curselection()` 返回当前选中项的索引元组（从 0 开始）：**

```
def show():
    sel = lb.curselection()
    if sel:
        idx = sel[0]
        print("选中：", lb.get(idx))
    else:
        print("没选中")

tk.Button(root, text="显示", command=show).pack()
```

**多选模式下 `curselection()` 返回多个索引：**

```
lb = tk.Listbox(root, selectmode="extended")
# 用户 Ctrl+点击多选
sel = lb.curselection()   # (0, 2, 4)
for idx in sel:
    print(lb.get(idx))
```

## 增删改

| 方法 | 作用 |
|---|---|
| `insert(idx, *items)` | 在 idx 位置插入（"end"=末尾） |
| `delete(first, last=None)` | 删除一项或一段 |
| `get(first, last=None)` | 读一项或一段 |
| `size()` | 选项总数 |
| `curselection()` | 选中项索引元组 |
| `selection_set(first, last=None)` | 代码选中某些项 |
| `selection_clear(first, last=None)` | 取消选中 |
| `activate(idx)` | 激活某项（高亮） |

## 代码选中 / 取消选中

```
lb.selection_set(0)          # 选中第 1 项
lb.selection_set(0, "end")   # 全选
lb.selection_clear(0, "end") # 全不选
lb.activate(2)               # 激活第 3 项
```

**`select_set` 和 `select_clear` 是 Listbox 独有的"选中"方法**（不是 `select`）。

## Scrollbar：滚动条

**Listbox 选项多了需要滚动条。** 关键是如何把滚动条和列表"双向绑定"：

```
import tkinter as tk

root = tk.Tk()

scrollbar = tk.Scrollbar(root)
scrollbar.pack(side="right", fill="y")

lb = tk.Listbox(root, yscrollcommand=scrollbar.set)
lb.pack(side="left", fill="both", expand=True)

for i in range(50):
    lb.insert("end", f"第 {i} 行")

scrollbar.config(command=lb.yview)

root.mainloop()
```

**绑定是双向的：**

1. `yscrollcommand=scrollbar.set`：列表滚动时，通知滚动条更新滑块位置
2. `scrollbar.config(command=lb.yview)`：拖滚动条时，通知列表滚动

**两条线都要写，少一条就"单边失灵"。**

## 翻车现场一：只写了一条绑定

```
scrollbar.config(command=lb.yview)
# 漏了 yscrollcommand=scrollbar.set
```

**症状**：拖滚动条能滚列表，但用鼠标滚轮滚列表时滚动条滑块不动。看起来是坏的。

## 翻车现场二：把 Scrollbar 当成 Listbox 的布局子控件

**Scrollbar 和 Listbox 是**兄弟**关系，都是 root 的子控件，各自 pack/grid：**

```
# 正确：scrollbar 和 lb 是兄弟
scrollbar.pack(side="right", fill="y")
lb.pack(side="left", fill="both", expand=True)

# 错误：把 scrollbar 当成 lb 的子控件
lb = tk.Listbox(root)
lb.pack()
tk.Scrollbar(lb).pack()   # 错！scrollbar 的父控件应该是 root（或同级容器）
```

## 横向滚动条

**`xscrollcommand` + `xview` 管横向滚动：**

```
h_sb = tk.Scrollbar(root, orient="horizontal")
h_sb.pack(side="bottom", fill="x")

lb = tk.Listbox(root, xscrollcommand=h_sb.set)
lb.pack(side="bottom", fill="x")

h_sb.config(command=lb.xview)
```

**Listbox 横向滚动需要设置 `width` 且内容超长才体现。** 横向滚动更常用于 Text 和 Canvas。

## Listbox 的多选模式

```
# 单选（默认）
lb = tk.Listbox(root, selectmode="browse")

# 可连续选（Shift+点击、拖动）
lb = tk.Listbox(root, selectmode="extended")

# 可多选（Ctrl+点击）
lb = tk.Listbox(root, selectmode="multiple")

# 严格单选（不能取消已选）
lb = tk.Listbox(root, selectmode="single")
```

**`"extended"` 是最常用的多选方式**——用户能 Shift 连选、Ctrl 跳选。

## Listbox 事件：双击 / 选中即响应

**绑定双击事件，用户双击就触发：**

```
def on_double(event):
    sel = lb.curselection()
    if sel:
        print("双击了：", lb.get(sel[0]))

lb.bind("<Double-1>", on_double)
```

**bind 的用法第 18 课会细讲，这里先看结论。**

**选中即响应（不用按钮）：**

```
def on_select(event):
    sel = lb.curselection()
    if sel:
        label.configure(text=lb.get(sel[0]))

lb.bind("<<ListboxSelect>>", on_select)
```

**`<<ListboxSelect>>` 是 Listbox 的虚拟事件**，选中变化就触发。

## 翻车现场三：curselection 返回空元组

```
sel = lb.curselection()
print(lb.get(sel[0]))   # IndexError 如果没选中
```

**没选中时 `curselection()` 返回空元组 `()`，`sel[0]` 会报 IndexError。** 务必先判断：

```
sel = lb.curselection()
if sel:
    print(lb.get(sel[0]))
else:
    print("请先选中一项")
```

## 翻车现场四：insert 和 delete 的索引

```
lb.insert(0, "新项")     # 插到第 1 个位置，原有项后移
lb.delete(0)             # 删除第 1 项
lb.delete(0, "end")      # 清空全部
```

**`insert(0, ...)` 插到最前面。** 清空用 `delete(0, "end")`，记住这个。

## 实战：一个可增删的列表

```
import tkinter as tk

root = tk.Tk()
root.title("待办清单")

entry = tk.Entry(root)
entry.pack(padx=10, pady=5)

lb = tk.Listbox(root)
lb.pack(padx=10, fill="both", expand=True)

scrollbar = tk.Scrollbar(root, command=lb.yview)
scrollbar.pack(side="right", fill="y")
lb.config(yscrollcommand=scrollbar.set)

def add():
    t = entry.get().strip()
    if t:
        lb.insert("end", t)
        entry.delete(0, "end")

def remove():
    sel = lb.curselection()
    if sel:
        lb.delete(sel[0])

tk.Button(root, text="添加", command=add).pack(side="left", padx=10)
tk.Button(root, text="删除选中", command=remove).pack(side="left")

root.mainloop()
```

**输入文字点"添加"就进列表，选中一项点"删除选中"就删掉。** 一个迷你待办应用。

## 小结

- Listbox 显示选项列表，`insert("end", item)` 追加
- `curselection()` 返回选中索引元组，**空元组要先判断**
- `selectmode` 控制单选/多选：`browse`/`extended`/`multiple`
- Scrollbar 绑定**双向**：`yscrollcommand=sb.set` + `sb.config(command=lb.yview)`
- Scrollbar 和 Listbox 是**兄弟**控件，各自布局
- `<<ListboxSelect>>` 虚拟事件可监听选中变化
