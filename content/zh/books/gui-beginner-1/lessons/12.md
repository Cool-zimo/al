# Text 多行文本：insert / get / delete

> Entry 只能输入一行，写编辑器、聊天框、日志区必须用 Text。这一节讲 Text 控件：多行编辑、索引 `"1.0"`、增删改查、禁用与只读。

## Text 是什么

**Text 是多行文本编辑控件**——记事本那个大输入框就是它。

```
import tkinter as tk

root = tk.Tk()
root.title("多行文本")

text = tk.Text(root, width=40, height=10)
text.pack(padx=10, pady=10)

root.mainloop()
```

**常用参数：**

| 参数 | 作用 |
|---|---|
| `width` / `height` | 宽高（字符数 / 行数） |
| `wrap` | 换行模式：`"none"`/`"char"`/`"word"` |
| `state` | `"normal"` 可编辑 / `"disabled"` 只读 |
| `fg` / `bg` | 文字色 / 背景色 |
| `font` | 字体 |
| `spacing1` / `spacing2` / `spacing3` | 段前/段内/段后行距 |

**`wrap="word"` 让长行按单词边界换行**（中文按字符），体验最好。

## "1.0" 是什么：Text 的索引系统

**这是 Text 最独特也最易混的地方：它的位置用 `"行.列"` 表示，行从 1 开始，列从 0 开始。**

```
"1.0"   → 第 1 行第 0 列（文档最开头）
"1.5"   → 第 1 行第 5 列
"2.0"   → 第 2 行开头
"end"   → 文档末尾
```

**为什么行从 1、列从 0？** 这是 Tcl/Tk 的历史设计。记住规则就行。

**验证一下：**

```
text.insert("1.0", "你好世界")
print(text.get("1.0", "1.3"))   # "你好世"（第1行 0~3 列，不含3）
```

## insert：插入文字

**`insert(index, string)` 在指定位置插入：**

```
text.insert("1.0", "第一行\n")    # 在第1行开头插入
text.insert("end", "追加到最后\n")  # 追加到末尾
text.insert("2.0", "插到第二行开头")
```

**`"end"` 是最常用的插入位置**——往末尾追加。

## get：读取文字

**`get(start, end)` 读取一段文字：**

```
all_text = text.get("1.0", "end")   # 读全部
line1 = text.get("1.0", "1.end")    # 读第1行（含到行尾）
```

**翻车现场：`get("1.0", "end")` 末尾会多一个换行符。**

```
text.insert("1.0", "你好")
print(repr(text.get("1.0", "end")))   # '你好\n'
```

**Text 在末尾会自动维护一个换行。** 读全部内容做比较时容易因此出错，通常要 `.strip()`：

```
content = text.get("1.0", "end").strip()
```

## delete：删除

**`delete(start, end)` 删除一段：**

```
text.delete("1.0", "1.end")   # 删除第1行
text.delete("1.0", "end")     # 清空全部
```

**清空 Text 的标准写法：`text.delete("1.0", "end")`。**

## 常用索引常量

**除了 `"1.0"` 和 `"end"`，还有几个常用位置：**

| 常量 | 含义 |
|---|---|
| `"1.0"` | 文档开头 |
| `"end"` | 文档末尾 |
| `"insert"` | 当前光标位置 |
| `"sel.first"` / `"sel.last"` | 当前选区的起止（没选区时报错） |
| `"@x,y"` | 鼠标位置对应的字符（用于事件） |

## 只读 Text：做日志显示区

**让 Text 只读（只能程序写入，用户不能改）：**

```
text = tk.Text(root, state="disabled")
text.insert("1.0", "这是日志\n")
```

**但 disabled 状态下不能 insert。正确姿势：写之前临时改 normal，写完改回 disabled：**

```
def append_log(msg):
    text.configure(state="normal")
    text.insert("end", msg + "\n")
    text.configure(state="disabled")

append_log("程序启动")
append_log("用户登录")
```

**这是一个非常实用的"日志显示"模式。**

## 给文字上色：tag 系统

**Text 支持给一段文字打"标签"，再给标签设样式——这是做代码编辑器的雏形。**

```
text = tk.Text(root)
text.pack()

text.insert("1.0", "这是红色文字\n这是蓝色文字")

# 给第1行打标签
text.tag_add("red", "1.0", "1.5")
text.tag_config("red", foreground="red", font=("微软雅黑", 12, "bold"))

# 给第2行打标签
text.tag_add("blue", "2.0", "2.6")
text.tag_config("blue", foreground="blue")
```

**`tag_add(标签名, 起始, 结束)` 标记一段；`tag_config` 给标签配样式。**

**可以给同一段文字叠加多个标签**，前景色、背景色、字体各管各的。

## 翻车现场一：索引写错成 "0.0"

```
text.insert("0.0", "x")   # TclError: bad text index "0.0"
```

**Text 行号从 1 开始，最小是 `"1.0"`。** `"0.0"` 非法。

## 翻车现场二：以为 get 会去掉末尾换行

```
text.insert("1.0", "hi")
print(text.get("1.0", "end"))   # 'hi\n'
```

**末尾自带 `\n`。** 要做内容比较记得 `.strip()`。

## 翻车现场三：disabled 状态下 insert

```
text = tk.Text(root, state="disabled")
text.insert("1.0", "x")   # TclError: text is disabled
```

**disabled 的 Text 任何修改都会报错。** 先 `configure(state="normal")` 再改。

## 翻车现场四：读选区时没选区

```
sel = text.get("sel.first", "sel.last")   # 没选区时报错
```

**用户没选中文字时，`"sel.first"` 不存在。** 安全写法：

```
try:
    sel = text.get("sel.first", "sel.last")
except tk.TclError:
    sel = ""   # 没选区
```

## Text 的常用方法速查

| 方法 | 作用 |
|---|---|
| `insert(idx, s)` | 插入 |
| `get(a, b)` | 读取 |
| `delete(a, b)` | 删除 |
| `see(idx)` | 滚动到让 idx 可见 |
| `index(idx)` | 把 idx 规范化成 `"行.列"` |
| `compare(a, op, b)` | 比较两个位置 |
| `search(pattern, start, stopindex=...)` | 查找 |
| `replace(a, b, s)` | 替换一段 |
| `tag_add(name, a, b)` | 加标签 |
| `tag_config(name, **opts)` | 配标签样式 |
| `tag_remove(name, a, b)` | 去标签 |

## 实战：一个"字数统计"小工具

**Text 配合 Button 和 Label，做一个实时字数统计：**

```
import tkinter as tk

root = tk.Tk()
root.title("字数统计")

text = tk.Text(root, height=10, wrap="word")
text.pack(padx=10, pady=10)

label = tk.Label(root, text="字符数：0")

def count():
    content = text.get("1.0", "end")
    n = len(content) - 1   # 去掉末尾自动换行
    label.configure(text=f"字符数：{n}")

tk.Button(root, text="统计", command=count).pack()
label.pack()

root.mainloop()
```

**点按钮统计。** 下一课会讲用 `trace` 让它"输入时自动统计"。

## 一个完整例子：简单编辑器骨架

```
import tkinter as tk

root = tk.Tk()
root.title("简易编辑器")

toolbar = tk.Frame(root)
toolbar.pack(fill="x")
tk.Button(toolbar, text="清空").pack(side="left")
tk.Button(toolbar, text="统计").pack(side="left")

text = tk.Text(root, wrap="word")
text.pack(expand=True, fill="both")

status = tk.Label(root, text="就绪", anchor="w")
status.pack(fill="x")

root.mainloop()
```

**这就是记事本的骨架：顶部工具栏、中间编辑区（可缩放）、底部状态栏。**

## 小结

- Text 是**多行**编辑控件，Entry 只能单行
- 索引格式 `"行.列"`：行从 1 开始、列从 0 开始；`"end"` 是末尾
- `insert(idx, s)` 插入、`get(a, b)` 读取、`delete(a, b)` 删除
- `get("1.0", "end")` 末尾自带 `\n`，记得 `.strip()`
- 只读要 disabled，但写入前需临时改回 normal
- `tag_add` + `tag_config` 给文字上色、做样式
