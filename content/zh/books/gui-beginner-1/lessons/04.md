# 第一个控件：Label 与 Button

> 窗口里总得有点东西。这一节讲最常用的两个控件：Label（显示文字）和 Button（点击按钮）。重点是——控件创建出来**不等于**看得见，还得"放进去"。

## 控件是什么

**控件（Widget）就是窗口里那些看得见摸得着的东西**：文字、按钮、输入框、复选框……tkinter 里有几十种。

**所有控件都遵循同一个套路**：创建 → 配置属性 → 放到窗口里。漏了任何一步都会出问题。

## Label：最简单的文字展示

**Label 就是一块"贴纸"，用来显示文字或图片。**

```
import tkinter as tk

root = tk.Tk()
root.title("Label 示例")

label = tk.Label(root, text="你好，世界")
label.pack()

root.mainloop()
```

**关键参数：**

| 参数 | 作用 | 例子 |
|---|---|---|
| `text` | 显示的文字 | `text="你好"` |
| `bg` / `background` | 背景色 | `bg="yellow"` |
| `fg` / `foreground` | 文字颜色 | `fg="red"` |
| `font` | 字体字号 | `font=("微软雅黑", 14, "bold")` |
| `width` / `height` | 宽高（字符数/行数） | `width=20` |
| `anchor` | 文字在控件内的对齐 | `anchor="w"`（左对齐） |
| `justify` | 多行文字的对齐方式 | `justify="left"` |
| `wraplength` | 超过多少像素自动换行 | `wraplength=200` |

**`font` 参数是一个元组**：`(字体名, 字号, 样式)`。样式可选 `"bold"`、`"italic"` 或 `"bold italic"`。

```
label = tk.Label(root, text="大标题",
                 font=("微软雅黑", 20, "bold"),
                 fg="white", bg="#3498db",
                 width=20, height=3)
```

**`width` 和 `height` 的单位是"字符数"不是像素**（Label 上）。**这个细节容易坑人**：`width=20` 大概是 20 个英文字符的宽度，中文字符宽度约等于两个英文字符。

**多行文字用 `\n` 换行，或者用 `wraplength` 自动折行：**

```
label = tk.Label(root, text="这是一段很长很长很长很长很长很长很长的文字",
                 wraplength=150, justify="left", anchor="w")
```

**`wraplength=150` 表示超过 150 像素就自动换行。** `justify` 管多行之间的对齐，`anchor` 管文字在控件框内的整体位置（"w"=西=左，"e"=东=右，"n"=北=上，"s"=南=下）。

## 修改文字：configure 与 textvariable

**控件创建后还能改文字，两种方式：**

```
label = tk.Label(root, text="旧文字")
label.pack()

# 方式一：configure
label.configure(text="新文字")

# 方式二：直接改属性（效果一样）
label["text"] = "又改了"
```

**`label["text"] = ...` 这种字典式写法完全合法**，因为控件的属性本质就是一个字典。两种写法任选。

## 翻车现场一：忘了 pack/grid/place，控件"隐形"

**这是本章最大坑。**

```
import tkinter as tk

root = tk.Tk()
label = tk.Label(root, text="我看不见")   # 创建了，但没放进去
root.mainloop()
```

**症状**：窗口能打开，但是**空白的**，Label 根本没显示。

**原因**：创建控件只是把它造出来了，还得用 `pack()`/`grid()`/`place()` 之一把它放进窗口的布局里。**没有这一步，控件就"漂浮"在真空里，没人看得见。**

**修复**：补上 `.pack()`：

```
label = tk.Label(root, text="我看得见")
label.pack()   # 关键！
```

**记住口诀：控件创建后必须"上架"，上架就是调用 pack/grid/place 之一。**

## 翻车现场二：把 pack 的返回值存进变量

第 2 课提过，这里再强调：

```
label = tk.Label(root, text="提示").pack()   # 错！
print(label)   # None
label.configure(text="新")   # AttributeError!
```

**`pack()` 返回 `None`。** 正确分两行写：

```
label = tk.Label(root, text="提示")
label.pack()
```

## Button：点我一下

**Button 是按钮，它多了一个核心参数 `command`——点按钮时要执行的函数。**

```
import tkinter as tk

root = tk.Tk()
root.title("按钮示例")

def say_hi():
    print("你好！")

btn = tk.Button(root, text="点我", command=say_hi)
btn.pack()

root.mainloop()
```

**点一下按钮，终端打印"你好！"。**

**Button 常用参数：**

| 参数 | 作用 |
|---|---|
| `text` | 按钮上的文字 |
| `command` | 点击时调用的函数（**不加括号**） |
| `bg` / `fg` | 背景色 / 文字色 |
| `font` | 字体 |
| `width` / `height` | 尺寸（字符数） |
| `state` | `"normal"` 可用 / `"disabled"` 灰掉 |
| `relief` | 边框样式：`"raised"`/`"sunken"`/`"flat"`/`"ridge"`/`"groove"` |
| `cursor` | 鼠标悬停时的光标样式 |

**`command` 是最关键也最容易写错的地方**，下一节专门讲。先记住：**`command=say_hi` 不加括号；写成 `command=say_hi()` 就错了。**

## 按钮的三种状态

```
btn = tk.Button(root, text="可用", state="normal")
btn = tk.Button(root, text="灰掉了", state="disabled")
```

**`state="disabled"` 让按钮变灰、不可点击。** 这在"还没填完表单就禁用提交按钮"的场景很有用。

**想让按钮恢复可用**：

```
btn.configure(state="normal")
```

## relief：按钮的立体感

**`relief` 控制边框样式，做"按下去"的视觉效果很好用：**

```
tk.Button(root, text="凸起", relief="raised").pack()
tk.Button(root, text="凹陷", relief="sunken").pack()
tk.Button(root, text="平面", relief="flat").pack()
tk.Button(root, text="脊", relief="ridge").pack()
tk.Button(root, text="沟", relief="groove").pack()
```

**配合 `bd`（borderwidth，边框宽度）使用效果更明显：**

```
tk.Button(root, text="厚边框", relief="ridge", bd=5).pack()
```

## 一个"点了 N 次"的计数器

**这是个经典小例子，展示了按钮如何和变量配合：**

```
import tkinter as tk

root = tk.Tk()
root.title("计数器")

count = 0

def add():
    global count
    count += 1
    label.configure(text=f"已点击 {count} 次")

label = tk.Label(root, text="已点击 0 次", font=("微软雅黑", 16))
label.pack(pady=20)

btn = tk.Button(root, text="点我加一", command=add)
btn.pack()

root.mainloop()
```

**这里用 `global count` 声明 count 是全局变量**，因为函数里要对它重新赋值。如果只读不改，不用 `global`。

**翻车现场**：忘写 `global count`，运行会报 `UnboundLocalError: local variable 'count' referenced before assignment`。这是因为函数里出现了 `count += 1`（赋值），Python 就把 count 当成局部变量了，但读的时候它还没被赋值。

## 让按钮"变身"：改文字、改状态

**按钮本身也能动态改：**

```
def toggle():
    if btn["text"] == "开始":
        btn.configure(text="停止", bg="red")
    else:
        btn.configure(text="开始", bg="SystemButtonFace")  # 恢复系统默认色

btn = tk.Button(root, text="开始", command=toggle)
btn.pack()
```

**这种"切换按钮"在播放器、计时器里很常见。**

## Label 显示图片

**Label 不光能放文字，也能放图片。** 用 `PhotoImage`：

```
import tkinter as tk

root = tk.Tk()

# 支持 PNG、GIF、PPM；不支持 JPG（需要 Pillow）
img = tk.PhotoImage(file="example.png")
label = tk.Label(root, image=img)
label.pack()

root.mainloop()
```

**翻车现场**：图片不显示，也不报错。

```
img = tk.PhotoImage(file="photo.jpg")   # 报错或空白
```

**tkinter 原生只支持 PNG / GIF / PPM，不支持 JPG。** 要显示 JPG 得装 Pillow：`from PIL import Image, ImageTk`，然后 `img = ImageTk.PhotoImage(Image.open("photo.jpg"))`。

**另一个坑：图片对象被垃圾回收。** 在某些环境下，`PhotoImage` 对象如果只作为局部变量，函数结束后会被回收，图片变空白。稳妥做法：**把图片存成全局变量或挂到控件属性上**：

```
label.image = img   # 保留引用，防止被回收
```

## 控件属性的统一规则

**所有控件共享一套属性系统，这也是 tkinter 好学的原因：**

| 操作 | 写法 |
|---|---|
| 创建时设 | `tk.Label(root, text="x", bg="red")` |
| 创建后改 | `label.configure(text="y")` |
| 字典式改 | `label["text"] = "y"` |
| 读取值 | `label["text"]` 或 `label.cget("text")` |

**`cget` 是读属性的标准方法：**

```
print(label.cget("text"))   # "y"
```

## 小结

- **Label** 显示文字：`text`、`font`、`fg`、`bg`、`wraplength` 最常用
- **Button** 响应点击：`command` 指定点击时调用的函数
- **控件创建后必须 pack/grid/place，否则看不见**
- `pack()` 返回 `None`，别把它的返回值存进变量
- `command=say_hi`（不加括号），括号的坑下一课讲
- Label 能放图片：`PhotoImage(file="x.png")`，原生不支持 JPG
- 改属性用 `configure()`，读属性用 `cget()`
