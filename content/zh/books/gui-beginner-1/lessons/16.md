# command 回调：按钮点了要做什么

> 按钮点下去要执行一段代码，这段代码就是"回调"。这一节讲清 command 的正确写法、为什么不能加括号、以及怎么传参数。

## 回调是什么

**回调（callback）就是"等事件发生时被调用的函数"。** 按钮的 `command` 参数是最典型的回调。

```
import tkinter as tk

root = tk.Tk()

def say_hi():
    print("你好！")

tk.Button(root, text="点我", command=say_hi).pack()

root.mainloop()
```

**点按钮 → tkinter 去调用 `say_hi` → 打印"你好！"。**

**整个流程：你写好函数 → 交给按钮保管 → 用户点击时按钮替你调用。**

## command 的正确写法：不加括号

**`command=say_hi` 不加括号，`command=say_hi()` 是错的。**

```
# 正确
tk.Button(root, text="点我", command=say_hi).pack()

# 错误
tk.Button(root, text="点我", command=say_hi()).pack()
```

**为什么？** `say_hi()` 带括号是"立刻调用"——在创建按钮的那一刻就执行了，而且 command 收到的是函数的返回值（`None`），不是函数本身。结果就是：程序一启动按钮上的功能就跑了一次，之后点击毫无反应。

## 翻车现场一：command 加括号

```
def greet():
    print("hello")

tk.Button(root, text="点我", command=greet()).pack()
# 程序启动立刻打印 "hello"，按钮点击没反应
```

**修复：去掉括号。**

## 翻车现场二：command 传了字符串

```
tk.Button(root, text="点我", command="greet").pack()
# 点击报错：call() got an unexpected keyword 'greet'
```

**command 要的是函数对象，不是函数名的字符串。**

## command 能传哪些东西

**command 可以是：**

| 写法 | 说明 |
|---|---|
| `command=函数名` | 最常用 |
| `command=lambda: ...` | 需要传参数时用 |
| `command=某个可调用对象` | 类的实例如果定义了 `__call__` |

**`command` 永远只能接收"无参"的函数对象。** 想传参数，就得用 lambda 包一层（下一课讲）。

## 回调访问界面元素

**回调函数通常要读写控件，所以控件变量必须是它能访问到的（全局或闭包）：**

```
import tkinter as tk

root = tk.Tk()

entry = tk.Entry(root)
entry.pack()

label = tk.Label(root, text="")

def show():
    name = entry.get()
    label.configure(text=f"你好，{name}！")

label.pack()
tk.Button(root, text="问好", command=show).pack()

root.mainloop()
```

**`entry`、`label` 是全局变量，`show` 能读到。** 注意：读全局变量不需要 `global`，只有要重新赋值才需要。

## 带参数的回调：lambda 初探

**想传参数给回调，用 `lambda`：**

```
def greet(name):
    print(f"你好，{name}！")

tk.Button(root, text="问候张三", command=lambda: greet("张三")).pack()
tk.Button(root, text="问候李四", command=lambda: greet("李四")).pack()
```

**`lambda: greet("张三")` 创建一个"零参数函数"，点击时调用它，它再去调用 `greet("张三")`。**

**`lambda` 是这一章的核心技巧，第 17 课会专门深入讲。**

## 用类组织回调（进阶）

**当界面复杂时，用类把控件和回调组织在一起更清晰：**

```
import tkinter as tk

class App:
    def __init__(self, root):
        self.root = root
        root.title("计数器")

        self.count = 0
        self.label = tk.Label(root, text="0")
        self.label.pack()

        tk.Button(root, text="加一", command=self.add).pack()

    def add(self):
        self.count += 1
        self.label.configure(text=str(self.count))

root = tk.Tk()
App(root)
root.mainloop()
```

**`command=self.add` 传的是方法对象，点击时 Python 自动把 `self` 传进去。** 这种方式把界面和逻辑都挂在 `self` 上，避免一堆全局变量。

## 翻车现场三：方法传参又忘了 self

```
class App:
    def __init__(self, root):
        tk.Button(root, text="点", command=self.click).pack()

    def click(self, name):   # 多了一个参数
        print(name)

# 点击时报错：click() missing 1 required positional argument: 'name'
```

**command 调用回调时不传任何参数。** 如果回调需要参数，用 lambda 或 functools.partial：

```
from functools import partial
tk.Button(root, text="点", command=partial(self.click, "张三")).pack()
```

## 多个按钮共用一个回调

**用一个回调 + 区分参数：**

```
def choose(option):
    label.configure(text=f"你选了：{option}")

tk.Button(root, text="A", command=lambda: choose("A")).pack()
tk.Button(root, text="B", command=lambda: choose("B")).pack()
tk.Button(root, text="C", command=lambda: choose("C")).pack()
```

**lambda 在这里的价值：把"点击"和"选了哪个"绑定在一起。**

## 回调里修改多个控件

**一个回调更新整个界面很常见：**

```
def submit():
    name = name_entry.get().strip()
    age_str = age_entry.get().strip()
    if not name:
        result.configure(text="名字不能为空", fg="red")
        return
    try:
        age = int(age_str)
    except ValueError:
        result.configure(text="年龄必须是数字", fg="red")
        return
    result.configure(text=f"提交成功：{name}, {age}岁", fg="black")
```

**这种"读取多个输入 → 校验 → 更新结果"的模式，是 GUI 程序的骨架。**

## command 的局限

**command 只能处理"点击/调用"这类简单事件，而且只能绑定到 Button、Checkbutton、Radiobutton、Scale、Spinbox 等少数控件。**

**想要更细的事件（鼠标移动、键盘按键、双击、窗口缩放）——得用 `bind`**，第 18 课讲。

## 小结

- 回调是"等事件发生时被调用的函数"，command 是最典型的回调
- **command=函数名（不加括号）**；加括号会立即执行且点击失效
- command 只能接"无参"函数；要传参用 lambda 或 functools.partial
- 回调访问界面元素：读不用 global，重新赋值才要 global
- 复杂界面用**类**组织，控件和方法都挂在 self 上
- command 只管点击类事件，更细的事件用 bind
