# pack：上下左右排

> pack 是最简单的布局管理器，也是新手最先用会的。这一节把 pack 的每个参数掰开讲，让你知道它够用在哪、不够用在哪。

## pack 的默认行为

**pack 默认 `side="top"`，控件从上到下依次排开：**

```
import tkinter as tk

root = tk.Tk()
for color in ["red", "green", "blue"]:
    tk.Label(root, text=color, bg=color, width=20, height=3).pack()
root.mainloop()
```

**三个 Label 从上到下各占一行。** 这是 pack 最直觉的用法。

## side：贴哪边

**`side` 决定控件贴父控件的哪条边：**

```
tk.Label(root, text="上").pack(side="top")
tk.Label(root, text="下").pack(side="bottom")
tk.Label(root, text="左").pack(side="left")
tk.Label(root, text="右").pack(side="right")
```

**一个"上下分割 + 左右按钮"的实用布局：**

```
import tkinter as tk

root = tk.Tk()

top = tk.Label(root, text="顶部标题栏", bg="lightblue")
top.pack(side="top", fill="x")

bottom = tk.Label(root, text="底部状态栏", bg="gray80")
bottom.pack(side="bottom", fill="x")

left = tk.Label(root, text="左侧栏", bg="lightyellow", width=10)
left.pack(side="left", fill="y")

tk.Label(root, text="中间主体内容区").pack()
root.mainloop()
```

**side 的顺序会影响最终布局**——pack 是按"调用顺序"依次给每个控件分配空间的。想做复杂结构，还是建议用 Frame 分区 + 各自 pack。

## fill：沿哪个方向填满

**`fill` 让控件在有额外空间时撑开：**

| 值 | 效果 |
|---|---|
| `"none"` | 保持自然尺寸（默认） |
| `"x"` | 水平撑满 |
| `"y"` | 垂直撑满 |
| `"both"` | 水平 + 垂直都撑满 |

```
tk.Label(root, text="横向撑满", bg="yellow").pack(fill="x")
tk.Label(root, text="自然尺寸", bg="green").pack()
```

**第一个 Label 会横向占满整个窗口宽度；第二个保持文字本来的宽度。**

**对比一下 fill 的效果：**

```
for t, fill in [("none", "none"), ("x", "x"), ("both", "both")]:
    tk.Label(root, text=f"fill={t}", bg=color, width=20).pack(fill=fill)
```

**只有 `fill="x"` 或 `fill="both"` 时，窗口加宽控件才跟着加宽。**

## expand：抢不抢额外空间

**`expand=True` 表示"如果有剩余空间，分我一份"。** 它和 `fill` 经常配合：

```
tk.Label(root, text="expand=True, fill='both'", bg="red").pack(expand=True, fill="both")
tk.Label(root, text="默认", bg="blue").pack()
```

**红 Label 会占满除蓝 Label 以外的所有空间。**

**`expand` 和 `fill` 的区别**：`expand` 决定"要不要空间"，`fill` 决定"拿到空间后怎么用"。只写 `expand=True` 不写 `fill`，控件拿到空间但保持自然尺寸居中；只写 `fill="both"` 不写 `expand`，控件只在它那一"行"里撑满。

**最常见的组合是 `expand=True, fill="both"`**：让一个控件（比如中间的编辑区）占满所有剩余空间，窗口缩放时也跟着变。

## padx / pady：外边距

**`padx`/`pady` 给控件周围留空白：**

```
tk.Button(root, text="按钮1").pack(padx=20, pady=10)
tk.Button(root, text="按钮2").pack(padx=20, pady=10)
```

**两个按钮之间垂直留白 20 像素（两个 pady 相加），左右各留 20 像素。**

**`padx` 也可以是元组 `(左, 右)`、`pady=(上, 下)`：**

```
tk.Label(root, text="不等边距").pack(padx=(5, 30), pady=(2, 15))
```

## ipadx / ipady：内边距

**`ipadx`/`ipady` 是控件内部的留白，会让控件本身变大：**

```
tk.Button(root, text="小").pack()
tk.Button(root, text="大（内边距）").pack(ipadx=20, ipady=10)
```

**第二个按钮比第一个大一圈**，因为内部左右各加了 20、上下各加了 10 像素的"衬垫"。

**`padx` vs `ipadx` 的区别**：pad 是"我和邻居之间的距离"，ipad 是"我自己的尺寸膨胀"。

## anchor：在分配到的空间里靠哪边

**`anchor` 控制控件在它被分配到的那块空间里靠哪里：**

```
tk.Label(root, text="左上", bg="red").pack(anchor="nw", fill="x")
tk.Label(root, text="居中", bg="green").pack(anchor="center", fill="x")
tk.Label(root, text="右下", bg="blue").pack(anchor="se", fill="x")
```

**方向缩写**：`n`(北上)、`s`(南下)、`w`(西左)、`e`(东右)，可以组合成 `"nw"`、`"se"` 等。

**常见用法**：`anchor="w"` 让文字左对齐——Label 撑满整行但文字靠左。

## pack 的排布顺序

**pack 是按"调用顺序"依次分配空间的**，这个细节常被忽略：

```
tk.Label(root, text="第一个").pack(side="top")
tk.Label(root, text="第二个").pack(side="top")
```

**结果是"第一个"在上、"第二个"在下。** 反过来写就反过来显示。

**一个容易踩的坑：**

```
tk.Label(root, text="A").pack(side="left")
tk.Label(root, text="B").pack(side="top")   # 这个 top 是相对剩余空间的 top
```

**当 side 混合使用时，pack 会先给 side="left" 的控件分配左边缘空间，剩下的空间里再排 side="top" 的。** 结果可能不是你直觉预期的。混用 side 容易乱，尽量统一。

## 翻车现场一：以为 pack 能对齐成表格

```
tk.Label(root, text="姓名：").pack(side="left")
tk.Entry(root).pack(side="left")
tk.Label(root, text="年龄：").pack(side="left")
tk.Entry(root).pack(side="left")
```

**四件套会排成一行，挤在左边，且两行控件不会纵向对齐。** 这不是表单，别这样写。

**这种需求就该用 grid**——pack 没有"列对齐"的概念。

## 翻车现场二：fill="both" 但没 expand

```
tk.Label(root, text="编辑区", bg="lightblue").pack(fill="both")
```

**看起来好像撑满了，其实只在它那"一行"里水平撑满，垂直方向没抢到空间。** 想要随窗口缩放都要加 `expand=True`：

```
tk.Label(root, text="编辑区", bg="lightblue").pack(expand=True, fill="both")
```

## 翻车现场三：pack 之后还想精确定位

```
label = tk.Label(root, text="x").pack()
label.place(x=100, y=100)   # 报错！label 是 None
```

**`pack()` 返回 `None`**（前面强调过）。而且一个控件被 pack 后就不能再 place。

**想要精确定位，一开始就用 place。**

## 一个实用例子：工具栏 + 主体

**pack 最擅长的结构：**

```
import tkinter as tk

root = tk.Tk()
root.title("编辑器")

toolbar = tk.Frame(root, bg="lightgray")
toolbar.pack(side="top", fill="x")

tk.Button(toolbar, text="新建").pack(side="left", padx=2, pady=2)
tk.Button(toolbar, text="打开").pack(side="left", padx=2, pady=2)
tk.Button(toolbar, text="保存").pack(side="left", padx=2, pady=2)

status = tk.Label(root, text="就绪", bd=1, relief="sunken", anchor="w")
status.pack(side="bottom", fill="x")

body = tk.Label(root, text="（这里是编辑区）", bg="white")
body.pack(expand=True, fill="both")

root.mainloop()
```

**这个结构在真实软件里非常常见**：顶部工具栏、底部状态栏、中间可缩放的主体。全靠 pack + Frame 就能搭出来。

## 小结

- `side`：贴哪边，默认 `"top"`
- `fill`：沿 x/y/both 撑满；`expand`：抢不抢额外空间
- 最常用组合：`expand=True, fill="both"` 让控件占满剩余空间
- `padx`/`pady` 外边距，`ipadx`/`ipady` 内边距（让控件变大）
- `anchor` 控制控件在分配到的空间里靠哪边
- pack 适合：工具栏、简单堆叠；不适合：对齐成表格（用 grid）
