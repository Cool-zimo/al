# bind 与事件序列

> command 只能管"点击按钮"这种简单事件。想响应鼠标移动、键盘按键、双击、窗口缩放，得用 `bind`。这一节讲 bind 怎么用、事件序列怎么写、事件对象 event 里有什么。

## bind 是什么

**`bind` 把一个事件序列和一个回调函数绑起来。** 事件发生时，回调被调用并收到一个事件对象。

```
import tkinter as tk

root = tk.Tk()

def on_click(event):
    print(f"点击坐标：({event.x}, {event.y})")

root.bind("<Button-1>", on_click)   # 绑定左键单击
root.mainloop()
```

**点击窗口任意位置，终端打印坐标。**

## 事件序列的格式

**事件序列是一个字符串，格式 `<修饰符-类型-细别>`：**

```
<Button-1>     → 鼠标左键单击
<Button-3>     → 鼠标右键单击
<Double-1>     → 鼠标左键双击
<Enter>        → 鼠标进入控件
<Leave>        → 鼠标离开控件
<Key>          → 任意键按下
<Return>       → 回车键
<Shift_L>      → 左 Shift 键
<Configure>    → 窗口大小改变
```

**常见事件类型：**

| 类型 | 含义 |
|---|---|
| `Button-1`/`2`/`3` | 鼠标左/中/右键按下 |
| `ButtonRelease-1` | 左键松开 |
| `Motion` | 鼠标移动 |
| `Enter` / `Leave` | 鼠标进入/离开控件 |
| `Key` / `KeyPress` | 按键按下 |
| `KeyRelease` | 按键松开 |
| `FocusIn` / `FocusOut` | 获得/失去焦点 |
| `Configure` | 控件尺寸/位置变化 |
| `Destroy` | 控件被销毁 |

## 控件级绑定 vs 全局绑定

**绑定到某个控件：只有该控件上发生事件才触发。**

```
btn = tk.Button(root, text="按钮")
btn.bind("<Enter>", lambda e: print("鼠标进来了"))
```

**绑定到 root（全局）：整个窗口都监听。**

```
root.bind("<Key>", lambda e: print("按了", e.char))
```

**区别**：全局绑定监听整个窗口，控件级绑定只监听那个控件。

## 事件对象 event

**回调被调用时会自动收到一个 `event` 对象，里面装满了有用信息：**

| 属性 | 含义 |
|---|---|
| `event.x` / `event.y` | 相对于**绑定控件**左上角的坐标 |
| `event.x_root` / `event.y_root` | 相对于**屏幕**左上角的坐标 |
| `event.char` | 按键的字符（可打印字符） |
| `event.keysym` | 按键名（"Return"、"Escape"、"a"） |
| `event.keycode` | 按键码（数字） |
| `event.num` | 鼠标按键号（1/2/3） |
| `event.widget` | 触发事件的控件对象 |
| `event.width` / `event.height` | Configure 事件的新尺寸 |

## 键盘事件：读按键

```
def on_key(event):
    print(f"按键：{event.char!r}, 键名：{event.keysym}")

root.bind("<Key>", on_key)
```

**`event.char` 是字符（如 `'a'`、`'1'`、空格是 `' '`）；`event.keysym` 是键名（如 `"Return"`、`"Escape"`、`"Shift_L"`）。**

**翻车现场：`event.char` 对功能键是空字符串。**

```
event.keysym == "Return"   # 回车
event.keysym == "Escape"   # ESC
event.keysym == "Tab"      # Tab
```

**想判断功能键要用 `event.keysym`。**

## <Return>：回车提交

**最常见的键盘绑定——输入框里按回车触发提交：**

```
entry = tk.Entry(root)
entry.pack()
entry.bind("<Return>", lambda e: print("提交：", entry.get()))
```

**注意 lambda 要接收 `e` 参数**，因为 bind 会传 event 进来。

## 翻车现场一：bind 回调忘了接收 event

```
def handler():   # 没写 event 参数
    print("点击")

btn.bind("<Button-1>", handler)
# 点击时报错：handler() takes 0 positional arguments but 1 was given
```

**bind 的回调必须能接收一个参数（事件对象）。** 修复：

```
def handler(event):
    print("点击")
```

**如果确实不需要 event，用 `lambda e:` 吃掉它：**

```
btn.bind("<Button-1>", lambda e: do_something())
```

## 翻车现场二：command 回调却想收 event

```
def handler(event):
    print(event)

btn = tk.Button(root, text="点", command=handler)
# 点击时报错：handler() missing 1 required positional argument: 'event'
```

**`command=` 调用回调时**不**传 event 对象。** 只有 `bind` 的回调才收到 event。

**如果既要用 command 又要用 bind 同一函数，给 event 参数设默认值：**

```
def handler(event=None):
    print("点击或按键")

btn = tk.Button(root, text="点", command=handler)
btn.bind("<Button-1>", handler)
```

## 翻车现场三：控件没获得焦点，键盘事件不触发

```
entry.bind("<Key>", on_key)   # 只有 entry 获得焦点时才触发
```

**键盘事件只对"当前有焦点的控件"触发。** 想让整个窗口都能接按键，绑到 root 上：

```
root.bind("<Key>", on_key)
```

**想让某个控件主动获得焦点：**

```
entry.focus_set()   # 把焦点设到 entry
```

## 常用虚拟事件

**tkinter 还为一些控件定义了"虚拟事件"（双尖括号）：**

| 事件 | 触发 |
|---|---|
| `<<ListboxSelect>>` | Listbox 选中项变化 |
| `<<ComboboxSelected>>` | Combobox 选中项变化 |
| `<<NotebookTabChanged>>` | Notebook 切换标签 |
| `<<TreeviewSelect>>` | Treeview 选中变化 |

**绑定方式和普通事件一样：**

```
lb.bind("<<ListboxSelect>>", on_select)
```

## 组合修饰键

**事件序列支持修饰符：**

```
<Control-s>     → Ctrl+S
<Alt-F4>        → Alt+F4
<Shift-Return>  → Shift+回车
```

**注意大小写和连字符：**

```
root.bind("<Control-s>", lambda e: print("保存"))
root.bind("<Control-Shift-s>", lambda e: print("另存为"))
```

## 阻止默认行为

**`return "break"` 能阻止事件继续传播（阻止默认行为）：**

```
def on_close(event):
    print("拦截到 Alt+F4")
    return "break"

root.bind("<Alt-F4>", on_close)
```

**`return "break"` 告诉 tkinter "这事我处理完了，别再往下传了"。**

## 实战：一个"鼠标坐标跟踪"

```
import tkinter as tk

root = tk.Tk()
root.title("鼠标跟踪")

label = tk.Label(root, text="把鼠标移进来")
label.pack(padx=20, pady=20)

def on_motion(event):
    label.configure(text=f"坐标：({event.x}, {event.y})")

root.bind("<Motion>", on_motion)
root.mainloop()
```

**鼠标在窗口上移动，Label 实时显示坐标。**

## 一个技巧：bind 的 "add" 参数

**默认情况下，重复 bind 同一事件会**覆盖**之前的绑定。想"追加"而不是覆盖：**

```
def a(event): print("A")
def b(event): print("B")

btn.bind("<Button-1>", a)
btn.bind("<Button-1>", b)          # 覆盖 a
btn.bind("<Button-1>", b, add="+") # 追加，a 和 b 都会执行
```

## 小结

- `bind(事件序列, 回调)` 绑定事件；回调**必须接收一个 event 参数**
- 事件序列格式 `<修饰符-类型-细别>`，如 `<Button-1>`、`<Return>`、`<Configure>`
- event 对象常用属性：`x`/`y`（控件坐标）、`char`/`keysym`（按键）、`widget`（触发控件）
- 键盘事件绑到 root 才能全局响应；控件要 `focus_set()` 才有焦点
- command 回调**不**收 event，bind 回调**收** event
- `return "break"` 阻止事件继续传播
