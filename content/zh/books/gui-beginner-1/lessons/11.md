# Entry 单行输入：get / delete / insert

> Entry 是最常用的输入控件，只能输入一行。这一节讲清它的增删改查方法，以及 `StringVar` 和 `trace`——这两个东西是 tkinter 里"数据和界面绑定"的核心。

## Entry 的基本用法

**Entry 就是单行输入框：**

```
import tkinter as tk

root = tk.Tk()
root.title("输入框")

entry = tk.Entry(root, width=30)
entry.pack(padx=10, pady=10)

root.mainloop()
```

**常用参数：**

| 参数 | 作用 |
|---|---|
| `width` | 显示宽度（字符数） |
| `show` | 显示成别的字符（做密码框） |
| `state` | `"normal"` 可编辑 / `"readonly"` 只读 / `"disabled"` 禁用 |
| `fg` / `bg` | 文字色 / 背景色 |
| `font` | 字体 |
| `justify` | 对齐 `"left"`/`"center"`/`"right"` |
| `validate` / `validatecommand` | 输入校验（高级） |

## show：密码框

**`show="*"` 让输入的字符显示为星号：**

```
pwd = tk.Entry(root, show="*")
pwd.pack()
```

**登录界面的密码框就是这样做的。** 输入的内容实际还在，只是显示成 `*`。

**`show` 只影响显示，不影响 `get()` 拿到的值：**

```
pwd.get()   # 返回的还是真实密码字符串
```

## state：只读与禁用

**三种状态：**

```
tk.Entry(root, state="normal")     # 可编辑（默认）
tk.Entry(root, state="readonly")   # 只读，可选中、可复制，不能改
tk.Entry(root, state="disabled")   # 禁用，灰掉，不能交互
```

**"只读"在显示计算结果时很有用**：用户能看到但不能手改。

```
result = tk.Entry(root, state="readonly")
result.insert(0, "计算结果")
```

**翻车现场：往只读 Entry 里 insert 会报错。**

```
entry = tk.Entry(root, state="readonly")
entry.insert(0, "hello")   # TclError: state must be normal to modify text
```

**修复：改之前先设成 normal，改完再设回 readonly：**

```
entry.configure(state="normal")
entry.delete(0, "end")
entry.insert(0, "新内容")
entry.configure(state="readonly")
```

## get：读取值

**`entry.get()` 返回当前输入框里的字符串：**

```
def show():
    print("输入的是：", entry.get())

tk.Button(root, text="打印", command=show).pack()
```

**用户没输入时返回空字符串 `""`。**

## insert：插入文字

**`insert(index, string)` 在指定位置插入文字：**

```
entry.insert(0, "默认内容")       # 在开头插入
entry.insert("end", "追加内容")   # 在末尾追加
entry.insert(tk.END, "也行")     # 同上，导入 END
```

**`"end"` 是 tkinter 定义的特殊位置常量，表示"末尾"。**

**设置默认值的标准写法：**

```
entry = tk.Entry(root)
entry.insert(0, "请输入...")
entry.pack()
```

## delete：删除文字

**`delete(start, end)` 删除一段文字（含 start，不含 end）：**

```
entry.delete(0, "end")    # 清空整个输入框
entry.delete(0, 5)        # 删除前 5 个字符
entry.delete(tk.END)      # 删除光标前的一个字符（常用在退格逻辑）
```

**`"end"` 作为 end 参数时表示"删到末尾"。**

## index：获取光标位置

**`entry.index("insert")` 返回当前光标位置（整数）：**

```
entry.insert("insert", "在光标处插入")   # 在当前光标位置插入
```

**`"insert"` 表示当前光标位置，`"end"` 表示末尾。**

## StringVar：让变量和控件绑定

**`StringVar` 是一个"会通知界面"的字符串变量。** 改它的值，界面自动更新；界面改了，变量也自动跟着变。

**为什么要它？先看不用它的写法：**

```
entry = tk.Entry(root)
entry.pack()

# 想改输入框内容
entry.delete(0, "end")
entry.insert(0, "新内容")   # 要两句
```

**用 StringVar 之后：**

```
import tkinter as tk

root = tk.Tk()

var = tk.StringVar()
var.set("默认内容")                    # 设置值

entry = tk.Entry(root, textvariable=var)
entry.pack()

tk.Button(root, text="改成你好",
          command=lambda: var.set("你好")).pack()

root.mainloop()
```

**`textvariable=var` 把输入框和 var 绑定。** 点按钮时 `var.set("你好")`，Entry 里的文字**自动更新**，不用手动 delete + insert。

## StringVar 的读取

**`var.get()` 读值，`var.set()` 设值：**

```
var = tk.StringVar()
var.set("abc")
print(var.get())   # "abc"
```

**绑定后，`var.get()` 和 `entry.get()` 拿到的是同一个值：**

```
var = tk.StringVar(value="初始")
entry = tk.Entry(root, textvariable=var)
entry.pack()

# 两种方式等价
print(entry.get())   # "初始"
print(var.get())     # "初始"
```

**推荐：凡是要"读取或修改输入框"的场景，用 StringVar，代码更干净。**

## tkinter 里的变量类家族

**tkinter 有四种"变量类"，都用来绑定控件：**

| 变量类 | 对应的 Python 类型 | 绑定控件 |
|---|---|---|
| `StringVar` | `str` | Entry、Label、OptionMenu、Text（部分） |
| `IntVar` | `int` | Checkbutton、Radiobutton、Scale |
| `DoubleVar` | `float` | Scale |
| `BooleanVar` | `bool` | Checkbutton |

**它们的 API 都一样：`get()` 读、`set()` 写。**

## 翻车现场一：StringVar 忘了 set

**创建了 StringVar 却没设初值，界面显示空白：**

```
var = tk.StringVar()        # 没 set
entry = tk.Entry(root, textvariable=var)
entry.pack()
print(var.get())            # "" 空字符串
```

**这不是 bug，但常让人困惑"为什么没显示"。** 设初值：`var = tk.StringVar(value="初始值")` 或 `var.set("初始值")`。

## 翻车现场二：StringVar 被垃圾回收

**在函数里创建的 StringVar 如果没被引用，可能被回收，导致绑定失效：**

```
def make_entry():
    var = tk.StringVar(value="x")
    return tk.Entry(root, textvariable=var)

entry = make_entry()
entry.pack()
# var 离开作用域后被回收，绑定可能失效
```

**修复**：把 var 存成属性或全局变量：

```
entry.var = tk.StringVar(value="x")   # 挂到 entry 上，保留引用
```

## 翻车现场三：把普通字符串当 StringVar 用

```
name = "张三"
entry = tk.Entry(root, textvariable=name)   # 报错或无效
```

**`textvariable` 必须传变量类对象，不能传普通字符串。** 普通字符串没有 `get`/`set` 方法。

## 翻车现场四：试图把 Entry 当多行用

**Entry 只能是单行。** 想输入多行文字要用 Text 控件（下一课讲）。

```
entry.insert("end", "第一行\n第二行")   # \n 会显示成字面上的 \n 或无效
```

## 实战：输入校验

**`validate` + `validatecommand` 能在输入时实时校验：**

```
import tkinter as tk

root = tk.Tk()

def only_digits(new_val):
    # new_val 是用户输入后的新值
    return new_val.isdigit() or new_val == ""

vcmd = (root.register(only_digits), "%P")

entry = tk.Entry(root, validate="key", validatecommand=vcmd)
entry.pack()

root.mainloop()
```

**只能输入数字。** `validate="key"` 表示每次按键都校验，`%P` 是"输入后的值"。

**这个高级特性先了解，后面用到再查。现阶段用 Button 回调里 `try/except` 更直观。**

## 小结

- Entry 是**单行**输入框，`get()` 读值（永远是字符串）
- `insert(i, s)` 插入、`delete(a, b)` 删除、`"end"` 表示末尾
- `show="*"` 做密码框；`state="readonly"` 只读
- **StringVar** 是带通知的字符串变量，用 `textvariable` 绑定
- `var.set()` 改值界面自动更新；`var.get()` 读值
- 变量类还有 IntVar / DoubleVar / BooleanVar，下一课用
