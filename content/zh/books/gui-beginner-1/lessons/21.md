# 弹出对话框：`messagebox`

> GUI 程序有时候需要跟用户说句话——确认一个危险操作、报告一个错误，或者问一个是/否问题。`tkinter.messagebox` 提供了一组现成的弹窗，你不用从零造轮子。

## 为什么需要弹窗

**弹窗会打断流程、强制用户关注——所以你也应该少用，但关键时刻少不了它。** 命令行程序里你 `print` 一句，只能指望用户盯着终端看；GUI 程序里用户可能根本没开终端。一个 `messagebox` 会把一条消息和一个或两个按钮直接怼到最前面，逼用户处理。

```
import tkinter as tk
from tkinter import messagebox

root = tk.Tk()
root.title("示例")

def clicked():
    messagebox.showinfo("你好", "你点了按钮！")

tk.Button(root, text="点我", command=clicked).pack(padx=20, pady=20)

root.mainloop()
```

**运行后点一下按钮：一个新小窗口弹出来，带信息图标、标题、正文和一个「确定」按钮。** 点「确定」它就消失。这就是全部套路——一次函数调用，阻塞到你回应。

## 四种只报不答的弹窗

**`showinfo`、`showwarning`、`showerror` 用法完全一样，区别只在图标和语气。**

| 函数 | 图标 | 典型用途 |
|---|---|---|
| `showinfo(title, msg)` | 蓝色「i」 | "文件已保存" |
| `showwarning(title, msg)` | 黄色「!」 | "你有未保存的修改" |
| `showerror(title, msg)` | 红色「X」 | "无法打开文件" |
| `showinfo` 加 `parent=` | 任意 | 挂到某个具体窗口上 |

```
def save():
    # 假装保存……
    messagebox.showinfo("已保存", "你的文件已经保存好了。")

def check():
    messagebox.showwarning("提醒", "这将会覆盖旧文件。")

def fail():
    messagebox.showerror("出错", "没有权限：\n无法写入该文件夹。")
```

**第二个参数是消息正文，`\n` 会换行，所以你能写一小段话。** 别把堆栈跟踪往里塞——用户不想看，你也不该把内部细节暴露出去。一两句话，然后让用户点「确定」。

## 翻车现场一：忘记导入模块

```
import tkinter as tk

root = tk.Tk()

def clicked():
    messagebox.showinfo("嗨", "你好")   # WRONG: NameError
```

**`messagebox` 不是 Python 导入 `tkinter` 时自动带进来的子模块。** 必须自己引：

```
from tkinter import messagebox
```

这行很容易忘，因为 `tk.Button`、`tk.Label` 之类只用 `import tkinter as tk` 就能用。加上这行导入，错误就消失了。

## 提问函数会返回值

**`askyesno`、`askokcancel`、`askyesnocancel`、`askretrycancel` 不只是显示个框——它们会给你一个值，你能在分支里用。** 到这一步弹窗才不再只是装饰品，而开始控制程序逻辑。

```
from tkinter import messagebox

answer = messagebox.askyesno("删除", "确定删除这个文件吗？")
if answer:
    print("用户点了是")
else:
    print("用户点了否")
```

**`askyesno` 返回的就是普通 Python 的 `True` 或 `False`。** `askokcancel` 同样返回布尔值。`askretrycancel` 点「重试」返回 `True`，点「取消」返回 `False`。`askyesnocancel` 返回 `True`、`False` 或 `None`——`None` 表示用户点了窗口右上角的 X 关掉对话框，而不是选任何选项，所以第三个情况一定要处理。

```
result = messagebox.askyesnocancel("保存", "退出前是否保存修改？")
if result is True:
    save_and_quit()
elif result is False:
    quit_without_saving()
else:            # None
    pass         # 不退出，回到程序
```

## 翻车现场二：把返回值当字符串比

```
result = messagebox.askyesno("继续", "继续吗？")
if result == "yes":          # WRONG: 永远匹配不上
    do_it()
```

**对话框返回的是 `True`/`False`，不是按钮上写的文字。** 跟 `"yes"` 或 `"ok"` 比，分支永远不会执行，于是你什么都不做还毫无察觉。要跟 `True`、`False` 比；三按钮版本则用 `is None`。

## 把对话框钉到父窗口

**不带 `parent` 的对话框容易被别的窗口盖住，在 Windows 和 macOS 上尤其明显。** 传 `parent=root`（或者你主窗口变量的名字），弹窗就会一直贴着它。

```
messagebox.showerror(parent=root, title="哎呀", message="出错了")
```

**`parent` 参数必须放在第一个位置，或者用关键字形式。** 用关键字参数时 `parent` 写哪都行，这是最值得照抄的写法。它还会让对话框在父窗口中央弹出并变成模态——用户点主窗口也忽略不掉。

## 翻车现场三：`mainloop` 还没跑起来

```
import tkinter as tk
from tkinter import messagebox

root = tk.Tk()
messagebox.showerror("糟了", "出问题了")   # WRONG: 很多环境下都有问题
root.mainloop()
```

**如果你在 `mainloop()` 跑起来之前就弹对话框——比如在导入时或模块级初始化阶段——对话框可能显示出来但行为诡异，在某些系统上程序直接报错。** 安全规则：只在回调函数里，或者 `mainloop` 启动之后才弹对话框。要报告启动失败，就打印到控制台。

## 综合示例：退出前确认

**`askyesno` 的经典用法，就是在做危险操作前问一句。**

```
import tkinter as tk
from tkinter import messagebox

root = tk.Tk()
root.title("像记事本")
root.geometry("300x200")

def on_close():
    if messagebox.askyesno("退出", "确定不保存就退出吗？"):
        root.destroy()

root.protocol("WM_DELETE_WINDOW", on_close)
root.mainloop()
```

**`root.protocol("WM_DELETE_WINDOW", ...)` 让你能拦截右上角关闭按钮**，用你自己的函数替换默认行为。现在点 X 会先弹确认框，而不是立刻把窗口杀掉。

## 小结

- 显式导入模块：`from tkinter import messagebox`
- `showinfo`、`showwarning`、`showerror` 只是通知，不返回有用的值
- `askyesno` / `askokcancel` 返回 `True`/`False`；`askyesnocancel` 还可能返回 `None`
- 永远把返回值跟布尔值比，别跟按钮文字比
- 传 `parent=`，对话框才会贴住你的窗口
- 只在 `mainloop` 跑起来之后弹对话框，最好在回调函数里弹
