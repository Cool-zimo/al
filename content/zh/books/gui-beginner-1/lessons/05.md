# 实战：一个会打招呼的窗口

> 前面都是零散知识点，这一节把它们串起来：用 Entry（输入框）+ Button（按钮）+ Label（显示）做一个能互动的小程序。重点是"界面和逻辑怎么接起来"。

## 我们要做什么

**目标很朴素：用户输入名字，点按钮，程序说"你好，XXX"。**

```
界面布局（从上到下）：
[ 请输入你的名字: ]
[ ________________ ]   ← Entry 输入框
[ 问好 ]               ← Button 按钮
你好，张三             ← Label 显示结果
```

**三个控件各司其职：**

| 控件 | 角色 |
|---|---|
| Entry | 让用户输入 |
| Button | 触发动作 |
| Label | 显示结果 |

## 第一步：搭界面骨架

**先把三个控件摆上去，先不管交互：**

```
import tkinter as tk

root = tk.Tk()
root.title("打招呼程序")

tk.Label(root, text="请输入你的名字：").pack()

entry = tk.Entry(root)
entry.pack()

def greet():
    pass   # 先空着

tk.Button(root, text="问好", command=greet).pack()

result_label = tk.Label(root, text="")
result_label.pack()

root.mainloop()
```

**现在运行，界面出来了，但点按钮没反应。** 下一步让它活起来。

## 第二步：让按钮读到输入框的内容

**Entry 的 `get()` 方法能拿到用户输入的文字：**

```
def greet():
    name = entry.get()          # 读取输入框内容
    print("名字是：", name)     # 先打印到终端验证
```

**`entry.get()` 返回字符串。** 用户没输入时返回空字符串 `""`。

**问题来了：`greet` 函数里怎么拿到 `entry` 这个变量？** 因为 `entry` 是在外面定义的，函数里直接用它就行（它是全局变量，读不需要 `global`）。

## 第三步：把结果显示到 Label 上

**用 `result_label.configure(text=...)` 动态改文字：**

```
def greet():
    name = entry.get()
    result_label.configure(text=f"你好，{name}！")
```

**完整代码：**

```
import tkinter as tk

root = tk.Tk()
root.title("打招呼程序")

tk.Label(root, text="请输入你的名字：").pack()

entry = tk.Entry(root)
entry.pack()

result_label = tk.Label(root, text="")

def greet():
    name = entry.get()
    result_label.configure(text=f"你好，{name}！")

tk.Button(root, text="问好", command=greet).pack()
result_label.pack()

root.mainloop()
```

**运行：输入"张三"，点按钮，Label 显示"你好，张三！"。**

**这就是 GUI 程序的基本循环：用户输入 → 按钮触发 → 函数读取输入 → 更新界面。** 你以后写的每一个窗口程序，本质都是这个模式的放大版。

## Entry 的其他常用方法

**Entry 是单行输入框，方法不多但都要会用：**

| 方法 | 作用 |
|---|---|
| `get()` | 读取值（返回字符串） |
| `insert(index, string)` | 在指定位置插入文字 |
| `delete(start, end)` | 删除一段文字 |
| `delete(0, "end")` | 清空整个输入框 |
| `icursor(index)` | 设置光标位置 |
| `select_range(start, end)` | 选中一段文字 |

**清空输入框是个高频操作：**

```
entry.delete(0, "end")   # "end" 是 tkinter 定义的特殊位置
```

**`"end"` 是个字符串常量**，表示"末尾"。它比自己算长度方便得多。也可以 `from tkinter import END` 后写 `entry.delete(0, END)`。

## 给输入框设默认值

**程序启动时输入框里预填一段提示文字：**

```
entry.insert(0, "默认名字")
```

**改进打招呼程序：点完按钮顺便清空输入框，体验更好：**

```
def greet():
    name = entry.get()
    result_label.configure(text=f"你好，{name}！")
    entry.delete(0, "end")   # 清空，方便下次输入
```

## 翻车现场一：Entry 里读到的是字符串

```
def calc():
    a = entry.get()
    print(a + 10)   # TypeError: can only concatenate str (not "int") to str
```

**`entry.get()` 永远是字符串。** 要做数学运算必须转换：

```
def calc():
    a = int(entry.get())   # 或 float()
    print(a + 10)
```

**如果用户输入的不是数字，`int()` 会报 `ValueError`。** 后面第 29 课讲异常处理时会解决这个。现阶段知道要转换就行。

## 翻车现场二：按钮的 command 加了括号

```
tk.Button(root, text="问好", command=greet()).pack()
```

**症状**：程序一启动就立刻执行了 `greet()`，而且按钮点击毫无反应。

**原因**：`greet()` 后面带了括号，是**立刻调用**——在创建按钮的那一刻就执行了。而 `command` 要的是一个"函数对象"，等点击时才调用。

**修复**：去掉括号：

```
tk.Button(root, text="问好", command=greet).pack()
```

**记忆法**：`command=greet` 是"把函数交给按钮，以后再说"；`command=greet()` 是"现在就执行"。

## 翻车现场三：回调函数带参数写错

**想传参数给 `greet`？不能写 `command=greet("张三")`。** 正确写法要用 `lambda`（下一章会详细讲，这里先看结论）：

```
# 错误
tk.Button(root, text="问好", command=greet("张三")).pack()

# 正确
tk.Button(root, text="问好", command=lambda: greet("张三")).pack()
```

**`lambda` 创建一个"延迟执行"的小函数**，点击时才调用 `greet("张三")`。

## 翻车现场四：控件顺序和 pack 顺序

**`pack()` 按调用顺序从上到下排列：**

```
tk.Label(root, text="第一行").pack()
tk.Label(root, text="第二行").pack()
tk.Label(root, text="第三行").pack()
```

**颠倒代码顺序，界面就颠倒。** 所以界面布局其实就是"调整控件创建 + pack 的顺序"。想让 Label 显示结果，就得保证 `result_label` 在 `entry` 和 `button` 之后 pack。

**如果先 pack 了 result_label 再 pack 按钮，结果区就会夹在中间。** 这在只用 pack 的布局里很常见，遇到复杂界面就该用 grid（下一章）。

## 升级版：输入为空时给提示

**加个判断，用户没填名字时点按钮：**

```
def greet():
    name = entry.get().strip()   # strip 去掉首尾空格
    if name == "":
        result_label.configure(text="名字不能为空哦！", fg="red")
    else:
        result_label.configure(text=f"你好，{name}！", fg="black")
```

**`strip()` 很重要**：用户只敲了空格，逻辑上等同于没输入。

**临时改 `fg`（文字颜色）是个好用的反馈手段**，让用户一眼看到哪里错了。

## 再升级：按回车也能问好

**除了点按钮，让用户在输入框里按回车也触发问候：**

```
def greet():
    name = entry.get().strip()
    if name:
        result_label.configure(text=f"你好，{name}！", fg="black")
    else:
        result_label.configure(text="名字不能为空哦！", fg="red")

entry = tk.Entry(root)
entry.pack()
entry.bind("<Return>", lambda e: greet())   # 按回车也触发
```

**`bind` 的用法下一章会系统讲**，这里只要知道：`<Return>` 表示回车键，`lambda e: greet()` 里的 `e` 是事件对象，后面必须接收它。

## 一个常见结构：函数读、函数写

**把界面拆成"读取函数"和"写入函数"两个，是 tkinter 的好习惯：**

```
def read_input():
    return entry.get().strip()

def write_output(msg, color="black"):
    result_label.configure(text=msg, fg=color)

def greet():
    name = read_input()
    if name:
        write_output(f"你好，{name}！")
    else:
        write_output("名字不能为空哦！", "red")
```

**好处**：界面一变（比如换成弹窗显示），只改 `write_output` 一处就行，业务逻辑不用动。

## 完整成品

**下面是可运行的最终版本：**

```
import tkinter as tk

root = tk.Tk()
root.title("打招呼程序")
root.geometry("300x200")

tk.Label(root, text="请输入你的名字：").pack(pady=5)

entry = tk.Entry(root)
entry.pack(pady=5)
entry.focus_set()   # 启动后自动聚焦到输入框

result_label = tk.Label(root, text="")
result_label.pack(pady=5)

def greet():
    name = entry.get().strip()
    if name:
        result_label.configure(text=f"你好，{name}！", fg="black")
    else:
        result_label.configure(text="名字不能为空哦！", fg="red")
    entry.delete(0, "end")

tk.Button(root, text="问好", command=greet).pack(pady=5)
entry.bind("<Return>", lambda e: greet())

root.mainloop()
```

**`entry.focus_set()` 让程序启动时光标自动停在输入框里**，用户不用先点一下再打字，体验好很多。

## 小结

- 三个控件配合：**Entry 输入、Button 触发、Label 显示**
- `entry.get()` 读输入（永远是字符串，要数字得转 `int()`/`float()`）
- `entry.delete(0, "end")` 清空；`"end"` 是 tkinter 常量
- `label.configure(text=...)` 动态更新显示
- `command=greet`（**不加括号**），加括号是"立刻执行"
- 带参数的回调用 `lambda`；空输入用 `strip()` 判断
- `entry.focus_set()` 自动聚焦，提升体验
