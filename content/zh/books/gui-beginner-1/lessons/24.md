# 菜单：主菜单、下拉菜单与右键菜单

> 每一个真正的桌面程序顶部都有一条菜单栏：文件、编辑、帮助。`tkinter.Menu` 能造出这些，外加下拉子菜单和右键上下文菜单。学会"三步法"，三种菜单就全都出来了。

## 三步法：建、加、挂

**菜单也是一个控件，只是它住在窗口的框架里，而不是被 pack 进去。**

```
import tkinter as tk

root = tk.Tk()
root.title("菜单示例")
root.geometry("300x200")

menubar = tk.Menu(root)        # 1. 创建菜单栏
root.config(menu=menubar)      # 2. 挂到窗口上

def say_hello():
    print("你好！")

menubar.add_command(label="打招呼", command=say_hello)   # 3. 添加菜单项
menubar.add_command(label="退出", command=root.destroy)

root.mainloop()
```

**第 1 步创建一个挂在 `root` 上的 `Menu`。第 2 步用 `root.config(menu=...)` 告诉窗口把它当作菜单栏显示。第 3 步添加 `command` 项——每一项就是一个带标签、会触发回调的按钮。** 这就是全部骨架，剩下的都是它的变体。

## 翻车现场一：忘了 `root.config(menu=...)`

```
menubar = tk.Menu(root)
menubar.add_command(label="打招呼", command=say_hello)
# WRONG: 菜单栏永远不会显示
```

**菜单可以写得完美无缺，你却什么都看不到，因为真正把它放上屏幕的就那一行 `root.config(menu=menubar)`。** 如果你的菜单"不见了"，先找这一行。

## 下拉子菜单

**下拉菜单是第二个 `Menu`，用 `add_cascade` 而不是 `add_command` 挂到第一个上。**

```
import tkinter as tk

root = tk.Tk()
root.title("编辑器")

menubar = tk.Menu(root)
root.config(menu=menubar)

# 下拉菜单本身也是一个 Menu
file_menu = tk.Menu(menubar, tearoff=False)

def do_open():  print("打开")
def do_save():  print("保存")
def do_quit():  root.destroy()

file_menu.add_command(label="打开...", command=do_open)
file_menu.add_command(label="保存", command=do_save)
file_menu.add_separator()          # 一条横线
file_menu.add_command(label="退出", command=do_quit)

# cascade 把下拉菜单挂到菜单栏上
menubar.add_cascade(label="文件", menu=file_menu)

root.mainloop()
```

**`add_cascade(label=..., menu=...)` 是那座桥：它在菜单栏上放一个带标签的项，点击后展开你建好的子菜单。** `add_separator()` 画出那条细分隔线，把相关的命令归成一组——放在"退出"之前、破坏性操作之前，或任何有助于阅读的地方。

## `tearoff=False` 及其意义

**用 `tearoff=True`（默认）建的菜单，顶部会有一条虚线，允许用户把菜单拖出来变成一个独立浮窗。** 这在 90 年代还有点用；今天它大多只是让人困惑，还多出一个要绕过去的空位。

```
file_menu = tk.Menu(menubar, tearoff=False)
```

**设 `tearoff=False` 就能去掉那条虚线，让菜单表现得跟所有现代程序一样。** 零成本，还能让你的程序看起来不那么像博物馆藏品。

## 翻车现场二：`add_cascade` 参数写错

```
menubar.add_cascade(label="文件", file_menu)   # WRONG: TypeError
```

**`add_cascade` 要的是关键字参数 `label=` 和 `menu=`。** 把子菜单按位置传，或者名字写错，都会报错。正确写法是 `add_cascade(label="文件", menu=file_menu)`。

## 一条完整的菜单栏

**三个顶级菜单，就是把这个套路重复三遍。**

```
menubar = tk.Menu(root)
root.config(menu=menubar)

file_menu = tk.Menu(menubar, tearoff=False)
file_menu.add_command(label="打开", command=open_file)
file_menu.add_command(label="保存", command=save_file)
file_menu.add_separator()
file_menu.add_command(label="退出", command=root.destroy)
menubar.add_cascade(label="文件", menu=file_menu)

edit_menu = tk.Menu(menubar, tearoff=False)
edit_menu.add_command(label="剪切", command=cut)
edit_menu.add_command(label="复制", command=copy)
edit_menu.add_command(label="粘贴", command=paste)
menubar.add_cascade(label="编辑", menu=edit_menu)

help_menu = tk.Menu(menubar, tearoff=False)
help_menu.add_command(label="关于", command=show_about)
menubar.add_cascade(label="帮助", menu=help_menu)
```

**结构极其规整：一个下拉菜单对应一个 `Menu`，菜单栏上每一项下拉对应一个 `add_cascade`。** 等你能不假思索地打出这段，菜单就不再是特殊话题，而只是又一个布局活儿。

## 用 `bind` 和 `post` 做右键菜单

**上下文菜单就是在用户右键时，出现在鼠标位置上的菜单。**

```
import tkinter as tk

root = tk.Tk()
root.title("右键示例")

def cut():   print("剪切")
def copy():  print("复制")
def paste(): print("粘贴")

# 一个不带 tearoff、也不挂到任何菜单栏的菜单
context = tk.Menu(root, tearoff=False)
context.add_command(label="剪切", command=cut)
context.add_command(label="复制", command=copy)
context.add_command(label="粘贴", command=paste)

def show_menu(event):
    context.post(event.x_root, event.y_root)   # 在光标处弹出

# X11/macOS 上右键是 Button-3，某些配置下是 Button-2
root.bind("<Button-3>", show_menu)

root.mainloop()
```

**`event.x_root` 和 `event.y_root` 是光标在屏幕上的坐标，正好是 `post()` 想要的东西。** 菜单出现在鼠标位置，直到用户选中某项或点别处才会消失。

## 翻车现场三：`bind` 期待一个事件参数

```
root.bind("<Button-3>", show_menu)

def show_menu():                  # WRONG: 点击时 TypeError
    context.post(100, 100)
```

**`bind` 会不管你愿不愿意，都把一个 `event` 对象传给你的函数。** 处理函数必须接住这个参数，哪怕你不用它。把 `event` 作为第一个参数加上，错误就没了。

## 综合示例

**一个程序可以同时有菜单栏*和*右键菜单——它们是彼此独立的对象。**

```
import tkinter as tk
from tkinter import messagebox

root = tk.Tk()
root.title("菜单组合")

def about():
    messagebox.showinfo("关于", "一个菜单示例", parent=root)

menubar = tk.Menu(root, tearoff=False)
root.config(menu=menubar)
app_menu = tk.Menu(menubar, tearoff=False)
app_menu.add_command(label="关于", command=about)
app_menu.add_command(label="退出", command=root.destroy)
menubar.add_cascade(label="程序", menu=app_menu)

context = tk.Menu(root, tearoff=False)
context.add_command(label="清空", command=lambda: print("已清空"))
root.bind("<Button-3>", lambda e: context.post(e.x_root, e.y_root))

tk.Label(root, text="在任何地方右键试试").pack(padx=20, pady=40)

root.mainloop()
```

**注意右键菜单用 `lambda` 把事件传过去，而菜单栏的项直接指向函数。** 两种写法都行；`lambda e: ...` 只是把事件透传过去最省事的方式。

## 小结

- 三步法：创建 `Menu(root)`，调用 `root.config(menu=bar)`，再 `add_command` / `add_cascade`
- 下拉菜单是第二个 `Menu`，用 `add_cascade(label=, menu=)` 挂上
- `tearoff=False` 去掉顶部那条可拖出的虚线
- `add_separator()` 画分隔线，用来把相关项分组
- 上下文菜单是一个自由浮动的 `Menu`，在 `bind` 处理器里用 `.post(x_root, y_root)` 显示
- `bind` 绑定的处理器必须接收 `event` 参数
