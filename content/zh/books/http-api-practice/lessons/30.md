## 设计：先想清楚分几块

**不要一上来就写代码。** 先画模块：

```
reqcli.py
├── CONFIG        配置（base_url / token / timeout）
├── Client        HTTP 层：Session + 重试 + 发送
├── Formatter     把响应变成人能看的样子
├── History       记录请求历史
├── parse_command 把一行输入解析成 (method, path, params, headers, output)
└── main          REPL 主循环
```

**为什么要分**：每一块都能单独改。比如想换 HTTP 库，只动 `Client`；想换输出样式，只动 `Formatter`。

> **这是第 26 课"状态放在正确的层"的实践**：每个模块管自己的事，`Client` 不知道 `Formatter` 存在，`Formatter` 也不知道输入是怎么解析的。

## 第一步：配置

```python
import os

CONFIG = {
    "base_url": "https://api.github.com",
    "user_agent": "ReqCLI/1.0",
    "accept": "application/vnd.github+json",
    "token": os.environ.get("GITHUB_TOKEN", ""),   # ① 从环境变量读
    "timeout": 10,
    "max_retries": 2,
}
```

> **逐行拆解**
>
> - **① `os.environ.get(...)`**：**第 22 课的核心原则**——密钥绝不写进代码。
>   - 没配到就是空字符串，程序照样能跑（只是配额只有 60/小时，第 28 课）
>   - 用 `get(key, "")` 而不是 `os.environ[key]`，**后者在没配时直接 KeyError 崩溃**

**配置为什么用字典而不是一堆全局变量**：方便遍历（`config` 命令要打印全部），也方便以后改成读配置文件。

### set 命令

```python
def handle_set(arg):
    """set base_url https://api.example.com"""
    parts = arg.split(" ", 1)
    if len(parts) < 2:
        return "用法: set <key> <value>"

    key, value = parts[0].lower(), parts[1].strip()

    if key == "base_url":
        if not value.startswith("http"):      # ① 自动补协议
            value = "https://" + value
        CONFIG[key] = value.rstrip("/")       # ② 去掉结尾斜杠
        return f"✅ base_url = {CONFIG[key]}"

    elif key == "token":
        CONFIG[key] = value
        return f"✅ token 已更新 (长度 {len(value)})"    # ③ 不显示内容！

    elif key == "timeout":
        try:
            CONFIG["timeout"] = int(value)    # ④ 转换 + 校验
        except ValueError:
            return f"❌ timeout 必须是数字"
        return f"✅ timeout = {value}s"

    else:
        return f"❌ 未知配置: {key}"
```

> **逐行拆解**
>
> - **① 自动补 `https://`**：用户输 `api.example.com` 也能用。**这是"对用户宽容"**
> - **② `rstrip("/")`**：**关键**。base_url 结尾带不带 `/` 会导致拼出 `//users`（双斜杠）——**很多 API 会返回 404**。统一去掉结尾斜杠，拼接时再加
> - **③ 只显示长度**：**token 绝不回显到屏幕**（屏幕上会进日志、会被截图）
> - **④ `int(value)` 包 try**：用户输入是文本，必须转换并容错

## 第二步：HTTP 客户端（本课核心）

**这里是第 26 课（Session）+ 第 24 课（重试）+ 第 15 课（超时）的合体。**

```python
import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

class Client:
    """HTTP 客户端：管连接、重试、默认头"""

    def __init__(self):
        self.session = requests.Session()

        # ① 默认头（第 14 课）
        self.session.headers.update({
            "User-Agent": CONFIG["user_agent"],
            "Accept": CONFIG["accept"],
        })
        self._mount_adapter()

    def _mount_adapter(self):
        """配置重试和连接池"""
        retry = Retry(
            total=CONFIG["max_retries"],              # ② 重试次数（不含首次）
            backoff_factor=0.5,                        # ③ 指数退避
            status_forcelist=[429, 500, 502, 503, 504], # ④ 哪些状态码重试
            allowed_methods=["GET", "HEAD", "PUT", "DELETE", "OPTIONS"],  # ⑤ 幂等才重试
            raise_on_status=False,                     # ⑥ 重试完仍失败就正常返回
        )
        adapter = HTTPAdapter(max_retries=retry, pool_connections=10, pool_maxsize=10)
        self.session.mount("https://", adapter)        # ⑦ 必须在请求前 mount
        self.session.mount("http://", adapter)

    def request(self, method, path, params=None, headers=None, body=None):
        """
        发请求
        :return: (response, error_message)  error 为 None 表示成功
        """
        url = CONFIG["base_url"] + path                # ⑧ 拼接

        req_headers = {}
        if CONFIG["token"]:
            req_headers["Authorization"] = f"Bearer {CONFIG['token']}"   # ⑨ 只在有时加

        if headers:
            req_headers.update(headers)                 # ⑩ 用户传的优先

        try:
            r = self.session.request(
                method, url,
                params=params,          # ⑪ 查询参数（第 13 课）
                headers=req_headers,
                json=body,              # ⑫ 请求体自动序列化 + 设 Content-Type
                timeout=CONFIG["timeout"],   # ⑬ 永远设超时（第 15 课）
            )
            return r, None

        except requests.exceptions.Timeout:
            return None, f"⏱ 请求超时（{CONFIG['timeout']}秒）"
        except requests.exceptions.ConnectionError:
            return None, "🔌 连接失败（网络问题或 URL 错误）"
        except requests.exceptions.RequestException as e:
            return None, f"❌ 请求失败: {e}"
```

> **逐行拆解**
>
> - **① 默认头放在 Session 上**：之后每个请求自动带（第 26 课）
> - **② `total=2`**：**不含首次请求**，实际最多发 3 次（第 24 课讲过这个"差一"）
> - **③ `backoff_factor=0.5`**：退避序列 0s、0.5s、1.0s
> - **④ `status_forcelist`**：**只对这些状态码重试**。4xx 不重试（请求本身有错）
> - **⑤ `allowed_methods`**：**只重试幂等方法**。这是第 6 课（幂等性）的直接应用——**POST 不重试，否则可能重复下单**
> - **⑥ `raise_on_status=False`**：重试耗尽后**返回响应**而不是抛异常，这样我们能自己检查状态码
> - **⑦ `mount` 必须在请求前**（第 26 课的翻车四）
> - **⑨ token 只在有值时加**：没有 token 也能访问公开接口
> - **⑩ 用户 headers 后 update**：**用户传的覆盖默认的**（第 26 课的合并规则）
> - **⑪ `params=`**：requests 自动 URL 编码（第 13 课）
> - **⑫ `json=body`**：**自动 `json.dumps` 并设 `Content-Type: application/json`**（第 16 课）——**不要用 `data=json.dumps(body)`，那样还要手动设头**
> - **⑬ `timeout`**：**永远不能省**

### 为什么返回 (response, error) 而不是抛异常

```python
r, err = client.request("GET", "/users/Cool-zimo")
if err:
    print(err)        # ① 网络层错误
    return
if r.status_code >= 400:
    print(f"HTTP {r.status_code}")   # ② HTTP 层错误
```

**这样调用方不用写 try/except**。网络异常和 HTTP 错误码是两种东西，但**对调用方来说都是"这次请求没拿到想要的数据"**，用统一的返回更简洁。

## 第三步：格式化输出

**响应要让人一眼看懂。** 三个要点：状态码带语义、JSON 缩进、显示耗时。

```python
import json

STATUS_HINT = {          # ① 状态码 → 一句人话
    200: "成功", 201: "已创建", 204: "无内容",
    301: "永久重定向", 302: "临时重定向",
    400: "请求有误", 401: "未认证", 403: "禁止访问",
    404: "找不到", 429: "请求太频繁",
    500: "服务器错误", 502: "网关错误", 503: "服务不可用",
}

def format_response(r, elapsed):
    """把响应格式化成可读文本"""
    hint = STATUS_HINT.get(r.status_code, "")     # ② 查表，没有就空

    lines = [
        f"HTTP {r.status_code} {hint}  ({elapsed:.2f}s)",   # ③ 状态 + 耗时
        "-" * 50,
    ]

    # ④ 尝试解析 JSON
    try:
        obj = r.json()
        lines.append(json.dumps(obj, indent=2, ensure_ascii=False))  # ⑤ 缩进 + 不转义中文
    except ValueError:
        # 不是 JSON，原样输出
        lines.append(r.text.strip() or "(空响应体)")

    # ⑥ 限流信息（第 28 课）
    remaining = r.headers.get("X-RateLimit-Remaining")
    if remaining is not None:
        lines.append("")
        lines.append(f"📊 配额剩余: {remaining}/{r.headers.get('X-RateLimit-Limit', '?')}")

    return "\n".join(lines)
```

> **逐行拆解**
>
> - **① 状态码提示表**：见到 `429` 立刻知道是"太频繁"而不是去查文档
> - **② `.get(code, "")`**：**未知状态码返回空字符串**，不要崩
> - **③ 显示耗时**：这是**性能调试的第一手信息**——你的程序慢，是从这里看出来
> - **④ `r.json()` 要包 try**：**响应不一定是 JSON**（HTML 错误页、纯文本）。第 20 课的翻车三
> - **⑤ `indent=2, ensure_ascii=False`**：
>   - `indent=2` 缩进，人能读
>   - **`ensure_ascii=False`** —— 不加的话中文会变成 `\u4e2d\u6587`
> - **⑥ 显示配额**：**每次都看得到，就不会突然被限流才知道**（第 28 课的"主动检查"）

### 保存到文件

```python
def save_response(r, path):
    """把响应体存到文件"""
    try:
        # ① 判断是不是文本
        content_type = r.headers.get("Content-Type", "")
        if "json" in content_type or "text" in content_type:
            try:
                text = json.dumps(r.json(), indent=2, ensure_ascii=False)   # ② 美化后存
            except ValueError:
                text = r.text
            with open(path, "w", encoding="utf-8") as f:     # ③ 明确编码
                f.write(text)
        else:
            # 二进制：原样写（第 25 课）
            with open(path, "wb") as f:
                f.write(r.content)

        return f"✅ 已保存到 {path} ({len(r.content)} 字节)"

    except OSError as e:
        return f"❌ 保存失败: {e}"
```

> **逐行拆解**
>
> - **① 看 Content-Type 决定怎么处理**：JSON 美化后存（人要看），二进制原样存（不能改）
> - **③ `encoding="utf-8"`**：**必须显式指定**。不写会用系统默认编码，**在 Windows 上可能是 GBK，中文会乱码**（第 18 课的编码坑）
> - **`wb` 分支**：第 25 课——二进制用 `r.content` 和 `"wb"`
> - **`OSError`**：文件操作的所有错误（权限、路径不存在）都是它

## 第四步：历史记录

```python
from datetime import datetime

class History:
    """请求历史"""

    def __init__(self, max_size=100):
        self.entries = []
        self.max_size = max_size       # ① 上限，防止无限增长

    def add(self, method, url, status):
        self.entries.append({
            "time": datetime.now().strftime("%H:%M:%S"),
            "method": method,
            "url": url,
            "status": status,
        })
        if len(self.entries) > self.max_size:     # ② 超了就丢最老的
            self.entries.pop(0)

    def show(self, n=10):
        if not self.entries:
            return "  (暂无记录)"
        lines = []
        for e in self.entries[-n:]:               # ③ 只显示最近 n 条
            lines.append(f"  {e['time']} {e['method']:8s} {e['status']:6d}  {e['url']}")
        return "\n".join(lines)
```

> **逐行拆解**
>
> - **① `max_size=100`**：**内存里的列表不能无限增长**。跑一整天会攒几万条
> - **② `pop(0)` 丢最老的**：**这是"环形缓冲"的最简实现**
> - **③ `[-n:]`**：**切片取最后 n 条**。`-n` 当 n 大于长度时会从头取，不会越界（Python 切片的宽容之处）

## 第五步：命令解析（最容易出错的部分）

**这是整个程序最需要小心的地方。** 我们要把：

```
GET /users/Cool-zimo/repos -params={per_page:5,sort:created} > out.json
```

解析成：

```python
{
    "method": "GET",
    "path": "/users/Cool-zimo/repos",
    "params": {"per_page": 5, "sort": "created"},
    "headers": {},
    "output": "out.json",
}
```

### 难点一：`-params={per_page:5}` 不是合法 JSON

JSON 要求 key 加引号：`{"per_page": 5}`。**手输引号太痛苦**，所以我们要支持"裸 key"。

```python
import re

def auto_quote(s):
    """给裸 key 加引号: {a:1} → {"a":1}"""
    # ① 匹配 key 的位置：{ 或 , 之后，到 : 之前
    def repl(m):
        key = m.group(1)
        if key.startswith('"'):      # ② 已经有引号就不动
            return m.group(0)
        return f'"{key}":'

    # ③ 正则：({|,)\s*([^"{\[:,]+)\s*:
    pattern = re.compile(r'([{,]\s*)([^"\'{}\[\]:,\s]+)(\s*:)')
    return pattern.sub(lambda m: m.group(1) + '"' + m.group(2) + '"' + m.group(3), s)
```

**测试**：

```python
auto_quote("{per_page:5,sort:created}")
# '{"per_page":5,"sort":created}'    ← key 加了引号，但值 "created" 没有

# 值也要处理：把裸词变成字符串
auto_quote('{sort:created}')  # 还需要处理值
```

**完整版**（同时处理 key 和裸值）：

```python
def parse_loose_json(s):
    """解析"宽松 JSON"：key 可不加引号，字符串值可不加引号"""
    # ① 先给 key 加引号
    s = re.sub(r'([{,]\s*)([A-Za-z_][A-Za-z0-9_]*)(\s*:)', r'\1"\2"\3', s)

    # ② 给裸字符串值加引号（true/false/null/数字除外）
    def quote_value(m):
        v = m.group(2)
        if v in ("true", "false", "null") or re.match(r'^-?\d+(\.\d+)?$', v):
            return m.group(0)                    # ③ 已经是合法字面量
        return f'{m.group(1)}"{v}"'

    s = re.sub(r'(:\s*)([^"{}\[\],\s]+)', quote_value, s)

    return json.loads(s)      # ④ 现在能正常解析了
```

> **逐行拆解**
>
> - **① `[A-Za-z_][A-Za-z0-9_]*`**：**只给"看起来像标识符"的 key 加引号**。这样 `{a:1}` 变 `{"a":1}`，而 `{"a":1}` 因为已经有引号不匹配，不会被重复处理
> - **② 值处理**：`created` → `"created"`
> - **③ 排除字面量**：`true`/`false`/`null`/数字**不能加引号**，否则 `{"a": true}` 会变成 `{"a": "true"}`（字符串！）
> - **④ `json.loads`**：转换完后就是标准 JSON

**注意**：这个函数**不完美**——复杂的嵌套结构可能出问题。但对命令行手输的简单参数够用了。**工程上的取舍：够用就好，别追求完美。**

### 难点二：`>` 重定向

```python
def split_output(raw):
    """分离 '> file'"""
    if " > " in raw:                    # ① 要求两边有空格
        raw, output = raw.rsplit(" > ", 1)   # ② 从右边切，只切最后一个
        return raw.strip(), output.strip()
    return raw, None
```

> - **① `" > "` 带空格**：**避免把 URL 里的 `>` 或参数里的内容误判**
> - **② `rsplit(..., 1)`**：从右边找第一个，这样 `a > b > c` 会以最后一个 `>` 分割

### 难点三：URL 里的 `&`

**这是最容易埋雷的地方。** 如果你想支持 `&` 作为参数分隔符：

```
GET /x & python "print(1)"
```

**但 `params` 拼出来的 URL 里全是 `&`**：

```
https://api.github.com/repos?per_page=5&sort=created
```

**如果无脑 `if "&" in raw: split("&")`，搜索条件会被拦腰砍断，而且不报错。**

**正确做法**：只认**前后带空格的独立 `&`**。

```python
def has_separator(raw):
    """判断是否包含独立的 & 分隔符"""
    return " & " in raw          # ① 两边必须有空格
```

> - **① `" & "`**：紧贴字符的 `&`（URL 里的）不会被匹配
>
> **这个坑的教训**：**分隔符必须比内容里的字符"更严格"**。这是所有解析器设计的核心原则。

### 完整解析函数

```python
def parse_command(raw):
    """
    解析一行命令
    返回 dict: {method, path, params, headers, body, output}
    """
    raw, output = split_output(raw)

    parts = raw.split(None, 2)          # ① 最多切 3 段
    if len(parts) < 2:
        return None                      # ② 至少要有 method 和 path

    method = parts[0].upper()
    path = parts[1]
    result = {
        "method": method,
        "path": path if path.startswith("/") else "/" + path,   # ③ 自动补 /
        "params": None,
        "headers": None,
        "body": None,
        "output": output,
    }

    rest = parts[2] if len(parts) > 2 else ""

    # ④ 提取 -params={...}
    m = re.search(r'-params=(\{.*?\})(?:\s|$)', rest)
    if m:
        try:
            result["params"] = parse_loose_json(m.group(1))
        except Exception as e:
            return f"params 解析失败: {e}"

    # ⑤ 提取 -headers={...}
    m = re.search(r'-headers=(\{.*?\})(?:\s|$)', rest)
    if m:
        try:
            result["headers"] = parse_loose_json(m.group(1))
        except Exception as e:
            return f"headers 解析失败: {e}"

    # ⑥ 提取请求体（裸的 JSON）
    m = re.search(r'(\{.*\}|\[.*\])', rest)
    if m and method in ("POST", "PUT", "PATCH"):
        try:
            result["body"] = parse_loose_json(m.group(1))
        except Exception as e:
            return f"body 解析失败: {e}"

    return result
```

> **逐行拆解**
>
> - **① `split(None, 2)`**：`None` 表示按任意空白切，`2` 表示**最多切 2 次**（得到 3 段）。**这样 path 后面的内容保持完整**
> - **② 参数不足返回 None**：调用方要检查
> - **③ 自动补 `/`**：用户输 `users/xxx` 也能用。**又是"对用户宽容"**
> - **④⑤⑥ 正则提取**：`(\{.*?\})` 的 `?` 是**非贪婪**——匹配最短的 `{}`，避免把两个 `{}` 当成一个
> - **返回字符串表示错误**：**调用方用 `isinstance(result, dict)` 区分成功和失败**。这不是最优雅的设计（正常应该抛异常），但在这个小工具里够清晰

## 第六步：主循环

```python
def main():
    client = Client()
    history = History()

    print("""
╔══════════════════════════════════════╗
║   ReqCLI v1.0  -  HTTP 终端          ║
║   help 帮助  |  exit 退出            ║
╚══════════════════════════════════════╝
    """)

    while True:
        try:
            raw = input(">>> ").strip()      # ① strip 去掉首尾空格
        except (EOFError, KeyboardInterrupt):   # ② Ctrl+D / Ctrl+C
            print("\nbye~")
            break

        if not raw:
            continue                          # ③ 空输入跳过

        # ④ 内置命令
        cmd = raw.lower()
        if cmd in ("exit", "quit"):
            print("bye~ 👋")
            break
        elif cmd in ("help", "h", "?"):
            print(HELP_TEXT)
            continue
        elif cmd == "history":
            print(history.show())
            continue
        elif cmd == "config":
            for k, v in CONFIG.items():
                shown = f"******({len(v)})" if k == "token" and v else str(v)   # ⑤ 遮蔽 token
                print(f"  {k:15s} = {shown}")
            continue
        elif cmd.startswith("set "):
            print(handle_set(cmd[4:].strip()))
            continue

        # ⑥ 解析命令
        parsed = parse_command(raw)
        if parsed is None:
            print("❌ 用法: METHOD /path [-params={...}] [> file]")
            continue
        if isinstance(parsed, str):        # ⑦ 解析出错，parsed 是错误信息
            print(f"❌ {parsed}")
            continue

        # ⑧ 发请求
        import time
        start = time.time()
        r, err = client.request(
            parsed["method"], parsed["path"],
            params=parsed["params"],
            headers=parsed["headers"],
            body=parsed["body"],
        )

        if err:
            print(err)
            continue

        elapsed = time.time() - start
        history.add(parsed["method"], r.url, r.status_code)   # ⑨ 记录

        # ⑩ 输出
        if parsed["output"]:
            print(save_response(r, parsed["output"]))
        else:
            print(f"\n{format_response(r, elapsed)}\n")
```

> **逐行拆解**
>
> - **① `input().strip()`**：**必须 strip**，否则用户多打一个空格就匹配不上内置命令
> - **② `EOFError, KeyboardInterrupt`**：**Ctrl+D（管道输入结束）和 Ctrl+C（用户中断）都要优雅处理**。不捕获的话会打出一片红色 traceback，很难看
> - **③ 空输入跳过**：不然 `continue` 之后会走到解析，报一堆错
> - **④ 内置命令优先于请求解析**：因为 `config` 这种词不是 HTTP 方法
> - **⑤ 遮蔽 token**：**`config` 命令绝不能把 token 打出来**
> - **⑦ `isinstance(parsed, str)`**：这是前面设计的"返回字符串表示错误"的代价——**调用方要判断类型**。如果重做，这里应该改成抛异常
> - **⑨ `r.url`**：**requests 会记录最终 URL**（含拼好的查询参数）。用它比用原始 path 更有信息量
> - **⑩ 保存优先于打印**：有 `> file` 就不打印到屏幕（否则大响应会刷屏）

```python
#!/usr/bin/env python3
"""reqcli.py - 一个能用的 HTTP 命令行工具"""

import os
import re
import json
import time
from datetime import datetime

import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

# ================= 配置 =================
CONFIG = {
    "base_url": "https://api.github.com",
    "user_agent": "ReqCLI/1.0",
    "accept": "application/vnd.github+json",
    "token": os.environ.get("GITHUB_TOKEN", ""),
    "timeout": 10,
    "max_retries": 2,
}

STATUS_HINT = {
    200: "成功", 201: "已创建", 204: "无内容",
    301: "永久重定向", 302: "临时重定向",
    400: "请求有误", 401: "未认证", 403: "禁止访问",
    404: "找不到", 429: "请求太频繁",
    500: "服务器错误", 502: "网关错误", 503: "服务不可用",
}

HELP_TEXT = """
📌 请求:
  METHOD /path [-params={...}] [-headers={...}] [body] [> file]

📌 内置命令:
  help / h / ?    显示帮助
  config          显示当前配置
  set <k> <v>     修改配置 (base_url/token/timeout)
  history         最近 10 条请求
  exit / quit     退出
"""


# ================= HTTP 客户端 =================
class Client:
    def __init__(self):
        self.session = requests.Session()
        self.session.headers.update({
            "User-Agent": CONFIG["user_agent"],
            "Accept": CONFIG["accept"],
        })
        self._mount_adapter()

    def _mount_adapter(self):
        retry = Retry(
            total=CONFIG["max_retries"],
            backoff_factor=0.5,
            status_forcelist=[429, 500, 502, 503, 504],
            allowed_methods=["GET", "HEAD", "PUT", "DELETE", "OPTIONS"],
            raise_on_status=False,
        )
        adapter = HTTPAdapter(max_retries=retry, pool_connections=10, pool_maxsize=10)
        self.session.mount("https://", adapter)
        self.session.mount("http://", adapter)

    def request(self, method, path, params=None, headers=None, body=None):
        url = CONFIG["base_url"] + path
        req_headers = {}
        if CONFIG["token"]:
            req_headers["Authorization"] = f"Bearer {CONFIG['token']}"
        if headers:
            req_headers.update(headers)

        try:
            r = self.session.request(
                method, url, params=params, headers=req_headers,
                json=body, timeout=CONFIG["timeout"],
            )
            return r, None
        except requests.exceptions.Timeout:
            return None, f"⏱ 请求超时（{CONFIG['timeout']}秒）"
        except requests.exceptions.ConnectionError:
            return None, "🔌 连接失败"
        except requests.exceptions.RequestException as e:
            return None, f"❌ 请求失败: {e}"


# ================= 格式化 =================
def format_response(r, elapsed):
    hint = STATUS_HINT.get(r.status_code, "")
    lines = [f"HTTP {r.status_code} {hint}  ({elapsed:.2f}s)", "-" * 50]
    try:
        lines.append(json.dumps(r.json(), indent=2, ensure_ascii=False))
    except ValueError:
        lines.append(r.text.strip() or "(空响应体)")

    remaining = r.headers.get("X-RateLimit-Remaining")
    if remaining is not None:
        lines.append("")
        lines.append(f"📊 配额剩余: {remaining}/{r.headers.get('X-RateLimit-Limit','?')}")
    return "\n".join(lines)


def save_response(r, path):
    try:
        ctype = r.headers.get("Content-Type", "")
        if "json" in ctype or "text" in ctype:
            try:
                text = json.dumps(r.json(), indent=2, ensure_ascii=False)
            except ValueError:
                text = r.text
            with open(path, "w", encoding="utf-8") as f:
                f.write(text)
        else:
            with open(path, "wb") as f:
                f.write(r.content)
        return f"✅ 已保存到 {path}"
    except OSError as e:
        return f"❌ 保存失败: {e}"


# ================= 历史 =================
class History:
    def __init__(self, max_size=100):
        self.entries = []
        self.max_size = max_size

    def add(self, method, url, status):
        self.entries.append({
            "time": datetime.now().strftime("%H:%M:%S"),
            "method": method, "url": url, "status": status,
        })
        if len(self.entries) > self.max_size:
            self.entries.pop(0)

    def show(self, n=10):
        if not self.entries:
            return "  (暂无记录)"
        return "\n".join(
            f"  {e['time']} {e['method']:8s} {e['status']:6d}  {e['url']}"
            for e in self.entries[-n:]
        )


# ================= 解析 =================
def parse_loose_json(s):
    s = re.sub(r'([{,]\s*)([A-Za-z_][A-Za-z0-9_]*)(\s*:)', r'\1"\2"\3', s)

    def quote_value(m):
        v = m.group(2)
        if v in ("true", "false", "null") or re.match(r'^-?\d+(\.\d+)?$', v):
            return m.group(0)
        return f'{m.group(1)}"{v}"'

    s = re.sub(r'(:\s*)([^"{}\[\],\s]+)', quote_value, s)
    return json.loads(s)


def split_output(raw):
    if " > " in raw:
        raw, output = raw.rsplit(" > ", 1)
        return raw.strip(), output.strip()
    return raw, None


def parse_command(raw):
    raw, output = split_output(raw)
    parts = raw.split(None, 2)
    if len(parts) < 2:
        return None

    method = parts[0].upper()
    path = parts[1]
    result = {
        "method": method,
        "path": path if path.startswith("/") else "/" + path,
        "params": None, "headers": None, "body": None, "output": output,
    }
    rest = parts[2] if len(parts) > 2 else ""

    m = re.search(r'-params=(\{.*?\})(?:\s|$)', rest)
    if m:
        try:
            result["params"] = parse_loose_json(m.group(1))
        except Exception as e:
            return f"params 解析失败: {e}"

    m = re.search(r'-headers=(\{.*?\})(?:\s|$)', rest)
    if m:
        try:
            result["headers"] = parse_loose_json(m.group(1))
        except Exception as e:
            return f"headers 解析失败: {e}"

    m = re.search(r'(\{.*\}|\[.*\])', rest)
    if m and method in ("POST", "PUT", "PATCH"):
        try:
            result["body"] = parse_loose_json(m.group(1))
        except Exception as e:
            return f"body 解析失败: {e}"

    return result


# ================= 配置命令 =================
def handle_set(arg):
    parts = arg.split(" ", 1)
    if len(parts) < 2:
        return "用法: set <key> <value>"
    key, value = parts[0].lower(), parts[1].strip()

    if key == "base_url":
        if not value.startswith("http"):
            value = "https://" + value
        CONFIG[key] = value.rstrip("/")
        return f"✅ base_url = {CONFIG[key]}"
    elif key == "token":
        CONFIG[key] = value
        return f"✅ token 已更新 (长度 {len(value)})"
    elif key == "timeout":
        try:
            CONFIG["timeout"] = int(value)
        except ValueError:
            return "❌ timeout 必须是数字"
        return f"✅ timeout = {value}s"
    return f"❌ 未知配置: {key}"


# ================= 主循环 =================
def main():
    client = Client()
    history = History()

    print("""
╔══════════════════════════════════════╗
║   ReqCLI v1.0  -  HTTP 终端          ║
║   help 帮助  |  exit 退出            ║
╚══════════════════════════════════════╝
    """)

    while True:
        try:
            raw = input(">>> ").strip()
        except (EOFError, KeyboardInterrupt):
            print("\nbye~")
            break

        if not raw:
            continue

        cmd = raw.lower()
        if cmd in ("exit", "quit"):
            print("bye~ 👋")
            break
        elif cmd in ("help", "h", "?"):
            print(HELP_TEXT)
            continue
        elif cmd == "history":
            print(history.show())
            continue
        elif cmd == "config":
            for k, v in CONFIG.items():
                shown = f"******({len(v)})" if k == "token" and v else str(v)
                print(f"  {k:15s} = {shown}")
            continue
        elif cmd.startswith("set "):
            print(handle_set(cmd[4:].strip()))
            continue

        parsed = parse_command(raw)
        if parsed is None:
            print("❌ 用法: METHOD /path [-params={...}] [> file]")
            continue
        if isinstance(parsed, str):
            print(f"❌ {parsed}")
            continue

        start = time.time()
        r, err = client.request(
            parsed["method"], parsed["path"],
            params=parsed["params"], headers=parsed["headers"], body=parsed["body"],
        )
        if err:
            print(err)
            continue

        elapsed = time.time() - start
        history.add(parsed["method"], r.url, r.status_code)

        if parsed["output"]:
            print(save_response(r, parsed["output"]))
        else:
            print(f"\n{format_response(r, elapsed)}\n")


if __name__ == "__main__":
    main()
```

## 翻车现场

### 翻车一：base_url 结尾的斜杠

```python
# ❌ 用户 set base_url https://api.github.com/
CONFIG["base_url"] + "/users"     # https://api.github.com//users  ← 双斜杠
```

**现象**：404，或者服务器返回奇怪的结果。

**原因**：双斜杠在 URL 里是**有意义的**（不同路径）。

**教训**：**`rstrip("/")` 统一处理**。这也是为什么我们在 `handle_set` 里做了这件事。

### 翻车二：忘了 `ensure_ascii=False`

```python
# ❌
json.dumps({"name": "张三"})
# '{"name": "\\u5f20\\u4e09"}'    ← 中文变成转义序列
```

**现象**：输出的 JSON 里全是 `\uXXXX`，看不懂。

**原因**：`json.dumps` 默认 `ensure_ascii=True`，**把所有非 ASCII 字符转义**。

**教训**：**输出给人看的时候永远加 `ensure_ascii=False`**。

（**注意**：如果要通过网络传输或存文件给机器读，用默认 `True` 反而更安全——避免编码问题。**看用途决定。**）

### 翻车三：正则贪婪匹配吃掉两个参数

```python
# ❌ 贪婪
re.search(r'-params=(\{.*\})', "-params={a:1} -headers={b:2}")
# 匹配到: {a:1} -headers={b:2}     ← 把 headers 也吃进去了！

# ✅ 非贪婪
re.search(r'-params=(\{.*?\})', "-params={a:1} -headers={b:2}")
# 匹配到: {a:1}
```

**现象**：解析出的 params 内容莫名其妙包含了后面的东西。

**原因**：`.*` 是贪婪的，会匹配到**最后一个** `}`。

**教训**：**用 `.*?`（非贪婪）**。这是正则最常见的坑之一。

### 翻车四：内置命令和请求路径冲突

```python
# 用户输入
>>> get /config
```

**现象**：如果内置命令判断写的是 `if raw.startswith("config")`，这个请求会被当成 `config` 命令。

**原因**：**内置命令判断太宽松**。

**教训**：**内置命令要精确匹配**（`cmd == "config"`），而不是 `startswith`。我们的代码用的是 `cmd.startswith("set ")`（**带空格**），这就不容易和路径冲突。

### 翻车五：异常捕获顺序

```python
# ❌ 顺序错了
try:
    ...
except requests.exceptions.RequestException as e:    # ① 父类在前
    ...
except requests.exceptions.Timeout:                   # ② 子类在后，永远到不了
    ...
```

**现象**：超时错误被当成"一般请求失败"处理，提示信息不够准确。

**原因**：**`Timeout` 是 `RequestException` 的子类**。Python 按顺序匹配第一个能处理的 except。

**教训**：**子类在前，父类在后**。

## 小结

- **模块划分**：配置 / 客户端 / 格式化 / 历史 / 解析 / 主循环，各管各的
- **Client**：Session + `HTTPAdapter(max_retries=Retry(...))` + `mount` 在请求前 + **永远设 timeout**
- **`Retry` 的参数**：`total`（不含首次）、`status_forcelist`（只重试 5xx/429）、**`allowed_methods` 排除 POST**
- **token 从环境变量读，`config` 显示时遮蔽**
- **`base_url` 用 `rstrip("/")`，path 自动补 `/`**
- **JSON 输出用 `ensure_ascii=False`**；写文件要 `encoding="utf-8"`
- **正则用 `.*?` 非贪婪**，否则会吃掉后面的参数
- **分隔符必须带空格**（`" & "`、`" > "`），避免和 URL 里的字符冲突
- **异常捕获：子类在前，父类在后**
- **REPL 要处理 `EOFError` / `KeyboardInterrupt`**，否则 Ctrl+C 会打出 traceback
- ❌ 别忘 timeout；别重试 POST；别回显 token；别用贪婪正则；别把 `json=` 写成 `data=`

q: 在 requests 中发送 JSON 请求体，正确的做法是？
options:
- data=json.dumps(body)，并手动设置 Content-Type
- json=body，requests 会自动序列化并加上 Content-Type: application/json
- body=json.dumps(body)
- 直接把字典传给 data=
answer: 1

- POST 不幂等，超时后无法确认服务器是否已处理，自动重试可能造成重复下单、重复扣款
