# 21 Basic 认证：Base64 不是加密

> 这是三种认证方式里最简单的一种，也是**最容易被误解**的一种。很多人以为"Base64 编码了就是加密了"——不是，Base64 是**肉眼可见的明文换了一种写法**。这一课讲清它的原理、为什么必须配合 HTTPS、以及 `requests` 里怎么用。

## 认证和授权是两件事

先分清这两个词，它们经常被混用：

| | 英文 | 回答的问题 |
|---|---|---|
| **认证** | Authentication | **你是谁？** |
| **授权** | Authorization | **你能干什么？** |

- 刷门禁卡 → **认证**（证明你是员工）
- 门禁系统判断你能进哪些房间 → **授权**（你的权限范围）

**HTTP 的 `Authorization` 头虽然名字是"授权"，实际上传的大多是"认证凭证"**。这是历史命名问题，记住就行。

**这一课讲认证**（证明你是谁）。

## Basic 认证的工作原理

### 流程

```
1. 客户端请求一个需要登录的资源
   GET /private HTTP/1.1

2. 服务器返回 401，并告诉客户端怎么认证
   HTTP/1.1 401 Unauthorized
   WWW-Authenticate: Basic realm="Admin Area"
                             ↑ 告诉客户端用 Basic 方式

3. 客户端把"用户名:密码"拼起来，Base64 编码，放进头里重发
   GET /private HTTP/1.1
   Authorization: Basic Y29vbDpzZWNyZXQ=

4. 服务器解码，验证，通过就返回内容
```

### Base64 那一串是什么

```python
import base64

cred = "cool:secret"                              # ① 用户名:密码
encoded = base64.b64encode(cred.encode("utf-8"))  # ② Base64 编码
print(encoded)
# b'Y29vbDpzZWNyZXQ='
```

> **逐行拆解**
>
> - **①** 格式是 `用户名:密码`，**中间一个冒号**
> - **②** Base64 编码的**字节**（所以要先 encode）

**反过来看**：

```python
print(base64.b64decode("Y29vbDpzZWNyZXQ=").decode("utf-8"))
# cool:secret        ← 一眼就还原了
```

**这就是关键**：

> **Base64 不是加密，是编码。任何人拿到都能瞬间还原，不需要密钥。**

**为什么还要用它**？不是为了保密，是为了**让密码里可能有冒号、换行、非 ASCII 字符的内容能安全地放进 HTTP 头**（头部要求是 ASCII）。

### 一个重要的推论

> **Basic 认证在 HTTP（非 HTTPS）上等于把密码明文广播。**

因为中间人只要抓到请求，执行一次 `base64 -d` 就拿到密码了。

**所以**：**Basic 认证必须在 HTTPS 下使用**。这不是建议，是必须。

## requests 里怎么用

### 方式一：auth= 参数（推荐）

```python
import requests
from requests.auth import HTTPBasicAuth

r = requests.get(
    "https://httpbin.org/basic-auth/cool/secret",
    auth=HTTPBasicAuth("cool", "secret"),        # ① 显式写法
    timeout=10,
)
print(r.status_code)        # 200
```

> **①** `HTTPBasicAuth(用户名, 密码)`——`requests` 会帮你做 Base64 编码和拼头。

### 方式二：元组简写

```python
import requests

r = requests.get(
    "https://httpbin.org/basic-auth/cool/secret",
    auth=("cool", "secret"),        # ① 元组，效果和上面一样
    timeout=10,
)
```

> **①** **传一个 `(用户名, 密码)` 元组，`requests` 自动识别成 Basic 认证**。这是最简洁的写法。

### 验证它发出去的头

```python
import requests
import base64

r = requests.get(
    "https://httpbin.org/basic-auth/cool/secret",
    auth=("cool", "secret"),
    timeout=10,
)

print(r.request.headers.get("Authorization"))
# Basic Y29vbDpzZWNyZXQ=

# 自己验证一下
print(base64.b64decode("Y29vbDpzZWNyZXQ=").decode())
# cool:secret
```

**这就是"Base64 不是加密"的实证**——你从请求头里直接还原出了密码。

### 方式三：手动设头（不推荐，但要知道）

```python
import requests
import base64

cred = base64.b64encode(b"cool:secret").decode("ascii")
r = requests.get(
    url,
    headers={"Authorization": f"Basic {cred}"},      # 注意 "Basic " 后面的空格
    timeout=10,
)
```

**为什么不推荐**：多写几行，还要自己处理编码。**用 `auth=` 就好**。

但**知道它有用**，因为：
- 调试时能看懂 `Authorization: Basic xxx` 是什么
- 有些库没有 `auth=` 参数，你得手动来

### 方式四：Session 级别

```python
import requests

s = requests.Session()
s.auth = ("cool", "secret")        # ① 设到 Session 上

r1 = s.get(url1, timeout=10)       # 自动带
r2 = s.get(url2, timeout=10)       # 也自动带
```

> **①** `s.auth` 对该 Session 的所有请求生效。**适合整个 API 都用同一套凭证的场景**

## WWW-Authenticate 头

服务器返回 401 时**必须**带这个头（第 7 课讲过）：

```python
import requests

r = requests.get("https://httpbin.org/basic-auth/cool/secret", timeout=10)
# 不带认证

print(r.status_code)                              # 401
print(r.headers.get("WWW-Authenticate"))
# Basic realm="Fake Realm"
```

**`realm` 是什么**：一个"保护区域"的名字。浏览器会把它显示在登录框上：

```
网站要求你登录：
"Admin Area"  ← 这就是 realm
用户名: ____
密码:   ____
```

**它唯一的用途就是给人看**。**对程序没有意义**，你不用解析它。

## 密码里有特殊字符怎么办

```python
# 密码是 p@ss:word （含冒号）
auth = ("cool", "p@ss:word")
```

**有问题吗？** 没有。因为格式是**第一个冒号**分隔：

```
cool:p@ss:word
    ↑ 第一个冒号是分隔符，后面的都是密码的一部分
```

服务器按第一个冒号 split，所以密码里的冒号没问题。

**非 ASCII 密码呢**（比如中文密码）？

`requests` 会帮你做 UTF-8 编码再 Base64，所以能用。**但服务器那边可能处理不好**——很多老服务器假设是 Latin-1。

**建议**：**密码尽量用 ASCII**。这是和第 18 课文件名一样的原则。

## 什么时候用 Basic 认证

**优点**：
- 极简单，几行代码
- 几乎所有 HTTP 客户端和服务器都支持

**缺点**：
- **每次请求都要发密码**（没有"登录一次拿票据"的机制）
- 密码存在客户端内存/配置里
- 无法细粒度控制权限（只能"能访问"或"不能"）
- 没有过期机制

**适用场景**：
- 内部工具、测试环境
- 简单的 API（比如路由器的管理接口）
- **配合 HTTPS** 的简单服务

**不适合**：
- 面向用户的产品（该用 OAuth）
- 需要细粒度权限的（该用 Token）

## 翻车现场

### 翻车一：在 HTTP 上用 Basic

```python
# ❌ 危险
r = requests.get("http://api.example.com/private", auth=("cool", "secret"))
```

**现象**：能用，测试全过。直到某天有人在同一 WiFi 下抓包。

**原因**：Base64 是编码不是加密，明文传输等于广播密码。

**教训**：**Basic 认证必须 HTTPS**。写代码时检查 URL 开头是不是 `https://`。

### 翻车二：把凭证写进代码并提交到 Git

```python
# ❌ 灾难
USERNAME = "admin"
PASSWORD = "SuperSecret123"
r = requests.get(url, auth=(USERNAME, PASSWORD), timeout=10)
```

**现象**：代码能跑。然后你把仓库推到 GitHub。**凭证永久留在 git 历史里**，即使后来删掉也能从历史中翻出来。

**而且**：GitHub 有自动扫描，**公开的 token 会在几分钟内被机器人发现并利用**。

**正确做法**：

```python
import os

username = os.environ.get("API_USER")      # ① 从环境变量读
password = os.environ.get("API_PASS")

if not username or not password:            # ② 检查
    raise RuntimeError("请设置 API_USER 和 API_PASS 环境变量")

r = requests.get(url, auth=(username, password), timeout=10)
```

> **① `os.environ.get()`** 从环境变量读。**代码里不出现任何凭证**
> **②** 缺失时立刻报错，而不是带着 `None` 去发请求

**设置环境变量**：

```bash
export API_USER=admin
export API_PASS=SuperSecret123
python my_script.py
```

**更进一步的方案**：用 `.env` 文件（配合 `python-dotenv` 库），但**必须把 `.env` 加进 `.gitignore`**。

### 翻车三：Bearer 写成 Basic

```python
# ❌ 错误
r = requests.get(url, auth=("token", "ghp_xxxx"), timeout=10)
# 生成的是 Basic 认证头，但对方要的是 Bearer
```

**现象**：401。你确认 token 是对的。

**原因**：第 14 课讲过——**`Bearer xxx` 和 `Basic xxx` 是两种不同的认证方案**，格式完全不同：

```
Basic:  Authorization: Basic base64(用户名:密码)
Bearer: Authorization: Bearer ghp_xxxx
```

**教训**：**看文档确认是哪种**。混淆这两种是 401 的常见原因。

## 为什么这对你写代码有用

1. **Base64 是编码不是加密**——这是本课最重要的一条。任何人都能还原
2. **Basic 认证必须配 HTTPS**，否则等于明文广播密码
3. **用 `auth=(user, pass)` 元组**，最简单
4. **`s.auth` 设一次全站生效**
5. **凭证永远不要写进代码**，用环境变量
6. **分清 Basic 和 Bearer**——混淆会导致 401

## 小结

- **认证 = 你是谁；授权 = 你能干什么**。`Authorization` 头传的通常是认证凭证
- **Basic 认证流程**：请求 → 401 + `WWW-Authenticate` → 带 `Authorization: Basic base64(user:pass)` 重发
- **Base64 是编码不是加密**，无密钥、可瞬间还原。**它只是让密码能安全放进 HTTP 头**
- **Basic 必须配 HTTPS**，否则等于明文广播
- **`auth=("user", "pass")` 元组最简洁**；`HTTPBasicAuth` 显式等价
- **`s.auth = (...)`** 设一次，全 Session 生效
- **`WWW-Authenticate` 的 `realm` 只给人看**，程序不用解析
- **密码里的冒号没问题**（按第一个冒号分隔）；**非 ASCII 密码可能出问题**
- ❌ **别在 http 上用 Basic**；**别把凭证写进代码**（用 `os.environ`）；**别把 Basic 和 Bearer 搞混**

  def parse_basic_header(header):
      # 提示：检查前缀，取出后半部分，base64 解码，按第一个冒号 split
