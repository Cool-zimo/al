# 实战：项目备份工具

> 这一课把第 4~5 章的知识串起来：用 `pathlib` 遍历目录、`fnmatch` 过滤排除规则、`tarfile`/`zipfile` 打包归档、日期戳命名、模拟校验和。你会做一个能用的命令行备份工具。

## 需求分析

我们要做一个项目备份工具，功能如下：

- 把指定目录打包成带**日期戳**的压缩包：`myproject_20260928_143000.tar.gz`
- 支持**排除规则**：跳过 `__pycache__`、`.git`、`*.pyc`、`node_modules` 等
- 输出**备份清单**：记录哪些文件被纳入、总大小、压缩率
- 生成**校验信息**：用模拟的校验和确认归档完整性

**设计思路**：把所有文件系统交互抽象成"接收目录列表 → 返回备份计划"的纯函数，方便测试。

## 完整代码

```python
import hashlib
from datetime import datetime
from pathlib import Path


# 默认排除规则（fnmatch 模式）
DEFAULT_EXCLUDES = [
    "__pycache__", "*.pyc", "*.pyo", ".git", ".svn",
    "node_modules", "*.tmp", ".DS_Store",
]


def should_exclude(rel_path, exclude_patterns):
    """判断相对路径是否命中任一排除模式"""
    from fnmatch import fnmatch
    import os
    parts = rel_path.split(os.sep)
    for pat in exclude_patterns:
        # 匹配完整路径或任意一段
        if fnmatch(rel_path, pat) or any(fnmatch(p, pat) for p in parts):
            return True
    return False


def build_backup_plan(root, files, excludes=None):
    """构建备份计划：返回被纳入的文件列表（相对路径）"""
    excludes = excludes or DEFAULT_EXCLUDES
    included = []
    for f in files:
        if not should_exclude(f, excludes):
            included.append(f)
    return included


def make_archive_name(root, fmt="tar.gz"):
    """生成带日期戳的归档名"""
    ts = datetime.now().strftime("%Y%m%d_%H%M%S")
    stem = Path(root).name or "backup"
    return f"{stem}_{ts}.{fmt}"


def simulate_archive(included, content_sizes):
    """模拟打包：接收纳入的文件列表和对应的内容大小，返回归档摘要。
    content_sizes: dict，相对路径 -> 字节大小"""
    total_raw = sum(content_sizes.get(f, 0) for f in included)
    # 文本类压缩到 30%，媒体类几乎不压——这里简化：统一按 0.5 估算
    estimated = int(total_raw * 0.5)
    return {
        "file_count": len(included),
        "total_raw_bytes": total_raw,
        "estimated_bytes": estimated,
        "compression_ratio": (estimated / total_raw) if total_raw else 0,
    }


def make_manifest(included, content_sizes):
    """生成备份清单（模拟校验和）"""
    manifest = []
    for f in included:
        size = content_sizes.get(f, 0)
        # 模拟校验和：真实场景用 hashlib.sha256(open(f,'rb').read()).hexdigest()
        fake_hash = hashlib.md5(f.encode("utf-8")).hexdigest()[:12]
        manifest.append({"path": f, "size": size, "checksum": fake_hash})
    return manifest
```

## 逐个函数拆解

`should_exclude` 是核心：一个文件只要**完整路径**或**任意一段目录名**命中排除模式，就被跳过。这样 `__pycache__/x.py` 会被命中，`.git/config` 也会被命中。

```python
from fnmatch import fnmatch
import os

print(should_exclude("__pycache__/x.py", DEFAULT_EXCLUDES))   # True
print(should_exclude("src/main.py", DEFAULT_EXCLUDES))       # False
print(should_exclude("data/.DS_Store", DEFAULT_EXCLUDES))    # True
```

`build_backup_plan` 把"遍历目录"和"过滤规则"分开——遍历由外部提供文件列表，函数只负责过滤，方便测试。

`simulate_archive` 做体积预估。`compression_ratio` 直接给出"压到几成"的直观数字。

## 翻车现场：排除规则只匹配文件名，漏掉目录

```python
from fnmatch import fnmatch

# WRONG：只拿 basename 去匹配
files = ["src/main.py", "__pycache__/x.py", ".git/config", "src/util.py"]
excludes = ["__pycache__", "*.pyc", ".git"]

result = [f for f in files if not fnmatch(Path(f).name, excludes[0])]
print(result)
# ['src/main.py', '__pycache__/x.py', '.git/config', 'src/util.py']
# __pycache__/x.py 还在！因为匹配的是 "x.py" 而不是 "__pycache__"
```

只匹配 basename 会**漏掉目录名匹配**。正确做法是对完整相对路径和每一段目录名都做检查——也就是上面 `should_exclude` 的逻辑。

## 翻车现场：时间戳精度不够，归档名撞车

一分钟甚至一秒内跑两次备份，会生成同名归档——第二次直接覆盖第一次，第一次的备份悄无声息地没了。

```python
from datetime import datetime

# WRONG：只用到秒的时间戳
ts = datetime.now().strftime("%Y%m%d_%H%M%S")
archive = f"backup_{ts}.tar.gz"
print(archive)
# backup_20260928_143000.tar.gz
# 一秒内再跑一次，名字完全一样 → 覆盖！
```

```python
from datetime import datetime

# 正确：加微秒，几乎不可能撞车
ts = datetime.now().strftime("%Y%m%d_%H%M%S_%f")
archive = f"backup_{ts}.tar.gz"
print(archive)
# backup_20260928_143000_412831.tar.gz
```

微秒在多数场景足够唯一。如果还要保证"同一目录多次备份互不覆盖"，更稳妥的是先探测：

```python
from pathlib import Path
from datetime import datetime

def unique_archive_name(directory, stem, ext):
    """生成目录内不重复的时间戳归档名"""
    base = Path(directory)
    i = 0
    while True:
        ts = datetime.now().strftime("%Y%m%d_%H%M%S_%f")
        name = f"{stem}_{ts}{ext}" if i == 0 else f"{stem}_{ts}_{i}{ext}"
        if not (base / name).exists():
            return name
        i += 1

# 模拟（不真查文件系统）
print(unique_archive_name("/tmp", "backup", ".tar.gz"))
```

这样即使时间戳意外重复，也能靠自增编号兜底。

## 实战演示：完整流程

```python
# 模拟一个项目目录的文件列表（相对路径）
project_files = [
    "main.py", "README.md", "requirements.txt",
    "src/util.py", "src/model.py",
    "__pycache__/util.cpython-311.pyc",
    ".git/config", ".git/HEAD",
    "data/notes.txt",
    "node_modules/left-pad/index.js",
]

# 模拟每个文件的大小
sizes = {
    "main.py": 2_000,
    "README.md": 500,
    "requirements.txt": 100,
    "src/util.py": 1_500,
    "src/model.py": 3_000,
    "data/notes.txt": 800,
    ".git/config": 300,
    "__pycache__/util.cpython-311.pyc": 1_200,
    "node_modules/left-pad/index.js": 5_000,
}

# 1. 构建备份计划
included = build_backup_plan(".", project_files)
print("纳入备份的文件:")
for f in included:
    print(f"  {f}")
# main.py / README.md / requirements.txt / src/util.py / src/model.py / data/notes.txt

# 2. 生成归档名
print("归档名:", make_archive_name("./myproject"))

# 3. 模拟打包摘要
summary = simulate_archive(included, sizes)
print("摘要:", summary)

# 4. 生成清单
manifest = make_manifest(included, sizes)
print(f"清单含 {len(manifest)} 条记录")
```

输出：

```
纳入备份的文件:
  main.py
  README.md
  requirements.txt
  src/util.py
  src/model.py
  data/notes.txt
归档名: myproject_20260928_143000.tar.gz
摘要: {'file_count': 6, 'total_raw_bytes': 7900, ...}
清单含 6 条记录
```

## 小结

- 备份工具三件套：遍历目录 → 按 fnmatch 排除 → 打包归档
- 排除规则要匹配**完整路径和每一段目录名**，只匹配 basename 会漏
- 归档命名用 `YYYYMMDD_HHMMSS` 时间戳，排序即时间序
- 备份清单 + 校验和，是"能回滚、能验证"的关键
- 文件系统操作抽成纯函数，测试时用模拟列表即可
