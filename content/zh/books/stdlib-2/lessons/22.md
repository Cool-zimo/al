# tarfile：tar.gz / tar.bz2 / tar.xz 的选择

> 这一课讲 Python 的 `tarfile` 模块，以及 `.tar.gz`、`.tar.bz2`、`.tar.xz` 三种后缀的区别与选择。你会学会如何根据场景挑压缩格式。

## tar 是什么

`tar`（tape archive）本身只是把多个文件**打包**成一个文件，**不带压缩**。压缩是外面再套一层算法：`.tar.gz` = tar + gzip，`.tar.bz2` = tar + bzip2，`.tar.xz` = tar + xz。

```python
import tarfile

# 创建 tar.gz
with tarfile.open("backup.tar.gz", "w:gz") as tf:
    tf.add("project", arcname="project")

# 创建 tar.bz2（更高压缩率，更慢）
with tarfile.open("backup.tar.bz2", "w:bz2") as tf:
    tf.add("project", arcname="project")

# 创建 tar.xz（最高压缩率，最慢）
with tarfile.open("backup.tar.xz", "w:xz") as tf:
    tf.add("project", arcname="project")
```

模式字符串的规律：`w:gz` / `w:bz2` / `w:xz`，对应三种压缩算法。

## 读取与解压

```python
import tarfile

with tarfile.open("backup.tar.gz", "r:gz") as tf:
    # 列出所有条目
    for m in tf.getmembers():
        print(m.name, m.size, "目录" if m.isdir() else "文件")

    # 读单个文件的内容
    f = tf.extractfile("project/README.md")
    if f:
        print(f.read().decode("utf-8"))

    # 解压全部
    tf.extractall(path="restored")
```

`getmembers()` 返回 `TarInfo` 对象，包含权限位、所有者、修改时间等 Unix 元数据——这是 tar 相比 zip 的一大优势（保留权限、软链接、设备文件）。

## 三种格式的区别

| 格式 | 压缩率 | 速度 | 典型场景 |
|------|--------|------|---------|
| `.tar.gz`（gzip） | 中 | 快 | **默认选择**，日常备份、源码发布 |
| `.tar.bz2`（bzip2） | 较高 | 较慢 | 需要更省空间、不赶时间 |
| `.tar.xz`（xz/LZMA） | 最高 | 最慢 | 归档存档、最小化体积 |

```python
import time

# 小文件用 gz 就够了，xz 的优势在大文件上才明显
data = b"x" * 10_000_000

for fmt, mode in [("gz", "w:gz"), ("bz2", "w:bz2"), ("xz", "w:xz")]:
    t0 = time.time()
    with tarfile.open(f"test.{fmt}", mode) as tf:
        import io
        tf.addfile(tarfile.TarInfo(name="big.bin"), io.BytesIO(data))
    print(f"{fmt}: {time.time()-t0:.2f}s")
```

一般规则：**默认 `.tar.gz`**，体积优先选 `.tar.xz`，传输带宽优先也选 `.tar.xz`。

## 翻车现场：模式字符串写错

```python
import tarfile

# WRONG：模式写成了 zip 的
with tarfile.open("backup.tar.gz", "w") as tf:
    tf.add("project")
# 如果文件已存在且是合法 tar，会打开它；否则行为取决于文件类型
```

更常见的是读写模式不匹配：

```python
import tarfile

# WRONG：用读模式去写
with tarfile.open("new.tar.gz", "r:gz") as tf:
    tf.add("project")
```

报错：

```
ReadError: file could not be opened for reading
```

模式字符串里**冒号前**是操作（`r`/`w`/`x`/`a`），**冒号后**是压缩算法（`gz`/`bz2`/`xz`/`''` 表示不压缩）。写就写 `w:xxx`，读就写 `r:xxx`。

## 翻车现场：tar 也有路径穿越问题

和 zip 一样，tar 里的恶意条目可以是 `../../etc/passwd`。

```python
import tarfile

# WRONG：直接解压不可信 tar
with tarfile.open("untrusted.tar.gz", "r:gz") as tf:
    tf.extractall(path="out")
```

Python 3.12+ 的 `tarfile` 已默认做了部分防护，但更稳妥的是自己校验：

```python
from pathlib import Path
import tarfile

def safe_extract_tar(tf, target_dir):
    target = Path(target_dir).resolve()
    for member in tf.getmembers():
        dest = (target / member.name).resolve()
        if not str(dest).startswith(str(target) + str(Path.sep)):
            raise ValueError(f"危险路径，拒绝解压: {member.name}")
        tf.extract(member, path=target)

with tarfile.open("untrusted.tar.gz", "r:gz") as tf:
    safe_extract_tar(tf, "out")
```

另外注意 `member.islink()` / `member.issym()` 的软链接：解压软链接可能指向系统任意文件，需要额外判断。

## 实战：自动选择压缩格式

```python
import tarfile
import io

def make_archive(data_map, fmt="gz"):
    """接收一个 {文件名: 内容字节} 的字典，返回归档字节（不写磁盘）。
    fmt 为 'gz' / 'bz2' / 'xz'。"""
    buf = io.BytesIO()
    mode = f"w:{fmt}"
    with tarfile.open(fileobj=buf, mode=mode) as tf:
        for name, content in data_map.items():
            info = tarfile.TarInfo(name=name)
            info.size = len(content)
            tf.addfile(info, io.BytesIO(content))
    return buf.getvalue()

# 模拟调用（不真写磁盘）
data = {"report.txt": b"2026 Q3 财报", "data.csv": b"1,2,3\n4,5,6\n"}
result = make_archive(data, "gz")
print(f"归档大小: {len(result)} 字节")   # 压缩后的字节数
```

这个函数在测试、网络传输场景很有用——`fileobj=BytesIO()` 让归档直接活在内存里，不必落盘。

## 小结

- `tar` 只打包不压缩，压缩靠外面的 gzip/bzip2/xz
- 模式字符串：`w:gz` / `w:bz2` / `w:xz`，读写对应 `r:gz` 等
- `.tar.gz` 是默认选择；`.tar.xz` 压缩率最高但最慢
- `getmembers()` 返回 `TarInfo`，保留 Unix 权限、所有者等元数据
- tar 同样有路径穿越问题，解压不可信归档前要校验
- `fileobj=BytesIO()` 可让归档活在内存中，适合测试和网络传输
