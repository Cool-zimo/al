# 格式化：strftime 与 strptime

> 这一课解决"日期对象怎么变成字符串给人看、字符串怎么变成日期对象"。你会记住最常用的占位符，以及 `%` 在 strftime 里必须转义的坑。

## strftime：日期 → 字符串

`strftime`（string format time）把 date/datetime 对象**格式化**成人类可读的字符串。

```python
from datetime import datetime

now = datetime(2026, 9, 27, 14, 30, 5)
print(now.strftime("%Y-%m-%d"))              # 2026-09-27
print(now.strftime("%Y/%m/%d %H:%M"))        # 2026/09/27 14:30
print(now.strftime("%Y年%m月%d日 %H:%M:%S"))  # 2026年09月27日 14:30:05
```

## 最常用的占位符速查表

| 占位符 | 含义 | 示例 |
|---|---|---|
| `%Y` | 四位年份 | 2026 |
| `%y` | 两位年份 | 26 |
| `%m` | 两位月份 | 09 |
| `%d` | 两位日期 | 27 |
| `%H` | 24小时制小时 | 14 |
| `%I` | 12小时制小时 | 02 |
| `%M` | 分钟 | 30 |
| `%S` | 秒 | 05 |
| `%A` | 星期全名（英文） | Sunday |
| `%a` | 星期缩写 | Sun |
| `%B` | 月份全名（英文） | September |
| `%p` | AM/PM | PM |

```python
from datetime import datetime
d = datetime(2026, 9, 27, 14, 30)

print(d.strftime("%A, %B %d, %Y"))       # Sunday, September 27, 2026
print(d.strftime("%Y%m%d_%H%M%S"))       # 20260927_143000（常用于文件名）
```

## strptime：字符串 → 日期

`strptime`（string parse time）是 strftime 的反向操作：把**字符串**按指定格式**解析**成 datetime 对象。

```python
from datetime import datetime

s = "2026-09-27 14:30:00"
dt = datetime.strptime(s, "%Y-%m-%d %H:%M:%S")
print(dt)               # 2026-09-27 14:30:00
print(type(dt))         # <class 'datetime.datetime'>
```

注意 strptime 的参数是**（字符串, 格式）**——顺序是"数据在前，格式在后"。

## 翻车现场：% 在 strftime 里必须转义

这是非常经典且容易踩的坑：

```python
from datetime import datetime

now = datetime(2026, 9, 27, 14, 30)

# WRONG：想在输出里放一个百分号 %
print(now.strftime("%Y-%m-%d %H:%M:%S 完成度 50%"))
```

报错：

```
ValueError: Invalid format string
```

`%` 在格式字符串里有特殊含义（它引导占位符），所以**字面量的 `%` 必须写成 `%%`**：

```python
# 正确
print(now.strftime("%Y-%m-%d %H:%M:%S 完成度 50%%"))
# 2026-09-27 14:30:00 完成度 50%
```

同理，想输出 `%Y` 字面量（而不是年份），也要写 `%%Y`。

## 翻车现场：格式串和实际字符串不匹配

```python
from datetime import datetime

# WRONG：格式串写的是 %Y/%m/%d，实际字符串是 - 分隔
datetime.strptime("2026-09-27", "%Y/%m/%d")
```

报错：

```
ValueError: time data '2026-09-27' does not match format '%Y/%m/%d'
```

格式串的分隔符、顺序、数量必须和输入字符串**完全一致**。格式串是模板，不是"模糊匹配"。

## 实战例子：日志文件名生成

```python
from datetime import datetime

def make_log_filename(app_name):
    """生成带时间戳的日志文件名"""
    now = datetime.now()
    ts = now.strftime("%Y%m%d_%H%M%S")
    return f"{app_name}_{ts}.log"

print(make_log_filename("支付服务"))
# 支付服务_20260927_143005.log
```

这种 `YYYYMMDD_HHMMSS` 格式的好处：按文件名排序就是按时间排序，一目了然。

## 实战例子：解析多种格式的输入

用户可能输入各种格式的日期，第 09 课会讲更完整的容错方案，这里先给一个简单框架：

```python
from datetime import datetime

def parse_date_flexible(s):
    formats = [
        "%Y-%m-%d",
        "%Y/%m/%d",
        "%Y年%m月%d日",
        "%m/%d/%Y",
    ]
    for fmt in formats:
        try:
            return datetime.strptime(s, fmt)
        except ValueError:
            continue
    raise ValueError(f"无法解析日期: {s}")

print(parse_date_flexible("2026-09-27"))     # 2026-09-27 00:00:00
print(parse_date_flexible("09/27/2026"))     # 2026-09-27 00:00:00
print(parse_date_flexible("2026年09月27日"))  # 2026-09-27 00:00:00
```

用 try/except 逐个尝试格式，是处理"不确定输入格式"的标准套路。

## 小结

- `strftime(格式串)`：日期对象 → 字符串；`strptime(字符串, 格式串)`：字符串 → 日期对象
- 常用占位符：`%Y %m %d %H %M %S`（年 月 日 时 分 秒）
- **`%` 是特殊字符**，想输出字面量 `%` 必须写成 `%%`
- strptime 的格式串必须和输入**精确匹配**（分隔符、顺序都不能错）
- 处理不确定格式：用 try/except 循环尝试多种格式
