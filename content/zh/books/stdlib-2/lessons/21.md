# zipfile：创建与读取 zip 归档

> 这一课讲 Python 标准库里的 `zipfile` 模块。你会学会创建 zip、列出内容、读取单个文件、解压，以及密码保护的现实局限。

## 创建 zip：ZipFile + write

```python
import zipfile

with zipfile.ZipFile("archive.zip", "w", zipfile.ZIP_DEFLATED) as zf:
    zf.write("report.pdf")
    zf.write("data/notes.csv", arcname="notes.csv")   # 自定义归档内的路径
```

`ZIP_DEFLATED` 是压缩算法（deflate），最常用的一种。还有 `ZIP_STORED`（不压缩，仅打包）和 `ZIP_BZIP2` / `ZIP_LZMA`（更高压缩率但更慢）。

`arcname` 参数控制文件在归档里的名字。不指定的话会保留原来的完整路径，解压时可能把 `data/notes.csv` 的目录结构一起还原。

## 读取与列出内容

```python
import zipfile

with zipfile.ZipFile("archive.zip", "r") as zf:
    # 列出所有条目
    for name in zf.namelist():
        print(name)

    # 读单个文件的内容（字节）
    data = zf.read("notes.csv")
    print(data.decode("utf-8"))

    # 更详细的信息
    for info in zf.infolist():
        print(info.filename, info.file_size, info.compress_size)
```

`infolist()` 返回 `ZipInfo` 对象列表，包含文件名、原始大小、压缩后大小、修改时间、压缩方式等。

## 解压

```python
import zipfile

with zipfile.ZipFile("archive.zip", "r") as zf:
    zf.extract("notes.csv", path="out_dir")       # 解压单个文件
    zf.extractall(path="out_dir")                  # 解压全部
```

`extractall` 可以配合 `members` 参数只解压指定的子集：

```python
with zipfile.ZipFile("archive.zip", "r") as zf:
    # 只解压 .txt 文件
    txts = [n for n in zf.namelist() if n.endswith(".txt")]
    zf.extractall(path="out", members=txts)
```

## 翻车现场：路径穿越攻击

如果你从不可信的 zip 里直接 `extractall`，归档里可能藏有 `../../etc/passwd` 这样的条目，覆盖系统文件。

```python
import zipfile

# WRONG：直接解压不可信 zip
with zipfile.ZipFile("untrusted.zip", "r") as zf:
    zf.extractall(path="out")
# 如果里面有 "../../etc/passwd" 这种条目，就写到了 out 之外
```

防御做法：检查每个条目的规范化路径是否落在目标目录内。

```python
from pathlib import Path
import zipfile

def safe_extract(zf, target_dir):
    target = Path(target_dir).resolve()
    for name in zf.namelist():
        dest = (target / name).resolve()
        if not str(dest).startswith(str(target) + str(Path.sep)):
            raise ValueError(f"危险路径，拒绝解压: {name}")
        zf.extract(name, path=target)

with zipfile.ZipFile("untrusted.zip", "r") as zf:
    safe_extract(zf, "out")
```

这是处理用户上传 zip 时的标准防护。

## 翻车现场：读取 zip 里的内容要 decode

```python
import zipfile

with zipfile.ZipFile("data.zip", "r") as zf:
    # WRONG：read() 返回 bytes，直接当字符串用会出问题
    content = zf.read("notes.txt")
    print(content.upper())      # AttributeError: 'bytes' object has no attribute 'upper'
```

报错：

```
AttributeError: 'bytes' object has no attribute 'upper'
```

`read()` 永远返回 `bytes`。文本文件记得 `decode`：

```python
with zipfile.ZipFile("data.zip", "r") as zf:
    content = zf.read("notes.txt").decode("utf-8")
    print(content.upper())
```

或者用 `zf.open(name, "r", encoding="utf-8")` 以文本模式打开（Python 3.9+）。

## 密码保护的局限

`zipfile` 支持密码，但**只支持传统的 ZipCrypto 加密**，不支持更现代的 AES-256。而且 ZipCrypto 本身已被证明有已知漏洞，易被破解。

```python
import zipfile

with zipfile.ZipFile("secret.zip", "w") as zf:
    zf.setpassword(b"123456")                # 密码必须是字节
    zf.writestr("secret.txt", "机密内容", zipfile.ZIP_DEFLATED)

with zipfile.ZipFile("secret.zip", "r") as zf:
    zf.setpassword(b"123456")
    print(zf.read("secret.txt").decode("utf-8"))
```

**现实局限**：
- 只支持 ZipCrypto，安全性弱
- 不支持 AES-256（需用第三方库 `pyzipper`）
- 不能"给已有的 zip 加密"，只能写的时候设置
- 很多工具（包括 Python 的 `shutil.unpack_archive`）遇到加密 zip 会失败

所以 zip 密码只能挡"路过的普通人"，真正敏感的数据请用专门的加密方案。

## 实战：按扩展名分类统计归档内容

```python
import zipfile
from collections import defaultdict

def analyze_zip(file_list):
    """接收模拟 zip 内文件列表（含大小），返回按扩展名的分类统计。
    file_list: list of (name, size)"""
    stats = defaultdict(lambda: {"count": 0, "size": 0})
    for name, size in file_list:
        ext = name.rsplit(".", 1)[-1] if "." in name else "(无扩展名)"
        stats[ext]["count"] += 1
        stats[ext]["size"] += size
    return dict(stats)

files = [("a.txt", 100), ("b.txt", 200), ("c.png", 5000)]
print(analyze_zip(files))
# {'txt': {'count': 2, 'size': 300}, 'png': {'count': 1, 'size': 5000}}
```

真实场景下把 `file_list` 换成 `zf.infolist()` 即可。这个函数是备份工具里做"归档内容概览"的基础。

## 小结

- `ZipFile(name, "w", ZIP_DEFLATED)` 创建，`write(path, arcname=)` 添加
- `namelist()` 列出条目，`read(name)` 读内容（返回 bytes）
- `infolist()` 提供文件大小、压缩后大小、修改时间等元数据
- `extract(name, path=)` 解压单个，`extractall(path=, members=)` 解压多个
- **解压不可信 zip 前检查路径穿越**
- `read()` 返回 bytes，文本要 `decode`
- `zipfile` 密码只支持弱加密 ZipCrypto，不支持 AES
