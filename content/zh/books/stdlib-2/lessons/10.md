# 实战：日程与倒计时工具

> 这一课把前 9 课的知识串起来，做一个能用的"日程倒计时"工具。你会学会如何组合 date、timedelta、strftime 解决实际问题。

## 需求分析

我们要做一个工具，功能：

1. 输入一个目标日期（如"2026-12-25"），计算距离今天还有多少天
2. 支持多个日程，显示每个日程的倒计时
3. 对已经过去的日程，显示"已过期 N 天"
4. 按时间从近到远排序

## 核心：计算天数差

```python
from datetime import date, datetime

def days_until(target):
    """计算距离目标日期还有多少天"""
    today = date.today()
    delta = target - today
    return delta.days

# 假设今天是 2026-09-27
print(days_until(date(2026, 12, 25)))   # 89
print(days_until(date(2026, 10, 1)))    # 4
```

**核心就一行**：`target - today` 得到 timedelta，取 `.days`。这就是前面学的知识直接应用。

## 完整实现

```python
from datetime import date

def format_countdown(target, label):
    """格式化单个日程的倒计时信息"""
    today = date.today()
    days = (target - today).days

    if days > 0:
        return f"{label}：还有 {days} 天（{target.strftime('%Y-%m-%d')}）"
    elif days == 0:
        return f"{label}：就是今天！"
    else:
        return f"{label}：已过期 {abs(days)} 天"

# 示例
events = [
    (date(2026, 10, 1), "国庆节"),
    (date(2026, 12, 25), "圣诞节"),
    (date(2027, 1, 1), "元旦"),
    (date(2026, 9, 10), "教师节"),
]

for target, label in events:
    print(format_countdown(target, label))
```

输出（假设今天 2026-09-27）：

```
国庆节：还有 4 天（2026-10-01）
圣诞节：还有 89 天（2026-12-25）
元旦：还有 96 天（2027-01-01）
教师节：已过期 17 天
```

## 翻车现场：忘记处理"就是今天"的边界情况

```python
from datetime import date

# WRONG：只判断了 > 0 和 < 0，漏了 == 0
def countdown(target, label):
    days = (target - date.today()).days
    if days > 0:
        return f"还有 {days} 天"
    else:
        return f"已过期 {abs(days)} 天"

# 如果 target 正好是今天，会显示"已过期 0 天"——语义错误
```

边界情况（`days == 0`）最容易漏。永远记得测试"恰好相等"的场景。

## 扩展：带时区的日程提醒

如果日程是"北京时间 2026-12-25 08:00 的线上会议"，需要考虑时区：

```python
from datetime import datetime
from zoneinfo import ZoneInfo

def meeting_countdown(meeting_time, user_tz_name):
    """计算距会议还有多久"""
    tz = ZoneInfo(user_tz_name)
    now = datetime.now(tz)
    delta = meeting_time - now
    return delta

tz_bj = ZoneInfo("Asia/Shanghai")
meeting = datetime(2026, 12, 25, 8, 0, tzinfo=tz_bj)

# 用户在美国，看倒计时
tz_ny = ZoneInfo("America/New_York")
delta = meeting_countdown(meeting, "America/New_York")
print(f"距会议还有 {delta.total_seconds() / 3600:.1f} 小时")
```

## 扩展：按时间排序

```python
from datetime import date

events = [
    (date(2026, 12, 25), "圣诞节"),
    (date(2026, 10, 1), "国庆节"),
    (date(2027, 1, 1), "元旦"),
]

# 按日期排序
events.sort(key=lambda x: x[0])
for target, label in events:
    print(f"{label}: {target}")
```

date 对象天然支持排序，直接 `sort` 就行。

## 实战例子：完整的日程管理类

```python
from datetime import date

class CountdownManager:
    def __init__(self):
        self.events = []

    def add(self, target, label):
        self.events.append((date.fromisoformat(target) if isinstance(target, str) else target, label))

    def show_all(self):
        today = date.today()
        # 按日期排序
        sorted_events = sorted(self.events, key=lambda x: x[0])
        for target, label in sorted_events:
            days = (target - today).days
            if days > 0:
                print(f"  {label}: 还有 {days} 天")
            elif days == 0:
                print(f"  {label}: 就是今天！🎉")
            else:
                print(f"  {label}: 已过期 {abs(days)} 天")

cm = CountdownManager()
cm.add("2026-10-01", "国庆节")
cm.add("2026-12-25", "圣诞节")
cm.add("2027-01-01", "元旦")
cm.show_all()
```

## 小结

- 倒计时核心：`(target - today).days`，一行搞定
- 边界情况（`days == 0`）必须单独处理
- date 对象天然支持排序，直接用 `sort(key=lambda x: x[0])`
- 带时区的日程：用 aware datetime + astimezone 转换
- 组合前面学过的 date、timedelta、strftime、zoneinfo，就能做出实用的工具
