# 为什么时间难处理

> 这一课解决"时间为什么是编程里最坑人的数据类型之一"。你会明白为什么不能用手工算日期，以及时区、闰秒、夏令时这些坑有多深。

## 手工算日期：看起来简单，处处是坑

假设你写了一个程序，要算出用户注册后满 30 天的到期时间。最朴素的想法：拿到年月日，天数加上 30，完事。

```python
year, month, day = 2026, 1, 15
day += 30
print(f"{year}-{month}-{day}")   # 2026-1-45 ？
```

结果出现了 1 月 45 日——这显然不是合法的日期。你可能会想："那就判断一下，超过当月天数就进位啊。"于是你开始写：

```python
# 每月天数表
days_in_month = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]

def add_days(year, month, day, n):
    day += n
    while day > days_in_month[month - 1]:
        day -= days_in_month[month - 1]
        month += 1
        if month > 12:
            month = 1
            year += 1
    return year, month, day
```

看起来能跑。但它在 2024 年 2 月 29 日加 1 天时会怎样？`days_in_month[1]` 是 28，你的表没考虑闰年。2024 是闰年，2 月有 29 天，但你的程序会算成 3 月 1 日（跳过 2 月 29 日直接到 3 月 2 日？不对，让我们仔细算……算了，这正是问题所在——你自己都快算晕了）。

## 翻车现场：闰年让你算错生日

```python
# WRONG：手工判断闰年，条件写错了
def is_leap(year):
    return year % 4 == 0   # 忘了百年不闰、四百年再闰

print(is_leap(1900))   # True？错！1900 不是闰年
```

1900 年能被 4 整除，但它同时是 100 的倍数且不是 400 的倍数，所以**不是闰年**。正确的判断是：

```python
def is_leap(year):
    return (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)

print(is_leap(1900))  # False ✓
print(is_leap(2000))  # True  ✓
print(is_leap(2024))  # True  ✓
```

这只是冰山一角。时间处理还面临：

| 坑 | 具体表现 |
|---|---|
| 时区 | 北京时间 UTC+8，但纽约有夏令时，一年变两次 |
| 闰秒 | 地球自转不规则，偶尔会插入一秒 |
| 夏令时 | 每年 3 月"凭空消失"一小时，11 月"凭空多出一"小时 |
| 各国历法 | 沙特用伊斯兰历，日本有年号，台湾用民国纪年 |
| 日期格式 | 美国写 09/27/2026（月/日/年），中国写 2026-09-27 |

## 翻车现场：日期字符串格式各地不同

张三从美国同事那里收到一条数据：

```python
# WRONG：按中国习惯解析美国日期
date_str = "03/04/2026"
month, day, year = date_str.split("/")
print(f"年份：{year}，月份：{month}，日：{day}")
```

输出 `年份：2026，月份：03，日：04`——张三以为是 2026 年 3 月 4 日。但美国同事写的是 **March 4, 2026**（3 月 4 日）还是 **April 3, 2026**（4 月 3 日）？其实美国习惯是月/日/年，所以这是 3 月 4 日。但如果张三按中国习惯理解成 4 月 3 日，就差了一个月。

**真正的解法**：用标准库的时间处理模块，把格式解析交给专门的库来做，不要自己切字符串。

## 标准库的三件套

Python 处理时间有三件主要工具，这一册会逐一讲透：

| 模块 | 管什么 | 典型场景 |
|---|---|---|
| `datetime` | 日期、时间、时间差、时区 | 计算到期日、格式化输出 |
| `time` | 时间戳、计时、休眠 | 性能测试、延时操作 |
| `pathlib` / `os` | 文件系统、路径 | 遍历目录、读写文件属性 |

本课先建立直觉，后面几课逐个深入。

## 一个直觉例子：时间差

```python
from datetime import date

today = date(2026, 9, 27)
birthday = date(2026, 12, 25)
delta = birthday - today
print(f"距离圣诞节还有 {delta.days} 天")
```

输出：

```
距离圣诞节还有 89 天
```

注意这里没有手工算"12 月 25 日减 9 月 27 日"——`date` 对象自己知道每个月有多少天，直接做减法就行。`delta` 的类型是 `timedelta`，后面第 03 课会详细讲。

## 小结

- 时间处理的核心难点：闰年规则、时区、夏令时、各国格式不同
- **永远不要自己手写日期计算逻辑**，用标准库 `datetime`
- 闰年判断：`(year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)`
- 日期格式有地域差异：美国 `MM/DD/YYYY`，中国 `YYYY-MM-DD`
- `datetime.date` 对象相减得到 `timedelta`，自动处理月份天数差异
