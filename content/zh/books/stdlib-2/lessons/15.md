# 实战：批量重命名工具

> 这一课把前面学的 pathlib 知识串起来，做一个命令行批量重命名工具。核心设计理念是：**先预览，再执行**——绝不一声不吭地改文件名。你还会学会处理重名冲突、支持撤销操作。

## 需求分析

我们要做一个工具，能按规则批量修改文件名。比如：

- 给所有 `.txt` 文件加上日期前缀：`notes.txt` → `20240928_notes.txt`
- 把文件名里的空格替换成下划线：`my file.txt` → `my_file.txt`
- 统一小写化：`Report.PDF` → `report.pdf`

**三个核心安全设计**：

1. **先预览再执行**：默认只打印"将要做什么"，加 `--apply` 才真正动手
2. **检测重名冲突**：如果目标文件名已存在，要么报错要么自动加编号
3. **生成撤销脚本**：执行后输出一条命令，能把改名全部还原

## 完整代码

```python
import argparse
import sys
from datetime import datetime
from pathlib import Path


def build_new_name(p: Path, rule: str) -> str:
    """根据规则生成新文件名"""
    if rule == "date_prefix":
        today = datetime.now().strftime("%Y%m%d")
        return f"{today}_{p.name}"
    elif rule == "underscore":
        return p.name.replace(" ", "_")
    elif rule == "lowercase":
        return p.name.lower()
    else:
        raise ValueError(f"未知规则：{rule}")


def find_unique_path(target: Path) -> Path:
    """如果目标已存在，自动加编号：file.txt → file_1.txt → file_2.txt"""
    if not target.exists():
        return target
    stem = target.stem
    suffix = target.suffix
    parent = target.parent
    i = 1
    while True:
        candidate = parent / f"{stem}_{i}{suffix}"
        if not candidate.exists():
            return candidate
        i += 1


def preview(directory: str, pattern: str, rule: str):
    """预览模式：只打印将要做的操作"""
    base = Path(directory)
    if not base.is_dir():
        print(f"错误：{directory} 不是有效目录")
        sys.exit(1)

    files = list(base.glob(pattern))
    if not files:
        print(f"没有匹配 {pattern} 的文件")
        return

    print(f"将处理 {len(files)} 个文件：\n")
    for f in files:
        new_name = build_new_name(f, rule)
        if new_name == f.name:
            print(f"  跳过  {f.name}（规则未产生变化）")
        else:
            print(f"  {f.name}  →  {new_name}")

    print(f"\n以上 {len(files)} 个文件将被重命名。")
    print("确认无误后加 --apply 执行。")


def apply_rename(directory: str, pattern: str, rule: str):
    """执行模式：真正重命名，并处理冲突"""
    base = Path(directory)
    files = list(base.glob(pattern))

    renames = []  # (原路径, 新路径)
    for f in files:
        if not f.is_file():
            continue
        new_name = build_new_name(f, rule)
        if new_name == f.name:
            continue
        target = find_unique_path(base / new_name)
        renames.append((f, target))

    # 执行重命名
    undo_pairs = []
    for old, new in renames:
        old.rename(new)
        undo_pairs.append((new.name, old.name))
        print(f"  ✓ {old.name}  →  {new.name}")

    # 生成撤销命令
    if undo_pairs:
        print(f"\n完成 {len(undo_pairs)} 个重命名。")
        print("撤销命令（保存为 undo.sh 后执行）：")
        print("#!/bin/bash")
        for new_name, orig_name in undo_pairs:
            print(f'mv "{new_name}" "{orig_name}"')
    else:
        print("没有需要重命名的文件。")


def main():
    parser = argparse.ArgumentParser(
        description="批量重命名工具 —— 先预览再执行"
    )
    parser.add_argument("directory", help="目标目录")
    parser.add_argument("--pattern", default="*", help="匹配模式，如 *.txt")
    parser.add_argument(
        "--rule",
        default="underscore",
        choices=["date_prefix", "underscore", "lowercase"],
        help="重命名规则",
    )
    parser.add_argument("--apply", action="store_true", help="真正执行（不加则预览）")

    args = parser.parse_args()

    if args.apply:
        print("=== 执行模式 ===")
        apply_rename(args.directory, args.pattern, args.rule)
    else:
        print("=== 预览模式 ===")
        preview(args.directory, args.pattern, args.rule)


if __name__ == "__main__":
    main()
```

## "预览"设计的意义

重命名是不可逆操作（至少在 shell 层面不容易 undo）。**预览模式让你在真正动手之前看到全部变更**，检查有没有：

- 误匹配的文件
- 规则产生的文件名不符合预期
- 可能的冲突

只有确认 `--apply` 之后才真正执行。这种"**dry-run → confirm → apply**"的三段式设计，在运维脚本、数据库迁移、批量处理中都是最佳实践。

## 冲突处理：find_unique_path

当两个文件规则处理后变成同一个名字时（比如 `IMG_001.jpg` 和 `img_001.jpg` 在大小写不敏感的文件系统上），`find_unique_path()` 自动加编号：

```python
# 第一次：20240928_IMG_001.jpg 不存在，直接返回
# 第二次：20240928_IMG_001.jpg 已存在，返回 20240928_IMG_001_1.jpg
# 第三次：继续 → 20240928_IMG_001_2.jpg
```

这样即使规则产生冲突，也不会覆盖已有文件。

## 翻车现场：不加预览直接执行

```python
from pathlib import Path

# WRONG：直接遍历 + rename，没有预览，没有确认
base = Path("./docs")
for f in base.iterdir():
    new = f.with_name(f.name.upper())
    f.rename(new)
    print(f"renamed {f.name} → {new.name}")
# 跑完才发现把不该改的 .git 目录也动了，或者文件名冲突覆盖了文件
```

**后果**：文件名冲突导致覆盖、误改不该改的文件、无法回退。

**正确做法**：像上面实战代码那样，**先遍历打印计划，确认后再执行**。

## 翻车现场：rename 覆盖已存在的文件

```python
from pathlib import Path

p = Path("./notes.txt")
target = Path("./README.txt")

# WRONG：如果 README.txt 已存在，会被静默覆盖！
p.rename(target)
```

在 Unix 上 `rename()` 会覆盖已存在的目标文件（如果权限允许），数据直接丢失。

**正确做法**：用 `find_unique_path()` 类似的逻辑，先检查目标是否存在：

```python
if target.exists():
    print(f"警告：{target.name} 已存在，跳过")
else:
    p.rename(target)
```

或者用 `replace()` 明确表达"我知道会覆盖"的意图（Windows 上 `rename` 对已有文件会报错，而 `replace` 会覆盖）。

## 扩展练习：支持更多规则

你可以给这个工具加更多重命名规则，比如：

- `sequential`：按顺序编号 `file_01.txt`、`file_02.txt`……
- `remove_spaces`：去掉所有空格（而不是替换成下划线）
- `add_suffix`：在文件名后加后缀 `_backup`

只需要在 `build_new_name()` 里加 elif 分支，然后在 argparse 的 `choices` 里注册即可。

## 小结

- 批量重命名工具的核心是"先预览，再执行"的安全设计
- `build_new_name()` 根据规则生成新文件名，`find_unique_path()` 处理冲突
- 预览模式遍历匹配文件并打印计划，确认后 `--apply` 才真正执行
- 冲突时自动加编号（`_1`、`_2`...），绝不静默覆盖
- 执行后输出撤销命令，方便回滚
- "dry-run → confirm → apply" 是运维脚本的通用最佳实践
