# timestamp 时间戳

> 这一课解决"为什么跨系统传时间要用时间戳，以及时间戳和 datetime 互转时的时区陷阱"。你会明白为什么直接存本地时间会出 bug。

## 什么是时间戳

**时间戳（timestamp）** 是从 **1970-01-01 00:00:00 UTC** 到某个时刻经过的**秒数**（在 Python 中通常是带小数的浮点数，小数部分表示微秒）。

```python
import time

ts = time.time()
print(ts)   # 1787800000.123456（某个大数字）
```

这个数字看起来毫无意义，但它有一个巨大的好处：**不依赖时区**。无论你在北京还是纽约，"1970-01-01 以来过了多少秒"这个事实是全世界统一的。所以时间戳是跨系统传递时间的"通用货币"。

## datetime 和时间戳互转

```python
from datetime import datetime, timezone, timedelta

# datetime → timestamp
dt = datetime(2026, 9, 27, 14, 30, 0)
ts = dt.timestamp()
print(ts)   # 1787807400.0

# timestamp → datetime
dt2 = datetime.fromtimestamp(ts)
print(dt2)  # 2026-09-27 14:30:00
```

## 翻车现场：timestamp 互转的时区陷阱

```python
from datetime import datetime

# WRONG：naive datetime 的 timestamp() 会按本地时区解释
dt = datetime(2026, 9, 27, 14, 30, 0)
ts = dt.timestamp()

# 在北京（UTC+8）机器上，这个 ts 对应的是 UTC 时间 06:30
# 如果代码部署到美国服务器，同一行代码算出的值就不同了！
```

问题的根源：`dt` 是 naive 的（没有时区信息），但 `timestamp()` 方法**假定它是本地时间**。如果你的服务器换了时区，结果就变了。

```python
from datetime import datetime, timezone, timedelta

# 正确：明确指定时区
tz_cst = timezone(timedelta(hours=8))  # UTC+8
dt = datetime(2026, 9, 27, 14, 30, 0, tzinfo=tz_cst)
ts = dt.timestamp()
print(ts)  # 无论在哪台机器上跑，结果都一样
```

## 翻车现场：fromtimestamp 返回本地时间

```python
from datetime import datetime

ts = 1787807400.0

# WRONG：fromtimestamp 返回的是"本地时间视角"下的时间
dt_local = datetime.fromtimestamp(ts)
print(dt_local)
# 在北京打印：2026-09-27 14:30:00
# 在伦敦打印：2026-09-27 06:30:00（夏令时可能是 07:30:00）
```

如果你想要"这个时间戳在 UTC 时区对应几点"，用 `utcfromtimestamp`：

```python
# 正确：明确要 UTC 视角
dt_utc = datetime.utcfromtimestamp(ts)
print(dt_utc)  # 2026-09-27 06:30:00 ← 永远是 UTC 时间
```

不过 `utcfromtimestamp` 返回的是 naive 对象（tzinfo 为 None），这在 Python 3.12+ 已被弃用警告。推荐用带时区的写法：

```python
dt_utc_aware = datetime.fromtimestamp(ts, tz=timezone.utc)
print(dt_utc_aware)  # 2026-09-27 06:30:00+00:00
```

## 实战例子：记录事件时间

```python
import time
from datetime import datetime, timezone, timedelta

def log_event(name):
    """记录事件，返回时间戳和可读时间"""
    ts = time.time()
    tz_cst = timezone(timedelta(hours=8))
    dt = datetime.fromtimestamp(ts, tz=tz_cst)
    return ts, dt.strftime("%Y-%m-%d %H:%M:%S")

ts, readable = log_event("用户登录")
print(f"事件时间（北京时间）：{readable}")
print(f"时间戳：{ts}")
```

## 实战例子：比较两个时间戳

```python
from datetime import datetime, timezone, timedelta

tz_cst = timezone(timedelta(hours=8))

t1 = datetime(2026, 9, 27, 10, 0, 0, tzinfo=tz_cst).timestamp()
t2 = datetime(2026, 9, 27, 14, 30, 0, tzinfo=tz_cst).timestamp()

diff_seconds = t2 - t1
print(f"相差 {diff_seconds / 3600:.1f} 小时")  # 相差 4.5 小时
```

时间戳本质是数字，所以可以直接做加减乘除、比较大小，不需要 timedelta。

## 小结

- 时间戳 = 1970-01-01 00:00:00 UTC 以来的秒数，是跨系统的"通用货币"
- `datetime.timestamp()` → 时间戳；`datetime.fromtimestamp(ts)` → datetime
- **naive datetime 的 timestamp() 按本地时区解释**，换服务器可能出错
- 正确做法：给 datetime 加上 `tzinfo=timezone(timedelta(hours=8))`
- `fromtimestamp(ts, tz=timezone.utc)` 获取 UTC 视角的时间
- 时间戳是数字，可以直接比较和运算
