# shutil 高级操作

> `os` 模块只能操作单文件，跨文件系统的移动、目录树拷贝都得靠 `shutil`。这一课讲 `copy`/`copy2`/`move`/`rmtree`/`copytree` 的差别，以及最危险的那一个。

## 最常用的五个函数

```python
import shutil

shutil.copy("src.txt", "dst.txt")      # 拷内容 + 权限位
shutil.copy2("src.txt", "dst.txt")     # copy + 保留所有元数据（mtime、atime）
shutil.copystat("a.txt", "b.txt")      # 只拷元数据，不动内容
shutil.move("a.txt", "backup/a.txt")   # 移动/重命名
shutil.rmtree("old_dir")               # 递归删除整个目录树
```

`copy` 和 `copy2` 的区别只有一点：`copy2` 会尽量保留**所有元数据**（修改时间、访问时间等），做备份时用 `copy2`，做临时复制时用 `copy` 就够了。

## copytree：递归拷贝整个目录

`copy` 只能拷单个文件，`copytree` 才能连子目录一起搬。

```python
import shutil

# 把 project 整个目录拷到 project_backup
shutil.copytree("project", "project_backup")

# 忽略规则：跳过 .git 和 __pycache__
shutil.copytree(
    "project", "project_backup",
    ignore=shutil.ignore_patterns("__pycache__", ".git", "*.pyc"),
)
```

`ignore_patterns()` 返回的是一个可调用对象，它接收 `(dir, entries)` 并返回要忽略的文件名集合。你也可以自己写：

```python
def my_ignore(dirname, names):
    return [n for n in names if n.endswith(".tmp")]

shutil.copytree("src", "dst", ignore=my_ignore)
```

## disk_usage：磁盘占用

```python
import shutil

usage = shutil.disk_usage("/")
print(f"总空间: {usage.total / 2**30:.1f} GB")
print(f"已用:   {usage.used / 2**30:.1f} GB")
print(f"可用:   {usage.free / 2**30:.1f} GB")
print(f"使用率: {usage.used / usage.total * 100:.1f}%")
```

返回的是具名元组 `sdiskusage(total, used, free)`，单位是字节。

## 翻车现场：`rmtree` 删了就没了

`rmtree` 是标准库里最危险的函数——**没有回收站、没有确认、没有日志**，删完就再也找不回来。

```python
import shutil

# WRONG：路径拼错，rmtree 会照单全收
base = "/data/projects/"
target = "old_project"
shutil.rmtree(base + target)   # 如果 base 是 "/data/projects" 少了斜杠
# 结果变成 rmtree("/data/projectsold_project")
# 更惨的是：如果 target 是空的 ""
shutil.rmtree(base + "")       # 删掉整个 /data/projects/ ！
```

报错：

```
FileNotFoundError: [Errno 2] No such file or directory: '/data/projectsold_project'
```

如果拼出来的路径不存在，会抛 `FileNotFoundError`——这其实是救了你一命。但如果是路径拼接出错指向了真实目录，那就真的没了。

**安全写法**：

```python
from pathlib import Path
import shutil

base = Path("/data/projects")
target = base / "old_project"     # 用 Path 拼接，斜杠不用操心

if target.exists() and target.is_dir():
    shutil.rmtree(target)
    print(f"已删除 {target}")
else:
    print("目标不存在，跳过")
```

三条纪律：
1. 删除前先 `exists()` + `is_dir()` 双重确认
2. 用 `pathlib` 拼接路径，别手拼字符串
3. 生产环境加 `input("确认删除 y/n: ")` 或日志留痕

## 翻车现场：`copytree` 目标已存在会报错

```python
import shutil

# WRONG：目标目录已经存在
shutil.copytree("project", "project_backup")
# 第一次成功，第二次再跑就报错
shutil.copytree("project", "project_backup")
```

报错：

```
FileExistsError: [Errno 17] File exists: 'project_backup'
```

`copytree` 要求目标目录**不能存在**（和 `open(..., "x")` 一个思路）。解决办法：

```python
import shutil
import os

dst = "project_backup"
if os.path.exists(dst):
    shutil.rmtree(dst)          # 先清掉再拷
shutil.copytree("project", dst)

# 或者用 dirs_exist_ok=True（Python 3.8+）
shutil.copytree("project", dst, dirs_exist_ok=True)
```

`dirs_exist_ok=True` 表示允许目标已存在，文件会合并覆盖，目录里的其他文件会保留——做增量备份时很有用。

## 实战：清理临时文件目录

```python
import shutil
import os
from pathlib import Path

def cleanup_temp(temp_dir):
    """清空指定临时目录里的所有内容，但保留目录本身"""
    p = Path(temp_dir)
    if not p.exists():
        return 0
    deleted = 0
    for entry in p.iterdir():
        if entry.is_dir():
            shutil.rmtree(entry)
        else:
            entry.unlink()
        deleted += 1
    return deleted

# 模拟调用（不真删文件）
print(cleanup_temp("/tmp/cache"))   # 0（目录不存在）
```

真实使用时这个函数要格外小心，最好加个白名单路径校验，防止传入 `/` 之类。

## 小结

- `copy` 拷内容+权限，`copy2` 额外保留所有元数据
- `copytree(src, dst)` 递归拷贝，`ignore=` 可跳过指定文件
- `copytree` 要求目标不存在，`dirs_exist_ok=True` 可覆盖此限制
- `move` 本质是 `os.rename`，跨设备时退化为拷贝+删除
- `rmtree` 递归删除且无回收站，务必先 `exists()` + `is_dir()` 确认
- `disk_usage(path)` 返回 (total, used, free) 字节数
