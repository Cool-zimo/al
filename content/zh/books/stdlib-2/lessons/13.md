# 遍历目录

> 这一课讲怎么把目录里的文件"翻出来"——从 `iterdir()` 的逐层浏览，到 `glob()` 的模式匹配，再到 `os.walk()` 的深度遍历。你会学会按名字筛选文件、递归查找子目录、理解 `*` 与 `**` 的微妙差别。

## iterdir：列出当前目录的直接子项

`Path.iterdir()` 返回一个生成器，产出当前目录下的所有子项（文件和子目录），**不包含** `.` 和 `..`，也**不递归**进入子目录。

```python
from pathlib import Path

base = Path("./project")
for entry in base.iterdir():
    print(entry.name, "DIR" if entry.is_dir() else "FILE")
```

注意 `iterdir()` 只扫一层。如果你想区分文件和目录，用 `is_file()` / `is_dir()` 逐个判断。

## glob：用模式匹配文件名

`glob()` 支持 shell 风格的通配符。`*` 匹配**当前层级**任意字符（不含路径分隔符 `/`）。

```python
from pathlib import Path

base = Path("./project")

# 匹配当前目录下所有 .py 文件（不含子目录）
for py in base.glob("*.py"):
    print(py)
```

常见的通配符：

| 模式 | 含义 |
|------|------|
| `*` | 匹配任意字符（不含 `/`） |
| `?` | 匹配单个字符 |
| `[abc]` | 匹配 a、b 或 c |
| `**` | 匹配任意层级（含子目录） |

## rglob：递归 glob 的快捷方式

`rglob(pattern)` 等价于 `glob("**/" + pattern)`——它会递归进入所有子目录。

```python
from pathlib import Path

base = Path("./project")

# 递归查找所有 .py 文件
for py in base.rglob("*.py"):
    print(py)
```

`rglob("*.py")` 和 `glob("**/*.py")` 结果一样，但前者更简洁。

## 翻车现场：`*` 不会跨目录匹配

这是新手最容易踩的坑——以为 `glob("*.py")` 能找到子目录里的 `.py` 文件。

```python
from pathlib import Path

base = Path("./project")

# WRONG：*.py 只匹配 project/ 的直接子文件，不会进入子目录
for py in base.glob("*.py"):
    print(py)
# 如果 .py 文件在 project/src/main.py，这里什么都找不到！
```

报错倒不会，但**结果比你预期的少**。记住：**`*` 不跨目录**。

要递归查找，用 `rglob()` 或 `glob("**/*.py")`：

```python
# 正确：递归查找
for py in base.rglob("*.py"):
    print(py)   # project/src/main.py ← 能找到了
```

## 翻车现场：`**` 不写后面的 `/*.py` 会匹配目录

```python
from pathlib import Path

base = Path("./project")

# WRONG：这样写会连目录一起匹配到
for item in base.glob("**"):
    print(item)
# 输出：project/.  project/src  project/src/main.py ...
# 目录也被算进来了，过滤逻辑会出错
```

正确写法——明确指定文件名模式：

```python
# 正确：只要文件，不要目录
for py in base.glob("**/*.py"):
    if py.is_file():   # 加一层保险
        print(py)
```

## os.walk：经典的三元组遍历

`os.walk()` 是 pathlib 出现之前的老牌遍历工具，它**自上而下**递归遍历目录树，每次返回一个三元组 `(dirpath, dirnames, filenames)`。

```python
import os

for dirpath, dirnames, filenames in os.walk("./project"):
    print(f"=== {dirpath} ===")
    for f in filenames:
        print(f"  {f}")
```

- `dirpath`：当前目录的完整路径（字符串）
- `dirnames`：当前目录下所有子目录名（列表）
- `filenames`：当前目录下所有文件名（列表）

**关键技巧**：你可以**原地修改 `dirnames` 列表**来控制遍历行为。删掉某些项，os.walk 就不会进入那些目录。

```python
import os

for dirpath, dirnames, filenames in os.walk("./project"):
    # 跳过所有 .git 和 __pycache__ 目录
    dirnames[:] = [d for d in dirnames if d not in (".git", "__pycache__")]
    for f in filenames:
        if f.endswith(".py"):
            print(os.path.join(dirpath, f))
```

`dirnames[:] = ...` 用切片赋值修改原列表，os.walk 在下一次迭代时就不会再进入被删掉的目录。这在跳过 `.git`、`node_modules` 等目录时非常实用。

## 小结

- `iterdir()` 列出当前目录的直接子项，不递归
- `glob("*.py")` 只匹配当前层级；`*` 不跨目录
- `rglob("*.py")` 等价于 `glob("**/*.py")`，递归匹配
- `**` 要配合文件名模式使用，否则会把目录也算进去
- `os.walk()` 返回 `(dirpath, dirnames, filenames)` 三元组
- 原地修改 `dirnames` 列表可以控制遍历路径
