# glob 与 fnmatch：文件名模式匹配

> 这一课讲两个配对的模块：`fnmatch` 负责判断单个文件名是否匹配某个 shell 风格模式，`glob` 负责把这个模式展开成真实的文件列表。你会学会它们的语法，以及与 `pathlib.glob` 的分工。

## fnmatch：匹配单个文件名

`fnmatch.fnmatch(name, pattern)` 判断文件名是否匹配模式，返回布尔值。

```python
import fnmatch

print(fnmatch.fnmatch("main.py", "*.py"))        # True
print(fnmatch.fnmatch("data.tar.gz", "*.gz"))    # True
print(fnmatch.fnmatch("notes.TXT", "*.txt"))     # True（默认大小写不敏感，Windows 行为）
print(fnmatch.fnmatch("README.md", "*.py"))      # False
```

## fnmatch 的四种通配符

| 模式 | 含义 |
|------|------|
| `*` | 匹配任意个字符（包括零个） |
| `?` | 匹配单个字符 |
| `[abc]` | 匹配 a、b 或 c 中的任意一个 |
| `[!abc]` | 匹配**不在** a、b、c 中的任意一个 |

```python
import fnmatch

files = ["photo01.jpg", "photo02.jpg", "photo10.jpg", "doc.txt"]

# ? 匹配单个字符
print([f for f in files if fnmatch.fnmatch(f, "photo??.jpg")])
# ['photo01.jpg', 'photo02.jpg'] —— photo10 是两位，不匹配

# [abc] 字符集
print([f for f in files if fnmatch.fnmatch(f, "photo0[12].jpg")])
# ['photo01.jpg', 'photo02.jpg']
```

注意 `?` 只匹配**一个**字符，想匹配两位就得写 `??`，这就是它和 `*` 的差别。

## glob：把模式展开成文件列表

`glob.glob(pattern)` 返回匹配到的路径列表（字符串）。

```python
import glob

# 当前目录下的所有 py 文件
py_files = glob.glob("*.py")

# 递归查找（Python 3.5+ 支持 **）
all_py = glob.glob("**/*.py", recursive=True)

# 多目录匹配
configs = glob.glob("config/*.yaml")
```

`recursive=True` 才会让 `**` 生效，否则 `**` 就是字面量 `**`。

## fnmatch vs glob vs pathlib.glob

| 场景 | 用哪个 |
|------|--------|
| 判断一个已知文件名是否匹配模式 | `fnmatch.fnmatch` |
| 需要真实路径列表（文件系统操作） | `glob.glob` 或 `pathlib.Path.glob` |
| 想要面向对象的 Path 对象链式操作 | `pathlib.Path.glob` |
| 只想对内存里的字符串列表做过滤 | `fnmatch.fnmatch`（最快、最轻） |

```python
import fnmatch
from pathlib import Path

# 轻量过滤：纯字符串，不碰文件系统
names = ["a.py", "b.py", "c.md"]
py_only = [n for n in names if fnmatch.fnmatch(n, "*.py")]

# 真实文件操作：要 Path 对象
py_paths = list(Path(".").glob("*.py"))
```

## 翻车现场：`[!...]` 的写法别写错

```python
import fnmatch

files = ["a.txt", "b.txt", "_tmp.txt", ".gitignore"]

# WRONG：想排除以 . 开头的隐藏文件，写成 [!.] 以为匹配非点
# 但想匹配"不是 . 开头且是 .txt"的写法
result = [f for f in files if fnmatch.fnmatch(f, "[!.]*.txt")]
print(result)
# ['a.txt', 'b.txt', '_tmp.txt'] —— 注意 .gitignore 不含 .txt 所以本来也不匹配
```

真正容易踩的是字符集语法：`[!abc]` 是"非 abc"，但 `[^abc]` **不是** fnmatch 的合法语法（那是正则的写法）。

```python
import fnmatch

# WRONG：用正则语法，fnmatch 不认
fnmatch.fnmatch("a.txt", "[^.]*.txt")
# 这个模式会去匹配字面量的 "^" 字符
```

```python
import fnmatch

# 正确：fnmatch 用 ! 表示否定
fnmatch.fnmatch("a.txt", "[!.]*")   # True
fnmatch.fnmatch(".git", "[!.]*")    # False
```

**记住：fnmatch 是 shell 风格，不是正则。** `*`、`?`、`[]` 是 fnmatch 的语法；`.`、`^`、`$`、`\d` 都是字面量。

## 翻车现场：`**` 要 recursive=True

```python
import glob

# WRONG：想递归找所有 py，忘了 recursive
all_py = glob.glob("**/*.py")
print(all_py)   # 如果当前目录没有名为 ** 的目录，结果可能就是 []
```

报错或空结果（不报错但结果比你预期的少）：

```
[]
```

`glob.glob` 默认 `recursive=False`，此时 `**` 不会被当作"任意层级"。必须显式开启：

```python
import glob

# 正确
all_py = glob.glob("**/*.py", recursive=True)
```

对比 `pathlib`：`Path.rglob("*.py")` 等价于 `glob("**/*.py", recursive=True)`，写起来更省心。

## 实战：按模式筛选备份清单

```python
import fnmatch

def build_exclude_filter(patterns):
    """接收一个 fnmatch 模式列表，返回过滤函数"""
    def should_exclude(name):
        return any(fnmatch.fnmatch(name, pat) for pat in patterns)
    return should_exclude

is_excluded = build_exclude_filter([
    "*.pyc", "__pycache__", ".git", "*.tmp", "node_modules",
])

files = ["main.py", "main.pyc", "__pycache__/x.py", ".git/config", "data.csv"]
kept = [f for f in files if not is_excluded(f)]
print(kept)   # ['main.py', 'data.csv']
```

这是备份工具里"排除规则"的核心实现——用 `fnmatch` 在内存里过滤，比真去文件系统遍历快得多。

## 小结

- `fnmatch.fnmatch(name, pattern)` 判断单文件名是否匹配，返回布尔
- 通配符：`*` 任意个、`?` 单个、`[abc]` 字符集、`[!abc]` 反向字符集
- **fnmatch 是 shell 风格，不是正则**：`*` 是通配，`^` `$` `\d` 都是字面量
- `glob.glob(pattern, recursive=True)` 展开成路径列表，`**` 需 recursive
- `pathlib.Path.rglob("*.py")` 等价于 `glob("**/*.py", recursive=True)`
- 筛选内存中的字符串列表用 fnmatch；操作文件系统用 glob 或 pathlib
