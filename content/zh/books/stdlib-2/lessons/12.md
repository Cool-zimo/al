# pathlib 路径操作

> 这一课把 pathlib 的常用操作掰开揉碎。你会学会用 `/` 拼路径、提取各部分信息、检查存在性、创建目录——全部用 Path 对象的方法。

## 路径拼接：重载的 `/` 运算符

`Path` 重载了 `/` 运算符来做路径拼接。这是 pathlib 最优雅的设计之一：

```python
from pathlib import Path

base = Path("/home/zhangsan")
config = base / "config" / "app.json"
print(config)   # /home/zhangsan/config/app.json

# 也可以拼字符串和 Path 的混合
p = Path("/data") / "logs" / "2026" / "09.log"
print(p)   # /data/logs/2026/09.log
```

**注意**：`/` 的左边或右边至少有一个是 `Path` 对象。两个字符串用 `/` 不行（`str` 没有重载 `/`）。

## 路径各部分：name / stem / suffix / parent / parts

```python
from pathlib import Path

p = Path("/home/zhangsan/docs/archive.tar.gz")

print(p.name)     # archive.tar.gz ← 完整文件名
print(p.stem)     # archive.tar    ← 去掉最后一个后缀
print(p.suffix)   # .gz            ← 最后一个后缀
print(p.suffixes) # ['.tar', '.gz'] ← 所有后缀（列表）
print(p.parent)   # /home/zhangsan/docs ← 父目录
print(p.parents[0])  # /home/zhangsan/docs
print(p.parents[1])  # /home/zhangsan
print(p.parents[2])  # /home
print(p.parts)    # ('/', 'home', 'zhangsan', 'docs', 'archive.tar.gz')
```

## 翻车现场：suffix 和 suffixes 的区别

```python
from pathlib import Path

p = Path("archive.tar.gz")

# WRONG：以为 suffix 会返回 .tar.gz
print(p.suffix)    # .gz ← 只返回最后一个后缀！
print(p.suffixes)  # ['.tar', '.gz'] ← 这才是所有后缀
```

如果你要判断"是不是 tar.gz 文件"，应该用 `suffixes`：

```python
if p.suffixes == ['.tar', '.gz']:
    print("这是一个 tar.gz 文件")
```

或者拼接起来判断：

```python
if "".join(p.suffixes) == ".tar.gz":
    print("tar.gz 文件")
```

## 存在性检查：exists / is_file / is_dir

```python
from pathlib import Path

p = Path("/etc/hosts")

print(p.exists())    # True（系统里有这个文件）
print(p.is_file())   # True
print(p.is_dir())    # False

d = Path("/etc")
print(d.exists())    # True
print(d.is_file())   # False
print(d.is_dir())    # True
```

注意：`exists()` 返回 False 不代表一定是文件不存在——可能是权限问题。而 `is_file()` 为 True 意味着"存在且是文件"。

## 创建目录：mkdir

```python
from pathlib import Path

# 创建单级目录
p = Path("./output")
p.mkdir(exist_ok=True)   # exist_ok=True 防止已存在时报错

# 创建多级目录
deep = Path("./data/logs/2026/09")
deep.mkdir(parents=True, exist_ok=True)
# parents=True 会递归创建所有不存在的父目录
```

**`parents=True` 和 `exist_ok=True` 是最常用的组合**——前者允许创建多级目录，后者防止重复创建报错。

## 翻车现场：mkdir 不写 exist_ok 重复创建

```python
from pathlib import Path

p = Path("./cache")
p.mkdir()

# 第二次运行，目录已经存在
p.mkdir()   # FileExistsError!
```

报错：

```
FileExistsError: [Errno 17] File exists: './cache'
```

**解决**：永远加上 `exist_ok=True`，除非你有明确的理由要报错。

```python
p.mkdir(exist_ok=True)   # 安全：已存在就跳过，不存在就创建
```

## 创建文件：touch

```python
from pathlib import Path

p = Path("./data/note.txt")
p.parent.mkdir(parents=True, exist_ok=True)  # 先确保父目录存在
p.touch()   # 创建空文件（如果已存在则更新修改时间）
```

`touch()` 模仿 Linux 的 `touch` 命令：文件不存在就创建，存在就"摸一下"（更新 atime/mtime）。

## with_suffix / with_name / with_stem：路径变换

```python
from pathlib import Path

p = Path("/home/zhangsan/docs/report.txt")

# 换扩展名
print(p.with_suffix(".md"))     # /home/zhangsan/docs/report.md
print(p.with_suffix(".tar.gz")) # /home/zhangsan/docs/report.tar.gz

# 换文件名（保留目录）
print(p.with_name("summary.txt"))  # /home/zhangsan/docs/summary.txt

# 换主名（保留目录和后缀）
print(p.with_stem("summary"))      # /home/zhangsan/docs/summary.txt
```

这些方法**返回新路径**，不修改原路径（Path 是不可变对象）。

## 小结

- `/` 运算符拼接路径，左边或右边至少一个是 Path 对象
- `name` 完整文件名，`stem` 去后缀主名，`suffix` 最后后缀，`suffixes` 所有后缀
- `parent` 父目录，`parents[i]` 第 i 级父目录，`parts` 路径各部分元组
- `exists()` / `is_file()` / `is_dir()` 检查路径状态
- `mkdir(parents=True, exist_ok=True)` 创建目录的标准写法
- `with_suffix()` / `with_name()` / `with_stem()` 返回变换后的新路径
