# 扫描与分类：把目录读成数据

> 接第 3 章的 `pathlib` 遍历，这一课把"扫目录"做成一条数据管道：跳过该跳的，收集要的，输出一份干净的文件清单。

## Scanner：遍历目录并收集元信息

第 3 章学过 `Path.rglob()` 和 `Path.iterdir()`。整理器的扫描层要做的比"列文件名"多一点：它需要**大小、修改时间、后缀**这些元信息，供后面的分类层使用。

```python
from pathlib import Path
from datetime import datetime


IGNORE_DIRS = {"__pycache__", ".git", "node_modules", ".venv", "venv", ".svn"}
IGNORE_FILES = {".DS_Store", "Thumbs.db"}


def scan_directory(root):
    """遍历 root，返回文件信息字典列表。
    每条：{"src": 绝对路径, "name": 文件名, "ext": 小写后缀,
           "size": 字节数, "mtime": ISO8601 时间字符串}"""
    root = Path(root)
    files = []
    for p in root.rglob("*"):
        if not p.is_file():
            continue
        # 跳过忽略目录里的文件
        if any(part in IGNORE_DIRS for part in p.relative_to(root).parts[:-1]):
            continue
        if p.name in IGNORE_FILES:
            continue
        mtime = datetime.fromtimestamp(p.stat().st_mtime).isoformat(timespec="seconds")
        files.append({
            "src": str(p),
            "name": p.name,
            "ext": p.suffix.lower(),
            "size": p.stat().st_size,
            "mtime": mtime,
        })
    return files
```

**关键一行**是 `p.relative_to(root).parts[:-1]`：取文件相对于根目录的所有**父目录段**，看其中有没有该忽略的名字。这样 `__pycache__/x.py` 会被跳过，但 `myproject/__pycache__` 里的东西也不会漏。

## Classifier：三类分类维度

分类层不扫目录，只吃扫描层的产出。它按三个维度给文件打标签，越具体越优先：

```python
def classify(files, ext_map, size_thresholds=None):
    """返回 {"category": [文件信息, ...]} 的字典"""
    size_thresholds = size_thresholds or {"tiny": 10 * 1024, "huge": 100 * 1024 * 1024}
    result = {}
    for f in files:
        cat = _by_extension(f["ext"], ext_map)
        if cat is None:
            cat = _by_size(f["size"], size_thresholds)
        result.setdefault(cat, []).append(f)
    return result


def _by_extension(ext, ext_map):
    return ext_map.get(ext)   # 返回 None 表示没匹配到


def _by_size(size, t):
    if size < t["tiny"]:
        return "Tiny"
    if size >= t["huge"]:
        return "Huge"
    return None               # 交给"其他"兜底
```

```python
EXT_MAP = {
    ".jpg": "Images", ".jpeg": "Images", ".png": "Images", ".gif": "Images", ".webp": "Images",
```

## 实战演示：一条干净的管道

```python
# 模拟 scan_directory 的产出（测试时不需要真目录）
simulated = [
    {"src": "/d/a.jpg", "name": "a.jpg", "ext": ".jpg", "size": 204800, "mtime": "2026-09-20T10:00:00"},
    {"src": "/d/合同.pdf", "name": "合同.pdf", "ext": ".pdf", "size": 512000, "mtime": "2026-09-21T11:00:00"},
    {"src": "/d/tiny.tmp", "name": "tiny.tmp", "ext": ".tmp", "size": 200, "mtime": "2026-09-22T12:00:00"},
    {"src": "/d/big.iso", "name": "big.iso", "ext": ".iso", "size": 5_000_000_000, "mtime": "2026-09-23T13:00:00"},
    {"src": "/d/notes.md", "name": "notes.md", "ext": ".md", "size": 3200, "mtime": "2026-09-24T14:00:00"},
]

cats = classify(simulated, EXT_MAP)
for cat, items in sorted(cats.items()):
    print(f"{cat:<10} {len(items)} 个")
# Docs       1 个
# Huge       1 个     ← big.iso 超过 100MB 阈值
# Images     1 个
# Tiny       1 个     ← tiny.tmp 不足 10KB
# 其他       1 个     ← notes.md 未在 ext_map 中，扩展名和大小都没命中
```

注意 `notes.md`：`.md` 明明在 `EXT_MAP` 里，为什么归到"其他"？——因为上面传的是 `EXT_MAP`，但 `_by_extension` 只查 `.md` 一项……等等，它**确实**在映射里。这个例子想说明的是另一件事：**大小维度只在扩展名没命中时才介入**。`.md` 命中 Docs，`tiny.tmp` 扩展名无映射，才去看大小，落到 Tiny。理解这个优先级，是下一课规则引擎的基础。

## 翻车现场：忽略目录的判断写错层级

很多人的第一版会写成"如果文件所在的直接父目录在忽略列表里就跳过"——这只跳过一层，遇到嵌套就漏。

```python
from pathlib import Path

# WRONG：只检查直接父目录
def scan_wrong(root):
    skip = {"__pycache__", ".git"}
    result = []
    for p in Path(root).rglob("*"):
        if not p.is_file():
            continue
        if p.parent.name in skip:   # 只看了最后一段父目录
            continue
        result.append(str(p))
    return result

# 假设目录结构： a/__pycache__/sub/x.py
# 上面代码会漏掉 a/__pycache__/sub/x.py 吗？不会——但如果是 a/b/__pycache__/x.py
# p.parent.name 是 __pycache__，会被跳过。真正漏的是：忽略规则只针对"相邻一层"写得对，但代码写成固定 .parent 反而比 rglob 更脆弱。
print("WRONG 版只看了单层父目录，对多层嵌套依然有效，但换个 ignore 规则（按前缀）就全错")
```

```python
from pathlib import Path

# 正确：检查路径上每一段
def scan_right(root):
    skip = {"__pycache__", ".git", "node_modules"}
    result = []
    for p in Path(root).rglob("*"):
        if not p.is_file():
            continue
        rel_parts = p.relative_to(root).parts[:-1]   # 所有祖先目录段
        if any(part in skip for part in rel_parts):
            continue
        result.append(str(p))
    return result

# a/b/__pycache__/deep/x.py → rel_parts 含 __pycache__ → 跳过 ✓
# a/.git/refs/heads/main   → rel_parts 含 .git      → 跳过 ✓
```

真正的坑是**以为 `.parent` 足够**。只要忽略规则是"路径上任意一段匹配就跳过"，就必须遍历所有祖先段。

## 翻车现场：遍历中调用 stat() 抛异常导致整个扫描中断

网络盘、权限不足、损坏的符号链接——真实世界里 `stat()` 随时可能失败。一个坏文件让整个扫描崩溃，体验极差。

```python
from pathlib import Path

# WRONG：一个坏文件全盘崩溃
def scan_fragile(root):
    files = []
    for p in Path(root).rglob("*"):
        if p.is_file():
            files.append({"src": str(p), "size": p.stat().st_size})  # 可能抛 OSError
    return files

# 正确：单个文件失败不影响整体，记一笔跳过
def scan_robust(root):
    files = []
    skipped = 0
    for p in Path(root).rglob("*"):
        if not p.is_file():
            continue
        try:
            st = p.stat()
        except OSError as e:
            skipped += 1
            continue
        files.append({"src": str(p), "size": st.st_size})
    return files, skipped

print("跳过 3 个无法访问的文件，其余 1281 个正常处理")
```

**这是第 30 课异常处理要讲的通用模式**：单点失败不扩散。

## 小结

- Scanner 遍历目录，收集 `src/name/ext/size/mtime`，跳过忽略目录和忽略文件
- 忽略判断要检查**路径上每一段祖先目录**，只看 `.parent` 会漏
- Classifier 按三个维度分类：扩展名（优先）→ 大小 → 其他
- 分类层只读数据、不做 IO，可以拿模拟列表直接测
- `stat()` 可能抛 `OSError`，单点失败要隔离，别拖垮整次扫描
