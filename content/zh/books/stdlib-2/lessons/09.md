# 解析各种日期字符串

> 这一课解决"用户输入的日期格式五花八门，怎么容错地解析"。你会学会用 try/except 多格式尝试，以及 dateutil 的高级解析。

## 现实中的日期格式乱象

你永远不知道用户会输入什么格式的日期：

| 来源 | 典型格式 |
|---|---|
| 中国用户 | `2026年9月27日`、`2026-09-27`、`26/9/27` |
| 美国接口 | `09/27/2026`、`Sep 27, 2026`、`2026-09-27T14:30:00Z` |
| 日志文件 | `[2026-09-27 14:30:05]`、`27/Sep/2026:14:30:05 +0800` |
| 文件名 | `20260927_143005` |

如果只支持一种格式，用户一输错就崩。你需要**容错解析**。

## 多格式尝试法

这是最实用的方案：准备一组格式串，逐个尝试，第一个成功的就是答案。

```python
from datetime import datetime

def parse_date(s):
    """尝试多种格式解析日期字符串"""
    formats = [
        "%Y-%m-%d",
        "%Y/%m/%d",
        "%Y年%m月%d日",
        "%m/%d/%Y",
        "%d/%m/%Y",
        "%Y-%m-%d %H:%M:%S",
    ]
    for fmt in formats:
        try:
            return datetime.strptime(s, fmt)
        except ValueError:
            continue
    raise ValueError(f"无法解析日期: {s}")

print(parse_date("2026-09-27"))       # 2026-09-27 00:00:00
print(parse_date("09/27/2026"))       # 2026-09-27 00:00:00
print(parse_date("2026年09月27日"))    # 2026-09-27 00:00:00
```

## 翻车现场：格式有歧义时解析错了

```python
# WRONG：没有处理歧义
formats = ["%m/%d/%Y", "%d/%m/%Y"]

def parse(s):
    for fmt in formats:
        try:
            return datetime.strptime(s, fmt)
        except ValueError:
            continue

print(parse("03/04/2026"))
```

输出 `2026-03-04 00:00:00`——因为先尝试了 `%m/%d/%Y`，把 03 当成了月。但如果这是英国用户输的 `3rd April`，正确结果应该是 `2026-04-03`。

**这就是格式解析的固有限制**：当输入有歧义时，你必须**先验地知道**用户的格式习惯，或者让用户明确选择。程序无法自动判断 `03/04/2026` 是 3 月 4 日还是 4 月 3 日。

## 实战：解析带时区的 ISO 格式

很多 API 返回 ISO 8601 格式：`2026-09-27T14:30:00+08:00`

```python
from datetime import datetime
from zoneinfo import ZoneInfo

def parse_iso(s):
    """解析带时区的 ISO 8601 字符串"""
    # 替换 Z 为 +00:00（Z 表示 UTC）
    s = s.replace("Z", "+00:00")
    # Python 3.11+ 可以直接 fromisoformat
    return datetime.fromisoformat(s)

dt = parse_iso("2026-09-27T14:30:00+08:00")
print(dt)   # 2026-09-27 14:30:00+08:00

dt2 = parse_iso("2026-09-27T06:30:00Z")
print(dt2)  # 2026-09-27 06:30:00+00:00
```

Python 3.11+ 的 `fromisoformat` 已经支持解析带 `Z` 和 `+HH:MM` 后缀的 ISO 字符串。如果是更早版本，需要手动处理。

## 实战：宽松解析——提取数字

有些场景格式极度不统一，可以用正则提取年月日再组装：

```python
import re
from datetime import datetime

def parse_flexible(s):
    """极度宽松：提取所有数字，按位置组装"""
    numbers = re.findall(r'\d+', s)
    if len(numbers) >= 3:
        y, m, d = int(numbers[0]), int(numbers[1]), int(numbers[2])
        # 简单处理两位年份
        if y < 100:
            y += 2000
        return datetime(y, m, d)
    raise ValueError(f"无法提取日期: {s}")

print(parse_flexible("今天是2026年9月27号"))    # 2026-09-27 00:00:00
print(parse_flexible("日期: 2026/09/27"))      # 2026-09-27 00:00:00
```

## 第三方方案：dateutil.parser

如果允许用第三方库，`python-dateutil` 的 `parser.parse` 能自动识别几乎所有常见格式：

```python
# pip install python-dateutil
from dateutil.parser import parse

print(parse("2026-09-27"))
print(parse("Sep 27, 2026"))
print(parse("27/09/2026"))
print(parse("20260927"))
```

**但注意**：这也是有歧义的。`parse("03/04/2026")` 会按美国习惯解析成 3 月 4 日。可以用 `dayfirst=True` 参数指定。

## 实战例子：解析日志时间戳

```python
import re
from datetime import datetime

log_line = "2026-09-27 14:30:05 [INFO] 用户张三登录成功"

def extract_time(log):
    match = re.match(r'^(\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2})', log)
    if match:
        return datetime.strptime(match.group(1), "%Y-%m-%d %H:%M:%S")
    return None

print(extract_time(log_line))  # 2026-09-27 14:30:05
```

## 小结

- 多格式解析用 **try/except 循环尝试**一组格式串
- 有歧义的输入（`03/04/2026`）无法自动判断，需要用户指定或先验知识
- Python 3.11+ 的 `datetime.fromisoformat()` 支持 ISO 8601 格式
- 极度宽松解析可用正则提取数字再组装
- `python-dateutil` 的 `parser.parse` 能自动识别大多数格式（第三方库）
