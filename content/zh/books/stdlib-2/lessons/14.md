# 文件属性

> 这一课讲怎么读取文件的大小、修改时间等元信息，以及如何把 Unix 时间戳转换成人类可读的日期时间。你会学会 `stat()` 的用法，理解 `os.path.getsize` 和 `Path.stat().st_size` 的关系。

## stat()：一次获取所有文件属性

`Path.stat()` 返回一个 `os.stat_result` 对象，包含文件大小、修改时间、权限等所有元信息。调用一次就能拿到全部，比逐个查高效得多。

```python
from pathlib import Path
import time

p = Path("./data/report.pdf")
info = p.stat()

print(info.st_size)    # 文件大小（字节），如 245760
print(info.st_mtime)   # 最后修改时间（Unix 时间戳），如 1717027200.0
print(info.st_atime)   # 最后访问时间
print(info.st_ctime)   # 创建时间（Windows）/ 元数据变更时间（Unix）
```

`os.stat_result` 的常用属性：

| 属性 | 含义 |
|------|------|
| `st_size` | 文件大小（字节） |
| `st_mtime` | 最后修改时间（时间戳） |
| `st_atime` | 最后访问时间（时间戳） |
| `st_ctime` | 创建时间（平台相关） |
| `st_mode` | 权限位（整数） |

## 时间戳转可读时间

第 5 课我们学过 `datetime.fromtimestamp()`。这里直接用它把 `st_mtime` 变成可读的日期：

```python
from pathlib import Path
from datetime import datetime

p = Path("./data/report.pdf")
mtime = p.stat().st_mtime

# 时间戳 → datetime 对象
dt = datetime.fromtimestamp(mtime)
print(dt)                      # 2024-05-30 10:00:00
print(dt.strftime("%Y-%m-%d %H:%M:%S"))  # 自定义格式
```

⚠️ **注意 UTC 陷阱**：`fromtimestamp()` 使用的是**本地时区**。如果你存的时间戳是 UTC 的，应该用 `datetime.fromtimestamp(mtime, tz=timezone.utc)` 或在转换后 `.astimezone()` 转换时区。

## os.path.getsize vs Path.stat().st_size

`os.path.getsize()` 和 `Path.stat().st_size` 拿到的是同一个数字——前者底层就是调用了 `os.stat()`。

```python
import os
from pathlib import Path

p = Path("./data/report.pdf")

size_a = os.path.getsize(str(p))     # os.path 方式
size_b = p.stat().st_size            # pathlib 方式

print(size_a == size_b)   # True
```

**区别**：
- `os.path.getsize()` 只返回一个数字，如果你只需要大小，写起来最短
- `Path.stat()` 一次拿到所有属性（大小 + 时间 + 权限），如果你还要查修改时间，用它更省事（一次系统调用搞定）

```python
# 如果你既要大小又要时间，用 stat() 一次搞定
info = p.stat()
size = info.st_size
mtime = datetime.fromtimestamp(info.st_mtime)

# 如果用 os.path.getsize，还要再调用一次 os.path.getmtime（又是一次系统调用）
size = os.path.getsize(str(p))
mtime = os.path.getmtime(str(p))
```

## 翻车现场：忘记文件可能不存在

```python
from pathlib import Path

p = Path("./data/nonexistent.txt")

# WRONG：文件不存在时 stat() 直接抛异常
info = p.stat()   # FileNotFoundError!
```

报错：

```
FileNotFoundError: [Errno 2] No such file or directory: './data/nonexistent.txt'
```

**解决**：先检查存在性，或者用 try/except 包裹。

```python
p = Path("./data/nonexistent.txt")

if p.exists():
    info = p.stat()
    print(f"大小：{info.st_size} 字节")
else:
    print("文件不存在")

# 或者用 try/except
try:
    info = p.stat()
except FileNotFoundError:
    print("文件不存在，跳过")
```

## 翻车现场：用 st_mtime 直接做字符串格式化

```python
from pathlib import Path

p = Path("./data/report.pdf")

# WRONG：st_mtime 是浮点数，不是 datetime，不能直接 strftime
mtime = p.stat().st_mtime
print(mtime.strftime("%Y-%m-%d"))   # AttributeError!
```

报错：

```
AttributeError: 'float' object has no attribute 'strftime'
```

**解决**：先用 `datetime.fromtimestamp()` 转换。

```python
from datetime import datetime

mtime = p.stat().st_mtime
dt = datetime.fromtimestamp(mtime)
print(dt.strftime("%Y-%m-%d %H:%M:%S"))   # 正确
```

## 格式化文件信息：一个实用小函数

把上面学到的串起来，写一个函数，输入路径，输出人类可读的文件信息：

```python
from pathlib import Path
from datetime import datetime

def file_info(path_str):
    p = Path(path_str)
    if not p.exists():
        return f"{path_str} 不存在"
    info = p.stat()
    size_kb = info.st_size / 1024
    mtime = datetime.fromtimestamp(info.st_mtime).strftime("%Y-%m-%d %H:%M:%S")
    return f"{p.name} | {size_kb:.1f} KB | 修改于 {mtime}"

print(file_info("./data/report.pdf"))
# report.pdf | 240.0 KB | 修改于 2024-05-30 10:00:00
```

## 小结

- `Path.stat()` 一次获取文件所有属性，`st_size` 是大小，`st_mtime` 是修改时间戳
- 时间戳用 `datetime.fromtimestamp()` 转成可读格式，注意本地时区与 UTC 的区别
- `os.path.getsize()` 和 `Path.stat().st_size` 结果相同，前者只取大小，后者一次取全部
- 需要多个属性时用 `stat()` 更省系统调用
- `stat()` 在文件不存在时抛 `FileNotFoundError`，记得先检查或捕获异常
- `st_mtime` 是浮点数，不能直接 `strftime`，必须先用 `datetime.fromtimestamp()` 转换
