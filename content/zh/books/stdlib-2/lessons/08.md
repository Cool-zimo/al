# 日期计算进阶

> 这一课解决"当月最后一天是几号、某个日期是第几周、怎么算工作日"。你会用 `calendar` 模块和 date 对象的内置方法搞定这些日常需求。

## 当月最后一天

"某个月的最后一天是几号"是最常见的日期计算之一。第一反应可能是查表，但 Python 有个巧妙的写法：

```python
from datetime import date

# 妙招：下个月的第 0 天 = 这个月的最后一天
def last_day_of_month(year, month):
    if month == 12:
        next_month = date(year + 1, 1, 1)
    else:
        next_month = date(year, month + 1, 1)
    return next_month - date.resolution  # 不行，换个思路

# 更简单的写法
def last_day(year, month):
    if month == 12:
        return date(year + 1, 1, 1) - __import__("datetime").timedelta(days=1)
    return date(year, month + 1, 1) - __import__("datetime").timedelta(days=1)

print(last_day(2026, 2))   # 2026-02-28
print(last_day(2024, 2))   # 2024-02-29（闰年！）
print(last_day(2026, 4))   # 2026-04-30
```

**原理**：下个月的 1 号减去 1 天，就是这个月的最后一天。`date` 自动处理所有进位，包括闰年。

## calendar 模块：更多日期信息

```python
import calendar

# 某月有多少天
print(calendar.monthrange(2026, 2))   # (6, 28)
# 返回 (第一天是星期几, 这个月有多少天)
# 6 = 周日（0=周一），28 天

print(calendar.monthrange(2024, 2))   # (3, 29) ← 2024 闰年 29 天

# 某月日历
print(calendar.month(2026, 9))
```

`calendar.monthrange(year, month)` 返回的元组：第一个值是该月 1 号是星期几（0=周一），第二个值是该月天数。

## 翻车现场：自己写闰年判断出错

```python
# WRONG：遗漏了百年规则
def days_in_month(year, month):
    days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
    if month == 2 and year % 4 == 0:
        return 29
    return days[month - 1]

print(days_in_month(1900, 2))   # 29？错！1900 不是闰年，应该是 28
```

**正确做法**：用 calendar 模块，它已经帮你处理了所有规则：

```python
import calendar

def days_in_month(year, month):
    return calendar.monthrange(year, month)[1]

print(days_in_month(1900, 2))   # 28 ✓
print(days_in_month(2000, 2))   # 29 ✓
print(days_in_month(2024, 2))   # 29 ✓
```

## 第几周：isocalendar

```python
from datetime import date

d = date(2026, 1, 1)
print(d.isocalendar())       # (2026, 1, 4) → (年份, 第几周, 星期几)

d2 = date(2026, 12, 31)
print(d2.isocalendar())      # (2026, 53, 4)
```

`isocalendar()` 返回 `(ISO_year, ISO_week, ISO_weekday)`。ISO 周的规则：

- 一周从周一开始
- 第 1 周是包含该年第一个周四的那一周
- 所以 1 月初可能属于上一年的第 52/53 周，12 月底可能属于下一年的第 1 周

## 工作日计算

```python
from datetime import date, timedelta

def is_workday(d):
    """判断是否为工作日（周一到周五）"""
    return d.weekday() < 5   # 0-4 是工作日，5-6 是周末

def next_workday(d):
    """返回下一个工作日"""
    while True:
        d += timedelta(days=1)
        if is_workday(d):
            return d

print(is_workday(date(2026, 9, 28)))   # True（周一）
print(is_workday(date(2026, 9, 26)))   # False（周六）

print(next_workday(date(2026, 9, 25)))  # 2026-09-28（周五→下周一）
```

## 实战例子：生成当月所有工作日

```python
from datetime import date, timedelta
import calendar

def get_workdays(year, month):
    """返回某月所有工作日的列表"""
    _, days = calendar.monthrange(year, month)
    workdays = []
    for day in range(1, days + 1):
        d = date(year, month, day)
        if d.weekday() < 5:
            workdays.append(d)
    return workdays

ws = get_workdays(2026, 9)
print(f"2026年9月共 {len(ws)} 个工作日")
```

## 实战例子：判断是否是月底最后 N 天

```python
from datetime import date, timedelta
import calendar

def is_last_n_days(d, n):
    """判断日期是否在当月最后 n 天内"""
    _, total_days = calendar.monthrange(d.year, d.month)
    return d.day > total_days - n

print(is_last_n_days(date(2026, 9, 28), 3))   # True
print(is_last_n_days(date(2026, 9, 25), 3))   # False
```

## 小结

- 当月最后一天：`date(year, month+1, 1) - timedelta(days=1)`
- `calendar.monthrange(year, month)` → `(首日是周几, 天数)`
- `calendar.monthrange(年, 月)[1]` 获取某月天数（自动处理闰年）
- `date.isocalendar()` 获取 ISO 年份、周数、星期
- 工作日判断：`weekday() < 5`
- **不要自己写闰年/月份天数逻辑**，用标准库
