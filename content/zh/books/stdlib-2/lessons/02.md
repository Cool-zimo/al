# datetime 三兄弟

> 这一课解决"date、time、datetime 到底用哪个"。你会明白三个类型各管什么，以及什么时候该组合、什么时候该拆分。

## 三个类型，三种粒度

`datetime` 模块里有三个最常用的类，名字容易混，但职责完全不同：

| 类 | 管什么 | 典型用途 |
|---|---|---|
| `date` | 年-月-日 | 生日、截止日、还款日 |
| `time` | 时:分:秒.微秒 | 闹钟时间、营业时间 |
| `datetime` | 年-月-日 时:分:秒 | 日志时间戳、订单创建时间 |

```python
from datetime import date, time, datetime

d = date(2026, 9, 27)          # 只有日期
t = time(14, 30, 0)             # 只有时间
dt = datetime(2026, 9, 27, 14, 30, 0)  # 日期+时间

print(d)    # 2026-09-27
print(t)    # 14:30:00
print(dt)   # 2026-09-27 14:30:00
```

**关键区别**：`date` 不知道几点，`time` 不知道哪天。`datetime` 两者都有，但占用更多空间、操作也更复杂。

## date：只要年月日的场景

适合场景：纪念日、合同期限、生日提醒。

```python
from datetime import date

today = date.today()
print(today)              # 2026-09-27（运行当天）
print(today.year)         # 2026
print(today.month)        # 9
print(today.day)          # 27
print(today.weekday())    # 6 → 周日（0=周一，6=周日）
```

注意 `weekday()` 返回 0 到 6，对应周一到周日。如果你习惯周日为一周的开始，用 `isoweekday()`，它返回 1 到 7（周一到周日）。

```python
print(today.isoweekday())  # 7 → 周日
```

## time：只要时分秒的场景

适合场景：定时提醒、店铺营业时间、日程表的时间段。

```python
from datetime import time

opening = time(9, 0)       # 9:00 开门
closing = time(22, 30)     # 22:30 关门
now = time(14, 30)

print(opening.hour)    # 9
print(closing.minute)  # 30
print(now > opening)   # True
```

`time` 对象可以直接比较大小——早上 9 点小于下午 2 点，这很直觉。

## datetime：日期时间合体

适合场景：日志、订单时间、消息发送时间——所有需要知道"具体哪一刻"的场景。

```python
from datetime import datetime

now = datetime.now()
print(now)           # 2026-09-27 14:30:05.123456

# 组合 date + time → datetime
from datetime import date, time
d = date(2026, 9, 27)
t = time(9, 0)
dt = datetime.combine(d, t)
print(dt)   # 2026-09-27 09:00:00

# 反过来拆开
print(dt.date())   # 2026-09-27
print(dt.time())   # 09:00:00
```

## 翻车现场：混用 date 和 datetime 直接报错

```python
from datetime import date, datetime

d = date(2026, 9, 27)
dt = datetime(2026, 9, 27, 10, 0)

# WRONG：date 和 datetime 不能直接比较
print(dt > d)
```

报错：

```
TypeError: can't compare datetime.datetime to datetime.date
```

这两个类型不能直接比大小。正确做法：把 date 转成 datetime，或把 datetime 转成 date。

```python
# 正确：把 date 转成 datetime 的"当天零点"
from datetime import datetime, time
dt_same_day = datetime.combine(d, time.min)  # 2026-09-27 00:00:00
print(dt > dt_same_day)   # True
```

或者反过来，只取 datetime 的日期部分来比：

```python
print(dt.date() == d)   # True
```

## 翻车现场：datetime.now() 的时区问题

```python
from datetime import datetime

# WRONG：now() 返回的是"本地时间"，但没有时区信息
t = datetime.now()
print(t)           # 2026-09-27 14:30:05.123456
print(t.tzinfo)    # None ← 没有时区！
```

这种对象叫 **naive**（天真的）——它带着本地时钟的数字，但不知道自己属于哪个时区。如果把这个值存进数据库，另一个时区的用户读出来就是错的。后面第 06 课专门讲时区。

## 小结

- `date` = 年月日，`time` = 时分秒，`datetime` = 日期+时间
- 三个类型**不能混用比较**，需要 `datetime.combine()` 或 `.date()` 转换
- `date.today()` / `datetime.now()` 获取当前时间
- `date.weekday()` 返回 0-6（周一=0），`isoweekday()` 返回 1-7
- `datetime.now()` 返回 naive 对象，不带时区信息（第 06 课解决）
