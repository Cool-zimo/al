# timedelta：时间差与日期加减

> 这一课解决"如何正确地给日期加天数、算两个时间点差多久"。你会明白 timedelta 的边界——它能加天、秒、微秒，但**不能加月**。

## timedelta 是什么

`timedelta` 代表一段**持续时间**。它是 date 和 datetime 做加减法时产生的中间类型，也可以直接创建。

```python
from datetime import timedelta, date, datetime

# 创建 timedelta
one_day = timedelta(days=1)
three_hours = timedelta(hours=3)
one_week = timedelta(weeks=1)     # 等同于 days=7

print(one_day)        # 1 day, 0:00:00
print(three_hours)    # 3:00:00
print(one_week)       # 7 days, 0:00:00
```

timedelta 支持的参数：`weeks`、`days`、`hours`、`minutes`、`seconds`、`milliseconds`、`microseconds`。

## 日期加减：核心用法

```python
from datetime import date, timedelta

today = date(2026, 9, 27)

tomorrow = today + timedelta(days=1)
print(tomorrow)   # 2026-09-28

next_week = today + timedelta(weeks=1)
print(next_week)  # 2026-10-04

last_month_ish = today - timedelta(days=30)
print(last_month_ish)  # 2026-08-28
```

这里体现了标准库的价值：**date 加 timedelta 自动处理月份进位**。你不用管 9 月有多少天、跨年怎么办。

## 两个日期相减：得到 timedelta

```python
from datetime import date

deadline = date(2026, 12, 31)
today = date(2026, 9, 27)

remaining = deadline - today
print(remaining)            # 95 days, 0:00:00
print(remaining.days)       # 95
print(remaining.total_seconds())  # 8208000.0
```

`timedelta.days` 取整数天，`total_seconds()` 换算成秒。

## 翻车现场：timedelta 不支持 months

这是最常见的坑：

```python
from datetime import timedelta

# WRONG：timedelta 根本没有 months 参数
delta = timedelta(months=1)
```

报错：

```
TypeError: 'months' is an invalid keyword argument for timedelta()
```

**timedelta 只认天、秒、微秒。** 为什么？因为"一个月"不是一个固定长度——2 月 28 天，有的年份 29 天，其他月份 30 或 31 天。timedelta 设计上就不接受这种"模糊"的间隔。

正确做法：要加一个月，用 `dateutil.relativedelta`（第三方库），或者自己算。标准库里最实用的替代方案是操作 `date.replace()`：

```python
from datetime import date

d = date(2026, 1, 15)

# 加一个月：手动进位
month = d.month + 1
year = d.year
if month > 12:
    month = 1
    year += 1
d2 = date(year, month, min(d.day, 28))  # 防止 1月31日→2月31日
print(d2)   # 2026-02-15（但如果是1月31日，会截断为2月28日）
```

或者用 `calendar` 模块算出当月最后一天来确保安全（第 08 课会详细讲）。

## 翻车现场：时间差的单位搞错

```python
from datetime import datetime

t1 = datetime(2026, 9, 27, 10, 0, 0)
t2 = datetime(2026, 9, 27, 12, 30, 0)

delta = t2 - t1
print(delta.seconds)        # 9000
print(delta.total_seconds())  # 9000.0
print(delta.days)           # 0
```

`delta.seconds` 返回的是**不足一天的部分**的秒数（9000 秒 = 2 小时 30 分），不是总秒数。`delta.days` 是完整的天数部分。想要总时间差，用 `total_seconds()`。

如果跨越了午夜：

```python
t1 = datetime(2026, 9, 27, 23, 0, 0)
t2 = datetime(2026, 9, 28, 2, 0, 0)

delta = t2 - t1
print(delta.days)           # 0  ← 不足一天！
print(delta.seconds)        # 10800 ← 3 小时，不是 27 小时
print(delta.total_seconds())  # 10800.0 ← 这才是真实差值
```

## timedelta 也能乘和取绝对值

```python
from datetime import timedelta

one_day = timedelta(days=1)
print(one_day * 7)        # 7 days, 0:00:00
print(one_day / 2)        # 0:12:00
print(one_day * 1.5)      # 1 day, 12:00:00

d1 = timedelta(days=1)
d2 = timedelta(days=3)
print(abs(d1 - d2))       # 2 days, 0:00:00
```

## 实战例子：计算会员到期日

```python
from datetime import date, timedelta

def calc_expiry(join_date, plan):
    """根据套餐类型计算到期日"""
    plans = {"月卡": 30, "季卡": 90, "年卡": 365}
    days = plans.get(plan, 30)
    return join_date + timedelta(days=days)

join = date(2026, 9, 27)
print(calc_expiry(join, "月卡"))  # 2026-10-27
print(calc_expiry(join, "年卡"))  # 2027-09-27
```

## 小结

- `timedelta` 代表一段时间，支持 days/seconds/microseconds/weeks/hours/minutes
- date/datetime + timedelta → 新日期（自动处理进位）
- 两个日期相减 → timedelta
- **timedelta 没有 months 参数**，加月要用第三方库或手动算
- `delta.total_seconds()` 取总秒数；`delta.seconds` 只取不足一天的部分
- timedelta 支持乘法、除法、绝对值
