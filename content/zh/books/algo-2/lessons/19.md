# 单调队列：滑动窗口最大值

> 给你一个数组和一个窗口大小 k，窗口从左滑到右，每次问"窗口里的最大值是多少"。暴力 O(nk)，单调队列 O(n)——每个元素只进队出队一次。

## 问题

```
nums = [1, 3, -1, -3, 5, 3, 6, 7], k = 3

窗口滑动过程：
[1  3  -1] -3  5  3  6  7  → max = 3
 1 [3  -1  -3] 5  3  6  7  → max = 3
 1  3 [-1  -3  5] 3  6  7  → max = 5
 1  3  -1 [-3  5  3] 6  7  → max = 5
 1  3  -1  -3 [5  3  6] 7  → max = 6
 1  3  -1  -3  5 [3  6  7] → max = 7

输出: [3, 3, 5, 5, 6, 7]
```

暴力做法：每个窗口遍历 k 个元素找最大值。共 n-k+1 个窗口，每个 O(k)，总计 **O(nk)**。当 n=10⁵, k=10⁵ 时，这是 10¹⁰ 次操作，直接超时。

## 核心思路：队列里只留"有前途"的候选

单调队列的关键洞察：**如果窗口里有一个小的值，它左边还有一个比它大的值，那这个小的值在"大值还活着"的时候永远不可能成为最大值。**

换句话说：**大值活着的时候，小值没有存在的意义。**

```python
from collections import deque

def max_sliding_window(nums, k):
    q = deque()              # 存下标，队列从队首到队尾对应的值单调递减
    result = []

    for i, x in enumerate(nums):
        # ① 维护单调性：新元素比队尾小才有资格入队
        #    如果队尾的值 <= x，那它在 x 活着时永远当不了最大值，踢掉
        while q and nums[q[-1]] <= x:
            q.pop()
        q.append(i)

        # ② 移除窗口外的旧元素（队首过期）
        if q[0] == i - k:
            q.popleft()

        # ③ 窗口形成后，队首就是当前窗口的最大值
        if i >= k - 1:
            result.append(nums[q[0]])

    return result
```

**手跑一遍** `nums = [1, 3, -1, -1, 5, 3, 6, 7]`, `k = 3`：

```
i=0, x=1:  q空, 入队 [0]           窗口未成形
i=1, x=3:  nums[0]=1<=3, 弹出0, 入队[1]   窗口未成形
            (3 比 1 大，1 永远不会是最大值)
i=2, x=-1: nums[1]=3>-1, 不弹, 入队[1,2]  窗口成形! 队首nums[1]=3 → [3]
i=3, x=-1: nums[2]=-1<=-1, 弹出2, 入队[1,3] 队首nums[1]=3 → [3,3]
            (-1<=-1 弹出2号，因为新-1和旧-1一样大时，旧的位置更靠左会更早过期)
i=4, x=5:  nums[3]=-1<=5, 弹出3; nums[1]=3<=5, 弹出1; 入队[4]
            队首nums[4]=5 → [3,3,5]
i=5, x=3:  nums[4]=5>3, 不弹, 入队[4,5]    队首nums[4]=5 → [3,3,5,5]
i=6, x=6:  nums[5]=3<=6, 弹出5; nums[4]=5<=6, 弹出4; 入队[6]
            队首nums[6]=6 → [3,3,5,5,6]
i=7, x=7:  nums[6]=6<=7, 弹出6; 入队[7]    队首nums[7]=7 → [3,3,5,5,6,7]
结果: [3, 3, 5, 5, 6, 7]
```

## 为什么是 O(n)：每个元素进出各一次

| 操作 | 频次 | 说明 |
|---|---|---|
| `while q and ...: q.pop()` | 总计 ≤ n 次 | 每个元素最多被弹出一次 |
| `q.append(i)` | 恰好 n 次 | 每个元素入队一次 |
| `q.popleft()` | 恰好 n 次 | 每个元素最多成为队首并被移出一次 |

虽然 while 循环看起来是嵌套的，但**所有 pop 操作加起来不超过 n 次**——因为每个元素只进队一次，也最多被弹出一次。这就是"均摊 O(1)"的含义。总复杂度 **O(n)**。

对比暴力的 O(nk)，当 k 很大时差距是天壤之别。

## 翻车现场：队列里存值而不是存下标

```python
# WRONG：队列里存值
q = deque()
for x in nums:
    while q and q[-1] <= x:
        q.pop()
    q.append(x)          # 存的是值
    # 问题：怎么判断队首是否过期？
    # 你不知道队首这个值是在哪个位置出现的！
```

**存值不存下标的致命问题**：你无法判断队首元素是否已经滑出窗口。同一个值可能出现多次，你不知道该移除哪一个。

```python
# RIGHT：存下标
q = deque()
for i, x in enumerate(nums):
    while q and nums[q[-1]] <= x:
        q.pop()
    q.append(i)              # 存下标
    # 判断过期：队首下标是否 <= i - k
    if q[0] == i - k:
        q.popleft()
    # 队首的下标对应的值就是最大值
```

**存下标既能用 nums[队首] 取值，又能用下标判断过期时间，一举两得。**

## 翻车现场：判断过期的条件写错

```python
# WRONG：用 q[0] < i - k（小于号）
if q[0] < i - k:
    q.popleft()
# 当 q[0] == i - k 时，这个元素恰好在窗口左边界上，
# 窗口是 [i-k+1, i-k+2, ..., i]，左边界是 i-k+1
# q[0] == i-k 说明它在窗口左边一位，已经出去了！

# WRONG2：用 q[0] <= i - k + 1（想太多了）
# 条件应该是：队首下标 <= i - k 时，它不在窗口内

# RIGHT：q[0] == i - k 时刚好过期
if q[0] <= i - k:
    q.popleft()
```

**记忆方法**：窗口覆盖的下标范围是 `[i-k+1, i]`。队首下标 ≤ i-k 说明它在窗口左边，需要移除。

## 翻车现场：比较符号 `<` 和 `<=` 混用

```python
# 用 <= 还是 < ？取决于你要不要保留相等元素
while q and nums[q[-1]] <= x:   # 用 <= ：相等的也弹出
    q.pop()
```

对于"滑动窗口最大值"这道题，用 `<=` 和 `<` 都行，但含义不同：

- `<=`：相等的旧元素会被弹出，队列里不会有重复值。新元素的位置更靠右，寿命更长，弹出旧的是合理的。
- `<`：相等值会保留在队列里。结果也是正确的，因为队首仍然能取到最大值。

**但如果你用的是 `<` 而题目要求"严格递减"，队列里会出现相同值，可能影响后续判断**。建议统一用 `<=` 保持严格单调。

## 单调队列 vs 第 6 章的堆/优先队列

第 6 章你可能学过用**大顶堆**做滑动窗口最大值：

| 方法 | 插入 | 取最大值 | 移除过期元素 | 总时间 |
|---|---|---|---|---|
| 暴力 | O(1) | O(k) | — | O(nk) |
| 大顶堆 | O(log k) | O(1) | O(log k) 懒删除 | O(n log k) |
| **单调队列** | 均摊 O(1) | O(1) | O(1) | **O(n)** |

**单调队列的优势**：它不仅维护"当前最大是谁"，还利用滑动窗口的**顺序性**——窗口只移动一格，你可以精确保留"有前途的候选"，把"没前途的"提前淘汰。这是堆做不到的。

**什么时候用堆，什么时候用单调队列？**
- 窗口大小固定、只要最大/最小值 → 单调队列 O(n) 最优
- 窗口大小变化、或需要第 K 大 → 堆更灵活

## 复杂度

| 指标 | 值 |
|---|---|
| 时间 | **O(n)**，每个元素入队出队各一次 |
| 空间 | **O(k)**，队列最多存 k 个元素 |

从 O(nk) 到 O(n)，省掉的是每个窗口里"从头找最大值"的内循环。

## 小结

- 单调队列 = 队列中元素保持单调递减（从队首到队尾）
- **队首永远是当前窗口的最大值**，取最大值 O(1)
- 维护两件事：① 新元素入队前踢掉所有 ≤ 它的队尾  ② 队首过期时 popleft
- **必须存下标**，因为需要判断元素是否滑出窗口
- 每个元素进出队各一次，均摊 O(1)，总时间 O(n)
- 单调队列 > 堆 当窗口固定且只要最大/最小值时
