# 实战：表达式求值与计算器

> 给你一串中缀表达式 `"3 + 5 * (2 - 4)"`，怎么算出结果？这是栈的综合应用——两个栈（操作数栈 + 运算符栈），靠运算符优先级决定"谁先算"。

## 为什么计算器要用栈

人写表达式习惯用**中缀**（运算符在操作数中间，如 `3 + 5 * 2`），但计算机算的时候要先知道"先算哪部分"。这本质上是**就近匹配**问题——`(` 要等 `)` 来"结算"它里面的内容，而栈正是干这个的。

> 中缀表达式 → 借助栈 → 按优先级正确求值。

## 运算符优先级

先定义一张优先级表：

```python
precedence = {'+': 1, '-': 1, '*': 2, '/': 2}
```

`*` `/` 优先级是 2，`+` `-` 是 1。**优先级高的先算**。同级的从左到右（左结合）。

## 两个栈的思路

| 栈 | 存什么 |
|---|---|
| `vals` | 操作数（数字） |
| `ops` | 运算符 |

规则一句话：**新来的运算符如果优先级 ≤ 栈顶运算符，就先把栈顶运算做完，再压新运算符。** 括号是特例——`(` 压栈，`)` 一路算到 `(`。

```python
def eval_expr(s):
    precedence = {'+': 1, '-': 1, '*': 2, '/': 2}
    vals, ops = [], []
    i = 0
    while i < len(s):
        c = s[i]
        if c == ' ':                    # 跳过空格
            i += 1; continue
        if c.isdigit():                 # 多位数字要一次读完
            num = 0
            while i < len(s) and s[i].isdigit():
                num = num * 10 + int(s[i]); i += 1
            vals.append(num); continue
        if c == '(':
            ops.append(c)
        elif c == ')':                  # 一路算到 '('
            while ops[-1] != '(':
                _apply(vals, ops.pop())
            ops.pop()                   # 扔掉 '('
        else:                           # 运算符 + - * /
            while ops and ops[-1] != '(' and precedence[ops[-1]] >= precedence[c]:
                _apply(vals, ops.pop())
            ops.append(c)
        i += 1
    while ops:                          # 扫完后把剩余运算符算完
        _apply(vals, ops.pop())
    return vals[0]

def _apply(vals, op):
    b = vals.pop(); a = vals.pop()      # 注意顺序：先出的是右操作数
    if op == '+': vals.append(a + b)
    elif op == '-': vals.append(a - b)
    elif op == '*': vals.append(a * b)
    elif op == '/': vals.append(int(a / b))   # 向零取整
```

`_apply` 是真正做计算的地方：弹出两个数、弹出一个运算符、把结果压回操作数栈。

## 手跑 `3 + 5 * 2`

```
读 3       → vals=[3]
读 +       → ops 空，压入     ops=['+']
读 5       → vals=[3,5]
读 *       → 栈顶 '+' 优先级1 < 2，不弹，压入  ops=['+','*']
读 2       → vals=[3,5,2]
扫描结束    → 弹出 '*': 5*2=10 → vals=[3,10]
             弹出 '+': 3+10=13 → vals=[13]
返回 13 ✓
```

注意：**`*` 没被弹掉，因为它优先级更高，要"先算"。** 这就是"优先级高先算"的栈式表达。

## 手跑 `3 * (5 + 2)`

```
读 3       → vals=[3]
读 *       → ops=['*']
读 (       → ops=['*','(']
读 5       → vals=[3,5]
读 +       → 栈顶是 '('，不弹（遇到左括号要等它配对的右括号）ops=['*','(','+']
读 2       → vals=[3,5,2]
读 )       → 一路算到 '('：弹出 '+' → 5+2=7 → vals=[3,7]，弹出 '('
扫描结束    → 弹出 '*': 3*7=21 → vals=[21]
返回 21 ✓
```

`(` 的作用是**隔离优先级**——它把一整段子表达式"封"起来，等 `)` 来结算。

## 翻车现场：多位数只读了第一位

```python
# WRONG
for c in s:
    if c.isdigit():
        vals.append(int(c))    # "42" 会被读成 4 和 2 两个数字
```

输入 `42 + 1`，你会得到 `4 2 1` 三个操作数，结果变成 `4+2+1=7`。**必须用一个 while 把连续数字读完**：`num = num*10 + int(c)`。这是写计算器最常犯的错。

## 翻车现场：`_apply` 里 a、b 顺序写反

```python
# WRONG
def _apply(vals, op):
    a = vals.pop(); b = vals.pop()   # 先出的是右操作数！
    vals.append(a - b)              # 8-3 算成 3-8=-5
```

栈是 LIFO。先压进去的是左操作数 `a`，后压的是右操作数 `b`。所以弹出顺序必须是 `b = pop(); a = pop()`。**减法、除法顺序一反答案就错**，而且因为都是数字运算，Python 不会报错——bug 极其隐蔽。

## 翻车现场：除法向零取整搞错

```python
vals.append(a / b)          # 浮点，3/2=1.5
vals.append(a // b)         # Python 的 // 是向下取整：-3//2=-2，不是向零！
```

计算器的除法（如 LeetCode 227 基本计算器）通常要求**向零截断**。`int(a/b)` 在 Python 里就是向零取整（因为 `/` 返回浮点，`int()` 直接截断小数部分）。**别用 `//`**，它和数学上的"向零取整"在负数时不一致。

## 翻车现场：忘了扫完表达式后把 ops 清空

```python
# WRONG：循环结束后直接 return vals[0]
while i < len(s):
    ...
return vals[0]          # ops 里可能还留着没算的运算符
```

输入 `3 + 4`，循环结束时 `ops=['+']` 还在，`vals=[3,4]`，直接返回 `vals[0]=3`。**扫描结束后必须 `while ops: apply(pop())`**，把所有剩余运算符算完。

## 进阶：中缀转后缀（逆波兰）

如果你想先转成后缀再算，思路是另一套（输出队列 + 运算符栈），结果形如：

```
中缀:  3 + 5 * 2
后缀:  3 5 2 * +        ← 没有括号，计算时遇到运算符就弹出两个数算

中缀:  (3 + 5) * 2
后缀:  3 5 + 2 *
```

后缀表达式的好处是**计算时只需要一个栈**，不需要优先级判断：从左到右扫，数字压栈，遇到运算符就弹两个数算，结果压回。这是很多编译器和计算器内部的中间表示。

## 复杂度

| 指标 | 值 |
|---|---|
| 时间 | O(n)，每个字符进出栈各一次 |
| 空间 | O(n)，栈最坏存满 |

## 小结

- 计算器 = 操作数栈 + 运算符栈，靠优先级决定计算顺序
- 新运算符优先级 ≤ 栈顶 → 先把栈顶算掉
- `(` 压栈，`)` 一路算到 `(`；括号隔离优先级
- 多位数要用 while 连续读，不能只读一位
- `_apply` 弹出顺序：`b=pop(); a=pop()`，减法和除法顺序不能反
- 除法用 `int(a/b)` 向零取整，别用 `//`
- 扫描结束后必须把 ops 里的运算符全部算完

## 本节测验

```quiz
type: choice
exam: true
q: 用两个栈计算表达式时，遇到一个新的运算符为什么可能要先"把栈顶的运算符算掉"再压栈？
options:
- 为了让栈看起来更短
- 因为栈顶运算符优先级更高或同级（左结合），它必须比新运算符先执行
- 因为 Python 的栈最多只能存 3 个元素
- 因为数字栈和运算符栈必须一样长
answer: 1
explain: 新运算符进栈前，若栈顶优先级 ≥ 它，说明栈顶代表的运算要"先算完"才能轮到新的。这正是"优先级高的先算"在栈上的实现方式。同级时从左到右（左结合），也要先算栈顶。
```
