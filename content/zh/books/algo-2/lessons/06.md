# 快慢指针找中点：判环、找中点

> 快慢指针是链表的独门绝技。两个指针同起步、不同速，能做的事远超想象：找中点、判环、找倒数第 k 个。


## 快慢指针的基本形态

一个一次走一步，一个一次走两步。

```python
def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:        # 相遇了！
            return True
    return False
```

`fast and fast.next` 这个循环条件是**铁律**：因为 fast 一次走两步，必须先确认它自己不是 None、它的 next 也不是 None，否则 `fast.next.next` 会崩。


## 找中点：慢指针正好停在中点

fast 走到终点时，slow 正好在中间。

```python
def find_middle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow

print(find_middle(build([1,2,3,4,5])).val)   # 3
print(find_middle(build([1,2,3,4])).val)     # 2（偶数时停在左中点）
```

**原理**：fast 走 2 步时 slow 走 1 步，fast 走的总路程永远是 slow 的两倍。fast 走完全程时，slow 正好走了一半。


## 翻车现场：偶数长度时中点位置不一致

```python
# WRONG（语义不清）
def middle(head):
    slow = fast = head
    while fast.next:        # 少判断了 fast 本身
        slow = slow.next
        fast = fast.next.next
    return slow
```

```text
输入 [1,2]：fast 一开始就是 1，fast.next 是 2，进入循环。
slow=2, fast=fast.next.next=None.next → AttributeError: 'NoneType' object has no attribute 'next'
```

而且偶数长度时「中点」有两种理解：**左中点**（长度 4 时是 2）和**右中点**（长度 4 时是 3）。上面的模板给的是**左中点**。

要拿**右中点**（归并排序常用），让 fast 从 `head.next` 起步，或循环条件改成 `while fast and fast.next`。


## 找中点后切开

很多题要求「把链表从中间切成两半」：

```python
def split(head):
    slow = fast = head
    prev = None                      # 记录 slow 的前驱
    while fast and fast.next:
        prev = slow
        slow = slow.next
        fast = fast.next.next
    prev.next = None                 # 切断
    return head, slow                # 左半、右半

left, right = split(build([1,2,3,4,5]))
print(to_list(left))     # [1, 2, 3]
print(to_list(right))    # [4, 5]
```

`prev` 用来在最后把链切断（`prev.next = None`）。这也是归并排序切分的基础。


## 小结

- - 快慢指针：slow 一步、fast 两步，fast 路程是 slow 的两倍
- - 循环条件必须是 `while fast and fast.next`，否则 fast.next.next 崩
- - fast 走完时 slow 正好在中点（偶数时是左中点）
- - 要切分链表，还需维护 slow 的前驱来切断

```quiz
type: choice

q: 用快慢指针找中点时，为什么循环条件必须写成 while fast and fast.next:？
options:
- 因为 fast 一次走两步，必须保证 fast 和 fast.next 都不是 None，否则 fast.next.next 会触发属性错误
- 因为 slow 一次走两步
- 为了统计走了几步
- 为了节省时间
answer: 0
explain: fast 每轮前进两步（fast.next.next），所以进入本轮时 fast 自身和 fast.next 都必须存在。若只判断 fast，遇到长度为 2 的链表会进入循环，fast 走到 None 后再取 None.next 就崩溃。这是所有「fast 走两步」模板的统一入口条件。
```
