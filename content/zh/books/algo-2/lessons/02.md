# ListNode 与手写链表：定义节点、串起来、遍历打印

> 这一课亲手把链表造出来：定义节点、把节点串成一条链、遍历并打印。链表从此不再抽象。


## 节点是什么

链表的最小单元叫**节点（Node）**，它有两样东西：一个**数据**，一个**指向下一个节点的指针**。

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val      # 存的数据
        self.next = next    # 指向下一个节点，没有就是 None
```

就这么简单。一个节点 = 一个值 + 一个箭头。

```
   ┌────┬────┐
   │ 42 │  ──┼──→ 下一个节点
   └────┴────┘
   val=42   next
```

最后一个节点的 `next` 是 `None`，表示"我后面没人了"，这是链表的**终点标记**。


## 把节点串起来

手动串一条链：`1 → 2 → 3`。

```python
n1 = ListNode(1)
n2 = ListNode(2)
n3 = ListNode(3)
n1.next = n2      # 1 指向 2
n2.next = n3      # 2 指向 3
n3.next = None    # 3 是最后一个（其实 __init__ 默认就是 None）

head = n1         # head 指向第一个节点，称为"头指针"
```

更常用的写法是**头插法**，从空链开始一个一个往前挂：

```python
vals = [3, 2, 1]          # 想建成 1→2→3，倒着插
head = None
for v in vals:
    head = ListNode(v, head)
# 第一次：head = 3→None
# 第二次：head = 2→3→None
# 第三次：head = 1→2→3→None
```

头插法总是 O(1)，但它会**把顺序反过来**。需要保持原顺序就用尾插法（记一个 tail 指针）。


## 遍历与打印

遍历链表的唯一方式：**顺着 next 一路走，直到 None**。

```python
def print_list(head):
    cur = head
    while cur is not None:
        print(cur.val, end=" -> ")
        cur = cur.next
    print("None")

print_list(head)    # 1 -> 2 -> 3 -> None
```

注意循环条件是 `cur is not None`，不是 `cur.next`。这一点马上会在翻车现场看到。


## 翻车现场：用 cur.val 当条件，遇到 None 就炸

新手最爱写的错误：

```python
# WRONG
def print_list(head):
    cur = head
    while cur.val:            # 当 cur 是 None 时，None 没有 .val
        print(cur.val)
        cur = cur.next
```

```text
报错：AttributeError: 'NoneType' object has no attribute 'val'
```

当 `cur` 走到最后一个节点的 `next`（也就是 `None`）时，循环还进了一次，去取 `None.val`，直接崩溃。**判断链表走到头，永远判断"节点是不是 None"，不要判断"节点的值"**。

正确写法：`while cur is not None:`。


## 用列表构造/还原链表：测验里的标配

测验题里为了省事，约定**用普通列表表示链表**。所以需要两个工具函数：

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def build(lst):
    head = None
    for v in reversed(lst):
        head = ListNode(v, head)
    return head

def to_list(head):
    res = []
    cur = head
    while cur:
        res.append(cur.val)
        cur = cur.next
    return res

# 验证：转过去再转回来，应该和原来一样
print(to_list(build([1, 2, 3])))    # [1, 2, 3]
```

这两个函数会伴随你整本《链表》章节的每一道函数题。


## 小结

- - 节点 = `val` + `next` 两个字段
- - 最后一个节点的 `next` 是 `None`，这是链表终点
- - 遍历用 `while cur is not None`，不要碰 `cur.val` 当条件
- - 头插法 O(1) 但会反序；保持顺序用尾插法
- - 列表与链表互转的两个工具函数是链表题的通用脚手架
