# 实战：用 BFS 解无权图最短路径

> BFS 最强大的应用就是求无权图的最短路径。为什么 BFS 能找到最短路径？因为"先到达"就意味着"步数最少"。这一课把它彻底讲透。

## 问题

给你一个无向无权图和一个起点，求从起点到所有其他节点的最短距离。

```
graph = {
    0: [1, 2],
    1: [0, 3, 4],
    2: [0, 5],
    3: [1],
    4: [1],
    5: [2],
}

从 0 出发：
  dist[0] = 0
  dist[1] = 1  (0→1)
  dist[2] = 1  (0→2)
  dist[3] = 2  (0→1→3)
  dist[4] = 2  (0→1→4)
  dist[5] = 2  (0→2→5)
```

**为什么 BFS 能求最短路径？** 因为 BFS 按"层"扩展，第 k 层的所有节点距离起点恰好是 k 步。如果你在第 k 层第一次遇到某个节点，那这个节点到起点的最短距离就是 k——不可能有更短的路径，因为 BFS 已经检查了所有 k-1 步以内能到达的节点。

## 核心思路：距离 + 父节点

标准的 BFS 最短路径模板需要三个数据结构：

```python
from collections import deque

def bfs_shortest_path(graph, start):
    dist = {}          # 记录起点到每个节点的最短距离
    parent = {}        # 记录每个节点的前驱，用于回溯路径
    visited = set([start])

    dist[start] = 0
    parent[start] = None
    q = deque([start])

    while q:
        node = q.popleft()
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                dist[neighbor] = dist[node] + 1   # ★ 距离 = 父节点距离 + 1
                parent[neighbor] = node           # ★ 记录父节点
                q.append(neighbor)

    return dist, parent
```

**关键**：`dist[neighbor] = dist[node] + 1`。当一个节点第一次被访问时，它经过的步数就是最短步数。因为 BFS 保证先处理距离小的节点，所以第一次遇到必然是最近的一次。

## 从 parent 回溯完整路径

有了 parent 字典，可以还原从起点到任意节点的路径：

```python
def reconstruct_path(parent, start, target):
    path = []
    cur = target
    while cur is not None:       # 从目标一路回溯到起点
        path.append(cur)
        cur = parent[cur]
    path.reverse()               # 反转：起点→终点
    return path

# 继续上面的例子
dist, parent = bfs_shortest_path(graph, 0)
print(dist)    # {0: 0, 1: 1, 2: 1, 3: 2, 4: 2, 5: 2}
print(reconstruct_path(parent, 0, 3))  # [0, 1, 3]
print(reconstruct_path(parent, 0, 5))  # [0, 2, 5]
```

## 为什么 BFS 找到的是最短路径：严格证明

假设 BFS 在第 k 层第一次遇到节点 v。要证明 `dist[v] = k` 是最短距离：

1. **存在性**：BFS 在第 k 层找到 v，说明确实存在一条长度为 k 的路径。
2. **最优性**：假设存在一条更短的路径，长度为 k' < k。那么 BFS 在第 k' 层就会处理 v 的父节点，在第 k'+1 层就会遇到 v。这与"第 k 层第一次遇到 v"矛盾。

**这就是 BFS 求最短路径的正确性保证**。它不依赖于运气，而是严格的分层保证。

> 对比 DFS：DFS 也能找到路径，但找到的不一定是最短的。比如 0→2→5 是 2 步，但 DFS 可能走 0→1→3→...→5 绕一大圈。

## 翻车现场：距离数组初始化不完整

```python
# WRONG：只初始化起点，访问时假设 dist 里有值
dist = {start: 0}
# ...
for neighbor in graph[node]:
    if neighbor not in visited:
        dist[neighbor] = dist[node] + 1  # 如果 node 不在 dist 里会 KeyError
```

虽然 BFS 中 node 一定在 dist 里（因为 dist 和 visited 同步更新），但更常见的错误是：

```python
# WRONG2：用 dist 判断 visited，但没初始化所有节点
dist = [-1] * len(graph)   # 用 -1 表示未访问
dist[start] = 0
q = deque([start])
while q:
    node = q.popleft()
    for neighbor in graph[node]:
        if dist[neighbor] == -1:    # 用 -1 判断未访问
            dist[neighbor] = dist[node] + 1
            q.append(neighbor)
```

**这两种写法都对**，关键是保持**一致性**：要么用 `visited` 集合 + `dist` 字典，要么用 `dist` 数组的哨兵值（如 -1）统一判断。混用容易出 bug。

## 翻车现场：忘记处理不可达节点

```python
# WRONG：假设所有节点都可达
dist, parent = bfs_shortest_path(graph, 0)
print(dist[5])   # 如果 5 不可达，KeyError！

# RIGHT：检查是否存在
if target in dist:
    print(f"距离: {dist[target]}")
else:
    print("不可达")

# 或者用 dist 数组 + 哨兵值：
dist = [-1] * n
# ...
if dist[target] == -1:
    print("不可达")
else:
    print(f"距离: {dist[target]}")
```

**不可达的情况必须处理**。图可能不是连通的，BFS 只能遍历从起点可达的那些节点。

## 翻车现场：把无向图当成了有向图

```python
# WRONG：建图时只加单向边
graph = {}
graph[0] = [1, 2]      # 0→1, 0→2
graph[1] = [3, 4]      # 但忘了 1→0！
# 这样 BFS 从 0 出发能到 1，但从 1 出发到不了 0

# RIGHT：无向图加双向边
graph = {}
graph.setdefault(0, []).append(1)
graph.setdefault(1, []).append(0)   # 双向！
```

**无向图的邻接表必须加两条边**。如果题目说"无向"但你只加了单向，BFS 会漏掉很多可达节点。

## 完整实战：迷宫最短路径

把 BFS 用到二维网格上（比如迷宫问题）：

```python
from collections import deque

def maze_shortest_path(grid, start, target):
    """grid 是二维列表，0=可走，1=障碍。求 start 到 target 的最短步数。"""
    n, m = len(grid), len(grid[0])
    visited = [[False] * m for _ in range(n)]
    dist = [[-1] * m for _ in range(n)]

    sx, sy = start
    tx, ty = target

    q = deque([(sx, sy)])
    visited[sx][sy] = True
    dist[sx][sy] = 0

    # 四个方向
    directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]

    while q:
        x, y = q.popleft()
        if (x, y) == (tx, ty):
            return dist[x][y]          # 第一次到达就是最短

        for dx, dy in directions:
            nx, ny = x + dx, y + dy
            if (0 <= nx < n and 0 <= ny < m
                and not visited[nx][ny]
                and grid[nx][ny] == 0):
                visited[nx][ny] = True
                dist[nx][ny] = dist[x][y] + 1
                q.append((nx, ny))

    return -1   # 不可达

# 测试
grid = [
    [0, 0, 0, 0],
    [1, 1, 0, 1],
    [0, 0, 0, 0],
    [0, 1, 1, 0],
]
print(maze_shortest_path(grid, (0, 0), (3, 3)))  # 6
```

**二维 BFS 和图 BFS 的区别**：只是邻居的计算方式变了（从"查邻接表"变成"算四方向坐标"），核心骨架完全一样。

## 复杂度

| 指标 | 值 |
|---|---|
| 时间 | **O(V + E)**，每个节点和边各访问一次 |
| 空间 | **O(V)**，visited/dist/parent 各 O(V)，队列 O(V) |

对于网格迷宫：V = n×m，E ≈ 4×V，所以时间是 **O(nm)**。

## 小结

- BFS 天然求无权图最短路径，因为"按层扩展"= "按步数递增"
- 模板三件套：visited（去重）、dist（记录距离）、parent（回溯路径）
- `dist[neighbor] = dist[node] + 1` 是核心递推式
- 第一次访问某节点时的距离就是最短距离（严格证明见上）
- 必须处理不可达情况（返回 -1 或用哨兵值）
- 无向图建邻接表要加双向边
- 二维网格 BFS：邻居改为四方向坐标计算，骨架不变
