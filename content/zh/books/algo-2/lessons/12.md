# 括号匹配：栈最经典的应用

> 给你一串括号，判断能不能一一闭合。这道题几乎是所有面试里栈的"入场券"，也是栈"就近匹配"思想的教科书级示范。

## 为什么必须用栈

括号的本质是**就近匹配**：一个右括号 `)` 要和它**左边最近的**未匹配左括号配对。而"最近"这件事，正是栈最擅长的事——栈顶永远是最后进来的那个。

> 遇到左括号 → 压栈。遇到右括号 → 弹出栈顶，看能不能配对。

如果用别的办法呢？比如计数：`(` 加一、`)` 减一，最后为 0 就行。这在**只有一种括号**时确实够用，但一旦混了 `()` `[]` `{}`，计数就彻底失效了：

```
([)]    ← 计数能过（2 个左、2 个右），但显然不合法
```

所以**栈是唯一干净的解法**。

## 核心算法（三句话）

```python
def is_valid(s: str) -> bool:
    pair = {')': '(', ']': '[', '}': '{'}   # 右→左的映射表
    stack = []
    for ch in s:
        if ch in pair:            # 是右括号
            if not stack:         # ★ 栈空，说明多了一个右括号
                return False
            if stack.pop() != pair[ch]:
                return False      # 类型对不上
        else:                     # 是左括号
            stack.append(ch)
    return len(stack) == 0        # 栈必须清空，否则有落单左括号
```

**逐字符走一遍 `({[]})`**：

```
(  → 压栈     栈: ['(']
{  → 压栈     栈: ['(', '{']
[  → 压栈     栈: ['(', '{', '[']
]  → 弹出 [   配对 ok，栈: ['(', '{']
}  → 弹出 {   配对 ok，栈: ['(']
)  → 弹出 (   配对 ok，栈: []
结束，栈空 → True
```

再看一次不合法的 `([)]`：

```
(  → 压栈   ['(']
[  → 压栈   ['(', '[']
)  → 弹出 [   但 pair[')']='('，[( ≠ (，失败
```

类型检查当场把它拦下来。

## 三个必须处理的边界

### 1. 栈空时遇到右括号 → 立刻 False

```python
if ch in pair:
    if not stack:          # 没有左括号可以配
        return False
    ...
```

漏掉这行会怎样？`stack.pop()` 直接 `IndexError`。

### 2. 结束后栈必须为空

```python
return len(stack) == 0
```

漏掉会怎样？`((` 这种"左括号太多"的情况会被判 True。

### 3. 只保留左括号进栈

右括号不入栈——它只负责弹出和比对。写代码时最容易犯的错误是把所有字符都压栈，包括右括号。

## 翻车现场：忘了判栈空，空栈上 pop

```python
# WRONG
def is_valid_bad(s):
    stack = []
    pair = {')':'(', ']':'[', '}':'{'}
    for ch in s:
        if ch in pair:
            if stack.pop() != pair[ch]:   # 没判断 stack 是否为空
                return False
        else:
            stack.append(ch)
    return len(stack) == 0

is_valid_bad(")(")
```

报错：

```
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
  File "<stdin>", line 6, in is_valid_bad
IndexError: pop from empty stack
```

输入 `")("` 一开头就是右括号，栈是空的。必须先 `if not stack: return False`。

## 翻车现场：循环结束没检查栈是否为空

```python
# WRONG
def is_valid_bad2(s):
    stack = []
    pair = {')':'(', ']':'[', '}':'{'}
    for ch in s:
        if ch in pair:
            if not stack: return False
            stack.pop()
        else:
            stack.append(ch)
    return True          # 错！没判断栈有没有剩东西

print(is_valid_bad2("(("))    # True（错误！）
print(is_valid_bad2("(()"))   # True（错误！）
```

左括号多出来的情况全部漏报。**两个条件缺一不可**：中途栈空报错 + 结束栈空才算成功。

## 翻车现场：把右括号也压栈了

```python
# WRONG
stack = []
for ch in s:
    stack.append(ch)         # 所有字符都进栈
# 然后想"从头到尾比对"——根本无从下手
```

栈里塞满了右括号，你既没法用它做就近匹配，也丢了"左括号等右括号来闭合"这个语义。正确做法是 `else: stack.append(ch)`——只有左括号进栈。

## 变体一：返回最长有效括号子串的长度

LeetCode 32。思路是用**栈存下标**，而不是存字符：

```python
def longest_valid(s):
    stack = [-1]          # 基准下标，用来算长度
    ans = 0
    for i, ch in enumerate(s):
        if ch == '(':
            stack.append(i)
        else:
            stack.pop()
            if not stack:          # 弹空了，说明这个 ) 没得配
                stack.append(i)    # 以它为新基准
            else:
                ans = max(ans, i - stack[-1])   # 当前长度
    return ans
```

为什么存下标？因为长度 = `当前位置 - 上一个无法匹配的位置`，而这个"上一个无法匹配的位置"正好在栈顶。

## 变体二：生成所有合法括号组合

LeetCode 22。这题其实**不需要栈**，用回溯+计数就行：

```python
def generate(n):
    res = []
    def backtrack(path, left, right):
        if len(path) == 2 * n:
            res.append(path); return
        if left < n:                    # 左括号没用完
            backtrack(path + '(', left + 1, right)
        if right < left:                # 右括号少于左括号才能加
            backtrack(path + ')', left, right + 1)
    backtrack('', 0, 0)
    return res
```

`right < left` 这一句保证了任何时候都不会出现"右括号比左括号多"的情况——本质就是用两个计数器代替了栈。

## 复杂度

| 指标 | 值 |
|---|---|
| 时间 | O(n)，每个字符进出栈各一次 |
| 空间 | O(n)，最坏情况全是左括号 |

## 小结

- 括号匹配是栈的"就近匹配"思想的经典应用
- 左括号压栈，右括号弹出栈顶比对；栈空或类型不合都直接 False
- **三处边界缺一不可**：栈空判断、类型比对、结束栈空检查
- 只有左括号进栈，右括号只负责弹出和比对
- 存下标而不是字符，可以解"最长有效括号子串"
- 只生成不校验的场景（如合法括号组合），用两个计数器回溯即可，无需栈
