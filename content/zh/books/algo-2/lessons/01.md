# 为什么要有链表：数组的短板与链表的优势

> 前两章我们把数组玩出了花：双指针、前缀和、二分、滑动窗口。但数组有一个天生的短板——**插入和删除是 O(n)**。这一章我们认识它的解药：链表。

## 先看数组的痛点

**题目**：有一个排好序的名单 `names`，现在要在中间插入一个新名字，或者删掉一个名字。

```python
names = ["张三", "李四", "王五", "赵六"]
# 在"李四"后面插入"钱七"
```

用数组怎么做？先找到位置，再把后面的元素统统往后挪一格。

```python
names = ["张三", "李四", "王五", "赵六"]
names.append(None)          # 先扩一个位置
for i in range(4, 1, -1):   # 从后往前搬
    names[i] = names[i - 1]
names[2] = "钱七"
print(names)
# ['张三', '李四', '钱七', '王五', '赵六']
```

**插入一次，要搬动后面所有元素，O(n)。** 如果名单有 10 万人，插一个人就得搬 10 万次。

删除同理：删掉中间一个，后面的都得往前补一格，还是 O(n)。

## 链表怎么解决

链表的思路特别朴素：**不连续存放，每个元素只记"我的下一个是谁"**。

```
数组:   [张三][李四][王五][赵六]   ← 紧挨着，中间插不进去
链表:   张三 → 李四 → 王五 → 赵六   ← 每个只记下一个，想插就改一个箭头
```

插入"钱七"：只要把"李四"的箭头指向"钱七"，让"钱七"指向"王五"，两步搞定，**O(1)**。

```
李四 → 钱七 → 王五
```

不用搬动任何数据。这就是链表存在的全部理由。

## 数组连续内存：一个链表没有的优势

链表解决了插入删除，但**牺牲了随机访问**。

```python
names = ["张三", "李四", "王五", "赵六"]
print(names[2])    # 王五 —— O(1)，直接算偏移量
```

数组的元素是**连续内存**，所以 `names[2]` 就是"起始地址 + 2 × 每个元素大小"，一步定位。

链表呢？想找第 3 个，只能从第一个开始，顺着箭头走 3 步：**O(n)**。

| 操作 | 数组 | 链表 |
|---|---|---|
| 按下标访问 | O(1) | O(n) |
| 头部插入 | O(n) | O(1) |
| 中间插入 | O(n) | O(1)（找到位置后） |
| 中间删除 | O(n) | O(1)（找到位置后） |
| 内存利用 | 紧凑，有碎片风险 | 灵活，每个节点多两个指针 |

## 翻车现场：`list.insert` 是 O(n)，别被骗了

很多人以为 Python 的 `list` 插入很快，于是写出这样的代码：

```python
# WRONG
data = list(range(100000))
for _ in range(10000):
    data.insert(0, 0)   # 每次都在头部插入
```

```text
运行结果：程序卡住，因为每次 insert(0, x) 都要把 10 万个元素往后搬，
总共搬了 10000 × 100000 = 10 亿次。这在竞赛里必超时。
```

`list.insert` 的复杂度就是 O(n)。**当你需要频繁在两端插入删除时，`list` 不是正确的选择**——应该用 `collections.deque`（双端队列），或自己写链表。

## 什么时候用数组，什么时候用链表

经验法则：

- **需要按下标快速访问**（二分、前缀和、动态规划）→ 数组
- **需要频繁插入删除，尤其是头部**（队列、LRU 缓存）→ 链表
- **元素数量不确定，又不想预留空间** → 链表

> 💡 链表和数组不是谁替代谁，而是**各管一头**：数组管"查得快"，链表管"改得快"。

## 小结

- 数组插入/删除要搬动元素，**O(n)**；链表只要改箭头，**O(1)**
- 数组胜在**连续内存、随机访问 O(1)**；链表没有这个优势
- Python 的 `list.insert(0, x)` 是 O(n)，大量头插会超时
- 链表是后面所有数据结构（栈、队列、哈希表、LRU）的地基

```quiz
type: choice
exam: true
q: 为什么数组在头部插入元素是 O(n)，而链表是 O(1)？
options:
- 数组元素连续存放，插入要搬动后续所有元素；链表靠指针连接，改两个指针即可
- 数组比链表占内存更多
- 链表的节点比数组元素小
- 数组只能存数字，不能存字符串
answer: 0
explain: 数组要求元素在内存中连续，在头部插入时，头部之后的所有元素都必须整体后移一格，共 O(n) 次搬动。链表节点在内存里随意分布，每个节点只记录下一个节点的位置，插入时只需修改前驱和自身的指针（共 2 处），与链表长度无关，故 O(1)。其余选项与插入复杂度无因果关系。
```
