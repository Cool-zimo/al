# 插入与删除：头插、中间插、删除节点（为什么需要前驱）

> 链表最拿手的活儿就是插入和删除。这一课把头插、中间插、删除逐个拆开讲，并说清为什么删除非得拿到「前驱」不可。


## 头插：链表最快的操作

头插就是在链表最前面加一个节点，O(1) 完成。

```python
def insert_head(head, val):
    return ListNode(val, head)   # 新节点的 next 指向原来的头

head = build([2, 3])
head = insert_head(head, 1)
print(to_list(head))    # [1, 2, 3]
```

原理：新节点指向旧头，然后让头指针指向新节点。**两步，不管链表多长都是两步。**


## 中间插入：必须找到前驱

要在 `2` 和 `3` 之间插入 `99`，得先拿到节点 `2`（前驱），然后：

```
前驱.next = 新节点
新节点.next = 前驱.next 的原来指向
```

代码：

```python
def insert_after(prev_node, val):
    new_node = ListNode(val, prev_node.next)
    prev_node.next = new_node

head = build([1, 2, 3])
insert_after(head.next, 99)   # head.next 是节点 2
print(to_list(head))          # [1, 2, 99, 3]
```

**关键点**：先让新节点的 `next` 指向 `2` 原来的下一个，再让 `2.next` 指向新节点。**顺序不能反**——如果先改 `prev_node.next`，原来的下一个节点就丢了。


## 翻车现场：先改前驱的 next，原来的后继直接蒸发

```python
# WRONG
def insert_after(prev_node, val):
    prev_node.next = ListNode(val)          # 新节点挂上去了
    prev_node.next.next = prev_node.next    # 想接原来的后继？早就丢了
```

```text
结果：[1, 2, 99]，节点 3 被永久丢失，内存泄漏。
```

先动了 `prev_node.next`，原来指向的 `3` 就再也没人引用了。正确是先 `ListNode(val, prev_node.next)` 把旧后继存进新节点的 `next`，再覆盖 `prev_node.next`。


## 删除节点：为什么必须拿到前驱

链表删除一个节点，其实是"让它的前驱跳过它"。

```python
def delete_node(head, target_val):
    if head is None:
        return head
    if head.val == target_val:      # 要删的是头节点，得单独处理
        return head.next
    prev = head
    cur = head.next
    while cur:
        if cur.val == target_val:
            prev.next = cur.next    # 前驱跳过 cur
            return head
        prev = cur
        cur = cur.next
    return head

head = build([1, 2, 3, 4])
head = delete_node(head, 3)
print(to_list(head))    # [1, 2, 4]
```

**为什么一定要前驱？** 因为链表只能从前一个节点出发。`prev.next = cur.next` 这一句让前驱直接指向后继，cur 就"掉出"了链表。没有前驱指针，你根本改不动前面的箭头。


## 翻车现场：直接把 cur 指向 cur.next，节点没被删

这是最经典的误解：

```python
# WRONG
def delete_node(head, target):
    cur = head
    while cur:
        if cur.val == target:
            cur = cur.next    # 以为这就删了
            return head
        cur = cur.next
```

```text
结果：链表纹丝不动。改的是局部变量 cur 的指向，链表的箭头一个都没动。
```

`cur` 只是一个变量，你让 `cur` 指向下一个，只是让这个变量变了，节点 `2→3` 的箭头还是 `2→3`。**删除一定要改前驱的 `next`。**


## 边界：删除头节点要单独返回

注意上面的 `delete_node` 里对头的特殊处理：

```python
if head.val == target_val:
    return head.next
```

因为头节点没有前驱。这也是下一课"虚拟头节点 dummy"要解决的问题。


## 小结

- - 头插 O(1)：`ListNode(val, head)` 一步搞定
- - 中间插入要先找到前驱，且必须先接旧后继再改前驱
- - 删除必须改前驱的 `next`，只改局部变量 `cur` 毫无作用
- - 头节点无前驱，删除头要单独处理（这是 dummy 的动机）
