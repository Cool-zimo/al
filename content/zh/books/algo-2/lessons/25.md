# 实战：字母异位词分组

> 字母异位词分组是哈希表 + 字符串处理的经典组合题。核心思路：找到一种"把异位词映射到同一个 key"的方法。

## 问题

**字母异位词（Anagram）**：两个字符串包含的字符种类和数量完全相同，只是排列顺序不同。例如 "eat"、"tea"、"ate" 互为异位词。

**题目要求**：给定一个字符串数组 `strs`，把互为字母异位词的字符串分组，返回分组后的列表。

```
输入：["eat", "tea", "tan", "ate", "nat", "bat"]
输出：[["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
```

**顺序不重要**，只要分组正确即可。

## 思路一：排序作为 key

互为异位词的两个字符串，**排序后完全相同**。

```python
"eat" → sorted → "aet"
"tea" → sorted → "aet"
"ate" → sorted → "aet"
"tan" → sorted → "ant"
"nat" → sorted → "ant"
"bat" → sorted → "abt"
```

**所以思路是**：以"排序后的字符串"作为 key，把所有排序后相同的字符串归为一组。

```python
from collections import defaultdict

def group_anagrams(strs):
    groups = defaultdict(list)
    for s in strs:
        key = "".join(sorted(s))   # 排序后的字符串作为 key
        groups[key].append(s)
    return list(groups.values())

print(group_anagrams(["eat", "tea", "tan", "ate", "nat", "bat"]))
# [['eat', 'tea', 'ate'], ['tan', 'nat'], ['bat']]
```

**复杂度分析**：
- 每个字符串排序：O(k log k)，k 是字符串长度
- 总共 n 个字符串：O(n × k log k)
- 空间：O(n × k) 存储结果

## 思路二：字符计数作为 key

排序需要 O(k log k)，能不能更快？

**换个角度**：异位词的本质是"每个字符出现次数相同"。可以用**字符频次元组**作为 key。

```python
"eat" → (1, 0, 0, ..., 1, 0, ..., 1, 0, ...)  # a:1, b:0, ..., e:1, ...
"tea" → (1, 0, 0, ..., 1, 0, ..., 1, 0, ...)  # 一样的！
```

```python
def group_anagrams_count(strs):
    groups = defaultdict(list)
    for s in strs:
        count = [0] * 26                      # 26 个小写字母
        for c in s:
            count[ord(c) - ord('a')] += 1
        key = tuple(count)                    # list 不可哈希，转 tuple
        groups[key].append(s)
    return list(groups.values())

print(group_anagrams_count(["eat", "tea", "tan", "ate", "nat", "bat"]))
# [['eat', 'tea', 'ate'], ['tan', 'nat'], ['bat']]
```

**复杂度分析**：
- 每个字符串统计频次：O(k)
- 总共 n 个字符串：O(n × k)
- 比排序法快（k log k vs k），但 key 更长（26 个 int vs k 个字符）

**两种方法的取舍**：
- k 很小（短单词）→ 排序法更简单
- k 很大（长字符串）→ 计数法更快

## 翻车现场：用 list 当 dict 的 key

```python
# WRONG：直接用 count list 当 key
groups = {}
for s in strs:
    count = [0] * 26
    for c in s:
        count[ord(c) - ord('a')] += 1
    groups[count].append(s)   # TypeError: unhashable type: 'list'
```

报错：

```
TypeError: unhashable type: 'list'
```

**解决**：把 list 转成 tuple。

```python
# RIGHT：转成 tuple
key = tuple(count)   # tuple 不可变，可以当 key
groups[key].append(s)
```

**或者用计数字符串作为 key**（更省空间）：

```python
def group_anagrams_strkey(strs):
    groups = defaultdict(list)
    for s in strs:
        count = [0] * 26
        for c in s:
            count[ord(c) - ord('a')] += 1
        # 把计数转成字符串："1#0#0#...#1#..."
        key = "#".join(str(x) for x in count)
        groups[key].append(s)
    return list(groups.values())
```

## 翻车现场：空字符串和单字符的处理

```python
# 边界情况
strs = ["", ""]
print(group_anagrams(strs))
# [['', '']]  ✅ 两个空字符串互为异位词（排序后都是 ""）

strs = ["a"]
print(group_anagrams(strs))
# [['a']]  ✅ 单个字符

strs = []
print(group_anagrams(strs))
# []  ✅ 空数组
```

**注意**：空字符串排序后还是空字符串 `""`，`"".join(sorted(""))` 也是 `""`，key 是有效的。

## 翻车现场：Unicode 字符超出 a-z 范围

```python
# WRONG：假设所有字符都是小写字母
def group_anagrams_ascii(strs):
    groups = defaultdict(list)
    for s in strs:
        count = [0] * 26
        for c in s:
            count[ord(c) - ord('a')] += 1  # 如果 c 不是 a-z，下标越界！
        groups[tuple(count)].append(s)
    return list(groups.values())

print(group_anagrams_ascii(["café", "faéc"]))
# IndexError: list assignment index out of range
```

**解决**：如果字符范围不确定，用排序法（更通用）或者用 dict 计数：

```python
def group_anagrams_unicode(strs):
    groups = defaultdict(list)
    for s in strs:
        # 用 tuple + sorted，适用于任何可比较的字符
        key = tuple(sorted(s))
        groups[key].append(s)
    return list(groups.values())

print(group_anagrams_unicode(["café", "faéc"]))
# [['café', 'faéc']]  ✅
```

**或者用 Counter 作为 key**（但 Counter 本身不可哈希，需要转 tuple 排序）：

```python
from collections import Counter

def group_anagrams_counter(strs):
    groups = defaultdict(list)
    for s in strs:
        # Counter 的 items 排序后转 tuple
        key = tuple(sorted(Counter(s).items()))
        groups[key].append(s)
    return list(groups.values())
```

## 翻车现场：返回顺序不一致导致测试失败

```python
# 题目说"顺序不重要"，但有些 OJ 要求特定的输出顺序
result = group_anagrams(["eat", "tea", "tan", "ate", "nat", "bat"])
print(result)
# 可能是 [['eat', 'tea', 'ate'], ['tan', 'nat'], ['bat']]
# 也可能是 [['bat'], ['tan', 'nat'], ['eat', 'tea', 'ate']]

# 如果你的测试代码用了 == 严格比较，顺序不同会失败
expected = [["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
print(result == expected)  # 可能是 False！
```

**正确做法：排序后比较**

```python
def compare_anagram_groups(result, expected):
    # 对每个子列表排序，对总列表排序
    result_sorted = sorted([sorted(g) for g in result])
    expected_sorted = sorted([sorted(g) for g in expected])
    return result_sorted == expected_sorted

result = group_anagrams(["eat", "tea", "tan", "ate", "nat", "bat"])
expected = [["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
print(compare_anagram_groups(result, expected))  # True
```

## 翻车现场：忘记转成 list 返回

```python
# WRONG：直接返回 defaultdict 的 values
def group_anagrams_wrong(strs):
    groups = defaultdict(list)
    for s in strs:
        key = "".join(sorted(s))
        groups[key].append(s)
    return groups.values()  # 返回的是 dict_values 对象！

result = group_anagrams_wrong(["a", "b"])
print(result)  # dict_values([['a'], ['b']])
print(list(result) == [['a'], ['b']])  # True，但类型不是 list of lists
```

**有些 OJ 严格要求返回 `List[List[str]]`**，直接返回 `dict_values` 会导致类型检查失败。

```python
# RIGHT：显式转成 list
return list(groups.values())
```

## 完整实现（排序法）

```python
from collections import defaultdict
from typing import List

def group_anagrams(strs: List[str]) -> List[List[str]]:
    """
    字母异位词分组
    思路：以排序后的字符串为 key，把异位词归为一组
    时间复杂度：O(n * k log k)，n 是字符串个数，k 是最长字符串长度
    空间复杂度：O(n * k)
    """
    groups = defaultdict(list)
    
    for s in strs:
        # key：排序后的字符元组
        key = tuple(sorted(s))
        groups[key].append(s)
    
    return list(groups.values())

# 测试
test = ["eat", "tea", "tan", "ate", "nat", "bat"]
result = group_anagrams(test)
print(result)
# [['eat', 'tea', 'ate'], ['tan', 'nat'], ['bat']]（顺序可能不同）
```

## 扩展：如果要求按字典序排列每组内的字符串？

```python
def group_anagrams_sorted_output(strs):
    groups = defaultdict(list)
    for s in strs:
        key = tuple(sorted(s))
        groups[key].append(s)
    
    # 每组内部排序
    result = [sorted(group) for group in groups.values()]
    # 总结果排序（按第一个元素）
    result.sort(key=lambda x: x[0])
    return result

print(group_anagrams_sorted_output(["eat", "tea", "tan", "ate", "nat", "bat"]))
# [['ate', 'eat', 'tea'], ['bat'], ['nat', 'tan']]
```

## 小结

- 字母异位词分组的核心是**找到一个"把异位词映射到同一个 key"的方法**
- 方法一：排序法，`key = tuple(sorted(s))`，O(n × k log k)
- 方法二：计数法，`key = tuple(count)`，O(n × k)，更快但有字符范围限制
- 计数法用 list 当 key 会 TypeError，必须转 tuple 或用计数字符串
- 排序法更通用，适用于 Unicode 字符
- 返回结果时注意转成 `list`，比较时注意排序
- 这类"分组"问题的通用套路：找一个不变量作为 key，用 `defaultdict(list)` 聚合
