# 第 3 章章测 · 栈

> 五道题的选择题 + 两道动手题 + 一个小项目，覆盖栈的基本操作、括号匹配、单调栈、递归调用栈与表达式求值。建议限时 40 分钟。

## 第一部分 · 选择题

```quiz
type: choice
exam: true
q: 用 Python 的 list 实现一个栈，下面哪组操作的时间复杂度都是 O(1)？
options:
- push 用 list.append(x)，pop 用 list.pop(0)
- push 用 list.insert(0, x)，pop 用 list.pop()
- push 用 list.append(x)，pop 用 list.pop()
- push 用 list.append(x)，peek 用 list.index(x)
answer: 2
explain: append 在尾部写入、pop() 无参数弹出尾部，两者都不搬动其他元素，O(1)。pop(0) 要搬动 n-1 个元素，O(n)；insert(0) 同理 O(n)；index 是线性扫描 O(n)。
```

```quiz
type: choice
exam: true
q: 判断括号串 `s = "()[]{}"` 是否合法时，下面哪一步是多余的、不会导致错误答案？
options:
- 遇到右括号时检查栈是否为空
- 弹出栈顶后检查类型是否匹配
- 遍历结束后检查栈是否为空
- 把右括号也一并压入栈
answer: 3
explain: 前三个都是必要判断：栈空防 IndexError、类型匹配防 ([)] 误判、遍历结束栈空防左括号多。而"把右括号也压栈"是错误的做法——右括号只负责弹出和比对，压进去会破坏匹配语义。
```

```quiz
type: choice
exam: true
q: 单调栈求"下一个更大元素"，栈里通常存的是下标。弹出栈顶的那一刻意味着什么？
options:
- 栈顶元素比当前元素小，当前元素就是它右边第一个比它大的数，可以回填答案
- 栈顶元素比当前元素大，两者应该交换位置
- 当前元素应该被丢弃，不参与后续计算
- 栈已满，必须腾出一个位置给新元素
answer: 0
explain: 这正是单调栈的精髓：nums[栈顶] < x 成立时才弹出，此时 x 正是 nums[栈顶] 右边第一个比它大的数，答案在这一刻确定。它不是"腾位置"，而是"结算"。
```

```quiz
type: choice
exam: true
q: 下面关于递归和调用栈的说法，哪一句是正确的？
options:
- Python 没有调用栈，递归靠解释器自动优化
- 递归函数没有终止条件时，会触发 RecursionError，因为帧数超过了 Python 的递归深度上限
- 递归一定比循环慢，但可以省掉所有内存开销
- 调用栈满了之后 Python 会自动扩容，永远不会报错
answer: 1
explain: 每次函数调用压一帧，没有终止条件则帧数持续增长，触到默认 1000 的上限后抛 RecursionError 以保护内存。递归有 O(n) 的栈空间开销，Python 也不做尾递归优化。
```

```quiz
type: choice
exam: true
q: 用两个栈（操作数栈 + 运算符栈）计算 `3 + 5 * 2` 时，读到 `*` 后为什么没有立刻把栈顶的 `+` 算掉？
options:
- 因为加法和乘法不能一起算
- 因为 `*` 的优先级比栈顶的 `+` 高，要"先算乘"，所以 `+` 先留着
- 因为运算符栈最多只能存一个元素
- 因为数字栈是空的
answer: 1
explain: 新运算符进栈前，只有栈顶优先级 ≥ 新运算符时才先算。这里 * 优先级 2 高于 + 的 1，所以 + 留在栈里，乘号先进栈，等后续数字压入后再算乘法。
```

  [2,4] -> 4
  [4,2,0,3,2,5] -> 6
