# 循环队列：用固定数组实现队列

> 面试官最爱问的题：给你一块固定大小的数组，怎么实现一个队列？答案是循环队列——用两个指针在数组上"绕圈"。

## 问题

`deque` 很好用，但在一些底层场景（嵌入式、高频交易、面试）中，你需要**用固定大小的数组**实现一个队列。这就要求你把有限的空间"循环"利用起来。

核心挑战：**怎么区分"队列空"和"队列满"？**

如果 front 和 rear 指向同一个位置，到底表示空还是满？

## 核心思路：front 和 rear 两个指针

循环队列用一块固定大小的数组 `data`，配合两个指针：

- **front**：指向下一个要出队的元素（队首）
- **rear**：指向下一个要入队的空位（队尾的下一个位置）

```
假设容量为 5（实际可存 4 个元素，留一个空位）：

初始状态（空）：
data: [_, _, _, _, _]
       ↑            ↑
      front        rear

入队 10, 20, 30：
data: [10, 20, 30, _, _]
        ↑           ↑
       front       rear

出队一个（10 走）：
data: [_, 20, 30, _, _]
             ↑      ↑
           front   rear

入队 40, 50（rear 绕回到开头）：
data: [50, 20, 30, 40, _]
       ↑        ↑
      rear     front
```

## 为什么必须留一个空位

这是循环队列最精妙的设计。如果不留空位：

```
如果 front == rear 表示空：
  入队到满时，rear 也追到 front 位置 → front == rear 表示满
  → 空和满无法区分！
```

**解决方案：永远留一个空位**。这样：

- **空**：`front == rear`
- **满**：`(rear + 1) % capacity == front`

空位牺牲了一个存储单元，换来了 O(1) 的判空判满。

```python
class CircularQueue:
    def __init__(self, k):
        self.capacity = k + 1        # 多开一个空位
        self.data = [0] * self.capacity
        self.front = 0
        self.rear = 0

    def enqueue(self, x):
        if self.is_full():
            return False
        self.data[self.rear] = x
        self.rear = (self.rear + 1) % self.capacity
        return True

    def dequeue(self):
        if self.is_empty():
            return False
        self.front = (self.front + 1) % self.capacity
        return True

    def is_empty(self):
        return self.front == self.rear

    def is_full(self):
        return (self.rear + 1) % self.capacity == self.front

    def get_front(self):
        if self.is_empty():
            return -1
        return self.data[self.front]

# 测试
cq = CircularQueue(3)   # 实际数组大小 4，最多存 3 个
cq.enqueue(1)           # [1, _, _, _], front=0, rear=1
cq.enqueue(2)           # [1, 2, _, _], front=0, rear=2
cq.enqueue(3)           # [1, 2, 3, _], front=0, rear=3
print(cq.is_full())     # True ← 第 4 个空位不让用
cq.dequeue()            # [_, 2, 3, _], front=1, rear=3
cq.enqueue(4)           # [4, 2, 3, _], front=3, rear=0 ← 绕回来了！
```

## 取模运算实现"绕圈"

关键就一行：`(rear + 1) % capacity`。当 `rear` 到达数组末尾时，加 1 后取模回到 0。

```
capacity = 5
rear = 0 → (0+1)%5 = 1
rear = 1 → (1+1)%5 = 2
rear = 2 → (2+1)%5 = 3
rear = 3 → (3+1)%5 = 4
rear = 4 → (4+1)%5 = 0  ← 绕回开头！
```

这比用 if 判断"是否越界再重置"更优雅、更不容易出错。

## 翻车现场：判空判满混淆

```python
# WRONG：用同一个条件判断空和满
def is_empty(self):
    return self.front == self.rear

def is_full(self):
    return self.front == self.rear   # 和 is_empty 一模一样！
# 结果：永远分不清空和满，入队出队逻辑全乱
```

**正确做法**：满的条件是 `(rear + 1) % capacity == front`，比空多了一个 `+1`。

```
区分速记：
  空：front 追上了 rear     → front == rear
  满：rear 的下一个是 front → (rear+1) % cap == front
```

## 翻车现场：取模写成 if 判断

```python
# WRONG：用 if 手动回绕
self.rear += 1
if self.rear == self.capacity:
    self.rear = 0   # 看起来没问题...

# 但如果有其他操作（比如计算长度），也会需要取模：
# len = (self.rear - self.front) 可能为负！
```

**统一用取模**更安全：

```python
# RIGHT
self.rear = (self.rear + 1) % self.capacity

# 计算当前元素个数也要用取模：
def size(self):
    return (self.rear - self.front) % self.capacity
```

```
例子：front=3, rear=1, capacity=5
  rear - front = 1 - 3 = -2
  (rear - front) % 5 = 3  ← 正确，队列里确实有 3 个元素
```

## 翻车现场：忘记 capacity 比 k 大 1

```python
# WRONG：用户说容量 3，你就开 3
self.data = [0] * k       # 开 3 个
# 留一个空位后只能存 2 个，不符合预期

# RIGHT：多开一个
self.capacity = k + 1     # 开 4 个，实际存 3 个
self.data = [0] * self.capacity
```

**构造函数里的 `k` 是用户期望的容量，你要开 `k+1` 的数组**。这是循环队列最容易犯的"差一错误"。

## 循环队列 vs deque

| 特性 | 循环队列 | collections.deque |
|---|---|---|
| 底层 | 固定数组 | 分块数组/链表 |
| 容量 | 固定 | 动态增长 |
| 空间效率 | 高（无额外指针开销） | 略低 |
| 实现难度 | 中（要处理指针和取模） | 无（直接用） |
| 适用场景 | 嵌入式、面试、固定缓冲区 | 日常开发 |

**面试时**：循环队列考的是你对指针和取模的理解。
**实际写代码时**：直接用 `deque`，不要自己造轮子。

## 复杂度

| 操作 | 时间 | 空间 |
|---|---|---|
| enqueue | O(1) | O(k) |
| dequeue | O(1) | O(k) |
| is_empty / is_full | O(1) | — |
| 随机访问 | O(1) | — |

所有操作都是 O(1)，空间是 O(k) 固定不变。

## 小结

- 循环队列用固定数组 + front/rear 两个指针实现 FIFO
- **必须留一个空位**才能区分"空"（`front==rear`）和"满"（`(rear+1)%cap==front`）
- 取模 `% capacity` 实现指针的循环回绕
- 构造函数里 `capacity = k + 1`，用户要容量 k，你开 k+1
- 计算元素个数：`(rear - front) % capacity`
- 实际开发中直接用 `deque`；面试和底层场景需要手写循环队列
