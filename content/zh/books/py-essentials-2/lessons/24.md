# 综合实战一：通讯录

> 这一课是《巩固篇》的第一个真正大项目。前面四章（字符串、容器、函数与异常、文件与模块）学的东西，在这里要合起来用。
> 目标是做出一个**能增删改查、能存盘、能容错**的命令行通讯录。代码不求长，但求结构清楚、每一层各司其职。

## 三十秒速览

```python
def load_contacts(path): ...
def save_contacts(contacts, path): ...
def add_contact(contacts, name, phone): ...
def find_contact(contacts, keyword): ...
def update_contact(contacts, name, new_phone): ...
def delete_contact(contacts, name): ...

def main():
    contacts = load_contacts("contacts.txt")
    while True:
        cmd = input("> ")
        if cmd == "1":
            add_contact(contacts, input("姓名："), input("电话："))
        ...
```

一个能交付的项目长这样：**数据（列表/字典）+ 纯函数（不读 input 不 print）+ 交互层（负责输入输出）+ 持久化（读写文件）** 四层分明。这一课的所有坑，都来自这四层被糊成了一团。

## 最容易错的三件事

### 一、把输入、计算、输出全挤在一个函数里

新手版通讯录通常长这样：

```python
# WRONG
def add():
    name = input("姓名：")
    phone = input("电话：")
    contacts.append({"name": name, "phone": phone})
    print("已添加")
    save(contacts)
```

看着能跑，但**没法测试**。`add()` 里嵌了 `input()`，你写单元测试就得模拟键盘；嵌了 `print()`，断言输出就得解析字符串；嵌了 `save()`，每次测试都真往磁盘写文件。

**正确分层：**

```python
def add_contact(contacts, name, phone):
    """纯函数：只改 contacts，返回是否成功。不碰 input/print/文件。"""
    if any(c["name"] == name for c in contacts):
        return False          # 重名
    contacts.append({"name": name, "phone": phone})
    return True

def cmd_add(contacts):
    """交互层：负责 input 和 print，业务逻辑交给 add_contact。"""
    name = input("姓名：")
    phone = input("电话：")
    if add_contact(contacts, name, phone):
        print("已添加")
    else:
        print("姓名已存在")
```

这个拆法的好处：**`add_contact` 可以用任何方式测试**——直接传个列表和字符串就行，不需要键盘，不需要文件，不需要改一行交互代码。

### 二、存盘格式自己发明，结果读不回来

```python
# WRONG
def save(contacts):
    with open("contacts.txt", "w") as f:
        f.write(str(contacts))   # 写入 "[{'name': '张三', 'phone': '138...'}]"
```

`str(contacts)` 看着像 Python 语法，但它**不是可靠的序列化格式**。`eval()` 读回来更危险——等于让文件里的任何字符串都能在你的程序里执行任意代码，这是经典的安全漏洞。

```python
# RIGHT：用 json
import json

def save_contacts(contacts, path):
    with open(path, "w", encoding="utf-8") as f:
        json.dump(contacts, f, ensure_ascii=False, indent=2)

def load_contacts(path):
    try:
        with open(path, "r", encoding="utf-8") as f:
            return json.load(f)
    except FileNotFoundError:
        return []                # 首次运行，文件不存在，返回空列表
    except json.JSONDecodeError:
        print("通讯录文件损坏，已重置")
        return []
```

三个细节：
- `ensure_ascii=False` 让中文**直接写出来**，而不是 `\u5f20\u4e09`；
- `FileNotFoundError` 要单独捕获，首次启动没有文件是正常情况，不该报错；
- `JSONDecodeError` 也要接住——文件被人手动改坏了，程序不该崩溃。

### 三、电话查重、按名字找人，全用 `for` 循环手写

```python
# WRONG：一遍遍遍历
def find(contacts, name):
    for c in contacts:
        if c["name"] == name:
            return c
    return None

def exists(contacts, name):
    for c in contacts:
        if c["name"] == name:
            return True
    return False
```

这里有个更清爽的写法——**用字典当索引**：

```python
def index_by_name(contacts):
    return {c["name"]: c for c in contacts}

idx = index_by_name(contacts)
if "张三" in idx:        # O(1) 查找
    print(idx["张三"]["phone"])
```

但通讯录要**允许重名**，所以索引不是万能的。重名场景用 `filter` 或推导式：

```python
matches = [c for c in contacts if keyword in c["name"]]
```

`in` 对字符串做子串匹配，输入"张"就能找到所有姓张的人——比"必须全名"好用得多。

## 翻车现场：菜单循环里忘写退出条件

```python
# WRONG
while True:
    print("1 添加  2 查找  3 退出")
    choice = input("> ")
    if choice == "1":
        ...
    elif choice == "2":
        ...
    # 忘了 elif choice == "3": break
```

用户永远退不出程序，只能 Ctrl+C。这在自己机器上测试时没人注意，交给别人用立刻露馅。

```python
while True:
    print("\n=== 通讯录 ===")
    print("1 添加  2 查找  3 修改  4 删除  5 列出全部  q 退出")
    choice = input("> ").strip().lower()
    if choice == "q":
        save_contacts(contacts, PATH)
        print("已保存，再见")
        break
    elif choice == "1":
        cmd_add(contacts)
    elif choice == "2":
        cmd_find(contacts)
    elif choice == "3":
        cmd_update(contacts)
    elif choice == "4":
        cmd_delete(contacts)
    elif choice == "5":
        cmd_list(contacts)
    else:
        print("没有这个选项")
```

三个好习惯：`save` 放在退出前而不是每次操作后（减少磁盘 I/O，且中途异常退出时至少保留上次保存的版本）；`choice` 先 `strip().lower()` 容错空格和大写；`else` 分支兜底未知输入，而不是默默忽略。

## 小结

- 项目分四层：**数据 / 纯函数 / 交互层 / 持久化**，纯函数不碰 input、print、文件
- 分层是为了可测试性，不是为分层而分层
- 存盘用 `json.dump(..., ensure_ascii=False)`，别用 `str()` + `eval()`
- `FileNotFoundError`（首次启动）和 `JSONDecodeError`（文件损坏）都要捕获
- 查重用 `in` + 推导式，重名场景允许返回多个结果
- 菜单循环必须有退出条件，退出前 `save`，未知选项要兜底
