# 函数巩固

> 这一课不重新讲概念。它做三件事：**用三十秒回顾要点、纠正最容易犯的三个错、用题目检验你是不是真的会了**。
> 如果你发现回顾部分有任何一句看着陌生，先回去看《学习篇》第 16 课，再回来做题。

## 三十秒速览

```python
def 函数名(参数1, 参数2):
    做点什么
    return 结果     # 把结果交回来
```

```python
def add(a, b):
    return a + b

s = add(3, 5)
print(s)            # 8
```

| 概念 | 一句话 | 例子 |
|---|---|---|
| `def` | 定义一个函数 | `def hi():` |
| 参数 | 函数运行前要拿到的值 | `def add(a, b)` |
| `return` | 把结果交回去 | `return a + b` |
| 没有 `return` | 默认返回 `None` | `def f(): pass` |
| 返回多个值 | 其实是返回一个**元组** | `return a, b` |

函数就是**一段可以反复调用的代码**，参数负责"喂数据"，`return` 负责"交结果"。

## 最容易错的三件事

### 一、忘记写 `return`，结果拿到 `None`

这是最容易犯的错，而且报错还看不出来——因为根本不报错。

```python
# WRONG
def add(a, b):
    a + b            # 算出来了，但没有 return 交出去

result = add(3, 5)
print(result)        # None
```

`a + b` 确实算了，但结果被丢掉了。**要拿结果就必须 `return`**：

```python
def add(a, b):
    return a + b

print(add(3, 5))     # 8
```

记住这句话：**函数里算出来的东西，不 `return` 就带不回来。**

### 二、以为"返回多个值"是真的返回了多个

```python
def point():
    x = 3
    y = 4
    return x, y       # 看起来返回了两个

p = point()
print(p)             # (3, 4)
print(type(p))       # <class 'tuple'>
```

`return x, y` 其实是**把 x 和 y 打包成一个元组返回**。`p` 就是一个元组 `(3, 4)`，只是 Python 允许你用一个"解包"写法同时接住：

```python
a, b = point()       # 解包，a 拿到 3，b 拿到 4
print(a, b)          # 3 4
```

所以"返回多个值"只是语法糖，本质还是返回**一个元组**。

### 三、以为参数是"传值"，外面不会变

Python 的参数是**传对象引用**：函数里拿到的是同一个对象，如果这个对象**可变**，在里面改它，外面也会变。

```python
def add_item(lst, item):
    lst.append(item)         # 改的是外面那个列表本身

scores = [90, 85]
add_item(scores, 100)
print(scores)               # [90, 85, 100] —— 外面也变了
```

而数字、字符串这些**不可变对象**，怎么"改"都是新建一个，外面不会变：

```python
def raise_price(price):
    price = price + 10       # 这只是让局部变量 price 指向新数字

p = 100
raise_price(p)
print(p)                    # 100 —— 没变
```

**可变的会被改（列表、字典），不可变的不会（数字、字符串、元组）。**

## 翻车现场：函数名被当成变量覆盖

```python
# WRONG
def add(a, b):
    return a + b

add = add(3, 5)      # 把 add 这个名字指向了数字 8
print(add(1, 2))     # TypeError: 'int' object is not callable
```

第一行定义的 `add` 是个函数，第三行把它**覆盖**成了数字 `8`。于是 `add` 不再是函数，"调用 add"就炸了。

这种错在写代码时很容易顺手写出。规则很简单：**别把函数名重新赋值给别的东西**。如果你确实需要存返回值，换一个变量名：

```python
def add(a, b):
    return a + b

result = add(3, 5)   # 换个名字
print(result)         # 8
```

## 小结

- 不写 `return` 的函数默认返回 `None`
- "返回多个值"其实是返回一个**元组**，可以用 `a, b = f()` 解包
- 参数是**传对象引用**：可变对象会被改，不可变对象不会
- 别用函数名当变量名去覆盖它

## 随堂练习

```quiz
type: function
q: 写 calc(a, b)：返回 a 加 b 的结果和 a 乘 b 的结果（用"返回多个值"的方式，调用方用两个变量接住）
func: calc
starter: |
  def calc(a, b):
      # 用 return 一次返回两个值
      return 0, 0
cases: |
  (3, 5) -> (8, 15)
  (10, 2) -> (12, 20)
  (-1, 4) -> (3, -4)
hint: return a + b, a * b。逗号隔开就是返回一个元组，外面用 x, y = calc(a, b) 接住。
explain: "返回多个值"本质就是返回一个元组。return a + b, a * b 等价于 return (a + b, a * b)，调用方解包即可拿到两个结果。
```

```quiz
type: choice
exam: true
q: 下面这段代码会打印什么？
code: |
  def f():
      x = 10

  print(f())
options:
- 10
- None
- 报错
- 0
answer: 1
explain: 函数里只给 x 赋了值，没有 return，所以 f() 默认返回 None。这是"忘记写 return"的经典翻车，返回 None 而不是 10。
```

```quiz
type: function
exam: true
q: 写 double_list(lst)：把传入的列表里每个数字都翻倍，并**返回同一个列表**。要求：直接在传入的列表上改（利用列表可变的特性），不要新建列表
func: double_list
starter: |
  def double_list(lst):
      # 直接修改传入的列表本身
      return []
cases: |
  ([1, 2, 3],) -> [2, 4, 6]
  ([10],) -> [20]
  ([0, -1, 5],) -> [0, -2, 10]
hint: 用 for 循环遍历索引，lst[i] = lst[i] * 2。列表是可变的，这样改外面也会跟着变。
explain: 列表是可变对象，函数里 lst[i] = ... 直接修改原列表，外面的变量也会看到变化。这正是"传对象引用"的后果——可变对象在函数内被改动会反映到外部。
```
