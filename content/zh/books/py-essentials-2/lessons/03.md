# 运算与字符串巩固

> 这一课不重新讲概念。它做三件事：**用三十秒回顾要点、纠正最容易犯的三个错、用题目检验你是不是真的会了**。
> 如果你发现回顾部分有任何一句看着陌生，先回去看《学习篇》第 4 课，再回来做题。

## 三十秒速览

```python
print(17 // 3)     # 5   整除，丢掉余数
print(17 % 3)      # 2   取余
print(2 ** 10)     # 1024 乘方

s = "python"
print(s[0])        # p    正索引：从 0 开始
print(s[-1])       # n    负索引：-1 是最后一个
print(s[1:4])      # yth  切片 [起点:终点)，终点取不到
print(s[::-1])     # nohtyp 反转

print("a" + "b")   # ab   字符串拼接
print("ab" * 3)    # ababab 重复
```

| 运算符 | 含义 | 例子 | 结果 |
|---|---|---|---|
| `//` | 整除 | `17 // 3` | `5` |
| `%` | 取余 | `17 % 3` | `2` |
| `**` | 乘方 | `2 ** 10` | `1024` |
| `[i]` | 索引 | `"abc"[1]` | `"b"` |
| `[a:b]` | 切片 | `"abcde"[1:4]` | `"bcd"` |
| `*` | 重复 | `"ab" * 3` | `"ababab"` |

**优先级**：乘方 `**` 最高，然后是乘除 `*` `/` `//` `%`，最后才是加减 `+` `-`。**不确定就加括号**，既安全又易读。

## 最容易错的三件事

### 一、运算符优先级坑：`-3 ** 2` 不等于 `9`

```python
print(-3 ** 2)      # -9
print((-3) ** 2)    # 9
```

`-3 ** 2` 被解析成 `-(3 ** 2)`，因为 `**` 优先级高于一元负号。这个坑在写公式时极常见。

另一个经典坑是 `%` 和负数：

```python
print(-17 % 3)      # 1    不是 -2！
print(-17 // 3)     # -6   向下取整，不是 -5
```

Python 的整除**向负无穷取整**，取余保证 `a == a // b * b + a % b` 恒成立。所以在 Python 里 `-17 // 3` 是 `-6`（因为 `-6 * 3 = -18 ≤ -17`），`-17 % 3` 就是 `1`。C/Java 的结果与此不同，跨语言时要小心。

### 二、切片是「左闭右开」，且越界不报错

```python
s = "python"
print(s[1:4])       # yth   —— 下标 4 那个 'o' 取不到
```

记住口诀：**起点要，终点不要**。所以 `s[0:2]` 是 `s[0]` 和 `s[1]`，不包含 `s[2]`。

切片还有一个"宽容"特性：下标越界**不报错**，自动截断到合法范围：

```python
s = "python"
print(s[2:100])     # thon    —— 越界部分被忽略
print(s[-100:2])    # py      —— 负得太多也不报错
print(s[100:])      # 空字符串
```

而**索引**越界会立刻报错：

```python
s[100]              # IndexError: string index out of range
```

这就是"索引严格、切片宽容"的区别。写循环或处理用户输入时，用切片往往比索引更省心。

### 三、`+` 和 `*` 对字符串是拼接/重复，不是算术

```python
print("3" + "5")    # 35    拼接
print("3" * 5)      # 33333  重复 5 次
print("3" * "5")    # TypeError: can't multiply sequence by non-int
```

字符串只能和整数做乘法（重复），不能和字符串相乘。想做算术就先转类型：

```python
print(int("3") + int("5"))   # 8
```

负索引是"从右往左数"，`-1` 是最后一个字符，`-len(s)` 是第一个：

```python
s = "python"
print(s[-1])        # n
print(s[-2])        # o
print(s[-6])        # p
print(s[-7])        # IndexError: string index out of range
```

注意负索引也有边界，超出同样报错。

## 翻车现场：用赋值的方式"修改"字符串切片

```python
# WRONG
s = "python"
s[1:3] = "YZ"       # TypeError: 'str' object does not support item assignment
```

字符串是不可变的，切片位置和单个字符一样**都不能赋值**。想替换一段，得靠切片拼出新字符串：

```python
s = "python"
s = s[:1] + "YZ" + s[3:]    # 用切片把前后两段接上
print(s)                     # pYthon
```

同样的道理适用于"删除"：

```python
s = "python"
s = s[:2] + s[4:]           # 去掉下标 2、3 的 'th'
print(s)                     # pyon
```

**切片时省略起点或终点**是非常实用的写法：

```python
s = "python"
print(s[:3])    # pyt   从头开始
print(s[3:])    # hon   直到末尾
print(s[:])     # python 复制一份（对字符串意义不大，对列表是浅拷贝）
```

## 小结

- `**` 优先级高于负号，写 `-3**2` 前先想清楚要不要括号
- 切片左闭右开，越界不报错；索引越界必报错
- 负索引从 `-1` 开始，代表从后往前
- `+` 对字符串是拼接，`*` 只能跟整数做重复
- 字符串不可变，修改要靠切片拼出新字符串
