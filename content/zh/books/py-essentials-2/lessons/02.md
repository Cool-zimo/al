# 输出与输入巩固

> 这一课不重新讲概念。它做三件事：**用三十秒回顾要点、纠正最容易犯的三个错、用题目检验你是不是真的会了**。
> 如果你发现回顾部分有任何一句看着陌生，先回去看《学习篇》第 3 课，再回来做题。

## 三十秒速览

```python
print("张三", "李四", "王五")          # 张三 李四 王五
print("张三", "李四", sep="|")        # 张三|李四|王五
print("你好", end="")                 # 末尾不换行
print(1, 2, 3, sep=", ", end="!\n")  # 1, 2, 3!

name = input("你叫什么：")            # 永远返回字符串
age = int(input("你多大了："))       # 转成整数
```

| 用法 | 作用 |
|---|---|
| `print(a, b, c)` | 用空格把各项隔开，末尾换行 |
| `print(..., sep="|")` | 自定义分隔符 |
| `print(..., end="")` | 末尾不换行 |
| `input("提示语")` | 显示提示语，等用户回车，返回字符串 |

**多个输入怎么读**是关键。一行里有多个数，用 `split()` 切开：

```python
a, b = input().split()        # 输入 "3 5"，得到 a="3", b="5"
x, y = map(int, input().split())   # 输入 "3 5"，得到 x=3, y=5
```

`split()` 不带参数时按**任意空白**（空格、Tab、换行）切，多个空格也算一个分隔符。

## 最容易错的三件事

### 一、`sep` 和 `end` 是关键字参数，不能乱放

```python
# WRONG
print(sep="|", "张三", "李四")   # SyntaxError: positional argument follows keyword argument
```

关键字参数（`sep=`、`end=`）必须放在**位置参数后面**。正确写法是：

```python
print("张三", "李四", sep="|")
```

`sep` 控制**各项之间**用什么连，`end` 控制**打印完之后**补什么。很多人搞反：

```python
print("1", "2", "3", sep="-")   # 1-2-3   ← 中间用 -
print("1", "2", "3", end="-")   # 1 2 3-  ← 末尾补 -
```

### 二、`input()` 拿到的总是字符串，多输入时要先 `split` 再转换

```python
# WRONG
a, b = input().split(int)        # 想读两个数：TypeError
```

`split()` 不接受 `int` 这种类型作为参数，它只接受"按什么字符切"。正确做法是**先切、再转**：

```python
# 输入：3 5
data = input().split()           # ['3', '5']
a, b = int(data[0]), int(data[1])
```

更简洁的写法是 `map`：

```python
a, b = map(int, input().split())   # 输入 "3 5" → a=3, b=5
```

注意：`map` 返回的是迭代器，这里靠**多重赋值**一次性把它拆给 a 和 b。如果输入的项数和变量数不一致，会报错：

```python
a, b = input().split()             # 输入只有一个数 → ValueError: not enough values
```

### 三、`print` 的结果不能当值用

```python
# WRONG
total = print("结果是", 18 + 24)   # 屏幕显示 "结果是 42"
print(total)                        # None
```

`print()` **永远返回 `None`**。它的作用是"往屏幕上显示"，不是"返回一个字符串"。想拿到字符串用格式化：

```python
result = f"结果是 {18 + 24}"
print(result)              # 结果是 42
print(result * 2)          # 结果是 42结果是 42
```

f-string 在运行时把 `{...}` 里的表达式替换成它的值：

```python
name, score = "张三", 95
print(f"{name} 的成绩是 {score} 分")   # 张三 的成绩是 95 分
```

## 翻车现场：忘记转换导致拼接而非相加

```python
# WRONG
a, b = input().split()     # 输入 "3 5"
print(a + b)               # 35
```

用户输入 `3 5`，`split()` 后得到 `["3", "5"]`，两个字符串相加就是拼接，得到 `"35"`。这不是报错，程序"正常"跑完了——所以这种 bug 最隐蔽。

```python
# RIGHT
a, b = map(int, input().split())   # 先转成整数
print(a + b)                       # 8
```

同样的坑在 `input` 后直接用比较运算时也会出现：`"5" > "18"` 结果是 `True`（字符串按字典序比，首字符 `'5' > '1'`），而 `5 > 18` 是 `False`。**凡是要做算术或数值比较，一律先 `int()` / `float()`。**

## 小结

- `sep` 管中间、`end` 管末尾，都是关键字参数，放位置参数之后
- `input()` 永远是字符串，多输入用 `split()` 切开再 `int()`
- `print()` 返回 `None`，要字符串用 f-string
- 字符串相加是拼接，数字相加才是算术，混用往往不报错但结果错
