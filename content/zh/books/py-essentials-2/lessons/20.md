# 文件读写巩固

> 这一课不重新讲概念。它做三件事：**用三十秒回顾要点、纠正最容易犯的三个错、用题目检验你是不是真的会了**。
> 如果你发现回顾部分有任何一句看着陌生，先回去看《学习篇》第 20 课，再回来做题。

## 三十秒速览

```python
# 读
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()     # 整个文件读成一个字符串
    lines = f.readlines()  # 读成字符串列表，每行带 \n

# 写（w 会清空！）
with open("report.txt", "w", encoding="utf-8") as f:
    f.write("你好\n")      # 不会自动加换行！
    f.write("世界\n")
```

| 模式 | 文件已存在 | 文件不存在 |
|---|---|---|
| `r` 只读 | 正常打开 | `FileNotFoundError` |
| `w` 写入 | **清空后写入** | 创建 |
| `a` 追加 | 写在末尾 | 创建 |

`with` 不是"优雅写法"，而是必需品：它会在代码块结束时自动调用 `f.close()`，即使中间抛了异常。

## 最容易错的三件事

### 一、`w` 模式会清空原文件，且没有任何提示

```python
# WRONG：本想"在 report.txt 里补一行"，结果……
f = open("report.txt", "w", encoding="utf-8")
f.write("新内容\n")
f.close()
```

如果 `report.txt` 里原本有 1000 行数据，执行完这段代码后，**那 1000 行全部消失**，只剩下"新内容"一行。`w` 的语义是"以写入方式打开"，只要文件存在就先截断成 0 字节。

想在末尾追加，用 `a`：

```python
f = open("report.txt", "a", encoding="utf-8")
f.write("补一行\n")   # 写在末尾，原有内容保留
f.close()
```

想"存在就报错、不存在才创建"，用 `x`（Python 3）：`open("report.txt", "x")` 已存在则 `FileExistsError`。`w` / `a` / `x` 三者的差别是文件操作最危险也最常考的地方。

### 二、忘写 `with`，文件句柄没关掉

```python
# WRONG
f = open("report.txt", "w", encoding="utf-8")
f.write("hello")
# 忘记 f.close()
```

三个后果：
1. 写入内容**可能没真正落到磁盘**。`write` 先写缓冲区，关闭时才刷盘，进程异常退出会丢数据。
2. 文件句柄是有限资源，大量打开不关会耗尽。
3. 文件被占用时（Windows 尤其常见），其他程序打不开它。

`with` 在代码块结束时**无论是否抛异常**都自动 `close()`：

```python
with open("report.txt", "w", encoding="utf-8") as f:
    f.write("hello")      # 缩进结束的瞬间，f.close() 被自动调用
```

顺带一提：`write` 返回的是写入的字符数，不是成功与否的布尔值，别拿它当条件判断。

### 三、`write` 不会自动加换行

```python
# WRONG
with open("names.txt", "w", encoding="utf-8") as f:
    f.write("张三")
    f.write("李四")
    f.write("王五")
```

读出来一看：

```
张三李四王五
```

三行内容挤成了一行。`print(..., file=f)` 会自动加换行，`f.write()` 不会：

```python
with open("names.txt", "w", encoding="utf-8") as f:
    f.write("张三\n")
    f.write("李四\n")
    f.write("王五\n")
```

另外 `readlines()` 返回的每一行都带着末尾的 `\n`，处理前通常需要 `strip()`：`[line.strip() for line in f.readlines()]`。

## 翻车现场：`read` / `readline` / `readlines` 共用一个文件指针

```python
# WRONG
with open("report.txt", "r", encoding="utf-8") as f:
    first = f.readline()
    rest = f.readlines()
    print(first, rest)
```

`report.txt` 只有一行时，输出是：

```
['']
```

`readline()` 已经把第一行（也就是唯一一行）读走了，文件指针到了末尾，`readlines()` 只能拿到空列表。三者不是"各自给一份拷贝"，而是**共用同一个指针，读一个少一个**：

```python
with open("report.txt", "r", encoding="utf-8") as f:
    content = f.read()   # 读走全部，指针到末尾

print(f.read())          # ""  什么也读不到
```

`read()` 全读成字符串 / `readline()` 读一行 / `readlines()` 全读成列表。要逐行处理，最干净的是直接迭代文件对象：

```python
with open("report.txt", "r", encoding="utf-8") as f:
    for line in f:       # 每次只读一行进内存，大文件友好
        print(line.strip())
```

## 小结

- `r` 只读 / `w` 写入（会清空！）/ `a` 追加；想"不存在才创建"用 `x`
- 必须用 `with`，它会自动 `close()`，即使中间抛异常
- `f.write()` 不自动加换行，要自己写 `\n`；想自动换行用 `print(..., file=f)`
- `read` 全读成字符串 / `readline` 读一行 / `readlines` 全读成列表，三者共用文件指针
- 大文件逐行处理用 `for line in f:`
- 涉及中文一定要写 `encoding="utf-8"`，否则 Windows 默认 GBK 会 `UnicodeDecodeError`
