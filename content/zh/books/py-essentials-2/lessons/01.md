# 变量与类型巩固

> 这一课不重新讲概念。它做三件事：**用三十秒回顾要点、纠正最容易犯的三个错、用题目检验你是不是真的会了**。
> 如果你发现回顾部分有任何一句看着陌生，先回去看《学习篇》第 2 课，再回来做题。

## 三十秒速览

```python
name = "张三"      # 字符串 str
age = 18           # 整数 int
height = 1.75      # 浮点数 float
is_student = True  # 布尔 bool
```

| 类型 | 例子 | 用 `type()` 看 |
|---|---|---|
| `int` | `18`、`-3`、`0` | `<class 'int'>` |
| `float` | `1.75`、`3.0`、`-0.5` | `<class 'float'>` |
| `str` | `"abc"`、`"18"` | `<class 'str'>` |
| `bool` | `True`、`False` | `<class 'bool'>` |

变量就是**给一个值贴标签**。贴完标签，用标签就能找到那个值。

```python
a = 10
b = a          # b 拿到的是 a 当前指向的值 10
a = 20         # 改 a 不影响 b
print(a, b)    # 20 10
```

这句话要记牢：**`=` 是把右边的值放进左边的标签里，不是声明"两边永远相等"。**

## 最容易错的三件事

### 一、把 `=` 当成数学上的等号

```python
# WRONG：想表达"x 等于 x + 1"
x = 5
x = x + 1      # 这句话在数学上不成立，但在编程里完全合法
print(x)       # 6
```

`x = x + 1` 的执行顺序是：**先算右边的 `x + 1`（此时 x 是 5，得 6），再把 6 放进 x**。所以它不是"等式"，是"覆盖"。

判断相等用的是 `==`（两个等号）：

```python
x = 5
print(x == 5)   # True   —— 这是"判断"
print(x = 5)    # SyntaxError —— 这是"赋值"，不能放在 print 里
```

### 二、忘了 `input()` 拿到的是字符串

这是新手撞得最多的一堵墙，没有之一。

```python
# WRONG
age = input("请输入年龄：")   # 用户输入 18
if age > 18:                 # TypeError: '>' not supported between 'str' and 'int'
    print("成年")
```

`input()` **永远返回字符串**，哪怕你输入的是数字。`"18" > 18` 是拿字符串和数字比大小，Python 直接拒绝。

正确写法：

```python
age = int(input("请输入年龄："))   # 转成整数
if age > 18:
    print("成年")
```

同理，要小数就用 `float()`。反过来，要把数字变成字符串用 `str()`：

```python
print("我今年" + str(18) + "岁")    # 我今年18岁
print("我今年" + 18)                # TypeError: can only concatenate str
```

### 三、`+` 在数字和字符串上是两回事

```python
print(1 + 2)        # 3      数字相加
print("1" + "2")    # 12     字符串拼接
print(1 + "2")      # TypeError: unsupported operand type(s)
```

看到 `TypeError: unsupported operand type(s)` 时，第一反应应该是：**两边类型不一样**。用 `type()` 检查一下：

```python
x = "2"
print(type(x))      # <class 'str'>   —— 果然是字符串
```

## 翻车现场：字符串是不可变的

```python
# WRONG
s = "hello"
s[0] = "H"
```

```
TypeError: 'str' object does not support item assignment
```

字符串一旦创建就**不能改某个位置的字符**。要改，得新建一个：

```python
s = "hello"
s = "H" + s[1:]     # 用切片拼一个新的
print(s)            # Hello
```

注意这里 `s = ...` 不是"修改原字符串"，而是**让标签 s 指向一个新字符串**。原来的 "hello" 还躺在内存里等着被回收。

列表就不一样，列表**可以**改：

```python
lst = ["h", "e", "l", "l", "o"]
lst[0] = "H"        # 可以
print(lst)          # ['H', 'e', 'l', 'l', 'o']
```

这个区别（字符串不可变 vs 列表可变）后面会反复考。

## 小结

- `=` 是赋值（覆盖），`==` 是判断（相等）
- `input()` 永远返回字符串，要数字就用 `int()` / `float()`
- `+` 对数字是加法，对字符串是拼接，混用会 `TypeError`
- 字符串不可变，改字符要新建
- 遇到 `TypeError` 先查两边的 `type()`

## 随堂练习

```quiz
type: code
q: 读入一个整数 n，打印 n 加 100 的结果。系统会依次输入 5
starter: |
  # input() 拿到的是字符串，记得转换
  n = int(input())
  
  print("在这里改")
stdin: |
  5
tests:
- assert "105" in __out
hint: int(input()) 转成整数后才能做加法。直接 print(n + 100)。
explain: 这一课的核心就是"input() 返回字符串"。如果写成 n = input()，那 n + 100 会报 TypeError；即使写成 n + "100" 也只是拼接成 "5100"，不是 105。
```

## 本节测验

```quiz
type: choice
exam: true
q: 下面这段代码运行后，a 和 b 分别是多少？
code: |
  a = 10
  b = a
  a = 20
options:
- a 是 20，b 是 20
- a 是 20，b 是 10
- a 是 10，b 是 20
- 报错
answer: 1
explain: b = a 这行执行时，a 是 10，所以 b 拿到的是 10 这个值，不是"绑定到 a 身上"。之后 a 改成 20，和 b 没有任何关系。变量之间赋值是"复制值"，不是"建立联系"。
```

func: describe
starter: |
  def describe(name, age, city):
      # 用 str() 把 age 转成字符串，再拼接
      return ""
cases: |
  ("张三", 18, "北京") -> "张三今年18岁，住在北京"
  ("李四", 7, "上海") -> "李四今年7岁，住在上海"
