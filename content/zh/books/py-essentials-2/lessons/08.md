# while 巩固

> 这一课不重新讲概念。它做三件事：**用三十秒回顾要点、纠正最容易犯的三个错、用题目检验你是不是真的会了**。
> 如果你发现回顾部分有任何一句看着陌生，先回去看《学习篇》第 8 课，再回来做题。

## 三十秒速览

```python
i = 1
while i <= 5:          # 条件为真就反复执行
    print(i)
    i = i + 1          # 别忘了更新，否则死循环
```

`while` 循环有三个要素，**缺一个就出事**：

1. **初始值**：循环变量一开始是多少（上面是 `i = 1`）
2. **循环条件**：什么时候继续转（上面是 `i <= 5`）
3. **更新语句**：每轮怎么推进（上面是 `i = i + 1`）

常见写法 `while True:` 配 `break`——条件写在循环体里，命中就跳出：

```python
while True:
    s = input("输入数字（q 退出）：")
    if s == "q":
        break              # 跳出整个循环
    print("你输入了", s)
```

## 最容易错的三件事

### 一、死循环：忘了写更新语句

```python
# WRONG：经典死循环
i = 1
while i <= 5:
    print(i)
    # 漏了 i = i + 1
```

程序会**不停地打印 1**，直到你手动中断。因为 `i` 永远是 1，条件 `i <= 5` 永远成立。

修法：在循环体里**推进循环变量**。

```python
i = 1
while i <= 5:
    print(i)
    i = i + 1         # 每轮 +1，5 轮后条件不成立，自动退出
```

养成习惯：**写 `while` 时先写更新语句，再填循环体**。先保证不会死循环，再往里加逻辑。

### 二、更新语句写错方向，条件永远成立

```python
# WRONG：条件是"小于"，更新却是"减"
i = 1
while i < 10:
    print(i)
    i = i - 1          # 越减越小，1, 0, -1, -2... 永远 < 10
```

或者**更新了错误的变量**：

```python
# WRONG
i = 1
while i <= 5:
    print(i)
    n = i + 1          # 改的是 n，i 纹丝不动
```

判断循环会不会终止，只要问一句：**循环变量有没有在朝"让条件不成立"的方向走？** 没走，就是死循环。

### 三、把 `=` 写在条件里

```python
# WRONG
while x = 5:           # SyntaxError: invalid syntax
    print(x)
```

条件里只能用 `==` 比较，不能用 `=` 赋值。Python 会直接报 `SyntaxError` 拦住你。

```python
x = 5
while x == 5:          # 语法对，但如果不改 x 就是死循环
    print(x)
    x = 0              # 必须让条件有机会不成立
```

顺带提一句：`while` 的条件不要写成 `while True:` 然后**忘了写 `break`**，那也是死循环。

## 翻车现场：三种死循环叠在一起

```python
# WRONG：三处致命问题
count = 0
while count < 3:
    print("count =", count)
    answer = input("继续吗？")
    if answer == "n":
        break
    # 漏了 count += 1  ← 死法一：忘记推进
```

用户一直不输入 `n`，循环就永远转。修法：

```python
count = 0
while count < 3:
    print("count =", count)
    answer = input("继续吗？")
    if answer == "n":
        break
    count += 1          # 修：无论如何都要推进
```

再看第二种死法——**条件变量和输入变量是两套**：

```python
# WRONG：指望用户输入来控制循环，却没用输入值当条件
data = ""
while data != "quit":      # 条件看的是 data
    s = input("输入：")    # 但输入存进了 s，data 永远是 ""
    print(s)
```

`data` 从未被更新，条件永远成立。修法：把输入存进判断用的变量。

```python
data = ""
while data != "quit":
    data = input("输入（quit 退出）：")   # 存进 data
    if data != "quit":
        print(data)
```

第三种死法是 `break` 写在了**永远进不去的分支**里：

```python
# WRONG
while True:
    n = int(input())
    if n > 0:             # 用户输入 0 或负数，这个分支不进，break 永远碰不到
        print(n)
        break
```

三种死法的共同点：**没有任何一条路径能让循环终止**。写 `while` 时，保证"正常路径"和"异常路径"都能走到出口。

## 小结

- `while` 三要素：初始值、循环条件、更新语句，缺一个就出事
- 死循环三大成因：忘了更新、更新方向反了、更新了错误的变量
- 条件里用 `==`，别用 `=`（后者会 `SyntaxError`）
- `while True:` 必须配 `break`，且 `break` 要写在所有可能走到的路径上
- 防死循环习惯：先写更新语句，再填循环体

## 随堂练习

```quiz
type: code
q: 用 while 循环，从 1 数到 5，每行打印一个数。系统无需输入
starter: |
  # 三要素：初始值 i = 1、条件 i <= 5、更新 i += 1
  print("TODO：把这行改成你要打印的结果")
tests:
- assert __out.strip() == "1\n2\n3\n4\n5"
hint: i 从 1 开始，while i <= 5 内打印 i 并 i += 1。注意别写成 while i < 5，那样只会打印到 4。
explain: 这是 while 最标准的写法。反例 1：漏了 i += 1 → 死循环，不停打印 1。反例 2：条件写成 while i < 5 → 只打印 1~4，少了 5。反例 3：更新写成 i -= 1 → i 越减越小，条件永远成立，又是死循环。
```

```quiz
q: 下面代码会怎样？
code: |
  i = 10
  while i > 0:
      print(i)
      i = i + 2
options:
- 打印 10 到 2 的偶数后停止
- 一直打印 10、12、14... 永不停止

answer: 1
explain: i 从 10 开始，每次 +2，越来越大，条件 i > 0 永远成立，所以是死循环。这正是"更新方向反了"的典型——本意若是倒计时，应该是 i -= 1；本意若是打印偶数，条件应该是 i <= 某个上限。
```
