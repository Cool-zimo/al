# 列表操作巩固

> 这一课不重新讲概念。它做三件事：**用三十秒回顾要点、纠正最容易犯的三个错、用题目检验你是不是真的会了**。
> 这一课对应《学习篇》第 12 课。如果你发现回顾部分有任何一句看着陌生，先回去看《学习篇》第 12 课，再回来做题。

## 三十秒速览

```python
a = [3, 1, 2]
a.append(4)     # [3, 1, 2, 4]      末尾加一个
a.insert(1, 9)  # [3, 9, 1, 2, 4]   在位置 1 插入
a.pop()         # 返回 4，a 变成 [3, 9, 1, 2]
a.remove(9)     # [3, 1, 2]         删除第一个值为 9 的元素
a.sort()        # [1, 2, 3]         原地排序，返回 None
sorted(a)       # 返回新列表，a 不变
a.reverse()     # [3, 2, 1]         原地反转
a.index(2)      # 1   第一次出现的位置
a.count(2)      # 1   出现次数
len(a)          # 3
```

| 原地改 | 返回新列表 | 区别 |
|---|---|---|
| `sort()` / `reverse()` | `sorted()` / `reversed()` | 前者改自身、返回 `None`；后者不动原列表 |

## 最容易错的三件事

### 一、`sort()` 返回 `None`，不是排好的列表

```python
# WRONG
a = [3, 1, 2]
b = a.sort()
print(b)        # None
```

`list.sort()` 是**原地排序**，它直接把 `a` 排好，然后返回 `None`。所以 `b` 拿到的是 `None`，`a` 自己倒是排好了。

想要"不改动原列表、拿到一份排好的新列表"，用内置函数 `sorted()`：

```python
a = [3, 1, 2]
b = sorted(a)   # b 是 [1, 2, 3]，a 仍是 [3, 1, 2]
```

顺带一提：`sorted()` 对任何可迭代对象都能用（元组、字符串、集合都行），`list.sort()` 只有列表有。

### 二、`pop()` 不写参数才是删末尾；写参数是删指定位置

```python
a = [10, 20, 30, 40]
a.pop()         # 返回 40，a 变成 [10, 20, 30]
a.pop(0)        # 返回 10，a 变成 [20, 30]
```

`pop` 是唯一一个**既删除又返回**的方法。`remove` 只删、不返回。另外 `pop(0)` 删第一个元素，代价是 O(n)（后面所有元素要前移），频繁在头部增删就该用 `collections.deque`。

### 三、`index()` 和 `remove()` 找不到就报错

```python
# WRONG
a = [1, 2, 3]
print(a.index(9))
```

```
ValueError: 9 is not in list
```

`a.index(x)` 在找不到时抛 `ValueError`，`a.remove(x)` 找不到同样抛 `ValueError`。**用之前先 `in` 判断一下**，或者写好异常处理。

## 翻车现场：遍历列表时删除元素

这是新手最容易撞、也最难自查的 bug。

```python
# WRONG：想删掉所有奇数
nums = [1, 2, 3, 4, 5]
for x in nums:
    if x % 2 != 0:
        nums.remove(x)
print(nums)     # [2, 4, 5]   5 居然还在
```

```
# 没有报错，结果却是错的
# 执行过程：
# i=0，x=1，删除 1，列表变成 [2, 3, 4, 5]，下一个看下标 1
# i=1，x=3（因为下标 1 现在是 3），删除 3，列表变成 [2, 4, 5]，下一个看下标 2
# i=2，x=5（下标 2 现在是 5）……等等，下标 2 其实是 4？
# 下标 2 是 4，跳过；循环结束。5 被漏掉了。
```

**边遍历边删，会跳过元素。** 删除一个元素后，后面的元素整体前移，而循环的下标照常推进，于是"下一个"就跳过了原本该检查的那一个。

正确写法有几种：

```python
# 法一：倒着删（下标前移不影响还没检查的部分）
nums = [1, 2, 3, 4, 5]
for i in range(len(nums) - 1, -1, -1):
    if nums[i] % 2 != 0:
        nums.pop(i)
print(nums)     # [2, 4]

# 法二：列表推导式，最推荐
nums = [1, 2, 3, 4, 5]
nums = [x for x in nums if x % 2 == 0]
print(nums)     # [2, 4]
```

**经验法则：凡是"过滤"，就用列表推导式**，干净且没有下标错位的问题。

## 小结

- `sort()` 原地改、返回 `None`；`sorted()` 返回新列表、原列表不动
- `pop()` 删并返回，`pop(0)` 是 O(n)
- `index()` / `remove()` 找不到就 `ValueError`，用前先 `in`
- **不要在遍历列表的同时删除元素**，用列表推导式替代
- 过滤数据首选推导式，别手动下标操作
