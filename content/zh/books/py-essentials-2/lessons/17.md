# 参数进阶巩固

> 这一课不重新讲概念。它做三件事：**用三十秒回顾要点、纠正最容易犯的三个错、用题目检验你是不是真的会了**。
> 如果你发现回顾部分有任何一句看着陌生，先回去看《学习篇》第 17 课，再回来做题。

## 三十秒速览

```python
def greet(name, greeting="你好"):          # greeting 有默认值
    print(greeting + "，" + name)

greet("张三")                              # 你好，张三
greet("李四", "早上好")                    # 早上好，李四
greet(name="王五", greeting="晚上好")      # 晚上好，王五 —— 关键字参数
```

| 写法 | 含义 | 例子 |
|---|---|---|
| `def f(a, b=1)` | `b` 有默认值 | `f(10)` 即可 |
| `f(b=2, a=1)` | 关键字参数，顺序随意 | 不报错 |
| `def f(*args)` | 收集多余位置参数为**元组** | `args=(1,2,3)` |
| `def f(**kwargs)` | 收集多余关键字参数为**字典** | `kwargs={'a':1}` |

参数进阶就是三件事：**给参数默认值、用名字传参、一次收一堆参数**。

## 最容易错的三件事

### 一、默认参数用了可变对象（经典陷阱）

这是 Python 里最著名的坑，没有之一。

```python
# WRONG
def add_item(item, lst=[]):
    lst.append(item)
    return lst

print(add_item(1))     # [1]
print(add_item(2))     # [1, 2]  —— 不是 [2]！
print(add_item(3))     # [1, 2, 3]
```

为什么？因为**默认参数 `lst=[]` 只在函数定义时创建一次**，之后每次调用都复用同一个列表。你以为的"空列表"其实是同一个列表，越攒越多。

正确写法是用 `None` 占位，在函数里再新建：

```python
def add_item(item, lst=None):
    if lst is None:
        lst = []               # 每次调用都新建一个
    lst.append(item)
    return lst

print(add_item(1))     # [1]
print(add_item(2))     # [2]
print(add_item(3))     # [3]
```

记牢一句话：**默认参数永远用不可变对象（`None`、数字、字符串、元组），不要用列表、字典。**

### 二、位置参数不能写在关键字参数后面

```python
def greet(name, greeting="你好"):
    print(greeting + "，" + name)

# WRONG
greet(name="张三", "早上好")
```

```
SyntaxError: positional argument follows keyword argument
```

规则是：**一旦用了关键字参数，它后面的参数都必须用关键字**。因为 Python 规定"位置参数要排在前，关键字参数排在后"。

正确写法：要么全用位置，要么关键字往后放。

```python
greet("张三", "早上好")            # 全位置，可以
greet("张三", greeting="早上好")   # 混用：位置在前，关键字在后，可以
```

### 三、`*args` 和 `**kwargs` 一次收集的是"多出来"的参数

```python
def show(name, *args, **kwargs):
    print("name:", name)
    print("args:", args)        # 多余的"位置"参数，是个元组
    print("kwargs:", kwargs)    # 多余的"关键字"参数，是个字典

show("张三", 90, 85, city="北京", age=18)
# name: 张三
# args: (90, 85)
# kwargs: {'city': '北京', 'age': 18}
```

`*args` 收集**位置参数**成元组，`**kwargs` 收集**关键字参数**成字典。它们用来写"参数数量不确定"的函数。

注意名字里的 `*` 和 `**` 是语法，**`args` 和 `kwargs` 只是约定俗成的名字**，换成别的也行。

## 翻车现场：`*args` 里不能带两个 `**`

```python
# WRONG
def f(*args, **args2, **args3):
    pass
```

```
SyntaxError: invalid syntax
```

一个函数里**只能有一个 `*` 收集和一个 `**` 收集**，多了 Python 不知道往哪放。正确顺序永远是：`普通参数 → *args → **kwargs`。

```python
def f(a, b=10, *args, **kwargs):   # 顺序：普通 → 默认 → * → **
    pass
```

实际用得最多的是这种写法：**`def f(*args, **kwargs)`**，意思是"我什么参数都接"，常在写装饰器、包装函数时用到。

## 小结

- **默认参数不要用可变对象**，用 `None` 占位，函数里再新建
- 位置参数必须排在关键字参数**前面**
- `*args` 收集多余位置参数为元组，`**kwargs` 收集多余关键字参数为字典
- 一个函数只能有一组 `*` 和一组 `**`，顺序固定
