# break / continue / 嵌套巩固

> 这一课不重新讲概念。它做三件事：**用三十秒回顾要点、纠正最容易犯的三个错、用题目检验你是不是真的会了**。
> 如果你发现回顾部分有任何一句看着陌生，先回去看《学习篇》第 10 课，再回来做题。

## 三十秒速览

```python
for i in range(5):
    if i == 2:
        continue        # 跳过本轮，直接进入下一轮
    if i == 4:
        break           # 跳出整个循环
    print(i)
# 输出：0 1 3  ← 2 被跳过，4 时跳出
```

三个控制流的分工：

- `continue`：**跳过本轮**，直接进入下一次迭代
- `break`：**跳出整个循环**，循环立刻结束
- `pass`：**什么都不做**，只是占个位（用来写空的分支）

嵌套循环：循环里套循环，内层循环完整跑完一遍，外层才推进一次。

```python
for i in range(2):          # 外层跑 2 次
    for j in range(3):      # 内层每次跑 3 次
        print(i, j)
# 0 0 / 0 1 / 0 2 / 1 0 / 1 1 / 1 2
```

`for ... else`：循环**正常结束**（不是被 `break` 打断）时，执行 `else` 块。

```python
for n in range(2, 10):
    if n == 5:
        break
else:
    print("没被 break 打断才执行")
# 这里 break 命中了，else 不执行
```

## 最容易错的三件事

### 一、`break` 只跳一层，跳不出外层

```python
# WRONG：想找到 5 就完全停下
for i in range(3):
    for j in range(3):
        if j == 1:
            break          # 只跳出内层的 for j
        print(i, j)
# 0 0 / 1 0 / 2 0  ← 外层还在继续
```

内层的 `break` 只能跳出**它所在的那一层**，外层照转不误。要跳出多层，常见两种办法：

```python
# 办法 1：用标志位
found = False
for i in range(3):
    for j in range(3):
        if j == 1:
            found = True
            break
    if found:
        break              # 外层也跳

# 办法 2：把逻辑抽成函数，用 return
def find():
    for i in range(3):
        for j in range(3):
            if j == 1:
                return i, j
    return None

print(find())              # (0, 1)
```

抽成函数 + `return` 通常更清晰，推荐优先用。

### 二、`continue` 放错位置，逻辑漏掉一轮

```python
# WRONG：想跳过偶数，只打印奇数
for i in range(5):
    if i % 2 == 0:
        print("偶数跳过")
        continue
    print(i)          # 这里只有奇数才打印
# 打印 偶数跳过 / 1 / 偶数跳过 / 3 / 偶数跳过
```

这个例子本身没错，但要警惕**`continue` 后面的代码被悄悄跳过**：

```python
# WRONG
for i in range(5):
    if i == 2:
        continue
    print("处理", i)
    total += i        # i == 2 时这行不会执行，total 少了 2
```

`continue` 之后的**所有**代码都跳过，包括你以为会执行的收尾逻辑。写 `continue` 时，问一句：**后面还有没有必须执行的事？** 有，就把那些事提到 `continue` 之前，或改用 `if-else`。

### 三、`for ... else` 的 `else` 不是"循环为空"

很多人以为 `else` 是"循环没执行时"才跑，其实完全相反：

```python
# else 在循环"正常跑完、没被 break"时执行
for n in []:            # 空列表，循环一次都没跑
    print("循环体")
else:
    print("else 块")     # 照样执行！因为没被 break 打断
```

`else` 的触发条件是**循环结束且没遇到 `break`**，哪怕一次都没迭代过也算"没被打断"。

```python
# 经典用法：在序列里找东西，找到就 break
for x in [3, 1, 4, 1, 5]:
    if x == 9:
        print("找到了")
        break
else:
    print("没找到 9")     # 会执行，因为没 break
```

`else` 是"没 break 就执行"，用来表达"找遍了都没找到"。

## 翻车现场：嵌套计数器的常见错误

需求：打印九九乘法表的前三行。

```python
# WRONG：只用一个变量，内外层混用
i = 1
while i <= 3:
    j = 1
    while j <= 3:
        print(f"{i}×{j}={i*j}", end="  ")
        i = i + 1       # 错：改的是外层的 i！
    print()
    j = j + 1
```

内层的 `i = i + 1` 把外层的 `i` 也改了，外层只跑一轮就停。内外层必须用**两个独立变量**：

```python
i = 1
while i <= 3:
    j = 1
    while j <= 3:
        print(f"{i}×{j}={i*j}", end="  ")
        j = j + 1       # 只改内层的 j
    print()
    i = i + 1           # 外层自己推进
# 1×1=1  1×2=2  1×3=3
# 2×1=2  2×2=4  2×3=6
# 3×1=3  3×2=6  3×3=9
```

再来一个 `for-else` 的坑：

```python
# WRONG：以为 else 是"没进循环"
found_prime = False
for n in range(2, 10):
    for d in range(2, n):
        if n % d == 0:
            found_prime = False
            break           # 这个 break 只跳出内层 for d
    else:
        found_prime = True  # 属于 for d 的 else！
        print(n, "是质数")
```

`else` 和它**最近的一层 `for`/`while` 配对**。这里 `else` 属于 `for d`，不是 `for n`。这种缩进错位是嵌套循环里最常见的 bug 来源。对齐缩进时，**`else` 要和想配对的 `for` 在同一列**。

## 小结

- `continue` 跳过本轮剩余代码，进入下一轮；`break` 直接结束整个循环
- `break` 只跳一层，跳不出外层；跳出多层用函数 `return` 或标志位
- `for ... else` 的 `else` 在**循环没被 break 打断时**执行，空循环也算
- 嵌套循环用独立变量控制内外层，别混用
- `else` 和它最近的那层 `for`/`while` 配对，缩进要对齐
- `pass` 是空操作，用来占住语法上不能空着的地方
