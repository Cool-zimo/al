# 元组与字典巩固

> 这一课不重新讲概念。它做三件事：**用三十秒回顾要点、纠正最容易犯的三个错、用题目检验你是不是真的会了**。
> 这一课对应《学习篇》第 13 课。如果你发现回顾部分有任何一句看着陌生，先回去看《学习篇》第 13 课，再回来做题。

## 三十秒速览

```python
t = (1, 2, 3)       # 元组 tuple，用小括号，不可变
print(t[0])         # 1         能取值
t[0] = 10           # TypeError 不能改

d = {"北京": 2184, "上海": 2487, "广州": 1881}   # 字典 dict
d["北京"]           # 2184      取值
d["深圳"] = 1766    # 新增/修改
del d["广州"]       # 删除
"上海" in d         # True      判断键是否存在
```

| | 元组 tuple | 字典 dict |
|---|---|---|
| 可不可变 | 不可变 | 可变 |
| 取元素 | 按下标 `t[0]` | 按键 `d[k]` |
| 常见用途 | 多值打包、作字典键 | 键值映射 |

## 最容易错的三件事

### 一、单元素元组要加逗号

```python
a = (42)
print(type(a))      # <class 'int'>   这不是元组

b = (42,)
print(type(b))      # <class 'tuple'>  这才是元组

c = 42,             # 不加括号也行，逗号才是关键
print(type(c))      # <class 'tuple'>
```

括号只是分组，逗号才是元组的标志。这个坑在函数返回多个值时尤其隐蔽——`return 1, 2` 返回的是一个元组 `(1, 2)`。

### 二、元组"不可变"不等于"里面绝对不能变"

```python
t = (1, [2, 3])
t[1].append(4)      # 可以
print(t)            # (1, [2, 3, 4])
```

```
# 报错出现在这一步：
t[1] = [2, 3, 4]    # TypeError: 'tuple' object does not support item assignment
```

元组的不可变，指的是**它装的那几个对象的引用不能换**。但那个对象本身如果是可变的（列表、字典），它的内容照样能改。所以准确的说法是：**元组保证的是"结构不变"，不是"数据不变"**。

### 三、字典的键必须可哈希，列表不能当键

```python
# WRONG
d = {[1, 2]: "value"}
```

```
TypeError: unhashable type: 'list'
```

列表是可变的，可变对象不可哈希，所以**不能当字典的键**。常见可用的键：`int`、`float`、`str`、`bool`、元组（里面的元素也都不可变时）。

```python
d = {(1, 2): "北京"}    # 可以，元组可哈希
print(d[(1, 2)])       # 北京
```

什么时候用元组？——**数据不该被改动时**。函数返回多个值、坐标点 `(x, y)`、当字典的复合键，都是元组的典型场景。

## 翻车现场：用不存在的键取值

```python
# WRONG
scores = {"张三": 95, "李四": 88}
print(scores["王五"])
```

```
KeyError: '王五'
```

直接 `d[k]` 取一个不存在的键，Python 会抛 `KeyError`，程序当场中断。

安全的取值方式有三种：

```python
# 法一：先 in 判断
if "王五" in scores:
    print(scores["王五"])

# 法二：get 带默认值，最常用
print(scores.get("王五", 0))    # 0    键不存在就返回 0，不会报错

# 法三：setdefault，不存在就设进去再返回
scores.setdefault("王五", 0)    # 顺便把 "王五": 0 写进字典
```

**养成习惯：拿不准键存不存在，就用 `get()`。** 它把"取值 + 默认处理"合成一步，是字典最常用的安全写法。

## 小结

- 单元素元组要写 `(42,)`，逗号才是元组的标志
- 元组结构不可变，但里面装的可变对象内容可变
- 字典的键必须可哈希：**列表不能当键，元组可以**
- 取不确定的键用 `get(k, default)`，避免 `KeyError`
- 不该被改动的数据用元组，需要映射查找用字典
