## 三十秒速览

```python
d = {"北京": 2184, "上海": 2487}

# 带默认值取值
d.get("广州", 0)      # 0   键不存在返回 0

# 三种遍历
for k in d:               # 遍历键（最常用）
    pass
for v in d.values():      # 遍历值
    pass
for k, v in d.items():    # 遍历键值对
    pass

# 字典推导式
squares = {x: x*x for x in range(5)}   # {0:0, 1:1, 2:4, 3:9, 4:16}
```

| 方法 | 返回 |
|---|---|
| `d.keys()` | 所有键的视图 |
| `d.values()` | 所有值的视图 |
| `d.items()` | 所有键值对的视图 |

**字典是无序的**这个说法在 Python 3.7+ 已经过时了——从 3.7 起字典**保持插入顺序**，可以放心按顺序遍历。

## 最容易错的三件事

### 一、`get()` 的默认值只在"键不存在"时生效

```python
d = {"北京": 2184, "上海": 0}
print(d.get("上海", 999))    # 0    值是 0，不是"不存在"
print(d.get("广州", 999))    # 999  键确实没有
```

`get(key, default)` 判断的是**键是否存在**，跟值是多少无关。所以别指望用 `get` 来区分"键不存在"和"值是 0/空字符串/None"。真要区分，用 `in`：

```python
if "上海" in d:
    # 键存在，值可能是 0、None 任何东西
    pass
```

### 二、`items()` 遍历时也不能随便删键

```python
# WRONG
d = {"北京": 2184, "上海": 2487, "广州": 1881}
for k in d:
    if d[k] < 2000:
        del d[k]     # RuntimeError: dictionary changed size during iteration
```

一边遍历一边改大小，直接 `RuntimeError`。想过滤字典，用字典推导式：

```python
d = {"北京": 2184, "上海": 2487, "广州": 1881}
d = {k: v for k, v in d.items() if v >= 2000}
print(d)    # {'北京': 2184, '上海': 2487}
```

**跟列表一个道理：过滤用推导式。**

### 三、嵌套字典取值要一层层判空

```python
db = {
    "张三": {"语文": 90, "数学": 95},
    "李四": {"语文": 88}
}

# WRONG：想拿李四的数学
print(db["李四"]["数学"])     # KeyError: '数学'
```

```python
# 正确：逐层 get
print(db.get("李四", {}).get("数学", 0))   # 0
```

链式 `get` 是嵌套字典取值的安全写法：外层 `get("李四", {})` 保证即使"李四"这个键没有，也返回一个空字典，再 `.get("数学", 0)` 就不会崩。

## 翻车现场：计数漏了默认值这一步

新手手写的计数常常写成这样：

```python
# WRONG：直接取值，键不存在就 KeyError
words = ["苹果", "香蕉", "苹果", "橙子", "香蕉", "苹果"]
count = {}
for w in words:
    count[w] = count[w] + 1      # KeyError: '苹果'
```

```
KeyError: '苹果'
```

第一次遇到"苹果"时，它还没在字典里，直接 `count[w]` 就炸了。

三种修法，都该记住：

```python
words = ["苹果", "香蕉", "苹果", "橙子", "香蕉", "苹果"]

# 法一：in 判断
count = {}
for w in words:
    if w in count:
        count[w] += 1
    else:
        count[w] = 1

# 法二：get 带默认值
count = {}
for w in words:
    count[w] = count.get(w, 0) + 1

# 法三：collections.Counter，最专业
from collections import Counter
count = Counter(words)
print(count)        # Counter({'苹果': 3, '香蕉': 2, '橙子': 1})
print(count["梨"])  # 0   Counter 访问不存在的键返回 0，不会报错
```

**实际项目里直接用 `Counter`**，它是为计数量身定做的。`most_common(n)` 还能直接取出现最多的前 n 个。

## 小结

- `get(k, default)` 只判断键是否存在，不关心值是不是 0
- 遍历字典时不要删键，过滤用字典推导式
- 嵌套字典用链式 `get(a, {}).get(b, 0)` 安全取值
- 计数优先用 `collections.Counter`
- 字典推导式：`{k: v for k, v in ... if ...}`
