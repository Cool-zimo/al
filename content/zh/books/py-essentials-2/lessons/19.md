# 字符串方法巩固

> 这一课不重新讲概念。它做三件事：**用三十秒回顾要点、纠正最容易犯的三个错、用题目检验你是不是真的会了**。
> 如果你发现回顾部分有任何一句看着陌生，先回去看《学习篇》第 19 课，再回来做题。

## 三十秒速览

```python
s = "  hello, WORLD  "
s.strip()            # "hello, WORLD"           去掉两端空白
s.replace("WORLD", "world")  # "  hello, world  "
s.find("WORLD")      # 3     找不到返回 -1
s.startswith("  he") # True
s.upper()            # "  HELLO, WORLD  "
s.lower()            # "  hello, world  "

s.split(",")         # ['  hello', ' WORLD  ']   按逗号切
"|".join(["a", "b", "c"])  # 'a|b|c'            用 | 拼回去

name = "张三"
f"你好，{name}，成绩是{89.4567:.2f}"   # 你好，张三，成绩是89.46
f"{name:<10}"                          # 左对齐占 10 位
```

| 操作 | 方法 | 常见坑 |
|---|---|---|
| 切分 | `split(",")` | 不传参数时按**任意空白**切，还会合并连续空白 |
| 拼接 | `"sep".join(可迭代)` | 参数只能是一个可迭代对象，不能写多个 |
| 查找 | `find` / `index` | `find` 找不到返回 -1；`index` 找不到抛 `ValueError` |
| 格式化 | `f"{x:.2f}"` / `f"{x:<10}"` | `:.2f` 只作用于浮点数 |

**字符串是不可变的**：所有方法都返回一个**新字符串**，原字符串纹丝不动。

## 最容易错的三件事

### 一、`split()` 不传参数 vs 传参数，行为完全不同

这是 `split` 最容易被误读的一点。

```python
s = "a  b\tc   d"
print(s.split())        # ['a', 'b', 'c', 'd']
print(s.split(" "))     # ['a', '', 'b\tc', '', '', 'd']
```

`split()` 不传参数时，会按**任意空白字符**（空格、换行、制表符）切，并且**自动合并连续空白**。而 `split(" ")` 只按**单个空格**切，多个空格之间会留下空字符串 `''`。

解析结构化文本（日志、成绩单）时几乎总是想要前者：

```python
line = "张三   95   北京"
name, score, city = line.split()
print(name, score, city)   # 张三 95 北京
```

另外 `split` 还有第二个参数 `maxsplit`，限制切几刀：

```python
"a:b:c:d".split(":", 1)   # ['a', 'b:c:d']   只切一刀，剩下整块留下
```

### 二、`join` 的参数是「一个可迭代对象」，不是多个参数

这是调用方式上的错，不是逻辑上的错。

```python
# WRONG
"|".join("a", "b", "c")   # TypeError
```

`join` 只接受一个位置参数，而且这个参数必须是可迭代的（列表、元组、字符串本身都行）。正确写法：

```python
"|".join(["a", "b", "c"])   # 'a|b|c'
"".join(["a", "b", "c"])    # 'abc'         空字符串 join = 拼接
", ".join(["苹果", "香蕉", "橘子"])  # '苹果, 香蕉, 橘子'
```

两个细节：
1. `join` 是**分隔符的方法**，不是列表的方法。记法："让 `|` 这个字符串把大家串起来"，所以是 `"|".join(...)`。
2. `join` 要求**每个元素都是字符串**。列表里混进数字会报错：

```python
",".join([1, 2, 3])       # TypeError: sequence item 0: expected str
",".join(str(x) for x in [1, 2, 3])  # '1,2,3'  用生成器表达式先转
```

### 三、字符串方法不改原值，调用后必须接住返回值

```python
s = "  hello  "
s.strip()         # 返回了新字符串，但没人接
print(s)          # "  hello  "  原值没变！
```

正确写法：

```python
s = "  hello  "
s = s.strip()     # 接住返回值
print(s)          # "hello"
```

`strip` / `replace` / `upper` / `lower` / `split` 全是如此。只有 `list.sort()` 这种列表原地方法才不返回新值——字符串没有"原地修改"这一说。

顺带一提，`strip()` 也可以传参数去掉指定字符，但它是**从两端逐个剥掉字符集里的字符**，不是删子串：

```python
"www.example.com".strip("w")      # '.example.com'
"www.example.com".strip("cmowz.") # 'example'   危险：会一路剥到剥不动为止
```

## 翻车现场：`find` 返回 -1 被当成"找到了"

```python
# WRONG
s = "hello world"
pos = s.find("python")
if pos:                # -1 是"真值"！-1 不是 0，所以这里居然走进了 if
    print("找到了，位置是", pos)
```

```
找到了，位置是 -1
```

`-1` 在 Python 里是真值（`if -1` 为 `True`），所以把 `find` 的结果直接放进 `if` 判断，会在"没找到"时也执行分支。正确写法：

```python
pos = s.find("python")
if pos != -1:          # 显式判断
    print("找到了，位置是", pos)
else:
    print("没找到")

# 更推荐：直接用 in 判断存在性
if "python" in s:
    print("找到了")
```

`-1` 不是 `False`。记住：**判断 find 的结果要用 `!= -1`，或者用 `in` 判断存在、用 `find` 只拿位置**。

## 小结

- `split()` 不传参数按任意空白切并合并连续空白；`split(",")` 只按逗号切
- `join` 只接受一个可迭代参数：`"|".join(list)`，且元素必须全是字符串
- 字符串不可变，所有方法都返回新字符串，记得接住返回值
- `find` 找不到返回 `-1`，判断存在用 `in`，拿位置才用 `find` 并写 `!= -1`
- f-string：`{x:.2f}` 保留两位小数，`{x:<10}` 左对齐占 10 位
