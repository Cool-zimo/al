## 三十秒速览

```python

name, age = "张三", 18

# 第 2 课 输出与输入：print 的 sep/end、input 是字符串、f-string
print(name, age, sep="|", end="!\n")

# 第 3 课 运算与字符串：// % **、切片、负索引、+ *
print(17 // 3, 17 % 3)            # 5 2
s = "python"; print(s[1:4], s[::-1])   # yth nohtyp

# 第 4 课 报错阅读：从下往上看、五个错误类型
# SyntaxError / NameError / TypeError / IndexError / ValueError

# 第 5 课 综合：把它们串起来
score = int(input("输入成绩："))   # 读入并转换
level = "及格" if score >= 60 else "不及格"   # 三元表达式
print(f"{name} 的成绩是 {score}，判定为{level}")
```

综合题的核心技巧是**先拆后写**：把需求拆成"读入 → 处理 → 输出"三步，每一步用前面学过的一个工具。

## 最容易错的三件事

### 一、把"读入多值"和"字符串转数字"两件事顺序搞反

```python
# WRONG：先转换再切分
nums = int(input().split())        # TypeError: int() argument must be a string
```

`split()` 返回的是**列表**（`['3', '5', '7']`），而 `int()` 只能吃**单个字符串**。顺序必须是**先 split 再 int**：

```python
nums = list(map(int, input().split()))   # [3, 5, 7]
a, b, c = map(int, input().split())     # 3, 5, 7
```

### 二、输出格式用 `+` 硬拼，整数没转字符串就报错

```python
# WRONG
print("结果：" + total)          # TypeError: can only concatenate str to str
```

`total` 是整数时，要么 `str(total)`，要么直接用 f-string：

```python
print(f"结果：{total}")          # 自动转换
print("结果：" + str(total))     # 手动转换
```

综合题里最常见的是"一行输出多个数，用空格隔开"：

```python
nums = [3, 5, 7]
print(*nums)              # 3 5 7    print 会自动用空格分隔
print(" ".join(map(str, nums)))   # 3 5 7    手动拼成字符串
```

`print(*nums)` 中的 `*` 是**解包**，把列表拆成一个个参数交给 print。

### 三、边界情况漏想：空输入、单个元素、越界

```python
s = input()               # 用户直接回车 → s = ""
print(s[0])               # IndexError: string index out of range
```

凡是取第一个/最后一个字符、取切片的操作，都要想"如果字符串是空的怎么办"：

```python
s = input()
if s:                    # 空字符串是假值
    print(s[0])
else:
    print("输入为空")
```

同样，除法前要判除数是否为 0，下标前要判是否在范围内。**先处理边界、再写主逻辑**，是写不出 bug 的最有效习惯。

## 翻车现场：一个综合题里的连锁错误

来看一道典型的"成绩单"需求：读入学生姓名和三门课成绩，输出总分、平均分和等级。

```python
# WRONG：三处错误叠在一起
name = input()
a, b, c = input().split()          # 错 1：忘了转 int，a/b/c 是字符串
total = a + b + c                  # 错 2：字符串拼接，不是相加
avg = total / 3
print(name + "的平均分是" + avg)    # 错 3：字符串 + 浮点数 → TypeError
```

**逐个修：**

```python
name = input()
a, b, c = map(int, input().split())   # 修 1：先切再转
total = a + b + c                      # 修 2：现在是整数加法
avg = round(total / 3, 1)
print(f"{name}的平均分是{avg}，总分{total}")   # 修 3：f-string 自动转类型
```

关键观察：**这三个错误彼此独立**，但任何一个都会让程序崩。所以调试时要**从第一个报错往下修**，不要试图一次改完。报错顺序一般是：先做 `a+b+c`（得到 "9095100" 这种怪东西），再 `total/3` 时报 TypeError——因为字符串不能除。修完前两个，第三个才暴露出来。

## 小结

- 综合题拆成"读入 → 处理 → 输出"三步，各用各的工具
- 读多值：`map(int, input().split())`；输出多值：`print(*nums)` 或 `" ".join(...)`
- 整数进字符串：f-string 最省事，省掉手动 `str()`
- 边界情况（空串、除零、越界）先处理，再写主逻辑
- 连锁错误从第一个报错开始修，不要跳着改

exam: true
q: 运行下面代码会报什么错？
code: |
  a, b = input().split()
  print(a * b)
  # 用户输入：3 4
options:
- SyntaxError
- NameError
- TypeError
- 输出 12
answer: 2
explain: input().split() 返回 ['3','4']，所以 a='3'、b='4'。字符串只能和整数做乘法，'3' * '4' 报 TypeError: can't multiply sequence by non-int。若先用 a,b=map(int, input().split()) 转成整数，结果才是 12。这正是最常见的一类"看着对、实际错"的 bug。
