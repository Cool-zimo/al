# 真假规则巩固

> 这一课不重新讲概念。它做三件事：**用三十秒回顾要点、纠正最容易犯的三个错、用题目检验你是不是真的会了**。
> 如果你发现回顾部分有任何一句看着陌生，先回去看《学习篇》第 7 课，再回来做题。

## 三十秒速览

Python 里每个值都自带一个"真假属性"。用在 `if` 条件里时，Python 会把它**自动转换成布尔值**。

```python
if name:            # name 是空字符串吗？不是 → True
    print("有名字")

if age:             # age 是 0 吗？不是 → True
    print("有年龄")
```

**以下这些值在条件里都算"假"**，其余都算"真"：

| 值 | 说明 |
|---|---|
| `False` | 布尔假 |
| `None` | 空值 |
| `0`、`0.0` | 数字零 |
| `""` | 空字符串 |
| `[]`、`()` | 空列表、空元组 |
| `{}` | 空字典 |
| `set()` | 空集合 |

其余全是"真"，包括 `"0"`、`[0]`、`"False"` 这些——**它们虽然"看起来像假的"，但都不是空的**。

```python
if "0":
    print("这个会执行")      # "0" 不是空字符串，是真

if [0]:
    print("这个也会执行")    # [0] 不是空列表，是真
```

## 最容易错的三件事

### 一、以为 `and` / `or` 只返回 `True` / `False`

`and` 和 `or` 的返回值是**其中一个操作数本身**，不是布尔值。

```python
print(3 and 5)         # 5
print(0 and 5)         # 0
print(3 or 5)          # 3
print(0 or 5)          # 5
```

规则：

- `and`：左边为假就返回左边，否则返回右边
- `or`：左边为真就返回左边，否则返回右边

这叫**短路求值**：`and` 一旦发现左边是假，右边根本不计算；`or` 一旦发现左边是真，右边同样跳过。

```python
# 短路：右边不执行，所以 x 不会被改成 999
x = 0
x != 0 and print("x 非零")     # 什么都不打印
```

这个特性常被用来写默认值：

```python
name = input() or "匿名"       # 如果 input() 是空串（假），就用 "匿名"
```

### 二、用 `==` 判断真假，写成 `if x == True`

```python
# 多余：多写了 == True
if x == True:
    print("x 是真")
```

Python 会帮你自动转布尔，所以直接写 `if x:` 就够了。`if x == True:` 不但不必要，还容易写错——比如写成 `if x is True:` 就更严格，只有 `x` 真的是 `True` 这个对象才行，`1` 都通不过。

更危险的是**拿 `[]` 去和 `True`/`False` 比**：

```python
[] == False      # False  ← 空列表不等于 False
[] == True       # False  ← 也不等于 True
bool([])         # False  ← 但转成布尔是假
```

记住：**`==` 是"值相等"，`bool()` 是"转布尔"**，两者不是一回事。要判断"是否为空"，用 `if lst:` 而不是 `if lst == True`。

### 三、`not` 的优先级比你想的低

```python
# WRONG：以为 not 优先级最高
not x == 0       # 实际是 not (x == 0)，等价于 x != 0，结果"碰巧对"
not x in [1,2,3] # 实际是 not (x in [1,2,3])，等价于 x not in [1,2,3]
```

`not` 的优先级**低于比较运算符**（`==`、`in`、`<` 等），但**高于 `and` / `or`**。所以 `not x == 0` 其实是 `not (x == 0)`，结果是对的；但读起来很容易误会。

容易翻车的是 `not` 和 `and` 混用：

```python
not x and y      # 等价于 (not x) and y
not (x and y)    # 这个才是"x 和 y 不同时成立"
```

建议：**只要混用，就加括号**。代码是写给人看的，编译器不会嫌你多写一对括号。

## 翻车现场：`or` 返回值的连锁反应

```python
# WRONG：想判断"用户名或密码是否为空"
username = ""
password = "123"

if username or password == "":      # 本意：两者有一个为空就提示
    print("用户名或密码不能为空")
else:
    print("OK")
```

看起来没问题，但 `username or password == ""` 的解析是：

```python
(username) or (password == "")      # username 是 ""，假；password=="" 是 False
# 结果是 False → 走到 else，打印 "OK"
```

空的用户名没被拦住。问题出在**运算符优先级**：`==` 比 `or` 高，所以实际是 `(username) or (password == "")`。

正确写法要两边都判断：

```python
if username == "" or password == "":
    print("用户名或密码不能为空")
else:
    print("OK")        # 用户名是空串 → 打印"用户名或密码不能为空"
```

或者更简洁：

```python
if not username or not password:    # not 优先级高于 or
    print("用户名或密码不能为空")
```

## 小结

- `False`、`None`、`0`、`0.0`、`""`、`[]`、`()`、`{}`、`set()` 都是假值，其余都是真
- `"0"`、`[0]`、`"False"` 都是真，因为它们不是空的
- `and`/`or` 返回的是操作数本身，且会短路（左边能定胜负就不算右边）
- 别写 `== True` / `== False`，直接用 `if x:` / `if not x:`
- `not` 优先级低于比较运算符，混用时加括号
- `or` 的经典用法：给默认值（`name = input() or "匿名"`）
