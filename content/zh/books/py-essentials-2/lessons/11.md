# 列表巩固

> 这一课不重新讲概念。它做三件事：**用三十秒回顾要点、纠正最容易犯的三个错、用题目检验你是不是真的会了**。
> 这一课对应《学习篇》第 11 课。如果你发现回顾部分有任何一句看着陌生，先回去看《学习篇》第 11 课，再回来做题。

## 三十秒速览

```python
nums = [10, 20, 30, 40, 50]
print(nums[0])     # 10     正索引从 0 开始
print(nums[-1])    # 50     负索引从末尾数，-1 是最后一个
print(nums[1:4])   # [20, 30, 40]   切片含左不含右
print(nums[::2])   # [10, 30, 50]   步长为 2
```

| 操作 | 写法 | 作用 |
|---|---|---|
| 取值 | `a[i]` | 第 i 个元素 |
| 改值 | `a[i] = x` | 原地修改 |
| 追加 | `a.append(x)` | 末尾加一个 |
| 删除 | `del a[i]` | 删指定位置 |
| 判断 | `x in a` | 是否存在 |
| 长度 | `len(a)` | 元素个数 |

列表是**可变的**：改一个位置、增一个、删一个，都是在同一个列表上动手，不会生成新列表。

## 最容易错的三件事

### 一、切片"含左不含右"，边界总是少一个

```python
a = [0, 1, 2, 3, 4, 5]
print(a[1:4])   # [1, 2, 3]   —— 注意：4 不在里面
```

这是 Python 切片最统一的规则：区间左闭右开 `[start, stop)`。`a[1:4]` 取的是位置 1、2、3，正好是 `4 - 1 = 3` 个元素。所以**想取"前 3 个"就写 `a[:3]`**，别写 `a[:2]`。

负索引也是同一个逻辑：

```python
a = [0, 1, 2, 3, 4, 5]
print(a[-3:])    # [3, 4, 5]  倒数 3 个
print(a[:-1])    # [0, 1, 2, 3, 4]  去掉最后一个
```

### 二、`b = a` 不是拷贝，是同一个列表

```python
a = [1, 2, 3]
b = a            # 没有新建列表，只是多贴了一个标签
b.append(4)
print(a)         # [1, 2, 3, 4]   a 也跟着变了
```

`b = a` 之后，`a` 和 `b` 指向**同一个对象**。`id(a) == id(b)` 为 `True`。所以改 `b` 就是改 `a`。

想要一份独立的副本，写法有好几种：

```python
b = a[:]          # 切片拷贝，最直观
b = a.copy()      # 列表自带的方法
b = list(a)       # 用构造函数
```

三种都行。注意：**它们都只是"浅拷贝"**——列表里套着列表时，里面的子列表仍然是同一个对象，这会在后面专门讲。

### 三、`in` 判断的是值，不是位置

```python
nums = [10, 20, 30]
print(20 in nums)    # True
print(15 in nums)    # False
```

`in` 从左到右逐个比较，找到了就返回 `True`。列表越长、要找的值越靠后，平均耗时就越久——**列表的 `in` 是 O(n)**。如果数据量大、又经常要判断"有没有"，就该用集合，那是 O(1)。这是第 15 课的内容，先留个印象。

## 翻车现场：浅拷贝只拷贝一层

```python
# WRONG
a = [[1, 2], [3, 4]]
b = a[:]
b[0].append(99)
print(a)    # [[1, 2, 99], [3, 4]]   a 也被改了
```

```
# 原因不是报错，而是"行为不符合直觉"
# b[0] 和 a[0] 指向的是同一个子列表
```

切片拷贝只复制了**最外层**这一层列表，里面装的那两个 `[1, 2]`、`[3, 4]` 还是原来那两个对象。所以改 `b[0]` 就等于改 `a[0]`。

要连子对象一起复制，用 `copy.deepcopy`：

```python
import copy
a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)
b[0].append(99)
print(a)    # [[1, 2], [3, 4]]   a 没事
print(b)    # [[1, 2, 99], [3, 4]]
```

这一课只要分清"浅拷贝"和"深拷贝"的边界就够了。日常用列表，绝大多数时候浅拷贝（切片或 `copy()`）已经够用；**只有列表里套着可变对象、又需要独立副本时，才上 `deepcopy`**。

## 小结

- 切片左闭右开：`a[1:4]` 取位置 1、2、3
- 负索引从末尾数：`-1` 是最后一个元素
- `b = a` 是别名，不是拷贝；`b = a[:]` 或 `b = a.copy()` 才是新列表
- 浅拷贝只复制一层，嵌套结构要 `copy.deepcopy`
- `in` 对列表是 O(n)，数据量大时要换成集合

  a = [1, 2, 3]

- "[1, 2, 3, 4]"
