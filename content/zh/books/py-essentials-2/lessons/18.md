# 作用域巩固

> 这一课不重新讲概念。它做三件事：**用三十秒回顾要点、纠正最容易犯的三个错、用题目检验你是不是真的会了**。
> 如果你发现回顾部分有任何一句看着陌生，先回去看《学习篇》第 18 课，再回来做题。

## 三十秒速览

```python
x = 10              # 全局变量

def show():
    x = 20          # 局部变量，和全局的 x 不是同一个
    print(x)

show()              # 20
print(x)            # 10
```

| 概念 | 在哪能用 | 关键字 |
|---|---|---|
| 局部变量 | 只在函数内部 | 函数里赋值 |
| 全局变量 | 整个文件 | 函数外赋值 |
| 在函数里改全局变量 | 需要声明 `global` | `global x` |
| 嵌套作用域 | 内层函数 | `nonlocal` |

作用域就是**一个名字在哪一层"看得见"**。函数里新赋值的名字默认是局部的。

## 最容易错的三件事

### 一、在函数里改全局变量忘了 `global`

```python
# WRONG
count = 0

def inc():
    count = count + 1      # 想改全局的 count

inc()
```

```
UnboundLocalError: local variable 'count' referenced before assignment
```

Python 看到函数里**有** `count = ...` 这行赋值，就把 `count` 当成局部变量。于是等号右边的 `count` 还是"还没赋值"的局部变量，炸了。

要改全局的，必须先 `global` 声明：

```python
count = 0

def inc():
    global count           # 我要用的是外面的那个 count
    count = count + 1

inc()
print(count)              # 1
```

**一句话：`=` 赋值到全局变量前，先写 `global`。**

### 二、读全局变量不用 `global`，但改就要

```python
x = 100

def read_x():
    print(x)              # 读可以，不用 global

def change_x():
    global x              # 改必须声明
    x = 200

read_x()                  # 100
change_x()
print(x)                  # 200
```

"读"不用声明，"**改**"（赋值）才需要 `global`。这是新手最容易混的一点。

### 三、函数里改可变参数，外面会跟着变

这和"作用域"不是一回事，但后果经常一起出现。

```python
def add_score(scores, s):
    scores.append(s)

all_scores = [90, 85]
add_score(all_scores, 100)
print(all_scores)          # [90, 85, 100]
```

这里没用到 `global`，只是**传进来的列表是可变对象**，`.append()` 改的是它自己，外面也变了。第 16 课讲过：**作用域管的是"名字"，可变对象管的是"内容"**，别搞混。

## 翻车现场：闭包共享同一个变量

```python
# WRONG
def make_functions():
    fs = []
    for i in range(3):
        def f():
            return i
        fs.append(f)
    return fs

for g in make_functions():
    print(g())             # 猜猜输出什么？
```

很多人以为是 `0 1 2`，其实是 `2 2 2`：三个函数**共享同一个 `i`**，调用时循环已结束，`i` 停在 `2`。

解决办法是用默认参数，默认值在函数定义时就被"冻结"：

```python
def make_functions():
    fs = []
    for i in range(3):
        def f(i=i):        # 把当前 i 的值"刻"进函数
            return i
        fs.append(f)
    return fs

for g in make_functions():
    print(g())             # 0 1 2
```

闭包捕获的是**变量本身**，不是那一刻的值。想"刻住"值，就用默认参数。

## 小结

- 函数里**改**全局变量要 `global`，**读**不用
- `global` 声明要写在赋值之前
- 作用域管"名字"，可变对象管"内容"，别混
- 闭包捕获的是变量本身；想刻住值用默认参数

```quiz
type: function
q: 写 counter()：利用 global 实现一个计数器。第一次调用返回 1，第二次返回 2，第三次返回 3……每次调用加一
func: counter
starter: |
  count = 0

  def counter():
      # 用 global 声明 count，每次加一并返回
      return 0
cases: |
  () -> 1
  () -> 2
  () -> 3
hint: 函数里写 global count，然后 count = count + 1，再 return count。
explain: 每次调用 counter 都要改全局的 count，所以必须 global 声明。先加一再返回，连续调用就会 1、2、3 递增。
```
