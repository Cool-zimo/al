# 别画骗人的图：截断 Y 轴、双轴误导、面积误导、样本量不标

> 同一组数据，画的方式不同，能讲出完全不同的故事。这一节讲四种最常见的视觉误导，以及怎么画才不会骗人。

## 误导一：截断 Y 轴

柱形图的基线不是 0，而是从一个接近最小值的地方开始，差异会被**成倍放大**。

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import pandas as pd

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

sales = pd.DataFrame({
    '门店': ['北京','上海','广州','深圳'],
    '销售额': [320, 310, 300, 295],
})

# 误导版：Y 轴从 280 开始
fig, ax = plt.subplots(figsize=(8, 5))
ax.bar(sales['门店'], sales['销售额'])
ax.set_ylim(280, 340)
ax.set_title('截断 Y 轴：差异看起来巨大')
fig.savefig('trick1.png')

# 诚实版：基线从 0
fig, ax = plt.subplots(figsize=(8, 5))
ax.bar(sales['门店'], sales['销售额'])
ax.set_ylim(0, 350)
ax.set_title('基线归零：差异其实很小')
fig.savefig('honest1.png')
```

数据只差 8%，截断后柱高差三倍。北京看起来"遥遥领先"，实际上和深圳只差 8%。**柱形图基线必须从 0 起**——这是柱形图的硬规则，因为它用高度编码数值，起点动了，编码就失效了。

**折线图是例外**：折线图表达的是"变化趋势"，起点可以不为 0，但要**在标题或注释里说明**。比如气温从 -5℃ 到 5℃，从 0 起会让曲线挤在下方，这时可以截断，但要标注。

## 误导二：双 Y 轴

同一张图左边一个刻度、右边一个刻度，两条线各自用不同的量纲，想让它们"看起来相关"。

```python
# 编造一个"冰淇淋销量与溺水人数同步上升"的假相关
fig, ax1 = plt.subplots(figsize=(8, 5))
months = ['5月','6月','7月','8月','9月']
ice = [10, 25, 60, 80, 40]
drown = [2, 5, 12, 15, 7]

ax1.plot(months, ice, color='orange', marker='o')
ax1.set_ylabel('冰淇淋销量', color='orange')
ax1.set_ylim(0, 100)

ax2 = ax1.twinx()
ax2.plot(months, drown, color='blue', marker='s')
ax2.set_ylabel('溺水人数', color='blue')
ax2.set_ylim(0, 20)

ax1.set_title('双 Y 轴：制造假相关')
fig.savefig('trick2.png')
```

两条线都"从左下到右上"，看起来强相关。**但两者的量纲和刻度范围完全独立，作者可以任意调整让它们重合**。这个例子里，共同原因是"夏天到了"，不是"吃冰淇淋导致溺水"。

**规则：能用分面就别用双轴。** 两个指标各画一张、上下对齐，既不会误导，还能直接比趋势。

```python
fig, axes = plt.subplots(2, 1, sharex=True, figsize=(8, 6))
axes[0].plot(months, ice, color='orange', marker='o')
axes[0].set_title('冰淇淋销量')
axes[1].plot(months, drown, color='blue', marker='s')
axes[1].set_title('溺水人数')
fig.tight_layout()
fig.savefig('honest2.png')
```

**如果必须用双轴**（比如两个指标确实要叠加看），至少做到三点：① 用明显不同的线型和颜色；② 图例明确标注各自对应哪条轴；③ 标题写明"注意量纲不同"。

## 误导三：面积误导

用圆的**面积**表示数值，但人眼对面积的判断天然不准；更糟的是直接拿**直径**当数值，面积就变成平方关系，差异被二次放大。

```python
fig, ax = plt.subplots(figsize=(7, 5))
sizes = [100, 200, 300]
radii = [1, 2, 3]   # WRONG：半径与数值成正比，面积变成 1:4:9
ax.set_title('气泡大小按半径映射（误导）')
fig.savefig('trick3.png')
```

数值 100→300 是三倍，但面积比是 1:9，看起来差九倍。**要让面积正比于数值，半径应取数值的平方根**：

```python
areas = [300, 600, 900]          # 面积正比于数值
radii = [np.sqrt(a) for a in areas]   # 半径取平方根
```

**气泡图里 `sizes` 参数控制的是面积，不是半径**——这是最容易踩的坑。`sns.scatterplot(..., size=..., sizes=(min, max))` 里 seaborn 已经帮你做了平方根映射，直接用就对。

## 误导四：样本量不标

一张对比图，两组样本量差十倍，但柱子上不写 n。这是报告里最高频的隐瞒。

```python
store = pd.DataFrame({
    '门店': ['北京','深圳'],
    '客单价': [185, 172],
    '样本量': [1200, 80],   # 差 15 倍
})

fig, ax = plt.subplots(figsize=(7, 5))
bars = ax.bar(store['门店'], store['客单价'])
for b, n in zip(bars, store['样本量']):
    ax.text(b.get_x() + b.get_width()/2, b.get_height() + 2,
            f'n={n}', ha='center', fontsize=11)
ax.set_title('各门店客单价（标注样本量）')
fig.savefig('honest3.png')
```

深圳 n=80，置信区间宽、波动大，那个"低一点"的结论不可靠。**样本量不平衡时，n 不是脚注，是结论的一部分**。不标样本量的对比图，本质是在隐瞒证据的强弱。

## 骗人图的四条自检清单

| 检查项 | 问自己 |
|---|---|
| 基线 | 柱形图从 0 起了吗 |
| 刻度 | 是不是用了两个独立量纲 |
| 面积 | 面积正比于数值，还是被平方放大了 |
| 样本量 | n 写了吗，证据够不够强 |

**翻车现场：把相关性说成因果性。**

```python
# 冰淇淋销量与溺水人数相关，但这是共同原因（夏季高温）造成的
# 画一张图暗示"吃冰淇淋导致溺水"就是造假
```

即使图本身没做截断、没做双轴，**叙事上的因果暗示也是造假**。图只是证据，结论要写在证据能支撑的边界内。报告中写"两者同步上升，共同原因可能是夏季高温"，而不是"冰淇淋导致溺水"。

## 小结

- 柱形图基线必须从 0 起，否则高度编码失效，差异被放大
- 折线图可截断但要注明；分面优于双轴
- 双轴可任意调刻度制造假相关，必须用则标清量纲
- 面积要正比于数值，半径取平方根；气泡图 `sizes` 控制面积
- 样本量不平衡时 n 必须标，它是结论的一部分
- 即使图没造假，叙事上的因果暗示也是造假
- 四步自检：基线、刻度、面积、样本量
