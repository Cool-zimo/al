# 颜色与样式：colormap、色盲友好与 seaborn 风格

> 配色决定一张图的专业度。这一节讲 colormap 怎么选、怎么避开色盲陷阱，以及用 seaborn 一行换一套风格。

## 颜色不是装饰，是信息的载体

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

months = ['1月','2月','3月','4月','5月','6月']
beijing = [120, 135, 128, 160, 175, 190]
shanghai = [110, 118, 130, 140, 155, 168]
guangzhou = [90, 100, 95, 110, 130, 140]

fig, ax = plt.subplots(figsize=(9, 5))
ax.plot(months, beijing, color='#e41a1c', marker='o', label='北京')
ax.plot(months, shanghai, color='#377eb8', marker='s', label='上海')
ax.plot(months, guangzhou, color='#4daf4a', marker='^', label='广州')
ax.set_title('三门店销售额对比')
ax.legend()
fig.savefig('colors_basic.png')
print('saved')
```

`#e41a1c`、`#377eb8`、`#4daf4a` 这套是 **Set1**，色盲友好、区分度高。

## 翻车现场 1：用红绿做区分

```python
ax.plot(months, beijing, color='red', label='北京')
ax.plot(months, shanghai, color='green', label='上海')     # 红绿对比
```

输出：看起来区分度够——**但红绿色盲（约 8% 男性、0.5% 女性）根本分不清这两条线**。这是最常见的配色错误。

**解法：用色盲友好配色。** matplotlib 内置了几套：

| colormap / 颜色组 | 特点 |
|---|---|
| `tab10` | 默认分类色，色盲友好 |
| `Set1` / `Set2` / `Set3` | 饱和度递减，经典 |
| `Paired` | 成对的色，适合分组 |
| `viridis` / `plasma` / `cividis` | 感知均匀，色盲友好 |

## colormap 的三种用途

**1. 散点图上色（连续映射）：**

```python
rent = np.random.uniform(10, 50, 100)
fig, ax = plt.subplots(figsize=(8, 5))
sc = ax.scatter(area, sales, c=rent, cmap='viridis')
fig.colorbar(sc, ax=ax, label='租金（万元）')
fig.savefig('cmap_continuous.png')
```

**2. 离散类别上色（取 colormap 的几个固定位置）：**

```python
cmap = plt.get_cmap('tab10')        # 取 colormap 对象
colors = [cmap(i) for i in range(3)]   # 取前 3 个颜色
ax.plot(months, beijing, color=colors[0], label='北京')
ax.plot(months, shanghai, color=colors[1], label='上海')
ax.plot(months, guangzhou, color=colors[2], label='广州')
fig.savefig('cmap_discrete.png')
```

`plt.get_cmap('tab10')(i)` 返回 colormap 上第 i 个位置的颜色（RGBA 元组）。**避免手写一堆 hex 的最佳做法。**

## 翻车现场 2：彩虹色 viridis 配离散类别

```python
# WRONG：用连续色带区分几个类别
colors = plt.cm.viridis(np.linspace(0, 1, 3))
# 得到深紫、中绿、浅黄 —— 亮度和饱和度差异大，看起来有"主次"
```

输出：三个类别看起来**有明暗主次**（深紫像重点、浅黄像次要），但类别本应平等。**离散类别要用离散色带（tab10、Set1），连续色带（viridis、coolwarm）只用于有大小关系的数值。**

## 深浅色搭配：背景与文字

```python
fig, ax = plt.subplots(figsize=(9, 5), facecolor='#f5f5f5')     # 画布浅灰背景
ax.set_facecolor('#ffffff')                                      # 坐标系白底
ax.plot(months, beijing, color='#e41a1c', linewidth=2)

ax.tick_params(colors='#333333')        # 刻度字用深灰，别用纯黑
ax.spines['top'].set_visible(False)     # 去掉上边框
ax.spines['right'].set_visible(False)   # 去掉右边框
fig.savefig('clean.png')
```

**去掉上、右边框**是数据新闻（FT、NYT）的标准做法——**数据区域是重点，边框是干扰**。去掉后图立刻显干净。

## seaborn 风格：一行换整套观感

```python
import seaborn as sns

sns.set_theme(style='whitegrid',          # 背景样式
              palette='Set1',             # 默认色板
              font='WenQuanYi Micro Hei', # 字体
              font_scale=1.1)             # 字体缩放

fig, ax = plt.subplots(figsize=(9, 5))
ax.plot(months, beijing, marker='o', label='北京')
ax.plot(months, shanghai, marker='s', label='上海')
ax.set_title('seaborn 风格')
fig.savefig('sns_style.png')
```

`sns.set_theme` **一次性改掉**默认字体、字号、网格、背景色、色板，省掉一堆 rcParams 设置。

**风格选项：**

| `style` | 效果 |
|---|---|
| `'white'` | 白底，无网格 |
| `'dark'` | 深灰底，适合深色背景 |
| `'whitegrid'` | 白底 + 网格（最常用） |
| `'darkgrid'` | 深底 + 网格 |
| `'ticks'` | 只留刻度线，最简洁 |

**翻车现场 3：seaborn 改了全局设置，污染了后续图。**

```python
sns.set_theme(style='dark')       # 全局变深底
# ... 画一张图 ...
fig2, ax2 = plt.subplots()        # 这张也是深底，不是预期的白底
```

输出：所有后续图都变成深底，**难以预期**。解法：用 `with` 局部生效：

```python
with sns.axes_style('darkgrid'):
    fig, ax = plt.subplots()
    ax.plot(months, beijing)
    fig.savefig('dark.png')
# 离开 with 后，风格自动还原
```

## 深浅主题怎么选

| 场景 | 推荐 |
|---|---|
| 打印、报告、PPT | 白底 + 深色数据线（`whitegrid`） |
| 网页、深色模式 | 深底 + 浅色数据线（`darkgrid`） |
| 高密度散点 | 白底 + 低 alpha |

**配色的一致性很重要**：一个报告里同一组数据在不同图上的颜色必须一致（北京永远是红色），否则读者每翻一页都要重新建立对应关系。

## 小结

- 红绿对比是**色盲雷区**，用 Set1/tab10/viridis 等色盲友好色
- colormap 两类用法：**连续映射**用 `c=rent, cmap=`，**离散类别**用 `plt.get_cmap('tab10')(i)`
- 连续色带（viridis）只用于有大小关系的值，别用来区分平等类别
- 专业观感：去上/右边框、刻度字用深灰而非纯黑、给画布加浅灰底
- seaborn：`sns.set_theme(style='whitegrid', palette='Set1')` 一行换全套
- 函数内用 `with sns.axes_style(...)` 局部生效，避免污染全局
