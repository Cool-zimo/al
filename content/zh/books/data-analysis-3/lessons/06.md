# 柱状图 bar / barh：分类对比

> 柱状图是"比大小"的首选：各个门店谁卖得多、哪个月业绩好。这一节讲 `bar` 和 `barh` 的差别，以及类别多了怎么办。

## 什么时候用柱状图

**你要回答的是"哪个类别最大"。** 柱状图的每一根柱子代表一个类别，高度就是数值，人眼一眼就能比出长短。

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

stores = ['北京', '上海', '广州', '深圳', '杭州']
sales = [1280, 1520, 980, 1100, 860]

fig, ax = plt.subplots(figsize=(8, 5))
ax.bar(stores, sales, color='#377eb8')
ax.set_title('五门店 2025 上半年销售额')
ax.set_ylabel('销售额（万元）')
fig.savefig('bar_basic.png')
print('saved')
```

`ax.bar(x, height)`：x 是类别位置（或标签），height 是高度。就这么简单。

## 横向柱状图 barh

**类别名很长、或者类别超过七八个的时候，用横向。**

```python
fig, ax = plt.subplots(figsize=(8, 5))
ax.barh(stores, sales, color='#e41a1c')
ax.set_xlabel('销售额（万元）')
ax.set_title('五门店 2025 上半年销售额')
fig.savefig('barh_basic.png')
```

`barh(y, width)`：y 是类别，width 是长度。**注意参数名从 height 变成了 width**——因为柱子横过来了。

| 纵向 `bar` | 横向 `barh` |
|---|---|
| 类别名短 | 类别名长（"华北区""华南区"） |
| 类别 ≤ 7 个 | 类别 ≥ 8 个，纵向会挤成毛刺 |
| 强调"高低" | 强调"长短排名" |
| x 轴是类别 | y 轴是类别 |

## 翻车现场 1：类别太多挤成毛刺

```python
cities = ['北京', '上海', '广州', '深圳', '杭州', '成都', '武汉',
          '南京', '苏州', '天津', '西安', '长沙', '郑州', '重庆']
vals = [1280, 1520, 980, 1100, 860, 720, 690, 650, 630, 590, 560, 510, 480, 460]

fig, ax = plt.subplots(figsize=(8, 5))
ax.bar(cities, vals)            # 14 个类别挤在 8 英寸宽里
fig.savefig('crowded.png')
```

输出：14 个 x 刻度标签**互相重叠**，糊成一片，根本看不清是哪个城市。`figsize` 没跟着类别数放大是主因。

**解法：换成 barh，或者加大图宽。**

```python
fig, ax = plt.subplots(figsize=(8, 6))
ax.barh(cities, vals)
ax.set_xlabel('销售额（万元）')
fig.savefig('barh_many.png')
```

横向后，每个城市名都有一行自己的空间，互不干扰。

## 参数速查

```python
ax.bar(stores, sales,
       width=0.6,           # 柱子宽度，0~1，越大越粗
       color='#377eb8',     # 填充色
       edgecolor='black',   # 边框色
       linewidth=1,         # 边框线宽
       alpha=0.8)           # 透明度，0 完全透明
```

| 参数 | 作用 |
|---|---|
| `width` | 柱子宽度，默认 0.8 |
| `color` | 填充色 |
| `edgecolor` | 柱子边框色 |
| `linewidth` | 边框粗细 |
| `alpha` | 透明度 0–1 |

## 翻车现场 2：柱子颜色太艳

```python
ax.bar(stores, sales, color='red')     # 正红，刺眼
```

输出：图很"炸"，看久了眼疼。**配色要柔和不刺眼**，用 hex 调低饱和度：`#e41a1c`（柔红）、`#377eb8`（柔蓝）、`#4daf4a`（柔绿）。这是 Set1/Tableau 那套经典配色，色盲友好。

## 分组柱状图：两组以上对比

```python
import numpy as np

stores = ['北京', '上海', '广州', '深圳']
q1 = [620, 710, 480, 550]
q2 = [660, 810, 500, 550]

x = np.arange(len(stores))      # [0, 1, 2, 3]
w = 0.35                        # 每根柱子的宽度

fig, ax = plt.subplots(figsize=(8, 5))
ax.bar(x - w/2, q1, w, label='第一季度')
ax.bar(x + w/2, q2, w, label='第二季度')
ax.set_xticks(x)                # 刻度放在整数位置
ax.set_xticklabels(stores)      # 标签用中文
ax.legend()
ax.set_title('各门店季度销售额对比')
fig.savefig('bar_grouped.png')
```

**关键技巧：`x - w/2` 和 `x + w/2` 把两组柱子错开**，否则会叠在一起。`np.arange(len(stores))` 生成 `[0,1,2,3]` 作为类别坐标。

## 翻车现场 3：错开算错了

```python
# WRONG
ax.bar(x, q1, w, label='第一季度')
ax.bar(x + 1, q2, w, label='第二季度')   # 偏移了 1 个整单位，中间空一大截
```

输出：两组柱子中间**空出很大一段**，而且第二组已经跑到了别的类别上。正确做法是偏移 `w/2`（半个柱宽），刚好贴住。

## 堆叠柱状图

```python
fig, ax = plt.subplots(figsize=(8, 5))
ax.bar(stores, q1, label='第一季度')
ax.bar(stores, q2, bottom=q1, label='第二季度')   # bottom 指定堆叠的基线
ax.legend()
ax.set_title('堆叠：总销售额 = Q1 + Q2')
fig.savefig('bar_stacked.png')
```

`bottom=q1` 让第二季度的柱子**从 Q1 的顶部开始画**，形成堆叠。适合看"总量 + 构成"。

**堆叠 vs 分组怎么选：**

| | 分组 | 堆叠 |
|---|---|---|
| 适合 | 对比各分项的大小 | 看总量 + 构成占比 |
| 缺点 | 柱子多会显挤 | 中间部分难以精确比大小 |
| 典型场景 | "北京和上海谁 Q1 卖得多" | "北京总销售额里 Q1 占多少" |

## 给柱子加数值标注

```python
fig, ax = plt.subplots(figsize=(8, 5))
bars = ax.bar(stores, sales, color='#377eb8')
for bar in bars:
    h = bar.get_height()
    ax.text(bar.get_x() + bar.get_width()/2, h,     # 柱子中心上方
            str(h), ha='center', va='bottom')
ax.set_title('柱子顶部标数值')
fig.savefig('bar_label.png')
```

`bars` 是一个 `BarContainer`，迭代它拿到每根柱子，`bar.get_height()` 拿高度，`bar.get_x()` 拿左边缘位置。**遍历+标注**是柱状图最常用的收尾动作。

## 小结

- 柱状图回答"哪个类别最大"，人眼比长短最快
- `bar` 纵向、`barh` 横向；**类别名长或数量多就用横向**
- 分组：`x ± w/2` 错开；堆叠：`bottom=` 指定基线
- 颜色别用正红正绿，用柔和的 hex 配色
- 给柱子加数值：`bar.get_height()` + `ax.text`
- 柱子宽度默认 0.8，太粗会挤
