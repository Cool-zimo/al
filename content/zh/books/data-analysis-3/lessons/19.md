# 分类图：boxplot / violinplot / barplot / countplot

> 横轴是类别、纵轴是数值时，你要看的不是"每个类别一个数"，而是"每个类别里的分布"。分类图家族就是干这个的。

## 箱线图：boxplot，看中位数与四分位

箱线图把一组数据压缩成五个数：最小值、Q1、中位数、Q3、最大值，并把超出 1.5 倍四分位距的点单独标成离群点。

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

tips = sns.load_dataset('tips')

fig, ax = plt.subplots(figsize=(8, 5))
sns.boxplot(data=tips, x='day', y='total_bill', ax=ax)
ax.set_title('各星期几的账单金额分布')
fig.savefig('box.png')
```

箱子里那条线是**中位数**（不是均值）。箱体上下沿是 Q1 和 Q3，箱体高度（IQR）反映数据的**离散程度**。须线外的点就是离群点——它们值得单独查：是录入错误，还是真的有异常大单。

**翻车现场 1：把箱线图的中位数当成均值。**

```python
tips.groupby('day')['total_bill'].mean()    # 均值
tips.groupby('day')['total_bill'].median()  # 中位数
```

两者数值经常不同。分布偏斜（比如有少数超大账单）时，均值会被拉高，中位数更能代表"典型水平"。**汇报时务必说清你用的是哪个**："各星期几账单中位数为 X"和"平均账单为 X"是两个不同的结论。

## 小提琴图：violinplot，箱线图的升级

箱线图只告诉你四分位，丢失了分布的形状。小提琴图用 KDE 画出密度轮廓，同时保留箱线信息。

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.violinplot(data=tips, x='day', y='total_bill', hue='sex',
               split=True, inner='quart', ax=ax)
ax.set_title('各星期账单分布（按性别分色，小提琴图）')
fig.savefig('violin.png')
```

`split=True` 让两个类别**共用一个宽度**，左右对半，方便直接对比形状。`inner='quart'` 在内部画四分位短线。小提琴最胖的地方是密度峰值——你能一眼看出"这个类别的分布是单峰还是双峰"，这是箱线图给不了的。

**什么时候用哪个？**

| 图 | 信息量 | 适合场景 |
|---|---|---|
| boxplot | 五数概括 + 离群点 | 类别多、只想快速看中位数和离散 |
| violinplot | 完整密度形状 + 四分位 | 类别少（≤5）、想看分布形态 |
| 两者都画 | 既看形态又看离群 | 报告里做对比 |

## 条形图：barplot，默认画均值+置信区间

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.barplot(data=tips, x='day', y='total_bill', hue='sex', ax=ax)
ax.set_title('各星期平均账单金额')
fig.savefig('bar.png')
```

注意：seaborn 的 `barplot` **默认画的是均值**（不是简单计数），柱顶那条小横线是 95% 置信区间。这一点和 `plt.bar` 完全不同——后者只画你给的数值。

**翻车现场 2：想画"各类别有多少条记录"，误用了 barplot。**

```python
# 想看每个星期有几笔交易
sns.barplot(data=tips, x='day', y='total_bill')  # WRONG：画的是平均账单
```

你画出来的柱子高度是"平均账单金额"，不是"笔数"。**要数个数，用 `countplot`**：

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.countplot(data=tips, x='day', ax=ax)
ax.set_title('各星期的交易笔数')
fig.savefig('count.png')
```

`countplot` 只接收一个维度（通常是 x 或 y），它做的事情等价于 `df[x].value_counts()` 然后画柱。

## 带散点的分类图：stripplot 与 swarmplot

光看箱子不够，你想看**原始数据点的位置**，可以叠一层散点。

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.stripplot(data=tips, x='day', y='total_bill', jitter=True,
              alpha=0.5, color='gray', ax=ax)
ax.set_title('带原始数据点的分类图')
fig.savefig('strip.png')
```

`jitter=True` 给点加横向抖动，避免重叠成一条线。`alpha=0.5` 让重叠处颜色加深，直观反映密度。样本量小（几十个）时用 `swarmplot` 做无重叠排布更漂亮；样本量大（几千）时 `swarmplot` 会算得很慢，老实用 `stripplot`。

## 分类图选型表

```python
# 把四种图并排看差异
fig, axes = plt.subplots(2, 2, figsize=(12, 9))
sns.boxplot(data=tips, x='day', y='total_bill', ax=axes[0, 0])
axes[0, 0].set_title('boxplot')
sns.violinplot(data=tips, x='day', y='total_bill', ax=axes[0, 1])
axes[0, 1].set_title('violinplot')
sns.barplot(data=tips, x='day', y='total_bill', ax=axes[1, 0])
axes[1, 0].set_title('barplot（均值）')
sns.countplot(data=tips, x='day', ax=axes[1, 1])
axes[1, 1].set_title('countplot（计数）')
fig.tight_layout()
fig.savefig('compare.png')
```

**翻车现场 3：样本量不平衡时，直接对比均值。**

周六只有 8 笔、周日有 77 笔，用 barplot 画出来的周六均值柱子又高又带一条很窄的置信区间，看起来"非常显著"。**样本量差异大时，置信区间宽度本身就是在警告你"这个数不可靠"**。报告中一定要同时标注样本量（n=8），否则读者会误读。

## 小结

- 箱线图看中位数与四分位，中位数≠均值
- 小提琴图能看到密度形态（单峰/双峰），split 方便对比
- `barplot` 默认画均值+置信区间；数个数用 `countplot`
- 类别多→boxplot，类别少→violinplot
- 叠加 stripplot 可看原始点，样本量大用 jitter
- 样本量不平衡时务必标注 n，避免误读置信区间
