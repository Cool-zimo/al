# 拿到一份脏数据：读取、概览、定清洗策略

> 真实数据从不会干净地递到你手上。这一节讲拿到文件后前 15 分钟该做的事：读进来、看清它、定下清洗策略——顺序错了，后面每一步都是白干。

## 第一步：读进来，别急着分析

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import pandas as pd
import numpy as np

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

# 模拟一份门店导出的脏数据
raw = pd.DataFrame({
    '门店': ['北京', '北京', '上海', None, '广州', '深圳', '北京'],
    '日期': ['2025-01-01', '2025-01-02', '2025/1/3', '2025-01-04',
            '20250105', '2025-01-06', '2025-01-07'],
    '销售额': ['1000', '1,200', '980', '1500', 'nan', '800', '3200元'],
    '客流量': [120, 130, '无记录', 150, 90, 100, 125],
    '渠道': ['线下', '线上', '线上', '线下', '线上', None, '线下'],
})

raw.to_csv('store_raw.csv', index=False, encoding='utf-8-sig')

df = pd.read_csv('store_raw.csv')
print(df.shape)        # (7, 5)
print(df.dtypes)
print(df.head())
```

`pd.read_csv` 的常用参数：

| 参数 | 作用 |
|---|---|
| `encoding` | 中文文件常是 `gbk` 或 `utf-8-sig`，读乱码就换 |
| `dtype` | 指定列类型，避免数字被读成 object |
| `parse_dates` | 指定哪些列解析成日期 |
| `na_values` | 额外标记为缺失的字符串，如 `['无记录','--']` |

**翻车现场 1：编码报错，读不进来。**

```python
# WRONG：中文系统导出的文件经常是 GBK，直接读立刻报错
pd.read_csv('北京门店.csv')
# UnicodeDecodeError: 'utf-8' codec can't decode byte 0xbc ...
```

报错信息已经把答案写给你了——`codec can't decode byte`，说明文件不是 UTF-8。**先换编码再谈别的**，常见顺序：`utf-8` → `utf-8-sig` → `gbk`。`utf-8-sig` 专门对付带 BOM 头（开头三个隐藏字节）的 Windows 文件。

## 第二步：概览，建立数据地图

```python
print('=== 形状 ===')
print(df.shape)                    # (7, 5)
print('\n=== 类型 ===')
print(df.dtypes)
print('\n=== 缺失 ===')
print(df.isna().sum())
print('\n=== 重复 ===')
print('重复行数:', df.duplicated().sum())
print('\n=== 唯一值预览 ===')
for c in df.columns:
    print(c, ':', df[c].unique()[:8])
```

这一步的目标是**建立数据地图**：多少行、哪些列是数字、哪里有缺失、有没有重复、每个字段的合法取值长什么样。四行代码，零成本，却能挡掉绝大多数后续错误。

**翻车现场 2：重复行没发现，聚合时数值翻倍。**

```python
print('去重前:', len(df))
df = df.drop_duplicates()
print('去重后:', len(df))
```

重复行会让求和、均值全部失真。**去重要在计算任何聚合之前做**。但注意：`drop_duplicates()` 只对完全重复的行生效；若某几列相同但其他列不同，那是有效记录，不能删——这种情况要显式指定 `subset=['订单号']` 来判断。

## 第三步：定清洗策略

看着概览结果，列一张清洗清单：

```python
plan = pd.DataFrame([

    ['销售额', '含逗号、单位、缺失', '去符号转数字',    '必做'],
    ['客流量', '混入字符串"无记录"', '转数字，标缺失',   '必做'],
    ['渠道',   '缺失',            '补"未知"',         '待定'],
], columns=['字段', '问题', '处理方式', '优先级'])
print(plan)
```

**翻车现场 3：没定策略就动手，越改越乱。**

边看边改、改完发现前面的假设错了、又回过头改，最后不知道哪一步改了什么。**先列清单、排优先级、再动手**，清洗过程可复现，别人也能看懂。清单的作用不是写报告，而是给自己一个"可以回头检查"的锚点。

## 一份脏数据里最常见的六类问题

| 类型 | 例子 | 处理方式 |
|---|---|---|
| 类型错误 | `'1000'` 是字符串 | `pd.to_numeric` |
| 缺失 | `None`、`nan`、空串 | `fillna` 或删除 |
| 重复 | 完全一样的行 | `drop_duplicates` |
| 格式不一 | `'2025-01-01'` vs `'2025/1/3'` | 统一解析 |
| 混入单位 | `'3200元'`、`'1,200'` | 去符号后转换 |
| 异常值 | 销售额 -5 | 核查后处理 |

```python
# 快速体检函数：一眼看全部问题
def profile(df):
    out = pd.DataFrame({
        '类型': df.dtypes.astype(str),
        '缺失数': df.isna().sum().values,
        '缺失率': (df.isna().mean() * 100).round(1).astype(str) + '%',
        '唯一值数': df.nunique().values,
        '重复行': df.duplicated().sum(),
    })
    return out

print(profile(df))
```

注意 `isna().sum().sum()` 是**两个** `sum()`：第一个对每列求和得到一个 Series，第二个把所有列加总。只写一个 `sum()` 返回的是一列一个数字的 Series，不是总数。

## 小结

- 读文件三步：读进来 → 换编码解决乱码 → 看 shape/dtypes/缺失/重复
- 编码顺序：`utf-8` → `utf-8-sig` → `gbk`
- 去重要在聚合之前，但只对完全重复行删
- 清洗前先列清单、排优先级、再动手，保证可复现
- 常见六类问题：类型、缺失、重复、格式、单位、异常
- profile 函数一键体检，建立数据地图
