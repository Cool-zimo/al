# 分布图：histplot / kdeplot / displot

> 拿到一份数据，第一件事不是画关系图，而是**看它长什么样**。分布图回答的是"这个值出现的频率是多少、密度集中在哪"。

## 直方图：histplot

直方图把一个连续变量切成若干段（bin），数每段里有多少条记录。它是最基础的分布观察工具。

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd
import numpy as np

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

tips = sns.load_dataset('tips')

fig, ax = plt.subplots(figsize=(8, 5))
sns.histplot(data=tips, x='total_bill', bins=20, ax=ax)
ax.set_title('账单金额分布（20 个 bin）')
fig.savefig('hist1.png')
```

`bins=20` 是**段数**。段数越多，柱子越窄，越能看出局部起伏，但也会暴露出样本的随机抖动；段数越少，曲线越平滑，但可能把两个峰压成一个。这不是"越大越好"，而是个需要来回试的参数。

**翻车现场 1：bins 太多，噪声被当成结构。**

```python
fig, ax = plt.subplots()
sns.histplot(data=tips, x='total_bill', bins=60, ax=ax)
ax.set_title('60 个 bin 的账单分布')
fig.savefig('hist2.png')
```

只有 244 条记录的样本被切成 60 段，很多柱子只有 0 或 1 条数据，图看起来像锯齿，你会误以为存在某种周期。**段数至少要保证大多数段里都有数据**，经验值：样本量 n，取 `bins ≈ √n` 到 `n/10` 之间先试，比如 n=244，取 15~25。

## 核密度估计：kdeplot

直方图的问题是对 bin 边界敏感——稍微挪一下边界，形状就变。KDE（核密度估计）用平滑曲线绕开这个问题，适合看**整体的重心和胖瘦**。

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.kdeplot(data=tips, x='total_bill', fill=True, ax=ax)
ax.set_title('账单金额的密度曲线')
fig.savefig('kde.png')
```

`fill=True` 把曲线下方填色，视觉上更接近"面积 = 概率"。KDE 背后有个带宽（bandwidth）参数控制平滑程度，默认用 Scott 或 Silverman 规则自动算，一般不用手调。

**翻车现场 2：把 KDE 和直方图当成互斥选择。**

```python
fig, ax = plt.subplots()
sns.histplot(data=tips, x='total_bill', bins=20, ax=ax)
sns.kdeplot(data=tips, x='total_bill', ax=ax, color='red')   # 重叠画
ax.set_title('直方图 + 密度曲线叠加')
fig.savefig('both.png')
```

这**不是错误写法，而是推荐做法**：直方图给你真实频次，KDE 给你平滑趋势，两者叠加一张图，读图的人同时看到"原始"和"拟合"。seaborn 内部就支持 `histplot(..., kde=True)` 一键叠加。

## 双变量分布：jointplot 与 2D KDE

当你要看两个连续变量的联合分布，单变量的直方图就不够了。

```python
g = sns.jointplot(data=tips, x='total_bill', y='tip', kind='hex')
g.figure.suptitle('账单与小费的联合分布', y=1.02)
g.figure.savefig('joint.png')
```

`kind` 可以是 `scatter`（散点）、`hex`（六边形分箱，点密时用）、`kde`（二维密度等高线，点很多时用）、`reg`（加回归线）。点少用 scatter，点多用 hex 或 kde——这是分析密度图的第一条经验。

## displot：分布图的"总开关"

`displot` 是 Figure-level 函数，一个入口覆盖 hist / kde / ecdf / rug，还能按列分面。

```python
g = sns.displot(
    data=tips, x='total_bill',
    kind='hist', bins=20, kde=True,
    hue='sex', col='time', col_wrap=2,
    height=4, aspect=1.4,
)
g.figure.savefig('displot.png')
```

一行代码做了四件事：直方图、叠加密度曲线、按性别分色、按用餐时段分面成四张小图。对应的 Axes-level 函数是 `histplot` / `kdeplot` / `ecdfplot` / `rugplot`，如果你需要把它塞进自己的 subplots 网格，就用它们。

**翻车现场 3：想给 displot 结果设标题，用错了对象。**

```python
g = sns.displot(data=tips, x='total_bill', kind='hist')
g.set_title('账单分布')          # WRONG：FacetGrid 没有 set_title 方法
g.figure.set_title('账单分布')   # WRONG：Figure 也没有 set_title
g.figure.suptitle('账单分布')    # 正确：suptitle 是 Figure 的方法
```

`displot` 返回的是 `FacetGrid`，不是 Axes。它有自己的方法：`g.set_axis_labels('金额', '频次')`、`g.set_titles('{col_name}')` 用来给每个子图加小标题。要整张大标题，走 `g.figure.suptitle`。

## ECDF：累计分布，不受 bin 影响

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.ecdfplot(data=tips, x='total_bill', hue='sex', ax=ax)
ax.set_title('账单金额的累计分布')
fig.savefig('ecdf.png')
```

ECDF（经验累计分布函数）回答"有多少比例的账单低于某个金额"。纵轴是比例（0 到 1），从左到右单调上升。**看中位数、看分位对比，ECDF 比直方图直接**：两条 ECDF 曲线在某处分离，说明那个分位上两组有差异。

| 图 | 适合回答 | 参数要点 |
|---|---|---|
| histplot | 频数集中在哪 | bins 段数 |
| kdeplot | 平滑的密度形状 | fill=True 填色 |
| ecdfplot | 某分位下占比多少 | 看分位对比 |
| jointplot | 两变量联合分布 | kind=hex/kde/scatter |

## 小结

- 分布图是 EDA 第一步：**先看形状，再看关系**
- 直方图段数 `bins` 不是越大越好，样本小段数多会暴露噪声
- KDE 与直方图叠加是推荐做法，同时给"真实"和"拟合"
- `displot` 是 Figure-level 总开关，返回 FacetGrid，标题用 `g.figure.suptitle`
- ECDF 看分位对比比直方图直接，不受 bin 边界影响
- 点多用 hex / kde，点少用 scatter
