# 保存与导出：savefig 的那些坑

> 画图不是终点，出图才是。这一节讲 `savefig` 的尺寸、dpi、bbox、格式四个维度，让你存出的图不糊、不裁边、不踩坑。

## 最简用法

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

fig, ax = plt.subplots()
ax.plot([1, 2, 3], [1, 2, 3])
ax.set_title('北京门店销售')

fig.savefig('out.png')        # 保存到文件
print('saved')
```

`savefig` 靠**文件扩展名**自动判断格式：`.png` 存 PNG、`.pdf` 存 PDF、`.svg` 存 SVG。不用你显式指定。

## 尺寸：figsize 和 dpi

图片清晰度由两个参数共同决定：

```python
fig, ax = plt.subplots(figsize=(8, 5))    # 画布大小，单位英寸
ax.plot([1, 2, 3], [1, 2, 3])
ax.set_title('北京门店销售')
fig.savefig('out.png', dpi=150)            # 每英寸 150 个像素
```

**最终像素 = figsize × dpi**：

| figsize | dpi | 实际像素 |
|---|---|---|
| (8, 5) | 100 | 800 × 500 |
| (8, 5) | 150 | 1200 × 750 |
| (8, 5) | 300 | 2400 × 1500 |

dpi 是"每英寸点数"。**屏幕/网页用 100–150 够用，印刷/论文要 300。**

## 翻车现场 1：图被标签裁掉

```python
fig, ax = plt.subplots(figsize=(4, 3))      # 画布太小
ax.plot([1, 2, 3], [1, 2, 3])
ax.set_title('北京门店上半年月度销售额详细统计')
ax.set_xlabel('月份（2025 年）')
ax.set_ylabel('销售额（万元，含税）')
fig.savefig('out.png')                      # 标题和 y 轴标签被裁掉
```

输出：图看起来正常，但**标题右侧、y 轴标签左侧被切掉了**。`savefig` 默认按画布边界裁剪，标签太长就会溢出。

**解法：`bbox_inches='tight'`**

```python
fig.savefig('out.png', bbox_inches='tight')
```

这会让 matplotlib **自动计算内容边界**，把标签、标题都包进去。

## 翻车现场 2：只 savefig 不 tight_layout

`bbox_inches='tight'` 是保存时的裁边；`fig.tight_layout()` 是绘图时的自动排版，**两者作用在不同阶段**：

```python
fig, axes = plt.subplots(1, 2)
axes[0].set_title('北京')
axes[1].set_title('上海，2025 年上半年销售额统计')
# 忘记 tight_layout → 两个子图的标题可能互相重叠
fig.savefig('out.png')
```

**正确写法：**

```python
fig.tight_layout()              # 先让子图自动排好
fig.savefig('out.png', bbox_inches='tight')   # 再裁掉多余白边
```

**翻车现场 3：figsize 没设，图太小糊成一团。**

```python
fig, ax = plt.subplots()          # 默认 figsize=(6.4, 4.8)
ax.plot([1, 2, 3], [1, 2, 3])
ax.set_title('北京门店销售')
fig.savefig('out.png', dpi=50)    # dpi 太低，字是锯齿
```

输出：像素约 320×240，文字边缘全是锯齿，放到 PPT 里糊成一片。**网页/报告里插图至少 dpi=100，正式出图 150–300。**

## 格式怎么选

| 格式 | 特点 | 用途 |
|---|---|---|
| **PNG** | 有损/无损位图，支持透明 | 网页、PPT、截图、最终交付 |
| **SVG** | 矢量图，无限放大不糊 | 网页内嵌、要后续用 AI 改图 |
| **PDF** | 矢量图，跨平台 | 论文、打印、投稿 |
| **JPG** | 有损压缩，会出伪影 | **不推荐存图表**（线条会糊） |

**关键区别：PNG 是"像素图"，放大就糊；SVG/PDF 是"矢量图"，放大不糊。**

```python
fig.savefig('chart.png', dpi=150)
fig.savefig('chart.svg')       # 矢量，无 dpi 概念
fig.savefig('chart.pdf')       # 矢量
```

## 透明背景

```python
fig.savefig('chart.png', transparent=True)
```

透明背景适合**叠在深色 PPT 或网页上**。但要注意：透明背景 + 白色字体 = 什么都看不见，配色要一起考虑。

## 别忘了关闭图

matplotlib 的 figure 会一直占内存。循环里画几百张图而不关，会**内存爆掉**：

```python
# WRONG：循环里反复建图不关
for i in range(500):
    fig, ax = plt.subplots()
    ax.plot([1, 2, 3], [1, 2, 3])
    fig.savefig(f'fig_{i}.png')
# 500 个 figure 全在内存里
```

**正确写法：**

```python
for i in range(500):
    fig, ax = plt.subplots()
    ax.plot([1, 2, 3], [1, 2, 3])
    fig.savefig(f'fig_{i}.png')
    plt.close(fig)        # 画完就关，释放内存
```

也可以用 `with` 上下文（matplotlib ≥ 3.5）：

```python
with plt.rc_context({'font.size': 12}):
    fig, ax = plt.subplots()
    ax.plot([1, 2, 3], [1, 2, 3])
    fig.savefig('out.png')
plt.close(fig)            # 用完后关掉
```

## 一个完整的标准套路

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

fig, ax = plt.subplots(figsize=(8, 5))

months = ['1月', '2月', '3月', '4月', '5月', '6月']
sales = [120, 135, 128, 160, 175, 190]
ax.plot(months, sales, marker='o', color='#e41a1c', linewidth=2)

ax.set_title('北京门店上半年销售额')
ax.set_xlabel('月份')
ax.set_ylabel('销售额（万元）')
ax.grid(True, linestyle='--', alpha=0.5)

fig.tight_layout()
fig.savefig('beijing_sales.png', dpi=150, bbox_inches='tight')
plt.close(fig)
print('done')
```

从字体到布局到保存，**这是可以复用的模板**。

## 小结

- `savefig` 靠**扩展名**判断格式，不用显式指定
- 像素 = `figsize × dpi`：网页 100–150，印刷 300
- 标签被裁 → `bbox_inches='tight'`；子图重叠 → `fig.tight_layout()`
- 格式选择：PNG 位图 / SVG PDF 矢量 / **JPG 别用来存图表**
- 循环里画图必须 `plt.close(fig)`，否则内存爆
- `transparent=True` 做透明背景，配深色背景时小心配色
