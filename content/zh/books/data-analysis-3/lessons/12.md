# 标题、轴标签、图例、网格：让图自解释

> 一张图拿给没背景的人看，他能不能看懂？这一节讲"自解释"的四个要素：标题、轴标签、图例、网格。

## 一张"自解释"的图长什么样

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

months = ['1月','2月','3月','4月','5月','6月']
beijing = [120, 135, 128, 160, 175, 190]
shanghai = [110, 118, 130, 140, 155, 168]

fig, ax = plt.subplots(figsize=(9, 5))

ax.plot(months, beijing, marker='o', label='北京')
ax.plot(months, shanghai, marker='s', linestyle='--', label='上海')

ax.set_title('北京 vs 上海：2025 上半年门店销售额', fontsize=14)
ax.set_xlabel('月份')
ax.set_ylabel('销售额（万元）')
ax.legend()
ax.grid(True, linestyle='--', alpha=0.4)

fig.tight_layout()
fig.savefig('self_explained.png')
print('saved')
```

这张图拿给任何人看，都能回答四个问题：**比的是什么（标题）、横轴是什么（xlabel）、纵轴是什么（ylabel）、两条线分别是谁（legend）、格子在哪（grid）**。

## 标题：要写成一句话

**翻车现场 1：标题太短。**

```python
ax.set_title('销售')            # 哪个门店？哪个时间段？哪个指标？
```

输出：看图的人**只能靠猜**。标题应该包含"主体 + 指标 + 时间"三个要素。

**好标题：**

```python
ax.set_title('北京 vs 上海：2025 上半年门店销售额', fontsize=14)
#            主体     对比关系       时间        指标
```

| 要素 | 例子 | 缺了会怎样 |
|---|---|---|
| 主体 | 北京门店 / 两门店对比 | 不知道谁的数据 |
| 指标 | 销售额 / 客单价 | 不知道纵轴是啥 |
| 时间 | 2025 上半年 | 不知道数据的时效 |

`fig.suptitle` 是**整张图的标题**，`ax.set_title` 是单个子图的标题。网格图用 suptitle 做总标题、各子图做分标题。

## 轴标签：必须带单位

```python
ax.set_xlabel('月份')
ax.set_ylabel('销售额（万元）')        # ← 单位是救命的细节
```

**翻车现场 2：忘了写单位。**

```python
ax.set_ylabel('销售额')               # 元？万元？亿元？
ax.set_xlabel('时间')                 # 天？月？季度？
```

输出：读者**无法判断量级**。"销售额"是 100 还是 100 万？这类歧义是报告被退回的常见原因。

**更严谨的写法：**

```python
ax.set_ylabel('销售额 / 万元')         # 用斜杠分隔，一秒看懂
ax.set_xlabel('月份（2025 年）')
```

## 图例：legend 的摆放位置

```python
ax.plot(months, beijing, label='北京')
ax.plot(months, shanghai, label='上海')
ax.legend(loc='upper left')           # 位置
```

`loc` 的可取值：`'best'`（自动选最空的位置）、`'upper left'`、`'upper right'`、`'lower left'`、`'lower right'`、`'center'`。

**翻车现场 3：legend 盖住了数据。**

```python
ax.legend(loc='upper left')           # 北京的数据恰好也在左上角，被盖住
```

输出：图例**压住了关键数据点**。解法：用 `loc='best'` 让 matplotlib 自动找空位，或者手动指定一个不冲突的位置。如果图上实在没空位：

```python
ax.legend(loc='upper center', bbox_to_anchor=(0.5, 1.12),
          ncol=2, frameon=False)
```

`bbox_to_anchor` 把图例**放到图的上方**（y=1.12 在图外），`ncol=2` 排成两列，`frameon=False` 去掉边框——这是报告里最常用的"图例置顶"写法。

## 网格：辅助读数，但别抢戏

```python
ax.grid(True, linestyle='--', alpha=0.4)   # 虚线 + 低透明度
```

网格的作用是**帮读者对齐数值**，但要轻。三个参数：

| 参数 | 推荐值 | 原因 |
|---|---|---|
| `linestyle` | `'--'` 虚线 | 比实线弱，不抢数据 |
| `alpha` | `0.3~0.5` | 淡一点 |
| `color` | `'gray'` | 中性色 |

**翻车现场 4：网格太重。**

```python
ax.grid(True, color='black', linewidth=1.5)    # 黑粗网格，数据被淹没
```

输出：网格线比数据线还醒目，**读者分不清主次**。网格永远要弱于数据。

**只想横向辅助或纵向辅助：**

```python
ax.grid(axis='y', linestyle=':', alpha=0.5)    # 只要横向参考线
ax.grid(axis='x', linestyle=':', alpha=0.5)    # 只要纵向
```

折线图通常只开 `axis='y'` 的水平网格，柱状图也只开横向，让眼睛沿数值方向对齐。

## 一张图搞定所有要素

```python
fig, ax = plt.subplots(figsize=(9, 5))

ax.plot(months, beijing, marker='o', linewidth=2, label='北京')
ax.plot(months, shanghai, marker='s', linestyle='--', linewidth=2, label='上海')

# 标题：主体 + 对比 + 时间 + 指标
ax.set_title('北京 vs 上海：2025 上半年门店销售额', fontsize=14)

# 轴标签带单位
ax.set_xlabel('月份')
ax.set_ylabel('销售额 / 万元')

# 图例
ax.legend(loc='upper left')

# 网格：淡、虚线、只开横向
ax.grid(axis='y', linestyle='--', alpha=0.4)

fig.tight_layout()
fig.savefig('final.png')
```

## 小结

- 好标题 = **主体 + 指标 + 时间**，三个要素齐全
- 轴标签**必须带单位**，写成"销售额 / 万元"最清楚
- 图例：`loc='best'` 自动避让，或 `bbox_to_anchor` 置顶
- 网格要**弱于数据**：虚线 + alpha 0.3~0.5 + 只开一个方向
- `suptitle` 是整张图标题，`set_title` 是子图标题
- 图例没显示？八成是漏了 `label=` 或 `legend()`
