# 为什么还要 seaborn：更省力的统计图

> matplotlib 什么都能画，但画"好看又带统计"的图要写十几行。seaborn 站在 matplotlib 肩膀上，把「聚合、分组、配色、置信区间」打包成一行调用。

## seaborn 解决什么问题

matplotlib 是"画笔画布"，你想画分组柱状图，要自己算均值、自己分组、自己配色、自己写图例。seaborn 是"统计图层"，你只告诉它**用哪一列做 x、哪一列做 y、哪一列做分组**，它自己把聚合、置信区间、配色做完。

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

sales = pd.DataFrame({
    '城市': ['北京','北京','上海','上海','广州','广州'] * 2,
    '季度': ['Q1','Q2'] * 6,
    '销售额': [120,135,110,128,95,105,130,142,118,135,100,112],
})

# matplotlib 写法：要自己 pivot、自己算均值、自己画
pivot = sales.pivot(index='城市', columns='季度', values='销售额')
fig, ax = plt.subplots()
for col in pivot.columns:
    ax.plot(pivot.index, pivot[col], marker='o', label=col)
ax.legend()
ax.set_title('各城市季度销售额（手写版）')
fig.savefig('mpl_way.png')

# seaborn 写法：直接给原始长表，一行出图
fig, ax = plt.subplots()
sns.lineplot(data=sales, x='城市', y='销售额', hue='季度', marker='o', ax=ax)
ax.set_title('各城市季度销售额（seaborn 版）')
fig.savefig('sns_way.png')
```

差别不在代码行数，而在**数据形态**。matplotlib 要你先"算好再画"，seaborn 接受"原始记录"，它内部替你聚合。分析脏数据时你拿到的永远是长表（每一行一笔交易），seaborn 省掉的正是"先 pivot 再画图"这段重复劳动。

## 三层关系：seaborn 是 matplotlib 的上层封装

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.histplot(data=sales, x='销售额', bins=10, ax=ax)   # seaborn 往 ax 里画
ax.set_title('销售额分布')                               # matplotlib 负责修饰
fig.savefig('mixed.png')
```

记住一个判断：**凡是"画什么图形"，用 seaborn；凡是"图形长什么样"，用 matplotlib**。图例、标题、刻度、坐标轴范围，都走 `ax.set_xxx` 和 `plt.rcParams`。混用不会冲突，因为 seaborn 的 `ax=` 参数就是接收 matplotlib 的 Axes 对象。

**翻车现场 1：忘了传 `ax=`，图形跑到了别的画布上。**

```python
fig, ax = plt.subplots()
ax.set_title('这是我要的图')        # 在 ax 上写标题
sns.histplot(data=sales, x='销售额') # WRONG：没传 ax，seaborn 自己新建了一张图
fig.savefig('lost.png')             # 存下来的图没有直方图
```

输出：`fig` 里只有那个空白标题，直方图跑到了 seaborn 偷偷新建的另一个 figure 上。多子图排版时这是最经典的"图不见了"。**只要你在用 subplots，seaborn 调用就一定要带 `ax=`**。

## 风格与配色：一行换皮

seaborn 的颜值来自它的默认主题。切换风格只要一句：

```python
sns.set_theme(style='whitegrid', palette='muted')

tips = sns.load_dataset('tips')
fig, ax = plt.subplots()
sns.scatterplot(data=tips, x='total_bill', y='tip', hue='sex', ax=ax)
ax.set_title('账单与小费的关系')
fig.savefig('styled.png')
```

`style` 控制背景（`whitegrid` 带浅色网格、`ticks` 带刻度短线、`darkgrid` 深色网格），`palette` 控制配色（`muted` 柔和、`deep` 饱和、`colorblind` 色盲友好、`husl` 等间距）。这些配色是**语义化的**，比手写 `#e41a1c` 更稳，因为它会自动给 hue 的每个类别分配一个对比度够的颜色。

**翻车现场 2：`sns.set()` 会全局污染，后面想还原很麻烦。**

```python
sns.set_theme(style='darkgrid')      # 全局生效
# ... 画了十张图 ...
# 现在想恢复 matplotlib 默认，怎么写？
plt.rcParams['axes.facecolor'] = 'white'
plt.rcParams['axes.grid'] = False
# WRONG：得记一堆参数才能还原，容易漏
```

**正确做法：用 `with sns.axes_style(...)` 做临时上下文**，离开缩进自动还原：

```python
with sns.axes_style('darkgrid'):
    fig, ax = plt.subplots()
    sns.histplot(data=tips, x='total_bill', ax=ax)
    fig.savefig('dark.png')
# 这里自动回到外层风格
fig2, ax2 = plt.subplots()
ax2.plot([1,2,3], [1,2,3])   # 用外层默认风格
fig2.savefig('light.png')
```

## 两种接口：Figure-level 与 Axes-level

这是 seaborn 最容易搞混的设计。

| 接口类型 | 代表函数 | 返回什么 | 适合场景 |
|---|---|---|---|
| Axes-level | `sns.scatterplot`、`sns.histplot`、`sns.boxplot` | matplotlib 的 Axes | 多子图排版、嵌进已有画布 |
| Figure-level | `sns.relplot`、`sns.displot`、`sns.catplot` | FacetGrid 对象 | 按某列分面、快速出多子图 |

```python
# Axes-level：我要这个 ax
fig, ax = plt.subplots(figsize=(7, 5))
sns.scatterplot(data=tips, x='total_bill', y='tip', hue='sex', ax=ax)
ax.set_title('一笔交易里的两个变量')

# Figure-level：我自己管整张图
g = sns.relplot(
    data=tips, x='total_bill', y='tip', hue='sex', col='time',
    kind='scatter', height=4, aspect=1.2,
)
g.fig.suptitle('按用餐时段分面', y=1.02)
g.savefig('facet.png')
```

**翻车现场 3：把 Figure-level 函数当 Axes-level 用，想传 `ax=` 传不进去。**

```python
fig, ax = plt.subplots()
sns.relplot(data=tips, x='total_bill', y='tip', hue='sex', ax=ax)
# TypeError: relplot() got an unexpected keyword argument 'ax'
```

`relplot` 不接受 `ax`，因为它**自己创建整张 figure**。判断规则：`relplot`/`displot`/`catplot` 这三个名字里带"plot"但不是具体图形的，都是 Figure-level。你没法把它们塞进别人的子图网格。要做分面，就用它们；要做嵌入，就用对应的 Axes-level 版本（`scatterplot`/`histplot`/`boxplot`）。

**对应关系速查：`relplot` 的 `kind='scatter'` ≈ `scatterplot`，`displot` 的 `kind='hist'` ≈ `histplot`，`catplot` 的 `kind='box'` ≈ `boxplot`**。

## 小结

- seaborn 站在 matplotlib 之上：**画图形用 seaborn，改样式用 matplotlib**
- 给原始长表、指定 `x/y/hue`，它内部替你聚合，省掉 pivot
- 多子图场景**必须传 `ax=`**，否则图跑到别处
- 风格用 `sns.set_theme()` 全局、`with sns.axes_style()` 临时
- Figure-level（`relplot`/`displot`/`catplot`）自己管 figure，不接受 `ax`
