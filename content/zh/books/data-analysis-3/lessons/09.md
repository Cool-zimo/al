# 直方图与箱线图：看分布、看异常

> 均值只能告诉你"中心在哪"，分布图才告诉你"数据长什么样"。这一节讲直方图 `hist` 和箱线图 `boxplot`——两个看分布的利器。

## 直方图：数据落在哪个区间

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

np.random.seed(42)
prices = np.random.normal(500, 100, 1000)     # 1000 件商品价格，均值 500

fig, ax = plt.subplots(figsize=(8, 5))
ax.hist(prices, bins=30, color='#377eb8', edgecolor='white')
ax.set_xlabel('价格（元）')
ax.set_ylabel('数量')
ax.set_title('商品价格分布')
fig.savefig('hist_basic.png')
print('saved')
```

`ax.hist(x, bins=30)` 把 x 切成 30 个等宽区间（bin），统计每个区间里有多少个数。

## bins 怎么选

**这是直方图最容易翻车的地方。** bins 太少看不出形状，太多全是噪声：

```python
fig, axes = plt.subplots(1, 3, figsize=(15, 4))
for ax, b in zip(axes, [5, 30, 100]):
    ax.hist(prices, bins=b, color='#377eb8', edgecolor='white')
    ax.set_title(f'bins={b}')
fig.savefig('bins_compare.png')
```

| bins | 效果 |
|---|---|
| 太少（5） | 形状被抹平，细节全丢 |
| 适中（30） | 正态分布的双肩清晰可见 |
| 太多（100） | 每个 bin 只有几个点，像噪声 |

**经验值：数据量 n 时，bins 取 `int(np.sqrt(n))` 到 `int(n/10)` 之间。** 1000 个点取 30 左右是合理起点，再根据形状微调。

## 翻车现场 1：bins 边界导致柱高怪异

```python
x = [1, 1, 1, 1, 1, 5, 5, 5, 5, 5]      # 只有 1 和 5 两个值
ax.hist(x, bins=10)                        # 切成 10 个 bin
```

输出：10 个 bin 里只有 2 个有数据，**中间 8 根空柱子**，图看起来全是空白。离散取值的数据不该用直方图，用柱状图（`bar`）按取值分组更合适。

## 密度图：和概率密度对齐

```python
ax.hist(prices, bins=30, density=True, color='#377eb8', alpha=0.6)
ax.set_ylabel('密度')
```

`density=True` 让柱子的总面积等于 1，可以直接和概率密度曲线叠在一起比较：

```python
import scipy.stats as stats
mu, sd = np.mean(prices), np.std(prices)
xs = np.linspace(prices.min(), prices.max(), 200)
ax.plot(xs, stats.norm.pdf(xs, mu, sd), color='#e41a1c', linewidth=2, label='正态拟合')
ax.legend()
```

**密度图和拟合曲线叠放**，是检验"数据是否接近正态"的常用手法。

## 箱线图：五数概括

```python
np.random.seed(42)
store_a = np.random.normal(120, 20, 200)
store_b = np.random.normal(140, 30, 200)
store_c = np.random.normal(110, 15, 200)

fig, ax = plt.subplots(figsize=(8, 5))
ax.boxplot([store_a, store_b, store_c], labels=['北京', '上海', '广州'])
ax.set_ylabel('日销售额（万元）')
ax.set_title('三门店销售额分布对比')
fig.savefig('boxplot_basic.png')
```

箱线图画出五个关键数：

| 元素 | 含义 |
|---|---|
| 箱子下沿 | 第 25 百分位（Q1） |
| 箱子中间线 | 中位数（Q2） |
| 箱子下沿 | 第 75 百分位（Q3） |
| 须线末端 | 通常 Q1−1.5·IQR 到 Q3+1.5·IQR |
| 须线外的小圆点 | **离群值（异常值）** |

## 翻车现场 2：离群值主导，箱子压成一条线

```python
data = [10, 11, 12, 13, 14, 15, 16, 17, 18, 500]     # 500 是离群值
ax.boxplot(data)
```

输出：箱子被压得很小，须线拉得很长，**中间那条中位数线几乎看不见**。这是离群值在拉扯须线，箱线图的好处恰恰就是**让它无所遁形**。

## 翻车现场 3：两个量级差 100 倍的组放一起

```python
ax.boxplot([store_a, store_big])      # store_big 均值是 store_a 的 100 倍
```

输出：第一个箱子**细成一条缝贴在 x 轴**，第二个箱子正常。**量级差太多要先取对数或归一化再画箱线图。**

## 水平箱线图

```python
ax.boxplot([store_a, store_b], vert=False, labels=['北京', '上海'])
```

`vert=False` 让箱子横过来，类别名在 y 轴，适合**类别名长**的情况（和 barh 同理）。

## 小提琴图：箱线图 + 密度

```python
ax.violinplot([store_a, store_b, store_c], showmeans=True)
ax.set_xticks([1, 2, 3])
ax.set_xticklabels(['北京', '上海', '广州'])
```

小提琴图**兼具箱线图的统计量和密度图的形状**，能看出分布是单峰还是双峰。中间窄两头宽说明中间密集。

## 直方图 vs 箱线图怎么选

| | 直方图 | 箱线图 |
|---|---|---|
| 回答 | 形状如何（偏态？双峰？） | 中心和中位数是多少，有没有异常 |
| 优点 | 形状细节丰富 | 一图多看几个组，异常值醒目 |
| 缺点 | 多组对比时堆叠难读 | 丢失形状细节 |
| 典型场景 | 看单组数据分布 | 对比 3 组以上 |

## 小结

- 直方图看**分布形状**，箱线图看**五数概括 + 异常值**
- bins 是关键：太少抹平、太多成噪声，经验取 `√n` 到 `n/10`
- 离散取值数据用 `bar` 而不是 `hist`
- 离群值会让箱子被压成线——这是箱线图在"报警"，不是 bug
- 量级差太多要先取对数或归一化
- 要多看形状用小提琴图 `violinplot`
