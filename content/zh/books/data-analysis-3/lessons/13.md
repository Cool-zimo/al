# 标注与参考线：annotate、axhline、axvline

> 一张图最想让观众记住的，往往只是一个点。这一节讲怎么把"关键发现"用箭头、文字和参考线标出来。

## 标出关键点：annotate

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

months = ['1月','2月','3月','4月','5月','6月']
sales = [120, 135, 128, 160, 175, 190]

fig, ax = plt.subplots(figsize=(9, 5))
ax.plot(months, sales, marker='o', color='#e41a1c', linewidth=2)

# 标出最高点
ax.annotate('上半年峰值：190 万元',
            xy=('6月', 190),            # 箭头指向的点
            xytext=('3月', 205),        # 文字放的位置
            arrowprops=dict(arrowstyle='->', color='#e41a1c', lw=1.5),
            fontsize=11, color='#e41a1c')

ax.set_title('北京门店 2025 上半年销售额')
ax.set_xlabel('月份')
ax.set_ylabel('销售额（万元）')
ax.grid(axis='y', linestyle='--', alpha=0.4)
fig.savefig('annotate_basic.png')
print('saved')
```

`annotate` 三个要素：**指向哪（`xy`）、文字在哪（`xytext`）、箭头长什么样（`arrowprops`）**。

## 翻车现场 1：xytext 和 xy 太近

```python
ax.annotate('峰值', xy=('6月', 190), xytext=('6月', 192))    # 文字紧贴数据点
```

输出：文字和数据点**重叠在一起**，根本看不清。`xytext` 要留出足够空间，通常往上偏 10%~20%。

## 箭头样式

```python
arrowprops=dict(arrowstyle='->',    # 箭头形状：->  ->  -|  <->
                color='#e41a1c',
                lw=1.5,             # 线宽
                connectionstyle='arc3,rad=0.2')   # 弧形连线
```

`connectionstyle='arc3,rad=0.2'` 让箭头**走弧线**，当两点之间有其他元素挡住直线时很有用。

## 参考线：axhline 与 axvline

```python
fig, ax = plt.subplots(figsize=(9, 5))
ax.plot(months, sales, marker='o', color='#377eb8', linewidth=2)

# 横向参考线：全年目标
ax.axhline(y=150, color='#e41a1c', linestyle='--', linewidth=1.5, label='全年月均目标 150 万')

# 纵向参考线：某个时间点
ax.axvline(x=2, color='#4daf4a', linestyle=':', linewidth=1.5, label='Q1 结束')

ax.set_title('销售额 vs 目标线')
ax.set_xlabel('月份')
ax.set_ylabel('销售额（万元）')
ax.legend()
fig.savefig('ref_lines.png')
```

| 方法 | 方向 | 参数 |
|---|---|---|
| `axhline(y=150)` | 横向（定值） | y 位置 |
| `axvline(x=2)` | 纵向（定值） | x 位置 |
| `axline((x0,y0), (x1,y1))` | 任意两点连线 | 两个点 |

**翻车现场 2：axhline 写成 plt.axhline 后坐标对不上。**

```python
plt.axhline(y=150)          # 状态机模式：画在当前 figure 的当前 axes 上
```

输出：如果你有多个子图，`plt.axhline` **只画在最后一个 axes 上**，其余子图没有参考线。用面向对象写法就不会有这个问题。

## 用 annotate 在参考线旁加文字

参考线本身没有文字说明，需要配合 `annotate`：

```python
ax.axhline(y=150, color='#e41a1c', linestyle='--', linewidth=1.5)
ax.annotate('月均目标 150 万',
            xy=(5, 150),
            xytext=(5, 158),
            fontsize=10, color='#e41a1c',
            arrowprops=dict(arrowstyle='->', color='#e41a1c'))
```

**参考线 + 标注**是"达标/不达标"分析的标配组合。

## 在数据点上方标数值

```python
fig, ax = plt.subplots(figsize=(9, 5))
bars = ax.bar(months, sales, color='#377eb8')
for bar in bars:
    h = bar.get_height()
    ax.text(bar.get_x() + bar.get_width()/2, h,
            str(h), ha='center', va='bottom', fontsize=9)
ax.set_title('柱子顶部标数值')
fig.savefig('bar_text.png')
```

`ax.text(x, y, s)` 在指定坐标写字。柱子顶部标数值是柱状图最常见的收尾。

**翻车现场 3：文字超出图的范围被裁。**

```python
ax.text(0, 210, '最高值', fontsize=12)     # y=210 超出当前 y 轴范围
```

输出：文字**被裁掉，看不到**。解法：`ax.set_ylim` 留出顶部空间：

```python
ax.set_ylim(0, 230)         # 给顶部留出 40 的空档
```

## 标注区间：axvspan / axhspan

```python
# 给"促销季"一个背景色块
ax.axvspan(3, 5, alpha=0.15, color='#ff7f00')
ax.text(4, 195, '618 促销季', ha='center', fontsize=10, color='#ff7f00')
```

`axvspan(xmin, xmax)` 给一段区间**铺背景色**，适合标注"活动期""节假日""异常时段"。配合文字说明，一眼就知道那段时间和别的时候不一样。

## 多重点标注怎么排

一张图上标 3 个以上点时，**箭头不要交叉**：

```python
peaks = [('6月', 190), ('4月', 160)]
offsets = [('3月', 205), ('1月', 175)]       # 文字位置交替上下
for (x, y), (tx, ty) in zip(peaks, offsets):
    ax.annotate(f'{y} 万元', xy=(x, y), xytext=(tx, ty),
                arrowprops=dict(arrowstyle='->', color='#e41a1c', lw=1.2),
                fontsize=10, color='#e41a1c')
```

文字位置**上下交替**，避免箭头互相穿过，也避免扎堆在图的一侧。

## 小结

- `annotate(xy=指向点, xytext=文字位置, arrowprops=箭头样式)` 三要素
- 参考线：`axhline`（横向定值）、`axvline`（纵向定值）、`axvspan`（区间背景）
- `ax.text(x, y, s)` 在坐标处写字，记得 `set_ylim` 留顶部空间
- 参考线没有文字说明时，配合 annotate 补一句
- 多标注时**文字上下交替**，避免箭头交叉
- 多子图时用面向对象写法，别用 `plt.axhline`
