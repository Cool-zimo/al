# 多子图 subplots：布局、共享坐标轴与紧凑排版

> 一个 figure 里排多张图，是报告的标准形态。这一节讲 `subplots` 的三种排法、共享坐标轴、以及 `tight_layout` 怎么用。

## subplots 的三种基本排法

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

months = ['1月','2月','3月','4月','5月','6月']

# 1) 一行多列
fig, axes = plt.subplots(1, 3, figsize=(15, 4))

# 2) 一列多行
fig, axes = plt.subplots(3, 1, figsize=(6, 12))

# 3) 网格
fig, axes = plt.subplots(2, 2, figsize=(10, 8))
```

`plt.subplots(nrows, ncols)` 返回一个元组：`(fig, axes)`，其中 `axes` 是 NumPy 数组。

## 索引方式

```python
fig, axes = plt.subplots(2, 2, figsize=(10, 8))

axes[0, 0].plot(months, [120,135,128,160,175,190])
axes[0, 0].set_title('北京')

axes[0, 1].plot(months, [110,118,130,140,155,168])
axes[0, 1].set_title('上海')

axes[1, 0].bar(months, [90,100,95,110,130,140])
axes[1, 0].set_title('广州')

axes[1, 1].scatter([1,2,3,4,5], [2,3,5,7,11])
axes[1, 1].set_title('深圳')

fig.tight_layout()
fig.savefig('grid.png')
```

**翻车现场 1：只有 1 行或 1 列时 axes 不是二维的。**

```python
fig, axes = plt.subplots(1, 3)      # 一行三列
axes[0].plot(...)                    # 正确：一维
axes[0, 0].plot(...)                # WRONG：IndexError，一维数组不能双下标
```

输出：`IndexError: too many indices for array`。`1×N` 和 `N×1` 的 axes 是**一维数组**，`N×M`（N>1, M>1）才是二维。

**统一写法：用 `axes.flat` 或提前 reshape。**

```python
for i, ax in enumerate(axes.flat):
    ax.plot(months, sales_list[i])
    ax.set_title(cities[i])
```

`axes.flat` 把任意维度的数组**展平成迭代器**，一维二维都能用。

## 共享坐标轴：省掉重复刻度

```python
fig, axes = plt.subplots(2, 1, sharex=True, figsize=(8, 6))

axes[0].plot(months, [120,135,128,160,175,190])
axes[0].set_title('北京')

axes[1].plot(months, [110,118,130,140,155,168])
axes[1].set_title('上海')

fig.tight_layout()
fig.savefig('sharex.png')
```

`sharex=True`：**上下两张图共享 x 轴刻度**，只保留最下面一张的刻度标签，上面那张不显示。好处是**去掉重复信息、纵向对齐**，方便对比两条曲线的走势。

**什么时候该共享？**

| 场景 | 该共享吗 |
|---|---|
| 对比同一时间段的两条线 | ✅ sharex |
| 同一指标在不同门店 | ✅ sharey（或 sharex） |
| 完全不同的指标 | ❌ 别共享，会误导 |
| 类别不同 | ❌ 共享会让刻度错位 |

## 翻车现场 2：共享了却不该共享

```python
fig, axes = plt.subplots(2, 1, sharey=True)
axes[0].bar(['北京','上海','广州'], [100,200,150])
axes[1].bar(['苹果','香蕉','橘子'], [10,20,15])      # 不同类别！
```

输出：两张图的 y 轴被强制对齐到同一刻度，**第二张的柱子被压得很矮**，视觉上暗示"第二组数值小"，其实只是量程不同。共享 y 轴只在两组数据的**量纲和范围相近**时有意义。

## 不规则布局：GridSpec

想做"上面一张大图、下面两张小图"这种布局，用 `GridSpec`：

```python
from matplotlib.gridspec import GridSpec

fig = plt.figure(figsize=(10, 8))
gs = GridSpec(2, 2, figure=fig)           # 2 行 2 列

ax1 = fig.add_subplot(gs[0, :])           # 第 0 行，横跨两列（大图）
ax2 = fig.add_subplot(gs[1, 0])           # 第 1 行第 0 列
ax3 = fig.add_subplot(gs[1, 1])           # 第 1 行第 1 列

ax1.plot(months, [120,135,128,160,175,190])
ax1.set_title('全国总览（横跨两列）')

ax2.bar(months, [90,100,95,110,130,140])
ax2.set_title('华南')

ax3.scatter([1,2,3,4,5], [2,3,5,7,11])
ax3.set_title('华东')

fig.tight_layout()
fig.savefig('gridspec.png')
```

`gs[0, :]` 表示第 0 行整行，`gs[1, 0]` 是单个格子。切片语法和 NumPy 一样灵活。

## tight_layout 与 constrained_layout

```python
fig, axes = plt.subplots(2, 2)
# ... 画图 ...
fig.tight_layout()              # 自动调整子图间距，避免重叠
```

`tight_layout` 在所有绘图**完成之后**调用，自动计算子图之间的间距，防止标题和刻度互相重叠。

**翻车现场 3：tight_layout 之后再画图。**

```python
fig, axes = plt.subplots(2, 2)
fig.tight_layout()              # 先调了
axes[0, 0].plot(...)
axes[0, 1].set_title('这是一个非常非常非常非常长的标题')
# 标题溢出，因为 tight_layout 算的时候图还是空的
```

输出：长标题**溢出到相邻子图**。因为 `tight_layout` 是在当时（图还是空的）算的，后面新增的内容它不知道。

**正确写法：**

```python
fig, axes = plt.subplots(2, 2)
axes[0, 0].plot(...)
axes[0, 1].set_title('这是一个非常非常非常非常长的标题')
# ... 所有绘图完成 ...
fig.tight_layout()              # 最后再调
```

也可以在创建时直接开启 `constrained_layout=True`（matplotlib ≥ 3.4），它会**持续自动调整**：

```python
fig, axes = plt.subplots(2, 2, constrained_layout=True)
```

## 设置整张图的标题：suptitle

```python
fig.suptitle('北京门店 2025 上半年经营分析', fontsize=14, fontweight='bold')
```

`fig.suptitle` 是**整张画布**的标题，和各子图的 `set_title` 不冲突。`tight_layout` 默认会给它留位置，但如果标题特别长，可能还需要 `fig.tight_layout(rect=[0, 0, 1, 0.96])` 把顶部留白扩大。

## 小结

- `plt.subplots(nrows, ncols)` 返回 `(fig, axes)`
- 1 行/1 列时 axes 是**一维**，网格时是二维；统一用 `axes.flat` 迭代
- 共享坐标轴：`sharex=True`/`sharey=True`，只在量纲相近时有意义
- 不规则布局用 `GridSpec`，切片语法和 NumPy 一样
- `tight_layout()` 要在**所有绘图完成之后**调用
- 整张图标题用 `fig.suptitle`
