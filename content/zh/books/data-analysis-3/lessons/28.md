# 分组洞察：找出真正有意思的结论

> 数据读完、洗干净之后，真正的功夫才开始：怎么分组、怎么聚合、怎么排序，把一堆数字变成"北京门店的客单价比上海高 18%"这样一句能讲给老板听的话。

## 分组的第一步：先想清楚"按什么切"

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import pandas as pd
import numpy as np

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

# 模拟一份门店月度销售数据
df = pd.DataFrame({
    '门店': ['北京']*4 + ['上海']*4 + ['广州']*4 + ['深圳']*4,
    '月份': ['1月','2月','3月','4月']*4,
    '渠道': ['线下','线上','线下','线上','线下','线上','线下','线上',
            '线下','线上','线下','线上','线下','线上','线下','线上'],
    '销售额': [3200,4100,3300,4300,2800,3900,2900,4000,
              2100,2600,2200,2700,2400,3100,2500,3200],
    '订单数': [120,180,125,190,100,160,105,165,
              80,120,85,125,90,140,95,145],
    '客流量': [300,450,310,470,260,400,270,420,
             200,300,210,320,230,350,240,360],
})

print(df.head())
print('共', len(df), '行')
```

分组前必须先回答一个问题：**我想比较谁和谁？** 是按门店比规模、按渠道比效率、还是按月份看趋势？分组字段就是这个"谁"。选错了分组字段，后面算出来的均值再精确也是废的。

**翻车现场 1：忘了去重，用明细行直接 groupby。**

```python
# WRONG：明细表里一行是一个 SKU，按门店分组求和会重复计算订单
detail = pd.DataFrame({
    '订单号': ['A001','A001','A002','A002'],
    '门店': ['北京','北京','上海','上海'],
    '商品': ['咖啡','蛋糕','咖啡','蛋糕'],
    '金额': [30, 20, 30, 20],
})
print(detail.groupby('门店')['金额'].sum())
# 北京 50, 上海 50 —— 看起来两店一样，实际是两笔订单各 50 元
```

明细粒度 vs 聚合粒度搞错，是新手最常见的错误。每个订单有两行（两件商品），按门店求和得到的是"所有 SKU 金额合计"，而不是"每店订单总额"。正确做法是先按订单去重汇总：`detail.groupby('订单号').agg(订单额=('金额','sum'))`，再按门店聚合。

## 分组 + 聚合：一次算出多个指标

```python
# 单分组，多指标
g = df.groupby('门店').agg(
    销售额合计=('销售额','sum'),
    订单数合计=('订单数','sum'),
    客流量合计=('客流量','sum'),
    平均单笔=('销售额','mean'),
    月份数=('月份','count'),
)
g['客单价'] = (g['销售额合计']/g['订单数合计']).round(1)
g['转化率%'] = (g['订单数合计']/g['客流量合计']*100).round(1)
print(g.sort_values('销售额合计', ascending=False))
```

`agg` 里可以同时放多个聚合函数，语法是 `新列名=(原列名, 函数)`。`'sum'`、`'mean'`、`'count'` 是字符串简写，`'nunique'` 也算一个。这样一次分组就能把"规模 + 效率 + 转化"三类指标全算出来，不用反复写 `groupby`。

**翻车现场 2：agg 里混用列，报错看不懂。**

```python
# WRONG：给同一列套了两个函数，但键名重复
try:
    df.groupby('门店').agg(['sum','mean'])
except Exception as e:
    print('报错:', repr(e)[:80])
# TypeError: ... 列名重复，agg 不知道新列叫什么
```

用列表 `["sum","mean"]` 这种写法，Pandas 会把聚合函数名当列名，多个函数作用于多列时立刻撞车。正确做法是**用字典或元组显式起名**：`agg(销售额合计=('销售额','sum'), 销售额均值=('销售额','mean'))`，每个结果都有独立列名。

## 多维度交叉：二维表看差异

```python
# 门店 × 渠道 的交叉销售额
cross = df.pivot_table(
    index='门店', columns='渠道', values='销售额', aggfunc='sum', fill_value=0)
print(cross)

# 再加一层：每个格子显示客单价
cross2 = df.pivot_table(
    index='门店', columns='渠道',
    values=['销售额','订单数'], aggfunc='sum', fill_value=0)
print(cross2)
```

`pivot_table` 就是"二维分组"。行是一个维度（门店），列是另一个维度（渠道），中间是聚合值。交叉表的意义在于**它天然把"差异"摆在你眼前**：哪个格子大、哪个格子小，一眼可见。这是找结论最快的工具，没有之一。

注意 `fill_value=0` 不能省——默认缺失值是 `NaN`，后面参与除法会得到 `NaN`，整列报废。

## 排序找 Top / Bottom：结论从比较中来

```python
# 按销售额排序，找 Top3 和 Bottom3
s = df.groupby('门店')['销售额'].sum().sort_values(ascending=False)
print('Top3:', list(s.head(3).index))
print('Bottom3:', list(s.tail(3).index))

# 差距有多大？算比值和差值
top, bot = s.iloc[0], s.iloc[-1]
print(f'最强 {s.index[0]} 是最弱 {s.index[-1]} 的 {top/bot:.2f} 倍')
```

排序的目的不是"把数排整齐"，而是**制造比较**。只报均值看不出问题，报"最高是最低的 1.6 倍"才有故事。Top/Bottom 要成对出现：只讲最好的会显得自夸，只讲最差的会显得丧气，两者并列才是客观分析。

## 把"差异"翻译成"故事"

```python
# 算相对差距，用百分比表达
base = g['销售额合计']
best = base.max()
g['相对最强%'] = ((base/best - 1)*100).round(1)
print(g[['销售额合计','客单价','转化率%','相对最强%']])
```

原始数据说"北京 14900、上海 13600"，故事版本说"**北京以 9.6% 的优势领先上海，且客单价高出 12%**"。差别在于：原始数据是给机器看的，故事是给决策人看的。翻译三件套：**找主角（谁最强/最弱）、算差距（倍数或百分比）、给原因（结合其他指标解释）**。

```python
# 自动生成一句结论
row = g.sort_values('销售额合计', ascending=False).iloc[0]
print(f"结论：{row.name}店销售额最高（{row['销售额合计']}元），"
      f"客单价 {row['客单价']} 元，转化率 {row['转化率%']}%，"
      f"是表现最好的门店。")
```

## 小结

- 分组前先想清楚"按什么切"，分组字段决定结论的边界
- 明细粒度 vs 聚合粒度必须分清，去重后再聚合
- `agg` 用 `新列名=(原列名,函数)` 显式起名，一次算多指标
- `pivot_table` 做二维交叉，天然暴露差异
- Top/Bottom 成对出现，差距用倍数或百分比表达
- 故事 = 主角 + 差距 + 原因，三件套缺一不可
