# 散点图 scatter：两个变量的关系与第三维映射

> 散点图看的是"两个变量怎么一起变"。`scatter` 比 `plot` 强在能给每个点独立上色、调大小——把第三、第四个维度塞进同一张图。

## scatter 的基本用法

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

np.random.seed(42)
area = np.random.uniform(50, 200, 100)        # 门店面积（平米）
sales = area * 5 + np.random.normal(0, 80, 100)  # 销售额，与面积正相关

fig, ax = plt.subplots(figsize=(8, 5))
ax.scatter(area, sales, color='#377eb8', alpha=0.6)
ax.set_xlabel('门店面积（㎡）')
ax.set_ylabel('月销售额（万元）')
ax.set_title('门店面积 vs 月销售额')
fig.savefig('scatter_basic.png')
print('saved')
```

`ax.scatter(x, y)` 和 `ax.plot(x, y, 'o')` 都能画点，区别在哪？

| | `plot(..., 'o')` | `scatter` |
|---|---|---|
| 每个点独立颜色 | ❌ 只能统一 | ✅ 可以传数组 |
| 每个点独立大小 | ❌ | ✅ 可以传数组 |
| 数据量大 | 快 | 慢 |
| 支持 colormap | ❌ | ✅ |

**数据量大（上万点）用 `plot`；需要颜色/大小映射用 `scatter`。**

## 翻车现场 1：点重叠成一片黑

```python
x = np.random.normal(0, 1, 2000)
y = x + np.random.normal(0, 0.5, 2000)

fig, ax = plt.subplots()
ax.scatter(x, y, color='black')          # 2000 个黑点叠成一片黑
fig.savefig('overlap.png')
```

输出：中间浓成一团黑，看不出密度分布。`alpha=0.3` 是解法：

```python
ax.scatter(x, y, color='#377eb8', alpha=0.3, s=20)
```

透明度叠加后，**颜色越深的地方点越密**，密度分布一目了然。

## 用颜色映射第三维

```python
rent = np.random.uniform(10, 50, 100)      # 租金（万元/月），第三维

fig, ax = plt.subplots(figsize=(8, 5))
sc = ax.scatter(area, sales, c=rent, cmap='viridis',
                alpha=0.7, s=50)
fig.colorbar(sc, ax=ax, label='月租金（万元）')
ax.set_xlabel('门店面积（㎡）')
ax.set_ylabel('月销售额（万元）')
ax.set_title('面积 vs 销售额，颜色=租金')
fig.savefig('scatter_color.png')
```

- `c=rent`：把租金数组映射成颜色
- `cmap='viridis'`：指定色带
- `fig.colorbar(sc, ...)`：**必须有**，否则颜色没有刻度意义
- `s=50`：点的大小

**一张图塞进了三个变量：x、y、颜色。** 这是散点图最强大的地方。

## 常用 colormap

| cmap | 特点 | 适用 |
|---|---|---|
| `viridis` | 感知均匀，色盲友好 | **默认推荐** |
| `plasma` | 高对比 | 强调极值 |
| `coolwarm` | 蓝-白-红，有中心零点 | **有正负的数据**（温度偏差、涨跌幅） |
| `RdYlGn` | 红-黄-绿 | 好坏分级 |
| `coolwarm_r` | 加 `_r` 反转方向 | 想反过来映射 |

**翻车现场 2：有正负的数据用了单色带。**

```python
deviation = np.array([-5, -2, 0, 3, 8])     # 有正有负
ax.scatter(x, y, c=deviation, cmap='viridis')   # 负数和正数都从紫到黄，0 是绿色，看不出"过零"
```

输出：0 和正负值都在色带上，**没有明显的"中点"参照**，读者看不出哪边是负。正确用 `coolwarm` 这类**有中心零点的双色带**，0 是白色，红绿分明。

## 用大小映射第四维

```python
staff = np.random.randint(3, 30, 100)        # 员工数，第四维

fig, ax = plt.subplots(figsize=(8, 5))
sc = ax.scatter(area, sales, c=rent, cmap='viridis',
                s=staff * 10, alpha=0.6)
fig.colorbar(sc, ax=ax, label='月租金（万元）')
ax.set_xlabel('门店面积（㎡）')
ax.set_ylabel('月销售额（万元）')
ax.set_title('面积 vs 销售额（颜色=租金，大小=员工数）')
fig.savefig('scatter_4d.png')
```

`s=staff * 10` 把员工数映射成点的大小（默认 s=36，所以要乘个系数放大到可见）。

**翻车现场 3：点的大小差异太大。**

```python
s = np.array([1, 1, 1, 1, 500])      # 有极端值
ax.scatter(x, y, s=s)                 # 一个点巨大，其余看不见
```

输出：一个点占了半张图，其余的点小到看不见。**映射前要先做归一化或取对数**：

```python
import numpy as np
s_norm = (staff - staff.min()) / (staff.max() - staff.min()) * 200 + 20   # 压到 20-220
ax.scatter(area, sales, s=s_norm)
```

## 边缘密度图（快看一眼分布）

`scatter` 之外，想快速看两个变量的密度：

```python
fig, ax = plt.subplots(figsize=(8, 5))
hb = ax.hexbin(area, sales, gridsize=20, cmap='viridis')
fig.colorbar(hb, ax=ax, label='点数')
ax.set_title('六边形密度图（hexbin）')
fig.savefig('hexbin.png')
```

`hexbin` 把平面切成六边形格子，按格子里的点数上色，**上万点也能一眼看出密度核心**，比 scatter 快得多。

## 小结

- 散点图看两个变量的关系；`scatter` 支持**每个点独立颜色和大小**
- 大数据量（上万点）用 `plot` 或 `hexbin`；要映射第三维用 `scatter`
- 点重叠 → `alpha` 透明叠加看密度
- 颜色映射：`c=` + `cmap=` + **`colorbar` 三件套**
- 有正负的数据用双色带 `coolwarm`，别用单色带
- 点大小差异大 → 先归一化再映射
