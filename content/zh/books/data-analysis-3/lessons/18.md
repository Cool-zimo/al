# 关系图：relplot / scatterplot / lineplot 与 hue 分组

> "两个变量之间有关系吗"是数据分析里问得最多的问题。seaborn 的关系图把"画点画线"和"按组着色"合成一个动作，一行就能看出组间差异。

## 散点图：scatterplot

散点图看两个连续变量的关系：正相关、负相关、无关系、或者某种曲线关系。

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

tips = sns.load_dataset('tips')

fig, ax = plt.subplots(figsize=(8, 5))
sns.scatterplot(data=tips, x='total_bill', y='tip', ax=ax)
ax.set_title('账单金额与小费：基本正相关')
fig.savefig('scatter1.png')
```

点大致从左下到右上，说明账单越贵、小费越高，这是最朴素的正相关形态。但散点图**只能给直觉，不能给结论**——要看相关系数还得算。

## hue：一行代码分成两组看

想加上"性别"这个维度，不用画两次，只要给 `hue`：

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.scatterplot(data=tips, x='total_bill', y='tip', hue='sex', ax=ax)
ax.set_title('按性别分色')
fig.savefig('scatter2.png')
```

`hue` 会自动给每个类别分配一个颜色，并在图里加图例。这比手写两次 `ax.scatter` 然后 `ax.legend()` 省事得多，因为配色和图例都是它管的。

**翻车现场 1：类别太多，颜色区分不开。**

```python
fig, ax = plt.subplots()
sns.scatterplot(data=tips, x='total_bill', y='tip', hue='size', ax=ax)
# size 有 1~6 共 6 个类别，靠颜色分辨很吃力
```

`hue` 适合 **3~6 个类别**。类别再多（比如按"顾客姓名"分组，几十个），颜色分不出来，反而制造混乱。**类别超过 8 个，考虑改用分面（col=）或者干脆放弃在这张图上对比。**

## 第三个维度：size 与 style

点的**大小**和**形状**也能映射变量，最多把四个维度塞进一张散点图。

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.scatterplot(
    data=tips, x='total_bill', y='tip',
    hue='day', style='time', size='size',
    sizes=(30, 200), ax=ax,
)
ax.set_title('颜色=星期 形状=时段 大小=人数')
fig.savefig('scatter3.png')
```

- `hue` 映射颜色
- `size` 映射点的大小，`sizes=(min, max)` 控制范围，避免点大得盖住别的
- `style` 映射点的形状（圆圈、叉号、三角）

**翻车现场 2：size 映射了一个连续变量但范围没限制。**

```python
sns.scatterplot(data=tips, x='total_bill', y='tip', size='tip', sizes=(10, 1000))
# 小费最大 10 元、最小 1 元，点的大小差 900 倍，大的完全盖住别的
```

`sizes` 的范围要**贴合数据量级**。小费才 1~10 元，最大最小点差 10 倍就够了，设到 1000 纯粹是视觉灾难。一般取 `(30, 300)` 这类温和区间。

## lineplot：带置信区间的趋势线

折线图不止是"把点连起来"。seaborn 的 `lineplot` 在你有多个观测值时，**自动算均值并画出置信区间带**。

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.lineplot(data=tips, x='size', y='total_bill', hue='sex', marker='o', ax=ax)
ax.set_title('不同人数下的平均账单金额')
fig.savefig('line1.png')
```

`tips` 里每个 size 都有很多笔交易，`lineplot` 自动算该 size 下 total_bill 的均值连成线，周围那条半透明带是 95% 置信区间。**这条带是 lineplot 和 plt.plot 的本质区别**——后者只是连线，看不出"这个位置的均值稳不稳"。

**翻车现场 3：数据没有重复观测，置信区间带消失或报错。**

```python
single = pd.DataFrame({'x':[1,2,3,4,5], 'y':[2,4,6,8,10]})
fig, ax = plt.subplots()
sns.lineplot(data=single, x='x', y='y', ax=ax)
# 每个 x 只有一个观测，无法计算置信区间，只有一条线
```

每个 x 值只有一个观测时，置信区间**无从计算**，只有一条孤零零的线。这不是 bug，是提醒你：**lineplot 的置信区间要求"同一 x 有多条记录"**。若你的数据就是这种形态，改用 `marker='o'` 明确标出数据点，或者接受"这里没有区间"。

## relplot：一行出多张关系图

`relplot` 是 Figure-level 的关系图入口，`kind` 切 scatter 和 line。

```python
g = sns.relplot(
    data=tips, x='total_bill', y='tip',
    hue='sex', col='time', row='smoker',
    kind='scatter', height=4, aspect=1.2,
)
g.figure.savefig('relplot.png')
```

`col='time'` 按列分面、`row='smoker'` 按行分面，2×2 共四张小图一次出来。这是**"控制变量后看关系"**的标准手法：先按时段和是否吸烟分层，再看账单与小费的关系是否还成立。

## 关系图能看出什么、看不出什么

```python
# 相关性强 ≠ 因果
fig, ax = plt.subplots(figsize=(8, 5))
sns.scatterplot(data=tips, x='total_bill', y='tip', hue='sex', ax=ax)
ax.set_title('账单与小费：相关，但不是因果')
fig.savefig('corr_only.png')
```

账单越高小费越高，但这是**共同原因（消费水平）**驱动的，不是"账单贵导致小费高"。**散点图只能给相关性的线索，因果要靠实验设计或领域知识**。这是关系图最重要的使用边界。

## 小结

- `scatterplot` 看两变量关系形态，`hue` 一行分色
- `hue` 适合 3~6 个类别，超过 8 个改用分面
- `size` 映射点大小，`sizes` 范围要贴合数据量级
- `lineplot` 自动算均值+95% 置信区间带，是它与 plt.plot 的本质区别
- 同一 x 只有一条观测时置信区间算不出来，只有孤线
- `relplot(kind='scatter'/'line')` 是 Figure-level 总入口
- 关系图只给相关性线索，**不能推因果**
