# 画第一条线：plot、marker、linestyle、color

> 折线图是数据可视化里最常用的图。这一节讲透 `plot` 的四个核心参数，让你一条线能画出所有想要的样式。

## 最简折线

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

months = ['1月', '2月', '3月', '4月', '5月', '6月']
sales = [120, 135, 128, 160, 175, 190]

fig, ax = plt.subplots()
ax.plot(months, sales)
ax.set_title('北京门店上半年销售额')
ax.set_xlabel('月份')
ax.set_ylabel('销售额（万元）')
fig.savefig('line_basic.png')
print('saved')
```

`ax.plot(x, y)` 只传两个列表就能出图。**注意 x 是字符串列表时，matplotlib 会按顺序排成类别刻度**，和 pandas 的 Category 行为类似。

## 四个核心参数

```python
ax.plot(x, y,
        marker='o',        # 每个数据点的标记形状
        linestyle='--',    # 线的样式
        color='#e41a1c',   # 颜色
        linewidth=2)       # 线宽
```

| 参数 | 作用 | 常用取值 |
|---|---|---|
| `marker` | 数据点标记 | `o`（圆）`s`（方）`^`（三角）`D`（菱形）`.`（点）`None` |
| `linestyle` | 线型 | `-`（实线）`--`（虚线）`-.`（点划）`:`（点线） |
| `color` | 颜色 | 颜色名、`#rrggbb`、简写 |
| `linewidth` | 线宽 | 数字，默认 1.5 |

## marker：让点看得见

数据点少的时候（比如只有 6 个月），**纯直线看不出每个点的位置**，加 marker 立刻清晰：

```python
fig, ax = plt.subplots()
ax.plot(months, sales, marker='o', color='#377eb8', linewidth=2)
ax.set_title('加 marker 后每个月的数值点清晰可见')
fig.savefig('line_marker.png')
```

常见 marker 一览：

| marker | 形状 | 适用场景 |
|---|---|---|
| `o` | 圆 | 最通用 |
| `s` | 方块 | 类别较少时 |
| `^` `v` `<` `>` | 三角 | 强调方向 |
| `D` | 菱形 | 强调单个关键点 |
| `.` | 小点 | 数据点极多时（上千个点） |

**翻车现场：marker 太多导致变成一团黑。**

```python
import numpy as np

x = np.linspace(0, 10, 500)
y = np.sin(x)

fig, ax = plt.subplots()
ax.plot(x, y, marker='o')          # 500 个圆圈，重叠成一片黑
fig.savefig('mess.png')
```

500 个 marker 全部画出来，互相重叠，图形变成一团黑。**数据点超过一两百个时就别用 marker 了**，或者 `markevery=10` 每隔 10 个画一个。

## linestyle 简写

`linestyle` 可以缩写成 `ls`，值也能用单字符：

```python
ax.plot(x, y, ls='-')    # 实线（默认）
ax.plot(x, y, ls='--')   # 虚线
ax.plot(x, y, ls='-.')   # 点划线
ax.plot(x, y, ls=':')    # 点线
```

**两根线要对比时，用不同线型比用不同颜色更稳妥**——因为打印成黑白后颜色区分会消失，线型还在。这是科研绘图的基本功。

## color 简写

颜色可以用单个字符缩写：

```python
ax.plot(x, y, color='b')   # blue
ax.plot(x, y, color='r')   # red
ax.plot(x, y, color='g')   # green
ax.plot(x, y, color='k')   # black
ax.plot(x, y, color='c')   # cyan
ax.plot(x, y, color='m')   # magenta
ax.plot(x, y, color='y')   # yellow
ax.plot(x, y, color='w')   # white
```

也可以直接用十六进制：`#e41a1c`、`#377eb8`。**推荐用 hex**，因为它能精确复现品牌色或论文配色，而 `'r'` 这种没法微调。

## 一个字符串写完全部样式

matplotlib 支持 `fmt` 格式串，把颜色、marker、线型写在一个字符串里：

```python
ax.plot(x, y, 'bo--')     # 蓝色(b) 圆圈(o) 虚线(--)
ax.plot(x, y, 'r^-')      # 红色(r) 三角(^) 点线(:)  —— 注意点线是 :
```

**翻车现场：fmt 和关键字参数冲突。**

```python
ax.plot(x, y, 'bo--', color='red')     # 警告：color 会被忽略
```

输出：会打印一条 `UserWarning: Attempted to set non-positive bottom...` 或更常见的 `Warning: color is redundantly defined`，实际颜色取 `fmt` 里的 `'b'`（蓝色），你写的 `red` 被无视。**同一个属性不要两处都指定**。

## 一条图里画多条线

```python
fig, ax = plt.subplots()

beijing = [120, 135, 128, 160, 175, 190]
shanghai = [110, 118, 130, 140, 155, 168]

ax.plot(months, beijing, marker='o', label='北京')
ax.plot(months, shanghai, marker='s', linestyle='--', label='上海')
ax.set_title('两门店上半年销售额对比')
ax.legend()                  # 必须有 legend()，label 才会显示
fig.savefig('two_lines.png')
```

**没有 `ax.legend()`，`label=` 写了也白写。** 这是最常见的漏项。

## 小结

- `ax.plot(x, y, marker, linestyle, color, linewidth)` 四个核心参数
- marker 让点可见，**但数据量太大时要关掉或降采样**，否则一团黑
- 对比图优先用**不同线型**（黑白打印后仍有区分）
- 颜色推荐 hex 精确值，少用单字符简写
- `fmt` 字符串和关键字参数**不要重复指定同一个属性**
- 多条线配 `label=` + `ax.legend()`，后者不能漏
