# 实战：一份可交付的分析图表页

> 把前 24 节串成一件完整的东西：一页 A4 能装下的分析页，三张图各讲一个结论，配一段结论文字。这是你能交给别人的东西。

## 一份图表页的骨架

一张可交付的图表页（dashboard page）由四部分组成：

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd
import numpy as np

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

# 构造一份"门店销售"数据
np.random.seed(42)
stores = ['北京','上海','广州','深圳']
data = pd.DataFrame({
    '门店': np.random.choice(stores, 240),
    '月份': np.random.choice(['1月','2月','3月','4月','5月','6月'], 240),
    '渠道': np.random.choice(['线上','线下'], 240, p=[0.6, 0.4]),
    '销售额': np.random.randint(50, 500, 240),
    '客单价': np.random.randint(80, 300, 240),
})
```

| 区域 | 内容 | 占比 |
|---|---|---|
| 顶部 | 总标题（分析主题） | 10% |
| 左侧 | 核心结论文字（3 条） | 35% |
| 右侧 | 三张图（分布 / 趋势 / 对比） | 55% |

## 布局：GridSpec 做不规则排版

```python
fig = plt.figure(figsize=(14, 9))
fig.suptitle('上海门店 2025 上半年销售分析', fontsize=17, fontweight='bold', y=0.98)

gs = fig.add_gridspec(3, 2, hspace=0.4, wspace=0.3,
                      left=0.07, right=0.97, top=0.90, bottom=0.06)

# 上方跨两列：各月趋势
ax_trend = fig.add_subplot(gs[0, :])
# 下方左侧：销售额分布
ax_dist = fig.add_subplot(gs[1, 0])
# 下方右中：各门店对比
ax_comp = fig.add_subplot(gs[1, 1])
# 最下方：渠道占比
ax_ch = fig.add_subplot(gs[2, :])
```

`left/right/top/bottom` 控制整张画布的留白边距，`hspace`/`wspace` 控制子图间距。上面一行横贯两列，下面各放一张小图，这是分析页的经典骨架。

## 三张图各讲一个结论

```python
# 图 1：各月销售额趋势 —— 结论：5、6 月明显回升
month_order = ['1月','2月','3月','4月','5月','6月']
trend = data.groupby('月份', observed=True)['销售额'].mean().reindex(month_order)
ax_trend.plot(month_order, trend.values, marker='o', linewidth=2.5, color='#4C72B0')
ax_trend.fill_between(month_order, trend.values, alpha=0.15, color='#4C72B0')
ax_trend.set_title('各月平均销售额（5、6 月回升）', fontsize=12, loc='left')
ax_trend.set_ylabel('销售额（元）')
ax_trend.spines['top'].set_visible(False)
ax_trend.spines['right'].set_visible(False)
ax_trend.grid(axis='y', alpha=0.3)
ax_trend.set_axisbelow(True)

# 图 2：销售额分布 —— 结论：集中在 150~300 元区间
sns.histplot(data, x='销售额', bins=20, kde=True, ax=ax_dist, color='#55A868')
ax_dist.set_title('销售额分布（集中在 150~300 元）', fontsize=12, loc='left')
ax_dist.spines['top'].set_visible(False)
ax_dist.spines['right'].set_visible(False)

# 图 3：各门店对比 —— 结论：北京、深圳领先
comp = data.groupby('门店', observed=True)['销售额'].mean().reindex(stores)
bars = ax_comp.bar(comp.index, comp.values, color='#C44E52')
ax_comp.set_title('各门店平均销售额（北京、深圳领先）', fontsize=12, loc='left')
ax_comp.set_ylabel('销售额（元）')
for b in bars:
    ax_comp.text(b.get_x()+b.get_width()/2, b.get_height()+3,
                 f'{b.get_height():.0f}', ha='center', fontsize=9)
ax_comp.spines['top'].set_visible(False)
ax_comp.spines['right'].set_visible(False)

# 图 4：渠道占比 —— 结论：线上占比超六成
ch = data.groupby('渠道', observed=True).size()
ax_ch.bar(ch.index, ch.values, color=['#8172B2','#CCB974'])
ax_ch.set_title('订单渠道占比（线上超六成）', fontsize=12, loc='left')
for i, v in enumerate(ch.values):
    ax_ch.text(i, v+3, f'{v} 单（{v/len(data)*100:.0f}%）', ha='center')
ax_ch.spines['top'].set_visible(False)
ax_ch.spines['right'].set_visible(False)

fig.savefig('dashboard.png', dpi=150)
plt.close(fig)
print('saved')
```

每张图的标题都写成一句话结论，而不是"销售额图"。**读图的人扫一眼标题就知道这张图要说什么**。

## 配色：整页统一取色

一页里的颜色不能随便取，要用同一套色板：

```python
palette = sns.color_palette('muted')
# 主色 #4C72B0 用于趋势
# 次色 #55A868 用于分布
# 强调色 #C44E52 用于对比
# 中性色 #8172B2 用于占比
```

**翻车现场 1：每张图用一套随机配色。**

蓝、绿、红、紫各来一遍，整页像彩虹，没有任何视觉逻辑。读者会以为颜色在编码什么信息，其实只是随手选的。**同页用同一套 palette，需要强调时用饱和度更高的色**。

## 结论文字：三条，每条带证据

```text
核心结论：
① 5、6 月平均销售额回升约 15%，暑期旺季效应明显；
② 销售额集中在 150~300 元区间，长尾订单（>400 元）占比不足 5%；
③ 北京、深圳两店领先，但样本量仅 60 单，差异显著性待验证。
```

**翻车现场 2：结论不带证据。**

"北京店表现很好"——好到什么程度？数据是多少？n 是多少？**结论必须能指回图上的具体数值**，否则只是印象。

**翻车现场 3：把局限性藏起来。**

"差异显著性待验证"这句话必须写。只报"北京领先"而不提 n=60，读者可能据此做资源决策，这是专业性的缺口。**局限不是示弱，是告诉别人这个结论能用到什么程度**。

## 小结

- 可交付图表页四部分：总标题、结论文字、三张图、局限说明
- GridSpec 做不规则排版：上方横贯趋势，下方分列对比
- 每张图标题写结论，不是写"XX 图"
- 配色整页统一取同一套 palette，强调色唯一
- 结论必须带数据、带 n，局限必须写明
- dpi=150、bbox_inches='tight'，保证交付清晰度
