# figure 与 axes：画布和坐标系

> 只写 `plt.plot(x, y)` 也能出图，但你要画多子图、调标题、存不同尺寸，就必须懂 figure 和 axes。这一节一次讲清两套 API。

## 两个概念

- **Figure（画布）**：一整张纸，一个文件、一张图。可以只有一个坐标系，也可以切成 2×2 的格子。
- **Axes（坐标系）**：画布上的一块**绘图区域**，包含 x 轴、y 轴、刻度、数据。`plot` 最终画在 Axes 上。

注意名字容易混：`Axes` 是**一个**坐标系（不是复数的坐标轴 axes），而 `Axis` 才是 x 轴或 y 轴。

## 写法一：plt 接口（"状态机"）

`plt.plot` 会找到"当前这张图、当前这个坐标系"往上画，不显式声明。

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

months = ['1月', '2月', '3月', '4月', '5月', '6月']
sales = [120, 135, 128, 160, 175, 190]

plt.plot(months, sales)
plt.title('北京门店上半年销售额')
plt.xlabel('月份')
plt.ylabel('销售额（万元）')
plt.savefig('sales.png')
print('saved')
```

这套写法**上手快、写起来短**，适合临时看一眼数据。

## 写法二：面向对象（显式拿到对象）

```python
fig, ax = plt.subplots()          # fig 是画布，ax 是坐标系

ax.plot(months, sales)
ax.set_title('北京门店上半年销售额')
ax.set_xlabel('月份')
ax.set_ylabel('销售额（万元）')
fig.savefig('sales2.png')
```

`plt.subplots()` 不带参数时返回一个 `(fig, ax)` 元组。关键区别：**你手里握着 `ax` 这个对象**，后面所有操作都点在这个对象上。

## 为什么推荐面向对象

**翻车现场 1：画多张图时状态被串了。**

```python
# WRONG：状态机模式下画两张图，第二张会"继承"第一张的设置
plt.plot([1, 2, 3], [1, 2, 3])
plt.title('第一张')              # 以为这是第一张的标题
plt.savefig('fig1.png')         # 实际保存的是"第一张+第二张"叠在一起

plt.plot([1, 2, 3], [3, 2, 1])
plt.title('第二张')
plt.savefig('fig2.png')         # 这张也会带上第一张的线！
```

输出：两张图**都包含两组数据**，`fig2.png` 上标题写着"第二张"却有四条线。原因是 `plt` 接口一直在用**同一个当前 figure**，除非你显式 `plt.figure()` 新建。

**正确写法：**

```python
fig1, ax1 = plt.subplots()
ax1.plot([1, 2, 3], [1, 2, 3])
ax1.set_title('第一张')
fig1.savefig('fig1.png')

fig2, ax2 = plt.subplots()
ax2.plot([1, 2, 3], [3, 2, 1])
ax2.set_title('第二张')
fig2.savefig('fig2.png')
```

每个 `fig` 是独立的画布，绝不串味。

## plt.xxx 和 ax.xxx 的对照

绝大多数 `plt.xxx` 都有对应的 `ax.set_xxx` / `ax.xxx`：

| 需求 | plt 接口 | 面向对象 |
|---|---|---|
| 画线 | `plt.plot(x, y)` | `ax.plot(x, y)` |
| 标题 | `plt.title(t)` | `ax.set_title(t)` |
| x 轴标签 | `plt.xlabel(t)` | `ax.set_xlabel(t)` |
| y 轴标签 | `plt.ylabel(t)` | `ax.set_ylabel(t)` |
| 图例 | `plt.legend()` | `ax.legend()` |
| 网格 | `plt.grid(True)` | `ax.grid(True)` |
| x 范围 | `plt.xlim(a, b)` | `ax.set_xlim(a, b)` |
| 存图 | `plt.savefig(f)` | `fig.savefig(f)` |

规律：`plt` 是动词（`plt.title`），`ax` 是 `set_xxx` 方法。**记住这一条，两套 API 都能看懂。**

## 一张画布多个坐标系

```python
fig, axes = plt.subplots(1, 2, figsize=(10, 4))   # 1 行 2 列
ax1, ax2 = axes                                   # 解包

ax1.plot(months, sales, color='#e41a1c')
ax1.set_title('北京')

ax2.bar(months, [90, 100, 95, 110, 130, 140], color='#377eb8')
ax2.set_title('上海')

fig.suptitle('上半年销售对比')
fig.tight_layout()
fig.savefig('two_axes.png')
```

`plt.subplots(1, 2)` 返回的是 `(fig, array([ax1, ax2]))`。多子图时 `axes` 是个 NumPy 数组，可以下标访问 `axes[0]`、`axes[1]`，也可以像上面那样解包。**解包时数量必须和列数一致**，写 `ax1, ax2, ax3 = axes` 而实际只有 2 列会报错。

## 翻车现场 2：set 和 get 混着写

```python
# WRONG
ax.title('标题')          # AttributeError: 'Axes' object has no attribute 'title'
ax.set_xlabel = '月份'    # 错误：把方法当成属性赋值了，图上看不到任何变化
```

输出：第一条报 `AttributeError`；第二条**不报错但什么都没发生**——静默失败，最危险。

**正确写法：**

```python
ax.set_title('标题')        # 是方法，要加括号
ax.set_xlabel('月份')       # 同上
ax.set_ylabel('销售额（万元）')
```

## 小结

- **Figure = 画布（一张纸）**，**Axes = 绘图区域**（含 x/y 轴刻度）
- `plt.subplots()` 返回 `(fig, ax)`；多子图时 `axes` 是数组
- `plt` 接口是"状态机"，**画多张图容易串味**；推荐面向对象写法
- `plt.xxx` ↔ `ax.set_xxx` 是对应的两套 API
- 想多子图就 `plt.subplots(nrows, ncols)`，解包数量要对得上
