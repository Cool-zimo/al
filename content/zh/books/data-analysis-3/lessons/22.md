# EDA 完整流程：看形状、看缺失、看异常、看关系

> 拿到一份新数据，别急着建模、别急着画图。EDA（探索性数据分析）有四道固定工序，按顺序走一遍，后面每一步都更稳。

## 第一步：看形状

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd
import numpy as np

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

tips = sns.load_dataset('tips')
print(tips.shape)          # 行数、列数
print(tips.dtypes)         # 每列的类型
print(tips.head())          # 前几行长什么样
print(tips.describe())      # 数值列的统计概览
```

`shape` 告诉你数据有多大，`dtypes` 告诉你每列是什么类型（int / float / object / datetime），`describe()` 给出计数、均值、标准差、四分位。这三步是**零成本的信息获取**，但能挡掉绝大多数后续错误。

**翻车现场 1：object 列其实是数字，数值运算全报错。**

```python
# 假设销售额被读成字符串
df = pd.DataFrame({'销售额': ['100', '200', '300', None]})
print(df['销售额'].dtype)          # object
# df['销售额'].mean()              # WRONG：object 类型算不出均值
df['销售额'] = pd.to_numeric(df['销售额'], errors='coerce')
print(df['销售额'].mean())          # 200.0
```

类型错了，后面所有数值分析都是空的。`dtypes` 是第一道检查，**任何非预期的 object 列都要追问一句"它本该是数字吗"**。

## 第二步：看缺失

```python
print(tips.isna().sum())                    # 每列缺失条数
print(tips.isna().mean().sort_values(ascending=False))  # 缺失比例
```

缺失不是"脏"，而是**信息**。怎么处理取决于缺失的**机制**：

| 情况 | 处理方式 |
|---|---|
| 缺失随机、比例低（<5%） | 直接删除对应行 |
| 缺失随机、比例高 | 用均值/中位数填充 |
| 缺失本身有意义（如"未填写=未购买"） | 单独作为一个类别 |
| 关键列缺失严重 | 整列丢弃 |

**翻车现场 2：用均值填充，却把分布中心拉偏。**

```python
df = pd.DataFrame({'销售额': [100, 200, 300, np.nan, np.nan]})
filled = df['销售额'].fillna(df['销售额'].mean())
print(filled.mean())     # 200.0
# 看似没问题，但缺失若是"大额订单漏录"，均值会被严重低估
```

填充不是"补齐就行"。**填充前先判断缺失是否随机**，填充后重画分布图，看形状有没有被改变。

## 第三步：看异常

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.boxplot(data=tips, x='total_bill', ax=ax)
ax.set_title('账单金额：有没有离群点')
fig.savefig('outlier.png')
```

箱线图的须线之外就是离群点。但**离群点不等于错误**：

```python
# 用 IQR 法标记离群点
Q1 = tips['total_bill'].quantile(0.25)
Q3 = tips['total_bill'].quantile(0.75)
IQR = Q3 - Q1
lo, hi = Q1 - 1.5 * IQR, Q3 + 1.5 * IQR
outliers = tips[(tips['total_bill'] < lo) | (tips['total_bill'] > hi)]
print(f'离群点 {len(outliers)} 条')
```

- 若是**录入错误**（年龄=200、日期=2999 年），修正或删除
- 若是**真实极端值**（顶级客户的大额订单），保留，它可能正是你最该关注的样本
- 若是**你选错了模型**（数据本来就是重尾分布），换方法，别删数据

**翻车现场 3：为了"让模型更好"删掉所有离群点。**

删掉离群点后，方差变小、R² 变高，模型看起来更"准"了。**但你删掉的可能正是业务里最有价值的一部分**。删之前先算一遍：去掉它们，核心结论变不变？不变才删。

## 第四步：看关系

```python
# 相关矩阵扫全貌
corr = tips.corr(numeric_only=True)
fig, ax = plt.subplots(figsize=(7, 6))
sns.heatmap(corr, annot=True, fmt='.2f', cmap='coolwarm',
            vmin=-1, vmax=1, square=True, ax=ax)
ax.set_title('变量间相关关系')
fig.savefig('corr.png')

# 重点关系画散点
fig, ax = plt.subplots(figsize=(8, 5))
sns.scatterplot(data=tips, x='total_bill', y='tip', hue='sex', ax=ax)
ax.set_title('账单与小费的关系')
fig.savefig('scatter.png')
```

四步的顺序不能颠倒：**先看形状，才知道用什么图；看缺失和异常，才敢做聚合；最后看关系，才不会被错误数据带偏**。

## EDA 总览图：四个维度一屏看全

```python
# 一屏展示四个维度的典型图
fig, axes = plt.subplots(2, 2, figsize=(13, 10))

sns.histplot(data=tips, x='total_bill', kde=True, ax=axes[0, 0])
axes[0, 0].set_title('① 形状：分布')

sns.boxplot(data=tips, x='day', y='total_bill', ax=axes[0, 1])
axes[0, 1].set_title('③ 异常：离群点')

axes[1, 0].bar(tips['day'].value_counts().index, tips['day'].value_counts().values)
axes[1, 0].set_title('② 缺失：各类别样本量')

sns.scatterplot(data=tips, x='total_bill', y='tip', ax=axes[1, 1])
axes[1, 1].set_title('④ 关系：两变量联动')

fig.tight_layout()
fig.savefig('overview.png')
```

## 小结

- EDA 四步按顺序：形状→缺失→异常→关系，不能颠倒
- `shape` / `dtypes` / `head()` / `describe()` 零成本获取信息
- object 列要追问"本该是数字吗"，及时 `to_numeric`
- 缺失处理取决于缺失机制，填充后重画分布验证
- 离群点不等于错误，删之前先问"核心结论变不变"
- 相关矩阵做全局扫描，散点图做重点验证
