# 写成报告：结论、证据、局限，以及"下一步该收集什么数据"

> 这是全书的最后一课。到这里你已经能读数据、洗数据、做分组、画图，只差最后一步：把成果写成一份别人愿意看、敢拿去用的报告。好报告 = 明确结论 + 可核验证据 + 坦承局限 + 指向下一步。

## 一份能用的报告长什么样

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import pandas as pd
import numpy as np

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

df = pd.DataFrame({
    '门店': ['北京']*4 + ['上海']*4 + ['广州']*4 + ['深圳']*4,
    '月份': ['1月','2月','3月','4月']*4,
    '渠道': ['线下','线上']*8,
    '销售额': [3200,4100,3300,4300,2800,3900,2900,4000,
              2100,2600,2200,2700,2400,3100,2500,3200],
    '订单数': [120,180,125,190,100,160,105,165,
              80,120,85,125,90,140,95,145],
    '客流量': [300,450,310,470,260,400,270,420,
             200,300,210,320,230,350,240,360],
})

# 算结论
g = df.groupby('门店').agg(销售额合计=('销售额','sum'),
                         订单数合计=('订单数','sum'),
                         客流量合计=('客流量','sum')).sort_values('销售额合计')
g['客单价'] = (g['销售额合计']/g['订单数合计']).round(1)
g['转化率%'] = (g['订单数合计']/g['客流量合计']*100).round(1)

print(g)
print('\n=== 报告要点 ===')
print(f'1. 规模排名：{list(g.index)}')
print(f'2. 北京领先广州 {(g["销售额合计"].max()/g["销售额合计"].min()-1)*100:.1f}%')
print(f'3. 客单价差距 < {(g["客单价"].max()-g["客单价"].min())/g["客单价"].min()*100:.1f}%')
```

一份合格的报告有四个段落，缺一个都不行：

| 段落 | 作用 | 常见错误 |
|---|---|---|
| 结论 | 开门见山说发现 | 绕半天不说重点 |
| 证据 | 数字 + 图支撑结论 | 只有结论没有数 |
| 局限 | 说清数据边界 | 把结论说满 |
| 下一步 | 指出缺什么数据 | 报告到结论就结束 |

## 结论：一句话说清"所以呢"

```python
# 用程序生成结论句，保证数字与数据一致
best = g.iloc[-1]
worst = g.iloc[0]
print(f"结论：{best.name}店以 {best['销售额合计']} 元销售额领先，"
      f"比 {worst.name}店高 "
      f"{(best['销售额合计']/worst['销售额合计']-1)*100:.1f}%；"
      f"但四店客单价集中在 {g['客单价'].min()}–{g['客单价'].max()} 元，"
      f"差距小于 {(g['客单价'].max()-g['客单价'].min())/g['客单价'].min()*100:.1f}%，"
      f"说明优势来自客流而非单客价值。")
```

**结论句要"有数字、有比较、有判断"**。纯描述（"北京销售额最高"）不是结论，因为没说高多少、为什么重要。带比较（"领先 34%"）才是结论。让程序生成结论句还能避免一个低级但致命的错误：改了数据却忘了改报告里的数字。

**翻车现场 1：结论写得像摘要，全是"本报告分析了……"。**

```python
# WRONG：结论段写成了过程描述
report_wrong = """
本报告对四家门店的销售数据进行了深入分析，
使用了 groupby 分组和 matplotlib 可视化方法，
对销售额、订单数、客流量等指标进行了统计，
得出了相关结论，具有一定参考价值。
"""
print(report_wrong)
# 读完不知道结论是什么，等于没写
```

这种"过程式结论"在真实报告里极其常见，读起来很忙但信息量为零。**结论段的第一句必须是判断句**，比如"北京店的领先来自客流而非客单价"。方法、工具、过程属于附录，不该出现在结论里。

## 证据：把图和数一起摆出来

```python
# 配套图表：结论的视觉证据
fig, axes = plt.subplots(1, 2, figsize=(13, 5))

axes[0].bar(g.index, g['销售额合计'], color='#4C72B0')
axes[0].set_title(f'{best.name}领先{worst.name} '
                  f'{(best["销售额合计"]/worst["销售额合计"]-1)*100:.1f}%')
for i, v in enumerate(g['销售额合计']):
    axes[0].text(i, v+200, str(v), ha='center', fontsize=9)

axes[1].bar(g.index, g['客单价'], color='#DD8452')
axes[1].set_title(f'客单价仅差 {g["客单价"].max()-g["客单价"].min()} 元，效率无差距')
for i, v in enumerate(g['客单价']):
    axes[1].text(i, v+0.3, str(v), ha='center', fontsize=9)

plt.tight_layout()
plt.savefig('final_report.png', dpi=120)
plt.close()
print('图表已保存')
```

证据的标准姿势是**一张表 + 一张图**。表给精确数字（别人可以拿去复核），图给直观印象（别人一眼看懂）。两者互补：只给图会被质疑"这个 34% 怎么算的"，只给表会被嫌"看不出趋势"。

## 局限：坦承边界，反而更可信

```python
# 自动检测并列出数据的局限
issues = []
if df['月份'].nunique() < 6:
    issues.append(f'数据仅覆盖 {df["月份"].nunique()} 个月，季节性结论不可靠')
if df['门店'].nunique() < 5:
    issues.append(f'样本门店仅 {df["门店"].nunique()} 家，外推到其他城市需谨慎')
if '成本' not in df.columns:
    issues.append('缺少成本数据，无法判断利润，销售额≠盈利')
if '会员' not in df.columns:
    issues.append('缺少会员/复购数据，无法评估客户留存')

print('数据局限：')
for i, x in enumerate(issues, 1):
    print(f'  {i}. {x}')
```

局限不是"示弱"，而是**给结论划定适用范围**。数据只有 4 个月就说"发现淡季规律"，这是过度推断；明确说"样本不足 6 个月，季节性待验证"，读者反而更信你前面的结论。写局限的实用方法：逐列检查——缺什么字段、覆盖多长周期、粒度多细、有没有缺失——每一条都是一条局限。

**翻车现场 2：把相关性当因果性写进结论。**

```python
# WRONG：看到线上占比高，就断定线上是增长原因
corr = df.groupby('渠道')['销售额'].sum()
if corr.get('线上', 0) > corr.get('线下', 0):
    print('结论：线上渠道是销售增长的主要原因')  # 错！
# 数据只记录了"是什么"，没有记录"为什么"
```

相关性只能说明两个变量一起变，不能说明谁导致谁。可能是北京门店本来客流就大，恰好线上占比也高。**"原因"必须用额外数据验证**：做 A/B 测试、看同期对照、加控制变量。报告里写"线上占比更高"是证据，写"线上带动了增长"是推测——推测要标出来，不能冒充结论。

## 下一步：该收集什么数据

```python
# 从当前局限反推下一步数据需求
plan = pd.DataFrame([
    ['成本 / 毛利', '利润分析', '成本表、采购价'],
    ['会员 ID / 复购次数', '客户留存', '会员系统导出'],
    ['促销记录', '活动效果归因', '营销日历'],
    ['竞品价格', '定价合理性', '市场调研'],
    ['天气 / 节假日', '外部因素控制', '公开数据源'],
], columns=['待收集数据', '能回答的问题', '获取途径'])

print(plan.to_string(index=False))
```

**数据缺口 = 下一步课题**。当前数据只能回答"规模多大、结构如何"，回答不了"赚没赚钱、客户留没留住、活动有没有用"——每一个回答不了的问号，就是一份待收集的数据。列出"下一步该收集什么"，是把一次性分析变成持续分析的分水岭，也是报告中最能体现专业度的部分。

## 全课总结：数据分析的完整闭环

```
读取 → 清洗 → 分组 → 洞察 → 可视化 → 报告
  ↑                                    ↓
  └──────── 收集更多数据 ←──────────────┘
```

全书走完这一圈：第 1-5 课搞定 Python 基础与数据结构，第 6-14 课掌握 NumPy 与 Pandas 的核心操作，第 15-20 课学会清洗与处理真实数据，第 21-25 课深入分组聚合与透视，第 26-27 课打通从脏数据到干净数据的完整流程，第 28-29 课把数据变成洞察和图表，这一课把它落成报告。**数据工作不是一条射线，而是一个循环**：写完报告 → 发现数据缺口 → 去收集 → 再分析，每一轮都比上一轮更近真相一步。

## 小结

- 好报告四段：结论、证据、局限、下一步
- 结论要有数字、有比较、有判断，第一句必须是判断句
- 证据 = 表（可复核）+ 图（可看懂），两者都要有
- 局限是给结论划边界，写清楚反而更可信
- 相关性≠因果性，推测必须标注，不能冒充结论
- 数据缺口就是下一步课题，闭环才是专业分析
