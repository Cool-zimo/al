# 从问题到图：先想"要回答什么"，再选图

> 大多数人画错图，不是不会写代码，而是**没想清楚要回答什么就动手**。这一节给你一张"问题→图"的决策表，以及一个完整的选题到出图流程。

## 先问三个问题

动笔前先回答：

1. **我要回答什么？**（"各门店销售额差距大吗"还是"销售额随时间怎么变"）
2. **变量是什么类型？**（类别 vs 数值 vs 时间）
3. **我想让人看出什么？**（对比 / 趋势 / 分布 / 关系）

这三个问题没答完，就别打开编辑器。

## 决策表：问题决定图

| 你要回答的问题 | 变量类型 | 用哪个图 |
|---|---|---|
| 各类别谁高谁低 | 类别 vs 数值 | bar / box |
| 随时间怎么变 | 时间 vs 数值 | line |
| 分布长什么样 | 单个数值 | hist / kde / box |
| 两变量什么关系 | 数值 vs 数值 | scatter |
| 两两之间谁和谁有关 | 多个数值 | heatmap（相关矩阵） |
| 占比多少 | 类别 vs 占比 | 堆叠 bar（慎用 pie） |

**翻车现场 1：拿箱线图回答"哪个更高"。**

```python
# 想比较北京上海广州的销售额谁最高
sns.boxplot(data=sales, x='城市', y='销售额')   # WRONG：给了太多信息
```

你要的只是"谁高"，箱线图却同时给了四分位、离群点。信息过多等于没有重点。**单一对比用 bar，分布差异才用 box**。先锁定问题，再决定信息密度。

## 四类基本诉求

### 对比：类别之间的差异

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

sales = pd.DataFrame({
    '城市': ['北京','上海','广州','深圳'],
    'Q1': [320, 280, 210, 245],
    'Q2': [335, 310, 230, 268],
})

fig, ax = plt.subplots(figsize=(8, 5))
sns.barplot(data=sales, x='城市', y='Q1', ax=ax)
ax.set_title('各城市一季度销售额对比')
fig.savefig('compare.png')
```

对比的核心原则是**基线对齐**：柱形图基线从 0 起，折线图共享 y 轴。任何破坏对齐的做法都会扭曲对比。

### 趋势：随时间的变化

```python
months = pd.DataFrame({
    '月份': ['1月','2月','3月','4月','5月','6月'],
    '销售额': [120, 135, 128, 160, 175, 190],
})
fig, ax = plt.subplots(figsize=(8, 5))
sns.lineplot(data=months, x='月份', y='销售额', marker='o', ax=ax)
ax.set_title('上半年销售额趋势')
fig.savefig('trend.png')
```

趋势图**必须用折线或面积，不能换成柱形**——类别顺序在类别对比里是任意的，在时间趋势里是有意义的，换柱形会丢掉"连续性"。

### 分布：数据的形状

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.histplot(data=sales, x='Q1', kde=True, ax=ax)
ax.set_title('一季度销售额分布')
fig.savefig('dist.png')
```

看分布用 hist/kde/box/violin，别用 bar——bar 暗示类别离散，分布是连续变量。

### 关系：两个变量的联动

```python
tips = sns.load_dataset('tips')
fig, ax = plt.subplots(figsize=(8, 5))
sns.scatterplot(data=tips, x='total_bill', y='tip', ax=ax)
ax.set_title('账单金额与小费的关系')
fig.savefig('rel.png')
```

## 选题到出图的完整流程

```text
1. 写下问题："我想知道什么"
2. 圈出变量：自变量（x）是什么、因变量（y）是什么
3. 定类型：x 是类别/时间/数值？y 是什么？
4. 查决策表：选出候选图
5. 画草图：先在纸上画个大概
6. 写代码：画出来
7. 自查：标题、轴标签、单位、图例、数据来源都齐了吗
8. 问一句："看这张图的人能在 3 秒内看懂吗"
```

**翻车现场 2：跳过了第 1 步直接画图，结果图很漂亮但答非所问。**

这是最普遍也最致命的错误。你手上有一份销售数据，随手画了各月销售额折线图，因为它"好画"。但老板问的是"哪些门店在拖后腿"。**图再漂亮，答错问题就是零分**。写完代码，回头对着第 1 步的问题看一眼：这张图回答它了吗？

## 一个完整例子：门店坪效

问题：**"哪个城市的门店坪效（每平方米销售额）最高？"**

```python
# 1. 问题：哪个城市坪效最高
# 2. 变量：城市（类别，x），坪效（数值，y）
# 3. 类型：类别 vs 数值 → 对比
# 4. 决策表：用 bar
store = pd.DataFrame({
    '城市': ['北京','上海','广州','深圳'],
    '销售额_万': [320, 280, 210, 245],
    '面积_平': [80, 70, 65, 72],
})
store['坪效'] = store['销售额_万'] * 10000 / store['面积_平']

fig, ax = plt.subplots(figsize=(8, 5))
sns.barplot(data=store, x='城市', y='坪效', ax=ax)
ax.set_title('各城市门店坪效对比（元/平方米）')
ax.set_ylabel('坪效（元/平方米）')
fig.savefig('pingxiao.png')
print(store[['城市','坪效']].round(0))
```

如果直接比较销售额，北京最高；算成坪效，排序可能完全不同。**这一步的"派生指标"往往比原始指标更能回答问题**。

## 小结

- 动笔前先答三个问题：回答什么、变量类型、想让人看出什么
- 决策表：对比→bar/box，趋势→line，分布→hist/kde，关系→scatter，多变量→heatmap
- 对比要基线对齐，趋势要保持连续性，分布别用 bar
- 流程八步：问题→变量→类型→查表→草图→代码→自查→3 秒测试
- 跳过"问题"那一步，图再漂亮也是零分
- 派生指标（坪效、人均、转化率）常常比原始指标更能回答业务问题
