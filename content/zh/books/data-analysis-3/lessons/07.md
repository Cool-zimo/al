# 折线图与时间序列：趋势与双 Y 轴

> 折线图讲"变化"。销售怎么走、温度怎么变、用户怎么涨，全靠它。这一节讲时间序列的正确画法，以及"两个量纲"怎么放在一张图里。

## 折线图讲的是什么

**柱状图比大小，折线图看趋势。** 折线图的连线暗示"连续"——数据在两点之间是有意义的（时间、年龄、距离）。如果你的 x 是纯类别（比如门店名），用折线图是错的，会画出毫无意义的连线。

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

months = ['1月', '2月', '3月', '4月', '5月', '6月',
          '7月', '8月', '9月', '10月', '11月', '12月']
sales = [120, 135, 128, 160, 175, 190, 205, 220, 210, 230, 250, 270]

fig, ax = plt.subplots(figsize=(9, 5))
ax.plot(months, sales, marker='o', color='#e41a1c', linewidth=2)
ax.set_title('北京门店 2025 全年销售额')
ax.set_xlabel('月份')
ax.set_ylabel('销售额（万元）')
fig.autofmt_xdate(rotation=45)      # x 标签倾斜，避免重叠
fig.savefig('line_trend.png')
print('saved')
```

`fig.autofmt_xdate(rotation=45)` 让 x 轴标签旋转 45°，**月份多了不会挤成一团**。

## 双 Y 轴：两个量纲放一张图

常见场景：销售额（万元）和客单价（元）要一起看，但**两者量级差一百倍**，画在同一轴上会压扁其中一个。

```python
months = ['1月', '2月', '3月', '4月', '5月', '6月']
sales = [120, 135, 128, 160, 175, 190]        # 万元
avg_price = [320, 315, 340, 335, 330, 345]    # 元

fig, ax1 = plt.subplots(figsize=(9, 5))

# 第一个轴：销售额
ax1.plot(months, sales, color='#e41a1c', marker='o', label='销售额')
ax1.set_xlabel('月份')
ax1.set_ylabel('销售额（万元）', color='#e41a1c')
ax1.tick_params(axis='y', labelcolor='#e41a1c')

# 第二个轴：客单价（共享 x 轴）
ax2 = ax1.twinx()
ax2.plot(months, avg_price, color='#377eb8', marker='s', label='客单价')
ax2.set_ylabel('客单价（元）', color='#377eb8')
ax2.tick_params(axis='y', labelcolor='#377eb8')

fig.savefig('twinx.png')
```

`ax1.twinx()` 创建**共享 x 轴、独立 y 轴**的新坐标系。注意要给两个轴分别着色（`tick_params` 把刻度字也染成对应颜色），否则读者分不清哪条线对应哪个轴。

## 翻车现场 1：twinx 后图例只显示一半

```python
ax1.plot(months, sales, color='#e41a1c', label='销售额')
ax2 = ax1.twinx()
ax2.plot(months, avg_price, color='#377eb8', label='客单价')

ax1.legend()         # 只显示"销售额"
```

输出：图例里**只有销售额**，客单价不见了。`ax1.legend()` 只会收集 `ax1` 上的线。

**解法：把两条线的句柄合并。**

```python
lines1, labels1 = ax1.get_legend_handles_labels()
lines2, labels2 = ax2.get_legend_handles_labels()
ax1.legend(lines1 + lines2, labels1 + labels2, loc='upper left')
```

## 翻车现场 2：两个轴没对齐基准

```python
# WRONG：两个 y 轴各自从 0 开始，但其实该让 0 对齐
ax1.set_ylim(0, 300)
ax2.set_ylim(300, 400)      # 客单价 320-345 只在上面一条缝里，看起来像一条直线
```

输出：客单价那条线**几乎没波动**，因为它只占了 y 轴顶部一小段。两条线量纲不同是正常的，但要留意这种"被压缩"造成的视觉误导。

## 时间序列的正确画法

**x 是日期字符串时，matplotlib 会按顺序排成类别，不是真正的时间轴。** 想让 x 轴按真实日期间距缩放，要用 `datetime`：

```python
from datetime import datetime

dates = [datetime(2025, 1, 1), datetime(2025, 2, 1), datetime(2025, 3, 1),
         datetime(2025, 4, 1), datetime(2025, 5, 1), datetime(2025, 6, 1)]
sales = [120, 135, 128, 160, 175, 190]

fig, ax = plt.subplots(figsize=(9, 5))
ax.plot(dates, sales, marker='o')
ax.set_title('用 datetime 做 x，间隔自动按比例')
fig.autofmt_xdate()
fig.savefig('datetime.png')
```

好处：缺了某个月（比如数据缺失），时间轴会**留出空档**，不会把断开的月份连成连续的线——这才是真实的时间关系。

## 翻车现场 3：日期间隔不均匀却被连成直线

```python
dates = [datetime(2025, 1, 1), datetime(2025, 1, 15),
         datetime(2025, 3, 1), datetime(2025, 6, 1)]    # 间隔 1天/45天/91天
vals = [10, 12, 15, 20]

ax.plot(dates, vals)     # 看起来是平滑上升
```

输出：画出来是**一条直线上升**，看不出中间有长达几个月的空档。**真时间序列一定要用 datetime 做 x**，matplotlib 才会按比例留空。

## 阶梯线和面积图

**看累计量用阶梯线（step）**：

```python
ax.step(months, sales, where='mid', color='#4daf4a')
```

`where='mid'` 表示在类别中点处跳变，适合"库存、订单数"这类只在离散时刻变化的量。

**想强调"量"用面积图**：

```python
ax.fill_between(months, sales, alpha=0.3, color='#377eb8')
```

`fill_between` 会填充曲线下方的区域，**视觉重量更大**，适合强调总量。

## 多条线对比的配色

```python
fig, ax = plt.subplots(figsize=(9, 5))
ax.plot(months, sales_beijing, label='北京', color='#e41a1c')
ax.plot(months, sales_shanghai, label='上海', color='#377eb8')
ax.plot(months, sales_guangzhou, label='广州', color='#4daf4a')
ax.legend()
```

三色用**区分度高的柔和色**，别用三个相近的蓝。红蓝绿（Set1）是经典组合，色盲友好。

## 小结

- 折线图看**趋势和变化**，x 应该是连续的（时间/年龄/距离）
- 双 Y 轴：`ax1.twinx()`，给两个轴**分别配色**，图例要手动合并
- 真时间序列用 `datetime` 做 x，缺月会留空档
- 类别多：`autofmt_xdate(rotation=45)` 让标签倾斜
- 累计量用 `step`，强调总量用 `fill_between`
