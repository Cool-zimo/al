# pandas 直接画图：df.plot() 系列

> DataFrame 自带 `.plot()` 方法，几行代码出图。这一节讲它够用在哪、不够用在哪，以及怎么和 matplotlib 混用。

## df.plot() 是 matplotlib 的快捷方式

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import pandas as pd

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

df = pd.DataFrame({
    '月份': ['1月','2月','3月','4月','5月','6月'],
    '北京': [120, 135, 128, 160, 175, 190],
    '上海': [110, 118, 130, 140, 155, 168],
    '广州': [90, 100, 95, 110, 130, 140]
})
df = df.set_index('月份')

fig, ax = plt.subplots(figsize=(9, 5))
df.plot(ax=ax, marker='o')                    # ← 把 ax 传进去
ax.set_title('三门店销售额对比')
ax.set_ylabel('销售额（万元）')
fig.savefig('df_plot.png')
print('saved')
```

`df.plot(ax=ax)` 返回的是 matplotlib 的 Axes 对象，**可以继续用 ax.set_title 等所有方法加工**。这就是"混用"的桥梁。

## plot 的 kind 参数

| kind | 图 | 等价写法 |
|---|---|---|
| `'line'`（默认） | 折线 | `df.plot.line()` |
| `'bar'` | 柱状 | `df.plot.bar()` |
| `'barh'` | 横向柱状 | `df.plot.barh()` |
| `'hist'` | 直方图 | `df.plot.hist()` |
| `'box'` | 箱线图 | `df.plot.box()` |
| `'scatter'` | 散点 | `df.plot.scatter()` |
| `'area'` | 面积图 | `df.plot.area()` |
| `'pie'` | 饼图 | `df.plot.pie()` |

**例：柱状图**

```python
df.plot(kind='bar', figsize=(9, 5), color=['#e41a1c', '#377eb8', '#4daf4a'])
```

`df.plot` 会**自动用列名做图例**——这是它最大的便利。

## 翻车现场 1：没传 ax，图跑到别处去了

```python
fig, ax = plt.subplots(figsize=(9, 5))
df.plot()                     # 忘记 ax=ax！会新建一个 figure
ax.set_title('标题')          # 标题出现在另一个空图上
```

输出：画出了两张图——**一张是数据图（但没有标题），一张是带标题的空图**。因为 `df.plot()` 不指定 ax 时会自己新建 figure。

**解法：永远把 `ax=ax` 写上。**

## 翻车现场 2：x 轴是数字而不是类别

```python
df2 = pd.DataFrame({
    '北京': [120, 135, 128],
    '上海': [110, 118, 130]
})                          # 没有显式 index
df2.plot()
```

输出：x 轴是 `0, 1, 2` 三个整数，不是我们想要的门店名。**想把某列当 x 轴，要先 `set_index`**。

## 横向柱状与堆叠

```python
# 横向柱状
df.plot(kind='barh', figsize=(9, 5))

# 堆叠柱状
df.plot(kind='bar', stacked=True, figsize=(9, 5))

# 面积图
df.plot(kind='area', alpha=0.5, figsize=(9, 5))
```

`stacked=True` 让多列堆叠，适合看总量 + 构成。

## 散点图：必须指定 x 和 y 列

```python
df3 = pd.DataFrame({
    '面积': [50, 80, 120, 150, 200],
    '销售额': [300, 500, 700, 900, 1200],
    '租金': [10, 15, 25, 30, 45]
})

fig, ax = plt.subplots(figsize=(8, 5))
df3.plot.scatter(x='面积', y='销售额', c='租金', cmap='viridis',
                s=80, ax=ax)
fig.colorbar(ax.collections[0], ax=ax, label='租金（万元）')
fig.savefig('df_scatter.png')
```

散点图的 `c` 可以**直接传列名**（`c='租金'`），比手写到 numpy 数组方便。

## 什么时候 df.plot 不够用

`df.plot` 适合**快速探索**，但以下场景它做不到：

| 场景 | 为什么不够 |
|---|---|
| 双 Y 轴（twinx） | 没有 twinx 参数 |
| 复杂的图例合并 | 多 axes 的 legend 要手动合并 handles |
| 不规则子图布局 | GridSpec 需要直接操作 figure |
| 精确的标注位置 | annotate 需要坐标计算 |
| 多图共用一个 colorbar | df.plot 不返回 colorbar |

**判断标准：探索阶段用 df.plot，出正式图用 matplotlib。**

## 混用的最佳实践

```python
fig, axes = plt.subplots(2, 1, figsize=(9, 8))

# 上半：折线
df.plot(ax=axes[0], marker='o')
axes[0].set_title('销售额趋势')

# 下半：柱状
df.plot(kind='bar', ax=axes[1], color=['#e41a1c', '#377eb8', '#4daf4a'])
axes[1].set_title('各月对比')

fig.tight_layout()
fig.savefig('mixed.png')
```

**统一流程**：先 `plt.subplots` 建好 ax，再 `df.plot(ax=ax)` 把数据画进去，最后用 ax 的方法做标题、图例、标注。**既享受 pandas 的便捷，又保留 matplotlib 的全部控制力。**

## 翻车现场 3：df.plot 返回的 ax 和 subplots 返回的 ax 类型不一致

```python
ax = df.plot()               # ax 是 matplotlib.axes.Axes
fig, axes = plt.subplots(2, 1)
axes[0] = df.plot()          # 覆盖了 axes[0]，但丢掉了共享坐标轴等设置
```

输出：子图布局混乱，共享坐标轴的设置失效。**应该显式传 ax**：

```python
df.plot(ax=axes[0])          # 画在指定的 axes 上，不新建
```

## 小结

- `df.plot(ax=ax)` 是 pandas 和 matplotlib 混用的桥梁
- `kind` 决定图型：`line`/`bar`/`barh`/`box`/`scatter`/`area`/`pie`
- 列名自动变成图例；想指定 x 轴要先 `set_index`
- **必须传 `ax=`**，否则会新建 figure
- 散点图 `c='列名'` 可直接用某列做颜色映射
- 探索用 df.plot，正式出图用 matplotlib + 显式 ax
