# 可视化呈现：把结论画成一组图

> 上一节算出了结论，这一节要把结论画出来。核心原则只有一条：**一图一结论**——每张图只回答一个问题，图与图之间要有逻辑顺序。

## 排版：一组图，不是一堆图

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import pandas as pd
import numpy as np

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

df = pd.DataFrame({
    '门店': ['北京']*4 + ['上海']*4 + ['广州']*4 + ['深圳']*4,
    '月份': ['1月','2月','3月','4月']*4,
    '渠道': ['线下','线上']*8,
    '销售额': [3200,4100,3300,4300,2800,3900,2900,4000,
              2100,2600,2200,2700,2400,3100,2500,3200],
    '订单数': [120,180,125,190,100,160,105,165,
              80,120,85,125,90,140,95,145],
})

# 算好结论数据
g = df.groupby('门店').agg(销售额合计=('销售额','sum'),
                         订单数合计=('订单数','sum')).sort_values('销售额合计')
g['客单价'] = (g['销售额合计']/g['订单数合计']).round(1)

# 图 1：各门店销售额合计（结论：谁规模最大）
fig, axes = plt.subplots(1, 2, figsize=(13, 5))

axes[0].bar(g.index, g['销售额合计'], color='#4C72B0')
axes[0].set_title('北京门店销售额领先，广州差距明显')
axes[0].set_ylabel('销售额（元）')
for i, v in enumerate(g['销售额合计']):
    axes[0].text(i, v+200, str(v), ha='center', fontsize=9)

# 图 2：各门店客单价（结论：谁效率最高）
axes[1].bar(g.index, g['客单价'], color='#DD8452')
axes[1].set_title('各门店客单价接近，无明显效率差距')
axes[1].set_ylabel('客单价（元）')
for i, v in enumerate(g['客单价']):
    axes[1].text(i, v+0.5, str(v), ha='center', fontsize=9)

plt.tight_layout()
plt.savefig('store_overview.png', dpi=120)
print('已保存 store_overview.png')
```

`subplots(1, 2)` 生成一个 1 行 2 列的子图网格，返回一个 `fig`（整张画布）和 `axes`（子图数组）。**每张子图只回答一个问题**：左边回答"谁规模最大"，右边回答"谁效率最高"。两图并排，规模与效率的对比关系立刻显现——北京规模领先但客单价并不突出，说明它的优势来自客流而非单客价值。

**翻车现场 1：每张图画太多东西，结论被稀释。**

```python
# WRONG：一张图塞 4 个指标，颜色杂乱，没人看得懂
fig, ax = plt.subplots()
ax.bar(g.index, g['销售额合计'], color='blue', label='销售额')
ax.bar(g.index, g['订单数合计'], color='red', label='订单数')  # 量级不同，柱子崩坏
ax.bar(g.index, g['客单价'], color='green', label='客单价')
ax.legend()
plt.savefig('mess.png')
# 订单数是几百，客单价是几十，柱子高低差一个量级，图基本废了
```

量级不同的指标绝对不能画在同一张图上。要么拆成多张子图，要么用双 Y 轴（但双 Y 轴本身就难读，能拆就别用）。判断标准很简单：**如果必须写三段解释才能让人看懂一张图，那就该拆图。**

## 一图一结论：给图写标题就是给结论起名

```python
# 图 3：渠道结构（结论：线上已是主导渠道）
chan = df.groupby('渠道')['销售额'].sum()
fig, ax = plt.subplots(figsize=(6, 5))
colors = ['#55A868', '#C44E52']
ax.pie(chan.values, labels=chan.index, autopct='%1.1f%%',
       colors=colors, startangle=90)
ax.set_title('线上渠道贡献 56.9%，已成为主力')
plt.tight_layout()
plt.savefig('channel_pie.png', dpi=120)
print('渠道占比:\n', chan)
```

标题不是"各渠道销售额占比"，而是"**线上渠道贡献 56.9%，已成为主力**"。把结论写进标题，看图的人 1 秒就能拿到信息，不用自己算、不用猜你想说什么。这是报告图和分析图的本质区别。

## 逻辑顺序：先总后分，先规模后效率

```python
# 三张图按逻辑顺序排列：总览 → 结构 → 趋势
fig, axes = plt.subplots(2, 2, figsize=(13, 10))

# ① 总览：各门店规模
axes[0, 0].bar(g.index, g['销售额合计'], color='#4C72B0')
axes[0, 0].set_title('① 北京销售额领先广州 34%')

# ② 结构：渠道占比
chan_pct = (chan/chan.sum()*100).round(1)
axes[0, 1].pie(chan_pct.values, labels=chan_pct.index, autopct='%1.1f%%')
axes[0, 1].set_title('② 线上贡献近六成销售额')

# ③ 趋势：月度走势
monthly = df.groupby('月份')['销售额'].sum()
axes[1, 0].plot(monthly.index, monthly.values, marker='o', color='#8172B3')
axes[1, 0].set_title('③ 销售额逐月稳步上升')

# ④ 交叉：门店 × 渠道
pivot = df.pivot_table(index='门店', columns='渠道', values='销售额', aggfunc='sum')
pivot.plot(kind='bar', ax=axes[1, 1], color=['#55A868','#C44E52'])
axes[1, 1].set_title('④ 每家店都是线上高于线下')

plt.tight_layout()
plt.savefig('report_grid.png', dpi=120)
print('已保存 report_grid.png')
```

四张图的逻辑链是：**先看总体盘子有多大（①）→ 再看盘子怎么切（②）→ 然后看时间上怎么变（③）→ 最后看交叉维度有没有规律（④）**。这就是"先总后分、先规模后效率、先静态后动态"的呈现顺序。打乱这个顺序，读者会迷失；按这个顺序排，即使不看文字也能读完整条故事线。

**翻车现场 2：图排了但没存盘，或者尺寸被挤爆。**

```python
# WRONG：忘记 tight_layout，也忘记 savefig，图被标签挤烂
fig, ax = plt.subplots(figsize=(4, 3))
ax.bar(['北京','上海','广州','深圳'],[14900,13600,9600,11200])
ax.set_title('各门店销售额对比'*3)  # 标题太长
# plt.tight_layout()  # 忘了
# plt.savefig('bad.png')  # 忘了
plt.close()
```

中文标签长、标题长、子图多，任何一个不加 `tight_layout()` 都会让标签重叠出界。另外**一定要 `plt.close()` 或用 `plt.savefig()` 后关掉**，否则在循环里反复画图会吃光内存。生成报告图的标准四件套：`figsize` 定尺寸 → 画图 → `tight_layout()` → `savefig()` + `close()`。

## 小结

- 用 `subplots` 做多子图排版，一张大画布承载一组图
- 一图一结论，把结论写进标题而不是留给读者猜
- 量级不同的指标绝不画在同一张图上，要么拆图要么双 Y 轴
- 呈现顺序：先总后分、先规模后效率、先静态后动态
- 中文标签必须配 `tight_layout()`，否则必重叠
- 画完图必 `savefig` + `close`，循环里尤其不能漏
