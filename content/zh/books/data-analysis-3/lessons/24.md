# 图表的可读性：信息密度、留白、字体层级、一图一结论

> 图能跑通不等于图能读懂。可读性是"让人在 3 秒内抓到结论"的工程，它由四个旋钮控制：信息密度、留白、字体层级、结论数量。

## 一图一结论

一张图只承载一个信息点。这是可读性第一条，也最常被违反。

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

sales = pd.DataFrame({
    '门店': ['北京','上海','广州','深圳'],
    '销售额': [320, 310, 300, 295],
    '客单价': [185, 172, 158, 168],
    '坪效': [4.0, 4.4, 3.2, 3.4],
})

# 一图一结论：只讲"销售额对比"
fig, ax = plt.subplots(figsize=(7, 5))
ax.bar(sales['门店'], sales['销售额'], color='#4C72B0')
ax.set_title('北京门店销售额最高')
ax.set_ylabel('销售额（万元）')
for b in ax.patches:
    ax.text(b.get_x()+b.get_width()/2, b.get_height()+5,
            f'{int(b.get_height())}', ha='center')
fig.tight_layout()
fig.savefig('one_point.png')
```

标题直接写结论"北京门店销售额最高"，而不是笼统的"销售数据"。**读图的人不需要自己归纳**——你把结论替他说出来了。

**翻车现场 1：一图塞三个结论。**

```python
fig, ax = plt.subplots(figsize=(7, 5))
x = range(len(sales))
ax.bar([i-0.2 for i in x], sales['销售额'], width=0.2, label='销售额')
ax.bar(x, sales['客单价'], width=0.2, label='客单价')
ax.bar([i+0.2 for i in x], sales['坪效'], width=0.2, label='坪效')
ax.set_title('销售综合对比')      # 三个指标、量纲不同、结论不明
ax.legend()
fig.savefig('three_in_one.png')
```

三个指标量纲完全不同（万元、元、元/㎡），挤在同一坐标轴上，谁都看不出重点。**量纲不同就分开画**，三张小图（分面）比一张乱图好得多。

## 信息密度：去掉一切不参与表达的墨迹

数据墨水比（data-ink ratio）：图上用于表达数据的墨迹 ÷ 总墨迹。越高越清晰。

```python
# 改进版：去掉顶部和右侧边框、淡化网格
fig, ax = plt.subplots(figsize=(7, 5))
ax.bar(sales['门店'], sales['销售额'], color='#4C72B0')
ax.set_title('北京门店销售额最高', fontsize=13, pad=14)
ax.set_ylabel('销售额（万元）')
ax.spines['top'].set_visible(False)
ax.spines['right'].set_visible(False)
ax.grid(axis='y', alpha=0.3)
ax.set_axisbelow(True)            # 网格线在柱体下方
fig.tight_layout()
fig.savefig('clean.png')
```

去掉的每一条线都是**减少的认知负担**。网格线用 `alpha=0.3` 放淡、`set_axisbelow(True)` 让网格沉到柱体后面，既保留参照又不抢戏。

## 留白：不是空白，是节奏

```python
fig, ax = plt.subplots(figsize=(7, 5))
ax.bar(sales['门店'], sales['销售额'])
ax.set_title('北京门店销售额最高', fontsize=13, pad=18)   # pad 给标题下方留白
ax.set_xlabel('门店', labelpad=10)                        # 轴标签下方留白
ax.set_ylabel('销售额（万元）', labelpad=10)
ax.margins(y=0.15)                                        # 顶部留白，柱顶不贴边
fig.tight_layout()
fig.savefig('whitespace.png')
```

`pad` 控制文字与轴的距离，`margins(y=0.15)` 让柱子上方留出空间。柱顶数值、标题都不该贴边。**留白不是浪费，是让重点被看见**。

## 字体层级：三个层级，各有分工

一张图里的文字分三层，字号要能看出主次：

| 层级 | 内容 | 字号参考 |
|---|---|---|
| 一级 | 图标题（结论） | 13–15，加粗 |
| 二级 | 轴标签（单位说明） | 11 |
| 三级 | 刻度标签、图例 | 10 |

```python
fig, ax = plt.subplots(figsize=(7, 5))
ax.bar(sales['门店'], sales['销售额'])
ax.set_title('北京门店销售额最高', fontsize=14, fontweight='bold', pad=18)
ax.set_xlabel('门店', fontsize=11)
ax.set_ylabel('销售额（万元）', fontsize=11)
ax.tick_params(labelsize=10)
fig.tight_layout()
fig.savefig('hierarchy.png')
```

**翻车现场 2：全图一个字号。**

标题、轴标签、刻度都用 10 号字，读图的人不知道先看哪。**字号就是阅读顺序**，层级混乱等于没有重点。

## 可读性自查表

画完一张图，过一遍这张表：

- [ ] 标题是不是一句话结论，而不是"数据分析"
- [ ] 轴标签有没有单位（万元？人次？%？）
- [ ] 图例有没有、是不是多余（单组数据往往不需要图例）
- [ ] 顶部和右侧边框删了吗
- [ ] 网格线淡化了吗，有没有压住数据
- [ ] 柱顶/点上的数值标注有没有
- [ ] 有没有塞进第二个量纲、第二个结论
- [ ] 3 秒内，别人能不能说出这张图讲什么

**翻车现场 3：图例成了多余装饰。**

```python
ax.bar(sales['门店'], sales['销售额'], label='销售额')
ax.legend()   # 只有一组数据，图例只重复了一遍"销售额"
```

单组数据的图例**完全多余**，它占用空间、制造噪声。图例只在 hue 分组或多组数据时才出现。判断标准：图例是否提供了新的编码信息？没有就删。

## 小结

- 一图一结论：标题直接写结论，量纲不同就分面
- 信息密度：去掉不参与表达的墨迹，网格线淡化且沉到数据下方
- 留白：`pad` 控制文字间距，`margins` 防贴边
- 字体三级：标题 14 加粗 / 轴标签 11 / 刻度 10
- 图例只在提供新编码信息时才保留，单组数据删掉
- 画完过八项自查表，3 秒测试决定是否合格
