# 热力图与相关矩阵：heatmap、annot、mask 去上三角

> 变量一多，逐个画散点就太慢了。相关矩阵用一张方阵告诉你"谁和谁有关系"，是探索阶段最快的全局扫描工具。

## 相关矩阵：一眼扫完全部关系

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd
import numpy as np

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

tips = sns.load_dataset('tips')

corr = tips.corr(numeric_only=True)
print(corr)
```

`df.corr()` 默认算的是 **Pearson 相关系数**，取值 -1 到 1：越接近 ±1 线性关系越强，越接近 0 越没线性关系。输出是一个对称方阵——第 i 行第 j 列是变量 i 与 j 的相关。

**翻车现场 1：把相关系数当成因果强度。**

```python
corr.loc['total_bill', 'tip']   # 约 0.68，看起来很强
```

0.68 只说明"账单越高小费越高"的**线性同步程度**，不代表"账单导致小费"。相关矩阵是**线索清单**，不是因果结论。真正有用的是靠它**决定下一步该深挖哪一对**。

## heatmap：把矩阵画成色块

光看数字方阵，十几个变量时眼睛会花。热力图把数值映射成颜色深浅。

```python
fig, ax = plt.subplots(figsize=(7, 6))
sns.heatmap(corr, annot=True, fmt='.2f', cmap='coolwarm',
            vmin=-1, vmax=1, square=True, ax=ax)
ax.set_title('tips 数据相关矩阵')
fig.savefig('heatmap1.png')
```

关键参数：

| 参数 | 作用 |
|---|---|
| `annot=True` | 在每个色块里写数值，必开，否则看不出精确相关 |
| `fmt='.2f'` | 数值格式，两位小数 |
| `cmap='coolwarm'` | 发散型配色，红=正、蓝=负、白=0 |
| `vmin=-1, vmax=1` | 固定两端，保证 0 落在正中间 |
| `square=True` | 每个格子是正方形，矩阵对齐好看 |
| `center=0` | 让 0 值对应 colormap 的中心色 |

**翻车现场 2：用了顺序型 colormap（如 `viridis`）画相关矩阵。**

顺序型配色（黄→紫）没有"中间值=无关"的语义，看起来会暗示"所有变量都是正相关"。**相关矩阵必须用发散型配色**（coolwarm、RdBu_r、seismic），并且固定 `vmin=-1, vmax=1` 让 0 居中。

## mask：去掉重复的上三角

相关矩阵是**对称**的，左下和右上完全一样；对角线永远是 1。画出来一半信息是废话。用 mask 遮掉上三角：

```python
mask = np.triu(np.ones_like(corr, dtype=bool))   # 上三角为 True

fig, ax = plt.subplots(figsize=(7, 6))
sns.heatmap(corr, annot=True, fmt='.2f', cmap='coolwarm',
            vmin=-1, vmax=1, square=True, mask=mask, ax=ax)
ax.set_title('遮掉上三角的相关矩阵')
fig.savefig('heatmap2.png')
```

`np.triu` 取上三角，`np.ones_like(..., dtype=bool)` 生成同形状的布尔矩阵。heatmap 看到 mask 里为 `True` 的位置就**不画**，留下空白。这样信息量立刻减半、可读性翻倍。

## p 值：别只看相关系数大小

相关系数大不一定"显著"，样本量小的时候偶然也能凑出高相关。**要看显著性，得算 p 值**。

```python
from scipy import stats

def corr_pvalues(df):
    cols = df.select_dtypes('number').columns
    n = len(cols)
    pmat = pd.DataFrame(np.zeros((n, n)), index=cols, columns=cols)
    for i in cols:
        for j in cols:
            if i != j:
                r, p = stats.pearsonr(df[i].dropna(), df[j].dropna())
                pmat.loc[i, j] = p
    return pmat

pmat = corr_pvalues(tips)
print(pmat.round(3))
```

`stats.pearsonr` 同时返回相关系数和 p 值。p 值小于 0.05 才说明这个相关"不太可能是随机凑出来的"。**相关系数告诉你关系有多强，p 值告诉你这个强度可不可信**，两个都要看。

**翻车现场 3：只在乎 |r|>0.7，忽略样本量。**

`size` 与 `total_bill` 的相关可能只有 0.6，但 n=244、p 值极小，结论很稳；而某个只有 8 条记录的分组算出来 0.95，好看但不靠谱。**报告里要写清 n 和 p 值**，只报相关系数大小是不专业的。

## 分组相关：控制变量后重算

```python
# 只看午餐时段的账单与小费相关
lunch = tips[tips['time'] == 'Lunch']
print(lunch[['total_bill', 'tip']].corr().loc['total_bill', 'tip'])

# 只看晚餐
dinner = tips[tips['time'] == 'Dinner']
print(dinner[['total_bill', 'tip']].corr().loc['total_bill', 'tip'])
```

同一对相关在不同分组下可能**数值不同**，这本身就是发现——它说明存在一个**调节变量**。相关矩阵不是一次性产物，控制不同条件后要重算。

## 小结

- `df.corr()` 给出 Pearson 相关矩阵，对称且对角为 1
- 热力图必开 `annot=True`，用发散型 colormap 并固定 vmin/vmax
- `mask=np.triu(...)` 去掉重复上三角，可读性翻倍
- 相关系数说"多强"，p 值说"可不可信"，两个都要报
- 相关≠因果，它是**线索清单**
- 控制变量后要重算相关，可能发现调节效应
