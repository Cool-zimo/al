# 为什么要有图：Anscombe 四重奏

> 四组数据，统计量几乎一模一样，画出来却是四个完全不同的故事。这一节回答一个根本问题：为什么算完均值方差还不够，非得画图。

## 先看四组数字

1973 年，统计学家 Francis Anscombe 造了四组人造数据，叫 **Anscombe's quartet（安斯库姆四重奏）**。每组都是 11 个点，都是 (x, y) 两个数。

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

# 四组数据的 (x, y)，共 4 组
data = {
    'I':   [(10.0, 8.04), (8.0, 6.95), (13.0, 7.58), (9.0, 8.81),
            (11.0, 8.33), (14.0, 9.96), (6.0, 7.24), (4.0, 4.26),
            (12.0, 10.84), (7.0, 4.82), (5.0, 5.68)],
    'II':  [(10.0, 9.14), (8.0, 8.14), (13.0, 8.74), (9.0, 8.77),
            (11.0, 9.26), (14.0, 8.10), (6.0, 6.13), (4.0, 3.10),
            (12.0, 9.13), (7.0, 7.26), (5.0, 4.74)],
    'III': [(10.0, 7.46), (8.0, 6.77), (13.0, 12.74), (9.0, 7.11),
            (11.0, 7.81), (14.0, 8.84), (6.0, 6.08), (4.0, 5.39),
            (12.0, 8.15), (7.0, 6.42), (5.0, 5.73)],
    'IV':  [(8.0, 6.58), (8.0, 5.76), (8.0, 7.71), (8.0, 8.84),
            (8.0, 8.47), (8.0, 7.04), (8.0, 5.25), (19.0, 12.50),
            (8.0, 5.56), (8.0, 7.91), (8.0, 6.89)],
}
```

这四组数据的 x 和 y，**基本统计量完全一样**。

## 算一遍统计

```python
import numpy as np

for name, points in data.items():
    xs = [p[0] for p in points]
    ys = [p[1] for p in points]
    # 均值保留两位
    mx, my = round(np.mean(xs), 2), round(np.mean(ys), 2)
    # 样本方差（除以 n-1）
    vx, vy = round(np.var(xs, ddof=1), 2), round(np.var(ys, ddof=1), 2)
    # 相关系数
    r = round(np.corrcoef(xs, ys)[0, 1], 3)
    # 线性回归 y = a + b*x 的斜率 b
    b, a = np.polyfit(xs, ys, 1)
    print(f"{name:>3}: x̄={mx:>5}  ȳ={my:>5}  var(x)={vx:>5}  var(y)={vy:>5}  r={r:>5}  斜率={round(b, 2)}")
```

```
III: x̄=  9.0  ȳ= 7.5  var(x)= 11.0  var(y)= 4.13  r= 0.816  斜率=0.5

```

**均值、方差、相关系数、回归斜率，四组一模一样。** 如果你只报这几个数字，任何人都无法分辨这四组数据。

## 画出来就完全不一样

```python
fig, axes = plt.subplots(2, 2, figsize=(8, 7))

for ax, (name, points) in zip(axes.flat, data.items()):
    xs = [p[0] for p in points]
    ys = [p[1] for p in points]
    ax.scatter(xs, ys, color='#2c7fb8')
    ax.set_title(f'数据集 {name}')
    ax.set_xlabel('x')
    ax.set_ylabel('y')

fig.suptitle("Anscombe's Quartet（安斯库姆四重奏）")
fig.tight_layout()
fig.savefig('anscombe.png')
print('图已保存，用 plt.show() 可查看')
```

四张图的故事完全不同：

| 数据集 | 画出来是什么样 | 讲的什么故事 |
|---|---|---|
| **I** | 正常的散点，大致一条直线 | 典型的正相关，x 越大 y 越大 |
| **II** | 一条清晰的曲线 | **非线性关系**——用直线拟合是错的 |
| **III** | 除了一个点几乎在一条竖线上 | 极端值完全主导了结果，斜率是假象 |
| **IV** | 除了一个离群点全部 x 相同 | 同样是**离群值主导**，去掉它就什么都没了 |

## 关键结论

- **统计量是对数据的压缩，压缩会丢信息**。均值、方差、相关系数把 11 个点压成 4 个数字，必然丢失形状。
- **回归直线是斜率=0.5 这条线**，但只有在数据集 I 上这条直线有意义。在 III、IV 上它是有误导性的。
- **"先看图"应该成为你的习惯**：拿到一份数据，先 `plt.scatter` 或 `df.plot()` 瞄一眼分布，再谈均值和拟合。很多真实项目里的分析错误，都是因为跳过这一步。

## 一个常见误区

> 「我已经算过均值和标准差了，结论很稳定，没必要画图。」

Anscombe 就是专门用来打这种想法的。四组数据的统计量**完全相同**，却描述了四种完全不同的数据生成过程。**同样的均值，可能是正态分布，也可能是一个离群值拉出来的假象**——这两种情况该采取的处理方式截然不同（一个直接建模，一个先剔除或单独分析）。

## 小结

- 均值、方差、相关系数会把数据压成几个数，**必然丢信息**
- Anscombe 四重奏：四组数据的 x̄=9.0、ȳ=7.5、var(x)=11.0、var(y)=4.13、r=0.816、斜率=0.5，全部相同
- 但四张图分别讲「正常线性」「非线性」「离群值主导」「单点绑架」四个故事
- 拿到数据，**先画图再看统计量**，这是避免方向性错误的最低成本动作
