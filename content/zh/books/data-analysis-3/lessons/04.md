# 中文乱码与字体

> 中文显示成方框、负号显示成方块，是每个中国用户的必经之痛。这一节讲清根因和四种解法。

## 先看现象

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

fig, ax = plt.subplots()
ax.plot([1, 2, 3], [1, 2, 3])
ax.set_title('北京门店销售额')
ax.set_xlabel('月份')
ax.savefig('chinese_broken.png')
```

输出（`chinese_broken.png`）：标题和轴标签的位置留着，但**字是方框 □□□**。

为什么？matplotlib 默认的字体是 **DejaVu Sans**，一套**纯英文**字体。它里面没有"北""京""门"这几个字形，找不到就画个豆腐块。

## 解法一：rcParams 全局指定（最常用）

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False      # 让负号正常显示

fig, ax = plt.subplots()
ax.plot([1, 2, 3], [1, 2, 3])
ax.set_title('北京门店销售额')
ax.set_xlabel('月份')
ax.savefig('chinese_ok.png')
print('saved')
```

两行配置解决两个问题：

- `font.sans-serif`：告诉 matplotlib 用哪个字体渲染中文
- `axes.unicode_minus`：解决**负号变成方块**的问题（见下文）

**这组设置建议放在每个脚本的最开头，在所有绘图之前。**

## 翻车现场 1：字体名写错

```python
# WRONG
plt.rcParams['font.sans-serif'] = ['微软雅黑']     # 在某些 Linux 环境下找不到
fig, ax = plt.subplots()
ax.set_title('北京')                                # 依然是方框
```

输出：依然方框，且**不报错**——matplotlib 找不到字体时会静默回退到默认字体。这就是为什么很多人"明明设了字体却没生效"，因为根本没提示。

**排查方法：**

```python
from matplotlib import font_manager
# 列出系统里可用的中文字体名
names = sorted({f.name for f in font_manager.fontManager.ttflist if 'CJK' in f.name or 'Hei' in f.name or 'Song' in f.name or 'Micro' in f.name})
print(names)
```

找到**确切的名字**再填进 `rcParams`。常见可用值：

| 平台 | 可用字体名 |
|---|---|
| Windows | `Microsoft YaHei`（微软雅黑）、`SimHei`（黑体） |
| macOS | `PingFang SC`、`Heiti SC`、`STHeiti` |
| Linux | `WenQuanYi Micro Hei`、`Noto Sans CJK SC` |

**翻车现场 2：写了列表却没用列表。**

```python
# WRONG
plt.rcParams['font.sans-serif'] = 'WenQuanYi Micro Hei'   # 错误：必须传列表
```

输出：字体依然不生效，因为 matplotlib 期望的是**列表**，字符串会被当成字符序列逐个处理。

## 解法二：给单个 Text 对象指定 fontproperties

不想全局改，只想让某个标题用中文字体：

```python
from matplotlib.font_manager import FontProperties

fp = FontProperties(family='WenQuanYi Micro Hei', size=14)
ax.set_title('北京门店销售额', fontproperties=fp)
```

`fontproperties` 是显式传参，优先级高于 `rcParams`。**适合"混排"场景**，比如标题中文、刻度英文。

## 解法三：with 语句临时切换（推荐给函数用）

```python
from matplotlib import rc_context

with rc_context({'font.sans-serif': ['WenQuanYi Micro Hei'],
                 'axes.unicode_minus': False}):
    fig, ax = plt.subplots()
    ax.set_title('北京')
    fig.savefig('tmp.png')
# 离开 with 块后，字体设置自动还原，不影响其他图
```

**这是写工具函数时的最佳实践**——不会污染全局状态，调用方无感知。

## 负号为啥也变方块

`axes.unicode_minus = False` 这个设置看起来莫名其妙。原因：

- 默认情况下 matplotlib 用 **Unicode 减号 `−`（U+2212）** 渲染坐标轴刻度
- 大多数中文字体**不包含这个字符**，于是变成方块
- 设成 `False` 后，matplotlib 改用**普通的 ASCII 减号 `-`（U+002D）**，而 ASCII 减号所有字体都有

```python
fig, ax = plt.subplots()
ax.plot([-1, 0, 1], [-1, 0, 1])
ax.set_title('温度变化')
ax.set_xlabel('ΔT（℃）')
# 不设 axes.unicode_minus = False 的话，刻度的负号会是方块
fig.savefig('minus.png')
```

## 想换别的字体风格

```python
plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']   # 黑体，正式报告
plt.rcParams['font.sans-serif'] = ['Noto Serif CJK SC']     # 衬线体，论文风
plt.rcParams['font.family'] = 'serif'                        # 全局走衬线体
```

字体选择影响观感：

- **黑体（sans-serif）**：屏幕阅读、PPT、网页，清晰醒目
- **衬线体（serif）**：印刷、长篇文档、学术论文，更有质感
- **等宽体（monospace）**：代码、对齐数字

## 小结

- 中文变方框的根因：**默认字体 DejaVu Sans 没有中文字形**
- 最常用解法：`rcParams['font.sans-serif']` + `rcParams['axes.unicode_minus'] = False`
- 字体名必须**确切**，写错不报错（静默回退），用 `font_manager` 查
- `rcParams` 要传**列表**，传字符串无效
- 单元素指定用 `fontproperties=FontProperties(...)`；函数内临时切换用 `rc_context`
- 负号变方块是因为 Unicode 减号，改 `axes.unicode_minus = False` 即可
