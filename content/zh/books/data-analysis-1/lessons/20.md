# 去重与集合运算

> 数据清洗的常客：去掉重复、找出共有、筛出差异。

## unique：去重并排序

```python
import numpy as np

arr = np.array([3, 1, 2, 3, 1])
print(np.unique(arr))     # [1 2 3]
```

**注意：结果会自动排序**。这是 `unique` 的额外福利（也是它的代价——需要排序，比纯去重慢一点）。

### 三个很实用的参数

```python
arr = np.array([3, 1, 2, 3, 1])

vals, counts = np.unique(arr, return_counts=True)
print(vals)       # [1 2 3]   有哪些值
print(counts)     # [2 1 2]   各出现几次
```

**`return_counts` 是做频率统计最快的写法**：

```python
# 统计成绩分布
scores = np.array([85, 90, 85, 70, 90, 90])
vals, counts = np.unique(scores, return_counts=True)
for v, c in zip(vals, counts):
    print(f"  {v} 分：{c} 人")
```

```
70 分：1 人
85 分：2 人
90 分：3 人
```

还有两个：

```python
# 每个唯一值第一次出现的下标
vals, first_idx = np.unique(arr, return_index=True)
print(first_idx)      # [1 3 0]

# 用唯一值重构原数组的下标
vals, inverse = np.unique(arr, return_inverse=True)
print(inverse)        # [2 0 1 2 0]
print(vals[inverse])  # [3 1 2 3 1]  ← 还原了原数组
```

`return_inverse` 在"把类别映射成数字编号"时非常有用（这也是机器学习里编码分类特征的手段）。

### 二维去重

```python
m = np.array([[1, 2],
              [3, 4],
              [1, 2]])

print(np.unique(m, axis=0))    # 按行去重
```

```
[[1 2]
 [3 4]]
```

`axis=0` 表示"把每一行当作一个整体来比较"。**记住要写 axis**，否则会拉平成一维再去重。

## isin：成员判断

**"这个数组里有哪些元素出现在另一个数组里"**：

```python
arr = np.array([1, 2, 3, 4, 5])
targets = np.array([2, 4])

print(np.isin(arr, targets))      # [False  True False  True False]
print(arr[np.isin(arr, targets)]) # [2 4]  直接筛出来
```

**这是"白名单筛选"的标准写法**：

```python
# 只保留重点城市的记录
cities = np.array(['北京', '上海', '广州', '深圳', '杭州'])
key = np.array(['北京', '深圳'])
print(cities[np.isin(cities, key)])      # ['北京' '深圳']
```

> ⚠️ 老代码里你可能看到 `np.in1d(arr, targets)`，它和 `np.isin` 功能一样，但**在 NumPy 2.x 已弃用**，会有 DeprecationWarning。新代码统一用 `np.isin`。

### 取反：不在名单里的

```python
print(arr[~np.isin(arr, targets)])    # [1 3 5]  ← 黑名单
```

`~` 是按位取反，对布尔数组就是"非"。

## 集合运算四件套

```python
a = np.array([1, 2, 3, 4])
b = np.array([3, 4, 5, 6])

print(np.intersect1d(a, b))     # [3 4]        交集（都在）
print(np.union1d(a, b))         # [1 2 3 4 5 6] 并集（去重后合起来）
print(np.setdiff1d(a, b))       # [1 2]        差集（在 a 不在 b）
print(np.setxor1d(a, b))        # [1 2 5 6]    对称差（只在一边的）
```

**这些函数都会去重并排序**。

**典型用途**：

```python
# 找出"上个月有、这个月没了"的客户（流失）
last_month = np.array([101, 102, 103, 104])
this_month = np.array([102, 103, 105])

churned = np.setdiff1d(last_month, this_month)
print("流失客户：", churned)      # [101 104]

new = np.setdiff1d(this_month, last_month)
print("新增客户：", new)          # [105]
```

## 找重复项

`unique` 只告诉你"有哪些值"，想知道"哪些值重复了"要配合 counts：

```python
arr = np.array([1, 2, 2, 3, 3, 3])
vals, counts = np.unique(arr, return_counts=True)
dups = vals[counts > 1]
print("重复出现的值：", dups)      # [2 3]
```

## 实战：清洗一份脏数据

```python
import numpy as np

raw = np.array([85, 90, -1, 85, 999, 70, 90, -1])

# 1. 去掉哨兵值（-1 表示缺失，999 表示录入错误）
valid = raw[~np.isin(raw, [-1, 999])]
print("有效数据：", valid)

# 2. 看有没有重复录入（这一步通常需要保留，所以只统计不删）
vals, counts = np.unique(valid, return_counts=True)
print("出现多次的值：", vals[counts > 1])

# 3. 最终去重后的成绩分布
print("去重后：", vals)
print("各出现：", counts)
```

## 速查

| 需求 | 函数 |
|---|---|
| 去重（并排序） | `np.unique(arr)` |
| 去重 + 计数 | `np.unique(arr, return_counts=True)` |
| 二维按行去重 | `np.unique(arr, axis=0)` |
| 白名单筛选 | `np.isin(arr, targets)` |
| 交集 | `np.intersect1d(a, b)` |
| 并集 | `np.union1d(a, b)` |
| 差集（在 a 不在 b） | `np.setdiff1d(a, b)` |
| 对称差 | `np.setxor1d(a, b)` |
