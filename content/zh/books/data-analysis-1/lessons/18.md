# 重复与铺砖

> `repeat` 和 `tile` 都能"把数组变大"，但方式完全不同。这是面试和实战都常考的一对。

## repeat：逐个复制

**每个元素各自重复 N 次**：

```python
import numpy as np

arr = np.array([1, 2, 3])
print(np.repeat(arr, 2))
```

```
[1 1 2 2 3 3]
```

像把每个元素"抻长"了：`1,2,3` → `1,1,2,2,3,3`。

**也可以给每个元素不同的重复次数**：

```python
arr = np.array([1, 2, 3])
print(np.repeat(arr, [3, 1, 2]))    # 1 重复 3 次，2 重复 1 次，3 重复 2 次
```

```
[1 1 1 2 3 3]
```

**长度必须和原数组一致**，否则报错。

### 二维的 repeat

```python
m = np.array([[1, 2],
              [3, 4]])

print(np.repeat(m, 2, axis=1))   # 沿列方向重复
```

```
[[1 1 2 2]
 [3 3 4 4]]
```

不写 axis 会先拉平再重复：

```python
print(np.repeat(m, 2))    # [1 1 2 2 3 3 4 4]  一维
```

## tile：整体铺砖

**把整个数组当作一块砖，重复铺 N 次**：

```python
arr = np.array([1, 2])
print(np.tile(arr, 3))
```

```
[1 2 1 2 1 2]
```

对比一下，同样的输入 `[1, 2]`：

| 函数 | 结果 | 思路 |
|---|---|---|
| `repeat(arr, 3)` | `[1 1 1 2 2 2]` | 每个元素各自重复 |
| `tile(arr, 3)` | `[1 2 1 2 1 2]` | 整体复制 3 份 |

**记忆法**：`repeat` 是"每个抻长"，`tile` 是"整块复制"。

### 二维的 tile

第二个参数用元组表示"行方向铺几次，列方向铺几次"：

```python
m = np.array([[1, 2],
              [3, 4]])

print(np.tile(m, (2, 1)))    # 上下铺 2 次，左右铺 1 次
```

```
[[1 2]
 [3 4]
 [1 2]
 [3 4]]
```

```python
print(np.tile(m, (1, 3)))    # 上下 1 次，左右 3 次
```

```
[[1 2 1 2 1 2]
 [3 4 3 4 3 4]]
```

## 典型用途

### tile 的用途：造"背景板"

```python
# 想让每一行都减去同一组"基准值"
data = np.array([[10, 20, 30],
                 [40, 50, 60]])
baseline = np.array([1, 2, 3])

# 方法：把 baseline 铺成和 data 一样大
print(data - np.tile(baseline, (2, 1)))
```

不过——**广播能直接做到同样的事，而且更省内存**：

```python
print(data - baseline)     # 推荐！不需要真的铺开
```

> 💡 经验：**能用广播就别用 tile**。`tile` 真的会复制数据，`data - baseline` 不会。在大数据上这个差别很可观。

### repeat 的用途：按权重展开

```python
# 每个商品的销量，想按销量把它展开成一条条记录
counts = np.array([2, 0, 3])      # 三个商品分别卖了 2、0、3 件
product_ids = np.repeat(np.array([0, 1, 2]), counts)
print(product_ids)                # [0 0 2 2 2]
```

这一手在数据展开（unnest）时很实用。

## 另一种重复：np.concatenate 配合列表

如果你想要"整体复制 N 份"且保持多维：

```python
arr = np.array([[1, 2]])
print(np.concatenate([arr] * 3, axis=0))
```

```
[[1 2]
 [1 2]
 [1 2]]
```

`[arr] * 3` 是 Python 的列表重复（注意：对列表用 `*`，得到的是同一个数组的三个引用，但 concatenate 只读不写，所以没问题）。

## 速查

| 需求 | 用 |
|---|---|
| 每个元素重复 N 次 | `np.repeat(arr, N)` |
| 每个元素重复不同次数 | `np.repeat(arr, [n1, n2, ...])` |
| 整体复制 N 份 | `np.tile(arr, N)` |
| 二维数组按行/列铺 | `np.tile(arr, (rows, cols))` |
| 让小数组匹配大数组的形状 | **优先用广播**，别用 tile |
