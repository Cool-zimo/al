# 分割数组

> 拼接的逆操作。除了"均分"和"不均分"的区别，这一课没有太多难点。

## split：均分

```python
import numpy as np

arr = np.arange(6)          # [0 1 2 3 4 5]
print(np.split(arr, 3))     # 分成 3 份
```

```
[array([0, 1]), array([2, 3]), array([4, 5])]
```

**返回的是一个列表**，里面装着若干个数组。

## 关键区别：split 必须整除

```python
np.split(np.arange(5), 3)
# ValueError: array split does not result in an equal division
```

5 个数分 3 份，分不匀，`split` 直接报错。

**用 `array_split` 就不会**：

```python
print(np.array_split(np.arange(5), 3))
```

```
[array([0, 1]), array([2, 3]), array([4])]
```

前两份各 2 个，最后一份 1 个。**`array_split` 允许不均分，把余量分给前面几份**。

> 💡 实战建议：**不确定能不能整除时，一律用 `array_split`**。它永远不会因为这个原因报错。

## 指定分割点

除了"分成几份"，也可以用"在第几个位置切"——传一个**下标列表**：

```python
arr = np.arange(10)
print(np.split(arr, [3, 7]))    # 在下标 3 和 7 处切两刀
```

```
[array([0, 1, 2]), array([3, 4, 5, 6]), array([7, 8, 9])]
```

切成三段：`[0:3]`、`[3:7]`、`[7:]`。

**这个用法在"按阈值切分"时特别有用**，比如把成绩按 60、80 分成三档。

## vsplit 与 hsplit

和 vstack / hstack 对应：

```python
m = np.arange(6).reshape(2, 3)
print(m)
```

```
[[0 1 2]
 [3 4 5]]
```

```python
print(np.vsplit(m, 2))    # 横向切一刀，分成上下两块
print(np.hsplit(m, 3))    # 纵向切两刀，分成左右三块
```

```
vsplit: [array([[0, 1, 2]]), array([[3, 4, 5]])]
hsplit: [array([[0], [3]]), array([[1], [4]]), array([[2], [5]])]
```

**记忆法**：`vsplit` 是"横着切一刀"（把行分开），`hsplit` 是"竖着切"（把列分开）。这个命名确实容易绕——记住 v 对应"垂直方向堆叠的逆操作"，也就是按行分。

## 实战：训练集与测试集切分

机器学习里最常见的切分操作：

```python
data = np.arange(100)
np.random.seed(42)
np.random.shuffle(data)      # 打乱

split_at = int(len(data) * 0.8)
train, test = np.split(data, [split_at])

print(f"训练集 {len(train)} 条，测试集 {len(test)} 条")
```

**`np.split(data, [n])` 是"前 n 个 | 剩下的"最简洁写法**。

（注意 `np.random.shuffle` 是**原地**打乱，会直接改掉 `data`。想要不破坏原数组，用 `np.random.permutation(data)`，它返回打乱后的副本。）

## 常见陷阱

**1. 返回值是列表不是数组。**

```python
parts = np.split(arr, 2)
print(parts[0])        # 要用下标取，不能直接当数组用
print(parts.shape)     # AttributeError: 'list' object has no attribute 'shape'
```

**2. 分割出来的是视图。**

和切片一样，split 的结果共享原数组的内存：

```python
arr = np.arange(6)
parts = np.split(arr, 2)
parts[0][0] = 99
print(arr)      # [99  1  2  3  4  5]  ← 原数组被改了
```

想独立就 `.copy()`。
