# 广播报错怎么读

> 读懂 `shape mismatch`，是 NumPy 从"能用"到"用得顺"的分水岭。

## 先看清报错长什么样

```python
import numpy as np

m = np.array([[1, 2, 3],
              [4, 5, 6]])      # (2, 3)
v = np.array([10, 20])         # (2,)

print(m + v)
```

报错：

```
ValueError: operands could not be broadcast together with shapes (2,3) (2,)
```

**这句话的信息量其实很大**，它把两个操作数的形状直接列出来了：`(2,3)` 和 `(2,)`。

## 拆解报错的三步法

**第一步：把两个形状抄下来，右边对齐。**

```
(2, 3)
(   2)
  ↑  ↑
```

**第二步：短的左边补 1。**

```
(2, 3)
(1, 2)
```

**第三步：从右往左逐位比较。**

```
最右位： 3  vs  2   → 不相等，且都不是 1  → ✗ 失败
```

失败点找到了：**最后一维对不上**。

**修复**：你想让 `v` 作用于"行"方向，就把它变成 `(2, 1)`：

```python
print(m + v.reshape(-1, 1))
```

```
[[11 12 13]
 [24 25 26]]
```

## 常见报错与解法对照表

| 你想做的事 | 错误写法 | 报错形状 | 正确写法 |
|---|---|---|---|
| 给每行加一个值 | `m + v` （v 是 (2,)） | (2,3) vs (2,) | `v.reshape(-1,1)` |
| 给每列加一个值 | `m + v` （v 是 (2,)） | (2,3) vs (2,) | 用长度 3 的 v |
| 两个矩阵相加 | 形状不同 | (2,3) vs (3,2) | 检查是否该转置 `.T` |
| 一维当列用 | `(4,) - (4,1)` | 其实能广播，但结果是 (4,4) | 确认你要的是不是 (4,4) |

**最后一行值得注意**：有些广播"成功"了，但结果不是你想要的。

## 静默错误比报错更危险

```python
a = np.array([1, 2, 3])        # (3,)
b = np.array([[10], [20]])     # (2, 1)

print(a + b)                   # 不报错！结果是 (2, 3)
print((a + b).shape)
```

```
[[11 12 13]
 [21 22 23]]
```

NumPy 认为"你大概是想要所有组合"，于是给了你一个 2×3 的结果。如果你本来只想加 3 个数，这个结果就是错的——**而且完全不提示**。

> 💡 防御习惯：**任何广播运算之后，立刻检查 `.shape`**。花一秒钟，省一小时。

## 调试三板斧

遇到形状问题，按顺序做这三件事：

**1. 打印所有涉及变量的 shape。**

```python
print("m:", m.shape, "v:", v.shape)
```

**2. 手动推演一遍广播规则**（补 1 → 右对齐 → 逐位比）。

**3. 不确定就显式 reshape，别靠猜。**

```python
v_col = v.reshape(-1, 1)     # 明确要列
v_row = v.reshape(1, -1)     # 明确要行
```

## 一个实用的断言习惯

写数据处理代码时，把形状假设写成断言，让错误在第一时间暴露：

```python
def normalize_rows(m):
    assert m.ndim == 2, f"需要二维数组，收到 {m.ndim} 维"
    row_mean = m.mean(axis=1).reshape(-1, 1)
    return m - row_mean
```

这样将来传入一维数组时，会立刻得到一句人话提示，而不是一个莫名其妙的广播结果。

## 关于 axis 的补充

这一章反复出现了 `axis=0` 和 `axis=1`，先给一个够用的理解：

- `axis=0`：**跨行**运算，得到"每一列"的结果（结果少了"行"这一维）
- `axis=1`：**跨列**运算，得到"每一行"的结果（结果少了"列"这一维）

```python
m = np.array([[1, 2, 3],
              [4, 5, 6]])

print(m.sum(axis=0))    # [5 7 9]   每列的和
print(m.sum(axis=1))    # [ 6 15]   每行的和
```

`axis` 的完整讲解在第 3 章，这里先记住"**axis 就是被压缩掉的那一维**"。

## 随堂练习

读一个报错信息，判断问题出在哪。

```quiz
type: choice
q: 报错 "operands could not be broadcast together with shapes (2,3) (2,)" 说明什么？
options:
- 两个数组的数据类型不同
- 形状 (2,) 会被对齐到最后一维，与 (2,3) 的 3 对不上
- 数组太大，内存不够
- 其中一个数组是空的
answer: 1
explain: 广播从右往左对齐：(2,) 补成 (1,2)，最后一位是 2，而 (2,3) 的最后一位是 3，两者不相等且都不是 1，所以失败。想按行广播就用 reshape(-1,1) 变成 (2,1)。
```
