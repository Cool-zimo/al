# 广播机制

> 这是 NumPy 最强大、也最容易绕晕的特性。
> 它的作用是：**让形状不同的数组也能一起运算**。

## 先看一个"不合理"的运算

```python
import numpy as np

arr = np.array([[1, 2, 3],
                [4, 5, 6]])      # 形状 (2, 3)

v = np.array([10, 20, 30])       # 形状 (3,)

print(arr + v)
```

两个形状不同的数组，居然能相加：

```
[[11 22 33]
 [14 25 36]]
```

发生了什么？**`v` 被"复制"成了两行**，然后再逐位置相加：

```
[[1 2 3]      [[10 20 30]
 [4 5 6]]  +   [10 20 30]]   =  [[11 22 33]
                                 [14 25 36]]
```

这个自动复制的过程，就叫**广播（broadcasting）**。

> 💡 关键理解：**NumPy 并不会真的把 v 复制两份存在内存里**。它只是"假装"复制了，实际计算时循环复用同一份数据。所以广播既方便，又不浪费内存。

## 广播的两条规则

**规则一：维度少的，左边补 1。**

```
(3,)        →  (1, 3)
(2, 3)      →  (2, 3)   不变
```

**规则二：从右往左逐维对齐，满足以下任一条件就能广播：**

- 两个维度**相等**，或者
- 其中一个是 **1**（这个维度会被拉伸）

都不满足就报错。

### 一步步看例子

**例 1：(2,3) + (3,)**

```
(2, 3)
(   3)   → 左边补 1 → (1, 3)
           从右往左比：3 vs 3 相等 ✓；2 vs 1 有一个是 1 ✓
           结果形状：(2, 3)
```

**例 2：(2,3) + (2,1)**

```
(2, 3)
(2, 1)
从右往左比：3 vs 1 → 有一个是 1，拉伸成 3 ✓
            2 vs 2 相等 ✓
结果形状：(2, 3)
```

**例 3：(2,3) + (2,)** ← 这个会报错！

```
(2, 3)
(   2)   → 左边补 1 → (1, 2)
           从右往左比：3 vs 2 ← 不相等，且没有一个是 1 ✗
           ValueError!
```

**这是最经典的坑**：你有个 2 行 3 列的矩阵，想给每行加上一个长度为 2 的向量，结果报错。因为 `(2,)` 被对齐到了**最后一个维度（列）**，而不是你以为的"行"。

**解决办法**：显式把它变成列向量 `(2, 1)`：

```python
v = np.array([10, 20])
print(v.shape)              # (2,)
print(v.reshape(-1, 1))     # 变成 (2, 1) 的列
print(arr + v.reshape(-1, 1))
```

## 三种常见广播场景

### 场景一：标量（最简单）

```python
arr = np.array([1, 2, 3])
print(arr + 100)      # [101 102 103]
```

标量形状是 `()`，补成 `(1,)`，再拉伸到 `(3,)`。

### 场景二：行向量 × 矩阵

```python
m = np.array([[1, 2, 3],
              [4, 5, 6]])      # (2, 3)
row = np.array([10, 20, 30])   # (3,) → (1, 3) → (2, 3)

print(m + row)
# 每一列都加上对应的值
```

### 场景三：列向量 × 矩阵

```python
col = np.array([[10],
                [20]])           # (2, 1) → (2, 3)

print(m + col)
# 每一行都加上对应的值
```

**注意 (3,) 和 (2,1) 的区别**：前者广播到"列方向"，后者广播到"行方向"。想清楚你要往哪个方向加。

## 用 np.newaxis 增加维度

不用 reshape，也能凭空加一个维度：

```python
v = np.array([10, 20, 30])

print(v.shape)              # (3,)
print(v[np.newaxis, :].shape)   # (1, 3)  ← 变成行
print(v[:, np.newaxis].shape)   # (3, 1)  ← 变成列
```

`np.newaxis` 就是 `None` 的一个别名，所以你也可以写：

```python
print(v[None, :].shape)     # (1, 3)
print(v[:, None].shape)     # (3, 1)
```

两种写法完全等价，`np.newaxis` 可读性更好。

## 广播的实际价值：少写一层循环

**需求**：一个 3 行 4 列的成绩表，每一行是一个学生，求每个学生减去班级均分后的差值。

不用广播：

```python
scores = np.array([[80, 90, 70, 85],
                   [60, 75, 80, 65],
                   [95, 88, 92, 90]])

class_mean = scores.mean(axis=0)     # 每列的均分，形状 (4,)

# 循环写法
result = np.zeros_like(scores)
for i in range(scores.shape[0]):
    result[i] = scores[i] - class_mean
```

用广播：

```python
result = scores - class_mean     # 一行搞定
```

`(3, 4) - (4,)` → `(4,)` 补成 `(1, 4)` → 拉伸成 `(3, 4)`。每一行都减去了同样的班级均分。

## 什么时候广播会咬人

广播是**静默**的——能广播就广播，不会问你"你确定吗"。

所以当你写错了形状，得到的往往不是报错，而是**一个形状诡异但合法的结果**：

```python
a = np.array([[1, 2, 3]])     # (1, 3)
b = np.array([[1], [2]])      # (2, 1)
print((a + b).shape)          # (2, 3)  ← 合法，但你可能想要的是别的
```

`(1,3)` 和 `(2,1)` 广播出 `(2,3)`。如果你本来只想做个对应位置相加，这个结果就是错的——而且不报错。

> 💡 排查习惯：**做完广播后立刻 `print(result.shape)`**，确认它和你预期的一致。这能挡掉一大半广播相关的 bug。
