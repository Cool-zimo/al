# 实战一：销售数据月度分析

> 第一个完整项目。不讲新函数，只把前五章的东西组合起来解决一个真实问题。

## 需求

一份 12 个月 × 5 个商品的销售数据，要回答四个问题：

1. 全年总销售额是多少？
2. 哪个月卖得最好？
3. 哪个商品贡献最多？
4. 各季度的增长趋势如何？

## 造数据

```python
import numpy as np

np.random.seed(42)
products = ['键盘', '鼠标', '显示器', '耳机', '摄像头']
months = 12

# 每个商品有个"基础销量"，再叠加月度波动
base = np.array([200, 500, 80, 300, 150])        # 各商品基础销量
prices = np.array([199, 89, 1299, 399, 259])     # 各商品单价

sales = np.random.randint(-30, 60, size=(months, 5)) + base
sales = np.clip(sales, 0, None)                  # 销量不能为负
print("销量表（12 个月 × 5 商品）：")
print(sales)
```

**`np.clip(sales, 0, None)`** 把负数截成 0——销量不能是负的。这是个很实用的清洗动作。

## 问题一：全年总销售额

```python
# 销售额 = 销量 × 单价（广播）
revenue = sales * prices
print("各月销售额：", revenue.sum(axis=1))
print("全年总额：", revenue.sum())
```

**这里广播直接生效**：`sales` 是 `(12, 5)`，`prices` 是 `(5,)`，相乘时 prices 被拉伸成 `(12, 5)`。

如果要看每个商品各自的年度销售额：

```python
print("各商品年度销售额：", revenue.sum(axis=0))
```

**axis 的取舍**：
- `sum(axis=1)` → 跨商品加，得到"每月"的总额 → 12 个
- `sum(axis=0)` → 跨月份加，得到"每商品"的总额 → 5 个

## 问题二：哪个月最好

```python
monthly = revenue.sum(axis=1)
best = np.argmax(monthly)
print(f"最好的月份：第 {best + 1} 月，销售额 {monthly[best]:,}")

# 顺便看看最差
worst = np.argmin(monthly)
print(f"最差的月份：第 {worst + 1} 月，销售额 {monthly[worst]:,}")
```

**注意 `+ 1`**：下标从 0 开始，但月份从 1 开始。这个偏移是实战里最常见的低级错误。

## 问题三：哪个商品贡献最多

```python
by_product = revenue.sum(axis=0)
order = np.argsort(by_product)[::-1]      # 降序

print("\n商品贡献排名：")
for rank, i in enumerate(order, 1):
    share = by_product[i] / by_product.sum() * 100
    print(f"  {rank}. {products[i]:<5} {by_product[i]:>10,.0f} 元  ({share:.1f}%)")
```

**`argsort(...)[::-1]` 降序排名 + 占比计算**，这是排行榜的标准写法。

## 问题四：季度趋势

把 12 个月分成 4 个季度：

```python
# reshape 成 (4, 3, 5) → 4 个季度，每季 3 个月，5 个商品
quarterly = revenue.reshape(4, 3, 5)
q_revenue = quarterly.sum(axis=(1, 2))     # 同时跨月和跨商品求和
print("\n各季度销售额：", q_revenue)

growth = np.diff(q_revenue) / q_revenue[:-1] * 100
print("季度环比（%）：", np.round(growth, 1))
```

**`sum(axis=(1, 2))` 可以传元组**，一次对多个维度求和。这比写两次 sum 更清晰。

> ⚠️ `reshape(4, 3, 5)` 要求总数对得上（`4×3×5 = 60 = 12×5`）。**reshape 前最好确认一下**：

```python
assert revenue.size == 4 * 3 * 5, "数据量和季度划分对不上"
```

## 完整报告

```python
import numpy as np

line = "=" * 46
print(line)
print("            年度销售分析报告")
print(line)

print(f"全年总销售额：{revenue.sum():,.0f} 元")
print(f"月均销售额：{monthly.mean():,.0f} 元")
print(f"最好/最差月份：第 {best+1} 月 / 第 {worst+1} 月")
print(f"波动程度（标准差）：{monthly.std():,.0f}")

print("\n商品贡献：")
for rank, i in enumerate(order, 1):
    share = by_product[i] / by_product.sum() * 100
    print(f"  {rank}. {products[i]:<5} {by_product[i]:>10,.0f}  ({share:>5.1f}%)")

print("\n季度走势：")
for q, v in enumerate(q_revenue, 1):
    bar = "█" * int(v / q_revenue.max() * 30)
    print(f"  Q{q}  {v:>10,.0f}  {bar}")
print(line)
```

**那个 `bar` 是纯文本柱状图**：用 `"█" * 数量` 画出长度正比于数值的条形。没有 matplotlib 时，这是最快的可视化手段。

## 复盘：用到的所有东西

| 需求 | 工具 |
|---|---|
| 限制范围 | `np.clip` |
| 销量转金额 | 广播 `sales * prices` |
| 按月/按商品汇总 | `sum(axis=1)` / `sum(axis=0)` |
| 找最好最差 | `argmax` / `argmin` |
| 排名 | `argsort(...)[::-1]` |
| 季度分组 | `reshape` + `sum(axis=(1,2))` |
| 环比 | `diff` / 前一期 |
| 可视化 | 字符串 × 数量 |

**没有一个是新函数**——把学过的东西组合起来，就是"做项目"。

- sum(axis=0)
- sum(axis=1)
- sum(axis=2)
- sum()
answer: 0
explain: axis=0 是"跨行（月份）加"，把 12 个月压成 1 个，剩下 5 个商品各自的年度总量。axis=1 会跨商品加，得到 12 个月的月度总量。口诀：axis=n 就是把第 n 维"压掉"。
