# 文本文件 savetxt / loadtxt

> 需要把数据交给别人、或者用 Excel 打开时，就得用 CSV 这类文本格式。

## savetxt：写出去

```python
import numpy as np

arr = np.array([[1, 2, 3],
                [4, 5, 6]])

np.savetxt('data.csv', arr, delimiter=',', fmt='%d')
```

文件内容：

```
1,2,3
4,5,6
```

**两个最常用的参数**：

| 参数 | 作用 | 常用值 |
|---|---|---|
| `delimiter` | 分隔符 | `','`（CSV）、`'\t'`（TSV，Excel 粘贴友好） |
| `fmt` | 每个数字的格式 | `'%d'` 整数、`'%.2f'` 两位小数 |

### fmt 很重要

不写 fmt 的话，NumPy 会用一长串小数：

```python
np.savetxt('a.csv', np.array([[1, 2.5]]))
```

```
1.000000000000000000e+00 2.500000000000000000e+00
```

很难看。指定 `fmt='%.2f'` 之后：

```python
np.savetxt('b.csv', np.array([[1, 2.5]]), fmt='%.2f')
```

```
1.00 2.50
```

**常用 fmt**：

| 写法 | 效果 |
|---|---|
| `'%d'` | `1` |
| `'%.2f'` | `2.50` |
| `'%.1f'` | `2.5` |
| `'%s'` | 原样字符串 |

### 加表头

```python
np.savetxt('c.csv', arr, delimiter=',', fmt='%d',
           header='语文,数学,英语', comments='')
```

```
语文,数学,英语
1,2,3
4,5,6
```

> ⚠️ **`comments=''` 是关键**。默认情况下 NumPy 会在表头前面加一个 `#`，读回来时虽然会自动跳过，但用 Excel 打开就会看到 `#语文`。设成空字符串就干净了。

## loadtxt：读进来

```python
data = np.loadtxt('data.csv', delimiter=',')
print(data)
```

```
[[1. 2. 3.]
 [4. 5. 6.]]
```

**注意读回来默认是 float**（就算你存的是整数）。要整数得自己转：

```python
data = np.loadtxt('data.csv', delimiter=',', dtype=int)
print(data)      # [[1 2 3] [4 5 6]]
```

### 跳过表头

```python
data = np.loadtxt('c.csv', delimiter=',', skiprows=1)
```

**`skiprows=1` 跳过第一行**。如果文件里有 `#` 开头的注释行，loadtxt 会**自动忽略**，不需要 skiprows。

### 只读某几列

```python
# 只要第 0 列和第 2 列
data = np.loadtxt('data.csv', delimiter=',', usecols=(0, 2))
```

### 读成字符串

```python
# 文件里含中文或文字时
data = np.loadtxt('zh.csv', delimiter=',', dtype=str, encoding='utf-8')
```

**`encoding='utf-8'` 处理中文**，否则可能报 `UnicodeDecodeError`。

## 一个完整例子

```python
import numpy as np

# 造数据
np.random.seed(0)
scores = np.random.randint(50, 101, size=(5, 3))

# 存（带表头、整数格式）
np.savetxt('scores.csv', scores, delimiter=',', fmt='%d',
           header='语文,数学,英语', comments='')

# 读（跳过表头）
loaded = np.loadtxt('scores.csv', delimiter=',', skiprows=1, dtype=int)
print(loaded)
print("平均分：", loaded.mean(axis=0))
```

## loadtxt 的两个限制

**1. 不能有缺失值。**

文件里如果出现空字段：

```
1,2
3,
```

`loadtxt` 会报 `ValueError: could not convert string to float`。**有缺失值要用下一课的 `genfromtxt`。**

**2. 每行列数必须一致。**

```
1,2,3
4,5
```

会报 `ValueError: the number of columns changed from 3 to 2 at row 2`。

## 什么时候用文本格式

| 场景 | 用 |
|---|---|
| 纯 Python 内部流转 | `np.save` / `np.load`（npy） |
| 给人看、给 Excel | `savetxt` / `loadtxt`（CSV） |
| 有多个数组要打包 | `savez`（npz） |
| 数据里有缺失 | `genfromtxt` 读 |

## 随堂练习

写出去再读回来，注意表头的处理。

```quiz
type: code
q: 把数组存成带表头的 CSV，再跳过表头读回来，打印读到的数组
starter: |
  import numpy as np
  
  arr = np.array([[1, 2], [3, 4]])
  
  # 存：header='a,b'，comments=''（避免加 #），fmt='%d'，delimiter=','
  np.savetxt('t.csv', arr, delimiter=',', fmt='%d',
             header='a,b', comments='')
  
  # 读：skiprows=1 跳过表头，dtype=int
  # 打印读回来的数组，应该是 [[1 2] [3 4]]
  
  print("在这里改")
tests:
- assert "[[1 2]" in __out
- assert "[3 4]]" in __out
hint: print(np.loadtxt('t.csv', delimiter=',', skiprows=1, dtype=int))。skiprows=1 跳过表头行，dtype=int 让读回来是整数而不是默认的 float。
explain: 这是 CSV 读写的完整闭环：写的时候用 comments='' 去掉 # 号、用 fmt 控制格式；读的时候用 skiprows 跳过表头、用 dtype 指定类型。缺了任何一步，结果都不是你想要的。
```
