# 创建数组的六种方式

> 手工写 `np.array([1,2,3])` 只是入门。真正用起来，你更需要"凭空造出一堆数"。

## 先记住这个约定

全世界写 NumPy 的人都用这一行开头：

```python
import numpy as np
```

**为什么要用 `np` 这个简称？** 没有强制，但它是约定俗成的。你看到别人的代码、查到的答案，几乎全是 `np.`。跟着用，代码才好交流。

本课程所有代码都假设你写了这一行。

## 方式一：从列表转换 np.array()

最基础的一种：

```python
arr = np.array([1, 2, 3, 4, 5])
print(arr)        # [1 2 3 4 5]
```

嵌套列表会变成二维数组：

```python
matrix = np.array([[1, 2, 3],
                   [4, 5, 6]])
print(matrix)
print(matrix.shape)    # (2, 3)  ← 2 行 3 列
```

注意**外面那一层方括号**，以及每一行的元素个数必须一致，否则会得到一个奇怪的 dtype（object）或者报错。

## 方式二：全零 np.zeros()

```python
print(np.zeros(5))           # [0. 0. 0. 0. 0.]
print(np.zeros((2, 3)))      # 2 行 3 列的全零矩阵
```

**注意参数是元组**：`np.zeros((2, 3))`，两层括号。写成 `np.zeros(2, 3)` 会报错，因为 NumPy 会把 3 当成 dtype 参数。

这是新手最常犯的错之一。记住：**形状永远用元组传，所以要双括号。**

默认值是 float（所以显示 `0.`）。想要整数：

```python
print(np.zeros(5, dtype=int))    # [0 0 0 0 0]
```

**典型用途**：先开一块空间，后面再往里填。

## 方式三：全一 np.ones()

```python
print(np.ones(4))          # [1. 1. 1. 1.]
print(np.ones((3, 2)))     # 3 行 2 列
```

还有个变体 `np.full()`，用任意值填充：

```python
print(np.full(4, 7))       # [7 7 7 7]
```

## 方式四：等差序列 np.arange()

**这是最像 `range()` 的一个**：

```python
print(np.arange(5))        # [0 1 2 3 4]
print(np.arange(2, 8))     # [2 3 4 5 6 7]    起点 2，不含 8
print(np.arange(0, 10, 2)) # [0 2 4 6 8]      步长 2
```

**和 `range()` 一样：含左不含右。**

一个区别：`arange` 可以用小数步长，`range` 不行：

```python
print(np.arange(0, 1, 0.2))    # [0.  0.2 0.4 0.6 0.8]
```

> ⚠️ 用小数步长时要小心浮点精度。下面这个例子到底生成几个数，可能和你想的不一样：`np.arange(0, 1, 0.1)`。涉及精确个数时，用方式五的 `linspace` 更稳。

## 方式五：等分区间 np.linspace()

**"在 a 和 b 之间，等分成 n 个数"**：

```python
print(np.linspace(0, 1, 5))     # [0.   0.25 0.5  0.75 1.  ]
print(np.linspace(0, 10, 6))    # [ 0.  2.  4.  6.  8. 10.]
```

**关键区别：`linspace` 是"含右"的**（首尾都包括），`arange` 是"不含右"的。

| | 参数含义 | 是否含终点 |
|---|---|---|
| `arange(start, stop, step)` | 步长 | ❌ 不含 |
| `linspace(start, stop, num)` | 个数 | ✅ 含 |

**画图时用 linspace**。比如画 sin 曲线，要 x 轴上取 100 个等距点：

```python
x = np.linspace(0, 6.28, 100)
```

## 方式六：随机数

做数据分析，随机数用得极多（模拟数据、抽样、初始化）。

```python
# 0~1 之间的随机小数
print(np.random.random(5))

# 标准正态分布（均值 0，标准差 1）
print(np.random.randn(5))

# 指定范围的随机整数：1~100 之间取 5 个（不含 101）
print(np.random.randint(1, 101, 5))
```

> 💡 **可复现很重要**：做实验时，你希望每次跑出一样的随机数，否则没法调试。用 `np.random.seed()` 定一个种子：
> ```python
> np.random.seed(42)
> print(np.random.randn(3))    # 每次跑都一样
> ```
> 种子值写什么都行（42 是程序员的传统玩笑数字），关键是**同一个种子给出同一串随机数**。

## 两个特殊矩阵

```python
# 单位矩阵（对角线是 1）
print(np.eye(3))

# 对角矩阵
print(np.diag([1, 2, 3]))
```

线性代数里常用，做数据分析偶尔碰到。

## 一张速查表

| 函数 | 作用 |
|---|---|
| `np.array(list)` | 从列表转换 |
| `np.zeros(n)` | 全 0 |
| `np.ones(n)` | 全 1 |
| `np.full(n, v)` | 全是 v |
| `np.arange(a, b, s)` | 等差（不含终点） |
| `np.linspace(a, b, n)` | 等分（含终点） |
| `np.random.random(n)` | 0~1 随机 |
| `np.random.randn(n)` | 正态分布随机 |
| `np.random.randint(a, b, n)` | 随机整数 |
| `np.eye(n)` | 单位矩阵 |
