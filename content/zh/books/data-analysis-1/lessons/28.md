# 实战三：图像即数组

> 一张彩色图片，本质上就是一个三维数组。这一课会让你对"多维数组"的理解彻底落地。

## 图像的三层结构

一张 1080×1920 的彩色照片，在 NumPy 里是：

```python
img.shape    # (1080, 1920, 3)
```

| 维度 | 含义 | 大小 |
|---|---|---|
| 第 0 维 | **行 / 高度**（y） | 1080 |
| 第 1 维 | **列 / 宽度**（x） | 1920 |
| 第 2 维 | **通道**（RGB） | 3 |

记住顺序：**高 × 宽 × 通道**，不是宽 × 高。

```python
import numpy as np

# 造一张 4×6 的"小图片"，值从 0 到 255
np.random.seed(0)
img = np.random.randint(0, 256, size=(4, 6, 3), dtype=np.uint8)
print("形状：", img.shape)
print("第一个像素：", img[0, 0])       # [R G B]
```

**每个像素是 3 个数字**：红、绿、蓝的强度，各 0~255。

## 取一个像素

```python
print(img[0, 0])        # 第 0 行第 0 列的 RGB
print(img[2, 3])        # 第 2 行第 3 列
```

**`img[y, x]`** —— 先写行（纵向第几行），再写列（横向第几列）。这和数学里的 (x, y) 相反，**是最容易搞混的地方**。

## 裁剪：切一块出来

```python
crop = img[1:3, 2:5]      # 行 1~2，列 2~4
print(crop.shape)         # (2, 3, 3)
```

**前两个维度是位置，第三个维度不动**——所以裁剪时只写前两个切片，通道自动全部保留。

想只保留某个区域的所有信息，什么都不写就是全取：

```python
top_half = img[:2]        # 前两行（上半部分），等价于 img[:2, :, :]
```

## 通道操作

```python
print("红色通道：\n", img[:, :, 0])
print("绿色通道：\n", img[:, :, 1])
print("蓝色通道：\n", img[:, :, 2])
```

**`img[:, :, n]` 取出第 n 个通道的整张灰度图**。

### 只留红色：把绿蓝清零

```python
red_only = img.copy()
red_only[:, :, 1:] = 0        # 绿色和蓝色通道全设 0
print(red_only[0, 0])         # [R, 0, 0]
```

**注意用了 `.copy()`**——否则会改掉原图（切片是视图，上一本书讲过）。

### 通道增益：调色

```python
# 让画面偏暖：红色 ×1.2，蓝色 ×0.8
warm = (img.astype(float) * np.array([1.2, 1.0, 0.8])).clip(0, 255).astype(np.uint8)
print(warm[0, 0])
```

**广播在这里特别自然**：`(4, 6, 3)` × `(3,)` —— 那个 `(3,)` 的增益向量自动作用到每一个像素。

**两个关键的类型处理**：

1. **`astype(float)` 必须在乘法前**。`uint8` 做乘法会**溢出绕回**（200 × 1.2 = 240，但 250 × 1.2 = 300 → 绕回成 44）
2. **算完要 `clip(0, 255)` 再转回 `uint8`**，否则超出 0~255 的值没有意义

> ⚠️ **uint8 的溢出陷阱是图像处理的头号 bug**。凡是做加减乘除，先转 float。

## 转灰度

三种常见方法：

```python
# 方法一：三通道平均（简单但不准）
gray1 = img.mean(axis=2)

# 方法二：加权平均（符合人眼感知）
weights = np.array([0.299, 0.587, 0.114])
gray2 = (img.astype(float) * weights).sum(axis=2)

print("平均法：", np.round(gray1[0], 1))
print("加权法：", np.round(gray2[0], 1))
```

**方法二更符合人眼**——人眼对绿色最敏感，所以绿色权重 0.587 最高，蓝色最低。

## 翻转与旋转

```python
print("上下翻转：", img[::-1].shape)
print("左右翻转：", img[:, ::-1].shape)
print("旋转 90°：", np.rot90(img).shape)       # 注意 shape 会变
```

**切片 `[::-1]` 是最快的翻转方式**，比任何函数都快（它只是改变了读取步长，不搬动数据）。

> ⚠️ `np.rot90` 会改变形状：`(4, 6, 3)` 变成 `(6, 4, 3)`。写代码时别假设形状不变。

## 实战：给图片加边框

```python
import numpy as np

np.random.seed(0)
img = np.random.randint(100, 200, size=(4, 6, 3), dtype=np.uint8)

# 造一张白色画布，把原图贴到中间
h, w = img.shape[:2]
canvas = np.full((h + 2, w + 2, 3), 255, dtype=np.uint8)   # 全白
canvas[1:-1, 1:-1] = img                                    # 中间贴原图

print("画布形状：", canvas.shape)
print("边框（第0行）：", canvas[0])
print("原图位置：", canvas[1, 1])
```

**`np.full(shape, 值, dtype)` 造一张纯色画布**，再用切片赋值贴上去——这就是"加边框"的全部原理。

## 为什么这一课重要

学完这个，你会明白：

- **三维数组不是抽象概念**，它就是"一堆位置，每个位置有若干属性"
- 图像如此，视频是四维（帧 × 高 × 宽 × 通道），一批图像是五维
- 所有你在图像上做的操作，都是切片 + 广播 + 聚合

**下一课讲性能，会用图像这种大数据量场景来实测。**
