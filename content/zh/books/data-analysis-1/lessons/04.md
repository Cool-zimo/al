# 数组的基本运算

> 数组把 `+ - * /` 全都改了意思。搞清楚这套新规则，后面才能顺畅。

## 与标量运算：每个元素都算一遍

```python
import numpy as np
arr = np.array([1, 2, 3, 4])

print(arr + 10)     # [11 12 13 14]
print(arr * 2)      # [ 2  4  6  8]
print(arr ** 2)     # [ 1  4  9 16]
print(arr / 2)      # [0.5 1.  1.5 2. ]
```

**标量会"广播"到每个元素上**。写 `arr + 10`，意思是"每个元素都加 10"。

这个特性叫**广播（broadcasting）**，第 2 章会详细讲。现在先享受它带来的便利。

**原数组不变**——上面这些运算都返回新数组：

```python
arr = np.array([1, 2, 3])
arr + 10
print(arr)          # [1 2 3]  ← 没变！

arr = arr + 10      # 想保留就得重新赋值
print(arr)          # [11 12 13]
```

## 数组与数组：逐元素

```python
a = np.array([1, 2, 3])
b = np.array([10, 20, 30])

print(a + b)        # [11 22 33]
print(b - a)        # [ 9 18 27]
print(a * b)        # [10 40 90]
print(b / a)        # [10. 10. 10.]
```

**全是"对应位置"运算**，不是矩阵乘法（矩阵乘法用 `@` 或 `np.dot()`，后面会遇到）。

形状必须相同，否则报错：

```python
a = np.array([1, 2, 3])
b = np.array([1, 2])
a + b     # ValueError: operands could not be broadcast together
```

## 一个经典陷阱：除法

```python
a = np.array([1, 2, 3])
b = np.array([0, 2, 4])

print(a / b)
```

```
[ inf 1.   0.75]
```

**除以 0 不报错**，得到 `inf`（无穷大），同时会打印一条 RuntimeWarning。

NumPy 的哲学是"继续算下去，别中断"。这在做数据分析时其实挺合理——你不想因为一个坏数据就整个崩掉。但也意味着**坏值会悄悄传播**：

```python
print(np.sum(a / b))     # inf  ← 一个 inf 污染了整个求和
```

想避免，得先过滤掉 0：

```python
b_safe = np.where(b == 0, 1, b)    # 把 0 换成 1
print(a / b_safe)                  # [1.  1.  0.75]
```

## 比较运算：得到布尔数组

```python
arr = np.array([1, 5, 3, 8, 2])
print(arr > 3)      # [False  True False  True False]
```

**返回的不是 True/False，而是一个布尔数组**——每个位置的比较结果。这是 NumPy 筛选数据的核心手段（第 3 章会大量使用）。

配合 `np.sum()` 可以数出"有几个满足条件"（因为 True 会当成 1）：

```python
print(np.sum(arr > 3))      # 2  ← 有 2 个数大于 3
```

判断是否"全部/任一满足"：

```python
print(np.all(arr > 0))      # True   所有元素都 > 0
print(np.any(arr > 7))      # True   存在元素 > 7
```

> ⚠️ 注意：不能写 `if arr > 3:`。布尔数组有多个值，Python 不知道该按哪个判断，会报 "ambiguous"。要写 `if np.all(arr > 3):` 或 `np.any(...)`。

## 常用数学函数

这些函数也都会"逐元素"作用：

```python
arr = np.array([1, 4, 9, 16])

print(np.sqrt(arr))     # [1. 2. 3. 4.]    开方
print(np.abs(arr))      # 绝对值
print(np.exp(arr))      # e 的 x 次方
print(np.log(arr))      # 自然对数
print(np.round(arr))    # 四舍五入
```

以及三角函数 `np.sin()`、`np.cos()`（参数是弧度，不是角度）。

## 聚合：把一堆数变成一个

```python
arr = np.array([3, 1, 4, 1, 5, 9, 2, 6])

print(np.sum(arr))      # 31   求和
print(np.mean(arr))     # 3.875 平均
print(np.max(arr))      # 9    最大
print(np.min(arr))      # 1    最小
print(np.std(arr))      # 标准差
print(np.argmax(arr))   # 5    最大值的下标（第 6 个）
```

**`argmax` 返回的是位置不是值**——这是新手常混淆的一点。想拿到最大值本身用 `np.max()`，想知道"第几个最大"用 `np.argmax()`。

也可以写成方法形式，两者等价：

```python
print(arr.sum())    # 同 np.sum(arr)
print(arr.mean())   # 同 np.mean(arr)
```

## 数学常数

```python
print(np.pi)     # 3.14159...
print(np.e)      # 2.71828...
```

画图时生成 sin 曲线的 x 轴：

```python
x = np.linspace(0, 2 * np.pi, 100)
y = np.sin(x)
print(y[:5])     # 看看前 5 个值
```

## 运算速查

| 写法 | 含义 |
|---|---|
| `arr + 5` | 每个元素加 5 |
| `a + b` | 对应位置相加 |
| `a * b` | 对应位置相乘（**不是**矩阵乘法） |
| `a @ b` | 矩阵乘法 |
| `arr > 3` | 布尔数组 |
| `np.sum(arr)` | 求和 |
| `np.argmax(arr)` | 最大值的**下标** |

## 随堂练习

用比较运算筛选出满足条件的数据个数。

```quiz
type: code
q: 数一数数组里有几个数大于 5，打印这个个数
starter: |
  import numpy as np
  
  arr = np.array([2, 7, 1, 9, 4, 6, 3])
  
  # 提示：arr > 5 会得到布尔数组
  # np.sum(布尔数组) 会把 True 当 1 来数
  # 答案应该是 3（7、9、6）
  
  print("在这里改")
tests:
- assert "3" in __out
hint: print(np.sum(arr > 5))。True 在求和时被当作 1，False 当作 0，所以求和结果就是"有几个满足"。
explain: "比较 + 求和"是 NumPy 里统计计数的标准套路，比写循环简洁得多。这个组合在数据分析里出现频率极高 —— 数异常值、数达标数、数缺失值，全是它。
```
