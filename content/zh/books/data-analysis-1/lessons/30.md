# 从 NumPy 到 pandas

> 这一课是《数据分析 1》的终点，也是《数据分析 2》的起点。我会明确告诉你：**NumPy 能做什么，做不到什么**。

## NumPy 擅长什么

**同类数据的批量数值计算**。当你的数据是"一个大方阵，每个格子是同类型的数字"时，NumPy 无可匹敌：

```python
import numpy as np

# 一百万个数的统计：瞬间完成
big = np.random.rand(1_000_000)
print(big.mean(), big.std(), big.min(), big.max())
```

优势总结：

| 优势 | 说明 |
|---|---|
| **快** | 底层 C 实现，向量化比 Python 循环快几十倍 |
| **省内存** | 一个 100 万 float64 数组只占 8 MB |
| **数学能力强** | 广播、线性代数、傅里叶变换、随机数 |
| **通用** | 是 pandas、scikit-learn、SciPy 的共同底座 |

## NumPy 不擅长什么

### 1. 每列类型不同的表格数据

```python
# 真实的学生表：姓名（文字）+ 年龄（整数）+ 成绩（小数）
data = np.array([['张三', '18', '89.5'],
                 ['李四', '19', '92.0']], dtype=str)
print(data)
print(data.dtype)      # <U... 全是字符串！
```

**NumPy 要求所有元素同类型**，所以数字被迫变成字符串。你想算平均分，得手动转：

```python
scores = data[:, 2].astype(float)     # 每列都要手动转
print(scores.mean())
```

**每加一列就要多一次转换**，很快就会失控。

> 💡 pandas 的 `DataFrame` 天生支持"每列一个类型"，这才是表格数据该有的样子。

### 2. 带标签的索引

```python
scores = np.array([89, 92, 78])
# 谁是张三的成绩？只能靠"第 0 个"这个位置
print(scores[0])
```

**NumPy 只有位置，没有名字**。你得自己维护一个"下标 → 姓名"的映射，容易错位。

pandas 可以直接写 `df.loc['张三', '数学']`。

### 3. 缺失值的优雅处理

我们在第 3 章学过 `nanmean`、`nanstd`……**每一类函数都要记得用 nan 版本**，很容易漏：

```python
arr = np.array([1.0, np.nan, 3.0])
print(arr.mean())        # nan  ← 忘了用 nanmean
print(np.nanmean(arr))   # 2.0  ← 对了
```

pandas 把缺失当作一等公民，`df.mean()` 默认就跳过 nan。

### 4. 分组、连接、透视

```python
# 想按班级分组算平均分 —— NumPy 要写不少代码
classes = np.array(['A', 'A', 'B', 'B'])
scores = np.array([80, 90, 70, 85])

for c in np.unique(classes):
    print(c, scores[classes == c].mean())
```

简单的分组还能手写，**但一旦要"按两列分组、算三个指标的均值、再排序"，NumPy 代码会迅速膨胀**。

pandas 一行：`df.groupby('班级')['成绩'].mean()`。

## 对照表

| 需求 | NumPy | pandas |
|---|---|---|
| 百万级数值计算 | ✅ 最快 | ⚠️ 稍慢（底层还是 NumPy） |
| 每列不同类型的表 | ❌ 别扭 | ✅ 天生支持 |
| 按名字取行列 | ❌ 只有位置 | ✅ `loc` / 列名 |
| 缺失值 | ⚠️ 要记得用 nan 版函数 | ✅ 默认跳过 |
| 分组聚合 | ⚠️ 手写循环 | ✅ `groupby` |
| 表连接（join） | ❌ 非常麻烦 | ✅ `merge` |
| 时间序列索引 | ❌ | ✅ 专门支持 |
| 矩阵/线性代数 | ✅ `linalg` | ⚠️ 不擅长 |

## 它们不是替代关系

**重要认知：pandas 是建立在 NumPy 之上的。**

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({'成绩': [80, 90, 70]})
print(type(df['成绩'].values))      # <class 'numpy.ndarray'>
```

**pandas  Series 的 `.values` 就是 NumPy 数组**。你在《数据分析 1》学的所有东西——广播、轴、布尔索引、ufunc——**在 pandas 里全部照用**。

所以这门课不是"学完就被替代了"，而是**打地基**。学了 NumPy 再学 pandas，你会发现自己已经在用底层的思维理解它。

## 什么时候坚持用 NumPy

即便学了 pandas，这些场景 NumPy 依然是首选：

1. **纯数值的大规模计算**（矩阵运算、信号处理、图像处理）
2. **给机器学习算法喂数据**（sklearn 接受 numpy 数组）
3. **需要极致性能的内层循环**
4. **科学计算**（微分方程、傅里叶变换、随机数模拟）

## 随堂练习

看看 NumPy 处理混合类型有多别扭。

```quiz
type: choice
q: 用 np.array 把 ['张三', 18, 89.5] 放进同一个数组，会发生什么？
options:
- 各元素保持自己的类型
- 全部被转成统一的字符串类型
- 报错
- 自动变成 object 类型并保留各自类型
answer: 1
explain: NumPy 要求所有元素同类型，混合类型会统一转成"能容纳所有值"的类型 —— 这里是字符串。所以数字 18 变成 '18'，你必须手动 astype 才能算平均分。这正是 pandas 存在的理由：DataFrame 每列一个类型。
```
