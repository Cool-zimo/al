# 广播实战

> 规则懂了，来看它在真实场景里怎么用。这一课两个案例：**数据标准化**和**距离矩阵**。

## 案例一：数据标准化（z-score）

**需求**：一份成绩表，3 个学生 × 4 门课。每门课的难度不同（有的课大家都 90 分，有的课大家都 60 分），直接比总分不公平。

**标准化**的思路：把每门课的成绩，转换成"距离这门课均分有几个标准差"。

公式：`z = (x - mean) / std`

```python
import numpy as np

scores = np.array([[80, 90, 70, 85],
                   [60, 75, 80, 65],
                   [95, 88, 92, 90]])

# 每门课（每一列）的均分和标准差
mean = scores.mean(axis=0)      # 形状 (4,)
std = scores.std(axis=0)        # 形状 (4,)

# 广播：每一行都减去同样的列均分
z = (scores - mean) / std

print("均分：", mean)
print("标准差：", std)
print("标准化后：")
print(z)
```

**广播在这里做了什么**：`scores` 是 `(3, 4)`，`mean` 是 `(4,)`。后者补成 `(1, 4)`，再拉伸成 `(3, 4)`——相当于对每个学生，都减去"这门课的均分"。

**没有广播的话**，你得写一个双层循环：

```python
z = np.zeros_like(scores, dtype=float)
for i in range(scores.shape[0]):
    for j in range(scores.shape[1]):
        z[i, j] = (scores[i, j] - mean[j]) / std[j]
```

五行变一行，而且快得多。

### 顺便：按行标准化

如果想看"每个学生内部，哪门课相对最强"，就要按行算：

```python
row_mean = scores.mean(axis=1)          # 形状 (3,)
row_mean_col = row_mean.reshape(-1, 1)  # 变成 (3, 1)

z_row = (scores - row_mean_col) / scores.std(axis=1).reshape(-1, 1)
```

**注意必须 reshape 成 `(3, 1)`**。因为 `scores` 是 `(3, 4)`，而 `row_mean` 是 `(3,)` ——后者会被对齐到列方向，导致报错（上一课讲过）。

## 案例二：距离矩阵

**需求**：有 4 个二维坐标点，算出它们两两之间的距离，得到一个 4×4 的矩阵。

```python
points = np.array([[0, 0],
                   [3, 4],
                   [6, 8],
                   [1, 1]])
```

**循环写法**（最直观但最慢）：

```python
n = len(points)
dist = np.zeros((n, n))
for i in range(n):
    for j in range(n):
        dist[i, j] = np.sqrt(np.sum((points[i] - points[j]) ** 2))
```

**广播写法**：利用"行向量 - 列向量 = 矩阵"这个技巧。

```python
# 取出所有 x 和 y
xs = points[:, 0].reshape(-1, 1)    # (4, 1) 列向量
ys = points[:, 1].reshape(-1, 1)    # (4, 1) 列向量

# 列向量 - 行向量 → 广播成 (4, 4)
dx = xs - xs.T      # xs.T 是 (1, 4)
dy = ys - ys.T

dist = np.sqrt(dx ** 2 + dy ** 2)
print(dist)
```

**关键技巧**：`(4, 1) - (1, 4)` 会广播成 `(4, 4)`，其中第 `i` 行第 `j` 列 = `xs[i] - xs[j]`。

```
xs      (4,1)          xs.T   (1,4)        结果 (4,4)
[0]                                       [0-0  0-3  0-6  0-1]
[3]      -      [0  3  6  1]      =       [3-0  3-3  3-6  3-1]
[6]                                       [6-0  6-3  6-6  6-1]
[1]                                       [1-0  1-3  1-6  1-1]
```

**"列向量减行向量"是生成所有组合的标准套路**，在图像处理、相似度计算里到处都是。

更简洁的写法（一次搞定）：

```python
# 利用 (4,1,2) - (1,4,2) → (4,4,2) 的三维广播
diff = points[:, np.newaxis, :] - points[np.newaxis, :, :]
dist = np.sqrt((diff ** 2).sum(axis=-1))
```

这一行有点烧脑，但它做的事很清晰：
1. `points[:, None, :]` 形状 `(4, 1, 2)`
2. `points[None, :, :]` 形状 `(1, 4, 2)`
3. 相减广播成 `(4, 4, 2)`——第 `[i, j, :]` 是"点 i 减点 j 的坐标差"
4. 平方求和再开方

## 案例三：给图片加滤镜

图像在 NumPy 里是三维数组 `(高, 宽, 通道)`。想给每个通道不同的亮度增益：

```python
# 假设 img 形状是 (100, 200, 3)
gain = np.array([1.2, 1.0, 0.8])    # 红绿蓝三个通道的增益
bright = img * gain                  # (100,200,3) * (3,) → 自动对齐到最后一维
```

**为什么能直接乘？** 因为广播规则是"从右往左对齐"——`(3,)` 正好对齐到通道那一维。`gain` 会被拉伸成 `(100, 200, 3)`。

## 广播实战三句话

1. **按列统一处理**（如每门课的均分）：用形状 `(n,)`，直接广播
2. **按行统一处理**（如每个学生的均分）：必须先 reshape 成 `(n, 1)`
3. **生成所有两两组合**：列向量 `(n,1)` 减（或加）行向量 `(1,n)`
