# 完整流程：从文件到报告

> 这一课把前四课串成一条流水线。真实工作里，你每天做的就是这件事。

## 场景

一份销售数据 CSV：4 个城市 × 12 个月的销售额，其中有缺失和异常值。要产出一份分析报告。

## 第一步：造一份"脏"数据

```python
import numpy as np

np.random.seed(42)
sales = np.random.randint(100, 1000, size=(12, 4)).astype(float)

# 制造真实感：3 处缺失、-1 表示录入错误
sales[2, 1] = np.nan
sales[7, 3] = np.nan
sales[5, 2] = -1

np.savetxt('sales.csv', sales, delimiter=',', fmt='%.0f',
           header='北京,上海,广州,深圳', comments='')
print("已生成 sales.csv")
```

## 第二步：读进来，先别急着算

```python
raw = np.genfromtxt('sales.csv', delimiter=',', skip_header=1)
print("形状：", raw.shape)
print("缺失数量：", np.sum(np.isnan(raw)))
```

**先看形状、看缺失，再动手。** 这一步能避免后面所有"结果不对但不知道为什么"。

## 第三步：清洗

```python
# 1. 把哨兵值 -1 变成 nan（让它和真缺失统一处理）
clean = raw.copy()
clean[clean == -1] = np.nan

# 2. 再数一次
print("清洗后缺失：", np.sum(np.isnan(clean)))

# 3. 用每列（每个城市）的均值填补
col_mean = np.nanmean(clean, axis=0)
inds = np.where(np.isnan(clean))
if len(inds[0]):
    clean[inds] = np.take(col_mean, inds[1])

print("填补后还有缺失吗：", np.any(np.isnan(clean)))
```

**三个动作**：哨兵值 → nan、数一数、按列均值填补。

> 💡 为什么用**列**均值而不是全表均值？因为不同城市的量级差别很大，用全表均值会把上海的数据往北京的水平上拉。按列填更合理。

## 第四步：统计

```python
cities = ['北京', '上海', '广州', '深圳']

print("\n各城市年度总额：")
totals = clean.sum(axis=0)
for name, t in zip(cities, totals):
    print(f"  {name}：{t:,.0f}")

print("\n各城市月均：")
print("  ", np.round(clean.mean(axis=0), 1))

print("\n波动最大（标准差）的城市：")
stds = clean.std(axis=0)
print(f"  {cities[np.argmax(stds)]}：{stds.max():.1f}")
```

## 第五步：找亮点

```python
# 哪个月卖得最好（按全公司总量）
monthly = clean.sum(axis=1)
best_month = np.argmax(monthly)
print(f"\n最好的月份：第 {best_month + 1} 月，总额 {monthly[best_month]:,.0f}")

# 每个城市最好的月份
best_months = np.argmax(clean, axis=0)
print("各城市最好的月份：")
for name, m in zip(cities, best_months):
    print(f"  {name}：第 {m + 1} 月")
```

注意这里的 axis：
- `clean.sum(axis=1)` → 每个月（跨城市）的总额 → 12 个
- `np.argmax(clean, axis=0)` → 每个城市（跨月份）最好的月份 → 4 个

## 第六步：环比增长

```python
# 每月相对上月的增长率
growth = np.diff(monthly) / monthly[:-1] * 100
print("\n月度环比（%）：")
print(np.round(growth, 1))

print(f"增长最快的月份：第 {np.argmax(growth) + 2} 月（+{growth.max():.1f}%）")
```

**`np.diff` 算相邻差**，长度会少 1。所以除的时候要用 `monthly[:-1]`（去掉最后一个月）。

> ⚠️ `np.argmax(growth) + 2`：因为 diff 少一个元素，且增长率是"从第 n 月到第 n+1 月"，所以加 2 才是"第几个月"。这种下标偏移是最容易写错的地方，多验证一次。

## 第七步：输出报告

```python
line = "=" * 40
print(line)
print("           销售数据分析报告")
print(line)
print(f"数据规模：{clean.shape[0]} 个月 × {clean.shape[1]} 个城市")
print(f"年度总额：{clean.sum():,.0f}")
print(f"月均总额：{monthly.mean():,.0f}")
print()
print("城市排名：")
for rank, i in enumerate(np.argsort(totals)[::-1], 1):
    print(f"  {rank}. {cities[i]}  {totals[i]:,.0f}")
print()
print(f"最佳月份：第 {best_month + 1} 月")
print(f"最稳定的城市：{cities[np.argmin(stds)]}（标准差 {stds.min():.1f}）")
print(line)

# 顺手把清洗后的数据存下来，下次直接用
np.save('sales_clean.npy', clean)
```

**最后那行很重要**：清洗是个耗时且需要复现的过程，存成 npy 下次直接读。

## 完整代码

```python
import numpy as np

np.random.seed(42)
raw = np.genfromtxt('sales.csv', delimiter=',', skip_header=1)
cities = ['北京', '上海', '广州', '深圳']

# 清洗
clean = raw.copy()
clean[clean == -1] = np.nan
col_mean = np.nanmean(clean, axis=0)
inds = np.where(np.isnan(clean))
if len(inds[0]):
    clean[inds] = np.take(col_mean, inds[1])

# 统计
totals = clean.sum(axis=0)
monthly = clean.sum(axis=1)
stds = clean.std(axis=0)

line = "=" * 40
print(line)
print(f"  总销售额 {clean.sum():,.0f}   月均 {monthly.mean():,.0f}")
print("  城市排名：")
for rank, i in enumerate(np.argsort(totals)[::-1], 1):
    print(f"    {rank}. {cities[i]}  {totals[i]:,.0f}")
print(f"  最佳月份：第 {np.argmax(monthly) + 1} 月")
print(line)
np.save('sales_clean.npy', clean)
```

## 回顾：整套流程用到的东西

| 步骤 | 工具 |
|---|---|
| 造/读数据 | `savetxt`、`genfromtxt` |
| 检查 | `shape`、`np.isnan` + `sum` |
| 清洗 | 布尔索引赋值、`nanmean`、`where` + `take` |
| 统计 | `sum(axis=)`、`mean`、`std`、`argmax` |
| 变化 | `diff` |
| 排名 | `argsort(...)[::-1]` |
| 输出 | f-string、`round` |
| 保存 | `np.save` |

**五章的知识全在这里了。** 换一份数据，这套代码几乎不用改。

```quiz
type: choice
exam: true
q: 填补缺失值时，为什么通常按"列均值"而不是"全表均值"？
options:
- 列均值计算更快
- 不同列（城市/指标）的量级可能差别很大，用全表均值会互相污染
- 全表均值会报错
- 两者其实没有区别
answer: 1
explain: 比如北京的月销售额是 800、深圳是 200，全表均值 500 会把北京的数据往下压、深圳的往上抬，两边的统计都失真。按列填补保留了每列自己的水平，这才是"填补"而不是"篡改"。
```
