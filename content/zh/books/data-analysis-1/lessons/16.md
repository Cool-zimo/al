# 拼接数组

> 把几个数组合成一个。听起来简单，但"往哪个方向拼"是最容易搞反的地方。

## concatenate：最基础的一个

```python
import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5])

print(np.concatenate([a, b]))     # [1 2 3 4 5]
```

注意参数是**一个列表**，里面装着要拼的数组：`np.concatenate([a, b])`，不是 `np.concatenate(a, b)`。

### 二维数组就要指定 axis

```python
m1 = np.array([[1, 2],
               [3, 4]])      # (2, 2)
m2 = np.array([[5, 6]])      # (1, 2)

print(np.concatenate([m1, m2], axis=0))
```

```
[[1 2]
 [3 4]
 [5 6]]
```

**`axis=0` = 往下堆（行数变多）**。

```python
m3 = np.array([[7], [8]])    # (2, 1)
print(np.concatenate([m1, m3], axis=1))
```

```
[[1 2 7]
 [3 4 8]]
```

**`axis=1` = 往右接（列数变多）**。

### 铁律：除了拼接那一维，其他维度必须一致

```python
m1.shape    # (2, 2)
m2.shape    # (1, 2)

# axis=0 时，第 1 维（列数）必须相同 → 2 == 2 ✓
# axis=1 时，第 0 维（行数）必须相同 → 2 == 2 ✓ 但 m3 是 (2,1) 所以 axis=1 能拼
```

拼不上就报错，信息很直白：

```python
np.concatenate([m1, np.array([[1, 2, 3]])], axis=0)
# ValueError: all the input array dimensions except for the concatenation axis must match exactly
```

**读报错的技巧**：把所有数组的 shape 打出来，挨个比"除了拼接那一维之外"的部分。

## vstack 与 hstack：不用记 axis 的快捷方式

很多人记不住 axis=0 是竖着还是横着，于是 NumPy 给了两个语义明确的函数：

```python
a = np.array([1, 2])
b = np.array([3, 4])

print(np.vstack([a, b]))     # vertical，竖直堆叠 → 变成 2 行
print(np.hstack([a, b]))     # horizontal，水平连接 → 还是 1 行
```

```
vstack: [[1 2]
         [3 4]]

hstack: [1 2 3 4]
```

**记忆法**：`v` = vertical（竖），`h` = horizontal（横）。

| 函数 | 等价写法 | 作用 |
|---|---|---|
| `np.vstack([a, b])` | `concatenate([a, b], axis=0)` | 上下堆，行数增加 |
| `np.hstack([a, b])` | `concatenate([a, b], axis=1)` | 左右接，列数增加 |

**vstack 有个贴心的地方**：对一维数组，它会先各自变成"一行"再堆起来。所以两个长度为 2 的一维数组，vstack 之后是 `(2, 2)`。而 `concatenate(a, b, axis=0)` 直接拼会得到 `(4,)`。

## column_stack：把两个一维数组变成两列

```python
names = np.array([1, 2])
ages = np.array([3, 4])

print(np.column_stack([names, ages]))
```

```
[[1 3]
 [2 4]]
```

**这是"由多个指标拼一张表"最常用的写法**。比如你有"身高数组"和"体重数组"，想合成一个 `(n, 2)` 的表——用 `column_stack` 最直观。

和 `hstack` 的区别：对一维输入，`hstack` 会接成一个更长的一维数组，`column_stack` 会把它们各作为一列。

```python
print(np.hstack([names, ages]))       # [1 2 3 4]      一维
print(np.column_stack([names, ages])) # [[1 3] [2 4]]  二维
```

## 实战：往表里加一列

**需求**：成绩表已经有 3 门课，现在要加一列"总分"。

```python
scores = np.array([[80, 90, 70],
                   [60, 75, 85]])      # (2, 3)

totals = scores.sum(axis=1, keepdims=True)   # (2, 1)，keepdims 很关键
print(totals)

full = np.hstack([scores, totals])
print(full)
```

```
[[ 80  90  70 240]
 [ 60  75  85 220]]
```

**`keepdims=True` 在这里是必需品**。如果写成 `scores.sum(axis=1)`，得到的是 `(2,)`，hstack 会把它接成一维，结果形状就错了。

## 什么时候用哪个

| 场景 | 用 |
|---|---|
| 想清楚表达"上下堆 / 左右接" | `vstack` / `hstack` |
| 处理三维以上的数组 | `concatenate` + axis |
| 由几个一维数组拼成表 | `column_stack` |
| 拼很多个（列表里十几个） | `concatenate` |
