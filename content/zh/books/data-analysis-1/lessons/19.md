# 排序与排名

> `sort` 给你排好的值，`argsort` 给你排好的**下标**。后者才是真正有用的那个。

## sort：排好序的值

```python
import numpy as np

arr = np.array([3, 1, 4, 1, 5])
print(np.sort(arr))     # [1 1 3 4 5]
```

**默认升序**。返回的是**新数组**，原数组不变：

```python
print(arr)              # [3 1 4 1 5]  ← 没变
arr.sort()              # 方法形式是原地排序
print(arr)              # [1 1 3 4 5]  ← 变了
```

和之前一样：**函数形式返回新数组，方法形式原地改**。

## argsort：排好序的下标

**这是更常用的一个**：

```python
arr = np.array([3, 1, 4, 1, 5])
print(np.argsort(arr))    # [1 3 0 2 4]
```

意思是"最小的数在原数组下标 1，第二小的在下标 3，第三小的在下标 0……"

验证一下：

```python
idx = np.argsort(arr)
print(arr[idx])          # [1 1 3 4 5]  ← 用下标取出来就是排序结果
```

**`arr[np.argsort(arr)]` 等价于 `np.sort(arr)`**，但 argsort 的价值在于：它让你知道"第几名是谁"。

### 降序

argsort 只给升序，倒过来就是降序：

```python
print(np.argsort(arr)[::-1])    # [4 2 0 3 1]  从大到小
```

**`np.argsort(x)[::-1]` 是"从大到小排名"的标准写法**，务必记住。

### 取 Top-N

```python
scores = np.array([50, 80, 90, 60])

top2 = np.argsort(scores)[::-1][:2]
print(top2)               # [2 1]   最高分的两个人
print(scores[top2])       # [90 80]
```

## 二维排序

```python
m = np.array([[3, 1, 4],
              [2, 5, 0]])

print(np.sort(m, axis=1))     # 每行内部排序
```

```
[[1 3 4]
 [0 2 5]]
```

```python
print(np.sort(m, axis=0))     # 每列内部排序
```

```
[[2 1 0]
 [3 5 4]]
```

**axis 的规则没变**：`axis=1` 是"跨列算"，这里是"每行内部排"。

## 按某一列排序（最实用）

**需求**：一张成绩表，想按"数学成绩"排序，但整行（学生）要跟着走。

```python
scores = np.array([[80, 90],      # 学生0: 语文80 数学90
                   [95, 70],      # 学生1: 语文95 数学70
                   [88, 85]])     # 学生2: 语文88 数学85

# 按数学（第 1 列）排序
order = np.argsort(scores[:, 1])
print(order)              # [1 2 0]  数学成绩 70 < 85 < 90
print(scores[order])      # 整行跟着重排
```

```
[[95 70]
 [88 85]
 [80 90]]
```

**这就是"按某列排序整张表"的标准做法**：

1. 取出那一列 `scores[:, 1]`
2. 对它 `argsort` 得到顺序
3. 用这个顺序索引整个二维数组

### 降序版本

```python
order = np.argsort(scores[:, 1])[::-1]
print(scores[order])
```

## 多列排序

想"先按数学排，数学相同再按语文排"，用 `np.lexsort`：

```python
scores = np.array([[80, 90],
                   [95, 90],    # 数学也是 90
                   [88, 85]])

# lexsort 的最后一个键是"主键"
order = np.lexsort((scores[:, 0], scores[:, 1]))   # 先按语文，再按数学（数学为主）
print(scores[order])
```

> ⚠️ **`np.lexsort` 的参数顺序是反的**：最后一个数组才是主键。这有点反直觉，用的时候多试一次。

如果觉得绕，可以分两次排（先按次要键排，再按主键稳定排序）：

```python
order = np.argsort(scores[:, 0], kind='stable')      # 先按语文
tmp = scores[order]
order2 = np.argsort(tmp[:, 1], kind='stable')        # 再按数学（稳定排序保序）
print(tmp[order2])
```

`kind='stable'` 保证相等元素的相对顺序不变——这是多次排序能生效的关键。

## 排名（第几名）

```python
scores = np.array([50, 80, 90, 60])

order = np.argsort(scores)[::-1]     # [2 1 3 0]  从高到低的下标
ranks = np.empty_like(order)
ranks[order] = np.arange(len(scores)) + 1
print(ranks)      # [4 2 1 3]  下标0的排第4，下标1的排第2...
```

这段有点绕，解释一下：`order[0]` 是第 1 名的下标，所以 `ranks[第1名的下标] = 1`。

## 速查

| 需求 | 写法 |
|---|---|
| 排好序的值 | `np.sort(arr)` |
| 排好序的下标 | `np.argsort(arr)` |
| 降序下标 | `np.argsort(arr)[::-1]` |
| Top-N 下标 | `np.argsort(arr)[::-1][:N]` |
| 按某列排序整表 | `tbl[np.argsort(tbl[:, col])]` |
| 多列排序 | `np.lexsort((次要, 主键))` |
