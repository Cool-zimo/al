# 综合实战：成绩分析

> 把三章的内容串起来，走一遍完整的数据分析流程。
> 这一课没有新概念，只有"把学过的东西用起来"。

## 任务

一份 5 个学生 × 4 门课的成绩表（含一个缺失值），要产出一份分析报告：

1. 每个人的总分与排名
2. 每门课的难度（均分与标准差）
3. 谁的波动最大（偏科程度）
4. 找出需要补考的人

## 第一步：造数据

```python
import numpy as np

np.random.seed(7)

# 5 个学生 × 4 门课，成绩在 40~100 之间
scores = np.random.randint(40, 101, size=(5, 4))
scores[2, 1] = -1        # -1 表示缺考（模拟真实数据的脏值）

print(scores)
```

真实场景里你会从 CSV / Excel 读入，但对 NumPy 来说，拿到手之后的处理完全一样。

## 第二步：清洗 —— 处理缺考

```python
# 缺考的标记为 nan，这样统计函数会自动跳过它
scores_clean = scores.astype(float)
scores_clean[scores_clean == -1] = np.nan

print("缺考数量：", np.sum(np.isnan(scores_clean)))
```

**关键动作**：把"哨兵值"（-1）换成 `np.nan`，让后续统计自动忽略。

## 第三步：每个人的总分与排名

```python
# 每行一个总分，缺考按 0 计（或者用 nanmean 更合理）
totals = np.nansum(scores_clean, axis=1)
print("总分：", totals)

# 排名：argsort 给出"从小到大"的下标，倒过来就是从高到低
order = np.argsort(totals)[::-1]
print("排名（学生下标）：", order)

for rank, idx in enumerate(order, start=1):
    print(f"  第 {rank} 名：学生 {idx + 1}，总分 {totals[idx]:.0f}")
```

**`np.argsort(x)[::-1]` 是"从大到小排名"的标准写法**。

## 第四步：每门课的难度

```python
subj_mean = np.nanmean(scores_clean, axis=0)
subj_std = np.nanstd(scores_clean, axis=0)

print("每门课均分：", np.round(subj_mean, 1))
print("每门课标准差：", np.round(subj_std, 1))
```

**标准差大 = 这门课大家分差大 = 区分度高**（也可能是出题不稳定）。

找出最难的一门（均分最低）：

```python
hardest = np.nanargmin(subj_mean)
print(f"最难的是第 {hardest + 1} 门课，均分 {subj_mean[hardest]:.1f}")
```

## 第五步：谁偏科最严重

**偏科程度 = 每个人各科成绩的离散程度**，用标准差衡量：

```python
# 每个学生内部的标准差 → 让"科目"这一维消失 → axis=1
per_student_std = np.nanstd(scores_clean, axis=1)
print("每个人的偏科指数：", np.round(per_student_std, 1))

worst = np.nanargmax(per_student_std)
print(f"偏科最严重：学生 {worst + 1}")
```

## 第六步：谁要补考

```python
# 有任何一门不及格（< 60）
fail_mask = scores_clean < 60
print("不及格的格子：", np.sum(fail_mask))

# 哪些学生至少有一门不及格
any_fail = np.any(fail_mask, axis=1)
print("需要补考的学生：", np.where(any_fail)[0] + 1)
```

**`np.any(mask, axis=1)`** —— 让"科目"这一维消失，得到"每个学生是否有不及格"。这就是 axis 的典型用法。

## 完整代码

```python
import numpy as np

np.random.seed(7)
scores = np.random.randint(40, 101, size=(5, 4))
scores = scores.astype(float)
scores[2, 1] = np.nan          # 缺考

line = "=" * 38
print(line)
print("一、每人总分与排名")
totals = np.nansum(scores, axis=1)
for rank, i in enumerate(np.argsort(totals)[::-1], start=1):
    print(f"  第 {rank} 名  学生{i+1}  {totals[i]:.0f} 分")

print("\n二、每门课难度")
print("  均分：", np.round(np.nanmean(scores, axis=0), 1))
print("  标准差：", np.round(np.nanstd(scores, axis=0), 1))

print("\n三、偏科指数（越大越偏）")
print("  ", np.round(np.nanstd(scores, axis=1), 1))

print("\n四、需要补考")
print("  学生：", np.where(np.any(scores < 60, axis=1))[0] + 1)
print(line)
```

## 回顾：这一路用了什么

| 步骤 | 用到的东西 |
|---|---|
| 造数据 | `np.random.randint`、`astype` |
| 清洗 | 布尔索引赋值、`np.isnan` |
| 总分 | `np.nansum(axis=1)` |
| 排名 | `np.argsort(...)[::-1]` |
| 课难度 | `np.nanmean(axis=0)`、`np.nanargmin` |
| 偏科 | `np.nanstd(axis=1)` |
| 补考 | 比较运算 + `np.any(axis=1)` + `np.where` |

**三章的知识，在这里全部用上了**：创建数组、向量化运算、广播、布尔索引、axis、聚合函数、nan 安全版本。

q: 想找出"至少有一门不及格"的学生，应该怎么写？
options:
- np.any(scores < 60, axis=0)
- np.any(scores < 60, axis=1)
- np.all(scores < 60, axis=1)
- np.sum(scores < 60)
answer: 1
explain: axis=1 让"科目"这一维消失，得到"每个学生是否（any）有不及格"，结果是每个学生一个布尔值。用 axis=0 会得到"每门课是否有人不及格"，用 all 会变成"全部科目都不及格"。
