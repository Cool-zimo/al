# 实战二：时间序列与移动平均

> 股票、气温、日活……凡是"按时间排成一列"的数据，都绕不开移动平均。

## 什么是移动平均

原始日销量波动很大，看不出趋势：

```python
import numpy as np

np.random.seed(0)
daily = np.random.randint(80, 120, size=30)     # 30 天的销量
print("原始：", daily)
```

**移动平均**：每天取"它和前面几天"的平均值，把锯齿抹平。

```python
# 3 天移动平均
window = 3
kernel = np.ones(window) / window               # [1/3, 1/3, 1/3]
ma = np.convolve(daily, kernel, mode='valid')
print("3日均：", np.round(ma, 1))
```

**`np.convolve` 是卷积**，用 `[1/3, 1/3, 1/3]` 这个"平均核"滑过整个序列，就是移动平均。

## mode 参数：结果有多长

`np.convolve(a, kernel, mode=...)` 有三种模式，长度不同：

```python
x = np.array([1., 2., 3., 4., 5., 6.])
k = np.ones(3) / 3

print("full :", len(np.convolve(x, k, mode='full')))    # 8 = 6 + 3 - 1
print("same :", len(np.convolve(x, k, mode='same')))    # 6 = 和输入一样长
print("valid:", len(np.convolve(x, k, mode='valid')))   # 4 = 6 - 3 + 1
```

| mode | 长度 | 含义 |
|---|---|---|
| `full` | `n + k - 1` | 完整卷积，两端有"半重叠"的部分 |
| `same` | `n` | 和输入等长，两端补零 |
| `valid` | `n - k + 1` | **只在完全重叠处计算**，最常用 |

**做移动平均统一用 `mode='valid'`**：两端的"半窗口"结果是失真的（只平均了 1~2 个数），valid 直接把它们去掉。

代价是结果比原始数据短 `k-1` 个——这是正常的，前 `k-1` 天本来就没有足够的"前面几天"。

## 另一种写法：cumsum（更快）

卷积很直观，但数据量大时偏慢。有个等价的快方法：

```python
def moving_average(x, window):
    cum = np.cumsum(np.insert(x, 0, 0))       # 前缀和，前面补个 0
    return (cum[window:] - cum[:-window]) / window

print(np.round(moving_average(daily, 3), 1))
```

**原理**：`cumsum` 算出前缀和后，第 i 个窗口的和 = `cum[i+window] - cum[i]`，一次减法搞定，**不用重复加法**。

验证一下两者一致：

```python
print(np.allclose(moving_average(daily, 3),
                  np.convolve(daily, np.ones(3)/3, mode='valid')))
# True
```

> 💡 **小数据用 convolve（好读），大数据用 cumsum（快）**。100 万条数据时 cumsum 能快几十倍。

## 累计量：cumsum 和 cumprod

```python
sales = np.array([100, 150, 120, 200])

print("累计销量：", np.cumsum(sales))       # [100 250 370 570]
print("累计增长率：", np.cumprod([1.1, 1.05, 1.2]))   # 复利相乘
```

**`cumsum` 是"到这天为止一共多少"**，画累计曲线必备。

## 滑动窗口的通用做法

想知道"任意连续 k 天的最大值/最小值/标准差"，可以手写循环，但更优雅的是用 `sliding_window_view`：

```python
from numpy.lib.stride_tricks import sliding_window_view

w = sliding_window_view(daily, window_shape=3)
print(w.shape)          # (28, 3)  28 个窗口，每个 3 天
print("每个窗口的最大值：", w.max(axis=1))
print("每个窗口的最小值：", w.min(axis=1))
print("每个窗口的波动：", np.round(w.std(axis=1), 1))
```

**`sliding_window_view` 生成的是视图**，不复制数据，所以很省内存。之后对每个窗口做 `axis=1` 的聚合即可。

> ⚠️ 这个函数在 `numpy.lib.stride_tricks` 里，需要 import。老版本 NumPy 可能没有。

## 实战：判断趋势

```python
import numpy as np

np.random.seed(0)
daily = np.random.randint(80, 120, size=30).astype(float)

def ma(x, k):
    cum = np.cumsum(np.insert(x, 0, 0))
    return (cum[k:] - cum[:-k]) / k

short = ma(daily, 3)      # 快线：3 日均
long_ = ma(daily, 10)     # 慢线：10 日均

# 对齐长度（快线长 28，慢线长 21，取尾部对齐）
n = min(len(short), len(long_))
short, long_ = short[-n:], long_[-n:]

print("快线（3日）：", np.round(short, 1))
print("慢线（10日）：", np.round(long_, 1))
print("\n快线在慢线上方的天数：", np.sum(short > long_))
```

**"快线上穿慢线"是经典的技术分析信号**（金叉）。这里只是演示思路，不构成任何投资建议——真用它炒股会亏钱。

## 常见陷阱

**1. 忘记窗口越界。**

```python
np.convolve(daily, np.ones(50)/50, mode='valid')   # 只有 30 天，窗口 50
# 得到空数组！
```

窗口比数据还长，valid 模式返回空。**加个检查**：

```python
assert window <= len(daily), "窗口不能比数据长"
```

**2. 把 nan 带进序列。**

移动平均遇到 nan 会"传染"——一个 nan 会让它后面的 k 个均值全变 nan。先填补再算：

```python
daily_clean = daily.copy()
inds = np.where(np.isnan(daily_clean))
if len(inds[0]):
    daily_clean[inds] = np.nanmean(daily_clean)
```
