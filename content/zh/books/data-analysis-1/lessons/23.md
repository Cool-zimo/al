# 真实 CSV：genfromtxt

> `loadtxt` 遇到空字段就崩。真实数据几乎总有缺失，所以你更需要 `genfromtxt`。

## 先看 loadtxt 崩在哪

文件长这样（第 2 行缺了一个数）：

```
1,2
3,
5,6
```

```python
np.loadtxt('miss.csv', delimiter=',')
# ValueError: could not convert string to float: ''
```

**换成 genfromtxt 就不会**：

```python
data = np.genfromtxt('miss.csv', delimiter=',')
print(data)
```

```
[[ 1.  2.]
 [ 3. nan]
 [ 5.  6.]]
```

**空字段自动变成 `nan`**。这正是我们上一本书讲过的"缺失值"表示法，后续的 `nanmean` 等函数能直接处理。

## 基本用法

```python
import numpy as np

data = np.genfromtxt('data.csv', delimiter=',', skip_header=1)
```

参数名和 loadtxt **略有不同**（这也是个坑）：

| loadtxt | genfromtxt | 作用 |
|---|---|---|
| `skiprows` | `skip_header` | 跳过开头几行 |
| — | `skip_footer` | 跳过结尾几行 |
| `dtype` | `dtype` | 指定类型 |
| `usecols` | `usecols` | 只读某几列 |
| — | `names` | 把第一行当列名 |
| — | `filling_values` | 缺失值填什么 |

> ⚠️ **注意 `skiprows` vs `skip_header`**。在 genfromtxt 里写 `skiprows` 也能用（它有别名），但为了不混淆，统一用 `skip_header`。

## 带列名读取

如果 CSV 第一行是表头：

```
语文,数学,英语
80,90,70
60,75,85
```

```python
data = np.genfromtxt('scores.csv', delimiter=',', names=True)
print(data)
print(data['语文'])      # 用列名取值
```

```
[(80., 90., 70.) (60., 75., 85.)]
[80. 60.]
```

**`names=True` 会把第一行当作列名**，之后可以用 `data['语文']` 这种字典式的语法取列。

读回来的东西叫**结构化数组**，打印出来是一行一行的小括号。它有点像"每行是一条记录"，但用起来和普通二维数组不太一样，容易让人困惑。

> 💡 我的建议：**初学阶段不要用 `names=True`**。直接 `skip_header=1` 读成普通二维数组，然后用 `data[:, 0]`、`data[:, 1]` 按位置取列，行为更可预测。等你学了 pandas，那里的列名机制会好用得多（第 2 本书会讲）。

## 缺失值填充

有时候你不想得到 nan，而是想填一个默认值：

```python
data = np.genfromtxt('miss.csv', delimiter=',', filling_values=0)
print(data)
```

```
[[1. 2.]
 [3. 0.]
 [5. 6.]]
```

**`filling_values=0` 把所有缺失填成 0**。

也可以按列填不同的值：

```python
data = np.genfromtxt('miss.csv', delimiter=',', filling_values=(0, -1))
```

（第 0 列缺失填 0，第 1 列缺失填 -1。）

**注意**：如果你想"用该列均值填充"，genfromtxt 做不到，得读进来之后再处理：

```python
data = np.genfromtxt('miss.csv', delimiter=',')
col_mean = np.nanmean(data, axis=0)
inds = np.where(np.isnan(data))
data[inds] = np.take(col_mean, inds[1])
```

这段代码值得记一下——**`np.where` 找出 nan 的位置，`np.take` 按列取对应的均值填进去**。

## 混合类型怎么办

真实 CSV 经常是这样：

```
北京,80,90
上海,75,88
```

第一列是文字，后两列是数字。**NumPy 处理这种数据很别扭**——它要求所有元素同类型。

勉强能读：

```python
data = np.genfromtxt('mixed.csv', delimiter=',', dtype=str, encoding='utf-8')
print(data)
```

```
[['北京' '80' '90']
 ['上海' '75' '88']]
```

但**数字变成了字符串**，你得手动转：

```python
nums = data[:, 1:].astype(float)
print(nums)
```

> 💡 **这就是 NumPy 的边界**。一旦你的数据出现"文字列 + 数字列"，就该用 pandas 了——它天生支持每列不同类型。这也是为什么《数据分析 2》要讲 pandas。

## 完整的真实数据流程

```python
import numpy as np

# 1. 读（跳过表头，缺失自动变 nan）
data = np.genfromtxt('scores.csv', delimiter=',', skip_header=1)

# 2. 看看有多少缺失
print("缺失数量：", np.sum(np.isnan(data)))

# 3. 用列均值填补
col_mean = np.nanmean(data, axis=0)
inds = np.where(np.isnan(data))
if len(inds[0]):
    data[inds] = np.take(col_mean, inds[1])

# 4. 正常统计
print("每列均分：", data.mean(axis=0))
print("每列标准差：", data.std(axis=0))
```

**"读进来 → 数缺失 → 填均值 → 再统计"**，这是处理真实数据的标准四步。

## 什么时候用哪个

| 数据情况 | 用 |
|---|---|
| 全是数字、没有缺失 | `np.loadtxt`（更快） |
| 有缺失值 | `np.genfromtxt` |
| 需要跳过末尾几行 | `np.genfromtxt`（有 skip_footer） |
| 有文字列 + 数字列 | **pandas**（NumPy 不适合） |
