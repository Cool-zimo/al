# 通用函数 ufunc

> NumPy 里有一大类函数，它们唯一的工作就是：**拿一个数组，对每个元素做同一件事，返回一个新数组**。这类函数叫 ufunc。

## 什么是 ufunc

**ufunc = universal function（通用函数）**。它的特征是：

1. 逐元素作用（element-wise）
2. 输入输出形状一致
3. 底层是 C 实现，所以很快

```python
import numpy as np
arr = np.array([1, 4, 9, 16])

print(np.sqrt(arr))     # [1. 2. 3. 4.]   形状还是 (4,)
```

你其实已经在用 ufunc 了——上一章的 `arr + 10`、`arr * 2`，本质上也是 ufunc（`np.add`、`np.multiply`）。

## 数学类

```python
arr = np.array([1, 4, 9, 16])

print(np.sqrt(arr))      # [1. 2. 3. 4.]   开方
print(np.square(arr))    # [  1  16  81 256]  平方
print(np.exp(arr))       # e 的 x 次方
print(np.log(arr))       # 自然对数
print(np.log10(arr))     # 常用对数（以 10 为底）
print(np.abs(arr))       # 绝对值
print(np.round(arr))     # 四舍五入
```

**一个实用技巧**：NumPy 里 `arr ** 0.5` 和 `np.sqrt(arr)` 等价，但 `np.sqrt` 更清晰，也通常略快。

## 三角函数（参数是弧度）

```python
import numpy as np

angles = np.array([0, 30, 45, 90])
radians = np.deg2rad(angles)      # 角度 → 弧度

print(radians)
print(np.sin(radians))            # [0.  0.5 0.707 1. ]
print(np.cos(radians))
```

> ⚠️ **NumPy 只认弧度**。如果你直接 `np.sin(90)`，得到的是 0.894，不是 1。要先把角度转成弧度（`np.deg2rad`），或者手动乘 `np.pi / 180`。

## 取整家族

```python
arr = np.array([1.2, 2.7, -1.5, 3.5])

print(np.floor(arr))     # [ 1.  2. -2.  3.]  向下取整
print(np.ceil(arr))      # [ 2.  3. -1.  4.]  向上取整
print(np.round(arr))     # [ 1.  3. -2.  4.]  四舍五入
print(np.trunc(arr))     # [ 1.  2. -1.  3.]  直接砍掉小数
```

注意负数：`floor(-1.5)` 是 `-2`（往更小的方向），`trunc(-1.5)` 是 `-1`（往 0 的方向）。

## 两个数组之间：maximum / minimum

```python
a = np.array([1, 5, 3])
b = np.array([2, 2, 9])

print(np.maximum(a, b))    # [2 5 9]  ← 逐位置取大的
print(np.minimum(a, b))    # [1 2 3]  ← 逐位置取小的
```

**别和 `np.max` / `np.min` 搞混**：

| 函数 | 作用 | 结果 |
|---|---|---|
| `np.max(a)` | 找出 a 里最大的**一个**值 | 标量 |
| `np.maximum(a, b)` | 逐位置比较，取大的 | 数组 |

记忆法：**带 mum 的是"逐元素比较"，不带的是"聚合求极值"**。

## 比较也是 ufunc

```python
arr = np.array([1, 5, 3, 8])

print(arr > 3)              # [False  True False  True]
print(np.greater(arr, 3))   # 同上，显式写法
```

比较运算符（`>` `>=` `<` `<=` `==` `!=`）本质上也是 ufunc，所以它们返回的是布尔数组。

布尔数组还能做逻辑运算，但**不能用 Python 的 `and` / `or`**：

```python
mask1 = arr > 2
mask2 = arr < 8

# ❌ 报错：and/or 只能用于单个布尔值
print(mask1 and mask2)

# ✅ 用 & 和 |
print(mask1 & mask2)        # 两个都满足
print(mask1 | mask2)        # 满足其一
print(~mask1)               # 取反
```

> ⚠️ `&` `|` 的优先级比比较运算符高，所以复杂条件要加括号：
> ```python
> print((arr > 2) & (arr < 8))    # 括号不能省
> ```

## np.where 再深入

它是 ufunc 思路的延伸——**根据条件从不同来源取值**：

```python
scores = np.array([45, 78, 92, 55])
print(np.where(scores >= 60, scores, 0))    # [ 0 78 92  0]
```

第二个、第三个参数也可以是数组：

```python
a = np.array([1, 2, 3])
b = np.array([10, 20, 30])
cond = np.array([True, False, True])
print(np.where(cond, a, b))     # [ 1 20  3]  ← True 取 a，False 取 b
```

还有个常用变体 `np.clip`，把值限制在范围内：

```python
arr = np.array([-5, 3, 12, 8])
print(np.clip(arr, 0, 10))      # [ 0  3 10  8]  ← 小于 0 的变 0，大于 10 的变 10
```

一行顶掉 if-elif-else 三分支。

## 累计函数（不是 ufunc，但常一起用）

```python
arr = np.array([1, 2, 3, 4])

print(np.cumsum(arr))      # [ 1  3  6 10]  累计和
print(np.cumprod(arr))     # [ 1  2  6 24]  累计积
print(np.diff(arr))        # [1 1 1]        相邻差（长度少 1）
```

`np.diff` 特别适合算"环比增长"：今天比昨天多了多少。

## 速查表

| 类别 | 函数 |
|---|---|
| 开方/平方 | `sqrt` `square` |
| 指数/对数 | `exp` `log` `log10` |
| 取整 | `floor` `ceil` `round` `trunc` |
| 绝对值/符号 | `abs` `sign` |
| 三角 | `sin` `cos` `tan` `deg2rad` |
| 逐元素比较 | `maximum` `minimum` `clip` |
| 条件选择 | `where` |
| 累计 | `cumsum` `cumprod` `diff` |
