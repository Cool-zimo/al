# 读文件常见报错

> 读文件失败时，报错信息其实把原因说得很清楚。这一课教你读懂它们。

## 报错一：找不到文件

```
FileNotFoundError: data.csv not found.
```

**原因**：路径不对。Python 是按**当前工作目录**找文件的，不是按代码文件所在的目录。

**排查**：

```python
import os
print(os.getcwd())          # 看看现在在哪
print(os.listdir('.'))      # 看看这里有什么
```

**最常见的坑**：你在 VSCode 里打开的是项目根目录，但运行时的工作目录可能是别的。

解决办法三选一：

```python
# 1. 用绝对路径
data = np.loadtxt('/home/me/project/data.csv', delimiter=',')

# 2. 先切换工作目录
os.chdir('/home/me/project')

# 3. 相对当前代码文件定位（最稳）
import pathlib
base = pathlib.Path(__file__).parent
data = np.loadtxt(base / 'data.csv', delimiter=',')
```

## 报错二：列数不一致

```
ValueError: the number of columns changed from 3 to 2 at row 2
```

**原因**：文件里某一行的字段数和其他行不一样。

```
1,2,3
4,5      ← 这行只有 2 个
```

**常见诱因**：

- 最后一行少了内容
- 某个字段里**本身就含分隔符**（比如地址 `北京市,朝阳区`，用逗号分隔就会被切成两列）
- 文件末尾有空行

**排查**：把出错那行打出来看看

```python
lines = open('data.csv', encoding='utf-8').read().split('\n')
for i, line in enumerate(lines, 1):
    n = len(line.split(','))
    if n != 3:
        print(f"第 {i} 行有 {n} 个字段：{line!r}")
```

**处理**：

```python
# 方案一：跳过末尾行
data = np.genfromtxt('data.csv', delimiter=',', skip_footer=1)

# 方案二：只读前 3 列
data = np.genfromtxt('data.csv', delimiter=',', usecols=(0, 1, 2))

# 方案三：先过滤掉字段数不对的行
lines = [l for l in open('data.csv', encoding='utf-8') if len(l.split(',')) == 3]
```

## 报错三：无法转成数字

```
ValueError: could not convert string to float: '语文'
```

**原因**：文件里有**文字**（通常是表头），但你让 NumPy 当数字读。

```
语文,数学,英语      ← 这行是文字
80,90,70
```

**解决**：跳过表头。

```python
data = np.loadtxt('scores.csv', delimiter=',', skiprows=1)
```

或者用 genfromtxt 的 `skip_header=1`。

**另一种情况**：空字段。

```
ValueError: could not convert string to float: ''
```

这是有逗号但没有值，改用 `genfromtxt`（上一课讲过）。

## 报错四：编码问题

```
UnicodeDecodeError: 'utf-8' codec can't decode byte 0xc4 in position 0
```

**原因**：文件不是 UTF-8 编码。**中文 Windows 上 Excel 另存的 CSV 默认是 GBK**，这是最常见的来源。

**解决**：指定编码。

```python
data = np.loadtxt('data.csv', delimiter=',', dtype=str, encoding='gbk')
```

**怎么知道文件是什么编码？** 试错法：

```python
for enc in ['utf-8', 'gbk', 'gb18030', 'latin1']:
    try:
        lines = open('data.csv', encoding=enc).readlines()
        print(f"{enc} 可以：{lines[0][:30]}")
        break
    except UnicodeDecodeError:
        print(f"{enc} 不行")
```

**gb18030 是 gbk 的超集**，如果 gbk 不行可以试它。

**从根上解决**：用 VSCode 或记事本把文件**另存为 UTF-8**，以后就不会再遇到。

## 报错五：分隔符不对

文件用分号分隔（欧洲的 CSV 常见），你却按逗号读：

```
1;2;3
```

```python
np.loadtxt('d.csv', delimiter=',')    # 得到一列乱七八糟的东西
```

**不会报错，只是读错**——这比报错更危险。

**排查**：先把原始内容打出来看一眼。

```python
print(open('d.csv', encoding='utf-8').read()[:200])
```

**养成习惯**：读任何陌生文件之前，先 `print` 前几行看看长什么样。这一步能省掉一大半麻烦。

```python
with open('data.csv', encoding='utf-8') as f:
    for i, line in enumerate(f):
        if i >= 5: break
        print(repr(line))
```

用 `repr()` 能看到换行符和隐藏字符。

## 报错六：只有一行数据

```python
data = np.loadtxt('one_row.csv', delimiter=',')
print(data.shape)     # (3,)   ← 只有一行，读成一维了
```

**这是个静默陷阱**：文件只有一行时，读回来是一维数组。你的代码如果假设它是二维（`data[:, 0]`），就会崩。

**解决**：强制至少二维。

```python
data = np.atleast_2d(np.loadtxt('one_row.csv', delimiter=','))
print(data.shape)     # (1, 3)
```

`np.atleast_2d` 是"至少二维"的安全包装，写通用代码时很有用。

## 通用排查清单

按顺序做这四件事，90% 的读文件问题都能解决：

1. **文件存在吗** → `os.path.exists(path)`
2. **原始内容长什么样** → `print(open(f, encoding='utf-8').read()[:200])`
3. **编码对不对** → 试 utf-8 / gbk
4. **分隔符和表头** → 确认 delimiter 和 skiprows
