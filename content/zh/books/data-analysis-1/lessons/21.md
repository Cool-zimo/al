# npy 与 npz

> 把算好的数据存下来、下次直接读回来。NumPy 有自己的二进制格式，比 CSV 快得多也稳得多。

## 为什么不用 CSV 存

CSV 存数字有两个硬伤：

1. **慢**——存和读都要做"数字 ↔ 文本"的转换，数据量大时差别巨大
2. **丢精度**——`0.1 + 0.2` 那种浮点数写进文本再读回来，可能不再是同一个数

**NumPy 的 `.npy` 格式直接存二进制**，原样保存、原样读回，又快又准。

> 💡 什么时候用 CSV？当你需要**给别人看**、或者要交给 Excel / 其他工具时。纯 Python 内部流转，一律用 npy。

## save 与 load：单个数组

```python
import numpy as np

arr = np.array([[1, 2, 3],
                [4, 5, 6]])

np.save('data.npy', arr)          # 存
loaded = np.load('data.npy')      # 读
print(loaded)
```

```
[[1 2 3]
 [4 5 6]]
```

**注意：`np.save` 会自动补 `.npy` 后缀**。写 `np.save('data', arr)` 得到的也是 `data.npy`。

读取时**后缀不能省**：

```python
np.load('data')      # FileNotFoundError（它找的是叫 data 的文件）
np.load('data.npy')  # ✅
```

### 存进去的是什么

npy 文件里除了数据，还自带**形状、dtype、字节序**这些元信息。所以读回来完全一样，不用你再指定类型：

```python
a = np.array([1.5, 2.5], dtype=np.float32)
np.save('x.npy', a)
b = np.load('x.npy')
print(b.dtype)      # float32  ← 类型也被记住了
```

这是 CSV 做不到的。

## savez：一次存多个数组

```python
x = np.array([1, 2, 3])
y = np.array([[10], [20]])

np.savez('bundle.npz', x=x, y=y)
```

读回来像一个**字典**：

```python
data = np.load('bundle.npz')
print(data.files)        # ['x', 'y']  里面有哪些
print(data['x'])         # [1 2 3]
print(data['y'])
```

**关键字参数就是名字**。也可以不写名字，那会自动命名成 `arr_0`、`arr_1`：

```python
np.savez('auto.npz', x, y)
d = np.load('auto.npz')
print(d.files)      # ['arr_0', 'arr_1']
```

**建议总是起名字**，`arr_0` 这种名字过一周你就忘了哪个是哪个。

### npz 是压缩包

`npz` 实际上是一个 zip，里面装着好几个 `.npy`。所以：

- 能用解压软件打开
- 体积比分别存要小一点（有压缩）

想要更强的压缩用 `savez_compressed`：

```python
np.savez_compressed('packed.npz', big=arr)    # 数据大时体积明显更小
```

代价是存的时候慢一点。

## 用完记得关

`np.load` 一个 npz 返回的对象**持有文件句柄**，用完了应该关掉：

```python
data = np.load('bundle.npz')
x = data['x'].copy()      # 取出你要的
data.close()              # 关闭
```

更优雅的写法是用 `with`：

```python
with np.load('bundle.npz') as data:
    x = data['x']
    y = data['y']
# 出了 with 自动关闭
print(x, y)
```

（读单个 `.npy` 不用关，它直接返回数组。）

## 一个实用习惯：存中间结果

数据分析里常遇到"前面几步要跑 10 分钟"的情况：

```python
import numpy as np
import os

if os.path.exists('cache.npy'):
    result = np.load('cache.npy')       # 有缓存直接用
    print("从缓存加载")
else:
    result = expensive_computation()    # 没有才算
    np.save('cache.npy', result)
    print("计算并缓存")
```

**这个模式能省下大量重复等待的时间。**

## 速查

| 需求 | 写法 |
|---|---|
| 存一个数组 | `np.save('a.npy', arr)` |
| 读一个数组 | `np.load('a.npy')` |
| 存多个（有名字） | `np.savez('b.npz', x=x, y=y)` |
| 存多个（压缩） | `np.savez_compressed(...)` |
| 读多个 | `d = np.load('b.npz'); d['x']` |
| 查看有哪些 | `d.files` |
