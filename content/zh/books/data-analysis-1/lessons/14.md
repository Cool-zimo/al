# axis 到底是谁

> NumPy 里最容易绕晕的概念，没有之一。
> 但只要抓住一句话，它就永远清楚了：**axis 就是"被压缩掉的那一维"**。

## 先看现象

```python
import numpy as np

m = np.array([[1, 2, 3],
              [4, 5, 6]])

print(m.sum())          # 21      全部求和
print(m.sum(axis=0))    # [5 7 9]  ← 得到了 3 个数
print(m.sum(axis=1))    # [ 6 15]  ← 得到了 2 个数
```

为什么 axis=0 出 3 个数，axis=1 出 2 个数？

## 核心理解：axis 是被压缩的维度

`m` 的形状是 `(2, 3)`：

- 第 0 维长度 2（行）
- 第 1 维长度 3（列）

**`axis=0` 意思是"沿着第 0 维方向算，算完这一维就没了"**：

```
输入 (2, 3)
      ↓ 沿第 0 维（行方向）压缩
输出 (3,)        ← 第 0 维消失了，剩下 3
```

结果是"每一列的和"：`[1+4, 2+5, 3+6] = [5, 7, 9]`。

**`axis=1` 是"沿着第 1 维压缩"**：

```
输入 (2, 3)
      ↓ 沿第 1 维（列方向）压缩
输出 (2,)        ← 第 1 维消失了，剩下 2
```

结果是"每一行的和"：`[1+2+3, 4+5+6] = [6, 15]`。

## 记忆口诀

> **`axis=n` 就是"让第 n 维消失"。**

判断结果形状的方法：**把原形状中第 n 位删掉**。

```
(2, 3)  sum(axis=0)  →  删第 0 位  →  (3,)
(2, 3)  sum(axis=1)  →  删第 1 位  →  (2,)
```

**反过来也能用**：如果你想要"每行一个结果"（即结果形状是 `(2,)`），那就得让第 1 维消失，所以用 `axis=1`。

> 💡 很多人记成"axis=0 是按行算"，这是错的，也是混乱的根源。正确说法是：**axis=0 是"跨行"算，得到每一列的结果**。

## 三维的例子

```python
a = np.ones((2, 3, 4))    # 形状 (2, 3, 4)

print(a.sum(axis=0).shape)   # (3, 4)   删第 0 位
print(a.sum(axis=1).shape)   # (2, 4)   删第 1 位
print(a.sum(axis=2).shape)   # (2, 3)   删第 2 位
```

**"删掉哪一位"这个口诀在任意维度都成立。**

## keepdims：保留被压缩的维度

有时候你希望结果的维度数不变（比如为了后续广播）：

```python
m = np.array([[1, 2, 3],
              [4, 5, 6]])

print(m.sum(axis=1))              # [ 6 15]       形状 (2,)
print(m.sum(axis=1, keepdims=True))  # [[ 6] [15]]  形状 (2, 1)
```

```
[[ 6]
 [15]]
```

**`keepdims=True` 把消失的那一维保留成 1。**

这是广播的绝佳搭档——还记得上一章"按行中心化"要手动 reshape 吗？用 keepdims 就不用了：

```python
# 之前：要手动 reshape
row_mean = m.mean(axis=1).reshape(-1, 1)
centered = m - row_mean

# 现在：keepdims 直接给出 (2, 1)
centered = m - m.mean(axis=1, keepdims=True)
```

**推荐在需要广播的地方都用 keepdims=True**，代码更干净，也不容易写错 reshape。

## 不只是聚合函数

所有"沿着某个方向操作"的函数都有 axis：

```python
m = np.array([[3, 1, 4],
              [1, 5, 9]])

print(np.sort(m, axis=1))         # 每行内部排序
print(np.argsort(m, axis=1))      # 每行内部排序后的下标
print(np.cumsum(m, axis=0))       # 沿列方向累计
print(np.argmax(m, axis=1))       # 每行最大值所在的下标
```

**`argmax` 带 axis 特别有用**：

```python
# 每个学生（每行）最强的是第几门课
scores = np.array([[80, 90, 70],
                   [60, 75, 85]])
print(np.argmax(scores, axis=1))    # [1 2]  ← 第 1 门、第 2 门
```

## 一个完整例子

```python
import numpy as np

# 3 个学生 × 4 门课
scores = np.array([[80, 90, 70, 85],
                   [60, 75, 80, 65],
                   [95, 88, 92, 90]])

print("每门课的均分：", scores.mean(axis=0))     # 4 个数（跨学生）
print("每个学生的总分：", scores.sum(axis=1))    # 3 个数（跨科目）
print("全班最高分：", scores.max())              # 1 个数
print("每个学生的最高分：", scores.max(axis=1))  # 3 个数
print("最高分出现在第几门：", scores.argmax(axis=1))
```

对照着看，axis 的作用就非常清楚了。

## 常见错误对照

| 你想算什么 | 该用哪个 axis |
|---|---|
| 每个学生的总分（跨科目） | `axis=1` |
| 每门课的平均分（跨学生） | `axis=0` |
| 全班所有成绩的平均 | 不写 axis |

**检验方法**：算完看结果的形状。想要 3 个数（3 个学生）就必须让"科目"那一维消失，即 `axis=1`。
