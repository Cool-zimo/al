# 函数：声明、表达式与箭头函数

> 这一节解决"JS 里函数有几种写法，以及箭头函数和 Python lambda 有什么关系"的问题。你学过 Python 的 `def` 和 `lambda`，JS 的函数体系更灵活。

## 三种定义方式

### 1. 函数声明（Function Declaration）

```javascript
function greet(name) {
  return "你好，" + name;
}
```

特点：**会被提升**（hoisting），可以在声明之前调用。

### 2. 函数表达式（Function Expression）

```javascript
const greet = function(name) {
  return "你好，" + name;
};
```

特点：赋值给变量，**不会被提升**（变量提升但函数体不会）。

### 3. 箭头函数（Arrow Function）

```javascript
const greet = (name) => {
  return "你好，" + name;
};
// 更简洁：单表达式可省略 {} 和 return
const greet = name => "你好，" + name;
```

特点：语法更简洁，且不绑定自己的 `this`。

## 箭头函数 vs Python lambda

```python
# Python
square = lambda x: x * x
add = lambda a, b: a + b
```

```javascript
// JavaScript
const square = x => x * x;
const add = (a, b) => a + b;
```

非常相似！但 JS 箭头函数比 Python lambda 更强：可以写多行（用 `{}`），可以没有参数（用 `()`）。

```javascript
const greet = () => "你好";
const sum = (a, b) => {
  const result = a + b;
  return result;
};
```

## 参数默认值与剩余参数

```javascript
// 默认值（类似 Python 的默认参数）
function greet(name = "游客") {
  return "你好，" + name;
}

// 剩余参数（类似 Python 的 *args）
function sum(...numbers) {
  return numbers.reduce((a, b) => a + b, 0);
}
sum(1, 2, 3, 4);  // 10
```

翻车现场一：默认值的坑。

```javascript
function add(a, b = 1) {
  return a + b;
}
add(5, undefined);  // 6（undefined 触发默认值）
add(5, null);       // 5（null 是有效值，不触发默认值！）
```

后果：`null` 被视为"传了值"，不会使用默认值 `1`。在表单处理中，空输入框的值是 `""`，也不是 `undefined`，同样不会触发默认值。

## 箭头函数的 `this` 差异

`this` 是 JS 中最复杂的话题之一。这里先点出差异，后续课程会深入。

```javascript
const person = {
  name: "张三",
  // 传统函数：this 指向调用者（person）
  greet: function() {
    console.log("你好，我是" + this.name);
  },
  // 箭头函数：this 继承外层作用域
  greetArrow: () => {
    console.log("你好，我是" + this.name);  // this 不是 person！
  }
};
person.greet();       // "你好，我是张三" ✅
person.greetArrow();  // "你好，我是undefined" ❌
```

**记住：箭头函数没有自己的 `this`，它继承定义时所在作用域的 `this`。**

翻车现场二：在对象方法中使用箭头函数。

```javascript
const counter = {
  count: 0,
  increment: () => {
    this.count++;  // this 不指向 counter！
  }
};
counter.increment();  // counter.count 仍然是 0
```

后果：`this.count++` 修改的是外层作用域的 `count`（可能不存在），`counter.count` 不变。对象方法应该用传统函数写法。

## 函数是一等公民

和 Python 一样，JS 的函数也是"一等公民"——可以赋值给变量、作为参数传递、作为返回值：

```javascript
// 作为参数（回调）
[1, 2, 3].map(x => x * 2);

// 作为返回值（闭包）
function makeAdder(n) {
  return x => x + n;
}
const add5 = makeAdder(5);
add5(3);  // 8
```

这点和 Python 完全一样，你已经理解了函数式编程的核心思想。

## 与 Python 的对比

| 特性 | Python | JavaScript |
|---|---|---|
| 函数定义 | `def f(x):` | `function f(x) {}` |
| 匿名函数 | `lambda x: x*2` | `(x) => x * 2` |
| 默认参数 | `def f(x=1):` | `function f(x=1) {}` |
| `*args` | `def f(*args):` | `function f(...args) {}` |
| 函数赋值 | `g = f` | `const g = f` |
| `this`/`self` | `self` 需手动传入 | `this` 自动绑定（箭头函数除外） |

## 小结

- 函数声明会被提升，函数表达式和箭头函数不会。
- 箭头函数语法简洁，类似 Python lambda 但更强大。
- 箭头函数没有自己的 `this`，继承外层作用域——对象方法别用箭头函数。
- 函数是一等公民：可赋值、可传参、可返回。
- 参数默认值：`undefined` 触发默认值，`null` 和 `""` 不会。
