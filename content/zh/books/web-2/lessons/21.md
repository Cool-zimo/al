# 表单取值：input、select、checkbox、radio 的正确取法

> 这一节解决"怎么从表单元素中拿到用户填的值"的问题——不同类型的输入框取法不同，用错方式会得到意外结果。

## input.value：最基础的取法

```javascript
const input = document.querySelector('#username');
const value = input.value;  // 获取用户输入的文本
console.log(value);
```

**注意：`value` 拿到的是字符串**，即使输入的是数字。

```javascript
const ageInput = document.querySelector('#age');
console.log(typeof ageInput.value);  // "string"，不是 "number"！

// 需要数字时要手动转换
const age = Number(ageInput.value);  // 或 parseInt(ageInput.value, 10)
```

## select 下拉框怎么取

```html
<select id="city">
  <option value="bj">北京</option>
  <option value="sh">上海</option>
  <option value="gz">广州</option>
</select>
```

```javascript
const citySelect = document.querySelector('#city');
console.log(citySelect.value);  // "bj"（选中的 option 的 value）

// 获取选中项的显示文本
const selectedText = citySelect.selectedOptions[0].textContent;  // "北京"
```

翻车现场一：用 textContent 取 select 的值。

```javascript
const citySelect = document.querySelector('#city');
console.log(citySelect.textContent);  // "北京\n  上海\n  广州" —— 所有选项的文本拼在一起！
// 不是当前选中的值！
```

后果：`select.textContent` 会返回所有 `<option>` 的文本拼接，而不是当前选中的值。正确用法是 `select.value`。

## checkbox：checked 属性

checkbox 不用 `value` 来判断是否选中，而是用 `.checked`（布尔值）。

```html
<input type="checkbox" id="agree">
<label for="agree">我已阅读并同意用户协议</label>
```

```javascript
const agree = document.querySelector('#agree');

// 判断是否勾选
if (agree.checked) {
  console.log('用户已同意');
}

// 设置勾选状态
agree.checked = true;   // 勾选
agree.checked = false;  // 取消勾选
```

翻车现场二：用 value 判断 checkbox 是否选中。

```javascript
const agree = document.querySelector('#agree');
console.log(agree.value);  // "on" —— 不管勾没勾选都是 "on"！

// agree.value 永远是 "on"（默认值），它不代表勾选状态
// 应该用 agree.checked
```

后果：`checkbox.value` 是 checkbox 的 value 属性值（默认 `"on"`），不会随勾选状态变化。`checked` 才是布尔值，表示是否勾选。

## radio：同一 name 的单选组

```html
<input type="radio" name="gender" value="male" id="male">
<label for="male">男</label>
<input type="radio" name="gender" value="female" id="female">
<label for="female">女</label>
<input type="radio" name="gender" value="other" id="other">
<label for="other">其他</label>
```

```javascript
// 遍历找到选中的那个
const selected = document.querySelector('input[name="gender"]:checked');
if (selected) {
  console.log(selected.value);  // "male" / "female" / "other"
} else {
  console.log('没有选中任何选项');
}
```

## 表单提交默认刷新页面

这是最经典的翻车场景：

```html
<form id="my-form">
  <input type="text" name="username" placeholder="用户名">
  <button type="submit">提交</button>
</form>
```

```javascript
document.querySelector('#my-form').addEventListener('submit', (event) => {
  // 如果不写 preventDefault，浏览器会：
  // 1. 刷新当前页面
  // 2. 把表单数据拼到 URL 上（GET）或发送请求（POST）
  // 3. 你的 JS 逻辑被打断

  event.preventDefault();  // ✅ 必须写！阻止默认刷新

  // 现在可以安全地用 JS 处理表单数据
  const form = event.target;
  const username = form.elements.username.value;
  console.log('用户提交：', username);
});
```

翻车现场三：忘记 preventDefault，页面一提交就刷新。

```javascript
document.querySelector('#my-form').addEventListener('submit', (event) => {
  // 忘了 event.preventDefault()！
  const data = { username: form.elements.username.value };
  fetch('/api/submit', {
    method: 'POST',
    body: JSON.stringify(data)
  });
  // fetch 发出去了，但页面立即刷新
  // 请求可能被中断，用户看到页面白屏或跳转
});
```

后果：表单提交后浏览器执行默认行为——刷新页面。所有异步请求（fetch）可能被中断，用户体验极差。页面状态全部丢失。

**最佳实践：在 submit 回调的第一行就写 `event.preventDefault()`。**

## FormData：批量取表单值

当表单字段很多时，用 `FormData` 一次拿到所有值：

```javascript
document.querySelector('#my-form').addEventListener('submit', (event) => {
  event.preventDefault();

  const formData = new FormData(event.target);
  console.log(formData.get('username'));   // 单个值
  console.log(formData.get('email'));      // 单个值

  // 转成普通对象
  const data = Object.fromEntries(formData.entries());
  console.log(data);  // { username: "张三", email: "zhangsan@example.com" }
});
```

## 各类型取值速查表

| 元素类型 | 取什么 | 怎么写 |
|---|---|---|
| `<input type="text">` | 文本内容 | `input.value` |
| `<input type="number">` | 数字（需转换） | `Number(input.value)` |
| `<select>` | 选中的 value | `select.value` |
| `<input type="checkbox">` | 是否勾选 | `checkbox.checked` |
| `<input type="radio">` | 选中的 value | `document.querySelector('input[name="x"]:checked').value` |
| `<textarea>` | 文本内容 | `textarea.value` |

## 与 Python 的对比

Python 的 Web 框架中，表单数据通常由框架自动解析：

```python
# Flask/Django 中表单数据在 request 对象里
# request.form 已经是一个类字典对象
username = request.form.get('username')
```

而 JS 中你需要手动从 DOM 元素上取值，每种输入类型的方式不同，这是初学者最容易踩坑的地方。

## 小结

- `input.value` 拿到的是**字符串**，数字需要 `Number()` 转换。
- `select` 用 `.value` 取选中项的 value，用 `.selectedOptions[0].textContent` 取显示文本。
- checkbox 用 `.checked`（布尔值），不是 `.value`。
- radio 用 `document.querySelector('input[name="x"]:checked').value` 取选中的值。
- 表单 `submit` 事件**必须** `event.preventDefault()`，否则页面刷新。
- `FormData` 适合批量获取表单数据。
