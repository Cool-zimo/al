# 什么是 DOM：树形结构与活的对象

> 这一节解决"DOM 到底是什么"的问题。这是 JS 独有的概念——Python 里没有 DOM。理解 DOM 是理解前端交互的基础。

## DOM 是一棵树

你已经学过 Python 的数据结构。DOM（Document Object Model）本质上就是一棵**树**，浏览器根据你写的 HTML 自动构建它。

```html
<!DOCTYPE html>
<html>
  <head>
    <title>张三的页面</title>
  </head>
  <body>
    <h1>你好</h1>
    <p class="intro">这是我的页面</p>
  </body>
</html>
```

浏览器解析后，DOM 树的结构是：

```
document
└── html
    ├── head
    │   └── title
    │       └── "张三的页面"（文本节点）
    └── body
        ├── h1
        │   └── "你好"（文本节点）
        └── p.intro
            └── "这是我的页面"（文本节点）
```

每个 HTML 标签变成一个**元素节点**，标签之间的文字变成**文本节点**。

## JS 拿到的是活的对象

DOM 最关键的特性：**JS 拿到的 DOM 对象不是副本，而是和页面共享的同一个对象。** 你改它，页面就变。

```javascript
// 获取 h1 元素
const h1 = document.querySelector('h1');

// 修改它的文字
h1.textContent = "你好，世界";

// 页面上的 h1 立刻变成"你好，世界"
```

这和 Python 里操作数据结构一样——你改了一个列表，所有引用它的地方都看到变化。DOM 就是浏览器暴露给你的一个"页面数据结构"，你可以读写它。

## document：入口对象

`document` 是 DOM 的**根**，所有操作都从它开始：

```javascript
document.title;              // 获取页面标题
document.title = "新标题";    // 修改页面标题（浏览器标签会更新！）
document.body;              // 获取 body 元素
document.documentElement;   // 获取 html 元素
document.head;              // 获取 head 元素
```

## 节点类型

DOM 里不止有元素节点：

```javascript
const h1 = document.querySelector('h1');

h1.nodeType;    // 1（元素节点）
h1.nodeName;    // "H1"（标签名大写）

// 文本节点
const textNode = h1.firstChild;
textNode.nodeType;  // 3（文本节点）
textNode.nodeValue; // "你好"
```

| nodeType | 含义 |
|---|---|
| 1 | 元素节点（div、p、h1...） |
| 3 | 文本节点 |
| 8 | 注释节点 |
| 9 | 文档节点（document） |

翻车现场一：直接操作文本节点。

```javascript
const h1 = document.querySelector('h1');
h1.nodeValue = "新文字";  // ❌ 不生效！h1 是元素节点，nodeValue 为 null
```

后果：元素节点的 `nodeValue` 是 `null`。要改文字，用 `textContent` 或 `innerHTML`。`nodeValue` 只对**文本节点**有效。

```javascript
// 正确做法
const textNode = h1.firstChild;  // 拿到文本节点
textNode.nodeValue = "新文字";    // ✅ 生效
// 或者更简单
h1.textContent = "新文字";       // ✅ 推荐
```

翻车现场二：脚本执行时 DOM 还没加载。

```html
<head>
  <script>
    // 此时 body 还没解析到！
    const h1 = document.querySelector('h1');  // null
    h1.textContent = "你好";  // ❌ TypeError
  </script>
</head>
<body>
  <h1>旧文字</h1>
</body>
```

后果：脚本在 `<head>` 里执行时，body 还没解析，`querySelector` 返回 `null`，后续操作报错。

**解决方案：**

```html
<!-- 方案 1：把脚本放 body 末尾 -->
<body>
  <h1>旧文字</h1>
  <script>
    document.querySelector('h1').textContent = "你好";  // ✅
  </script>
</body>

<!-- 方案 2：用 DOMContentLoaded 事件 -->
<script>
  document.addEventListener('DOMContentLoaded', function() {
    document.querySelector('h1').textContent = "你好";  // ✅
  });
</script>
```

## DOM 和 Python 的对比

Python 里没有 DOM 这个概念。但可以用你熟悉的概念类比：

| Python 概念 | DOM 对应 |
|---|---|
| 列表/字典 | DOM 树（嵌套的对象结构） |
| `dict["key"]` | `element.children`、`element.querySelector()` |
| `obj.attr = val` | `element.textContent = val` |
| 树形结构遍历 | DOM 树遍历 |
| 可变对象 | DOM 对象（改了就生效） |

## 小结

- DOM 是浏览器根据 HTML 自动构建的**树形数据结构**。
- `document` 是 DOM 的根，所有操作从它开始。
- DOM 对象是"活的"：JS 修改它，页面立即更新。
- 元素节点的 `nodeValue` 是 `null`，改文字用 `textContent`。
- 脚本要在 DOM 加载后执行（放 body 末尾或用 `DOMContentLoaded`）。

```quiz
type: js
q: 给定 HTML：<div id="app"><p class="msg">Hello</p></div>，写一个函数 getMessageText()：获取 class 为 "msg" 的元素，返回它的 textContent。需要处理元素不存在的情况。
func: getMessageText
starter: |
  function getMessageText() {
      // 用 querySelector 获取元素并返回 textContent
      return "";
  }
html: |
  <div id="app">
    <p class="msg">Hello</p>
  </div>
cases: |
  -> "Hello"
hint: document.querySelector('.msg').textContent。
explain: querySelector 通过 CSS 选择器获取元素，textContent 获取其文本内容。这就是 DOM 操作的基本模式：查到元素 → 读属性。
```
