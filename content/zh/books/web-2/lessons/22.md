# 表单验证：必填校验、格式校验与友好提示

> 这一节解决"怎么在用户提交前检查数据合法性，并给出清晰可读的错误提示"的问题。

## 为什么需要前端验证

前端验证的意义：
1. **即时反馈**——用户填错立刻知道，不用等提交后再报错。
2. **减少无效请求**——不合法的数据不应该发到服务器。
3. **更好的用户体验**——在正确位置显示正确信息。

## 必填校验

最简单的验证：检查字段是否为空。

```html
<form id="login-form">
  <input type="text" id="username" placeholder="用户名">
  <input type="password" id="password" placeholder="密码">
  <button type="submit">登录</button>
  <p id="error-msg" style="color: red;"></p>
</form>
```

```javascript
document.querySelector('#login-form').addEventListener('submit', (event) => {
  event.preventDefault();

  const username = document.querySelector('#username').value.trim();
  const password = document.querySelector('#password').value;
  const errorMsg = document.querySelector('#error-msg');

  if (username === '') {
    errorMsg.textContent = '用户名不能为空';
    return;  // 停止后续逻辑
  }

  if (password === '') {
    errorMsg.textContent = '密码不能为空';
    return;
  }

  // 全部通过，提交
  errorMsg.textContent = '';
  console.log('提交：', username, password);
});
```

**注意 `.trim()`**：用户可能输入全空格，`.trim()` 去掉首尾空格后再判断。

## 格式校验：正则表达式

```javascript
// 邮箱格式校验
function isValidEmail(email) {
  const re = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  return re.test(email);
}

// 手机号格式校验（中国大陆）
function isValidPhone(phone) {
  const re = /^1[3-9]\d{9}$/;
  return re.test(phone);
}

// 密码强度：至少8位，含字母和数字
function isStrongPassword(pwd) {
  return pwd.length >= 8 && /[a-zA-Z]/.test(pwd) && /\d/.test(pwd);
}
```

## 错误提示要具体可读

翻车现场一：只弹"错误"两个字。

```javascript
// ❌ 糟糕的提示
if (!isValid) {
  alert('错误');
  // 用户：什么错误？哪个字段？怎么改？
}
```

后果：用户完全不知道发生了什么，只能靠猜。体验极差，用户可能直接放弃。

```javascript
// ✅ 好的提示：具体、可读、指明方向
function showError(fieldName, reason) {
  const errorMsg = document.querySelector('#error-msg');
  errorMsg.textContent = `${fieldName}格式不正确：${reason}`;
}

// 使用示例
if (!isValidEmail(email)) {
  showError('邮箱', '请输入有效的邮箱地址，如 zhangsan@example.com');
  return;
}

if (!isValidPhone(phone)) {
  showError('手机号', '请输入11位有效手机号，如 13800138000');
  return;
}

if (!isStrongPassword(password)) {
  showError('密码', '密码至少8位，且必须同时包含字母和数字');
  return;
}
```

**好提示的三要素：**
1. **指明哪个字段**——"邮箱"而不是"输入"
2. **说明什么问题**——"格式不正确"而不是"错误"
3. **给出正确示例**——"如 13800138000"而不是只说"格式不对"

## 提交前统一校验

把校验逻辑封装成函数，返回校验结果：

```javascript
function validateForm(data) {
  const errors = [];

  if (!data.username.trim()) {
    errors.push({ field: 'username', message: '用户名不能为空' });
  } else if (data.username.length < 3) {
    errors.push({ field: 'username', message: '用户名至少需要3个字符' });
  }

  if (!data.email.trim()) {
    errors.push({ field: 'email', message: '邮箱不能为空' });
  } else if (!isValidEmail(data.email)) {
    errors.push({ field: 'email', message: '请输入有效的邮箱地址，如 zhangsan@example.com' });
  }

  if (!data.phone.trim()) {
    errors.push({ field: 'phone', message: '手机号不能为空' });
  } else if (!isValidPhone(data.phone)) {
    errors.push({ field: 'phone', message: '请输入11位有效手机号' });
  }

  return errors;  // 空数组表示全部通过
}

// 使用
document.querySelector('#my-form').addEventListener('submit', (event) => {
  event.preventDefault();

  const data = {
    username: document.querySelector('#username').value,
    email: document.querySelector('#email').value,
    phone: document.querySelector('#phone').value
  };

  const errors = validateForm(data);

  if (errors.length > 0) {
    // 显示第一个错误（或全部）
    document.querySelector('#error-msg').textContent = errors[0].message;
    // 聚焦到第一个出错的字段
    document.querySelector(`#${errors[0].field}`).focus();
    return;
  }

  // 全部通过
  document.querySelector('#error-msg').textContent = '';
  console.log('验证通过，提交数据：', data);
});
```

翻车现场二：校验顺序导致用户反复被提示。

```javascript
// ❌ 每次只提示一个错误，用户改一个提交后又报下一个
if (!data.username) { alert('用户名不能为空'); return; }
if (!data.email) { alert('邮箱不能为空'); return; }
if (!data.phone) { alert('手机号不能为空'); return; }
// 用户要提交3次才能看到所有问题
```

后果：用户每次提交只看到一个错误，需要反复提交多次才能把所有问题改完，体验极差。

```javascript
// ✅ 一次性收集所有错误，一次性展示
const errors = validateForm(data);
if (errors.length > 0) {
  // 把所有错误拼在一起展示
  const errorHtml = errors.map(e => `<li>${e.message}</li>`).join('');
  document.querySelector('#error-list').innerHTML = `<ul>${errorHtml}</ul>`;
  return;
}
```

## 实时校验（input 事件）

不在提交时才校验，而是在用户输入时就给反馈：

```javascript
document.querySelector('#email').addEventListener('input', (event) => {
  const value = event.target.value;
  const hint = document.querySelector('#email-hint');

  if (value === '') {
    hint.textContent = '';
    return;
  }

  if (!isValidEmail(value)) {
    hint.textContent = '请输入有效的邮箱格式，如 zhangsan@example.com';
    hint.style.color = 'red';
  } else {
    hint.textContent = '✓ 邮箱格式正确';
    hint.style.color = 'green';
  }
});
```

## HTML5 内置验证

浏览器也提供了内置验证属性，可以配合 JS 使用：

```html
<form id="my-form">
  <input type="email" required placeholder="邮箱">
  <input type="password" minlength="8" required placeholder="密码">
  <input type="tel" pattern="^1[3-9]\d{9}$" placeholder="手机号">
  <button type="submit">提交</button>
</form>
```

```javascript
document.querySelector('#my-form').addEventListener('submit', (event) => {
  event.preventDefault();

  const form = event.target;

  // checkValidity() 返回 true/false
  if (!form.checkValidity()) {
    // 浏览器会自动显示内置提示
    form.reportValidity();  // 触发浏览器内置错误提示
    return;
  }

  // 通过内置验证，继续自定义逻辑
  console.log('验证通过');
});
```

翻车现场三：只依赖 HTML5 验证，提示信息不友好。

```html
<!-- 浏览器默认的英文提示 "Please fill in this field" 对中文用户不友好 -->
<input type="email" required placeholder="邮箱">
```

后果：浏览器内置验证的提示语言取决于浏览器语言设置，可能无法满足产品需求。建议用 JS 自定义验证逻辑和提示。

## 与 Python 的对比

Python 后端验证通常在框架中完成：

```python
# Flask-WTF / Django Forms 自动生成验证逻辑
from wtforms import StringField, validators

class LoginForm(Form):
    username = StringField('用户名', [validators.Length(min=3, max=20)])
    email = StringField('邮箱', [validators.Email()])
```

JS 的优势在于**即时反馈**——用户填到一半就能看到提示，不用等提交到服务器再返回错误。

## 小结

- 前端验证提供即时反馈，减少无效请求。
- 必填校验用 `.trim()` + 空字符串判断。
- 格式校验用正则表达式（`test()` 方法）。
- 错误提示要**具体可读**：指明字段 + 说明问题 + 给出示例。
- 提交前统一校验，一次性收集所有错误，避免用户反复提交。
- 实时校验（input 事件）比提交时才校验体验更好。
- HTML5 内置验证（required、pattern、minlength）可以作为补充。
