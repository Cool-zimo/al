# map、filter、reduce：函数式三剑客

> 这一节解决"JS 怎么用函数式的方式处理数组"的问题。你学过 Python 的列表推导和 `map`/`filter`，JS 有对应的方法，用法更优雅。

## map：转换每个元素

```javascript
const numbers = [1, 2, 3, 4];

// 每个元素乘 2
const doubled = numbers.map(n => n * 2);
console.log(doubled);  // [2, 4, 6, 8]

// 提取对象属性
const users = [
  { name: "张三", age: 25 },
  { name: "李四", age: 30 }
];
const names = users.map(u => u.name);
console.log(names);    // ["张三", "李四"]
```

Python 对比：

```python
numbers = [1, 2, 3, 4]
doubled = [n * 2 for n in numbers]  # 列表推导
names = [u["name"] for u in users]
```

## filter：筛选元素

```javascript
const numbers = [1, 2, 3, 4, 5, 6];

const evens = numbers.filter(n => n % 2 === 0);
console.log(evens);  // [2, 4, 6]

const users = [
  { name: "张三", age: 17 },
  { name: "李四", age: 25 },
  { name: "王五", age: 16 }
];
const adults = users.filter(u => u.age >= 18);
console.log(adults);  // [{ name: "李四", age: 25 }]
```

Python 对比：

```python
evens = [n for n in numbers if n % 2 == 0]  # 带条件的列表推导
adults = [u for u in users if u["age"] >= 18]
```

## reduce：归约为单个值

```javascript
const numbers = [1, 2, 3, 4];

// 求和
const sum = numbers.reduce((acc, n) => acc + n, 0);
console.log(sum);  // 10

// 找最大值
const max = numbers.reduce((acc, n) => Math.max(acc, n));
console.log(max);  // 4

// 统计词频
const words = ["apple", "banana", "apple", "cherry", "banana", "apple"];
const freq = words.reduce((acc, word) => {
  acc[word] = (acc[word] || 0) + 1;
  return acc;
}, {});
console.log(freq);  // { apple: 3, banana: 2, cherry: 1 }
```

Python 对比：

```python
from functools import reduce
sum_result = reduce(lambda acc, n: acc + n, numbers, 0)

# Python 3.8+ 更常用 collections.Counter
from collections import Counter
freq = dict(Counter(words))
```

## 链式调用：三剑客合体

```javascript
const users = [
  { name: "张三", age: 17, city: "北京" },
  { name: "李四", age: 25, city: "上海" },
  { name: "王五", age: 30, city: "北京" },
  { name: "赵六", age: 16, city: "广州" }
];

// 找出所有北京的成年人，返回他们的名字（大写）
const result = users
  .filter(u => u.city === "北京")
  .filter(u => u.age >= 18)
  .map(u => u.name.toUpperCase());

console.log(result);  // ["王五"]
```

翻车现场一：map 忘了 return。

```javascript
const numbers = [1, 2, 3];
const doubled = numbers.map(n => {
  n * 2;  // ❌ 没有 return！
});
console.log(doubled);  // [undefined, undefined, undefined]
```

后果：用花括号 `{}` 写箭头函数体时，**必须显式写 `return`**。要么省略花括号（隐式返回），要么写 return。

```javascript
// 正确写法 1：省略花括号（隐式 return）
numbers.map(n => n * 2);

// 正确写法 2：写花括号 + return
numbers.map(n => {
  return n * 2;
});
```

翻车现场二：reduce 不传初始值。

```javascript
const numbers = [];

// 不传初始值
const sum = numbers.reduce((acc, n) => acc + n);
// TypeError: Reduce of empty array with no initial value

// 传了初始值就没问题
const sum = numbers.reduce((acc, n) => acc + n, 0);  // 0
```

后果：空数组上调用 `reduce` 且不传初始值会报错。养成习惯：**reduce 永远传初始值**。

## 性能考虑

链式调用会创建多个中间数组：

```javascript
// 三次遍历，创建两个中间数组
const result = arr.filter(...).map(...);

// 大数据量时，一次遍历更高效
const result = [];
for (const item of arr) {
  if (condition(item)) {
    result.push(transform(item));
  }
}
```

日常开发中链式调用的可读性远胜性能差异。只有处理**上万条数据**时才需要考虑合并遍历。

## 与 Python 的对比

| 操作 | Python | JavaScript |
|---|---|---|
| 转换 | `[f(x) for x in arr]` / `map(f, arr)` | `arr.map(f)` |
| 筛选 | `[x for x in arr if cond]` / `filter(cond, arr)` | `arr.filter(cond)` |
| 归约 | `reduce(f, arr, init)` | `arr.reduce(f, init)` |
| 链式 | 嵌套列表推导 | 方法链式调用 |
| 隐式 return | lambda 自动返回 | 箭头函数省略 `{}` 时自动返回 |

## 小结

- `map(fn)` 对每个元素应用函数，返回新数组。
- `filter(fn)` 保留 fn 返回 true 的元素，返回新数组。
- `reduce(fn, init)` 从左到右归约为单个值，**永远传初始值**。
- 箭头函数用 `{}` 时忘了 return 是常见 bug。
- 链式调用可读性好，小数据量下性能差异可以忽略。
