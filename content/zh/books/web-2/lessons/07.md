# 遍历：for、for...of、forEach 与 return 的陷阱

> 这一节解决"JS 里怎么遍历数组"的问题。JS 有多种遍历方式，它们之间有微妙但重要的差异——尤其是 `forEach` 里 `return` 不能跳出循环。

## 四种遍历方式

### 1. 传统 for 循环

```javascript
const arr = [10, 20, 30];
for (let i = 0; i < arr.length; i++) {
  console.log(arr[i]);
}
```

和 Python 的 `for i in range(len(arr))` 类似。有索引，可以灵活控制流程。

### 2. for...of（推荐）

```javascript
for (const item of arr) {
  console.log(item);
}
```

和 Python 的 `for item in arr` 几乎一样。简洁，直接拿到元素值。

### 3. forEach

```javascript
arr.forEach(function(item) {
  console.log(item);
});
// 或箭头函数
arr.forEach(item => console.log(item));
```

### 4. for...in（不推荐用于数组）

```javascript
for (const i in arr) {
  console.log(i);  // "0", "1", "2"（字符串索引！）
}
```

## forEach 里 return 不跳出循环！

这是 JS 的经典坑。很多从 Python 转过来的人会踩：

```javascript
// Python：找到第一个偶数就返回
numbers = [1, 3, 4, 5, 6]
for n in numbers:
    if n % 2 == 0:
        print(n)
        break  # 跳出循环
# 输出：4
```

```javascript
// JS：想在 forEach 里"提前结束"
[1, 3, 4, 5, 6].forEach(function(n) {
  if (n % 2 === 0) {
    console.log(n);
    return;  // ❌ 这只是跳过当前迭代，不是跳出循环！
  }
});
// 输出：4, 6（两个都打印了！）
```

翻车现场一：以为 forEach 里的 return 能 break。

```javascript
function findFirstEven(arr) {
  arr.forEach(function(n) {
    if (n % 2 === 0) {
      return n;  // ❌ 这个 return 只是跳过当前回调，不会返回到外层函数！
    }
  });
  return -1;  // 永远执行到这里
}
findFirstEven([1, 3, 4, 5]);  // 返回 -1，不是 4！
```

后果：`forEach` 的 `return` 相当于 Python 的 `continue`——跳过当前迭代，继续下一个。它**不能**跳出整个循环，也**不能**从外层函数返回值。

**解决方案：**

```javascript
// 方案 1：用 for...of + break（最接近 Python 的写法）
function findFirstEven(arr) {
  for (const n of arr) {
    if (n % 2 === 0) {
      return n;  // ✅ 从函数返回
    }
  }
  return -1;
}

// 方案 2：用 find()（更函数式）
function findFirstEven(arr) {
  return arr.find(n => n % 2 === 0) ?? -1;
}
```

## 三种遍历方式的选择

| 场景 | 推荐方式 | 原因 |
|---|---|---|
| 需要索引 | `for` 或 `forEach` | for...of 需要 `entries()` |
| 需要 break/continue | `for` 或 `for...of` | forEach 无法跳出 |
| 需要返回值 | `for`/`for...of` 或 `map`/`find` | forEach 的 return 不管用 |
| 纯遍历无控制流 | `forEach` | 语义清晰 |
| 需要转换每个元素 | `map` | 返回新数组 |
| 需要过滤 | `filter` | 返回新数组 |

## for...in 的陷阱

```javascript
const arr = [10, 20, 30];
arr.customProp = "oops";  // 给数组加了个自定义属性

for (const key in arr) {
  console.log(key);  // "0", "1", "2", "customProp"！
}
```

后果：`for...in` 遍历的是**所有可枚举属性**（包括自定义属性），得到的是字符串键。它会遍历到原型链上的属性，还会遍历到手动添加的非数字属性。

**永远用 `for...of` 遍历数组，永远用 `for...in` 遍历对象。**

## 与 Python 的对比

```python
# Python
numbers = [10, 20, 30]

for n in numbers:      # JS 的 for...of
    print(n)

for i in range(len(numbers)):  # JS 的 for
    print(numbers[i])

for i, n in enumerate(numbers):  # JS 的 for...of + entries()
    print(i, n)
```

```javascript
// JavaScript
const numbers = [10, 20, 30];

for (const n of numbers) { }       // Python 的 for...in
for (let i = 0; i < numbers.length; i++) { }  // Python 的 range(len())
for (const [i, n] of numbers.entries()) { }    // Python 的 enumerate
numbers.forEach(n => { });         // Python 没有直接对应
```

## 小结

- `for...of` 是最常用的遍历方式，行为类似 Python 的 `for...in`。
- `forEach` 里的 `return` 只是跳过当前迭代（相当于 `continue`），**不能 break 也不能从外层函数 return**。
- 需要 break 或返回值时，用 `for`/`for...of` 或数组方法（`find`、`some`、`every`）。
- `for...in` 遍历所有可枚举属性（含自定义的），不要用它遍历数组。
- `for...in` 遍历对象，`for...of` 遍历数组——这是铁律。

```quiz
q: 写一个函数 findIndex(arr, target)：找到 target 在 arr 中第一次出现的索引，找不到返回 -1。用 for...of 遍历，找到时用 break 跳出。不要用 indexOf。
func: findIndex
starter: |
  function findIndex(arr, target) {
      // 用 for...of + entries() 获取索引
      let result = -1;
      return result;
  }
cases: |
  [1, 2, 3, 4], 3 -> 2
  [1, 2, 3], 5 -> -1
  [10, 20, 30], 10 -> 0
  ["a", "b", "c"], "b" -> 1
hint: 用 for (const [i, item] of arr.entries()) 获取索引和值。
explain: for...of 配合 entries() 同时拿到索引和值，找到目标后 break 跳出循环。这比 forEach 更灵活，因为可以 break。
```
