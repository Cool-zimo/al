# 常见事件：click / input / submit / keydown 与 preventDefault

> 这一节解决"日常开发中常用的事件有哪些，怎么用，以及 preventDefault 是什么"的问题。

## 四个高频事件

### 1. click：点击事件

```javascript
button.addEventListener('click', function() {
  console.log('按钮被点击');
});
```

适用：按钮、链接、卡片、列表项。

### 2. input：输入内容变化

```javascript
const input = document.querySelector('#search');

input.addEventListener('input', function(event) {
  console.log('当前输入：', event.target.value);
});
```

每次按键都会触发（包括删除、粘贴、中文输入）。

对比 `change` 事件：只在**失去焦点且值变化**时触发。

### 3. submit：表单提交

```javascript
const form = document.querySelector('#login-form');

form.addEventListener('submit', function(event) {
  event.preventDefault();  // 阻止默认提交（刷新页面）
  // 自己处理表单数据
  const username = form.elements.username.value;
  const password = form.elements.password.value;
  login(username, password);
});
```

### 4. keydown：键盘按键

```javascript
document.addEventListener('keydown', function(event) {
  console.log('按下的键：', event.key);
  console.log('键码：', event.code);

  if (event.key === 'Enter') {
    console.log('按了回车');
  }

  if (event.ctrlKey && event.key === 's') {
    event.preventDefault();  // 阻止浏览器保存页面
    console.log('Ctrl+S 被拦截');
  }
});
```

## preventDefault：阻止默认行为

每个事件都有对应的**浏览器默认行为**：

| 事件 | 默认行为 | 阻止后的效果 |
|---|---|---|
| `submit` | 刷新页面、发送 GET 请求 | 页面不刷新，JS 自己处理 |
| `click`（在 a 标签上） | 跳转到 href | 不跳转 |
| `keydown`（在输入框） | 输入字符 | 不输入 |
| `contextmenu` | 显示右键菜单 | 不显示 |
| `wheel` / `touchmove` | 页面滚动 | 不滚动 |

翻车现场一：忘记 preventDefault 导致表单提交后页面刷新。

```javascript
const form = document.querySelector('#my-form');

form.addEventListener('submit', function(event) {
  // 忘了 event.preventDefault()！
  const data = new FormData(form);
  fetch('/api/submit', { method: 'POST', body: data });
  // 页面立即刷新，fetch 被中断，用户看到空白页面
});
```

后果：表单提交后浏览器执行默认行为——刷新页面（或跳转），所有 JS 逻辑和 fetch 请求被中断。用户体验极差。

**解决：在 submit 回调的最开始就写 `event.preventDefault()`。**

```javascript
form.addEventListener('submit', function(event) {
  event.preventDefault();  // 第一步：阻止默认刷新

  // 第二步：自己处理
  const input = form.querySelector('input');
  console.log('用户输入：', input.value);
});
```

翻车现场二：用 keydown 阻止输入但忘了阻止粘贴。

```javascript
const input = document.querySelector('#numeric');

input.addEventListener('keydown', function(event) {
  if (!/[0-9]/.test(event.key)) {
    event.preventDefault();  // 阻止非数字输入
  }
});

// 但用户可以通过粘贴输入 "abc"！
// keydown 拦不住粘贴操作
```

后果：`keydown` 只能拦截键盘输入，粘贴（Ctrl+V）走的是 `paste` 事件。要完全控制输入，还需要监听 `paste` 事件，或者在 `input` 事件里做过滤（最可靠）。

```javascript
// 更可靠的方案：在 input 事件中过滤
input.addEventListener('input', function() {
  this.value = this.value.replace(/[^0-9]/g, '');
});
```

## 实时搜索示例

```html
<input type="text" id="search" placeholder="搜索...">
<ul id="results"></ul>
```

```javascript
const search = document.querySelector('#search');
const results = document.querySelector('#results');

const allItems = ['苹果', '香蕉', '橙子', '西瓜', '葡萄'];

search.addEventListener('input', function() {
  const keyword = this.value.toLowerCase();

  // 过滤
  const matched = allItems.filter(item =>
    item.toLowerCase().includes(keyword)
  );

  // 渲染
  results.innerHTML = '';
  matched.forEach(item => {
    const li = document.createElement('li');
    li.textContent = item;
    results.appendChild(li);
  });
});
```

## 键盘事件对象属性

```javascript
document.addEventListener('keydown', function(event) {
  event.key;        // "a"、"Enter"、"ArrowUp"、"Escape"
  event.code;       // "KeyA"、"Enter"、"ArrowUp"、"Escape"
  event.ctrlKey;    // 是否按住 Ctrl
  event.shiftKey;   // 是否按住 Shift
  event.altKey;     // 是否按住 Alt
  event.metaKey;    // 是否按住 Cmd（Mac）
});
```

翻车现场三：用 keyCode（已废弃）。

```javascript
document.addEventListener('keydown', function(event) {
  if (event.keyCode === 13) {  // ❌ keyCode 已废弃！
    // ...
  }
});
```

后果：`keyCode` 已被标准废弃（deprecated），不同浏览器可能有差异。应该用 `event.key`：

```javascript
document.addEventListener('keydown', function(event) {
  if (event.key === 'Enter') {  // ✅ 语义清晰
    // ...
  }
});
```

## 与 Python 的对比

Python 的终端程序没有"事件"的概念——它是顺序执行的：

```python
# Python：阻塞式输入
while True:
    cmd = input("> ")  # 等待用户输入，回车后才有值
    if cmd == "quit":
        break
    print(f"执行：{cmd}")
```

JS 的事件模型是非阻塞的——注册监听器后代码继续往下走，不知道什么时候会触发：

```javascript
input.addEventListener('input', function(e) {
  console.log(e.target.value);  // 不知道什么时候执行
});
console.log('这行先执行');  // 先输出
```

## 小结

- `click` 用于点击交互，`input` 用于实时输入，`submit` 用于表单，`keydown` 用于键盘。
- `preventDefault()` 阻止浏览器默认行为，表单处理中**必须**调用。
- `input` 事件比 `keydown` 更适合做输入过滤（能拦截粘贴）。
- 键盘事件用 `event.key` 判断按键，不用废弃的 `keyCode`。
- 事件对象上的 `ctrlKey`/`shiftKey` 可以判断组合键。
