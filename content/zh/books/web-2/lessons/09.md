# 对象：增删改查、遍历与属性不存在的陷阱

> 这一节解决"JS 对象怎么增删改查、怎么遍历"的问题。你已经知道 JS 对象类似 Python dict，但有一些独特的操作方式需要注意。

## 增删改查

```javascript
const person = {
  name: "张三",
  age: 25
};

// 增（两种方式）
person.city = "北京";       // 点号
person["country"] = "中国";  // 方括号

// 改
person.age = 26;

// 查
console.log(person.name);    // "张三"
console.log(person["age"]);  // 26

// 删
delete person.city;          // true（返回删除是否成功）
console.log(person.city);    // undefined
```

和 Python 的对比：

```python
person = {"name": "张三", "age": 25}
person["city"] = "北京"   # 只能用方括号
del person["city"]
```

## 遍历对象的三种方式

### 1. for...in

```javascript
const person = { name: "张三", age: 25, city: "北京" };

for (const key in person) {
  console.log(key, person[key]);
}
// name 张三
// age 25
// city 北京
```

注意：`for...in` 会遍历到**原型链上的可枚举属性**。

### 2. Object.keys() / Object.values() / Object.entries()

```javascript
const person = { name: "张三", age: 25 };

Object.keys(person);    // ["name", "age"]
Object.values(person);  // ["张三", 25]
Object.entries(person); // [["name", "张三"], ["age", 25]]

// 配合 for...of 遍历
for (const [key, value] of Object.entries(person)) {
  console.log(`${key}: ${value}`);
}
```

### 3. Object.getOwnPropertyNames()

```javascript
const person = { name: "张三", age: 25 };
Object.getOwnPropertyNames(person);  // ["name", "age"]
```

## 属性不存在返回 undefined

这是 JS 和 Python 最本质的差异：

```javascript
const person = { name: "张三" };

person.age;        // undefined（不报错！）
person["city"];    // undefined（不报错！）
```

Python 里 `person["age"]` 会抛出 `KeyError`。JS 里返回 `undefined`，**代码继续执行**——这可能是好事（不用 try-catch），也可能是坏事（bug 被掩盖）。

翻车现场一：链式访问中的 undefined。

```javascript
function getDiscount(user) {
  return user.membership.level * 0.1;  // user.membership 可能是 undefined！
}

getDiscount({ name: "张三" });
// TypeError: Cannot read properties of undefined (reading 'level')
```

后果：代码报错，且报错信息不够清晰（"reading 'level'" 不知道是 `user` 还是 `membership` 是 undefined）。解决：

```javascript
// 方案 1：逐层防御
function getDiscount(user) {
  if (!user || !user.membership) return 0;
  return user.membership.level * 0.1;
}

// 方案 2：可选链（现代写法，推荐）
function getDiscount(user) {
  return user?.membership?.level * 0.1 || 0;
}
```

翻车现场二：用 `undefined` 参与计算。

```javascript
const product = { price: 100 };  // 忘了加 quantity 属性
const total = product.price * product.quantity;  // 100 * undefined = NaN
console.log(total);  // NaN（静默失败！）
```

后果：`undefined` 和数字运算得到 `NaN`，后续所有计算都变成 `NaN`，而且**不报错**。这种 bug 非常隐蔽。解决：用默认值 `|| 1` 或 `?? 1`。

## 判断属性是否存在

```javascript
const person = { name: "张三", age: undefined };

"name" in person;            // true（不关心值，只关心键是否存在）
person.hasOwnProperty("name"); // true（推荐，不含原型链）

// ❌ 错误方式
person.name !== undefined;    // false！但 name 属性确实存在（值为 undefined）
```

翻车现场三：用 `!== undefined` 判断属性存在。

```javascript
const config = { timeout: undefined };
if (config.timeout !== undefined) {
  setTimeout(fetchData, config.timeout);
}
// timeout 属性存在但值为 undefined，判断失效
```

后果：当属性值**恰好**是 `undefined` 时，`!== undefined` 判断会误判为"属性不存在"。正确做法：`"timeout" in config` 或 `config.hasOwnProperty("timeout")`。

## 对象的其他常用方法

```javascript
// 合并对象
const defaults = { theme: "light", lang: "zh" };
const userPrefs = { theme: "dark" };
const merged = { ...defaults, ...userPrefs };
// { theme: "dark", lang: "zh" }

// 深拷贝（浅层）
const copy = { ...original };

// 冻结（不可修改）
const frozen = Object.freeze({ name: "张三" });
frozen.name = "李四";  // 静默失败（严格模式报错）

// 检查是否为纯对象
typeof obj === 'object' && obj !== null && !Array.isArray(obj);
```

## 与 Python 的对比

| 操作 | Python | JavaScript |
|---|---|---|
| 检查键是否存在 | `"key" in d` / `d.get("key")` | `"key" in obj` / `obj.hasOwnProperty("key")` |
| 获取所有键 | `d.keys()` | `Object.keys(obj)` |
| 获取所有值 | `d.values()` | `Object.values(obj)` |
| 合并字典 | `{**d1, **d2}` | `{...o1, ...o2}` |
| 删除键 | `del d["key"]` | `delete obj.key` |
| 不存在时的默认 | `d.get("key", default)` | `obj.key ?? default` |

## 小结

- 对象增删改查：`obj.key = val`、`delete obj.key`、`obj.key`。
- 遍历用 `for...in` 或 `Object.keys()`/`entries()` 配合 `for...of`。
- 属性不存在返回 `undefined`，不报错——既是便利也是隐患。
- 判断属性存在用 `in` 或 `hasOwnProperty`，不要用 `!== undefined`。
- 可选链 `?.` 是现代 JS 处理嵌套对象的利器。
- 对象字面量展开 `{...obj}` 实现浅拷贝和合并。
