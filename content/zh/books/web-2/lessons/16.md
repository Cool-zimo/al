# 第一个事件：addEventListener

> 这一节解决"怎么让页面响应用户操作"的问题。Python 脚本是顺序执行的——读完最后一行就结束了。浏览器不一样：**代码执行完，浏览器还在等**——等用户点击、输入、滚动。这就是事件驱动。

## 事件驱动模型

```python
# Python 脚本：顺序执行，执行完就退出
print("开始")
name = input("请输入名字：")  # 阻塞等待用户输入
print(f"你好，{name}")
# 程序结束
```

```javascript
// JavaScript：执行完同步代码后，浏览器继续"等"
console.log("脚本执行完毕");

document.querySelector('button').addEventListener('click', function() {
  console.log("用户点击了按钮！");  // 不知道什么时候会执行
});

console.log("开始等待用户操作...");
// 同步代码到这里结束
// 但浏览器不会退出——它在等用户点击
```

**这就是事件驱动**：你注册一个"当某件事发生时执行什么"，然后浏览器在后台等待。

## addEventListener：注册事件

```javascript
const button = document.querySelector('#myBtn');

button.addEventListener('click', function(event) {
  console.log('按钮被点击了！');
});
```

三个要素：
1. **事件类型**（'click'）：什么时候触发。
2. **回调函数**：触发时执行什么。
3. **目标元素**：谁在监听。

## 为什么不用 onclick=

HTML 属性方式：

```html
<button onclick="handleClick()">点击</button>
```

JS 属性方式：

```javascript
button.onclick = function() {
  console.log('点击');
};
```

**问题：`onclick` 只能绑定一个处理函数。**

```javascript
const button = document.querySelector('#myBtn');

// 第一个处理器被覆盖了！
button.onclick = function() { console.log('第一个'); };
button.onclick = function() { console.log('第二个'); };
// 点击时只输出"第二个"
```

用 `addEventListener` 可以绑定多个：

```javascript
button.addEventListener('click', function() { console.log('第一个'); });
button.addEventListener('click', function() { console.log('第二个'); });
// 点击时两个都执行
```

翻车现场一：脚本在元素之前执行。

```html
<head>
  <script>
    // 此时按钮还不存在！
    document.querySelector('#myBtn').addEventListener('click', handler);
    // TypeError: Cannot read properties of null
  </script>
</head>
<body>
  <button id="myBtn">点击</button>
</body>
```

后果：脚本执行时按钮还没解析到，`querySelector` 返回 `null`。解决：把脚本放 `</body>` 前，或用 `DOMContentLoaded` 包裹。

翻车现场二：用 `onclick` 赋值覆盖了已有处理器。

```javascript
// 第三方库已经绑定了一个处理器
button.onclick = function() { trackClick(); };

// 你的代码
button.onclick = function() { showModal(); };
// trackClick 永远不执行了！被覆盖了！
```

后果：`onclick` 是属性赋值，后面的值覆盖前面的。这在团队协作或引入第三方库时尤其危险。永远用 `addEventListener`。

## 常用事件类型

| 事件 | 触发时机 | 常用元素 |
|---|---|---|
| `click` | 点击 | button、a、div |
| `input` | 输入框内容变化 | input、textarea |
| `change` | 值确认改变 | select、checkbox |
| `submit` | 表单提交 | form |
| `keydown` / `keyup` | 键盘按键 | document、input |
| `mouseover` / `mouseout` | 鼠标移入/移出 | 任意元素 |
| `load` | 资源加载完成 | window、img |
| `scroll` | 页面/元素滚动 | window、可滚动元素 |
| `focus` / `blur` | 获得/失去焦点 | input |

## 事件对象 event

回调函数的第一个参数是**事件对象**，包含这次事件的详细信息：

```javascript
button.addEventListener('click', function(event) {
  console.log(event.type);     // "click"
  console.log(event.target);   // 被点击的元素
  console.log(event.clientX);  // 鼠标 X 坐标
});
```

## 与 Python 的对比

Python 没有内建的事件驱动模型（除非用 GUI 框架如 Tkinter）：

```python
# Tkinter 的事件驱动（类似）
import tkinter as tk

root = tk.Tk()
button = tk.Button(root, text="点击")
button.bind("<Button-1>", lambda e: print("点击"))  # 类似 addEventListener
root.mainloop()  # 进入事件循环
```

`button.bind("<Button-1>", callback)` 就类似 `addEventListener('click', callback)`。Python GUI 框架和 JS 的事件模型本质相同，但 JS 浏览器环境天然支持，不需要 `mainloop()`。

## 小结

- 浏览器是事件驱动的：代码执行完后继续等待用户操作。
- `addEventListener(type, callback)` 注册事件处理器。
- `onclick` 只能绑定一个处理器且容易覆盖，`addEventListener` 可以绑定多个。
- 脚本要在 DOM 加载后执行（放 body 末尾或用 DOMContentLoaded）。
- 事件对象是回调的第一个参数，包含事件详细信息。
