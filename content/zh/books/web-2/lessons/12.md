# 查询元素：getElementById / querySelector / querySelectorAll

> 这一节解决"怎么从 DOM 树里找到我想要的元素"的问题。这是所有 DOM 操作的第一步——先找到，再操作。

## 三种查询方式

### 1. getElementById：按 ID 查

```javascript
const button = document.getElementById('submit-btn');
```

- 返回**单个元素**或 `null`。
- 速度最快（浏览器维护了 ID 索引）。
- 只能用 ID，不能用其他选择器。

### 2. querySelector：按 CSS 选择器查第一个

```javascript
document.querySelector('.intro');       // 第一个 class="intro" 的元素
document.querySelector('#header');     // 第一个 id="header" 的元素
document.querySelector('p:first-child'); // 第一个 p（作为子元素）
document.querySelector('ul li');        // 第一个 ul 里的第一个 li
```

- 返回**第一个匹配的元素**或 `null`。
- 用 CSS 选择器语法，非常灵活。

### 3. querySelectorAll：按 CSS 选择器查所有

```javascript
document.querySelectorAll('.item');     // 所有 class="item" 的元素
document.querySelectorAll('li');        // 所有 li 元素
document.querySelectorAll('div > p');   // 所有 div 的直接子 p
```

- 返回 **NodeList**（类似数组但不是数组）。
- 没有匹配时返回**空 NodeList**（不是 `null`！）。

## NodeList vs Array

```javascript
const items = document.querySelectorAll('.item');

items.length;      // 数量
items[0];          // 第一个元素

// NodeList 有 forEach 但没有 map/filter
items.forEach(item => console.log(item));

// 需要 map/filter 时转成数组
const arr = Array.from(items);
const arr2 = [...items];  // 展开运算符也行
```

翻车现场一：querySelectorAll 返回 null。

```javascript
const items = document.querySelectorAll('.nonexistent');
if (items === null) {  // ❌ 永远不会为 true！
  console.log("没找到");
}
console.log(items);  // NodeList []（空的，但不是 null）
```

后果：`querySelectorAll` 找不到元素时返回**空 NodeList**，不是 `null`。判断应该用 `items.length === 0`。

而 `querySelector` 找不到时返回 `null`：

```javascript
const item = document.querySelector('.nonexistent');
if (item === null) {  // ✅ 正确
  console.log("没找到");
}
```

**记住：`querySelector` 返回 null，`querySelectorAll` 返回空 NodeList。**

翻车现场二：getElementById 的 ID 大小写。

```javascript
// HTML: <button id="SubmitBtn">点击</button>
document.getElementById('submit-btn');  // null！ID 区分大小写
```

后果：HTML 的 ID 是区分大小写的，`SubmitBtn` ≠ `submit-btn`。这和 CSS 选择器一致。

## 查询范围：document vs 子元素

```javascript
// 从整个文档查
document.querySelector('.item');

// 从某个元素内部查（缩小范围，更高效）
const container = document.getElementById('container');
container.querySelector('.item');      // 只在 container 内部找
container.querySelectorAll('.item');   // 只在 container 内部找
```

```javascript
// 获取直接子元素
element.children;        // 所有子元素（HTMLCollection）
element.childNodes;     // 所有子节点（含文本节点、注释节点）

// 获取父元素
element.parentNode;     // 父节点
element.parentElement;  // 父元素（跳过非元素节点）

// 获取兄弟元素
element.nextElementSibling;
element.previousElementSibling;
```

翻车现场三：children 是动态集合。

```javascript
const container = document.getElementById('list');
const items = container.children;  // HTMLCollection（动态！）

console.log(items.length);  // 3

// 添加新元素
const newItem = document.createElement('li');
container.appendChild(newItem);

console.log(items.length);  // 4！HTMLCollection 是动态的
```

后果：`children`（HTMLCollection）和 `querySelectorAll`（NodeList）在大多数浏览器中是**动态的**——DOM 变化后它们会自动更新。这在循环中可能导致意外：

```javascript
// ❌ 危险：children 是动态的，循环中会跳过元素
for (let i = 0; i < container.children.length; i++) {
  container.removeChild(container.children[i]);
  // i=0 删掉第 0 个，原来的第 1 个变成第 0 个
  // i=1 删掉现在的第 1 个（原来的第 2 个），第 1 个被跳过了！
}
```

正确做法：倒序遍历或先转成静态数组：

```javascript
// ✅ 方案 1：倒序
for (let i = container.children.length - 1; i >= 0; i--) {
  container.removeChild(container.children[i]);
}

// ✅ 方案 2：转数组
const items = [...container.children];
items.forEach(item => container.removeChild(item));
```

## 与 Python 的对比

Python 里没有 DOM 查询的概念，但可以类比：

```python
# 如果把 DOM 比作嵌套字典
dom = {
    "tag": "div",
    "children": [
        {"tag": "h1", "text": "Hello"},
        {"tag": "p", "text": "World"}
    ]
}
# 手动查找类似 querySelector 的逻辑
def find_by_tag(dom, tag):
    if dom["tag"] == tag:
        return dom
    for child in dom.get("children", []):
        result = find_by_tag(child, tag)
        if result:
            return result
```

JS 的 `querySelector` 帮你做了这件事，而且用 CSS 选择器语法，比手动递归优雅得多。

## 小结

- `getElementById` 最快，但只能按 ID 查。
- `querySelector` 返回第一个匹配，`querySelectorAll` 返回所有匹配。
- `querySelector` 找不到返回 `null`，`querySelectorAll` 找不到返回**空 NodeList**。
- NodeList 有 `forEach` 但没有 `map`/`filter`，需要转数组。
- 动态集合（HTMLCollection）在 DOM 变化时会自动更新，循环中要注意。
