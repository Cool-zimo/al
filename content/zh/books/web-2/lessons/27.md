# 搭结构与样式：HTML 骨架与 CSS 布局

> 这一节解决"怎么把上一节设计的界面草图变成实际的 HTML 和 CSS"的问题。

## HTML 骨架

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>我的待办</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <div class="container">
    <h1>✦ 我的待办</h1>

    <!-- 输入区 -->
    <div class="input-area">
      <input type="text" id="todo-input" placeholder="输入新任务...">
      <button id="add-btn">添加</button>
    </div>

    <!-- 任务列表 -->
    <ul id="todo-list"></ul>

    <!-- 筛选区 -->
    <div class="filter-area">
      <button class="filter-btn active" data-filter="all">全部</button>
      <button class="filter-btn" data-filter="active">未完成</button>
      <button class="filter-btn" data-filter="completed">已完成</button>
    </div>

    <!-- 统计 -->
    <p id="stats">共 0 项</p>
  </div>

  <script src="app.js"></script>
</body>
</html>
```

**关键点：**
- 列表区域 `<ul id="todo-list">` 初始为空，由 JS 动态渲染。
- 筛选按钮用 `data-filter` 属性存储筛选条件，方便 JS 读取。
- `script` 放在 body 末尾，确保 DOM 加载后再执行 JS。

## 布局要点解析

### Flexbox 输入区

```css
.input-area {
  display: flex;
  gap: 10px;  /* 子元素间距 */
}

#todo-input {
  flex: 1;  /* 输入框占据剩余空间 */
}

#add-btn {
  /* 按钮宽度由内容决定 */
}
```

### Flexbox 列表项

```css
#todo-list li {
  display: flex;
  align-items: center;  /* 垂直居中 */
  gap: 10px;            /* 元素间距 */
}

.delete-btn {
  margin-left: auto;  /* 推到最右边 */
}
```

`margin-left: auto` 是 Flexbox 中将元素推到一端的经典技巧。

## 初始效果

页面加载后：
- 顶部有标题
- 中间是输入框和添加按钮
- 列表区域暂时为空
- 底部有筛选按钮和统计文字

所有交互都靠 JS 驱动，HTML 只提供骨架。

## 与 Python 的对比

Python 生成 HTML 通常是后端渲染模板：

```python
# Flask/Jinja2 模板
from flask import Flask, render_template

app = Flask(__name__)

@app.route('/')
def index():
    return render_template('index.html', todos=todos)
```

```html
<!-- Jinja2 模板：服务端渲染 -->
<ul>
  {% for todo in todos %}
    <li>{{ todo.text }}</li>
  {% endfor %}
</ul>
```

JS 的方式是**客户端渲染**——HTML 初始为空，JS 在浏览器中获取数据后动态生成 DOM。两者各有适用场景。

## 小结

- HTML 骨架只提供结构：输入区、列表容器（空）、筛选区、统计区。
- CSS 用 Flexbox 做布局：`display: flex` + `gap` + `margin-left: auto`。
- 列表初始为空，由 JS 动态渲染——这是前端渲染的核心模式。
- `data-filter` 属性方便 JS 读取筛选条件。
- `script` 放 body 末尾确保 DOM 就绪。
