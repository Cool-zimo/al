# 数组与对象：对比 Python 的 list 和 dict

> 这一节解决"JS 的数组和对象怎么用，和 Python 的 list/dict 有什么差异"的问题。你已经熟悉 Python 的列表和字典，JS 的版本有相似之处，但也有重要区别。

## JS 数组 vs Python list

```javascript
// Python: numbers = [1, 2, 3]
const numbers = [1, 2, 3];

numbers.length;      // 3（属性，不是方法）
numbers[0];          // 1（索引访问）
numbers[5] = 10;     // 可以越界赋值！数组自动扩展
numbers.length;      // 6（中间有 3 个 empty 位置）
```

关键差异：**JS 数组可以越界赋值**，不会报错。越界的位置值为 `undefined`，但 `length` 会更新。

```python
# Python: 越界赋值直接 IndexError
numbers[5] = 10  # IndexError: list assignment index out of range
```

## 解构赋值（Destructuring）

这是 JS 里非常常用的语法糖，Python 3.10+ 也有类似功能：

```javascript
// 数组解构
const numbers = [1, 2, 3];
const [first, second, third] = numbers;
console.log(first);   // 1

// 跳过元素
const [a, , c] = [1, 2, 3];
console.log(c);       // 3

// 默认值
const [x, y = 10] = [5];
console.log(y);       // 10

// 剩余元素
const [head, ...tail] = [1, 2, 3, 4];
console.log(tail);    // [2, 3, 4]
```

## JS 对象 vs Python dict

```javascript
// Python: person = {"name": "张三", "age": 25}
const person = {
  name: "张三",
  age: 25
};

// 点号访问
person.name;       // "张三"

// 方括号访问（键是动态的）
person["name"];    // "张三"
const key = "age";
person[key];       // 25
```

**核心差异：JS 对象可以用点号访问属性，像访问命名字段一样。**

## 属性不存在返回 undefined，不是 KeyError

这是 JS 和 Python 最大的差异之一：

```javascript
const person = { name: "张三" };

// JS：不存在的属性返回 undefined
person.age;        // undefined（不报错！）

// Python：不存在的键抛异常
# person["age"]   # KeyError: 'age'
```

翻车现场一：忘记检查属性是否存在。

```javascript
function getCity(user) {
  return user.address.city;  // user.address 可能是 undefined！
}

getCity({ name: "张三" });  // TypeError: Cannot read properties of undefined
```

后果：链式访问时中间任何一环是 `undefined`，整个表达式就报错。解决方法：

```javascript
// 方法 1：逐层检查
function getCity(user) {
  if (user && user.address && user.address.city) {
    return user.address.city;
  }
  return "未知";
}

// 方法 2：可选链操作符 ?.（现代写法）
function getCity(user) {
  return user?.address?.city ?? "未知";
}
```

## 对象的解构赋值

```javascript
const person = { name: "张三", age: 25, city: "北京" };

// 基本解构
const { name, age } = person;
console.log(name);  // "张三"

// 重命名
const { name: userName } = person;
console.log(userName);  // "张三"

// 默认值
const { country = "中国" } = person;
console.log(country);   // "中国"
```

## 对象的方法：增删改查

```javascript
const person = {};

// 增
person.name = "张三";
person["age"] = 25;

// 删
delete person.age;

// 改
person.name = "李四";

// 查
"name" in person;      // true（in 操作符）
person.hasOwnProperty("name");  // true

// 遍历
Object.keys(person);    // ["name"]
Object.values(person);  // ["张三"]
Object.entries(person); // [["name", "张三"]]
```

翻车现场二：用 `for...in` 遍历数组。

```javascript
const arr = [10, 20, 30];
for (const i in arr) {
  console.log(i);  // "0", "1", "2"（字符串！）
}
```

后果：`for...in` 遍历的是**可枚举属性名**（包括原型链上的），得到的是字符串 `"0"`、`"1"`、`"2"`，不是数字索引。遍历数组应该用 `for...of` 或 `forEach`。

## 与 Python 的对比

| 操作 | Python | JavaScript |
|---|---|---|
| 创建 | `[1,2,3]` / `{"a":1}` | `[1,2,3]` / `{"a":1}` |
| 取值 | `d["a"]` | `obj.a` 或 `obj["a"]` |
| 不存在 | `KeyError` | `undefined` |
| 解构 | `a, b = [1, 2]` | `const [a, b] = [1, 2]` |
| 遍历键 | `for k in d:` | `for (const k in obj)` 或 `Object.keys()` |
| 删除 | `del d["a"]` | `delete obj.a` |

## 小结

- JS 数组可以越界赋值，`length` 自动扩展。
- 解构赋值让多返回值、参数提取变得简洁。
- JS 对象用点号访问属性，比 Python dict 的方括号更方便。
- 对象属性不存在返回 `undefined`，不报错——需要防御性编程。
- 可选链 `?.` 和空值合并 `??` 是处理嵌套对象的现代方案。
- `for...in` 遍历的是属性名（含原型链），不是数组的正确遍历方式。
