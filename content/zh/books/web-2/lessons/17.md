# 事件对象：event.target vs currentTarget

> 这一节解决"事件回调里的 event 参数是什么，target 和 currentTarget 有什么区别"的问题。这是事件处理中容易混淆的概念。

## 事件对象 event

每次事件触发，浏览器都会传给回调函数一个**事件对象**：

```javascript
element.addEventListener('click', function(event) {
  // event 就是事件对象
});
```

常用属性：

| 属性 | 含义 |
|---|---|
| `event.type` | 事件类型（'click'、'input'...） |
| `event.target` | **真正触发事件的元素**（冒泡的起点） |
| `event.currentTarget` | **绑定监听器的元素**（this 指向的元素） |
| `event.clientX` / `clientY` | 鼠标相对于视口的坐标 |
| `event.key` | 按下的键（keydown 事件） |
| `event.preventDefault()` | 阻止默认行为 |
| `event.stopPropagation()` | 停止冒泡 |

## target vs currentTarget

```html
<div id="parent" style="padding: 20px; background: lightblue;">
  <button id="child">点击我</button>
</div>
```

```javascript
const parent = document.querySelector('#parent');
const child = document.querySelector('#child');

parent.addEventListener('click', function(event) {
  console.log('target:', event.target.id);          // "child"（实际被点击的）
  console.log('currentTarget:', event.currentTarget.id); // "parent"（绑定监听器的）
});
```

点击按钮时：
- `event.target` = 按钮（用户实际点击的元素）
- `event.currentTarget` = div（监听器绑在 div 上）

**记忆：`target` 是"谁被点了"，`currentTarget` 是"谁绑的监听"。**

翻车现场一：在父元素监听器中用 this 或 currentTarget 访问子元素属性。

```javascript
const list = document.querySelector('#todo-list');

list.addEventListener('click', function(event) {
  // 想获取被点击 li 的 data-id
  console.log(event.currentTarget.dataset.id);  // undefined！currentTarget 是 ul，没有 data-id
  console.log(event.target.dataset.id);         // "123"（target 是 li，有 data-id）
});
```

后果：`currentTarget` 是绑定监听器的元素（ul），不是被点击的元素（li）。要获取被点击元素的属性，用 `target`。

## 什么时候 target 和 currentTarget 相同？

当事件直接在绑定监听器的元素上触发时，两者相同：

```javascript
button.addEventListener('click', function(event) {
  // 点击按钮时：
  event.target === event.currentTarget;  // true
  // 因为按钮既是触发者也是监听者
});
```

当事件**冒泡**到父元素时，两者不同：

```javascript
// 点击 button，事件冒泡到 div
div.addEventListener('click', function(event) {
  event.target;         // button（冒泡起点）
  event.currentTarget;  // div（当前处理者）
});
```

## 事件委托中的实际应用

事件委托是下一课的主题，这里先看一个简单例子：

```html
<ul id="menu">
  <li data-page="home">首页</li>
  <li data-page="about">关于</li>
  <li data-page="contact">联系</li>
</ul>
```

```javascript
document.querySelector('#menu').addEventListener('click', function(event) {
  // event.target 是被点击的 li
  const page = event.target.dataset.page;
  if (page) {
    navigateTo(page);
  }
});
```

这里必须用 `event.target`，因为监听器绑在 `ul` 上，但用户点击的是 `li`。

翻车现场二：点击到子元素时 target 不是预期的。

```html
<button id="myBtn">
  <span class="icon">🖱️</span>
  <span class="text">点我</span>
</button>
```

```javascript
document.querySelector('#myBtn').addEventListener('click', function(event) {
  console.log(event.target.id);  // 可能是 ""（点击到 span 时，target 是 span 不是 button！）
});
```

后果：按钮里有子元素时，`event.target` 可能是内部的 `span` 而不是 `button`。解决：用 `event.currentTarget` 获取绑定监听器的元素（永远是 button），或用 `closest()` 查找最近的匹配祖先。

```javascript
// 方案 1：用 currentTarget
button.addEventListener('click', function(event) {
  console.log(event.currentTarget.id);  // "myBtn" ✅
});

// 方案 2：用 closest 从 target 往上找
container.addEventListener('click', function(event) {
  const button = event.target.closest('.btn');
  if (button) {
    // 处理点击
  }
});
```

## 事件对象的其他常用方法

```javascript
// preventDefault：阻止默认行为
form.addEventListener('submit', function(event) {
  event.preventDefault();  // 阻止表单提交刷新页面
  // 自己处理提交逻辑
});

// stopPropagation：停止冒泡
child.addEventListener('click', function(event) {
  event.stopPropagation();  // 点击 child 不会触发 parent 的监听器
});
```

## 与 Python 的对比

Python 的事件处理（如 Tkinter）概念类似但 API 不同：

```python
# Tkinter：回调没有统一的事件对象
import tkinter as tk

def on_click(event):
    print(event.x, event.y)  # 有 event 对象，但结构不同

button.bind("<Button-1>", on_click)
```

JS 的 `event` 对象更标准化，所有事件类型共享同一套核心 API（`preventDefault`、`stopPropagation`）。

## 小结

- `event.target` = 实际触发事件的元素（冒泡起点）。
- `event.currentTarget` = 绑定监听器的元素（处理者）。
- 点击子元素时，父元素监听器的 `target` 是子元素，`currentTarget` 是父元素。
- 有子元素的按钮中，`target` 可能是内部子元素，用 `currentTarget` 或 `closest()` 更可靠。
- `preventDefault()` 阻止默认行为，`stopPropagation()` 停止冒泡。
