# 创建与删除元素：createElement / appendChild / remove

> 这一节解决"怎么动态创建和删除 DOM 元素"的问题。之前都是改已有的元素，现在要学会从零创建元素并插入页面。

## 创建元素

```javascript
// 创建元素
const div = document.createElement('div');
const p = document.createElement('p');
const button = document.createElement('button');

// 设置内容
div.textContent = "我是一个新创建的 div";
p.textContent = "这是一段文字";

// 设置属性
div.className = "card";
button.id = "submit";
button.textContent = "提交";
```

`document.createElement(tagName)` 创建一个**游离的 DOM 元素**——它存在于内存中，还没被插入到页面的 DOM 树里，所以页面上看不到。

## 插入元素

### appendChild：追加到末尾

```javascript
const container = document.querySelector('#container');
const newItem = document.createElement('li');

newItem.textContent = "新项目";
container.appendChild(newItem);  // 插入到 container 的最后
```

### insertBefore：插入到指定位置

```javascript
const container = document.querySelector('#container');
const firstItem = container.firstElementChild;
const newItem = document.createElement('li');

newItem.textContent = "第一个";
container.insertBefore(newItem, firstItem);  // 插入到 firstItem 之前
```

### 现代方法：insertAdjacentHTML / append / prepend

```javascript
const container = document.querySelector('#container');

// append：可以追加多个元素或字符串
container.append(item1, item2, "纯文本也可以");

// prepend：插入到开头
container.prepend(newItem);

// insertAdjacentHTML：在指定位置插入 HTML 字符串
container.insertAdjacentHTML('beforeend', '<li>新项</li>');
// 四个位置：beforebegin、afterbegin、beforeend、afterend
```

## 完整的创建流程

```javascript
// 目标：创建一个 <li class="todo-item">买牛奶</li> 并插入到 <ul id="todo-list"> 中

// 1. 创建元素
const li = document.createElement('li');

// 2. 设置属性和内容
li.className = "todo-item";
li.textContent = "买牛奶";

// 3. 找到父容器
const list = document.querySelector('#todo-list');

// 4. 插入
list.appendChild(li);
```

## 删除元素

### remove：直接删除自己

```javascript
const item = document.querySelector('.todo-item');
item.remove();  // 从 DOM 中删除自己
```

### removeChild：父元素删除子元素

```javascript
const list = document.querySelector('#todo-list');
const firstItem = list.firstElementChild;
list.removeChild(firstItem);  // 父元素调用 removeChild 删除子元素
```

## 批量创建：用 DocumentFragment

```javascript
// 低效：每次 appendChild 都触发一次重排
const list = document.querySelector('#todo-list');
for (let i = 0; i < 1000; i++) {
  const li = document.createElement('li');
  li.textContent = `项目 ${i}`;
  list.appendChild(li);  // 1000 次重排！
}

// 高效：用 DocumentFragment 一次性插入
const fragment = document.createDocumentFragment();
for (let i = 0; i < 1000; i++) {
  const li = document.createElement('li');
  li.textContent = `项目 ${i}`;
  fragment.appendChild(li);  // 在内存中组装
}
list.appendChild(fragment);  // 一次重排！
```

翻车现场一：先设置 textContent 再设置 innerHTML。

```javascript
const div = document.createElement('div');
div.textContent = "安全文字";
div.innerHTML = "<strong>危险内容</strong>";  // textContent 被覆盖！
```

后果：先设置 `textContent` 再设置 `innerHTML`，后者会覆盖前者。这本身不算 bug，但说明两者的优先级——**后写的覆盖先写的**。如果内容来自用户输入，先用 `textContent` 再用 `innerHTML` 等于白做防御。

翻车现场二：appendChild 移动已有元素。

```javascript
const item = document.querySelector('#list1 li:first-child');
const list2 = document.querySelector('#list2');

list2.appendChild(item);
// item 从 list1 中消失了！它被"移动"到了 list2
```

后果：`appendChild` 如果传入的已经是 DOM 树中的元素，它会**从原来的位置移除，然后插入到新位置**——是移动不是复制。如果需要复制，用 `cloneNode(true)`。

## 清空元素内容

```javascript
const container = document.querySelector('#container');

// 方式 1：textContent = ""（最快）
container.textContent = "";

// 方式 2：innerHTML = ""（也可以，但会解析）
container.innerHTML = "";

// 方式 3：循环 removeChild（兼容性好但慢）
while (container.firstChild) {
  container.removeChild(container.firstChild);
}
```

翻车现场三：遍历 children 删除元素时的跳过问题。

```javascript
const list = document.querySelector('#list');
for (let i = 0; i < list.children.length; i++) {
  list.removeChild(list.children[i]);
  // 每次删除后，后面的元素前移，i 递增导致跳过
}
// 结果：只删了一半的元素
```

后果：删除了第 0 个后，原来的第 1 个变成第 0 个，但 `i` 已经变成 1 了，指向了原来的第 2 个——第 1 个被跳过。解决：倒序遍历，或用 `textContent = ""` 一步清空。

## 与 Python 的对比

Python 没有 DOM，但 `createElement` + `appendChild` 的模式类似手动构建数据结构：

```python
# 类比：构建一个嵌套结构
from dataclasses import dataclass
from typing import List

@dataclass
class Node:
    tag: str
    children: List['Node'] = None

# 创建
div = Node(tag="div")
div.children = []
p = Node(tag="p")
div.children.append(p)  # 类似 appendChild
```

JS 的 `createElement` + `appendChild` 就是这个模式，只不过操作的是浏览器实际渲染的 DOM 树。

## 小结

- `createElement(tag)` 创建游离的 DOM 元素（不在页面上）。
- `appendChild` 插入元素到末尾，`insertBefore` 插入到指定位置前。
- `element.remove()` 删除自己，`parent.removeChild(child)` 父删子。
- `appendChild` 对已存在元素是**移动**不是复制，要复制用 `cloneNode(true)`。
- 大量创建用 `DocumentFragment` 减少重排。
- 清空元素用 `textContent = ""` 最简洁高效。
