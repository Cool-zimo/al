# 改属性与样式：getAttribute/setAttribute、classList、style

> 这一节解决"怎么修改元素的属性和 CSS 样式"的问题。你改过 Python 对象的属性，DOM 元素的属性和样式操作类似，但有一些专属 API。

## 属性的两种操作方式

### 方式一：直接访问（推荐）

```javascript
const link = document.querySelector('a');

// 读
link.href;          // "https://example.com"
link.id;            // "myLink"
link.className;     // "external"

// 写
link.href = "https://google.com";
link.target = "_blank";
```

### 方式二：getAttribute / setAttribute

```javascript
const link = document.querySelector('a');

// 读
link.getAttribute('href');     // "https://example.com"
link.getAttribute('data-id');  // "123"

// 写
link.setAttribute('href', 'https://google.com');
link.setAttribute('data-user', '张三');
```

翻车现场一：两种方式的差异。

```javascript
const input = document.querySelector('input');

// 直接访问
input.value = "hello";       // 改的是 DOM 对象的 value 属性
input.getAttribute('value'); // "world"（HTML 属性没变！）

// setAttribute 改的是 HTML 属性
input.setAttribute('value', 'hello');
input.value;                 // "hello"（同步了）
```

后果：对于 `value`、`checked`、`disabled` 等**状态属性**，DOM 属性和 HTML 属性可能不同步。直接赋值 `input.value = "x"` 改变的是 DOM 状态，但 `getAttribute('value')` 读的是 HTML 属性（初始值）。

**经验法则**：日常操作用**直接访问**（`input.value`、`img.src`），只有在操作自定义属性或 `data-*` 属性时才用 `getAttribute`/`setAttribute`。

## classList：操作 CSS 类

```javascript
const btn = document.querySelector('.btn');

btn.classList.add('active');        // 添加类
btn.classList.remove('disabled');   // 移除类
btn.classList.toggle('dark-mode');  // 切换类（有则删，无则加）
btn.classList.toggle('dark-mode', true);  // 强制添加
btn.classList.contains('active');   // 检查是否包含某个类
btn.classList.replace('old', 'new'); // 替换类
```

```javascript
// 多个操作
btn.classList.add('active', 'primary');
btn.classList.remove('old', 'deprecated');
```

对比 Python（如果用一个列表模拟）：

```python
classes = ["btn", "primary"]
classes.append("active")       # 类似 classList.add
classes.remove("primary")      # 类似 classList.remove
```

## className：整体替换

```javascript
const div = document.querySelector('.box');
div.className = "new-class";    // 替换所有类（危险！会覆盖已有类）
div.className += " extra";     // 追加类（容易出错，末尾空格问题）
```

**推荐用 `classList` 而不是 `className`**，`className` 会整体覆盖。

翻车现场二：用 className += 追加类时忘了空格。

```javascript
const div = document.querySelector('.box');
div.className += "active";   // 如果原来 className 是 "box"，结果是 "boxactive"（少了空格！）
```

后果：类名粘连在一起，CSS 选择器 `.boxactive` 匹配不到任何元素。用 `classList.add()` 永远不会有这个问题。

## style：操作内联样式

```javascript
const div = document.querySelector('.box');

// 设置单个样式
div.style.color = "red";
div.style.fontSize = "20px";       // CSS 属性用驼峰命名
div.style.backgroundColor = "#fff"; // background-color → backgroundColor

// 批量设置
div.style.cssText = "color: red; font-size: 20px; padding: 10px;";

// 读取
div.style.color;  // "red"（只能读内联样式！）

// 获取计算后的样式（任何来源）
getComputedStyle(div).fontSize;  // "20px"
```

**重要**：`element.style.xxx` **只能读写内联样式**（写在 `style="..."` 里的）。要读 CSS 文件或 `<style>` 中定义的样式，用 `getComputedStyle()`。

## data-\* 属性

HTML5 引入了 `data-*` 自定义属性，JS 可以通过 `dataset` 访问：

```html
<div id="user" data-id="123" data-user-name="张三" data-role="admin"></div>
```

```javascript
const user = document.querySelector('#user');

// 读
user.dataset.id;         // "123"
user.dataset.userName;   // "张三"（data-user-name → userName，连字符转驼峰）
user.dataset.role;       // "admin"

// 写
user.dataset.id = "456";
user.dataset.newProp = "value";  // 自动创建 data-new-prop
```

翻车现场三：dataset 的命名转换。

```javascript
// HTML: <div data-user-id="123"></div>
element.dataset.user-id;   // ❌ undefined！不应该有连字符
element.dataset.userId;    // ✅ "123"
```

后果：`data-user-id` 在 JS 中要用 `dataset.userId` 访问（连字符转驼峰，去掉 `data-` 前缀）。`data-` 前缀在 HTML 中写，JS 中去掉。

## 与 Python 的对比

Python 没有 DOM，但可以类比操作字典：

```python
# 类比：属性操作像字典读写
element = {"tag": "a", "attrs": {"href": "https://example.com"}}
element["attrs"]["href"] = "https://google.com"  # 类似 setAttribute

# classList 类似集合操作
classes = {"btn", "primary"}
classes.add("active")      # 类似 classList.add
classes.remove("primary")  # 类似 classList.remove
```

## 小结

- 属性操作有两种方式：直接访问（`img.src`）和 `getAttribute`/`setAttribute`。
- 状态属性（`value`、`checked`）的 DOM 属性和 HTML 属性可能不同步。
- `classList` 是操作 CSS 类的最佳方式：add/remove/toggle/contains。
- `style.xxx` 用驼峰命名（`fontSize` 不是 `font-size`），只能读内联样式。
- `data-*` 属性通过 `dataset` 访问，连字符转驼峰。
- 优先用 `classList` 而非 `className`，避免覆盖和空格问题。
