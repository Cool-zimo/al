# localStorage / sessionStorage：浏览器本地存储

> 这一节解决"怎么在浏览器里保存数据，让页面刷新后数据还在"的问题。核心要点：**只能存字符串**。

## localStorage vs sessionStorage

| 特性 | localStorage | sessionStorage |
|---|---|---|
| 生命周期 | 永久（手动删除或清缓存） | 标签页关闭后自动清除 |
| 作用域 | 同源的所有标签页共享 | 仅当前标签页 |
| 容量 | 约 5MB | 约 5MB |

```javascript
// 基本 API（两者完全一致）
localStorage.setItem('key', 'value');   // 存
const val = localStorage.getItem('key'); // 取
localStorage.removeItem('key');          // 删单个
localStorage.clear();                    // 清空所有
```

## 只能存字符串——最大的坑

`localStorage` **只能存字符串**。你存数字、布尔值、对象进去，它们会被自动转成字符串。

```javascript
// 存数字
localStorage.setItem('age', 25);
console.log(localStorage.getItem('age'));  // "25"（字符串！）
console.log(typeof localStorage.getItem('age'));  // "string"

// 取出来要手动转
const age = Number(localStorage.getItem('age'));  // 25（数字）
```

## 存对象：JSON.stringify / JSON.parse

```javascript
const user = { name: '张三', age: 28, city: '北京' };

// ❌ 错误写法
localStorage.setItem('user', user);
console.log(localStorage.getItem('user'));  // "[object Object]" —— 完蛋了

// ✅ 正确写法：先转成 JSON 字符串
localStorage.setItem('user', JSON.stringify(user));
console.log(localStorage.getItem('user'));  // '{"name":"张三","age":28,"city":"北京"}'

// 取出来再解析
const savedUser = JSON.parse(localStorage.getItem('user'));
console.log(savedUser.name);  // "张三"
```

翻车现场一：存对象忘了转，得到 "[object Object]"。

```javascript
const settings = { theme: 'dark', fontSize: 16 };

// ❌ 直接存对象
localStorage.setItem('settings', settings);
// 等价于：localStorage.setItem('settings', String(settings))
// 即：localStorage.setItem('settings', '[object Object]')

// 后面取出来
const data = localStorage.getItem('settings');
console.log(data);  // "[object Object]"
JSON.parse(data);   // ❌ 报错：Unexpected token o in JSON at position 1
```

后果：对象被隐式转成 `"[object Object]"`，数据永久丢失且无法恢复。后续 `JSON.parse` 直接报错。

**记住口诀：存之前 `JSON.stringify`，取之后 `JSON.parse`。**

## 封装存储工具函数

```javascript
// 存对象
function saveData(key, data) {
  localStorage.setItem(key, JSON.stringify(data));
}

// 取对象（带默认值）
function loadData(key, defaultValue = null) {
  const raw = localStorage.getItem(key);
  if (raw === null) return defaultValue;  // key 不存在
  try {
    return JSON.parse(raw);
  } catch (err) {
    console.error('解析失败：', err);
    return defaultValue;  // 数据损坏时返回默认值
  }
}

// 使用示例
saveData('todos', [{ id: 1, text: '买牛奶', done: false }]);
const todos = loadData('todos', []);  // 不存在时返回 []
console.log(todos);  // [{ id: 1, text: '买牛奶', done: false }]
```

翻车现场二：取数据时没有处理 key 不存在的情况。

```javascript
// ❌ 不检查 null
const todos = JSON.parse(localStorage.getItem('todos'));
// 第一次访问时 'todos' 不存在
// localStorage.getItem('todos') 返回 null
// JSON.parse(null) 返回 null —— 这竟然不报错！但后续代码可能崩
todos.forEach(todo => console.log(todo));  // ❌ TypeError: Cannot read properties of null

// ✅ 正确做法
const todos = loadData('todos', []);  // 默认空数组
todos.forEach(todo => console.log(todo));  // 安全
```

后果：`localStorage.getItem(key)` 在 key 不存在时返回 `null`，直接 `JSON.parse(null)` 虽然不报错但返回 `null`，后续调用数组方法（forEach、map 等）会报错。

## 容量限制与异常处理

```javascript
// 尝试存储超过容量限制的数据
try {
  const hugeData = 'x'.repeat(10 * 1024 * 1024);  // 10MB 字符串
  localStorage.setItem('huge', hugeData);
} catch (err) {
  if (err.name === 'QuotaExceededError') {
    console.error('存储空间已满！');
    // 清理旧数据或提示用户
  }
}
```

## 隐私模式（无痕浏览）

翻车现场三：隐私模式下 localStorage 可能不可用。

```javascript
// ❌ 直接用，隐私模式下可能抛异常
localStorage.setItem('key', 'value');  // 某些浏览器隐私模式下抛 QuotaExceededError

// ✅ 先检测是否可用
function isStorageAvailable() {
  try {
    const testKey = '__test__';
    localStorage.setItem(testKey, testKey);
    localStorage.removeItem(testKey);
    return true;
  } catch (err) {
    return false;
  }
}

if (isStorageAvailable()) {
  localStorage.setItem('key', 'value');
} else {
  console.warn('当前浏览器不支持 localStorage，使用内存存储');
  // 降级方案：用变量存
  window.__memoryStore = {};
}
```

后果：Safari 的隐私模式（无痕浏览）中，`localStorage` 在写入时会抛 `QuotaExceededError`（容量为 0）。如果不做异常捕获，整个 JS 执行会中断。

## 实际应用场景

```javascript
// 1. 保存用户偏好
saveData('theme', { mode: 'dark', fontSize: 16 });

// 2. 保存表单草稿（防止刷新丢失）
const form = document.querySelector('#article-form');
form.addEventListener('input', () => {
  saveData('draft', { title: form.title.value, content: form.content.value });
});

// 页面加载时恢复草稿
const draft = loadData('draft', null);
if (draft) {
  form.title.value = draft.title;
  form.content.value = draft.content;
}

// 3. 保存购物车
saveData('cart', [{ id: 1, name: '商品A', price: 99, qty: 2 }]);
```

## sessionStorage 的典型用法

```javascript
// 保存当前会话的临时数据
sessionStorage.setItem('currentPage', '2');
sessionStorage.setItem('searchKeyword', 'JavaScript');

// 关闭标签页后自动清除
// 适合存：分页状态、临时表单数据、单次会话的 token
```

## 与 Python 的对比

Python 中持久化数据通常用文件或数据库：

```python
# Python：用 json 模块存文件
import json

with open('data.json', 'w') as f:
    json.dump(data, f)

with open('data.json', 'r') as f:
    data = json.load(f)
```

JS 的 `localStorage` 本质也是键值对存储，但自动绑定到当前域名，且有容量限制（约 5MB）。

## 小结

- `localStorage` 永久存储，`sessionStorage` 标签页关闭后清除。两者 API 一致。
- **只能存字符串**——存对象必须用 `JSON.stringify`，取对象必须用 `JSON.parse`。
- 忘记 `JSON.stringify` 会得到 `"[object Object]"`，数据丢失且无法恢复。
- key 不存在时 `getItem` 返回 `null`，要做好默认值处理。
- 隐私模式下 `localStorage` 可能不可用，需要 try-catch 检测。
- 容量约 5MB，超限会抛 `QuotaExceededError`。
