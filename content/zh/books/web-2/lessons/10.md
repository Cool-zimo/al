# 字符串方法：模板字符串、split/join/includes

> 这一节解决"JS 字符串有哪些常用操作"的问题。你熟悉 Python 的字符串方法，JS 的版本有相似之处，但也有自己的特色（比如模板字符串）。

## 模板字符串（Template Literals）

JS 用反引号 `` ` `` 定义模板字符串，支持**多行**和**插值**：

```javascript
const name = "张三";
const age = 25;

// 传统拼接
const greeting = "你好，我是" + name + "，今年" + age + "岁。";

// 模板字符串（推荐）
const greeting = `你好，我是${name}，今年${age}岁。`;
```

Python 对比：

```python
# Python f-string
greeting = f"你好，我是{name}，今年{age}岁。"
```

**核心差异**：JS 用 `${}` 插值，Python 用 `{}`；JS 用反引号，Python 用 `f"..."`。

## 多行字符串

```javascript
// 传统方式（用 \n 转义）
const html = "<div>\n  <p>Hello</p>\n</div>";

// 模板字符串（直接换行）
const html = `
  <div>
    <p>Hello</p>
  </div>
`;
```

翻车现场一：模板字符串里的多余缩进。

```javascript
function render() {
  return `
    <div>
      <p>内容</p>
    </div>
  `;
}
console.log(render());
// 输出包含前面的缩进空格和换行！
```

后果：模板字符串里的**所有空白字符**（包括换行和缩进）都会被保留。如果要把生成的 HTML 插入到 DOM 中，这些多余空格可能影响布局。解决：去掉首行换行或用 `.trim()`。

## 常用字符串方法

```javascript
const str = "Hello, World!";

str.length;            // 13
str.toUpperCase();     // "HELLO, WORLD!"
str.toLowerCase();     // "hello, world!"
str.includes("World");  // true
str.startsWith("Hello"); // true
str.endsWith("!");      // true
str.indexOf("o");       // 4（第一次出现的位置）
str.lastIndexOf("o");   // 8
str.slice(0, 5);       // "Hello"
str.split(", ");        // ["Hello", "World!"]
str.replace("World", "JS"); // "Hello, JS!"
str.trim();            // 去除首尾空格
```

## split 和 join

```javascript
// split：字符串 → 数组
const tags = "前端,后端,全栈";
tags.split(",");    // ["前端", "后端", "全栈"]

// join：数组 → 字符串
const words = ["Hello", "World"];
words.join(" ");    // "Hello World"
words.join("-");    // "Hello-World"
```

翻车现场二：split 的分隔符参数。

```javascript
const csv = "apple,banana,cherry";
csv.split("");      // ["a", "p", "p", "l", "e", ",", "b", ...]（每个字符！）
csv.split();        // ["apple,banana,cherry"]（不分割，返回原字符串作为单元素数组！）
csv.split(",");     // ["apple", "banana", "cherry"] ✅
```

后果：`split("")` 会把字符串拆成**单个字符**，`split()` 不传参数则**不分割**。这两个都和直觉不同。

## includes：检查是否包含

```javascript
const text = "JavaScript is awesome";

text.includes("Java");    // true
text.includes("java");    // false（区分大小写！）
text.includes("Python");  // false
```

翻车现场三：大小写敏感。

```javascript
const email = "ZhangSan@Example.com";
if (email.includes("@gmail.com")) {  // false！大小写不匹配
  console.log("是 Gmail");
}
```

后果：`includes` 是区分大小写的。需要不区分大小写时：

```javascript
email.toLowerCase().includes("@gmail.com");  // true
```

## 字符串是不可变的

和 Python 一样，JS 字符串不可修改：

```javascript
const str = "hello";
str[0] = "H";        // 静默失败！str 仍然是 "hello"
console.log(str);    // "hello"

// 要"修改"，只能创建新字符串
const newStr = "H" + str.slice(1);  // "Hello"
```

## 与 Python 的对比

| 操作 | Python | JavaScript |
|---|---|---|
| 模板/格式化 | `f"{name}"` | `` `${name}` `` |
| 多行字符串 | `"""..."""` | `` `...` `` |
| 包含 | `"hello" in text` | `text.includes("hello")` |
| 分割 | `text.split(", ")` | `text.split(", ")` |
| 拼接数组 | `"".join(arr)` | `arr.join("")` |
| 去除空白 | `text.strip()` | `text.trim()` |
| 替换 | `text.replace("a", "b")` | `text.replace("a", "b")` |
| 长度 | `len(text)` | `text.length` |

## 小结

- 模板字符串用反引号 `` ` `` 和 `${}` 插值，支持多行。
- `split(delimiter)` 把字符串拆成数组，`join(separator)` 把数组拼成字符串。
- `includes` 检查子串，区分大小写。
- `split("")` 拆成单字符，`split()` 不传参数不分割——都是常见坑。
- 字符串不可变，所有"修改"操作都返回新字符串。
