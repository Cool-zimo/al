# DataFrame：一张表

> 多个 Series 拼起来就是 DataFrame。这一课讲怎么造一张表，以及最常用的几个创建方式。

## 从字典创建（最常用）

```python
import pandas as pd

df = pd.DataFrame({
    '姓名': ['张三', '李四', '王五'],
    '年龄': [18, 19, 20],
    '成绩': [89.5, 92.0, 78.0]
})
print(df)
```

```
   姓名  年龄    成绩
0  张三  18  89.5
1  李四  19  92.0
2  王五  20  78.0
```

**字典的键变成列名，值变成那一列的数据**。左边多出来的 `0 1 2` 是**行索引**（默认从 0 开始）。

## 从列表的列表创建

```python
data = [['张三', 18, 89.5],
        ['李四', 19, 92.0],
        ['王五', 20, 78.0]]

df = pd.DataFrame(data, columns=['姓名', '年龄', '成绩'])
print(df)
```

**这种方式必须自己指定 `columns`**，否则列名会变成 0、1、2。

> ⚠️ 注意：如果某一行混入了不同类型（比如年龄写成 `'18'` 字符串），整列会变成 object 类型。从列表创建时**同一列要保持类型一致**。

## 从 NumPy 数组创建

```python
import numpy as np

arr = np.arange(12).reshape(4, 3)
df = pd.DataFrame(arr, columns=['A', 'B', 'C'])
print(df)
```

配合《数据分析 1》的知识很自然：先用 NumPy 算好矩阵，再转成 DataFrame 加上列名。

## 指定行索引

```python
df = pd.DataFrame({
    '销量': [120, 500, 30],
    '单价': [199, 89, 1299]
}, index=['键盘', '鼠标', '显示器'])

print(df)
print(df.index)        # Index(['键盘', '鼠标', '显示器'])
```

**用商品名当行索引**，之后 `df.loc['鼠标']` 就能直接取出鼠标那一行。

## 三个核心属性

```python
print(df.shape)      # (3, 2)   行数和列数
print(df.columns)    # Index(['销量', '单价'])
print(df.index)      # Index(['键盘', '鼠标', '显示器'])
```

**`shape`、`columns`、`index` 是查看表格结构最常用的三个**。拿到任何一张陌生的表，先打印这三个。

## 快速看数据

```python
print(df.head(2))        # 前 2 行（默认 5 行）
print(df.tail(2))        # 后 2 行
print(df.info())         # 列名、非空数量、类型
print(df.describe())     # 数值列的统计摘要
```

**`info()` 和 `describe()` 是拿到新数据后的标准起手式**：

```python
df = pd.DataFrame({
    '姓名': ['张三', '李四', '王五'],
    '成绩': [89.5, 92.0, 78.0]
})
print(df.describe())
```

```
         成绩
count   3.000000
mean   86.500000
std     7.466592
min    78.000000
25%    83.750000
50%    89.500000
75%    90.750000
max    92.000000
```

**`describe()` 只对数值列生效**——文字列（object）会被自动跳过。这一步能立刻看出：有多少条数据、均值多少、有没有离谱的最大最小值。

## 取一列 = 一个 Series

```python
print(df['成绩'])          # Series
print(type(df['成绩']))    # <class 'pandas.core.series.Series'>
```

**取多列要用双方括号**（里面是列表）：

```python
print(df[['姓名', '成绩']])   # DataFrame（两列）
print(type(df[['姓名', '成绩']]))
```

> ⚠️ **单方括号取一列 → Series；双方括号取多列 → DataFrame**。这个区别在后面做运算时很重要：DataFrame 有 `.columns`，Series 没有。

## 新增一列

三种等价写法：

```python
df['等级'] = ['优', '优', '良']              # 直接给列表
df['及格'] = df['成绩'] >= 60                 # 由其他列算出
df['排名'] = df['成绩'].rank(ascending=False) # 用方法算

print(df)
```

**`df['新列名'] = ...` 就是新增列**。如果这个列名已存在，就是覆盖。

## 删除

```python
df2 = df.drop(columns=['及格'])      # 删列，返回新表（原表不变）
df3 = df.drop(index=[0])             # 删行

# 想原地改就加 inplace=True
df.drop(columns=['及格'], inplace=True)
```

> ⚠️ **pandas 的大多数操作默认返回新表，不改原表**。要么赋值回去（`df = df.drop(...)`），要么加 `inplace=True`。这是新手最常困惑的点之一。

## DataFrame 是"Series 的字典"

理解了这个比喻，很多操作就顺理成章：

```python
# 遍历列名
for col in df.columns:
    print(col, '→', df[col].dtype)

# 判断列是否存在
print('成绩' in df.columns)     # True
```
