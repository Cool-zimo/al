# 看一眼数据

> 拿到一张陌生的表，前 5 分钟该做什么？这一课给你一套固定流程。

## 标准起手式

按顺序做这五件事，90% 的结构问题都能发现：

```python
import pandas as pd

df = pd.read_csv('data.csv')     # 先读进来（下一课讲）

# 1. 有多大规模
print(df.shape)

# 2. 前几行长什么样
print(df.head())

# 3. 列名和类型
print(df.info())

# 4. 数值列的统计
print(df.describe())

# 5. 有没有缺失
print(df.isna().sum())
```

## 1. shape：规模

```python
print(df.shape)      # (1000, 8) → 1000 行 8 列
```

**先知道多大**。1000 行和 100 万行的处理方式完全不同（后者要考虑性能）。

## 2. head / tail：看内容

```python
print(df.head())      # 默认前 5 行
print(df.head(10))    # 前 10 行
print(df.tail(3))     # 后 3 行
```

**`head()` 是最重要的一步**——亲眼看到数据长什么样，比看任何描述都可靠。

> 💡 如果列很多，打印时会被截断成 `col1  col2  ...  col8`。想看全所有列：

```python
pd.set_option('display.max_columns', None)    # 不限制列数
pd.set_option('display.width', 200)           # 加宽显示
```

## 3. info：列名、非空数、类型

```python
df = pd.DataFrame({
    '姓名': ['张三', '李四', '王五'],
    '年龄': [18, 19, 20],
    '成绩': [89.5, 92.0, 78.0]
})
print(df.info())
```

```
<class 'pandas.core.frame.DataFrame'>
RangeIndex: 3 entries, 0 to 2
Data columns (total 3 columns):
 #   Column  Non-Null Count  Dtype  
---  ------  --------------  -----  
 0   姓名     3 non-null      object 
 1   年龄     3 non-null      int64  
 2   成绩     3 non-null      float64
dtypes: float64(1), int64(1), object(1)
memory usage: 200.0+ bytes
```

**三个关键信息**：

- **Non-Null Count**：非空数量。如果某列是 `2 non-null` 而总共 3 行，说明**有 1 个缺失**
- **Dtype**：类型。如果本该是数字的"价格"列显示 object，说明**混进了文字**（比如 "1,299" 或 "暂无"）
- **memory usage**：内存占用

> ⚠️ **"数字列显示成 object"是最常见的脏数据信号**。原因通常是：混入了千分位逗号、货币符号、"暂无"/"-"这类占位文字。第 13 课会讲怎么处理。

## 4. describe：数值统计

```python
print(df.describe())
```

```
         年龄       成绩
count   3.000000   3.000000
mean   19.000000  86.500000
std     1.000000   7.466592
min    18.000000  78.000000
25%    18.500000  83.750000
50%    19.000000  89.500000
75%    19.500000  90.750000
max    20.000000  92.000000
```

**重点看四件事**：

| 看什么 | 能发现什么 |
|---|---|
| `count` 比行数少 | 有缺失值 |
| `min` / `max` 离谱 | 有异常值（比如年龄 200、价格 0） |
| `mean` 和 `50%` 差很多 | 数据严重偏斜（有极端值拉高均值） |
| `std` 特别大 | 数据很分散 |

**`describe()` 只看数值列**。想看文字列的分布：

```python
print(df['姓名'].value_counts())     # 各值出现几次
print(df['姓名'].unique())           # 有哪些不同的值
```

## 5. isna：缺失统计

```python
print(df.isna().sum())          # 每列各有多少缺失
print(df.isna().sum().sum())    # 全表总缺失数
print(df.isna().any())          # 每列是否"存在"缺失
```

**`isna().sum()` 是定位缺失的标准写法**。补一句占比更实用：

```python
print(df.isna().mean() * 100)     # 每列缺失占比（%）
```

某列缺失超过 50%，通常就该考虑**直接删掉这一列**而不是填补。

## 完整实战：诊断一张脏表

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    '订单号': ['A001', 'A002', 'A003', 'A004'],
    '金额': ['199', '1,299', '暂无', '89'],     # ← 脏：有逗号和文字
    '数量': [1, 2, np.nan, 1],                  # ← 有缺失
    '日期': ['2024-01-01', '2024-01-02', '2024-01-03', '2024-01-04']
})

print("规模：", df.shape)
print("\n--- info ---")
print(df.info())
print("\n--- 缺失 ---")
print(df.isna().sum())
```

从 `info()` 你会看到 **`金额` 列是 object**——因为它里面有 `'1,299'` 和 `'暂无'`，尽管看着像数字。这就是 `head()` + `info()` 组合的价值：**肉眼看到的是数字，程序看到的是文字**。

## 速查表

| 目的 | 写法 |
|---|---|
| 规模 | `df.shape` |
| 前/后几行 | `df.head()` / `df.tail()` |
| 列名 | `df.columns` |
| 行索引 | `df.index` |
| 类型与非空数 | `df.info()` |
| 数值统计 | `df.describe()` |
| 缺失数 | `df.isna().sum()` |
| 文字列分布 | `df['列'].value_counts()` |
| 唯一值 | `df['列'].unique()` |
