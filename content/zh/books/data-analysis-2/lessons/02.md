# Series：带标签的一列

> Series 是 pandas 的最小单位。搞懂它，DataFrame 就是"一堆 Series 拼起来"。

## 创建一个 Series

```python
import pandas as pd

s = pd.Series([10, 20, 30, 40])
print(s)
```

```
0    10
1    20
2    30
3    40
dtype: int64
```

两列输出：左边是**索引**，右边是**值**。不指定索引时，默认从 0 开始编号。

## 自定义索引

**这才是 Series 的精髓**——索引不必是数字：

```python
s = pd.Series([10, 20, 30], index=['北京', '上海', '广州'], name='销量')
print(s)
print("name:", s.name)
```

```
北京    10
上海    20
广州    30
Name: 销量, dtype: int64
```

现在可以用**名字**取值，而不是"第几个"：

```python
print(s['上海'])      # 20  ← 按标签
print(s.iloc[1])     # 20  ← 按位置
```

> ⚠️ **`s['上海']` 和 `s.iloc[1]` 的区别，是 pandas 最容易混淆的地方**，下一章会详细讲。现在先记住：**方括号里写标签，`.iloc[]` 里写位置**。

## 三个属性

```python
print(s.values)     # [10 20 30]  ← ndarray
print(s.index)      # Index(['北京', '上海', '广州'], dtype='object')
print(s.dtype)      # int64
```

**`s.values` 就是 NumPy 数组**——这再次印证了 pandas 建立在 NumPy 之上。

```python
import numpy as np
print(type(s.values))          # <class 'numpy.ndarray'>
print(s.values.mean())         # NumPy 的方法直接可用
```

## Series 的运算

**两个 Series 运算时按索引对齐**，不是按位置：

```python
a = pd.Series([1, 2, 3], index=['x', 'y', 'z'])
b = pd.Series([10, 20, 30], index=['z', 'y', 'x'])    # 注意顺序反了

print(a + b)
```

```
x    31    ← a的x(1) + b的x(30)
y    22    ← a的y(2) + b的y(20)
z    13    ← a的z(3) + b的z(10)
```

**pandas 先按标签配对，再计算**。这和 NumPy 的"按位置"完全不同——NumPy 会算成 `1+10, 2+20, 3+30`。

**这是 pandas 最重要的特性之一，也是最容易出 bug 的地方**：

```python
a = pd.Series([1, 2, 3], index=['x', 'y', 'z'])
b = pd.Series([10, 20], index=['x', 'y'])     # 少了 z

print(a + b)
```

```
x    11.0
y    22.0
z     NaN    ← 对不上的变成 NaN
```

**对不上的标签结果是 NaN**。这不会报错，只会默默产生缺失值——排查时很坑。

## 与标量的运算

和 NumPy 一样，广播：

```python
print(s * 2)          # 每个都乘 2
print(s > 15)         # 布尔 Series
print(s[s > 15])      # 用布尔 Series 筛选
```

```
北京    False
上海     True
广州     True
dtype: bool

上海    20
广州    30
dtype: int64
```

**布尔 Series 可以当筛子用**——和 NumPy 的布尔索引一个道理。

## 常用方法

```python
print(s.sum(), s.mean(), s.max(), s.min())
print(s.idxmax())       # 最大值的索引标签 ← 很实用
print(s.value_counts()) # 各值出现几次
print(s.sort_values(ascending=False))
```

**`idxmax()` 返回的是标签而不是位置**。接上一课的写法：

```python
print(f"销量最高的是：{s.idxmax()}，销了 {s.max()}")
# 销量最高的是：广州，销了 30
```

`idxmax` / `idxmin` 在"找出第一名是谁"时特别好用，比 `argmax`（返回位置）更直观。

## 从字典创建

字典的键自动变成索引：

```python
d = {'北京': 10, '上海': 20, '广州': 30}
s = pd.Series(d)
print(s)
```

这是最常见的创建方式之一。

## 缺失值

```python
import numpy as np
s = pd.Series([1, np.nan, 3])
print(s)
print("有缺失吗：", s.isna().any())
print("均值：", s.mean())        # 2.0 —— 自动跳过 NaN
```

**注意 `s.mean()` 直接跳过 NaN 得到 2.0**。NumPy 里 `arr.mean()` 会得到 nan，必须写 `np.nanmean()`。

> 💡 这是 pandas 比 NumPy 省心的第一个地方：**统计函数默认跳过缺失值**，不用记两套函数名。

## 随堂练习

体会"按索引对齐"。

```quiz
type: code
q: 两个索引顺序不同的 Series 相加，打印 'x' 位置的结果
starter: |
  import pandas as pd
  
  a = pd.Series([1, 2, 3], index=['x', 'y', 'z'])
  b = pd.Series([10, 20, 30], index=['z', 'y', 'x'])
  
  # pandas 按标签对齐：a的x(1) + b的x(30) = 31
  # 打印 (a+b)['x']
  
  print("在这里改")
tests:
- assert "31" in __out
hint: print((a + b)['x'])。pandas 相加时先按索引标签配对再计算 —— b 虽然顺序反了，但标签 'x' 对应的值是 30，所以 1+30=31。
explain: 这是 pandas 与 NumPy 最本质的区别之一：NumPy 按位置对齐（1+10），pandas 按标签对齐（1+30）。这个特性让数据处理更安全（不会因为行顺序变了就算错），但也意味着标签对不上时会产生 NaN —— 排查时要留意。
```
