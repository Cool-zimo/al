# 综合实战：一份销售分析报告

> 把前四章串起来，走一遍真实的分析流程。这一课没有多少新语法，重点是**顺序**。

## 完整流程

```
拿到数据 → 看清结构 → 清洗 → 分组聚合 → 透视 → 输出结论
```

很多人上来就 groupby，结果算出的数据是脏的。**顺序错了，结论就错了。**

## 第一步：看清结构

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    '日期': ['2024-01-01', '2024-01-01', '2024-01-02', '2024-01-02',
             '2024-01-03', '2024-01-03'],
    '城市': ['北京', '上海', '北京', '上海', '北京', '广州'],
    '类别': ['外设', '显示', '外设', '显示', '音频', '外设'],
    '销售额': ['¥1,299', '¥8,999', '¥899', '¥12,999', '暂无', '¥599'],
    '数量': ['2', '1', '3', '2', '1', 'x']
})

print(df.head())
print()
print(df.dtypes)
```

**先别急着算**——注意"销售额"是文字列（带 ¥ 和逗号），"数量"里还有个 `x`。

## 第二步：清洗

```python
# 1. 销售额：去掉符号和逗号，转数字
df['销售额'] = pd.to_numeric(
    df['销售额'].str.replace('¥', '').str.replace(',', ''),
    errors='coerce'
)

# 2. 数量：转数字，失败的填 0 再转 int
df['数量'] = pd.to_numeric(df['数量'], errors='coerce').fillna(0).astype(int)

# 3. 日期转 datetime
df['日期'] = pd.to_datetime(df['日期'])

print(df.dtypes)
print()
print("缺失情况：")
print(df.isna().sum())
```

**"暂无"变成了 NaN**——这是真实情况（那笔销售没记录金额），后面处理。

## 第三步：缺失处理

```python
# 销售额缺失的那一行，信息不完整 → 删掉
print("清洗前行数：", len(df))
df = df.dropna(subset=['销售额'])
print("清洗后行数：", len(df))
```

**决策依据**：销售额是核心指标，缺了就没法分析，删掉比瞎填好。

## 第四步：分组聚合

```python
print("=== 各城市销售额 ===")
city = df.groupby('城市')['销售额'].agg(['sum', 'mean', 'count'])
print(city.sort_values('sum', ascending=False))

print("\n=== 各类别销售额 ===")
cate = df.groupby('类别')['销售额'].agg(['sum', 'mean', 'count'])
print(cate.sort_values('sum', ascending=False))
```

```
=== 各城市销售额 ===
      sum     mean  count
城市
上海  21998  10999.0      2
北京   2197  1098.5       2
广州    599   599.0       1

=== 各类别销售额 ===
      sum     mean  count
类别
显示  21998  10999.0      2
外设   2197  1098.5       2
音频    599   599.0       1
```

**看 `count` 这一列**——上海和北京各 2 笔、广州只有 1 笔。**样本量小的组，均值不可靠**，这是很多人忽略的。

## 第五步：加分析列（transform）

```python
df['城市总额'] = df.groupby('城市')['销售额'].transform('sum')
df['城市占比'] = (df['销售额'] / df['城市总额'] * 100).round(1)
df['高于城市均值'] = df['销售额'] > df.groupby('城市')['销售额'].transform('mean')

print(df[['日期', '城市', '类别', '销售额', '城市总额', '城市占比', '高于城市均值']])
```

**明细 + 组级指标一次得到**。

## 第六步：透视表

```python
print("=== 城市 × 类别 透视表 ===")
pt = df.pivot_table(index='城市', columns='类别', values='销售额',
                    aggfunc='sum', fill_value=0, margins=True,
                    margins_name='合计')
print(pt)
```

```

城市
上海       0  21998     0  21998
北京    2197      0   599   2796
广州     599      0     0    599
合计    2796  21998   599  25393
```

**一眼看出**：上海全靠显示器，北京比较分散。

## 第七步：输出结论

```python
print("=== 分析结论 ===")
top_city = df.groupby('城市')['销售额'].sum().idxmax()
top_cate = df.groupby('类别')['销售额'].sum().idxmax()
total = df['销售额'].sum()

print(f"总销售额：{total:,.0f}")
print(f"销售额最高的城市：{top_city}（{df.groupby('城市')['销售额'].sum().max():,.0f}）")
print(f"销售额最高的类别：{top_cate}（{df.groupby('类别')['销售额'].sum().max():,.0f}）")
print(f"{top_city} 贡献占比：{df[df['城市']==top_city]['销售额'].sum()/total*100:.1f}%")
print(f"有效订单数：{len(df)}")
```

**分析的价值在结论，不在过程。** 前面所有步骤都是为了这几句话。

## 完整的分析模板

```python
import pandas as pd
import numpy as np

def analyze(df):
    """一份标准的销售分析流程"""
    # 1. 结构
    print("【1】结构")
    print(df.dtypes)
    print(f"{len(df)} 行 × {df.shape[1]} 列")

    # 2. 清洗
    print("\n【2】清洗")
    for col in df.select_dtypes(include='object').columns:
        conv = pd.to_numeric(df[col], errors='coerce')
        if conv.notna().sum() > 0:      # 有能转成功的，说明这列本该是数字
            df[col] = conv
            print(f"  {col}: 已转数字，{conv.isna().sum()} 个失败")
    print("  剩余缺失：")
    print(df.isna().sum().to_string())

    # 3. 分组
    print("\n【3】各城市汇总")
    g = df.groupby('城市')['销售额'].agg(['sum','mean','count'])
    print(g.sort_values('sum', ascending=False))

    # 4. 透视
    print("\n【4】透视表")
    print(df.pivot_table(index='城市', columns='类别', values='销售额',
                         aggfunc='sum', fill_value=0, margins=True))

    # 5. 结论
    print("\n【5】结论")
    s = df.groupby('城市')['销售额'].sum()
    print(f"  总额 {df['销售额'].sum():,.0f}，最高城市 {s.idxmax()}（{s.max():,.0f}，占比 {s.max()/s.sum()*100:.1f}%）")

    return df
```

## 回顾：这一章的顺序为什么是这样

| 步骤 | 为什么在这个位置 |
|---|---|
| 看结构 | 不知道列是什么类型就动手，一定出错 |
| 清洗 | 脏数据算出来的结论是错的 |
| 补缺失 | 缺失影响 count 和 mean |
| 分组 | 清洗干净了才能聚合 |
| transform | 需要组级指标时加列 |
| 透视 | 最后一步，为了展示 |

**调换顺序，比如先 groupby 再清洗，就会得到错误的汇总。**
