# 改值与加列

> 筛选之后就该改数据了。这一课讲赋值、新增列、apply，以及一个著名的警告。

## 新增一列

三种常见写法：

```python
import pandas as pd

df = pd.DataFrame({
    '姓名': ['张三', '李四', '王五'],
    '成绩': [89.5, 92.0, 78.0]
})

df['等级'] = ['良', '优', '及格']              # 直接给列表
df['及格'] = df['成绩'] >= 60                  # 由其他列算出
df['名次'] = df['成绩'].rank(ascending=False)   # 用方法算

print(df)
```

**给一个不存在的列名赋值，就是新增列**；列名已存在，就是覆盖。

> ⚠️ 用列表赋值时，**长度必须和行数一致**，否则报 `ValueError: Length of values does not match length of index`。

## 修改已有值

```python
# 改单个值
df.loc[0, '成绩'] = 90.0

# 按条件改
df.loc[df['成绩'] < 60, '等级'] = '不及格'

# 整列改
df['成绩'] = df['成绩'] + 5        # 每人加 5 分
```

**条件赋值是最高频的操作**，格式记住：

```python
df.loc[条件, '列名'] = 新值
```

## 一个著名的坑：链式赋值

```python
# ❌ 这样改可能无效
df[df['成绩'] < 60]['等级'] = '不及格'

# ✅ 正确
df.loc[df['成绩'] < 60, '等级'] = '不及格'
```

**为什么会失效？**

`df[条件]` 返回的是**一个新的 DataFrame**（pandas 大多数操作返回副本）。你在副本上改，原表没变。

pandas 会给出 `SettingWithCopyWarning` 提示，但**这个警告有时不显示**，导致你以为改成功了其实没有。

> 💡 **口诀：赋值一律用 `df.loc[行, 列] = 值`，不要用链式。**

## apply：逐行或逐列处理

当赋值逻辑复杂到"一列算式写不出来"时，用 `apply`：

```python
def judge(score):
    if score >= 90:
        return '优'
    elif score >= 80:
        return '良'
    elif score >= 60:
        return '及格'
    else:
        return '不及格'

df['等级'] = df['成绩'].apply(judge)
print(df)
```

**`apply` 接收一个函数，对 Series 的每个值调用它**，返回值组成新的一列。

**简单逻辑用 lambda 更省事**：

```python
df['等级'] = df['成绩'].apply(lambda x: '优' if x >= 90 else '良')
```

## apply 到整行：axis=1

```python
df2 = pd.DataFrame({
    '语文': [80, 95, 88],
    '数学': [90, 70, 85]
})

# 算总分（对每一行求和）
df2['总分'] = df2.apply(lambda row: row['语文'] + row['数学'], axis=1)
print(df2)
```

**`axis=1` 表示"沿着列方向走"**，也就是对每一行操作。

但**这个例子其实不需要 apply**：

```python
df2['总分'] = df2['语文'] + df2['数学']       # ✅ 更快更清晰
```

> ⚠️ **apply 是逐行跑 Python 函数，比向量化运算慢得多**。能用列运算就不要用 apply。
> apply 只在"逻辑确实无法向量化"时才用。

## 重命名列

```python
df = df.rename(columns={'成绩': '分数', '姓名': '名字'})
```

**也是返回新表**，要么赋值回去要么加 `inplace=True`。

## 删除行和列

```python
df = df.drop(columns=['及格'])          # 删列
df = df.drop(index=[0])                 # 删行
df = df.drop(index=df[df['分数'] < 60].index)   # 按条件删行
```

**按条件删行的套路**：先用条件找出要删的索引，再传给 `drop`。

## 替换值：replace

```python
df['等级'] = df['等级'].replace({'优': 'A', '良': 'B'})
```

支持字典（一对一映射），也支持单值替换：

```python
df['分数'] = df['分数'].replace(0, pd.NA)      # 把 0 换成缺失
```

## 一个实战例子

```python
import pandas as pd

df = pd.DataFrame({
    '商品': ['键盘', '鼠标', '显示器', '耳机'],
    '单价': [199, 89, 1299, 399],
    '销量': [120, 500, 30, 200]
})

# 1. 算销售额
df['销售额'] = df['单价'] * df['销量']

# 2. 按销售额分级
df['级别'] = df['销售额'].apply(
    lambda x: '爆款' if x >= 50000 else ('畅销' if x >= 20000 else '普通')
)

# 3. 给爆款打标
df.loc[df['级别'] == '爆款', '备注'] = '重点推广'

# 4. 按销售额排序
df = df.sort_values('销售额', ascending=False)

print(df)
```

## 小结

| 需求 | 写法 |
|---|---|
| 新增列 | `df['新列'] = ...` |
| 改单个值 | `df.loc[行, 列] = 值` |
| 按条件改 | `df.loc[条件, '列'] = 值` |
| 复杂逻辑 | `df['列'].apply(函数)` |
| 跨列计算 | `df.apply(函数, axis=1)`（尽量改用列运算） |
| 重命名 | `df.rename(columns={...})` |
| 删除 | `df.drop(columns=[...])` |
| 替换 | `df['列'].replace({...})` |
