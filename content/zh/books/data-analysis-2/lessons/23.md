# 连接时的坑：重复键、列名冲突与 indicator

> merge 最容易出问题的时候不是语法错，而是"结果看起来正常，数字却悄悄翻倍"。这一课专治这类隐蔽错误。

## 行数翻倍：最经典的翻车

```python
import pandas as pd

订单 = pd.DataFrame({'订单号': ['A001', 'A002'], '客户': ['张三', '李四']})
明细 = pd.DataFrame({
    '订单号': ['A001', 'A001', 'A002'],
    '商品': ['键盘', '鼠标', '显示器'],
    '金额': [200, 50, 1500]
})
```

想算每个订单的总金额：

```python
# WRONG
合并 = 订单.merge(明细, on='订单号')
print(合并.groupby('订单号')['金额'].sum())
```

```
订单号
A001    250
A002    1500
dtype: int64
```

**结果居然"对"了！** 但看看合并后的行数：

```python
print(len(合并))   # 3
```

订单表 2 行变 3 行。**一对多连接把左表撑大了**。上面这个例子恰好没出错，是因为 groupby 在明细侧聚合。

真出问题的是这种情况：

```python
# 订单表还有一列"运费"，也要一起求和
订单2 = pd.DataFrame({
    '订单号': ['A001', 'A002'], '客户': ['张三', '李四'], '运费': [10, 15]
})
合并2 = 订单2.merge(明细, on='订单号')
print(合并2.groupby('订单号')['运费'].sum())
```

```
订单号
A001    20
A002    15
dtype: int64
```

**张三的运费是 10，结果变成 20**——因为 A001 在明细里有两行，运费被重复计算了。

**正确做法：先聚合，再合并**：

```python
金额汇总 = 明细.groupby('订单号')['金额'].sum().reset_index()
结果 = 订单2.merge(金额汇总, on='订单号')
print(结果)
```

```
   订单号  客户  运费   金额
0  A001  张三   10   250
1  A002  李四   15  1500
```

## 翻车现场：outer join 产生大量 NaN

```python
会员 = pd.DataFrame({
    '用户id': [1, 2, 3],
    '等级': ['金', '银', '铜']
})
订单 = pd.DataFrame({
    '用户id': [2, 3, 4, 5],
    '金额': [100, 200, 300, 400]
})

全量 = 会员.merge(订单, on='用户id', how='outer')
print(全量)
```

```
    用户id   等级     金额
0   1.0    金     NaN
1   2.0    银   100.0
2   3.0    铜   200.0
3   4.0   NaN   300.0
4   5.0   NaN   400.0
```

**用户 1 没有订单（金额 NaN），用户 4、5 不是会员（等级 NaN）**。outer 把两边的全留下来了。

**这不一定是错的**——做"全量分析"就需要这样。但如果你的目标是"算会员的客单价"，**这里就该用 left join**：

```python
print(会员.merge(订单, on='用户id', how='left'))
```

```
   用户id  等级     金额
0     1   金     NaN
1     2   银   100.0
2     3   铜   200.0
```

**只保留会员，非会员不进入分母**。

## 重复键：笛卡尔积

```python
a = pd.DataFrame({'日期': ['09-01', '09-01'], '门店': ['北京', '北京'], '销售额': [1200, 1500]})
b = pd.DataFrame({'日期': ['09-01', '09-01'], '门店': ['北京', '北京'], '客流': [80, 120]})
```

**两张表在"日期+门店"上都有两行**：

```python
print(a.merge(b, on=['日期', '门店']))
```

```
     日期  门店  销售额   客流
0  09-01  北京  1200   80
1  09-01  北京  1200  120
2  09-01  北京  1500   80
3  09-01  北京  1500  120
```

**2×2=4 行，全排列**。merge 不知道哪行对哪行，只能全连。

**解决：加一个能区分行的列当键**（比如订单号、时间戳），或先聚合再去重：

```python
b1 = b.drop_duplicates(subset=['日期', '门店'])
print(len(a.merge(b1, on=['日期', '门店'])))   # 2
```

## indicator 参数：看穿每一行的来历

```python
r = 会员.merge(订单, on='用户id', how='outer', indicator=True)
print(r)
```

```
    用户id   等级     金额     _merge
0     1   金     NaN   left_only
1     2   银   100.0        both
2     3   铜   200.0        both
3     4  NaN   300.0  right_only
4     5  NaN   400.0  right_only
```

`_merge` 列只有三种值：`left_only`、`right_only`、`both`。

**这是排查连接质量最快的办法**。比如"会员里有多少人下过单"：

```python
下单会员 = r[r['_merge'] == 'both']
print(len(下单会员) / len(会员))   # 2/3
```

## 列名冲突：自动加后缀

```python
x = pd.DataFrame({'id': [1, 2], '值': [10, 20]})
y = pd.DataFrame({'id': [1, 2], '值': [100, 200]})

print(x.merge(y, on='id'))
```

```
   id  值_x  值_y
0   1   10  100
1   2   20  200
```

**同名的非键列自动加 `_x`（左表）、`_y`（右表）**。这是救命的设计——否则你根本分不清哪个是哪个。

如果想自定义后缀：

```python
print(x.merge(y, on='id', suffixes=('_去年', '_今年')))
```

```
   id  值_去年  值_今年
0   1    10    100
1   2    20    200
```

## 小结

- **一对多连接会让左表行数变多**，聚合前务必先 groupby 再 merge
- **outer 会留下大量 NaN**，明确你的目标是"全量"还是"单边"
- **重复键产生笛卡尔积**，先去重或加区分键
- **`indicator=True`** 给每行打上 `left_only/both/right_only` 标记
- **列名冲突自动加 `_x/_y`**，可用 `suffixes` 自定义
