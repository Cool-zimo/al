# 排序与去重

> 最后两个高频操作。这一课讲 sort_values、drop_duplicates，以及"索引跟着走"的注意事项。

## 排序：sort_values

```python
import pandas as pd

df = pd.DataFrame({
    '姓名': ['张三', '李四', '王五', '赵六'],
    '年龄': [18, 19, 20, 17],
    '成绩': [89.5, 92.0, 78.0, 95.0]
})

print(df.sort_values('成绩'))                       # 升序（默认）
print(df.sort_values('成绩', ascending=False))      # 降序
```

**默认升序**。`ascending=False` 改降序。

## 排序返回新表

```python
df2 = df.sort_values('成绩', ascending=False)
print(df.index)      # 原表没变：[0, 1, 2, 3]
print(df2.index)     # 新表：[3, 1, 0, 2]  ← 索引跟着行走
```

**两个要点**：

1. **默认不改原表**——要 `df = df.sort_values(...)` 或加 `inplace=True`
2. **索引跟着数据走，不会重新编号**

## 重置索引：reset_index

```python
df2 = df.sort_values('成绩', ascending=False).reset_index(drop=True)
print(df2.index)     # [0, 1, 2, 3]  ← 重新编号了
print(df2)
```

> ⚠️ **`drop=True` 很关键**。不写的话，旧索引会变成新的一列（叫 `index`）：

```python
df2 = df.sort_values('成绩', ascending=False).reset_index()
print(df2.columns)   # ['index', '姓名', '年龄', '成绩']  ← 多了一列
```

## 按多列排序

```python
df.sort_values(['年龄', '成绩'], ascending=[True, False])
```

**传列表**：先按年龄升序，年龄相同的再按成绩降序。`ascending` 也可以给列表，一一对应。

## 取前几名：nlargest / nsmallest

```python
print(df.nlargest(2, '成绩'))       # 成绩最高的 2 行
print(df.nsmallest(2, '成绩'))      # 成绩最低的 2 行
```

**比"排序再取前 N 行"更直接，也更省事**。

```python
# 等价，但更啰嗦
df.sort_values('成绩', ascending=False).head(2)
```

## 去重：drop_duplicates

```python
d = pd.DataFrame({
    '城市': ['北京', '北京', '上海', '广州', '上海'],
    '值': [1, 1, 2, 3, 4]
})

print(d.drop_duplicates())
```

```
  城市  值
0  北京  1
2  上海  2
3  广州  3
4  上海  4
```

**注意"上海"出现了两次但都保留了**——因为值不一样，整行不完全相同。

## 按部分列去重：subset

```python
print(d.drop_duplicates(subset=['城市']))
```

```
  城市  值
0  北京  1
2  上海  2
3  广州  3
```

**只按"城市"这列判断重复**，保留每个城市第一次出现的那行。

## 保留哪一个：keep

```python
print(d.drop_duplicates(subset=['城市'], keep='last'))    # 保留最后一次
print(d.drop_duplicates(subset=['城市'], keep=False))     # 重复的全删掉
```

| `keep` | 含义 |
|---|---|
| `'first'`（默认） | 保留第一次出现的 |
| `'last'` | 保留最后一次出现的 |
| `False` | 只要重复的，**全都不保留** |

## 先看有多少重复：duplicated

```python
print(d.duplicated().sum())                    # 完全重复的行数
print(d.duplicated(subset=['城市']).sum())     # 城市重复的行数
print(d[d.duplicated(subset=['城市'], keep=False)])   # 把重复的行列出来看看
```

**`duplicated()` 返回布尔 Series**，标记"这一行是不是重复出现的"。配合 `keep=False` 可以把所有重复项揪出来检查。

## 排序 + 去重的经典组合

**"每个城市取销售额最高的一笔"**：

```python
sales = pd.DataFrame({
    '城市': ['北京', '上海', '北京', '上海', '广州'],
    '销售额': [100, 200, 150, 180, 90]
})

# 先按销售额降序排，再按城市去重（保留第一条 = 最高的）
top = sales.sort_values('销售额', ascending=False).drop_duplicates(subset=['城市'])
print(top)
```

```
  城市  销售额
1  上海  200
2  北京  150
4  广州   90
```

**这个"先排序再去重"的套路非常实用**——它等价于 SQL 里的"分组取最大值所在行"。

## 按索引排序：sort_index

```python
df3 = df.sort_values('成绩', ascending=False)
print(df3.sort_index())      # 按索引标签排回去
```

排序后想恢复原来的行顺序，用 `sort_index()`。

## 小结

| 需求 | 写法 |
|---|---|
| 按值排序 | `df.sort_values('列', ascending=False)` |
| 多列排序 | `df.sort_values(['列1','列2'], ascending=[True,False])` |
| 重新编号 | `.reset_index(drop=True)` |
| 前 N 大 | `df.nlargest(N, '列')` |
| 去重 | `df.drop_duplicates()` |
| 按列去重 | `df.drop_duplicates(subset=['列'])` |
| 保留最后一个 | `keep='last'` |
| 看重复 | `df.duplicated().sum()` |
| 按索引排 | `df.sort_index()` |
