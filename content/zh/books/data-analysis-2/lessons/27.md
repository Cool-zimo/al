# resample：按时间频率重新采样

> 每天的数据太碎，按月看趋势更清晰。resample 就是把"日频"数据按"月频""周频"重新归拢的标准工具。

## 从按天到按月

```python
import pandas as pd

idx = pd.date_range('2026-01-01', periods=90, freq='D')
df = pd.DataFrame({'日期': idx, '销售额': range(90)})
df = df.set_index('日期')
```

90 天的日数据，想看"每月总额"：

```python
月度 = df['销售额'].resample('ME').sum()
print(月度)
```

```
日期
2026-01-31    465
2026-02-28   1246
2026-03-31   2826
Freq: M, Name: 销售额, dtype: int64
```

**90 行压成 3 行**。索引自动变成每月最后一天。

## 语法：像 groupby 一样用

```python
df.resample('频率').聚合函数()
```

**resample 是"按时间分组的 groupby"**。所以它后面接的也是 sum、mean、max 这些聚合函数。

常用频率别名：

| 别名 | 含义 |
|---|---|
| `D` | 天 |
| `W` | 周 |
| `M` | 月末 |
| `MS` | 月初 |
| `Q` | 季度末 |
| `Y` | 年末 |

**`M` 和 `MS` 的区别**：`M` 取每月最后一天做标签，`MS` 取第一天。

```python
print(df['销售额'].resample('MS').sum().head(2))
```

```
日期
2026-01-01    465
2026-02-01   1246
Freq: MS, Name: 销售额, dtype: int64
```

## 降采样 vs 升采样

**降采样**：高频→低频（日→月），需要聚合。

```python
日频 = pd.DataFrame({'v': [1, 2, 3]}, index=pd.date_range('2026-01-01', periods=3))
```

**升采样**：低频→高频（月→日），需要填充。

```python
月频 = pd.DataFrame({'v': [100, 200]}, index=pd.date_range('2026-01-01', periods=2, freq='ME'))
日升 = 月频.resample('D').ffill()
print(len(日升))   # 60（1月31天 + 2月28天附近的展开）
```

**升采样本身只产生索引，值全是 NaN**，必须配合 `ffill()`（前向填充）或 `bfill()`（后向填充）。

## 翻车现场：resample 后忘了聚合

```python
df2 = pd.DataFrame({'v': [1, 2, 3]},
                   index=pd.date_range('2026-01-01', periods=3))
```

```python
# WRONG
df2.resample('ME')
```

```
DatetimeIndexResampler 对象（不是结果！）
```

**resample 本身不计算结果**，必须跟上 `.sum()` / `.mean()` 等聚合。

正确写法：

```python
print(df2['v'].resample('ME').sum())
```

## asfreq：只要重排频率，不要聚合

```python
稀疏 = pd.DataFrame({'v': [10, 20, 30]},
                    index=pd.to_datetime(['2026-01-01', '2026-01-03', '2026-01-05']))
```

```python
print(稀疏['v'].asfreq('D'))
```

```
2026-01-01    10.0
2026-01-02     NaN
2026-01-03    20.0
2026-01-04     NaN
2026-01-05    30.0
Freq: D, Name: v, dtype: float64
```

**asfreq 只是把索引对齐到新频率，缺失的填 NaN**。它**不做聚合**。

对比 resample：

```python
print(稀疏['v'].resample('D').mean())
```

结果一样（因为每天最多一个值）。**但语义不同**：resample 是"按频率分组后聚合"，asfreq 是"按频率重新对齐"。

**需要填值时用 asfreq + ffill**：

```python
print(稀疏['v'].asfreq('D').ffill())
```

```
2026-01-01    10
2026-01-02    10
2026-01-03    20
2026-01-04    20
2026-01-05    30
Freq: D, Name: v, dtype: int64
```

## 翻车现场：索引不是时间类型

```python
坏 = pd.DataFrame({'日期': ['2026-01-01', '2026-01-02'], 'v': [1, 2]})
坏 = 坏.set_index('日期')

# WRONG
坏['v'].resample('ME').sum()
```

```
TypeError: Only valid with DatetimeIndex, TimedeltaIndex or PeriodIndex...
```

**resample 要求索引是 DatetimeIndex**。忘记 to_datetime 是最常见的报错原因。

```python
# 修复
坏.index = pd.to_datetime(坏.index)
print(坏['v'].resample('ME').sum())
```

## 多列一起聚合

```python
多列 = pd.DataFrame({
    '销售额': [100, 200, 150],
    '成本': [60, 120, 80]
}, index=pd.date_range('2026-01-01', periods=3))

print(多列.resample('ME').sum())
```

```
            销售额   成本
日期
2026-01-31   450  260
```

**对整张表 resample，所有数值列都会被聚合**。

## 小结

- **resample 是"按时间的 groupby"**，必须跟上聚合函数
- **降采样（日→月）要聚合**，升采样（月→日）要填充
- **`ME` 月末、`MS` 月初**，标签位置不同
- **asfreq 只重排频率、不聚合**，缺值补 NaN
- **索引必须是 DatetimeIndex**，否则报错
