# 条件筛选

> 从"取出全部"到"只取符合条件的"。这一课讲布尔索引、多条件，以及一个必错的语法坑。

## 布尔索引的本质

```python
import pandas as pd

df = pd.DataFrame({
    '姓名': ['张三', '李四', '王五', '赵六'],
    '年龄': [18, 19, 20, 17],
    '成绩': [89.5, 92.0, 78.0, 95.0]
})

print(df['成绩'] > 90)
```

```
0    False
1     True
2    False
3     True
Name: 成绩, dtype: bool
```

**比较运算得到一个布尔 Series**。把它放进方括号（或 loc）就是筛选：

```python
print(df[df['成绩'] > 90])
```

```
   姓名  年龄    成绩
1  李四  19  92.0
3  赵六  17  95.0
```

**原理**：布尔 Series 像一张"筛子"，True 的行留下，False 的行筛掉。

## 分步写更清楚

初学时拆成两步，不容易错：

```python
mask = df['成绩'] > 90        # 先算出筛子
print(mask.sum())             # 有多少个 True（= 符合条件的行数）

result = df[mask]             # 再筛
print(result)
```

**`mask.sum()` 是个实用技巧**——True 记 1，False 记 0，加起来就是"符合条件的行数"。

## 多条件：必须用 & 和 |

```python
# 年龄 > 18 且 成绩 > 90
print(df[(df['年龄'] > 18) & (df['成绩'] > 90)])

# 年龄 <= 18 或 成绩 >= 95
print(df[(df['年龄'] <= 18) | (df['成绩'] >= 95)])
```

> ⚠️ **三个必须记住的点**：

1. **不能用 `and` / `or`** —— 那是对单个布尔值做运算，对 Series 会报错
2. **必须加括号** —— `df['年龄'] > 18 & df['成绩'] > 90` 会因为运算符优先级出错
3. **取反用 `~`** —— 不是 `not`

```python
# ❌ 会报错
df[df['年龄'] > 18 and df['成绩'] > 90]

# ❌ 优先级错误
df[df['年龄'] > 18 & df['成绩'] > 90]

# ✅ 正确
df[(df['年龄'] > 18) & (df['成绩'] > 90)]

# 取反
df[~(df['成绩'] > 90)]        # 成绩不高于 90 的
```

## isin：按名单筛选

```python
# 只要张三和王五
print(df[df['姓名'].isin(['张三', '王五'])])

# 反过来：不要这两个
print(df[~df['姓名'].isin(['张三', '王五'])])
```

**`isin` 比写一堆 `==` 优雅得多**：

```python
# ❌ 啰嗦
df[(df['姓名'] == '张三') | (df['姓名'] == '王五')]

# ✅ 清晰
df[df['姓名'].isin(['张三', '王五'])]
```

## 字符串条件：.str 访问器

```python
# 姓名以"张"开头
print(df[df['姓名'].str.startswith('张')])

# 姓名包含"三"
print(df[df['姓名'].str.contains('三')])
```

**`.str` 是字符串列的专用访问器**，里面能用的方法就是 Python 字符串的那些（`startswith`、`contains`、`upper`、`strip` 等）。第 15 课会详细讲。

## 筛选后选列

```python
# 只要姓名（用 loc 一步到位）
print(df.loc[df['成绩'] > 90, '姓名'])

# 要两列
print(df.loc[df['成绩'] > 90, ['姓名', '成绩']])
```

> 💡 **推荐用 `loc[条件, 列]` 而不是 `df[条件]['姓名']` 链式写法**。链式在给筛选结果赋值时会失效（下一课会遇到）。

## 一个容易忽略的细节：索引跟着走

```python
result = df[df['成绩'] > 90]
print(result.index)      # [1, 3]  ← 原来的行号，不是 0、1
```

**筛选结果的索引保留了原来的标签**，不会重新编号。

这通常是好事（知道这些数据原本在哪），但如果你想重排：

```python
print(result.reset_index(drop=True))      # 变成 0、1
```

**`drop=True` 很重要**——不写的话旧索引会变成新的一列。

## 综合例子

```python
import pandas as pd

df = pd.DataFrame({
    '商品': ['键盘', '鼠标', '显示器', '耳机', '音箱'],
    '类别': ['外设', '外设', '显示', '外设', '音频'],
    '单价': [199, 89, 1299, 399, 599],
    '库存': [120, 500, 30, 200, 0]
})

# 有货的外设，且单价在 100~500 之间
mask = (df['类别'] == '外设') & (df['库存'] > 0) & (df['单价'].between(100, 500))
print(df.loc[mask, ['商品', '单价', '库存']])
```

```
   商品   单价   库存
0  键盘  199  120
3  耳机  399  200
```

**`between(100, 500)` 是闭区间**，等价于 `(df['单价'] >= 100) & (df['单价'] <= 500)`，写起来更清爽。

## 速查

| 需求 | 写法 |
|---|---|
| 单条件 | `df[df['列'] > 值]` |
| 且 | `df[(条件A) & (条件B)]` |
| 或 | `df[(条件A) \| (条件B)]` |
| 非 | `df[~条件]` |
| 在名单里 | `df['列'].isin([...])` |
| 区间 | `df['列'].between(低, 高)` |
| 空值 | `df['列'].isna()` / `.notna()` |
| 字符串包含 | `df['列'].str.contains('x')` |
| 符合几行 | `mask.sum()` |
