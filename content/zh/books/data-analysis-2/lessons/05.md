# 读 CSV 到 DataFrame

> `read_csv` 是 pandas 最常用的一个函数，也是参数最多的一个。这一课讲常用的那几个，以及四个最常见的坑。

## 最基本的用法

```python
import pandas as pd

df = pd.read_csv('data.csv')
print(df.shape)
print(df.head())
```

**pandas 会自动把第一行当表头**，剩下的当数据。

## 常用参数

| 参数 | 作用 |
|---|---|
| `sep` / `delimiter` | 分隔符，默认逗号 |
| `header` | 第几行是表头，`None` 表示没有表头 |
| `names` | 自己指定列名 |
| `index_col` | 用哪一列当行索引 |
| `usecols` | 只读指定的几列 |
| `encoding` | 文件编码（中文乱码用 `gbk`） |
| `skiprows` | 跳过开头几行 |
| `nrows` | 只读前多少行（试读大文件用） |
| `na_values` | 哪些文字算作缺失 |
| `thousands` | 千分位分隔符 |

## 坑一：没有表头

文件长这样（第一行就是数据）：

```
张三,18
李四,19
```

```python
df = pd.read_csv('no_header.csv')     # ❌ 会把"张三,18"当成表头！
print(df.columns)     # ['张三', '18']  ← 错了

df = pd.read_csv('no_header.csv', header=None)     # ✅
print(df.columns)     # [0, 1]

df = pd.read_csv('no_header.csv', header=None, names=['姓名', '年龄'])   # ✅ 更好
```

## 坑二：编码（中文乱码）

```
UnicodeDecodeError: 'utf-8' codec can't decode byte 0xd5 in position 0
```

**中文 Windows 上 Excel 另存的 CSV 默认是 GBK**，这是乱码的头号来源。

```python
df = pd.read_csv('data.csv', encoding='gbk')       # 试试这个
df = pd.read_csv('data.csv', encoding='gb18030')   # 还不行试这个（gbk 的超集）
```

**根治办法**：用 VSCode 把文件另存为 UTF-8，以后就不会再遇到。

## 坑三：数字列读成了文字

这是最隐蔽的坑。**文件里看着是数字，读进来却是 object 类型**：

```
价格
"1,299"
89
```

```python
df = pd.read_csv('price.csv')
print(df['价格'].dtype)      # object ← 明明是数字！
print(df['价格'].tolist())   # ['1,299', '89']
```

**原因**：`1,299` 里有千分位逗号，pandas 无法把它解析成数字，于是整列退回 object。

**两种解法**：

```python
# 方法一：读的时候就处理
df = pd.read_csv('price.csv', thousands=',')
print(df['价格'].dtype)      # int64 ✓

# 方法二：读进来再转
df['价格'] = pd.to_numeric(df['价格'].str.replace(',', ''), errors='coerce')
```

**还有一种是混入了占位文字**：

```
价格
199
暂无
89
```

```python
df = pd.read_csv('price2.csv')
print(df['价格'].dtype)      # object（因为"暂无"）

# 解法一：告诉 pandas 哪些算缺失
df = pd.read_csv('price2.csv', na_values=['暂无'])
print(df['价格'].dtype)      # float64 ✓，'暂无' 变成 NaN

# 解法二：强制转换，转不动的变 NaN
df['价格'] = pd.to_numeric(df['价格'], errors='coerce')
```

**`to_numeric(..., errors='coerce')` 是万能转换**——凡是转不成数字的都变成 NaN，之后按缺失值处理。

> 💡 **`info()` 是发现这个问题的唯一可靠手段**：看到本该是数字的列显示成 object，立刻去 `head()` 看看里面混了什么。

## 坑四：列数不一致

```
ParserError: Expected 3 fields in line 2, saw 2
```

某一行字段数不对。常见原因：

- 某个字段里本身就含逗号（没加引号）
- 文件末尾有残缺行
- 引号没配对

**排查**：先当纯文本看一眼

```python
with open('data.csv', encoding='utf-8') as f:
    for i, line in enumerate(f):
        if i >= 5: break
        print(repr(line))
```

## 大文件的试读技巧

几百万行的 CSV，别直接全读进来：

```python
# 先只读 1000 行看看结构
df = pd.read_csv('huge.csv', nrows=1000)
print(df.info())

# 确认没问题再读全部
df = pd.read_csv('huge.csv')
```

**`nrows` 是处理大文件的救命参数**。

还可以只讀需要的列，省内存：

```python
df = pd.read_csv('huge.csv', usecols=['日期', '金额', '城市'])
```

## 用某一列当索引

```python
df = pd.read_csv('data.csv', index_col='姓名')
print(df.index)          # Index(['张三', '李四', ...])
print(df.loc['张三'])    # 直接按姓名取行
```

**如果这一列适合当"标识"（订单号、城市名、日期），用 `index_col` 会方便很多。**

## 写出 CSV

```python
df.to_csv('out.csv', index=False)      # index=False 很关键
df.to_csv('out.csv', index=False, encoding='utf-8-sig')   # 给 Excel 看用这个
```

**两个要点**：

1. **`index=False`** —— 否则会把行索引也写进去，多出一列无名数字
2. **`encoding='utf-8-sig'`** —— 带 BOM，Excel 打开中文才不乱码

## 完整流程

```python
import pandas as pd

# 1. 先试读，看结构
df = pd.read_csv('sales.csv', nrows=100, encoding='utf-8')
print(df.info())

# 2. 发现问题（比如金额是 object）后，带上参数正式读
df = pd.read_csv('sales.csv',
                 encoding='utf-8',
                 thousands=',',
                 na_values=['暂无', '-'],
                 parse_dates=['日期'])

# 3. 再检查一遍
print(df.info())
print(df.isna().sum())
```

处理千分位逗号。

  # pd.read_csv('p.csv', thousands=',') 会把 1,299 解析成 1299
  # 打印 dtype，应该是 int64 而不是 object
  
  print("在这里改")
tests:
- assert "int64" in __out
hint: print(pd.read_csv('p.csv', thousands=',').dtypes['价格'])。thousands=',' 告诉 pandas 逗号是千分位分隔符而不是小数或字段分隔。
explain: 这是"数字列读成文字"最常见的成因：千分位逗号让 pandas 无法解析，整列退回 object，后续所有计算都会失败或报错。读的时候加 thousands=',' 一次解决。
