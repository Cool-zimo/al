# melt：把宽表熔成长表

> 为什么同一个数据要"转格式"？因为画图和分组都爱长表。melt 就是把"横着排的指标"立起来的工具。

## 宽表与长表

```python
import pandas as pd

宽表 = pd.DataFrame({
    '门店': ['北京', '上海'],
    '1月': [1200, 900],
    '2月': [1500, 1100],
    '3月': [1300, 1000]
})
```

这种"每个月一列"的表，人眼好看，**但画图、分组都很别扭**。

melt 把它转成"长表"：

```python
长表 = 宽表.melt(id_vars=['门店'], var_name='月份', value_name='销售额')
print(长表)
```

```
   门店  月份  销售额
0  北京   1月  1200
1  上海   1月   900
2  北京   2月  1500
3  上海   2月  1100
4  北京   3月  1300
5  上海   3月  1000
```

**6 行，3 列**。月份从"列名"变成了"值"，销售额从"多列"变成了"一列"。

## 三个参数

```python
df.melt(id_vars=[主键], var_name='新列名', value_name='新值列名')
```

| 参数 | 作用 |
|---|---|
| `id_vars` | 不动的列（主键、标识列） |
| `var_name` | 原来的列名变成这一列的名字 |
| `value_name` | 原来的值变成这一列的名字 |

**长表的好处**：可以直接 `groupby('月份')` 算季度趋势，可以直接传给绘图函数。宽表做不到这些。

## 翻车现场：忘了 id_vars，数据全被融化

```python
# WRONG
print(宽表.melt())
```

```
  variable value
0       门店    北京
1       门店    上海
2       1月  1200
3       1月   900
4       2月  1500
5       2月  1100
6       3月  1300
7       3月  1000
```

**门店也变成了"变量名"的一种**，"北京""上海"混进了月份列。数据没丢，但完全没法用。

**`id_vars` 必须写清楚**——它是"我不想动的那些列"。

## value_vars：只融化一部分列

```python
混合表 = pd.DataFrame({
    '门店': ['北京', '上海'],
    '1月': [1200, 900],
    '2月': [1500, 1100],
    '经理': ['张三', '李四']
})

# 只融化月份列，保留 经理
print(混合表.melt(id_vars=['门店', '经理'], value_vars=['1月', '2月'],
                  var_name='月份', value_name='销售额'))
```

```
   门店  经理  月份  销售额
0  北京  张三   1月  1200
1  上海  李四   1月   900
2  北京  张三   2月  1500
3  上海  李四   2月  1100
```

**`value_vars` 指定要融的列**，`id_vars` 指定不动的列，两者互补。不写 `value_vars` 就默认融化"除了 id_vars 之外的所有列"。

## melt 与 groupby 配合

长表最大的价值是**能分组**：

```python
print(长表.groupby('月份')['销售额'].mean())
```

```
月份
1月    1050
2月    1300
3月    1150
Name: 销售额, dtype: int64
```

**宽表想算"每个月全国均值"要写三行**（`df['1月'].mean()` 重复三次）。长表一行搞定。

## 反向操作：pivot

长表能转回宽表：

```python
print(长表.pivot(index='门店', columns='月份', values='销售额'))
```

```
月份   1月    2月    3月
门店
北京   1200  1500  1300
上海    900  1100  1000
```

**这正是第 25 课要讲的内容**。

## 翻车现场：melt 后 dtype 可能变

```python
数值宽表 = pd.DataFrame({
    '门店': ['北京', '上海'],
    'Q1': [100, 200],
    'Q2': [150, 250]
})
r = 数值宽表.melt(id_vars=['门店'], var_name='季度', value_name='销售额')
print(r.dtypes)
```

```
门店       object
季度      object
销售额      int64
dtype: object
```

**值列的 dtype 被保留**（int64），这没问题。但要小心的是：如果两列类型不一致，pandas 会做**向上兼容**的统一。比如一列 int 一列 str，结果全是 object。

## 小结

- **melt 把宽表变长表**：月份从列名变成值
- **`id_vars` 是必写项**：指定哪些列保持不动
- **`value_vars`** 指定融化哪些列，不写就默认融化剩余所有列
- **长表是分组和画图的最佳形态**
- **pivot 是 melt 的反向操作**
