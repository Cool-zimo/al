# 多级索引与重排

> 多键分组会产生"两层索引"。这一课讲怎么对付它——这是很多人卡住的地方。

## 先看长什么样

```python
import pandas as pd

df = pd.DataFrame({
    '城市': ['北京', '上海', '北京', '上海', '广州'],
    '类别': ['外设', '外设', '显示', '显示', '外设'],
    '销售额': [100, 200, 150, 300, 90]
})

r = df.groupby(['城市', '类别'])['销售额'].sum()
print(r)
```

```
城市  类别
上海  外设    200
     显示    300
北京  外设    100
     显示    150
广州  外设     90
Name: 销售额, dtype: int64
```

**注意"上海"只在第一行显示一次，第二行是空白**——这是 pandas 的显示优化，表示"同上"。**不是缺失值**。

```python
print(r.index)
# MultiIndex([('上海', '外设'), ('上海', '显示'), ('北京', '外设'), ...])
```

## 取值的两种方式

```python
# 方式一：用元组
print(r[('上海', '显示')])       # 300

# 方式二：分层取（推荐，更清晰）
print(r['上海'])                 # 上海下的所有类别
print(r['上海']['显示'])         # 300
```

**先取外层，再取内层**，像剥洋葱一样。

## 变回普通表格：reset_index

```python
print(r.reset_index())
```

```
   城市  类别  销售额
0  上海  外设   200
1  上海  显示   300
2  北京  外设   100
3  北京  显示   150
4  广州  外设    90
```

**`reset_index()` 把索引层变成普通列**——这是最常用的"扁平化"手段。

> ⚠️ 如果之后还要写文件或合并，几乎都要先 `reset_index()`。带 MultiIndex 的表导出后很难读。

## 交换层级：swaplevel

```python
print(r.swaplevel())
```

```
类别  城市
外设  上海    200
显示  上海    300
外设  北京    100
显示  北京    150
外设  广州     90
```

**外层变内层、内层变外层**。

## 按某一层排序：sort_index

```python
print(r.sort_index(level='城市'))
```

也可以直接在分组时就指定顺序：

```python
df.groupby(['城市', '类别'], sort=True)['销售额'].sum()
```

## unstack：把内层索引变成列

**这是最有用的一个**——它能把"长表"变成"宽表"：

```python
print(r.unstack())
```

```
类别     外设    显示
城市
上海   200.0  300.0
北京   100.0  150.0
广州    90.0    NaN
```

**内层的"类别"变成了列，外层"城市"还是行**。

**注意"广州-显示"是 NaN**——因为原始数据里广州没有显示类的销售。这是真实情况，不是 bug。

用 `fill_value=0` 可以填满：

```python
print(r.unstack(fill_value=0))
```

```
类别   外设   显示
城市
上海   200   300
北京   100   150
广州    90     0
```

## stack：反过来，把列变回索引

```python
wide = r.unstack()
print(wide.stack())
```

**`unstack` 和 `stack` 互为逆操作**。

| 操作 | 效果 |
|---|---|
| `unstack()` | 内层索引 → 列（长变宽） |
| `stack()` | 列 → 内层索引（宽变长） |

## 什么时候用哪个

**长表（long）**：每行一个观测，分组键在列里

```
城市  类别  销售额
上海  外设    200
上海  显示    300
```

**宽表（wide）**：一个维度变成列头

```
类别   外设   显示
城市
上海   200   300
```

| 场景 | 适合 |
|---|---|
| 继续做分析、筛选、分组 | **长表** |
| 给人看、做报表、画图 | **宽表** |

**pandas 的大多数操作喜欢长表**，`unstack` 通常是最后一步（为了展示）。

## 只看某一层：xs

```python
print(r.xs('外设', level='类别'))
```

```
城市
上海    200
北京    100
广州     90
```

**`xs` 按某一层的某个值横切一刀**，取出所有城市的外设数据。

## 给层级命名

```python
r.index.names = ['city', 'category']
print(r.index.names)      # ['city', 'category']
```

分组时也可以直接命名：

```python
df.groupby(['城市', '类别']).agg(总额=('销售额','sum'), 笔数=('销售额','count'))
```

## 实战：一份分层报表

```python
import pandas as pd

df = pd.DataFrame({
    '城市': ['北京', '上海', '北京', '上海', '广州', '广州'],
    '类别': ['外设', '外设', '显示', '显示', '外设', '音频'],
    '销售额': [100, 200, 150, 300, 90, 120]
})

# 1. 多键分组
r = df.groupby(['城市', '类别'])['销售额'].sum()

print("=== 长表 ===")
print(r)

print("\n=== 宽表（unstack）===")
print(r.unstack(fill_value=0))

print("\n=== 扁平化 ===")
flat = r.reset_index()
print(flat)

print("\n=== 只看外设 ===")
print(r.xs('外设', level='类别'))
```

## 小结

| 需求 | 写法 |
|---|---|
| 变回普通表 | `.reset_index()` |
| 交换层级 | `.swaplevel()` |
| 按层排序 | `.sort_index(level='名')` |
| 长变宽 | `.unstack(fill_value=0)` |
| 宽变长 | `.stack()` |
| 横切一层 | `.xs('值', level='层名')` |
| 分层取值 | `r['外层']['内层']` |
