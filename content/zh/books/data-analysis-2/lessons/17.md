# transform 与 filter

> groupby 的结果通常比原表"短"（每组一行）。但有时你想让结果和原表一样长——这就是 transform。

## 问题的由来

```python
import pandas as pd

df = pd.DataFrame({
    '城市': ['北京', '上海', '北京', '上海', '广州'],
    '销售额': [100, 200, 150, 300, 90]
})

# 分组求和 → 3 行
print(df.groupby('城市')['销售额'].sum())
```

```
城市
上海    500
北京    250
广州    90
```

**但如果你想在原表上加一列"这个城市的总额"呢？** 需要的是 5 行，不是 3 行。

## transform：结果和原表一样长

```python
df['城市总额'] = df.groupby('城市')['销售额'].transform('sum')
print(df)
```

```
   城市  销售额  城市总额
0  北京    100   250
1  上海    200   500
2  北京    150   250
3  上海    300   500
4  广州     90    90
```

**`transform` 把聚合结果"广播"回每一行**——同组的每行都拿到同一个值。

**对比一下**：

| | 结果行数 | 用途 |
|---|---|---|
| `groupby().sum()` | 每组一行（3 行） | 要看汇总 |
| `groupby().transform('sum')` | 和原表一样（5 行） | 要给原表加列 |

## 经典用法：算占比

```python
df['城市总额'] = df.groupby('城市')['销售额'].transform('sum')
df['占比'] = (df['销售额'] / df['城市总额'] * 100).round(1)
print(df)
```

```
   城市  销售额  城市总额    占比
0  北京    100   250  40.0
1  上海    200   500  40.0
2  北京    150   250  60.0
3  上海    300   500  60.0
4  广州     90    90 100.0
```

**"每一行占它所在组的百分比"**——这在报表里极其常见，用 transform 一行就搞定。

## 另一个经典用法：和组均值比较

```python
df['城市均值'] = df.groupby('城市')['销售额'].transform('mean')
df['高于均值'] = df['销售额'] > df['城市均值']
print(df)
```

**"这笔订单高于还是低于所在城市的平均水平"**——也是 transform 的典型场景。

还可以算"离均值差多少"：

```python
df['差值'] = df['销售额'] - df.groupby('城市')['销售额'].transform('mean')
```

## transform 能接什么

```python
df.groupby('城市')['销售额'].transform('sum')      # 字符串形式
df.groupby('城市')['销售额'].transform(sum)         # 函数形式
df.groupby('城市')['销售额'].transform('mean')
df.groupby('城市')['销售额'].transform(lambda x: x.max() - x.min())   # 自定义
```

**常用的都支持**。自定义函数收到的 `x` 是这一组的 Series。

## filter：按组的性质筛掉整组

**transform 是"给每行加列"，filter 是"整组保留或删掉"。**

```python
# 只保留"总销售额 > 200"的城市（整组保留）
result = df.groupby('城市').filter(lambda g: g['销售额'].sum() > 200)
print(result)
```

```
   城市  销售额  城市总额    占比
1  上海    200   500  40.0
3  上海    300   500  60.0
```

**注意：filter 里收到的 `g` 是一个子 DataFrame**（这一组的完整行），你要返回 True 或 False 决定整组去留。

```python
# 保留"至少有 2 笔订单"的城市
df.groupby('城市').filter(lambda g: len(g) >= 2)

# 保留"平均销售额 > 100"的城市
df.groupby('城市').filter(lambda g: g['销售额'].mean() > 100)
```

## 对比三个动作

| 方法 | 返回 | 行数 | 典型用途 |
|---|---|---|---|
| `.sum()` / `.agg()` | 每组一个值 | **变短** | 做汇总报表 |
| `.transform()` | 每行的值 | **不变** | 给原表加"组级别"的列 |
| `.filter()` | 原表的子集 | **变短**（整组） | 按组性质筛选 |

**记忆口诀**：
- 想**看**汇总 → 直接聚合
- 想**加**一列 → transform
- 想**筛**掉组 → filter

## 实战：给销售表加分析列

```python
import pandas as pd

df = pd.DataFrame({
    '城市': ['北京', '上海', '北京', '上海', '广州', '广州'],
    '类别': ['外设', '外设', '显示', '显示', '外设', '音频'],
    '销售额': [100, 200, 150, 300, 90, 120]
})

# 1. 每个城市的总额（transform 保持行数）
df['城市总额'] = df.groupby('城市')['销售额'].transform('sum')

# 2. 每行占城市的比例
df['城市占比'] = (df['销售额'] / df['城市总额'] * 100).round(1)

# 3. 每个类别的均值
df['类别均值'] = df.groupby('类别')['销售额'].transform('mean')

# 4. 是否高于所在城市均值
df['高于均值'] = df['销售额'] > df.groupby('城市')['销售额'].transform('mean')

print(df)
print()
print("各城市汇总：")
print(df.groupby('城市')['销售额'].agg(['sum', 'mean', 'count']))
```

**一次操作同时得到了"明细 + 组级指标"**，这就是 transform 的价值。
