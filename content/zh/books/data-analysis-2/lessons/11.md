# 认识 NaN 与 None

> 真实数据永远有缺口。这一课讲清 pandas 里"空"到底是什么——它有个反直觉的性质，不知道会写出静默出错的代码。

## 先看一个反直觉的事实

```python
import numpy as np

print(np.nan == np.nan)      # False  ← 自己不等于自己！
print(np.nan is np.nan)      # True
```

**NaN（Not a Number）不等于任何东西，包括它自己。**

这是 IEEE 754 浮点标准的定义。所以**永远不要用 `==` 判断缺失**：

```python
# ❌ 永远是 False，一个都找不到
df[df['成绩'] == np.nan]

# ✅ 正确
df[df['成绩'].isna()]
```

## pandas 里的两种"空"

| | 是什么 | 出现在哪 |
|---|---|---|
| **`NaN`** | 浮点里的"不是数" | 数值列 |
| **`None`** | Python 的空对象 | 文字列 |

```python
import pandas as pd
import numpy as np

s = pd.Series([1, np.nan, None])
print(s)
print(s.dtype)          # float64
print(s.tolist())       # [1.0, nan, nan]
```

**注意：放进数值 Series 后，`None` 会被自动转成 `NaN`**。pandas 为了保持一列一种类型，把它们统一了。

```python
s2 = pd.Series(['x', None])
print(s2.dtype)         # object
print(s2.tolist())      # ['x', None]  ← 文字列里 None 保持原样
```

## 统一用 isna / notna

**别管是 NaN 还是 None，`isna()` 都能抓出来**：

```python
print(s.isna())         # [False, True, True]
print(s.notna())        # [True, False, False]
```

| 需求 | 写法 |
|---|---|
| 这一列有没有空 | `df['列'].isna().any()` |
| 有几个空 | `df['列'].isna().sum()` |
| 每列各几个空 | `df.isna().sum()` |
| 全表共几个空 | `df.isna().sum().sum()` |
| 缺失占比 | `df.isna().mean()` |
| 挑出有空的行 | `df[df['列'].isna()]` |
| 挑出没空的行 | `df[df['列'].notna()]` |

**别用 `isnull` / `notnull`**——它们是 `isna` / `notna` 的别名，功能一样，但 `isna` 是更现代的写法。

## 空是怎么来的

三种常见来源：

```python
# 1. 读文件时 pandas 自动识别（空单元格、NA、N/A、null 等）
df = pd.read_csv('data.csv')        # 空单元格 → NaN

# 2. 运算产生
df['人均'] = df['总额'] / df['人数']      # 除零 → inf，不是 NaN
df['人均'] = df['总额'] / df['人数'].replace(0, np.nan)   # 0 改 NaN 再除

# 3. 对齐不上产生（第 1 课讲过）
a = pd.Series([1,2,3], index=['x','y','z'])
b = pd.Series([10,20], index=['x','y'])
print((a + b)['z'])     # nan ← 标签对不上
```

**"对齐不上产生 NaN"是最隐蔽的一种**，因为它不报错，只是默默产生空值。

## 一个重要的副作用：整数列会变浮点

```python
d = pd.DataFrame({'数量': [1, 2, np.nan]})
print(d['数量'].dtype)      # float64  ← 不是 int64！
print(d['数量'].tolist())   # [1.0, 2.0, nan]
```

**只要一列里混进 NaN，整数列就会被强制变成 float64**（因为 NaN 只能用浮点表示）。

后果：

```python
# ❌ 会报错：Cannot convert non-finite values (NA or inf) to integer
d['数量'].astype(int)

# ✅ 先填补再转
d['数量'].fillna(0).astype(int)

# ✅ 或者用可空整数类型（保留 NaN）
d['数量'].astype('Int64')     # 注意大写 I
```

**`Int64`（大写 I）是 pandas 的"可空整数类型"**，能同时存整数和缺失。第 13 课会详细讲。

## pandas 的统计函数默认跳过空

```python
s = pd.Series([1, np.nan, 3])
print(s.sum())      # 4.0   ← 跳过 NaN
print(s.mean())     # 2.0   ← 分母是 2 不是 3
```

**这和 NumPy 不一样**：

```python
import numpy as np
print(np.sum([1, np.nan, 3]))     # nan ！
```

NumPy 需要 `np.nansum()` / `np.nanmean()`，pandas 直接就跳过。**这是 pandas 省心的地方**，但也意味着：

> ⚠️ **你要留意"跳过"这件事本身**。如果一列 90% 是空，均值是基于剩下 10% 算的——数字看着正常，代表性却很差。**先查缺失比例，再看统计量。**

```python
print(df['列'].isna().mean())      # 缺失占比
print(df['列'].count())            # 非空数量（比 len() 更可信）
```

## 综合例子

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    '姓名': ['张三', '李四', '王五', '赵六'],
    '语文': [80, 95, np.nan, 70],
    '数学': [90, np.nan, 85, 75],
    '英语': [85, 88, np.nan, 92]
})

print("=== 每列缺失 ===")
print(df.isna().sum())

print("\n=== 缺失占比 ===")
print((df.isna().mean() * 100).round(1))

print("\n=== 有缺失的行 ===")
print(df[df.isna().any(axis=1)])

print("\n=== 各科平均分（自动跳过空）===")
print(df[['语文','数学','英语']].mean())
```

**`df.isna().any(axis=1)`** 是挑出"任何一列有空"的行的标准写法——`axis=1` 表示横跨列检查。

## 小结

- **NaN 不等于自己**，判断缺失只能用 `isna()` / `notna()`
- **None 进数值列会变 NaN**，pandas 统一成一列一种类型
- **整数列混进 NaN 会变 float64**，转 int 前要先填补或用 `Int64`
- **统计函数默认跳过空**——先查缺失比例再看统计量
- 缺失三大来源：读文件、运算、标签对不上
