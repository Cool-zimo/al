# 分组：groupby 的拆分-应用-合并

> 前三章都在"准备数据"。这一章开始真正问问题——而问问题的核心动作就是 groupby。

## 从一个问题开始

有一张销售表，你想知道：**每个城市各卖了多少？**

```python
import pandas as pd

df = pd.DataFrame({
    '城市': ['北京', '上海', '北京', '上海', '广州'],
    '类别': ['外设', '外设', '显示', '显示', '外设'],
    '销售额': [100, 200, 150, 300, 90]
})
```

不用 groupby 你得手动筛每个城市再求和。**有了 groupby 只要一行**：

```python
print(df.groupby('城市')['销售额'].sum())
```

```
城市
上海    500
北京    250
广州     90
Name: 销售额, dtype: int64
```

## 拆开看这三个动作

**groupby 的全称是 split-apply-combine（拆分-应用-合并）**：

```
原始数据                拆分                 应用              合并
┌──────────┐      ┌──────────┐      ┌──────────┐    ┌──────────┐
│ 北京 100 │      │ 北京 100 │      │ 北京 250 │    │ 北京 250 │
│ 上海 200 │  →   │ 北京 150 │  →   │ 上海 500 │ →  │ 上海 500 │
│ 北京 150 │      ├──────────┤      │ 广州  90 │    │ 广州  90 │
│ 上海 300 │      │ 上海 200 │      └──────────┘    └──────────┘
│ 广州  90 │      │ 上海 300 │
└──────────┘      ├──────────┤
                  │ 广州  90 │
                  └──────────┘
   split             apply sum          combine
```

1. **split**：按"城市"这列的值把行分成几堆
2. **apply**：对每一堆做同一个运算（这里是 sum）
3. **combine**：把每堆的结果拼成一张新表

**理解这个三步，后面所有 groupby 的变体都只是在换第 2 步做什么。**

## 语法：两段式

```python
df.groupby('分组依据')['要算的列'].聚合函数()
   └─────┬─────┘ └───┬───┘ └───┬───┘
      按什么分     算哪一列    怎么算
```

**最容易忘的是中间那一步**——不写列名会对所有能算的列都算一遍：

```python
# ✅ 只算销售额
df.groupby('城市')['销售额'].sum()

# 所有数值列都算（城市被当成分组键自动排除）
df.groupby('城市').sum()
```

> 💡 **养成写列名的习惯**。不写的话，万一表里有别的价格列也会被算进去。

## 常用聚合函数

```python
g = df.groupby('城市')['销售额']

print(g.sum())        # 求和
print(g.mean())       # 平均
print(g.max())        # 最大
print(g.min())        # 最小
print(g.count())      # 非空个数
print(g.size())       # 行数（含空）
print(g.std())        # 标准差
print(g.nunique())    # 去重后有几个不同值
```

**`count()` 和 `size()` 的区别**：

| | 统计什么 | 是否含空值 |
|---|---|---|
| `count()` | 非空的个数 | **不含** NaN |
| `size()` | 这一组共几行 | 含 |

数据没缺失时两者相同。**有缺失时 `count()` 会更小**——这正是"这组有多少有效数据"的答案。

## 一次算多个：agg

```python
print(df.groupby('城市')['销售额'].agg(['sum', 'mean', 'max', 'count']))
```

```
      sum   mean   max  count
城市
上海   500  250.0   300      2
北京   250  125.0   150      2
广州    90   90.0    90      1
```

**`agg` 接收一个列表**，一次性算出多个统计量，结果是一张表（每列一个统计量）。

## 按多个键分组

```python
print(df.groupby(['城市', '类别'])['销售额'].sum())
```

```
城市  类别
上海  外设    200
     显示    300
北京  外设    100
     显示    150
广州  外设     90
Name: 销售额, dtype: int64
```

**传列表就是多键分组**。结果有两层索引（MultiIndex）。

想把它变成普通表格：

```python
print(df.groupby(['城市', '类别'])['销售额'].sum().reset_index())
```

```
   城市  类别  销售额
0  上海  外设   200
1  上海  显示   300
2  北京  外设   100
3  北京  显示   150
4  广州  外设    90
```

## 分组键会变成索引

```python
result = df.groupby('城市')['销售额'].sum()
print(result.index)          # Index(['上海', '北京', '广州'])
print(result['北京'])        # 250 —— 可以直接按名字取
```

**默认分组键会变成结果的行索引**。这通常很方便（按名字取值）。

如果你不想要索引，用 `as_index=False`：

```python
print(df.groupby('城市', as_index=False)['销售额'].sum())
```

```
   城市  销售额
0  上海   500
1  北京   250
2  广州    90
```

**`as_index=False` 让分组键保持为一列**。后续还要继续处理（比如再筛选、再合并）时用这个更顺手。

## 结果排序

```python
# 按销售额从高到低
print(df.groupby('城市')['销售额'].sum().sort_values(ascending=False))
```

**注意排序的是聚合后的值**（销售额），不是城市名。groupby 默认按分组键排序。

## 看看每组有多少行

```python
print(df.groupby('城市').size())
```

这是最常用的"先看一眼"操作——**知道每组多大，才知道后面的均值可不可信**。

## 小结

- **groupby 三步**：拆分 → 应用 → 合并
- **语法两段式**：`groupby(按什么分)[算哪列].怎么算`
- **`count()` 不含空、`size()` 含空**
- **分组键默认变成索引**，`as_index=False` 可保持为列
- **多键分组传列表**，结果有两层索引
