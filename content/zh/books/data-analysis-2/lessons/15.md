# 字符串列处理

> 文字列不能用 Python 的字符串方法直接调——要用 `.str` 访问器。这一课讲清洗脏文本。

## 为什么需要 .str

```python
import pandas as pd

s = pd.Series(['苹果', '香蕉', '橙子'])

# ❌ 这样不行（Series 没有 upper 方法）
s.upper()

# ✅ 要加 .str
print(s.str.upper())
```

**`.str` 是 pandas 给文字列开的"专用通道"**，里面的方法名和 Python 字符串的完全一样。

## 最常用的几个

```python
s = pd.Series([' 苹果 ', '香蕉 ', '  橙子'])

print(s.str.strip())          # 去首尾空格 → ['苹果','香蕉','橙子']
print(s.str.upper())          # 转大写
print(s.str.lower())          # 转小写
print(s.str.len())            # 长度 → [4, 3, 4]
print(s.str.contains('苹'))   # 是否包含 → [True, False, False]
print(s.str.replace(' ', '_'))# 替换
```

> ⚠️ **注意 `len()` 的结果**：`' 苹果 '` 长度是 4（含两个空格），所以**清洗顺序很重要——先 strip 再算长度**。

## 清洗脏金额：完整流程

这是真实数据里最常见的场景：

```python
m = pd.Series(['¥1,299', '¥89', '暂无', '2,000元'])

# 1. 去掉货币符号
m1 = m.str.replace('¥', '').str.replace('元', '')
print(m1.tolist())        # ['1,299', '89', '暂无', '2,000']

# 2. 去掉千分位逗号
m2 = m1.str.replace(',', '')
print(m2.tolist())        # ['1299', '89', '暂无', '2000']

# 3. 转数字，转不动的变 NaN
nums = pd.to_numeric(m2, errors='coerce')
print(nums.tolist())      # [1299.0, 89.0, nan, 2000.0]
```

**三步：去符号 → 去逗号 → 转数字。**

## 拆分：split

```python
s = pd.Series(['北京-朝阳区', '上海-浦东', '广州-天河'])

print(s.str.split('-'))
```

```
0    [北京, 朝阳区]
1    [上海, 浦东]
2    [广州, 天河]
dtype: object
```

**拆成列表后，用 `.str[0]` 取第一段**（注意要再接一次 `.str`）：

```python
print(s.str.split('-').str[0])     # 城市
print(s.str.split('-').str[1])     # 区域
```

**想直接拆成两列**，加 `expand=True`：

```python
df = s.str.split('-', expand=True)
df.columns = ['城市', '区域']
print(df)
```

```
   城市   区域
0  北京  朝阳区
1  上海   浦东
2  广州   天河
```

**`expand=True` 直接得到 DataFrame**，非常实用。

## 提取：extract（正则）

```python
s = pd.Series(['订单A001', '订单B002', '订单C003'])
print(s.str.extract(r'(\d+)'))      # 提取数字部分
```

**`extract` 用正则提取**，括号里是要捕获的部分。第 1 章没讲正则，这里知道有这个功能就行。

## 筛选：contains 配合布尔索引

```python
df = pd.DataFrame({
    '商品': ['苹果手机', '苹果电脑', '香蕉', '苹果汁'],
    '价格': [5999, 9999, 5, 12]
})

# 找出商品名含"苹果"的
print(df[df['商品'].str.contains('苹果')])
```

**`str.contains()` 返回布尔 Series，可以直接当筛子用**。

```python
# 不包含（取反）
print(df[~df['商品'].str.contains('苹果')])

# 开头 / 结尾
print(df[df['商品'].str.startswith('苹果')])
print(df[df['商品'].str.endswith('汁')])
```

## 空值的坑

**`.str` 方法遇到 NaN 会返回 NaN，不会报错**：

```python
s = pd.Series(['苹果', None, '橙子'])
print(s.str.upper())
```

```
0      苹果
1     None    ← 保持缺失
2      橙子
dtype: object
```

但 **`contains` 遇到 NaN 会返回 NaN 而不是 True/False**，放进布尔索引会出问题：

```python
# ❌ NaN 混进布尔 Series，筛选会报错或得到意外结果
df[df['列'].str.contains('x')]

# ✅ 加 na=False
df[df['列'].str.contains('x', na=False)]
```

> 💡 **`na=False` 是防御性写法**，文字列可能有空时都加上它。

## 实战：清洗一份用户表

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    '姓名': [' 张三 ', '李四', ' 王五  '],
    '手机': ['138-0013-8000', '13900138001', '137-0013-7000'],
    '消费': ['¥1,299', '¥89', '¥2,000']
})

print("=== 清洗前 ===")
print(df)

# 1. 姓名去空格
df['姓名'] = df['姓名'].str.strip()

# 2. 手机号统一去掉横线
df['手机'] = df['手机'].str.replace('-', '')

# 3. 消费金额转数字
df['消费'] = pd.to_numeric(
    df['消费'].str.replace('¥', '').str.replace(',', ''),
    errors='coerce'
)

print("\n=== 清洗后 ===")
print(df)
print("\n类型：")
print(df.dtypes)
print("\n消费总额：", df['消费'].sum())
```

## 速查

| 需求 | 写法 |
|---|---|
| 去空格 | `.str.strip()` |
| 大小写 | `.str.upper()` / `.str.lower()` |
| 长度 | `.str.len()` |
| 包含 | `.str.contains('x', na=False)` |
| 开头/结尾 | `.str.startswith('x')` / `.str.endswith('x')` |
| 替换 | `.str.replace('旧','新')` |
| 拆分（成列表） | `.str.split('-')` |
| 拆分（成多列） | `.str.split('-', expand=True)` |
| 取第 N 段 | `.str.split('-').str[N]` |
| 正则提取 | `.str.extract(r'(\d+)')` |
