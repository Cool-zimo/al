# 删除还是填补

> 发现缺失之后，第一个决策是：这行还要不要？这一课讲 dropna 和 fillna 的用法与取舍。

## 两条路

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    '姓名': ['张三', '李四', '王五', '赵六'],
    '语文': [80, 95, np.nan, 70],
    '数学': [90, np.nan, 85, 75],
    '英语': [85, 88, np.nan, 92]
})

# 路一：删掉有缺失的行
print(df.dropna())

# 路二：填补
print(df.fillna(0))
```

**选哪条？** 看缺失比例和这一列重不重要。

## dropna：删

### 默认：删掉任何一列有空的行

```python
print(df.dropna())          # 只剩"赵六"这一行
print(len(df), '→', len(df.dropna()))
```

**默认很激进**——只要有一个空就整行删掉。数据量大时这通常是对的，但**数据量小时可能把表删空了**。

### how='all'：全空才删

```python
print(df.dropna(how='all'))     # 只有"整行全是空"才删
```

### thresh：至少要有 N 个非空

```python
print(df.dropna(thresh=3))      # 至少 3 个非空值才保留
```

**`thresh` 比 `how` 更灵活**——"这行至少要有 N 个有效数据我才要"。

### subset：只看指定的列

```python
# 只看"语文"，语文不空的就保留
print(df.dropna(subset=['语文']))
```

**`subset` 是最常用的参数**——关键列有空才删，其他列空着无所谓。

### axis=1：删列

```python
print(df.dropna(axis=1))        # 删掉有空的列
```

## fillna：填

### 填固定值

```python
print(df['语文'].fillna(0))
```

> ⚠️ **填 0 有风险**。成绩填 0 会把"缺考"和"考了 0 分"混为一谈，拉低平均分。填 0 只适合"空就等于没有"的场景（比如优惠券金额、数量）。

### 填统计量（最常用）

```python
mean = df['语文'].mean()
print(df['语文'].fillna(mean))
```

**填均值适合"数据比较集中、缺失随机"的情况**。也可以填中位数：

```python
print(df['语文'].fillna(df['语文'].median()))
```

**中位数比均值更抗异常值**——如果列里有极端值（比如收入数据），中位数更合适。

### 分组填（更精确）

```python
df['班级'] = ['A', 'A', 'B', 'B']
# 用各自班级的均值填（下一章讲 groupby 后会更清楚）
df['语文'] = df.groupby('班级')['语文'].transform(lambda x: x.fillna(x.mean()))
```

**"用同组的均值填"比"用全表均值填"精确得多**。比如男生女生的身高分开填。

### 前后填：ffill / bfill

```python
s = pd.Series([1, np.nan, np.nan, 4])
print(s.ffill())      # [1, 1, 1, 4]     用前一个值填
print(s.bfill())      # [1, 4, 4, 4]     用后一个值填
```

**适合时间序列**——比如某天的气温缺失，用前一天的值填是合理的。

```python
print(s.fillna(method='ffill'))     # 等价写法
```

### 不同列填不同值

```python
print(df.fillna({'语文': 60, '数学': df['数学'].mean()}))
```

**传字典**，键是列名、值是填什么。

## 怎么选：一张决策表

| 情况 | 建议 |
|---|---|
| 缺失 < 5%，且随机 | **删行**（`dropna()`） |
| 缺失 > 50% 的**列** | **删列**（`dropna(axis=1)`） |
| 数值列，分布集中 | **填均值 / 中位数** |
| 数值列，有异常值 | **填中位数** |
| 分类列（文字） | **填众数**或新增"未知"类别 |
| 时间序列 | **ffill / bfill** |
| 关键列（如订单号）缺失 | **必须删**，不能编 |

> 💡 **核心原则：不要为了让"缺失消失"而填补。** 填补是在猜数据，猜错了会引入偏差。宁可删掉也不要瞎填。

## 别忘了一件事

**这两个函数默认都返回新表**：

```python
df.dropna()                      # 原表没变
df = df.dropna()                 # ✅ 赋值回去
df.dropna(inplace=True)          # ✅ 或就地改
```

## 实战：清洗一张成绩表

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    '姓名': ['张三', '李四', '王五', '赵六', '孙七'],
    '语文': [80, 95, np.nan, 70, np.nan],
    '数学': [90, np.nan, 85, 75, np.nan],
    '英语': [85, 88, np.nan, 92, 90]
})

print("=== 清洗前 ===")
print(df.isna().sum())

# 1. 先看缺失占比
ratio = df[['语文','数学','英语']].isna().mean()
print("\n缺失占比：")
print(ratio)

# 2. 两科都缺的（孙七）→ 信息太少，删掉
df = df.dropna(subset=['语文','数学'], how='all')
print(f"\n删掉两科全缺的行后：{len(df)} 行")

# 3. 剩下的单科缺失 → 用该科中位数填
for col in ['语文','数学','英语']:
    df[col] = df[col].fillna(df[col].median())

print("\n=== 清洗后 ===")
print(df)
print("\n剩余缺失：", df.isna().sum().sum())
```

**这个流程是标准套路**：先看比例 → 缺太多的删 → 缺一点点的填。
