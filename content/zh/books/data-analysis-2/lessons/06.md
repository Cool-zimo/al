# 取列与取行

> 第 1 章说 DataFrame 是"Series 的字典"。这一课讲怎么从这个字典里拿东西——以及一个反直觉的规矩。

## 取一列

```python
import pandas as pd

df = pd.DataFrame({
    '姓名': ['张三', '李四', '王五', '赵六'],
    '年龄': [18, 19, 20, 17],
    '成绩': [89.5, 92.0, 78.0, 95.0]
})

print(df['成绩'])
```

```
0    89.5
1    92.0
2    78.0
3    95.0
Name: 成绩, dtype: float64
```

得到一个 **Series**。也可以用**点号**（但有限制）：

```python
print(df.成绩)      # 和 df['成绩'] 一样
```

> ⚠️ **点号写法只在列名是合法标识符时能用**。列名含空格（如 `'总分 '`）、中文标点，或者和数字/关键字冲突，`df.成绩` 就会失败或报错。**推荐统一用方括号**。

## 取多列：双方括号

```python
print(df[['姓名', '成绩']])
```

```
   姓名    成绩
0  张三  89.5
1  李四  92.0
2  王五  78.0
3  赵六  95.0
```

**里面是一个列表**，所以得到 DataFrame。

> 💡 记法：**单括号取一列（Series），双括号取多列（DataFrame）**。哪怕只取一列，写 `df[['成绩']]` 得到的也是 DataFrame 而不是 Series。

## 取行：两条路

### 路一：切片（按位置）

```python
print(df[0:2])      # 前 2 行
```

```
   姓名  年龄    成绩
0  张三  18  89.5
1  李四  19  92.0
```

**切片是按行的**，和 Python 列表一样**含头不含尾**。

### 路二：loc / iloc（推荐）

```python
print(df.loc[0])      # 按标签取一行
print(df.iloc[0])     # 按位置取一行
```

这两个在索引是 0、1、2 时看起来一样，**但规则完全不同**——下一课详细讲。

## 一个反直觉的规矩

**`df[...]` 里写什么，决定它是取列还是取行：**

| 写法 | 取什么 |
|---|---|
| `df['成绩']` | **列**（列名） |
| `df[['姓名','成绩']]` | **列**（列表） |
| `df[0:2]` | **行**（切片） |
| `df[布尔Series]` | **行**（筛选） |

**验证一下这个坑**：

```python
d = pd.DataFrame({'v': [10, 20, 30]})
print(d.columns)     # ['v']
print(d.index)       # [0, 1, 2]

print(d[0:2])        # ✅ 按行，切片
print(d[1])          # ❌ KeyError: 1
```

**`d[1]` 会报错**，因为方括号优先当成"取名为 1 的列"，而没有叫 1 的列。

> ⚠️ **这就是"想取第 1 行却写了 df[1] 然后报错"的原因。** 取行请用 `df.iloc[1]` 或切片 `df[1:2]`。

反过来，如果**列名本身就是数字**：

```python
d2 = pd.DataFrame({0: ['a', 'b'], 1: ['c', 'd']})
print(d2[0])         # ✅ 取到了名为 0 的列
```

## 取一行会得到什么

```python
row = df.iloc[0]
print(type(row))         # Series
print(row)
```

```
姓名    张三
年龄    18
成绩  89.5
Name: 0, dtype: object
```

**取一行得到的是一个 Series**（原来的一行变成了"索引=列名"的 Series）。

这里有个容易踩的类型陷阱：

```python
# 情况 A：表里混入文字列
row = df.iloc[0]
print(row['年龄'], type(row['年龄']))     # 18  <class 'numpy.int64'>

# 情况 B：表里全是数字列
df2 = df.set_index('姓名')
row2 = df2.loc['张三']
print(row2['年龄'], type(row2['年龄']))   # 18.0  <class 'numpy.float64'>
```

**全是数字列时，取一行会把所有值统一成 float**——整数 18 变成了 18.0。因为一个 Series 只能有一种 dtype。

混入文字列时，dtype 变成 object，**各值反而保持原类型**。

> 💡 **实用建议**：想保持类型就别取"一行"，而是取"一列的某个值"——`df.loc[0, '年龄']` 直接拿到 18（int）。

## 快捷方式：head / tail / sample

```python
print(df.head(2))       # 前 2 行
print(df.tail(2))       # 后 2 行
print(df.sample(2))     # 随机 2 行（每次不一样）
```

**`sample()` 在想随便看看数据时很好用**。

## 小结

| 目的 | 写法 | 得到 |
|---|---|---|
| 一列 | `df['成绩']` | Series |
| 多列 | `df[['姓名','成绩']]` | DataFrame |
| 前 N 行 | `df.head(N)` / `df[0:N]` | DataFrame |
| 一行 | `df.iloc[i]` / `df.loc[标签]` | Series |
| 随机几行 | `df.sample(N)` | DataFrame |

**规矩记住一条**：方括号里**写列名或列表 → 取列**；写**切片或布尔 → 取行**。
