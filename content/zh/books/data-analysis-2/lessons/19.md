# 透视表 pivot_table

> 如果你用过 Excel 的数据透视表，这一课就是它在 pandas 里的样子。没用过也没关系，它本质就是"分组 + 摊成表"。

## 一句话理解

```python
import pandas as pd

df = pd.DataFrame({
    '城市': ['北京', '上海', '北京', '上海', '广州'],
    '类别': ['外设', '外设', '显示', '显示', '外设'],
    '销售额': [100, 200, 150, 300, 90]
})

print(df.pivot_table(index='城市', columns='类别', values='销售额', aggfunc='sum'))
```

```
类别     外设    显示
城市
上海   200.0  300.0
北京   100.0  150.0
广州    90.0    NaN
```

**三个参数对应三个问题**：

| 参数 | 问题 |
|---|---|
| `index` | 什么是**行**？ |
| `columns` | 什么是**列**？ |
| `values` | 格子里**算什么**？ |
| `aggfunc` | 怎么算（默认 mean） |

## 它等价于什么

上面那行代码完全等价于：

```python
df.groupby(['城市', '类别'])['销售额'].sum().unstack()
```

**pivot_table = groupby + unstack 的快捷方式。**

理解这层关系很重要——**碰到 pivot_table 搞不定时，退回 groupby 一步步做，不容易懵**。

## 默认是求平均

```python
# 不写 aggfunc，默认是 mean！
print(df.pivot_table(index='城市', columns='类别', values='销售额'))
```

> ⚠️ **这是个坑**：Excel 的透视表默认求和，pandas 的 pivot_table 默认求平均。
> **想求和必须显式写 `aggfunc='sum'`。**

## 填掉空格：fill_value

```python
print(df.pivot_table(index='城市', columns='类别', values='销售额',
                     aggfunc='sum', fill_value=0))
```

```
类别   外设   显示
城市
上海   200   300
北京   100   150
广州    90     0
```

**"广州-显示"原本是 NaN**（没有这个组合的销售），`fill_value=0` 把它填成 0。

**填不填要看含义**：销售额填 0 合理（没卖出就是 0）；但如果是"平均分"，填 0 就会拉低整体——那种情况留 NaN 更诚实。

## 加小计：margins

```python
print(df.pivot_table(index='城市', columns='类别', values='销售额',
                     aggfunc='sum', fill_value=0, margins=True))
```

```
类别   外设   显示   All
城市
上海   200   300   500
北京   100   150   250
广州    90     0    90
All   390   450   840
```

**`margins=True` 加一行一列"总计"**，列名是 `All`（可以用 `margins_name` 改）。

**做报表给别人看时这个特别有用。**

## 多个 aggfunc

```python
print(df.pivot_table(index='城市', columns='类别', values='销售额',
                     aggfunc=['sum', 'mean']))
```

**传列表会生成多层列**——每种算法一组。

## 多个 values

```python
df2 = df.copy()
df2['数量'] = [1, 2, 3, 4, 5]

print(df2.pivot_table(index='城市', values=['销售额', '数量'], aggfunc='sum'))
```

不指定 `columns` 时，就是"按行分组、多列各自汇总"。

## crosstab：数个数

**pivot_table 算的是数值，crosstab 数的是出现次数。**

```python
print(pd.crosstab(df['城市'], df['类别']))
```

```
类别  外设  显示
城市
上海    1    1
北京    1    1
广州    1    0
```

**这就是"交叉频数表"**——统计每个组合出现了几次。

对比：

| | 算什么 | 格子里的值 |
|---|---|---|
| `pivot_table` | 数值列的聚合 | 销售额、数量… |
| `crosstab` | 出现次数 | 计数 |

```python
# 两者的关系
pd.crosstab(df['城市'], df['类别'])
# 等价于
df.pivot_table(index='城市', columns='类别', aggfunc='size', fill_value=0)
```

**`aggfunc='size'` 就是数行数**。

## 长表与宽表的互相转换

**pivot_table 是"长变宽"**，反过来用 `melt`：

```python
wide = df.pivot_table(index='城市', columns='类别', values='销售额',
                      aggfunc='sum', fill_value=0).reset_index()
print(wide)
```

```
类别  城市   外设   显示
0    上海   200   300
1    北京   100   150
2    广州    90     0
```

变回长表：

```python
long = wide.melt(id_vars='城市', var_name='类别', value_name='销售额')
print(long)
```

```
   城市  类别  销售额
0  上海  外设   200
1  北京  外设   100
2  广州  外设    90
3  上海  显示   300
4  北京  显示   150
5  广州  显示     0
```

**`melt` 的参数**：
- `id_vars`：保持不变的列（作为标识）
- `var_name`：原来的列名变成新列的列名
- `value_name`：原来的值变成新列的列名

## 什么时候用透视表

| 场景 | 工具 |
|---|---|
| 算销售额、平均值等数值 | `pivot_table` |
| 数出现次数 | `crosstab` |
| 长表变宽表 | `pivot_table` / `unstack` |
| 宽表变长表 | `melt` |

## 实战：一份销售透视报表

```python
import pandas as pd

df = pd.DataFrame({
    '城市': ['北京', '上海', '北京', '上海', '广州', '广州'],
    '类别': ['外设', '外设', '显示', '显示', '外设', '音频'],
    '销售额': [100, 200, 150, 300, 90, 120]
})

print("=== 透视表（含总计）===")
print(df.pivot_table(index='城市', columns='类别', values='销售额',
                     aggfunc='sum', fill_value=0, margins=True,
                     margins_name='合计'))

print("\n=== 各组合出现次数 ===")
print(pd.crosstab(df['城市'], df['类别']))

print("\n=== 城市汇总排序 ===")
print(df.groupby('城市')['销售额'].sum().sort_values(ascending=False))
```

## 小结

- **pivot_table = groupby + unstack**
- **默认是 mean，不是 sum** —— 想求和一定要写 `aggfunc='sum'`
- **`fill_value=0`** 填空格，**`margins=True`** 加总计
- **crosstab 数次数**，pivot_table 算数值
- **melt 是反向操作**（宽变长）
