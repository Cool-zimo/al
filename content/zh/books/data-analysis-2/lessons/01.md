# 为什么需要 pandas

> 《数据分析 1》结束时我们说过：NumPy 处理"文字列 + 数字列"很别扭。这一课就从这个痛点开始。

## 先看 NumPy 有多别扭

假设有一张学生表：

```python
import numpy as np

# 姓名（文字）+ 年龄（整数）+ 成绩（小数）
data = np.array([['张三', '18', '89.5'],
                 ['李四', '19', '92.0'],
                 ['王五', '20', '78.0']])
print(data)
print("dtype:", data.dtype)
```

```
[['张三' '18' '89.5']
 ['李四' '19' '92.0']
 ['王五' '20' '78.0']]
dtype: <U4
```

**注意 dtype 是 `<U4`——全是字符串**。因为 NumPy 一个数组只能有一种类型，混进文字之后，数字也被迫变成文字。

想算平均分？得手动转：

```python
scores = data[:, 2].astype(float)      # 每次都要转
print(scores.mean())
```

**每一列都要转一次**，列一多就失控了。

## pandas 的做法

```python
import pandas as pd

df = pd.DataFrame({
    '姓名': ['张三', '李四', '王五'],
    '年龄': [18, 19, 20],
    '成绩': [89.5, 92.0, 78.0]
})
print(df)
print(df.dtypes)
```

```
   姓名  年龄    成绩
0  张三  18  89.5
1  李四  19  92.0
2  王五  20  78.0

姓名     object
年龄      int64
成绩    float64
dtype: object
```

**关键差别**：`姓名` 是 object（文字），`年龄` 是 int64，`成绩` 是 float64 —— **每列各有自己的类型**。

这才是表格该有的样子。算平均分现在是：

```python
print(df['成绩'].mean())      # 86.5
```

不用转换，因为这一列本来就是数字类型。

## pandas 到底是什么

一句话：**pandas 是建立在 NumPy 之上的表格库**。

```python
print(type(df['成绩'].values))    # <class 'numpy.ndarray'>
```

**每一列的 `.values` 就是一个 NumPy 数组**。你在《数据分析 1》学的所有东西——广播、axis、布尔索引、ufunc——在这里全部照用。

```python
# NumPy 的知识直接生效
print(df['成绩'].values * 1.1)          # 广播
print(df['成绩'].values > 85)           # 布尔数组
print(np.where(df['成绩'].values > 85, '优', '良'))   # np.where
```

所以这不是"换个库从头学"，而是**在 NumPy 之上加了一层"表格"的便利**。

## pandas 解决的四个痛点

| NumPy 的痛点 | pandas 的解法 |
|---|---|
| 一列文字，全部变字符串 | **每列独立类型** |
| 只有位置下标，没有名字 | **列名 + 索引标签** |
| 缺失值要记得用 nanmean 等 | **`mean()` 默认跳过缺失** |
| 分组聚合要手写循环 | **`groupby` 一行搞定** |

## 三个名字要先记住

| 名字 | 是什么 | 类比 |
|---|---|---|
| **Series** | 一列带标签的数据 | NumPy 一维数组 + 索引名 |
| **DataFrame** | 一张表（多个 Series 拼起来） | Excel 的一个 sheet |
| **Index** | 行标签 | 表格最左边那列编号 |

```python
print(type(df))              # DataFrame
print(type(df['成绩']))      # Series ← 取一列得到 Series
print(type(df.index))        # Index
```

**DataFrame 是"Series 的字典"**：`df['成绩']` 就是取出名为"成绩"的那一列。

## 第一个完整例子

```python
import pandas as pd

df = pd.DataFrame({
    '商品': ['键盘', '鼠标', '显示器', '耳机'],
    '单价': [199, 89, 1299, 399],
    '销量': [120, 500, 30, 200]
})

# 新增一列：销售额 = 单价 × 销量
df['销售额'] = df['单价'] * df['销量']

print(df)
print("\n总销售额：", df['销售额'].sum())
print("最畅销：", df.loc[df['销量'].idxmax(), '商品'])
```

```
    商品   单价   销量    销售额
0   键盘  199  120   23880
1   鼠标   89  500   44500
2  显示器 1299  30   38970
3   耳机  399  200   79800

总销售额： 187150
最畅销： 鼠标
```

**注意这两行的写法**：

- `df['单价'] * df['销量']` —— 两列直接相乘，pandas 会**按索引对齐**后逐元素计算
- `df.loc[df['销量'].idxmax(), '商品']` —— `idxmax()` 返回最大值的**索引标签**，再用 `.loc` 按标签取对应的商品名

这两个操作（列间运算、按标签取值）是 pandas 最常用的两个动作，后面会详细讲。

## 什么时候不该用 pandas

pandas 不是万能的，这些场景 NumPy 更合适：

- **纯数值的大规模矩阵运算**（图像处理、信号处理、线性代数）
- **需要极致性能的内层循环**（NumPy 少了标签管理，更快）
- **给 sklearn 等库喂数据**（它们内部会转成 ndarray）

**原则**：数据结构是"表格"用 pandas，是"矩阵/张量"用 NumPy。
