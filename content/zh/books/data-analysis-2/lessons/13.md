# 类型转换

> "这列明明是数字，怎么算不了？"——这一课解决这个最高频的问题。

## 先看症状

```python
import pandas as pd

df = pd.DataFrame({'价格': ['199', '89', '1299']})
print(df['价格'].dtype)      # object
print(df['价格'] + 1)        # ❌ TypeError
```

**文字列做不了数学运算**。必须转成数字类型。

## astype：最直接的转换

```python
df['价格'] = df['价格'].astype(int)
print(df['价格'].dtype)      # int64
print(df['价格'] + 1)        # ✅
```

**但 astype 很"脆"——遇到一个转不动的就整个崩**：

```python
d = pd.DataFrame({'v': ['1', '2', 'x']})
d['v'].astype(int)
# ValueError: invalid literal for int() with base 10: 'x'
```

**只要有一个值转不动，整列转换失败**。真实数据里几乎总能碰上这种脏值。

## to_numeric：更宽容

```python
print(pd.to_numeric(d['v'], errors='coerce'))
```

```
0    1.0
1    2.0
2    NaN    ← 转不动的变成 NaN，不报错
Name: v, dtype: float64
```

**`errors='coerce'` 是清洗数字列的万能钥匙**。转完再按缺失处理：

```python
d['v'] = pd.to_numeric(d['v'], errors='coerce')
print(d['v'].isna().sum())      # 看看有几个转失败了
```

`errors` 三个选项：

| 值 | 行为 |
|---|---|
| `'raise'`（默认） | 转不动就报错 |
| `'coerce'` | 转不动变 NaN ← **清洗时用它** |
| `'ignore'` | 转不动就保持原样 |

## 实战：清洗金额列

真实数据里的金额长这样：`'¥1,299'`、`'1,299元'`、`'暂无'`。

```python
m = pd.Series(['¥1,299', '¥89', '暂无'])

# 第一步：去掉符号和逗号
cleaned = m.str.replace('¥', '').str.replace(',', '')
print(cleaned.tolist())      # ['1299', '89', '暂无']

# 第二步：转数字，转不动的变 NaN
nums = pd.to_numeric(cleaned, errors='coerce')
print(nums.tolist())         # [1299.0, 89.0, nan]
```

**两步走：先用 `.str` 清理掉干扰字符，再 `to_numeric` 转换。**

## 一个必踩的坑：NaN 转不了 int

```python
d = pd.DataFrame({'数量': [1.0, np.nan]})
d['数量'].astype(int)
# IntCastingNaNError: Cannot convert non-finite values (NA or inf) to integer
```

**只要列里有 NaN，就不能转成 int**（因为 int 没有"空"这个状态）。

三种解法：

```python
# 1. 先填补再转（最常用）
d['数量'].fillna(0).astype(int)      # [1, 0]

# 2. 转成可空整数类型 Int64（大写 I）
d['数量'].astype('Int64')            # [1, <NA>]
print(d['数量'].astype('Int64').dtype)   # Int64

# 3. 保持 float（如果后续还要做除法等运算）
```

> 💡 **`Int64`（大写 I）是 pandas 的可空整数类型**，能同时存整数和缺失。注意和 NumPy 的 `int64`（小写 i）区分——后者不能有 NaN。

## 转成文字

```python
df['编号'] = df['编号'].astype(str)      # 数字转文字
```

**注意**：转完 NaN 会变成字符串 `'nan'`——这通常不是你要的：

```python
s = pd.Series([1, np.nan])
print(s.astype(str).tolist())     # ['1.0', 'nan']  ← 'nan' 是文字，不是空
```

## 转成分类：category

```python
df['城市'] = df['城市'].astype('category')
print(df['城市'].dtype)      # category
```

**取值重复度高的文字列（城市、性别、类别）转成 category 能省内存、加速 groupby**。取值种类远少于行数时收益明显。

## 转成日期

```python
df['日期'] = pd.to_datetime(df['日期'])
print(df['日期'].dtype)      # datetime64[ns]
```

第 26 课会详细讲。这里先记住：**`to_datetime` 不是 `astype`**。

## 检查类型：dtypes

```python
print(df.dtypes)             # 每列的类型
print(df.dtypes.value_counts())   # 各类型有几个
print(df.select_dtypes(include='object').columns)   # 挑出所有文字列
```

**`select_dtypes` 在"找出所有需要清洗的文字列"时很好用**：

```python
# 把所有 object 列列出来，逐个检查该不该是数字
for col in df.select_dtypes(include='object').columns:
    print(col, '→', df[col].unique()[:5])
```

## 完整清洗流程

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    '价格': ['¥1,299', '¥89', '暂无', '¥2,000'],
    '数量': ['2', '3', 'x', '1'],
    '城市': ['北京', '上海', '北京', '广州']
})

print("=== 清洗前 ===")
print(df.dtypes)

# 1. 价格：去符号逗号 → 转数字
df['价格'] = pd.to_numeric(
    df['价格'].str.replace('¥','').str.replace(',',''),
    errors='coerce'
)

# 2. 数量：转数字，失败变 NaN 后填 0 再转 int
df['数量'] = pd.to_numeric(df['数量'], errors='coerce').fillna(0).astype(int)

# 3. 城市：转 category（取值少，省内存）
df['城市'] = df['城市'].astype('category')

print("\n=== 清洗后 ===")
print(df.dtypes)
print()
print(df)
print("\n价格列的缺失（'暂无' 转失败）：", df['价格'].isna().sum())
```

## 速查

| 需求 | 写法 |
|---|---|
| 转数字（严格） | `.astype(int)` / `.astype(float)` |
| 转数字（宽容） | `pd.to_numeric(列, errors='coerce')` |
| 转文字 | `.astype(str)` |
| 转分类 | `.astype('category')` |
| 转可空整数 | `.astype('Int64')`（大写 I） |
| 转日期 | `pd.to_datetime(列)` |
| 看类型 | `df.dtypes` |
| 挑出文字列 | `df.select_dtypes(include='object')` |
