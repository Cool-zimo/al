# 重复值与异常值

> 数据不一定"缺"，也可能"多"或者"离谱"。这一课讲怎么揪出它们。

## 重复值：duplicated

```python
import pandas as pd

d = pd.DataFrame({
    '城市': ['北京', '北京', '上海', '广州', '上海'],
    '值':   [1, 1, 2, 3, 4]
})

print(d.duplicated())
```

```
0    False
1     True    ← 和上一行完全相同
2    False
3    False
4    False
dtype: bool
```

**`duplicated()` 标记"这一行是不是重复出现的"**，第一次出现是 False，之后重复的是 True。

**注意第 4 行的"上海"没被标记**——因为它的值是 4，和前面的"上海/2"整行不同。

## 按部分列判断：subset

```python
print(d.duplicated(subset=['城市']))
```

```
0    False
1     True    ← 北京第二次出现
2    False
3    False
4     True    ← 上海第二次出现
```

**只按"城市"判断重复**。这是更常用的做法——业务上的"重复"通常是"主键重复"，不是"整行一模一样"。

## keep 参数

```python
print(d.duplicated(subset=['城市'], keep='last'))    # 最后一次不算重复
print(d.duplicated(subset=['城市'], keep=False))     # 所有重复项都标记
```

| `keep` | 行为 |
|---|---|
| `'first'`（默认） | 第一次出现不算重复，之后算 |
| `'last'` | 最后一次出现不算重复 |
| `False` | **所有**重复项都标记 True |

**`keep=False` 是"把重复项全揪出来检查"的关键**：

```python
# 看看有哪些重复的城市
print(d[d.duplicated(subset=['城市'], keep=False)])
```

## 删除：drop_duplicates

第 10 课讲过，这里补一个要点：

```python
d.drop_duplicates(subset=['城市'], keep='first')
```

**去重前先看看到底重复了多少**：

```python
print("重复行数：", d.duplicated().sum())
print("按城市重复的：", d.duplicated(subset=['城市']).sum())
```

## 异常值：先看统计

```python
v = pd.Series([10, 12, 11, 13, 12, 11, 999, 10, 12])
print(v.describe())
```

```
count      9.000000
mean     121.111111    ← 被 999 拉高了
std      329.209828
min       10.000000
25%       11.000000
50%       12.000000
75%       12.000000
max      999.000000    ← 明显离谱
```

**看三个信号**：

- `max` / `min` 明显脱离其他值
- `mean` 和 `50%`（中位数）差很多 → 有极端值在拉
- `std`（标准差）特别大

**这里 mean=121 而中位数只有 12，一眼就知道有异常值。**

## 用 IQR 划定异常

**最常用的量化方法**：

```python
q1 = v.quantile(0.25)      # 下四分位
q3 = v.quantile(0.75)      # 上四分位
iqr = q3 - q1              # 四分位距

lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr

print(f"正常范围：{lower} ~ {upper}")
print("异常值：", v[(v < lower) | (v > upper)].tolist())
```

```
正常范围：9.5 ~ 13.5
异常值： [999]
```

**口诀：小于 Q1-1.5×IQR 或大于 Q3+1.5×IQR 的就是异常值。**

这个方法是统计学里的标准做法（箱线图的原理），比"凭感觉设阈值"可靠。

## 也可以用标准差

```python
mean, std = v.mean(), v.std()
print(v[(v - mean).abs() > 3 * std])      # 偏离均值 3 个标准差以上
```

**但标准差法会被异常值本身影响**（999 把 std 撑得很大），**IQR 更稳健**。优先用 IQR。

## 处理异常值：三条路

```python
# 1. 删掉
v_clean = v[~((v < lower) | (v > upper))]

# 2. 截断（clip）——把超界的压到边界
v_clip = v.clip(lower, upper)
print(v_clip.tolist())      # 999 变成 13.5

# 3. 替换成 NaN，之后按缺失处理
v[v > upper] = np.nan
```

| 方法 | 适用 |
|---|---|
| **删掉** | 确定是录入错误（年龄 200、价格 0） |
| **clip 截断** | 不确定但不想让它影响统计（保留行数） |
| **转成 NaN** | 想保留行数，且后续有填补策略 |

> ⚠️ **别急着删异常值**。有些"异常"是真的业务信号——比如一笔 10 万的订单，可能是大客户而不是错误。**先看看它是什么，再决定。**

```python
# 看看异常值所在的那几行，而不只是那个数
print(df[df['金额'] > upper])
```

## 实战：清洗一份销售数据

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    '订单号': ['A001', 'A002', 'A002', 'A003', 'A004'],
    '金额': [199, 89, 89, 99999, 150],
    '数量': [1, 2, 2, 1, 3]
})

print("=== 步骤 1：查重复 ===")
print("重复订单号：", df.duplicated(subset=['订单号']).sum())
df = df.drop_duplicates(subset=['订单号'], keep='first')
print(f"去重后：{len(df)} 行")

print("\n=== 步骤 2：查异常 ===")
q1, q3 = df['金额'].quantile(0.25), df['金额'].quantile(0.75)
iqr = q3 - q1
upper = q3 + 1.5 * iqr
print(f"金额正常上界：{upper}")

outliers = df[df['金额'] > upper]
print("异常订单：")
print(outliers)

print("\n=== 步骤 3：处理（本例选择删掉）===")
df = df[df['金额'] <= upper]
print(df)
print("\n金额均值：", df['金额'].mean())      # 现在合理了
```

## 小结

| 需求 | 写法 |
|---|---|
| 标记重复 | `df.duplicated()` |
| 按关键列标记 | `df.duplicated(subset=['列'])` |
| 揪出所有重复项 | `keep=False` |
| 删重复 | `df.drop_duplicates(subset=['列'])` |
| 看异常 | `df.describe()`（对比 mean 与 50%） |
| IQR 划界 | `Q1-1.5×IQR` ~ `Q3+1.5×IQR` |
| 截断 | `df['列'].clip(下, 上)` |

```quiz
type: choice
exam: true
q: 为什么用 IQR 法比"偏离均值 3 个标准差"更可靠？
options:
- IQR 计算更快
- 标准差会被异常值本身撑大，导致漏判；IQR 基于分位数，不受极端值影响
- IQR 是 pandas 内置的
- 标准差法已经废弃了
answer: 1
explain: 一个 999 的极端值会把 std 撑得极大，于是"3 倍标准差"的门槛也被抬高到几乎抓不到它 —— 这叫"掩蔽效应"。IQR 基于分位数（Q1/Q3 是位置而不是数值），极端值动不了它，所以更稳健。
```
