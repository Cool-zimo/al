# loc 与 iloc

> 这是 pandas 最大的混淆点。搞懂这一课，后面一半的 bug 都不会发生。

## 一句话区别

| | 按什么取 | 切片是否含尾 |
|---|---|---|
| **`loc`** | 按**标签**（名字） | **含**尾 |
| **`iloc`** | 按**位置**（第几个） | **不含**尾 |

**两个区别，都要记住**：一个是"取什么"，一个是"切片边界"。

## 先看 loc：按名字

```python
import pandas as pd

df = pd.DataFrame({
    '姓名': ['张三', '李四', '王五', '赵六'],
    '年龄': [18, 19, 20, 17],
    '成绩': [89.5, 92.0, 78.0, 95.0]
})
df = df.set_index('姓名')      # 用姓名当行索引

print(df)
print()
print(df.loc['李四'])
```

```
     年龄    成绩
姓名
张三   18  89.5
李四   19  92.0
王五   20  78.0
赵六   17  95.0

年龄    19.0
成绩    92.0
Name: 李四, dtype: float64
```

**`loc['李四']` 按名字取到了那一行。**

## 再看 iloc：按位置

```python
print(df.iloc[1])      # 第 1 个位置（从 0 数）
```

```
年龄    19.0
成绩    92.0
Name: 李四, dtype: float64
```

**恰好也是李四**——因为李四就在第 1 个位置。但两者规则不同。

**什么时候会不一致？** 把表排序一下：

```python
df2 = df.sort_values('成绩', ascending=False)
print(df2)
print()
print("loc['李四']  →", df2.loc['李四', '成绩'])
print("iloc[1]     →", df2.iloc[1]['成绩'])
```

```
     年龄    成绩
姓名
赵六   17  95.0
李四   19  92.0
张三   18  89.5
王五   20  78.0

loc['李四']  → 92.0     ← 还是李四
iloc[1]     → 92.0     ← 碰巧也一样（李四排第2）
```

换成 iloc[0]：

```python
print("iloc[0] →", df2.iloc[0]['成绩'])     # 95.0，是赵六！
```

**排序后位置变了，但标签跟着行走**。这是两者最本质的差别：

- **`loc` 跟着"这一行是谁"走**——排序、筛选都不影响
- **`iloc` 跟着"第几行"走**——排序后就换成别人了

## 取单个值

```python
print(df.loc['李四', '成绩'])     # 92.0   行标签 + 列名
print(df.iloc[1, 1])              # 92.0   行位置 + 列位置
```

**格式是 `[行, 列]`**，逗号前面是行、后面是列。

也可以只取行的一部分列：

```python
print(df.loc['李四', ['年龄', '成绩']])     # 取一行的多列
print(df.iloc[1, 0:2])                      # 按位置取
```

## 切片：含尾 vs 不含尾

**这是第二个坑，而且更隐蔽。**

```python
s = pd.Series([10, 20, 30, 40], index=['a', 'b', 'c', 'd'])

print(s.loc['a':'c'])      # [10, 20, 30]   ← 含 'c'！3 个
print(s.iloc[0:2])         # [10, 20]       ← 不含位置 2！2 个
```

**同样写 `0:2` 的范围：**

```python
df3 = pd.DataFrame({'姓名': ['张三','李四','王五','赵六'], '成绩': [1,2,3,4]})

print(df3.loc[0:2])        # 3 行（含 2）
print(df3.iloc[0:2])       # 2 行（不含 2）
```

| 写法 | 结果行数 |
|---|---|
| `df.loc[0:2]` | **3 行**（0,1,2） |
| `df.iloc[0:2]` | **2 行**（0,1） |

> ⚠️ **`loc` 的切片含尾**是 pandas 刻意的设计（因为标签是名字，"从 a 到 c" 自然包含 c）。但它和 Python 的直觉相反，**是最容易数错行数的地方**。

## 布尔筛选：只能用 loc（或方括号）

```python
# 取成绩 > 90 的行，只要姓名列
print(df.loc[df['成绩'] > 90])
print(df.loc[df['成绩'] > 90, '年龄'])     # 加列选择
```

**`df.loc[布尔Series]` 是标准写法**。`iloc` 不接受布尔 Series（它只认位置）。

> 💡 也可以写 `df[df['成绩'] > 90]`，效果一样。但**一旦要同时选列，就必须用 loc**：
> `df.loc[条件, '列名']` 可以，`df[条件]['列名']` 链式写法在某些赋值场景会失效。

## 一张对照表

| 需求 | 写法 |
|---|---|
| 按名字取行 | `df.loc['李四']` |
| 按位置取行 | `df.iloc[1]` |
| 取某个值 | `df.loc['李四', '成绩']` |
| 按位置取值 | `df.iloc[1, 1]` |
| 按名字切片 | `df.loc['张三':'王五']`（含尾） |
| 按位置切片 | `df.iloc[0:2]`（不含尾） |
| 条件筛选 | `df.loc[df['成绩'] > 90]` |
| 条件筛选 + 选列 | `df.loc[df['成绩'] > 90, ['姓名','成绩']]` |

## 怎么记忆

- **`loc` = label（标签）** → 名字
- **`iloc` = integer location（整数位置）** → 第几个

`i` 就是 integer。记住这个，就不会搞反。

## 什么时候用哪个

- **知道"要哪一行"（比如某个城市、某个订单号）→ `loc`**
- **知道"第几行"（比如前 3 行、最后一行）→ `iloc`**

绝大多数真实场景是前者——按条件或名字取。所以 **`loc` 用得更多**。
