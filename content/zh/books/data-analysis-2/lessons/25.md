# pivot 与 pivot_table：长表变宽表

> melt 把宽表压扁，pivot 把它立起来。但 pivot 有个硬性要求——遇到重复组合会直接报错，这时候就得上 pivot_table。

## pivot：三要素

```python
import pandas as pd

长表 = pd.DataFrame({
    '门店': ['北京', '北京', '上海', '上海'],
    '月份': ['1月', '2月', '1月', '2月'],
    '销售额': [1200, 1500, 900, 1100]
})
```

```python
宽表 = 长表.pivot(index='门店', columns='月份', values='销售额')
print(宽表)
```

```
月份     1月    2月
门店
北京   1200  1500
上海    900  1100
```

**`pivot(index=行, columns=列, values=值)`**——三个要素缺一不可。

| 参数 | 作用 |
|---|---|
| `index` | 变成行索引的列 |
| `columns` | 变成列名的列 |
| `values` | 填充单元格的值 |

结果是**带列名的 DataFrame**（columns 变成二级表头）。

## 翻车现场：重复组合直接 ValueError

```python
有重复 = pd.DataFrame({
    '门店': ['北京', '北京', '北京'],
    '月份': ['1月', '1月', '2月'],
    '销售额': [1200, 1300, 1500]
})
```

北京在 1 月有两条记录（1200 和 1300），"北京+1月"这个组合出现了两次。

```python
# WRONG
有重复.pivot(index='门店', columns='月份', values='销售额')
```

```
ValueError: Index contains duplicate entries, cannot reshape
```

**pivot 要求每个 (index, columns) 组合唯一**。它不知道该取哪个值，直接报错。

## pivot_table：用聚合解决冲突

```python
result = 有重复.pivot_table(index='门店', columns='月份',
                            values='销售额', aggfunc='mean')
print(result)
```

```
月份         1月      2月
门店
北京    1250.0  1500.0
```

**`aggfunc='mean'` 把重复的组合求平均**（1200 和 1300 的均值 1250）。aggfunc 还能是 `'sum'`、`'max'`、`'count'`、`'first'`。

**pivot_table 是 pivot 的"带聚合版本"**，专为有重复的情况设计。

## pivot_table 的其他用法

```python
库存 = pd.DataFrame({
    '门店': ['北京', '北京', '上海', '上海', '上海'],
    '品类': ['外设', '显示', '外设', '显示', '外设'],
    '数量': [10, 5, 8, 6, 4]
})
```

按门店看品类分布：

```python
print(库存.pivot_table(index='门店', columns='品类', values='数量', aggfunc='sum'))
```

```
品类     外设   显示
门店
北京     10    5
上海     12    6
```

**上海的"外设"是 8+4=12**（自动聚合）。这是库存盘点、交叉分析的常用写法。

## 填满空值：fill_value

```python
稀疏 = pd.DataFrame({
    '门店': ['北京', '北京', '上海'],
    '品类': ['外设', '显示', '外设'],
    '数量': [10, 5, 8]
})

print(库存.pivot_table(index='门店', columns='品类', values='数量',
                       aggfunc='sum', fill_value=0))
```

```
品类      外设  显示
门店
北京      10   5
上海      12   6
```

**没有组合的单元格补 0**，而不是 NaN。下游计算时这很关键——NaN 会传染。

## margins：加一行一列合计

```python
print(库存.pivot_table(index='门店', columns='品类', values='数量',
                       aggfunc='sum', margins=True, margins_name='合计'))
```

```
品类      外设  显示   合计
门店
北京      10   5    15
上海      12   6    18
合计      22  11    33
```

**`margins=True` 自动加上行列总计**。做报表时这个参数能省不少事。

## crosstab：交叉计数

pivot_table 算的是"值"的聚合，crosstab 算的是"频次"：

```python
订单 = pd.DataFrame({
    '门店': ['北京', '北京', '北京', '上海', '上海'],
    '品类': ['外设', '外设', '显示', '外设', '显示']
})

频次 = pd.crosstab(订单['门店'], 订单['品类'])
print(频次)
```

```
品类    外设  显示
门店
北京      2    1
上海      1    1
```

**每个格子是"出现了几次"**。等价于 `pivot_table(aggfunc='size')`，但写起来更短。

## 翻车现场：pivot 后列名是多级索引

```python
r = 长表.pivot(index='门店', columns='月份', values='销售额')
print(r.columns)
```

```
Index(['1月', '2月'], dtype='object', name='月份')
```

**columns 带了个 name='月份'**。如果你接着 `r['1月']` 取值没问题，但想 `r.columns.tolist()` 当普通列表用时，这个 name 可能会让后续断言或比较出意外。

**用 `reset_index()` 可以压平成普通表**：

```python
print(r.reset_index())
```

```
月份  门店   1月    2月
0   北京  1200  1500
1   上海   900  1100
```

## 小结

- **pivot 三要素**：index、columns、values，要求组合唯一
- **pivot_table 加 aggfunc**，能处理重复组合
- **`fill_value=0`** 把缺失补成 0，避免 NaN 传染
- **`margins=True`** 自动加行列合计
- **crosstab 做交叉计数**，等价于 size 版 pivot_table
