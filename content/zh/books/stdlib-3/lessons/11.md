# collections.Counter：计数神器

> 这一课解决"数数"这件事。手写字典计数要写 4 行还容易漏判，`Counter` 一行搞定，还能直接告诉你"谁最多"。

## 手写计数为什么烦

张三统计一段文本里每个字出现了几次：

```python
text = "abracadabra"

# 手写字典计数
counts = {}
for ch in text:
    if ch in counts:
        counts[ch] += 1
    else:
        counts[ch] = 1

print(counts)
```

输出：

```
{'a': 5, 'b': 2, 'r': 2, 'c': 1, 'd': 1}
```

四行代码，还得专门处理"第一次见到这个键"的分支。忘写 `else`、或者把 `+=` 写成 `=` 是高频错误。

**`Counter` 把这件事变成一行**：

```python
from collections import Counter

text = "abracadabra"
c = Counter(text)
print(c)
```

输出：

```
Counter({'a': 5, 'b': 2, 'r': 2, 'c': 1, 'd': 1})
```

`Counter` 是 `dict` 的子类——它**就是**一个字典，只是多了几个专门为"计数"设计的方法。所有字典操作它都支持。

## most_common：直接问"谁最多"

这是 `Counter` 最有用的一个方法。不用排序、不用写 lambda，一行拿到前 N 名：

```python
from collections import Counter

votes = ["苹果", "香蕉", "苹果", "橘子", "香蕉", "苹果", "橘子", "苹果"]
c = Counter(votes)

print("第一名:", c.most_common(1))
print("前三名:", c.most_common(3))
print("全部（按频次降序）:", c.most_common())
```

输出：

```
第一名: [('苹果', 4)]
前三名: [('苹果', 4), ('香蕉', 2), ('橘子', 2)]
全部（按频次降序）: [('苹果', 4), ('香蕉', 2), ('橘子', 2)]
```

`most_common(n)` 返回 `(元素, 次数)` 元组的列表，已按次数从大到小排好。**这是手写字典永远做不到的便利**。

## 翻车现场：访问不存在的键返回 0，不是报错

普通字典访问不存在的键会抛 `KeyError`，但 `Counter` 为了"计数"的语义，会**返回 0**：

```python
from collections import Counter

c = Counter(["苹果", "香蕉"])
print("苹果:", c["苹果"])
print("西瓜:", c["西瓜"])      # 普通 dict 这里会 KeyError
```

输出：

```
苹果: 1
西瓜: 0
```

这是 `Counter` 特意为"数数"设计的容错。但它也是个隐患：你没法靠 `KeyError` 发现"键拼错了"这种 bug。

**结论**：当你确实想知道"这个键到底在不在"时，用 `c.get(key)` 或直接 `key in c` 判断，不要靠 `c[key] == 0` 来推断。

## 加减法：把计数当集合运算

`Counter` 支持加减法和集合操作，用来做"对比两批数据的差异"非常顺手：

```python
from collections import Counter

# 上周和本周的订单品类统计
last_week = Counter(苹果=30, 香蕉=20, 橘子=15)
this_week = Counter(苹果=35, 香蕉=18, 芒果=10)

print("合并两周:", last_week + this_week)
print("本周减上周（增长）:", this_week - last_week)
```

输出：

```
合并两周: Counter({'苹果': 65, '香蕉': 38, '橘子': 15, '芒果': 10})
本周减上周（增长）: Counter({'芒果': 10, '苹果': 5})
```

减法只保留**结果为正**的项（`香蕉` 18-20 为负，被丢掉）。这个特性用来做"增长榜"特别合适：减法结果里剩下的，就是本周新增或增长的品类。

## 翻车现场：Counter 里混进了不该计数的东西

`Counter` 的入参可以是**任何可迭代对象**。如果你传进去一个字符串，它会按字符计数；传进去一个列表，按元素计数。

```python
from collections import Counter

# WRONG：以为会按单词计数，结果按字符计数
c = Counter("苹果香蕉苹果")
print(c)
```

输出：

```
Counter({'苹': 2, '果': 2, '香': 1, '蕉': 1, '苹': 0, '果': 0})
```

想要按单词/按行计数，必须先把文本**切成列表**：

```python
from collections import Counter

words = "苹果 香蕉 苹果 橘子".split()
c = Counter(words)
print(c)
```

输出：

```
Counter({'苹果': 2, '香蕉': 1, '橘子': 1})
```

**这个坑的本质**：`Counter` 不认"语义"，它只管"迭代出来的每个元素是什么"。字符串的迭代单元是字符，列表的迭代单元是元素，字典的迭代单元是键——**搞清楚你传进去的东西迭代出来是什么，是正确使用的第一步**。

## 实战：统计订单金额区间分布

```python
from collections import Counter

orders = [29, 99, 129, 199, 299, 99, 129, 499, 99, 129, 29]

# 用区间标签做计数
def bucket(amount):
    if amount < 100:
        return "100以下"
    elif amount < 300:
        return "100-300"
    else:
        return "300以上"

buckets = Counter(bucket(o) for o in orders)
print(buckets.most_common())
```

输出：

```
[('100-300', 5), ('100以下', 3), ('300以上', 1)]
```

**这个套路在数据分析里极常见**：先定义一个"归类函数"，再用生成器表达式喂给 `Counter`。一行代码就把一堆数字变成了可读的分布表。

## 小结

- `Counter` 是 `dict` 的子类，专门为计数优化，省掉"判断键是否存在"的样板代码
- `most_common(n)` 直接返回按频次排序的前 N 名，不用手写排序
- 访问不存在的键返回 `0` 而不是报错——便利但掩盖拼写错误，要查存在性用 `in`
- 支持 `+` `-` 运算，`a - b` 只保留正数项，适合做增长/差异分析
- `Counter` 按"迭代单元"计数：字符串按字符、列表按元素，传参前先确认迭代出来的是什么
- 先用归类函数、再 `Counter(生成器表达式)`，是做分布统计的标准写法
