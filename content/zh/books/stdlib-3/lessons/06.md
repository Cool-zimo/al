# 编译正则：re.compile 与标志位

> 这一课解决"同一段模式要用很多次"时的性能与可读性。`re.compile` 把模式预编译成对象；`IGNORECASE` / `MULTILINE` / `DOTALL` 三个标志各自治一种具体的痛。

## re.compile：把模式提前编译好

前几课我们一直用 `re.findall(r'\d+', text)` 这种"函数式"写法。它内部每次都会先把模式字符串**编译**一遍。如果同一个模式要在循环里、在大量字符串上反复用，重复编译就是浪费。

```python
import re

texts = ["订单DD20260927", "客户编号C001", "订单DD20260928", "备注无"]

# 推荐：先编译一次，反复使用
pat = re.compile(r'DD(\d{8})')
results = [pat.findall(t) for t in texts]
print(results)
```

输出：

```
[['20260927'], [], ['20260928'], []]
```

`re.compile` 返回一个 `re.Pattern` 对象。它身上有和 `re` 模块一一对应的方法：`.search()` `.findall()` `.sub()` `.split()` `.finditer()`，用法完全一样，只是**少传一个模式参数**。

## 什么时候该编译

不是所有地方都要 `compile`。规则很简单：

| 场景 | 要不要 compile |
|---|---|
| 模式只用一两次 | 不用，直接 `re.findall(...)` 更简洁 |
| 模式在循环/函数里反复用 | **要**，编译一次反复用 |
| 模式要在多处复用、想给个名字 | **要**，名字就是文档 |
| 写一个被多处调用的工具函数 | 建议编译后存成模块级常量 |

```python
import re

# 模块级编译：名字即文档
PHONE_RE = re.compile(r'1[3-9]\d{9}')
ORDER_RE = re.compile(r'DD(\d{8})')

def extract_info(text):
    phone = PHONE_RE.search(text)
    order = ORDER_RE.search(text)
    return {
        "phone": phone.group() if phone else None,
        "order": order.group(1) if order else None,
    }

print(extract_info("电话13812345678订单DD20260927"))
```

输出：

```
{'phone': '13812345678', 'order': '20260927'}
```

**编译的另一个收益是可读性**：`PHONE_RE` 这个变量名本身就是注释，比散落在代码里的 `r'1[3-9]\d{9}'` 好懂得多。

## 三个最常用的标志

编译时可以把**标志**一起传进去。标志是 `re` 模块的属性，多个标志用 `|` 组合。

### re.IGNORECASE（简写 re.I）：忽略大小写

```python
import re

pat = re.compile(r'python', re.IGNORECASE)
print(pat.findall("Python python PYTHON pYtHoN"))
```

输出：

```
['Python', 'python', 'PYTHON', 'pYtHoN']
```

### re.MULTILINE（简写 re.M）：让 ^ 和 $ 匹配每一行

不加 `MULTILINE` 时，`^` 只匹配整个字符串的开头，`$` 只匹配整个字符串的结尾。

```python
import re

text = """错误: 磁盘满
信息: 运行正常
错误: 内存不足"""

# 不加 MULTILINE：^错误 只在最开头匹配
print("不加:", re.findall(r'^错误.*', text))

# 加 MULTILINE：^ 匹配每行的开头
print("加 M:", re.findall(r'^错误.*', text, re.MULTILINE))
```

输出：

```
不加: []
加 M: ['错误: 磁盘满', '错误: 内存不足']
```

### re.DOTALL（简写 re.S）：让 . 匹配换行

前面第 3 课见过这个。`re.DOTALL` 让 `.` 匹配**包括换行符在内的任意字符**，是处理跨行文本的关键。

```python
import re

text = """第一行
第二行
第三行"""

print("不加 S:", re.findall(r'第一(.*)第三', text))
print("加 S:", re.findall(r'第一(.*)第三', text, re.DOTALL))
```

输出：

```
不加 S: []
加 S: ['行\n第二行\n']
```

## 翻车现场：标志传错位置

`compile` 时标志是第二个参数；`re.findall` 时标志是**最后一个**位置参数。顺序错了直接报错：

```python
import re

text = "Python"
# WRONG：把 flags 当成了 count 参数
pat = re.compile(r'python', re.IGNORECASE)
# 下面这行把 text 和 flags 顺序搞反
print(re.findall(r'python', re.IGNORECASE, text))
```

报错：

```
TypeError: findall() takes at most 3 arguments (4 given)
```

`findall(pattern, string, flags)` 的顺序是**模式、字符串、标志**。标志必须放最后。

**正确做法**：

```python
import re

text = "Python"
pat = re.compile(r'python', re.IGNORECASE)
print(pat.findall(text))                       # 编译后用对象方法
print(re.findall(r'python', text, re.IGNORECASE))  # 或 findall 末尾传标志
```

输出：

```
['Python']
['Python']
```

## 翻车现场：内联标志写错位置

标志也能直接写进模式串里，用 `(?i)` `(?m)` `(?s)` 这种语法。但**它只对它右边的部分生效**，而且分组 `()` 会影响它的作用域：

```python
import re

text = "PYTHON"
# WRONG：内联标志写在开头，整句生效，能匹配
print(re.findall(r'(?i)python', text))
# 想只让一部分忽略大小写，必须包进括号
print(re.findall(r'固定(?i:python)', "固定PYTHON"))
```

输出：

```
['PYTHON']
['固定PYTHON']
```

内联写法的价值在于**局部生效**：`(?i:...)` 只对括号里那段忽略大小写，外面的 `固定` 仍是大小写敏感。写错了作用域，要么匹配过头，要么匹配不到。

## 小结

- `re.compile(pattern)` 把模式编译成 `Pattern` 对象，可反复调用 `.findall()` 等方法，避免重复编译
- 模式只用一两次不必编译；循环内/工具函数内/想给模式起名字时**一定要编译**
- `IGNORECASE`（`I`）：忽略大小写
- `MULTILINE`（`M`）：让 `^` `$` 匹配每一行的行首行尾
- `DOTALL`（`S`）：让 `.` 匹配换行符
- 多个标志用 `|` 组合；`findall` 里标志必须是最后一个参数
- 内联标志 `(?i)` `(?m)` `(?s)` 可局部生效，作用于其右侧/括号内的范围
