# 字符类与量词

> 这一课解决"怎么把一类字符、一段长度描述成一句话"。`.` `\d` `\w` `\s` 是速记符，`[]` `*` `+` `?` `{m,n}` 是量词——它们组合起来才是正则的真正表达力。而"贪婪"和"非贪婪"是这门课最值钱的坑。

## 预定义字符类：速记符

正则里有一批内置的"一类字符"速记，记住这几个能少写很多 `[]`：

| 符号 | 含义 | 等价于 |
|---|---|---|
| `.` | 任意字符（**默认不含换行**） | — |
| `\d` | 数字 | `[0-9]` |
| `\D` | 非数字 | `[^0-9]` |
| `\w` | 字母、数字、下划线 | `[a-zA-Z0-9_]` |
| `\W` | 非字母数字下划线 | `[^a-zA-Z0-9_]` |
| `\s` | 空白（空格、制表、换行） | `[ \t\n\r\f\v]` |
| `\S` | 非空白 | `[^ \t\n\r\f\v]` |

```python
import re

text = "张三 id:zh3_ 余额 1280.5 元\n备注：无"
print("数字:", re.findall(r'\d+\.?\d*', text))
print("单词字符:", re.findall(r'\w+', text))
print("空白位置:", re.findall(r'\s+', text))
```

输出：

```
数字: ['3', '1280.5']
单词字符: ['张三', 'id', 'zh3_', '1280', '5']
空白位置: [' ', ' ', ' ', '\n']
```

**注意**：`\w` 在默认设置下包含中文等 Unicode 字母（取决于 `re.ASCII` 标志）。上面"张三"被整块匹配出来，正是因为中文被当成"单词字符"。如果只想匹配英文字母数字，需要显式写 `[a-zA-Z0-9]` 或加 `re.ASCII` 标志（后续章节讲）。

## 自定义字符类：[]

`[]` 里写一个集合，匹配其中**任意一个**字符。`-` 表示范围，`^` 放在开头表示"取反"。

```python
import re

text = "编号 A1 B7 C3 X9 测试"

print("单个字母+数字:", re.findall(r'[A-Z][0-9]', text))   # 大写字母后跟数字
print("排除数字1:", re.findall(r'[^1]+', text))            # 不含 1 的连续段
```

输出：

```
单个字母+数字: ['A1', 'B7', 'C3', 'X9']
排除数字1: ['编号 A', ' B7 C3 X9 测试']
```

`[^...]` 这个取反很反直觉：它匹配"**不是这些字符**的任意一个"。常见用途是匹配"直到某个分隔符之前的所有内容"。

## 量词：说清"要几个"

量词决定前面的元素出现几次：

| 量词 | 含义 | 等价于 |
|---|---|---|
| `*` | 0 次或多次（可有可无） | `{0,}` |
| `+` | 1 次或多次（至少一次） | `{1,}` |
| `?` | 0 次或 1 次（可选） | `{0,1}` |
| `{n}` | 恰好 n 次 | — |
| `{m,n}` | m 到 n 次 | — |
| `{m,}` | 至少 m 次 | — |

```python
import re

text = "颜色: 红, 颜色: 蓝色blue, 颜色: 深蓝深蓝深蓝"

print(re.findall(r'蓝?色', text))      # 蓝可选
print(re.findall(r'蓝{2,3}', text))    # 蓝字重复 2-3 次
```

输出：

```
['色', '蓝色']
['蓝蓝', '蓝蓝蓝']
```

**注意量词作用的范围**：`蓝?色` 是"可选的蓝 + 色"，所以"色"和"蓝色"都能匹配。`{m,n}` 只修饰紧挨着它前面那**一个**元素。

## 翻车现场：贪婪匹配把整段都吞了

这是正则最经典、最容易踩的坑。张三想从一段 HTML 片段里提取第一个标签的内容：

```python
import re

html = "<div>标题</div><div>正文</div>"

# WRONG：贪婪匹配，.* 一路吃到最后一个
result = re.findall(r'<div>(.*)</div>', html)
print(result)
```

输出：

```
['标题</div><div>正文']
```

`.*` 里的 `*` 是**贪婪**的：它尽量多地匹配。于是 `.` 一口气吃掉了"标题`</div><div>`正文"，只留下最后一个 `</div>` 去收尾。这显然不是想要的。

**正确做法**：在量词后面加 `?`，变成"非贪婪"（也叫懒惰匹配），让它在**第一次**满足条件时就停下来。

```python
import re

html = "<div>标题</div><div>正文</div>"
result = re.findall(r'<div>(.*?)</div>', html)    # 注意 * 后面多了个 ?
print(result)
```

输出：

```
['标题', '正文']
```

| 写法 | 名称 | 行为 |
|---|---|---|
| `.*` | 贪婪 | 尽量多匹配，吃到最后一个符合条件处 |
| `.*?` | 非贪婪 | 尽量少匹配，在第一个符合条件处就停 |

`+?`、`??`、`{m,n}?` 同理，加 `?` 即变非贪婪。

## 翻车现场：`.` 匹配不到换行符

```python
import re

text = """第一行内容
第二行内容
第三行内容"""

# WRONG：. 默认不匹配换行
print(re.findall(r'第一行(.*)第三行', text))
```

输出：

```
[]
```

`.` 默认**不匹配换行符** `\n`，所以"第一行"到"第三行"之间的跨行内容根本匹配不上。

**正确做法**：加 `re.DOTALL` 标志（或写作内联 `(?s)`），让 `.` 把换行也算进去。标志的详细用法在第 6 课讲，这里先记住这个开关。

```python
import re

text = """第一行内容
第二行内容
第三行内容"""

print(re.findall(r'第一行(.*)第三行', text, re.DOTALL))
```

输出：

```
['内容\n第二行内容\n']
```

## 小结

- `\d` `\w` `\s` 是"一类字符"的速记，大写即取反
- `[]` 自定义字符集合，`[^...]` 表示"不是这些字符"
- 量词 `*` `+` `?` `{m,n}` 决定"要几个"，只修饰紧挨着的前一个元素
- **量词默认贪婪**：`(.*)` 会一直吃到最后一个匹配处，跨标签场景几乎必错
- 加 `?` 变非贪婪 `(.*?)`，在第一个符合条件处就停，提取内容时最常用
- `.` 默认不匹配换行，需要跨行时用 `re.DOTALL`
