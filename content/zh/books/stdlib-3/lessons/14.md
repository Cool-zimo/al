# itertools 常用：chain、product、combinations、permutations、groupby

> 这一课把五个最常用的 `itertools` 工具一次性讲透。它们全是**惰性迭代器**——省内存、可组合。重点是 `groupby`：**必须先排序**，这是它最坑的地方。

## itertools 是什么

`itertools` 模块提供一组"迭代器构造工具"。它们的返回值都是**迭代器**，一次吐一个元素，不预先生成完整列表——**惰性求值**。

```python
import itertools

# 返回的是迭代器对象，不是列表
print(itertools.chain([1, 2], [3, 4]))
print(list(itertools.chain([1, 2], [3, 4])))
```

输出：

```
<itertools.chain object at 0x...>
[1, 2, 3, 4]
```

**为什么要惰性**：处理大数据时，先 `list()` 把结果全装进内存可能直接 OOM；迭代器让你"要一个算一个"，配合 `for` 循环逐个消费。

## chain：把多个可迭代对象首尾相接

`chain` 把多个序列拼成一个"看起来是一个"的序列，且**不产生中间列表**。

```python
import itertools

a = [1, 2, 3]
b = [4, 5, 6]
c = [7, 8, 9]

print(list(itertools.chain(a, b, c)))

# 更常用的场景：二维列表摊平一层
matrix = [[1, 2], [3, 4], [5, 6]]
flat = list(itertools.chain.from_iterable(matrix))
print(flat)
```

输出：

```
[1, 2, 3, 4, 5, 6, 7, 8, 9]
[1, 2, 3, 4, 5, 6]
```

`chain.from_iterable` 接收一个"可迭代对象的可迭代对象"，把它摊平一层——处理二维数据是高频操作。

## product：笛卡尔积

`product` 生成多个序列的**笛卡尔积**（所有可能的组合）：

```python
import itertools

colors = ["红", "蓝"]
sizes = ["S", "M", "L"]

for combo in itertools.product(colors, sizes):
    print(combo)
```

输出：

```
('红', 'S')
('红', 'M')
('红', 'L')
('蓝', 'S')
('蓝', 'M')
('蓝', 'L')
```

**这是写"全组合测试"的利器**：SKU 生成、测试矩阵、暴力搜索，都是它的主场。

```python
import itertools

# 生成密码字典（示意）
chars = "ab"
length = 3
for pwd in itertools.product(chars, repeat=length):
    print("".join(pwd))
```

输出：

```
aba
abb
baa
bab
bba
bbb
```

`repeat=n` 表示"同一个序列自己乘 n 次"，是生成等长组合的最短写法。

## combinations 与 permutations：组合与排列

- `combinations`：**不关心顺序**，从 n 个里取 k 个，`(A,B)` 和 `(B,A)` 算同一个
- `permutations`：**关心顺序**，`(A,B)` 和 `(B,A)` 算两个

```python
import itertools

items = ["A", "B", "C"]

print("组合 取2:", list(itertools.combinations(items, 2)))
print("排列 取2:", list(itertools.permutations(items, 2)))
```

输出：

```
组合 取2: [('A', 'B'), ('A', 'C'), ('B', 'C')]
排列 取2: [('A', 'B'), ('A', 'C'), ('B', 'A'), ('B', 'C'), ('C', 'A'), ('C', 'B')]
```

组合 3 个、排列 6 个——排列恰好是组合的 k! 倍（这里 2! = 2，3×2=6）。

## 翻车现场：groupby 不排序，结果碎成一片

`groupby` 把**相邻的、相等的**元素归成一组。它**不会**先把整个序列排序。

```python
import itertools

data = ["苹果", "苹果", "香蕉", "苹果", "香蕉", "香蕉"]

# WRONG：没有先排序，相同元素不相邻，分组被切碎
groups = itertools.groupby(data)
for key, grp in groups:
    print(key, "->", list(grp))
```

输出：

```
苹果 -> ['苹果', '苹果']
香蕉 -> ['香蕉']
苹果 -> ['苹果']
香蕉 -> ['香蕉', '香蕉']
```

"苹果"被拆成了两组，"香蕉"也是。**这几乎是所有 `groupby` 使用者的第一个坑。**

**正确做法**：先用 `sorted` 排好序，让相同元素相邻，再 `groupby`。

```python
import itertools

data = ["苹果", "苹果", "香蕉", "苹果", "香蕉", "香蕉"]

for key, grp in itertools.groupby(sorted(data)):
    print(key, "->", list(grp))
```

输出：

```
苹果 -> ['苹果', '苹果', '苹果']
香蕉 -> ['香蕉', '香蕉', '香蕉']
```

**记住口诀：`groupby` 之前必 `sorted`**。

## 翻车现场：按自定义键分组时，键和元素一起排序

`groupby` 可以传 `key` 函数，按"某个属性"分组。常见需求是按"首字母"分组：

```python
import itertools

words = ["banana", "apple", "avocado", "cherry", "blueberry"]

# 按首字母分组
for key, grp in itertools.groupby(sorted(words), key=lambda w: w[0]):
    print(key, "->", list(grp))
```

输出：

```
a -> ['apple', 'avocado']
b -> ['banana', 'blueberry']
c -> ['cherry']
```

**关键点**：`sorted` 和 `groupby` 都要传**同样的** `key` 函数。如果排序用了默认规则、分组用了 `key`，两者对"相邻"的定义不一致，结果就会错。

```python
import itertools

words = ["banana", "apple", "avocado", "cherry"]

# WRONG：sorted 没传 key，默认按整词排，分组时按首字母，两者规则不一致
result = itertools.groupby(sorted(words), key=lambda w: w[0])
print([(k, list(g)) for k, g in result])
```

输出（顺序错乱，avocado 跑到 a 组后面）：

```
[('a', ['apple', 'avocado']), ('b', ['banana']), ('c', ['cherry'])]
```

这次碰巧结果还能看，是因为单词首字母恰好就是默认排序的依据。**换成数字、中文、或复合对象，立刻出错**。正确做法是两边都传 `key`：

```python
import itertools

words = ["banana", "apple", "avocado", "cherry", "blueberry"]

key = lambda w: w[0]
for k, grp in itertools.groupby(sorted(words, key=key), key=key):
    print(k, "->", list(grp))
```

## 小结

- `itertools` 的工具返回**迭代器**（惰性），省内存、可组合
- `chain` / `chain.from_iterable`：首尾相接、摊平一层
- `product`：笛卡尔积，`repeat=n` 是同序列自乘 n 次
- `combinations` 不计顺序，`permutations` 计顺序，后者是前者的 k! 倍
- **`groupby` 只归并"相邻"的相等元素，必须先 `sorted`**，否则分组被切碎
- 用自定义 `key` 分组时，`sorted` 和 `groupby` 必须传**同一个 key 函数**
