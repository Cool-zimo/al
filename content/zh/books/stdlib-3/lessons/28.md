## 级别分布：Counter 一行搞定

```python
from collections import Counter

level_counts = Counter(entry.level for entry in entries)
print(level_counts)
print(dict(level_counts))
print(level_counts.most_common())
```

输出：

```
Counter({'INFO': 8, 'ERROR': 8, 'WARN': 3, 'DEBUG': 2})
{'INFO': 8, 'ERROR': 8, 'WARN': 3, 'DEBUG': 2}
[('INFO', 8), (('ERROR', 8), ('WARN', 3), ('DEBUG', 2)]
```

`Counter` 接收一个生成器表达式，自动完成计数。`most_common()` 直接给出排名。

## 时间分布：按小时聚合

```python
hourly = Counter(entry.hour for entry in entries)
for hour in sorted(hourly.keys()):

```

输出：

```

11:00 | █████ (5)
12:00 | ████ (4)
13:00 | ████ (5)
```

这样一眼就能看出 **10 点这个小时日志最密集**，值得重点排查。

## Top N 错误：统计最常见的错误消息

```python
error_messages = Counter(
    entry.message for entry in entries if entry.level == "ERROR"
)
print("Top 5 错误：")
for msg, count in error_messages.most_common(5):
    print(f"  [{count:>2}次] {msg}")
```

输出：

```
Top 5 错误：
  [ 3次] 用户登录失败
  [ 2次] 连接超时
  [ 2次] token 过期
  [ 1次] 支付超时
```

**"用户登录失败"出现了 3 次，是最频繁的错误**——这是运维最该关注的信号。

## 按模块统计：defaultdict 的用武之地

想知道每个模块产生了多少 ERROR：

```python
from collections import defaultdict

module_errors = defaultdict(int)
for entry in entries:
    if entry.level == "ERROR":
        module_errors[entry.module] += 1

# 按数量降序排列
sorted_modules = sorted(module_errors.items(), key=lambda x: x[1], reverse=True)
for module, count in sorted_modules:
    print(f"  {module:<8} {count} 个 ERROR")
```

输出：

```
  auth     4 个 ERROR
  db       2 个 ERROR
  payment  1 个 ERROR
```

`defaultdict(int)` 的好处是**访问不存在的 key 自动返回 0**，不用写 `if key not in dict` 的判断。

## 组合维度：模块 × 级别 交叉表

```python
# 统计每个模块在各别级别的数量
module_level = defaultdict(lambda: defaultdict(int))
for entry in entries:
    module_level[entry.module][entry.level] += 1

print(f"{'模块':<10} {'DEBUG':<8} {'INFO':<8} {'WARN':<8} {'ERROR':<8}")
print("-" * 50)
for module in sorted(module_level.keys()):
    levels = module_level[module]
    print(f"{module:<10} {levels.get('DEBUG', 0):<8} {levels.get('INFO', 0):<8} "
          f"{levels.get('WARN', 0):<8} {levels.get('ERROR', 0):<8}")
```

输出：

```
模块       DEBUG   INFO    WARN    ERROR
--------------------------------------------------
auth       0       0       0       4
cache      2       0       0       0
db         0       0       1       2
order      0       6       0       0
payment    0       0       2       1
```

这张交叉表一眼看出：**order 模块全是 INFO（正常），auth 模块全是 ERROR（异常集中）**。

## 统计模块完整代码

```python
from collections import Counter, defaultdict


def level_distribution(entries: list) -> dict[str, int]:
    """各级别数量"""
    return dict(Counter(e.level for e in entries))


def hourly_distribution(entries: list) -> dict[str, int]:
    """每小时日志数量（按小时排序）"""
    return dict(sorted(Counter(e.hour for e in entries).items()))


def top_errors(entries: list, n: int = 10) -> list[tuple[str, int]]:
    """Top N 错误消息"""
    return Counter(e.message for e in entries if e.level == "ERROR").most_common(n)


def module_error_count(entries: list) -> dict[str, int]:
    """各模块 ERROR 数量（降序）"""
    d = defaultdict(int)
    for e in entries:
        if e.level == "ERROR":
            d[e.module] += 1
    return dict(sorted(d.items(), key=lambda x: x[1], reverse=True))


def module_level_matrix(entries: list) -> dict[str, dict[str, int]]:
    """模块 × 级别 交叉表"""
    result = defaultdict(lambda: defaultdict(int))
    for e in entries:
        result[e.module][e.level] += 1
    return {k: dict(v) for k, v in result.items()}
```

## 翻车现场：用 list.count 在循环里统计

```python
# WRONG：O(n²) 复杂度
levels = [e.level for e in entries]
unique_levels = list(set(levels))
counts = {}
for lvl in unique_levels:
    counts[lvl] = levels.count(lvl)  # 每次 count 都遍历一次列表
print(counts)
```

**问题**：`list.count()` 是 O(n) 操作，外面再套一层循环就是 O(n²)。20 条日志无所谓，200 万条日志就是几十秒的差距。用 `Counter` 一次遍历完成，O(n)。

## 翻车现场：用普通 dict 统计忘记初始化

```python
# WRONG：KeyError
module_errors = {}
for e in entries:
    if e.level == "ERROR":
        module_errors[e.module] += 1  # KeyError: 'auth' 第一次访问不存在的 key
```

**错误输出**：

```
KeyError: 'auth'
```

**两种修复**：

```python
# 方式一：get 带默认值
module_errors[e.module] = module_errors.get(e.module, 0) + 1

# 方式二：defaultdict（推荐）
from collections import defaultdict
module_errors = defaultdict(int)
module_errors[e.module] += 1  # 不存在的 key 自动初始化为 0
```

## 翻车现场：Counter.most_common() 结果不稳定

```python
from collections import Counter

c = Counter()
c["a"] = 2
c["b"] = 2
c["c"] = 1
print(c.most_common())  # [('a', 2), ('b', 2), ('c', 1)]
# 但如果 "b" 先被计数呢？
```

**注意**：当计数相同时，`most_common()` 的排序顺序是**不保证稳定**的（取决于插入顺序）。如果你需要稳定的二次排序（比如按字母序），要自己写：

```python
sorted(c.items(), key=lambda x: (-x[1], x[0]))
# 先按计数降序，再按 key 字母升序
```

## 小结

- `Counter` 是一行搞定频率统计的利器，配合 `most_common()` 直接出排名
- `defaultdict(int)` 省去手动初始化，统计代码更简洁
- 多维度统计 = 组合使用 Counter + defaultdict
- 交叉表（模块 × 级别）是定位问题的利器
- 避免在循环里用 `list.count()`，复杂度 O(n²)
- 统计层输入纯数据、输出纯数据，不涉及文件 IO
