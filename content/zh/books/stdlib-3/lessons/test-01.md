> 8 道题。这一章解决的是"从文本里按模式找东西"的问题——模式怎么写、怎么匹配、怎么替换、怎么切分。

## 第一部分 · 选择题

```quiz
type: choice
q: 要从一段文本里找出所有符合"1 开头 + 10 位数字"的手机号，应该用哪个函数？
code: |
  import re
  text = "电话 13812345678 和 13987654321"
options:
- re.search
- re.match
- re.findall
- re.split
answer: 2
explain: search/match 只返回第一个匹配；findall 返回所有匹配组成的列表；split 是按模式切分。要"所有"，只有 findall 能做到。
```

```quiz
type: choice
q: 下面哪段是合法的原始字符串写法，能正确把正则里的反斜杠原样交给引擎？
code: |
  a = '\d+'
  b = r'\d+'
  c = r"\\d+"
  d = "\\d+"
options:
- a
- b
- c
- d
answer: 1
explain: r'\d+' 是原始字符串，"反斜杠 + d" 两个字符原样进入正则。a 是普通字符串，反斜杠被 Python 解释；c 和 d 都多了一个反斜杠，正则会看到两个反斜杠。
```

```quiz
type: choice
q: 对于字符串 'aaaab'，正则 'a.*b' 会匹配到什么？
options:
- 'aab'
- 'aaab'
- 'aaaab'
- 无匹配
answer: 2
explain: .* 默认贪婪，会尽量多匹配 a，一直吃到最后一个 b 之前，所以是整个 'aaaab'。若写成 a.*?b 则只匹配 'aaab'。
```

```quiz
type: choice
q: re.findall(r'(\d+)-(\d+)', '区间100-200和300-400') 的返回值是？
options:
- ['100-200', '300-400']
- [('100', '200'), ('300', '400')]
- ['100', '200', '300', '400']
- [('100-200',), ('300-400',)]
answer: 1
explain: findall 遇到捕获分组就只返回分组内容；有两个分组就返回二元元组列表。要整段得去掉括号或整体再套一层。
```

```
type: choice
q: 关于 re.sub(r'(\d+)', r'\1\1', '12 34') 的结果，正确的是？
options:
- '12 34'
- '1122 3344'
- '1212 3434'
- 报错
answer: 2
explain: 替换串 \1 引用整段匹配内容（这里每组数字是连续数字），每个数字串被复制一遍拼回原位。'12' 变 '1212'，'34' 变 '3434'。
```

## 第二部分 · 动手题

```quiz
type: function
q: 写一个函数 extract_amounts，接收一个字符串，返回其中所有"数字（可带小数）+元"的金额数字列表，如"苹果5元 香蕉3.5元 西瓜12元"返回[5.0, 3.5, 12.0]。
func: extract_amounts
starter: |
  import re

  def extract_amounts(text):
      return []
cases: |
  "苹果5元 香蕉3.5元" -> [5.0, 3.5]
  "无价格信息" -> []
  "西瓜12元" -> [12.0]
hint: 用 findall 配合模式 r'\d+\.?\d*'，再把结果转成 float。没有匹配时返回空列表。
explain: 提取+类型转换是正则最常见的组合套路：先按模式抠出字符串，再转成业务需要的数字。
```

```quiz
type: function
q: 写一个函数 mask_phone，接收一个字符串，把其中所有 11 位手机号的中间 4 位替换为 ****（保留前 3 位和后 4 位）。
func: mask_phone
starter: |
  import re

  def mask_phone(text):
      return text
cases: |
  "电话13812345678和13987654321" -> "电话138****5678和139****4321"
  "无电话" -> "无电话"
  "电话0571-88123456" -> "电话0571-88123456"
hint: 模式用 r'(1[3-9]\d{3})\d{4}(\d{4})'，替换为 r'\1****\2'。注意替换串加 r 前缀。
explain: 脱敏是 sub + 分组引用的经典实战，替换串的 r 前缀是关键陷阱。
```
