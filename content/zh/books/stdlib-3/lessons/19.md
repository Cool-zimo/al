# argparse 基础：把命令行参数解析得明明白白

> 这一课讲 `argparse` 的基本用法：位置参数、可选参数、`type`、`default`、`help`，以及用 `choices` 做校验。手写 `sys.argv` 的日子可以结束了。

## 为什么不用 sys.argv 手写

手写参数解析是这样的：

```python
import sys

# 想支持：python script.py --name 张三 --age 25
args = sys.argv[1:]   # ['--name', '张三', '--age', '25']

name = None
age = None
for i, a in enumerate(args):
    if a == "--name":
        name = args[i + 1]
    elif a == "--age":
        age = int(args[i + 1])   # 忘记转换类型

print(f"{name}, {age}")
```

**问题一堆**：要自己转类型、要处理缺省值、要写帮助信息、要校验参数合法性、用户输入 `--help` 还得自己响应。这就是 `argparse` 存在的理由。

## 最简单的例子

```python
import argparse

parser = argparse.ArgumentParser(description="处理用户信息的工具")
parser.add_argument("name", help="用户名")
parser.add_argument("--age", type=int, default=18, help="年龄，默认 18")

args = parser.parse_args(["张三", "--age", "25"])
print(f"name={args.name}, age={args.age}")
```

输出：

```
name=张三, age=25
```

**三个要素**：`ArgumentParser` 是容器，`add_argument` 注册参数，`parse_args` 解析。解析结果是一个 `Namespace` 对象，用点号取值。

## 位置参数 vs 可选参数

| 类型 | 写法 | 是否必须 | 例子 |
|---|---|---|---|
| 位置参数 | 不加 `--` | 是 | `name` |
| 可选参数 | 加 `--` | 否（有 default） | `--age` |

```python
import argparse

parser = argparse.ArgumentParser()
parser.add_argument("src", help="源文件路径")          # 位置参数，必填
parser.add_argument("dst", help="目标文件路径")        # 位置参数，必填
parser.add_argument("-v", "--verbose", action="store_true", help="是否详细输出")

args = parser.parse_args(["/tmp/a.txt", "/tmp/b.txt", "-v"])
print(args.src, args.dst, args.verbose)
```

输出：

```
/tmp/a.txt /tmp/b.txt True
```

**`action="store_true"`** 表示这是个开关：出现了就是 `True`，没出现就是 `False`。不用再跟一个值。

## type、default、help 三件套

```python
import argparse

parser = argparse.ArgumentParser()
parser.add_argument("--count", type=int, default=1, help="重复次数（默认 1）")
parser.add_argument("--name", type=str, default="匿名", help="名称")

args = parser.parse_args(["--count", "3", "--name", "张三"])
print(args.count * args.name)
```

输出：

```
张三张三张三
```

**`type=int` 自动转换**，`type=str` 其实可以省略（默认就是字符串）。`default` 在用户不传时使用。

## choices：参数校验

`choices` 限制参数只能取指定的几个值，取错直接报错并提示。

```python
import argparse

parser = argparse.ArgumentParser()
parser.add_argument("--city", choices=["北京", "上海", "广州", "深圳"], help="城市")

args = parser.parse_args(["--city", "杭州"])  # 不在 choices 里
```

输出：

```
usage: xxx.py [-h] [--city {北京,上海,广州,深圳}]
xxx.py: error: argument --city: invalid choice: '杭州' (choose from '北京', '上海', '广州', '深圳')
```

**自动生成报错信息**，不用自己写 `if city not in [...]`。

## 翻车现场：type 转换失败会直接退出

```python
import argparse

parser = argparse.ArgumentParser()
parser.add_argument("--port", type=int, help="端口号")

args = parser.parse_args(["--port", "abc"])  # "abc" 转不了 int
```

输出：

```
usage: xxx.py [-h] [--port PORT]
xxx.py: error: argument --port: invalid int value: 'abc'
```

**argparse 在类型转换失败时会直接调用 `sys.exit()`**，程序终止。这意味着如果你在库代码或交互式环境里用 `parse_args`，一个非法输入就会把整个程序干掉。要安全解析，可以用 `parser.parse_args(args)` 传一个列表而不是依赖 `sys.argv`，或者用 `try/except SystemExit` 捕获。

## 翻车现场：可选参数和位置参数同名

```python
import argparse

parser = argparse.ArgumentParser()
parser.add_argument("name", help="用户名")
parser.add_argument("--name", help="用户名称")  # 和位置参数同名！

parser.parse_args([])
```

输出：

```
usage: xxx.py [-h] [-n NAME] name
xxx.py: error: argument name: conflicting option string: --name
```

**`name` 和 `--name` 会被认为是同一个参数的两种写法**，冲突报错。解决办法：位置参数用名词单数、可选参数加前缀，避免撞名。

## 翻车现场：忘了传必填的位置参数

```python
import argparse

parser = argparse.ArgumentParser()
parser.add_argument("file", help="要处理的文件")
parser.add_argument("--encoding", default="utf-8")

args = parser.parse_args(["--encoding", "gbk"])  # 忘传 file
```

输出：

```
usage: xxx.py [-h] [--encoding ENCODING] file
xxx.py: error: the following arguments are required: file
```

**位置参数是必填的**，没传会报错。这是和可选参数最大的区别——别把"一定需要"的东西做成可选。

## 小结

- `argparse` 三步：创建 `ArgumentParser`、用 `add_argument` 注册、用 `parse_args` 解析
- 位置参数不加 `--`，必填；可选参数加 `--`，可设默认值
- `type` 自动转换类型，`default` 设缺省值，`help` 写说明
- `action="store_true"` 做开关，出现为 True、不出现为 False
- `choices` 限制取值范围，取错自动报错
- 类型转换失败会 `sys.exit()`，交互式环境要注意
- 位置参数和可选参数不能同名，否则冲突
