# 替换与切分：sub 与 split

> 这一课解决"把匹配到的东西改成别的"和"按模式切开"两件事。`re.sub` 能用字符串、能用函数、能引用分组；`re.split` 能按"一个或多个空格"这种不规则分隔符切开。

## re.sub：把匹配到的换成别的

`re.sub(pattern, repl, string)` 三个参数：模式、替换内容、原字符串。返回替换后的新字符串，**不修改原字符串**。

```python
import re

text = "我的电话是 13812345678，备用 13987654321"

# 把所有手机号中间 4 位打成 *
masked = re.sub(r'(1[3-9]\d{3})\d{4}(\d{4})', r'\1****\2', text)
print(masked)
```

输出：

```
我的电话是 1381****5678，备用 1398****4321
```

这个例子用到了**分组引用**：`(1[3-9]\d{3})` 是第 1 组，`(\d{4})` 是第 2 组，替换字符串里的 `\1` `\2` 就代表"第 1、2 组匹配到的内容"。结果是"前四位 + 四个星 + 后四位"，既脱敏又保留可读性。

## 翻车现场：替换串里的 \1 被 Python 字符串吃掉

这是本课最重要的一坑。张三照着教程写脱敏：

```python
import re

text = "电话 13812345678"
# WRONG：没加 r 前缀，'\1' 在 Python 字符串里变成了控制字符
result = re.sub(r'1(\d{3})\d{4}(\d{4})', '\1***\2', text)
print(result)
```

报错或输出乱码：

```
re.error: invalid group reference 1
```

`'\1'` 在普通 Python 字符串里是**八进制转义**（一个不可见字符），根本到不了正则引擎。`\2` 同理。正则的分组引用 `\1` 必须是**原始字符串里的两个字符**。

**正确做法**：替换串也加 `r` 前缀。

```python
import re

text = "电话 13812345678"
result = re.sub(r'1(\d{3})\d{4}(\d{4})', r'\1***\2', text)
print(result)
```

输出：

```
电话 138***5678
```

**记忆口诀**：凡是带反斜杠的正则相关字符串，一律 `r` 前缀——模式串要，`sub` 的替换串也要。

## 用函数做替换：逻辑复杂时的唯一出路

替换内容如果只是一段固定文字，字符串就够了；但如果要根据匹配内容"动态计算"，就得传一个函数给 `repl`。

```python
import re

text = "价格 100 元, 数量 3, 价格 250 元"

def double_price(match):
    # match 是匹配对象，group(1) 是括号里捕获到的数字
    val = int(match.group(1))
    return str(val * 2)

result = re.sub(r'价格 (\d+) 元', double_price, text)
print(result)
```

输出：

```
价格 200 元, 数量 3, 价格 500 元
```

函数的入参是**匹配对象**，返回值（必须是字符串）就是替换内容。这个机制让 `sub` 的威力提升一个量级：格式化、查表、条件判断都能做。

```python
import re

# 把中文数字替换成阿拉伯数字
cn = {"一": "1", "二": "2", "三": "3", "十": "10"}
text = "第 一 章, 第 二 章, 第 十 章"

result = re.sub(r'第 (\S) 章', lambda m: "第 " + cn.get(m.group(1), m.group(1)) + " 章", text)
print(result)
```

输出：

```
第 1 章, 第 2 章, 第 10 章
```

## re.split：按模式切分

`str.split` 只能按一个固定分隔符切。`re.split` 能按"一个或多个空格""连续的逗号或分号"这种**不规则**的分隔符切。

```python
import re

text = "苹果,,香蕉;;橘子,,,西瓜"

# 按连续的一个或多个逗号/分号切
print(re.split(r'[,;]+', text))
```

输出：

```
['苹果', '香蕉', '橘子', '西瓜']
```

注意两端的空字符串：这里因为 `re.split` 的处理，两端不产生空串，但**当模式能匹配到字符串开头或结尾时**，会产生前导/尾随空串：

```python
import re

text = ",,苹果,,香蕉,,"
print(re.split(r'[,;]+', text))        # 开头匹配产生空串
```

输出：

```
['', '苹果', '香蕉', '']
```

**解法**：用 `filter(None, ...)` 或列表推导式 `[x for x in ... if x]` 过滤掉空串。

## 翻车现场：split 的分组决定"是否保留分隔符"

`re.split` 里**如果有捕获分组**，分组内容会一起出现在结果里——这个特性常被忽略。

```python
import re

text = "苹果,香蕉;橘子"

# WRONG：带分组，分隔符也进了结果
print(re.split(r'([,;])', text))
```

输出：

```
['苹果', ',', '香蕉', ';', '橘子']
```

分隔符被当作"捕获内容"插回了结果列表。这有时是想要的（比如要保留分隔符重建），但大多数时候是意外。

**正确做法**：不需要分隔符就用**非捕获分组** `(?:)` 或干脆不加括号。

```python
import re

text = "苹果,香蕉;橘子"
print(re.split(r'[,;]', text))            # 不要分隔符
print(re.split(r'(?:[,;])', text))        # 非捕获，同样不带分隔符
```

输出：

```
['苹果', '香蕉', '橘子']
['苹果', '香蕉', '橘子']
```

## 小结

- `re.sub(pattern, repl, string)` 返回替换后的新串，不改原串
- 替换串里用 `\1` `\2` 引用分组，且**必须加 `r` 前缀**，否则 `\1` 被 Python 当成八进制转义
- `sub` 的 `repl` 可以传函数，入参是匹配对象，返回值是替换字符串——处理动态替换的唯一正规手段
- `re.split` 按"模式"切分，适合不规则、连续的分隔符
- `split` 的模式若带**捕获分组**，分隔符会被插进结果；用 `(?:)` 非捕获分组避免
