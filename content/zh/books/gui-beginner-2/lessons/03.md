# 画文字与图片：create_text 与 PhotoImage

> 画布上不仅能画几何图形，还能写文字、贴图片。这一节讲两个最常用的"内容型"绘图方法，以及一个 tkinter 经典的大坑。

## create_text 写文字

**`create_text(x, y, text="...")` 在指定坐标写文字。注意：这个坐标是文字的"锚点"，默认在文字正中心。**

```python
import tkinter as tk

root = tk.Tk()
canvas = tk.Canvas(root, width=400, height=200, bg="white")
canvas.pack()

canvas.create_text(200, 50, text="你好，Canvas！", font=("SimHei", 24), fill="blue")
canvas.create_text(200, 120, text="Hello, tkinter!", font=("Arial", 16), fill="green")

root.mainloop()
```

常用参数：

| 参数 | 含义 |
|---|---|
| `text` | 要显示的文字 |
| `font` | 字体，元组 `(字体名, 字号, 样式)`，样式可选 `"bold"`/`"italic"` |
| `fill` | 文字颜色 |
| `anchor` | 锚点位置，`tk.CENTER`（默认）、`tk.NW`（左上）等 |
| `justify` | 多行对齐，`tk.LEFT`/`tk.CENTER`/`tk.RIGHT` |

## anchor 锚点决定对齐

**默认 `anchor=tk.CENTER`，坐标 (200, 50) 就是文字正中心。** 如果你想让坐标表示文字左上角，就设 `anchor=tk.NW`：

```python
canvas.create_text(10, 10, text="左上角对齐", anchor=tk.NW, font=("SimHei", 18))
```

锚点常量有八个方向：`N`、`S`、`E`、`W`、`NE`、`NW`、`SE`、`SW`、`CENTER`。**记法**：N 上、S 下、E 右、W 左，组合就是角落。

## 中文字体要指定

**在中文 Windows 上，`font=("SimHei", 20)` 能正常显示中文。在 Linux 或 macOS 上可能显示成方框（缺字体）。**

```python
font=("SimHei", 20)      # 黑体，Windows 常用
font=("Microsoft YaHei", 20)  # 微软雅黑
font=("WenQuanYi Micro Hei", 20)  # Linux 常用
```

**跨平台写界面的经验**：如果不确定用户的字体环境，就用系统默认字体（不指定 font 参数），或者用 tkinter 的 `font.Font` 对象来探测可用字体。本节先记住"中文要指定中文字体"即可。

## 加载图片：PhotoImage

**Canvas 显示图片用 `create_image`，图片对象用 `PhotoImage` 加载：**

```python
import tkinter as tk

root = tk.Tk()
canvas = tk.Canvas(root, width=400, height=300, bg="white")
canvas.pack()

img = tk.PhotoImage(file="demo.png")          # 加载图片
canvas.create_image(200, 150, image=img)      # 把图片贴到画布上

root.mainloop()
```

`create_image(x, y, image=img)` 中 `(x, y)` 是图片中心（默认 `anchor=tk.CENTER`）。

**PhotoImage 支持的格式**：GIF、PGM、PPM、PNG（tkinter 8.6+ 支持 PNG）。JPG 不支持，需要 `Pillow` 库转换。

## 翻车现场一：PhotoImage 引用丢失，图片不显示（最经典的 tkinter bug）

```
import tkinter as tk

root = tk.Tk()
canvas = tk.Canvas(root, width=400, height=300)
canvas.pack()

def load_image():
    img = tk.PhotoImage(file="demo.png")       # 局部变量
    canvas.create_image(200, 150, image=img)

load_image()
root.mainloop()
```

**症状**：窗口能显示，但图片位置是一片空白，没有任何报错。

**原因**：`img` 是 `load_image` 函数里的**局部变量**。函数执行完，`img` 就没有任何地方引用它了，Python 的垃圾回收（GC）把它收走，图片对象被销毁。Canvas 上那个 `create_image` 引用的是"已经消失的对象"，自然显示不出来。

**这是 tkinter 的"悬挂引用"问题，堪称新手第一坑。** 而且 tkinter 不会报任何错，静悄悄地不显示，极难排查。

**修复：保住引用，不让 GC 回收：**

```python
import tkinter as tk

root = tk.Tk()
canvas = tk.Canvas(root, width=400, height=300, bg="white")
canvas.pack()

img = tk.PhotoImage(file="demo.png")          # 提到全局/实例级别
canvas.create_image(200, 150, image=img)

root.mainloop()
```

**或者把图片挂到 Canvas 上，随画布生命周期一起存活：**

```python
canvas.image = img   # 强行让 canvas 持有一个引用
```

**或者在类里存成 `self.img`。核心原则：只要图片还在画布上显示，就必须有某个变量引用着它。**

## 翻车现场二：图片路径错了，但症状"不明显"

```
img = tk.PhotoImage(file="nonexistent.png")
```

**症状**：`tkinter.TclError: couldn't open "nonexistent.png"` —— 这个倒是比较明显，直接报错了。

**但更隐蔽的是路径写对、文件却不在当前工作目录**：`file="demo.png"` 是相对路径，相对于**程序运行时的当前目录**，而不是 `.py` 文件所在目录。用 `os.getcwd()` 打印当前目录，或改用绝对路径能避免这类问题。

## 翻车现场三：PhotoImage 不能加载 JPG

```
img = tk.PhotoImage(file="photo.jpg")
```

**症状**：`tkinter.TclError: couldn't recognize data in image file`。

**tkinter 8.6 以前只支持 GIF/PGM/PPM，8.6+ 加了 PNG 支持，但 JPG 始终不支持。** 解决方法是装 `Pillow`：

```python
from PIL import Image, ImageTk
img = ImageTk.PhotoImage(Image.open("photo.jpg"))
```

**但要小心**：`ImageTk.PhotoImage` 返回的对象同样有引用丢失问题，记得存住引用。

## 图片的 subsample 缩放

**PhotoImage 自带一个简单缩放方法 `subsample`：**

```python
img = tk.PhotoImage(file="big.png")
small = img.subsample(2, 2)   # 宽高各缩为 1/2
tiny  = img.subsample(4, 4)   # 宽高各缩为 1/4
```

`subsample(n, m)` 表示宽缩为 1/n、高缩为 1/m。**它只能做整数倍缩小，不能放大。** 要做任意缩放还得靠 Pillow。

## 小结

- `create_text` 写文字，`font=(字体名, 字号, 样式)`，`anchor` 控制对齐
- 中文必须指定中文字体（SimHei / 微软雅黑）
- `create_image` + `PhotoImage` 显示图片
- **图片引用陷阱**：局部变量 `img` 会被 GC 回收，图片消失 → 提到全局或挂到 canvas 上
- PhotoImage 只支持 GIF/PGM/PPM/PNG，JPG 需 Pillow
- 相对路径相对于"运行时的当前目录"，不是 `.py` 所在目录
