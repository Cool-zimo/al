# 声音与文字：让游戏会响也会说

> 到目前为止，你的游戏是个"哑巴"——只会画方块。这一节给游戏加上音效和文字：吃金币"叮"一声、Game Over 要能在屏幕上显示出来。

## 声音：pygame.mixer 是怎么回事

**pygame 的声音系统叫 `mixer`（混音器）。** 它的工作方式是：先把"播放设备"准备好（初始化），再把声音文件加载成对象，然后随时 `play()`。

```python
import pygame

pygame.mixer.init()                          # 初始化混音器
ding = pygame.mixer.Sound("coin.wav")        # 加载音效
ding.play()                                  # 播放一次
```

**`Sound` 对象一次加载、多次播放。** 它常驻内存，不像音乐那样边读边放。`play()` 可以带参数：

| 写法 | 含义 |
|---|---|
| `ding.play()` | 播 1 次 |
| `ding.play(loops=2)` | 总共播 3 次（原声 + 循环 2 次） |
| `ding.play(loops=-1)` | 无限循环（背景音乐用法） |
| `ding.play(maxtime=500)` | 只播 500 毫秒 |
| `ding.set_volume(0.5)` | 音量 0.0~1.0 |

**背景音乐是另一条通道**，用 `pygame.mixer.music` 这个模块单独管：

```python
pygame.mixer.music.load("bgm.mp3")
pygame.mixer.music.play(-1)          # 无限循环
pygame.mixer.music.set_volume(0.3)
# pygame.mixer.music.stop()
```

**约定**：短音效用 `Sound` + `play()`，长的背景曲用 `music` 模块。两者互不影响。

## 完整示例：按键发声 + 文字

```python
import pygame

pygame.init()
pygame.mixer.init()
screen = pygame.display.set_mode((600, 400))
pygame.display.set_caption("声音与文字")
clock = pygame.time.Clock()

# 用程序生成一个"哔"声，省得没素材也能跑
sample_rate = 22050
sound = pygame.mixer.Sound(buffer=bytes([128] * sample_rate))   # 1 秒静音占位

font = pygame.font.Font(None, 48)               # 默认字体，48 号
text = font.render("Hello Pygame", True, (255, 255, 255))

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_SPACE:
                sound.play()                    # 按空格发声

    screen.fill((30, 30, 60))
    screen.blit(text, (180, 160))
    pygame.display.flip()
    clock.tick(60)

pygame.quit()
```

## 文字：font.render 三步走

**文字不是画出来的线条，而是一张"印着字的图片"。** 所以要分三步：

1. **造字体**：`pygame.font.Font(路径, 字号)` 或 `pygame.font.SysFont(名称, 字号)`
2. **渲染成 Surface**：`font.render(字符串, 抗锯齿, 颜色)`
3. **贴到屏幕上**：`screen.blit(surface, 位置)`

```python
font = pygame.font.Font(None, 72)                       # None = 默认字体
img = font.render("得分 100", True, (255, 200, 0))      # 抗锯齿开，金色
screen.blit(img, (250, 100))
```

**`render` 的第二个参数 `True` 表示开抗锯齿**，字边缘更平滑；第三个参数是前景色。**想要背景色，传第四个参数**：`render("Hi", True, 前景, 背景)`。

## 翻车现场一：中文全是豆腐块（乱码/方块）

```python
font = pygame.font.Font(None, 48)
img = font.render("游戏结束", True, (255, 255, 255))
screen.blit(img, (100, 100))
```

**症状**：屏幕上中文位置出现空白，或者一坨"口口口"方块、问号，英文字母却正常。

**原因**：`Font(None)` 用的是 pygame 自带的默认字体，它**不含中文字形**。它不认识"游"字，就画不出，要么留空要么画成缺字符号。

**正确写法：指定一个带中文的字体文件。**

```python
# Windows
font = pygame.font.Font("C:/Windows/Fonts/msyh.ttc", 48)      # 微软雅黑
# macOS
font = pygame.font.Font("/System/Library/Fonts/PingFang.ttc", 48)
# 跨平台保险写法：用 SysFont 查可用中文名
font = pygame.font.SysFont("noto sans cjk sc", 48)            # Linux 常见
```

**如果不确定机器上有啥字体，先列出来看看：**

```python
print(pygame.font.get_fonts())      # 返回系统可用字体的小写名称列表
```

**最稳妥的方案是把字体文件（`.ttf`）和 `main.py` 放一起，用相对路径加载**——这样别人下载你的代码也能跑，不依赖他的系统装了什么。

## 翻车现场二：mixer 没 init 就加载声音

```python
import pygame
pygame.init()                       # 只 init 了主模块
ding = pygame.mixer.Sound("coin.wav")
```

**症状**：`pygame.error: mixer not initialized`。

**原因**：`pygame.init()` 会初始化大部分模块，但 `mixer` 的初始化参数（采样率、声道数）通常需要单独指定，所以稳妥做法是**显式再调一次 `pygame.mixer.init()`**。另外 Sound 只认 `WAV`、`OGG` 这类格式，**直接 `Sound("a.mp3")` 也可能报错**（看 pygame 编译时的音频后端）。

**保险写法**：声音用 `.wav` 或 `.ogg`；播放前先判断文件存在。

## 翻车现场三：render 传了中文引号或换行

```python
img = font.render("第一行\n第二行", True, (255,255,255))
```

**症状**：`\n` 被当成普通字符画出个小方块，或者整段错乱。`font.render` **不支持多行文本**。

**想写多行文字，要自己一行一行渲染、一行一行 blit，算好行距：**

```python
lines = ["得分 100", "最高 250", "按 R 重开"]
y = 100
for line in lines:
    img = font.render(line, True, (255, 255, 255))
    screen.blit(img, (200, y))
    y += img.get_height() + 8        # 行距 = 字高 + 8 像素
```

## 翻车现场四：音量设成 100

```python
ding.set_volume(100)        # 合法，但……
```

**症状**：声音爆音、刺耳失真，或报 `ValueError: volume must be between 0.0 and 1.0`。

**`set_volume` 的范围是 0.0 到 1.0**（小数，代表"倍数"），不是 0~100。写成 `set_volume(0.6)`。

## 小结

- 声音两条路：短音效用 `Sound` + `play()`，背景曲用 `mixer.music`
- 播放前必须 `pygame.mixer.init()`，素材优先用 `.wav`/`.ogg`
- 文字是图片：`Font` 造字体 → `render` 成 Surface → `blit` 贴上屏
- 中文必须指定中文字体文件，别用 `Font(None)`
- `render` 不支持换行，多行要自己分行渲染、累加 y
- 音量是 0.0~1.0 的小数，不是百分比
