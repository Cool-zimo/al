# 画基本图形：矩形、椭圆、线、多边形

> 上一节认识了画布，这一节正式开始"画画"。tkinter 提供了一套简单的绘图指令，学会这几个就能画出大部分界面元素。

## 五种最常用的图形

**Canvas 能画的核心图形就这几个，记住它们就够了：**

| 方法 | 画什么 | 参数形式 |
|---|---|---|
| `create_rectangle(x1,y1,x2,y2)` | 矩形 | 左上角 + 右下角 |
| `create_oval(x1,y1,x2,y2)` | 椭圆 | 外接矩形对角 |
| `create_line(x1,y1,x2,y2,...)` | 直线 | 多个点依次连线 |
| `create_polygon(x1,y1,x2,y2,...)` | 多边形 | 所有顶点 |
| `create_arc(x1,y1,x2,y2)` | 圆弧 | 外接矩形对角 |

**注意：椭圆、圆弧都是用"外接矩形"来定位的。** 你给一个矩形框，tkinter 在这个框里画最大的椭圆。

## 矩形与椭圆

```python
import tkinter as tk

root = tk.Tk()
canvas = tk.Canvas(root, width=400, height=300, bg="white")
canvas.pack()

# 矩形
canvas.create_rectangle(20, 20, 120, 80, fill="tomato")
# 椭圆（外接矩形 150,20 到 300,100）
canvas.create_oval(150, 20, 300, 100, fill="gold")

root.mainloop()
```

**`fill` 是填充色，`outline` 是边框色。** 默认有黑色边框，想要无边框就写 `outline=""`。

```python
canvas.create_oval(50, 120, 150, 220, fill="green", outline="")  # 无边框的实心圆
```

## 线：多段连起来就是折线

**`create_line` 可以接受任意多个点，依次相连：**

```python
# 画一个 "Z" 字形
canvas.create_line(10, 130, 90, 130, 10, 190, 90, 190, fill="blue", width=3)
```

常用参数：

| 参数 | 含义 |
|---|---|
| `fill` | 线条颜色 |
| `width` | 线宽（像素） |
| `dash` | 虚线样式，如 `(5, 3)` 表示 5 画 3 空 |
| `arrow` | 箭头，`tk.FIRST`/`tk.LAST`/`tk.BOTH` |
| `smooth` | 设为 True 会把折线变成平滑曲线 |

```python
canvas.create_line(10, 10, 50, 50, 90, 10, 130, 50, smooth=True, fill="purple", width=2)
```

## 多边形

**`create_polygon` 和 `create_line` 类似，但会自动把最后一个点和第一个点连起来，形成闭合图形：**

```python
# 画一个三角形
canvas.create_polygon(200, 20, 250, 100, 150, 100, fill="orange", outline="red")
```

参数顺序就是顶点依次排列：`x1,y1, x2,y2, x3,y3...`。

**多边形也支持 `fill` 和 `outline`**，还能用 `smooth=True` 做平滑变形。

## fill 与 outline 的默认值

**很多人画出来的图形"不是自己想要的颜色"，问题往往出在这里：**

```python
canvas.create_rectangle(10, 10, 100, 80)  # 什么颜色？
```

**默认是 `fill=""`（不填充，透明） + `outline="black"`（黑色边框）。** 所以上面这句画出的是一个"只有黑色边框、里面空的"矩形。

**记住这条经验法则**：

- 想实心填充 → 必须显式写 `fill="颜色"`
- 想无边框 → 必须显式写 `outline=""`
- 边框粗细 → `width=N`（默认 1）

## 翻车现场一：颜色的字符串写错导致图形不显示

```
canvas.create_rectangle(10, 10, 100, 80, fill=tomato)
```

**症状**：报错 `NameError: name 'tomato' is not defined`，程序直接崩。

**原因**：颜色必须是**字符串**。`tomato` 不加引号就是变量名，Python 会去找叫 tomato 的变量，找不到就报错。

正确写法：

```python
canvas.create_rectangle(10, 10, 100, 80, fill="tomato")
```

**tkinter 支持的颜色名**包括 `"red"`、`"blue"`、`"green"`、`"yellow"`、`"orange"`、`"purple"`、`"pink"`、`"gray"`、`"black"`、`"white"`，以及更细的如 `"lightblue"`、`"darkgreen"`、`"tomato"`、`"gold"` 等。也支持十六进制：`fill="#ff6600"`。

## 翻车现场二：以为画完还能改，其实是"新画"

```
canvas = tk.Canvas(root, width=400, height=300)
canvas.create_rectangle(10, 10, 100, 80, fill="red")
canvas.create_rectangle(10, 10, 100, 80, fill="blue")  # 又画了一个盖在上面
```

**很多人以为第二句会"修改"第一个矩形，其实是在同一个位置又画了一个新的蓝色矩形，盖住了红色的。** Canvas 的图形一旦画出就独立存在，要改它得用 `coords()`、`itemconfig()` 等方法（第 4 课讲）。

## 翻车现场三：坐标超出画布看不到

```
canvas.create_oval(500, 500, 600, 600, fill="red")  # 画布只有 400x300
```

**图形被画在了画布之外，屏幕上什么也看不到，程序也不报错。** 这是 Canvas 最"安静"的一类 bug——不会报错，就是看不到。调试时用 `canvas.bbox(item_id)` 可以拿到图形的实际边界框，确认它是否在可视范围内。

## 用 RGB 十六进制颜色

**除了颜色名，用 `#rrggbb` 能精确控制颜色：**

```python
canvas.create_rectangle(10, 10, 80, 60, fill="#3498db")   # 一种蓝
canvas.create_rectangle(10, 70, 80, 120, fill="#e74c3c")  # 一种红
canvas.create_rectangle(10, 130, 80, 180, fill="#2ecc71") # 一种绿
```

**六位十六进制分三段：前两位红、中两位绿、后两位蓝**，每位的取值 00~ff（0~255）。`#ff0000` 纯红，`#0000ff` 纯蓝，`#000000` 黑，`#ffffff` 白。

## 小结

- 矩形、椭圆用**对角两点**定位；椭圆是"外接矩形里的最大椭圆"
- 线用 `create_line` 多段连，多边形 `create_polygon` 自动闭合
- `fill` 填色、`outline` 边框、`width` 线宽、`dash` 虚线
- 默认 `fill=""` 透明 + `outline="black"` 黑边，要实心必须写 fill
- 颜色要加引号，支持颜色名或 `#rrggbb`
- 图形画在画布外不报错也不显示，是"安静 bug"
