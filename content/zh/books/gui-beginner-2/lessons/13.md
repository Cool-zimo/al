# Treeview 表格：列、行、插入数据、选中事件

> ttk 的 Treeview 是一个"树形+表格"控件。它可以当表格用（显示多行多列数据），也能做树形展开。这一节聚焦最常见的用法：做一个能展示数据的表格。

## Treeview 是什么

**Treeview 既能显示"树"（可展开折叠的层级），也能显示"表"（多列多行）。** 当成表格用时，第一列是隐藏的树列，其余列是我们定义的列。

```python
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.title("表格示例")

# 定义列：#0 是默认树列，另外定义 name/age/city 三列
columns = ("name", "age", "city")
tree = ttk.Treeview(root, columns=columns, show="headings")

# 设置列标题
tree.heading("name", text="姓名")
tree.heading("age", text="年龄")
tree.heading("city", text="城市")

tree.pack()
root.mainloop()
```

**`show="headings"` 表示"只显示我们定义的列，不显示左侧树列"**，这是表格模式的标准写法。

## 插入行：insert

**用 `tree.insert(parent, index, values=...)` 插入一行。** 表格模式下 `parent=""`（顶层，无父节点）：

```python
tree.insert("", "end", values=("张三", 25, "北京"))
tree.insert("", "end", values=("李四", 30, "上海"))
tree.insert("", "end", values=("王五", 28, "广州"))
```

**参数**：`parent` 是父节点（`""` 表示根）、`index` 是位置（`"end"` 追加到末尾）、`values` 是这一行的各列值。

## 设置列宽和对齐

**用 `tree.column(列名, width=..., anchor=...)` 调整列宽和对齐：**

```python
tree.column("name", width=100, anchor="w")   # 左对齐
tree.column("age", width=60, anchor="center")
tree.column("city", width=100, anchor="w")
```

**`anchor` 取值**：`"w"` 左对齐、`"e"` 右对齐、`"center"` 居中。数字列一般居中，文字列左对齐。

## 完整表格示例

```python
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.title("学生名单")

columns = ("name", "age", "city")
tree = ttk.Treeview(root, columns=columns, show="headings")

for col, text, w in zip(columns, ["姓名", "年龄", "城市"], [100, 60, 100]):
    tree.heading(col, text=text)
    tree.column(col, width=w, anchor="center")

students = [("张三", 25, "北京"), ("李四", 30, "上海"),
            ("王五", 28, "广州"), ("赵六", 22, "深圳")]
for s in students:
    tree.insert("", "end", values=s)

tree.pack(padx=10, pady=10)
root.mainloop()
```

**运行：一个带表头的表格，四行数据。**

## 选中事件：<<TreeviewSelect>>

**绑定 `<<TreeviewSelect>>` 事件，能在用户选中某行时拿到选中项：**

```python
def on_select(event):
    selection = tree.selection()      # 选中的行 ID 列表
    if selection:
        item_id = selection[0]
        values = tree.item(item_id)["values"]
        print("选中：", values)

tree.bind("<<TreeviewSelect>>", on_select)
```

**关键方法：**

| 方法 | 作用 |
|---|---|
| `tree.selection()` | 返回选中行 ID 的元组 |
| `tree.item(id)` | 返回该行的完整信息字典，含 `values` |
| `tree.focus()` | 返回当前焦点行 ID |

## 翻车现场一：忘了 show="headings"，多出一列空白

```
tree = ttk.Treeview(root, columns=columns)   # 缺 show
```

**症状**：表格最左边多出一列空白的"树列"，我们的数据从第 2 列开始。

**原因**：默认 `show=("tree", "headings")`，会显示左侧树列。要纯表格必须 `show="headings"`。

## 翻车现场二：insert 的 values 和列数不对应

```
tree.insert("", "end", values=("张三",))      # 只有 1 个值，却有 3 列
```

**症状**：不会报错，但那一行只有第一列有值，其余列空白。

**对策**：插入前确保 `values` 元组长度和列数一致。批量插入时可以用 `zip` 保证对齐。

## 翻车现场三：selection 可能为空

```
def on_select(event):
    item = tree.selection()[0]   # IndexError
```

**症状**：`IndexError: tuple index out of range`。用户取消选中（比如点了表头）时 `selection()` 返回空元组。

**修复**：先判断非空：

```python
def on_select(event):
    sel = tree.selection()
    if not sel:
        return
    values = tree.item(sel[0])["values"]
```

## 删除行

**`tree.delete(id)` 删除指定行，`tree.delete(*tree.get_children())` 清空所有行：**

```python
# 删单行
tree.delete(item_id)

# 清空整个表格
for item in tree.get_children():
    tree.delete(item)
```

**`get_children()` 返回所有顶层行的 ID 列表。**

## 修改行内容

**`tree.item(id, values=...)` 可以修改某行的值：**

```python
tree.item(item_id, values=("张三", 26, "北京"))   # 改这一行
```

**也可以只改某个单元格**（先读再写）：

```python
old = tree.item(item_id)["values"]
tree.item(item_id, values=(old[0], 99, old[2]))
```

## 排序：点表头排序

**给表头绑定点击事件，按该列排序并重新插入：**

```python
def sort_by(col, descending):
    data = [(tree.set(child, col), child) for child in tree.get_children("")]
    data.sort(reverse=descending)
    for idx, (val, child) in enumerate(data):
        tree.move(child, "", idx)   # 调整顺序
    tree.heading(col, command=lambda: sort_by(col, not descending))

for col in columns:
    tree.heading(col, command=lambda c=col: sort_by(c, False))
```

**`tree.set(child, col)` 读取某行某列的值，`tree.move` 调整行顺序。** 这是一个实用的"点表头排序"功能。

## 小结

- Treeview 既是树又是表；`show="headings"` 用纯表格模式
- `columns` 定义列，`heading` 设标题，`column` 设宽和 align
- `insert("", "end", values=...)` 插入行
- `<<TreeviewSelect>>` 选中事件，`selection()` 拿 ID，`item(id)["values"]` 拿数据
- 删行 `delete(id)`，清空 `delete(*get_children())`
- 改行 `item(id, values=...)`，排序用 `set` + `move`
