# Canvas 是什么：一个能画画的空白区域

> 之前我们用的控件都是"现成的"——按钮就是按钮，标签就是标签。但如果你想画一个圆形、画一条线、做一个能拖动的滑块，就得用 Canvas。它是 tkinter 里最自由的一个控件。

## Canvas 是 tkinter 的"画布"

**Canvas（画布）本质上是一个矩形空白区域，你可以在上面画任意图形、放文字和图片。** 它是 tkinter 里唯一一个"你想画什么就画什么"的控件。

之前的 Label、Button 都是"预制件"，长相和功能基本固定。Canvas 则是"空白纸"——你可以用它做出进度条、流程图、简易画板、甚至小游戏。

**为什么需要它？** 因为你迟早会遇到"标准控件做不出来"的需求：画一个圆角矩形按钮、在图片上标注几个点、做一个拖拽式的连线工具。这些全靠 Canvas。

## 创建 Canvas 并显示出来

**和所有控件一样，先创建，再布局：**

```python
import tkinter as tk

root = tk.Tk()
root.title("我的画布")

# 创建一块 400x300 的画布，背景白色
canvas = tk.Canvas(root, width=400, height=300, bg="white")
canvas.pack()

root.mainloop()
```

运行后会看到一个白色的大方块。现在上面什么都没有——**画布本身不画任何东西，它只是提供"画的地方"**。

参数说明：

| 参数 | 含义 |
|---|---|
| `width` / `height` | 画布的宽高（像素） |
| `bg` | 背景色，默认浅灰 |
| `highlightthickness` | 选中边框的厚度，设为 0 可去掉虚线框 |

## 坐标系：原点在左上角

**这是 Canvas 最重要的一条规则：坐标原点 `(0, 0)` 在左上角，x 轴向右增大，y 轴向下增大。**

这和数学里的坐标系不一样。数学里 y 轴向上增大，但在屏幕/画布里，**越往下，y 值越大**。

```python
# 画一个矩形，左上角在 (50, 30)，右下角在 (200, 120)
canvas.create_rectangle(50, 30, 200, 120, fill="skyblue")
```

这四个数字的含义是：`x1, y1, x2, y2`——**左上角坐标 + 右下角坐标**。

```python
import tkinter as tk

root = tk.Tk()
canvas = tk.Ck()  # 这里故意写错，见下方翻车现场
```

## 翻车现场一：把 Canvas 写成 Ck / ck

```
AttributeError: module 'tkinter' has no attribute 'Ck'
```

**很多人手快写成 `tk.Ck()` 或 `tk.ck()`。** tkinter 的控件名是 `Canvas`，首字母大写，其余小写。记住口诀：**控件名都是大驼峰**，第一个字母大写，后面每个单词首字母也大写（Canvas、Button、Label、Frame、Scale）。

正确写法：

```python
canvas = tk.Canvas(root, width=400, height=300)
```

## 翻车现场二：坐标写反，图形"消失"在画布外

```
canvas.create_rectangle(300, 250, 50, 30, fill="red")
```

**症状**：运行后画布上一片空白，什么都没画出来。

**原因**：虽然 tkinter 会自动把坐标"纠正"成左上-右下，但如果你把第二个点写到画布尺寸之外（比如画布只有 300 宽，你却从 x=500 开始画），图形就跑到可视区域外了。

**对策**：养成习惯，始终用 `(x1, y1, x2, y2)` 表示"小坐标在前、大坐标在后"，且坐标不要超过画布的宽高。

## 画布大小 vs 窗口大小

**画布的 `width/height` 是固定的像素值，不会随窗口拉伸自动变化。** 如果你希望画布随窗口缩放，需要配合 `pack(fill="both", expand=True)` 让它占满空间，但这只影响"控件占位"，**画布内部的绘图区域坐标仍是创建时设定的那些**。

```python
canvas = tk.Canvas(root, width=400, height=300, bg="white")
canvas.pack(fill="both", expand=True)
```

这里的 `fill="both"` 是让画布控件铺满父容器，`expand=True` 是让它在窗口变大时也跟着撑开。但**已画上去的图形不会自动重绘或缩放**——这是 Canvas 的一个重要限制，做可缩放画板时需要自己处理。

## 图形都有"ID"

**每次在画布上画一个图形，tkinter 都会返回一个整数 ID。** 这个 ID 是后续操作图形的"身份证"：

```python
rect_id = canvas.create_rectangle(10, 10, 100, 80, fill="orange")
print(rect_id)  # 输出 1（第一个图形 ID 通常是 1）
oval_id = canvas.create_oval(120, 10, 200, 80, fill="green")
print(oval_id)  # 输出 2
```

**ID 从 1 开始递增**，每画一个图形 +1。你可以把 ID 存到变量里，后面用它来移动、改色、删除图形（下一课细讲）。

## 小结

- Canvas 是 tkinter 里唯一能**自由绘图**的控件
- 坐标系**原点在左上角，y 轴向下增大**
- 矩形/图形用 `(x1, y1, x2, y2)` 表示左上角和右下角
- 画布大小固定，缩放需自己处理
- 每个图形返回一个唯一 ID，是后续操作的"身份证"
- 控件名大驼峰：`tk.Canvas`，别写成 `tk.Ck`
