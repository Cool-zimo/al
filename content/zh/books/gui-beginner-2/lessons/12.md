# ttk 的主题与样式：Style、theme_use、configure

> 上一节知道 ttk 控件外观由主题管理。这一节学怎么切换主题、怎么用 `ttk.Style()` 定制控件样式。

## 主题是什么

**主题是"一套控件外观规则"的集合。** ttk 内置几个主题，不同平台可用主题不同：

| 主题名 | 风格 | 常见平台 |
|---|---|---|
| `clam` | 扁平、可定制 | 跨平台，常用 |
| `alt` | 经典复古 | 跨平台 |
| `default` | tkinter 默认 | 跨平台 |
| `classic` | 最老样式 | 跨平台 |
| `vista` | Windows Vista/7 | Windows |
| `xpnative` | Windows XP | Windows |
| `winnative` | 原生 Windows | Windows |
| `aqua` | macOS 原生 | macOS |

**用 `ttk.Style().theme_names()` 查看当前平台有哪些主题。**

## 查看和切换主题

```python
import tkinter as tk
from tkinter import ttk

root = tk.Tk()

style = ttk.Style()
print(style.theme_names())     # 列出可用主题
print(style.theme_use())       # 当前主题名

style.theme_use("clam")        # 切换到 clam 主题
```

**切换主题必须在创建控件之前**，否则已创建的控件不会自动更新。

```python
style.theme_use("clam")        # 先切主题
ttk.Button(root, text="确定").pack()   # 再建控件
```

## 用 Style.configure 定制

**`Style.configure(样式名, **选项)` 修改某类控件的样式。** 样式名就是控件类名（小写）：

```python
style = ttk.Style()
style.theme_use("clam")

# 定制所有 TButton 的外观
style.configure("TButton",
                foreground="white",
                background="#3498db",
                font=("SimHei", 12),
                padding=8)

ttk.Button(root, text="蓝色按钮").pack(padx=10, pady=10)
```

**`TButton` 是 Button 的样式类名**，`TLabel`、`TEntry`、`TFrame` 同理。前缀 `T` 是 ttk 的命名约定。

## 常用样式选项

| 选项 | 含义 |
|---|---|
| `foreground` | 前景色（文字） |
| `background` | 背景色 |
| `fieldbackground` | 输入框内部背景（Entry、Combobox） |
| `font` | 字体 |
| `padding` | 内边距（像素或四边） |
| `relief` | 边框样式（flat、raised、sunken） |
| `borderwidth` | 边框宽度 |

```python
style.configure("TEntry",
                fieldbackground="lightyellow",
                borderwidth=2)
```

## 自定义样式名（继承）

**除了改全局 `TButton`，还可以定义一个"新样式"并让某个控件用上：**

```python
style.configure("Danger.TButton",
                foreground="white",
                background="#e74c3c",
                padding=10)

ttk.Button(root, text="删除", style="Danger.TButton").pack()
ttk.Button(root, text="取消").pack()   # 用默认 TButton 样式
```

**`Danger.TButton` 是自定义名，`.TButton` 后缀表示"继承 TButton 的布局"**。这样你能同时拥有"普通按钮"和"危险操作红色按钮"。

## 翻车现场一：background 对按钮不生效

```
style.configure("TButton", background="red")
```

**症状**：某些主题下（特别是 Windows 原生主题），按钮背景色没变。

**原因**：部分原生主题（如 `vista`、`aqua`）用系统绘图方式，忽略 `background`。**解决：切换到 `clam` 主题**，`clam` 支持自定义背景色。

```python
style.theme_use("clam")
style.configure("TButton", background="red", foreground="white")
```

**经验法则：想深度定制外观，就用 `clam` 主题。**

## 翻车现场二：忘写 `clam`，颜色还是没变

**切换主题必须在创建控件之前**，这是个高频错误：

```
style = ttk.Style()
ttk.Button(root, text="A").pack()   # 先创建了控件
style.theme_use("clam")             # 后切换主题，已创建的按钮不受影响
```

**修复：把 `theme_use` 提到最前，在所有控件创建之前。**

## 翻车现场三：样式名大小写/拼写错

```
style.configure("tbutton", ...)      # 小写，不生效
style.configure("Button", ...)       # 缺少 T 前缀，不生效
```

**正确的样式类名是首字母大写加 `T`：`TButton`、`TLabel`、`TEntry`。**

**自定义名可以是任意字符串，但后缀要指明继承谁**：`"Danger.TButton"`、`"Bold.TLabel"`。

## 用 map 做状态样式

**控件有不同状态：正常、鼠标悬停（active）、按下（pressed）、不可用（disabled）。`Style.map` 可以按状态设置不同样式：**

```python
style.map("TButton",
          foreground=[("active", "white"), ("disabled", "gray")],
          background=[("active", "#2980b9"), ("disabled", "#cccccc")])
```

**语法**：`选项名=[(状态, 值), ...]`。上面表示：鼠标悬停时背景变深蓝，禁用时变灰。

**这是做"交互反馈"的正道**，比手动绑定 `<Enter>`/`<Leave>` 改颜色规范得多。

## 一个完整例子

```python
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.title("样式示例")

style = ttk.Style()
style.theme_use("clam")

style.configure("TButton",
                foreground="white",
                background="#3498db",
                padding=10,
                font=("SimHei", 12))
style.map("TButton",
          background=[("active", "#2980b9")])

style.configure("TLabel",
                font=("SimHei", 14),
                foreground="#2c3e50")

ttk.Label(root, text="主题样式示例").pack(padx=20, pady=15)
ttk.Button(root, text="主按钮").pack(padx=20, pady=10)
ttk.Button(root, text="禁用", state="disabled").pack(padx=20, pady=10)

root.mainloop()
```

## 小结

- 主题 = 一套外观规则；`theme_use("clam")` 切主题（要建控件前切）
- 用 `ttk.Style().theme_names()` 看可用主题
- `Style.configure("TButton", ...)` 改全局样式
- 自定义样式：`"Danger.TButton"`，后缀指定继承
- 想自定义背景色就用 `clam` 主题
- 状态样式用 `Style.map`：悬停、按下、禁用各一套
- 样式类名：`TButton`、`TLabel`、`TEntry` 等
