# 键盘控制：bind 按键事件，方向键移动方块

> 游戏需要键盘操作。这一节学 tkinter 的键盘事件绑定，做一个能用方向键（上下左右）移动的方块。

## 键盘事件的三种绑定对象

**键盘事件可以绑在"具体控件"上，也可以绑在"整个窗口（root）"上。** 区别是：绑在控件上时，必须那个控件获得焦点（被选中）按键才生效；绑在 root 上则全局生效。

```python
import tkinter as tk

root = tk.Tk()
root.title("键盘移动")

def on_key(event):
    print("按下了：", event.keysym)

# 绑在 root 上：全局生效
root.bind("<Key>", on_key)
root.mainloop()
```

**事件对象 `event` 的关键属性：**

| 属性 | 含义 |
|---|---|
| `event.keysym` | 键的符号名，如 `"Left"`、`"a"`、`"Return"`、`"space"` |
| `event.keycode` | 键的数字编码（不同平台可能不同） |
| `event.char` | 可打印字符，如 `"a"`、`"!"`；方向键等无字符 |

## 常用的键名

**方向键和特殊键用符号名：**

| 事件字符串 | 对应按键 |
|---|---|
| `<Left>` / `<Right>` / `<Up>` / `<Down>` | 方向键 |
| `<Return>` | 回车 |
| `<space>` | 空格 |
| `<Escape>` | Esc |
| `<Key>` | 任意键 |
| `<KeyPress-a>` | 字母 a（区分大小写用） |
| `<Control-c>` | Ctrl+C |

**也可以写 `<KeyPress>`（按下）和 `<KeyRelease>`（松开）**。

## 第一步：画一个方块

```python
import tkinter as tk

root = tk.Tk()
root.title("方向键移动")
canvas = tk.Canvas(root, width=400, height=300, bg="white")
canvas.pack()

rect = canvas.create_rectangle(180, 130, 220, 170, fill="dodgerblue")
```

## 第二步：绑定方向键

**四个方向键各绑定一个函数，用 `move` 移动：**

```python
step = 10

def move_left(event):
    canvas.move(rect, -step, 0)

def move_right(event):
    canvas.move(rect, step, 0)

def move_up(event):
    canvas.move(rect, 0, -step)

def move_down(event):
    canvas.move(rect, 0, step)

root.bind("<Left>", move_left)
root.bind("<Right>", move_right)
root.bind("<Up>", move_up)
root.bind("<Down>", move_down)

root.mainloop()
```

**运行：按方向键，方块会按步长移动。**

## 翻车现场一：绑定在 Canvas 上但 Canvas 没焦点

```
canvas.bind("<Left>", move_left)   # 按方向键没反应
```

**症状**：明明绑了，按方向键方块就是不动。

**原因**：焦点在别的控件或窗口上。Canvas 绑定的事件只在它自己获得焦点时生效。

**修复**：绑在 `root` 上，或让 Canvas 获取焦点：

```python
root.bind("<Left>", move_left)   # 绑 root，全局生效
# 或
canvas.focus_set()               # 让 canvas 拿到焦点
```

**做游戏时几乎总是绑在 `root` 上**，避免焦点问题。

## 翻车现场二：函数多了一个参数没地方传

```
root.bind("<Left>", move_left)

def move_left(event, step=10):   # 多个默认参数没事
    ...
```

```
def move_left(event, direction):  # 报错
    ...
root.bind("<Left>", move_left)
```

**症状**：`TypeError: move_left() missing 1 required positional argument: 'direction'`。

**原因**：`bind` 只会在调用时传一个 `event` 参数。你的函数需要额外参数就没法从 bind 拿到。

**解决**：用 `lambda` 或默认参数：

```python
def move_rect(event, dx, dy):
    canvas.move(rect, dx, dy)

root.bind("<Left>", lambda e: move_rect(e, -10, 0))
root.bind("<Right>", lambda e: move_rect(e, 10, 0))
```

**这个套路在 pygame 里也会遇到（第 24 课讲连续按键）。**

## 翻车现场三：方块移出画布外

**一直按方向键，方块会移出画布、看不见。用 `coords` 读取位置做限制：**

```python
def move_left(event):
    x1, y1, x2, y2 = canvas.coords(rect)
    if x1 > 0:                    # 还在画布内才允许左移
        canvas.move(rect, -step, 0)
```

**更严谨的写法**：

```python
def move_left(event):
    x1, y1, x2, y2 = canvas.coords(rect)
    new_x = max(0, x1 - step)     # 不小于 0
    canvas.coords(rect, new_x, y1, new_x + (x2-x1), y2)
```

**用 `coords` 绝对定位 + `max/min` 做钳制（clamp），是游戏边界处理的通用手法。**

## 用一个字典统一处理

**四个方向写四个函数有点啰嗦，可以用字典把键名映射到位移：**

```python
step = 10
key_map = {
    "Left":  (-step, 0),
    "Right": (step, 0),
    "Up":    (0, -step),
    "Down":  (0, step),
}

def on_key(event):
    dx, dy = key_map.get(event.keysym, (0, 0))
    canvas.move(rect, dx, dy)

root.bind("<Key>", on_key)
```

**`event.keysym` 正好是 `"Left"` 等字符串，和字典键对得上。** 这种"查表法"在处理多种输入时非常清晰。

## 用 dt 让移动速度帧率无关

**结合上一节的 delta time，让方块"每秒移动 200 像素"而不是"每次按键跳 10 像素"：**

```python
import time

speed = 200.0
rect_x, rect_y = 180.0, 130.0
last_time = time.time()

def on_key(event):
    global rect_x, rect_y, last_time
    now = time.time()
    dt = now - last_time
    last_time = now
    if dt > 0.1:
        dt = 0
    dx, dy = key_map.get(event.keysym, (0, 0))
    rect_x += dx * speed * dt / 10    # 这里 dx 是 ±1 的方向
    rect_y += dy * speed * dt / 10
    canvas.coords(rect, rect_x, rect_y, rect_x+40, rect_y+40)
```

**但注意**：键盘事件是"离散触发"的（按一次触发一次），不像动画每帧都跑。dt 在这里意义有限，更常见的是 pygame 的"持续按压"处理（第 24 课）。

## 小结

- 键盘事件：`root.bind("<Key>", handler)`，事件对象有 `keysym`/`keycode`/`char`
- 方向键 `<Left>`/`<Right>`/`<Up>`/`<Down>`，回车 `<Return>`，空格 `<space>`
- 绑在 `root` 上全局生效；绑在控件上需要该控件有焦点
- 函数只接收一个 `event` 参数；要多参数用 `lambda`
- 边界限制：用 `coords` 读位置 + `max/min` 钳制
- 多按键用字典查表，代码更整洁
