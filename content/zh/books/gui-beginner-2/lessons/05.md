# 实战：一个能画能清的画板

> 前面几课零散学了 Canvas 的画法和操作，这一节串起来做一个真正能用的东西——鼠标拖动画线的画板。核心是"事件 + 坐标 + 画线"。

## 我们要做什么

**目标：鼠标在画布上拖动时留下笔迹，点按钮清空画布。**

```
界面：
[ 清屏 ]                    ← Button
┌─────────────────┐
│                 │        ← Canvas（鼠标拖动在这里画线）
│   笔迹在这里     │
│                 │
└─────────────────┘
```

**关键动作**：鼠标按下时"落笔"，拖动时"连续画线"，松开时"抬笔"。这正好对应三个鼠标事件。

## 第一步：搭界面骨架

**Canvas + Button，布局用 pack：**

```python
import tkinter as tk

root = tk.Tk()
root.title("简易画板")

canvas = tk.Canvas(root, width=500, height=400, bg="white")
canvas.pack()

tk.Button(root, text="清屏").pack()

root.mainloop()
```

运行出来一个白色画布加一个按钮。**现在什么都画不了**，因为还没绑定鼠标事件。

## 第二步：理解三个鼠标事件

**鼠标在 Canvas 上有三个关键事件：**

| 事件 | 触发时机 | 我们用来做什么 |
|---|---|---|
| `<ButtonPress-1>` | 按下左键 | 记录"落笔点" |
| `<B1-Motion>` | 按住左键拖动 | 从上一点画到当前点 |
| `<ButtonRelease-1>` | 松开左键 | 结束本次笔画 |

**`<B1-Motion>` 的 `B1` 就是 Button 1（左键）**，按住移动期间会**高频触发**，每触发一次我们就画一小段线。

## 第三步：用全局变量记录"上一个点"

**核心思路：拖动时每次拿到当前坐标，和"上一个点"连成一条短线，然后把当前点更新为"上一个点"。** 这样连续的小线段就拼成了笔迹。

```python
last_x, last_y = None, None   # 上一个点的坐标

def on_press(event):
    global last_x, last_y
    last_x, last_y = event.x, event.y   # 落笔：记录起点

def on_drag(event):
    global last_x, last_y
    x, y = event.x, event.y
    # 从 (last_x, last_y) 画到 (x, y)
    canvas.create_line(last_x, last_y, x, y, width=2, fill="black")
    last_x, last_y = x, y               # 更新"上一个点"

def on_release(event):
    global last_x, last_y
    last_x, last_y = None, None         # 抬笔：重置
```

**事件对象 `event` 带坐标**：`event.x` 和 `event.y` 是相对于**绑定控件的左上角**坐标，正好可以直接喂给 Canvas。

## 第四步：绑定事件

**用 `canvas.bind(事件名, 函数)` 把事件和处理函数连起来：**

```python
canvas.bind("<ButtonPress-1>", on_press)
canvas.bind("<B1-Motion>", on_drag)
canvas.bind("<ButtonRelease-1>", on_release)
```

**bind 的函数必须接收一个参数（事件对象）。** 即使你不用 `event`，形参也得写上，否则触发时报 `TypeError`。

## 第五步：清屏按钮

**清空画布用 `canvas.delete("all")`：**

```python
def clear():
    canvas.delete("all")

tk.Button(root, text="清屏", command=clear).pack()
```

## 完整成品

```python
import tkinter as tk

root = tk.Tk()
root.title("简易画板")

canvas = tk.Canvas(root, width=500, height=400, bg="white")
canvas.pack()

last_x, last_y = None, None

def on_press(event):
    global last_x, last_y
    last_x, last_y = event.x, event.y

def on_drag(event):
    global last_x, last_y
    x, y = event.x, event.y
    canvas.create_line(last_x, last_y, x, y, width=2, fill="black")
    last_x, last_y = x, y

def on_release(event):
    global last_x, last_y
    last_x, last_y = None, None

def clear():
    canvas.delete("all")

canvas.bind("<ButtonPress-1>", on_press)
canvas.bind("<B1-Motion>", on_drag)
canvas.bind("<ButtonRelease-1>", on_release)

tk.Button(root, text="清屏", command=clear).pack()

root.mainloop()
```

**运行：按住鼠标拖动，能画出连续的线条；点"清屏"，画布被清空。** 这就是一个最小可用的画板。

## 翻车现场一：忘了 mainloop，窗口一闪而过

```
import tkinter as tk
root = tk.Tk()
canvas = tk.Canvas(root, width=500, height=400)
canvas.pack()
# 忘记写 root.mainloop()
```

**症状**：程序"跑完了"但什么窗口都没看到，或者立刻退出。

**原因**：`mainloop()` 是 tkinter 的事件循环，没它就没有界面、没有事件响应。这是所有 tkinter 程序的前提。

## 翻车现场二：拖动时只画"点"不画线

```
def on_drag(event):
    x, y = event.x, event.y
    canvas.create_line(x, y, x, y, width=2, fill="black")  # 起点终点相同
```

**症状**：拖动鼠标只留下一串稀疏的小点，而不是连续的线。

**原因**：`create_line(x, y, x, y)` 起点终点一样，画出的是"零长度线段"，几乎看不见。正确做法是从"上一个点"画到"当前点"：`create_line(last_x, last_y, x, y, ...)`。

## 翻车现场三：全局变量忘写 global

```
def on_press(event):
    last_x, last_y = event.x, event.y   # UnboundLocalError
```

**症状**：点击时 `UnboundLocalError: local variable 'last_x' referenced before assignment`。

**原因**：函数里给 `last_x` 赋值，Python 就把它当成局部变量。但赋值前它就去读自己（或解释器判定有赋值就全当局部），就会报错。**解决方案**：函数内第一次使用全局变量前写 `global last_x, last_y`。三个函数都要写。

## 翻车现场四：清屏太狠，把背景也删了

**如果画布上有固定的背景元素（比如网格线、边框装饰），`delete("all")` 会连同它们一起删掉。** 解决方法是给笔迹打 tag，只删笔迹：

```python
def on_drag(event):
    global last_x, last_y
    x, y = event.x, event.y
    canvas.create_line(last_x, last_y, x, y, width=2, fill="black", tags="stroke")
    last_x, last_y = x, y

def clear():
    canvas.delete("stroke")   # 只删笔迹
```

## 升级：支持选择颜色

**加几个颜色按钮，点哪个就把当前画笔色改成那个颜色：**

```python
pen_color = "black"

def set_color(color):
    global pen_color
    pen_color = color

def on_drag(event):
    global last_x, last_y
    x, y = event.x, event.y
    canvas.create_line(last_x, last_y, x, y, width=2, fill=pen_color)
    last_x, last_y = x, y

color_frame = tk.Frame(root)
color_frame.pack()
tk.Button(color_frame, text="黑", command=lambda: set_color("black")).pack(side="left")
tk.Button(color_frame, text="红", command=lambda: set_color("red")).command = ...
```

**小细节**：`command=lambda: set_color("red")` 是带参数回调的标准写法（第 1 册讲过）。

## 小结

- 画板三事件：`<ButtonPress-1>` 落笔、`<B1-Motion>` 拖动、`<ButtonRelease-1>` 抬笔
- 用全局变量 `last_x/last_y` 记录上一次坐标，拖动时连成线段
- 事件函数必须接收 `event` 参数，`event.x/event.y` 是相对坐标
- `canvas.delete("all")` 清屏；要保留背景就给笔迹打 tag 只删 tag
- 别忘了 `mainloop()`；函数内改全局变量要写 `global`
- 颜色选择用全局变量 `pen_color` + lambda 回调
