# Sprite 与 Group：为什么要有精灵类

> 前面我们用一堆变量（x、y、speed、color）管理一个角色。当角色多了、逻辑复杂了，这种"散装状态"会失控。这一节引入 pygame 的 Sprite 和 Group，用面向对象的方式管理游戏对象。

## 为什么需要 Sprite

**回想之前的"玩家方块"，状态散落在各个变量里：**

```python
player_x = 375
player_y = 275
player_size = 50
player_speed = 4
player_color = (255, 0, 0)
```

**再加敌人、道具、子弹……变量数爆炸，代码变成一团乱麻。** 更糟的是，你还得自己维护一个"所有对象列表"，遍历更新、遍历绘制。

**Sprite（精灵）是 pygame 提供的一个基类，专门用来表示一个"游戏对象"**——它把位置、图片、碰撞、更新、绘制这些通用能力封装好了。

## Sprite 的基本用法

**自定义精灵继承 `pygame.sprite.Sprite`：**

```python
import pygame

class Player(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()                        # 必须调用父类初始化
        self.image = pygame.Surface((50, 50))
        self.image.fill((255, 0, 0))
        self.rect = self.image.get_rect()
        self.rect.center = (400, 300)

    def update(self):
        self.rect.x += 4                          # 每帧向右
        if self.rect.right >= 800:
            self.rect.left = 0
```

**两个核心属性：**

| 属性 | 含义 |
|---|---|
| `self.image` | 这个精灵的 Surface（长什么样） |
| `self.rect` | 这个精灵的 Rect（在哪、多大） |

**约定**：pygame 的碰撞检测和绘制都默认用 `sprite.rect`，所以**必须**设置 `self.rect`。

## Group：管理一群精灵

**`pygame.sprite.Group` 是一个"精灵容器"，帮你批量更新和绘制：**

```python
all_sprites = pygame.sprite.Group()

player = Player()
all_sprites.add(player)

# 主循环里：
all_sprites.update()          # 调用每个精灵的 update()
all_sprites.draw(screen)      # 把每个精灵的 image 按 rect 位置 blit 到 screen
```

**这一句 `all_sprites.draw(screen)` 替代了你之前手写的循环 blit**，而且内部做了优化。

## 完整示例

```python
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
clock = pygame.time.Clock()

class Player(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.image = pygame.Surface((50, 50))
        self.image.fill((255, 0, 0))
        self.rect = self.image.get_rect(center=(400, 300))

    def update(self):
        self.rect.x += 4
        if self.rect.left >= 800:
            self.rect.right = 0

player = Player()
all_sprites = pygame.sprite.Group(player)

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    all_sprites.update()

    screen.fill((0, 0, 0))
    all_sprites.draw(screen)
    pygame.display.flip()
    clock.tick(60)

pygame.quit()
```

## 翻车现场一：忘了调用 super().__init__()

```
class Player(pygame.sprite.Sprite):
    def __init__(self):
        self.image = pygame.Surface((50, 50))
        # 忘记 super().__init__()
```

**症状**：`AttributeError: 'Player' object has no attribute '_Sprite__g'`（或后续 add 时报错）。

**原因**：`Sprite.__init__()` 会初始化内部数据结构（比如 Groups 集合）。不调用，Sprite 处于"半成品"状态，后续 `add` 或 `update` 都会出问题。

**务必在 `__init__` 第一行写 `super().__init__()`。**

## 翻车现场二：忘了设置 self.rect

```
class Player(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.image = pygame.Surface((50, 50))
        # 忘记 self.rect
```

**症状**：`AttributeError: 'Player' object has no attribute 'rect'`，或碰撞、draw 时报错。

**原因**：`Group.draw()` 靠 `sprite.rect` 知道往哪 blit；碰撞检测也靠 rect。不设 rect 就等于"有样子没位置"。

## 翻车现场三：update 方法没定义

```
player = Player()
all_sprites.add(player)
all_sprites.update()        # 什么都没发生
```

**如果 Player 没定义 `update` 方法，`all_sprites.update()` 什么也不做**（不报错，因为 Sprite 基类有个空的 update）。这是"静默无操作"，调试时容易困惑。

**想让精灵动起来，必须自己写 `update(self)` 方法。**

## 多个精灵：一个 Group 统一管理

**往 Group 里加多个精灵，批量处理：**

```python
class Enemy(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()
        self.image = pygame.Surface((40, 40))
        self.image.fill((0, 255, 0))
        self.rect = self.image.get_rect(center=(x, y))

    def update(self):
        self.rect.y += 2

enemies = pygame.sprite.Group()
for i in range(5):
    enemies.add(Enemy(100 + i*120, 50))

# 主循环
enemies.update()
enemies.draw(screen)
```

**每个 Group 可以分管一类对象**：玩家一个 Group、敌人一个、子弹一个，逻辑清晰。

## 用 pygame.draw 还是 Surface

**小方块用 `pygame.Surface((w,h))` 画纯色图很快。** 但正式项目里精灵通常是加载图片：

```python
class Player(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.image = pygame.image.load("player.png").convert_alpha()
        self.rect = self.image.get_rect(center=(400, 300))
```

**用图片时别忘了 `convert_alpha()`**（第 19 课讲过）。

## 小结

- Sprite 把"样子(image)+位置(rect)+行为(update)"封装成一个对象
- 必须：`super().__init__()` + 设置 `self.image` + 设置 `self.rect`
- Group 批量管理：`add`、`update()`、`draw(screen)`
- 想让精灵动，自己写 `update(self)` 方法
- 不同类别的对象用不同 Group 分管
- 多个精灵 = 多个对象 + 一个 Group，告别散装变量
