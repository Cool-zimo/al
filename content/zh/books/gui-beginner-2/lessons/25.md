# 实战：接球小游戏（挡板 + 球 + 计分）

> 把第 18~24 课的知识点串起来，做一个完整的接球游戏：挡板用方向键左右移动，球随机落下，接住加分，漏球扣分，有开始/结束界面。

## 我们要做什么

**游戏规则：**

```
┌─────────────────────┐
│ 得分: 0   生命: 3     │
│                     │
│      o              │   ← 球随机落下
│                     │
│           ████      │   ← 挡板（方向键控制）
└─────────────────────┘
```

| 要素 | 说明 |
|---|---|
| 球 | 从顶部随机 x 位置生成，匀速下落 |
| 挡板 | 底部，方向键左右移动 |
| 接球 | 球碰挡板 → 得分 +1，球重置 |
| 漏球 | 球落地 → 生命 -1，球重置 |
| 结束 | 生命为 0 → 游戏结束 |

## 第一步：定义精灵类

```python
import pygame
import random

pygame.init()
WIDTH, HEIGHT = 800, 600
screen = pygame.display.set_mode((WIDTH, HEIGHT))
clock = pygame.time.Clock()

# 颜色
BLACK = (0, 0, 0)
WHITE = (255, 255, 255)
BLUE = (0, 150, 255)
RED = (255, 60, 60)
GREEN = (60, 220, 100)

class Paddle(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.image = pygame.Surface((120, 20))
        self.image.fill(BLUE)
        self.rect = self.image.get_rect(center=(WIDTH//2, HEIGHT - 40))
        self.speed = 400        # px/s

    def update(self, keys, dt):
        if keys[pygame.K_LEFT]:
            self.rect.x -= self.speed * dt
        if keys[pygame.K_RIGHT]:
            self.rect.x += self.speed * dt
        self.rect.clamp_ip(screen.get_rect())

class Ball(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.image = pygame.Surface((24, 24))
        self.image.fill(WHITE)
        self.rect = self.image.get_rect()
        self.reset()

    def reset(self):
        self.rect.centerx = random.randint(20, WIDTH - 20)
        self.rect.y = 0
        self.vy = random.randint(250, 400)

    def update(self, dt):
        self.rect.y += self.vy * dt
```

## 第二步：游戏状态和主循环

```python
paddle = Paddle()
paddle_group = pygame.sprite.Group(paddle)

ball = Ball()
ball_group = pygame.sprite.Group(ball)

score = 0
lives = 3
font = pygame.font.SysFont(None, 36)

running = True
while running:
    dt = clock.tick(60) / 1000
    keys = pygame.key.get_pressed()

    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    paddle_group.update(keys, dt)
    ball_group.update(dt)

    # 接球检测
    if pygame.sprite.spritecollide(paddle, ball_group, dokill=False):
        score += 1
        ball.reset()

    # 漏球检测
    if ball.rect.top > HEIGHT:
        lives -= 1
        if lives <= 0:
            running = False
        else:
            ball.reset()

    # 渲染
    screen.fill(BLACK)
    paddle_group.draw(screen)
    ball_group.draw(screen)

    score_text = font.render(f"得分: {score}  生命: {lives}", True, WHITE)
    screen.blit(score_text, (10, 10))

    pygame.display.flip()

pygame.quit()
```

**运行：一个球从顶部落下，用方向键移动挡板接住，接住得分，漏了扣命，三条命用完游戏结束。**

## 第三步：加开始界面

**用简单的"状态变量"控制流程：**

```python
state = "start"      # "start" 或 "playing"

while running:
    dt = clock.tick(60) / 1000
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_SPACE:
                if state == "start" or state == "gameover":
                    # 重新开始
                    state = "playing"
                    score = 0
                    lives = 3
                    ball.reset()

    if state == "start":
        screen.fill(BLACK)
        title = font.render("接球游戏", True, WHITE)
        hint = font.render("按空格开始", True, GREEN)
        screen.blit(title, (WIDTH//2 - 60, HEIGHT//2 - 40))
        screen.blit(hint, (WIDTH//2 - 70, HEIGHT//2 + 20))
    elif state == "playing":
        keys = pygame.key.get_pressed()
        paddle_group.update(keys, dt)
        ball_group.update(dt)
        if pygame.sprite.spritecollide(paddle, ball_group, dokill=False):
            score += 1
            ball.reset()
        if ball.rect.top > HEIGHT:
            lives -= 1
            if lives <= 0:
                state = "gameover"
            else:
                ball.reset()
        screen.fill(BLACK)
        paddle_group.draw(screen)
        ball_group.draw(screen)
        screen.blit(font.render(f"得分: {score}  生命: {lives}", True, WHITE), (10, 10))
    elif state == "gameover":
        screen.fill(BLACK)
        over = font.render(f"游戏结束！得分: {score}", True, RED)
        hint = font.render("按空格再来一局", True, GREEN)
        screen.blit(over, (WIDTH//2 - 120, HEIGHT//2 - 40))
        screen.blit(hint, (WIDTH//2 - 110, HEIGHT//2 + 20))

    pygame.display.flip()
```

**`state` 变量控制显示哪个界面**，按空格在 start/gameover 时进入 playing。

## 翻车现场一：球"卡"在挡板上连续加分

```
if pygame.sprite.spritecollide(paddle, ball_group, dokill=False):
    score += 1
    ball.reset()
```

**症状**：球一碰到挡板，分数疯狂飙升。

**原因**：球还在挡板范围内，下一帧又判为碰撞，反复加分。虽然这里调了 `ball.reset()` 把球移到顶部，一般能避免——但**如果 reset 后球位置仍在碰撞范围内**（比如 y=0 但挡板也很高），就会复发。

**修复**：加分后确保球"彻底离开"碰撞区。可以加个标记：

```python
if ball.rect.colliderect(paddle.rect) and not ball.caught:
    score += 1
    ball.caught = True
    ball.reset()
# 在 reset 里设 caught=False
```

## 翻车现场二：重置球时忘记重置速度

```
def reset(self):
    self.rect.centerx = random.randint(20, WIDTH-20)
    self.rect.y = 0
    # 忘记重置 vy，速度一直是 0 或旧值
```

**球会停在顶部不动（如果上次漏球时 vy 没变倒没事，但习惯上 reset 要完整）。**

**修复**：reset 里重置所有相关状态：`centerx`、`y`、`vy`。

## 翻车现场三：state 判断写错导致按空格没反应

```
if state = "start":     # SyntaxError
```

**这是 Python 基础错误**：判断用 `==`，赋值用 `=`。在状态机里频繁切换状态时容易手滑。

## 升级：球速随分数变快

**难度递增：**

```python
def reset(self):
    self.rect.centerx = random.randint(20, WIDTH-20)
    self.rect.y = 0
    base_speed = 250 + score * 20          # 随分数变快
    self.vy = random.randint(base_speed, base_speed + 150)
```

**每得一分，基础速度加 20，难度自然递增。**

## 小结

- 接球游戏 = 挡板（键盘移动）+ 球（下落）+ 碰撞计分 + 生命
- 精灵类封装 `image`/`rect`/`update`
- 用 `spritecollide` 检测接球，`rect.top > HEIGHT` 检测漏球
- 状态变量 `state` 管理开始/进行/结束界面
- reset 要重置完整状态（位置 + 速度）
- 球速随分数递增增加难度
