# 图形的操作：move、coords、itemconfig 与 tag

> 图形画上去不是"死"的。这一节学四个核心操作：移动、改坐标、改属性、删除，以及用"标签"批量管理一组图形。

## 图形 ID 是操作的钥匙

**前面讲过，每画一个图形都会返回一个整数 ID。** 所有操作都靠这个 ID：

```python
import tkinter as tk

root = tk.Tk()
canvas = tk.Canvas(root, width=400, height=300, bg="white")
canvas.pack()

rect = canvas.create_rectangle(10, 10, 60, 50, fill="orange")
oval = canvas.create_oval(80, 10, 140, 70, fill="skyblue")
print(rect, oval)   # 输出 1 2
```

**`rect` 和 `oval` 就是 ID**，后面用它们来操作这两个图形。

## move：相对移动

**`canvas.move(id, dx, dy)` 让图形相对当前位置移动 `dx` 像素（x 方向）、`dy` 像素（y 方向）：**

```python
canvas.move(rect, 30, 0)   # 向右移 30
canvas.move(oval, 0, 20)   # 向下移 20
```

**这是动画的基础**——每移动一小步、刷新一次，图形就"动"起来了（第 7 课详细讲）。

`dx/dy` 可以是负数：负 dx 向左，负 dy 向上。

## coords：绝对定位

**`canvas.coords(id, x1, y1, x2, y2)` 直接把图形"搬到"新的坐标位置。** 和 `move` 的区别：`move` 是"再走几步"，`coords` 是"直接传送到那里"。

```python
canvas.coords(rect, 100, 100, 160, 140)  # rect 现在在 (100,100)-(160,140)
```

**两种用法要分清：**

| 方法 | 语义 | 典型场景 |
|---|---|---|
| `move(id, dx, dy)` | 相对移动 | 动画、拖拽 |
| `coords(id, x1, y1, x2, y2)` | 绝对定位 | 精确摆放、重置位置 |

**不传新坐标时，`coords(id)` 返回当前坐标列表**：`[x1, y1, x2, y2]`。这招很实用，用来读取图形当前位置。

```python
x1, y1, x2, y2 = canvas.coords(rect)   # 解包拿到四个坐标
```

## itemconfig：动态改属性

**`canvas.itemconfig(id, **options)` 在图形画好后还能改它的颜色、边框等属性。** 这相当于"画完再化妆"。

```python
rect = canvas.create_rectangle(10, 10, 60, 50, fill="gray")

# 鼠标移上去变红
canvas.itemconfig(rect, fill="red", outline="black", width=3)
```

可改的属性就是创建时那些：`fill`、`outline`、`width`、`dash`、`state` 等。

**`state` 是个好东西**：设为 `"hidden"` 图形消失，设为 `"disabled"` 变灰不可交互，设为 `"normal"` 恢复。

```python
canvas.itemconfig(rect, state="hidden")    # 隐藏
canvas.itemconfig(rect, state="normal")    # 显示
```

## delete：删除图形

**`canvas.delete(id)` 删除指定图形；`canvas.delete("all")` 删除所有图形。**

```python
canvas.delete(rect)        # 删掉这一个
canvas.delete("all")       # 清屏
```

**"清屏"在画板、游戏里非常常用。** 但要小心：`delete("all")` 会把背景网格、固定 UI 一起删掉，实际项目里要给"不该被删的东西"加上 tag（下面讲）。

## 翻车现场一：itemconfig 写错属性名

```
canvas.itemconfig(rect, colour="red")   # 报错
```

**症状**：`_tkinter.TclError: unknown option "-colour"`。

**原因**：tkinter 用的是美式拼写 `color`，不是英式 `colour`。同理 `fill`（不是 `colour`）、`outline`。这跟 Python 关键字无关，是 Tcl/Tk 底层的参数名。

## 翻车现场二：对已经 delete 的 ID 再操作

```
canvas.delete(rect)
canvas.itemconfig(rect, fill="red")   # 报错了吗？
```

**实际上 tkinter 不会报错**，对已被删除的 ID 调用 `itemconfig`/`move` 是"静默无操作"。这既是不报错的好消息，也是隐患——你以为改成功了，画面却没变，很难排查。

**对策**：自己维护一个"还活着"的 ID 集合，删除时同步从集合里移除。做复杂画板时这个习惯能省很多调试时间。

## tag：给图形贴标签

**tag（标签）是一个字符串，可以贴给一个或多个图形，用来批量操作。** 类似 HTML 里的 class。

```python
# 创建时给 tag
c1 = canvas.create_rectangle(10, 10, 50, 50, fill="red", tags="enemy")
c2 = canvas.create_rectangle(70, 10, 110, 50, fill="blue", tags="enemy")
c3 = canvas.create_oval(130, 10, 170, 50, fill="green", tags="player")

# 批量操作：所有带 "enemy" 标签的都变灰
canvas.itemconfig("enemy", fill="gray")

# 批量移动所有 enemy
canvas.move("enemy", 0, 30)
```

**一个图形可以有多个 tag**，用空格分隔：`tags="enemy boss"`。判断某图形有没有某 tag：`canvas.gettags(id)` 返回它的 tag 列表。

## 用 tag 解决"误删背景"的问题

**给不该被删的东西打上特殊 tag，清屏时避开它们：**

```python
# 背景网格用 tag "grid"，清空时只删 "all" 再重画网格
canvas.create_line(0, 0, 400, 0, tags="grid")   # 假设画了网格
# 清屏但不删网格：
for item in canvas.find_all():
    if "grid" not in canvas.gettags(item):
        canvas.delete(item)
```

**更简单的做法是 `canvas.delete("obj")`** 只删带 `"obj"` 标签的图形，保留其他。实际画板项目里，通常把"用户画的笔迹"统一打 tag `"stroke"`，清屏就 `canvas.delete("stroke")`，干净利落。

## 小结

- 图形 ID 是操作的钥匙：`move`/`coords`/`itemconfig`/`delete`
- `move(id, dx, dy)` 相对移动；`coords` 绝对定位，不传参时读取坐标
- `itemconfig` 动态改 fill/outline/width/state
- `delete(id)` 删单个，`delete("all")` 清屏
- 属性名是美式拼写：`fill`、`outline`，别写 `colour`
- **tag 是批量管理的利器**：创建时 `tags="xxx"`，操作时用 tag 代替 ID
