# 安装与第一个窗口：pygame.init、display.set_mode、事件循环 quit

> 从这一节开始进入 pygame。先装库、建窗口、写出能正常关闭的"最小可运行程序"——这是所有 pygame 项目的起点。

## 安装 pygame

**用 pip 安装：**

```bash
pip install pygame
```

**验证安装：**

```python
import pygame
print(pygame.ver)
```

能打印出版本号（如 `2.5.2`）就说明装好了。

**常见坑：**

| 情况 | 现象 | 解决 |
|---|---|---|
| 装到了别的 Python | `import pygame` 报 ModuleNotFoundError | 用对应解释器的 pip：`python -m pip install pygame` |
| 多个 Python 版本 | 装到了 py3.11 但用的是 3.12 | 确认运行环境和安装环境一致 |
| 权限问题 | Linux/macOS 提示 permission denied | 加 `--user` 或虚拟环境 |

## 最小窗口程序

```python
import pygame

pygame.init()                               # 初始化所有模块
screen = pygame.display.set_mode((800, 600)) # 创建窗口
pygame.display.set_caption("我的第一个游戏")  # 标题栏

running = True
while running:
    for event in pygame.event.get():         # 处理事件队列
        if event.type == pygame.QUIT:        # 点关闭按钮
            running = False

    screen.fill((255, 255, 255))            # 用白色填充画面
    pygame.display.flip()                   # 刷新显示

pygame.quit()                               # 退出
```

**逐步拆解：**

1. `pygame.init()`：初始化 pygame 的各个模块（显示、声音、输入等）。必须放在最前面。
2. `display.set_mode((宽, 高))`：创建窗口，返回一个 Surface 对象（画面）。
3. 事件循环：不断从 `pygame.event.get()` 取事件，判断是不是 QUIT。
4. `screen.fill()`：每帧用背景色清空画面（不填的话会残影）。
5. `pygame.display.flip()`：把这一帧画面上屏。
6. `pygame.quit()`：退出时清理资源。

## 窗口尺寸与颜色

**`set_mode((width, height))` 的参数是元组 `(宽, 高)`，单位是像素。**

**颜色用 RGB 元组 `(R, G, B)`，每个分量 0~255：**

```python
BLACK = (0, 0, 0)
WHITE = (255, 255, 255)
RED   = (255, 0, 0)
GREEN = (0, 255, 0)
BLUE  = (0, 0, 255)
```

**用常量定义颜色是 pygame 的通用习惯**，让代码可读性更好。

## 翻车现场一：忘了处理 QUIT，窗口关不掉

```python
import pygame
pygame.init()
screen = pygame.display.set_mode((800, 600))

while True:
    screen.fill((255, 255, 255))
    pygame.display.flip()
    # 忘记处理事件
```

**症状**：窗口弹出来，点右上角 × 没反应，任务栏也关不掉，只能杀进程。

**原因**：pygame 需要你在循环里处理事件队列。不处理 QUIT 事件，操作系统发来的"关闭"请求就被忽略了。更严重的是，长期不处理事件队列会导致程序"无响应"。

**修复**：循环里必须 `for event in pygame.event.get()`，并判断 `QUIT`。

## 翻车现场二：忘了 pygame.init()

```
import pygame
screen = pygame.display.set_mode((800, 600))   # video system not initialized
```

**症状**：`pygame.error: video system not initialized`。

**原因**：`set_mode` 依赖 pygame 的视频子系统，必须先 `pygame.init()` 初始化。

## 翻车现场三：display 写成 Display / display

```
pygame.Display.set_mode((800,600))   # AttributeError
pygame.display.Set_Mode((800,600))  # AttributeError
```

**pygame 的模块名和方法名都是小写**：`pygame.display.set_mode`。记住小写。

## 翻车现场四：flip 写成 flop 或忘了调用

```python
screen.fill((255, 255, 255))
# 忘记 pygame.display.flip()
```

**症状**：窗口黑屏或内容不更新。

**原因**：pygame 是"双缓冲"机制——你画的都在后台缓冲区，`flip()` 才把它翻到前台。不 flip 就永远看不到。

**相关方法**：`pygame.display.flip()` 整屏刷新；`pygame.display.update(rect)` 只刷新指定区域（更省资源）。

## 翻车现场五：set_mode 传了整数不是元组

```
screen = pygame.display.set_mode(800, 600)   # TypeError
```

**`set_mode` 只接受一个参数（尺寸元组），必须写成 `(800, 600)`。**

## 加上一个颜色常量和退出提示

**更规范的写法，把颜色抽成常量、循环清晰：**

```python
import pygame

pygame.init()

WIDTH, HEIGHT = 800, 600
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("白底窗口")

WHITE = (255, 255, 255)

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
    screen.fill(WHITE)
    pygame.display.flip()

pygame.quit()
print("游戏结束")
```

## 用事件类型常量

**pygame 的事件用常量表示，常用的：**

| 常量 | 含义 |
|---|---|
| `pygame.QUIT` | 关闭窗口 |
| `pygame.KEYDOWN` | 按键按下 |
| `pygame.KEYUP` | 按键松开 |
| `pygame.MOUSEMOTION` | 鼠标移动 |
| `pygame.MOUSEBUTTONDOWN` | 鼠标按下 |
| `pygame.MOUSEBUTTONUP` | 鼠标松开 |

**判断按键：**

```python
for event in pygame.event.get():
    if event.type == pygame.KEYDOWN:
        if event.key == pygame.K_ESCAPE:
            running = False
        elif event.key == pygame.K_SPACE:
            print("跳跃")
```

**`pygame.K_xxx` 是键码常量**，如 `K_LEFT`、`K_RIGHT`、`K_UP`、`K_DOWN`、`K_a`、`K_SPACE`、`K_ESCAPE`。

## 小结

- 安装：`pip install pygame`，验证 `import pygame; print(pygame.ver)`
- 最小程序：`init` → `set_mode` → 事件循环 → `fill` + `flip` → `quit`
- `set_mode((宽, 高))` 参数是元组，返回 Surface
- 颜色用 RGB 元组，建议抽成常量
- **必须处理 QUIT 事件**，否则窗口关不掉
- 必须 `flip()` 才看得到画面
