# 碰撞检测：rect.colliderect、spritecollide

> 游戏里最常见的需求："球碰到挡板了吗？""子弹打中敌人了吗？"这一节学 pygame 的碰撞检测工具——从最简单的 Rect 碰撞，到精灵组之间的批量检测。

## 矩形碰撞：colliderect

**两个 Rect 是否相交，用 `rect1.colliderect(rect2)`：**

```python
rect1 = pygame.Rect(100, 100, 50, 50)
rect2 = pygame.Rect(130, 130, 50, 50)
print(rect1.colliderect(rect2))   # True（有重叠）
```

**返回 True 表示两个矩形有重叠区域，即"碰上了"。** 这是 2D 游戏最基础的碰撞检测，简单、快。

## 精灵之间的碰撞

**Sprite 有 `rect` 属性，所以直接用 rect 做碰撞：**

```python
class Player(pygame.sprite.Sprite):
    ...

class Enemy(pygame.sprite.Sprite):
    ...

player = Player()
enemy = Enemy()

if player.rect.colliderect(enemy.rect):
    print("撞上了！")
```

**注意**：`colliderect` 要求两边都是 Rect 对象。精灵本身不是 Rect，要用 `sprite.rect`。

## spritecollide：精灵和精灵组的碰撞

**`pygame.sprite.spritecollide(精灵, 组, dokill)` 检测一个精灵和一组精灵的碰撞，返回碰撞到的精灵列表：**

```python
class Player(pygame.sprite.Sprite):
    ...

class Coin(pygame.sprite.Sprite):
    ...

player = Player()
coins = pygame.sprite.Group(Coin(), Coin(), Coin())

# 检测玩家碰到了哪些金币
hits = pygame.sprite.spritecollide(player, coins, dokill=True)
# dokill=True：碰到的从组里删掉（回收金币）
# hits 是列表，长度就是碰到的数量
score += len(hits)
```

**三个参数**：要检测的精灵、目标组、是否删除碰到的。

**这是 pygame 最常用的碰撞方式**——一个主体对一群对象的碰撞。

## groupcollide：两组精灵互相碰撞

**`pygame.sprite.groupcollide(组A, 组B, dokillA, dokillB)` 检测两组之间的碰撞：**

```python
bullets = pygame.sprite.Group()
enemies = pygame.sprite.Group()

hits = pygame.sprite.groupcollide(bullets, enemies, True, True)
# True, True：子弹和敌人都删除（打中即消失）
```

**典型场景**：子弹打敌人、玩家与敌人接触。两个 True 表示两边都删。

## 完整示例：玩家吃金币

```python
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
clock = pygame.time.Clock()

class Player(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.image = pygame.Surface((50, 50))
        self.image.fill((0, 200, 255))
        self.rect = self.image.get_rect(center=(400, 300))

    def update(self):
        # 鼠标控制
        self.rect.center = pygame.mouse.get_pos()

class Coin(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()
        self.image = pygame.Surface((20, 20))
        self.image.fill((255, 215, 0))
        self.rect = self.image.get_rect(center=(x, y))

player = Player()
player_group = pygame.sprite.Group(player)

coins = pygame.sprite.Group(
    Coin(100, 100), Coin(300, 200), Coin(500, 400), Coin(700, 150)
)

score = 0
font = pygame.font.SysFont(None, 36)

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    player_group.update()

    # 碰撞检测：玩家吃金币
    hits = pygame.sprite.spritecollide(player, coins, dokill=True)
    score += len(hits)

    screen.fill((0, 0, 0))
    coins.draw(screen)
    player_group.draw(screen)
    score_text = font.render(f"得分: {score}", True, (255, 255, 255))
    screen.blit(score_text, (10, 10))
    pygame.display.flip()
    clock.tick(60)

pygame.quit()
```

## 翻车现场一：把精灵直接传给 colliderect

```
pygame.sprite.spritecollide(player, coins, True)   # 正确：传精灵
player.rect.colliderect(coins)                      # 错误：coins 是 Group 不是 Rect
```

**`colliderect` 要的是 Rect；`spritecollide` 要的是"一个精灵 + 一个组"。** 别混用。

## 翻车现场二：忘了 dokill 为 True，金币吃不完

```
hits = pygame.sprite.spritecollide(player, coins, dokill=False)
score += len(hits)
```

**症状**：玩家从金币堆里走过，金币还在，分数可能重复加。

**原因**：`dokill=False` 只做检测、不删除。如果只是"计数"可以保留；如果是"吃掉"就必须 `dokill=True`。

## 翻车现场三：碰撞盒太大/太小

**用整个精灵图片的 Rect 做碰撞，可能因为图片有留白导致"看起来没碰到却判为碰到"。**

**解决办法：用 `rect.inflate(-dx, -dy)` 缩小碰撞盒，或自定义一个专门的碰撞 Rect：**

```python
self.hitbox = self.rect.inflate(-10, -10)   # 缩小 10 像素的碰撞盒
# 碰撞时用 self.hitbox.colliderect(other.rect)
```

**这是做"手感好"的碰撞的常用技巧**——碰撞盒比视觉小一圈，玩家感觉更宽松。

## 圆形碰撞（距离判断）

**有些游戏需要"按距离"判断（比如爆炸范围、圆形角色）：**

```python
import math

def circle_collide(rect1, rect2, r1, r2):
    dx = rect1.centerx - rect2.centerx
    dy = rect1.centery - rect2.centery
    dist = math.hypot(dx, dy)        # 欧氏距离
    return dist < (r1 + r2)
```

**`math.hypot(dx, dy)` 算两点距离**，比手写 `sqrt(dx*dx + dy*dy)` 更规范。

## 小结

- `rect.colliderect(other_rect)` 判断两个矩形是否重叠
- 精灵碰撞用 `sprite.rect`，不是精灵本身
- `spritecollide(精灵, 组, dokill)` 一个对一群，返回碰撞列表
- `groupcollide(组A, 组B, dokillA, dokillB)` 两组互相碰撞
- `dokill=True` 自动删除碰到的精灵
- 碰撞盒可用 `rect.inflate` 调整大小改善手感
- 圆形碰撞用距离判断 `math.hypot`
