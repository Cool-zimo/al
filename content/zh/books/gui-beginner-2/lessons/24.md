# 处理键盘输入：连续按键与 key.get_pressed

> tkinter 的按键是"按一次触发一次"，做不了"按住方向键持续移动"。pygame 提供两种方式：事件式（KEYDOWN/KEYUP）和状态式（key.get_pressed）。这一节讲怎么用状态式输入做流畅的连续移动。

## 两种按键方式

**方式一：事件式——`KEYDOWN` / `KEYUP` 事件。** 按一下触发一次，适合"跳跃""开火""确认"这种离散动作。

```python
for event in pygame.event.get():
    if event.type == pygame.KEYDOWN:
        if event.key == pygame.K_SPACE:
            player.jump()
```

**方式二：状态式——`pygame.key.get_pressed()`。** 返回一个"所有键当前是否按下"的序列，适合"持续移动"。

```python
keys = pygame.key.get_pressed()
if keys[pygame.K_LEFT]:
    player.rect.x -= 5
if keys[pygame.K_RIGHT]:
    player.rect.x += 5
```

**区别**：事件是"边沿触发"（按下瞬间），`get_pressed` 是"电平触发"（只要按着就为真）。

## 状态式移动：平滑连续

**完整示例：用方向键移动玩家：**

```python
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
clock = pygame.time.Clock()

player = pygame.Rect(375, 275, 50, 50)
speed = 5

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    # 状态式输入
    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT]:
        player.x -= speed
    if keys[pygame.K_RIGHT]:
        player.x += speed
    if keys[pygame.K_UP]:
        player.y -= speed
    if keys[pygame.K_DOWN]:
        player.y += speed

    # 边界限制
    player.clamp_ip(screen.get_rect())

    screen.fill((0, 0, 0))
    pygame.draw.rect(screen, (0, 200, 255), player)
    pygame.display.flip()
    clock.tick(60)

pygame.quit()
```

**`clamp_ip` 是 Rect 的内置方法**：把 Rect 钳制在另一个 Rect 内，自动处理边界，非常方便。

## 翻车现场一：事件式按键做移动，一顿一顿

```
for event in pygame.event.get():
    if event.type == pygame.KEYDOWN:
        if event.key == pygame.K_RIGHT:
            player.rect.x += 5
```

**症状**：按住右方向键，玩家一格一格地跳，不是连续移动。

**原因**：`KEYDOWN` 有系统级的重复延迟（按住约 0.5 秒后才开始重复），用来打字是对的，用来游戏移动就一顿一顿。

**修复**：用 `pygame.key.get_pressed()` 状态式输入，每帧检测。

## 翻车现场二：用了 get_pressed 但只在事件循环里读

```
for event in pygame.event.get():
    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT]:
        player.rect.x -= 5
```

**症状**：玩家时动时不动，极其不稳定。

**原因**：`get_pressed()` 必须在**主循环每帧的开头（事件循环之外）**调用，而不是在事件循环里。事件循环只在有事件时才跑，没有事件时不执行，导致读取时机不稳定。

**正确位置**：

```python
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    keys = pygame.key.get_pressed()     # ← 事件循环之后、每帧都读
    if keys[pygame.K_LEFT]:
        player.rect.x -= speed
    ...
```

## 翻车现场三：同时按两个方向互相抵消

```
if keys[pygame.K_LEFT]:
    player.x -= speed
if keys[pygame.K_RIGHT]:
    player.x += speed     # 左右都按 → 先减后加，净位移 0
```

**这其实是"合理"的行为**（同时按左右 = 不动），不是 bug。但如果想要"优先级"（右优先），用 `elif` 链：

```python
if keys[pygame.K_LEFT]:
    player.x -= speed
elif keys[pygame.K_RIGHT]:
    player.x += speed
```

**一般斜向移动（同时上下左右）是允许的**，所以并列 if 更常见。

## 翻车现场四：用了不存在的键码

```
if keys[pygame.K_W]:      # 实际是 K_w（小写）
    ...
```

**键码常量是**`K_a`、`K_b`、...`K_z`（小写字母）、`K_0`~`K_9`、`K_SPACE`、`K_RETURN`、`K_ESCAPE`、`K_UP`、`K_DOWN`、`K_LEFT`、`K_RIGHT`。

**注意字母是小写 `K_a`，不是 `K_A`**（虽然有些大写也能工作，但标准是 `K_a`）。

## 用 dt 做帧率无关的移动

**和第 8、20 课一样，想让速度跨机器一致，用 dt：**

```python
speed = 300          # 像素/秒

while running:
    dt = clock.tick(60) / 1000          # 转成秒
    for event in pygame.event.get():
        ...
    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT]:
        player.x -= speed * dt
    if keys[pygame.K_RIGHT]:
        player.x += speed * dt
    ...
```

**`tick(60)` 返回毫秒，除以 1000 得到秒。** 位移 = 速度(px/s) × 时间(s)。

## 精灵类里封装移动

**把输入处理放进精灵的 `update`：**

```python
class Player(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.image = pygame.Surface((50, 50))
        self.image.fill((0, 200, 255))
        self.rect = self.image.get_rect(center=(400, 300))
        self.speed = 300        # px/s

    def update(self, keys, dt, bounds):
        if keys[pygame.K_LEFT]:
            self.rect.x -= self.speed * dt
        if keys[pygame.K_RIGHT]:
            self.rect.x += self.speed * dt
        if keys[pygame.K_UP]:
            self.rect.y -= self.speed * dt
        if keys[pygame.K_DOWN]:
            self.rect.y += self.speed * dt
        self.rect.clamp_ip(pygame.Rect(0, 0, *bounds))
```

**调用时把 keys 和 dt 传进去**：`player_group.update(keys, dt, (800, 600))`。

## 小结

- 事件式 KEYDOWN：离散动作（跳跃、开火）
- 状态式 `key.get_pressed()`：持续移动（按住就动）
- `get_pressed()` 必须每帧、在事件循环外调用
- 键码：`K_LEFT`、`K_a`、`K_SPACE` 等
- 帧率无关移动：位移 = speed × dt，dt = tick/1000
- `rect.clamp_ip(rect)` 一行搞定边界钳制
