# 移动与边界：速度向量、边界检测

> 上一节学了 Sprite。这一节把"移动"做得更规范：用速度向量 (vx, vy) 管理运动，把边界检测封装成方法，让精灵的移动逻辑清晰可复用。

## 速度向量：vx 和 vy

**把"速度"拆成水平、垂直两个分量，比单一 speed 更灵活：**

```python
class Ball(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.image = pygame.Surface((30, 30))
        self.image.fill((255, 255, 255))
        self.rect = self.image.get_rect(center=(400, 300))
        self.vx = 4
        self.vy = 3

    def update(self):
        self.rect.x += self.vx
        self.rect.y += self.vy
```

**`vx > 0` 向右，`vx < 0` 向左；`vy > 0` 向下，`vy < 0` 向上。** 两个分量独立，就能实现任意方向的斜向运动。

## 边界检测：反弹 vs 环绕 vs 消失

**撞到边界有三种常见处理：**

| 方式 | 做法 | 典型场景 |
|---|---|---|
| 反弹 | `vx = -vx` 或 `vy = -vy` | 弹球、乒乓球 |
| 环绕 | 出右边界→从左出现 | 太空游戏、卷轴 |
| 消失 | `self.kill()` | 子弹飞出屏 |

## 反弹：封装成方法

**把边界检测写成精灵自己的方法，逻辑内聚：**

```python
class Ball(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()
        self.image = pygame.Surface((30, 30))
        self.image.fill((255, 255, 255))
        self.rect = self.image.get_rect(center=(x, y))
        self.vx = 4
        self.vy = 3

    def update(self, bounds):
        """bounds 是 (width, height) 表示屏幕大小"""
        self.rect.x += self.vx
        self.rect.y += self.vy

        w, h = bounds
        # 水平边界
        if self.rect.left <= 0:
            self.rect.left = 0
            self.vx = abs(self.vx)
        elif self.rect.right >= w:
            self.rect.right = w
            self.vx = -abs(self.vx)
        # 垂直边界
        if self.rect.top <= 0:
            self.rect.top = 0
            self.vy = abs(self.vy)
        elif self.rect.bottom >= h:
            self.rect.bottom = h
            self.vy = -abs(self.vy)
```

**`bounds` 参数让这个方法通用，不硬编码 800/600。**

## 翻车现场一：反弹后球卡在墙里

```
if self.rect.right >= w:
    self.vx = -self.vx      # 只取反，没把球推出去
```

**症状**：球速度大时卡在右墙，反复取反、抖个不停。

**原因**：球已经"穿进"墙内（rect.right > w），只取反速度，下一帧它还在墙内、还是向右的趋势（或刚反向又穿回去），反复横跳。

**修复**：取反的同时把球**推出边界**：

```python
if self.rect.right >= w:
    self.rect.right = w       # 先把位置推到边界上
    self.vx = -abs(self.vx)   # 再确保向左
```

**`self.rect.right = w` 强制位置合法，`-abs(self.vx)` 确保方向确定**。两个一起做，绝不会卡。

## 翻车现场二：用 rect.x 判断右边界出错

```
if self.rect.x >= w:         # rect.x 是左上角
    self.vx = -self.vx
```

**球宽 30 时，`rect.x` 到达 w 意味着球"已经整个飞出画面"了。** 正确是用 `self.rect.right`（= x + width）判断。

**记住 Rect 的几个边界属性**：`left`、`right`、`top`、`bottom`、`centerx`、`centery`。

## 环绕：出界后从另一边出现

**"环绕"是太空射击、贪吃蛇等游戏常用手法：**

```python
def update_wrap(self, w, h):
    self.rect.x += self.vx
    self.rect.y += self.vy
    if self.rect.left > w:
        self.rect.right = 0        # 从左边出现
    elif self.rect.right < 0:
        self.rect.left = w
    if self.rect.top > h:
        self.rect.bottom = 0
    elif self.rect.bottom < 0:
        self.rect.top = h
```

**`rect.right = 0` 让右边缘贴到 x=0，即整个球刚好从左边出现。**

## 消失：kill 掉飞出屏幕的精灵

**子弹、粒子飞出屏幕就该回收，否则 Group 里堆积越来越多对象，越来越慢。**

```python
def update_bullet(self, h):
    self.rect.y += self.vy
    if self.rect.top > h or self.rect.bottom < 0:
        self.kill()         # 从所有 Group 中移除
```

**`self.kill()` 会把精灵从它所属的所有 Group 里移除。** 之后 `group.update()`/`draw()` 就不会再处理它，内存也释放了。

## 改变速度：加速与减速

**给精灵加一个"加速度"属性，实现越来越快/慢：**

```python
class Car(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.image = pygame.Surface((60, 30))
        self.image.fill((0, 200, 255))
        self.rect = self.image.get_rect(center=(100, 300))
        self.vx = 0
        self.ax = 0.2           # 加速度

    def update(self):
        self.vx += self.ax      # 持续加速
        self.rect.x += self.vx
        if self.rect.left > 800:
            self.rect.right = 0
            self.vx = 0         # 重置速度
```

**注意浮点精度**：Rect 的 x/y 只存整数，长期累加小数会丢失。要做精确运动，自己存 `self.x = 100.0`，每帧算完用 `self.rect.x = int(self.x)` 同步。

## 小结

- 速度拆成 `vx`/`vy` 两个分量，实现任意方向运动
- 三种边界处理：反弹、环绕、消失（kill）
- 反弹要"先推到边界 + 再确定方向"，防止卡墙
- 用 `rect.left/right/top/bottom` 判断边界
- `self.kill()` 移除精灵，回收飞出屏幕的对象
- 加速用加速度属性，注意浮点精度问题
