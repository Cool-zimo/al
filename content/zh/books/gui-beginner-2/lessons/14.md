# Notebook 标签页：多页面界面

> 一个窗口里要放很多内容时，全堆在一起会拥挤。Notebook 提供"标签页"切换，把不同功能分到不同页面——就是浏览器标签页那种效果。

## Notebook 是什么

**Notebook 是一个"可切换页面的容器"**：里面放多个 Frame（每页一个），顶部有标签栏，点击切换。

```python
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.title("标签页示例")

notebook = ttk.Notebook(root)
notebook.pack(fill="both", expand=True)

# 第一页
page1 = ttk.Frame(notebook)
ttk.Label(page1, text="这是第一页的内容").pack(padx=20, pady=20)

# 第二页
page2 = ttk.Frame(notebook)
ttk.Label(page2, text="这是第二页的内容").pack(padx=20, pady=20)

# 把页面加到 notebook，并给标签文字
notebook.add(page1, text="首页")
notebook.add(page2, text="设置")

root.mainloop()
```

**每个页面对应一个 Frame，Frame 里再放具体控件。**

## 为什么要用 Frame 做页面

**Frame 是"空白容器"，专门用来把一组控件打包成一个整体。** Notebook 的每一页必须是 Frame（或任何容器控件），这样切换时整体显示/隐藏。

```
Notebook
├── Frame (首页)  →  Label, Button, Entry...
├── Frame (设置)  →  Checkbutton, Combobox...
└── Frame (关于)  →  Label...
```

**这就是 GUI 里"容器嵌套"的基本思想**：大容器里套小容器，层层组织。

## add 与 insert：添加/插入页

```python
notebook.add(page1, text="首页")               # 追加到末尾
notebook.insert(0, page2, text="设置")         # 插到索引 0（最前面）
```

**`text` 是标签栏上显示的文字。** 还可以用 `image` 放图标、`compound` 控制图文排列。

## 切换与监听

**`notebook.select()` 返回当前显示页的 ID；`notebook.index(页ID)` 返回其索引。**

**监听切换事件 `<<NotebookTabChanged>>`：**

```python
def on_change(event):
    selected_id = notebook.select()
    index = notebook.index(selected_id)
    print("切换到了第", index, "页")

notebook.bind("<<NotebookTabChanged>>", on_change)
```

**注意**：回调里 `notebook.select()` 返回的是内部 ID（形如 `.!notebook.!frame`），不是你创建的 page1 变量。

## 翻车现场一：页面里控件不显示（忘了 pack/grid）

```
page1 = ttk.Frame(notebook)
ttk.Label(page1, text="内容")       # 忘记 pack
notebook.add(page1, text="首页")
```

**症状**：标签页存在，但内容空白。

**原因**：Frame 里的控件也需要布局（pack/grid）。加到 Notebook 只解决了"页面放进 notebook"，没解决"页面内部怎么排"。

## 翻车现场二：add 的顺序就是标签顺序

**标签栏从左到右的顺序 = `add` 调用的顺序。** 想调整顺序要么重排 add 调用，要么用 `insert`。

```
notebook.add(page2, text="设置")   # 先加 → 在左边
notebook.add(page1, text="首页")   # 后加 → 在右边
```

**结果：标签栏是"设置 | 首页"，和直觉相反。** 注意 add 顺序就是显示顺序。

## 翻车现场三：在页里用 place 导致切换异常

**页面对 Frame 布局推荐 pack/grid。如果用 `place`（绝对定位），切换标签页时可能出现"残留"或布局错乱。** 简单界面用 pack/grid 即可。

## 一个实用的三页示例

```python
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.title("多功能窗口")

notebook = ttk.Notebook(root)
notebook.pack(fill="both", expand=True)

# 首页：一个按钮
page_home = ttk.Frame(notebook)
ttk.Label(page_home, text="欢迎使用", font=("SimHei", 16)).pack(pady=20)
ttk.Button(page_home, text="开始").pack()

# 设置页：几个选项
page_settings = ttk.Frame(notebook)
ttk.Checkbutton(page_settings, text="开机自启").pack(anchor="w", padx=10, pady=5)
ttk.Checkbutton(page_settings, text="显示通知").pack(anchor="w", padx=10, pady=5)
ttk.Label(page_settings, text="主题：").pack(anchor="w", padx=10)
ttk.Combobox(page_settings, values=["浅色", "深色"]).pack(padx=10)

# 关于页：文字
page_about = ttk.Frame(notebook)
ttk.Label(page_about, text="版本 1.0\n作者：小明",
          justify="center").pack(pady=30)

notebook.add(page_home, text="首页")
notebook.add(page_settings, text="设置")
notebook.add(page_about, text="关于")

root.mainloop()
```

## 程序化切换标签页

**可以用代码主动切换到某一页：`notebook.select(页ID)` 或 `notebook.select(索引)`。**

```python
def goto_settings():
    notebook.select(1)          # 切到第 2 页（索引从 0 开始）

ttk.Button(page_home, text="去设置", command=goto_settings).pack()
```

**这在"向导式"界面里很常见**：填写完一页点"下一步"，自动切到下一页。

## 小结

- Notebook = 标签页容器，每页是一个 Frame
- 用 `add(frame, text="标签")` 加页，顺序决定显示顺序
- 页内控件仍要 pack/grid 布局
- `<<NotebookTabChanged>>` 监听切换，`select()` 拿当前页
- 可用 `select(索引)` 程序化切换
- Frame 是容器基本单位，用来组织"一组控件"
