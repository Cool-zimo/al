# 收官：做一个完整的小游戏，以及下一步学什么

> 前面五章讲了精灵、碰撞、声音、状态、存档、调试。这一节把它们**全部串起来**，做成一个能玩、能存分、有菜单、有音效、有结束画面的完整小游戏，并告诉你接下来该往哪走。

## 一个完整游戏长什么样

**"完整"不等于"复杂"，而是"闭环"。** 一个小游戏至少要具备：

1. **菜单**（有开始入口）
2. **游戏循环**（有玩法、有计分）
3. **结束画面**（显示结果、能重开）
4. **存档**（最高分跨次保留）
5. **声音**（反馈感）
6. **容错**（坏档不崩、图片丢了不崩）

**这一节我们把这些做成"接球游戏"：挡板在底部左右移动，球自动下落，接住加分，漏掉扣分，30 秒后结算，刷新最高分存盘。**

## 完整代码（逐块拆解）

**第一步：初始化和工具函数。**

```python
import json
import os
import random
import pygame

pygame.init()
pygame.mixer.init()
screen = pygame.display.set_mode((600, 500))
clock = pygame.time.Clock()
font = pygame.font.Font(None, 36)

SAVE_FILE = "save.json"
DEFAULT = {"high_score": 0}

def load_save():
    try:
        with open(SAVE_FILE, "r", encoding="utf-8") as f:
            return json.load(f)
    except (json.JSONDecodeError, FileNotFoundError, OSError):
        return dict(DEFAULT)

def save_high(score):
    data = load_save()
    if score > data["high_score"]:
        data["high_score"] = score
        tmp = SAVE_FILE + ".tmp"
        with open(tmp, "w", encoding="utf-8") as f:
            json.dump(data, f, ensure_ascii=False, indent=2)
        os.replace(tmp, SAVE_FILE)
```

**第二步：定义精灵——球和挡板。**

```python
class Paddle(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.image = pygame.Surface((100, 15))
        self.image.fill((0, 200, 255))
        self.rect = self.image.get_rect(center=(300, 470))

    def update(self, keys):
        if keys[pygame.K_LEFT] and self.rect.left > 0:
            self.rect.x -= 6
        if keys[pygame.K_RIGHT] and self.rect.right < 600:
            self.rect.x += 6

class Ball(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.image = pygame.Surface((20, 20))
        self.image.fill((255, 200, 0))
        self.rect = self.image.get_rect(center=(300, 50))
        self.vy = 4

    def update(self):
        self.rect.y += self.vy
```

**第三步：状态机 + 主循环。**

```python
MENU, PLAYING, GAMEOVER = 'menu', 'playing', 'gameover'
state = MENU
save = load_save()
score = 0
time_left = 30
start_ticks = 0

paddle = Paddle()
ball = Ball()
all_sprites = pygame.sprite.Group(paddle, ball)

running = True
while running:
    keys = pygame.key.get_pressed()

    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

        if state == MENU:
            if event.type == pygame.KEYDOWN and event.key == pygame.K_SPACE:
                score = 0
                time_left = 30
                start_ticks = pygame.time.get_ticks()
                ball.rect.center = (random.randint(20, 580), 50)
                state = PLAYING

        elif state == PLAYING:
            if event.type == pygame.KEYDOWN and event.key == pygame.K_ESCAPE:
                state = MENU

        elif state == GAMEOVER:
            if event.type == pygame.KEYDOWN and event.key == pygame.K_r:
                state = MENU

    # ---- 逻辑 ----
    if state == PLAYING:
        paddle.update(keys)
        ball.update()

        if ball.rect.colliderect(paddle.rect):
            score += 10
            ball.rect.center = (random.randint(20, 580), 50)

        if ball.rect.top > 500:
            score = max(0, score - 5)
            ball.rect.center = (random.randint(20, 580), 50)

        elapsed = (pygame.time.get_ticks() - start_ticks) // 1000
        time_left = 30 - elapsed
        if time_left <= 0:
            save_high(score)
            save = load_save()
            state = GAMEOVER

    # ---- 绘制 ----
    screen.fill((20, 20, 40))
    if state == MENU:
        screen.blit(font.render("接球游戏", True, (255, 255, 255)), (240, 180))
        screen.blit(font.render("按空格开始", True, (200, 200, 200)), (220, 240))
    elif state == PLAYING:
        all_sprites.draw(screen)
        screen.blit(font.render(f"得分 {score}  时间 {time_left}", True, (255, 255, 0)), (10, 10))
    elif state == GAMEOVER:
        screen.blit(font.render(f"结束！得分 {score}", True, (255, 100, 100)), (200, 180))
        screen.blit(font.render(f"最高 {save['high_score']}  按 R 重来", True, (200, 200, 200)), (170, 240))

    pygame.display.flip()
    clock.tick(60)

pygame.quit()
```

**这就是一个完整闭环**：菜单进游戏、接球加分、漏球扣分、计时结束结算、最高分存盘、重开不丢档。

## 翻车现场一：把整个游戏写在一个文件里，改一行要读一千行

**现象**：`main.py` 写到 500 行，想改球速要翻半天，加新功能心里没底。

**原因**：没分层。

**拆法：一个文件夹，四个文件。**

```
my_game/
├── main.py          # 主循环、事件、状态机
├── sprites.py       # Paddle / Ball 类
├── save.py          # load_save / save_high
└── settings.py      # 常量：窗口尺寸、颜色、路径
```

**`main.py` 里 `from sprites import Paddle, Ball`**——主文件只剩"流程"，一眼能看清。

## 翻车现场二：每帧都 load 图片和读档

```python
while running:
    img = pygame.image.load("ball.png")       # 每帧读盘！
```

**症状**：游戏越跑越卡，磁盘灯狂闪。

**原因**：文件 I/O 慢，Surface 创建有开销。

**解法**：**加载放在循环外，做成全局常量。**

```python
BALL_IMG = pygame.image.load(os.path.join(base, "ball.png")).convert_alpha()
```

## 翻车现场三：魔法数字满天飞

```python
rect = img.get_rect(center=(300, 470))     # 470 是哪来的？
if rect.right < 600:
    ...
if ball.rect.top > 500:
    ...
```

**症状**：想换 800x600 的窗口，要改 20 处数字，改漏一个就出 bug。

**解法**：**常量集中定义。**

```python
WIDTH, HEIGHT = 600, 500
PADDLE_Y = HEIGHT - 30
if self.rect.right < WIDTH:
    ...
```

**改一次 `WIDTH`，全程序跟着变。**

## 翻车现场四：直接在主循环里堆逻辑，没用 update

**现象**：`if state == PLAYING:` 下面 200 行缩进代码，加新状态只能继续嵌套。

**解法**：**每个状态的处理抽成函数**（`handle_menu / handle_playing / handle_gameover`），主循环只负责调度。

## 接下来学什么

**《Python 窗口入门 3》要讲的是"完整桌面项目"。** 你现在已经会了 pygame 做小游戏，但真实应用是**工具型软件**：

| 你已经会的 | 下一步要学的 |
|---|---|
| 事件循环、状态机 | 更完善的程序架构（MVC 分层） |
| 手写碰撞、手绘界面 | 现成的控件：按钮、输入框、表格、菜单栏 |
| 一个窗口一个画布 | 多窗口、对话框、系统托盘 |
| 自己算坐标布局 | 布局管理器自动排版 |
| pygame 的固定帧循环 | 事件驱动的桌面程序模型 |

**选 Qt 还是 Tkinter？**

- **Tkinter**：Python 自带、零安装、适合小工具。但丑、控件少、现代化界面难做。
- **Qt（PySide6/PyQt6）**：工业级、跨平台、控件丰富、能做商业软件；要单独装库。

**《窗口入门 3》会带你用 Qt 做一个完整桌面应用**：从界面设计器画界面、信号与槽连接逻辑、多线程不卡界面、打包成 exe/app，最终交付一个"能发给别人用的软件"。

**如果你想继续做游戏**，《窗口入门 2》的 pygame 基础已经够你做大多数 2D 小游戏了。可以自学：粒子系统、瓦片地图（tilemap）、状态机进阶、用 PyInstaller 打包成 exe。

## 小结

- "完整游戏" = 菜单 + 玩法 + 结算 + 存档 + 声音 + 容错，六个都有才算闭环
- 分层架构：精灵归精灵文件、存档归存档文件、主循环只管流程
- 资源加载放循环外做成常量；尺寸用常量集中管理，别散落魔法数字
- 状态处理抽函数，主循环只调度
- 下一步：《窗口入门 3》做 Qt 桌面项目，或自行深入 pygame 进阶
