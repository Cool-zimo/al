# 实战：简单的弹球游戏

> 把前几课学到的动画、键盘、碰撞判断串起来，做一个能玩的弹球游戏：球会反弹，挡板能用方向键移动，接住球得分，漏球扣分。

## 我们要做什么

**游戏有三个要素：球、挡板、得分。**

```
┌─────────────────────┐
│                     │
│      o  球           │
│                     │
│                ███ 挡板 │
│ 得分: 3              │
└─────────────────────┘
```

| 要素 | 作用 |
|---|---|
| 球 | 自动移动、碰壁反弹、碰挡板反弹 |
| 挡板 | 玩家控制，左右移动接球 |
| 得分 | 接住球 +1，球落地 -1 |

## 第一步：画球和挡板

```python
import tkinter as tk

root = tk.Tk()
root.title("弹球游戏")
canvas = tk.Canvas(root, width=400, height=300, bg="white")
canvas.pack()

# 球：外接矩形
ball = canvas.create_oval(190, 50, 210, 70, fill="tomato")
# 挡板
paddle = canvas.create_rectangle(160, 270, 240, 285, fill="dodgerblue")

# 得分文字
score = 0
score_text = canvas.create_text(50, 20, text=f"得分: {score}", font=("SimHei", 14))
```

## 第二步：让球动起来

**用 `after` 递归，每帧移动球，并处理墙壁反弹：**

```python
ball_x, ball_y = 190, 50
ball_r = 10          # 半径
dx, dy = 3, 3

def move_ball():
    global ball_x, ball_y, dx, dy, score
    ball_x += dx
    ball_y += dy

    # 左右墙反弹
    if ball_x <= 0 or ball_x >= 400 - ball_r*2:
        dx = -dx
    # 上墙反弹
    if ball_y <= 0:
        dy = -dy
    # 落地（漏球）
    if ball_y >= 300:
        dy = -dy          # 弹回去，不结束
        score -= 1
        update_score()

    canvas.coords(ball, ball_x, ball_y, ball_x+ball_r*2, ball_y+ball_r*2)
    root.after(20, move_ball)

def update_score():
    global score
    canvas.itemconfig(score_text, text=f"得分: {score}")
```

## 第三步：挡板键盘控制

**用方向键（或 A/D）移动挡板，并限制不出画布：**

```python
paddle_x = 160
paddle_w = 80

def move_paddle(event):
    global paddle_x
    if event.keysym in ("Left", "a", "A"):
        paddle_x = max(0, paddle_x - 20)
    elif event.keysym in ("Right", "d", "D"):
        paddle_x = min(400 - paddle_w, paddle_x + 20)
    canvas.coords(paddle, paddle_x, 270, paddle_x + paddle_w, 285)

root.bind("<Key>", move_paddle)
```

**`min(400 - paddle_w, ...)` 保证挡板右边界不超过画布宽度。**

## 第四步：碰撞检测——球碰到挡板

**最简单的碰撞：判断球是否落在挡板的矩形范围内。** 球底部 y 越过挡板顶部，且 x 落在挡板区间内，就算"接住"。

```python
def move_ball():
    global ball_x, ball_y, dx, dy, score
    ball_x += dx
    ball_y += dy

    if ball_x <= 0 or ball_x >= 400 - ball_r*2:
        dx = -dx
    if ball_y <= 0:
        dy = -dy
    if ball_y >= 300:
        dy = -dy
        score -= 1
        update_score()

    # 碰撞检测：球底部碰到挡板区域
    if (ball_y + ball_r*2 >= 270 and ball_y + ball_r*2 <= 300 and
        ball_x + ball_r >= paddle_x and ball_x + ball_r <= paddle_x + paddle_w):
        dy = -abs(dy)      # 向上反弹（确保是向上）
        score += 1
        update_score()

    canvas.coords(ball, ball_x, ball_y, ball_x+ball_r*2, ball_y+ball_r*2)
    root.after(20, move_ball)
```

**为什么用 `dy = -abs(dy)`？** 防止球"卡"在挡板里时连续反弹。强制向上，一次只反弹一次。

## 完整成品

```python
import tkinter as tk

root = tk.Tk()
root.title("弹球游戏")
canvas = tk.Canvas(root, width=400, height=300, bg="white")
canvas.pack()

ball = canvas.create_oval(190, 50, 210, 70, fill="tomato")
paddle = canvas.create_rectangle(160, 270, 240, 285, fill="dodgerblue")
score = 0
score_text = canvas.create_text(50, 20, text="得分: 0", font=("SimHei", 14))

ball_x, ball_y = 190, 50
ball_r = 10
dx, dy = 3, 3
paddle_x = 160
paddle_w = 80

def update_score():
    global score
    canvas.itemconfig(score_text, text=f"得分: {score}")

def move_ball():
    global ball_x, ball_y, dx, dy, score
    ball_x += dx
    ball_y += dy

    if ball_x <= 0 or ball_x >= 400 - ball_r*2:
        dx = -dx
    if ball_y <= 0:
        dy = -dy
    if ball_y >= 300:
        dy = -dy
        score -= 1
        update_score()

    # 接球判定
    if (ball_y + ball_r*2 >= 270 and ball_y + ball_r*2 <= 300 and
        ball_x + ball_r >= paddle_x and ball_x + ball_r <= paddle_x + paddle_w):
        dy = -abs(dy)
        score += 1
        update_score()

    canvas.coords(ball, ball_x, ball_y, ball_x+ball_r*2, ball_y+ball_r*2)
    root.after(20, move_ball)

def move_paddle(event):
    global paddle_x
    if event.keysym in ("Left", "a", "A"):
        paddle_x = max(0, paddle_x - 20)
    elif event.keysym in ("Right", "d", "D"):
        paddle_x = min(400 - paddle_w, paddle_x + 20)
    canvas.coords(paddle, paddle_x, 270, paddle_x + paddle_w, 285)

root.bind("<Key>", move_paddle)
move_ball()
root.mainloop()
```

## 翻车现场一：碰撞判定"卡住"连续加分

```
if ball_y + ball_r*2 >= 270 and ...:
    dy = -dy        # 球还在挡板范围内，下一帧又碰到
    score += 1
```

**症状**：球一碰到挡板，分数瞬间飙到几十。

**原因**：`dy = -dy` 后球向上走了一帧，但可能还没离开挡板范围，下一帧又判定"碰到了"，继续加分反弹，反复横跳。

**修复**：用 `dy = -abs(dy)` 强制向上，并且条件里限定"球在下落中"（`dy > 0`）：

```python
if (dy > 0 and ball_y + ball_r*2 >= 270 and ball_y + ball_r*2 <= 300 and
    ball_x + ball_r >= paddle_x and ball_x + ball_r <= paddle_x + paddle_w):
    dy = -abs(dy)
    score += 1
    update_score()
```

**`dy > 0` 保证只有"下落的球"才判定接球**，上升中的球（已经弹起）不会重复触发。这是碰撞检测的经典防抖技巧。

## 翻车现场二：忘了 mainloop / 忘记启动 move_ball

```
move_ball()         # 如果忘了这句，球不会动
root.mainloop()
```

**症状**：窗口出来了，球静止不动，挡板按键有反应（绑定了），但球不走。

**原因**：动画函数 `move_ball` 需要手动调用一次来"启动"递归。忘了调用，整个递归链就没开始。

## 翻车现场三：挡板移动时焦点问题

**如果焦点不在 root 上（比如先点了一下别的控件），方向键没反应。**

**对策**：绑在 `root` 而不是 canvas；或者在程序启动时强制 `root.focus_set()`。做游戏时一般把键盘绑定放在 root 上。

## 升级：让球速随得分变快

**难度递增是游戏的基本乐趣：**

```python
def move_ball():
    global ball_x, ball_y, dx, dy, score
    # 速度随得分提升
    speed = 3 + score * 0.3
    # 用方向符号保持速度
    step_x = speed if dx > 0 else -speed
    step_y = speed if dy > 0 else -speed
    ball_x += step_x
    ball_y += step_y
    ...
```

**注意**：这里为了简单直接用固定步长。严谨做法是用 dt（第 8 课）。但 tkinter 小游戏固定步长通常可接受。

## 小结

- 弹球 = 球自动移动 + 挡板键盘控制 + 碰撞判定
- 球用 `after` 递归驱动，碰壁 `dx/dy` 取反
- 挡板用方向键 + `coords` 绝对定位 + `min/max` 边界限制
- 碰撞 = 球底部 y 在挡板区间 + 球 x 落在挡板宽度内
- 防重复触发：用 `dy > 0` 判定"下落中"，反弹用 `-abs(dy)`
- 别忘了手动调用一次 `move_ball()` 启动动画
