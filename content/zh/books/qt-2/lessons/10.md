# 选择模型 QItemSelectionModel：获取当前选中、多选、选中变化信号

> 用户点了一行，你怎么知道？view 的选中状态其实归一个专门的类管——QItemSelectionModel。它管"当前是哪个 index""选了哪几行""选中变了通知谁"。

## SelectionModel 是 view 的内置成员

**每个 view 都有一个 selectionModel()。你不需要 new，直接拿。**

```
selection_model = view.selectionModel()
current = selection_model.currentIndex()     # 当前光标所在的 index
```

**这个 index 是 proxy 坐标系的（如果你的 view 接了 proxy）。** 想拿 source 的行，要用 proxy.mapToSource。

## 三种选中模式

**用 `view.setSelectionMode()` 设置：**

| 模式 | 含义 |
|---|---|
| `QAbstractItemView.NoSelection` | 不能选 |
| `SingleSelection` | 单选 |
| `ExtendedSelection` | 多选（Ctrl/Shift 加选，默认） |
| `MultiSelection` | 点击即切换选中，不用 Ctrl |
| `ContiguousSelection` | 连续区间选择 |

```
view.setSelectionMode(QAbstractItemView.ExtendedSelection)   # 允许 Ctrl/Shift 多选
view.setSelectionBehavior(QAbstractItemView.SelectRows)     # 点一个单元格选中整行
```

**SelectionMode 管"能不能多选"，SelectionBehavior 管"选中一个单元格时实际选中什么"。** 两个是不同维度，经常一起配。

## 选中变化信号

**这是 selectionModel 最实用的部分——选中一变，你就收到信号。**

```
selection_model = view.selectionModel()

selection_model.currentChanged.connect(on_current_changed)
selection_model.selectionChanged.connect(on_selection_changed)

def on_current_changed(current, previous):
    # current 是新的当前 index，previous 是上一个
    print("当前行：", current.row(), "列：", current.column())

def on_selection_changed(selected, deselected):
    # selected 和 deselected 是 QItemSelection（一组 index 区间）
    for index in selected.indexes():
        print("新选中：", index.row(), index.column())
    for index in deselected.indexes():
        print("取消选中：", index.row(), index.column())
```

**currentChanged 是"光标移到哪儿"，selectionChanged 是"哪些格子进入/离开选中集合"。** 两者不同：你可以用方向键移动光标而不改变选中，这时只有 currentChanged。

## 翻车现场一：currentChanged 和 selectionChanged 混用，逻辑错乱

**症状：想做"选中一行显示详情"，结果用 currentChanged，用户按方向键预览时也触发了详情加载（可能很慢）。**

```
# ❌ 用 currentChanged 做详情加载
selection_model.currentChanged.connect(load_detail_from_server)  # 每按一次键就请求一次
```

**✅ 正确做法：用 selectionChanged，只在"真正选中"时触发；或者用 currentChanged 但做防抖。**

```
# 需求是"选中一行"
selection_model.selectionChanged.connect(on_selection_changed)

def on_selection_changed(selected, deselected):
    indexes = selected.indexes()
    if not indexes:
        return
    current = indexes[0]
    load_detail(current.row())
```

**或者用 selection 的 `hasSelection()` 判断是否真的有选中：**

```
if selection_model.hasSelection():
    selected_rows = selection_model.selectedRows()   # 返回选中的行（第 0 列的 index）
```

## 程序化选中与取消

**你也可以在代码里选中某一行：**

```
# 选中第 2 行（整行）
row_index = model.index(2, 0)
selection_model.select(row_index, QItemSelectionModel.Select | QItemSelectionModel.Rows)

# 清除选中
selection_model.clearSelection()

# 只设当前（不高亮）
selection_model.setCurrentIndex(row_index, QItemSelectionModel.NoUpdate)
```

**select 的第二个参数是命令标志的组合。常用：**

| 标志 | 含义 |
|---|---|
| `Select` | 加入选中 |
| `Deselect` | 从选中移除 |
| `Toggle` | 切换 |
| `Clear` | 先清空再操作 |
| `Rows` | 整行 |
| `Columns` | 整列 |
| `Current` | 同时设为当前项 |

**组合使用很常见：`QItemSelectionModel.ClearAndSelect | QItemSelectionModel.Rows` 表示"先清空、再选中这一整行"。**

## 翻车现场二：proxy 下的选中 index 直接用，行号对不上

**症状：view 接了 proxy，用 `currentIndex().row()` 去 source model 取数据，拿到的不是界面显示的那一行。**

```
proxy_idx = view.currentIndex()         # proxy 坐标
row = proxy_idx.row()                    # 比如 0（过滤后第 0 行）
data = source_model._rows[row]          # ❌ 行号错乱
```

**✅ 正确做法：mapToSource。**

```
proxy_idx = view.currentIndex()
source_idx = proxy.mapToSource(proxy_idx)
real_row = source_idx.row()
data = source_model._rows[real_row]
```

**凡是 view 接了 proxy，从 view 拿到的 index 一律要 mapToSource 才能喂给 source model。** 这是 proxy 世界的通用纪律。

## 翻车现场三：在 selectionChanged 里又改 selection，死循环

**症状：想在选中变化时自动选中某些关联行，结果程序卡死或报"递归选择"警告。**

```
def on_selection_changed(selected, deselected):
    for idx in selected.indexes():
        # ❌ 在回调里又改选中，触发新的 selectionChanged，无限递归
        selection_model.select(idx, QItemSelectionModel.Select)
```

**原因：select() 会再次触发 selectionChanged，你又 select，又触发……**

**✅ 正确做法：用 blockSignals 临时阻断，或只在必要时改。**

```
def on_selection_changed(selected, deselected):
    selection_model.blockSignals(True)
    try:
        # 做你的批量选中操作
        pass
    finally:
        selection_model.blockSignals(False)
```

**blockSignals 是 Qt 里通用的"临时屏蔽信号"工具，配对用 try/finally。**

## 小结

- selectionModel() 是 view 内置的选中管理器，不用自己 new
- 三个常用模式：NoSelection / SingleSelection / ExtendedSelection
- SelectionBehavior 管选中粒度（单元格/行/列），和 Mode 是不同维度
- currentChanged 随光标移动，selectionChanged 随选中集合变化
- 程序化选中用 select()，标志可组合（ClearAndSelect | Rows）
- proxy 下的 index 必须 mapToSource 才能用
- 在 selectionChanged 里改选中要用 blockSignals 防递归

  import sys
  from PySide6.QtCore import QAbstractTableModel, Qt, QModelIndex, QSortFilterProxyModel

      QApplication, QWidget, QTableView, QLabel, QHBoxLayout, QVBoxLayout
  )

  class StudentModel(QAbstractTableModel):
      def __init__(self):
          super().__init__()
          self._rows = [
              ["张三", 20, "研发部"],
              ["李四", 25, "市场部"],
              ["王五", 22, "财务部"],
          ]
      def rowCount(self, p=QModelIndex()):
          return len(self._rows)
      def columnCount(self, p=QModelIndex()):
          return 3

          if not index.isValid():
              return None
          return str(self._rows[index.row()][index.column()])

          if role == Qt.DisplayRole and orientation == Qt.Horizontal:
              return ["姓名", "年龄", "部门"][section]
          return None

  app = QApplication(sys.argv)
  win = QWidget()
  win.setWindowTitle("选中显示详情")

  proxy.setSourceModel(source)
  proxy.setFilterKeyColumn(-1)

  view = QTableView()
  view.setModel(proxy)
  view.setSelectionMode(Qt.ExtendedSelection)   # 其实用 Single 也行
  view.setSelectionBehavior(Qt.SelectRows)

  detail = QLabel("请选中一行查看详情")
  detail.setWordWrap(True)

  def on_selection_changed(selected, deselected):
      # 在这里补全：用 mapToSource 取真实数据，拼成文本显示到 detail
      pass

  view.selectionModel().selectionChanged.connect(on_selection_changed)

  layout = QHBoxLayout(win)
  layout.addWidget(view, 2)
  layout.addWidget(detail, 1)
  win.resize(600, 300)
  win.show()
  app.exec()
