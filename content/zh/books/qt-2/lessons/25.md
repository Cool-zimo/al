# JSON 与网络数据：解析接口返回并填进 Model

> 网络请求的终点往往是一个 JSON。这一节把"网络请求 → JSON 解析 → 塞进 Model → 绑到 View"整条链路打通，做一个真正的"在线数据表格"。

## 整条链路长什么样

```
API 返回 JSON
   ↓ QJsonDocument::fromJson
QJsonDocument → QJsonArray / QJsonObject
   ↓ 遍历解析
Python list[dict]
   ↓ 交给自定义 Model
QAbstractTableModel / QSqlTableModel
   ↓ 绑定
QTableView
```

## 从 QByteArray 到 Python 数据

`reply.readAll()` 给的是 QByteArray，PySide6 里有两种处理方式：

```
from PySide6.QtCore import QJsonDocument, QJsonParseError

data = reply.readAll()
doc = QJsonDocument.fromJson(bytes(data))    # 需要 bytes，不是 QByteArray
if doc.isNull():
    print("JSON 解析失败")
    return
if doc.isArray():
    items = doc.array()      # QJsonArray
elif doc.isObject():
    items = doc.object()     # QJsonObject
```

更简单的做法：直接把 QByteArray 转 bytes 后交给 Python 标准库 `json`：

```
import json
data = reply.readAll()
items = json.loads(bytes(data).decode("utf-8"))
```

## 完整示例：在线用户列表

```
import sys, json
from PySide6.QtWidgets import (QApplication, QWidget, QVBoxLayout, QPushButton,
                              QTableView, QLabel, QHeaderView)
from PySide6.QtCore import Qt, QUrl
from PySide6.QtNetwork import QNetworkAccessManager, QNetworkRequest
from PySide6.QtCore import QAbstractTableModel

class UserModel(QAbstractTableModel):
    HEADERS = ["ID", "姓名", "邮箱", "城市"]

    def __init__(self, data=None):
        super().__init__()
        self._data = data or []

    def rowCount(self, parent=None):
        return len(self._data)

    def columnCount(self, parent=None):
        return len(self.HEADERS)

    def data(self, index, role=Qt.ItemDataRole.DisplayRole):
        if not index.isValid():
            return None
        if role == Qt.ItemDataRole.DisplayRole:
            return str(self._data[index.row()][index.column()])
        return None

    def headerData(self, section, orientation, role=Qt.ItemDataRole.DisplayRole):
        if role == Qt.ItemDataRole.DisplayRole and orientation == Qt.Orientation.Horizontal:
            return self.HEADERS[section]
        return None

    def set_users(self, users):
        self.beginResetModel()
        self._data = users
        self.endResetModel()


class Demo(QWidget):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("在线用户")
        self.resize(700, 500)

        self.status = QLabel("点击按钮加载数据")
        self.btn = QPushButton("加载")
        self.table = QTableView()

        self.model = UserModel()
        self.table.setModel(self.model)
        self.table.horizontalHeader().setSectionResizeMode(
            QHeaderView.ResizeMode.Stretch)

        self.manager = QNetworkAccessManager(self)
        self.btn.clicked.connect(self.fetch)

        layout = QVBoxLayout(self)
        layout.addWidget(self.status)
        layout.addWidget(self.btn)
        layout.addWidget(self.table)

    def fetch(self):
        self.status.setText("请求中...")
        self.btn.setEnabled(False)
        url = QUrl("https://jsonplaceholder.typicode.com/users")
        req = QNetworkRequest(url)
        reply = self.manager.get(req)
        reply.finished.connect(lambda: self.on_done(reply))

    def on_done(self, reply):
        self.btn.setEnabled(True)
        if reply.error() != reply.NetworkError.NoError:
            self.status.setText(f"错误: {reply.errorString()}")
            reply.deleteLater()
            return
        try:
            data = json.loads(bytes(reply.readAll()).decode("utf-8"))
        except (UnicodeDecodeError, json.JSONDecodeError) as e:
            self.status.setText(f"解析失败: {e}")
            reply.deleteLater()
            return

        users = [
            [u["id"], u["name"], u["email"], u["address"]["city"]]
            for u in data
        ]
        self.model.set_users(users)
        self.status.setText(f"加载完成，共 {len(users)} 条")
        reply.deleteLater()


if __name__ == "__main__":
    app = QApplication(sys.argv)
    w = Demo()
    w.show()
    app.exec()
```

## 为什么用 beginResetModel / endResetModel

一次性换掉整个数据集，最安全的方式是"包在 reset 对里"告诉 View：内部结构全变了，你重画吧。对于增量追加，则用 `beginInsertRows / endInsertRows` 更精细。

## 翻车现场一：忘了 json.loads 直接把字符串当下标用

**症状：`data[0]` 报 TypeError: string indices must be integers，或者拿到的是 JSON 字符串的第一个字符。

**原因**：`bytes(reply.readAll()).decode()` 得到的是**字符串**，不是 dict/list。必须再 `json.loads` 一次。

**正确写法：**

```
text = bytes(reply.readAll()).decode("utf-8")
data = json.loads(text)        # 现在 data 才是 list/dict
```

## 翻车现场二：JSON 字段嵌套取错，KeyError 闪退

**症状：接口返回 `{..., "address": {"city": "New York"}}`，直接 `u["city"]` 报 KeyError。

**错误写法：**

```
city = u["city"]               # 不存在这个顶层字段
```

**正确写法：用 .get 或按层级取值，并做兜底：**

```
city = u.get("address", {}).get("city", "未知")
```

## 翻车现场三：网络数据没来就刷新 Model，界面空白

**症状**：`self.model.set_users([])` 在请求失败路径里被忘记调用，界面停在"请求中"状态。

**正确做法**：任何路径（成功/失败/解析失败）都更新状态文字，失败时不改 Model 数据但要给反馈。

## 翻车现场四：UI 线程里用 time.sleep 等待网络

**症状**：点了按钮后窗口卡死几秒。

**错误写法：**

```
def on_click(self):
    import time
    time.sleep(3)              # 主线程阻塞，界面冻结
    self.load_data()
```

**正确做法：永远用异步信号，不用 sleep 轮询。**

## 翻车现场五：Model 换数据时没有 beginResetModel，View 显示错乱

**症状**：数据换了，但 View 还显示旧的行数，甚至出现空白行或越界崩溃。

**正确写法：**

```
def set_users(self, users):
    self.beginResetModel()
    self._data = users
    self.endResetModel()
```

## 小结

- 网络 JSON 流程：readAll → decode → json.loads → 解析 → 塞 Model
- QJsonDocument.fromJson 或标准库 json 都能解析
- 自定义 Model 用 beginResetModel/endResetModel 整体刷新
- JSON 字段用 .get 带默认值，避免 KeyError
- 任何路径都要更新状态文字，失败也要有反馈
- 禁止在 UI 线程 sleep 或同步等待
- reply 必须 deleteLater
