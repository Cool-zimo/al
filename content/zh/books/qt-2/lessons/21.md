# Qt 的数据库支持：QtSql 模块与 QSqlTableModel

> Qt 内置了一套数据库模块 QtSql，不用装 SQLAlchemy 就能连 SQLite、MySQL、PostgreSQL。更妙的是它自带 Model/View 集成——一张表直接绑到 QTableView，开箱可编辑。

## 模块与驱动

PySide6 里先 `from PySide6.QtSql import ...`，常用类：

| 类 | 作用 |
|---|---|
| QSqlDatabase | 数据库连接（增/删/查/改的连接对象） |
| QSqlQuery | 手写 SQL、执行、遍历结果 |
| QSqlTableModel | 单表 Model，可编辑，可直接绑 View |
| QSqlQueryModel | 只读 Model，支持任意 SELECT |
| QSqlRelationalTableModel | 支持外键关联的 TableModel |

查看当前可用的驱动：

```
from PySide6.QtSql import QSqlDatabase
print(QSqlDatabase.drivers())
# 常见输出：['QSQLITE', 'QODBC', 'QPSQL', 'QMYSQL']
```

SQLite 是自带的、零配置、单文件，最适合练手和小型桌面应用。

## 连接 SQLite 的完整流程

```
import sys
from PySide6.QtWidgets import (QApplication, QTableView, QWidget,
                               QVBoxLayout, QPushButton, QHBoxLayout)
from PySide6.QtSql import QSqlDatabase, QSqlTableModel
from PySide6.QtCore import Qt

DB_PATH = "demo.db"

def init_db():
    db = QSqlDatabase.addDatabase("QSQLITE")
    db.setDatabaseName(DB_PATH)
    if not db.open():
        print("数据库打开失败:", db.lastError().text())
        return False

    # 首次建表
    q = QSqlQuery()
    q.exec("CREATE TABLE IF NOT EXISTS books ("
           "id INTEGER PRIMARY KEY AUTOINCREMENT,"
           "title TEXT NOT NULL,"
           "author TEXT,"
           "price REAL DEFAULT 0)")
    return True

def main():
    app = QApplication(sys.argv)
    if not init_db():
        sys.exit(1)

    window = QWidget()
    window.setWindowTitle("图书管理")
    window.resize(600, 400)

    # Model：绑定到 books 表
    model = QSqlTableModel()
    model.setTable("books")
    model.setEditStrategy(QSqlTableModel.EditStrategy.OnRowChange)
    model.select()                       # ★ 必须 select()，否则没数据
    model.setHeaderData(0, Qt.Orientation.Horizontal, "编号")
    model.setHeaderData(1, Qt.Orientation.Horizontal, "书名")
    model.setHeaderData(2, Qt.Orientation.Horizontal, "作者")
    model.setHeaderData(3, Qt.Orientation.Horizontal, "价格")

    view = QTableView()
    view.setModel(model)
    view.setSelectionMode(QTableView.SelectionMode.SingleSelection)
    view.setSelectionBehavior(QTableView.SelectionBehavior.SelectRows)
    view.horizontalHeader().setStretchLastSection(True)

    btn_add = QPushButton("添加")
    btn_del = QPushButton("删除选中")

    def on_add():
        model.insertRow(model.rowCount())
    def on_del():
        idx = view.currentIndex()
        if idx.isValid():
            model.removeRow(idx.row())
            model.select()               # 删除后要刷新
    btn_add.clicked.connect(on_add)
    btn_del.clicked.connect(on_del)

    toolbar = QHBoxLayout()
    toolbar.addWidget(btn_add)
    toolbar.addWidget(btn_del)
    layout = QVBoxLayout(window)
    layout.addLayout(toolbar)
    layout.addWidget(view)
    window.show()
    app.exec()

if __name__ == "__main__":
    main()
```

## 三个关键细节

**1. QSqlDatabase 是连接池，用 `addDatabase` 获取。**

默认连接（不传第二个参数）在程序里只有一个。如果你需要多个连接，传不同名字：`QSqlDatabase.addDatabase("QSQLITE", "conn2")`。

**2. 连接用完要 `db.close()`，但进程退出前通常不必手动关。**

`QSqlDatabase.removeDatabase(name)` 可以显式移除连接。混用多个连接时尤其要注意：被其他对象引用的连接不能删。

**3. EditStrategy 决定"什么时候真正写库"。**

| 策略 | 时机 |
|---|---|
| OnFieldChange | 单元格失去焦点立即写库（每条改动一次事务） |
| OnRowChange | 换到另一行时提交 |
| OnManualSubmit | 只在调用 submitAll() 时提交，可批量 |

## 翻车现场一：忘了 `db.open()`，所有查询都返回空

**症状：程序不报错，但表是空的、查询也没有结果，`model.rowCount()` 永远是 0。**

**错误写法：**

```
db = QSqlDatabase.addDatabase("QSQLITE")
db.setDatabaseName("demo.db")
# 漏了 db.open()
model = QSqlTableModel()
model.setTable("books")
model.select()          # 静默返回 False，rowCount 为 0
```

**原因**：`addDatabase` + `setDatabaseName` 只是"配置"，没有真正建立连接。不调 `open()` 就不会打开文件，所有后续操作都针对一个无效连接。

**正确写法：**

```
db = QSqlDatabase.addDatabase("QSQLITE")
db.setDatabaseName("demo.db")
if not db.open():
    print("打开失败:", db.lastError().text())
    sys.exit(1)
```

## 翻车现场二：QSqlTableModel 忘了 `select()`，表格一片空白

**症状：表已经建好、也有数据，但 QTableView 死活不显示任何行。**

**错误写法：**

```
model = QSqlTableModel()
model.setTable("books")
# 漏了 model.select()
view.setModel(model)
```

**原因**：`setTable` 只是告诉 Model 要操作哪张表，并不会自动加载数据。`select()` 才是"去数据库拉数据"的动作。

**正确写法：**

```
model.setTable("books")
model.select()          # 拉取数据
view.setModel(model)
```

## 翻车现场三：数据库文件在网页/临时目录，路径一变就找不到表

**症状：本机跑得好好的，换台机器或换个工作目录就报"no such table"。**

**错误写法：**

```
db.setDatabaseName("demo.db")   # 相对路径，取决于当前工作目录
```

**正确做法**：用绝对路径，或用 Qt 的资源/应用数据目录：

```
import os
db_path = os.path.join(os.path.dirname(os.path.abspath(__file__)), "demo.db")
db.setDatabaseName(db_path)
```

## 翻车现场四：并发修改同一连接报"database is locked"

**症状**：多线程同时读写同一个 SQLite 连接，偶尔抛 `database is locked`。

**原因**：SQLite 是文件级锁，一个连接在同一时刻只允许一个写操作。Qt 的 Model/View 也在主线程用它。

**正确做法**：所有数据库操作都放在主线程，或为每个线程建独立连接（连接名不同），或换成支持并发的数据库引擎。

## 小结

- QtSql 支持 SQLite/MySQL/PostgreSQL 等，`QSqlDatabase.drivers()` 看驱动
- 标准流程：addDatabase → setDatabaseName → open → 建表 → 用 Model
- 必须 open()，必须 select()
- QSqlTableModel 可直接绑 QTableView，开箱可编辑
- EditStrategy 控制提交时机，OnManualSubmit 适合批量操作
- 数据库路径用绝对路径，避免工作目录漂移
- SQLite 单连接写操作串行，多线程要分连接
