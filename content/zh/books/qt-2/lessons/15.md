# 自定义控件实战：一个圆形进度指示器

> 前三课的工具全用上：继承 QWidget 自绘、处理鼠标事件、加自定义信号、用 QTimer 做动画。这一课做一个能点、能动、能发信号的圆形进度指示器。

## 目标：一个能点击、能动画、能发信号的圆形进度指示器

**功能清单：**

```
功能：
├── 显示 0~100 的进度（自绘圆环）
├── 鼠标拖动可以改变进度（处理鼠标事件）
├── 点击"播放"按钮开始自动动画（QTimer）
├── 进度到达 100 时发自定义信号（Signal）
└── 进度变化时发 progress_changed(value) 信号
```

**这个控件把第 11~14 课全部串起来：自绘（13）、事件（14）、继承扩展 + 信号（12）、复合控件打包（11）。**

## 第一步：骨架与自绘

**先把圆环画出来。**

```
from PySide6.QtCore import Qt, Signal, QTimer
from PySide6.QtGui import QPainter, QColor
from PySide6.QtWidgets import QWidget

class CircleProgress(QWidget):
    progress_changed = Signal(int)
    reached_100 = Signal()

    def __init__(self, parent=None):
        super().__init__(parent)
        self._value = 0                    # 0 ~ 100
        self.setMinimumSize(150, 150)
        self.setMouseTracking(True)

    def set_value(self, value):
        value = max(0, min(100, int(value)))
        if value == self._value:
            return
        self._value = value
        self.progress_changed.emit(self._value)
        if self._value == 100:
            self.reached_100.emit()
        self.update()

    def value(self):
        return self._value

    def paintEvent(self, event):
        painter = QPainter(self)
        painter.setRenderHint(QPainter.Antialiasing)

        rect = self.rect().adjusted(10, 10, -10, -10)
        pen_width = 12
        inner = rect.adjusted(pen_width//2, pen_width//2,
                             -pen_width//2, -pen_width//2)

        # 底环
        painter.setBrush(Qt.NoBrush)
        painter.setPen(Qt.NoPen)
        pen = painter.pen()
        pen.setWidth(pen_width)
        pen.setColor(QColor("#e8e8e8"))
        painter.setPen(pen)
        painter.drawEllipse(inner)

        # 进度环
        color = self._color_for(self._value)
        pen.setColor(color)
        painter.setPen(pen)
        span = int(-self._value * 3.6 * 16)
        painter.drawArc(inner, 90 * 16, span)

        # 中间文字
        painter.setPen(QColor("#333333"))
        font = painter.font()
        font.setPointSize(22)
        font.setBold(True)
        painter.setFont(font)
        painter.drawText(self.rect(), Qt.AlignCenter, f"{self._value}%")

        painter.end()

    def _color_for(self, value):
        if value >= 100:
            return QColor("#4caf50")
        if value >= 60:
            return QColor("#2196f3")
        return QColor("#ff9800")
```

**注意 set_value 里有个"防抖"判断：`if value == self._value: return`。** 避免重复设置相同值导致重复发信号。这是自定义控件的小细节，但很专业。

## 第二步：鼠标拖动改变进度

**把鼠标位置转成角度，再转成 0~100 的进度。**

```
class CircleProgress(QWidget):
    # ... 上面的代码 ...

    def mousePressEvent(self, event):
        if event.button() == Qt.LeftButton:
            self._update_from_pos(event.position().toPoint())
            self._dragging = True
        super().mousePressEvent(event)

    def mouseMoveEvent(self, event):
        if getattr(self, '_dragging', False):
            self._update_from_pos(event.position().toPoint())
        super().mouseMoveEvent(event)

    def mouseReleaseEvent(self, event):
        self._dragging = False
        super().mouseReleaseEvent(event)

    def _update_from_pos(self, pos):
        cx = self.width() // 2
        cy = self.height() // 2
        dx = pos.x() - cx
        dy = pos.y() - cy
        import math
        angle = math.degrees(math.atan2(-dy, dx))   # -dy 因为 y 轴向下
        # atan2 范围 -180~180，12 点钟方向是 -90°
        # 转换为从 12 点顺时针的 0~360
        if angle < 0:
            angle += 360
        # 12 点方向为 0，顺时针：angle = (angle + 90) % 360
        clockwise = (angle + 90) % 360
        self.set_value(clockwise / 360 * 100)
```

**角度计算是这一段的核心。** atan2 返回的是从 x 轴正方向（3 点钟）逆时针的角度，而我们的进度环从 12 点钟开始、顺时针增长。所以要 `-dy` 翻转 y 轴，再 `(angle + 90) % 360` 把 12 点对齐到 0。

**这里有个微妙点：atan2(-dy, dx) 得到的是数学坐标系下的角度（y 轴向上）。** 因为屏幕 y 轴向下，所以用 -dy 把它转正。这是坐标变换最容易出错的地方。

## 第三步：动画——QTimer 自动增长

**加一个 start_animation 和 stop_animation，用 QTimer 每 50ms 加一点。**

```
def start_animation(self, step=2, interval=50):
    if getattr(self, '_anim_timer', None) is None:
        self._anim_timer = QTimer(self)
        self._anim_timer.timeout.connect(self._animate_step)
    self._anim_step = step
    self._anim_timer.start(interval)

def stop_animation(self):
    if hasattr(self, '_anim_timer'):
        self._anim_timer.stop()

def _animate_step(self):
    if self._value >= 100:
        self.stop_animation()
        return
    self.set_value(self._value + self._anim_step)
```

**动画的本质就是"定时器 + 改数据 + update"。** 这和我们前面讲的所有原则一致：改数据后 update 触发重绘，paintEvent 负责绘制。

## 翻车现场一：QTimer 在 paintEvent 里创建，疯狂重绘

**症状：程序 CPU 占用飙升到 100%，paintEvent 被疯狂调用。**

```
def paintEvent(self, event):
    painter = QPainter(self)
    # ...
    painter.end()
    self._timer = QTimer(self)          # ❌ paintEvent 里创建定时器
    self._timer.timeout.connect(self._step)
    self._timer.start(16)
```

**原因：paintEvent 会被反复调用（每次 update、每次重绘）。在里面创建定时器、start，等于创建了无数个定时器，每个都在触发 update，又触发更多 paintEvent——死循环。**

**✅ 正确做法：定时器在 __init__ 或独立方法里创建，绝不在 paintEvent 里。**

```
def __init__(self, parent=None):
    super().__init__(parent)
    self._value = 0
    self._timer = QTimer(self)                # ✅ 构造时创建一次
    self._timer.timeout.connect(self._step)
    self.setMinimumSize(150, 150)

def start_animation(self):
    self._timer.start(50)
```

## 翻车现场二：进度到 100 后动画停了但状态不对

**症状：进度到 100 动画停了，但圆环颜色没变绿（还是蓝色），或者 reached_100 信号只发了一次，第二次再跑没发。**

```
def _animate_step(self):
    self.set_value(self._value + self._anim_step)
    if self._value >= 100:          # ❌ 判断用的是 _value，但 set_value 里会 emit
        self.stop_animation()
```

**原因：set_value 里已经有 `if self._value == 100: emit reached_100` 了，你在这里又判断一遍，逻辑重复，容易漏发或多发。**

**✅ 正确做法：让 set_value 作为唯一的状态管理者，动画逻辑只管"加值 + 到顶就停"。**

```
def _animate_step(self):
    if self._value >= 100:
        self.stop_animation()
        return
    self.set_value(self._value + self._anim_step)
```

**状态变化集中在 set_value 里处理（发信号、判断 100），动画只负责"推进"。这是单一职责。**

## 翻车现场三：鼠标拖动时进度抖动，因为鼠标在圆外时角度跳变

**症状：拖动到圆环底部附近时，进度在 99 和 0 之间反复跳。**

```
def _update_from_pos(self, pos):
    # ... 角度计算 ...
    clockwise = (angle + 90) % 360
    self.set_value(clockwise / 360 * 100)   # 在 359° 和 0° 交界处跳变
```

**原因：359° 附近的一点点移动就变成了 0°，视觉上进度条"翻转"了。**

**✅ 正确做法：加个死区，或者在鼠标按下时记录起始角度，用相对移动而不是绝对位置。**

```
def _update_from_pos(self, pos):
    cx = self.width() // 2
    cy = self.height() // 2
    dx = pos.x() - cx
    dy = pos.y() - cy
    import math
    angle = math.degrees(math.atan2(-dy, dx))
    if angle < 0:
        angle += 360
    clockwise = (angle + 90) % 360

    # 死区：接近 0°（顶部）时不做更新，避免抖动
    if 350 < clockwise < 360 or 0 <= clockwise < 10:
        if abs(clockwise - self._value / 100 * 360) > 20:
            return           # 跳变太大就忽略这次更新

    self.set_value(clockwise / 360 * 100)
```

**这是一个"够用"的简化处理。生产级控件会用鼠标按下的起始点做增量计算，避免绝对角度的跳变。**

## 完整组装：放进一个窗口

```
from PySide6.QtWidgets import QApplication, QWidget, QPushButton, QVBoxLayout, QHBoxLayout

app = QApplication(sys.argv)
win = QWidget()
win.setWindowTitle("圆形进度指示器")

circle = CircleProgress()
circle.reached_100.connect(lambda: print("到达 100%！"))

start_btn = QPushButton("开始动画")
stop_btn = QPushButton("停止")
reset_btn = QPushButton("重置")

start_btn.clicked.connect(lambda: circle.start_animation(2, 50))
stop_btn.clicked.connect(circle.stop_animation)
reset_btn.clicked.connect(lambda: circle.set_value(0))

h = QHBoxLayout()
h.addWidget(start_btn)
h.addWidget(stop_btn)
h.addWidget(reset_btn)

layout = QVBoxLayout(win)
layout.addWidget(circle)
layout.addLayout(h)
win.resize(300, 400)
win.show()
app.exec()
```

## 小结

- 自绘圆环 = 底环（drawEllipse）+ 进度弧（drawArc）+ 居中文字
- set_value 要做防抖（相同值不发信号）和单一职责（集中处理状态变化）
- 鼠标拖动改进度需要坐标→角度→进度的转换，注意 y 轴翻转
- 动画 = QTimer + 改数据 + update，定时器绝不能在 paintEvent 里创建
- 状态变化集中在 set_value，动画只管推进，保持单一职责
- 圆环顶部是角度跳变区，拖动时可能需要死区处理
- 自定义信号用 Signal() 定义成类属性，emit 时传值
