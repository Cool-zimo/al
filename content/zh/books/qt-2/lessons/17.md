# 基本图形：线、矩形、圆、多边形、文字与图片

> 上一节你画了一条线，这一节把 QPainter 的"图元工具箱"一次铺开——直线、矩形、圆角矩形、椭圆、多边形、文字、图片，以及让一切变好看的开关：抗锯齿。

## 图元速查表

| 方法 | 作用 | 典型参数 |
|---|---|---|
| drawLine | 线段 | QPoint, QPoint 或 x1,y1,x2,y2 |
| drawRect | 矩形（含边框） | QRect 或 x,y,w,h |
| drawRoundedRect | 圆角矩形 | rect, xRadius, yRadius |
| drawEllipse | 椭圆/圆 | QRect（外接矩形）或 中心+横纵半径 |
| drawPolygon | 多边形 | QPolygonF 或 QPolygon |
| drawPie | 扇形 | rect, startAngle, spanAngle（1/16 度） |
| drawArc | 圆弧 | 同上，只画线不填 |
| drawText | 文字 | rect + 对齐标志 + 字符串 |
| drawPixmap | 贴图 | QPoint 或 rect + QPixmap |
| drawImage | 贴 QImage | 同上 |

```
import sys
from PySide6.QtWidgets import QApplication, QWidget
from PySide6.QtCore import Qt, QRect, QPoint, QPointF, QLineF
from PySide6.QtGui import QPainter, QPen, QBrush, QPolygonF, QPixmap

class ShapesDemo(QWidget):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("基本图形")
        self.resize(480, 320)

    def paintEvent(self, event):
        p = QPainter(self)
        p.setRenderHint(QPainter.RenderHint.Antialiasing)

        # 1. 线
        p.setPen(QPen(Qt.GlobalColor.darkGreen, 2, Qt.PenStyle.DashLine))
        p.drawLine(20, 30, 200, 30)

        # 2. 矩形（有边框、有填充）
        p.setPen(QPen(Qt.GlobalColor.black, 1))
        p.setBrush(QBrush(Qt.GlobalColor.cyan))
        p.drawRect(QRect(20, 50, 120, 60))

        # 3. 圆角矩形
        p.setBrush(QBrush(Qt.GlobalColor.yellow))
        p.drawRoundedRect(QRect(160, 50, 120, 60), 12, 12)

        # 4. 圆（正方形外接框 + drawEllipse）
        p.setBrush(QBrush(Qt.GlobalColor.red))
        p.drawEllipse(QRect(20, 130, 80, 80))

        # 5. 多边形
        poly = QPolygonF([
            QPointF(130, 210), QPointF(170, 130),
            QPointF(210, 210), QPointF(170, 190),
        ])
        p.setBrush(QBrush(Qt.GlobalColor.magenta))
        p.drawPolygon(poly)

        # 6. 文字
        p.setPen(QPen(Qt.GlobalColor.black))
        p.setFont(QFont("Sans", 14, QFont.Weight.Bold))
        p.drawText(QRect(240, 50, 200, 40),
                   Qt.AlignmentFlag.AlignLeft | Qt.AlignmentFlag.AlignVCenter,
                   "你好，PySide6")

        # 7. 图片
        px = QPixmap(60, 60)
        px.fill(Qt.GlobalColor.blue)
        p.drawPixmap(QPoint(300, 150), px)

if __name__ == "__main__":
    app = QApplication(sys.argv)
    w = ShapesDemo()
    w.show()
    app.exec()
```

## 抗锯齿：一行代码，观感天差地别

```
p.setRenderHint(QPainter.RenderHint.Antialiasing)          # 图形边缘平滑
p.setRenderHint(QPainter.RenderHint.TextAntialiasing)      # 文字平滑（默认开启）
p.setRenderHint(QPainter.RenderHint.SmoothPixmapTransform) # 缩放图片平滑
```

不加抗锯齿时，斜线和圆的边缘是一圈锯齿状的台阶；开了之后 Qt 会做边缘羽化。代价是略多一点的计算，普通桌面程序可以无脑全开。

## 坐标系与尺寸

QPainter 的坐标系原点 `(0, 0)` 在**窗口左上角**，x 向右增大，y 向下增大。所有坐标都是相对于当前变换后的坐标系，单位是像素。

`event.rect()` 告诉你本次重绘的"脏区域"——优化场景下可以只画这个矩形内的内容；但入门阶段直接画全窗口通常也没问题。

## 翻车现场一：drawEllipse 传了四个数想画圆，结果画成椭圆

**症状：想画个正圆，出来的却是个扁椭圆，宽度和高度不一致。**

**错误写法：**

```
p.drawEllipse(20, 130, 80, 100)   # 宽 80、高 100，是椭圆
```

**原因**：`drawEllipse(x, y, w, h)` 的第三、四个参数是宽度和高度，不等就是椭圆。想画圆必须让 w == h。

**正确写法：**

```
p.drawEllipse(QRect(20, 130, 80, 80))   # 正方形外接框 = 正圆

# 或者用"中心 + 横纵半径"的重载，更直观
p.drawEllipse(QPoint(60, 170), 40, 40)  # 中心(60,170)，半径 40
```

## 翻车现场二：画了文字但中文全变成豆腐块/乱码

**症状：界面上中文显示为方框 `□□□` 或乱码。**

**错误写法：**

```
p.setFont(QFont("SomeMissingFont", 14))
p.drawText(rect, "你好")
```

**原因**：指定的字体名在系统里不存在，Qt 回退到不支持中文的字体；或者字符串本身的编码不是 Unicode（极少见，Python 源码默认 UTF-8）。

**正确做法**：用系统确定存在的字体，或直接用默认字体，只改字号和粗细：

```
font = QFont()
font.setPointSize(14)
font.setBold(True)
p.setFont(font)
p.drawText(rect, "你好，PySide6")
```

## 翻车现场三：drawPixmap 图片没显示，路径没错

**症状：`drawPixmap(0, 0, QPixmap("logo.png"))` 什么都没画出来，也没有报错。**

**错误写法：**

```
px = QPixmap("logo.png")     # 文件不存在或路径相对位置不对
p.drawPixmap(0, 0, px)       # 静默失败，画布上什么都不出现
```

**原因**：QPixmap 加载失败时会变成一个空对象（`px.isNull()` 为 True），但**不会抛异常**。paintEvent 里画空 pixmap 就是什么都没有。

**正确做法**：加载后检查，用绝对路径或 resource 系统：

```
px = QPixmap("logo.png")
if px.isNull():
    print("图片加载失败，检查路径")   # 先打印确认，再排查
else:
    p.drawPixmap(0, 0, px)
```

## 小结

- drawRect / drawRoundedRect / drawEllipse / drawPolygon 是日常最常用的图元
- 画正圆要用等宽等高的外接矩形，或"中心+半径"重载
- 抗锯齿三件套：Antialiasing、TextAntialiasing、SmoothPixmapTransform
- 坐标左上角为原点，y 轴向下
- QPixmap 加载失败不报错，务必 `isNull()` 检查
- 中文字体问题优先确认字体存在、字号用默认字体只改大小
