# QtSql 与 Model/View 结合：QSqlQueryModel vs QSqlTableModel

> 同样是"把 SQL 结果绑到 QTableView"，QSqlQueryModel 和 QSqlTableModel 走的是两条路：一个只读任意 SELECT，一个可编辑单表。这一节把两者的取舍讲透。

## 两者的定位

| | QSqlQueryModel | QSqlTableModel |
|---|---|---|
| 用途 | 执行任意 SELECT，只读展示 | 操作单张表，可编辑 |
| 设置数据 | setQuery(sql) | setTable(name) + select() |
| 可编辑 | 否（默认） | 是 |
| 复杂 SQL | 支持 JOIN、GROUP BY、子查询 | 不支持 |
| 提交策略 | 无 | EditStrategy（OnFieldChange/OnRowChange/OnManualSubmit） |
| 增删行 | 不支持 | insertRow / removeRow |
| 典型场景 | 报表、统计、联表查询 | 单表 CRUD 界面 |

## QSqlQueryModel：只读的任意查询

```
from PySide6.QtWidgets import QApplication, QTableView
from PySide6.QtSql import QSqlDatabase, QSqlQueryModel

def main():
    app = QApplication([])
    db = QSqlDatabase.addDatabase("QSQLITE")
    db.setDatabaseName("books.db")
    db.open()

    model = QSqlQueryModel()
    model.setQuery(
        "SELECT author, COUNT(*) AS cnt, AVG(price) AS avg_price "
        "FROM books GROUP BY author ORDER BY avg_price DESC"
    )
    model.setHeaderData(0, Qt.Orientation.Horizontal, "作者")
    model.setHeaderData(1, Qt.Orientation.Horizontal, "数量")
    model.setHeaderData(2, Qt.Orientation.Horizontal, "均价")

    view = QTableView()
    view.setModel(model)
    view.show()
    app.exec()
```

注意 `setHeaderData` 在 QueryModel 上设置表头，是给**显示**用的；但 QueryModel 的列对应 SELECT 的列顺序，不能随便 reorder。

## QSqlTableModel：可编辑的单表

```
model = QSqlTableModel()
model.setTable("books")
model.setEditStrategy(QSqlTableModel.EditStrategy.OnRowChange)
model.select()
view.setModel(model)
# 双击单元格即可编辑，失去焦点后自动提交
```

如果想批量编辑、手动提交：

```
model.setEditStrategy(QSqlTableModel.EditStrategy.OnManualSubmit)
# ... 用户改了很多单元格 ...
model.submitAll()          # 一次性提交
# 放弃修改：model.revertAll()
```

## 让 QSqlQueryModel 可编辑（进阶）

继承 QSqlQueryModel 重写 `flags` 和 `setData`，再在 setData 里手写 UPDATE SQL：

```
class EditableQueryModel(QSqlQueryModel):
    def flags(self, index):
        fl = super().flags(index)
        if index.column() in (1, 2):     # 允许编辑第 2、3 列
            fl |= Qt.ItemFlag.ItemIsEditable
        return fl

    def setData(self, index, value, role=Qt.ItemDataRole.EditRole):
        if role != Qt.ItemDataRole.EditRole:
            return False
        row = index.row()
        # 需要拿到主键 id，这里假定第 0 列是 id
        id_idx = self.index(row, 0)
        record_id = self.data(id_idx)
        col_name = self.record().fieldName(index.column())
        q = QSqlQuery()
        q.prepare(f"UPDATE books SET {col_name} = ? WHERE id = ?")
        q.addBindValue(value)
        q.addBindValue(record_id)
        if q.exec():
            self.refresh()
            return True
        return False

    def refresh(self):
        self.setQuery(self.query().lastQuery())   # 重新执行原查询
```

## 翻车现场一：用 QSqlQueryModel 想双击编辑，改了没反应

**症状：双击单元格能进入编辑状态，输入内容后回车，值瞬间恢复原样。

**原因**：QSqlQueryModel 默认 `flags()` 不含 `ItemIsEditable`，它的 setData 返回 False。它是**只读**设计——因为任意 SELECT 的结果不一定能映射回某张表的某一行。

**正确做法**：如果源是单表，换成 QSqlTableModel；如果是复杂查询，就自定义可编辑的 QueryModel（如上）。

## 翻车现场二：QSqlTableModel 用了 JOIN，setTable 报错

**症状：想展示"订单+客户名"，写个 JOIN 查出来，绑到 TableModel 后无法编辑，甚至 select 失败。

**错误写法：**

```
model.setTable("orders JOIN customers ON orders.cid = customers.id")
```

**原因**：`setTable` 接受的是**表名**，不是任意 SQL。它要靠表名去生成 UPDATE/INSERT/DELETE 语句，JOIN 结果无法反推出该改哪张表。

**正确做法**：单表操作用 TableModel；联表展示用 QueryModel（只读），或 QSqlRelationalTableModel。

## 翻车现场三：OnManualSubmit 改了数据没调 submitAll，一刷新全没了

**症状：用户在表格里改了半天，切个页面或关窗口再回来，改动全没了。

**原因**：OnManualSubmit 策略下，改动只在内存里，不调 submitAll 就不会写库。

**正确做法**：在合适的时机（保存按钮、窗口关闭事件）调用 `model.submitAll()`；要放弃就 `revertAll()`。

## 翻车现场四：setHeaderData 设了表头但显示不出来

**症状**：表头还是 id/title/author 这种列名。

**原因**：QueryModel 的 setHeaderData 要指定正确的 section 和水平方向，且必须在 setQuery 之后调用（setQuery 会重建表头）。

**正确写法：**

```
model.setQuery("SELECT id, title, price FROM books")
model.setHeaderData(0, Qt.Orientation.Horizontal, "编号")
model.setHeaderData(1, Qt.Orientation.Horizontal, "书名")
model.setHeaderData(2, Qt.Orientation.Horizontal, "价格")
```

## 小结

- QSqlQueryModel：任意 SELECT，只读，适合报表/统计
- QSqlTableModel：单表可编辑，开箱即用
- 复杂 SQL + 需要编辑 = 自定义 QueryModel 子类
- JOIN 结果不能绑 TableModel
- EditStrategy 决定提交时机，OnManualSubmit 需手动 submitAll
- QueryModel 的 setHeaderData 要在 setQuery 之后
- 想放弃修改用 revertAll()

## 随堂练习

```quiz
type: local
q: 用 QSqlTableModel 做一个"商品价格管理"界面：表 products，字段 id/name/price/stock。要求：① 单价大于 100 的商品，那一行整行背景显示为浅黄色（在 Model 的 data 方法里返回 Qt.ItemDataRole.BackgroundRole）；② 编辑策略用 OnRowChange；③ 加一个"筛选：仅显示缺货（stock=0）"的复选框，勾选后重新 select 带 WHERE 条件。注意：这是窗口程序，网页里跑不了，请点"在 VS Code 里打开"运行。
starter: |
  import sys
  from PySide6.QtWidgets import (QApplication, QTableView, QWidget, QVBoxLayout,
                                QCheckBox)
  from PySide6.QtSql import QSqlDatabase, QSqlTableModel, QSqlQuery
  from PySide6.QtCore import Qt
  from PySide6.QtGui import QBrush, QColor

  DB_PATH = "products.db"

  def init_db():
      db = QSqlDatabase.addDatabase("QSQLITE")
      db.setDatabaseName(DB_PATH)
      db.open()
      q = QSqlQuery()
      q.exec("CREATE TABLE IF NOT EXISTS products ("
             "id INTEGER PRIMARY KEY AUTOINCREMENT,"
             "name TEXT, price REAL, stock INTEGER DEFAULT 0)")
      q.exec("DELETE FROM products")
      for n, p, s in [("键盘", 199.0, 10), ("鼠标", 59.0, 0),
                      ("显示器", 1299.0, 3), ("耳机", 89.0, 0)]:
          q.prepare("INSERT INTO products (name, price, stock) VALUES (?,?,?)")
          q.addBindValue(n); q.addBindValue(p); q.addBindValue(s)
          q.exec()

  class ProductModel(QSqlTableModel):
      def data(self, index, role=Qt.ItemDataRole.DisplayRole):
          # 在这里处理 BackgroundRole：price > 100 返回浅黄画刷
          if role == Qt.ItemDataRole.BackgroundRole:
              price = float(self.index(index.row(), 2).data() or 0)
              if price > 100:
                  return QBrush(QColor(255, 255, 200))
          return super().data(index, role)

  def main():
      app = QApplication([])
      init_db()
      window = QWidget()
      window.setWindowTitle("商品管理")
      window.resize(600, 400)

      model = ProductModel()
      model.setTable("products")
      model.setEditStrategy(QSqlTableModel.EditStrategy.OnRowChange)
      model.select()
      model.setHeaderData(0, Qt.Orientation.Horizontal, "编号")
      model.setHeaderData(1, Qt.Orientation.Horizontal, "名称")
      model.setHeaderData(2, Qt.Orientation.Horizontal, "单价")
      model.setHeaderData(3, Qt.Orientation.Horizontal, "库存")

      view = QTableView()
      view.setModel(model)
      cb = QCheckBox("仅显示缺货")
      # 连接 cb 的 stateChanged：勾选时 model.setFilter("stock=0"); model.select()

      layout = QVBoxLayout(window)
      layout.addWidget(cb)
      layout.addWidget(view)
      window.show()
      app.exec()

  if __name__ == "__main__":
      main()
checklist:
- ProductModel 重写 data 处理 BackgroundRole
- 单价>100 的行显示浅黄色背景
- 编辑策略为 OnRowChange
- 复选框勾选时调用 setFilter("stock=0") 并 select
- 取消勾选时显示全部（setFilter("") + select）
- 价格/库存可编辑并自动提交
- 程序正常显示
```

type: local

starter: |
  import sys
  from PySide6.QtWidgets import QApplication, QTableView, QWidget, QVBoxLayout
  from PySide6.QtSql import QSqlDatabase, QSqlQueryModel, QSqlQuery
  from PySide6.QtCore import Qt

  DB_PATH = "products2.db"

  def init_db():
      db = QSqlDatabase.addDatabase("QSQLITE")
      db.setDatabaseName(DB_PATH)
      db.open()
      q = QSqlQuery()

  class EditableQueryModel(QSqlQueryModel):

          if index.column() == 2:        # price 列可编辑

      def setData(self, index, value, role=Qt.ItemDataRole.EditRole):

          self.setQuery("SELECT id, name, price FROM products")
