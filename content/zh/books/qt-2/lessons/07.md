# 自定义排序与过滤：lessThan 与 filterAcceptsRow

> 默认的字符串排序不够用：你想让"待办 < 进行中 < 完成"，或者按日期排，或者只显示"金额大于 1000 且未完成的行"。这些都要自己写——继承 proxy，重写 lessThan 和 filterAcceptsRow。

## lessThan：排序时怎么比大小，你说了算

**lessThan(left, right) 返回 True 表示 left 应该排在 right 前面。默认实现是按 DisplayRole 文本比较。**

```
from PySide6.QtCore import QSortFilterProxyModel, Qt

class StatusSortProxy(QSortFilterProxyModel):
    def lessThan(self, left, right):
        # left/right 是 source model 的 QModelIndex
        left_val = self.sourceModel().data(left, Qt.DisplayRole)
        right_val = self.sourceModel().data(right, Qt.DisplayRole)
        return left_val < right_val       # 默认行为：文本比较
```

**关键点：left 和 right 是 source model 坐标系的 index。** proxy 会自动做 mapToSource，你拿到的就是源头的 index，可以直接喂给 sourceModel().data()。

**为什么是 source 坐标？** 因为排序是 proxy 自己的内部状态，它知道"我在排的是 source 的第几行"，它把最原始的信息给你，你自己决定怎么比。

## 翻车现场一：在 lessThan 里用 proxy 的 index 去查数据，行号错乱

**症状：排序结果乱七八糟，完全不对。

```
class BadProxy(QSortFilterProxyModel):
    def lessThan(self, left, right):
        # ❌ left/right 已经是 source 坐标，再 mapToSource 就错了
        src_left = self.mapToSource(left)
        return self.sourceModel().data(src_left).text() < ...
```

**原因：Qt 传给 lessThan 的 left/right 已经是 source model 的 index。** 你再 mapToSource，等于做了一次不存在的转换，行号全错。

**✅ 正确做法：直接用 left/right 访问 sourceModel。**

```
def lessThan(self, left, right):
    model = self.sourceModel()
    l = model.data(left, Qt.DisplayRole)      # ✅ 直接用
    r = model.data(right, Qt.DisplayRole)
    return l < r
```

## 自定义排序实战：状态优先级

**需求："待办"排最前，"进行中"其次，"完成"最后。**

```
class StatusSortProxy(QSortFilterProxyModel):
    _ORDER = {"待办": 0, "进行中": 1, "完成": 2}

    def lessThan(self, left, right):
        model = self.sourceModel()
        l_status = model.data(model.index(left.row(), 1), Qt.DisplayRole)
        r_status = model.data(model.index(right.row(), 1), Qt.DisplayRole)
        l_rank = self._ORDER.get(l_status, 99)
        r_rank = self._ORDER.get(r_status, 99)
        return l_rank < r_rank
```

**用一个字典把状态映射到数字，比较数字即可。** 这是自定义排序最常用、最清爽的套路。

## 翻车现场二：只用 DisplayRole 比较日期，字符串比较出错

**症状：日期列 "2024-1-15" 排在 "2024-12-3" 后面（按字符串是对的），但 "2024-2-1" 排在 "2024-10-5" 前面（字符串 "2" < "1" 不成立）。**

```
# data() 返回的是 "2024-2-1" 这样的字符串
def lessThan(self, left, right):
    l = self.sourceModel().data(left, Qt.DisplayRole)   # "2024-2-1"
    r = self.sourceModel().data(right, Qt.DisplayRole)  # "2024-10-5"
    return l < r      # ❌ 字符串比较："2024-2-1" < "2024-10-5" 是 True（'2' < '1' 不成立）
```

**原因：ISO 格式的日期字符串 "YYYY-M-D" 月份和日期不是零填充的，字典序不等于时间序。**

**✅ 正确做法：在 data() 里提供 UserRole 存 datetime 对象，lessThan 用 UserRole 比。**

```
# source model 的 data()
if role == Qt.UserRole and column == 2:      # 日期列
    return self._rows[row][column]           # 这是 datetime.date

def lessThan(self, left, right):
    model = self.sourceModel()
    l = model.data(left, Qt.UserRole)        # ✅ 拿到 date 对象
    r = model.data(right, Qt.UserRole)
    if l is None or r is None:
        return False
    return l < r
```

**给 model 提供"逻辑值"角色（UserRole），是让排序、过滤、编辑都更顺的唯一正解。**

## filterAcceptsRow：决定哪行能留下

**返回 True 表示这一行通过过滤、要显示；False 表示过滤掉。**

```
class NumberFilterProxy(QSortFilterProxyModel):
    def filterAcceptsRow(self, source_row, source_parent):
        model = self.sourceModel()
        idx = model.index(source_row, 1, source_parent)   # 金额列
        value = model.data(idx, Qt.UserRole)              # 拿逻辑值
        if value is None:
            return True
        return value >= 1000                              # 只显示 ≥ 1000 的
```

**参数 source_row 是 source model 里的行号，source_parent 用于树形结构（表格里永远是无效 QModelIndex）。**

## 翻车现场三：filterAcceptsRow 里用错了列号，过滤结果全错

**症状：想按金额过滤，结果按姓名过滤了。

```
def filterAcceptsRow(self, source_row, source_parent):
    idx = self.sourceModel().index(source_row, 0, source_parent)  # ❌ 第 0 列是姓名
    value = self.sourceModel().data(idx, Qt.UserRole)
    return value >= 1000     # 姓名的 UserRole 是 None，全返回 False → 啥都不显示
```

**✅ 正确做法：确认你要过滤的那一列的 index 是对的。**

```
idx = self.sourceModel().index(source_row, 1, source_parent)   # ✅ 第 1 列是金额
```

**这种"列号对不上"的 bug 很隐蔽，因为不会报错，只是结果悄悄不对。** 解决方法是把列号定义成常量。

```
class AmountFilterProxy(QSortFilterProxyModel):
    AMOUNT_COLUMN = 1

    def filterAcceptsRow(self, source_row, source_parent):
        idx = self.sourceModel().index(source_row, self.AMOUNT_COLUMN, source_parent)
        value = self.sourceModel().data(idx, Qt.UserRole)
        return value is not None and value >= self._min_amount
```

## 翻车现场四：filterAcceptsRow 每次都重新算阈值，参数改不了

**症状：想在界面上动态调整过滤阈值（比如一个 QSpinBox 控制"≥ 多少"），发现 filterAcceptsRow 是只读的、拿不到外部参数。**

```
class BadFilter(QSortFilterProxyModel):
    def filterAcceptsRow(self, source_row, source_parent):
        idx = self.sourceModel().index(source_row, 1, source_parent)
        value = self.sourceModel().data(idx, Qt.UserRole)
        return value >= 1000       # ❌ 阈值写死了
```

**✅ 正确做法：把阈值存成实例属性，提供 setter，改完调 invalidateFilter()。**

```
class AmountFilterProxy(QSortFilterProxyModel):
    AMOUNT_COLUMN = 1

    def __init__(self, parent=None):
        super().__init__(parent)
        self._min_amount = 0

    def set_min_amount(self, value):
        self._min_amount = value
        self.invalidateFilter()        # ✅ 关键：让 proxy 重新过一遍 filterAcceptsRow

    def filterAcceptsRow(self, source_row, source_parent):
        idx = self.sourceModel().index(source_row, self.AMOUNT_COLUMN, source_parent)
        value = self.sourceModel().data(idx, Qt.UserRole)
        return value is not None and value >= self._min_amount
```

**`invalidateFilter()` 是告诉 proxy"你的过滤条件变了，重新算一遍"。** 不调用它，即使属性改了，显示也不会更新——又一个"界面不刷新"的坑。

## 组合拳：动态过滤 + 自定义排序

**一个 proxy 同时重写 lessThan 和 filterAcceptsRow，就是"自定义排序 + 自定义过滤"。**

```
class SmartProxy(QSortFilterProxyModel):
    def __init__(self, parent=None):
        super().__init__(parent)
        self._min_amount = 0
        self._keyword = ""

    def set_min_amount(self, v):
        self._min_amount = v
        self.invalidateFilter()

    def set_keyword(self, kw):
        self._keyword = kw
        self.invalidateFilter()

    def filterAcceptsRow(self, source_row, source_parent):
        model = self.sourceModel()
        # 条件1：金额达标
        amt_idx = model.index(source_row, 1, source_parent)
        amt = model.data(amt_idx, Qt.UserRole)
        if amt is None or amt < self._min_amount:
            return False
        # 条件2：姓名包含关键字
        name_idx = model.index(source_row, 0, source_parent)
        name = model.data(name_idx, Qt.DisplayRole) or ""
        if self._keyword and self._keyword not in name:
            return False
        return True

    def lessThan(self, left, right):
        # 状态优先级排序
        model = self.sourceModel()
        order = {"待办": 0, "进行中": 1, "完成": 2}
        l = model.data(model.index(left.row(), 2), Qt.DisplayRole)
        r = model.data(model.index(right.row(), 2), Qt.DisplayRole)
        return order.get(l, 99) < order.get(r, 99)
```

## 小结

- lessThan(left, right) 返回 True 表示 left 应排在 right 前
- lessThan 收到的 index 已经是 source 坐标，不要再次 mapToSource
- 自定义排序用"映射成数字"的字典套路最清爽
- 日期等类型要存 UserRole 逻辑值，否则字符串比较出错
- filterAcceptsRow 返回 True 表示这行显示，False 表示过滤掉
- 过滤阈值要存属性 + setter + invalidateFilter() 三件套
- 一个 proxy 可同时重写 lessThan 和 filterAcceptsRow
