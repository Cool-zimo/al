# 委托 Delegate：为什么单元格要能放按钮/进度条/下拉框

> 单元格里只能放文字吗？不是。Model/View 的第三块拼图是 Delegate（委托）：它决定一个单元格"怎么画、怎么编辑"。默认的 QStyledItemDelegate 只画文字、只弹输入框，你想放进度条、下拉框、按钮，就得自己写 delegate。

## Delegate 解决什么问题

**前面我们说的 model 管数据、view 管显示。但"显示"这件事其实可以再拆：view 管布局（谁在哪儿），delegate 管绘制（长什么样）和编辑（怎么输入）。**

| 角色 | 管什么 |
|---|---|
| Model | 数据、角色值 |
| View | 布局、选中、滚动 |
| Delegate | 单个单元格的绘制和编辑 |

**默认 delegate 是 `QStyledItemDelegate`。** 你不写任何 delegate，view 就用它：文字用系统字体画，双击编辑弹出一个 QLineEdit。

**什么时候必须自己写 delegate？**

```
需求场景举例：
├── 成绩列显示成进度条（不是数字）
├── 状态列显示成带颜色的下拉框
├── 操作列放一个"删除"按钮
├── 日期列点击弹出日历选择器
└── 评分列双击弹出 1~5 星
```

**这些都是"一个单元格要长得不像文字"的需求。** 你不该把按钮塞进 model（model 不认识 widget），也不该 hack view，正确的做法是写一个 delegate 装到 view 上。

## 装 delegate 到 view

**view 提供三个粒度：整个 view 一套、某一列、某一行。**

```
from PySide6.QtWidgets import QStyledItemDelegate

class ProgressDelegate(QStyledItemDelegate):
    pass    # 暂空，下一课填

# 整个 view 用一套
view.setItemDelegate(ProgressDelegate())

# 只给某一列
view.setItemDelegateForColumn(1, ProgressDelegate())

# 只给某一行
view.setItemDelegateForRow(0, ProgressDelegate())
```

**粒度很重要：给第 1 列装进度条 delegate，其余列保持默认。** 这就是"成绩列画成进度条、姓名列还是文字"的实现方式。

## Delegate 的四个核心方法

| 方法 | 何时调用 | 干什么 |
|---|---|---|
| `paint(painter, option, index)` | 绘制单元格 | 用 QPainter 画你想要的样子 |
| `createEditor(parent, option, index)` | 双击开始编辑 | 返回一个编辑器 widget |
| `setEditorData(editor, index)` | 编辑器弹出时 | 把 model 数据灌进编辑器 |
| `setModelData(editor, model, index)` | 编辑完成时 | 把编辑器的值写回 model |

**这四个方法是 delegate 的全部。前两管"看"，后两管"改"。**

## paint：自己动手画

**paint 接收一个 QPainter、一个 option（包含矩形区域、状态等）、一个 index。**

```
from PySide6.QtCore import Qt
from PySide6.QtGui import QPainter, QColor
from PySide6.QtWidgets import QStyledItemDelegate, QApplication

class ProgressDelegate(QStyledItemDelegate):
    def paint(self, painter, option, index):
        # 先让基类画背景（选中、hover 等）
        super().paint(painter, option, index)

        value = index.data(Qt.UserRole)          # 拿逻辑值：0~100 的整数
        if value is None:
            return

        rect = option.rect
        bar_width = int(rect.width() * value / 100)

        painter.save()
        # 画背景槽
        painter.setPen(Qt.NoPen)
        painter.setBrush(QColor("#eeeeee"))
        painter.drawRect(rect)

        # 画进度条
        painter.setBrush(QColor("#4caf50"))
        painter.drawRect(rect.x(), rect.y(), bar_width, rect.height())

        # 画文字
        painter.setPen(QColor("#333333"))
        painter.drawText(rect, Qt.AlignCenter, f"{value}%")
        painter.restore()
```

**paint 的纪律：`super().paint()` 先画背景，保证选中态、hover 态、禁用态都正常；然后用 save()/restore() 包裹你的自定义绘制，避免画笔状态污染别的单元格。**

## 翻车现场一：只画了进度条，选中态全丢了

**症状：单元格能显示进度条，但点击选中这行时，别的列都变蓝了，只有进度条那列还是灰色背景。

```
def paint(self, painter, option, index):
    # ❌ 没调 super().paint()，背景完全没画
    value = index.data(Qt.UserRole)
    painter.setBrush(QColor("#4caf50"))
    painter.drawRect(option.rect.adjusted(2, 2, -2, -2))
    painter.drawText(option.rect, Qt.AlignCenter, f"{value}%")
```

**原因：QStyledItemDelegate.paint 负责画背景（选中高亮、hover、焦点框）。** 你完全不调它，这些视觉反馈就没了。

**✅ 正确做法：先 super().paint() 画背景，再叠你的内容。**

```
def paint(self, painter, option, index):
    super().paint(painter, option, index)    # ✅ 背景、选中态都在
    painter.save()
    # ... 你的绘制
    painter.restore()
```

**或者：如果你想完全自定义背景，就自己读 option.state 判断选中态。**

```
if option.state & QStyle.State_Selected:
    painter.fillRect(option.rect, option.palette.highlight())
```

## 翻车现场二：没 save/restore，画笔状态污染了相邻单元格

**症状：进度条那列画对了，但旁边的文字列颜色也变成了绿色、字体也变了。

```
def paint(self, painter, option, index):
    painter.setPen(QColor("green"))      # ❌ 设了绿色画笔
    painter.setFont(some_big_font)       # ❌ 换了字体
    # 画完没恢复
    painter.drawText(...)
```

**原因：QPainter 是 view 复用的同一个对象，所有单元格共用一支笔。** 你改了它的颜色、字体、变换矩阵，不还原，下一个单元格继承的就是被污染的状态。

**✅ 正确做法：save() 和 restore() 成对。**

```
def paint(self, painter, option, index):
    painter.save()                 # ✅ 保存当前状态
    painter.setPen(QColor("green"))
    painter.setFont(some_big_font)
    # ... 绘制
    painter.restore()              # ✅ 还原
```

## sizeHint：告诉 view 我需要多大

**如果你的自定义绘制比默认文字高（比如要画两行、画一个色块），需要重写 sizeHint。**

```
def sizeHint(self, option, index):
    size = super().sizeHint(option, index)
    size.setHeight(28)            # 让这行的高度至少 28px，给进度条留空间
    return size
```

**不重写的话 view 按默认行高布局，你的进度条可能被挤扁。**

## 小结

- delegate 管单个单元格的绘制和编辑，是 Model/View 的第三块拼图
- 默认是 QStyledItemDelegate，只画文字和弹输入框
- 装 delegate：setItemDelegate / setItemDelegateForColumn / ForRow
- 四个核心方法：paint、createEditor、setEditorData、setModelData
- paint 先 super().paint() 保选中态，再用 save/restore 包裹自定义绘制
- sizeHint 决定单元格需要多少空间
