# QPainter 入门

> 想在窗口上画一条线、一个圆、一段文字？PySide6 里所有自定义绘制都绕不开 QPainter，而它只有一个正确的出场位置——paintEvent。

## 为什么绘制必须写在 paintEvent 里

Qt 的绘制模型有一条硬规则：**只有 paintEvent 里创建的 QPainter 才是"激活"的**。窗口需要显示、被遮挡后重现、调用 update() 重绘，Qt 都会派发一个绘图事件，你在事件里拿到画布，画完就走。出这个作用域再用 QPainter，就是违规操作。

```
import sys
from PySide6.QtWidgets import QApplication, QWidget
from PySide6.QtCore import Qt
from PySide6.QtGui import QPainter, QPen

class Canvas(QWidget):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("第一笔绘制")
        self.resize(300, 200)

    def paintEvent(self, event):
        painter = QPainter(self)              # ① 画布 = 当前窗口
        painter.setRenderHint(QPainter.RenderHint.Antialiasing)
        pen = QPen(Qt.GlobalColor.blue)       # ② 笔：颜色、粗细、线型
        pen.setWidth(3)
        painter.setPen(pen)
        painter.drawLine(20, 30, 280, 170)    # ③ 画一条线
        painter.end()                         # ④ 显式结束（离开作用域也会自动结束）

if __name__ == "__main__":
    app = QApplication(sys.argv)
    w = Canvas()
    w.show()
    app.exec()
```

三个对象分工明确：

| 对象 | 作用 | 常见设置 |
|---|---|---|
| QPainter | 画笔工具箱，真正下笔的东西 | setPen / setBrush / drawXxx |
| QPen | 描边（边框、线条） | 颜色、宽度、线型（实线/虚线）、端点样式 |
| QBrush | 填充（闭合图形内部） | 纯色、纹理、渐变 |

## 什么时候会触发重绘

不需要你自己"刷新"，Qt 会自动派发 paintEvent：

1. 窗口第一次显示
2. 窗口被别的窗口遮挡后重新露出来
3. 窗口被放大、缩小、拖到另一个屏幕
4. 你主动调用 `self.update()`（推荐，合并多次为一次重绘）
5. 你主动调用 `self.repaint()`（立即、同步重绘，会卡界面，少用）

**不要在 paintEvent 里调用 update() 或 repaint()**，那会形成无限递归的绘图事件循环。

## 用成员变量记住"想画什么"

paintEvent 是被动触发的，它的参数 `event` 只是告诉你"该画了"，不携带你想画的内容。所以要画的东西得存成成员变量，paintEvent 读取它，想改图就改数据再 `update()`：

```
class Canvas(QWidget):
    def __init__(self):
        super().__init__()
        self._points = []          # 存点
        self._color = Qt.GlobalColor.red

    def mousePressEvent(self, event):
        self._points.append(event.position().toPoint())
        self.update()              # 数据变了，请求重绘

    def paintEvent(self, event):
        painter = QPainter(self)
        painter.setPen(QPen(self._color, 6))
        for p in self._points:
            painter.drawPoint(p)
```

## 翻车现场一：在 paintEvent 外面用 QPainter 直接画

**症状：程序一运行就崩溃，控制台抛出：**

```
QPainter::begin: Painter already active
QPainter::setPen: Painter not active
```

**错误写法：**

```
class Canvas(QWidget):
    def __init__(self):
        super().__init__()
        painter = QPainter(self)          # ← 构造时窗口还没显示，画布不可用
        painter.drawLine(0, 0, 100, 100) # 这行会报 "Painter not active"
```

**原因**：QPainter 的构造函数需要一个"已经准备好被绘制"的 paint device。窗口第一次显示之前、paintEvent 之外，这个前提不成立。而且 paintEvent 随时会被 Qt 再次调用，你在 `__init__` 里画的东西下一秒就被清掉了。

**正确做法**：所有绘制代码只在 paintEvent 里出现，其他函数只改数据 + 调 update()。

```
def mousePressEvent(self, event):
    self._points.append(event.position().toPoint())
    self.update()          # 让 Qt 在合适的时机调用 paintEvent

def paintEvent(self, event):
    painter = QPainter(self)
    ...
```

## 翻车现场二：忘记调用 update()，点了没反应

**症状：鼠标点了十下，窗口一片空白，控制台没有任何报错。**

**错误写法：**

```
def mousePressEvent(self, event):
    self._points.append(event.position().toPoint())
    # 忘记 self.update()，paintEvent 永远不被调用
```

**原因**：Qt 不知道你的数据变了。paintEvent 只在 Qt 认为"需要重绘"时触发，往列表里塞数据不会自动触发它。

**正确做法**：改完数据立刻 `self.update()`。注意 update() 是异步合并的——一毫秒内连调 100 次 update()，Qt 只会派发一次 paintEvent，所以放心大胆地调。

## 小结

- 所有绘制代码只能在 `paintEvent(self, event)` 里写
- QPainter 管"怎么画"，QPen 管线条样式，QBrush 管填充
- 要画的内容存成成员变量，paintEvent 读取它
- 改数据后调 `self.update()` 触发重绘
- 禁止在 paintEvent 里再调 update() / repaint()
- repaint() 会同步卡界面，日常用 update() 就够了

```quiz
type: local
exam: true
q: 把上一节的"呼吸圆"升级成双色：让圆的半径继续变化，但颜色在蓝色和橙色之间随半径交替——半径小于 80 时画蓝色，大于等于 80 时画橙色。要求：只改 paintEvent 里的画笔/画刷设置，不改 _tick 逻辑。注意：这是窗口程序，网页里跑不了，请点"在 VS Code 里打开"运行。
starter: |
  import sys
  from PySide6.QtWidgets import QApplication, QWidget
  from PySide6.QtCore import Qt, QTimer
  from PySide6.QtGui import QPainter, QPen, QBrush

  class ColorCircle(QWidget):
      def __init__(self):
          super().__init__()
          self.setWindowTitle("双色呼吸圆")
          self.resize(300, 300)
          self._radius = 10
          timer = QTimer(self)
          timer.timeout.connect(self._tick)
          timer.start(50)

      def _tick(self):
          self._radius += 2
          if self._radius > 150:
              self._radius = 10
          self.update()

      def paintEvent(self, event):
          painter = QPainter(self)
          painter.setRenderHint(QPainter.RenderHint.Antialiasing)
          # 在这里根据 self._radius 选择蓝色或橙色
          painter.setPen(QPen(Qt.GlobalColor.blue, 2))
          painter.setBrush(QBrush(Qt.GlobalColor.blue))
          cx, cy = self.width() // 2, self.height() // 2
          painter.drawEllipse(cx - self._radius, cy - self._radius,
                              self._radius * 2, self._radius * 2)

  if __name__ == "__main__":
      app = QApplication(sys.argv)
      w = ColorCircle()
      w.show()
      app.exec()
checklist:
- 在 paintEvent 中根据 self._radius 判断颜色
- 半径 < 80 时使用蓝色（Qt.GlobalColor.blue）
- 半径 >= 80 时使用橙色（Qt.GlobalColor.darkOrange 或 QColor(255,140,0)）
- 同时设置 pen 和 brush 为同一颜色
- 圆能正常随半径变化显示
- 颜色随半径切换明显可见
- 程序正常显示并持续动画
```
