# 自定义 Delegate：paint 与 createEditor，以及 setEditorData/setModelData

> 上一课讲了 paint，单元格能"看起来"不一样了。这一课让它能"改"：双击弹出日历、下拉框、星级选择器。关键是四个方法的配合——漏一个，编辑就白搭。

## 编辑流程的四步

**一个单元格被双击编辑，到最终值写回 model，完整流程是：**

```
① 用户双击单元格
        ↓
② createEditor(parent, option, index)  ← 你返回一个编辑器 widget
        ↓
③ setEditorData(editor, index)         ← 你把 model 当前值灌进编辑器
        ↓
④ 用户在编辑器里操作（选日期、点星级...）
        ↓
⑤ setModelData(editor, model, index)   ← 你把编辑器的值写回 model
        ↓
⑥ 编辑器关闭，view 用新值重画
```

**四个方法各管一步。最常见的 bug 就是只写了 createEditor，没写 setModelData，结果"编辑完一按回车，值又变回去了"。**

## createEditor：返回一个编辑器

**你在里面 new 一个 widget（QSpinBox、QComboBox、QDateEdit 等），配好它的属性，返回它。**

```
from PySide6.QtWidgets import QSpinBox, QStyledItemDelegate, QComboBox

class SpinDelegate(QStyledItemDelegate):
    def createEditor(self, parent, option, index):
        editor = QSpinBox(parent)
        editor.setRange(0, 100)
        editor.setSuffix("%")
        return editor
```

**parent 必须传。** 这是 Qt 的内存管理要求：编辑器作为 child 挂在 view 的 viewport 上，关闭时自动销毁。

**createEditor 只负责"造"，不负责"填值"。** 填值在 setEditorData。

## setEditorData：把 model 的值灌进编辑器

```
def setEditorData(self, editor, index):
    value = index.data(Qt.EditRole)       # 从 model 拿当前值
    if value is None:
        value = 0
    editor.setValue(int(value))           # 灌进 spinbox
```

**这里拿的是 EditRole。** 因为 model 的 data() 里，DisplayRole 可能返回格式化字符串（如 "92%"），而 EditRole 返回原始 int。用 DisplayRole 灌值会导致转换错误。

## setModelData：把编辑器的值写回 model

**这是最常被漏掉的一步。**

```
def setModelData(self, editor, model, index):
    value = editor.value()                # 从编辑器拿当前值
    model.setData(index, value, Qt.EditRole)   # 写回 model
```

**注意是 `model.setData`，不是直接改 model 的内部列表。** 走 model 的接口，才能触发 dataChanged 信号、才能经过 model 的校验逻辑。

## 翻车现场一：只写 createEditor 没写 setModelData，编辑不生效

**症状：双击单元格，spinbox 弹出来了，能改数字，一按回车 spinbox 消失，单元格显示的还是旧值。

```
class BadDelegate(QStyledItemDelegate):
    def createEditor(self, parent, option, index):
        editor = QSpinBox(parent)
        editor.setRange(0, 100)
        return editor

    def setEditorData(self, editor, index):
        editor.setValue(int(index.data(Qt.EditRole)))

    # ❌ 没写 setModelData
```

**原因：Qt 的编辑流程是——打开编辑器、提交时调 setModelData、关闭编辑器。你没有 setModelData，model 的数据就没被更新，view 重画时还是旧值。**

**✅ 正确做法：补上 setModelData。**

```
def setModelData(self, editor, model, index):
    model.setData(index, editor.value(), Qt.EditRole)
```

**这是 delegate 编辑的"头号坑"，和 model 漏发 dataChanged 是同一个病根：数据改了但没走正确通道，界面就不知道。**

## 翻车现场二：setEditorData 用了 DisplayRole，灌进 spinbox 报错

**症状：双击编辑时报 `ValueError: invalid literal for int() with base 10: '92%'`。

```
def setEditorData(self, editor, index):
    value = index.data(Qt.DisplayRole)   # ❌ 拿到 "92%"
    editor.setValue(int(value))           # 转换失败
```

**原因：DisplayRole 是格式化后的显示文本，带单位、带千分位。**

**✅ 正确做法：用 EditRole 拿原始值。**

```
def setEditorData(self, editor, index):
    value = index.data(Qt.EditRole)      # ✅ 原始 int：92
    if value is None:
        value = 0
    editor.setValue(int(value))
```

**前提是 model 的 data() 要正确实现 EditRole。两者要配套，缺一编辑就坏。**

## 翻车现场三：编辑器没设 parent，内存泄漏或闪退

**症状：编辑器打开后界面卡死，或者 Python 报错 `RuntimeError: wrapped C/C++ object has been deleted`。

```
def createEditor(self, parent, option, index):
    editor = QSpinBox()                  # ❌ 没传 parent
    return editor
```

**原因：Qt 的父子所有权机制依赖 parent。没 parent 的 widget 生命周期无人管理，可能被提前销毁。**

**✅ 正确做法：永远传 parent。**

```
def createEditor(self, parent, option, index):
    editor = QSpinBox(parent)            # ✅
    return editor
```

## 下拉框委托实战

**状态列想用下拉框选"待办/进行中/完成"：**

```
class StatusDelegate(QStyledItemDelegate):
    _OPTIONS = ["待办", "进行中", "完成"]

    def createEditor(self, parent, option, index):
        editor = QComboBox(parent)
        editor.addItems(self._OPTIONS)
        return editor

    def setEditorData(self, editor, index):
        current = index.data(Qt.EditRole) or index.data(Qt.DisplayRole)
        if current in self._OPTIONS:
            editor.setCurrentText(current)

    def setModelData(self, editor, model, index):
        model.setData(index, editor.currentText(), Qt.EditRole)

    def paint(self, painter, option, index):
        # 可选：非编辑状态下也画成带颜色的标签
        super().paint(painter, option, index)
```

**这里 createEditor 和 paint 可以分开做。** 平时显示文字，双击才弹下拉框。如果你想平时就显示成彩色标签，就在 paint 里自己画。

## 日期委托：弹日历

**日期列用 QDateEdit 弹日历选择器：**

```
from PySide6.QtWidgets import QDateEdit
from PySide6.QtCore import QDate

class DateDelegate(QStyledItemDelegate):
    def createEditor(self, parent, option, index):
        editor = QDateEdit(parent)
        editor.setCalendarPopup(True)           # 弹出日历
        editor.setDisplayFormat("yyyy-MM-dd")
        return editor

    def setEditorData(self, editor, index):
        value = index.data(Qt.EditRole)        # 期望是 QDate 或 date
        if isinstance(value, QDate):
            editor.setDate(value)
        else:
            editor.setDate(QDate.currentDate())

    def setModelData(self, editor, model, index):
        model.setData(index, editor.date(), Qt.EditRole)
```

**注意 model 里存 QDate 还是 datetime.date 要统一。** 混用会导致 setEditorData 里类型判断复杂。建议 model 统一存 QDate，或者转换。

## updateEditorGeometry：编辑器位置对不上

**默认实现会用 option.rect 定位编辑器。如果你自定义的编辑器有特殊尺寸，可以重写：**

```
def updateEditorGeometry(self, editor, option, index):
    editor.setGeometry(option.rect)
```

**这个方法的默认实现通常够用，但如果你遇到"编辑器只显示一半、被单元格裁掉"，就需要在这里调整矩形。**

## 小结

- 编辑流程四步：createEditor 造 → setEditorData 灌 → 用户改 → setModelData 写回
- 漏写 setModelData 是最常见 bug，表现为"编辑完值又变回去"
- setEditorData 用 EditRole 拿原始值，避免格式化字符串转换失败
- createEditor 必须传 parent，否则生命周期失控
- 下拉框委托用 QComboBox，日期用 QDateEdit(setCalendarPopup)
- 类型统一很重要：model 存什么类型，delegate 就按什么类型读
