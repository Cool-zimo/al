# 实战：一个自定义仪表盘控件

> 把前面四节全部串起来——paintEvent、图元、坐标变换、渐变、路径。这一节做一个可复用的圆形仪表盘：刻度、刻度数字、彩色弧、指针、数值显示，全部在一个 QWidget 里画出来。

## 功能规划

我们要做一个这样的控件：

```
           270°（起点）
         ╭─────────╮
        ╱           ╲
       ╱    0   240   ╲
      │       °C       │
       ╲             ╱
        ╲___________╱
     左下角        右下角
     210°         330°
```

| 部件 | 技术 |
|---|---|
| 外圈彩色弧 | drawArc + QPen 渐变/多段 |
| 刻度线 | rotate 循环画短线 |
| 刻度数字 | rotate 后在固定位置 drawText |
| 指针 | translate 到中心 + rotate + drawPolygon |
| 中心圆 | drawEllipse 径向渐变 |
| 数值文字 | drawText 居中 |

## 完整代码

```
import sys
from PySide6.QtWidgets import QApplication, QWidget, QVBoxLayout, QSlider
from PySide6.QtCore import Qt, QRect, QPointF
from PySide6.QtGui import (QPainter, QPen, QBrush, QColor, QFont,
                          QRadialGradient, QConicalGradient, QPainterPath)

class Gauge(QWidget):
    def __init__(self, parent=None):
        super().__init__(parent)
        self.setMinimumSize(240, 240)
        self._value = 0          # 当前值 0~100
        self._min = 0
        self._max = 100

    def set_value(self, v):
        self._value = max(self._min, min(self._max, v))
        self.update()

    def paintEvent(self, event):
        p = QPainter(self)
        p.setRenderHint(QPainter.RenderHint.Antialiasing)

        side = min(self.width(), self.height())
        rect = QRect(0, 0, side, side)
        rect.adjust(20, 20, -20, -20)        # 留边距
        cx, cy = rect.center().x(), rect.center().y()
        r = rect.width() // 2

        # 1. 底部灰底弧（整个量程范围）
        p.setPen(QPen(QColor(230, 230, 230), 16,
                      Qt.PenStyle.SolidLine, Qt.PenCapStyle.RoundCap))
        p.drawArc(rect.adjusted(8, 8, -8, -8),
                  225 * 16, -270 * 16)       # 角度单位是 1/16 度

        # 2. 彩色进度弧（按当前值比例）
        ratio = (self._value - self._min) / (self._max - self._min)
        span = int(270 * ratio)
        grad = QConicalGradient(cx, cy, 225 - 0)   # 起点在右侧
        grad.setColorAt(0.0, QColor(0, 200, 100))
        grad.setColorAt(0.5, QColor(255, 200, 0))
        grad.setColorAt(1.0, QColor(255, 60, 60))
        p.setPen(QPen(QBrush(grad), 16,
                      Qt.PenStyle.SolidLine, Qt.PenCapStyle.RoundCap))
        p.drawArc(rect.adjusted(8, 8, -8, -8),
                  225 * 16, -span * 16)

        # 3. 刻度线（rotate 循环）
        p.save()
        p.translate(cx, cy)
        p.rotate(225)                          # 起点角度
        ticks = 11
        for i in range(ticks):
            angle = i * (270 / (ticks - 1))
            p.save()
            p.rotate(angle)
            p.setPen(QPen(QColor(120, 120, 120), 2))
            p.drawLine(r - 6, 0, r + 8, 0)
            p.restore()
        p.restore()

        # 4. 指针
        p.save()
        p.translate(cx, cy)
        p.rotate(225 + 270 * ratio)
        p.setBrush(QBrush(QColor(60, 60, 60)))
        p.setPen(Qt.PenStyle.NoPen)
        p.drawPolygon([QPointF(-6, 0), QPointF(0, -(r - 22)),
                       QPointF(6, 0), QPointF(0, 14)])
        p.restore()

        # 5. 中心圆（径向渐变）
        rad = QRadialGradient(cx, cy, 22, cx - 6, cy - 6)
        rad.setColorAt(0.0, QColor(255, 255, 255))
        rad.setColorAt(1.0, QColor(200, 200, 200))
        p.setBrush(QBrush(rad))
        p.setPen(QPen(QColor(160, 160, 160), 1))
        p.drawEllipse(QRect(cx - 12, cy - 12, 24, 24))

        # 6. 数值文字
        p.setPen(QPen(QColor(40, 40, 40)))
        f = QFont("Sans", 26, QFont.Weight.Bold)
        p.setFont(f)
        p.drawText(rect.adjusted(0, r // 2, 0, 0),
                   Qt.AlignmentFlag.AlignCenter, str(self._value))


class Demo(QWidget):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("仪表盘")
        self.resize(320, 400)

        self.gauge = Gauge()
        slider = QSlider(Qt.Orientation.Horizontal)
        slider.setRange(0, 100)
        slider.setValue(68)
        slider.valueChanged.connect(self.gauge.set_value)
        self.gauge.set_value(68)

        layout = QVBoxLayout(self)
        layout.addWidget(self.gauge)
        layout.addWidget(slider)


if __name__ == "__main__":
    app = QApplication(sys.argv)
    w = Demo()
    w.show()
    app.exec()
```

## 关键设计决策

**1. 为什么角度要乘 16？**

Qt 的 `drawArc` / `drawPie` 角度单位是**十六分之一度**（历史遗留），所以 270° 要写成 `270 * 16`。这是新手最常踩的坑。

**2. 为什么进度弧和刻度线都用 rotate？**

指针要绕中心旋转，刻度要均匀分布——这两类需求的坐标系"本来就该是极坐标系"。把原点 translate 到中心再 rotate，代码比算三角坐标简洁得多，而且 save/restore 天然隔离。

**3. 为什么刻度线要在 rotate 里面再 save/restore？**

因为每次 `p.rotate(angle)` 是**累加**的。如果你不恢复，下一轮旋转会叠在上一轮之上，刻度全歪。

## 翻车现场一：drawArc 的角度写成 270 而不是 270*16

**症状：弧几乎看不见，只画了一小段。**

**错误写法：**

```
p.drawArc(rect, 225, 270)        # 单位是 1/16 度，270 只等于 16.875°
```

**正确写法：**

```
p.drawArc(rect, 225 * 16, 270 * 16)
```

## 翻车现场二：刻度线的旋转叠加，刻度歪成一团

**症状：11 根刻度线挤在一小撮角度里，越往后越密。**

**错误写法：**

```
p.save()
p.translate(cx, cy)
p.rotate(225)
for i in range(11):
    angle = i * 27
    p.rotate(angle)              # ← 每次都累加：0, 27, 54... 是相对上一根的
    p.drawLine(...)
p.restore()
```

**正确写法：要么每次从 225 基准重算，要么每轮 restore 回去：**

```
p.save()
p.translate(cx, cy)
for i in range(11):
    p.save()
    p.rotate(225 + i * 27)
    p.drawLine(...)
    p.restore()                 # 回到未旋转状态再下一轮
p.restore()
```

## 翻车现场三：指针旋转时图形飞出画面

**症状：指针越转越远，最后跑出窗口。**

**错误写法：**

```
p.translate(cx, cy)
p.rotate(self._angle)
p.drawPolygon([QPointF(0, 0), QPointF(0, -80), QPointF(6, 0), QPointF(0, 10)])
# 忘了 p.restore()
```

**原因**：translate/rotate 没恢复，下一帧 paintEvent 继续叠加，指针以指数级漂移。

**正确写法：用 try/finally 保证 restore。**

## 翻车现场四：QConicalGradient 方向看起来反了

**症状：想让渐变从绿到红，实际是从红到绿。**

**原因**：QConicalGradient 的角度参数和 Qt 顺时针为正的方向决定了颜色排布。需要按实际效果调整 setColorAt 的顺序或角度起点。

**正确做法**：先画出来看一眼，如果反了就把起点角度加减 360° 或交换 colorAt 顺序。

## 小结

- 仪表盘 = 弧 + 刻度 + 指针 + 中心圆 + 数值
- drawArc 角度单位是 1/16 度，务必 `* 16`
- translate 到中心 + rotate 是指针/刻度的标准套路
- 循环中 rotate 后必须 restore，否则角度累加
- save/restore 成对，try/finally 保证恢复
- 进度弧用 QConicalGradient 做多色过渡
- 中心用 QRadialGradient 制造立体感
