# 从 QWidget 完全自绘：paintEvent、QPainter，必须在 paintEvent 里画，不能在别处画

> 继承现有控件只能改已有部件的样子。要画一个环形进度条、仪表盘、星星评分，你得从 QWidget 开始自己画。这一课把"自绘"这条线彻底讲透。

## 自绘的基本骨架

**继承 QWidget，重写 paintEvent。paintEvent 接收一个 QPaintEvent，你创建一个 QPainter，画，然后结束。**

```
from PySide6.QtWidgets import QWidget, QApplication
from PySide6.QtGui import QPainter, QColor
from PySide6.QtCore import Qt

class CircleWidget(QWidget):
    def __init__(self, parent=None):
        super().__init__(parent)
        self.setMinimumSize(200, 200)      # 给个最小尺寸，否则可能画不出来

    def paintEvent(self, event):
        painter = QPainter(self)
        painter.setRenderHint(QPainter.Antialiasing)   # 抗锯齿，让圆变圆滑
        painter.setBrush(QColor("#4caf50"))
        painter.setPen(Qt.NoPen)
        rect = self.rect().adjusted(10, 10, -10, -10)
        painter.drawEllipse(rect)
        painter.end()
```

**三个关键点：`QPainter(self)` 以当前 widget 为绘制设备；`setRenderHint(Antialiasing)` 让边缘平滑；画完 `painter.end()`。**

## QPainter 常用 API

| 方法 | 用途 |
|---|---|
| `drawLine(x1, y1, x2, y2)` | 画线 |
| `drawRect(x, y, w, h)` / `drawRect(QRect)` | 画矩形 |
| `drawEllipse(rect)` | 画椭圆/圆 |
| `drawText(rect, flags, text)` | 绘制文本 |
| `drawArc(rect, startAngle, spanAngle)` | 画弧（角度用 1/16 度） |
| `drawPie(rect, startAngle, spanAngle)` | 画扇形 |
| `drawPolygon(points)` | 画多边形 |
| `fillRect(rect, color)` | 填充矩形 |
| `setPen(color/width)` | 设置画笔（边框） |
| `setBrush(color)` | 设置画刷（填充） |

**坐标以 widget 左上角为原点，x 向右，y 向下。**

## 翻车现场一：在 paintEvent 之外创建 QPainter，报错

**症状：运行时报 `QPainter::begin: Paint device returned engine == 0` 或 `QPainter::setPen: Painter not active`。**

```
class BadWidget(QWidget):
    def __init__(self, parent=None):
        super().__init__(parent)
        self._painter = QPainter(self)      # ❌ 在构造时创建

    def mousePressEvent(self, event):
        self._painter.setPen(Qt.red)        # ❌ 在非 paintEvent 上下文用
        self._painter.drawPoint(...)
```

**原因：QPainter 只能在 paintEvent 期间活跃。它的 begin/end 和 widget 的绘制周期绑定，构造时创建、事件里用都是非法的。**

**✅ 正确做法：每次 paintEvent 里 new 一个，画完 end。**

```
def paintEvent(self, event):
    painter = QPainter(self)               # ✅ 在 paintEvent 里创建
    painter.setPen(Qt.red)
    # ... 绘制
    painter.end()
```

**QPainter 是"一次性"的，不要当成员变量长期持有。**

## 翻车现场二：角度单位用错了，圆弧画成一条线

**症状：想画一个 90° 的弧，结果画出来是一条几乎看不见的线。**

```
painter.drawArc(rect, 0, 90)      # ❌ 90 是 1/16 度单位，实际只有 5.6°
```

**原因：drawArc / drawPie 的角度参数是"十六分之一度"。90 表示 90/16 = 5.625 度。**

**✅ 正确做法：乘以 16。**

```
painter.drawArc(rect, 0, 90 * 16)         # ✅ 90 度
painter.drawPie(rect, 0, 270 * 16)        # 270 度扇形
```

**或者写个辅助常量：**

```
from PySide6.QtCore import Qt as QtCore_const
# 用一个变量记一下：1 度 = 16 个单位
DEG = 16
painter.drawArc(rect, 0, 90 * DEG)
```

**这是 Qt 自绘第二个高频坑（第一个是 QTimer 的毫秒）。**

## 环形进度条实战

**一个经典的自绘控件：外环灰色底、内环彩色进度、中间显示百分比。**

```
from PySide6.QtCore import Qt, QRect

class RingProgress(QWidget):
    def __init__(self, parent=None):
        super().__init__(parent)
        self._value = 0                    # 0 ~ 100
        self.setMinimumSize(120, 120)

    def set_value(self, value):
        self._value = max(0, min(100, value))
        self.update()                      # 触发重绘

    def paintEvent(self, event):
        painter = QPainter(self)
        painter.setRenderHint(QPainter.Antialiasing)

        rect = self.rect().adjusted(8, 8, -8, -8)
        pen_width = 12

        # 底环
        painter.setPen(Qt.NoPen)
        # 用画刷画底
        # 实际画环要用 QPen 的宽度
        pen = painter.pen()
        pen.setWidth(pen_width)
        pen.setColor(QColor("#e0e0e0"))
        painter.setPen(pen)
        painter.setBrush(Qt.NoBrush)
        painter.drawEllipse(rect.adjusted(pen_width//2, pen_width//2,
                                         -pen_width//2, -pen_width//2))

        # 进度环（用 drawArc，起点 90° 顺时针）
        pen.setColor(QColor("#4caf50"))
        painter.setPen(pen)
        # drawArc 起点是 3 点钟方向，角度顺时针
        # 要让它从 12 点方向开始：起点 = 90° * 16，span = -value * 3.6 * 16
        span = int(-self._value * 3.6 * 16)
        painter.drawArc(rect.adjusted(pen_width//2, pen_width//2,
                                     -pen_width//2, -pen_width//2),
                       90 * 16, span)

        # 中间文字
        painter.setPen(QColor("#333333"))
        font = painter.font()
        font.setPointSize(16)
        font.setBold(True)
        painter.setFont(font)
        painter.drawText(self.rect(), Qt.AlignCenter, f"{self._value}%")

        painter.end()
```

**要点：底环和进度环用同一个 QPen 宽度，只是换颜色；drawArc 画的是弧线，配合宽 pen 就成了"环"；中间文字用 drawText + AlignCenter。**

## 翻车现场三：没调 update()，改了数据界面不刷新

**症状：调用 `ring.set_value(50)`，界面没变化。print 确认 _value 确实变了。**

```
class RingProgress(QWidget):
    def set_value(self, value):
        self._value = value
        # ❌ 没调 update()，paintEvent 不会被调用
```

**原因：Qt 不会主动重绘 widget，你必须显式告诉它"这块区域脏了，需要重画"。**

**✅ 正确做法：改完数据调 update()。**

```
def set_value(self, value):
    self._value = max(0, min(100, value))
    self.update()                    # ✅ 标记整个 widget 需要重绘
```

**update() 是"异步"的——它只是标记脏区域，Qt 会在下一个绘制周期统一重画，可以多次调用合并成一次，性能友好。如果要立即强制重画，用 repaint()，但一般不用。**

## 翻车现场四：画的内容随窗口大小变化错位

**症状：窗口拉伸后，圆环不在正中间，或者文字跑偏了。

```
def paintEvent(self, event):
    painter = QPainter(self)
    painter.drawText(10, 20, "进度")   # ❌ 写死坐标，拉伸就错位
```

**原因：写死的坐标不会随 widget 尺寸变化。**

**✅ 正确做法：用 `self.rect()` / `self.width()` / `self.height()` 动态计算。**

```
def paintEvent(self, event):
    painter = QPainter(self)
    rect = self.rect()
    cx, cy = rect.width() // 2, rect.height() // 2
    radius = min(cx, cy) - 10
    painter.drawEllipse(cx - radius, cy - radius, radius * 2, radius * 2)
    painter.drawText(rect, Qt.AlignCenter, "进度")
```

**所有坐标都从 `self.rect()` 推导，这样拉伸时自动重排（别忘了改完尺寸 Qt 会自动调 update）。**

## 小结

- 自绘：继承 QWidget，重写 paintEvent，创建 QPainter，画，end
- QPainter 只能在 paintEvent 期间活跃，不能当成员变量
- drawArc/drawPie 角度单位是 1/16 度，90° 要写 90 * 16
- 环形进度条 = 底环（灰）+ 进度弧（彩色）+ 居中文字
- 改数据后必须 update() 才会触发重绘
- 坐标用 self.rect() 动态算，避免拉伸错位
- setRenderHint(Antialiasing) 让边缘平滑
