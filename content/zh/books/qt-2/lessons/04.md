# 自定义 Model：继承 QAbstractTableModel，必须实现的三个方法

> QStandardItemModel 够用了，但你的数据可能在一个 CSV、一个数据库、一个网络接口里。这时候你得自己写 model：告诉 Qt 你有多少行、多少列、每个格子是什么。

## 自定义 model 的最小骨架

**继承 `QAbstractTableModel`（表格用这个，列表用 `QAbstractListModel`，树用 `QAbstractItemModel`）。表格 model 必须实现三个方法：`rowCount`、`columnCount`、`data`。再加一个 `headerData` 表头就完整了。**

```
from PySide6.QtCore import QAbstractTableModel, Qt

class ScoreModel(QAbstractTableModel):
    def __init__(self, rows=None):
        super().__init__()
        self._rows = rows or []

    def rowCount(self, parent=Qt.QModelIndex()):
        return len(self._rows)

    def columnCount(self, parent=Qt.QModelIndex()):
        return 3

    def data(self, index, role=Qt.DisplayRole):
        if not index.isValid():
            return None
        if role == Qt.DisplayRole:
            return str(self._rows[index.row()][index.column()])
        return None

    def headerData(self, section, orientation, role=Qt.DisplayRole):
        if role == Qt.DisplayRole:
            if orientation == Qt.Horizontal:
                return ["姓名", "科目", "成绩"][section]
            return f"第 {section + 1} 行"
        return None
```

**四个方法，每行代码都在回答一个具体问题。** rowCount 答"几行"，columnCount 答"几列"，data 答"这个格子显示什么"，headerData 答"表头写什么"。view 就是通过这四个问题把整个表格画出来的。

## 翻车现场一：data() 忘了处理 DisplayRole，什么都不显示

**症状：model 接上了，表格画出来了，但每个格子都是空的。没有报错，界面就是白的。**

```
def data(self, index, role=Qt.DisplayRole):
    value = self._rows[index.row()][index.column()]
    if role == Qt.EditRole:        # ❌ 只处理了 EditRole
        return value
    return None                    # DisplayRole 落到这里，返回 None
```

**原因：QTableView 默认用 DisplayRole 取显示内容。** 你只实现了 EditRole，那是在双击编辑时才用的。平时显示，view 问的是 DisplayRole，你返回了 None，所以什么都不画。

**✅ 正确做法：至少处理 DisplayRole。**

```
def data(self, index, role=Qt.DisplayRole):
    value = self._rows[index.row()][index.column()]
    if role == Qt.DisplayRole:
        return str(value)          # ✅ 显示用
    if role == Qt.EditRole:
        return value               # ✅ 编辑用
    return None
```

**DisplayRole 必须返回字符串（或可转字符串的类型）。** 返回 None 表示"我没有这个值要显示"，格子就空着。

## 翻车现场二：index 没校验 isValid()，越界崩溃

**症状：程序偶尔崩，报 `IndexError: list index out of range`。**

```
def data(self, index, role=Qt.DisplayRole):
    r, c = index.row(), index.column()
    return str(self._rows[r][c])      # ❌ 没校验，index 可能无效
```

**原因：view 在布局、拖拽、编辑等过程中，可能问到一个无效的 index（比如 parent 无效、或者行数刚好变化）。** 这时候 `index.isValid()` 是 False，`row()` 返回 -1，直接当下标就炸。

**✅ 正确做法：第一行永远是 isValid 校验。**

```
def data(self, index, role=Qt.DisplayRole):
    if not index.isValid():              # ✅ 永远先校验
        return None
    if index.row() >= len(self._rows):
        return None
    if index.column() >= len(self._rows[0]):
        return None
    # 下面才是业务逻辑
```

**这个 isValid 检查不是防御性编程的洁癖，是 Qt 协议的一部分。** 不写的话，你的 model 在动态增删数据时极易崩。

## 翻车现场三：忘了实现 headerData，表头全是 1、2、3

**症状：数据显示正常，但表头是数字 1、2、3，不是你想要的"姓名""科目""成绩"。**

```
class ScoreModel(QAbstractTableModel):
    # ❌ 没写 headerData
    def rowCount(self, parent=Qt.QModelIndex()):
        return len(self._rows)
    def columnCount(self, parent=Qt.QModelIndex()):
        return 3
    def data(self, index, role=Qt.DisplayRole):
        return str(self._rows[index.row()][index.column()])

# view 显示表头为 1, 2, 3
```

**原因：没重写 headerData，基类默认实现返回 section + 1（即 1、2、3）。**

**✅ 正确做法：实现 headerData，按 orientation 区分行列表头。**

```
def headerData(self, section, orientation, role=Qt.DisplayRole):
    if role != Qt.DisplayRole:
        return None
    if orientation == Qt.Horizontal:
        headers = ["姓名", "科目", "成绩"]
        return headers[section] if section < len(headers) else None
    return f"第 {section + 1} 行"     # 竖列表头（行号）
```

**表头是用户理解表格的第一入口。** 不写表头，你的 model 能用，但很"丑"——就像写了个函数不给文档字符串。

## 翻车现场四：忘了实现 index()，以为基类有默认实现

**症状：有人写自定义 model 时，`index()` 没写，运行报错 `NotImplementedError` 或 `index()` 返回的全是无效 index。**

```
class MyModel(QAbstractTableModel):
    # ❌ 忘记实现 index()，基类的 index() 返回无效 index
    def rowCount(self, parent=Qt.QModelIndex()):
        return len(self._rows)
    # ... 其他都写了
```

**原因：`QAbstractTableModel` 其实有一个默认 index 实现（返回 createIndex(row,col)），但很多人以为要自己写，结果写出错的版本；反过来，如果继承的是最底层的 `QAbstractItemModel`，index 是纯虚的必须实现。**

**✅ 正确做法：继承 `QAbstractTableModel` 时可以直接用默认的 index；要自定义就在 data 里挂指针。**

```
# QAbstractTableModel 已经提供了 index() 的默认实现
# 它等价于：
def index(self, row, column, parent=Qt.QModelIndex()):
    if not self.hasIndex(row, column, parent):
        return Qt.QModelIndex()
    return self.createIndex(row, column, None)

# 对表格来说这就够了，不需要重写
```

**`hasIndex(row, column, parent)` 是 Qt 提供的便利方法，等价于判断 row/column 是否在合法范围内。** 表格 model 直接用基类的 index 即可，不用手写。

## setData 与 flags：让 model 可编辑

**光显示还不够，你要让单元格可编辑。两个必备：`flags()` 返回 `ItemIsEditable`，`setData()` 处理 EditRole。**

```
def flags(self, index):
    f = super().flags(index)
    return f | Qt.ItemIsEditable         # 加上可编辑标志

def setData(self, index, value, role=Qt.EditRole):
    if not index.isValid() or role != Qt.EditRole:
        return False
    self._rows[index.row()][index.column()] = value
    self.dataChanged.emit(index, index, [role])   # ✅ 必须发信号
    return True
```

**`flags()` 决定一个单元格"能干什么"。** 常用标志：

| 标志 | 含义 |
|---|---|
| `Qt.ItemIsSelectable` | 可选中 |
| `Qt.ItemIsEditable` | 可双击编辑 |
| `Qt.ItemIsEnabled` | 可用（灰掉就是没它） |
| `Qt.ItemIsUserCheckable` | 可勾选（配合 CheckStateRole） |
| `Qt.ItemIsDragEnabled` / `ItemIsDropEnabled` | 可拖拽 |

**flags 是"位或"组合。** `super().flags(index)` 先拿到默认标志，再 `|` 上你要加的，不要直接 return 一个新值（会丢掉默认行为）。

## 翻车现场五：setData 没发 dataChanged 信号，界面不刷新

**症状：双击单元格编辑，输入新值回车，焦点一走，值又变回去了。**

```
def setData(self, index, value, role=Qt.EditRole):
    self._rows[index.row()][index.column()] = value
    # ❌ 没发 dataChanged 信号
    return True
```

**原因：内部数据确实改了，但 view 不知道。** view 只在收到 dataChanged 信号时才重画那个区域。没信号，显示就停在旧值上。

**✅ 正确做法：改完立刻 emit dataChanged，把"变了哪个范围"告诉 view。**

```
self.dataChanged.emit(index, index, [role])
#                    起点     终点    角色列表
```

**dataChanged 的两个 index 是"脏区域"的左上角和右下角。** 只改一个单元格，就传同一个 index 两次。批量改多行，传首行和末行。Qt 只重画这块区域，效率高。

## 小结

- 自定义表格 model 必须实现 rowCount / columnCount / data，建议加 headerData
- data() 至少处理 DisplayRole，否则界面一片空白且不报错
- 第一行永远是 index.isValid() 校验，这是 Qt 协议不是洁癖
- headerData 按 orientation 区分行/列表头，不写就显示 1、2、3
- QAbstractTableModel 的 index() 有默认实现，表格 model 不用手写
- 可编辑需要 flags 加 ItemIsEditable + setData 处理 EditRole
- setData 改完必须 emit dataChanged，否则显示不刷新

  from PySide6.QtCore import QAbstractTableModel, Qt
  from PySide6.QtWidgets import QApplication, QTableView

  class EmployeeModel(QAbstractTableModel):
      def __init__(self, rows=None):
          super().__init__()
          self._rows = rows or []

      def rowCount(self, parent=Qt.QModelIndex()):
          return len(self._rows)

      def columnCount(self, parent=Qt.QModelIndex()):

      def data(self, index, role=Qt.DisplayRole):

- 程序正常显示并运行
