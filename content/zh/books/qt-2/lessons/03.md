# QStandardItemModel 入门：最常用的现成 model，增删改查数据

> 不想写自定义 model，又想要 Model/View 的灵活性？QStandardItemModel 是 Qt 给你的"半糖"方案：自带数据容器，拿来就用，先把流程跑通再说。

## QStandardItemModel 是什么

**它是 Qt 预置的一个通用 model：内部用 QStandardItem 这棵树来存数据，开箱即用，不需要你继承。你可以把它理解为"把 QTableWidget 的数据和显示重新拆开"的那个版本。**

QTableWidget 是一手包办，QStandardItemModel 是把"数据容器"单独拿出来给你用，view 还是那个 view。你先建 model，往里塞 item，再 `setModel`。

```
from PySide6.QtWidgets import QApplication, QTableView
from PySide6.QtGui import QStandardItemModel, QStandardItem

app = QApplication([])

model = QStandardItemModel(3, 2)          # 3 行 2 列
model.setHorizontalHeaderLabels(["姓名", "成绩"])

model.setItem(0, 0, QStandardItem("张三"))
model.setItem(0, 1, QStandardItem("92"))
model.setItem(1, 0, QStandardItem("李四"))
model.setItem(1, 1, QStandardItem("85"))

view = QTableView()
view.setModel(model)
view.show()
app.exec()
```

**看到没？用法几乎和 QTableWidget 一样，只是 `table.setItem` 变成了 `model.setItem`。** 差别在于：现在是 model 在管数据，view 只是个画板。这个差别，从下一行代码开始就值钱了。

## 增：插入行与追加行

**QStandardItemModel 提供 `appendRow`、`insertRow`，以及给行里批量设 item 的方式。**

```
# 追加一行：直接传一组 item
model.appendRow([QStandardItem("王五"), QStandardItem("77")])

# 在指定位置插入一行
model.insertRow(1, [QStandardItem("赵六"), QStandardItem("88")])

# 先建空行，再逐个填
model.appendRow([])
model.setItem(model.rowCount() - 1, 0, QStandardItem("钱七"))
```

**这里有个微妙的点：appendRow 会发出 dataChanged / rowsInserted 信号，view 自动刷新。** 你不需要手动调 `view.update()`，这是 model 的"通知"机制在工作（第 05 课细讲）。

**QStandardItem 还自带一份"每单元格"的样式设置。** 这是它比纯数据 model 方便的地方。

```
item = QStandardItem("99")
item.setForeground(QColor("green"))       # 绿色字体
item.setBackground(QColor("yellow"))      # 黄色背景
item.setTextAlignment(Qt.AlignCenter)     # 居中
item.setEditable(False)                   # 不可编辑
item.setToolTip("满分")
model.setItem(0, 1, item)
```

## 查：三种取值方式

**拿到一个单元格的值，有几条路，按场景挑。**

```
# 方式一：直接 item()
item = model.item(0, 1)
if item is not None:
    value = item.text()

# 方式二：通过 index 拿 item（更"model 味"）
index = model.index(0, 1)
item = model.itemFromIndex(index)
text = item.text()

# 方式三：直接用 model.data() 问 DisplayRole
value = model.data(model.index(0, 1), Qt.DisplayRole)
```

**方式一最直观，方式三最"正统"。** 方式一给你 QStandardItem 对象本身，你可以改它的颜色、对齐；方式三只返回值，不参与 item 的属性。

## 翻车现场一：用错 role 取数字，比大小比错

**症状：存的是 "92"，拿到的也是字符串，排序出来 "9" > "100"。**

```
item = model.item(0, 1)
score = item.text()          # 这是个 str："92"
scores = [item.text() for item in model.findItems("", Qt.MatchContains)]

# ❌ 按字符串排序
scores.sort()                # ['100', '85', '9']
```

**原因：QStandardItem 默认把什么都当文本存，`text()` 永远返回字符串。**

**✅ 正确做法：用 `setData` 存一个数值角色，取值时指定 UserRole。**

```
item = QStandardItem()
item.setData(92, Qt.UserRole)         # 存 int
item.setText("92")                    # 显示还是文本

# 取值
val = item.data(Qt.UserRole)          # 92，int
```

**QStandardItem 的 `setData(value, role)` 可以挂任意角色。** 显示用 DisplayRole（文本），逻辑值用 UserRole（int）。这一课的关键技巧就是"两个角色各管一摊"。

## 改：改完要通知

**QStandardItemModel 改 item 的文本或数据，它会自动发 dataChanged 信号。** 这是它"聪明"的地方——因为 item 是它自己造的，它知道你在改。

```
item = model.item(0, 1)
item.setText("99")           # ✅ 自动通知 view 刷新

item.setData(99, Qt.UserRole) # ✅ 同样会通知
```

**这个自动通知是 QStandardItem 内部实现的，不是 model 的魔法。** 你用 `setItem` 换掉一整个 item、用 `setText` 改文本，都会触发。但如果你绕过 item 直接动它的内部数据（比如拿到一个自定义对象硬改属性），通知就发不出来。

## 删：removeRow 与 clear

```
model.removeRow(2)           # 删第 2 行
model.removeRows(1, 3)       # 从第 1 行起删 3 行
model.clear()                # 清空所有数据（保留列头！列头会被清掉）
```

**`clear()` 会把表头也一起清掉。** 这是一个常见踩坑点，下面翻车现场二会讲。

## 翻车现场二：clear() 之后表头没了，界面一片空白

**症状：点"重置"按钮调用 `model.clear()`，再重新塞数据，发现列名（姓名/成绩）不见了。**

```
model.clear()
# ❌ 此时 horizontalHeaderLabels 也没了
model.appendRow([QStandardItem("张三"), QStandardItem("92")])
# 表格能显示数据，但第一行没有"姓名""成绩"了
```

**原因：`clear()` 清空的是整个 model 的内容，包括表头。文档里写得很清楚，但没人会读文档。**

**✅ 正确做法：clear 之后重新设表头，或者只删数据行不碰表头。**

```
# 方法一：clear 后重设表头
model.clear()
model.setHorizontalHeaderLabels(["姓名", "成绩"])

# 方法二：只删数据行，保留表头
model.removeRows(0, model.rowCount())
```

**方法二更安全。** 你的表头定义只在一个地方写着，不要在代码里出现两次（清一次、设一次），那是重复维护，迟早不一致。

## 翻车现场三：findItems 只找 DisplayRole，找数字找不到

**症状：想查找成绩为 92 的行，`findItems` 返回空列表。**

```
item = QStandardItem()
item.setData(92, Qt.UserRole)      # 存的是数字角色
item.setText("92")

found = model.findItems("92")      # ✅ 能找到，因为 DisplayRole 是 "92"
found2 = model.findItems(92)       # ❌ 找不到，findItems 按 DisplayRole 匹配字符串
```

**原因：`findItems` 是按 DisplayRole 的文本匹配，传数字会被转成字符串比较，容易踩坑。**

**✅ 正确做法：要么确保 DisplayRole 就是你要查的字符串，要么自己遍历。**

```
# 自己遍历，用 UserRole 精确匹配
def find_by_score(model, score):
    for r in range(model.rowCount()):
        item = model.item(r, 1)
        if item.data(Qt.UserRole) == score:
            yield r

list(find_by_score(model, 92))     # [0]
```

## 小结

- QStandardItemModel 是开箱即用的通用 model，不需要继承
- 用法接近 QTableWidget，只是 `table.setItem` → `model.setItem`
- 增用 appendRow/insertRow，删用 removeRow，查用 item/data 两种思路
- QStandardItem 自带样式设置：颜色、对齐、可编辑、tooltip
- 数字要存 UserRole，否则 text() 返回字符串，比大小会出错
- `clear()` 会清空表头，只删数据请用 removeRows(0, rowCount())
- findItems 按 DisplayRole 文本匹配，数字查找要自己遍历
