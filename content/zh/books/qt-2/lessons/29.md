# 自绘图表：用 QPainter 画饼图和柱状图

> 第 4 章的绘图知识终于有了用武之地。这一课我们用 `QPainter` 自己画一个分类占比饼图和一个月度趋势柱状图，把"能画"升级成"画一个有意义的图"。

## 为什么这一课值得单独讲

第 4 章我们画过仪表盘——那是"练手"。记账本的图表是"产品功能"，区别在哪？练手只要画得好看，产品功能要**跟着数据变**。数据一换，图就得跟着换；窗口一缩放，图就得跟着缩放。这两个要求决定了整个结构。

先看一下成品长什么样：

```
┌─────────────────────────────────────────┐
│  分类占比                   月度趋势     │
│   ┌─────────┐                ████       │
│   │  饼图   │  餐饮 45%       ██████     │
│   │  (自绘) │  交通 10%      ████████   │
│   └─────────┘  居住 40%     ██████████  │
│   图例                       ████████████│
└─────────────────────────────────────────┘
```

## ChartView：一个能收数据的 QWidget

图表控件只要一件事：把数据接进来，把自己画出来。其余的一概不管。

```
from PySide6.QtWidgets import QWidget
from PySide6.QtCore import Qt
from PySide6.QtGui import QPainter, QColor, QFont, QPen, QBrush

class ChartView(QWidget):
    def __init__(self, parent=None):
        super().__init__(parent)
        self._by_category = {}          # {分类: 总额}
        self._by_month = {}             # {月份: 总额}
        self.setMinimumHeight(260)

    def set_data(self, by_category, by_month):
        self._by_category = by_category
        self._by_month = by_month
        self.update()                  # 触发一次 paintEvent
```

**`set_data` 之后必须 `update()`。** 这是最容易漏的一步——数据换了但没调 `update()`，界面还显示旧图，看着像 bug。`update()` 是 Qt 的"请在合适的时候重画我"，它会异步触发 `paintEvent`。

## paintEvent：整个绘图都在这里

```
def paintEvent(self, event):
    painter = QPainter(self)
    painter.setRenderHint(QPainter.RenderHint.Antialiasing)

    rect = self.rect()
    left = rect.width() // 2            # 左半画饼图，右半画柱状图
    self._draw_pie(painter, rect.adjusted(0, 0, -left, 0))
    self._draw_bars(painter, rect.adjusted(left, 0, 0, 0))
```

**每个 `QPainter` 只在一个 `paintEvent` 里活。** 用完不用手动关，出作用域就销毁。第 4 章强调的"别把 QPainter 存成成员变量"在这里尤其重要——`paintEvent` 随时可能被 Qt 调用，长期持有的 painter 会指向已失效的设备。

## 饼图：角度是怎么算的

饼图的关键是"数据值 → 角度跨度"。Qt 的角度单位是**十六分之一度**，`360° = 5760`，所以算好度数后要乘 16。

```
def _draw_pie(self, painter, rect):
    total = sum(self._by_category.values())
    if not self._by_category or total == 0:
        painter.drawText(rect, Qt.AlignmentFlag.AlignCenter, "暂无数据")
        return

    colors = [QColor(66,133,244), QColor(52,168,83), QColor(251,188,4),
              QColor(234,67,53), QColor(154,76,175), QColor(0,172,193)]

    cx = rect.center().x()
    cy = rect.center().y()
    radius = min(rect.width() - 120, rect.height()) // 2 - 10
    x = cx - radius
    y = cy - radius
    size = radius * 2
    box = (x, y, size, size)

    start_angle = 0
    legend_y = rect.top() + 10
    for i, (cat, val) in enumerate(self._by_category.items()):
        span = int(360 * 16 * abs(val) / total)
        color = colors[i % len(colors)]
        painter.setBrush(QBrush(color))
        painter.setPen(Qt.PenStyle.NoPen)
        painter.drawPie(x, y, size, size, start_angle, span)
        start_angle += span

        # 图例
        painter.setBrush(QBrush(color))
        painter.drawRect(rect.right() - 110, legend_y, 12, 12)
        painter.setPen(QPen())
        painter.drawText(rect.right() - 92, legend_y + 10,
                         f"{cat} {abs(val):.0f}元")
        legend_y += 22
```

**饼图一定要用 `abs(val)`。** 支出是负数，直接拿去乘角度会得到负的跨度，Qt 能画出来但扇区方向是反的，看着很怪。展示上我们只关心"占比"，用绝对值就行。

## 柱状图：坐标变换才是核心

柱状图的难点不是画矩形，是**把数据值映射到像素高度**。需要三步：找最大值定比例、算每个柱子的宽度、算柱子顶部的 y 坐标。

```
def _draw_bars(self, painter, rect):
    if not self._by_month:
        painter.drawText(rect, Qt.AlignmentFlag.AlignCenter, "暂无数据")
        return

    months = sorted(self._by_month.keys())
    values = [abs(self._by_month[m]) for m in months]
    max_val = max(values) or 1

    margin = 30
    top = rect.top() + margin
    bottom = rect.bottom() - margin
    plot_height = bottom - top
    left = rect.left() + margin
    right = rect.right() - margin
    slot = (right - left) / len(months)
    bar_w = min(40, slot * 0.6)

    # 基线
    painter.setPen(QPen(Qt.GlobalColor.gray))
    painter.drawLine(left, bottom, right, bottom)

    for i, (m, v) in enumerate(zip(months, values)):
        h = int(plot_height * v / max_val)
        bx = int(left + slot * i + (slot - bar_w) / 2)
        by = bottom - h
        painter.setBrush(QBrush(QColor(66,133,244)))
        painter.setPen(Qt.PenStyle.NoPen)
        painter.drawRect(bx, by, int(bar_w), h)

        # X 轴标签
        painter.setPen(QPen())
        painter.drawText(bx, bottom + 16, m[-2:])       # 显示 09 / 10

        # 柱顶数值
        painter.drawText(bx, by - 4, f"{v:.0f}")
```

**比例系数是 `v / max_val`，不是 `v / sum`。** 饼图才除以总和，柱状图除最大值是为了让最高的柱子顶到绘图区顶部，这样视觉对比才清晰。

## 跟着窗口缩放

因为所有坐标都是**用 `rect()` 现场算出来的**，窗口一变 `paintEvent` 自动重发，图表自然跟着缩放。这是 QPainter 自绘相对于 matplotlib 图片的最大优势之一。

**前提是你没有缓存像素图。** 一旦把图 `render` 成 QPixmap 存起来，缩放就失效了。自绘的要义就是"每次都现算"。

## 两种方式怎么选

| | QPainter 自绘 | matplotlib 嵌入 |
|---|---|---|
| 依赖 | 无，PySide6 自带 | 需额外装 matplotlib |
| 缩放 | 矢量，永远清晰 | 位图会模糊（可调 dpi） |
| 开发速度 | 要自己算坐标 | `plt.pie()` 一行搞定 |
| 样式 | 要自己画图例/标签 | 图例、标注齐全 |
| 打包体积 | 几乎不增 | 增加几十 MB |
| 适合场景 | 内嵌小图表、简单可视化 | 科学绘图、3D、导出高清图 |

**结论：功能型小图表用 QPainter，展示/科研型图表用 matplotlib。** 记账本的分类占比和月度趋势明显是前者——信息量不大、要跟着窗口缩放、不想背 matplotlib 的体积。

## 把图表接到主窗口

Model 算汇总，主窗口喂数据，中间不存中间变量：

```
def refresh(self):
    self.model.refresh()
    self.chart.set_data(
        self.model.total_by_category(),
        self.model.total_by_month(),
    )
```

**`refresh` 同时刷新表格和图表，只调一次。** 这是 Model/View 分层的红利：数据只拉一次，两个视图各取所需。

## 翻车现场一：set_data 之后忘了 update()

**症状**：代码明明跑了，`_by_category` 也换成了新数据，图却纹丝不动。

**正确写法：**

```
def set_data(self, by_category, by_month):
    self._by_category = by_category
    self._by_month = by_month
    self.update()                  # 必须有
```

## 翻车现场二：饼图角度没乘 16，画出来是个小牙签

**症状**：`drawPie(x, y, w, h, start, span)` 传了 `360` 想画整圆，结果只画了 22.5° 的一小块。

**原因**：Qt 角度单位是 1/16 度。

**正确写法：**

```
span = int(360 * 16 * abs(val) / total)
```

## 翻车现场三：支出是负数，饼图扇区反向画出

**症状**：饼图扇区逆时针展开，或者跨度为负直接报错。

**正确写法：用 `abs(val)` 算角度跨度。**

## 翻车现场四：柱状图画在绘图区外面

**症状**：柱子底部超出窗口，或者顶部坐标算成负数。

**原因**：用 `bottom - h` 但 h 算得比 `plot_height` 还大，结果 `by` 跑到 `top` 上方去了。

**正确写法：比例系数保证 `h <= plot_height`。**

```
h = int(plot_height * v / max_val)     # max_val 是 values 的最大值
assert h <= plot_height                # 这行放开发期验证
```

## 翻车现场五：把 QPainter 存成 self.painter 长期持有

**症状**：第一次画完之后偶发崩溃，或者后续绘制全画在了错误的设备上。

**正确写法：QPainter 在 paintEvent 里创建、出函数即销毁，绝不存成员变量。**

## 翻车现场六：饼图和柱状图挤在同一个 rect 里互相覆盖

**症状**：两个图重叠成一团，看不清。

**正确写法：用 `rect.adjusted()` 把区域切两半，各自画各自的。**

```
left_w = rect.width() // 2
self._draw_pie(painter, rect.adjusted(0, 0, -left_w, 0))
self._draw_bars(painter, rect.adjusted(left_w, 0, 0, 0))
```

## 翻车现场七：缩放时字体大小不变，小窗里字挤成一团

**症状**：窗口缩小后柱子变窄了，但字体还是原来的 9pt，标签互相重叠。

**正确做法：字体大小也按 rect 缩放，或者干脆只显示部分标签（间隔显示）。** 这是自绘的代价——matplotlib 会自动避让，你得自己写。

## 小结

- ChartView(QWidget) 只暴露 set_data，把数据接进来
- set_data 必须调 update() 触发重绘
- QPainter 只在 paintEvent 里创建，不存成员变量
- 饼图角度单位是 1/16 度，要乘 16
- 饼图用 abs(val) 算跨度，避免负数反向
- 柱状图比例系数用 v / max_val，让最高柱顶到顶
- 现算坐标，图表自动跟随窗口缩放
- 内嵌小图表用 QPainter，科研可视化用 matplotlib
