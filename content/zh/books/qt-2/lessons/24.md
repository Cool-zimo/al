# QNetworkAccessManager 基础：HTTP 请求与异步响应

> 桌面程序要联网抓数据，用 requests 虽然能跑，但它是同步的——一调用界面就冻住。Qt 的做法是异步：`QNetworkAccessManager` 发请求，信号回来时再处理响应。

## 一个最小 GET 请求

```
import sys
from PySide6.QtWidgets import QApplication, QWidget, QVBoxLayout, QPushButton, QLabel
from PySide6.QtNetwork import QNetworkAccessManager, QNetworkRequest
from PySide6.QtCore import QUrl

class Demo(QWidget):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("网络请求")
        self.resize(400, 200)

        self.label = QLabel("点击按钮发起请求")
        btn = QPushButton("请求数据")
        btn.clicked.connect(self.fetch)

        self.manager = QNetworkAccessManager(self)   # ① 管理器（长生命周期）

        layout = QVBoxLayout(self)
        layout.addWidget(self.label)
        layout.addWidget(btn)

    def fetch(self):
        url = QUrl("https://httpbin.org/get")
        request = QNetworkRequest(url)
        reply = self.manager.get(request)            # ② 发 GET
        reply.finished.connect(lambda: self.on_done(reply))  # ③ 信号连接

    def on_done(self, reply):
        if reply.error() != reply.NetworkError.NoError:
            self.label.setText(f"错误: {reply.errorString()}")
            reply.deleteLater()
            return
        data = reply.readAll()                       # ④ 读响应
        text = bytes(data).decode("utf-8")
        self.label.setText(text[:200])
        reply.deleteLater()                          # ⑤ 必须释放

if __name__ == "__main__":
    app = QApplication(sys.argv)
    w = Demo()
    w.show()
    app.exec()
```

## 关键 API

| 类/方法 | 作用 |
|---|---|
| QNetworkAccessManager | 网络管理器，通常一个 App 一个实例 |
| QNetworkRequest(url) | 请求对象，可设 Header、超时等 |
| manager.get(request) | 发 GET，返回 QNetworkReply |
| manager.post(request, data) | 发 POST |
| reply.finished | 完成信号（无论成败） |
| reply.readyRead | 有数据可读时（用于流式） |
| reply.errorOccurred | 出错信号 |
| reply.readAll() | 读取全部响应体（QByteArray） |
| reply.deleteLater() | 异步安全释放 reply |

## POST 请求

```
from PySide6.QtCore import QByteArray, QJsonDocument

def post_json(self):
    url = QUrl("https://httpbin.org/post")
    request = QNetworkRequest(url)
    request.setHeader(QNetworkRequest.KnownHeaders.ContentTypeHeader,
                      "application/json")

    payload = QJsonDocument({"name": "测试", "value": 42}).toJson()
    reply = self.manager.post(request, payload)
    reply.finished.connect(lambda: self.on_done(reply))
```

## 异步为什么重要

GUI 主线程负责处理鼠标、键盘、绘制。**一旦主线程阻塞，界面就卡死**——拖动无响应、按钮点不动、动画停摆。

```
# 错误示范：同步等待（会冻住界面几秒）
import urllib.request
data = urllib.request.urlopen("https://httpbin.org/get", timeout=5).read()
```

Qt 的事件循环靠信号回调，请求在后台线程跑，完成才切回主线程触发 `finished`，全程 UI 不卡。

## 翻车现场一：网络请求用同步等待，界面冻住

**症状：点一下按钮，窗口"白屏"几秒，鼠标变转圈，期间点什么都无响应。

**错误写法：**

```
import requests
def on_click(self):
    resp = requests.get("https://httpbin.org/get", timeout=5)   # 主线程阻塞 5 秒
    self.label.setText(resp.text[:200])
```

**正确做法：用 QNetworkAccessManager 的异步信号机制（见上面完整示例）。**

## 翻车现场二：忘了 reply.deleteLater()，内存泄漏

**症状**：程序跑久了内存持续增长，尤其频繁请求时。

**原因**：QNetworkReply 是 QObject，分配在堆上。Qt 不会自动回收它，必须手动 `deleteLater()`。

**正确做法：无论成功失败，finished 回调里都要 deleteLater：**

```
def on_done(self, reply):
    try:
        ...
    finally:
        reply.deleteLater()
```

## 翻车现场三：响应是中文但解码成乱码

**症状：中文全变成 `\xe4\xb8\xad\xe6\x96\x87` 或 `����`。

**原因**：`reply.readAll()` 返回 QByteArray。没解码就是 bytes；或者服务端没返回 charset，按错编码解码就乱。

**正确做法：用 utf-8 解码，并处理异常：**

```
data = reply.readAll()
try:
    text = bytes(data).decode("utf-8")
except UnicodeDecodeError:
    text = bytes(data).decode("gbk", errors="replace")
```

## 翻车现场四：manager 是局部变量，被垃圾回收导致请求失败

**症状**：程序运行一段时间或函数返回后，请求发出去但 finished 永远不触发。

**原因**：manager 被当成了局部变量，函数结束后被 Python 回收，Qt 的网络会话随之结束。

**正确做法：manager 做成实例成员（self.manager），保证生命周期覆盖请求全过程。**

## 翻车现场五：SSL 报错 "TLS initialization failed"

**症状**：在部分 Windows 环境访问 HTTPS 站点时报 SSL 初始化失败。

**原因**：Qt 的网络模块依赖系统的 TLS 后端，某些环境缺失或版本不匹配。

**应对**：确认 Qt 版本较新（5.12.4+ / 6.x 通常自带 Schannel 或 OpenSSL 集成），或用 HTTP 测试端点（如 httpbin.org 的 http 版本）验证代码逻辑。

## 小结

- 网络请求用 QNetworkAccessManager，全局通常一个实例
- 请求异步，通过 finished 信号回调处理结果
- 响应用 reply.readAll() 读取，返回 QByteArray，需 decode
- 务必 reply.deleteLater() 释放资源
- manager 要作为成员变量保持生命周期
- 禁止在主线程用 requests / urllib 同步等待
- 中文乱码问题统一用 utf-8 解码并处理异常

  import sys
  from PySide6.QtWidgets import (QApplication, QWidget, QVBoxLayout,

                                QPlainTextEdit)

  from PySide6.QtCore import QUrl, QTimer

  class Browser2(QWidget):
      def __init__(self):
          super().__init__()
          self.setWindowTitle("迷你请求器（超时版）")

          self._current_reply = None

          self.btn.clicked.connect(self.fetch)

          bar = QHBoxLayout()

          reply = self.manager.get(req)
          self._current_reply = reply
