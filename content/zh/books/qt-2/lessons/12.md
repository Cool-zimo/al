# 继承现有控件扩展：子类化 QPushButton 加个倒计时、加自定义信号

> 完全自绘太重，QSS 又不够。这一课讲"继承现有控件扩展"：复用父类全部行为，只加你要的那一点——倒计时、自定义信号、额外属性。这是性价比最高的自定义方式。

## 子类化的基本套路

**继承一个现有控件，先 `super().__init__()`，再追加你自己的逻辑。**

```
from PySide6.QtWidgets import QPushButton

class IconButton(QPushButton):
    def __init__(self, icon_text, label, parent=None):
        super().__init__(parent)
        self._icon_text = icon_text
        self._label = label
        self.setText(f"{icon_text}  {label}")
        self.setFixedHeight(40)
```

**看起来只是个"配置过的按钮"，但它已经是你自己的类了，可以加信号、加方法、加状态。**

## 加自定义信号

**在类体里用 `Signal()` 定义，注意要用 `Signal` 而不是 `pyqtSignal`（PySide6 的写法）。**

```
from PySide6.QtCore import Signal

class SubmitButton(QPushButton):
    submitting = Signal()          # 无参数信号
    submitted = Signal(bool)       # 带 bool 参数
    progress = Signal(int)         # 带 int 参数

    def __init__(self, parent=None):
        super().__init__("提交", parent)
        self.clicked.connect(self._on_click)

    def _on_click(self):
        self.submitting.emit()
        # ... 模拟提交 ...
        self.submitted.emit(True)
```

**信号的参数是"声明时定类型、emit 时传值"。** `self.submitted.emit(True)` 传了 bool，声明时就要写 `Signal(bool)`。类型不匹配运行时会报错。

## 翻车现场一：Signal 写成了实例属性，信号没定义

**症状：运行时报 `AttributeError: 'Signal' object has no attribute 'connect'` 或者根本 connect 不上。**

```
class BadButton(QPushButton):
    def __init__(self, parent=None):
        super().__init__(parent)
        self.submitting = Signal()    # ❌ 写在 __init__ 里，成了实例属性
```

**原因：`Signal()` 必须是类属性，写在类体里。写在 `__init__` 里就成了普通实例属性，不是 Qt 的信号。**

**✅ 正确做法：写在类体里。**

```
class GoodButton(QPushButton):
    submitting = Signal()            # ✅ 类属性

    def __init__(self, parent=None):
        super().__init__(parent)
```

**这个坑在 PyQt5/PySide2 时代尤其常见，PySide6 会直接报错，反而更容易发现。**

## 倒计时按钮完整实现

**把上一课的思路落地成一个完整的、可复用的控件：**

```
from PySide6.QtCore import QTimer, Signal

class CountdownButton(QPushButton):
    countdown_finished = Signal()     # 倒计时结束
    countdown_tick = Signal(int)     # 每秒 tick，带剩余秒数

    def __init__(self, normal_text="获取验证码", seconds=10, parent=None):
        super().__init__(normal_text, parent)
        self._normal_text = normal_text
        self._seconds = seconds
        self._remaining = seconds
        self._timer = QTimer(self)
        self._timer.setInterval(1000)
        self._timer.timeout.connect(self._tick)

    def start_countdown(self):
        if self._timer.isActive():
            return                    # 已经在倒计时，防重入
        self._remaining = self._seconds
        self.setEnabled(False)
        self._timer.start()
        self._update_text()

    def reset(self):
        self._timer.stop()
        self.setEnabled(True)
        self.setText(self._normal_text)

    def _tick(self):
        self._remaining -= 1
        self.countdown_tick.emit(self._remaining)
        if self._remaining <= 0:
            self._timer.stop()
            self.setEnabled(True)
            self.setText(self._normal_text)
            self.countdown_finished.emit()
        else:
            self._update_text()

    def _update_text(self):
        self.setText(f"请等待 {self._remaining}s")
```

**注意 `start_countdown` 里的防重入检查。** 这是个常被漏掉的小细节，但很重要——用户狂点按钮会启动多个定时器，倒数速度翻倍。

## 翻车现场二：QTimer 的 interval 用错了单位，倒数快了/慢了 1000 倍

**症状：预期每秒倒数一次，结果每秒倒数 1000 次（或完全不动）。**

```
self._timer = QTimer(self)
self._timer.setInterval(1)     # ❌ 单位是毫秒，1ms 一轮 = 每秒 1000 次
```

**原因：QTimer 的 interval 是毫秒。**

**✅ 正确做法：**

```
self._timer.setInterval(1000)          # ✅ 1000ms = 1 秒
# 或者用静态方法
self._timer.start(1000)
```

**"毫秒还是秒"是 Qt 里第二个高频单位坑**（第一个是角度用弧度）。

## 复合控件：把多个控件打包成一个

**"组合"不是自绘，但也是一种自定义——把 QPushButton + QLineEdit + QLabel 包进一个 QWidget，对外只暴露干净的方法。**

```
from PySide6.QtWidgets import QWidget, QHBoxLayout, QLineEdit, QPushButton

class SearchBox(QWidget):
    search_clicked = Signal(str)     # 对外只发这一个信号

    def __init__(self, parent=None):
        super().__init__(parent)
        self._input = QLineEdit()
        self._input.setPlaceholderText("搜索...")
        self._btn = QPushButton("搜索")

        self._btn.clicked.connect(self._on_search)

        layout = QHBoxLayout(self)
        layout.setContentsMargins(0, 0, 0, 0)
        layout.addWidget(self._input)
        layout.addWidget(self._btn)

    def _on_search(self):
        text = self._input.text().strip()
        if text:
            self.search_clicked.emit(text)

    def text(self):
        return self._input.text()

    def set_text(self, text):
        self._input.setText(text)
```

**对外只暴露 `search_clicked` 信号和 `text()`/`set_text()` 方法，内部两个控件对外部是隐藏的。** 这就是封装的价值——使用方不需要知道里面是 QLineEdit 还是别的什么。

## 翻车现场三：复合控件的布局忘了设 ContentsMargins，外层被撑大

**症状：SearchBox 放进外层布局后，外层布局的间距看起来不对，左侧多了一块空白。**

```
class SearchBox(QWidget):
    def __init__(self, parent=None):
        super().__init__(parent)
        layout = QHBoxLayout(self)
        # ❌ 默认 contentsMargins 是 (9, 9, 9, 9)，外层看起来有额外边距
        layout.addWidget(self._input)
        layout.addWidget(self._btn)
```

**原因：QWidget 的默认布局边距是 9px。作为独立窗口没问题，作为嵌入组件就显得"多了一圈"。**

**✅ 正确做法：设为 0，或者你想要的值。**

```
layout = QHBoxLayout(self)
layout.setContentsMargins(0, 0, 0, 0)     # ✅
```

## 小结

- 子类化是性价比最高的自定义方式，复用父类全部行为
- Signal 必须是类属性，写在类体里，不能写在 __init__
- 信号声明时定类型，emit 时传值，类型要匹配
- QTimer interval 单位是毫秒，1 秒 = 1000
- 倒计时按钮要做防重入检查，避免狂点启动多个定时器
- 复合控件用 QWidget + 布局封装，对外只暴露必要接口
- 复合控件布局一般设 contentsMargins 为 0
