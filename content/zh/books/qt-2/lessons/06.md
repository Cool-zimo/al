# QSortFilterProxyModel：排序与过滤不用改原数据，一行接入

> 你写好了 model，产品经理又来了：要排序、要搜索。你不用改 model 一行代码——加一个 QSortFilterProxyModel 当中间人，原数据纹丝不动。

## ProxyModel 是什么：夹在 model 和 view 之间的中间层

**ProxyModel 自己也是一个 model。view 不知道它是"代理"，只当它是普通 model 用；它再去找真正的 source model 要数据。**

```
source_model ──► proxy_model ──► view
   （真实数据）   （排序/过滤）    （显示）
```

**这个设计的妙处：source model 是只读的、完整的、原始顺序的。proxy 在中间做任何变换，对 source 完全透明。**

```
from PySide6.QtCore import QSortFilterProxyModel, Qt
from PySide6.QtWidgets import QApplication, QTableView

# 假设有一个已经写好的 model
source_model = ScoreModel(students)          # 你的自定义 model

proxy = QSortFilterProxyModel()
proxy.setSourceModel(source_model)            # 接上源头

view = QTableView()
view.setModel(proxy)                         # view 只跟 proxy 说话
```

**关键：view.setModel(proxy)，不是 source_model。** 新手最常写错这一句——set 了 source 又想让排序生效，发现没反应。

## 排序：setSortRole + sort

**默认按 DisplayRole（文本）排序。要按数字排，得告诉 proxy 用哪个 role。**

```
# source model 里给数字列设了 UserRole
proxy.setSortRole(Qt.UserRole)               # 告诉 proxy 用 UserRole 排序
view.setSortingEnabled(True)                 # 允许用户点表头排序
```

**点表头排序就这一句 `setSortingEnabled(True)`。** Qt 自动连好表头点击 → proxy.sort() 的逻辑。

**程序化排序：**

```
proxy.sort(1, Qt.DescendingOrder)            # 按第 1 列降序排
proxy.sort(-1)                              # -1 表示恢复原始顺序
```

## 翻车现场一：排序按文本排，"100"排在"9"前面

**症状：成绩列点表头排序，结果是 9、100、85、88，而不是 9、85、88、100。**

```
# source model 的 data() 里只处理了 DisplayRole
def data(self, index, role=Qt.DisplayRole):
    if role == Qt.DisplayRole:
        return str(self._rows[index.row()][index.column()])  # "92"
    return None
    # ❌ 没有处理 UserRole，proxy 拿不到数字
```

**原因：proxy 默认用 DisplayRole 排序，而 DisplayRole 是字符串 "92"。字符串比较 "100" < "9"（因为 '1' < '9'）。**

**✅ 正确做法：data() 里给数字列提供 UserRole 数值，proxy 用 UserRole 排序。**

```
def data(self, index, role=Qt.DisplayRole):
    value = self._rows[index.row()][index.column()]
    if role == Qt.DisplayRole:
        return str(value)
    if role == Qt.UserRole:                  # ✅ 数字排序用这个
        return value if isinstance(value, int) else None
    return None

# 用的时候
proxy.setSortRole(Qt.UserRole)
```

**只处理 DisplayRole 是不够的，排序和过滤经常会需要"逻辑值"而不是"显示值"。**

## 过滤：setFilterFixedString 与正则

**过滤就是在 proxy 里筛出符合条件的行，view 只看到筛后的结果。**

```
proxy.setFilterFixedString("张")             # 包含"张"的行留下
proxy.setFilterRegularExpression(r"^张")     # 正则：以"张"开头
proxy.setFilterCaseSensitivity(Qt.CaseInsensitive)  # 忽略大小写
```

**filterKeyColumn：指定按哪一列过滤。**

```
proxy.setFilterKeyColumn(0)                 # 只按第 0 列（姓名）过滤
proxy.setFilterKeyColumn(-1)                # -1 表示所有列都参与
```

**清空过滤：**

```
proxy.setFilterFixedString("")              # 传空字符串，显示全部
```

## 翻车现场二：filterKeyColumn 默认只按第一列，其他列搜不到

**症状：搜索框输入"92"，想找成绩 92 的行，结果什么都没出来。

```
proxy.setFilterFixedString("92")
# 默认 filterKeyColumn = 0，只搜姓名列，成绩列不参与
```

**原因：`setFilterKeyColumn` 默认是 0（只搜第一列）。** 想搜所有列要显式设为 -1。

**✅ 正确做法：**

```
proxy.setFilterKeyColumn(-1)                # 所有列参与过滤
proxy.setFilterFixedString("92")            # 现在能搜到成绩列了
```

**或者按特定列搜（更常见，比如专门的"搜索姓名"框）。**

```
name_filter = QSortFilterProxyModel()
name_filter.setSourceModel(source_model)
name_filter.setFilterKeyColumn(0)          # 只搜姓名列
```

## 翻车现场三：view 拿到的 index 是 proxy 的，不是 source 的

**症状：想拿到选中行的原始数据，用 proxy 的 index 去 source model 里查，行号对不上。**

```
idx = view.currentIndex()                  # 这是 proxy 的 index
row = idx.row()                            # 比如 0（过滤后的第 0 行）
source_model._rows[row]                    # ❌ 可能是"李四"，不是显示的"张三"
```

**原因：过滤后 proxy 的行序和 source 的行序不一样了。** proxy 的 index 带的是 proxy 坐标系，不能直接喂给 source model。

**✅ 正确做法：用 `mapToSource` 转换。**

```
proxy_idx = view.currentIndex()
source_idx = proxy.mapToSource(proxy_idx)  # 转成 source 坐标
real_row = source_idx.row()                # 这才是 source 里的真实行号
data = source_model._rows[real_row]
```

**配套的还有 `mapFromSource`（source→proxy）和 `mapSelectionToSource`（批量转换选中）。** 凡是要在 proxy 和 source 之间走动，都走这两个方法。

## 多级代理：排序 + 过滤叠两层

**proxy 也是 model，所以 proxy 还能再套 proxy。**

```
source_model = ScoreModel(students)

filter_proxy = QSortFilterProxyModel()
filter_proxy.setSourceModel(source_model)
filter_proxy.setFilterKeyColumn(0)

sort_proxy = QSortFilterProxyModel()
sort_proxy.setSourceModel(filter_proxy)     # 在过滤后的结果上排序
sort_proxy.setSortRole(Qt.UserRole)

view.setModel(sort_proxy)
```

**顺序有意义：先过滤、再排序，结果是"筛选后的子集按成绩排"。** 反过来先排序再过滤，结果一样但效率不同（过滤是便宜操作，放内层减少外层处理量）。

## 小结

- ProxyModel 是夹在 source model 和 view 之间的中间层，对两边都是透明 model
- view.setModel 要设 proxy，不是 source
- 排序用 setSortRole(UserRole) + setSortingEnabled(True) 或 proxy.sort()
- 数字列必须在 data() 里提供 UserRole，否则按文本排
- 过滤用 setFilterFixedString / setFilterRegularExpression
- filterKeyColumn 默认 0，搜所有列要设 -1
- proxy 的 index 要用 mapToSource 转成 source 坐标才能用
- 可多级代理叠加排序和过滤

  import sys
  from PySide6.QtCore import QAbstractTableModel, Qt, QSortFilterProxyModel, QModelIndex
  from PySide6.QtWidgets import (
      QApplication, QWidget, QTableView, QLineEdit, QVBoxLayout
  )

  class TodoModel(QAbstractTableModel):
      def __init__(self, rows=None):
          super().__init__()
          self._rows = rows or [
              ["买菜", "待办"],
              ["写代码", "进行中"],
              ["健身", "待办"],
              ["看书", "完成"],
          ]

      def rowCount(self, parent=Qt.QModelIndex()):
          return len(self._rows)

      def columnCount(self, parent=Qt.QModelIndex()):
          return 2

      def data(self, index, role=Qt.DisplayRole):
          if not index.isValid():
              return None
          if role == Qt.DisplayRole:
              return str(self._rows[index.row()][index.column()])
          return None

      def headerData(self, section, orientation, role=Qt.DisplayRole):
          if role == Qt.DisplayRole and orientation == Qt.Horizontal:
              return ["事项", "状态"][section]
          return None

  app = QApplication(sys.argv)
  win = QWidget()
  win.setWindowTitle("带排序过滤的待办")

  proxy = QSortFilterProxyModel()
  proxy.setSourceModel(source)
  proxy.setFilterKeyColumn(-1)                       # 所有列参与过滤

  search = QLineEdit()
  search.setPlaceholderText("输入关键字过滤...")

  def on_text(text):
      proxy.setFilterFixedString(text)

  search.textChanged.connect(on_text)

  view = QTableView()
  view.setModel(proxy)
  # 在这里补全：让表头点击可以排序
  # view.setSortingEnabled(True)

  layout = QVBoxLayout(win)
  layout.addWidget(search)
  layout.addWidget(view)
  win.resize(400, 300)
  win.show()
  app.exec()

- 搜索框输入关键字后能实时过滤
