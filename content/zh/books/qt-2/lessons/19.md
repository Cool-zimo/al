# 渐变与路径：QLinearGradient / QRadialGradient 与 QPainterPath

> 纯色填充满大街都是，渐变才是让控件"有质感"的第一步。而 QPainterPath 能让你画出任意复杂轮廓——圆角标签、箭头、进度弧、不规则按钮，全靠它。

## 线性渐变 QLinearGradient

渐变对象本身是个"颜色配方"，要挂到 QBrush 上才生效。

```
from PySide6.QtGui import QLinearGradient, QRadialGradient, QPainterPath, QPainterPath
from PySide6.QtCore import Qt, QPointF

p = QPainter(self)
p.setRenderHint(QPainter.RenderHint.Antialiasing)

# 线性渐变：从 (0,0) 到 (0,200)，垂直方向
grad = QLinearGradient(0, 0, 0, 200)
grad.setColorAt(0.0, Qt.GlobalColor.white)
grad.setColorAt(1.0, Qt.GlobalColor.blue)
p.setBrush(QBrush(grad))
p.setPen(Qt.PenStyle.NoPen)
p.drawRect(20, 20, 120, 200)
```

`setColorAt(stop, color)` 的 stop 取值 0.0~1.0，代表渐变方向上的位置。可以设任意多个停靠点，做多色渐变：

```
grad.setColorAt(0.0, Qt.GlobalColor.red)
grad.setColorAt(0.5, Qt.GlobalColor.yellow)
grad.setColorAt(1.0, Qt.GlobalColor.green)
```

**渐变的坐标空间是当前 QPainter 坐标系**，也就是说如果旋转或平移了画布，渐变方向会跟着一起转。

## 径向渐变 QRadialGradient

从中心向外辐射，适合画"球体感""光晕"。

```
rad = QRadialGradient(100, 100, 80)   # 中心 (100,100)，半径 80
rad.setColorAt(0.0, Qt.GlobalColor.white)
rad.setColorAt(1.0, Qt.GlobalColor.darkGray)
p.setBrush(QBrush(rad))
p.drawEllipse(QRect(20, 20, 160, 160))   # 一个立体感小球
```

完整形式 `QRadialGradient(cx, cy, radius, fx, fy)` 还能指定焦点（高光点）偏移中心，做出"侧光"效果。

## QPainterPath：把线条攒成一条路径

Path 的本质是一个可复用的矢量轮廓，可以 moveTo / lineTo / arcTo / cubicTo / closeSubPath 逐步拼接，然后一次性 stroke（描边）+ fill（填充）。

```
path = QPainterPath()
path.moveTo(50, 150)        # 落笔点
path.lineTo(100, 50)        # 直线
path.lineTo(150, 150)       # 直线
path.closeSubPath()         # 回到起点，闭合

p.setBrush(QBrush(Qt.GlobalColor.orange))
p.setPen(QPen(Qt.GlobalColor.darkRed, 2))
p.drawPath(path)            # 一次描边+填充
```

## Path 的常见套路

| 需求 | 写法 |
|---|---|
| 圆角矩形 | `path.addRoundedRect(rect, rx, ry)` |
| 椭圆 | `path.addEllipse(rect)` |
| 多边形 | moveTo + 多次 lineTo + closeSubPath |
| 弧形 | `path.arcTo(rect, startAngle, spanAngle)` |
| 文字轮廓 | `path.addText(point, font, "ABC")` |

## 一个完整示例：渐变按钮 + 圆角标签

```
class FancyDemo(QWidget):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("渐变与路径")
        self.resize(400, 260)

    def paintEvent(self, event):
        p = QPainter(self)
        p.setRenderHint(QPainter.RenderHint.Antialiasing)

        # 线性渐变按钮
        grad = QLinearGradient(0, 60, 0, 120)
        grad.setColorAt(0.0, Qt.GlobalColor.cyan)
        grad.setColorAt(1.0, Qt.GlobalColor.blue)
        p.setBrush(QBrush(grad))
        p.setPen(QPen(Qt.GlobalColor.darkBlue, 1))
        p.drawRoundedRect(QRect(30, 60, 200, 60), 12, 12)

        p.setPen(Qt.GlobalColor.white)
        p.setFont(QFont("Sans", 14, QFont.Weight.Bold))
        p.drawText(QRect(30, 60, 200, 60),
                   Qt.AlignmentFlag.AlignCenter, "确认提交")

        # 径向渐变小太阳
        rad = QRadialGradient(320, 90, 50, 310, 80)
        rad.setColorAt(0.0, Qt.GlobalColor.yellow)
        rad.setColorAt(1.0, Qt.GlobalColor.red)
        p.setBrush(QBrush(rad))
        p.setPen(Qt.PenStyle.NoPen)
        p.drawEllipse(QRect(270, 40, 100, 100))

        # Path 画一个箭头
        arrow = QPainterPath()
        arrow.moveTo(60, 180)
        arrow.lineTo(140, 180)
        arrow.lineTo(140, 170)
        arrow.lineTo(180, 195)
        arrow.lineTo(140, 220)
        arrow.lineTo(140, 210)
        arrow.lineTo(60, 210)
        arrow.closeSubPath()
        p.setBrush(QBrush(Qt.GlobalColor.darkGreen))
        p.setPen(Qt.PenStyle.NoPen)
        p.drawPath(arrow)
```

## 翻车现场一：渐变画出来是纯色块，没有渐变效果

**症状：设置了 setColorAt，结果矩形是一片纯色，完全没有过渡。**

**错误写法：**

```
grad = QLinearGradient(0, 0, 0, 0)    # ← 起点终点相同，方向长度为零
grad.setColorAt(0.0, Qt.GlobalColor.white)
grad.setColorAt(1.0, Qt.GlobalColor.blue)
```

**原因**：渐变的起点和终点重合，Qt 无法计算方向，就退化成纯色（通常取第一个停靠点的颜色）。

**正确写法：让起点终点有明确距离和方向：**

```
grad = QLinearGradient(0, 0, 0, 200)        # 垂直渐变
grad = QLinearGradient(0, 0, 200, 0)        # 水平渐变
grad = QLinearGradient(0, 0, 200, 200)      # 对角线渐变
```

## 翻车现场二：Path 没 closeSubPath，填充出现缺口

**症状：用 moveTo/lineTo 画的多边形，填充后有一条边没封住，看起来像开口的口袋。**

**错误写法：**

```
arrow = QPainterPath()
arrow.moveTo(60, 180)
arrow.lineTo(140, 180)
arrow.lineTo(140, 210)
arrow.lineTo(60, 210)
# 漏了 closeSubPath()
p.drawPath(arrow)
```

**原因**：Path 只是记录了你给的顶点，不会自动闭合。描边时最后一条边不画，填充时边界也不完整。

**正确做法：手动回到起点，或调用 closeSubPath()：**

```
arrow.lineTo(60, 180)          # 手动回到起点
# 或者
arrow.closeSubPath()           # 自动连回 moveTo 的起点
```

## 翻车现场三：渐变坐标被变换矩阵带偏

**症状：translate/rotate 之后，渐变方向跟着画布一起转了，本想做垂直渐变却变成水平的。**

**错误写法：**

```
p.rotate(90)
grad = QLinearGradient(0, 0, 0, 200)   # 你以为是垂直，实际被旋转成水平
p.setBrush(QBrush(grad))
p.drawRect(0, 0, 200, 200)
```

**原因**：渐变停靠点是在 QPainter 当前坐标系里解释的。旋转后，"竖直方向"已经变了。

**正确做法：在变换之前创建并设置好渐变，或者在变换坐标系里重新计算起点终点。**

## 小结

- 渐变必须挂到 QBrush 上，setColorAt 停靠点 0.0~1.0
- QLinearGradient 起终点不能重合，否则退化为纯色
- QRadialGradient 可做球体/光晕，焦点偏移制造侧光
- QPainterPath 用 moveTo/lineTo/closeSubPath 攒轮廓
- Path 必须 closeSubPath，否则填充有缺口
- 渐变坐标随当前变换矩阵，变换后方向会变
- addRoundedRect / addEllipse / addText 是 Path 的便捷方法
