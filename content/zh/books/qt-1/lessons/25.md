# 深色模式与主题切换

> 一个"切换主题"按钮，背后是动态替换 QSS。这一课讲怎么组织两套样式表，以及切换时最容易踩的坑。

## 主题就是两套 QSS

**最朴素的做法：把深色和浅色两套 QSS 写成字符串，切换时重新 setStyleSheet。**

```
light_qss = """
    QWidget {
        background-color: #ffffff;
        color: #2c3e50;
    }
    QPushButton {
        background-color: #3498db;
        color: white;
        border: none;
        border-radius: 6px;
        padding: 8px 16px;
    }
    QLineEdit {
        background-color: white;
        border: 1px solid #bdc3c7;
        border-radius: 4px;
        padding: 6px;
    }
"""

dark_qss = """
    QWidget {
        background-color: #2c3e50;
        color: #ecf0f1;
    }
    QPushButton {
        background-color: #1abc9c;
        color: #2c3e50;
        border: none;
        border-radius: 6px;
        padding: 8px 16px;
    }
    QLineEdit {
        background-color: #34495e;
        color: #ecf0f1;
        border: 1px solid #7f8c8d;
        border-radius: 4px;
        padding: 6px;
    }
"""
```

**切换函数：**

```
def apply_theme(theme):
    if theme == "dark":
        app.setStyleSheet(dark_qss)
    else:
        app.setStyleSheet(light_qss)
```

**关键是"全部重新设"——QSS 是整体替换，不是增量叠加。** 设一次新的就把旧的覆盖掉。

## 动态切换的完整示例

**按钮触发切换，并用 QSettings 记住用户选择：**

```
from PySide6.QtCore import QSettings

settings = QSettings("MyCompany", "MyApp")

def toggle_theme():
    current = settings.value("theme", "light")
    new_theme = "dark" if current == "light" else "light"
    apply_theme(new_theme)
    settings.setValue("theme", new_theme)
    settings.sync()

btn = QPushButton("切换主题")
btn.clicked.connect(toggle_theme)

# 启动时应用保存的主题
apply_theme(settings.value("theme", "light"))
```

**`QSettings` 把偏好存到系统配置里，下次启动自动恢复。** Windows 存在注册表，macOS 存在 plist，Linux 存在 ini，代码不用管。

**按钮文字跟着变：**

```
def apply_theme(theme):
    if theme == "dark":
        app.setStyleSheet(dark_qss)
        btn.setText("切换到浅色模式")
    else:
        app.setStyleSheet(light_qss)
        btn.setText("切换到深色模式")
```

## 翻车现场一：只给主窗口设样式，子控件还是旧的

**症状：点了切换，主窗口背景变了，但 QLineEdit 和 QPushButton 完全没反应。**

```
def apply_theme(theme):
    window.setStyleSheet(dark_qss)    # ❌ 只设给 window
```

**原因：QSS 的作用域取决于你 set 给谁。** 设给 window 时，子控件会继承一部分，但很多控件（尤其 QPushButton）有自己独立的背景绘制逻辑，不总是继承父级的。

**✅ 正确做法：把样式设给 app，全局生效。**

```
def apply_theme(theme):
    app.setStyleSheet(dark_qss)    # ✅ 全局
```

**如果想让不同窗口用不同主题，那才设给 window。** 单一主题的应用一律设给 app 最省心。

## 翻车现场二：QSS 里写了固定颜色，切换后 QLabel 文字看不见

**症状：浅色主题下 QLabel 正常，切到深色主题后 QLabel 文字消失了——其实是白色文字配了白色背景。**

```
light_qss = """
    QWidget { background-color: #ffffff; }
    QLabel { color: #333333; }
"""
dark_qss = """
    QWidget { background-color: #2c3e50; }
    QLabel { color: #ffffff; }
"""
# 但如果某处单独给某个 QLabel 设了白色背景：
label.setStyleSheet("background-color: white; color: white;")
# 切到深色主题后，这个 label 白底白字，啥也看不见
```

**原因：局部 setStyleSheet 的优先级永远高于全局。** 全局切换覆盖不了它，因为它"更靠近"控件。

**✅ 正确做法：不要在单个控件上写死背景色和前景色，让它们继承全局主题。**

```
label.setStyleSheet("")    # 清空局部样式，让全局 QSS 接管
```

**如果必须给某个控件特殊样式，用 QSS 类选择器或 ID 选择器把它写进全局主题，两套主题里都定义：**

```
light_qss = """
    QLabel#status { color: #27ae60; }
"""
dark_qss = """
    QLabel#status { color: #2ecc71; }
"""
```

**规则：全局统一管理的颜色才能跟着主题切换，局部写死的颜色会脱离主题。**

## 从文件加载 QSS

**把 QSS 写进 .qss 文件，用 Python 读取，比硬编码字符串清爽得多。**

```
def load_qss(path):
    with open(path, "r", encoding="utf-8") as f:
        return f.read()

light_qss = load_qss("themes/light.qss")
dark_qss = load_qss("themes/dark.qss")
```

**目录结构：**

```
project/
├── main.py
├── themes/
│   ├── light.qss
│   └── dark.qss
└── icons/
```

**读取失败要有兜底：**

```
def load_qss(path):
    try:
        with open(path, "r", encoding="utf-8") as f:
            return f.read()
    except FileNotFoundError:
        print(f"主题文件 {path} 不存在，使用默认样式")
        return ""
```

**结合 qrc 把主题文件也打包：**

```
<RCC>
    <qresource prefix="/themes">
        <file>themes/light.qss</file>
        <file>themes/dark.qss</file>
    </qresource>
</RCC>
```

**从资源读 QSS：**

```
from PySide6.QtCore import QFile, QTextStream

def load_qss_from_rc(path):
    file = QFile(path)
    if file.open(QFile.ReadOnly | QFile.Text):
        stream = QTextStream(file)
        return stream.readAll()
    return ""
```

## 适配系统主题

**监听系统深浅色变化，自动跟随：**

```
from PySide6.QtGui import QPalette

# 判断当前系统主题
def is_dark_mode():
    palette = app.palette()
    bg = palette.color(QPalette.Window)
    return bg.lightness() < 128    # 窗口背景亮度低于 128 认为是深色

# 启动时跟随系统
apply_theme("dark" if is_dark_mode() else "light")
```

**更精细的跟随需要监听系统信号，Windows 上要处理 WM_SETTINGCHANGE 消息，通常只在专业应用里做。** 一般应用提供手动切换按钮 + 记住偏好就够了。

## 小结

- 主题切换本质是动态替换 QSS，两套字符串/文件
- 用 app.setStyleSheet 全局生效，不要只设给 window
- QSettings 记住用户偏好，下次启动自动恢复
- ⚠️ 经典坑：局部写死颜色脱离主题导致白底白字；只给 window 设样式子控件不生效
- 主题写进 .qss 文件更清爽，可用 qrc 打包
- 配色方案：浅色用 #ffffff 背景 + 深色文字，深色用 #2c3e50 背景 + #ecf0f1 文字
- is_dark_mode 用 QPalette 判断系统主题
