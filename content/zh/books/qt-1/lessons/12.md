# QTextEdit 与 QPlainTextEdit：多行文本

> 单行的用 QLineEdit，多行的用 QTextEdit 或 QPlainTextEdit。两者的差别在"要不要富文本"：QTextEdit 支持字体、颜色、图片（富文本），QPlainTextEdit 只处理纯文本但更快。这一课讲清怎么选、怎么用、textChanged 信号怎么接。

## QTextEdit：富文本编辑器

**QTextEdit 支持加粗、颜色、字体、图片——一个迷你 Word。**

```
from PySide6.QtWidgets import QTextEdit

editor = QTextEdit()
editor.setPlainText("这是纯文本内容")     # 设纯文本
editor.setHtml("<b>加粗</b> 和 <i>斜体</i>")   # 设富文本
```

**`setPlainText` 把内容当纯文本处理；`setHtml` 会解析 HTML 标签渲染。**

**取值两种方式：**

```
print(editor.toPlainText())    # 只取文字，丢样式："加粗 和 斜体"
print(editor.toHtml())         # 取完整 HTML，含样式标签
```

**一般做编辑器用 `toPlainText()`，做聊天记录显示用 `setHtml()` 或 `append()`。**

## QPlainTextEdit：纯文本，更快

**QPlainTextEdit 只处理纯文本，不做富文本渲染，性能更好。**

```
from PySide6.QtWidgets import QPlainTextEdit

editor = QPlainTextEdit()
editor.setPlainText("第一行\n第二行\n第三行")
print(editor.toPlainText())
```

**怎么选？**

| 场景 | 用哪个 |
|---|---|
| 写代码、写日志、写笔记（纯文本） | QPlainTextEdit |
| 聊天记录、富文本显示 | QTextEdit |
| 需要加粗/颜色/图片 | QTextEdit |
| 十万行以上大文本 | QPlainTextEdit（性能优势明显） |

**做代码编辑器（第 6 课那种简单编辑器）用 QPlainTextEdit。** 做聊天软件的消息区用 QTextEdit。

## 只读模式

**`setReadOnly(True)` 让编辑区变成只读（可滚动、可选中、可复制，但不能改）：**

```
editor = QTextEdit()
editor.setReadOnly(True)
editor.setPlainText("这是一段只读的协议内容……")
```

**常见用途：用户协议、日志查看器、聊天记录。**

**翻车现场：用了 setEnabled(False) 导致连复制都不行：**

```
editor.setReadOnly(True)      # 正确：可滚动可复制
editor.setEnabled(False)      # 错误：完全灰掉，无法交互
```

**要"能看不能改"，用 setReadOnly，不要用 setEnabled(False)。**

## 追加内容

**`append` 在末尾追加一行（QTextEdit 有，QPlainTextEdit 也有类似方法）：**

```
editor = QTextEdit()
editor.append("第一条消息")      # 追加并换行
editor.append("第二条消息")
```

**QPlainTextEdit 的 appendPlainText：**

```
editor = QPlainTextEdit()
editor.appendPlainText("日志行 1")
editor.appendPlainText("日志行 2")
```

**做日志查看器常用：**

```
import datetime

def log(msg):
    now = datetime.datetime.now().strftime("%H:%M:%S")
    editor.append(f"[{now}] {msg}")
```

## textChanged 信号

**`textChanged` 在内容变化时触发，不带参数：**

```
editor.textChanged.connect(lambda: print("内容变了"))
```

**如果想知道新内容是什么，在槽函数里自己读：**

```
def on_text_changed():
    current = editor.toPlainText()
    print("当前内容：", current)

editor.textChanged.connect(on_text_changed)
```

**这个信号不带参数，和 QLineEdit 的 `textChanged(str)` 不一样。** 别写成 `lambda text: ...`，text 会是 None 或者报错。

## 翻车现场一：textChanged 槽函数多写了一个参数

**症状：一输入就崩溃。**

```
editor.textChanged.connect(lambda text: print(text))   # 报错！
```

**报错信息：`TypeError: <lambda>() missing 1 required positional argument: 'text'`**

**原因：QTextEdit.textChanged 信号不带参数，但 lambda 定义了一个参数 `text`，调用时没传值。**

**解决：**

```
editor.textChanged.connect(lambda: print(editor.toPlainText()))   # 正确
```

**或者写个普通函数，在函数体里读：**

```
def on_changed():
    print(editor.toPlainText())

editor.textChanged.connect(on_changed)
```

## 光标与选中文本

**`textCursor()` 拿到光标对象，可以做选中、插入等操作：**

```
cursor = editor.textCursor()
cursor.select(QTextCursor.SelectionType.Document)   # 全选
editor.setTextCursor(cursor)
```

**`selectedText()` 拿到选中的文本：**

```
selected = editor.textCursor().selectedText()
print("用户选中了：", selected)
```

**`insertPlainText` 在光标处插入：**

```
editor.insertPlainText("新内容")
```

## 翻车现场二：想清空内容，用了错误的属性

**症状：内容清不掉或者报错。**

```
editor.setText("")         # 正确：设成空字符串
editor.clear()            # 也正确：QTextEdit 有 clear 方法
```

**两者都能清空，用哪个都行。** `clear()` 更语义化。

**更隐蔽的问题：**

```
editor.setText(None)      # 报错！None 不是字符串
```

**解决：传空字符串 `""`，别传 None。**

## 字号与字体

**`setFontPointSize` 设字号（QTextEdit 支持富文本的字体操作）：**

```
editor.setFontPointSize(14)
```

**配合 `setFontWeight(QFont.Weight.Bold)` 加粗：**

```
from PySide6.QtGui import QFont
editor.setFontWeight(QFont.Weight.Bold)
```

**QPlainTextEdit 不支持逐字样式**，要统一改整个编辑区的字体：

```
from PySide6.QtGui import QFont
font = QFont("Consolas", 12)      # 字体名 + 字号
editor.setFont(font)
```

**代码编辑器常用等宽字体 Consolas / Menlo / DejaVu Sans Mono。**

## 一个完整例子：简易笔记本

**标题 + 正文 + 自动统计字数：**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QLineEdit, QPlainTextEdit, QLabel, QVBoxLayout
)

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("简易笔记本")
window.resize(500, 400)

title_edit = QLineEdit()
title_edit.setPlaceholderText("标题")

body_edit = QPlainTextEdit()
body_edit.setPlaceholderText("正文……")

counter = QLabel("0 字")
counter.setAlignment(Qt.AlignmentFlag.AlignRight)

def update_count():
    text = body_edit.toPlainText()
    counter.setText(f"{len(text)} 字")

body_edit.textChanged.connect(update_count)

layout = QVBoxLayout(window)
layout.addWidget(title_edit)
layout.addWidget(body_edit, 1)
layout.addWidget(counter)

window.show()
app.exec()
```

**`layout.addWidget(body_edit, 1)` 里的 1 是 stretch**，让正文区占满剩余空间。字数统计用 `len(text)`，中文一个字算一个字符。

## 小结

- QTextEdit 支持富文本（字体、颜色、图片），QPlainTextEdit 只处理纯文本但更快
- 代码/日志用 QPlainTextEdit，聊天记录/富文本用 QTextEdit
- setReadOnly(True) 让编辑区"能看不能改"，别用 setEnabled(False)
- append / appendPlainText 追加一行
- textChanged 不带参数，要内容自己在槽函数里读
- setText("") 或 clear() 都能清空内容
- 字数统计用 len(editor.toPlainText())
