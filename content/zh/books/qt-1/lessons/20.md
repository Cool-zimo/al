# QAction：一处定义，多处挂载

> QAction 是"动作"对象：一个逻辑操作，可以同时挂到菜单和工具栏，还能带图标和快捷键。它是菜单和工具栏共用的"原子"。

## QAction 是什么

**QAction 把一个操作抽象成对象：名字、图标、快捷键、状态，一次定义，多处使用。**

```
from PySide6.QtGui import QAction

open_action = QAction("打开", self)
open_action.setShortcut("Ctrl+O")
open_action.setStatusTip("打开一个文件")    # 鼠标悬停时在状态栏显示
open_action.triggered.connect(self.open_file)
```

**一个 open_action 可以同时进菜单和工具栏，不用写两遍。**

```
file_menu.addAction(open_action)
toolbar.addAction(open_action)
```

**菜单里显示文字，工具栏里显示图标（如果设了的话）。** 文字和图标各用各的，互不影响。

## 一处定义，菜单工具栏共享

**完整写法：把动作集中定义，再分发到菜单和工具栏。**

```
from PySide6.QtGui import QAction, QIcon
from PySide6.QtWidgets import QMainWindow, QToolBar

class MainWindow(QMainWindow):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("编辑器")
        self.resize(500, 350)

        # 定义动作
        self.open_action = QAction("打开", self)
        self.open_action.setShortcut("Ctrl+O")
        self.open_action.setStatusTip("打开文件")
        self.open_action.triggered.connect(self.open_file)

        self.save_action = QAction("保存", self)
        self.save_action.setShortcut("Ctrl+S")
        self.save_action.triggered.connect(self.save_file)

        self.quit_action = QAction("退出", self)
        self.quit_action.setShortcut("Ctrl+Q")
        self.quit_action.triggered.connect(self.close)

        # 菜单栏
        menubar = self.menuBar()
        file_menu = menubar.addMenu("文件(&F)")
        file_menu.addAction(self.open_action)
        file_menu.addAction(self.save_action)
        file_menu.addSeparator()
        file_menu.addAction(self.quit_action)

        # 工具栏
        toolbar = QToolBar("文件")
        self.addToolBar(toolbar)
        toolbar.addAction(self.open_action)
        toolbar.addAction(self.save_action)

    def open_file(self):
        self.statusBar().showMessage("打开文件", 2000)

    def save_file(self):
        self.statusBar().showMessage("保存文件", 2000)
```

**好处：快捷键在菜单项和工具栏按钮上自动生效，改一处全生效，不用维护两份逻辑。**

## 翻车现场一：建了 QAction 却忘了 addAction，菜单里什么都不显示

**症状：明明 new 了一个 QAction，运行时菜单里却空空如也，工具栏也什么都没有。**

```
self.save_action = QAction("保存", self)
self.save_action.setShortcut("Ctrl+S")
# ❌ 忘了 addAction，动作从来没挂到任何地方
```

**原因：QAction 只是"定义了动作"，不会自己显示出来。** 必须显式调用 `menu.addAction(action)` 或 `toolbar.addAction(action)`，它才出现在界面上。

**✅ 正确写法：定义后一定要挂载。**

```
self.save_action = QAction("保存", self)
self.save_action.triggered.connect(self.save_file)

file_menu.addAction(self.save_action)    # ✅ 挂到菜单
toolbar.addAction(self.save_action)      # ✅ 挂到工具栏
```

**同理，只用字符串 `file_menu.addAction("保存")` 时 Qt 内部帮你建了临时 QAction，你拿不到引用，也就没法设快捷键和状态提示。要设这些就必须显式建 QAction。**

## 快捷键与图标

**`setShortcut` 支持标准写法和 QKeySequence 常量：**

```
open_action.setShortcut("Ctrl+O")
save_action.setShortcut("Ctrl+S")
quit_action.setShortcut(QKeySequence.Quit)    # 跨平台的标准退出快捷键
```

**`QKeySequence.Quit` 在 macOS 上是 Cmd+Q，在 Windows/Linux 上是 Ctrl+Q，用常量比硬编码字符串更专业。**

**`setIcon` 给动作加图标，工具栏就会显示图标，菜单里也会有小图标：**

```
open_action.setIcon(QIcon("open.png"))
```

**图标尺寸用工具栏的 `setIconSize` 统一控制：**

```
toolbar.setIconSize(QSize(24, 24))
```

**如果只想要文字不想要图标，工具栏也能强制显示文字：**

```
toolbar.setToolButtonStyle(Qt.ToolButtonTextOnly)
```

**四种 ToolButtonStyle：`ToolButtonIconOnly`（默认）、`ToolButtonTextOnly`、`ToolButtonTextBesideIcon`、`ToolButtonTextUnderIcon`。**

## 翻车现场二：setShortcut 写成 setKeySequence 还不生效

**症状：想给动作设快捷键，写错了方法名，运行不报错但快捷键完全没反应。**

```
self.save_action.setKeySequence("Ctrl+S")    # ❌ 方法名写错，静默失败
```

**原因：QAction 的方法叫 `setShortcut`，不是 `setKeySequence`。** 前者接受字符串和 QKeySequence，后者根本不存在，但 PySide6 的绑定在错误写法下可能报 AttributeError，也可能被静默忽略。

**✅ 正确写法：**

```
self.save_action.setShortcut("Ctrl+S")
# 或者
self.save_action.setShortcut(QKeySequence("Ctrl+S"))
```

**多快捷键：`setShortcuts` 接受列表：**

```
self.save_action.setShortcuts(["Ctrl+S", "Ctrl+Shift+S"])
```

## 禁用与可见性

**`setEnabled(False)` 让动作变灰不可用，菜单项和工具栏按钮同步变灰。**

```
self.save_action.setEnabled(False)    # 未编辑时禁用保存
# 编辑后启用
self.editor.textChanged.connect(lambda: self.save_action.setEnabled(True))
```

**`setVisible(False)` 完全隐藏，连占的位置都不要。**

```
self.advanced_action.setVisible(False)    # 普通模式下隐藏高级功能
```

**这两个状态在菜单和工具栏上完全同步，因为底层是同一个 QAction 对象。**

## 小结

- QAction 抽象"动作"，一处定义，菜单和工具栏共享
- setShortcut 设快捷键，setStatusTip 设悬停提示，setIcon 设图标
- ⚠️ 经典坑：建了 QAction 却忘了 addAction，界面上什么都不显示
- 快捷键常量 QKeySequence.Quit 比硬编码更跨平台
- setEnabled/setVisible 在菜单和工具栏上同步生效
- 工具栏按钮样式用 setToolButtonStyle，图标尺寸用 setIconSize
