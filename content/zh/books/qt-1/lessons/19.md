# QMenuBar / QToolBar / QStatusBar

> 菜单、工具栏、状态栏是桌面应用的"门面三件套"。这一课讲它们各自的写法和互相配合。

## QMenuBar：菜单栏

**QMainWindow 自带菜单栏，用 `menuBar()` 拿到，再用 addMenu 加菜单。**

```
from PySide6.QtWidgets import QMainWindow, QMenuBar, QMenu

class MainWindow(QMainWindow):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("记事本")
        self.resize(600, 400)

        menubar = self.menuBar()

        file_menu = menubar.addMenu("文件(&F)")    # &F 表示 Alt+F 快捷键
        file_menu.addAction("新建")
        file_menu.addAction("打开")
        file_menu.addAction("保存")
        file_menu.addSeparator()                    # 分隔线
        file_menu.addAction("退出")

        edit_menu = menubar.addMenu("编辑(&E)")
        edit_menu.addAction("撤销")
        edit_menu.addAction("重做")
```

**`&F` 里的 `&` 不是装饰，是助记符，Alt+F 直接展开这个菜单。** 中文界面也建议加，键盘操作快很多。

**菜单项是 QAction，后面第 20 课会详细讲。** 这里先直接用字符串，Qt 会帮你包成 QAction。

## QToolBar：工具栏

**`addToolBar` 创建一个工具栏，往里加 QAction 或任意控件。**

```
from PySide6.QtWidgets import QToolBar, QAction

toolbar = QToolBar("主工具栏")
self.addToolBar(toolbar)

toolbar.addAction("新建")
toolbar.addAction("打开")
toolbar.addSeparator()
toolbar.addAction("保存")
```

**工具栏默认可拖拽停靠，加个控件也很常见：**

```
from PySide6.QtWidgets import QLineEdit

search = QLineEdit()
search.setPlaceholderText("搜索...")
toolbar.addWidget(search)         # addWidget 加任意控件
```

**位置控制：`addToolBar` 第二个参数指定停靠区域。**

```
self.addToolBar(Qt.TopToolBarArea, toolbar)    # 顶部（默认）
self.addToolBar(Qt.LeftToolBarArea, toolbar)    # 左侧
```

**`setMovable(False)` 禁止拖拽，`setFloatable(False)` 禁止拖出来变成浮动窗口。**

## 翻车现场一：用 QWidget 做主窗口，menuBar() 是 None

**症状：代码照搬了菜单栏写法，运行却报 `AttributeError: 'QWidget' object has no attribute 'menuBar'`。**

```
class MainWindow(QWidget):              # ❌ QWidget 没有菜单栏
    def __init__(self):
        super().__init__()
        self.menuBar()                  # AttributeError!
```

**原因：菜单栏、工具栏、状态栏都是 QMainWindow 的能力，QWidget 一个都没有。** 很多人从"QWidget 窗口 + 布局"入门，换到桌面应用忘了把基类改成 QMainWindow。

**✅ 正确写法：**

```
class MainWindow(QMainWindow):          # ✅ 继承 QMainWindow
    def __init__(self):
        super().__init__()
        self.menuBar().addMenu("文件")
        self.addToolBar(QToolBar("工具"))
        self.setStatusBar(QStatusBar())
```

**如果你就是想用 QWidget 做主窗口，菜单栏就只能自己用 QMenuBar 控件塞进布局里，写法更啰嗦，不建议。**

## QStatusBar：状态栏

**`statusBar()` 拿到状态栏，用 `showMessage` 显示临时消息。**

```
statusbar = self.statusBar()
statusbar.showMessage("就绪", 3000)      # 3000 毫秒后自动清除
```

**第二个参数是超时毫秒数，不传就一直显示。** 做"已保存"提示就传 2000，做常驻提示就不传。

**状态栏可以永久放置控件：**

```
from PySide6.QtWidgets import QLabel

self.statusbar = self.statusBar()
self.cursor_label = QLabel("行 1, 列 1")
self.statusbar.addPermanentWidget(self.cursor_label)    # 靠右常驻
```

**`addPermanentWidget` 放右边，`addWidget` 放左边。** 两者都能放任意控件，不只是 QLabel。

**典型用法：主编辑区信号驱动状态栏更新。**

```
self.editor.cursorPositionChanged.connect(
    lambda: self.cursor_label.setText(f"行 {self.editor.textCursor().blockNumber() + 1}")
)
```

## 三件套合体

**菜单栏、工具栏、状态栏配齐的标准写法：**

```
class MainWindow(QMainWindow):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("编辑器")
        self.resize(600, 400)

        # 中央部件
        from PySide6.QtWidgets import QTextEdit
        self.editor = QTextEdit()
        self.setCentralWidget(self.editor)

        # 菜单栏
        menubar = self.menuBar()
        file_menu = menubar.addMenu("文件(&F)")
        file_menu.addAction("打开")
        file_menu.addAction("保存")
        file_menu.addSeparator()
        file_menu.addAction("退出")

        # 工具栏
        toolbar = QToolBar("工具")
        self.addToolBar(toolbar)
        toolbar.addAction("打开")
        toolbar.addAction("保存")

        # 状态栏
        self.statusbar = self.statusBar()
        self.statusbar.showMessage("就绪")
```

**`setCentralWidget` 是 QMainWindow 的中心区域，三件套之外所有内容都放这里。** 忘记设中央部件的话窗口是空的。

## 翻车现场二：直接给 QMainWindow 套布局，内容不显示

**症状：往 QMainWindow 里 addWidget 各种控件，运行后窗口一片空白。**

```
layout = QVBoxLayout()
layout.addWidget(QPushButton("按钮"))
self.setLayout(layout)              # ❌ QMainWindow 不能直接设 layout
```

**原因：QMainWindow 有固定结构（菜单栏、工具栏、中央区、停靠区、状态栏），不允许直接 setLayout。** 必须先用一个 QWidget 做中央部件，再给它套布局。

**✅ 正确写法：**

```
central = QWidget()
layout = QVBoxLayout(central)
layout.addWidget(QPushButton("按钮"))
self.setCentralWidget(central)      # ✅ 套一层中央部件
```

**记住口诀：QMainWindow 只认中央部件，所有子控件先塞进一个 QWidget。**

## 小结

- 菜单栏、工具栏、状态栏是 QMainWindow 专属，基类必须是 QMainWindow
- menuBar().addMenu() 加菜单，addSeparator 加分隔线，&F 设助记符
- addToolBar 加工具栏，addAction 加动作，addWidget 加任意控件
- statusBar().showMessage(text, timeout)，addPermanentWidget 放右侧常驻
- ⚠️ 经典坑：QWidget 没有 menuBar；QMainWindow 不能直接 setLayout，要先 setCentralWidget
- 中央部件是三件套之外所有内容的容器
