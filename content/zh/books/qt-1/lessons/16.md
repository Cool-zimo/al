# QMessageBox：四种提示与返回值

> 弹窗是和用户沟通最快的方式。这一课讲 QMessageBox 的四种标准对话框，以及怎么读取用户点了哪个按钮。

## QMessageBox 的四种姿势

**QMessageBox 是模态消息框，四种静态方法对应四种图标：information / warning / critical / question。**

```
from PySide6.QtWidgets import QMessageBox

QMessageBox.information(window, "标题", "操作成功！")
QMessageBox.warning(window, "警告", "磁盘空间不足")
QMessageBox.critical(window, "错误", "文件无法打开")
ret = QMessageBox.question(window, "确认", "确定要删除吗？")
```

**四个参数依次是：父窗口、标题、正文、标准按钮（可选）、默认按钮（可选）。** 返回值是一个 `StandardButton` 枚举，代表用户点的那个按钮。

**只有 `question` 默认带"是/否"两个按钮，其余三个默认只有一个"OK"。** 想让 information 也带 Yes/No，要手动传 buttons 参数：

```
ret = QMessageBox.information(
    window, "保存", "内容已修改，是否保存？",
    QMessageBox.Yes | QMessageBox.No | QMessageBox.Cancel,
    QMessageBox.Yes    # 默认高亮 Yes
)
```

## 翻车现场一：用 == 比较返回值却写成字符串

**症状：明明点了"是"，判断分支却走不进去。**

```
ret = QMessageBox.question(window, "确认", "删除？")
if ret == "Yes":          # ❌ ret 是枚举，不是字符串
    print("删除")
# 运行后点"是"也不删除，没有任何报错，分支静默跳过
```

**原因：返回值类型是 `QMessageBox.StandardButton`，是个枚举，不是字符串，也不是整数 0/1。** 用字符串比较永远不成立，Python 也不会警告。

**✅ 正确写法：**

```
from PySide6.QtWidgets import QMessageBox

ret = QMessageBox.question(window, "确认", "删除？")
if ret == QMessageBox.Yes:
    print("删除")
elif ret == QMessageBox.No:
    print("取消")
```

**PySide6 的枚举要写 `QMessageBox.Yes`，不是 `QMessageBox.YesRole`。** `YesRole` 是给自定义按钮排序用的角色值，跟返回值不是一个东西。

## 读取按钮返回值

**`question` 的返回值判断是最常用场景，本质是"要不要继续"的二选一：**

```
reply = QMessageBox.question(
    window, "退出", "确定要退出吗？",
    QMessageBox.Yes | QMessageBox.No,
    QMessageBox.No       # 默认选中 No，防误关
)

if reply == QMessageBox.Yes:
    app.quit()
```

**多按钮时用位或 `|` 组合，返回值逐个判断：**

```
ret = QMessageBox.warning(
    window, "覆盖文件", "目标文件已存在",
    QMessageBox.Save | QMessageBox.Discard | QMessageBox.Cancel,
    QMessageBox.Cancel
)

if ret == QMessageBox.Save:
    do_save()
elif ret == QMessageBox.Discard:
    do_overwrite()
else:    # Cancel
    pass
```

**`exec()` 也能打开消息框，但静态方法更省事。** 静态方法内部已经帮你 new 对象、设图标、调 exec，通常不用自己写。

## 翻车现场二：忘了父窗口参数，弹窗跑到后台

**症状：点了触发按钮，程序像卡死一样没反应，切到别的窗口才发现弹窗藏在后面。**

```
QMessageBox.information(None, "提示", "完成")    # ❌ 父窗口传 None
```

**原因：模态对话框依赖父窗口做层级管理。** 父窗口为 None 时，弹窗可能没有任务栏入口，或被父窗口遮挡，看起来像程序无响应。

**✅ 正确写法：把 self 或 window 传进去：**

```
QMessageBox.information(self, "提示", "保存成功")
```

**父窗口不为 None 还有额外好处：对话框会居中在父窗口上，关掉父窗口时弹窗也会跟着关。**

## 自定义图标和详细文本

**`setIcon` 可以手动指定图标类型：**

```
msg = QMessageBox()
msg.setWindowTitle("提示")
msg.setText("磁盘空间不足")
msg.setIcon(QMessageBox.Warning)    # Information / Warning / Critical / Question
msg.exec()
```

**`setDetailedText` 加一个可展开的"显示详情"区域，放堆栈或日志很合适：**

```
msg = QMessageBox()
msg.setWindowTitle("错误")
msg.setText("文件保存失败")
msg.setDetailedText("PermissionError: [Errno 13] Permission denied: '/root/a.txt'")
msg.exec()
```

**`setInformativeText` 是那段灰色小字，比主文本更具体但没那么醒目：**

```
msg = QMessageBox()
msg.setText("保存失败")
msg.setInformativeText("目标文件被另一个程序占用，请关闭后重试")
msg.setStandardButtons(QMessageBox.Retry | QMessageBox.Cancel)
msg.exec()
```

## 小结

- 四种静态方法：information / warning / critical / question，图标各不同
- question 默认 Yes/No，其余默认只有 OK
- 返回值是 StandardButton 枚举，用 `== QMessageBox.Yes` 判断
- ⚠️ 经典坑：用字符串 "Yes" 比较返回值永远不成立；父窗口传 None 导致弹窗被遮挡
- 多按钮用 `|` 组合，默认按钮用最后一个参数指定
- setInformativeText 放灰色说明，setDetailedText 放可展开的详细内容
