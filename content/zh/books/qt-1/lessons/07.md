# QVBoxLayout 与 QHBoxLayout

> 纵向布局（QVBoxLayout）和横向布局（QHBoxLayout）是 Qt 最常用的两种布局。它们像乐高积木：控件往里加、加拉伸因子、加间距，界面就搭起来了。这一课把 addWidget、addStretch、setSpacing 三个核心操作讲透。

## 基本用法：addWidget

**QVBoxLayout 让控件从上到下排，QHBoxLayout 让控件从左到右排。**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QPushButton, QVBoxLayout
)

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("纵向布局")

btn1 = QPushButton("按钮一")
btn2 = QPushButton("按钮二")
btn3 = QPushButton("按钮三")

layout = QVBoxLayout(window)
layout.addWidget(btn1)
layout.addWidget(btn2)
layout.addWidget(btn3)

window.resize(300, 200)
window.show()
app.exec()
```

**运行效果：三个按钮从上到下排成一行一列。** 窗口拉伸时，三个按钮一起纵向拉伸，各占三分之一高度。

**QHBoxLayout 只换一个类名，效果变成横排：**

```
layout = QHBoxLayout(window)
layout.addWidget(btn1)
layout.addWidget(btn2)
layout.addWidget(btn3)
```

**三个按钮从左到右排成一行，窗口拉伸时横向拉长。**

## addStretch：插入弹簧

**`addStretch()` 往布局里加一段"弹性空白"，把控件挤到一边。**

```
layout = QVBoxLayout(window)
layout.addWidget(btn1)
layout.addWidget(btn2)
layout.addStretch()          # 弹簧
layout.addWidget(btn3)
```

**效果：btn1、btn2 挤在上半部分，btn3 被挤到窗口底部。** 中间的弹簧会吸收所有多余空间。

**`addStretch(1)` 的数字是"拉伸因子"，决定这段空白的相对大小：**

```
layout.addWidget(btn1)
layout.addStretch(1)         # 占 1 份
layout.addWidget(btn2)
layout.addStretch(2)         # 占 2 份，是上面那段的两倍
layout.addWidget(btn3)
```

**多个 stretch 按因子比例分配多余空间。** 如果只有一个 stretch，因子写多少都一个样（因为没人和它分）。

## 翻车现场一：弹簧加错位置，控件挤在一堆

**症状：想让按钮靠下，结果按钮全挤在上边，还缩成最小尺寸。**

```
layout = QVBoxLayout(window)
layout.addStretch()          # 弹簧放最前面
layout.addWidget(btn1)
layout.addWidget(btn2)
layout.addWidget(btn3)
```

**效果：弹簧在最上面吃掉了所有多余空间，三个按钮被挤到窗口底部、紧贴在一起。**

**这是"靠下"的正确写法，但你本意可能是"靠上"。**

**想让控件靠上：把弹簧放最后。**

```
layout.addWidget(btn1)
layout.addWidget(btn2)
layout.addWidget(btn3)
layout.addStretch()          # 弹簧在最后 → 控件靠上
```

**想让控件垂直居中：两边各加一个等大的弹簧。**

```
layout.addStretch()
layout.addWidget(btn1)
layout.addWidget(btn2)
layout.addStretch()
```

**想让两个按钮分别在左右两端：**

```
hlayout = QHBoxLayout()
hlayout.addWidget(btn1)
hlayout.addStretch()
hlayout.addWidget(btn2)
```

**记住口诀：弹簧吃空间，控件被挤到弹簧的反方向。**

## setSpacing：控件间距

**`setSpacing(n)` 设置布局内控件之间的像素间距。**

```
layout = QVBoxLayout(window)
layout.setSpacing(20)        # 控件之间留 20 像素
layout.addWidget(btn1)
layout.addWidget(btn2)
layout.addWidget(btn3)
```

**默认间距是平台相关的**（Windows 上大约 6px），视觉上比较挤。自己设一个值能统一风格。

**`setContentsMargins(left, top, right, bottom)` 设置布局边缘到窗口边缘的距离：**

```
layout.setContentsMargins(20, 20, 20, 20)   # 四周各留 20 像素
```

**默认边距是 9px 左右（不同样式不同）。** 做表单界面时通常把左右边距设大一点，看起来不那么贴边。

**四个数字的顺序：左上右下，顺时针。**

## 翻车现场二：setSpacing 设成了负数

**症状：控件重叠在一起。**

```
layout.setSpacing(-5)
```

**原因：间距不能为负。** Qt 会把它当 0 处理，或者直接 clamp 到 0。

**解决：间距用非负整数，一般 0~30 之间。**

## 布局也可以 addLayout：嵌套布局

**布局里可以再放一个布局，这就是"布局嵌套"。**

```
main_layout = QVBoxLayout(window)

top_bar = QHBoxLayout()
top_bar.addWidget(QPushButton("新建"))
top_bar.addWidget(QPushButton("打开"))
top_bar.addStretch()

main_layout.addLayout(top_bar)           # 注意是 addLayout
main_layout.addWidget(QTextEdit())

window.setLayout(main_layout)
```

**效果：上面一行横向按钮栏（右侧有弹簧，按钮靠左），下面是占满剩余空间的文本编辑区。**

**`addLayout` 接收的是布局对象，不是控件。** 写错成 `addWidget(top_bar)` 会报错。

## 翻车现场三：addWidget 和 addLayout 用混

**症状：报类型错误。**

```
layout.addWidget(QHBoxLayout())   # 错误！应 addLayout
```

**报错信息：`QBoxLayout::addWidget: Cannot add a layout to a layout` 或者 `TypeError`。**

**原因：布局对象不是 QWidget，不能被 addWidget 接收。**

**解决：往布局里加子布局用 `addLayout`，加控件用 `addWidget`。**

## 给控件加拉伸因子

**`addWidget(widget, stretch)` 的第二个参数是这个控件的拉伸因子。**

```
layout = QHBoxLayout()
layout.addWidget(btn1)               # 默认 stretch=0，不拉伸
layout.addWidget(btn2, 1)            # stretch=1，吸收多余空间
```

**效果：btn1 保持推荐宽度，btn2 把剩下的空间全占了。**

**两个控件都设拉伸因子：**

```
layout.addWidget(btn1, 1)
layout.addWidget(btn2, 2)
```

**btn2 分到的是 btn1 的两倍宽。** 这是做"主内容区 + 侧边栏"的标准手法。

## 完整例子：一个像样的界面骨架

**把今天学的全用上：**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QPushButton, QLabel,
    QVBoxLayout, QHBoxLayout, QTextEdit
)
from PySide6.QtCore import Qt

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("简单编辑器")
window.resize(600, 400)

# 顶部工具栏（横向）
toolbar = QHBoxLayout()
toolbar.addWidget(QPushButton("新建"))
toolbar.addWidget(QPushButton("打开"))
toolbar.addWidget(QPushButton("保存"))
toolbar.addStretch()                        # 右侧弹簧
toolbar.addWidget(QPushButton("设置"))

# 主区域
editor = QTextEdit()
status = QLabel("就绪")
status.setAlignment(Qt.AlignmentFlag.AlignRight)

# 纵向主布局
main = QVBoxLayout(window)
main.setContentsMargins(10, 10, 10, 10)
main.setSpacing(8)
main.addLayout(toolbar)
main.addWidget(editor, 1)                   # 编辑区吸收多余空间
main.addWidget(status)

window.show()
app.exec()
```

**层次：纵向主布局里，先是横向工具栏，再是编辑区，最后是状态栏。** 编辑区的拉伸因子是 1，所以它吃掉了除了工具栏和状态栏之外的所有空间。

## 小结

- QVBoxLayout 纵向、QHBoxLayout 横向，addWidget 加控件
- addStretch 插入弹簧，吃掉多余空间，控件被挤到反方向
- setSpacing(n) 设控件间距，setContentsMargins 设四周边距
- 弹簧口诀：弹簧吃空间，控件被挤到弹簧的反方向
- 布局嵌套用 addLayout，不要写成 addWidget
- addWidget(widget, stretch) 给控件设拉伸因子
- 两个控件 stretch=1:2，后者分到两倍空间
