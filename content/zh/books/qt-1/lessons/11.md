# QLabel、QPushButton、QLineEdit

> 这三个是 Qt 最基础的控件：QLabel 显示文字或图片、QPushButton 触发动作、QLineEdit 接收单行输入。它们你已经用过多次了，这一课把各自的进阶用法和翻车点补齐。

## QLabel：不只是显示文字

**QLabel 显示文本、图片、动画，还能做文字选择。**

```
from PySide6.QtWidgets import QLabel

label = QLabel("你好，世界")
label.setText("新的文字")         # 改文字
print(label.text())              # 读文字
```

**`setWordWrap(True)` 开启自动换行：**

```
label = QLabel("这是一段很长的文字，如果不开启自动换行，它就会一直往右延伸出窗口外面去")
label.setWordWrap(True)          # 超出宽度时自动换行
```

**不开自动换行，长文本会撑破布局或者显示不全。**

**`setAlignment` 设对齐：**

```
from PySide6.QtCore import Qt
label.setAlignment(Qt.AlignmentFlag.AlignCenter)          # 水平垂直居中
label.setAlignment(Qt.AlignmentFlag.AlignRight)           # 右对齐
label.setAlignment(Qt.AlignmentFlag.AlignTop | Qt.AlignmentFlag.AlignLeft)  # 左上
```

**多个对齐标志用 `|` 组合（位或）。**

## 翻车现场一：换行后标签高度没跟着变

**症状：开了自动换行，但标签还是一行高，文字被截断。**

**原因：QLabel 的 sizePolicy 默认垂直方向是 Preferred，但布局可能把它压成了固定高度。**

**解决：让标签的 sizePolicy 垂直方向设为 Minimum 或 Expanding，给它生长空间。**

```
label.setSizePolicy(
    QSizePolicy.Policy.Preferred,
    QSizePolicy.Policy.Minimum        # 垂直方向：至少显示全部内容
)
```

## QLabel 显示图片

**`setPixmap` 显示图片：**

```
from PySide6.QtGui import QPixmap

pixmap = QPixmap("logo.png")
label.setPixmap(pixmap)
```

**图片路径找不到时不会报错，`label.pixmap()` 返回空。**

**缩放图片到标签大小：**

```
pixmap = QPixmap("logo.png")
scaled = pixmap.scaled(
    label.size(),
    Qt.AspectRatioMode.KeepAspectRatio,      # 保持宽高比
    Qt.TransformationMode.SmoothTransformation
)
label.setPixmap(scaled)
```

**`KeepAspectRatio` 保证图片不变形。** 这在做头像、缩略图时天天用。

## QPushButton：文字、图标、禁用

**最基本的按钮：**

```
from PySide6.QtWidgets import QPushButton

btn = QPushButton("确定")
btn.clicked.connect(lambda: print("点了"))
```

**`setIcon` 加图标：**

```
from PySide6.QtGui import QIcon

btn.setIcon(QIcon.fromTheme("document-save"))   # Linux 主题图标
btn.setIcon(QIcon("save.png"))                  # 本地文件
```

**`setEnabled(False)` 禁用按钮（变灰不可点）：**

```
btn.setEnabled(False)
```

**`setDefault(True)` 设为默认按钮（对话框里按回车就触发它）：**

```
ok_btn = QPushButton("确定")
ok_btn.setDefault(True)
```

**`setCheckable(True)` 让按钮变成开关：**

```
btn = QPushButton("加星")
btn.setCheckable(True)
btn.toggled.connect(lambda checked: print("勾选状态：", checked))
```

**`toggled` 信号带一个 bool 参数**，表示当前是按下还是弹起。这是开关按钮的标准做法。

## 翻车现场二：按钮点了没反应，原来是 setEnabled(False)

**症状：按钮变灰，点下去什么也不发生，怀疑信号没连上。**

**原因：按钮被 `setEnabled(False)` 了，处于禁用状态，不接受点击。**

**排查：检查代码里是不是在某处禁用了它，或者看它是否是灰色。**

**解决：需要响应点击时保持 `setEnabled(True)`。按钮条件满足时才启用是常见交互，但要记得在条件变化后重新启用。**

## QLineEdit：单行文本输入

**接收一行文本输入：**

```
from PySide6.QtWidgets import QLineEdit

edit = QLineEdit()
edit.setPlaceholderText("请输入用户名")    # 灰色提示文字
edit.setText("张三")                      # 设值
print(edit.text())                       # 取值
```

**`placeholderText` 是灰色的占位提示，用户一输入就消失。** 表单界面里很有用。

**`setMaxLength(20)` 限制最多输入 20 个字符：**

```
edit.setMaxLength(20)
```

**`setReadOnly(True)` 只读：**

```
edit.setReadOnly(True)      # 不能改，但可以选中和复制
```

**只读和禁用不同：禁用（setEnabled(False)）连选中复制都不行。**

## 翻车现场三：拿到的是整数却用 text() 当数字算

**症状：报错 `TypeError: unsupported operand type(s) for +: 'int' and 'str'`**

```
age_edit = QLineEdit()
age_edit.setText("18")
age = age_edit.text()       # 这是字符串 "18"
print(age + 1)             # 报错！
```

**解决：`int(edit.text())` 转成整数。** 但输入可能不是数字，要捕获异常：

```
text = edit.text()
try:
    age = int(text)
except ValueError:
    print("请输入数字")
```

## textChanged 与 returnPressed 信号

**`textChanged(str)` 实时响应输入变化：**

```
edit.textChanged.connect(lambda text: print("当前：", text))
```

**每敲一个键都触发一次。** 第 3 课讲过这个信号。

**`returnPressed` 是按下回车时触发：**

```
edit.returnPressed.connect(lambda: print("回车确认：", edit.text()))
```

**常用于搜索框、聊天输入框**：按回车提交，而不是点按钮。

**`editingFinished` 是输入框失去焦点时触发：**

```
edit.editingFinished.connect(lambda: print("编辑结束"))
```

**适合做"输入完离开时校验"的场景。**

## 三个控件组合：登录小界面

**把今天学的全用上：**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QLabel, QLineEdit, QPushButton,
    QFormLayout, QVBoxLayout, QHBoxLayout
)
from PySide6.QtCore import Qt

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("登录")

user_edit = QLineEdit()
user_edit.setPlaceholderText("请输入用户名")
pass_edit = QLineEdit()
pass_edit.setPlaceholderText("请输入密码")
pass_edit.setEchoMode(QLineEdit.EchoMode.Password)

tip_label = QLabel("请输入用户名和密码")
tip_label.setStyleSheet("color: gray;")

def on_login():
    u = user_edit.text()
    p = pass_edit.text()
    if u and p:
        tip_label.setText(f"登录中：{u}")
        tip_label.setStyleSheet("color: green;")
    else:
        tip_label.setText("用户名和密码不能为空")
        tip_label.setStyleSheet("color: red;")

login_btn = QPushButton("登录")
login_btn.setDefault(True)
login_btn.clicked.connect(on_login)

form = QFormLayout()
form.addRow("用户名：", user_edit)
form.addRow("密码：", pass_edit)

btn_bar = QHBoxLayout()
btn_bar.addStretch()
btn_bar.addWidget(login_btn)

main = QVBoxLayout(window)
main.addLayout(form)
main.addWidget(tip_label)
main.addLayout(btn_bar)

window.resize(320, 160)
window.show()
app.exec()
```

**`setStyleSheet` 动态改文字颜色**，做表单校验提示很方便。

## 小结

- QLabel：setText/getText、setWordWrap、setAlignment、setPixmap
- 换行后标签高度不更新，检查 sizePolicy 垂直方向
- QPushButton：setIcon、setEnabled、setDefault、setCheckable
- setCheckable(True) 后按钮变开关，toggled 信号带 bool
- QLineEdit：placeholderText 提示、maxLength 限长、readOnly 只读
- text() 返回字符串，要数字得 int() 并捕获 ValueError
- textChanged 实时、returnPressed 回车、editingFinished 失焦
