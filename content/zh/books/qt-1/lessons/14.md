# QListWidget 与 QTableWidget

> 列表和表格是 GUI 里最常见的数据展示方式。这一课讲两个"Item-based"控件：QListWidget 管一维列表，QTableWidget 管二维表格。它们的 API 几乎一模一样，学会一个另一个秒懂。

## QListWidget：一维列表

**QListWidget 是列表控件，每一行是一个 QListWidgetItem。**

```
from PySide6.QtWidgets import QListWidget, QListWidgetItem

list_widget = QListWidget()
list_widget.addItem("苹果")
list_widget.addItem("香蕉")
list_widget.addItem("橙子")
```

**`addItem(text)` 加一行文本，`addItems(list)` 一次加多行：**

```
fruits = ["苹果", "香蕉", "橙子", "葡萄", "西瓜"]
list_widget.addItems(fruits)
```

**`QListWidgetItem` 是列表项对象，可以携带额外数据：**

```
item = QListWidgetItem("苹果")
item.setData(1, "apple")       # 角色 1 = UserRole，存一个标识
list_widget.addItem(item)

# 读取
current = list_widget.currentItem()
if current:
    print(current.text())           # "苹果"
    print(current.data(1))          # "apple"
```

**`currentItemChanged` 信号在选中项变化时触发：**

```
list_widget.currentItemChanged.connect(
    lambda current, previous: print("选中：", current.text() if current else "无")
)
```

**`itemClicked` 信号在单击某一项时触发，参数是被点击的 item：**

```
list_widget.itemClicked.connect(lambda item: print("点击了：", item.text()))
```

## 翻车现场一：忘记设置选择模式，以为可以多选

**症状：按住 Ctrl 想多选，结果只能选一个。**

```
list_widget = QListWidget()
list_widget.addItems(["A", "B", "C"])
# 默认 selectionMode 是 SingleSelection，只能单选
```

**解决：设置选择模式为 `ExtendedSelection`：**

```
from PySide6.QtWidgets import QAbstractItemView

list_widget.setSelectionMode(QAbstractItemView.ExtendedSelection)
# 现在可以 Ctrl+点击多选、Shift+点击连选
```

**常用选择模式：**
- `SingleSelection`：只能选一个（默认）
- `MultiSelection`：点击切换选中状态
- `ExtendedSelection`：Ctrl/Shift 多选（最常用）
- `NoSelection`：不可选择

## QListWidget 的增删改查

**增加行：**

```
list_widget.addItem("新水果")              # 追加到末尾
list_widget.insertItem(0, "最前面")        # 插到索引 0
```

**删除选中行：**

```
def remove_selected():
    row = list_widget.currentRow()
    if row >= 0:
        list_widget.takeItem(row)          # takeItem 移除并返回 item

remove_btn.clicked.connect(remove_selected)
```

**`takeItem(row)` 移除指定行并返回 QListWidgetItem 对象。** 注意：它不是 `deleteItem`，Qt 不会自动释放内存。

**修改某行文本：**

```
item = list_widget.item(0)                 # 拿到第 0 行
if item:
    item.setText("修改过的文本")
```

**遍历所有行：**

```
for i in range(list_widget.count()):
    item = list_widget.item(i)
    print(f"第 {i} 行：{item.text()}")
```

## QTableWidget：二维表格

**QTableWidget 是表格控件，有行有列。每一格是一个 QTableWidgetItem。**

**⚠️ 经典坑：用 QTableWidget 之前必须设置列数，否则数据根本显示不出来！**

```
from PySide6.QtWidgets import QTableWidget, QTableWidgetItem

table = QTableWidget()

# ❌ 错误写法：没设列数就直接设数据
table.setItem(0, 0, QTableWidgetItem("张三"))
table.setItem(0, 1, QTableWidgetItem("25"))
# 运行后表格是空的，什么都不显示，也没有报错！
```

**✅ 正确写法：先设行数、列数，再设表头：**

```
table = QTableWidget()
table.setColumnCount(3)                              # 必须！设 3 列
table.setHorizontalHeaderLabels(["姓名", "年龄", "城市"])  # 设表头
table.setRowCount(3)                                 # 设 3 行

table.setItem(0, 0, QTableWidgetItem("张三"))
table.setItem(0, 1, QTableWidgetItem("25"))
table.setItem(0, 2, QTableWidgetItem("北京"))

table.setItem(1, 0, QTableWidgetItem("李四"))
table.setItem(1, 1, QTableWidgetItem("30"))
table.setItem(1, 2, QTableWidgetItem("上海"))

table.setItem(2, 0, QTableWidgetItem("王五"))
table.setItem(2, 1, QTableWidgetItem("28"))
table.setItem(2, 2, QTableWidgetItem("广州"))
```

**`setColumnCount(n)` 设列数，`setRowCount(n)` 设行数，`setHorizontalHeaderLabels(list)` 设表头文字。**

**顺序不能乱：先设列数 → 再设表头 → 最后填数据。** 如果先 `setItem` 再 `setColumnCount`，数据可能还在（取决于版本），但表头必须放在 `setColumnCount` 之后，否则不显示。

## 翻车现场二：setHorizontalHeaderLabels 放在 setColumnCount 之前

**症状：表头文字不显示，表格顶部一片空白。**

```
table = QTableWidget()
table.setHorizontalHeaderLabels(["姓名", "年龄", "城市"])  # ❌ 先设表头
table.setColumnCount(3)                                   # 后设列数
table.setItem(0, 0, QTableWidgetItem("张三"))
# 运行后表头不显示
```

**原因：`setColumnCount` 会重置表头。** 调用 `setColumnCount(3)` 时，Qt 会重建水平表头模型，之前通过 `setHorizontalHeaderLabels` 设置的标签被清空。

**✅ 正确顺序：**

```
table.setColumnCount(3)                              # 先设列数
table.setHorizontalHeaderLabels(["姓名", "年龄", "城市"])  # 再设表头
table.setItem(0, 0, QTableWidgetItem("张三"))          # 最后填数据
```

## 表格的增删改查

**动态添加一行：**

```
def add_row():
    row = table.rowCount()                # 当前行数
    table.insertRow(row)                  # 在末尾插入新行
    table.setItem(row, 0, QTableWidgetItem(f"新人{row}"))
    table.setItem(row, 1, QTableWidgetItem("20"))
    table.setItem(row, 2, QTableWidgetItem("未知"))

add_btn.clicked.connect(add_row)
```

**删除选中行：**

```
def remove_row():
    current_row = table.currentRow()
    if current_row >= 0:
        table.removeRow(current_row)

remove_btn.clicked.connect(remove_row)
```

**读取整行数据：**

```
def read_row(row):
    data = []
    for col in range(table.columnCount()):
        item = table.item(row, col)
        data.append(item.text() if item else "")
    return data

print(read_row(0))    # ["张三", "25", "北京"]
```

**`table.item(row, col)` 可能返回 None！** 如果那个格子没被 `setItem` 过，`item()` 返回 None，直接调 `.text()` 会崩溃。

## 表格信号

**单元格内容变化：`cellChanged(row, col)`**

```
table.cellChanged.connect(
    lambda row, col: print(f"第 {row} 行第 {col} 列变了")
)
```

**注意：`setItem` 设置数据也会触发 `cellChanged`！** 如果要在代码里批量填数据又不触发信号，用 `blockSignals`：

```
table.blockSignals(True)
table.setItem(0, 0, QTableWidgetItem("新值"))
table.blockSignals(False)
```

**选中行变化：`currentCellChanged`**

```
table.currentCellChanged.connect(
    lambda row, col, prev_row, prev_col: print(f"移动到第 {row} 行")
)
```

## 完整示例：学生信息管理

**列表展示 + 表格增删改 + 搜索过滤：**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QTableWidget, QTableWidgetItem,
    QPushButton, QLineEdit, QVBoxLayout, QHBoxLayout, QLabel
)

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("学生管理")
window.resize(500, 400)

table = QTableWidget()
table.setColumnCount(3)
table.setHorizontalHeaderLabels(["姓名", "年龄", "成绩"])
table.setRowCount(0)

# 输入区
name_edit = QLineEdit()
name_edit.setPlaceholderText("姓名")
age_edit = QLineEdit()
age_edit.setPlaceholderText("年龄")
score_edit = QLineEdit()
score_edit.setPlaceholderText("成绩")

# 按钮
add_btn = QPushButton("添加")
del_btn = QPushButton("删除选中行")
search_edit = QLineEdit()
search_edit.setPlaceholderText("搜索姓名...")

def add_student():
    row = table.rowCount()
    table.insertRow(row)
    table.setItem(row, 0, QTableWidgetItem(name_edit.text()))
    table.setItem(row, 1, QTableWidgetItem(age_edit.text()))
    table.setItem(row, 2, QTableWidgetItem(score_edit.text()))
    name_edit.clear()
    age_edit.clear()
    score_edit.clear()

def delete_student():
    row = table.currentRow()
    if row >= 0:
        table.removeRow(row)

def search():
    keyword = search_edit.text().lower()
    for row in range(table.rowCount()):
        item = table.item(row, 0)
        match = item and keyword in item.text().lower()
        table.setRowHidden(row, not match)    # 不匹配的行隐藏

add_btn.clicked.connect(add_student)
del_btn.clicked.connect(delete_student)
search_edit.textChanged.connect(search)

# 布局
input_layout = QHBoxLayout()
input_layout.addWidget(name_edit)
input_layout.addWidget(age_edit)
input_layout.addWidget(score_edit)
input_layout.addWidget(add_btn)

btn_layout = QHBoxLayout()
btn_layout.addWidget(del_btn)
btn_layout.addWidget(QLabel("搜索："))
btn_layout.addWidget(search_edit)

main = QVBoxLayout(window)
main.addLayout(input_layout)
main.addLayout(btn_layout)
main.addWidget(table)

window.show()
app.exec()
```

**`setRowHidden(row, True/False)` 可以隐藏指定行——做搜索过滤就靠它。**

## 小结

- QListWidget：一维列表，addItem/addItems 加数据，currentItemChanged 监听选择
- 多选要设 selectionMode 为 ExtendedSelection
- 增删改查：addItem/insertItem/takeItem/setItem + item(row) 读取
- QTableWidget：二维表格，必须先 setColumnCount + setHorizontalHeaderLabels
- ⚠️ 经典坑：不设列数数据不显示；setHorizontalHeaderLabels 必须在 setColumnCount 之后
- table.item(row, col) 可能返回 None，访问前先判断
- setRowHidden 做搜索过滤，blockSignals 避免代码改数据触发信号
