# QGridLayout：行列网格布局

> 计算器界面、登录表单、参数设置页——这些"格子状"的界面用 QGridLayout 最合适。它按行和列摆控件，还能让一个控件跨多行多列。这一课讲清参数顺序，以及最常见的参数写错导致控件堆一起的翻车现场。

## 基本用法：行、列、控件

**`addWidget(widget, row, column)`：把控件放到第 row 行、第 column 列。**

**行列从 0 开始计数。**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QPushButton, QGridLayout
)

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("计算器")

layout = QGridLayout(window)

layout.addWidget(QPushButton("1"), 0, 0)
layout.addWidget(QPushButton("2"), 0, 1)
layout.addWidget(QPushButton("3"), 0, 2)
layout.addWidget(QPushButton("4"), 1, 0)
layout.addWidget(QPushButton("5"), 1, 1)
layout.addWidget(QPushButton("6"), 1, 2)

window.resize(300, 200)
window.show()
app.exec()
```

**效果：两行三列的数字键盘。**

**表格对照：**

| 行\列 | 0 | 1 | 2 |
|---|---|---|---|
| 0 | 1 | 2 | 3 |
| 1 | 4 | 5 | 6 |

**空的格子会被保留为空白。** 如果你跳着放控件（比如只放 (0,0)、(1,2)），中间的格子会空着但不会坍塌。

## 跨行跨列：rowSpan 和 columnSpan

**`addWidget(widget, row, column, rowSpan, columnSpan)` 后面两个参数控制跨几行几列。**

```
layout = QGridLayout(window)

layout.addWidget(QPushButton("0"), 0, 0)          # 第 0 行第 0 列
layout.addWidget(QPushButton("跨两列"), 0, 1, 1, 2)  # 占第 0 行、第 1~2 列
layout.addWidget(QPushButton("1"), 1, 0)
layout.addWidget(QPushButton("2"), 1, 1)
layout.addWidget(QPushButton("3"), 1, 2)
```

**`rowSpan=1, columnSpan=2` 表示这个按钮横跨两列。** 计算器里"0"键常常占两格宽，就是这么做的。

**一个更完整的计算器示例（"0"占两格、"="占两行）：**

```
layout = QGridLayout(window)

buttons = [
    ("7", 0, 0), ("8", 0, 1), ("9", 0, 2), ("/", 0, 3),
    ("4", 1, 0), ("5", 1, 1), ("6", 1, 2), ("*", 1, 3),
    ("1", 2, 0), ("2", 2, 1), ("3", 2, 2), ("-", 2, 3),
    ("0", 3, 0, 1, 2), ("=", 3, 2, 1, 2),  # 简化：0 占两列
]

for btn in buttons:
    if len(btn) == 4:
        text, r, c, rs, cs = btn
        layout.addWidget(QPushButton(text), r, c, rs, cs)
    else:
        text, r, c = btn
        layout.addWidget(QPushButton(text), r, c)

# 上面 buttons 元组结构不一致，下面给一个更清晰的版本
```

**更清晰的写法：**

```
layout = QGridLayout(window)

# 普通按钮：文本, 行, 列
normal = [
    ("7", 0, 0), ("8", 0, 1), ("9", 0, 2),
    ("4", 1, 0), ("5", 1, 1), ("6", 1, 2),
    ("1", 2, 0), ("2", 2, 1), ("3", 2, 2),
]
for text, r, c in normal:
    layout.addWidget(QPushButton(text), r, c)

# 特殊按钮：占多格
layout.addWidget(QPushButton("0"), 3, 0, 1, 2)    # 0 占两列
layout.addWidget(QPushButton("="), 3, 2, 1, 2)    # = 占右边两列
```

## 翻车现场一：参数顺序写错，控件全堆在左上角

**这是本课的头号翻车点。**

**症状：明明放了六个按钮，运行后只看到一两个，其余都叠在一起。**

```
layout.addWidget(0, 0, QPushButton("1"))   # 错误：把参数顺序写反了！
```

**报错信息：`TypeError: addWidget(self, QWidget, ...): argument 1 has unexpected type 'int'`**。因为 Qt 期望第一个参数是 QWidget，你传了个 int 0。

**但更隐蔽的错误是没有报错、只是显示不对：**

```
layout.addWidget(QPushButton("1"), 0, 0)
layout.addWidget(QPushButton("2"), 0, 1)
layout.addWidget(QPushButton("3"), 1, 0)
layout.addWidget(QPushButton("4"), 1, 1)
layout.addWidget(QPushButton("5"), 1, 1)   # 写错行号！和 4 重叠
layout.addWidget(QPushButton("6"), 1, 1)   # 又错！三个叠一起
```

**症状：按钮 4、5、6 叠在同一个格子里，只看到最后一个。** 不报错，因为语法完全合法。

**原因：行号列号写错或重复了。** 尤其从 0 开始数容易数错。

**解决：写之前先画网格，标好行列号再写代码。** 或者用一个二维列表生成：

```
grid = [
    ["7", "8", "9"],
    ["4", "5", "6"],
    ["1", "2", "3"],
]
for r, row in enumerate(grid):
    for c, text in enumerate(row):
        layout.addWidget(QPushButton(text), r, c)
```

**用 enumerate 自动生成行列号，永远不会数错。**

## 翻车现场二：跨列参数写错，格子被撑破

**症状：按钮跨了不该跨的列，界面错乱。**

```
layout.addWidget(QPushButton("0"), 3, 0, 1, 3)   # 本想跨 2 列，写成 3
```

**原因：`columnSpan=3` 意味着从列 0 开始占 3 列（0、1、2），这没问题；但如果后面还有控件被放到第 3 行第 1 列，就会被挤走。**

**更常见的错是跨度算错导致覆盖：**

```
layout.addWidget(QPushButton("宽按钮"), 0, 0, 1, 2)   # 占第 0 行 0、1 列
layout.addWidget(QPushButton("撞车"), 0, 1)            # 也放第 0 行第 1 列！
```

**撞车后两个控件重叠显示，后面的盖住前面的。**

**解决：跨列的控件，被它覆盖的格子不要再放别的控件。**

## setRowStretch 与 setColumnStretch

**`setColumnStretch(column, stretch)` 设置某列的拉伸因子。**

```
layout = QGridLayout(window)
layout.addWidget(QLabel("姓名"), 0, 0)
layout.addWidget(QLineEdit(), 0, 1)
layout.addWidget(QLabel("电话"), 1, 0)
layout.addWidget(QLineEdit(), 1, 1)

layout.setColumnStretch(1, 1)    # 第 1 列（输入框）拉伸
```

**效果：第 0 列（标签）保持最小宽度，第 1 列（输入框）吸收所有多余空间。**

**同理 `setRowStretch(row, stretch)` 设行的拉伸。**

**`setHorizontalSpacing` 和 `setVerticalSpacing` 分别设横向、纵向间距：**

```
layout.setHorizontalSpacing(10)
layout.setVerticalSpacing(4)
```

## 翻车现场三：只 addWidget 没给列设 stretch，输入框太窄

**症状：窗口拉得很宽，但输入框还是那么窄，右侧大片空白。**

```
layout = QGridLayout(window)
layout.addWidget(QLabel("搜索"), 0, 0)
layout.addWidget(QLineEdit(), 0, 1)
# 漏了 setColumnStretch(1, 1)
```

**原因：两列都是 stretch=0，都不拉伸。窗口多出来的空间谁都不吸收，全堆在右边。

**解决：`setColumnStretch(1, 1)` 让输入框那列吸收多余空间。**

## 完整例子：登录表单

**一个标准的两列表单界面：**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QLabel, QLineEdit,
    QPushButton, QGridLayout, QVBoxLayout
)
from PySide6.QtCore import Qt

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("登录")
window.resize(320, 200)

grid = QGridLayout()
grid.addWidget(QLabel("用户名"), 0, 0)
grid.addWidget(QLineEdit(), 0, 1)
grid.addWidget(QLabel("密码"), 1, 0)
grid.addWidget(QLineEdit(), 1, 1)
grid.addWidget(QLabel("验证码"), 2, 0)
grid.addWidget(QLineEdit(), 2, 1)

grid.setColumnStretch(1, 1)          # 输入框列拉伸
grid.setVerticalSpacing(8)

main = QVBoxLayout(window)
main.addLayout(grid)
main.addWidget(QPushButton("登录"), alignment=Qt.AlignmentFlag.AlignRight)

window.show()
app.exec()
```

**说明：网格布局负责两列对齐，外层纵向布局负责把按钮栏放下面。** 网格里标签列窄、输入列宽，拉伸时输入列变宽。

## 小结

- `addWidget(widget, row, column)` 按行列放控件，行列从 0 开始
- 参数顺序记牢：控件在前、行列在后
- `addWidget(widget, r, c, rowSpan, colSpan)` 跨行跨列
- **参数写错不报错但控件重叠**，是本课的翻车现场
- 用 enumerate 遍历二维列表，行列号永远不会数错
- setColumnStretch / setRowStretch 让某列某行吸收多余空间
- 表单界面常用"网格布局 + 外层纵向布局"组合
