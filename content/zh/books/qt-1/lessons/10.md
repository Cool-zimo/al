# 布局的伸缩：sizePolicy、setStretch 与 minimumSize

> 布局会把多余空间分配给控件，但"分配给谁、分多少"由伸缩机制决定。这一课讲三件控制伸缩的事：sizePolicy（控件自己说自己想怎么变）、setStretch（布局给控件分比例）、minimumSize / maximumSize（尺寸边界）。

## sizePolicy：控件自己报的"生长意愿"

**每个 QWidget 都有一个 QSizePolicy，描述它希望如何随布局伸缩。**

```
from PySide6.QtWidgets import QSizePolicy

widget.sizePolicy()                        # 读取
widget.setSizePolicy(
    QSizePolicy.Policy.Expanding,          # 水平方向
    QSizePolicy.Policy.Fixed               # 垂直方向
)
```

**水平 Expanding、垂直 Fixed：意思是"我在横向上尽量占满空间，纵向保持推荐大小不变"。**

**几种常用策略：**

| 策略 | 含义 |
|---|---|
| Fixed | 只用 sizeHint()，绝不改变 |
| Minimum | 不小于 sizeHint()，可以变大 |
| Maximum | 不大于 sizeHint()，可以变小 |
| Preferred | sizeHint() 是理想值，可大可小 |
| Expanding | 尽可能多占空间（有伸展意愿） |
| Ignored | 完全忽略 sizeHint()，占满为止 |

**记忆口诀：Expanding 最贪心，Fixed 最固执。**

## 一个例子：编辑区该占满剩余空间

**典型场景：上面几个输入框、下面一个大文本区。**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QLineEdit, QTextEdit, QVBoxLayout
)
from PySide6.QtWidgets import QSizePolicy

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("伸缩示例")

title_edit = QLineEdit()
title_edit.setSizePolicy(
    QSizePolicy.Policy.Preferred,      # 横向保持推荐宽度
    QSizePolicy.Policy.Fixed          # 纵向固定高度
)

body_edit = QTextEdit()
body_edit.setSizePolicy(
    QSizePolicy.Policy.Expanding,     # 横向尽量占满
    QSizePolicy.Policy.Expanding      # 纵向也尽量占满
)

layout = QVBoxLayout(window)
layout.addWidget(title_edit)
layout.addWidget(body_edit)

window.resize(400, 350)
window.show()
app.exec()
```

**效果：标题输入框保持一行高，下面的文本编辑区把剩余空间全占了。**

## 翻车现场一：控件死活不拉伸

**症状：窗口拉得很大，控件还是缩在左上角，像没设置过布局一样。**

**最常见的原因：控件的 sizePolicy 是 Fixed。**

```
body_edit.setSizePolicy(
    QSizePolicy.Policy.Fixed,     # 错了！固定尺寸，不拉伸
    QSizePolicy.Policy.Fixed
)
```

**解决：把水平或垂直方向改成 Expanding 或 MinimumExpanding。**

**另一个原因：布局本身没设 stretch。** 看下面 `setStretch` 的讲解。

## setStretch：布局给控件分比例

**`layout.setStretch(index, stretch)` 设置第 index 个控件的分空间比例。**

```
layout = QVBoxLayout(window)
layout.addWidget(top_widget)      # index 0
layout.addWidget(mid_widget)     # index 1
layout.addWidget(bot_widget)     # index 2

layout.setStretch(0, 1)
layout.setStretch(1, 2)
layout.setStretch(2, 1)
```

**效果：中间控件分到的是上下两控件的两倍空间。** 比例 1:2:1。

**`addWidget(widget, stretch)` 的第二个参数就是 stretch，一次写完更方便：**

```
layout.addWidget(top_widget, 1)
layout.addWidget(mid_widget, 2)
layout.addWidget(bot_widget, 1)
```

**stretch=0 表示不参与拉伸**，保持 sizeHint()。这也是为什么有时候"加了控件但窗口拉大它不变"——它的 stretch 是 0，sizePolicy 又不是 Expanding。

## 翻车现场二：stretch 设了但 sizePolicy 是 Fixed

**症状：setStretch 怎么设都不生效。**

```
widget.setSizePolicy(QSizePolicy.Policy.Fixed, QSizePolicy.Policy.Fixed)
layout.addWidget(widget, 10)     # 设了 10 倍拉伸也没用
```

**原因：stretch 是布局层面的分配意愿，但 sizePolicy 是控件层面的"接不接受"。控件说 Fixed，布局给它空间它也不要。**

**解决：两个要配合。布局 setStretch 分配，控件 sizePolicy 设为 Expanding 接收。**

## minimumSize 与 maximumSize

**`setMinimumSize(w, h)` 和 `setMaximumSize(w, h)` 给控件设尺寸边界。**

```
window.setMinimumSize(300, 200)   # 窗口最小 300×200
window.setMaximumSize(800, 600)   # 窗口最大 800×600
```

**窗口被限制在 300×200 到 800×600 之间，用户拖不出这个范围。**

**`setFixedSize(w, h)` 是最小最大都设为同一个值，窗口不可拉伸：**

```
window.setFixedSize(400, 300)
```

**对单个控件也一样：**

```
btn.setMinimumWidth(120)          # 按钮最小宽 120
btn.setMaximumWidth(200)
```

**`sizeHint()` 返回控件的"推荐大小"，布局默认按它分配空间：**

```
print(btn.sizeHint())            # PyQt6/PySide6: QSize(...)
```

**sizeHint 由控件内容决定**：按钮的 sizeHint 取决于它的文本长度加边距。

## minimumSizeHint 与 sizeHint 的区别

**两个概念容易混：**

- **sizeHint()**：推荐大小，布局用它做初始分配依据。
- **minimumSizeHint()**：最小合理大小，控件小到这个尺寸还能正常使用。

**大多数情况下你只需要关心 sizeHint 和 setMinimumSize。**

## 翻车现场三：用 setFixedSize 后又想让用户拉伸

**症状：设了固定尺寸后窗口无法拉伸，用户抱怨。**

```
window.setFixedSize(400, 300)
# 后来需求变了，想让用户拉伸
```

**解决：改成 setMinimumSize + setMaximumSize，或者干脆去掉固定尺寸：**

```
window.setMinimumSize(300, 200)
# 不设 maximumSize，让窗口可以自由拉大
```

**只在确实需要固定尺寸的窗口（如计算器、小工具）才用 setFixedSize。**

## 一个综合示例：三栏布局

**左侧导航、中间内容、右侧属性面板，比例 1:3:1：**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QLabel, QHBoxLayout
)
from PySide6.QtWidgets import QSizePolicy
from PySide6.QtCore import Qt

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("三栏")
window.resize(800, 500)

nav = QLabel("导航")
nav.setAlignment(Qt.AlignmentFlag.AlignCenter)
nav.setStyleSheet("background: #e0e0e0;")

content = QLabel("内容区")
content.setAlignment(Qt.AlignmentFlag.AlignCenter)

props = QLabel("属性")
props.setAlignment(Qt.AlignmentFlag.AlignCenter)
props.setStyleSheet("background: #f0f0f0;")

layout = QHBoxLayout(window)
layout.addWidget(nav, 1)
layout.addWidget(content, 3)
layout.addWidget(props, 1)

window.show()
app.exec()
```

**`addWidget(nav, 1)`、`addWidget(content, 3)`、`addWidget(props, 1)`** 直接写出 1:3:1 的比例。这就是 stretch 参数版的写法。

**窗口拉伸时，三栏按 1:3:1 一起变宽。**

## 小结

- sizePolicy 是控件自己报的"生长意愿"：Expanding 最贪心、Fixed 最固执
- setStretch(index, n) 或 addWidget(widget, n) 让布局按比例为控件分空间
- stretch 和 sizePolicy 要配合：布局分、控件接
- setMinimumSize / setMaximumSize 设尺寸边界
- setFixedSize 让窗口不可拉伸，只适合小工具
- sizeHint() 是推荐大小，minimumSizeHint() 是最小合理大小
- 三栏 1:3:1 用 addWidget 的 stretch 参数一次写完
