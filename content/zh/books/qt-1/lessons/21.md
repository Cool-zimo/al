# QSS 样式表入门

> QSS（Qt Style Sheets）是 Qt 的样式语言，语法和 CSS 像到几乎一样。这一课讲怎么用 QSS 美化界面，以及它和 CSS 到底差在哪。

## QSS 和 CSS 像在哪

**QSS 语法就是 CSS 的翻版：选择器 + 属性 + 值。**

```
QPushButton {
    background-color: #3498db;
    color: white;
    border: none;
    border-radius: 6px;
    padding: 8px 16px;
    font-size: 14px;
}
```

**作用方式也一样，用 `setStyleSheet` 应用：**

```
btn = QPushButton("点击")
btn.setStyleSheet("""
    QPushButton {
        background-color: #3498db;
        color: white;
        border-radius: 6px;
        padding: 8px 16px;
    }
""")
```

**QSS 和 CSS 的共同点：都支持颜色、边框、圆角、字体、padding/margin、背景渐变，都支持子控件和伪状态。** 会 CSS 的人 80% 的语法直接能搬过来。

## 选择器语法

**最常用的是类型选择器：控件类名直接当标签名。**

```
QPushButton { color: white; }      # 所有 QPushButton
QLineEdit { border: 1px solid gray; }
QWidget { background: #f0f0f0; }
```

**类选择器用 `.ClassName`，只匹配该类本身，不匹配子类。**

```
.QPushButton { color: red; }       # 只匹配 QPushButton，不匹配它的子类
```

**ID 选择器用 `#objectName`，精确匹配某个控件。**

```
#title_label {
    font-size: 24px;
    font-weight: bold;
    color: #2c3e50;
}
```

**前提是先设 objectName：**

```
label.setObjectName("title_label")
```

**后代选择器：空格分隔，匹配嵌套关系。**

```
QGroupBox QPushButton {
    background-color: green;
}
```

**只影响 QGroupBox 里的 QPushButton，外面的不受影响。** 做分组内按钮统一样式很好用。

## 翻车现场一：选择器写错控件名，样式完全不生效

**症状：写了一大段 QSS，运行后界面纹丝不动，跟没写一样。**

```
btn.setStyleSheet("""
    PushButton {            # ❌ 控件名写错了
        background-color: red;
    }
""")
```

**原因：QSS 的控件名必须和 PySide6 的类名完全一致，包括大小写：`QPushButton`、`QLineEdit`、`QMainWindow`。** 写成 `PushButton`、`qpushbutton`、`Button` 都是无效选择器，而且不会报错，静默失败。

**✅ 正确写法：**

```
btn.setStyleSheet("""
    QPushButton {
        background-color: red;
    }
""")
```

**另一个高频错误是漏了分号或用了 `=` 号：QSS 是 CSS 语法，属性用 `:` 分隔，结尾必须 `;`。** 写 `background-color = red` 或漏掉 `;` 都会让整条规则失效。

## QSS 和 CSS 差在哪

**差异一：QSS 有"子控件"概念，CSS 没有。** Qt 的复杂控件由多个子部件组成，用 `::` 访问：

```
QComboBox::drop-down {
    border: none;
    width: 20px;
}

QScrollBar::handle {
    background: #888;
    border-radius: 4px;
}

QCheckBox::indicator {
    width: 16px;
    height: 16px;
}
```

**差异二：QSS 有"伪状态"，但写法和 CSS 的 `:hover` 一样，是 `:`。**

```
QPushButton:hover {
    background-color: #2980b9;
}

QPushButton:pressed {
    background-color: #1f6391;
}

QLineEdit:focus {
    border: 2px solid #3498db;
}
```

**差异三：QSS 不支持 CSS 的一些现代特性。** 没有 flex 布局、grid 布局、CSS 变量、`:nth-child` 复杂选择器、`transform` 动画。Qt 的布局由 Layout 系统管理，QSS 只负责"长什么样"。

**差异四：盒模型不同。** QSS 的盒模型是 `margin → border → padding → content`，和 CSS 基本一致，但 `width/height` 在 QSS 里作用于整个控件外框，不能像 CSS 那样轻易控制尺寸（因为 Qt 布局会重算）。

## 全局样式与局部样式

**给整个应用设一套样式：**

```
app = QApplication(sys.argv)
app.setStyleSheet("""
    QWidget {
        font-family: "Microsoft YaHei";
        font-size: 13px;
    }
    QPushButton {
        background-color: #3498db;
        color: white;
        border-radius: 4px;
        padding: 6px 12px;
    }
    QPushButton:hover {
        background-color: #2980b9;
    }
""")
```

**作用域规则：父控件设的样式会继承给子控件，子控件自己的样式优先级更高。**

```
window.setStyleSheet("QWidget { background: white; }")
btn.setStyleSheet("QPushButton { background: red; }")    # 这个按钮不受影响，自己的优先
```

**`QWidget { background: ... }` 会把它下面所有子控件的背景都改掉。** 想只改窗口背景，用 `#objectName` 精确指定。

## 小结

- QSS 语法和 CSS 几乎一样：选择器 { 属性: 值; }
- 选择器：类型 `QPushButton`、类 `.ClassName`、ID `#objectName`、后代空格
- ⚠️ 经典坑：控件名大小写写错（如 PushButton）样式静默不生效；属性必须用 `:` 和 `;`
- QSS 独有子控件 `::drop-down`、伪状态 `:hover/:pressed/:focus`
- QSS 不支持 flex/grid/CSS 变量/transform
- 全局用 app.setStyleSheet，局部用 widget.setStyleSheet，子控件优先
