# QFormLayout 与嵌套布局

> 表单界面（标签 + 输入框成对出现）在 QGridLayout 里也能做，但 Qt 专门提供了一个 QFormLayout，语义更清晰、还能自动适配宽窄屏。这一课讲 QFormLayout，再讲布局嵌套——把多个小布局拼成一个完整界面。

## QFormLayout：专门给表单用的布局

**表单的本质是"标签 + 控件"成对出现。** QFormLayout 就是为这个场景设计的：

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QLabel, QLineEdit, QPushButton, QFormLayout
)

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("注册")
window.resize(360, 200)

form = QFormLayout(window)

form.addRow("用户名：", QLineEdit())
form.addRow("密码：", QLineEdit())
form.addRow("确认密码：", QLineEdit())
form.addRow("邮箱：", QLineEdit())

window.show()
app.exec()
```

**`addRow(label_text, widget)` 一次加一行：左边标签、右边控件。** 标签可以是字符串，也可以是 QLabel 对象。

**效果：四行表单，标签右对齐、输入框左对齐，行列整齐。**

## addRow 的三种用法

**用法一：字符串 + 控件（最常用）**

```
form.addRow("姓名：", QLineEdit())
```

**Qt 会自动帮你创建一个 QLabel**，文本就是那个字符串，还会自动设置 `buddy`（后面讲）。

**用法二：QLabel + 控件（需要特殊设置时用）**

```
label = QLabel("密码：")
label.setStyleSheet("color: red;")
form.addRow(label, QLineEdit())
```

**想要给标签加样式、改字体、设 tooltip，就得自己创建 QLabel。**

**用法三：只放一个控件（跨两列）**

```
form.addRow(QLabel("这是一行说明文字，跨两列"))
form.addRow("地址：", QLineEdit())
```

**只传一个控件时，它会横跨标签列和控件列。** 常用来放提示文字、分隔说明。

## buddy：按 Alt 键快速跳转

**buddy 是 QLabel 的一个功能：给标签设快捷键，按 Alt+字母 焦点跳到对应输入框。**

```
name_label = QLabel("用户名(&U)：")    # &U 表示 Alt+U
name_edit = QLineEdit()
name_label.setBuddy(name_edit)        # 设 buddy
form.addRow(name_label, name_edit)
```

**`&U` 里的 `&` 是助记符标记**，界面上显示时 U 会带下划线。按 Alt+U 焦点跳到 name_edit。

**用字符串版 addRow 时 Qt 会自动处理 & 标记：**

```
form.addRow("用户名(&U)：", QLineEdit())   # Qt 自动创建 QLabel 并设 buddy
```

**注意：中文界面用拼音首字母做助记符，比如"姓名(&X)"对应 Alt+X。**

## 翻车现场一：标签冒号写成全角，对齐看着别扭

**症状：有的标签对齐整齐，有的歪了。**

```
form.addRow("用户名:", QLineEdit())    # 半角冒号
form.addRow("密码：", QLineEdit())    # 全角冒号
```

**原因：全角冒号"："占两个半角宽度，导致标签文本长度不一致，右对齐后参差不齐。**

**解决：统一用半角冒号 `:`，或者在标签前补空格手动对齐。** 更专业的做法是给标签设固定宽度：

```
label.setFixedWidth(80)
```

## 翻车现场二：addRow 参数顺序写反

**症状：输入框在左边、标签在右边，或者报错。**

```
form.addRow(QLineEdit(), "用户名")   # 错误：控件在前、标签在后
```

**报错信息：`TypeError: addRow(self, QLabel, QWidget): argument 1 has unexpected type 'QLineEdit'`**

**原因：addRow 第一个参数是标签（str 或 QLabel），第二个才是控件。**

**解决：记牢"标签在前、控件在后"。**

## 嵌套布局：把多个小布局拼成一个界面

**真实软件界面从来不是单一布局。** 标准套路是：外层一个 QVBoxLayout，里面套 QFormLayout、QHBoxLayout 等。

**一个完整的"设置对话框"：**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QLabel, QLineEdit, QPushButton,
    QFormLayout, QVBoxLayout, QHBoxLayout
)
from PySide6.QtCore import Qt

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("系统设置")
window.resize(400, 250)

# 中间：表单区
form = QFormLayout()
form.addRow("服务器地址：", QLineEdit())
form.addRow("端口：", QLineEdit())
form.addRow("用户名：", QLineEdit())
form.addRow("超时（秒）：", QLineEdit())

# 底部：按钮栏（右对齐）
btn_bar = QHBoxLayout()
btn_bar.addStretch()
btn_bar.addWidget(QPushButton("取消"))
btn_bar.addWidget(QPushButton("确定"))

# 外层纵向布局
main = QVBoxLayout(window)
main.addLayout(form)
main.addLayout(btn_bar)

window.show()
app.exec()
```

**三层结构：外层 QVBoxLayout → 里层 QFormLayout（表单）+ QHBoxLayout（按钮栏）。**

**按钮栏先加弹簧再放按钮，按钮就靠右了——第 7 课的口诀。**

## 翻车现场三：嵌套时用了 addWidget 而不是 addLayout

**症状：报错，说布局不是 QWidget。**

```
main = QVBoxLayout(window)
main.addLayout(form)      # 正确
main.addLayout(btn_bar)   # 正确
main.addWidget(form)      # 错误！form 是布局不是控件
```

**报错信息：`QBoxLayout::addWidget: Cannot add a layout to a layout`**

**解决：往布局里加子布局用 `addLayout`，加控件用 `addWidget`。第 7 课讲过，这里再强调一次，因为它太常见了。**

## QFormLayout 的几个实用设置

**`setLabelAlignment` 设标签对齐方式：**

```
form.setLabelAlignment(Qt.AlignmentFlag.AlignRight)   # 标签右对齐
```

**默认就是右对齐，但有时被外层布局影响，显式设一次更稳。**

**`setSpacing` 和 `setContentsMargins` 同样适用：**

```
form.setSpacing(10)
form.setContentsMargins(12, 12, 12, 12)
```

**`setFieldGrowthPolicy` 控制输入控件如何生长：**

```
form.setFieldGrowthPolicy(QFormLayout.FieldGrowthPolicy.ExpandingFieldsGrow)
```

**`ExpandingFieldsGrow` 是默认策略**：输入框会随窗口拉伸。另有 `AllNonFixedFieldsGrow`、`FieldsStayAtSizeHint` 可选。

## 翻车现场四：表单拉伸时标签也被拉宽了

**症状：窗口拉宽后，标签列也变宽，标签文字和输入框之间距离越来越大。**

**原因：默认策略下标签列和输入列都参与拉伸。**

**解决：给标签设固定宽度，让输入列独占拉伸：**

```
for i in range(form.rowCount()):
    label = form.itemAt(i, QFormLayout.ItemRole.LabelRole).widget()
    if isinstance(label, QLabel):
        label.setFixedWidth(80)
```

**或者用 `setFieldGrowthPolicy(QFormLayout.FieldGrowthPolicy.FieldsStayAtSizeHint)`** 限制输入列的生长，再用 `setHorizontalSpacing` 控制间距。

## 完整例子：登录窗口

**把第 8、9 课学到的组合起来：**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QLabel, QLineEdit, QPushButton,
    QFormLayout, QVBoxLayout, QHBoxLayout
)
from PySide6.QtCore import Qt

class LoginWindow(QWidget):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("登录")
        self.resize(340, 180)

        self.user_edit = QLineEdit()
        self.pass_edit = QLineEdit()
        self.pass_edit.setEchoMode(QLineEdit.EchoMode.Password)

        form = QFormLayout()
        form.addRow("用户名(&U)：", self.user_edit)
        form.addRow("密码(&P)：", self.pass_edit)
        form.setLabelAlignment(Qt.AlignmentFlag.AlignRight)

        btn_bar = QHBoxLayout()
        btn_bar.addStretch()
        login_btn = QPushButton("登录")
        login_btn.clicked.connect(self.on_login)
        btn_bar.addWidget(login_btn)
        btn_bar.addWidget(QPushButton("取消"))

        main = QVBoxLayout(self)
        main.addLayout(form)
        main.addLayout(btn_bar)

    def on_login(self):
        print("用户名：", self.user_edit.text())
        print("密码：", self.pass_edit.text())

app = QApplication(sys.argv)
window = LoginWindow()
window.show()
app.exec()
```

**`setEchoMode(QLineEdit.EchoMode.Password)` 让密码框显示为圆点。** 这是密码框的标准做法。

**`self.user_edit.text()` 拿到输入框的当前文本。** 后面第 11 课会细讲 QLineEdit。

## 小结

- QFormLayout 专为表单设计：addRow(标签, 控件)
- 标签可以是字符串（Qt 自动建 QLabel）或 QLabel 对象
- 只传一个控件时横跨两列，适合放说明文字
- `&X` 助记符 + setBuddy 实现 Alt+X 跳转
- 嵌套布局：外层 QVBoxLayout，里层套各种子布局
- 加子布局用 addLayout，加控件用 addWidget，别混用
- setFieldGrowthPolicy 控制输入列如何随窗口拉伸
