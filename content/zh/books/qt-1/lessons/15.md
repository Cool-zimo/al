# QSlider、QSpinBox 与 QProgressBar

> 数值输入和进度反馈是 GUI 的标配。QSlider 是拖动条、QSpinBox 是数字输入框、QProgressBar 是进度条——三者联动起来，就是信号槽最经典的应用场景。

## QSlider：拖动条

**QSlider 是滑块控件，拖动它来改变一个整数值。**

```
from PySide6.QtWidgets import QSlider
from PySide6.QtCore import Qt

slider = QSlider(Qt.Horizontal)    # 水平方向
slider.setMinimum(0)               # 最小值
slider.setMaximum(100)            # 最大值
slider.setValue(50)               # 当前值
print(slider.value())             # 50
```

**`Qt.Horizontal` 是水平滑块，`Qt.Vertical` 是竖直滑块。**

**`valueChanged(int)` 信号在值变化时触发：**

```
slider.valueChanged.connect(lambda val: print("当前值：", val))
```

**也可以一步设范围：**

```
slider.setRange(0, 255)    # 等价于 setMinimum(0) + setMaximum(255)
```

**`setTickPosition` 显示刻度：**

```
slider.setTickPosition(QSlider.TicksBelow)    # 刻度在下方
slider.setTickInterval(10)                     # 每隔 10 一个刻度
```

## 翻车现场一：信号循环触发导致死循环

**症状：拖动滑块 → 更新 SpinBox → SpinBox 的值变化信号又更新滑块 → 无限循环。**

```
slider = QSlider(Qt.Horizontal)
slider.setRange(0, 100)
spin = QSpinBox()
spin.setRange(0, 100)

# ❌ 双向连接，可能递归
slider.valueChanged.connect(lambda v: spin.setValue(v))   # 滑块→数字框
spin.valueChanged.connect(lambda v: slider.setValue(v))    # 数字框→滑块
```

**当滑块值改变 → spin.setValue(v) → spin 发出 valueChanged → slider.setValue(v) → 滑块又发出 valueChanged……**

**看起来会死循环，但实际运行不会崩溃。** 因为 `setValue` 只在值真正变化时才发信号，如果新值等于当前值，就不会再触发。所以上面的代码其实能跑，但逻辑冗余。

**更好的做法：用信号参数判断来源，或者用 `valueChanged` 的 int 和 str 重载来区分。** 大多数情况下双向 connect 不会出问题，但要心里有数。

## QSpinBox：数字输入框

**QSpinBox 是整数微调框，带上下箭头。**

```
from PySide6.QtWidgets import QSpinBox

spin = QSpinBox()
spin.setRange(0, 100)          # 范围 0~100
spin.setSingleStep(5)          # 每次加减 5
spin.setValue(20)              # 当前值
spin.setPrefix("¥ ")           # 前缀：¥ 20
spin.setSuffix(" 元")           # 后缀：20 元
```

**`valueChanged(int)` 发整数，`textChanged(str)` 发带前缀后缀的完整文本：**

```
spin.valueChanged.connect(lambda v: print("数值：", v))
spin.textChanged.connect(lambda t: print("文本：", t))    # "¥ 20 元"
```

**设置特殊值显示：**

```
spin.setSpecialValueText("自动")    # 当值等于 minimum 时显示"自动"
spin.setRange(0, 100)
spin.setValue(0)    # 显示"自动"而不是"0"
```

## QProgressBar：进度条

**QProgressBar 显示任务进度，0~100 的百分比。**

```
from PySide6.QtWidgets import QProgressBar

bar = QProgressBar()
bar.setRange(0, 100)       # 默认就是 0~100
bar.setValue(35)           # 显示 35%
```

**进度条三种模式：**

```
# 模式 1：确定进度（默认）
bar.setRange(0, 100)
bar.setValue(50)

# 模式 2：不确定进度（忙碌动画）
bar.setRange(0, 0)          # 最小值==最大值 → 不确定模式
# 显示一个来回跑的动画条

# 模式 3：设回确定进度
bar.setRange(0, 100)
```

**`setFormat` 自定义文字：**

```
bar.setFormat("已完成 %p%")      # %p = 百分比，%v = 当前值
bar.setValue(75)                 # 显示"已完成 75%"
```

## 三者联动：信号槽的用武之地

**核心思路：拖动滑块 → 数字框跟着变 → 进度条跟着走。**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QSlider, QSpinBox,
    QProgressBar, QVBoxLayout, QLabel
)
from PySide6.QtCore import Qt

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("数值联动")
window.resize(300, 150)

slider = QSlider(Qt.Horizontal)
slider.setRange(0, 100)

spin = QSpinBox()
spin.setRange(0, 100)

bar = QProgressBar()
bar.setRange(0, 100)

label = QLabel("当前值：50")

# 滑块 → 数字框 + 进度条 + 标签
slider.valueChanged.connect(spin.setValue)
slider.valueChanged.connect(bar.setValue)
slider.valueChanged.connect(lambda v: label.setText(f"当前值：{v}"))

# 数字框 → 滑块 + 进度条 + 标签
spin.valueChanged.connect(slider.setValue)
spin.valueChanged.connect(bar.setValue)
spin.valueChanged.connect(lambda v: label.setText(f"当前值：{v}"))

# 设初始值（通过滑块设，会连带更新其他）
slider.setValue(50)

main = QVBoxLayout(window)
main.addWidget(label)
main.addWidget(slider)
main.addWidget(spin)
main.addWidget(bar)

window.show()
app.exec()
```

**信号链：滑块的 valueChanged 同时连到 spin.setValue、bar.setValue、label 更新。一个信号触发三个动作。**

**反过来数字框改值也一样：spin.valueChanged 连回 slider.setValue，保持两者同步。**

## 翻车现场二：设了 setRange 但 setValue 超出范围

**症状：进度条始终显示 0% 或不更新。**

```
bar = QProgressBar()
bar.setRange(0, 100)
bar.setValue(150)       # 超出最大值
# 进度条显示 100%（被截断到上限）
```

**原因：`setValue` 超出范围会被截断到 `[minimum, maximum]`。** 如果进度条不更新，先检查 `value()` 是否在范围内：

```
print("range:", bar.minimum(), "~", bar.maximum())
print("value:", bar.value())
```

**更常见的坑：忘记 `setRange` 直接 `setValue`：**

```
bar = QProgressBar()
bar.setValue(50)
# 进度条默认 range 就是 0~100，所以这里没问题
```

**但如果你的进度是 0~1 的小数（比如下载进度），必须改 range：**

```
bar = QProgressBar()
bar.setRange(0, 100)
# 如果传入 0.5 会失败，因为 QProgressBar 只接受整数
# 解决：把小数乘以 100 转成整数
bar.setValue(int(0.5 * 100))    # 50%
```

## 进阶：用定时器模拟进度

**`QTimer` 定时触发，模拟任务进度：**

```
from PySide6.QtCore import QTimer

bar = QProgressBar()
bar.setRange(0, 100)

timer = QTimer()
timer.setInterval(50)    # 每 50ms 触发一次

def on_tick():
    value = bar.value() + 1
    bar.setValue(value)
    if value >= 100:
        timer.stop()

timer.timeout.connect(on_tick)
timer.start()    # 启动定时器
```

**`QTimer.singleShot` 延迟执行一次：**

```
QTimer.singleShot(2000, lambda: label.setText("2 秒到了！"))
```

## 完整示例：音量控制器

**滑块 + 数字框 + 进度条 + 颜色变化：**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QSlider, QSpinBox,
    QProgressBar, QLabel, QVBoxLayout, QHBoxLayout
)
from PySide6.QtCore import Qt

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("音量控制")
window.resize(350, 200)

title = QLabel("🔊 音量控制")
title.setStyleSheet("font-size: 18px; font-weight: bold;")

slider = QSlider(Qt.Horizontal)
slider.setRange(0, 100)
slider.setTickPosition(QSlider.TicksBelow)
slider.setTickInterval(10)

spin = QSpinBox()
spin.setRange(0, 100)
spin.setSuffix("%")

bar = QProgressBar()
bar.setRange(0, 100)
bar.setFormat("%p%")

status = QLabel("状态：适中")

def update_all(value):
    bar.setValue(value)
    if value == 0:
        status.setText("🔇 静音")
        bar.setStyleSheet("")
    elif value < 30:
        status.setText("🔈 较小")
        bar.setStyleSheet("QProgressBar::chunk { background-color: #4CAF50; }")
    elif value < 70:
        status.setText("🔉 适中")
        bar.setStyleSheet("QProgressBar::chunk { background-color: #FFC107; }")
    else:
        status.setText("🔊 较大")
        bar.setStyleSheet("QProgressBar::chunk { background-color: #F44336; }")

slider.valueChanged.connect(spin.setValue)
slider.valueChanged.connect(update_all)
spin.valueChanged.connect(slider.setValue)

slider.setValue(50)

row = QHBoxLayout()
row.addWidget(slider)
row.addWidget(spin)

main = QVBoxLayout(window)
main.addWidget(title)
main.addLayout(row)
main.addWidget(bar)
main.addWidget(status)

window.show()
app.exec()
```

**通过 `setStyleSheet` 动态改进度条颜色，让视觉反馈更直观。**

## 小结

- QSlider：setRange/setValue，valueChanged(int) 信号，Horizontal/Vertical 方向
- QSpinBox：setRange/setSingleStep/setPrefix/setSuffix，valueChanged 有 int 和 str 两个重载
- QProgressBar：setRange + setValue，range(0,0) 为不确定模式
- 三者联动：一个控件的 valueChanged 信号 connect 到其他控件的 setValue
- QTimer 模拟进度：timeout 信号 + start/stop
- setStyleSheet 动态改样式，实现颜色反馈
