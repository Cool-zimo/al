# connect 的几种写法

> 第 3 课讲了信号与槽的概念，这一课把 `connect` 的几种常见写法铺开：连内置信号、连自定义信号、用 lambda 传参、用装饰器声明信号。学会自定义信号，才算真正掌握了 Qt 的解耦能力。

## 写法一：连内置信号（最常见）

**这是你已经见过的写法，复习一下：**

```
from PySide6.QtWidgets import QPushButton

def on_click():
    print("点了")

btn = QPushButton("点我")
btn.clicked.connect(on_click)
```

**注意：connect 后面写的是函数对象 `on_click`，不要加括号 `on_click()`。** 加了括号就是立即调用，把返回值（None）连上去，点击时什么也不会发生。

**完整可运行的例子：**

```
import sys
from PySide6.QtWidgets import QApplication, QWidget, QPushButton, QVBoxLayout

def on_click():
    print("按钮被点击")

app = QApplication(sys.argv)
window = QWidget()
btn = QPushButton("点我")
btn.clicked.connect(on_click)

layout = QVBoxLayout(window)
layout.addWidget(btn)
window.show()
app.exec()
```

## 翻车现场一：connect 后面加了括号

**症状**：按钮点下去没有任何反应，控制台也不报错。控制台在程序启动时反而打印了一行东西。

```
def on_click():
    print("点了")

btn.clicked.connect(on_click())   # 错误：加了括号
```

**原因**：`on_click()` 在 connect 这一行就被立即执行了，返回 None。`btn.clicked.connect(None)` 等于什么都没连。而且 `on_click` 里的 `print("点了")` 在启动时就被调用了一次，你会看到控制台莫名其妙先打印一次。

**解决**：**connect 接收的是函数对象，去掉括号。** 要传参数的话用 lambda 或 partial（见下文）。

## 写法二：lambda 传参

**槽函数需要额外参数时，lambda 是最方便的写法。**

```
from PySide6.QtWidgets import QPushButton

def greet(name):
    print(f"你好，{name}")

btn = QPushButton("打招呼")
btn.clicked.connect(lambda: greet("张三"))
```

**lambda 充当了"适配器"**：`clicked` 信号不带参数，但 `greet` 需要一个 `name`。lambda 吃掉信号的参数（如果有的话），再调用 `greet("张三")`。

**lambda 接收信号参数的写法：**

```
btn.clicked.connect(lambda checked: print("是否按下：", checked))
```

**`checked` 是 `clicked(bool)` 重载版本传来的 bool 值**，表示按钮是否被按下。注意 QPushButton 只有在 `setCheckable(True)` 之后才有这个 bool 值，普通按钮的 clicked 不带参数。

**更实用的例子：循环创建多个按钮：**

```
from PySide6.QtWidgets import QPushButton, QWidget, QVBoxLayout

window = QWidget()
layout = QVBoxLayout(window)

names = ["新建", "打开", "保存"]

def do_action(name):
    print(f"执行操作：{name}")

for n in names:
    btn = QPushButton(n)
    btn.clicked.connect(lambda checked, name=n: do_action(name))
    layout.addWidget(btn)
```

**`name=n` 用默认参数捕获了当前循环的值**，每个 lambda 各存一份。这是第 3 课讲过的闭包技巧，Qt 里天天用。

## 写法三：用 functools.partial

**lambda 的替代品，适合参数多、逻辑复杂的情况。**

```
from functools import partial
from PySide6.QtWidgets import QPushButton

def do_action(name, times):
    for _ in range(times):
        print(name)

btn = QPushButton("连点")
btn.clicked.connect(partial(do_action, "保存", 3))
```

**partial 把 `do_action` 和前两个参数绑死**，返回一个新函数。点击时这个新函数被调用，等价于 `do_action("保存", 3)`。

**partial 和 lambda 怎么选？** 参数少、逻辑短用 lambda；参数多、要复用同一个绑定逻辑用 partial。partial 读起来更清晰，因为参数在定义处就明确了。

## 写法四：自定义信号

**这是 Qt 最强大的特性之一：你可以定义自己的信号。**

**自定义信号必须写在 `QObject` 的子类里，用 `Signal` 声明：**

```
from PySide6.QtCore import QObject, Signal

class TaskWorker(QObject):
    finished = Signal()                    # 无参数信号
    progress = Signal(int)                 # 带一个 int 参数
    result_ready = Signal(str, int)        # 带两个参数

    def run(self):
        for i in range(1, 6):
            self.progress.emit(i)          # 发射信号
        self.result_ready.emit("完成", 100)
        self.finished.emit()
```

**三要素：**

1. **声明**：`finished = Signal()`，写在类体里，不在 `__init__` 里。
2. **发射**：`self.progress.emit(3)`，用 `.emit()` 方法。
3. **连接**：`worker.progress.connect(on_progress)`，和普通信号一样用 connect。

**运行示例：**

```
def on_progress(value):
    print(f"进度：{value}/5")

worker = TaskWorker()
worker.progress.connect(on_progress)

worker.run()
```

**输出：**

```
进度：1/5
进度：2/5
进度：3/5
进度：4/5
进度：5/5
```

## 翻车现场二：把 Signal 声明写进了 __init__

**症状**：程序运行时报错，说这个属性不是信号。

```
from PySide6.QtCore import QObject, Signal

class BadWorker(QObject):
    def __init__(self):
        super().__init__()
        self.finished = Signal()   # 错误！
```

**报错信息**：`AttributeError: 'PySide6.QtCore.Signal' object has no attribute 'connect'` 或者 `TypeError: Signal must be used as a class attribute`。

**原因**：`Signal` 是描述符（descriptor），必须在**类体**里声明，让 Qt 的元对象系统在类创建时处理它。写进 `__init__` 就成了普通实例属性，失去了信号的特性。

**解决**：**把 Signal 声明提到类体顶层，和实例方法并列。**

```
class GoodWorker(QObject):
    finished = Signal()           # 正确：类体里声明

    def __init__(self):
        super().__init__()
```

## 翻车现场三：信号带了参数，槽函数没接住

**症状**：点击按钮或发射信号时程序崩溃。

```
class Worker(QObject):
    data_ready = Signal(str, int)

worker = Worker()
worker.data_ready.connect(lambda s: print(s))   # 错误：只接一个参数
worker.data_ready.emit("分数", 95)
```

**报错信息**：`TypeError: <lambda>() takes 1 positional argument but 2 were given`。

**原因**：`data_ready` 发射时传了两个值 `("分数", 95)`，但 lambda 只定义了一个参数 `s`，第二个值无处安放。

**解决**：槽函数的参数个数要和信号发射的值的个数一致。要么改成 `lambda s, n: print(s, n)`，要么在信号端减参数。

## 用装饰器声明信号（进阶）

**除了 `Signal()` 类属性，还可以用 `@Signal` 装饰器（Qt 6.6+ 支持）：**

```
from PySide6.QtCore import QObject, Signal

class Worker(QObject):
    @Signal
    def finished(self): ...                 # 无参数

    @Signal
    def progress(self, value: int): ...     # 带参数，靠类型注解
```

**这种写法更 Pythonic**，参数类型靠注解声明。但老版本 Qt 不支持，为了兼容性，本书统一用 `Signal()` 类属性的写法。

## 小结

- `connect` 接收函数对象，不要加括号
- lambda 传参：`btn.clicked.connect(lambda: func(arg))`
- 循环绑参用 `lambda checked, i=i: ...` 捕获当时值
- functools.partial 是 lambda 的替代品，参数多时用它更清晰
- 自定义信号：`类名里 Signal() 声明 → emit() 发射 → connect 连接`
- Signal 必须声明在类体里，不能写进 `__init__`
- 槽函数参数个数要和信号发射的值的个数一致
