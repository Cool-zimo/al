# QComboBox、QCheckBox、QRadioButton

> 下拉框、复选框、单选按钮——这是选择类控件的三个主力。它们的共同点是"选一个或几个值"，但交互方式不同：下拉框省空间、复选框允许多选、单选按钮强制单选。这一课把三者讲透，重点是单选按钮要分组才不会乱。

## QComboBox：下拉选择框

**QComboBox 是下拉框，点击展开一个列表。**

```
from PySide6.QtWidgets import QComboBox

combo = QComboBox()
combo.addItem("北京")
combo.addItem("上海")
combo.addItem("广州")
combo.addItem("深圳")

combo.setCurrentIndex(1)        # 默认选中"上海"（索引 1）
print(combo.currentIndex())     # 当前索引：1
print(combo.currentText())      # 当前文本："上海"
```

**`addItem(text)` 加选项，`currentIndex()` 读索引，`currentText()` 读文本。**

**`addItems(list)` 一次加多个：**

```
cities = ["北京", "上海", "广州", "深圳", "杭州", "成都"]
combo.addItems(cities)
```

**`currentIndexChanged` 信号带两个重载：带 int 和带 str：**

```
combo.currentIndexChanged.connect(lambda index: print("索引变了：", index))
```

**注意：currentIndexChanged 默认发出 int（新索引）。** 要拿到文本得自己在槽里调 `combo.currentText()`。

**`currentTextChanged` 直接发文本：**

```
combo.currentTextChanged.connect(lambda text: print("选了：", text))
```

**做"选择城市后联动更新其他控件"，用 currentTextChanged 更方便。**

## 翻车现场一：用索引做判断，选项一重排就出错

**症状：代码里写死 `if index == 1:` 代表上海，后来有人往列表头插了个"全国"，判断全错。**

```
combo.addItems(["全国", "北京", "上海", "广州"])   # 插入后上海变成索引 2
combo.currentIndexChanged.connect(lambda i: print("上海" if i == 1 else "其他"))
# 选上海时打印"其他"，因为上海现在是索引 2
```

**解决：用 `currentText()` 判断文本，而不是索引。**

```
combo.currentTextChanged.connect(lambda text: print("选了：" + text))
```

**或者用 `findText` 查找：**

```
idx = combo.findText("上海")
if idx >= 0:
    combo.setCurrentIndex(idx)
```

## QCheckBox：复选框（可多选）

**QCheckBox 表示"是/否"或"多选"选项，可以多选。**

```
from PySide6.QtWidgets import QCheckBox

cb = QCheckBox("记住密码")
cb.setChecked(True)             # 默认勾选
print(cb.isChecked())           # True

cb.toggled.connect(lambda checked: print("勾选状态：", checked))
```

**`setChecked(True/False)` 设勾选状态，`isChecked()` 读取。**

**`toggled(bool)` 信号在状态变化时触发**，参数就是当前是否勾选。

**多个复选框收集结果：**

```
hobbies = ["阅读", "运动", "音乐", "旅行"]
checks = []
for h in hobbies:
    cb = QCheckBox(h)
    checks.append(cb)

def collect():
    chosen = [cb.text() for cb in checks if cb.isChecked()]
    print("选择了：", chosen)

for cb in checks:
    cb.toggled.connect(collect)
```

**列表推导式 `[cb.text() for cb in checks if cb.isChecked()]` 一行收集所有勾选项。**

## 翻车现场二：复选框状态判断写反了

**症状：逻辑和预期相反。**

```
if not cb.isChecked():     # 本想判断是否勾选
    print("已勾选")
```

**`isChecked()` 返回 True 表示已勾选。** 判断已勾选用 `if cb.isChecked():`，判断未勾选用 `if not cb.isChecked():`。

## QRadioButton：单选按钮（互斥单选）

**QRadioButton 是单选按钮，同一组里只能选一个。**

```
from PySide6.QtWidgets import QRadioButton

r1 = QRadioButton("男")
r2 = QRadioButton("女")
r3 = QRadioButton("其他")

r1.setChecked(True)        # 默认选"男"
```

**问题：这三个单选按钮放一起，用户能同时选中多个吗？** 答案是：**会**——如果它们没有正确地放在同一个父容器或布局下。

**单选按钮的互斥靠"同一个父容器 / 同一个布局"实现：**

```
from PySide6.QtWidgets import QGroupBox, QVBoxLayout

group = QGroupBox("性别")
layout = QVBoxLayout(group)
layout.addWidget(r1)
layout.addWidget(r2)
layout.addWidget(r3)
```

**把单选按钮放进同一个 QGroupBox 或同一个布局，Qt 自动让它们互斥。** 不分组的话，散落在窗口各处的单选按钮可能各自独立，也可能全混在一起，行为不可控。

**正确做法：用 QButtonGroup 显式分组（推荐）：**

```
from PySide6.QtWidgets import QButtonGroup

sex_group = QButtonGroup(window)
sex_group.addButton(r1)
sex_group.addButton(r2)
sex_group.addButton(r3)
```

**QButtonGroup 不管显示（不继承 QWidget），只管逻辑互斥。** 这样即使单选按钮散落在不同布局里，只要加进同一个 QButtonGroup，就保证互斥。

## 翻车现场三：单选按钮没分组，多个同时被选中

**症状：界面上"男"和"女"能同时打勾，逻辑上说不通。**

```
r1 = QRadioButton("男", window)
r2 = QRadioButton("女", window)
r3 = QRadioButton("其他", window)
r1.setChecked(True)
# 三个按钮直接挂在 window 上，互斥关系不明确
```

**原因：单选按钮的互斥依赖"同一个父容器的布局"或"同一个 QButtonGroup"。直接挂在窗口上、没有显式分组，行为可能不符合预期。**

**解决：用 QButtonGroup：**

```
sex_group = QButtonGroup()
sex_group.addButton(r1)
sex_group.addButton(r2)
sex_group.addButton(r3)
```

**或者放进同一个 QGroupBox / 布局。**

## QButtonGroup 的进阶用法

**`checkedButton()` 拿到当前选中的那个按钮：**

```
def on_sex_changed():
    btn = sex_group.checkedButton()
    if btn:
        print("性别：", btn.text())

sex_group.buttonToggled.connect(lambda btn, checked: on_sex_changed())
```

**`buttonToggled` 信号带两个参数：哪个按钮、是否选中。**

**`setId(button, id)` 给按钮设数字 ID，方便判断：**

```
sex_group.addButton(r1, 1)     # ID 1
sex_group.addButton(r2, 2)     # ID 2
sex_group.addButton(r3, 3)     # ID 3

print("选中 ID：", sex_group.checkedId())   # 返回当前选中按钮的 ID
```

**用 ID 代替文本判断更稳：文本可能改，ID 不变。**

## 三个控件组合：筛选设置面板

**下拉框选排序方式、复选框选筛选条件、单选按钮选视图模式：**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QComboBox, QCheckBox,
    QRadioButton, QButtonGroup, QLabel, QVBoxLayout, QHBoxLayout, QGroupBox
)
from PySide6.QtCore import Qt

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("筛选设置")
window.resize(350, 300)

# 排序方式（下拉框）
sort_combo = QComboBox()
sort_combo.addItems(["按时间", "按名称", "按大小", "按类型"])
sort_label = QLabel("排序：综合排序")       # 初始
sort_combo.currentTextChanged.connect(lambda t: sort_label.setText("排序：" + t))

# 筛选条件（复选框）
filters = QGroupBox("筛选条件")
f_layout = QVBoxLayout(filters)
check_read = QCheckBox("只看未读")
check_star = QCheckBox("已加星标")
check_attach = QCheckBox("含附件")
f_layout.addWidget(check_read)
f_layout.addWidget(check_star)
f_layout.addWidget(check_attach)

# 视图模式（单选按钮）
view_group = QButtonGroup()
view_box = QGroupBox("视图模式")
v_layout = QVBoxLayout(view_box)
r_list = QRadioButton("列表")
r_grid = QRadioButton("网格")
r_list.setChecked(True)
view_group.addButton(r_list)
view_group.addButton(r_grid)
v_layout.addWidget(r_list)
v_layout.addWidget(r_grid)

main = QVBoxLayout(window)
main.addWidget(sort_combo)
main.addWidget(sort_label)
main.addWidget(filters)
main.addWidget(view_box)

window.show()
app.exec()
```

**层次：一个下拉框、一个复选框组、一个单选按钮组，纵向排列。**

## 小结

- QComboBox：addItem/addItems 加选项，currentText() 读文本，currentTextChanged 信号
- 判断选项用文本或 findText，别依赖索引（选项顺序一变就错）
- QCheckBox：setChecked/isChecked，toggled(bool) 信号
- 多选结果用列表推导式收集
- QRadioButton：同一组互斥，需要显式分组
- 用 QButtonGroup 保证互斥（推荐），或放进同一 QGroupBox
- QButtonGroup.setId 设数字 ID，checkedId() 读取，比判断文本稳
