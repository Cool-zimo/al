# QInputDialog / QFileDialog / QColorDialog

> 三个最常用的内置对话框：取一个值、选一个文件、挑一个颜色。都是静态方法一行搞定，但都藏着同一个坑——用户可能取消。

## QInputDialog：取用户输入

**QInputDialog 用来取一行文本、一个数字或一个选项，返回 `(值, 是否确认)` 元组。**

```
from PySide6.QtWidgets import QInputDialog

text, ok = QInputDialog.getText(window, "输入", "请输入你的名字：")
if ok:
    print("你输入了：", text)
```

**`ok` 是布尔值，True 表示点了 OK，False 表示点了取消。** 这是最容易忘判空的地方。

**取整数和浮点数：**

```
age, ok = QInputDialog.getInt(window, "年龄", "请输入年龄：", value=18, min=0, max=120)
if ok:
    print("年龄：", age)
```

```
weight, ok = QInputDialog.getDouble(window, "体重", "请输入体重：", value=60.0, min=0, max=300, decimals=1)
if ok:
    print("体重：", weight)
```

**`getItem` 从下拉列表里选一项：**

```
items = ["Python", "C++", "Rust", "Go"]
lang, ok = QInputDialog.getItem(window, "选择", "你最爱的语言：", items, current=0, editable=False)
if ok:
    print("选择了：", lang)
```

**`editable=False` 时只能选不能改；去掉它就能让用户自己输入新值。**

## 翻车现场一：直接解包不判 ok，取消时报错

**症状：弹窗里点了取消，程序直接崩溃 `TypeError: cannot unpack non-iterable ...`。**

```
text = QInputDialog.getText(window, "输入", "名字：")   # ❌ 只接一个变量
print(text.upper())    # 返回值其实是元组，这样 text 成了 tuple
```

**更隐蔽的错误是不判断 ok 就用值：**

```
text, ok = QInputDialog.getText(window, "输入", "名字：")
print(f"你好，{text}")    # ❌ 用户取消后 text 是空字符串，逻辑上就不对
```

**✅ 正确写法永远是判 ok：**

```
text, ok = QInputDialog.getText(window, "输入", "名字：")
if ok and text.strip():
    print(f"你好，{text}")
else:
    print("用户取消了，或者没输入内容")
```

**`text` 取消后是空字符串，不是 None。** 所以判断"有没有内容"要用 `text.strip()`，而不是 `if text`。

## QFileDialog：选文件

**`getOpenFileName` 选一个文件，返回 `(路径, 过滤器)` 元组。**

```
from PySide6.QtWidgets import QFileDialog

file_path, _ = QFileDialog.getOpenFileName(
    window, "打开文件", "", "文本文件 (*.txt);;所有文件 (*)"
)
if file_path:
    print("选中：", file_path)
```

**第三个参数是起始目录，第四个参数是过滤器，用 `;;` 分隔多个选项。** 返回值第二个元素是用户选中的过滤器，通常不需要，用 `_` 丢掉。

**`getOpenFileNames` 选多个文件，返回列表：**

```
files, _ = QFileDialog.getOpenFileNames(window, "打开多个", "", "图片 (*.png *.jpg)")
print(files)    # ['/a.png', '/b.jpg']
```

**`getSaveFileName` 是"另存为"对话框：**

```
save_path, _ = QFileDialog.getSaveFileName(window, "保存", "untitled.txt", "文本 (*.txt)")
if save_path:
    with open(save_path, "w", encoding="utf-8") as f:
        f.write("hello")
```

**`getExistingDirectory` 只选文件夹：**

```
folder = QFileDialog.getExistingDirectory(window, "选择目录", "")
if folder:
    print("目录：", folder)
```

## 翻车现场二：用户点取消，拿到空字符串还去 open

**症状：点了取消，`file_path` 是 `""`，接着 `open("")` 抛出 `FileNotFoundError` 或 `ValueError`。**

```
file_path, _ = QFileDialog.getOpenFileName(window, "打开", "", "文本 (*.txt)")
with open(file_path, "r", encoding="utf-8") as f:    # ❌ 没判空
    content = f.read()
# 点取消后：ValueError: invalid mode: 'r'
```

**✅ 正确写法：先判空再操作。**

```
file_path, _ = QFileDialog.getOpenFileName(window, "打开", "", "文本 (*.txt)")
if not file_path:
    return    # 用户取消，直接返回

with open(file_path, "r", encoding="utf-8") as f:
    content = f.read()
label.setText(content)
```

**这是一个必须养成的习惯：任何对话框的"取回值"都要先判空。** QInputDialog 判 ok，QFileDialog 判路径是否为空，QColorDialog 判 isValid。

## QColorDialog：选颜色

**`getColor` 返回 QColor 对象，取消时 `isValid()` 为 False。**

```
from PySide6.QtWidgets import QColorDialog
from PySide6.QtGui import QColor

color = QColorDialog.getColor(QColor("white"), window, "选择颜色")
if color.isValid():
    print(color.name())              # "#ff0000"
    print(color.red(), color.green(), color.blue())
    btn.setStyleSheet(f"background-color: {color.name()};")
else:
    print("用户取消了选色")
```

**第一个参数是初始颜色，传 QColor 或颜色名字符串都行。** `color.name()` 返回 `#rrggbb` 格式，直接塞进 QSS 就能用。

**结合 QSS 做实时预览：**

```
color = QColorDialog.getColor(QColor("#3498db"), self, "选择背景色")
if color.isValid():
    self.setStyleSheet(f"QWidget {{ background-color: {color.name()}; }}")
```

## 小结

- QInputDialog：getText / getInt / getDouble / getItem，返回 `(值, ok)`
- ⚠️ 经典坑：不判断 ok 就使用返回值；取消时 text 是空字符串不是 None
- QFileDialog：getOpenFileName / getOpenFileNames / getSaveFileName / getExistingDirectory
- 文件对话框返回 `(路径, 过滤器)`，判空再 open，否则取消会抛异常
- 过滤器用 `;;` 分隔，如 `"文本 (*.txt);;所有文件 (*)"`
- QColorDialog.getColor 返回 QColor，用 isValid() 判断取消，name() 取十六进制色值
- 所有对话框的返回值都必须先校验再使用
