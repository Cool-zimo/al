# 常用 QSS 写法

> 这一课把最常用的几组 QSS 写法一次讲透：按钮的悬停按下、边框圆角、输入框聚焦。记住这几套模板，日常界面美化就够了。

## 按钮的三态样式

**按钮最值得写的是三种状态：正常、悬停、按下。**

```
QPushButton {
    background-color: #3498db;
    color: white;
    border: none;
    border-radius: 6px;
    padding: 8px 16px;
    font-size: 14px;
}

QPushButton:hover {
    background-color: #2980b9;
}

QPushButton:pressed {
    background-color: #1f6391;
    padding: 9px 15px 7px 17px;    /* 按下时轻微错位，模拟按下去 */
}
```

**`:hover` 鼠标悬停，`:pressed` 鼠标按下，`:disabled` 禁用状态。**

**`:disabled` 一定要写，否则禁用按钮看起来还能点：**

```
QPushButton:disabled {
    background-color: #bdc3c7;
    color: #7f8c8d;
}
```

**`border: none` 能去掉系统默认的按钮浮雕感，配合背景色才是扁平风。** 不去掉的话 Windows 上会有一圈原生边框，跟你的配色打架。

## 翻车现场一：悬停样式不生效，因为子控件覆盖了它

**症状：写了 `:hover` 规则，鼠标移上去按钮颜色纹丝不动。**

```
btn = QPushButton("提交")
btn.setStyleSheet("""
    QPushButton { background-color: #3498db; }    /* ❌ 作用在这个按钮上 */
""")
# 同时父窗口又有：
window.setStyleSheet("""
    QPushButton:hover { background-color: red; }   /* 被上面更具体的规则盖住 */
""")
```

**原因：QSS 有特异性规则，更"靠近"控件的样式优先级更高。** 控件自己的 setStyleSheet 里没写 `:hover`，而父窗口的样式表里写了，两者合并后可能不按预期工作。更常见的情况是：样式表里 `QPushButton` 规则写在 `:hover` 之后，后面覆盖前面。

**✅ 正确写法：把所有状态写在一起，顺序正常排列。**

```
btn.setStyleSheet("""
    QPushButton {
        background-color: #3498db;
        color: white;
        border-radius: 6px;
        padding: 8px 16px;
    }
    QPushButton:hover { background-color: #2980b9; }
    QPushButton:pressed { background-color: #1f6391; }
""")
```

**顺序建议：基础状态 → :hover → :pressed → :disabled，按这个顺序写最不容易出乱子。**

## 边框与圆角

**`border` 是复合写法：`border: 宽度 样式 颜色`。**

```
QLineEdit {
    border: 2px solid #bdc3c7;
    border-radius: 6px;
}

QLineEdit:focus {
    border: 2px solid #3498db;
}
```

**只设圆角不设背景，也能做出卡片效果：**

```
QLabel#card {
    background-color: white;
    border: 1px solid #e0e0e0;
    border-radius: 10px;
    padding: 16px;
}
```

**四个角单独控制：**

```
QPushButton {
    border-top-left-radius: 8px;
    border-top-right-radius: 8px;
    border-bottom-left-radius: 0;
    border-bottom-right-radius: 0;
}
```

**`border-radius` 超过控件高度的一半就是正圆形：**

```
QPushButton#circle_btn {
    border-radius: 25px;    /* 高度 50 的按钮，25 就是圆角到一半 */
}
```

## 输入框聚焦与占位符

**`:focus` 是输入框最有用的伪状态。**

```
QLineEdit {
    background-color: white;
    border: 1px solid #ccc;
    border-radius: 4px;
    padding: 6px 10px;
    selection-background-color: #3498db;    /* 选中文字时的背景 */
}

QLineEdit:focus {
    border: 2px solid #3498db;
    padding: 5px 9px;    /* 边框变宽，内边距减 1px 防止文字抖动 */
}

QLineEdit:hover:!focus {
    border: 1px solid #999;
}
```

**`hover:!focus` 表示悬停但不聚焦，两个条件同时满足。** `!` 是否定，组合伪状态用冒号连。

**占位符文字用 `::placeholder`：**

```
QLineEdit::placeholder {
    color: #95a5a6;
    font-style: italic;
}
```

**密码框的显示模式字符：**

```
QLineEdit#pwd {
    lineedit-password-character: 9679;    /* 实心圆点，默认就是这个 */
    lineedit-password-mask-delay: 1000;  /* 延迟 1 秒后变成圆点 */
}
```

## 翻车现场二：内边距变化导致文字跳动

**症状：输入框聚焦时，文字突然向左抖动一下，看起来很廉价。**

```
QLineEdit { border: 1px solid #ccc; padding: 6px 10px; }
QLineEdit:focus { border: 2px solid #3498db; padding: 6px 10px; }
# 2px 边框比 1px 边框占的空间多 1px，文字会被挤
```

**原因：边框从 1px 变 2px，控件内部可用空间少了 1px，文字位置随之移动。** 肉眼可见的抖动。

**✅ 正确写法：边框变宽时，内边距同步减少。**

```
QLineEdit { border: 1px solid #ccc; padding: 6px 10px; }
QLineEdit:focus { border: 2px solid #3498db; padding: 5px 9px; }
```

**或者统一用 `outline`（Qt 支持 `outline` 属性，不占布局空间）：**

```
QLineEdit { border: 1px solid #ccc; }
QLineEdit:focus { outline: 2px solid #3498db; }
```

## 渐变背景

**QSS 支持线性渐变和径向渐变。**

```
QPushButton {
    background: qlineargradient(
        x1: 0, y1: 0, x2: 0, y2: 1,
        stop: 0 #3498db, stop: 1 #2980b9
    );
    color: white;
    border: none;
    border-radius: 6px;
    padding: 8px 16px;
}
```

**`x1:0, y1:0, x2:0, y2:1` 是从上到下。** `stop:0` 是起点颜色，`stop:1` 是终点颜色，中间可以插任意多个 stop。

**多段渐变做高级按钮：**

```
QPushButton {
    background: qlineargradient(
        x1: 0, y1: 0, x2: 0, y2: 1,
        stop: 0 #4facfe, stop: 0.5 #00f2fe, stop: 1 #4facfe
    );
    color: white;
    border-radius: 20px;
    padding: 8px 24px;
}
```

**径向渐变 `qradialgradient`：**

```
QWidget#header {
    background: qradialgradient(
        cx: 0.5, cy: 0.5, radius: 0.5,
        fx: 0.5, fy: 0.5,
        stop: 0 white, stop: 1 #3498db
    );
}
```

## 小结

- 按钮三态：正常 / :hover / :pressed，顺序按此排列最稳
- :disabled 必须写，否则禁用按钮看起来还能点
- ⚠️ 经典坑：样式表里状态规则顺序写反导致不生效；边框变宽没减内边距导致文字抖动
- 边框圆角：border-radius 超过半高即圆形；四个角可单独设
- 输入框聚焦：:focus 改边框色，内边距要同步减；::placeholder 改占位符
- 渐变：qlineargradient / qradialgradient，用 stop 控制颜色断点

```quiz
type: choice
exam: true
q: 希望输入框聚焦时边框从 1px 变成 2px 且文字不抖动，正确做法是？
options:
- 边框变 2px 时把 padding 也加大 1px
- 边框变 2px 时把 padding 减小 1px 保持内容位置不变
- 把 border-radius 改成 0
- 聚焦时隐藏边框
answer: 1
explain: 边框从 1px 变 2px 会挤占 1px 内部空间，导致文字抖动。正确做法是对应的内边距减小 1px（或者干脆用 outline 属性，它不占布局空间）。加大 padding 反而让文字更挤。
```
