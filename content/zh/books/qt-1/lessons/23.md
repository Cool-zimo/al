# 资源系统 qrc

> 把图片打包进程序，发布时不用带一堆零散文件。这一课讲 qrc 资源文件和 pyrcc6 编译流程。

## 为什么要用资源系统

**直接传文件路径的痛点：程序分发时图片文件必须和 exe 放在一起，路径一变就裂。**

```
btn.setIcon(QIcon("icons/open.png"))    # ❌ 依赖外部文件，换台机器可能找不到
```

**用 qrc 资源系统后，图片编译进 Python 文件，变成代码的一部分：**

```
btn.setIcon(QIcon(":/icons/open.png"))    # ✅ 从资源里取，不依赖外部文件
```

**`:` 前缀表示"这是资源路径"，冒号后面跟 qrc 里定义的路径。** 运行时从内存取，不存在"文件找不到"的问题。

## qrc 文件怎么写

**qrc 是 XML 文件，列出要打包的资源：**

```
<RCC>
    <qresource prefix="/icons">
        <file>open.png</file>
        <file>save.png</file>
        <file>cut.png</file>
    </qresource>
    <qresource prefix="/images">
        <file>logo.png</file>
        <file>background.jpg</file>
    </qresource>
</RCC>
```

**保存为 `resources.qrc`。`<qresource prefix>` 是路径前缀，资源引用时是 `:/icons/open.png`。**

**不写 prefix 也行，那就直接用文件名：**

```
<RCC>
    <qresource>
        <file>icons/open.png</file>
    </qresource>
</RCC>
```

**引用时写成 `:/icons/open.png`。** prefix 的好处是给资源分组，避免重名。

## pyrcc6 编译流程

**第一步：写好 resources.qrc，把所有图片放进项目目录。**

```
project/
├── main.py
├── resources.qrc
└── icons/
    ├── open.png
    ├── save.png
    └── cut.png
```

**第二步：用 pyrcc6 把 qrc 编译成 Python 文件。**

```
pyrcc6 resources.qrc -o resources_rc.py
```

**`-o` 指定输出文件名，约定俗成用 `_rc.py` 后缀。** 生成的文件里是一个大字典，把每个文件转成字节数据。

**第三步：在 main.py 里 import 这个模块，然后正常使用。**

```
import sys
import resources_rc                # ⚠️ 必须先 import，否则 :/ 路径找不到
from PySide6.QtWidgets import QApplication, QPushButton
from PySide6.QtGui import QIcon

app = QApplication(sys.argv)
btn = QPushButton()
btn.setIcon(QIcon(":/icons/open.png"))
btn.show()
app.exec()
```

**`import resources_rc` 这个 import 看起来没被用到，但它执行时会把资源注册进 Qt 的资源系统。** 删掉这行，`QIcon(":/icons/open.png")` 就拿不到图片。

## 翻车现场一：改了 qrc 没重跑 pyrcc6，资源没更新

**症状：往 qrc 里新加了一个 `paste.png`，代码里 `QIcon(":/icons/paste.png")`，运行后图标是空的，什么都显示不出来。**

**原因：qrc 只是源文件，真正被程序读取的是编译产物 `resources_rc.py`。** 改了 qrc 必须重新跑 `pyrcc6 resources.qrc -o resources_rc.py`，否则代码里引用的新资源在旧的 `_rc.py` 里根本不存在。

**✅ 正确流程：改图/加图 → 更新 qrc → 重跑 pyrcc6 → 再运行。**

**排查清单：**

```
1. qrc 里有没有写这个文件？            # 检查 <file> 标签
2. 文件名大小写对不对？                # Linux 下大小写敏感
3. 有没有重新跑 pyrcc6？               # 最关键的一步
4. resources_rc.py 里有没有这个资源？   # 打开看看，搜一下文件名
5. main.py 有没有 import resources_rc？ # 忘了 import 等于没注册
```

**一个省事的办法是把编译写进构建脚本：**

```
# build.bat / build.sh
pyrcc6 resources.qrc -o resources_rc.py
python main.py
```

## 翻车现场二：import 放在后面，图标加载时资源还没注册

**症状：代码逻辑上 import 了 resources_rc，但图标还是显示不出来。**

```
from PySide6.QtWidgets import QApplication, QPushButton
from PySide6.QtGui import QIcon

btn = QPushButton()
btn.setIcon(QIcon(":/icons/open.png"))    # ❌ 此时 resources_rc 还没 import
import resources_rc                        # 太晚了
```

**原因：资源注册发生在 `import resources_rc` 这一刻。** 如果在这之前就创建 QIcon，资源系统里还没有这个资源，图标加载失败。

**✅ 正确写法：resources_rc 要在所有用到资源的代码之前 import。**

```
import resources_rc                        # ✅ 放在最前面
from PySide6.QtWidgets import QApplication, QPushButton
from PySide6.QtGui import QIcon

btn = QPushButton()
btn.setIcon(QIcon(":/icons/open.png"))    # 此时资源已注册
```

**习惯上把它放在所有 import 的最前面，和第三方库 import 分开，一眼能看见。**

## 在 QSS 里用资源

**QSS 也能引用资源路径：**

```
QPushButton#open_btn {
    image: url(:/icons/open.png);
    /* 或者用 border-image / background-image */
}

QPushButton#open_btn:hover {
    image: url(:/icons/open_hover.png);
}
```

**`image` 保持图片原始比例；`border-image` 会拉伸填满控件；`background-image` 平铺。**

**在 QSS 里用资源做背景图：**

```
QWidget#header {
    background-image: url(:/images/header_bg.png);
    background-repeat: no-repeat;
    background-position: center;
}
```

**QSS 里的 `url()` 也支持 `:/` 资源路径，和普通文件路径混用都没问题。**

## 小结

- qrc 把图片打包进程序，运行时不依赖外部文件
- 资源路径用 `:/prefix/filename` 引用，冒号是资源前缀
- 编译流程：写 qrc → `pyrcc6 resources.qrc -o resources_rc.py` → import 使用
- ⚠️ 经典坑：改了 qrc 没重跑 pyrcc6 导致资源没更新；import resources_rc 太晚或漏了导致资源未注册
- resources_rc 必须放在所有用资源的代码之前 import
- QSS 里用 `url(:/path)` 引用资源，image / border-image / background-image 三种用法不同
