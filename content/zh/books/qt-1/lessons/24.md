# 图标与字体

> 图标要清晰，字体要好看，还要在 4K 屏上不糊。这一课讲 QIcon 的多分辨率机制、字体设置和 DPI 适配。

## QIcon 的多分辨率机制

**QIcon 可以装多个尺寸的图，Qt 自动选最合适的一张显示。**

```
from PySide6.QtGui import QIcon

icon = QIcon()
icon.addFile("icons/app_16.png", QSize(16, 16))
icon.addFile("icons/app_24.png", QSize(24, 24))
icon.addFile("icons/app_32.png", QSize(32, 32))
icon.addFile("icons/app_64.png", QSize(64, 64))

app.setWindowIcon(icon)
```

**为什么要多张：工具栏图标在 100% 缩放下用 24px，在 200% 缩放下系统会要 48px，有 64px 的图就能清晰显示，否则会拉伸模糊。**

**用 qrc 资源更省事，一套写好全程序通用：**

```
icon = QIcon()
icon.addFile(":/icons/app_16.png", QSize(16, 16))
icon.addFile(":/icons/app_24.png", QSize(24, 24))
icon.addFile(":/icons/app_32.png", QSize(32, 32))
```

**QIcon 还能区分普通态和禁用态：**

```
icon = QIcon()
icon.addPixmap(QPixmap(":/icons/save.png"), QIcon.Normal)
icon.addPixmap(QPixmap(":/icons/save_disabled.png"), QIcon.Disabled)
```

**按钮禁用时自动显示 Disabled 版本的图标，不用手动切。**

## 翻车现场一：图标只给一张小图，高 DPI 下模糊

**症状：在普通屏看着还行，换到 4K 屏（缩放 200%）工具栏图标糊成一团。**

```
btn.setIcon(QIcon("icons/app_16.png"))    # ❌ 只有 16px 一张
```

**原因：只有一张 16px 图，系统要 32px 显示时只能把它拉伸插值，必然模糊。** 人眼对图标模糊特别敏感。

**✅ 正确做法：准备多尺寸图，addFile 分别注册。**

```
icon = QIcon()
for size in (16, 24, 32, 48, 64):
    icon.addFile(f":/icons/app_{size}.png", QSize(size, size))
btn.setIcon(icon)
```

**最低配置是 1x 和 2x 两张（比如 24px 和 48px）。** 有 2x 图就能覆盖绝大多数 200% 缩放下的情况。

## 字体设置

**用 QFont 设置字体：**

```
from PySide6.QtGui import QFont

font = QFont()
font.setFamily("Microsoft YaHei")
font.setPointSize(12)
font.setBold(True)
font.setItalic(True)

label.setFont(font)
```

**直接传字符串更简洁：**

```
label.setFont(QFont("Microsoft YaHei", 14, QFont.Bold))
# 参数：family, pointSize, weight, italic
```

**给整个应用设默认字体：**

```
app = QApplication(sys.argv)
font = QFont("Microsoft YaHei", 10)
app.setFont(font)    # 所有控件默认用这个字体
```

**全局字体设一次就够，个别控件再单独覆盖。** 反过来如果每个控件都 setFont 一遍，代码会很啰嗦。

## 字体族选择

**常用中文字体：**

```
"Microsoft YaHei"      # 微软雅黑，Windows 首选
"SimHei"               # 黑体
"SimSun"               # 宋体，正文衬线
"KaiTi"                # 楷体
"DengXian"             # 等线，Win10+ 默认
```

**跨平台字体列表：用 setFamilies 给一个候选列表，按顺序匹配。**

```
font = QFont()
font.setFamilies(["Microsoft YaHei", "PingFang SC", "Noto Sans CJK SC", "WenQuanYi Micro Hei"])
font.setPointSize(11)
app.setFont(font)
```

**Qt 会按顺序找第一个已安装的字体。** 这套列表在 Windows / macOS / Linux 上都能落到一个中文字体，不会出现方块。

**emoji 需要支持彩色字体的字体，普通界面字体通常不覆盖 emoji 区段，显示成方框是正常的。**

## 翻车现场二：字体名写错，静默回退到默认字体

**症状：设了字体但界面毫无变化，看起来还是系统默认。**

```
label.setFont(QFont("微软雅黑 Light"))    # ❌ 这个字体名可能不存在
```

**原因：字体名写错时 Qt 不会报错，而是静默回退到默认字体，界面上完全看不出异常。** 你在代码里写对了也白写。

**✅ 排查方法：用 QFontDatabase 查可用字体。**

```
from PySide6.QtGui import QFontDatabase

families = QFontDatabase.families()
for f in families:
    if "YaHei" in f or "Hei" in f or "PingFang" in f:
        print(f)
# 用打印出来的确切名字
```

**Linux 服务器上中文字体可能根本没装，部署前务必查一下 `QFontDatabase.families()`。**

## DPI 适配

**高 DPI 屏要启用自动缩放：**

```
QApplication.setHighDpiScaleFactorRoundingPolicy(
    Qt.HighDpiScaleFactorRoundingPolicy.PassThrough
)
app = QApplication(sys.argv)
```

**`setHighDpiScaleFactorRoundingPolicy` 必须在创建 QApplication 之前调用。** 放晚了无效。

**PySide6 默认会读系统缩放设置，但启用 PassThrough 能得到更精确的缩放（如 1.5x 而不是取整成 1x 或 2x）。**

**手动检测 DPI：**

```
screen = app.primaryScreen()
dpi = screen.logicalDotsPerInch()
print(f"DPI: {dpi}")          # 96 是 100%，192 是 200%
scale = dpi / 96.0
print(f"缩放: {scale}")
```

**用 DPI 动态调字体大小：**

```
dpi = app.primaryScreen().logicalDotsPerInch()
base_size = 10
font = QFont("Microsoft YaHei", int(base_size * dpi / 96))
app.setFont(font)
```

**但更推荐直接用布局 + 布局的默认缩放，Qt 6 已经处理得不错，手动算 DPI 调字号通常是过度设计。**

## 小结

- QIcon 用 addFile 注册多尺寸图，Qt 自动选最合适的一张
- ⚠️ 经典坑：只给 1x 图，高 DPI 下拉伸模糊；字体名写错静默回退默认字体
- 最低配置是 1x + 2x 两张图（24px 和 48px）
- 字体用 QFont，全局用 app.setFont，中文字体用 families 列表做跨平台候选
- QFontDatabase.families() 查系统可用字体
- DPI 适配要在 QApplication 创建前设 HighDpiScaleFactorRoundingPolicy

```quiz
type: choice

q: 关于 QIcon 的多分辨率机制，以下说法正确的是？
options:
- QIcon 只能装一张图片，多张会报错
- QIcon 用 addFile 注册多尺寸后，Qt 会根据显示需求自动选择最合适的图
- 必须手动判断 DPI 并手动切换图标，Qt 不会自动选
- 图标模糊时只要重启程序就能解决
answer: 1
explain: QIcon 支持 addFile 注册多个尺寸的图，Qt 会在不同 DPI 和不同显示尺寸下自动选择最合适的那张。这正是多分辨率机制的意义所在。QIcon 可以装多张图不会报错，也不需要手动切换；图标模糊通常是缺 2x 图，重启解决不了。
```
