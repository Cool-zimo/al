# 实战：一个带计数按钮的窗口

> 前面四课把概念铺完了，这一课把它们串起来：做一个能点一次 +1、能重置的计数窗口。你会用到 QVBoxLayout 摆控件、信号与槽处理逻辑、用 QLabel 显示状态——一个最小但完整的 Qt 程序长什么样，全在这里。

## 成品长什么样

**三个控件竖着排：**

```
┌──────────────────────┐
│        0             │   ← QLabel 显示当前计数
│                      │
│   [  +1  ]  [重置]    │   ← 两个 QPushButton
└──────────────────────┘
```

**交互逻辑：**

- 点"+1"按钮，数字加 1
- 点"重置"按钮，数字归零
- 数字为 0 时显示大字，非零时显示加粗

## 完整代码

**先看完整版，再逐段拆：**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QPushButton,
    QLabel, QVBoxLayout
)
from PySide6.QtCore import Qt

class CounterWindow(QWidget):
    def __init__(self):
        super().__init__()
        self.count = 0
        self.setWindowTitle("计数器")
        self.resize(300, 200)

        self.label = QLabel("0")
        self.label.setAlignment(Qt.AlignmentFlag.AlignCenter)
        font = self.label.font()
        font.setPointSize(48)
        self.label.setFont(font)

        self.btn_plus = QPushButton("+1")
        self.btn_reset = QPushButton("重置")

        self.btn_plus.clicked.connect(self.on_plus)
        self.btn_reset.clicked.connect(self.on_reset)

        layout = QVBoxLayout(self)
        layout.addWidget(self.label)
        layout.addWidget(self.btn_plus)
        layout.addWidget(self.btn_reset)

    def on_plus(self):
        self.count += 1
        self.label.setText(str(self.count))

    def on_reset(self):
        self.count = 0
        self.label.setText("0")

app = QApplication(sys.argv)
window = CounterWindow()
window.show()
app.exec()
```

**逐段拆开讲。**

## 第一部分：类结构

**用类来组织窗口是 Qt 的标准做法**，因为槽函数需要访问控件和状态（如 `self.count`、`self.label`）。

```
class CounterWindow(QWidget):
    def __init__(self):
        super().__init__()
        self.count = 0
```

**`super().__init__()` 不能漏。** QWidget 的初始化要做很多内部工作（创建原生窗口句柄、注册元对象），不调 super 会出各种诡异问题。

**`self.count = 0` 是计数器状态**，存在实例属性上。不用全局变量，因为可能同时开多个计数器窗口。

## 第二部分：控件与字体

**QWidget 的构造函数可以接收一个 parent 参数。** 给控件指定 parent，布局管理会更省心（自动销毁、自动布局）。

```
self.label = QLabel("0")
self.label.setAlignment(Qt.AlignmentFlag.AlignCenter)

font = self.label.font()       # 先拿到当前字体
font.setPointSize(48)          # 改字号
self.label.setFont(font)        # 设回去
```

**改字体的三步套路：拿 → 改 → 设。** `font()` 返回的是当前字体的**副本**，所以你改它不会影响别的控件，改完再 `setFont` 回去。

**`setPointSize(48)` 让数字变成 48 磅的大字**，视觉上像一个真正的计数器。磅（point）是印刷单位，1 磅 ≈ 1.33 像素。

## 第三部分：连接信号

**`self.on_plus` 和 `self.on_reset` 是实例方法，作为槽函数传给 connect。**

```
self.btn_plus.clicked.connect(self.on_plus)
self.btn_reset.clicked.connect(self.on_reset)
```

**注意 connect 写的是 `self.on_plus`，不是 `self.on_plus()`。** 这是第 4 课讲过的翻车点。

**槽函数实现：**

```
def on_plus(self):
    self.count += 1
    self.label.setText(str(self.count))

def on_reset(self):
    self.count = 0
    self.label.setText("0")
```

**`setText(str(self.count))` 要转成字符串**——QLabel 的文本必须是 str，int 不行。

## 第四部分：布局

**`QVBoxLayout(self)` 把布局直接设给窗口当主布局。** 这比先创建再 `self.setLayout(layout)` 少一行。

```
layout = QVBoxLayout(self)
layout.addWidget(self.label)
layout.addWidget(self.btn_plus)
layout.addWidget(self.btn_reset)
```

**控件按 addWidget 的顺序从上到下排列。** label 在最上，两个按钮在下面。布局会在第 6~10 课系统讲，这里先会用就行。

## 翻车现场一：忘了 super().__init__()

**症状**：程序启动时报错，或者窗口显示异常、控件不响应。

```
class CounterWindow(QWidget):
    def __init__(self):
        # super().__init__()   漏了！
        self.count = 0
        self.setWindowTitle("计数器")
```

**原因**：QWidget 的 `__init__` 负责创建原生窗口资源。不调用它，这个 QWidget 实例就没完成初始化，后续所有操作都在一个"半成品"上进行。

**解决**：**每个 QWidget 子类的 `__init__` 第一行必须是 `super().__init__()`**（或带 parent 的 `super().__init__(parent)`）。

## 翻车现场二：setLayout 和布局构造函数里传 self 混用

**症状**：控件不显示，或者报 `QWidget::setLayout: Cannot set layout for itself`。

```
layout = QVBoxLayout(self)      # 已经把 self 当 parent
self.setLayout(layout)          # 又设一次，冲突！
```

**原因**：`QVBoxLayout(self)` 时布局已经"认"了 self 当父容器，`setLayout` 又会再设一次，等于一个控件有两个布局。

**解决**：**二选一，不要两个都写。**

```
# 写法 A：构造函数里传 self（推荐，省一行）
layout = QVBoxLayout(self)

# 写法 B：先创建再 setLayout
layout = QVBoxLayout()
layout.addWidget(...)
self.setLayout(layout)
```

## 翻车现场三：setFont 之后字体没变

**症状**：代码里改了字号，界面上数字还是原来的大小。

```
self.label.font().setPointSize(48)   # 错误！
```

**原因**：`font()` 返回的是副本，你改了副本，但没把副本设回去。副本被丢弃了。

**解决**：**用"拿 → 改 → 设"三步：**

```
font = self.label.font()
font.setPointSize(48)
self.label.setFont(font)
```

## 扩展：禁用/启用按钮

**计数器可以加个上限，到 10 就禁用"+1"按钮。**

```
def on_plus(self):
    self.count += 1
    self.label.setText(str(self.count))
    if self.count >= 10:
        self.btn_plus.setEnabled(False)
```

**`setEnabled(False)` 让按钮变灰、不可点击。** 重置时再启用：

```
def on_reset(self):
    self.count = 0
    self.label.setText("0")
    self.btn_plus.setEnabled(True)
```

**这个交互在真实软件里非常常见**：表单未填完时"提交"按钮置灰，条件满足才解锁。

## 小结

- 用类组织窗口：状态存实例属性，槽函数用实例方法
- `__init__` 第一行必须 `super().__init__()`
- 改字体的三步：font() 拿副本 → setPointSize 改 → setFont 设回去
- connect 写函数对象，不加括号
- 布局：`QVBoxLayout(self)` 或 `setLayout`，二选一
- setEnabled(False) 让按钮变灰不可用
