# 实战：CSV ↔ JSON 互转工具

> 这一课把第 3 章全部串起来，做一个能在命令行里用的互转工具。重点是**类型还原**——CSV 里全是字符串，转 JSON 时必须还原成数字、布尔、null。

## 目标功能

我们要实现一个工具模块，支持：

1. `csv_to_json(text)`：CSV 文本 → JSON 字符串（带类型还原）
2. `json_to_csv(data)`：JSON 可序列化对象 → CSV 文本
3. 类型还原规则：看起来像数字就转 int/float，像布尔转 bool，`""` 转 null

## 为什么需要类型还原

CSV 是纯文本，所有值读出来都是字符串：

```python
import csv
import io

text = """name,age,score,active
张三,28,95.5,true
李四,35,88.0,false"""

reader = csv.DictReader(io.StringIO(text))
records = list(reader)
print(records)
```

输出：

```
[{'name': '张三', 'age': '28', 'score': '95.5', 'active': 'true'},
 {'name': '李四', 'age': '35', 'score': '88.0', 'active': 'false'}]
```

`age` 是字符串 `"28"`，`active` 是字符串 `"true"`。这不是我们想要的。

## 类型还原函数

写一个 `convert_value`：按规则尝试转换。

```python
def convert_value(s):
    """把 CSV 字符串尝试还原成更合适的类型。"""
    if s == "":
        return None
    if s.lower() == "true":
        return True
    if s.lower() == "false":
        return False
    if s.lower() == "null":
        return None
    # 尝试整数
    try:
        return int(s)
    except ValueError:
        pass
    # 尝试浮点
    try:
        return float(s)
    except ValueError:
        pass
    # 都不是，保留字符串
    return s
```

测试：

```python
for v in ["28", "95.5", "true", "false", "null", "", "张三"]:
    print(f"{v!r} -> {convert_value(v)!r}")
```

输出：

```
'28' -> 28
'95.5' -> 95.5
'true' -> True
'false' -> False
'null' -> None
'' -> None
'张三' -> '张三'
```

**顺序很关键**：先试 `int`，再试 `float`。如果先试 `float`，`"28"` 会变成 `28.0`。

## csv_to_json 完整实现

```python
import csv
import io
import json


def convert_value(s):
    if s == "":
        return None
    if s.lower() == "true":
        return True
    if s.lower() == "false":
        return False
    if s.lower() == "null":
        return None
    try:
        return int(s)
    except ValueError:
        pass
    try:
        return float(s)
    except ValueError:
        pass
    return s


def csv_to_json(text, indent=2):
    """CSV 文本 → 带类型还原的 JSON 字符串。"""
    reader = csv.DictReader(io.StringIO(text))
    records = []
    for row in reader:
        converted = {k: convert_value(v) for k, v in row.items()}
        records.append(converted)
    return json.dumps(records, ensure_ascii=False, indent=indent)


# 演示
text = """name,age,score,active
张三,28,95.5,true
李四,35,88.0,false"""

result = csv_to_json(text)
print(result)
```

输出：

```json
[
  {
    "name": "张三",
    "age": 28,
    "score": 95.5,
    "active": true
  },
  {
    "name": "李四",
    "age": 35,
    "score": 88.0,
    "active": false
  }
]
```

## json_to_csv：反向转换

把 JSON 对象列表转回 CSV。思路：先确定表头（取所有字典的键的并集），再逐行填值。

```python
def json_to_csv(data, fieldnames=None):
    """JSON 对象列表 → CSV 文本。"""
    if not isinstance(data, list) or not data:
        return ""

    # 确定列顺序：优先用传入的 fieldnames，否则按第一个对象的键
    if fieldnames is None:
        fieldnames = list(data[0].keys())

    buf = io.StringIO()
    writer = csv.DictWriter(buf, fieldnames=fieldnames, restval="", extrasaction="ignore")
    writer.writeheader()
    writer.writerows(data)
    return buf.getvalue()


# 演示
records = [
    {"name": "张三", "age": 28, "city": "北京"},
    {"name": "李四", "age": 35, "city": "上海"},
]
csv_text = json_to_csv(records)
print(csv_text)
```

输出：

```
name,age,city
张三,28,北京
李四,35,上海
```

## 翻车现场：JSON 里有嵌套对象

CSV 是"扁平表格"，装不下嵌套结构：

```python
# WRONG
data = [
    {"name": "张三", "address": {"city": "北京", "district": "海淀"}},
]
json_to_csv(data)
```

输出：

```
name,address
张三,"{'city': '北京', 'district': '海淀'}"
```

`address` 被当成普通值塞进去了。**正确做法**：展开嵌套键，或者先展平成 `address.city`、`address.district`。

```python
def flatten(obj, prefix=""):
    """把嵌套字典展平成带点号的扁平键。"""
    result = {}
    for k, v in obj.items():
        key = f"{prefix}.{k}" if prefix else k
        if isinstance(v, dict):
            result.update(flatten(v, key))
        else:
            result[key] = v
    return result

flat_records = [flatten(r) for r in data]
print(json_to_csv(flat_records))
```

输出：

```
name,address.city,address.district
张三,北京,海淀
```

## 加上命令行入口

```python
import sys
import json

def main():
    if len(sys.argv) < 3:
        print("用法: python conv.py csv2json <文件>  或  python conv.py json2csv <文件>")
        return

    mode = sys.argv[1]
    path = sys.argv[2]

    with open(path, encoding="utf-8") as f:
        content = f.read()

    if mode == "csv2json":
        # 判断是否有表头：简单起见假定有
        print(csv_to_json(content))
    elif mode == "json2csv":
        data = json.loads(content)
        print(json_to_csv(data))

if __name__ == "__main__":
    main()
```

跑一下：

```
$ python conv.py csv2json users.csv
$ python conv.py json2csv users.json
```

## 小结

- CSV 读出的值**全是字符串**，必须自己做类型还原
- 类型还原顺序：`""/null` → 布尔 → int → float → 保留字符串
- `csv_to_json`：DictReader 读 → 逐字段 convert_value → json.dumps
- `json_to_csv`：DictWriter + fieldnames + writeheader
- 嵌套对象 CSV 装不下，需先展平成点号键
- 整体是"读字符串 → 处理 → 写字符串"，可嵌入任何流程
