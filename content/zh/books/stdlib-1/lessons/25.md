# 实战：订单数据校验器

> 这是第 5 章的收尾大项目。把 `decimal`、`enum`、`dataclasses`、`json` 串起来，做一套能读入、校验、出报告的订单校验系统。

## 项目目标

我们要处理一批订单数据（来自 JSON），要求：

1. 金额用 `Decimal` 精确计算，不允许用 float
2. 订单状态用枚举，杜绝魔法字符串
3. 用 dataclass 承载订单结构
4. 校验每条订单：金额非负、状态合法、数量大于 0
5. 输出一份校验报告：通过几条、失败几条、失败原因

## 第一步：定义枚举和 dataclass

```python
from enum import Enum
from dataclasses import dataclass, field, asdict
from decimal import Decimal, ROUND_HALF_UP
import json

class OrderStatus(Enum):
    PENDING = "pending"
    PAID = "paid"
    SHIPPED = "shipped"
    CANCELLED = "cancelled"

@dataclass
class Order:
    id: str
    amount: Decimal
    status: OrderStatus
    qty: int

    @classmethod
    def from_dict(cls, d):
        return cls(
            id=d["id"],
            amount=Decimal(str(d["amount"])),
            status=OrderStatus(d["status"]),
            qty=int(d["qty"]),
        )
```

**注意 `amount=Decimal(str(d["amount"]))`**——外部数据一律字符串构造，不留 float 误差。

## 第二步：校验逻辑

```python
from dataclasses import dataclass
from decimal import Decimal, ROUND_HALF_UP
from enum import Enum
import json

class OrderStatus(Enum):
    PENDING = "pending"
    PAID = "paid"
    SHIPPED = "shipped"
    CANCELLED = "cancelled"

@dataclass
class Order:
    id: str
    amount: Decimal
    status: OrderStatus
    qty: int

    @classmethod
    def from_dict(cls, d):
        return cls(
            id=d["id"],
            amount=Decimal(str(d["amount"])),
            status=OrderStatus(d["status"]),
            qty=int(d["qty"]),
        )

def validate(order):
    """返回 (是否通过, 原因)"""
    if order.amount < 0:
        return False, "金额不能为负"
    if order.qty <= 0:
        return False, "数量必须大于 0"
    # 已支付的订单金额必须 >= 0.01
    if order.status == OrderStatus.PAID and order.amount < Decimal("0.01"):
        return False, "已支付订单金额不能为 0"
    return True, "ok"
```

校验函数返回元组 `(bool, str)`，便于汇总报告。

## 第三步：处理一批订单并出报告

```python
from decimal import Decimal, ROUND_HALF_UP
from enum import Enum
from dataclasses import dataclass, field, asdict
import json

class OrderStatus(Enum):
    PENDING = "pending"
    PAID = "paid"
    SHIPPED = "shipped"
    CANCELLED = "cancelled"

@dataclass
class Order:
    id: str
    amount: Decimal
    status: OrderStatus
    qty: int

    @classmethod
    def from_dict(cls, d):
        return cls(
            id=d["id"],
            amount=Decimal(str(d["amount"])),
            status=OrderStatus(d["status"]),
            qty=int(d["qty"]),
        )

def validate(order):
    if order.amount < 0:
        return False, "金额不能为负"
    if order.qty <= 0:
        return False, "数量必须大于 0"
    if order.status == OrderStatus.PAID and order.amount < Decimal("0.01"):
        return False, "已支付订单金额不能为 0"
    return True, "ok"

def process(raw_list):
    """接收原始字典列表，返回 (通过列表, 失败列表)"""
    passed = []
    failed = []
    for d in raw_list:
        try:
            order = Order.from_dict(d)
        except (ValueError, KeyError) as e:
            failed.append({"id": d.get("id", "?"), "reason": f"数据格式错误: {e}"})
            continue
        ok, reason = validate(order)
        if ok:
            passed.append(order)
        else:
            failed.append({"id": order.id, "reason": reason})
    return passed, failed

# 测试数据
data = [
    {"id": "A001", "amount": "19.90", "status": "paid", "qty": 2},
    {"id": "A002", "amount": "-5.00", "status": "pending", "qty": 1},
    {"id": "A003", "amount": "0", "status": "paid", "qty": 3},
    {"id": "A004", "amount": "9.99", "status": "shipped", "qty": 0},
]
passed, failed = process(data)
print(f"通过 {len(passed)} 条，失败 {len(failed)} 条")
for f in failed:
    print("  失败:", f)
```

输出：

```
通过 1 条，失败 3 条
  失败: {'id': 'A002', 'reason': '金额不能为负'}
  失败: {'id': 'A003', 'reason': '已支付订单金额不能为 0'}
  失败: {'id': 'A004', 'reason': '数量必须大于 0'}
```

## 翻车现场一：status 拼错导致崩溃

如果 JSON 里混进非法状态值，`OrderStatus(d["status"])` 会抛 `ValueError`：

```python
from enum import Enum

class OrderStatus(Enum):
    PENDING = "pending"
    PAID = "paid"

# WRONG：非法值
# OrderStatus("unknow")      # ValueError
```

**上面 `process` 函数已经用 try/except 兜住**——捕获 `ValueError` 和 `KeyError`，把格式错误的记录归到失败列表，不会让整个批次挂掉。

## 翻车现场二：金额用 float 构造会失精

```python
from decimal import Decimal

# WRONG
print(Decimal(19.90))     # 带 float 误差
# 正确
print(Decimal("19.90"))
```

输出：

```
19.9000000000000003552713678800500929355621337890625
19.90
```

`Order.from_dict` 里用了 `Decimal(str(d["amount"]))`，即使传进来是数字也能正确构造。

## 报告输出：转成 JSON

把报告序列化成 JSON，注意 Decimal 和 Enum 都要转：

```python
from decimal import Decimal, ROUND_HALF_UP
from enum import Enum
from dataclasses import dataclass, field, asdict
import json

class OrderStatus(Enum):
    PENDING = "pending"
    PAID = "paid"
    SHIPPED = "shipped"
    CANCELLED = "cancelled"

@dataclass
class Order:
    id: str
    amount: Decimal
    status: OrderStatus
    qty: int

    @classmethod
    def from_dict(cls, d):
        return cls(
            id=d["id"],
            amount=Decimal(str(d["amount"])),
            status=OrderStatus(d["status"]),
            qty=int(d["qty"]),
        )

def order_to_dict(order):
    d = asdict(order)
    d["amount"] = str(order.amount)       # Decimal -> str
    d["status"] = order.status.value      # Enum -> value
    return d

passed = [Order("A001", Decimal("19.90"), OrderStatus.PAID, 2)]
report = {
    "passed": [order_to_dict(o) for o in passed],
}
print(json.dumps(report, ensure_ascii=False, indent=2))
```

输出：

```
{
  "passed": [
    {
      "id": "A001",
      "amount": "19.90",
      "status": "paid",
      "qty": 2
    }
  ]
}
```

**`asdict` 只转一层**，Decimal 和 Enum 仍需手动处理——这是综合实战里最常见的坑。

## 完整流程图

整个校验器的工作流：

```
原始 JSON 列表
   ↓ from_dict（Decimal 字符串构造、Enum 取值）
Order dataclass 实例
   ↓ validate
(通过, "ok") / (False, 原因)
   ↓ 分流
通过列表 / 失败列表
   ↓ order_to_dict（Decimal→str, Enum→value）
JSON 报告
```

## 小结

- 金额一律 `Decimal(str(...))` 构造，全程精确
- 状态用 `Enum`，`Status(value)` 反查，非法值用 try/except 兜住
- dataclass 承载结构，`asdict` 做第一层序列化
- Decimal/Enum 需要手动转成 str/value 才能进 JSON
- 校验函数返回 `(bool, str)`，便于汇总报告
- 综合实战就是把前面几课的工具组合起来各司其职
