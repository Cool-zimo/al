# enum：用枚举干掉魔法字符串

> 代码里满屏 `"pending"`、`"paid"`、`"shipped"`？这一课用 `enum` 把它们收进一个有名字、有类型的枚举类，再也不会拼错。

## 为什么需要枚举

先看没有枚举的痛苦：

```python
STATUS_PENDING = "pending"
STATUS_PAID = "paid"
STATUS_SHIPPED = "shipped"

def handle(status):
    if status == "pading":      # 拼错了，还不会报错
        print("处理")
```

`"pading"` 拼错了，Python 静默通过，上线后才发现。用枚举从类型层面杜绝：

```python
from enum import Enum

class Status(Enum):
    PENDING = "pending"
    PAID = "paid"
    SHIPPED = "shipped"

print(Status.PENDING)
print(Status.PENDING.value)
```

输出：

```
Status.PENDING
pending
```

`Status.PENDING` 是枚举成员，`.value` 才是背后的字符串。

## IntEnum 与 auto()：自动编号

如果值是整数，用 `IntEnum`；想自动分配值，用 `auto()`：

```python
from enum import IntEnum, auto

class Level(IntEnum):
    LOW = auto()       # 1
    MID = auto()       # 2
    HIGH = auto()      # 3

print(Level.LOW)
print(Level.LOW.value)
print(Level.LOW == 1)      # True：IntEnum 可与 int 比较
```

输出：

```
Level.LOW
1
True
```

**`auto()` 从 1 开始自增**。普通 `Enum` 的成员不能和整数直接比较，`IntEnum` 可以（因为它就是 int 的子类）。

## 遍历与取值

枚举可以遍历、可以通过值反查成员：

```python
from enum import Enum

class Status(Enum):
    PENDING = "pending"
    PAID = "paid"
    SHIPPED = "shipped"

# 遍历
for s in Status:
    print(s.name, s.value)

print("---")
# 通过值反查
print(Status("pending"))
print(Status["PENDING"])
```

输出：

```
PENDING pending
PAID paid
SHIPPED shipped
---
Status.PENDING
Status.PENDING
```

`Status("pending")` 用值反查成员，`Status["PENDING"]` 用名字取成员。

## 翻车现场一：枚举成员不可比较，除非是 IntEnum

普通 `Enum` 成员**不能**和 `.value` 直接比：

```python
from enum import Enum

class Status(Enum):
    PENDING = "pending"
    PAID = "paid"

# WRONG：枚举成员和字符串比，永远是 False
print(Status.PAID == "paid")
```

输出：

```
False
```

`Status.PAID == "paid"` 是 False！**要用 `.value`**：

```python
from enum import Enum

class Status(Enum):
    PENDING = "pending"
    PAID = "paid"

print(Status.PAID.value == "paid")     # True
print(Status.PAID is Status.PAID)      # True
```

## 翻车现场二：JSON 序列化枚举会报错

直接 `json.dumps(Status.PAID)` 会抛 `TypeError`，因为 JSON 不认识枚举：

```python
import json
from enum import Enum

class Status(Enum):
    PAID = "paid"

# WRONG
# json.dumps(Status.PAID)      # TypeError
```

**解决方法：用 `.value` 转成字符串，或写自定义编码器**：

```python
import json
from enum import Enum

class Status(Enum):
    PAID = "paid"
    SHIPPED = "shipped"

# 方法一：直接取 .value
print(json.dumps(Status.PAID.value))

# 方法二：自定义编码器
class EnumEncoder(json.JSONEncoder):
    def default(self, obj):
        if isinstance(obj, Enum):
            return obj.value
        return super().default(obj)

print(json.dumps(Status.SHIPPED, cls=EnumEncoder))
```

输出：

```
"paid"
"shipped"
```

## .value vs .name 怎么选

| 场景 | 用 | 例子 |
| --- | --- | --- |
| 存数据库、写 JSON、对外接口 | `.value` | `"paid"` |
| 日志、调试、给人看 | `.name` | `"PAID"` |
| 反查成员 | `Enum(value)` | `Status("paid")` |
| 按名字取 | `Enum[name]` | `Status["PAID"]` |

`.value` 是业务值，`.name` 是代码里的名字，两者不要混用。

## 小结

- 枚举替代魔法字符串，`Status.PENDING` 比 `"pending"` 安全
- `Enum` 成员和值比较要用 `.value`；`IntEnum` 可直接与 int 比
- `auto()` 自动编号，`Status(value)` 反查成员
- JSON 序列化要用 `.value` 或自定义 `JSONEncoder`
- `.value` 用于持久化，`.name` 用于日志调试
