# 第 28 课 · 数据管道：清洗与校验

> 校验的核心原则——**收集所有错误，而不是遇到第一个就崩**。

## 逐条校验

转换层输出标准 `dict` 列表后，校验层逐条检查。每条记录可能有多个问题，我们要全部找出来：

```python
from decimal import Decimal, InvalidOperation
from enum import Enum

class Status(Enum):
    PENDING = "pending"
    PAID = "paid"
    SHIPPED = "shipped"

def validate(record):
    """返回错误列表，空列表表示通过"""
    errors = []
    
    # 检查 id
    if not record.get("id"):
        errors.append("缺少 id")
    
    # 检查 amount
    try:
        amount = Decimal(record["amount"])
    except (InvalidOperation, KeyError, TypeError):
        errors.append(f"金额非法: {record.get('amount')}")
        amount = None
    
    if amount is not None and amount < 0:
        errors.append(f"金额不能为负: {amount}")
    
    # 检查 qty
    qty = record.get("qty", 0)
    if qty <= 0:
        errors.append(f"数量必须大于 0: {qty}")
    
    # 检查 status
    status_str = record.get("status")
    try:
        Status(status_str)
    except ValueError:
        errors.append(f"状态非法: {status_str}")
    
    return errors
```

**`validate` 返回错误列表而不是抛异常**——一条记录的所有问题都会被收集到，而不是第一个问题就中断。

## 分批处理：通过的进一个桶，失败的进另一个桶

```python
from decimal import Decimal, InvalidOperation
from enum import Enum

class Status(Enum):
    PENDING = "pending"
    PAID = "paid"
    SHIPPED = "shipped"

def validate(record):
    errors = []
    if not record.get("id"):
        errors.append("缺少 id")
    try:
        amount = Decimal(str(record.get("amount", "")))
    except InvalidOperation:
        errors.append(f"金额非法: {record.get('amount')}")
        amount = None
    if amount is not None and amount < 0:
        errors.append(f"金额不能为负: {amount}")
    qty = int(record.get("qty", 0))
    if qty <= 0:
        errors.append(f"数量必须大于 0: {qty}")
    status_str = record.get("status")
    try:
        Status(status_str)
    except ValueError:
        errors.append(f"状态非法: {status_str}")
    return errors

def check_all(records):
    passed = []
    failed = []
    for rec in records:
        errors = validate(rec)
        if errors:
            failed.append({"record": rec, "errors": errors})
        else:
            passed.append(rec)
    return passed, failed

# 测试
data = [
    {"id": "T001", "amount": "19.90", "status": "paid", "qty": 2},
    {"id": "",    "amount": "-5.00", "status": "pending", "qty": 0},
    {"id": "T003", "amount": "abc",  "status": "UNKNOWN", "qty": 1},
    {"id": "T004", "amount": "9.99", "status": "shipped", "qty": 3},
]

passed, failed = check_all(data)
print(f"通过 {len(passed)} 条，失败 {len(failed)} 条")
for f in failed:
    print(f"  {f['record']['id'] or '(无id)'}: {f['errors']}")
```

输出：

```
通过 2 条，失败 2 条
  (无id): ['缺少 id', '金额不能为负: -5.00', '数量必须大于 0: 0']
  T003: ['金额非法: abc', '状态非法: UNKNOWN']
```

**注意 T003 同时报了两个错误**——这就是"收集所有错误"的价值。如果只报第一个错误，用户要反复跑程序才能把所有问题找全。

## 出报告

校验完要给用户一份清晰的报告：

```python
def make_report(passed, failed):
    lines = []
    lines.append(f"=== 数据校验报告 ===")
    lines.append(f"总计: {len(passed) + len(failed)} 条")
    lines.append(f"通过: {len(passed)} 条")
    lines.append(f"失败: {len(failed)} 条")
    lines.append("")
    if failed:
        lines.append("--- 失败详情 ---")
        for f in failed:
            rid = f["record"].get("id") or "(无id)"
            lines.append(f"[{rid}]")
            for err in f["errors"]:
                lines.append(f"  ✗ {err}")
    return "\n".join(lines)

print(make_report(passed, failed))
```

输出：

```
=== 数据校验报告 ===
总计: 4 条
通过: 2 条
失败: 2 条

--- 失败详情 ---
[(无id)]
  ✗ 缺少 id
  ✗ 金额不能为负: -5.00
  ✗ 数量必须大于 0: 0
[T003]
  ✗ 金额非法: abc
  ✗ 状态非法: UNKNOWN
```

## 严格模式 vs 宽松模式

有时候你想"宁可少处理也不要脏数据"，有时候你想"尽量多处理，脏数据单独放"。两种策略都可以：

```python
def check_all(records, strict=False):
    passed = []
    failed = []
    for rec in records:
        errors = validate(rec)
        if errors:
            failed.append({"record": rec, "errors": errors})
            if strict:
                # 严格模式：遇到任何错误就停止
                break
        else:
            passed.append(rec)
    return passed, failed
```

**默认宽松、可选严格**——这是 CLI 工具的常见设计。用户可以通过参数选择策略。

## 小结

- 校验函数返回错误列表，收集一条记录的所有问题
- `Decimal` 构造用 try/except 兜住非法值
- `Enum(value)` 反查状态，非法值抛 `ValueError` 捕获
- 分批处理：通过的进 `passed`，失败的进 `failed` 并附带错误列表
- 报告要清晰展示每条记录的每个问题
- 可选严格模式，遇到错误立即停止

## 翻车现场一：Decimal 构造空字符串

```python
from decimal import Decimal, InvalidOperation

# WRONG
# Decimal("")        # InvalidOperation: Invalid literal for Decimal

# 正确：先判断空值
s = ""
if s.strip():
    d = Decimal(s)
else:
    print("金额为空")
```

**空字符串不能构造 Decimal**。校验时要么提前判断，要么用 try/except 兜住 `InvalidOperation`。

## 翻车现场二：INI 里数字全是字符串

```python
import configparser

cp = configparser.ConfigParser()
# cp.read(...) 省略
# WRONG
# qty = cp["T001"]["qty"]   # str '2'，直接和 int 比较会出错
# if qty > 0: ...            # TypeError

# 正确：手动转类型
qty = int(cp["T001"]["qty"])
print(qty > 0)
```

**INI 没有类型系统，所有值都是 str**。读取后必须显式转换，否则类型比较会出 `TypeError`。
