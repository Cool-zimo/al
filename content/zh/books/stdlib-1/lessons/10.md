# 实战：一个配置读写模块

> 这一课把第 2 章学的所有东西串起来：读配置、改配置、写回文件，还要带默认值和容错。做完你会拥有一个能直接用在自己项目里的 `config.py`。

## 一个真实场景

张三在写一个命令行工具，需要保存用户的偏好：默认城市、每页显示条数、是否开启深色模式。他打算用 JSON 文件存。

```python
import json

DEFAULT_CONFIG = {
    "city": "北京",
    "page_size": 20,
    "dark_mode": False,
}

def load_config(path):
    with open(path, encoding="utf-8") as f:
        return json.load(f)

def save_config(path, config):
    with open(path, "w", encoding="utf-8") as f:
        json.dump(config, f, ensure_ascii=False, indent=2)
```

看起来没问题。但真实环境远比这残酷。

## 翻车现场一：文件不存在就崩溃

```python
# WRONG
import json

with open("config.json", encoding="utf-8") as f:
    config = json.load(f)
# FileNotFoundError: [Errno 2] No such file or directory: 'config.json'
```

用户第一次运行程序，配置文件还没创建，直接 `open` 就读，必然报错。**正确做法：捕获异常，返回默认值。**

```python
import json

DEFAULT_CONFIG = {
    "city": "北京",
    "page_size": 20,
    "dark_mode": False,
}

def load_config(path):
    try:
        with open(path, encoding="utf-8") as f:
            return json.load(f)
    except FileNotFoundError:
        return dict(DEFAULT_CONFIG)   # 返回默认配置的副本
```

为什么用 `dict(DEFAULT_CONFIG)` 而不是 `DEFAULT_CONFIG`？因为如果直接返回原字典，用户修改后会影响全局默认值。

## 翻车现场二：配置文件是坏 JSON

```python
# WRONG
# config.json 里写的是：{"city": "北京", "page_size": 20, dark_mode: False}
# 最后一个键没加引号，是无效 JSON

import json
json.load(open("config.json", encoding="utf-8"))
# json.decoder.JSONDecodeError: Expecting property name enclosed in double quotes
```

用户手改了配置文件，写错了。**正确做法：捕获 `JSONDecodeError`，给一个提示并回退默认值。**

```python
import json
from json import JSONDecodeError

def load_config(path):
    try:
        with open(path, encoding="utf-8") as f:
            return json.load(f)
    except FileNotFoundError:
        return dict(DEFAULT_CONFIG)
    except JSONDecodeError:
        print("配置文件格式错误，使用默认配置")
        return dict(DEFAULT_CONFIG)
```

## 补全缺失的字段：get 的默认值兜底

用户手里有一份旧配置，只有 `"city"` 没有 `"page_size"` 和 `"dark_mode"`。直接读出来用，访问不存在的键会 `KeyError`。

```python
config = load_config("config.json")
config.setdefault("page_size", DEFAULT_CONFIG["page_size"])
config.setdefault("dark_mode", DEFAULT_CONFIG["dark_mode"])
```

或者更简洁地**用默认值打底、再用读到的配置覆盖**：

```python
def load_config(path):
    cfg = dict(DEFAULT_CONFIG)          # 先拿全量默认值
    try:
        with open(path, encoding="utf-8") as f:
            user_cfg = json.load(f)
        cfg.update(user_cfg)            # 用户配置覆盖默认值
    except (FileNotFoundError, JSONDecodeError):
        pass
    return cfg
```

`dict.update` 只覆盖已存在的键，缺失的保持默认——这样不管用户配置缺多少字段都不会崩。

## 完整模块：config.py

把上面所有考虑合在一起，一个能直接用的配置模块长这样：

```python
import json
from json import JSONDecodeError

DEFAULT_CONFIG = {
    "city": "北京",
    "page_size": 20,
    "dark_mode": False,
}


def load_config(path):
    """读取配置。文件不存在/格式错误时返回默认配置。"""
    cfg = dict(DEFAULT_CONFIG)
    try:
        with open(path, encoding="utf-8") as f:
            user_cfg = json.load(f)
        if isinstance(user_cfg, dict):
            cfg.update(user_cfg)
        else:
            print("配置文件根节点不是对象，使用默认配置")
    except FileNotFoundError:
        pass
    except JSONDecodeError:
        print("配置文件格式错误，使用默认配置")
    return cfg


def save_config(path, config):
    """把配置写回文件，缩进 2 空格、中文不转义。"""
    with open(path, "w", encoding="utf-8") as f:
        json.dump(config, f, ensure_ascii=False, indent=2)


def get(config, key, default=None):
    """安全取值：键不存在返回 default。"""
    return config.get(key, default)


def set_and_save(path, config, key, value):
    """改一个字段并立即写回。"""
    config[key] = value
    save_config(path, config)
```

**注意 `load_config` 里多了一层 `isinstance(user_cfg, dict)` 检查**：如果配置文件根节点是字符串或数组，`update` 会报错，这里兜底一下。

## 使用演示

```python
import os

path = "app_config.json"

# 第一次运行：文件不存在，返回默认配置
cfg = load_config(path)
print(cfg)                      # {'city': '北京', 'page_size': 20, 'dark_mode': False}

# 改配置并保存
cfg["city"] = "上海"
cfg["page_size"] = 50
save_config(path, cfg)

# 再次读取
cfg2 = load_config(path)
print(cfg2["city"], cfg2["page_size"])   # 上海 50

# 清理演示文件
os.remove(path)
```

输出：

```
{'city': '北京', 'page_size': 20, 'dark_mode': False}
上海 50
```

整个流程是**读取 → 内存修改 → 写回**，用户无感知地持久化。

## 小结

- 配置读写的核心是 `load_config` + `save_config` 两个函数
- 用 `dict(DEFAULT_CONFIG)` 先打底，再用 `update` 覆盖，自动补全缺失字段
- 捕获 `FileNotFoundError` 和 `JSONDecodeError`，容错不崩溃
- 写回用 `ensure_ascii=False, indent=2`，中文可读、格式美观
- 模块化的好处：所有调用方都用 `load_config`，不用到处写 `try/except`
