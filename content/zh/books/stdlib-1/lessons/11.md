# csv 模块与为什么不能自己 split(',')

> 这一课告诉你：CSV 看似简单，但引号里的逗号、字段里的换行会让你手写的解析器全线崩溃。Python 标准库的 `csv` 模块就是为这些坑而生的。

## CSV 到底是什么

CSV = Comma-Separated Values（逗号分隔值）。每行是一条记录，字段之间用逗号隔开，第一行通常是表头。

```csv
name,age,city
张三,28,北京
李四,35,上海
```

看着太简单了，于是很多人写出这样的代码：

```python
# WRONG
line = "张三,28,北京"
fields = line.split(",")
print(fields)        # ['张三', '28', '北京']
```

能跑。但**只在第一行能跑**。

## 翻车现场一：字段里带逗号

```python
# WRONG
line = '张三,"北京,朝阳区",28'
fields = line.split(",")
print(fields)
```

输出：

```
['张三', '"北京', '朝阳区"', '28']
```

裂开了。真实地址是"北京,朝阳区"，应该算一个字段，但 `split` 不管三七二十一就在逗号处切。

**正确做法**：用 `csv.reader`，它会识别双引号包裹的字段。

```python
import csv
import io

line = '张三,"北京,朝阳区",28\n'
reader = csv.reader(io.StringIO(line))
for row in reader:
    print(row)
```

输出：

```
['张三', '北京,朝阳区', '28']
```

`csv.reader` 知道：**引号内的逗号不是分隔符**。这是它和 `split` 最本质的区别。

## 翻车现场二：字段里带换行符

CSV 规范允许字段内部包含换行符，只要该字段用双引号包住：

```csv
name,remark
张三,"第一次来
北京出差",2026-01-01
```

```python
# WRONG
text = '''name,remark
张三,"第一次来
北京出差",2026-01-01'''

lines = text.split("\n")
print(len(lines))        # 3 —— 但只有 2 行数据！
```

用 `split("\n")` 会把一条记录切成两半。`csv.reader` 能正确处理：

```python
import csv
import io

reader = csv.reader(io.StringIO(text))
for row in reader:
    print(row)
```

输出：

```
['name', 'remark']
['张三', '第一次来\n北京出差', '2026-01-01']
```

换行符被保留在字段内部，没有被当成记录分隔符。

## 为什么一定要用 csv 模块

| 情况 | `split(",")` | `csv.reader` |
|---|---|---|
| 普通无逗号字段 | 能用 | 能用 |
| 引号内有逗号 | 崩 | 正确 |
| 字段内有换行 | 崩 | 正确 |
| 引号内有引号（转义） | 崩 | 正确（按 `""` 处理） |
| 不同分隔符（制表符等） | 改 split | 改 `delimiter` |

CSV 格式"看起来是纯文本协议"，但 RFC 4180 规范里关于引号和换行的规则有十几条。`csv` 模块帮你实现了全部。

## 最小可用：读一个 CSV 文本

```python
import csv
import io

text = """name,age,city
张三,28,北京
李四,35,上海
王五,42,广州"""

reader = csv.reader(io.StringIO(text))
for row in reader:
    print(row)
```

输出：

```
['name', 'age', 'city']
['张三', '28', '北京']
['李四', '35', '上海']
['王五', '42', '广州']
```

`io.StringIO` 把字符串当成一个"文件"喂给 `reader`，这在 Pyodide/判分环境里尤其方便，因为不依赖真实文件系统。

## 写入也别自己拼逗号

```python
# WRONG
rows = [["张三", "北京,朝阳区", 28], ["李四", "上海", 35]]
for r in rows:
    line = ",".join(str(x) for x in r)
    print(line)
```

输出：

```
张三,北京,朝阳区,28       # 字段被切开了
李四,上海,35
```

**正确做法**：用 `csv.writer`。

```python
import csv
import io

buf = io.StringIO()
writer = csv.writer(buf)
writer.writerow(["name", "address", "age"])
writer.writerow(["张三", "北京,朝阳区", 28])
writer.writerow(["李四", "上海", 35])

print(buf.getvalue())
```

输出：

```
name,address,age
"张三","北京,朝阳区",28
"李四","上海",35
```

`csv.writer` 会自动给含逗号（或换行）的字段加上双引号。

## 翻车现场三：忘了 newline='' 导致多空行

（这个坑会在第 12 课详细讲，先预告一下）

```python
# WRONG：在 Windows 上用默认模式写 CSV
import csv

with open("out.csv", "w", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["a", "b"])
    writer.writerow(["c", "d"])
```

在 Windows 上，每行之间会多一个空行。原因是 `csv` 模块自己管换行，而你打开文件时 Python 又加了一次换行转换，两层叠加就空行了。**解决：加 `newline=''`**。

## 小结

- CSV **不是简单的"按逗号切"**，引号内的逗号、字段内换行都会让 `split` 崩溃
- `csv.reader` 遵守 RFC 4180，正确处理引号、换行、转义
- 用 `io.StringIO` 把字符串当文件传给 reader/writer，方便测试
- 写入用 `csv.writer`，它会自动给含特殊字符的字段加引号
- 别忘了 `newline=''`——下一课详细讲
