# dataclasses：少写 80% 样板代码的数据类

> 一个存数据的类，要写 `__init__`、`__repr__`、`__eq__`……写三遍就想吐。这一课用 `@dataclass` 自动生成，让你专注字段本身。

## 普通类 vs dataclass：样板代码对比

先看没有 dataclass 的痛苦：

```python
class Product:
    def __init__(self, name, price, qty):
        self.name = name
        self.price = price
        self.qty = qty

    def __repr__(self):
        return f"Product(name={self.name!r}, price={self.price!r}, qty={self.qty!r})"

    def __eq__(self, other):
        if not isinstance(other, Product):
            return NotImplemented
        return (self.name, self.price, self.qty) == (other.name, other.price, other.qty)
```

再看成 dataclass 之后：

```python
from dataclasses import dataclass

@dataclass
class Product:
    name: str
    price: float
    qty: int

p = Product("键盘", 199.0, 3)
print(p)
print(p == Product("键盘", 199.0, 3))
```

输出：

```
Product(name='键盘', price=199.0, qty=3)
True
```

**`@dataclass` 一行装饰器，自动生成 `__init__`、`__repr__`、`__eq__`**。字段类型注解就是声明，Python 会自动生成初始化方法。

## 常用参数

| 参数 | 作用 |
| --- | --- |
| `frozen=True` | 冻结实例，不可修改（类似元组） |
| `order=True` | 自动生成比较方法（`__lt__` 等），可按字段排序 |
| `slots=True` | 用 `__slots__` 省内存（Python 3.10+） |
| `kw_only=True` | 强制关键字传参 |

```python
from dataclasses import dataclass

@dataclass(frozen=True, order=True)
class Item:
    name: str
    price: float

a = Item("A", 10)
# a.price = 20   # 报错：frozen
items = [Item("B", 5), Item("C", 15), Item("A", 10)]
print(sorted(items))     # 按 price 排序
```

输出：

```
[Item(name='B', price=5), Item(name='A', price=10), Item(name='C', price=15)]
```

## 翻车现场一：可变默认值用 `[]` 会共享

**这是 Python 的经典坑，dataclass 里依然存在**。直接用 `[]` 作默认值，所有实例共享同一个列表：

```python
from dataclasses import dataclass

@dataclass
class Cart:
    items: list = []        # WRONG

c1 = Cart()
c2 = Cart()
c1.items.append("苹果")
print(c2.items)            # 居然也有 苹果！
```

输出：

```
['苹果']
```

`c1` 和 `c2` 的 `items` 指向**同一个列表**，c1 改了 c2 也跟着变。这是所有 Python 人都踩过的坑。

**正确做法：用 `field(default_factory=list)`**：

```python
from dataclasses import dataclass, field

@dataclass
class Cart:
    items: list = field(default_factory=list)

c1 = Cart()
c2 = Cart()
c1.items.append("苹果")
print(c1.items)            # ['苹果']
print(c2.items)            # []
```

输出：

```
['苹果']
[]
```

`default_factory` 每次实例化都会**调用一次** `list()`，拿到全新空列表，互不影响。

## 翻车现场二：`asdict` 返回的是嵌套 dict，不是 JSON

`asdict()` 能把 dataclass 递归转成字典，方便序列化：

```python
from dataclasses import dataclass, asdict
import json

@dataclass
class Address:
    city: str
    street: str

@dataclass
class User:
    name: str
    addr: Address

u = User("张三", Address("北京", "长安街"))
d = asdict(u)
print(d)
print(json.dumps(d, ensure_ascii=False))
```

输出：

```
{'name': '张三', 'addr': {'city': '北京', 'street': '长安街'}}
{"name": "张三", "addr": {"city": "北京", "street": "长安街"}}
```

**坑在哪**：`asdict()` 只负责转 dict，**不会帮你做 json.dumps**。而且它返回的是**新对象**（深拷贝），改 dict 不影响原实例：

```python
from dataclasses import dataclass, asdict

@dataclass
class Point:
    x: int
    y: int

p = Point(1, 2)
d = asdict(p)
d["x"] = 999
print(p)        # Point(x=1, y=2) 没变
```

输出：

```
Point(x=1, y=2)
```

## field 的常用选项

| 选项 | 作用 |
| --- | --- |
| `default` | 默认值（不可变对象） |
| `default_factory` | 工厂函数，生成默认值（可变对象用这个） |
| `init=False` | 不进 `__init__` |
| `repr=False` | 不进 `__repr__` |
| `compare=False` | 不参与 `__eq__` 比较 |

```python
from dataclasses import dataclass, field

@dataclass
class Order:
    id: str
    items: list = field(default_factory=list)
    tax: float = 0.13
    _internal: str = field(default="", repr=False, init=False)

o = Order("A001")
print(o)
```

输出：

```
Order(id='A001', items=[], tax=0.13)
```

`_internal` 没出现在 repr 里，因为 `repr=False`。

## 小结

- `@dataclass` 自动生成 `__init__`、`__repr__`、`__eq__`，省下大量样板
- `frozen=True` 冻结、`order=True` 支持比较排序
- **可变默认值用 `field(default_factory=list)`**，别用 `[]` 或 `{}`
- `asdict()` 递归转字典，是序列化第一步，返回深拷贝
- `field(repr=False, init=False, compare=False)` 精细控制字段行为
