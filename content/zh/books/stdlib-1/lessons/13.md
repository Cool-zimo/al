# DictReader / DictWriter：按列名读写

> 上一课用索引取列（`row[0]`、`row[1]`）很脆——表头一变就全错。这一课用列名代替索引，代码更稳、更易读。

## DictReader：每行是一个字典

`csv.DictReader` 和 `reader` 的唯一区别：**它把表头当键，每行变成一个字典**。

```python
import csv
import io

text = """name,age,city
张三,28,北京
李四,35,上海"""

reader = csv.DictReader(io.StringIO(text))
for row in reader:
    print(type(row).__name__, row)
```

输出：

```
dict {'name': '张三', 'age': '28', 'city': '北京'}
dict {'name': '李四', 'age': '35', 'city': '上海'}
```

取值方式从 `row[1]` 变成 `row["age"]`——**按列名取，表头换顺序也不影响代码**。

## 表头不是第一行怎么办

有些 CSV 前面几行是说明文字，真正表头在第 3 行：

```python
import csv
import io

text = """# 这是数据导出
# 日期：2026-09-27
name,age,city
张三,28,北京"""

reader = csv.DictReader(io.StringIO(text), skipinitialspace=True)
# 默认第一行就是表头，会出问题
for row in reader:
    print(row)
```

输出（错误）：

```
{'# 这是数据导出': 'name', '# 日期：2026-09-27': 'age', 'name,age,city': '张三,28,北京'}
```

用 `fieldnames` 显式指定表头行：

```python
import csv
import io

text = """# 这是数据导出
name,age,city
张三,28,北京
李四,35,上海"""

reader = csv.DictReader(io.StringIO(text), fieldnames=None)
# 或者跳过前两行
lines = text.split("\n")
data_text = "\n".join(lines[1:])      # 去掉说明行

reader = csv.DictReader(io.StringIO(data_text))
for row in reader:
    print(row["name"], row["city"])
```

输出：

```
张三 北京
李四 上海
```

## fieldnames：写的时候指定列顺序

`csv.DictWriter` 写字典时，**必须告诉它列的顺序**，因为字典本身不保证顺序（Python 3.7+ 虽然保插入序，但写文件时你往往想控制输出顺序）。

```python
import csv
import io

buf = io.StringIO()
fieldnames = ["name", "city", "age"]          # 想输出的列顺序

writer = csv.DictWriter(buf, fieldnames=fieldnames)
writer.writeheader()                           # 写表头
writer.writerow({"name": "张三", "age": 28, "city": "北京"})
writer.writerow({"name": "李四", "age": 35, "city": "上海"})

print(buf.getvalue())
```

输出：

```
name,city,age
张三,北京,28
李四,上海,35
```

注意：**`fieldnames` 的顺序是 `name, city, age`，所以输出列也是这个顺序**，尽管字典里 `age` 写在前面。

## 翻车现场：忘写 writeheader

```python
# WRONG
import csv
import io

buf = io.StringIO()
writer = csv.DictWriter(buf, fieldnames=["name", "age"])
writer.writerow({"name": "张三", "age": 28})
print(repr(buf.getvalue()))
```

输出：

```
'张三,28\n'
```

**没有表头行**！数据直接写出去了，读回来时不知道哪一列是什么。

**正确做法**：`DictWriter` 写完必须先调 `writeheader()`。

```python
import csv
import io

buf = io.StringIO()
writer = csv.DictWriter(buf, fieldnames=["name", "age"])
writer.writeheader()               # ← 不能忘
writer.writerow({"name": "张三", "age": 28})
print(buf.getvalue())
```

输出：

```
name,age
张三,28
```

## 字典缺键怎么办：restval 与 extrasaction

### 缺失键 → restval

```python
import csv
import io

buf = io.StringIO()
writer = csv.DictWriter(buf, fieldnames=["name", "age", "city"], restval="未知")
writer.writeheader()
writer.writerow({"name": "张三", "age": 28})    # 缺 city
print(buf.getvalue())
```

输出：

```
name,age,city
张三,28,未知
```

`restval="未知"` 表示：字典里没有对应键时，填 `"未知"`（默认是空字符串 `""`）。

### 多了键 → extrasaction

```python
# WRONG
import csv
import io

buf = io.StringIO()
writer = csv.DictWriter(buf, fieldnames=["name", "age"])
writer.writeheader()
writer.writerow({"name": "张三", "age": 28, "extra": "多余"})   # 多了 extra
# ValueError: dict contains fields not in fieldnames: 'extra'
```

**解决**：`extrasaction="ignore"`。

```python
import csv
import io

buf = io.StringIO()
writer = csv.DictWriter(buf, fieldnames=["name", "age"], extrasaction="ignore")
writer.writeheader()
writer.writerow({"name": "张三", "age": 28, "extra": "多余"})
print(buf.getvalue())
```

输出：

```
name,age
张三,28
```

多余的键被安静地丢弃。

## DictReader + DictWriter 完整流程

```python
import csv
import io

src = """name,age,city
张三,28,北京
李四,35,上海"""

# 读
reader = csv.DictReader(io.StringIO(src))
records = list(reader)
for r in records:
    r["age"] = str(int(r["age"]) + 1)     # 年龄+1

# 写
buf = io.StringIO()
writer = csv.DictWriter(buf, fieldnames=["name", "age", "city"], restval="")
writer.writeheader()
writer.writerows(records)

print(buf.getvalue())
```

输出：

```
name,age,city
张三,29,北京
李四,36,上海
```

按列名读写，代码一眼就能看懂在做什么。

## 小结

- `DictReader` 把每行变成 `{列名: 值}` 的字典，按 `row["列名"]` 取值
- 表头不在第一行时，可用 `fieldnames` 或预处理文本
- `DictWriter` **必须传 `fieldnames`** 控制输出列顺序
- **写完先调 `writeheader()`**，否则没有表头行
- `restval` 处理缺键，`extrasaction="ignore"` 忽略多出的键
- 按列名比按索引稳得多，表头换顺序不影响逻辑
