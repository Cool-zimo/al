# configparser：INI 配置文件怎么读

> 这一课解决"程序启动时怎么读配置"。你不用再手写 `key=value` 的解析器——标准库自带一个，叫 `configparser`。学完你会明白：它读出来的**全是字符串**，这是新手掉坑最密集的地方。

## INI 文件长什么样

INI 是 Windows 时代流传下来的配置格式，结构简单到一眼看懂：用方括号 `[ ]` 分成若干段（section），段里面是 `键 = 值`（option）。

```ini
[database]
host = localhost
port = 3306
debug = true

[user]
name = 张三
city = 北京
```

三段式命名：`[database]` 是段名，`host` 是选项名，`localhost` 是值。注释用 `#` 或 `;`。

## 最小可用：读一个 INI 字符串

`configparser` 只能从"文件"读，不能直接吃字符串。所以用 `io.StringIO` 把字符串包成文件对象——这个套路你在 csv 那几课已经见过。

```python
import configparser
import io

text = """[database]
host = localhost
port = 3306

[user]
name = 张三
city = 北京"""

cp = configparser.ConfigParser()
cp.read_file(io.StringIO(text))

print(cp.sections())              # 有哪些段
print(cp['database']['host'])     # 取值
print(type(cp['database']['port']))  # 值的类型
```

输出：

```
['database', 'user']
localhost
<class 'str'>
```

注意最后一行：`port` 明明是数字 `3306`，读出来却是字符串 `'3306'`。**`configparser` 不做类型推断，所有值一律按字符串返回**。这是它和 JSON（会自动识别数字、布尔）最大的区别。

## getint / getfloat / getboolean：手动要类型

既然全是字符串，就得自己转换。模块提供了三个便捷方法：

```python
import configparser
import io

text = """[database]
host = localhost
port = 3306
ratio = 0.75
debug = true"""

cp = configparser.ConfigParser()
cp.read_file(io.StringIO(text))

port = cp.getint("database", "port")
ratio = cp.getfloat("database", "ratio")
debug = cp.getboolean("database", "debug")

print(port, type(port).__name__)    # 3306 int
print(ratio, type(ratio).__name__)  # 0.75 float
print(debug, type(debug).__name__)  # True bool
```

`getboolean` 还认中文程序常见的几种写法：`true/false`、`yes/no`、`on/off`、`1/0`。

## 翻车现场一：把字符串当数字用

```python
# WRONG
port = cp["database"]["port"]
print(port + 1)          # 想做端口偏移
```

报错：

```
TypeError: can only concatenate str (not "int") to str
```

因为 `port` 是 `"3306"`，字符串加数字直接崩。

**正确做法**：用 `getint`，或者自己 `int()`。

```python
port = cp.getint("database", "port")
print(port + 1)          # 3307
```

顺带一提，`getint("database", "host")` 会怎样？会报 `ValueError: invalid literal for int() with base 10: 'localhost'`——所以**键存在不等于能转成数字**，生产代码里记得包一层 try。

## 翻车现场二：大小写——option 会被转小写

这是 `configparser` 最反直觉的一点：**option 名（键名）在内部会被转成小写**，但 section 名（段名）保留原样。

```python
import configparser
import io

text = """[database]
Host = localhost
PORT = 3306"""

cp = configparser.ConfigParser()
cp.read_file(io.StringIO(text))

print(cp["database"]["host"])   # localhost，键名被小写化
print(cp["database"]["Host"])   # 也能取到，大小写不敏感
try:
    print(cp["DATABASE"]["host"])
except KeyError as e:
    print("KeyError:", e)       # section 名大小写敏感！
```

输出：

```
localhost
localhost
KeyError: 'DATABASE'
```

**段名敏感，键名不敏感，而且键名被规范化成小写**。记不住这条，排查"明明写了 `Host` 为什么取不到"能浪费你半小时。

## 翻写：改配置并写回

`configparser` 是可读可写的。改完用 `io.StringIO` 当"文件"接收输出，就能拿到改后的字符串，不依赖真实磁盘。

```python
import configparser
import io

cp = configparser.ConfigParser()
cp["database"] = {"host": "localhost", "port": "3306"}
cp["user"] = {}
cp["user"]["name"] = "张三"

buf = io.StringIO()
cp.write(buf)
print(buf.getvalue())
```

输出：

```
[database]
host = localhost
port = 3306

[user]
name = 张三

```

写入时它会自动补空格、自动分节，格式非常规整。

## 判断键存不存在：`in` 和 `get` 的默认值

```python
import configparser
import io

cp = configparser.ConfigParser()
cp.read_file(io.StringIO("[db]\nhost=localhost\n"))

# 用 in 判断
if "timeout" in cp["db"]:
    print("有 timeout")
else:
    print("没有 timeout")       # 走这里

# 用 get 带默认值（第二个参数是默认值）
t = cp.get("db", "timeout", fallback="30")
print(t)                        # 30
```

`fallback` 比先 `in` 再取值优雅得多，推荐优先用。

## 什么时候不该用 INI

INI 只适合"扁平的键值对"。如果你的配置长这样，就该换 YAML 或 JSON：

- 需要嵌套多层（INI 的段只能一层）
- 值是个列表，比如 `servers = a, b, c`（得自己 split）
- 配置项上百个，分节分不动

INI 的优势恰恰来自它的简陋：**人类手写不易出错，diff 友好，代码三行就能读完**。日志级别、数据库连接、功能开关这类"几行搞定"的场景，它依然是首选。

## 小结

- INI 结构是 `section → option → value`，用 `[段名]` 分节
- `configparser` 读出的值**全是字符串**，必须用 `getint/getfloat/getboolean` 或自己 `int()` 转换
- **option 名会被转成小写（大小写不敏感），section 名大小写敏感**——这是最容易翻车的地方
- 用 `io.StringIO` 代替真实文件做读写，测试更方便
- 取可能不存在的键用 `get(..., fallback=...)` 给默认值

```quiz

exam: true
q: 写一个函数 get_timeout(ini_text)，接收 INI 格式字符串，返回 [app] 段 timeout 选项的整数值；如果 [app] 段不存在、timeout 不存在、或无法转成整数，返回默认值 30。

  import configparser
  import io

  def get_timeout(ini_text):
```
