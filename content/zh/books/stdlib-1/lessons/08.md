# JSONDecodeError：常见坏 JSON 与定位错误位置

> 这一课专门讲"解析失败怎么办"。你会学会读报错信息里的行号和列号，并认全 JSON 最常犯的几种错。

## 报错长什么样

`json.loads` 遇到不合法的内容，会抛出 `json.JSONDecodeError`。它和普通异常不同，**带有精确的位置信息**：

```python
import json

raw = '{"name": "张三", "age": }'
try:
    json.loads(raw)
except json.JSONDecodeError as e:
    print("错误信息：", e)
    print("出错行号：", e.lineno)
    print("出错列号：", e.colno)
    print("字符位置：", e.pos)
```

输出：

```
错误信息： Expecting value: line 1 column 22 (char 21)
出错行号： 1
出错列号： 22
字符位置： 21
```

`lineno`/`colno` 是**行号和列号**（从 1 开始），`pos` 是**从头数第几个字符**（从 0 开始）。

**这些信息的价值**：当你的 JSON 有几千行时，报错会告诉你"第 342 行第 15 列"，你直接跳过去修，不用肉眼扫。

## 常见错误一：尾随逗号

```python
import json

raw = '''
{
    "name": "张三",
    "age": 20,    <<< 这里多了个逗号
}
'''

json.loads(raw)
```

报错：

```
JSONDecodeError: Expecting property name enclosed in double quotes: line 4 column 5 (char ...)
```

**`age: 20` 后面那个逗号是非法的**。Python 的字典允许尾随逗号，JSON 不行。这是从 Python 转 JSON 的人最常犯的错。

**修法**：删掉最后一个元素后面的逗号。或者用代码预处理（见下文）。

## 常见错误二：单引号

```python
import json

raw = "{'name': '张三'}"
json.loads(raw)
```

报错：

```
JSONDecodeError: Expecting property name enclosed in double quotes: line 1 column 2 (char 1)
```

JSON 规定**字符串和键都必须用双引号**。单引号是 Python 风格，不是 JSON 风格。

```python
# WRONG：用 repr 生成"看起来像 JSON"的字符串
data = str({"name": "张三"})          # "{'name': '张三'}"
json.loads(data)                      # 报错
```

**修法**：永远用 `json.dumps` 生成，不要 `str()`。

## 常见错误三：把 Python 的 True/None 当 JSON

```python
import json

raw = '{"paid": True, "note": None}'
json.loads(raw)
```

报错：

```
JSONDecodeError: Expecting value: line 1 column 10 (char 9)
```

`True`/`None` 要写成 `true`/`null`。同理 `False` → `false`。

## 常见错误四：把注释写进 JSON

```python
import json

raw = '''
{
    // 用户名
    "name": "张三"
}
'''

json.loads(raw)
```

报错：

```
JSONDecodeError: Expecting property name enclosed in double quotes: line 3 column 5 (char ...)
```

**JSON 标准不支持注释**。很多配置文件（比如 VS Code 的 `settings.json`、npm 的 `package.json`）其实用的是 JSON5 或 JSONC 的超集，但标准 `json` 模块不认。

**如果一定要带注释**，常见做法是先去掉注释再解析（自己写预处理，或用第三方库 `json5`）。

## 翻车现场：捕获了异常却不看错误信息，一律提示"格式错误"

```python
# 不推荐
try:
    data = json.loads(raw)
except json.JSONDecodeError:
    print("JSON 格式错误")
```

这种提示对用户毫无帮助，他不知道该改哪一行。

**正确做法**：把行号和列号一起报出来：

```python
def parse_with_report(raw):
    try:
        return json.loads(raw)
    except json.JSONDecodeError as e:
        print(f"第 {e.lineno} 行第 {e.colno} 列出错：{e.msg}")
        return None

parse_with_report('{"name": "张三", "age": }')
# 第 1 行第 22 列出错：Expecting value
```

## 用 json.tool 在命令行快速校验

Python 自带一个命令行工具，可以校验并美化 JSON：

```bash
python3 -m json.tool data.json
```

如果 `data.json` 有语法错误，它会报出具体位置和原因；如果合法，它会输出美化后的内容。

```bash
# 也可以从标准输入读
echo '{"name": "张三", "age": }' | python3 -m json.tool
```

输出：

```
Expecting value: line 1 column 22 (char 21)
```

这是排查"某个 JSON 文件为什么读不了"的最快手段，不用写代码。

## 实战：写一个能自动修复常见错误的解析器

下面这个函数演示"容错解析"：遇到常见错误时，尝试自动修正，而不是立刻放弃。

```python
import json
import re

def forgiving_loads(raw):
    """尝试解析 JSON；遇到常见错误自动修正后重试"""
    try:
        return json.loads(raw)
    except json.JSONDecodeError:
        pass

    fixed = raw

    # 修复 1：去掉 // 行注释和 /* */ 块注释
    fixed = re.sub(r"//.*", "", fixed)
    fixed = re.sub(r"/\*.*?\*/", "", fixed, flags=re.DOTALL)

    # 修复 2：去掉尾随逗号（} 或 ] 前面的逗号）
    fixed = re.sub(r",(\s*[}\]])", r"\1", fixed)

    # 修复 3：单引号转双引号（仅粗略处理，不覆盖所有情况）
    # 这里不自动做，因为风险高，交给用户自己改

    try:
        return json.loads(fixed)
    except json.JSONDecodeError as e:
        raise ValueError(f"无法修复，第 {e.lineno} 行第 {e.colno} 列仍有错：{e.msg}") from e

# 测试
raw_with_comments = '''
{
    // 用户信息
    "name": "张三",
    "age": 20,   // 尾随逗号
}
'''

data = forgiving_loads(raw_with_comments)
print(data)            # {'name': '张三', 'age': 20}
```

**注意**：自动修复是有风险的（比如字符串里的内容被误伤），真实项目里一般只做**明确、保守**的修复，并把修正记录打日志，绝不静默吞掉。

## 小结

- `JSONDecodeError` 带行号、列号、字符位置，是定位坏 JSON 的关键
- 四大常见错误：**尾随逗号、单引号、True/None 没小写、注释**
- Python 的 `repr`/`str(dict)` 生成的不是合法 JSON，永远用 `json.dumps`
- 报错时**要把行号列号一起报给用户**，而不是笼统说"格式错误"
- `python3 -m json.tool 文件` 是命令行快速校验 JSON 的利器
- 容错解析可做，但要保守、要留日志，不要静默吞错
