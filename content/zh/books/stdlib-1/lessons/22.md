# fractions：用分数做精确计算，避开浮点误差

> 当业务里出现"比例""配方""分摊"，浮点越算越歪。这一课用 `fractions.Fraction` 帮你把精确分数玩明白，并说清它和 float 混算的坑。

## Fraction 基本用法：分子分母一写就对

`fractions` 模块提供 `Fraction`，用两个整数表示分数，永远不会被二进制截断。

```python
from fractions import Fraction

a = Fraction(1, 3)
b = Fraction(2, 5)
print(a)            # 1/3
print(a + b)        # 11/15
print(float(a))     # 0.3333333333333333
```

输出：

```
1/3
11/15
0.3333333333333333
```

**关键点：`Fraction(n, d)` 里 n、d 都是整数**，写 `Fraction(1, 3)` 比 `1/3` 可靠得多。

## 字符串也能构造，自动约分

Fraction 支持从字符串构造，而且**会自动约分**：

```python
from fractions import Fraction

print(Fraction("2/4"))      # 1/2
print(Fraction("0.25"))     # 1/4
print(Fraction(4, 6))       # 2/3
print(Fraction(0, 1))       # 0
```

输出：

```
1/2
1/4
2/3
0
```

`Fraction(4, 6)` 自动约成 `2/3`，分母里不会有公因子。

## 翻车现场一：Fraction 和 float 混算会变 float

这是最大的坑。**只要运算里出现 float，结果就变成 float**，分数精度当场清零：

```python
from fractions import Fraction

a = Fraction(1, 3)
# WRONG：和 float 相加
result = a + 0.5
print(result)
print(type(result))
```

输出：

```
0.8333333333333333
<class 'float'>
```

结果变成了 `float`！`Fraction` 和 `float` 的运算结果按 Python 规则会提升为 float，所有精确性都丢了。

```python
from fractions import Fraction

a = Fraction(1, 3)
# 正确：全用 Fraction
result = a + Fraction(1, 2)
print(result)            # 5/6
print(type(result))      # <class 'fractions.Fraction'>
```

## 翻车现场二：Fraction(float) 会继承 float 误差

用 float 值构造 Fraction，会把 float 的二进制误差原样带进来：

```python
from fractions import Fraction

# WRONG：Fraction(0.1) 带进 float 误差
print(Fraction(0.1))
```

输出：

```
3602879701896397/36028797018963968
```

这个分母非常诡异，因为 `0.1` 本身不精确。正确做法是传字符串：

```python
from fractions import Fraction

print(Fraction("0.1"))   # 1/10
```

**和 Decimal 一样的道理：从外部进来的小数，用字符串构造。**

## 什么时候比浮点好：精确比例

需要**精确比例、配方、分摊**时用 Fraction，结果永远是精确的分数。

```python
from fractions import Fraction

# 配方：3 份面粉配 5 份水，求 2 份面粉对应多少水
flour = Fraction(3)
water = Fraction(5)
ratio = water / flour           # 5/3
need = ratio * 2                # 10/3
print(need)                     # 10/3
print(f"需水 {float(need):.2f} 份")
```

输出：

```
10/3
需水 3.33 份
```

如果是 float 算 `5/3 * 2`，得到的是近似值；Fraction 全程精确，最后要显示再转 float。

## 什么时候别用：高频大量运算

Fraction 的分母会越来越大，算得越久越慢、越占内存。**CPU 密集、纯数值模拟场景还是用 float 或 Decimal**。

```python
from fractions import Fraction

# 连续相乘，分母爆炸
x = Fraction(1, 2)
for _ in range(10):
    x *= Fraction(3, 2)
print(x)        # 59049/1024
```

输出：

```
59049/1024
```

`59049/1024` 这种大分母计算成本高。**判断标准：要"精确比值"用 Fraction，要"算得快/存得省"用 float，要"金额精确到分"用 Decimal。**

## 常用操作一览

| 操作 | 写法 | 说明 |
| --- | --- | --- |
| 构造 | `Fraction(1, 3)` / `Fraction("0.25")` | 整数对或字符串 |
| 约分 | 自动 | 内部 gcd 处理 |
| 转 float | `float(f)` | 显示用 |
| 转整数 | `f.numerator // f.denominator` | 整除取整 |
| 分子 | `f.numerator` | 属性 |
| 分母 | `f.denominator` | 属性 |
| 限制分母 | `f.limit_denominator(100)` | 找近似简单分数 |

`limit_denominator` 特别适合"把浮点结果还原成好看分数"：

```python
from fractions import Fraction

x = Fraction(355, 113)
print(x)                            # 355/113
print(x.limit_denominator(10))      # 3 = 约等于 3.14159
```

## 小结

- `Fraction(n, d)` 用两个整数表示分数，**自动约分**
- 支持字符串构造 `Fraction("0.25")`，结果精确
- **和 float 混算结果变 float**，精确性归零——全用 Fraction
- `Fraction(float)` 会继承 float 误差，外部小数用字符串构造
- 适合精确比例/配方/分摊；不适合高频大量数值运算
- 对比：精确比值用 Fraction，金额用 Decimal，通用数值用 float
