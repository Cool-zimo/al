# reader / writer：列表形式的读写

> 这一课深入 `csv.reader` 和 `csv.writer`：怎么读、怎么写、返回值是什么类型。并彻底讲清楚 `newline=''` 为什么是必须的。

## csv.reader：返回列表的迭代器

`csv.reader` 接收任何可迭代对象（通常是文件对象），每次 `next` 吐出一个**字符串列表**——每一列是列表里的一个元素。

```python
import csv
import io

text = """name,age,city
张三,28,北京
李四,35,上海"""

reader = csv.reader(io.StringIO(text))
for row in reader:
    print(type(row).__name__, row)
```

输出：

```
list ['name', 'age', 'city']
list ['张三', '28', '北京']
list ['李四', '35', '上海']
```

**每一行都是一个 `list[str]`**。要取第 2 列就用 `row[1]`，取最后一列用 `row[-1]`。

## 读到列表后怎么处理

```python
import csv
import io

text = """name,age,city
张三,28,北京
李四,35,上海
王五,42,广州"""

reader = csv.reader(io.StringIO(text))
header = next(reader)              # 表头单独取出来
print("表头:", header)

data = []
for row in reader:
    data.append({"name": row[0], "age": int(row[1]), "city": row[2]})

print(data)
```

输出：

```
表头: ['name', 'age', 'city']
[{'name': '张三', 'age': 28, 'city': '北京'}, {'name': '李四', 'age': 35, 'city': '上海'}, {'name': '王五', 'age': 42, 'city': '广州'}]
```

`next(reader)` 跳过表头，剩下的就是纯数据。这里还做了**类型还原**：`age` 从字符串转成了 `int`。

## csv.writer：writerow 和 writerows

`writer` 的核心方法是 `writerow(row)`（写一行）和 `writerows(rows)`（写多行）。

```python
import csv
import io

buf = io.StringIO()
writer = csv.writer(buf)

writer.writerow(["name", "age", "city"])        # 写一行
writer.writerows([                               # 写多行
    ["张三", 28, "北京"],
    ["李四", 35, "上海"],
    ["王五", 42, "广州"],
])

print(buf.getvalue())
```

输出：

```
name,age,city
张三,28,北京
李四,35,上海
王五,42,广州
```

`writerow` 接收单个可迭代对象，`writerows` 接收"可迭代对象的可迭代对象"（二维）。

## newline='' 是必须的

先说结论：**在 Windows 上打开文件写 CSV，必须传 `newline=''`**。

### 为什么？

CSV 规范里一条记录的结束标记是 `\r\n`（CRLF）。Python 的文本模式 `open()` 在 Windows 上会把你写入的 `\n` **自动翻译成 `\r\n`**。

而 `csv` 模块自己在写每行时**已经写了 `\r\n`**。两层叠加的结果：

| 场景 | csv 写的实际字节 | 显示效果 |
|---|---|---|
| 正确 `newline=''` | `\r\n` | 正常 |
| 错误 默认模式(Windows) | `\r\r\n` | 每行之间多一个空行 |

### 翻车现场：多空行

```python
# WRONG（Windows 上）
import csv

with open("users.csv", "w", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["name", "age"])
    writer.writerow(["张三", 28])
```

用记事本打开，变成：

```
name,age
                                    ← 空行
张三,28
                                    ← 空行
```

**正确写法**：

```python
import csv

with open("users.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["name", "age"])
    writer.writerow(["张三", 28])
```

`newline=''` 的含义是：**告诉 Python 不要做任何换行符转换，全部交给 csv 模块处理**。

> Linux/Mac 上默认模式通常也碰不到问题，但**养成 `newline=''` 的习惯**，代码跨平台就不会出 bug。

## 读取也要 newline='' 吗？

**读取时 `newline=''` 是推荐但不强制**。为了代码一致和跨平台稳妥，读也建议加：

```python
import csv

with open("users.csv", encoding="utf-8", newline="") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)
```

## 一个完整的读写流程

```python
import csv
import io

# 读
src = """name,age,city
张三,28,北京
李四,35,上海"""

reader = csv.reader(io.StringIO(src))
rows = list(reader)
header = rows[0]
data = rows[1:]

# 改：所有人年龄 +1
for r in data:
    r[1] = str(int(r[1]) + 1)

# 写
buf = io.StringIO()
writer = csv.writer(buf)
writer.writerow(header)
writer.writerows(data)

print(buf.getvalue())
```

输出：

```
name,age,city
张三,29,北京
李四,36,上海
```

**列表形式读、列表形式改、列表形式写**——这就是 `reader/writer` 的完整工作流。

## 小结

- `csv.reader` 返回**字符串列表**的迭代器，取列用索引 `row[0]`、`row[1]`
- `next(reader)` 可单独取出表头，剩下是纯数据
- `writer.writerow` 写一行，`writer.writerows` 写多行
- **写 CSV 必须 `newline='''`**，否则 Windows 上每行多一个空行
- 读也建议加 `newline=''` 保证跨平台一致
- 完整流程：读成列表 → 修改 → 写回
