# 自定义对象序列化：default 与 object_hook

> 这一课解决"我的类对象怎么存进 JSON"。你会在第 03 课踩到的坑上，学会用 `default=` 把任意对象转成 JSON，再用 `object_hook` 还原。

## 问题：自定义类的实例没法直接序列化

```python
import json

class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(3, 4)
json.dumps(p)
```

报错：

```
TypeError: Object of type Point is not JSON serializable
```

`json` 模块只认六种基本类型。它不知道你的 `Point` 该怎么变成 JSON。你需要**告诉它规则**。

## default 参数：给序列化器一个"转换函数"

`json.dumps` 的 `default` 参数接收一个函数：当遇到不认识的类型时，就会调用这个函数，把你返回的值拿去序列化。

最常用的写法是返回对象的 `__dict__`：

```python
import json

class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(3, 4)

text = json.dumps(p, default=lambda o: o.__dict__)
print(text)            # {"x": 3, "y": 4}
```

`o.__dict__` 是对象的所有**实例属性**组成的字典。`Point(3,4)` 的 `__dict__` 就是 `{"x": 3, "y": 4}`，恰好是合法的 JSON。

```python
class Order:
    def __init__(self, order_id, total):
        self.order_id = order_id
        self.total = total

orders = [Order("DD001", 199.0), Order("DD002", 59.0)]
text = json.dumps(orders, default=lambda o: o.__dict__, ensure_ascii=False)
print(text)
# [{"order_id": "DD001", "total": 199.0}, {"order_id": "DD002", "total": 59.0}]
```

## 翻车现场：default 函数没覆盖到所有类型

如果你的 default 函数只想处理 `Point`，遇到别的类型就懵了：

```python
import json

class Point:
    pass

def my_default(o):
    if isinstance(o, Point):
        return {"x": o.x, "y": o.y}
    # WRONG：别的类型没处理，直接报错

json.dumps([Point(1,2), set([1,2])], default=my_default)
```

报错：

```
TypeError: Object of type set is not JSON serializable
```

**更稳妥的 default 写法**：把不认识的类型兜底成字符串，至少能序列化出来：

```python
def safe_default(o):
    if isinstance(o, Point):
        return {"x": o.x, "y": o.y}
    # 兜底：转成字符串，保证不崩
    return str(o)
```

## 自定义转换逻辑：不是所有对象都适合用 `__dict__`

`__dict__` 会把**所有属性**都暴露出去，包括你不想存的（比如缓存、连接对象）。更精细的做法是自己构造字典：

```python
import json

class User:
    def __init__(self, uid, name, password, email):
        self.uid = uid
        self.name = name
        self.password = password      # 敏感字段，不能序列化
        self.email = email

u = User(10086, "张三", "123456", "zhangsan@example.com")

def user_to_dict(o):
    if isinstance(o, User):
        return {
            "uid": o.uid,
            "name": o.name,
            "email": o.email
            # 故意不含 password
        }
    raise TypeError(f"不支持的类型: {type(o)}")

text = json.dumps(u, default=user_to_dict, ensure_ascii=False)
print(text)
# {"uid": 10086, "name": "张三", "email": "zhangsan@example.com"}
```

**这个例子很关键**：序列化是数据出口，也是做"脱敏"的好时机。密码、token、私钥绝不能进 JSON。

## 翻车现场：lambda 里访问 self 引发 NameError

有人想更优雅，给类加一个方法：

```python
class Point:
    def to_dict(self):
        return {"x": self.x, "y": self.y}

p = Point(3, 4)
json.dumps(p, default=lambda o: o.to_dict())   # 这行本身没问题
```

**注意 lambda 里 `o.to_dict()` 的前提是 o 真的有这个方法**。更稳的做法是判断 `hasattr`：

```python
text = json.dumps(p, default=lambda o: o.to_dict() if hasattr(o, "to_dict") else str(o))
```

## object_hook：反序列化时把字典变回对象

序列化出去的是字典，读回来时还是字典。如果你希望它变回 `Point`，就要用 `object_hook`：

```python
import json

class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

def dict_to_point(d):
    """如果这个字典长得很像 Point，就转成 Point 对象"""
    if "x" in d and "y" in d and len(d) == 2:
        return Point(d["x"], d["y"])
    return d          # 别的字典原样返回

# 先序列化一个 Point
text = json.dumps(Point(3, 4), default=lambda o: o.__dict__)
print("出去的：", text)          # {"x": 3, "y": 4}

# 再反序列化，用 object_hook 还原
back = json.loads(text, object_hook=dict_to_point)
print("回来的类型：", type(back))  # <class '__main__.Point'>
print(back.x, back.y)            # 3 4
```

`object_hook` 的机制：解析器每构造出一个字典，都会先过一遍你的函数。你返回什么，最终 `loads` 的结果就是什么。

## 翻车现场：object_hook 没返回原字典，结构被拆坏

```python
def bad_hook(d):
    return Point(d["x"], d["y"])      # 不管三七二十一全转成 Point

# 如果 JSON 里还有别的字典（比如嵌套的用户信息）：
text = '{"point": {"x": 3, "y": 4}, "meta": {"version": 1}}'
json.loads(text, object_hook=bad_hook)
```

报错：

```
KeyError: 'x'
```

因为 `"meta": {"version": 1}` 这个字典也被丢进了 `bad_hook`，它没 `x` 键。

**正确做法**：在 hook 里做**类型标记识别**。约定序列化时加一个类型字段：

```python
import json

class Point:
    def __init__(self, x, y):
        self.x = self.y = None

def point_to_json(o):
    if isinstance(o, Point):
        return {"__type__": "Point", "x": o.x, "y": o.y}
    raise TypeError(f"不支持的类型: {type(o)}")

def json_to_point(d):
    if d.get("__type__") == "Point":
        p = Point(0, 0)
        p.x, p.y = d["x"], d["y"]
        return p
    return d

text = json.dumps(Point(3, 4), default=point_to_json)
back = json.loads(text, object_hook=json_to_point)
print(type(back).__name__, back.x, back.y)    # Point 3 4
```

**`__type__` 字段是约定的"类型标记"**。序列化时带上，反序列化时按它判断。这是 JSON 里保存类型信息的经典方案。

## 实战：一个能存能取的"对象存档"工具

```python
import json
import os

# 注册表：类型名 -> (编码函数, 解码函数)
_REGISTRY = {}

def register_type(name, cls, to_dict, from_dict):
    _REGISTRY[name] = (cls, to_dict, from_dict)

def _encoder(o):
    for name, (cls, to_dict, _) in _REGISTRY.items():
        if isinstance(o, cls):
            d = to_dict(o)
            d["__type__"] = name
            return d
    raise TypeError(f"未注册的类型: {type(o)}")

def _decoder(d):
    t = d.get("__type__")
    if t in _REGISTRY:
        d2 = {k: v for k, v in d.items() if k != "__type__"}
        return _REGISTRY[t][2](d2)
    return d

def save_objects(obj, path):
    with open(path, "w", encoding="utf-8") as f:
        json.dump(obj, f, default=_encoder, ensure_ascii=False, indent=2)

def load_objects(path):
    with open(path, encoding="utf-8") as f:
        return json.load(f, object_hook=_decoder)

# —— 注册 Point 类型 ——
class Point:
    def __init__(self, x, y): self.x, self.y = x, y

register_type(
    "Point",
    Point,
    to_dict=lambda p: {"x": p.x, "y": p.y},
    from_dict=lambda d: Point(d["x"], d["y"])
)

# 使用
data = {
    "title": "几何图形存档",
    "origin": Point(0, 0),
    "points": [Point(1, 2), Point(3, 4)]
}
save_objects(data, "shapes.json")

loaded = load_objects("shapes.json")
print("标题：", loaded["title"])
print("原点：", type(loaded["origin"]).__name__, loaded["origin"].x, loaded["origin"].y)
print("第一个点：", loaded["points"][0].x, loaded["points"][0].y)
```

输出：

```
标题： 几何图形存档
原点： Point 0 0
第一个点： 1 2
```

打开 `shapes.json` 你会看到一份带 `__type__` 标记的、人也能看懂的存档文件。**这就是很多"存档系统""配置系统"在底层做的事**。

## 小结

- 自定义类直接 `dumps` 会 TypeError
- `default=` 接收一个函数，把不认识的对象转成可序列化的东西
- 最常用 `default=lambda o: o.__dict__`，但要注意会暴露所有属性
- **序列化是脱敏好时机**：敏感字段别写进字典
- `object_hook=` 让 `loads` 把字典还原成对象
- hook 里要做**类型标记**（如 `__type__`），否则会把别的字典也误转
- 用"注册表 + 编码器 + 解码器"可做成通用的对象存档工具
