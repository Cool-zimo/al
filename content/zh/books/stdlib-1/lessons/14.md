# CSV 的编码与方言坑

> 这一课专治"打开全是乱码"和"分隔符怎么不对"。UTF-8 与 GBK 的差别、delimiter 怎么改、quoting 四种策略——都在这儿。

## 坑一：Excel 打开中文 CSV 乱码

张三写了一个 CSV：

```python
import csv

with open("users.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["姓名", "城市"])
    writer.writerow(["张三", "北京"])
```

双击用 Excel 打开——全是乱码。

**原因**：Excel 在 Windows 上默认按 **GBK（CP936）** 解码 CSV，而文件是 UTF-8 存的。编码对不上就乱码。

### 解法 A：存成 GBK

```python
with open("users_gbk.csv", "w", encoding="gbk", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["姓名", "城市"])
    writer.writerow(["张三", "北京"])
```

Excel 打开正常。**代价**：GBK 不支持 emoji 和部分生僻字，存进去会报错。

### 解法 B：UTF-8 带 BOM

```python
with open("users_bom.csv", "w", encoding="utf-8-sig", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["姓名", "城市"])
    writer.writerow(["张三", "北京"])
```

`utf-8-sig` 会在文件开头写入 BOM（`\ufeff`），**Excel 看到 BOM 就知道这是 UTF-8**，正确解码。这是目前最推荐的折中方案。

### 读取时的对应

```python
# 读 GBK 文件
with open("users_gbk.csv", encoding="gbk", newline="") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)

# 读带 BOM 的 UTF-8
with open("users_bom.csv", encoding="utf-8-sig", newline="") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)
```

用错编码读文件会抛 `UnicodeDecodeError`。

## 坑二：分隔符不是逗号

CSV 不一定用逗号分隔。Linux 下很多工具用**制表符（TSV）**，欧洲一些地区用**分号**（因为逗号是小数位）。

```python
import csv
import io

# TSV（制表符分隔）
text = "name\tage\tcity\n张三\t28\t北京\n"
reader = csv.reader(io.StringIO(text), delimiter="\t")
for row in reader:
    print(row)
```

输出：

```
['name', 'age', 'city']
['张三', '28', '北京']
```

指定 `delimiter="\t"` 即可。分号同理：`delimiter=";"`。

## quoting：什么时候加引号

CSV 里有四种引用策略，通过 `quoting` 参数控制：

| 策略 | 含义 | 示例输出 |
|---|---|---|
| `QUOTE_MINIMAL`（默认） | 只有字段含逗号/换行/引号时才加引号 | `张三,28,北京` |
| `QUOTE_ALL` | 所有字段都加引号 | `"张三","28","北京"` |
| `QUOTE_NONNUMERIC` | 非数字字段加引号 | `"张三","28","北京"` |
| `QUOTE_NONE` | 都不加引号（需自己保证不含逗号） | `张三,28,北京` |

### QUOTE_MINIMAL（默认）

```python
import csv
import io

buf = io.StringIO()
writer = csv.writer(buf, quoting=csv.QUOTE_MINIMAL)
writer.writerow(["name", "北京", "28"])        # 只有北京要加引号
print(repr(buf.getvalue()))
```

输出：

```
'name,"北京",28\r\n'
```

### QUOTE_ALL

```python
buf = io.StringIO()
writer = csv.writer(buf, quoting=csv.QUOTE_ALL)
writer.writerow(["name", "北京", "28"])
print(repr(buf.getvalue()))
```

输出：

```
'"name","北京","28"\r\n'
```

每个字段都被双引号包裹，和某些系统对接时（比如老式数据库导入）必须用这个。

### QUOTE_NONNUMERIC：自动把字符串变成数字

```python
buf = io.StringIO()
writer = csv.writer(buf, quoting=csv.QUOTE_NONNUMERIC)
writer.writerow(["张三", 28, 3.14])
print(repr(buf.getvalue()))
```

输出：

```
'"张三",28,3.14\r\n'
```

`"张三"` 是字符串加引号，`28` 和 `3.14` 是数字不加。**反过来**：用 `QUOTE_NONNUMERIC` 读取时，csv 会把**不带引号的字段自动转成 float**。

```python
import csv
import io

text = '"张三",28,3.14\n'
reader = csv.reader(io.StringIO(text), quoting=csv.QUOTE_NONNUMERIC)
for row in reader:
    print(row, [type(x).__name__ for x in row])
```

输出：

```
['张三', 28.0, 3.14] ['str', 'float', 'float']
```

注意 `28` 变成了 `28.0`（float）。这是 csv 模块**唯一的自动类型转换**。

## 翻车现场：escapechar 与引号内的引号

字段里本身含双引号怎么办？

```python
import csv
import io

buf = io.StringIO()
writer = csv.writer(buf, quoting=csv.QUOTE_MINIMAL)
writer.writerow(["note", '他说"你好"'])
print(repr(buf.getvalue()))
```

输出：

```
'note,"他说""你好"""\r\n'
```

CSV 用**两个双引号表示一个双引号**来转义。读回来能正确还原。

## dialect：一次配置多项格式

如果每次都传 `delimiter`、`quoting`、`escapechar` 太麻烦，可以注册一个方言：

```python
import csv

csv.register_dialect("pipe", delimiter="|", quoting=csv.QUOTE_NONE)

buf = io.StringIO()
writer = csv.writer(buf, dialect="pipe")
writer.writerow(["张三", "北京", 28])
print(repr(buf.getvalue()))        # '张三|北京|28\r\n'
```

内置方言 `csv.excel` 就是默认行为，`csv.unix_dialect` 用 `\n` 换行不加 `\r`。

## 小结

- Excel 乱码：存 **GBK**（兼容性最好）或 **UTF-8-SIG**（带 BOM，推荐折中）
- 读 GBK 用 `encoding="gbk"`，读 UTF-8-SIG 用 `encoding="utf-8-sig"`
- 分隔符不是逗号：`delimiter="\t"` 或 `delimiter=";"`
- `QUOTE_MINIMAL`（默认）：只有含特殊字符才加引号
- `QUOTE_ALL`：全加引号，适合老式系统对接
- `QUOTE_NONNUMERIC`：写入时数字不加引号；读取时把无引号字段转 float
- `csv.register_dialect` 把一组格式参数打包复用
