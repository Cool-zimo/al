# 类型转换与 type()

> 为什么 `"18"` 加 `1` 会报错？为什么 `1 + 1` 是 2 而 `"1" + "1"` 是 `"11"`？
> 这一课把这些"看起来一样其实不一样"的问题一次讲透。

## 先看三个"诡异"的结果

```python
print(1 + 1)        # 2
print("1" + "1")    # 11
print(1 + "1")      # TypeError
```

同样的 `+`，三种完全不同的结果。区别在哪？**在于参与运算的东西是什么类型**。

- 数字加数字 → 数学加法
- 字符串加字符串 → 拼接
- 数字加字符串 → 报错，Python 不知道你想要哪种

这就是类型的意义：**类型决定了"这个数据能做什么操作"**。

## type()：看看它到底是什么

不确定一个值是什么类型时，直接问：

```python
print(type(18))        # <class 'int'>
print(type(18.5))      # <class 'float'>
print(type("你好"))     # <class 'str'>
print(type(True))      # <class 'bool'>
print(type(None))      # <class 'NoneType'>
```

输出里的 `int`、`float`、`str`、`bool` 就是类型名。

`type()` 最常见的用途是**排查奇怪的 bug**。比如你算出来的结果不对，先 `print(type(x))` 看看它到底是什么——很多时候问题就出在"你以为是数字，其实是字符串"。

### isinstance()：判断是不是某个类型

```python
print(isinstance(18, int))       # True
print(isinstance("18", int))     # False
print(isinstance(18.5, (int, float)))   # True ← 可以是多个类型之一
```

`isinstance()` 比 `type(x) == int` 更推荐，因为它能处理继承关系（比如 `True` 既是 bool 也是 int）。

## 四种基本类型回顾

| 类型 | 名字 | 例子 | 说明 |
|---|---|---|---|
| `int` | 整数 | `18`、`-3` | 没有小数点 |
| `float` | 浮点数 | `18.5`、`3.0` | 有小数点 |
| `str` | 字符串 | `"你好"` | 引号包起来的文字 |
| `bool` | 布尔 | `True`、`False` | 只有两个值 |

再加上 `NoneType`（只有一个值 `None`），这就是你目前需要掌握的全部类型。

## 转换：三个函数

想把数据从一种类型变成另一种，用这三个函数：

```python
int(x)     # 转成整数
float(x)   # 转成浮点数
str(x)     # 转成字符串
```

### str()：任何东西都能变成字符串

```python
print(str(18) + "岁")        # 18岁
print(str(3.14))             # "3.14"
print(str(True))             # "True"
print(str(None))             # "None"
```

`str()` 是最安全的转换——**几乎不会失败**。它是拼接字符串时救急的法宝。

这也是 f-string 背后做的事：

```python
age = 18
print(f"我{age}岁")          # 自动调用 str(age)
print("我" + str(age) + "岁")  # 手动写，效果一样
```

### int()：转成整数

```python
print(int("18"))       # 18
print(int(3.9))        # 3    ← 直接截断，不是四舍五入！
print(int(3.1))        # 3
print(int(True))       # 1
```

**两个关键注意点**：

**1. 小数转整数是"截断"不是"四舍五入"**：

```python
print(int(3.9))        # 3，不是 4
print(int(-3.9))       # -3，不是 -4
```

想要四舍五入用 `round()`：

```python
print(round(3.9))      # 4
```

**2. 字符串转整数，字符串必须是"纯数字"**：

```python
print(int("18"))       # ✅ 18
print(int("18.5"))     # ❌ ValueError！
print(int("十八"))     # ❌ ValueError！
print(int(""))         # ❌ ValueError！
```

`int("18.5")` 报错是因为 `"18.5"` 不是整数格式。要先转 float 再转 int：

```python
print(int(float("18.5")))     # 18 ✅
```

### float()：转成浮点数

```python
print(float("3.14"))   # 3.14
print(float("3"))      # 3.0
print(float(3))        # 3.0
print(float(True))     # 1.0
```

比 `int()` 宽容一些，`float("3")` 是允许的。

## input() 永远是字符串

**这是最实用的一个知识点**，没有之一。

```python
age = input("请输入年龄：")
print(type(age))       # <class 'str'>  永远是 str！
```

不管用户输入的是 `18` 还是 `3.14` 还是 `hello`，`input()` 返回的**一律是字符串**。

所以这段代码是错的：

```python
age = input("请输入年龄：")
if age > 18:           # 拿字符串和数字比大小 → TypeError
    print("成年")
```

报 `TypeError: '>' not supported between instances of 'str' and 'int'`。

**正确写法**——先转类型：

```python
age = int(input("请输入年龄："))
if age > 18:
    print("成年")
```

> 💡 记住这条铁律：**从外部（用户输入、文件、网络）拿到的数据，几乎都是字符串。要拿来算数，先转换。**

## 转换失败会怎样

转不了就抛 `ValueError`：

```python
int("abc")
```

```
ValueError: invalid literal for int() with base 10: 'abc'
```

翻译："'abc' 不是合法的十进制数字格式。"

**实际写代码时要防着这一手**——用户可能输入任何东西。等第 3 章讲了 `try/except`（后续章节），就能优雅处理：

```python
# 现在的写法（会崩）
age = int(input("年龄："))

# 以后会学的写法（安全）
try:
    age = int(input("年龄："))
except ValueError:
    print("请输入数字！")
```

## 隐式转换：Python 自动帮你转

有些情况不需要你手动转，Python 自动来：

```python
print(1 + 2.0)      # 3.0  ← int 自动升级成 float
print(3 * 1.5)      # 4.5
```

规则是**往"更精确"的方向转**：int → float。因为转过去不会丢信息（只是加个 `.0`），反过来会丢小数部分。

但 **str 永远不会被自动转**：

```python
print("18" + 1)     # TypeError，不会自动把 "18" 转成 18
```

这是 Python 的设计选择：**宁可报错，也不猜你的意图**。因为把 `"18"` 变成 `18` 还是把 `1` 变成 `"1"`，两种结果完全不同（19 vs "181"），猜错了比报错更糟。

## 布尔转换：bool()

```python
print(bool(1))         # True
print(bool(0))         # False
print(bool(""))        # False
print(bool("False"))   # True  ← 非空字符串！
print(bool(None))      # False
```

上一课讲过：**空的和零是 False，其余是 True**。`bool()` 就是把这个规则显式地跑一遍。

实际代码里很少手写 `bool()`，因为 `if x:` 会自动做这件事。

## 一个完整例子：温度转换

把学过的东西串起来：

```python
# 用户输入摄氏温度，转成华氏温度
celsius = float(input("请输入摄氏温度："))
fahrenheit = celsius * 9 / 5 + 32
print(f"{celsius}°C = {fahrenheit}°F")
```

这短短三行里用到了：`input()`、`float()` 转换、算术运算、运算符优先级、f-string 格式化。

## 常见错误清单

| 错误 | 原因 | 修法 |
|---|---|---|
| `"18" + 1` 报 TypeError | 字符串不能和数字相加 | `int("18") + 1` |
| `int("18.5")` 报 ValueError | 字符串不是整数格式 | `int(float("18.5"))` |
| `input()` 结果比大小报错 | input 返回字符串 | `int(input(...))` |
| `int(3.9)` 得到 3 | 截断不是四舍五入 | 用 `round(3.9)` |
| 布尔判断 `"0"` 为真 | 非空字符串都是真 | 先 `int()` 再判断 |

## 随堂练习

从用户角度想：用户输入的是字符串，你要拿它算数。

```quiz
type: code
q: 把字符串 "25" 转成整数，加上 5，打印结果（应该是 30）
starter: |
  text = "25"
  
  # 用 int() 把 text 转成整数，加上 5，再打印
  # 注意：直接 text + 5 会报错
  
  print("在这里改")
tests:
- assert "30" in __out
hint: print(int(text) + 5)。先转类型再运算 —— int(text) 得到数字 25，加 5 就是 30。如果写成 text + 5 会 TypeError。
explain: 这是类型转换最典型的场景：数据以字符串形式进来（input、文件、网络），要算数就得先转。养成"先转换再运算"的习惯，能避开一大类 bug。
```
