# 布尔值与比较

> 有一种数据类型只有两个值，但它是整个编程世界里"做决定"的基础。

## 只有两个值

**布尔值（bool）**只有两个：`True` 和 `False`。

```python
is_student = True
has_paid = False
print(is_student)
print(has_paid)
```

注意**首字母必须大写**。`true`、`TRUE`、`True1` 都不行——`true` 会被当成变量名（然后报 NameError）。

> 💡 名字来自数学家乔治·布尔（George Boole），他建立了一套只有"真/假"的逻辑代数。程序员天天在用他的成果。

## 布尔值从哪来：比较运算

你很少会手写 `True`，更多是**比较出来的**：

```python
age = 18
print(age > 16)      # True
print(age < 16)      # False
```

比较运算符一共 6 个：

| 运算符 | 含义 | 例子 | 结果 |
|---|---|---|---|
| `==` | 等于 | `5 == 5` | `True` |
| `!=` | 不等于 | `5 != 3` | `True` |
| `>` | 大于 | `5 > 3` | `True` |
| `<` | 小于 | `5 < 3` | `False` |
| `>=` | 大于等于 | `5 >= 5` | `True` |
| `<=` | 小于等于 | `5 <= 4` | `False` |

**`==` 和 `=` 是完全不同的东西**——这是新手最高频的错误，没有之一：

```python
age = 18        # 一个等号：赋值（把 18 放进 age）
age == 18       # 两个等号：比较（age 是不是等于 18？）
```

如果你在需要比较的地方写了一个 `=`，Python 会报 `SyntaxError`。反过来，在需要赋值的地方写了 `==`，代码不会报错但什么也没发生——这种"静默失败"更难发现。

> 💡 记忆法：`=` 是"放进去"，`==` 是"是不是"。一个是动作，一个是提问。

## 比较也能用在字符串上

```python
print("apple" == "apple")    # True
print("apple" == "Apple")    # False  ← 大小写敏感！
print("apple" < "banana")    # True   ← 按字典序比较
```

字符串比大小用的是**字典序**（按字母表顺序），先比第一个字符，一样就比第二个，以此类推。

```python
print("abc" < "abd")     # True，第三个字符 c < d
print("Zoo" < "apple")   # True，大写字母的编码排在小写前面
```

**中文也能比**，按 Unicode 编码顺序，但日常很少这么用。

## 逻辑运算：and / or / not

三个词把多个条件组合起来：

### and —— 两个都成立

```python
age = 20
print(age >= 18 and age <= 65)     # True，20 在 18~65 之间
```

**真值表**：

| A | B | A and B |
|---|---|---|
| True | True | **True** |
| True | False | False |
| False | True | False |
| False | False | False |

口诀：**and 是"都要"**——有一个 False 就是 False。

### or —— 有一个成立就行

```python
day = "周六"
print(day == "周六" or day == "周日")    # True，是周末
```

| A | B | A or B |
|---|---|---|
| True | True | **True** |
| True | False | **True** |
| False | True | **True** |
| False | False | False |

口诀：**or 是"任一"**——有一个 True 就是 True。

### not —— 取反

```python
is_raining = False
print(not is_raining)     # True
```

| A | not A |
|---|---|
| True | False |
| False | True |

### 组合起来

```python
age = 20
has_ticket = True

# 成年 且 有票
print(age >= 18 and has_ticket)          # True

# 未成年 或 没票
print(age < 18 or not has_ticket)        # False
```

**优先级**：`not` > `and` > `or`。记不住就加括号：

```python
print((a or b) and c)     # 括号让意图一目了然
```

## 短路求值：一个小优化

Python 很聪明——**能提前确定答案时，后面的就不算了**：

```python
# and：左边是 False，右边根本不看
print(False and 1 / 0)     # False，没有报错！

# or：左边是 True，右边也不看
print(True or 1 / 0)       # True，没有报错！
```

`1 / 0` 本来会抛 ZeroDivisionError，但因为短路，它压根没被执行。

这不只是优化，还是个实用技巧——**用 and 做安全检查**：

```python
name = ""
print(name and name[0])    # 空字符串 → 直接返回 ""，不会 IndexError
```

## Python 里的"真假"

这是个重要特性：**不只是 True/False，很多值都能当布尔用**。

Python 判定真假有个简单规则：**"空的"和"零"就是假，其他都是真**。

**被视为 False 的值**：

```python
False          # 布尔假
0, 0.0         # 数字零
""             # 空字符串
[]             # 空列表（后面讲）
{}             # 空字典
None           # 空值
```

**其他一切都是 True**，包括：

```python
True
1, -1, 0.1     # 任何非零数字
"False"        # ⚠️ 注意！这是非空字符串，所以是 True
"0"            # ⚠️ 同理，字符串 "0" 也是 True
```

最后两条是常见陷阱：**字符串 `"False"` 是真**，因为它是一段有内容的文字。

**怎么用这个特性？** 判断东西"有没有内容"：

```python
name = ""
if name:             # 空字符串 → False
    print("有名字")
else:
    print("没填名字")
```

> 💡 下一章讲 if 时会大量用到这个特性。现在先记住规则：**空和零是假，其余是真**。

## None：什么都没有

`None` 是 Python 里表示"没有值"的特殊常量。

```python
result = None
print(result)          # None
print(result == None)  # True，但不推荐这样写
```

**判断是不是 None，用 `is`**：

```python
print(result is None)       # True   ✅ 推荐
print(result is not None)   # False
```

为什么不用 `==`？因为 `is` 比较的是"是不是同一个东西"，而 `==` 比较的是"值是否相等"。对 None 这种单例对象，`is` 更准确也更快。

**None 最常见的场景**：函数没有返回值时，默认返回 None。

```python
def greet():
    print("你好")

result = greet()      # 打印"你好"，但函数没 return
print(result)         # None
```

这也是新手常困惑的一点："我明明看到输出了，为什么变量是 None？"——因为 `print` 是显示在屏幕上，`return` 才是把值交给调用者。

## 布尔值其实是数字

有个 Python 的小秘密：

```python
print(True + True)     # 2
print(True * 10)       # 10
print(False + 5)       # 5
```

因为 `bool` 是 `int` 的子类，`True` 本质是 1，`False` 本质是 0。

**但别这么用**——这是内部实现细节，写出来别人看不懂。知道就好，实际代码里该用 True/False 就用。

- assert "True" in __out
