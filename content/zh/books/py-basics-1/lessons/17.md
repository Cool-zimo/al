# 否则呢：else

> 上一课的 if 有个明显的不足：**条件不成立时，它什么都不做。**
>
> 但现实里更常见的是「两种情况，必选其一」—— 及格了说"通过"，没及格说"补考"，
> 总得说一句。
>
> `else` 就是那个"否则"。

## 一、else 解决什么问题

回到票价程序。上一课我们这样写：

```python
age = 8

if age < 12:
    print("儿童票：20 元")

if age >= 12:
    print("成人票：40 元")
```

能跑，但有个隐患：**你在两个地方重复描述了同一件事的两面。**

`age < 12` 和 `age >= 12` 加起来必然覆盖所有情况 —— 它们就是"一件事的两面"。

万一哪天你把标准改成 14 岁，你得**同时改两处**，改漏一处就会出现诡异的 bug（比如 13 岁既打儿童票又打成人票，或者什么都不打）。

`else` 让你只说一次条件：

```python
age = 8

if age < 12:
    print("儿童票：20 元")
else:
    print("成人票：40 元")
```

**`else` 的意思就是：上面那个条件不成立的时候，就走我。**

现在标准改成 14 岁，你只需要改一行。

## 二、else 长什么样

```
if 条件:
    条件成立时做的事
else:
    条件不成立时做的事
```

四个细节：

1. `else` 要和 `if` **对齐**（缩进一样）
2. `else` 后面**也要有冒号** `:`
3. `else` 后面**不能写条件**（这是新手最常犯的错，见下文）
4. `else` 下面的代码**也要缩进**

### ⚠️ else 后面不能跟条件

```python
if age < 12:
    print("儿童票")
else age >= 12:        # ✗ 报错！
    print("成人票")
```

为什么？因为 `else` 的定义就是"**除此之外的一切情况**"。

你已经在 `if` 里说了条件，`else` 拿走的是剩下的全部，它不需要、也不允许再写条件。

如果你想表达"否则**如果**……"，那要用下一课的 `elif`。

## 三、if 和 else 必定执行其中一个

这是 `else` 最重要的性质，也是它和"两个独立 if"最大的区别。

```python
age = 8
if age < 12:
    print("儿童票")
else:
    print("成人票")
```

- age = 8 → 打印"儿童票"
- age = 20 → 打印"成人票"
- age = -5 → 打印"儿童票"（负数也小于 12）
- age = 12 → 打印"成人票"

**无论 age 是什么，两段里必定有一段被执行，而且只执行一段。**

这叫**互斥且完备**：不会两段都跑，也不会一段都不跑。

对比一下两个独立 if 的写法：

```python
if age < 12:
    print("儿童票")
if age > 30:
    print("青年票")
```

age 是 8 时，第一个成立、第二个不成立；age 是 35 时，第一个不成立、第二个成立；
age 是 20 时 —— **两个都不成立，什么都不打印。**

所以：**当两种情况是"一件事的两面"时，用 if/else；当它们是两件独立的事时，用两个 if。**

## 四、else 里的代码也一样要缩进

```python
score = 45

if score >= 60:
    print("及格了")
    print("恭喜")
else:
    print("没及格")
    print("下次加油")
```

score 是 45，走 else，打印：

```
没及格
下次加油
```

缩进在这里的作用和 if 里完全一样：**缩进多少行，就有多少行归它管。**

一个常见错误 —— else 下面的代码没缩进：

```python
if score >= 60:
    print("及格了")
else:
print("没及格")         # ✗ 忘了缩进
```

同样是 `IndentationError: expected an indented block`。

## 五、一个更实际的例子

写一个程序，判断一个数字是奇数还是偶数：

```python
num = 17

if num % 2 == 0:
    print("偶数")
else:
    print("奇数")
```

`%` 是取余运算符，`num % 2` 就是"除以 2 的余数"。

- 余数是 0 → 能被 2 整除 → 偶数
- 余数不是 0 → 奇数

这正是"一件事的两面"，用 if/else 完美对应。

## 六、if / else 可以整体放在别的代码里

这一点现在提一句，后面会经常见到。

if/else 是一个整体结构，它可以出现在任何需要语句的地方。比如下一章的循环里面、后面学的函数里面。

现在你只需要知道：**if 和 else 永远成对出现，else 不能单独存在。**

```python
else:               # ✗ 报错：else 前面没有 if
    print("否则")
```

报 `SyntaxError: invalid syntax`。
