# input 得到的永远是字符串

> 上一课结尾留了个悬念：为什么 `18 + 18` 会变成 `1818`？
>
> 这一课把这件事讲透。它是初学者**最常踩、也最莫名其妙**的坑 —— 因为代码看着完全没问题，结果却离谱。搞懂它，你能省下未来几十个小时的调试时间。

## 先看这个诡异的现象

```python
a = input("请输入一个数字：")
b = input("请再输入一个数字：")
print(a + b)
```

输入 `18` 和 `18`，你以为会得到 `36`，实际输出：

```
1818
```

再看一个：

```python
age = input("你今年几岁？")
print(age + 1)
```

输入 `18`，你以为会输出 `19`，实际得到一坨红色报错：

```
TypeError: can only concatenate str (not "int") to str
```

**两个问题，同一个根源。**

## 根源：input 给你的永远是「文字」

上一课说过：`input()` 返回字符串。

所以用户输入 `18`，你拿到的**不是数字十八**，而是**由字符「1」和「8」组成的一段文字** —— 跟用户输入「abc」在类型上没有任何区别。

用 `type()` 亲眼看一下（这是第 10 课学的工具）：

```python
a = input("请输入一个数字：")
print(type(a))
```

输入 `18`，输出：

```
<class 'str'>
```

`str` 就是字符串。**哪怕用户敲的是纯数字，Python 也把它当文字。**

为什么这么设计？因为 Python 无从判断你的意图：

| 用户输入 | 你的意图可能是 |
|---|---|
| `18` | 数字十八（要算年龄） |
| `18` | 文字"18"（要当门牌号，因为 "18号" 和 "18.0号" 不一样） |
| `007` | 文字（前面的 0 有意义，转成数字会变成 7） |
| `+86 138...` | 电话号码（是文字，不是数） |

Python 选择**不做猜测** —— 还记得第 1 课那句话吗：*电脑快得离谱，但一个字都不会猜*。它一律返回字符串，把转换的决定权交给你。

## 那么 + 号到底在干嘛

关键认知：**`+` 对不同类型有不同含义。**

```python
print(18 + 18)      # 数字 + 数字  → 数学加法  → 36
print("18" + "18")  # 文字 + 文字  → 拼接      → "1818"
```

同一个符号，两种行为。这不是 Python 捣乱，而是它按**参与运算的东西的类型**来决定做什么。

再看几种组合，感受一下：

```python
print("你好" + "世界")     # 你好世界（拼接）
print("猫" * 3)           # 猫猫猫（字符串也能乘！重复 3 次）
print(3 * 5)              # 15（数学乘法）
```

**字符串居然能乘？** 是的，`"猫" * 3` 就是把「猫」重复三次。这进一步说明：`+` `*` 这些符号的含义，取决于它们操作的是什么类型。

回到 `age + 1` 的报错：

```
TypeError: can only concatenate str (not "int") to str
```

翻译：*我只能把字符串和字符串拼接，没法把字符串和整数拼到一起*。

Python 在告诉你：**你混用了类型。** 它拒绝猜 —— 到底是想把 1 当成文字拼上去（得 `"181"`），还是想把 age 转成数字加（得 `19`）？它不知道，所以报错让你说清楚。

## 解法：转成数字再算

要算数，就用 `int()` 或 `float()` 把字符串转成数字（第 10 课学过）。

```python
a = input("请输入一个数字：")
b = input("请再输入一个数字：")
print(int(a) + int(b))
```

输入 `18` 和 `18`：

```
36
```

对了。

有三种写法，看清区别：

```python
# 写法一：先转换，存进新变量（最清楚，推荐初学用）
a = input("数字：")
num = int(a)
print(num + 10)

# 写法二：转换和使用写在一行（简洁）
a = input("数字：")
print(int(a) + 10)

# 写法三：拿到就转（最常用，变量从头到尾都是数字）
num = int(input("数字："))
print(num + 10)
```

写法三最精炼：用户输入 → 立刻转成整数 → 存进 `num`。**以后 `num` 就是干干净净的数字**，不会再有类型混淆。

**行业习惯**：凡是 `input` 用来算数的，都在**接收时立刻转换**，不要留着字符串版本到处传。

带小数的用 `float()`：

```python
price = float(input("价格是多少？"))
print(price * 0.8)   # 打八折
```

## 常见翻车现场

### 翻车一：转了输入，忘了另一个

```python
a = int(input("数字："))
b = input("数字：")      # ← 忘了转
print(a + b)             # 还是报错
```

`int` 和 `str` 依然不能相加。要么都转，要么都不转。

### 翻车二：用户输入了非数字

```python
age = int(input("你今年几岁？"))
```

用户输入「十八」或「abc」：

```
ValueError: invalid literal for int() with base 10: 'abc'
```

`int()` 只能转换**长得像整数的文字**。这是个新问题 —— **程序崩了**。

怎么处理？老实说，**这道题超出了现阶段**。完整解法是「异常捕获」（`try...except`），在《Python 详细基础 3》里讲。

现阶段你只要知道：**`int(input(...))` 在用户输入非法内容时会崩溃**，这是正常的、已知的限制。第 14 课会教你用 `strip()` 先清洗掉空格这类小毛病。

### 翻车三：该用字符串时转成了数字

```python
phone = int(input("手机号："))
```

用户输入 `13800138000`，能转成功，但这是**错的**。手机号是标识符不是数值，转成整数后前导 0 会丢失（比如 `013800138000` 变成 `13800138000`）。

**判断标准：这个东西要参与算术吗？** 不参与就别转。

## 这一课你只需要记住三句话

1. `input()` 返回的**永远是字符串**，哪怕用户敲的是数字
2. 想算数，用 `int()` / `float()` **转换后再算**
3. `+` 的含义取决于类型：数字相加是数学，字符串相加是拼接

a = input("第一个数：")
