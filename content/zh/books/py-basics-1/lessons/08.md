# 字符串：处理文字

> 程序处理的不只是数字。名字、地址、一句话、一整篇文章——这些在 Python 里都叫**字符串**。

## 什么是字符串

**字符串（string，简称 str）**就是一串文字。用引号包起来：

```python
name = "张三"
city = '杭州'
sentence = "他说：'今天天气不错'"
```

三种写法都能用：

| 写法 | 例子 | 什么时候用 |
|---|---|---|
| 双引号 | `"你好"` | 最常用 |
| 单引号 | `'你好'` | 文字里本身有双引号时 |
| 三引号 | `"""多行"""` | 文字跨多行时 |

**为什么要有两种引号？** 为了让你在文字里安全地包含另一种引号：

```python
print("他说：'好的'")      # 外面双引号，里面单引号，没问题
print('她说："真的"')      # 反过来也行
```

如果非要在双引号里放双引号，就得用反斜杠转义：

```python
print("他说：\"好的\"")     # \" 表示一个普通的双引号字符
```

> 💡 建议：**默认用双引号**，需要时再用单引号。统一风格比争论哪种更好更重要。

## 三引号：多行文字

```python
poem = """床前明月光，
疑是地上霜。
举头望明月，
低头思故乡。"""
print(poem)
```

三个引号（单双都行）包起来的文字可以跨行，**换行符会被保留**。前面第 1 章讲过的 `\n`，在这里就是直接敲回车。

## 拼接：把字符串接起来

```python
first = "你好"
second = "世界"
print(first + second)      # 你好世界
```

用 `+` 就能接起来。但注意它**不会自动加空格**：

```python
print("你好" + "世界")     # 你好世界   ← 粘在一起了
print("你好" + " " + "世界")  # 你好 世界
```

**字符串 + 数字会报错**，这是新手最常撞的墙之一：

```python
age = 18
print("我今年" + age)     # TypeError！
```

```
TypeError: can only concatenate str (not "int") to str
```

翻译："只能把字符串和字符串接起来，不能接 int。"

**怎么修？** 把数字转成字符串：

```python
print("我今年" + str(age))     # ✅
print("我今年", age)            # ✅ print 用逗号会自动加空格并转换
```

下一课会专门讲 `str()` 这个转换函数。

## 重复：字符串也能"乘"

```python
print("哈" * 3)          # 哈哈哈
print("-" * 20)          # --------------------
print("=" * 10 + " 标题 " + "=" * 10)
```

第 1 章测验里那道三角形题用的就是这个特性。做分隔线时特别顺手。

## 长度：len()

```python
text = "Hello"
print(len(text))         # 5

print(len("你好"))       # 2  ← 中文每个字算 1
print(len(""))           # 0  空字符串
```

**`len()` 数的是"字符个数"**，不是字节数。中文、emoji 都按 1 个字符算（这点和某些语言不一样，Python 3 处理得很自然）。

## 索引：取出某一个字符

字符串里的每个字符都有一个编号，叫**索引（index）**。

**关键规则：从 0 开始数。**

```
字符:    H    e    l    l    o
索引:    0    1    2    3    4
```

```python
text = "Hello"
print(text[0])     # H
print(text[1])     # e
print(text[4])     # o
```

第 1 个字符的索引是 **0**，不是 1。这是编程里最反直觉、也最容易犯错的地方之一，几乎所有语言都这样。

### 负数索引：从末尾开始数

```python
print(text[-1])    # o  ← 最后一个
print(text[-2])    # l  ← 倒数第二个
```

想拿最后一个字符时，`text[-1]` 比 `text[len(text)-1]` 简洁太多。

### 索引越界

```python
print(text[10])    # IndexError: string index out of range
```

"你要第 10 个，但这个字符串只有 5 个。"

## 切片：取出一段

```python
text = "Hello World"
print(text[0:5])     # Hello
print(text[6:11])    # World
print(text[6:])      # World  ← 省略右边，取到末尾
print(text[:5])      # Hello  ← 省略左边，从头开始
print(text[:])       # Hello World  ← 都省略，全部
```

**切片的规则：含左不含右。**

`text[0:5]` 取的是索引 0、1、2、3、4 —— **不含 5**。这个"右边要加 1"的规则一开始很别扭，但用多了会变成本能。

记忆技巧：想象索引是"字符之间的缝隙"，`[0:5]` 就是从 0 号缝切到 5 号缝。

```
  H   e   l   l   o
0   1   2   3   4   5
```

切片也可以用负数，还能加步长：

```python
print(text[::2])     # HloWrd  ← 每隔一个取一个
print(text[::-1])    # dlroW olleH  ← 反转字符串
```

`[::-1]` 反转是个很常用的小技巧，值得记住。

## 字符串是"不可变"的

**这一点非常重要**：字符串创建后，它的内容**不能改**。

```python
text = "Hello"
text[0] = "h"        # TypeError！
```

想改怎么办？**造一个新的**：

```python
text = "Hello"
text = "h" + text[1:]      # 用切片拼出新的
print(text)                # hello
```

看起来像是"改了"，其实是"用旧的部分做了一个新的，再把标签贴到新的上面"。这就是第 1 课说的"变量是标签不是盒子"。

## 常用方法：字符串自带的工具

字符串自带很多现成的操作，用 `点` 调用：

```python
text = "  Hello World  "

print(text.strip())        # "Hello World"      去掉两端空格
print(text.lower())        # "  hello world  "  转小写
print(text.upper())        # "  HELLO WORLD  "  转大写
print(text.replace("o", "0"))   # "  Hell0 W0rld  "  替换
print(text.split())        # ['Hello', 'World']  按空格切成列表
```

**注意：这些方法都不改变原字符串**（因为字符串不可变），而是**返回一个新的**：

```python
text = "Hello"
print(text.upper())    # HELLO
print(text)            # Hello  ← 原样没变！

# 想保留结果就要重新赋值
text = text.upper()
print(text)            # HELLO
```

### 查找：in 和 find

```python
text = "Hello World"

print("World" in text)       # True   ← 有没有
print("Python" in text)      # False
print(text.find("World"))    # 6      ← 在哪（找不到返回 -1）
```

`in` 是判断"是否包含"，返回 True/False，用得非常多。

### 统计和替换

```python
text = "滚滚长江东逝水"
print(text.count("滚"))      # 2
print(len(text))             # 7
```

## 格式化：把变量塞进字符串

拼字符串用 `+` 很麻烦（还要转类型），Python 有个好得多的写法：**f-string**。

```python
name = "张三"
age = 18
print(f"我叫{name}，今年{age}岁")
```

**在字符串前面加一个 `f`**，然后用 `{}` 把变量包进去。花括号里会自动替换成变量的值，还自动帮你转类型——不用再写 `str(age)`。

花括号里甚至能写表达式：

```python
print(f"明年我就{age + 1}岁了")
print(f"名字长度是{len(name)}")
```

> 💡 f-string 是 Python 3.6 引入的，现在是最推荐的写法。网上老教程里常见的 `%` 和 `.format()` 已经不推荐了，遇到认识就行，自己写用 f-string。

## 转义字符

有些字符没法直接打出来，用反斜杠 `\` 表示：

| 写法 | 含义 |
|---|---|
| `\n` | 换行 |
| `\t` | 制表符（Tab） |
| `\\` | 一个普通的反斜杠 |
| `\"` | 一个普通的双引号 |
| `\'` | 一个普通的单引号 |

```python
print("第一行\n第二行")
print("路径：C:\\Users\\name")
```

**如果字符串里反斜杠很多**（比如 Windows 路径、正则表达式），可以在引号前加 `r`，表示"原始字符串，别处理转义"：

```python
print(r"C:\Users\name")     # 直接输出，不用写两个反斜杠
```
