# 实战：猜数字游戏

> 第 5 章最后一课。不学新语法，把前四课的东西**串成一个真正能玩的游戏**。
>
> 写完它你会发现：一个"能一直玩下去"的程序，其实就是**循环 + 判断 + 一个出口**这三样东西。

## 一、我们要做什么

先说清楚需求，这一步比写代码重要：

> 电脑心里想一个 1 到 100 的数字，你来猜。
> 每次猜完，电脑告诉你**大了**还是**小了**，直到你猜中为止。

就这些。看起来简单，但它已经具备了"程序"的所有要素：

| 需求 | 需要的东西 |
|---|---|
| 电脑心里有个数字 | 变量 |
| 你来猜 | 读取输入 |
| 告诉你是大了还是小了 | `if` / `elif` / `else` |
| 直到猜中为止 | **循环** ← 第 5 章的主角 |
| 猜中就结束 | `break` |

**缺了循环，这个游戏只能玩一次。**

## 二、先写一个"只能玩一次"的版本

不要一上来就写最终版。先看最小版本，你才能明白后面每一版加了什么。

```python
answer = 42
guess = 30          # 真实场景里这里是 int(input())

if guess == answer:
    print("猜中了！")
elif guess < answer:
    print("太小了")
else:
    print("太大了")
```

运行：

```
太小了
```

能判断了，但**只能猜一次**。这就是前四章的水平线 —— 程序跑一遍就结束。

## 三、加上循环：让它一直玩

现在动第 5 章的手术。把"猜一次"这段代码包进循环里：

```python
answer = 42
guess = 30

while True:
    if guess == answer:
        print("猜中了！")
        break              # ← 猜中，结束
    elif guess < answer:
        print("太小了")
    else:
        print("太大了")
```

⚠️ 先别急着运行这个版本 —— 它有个**严重问题**。

`guess` 从头到尾都是 30，`while True` 又永远成立，于是：

```
太小了
太小了
太小了
...（永远）
```

**死循环。** 因为你只是把代码包进了循环，但没让"下一次猜"真的发生。

这正好复习了第 21 课讲的：循环体里必须有让条件走向不成立的东西。这里 `break` 唯一的触发条件是 `guess == answer`，而 `guess` 永远不变 —— 它永远不会成立。

## 四、把输入放进循环里

关键的一步：**读取猜测的那行代码，必须在循环内部。**

```python
answer = 42

while True:
    guess = int(input())      # ← 每一轮都重新问一次

    if guess == answer:
        print("猜中了！")
        break
    elif guess < answer:
        print("太小了")
    else:
        print("太大了")
```

注意 `guess = int(input())` 现在**缩进在 while 里面**了。这意味着"每一轮都会重新读一次输入"。

这就是为什么它能一直玩下去：

| 轮次 | 你输入 | 判断 | 输出 |
|---|---|---|---|
| 1 | 30 | 30 < 42 | 太小了 |
| 2 | 60 | 60 > 42 | 太大了 |
| 3 | 42 | 相等 | 猜中了！→ break |

**"读取输入"必须在循环内，否则循环转得再久，读到的还是同一个值。** 这是新手写交互式程序最常见的错误。

### 为什么是 `int(input())`？

第 12 课讲过：`input()` 拿到的是**字符串**。

拿字符串和数字比大小会直接报错：

```python
"30" < 42     # TypeError: '<' not supported between 'str' and 'int'
```

所以必须先用 `int()` 转成数字。这个转换在本课每次读取时都要做一次。

## 五、加上次数限制（让它更完整）

真正好玩的游戏会给次数限制 —— 比如只有 5 次机会。

思路：用一个变量记录"已经猜了几次"，超了就结束。

```python
answer = 42
max_tries = 5
tries = 0

while True:
    guess = int(input("请猜一个数字: "))
    tries = tries + 1

    if guess == answer:
        print("猜中了！用了", tries, "次")
        break
    elif guess < answer:
        print("太小了")
    else:
        print("太大了")

    if tries >= max_tries:
        print("次数用完了，答案是", answer)
        break
```

注意最后一个 `if` 的位置 —— **它在 `elif` 结构之外**，没有缩进在 `elif` 里。

为什么？因为不管猜大了还是猜小了，都要检查次数。如果缩进进 `elif` 的某个分支，另一个分支就不会检查了。

**判断"这一段代码归谁管"，永远只看缩进。** 这是第 4 章和第 5 章共用的一条铁律。

## 六、完整版（可以直接抄走用）

把上面几版合起来，加上一点输入保护：

```python
answer = 42
max_tries = 5
tries = 0

print("我想了一个 1 到 100 的数字，你有 5 次机会")

while True:
    guess = int(input("请猜: "))
    tries = tries + 1

    if guess == answer:
        print("猜中了！用了", tries, "次")
        break
    elif guess < answer:
        print("太小了，还剩", max_tries - tries, "次")
    else:
        print("太大了，还剩", max_tries - tries, "次")

    if tries >= max_tries:
        print("次数用完了，答案是", answer)
        break
```

这就是本册到目前为止**最完整的一个程序**。

## 七、复盘：它用到了什么

把整册的知识过一遍，看看这个游戏吃进去了多少：

| 章节 | 用在哪 |
|---|---|
| 第 2 章 变量 | `answer` / `tries` / `max_tries` |
| 第 2 章 类型转换 | `int(input())` |
| 第 3 章 输入 | 每一轮读一次猜测 |
| 第 3 章 f-string | 拼接提示语 |
| 第 4 章 if/elif/else | 大了 / 小了 / 猜中 |
| 第 5 章 while True | 一直玩 |
| 第 5 章 break | 猜中或次数用完时结束 |

**七章知识，凑成了一个别人真的会玩的东西。**

到这儿，你已经能独立写出"会一直运行、能反复接受输入、并根据输入走不同分支"的程序了 —— 猜数字、菜单计算器、简易问答，都是这个结构。

它还记不住数据（比如历史成绩）。那是基础 2（列表/字典）和基础 3（文件）的事。

## 八、一个小提醒：真实程序和练习题的差别

上面的完整版用的是 `while True` —— **真实程序就该这么写**，因为你不知道玩家要猜几次。

但在本课的练习题里，我们会用一个**次数固定**的版本（`for` + `range`）。原因是判分系统是一次性把输入喂进来的，喂完就空了；一个停不下来的 `while True` 会把它卡住。

**这不是两种写法有优劣，是场景不同。** 你自己写程序时，放心用 `while True`。

  7

## 本节测验

```quiz
type: choice
exam: true
q: 在猜数字游戏里，`guess = int(input())` 必须放在哪里？
options:
- 放在 while 循环之前，读一次就够了
- 放在 while 循环内部，每一轮都重新读
- 放在 break 后面
- 放在 if 里面
answer: 1
explain: 放在循环外的话，guess 从头到尾是同一个值，条件永远不变 —— 要么一直输出同一个结果（死循环），要么第一轮就命中。交互式程序的关键就是「每一轮都重新问一次」。
```

```quiz
type: code
exam: true
q: 补全这个猜数字程序：答案是 7，最多猜 3 次。每次读入一个猜测，相等打印「猜中了」并**立刻停止**，小于打印「太小了」，大于打印「太大了」。系统会依次输入 3、7、1 三次
stdin: |
  3
  7
  1
starter: |
  answer = 7

  for i in range(3):
      guess = int(input())
      if guess == answer:
          print("猜中了")
          # 在这里补一行
      elif guess < answer:
          print("太小了")
      else:
          print("太大了")
tests:
- assert "猜中了" in __out
- assert __out.count("太小了") == 1
hint: 猜中之后就不该再猜了 —— 跳出循环用哪个关键字？注意输入是 3（小）、7（中）、1（小）：如果没停住，最后的 1 会多输出一次「太小了」。
explain: 补的是 break。这个测试的判据是「太小了」只出现 1 次：输入 3 时输出一次，输入 7 猜中后必须立刻停止，否则输入 1 会再输出一次，count 变成 2 就不通过。这正是 break 的作用 —— 满足条件就走，不再管后面还有什么。
```
