# 用户不会按你的想法输入

> 你写好了程序，自己测试输入「北京」，一切正常。
>
> 然后你把它给别人用。有人输入了 `北京 `（末尾多敲了个空格），有人输入了 `YES`，有人输入了 `yes`，还有人输入了空字符串直接回车。
>
> **程序全部崩溃或判断错误。**
>
> 不是用户的问题 —— 是程序太脆弱。这一课教你把用户的输入**清洗干净**再用。

## 先看程序有多脆弱

一个判断是否来自北京的程序：

```python
city = input("你来自哪个城市？")

if city == "北京":
    print("哦，首都！")
else:
    print("欢迎你。")
```

自己测试输入 `北京`，输出「哦，首都！」—— 完美。

然后真实用户来了：

| 用户输入 | 实际内容 | 结果 |
|---|---|---|
| `北京` | `"北京"` | ✅ 正常 |
| `北京 ` | `"北京 "` | ❌ 走到 else |
| ` 北京` | `" 北京"` | ❌ 走到 else |
| `北京\n`（某些环境） | `"北京\n"` | ❌ 走到 else |
| `Beijing` | 英文 | ❌ 走到 else |

**只有一种写法能正常工作，其他全失败。**

原因很直白：`==` 是**精确比较**。`"北京 "` 和 `"北京"` 是两个不同的字符串 —— 多一个空格就是不同。

而人类输入天然带着各种"杂质"：**多余空格、大小写不统一、全角半角混用**。

结论：**永远不要拿用户的原始输入直接做判断。** 先清洗。

## 武器一：strip() —— 去掉首尾空白

```python
text = "  北京  "
print(text.strip())      # 北京
```

`strip()` 去掉字符串**两端**的空白字符（空格、Tab、换行），**中间的空格不动**：

```python
print("  北京  ".strip())        # "北京"
print("北 京".strip())           # "北 京"（中间的空格保留）
print("\t北京\n".strip())        # "北京"（Tab 和换行也去掉）
```

**每次拿到 input 就 strip 一下，应该成为肌肉记忆：**

```python
city = input("你来自哪个城市？").strip()
```

注意写法：`input()` 返回字符串，**可以直接在后面接 `.strip()`**，一步到位。

还有两个变体：

```python
text = "  北京  "
print(text.lstrip())   # "北京  "  只去掉左边（left）
print(text.rstrip())   # "  北京"  只去掉右边（right）
```

`strip` 用得最多，另外两个偶尔救急。

### 带参数的 strip

`strip()` 还能指定要去掉哪些字符：

```python
print("***重要***".strip("*"))       # "重要"
print("￥100元".strip("￥元"))        # "100"
```

这个不常用，知道有这回事就行。

## 武器二：lower() / upper() —— 统一大小写

英文输入最大的麻烦是大小写：

```python
answer = input("继续吗？(yes/no)")
if answer == "yes":
    print("继续")
```

用户输入 `YES`、`Yes`、`yES` —— 全部失败。

解法：比较前统一转成小写。

```python
answer = input("继续吗？(yes/no)").strip().lower()

if answer == "yes":
    print("继续")
```

现在 `YES`、`Yes`、` yes ` 全部能识别。

`lower()` 把字符串转小写，`upper()` 转大写：

```python
print("Hello World".lower())    # "hello world"
print("Hello World".upper())    # "HELLO WORLD"
```

**注意：只对英文有效。** 中文没有大小写，`"北京".lower()` 还是 `"北京"`（不会报错，原样返回）。

### 连锁调用

上面那行有个重要写法：

```python
input("...").strip().lower()
```

**方法一个接一个往下点**，这叫**链式调用**。执行顺序从左到右：

1. `input(...)` 得到 `" YES "`
2. `.strip()` 得到 `"YES"`
3. `.lower()` 得到 `"yes"`

这是 Python 里非常常见的风格，看惯了会觉得比拆成三行更清楚。

## 武器三：in —— 包含判断

前面都是「**必须完全等于**某个值」。但很多时候你需要的是「**包含**某个词就行」。

```python
city = input("你来自哪个城市？").strip()

if "北京" in city:
    print("哦，首都！")
```

现在这些输入全部能识别：

```
北京          ✅
北京市        ✅
北京朝阳区     ✅
我在北京上班   ✅
```

`in` 判断的是**子串**：`"北京" in "北京市朝阳区"` 是真的，因为后者**包含**前者。

对比一下两种判断：

| 判断 | 含义 | 适合场景 |
|---|---|---|
| `city == "北京"` | 必须完全等于 | 选项固定的场景（如 yes/no） |
| `"北京" in city` | 包含即可 | 自由输入、可能有附加信息的场景 |

**经验法则：自由文本用 `in`，固定选项用 `==`（配合 lower）。**

### 判断不等于

`in` 的反面是 `not in`：

```python
if "北京" not in city:
    print("不是北京的")
```

## 武器四：真的空输入

用户什么都不输直接回车：

```python
name = input("你叫什么？").strip()
```

`name` 会是**空字符串** `""`。

这在程序里是合法的，但通常没意义。判空写法：

```python
if name == "":
    print("你还没输入名字呢")
else:
    print(f"你好，{name}")
```

更 Pythonic 的写法（利用空字符串是「假」的特性）：

```python
if not name:
    print("你还没输入名字呢")
```

`not name` 在 `name` 为空字符串时为真。这个写法很常见，但初学阶段**用 `name == ""` 更直观**，不容易绕晕。

## 组合起来：一个健壮的输入

把三个武器用在一起：

```python
city = input("你来自哪个城市？").strip()

if not city:
    print("你没有输入城市。")
elif "北京" in city:
    print("哦，首都！")
elif "上海" in city:
    print("魔都！")
else:
    print(f"欢迎来自{city}的朋友。")
```

（关于 `if / elif / else` 多分支判断，会在《Python 详细基础 2》详细展开。这里先感受一下结构。）

这一小段程序已经能处理：多余空格、空输入、各种城市写法。**这才是能给别人用的程序。**

## 一线之隔：清洗不能过度

清洗是好事，但别洗过头：

```python
# 过度清洗的坏例子
password = input("密码：").strip()
```

密码首尾的空格**可能是用户有意输入的**！`strip()` 会把密码改掉，导致用户设置的密码和验证时对不上。

**判断标准：这个输入是「标识符/选择」还是「内容」？**

| 输入类型 | 该不该 strip | 例子 |
|---|---|---|
| 城市名、姓名、选项 | ✅ 该 | 用户多敲空格是无意的 |
| 密码、文章内容、代码 | ❌ 不该 | 空格本身是内容的一部分 |

## 这一课你只需要记住三句话

1. **永远不要直接判断用户原始输入** —— 先 `strip()` 去空格
2. 英文输入比较前 **`.lower()` 统一大小写**
3. 自由文本用 **`in`** 做包含判断，固定选项才用 `==`
