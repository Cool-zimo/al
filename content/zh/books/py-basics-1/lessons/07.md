# 数字：整数与小数

> Python 里有两种常用的数字，它们的区别很微妙，但搞错了会闹出真 bug。

## 两种数字

```python
age = 18          # 整数 int
price = 9.9       # 小数 float
```

- **int（整数）**：没有小数点。`18`、`0`、`-5`、`1000000`
- **float（浮点数）**：有小数点。`9.9`、`3.0`、`-0.5`

**为什么小数叫"浮点数"？** 因为小数点可以"浮动"——`1.0`、`0.1`、`100.5` 用的都是同一种存储格式，小数点位置是可变的。这个名字来自计算机内部怎么存小数，你只要记住 **float = 小数** 就行。

> 💡 一个反直觉的点：`3` 是 int，`3.0` 是 float。虽然数值一样，但在 Python 眼里它们是**两个不同的类型**。

## 基本运算

| 运算符 | 含义 | 例子 | 结果 |
|---|---|---|---|
| `+` | 加 | `7 + 3` | `10` |
| `-` | 减 | `7 - 3` | `4` |
| `*` | 乘 | `7 * 3` | `21` |
| `/` | 除 | `7 / 2` | `3.5` |
| `//` | 整除（取商） | `7 // 2` | `3` |
| `%` | 取余（取模） | `7 % 2` | `1` |
| `**` | 幂 | `2 ** 10` | `1024` |

前四个不用解释，重点看后三个。

### `/` 永远返回小数

这是 Python 3 和 Python 2 最大的差别之一，也是新手常踩的坑：

```python
print(10 / 2)     # 5.0  ← 注意！是 5.0 不是 5
print(10 / 4)     # 2.5
print(4 / 2)      # 2.0
```

**即使能整除，`/` 的结果也是 float。** 这看起来有点怪，但规则统一反而好记：想要小数用 `/`，想要整数用 `//`。

### `//` 整除：只要商，扔掉余数

```python
print(7 // 2)     # 3
print(8 // 2)     # 4
print(-7 // 2)    # -4  ← 注意负数向下取整
```

负数那条不用死记，用到了再查。日常 `//` 主要用在正整数上。

**整除最典型的用途**：算"能装几箱"。

```python
eggs = 47
boxes = eggs // 12      # 每箱 12 个，能装几箱？
print(boxes)            # 3
```

### `%` 取余：只要余数

```python
print(7 % 2)      # 1
print(8 % 2)      # 0
print(47 % 12)    # 11
```

接着上面的例子：47 个鸡蛋装 3 箱（36 个）后，**还剩几个**？

```python
left = 47 % 12
print(left)       # 11
```

`%` 还有个超高频的用法——**判断奇偶**：

```python
n = 7
print(n % 2)      # 1 → 奇数
n = 8
print(n % 2)      # 0 → 偶数
```

以及**判断能不能整除**：`n % 3 == 0` 就是"n 能被 3 整除"。

### `**` 幂运算

```python
print(2 ** 10)    # 1024
print(3 ** 2)     # 9
print(9 ** 0.5)   # 3.0  ← 开平方就是 0.5 次方
```

注意：**Python 没有 `^` 运算符**。`2 ^ 3` 在 Python 里是按位异或（二进制运算），结果是 `1`，不是 8。这是个经典陷阱，从其他语言转过来的人最容易踩。

## 运算优先级

和数学一样：先乘除后加减。

```python
print(2 + 3 * 4)      # 14，不是 20
print((2 + 3) * 4)    # 20，括号优先
```

完整优先级（从高到低）：

1. `()` 括号
2. `**` 幂
3. `*`、`/`、`//`、`%`
4. `+`、`-`

**记不住就用括号。** 这不是偷懒——加括号让读代码的人（包括三周后的你）一眼看懂意图，是好事。

> ⚠️ 一个陷阱：`-2 ** 2` 的结果是 `-4` 而不是 `4`，因为 `**` 比 `-` 优先级高，相当于 `-(2 ** 2)`。想要 4 就写 `(-2) ** 2`。

## 整数和浮点数混着算

规则很简单：**只要有 float 参与，结果就是 float**。

```python
print(1 + 2)        # 3    (int)
print(1 + 2.0)      # 3.0  (float)
print(3 * 1.5)      # 4.5  (float)
print(6 / 2)        # 3.0  (float)
```

Python 自动把 int "升级"成 float 再算，因为它不想丢掉小数部分。

## 浮点数的精度问题（必看）

这是**每个学 Python 的人都必须知道**的一件事：

```python
print(0.1 + 0.2)
```

你以为会输出 `0.3`。实际输出：

```
0.30000000000000004
```

**为什么？** 因为计算机用二进制存小数，而 `0.1` 在二进制里是**无限循环**的（就像 1/3 在十进制里是 0.333...）。存不下精确值，只能存近似值，误差就被带进了计算。

这不是 Python 的 bug，**所有编程语言都这样**，因为它们用的是同一套 IEEE 754 标准。

**怎么应对？**

第一，**不要直接用 `==` 比较两个浮点数**：

```python
print(0.1 + 0.2 == 0.3)      # False ！
```

第二，要比较就比"差值够不够小"：

```python
a = 0.1 + 0.2
b = 0.3
print(abs(a - b) < 0.00001)  # True
```

第三，**涉及钱的计算用整数分，不用元**：

```python
# 别这样
price = 19.99
total = price * 3

# 这样
price_cents = 1999
total_cents = price_cents * 3
print(total_cents / 100)     # 59.97
```

> 💡 记住：浮点数适合**科学计算**（差一点点无所谓），不适合**精确计数**（钱、库存、票数）。后者用整数。

## 大数字和可读性

Python 的整数**没有大小限制**，想多大就多大：

```python
print(2 ** 100)   # 一个 31 位的巨大数字，Python 算得毫无压力
```

很多语言到这里会溢出，Python 不会。

写大数字时可以用下划线分组，Python 会自动忽略它：

```python
population = 1_400_000_000     # 等价于 1400000000
print(population + 1)
```

下划线只是给你看的，让数字一眼能数清位数。

## 几个常用的内置函数

```python
print(abs(-5))        # 5     绝对值
print(round(3.7))     # 4     四舍五入
print(round(3.14159, 2))   # 3.14  保留 2 位小数
print(max(3, 7, 2))   # 7     最大的
print(min(3, 7, 2))   # 2     最小的
```

> ⚠️ `round()` 有个"银行家舍入"的怪脾气：`round(2.5)` 得 `2` 而不是 `3`，`round(1.5)` 得 `2`。它遇到正好在中间的数时会取最近的**偶数**。日常用问题不大，但如果你在写财务报表，要特别注意。

算一算：你有 47 个鸡蛋，每 12 个装一箱。

```quiz
type: code
q: 算出能装几箱、还剩几个，用 print 输出这两个数
starter: |
  eggs = 47
  per_box = 12
  
  # 用 // 算能装几箱，存进 boxes
  # 用 % 算还剩几个，存进 left
  
  print(boxes)
  print(left)
tests:
- assert "3" in __out
- assert "11" in __out
hint: boxes = eggs // per_box，left = eggs % per_box。别忘了先赋值再 print，否则会 NameError。
explain: // 和 % 是一对搭档：一个给商，一个给余数。这个组合在编程里出现频率极高 —— 分页、分组、轮转、进制转换，全是它俩。
```
