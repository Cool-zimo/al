## 第一部分 · 选择题

检验这章的概念有没有真正记住。

```quiz
type: choice
q: 执行 age = input("几岁？") 时用户输入了 18。请问 age 里存的是什么类型？
options:
- 整数 18
- 字符串 "18"
- 浮点数 18.0
- 取决于用户输的是不是数字
answer: 1
explain: input() 永远返回字符串，无论用户输入什么内容。这是第 12 课的核心。想算数必须用 int() 或 float() 转换，这也是初学者最常踩的坑。
```

```quiz
type: choice
q: name = "小红"，下面哪行代码的引号前漏了 f？
code: |
  print("你好，{name}")
options:
- print("你好，{name}")
- print(f"你好，{name}")
- 两行都漏了
- 两行都没漏
answer: 0
explain: 字符串前面没有 f，Python 就把 {name} 当普通文字原样输出，结果是"你好，{name}"。看到输出里出现大括号，第一反应就该检查是不是漏了 f。
```

```quiz
type: choice
q: 执行 "  Hello  ".strip() 得到什么？
options:
- "Hello"
- "  Hello"
- "Hello  "
- "  Hello  "
answer: 0
explain: strip() 去掉字符串两端的空白，保留中间的。所以 "  Hello  " 变成 "Hello"。如果是 "He llo"，中间的空格会保留。
```

```quiz
type: choice
q: 想判断用户输入的城市是不是北京，用户可能输「北京市」「北京朝阳区」「 北京 」。哪种判断最稳？
options:
- city == "北京"
- "北京" in city
- "北京" in city.strip()
- city.strip() == "北京"
answer: 2
explain: 两个要点：先 strip() 去掉首尾空格（避免" 北京 "这种），再用 in 做包含匹配（让"北京市"也能命中）。单用 == 太严格，单用 in 不处理空格杂质虽然也能过，但清洗是好习惯。
```

```quiz
type: choice
q: 关于清洗用户输入，下面哪种做法是错的？
options:
- 城市名用 .strip() 去掉多余空格
- 英文选项用 .lower() 统一大小写
- 密码也用 .strip() 去掉首尾空格
- 判断空输入用 if not name
answer: 2
explain: 密码首尾的空格可能是用户有意输入的内容，strip() 会把密码改掉，导致设置和验证时对不上。判断标准是：标识符/选择类输入该清洗，内容类（密码、文章、代码）不该洗。
```

## 第二部分 · 动手题

光看懂不算会。把代码写出来跑通才算。

```quiz
type: code
q: age_text 是用户输入的「18」。请算出出生年并打印「你出生于 2007 年」（按 2025 年算）
starter: |
  # 用户输入的其实是字符串 "18"
  age_text = "18"
  
  # 请转成整数，算出 2025 - 年龄，然后按格式打印
  print("TODO：把这行改成你要打印的结果")
tests:
- assert "2007" in __out
hint: birth = 2025 - int(age_text)，然后 print(f"你出生于 {birth} 年")。关键在 int() —— 字符串不能做减法。
explain: input 来的数据要参与算术必须先转换，这是硬性规则。age_text 是字符串 "18"，不转就成了 2025 - "18"，TypeError。
```

```quiz
type: code
q: 把名字和年龄排成一行输出：「小红今年 18 岁了！」（name 已 strip 过，age 是整数）
starter: |
  # 已经清洗过的数据
  name = "小红"
  age = 18
  
  # 用 f-string 打印
  print("TODO：把这行改成你要打印的结果")
tests:
- assert "小红今年 18 岁了！" in __out
hint: print(f"{name}今年 {age} 岁了！") —— 注意「今年」后面和「岁」前面的空格要照抄。
explain: f-string 让排版变成"照着成品抄一句话"，变量位置挖洞即可。真实程序里 name 来自 input().strip()、age 来自 int(input())。
```

## 第三部分 · 小项目

把整章知识串起来，做一个能给别人用的东西。

```quiz
type: project
q: 做一个「自我介绍生成器」—— 至少问用户 3 个问题，把答案清洗干净，然后排版成一段自我介绍输出
checklist:
- 至少用了 3 次 input()（建议：名字、年龄、爱好）
- 每个 input 都跟了 .strip()
- 至少有一个输入做了类型转换（int 或 float）
- 输出用了 f-string（引号前有 f，里面有 {变量}）
- 排版有结构感（有分隔线或对齐），不是一行堆完
- 自己用「带首尾空格的输入」测试过，确认不会显示多余空格
- 点过「运行」，确认真的能跑出结果
hint: 照着第 15 课那个「个人信息卡片」的结构做。先问完所有问题（每个都 strip），再做转换和计算，最后统一打印。打印时用 f-string 的 {标签:<6} 做对齐会更整齐。
explain: 这个项目考察的是整章知识的串联能力。真实程序从来不是单个知识点，而是「提问 → 清洗 → 转换 → 计算 → 排版」这条流水线。做出来一次，这个流程就刻进肌肉记忆了。
```

### 参考答案（做完再看）

```python
print("===== 自我介绍生成器 =====")
print()

# 提问，每个都 strip 清洗
name = input("你的名字：").strip()
age = int(input("你的年龄：").strip())
hobby = input("你的爱好：").strip()

# 空值兜底
if not hobby:
    hobby = "还没想好"

# 计算
birth_year = 2025 - age

# 排版输出
print()
print("------------------------------")
print(f"  {'姓名':<6}{name}")
print(f"  {'年龄':<6}{age} 岁（生于 {birth_year} 年）")
print(f"  {'爱好':<6}{hobby}")
print("------------------------------")
print(f"大家好，我是{name}，今年{age}岁，平时喜欢{hobby}。")
```

跑出来是这样：

```
===== 自我介绍生成器 =====

你的名字： 小红
你的年龄：18
你的爱好： 画画

------------------------------
  姓名   小红
  年龄   18 岁（生于 2007 年）
  爱好   画画
------------------------------
大家好，我是小红，今年18岁，平时喜欢画画。
```

即使输入时带了空格（上面故意在「小红」和「画画」前加了空格），输出依然是干净的 —— 这就是 `strip()` 的价值。

## 这一章，你学会了什么

- ✅ `input("提示语")` 让程序**停下来等用户输入**，返回字符串
- ✅ **input 拿到的永远是字符串** —— 算数前必须 `int()` / `float()` 转换
- ✅ `f"文字{变量}"` —— 引号前加 f，变量放 `{}`，**不用 `str()`**，还能写表达式
- ✅ `strip()` 去首尾空格、`.lower()` 统一大小写、`in` 做包含判断
- ✅ 健壮程序的三板斧：**提问 → 清洗 → 转换**，最后才输出
