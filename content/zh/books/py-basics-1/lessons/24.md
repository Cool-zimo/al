# 循环里的循环：嵌套

> 到目前为止，我们写的循环都是"一维"的 —— 一件重复的事。
>
> 但现实里有一类重复是**套娃**：一年有 12 个月，**每个月**又有 30 天；一张乘法表有 9 行，**每一行**又有 9 列。
>
> 这类需求用一层循环写不出来。这一课学**循环里面再放一个循环**。

## 一、它解决的是什么问题

先想一个很具体的东西：乘法表。

它长这样（只看前 3 行）：

```
1×1=1
2×1=2  2×2=4
3×1=3  3×2=6  3×3=9
```

观察它的结构，你会发现**重复出现了两次**：

- 外层重复：**行**在重复（第 1 行、第 2 行、第 3 行……）
- 内层重复：**每一行里面，列**在重复（第 3 行要算 3 次）

也就是说：**"重复做某件事"这件事本身，也要被重复 9 次。**

这就是嵌套循环存在的理由。

## 二、嵌套循环长什么样

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(i, "×", j, "=", i * j)
```

运行（节选）：

```
1 × 1 = 1
1 × 2 = 2
1 × 3 = 3
2 × 1 = 2
...
3 × 3 = 9
```

一共打印了 9 行 —— **3 × 3 = 9**。

**嵌套循环的总轮数 = 外层次数 × 内层次数。**

## 三、它到底是怎么跑的（核心理解）

这一步想不明白，后面所有嵌套的东西都会糊。

嵌套循环的执行顺序是：

> **外层走一步，内层走完一整圈。**

用上面那段代码举例：

| 外层 i | 内层 j 走过的值 | 打印了什么 |
|---|---|---|
| i = 1 | j = 1, 2, 3 | 1×1、1×2、1×3 |
| i = 2 | j = 1, 2, 3 | 2×1、2×2、2×3 |
| i = 3 | j = 1, 2, 3 | 3×1、3×2、3×3 |

外层 `i` 变成 1 之后**停在那不动**，让内层 `j` 从 1 跑到 3；内层跑完了，`i` 才变成 2，然后 `j` **又从 1 重新开始跑**。

**内层每换一轮外层，都会从头再来一遍。** 这是嵌套循环最关键的认知。

## 四、缩进决定谁在谁里面

```python
for i in range(1, 4):          # 第 1 层
    for j in range(1, 4):      # 第 2 层（缩进 4 格）
        print(i, j)            # 第 3 层（缩进 8 格）
```

判断"哪段代码归哪个循环管"，还是老规矩：**看缩进**。

- 缩进 4 格 → 属于外层循环，每轮外层执行一次
- 缩进 8 格 → 属于内层循环，每轮内层都执行

看个能说明问题的例子：

```python
for i in range(1, 3):
    print("外层开始", i)

    for j in range(1, 3):
        print("   内层", j)

    print("外层结束", i)
```

运行：

```
外层开始 1
   内层 1
   内层 2
外层结束 1
外层开始 2
   内层 1
   内层 2
外层结束 2
```

数一数：`外层开始` 出现 2 次（外层次数），`内层` 出现 4 次（2×2）。

**想验证自己有没有理解对，就把循环次数改成不一样的两个数**（比如外层 2、内层 3），看看是不是 6 次。

## 五、两个循环的计数变量必须不同名

```python
for i in range(1, 4):
    for i in range(1, 4):    # ❌ 名字重复了
        print(i)
```

这**不会报错**，但内层会把外层的 `i` 覆盖掉，结果完全乱套。

所以约定俗成：**外层用 `i`，内层用 `j`，再套一层用 `k`。**

这种 bug 不报错、结果很怪，属于"最难查的那类"。写的时候多花一秒确认变量名。

## 六、实战：完整的九九乘法表

现在是本册最漂亮的一段代码。先看成品想达到的效果：

```
1×1=1
2×1=2  2×2=4
3×1=3  3×2=6  3×3=9
...
9×1=9  9×2=18 ... 9×9=81
```

每一行的列数**跟行号相等**：第 3 行有 3 列，第 9 行有 9 列。

这说明内层的次数**不是固定的**，它取决于外层现在是第几行。写法：

```python
for i in range(1, 10):
    for j in range(1, i + 1):
        print(i, "×", j, "=", i * j)
    print("---")
```

关键在第 2 行的 `range(1, i + 1)`：

- i = 1 → `range(1, 2)` → j 只取 1 → 1 列
- i = 3 → `range(1, 4)` → j 取 1,2,3 → 3 列
- i = 9 → `range(1, 10)` → j 取 1~9 → 9 列

**内层循环的终点由外层变量决定** —— 这是嵌套循环最常用的技巧。

那个 `+ 1` 就是上一课说的"结尾取不到"：想要 j 最大到 `i`，结尾就得写 `i + 1`。

### 让它真的排成一张表

上面每个 `print` 都会换行，看起来是一长条。想让同一行的内容挤在一起，用 `end` 参数：

```python
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{i}×{j}={i*j}", end="  ")
    print()          # 这一行只负责换行
```

`print()` 默认会在结尾加一个换行。`end="  "` 的意思是"**结尾改成分两个空格，不要换行**"。

而最后那个空的 `print()`，作用就是**在内层跑完后补一个换行**，让下一行从新的一行开始。

> `end` 参数在第 13 课讲 f-string 时没提，因为它只有在这种"要手动控制排版"的场合才用得上。
> 日常打印一行一个结果时，用默认的就行。

## 七、嵌套的深度

两层是常态，三层已经开始难读了：

```python
for i in range(1, 3):
    for j in range(1, 3):
        for k in range(1, 3):
            print(i, j, k)      # 2×2×2 = 8 次
```

**如果你发现自己要写三层以上的嵌套，通常说明该换思路了**（比如后面学的函数、列表推导式）。

初级阶段遇到三层就要警惕，先问问能不能拆开。

  for row in range(3):
      for col in range(4):
          print("*", end="")

- assert __out.count("****") == 3

explain: 内层跑完一整轮，外层才走一步 —— 这是嵌套循环唯一需要记的事。print("*", end="") 让星号排成一行，行末再用一次空的 print() 换行。
