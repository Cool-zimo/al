# 变量：给数据起个名字

> 第一章我们写的程序都是"一次性的"——打印完就结束，什么都没留下。
> 从这一课开始，程序有了**记忆**。

## 先想一个问题

假设你要写一个程序，把一个人的名字打印 5 遍：

```python
print("张三")
print("张三")
print("张三")
print("张三")
print("张三")
```

能跑。但现在老板说："名字改成李四。"

你得改 5 个地方。如果是 500 行代码里散落着 50 处呢？

**变量就是为了解决这件事而存在的**：把数据存进一个"盒子"，给盒子贴个标签，以后用标签来指代里面的东西。改名字时只改盒子里的内容，所有用到这个标签的地方自动跟着变。

```python
name = "张三"
print(name)
print(name)
print(name)
print(name)
print(name)
```

现在只要改第一行，5 个 print 全跟着变。

## `=` 不是"等于"

这是新手最大的误解来源，值得单独讲清楚。

**数学里的 `=`**：表示左右两边相等，是一个陈述。
`x = 5` 意思是"x 就是 5"。

**Python 里的 `=`**：是一个**动作**，叫"赋值"（assignment）。
`x = 5` 意思是"**把 5 放进去叫 x 的盒子里**"。

所以下面这段在数学里很荒谬，在 Python 里完全正常：

```python
x = 5
x = 10
print(x)
```

为什么没问题？因为第二句不是"宣布 x 等于 10"，而是"**把盒子里的东西换成 10**"。旧的值 5 被丢掉了。

再看这个，数学里不可能，Python 里天天写：

```python
x = x + 1
```

数学上这个方程无解。但在 Python 里它的意思是：
1. 先算出右边 `x + 1` 的值（假设 x 现在是 5，那结果是 6）
2. 再把这个结果放进 x 的盒子

所以执行完 x 变成了 6。**永远是"先算右边，再放进左边"**。

> 💡 记住这个口诀：**右边是"取"，左边是"存"**。顺序永远是先取后存。

## 变量存在哪：一个形象的比喻

把电脑内存想象成一排带编号的储物柜。

```python
age = 18
```

Python 做了三件事：
1. 找个空柜子，把 `18` 放进去
2. 在柜子上贴标签 `age`
3. 记下"age → 这个柜子"的对应关系

以后你写 `print(age)`，Python 就顺着标签找到柜子，把里面的东西取出来。

**关键点**：标签和柜子是可以分开的。

```python
a = 10
b = a      # 不是"把 a 复制一份给 b"，而是"让 b 也指向 a 那个柜子"
```

这一课先不用深究这个区别（后面讲列表时会回来），但你要知道：**变量更像"标签"而不是"盒子"**，这是 Python 和其他一些语言的重要差别。

## 起名字的规则

Python 对变量名有硬性规定，违反了直接报错：

| 规则 | ✅ 可以 | ❌ 不行 |
|---|---|---|
| 只能用字母、数字、下划线 | `name_1` | `name-1`（减号不行） |
| 不能以数字开头 | `score2` | `2score` |
| 区分大小写 | `age` 和 `Age` 是两个不同的变量 | — |
| 不能用关键字 | `my_name` | `print`、`if`、`for`、`class` |
| 可以用中文（但不推荐） | `名字 = "张三"` | — |

**关键字（keyword）**是 Python 留给自己用的词，一共 35 个。你不用背，写代码时如果发现某个名字突然变色了（编辑器会高亮），那就是关键字，换一个。

## 起名字的品味

规则只是"能不能跑"，品味决定"好不好读"。

**用有意义的单词：**

```python
# 糟糕
a = 18
b = "张三"
x1 = 75.5

# 好
age = 18
name = "张三"
weight_kg = 75.5
```

**用下划线连接多个词（Python 的惯例）：**

```python
user_name = "张三"      # ✅ snake_case，Python 主流
userName = "张三"        # ⚠️ camelCase，能用但不是 Python 风格
```

**带上单位或类型，避免歧义：**

```python
timeout = 30           # 30 秒？毫秒？分钟？
timeout_seconds = 30   # ✅ 一目了然
```

**常量用全大写：**

```python
PI = 3.14159
MAX_RETRY = 3
```

这不是语法强制（Python 没有真正的常量），是约定——看到全大写，别人就知道"这个值不该改"。

## 一次给多个变量赋值

Python 有个很方便的写法：

```python
x, y, z = 1, 2, 3
print(x)
print(y)
print(z)
```

左边 3 个名字，右边 3 个值，一一对应。

**交换两个变量**时这个写法特别漂亮：

```python
a = 10
b = 20

# 其他语言需要第三个临时变量
# temp = a
# a = b
# b = temp

# Python 一行搞定
a, b = b, a
print(a)
print(b)
```

右边先算出 `(20, 10)`，再分别放进 `a` 和 `b`。这就是"先算右边再存左边"的威力。

也可以给多个变量赋同一个值：

```python
x = y = z = 0
print(x, y, z)
```

> ⚠️ 小心：这种写法对数字没问题，但对列表会有坑（讲到列表时再说）。初学阶段记住"多个名字 = 同一个数字"是安全的。

## 没有"声明"这回事

很多语言（C、Java）要求你先说清楚"这个变量是什么类型"，才能用：

```c
int age = 18;         // 必须先声明是 int
age = "hello";        // 报错！类型不匹配
```

Python 不需要。`age` 这个盒子先装数字，过一会儿装字符串，完全没问题：

```python
age = 18
print(age)
age = "十八岁"        # 换成字符串，Python 不管
print(age)
```

这叫**动态类型**——变量本身没有类型，是"值"有类型。

好处是灵活、写得快。代价是：类型错了不会在写的时候报错，要等跑到那一行才炸。这个取舍贯穿整个 Python 学习过程。

## 变量必须先赋值才能用

这是新手第二高频的报错：

```python
print(message)
```

```
NameError: name 'message' is not defined
```

翻译过来就是："你让我去取一个叫 message 的盒子，但我从没见过这个标签。"

**为什么会有这个限制？** 想想如果 Python 允许的话，它该给 `message` 什么值？0？空字符串？都不对。与其猜一个错误的答案，不如直接告诉你"这东西不存在"。

**怎么修？** 在用之前先赋值：

```python
message = "你好"
print(message)
```

> 排查 NameError 的三板斧：
> 1. 是不是拼错了？（`massage` vs `message`）
> 2. 是不是用了中文引号或全角字符？
> 3. 是不是还没赋值就用了？

## 随堂练习

下面的程序声明了两个变量，但只打印了其中一个。补上第二行，把两个都打印出来。

```quiz
type: code
q: 让程序输出「张三」和「18」，各占一行
starter: |
  name = "张三"
  age = 18
  print(name)
  # 在这里补一行，把 age 也打印出来
tests:
- assert "张三" in __out
- assert "18" in __out
hint: 照着第 3 行的格式，把 name 换成 age。print(age) —— 注意这里 age 不加引号，加了引号就变成打印"age"这两个字母了。
explain: 这是变量最核心的区分：name 是变量（取盒子里的东西），"name" 是字符串（就是这五个字母本身）。加了引号，Python 就当它是普通文字；不加引号，才当成"去取那个盒子"。
```

读完这一节，做完下面 2 题才算学完。

```quiz
type: choice
exam: true
q: 执行完下面这段代码后，x 的值是多少？
code: |
  x = 5
  x = x + 1
  x = x * 2
options:
- 12
- 10
- 11
- 报错
answer: 0
explain: 一步一步来：x=5 → x+1 得 6，存回 x（现在 x=6）→ x*2 得 12，存回 x。记住口诀：先算右边，再存左边。
```

```quiz
type: code
exam: true
q: 用变量改写这段代码，让你只需要改一处就能换名字
starter: |
  # 目标输出：
  # 欢迎你，张三
  # 再见，张三
  # 张三 很棒
  #
  # 要求：把"张三"存进一个叫 name 的变量，
  # 再用 print 拼出这三行（"张三"三个字只能出现一次）
  
  # 在这里写你的代码
tests:
- assert __out.count("张三") >= 3
- assert "欢迎你" in __out
- assert "再见" in __out
hint: 先写 name = "张三"。然后三行 print 都有两种写法：用逗号 print("欢迎你，", name)，或者用加号拼 print("欢迎你，" + name）。两种都试试。
explain: 这正是变量存在的意义 —— 「一处定义，处处生效」。以后讲函数、讲类，本质上都是在做同一件事：把会变的东西集中到一处管理。
```
