# 条件可以组合：and / or / not

> 到目前为止，每个 if 后面都只有**一个**条件。
>
> 但现实中的判断往往是复合的：「**既**满 18 岁**又**是会员」「**要么**下雨**要么**堵车」。
>
> 这一课给你三个把条件拼起来的工具：`and`、`or`、`not`。

## 一、and：两个都要成立

```python
age = 20
is_member = True

if age >= 18 and is_member:
    print("可以进入会员区")
```

`and` 的意思是**并且**。只有左右两边**同时为 True**，整个条件才是 True。

对照表（真值表）：

| 左边 | 右边 | 结果 |
|---|---|---|
| True | True | **True** |
| True | False | False |
| False | True | False |
| False | False | False |

一句话记住：**and 只要有一个 False，结果就是 False。**

### ⚠️ and 两边都要写完整的条件

这是新手高频错误：

```python
if age > 18 and < 60:        # ✗ 报错
    print("成年但未退休")
```

为什么错？因为 `< 60` 里**没有主语**，Python 不知道谁小于 60。

必须写全：

```python
if age > 18 and age < 60:    # ✓
    print("成年但未退休")
```

**口诀：and / or 连接的是两个完整的判断，每一边都要能单独成立。**

## 二、or：至少一个成立

```python
weather = "雨"

if weather == "雨" or weather == "雪":
    print("带伞")
```

`or` 的意思是**或者**。左右两边**只要有一个是 True**，整个条件就是 True。

| 左边 | 右边 | 结果 |
|---|---|---|
| True | True | True |
| True | False | **True** |
| False | True | **True** |
| False | False | False |

一句话记住：**or 只要有一个 True，结果就是 True。**

### or 也常犯同样的错

```python
if weather == "雨" or "雪":        # ✗ 逻辑错，而且不报错！
    print("带伞")
```

这个例子比 and 那个更阴险 —— **它不报错，但结果永远是对的（永远打印"带伞"）。**

为什么？因为 `"雪"` 是一个非空字符串，Python 认为它等价于 True。所以这个条件变成了：

> 天气是雨 **或者** True

结果永远是 True，不管天气是什么。

**这是最危险的一类 bug：不报错，静默地给出错误结果。**

正确写法：

```python
if weather == "雨" or weather == "雪":    # ✓
    print("带伞")
```

## 三、not：反过来

```python
is_weekend = False

if not is_weekend:
    print("要上班")
```

`not` 的意思是**取反**：True 变 False，False 变 True。

| 原来 | not 之后 |
|---|---|
| True | False |
| False | True |

`not` 只有一个操作数，写在它前面。

常见用法：

```python
if not name == "":
    print("你好，" + name)
```

不过这个例子有更地道的写法。Python 里空字符串本身就算 False，所以可以写成：

```python
if name:
    print("你好，" + name)
```

## 四、Python 的独门绝技：链式比较

判断一个分数是否在 60 到 80 之间，其他语言要这样写：

```python
if score >= 60 and score < 80:
    print("中等")
```

Python 允许你写得更像数学：

```python
if 60 <= score < 80:
    print("中等")
```

**这在其他大多数语言里是错的，但在 Python 里完全合法**，而且读起来就是数学里的区间写法。

这两句完全等价，选你读着顺的。推荐用链式写法，因为它一眼就能看出"区间"的意图。

## 五、三个关键字的优先级

混用时，优先级是：

```
not  >  and  >  or
```

也就是说 `not` 最先算，`and` 其次，`or` 最后。

```
if age < 12 or age > 65 and is_member:
```

这句会被理解成：

```
if age < 12 or (age > 65 and is_member):
```

**但强烈建议你不要依赖优先级，直接加括号。**

```python
if (age < 12) or (age > 65 and is_member):
    print("优惠票")
```

括号不花钱，但它能让读代码的人（包括三周后的你）不用去回忆优先级规则。

## 六、嵌套 if 还是 and？

想表达"满 18 岁且是会员"，有两种写法。

**写法 A：用 and**

```python
if age >= 18 and is_member:
    print("可以进入")
```

**写法 B：if 里面套 if**

```python
if age >= 18:
    if is_member:
        print("可以进入")
```

两种都对，结果一样。选哪个？

**经验法则：**

- 条件简单、只是"几个都要满足" → 用 `and`，一行搞定
- 外层条件不成立时**还要做别的事** → 用嵌套

比如：

```python
if age >= 18:
    if is_member:
        print("会员通道")
    else:
        print("普通通道")
else:
    print("未满 18 岁，不能进入")
```

这种情况嵌套更清楚，因为每个层级都有自己的 else。用 and 反而要把所有组合都列一遍。

**一句话：嵌套的层级越多，代码越难读。能用 and 压平就压平。**

## 七、一个完整的例子

判断一个年份是不是闰年（能被 4 整除且不能被 100 整除，或者能被 400 整除）：

```python
year = 2024

if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print(year, "是闰年")
else:
    print(year, "不是闰年")
```

注意括号的使用 —— 它让 `or` 左右两边各自成为一个整体，即使你不记得优先级也不会搞错。
