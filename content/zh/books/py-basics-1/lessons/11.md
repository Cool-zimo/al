# 让程序向你提问

> 到目前为止，你写的程序都是「自说自话」的：内容写死在代码里，谁运行都得到同一个结果。
>
> 这一课要打破这个状态 —— 让程序在运行时**问用户要东西**，然后用拿到的答案去做事。这是从「一段脚本」走向「一个工具」的分界线。

## 先看现在的程序有多不灵活

假设你写了个问候程序：

```python
print("你好，小明！")
print("你今年 18 岁了吧？")
```

运行一万次，它说的都是「小明」「18 岁」。

想让它问候别人，你只能**改代码** —— 把小明改成小红，再运行一次。

这很荒谬：你写程序的目的是让电脑干活，结果每次换个人干活你还得重写一遍。**程序应该是模具，不是成品。**

真正想要的是：

```
程序：你叫什么名字？
用户：小红
程序：你好，小红！
```

名字在运行的时候才确定。这就是 `input()` 存在的理由。

## input()：让程序停下来等你

```python
name = input("你叫什么名字？")
print("你好，" + name + "！")
```

运行一下（在网页的编辑器里点运行，会弹出输入框）：

```
你叫什么名字？小红
你好，小红！
```

发生了三件事：

1. 程序执行到 `input(...)`，**停住了**
2. 屏幕上显示括号里的提示文字，等你打字
3. 你按回车，你打的字被打包成一个字符串，**交给了 `=` 左边的变量**

所以 `input()` 可以理解为：**一次提问，得到一个答案**。

那句 `name = input("你叫什么名字？")` 用大白话说就是：

> 向用户提问「你叫什么名字？」，把用户回答的内容，装进叫 `name` 的盒子里。

## 括号里那段文字：提示语（prompt）

```python
input("你叫什么名字？")
```

括号里这个字符串叫**提示语**。它的作用是告诉用户「现在该输入什么」。

没有提示语会怎样？

```python
name = input()
```

程序会**停在那里什么都不显示**。用户盯着一个光标闪啊闪，完全不知道要干什么 —— 他甚至可能以为程序卡死了。

**永远给 input 加提示语。** 这是对用户最基本的善意。

提示语的写法有个小讲究，看对比：

| 写法 | 用户看到 | 评价 |
|---|---|---|
| `input("名字")` | `名字` | 能看懂，但光标紧贴着文字 |
| `input("名字：")` | `名字：` | 好一点，冒号暗示"该我输入了" |
| `input("请输入你的名字：")` | `请输入你的名字：` | 最清楚，但有点长 |

习惯上结尾加个冒号或空格，让光标和提示分开：

```python
input("请输入你的名字：")
```

## 一个完整的两段式对话

光问候没意思。让程序用拿到的名字做点事：

```python
name = input("你叫什么名字？")
print("你好，" + name + "！")
print(name + "，欢迎来到 Python 的世界。")
```

输入「小红」，输出：

```
你好，小红！
欢迎来到 Python 的世界。小红
```

注意 `name` 这个变量**可以反复用**。它被赋值一次，后面想用几次就用几次 —— 这正是变量的价值。

再来个更有用的，算出生年份：

```python
name = input("你叫什么名字？")
age = input("你今年几岁？")
print(name + "，你大概出生在 2025 年往前推 " + age + " 年的某一天。")
```

运行：

```
你叫什么名字？小红
你今年几岁？18
小红，你大概出生在 2025 年往前推 18 年的某一天。
```

**等等 —— 为什么不能直接算出 2007？**

因为 `age` 拿到的是**字符串** `"18"`，不是数字 `18`。字符串不能做减法。

这个问题第 12 课专门解决。现在先记住这个现象：**input 给你的永远是文字。**

## 为什么不能直接算

先剧透一句，免得你现在就去试错：

```python
age = input("你今年几岁？")   # 用户输入 18
print(age + age)             # 得到 1818，不是 36
```

`"18" + "18"` 是字符串的**拼接**，结果是 `"1818"`。

想做加法，得先转成数字 —— 第 12 课讲。这里先建立一个直觉：

> **从用户那来的一切，都是文字。想算数，先转换。**

## 程序停下来的那一刻

理解 `input()` 有个关键点：**它会阻塞程序**。

```python
print("第一行")
name = input("你叫什么？")
print("第三行")
```

运行过程：

```
第一行                 ← 立刻显示
你叫什么？_            ← 光标闪烁，程序在这里等你
                        （你输入"小红"并回车）
第三行                 ← 你回车之后才显示
```

**第二行不会出现在用户没回答之前。** 这在写交互程序时很重要：你想收集三样东西，就得按顺序列三个 `input`，用户答完第一个才会看到第二个。

```python
a = input("第一个问题：")
b = input("第二个问题：")
c = input("第三个问题：")
print("都答完了！")
```

## 这一课你只需要记住三句话

1. `input("提示语")` 让程序**停下来等用户输入**，返回一个字符串
2. 提示语**必须写**，否则用户不知道要干什么
3. **用户输入的一切都是字符串** —— 想算数得先转换（下一课）

## 小测验 · 让程序问你要一个颜色

程序要问你最喜欢的颜色，然后把它打印出来。框架已经写好，缺 `input` 那一句。

```python
# 下面这行要改成：问"你最喜欢的颜色是？"，把答案存进 color
color = "红色"

print("你最喜欢的颜色是：" + color)
```

- 小明
- "小明"（带引号的字符串）
- 名字：小明
- 什么都没有，input 只是显示文字
answer: 1
explain: input() 返回的是字符串，也就是带引号的 "小明"。引号不是内容的一部分，它只是表示"这是文字"。而"名字：小明"是屏幕上显示的全部内容，包含提示语，不是 name 的值。
