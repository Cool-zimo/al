# 如果…就…：if 的基本形态

> 前面三章写的所有程序，都有一个共同的毛病：**它们只会从上往下照着做一遍，做完就结束。**
>
> 不管你输入什么，它都输出同样的东西。这样的程序只能叫"脚本"，不能叫"工具"。
>
> 这一课给程序装上第一个真正像"智能"的东西 —— **看情况做事**。

## 一、if 解决的是什么问题

先想一个你每天都会遇到的场景。

早上出门前，你脑子里跑过这样一句话：

> **如果**下雨，**就**带伞。

注意这句话的结构：它有一个**条件**（下雨），和一个**只有条件成立才做的动作**（带伞）。

如果不下雨呢？那你根本不会去拿伞 —— 这个动作被**跳过**了。

这就是 `if` 的全部含义。**if 就是"如果"。**

再看一个程序里的真实例子。假设你在写一个票价程序：

- 年龄小于 12 岁 → 儿童票 20 元
- 年龄大于等于 12 岁 → 成人票 40 元

用你目前学过的知识，你写不出这个程序。因为你没有任何办法表达"看情况"。

`if` 就是为了解决这一件事而存在的。

## 二、if 长什么样

```python
age = 18

if age >= 18:
    print("你已成年")
```

运行它，你会看到：

```
你已成年
```

把 `age` 改成 10 再运行，你会看到……**什么都没有**。

这就是 if 的行为：**条件成立就做，不成立就跳过，什么都不做。**

## 三、三个必须记住的细节

这一节是全课最容易翻车的地方，请慢慢看。

### 1. 条件后面必须有冒号 `:`

```python
if age >= 18:        # ← 这个冒号不能少
    print("你已成年")
```

少了冒号会报 `SyntaxError: expected ':'`。

这是新手第一大报错，没有之一。**口诀：if 条件后面，冒号不能少。**

### 2. 冒号下面要缩进

```python
if age >= 18:
    print("你已成年")     # ← 前面空了 4 格
```

这 4 个空格**不是排版习惯，是语法的一部分**。

它告诉 Python："这行属于上面的 if。"

### 3. 缩进多少行，就有多少行归 if 管

```python
age = 18

if age >= 18:
    print("你已成年")        # 归 if 管
    print("可以考驾照了")    # 也归 if 管（缩进一样）
print("程序结束")            # 不归 if 管（没缩进）
```

运行结果：

```
你已成年
可以考驾照了
程序结束
```

现在把 `age` 改成 10：

```
程序结束
```

看懂了吗？**前两行被整个跳过了，但"程序结束"照常打印。**

因为它是唯一一个没有缩进的行 —— 不管 if 成不成立，它都会执行。

## 四、缩进：Python 最特别的地方

大多数编程语言用花括号 `{}` 来表示"这段代码属于谁"：

```javascript
if (age >= 18) {
    print("你已成年");
}
```

Python 不用花括号，它**只用缩进**。这带来两个后果：

**好处**：代码天然整齐，你不可能写出缩进混乱但能跑的代码。

**坏处**：缩进错了，程序的行为就错了 —— 而且**不报错，只是结果不对**。

### 缩进必须一致

```python
if age >= 18:
    print("你已成年")
      print("可以考驾照了")   # ✗ 这里缩进了 6 格
```

Python 会报 `IndentationError`。

规矩很简单：**同一个代码块里，每一行的缩进空格数必须完全相同。**

建议永远用 **4 个空格**。不要一会 2 格一会 4 格，更不要混用 Tab 和空格（Tab 和空格看起来一样，但 Python 眼里是两个东西，混用必炸）。

### 一个真实的坑：忘了缩进

```python
age = 18
if age >= 18:
print("你已成年")        # ✗ 忘了缩进
```

这行会报 `IndentationError: expected an indented block`。

翻译过来就是：**我等着一个缩进的代码块，你没给我。**

## 五、条件从哪来

if 后面跟的那个东西，叫**条件**。

条件的本质只有一个要求：**它的结果必须是 True 或 False。**

你在第 2 章学过的比较运算符，正是生产 True / False 的机器：

| 写法 | 意思 | 例子 | 结果 |
|---|---|---|---|
| `a == b` | a 等于 b | `5 == 5` | True |
| `a != b` | a 不等于 b | `5 != 3` | True |
| `a > b` | a 大于 b | `5 > 8` | False |
| `a < b` | a 小于 b | `5 < 8` | True |
| `a >= b` | a 大于等于 b | `5 >= 5` | True |
| `a <= b` | a 小于等于 b | `5 <= 3` | False |

所以这些都能当条件：

```python
score = 85
if score >= 60:
    print("及格了")
```

```python
name = "小明"
if name == "小明":
    print("你好，小明")
```

### ⚠️ `==` 和 `=` 不是一回事

这是新手第二大坑，而且它**报错信息很不友好**。

```python
if score = 60:       # ✗ 报错
    print("刚好及格")
```

两个符号的区别：

- `=` 是**赋值** —— "把右边的值放进左边的变量"
- `==` 是**判断** —— "左右两边相等吗？"

if 后面要的是一个"是或否"的答案，所以用 `==`。

如果你不小心写成了 `=`，Python 会报 `SyntaxError: cannot assign to literal` 之类的话，看不懂很正常 —— 记住这条规矩就行：**if 里面判断相等，永远用两个等号。**

## 六、把 if 用起来：票价程序

现在你能写出开头那个票价程序了。用两个独立的 if：

```python
age = 8

if age < 12:
    print("儿童票：20 元")

if age >= 12:
    print("成人票：40 元")
```

`age` 是 8，第一个条件成立、第二个不成立，所以只打印儿童票。

把 age 改成 20，就只打印成人票。

这个写法能用，但有点笨 —— 你写了两个条件，而这两个条件其实是**一件事的两面**（要么小于 12，要么不小于 12）。

下一课的 `else` 会让这段代码清爽很多。

```quiz
type: code
q: 天气预报说今天是 35 度。写一段代码，当温度高于 30 度时打印「今天很热」
starter: |
  temp = 35

  # 在这里写你的 if

tests:
- assert "今天很热" in __out
hint: 三件事：if 开头、条件用 temp > 30、条件后面别忘冒号，print 要缩进 4 格。
explain: temp > 30 成立，所以缩进的 print 会执行。把 temp 改成 20 再想想 —— 条件不成立，那行就被跳过了，什么都不打印。
```

## 七、if 不成立时，程序会继续往下走

这一点新手经常误解，值得单独说一次。

```python
age = 10

if age >= 18:
    print("你已成年")

print("程序结束")
print("bye")
```

运行：

```
程序结束
bye
```

**if 不成立，不代表程序停止。** 它只是跳过属于自己的那一段，然后继续往下跑。

这个理解非常重要，因为后面你会写很多个 if 排在一起 —— 每一个都是"轮到我就判断一次，不成立就跳过去"。

## 本节测验

```quiz
type: choice
exam: true
q: 下面这段代码中，哪几行一定会打印出来？
starter: |
  age = 10
  if age >= 18:
      print("A")
  print("B")
options:
- 只有 A
- 只有 B
- A 和 B 都打印
- 都不打印
answer: 1
explain: age 是 10，条件不成立，所以缩进的 print("A") 被跳过。而 print("B") 没有缩进，跟 if 无关，一定会执行。这是 if 最关键的理解点：不成立 = 跳过，不是停止。
```

```quiz
type: code
exam: true
q: 修好这段代码，让它在 score 及格时打印「及格了」。代码里有两处错误

  score = 75
  if score >= 60
  print("及格了")
tests:
- assert "及格了" in __out
hint: 第一处：if 那一行末尾少了什么符号？第二处：print 前面应该空几格？
explain: 两个错误分别是「if 后面少了冒号」和「print 忘了缩进」。这两处占了新手 if 报错的八成以上，遇到先看这两处，能省下大量时间。
```
