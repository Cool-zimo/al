# 不止两种可能：elif

> `if` / `else` 只能处理「二选一」。但现实中更多是**多选一**。
>
> 成绩分 A/B/C/D，天气分晴/雨/阴，会员分普通/白银/黄金 —— 这些都不是两个选项能装下的。
>
> `elif` 就是为此存在的。它也是整个第 4 章**最容易写错**的地方，因为它的陷阱藏得很深。

## 一、elif 解决什么问题

想把成绩分成四档：

- 90 分及以上 → 优秀
- 75 分及以上 → 良好
- 60 分及以上 → 及格
- 60 分以下 → 不及格

只用 if / else 你写不出来 —— 它们只有两条路。

`elif` 让你可以**串起任意多个条件**：

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 75:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

`elif` 是 **else if** 的缩写，意思是："否则，如果……"

读一遍这段代码，它几乎就是人话：

> 如果 90 以上，优秀；**否则如果** 75 以上，良好；**否则如果** 60 以上，及格；**否则**，不及格。

## 二、语法结构

```
if 条件1:
    条件1 成立时做
elif 条件2:
    条件1 不成立、且条件2 成立时做
elif 条件3:
    前面都不成立、且条件3 成立时做
else:
    前面都不成立时做
```

规则：

1. `if` 必须有，且只能有一个，在最前面
2. `elif` 可以有**任意多个**（也可以没有）
3. `else` 最多一个，在最后，**可以省略**
4. 它们全部**左对齐**（同一缩进层级）
5. 每一个后面都要有**冒号**

### else 可以省略

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 75:
    print("良好")
```

如果 score 是 50，两个条件都不成立 → **什么都不打印**。

这不一定是 bug。有时候你确实只想在某些情况做事，其他情况保持沉默。

但**更多时候，忘了写 else 会让你漏掉边界情况**。经验法则：

> 能用 else 兜底的时候就用上。它代表"我考虑过剩下的情况了"。

## 三、最重要的性质：从上往下，命中即停

这是本课的核心，也是 90% 的 elif bug 的根源。

**Python 会从第一个条件开始，一个一个往下试。一旦某个条件成立，就执行它下面那段，然后整个 if 结构结束 —— 后面的条件一个都不再看了。**

```python
score = 95

if score >= 60:
    print("及格")
elif score >= 90:
    print("优秀")
```

你猜打印什么？

```
及格
```

**95 分明明是"优秀"，却打印了"及格"。**

因为 Python 从上往下检查：

1. 第一个条件 `score >= 60` —— 95 >= 60，**成立**
2. 立刻执行 `print("及格")`
3. **结束。** 后面的 `elif score >= 90` 根本没机会被检查

代码没有报错，逻辑看起来也对，就是结果不对。**这是最难查的一类 bug。**

### 正确的写法：从严格到宽松

把**范围最小的条件放前面**：

```python
score = 95

if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

现在 95 分：先检查 >= 90，成立 → 打印"优秀" → 结束。正确。

**口诀：写 elif 时，把条件按「从最严格到最宽松」排列。**

或者换个说法：**从数值高的往下排。**

## 四、一个对照实验

把下面两段代码各跑一遍，体会顺序的威力。

**顺序错（宽的在前）：**

```python
score = 95
if score >= 60:
    print("及格")
elif score >= 90:
    print("优秀")
```

输出：`及格` ← 错

**顺序对（严的在前）：**

```python
score = 95
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
```

输出：`优秀` ← 对

两个数都是 95，两段代码用的条件也一样，**只换了顺序，结果就变了。**


## 五、elif 和多个独立 if 的区别

这两种写法看起来很像，行为完全不同。

**写法 A：elif（多选一）**

```python
score = 95
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
```

输出：`优秀`（只有一行）

**写法 B：多个独立 if（可以都成立）**

```python
score = 95
if score >= 90:
    print("优秀")
if score >= 60:
    print("及格")
```

输出：

```
优秀
及格
```

**两个都打印了**，因为它们是两次独立的判断，互不影响。

什么时候该用哪个？

| 场景 | 用 | 例子 |
|---|---|---|
| 几种情况互斥，只该命中一个 | `elif` | 成绩等级、年龄段 |
| 几种情况可以同时成立 | 多个 `if` | 既满 18 又是会员、既下雨又堵车 |

## 六、完整例子：年龄段判断

```python
age = 25

if age < 12:
    print("儿童")
elif age < 18:
    print("青少年")
elif age < 60:
    print("成年")
else:
    print("长者")
```

注意这里条件的写法：`elif age < 18` 你**不需要**写成 `age >= 12 and age < 18`。

因为能走到这一行，就说明前面的 `age < 12` 已经不成立 —— 也就是说 `age >= 12` 必然为真。

**这就是 elif 的隐藏福利：每个分支都自动排除了前面所有分支的情况。**

前提是顺序对。如果把 `age < 60` 放最前面，25 岁就会命中它，后面全废。
