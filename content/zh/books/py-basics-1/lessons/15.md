# 实战：个人信息卡片

> 第 3 章最后一课。不学新语法，把前面四课的东西**串成一个真正能用的程序**。
>
> 这是你学编程以来第一个「拿得出手给别人看」的东西 —— 一个会提问、会算数、会排版、还不会因为用户乱输入而崩溃的小程序。

## 要做成什么样

运行效果（用户输入用 `←` 标出）：

```
===== 个人信息卡片生成器 =====

请输入你的名字：小红 ←
请输入你的年龄：18 ←
请输入你的身高（米）：1.65 ←
请输入你所在的城市： 北京 ←
你最喜欢的一句话： 加油 ←

==============================
          个人信息卡片
==============================
  姓名      小红
  年龄      18 岁（出生年约 2007）
  身高      1.65 米
  城市      北京
  座右铭    「加油」
==============================
```

看着挺像回事。但其实每一行用到的东西你都学过：

| 卡片上的内容 | 用到的知识 | 出自 |
|---|---|---|
| 姓名、城市、座右铭 | `input()` 提问 | 第 11 课 |
| 出生年（2025 - 18） | `int()` 转换后算数 | 第 12 课 |
| 整齐的排版 | `f-string` + 对齐 | 第 13 课 |
| 空格、大小写不怕 | `strip()` 清洗 | 第 14 课 |

## 先写第一版：能跑就行

别想着一步到位。先把骨架搭起来：

```python
print("===== 个人信息卡片生成器 =====")
print()

name = input("请输入你的名字：")
age = input("请输入你的年龄：")
height = input("请输入你的身高（米）：")
city = input("请输入你所在的城市：")
motto = input("你最喜欢的一句话：")

print()
print("==============================")
print("          个人信息卡片")
print("==============================")
print(f"  姓名      {name}")
print(f"  年龄      {age}")
print(f"  身高      {height}")
print(f"  城市      {city}")
print(f"  座右铭    {motto}")
print("==============================")
```

跑一下，卡片出来了。**但有三个问题：**

### 问题一：没有出生年

年龄我们拿到了，但没算出生年。加上：

```python
birth_year = 2025 - int(age)
```

然后输出改成：`f"  年龄      {age} 岁（出生年约 {birth_year}）"`

注意 `int(age)` —— `age` 来自 `input`，是字符串，**必须转成整数才能做减法**。忘了转就是第 12 课那个 `TypeError`。

### 问题二：有多余空格就难看

用户输入 ` 北京 `，卡片上会显示 `  城市       北京 `（后面拖个空格），排版错乱。

修：每个 `input` 后面加 `.strip()`。

```python
name = input("请输入你的名字：").strip()
```

### 问题三：身高是小字符串

身高 `1.65` 是小数。现在没用它算数，所以没问题。但如果要算 BMI，就得 `float(height)`。

## 第二版：加上清洗和出生年

```python
print("===== 个人信息卡片生成器 =====")
print()

name = input("请输入你的名字：").strip()
age = input("请输入你的年龄：").strip()
height = input("请输入你的身高（米）：").strip()
city = input("请输入你所在的城市：").strip()
motto = input("你最喜欢的一句话：").strip()

birth_year = 2025 - int(age)

print()
print("==============================")
print("          个人信息卡片")
print("==============================")
print(f"  姓名      {name}")
print(f"  年龄      {age} 岁（出生年约 {birth_year}）")
print(f"  身高      {height} 米")
print(f"  城市      {city}")
print(f"  座右铭    「{motto}」")
print("==============================")
```

跑起来，基本达到目标效果了。

## 还能更好：用对齐让排版真正整齐

现在姓名那栏靠的是手写空格凑。如果名字很长（比如「欧阳 FileOutputStream」），排版就乱了。

用 f-string 的对齐语法（第 13 课学过）：

```python
print(f"  {'姓名':<6}{name}")
print(f"  {'年龄':<6}{age} 岁（出生年约 {birth_year}）")
print(f"  {'身高':<6}{height} 米")
print(f"  {'城市':<6}{city}")
print(f"  {'座右铭':<6}「{motto}」")
```

`{'姓名':<6}` 的意思是：**「姓名」这两个字左对齐，占 6 个字符宽度**。

中文有个坑：**一个中文字符在等宽字体里占 2 个英文字符宽度**，所以 `<6` 对中文标签来说其实不够精确。但在网页/终端的大多数场景够用了，不必纠结。

## 一个更狠的改进：允许空输入

用户嫌麻烦，城市和座右铭直接回车跳过了。现在程序会打印空行：

```
  城市      
  座右铭    「」
```

不好看。给它个默认值：

```python
if not city:
    city = "未填写"
if not motto:
    motto = "（这个人很懒，什么都没留下）"
```

（第 14 课的判空写法）

## 最终版

```python
print("===== 个人信息卡片生成器 =====")
print()

name = input("请输入你的名字：").strip()
age = input("请输入你的年龄：").strip()
height = input("请输入你的身高（米）：").strip()
city = input("请输入你所在的城市：").strip()
motto = input("你最喜欢的一句话：").strip()

# 空值兜底
if not city:
    city = "未填写"
if not motto:
    motto = "（这个人很懒，什么都没留下）"

# 算出生年
birth_year = 2025 - int(age)

# 出卡片
print()
print("==============================")
print("          个人信息卡片")
print("==============================")
print(f"  {'姓名':<6}{name}")
print(f"  {'年龄':<6}{age} 岁（出生年约 {birth_year}）")
print(f"  {'身高':<6}{height} 米")
print(f"  {'城市':<6}{city}")
print(f"  {'座右铭':<6}「{motto}」")
print("==============================")
```

**这就是一个完整的、能给别人用的小程序了。**

## 审视这个程序：它还差什么

诚实地列一下，**别以为它完美**：

| 缺陷 | 后果 | 什么时候解决 |
|---|---|---|
| 年龄输入「十八」会崩溃 | `int()` 报 ValueError | 基础 3 的 `try...except` |
| 没有重复输入的机会 | 输错了只能重跑 | 基础 2 的循环 |
| 出生年写死 2025 | 明年就错了 | 基础 3 的日期模块 |
| 信息用完就丢 | 关掉程序就没了 | 基础 3 的文件读写 |

**这些不是缺陷，是进度。** 每个都有明确的解决时间和地方 —— 你现在知道它们存在，比糊里糊涂以为程序完美要强得多。

## 你刚刚跨过的那条线

回顾一下这五课：

- **第 11 课之前**，你的程序是自说自话的脚本
- **现在**，你的程序会提问、会算数、会排版、能扛住乱输入

差别不在语法，在于**你开始考虑「别人会用这个程序」了**。

这是从「写代码」到「做东西」的转变。后面所有课程，本质都是在加固这条线：让程序更能扛、更能干、更好看。
