# 实战：成绩评级器

> 第 4 章最后一课。不学新语法，把前四课的东西**串成一个真正能用的程序**。
>
> 这是你第一次写出「有判断力」的程序 —— 它会根据输入给出不同的结果，而不是永远一个答案。

## 一、要做成什么样

运行效果（`←` 后面是你输入的内容）：

```
请输入成绩：85 ←
==============================
  成绩：85 分
  等级：良好
==============================
```

输入 95：等级是「优秀」
输入 45：等级是「不及格，还差 15 分及格」
输入 150：提示「成绩不合法」

## 二、先别急着写完整版

新手最容易犯的错，就是一上来就想写出最终版本，然后被一堆bug淹没。

我们分四步走，每一步都能跑。

## 三、第一步：只做等级判断

先不碰输入，把分数写死在代码里，专注把判断逻辑写对：

```python
score = 85

if score >= 90:
    level = "优秀"
elif score >= 75:
    level = "良好"
elif score >= 60:
    level = "及格"
else:
    level = "不及格"

print("等级：" + level)
```

这里用了一个新东西 —— 用变量 `level` **存住判断的结果**，最后统一打印。

这比在每个分支里各写一次 print 要好，因为：

1. 要改输出格式时只改一处
2. 判断逻辑和输出逻辑分开了，更清楚

**记住这个套路：if 负责决定"是什么"，print 负责"怎么显示"。**

先跑通这一步，再往下走。

## 四、第二步：加上真正的输入

现在让分数来自用户（第 3 章的 `input`）：

```python
score_text = input("请输入成绩：")
score = int(score_text)

if score >= 90:
    level = "优秀"
elif score >= 75:
    level = "良好"
elif score >= 60:
    level = "及格"
else:
    level = "不及格"

print("等级：" + level)
```

两行关键代码：

- `input()` 拿到的是**字符串**，所以放进 `score_text`
- `int()` 把它转成**整数**，才能跟 90、75 做比较

忘了 `int()` 会怎样？第 3 章讲过 —— 字符串和整数比大小会直接 `TypeError`。

## 五、第三步：处理非法输入

用户是不可信的。第 3 章第 14 课说过：**用户不会按你的想法输入。**

现在的问题是：如果有人输入 150 或者 -20，程序会给出「优秀」或「不及格」—— 这在业务上是错的，150 分根本不存在。

加一道前置检查：

```python
score_text = input("请输入成绩：")
score = int(score_text)

if score > 100 or score < 0:
    level = "成绩不合法（应在 0 - 100 之间）"
elif score >= 90:
    level = "优秀"
elif score >= 75:
    level = "良好"
elif score >= 60:
    level = "及格"
else:
    level = "不及格"

print("等级：" + level)
```

注意这个 `if` 放在**最前面**。为什么？

因为 elif 是「命中即停」的。如果把合法范围检查放在后面，150 分会先命中 `score >= 90` 变成"优秀"，永远轮不到合法性检查。

**这正好印证了第 18 课那句话：范围最小、最特殊的条件放最前面。**

这里 `score > 100 or score < 0` 是最特殊的（异常情况），所以排第一。

也可以用链式写法让意图更明显：

```python
if not (0 <= score <= 100):
    level = "成绩不合法"
```

## 六、第四步：让不及格的提示更有用

光说"不及格"没什么用。告诉用户**还差多少分**，这才是真正有用的程序：

```python
score_text = input("请输入成绩：")
score = int(score_text)

if score > 100 or score < 0:
    level = "成绩不合法（应在 0 - 100 之间）"
elif score >= 90:
    level = "优秀"
elif score >= 75:
    level = "良好"
elif score >= 60:
    level = "及格"
else:
    level = f"不及格，还差 {60 - score} 分及格"

print("等级：" + level)
```

最后那个分支用了第 3 章学的 **f-string**，把计算直接嵌进字符串。

45 分 → `还差 15 分及格`。

## 七、最终版本

加上第 3 章学的排版，做成完整样子：

```python
score_text = input("请输入成绩：")
score = int(score_text)

if score > 100 or score < 0:
    level = "成绩不合法（应在 0 - 100 之间）"
elif score >= 90:
    level = "优秀"
elif score >= 75:
    level = "良好"
elif score >= 60:
    level = "及格"
else:
    level = f"不及格，还差 {60 - score} 分及格"

print("==============================")
print(f"  成绩：{score} 分")
print(f"  等级：{level}")
print("==============================")
```

试试这几个输入，看看输出：

| 输入 | 等级 |
|---|---|
| 100 | 优秀 |
| 90 | 优秀 |
| 89 | 良好 |
| 75 | 良好 |
| 60 | 及格 |
| 59 | 不及格，还差 1 分及格 |
| 150 | 成绩不合法 |

**边界值特别值得试**：90、75、60 这三个点，正好是每个档位的分界线。

这种"刚好在边界上"的输入，是 bug 最爱藏的地方。以后你自己写程序，也要专门试边界值。

```quiz

```

## 八、本章回顾

这一章你给程序装上了"判断力"：

| 课 | 你学会的 | 解决什么 |
|---|---|---|
| 16 | `if` | 条件成立才做 |
| 17 | `else` | 不成立时也有个交代 |
| 18 | `elif` | 多种情况选一个 |
| 19 | `and` / `or` / `not` | 把条件组合起来 |
| 20 | 综合 | 串成一个能用的程序 |

三个最容易翻车的地方，值得再记一遍：

1. **冒号和缩进** —— if / elif / else 后面都要冒号，下面都要缩进
2. **elif 的顺序** —— 从严格到宽松，命中即停
3. **and / or 两边要写完整条件** —— `age > 18 and < 60` 是错的

## 九、下一章预告

现在这个程序有个明显的不足：**运行一次就结束了。**

你想再评一个分数，得重新点运行。

真正的工具应该能**一直运行，让你反复操作，直到你说退出**。

这就是下一章的循环 —— `while` 和 `for`。

有了循环，你的程序才第一次变成"工具"而不是"脚本"。

- 因为 elif 命中即停，放后面的话 150 分会先命中 score >= 90 变成「优秀」
