# 让输出变好看

上一课你学会了转换类型，能算出正确结果了。但打印那段代码大概长这样：

```python
print("你好，" + name + "！你今年" + str(age) + "岁，身高" + str(height) + "米。")
```

一堆加号、一堆引号、还得记得 `str()`。写起来痛苦，看起来更痛苦。

这一课教你 **f-string** —— 现代 Python 里最推荐的格式化写法。学会它，上面那行会变成：

```python
print(f"你好，{name}！你今年{age}岁，身高{height}米。")
```

## 先感受一下差距

**老写法（字符串拼接）：**

```python
name = "小红"
age = 18
print("我叫" + name + "，今年" + str(age) + "岁。")
```

输出：`我叫小红，今年18岁。`

**f-string 写法：**

```python
name = "小红"
age = 18
print(f"我叫{name}，今年{age}岁。")
```

输出一模一样，但代码干净了一个档次。

区别在哪？老写法里，你是在**把零件粘起来**（用 `+` 拼接）；f-string 里，你是在**写一句话，中间挖几个洞**（用 `{}` 填变量）。

**写一句话，当然比粘零件自然。**

## 怎么用：三步

### 第一步：在引号前加 `f`

```python
print(f"这是一句 f-string")
```

`f` 是 format（格式化）的意思。它告诉 Python：**这个字符串里的大括号要特殊处理。**

忘了加 `f`？大括号会被当成普通字符原样打印：

```python
name = "小红"
print("你好，{name}")    # 忘了 f
```

输出：`你好，{name}` ← 这是个非常常见的低级错误，看到大括号原样输出就检查 `f`。

### 第二步：用 `{}` 把变量包起来

```python
print(f"你好，{name}")
```

Python 会**把 `{name}` 换成 `name` 变量的值**。

### 第三步：类型不用管了

这是最大的好处 —— **`{}` 里放什么类型都能直接显示，不用 `str()`。**

```python
name = "小红"
age = 18
height = 1.65
is_student = True

print(f"姓名：{name}，年龄：{age}，身高：{height}，学生：{is_student}")
```

输出：`姓名：小红，年龄：18，身高：1.65，学生：True`

四个变量四种类型（字符串、整数、小数、布尔），**一个 `str()` 都不用写**。

对比拼接写法：

```python
print("姓名：" + name + "，年龄：" + str(age) + "，身高：" + str(height) + "，学生：" + str(is_student))
```

看到 `str()` 重复的那一刻，你就该想起 f-string。

## `{}` 里能放的不只是变量

这是 f-string 真正强大的地方 —— **大括号里可以是一整个表达式。**

### 直接算

```python
price = 25
count = 3
print(f"总价：{price * count} 元")
```

输出：`总价：75 元`

不用先算好存变量，可以直接在 `{}` 里写 `price * count`。

### 调用函数

```python
name = "小红"
print(f"名字长度：{len(name)}")
print(f"大写：{name.upper()}")
```

### 调用方法

```python
text = "  Hello  "
print(f"去掉空格后：{text.strip()}")
```

（第 14 课会详细讲 `strip()`）

### 放数字运算 + 格式化

想控制小数位数？用 `:.2f`（保留两位小数）：

```python
pi = 3.1415926
print(f"圆周率约等于 {pi:.2f}")
```

输出：`圆周率约等于 3.14`

`:.2f` 读作「冒号点二 f」——**冒号后面跟格式说明**。常用的：

| 写法 | 含义 | 例子（`x = 3.14159`） | 输出 |
|---|---|---|---|
| `{x:.2f}` | 保留 2 位小数 | `f"{x:.2f}"` | `3.14` |
| `{x:.0f}` | 不要小数（四舍五入） | `f"{x:.0f}"` | `3` |
| `{x:>10}` | 右对齐，占 10 个字符宽 | `f"{x:>10.2f}"` | `      3.14` |

对齐那个在打印表格时特别有用：

```python
print(f"{'苹果':<6}{'3.5':>8}")
print(f"{'香蕉':<6}{'2.0':>8}")
```

输出：

```
苹果      3.5
香蕉      2.0
```

`<6` 是左对齐占 6 格，`>8` 是右对齐占 8 格。数字右对齐是通行做法（个位对齐好比较）。

## 多行输出：三引号 + f

想一次打印多行，用三个引号：

```python
name = "小红"
age = 18
info = f"""
===== 个人信息 =====
姓名：{name}
年龄：{age}
===================
"""
print(info)
```

前面的 `f` 同样有效，大括号照常被替换。

## 什么时候不用 f-string

**没有变量要插入的时候。**

```python
print("欢迎使用本程序")     # 对，直接写
print(f"欢迎使用本程序")    # 多余，加了 f 也没变量
```

加了 `f` 但里面没有 `{}`，不会报错，只是没必要。**看到没有大括号却带 `f` 的字符串，就知道作者可能是复制粘贴的。**

## 对比三种写法

同一个需求：输出「我叫小红，今年 18 岁」。

| 写法 | 代码 | 评价 |
|---|---|---|
| 逗号分隔 | `print("我叫", name, "，今年", age, "岁。")` | 能用，但会在每部分之间**自动插空格**，标点前会有多余空格 |
| 加号拼接 | `print("我叫" + name + "，今年" + str(age) + "岁。")` | 精确，但引号和 `str()` 太多 |
| **f-string** | `print(f"我叫{name}，今年{age}岁。")` | **推荐**。可读、不用管类型 |

逗号那个要特别说一下，`print("我叫", name)` 输出是 `我叫 小红`（自动空格），中文里很别扭。**中文排版优先 f-string。**

## 这一课你只需要记住三句话

1. **引号前加 `f`，字符串里用 `{变量}`** —— 就这两步
2. `{}` 里**不用 `str()`**，什么类型都能显示；还能直接写表达式
3. 忘了 `f` 会导致大括号**原样输出**，这是最常见的错误

## 小测验 · 把拼接改成 f-string

下面这段代码能跑，但很难看。改成 f-string 版本。

```python
name = "小明"
score = 95
print("学生" + name + "的成绩是" + str(score) + "分。")
```

```quiz
type: code
q: 下面这行能跑但很难看，请改成 f-string 版本，输出必须完全一致：「学生小明的成绩是95分。」
starter: |
  name = "小明"
  score = 95
  print("学生" + name + "的成绩是" + str(score) + "分。")
tests:
- assert "学生小明的成绩是95分。" in __out
hint: 写成 print(f"学生{name}的成绩是{score}分。") —— 引号前加 f，中文照抄，变量位置换 {name} 和 {score}，加号和 str() 全删掉。
explain: f-string 把「拼接零件」变成「填空造句」。score 是整数也不用 str() 了 —— 这是它最省事的地方。
```

> 卡住了？点「提示」。记住口诀：**引号前加 f，变量放大括号，加号和 str() 全删掉**。
