# while：让程序重复做事

> 前面四章写的所有程序，都有一个共同的局限：**它们跑一遍就结束了。**
>
> 你想让程序再算一次，只能自己再点一次"运行"。
>
> 但真实世界里，程序要做的很多事情本质上是**重复的**：一直问密码直到输对、把一百个文件挨个处理、每秒检查一次有没有新消息。
>
> 这一课给程序装上第二种"控制力" —— **重复**。

## 一、while 解决的是什么问题

先想一个你熟悉的场景：手机解锁。

你输错密码，手机不会说"错了，再见"然后锁死。**它会让你再试一次**，再错再试，直到你输对为止。

用"人话"描述这个流程：

> **只要**密码还不对，**就**继续让用户输。

注意这句话的结构，和上一章的 `if` 非常像 —— 都有一个条件。区别只有一个：

| | 含义 |
|---|---|
| `if` | 条件成立 → 做**一次**，然后往下走 |
| `while` | 条件成立 → 做一次，**回来再检查**，成立就再做一次 |

**`if` 是"如果"，`while` 是"只要……就一直"。**

这就是它解决的全部问题：**让同一段代码，在条件还成立的时候反复运行。**

## 二、while 长什么样

```python
count = 1

while count <= 3:
    print("第", count, "次问好")
    count = count + 1

print("结束")
```

运行它，你会看到：

```
第 1 次问好
第 2 次问好
第 3 次问好
结束
```

同样一段 `print`，写了**一次**，却执行了**三遍**。这就是循环的威力。

## 三、while 是怎么跑的（这一步必须想清楚）

很多新手学循环学不会，不是因为语法难，而是**没在脑子里把它跑一遍**。我们把上面那段拆开，一步一步看：

| 第几轮 | `count` 的值 | `count <= 3` 成立吗 | 做了什么 |
|---|---|---|---|
| 开始前 | 1 | — | — |
| 第 1 轮 | 1 | ✅ 成立 | 打印"第 1 次"，count 变成 2 |
| 第 2 轮 | 2 | ✅ 成立 | 打印"第 2 次"，count 变成 3 |
| 第 3 轮 | 3 | ✅ 成立 | 打印"第 3 次"，count 变成 4 |
| 第 4 轮 | 4 | ❌ 不成立 | **跳出循环**，什么都不做 |

然后程序继续往下走，执行最后的 `print("结束")`。

**关键结论：条件是在"每一轮开始前"检查的。**

所以 `count` 变成 4 的那一刻，循环体并没有被执行第四次 —— 它在门口就被拦下了。

## 四、三个必须记住的细节

### 1. 和 if 一样：冒号 + 缩进

```python
while count <= 3:        # ← 冒号不能少
    print(...)           # ← 缩进的才是"循环体"
    count = count + 1    # ← 这一行也在循环体内
print("结束")            # ← 没缩进，循环结束后才执行一次
```

判断"哪几行在循环里"，**只看缩进**。这跟 `if` 是完全相同的规则。

### 2. 循环体里必须有"让条件走向不成立"的东西

看这一行：

```python
count = count + 1
```

它看起来平平无奇，但**它是整个循环的刹车**。

把它删掉试试：

```python
count = 1

while count <= 3:
    print("第", count, "次问好")
```

`count` 永远是 1，`count <= 3` 永远成立，于是程序会**一直打印下去，永不停止**。

这就是传说中的**死循环**。

> 如果你在网页上点运行遇到了死循环，页面会卡住。
> 刷新页面就能停下。在学习阶段，写一个死循环不是"犯错"，是**每个人都会经历的一次**。

**判断标准：循环体里，有没有让条件最终变成 False 的东西？** 没有的话，它一定停不下来。

### 3. `count = count + 1` 不是数学等式

这一行最容易让新手怀疑人生，因为在数学里它显然不成立。

但 Python 里的 `=` 是**赋值**，意思是"把右边算出来的结果，放进左边的变量里"，不是"两边相等"。

它的执行分两步：

1. 先算右边：`count + 1`，也就是 `1 + 1 = 2`
2. 再把 2 放回 `count`

所以这一行的真实含义是：**让 count 增加 1。**

如果你觉得别扭，Python 也提供了简写：

```python
count += 1      # 完全等价于 count = count + 1
```

两种写法都对。本书主要用 `count = count + 1`，因为它**更直白地展示了"先算右边再放回去"**这件事。

## 五、两个最常用的套路

循环千变万化，但新手阶段你只需要先掌握两个固定套路。

### 套路一：数着做（做固定次数）

```python
count = 1

while count <= 5:
    print("正在处理第", count, "个文件")
    count = count + 1
```

三件套：**起始值、条件、自增**。缺一个就转不起来。

### 套路二：算总和（累加）

```python
total = 0
count = 1

while count <= 100:
    total = total + count
    count = count + 1

print("1 到 100 的总和是:", total)
```

运行结果：

```
1 到 100 的总和是: 5050
```

这里出现了两个变量，各司其职：

- `total` —— **累加器**，每轮往里加一点，最后就是答案
- `count` —— **计数器**，只负责记录"现在是第几轮"

用 `=` 的"先算右边"原则看 `total = total + count`：先算出 `0 + 1`，放进 total；下一轮算出 `1 + 2`，再放进去…… **每轮它都在自己的旧值上加一点，这就是"累加"。**

## 六、循环和 if 可以套在一起

判断和重复不是二选一，它们几乎总是一起出现。

```python
total = 0
count = 1

while count <= 10:
    if count % 2 == 0:
        total = total + count
    count = count + 1

print("1 到 10 里所有偶数的和:", total)
```

运行结果：

```
1 到 10 里所有偶数的和: 30
```

注意 `count = count + 1` 的位置：**它没有缩进在 `if` 里面**。

如果把它缩进进去，会发生什么？只有 `count` 是偶数时它才会 +1，于是第一轮 `count` 是 1（奇数），不加 1，永远是 1 —— **死循环**。

> **这是新手最常踩的坑之一**：自增写进了 if 里面。
> 检查方法：看 `count = count + 1` 和 `while` 是不是**同一层缩进**。

## 七、什么时候用 while，什么时候用 if

给你一个最简单的判断方法，问自己一句话：

> **这件事需要做几次？**

- 如果答案是"**看情况，可能一次都不做，也可能做很多次**" → `while`
- 如果答案是"**就一次，看情况决定做不做**" → `if`

下一课我们会讲 `while True`，那是"做无数次，直到我喊停"的写法；再下一课的 `for` 则是"**我很清楚要做几次**"的写法。

## 随堂练习

边读边练：先用 while 把一件重复的事做出来，再往下读。

```quiz
type: code
q: 用 while 打印 1 到 5 这五个数字，每个一行
starter: |
  count = 1
  while count <= 5:
      print(count)
      # 在这里补一行

tests:
- assert "1" in __out and "5" in __out
- assert "6" not in __out
hint: 和第 21 课讲的「计数器」一样 —— print 之外还要让 count 变大，否则条件永远成立。
explain: while 的三个零件：初始条件（count = 1）、判断条件（count <= 5）、让条件走向结束的那一行（count = count + 1）。少了任何一件都不叫循环。
```

## 本节测验

```quiz
type: choice
exam: true
q: 下面这段代码会打印几次「你好」？
code: |
  count = 1
  while count < 3:
      print("你好")
      count = count + 1
options:
- 1 次
- 2 次
- 3 次
- 无数次
answer: 1
explain: count 依次是 1、2 时条件成立（打印两次），变成 3 时 3 < 3 不成立，循环结束。注意条件是 <（小于）不是 <=（小于等于），这是本题唯一的陷阱。
```

starter: |
  result = 1
  count = 1

      result = result * count
