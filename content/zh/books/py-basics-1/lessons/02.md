# 让电脑听懂你的话

> 写代码之前得先有个「能跑代码的地方」。这一课把这个地方讲透，并手把手装好编辑器。
>
> 篇幅偏长，但这一课值得慢读 —— 环境没搭对，后面每一课都会卡。

## 先搞懂一件事：Python 是"解释型"的

编程语言大致分两类，理解它们的差别，你就知道为什么"环境"这么重要。

**编译型（比如 C 语言）**：你把整本书写完，找个翻译官一次性翻译成英文，然后把英文版给外国人看。翻译慢，但看的时候快。

**解释型（比如 Python）**：你说一句，翻译官翻一句，外国人听一句。

Python 属于后者。它有一个程序叫**解释器（interpreter）**，负责读你的代码、一句一句执行。

这带来两个直接后果：

1. **好处**：写一行就能立刻跑一行，试错成本极低。特别适合学习。
2. **代价**：必须先装好正确的解释器，否则代码就是一堆普通文字。

所以"搭建环境"的本质就一句话：

> **弄到一个 Python 解释器，并且让你的代码能被它读到。**

## 两条路，先走第一条

### 路线 A：浏览器里跑（现在就用这个）

**你现在看到的这个网站，本身就能运行 Python。**

这不是把代码上传到某台服务器去跑 —— 而是用了一种叫 **Pyodide** 的技术：把真正的 CPython（Python 官方解释器）编译成了网页能跑的格式，直接在你自己的浏览器里运行。

它的好处：

- **零安装**：打开网页就能写代码，手机上也行
- **零风险**：怎么折腾都不会弄坏你的电脑
- **够真实**：这是真正的 Python 3，不是简化版，`import math` 之类的库都能用

它的边界：

- 不能用需要联网的库（比如爬虫的 `requests`）
- 不能读写你电脑上的真实文件（浏览器不允许，这是好事）
- 第一次运行时要下载一个约 10MB 的运行环境（之后会缓存）

**我的建议**：整个"详细基础 1"，你都可以只用浏览器。等你学到「读写文件」「装第三方库」的章节（基础 3 及之后），再走路线 B。

**但这不代表你现在可以什么都不装。** 编辑器是另一回事 —— 就算只在浏览器里学，你也迟早要在本机写真正的代码。下面把 VSCode 装好，一次到位。

### 路线 B：装一个真正的 Python 到你电脑上

等你开始做真正的工具，就需要本机的 Python 了。

**Windows：**

1. 打开 [python.org/downloads](https://www.python.org/downloads/)
2. 点那个黄色大按钮下载 Python 3.12 或更高版本
3. **⚠️ 运行安装程序时，务必勾选最下面那个 `Add python.exe to PATH`**
   —— 这一步忘了，后面你会遇到"命令找不到"的世纪难题
4. 点 `Install Now`，等它装完

**macOS：**

1. 同样去 python.org 下载安装包，双击安装
2. 或者如果你装了 Homebrew，在终端里执行 `brew install python3`

**Linux：**

大概率已经自带了。在终端输入 `python3 --version` 看看；没有的话用 `sudo apt install python3`（Ubuntu/Debian）。

### 怎么知道装没装成功

打开终端，输入：

```
python --version
```

或者：

```
python3 --version
```

看到 `Python 3.12.x` 这样的输出就成功了。看到「不是内部或外部命令」，说明 PATH 那步没勾对 —— 卸掉重装一遍，这次记得勾。

## 装 VSCode：一步一步来

写代码需要一个顺手的编辑器。我们就用 **VS Code（Visual Studio Code）** —— 免费、跨平台、几乎是现在的行业默认。

### 第 1 步：下载

打开官网：**https://code.visualstudio.com/download**

页面会自动识别你的系统，中间那个大按钮就是对应版本。想手动选的话，往下翻：

| 你的系统 | 选哪个 |
|---|---|
| Windows | `Windows` → 一般选 **User Installer 64-bit** |
| macOS | 看芯片：M 系列选 **macOS (Apple Silicon)**，Intel 芯片选 **macOS (Intel)** |
| Linux | `.deb`（Ubuntu/Debian 系）或 `.rpm`（Fedora/openSUSE 系） |

> **User Installer 和 System Installer 有什么区别？**
> User Installer 装在你自己的用户目录下，不需要管理员权限，将来卸载升级都干净 —— **选这个就行**。System Installer 要管理员权限，装在 `C:\Program Files`，适合一台电脑多人用的场景。

### 第 2 步：安装（这里最容易漏勾）

**Windows：**

双击安装包，一路 Next，但**在「选择附加任务」这一页停下来**，把这几项都勾上：

- ✅ **添加到 PATH（重启后生效）** —— 不勾的话，将来在终端里输入 `code` 打不开 VSCode
- ✅ 添加"通过 Code 打开"操作到 Windows 资源管理器文件上下文菜单 —— 右键文件直接能编辑，很方便
- ✅ 添加"通过 Code 打开"操作到 Windows 资源管理器目录上下文菜单
- ✅ 将 Code 注册为受支持的文件类型的编辑器

然后点安装，装完会自己打开。

**macOS：**

下载下来是个 `.zip`。双击解压，得到一个 `Visual Studio Code.app`。**把它拖进 `应用程序（Applications）` 文件夹** —— 这步不能省，否则从 Launchpad 里找不到它。

**Linux：**

Ubuntu/Debian 双击 `.deb` 用软件中心装，或者命令行：

```
sudo apt install ./code_xxx.deb
```

### 第 3 步：切成中文界面（可选）

刚打开是英文的。想换中文：

1. 按 `Ctrl + Shift + X`（Mac 是 `Cmd + Shift + X`）打开**扩展面板**
2. 搜索框输入 `Chinese`
3. 找到 **Chinese (Simplified) Language Pack for Visual Studio Code**（作者是 Microsoft），点 `Install`
4. 装完右下角弹提示，点 `Yes` / `Restart` 重启，界面就变中文了

> 装插件要联网，第一次可能慢，耐心等一下。

### 第 4 步：装 Python 插件

这是让 VSCode 真正"懂 Python"的关键一步。

1. 同样在扩展面板（那个方块图标）
2. 搜索 `Python`
3. 认准 **作者是 Microsoft** 的那个（扩展名 `ms-python.python`，安装量几千万），点 `Install`

装完你会得到：语法高亮、代码补全、鼠标悬停看函数说明、按 `F5` 调试、自动发现你电脑上的 Python 解释器。

> 搜索结果里还会有 `Python Extension Pack`、`Pylance` 等等。装微软那个 `Python` 时会**自动带上 Pylance**（负责补全和报错提示），不用手动装第二个。

### 第 5 步：写第一个文件

1. 点左上角 `文件 → 新建文件`（或者 `Ctrl + N`）
2. 在弹出来的选项里选 `Python`
3. 输入这一行：

```python
print("你好，VSCode")
```

4. `Ctrl + S` 保存。**文件名必须以 `.py` 结尾**，比如 `hello.py`
   存哪都行，建议专门建个文件夹，比如 `D:\pycode` 或 `~/pycode`

**为什么后缀必须是 `.py`？** 因为 VSCode 靠后缀判断"这是什么语言"。存成 `hello.txt`，它就不给你高亮，也不会当 Python 运行。

### 第 6 步：让它跑起来

三种方法，从省事到正规：

**方法一：右上角三角形（最省事）**

装了 Python 插件后，编辑器右上角会出现一个 ▶ 三角按钮。点它，代码就跑了，结果在下方的**终端**面板里显示。

**方法二：在文件里右键**

在代码区右键 → `在终端中运行 Python 文件`。

**方法三：自己在终端敲命令（推荐学会这个）**

按 `` Ctrl + ` ``（就是数字 1 左边那个反引号）叫出 VSCode 自带的终端，然后输入：

```
python hello.py
```

回车。看到输出「你好，VSCode」就成了。

> **如果提示找不到命令**，试试把 `python` 换成 `python3`：
> ```
> python3 hello.py
> ```
> Windows 上如果用 `python3` 报错，换回 `python`。这两个名字的差别只是不同系统的习惯，指的是同一个东西。

### 第 7 步：确认 VSCode 找对了解释器

如果你发现代码能跑，但没高亮、没补全、报一些奇怪的错，多半是 VSCode 没找到 Python 装在哪。

按 `Ctrl + Shift + P` 打开命令面板，输入 `Python: Select Interpreter`，会列出它找到的所有 Python。选一个带版本号、路径里含 `Python3xx` 的那个。

选完，窗口左下角会显示当前用的解释器版本 —— 看到 `Python 3.12.x` 就对了。

## VSCode 的几个救命快捷键

不要求一次记住，用到时回来查：

| 快捷键 | 作用 |
|---|---|
| `` Ctrl + ` `` | 开关终端面板 |
| `Ctrl + S` | 保存（写一行按一下，养成肌肉记忆） |
| `Ctrl + /` | 把选中行注释掉 / 取消注释 |
| `Ctrl + Shift + X` | 打开扩展面板 |
| `Ctrl + Shift + P` | 命令面板（忘了功能在哪，来这里搜） |
| `Alt + ↑ / ↓` | 把当前行上下移动 |
| `Shift + Alt + ↓` | 把当前行复制一份到下面 |
| `Ctrl + D` | 选中下一个相同的词（批量改变量名极好用） |

## 新手最常遇到的 4 个问题

**1. 终端里输出中文是乱码**

Windows 老版本容易遇到。在终端里先执行：

```
chcp 65001
```

再把字体改成支持中文的（比如 `Consolas` 或 `微软雅黑`）。更彻底的办法：VSCode 设置里搜 `files.autoGuessEncoding`，勾上。

**2. 代码能保存，但点运行没反应**

看看右下角有没有弹窗提示"需要选择解释器"。按第 7 步手动选一个。

**3. 提示 `python 不是内部或外部命令`**

Python 装的时候没勾 `Add to PATH`。卸载重装，这次记得勾。

**4. 装了插件但没生效**

插件要重启 VSCode 才完全生效。另外确认文件后缀是 `.py`。

## 三种运行方式，记住它们的区别

等你用本机 Python 时，会遇到三种跑法：

| 方式 | 怎么用 | 适合什么 |
|---|---|---|
| 交互式 | 终端输入 `python` 后回车，进 `>>>` 提示符 | 试一行代码的即时效果 |
| 脚本文件 | 写进 `hello.py`，终端 `python hello.py` | 正式的程序 |
| 网页运行 | 就是本站 | 学习、演示、临时验证 |

`>>>` 这个符号是 Python 的"我准备好了，请说话"的意思，以后在资料里看到它，就知道那是让你在交互式环境里输入的。

## 小测验 · 确认你的环境是活的

不管你走的是哪条路线，先验证一下解释器在正常工作。

下面这段代码会打印出当前运行环境的 Python 版本号，直接运行它。

```quiz
type: code
q: 运行下面这段代码，看看你正在用的 Python 是哪个版本
starter: |
  import sys
  print(sys.version)
tests:
- assert "3." in __out
hint: 代码已经写好了，你只需要点「运行并检查」。如果想看更多信息，可以再加一行 print(sys.version_info)。
explain: import sys 是"把系统相关的工具箱拿过来"，sys.version 里面存着版本信息。看到以 3. 开头的输出，说明你跑的是 Python 3 —— 这个教程里的所有代码都基于 Python 3。
```

看到输出里有个 `3.` 了吗？那就对了。

> 顺带一提：Python 2 已经在 2020 年停止维护了。现在看到的所有 Python 代码，默认都是 Python 3。
