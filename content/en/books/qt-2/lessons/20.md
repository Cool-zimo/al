# Hands-On: A Custom Gauge Control

> Now we tie together everything from the last four sections — paintEvent, shapes, coordinate transforms, gradients, and paths. In this section we build a reusable circular gauge: tick marks, tick labels, a colored arc, a needle, a value readout — all painted inside one QWidget.

## Feature Plan

Here's the control we're building:

```
           270° (start)
         ╭─────────╮
        ╱           ╲
       ╱    0   240   ╲
      │        °C       │
       ╲             ╱
        ╲___________╱
      bottom-left   bottom-right
     210°         330°
```

| Part | Technique |
|---|---|
| Outer colored arc | drawArc + QPen gradient/multi-segment |
| Tick marks | Rotated loop of short lines |
| Tick numbers | drawText after rotation |
| Needle | translate to center + rotate + drawPolygon |
| Center cap | drawEllipse with radial gradient |
| Value text | drawText, centered |

## Complete Code

```
import sys
from PySide6.QtWidgets import QApplication, QWidget, QVBoxLayout, QSlider
from PySide6.QtCore import Qt, QRect, QPointF
from PySide6.QtGui import (QPainter, QPen, QBrush, QColor, QFont,
                          QRadialGradient, QConicalGradient, QPainterPath)

class Gauge(QWidget):
    def __init__(self, parent=None):
        super().__init__(parent)
        self.setMinimumSize(240, 240)
        self._value = 0          # Current value 0~100
        self._min = 0
        self._max = 100

    def set_value(self, v):
        self._value = max(self._min, min(self._max, v))
        self.update()

    def paintEvent(self, event):
        p = QPainter(self)
        p.setRenderHint(QPainter.RenderHint.Antialiasing)

        side = min(self.width(), self.height())
        rect = QRect(0, 0, side, side)
        rect.adjust(20, 20, -20, -20)        # Margin
        cx, cy = rect.center().x(), rect.center().y()
        r = rect.width() // 2

        # 1. Gray background arc (full range)
        p.setPen(QPen(QColor(230, 230, 230), 16,
                      Qt.PenStyle.SolidLine, Qt.PenCapStyle.RoundCap))
        p.drawArc(rect.adjusted(8, 8, -8, -8),
                  225 * 16, -270 * 16)       # Angles are in 1/16 degree units

        # 2. Colored progress arc (proportional to current value)
        ratio = (self._value - self._min) / (self._max - self._min)
        span = int(270 * ratio)
        grad = QConicalGradient(cx, cy, 225 - 0)   # Start at the right side
        grad.setColorAt(0.0, QColor(0, 200, 100))
        grad.setColorAt(0.5, QColor(255, 200, 0))
        grad.setColorAt(1.0, QColor(255, 60, 60))
        p.setPen(QPen(QBrush(grad), 16,
                      Qt.PenStyle.SolidLine, Qt.PenCapStyle.RoundCap))
        p.drawArc(rect.adjusted(8, 8, -8, -8),
                  225 * 16, -span * 16)

        # 3. Tick marks (rotated loop)
        p.save()
        p.translate(cx, cy)
        p.rotate(225)                          # Starting angle
        ticks = 11
        for i in range(ticks):
            angle = i * (270 / (ticks - 1))
            p.save()
            p.rotate(angle)
            p.setPen(QPen(QColor(120, 120, 120), 2))
            p.drawLine(r - 6, 0, r + 8, 0)
            p.restore()
        p.restore()

        # 4. Needle
        p.save()
        p.translate(cx, cy)
        p.rotate(225 + 270 * ratio)
        p.setBrush(QBrush(QColor(60, 60, 60)))
        p.setPen(Qt.PenStyle.NoPen)
        p.drawPolygon([QPointF(-6, 0), QPointF(0, -(r - 22)),
                       QPointF(6, 0), QPointF(0, 14)])
        p.restore()

        # 5. Center cap (radial gradient)
        rad = QRadialGradient(cx, cy, 22, cx - 6, cy - 6)
        rad.setColorAt(0.0, QColor(255, 255, 255))
        rad.setColorAt(1.0, QColor(200, 200, 200))
        p.setBrush(QBrush(rad))
        p.setPen(QPen(QColor(160, 160, 160), 1))
        p.drawEllipse(QRect(cx - 12, cy - 12, 24, 24))

        # 6. Value text
        p.setPen(QPen(QColor(40, 40, 40)))
        f = QFont("Sans", 26, QFont.Weight.Bold)
        p.setFont(f)
        p.drawText(rect.adjusted(0, r // 2, 0, 0),
                   Qt.AlignmentFlag.AlignCenter, str(self._value))


class Demo(QWidget):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("Gauge")
        self.resize(320, 400)

        self.gauge = Gauge()
        slider = QSlider(Qt.Orientation.Horizontal)
        slider.setRange(0, 100)
        slider.setValue(68)
        slider.valueChanged.connect(self.gauge.set_value)
        self.gauge.set_value(68)

        layout = QVBoxLayout(self)
        layout.addWidget(self.gauge)
        layout.addWidget(slider)


if __name__ == "__main__":
    app = QApplication(sys.argv)
    w = Demo()
    w.show()
    app.exec()
```

## Key Design Decisions

**1. Why multiply the angle by 16?**

Qt's `drawArc` / `drawPie` use **1/16 of a degree** as their unit (a historical holdover), so 270° must be written as `270 * 16`. This is the most common newbie pitfall.

**2. Why do both the progress arc and the tick marks use rotate?**

The needle rotates around a center; the ticks are evenly spaced — both of these coordinate systems are naturally polar. By translating the origin to the center and then rotating, the code is far cleaner than computing trigonometric coordinates by hand, and `save/restore` isolates the transforms automatically.

**3. Why save/restore again inside the tick loop?**

Because each call to `p.rotate(angle)` is **additive**. If you don't restore, the next rotation stacks on top of the previous one and the ticks end up skewed.

## Crash Site 1: Writing 270 Instead of 270*16 for drawArc

**Symptoms: The arc is nearly invisible — just a tiny sliver.**

**WRONG — Do not do this:**

```
p.drawArc(rect, 225, 270)        # Unit is 1/16 degree; 270 equals only 16.875°
```

**The fix:**

```
p.drawArc(rect, 225 * 16, 270 * 16)
```

## Crash Site 2: Rotations Accumulate Inside the Tick Loop

**Symptoms: All 11 ticks are crammed into a small angular range, getting denser and denser toward the end.**

**WRONG — Do not do this:**

```
p.save()
p.translate(cx, cy)
p.rotate(225)
for i in range(11):
    angle = i * 27
    p.rotate(angle)              # Each iteration adds to the previous one
    p.drawLine(...)
p.restore()
```

**The fix: Either recompute from the 225 baseline each time, or restore between iterations:**

```
p.save()
p.translate(cx, cy)
for i in range(11):
    p.save()
    p.rotate(225 + i * 27)
    p.drawLine(...)
    p.restore()                 # Back to the unrotated state for the next iteration
p.restore()
```

## Crash Site 3: The Needle Drifts Off-Screen

**Symptoms: The needle keeps moving farther away and eventually leaves the window.**

**WRONG — Do not do this:**

```
p.translate(cx, cy)
p.rotate(self._angle)
p.drawPolygon([QPointF(0, 0), QPointF(0, -80), QPointF(6, 0), QPointF(0, 10)])
# Forgot p.restore()
```

**Why it fails:** The un-restored translate/rotate compounds on the next `paintEvent`, so the needle drifts exponentially.

**The fix: Use `try/finally` to guarantee the restore.**

## Crash Site 4: QConicalGradient Looks Backwards

**Symptoms: You wanted green-to-red, but it came out red-to-green.**

**Why:** `QConicalGradient`'s angle parameter combined with Qt's clockwise-positive direction determines the color layout.

**The fix:** Render it once; if it's reversed, add or subtract 360° from the start angle, or swap the order of the `colorAt` stops.

## Summary

- A gauge = arc + ticks + needle + center cap + value
- `drawArc` angles are in 1/16 degree units — always multiply by 16
- Translating to the center + rotating is the standard recipe for needles and ticks
- Rotations inside a loop must be restored, or angles accumulate
- `save/restore` in pairs; `try/finally` guarantees restoration
- A progress arc uses `QConicalGradient` for a smooth multi-color transition
- The center cap uses `QRadialGradient` for depth
