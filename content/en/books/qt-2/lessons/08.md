# Delegates: Why Cells Need to Show Buttons, Progress Bars, and Dropdowns

> Must a cell contain only text? No. Delegates are the third piece of the Model/View puzzle: they decide how a cell is drawn and how it is edited. The default `QStyledItemDelegate` draws text and pops up a plain input box; if you want a progress bar, a dropdown, or a button, you must write your own delegate.

## What Problem Does a Delegate Solve?

**So far we have said the model owns data and the view owns display. But "display" can be split further: the view owns layout (who sits where), while the delegate owns rendering (what it looks like) and editing (how a value is entered).**

| Role | Owns |
|---|---|
| Model | Data and role values |
| View | Layout, selection, scrolling |
| Delegate | Rendering and editing of a single cell |

**The default delegate is `QStyledItemDelegate`.** If you write no delegate at all, the view uses it: text is drawn in the system font, and double-clicking opens a `QLineEdit`.

**When must you write your own delegate?**

```
Example requirements:
├── The score column should render as a progress bar, not a number
├── The status column should render as a colored dropdown
├── The action column should contain a "Delete" button
├── The date column should pop up a calendar picker on click
└── The rating column should pop up a 1-to-5 star selector on double-click
```

**These all share one trait: a cell that must not look like text.** You should not stuff a button into the model (the model knows nothing about widgets), and you should not hack the view. The correct move is to write a delegate and attach it to the view.

## Attaching a Delegate to a View

**The view offers three levels of granularity: one delegate for the whole view, one for a specific column, or one for a specific row.**

```python
from PySide6.QtWidgets import QStyledItemDelegate

class ProgressDelegate(QStyledItemDelegate):
    pass    # Empty for now; we will fill it in the next lesson

# One delegate for the entire view
view.setItemDelegate(ProgressDelegate())

# Only for column 1
view.setItemDelegateForColumn(1, ProgressDelegate())

# Only for row 0
view.setItemDelegateForRow(0, ProgressDelegate())
```

**Granularity matters: install a progress-bar delegate on column 1, and the rest of the columns keep the default.** This is exactly how you make "the score column renders as a bar while the name column stays as text".

## The Four Core Methods of a Delegate

| Method | When it is called | What it does |
|---|---|---|
| `paint(painter, option, index)` | Drawing the cell | Use `QPainter` to draw the look you want |
| `createEditor(parent, option, index)` | Double-click starts editing | Return an editor widget |
| `setEditorData(editor, index)` | The editor pops up | Pour the model data into the editor |
| `setModelData(editor, model, index)` | Editing finishes | Write the editor's value back into the model |

**These four methods are the whole delegate. The first two govern "seeing"; the last two govern "changing".**

## paint: Rolling Your Own Drawing

**`paint` receives a `QPainter`, an `option` (containing the rectangle, state, and more), and an `index`.**

```python
from PySide6.QtCore import Qt
from PySide6.QtGui import QPainter, QColor
from PySide6.QtWidgets import QStyledItemDelegate, QApplication

class ProgressDelegate(QStyledItemDelegate):
    def paint(self, painter, option, index):
        # Let the base class draw the background (selection, hover, etc.)
        super().paint(painter, option, index)

        value = index.data(Qt.UserRole)          # Logical value: an int 0..100
        if value is None:
            return

        rect = option.rect
        bar_width = int(rect.width() * value / 100)

        painter.save()
        # Draw the track
        painter.setPen(Qt.NoPen)
        painter.setBrush(QColor("#eeeeee"))
        painter.drawRect(rect)

        # Draw the progress fill
        painter.setBrush(QColor("#4caf50"))
        painter.drawRect(rect.x(), rect.y(), bar_width, rect.height())

        # Draw the text
        painter.setPen(QColor("#333333"))
        painter.drawText(rect, Qt.AlignCenter, f"{value}%")
        painter.restore()
```

**The discipline of `paint`: call `super().paint()` first to draw the background, so selection, hover, and disabled states all render correctly; then wrap your custom drawing in `save()` / `restore()` so your pen state never bleeds into other cells.**

## Crash Site 1: You Drew the Bar but Lost the Selection State

**Symptom: the cell shows a progress bar, but when you select the row, every other column turns blue while the bar column stays grey.**

```python
def paint(self, painter, option, index):
    # ❌ super().paint() is never called, so the background is never drawn
    value = index.data(Qt.UserRole)
    painter.setBrush(QColor("#4caf50"))
    painter.drawRect(option.rect.adjusted(2, 2, -2, -2))
    painter.drawText(option.rect, Qt.AlignCenter, f"{value}%")
```

**Root cause: `QStyledItemDelegate.paint` is what draws the background — the selection highlight, the hover state, the focus frame.** Skip it entirely and those visual cues vanish.

**✅ Fix: call `super().paint()` first, then layer your content on top.**

```python
def paint(self, painter, option, index):
    super().paint(painter, option, index)    # ✅ Background and selection are intact
    painter.save()
    # ... your drawing ...
    painter.restore()
```

**Alternatively, if you want a fully custom background, read `option.state` yourself to detect the selection state.**

```python
from PySide6.QtWidgets import QStyle
if option.state & QStyle.State_Selected:
    painter.fillRect(option.rect, option.palette.highlight())
```

## Crash Site 2: No save/restore, Pen State Pollutes Neighbouring Cells

**Symptom: the bar column draws correctly, but the text column beside it turns green and its font changes too.**

```python
def paint(self, painter, option, index):
    painter.setPen(QColor("green"))      # ❌ Green pen
    painter.setFont(some_big_font)       # ❌ A different font
    # And never restored
    painter.drawText(...)
```

**Root cause: the `QPainter` is the same object reused by the view for every cell — they all share one pen.** Change its colour, font, or transform matrix and fail to restore them, and the next cell inherits the contaminated state.

**✅ Fix: pair `save()` with `restore()`.**

```python
def paint(self, painter, option, index):
    painter.save()                 # ✅ Save the current state
    painter.setPen(QColor("green"))
    painter.setFont(some_big_font)
    # ... drawing ...
    painter.restore()              # ✅ Restore
```

## sizeHint: Telling the View How Much Space You Need

**If your custom drawing is taller than plain text (say you draw two lines or a colour block), override `sizeHint`.**

```python
def sizeHint(self, option, index):
    size = super().sizeHint(option, index)
    size.setHeight(28)            # At least 28 px tall, leaving room for the bar
    return size
```

**Without it, the view lays out rows at the default height and your progress bar may get squashed.**

## Summary

- A delegate owns the rendering and editing of a single cell — the third piece of the Model/View puzzle
- The default is `QStyledItemDelegate`, which only draws text and pops up an input box
- Attach a delegate with `setItemDelegate` / `setItemDelegateForColumn` / `setItemDelegateForRow`
- The four core methods: `paint`, `createEditor`, `setEditorData`, `setModelData`
- In `paint`, call `super().paint()` first to preserve selection; wrap custom drawing in `save`/`restore`
- `sizeHint` decides how much space a cell needs

  from PySide6.QtCore import Qt
  from PySide6.QtGui import QPainter, QColor

      QApplication, QWidget, QTableView, QVBoxLayout, QStyledItemDelegate
  )

  from PySide6.QtCore import QAbstractTableModel, QModelIndex

  class ProgressDelegate(QStyledItemDelegate):
      def paint(self, painter, option, index):
          pass

  app = QApplication(sys.argv)
  win = QWidget()
  win.setWindowTitle("Progress Bar Delegate")

  class SimpleModel(QAbstractTableModel):
      def __init__(self):
          super().__init__()
          self._rows = [["Alice", 92], ["Bob", 45], ["Carol", 78], ["Dan", 15]]
      def rowCount(self, p=QModelIndex()):
          return len(self._rows)
      def columnCount(self, p=QModelIndex()):
          return 2
      def data(self, index, role=Qt.DisplayRole):
          if not index.isValid():
              return None
          value = self._rows[index.row()][index.column()]
          if role == Qt.DisplayRole:
              return str(value)
          if role == Qt.UserRole and index.column() == 1:
              return value
          return None

              return ["Name", "Score"][section]

  view.show()
