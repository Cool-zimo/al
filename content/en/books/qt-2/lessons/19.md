# Gradients and Paths: QLinearGradient / QRadialGradient and QPainterPath

> Solid fills are everywhere; gradients are what give a control its sense of depth. And `QPainterPath` lets you draw any arbitrary outline — rounded tags, arrows, progress arcs, irregular buttons — all of it.

## Linear Gradients with QLinearGradient

A gradient object is a "color recipe"; it only takes effect when attached to a `QBrush`.

```
from PySide6.QtGui import QLinearGradient, QRadialGradient, QPainterPath
from PySide6.QtCore import Qt, QPointF

p = QPainter(self)
p.setRenderHint(QPainter.RenderHint.Antialiasing)

# Linear gradient: from (0,0) to (0,200), i.e. vertical
grad = QLinearGradient(0, 0, 0, 200)
grad.setColorAt(0.0, Qt.GlobalColor.white)
grad.setColorAt(1.0, Qt.GlobalColor.blue)
p.setBrush(QBrush(grad))
p.setPen(Qt.PenStyle.NoPen)
p.drawRect(20, 20, 120, 200)
```

`setColorAt(stop, color)` takes a `stop` from 0.0 to 1.0, representing position along the gradient direction. You can set any number of stops to make a multi-color gradient:

```
grad.setColorAt(0.0, Qt.GlobalColor.red)
grad.setColorAt(0.5, Qt.GlobalColor.yellow)
grad.setColorAt(1.0, Qt.GlobalColor.green)
```

**A gradient's coordinate space is the current QPainter coordinate system** — so if you rotate or translate the canvas, the gradient direction rotates and translates with it.

## Radial Gradients with QRadialGradient

These radiate outward from a center, perfect for a "spherical" or "glow" look.

```
rad = QRadialGradient(100, 100, 80)   # Center (100,100), radius 80
rad.setColorAt(0.0, Qt.GlobalColor.white)
rad.setColorAt(1.0, Qt.GlobalColor.darkGray)
p.setBrush(QBrush(rad))
p.drawEllipse(QRect(20, 20, 160, 160))   # A ball with depth
```

The full form `QRadialGradient(cx, cy, radius, fx, fy)` lets you offset the focal point (the highlight) from the center, producing a "side-lit" effect.

## QPainterPath: Building a Path One Line at a Time

A path is essentially a reusable vector outline. You stitch it together with `moveTo` / `lineTo` / `arcTo` / `cubicTo` / `closeSubPath`, then stroke (outline) and fill it in one pass.

```
path = QPainterPath()
path.moveTo(50, 150)        # Pen down here
path.lineTo(100, 50)        # Straight line
path.lineTo(150, 150)       # Straight line
path.closeSubPath()         # Back to the start, closing the shape

p.setBrush(QBrush(Qt.GlobalColor.orange))
p.setPen(QPen(Qt.GlobalColor.darkRed, 2))
p.drawPath(path)            # One stroke + fill
```

## Common Path Recipes

| Goal | How |
|---|---|
| Rounded rectangle | `path.addRoundedRect(rect, rx, ry)` |
| Ellipse | `path.addEllipse(rect)` |
| Polygon | moveTo + repeated lineTo + closeSubPath |
| Arc | `path.arcTo(rect, startAngle, spanAngle)` |
| Text outline | `path.addText(point, font, "ABC")` |

## A Complete Example: Gradient Button + Rounded Tag

```
class FancyDemo(QWidget):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("Gradients and Paths")
        self.resize(400, 260)

    def paintEvent(self, event):
        p = QPainter(self)
        p.setRenderHint(QPainter.RenderHint.Antialiasing)

        # Linear-gradient button
        grad = QLinearGradient(0, 60, 0, 120)
        grad.setColorAt(0.0, Qt.GlobalColor.cyan)
        grad.setColorAt(1.0, Qt.GlobalColor.blue)
        p.setBrush(QBrush(grad))
        p.setPen(QPen(Qt.GlobalColor.darkBlue, 1))
        p.drawRoundedRect(QRect(30, 60, 200, 60), 12, 12)

        p.setPen(Qt.GlobalColor.white)
        p.setFont(QFont("Sans", 14, QFont.Weight.Bold))
        p.drawText(QRect(30, 60, 200, 60),
                   Qt.AlignmentFlag.AlignCenter, "Submit")

        # Radial-gradient sun
        rad = QRadialGradient(320, 90, 50, 310, 80)
        rad.setColorAt(0.0, Qt.GlobalColor.yellow)
        rad.setColorAt(1.0, Qt.GlobalColor.red)
        p.setBrush(QBrush(rad))
        p.setPen(Qt.PenStyle.NoPen)
        p.drawEllipse(QRect(270, 40, 100, 100))

        # An arrow made from a Path
        arrow = QPainterPath()
        arrow.moveTo(60, 180)
        arrow.lineTo(140, 180)
        arrow.lineTo(140, 170)
        arrow.lineTo(180, 195)
        arrow.lineTo(140, 220)
        arrow.lineTo(140, 210)
        arrow.lineTo(60, 210)
        arrow.closeSubPath()
        p.setBrush(QBrush(Qt.GlobalColor.darkGreen))
        p.setPen(Qt.PenStyle.NoPen)
        p.drawPath(arrow)
```

## Crash Site 1: Gradient Paints as a Solid Block, No Transition

**Symptoms: You set `setColorAt`, but the rectangle is one flat color with no transition at all.**

**WRONG — Do not do this:**

```
grad = QLinearGradient(0, 0, 0, 0)    # Start and end are identical — zero-length direction
grad.setColorAt(0.0, Qt.GlobalColor.white)
grad.setColorAt(1.0, Qt.GlobalColor.blue)
```

**Why it fails:** The start and end points coincide, so Qt can't determine a direction and falls back to a solid color (usually the first stop's color).

**The fix: Give the start and end a clear distance and direction:**

```
grad = QLinearGradient(0, 0, 0, 200)        # Vertical gradient
grad = QLinearGradient(0, 0, 200, 0)        # Horizontal gradient
grad = QLinearGradient(0, 0, 200, 200)      # Diagonal gradient
```

## Crash Site 2: Path Is Missing closeSubPath, Fill Has a Gap

**Symptoms: The polygon you built with moveTo/lineTo has one side that doesn't close — it looks like an open pocket.**

**WRONG — Do not do this:**

```
arrow = QPainterPath()
arrow.moveTo(60, 180)
arrow.lineTo(140, 180)
arrow.lineTo(140, 210)
arrow.lineTo(60, 210)
# Missing closeSubPath()
p.drawPath(arrow)
```

**Why it fails:** A path only records the vertices you give it; it won't close itself. The last edge won't be stroked, and the fill boundary is incomplete.

**The fix: Return to the start manually, or call `closeSubPath()`:**

```
arrow.lineTo(60, 180)          # Return to the start manually
# or
arrow.closeSubPath()           # Auto-connect back to moveTo's start point
```

## Crash Site 3: Transform Matrix Skews the Gradient Direction

**Symptoms: After translate/rotate, the gradient direction rotates with the canvas — what you intended as vertical became horizontal.**

**WRONG — Do not do this:**

```
p.rotate(90)
grad = QLinearGradient(0, 0, 0, 200)   # You expected vertical, but it's now horizontal
p.setBrush(QBrush(grad))
p.drawRect(0, 0, 200, 200)
```

**Why it fails:** Gradient stops are interpreted in the current `QPainter` coordinate system. After rotation, "vertical" has changed.

**The fix: Create and set up the gradient before the transform, or recompute the start/end in the transformed coordinate system.**

## Summary

- A gradient must be attached to a `QBrush`; `setColorAt` stops range from 0.0 to 1.0
- `QLinearGradient` start and end must not coincide, or it collapses to a solid color
- `QRadialGradient` makes spheres/glows; offset the focal point for side lighting
- `QPainterPath` accumulates an outline with moveTo/lineTo/closeSubPath
- A path must call `closeSubPath` or the fill will have a gap
- Gradient coordinates follow the current transform; direction changes after a transform
- `addRoundedRect` / `addEllipse` / `addText` are convenient path helpers
