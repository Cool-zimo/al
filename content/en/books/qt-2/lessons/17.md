# Basic Shapes: Lines, Rectangles, Circles, Polygons, Text, and Images

> Last section you drew a line. This section opens up the full "shape toolbox": straight lines, rectangles, rounded rectangles, ellipses, polygons, text, and images — plus the one switch that makes everything look polished: antialiasing.

## Shape Quick-Reference

| Method | What it draws | Typical arguments |
|---|---|---|
| drawLine | A line segment | QPoint, QPoint or x1,y1,x2,y2 |
| drawRect | A rectangle (with border) | QRect or x,y,w,h |
| drawRoundedRect | A rounded rectangle | rect, xRadius, yRadius |
| drawEllipse | An ellipse/circle | QRect (bounding box) or center + horizontal/vertical radii |
| drawPolygon | A polygon | QPolygonF or QPolygon |
| drawPie | A pie slice | rect, startAngle, spanAngle (1/16 degree units) |
| drawArc | An arc | Same as above — lines only, no fill |
| drawText | Text | rect + alignment flags + string |
| drawPixmap | A raster image | QPoint or rect + QPixmap |
| drawImage | A QImage | Same as above |

```
import sys
from PySide6.QtWidgets import QApplication, QWidget
from PySide6.QtCore import Qt, QRect, QPoint, QPointF, QLineF
from PySide6.QtGui import QPainter, QPen, QBrush, QPolygonF, QPixmap

class ShapesDemo(QWidget):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("Basic Shapes")
        self.resize(480, 320)

    def paintEvent(self, event):
        p = QPainter(self)
        p.setRenderHint(QPainter.RenderHint.Antialiasing)

        # 1. Line
        p.setPen(QPen(Qt.GlobalColor.darkGreen, 2, Qt.PenStyle.DashLine))
        p.drawLine(20, 30, 200, 30)

        # 2. Rectangle (border + fill)
        p.setPen(QPen(Qt.GlobalColor.black, 1))
        p.setBrush(QBrush(Qt.GlobalColor.cyan))
        p.drawRect(QRect(20, 50, 120, 60))

        # 3. Rounded rectangle
        p.setBrush(QBrush(Qt.GlobalColor.yellow))
        p.drawRoundedRect(QRect(160, 50, 120, 60), 12, 12)

        # 4. Circle (square bounding box + drawEllipse)
        p.setBrush(QBrush(Qt.GlobalColor.red))
        p.drawEllipse(QRect(20, 130, 80, 80))

        # 5. Polygon
        poly = QPolygonF([
            QPointF(130, 210), QPointF(170, 130),
            QPointF(210, 210), QPointF(170, 190),
        ])
        p.setBrush(QBrush(Qt.GlobalColor.magenta))
        p.drawPolygon(poly)

        # 6. Text
        p.setPen(QPen(Qt.GlobalColor.black))
        p.setFont(QFont("Sans", 14, QFont.Weight.Bold))
        p.drawText(QRect(240, 50, 200, 40),
                   Qt.AlignmentFlag.AlignLeft | Qt.AlignmentFlag.AlignVCenter,
                   "Hello, PySide6")

        # 7. Image
        px = QPixmap(60, 60)
        px.fill(Qt.GlobalColor.blue)
        p.drawPixmap(QPoint(300, 150), px)

if __name__ == "__main__":
    app = QApplication(sys.argv)
    w = ShapesDemo()
    w.show()
    app.exec()
```

## Antialiasing: One Line, a Big Visual Difference

```
p.setRenderHint(QPainter.RenderHint.Antialiasing)          # Smooth edges on shapes
p.setRenderHint(QPainter.RenderHint.TextAntialiasing)      # Smooth text (on by default)
p.setRenderHint(QPainter.RenderHint.SmoothPixmapTransform) # Smooth scaled images
```

Without antialiasing, diagonal lines and circles show jagged "staircase" edges. With it, Qt feathers the edges. The cost is a little extra computation — fine to enable everywhere for a typical desktop app.

## Coordinate System and Size

The `QPainter` origin `(0, 0)` sits at the **top-left corner** of the window; x grows to the right and y grows downward. All coordinates are relative to the current transformed coordinate system, in pixels.

`event.rect()` tells you the "dirty region" that needs repainting — in performance-sensitive code you can redraw only that rectangle. For learning purposes, redrawing the whole window is usually fine.

## Crash Site 1: Passing Four Numbers to drawEllipse and Getting an Ellipse

**Symptoms: You wanted a perfect circle, but what appeared is a flattened ellipse — the width and height don't match.**

**WRONG — Do not do this:**

```
p.drawEllipse(20, 130, 80, 100)   # Width 80, height 100 -> that's an ellipse
```

**Why it fails:** In `drawEllipse(x, y, w, h)`, the third and fourth arguments are width and height. If they differ, you get an ellipse.

**The fix:**

```
p.drawEllipse(QRect(20, 130, 80, 80))   # Square bounding box = perfect circle

# Or use the "center + radii" overload, which is more intuitive
p.drawEllipse(QPoint(60, 170), 40, 40)  # Center (60,170), radius 40
```

## Crash Site 2: Chinese Text Shows as Boxes or Garbled Characters

**Symptoms: The interface displays squares `□□□` or mojibake instead of Chinese characters.**

**WRONG — Do not do this:**

```
p.setFont(QFont("SomeMissingFont", 14))
p.drawText(rect, "你好")
```

**Why it fails:** The named font doesn't exist on the system, so Qt falls back to a font that doesn't support Chinese. (Much less common nowadays: the source string itself not being Unicode — Python source is UTF-8 by default.)

**The fix:** Use a font you know exists, or just use the default font and only change size and weight:

```
font = QFont()
font.setPointSize(14)
font.setBold(True)
p.setFont(font)
p.drawText(rect, "你好，PySide6")
```

## Crash Site 3: drawPixmap Shows Nothing, Path Is Correct

**Symptoms: `drawPixmap(0, 0, QPixmap("logo.png"))` draws nothing and raises no error.**

**WRONG — Do not do this:**

```
px = QPixmap("logo.png")     # File missing or path is wrong
p.drawPixmap(0, 0, px)       # Silent failure — nothing appears on the canvas
```

**Why it fails:** When `QPixmap` fails to load, it becomes a null object (`px.isNull()` is `True`) — but **it does not raise an exception**. Painting a null pixmap is a no-op.

**The fix:** Check after loading; use an absolute path or the resource system:

```
px = QPixmap("logo.png")
if px.isNull():
    print("Image failed to load — check the path")   # Verify first, then investigate
else:
    p.drawPixmap(0, 0, px)
```

## Summary

- `drawRect` / `drawRoundedRect` / `drawEllipse` / `drawPolygon` are the everyday workhorses
- For a perfect circle, use equal width and height, or the "center + radius" overload
- The antialiasing trio: Antialiasing, TextAntialiasing, SmoothPixmapTransform
- Origin is top-left; y grows downward
- `QPixmap` failures are silent — always check with `isNull()`
- For font issues, confirm the font exists; or use the default font and only change size
