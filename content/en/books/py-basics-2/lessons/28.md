# Lambda and Higher-Order Functions: Tiny One-Line Functions

> This lesson covers "anonymous functions" with `lambda`, plus three of the most useful **higher-order functions**: `map`, `filter` and `sorted(key=...)`.
>
> Master this and you have Python's most common, most "functional" toolbox.

## 1. `lambda`: a nameless little function

`lambda` writes a **one-line** function without bothering to name it with `def`:

```python
square = lambda x: x * x
print(square(5))        # 25
```

Read `lambda x: x * x` as "take x, return x*x". It is exactly equivalent to:

```python
def square(x):
    return x * x
```

The only differences: `lambda` **has no name** (it is anonymous) and **can only contain one expression**.

⚠️ **Crash: putting multiple lines or an assignment inside a lambda.**

```python
f = lambda x: (            # WRONG  SyntaxError: invalid syntax
    y = x + 1
    y * 2)
```

A lambda body must be **one expression** — no assignment, and no multi-branch `if` statement block (a conditional expression `a if c else b` is fine). When the logic grows, just use `def`.

⚠️ **Crash: forgetting that a lambda still needs parameters.**

```python
nums = [1, 2, 3]
list(map(lambda: x * 2, nums))      # WRONG  NameError: name 'x' is not defined
```

`lambda:` has no parameter, but the expression uses `x`. **The parameter list is not optional: `lambda x: x * 2`.**

## 2. `map`: apply a function to every element

`map(func, iterable)` applies `func` to each element in turn:

```python
nums = [1, 2, 3, 4]
squares = list(map(lambda x: x * x, nums))
print(squares)        # [1, 4, 9, 16]
```

This is equivalent to the list comprehension `[x*x for x in nums]`. `map` returns an iterator, so wrap it in `list()` to see the result.

⚠️ **Crash: forgetting `list()`, and getting back an iterator.**

```python
result = map(lambda x: x * 2, [1, 2, 3])
print(result)         # <map object at 0x...> -- not a list
```

Printing it raw only shows "a map object". To get a list, call `list(result)`.

## 3. `filter`: keep only what passes the test

`filter(func, iterable)` uses `func` as a test on each element and keeps only the ones that return truthy:

```python
nums = [1, 2, 3, 4, 5, 6]
evens = list(filter(lambda x: x % 2 == 0, nums))
print(evens)        # [2, 4, 6]
```

`lambda x: x % 2 == 0` is the test; elements that return `True` are kept.

⚠️ **Crash: the test function returns None (forgetting the return-value expression).**

```python
list(filter(lambda x: x > 0, [-1, 2, 3]))   # runs, but relies on truthiness
list(filter(lambda x: print(x > 0), [1, 2]))  # WRONG  logic broken
```

The lambda body must be **an expression that returns a boolean**. `print(...)` returns `None`, which is treated as falsy and filtered out. **A filter test must return a truthy value.**

## 4. The most practical one: `sorted` with a `key`

The `key` parameter of `sorted` takes **a function** that decides "what to sort by":

```python
words = ["banana", "apple", "pear", "kiwi"]
by_length = sorted(words, key=lambda w: len(w))
print(by_length)        # ['pear', 'kiwi', 'apple', 'banana']
```

`key=lambda w: len(w)` means: "do not compare the strings themselves; compare their lengths."

⚠️ **Crash: passing the *result* of calling `key` instead of the function.**

```python
sorted(words, key=len(words))      # WRONG  TypeError
```

`key` wants **a function** (`len`), not the result `len(words)`. Write `key=len` and it works.

## 5. Sorting by a field: a real scenario

Sorting a list of dictionaries is where `key` really shines:

```python
students = [
    {"name": "Alice", "score": 92},
    {"name": "Bob",   "score": 78},
    {"name": "Carol", "score": 100},
]

by_score = sorted(students, key=lambda s: s["score"])
print(by_score)
# [{'name': 'Bob', 'score': 78}, {'name': 'Alice', 'score': 92}, {'name': 'Carol', 'score': 100}]
```

`key=lambda s: s["score"]` pulls out each student's score as the sort key. **This is dramatically cleaner than writing your own sort algorithm.**

⚠️ **Crash: the `key` function returns inconsistent types across elements.**

```python
mixed = [{"name": "Alice", "score": 92}, {"name": "Bob"}]
sorted(mixed, key=lambda s: s["score"])      # WRONG  KeyError: 'score'
```

The second dictionary has no `score` key, so `s["score"]` raises `KeyError`. **Make sure every element has the key your key function needs**, or use `s.get("score", 0)` to supply a default.

## 6. Worked example: a shopping cart, sorted

```python
cart = [
    {"item": "apple",  "price": 5.5, "qty": 3},
    {"item": "milk",   "price": 8.0, "qty": 1},
    {"item": "bread",  "price": 3.5, "qty": 5},
]

# sort by total value (price * qty), highest first
by_total = sorted(
    cart,
    key=lambda g: g["price"] * g["qty"],
    reverse=True,
)
for g in by_total:
    print(g["item"], g["price"] * g["qty"])
# apple 16.5
# milk 8.0
# bread 17.5
```

The `key` function computes "the line total" as the sort key, and `reverse=True` asks for descending order.

⚠️ **Crash: using `sort` (in-place) but expecting a new list back.**

```python
cart = [{"price": 5}, {"price": 3}]
result = cart.sort(key=lambda x: x["price"])
print(result)        # None -- sort is in-place and returns None
```

`list.sort()` is **in-place and returns None**; `sorted(list)` **returns a new list and leaves the original alone**. Want a new list → `sorted`; want to reorder the existing one → `list.sort()`.

## 7. `lambda` vs `def`: how to choose

| Situation | Use |
|---|---|
| One line of logic, throwaway | `lambda` |
| Complex logic, multiple lines | `def` |
| You need to reuse it or name it | `def` |
| As an argument to `key`, `map`, `filter` | `lambda` (most common) |

```python
# lambda: one-shot, as an argument
sorted(students, key=lambda s: s["score"])

# def: when you reuse it
def by_score(s):
    return s["score"]

sorted(students, key=by_score)
sorted(teachers, key=by_score)
```

⚠️ **Crash: trying to use `=` assignment inside a lambda.**

```python
lambda x: x = x + 1        # WRONG  SyntaxError
```

A lambda body must be an expression. To "assign" just write `lambda x: x + 1`.

## Summary

- `lambda params: expression` is a nameless, single-expression function
- A lambda can only contain an expression, not an assignment or multi-line statement
- `map(func, sequence)` applies func to every element
- `filter(func, sequence)` keeps only elements where func returns truthy
- `sorted(sequence, key=func)` sorts by the return value of key — the most useful of the three
- `map`/`filter` return iterators; wrap them in `list()` to see results
- `key` wants the **function itself**, never a call result
