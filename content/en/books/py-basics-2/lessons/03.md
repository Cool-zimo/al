# Adding and Removing: Letting a List Grow and Shrink

> An index can only change a position that **already exists**. But real programs usually collect data as they run — every time the user submits something, there's one more.
>
> This lesson covers **adding and removing**: how to put things in, how to take them out, and a few traps you must memorize.

## 1. Meet the Four Methods

The built-in "actions" of a list are called **methods**. You write them with a dot after the list:

```python
bag = []
bag.append("book")      # add one at the end
```

| Method | What it does | What it changes |
|---|---|---|
| `append(x)` | adds one at the **end** | the original list |
| `insert(i, x)` | inserts one at **a given position** | the original list |
| `pop(i)` | removes that position **and hands it back to you** | the original list |
| `remove(x)` | removes **the first one whose value is x** | the original list |

All four **modify the original list** and don't return a new one (only `pop` returns the element it removed).

## 2. append: The One You'll Use Most

```python
bag = []
bag.append("book")
bag.append("pen")
bag.append("notebook")
print(bag)
```

```
['book', 'pen', 'notebook']
```

**append adds exactly one element**, at the end.

⚠️ **Trap: trying to add several at once.**

```python
bag = []
bag.append("book", "pen")     # ✗ TypeError: append() takes exactly one argument
```

`append` accepts one argument. To add several at once, use `extend` (lesson 4) or just write several `append` lines.

⚠️ **Another trap: grabbing its return value.**

```python
bag = ["book"]
result = bag.append("pen")
print(result)      # None
```

`append` **returns nothing** (it returns `None`); it just quietly changes `bag`. To see the result, print `bag` itself:

```python
bag = ["book"]
bag.append("pen")
print(bag)         # ['book', 'pen']
```

**The rule**: a method returns something only if there's something to hand back (`pop`, for instance). Methods that just "do an action" return `None`.

## 3. insert: Put It at a Specific Position

`append` only reaches the end. For the middle, use `insert`:

```python
queue = ["Alice", "Bob"]
queue.insert(0, "Charlie")     # insert at the very front
print(queue)
```

```
['Charlie', 'Alice', 'Bob']
```

`insert(position, value)` — note **position first, value second**. Don't get them backwards.

After inserting, "Charlie" is at index 0 and everyone else shifts one step back.

⚠️ Inserting past the end does *not* error — Python treats it as "add to the end":

```python
queue = ["Alice", "Bob"]
queue.insert(99, "Charlie")
print(queue)      # ['Alice', 'Bob', 'Charlie'] — no error, but not at 99 either
```

That's different from index assignment, which does crash. **insert is forgiving.** Just don't expect it to fill in a pile of empty slots.

## 4. pop: Remove It, and Hand It to You

```python
scores = [87, 92, 78]
last = scores.pop()        # no position = remove the last
print(last)                # 78
print(scores)              # [87, 92]
```

**pop is the only removing method that gives something back**: it returns the element it removed.

That's the big difference from `remove` — sometimes you don't just want to delete, you want to **use** the deleted value:

```python
tasks = ["homework", "reading", "exercise"]
doing = tasks.pop(0)       # take the first one out of the list
print("Doing now:", doing)
print("Still to do:", tasks)
```

```
Doing now: homework
Still to do: ['reading', 'exercise']
```

This "take out and remove" move has a name — **dequeue** — and it's everywhere in task queues.

⚠️ pop on an empty list errors:

```python
bag = []
bag.pop()      # ✗ IndexError: pop from empty list
```

## 5. remove: Delete by Value, Not by Position

The first three work by position. `remove` is different — you tell it **what content to delete**:

```python
names = ["Alice", "Bob", "Charlie"]
names.remove("Bob")
print(names)
```

```
['Alice', 'Charlie']
```

You don't need to know which position "Bob" was at.

⚠️ **The trap everyone hits: remove only deletes the first match.**

```python
nums = [1, 2, 3, 2, 2]
nums.remove(2)
print(nums)      # [1, 3, 2, 2] — only the first 2 went
```

There are two more 2s left and it doesn't care. **remove removes one per call.**

⚠️ **Another trap: removing something that isn't there errors.**

```python
names = ["Alice", "Bob"]
names.remove("Charlie")      # ✗ ValueError: list.remove(x): x not in list
```

So the safe pattern is to ask first (`in` is lesson 5's topic, but here's a sneak peek):

```python
names = ["Alice", "Bob"]
if "Charlie" in names:
    names.remove("Charlie")
else:
    print("No such person")
```

## 6. del: Remove by Position, No Return Value

There's also the `del` statement (not a method — no parentheses):

```python
scores = [87, 92, 78]
del scores[0]
print(scores)      # [92, 78]
```

`del scores[0]` and `scores.pop(0)` do the same thing; **the difference is that del doesn't hand back the removed value.**

| What you want | Use |
|---|---|
| Just delete it, don't need it | `del scores[i]` |
| Delete it and use the value | `scores.pop(i)` |
| You know the content, not the position | `scores.remove(x)` |

## 7. A Very Common Mistake: Removing While Iterating

This one gets mentioned early because so many people hit it. It'll make more sense after lesson 5 covers iteration.

First, an example that **looks correct**:

```python
nums = [1, 2, 3, 4, 5]
for n in nums:
    if n % 2 == 0:
        nums.remove(n)
print(nums)      # [1, 3, 5] — exactly what we wanted
```

Now the **same pattern** again:

```python
nums = [2, 4, 6, 8]
for n in nums:
    if n % 2 == 0:
        nums.remove(n)
print(nums)      # [4, 8] — two got missed!
```

Why did the first one get lucky and the second fall apart?

Because: **after an element is removed, everything behind it shifts one step forward, but the iteration pointer still moves one step forward too** — so each deletion skips an element.

| Round | Pointer | n it sees | List after removal |
|---|---|---|---|
| 1 | 0 | 2 | `[4, 6, 8]` |
| 2 | 1 | **6** (4 got skipped) | `[4, 8]` |
| 3 | 2 | nothing there, done | `[4, 8]` |

**The correct approach**: don't modify the list while iterating over it. Instead, **build a new list of what you want to keep**:

```python
nums = [2, 4, 6, 8, 9]
kept = []
for n in nums:
    if n % 2 != 0:
        kept.append(n)
print(kept)      # [9]
```

Iterate the original, append into a new one — that way every element gets checked and none are skipped.

**Remember this rule: don't modify the list you're iterating over.** If you need to remove things, collect what stays.

```quiz
type: code
q: Start with an empty list, append 5, 10 and 15, then use pop() to remove the last one. Finally print the list.
starter: |
  nums = []
  nums.append(5)
  nums.append(10)
  nums.append(15)

  # remove the last one

tests:
- assert "[5, 10]" in __out
hint: pop() with no argument removes the last element. It's an action on the list itself — you don't need to assign the result to anything.

```

```quiz

exam: true

options:
- `[1, 3]`
- `[1, 3, 2]`
- `[1, 2, 3]`
- It errors, because there are two 2s
answer: 1
explain: remove deletes by *value*, and only the **first** match per call. So it removed the 2 at index 1 and left the one at index 3 alone — the result is [1, 3, 2]. To delete every 2 you'd need a loop, or build a new list of everything that isn't 2.
```
