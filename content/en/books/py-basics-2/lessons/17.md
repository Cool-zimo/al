# Set Operations: Intersection, Union, Difference, Symmetric Difference

> The most delightful thing about sets is that they ship with the operations you learned in maths class — intersection, union and difference, all in one line.
>
> This lesson covers those operations and the method-style forms that go with them.

## 1. Intersection `&`: what both groups have in common

The intersection is **the elements that appear in both sets**.

```python
a = {"Alice", "Bob", "Carol"}
b = {"Bob", "Carol", "David"}
print(a & b)        # {'Bob', 'Carol'}
```

The symbol is `&` (the same symbol used for bitwise AND, but on sets it means intersection).

A real scenario: finding the students who signed up for both courses.

```python
math = {"Alice", "Bob", "Carol", "David"}
english = {"Bob", "Carol", "Eve"}
both = math & english
print("Taking both:", both)       # Taking both: {'Bob', 'Carol'}
```

⚠️ **Crash: trying to intersect two lists.**

```python
["Alice", "Bob"] & ["Bob", "Carol"]      # WRONG  TypeError: unsupported operand type(s)
```

`&` only works on sets. To intersect lists you must convert first — use a set, or a list comprehension.

## 2. Union `|`: everything, with duplicates merged once

The union is **all the elements from both sets, with overlaps counted only once**.

```python
a = {"Alice", "Bob"}
b = {"Bob", "Carol"}
print(a | b)        # {'Alice', 'Bob', 'Carol'}
```

The symbol is `|` (the vertical bar). Notice that "Bob" appears only once — the union dedupes automatically.

A real scenario: merging user lists from two sources.

```python
vip_2025 = {"Alice", "Bob"}
vip_2026 = {"Bob", "Carol", "David"}
all_vip = vip_2025 | vip_2026
print("All VIPs:", all_vip)      # All VIPs: {'Alice', 'Bob', 'Carol', 'David'}
```

⚠️ **Crash: using `+` to combine two sets.**

```python
{"Alice"} + {"Bob"}      # WRONG  TypeError: unsupported operand type(s) for +
```

Sets do not use `+`; they use `|`. `+` is for concatenating lists and tuples, and the two operations have different meanings: concatenation keeps duplicates, union does not.

## 3. Difference `-`: what you have that I do not

`a - b` means **the elements that are in a but not in b**.

```python
all_students = {"Alice", "Bob", "Carol", "David"}
paid = {"Alice", "Carol"}
unpaid = all_students - paid
print("Still owe fees:", unpaid)      # Still owe fees: {'Bob', 'David'}
```

A real scenario: **filtering a blocklist**.

```python
all_users = {"alice", "bob", "charlie", "david"}
banned = {"bob", "david"}
active = all_users - banned
print(active)                   # {'alice', 'charlie'}
```

⚠️ **Crash: getting the direction of the difference wrong.**

```python
a = {"Alice", "Bob"}
b = {"Bob", "Carol"}
print(a - b)        # {'Alice'}
print(b - a)        # {'Carol'}  -- different direction, different result!
```

Difference is **asymmetric**: `a - b` and `b - a` are two different things. Always think carefully about "who is being subtracted from whom".

## 4. Symmetric difference `^`: in one side but not in both

The symmetric difference is **the elements that are in a or b, but not in both** — the ones that appear exactly once.

```python
a = {"Alice", "Bob", "Carol"}
b = {"Bob", "Carol", "David"}
print(a ^ b)        # {'Alice', 'David'}
```

A real scenario: finding the students who took **exactly one** of the two courses (excluding both the "took both" and the "took neither" groups).

```python
math = {"Alice", "Bob", "Carol"}
english = {"Carol", "David", "Eve"}
only_one = math ^ english
print("Exactly one course:", only_one)       # Exactly one course: {'Alice', 'Bob', 'David', 'Eve'}
```

You can think of `^` as **the union minus the intersection**, or `(a - b) | (b - a)`.

## 5. The four operations at a glance

| Operation | Symbol | Meaning | Example with `a={1,2,3}`, `b={2,3,4}` |
|---|---|---|---|
| Intersection | `&` | in both | `a & b` → `{2, 3}` |
| Union | `|` | everything, deduped | `a | b` → `{1, 2, 3, 4}` |
| Difference | `-` | in the left, not the right | `a - b` → `{1}` |
| Symmetric difference | `^` | in exactly one of them | `a ^ b` → `{1, 4}` |

⚠️ **Crash: mixing up difference and symmetric difference.**

```python
a - b       # {1}     -- only in a
a ^ b       # {1, 4}  -- only in a or only in b
```

Difference is one-way, symmetric difference is two-way. Remember the word "symmetric" = both sides count.

## 6. The method-style forms

As well as the symbols, sets offer method versions of the operations (the arguments can be any iterable, not necessarily a set):

| Operation | Symbol form | Method form |
|---|---|---|
| Intersection | `a & b` | `a.intersection(b)` |
| Union | `a | b` | `a.union(b)` |
| Difference | `a - b` | `a.difference(b)` |
| Symmetric difference | `a ^ b` | `a.symmetric_difference(b)` |

```python
a = {1, 2, 3}
print(a.intersection([2, 3, 4]))      # {2, 3}  -- the argument can be a list
print(a.union("abc"))                 # {1, 2, 3, 'a', 'b', 'c'}
```

⚠️ **Crash: assuming the method mutates the original set.**

```python
a = {1, 2, 3}
a.intersection([2, 3, 4])
print(a)          # {1, 2, 3}  -- unchanged
```

Methods such as `intersection` **return a new set** and leave the original alone. For in-place changes use the `-update` suffix versions:

```python
a = {1, 2, 3}
a.intersection_update([2, 3, 4])
print(a)          # {2, 3}  -- the original set was modified
```

The in-place versions are `intersection_update`, `update` (for union), `difference_update` and `symmetric_difference_update`.

## Summary

- Intersection `&`: in both; union `|`: everything, deduped; difference `-`: in left not right; symmetric difference `^`: in exactly one
- Difference is **asymmetric**, so `a - b` ≠ `b - a`
- Method forms: `intersection`, `union`, `difference`, `symmetric_difference`
- Methods without `-update` return a new set and do not touch the original
- These operations make "compare two lists, blocklists, common friends" read beautifully

## In-class Exercise

```quiz
type: code
q: Given two sets `a = {"apple", "banana", "orange"}` and `b = {"banana", "orange", "grape"}`, print their intersection and their union.
starter: |
  a = {"apple", "banana", "orange"}
  b = {"banana", "orange", "grape"}

  # print the intersection
  # print the union
tests:
- assert "intersection" in __out
- assert "{'banana', 'orange'}" in __out or "{'orange', 'banana'}" in __out
- assert "{'apple', 'banana', 'orange', 'grape'}" in __out or ("'grape'" in __out and "'apple'" in __out)
hint: Intersection uses &, union uses |. Remember that a set's element order is not fixed when checking the printed output.
explain: The answer is print("intersection:", a & b) and print("union:", a | b). This tests the two most basic set-operation symbols and the fact that a set's printed order is not guaranteed.
```

## Section Quiz

```quiz
type: choice
exam: true
q: 'Given `a = {1, 2, 3}` and `b = {2, 3, 4}`, what are `a - b` and `b - a`?'
options:
- '{1} and {4}'
- '{1, 2, 3} and {2, 3, 4}'
- '{1, 4} and {1, 4}'
- '{4} and {1}'
answer: 0
explain: Difference means "in the left set, not in the right". a - b is {1} (1 is in a but not b); b - a is {4} (4 is in b but not a). Difference is not symmetric, so the direction matters.
```

type: function

starter: |
  def common_elements(a, b):
      return []
cases: |
  [1, 2, 2, 3], [2, 3, 4] -> [2, 3]
  ["x", "y"], ["y", "z"] -> ["y"]
hint: Convert both lists to sets, take the intersection &, then turn the result into a sorted list.
explain: The answer is return sorted(set(a) & set(b)). One line does three jobs — convert to sets for dedup, take the intersection, and sort. sorted returns a list, which matches the requirement to "return a sorted list".
