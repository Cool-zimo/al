# Hands-on: Counting and Grouping

> The previous four lessons covered the fundamentals. This lesson does the two things dictionaries are **best at**: counting (how many times does each item appear) and grouping (gathering items together under some field).
>
> These two patterns turn up almost daily in real projects.

## 1. Counting: how many times each item appears

Scenario: a pile of votes, words, or cities — and you want to know **how many times each one occurs**.

### The idea

Use a dictionary as a **counter**: the key is the item, the value is the count.

```python
cities = ["London", "Paris", "London", "Tokyo", "Paris", "London"]
count = {}

for city in cities:
    if city in count:
        count[city] += 1        # seen before, add one
    else:
        count[city] = 1         # first sighting, record 1

print(count)        # {'London': 3, 'Paris': 2, 'Tokyo': 1}
```

The logic is clear: seen before means add one; never seen means record one.

⚠️ **Crash: incrementing a key you have not seen yet.**

```python
count = {}
for city in cities:
    count[city] += 1        # WRONG  KeyError: 'London' (does not exist on the first encounter)
```

The first time you meet `"London"`, `count["London"]` does not exist, so adding one immediately raises `KeyError`. You must check whether it is present first.

### Using `get` to write it shorter

```python
count = {}
for city in cities:
    count[city] = count.get(city, 0) + 1
```

`count.get(city, 0)` means "give me the current count, or 0 if there is none"; add one and write it back. One line covers the test and the increment.

### `setdefault` does the same job

```python
count = {}
for city in cities:
    count.setdefault(city, 0)
    count[city] += 1
```

`setdefault(city, 0)` guarantees the key exists and starts at 0, so the increment after it is safe.

### A complete example

```python
votes = ["apple", "banana", "apple", "orange", "banana", "apple", "grape"]
count = {}
for v in votes:
    count[v] = count.get(v, 0) + 1

# find the winner
winner = max(count, key=count.get)
print("Most votes:", winner)          # Most votes: apple
print("Count:", count[winner])        # Count: 3
```

`max(count, key=count.get)` means: among the keys of `count`, pick the one whose value is largest.

⚠️ **Crash: using plain `max(count)` to find the maximum.**

```python
max(count)          # 'grape' — picks the largest key by alphabetical/insertion order, not the largest value
```

By default, `max` compares the keys themselves. For "pick by value" you must supply the `key` argument.

## 2. Grouping: gathering items under a field

Scenario: a list of student records, and you want to group them **by class, by city, or by grade band**.

### The idea

The key is the "grouping criterion"; the value is a **list of the elements in that group**.

```python
students = [
    ("Alice", "Class A"),
    ("Bob", "Class B"),
    ("Carol", "Class A"),
    ("Diana", "Class C"),
    ("Eve", "Class B"),
]

groups = {}
for name, cls in students:
    if cls not in groups:
        groups[cls] = []          # group does not exist yet, start an empty list
    groups[cls].append(name)

print(groups)
# {'Class A': ['Alice', 'Carol'], 'Class B': ['Bob', 'Eve'], 'Class C': ['Diana']}
```

The logic: if the group is absent, create an empty list, then append the name to it.

⚠️ **Crash: forgetting to create the list before calling append.**

```python
groups = {}
for name, cls in students:
    groups[cls].append(name)      # WRONG  KeyError: 'Class A'
```

The first time you meet `"Class A"`, `groups["Class A"]` does not exist, so calling `append` on it crashes. You must check first and create first.

### Using `setdefault` to write it shorter

```python
groups = {}
for name, cls in students:
    groups.setdefault(cls, []).append(name)
```

`setdefault(cls, [])` returns "the list for cls" (creating an empty list first if necessary), and then you call `.append(name)` directly on it.

⚠️ **Crash: worrying that the `[]` default to `setdefault` gets reused.**

In fact there is no need to worry — `setdefault` only creates that list **once**, when the key is absent; afterwards it returns the same already-existing list, so it never builds a fresh one repeatedly.

### A practical example: grouping by grade band

```python
scores = [("Alice", 92), ("Bob", 78), ("Carol", 55), ("Diana", 88), ("Eve", 45)]

def level(s):
    if s >= 90: return "excellent"
    if s >= 60: return "pass"
    return "fail"

groups = {}
for name, s in scores:
    groups.setdefault(level(s), []).append(name)

print(groups)
# {'excellent': ['Alice'], 'pass': ['Bob', 'Diana'], 'fail': ['Carol', 'Eve']}
```

The grouping criterion can be the **result of a function**, which makes grouping extremely flexible.

## 3. Summary of the two patterns

| Pattern | What the dictionary looks like | How to write it |
|---|---|---|
| Counting | `{item: count}` | `count[x] = count.get(x, 0) + 1` |
| Grouping | `{category: [item, ...]}` | `groups.setdefault(category, []).append(item)` |

These two patterns **cover most "organising data" needs**. Repeat them until they are muscle memory:

- Counting: `d[k] = d.get(k, 0) + 1`
- Grouping: `d.setdefault(k, []).append(v)`

⚠️ **Crash: mixing the two patterns up.**

```python
# meant to group, but wrote a count instead
groups = {}
for name, cls in students:
    groups[cls] = groups.get(cls, 0) + 1     # this gives the size of each class, not the roster
```

The result is "number of students per class", not a grouping. To group, the value must be a list and you use `append`; to count, the value is a number and you add one. Do not confuse the two.

## Summary

- Counting pattern: `count[x] = count.get(x, 0) + 1`
- Grouping pattern: `groups.setdefault(k, []).append(v)`
- Together they cover the vast majority of "organising data" tasks.
- To find the maximum count use `max(count, key=count.get)` — never just `max(count)`.
- The grouping criterion can be the result of a function, which is very flexible.
