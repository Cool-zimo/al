# Hands-on: Word Frequency Counting

> This is the last "textbook example" in this book — it combines the dictionaries from Chapter 3 with the sets from Chapter 4.
>
> The goal: count how many times each word appears in a piece of text, find **the most frequent word**, and build a **deduplicated vocabulary list**.

## 1. Breaking the task down

The input is a piece of text:

```python
text = "Python is the best language Python is easy to learn"
```

We want three things:

1. **A frequency table**: how many times each word appears → a `{word: count}` dictionary
2. **The most frequent word** → the key whose value is largest in that table
3. **A deduped vocabulary list** → all the distinct words (the keys of the table, or just a set)

Split the work into three steps; each one is a pattern you have already learned.

## 2. Step one: count the frequencies

Counting is the "counter" pattern: the key is the word, the value is the count.

```python
text = "Python is the best language Python is easy to learn"
words = text.split()        # split on whitespace
count = {}

for w in words:
    count[w] = count.get(w, 0) + 1

print(count)
# {'Python': 2, 'is': 2, 'the': 1, 'best': 1, 'language': 1, 'easy': 1, 'to': 1, 'learn': 1}
```

Two lines do all the work: `split()` turns the string into a list, and `count.get(w, 0) + 1` completes the count.

⚠️ **Crash: forgetting that punctuation is part of the "word".**

```python
text = "I love Python, Python is great"
print(text.split())
# ['I', 'love', 'Python,', 'Python', 'is', 'great']  -- "Python," and "Python" count as different
```

`split()` cuts on whitespace. Without punctuation handling, `"Python,"` and `"Python"` look like two different words. A real project needs a regex or a proper tokenizer. This lesson simplifies things: **assume the input words are already separated by spaces**.

## 3. Step two: find the most frequent word

Once you have the frequency table, finding the key with the largest value needs `max` plus a `key`:

```python
winner = max(count, key=count.get)
print("Most frequent word:", winner)          # Most frequent word: Python
print("Count:", count[winner])                # Count: 2
```

`max(count, key=count.get)` means: among the keys of `count`, pick the one whose value is largest.

⚠️ **Crash: calling plain `max(count)`.**

```python
max(count)         # 'language'  -- picks the largest key alphabetically, not by count
```

Without `key=count.get`, `max` compares the keys themselves (strings). You must supply the `key` argument to mean "by value".

### What if there is a tie?

If "Python" and "easy" both appeared twice, `max` returns **the one it encounters first** — the behaviour is deterministic, but not necessarily what you wanted. In a real project you would normally find "all the joint winners" like this:

```python
max_count = max(count.values())
winners = [w for w, c in count.items() if c == max_count]
print(winners)         # ['Python', 'is']  -- every word that hit 2
```

⚠️ **Crash: assuming `max` returns all the joint winners.**

```python
max(count, key=count.get)      # returns only one of them
```

`max` returns exactly one value. To get "every joint winner" you have to filter the table yourself.

## 4. Step three: the deduped vocabulary list

The vocabulary is the set of distinct words that appeared. There are two approaches.

### Approach one: the keys of the frequency table are already deduped

```python
vocab = list(count.keys())
print(vocab)         # ['Python', 'is', 'the', 'best', 'language', 'easy', 'to', 'learn']
```

Dictionary keys are naturally unique.

### Approach two: use a set directly

```python
words = text.split()
vocab_set = set(words)
print(vocab_set)     # {'Python', 'is', 'the', 'best', 'language', 'easy', 'to', 'learn'}
```

⚠️ **Crash: using a set to dedupe and silently losing the order.**

```python
list(set(words))     # the order is not guaranteed and may differ each time
```

A set is unordered. If you need "deduped while keeping the first-seen order", use the pattern from Lesson 16:

```python
seen = set()
vocab = []
for w in words:
    if w not in seen:
        seen.add(w)
        vocab.append(w)
print(vocab)         # ['Python', 'is', 'the', 'best', 'language', 'easy', 'to', 'learn']
```

## 5. The complete program

Putting the three steps together:

```python
text = "Python is the best language Python is easy to learn"
words = text.split()

# 1. count frequencies
count = {}
for w in words:
    count[w] = count.get(w, 0) + 1

# 2. find the most frequent word
winner = max(count, key=count.get)

# 3. deduped vocabulary, order preserved
seen = set()
vocab = []
for w in words:
    if w not in seen:
        seen.add(w)
        vocab.append(w)

print("Frequencies:", count)
print("Most frequent:", winner, count[winner], "times")
print("Vocabulary:", vocab)
```

Output:

```
Frequencies: {'Python': 2, 'is': 2, 'the': 1, 'best': 1, 'language': 1, 'easy': 1, 'to': 1, 'learn': 1}
Most frequent: Python 2 times
Vocabulary: ['Python', 'is', 'the', 'best', 'language', 'easy', 'to', 'learn']
```

⚠️ **Crash: writing the "count" and "find the maximum" steps in the wrong order.**

```python
winner = max(count, key=count.get)      # count is still empty!
count = {}
```

Count first, then find the maximum. In the wrong order `count` is an empty dict and `max` raises `ValueError: arg is an empty sequence`.

## 6. A more complete example: ranking by frequency

Printing the frequency table from highest to lowest count:

```python
# count frequencies (same as above)
count = {}
for w in words:
    count[w] = count.get(w, 0) + 1

# rank from highest to lowest
ranked = sorted(count.items(), key=lambda item: item[1], reverse=True)
for w, c in ranked:
    print(f"{w}: {c}")
```

```
Python: 2
is: 2
the: 1
best: 1
language: 1
easy: 1
to: 1
learn: 1
```

`sorted(count.items(), key=lambda item: item[1], reverse=True)` sorts by the value from high to low — a technique from Lesson 13.

## Summary

- Word frequency counting uses the dict pattern: `count[w] = count.get(w, 0) + 1`
- For the most frequent word use `max(count, key=count.get)` — never skip the `key`
- For a deduped vocabulary you can use a set, or "set for bookkeeping + list for order"
- To find "every joint winner" you must filter by the maximum value yourself
- This is the classic combination of a dictionary (counting) and a set (dedupe checks)
