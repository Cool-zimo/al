# One Box, Many Values: Lists

> So far every variable you have written holds exactly **one** thing — one score, one name, one number.
>
> Real programs do not work that way. A class has thirty students, a shopping cart holds ten items, and a week has seven temperatures.
>
> This lesson answers one question: **how can a single variable hold a whole pile of data?**

## 1. Why a single value is not enough

Imagine you need to record five quiz scores and print the average. With what you already know, you write this:

```python
s1 = 87
s2 = 92
s3 = 78
s4 = 95
s5 = 61

total = s1 + s2 + s3 + s4 + s5
print("Average:", total / 5)
```

It runs. But now a harder question appears.

**What if the class has fifty students?**

You would write fifty variable names and fifty additions by hand. And what if the number of scores comes from the user, so you do not know it in advance? **You cannot even decide how many variables to write.**

That is the real limit of one-value-per-variable:

> **The number of variables is fixed when you write the code, but the amount of data is usually unknown until the program runs.**

## 2. A list: a row of numbered lockers

A list exists to solve exactly this problem. One variable holds a whole row of values:

```python
scores = [87, 92, 78, 95, 61]
print(scores)
```

Output:

```
[87, 92, 78, 95, 61]
```

`scores` is a single variable, yet it contains five numbers.

Think of an ordinary variable as **one box**. A list is **a row of numbered lockers**.

```
scores  →  ┌────┬────┬────┬────┬────┐
           │ 87 │ 92 │ 78 │ 95 │ 61 │
           └────┴────┴────┴────┴────┘
             0    1    2    3    4      ← the numbers are called "indexes"
```

Each locker has a fixed number, and you reach in by that number. That number is called an **index**, and the next lesson explains how to use it.

## 3. How to create a list

Use square brackets `[]`, with elements separated by commas:

```python
numbers = [1, 2, 3, 4, 5]
names = ["Alice", "Bob", "Carol"]
mixed = [87, "Alice", True, 3.14]   # any type, mixed freely
empty = []                          # a list with nothing in it yet
```

Three things to notice:

**① A list can hold any type, and you can mix types.** Numbers, strings, booleans, and even another list — all are welcome.

**② An empty list is legal, and it is extremely useful.** It is like pushing an empty shopping cart around the shop and dropping items in as you find them.

**③ Order matters.** `[87, 92]` and `[92, 87]` are **two different lists** — the order itself carries information, for example "the first attempt and the second attempt".

### A handy trick: split a string into characters

```python
chars = list("hello")
print(chars)
```

Output:

```
['h', 'e', 'l', 'l', 'o']
```

`list()` walks through a string and turns it into "a list of single characters".

## 4. How long is the list: `len()`

Do not count by hand. Ask the list with `len()`:

```python
scores = [87, 92, 78, 95, 61]
print(len(scores))
```

Output:

```
5
```

`len` is short for "length". It is a Python built-in function that can measure almost any "container".

**Why this one line matters:** it means your program **no longer needs to know in advance how much data there is**.

```python
scores = [87, 92, 78, 95, 61]
print("Count:", len(scores))
```

Whether the list grows to five items or five hundred, this line of code never changes.

⚠️ **The crash you will hit first: calling `len` like a method.**

```python
scores.len()      # WRONG  AttributeError: 'list' object has no attribute 'len'
```

`len()` is a **function**, so it wraps the list from the outside. It is not a method, so you must not put a dot after the list.

| Writing | Correct? | Meaning |
|---|---|---|
| `len(scores)` | ✅ | `len` is a function, written outside |
| `scores.len()` | ❌ | A list has no `.len()` method |

**A rule of thumb:** `len` is an "outsider" that counts for you, so it stands outside the parentheses. A method is an "insider", so it follows a dot.

## 5. The single most important ability: a list can change

This deserves to be said early, because it decides what lists are for:

```python
scores = [87, 92, 78]
scores.append(95)          # add one value at the end
print(scores)
```

Output:

```
[87, 92, 78, 95]
```

**A list can grow, shrink, and be rewritten while the program runs.** That means you do not need to know in advance how much data there will be — the user submits one entry, and you `append` one entry.

This is precisely how lists solve the problem at the start: **the amount of data is decided at runtime.**

(The full story of adding and removing comes in Lesson 3. For now, just remember "it can change".)

## 6. Back to the original problem

Here is the "compute an average" problem rewritten with a list:

```python
scores = [87, 92, 78, 95, 61]

total = 0
for s in scores:
    total = total + s

print("Average:", total / len(scores))
```

Output:

```
Average: 82.6
```

Do you see it? **This code has nothing to do with how many scores there are.**

- Add one score: put it in the list, and not a single line changes.
- Remove one score: same thing.
- Switch to fifty students: it still works.

That is the real value of a list: **it removes "how many" from your code.**

(`for s in scores` is called iteration. Lesson 5 covers it fully. For now, read it as "take every element out of the list and do something with it once".)

## 7. When should you use a list?

Here is a simple rule:

| Situation | Use |
|---|---|
| One user's name | A plain variable |
| Forty names in a class | **A list** |
| One fixed tax rate | A plain variable |
| Seven temperatures in a week | **A list** |

The test is a sentence: **if you cannot say how many items there will be when you write the code, reach for a list.**
