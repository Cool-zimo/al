# Data Types: What Is Actually Inside the Box

> This lesson answers the question: "What can I put in a variable?" Numbers, text, and true/false values are all different kinds of data, and the kind decides what you can do with it.

## The three most basic types

A box can hold different kinds of thing. A fridge holds vegetables, meat, and drinks, and you handle each one differently -- meat needs defrosting, a drink you just open. Data in a program is the same: it comes in types.

| Type | JS name | Examples | What it is for |
|---|---|---|---|
| Number | `number` | `100`, `3.14`, `-5` | Counting and calculating |
| String | `string` | `"Hello"`, `'abc'` | A piece of text |
| Boolean | `boolean` | `true`, `false` | A yes/no, on/off answer |

```js
let price = 9.9;          // a number
let productName = "noodles";  // a string
let isAvailable = true;   // a boolean
```

## How to check the type: `typeof`

If you want to know what kind of thing is inside a box, use `typeof`:

```js
console.log(typeof 100);       // "number"
console.log(typeof "Hello");   // "string"
console.log(typeof true);      // "boolean"
console.log(typeof "123");     // "string"  (watch out! Quotes make it text)
```

`typeof` is followed by a value or a variable name, and it tells you what type that thing is.

## A string is "text wrapped in quotes"

You write a string by wrapping text in single quotes `'...'` or double quotes `"..."`:

```js
let greeting = "Hello";
let name = 'Alice';
```

Single and double quotes behave exactly the same, so pick one and stick with it. But **the quotes must match** -- start with a single quote, end with a single quote.

## Joining strings together

The `+` operator can glue two strings into one:

```js
let firstName = "A";
let lastName = "Smith";
let fullName = firstName + lastName;
console.log(fullName);  // "ASmith"
```

It is like sticking two pieces of tape together. `+` means "add" for numbers and "join" for strings.

A practical example:

```js
let product = "noodles";
let price = 5;
console.log(product + " costs " + price + " pounds");
// prints: noodles costs 5 pounds
```

**Notice:** `price` is a number, but when it sits inside a string joining operation, JS quietly turns it into text. So the `5` gets glued on instead of being added.

## Crash site 1: forgetting the quotes on a string

```js
let name = Alice;  // forgot the quotes!
console.log(name);
```

**Consequence:** the browser throws `ReferenceError: Alice is not defined`. Without quotes, `Alice` looks like a variable name, so the browser goes hunting for a variable called Alice -- and finds nothing. **Strings always need quotes.**

## Crash site 2: mismatched quotes

```js
let msg = "He said: 'Hello"';  // the quotes are a mess
```

**Consequence:** a `SyntaxError`. The browser sees the second quote, decides the string is finished, and then has no idea what to do with the rest of the line. **Start with one kind of quote, end with the same kind.**

The clean versions:

```js
let msg = "He said: 'Hello'";  // double quotes wrapping single -- fine
let msg2 = 'He said: "Hello"';  // single quotes wrapping double -- also fine
```

## Summary

- Three basic types: **number** (for maths), **string** (text, always in quotes), **boolean** (true/false).
- `typeof` tells you the type of a value.
- Strings join together with `+`.
- Strings must be wrapped in matching quotes.
