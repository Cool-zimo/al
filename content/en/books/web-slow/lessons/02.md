# Variables: Labels You Stick on Boxes

> This lesson answers the question: "How does a program remember anything?" A variable is the name you give to a piece of data. Remember the name and you can pull the data back out whenever you need it.

## A variable is a box with a label on it

Imagine you have a box on your desk. Across the front someone has taped a label that says **"Pocket money"**, and inside the box there is £100. Next time you need that money, you do not open every box in the house -- you just look for the one labelled "Pocket money".

A **variable** in a program is exactly that labelled box:

```js
let pocketMoney = 100;
```

This line says: "Make a box called `pocketMoney` and put 100 inside it."

- `let` is the keyword that means "I want to make a box"
- `pocketMoney` is the label on the box (the variable name)
- `=` means "take what is on the right and put it into the box on the left"
- `100` is the data sitting inside

From now on, whenever you write `pocketMoney`, you get that 100 back:

```js
let pocketMoney = 100;
console.log(pocketMoney);       // prints 100
console.log(pocketMoney + 50);  // prints 150
```

## `=` does not mean "equals" -- it means "put it in"

This is the trap that catches almost everyone. In maths, `=` means "is equal to". In programming, `=` means **"assignment"** -- take the value on the right and stuff it into the box on the left.

```js
let age = 20;  // make a box called age, put 20 inside
age = 21;      // throw out what was there and put 21 in instead
```

That second line is not a statement of fact about the universe. It is an instruction: "Replace the contents of the `age` box with 21." In everyday language, think "tip the old contents out, put the new ones in."

So how do you say "is equal to"? With `===` (three equals signs). That is lesson 06.

## `let` and `const`: the box you can refill, and the one you cannot

A box made with `let` **can** be refilled:

```js
let score = 80;
score = 95;  // no problem
console.log(score);  // 95
```

A box made with `const` **cannot** be refilled. `const` is short for "constant":

```js
const pi = 3.14159;
pi = 3.14;  // ERROR! You cannot change it
```

When should you use which? **First ask whether this value will ever change.** The number pi never changes, so `const` is right. Your exam score might change, so `let` is right.

> 💡 A useful rule of thumb: when in doubt, start with `const`. If you later discover you need to change the value, switch it to `let`. Many teams default to `const` everywhere.

## The rules for naming a variable

You cannot call a variable anything you fancy. There are a few rules:

| Rule | ✅ Allowed | ❌ Not allowed |
|---|---|---|
| Letters, digits, `_` and `$` only | `myName`, `_count`, `$price` | `my-name` (the dash is banned) |
| Cannot start with a digit | `age2` | `2age` |
| Cannot be a reserved word | `myLet`, `myFunction` | `let`, `const`, `function` |
| Uppercase and lowercase count as different | `name` and `Name` are two separate boxes | — |

The style everyone uses is **camelCase**: `myFirstName`, `totalPrice`, `userAge`. Join several words together, start the first one lowercase, then capitalise the first letter of every word after it.

## Declare before you use

**A variable must be created before you can use it.** Just like you need a cup before you can pour water into one.

```js
console.log(myName);  // ERROR! myName does not exist yet
let myName = "Alice";
```

The right order:

```js
let myName = "Alice";  // declare the box AND put something in it
console.log(myName);   // now use it
```

## Crash site 1: using a variable without declaring it

```js
score = 100;  // forgot let / const
console.log(score);
```

**Consequence:** in strict mode this throws an error on the spot. Even when it does not, the variable silently becomes global, which means some other piece of code across the page can change it without you noticing -- a nightmare to track down. **Always declare your variables.**

## Crash site 2: trying to change a `const`

```js
const userName = "Alice";
userName = "Bob";  // TypeError: Assignment to constant variable
```

**Consequence:** the browser shows a red error and stops running the code at that line. If you genuinely need to swap the value, change `const` to `let`.

## Summary

- A variable is a labelled box: `let name = value` creates the box and fills it.
- `=` means "put it in" (assignment), never "equals".
- `let` can be changed, `const` cannot. When unsure, start with `const`.
- Declare before use, and follow the naming rules (camelCase, no digits first, no reserved words).
