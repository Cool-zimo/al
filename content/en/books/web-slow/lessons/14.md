# Arrays of Objects: What Real Data Looks Like

> This lesson answers the question: "How do I store a whole list of structured records?" In real projects, the data you get back from a server is almost always an "array of objects" — an array where each item is itself an object.

## What does real data look like?

Open up the API of almost any website and the data comes back shaped like this:

```json
[
  { "name": "Alice", "age": 20, "city": "London" },
  { "name": "Bob", "age": 25, "city": "Paris" },
  { "name": "Charlie", "age": 30, "city": "Berlin" }
]
```

**This is an array of objects:** an array where each item is an object.

Everyday analogy: think of the array as a **table**, each object as one **row**, and each property as a **column**:

| name | age | city |
|---|---|---|
| Alice | 20 | London |
| Bob | 25 | Paris |
| Charlie | 30 | Berlin |

## Creating an array of objects

```js
let students = [
    { name: "Alice", age: 20, city: "London" },
    { name: "Bob", age: 25, city: "Paris" },
    { name: "Charlie", age: 30, city: "Berlin" }
];
```

This is an array of length 3, and each item is an object.

## Reading data: index first, then property

**Two layers of lookup:** first use the array index to grab an object, then use dot notation to grab a property from it.

```js
console.log(students[0]);        // { name: "Alice", age: 20, city: "London" }
console.log(students[0].name);   // "Alice"
console.log(students[1].city);   // "Paris"
console.log(students[2].age);    // 30
```

**How to read it:** `students[0]` gets you the first object, then `.name` reaches into that object for the `name` property.

You can chain several layers:

```js
let orders = [
    { id: "A001", items: ["Mouse", "Keyboard"], total: 75 },
    { id: "A002", items: ["Monitor"], total: 200 }
];

console.log(orders[0].items[1]);  // "Keyboard"
// orders[0]   -> the first order object
// .items      -> its items array
// [1]         -> the second item in that array
```

## Looping over an array of objects

This is **the core operation**. You have a list of records and you want to display each person's or each product's information:

```js
let students = [
    { name: "Alice", age: 20, city: "London" },
    { name: "Bob", age: 25, city: "Paris" },
    { name: "Charlie", age: 30, city: "Berlin" }
];

for (let i = 0; i < students.length; i++) {
    console.log(students[i].name + ", " + students[i].age + " years old, from " + students[i].city);
}
```

Output:

```
Alice, 20 years old, from London
Bob, 25 years old, from Paris
Charlie, 30 years old, from Berlin
```

**The key idea:** `students[i]` is the current object, and then `.name`, `.age`, `.city` reach into its properties.

## Filtering inside an array of objects

```js
let students = [
    { name: "Alice", age: 20, city: "London" },
    { name: "Bob", age: 25, city: "Paris" },
    { name: "Charlie", age: 30, city: "London" },
    { name: "Diana", age: 18, city: "Berlin" }
];

// find everyone from London
let londoners = [];
for (let i = 0; i < students.length; i++) {
    if (students[i].city === "London") {
        londoners.push(students[i]);
    }
}
console.log(londoners);
// [{ name: "Alice", age: 20, city: "London" }, { name: "Charlie", age: 30, city: "London" }]
```

**The pattern:** loop + condition + push into a new array. Lesson 15 uses this pattern heavily.

## Crash site 1: forgetting the index and grabbing a property directly

```js
let students = [
    { name: "Alice", age: 20 },
    { name: "Bob", age: 25 }
];

console.log(students.name);  // undefined
```

**Consequence:** you get `undefined`. `students` is the array, and the array itself has no `name` property. You must index first: `students[0].name`. **With an array of objects it is always "index first, then dot."**

## Crash site 2: the wrong loop condition leaves one round too many

```js
let students = [
    { name: "Alice", age: 20 },
    { name: "Bob", age: 25 },
    { name: "Charlie", age: 30 }
];

for (let i = 0; i <= students.length; i++) {  // that extra = is the problem
    console.log(students[i].name);  // on the last round i is 3, students[3] is undefined -> crash!
}
```

**Consequence:** on the final round `i` is 3, `students[3]` is `undefined`, and `undefined.name` throws an error. **The condition should be `i < students.length`, never `<=`.**

## Summary

- An array of objects = an array where each item is an object. Almost all real data looks like this.
- To read a value: "index first, then dot" — `array[index].propertyName`.
- The standard loop: `for (let i = 0; i < arr.length; i++)`, using `arr[i].property` inside the body.
- The filtering pattern: loop + if check + push into a new array.
