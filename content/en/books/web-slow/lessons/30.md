# The Final Lesson: Code Organisation, Common Bugs, and What Comes Next

> This is the last lesson of *Web Design · JavaScript from Scratch (Slow Track)*. It organises the whole project's code, reviews three common bugs, and tells you what to learn next.

## The complete code

```js
// ===== data =====
let todos = [];

// ===== elements =====
let input = document.querySelector("#todo-input");
let addBtn = document.querySelector("#add-btn");
let list = document.querySelector("#todo-list");

// ===== rendering =====
function render() {
    list.innerHTML = "";                    // clear first, to avoid duplicates

    todos.forEach(function (todo) {
        let li = document.createElement("li");

        let span = document.createElement("span");
        span.textContent = todo.text;        // use textContent to prevent XSS
        li.appendChild(span);

        let delBtn = document.createElement("button");
        delBtn.textContent = "Delete";
        delBtn.addEventListener("click", function () {
            deleteTodo(todo.id);
        });
        li.appendChild(delBtn);

        list.appendChild(li);
    });
}

// ===== adding =====
function addTodo(text) {
    todos.push({
        id: Date.now(),
        text: text,
        done: false
    });
    render();                               // changed the array → must render
}

// ===== deleting =====
function deleteTodo(id) {
    todos = todos.filter(function (todo) {
        return todo.id !== id;
    });
    render();                               // changed the array → must render
}

// ===== event binding =====
addBtn.addEventListener("click", function () {
    let text = input.value;
    if (text === "") return;
    addTodo(text);
    input.value = "";
});

render();   // first render
```

**The rule for organising code: from top to bottom it reads "data → elements → functions → event binding".** Anyone reading it can see at a glance where each block lives.

## Three common bugs reviewed

### Bug 1: changing the array but forgetting to re-render

```js
function addTodo(text) {
    todos.push({ id: Date.now(), text: text, done: false });
    // forgot render()
}
```

**Symptom:** the data changes but the page stays still.
**Rule of thumb:** whenever you touch todos, you render.

### Bug 2: writing `===` instead of `=`

```js
input.value = "abc";    // assignment: correct
input.value === "abc";  // comparison: returns true or false, does not change the value
```

**Symptom:** you meant to change the value but wrote a comparison, so the input box never moves.
**Rule of thumb:** one `=` for assignment, three `===` for comparison.

### Bug 3: counting from 1 instead of 0

```js
let first = todos[1];   // thought this was the first item, but it is the second
let first = todos[0];   // this is the correct one
```

**Symptom:** you grab the wrong item, get the loop condition wrong, and see `undefined`.
**Rule of thumb:** indexes start at 0; the loop condition is `< length`, not `<= length`.

## Features you can add (extra practice)

1. **Mark as done:** add a checkbox to each item; when ticked, toggle a `done` style with `classList.toggle`.
2. **Persistence:** store with `localStorage.setItem("todos", JSON.stringify(todos))`, read with `JSON.parse`, so the list survives a refresh.
3. **Editing:** double-click the text to turn it into an input box, then save on Enter.
4. **Filtering:** three tabs for All / Active / Completed.

None of these needs new knowledge — you can build them with the first 30 lessons alone. **Whether you can do these on your own is the real test of how well you learned this book.**
