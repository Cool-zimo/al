# Changing Styles: `classList` and Editing `style` Directly

> This lesson covers two ways to change styling. The preferred one is `classList` — toggling a class on and off — with direct `style` edits kept for quick, one-off fixes. Learn the first well and your styles stay manageable.

## classList: add, remove, and toggle a class

```html
<style>
  .red { color: rgb(255, 0, 0); }
  .big { font-size: 24px; }
</style>
<p id="text">a piece of text</p>
```

```js
let p = document.querySelector("#text");

p.classList.add("red");      // adds class="red" — the text turns red
p.classList.add("big");      // also adds class="big" — the text gets larger
p.classList.remove("red");   // removes red, so the colour returns to normal
p.classList.toggle("big");   // if present, remove it; if absent, add it (a switch)
```

**`classList` is the recommended way to change styles:** the rules live in CSS, and JavaScript only "flips the class on or off." The separation stays clean and the result is easy to maintain.

## The beauty of toggle: click to switch a highlight

```html
<button id="btn">Click me</button>
```

```js
let btn = document.querySelector("#btn");

btn.addEventListener("click", function () {
    btn.classList.toggle("active");   // each click switches between adding and removing "active"
});
```

Together with this CSS:

```css
.active { background: rgb(33, 150, 243); color: white; }
```

**One line with `toggle` gives you "click once to turn it on, click again to turn it off."**

## Editing style directly: for quick fixes

```js
let box = document.querySelector("#box");

box.style.color = "rgb(255, 0, 0)";
box.style.fontSize = "24px";
box.style.backgroundColor = "rgb(227, 242, 253)";
```

Two things to watch:

1. **CSS properties with a dash, like `font-size` and `background-color`, become camelCase in JS: `fontSize`, `backgroundColor`.**
2. **The value is a string, and it must include a unit.** Writing `box.style.fontSize = 24` does nothing; you need `"24px"`.

## Reading a style back: getComputedStyle

```js
let box = document.querySelector("#box");

// read the style after the browser has finished computing it
let color = getComputedStyle(box).color;
console.log(color);   // "rgb(255, 0, 0)"
```

**`el.style.xxx` can only see inline styles (the ones written in the tag's `style` attribute); it cannot see styles that came from a CSS class.** To read the value that actually applies, use `getComputedStyle(el).xxx`.

## Crash site 1: writing a hex colour that the grader cannot see

```js
box.style.backgroundColor = "#e3f2fd";
console.log(getComputedStyle(box).backgroundColor);   // "rgb(227, 242, 253)"
```

Consequence: you wrote `#e3f2fd`, but the browser stores the computed result as `rgb(227, 242, 253)`. **For any style check, write colours in `rgb(R, G, B)` form — and remember the space after each comma.**

## Crash site 2: writing `font-size` instead of `fontSize`

```js
box.style["font-size"] = "24px";   // ✗ no error, but nothing happens
box.style.fontSize = "24px";       // ✓
```

Consequence: the first version just adds a weird property to the object; it is not a real CSS property. **Any CSS property with a dash must be converted to camelCase.**

## classList methods at a glance

| Method | What it does |
|---|---|
| `add("x")` | add a class |
| `remove("x")` | remove a class |
| `toggle("x")` | remove it if present, add it if absent |
| `contains("x")` | return true or false depending on whether the class is there |

```js
if (box.classList.contains("active")) {
    console.log("it is highlighted right now");
}
```

## Summary

- Prefer `classList.add / remove / toggle` for switching classes.
- Edit `style` directly only as a quick fix: camelCase names, and string values with units.
- `el.style.xxx` only sees inline styles; for the real value use `getComputedStyle`.
- For grading, `rgb(R, G, B)` is the safest colour format.
