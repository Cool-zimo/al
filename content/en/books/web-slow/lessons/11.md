# Arrays: A Row of Numbered Boxes

> This lesson answers the question: "How do I store a whole bunch of things at once?" A variable holds one value, but an array holds a whole list of values, kept in order.

## One variable is not enough

Say you need to store the names of five classmates.

**The awkward way:**

```js
let name1 = "Alice";
let name2 = "Bob";
let name3 = "Charlie";
let name4 = "Diana";
let name5 = "Ethan";
```

Five names mean five variables. What if there are fifty? Five hundred? Clearly that will not do.

**The right way: use an array.**

## An array = a row of numbered boxes

Picture a row of lockers in a school corridor, each one with a number on the door: locker 0, locker 1, locker 2... You put something in each locker, and when you want it back you just say the number.

That is exactly what a JavaScript array is:

```js
let students = ["Alice", "Bob", "Charlie", "Diana", "Ethan"];
```

| Index | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| Value | "Alice" | "Bob" | "Charlie" | "Diana" | "Ethan" |

**You create an array with square brackets `[]`**, with the items separated by commas.

## Indexes start at 0!

This is **the classic beginner trap**. The numbers on an array (properly called "indexes") **start at 0, not 1**.

```js
let students = ["Alice", "Bob", "Charlie"];
// index:             0        1        2

console.log(students[0]);  // "Alice" (the first item)
console.log(students[1]);  // "Bob"   (the second item)
console.log(students[2]);  // "Charlie" (the third item)
```

**Everyday analogy:** this is a bit like floor numbering in some countries, where the floor you walk in on is the "Ground Floor" and what we would call the second floor is numbered 1. You are used to counting from 1, but a programmer's array counts from 0.

**To grab an item, use square brackets with the index:**

```js
let fruits = ["apple", "banana", "orange"];
console.log(fruits[0]);  // "apple"
console.log(fruits[2]);  // "orange"
```

## `length`: how long is the array?

To find out how many items an array has, use `.length`:

```js
let fruits = ["apple", "banana", "orange"];
console.log(fruits.length);  // 3
```

`length` is simply "the number of items."

**Using length together with a loop to walk through the array:**

```js
for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}
```

Here `i < fruits.length` means `i < 3`, so i takes the values 0, 1, 2 — exactly the three items. **This is the standard way to go through an array.**

## An array can hold different types

```js
let mixed = [1, "hello", true, 3.14];
console.log(mixed[0]);  // 1
console.log(mixed[1]);  // "hello"
```

An array can mix numbers, strings, and booleans. In real projects, though, you usually keep one type of thing in a single array.

## Crash site 1: counting indexes from 1

```js
let fruits = ["apple", "banana", "orange"];
console.log(fruits[1]);  // thought this was the first one? Nope, it is "banana"
```

**Consequence:** you grab the wrong item. You thought you were getting the first, but you actually got the second. **Always remember: the first item is [0], not [1].**

## Crash site 2: going past the end

```js
let fruits = ["apple", "banana", "orange"];
console.log(fruits[5]);  // undefined
```

**Consequence:** no error is thrown, but you get back `undefined` ("there is nothing there"). And if you then try to use that value:

```js
let total = fruits[5] + " items";  // "undefined items"
```

You end up with nonsense. **Before you access an index, check that it is inside the range: `index < array.length`.**

## Summary

- An array is created with `[]`, items separated by commas — it holds a whole list of values.
- **Indexes start at 0**: the first item is `[0]`, the second is `[1]`.
- `.length` tells you how many items there are.
- The standard way to walk through an array: `for (let i = 0; i < arr.length; i++)`.
- Going past the end gives you `undefined` — no error, but be careful.
