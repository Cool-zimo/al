# Objects: One Thing with Several Labels

> This lesson answers the question: "How do I describe one specific thing?" An array is great for a list of similar items, but an object bundles together several facts about one thing — name, age, city — in one place.

## Where arrays fall short

An array is perfect for "a list of similar things":

```js
let students = ["Alice", "Bob", "Charlie"];  // a list of names
```

But what if you want to store **everything about Alice** — her name, age, city, hobby? An array gets messy fast:

```js
let alice = ["Alice", 20, "London", "football"];  // what is what? it falls apart if the order changes
```

Is `"London"` her city or her hobby? Is `20` her age or an ID number? It is impossible to tell at a glance.

## An object = an information card

An object is created with `{}`, and inside it you have **key-value pairs**:

```js
let alice = {
    name: "Alice",
    age: 20,
    city: "London",
    hobby: "football"
};
```

| Key | Value |
|---|---|
| `name` | `"Alice"` |
| `age` | `20` |
| `city` | `"London"` |
| `hobby` | `"football"` |

**Everyday analogy:** an object is like a filled-in registration form. Each box on the form has a label (Name, Age, City) and you write the matching value inside it.

## Reading values with dot notation

To grab a property from an object, use a **dot**:

```js
let alice = {
    name: "Alice",
    age: 20,
    city: "London"
};

console.log(alice.name);   // "Alice"
console.log(alice.age);    // 20
console.log(alice.city);   // "London"
```

`object.propertyName` means "give me the value of this property from this object."

## Changing and adding properties

```js
let alice = { name: "Alice", age: 20 };

// change an existing property
alice.age = 21;
console.log(alice.age);  // 21

// add a brand new property
alice.email = "alice@example.com";
console.log(alice.email);  // "alice@example.com"
```

Just use `=` to assign it. If the property already exists it is updated; if it does not, it is added.

## Why bother with objects?

**Because real-world data is almost always "one thing with several properties."**

A product, for example:

```js
let product = {
    name: "Wireless Mouse",
    price: 25,
    stock: 50,
    inStock: true
};
```

Or an order:

```js
let order = {
    id: "A001",
    items: ["Mouse", "Keyboard"],
    total: 75,
    status: "paid"
};
```

If you tried to store all that in arrays, your code would be a nightmare. With an object, the property names make everything obvious and hard to get wrong.

## An object can hold an array too

```js
let student = {
    name: "Alice",
    scores: [85, 92, 78, 96],  // a property can be an array
    friends: ["Bob", "Charlie"]
};

console.log(student.scores[0]);  // 85 (grab the scores array, then index 0)
```

**You can chain the lookups:** `object.property` gets you the array, then `[index]` grabs an item out of it.

## Crash site 1: using array indexing on an object

```js
let alice = { name: "Alice", age: 20 };
console.log(alice[0]);  // undefined
```

**Consequence:** you get `undefined`. An object is read by key name, not by position. `alice[0]` is wrong — you want `alice.name`. **Objects and arrays are looked up in different ways; do not mix them up.**

## Crash site 2: a quoted key name that breaks dot notation

```js
let obj = {
    "first-name": "Alice",
    "last name": "Wong"
};

console.log(obj.first-name);  // error!
```

**Consequence:** when a key contains special characters (a dash, a space), dot notation will not work — you must use square brackets:

```js
console.log(obj["first-name"]);  // "Alice"  ok
console.log(obj["last name"]);   // "Wong"   ok
```

**The rule:** if the key is plain letters and digits (no spaces, no dashes) use dot notation; if it has spaces or dashes, use square brackets.

## Summary

- An object is created with `{}` and holds key-value pairs — several facts about one thing.
- Read a value with a dot: `object.propertyName`.
- Change or add a property with `=`.
- Real data is "one thing with several properties," and that is exactly what objects model.
- When a key has spaces or dashes, use square brackets: `object["key name"]`.

q: Write a function getFullName that takes an object person with two properties, firstName and lastName, and returns the two names joined together.
func: getFullName

  function getFullName(person) {
