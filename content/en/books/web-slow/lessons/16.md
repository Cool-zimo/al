# What a Function Is: Wrapping Up a Block of Code

> For the first 15 lessons, your code ran top to bottom, one line after another. From this lesson on we learn **functions**: they wrap a block of code and give it a name, so you can run it whenever you call that name. It is one of the most valuable habits in programming.

## Why bother with functions?

Here is a version without functions. Alice greets her teachers every morning:

```js
console.log("Good morning, Mr. Smith");
console.log("Good morning, Ms. Jones");
console.log("Good morning, Dr. Brown");
```

If there are 40 teachers on the staff, that is 40 lines. Worse: the day Alice decides to say "Hello" instead, she has to edit all 40 lines by hand.

A function wraps it up:

```js
function sayHi(name) {
    console.log("Good morning, " + name);
}

sayHi("Mr. Smith");
sayHi("Ms. Jones");
sayHi("Dr. Brown");
```

**The same three greetings, written once.** If she wants "Hello" instead, she edits the single line inside the function and all three greetings change at once.

Three reasons to use functions — remember these three sentences and you are set:

1. **No copying and pasting**: the same logic is written once and called from anywhere.
2. **Easy to change**: change the logic in one place and every caller follows.
3. **Easy to read**: when you see `sayHi("Mr. Smith")` you know exactly what that line does.

## Defining and calling a function

The fixed shape of a definition:

```js
function functionName(parameters) {
    body: the code that runs
}
```

- `function` is a keyword — type it exactly.
- Give it a name you can read: `sayHi`, `calcTotal`, `findMax`.
- Parameters go inside the parentheses; with no parameters write an empty pair `()`.
- The body is wrapped in curly braces `{}`.

**Defining does not run anything.** You must *call* it:

```js
function greet() {
    console.log("Hi there");
}

greet();   // calling: the name plus parentheses — this line prints "Hi there"
console.log("I have not called the function yet");
greet();   // call it again and it prints "Hi there" again
```

Calling is just `name()`. You can call it as many times as you like; each call runs the whole body once.

## Crash Site 1: defining but never calling

```js
function hello() {
    console.log("Will I print?");
}

hello   // ← the () is missing
```

Result: nothing prints. **Without `()` after the name it is not a call — it is just the name, and JavaScript glances at it and moves on.**

Remember: `()` is the "run it now" signal. No parentheses, no execution.

## Crash Site 2: defining after you call it

```js
sayHi();   // the call comes first here

function sayHi() {
    console.log("Hello");
}
```

This one **actually works**. Function declarations are hoisted — lifted as a whole to the top of the current scope — so it does not matter whether the definition sits above or below the call. But this rule **only holds for `function` declarations**; the function expressions you will meet later do not get the same treatment. For now, keep definitions above their calls so the file reads naturally.

## Where the definition goes

Recommended order: **define first, call after** — it reads best top to bottom:

```js
function printMenu() {           // 1. define
    console.log("1. Log in");
    console.log("2. Sign up");
    console.log("3. Quit");
}

printMenu();                     // 2. call
```

Two functions that call each other are fine too, as long as both are defined:

```js
function start() {
    console.log("Start");
    end();       // end is defined below, but it is also a declaration, so this works
}

function end() {
    console.log("End");
}

start();
```

## A function with a parameter

Notice `sayHi(name)` above. `name` is a **parameter** — a placeholder that gets filled in when you call:

```js
function sayHi(name) {
    console.log("Good morning, " + name);
}

sayHi("Mr. Smith");   // name becomes "Mr. Smith"
sayHi("Ms. Jones");   // name becomes "Ms. Jones"
```

We will dig into parameters properly in the next lesson. For now just notice: **the same function body produces different output depending on what you pass in.** That is most of the power right there.

## Recap

- A function is a name for a block of code. Define it with `function name() { ... }`.
- Defining does not execute anything; you must call `name()`.
- The same function can be called many times, which saves copying and pasting.
- The easiest thing to forget is `()`: if you want it to run, add the parentheses.

## In-class exercise

```quiz
type: js
q: Write a function sayHello that prints "Hello, world!" when you call it.
func: sayHello
starter: |
  function sayHello() {
      // write here
  }
checks:
- (function(){ const logs = []; const orig = console.log; console.log = function (...a) { logs.push(a.join(' ')); }; sayHello(); console.log = orig; return logs.length === 1 && logs[0] === 'Hello, world!'; })()
hint: use console.log inside the body to print that sentence
explain: once the function is defined and called, the console.log in its body runs.
```
