# AND, OR and NOT: Combining Conditions

> This lesson answers the question: "How do I combine several checks?" It is like saying "cheap **and** good quality" -- both have to hold. Or "VIP **or** on sale" -- either one is enough.

## Combined checks in real life

When you shop online you might think:

- Price < £100 **and** rating > 4.5 → buy it! (both must be true)
- Is it a VIP **or** is there a sale today → free delivery (one is enough)
- Is the stock **not** zero → I can order (the opposite of "out of stock")

A program expresses those three ideas with three symbols:

| Symbol | Name | Everyday word | Rule |
|---|---|---|---|
| `&&` | Logical AND | "and" | true only if both sides are true |
| `||` | Logical OR | "or" | true if either side is true |
| `!` | Logical NOT | "not" | flips true to false and false to true |

## `&&` AND: both sides must be right

```js
let price = 80;
let rating = 4.8;

if (price < 100 && rating > 4.5) {
    console.log("Buy it!");
}
// price < 100 is true, rating > 4.5 is true, so true && true is true
```

| Left | Right | `&&` result |
|---|---|---|
| true | true | **true** |
| true | false | false |
| false | true | false |
| false | false | false |

**Only "true and true" gives true.** Like "cheap **and** good" -- one failing is enough to walk away.

## `||` OR: one side is enough

```js
let isVip = false;
let isSale = true;

if (isVip || isSale) {
    console.log("Free delivery!");
}
// false || true → true
```

| Left | Right | `||` result |
|---|---|---|
| true | true | **true** |
| true | false | **true** |
| false | true | **true** |
| false | false | false |

**If either side is true, the whole thing is true.** Like "VIP **or** sale" -- meet one condition and you get free delivery.

## `!` NOT: flipping it around

```js
let isSoldOut = false;

if (!isSoldOut) {
    console.log("You can order");
}
// !false → true
```

`!` simply means "the opposite." `!true` is false; `!false` is true.

A common use: checking for "not empty":

```js
let name = "";
if (!name) {
    console.log("Name cannot be empty");
}
```

## Short-circuiting: a clever kind of laziness

`&&` and `||` have a neat habit called **short-circuiting**:

- With `&&`: if the left side is false, the right side is **never even checked**
- With `||`: if the left side is true, the right side is **never even checked**

```js
true || console.log("this never runs");
// left side is already true, so the right side is skipped

false && console.log("this never runs");
// left side is already false, so the right side is skipped
```

This comes in handy for "safe checks" in real code:

```js
let user = null;
console.log(user && user.name);  // null, with no error
// if user is null, the left side is already falsy, so the right side never runs
```

## Putting them together

```js
let age = 25;
let hasTicket = true;
let isVip = false;

if (age >= 18 && hasTicket || isVip) {
    console.log("You may enter");
}
```

About priority: `&&` is evaluated before `||`. So this is the same as `(age >= 18 && hasTicket) || isVip`.

**Best practice: add parentheses so your intention is obvious:**

```js
if ((age >= 18 && hasTicket) || isVip) {
    console.log("You may enter");
}
```

## Crash site 1: mixing `&&` and `||` without parentheses

```js
if (age >= 18 && hasTicket || isVip) {
    // meant: over 18 with a ticket, or a VIP
}
```

**Consequence:** even though the result happens to be right here, it is horrible to read. Other people -- and you, a week from now -- will not follow it. **Reach for parentheses whenever you mix conditions.**

## Crash site 2: writing a chained comparison without `&&`

```js
let score = 85;
if (60 <= score <= 100) {  // maths notation, but JS does not support it!
    console.log("Valid score");
}
```

**Consequence:** an error or a wrong result. JS does not allow that mathematical shortcut. The fix:

```js
if (score >= 60 && score <= 100) {
    console.log("Valid score");
}
```

## Summary

- `&&` (and): true only when both sides are true.
- `||` (or): true when either side is true.
- `!` (not): flips the value, true becomes false and false becomes true.
- `&&` and `||` short-circuit.
- **Use parentheses** when combining several conditions so your meaning is clear.
