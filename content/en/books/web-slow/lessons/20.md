# Array Methods: forEach / map / filter

> In lesson 13 we used a `for` loop to walk through an array. This lesson introduces three built-in array methods that do the same job with less code and better readability. We focus on building intuition first; the callback details will come later.

## forEach: it runs the loop for you

The old way, with a `for` loop:

```js
let fruits = ["apple", "banana", "orange"];

for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}
```

With `forEach` it becomes:

```js
fruits.forEach(function (item) {
    console.log(item);
});
```

**`forEach` means "run this function once for every element in the array."** You only say *what to do with each item*; it handles the looping itself.

`item` is the current element for that round — first `"apple"`, then `"banana"`, then `"orange"`.

## map: transform each item into a new array

`map` also visits every element, but it **collects each return value into a brand-new array** and gives it back:

```js
let nums = [1, 2, 3];

let doubled = nums.map(function (n) {
    return n * 2;
});

console.log(doubled);   // [2, 4, 6]
console.log(nums);      // [1, 2, 3] — the original array is untouched
```

**`map` is a one-to-one mapping: every element is transformed by a rule, producing a new array.** The original stays put.

Pulling out just the names from a list of students:

```js
let students = [
    { name: "Alice", score: 85 },
    { name: "Bob", score: 92 }
];

let names = students.map(function (s) {
    return s.name;
});

console.log(names);   // ["Alice", "Bob"]
```

## filter: keep only what passes the test

`filter` visits every element. You return `true` to say "keep it" or `false` to say "drop it":

```js
let scores = [55, 82, 97, 60, 43];

let passed = scores.filter(function (n) {
    return n >= 60;
});

console.log(passed);   // [82, 97, 60]
```

Keeping only the students who passed:

```js
let students = [
    { name: "Alice", score: 85 },
    { name: "Bob", score: 55 },
    { name: "Charlie", score: 92 }
];

let passed = students.filter(function (s) {
    return s.score >= 60;
});

console.log(passed);
// [{ name: "Alice", score: 85 }, { name: "Charlie", score: 92 }]
```

**`filter` never changes the original array; it only returns a new one.**

## Comparing the three

| Method | What it does | What it returns |
|---|---|---|
| forEach | runs once per element (to *do* something) | undefined |
| map | transforms each element | a new array |
| filter | keeps elements that pass a test | a new array |

**Which to pick:** just printing or updating external state → `forEach`; you want a transformed copy → `map`; you want a subset → `filter`.

## Crash site 1: expecting forEach to give you a new array

```js
let nums = [1, 2, 3];

let result = nums.forEach(function (n) {
    return n * 2;     // forEach ignores the return value
});

console.log(result);   // undefined, not [2, 4, 6]
```

**Consequence:** `result` is `undefined`. **If you need a new array, use `map`. `forEach` always returns `undefined`.**

## Crash site 2: forgetting `return` inside map

```js
let nums = [1, 2, 3];

let doubled = nums.map(function (n) {
    n * 2;            // calculated, but not returned
});

console.log(doubled);   // [undefined, undefined, undefined]
```

**Consequence:** the array has the right length but every item is `undefined`. **`map` must return the new value for each item, or you get nothing back.**

## Arrow functions (a quick preview)

For now we use the `function` syntax. Later you will meet the shorter arrow style. Just be aware it exists:

```js
// how we write it now
let doubled = nums.map(function (n) { return n * 2; });

// how you will see it later (much shorter)
let doubled = nums.map(n => n * 2);
```

**The meaning is exactly the same** — only the syntax differs. Master the `function` form first so arrow functions do not throw you off later.

## Summary

- `forEach` loops to *do* things; it returns nothing.
- `map` transforms each item and returns a new array.
- `filter` keeps elements by a true/false test and returns a new array.
- All three **leave the original array unchanged**.
- The easiest thing to forget is `return` inside `map` and `filter`.
