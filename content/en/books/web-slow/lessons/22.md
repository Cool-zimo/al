# Finding Elements: `querySelector` / `querySelectorAll`

> Last lesson we learned that `document` is the entry point. This lesson is about "how to find an element inside the DOM tree" — the prerequisite for every operation that follows.

## querySelector: find one by a CSS selector

```js
// find the element whose id is "title"
let title = document.querySelector("#title");

// find the element whose class is "active"
let active = document.querySelector(".active");

// find the first <p>
let firstP = document.querySelector("p");
```

**`querySelector(selector)` returns the first matching element.** It uses the same selector syntax you already know from writing CSS:

- `#theId` finds an id
- `.theClass` finds a class
- a tag name finds that tag

## id uses `#`, class uses `.` — do not swap them

```html
<h1 id="main">Title</h1>
<p class="intro">Introduction</p>
```

```js
document.querySelector("#main");     // ✓ finds the h1
document.querySelector("p.intro");   // ✓ finds the p
document.querySelector(".intro");    // ✓ also works
```

**The `#` and `.` are exactly the same as in CSS.** Forget them and you will not find anything:

```js
document.querySelector("main");   // ✗ this looks for a <main> tag, not id="main"
```

## querySelectorAll: find every match

```html
<p class="item">Apple</p>
<p class="item">Banana</p>
<p class="item">Orange</p>
```

```js
let items = document.querySelectorAll(".item");
console.log(items.length);   // 3

// you can loop over it like an array
for (let i = 0; i < items.length; i++) {
    console.log(items[i].textContent);
}
```

**`querySelectorAll` returns an "array-like" collection: it has `length` and supports indexing, but it is not a real array.** That is usually enough; when you need real array methods, wrap it with `Array.from(items)`.

## When nothing matches, it returns null

```js
let el = document.querySelector("#does-not-exist");
console.log(el);   // null
```

**When it finds nothing, `querySelector` returns `null` — not an error, and not `undefined`.** This detail matters, because it decides whether you can safely read a property on the result.

## Crash site 1: reading a property on an element you never found

```js
let el = document.querySelector("#does-not-exist");
console.log(el.textContent);   // error: Cannot read properties of null
```

Consequence: the browser throws an error and the code after it stops running. **Check whether the element exists before touching it:**

```js
let el = document.querySelector("#title");
if (el !== null) {
    el.textContent = "New title";
}
```

## Crash site 2: forgetting the `#` on an id selector

```js
document.querySelector("title");   // meant id="title", but this looks for a <title> tag
```

Consequence: returns `null`, because there is no `<title>` tag in the body to match (`<title>` lives in `<head>`, and is not the element you want anyway). **For an id you must write `#theId`; for a class you must write `.theClass`.**

## Combining selectors

```html
<div class="card">
  <p class="name">Alice</p>
  <p class="age">20</p>
</div>
<div class="card">
  <p class="name">Bob</p>
</div>
```

```js
// find the first .name inside a .card
let name = document.querySelector(".card .name");
console.log(name.textContent);   // "Alice"

// find every .name inside any .card
let names = document.querySelectorAll(".card .name");
```

**Selectors can be combined, nested, and listed with commas, just like in CSS.** If you can write the CSS selector, you can already find the element.

## Summary

- `querySelector(selector)` returns the first matching element.
- `querySelectorAll(selector)` returns a collection of every matching element.
- id uses `#`, class uses `.` — same as CSS.
- Nothing found means `null`; check before you read properties.

  function getFirstItem() {

- document.querySelector(".app")
