# Adding and Deleting: Add One, Remove One, and Re-render After Every Change

> Last lesson implemented render. This lesson finishes the two features "add" and "delete" — and now the whole to-do list runs. The core is just one sentence: **after changing the array, re-render.**

## Adding: push one item into the array

```js
function addTodo(text) {
    let todo = {
        id: Date.now(),     // use a timestamp as a unique id
        text: text,
        done: false
    };
    todos.push(todo);       // 1. change the array
    render();               // 2. re-render
}
```

**Two steps: push into the array, then call render.** The order cannot be reversed, and you cannot do only half of it.

## Bind an event to the button and read the input box

```js
addBtn.addEventListener("click", function () {
    let text = input.value;          // read the text in the input box

    if (text === "") return;         // do not add empty text

    addTodo(text);                   // add to the array and render
    input.value = "";                // clear the input box
});
```

**Type some text into the box → click the button → the text appears in the list. That is the complete "add" flow.**

## Deleting: remove from the array, then render

```js
function deleteTodo(id) {
    // keep every item whose id is NOT this one
    let newTodos = [];
    for (let i = 0; i < todos.length; i++) {
        if (todos[i].id !== id) {
            newTodos.push(todos[i]);
        }
    }
    todos = newTodos;   // 1. change the array
    render();           // 2. re-render
}
```

**Deleting is really "filtering": drop the item you do not want, and rebuild the array from what is left.**

With `filter` it takes one line:

```js
function deleteTodo(id) {
    todos = todos.filter(function (todo) {
        return todo.id !== id;
    });
    render();
}
```

## Binding events to the delete buttons while rendering

```js
function render() {
    list.innerHTML = "";

    todos.forEach(function (todo) {
        let li = document.createElement("li");

        let span = document.createElement("span");
        span.textContent = todo.text;
        li.appendChild(span);

        let delBtn = document.createElement("button");
        delBtn.textContent = "Delete";
        delBtn.addEventListener("click", function () {
            deleteTodo(todo.id);    // click delete → remove this item
        });
        li.appendChild(delBtn);

        list.appendChild(li);
    });
}
```

**The buttons are created dynamically inside render, so the events can only be bound inside render too.** Click → deleteTodo → render forms a complete loop.

## Crash site 1: changing the array but forgetting to re-render

```js
function addTodo(text) {
    todos.push({ id: Date.now(), text: text, done: false });
    // forgot to write render()
}
```

Consequence: the array does have the new data, but the page never moves. **This is the most common bug in the project. Remember: whenever you touch todos, you render.**

## Crash site 2: using splice to delete, but miscounting the index

```js
function deleteTodo(index) {
    todos.splice(index, 1);
    render();
}
// the index bound during rendering was the loop counter i at that moment
```

Problem: after `splice`, the array length changes, but the buttons on the page still remember the old index, so **deleting the second item may end up removing a different one.** Use an `id` instead of an index to identify items, and you avoid this trap.

## Identifying by id is safer than by index

```js
// recommended: identify by id
todos = todos.filter(function (t) { return t.id !== id; });

// not recommended: use the index, which goes out of sync after deletion
todos.splice(index, 1);
```

**An id is permanent and unique; an index is temporary and shifts.** In a list where items come and go, always identify by id.

## Summary

- Add: push → render. Delete: filter → render.
- **Whenever you change the array, render** — this is the first rule of the project.
- Delete by id, not by index, to avoid items shifting out of place.
- Bind events inside render; button click → change the data → render closes the loop.
