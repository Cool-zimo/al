# Changing an Array: Adding, Removing, and Editing

> This lesson answers the question: "How do I add things to an array, take things out, or change what is inside?" `push`, `pop`, and `splice` are the workhorses of array manipulation, and together with a loop they handle almost any list-based task.

## Adding to the end: `push`

`push` means "put a new item on the end of the array":

```js
let fruits = ["apple", "banana"];
fruits.push("orange");
console.log(fruits);  // ["apple", "banana", "orange"]
```

`push` is like a new person joining the back of a queue. After it runs, the array is one item longer.

```js
let numbers = [1, 2, 3];
numbers.push(4);
numbers.push(5);
console.log(numbers);  // [1, 2, 3, 4, 5]
```

## Taking from the end: `pop`

`pop` means "take the last item off the array and remove it":

```js
let fruits = ["apple", "banana", "orange"];
let last = fruits.pop();
console.log(last);     // "orange" (the item that was taken off)
console.log(fruits);   // ["apple", "banana"] (orange is gone)
```

`pop` does two things at once: it returns the last item, and it removes that item from the array.

> Memory trick: `push` is "push it in," `pop` is "pop it out."

## Removing or changing anywhere: `splice`

`splice` is more powerful — it can remove, insert, or replace items at any position. The most common use is removing:

```js
let fruits = ["apple", "banana", "orange", "grape"];
fruits.splice(1, 1);  // start at index 1, remove 1 item
console.log(fruits);   // ["apple", "orange", "grape"]
```

`splice(startIndex, deleteCount)`:

```js
let nums = [10, 20, 30, 40, 50];
nums.splice(2, 2);    // start at index 2, remove 2 items
console.log(nums);    // [10, 20, 50]
```

`splice` can also insert items:

```js
let fruits = ["apple", "orange"];
fruits.splice(1, 0, "banana");  // at index 1, remove 0, insert "banana"
console.log(fruits);  // ["apple", "banana", "orange"]
```

## Walking through an array: looking at every item

We covered looping in lesson 09. Here are a few common patterns.

**Pattern 1: print every item**

```js
let students = ["Alice", "Bob", "Charlie"];

for (let i = 0; i < students.length; i++) {
    console.log(students[i]);
}
```

**Pattern 2: transform each item into a new array**

```js
let numbers = [1, 2, 3, 4];
let doubled = [];

for (let i = 0; i < numbers.length; i++) {
    doubled.push(numbers[i] * 2);
}
console.log(doubled);  // [2, 4, 6, 8]
```

**Pattern 3: count how many items match a condition**

```js
let scores = [85, 92, 78, 96, 63];
let passCount = 0;

for (let i = 0; i < scores.length; i++) {
    if (scores[i] >= 60) {
        passCount++;
    }
}
console.log("Number who passed: " + passCount);  // "Number who passed: 5"
```

## Changing an item in an array

Just use the index with `=` to overwrite it:

```js
let fruits = ["apple", "banana", "orange"];
fruits[1] = "grape";  // replace whatever is at index 1 with "grape"
console.log(fruits);  // ["apple", "grape", "orange"]
```

It is like "open locker 1 and swap what is inside for grapes."

## Crash site 1: `push` does not return the new array

```js
let arr = [1, 2, 3];
let result = arr.push(4);
console.log(result);  // 4 (not [1,2,3,4]!)
```

**Consequence:** `push` returns the **new length** of the array (here, 4), not the array itself. If you want the updated array, just use `arr` directly.

## Crash site 2: changing the array while looping over it

```js
let arr = [1, 2, 3, 4, 5];
for (let i = 0; i < arr.length; i++) {
    arr.push(arr[i] * 10);  // adding items while looping!
}
console.log(arr);
// [1, 2, 3, 4, 5, 10, 20, 30, 40, 50] (the length keeps growing!)
```

**Consequence:** the array's length keeps changing as you loop, which can cause an infinite loop or just confusing behaviour. **Do not change the length of the array you are looping over.** If you need to modify, save the original length first or work on a copy.

## Summary

- `push(item)` adds to the end and returns the new length.
- `pop()` takes the last item off and returns it.
- `splice(index, count)` removes items starting at a given position.
- Change an item with `arr[index] = newValue`.
- The standard loop: `for (let i = 0; i < arr.length; i++)`.
- Avoid changing the array's length while looping over it.
