# Putting It All Together: A Class Roster

> This lesson ties together everything you have learned so far. You are going to build a small project: managing a class roster with arrays and objects — adding, listing, filtering, and counting.

## The goal

Build a little "class management" program with these features:

1. Store every student's information (an array of objects)
2. Print out the whole class list
3. Count how many students passed
4. Filter the students from a chosen city
5. Work out the class average score

## Step 1: the data structure

```js
let students = [
    { name: "Alice", age: 20, city: "London", score: 85 },
    { name: "Bob", age: 19, city: "Paris", score: 92 },
    { name: "Charlie", age: 21, city: "London", score: 78 },
    { name: "Diana", age: 20, city: "Berlin", score: 55 },
    { name: "Ethan", age: 22, city: "Paris", score: 96 }
];
```

Each student is an object; all the students together form an array. This is the "array of objects" pattern from lesson 14.

## Step 2: print the class list

```js
function printRoster(students) {
    console.log("===== Class Roster =====");
    for (let i = 0; i < students.length; i++) {
        let s = students[i];
        console.log((i + 1) + ". " + s.name + " | " + s.age + " yrs | " + s.city + " | score:" + s.score);
    }
}

printRoster(students);
```

Output:

```
===== Class Roster =====
1. Alice | 20 yrs | London | score:85
2. Bob | 19 yrs | Paris | score:92
3. Charlie | 21 yrs | London | score:78
4. Diana | 20 yrs | Berlin | score:55
5. Ethan | 22 yrs | Paris | score:96
```

**Uses:** a for loop, reading object properties, and string concatenation.

## Step 3: count the students who passed

```js
function countPass(students) {
    let passCount = 0;
    for (let i = 0; i < students.length; i++) {
        if (students[i].score >= 60) {
            passCount++;
        }
    }
    return passCount;
}

console.log("Passed: " + countPass(students));  // "Passed: 4"
```

**Uses:** a loop + an if check + a running counter.

## Step 4: filter by city

```js
function getStudentsByCity(students, city) {
    let result = [];
    for (let i = 0; i < students.length; i++) {
        if (students[i].city === city) {
            result.push(students[i]);
        }
    }
    return result;
}

let londoners = getStudentsByCity(students, "London");
console.log(londoners);
// [{ name: "Alice", age: 20, city: "London", score: 85 }, { name: "Charlie", age: 21, city: "London", score: 78 }]
```

**Uses:** a loop + a condition + pushing into a new array. This is the classic pattern from lesson 14.

## Step 5: work out the class average

```js
function calcAverage(students) {
    let total = 0;
    for (let i = 0; i < students.length; i++) {
        total = total + students[i].score;
    }
    let avg = total / students.length;
    return avg;
}

console.log("Class average: " + calcAverage(students));  // "Class average: 81.2"
```

**Uses:** a running total from a loop + division to get the average.

## All the code in one place

```js
    let count = 0;
    for (let i = 0; i < list.length; i++) {

    }

}

// filter by city
function getByCity(list, city) {
    let result = [];
    for (let i = 0; i < list.length; i++) {
        if (list[i].city === city) result.push(list[i]);
    }

// calculate the average

    }
    return total / list.length;
}
```

Those roughly 60 lines bring together **variables, arrays, objects, for loops, if checks, and functions** — everything from the first 14 lessons is right here.

## Crash site 1: using `<=` in the loop condition

```js
for (let i = 0; i <= students.length; i++) {
    console.log(students[i].name);  // on the last round i is 5, students[5] is undefined
}
```

**Consequence:** `students[5]` is `undefined`, and `undefined.name` crashes. **Remember: the condition is `< length`, never `<= length`.**

## Crash site 2: pushing into the array while looping over it

```js
for (let i = 0; i < students.length; i++) {
    students.push({ name: "Newcomer", score: 60 });  // the length keeps growing!
}
```

**Consequence:** the length keeps climbing, i can never catch up, and you get an infinite loop. **While looping, do not add items to the original array — build a new one for the results.**

## Summary

- An array of objects is the most common data shape you will meet in real projects.
- Loop + condition + counter (or new array) are the three core patterns.
- For counting, use a counter (`count++` / `total +=`); for filtering, push into a new array.
- Do not change the length of the array you are looping over.
