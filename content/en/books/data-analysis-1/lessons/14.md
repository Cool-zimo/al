# What on earth is axis

> NumPy's single most confusing idea. Grasp one sentence and it's clear forever: **axis is the dimension that gets collapsed**.

## The behaviour first

```python
import numpy as np

m = np.array([[1, 2, 3],
              [4, 5, 6]])

print(m.sum())          # 21      sum of everything
print(m.sum(axis=0))    # [5 7 9]  ← three numbers
print(m.sum(axis=1))    # [ 6 15]  ← two numbers
```

Why does axis=0 give three numbers and axis=1 give two?

## The core idea: axis is what disappears

`m` has shape `(2, 3)`:

- dimension 0 has length 2 (rows)
- dimension 1 has length 3 (columns)

**`axis=0` means "compute along dimension 0; afterwards that dimension is gone":**

```
input (2, 3)
      ↓ collapse along dimension 0 (across rows)
output (3,)       ← dimension 0 vanished, 3 remains
```

So you get each column's sum: `[1+4, 2+5, 3+6] = [5, 7, 9]`.

**`axis=1` collapses dimension 1:**

```
input (2, 3)
      ↓ collapse along dimension 1 (across columns)
output (2,)       ← dimension 1 vanished, 2 remains
```

So you get each row's sum: `[1+2+3, 4+5+6] = [6, 15]`.

## The mnemonic

> **`axis=n` makes dimension n disappear.**

To predict the result shape: **delete position n from the input shape.**

```
(2, 3)  sum(axis=0)  →  delete position 0  →  (3,)
(2, 3)  sum(axis=1)  →  delete position 1  →  (2,)
```

**It works backwards too:** if you want one number per row (result shape `(2,)`), dimension 1 must vanish, so use `axis=1`.

> 💡 Many people memorise "axis=0 means by row" — that's wrong, and it's the source of all the confusion. The correct statement: **axis=0 computes across rows, giving one result per column.**

## A 3-D example

```python
a = np.ones((2, 3, 4))    # shape (2, 3, 4)

print(a.sum(axis=0).shape)   # (3, 4)   position 0 deleted
print(a.sum(axis=1).shape)   # (2, 4)   position 1 deleted
print(a.sum(axis=2).shape)   # (2, 3)   position 2 deleted
```

**"Delete that position" holds in any number of dimensions.**

## keepdims: keep the collapsed dimension

Sometimes you want the same number of dimensions back (usually to broadcast afterwards):

```python
m = np.array([[1, 2, 3],
              [4, 5, 6]])

print(m.sum(axis=1))                 # [ 6 15]       shape (2,)
print(m.sum(axis=1, keepdims=True))  # [[ 6] [15]]   shape (2, 1)
```

```
[[ 6]
 [15]]
```

**`keepdims=True` keeps the vanished dimension as a 1.**

A perfect partner for broadcasting — remember the manual reshape from last chapter? keepdims removes it:

```python
# before: reshape by hand
row_mean = m.mean(axis=1).reshape(-1, 1)
centered = m - row_mean

# now: keepdims gives (2, 1) directly
centered = m - m.mean(axis=1, keepdims=True)
```

**Prefer keepdims=True wherever you're about to broadcast** — cleaner code, no reshape mistakes.

## Not just aggregations

Every function that works "along a direction" takes axis:

```python
m = np.array([[3, 1, 4],
              [1, 5, 9]])

print(np.sort(m, axis=1))         # sort within each row
print(np.argsort(m, axis=1))      # indices that sort each row
print(np.cumsum(m, axis=0))       # cumulative down the columns
print(np.argmax(m, axis=1))       # index of each row's maximum
```

**`argmax` with axis is especially handy:**

```python
# which subject is each student's strongest?
scores = np.array([[80, 90, 70],
                   [60, 75, 85]])
print(np.argmax(scores, axis=1))    # [1 2]  ← subject 1, subject 2
```

## A full example

```python
import numpy as np

# 3 students × 4 subjects
scores = np.array([[80, 90, 70, 85],
                   [60, 75, 80, 65],
                   [95, 88, 92, 90]])

print("mean per subject:", scores.mean(axis=0))    # 4 numbers (across students)
print("total per student:", scores.sum(axis=1))    # 3 numbers (across subjects)
print("class maximum:", scores.max())              # 1 number
print("each student's best:", scores.max(axis=1))  # 3 numbers
print("best subject index:", scores.argmax(axis=1))
```

Read them side by side and axis becomes obvious.

## Common mistakes

| What you want | Which axis |
|---|---|
| Each student's total (across subjects) | `axis=1` |
| Each subject's mean (across students) | `axis=0` |
| The average over every score | no axis |

**Check method:** look at the result's shape. Wanting 3 numbers (3 students) means the subject dimension must vanish — that's `axis=1`.
