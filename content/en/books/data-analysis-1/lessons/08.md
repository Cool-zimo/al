# Broadcasting

> NumPy's most powerful — and most confusing — feature.
> It does one thing: **lets arrays of different shapes compute together**.

## An operation that shouldn't work

```python
import numpy as np

arr = np.array([[1, 2, 3],
                [4, 5, 6]])      # shape (2, 3)

v = np.array([10, 20, 30])       # shape (3,)

print(arr + v)
```

Two arrays with different shapes, added successfully:

```
[[11 22 33]
 [14 25 36]]
```

What happened? **`v` was "copied" into two rows**, then added position by position:

```
[[1 2 3]      [[10 20 30]
 [4 5 6]]  +   [10 20 30]]   =  [[11 22 33]
                                 [14 25 36]]
```

That automatic copying is **broadcasting**.

> 💡 Key insight: **NumPy doesn't literally copy `v` twice in memory.** It only pretends to, reusing the same data during the calculation. So broadcasting is convenient *and* memory-free.

## The two rules

**Rule one: the shape with fewer dimensions gets 1s prepended.**

```
(3,)        →  (1, 3)
(2, 3)      →  (2, 3)   unchanged
```

**Rule two: align from the right; a dimension works if either**

- the two dimensions are **equal**, or
- one of them is **1** (that axis gets stretched)

Otherwise: error.

### Step by step

**Example 1: (2,3) + (3,)**

```
(2, 3)
(   3)   → prepend 1 → (1, 3)
           compare right to left: 3 vs 3 equal ✓; then 2 vs 1, one is 1 ✓
           result shape: (2, 3)
```

**Example 2: (2,3) + (2,1)**

```
(2, 3)
(2, 1)
compare: 3 vs 1 → one is 1, stretch to 3 ✓
         2 vs 2 equal ✓
result: (2, 3)
```

**Example 3: (2,3) + (2,)** ← this one fails!

```
(2, 3)
(   2)   → prepend 1 → (1, 2)
           compare: 3 vs 2 ← not equal, and neither is 1 ✗
           ValueError!
```

**The classic trap:** you have a 2×3 matrix and want to add a length-2 vector to each row, but it fails — because `(2,)` aligns to the **last** dimension (columns), not to rows as you assumed.

**The fix:** make it an explicit column, `(2, 1)`:

```python
v = np.array([10, 20])
print(v.shape)              # (2,)
print(v.reshape(-1, 1))     # becomes a (2, 1) column
print(arr + v.reshape(-1, 1))
```

## Three common cases

### Case one: a scalar (simplest)

```python
arr = np.array([1, 2, 3])
print(arr + 100)      # [101 102 103]
```

A scalar's shape is `()`, prepended to `(1,)`, then stretched to `(3,)`.

### Case two: row vector × matrix

```python
m = np.array([[1, 2, 3],
              [4, 5, 6]])      # (2, 3)
row = np.array([10, 20, 30])   # (3,) → (1, 3) → (2, 3)

print(m + row)
# each column gets its own offset
```

### Case three: column vector × matrix

```python
col = np.array([[10],
                [20]])           # (2, 1) → (2, 3)

print(m + col)
# each row gets its own offset
```

**Note the difference between `(3,)` and `(2,1)`:** the first broadcasts across columns, the second across rows. Be clear about which direction you want.

## Adding a dimension with np.newaxis

You can insert a dimension without reshape:

```python
v = np.array([10, 20, 30])

print(v.shape)                  # (3,)
print(v[np.newaxis, :].shape)   # (1, 3)  ← makes a row
print(v[:, np.newaxis].shape)   # (3, 1)  ← makes a column
```

`np.newaxis` is simply an alias for `None`, so this works too:

```python
print(v[None, :].shape)     # (1, 3)
print(v[:, None].shape)     # (3, 1)
```

Identical results; `np.newaxis` reads better.

## Why broadcasting matters: one less loop

**Task:** a 3×4 score table, one row per student. Find each student's difference from the class average.

Without broadcasting:

```python
scores = np.array([[80, 90, 70, 85],
                   [60, 75, 80, 65],
                   [95, 88, 92, 90]])

class_mean = scores.mean(axis=0)     # mean per column, shape (4,)

result = np.zeros_like(scores)
for i in range(scores.shape[0]):
    result[i] = scores[i] - class_mean
```

With broadcasting:

```python
result = scores - class_mean     # one line
```

`(3, 4) - (4,)` → `(4,)` becomes `(1, 4)` → stretched to `(3, 4)`. Every row loses the same per-column mean.

## When broadcasting bites

Broadcasting is **silent** — if it can, it does, without asking "are you sure?".

So a wrong shape often produces not an error but a **legal yet bizarre result**:

```python
a = np.array([[1, 2, 3]])     # (1, 3)
b = np.array([[1], [2]])      # (2, 1)
print((a + b).shape)          # (2, 3)  ← legal, but maybe not what you meant
```

If you wanted element-wise addition, this answer is wrong — and nothing complains.

> 💡 Habit: **print `result.shape` immediately after any broadcast.** That single habit blocks most broadcasting bugs.
