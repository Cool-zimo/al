# Universal functions (ufuncs)

> NumPy has a large family of functions with exactly one job: **take an array, do the same thing to every element, return a new array**. They're called ufuncs.

## What a ufunc is

**ufunc = universal function.** Its traits:

1. Element-wise
2. Output shape equals input shape
3. Implemented in C underneath, so fast

```python
import numpy as np
arr = np.array([1, 4, 9, 16])

print(np.sqrt(arr))     # [1. 2. 3. 4.]   shape still (4,)
```

You've been using ufuncs already — `arr + 10` and `arr * 2` from the last chapter are ufuncs underneath (`np.add`, `np.multiply`).

## Maths

```python
arr = np.array([1, 4, 9, 16])

print(np.sqrt(arr))      # [1. 2. 3. 4.]      square root
print(np.square(arr))    # [  1  16  81 256]  square
print(np.exp(arr))       # e to the power x
print(np.log(arr))       # natural log
print(np.log10(arr))     # log base 10
print(np.abs(arr))       # absolute value
print(np.round(arr))     # rounding
```

**Practical note:** `arr ** 0.5` equals `np.sqrt(arr)`, but `np.sqrt` reads better and is usually slightly faster.

## Trigonometry (radians, not degrees)

```python
import numpy as np

angles = np.array([0, 30, 45, 90])
radians = np.deg2rad(angles)      # degrees → radians

print(radians)
print(np.sin(radians))            # [0.  0.5 0.707 1. ]
print(np.cos(radians))
```

> ⚠️ **NumPy only speaks radians.** `np.sin(90)` gives 0.894, not 1. Convert first with `np.deg2rad`, or multiply by `np.pi / 180`.

## The rounding family

```python
arr = np.array([1.2, 2.7, -1.5, 3.5])

print(np.floor(arr))     # [ 1.  2. -2.  3.]  round down
print(np.ceil(arr))      # [ 2.  3. -1.  4.]  round up
print(np.round(arr))     # [ 1.  3. -2.  4.]  round to nearest
print(np.trunc(arr))     # [ 1.  2. -1.  3.]  drop the fraction
```

Watch the negatives: `floor(-1.5)` is `-2` (towards smaller), `trunc(-1.5)` is `-1` (towards zero).

## Between two arrays: maximum / minimum

```python
a = np.array([1, 5, 3])
b = np.array([2, 2, 9])

print(np.maximum(a, b))    # [2 5 9]  ← larger at each position
print(np.minimum(a, b))    # [1 2 3]  ← smaller at each position
```

**Don't confuse them with `np.max` / `np.min`:**

| Function | Does | Result |
|---|---|---|
| `np.max(a)` | find the single largest value in a | scalar |
| `np.maximum(a, b)` | compare position by position | array |

Mnemonic: **the one with "mum" compares element-wise; the one without aggregates.**

## Comparisons are ufuncs too

```python
arr = np.array([1, 5, 3, 8])

print(arr > 3)              # [False  True False  True]
print(np.greater(arr, 3))   # the same, written out
```

Comparison operators (`>` `>=` `<` `<=` `==` `!=`) are ufuncs, which is why they return boolean arrays.

Boolean arrays support logic — but **not Python's `and` / `or`**:

```python
mask1 = arr > 2
mask2 = arr < 8

# ❌ error: and/or work on single booleans only
print(mask1 and mask2)

# ✅ use & and |
print(mask1 & mask2)        # both
print(mask1 | mask2)        # either
print(~mask1)               # not
```

> ⚠️ `&` and `|` bind tighter than comparisons, so bracket your conditions:
> ```python
> print((arr > 2) & (arr < 8))    # brackets required
> ```

## np.where, deeper

An extension of the same idea — **choose between sources based on a condition**:

```python
scores = np.array([45, 78, 92, 55])
print(np.where(scores >= 60, scores, 0))    # [ 0 78 92  0]
```

The second and third arguments can be arrays:

```python
a = np.array([1, 2, 3])
b = np.array([10, 20, 30])
cond = np.array([True, False, True])
print(np.where(cond, a, b))     # [ 1 20  3]  ← True takes a, False takes b
```

And there's a handy variant, `np.clip`, for clamping to a range:

```python
arr = np.array([-5, 3, 12, 8])
print(np.clip(arr, 0, 10))      # [ 0  3 10  8]
```

One line replacing a three-branch if/elif/else.

## Cumulative functions (not ufuncs, but often nearby)

```python
arr = np.array([1, 2, 3, 4])

print(np.cumsum(arr))      # [ 1  3  6 10]  running total
print(np.cumprod(arr))     # [ 1  2  6 24]  running product
print(np.diff(arr))        # [1 1 1]        differences between neighbours
```

`np.diff` is ideal for "change since yesterday".

## Quick reference

| Category | Functions |
|---|---|
| roots / powers | `sqrt` `square` |
| exp / log | `exp` `log` `log10` |
| rounding | `floor` `ceil` `round` `trunc` |
| magnitude / sign | `abs` `sign` |
| trig | `sin` `cos` `tan` `deg2rad` |
| element-wise compare | `maximum` `minimum` `clip` |
| conditional pick | `where` |
| cumulative | `cumsum` `cumprod` `diff` |
