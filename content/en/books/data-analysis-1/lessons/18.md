# Repeating and tiling

> `repeat` and `tile` both make arrays bigger, in completely different ways. A classic pair that trips people up.

## repeat: copy element by element

**Each element is duplicated N times:**

```python
import numpy as np

arr = np.array([1, 2, 3])
print(np.repeat(arr, 2))
```

```
[1 1 2 2 3 3]
```

As if each element were stretched: `1,2,3` → `1,1,2,2,3,3`.

**You can give each element its own count:**

```python
arr = np.array([1, 2, 3])
print(np.repeat(arr, [3, 1, 2]))    # 1 three times, 2 once, 3 twice
```

```
[1 1 1 2 3 3]
```

**The counts array must match the length of the input**, or you get an error.

### repeat on 2-D

```python
m = np.array([[1, 2],
              [3, 4]])

print(np.repeat(m, 2, axis=1))   # repeat across columns
```

```
[[1 1 2 2]
 [3 3 4 4]]
```

Without axis it flattens first:

```python
print(np.repeat(m, 2))    # [1 1 2 2 3 3 4 4]  1-D
```

## tile: copy the whole block

**Treat the array as one brick and lay it N times:**

```python
arr = np.array([1, 2])
print(np.tile(arr, 3))
```

```
[1 2 1 2 1 2]
```

Compare, with the same input `[1, 2]`:

| Function | Result | Mental model |
|---|---|---|
| `repeat(arr, 3)` | `[1 1 1 2 2 2]` | each element stretched |
| `tile(arr, 3)` | `[1 2 1 2 1 2]` | the whole block copied 3× |

**Mnemonic:** `repeat` works per element; `tile` works per array.

### tile on 2-D

The second argument is a tuple: "how many times down, how many across".

```python
m = np.array([[1, 2],
              [3, 4]])

print(np.tile(m, (2, 1)))    # twice down, once across
```

```
[[1 2]
 [3 4]
 [1 2]
 [3 4]]
```

```python
print(np.tile(m, (1, 3)))    # once down, three times across
```

```
[[1 2 1 2 1 2]
 [3 4 3 4 3 4]]
```

## Typical uses

### tile: building a backdrop

```python
# subtract the same baseline from every row
data = np.array([[10, 20, 30],
                 [40, 50, 60]])
baseline = np.array([1, 2, 3])

print(data - np.tile(baseline, (2, 1)))
```

Except — **broadcasting does the same thing and costs no memory:**

```python
print(data - baseline)     # preferred
```

> 💡 Rule: **prefer broadcasting over tile.** `tile` really copies; `data - baseline` doesn't. On large data that difference is significant.

### repeat: expanding by weight

```python
# units sold per product; expand into individual records
counts = np.array([2, 0, 3])      # products sold 2, 0 and 3 units
product_ids = np.repeat(np.array([0, 1, 2]), counts)
print(product_ids)                # [0 0 2 2 2]
```

A genuinely useful move when unnesting aggregated data.

## Another way to repeat: concatenate with a list

For "copy the whole thing N times" while staying multi-dimensional:

```python
arr = np.array([[1, 2]])
print(np.concatenate([arr] * 3, axis=0))
```

```
[[1 2]
 [1 2]
 [1 2]]
```

`[arr] * 3` is Python list repetition (it stores three references to the same array, which is fine because concatenate only reads).

## Quick reference

| Need | Use |
|---|---|
| Each element N times | `np.repeat(arr, N)` |
| Per-element counts | `np.repeat(arr, [n1, n2, ...])` |
| Whole array N times | `np.tile(arr, N)` |
| 2-D tiling by row/column | `np.tile(arr, (rows, cols))` |
| Match a small array to a big one | **broadcast first**, not tile |
