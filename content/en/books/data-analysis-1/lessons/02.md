# Six ways to create an array

> Typing `np.array([1,2,3])` by hand is only the start. In practice you far more often need to conjure a pile of numbers out of nothing.

## First, the convention

Everyone writing NumPy in the world starts with this line:

```python
import numpy as np
```

**Why the `np` alias?** Nothing forces it, but it's the convention. Code you read and answers you find will almost all say `np.`. Follow it and your code stays legible to others.

Every snippet in this course assumes that line is present.

## 1. From a list: np.array()

The basic one:

```python
arr = np.array([1, 2, 3, 4, 5])
print(arr)        # [1 2 3 4 5]
```

A nested list becomes 2-D:

```python
matrix = np.array([[1, 2, 3],
                   [4, 5, 6]])
print(matrix)
print(matrix.shape)    # (2, 3)  ← 2 rows, 3 columns
```

Mind the **outer brackets**, and every row must have the same length — otherwise you get an odd dtype (object) or an error.

## 2. All zeros: np.zeros()

```python
print(np.zeros(5))           # [0. 0. 0. 0. 0.]
print(np.zeros((2, 3)))      # 2 rows, 3 columns of zeros
```

**The argument is a tuple**: `np.zeros((2, 3))`, with double brackets. Writing `np.zeros(2, 3)` errors, because NumPy reads 3 as the dtype argument.

This is one of the most common beginner mistakes. Remember: **shapes are always passed as tuples, so double brackets.**

The default is float (hence `0.`). For integers:

```python
print(np.zeros(5, dtype=int))    # [0 0 0 0 0]
```

**Typical use:** reserve a block of space, fill it later.

## 3. All ones: np.ones()

```python
print(np.ones(4))          # [1. 1. 1. 1.]
print(np.ones((3, 2)))     # 3 rows, 2 columns
```

And the variant `np.full()`, filling with any value:

```python
print(np.full(4, 7))       # [7 7 7 7]
```

## 4. Even steps: np.arange()

**The one most like `range()`**:

```python
print(np.arange(5))        # [0 1 2 3 4]
print(np.arange(2, 8))     # [2 3 4 5 6 7]    starts at 2, excludes 8
print(np.arange(0, 10, 2)) # [0 2 4 6 8]      step 2
```

**Like `range()`: includes the start, excludes the stop.**

One difference — `arange` accepts a fractional step, `range` doesn't:

```python
print(np.arange(0, 1, 0.2))    # [0.  0.2 0.4 0.6 0.8]
```

> ⚠️ Be careful with fractional steps and floating point. How many values `np.arange(0, 1, 0.1)` produces may surprise you. When the exact count matters, use `linspace`.

## 5. Evenly divided: np.linspace()

**"Split the range from a to b into n values"**:

```python
print(np.linspace(0, 1, 5))     # [0.   0.25 0.5  0.75 1.  ]
print(np.linspace(0, 10, 6))    # [ 0.  2.  4.  6.  8. 10.]
```

**The key difference: `linspace` includes the endpoint; `arange` doesn't.**

| | Arguments mean | Includes the end? |
|---|---|---|
| `arange(start, stop, step)` | step size | ❌ no |
| `linspace(start, stop, num)` | count of values | ✅ yes |

**Use linspace when plotting.** For a sine curve with 100 points on the x-axis:

```python
x = np.linspace(0, 6.28, 100)
```

## 6. Random numbers

Data analysis uses randomness constantly (simulating data, sampling, initialising).

```python
# random floats between 0 and 1
print(np.random.random(5))

# standard normal distribution (mean 0, std 1)
print(np.random.randn(5))

# random integers: 5 values from 1 to 100 (101 excluded)
print(np.random.randint(1, 101, 5))
```

> 💡 **Reproducibility matters:** when experimenting you want the same numbers every run, otherwise debugging is impossible. Set a seed with `np.random.seed()`:
> ```python
> np.random.seed(42)
> print(np.random.randn(3))    # identical every run
> ```
> Any seed value works (42 is a programmer's in-joke); what matters is that **the same seed gives the same sequence**.

## Two special matrices

```python
# identity matrix (ones on the diagonal)
print(np.eye(3))

# diagonal matrix
print(np.diag([1, 2, 3]))
```

Used in linear algebra, occasionally in data work.

## Quick reference

| Function | Does |
|---|---|
| `np.array(list)` | convert from a list |
| `np.zeros(n)` | all zeros |
| `np.ones(n)` | all ones |
| `np.full(n, v)` | all v |
| `np.arange(a, b, s)` | even steps (excludes end) |
| `np.linspace(a, b, n)` | even split (includes end) |
| `np.random.random(n)` | random 0–1 |
| `np.random.randn(n)` | random normal |
| `np.random.randint(a, b, n)` | random integers |
| `np.eye(n)` | identity matrix |
