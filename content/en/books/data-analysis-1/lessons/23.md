# Real CSVs: genfromtxt

> `loadtxt` breaks on an empty field. Real data almost always has gaps, so `genfromtxt` is the one you'll reach for.

## Where loadtxt breaks

A file like this (one value missing on line 2):

```
1,2
3,
5,6
```

```python
np.loadtxt('miss.csv', delimiter=',')
# ValueError: could not convert string to float: ''
```

**genfromtxt copes:**

```python
data = np.genfromtxt('miss.csv', delimiter=',')
print(data)
```

```
[[ 1.  2.]
 [ 3. nan]
 [ 5.  6.]]
```

**Empty fields become `nan` automatically** — exactly the missing-value representation from earlier chapters, so `nanmean` and friends work directly on it.

## Basic use

```python
import numpy as np

data = np.genfromtxt('data.csv', delimiter=',', skip_header=1)
```

The argument names differ slightly from loadtxt (a genuine trap):

| loadtxt | genfromtxt | Does |
|---|---|---|
| `skiprows` | `skip_header` | skip lines at the top |
| — | `skip_footer` | skip lines at the bottom |
| `dtype` | `dtype` | set the type |
| `usecols` | `usecols` | read only some columns |
| — | `names` | treat row 1 as column names |
| — | `filling_values` | what to put in gaps |

> ⚠️ **`skiprows` versus `skip_header`.** genfromtxt accepts `skiprows` as an alias, but to avoid confusion always write `skip_header`.

## Reading with column names

If the first line is a header:

```
lang,maths,english
80,90,70
60,75,85
```

```python
data = np.genfromtxt('scores.csv', delimiter=',', names=True)
print(data)
print(data['lang'])      # fetch by name
```

```
[(80., 90., 70.) (60., 75., 85.)]
[80. 60.]
```

**`names=True` makes the first row the column names**, so you can use `data['lang']` dictionary-style.

What comes back is a **structured array** — it prints as parenthesised rows. It behaves like "one record per row", but it doesn't behave like a normal 2-D array, which confuses people.

> 💡 Recommendation: **skip `names=True` while you're learning.** Use `skip_header=1` to get an ordinary 2-D array and take columns by position with `data[:, 0]`, `data[:, 1]` — far more predictable. Once you meet pandas, its column handling is much nicer (that's book 2).

## Filling missing values

Sometimes you don't want nan — you want a default:

```python
data = np.genfromtxt('miss.csv', delimiter=',', filling_values=0)
print(data)
```

```
[[1. 2.]
 [3. 0.]
 [5. 6.]]
```

**`filling_values=0` fills every gap with 0.**

You can fill per column:

```python
data = np.genfromtxt('miss.csv', delimiter=',', filling_values=(0, -1))
```

(column 0 gaps become 0, column 1 gaps become -1.)

**Note:** if you want "fill with that column's mean", genfromtxt can't do it — you fill after loading:

```python
data = np.genfromtxt('miss.csv', delimiter=',')
col_mean = np.nanmean(data, axis=0)
inds = np.where(np.isnan(data))
data[inds] = np.take(col_mean, inds[1])
```

Worth memorising — **`np.where` locates the nans, `np.take` fetches the matching column mean.**

## Mixed types

Real CSVs often look like this:

```
London,80,90
Paris,75,88
```

Text in column one, numbers after. **NumPy handles this awkwardly** — it wants one type throughout.

You can force it:

```python
data = np.genfromtxt('mixed.csv', delimiter=',', dtype=str, encoding='utf-8')
print(data)
```

```
[['London' '80' '90']
 ['Paris' '75' '88']]
```

But **the numbers are now text** and you must convert them:

```python
nums = data[:, 1:].astype(float)
print(nums)
```

> 💡 **This is where NumPy ends.** The moment your data has a text column alongside numeric ones, reach for pandas — it supports a different type per column natively. That's exactly why book 2 exists.

## A full realistic pass

```python
import numpy as np

# 1. read (skip the header; gaps become nan)
data = np.genfromtxt('scores.csv', delimiter=',', skip_header=1)

# 2. see how much is missing
print("missing cells:", np.sum(np.isnan(data)))

# 3. fill with the column means
col_mean = np.nanmean(data, axis=0)
inds = np.where(np.isnan(data))
if len(inds[0]):
    data[inds] = np.take(col_mean, inds[1])

# 4. carry on as normal
print("column means:", data.mean(axis=0))
print("column stds:", data.std(axis=0))
```

**"load → count gaps → fill with means → analyse"** — the standard four steps for real data.

## Which one

| Data looks like | Use |
|---|---|
| All numeric, no gaps | `np.loadtxt` (faster) |
| Has missing values | `np.genfromtxt` |
| Need to skip trailing lines | `np.genfromtxt` (has skip_footer) |
| Text columns + numeric columns | **pandas** (NumPy isn't the tool) |
