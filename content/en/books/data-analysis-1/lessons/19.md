# Sorting and ranking

> `sort` gives you sorted values; `argsort` gives you sorted **indices**. The latter is the one you'll actually use.

## sort: the sorted values

```python
import numpy as np

arr = np.array([3, 1, 4, 1, 5])
print(np.sort(arr))     # [1 1 3 4 5]
```

**Ascending by default.** It returns a **new array**; the original is untouched:

```python
print(arr)              # [3 1 4 1 5]  ← unchanged
arr.sort()              # the method sorts in place
print(arr)              # [1 1 3 4 5]  ← changed
```

As always: **the function returns a new array, the method modifies in place.**

## argsort: the sorted indices

**The more useful one:**

```python
arr = np.array([3, 1, 4, 1, 5])
print(np.argsort(arr))    # [1 3 0 2 4]
```

Meaning "the smallest sits at index 1, the next at index 3, the next at index 0…"

Check it:

```python
idx = np.argsort(arr)
print(arr[idx])          # [1 1 3 4 5]  ← indexing by it sorts the array
```

**`arr[np.argsort(arr)]` equals `np.sort(arr)`**, but argsort's real value is that it tells you *who* came first.

### Descending

argsort only ascends; reverse it to descend:

```python
print(np.argsort(arr)[::-1])    # [4 2 0 3 1]  largest first
```

**`np.argsort(x)[::-1]` is the standard "largest first" idiom.** Worth memorising.

### Top-N

```python
scores = np.array([50, 80, 90, 60])

top2 = np.argsort(scores)[::-1][:2]
print(top2)               # [2 1]   the two highest scorers
print(scores[top2])       # [90 80]
```

## Sorting 2-D

```python
m = np.array([[3, 1, 4],
              [2, 5, 0]])

print(np.sort(m, axis=1))     # sort within each row
```

```
[[1 3 4]
 [0 2 5]]
```

```python
print(np.sort(m, axis=0))     # sort within each column
```

```
[[2 1 0]
 [3 5 4]]
```

**The axis rule is unchanged:** `axis=1` computes across columns — here, sorting inside each row.

## Sorting by one column (the useful one)

**Task:** a score table you want ordered by maths, with each student's whole row following along.

```python
scores = np.array([[80, 90],      # student 0: lang 80, maths 90
                   [95, 70],      # student 1: lang 95, maths 70
                   [88, 85]])     # student 2: lang 88, maths 85

# sort by maths (column 1)
order = np.argsort(scores[:, 1])
print(order)              # [1 2 0]   maths 70 < 85 < 90
print(scores[order])      # whole rows reorder together
```

```
[[95 70]
 [88 85]
 [80 90]]
```

**That's the standard "sort a whole table by one column" recipe:**

1. Take that column: `scores[:, 1]`
2. `argsort` it to get the order
3. Index the whole 2-D array with that order

### Descending version

```python
order = np.argsort(scores[:, 1])[::-1]
print(scores[order])
```

## Sorting by several columns

For "maths first, then language as a tie-break", use `np.lexsort`:

```python
scores = np.array([[80, 90],
                   [95, 90],    # maths 90 as well
                   [88, 85]])

# with lexsort the LAST key is the primary one
order = np.lexsort((scores[:, 0], scores[:, 1]))   # lang first, maths primary
print(scores[order])
```

> ⚠️ **`np.lexsort` takes its keys in reverse priority**: the last array is the primary key. Counter-intuitive, so test it once.

If that bothers you, sort twice using a stable sort:

```python
order = np.argsort(scores[:, 0], kind='stable')      # sort by language first
tmp = scores[order]
order2 = np.argsort(tmp[:, 1], kind='stable')        # then by maths, stably
print(tmp[order2])
```

`kind='stable'` keeps equal elements in their existing relative order — that's what makes repeated sorting work.

## Ranks (1st, 2nd, 3rd…)

```python
scores = np.array([50, 80, 90, 60])

order = np.argsort(scores)[::-1]     # [2 1 3 0]  indices, highest first
ranks = np.empty_like(order)
ranks[order] = np.arange(len(scores)) + 1
print(ranks)      # [4 2 1 3]  index 0 is 4th, index 1 is 2nd...
```

Slightly brain-bending, so: `order[0]` is the index of 1st place, therefore `ranks[index of 1st place] = 1`.

## Quick reference

| Need | Write |
|---|---|
| sorted values | `np.sort(arr)` |
| sorted indices | `np.argsort(arr)` |
| descending indices | `np.argsort(arr)[::-1]` |
| top-N indices | `np.argsort(arr)[::-1][:N]` |
| sort a table by a column | `tbl[np.argsort(tbl[:, col])]` |
| multi-column sort | `np.lexsort((secondary, primary))` |
