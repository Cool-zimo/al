# Joining arrays

> Combining several arrays into one. Sounds simple, but "which direction" is surprisingly easy to get backwards.

## concatenate: the basic one

```python
import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5])

print(np.concatenate([a, b]))     # [1 2 3 4 5]
```

Note the argument is **a list** holding the arrays: `np.concatenate([a, b])`, not `np.concatenate(a, b)`.

### With 2-D you must name the axis

```python
m1 = np.array([[1, 2],
               [3, 4]])      # (2, 2)
m2 = np.array([[5, 6]])      # (1, 2)

print(np.concatenate([m1, m2], axis=0))
```

```
[[1 2]
 [3 4]
 [5 6]]
```

**`axis=0` means stack downwards (more rows).**

```python
m3 = np.array([[7], [8]])    # (2, 1)
print(np.concatenate([m1, m3], axis=1))
```

```
[[1 2 7]
 [3 4 8]]
```

**`axis=1` means join sideways (more columns).**

### The iron rule: every other dimension must match

```python
np.concatenate([m1, np.array([[1, 2, 3]])], axis=0)
# ValueError: all the input array dimensions except for the concatenation axis must match exactly
```

**Reading that error:** print every array's shape and compare everything *except* the axis you're joining along.

## vstack and hstack: no axis to remember

Plenty of people can't recall whether axis=0 is vertical or horizontal, so NumPy offers two self-describing helpers:

```python
a = np.array([1, 2])
b = np.array([3, 4])

print(np.vstack([a, b]))     # vertical: stack into rows
print(np.hstack([a, b]))     # horizontal: join along the row
```

```
vstack: [[1 2]
         [3 4]]

hstack: [1 2 3 4]
```

**Mnemonic:** `v` = vertical, `h` = horizontal.

| Function | Equivalent | Does |
|---|---|---|
| `np.vstack([a, b])` | `concatenate([a, b], axis=0)` | stack downwards, more rows |
| `np.hstack([a, b])` | `concatenate([a, b], axis=1)` | join sideways, more columns |

**vstack has a helpful quirk:** for 1-D inputs it first promotes each to "one row", then stacks. So two length-2 arrays become `(2, 2)`. Plain `concatenate(..., axis=0)` would just give `(4,)`.

## column_stack: turn two 1-D arrays into two columns

```python
ids = np.array([1, 2])
ages = np.array([3, 4])

print(np.column_stack([ids, ages]))
```

```
[[1 3]
 [2 4]]
```

**This is the standard way to build a table from separate measurements.** Height array plus weight array into an `(n, 2)` table — `column_stack` says it best.

Versus `hstack`: on 1-D input, `hstack` produces a longer 1-D array while `column_stack` makes each input a column.

```python
print(np.hstack([ids, ages]))        # [1 2 3 4]      1-D
print(np.column_stack([ids, ages]))  # [[1 3] [2 4]]  2-D
```

## In practice: adding a column to a table

**Task:** a score table has 3 subjects; add a "total" column.

```python
scores = np.array([[80, 90, 70],
                   [60, 75, 85]])      # (2, 3)

totals = scores.sum(axis=1, keepdims=True)   # (2, 1) — keepdims is essential
print(totals)

full = np.hstack([scores, totals])
print(full)
```

```
[[ 80  90  70 240]
 [ 60  75  85 220]]
```

**`keepdims=True` is required here.** With plain `scores.sum(axis=1)` you get `(2,)`, and hstack would splice it into a 1-D result with the wrong shape.

## Which to use

| Situation | Use |
|---|---|
| You want to say "stack down / join across" plainly | `vstack` / `hstack` |
| Working with 3+ dimensions | `concatenate` + axis |
| Building a table from several 1-D arrays | `column_stack` |
| Joining many at once (a list of a dozen) | `concatenate` |
