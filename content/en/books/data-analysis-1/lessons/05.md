# Lists vs arrays

> Both hold a pile of numbers. How do you choose? This lesson gives a workable rule — and runs a real speed test.

## Converting between them

```python
import numpy as np

# list → array
lst = [1, 2, 3, 4, 5]
arr = np.array(lst)
print(arr, type(arr))     # [1 2 3 4 5] <class 'numpy.ndarray'>

# array → list
back = arr.tolist()
print(back, type(back))   # [1, 2, 3, 4, 5] <class 'list'>
```

**`tolist()` recurses** — a 2-D array becomes nested lists:

```python
m = np.array([[1, 2], [3, 4]])
print(m.tolist())     # [[1, 2], [3, 4]]
```

**When do you need to go back to a list?**

- When you need frequent `append` / `insert`
- When saving to JSON (NumPy arrays aren't serialisable directly)
- When handing data to a library that only accepts lists

## Measure it yourself

Here's a reproducible comparison. Run it in the box below:

```python
import numpy as np
import time

n = 500_000
data = list(range(n))
arr = np.array(data)

# list: loop
t0 = time.time()
s1 = 0
for x in data:
    s1 += x
t1 = time.time()

# array: vectorised
s2 = np.sum(arr)
t2 = time.time()

print(f"same result: {s1 == s2}")
print(f"list loop: {(t1 - t0) * 1000:.2f} ms")
print(f"array sum: {(t2 - t1) * 1000:.2f} ms")
```

The array wins by an order of magnitude.

**But note:** that gap only shows up for **bulk operations on large data**.

## The counter-case: arrays lose too

Try adding elements one at a time:

```python
import numpy as np
import time

n = 50_000

t0 = time.time()
lst = []
for i in range(n):
    lst.append(i)
t1 = time.time()

arr = np.array([])
for i in range(n):
    arr = np.append(arr, i)
t2 = time.time()

print(f"list append: {(t1 - t0) * 1000:.1f} ms")
print(f"array append: {(t2 - t1) * 1000:.1f} ms")
```

The array is dramatically slower — possibly tens of times.

**Why?** `np.append` doesn't extend the existing storage; it **builds a new, larger array, copies everything across, then adds the item**. Doing that 50,000 times means rebuilding 50,000 times.

> 💡 Remember: **arrays suit "build once, compute often", not "grow as you go".** When collecting dynamically, gather in a list and convert once at the end.

```python
# the right way
rows = []
for i in range(1000):
    rows.append(compute(i))     # collect in a list
arr = np.array(rows)            # convert once
```

## Decision table

| What you need | Use |
|---|---|
| Doing maths (arithmetic, statistics) | **array** |
| Large data (tens of thousands+) | **array** |
| Frequent insert / delete | **list** |
| Mixed types | **list** |
| A handful of values, casually | **list** |
| Saving to JSON / passing to a library | **list** |
| Matrix maths, plotting | **array** |

In one line: **compute with arrays, store with lists.**

## Arrays work as containers too

Arrays support most list operations:

```python
arr = np.array([10, 20, 30, 40, 50])

print(arr[0])          # 10      index
print(arr[-1])         # 50      negative index
print(arr[1:3])        # [20 30] slice
print(len(arr))        # 5       length
print(30 in arr)       # True    membership
```

But two important differences:

**1. A slice is a view, not a copy.**

```python
arr = np.array([1, 2, 3, 4, 5])
part = arr[1:3]
part[0] = 99
print(arr)      # [1 99 3 4 5]  ← the original changed!
```

A list slice copies; an array slice just opens a window onto the same data. This is one of NumPy's biggest traps, and chapter 3 covers it properly.

**2. Arrays have no append.**

As covered above — `np.append` is create-and-copy, and it's expensive.

## Memory comparison

See it directly:

```python
import numpy as np
import sys

n = 100_000
lst = list(range(n))
arr = np.arange(n)

# list: the container plus every int object
list_bytes = sys.getsizeof(lst) + sum(sys.getsizeof(x) for x in lst)
arr_bytes = arr.nbytes

print(f"list: {list_bytes / 1024 / 1024:.1f} MB")
print(f"array: {arr_bytes / 1024 / 1024:.1f} MB")
```

Typically the list takes several times more.

**`arr.nbytes`** is the array's byte count — handy when chasing memory problems.

## A realistic scenario

Say you have 100,000 rows of sales data:

```python
import numpy as np

np.random.seed(0)
prices = np.random.uniform(10, 500, 100_000)   # 100k prices
quantities = np.random.randint(1, 10, 100_000) # 100k quantities

# totals: one line
total = prices * quantities

print(f"total revenue: {np.sum(total):,.0f}")
print(f"average price: {np.mean(prices):.1f}")
print(f"largest order: {np.max(total):,.0f}")
print(f"orders over 1000: {np.sum(total > 1000)}")
```

With lists, that's four loops.
