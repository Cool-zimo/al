# Unique values and set operations

> Staples of data cleaning: drop duplicates, find what's shared, isolate what differs.

## unique: de-duplicate and sort

```python
import numpy as np

arr = np.array([3, 1, 2, 3, 1])
print(np.unique(arr))     # [1 2 3]
```

**Note: the result is sorted.** A bonus — and a cost, since sorting makes it slower than pure de-duplication.

### Three very useful arguments

```python
arr = np.array([3, 1, 2, 3, 1])

vals, counts = np.unique(arr, return_counts=True)
print(vals)       # [1 2 3]   which values
print(counts)     # [2 1 2]   how often each
```

**`return_counts` is the fastest frequency count there is:**

```python
scores = np.array([85, 90, 85, 70, 90, 90])
vals, counts = np.unique(scores, return_counts=True)
for v, c in zip(vals, counts):
    print(f"  {v} pts: {c} students")
```

```
70 pts: 1 students
85 pts: 2 students
90 pts: 3 students
```

Two more:

```python
# where each unique value first appears
vals, first_idx = np.unique(arr, return_index=True)
print(first_idx)      # [1 3 0]

# indices that rebuild the original from the unique values
vals, inverse = np.unique(arr, return_inverse=True)
print(inverse)        # [2 0 1 2 0]
print(vals[inverse])  # [3 1 2 3 1]  ← the original, reconstructed
```

`return_inverse` is valuable when mapping categories to numeric codes (exactly how categorical features get encoded for machine learning).

### Unique on 2-D

```python
m = np.array([[1, 2],
              [3, 4],
              [1, 2]])

print(np.unique(m, axis=0))    # de-duplicate by row
```

```
[[1 2]
 [3 4]]
```

`axis=0` means "compare each row as a whole". **Always pass axis** — without it the array is flattened first.

## isin: membership tests

**"Which elements of this array also appear in that one?"**

```python
arr = np.array([1, 2, 3, 4, 5])
targets = np.array([2, 4])

print(np.isin(arr, targets))      # [False  True False  True False]
print(arr[np.isin(arr, targets)]) # [2 4]   filter straight away
```

**The standard allow-list filter:**

```python
cities = np.array(['London', 'Paris', 'Berlin', 'Rome', 'Oslo'])
key = np.array(['London', 'Rome'])
print(cities[np.isin(cities, key)])      # ['London' 'Rome']
```

> ⚠️ Older code may show `np.in1d(arr, targets)` — same behaviour, but **deprecated in NumPy 2.x** and it emits a DeprecationWarning. Use `np.isin` in new code.

### Negation: not in the list

```python
print(arr[~np.isin(arr, targets)])    # [1 3 5]  ← the block-list
```

`~` is bitwise not; on a boolean array it means "not".

## The four set operations

```python
a = np.array([1, 2, 3, 4])
b = np.array([3, 4, 5, 6])

print(np.intersect1d(a, b))     # [3 4]        intersection (in both)
print(np.union1d(a, b))         # [1 2 3 4 5 6] union (all, de-duplicated)
print(np.setdiff1d(a, b))       # [1 2]        difference (in a, not in b)
print(np.setxor1d(a, b))        # [1 2 5 6]    symmetric difference (only in one)
```

**All of them de-duplicate and sort.**

**A typical use:**

```python
# which customers were here last month but not this month (churn)
last_month = np.array([101, 102, 103, 104])
this_month = np.array([102, 103, 105])

churned = np.setdiff1d(last_month, this_month)
print("churned:", churned)      # [101 104]

new = np.setdiff1d(this_month, last_month)
print("new:", new)              # [105]
```

## Finding duplicates

`unique` tells you which values exist; to find which ones repeat, combine with counts:

```python
arr = np.array([1, 2, 2, 3, 3, 3])
vals, counts = np.unique(arr, return_counts=True)
dups = vals[counts > 1]
print("values appearing more than once:", dups)      # [2 3]
```

## In practice: cleaning a dirty dataset

```python
import numpy as np

raw = np.array([85, 90, -1, 85, 999, 70, 90, -1])

# 1. drop sentinels (-1 means missing, 999 means a keying error)
valid = raw[~np.isin(raw, [-1, 999])]
print("valid:", valid)

# 2. spot duplicate entries (usually kept, so just measure)
vals, counts = np.unique(valid, return_counts=True)
print("appearing more than once:", vals[counts > 1])

# 3. the final distribution
print("unique:", vals)
print("counts:", counts)
```

## Quick reference

| Need | Function |
|---|---|
| de-duplicate (and sort) | `np.unique(arr)` |
| de-duplicate + count | `np.unique(arr, return_counts=True)` |
| de-duplicate rows | `np.unique(arr, axis=0)` |
| allow-list filtering | `np.isin(arr, targets)` |
| intersection | `np.intersect1d(a, b)` |
| union | `np.union1d(a, b)` |
| difference (in a, not b) | `np.setdiff1d(a, b)` |
| symmetric difference | `np.setxor1d(a, b)` |
