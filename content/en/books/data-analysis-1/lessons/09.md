# Broadcasting in practice

> Rules understood — now see them at work. Two cases: **standardising data** and **distance matrices**.

## Case one: standardisation (z-score)

**Task:** a score table, 3 students × 4 subjects. Subjects differ in difficulty (in one everyone scores 90, in another everyone scores 60), so comparing raw totals is unfair.

**Standardisation** converts each score into "how many standard deviations from that subject's mean".

Formula: `z = (x - mean) / std`

```python
import numpy as np

scores = np.array([[80, 90, 70, 85],
                   [60, 75, 80, 65],
                   [95, 88, 92, 90]])

# mean and std per subject (per column)
mean = scores.mean(axis=0)      # shape (4,)
std = scores.std(axis=0)        # shape (4,)

# broadcasting: every row loses the same column mean
z = (scores - mean) / std

print("means:", mean)
print("stds:", std)
print("standardised:")
print(z)
```

**What broadcasting did here:** `scores` is `(3, 4)`, `mean` is `(4,)`. The latter becomes `(1, 4)` then stretches to `(3, 4)` — as if every student had that subject's mean subtracted.

**Without broadcasting** you'd write a nested loop:

```python
z = np.zeros_like(scores, dtype=float)
for i in range(scores.shape[0]):
    for j in range(scores.shape[1]):
        z[i, j] = (scores[i, j] - mean[j]) / std[j]
```

Five lines to one, and much faster.

### Aside: standardising by row

To ask "within each student, which subject is relatively strongest", compute per row:

```python
row_mean = scores.mean(axis=1)          # shape (3,)
row_mean_col = row_mean.reshape(-1, 1)  # becomes (3, 1)

z_row = (scores - row_mean_col) / scores.std(axis=1).reshape(-1, 1)
```

**The reshape to `(3, 1)` is mandatory.** `scores` is `(3, 4)` while `row_mean` is `(3,)` — the latter would align to columns and fail, as the previous lesson showed.

## Case two: a distance matrix

**Task:** given 4 two-dimensional points, compute every pairwise distance, producing a 4×4 matrix.

```python
points = np.array([[0, 0],
                   [3, 4],
                   [6, 8],
                   [1, 1]])
```

**Loop (clearest, slowest):**

```python
n = len(points)
dist = np.zeros((n, n))
for i in range(n):
    for j in range(n):
        dist[i, j] = np.sqrt(np.sum((points[i] - points[j]) ** 2))
```

**Broadcast version:** exploit "column vector minus row vector = matrix".

```python
# pull out all x and all y
xs = points[:, 0].reshape(-1, 1)    # (4, 1) column
ys = points[:, 1].reshape(-1, 1)    # (4, 1) column

# column − row → broadcasts to (4, 4)
dx = xs - xs.T      # xs.T is (1, 4)
dy = ys - ys.T

dist = np.sqrt(dx ** 2 + dy ** 2)
print(dist)
```

**The trick:** `(4, 1) - (1, 4)` broadcasts to `(4, 4)`, where row `i`, column `j` is `xs[i] - xs[j]`.

```
xs      (4,1)          xs.T   (1,4)        result (4,4)
[0]                                       [0-0  0-3  0-6  0-1]
[3]      -      [0  3  6  1]      =       [3-0  3-3  3-6  3-1]
[6]                                       [6-0  6-3  6-6  6-1]
[1]                                       [1-0  1-3  1-6  1-1]
```

**"Column minus row" is the standard way to generate all pairs** — it's everywhere in image processing and similarity computation.

A shorter form (one shot):

```python
# (4,1,2) - (1,4,2) → (4,4,2) three-dimensional broadcasting
diff = points[:, np.newaxis, :] - points[np.newaxis, :, :]
dist = np.sqrt((diff ** 2).sum(axis=-1))
```

Brain-bending but clear in intent:
1. `points[:, None, :]` has shape `(4, 1, 2)`
2. `points[None, :, :]` has shape `(1, 4, 2)`
3. Subtracting broadcasts to `(4, 4, 2)` — entry `[i, j, :]` is "point i minus point j"
4. Square, sum, take the root

## Case three: a filter on an image

An image in NumPy is a 3-D array `(height, width, channels)`. To apply a different brightness gain per channel:

```python
# suppose img has shape (100, 200, 3)
gain = np.array([1.2, 1.0, 0.8])    # gains for red, green, blue
bright = img * gain                  # (100,200,3) * (3,) → aligns to the last axis
```

**Why does that work?** Broadcasting aligns from the right, so `(3,)` lines up with the channel axis and stretches across height and width.

## Three rules of thumb

1. **Per-column treatment** (e.g. each subject's mean): use shape `(n,)` and broadcast directly
2. **Per-row treatment** (e.g. each student's mean): reshape to `(n, 1)` first
3. **All pairs**: column `(n,1)` minus (or plus) row `(1,n)`
