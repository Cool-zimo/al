## The task

A table of 5 students × 4 subjects (with one missing grade). Produce a report:

1. Each student's total and ranking
2. Each subject's difficulty (mean and standard deviation)
3. Who is the most uneven (spread across subjects)
4. Who needs a resit

## Step one: make the data

```python
import numpy as np

np.random.seed(7)

# 5 students × 4 subjects, grades from 40 to 100
scores = np.random.randint(40, 101, size=(5, 4))
scores[2, 1] = -1        # -1 means "missed the exam" (a realistic dirty value)

print(scores)
```

In real work you'd read a CSV or spreadsheet, but from here on the NumPy handling is identical.

## Step two: clean — handle the absence

```python
# mark it as nan so statistics skip it automatically
scores_clean = scores.astype(float)
scores_clean[scores_clean == -1] = np.nan

print("missing entries:", np.sum(np.isnan(scores_clean)))
```

**The key move:** turn the sentinel (-1) into `np.nan` so later statistics ignore it.

## Step three: totals and ranking

```python
totals = np.nansum(scores_clean, axis=1)
print("totals:", totals)

# argsort gives ascending order; reverse it for highest-first
order = np.argsort(totals)[::-1]
print("ranking (student indices):", order)

for rank, idx in enumerate(order, start=1):
    print(f"  #{rank}: student {idx + 1}, total {totals[idx]:.0f}")
```

**`np.argsort(x)[::-1]` is the standard "largest first" ranking idiom.**

## Step four: subject difficulty

```python
subj_mean = np.nanmean(scores_clean, axis=0)
subj_std = np.nanstd(scores_clean, axis=0)

print("mean per subject:", np.round(subj_mean, 1))
print("std per subject:", np.round(subj_std, 1))
```

**A large standard deviation means the subject separates students well** (or that the paper was inconsistent).

Find the hardest (lowest mean):

```python
hardest = np.nanargmin(subj_mean)
print(f"hardest is subject {hardest + 1}, mean {subj_mean[hardest]:.1f}")
```

## Step five: who is most uneven

**Unevenness = the spread of each student's own grades**, measured by standard deviation:

```python
# spread within each student → collapse the subject dimension → axis=1
per_student_std = np.nanstd(scores_clean, axis=1)
print("unevenness:", np.round(per_student_std, 1))

worst = np.nanargmax(per_student_std)
print(f"most uneven: student {worst + 1}")
```

## Step six: who needs a resit

```python
# any grade below 60
fail_mask = scores_clean < 60
print("failing cells:", np.sum(fail_mask))

# which students have at least one failure
any_fail = np.any(fail_mask, axis=1)
print("students needing a resit:", np.where(any_fail)[0] + 1)
```

**`np.any(mask, axis=1)`** collapses the subject dimension into "does this student have any failure". A textbook use of axis.

## The whole thing

```python
import numpy as np

np.random.seed(7)
scores = np.random.randint(40, 101, size=(5, 4)).astype(float)
scores[2, 1] = np.nan          # missed exam

line = "=" * 38
print(line)
print("1. totals and ranking")
totals = np.nansum(scores, axis=1)
for rank, i in enumerate(np.argsort(totals)[::-1], start=1):
    print(f"  #{rank}  student {i+1}  {totals[i]:.0f} pts")

print("\n2. subject difficulty")
print("  means:", np.round(np.nanmean(scores, axis=0), 1))
print("  stds:", np.round(np.nanstd(scores, axis=0), 1))

print("\n3. unevenness (higher = more uneven)")
print("  ", np.round(np.nanstd(scores, axis=1), 1))

print("\n4. resits needed")
print("  students:", np.where(np.any(scores < 60, axis=1))[0] + 1)
print(line)
```
