# Splitting arrays

> The inverse of joining. Beyond "equal parts versus unequal", there's little to trip over here.

## split: equal parts

```python
import numpy as np

arr = np.arange(6)          # [0 1 2 3 4 5]
print(np.split(arr, 3))     # into 3 parts
```

```
[array([0, 1]), array([2, 3]), array([4, 5])]
```

**The return value is a list** of arrays.

## The key difference: split demands an exact division

```python
np.split(np.arange(5), 3)
# ValueError: array split does not result in an equal division
```

Five values into three parts doesn't divide, so `split` refuses.

**`array_split` doesn't mind:**

```python
print(np.array_split(np.arange(5), 3))
```

```
[array([0, 1]), array([2, 3]), array([4])]
```

Two parts of 2 and a final part of 1. **`array_split` allows uneven splits, giving the leftovers to the earlier parts.**

> 💡 Practical advice: **when you can't guarantee divisibility, always use `array_split`.** It never fails for that reason.

## Naming the cut points

Instead of "into N parts" you can say "cut at these indices" by passing a **list**:

```python
arr = np.arange(10)
print(np.split(arr, [3, 7]))    # cut at index 3 and at index 7
```

```
[array([0, 1, 2]), array([3, 4, 5, 6]), array([7, 8, 9])]
```

Three pieces: `[0:3]`, `[3:7]`, `[7:]`.

**Handy when cutting by thresholds** — e.g. splitting grades into bands at 60 and 80.

## vsplit and hsplit

Mirroring vstack / hstack:

```python
m = np.arange(6).reshape(2, 3)
print(m)
```

```
[[0 1 2]
 [3 4 5]]
```

```python
print(np.vsplit(m, 2))    # cut horizontally, two blocks
print(np.hsplit(m, 3))    # cut vertically, three blocks
```

```
vsplit: [array([[0, 1, 2]]), array([[3, 4, 5]])]
hsplit: [array([[0], [3]]), array([[1], [4]]), array([[2], [5]])]
```

**Mnemonic:** `vsplit` cuts across (separating rows), `hsplit` cuts down (separating columns). The naming is genuinely confusing — remember v mirrors "the inverse of vertical stacking", i.e. split by row.

## In practice: train / test split

The most common split in machine learning:

```python
data = np.arange(100)
np.random.seed(42)
np.random.shuffle(data)      # shuffle in place

split_at = int(len(data) * 0.8)
train, test = np.split(data, [split_at])

print(f"train {len(train)}, test {len(test)}")
```

**`np.split(data, [n])` is the tidiest "first n | the rest" idiom.**

(Note `np.random.shuffle` shuffles **in place**, destroying the original order. For a shuffled copy use `np.random.permutation(data)`.)

## Traps

**1. The result is a list, not an array.**

```python
parts = np.split(arr, 2)
print(parts[0])        # index into it
print(parts.shape)     # AttributeError: 'list' object has no attribute 'shape'
```

**2. The pieces are views.**

Like slices, split shares memory with the original:

```python
arr = np.arange(6)
parts = np.split(arr, 2)
parts[0][0] = 99
print(arr)      # [99  1  2  3  4  5]  ← the original changed
```

Use `.copy()` if you need independence.
