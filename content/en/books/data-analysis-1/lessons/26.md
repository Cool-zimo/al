# Project 1: monthly sales analysis

> The first complete project. No new functions — just combining the first five chapters to solve a real problem.

## The brief

Twelve months × five products of sales data, four questions to answer:

1. What were total annual sales?
2. Which month was best?
3. Which product contributed most?
4. What does the quarterly trend look like?

## Making the data

```python
import numpy as np

np.random.seed(42)
products = ['Keyboard', 'Mouse', 'Monitor', 'Headset', 'Webcam']
months = 12

base = np.array([200, 500, 80, 300, 150])        # baseline units per product
prices = np.array([199, 89, 1299, 399, 259])     # unit price per product

sales = np.random.randint(-30, 60, size=(months, 5)) + base
sales = np.clip(sales, 0, None)                  # units can't be negative
print("units (12 months × 5 products):")
print(sales)
```

**`np.clip(sales, 0, None)`** floors negatives at zero — you can't sell negative units. A genuinely useful cleaning move.

## Question one: annual revenue

```python
# revenue = units × price (broadcast)
revenue = sales * prices
print("monthly revenue:", revenue.sum(axis=1))
print("annual total:", revenue.sum())
```

**Broadcasting does the work**: `sales` is `(12, 5)`, `prices` is `(5,)`, so prices stretches to `(12, 5)`.

Per-product annual revenue:

```python
print("revenue by product:", revenue.sum(axis=0))
```

**Choosing the axis:**
- `sum(axis=1)` → adds across products, giving a value per month → 12 values
- `sum(axis=0)` → adds across months, giving a value per product → 5 values

## Question two: the best month

```python
monthly = revenue.sum(axis=1)
best = np.argmax(monthly)
print(f"best month: #{best + 1}, revenue {monthly[best]:,}")

worst = np.argmin(monthly)
print(f"worst month: #{worst + 1}, revenue {monthly[worst]:,}")
```

**Mind the `+ 1`**: indices start at 0, months at 1. This off-by-one is the most common beginner error in real work.

## Question three: top contributors

```python
by_product = revenue.sum(axis=0)
order = np.argsort(by_product)[::-1]      # descending

print("\nproduct ranking:")
for rank, i in enumerate(order, 1):
    share = by_product[i] / by_product.sum() * 100
    print(f"  {rank}. {products[i]:<10} {by_product[i]:>10,.0f}  ({share:.1f}%)")
```

**`argsort(...)[::-1]` for ranking plus a share calculation** — the standard leaderboard recipe.

## Question four: quarterly trend

Split the 12 months into 4 quarters:

```python
# reshape to (4, 3, 5) → 4 quarters, 3 months each, 5 products
quarterly = revenue.reshape(4, 3, 5)
q_revenue = quarterly.sum(axis=(1, 2))     # sum over months AND products
print("\nquarterly revenue:", q_revenue)

growth = np.diff(q_revenue) / q_revenue[:-1] * 100
print("quarter-on-quarter (%):", np.round(growth, 1))
```

**`sum(axis=(1, 2))` accepts a tuple** to collapse several dimensions at once — clearer than two nested sums.

> ⚠️ `reshape(4, 3, 5)` requires the totals to match (`4×3×5 = 60 = 12×5`). **Assert it first**:

```python
assert revenue.size == 4 * 3 * 5, "row count doesn't match the quarter split"
```

## The full report

```python
import numpy as np

line = "=" * 46
print(line)
print("          ANNUAL SALES REPORT")
print(line)

print(f"annual revenue: {revenue.sum():,.0f}")
print(f"monthly average: {monthly.mean():,.0f}")
print(f"best/worst month: #{best+1} / #{worst+1}")
print(f"volatility (std): {monthly.std():,.0f}")

print("\ncontribution by product:")
for rank, i in enumerate(order, 1):
    share = by_product[i] / by_product.sum() * 100
    print(f"  {rank}. {products[i]:<10} {by_product[i]:>10,.0f}  ({share:>5.1f}%)")

print("\nquarterly trend:")
for q, v in enumerate(q_revenue, 1):
    bar = "#" * int(v / q_revenue.max() * 30)
    print(f"  Q{q}  {v:>10,.0f}  {bar}")
print(line)
```

**That `bar` is a plain-text chart**: `"#" * count` draws a bar proportional to the value. When matplotlib isn't available, this is the fastest visualisation there is.

## What you used

| Need | Tool |
|---|---|
| clamp a range | `np.clip` |
| units → money | broadcasting `sales * prices` |
| monthly / product totals | `sum(axis=1)` / `sum(axis=0)` |
| best and worst | `argmax` / `argmin` |
| ranking | `argsort(...)[::-1]` |
| quarterly grouping | `reshape` + `sum(axis=(1,2))` |
| growth | `diff` / previous period |
| a chart | string × count |

**Not one of these is new.** Combining what you know is what "doing a project" means.
