# Basic array arithmetic

> Arrays redefine what `+ - * /` mean. Get these new rules straight and everything after flows.

## With a scalar: every element, once each

```python
import numpy as np
arr = np.array([1, 2, 3, 4])

print(arr + 10)     # [11 12 13 14]
print(arr * 2)      # [ 2  4  6  8]
print(arr ** 2)     # [ 1  4  9 16]
print(arr / 2)      # [0.5 1.  1.5 2. ]
```

**The scalar is "broadcast" to every element.** `arr + 10` means "add 10 to each element".

That property is called **broadcasting**, and chapter 2 covers it properly. For now, just enjoy it.

**The original is unchanged** — these all return new arrays:

```python
arr = np.array([1, 2, 3])
arr + 10
print(arr)          # [1 2 3]  ← unchanged!

arr = arr + 10      # reassign to keep it
print(arr)          # [11 12 13]
```

## Array with array: element by element

```python
a = np.array([1, 2, 3])
b = np.array([10, 20, 30])

print(a + b)        # [11 22 33]
print(b - a)        # [ 9 18 27]
print(a * b)        # [10 40 90]
print(b / a)        # [10. 10. 10.]
```

**Everything is position-by-position** — this is not matrix multiplication (that's `@` or `np.dot()`, which you'll meet later).

Shapes must match, or you get an error:

```python
a = np.array([1, 2, 3])
b = np.array([1, 2])
a + b     # ValueError: operands could not be broadcast together
```

## A classic trap: division

```python
a = np.array([1, 2, 3])
b = np.array([0, 2, 4])

print(a / b)
```

```
[ inf 1.   0.75]
```

**Dividing by zero does not raise.** You get `inf` (infinity) plus a printed RuntimeWarning.

NumPy's philosophy is "keep going, don't stop". For data analysis that's often reasonable — you don't want one bad value to abort everything. But it also means **bad values spread quietly**:

```python
print(np.sum(a / b))     # inf  ← one inf contaminates the whole sum
```

To avoid it, filter the zeros first:

```python
b_safe = np.where(b == 0, 1, b)    # replace 0 with 1
print(a / b_safe)                  # [1.  1.  0.75]
```

## Comparisons: you get a boolean array

```python
arr = np.array([1, 5, 3, 8, 2])
print(arr > 3)      # [False  True False  True False]
```

**The result isn't a single True/False — it's a boolean array** holding each position's outcome. This is NumPy's core filtering tool (used heavily in chapter 3).

Combine with `np.sum()` to count how many satisfy a condition, since True counts as 1:

```python
print(np.sum(arr > 3))      # 2  ← two values are greater than 3
```

For "all / any":

```python
print(np.all(arr > 0))      # True   every element > 0
print(np.any(arr > 7))      # True   at least one > 7
```

> ⚠️ You cannot write `if arr > 3:`. A boolean array holds many values, so Python doesn't know which to decide on and raises "ambiguous". Write `if np.all(arr > 3):` or `np.any(...)`.

## Common maths functions

These also act element-wise:

```python
arr = np.array([1, 4, 9, 16])

print(np.sqrt(arr))     # [1. 2. 3. 4.]    square root
print(np.abs(arr))      # absolute value
print(np.exp(arr))      # e to the power x
print(np.log(arr))      # natural log
print(np.round(arr))    # rounding
```

Plus trigonometry `np.sin()`, `np.cos()` — the argument is in radians, not degrees.

## Aggregation: many numbers to one

```python
arr = np.array([3, 1, 4, 1, 5, 9, 2, 6])

print(np.sum(arr))      # 31    sum
print(np.mean(arr))     # 3.875 mean
print(np.max(arr))      # 9     maximum
print(np.min(arr))      # 1     minimum
print(np.std(arr))      # standard deviation
print(np.argmax(arr))   # 5     index of the maximum (6th item)
```

**`argmax` returns a position, not a value** — a frequent beginner mix-up. For the largest value use `np.max()`; for "which one is largest" use `np.argmax()`.

Method form works too and is equivalent:

```python
print(arr.sum())    # same as np.sum(arr)
print(arr.mean())   # same as np.mean(arr)
```

## Constants

```python
print(np.pi)     # 3.14159...
print(np.e)      # 2.71828...
```

Building the x-axis for a sine curve:

```python
x = np.linspace(0, 2 * np.pi, 100)
y = np.sin(x)
print(y[:5])     # look at the first 5 values
```

## Quick reference

| Written | Means |
|---|---|
| `arr + 5` | add 5 to every element |
| `a + b` | add position by position |
| `a * b` | multiply position by position (**not** matrix product) |
| `a @ b` | matrix product |
| `arr > 3` | boolean array |
| `np.sum(arr)` | sum |
| `np.argmax(arr)` | the **index** of the maximum |
