# Text files: savetxt / loadtxt

> When the data needs to reach a person or a spreadsheet, you want CSV-like text.

## savetxt: writing out

```python
import numpy as np

arr = np.array([[1, 2, 3],
                [4, 5, 6]])

np.savetxt('data.csv', arr, delimiter=',', fmt='%d')
```

File contents:

```
1,2,3
4,5,6
```

**The two arguments you'll use most:**

| Argument | Does | Common values |
|---|---|---|
| `delimiter` | separator | `','` (CSV), `'\t'` (TSV, pastes nicely into Excel) |
| `fmt` | format per number | `'%d'` integer, `'%.2f'` two decimals |

### fmt matters

Without it, NumPy writes a long string of digits:

```python
np.savetxt('a.csv', np.array([[1, 2.5]]))
```

```
1.000000000000000000e+00 2.500000000000000000e+00
```

Ugly. With `fmt='%.2f'`:

```python
np.savetxt('b.csv', np.array([[1, 2.5]]), fmt='%.2f')
```

```
1.00 2.50
```

**Common fmt values:**

| Format | Result |
|---|---|
| `'%d'` | `1` |
| `'%.2f'` | `2.50` |
| `'%.1f'` | `2.5` |
| `'%s'` | the string as-is |

### Adding a header

```python
np.savetxt('c.csv', arr, delimiter=',', fmt='%d',
           header='lang,maths,english', comments='')
```

```
lang,maths,english
1,2,3
4,5,6
```

> ⚠️ **`comments=''` is the trick.** By default NumPy prefixes the header with `#`; loadtxt skips it automatically, but opening the file in Excel shows `#lang`. An empty comment string keeps it clean.

## loadtxt: reading in

```python
data = np.loadtxt('data.csv', delimiter=',')
print(data)
```

```
[[1. 2. 3.]
 [4. 5. 6.]]
```

**Note it reads as float by default**, even from integers. For integers, say so:

```python
data = np.loadtxt('data.csv', delimiter=',', dtype=int)
print(data)      # [[1 2 3] [4 5 6]]
```

### Skipping a header

```python
data = np.loadtxt('c.csv', delimiter=',', skiprows=1)
```

**`skiprows=1` skips the first line.** Lines starting with `#` are ignored **automatically** — no skiprows needed for those.

### Reading only some columns

```python
# just columns 0 and 2
data = np.loadtxt('data.csv', delimiter=',', usecols=(0, 2))
```

### Reading as text

```python
# when the file holds words
data = np.loadtxt('zh.csv', delimiter=',', dtype=str, encoding='utf-8')
```

**`encoding='utf-8'` handles non-ASCII text**; without it you may see `UnicodeDecodeError`.

## A complete example

```python
import numpy as np

np.random.seed(0)
scores = np.random.randint(50, 101, size=(5, 3))

# write (header, integer format)
np.savetxt('scores.csv', scores, delimiter=',', fmt='%d',
           header='lang,maths,english', comments='')

# read (skip the header)
loaded = np.loadtxt('scores.csv', delimiter=',', skiprows=1, dtype=int)
print(loaded)
print("means:", loaded.mean(axis=0))
```

## Two limits of loadtxt

**1. No missing values.**

With an empty field in the file:

```
1,2
3,
```

`loadtxt` raises `ValueError: could not convert string to float`. **For missing data use `genfromtxt` (next lesson).**

**2. Every row must have the same column count.**

```
1,2,3
4,5
```

gives `ValueError: the number of columns changed from 3 to 2 at row 2`.

## When to use text

| Situation | Use |
|---|---|
| Staying inside Python | `np.save` / `np.load` (npy) |
| For humans or Excel | `savetxt` / `loadtxt` (CSV) |
| Bundling several arrays | `savez` (npz) |
| Data contains gaps | read with `genfromtxt` |
