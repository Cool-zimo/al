# Topological Sort: Dependencies and Kahn's Algorithm

> Topological sort solves the problem of "how to order tasks with dependencies". You must put on socks before shoes; you must finish a prerequisite course before taking the advanced one. Arranging these "before → after" relationships into a sequence is topological sorting. It only exists for Directed Acyclic Graphs (DAGs).

## What Is Topological Sort

**A topological sort arranges the vertices of a DAG into a sequence such that for every directed edge u→v, u appears before v.**

```
Course dependencies:
  Data Structures  →  Algorithms
  Algorithms        →  Graph Theory
  Discrete Math     →  Data Structures
  Discrete Math     →  Algorithms
```

**A valid topological order must place every predecessor before its successor.** The dependencies above allow multiple valid orderings, such as `[Discrete Math, Data Structures, Algorithms, Graph Theory]` or `[Discrete Math, Algorithms, Data Structures, Graph Theory]`.

**A topological sort is not a single unique sequence.** Any valid arrangement that satisfies "predecessors first" counts as a topological order.

## The Idea: Always Pick a Node With "No Predecessors"

**If a node has no unprocessed incoming edges (in-degree is 0), it means everything it depends on has already been placed, so it can be added to the result.**

Kahn's Algorithm:

1. Compute the in-degree of each node (how many edges point to it).
2. Put all nodes with in-degree 0 into a queue.
3. Dequeue a node u, add it to the result, and "remove" all outgoing edges from u (decrement the in-degree of each neighbor v).
4. If a neighbor v's in-degree becomes 0, enqueue it.
5. Repeat until the queue is empty.

```python
from collections import deque

def topo_sort(n, edges):
    """n nodes 0~n-1, edges is a list of directed edges [[u,v], ...]"""
    adj = [[] for _ in range(n)]
    indeg = [0] * n
    for u, v in edges:
        adj[u].append(v)
        indeg[v] += 1

    q = deque([i for i in range(n) if indeg[i] == 0])
    ans = []
    while q:
        u = q.popleft()
        ans.append(u)
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return ans

print(topo_sort(4, [[0,1],[0,2],[1,3],[2,3]]))   # [0, 1, 2, 3] or [0, 2, 1, 3]
print(topo_sort(3, [[0,1],[1,2],[0,2]]))          # [0, 1, 2]
```

**"In-degree becomes 0 after decrementing" means the last predecessor has been placed, so the node can join the queue.**

## # WRONG: On a Cyclic Graph, Topological Sort Does Not Exist

```python
# Cyclic: A→B→C→A
print(topo_sort(3, [[0,1],[1,2],[2,0]]))
# Output: []
```

**The output is an empty list.** All three nodes have in-degree 1, so no node with in-degree 0 can enter the queue — the queue starts out empty.

**`len(ans) != n` means the graph has a cycle and no topological sort exists.** This is the classic application of topological sort: **detecting whether a directed graph has a cycle.**

```python
def has_cycle_directed(n, edges):
    adj = [[] for _ in range(n)]
    indeg = [0] * n
    for u, v in edges:
        adj[u].append(v)
        indeg[v] += 1
    q = deque([i for i in range(n) if indeg[i] == 0])
    seen = 0
    while q:
        u = q.popleft()
        seen += 1
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return seen != n     # True means there is a cycle

print(has_cycle_directed(3, [[0,1],[1,2],[2,0]]))   # True
print(has_cycle_directed(4, [[0,1],[1,2],[0,2]]))   # False
```

## DFS-Based Topological Sort

**Another approach uses DFS: output nodes in reverse order of "finish time".** A node is pushed onto the result stack only after all of its successors have been processed (the recursive call returns).

```python
def topo_sort_dfs(n, edges):
    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)

    visited = [0] * n      # 0=unvisited, 1=visiting, 2=done
    stack = []
    has_cycle = [False]

    def go(u):
        visited[u] = 1
        for v in adj[u]:
            if visited[v] == 1:        # Encountered a node still being visited = cycle
                has_cycle[0] = True
                return
            if visited[v] == 0:
                go(v)
        visited[u] = 2
        stack.append(u)                # Push after finishing

    for i in range(n):
        if visited[i] == 0:
            go(i)
    if has_cycle[0]:
        return []
    return stack[::-1]                # Reversed = topological order

print(topo_sort_dfs(4, [[0,1],[0,2],[1,3],[2,3]]))   # [0, 1, 2, 3]
print(topo_sort_dfs(3, [[0,1],[1,2],[2,0]]))          # []
```

**`visited` uses three colors instead of a boolean to detect "back edges" (a node being visited again = cycle).**

**The stack stores nodes in "latest finish time first"; reversing it gives the topological order.** Intuition: a node must wait until all its successors are placed before it can be placed, so it belongs near the end.

## Comparing the Two Approaches

| Dimension | Kahn (in-degree + queue) | DFS + stack |
|---|---|---|
| Cycle detection | `len(ans) != n` | Detect back edges |
| Implementation | Simple and intuitive | Requires 3-color marking |
| Space | O(n+m) | O(n+m) |
| Output | Order of "in-degree 0" nodes, not unique | Reverse finish order, not unique |

**In practice, Kahn is more common** because it is more straightforward to write and naturally reveals "which batch of nodes can be processed in parallel" (all nodes with in-degree 0 in the queue are mutually independent).

## Application: Course Schedule

**LeetCode 207/210 Course Schedule: given the number of courses and prerequisite relationships, determine whether it is possible to finish all courses.**

```python
def can_finish(numCourses, prerequisites):
    adj = [[] for _ in range(numCourses)]
    indeg = [0] * numCourses
    for u, v in prerequisites:      # u requires v as a prerequisite, so v→u
        adj[u].append(v)
        indeg[v] += 1
    q = deque([i for i in range(numCourses) if indeg[i] == 0])
    seen = 0
    while q:
        u = q.popleft()
        seen += 1
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return seen == numCourses

print(can_finish(2, [[1, 0]]))          # True   (0 is a prerequisite for 1)
print(can_finish(2, [[1, 0], [0, 1]]))  # False  (mutual dependency = cycle)
```

**"Can all courses be finished?" is equivalent to "does the graph have a cycle?"** If there is no cycle, a topological order exists. If there is a cycle, there must be a circular dependency.

## Summary

- Topological sort arranges a DAG so that all predecessors come first; the result is not unique
- Kahn's algorithm: in-degree array + queue; repeatedly take a node with in-degree 0 and remove its outgoing edges
- **`len(ans) != n` means the graph has a cycle**, so no topological sort exists
- To detect directed cycles: Kahn checks `seen != n`; DFS checks for "visiting" nodes
- Use a list of lists for the adjacency list to avoid KeyError on isolated nodes
- The course schedule problem is fundamentally about detecting cycles in a directed graph
