# Shortest Path: The Intuition Behind Dijkstra

> How do you find the shortest path between two nodes in a weighted graph? BFS only works for unweighted graphs. Dijkstra is the answer — it uses a greedy strategy of "always pick the node with the current minimum distance" to progressively determine the shortest distance to every node. This lesson explains the intuition, not the proof.

## BFS for Unweighted Graphs, Dijkstra for Weighted Graphs

**BFS can find the shortest path in an unweighted graph because every edge has the same weight (1). As soon as edges carry weight (road distance, time, cost), BFS no longer works.**

Dijkstra handles **graphs with non-negative weights**: given a starting node s, it computes the shortest distance from s to every other node.

```python
# Weighted directed graph: adjacency list stores (neighbor, weight)
adj = {
    0: [(1, 4), (2, 1)],
    1: [(3, 1)],
    2: [(1, 2), (3, 5)],
    3: [],
}
```

**Edge weights must be non-negative.** If there are negative-weight edges, Dijkstra gives incorrect answers — use Bellman-Ford or SPFA in that case.

## Greedy Intuition: Always Settle the "Closest" Node

**The core intuition of Dijkstra: once a node's shortest distance is determined, it will never be updated again.**

Suppose the current distance from start s to node u is `dist[u]`, and u has the smallest distance among all "unsettled" nodes. Then `dist[u]` is the shortest distance from s to u — because any path that "detours through another unsettled node" must take at least one extra edge, and the total distance is necessarily ≥ that edge's weight + the other node's distance ≥ `dist[u]`.

```python
import heapq

def dijkstra(n, adj, start):
    dist = [float('inf')] * n
    dist[start] = 0
    pq = [(0, start)]           # Min-heap: (current distance, node)

    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:         # Stale entry, skip it
            continue
        for v, w in adj[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist

n = 4
adj = [[] for _ in range(n)]
for u, v, w in [(0,1,4),(0,2,1),(1,3,1),(2,1,2),(2,3,5)]:
    adj[u].append((v, w))

print(dijkstra(n, adj, 0))   # [0, 3, 1, 4]
```

**From node 0: the shortest to node 2 is 1; the shortest to node 1 is 0→2→1 = 3 (shorter than the direct edge of 4!); the shortest to node 3 is 0→2→1→3 = 4.**

**Key insight: the direct path to node 1 has length 4, but "detouring through node 2" only costs 3.** Dijkstra's greedy strategy processes the smaller-distance node 2 first, then uses it to update node 1, eventually getting 3.

## # WRONG: Forgetting to Skip Stale Entries Causes Repeated Processing

```python
# WRONG: No `if d > dist[u]: continue`, so the same node is processed multiple times
def dijkstra_wrong(n, adj, start):
    dist = [float('inf')] * n
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        # Forgot to skip
        for v, w in adj[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist
```

**`dist[v]` can be updated many times, so the same node is enqueued repeatedly.** Although the final result is correct, the heap accumulates many "stale entries", and each node may be processed multiple times — performance degrades to O(m log m).

**Fix: `if d > dist[u]: continue`** — if the popped distance is larger than the known distance, it is an old record, so skip it.

## Why Use a Min-Heap

**Dijkstra needs to "repeatedly extract the unsettled node with the minimum distance".** The heap is the standard tool for this dynamic-minimum operation, at O(log n) per extraction.

**A naive implementation without a heap scans linearly for the minimum each time, costing O(n²).** The heap-optimized version runs in O((n+m) log n).

```python
# Comparison: naive version (good for dense graphs with small n)
def dijkstra_naive(n, adj, start):
    dist = [float('inf')] * n
    dist[start] = 0
    visited = [False] * n
    for _ in range(n):
        u = min((i for i in range(n) if not visited[i]), key=lambda i: dist[i])
        visited[u] = True
        for v, w in adj[u]:
            dist[v] = min(dist[v], dist[u] + w)
    return dist
```

**`heapq` is a min-heap, which perfectly matches "extract minimum".** If you need a max-heap, you would store negative values (covered in Lesson 10).

## # WRONG: Using dist as the Heap Key Means Equal Distances Are Not Updated

```python
# WRONG: Comparing nodes instead of distances, so updates are missed
def relax(u, v, w, pq, dist):
    nd = dist[u] + w
    if nd <= dist[v]:         # Using <= enqueues another copy even when equal
        dist[v] = nd
        heapq.heappush(pq, (nd, v))
```

**When `nd <= dist[v]` and nd == dist[v], this pushes a duplicate entry.** It is not fatal (the "stale skip" handles it), but it wastes heap space.

**Just use `<`: `if nd < dist[v]`.**

## Checking Reachability

**If a node is unreachable, its entry in `dist` stays `inf`.**

```python
dist = dijkstra(4, adj, 0)
print(dist[3])          # 4, reachable
print(dist[0])          # 0, the start node itself

# Check whether a node can be reached
def reachable(dist, target):
    return dist[target] != float('inf')

print(reachable(dist, 3))   # True
```

**Initializing `dist = [inf] * n` with the start at 0 is the standard pattern.** `inf + w` is still `inf`, so unreachable nodes remain `inf` forever.

## Single-Source vs Multi-Source

**Single-source: one starting node.** All the examples above are single-source.

**Multi-source: multiple starting nodes; compute the distance from each node to its "nearest start".** Just initialize the heap so that "every start node has distance 0".

```python
def multi_source(adj, starts):
    n = len(adj)
    dist = [float('inf')] * n
    pq = []
    for s in starts:
        dist[s] = 0
        heapq.heappush(pq, (0, s))
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in adj[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist
```

**Multi-source shortest path = "dump all starts into the heap at once".** A classic application: finding the distance from each house to the nearest fire station.

## Summary

- Dijkstra finds single-source shortest paths and requires non-negative edge weights
- Core greedy idea: always pick the "currently closest" unsettled node; its distance is now final
- Heap-optimized: O((n+m) log n); naive version: O(n²), better for dense graphs
- **Always skip stale entries: `if d > dist[u]: continue`**
- Multi-source shortest path = initialize all starts at distance 0 and push them all into the heap
- Dijkstra fails with negative-weight edges; use Bellman-Ford instead
