# Disjoint Set Union: Connectivity and Path Compression

> Disjoint Set Union (DSU) is the go-to tool for "dynamic connectivity": checking whether two nodes are connected and merging two sets. Its two optimizations — union by rank and path compression — bring each operation to nearly O(1).

## The Problem: Dynamic Connectivity

**DSU solves problems of this form: there are a bunch of elements, each independent at the start; you keep being told "a and b are connected", and at any time you are asked "are c and d connected?"**

Typical scenarios: "do two people know each other (through a chain of friends)?" in a social network, counting the number of islands, and Kruskal's Minimum Spanning Tree (used in the latter part of Lesson 20).

**There are only two core operations:**
- `find(x)`: which set does x belong to (find the root)?
- `union(x, y)`: merge the sets containing x and y into one

```python
class DSU:
    def __init__(self, n):
        self.parent = list(range(n))     # Each node is its own parent initially
        self.rank = [0] * n              # Rank (upper bound on tree height)

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])   # Path compression
        return self.parent[x]

    def union(self, x, y):
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return False                 # Already connected, nothing to do
        # Union by rank: attach the shorter tree to the taller one
        if self.rank[rx] < self.rank[ry]:
            self.parent[rx] = ry
        elif self.rank[rx] > self.rank[ry]:
            self.parent[ry] = rx
        else:
            self.parent[ry] = rx
            self.rank[rx] += 1
        return True
```

## Path Compression: Flatten the Tree on the Fly

**`find(x)` walks up the parent chain to find the root, then points every node along the path directly to the root.** The next `find` is O(1).

```python
def find(self, x):
    if self.parent[x] != x:
        self.parent[x] = self.find(self.parent[x])   # Recurse: find root first, then point x's parent to root
    return self.parent[x]
```

**Pay attention to the recursion order: `self.find(parent[x])` runs first and returns the root; then `parent[x]` is set to the root.** This is "path compression" — `parent[x]` used to point to some intermediate node, and now it points directly to the root.

```python
dsu = DSU(6)
dsu.union(0, 1)
dsu.union(1, 2)
dsu.union(3, 4)
print(dsu.find(0) == dsu.find(2))   # True
print(dsu.find(0) == dsu.find(3))   # False
print(dsu.find(4) == dsu.find(3))   # True
dsu.union(2, 4)
print(dsu.find(0) == dsu.find(4))   # True
```

## Union by Rank: Attach the Shorter Tree to the Taller One

**If you always "attach arbitrarily", the tree can degenerate into a linked list and `find` degrades to O(n).** Union by rank keeps the tree height bounded.

**Rule: attach the tree with lower rank to the tree with higher rank; when ranks are equal, attach either one and increment its rank.**

```python
if self.rank[rx] < self.rank[ry]:
    self.parent[rx] = ry          # Shorter attaches to taller
elif self.rank[rx] > self.rank[ry]:
    self.parent[ry] = rx
else:
    self.parent[ry] = rx          # Equal: attach under rx
    self.rank[rx] += 1            # rx's height increases by 1
```

**With path compression and union by rank, each operation is amortized O(α(n))**, where α is the inverse Ackermann function — it grows so slowly that even at n = 10^600, α(n) is only 5. In practice, treat it as O(1).

## # WRONG: Writing find as an Infinite Loop

```python
# WRONG: find does not update parent, degenerating into a linked list
def find(self, x):
    while self.parent[x] != x:
        x = self.parent[x]         # Finds the root but does not compress
    return x
```

**This code "runs", but it does not compress at all.** In the worst case (always attaching a tall tree under a short one), it degenerates to O(n).

**The real trap is this:**

```python
# WRONG: Incorrect path compression creates a cycle
def find_wrong(self, x):
    if self.parent[x] != x:
        self.parent[x] = self.find_wrong(self.parent[x])
    return self.parent[x]   # Looks right, but...

# If parent contains a cycle (e.g., parent[1]=2, parent[2]=1), it recurses infinitely
```

**If the `parent` array contains a cycle (wrong initialization or a botched union), `find` recurses infinitely until the stack overflows.** Always verify that `parent[i] = i` is initialized correctly before using DSU.

## # WRONG: Forgetting to Call find First in union

```python
# WRONG: Directly setting x's parent to y without considering their roots
def union_wrong(self, x, y):
    self.parent[x] = y      # <- Directly changes x's parent without find

dsu = DSU(5)
dsu.union_wrong(0, 1)
dsu.union_wrong(1, 2)
print(dsu.find(0))   # 1, but 0, 1, and 2 should all be in the same set
```

**`union` must merge "the roots of the two sets", not just connect any two nodes.** Setting `parent[x] = y` attaches x under y, breaking the "all nodes in a set share one root" structure.

**The correct approach is always `rx = find(x); ry = find(y)`, then manipulate `parent[rx]` and `parent[ry]`.**

## Application: Counting Connected Components

**Figuring out how many connected blocks a graph is split into is a natural job for DSU.** Union every edge, then count how many distinct roots remain.

```python
def count_components(n, edges):
    dsu = DSU(n)
    for u, v in edges:
        dsu.union(u, v)
    roots = set()
    for i in range(n):
        roots.add(dsu.find(i))
    return len(roots)

print(count_components(5, [[0,1],[1,2],[3,4]]))   # 2
print(count_components(4, [[0,1],[1,2],[2,3]]))   # 1
```

**Note: call `find(i)` rather than reading `parent[i]`** — because path compression may not have occurred, `parent[i]` might not be the root. Only `find(i)` is guaranteed to return the root.

## Application: Detecting Whether Adding an Edge Creates a Cycle

**"Will this edge create a cycle?" is equivalent to "are its two endpoints already in the same set?"**

```python
def has_cycle(n, edges):
    dsu = DSU(n)
    for u, v in edges:
        if dsu.find(u) == dsu.find(v):    # Already connected
            return True                    # Adding this edge creates a cycle
        dsu.union(u, v)
    return False

print(has_cycle(4, [[0,1],[1,2],[2,3]]))        # False
print(has_cycle(4, [[0,1],[1,2],[2,3],[3,0]]))  # True
```

**This is exactly the core of Kruskal's algorithm**: add edges in increasing order of weight and use DSU to test "will adding this edge create a cycle?" — only add it to the MST if it does not.

## Summary

- DSU has two operations: `find(x)` finds the root; `union(x, y)` merges two sets
- **Path compression**: while finding, point every node along the path directly to the root for O(1) next time
- **Union by rank**: attach the shorter tree under the taller one to keep trees shallow
- Together, each operation is amortized O(α(n)), effectively O(1) in practice
- `union` must merge roots: `rx = find(x); ry = find(y)` — never connect arbitrary nodes directly
- Applications: counting connected components, cycle detection, Kruskal's MST
