# 1D Dynamic Programming: House Robber & Longest Increasing Subsequence

> 1D DP is the most common and fundamental form of dynamic programming. This lesson uses two classic problems—House Robber and Longest Increasing Subsequence—to help you fully grasp the 1D DP mindset.

## House Robber: No Two Adjacent Houses

**Problem description:** You are a robber planning to rob houses along a street. Each house has a certain amount of money stashed. All houses in the same street are connected in a circle—wait, no, they're in a line. Adjacent houses have security systems connected, and **if you rob two adjacent houses on the same night, the police will be alerted.** Find the maximum amount of money you can rob without alerting the police.

### Meaning of dp[i]

> `dp[i]` = the maximum amount you can rob up to and including house i

### Transition Equation

**If you rob house i, you cannot rob house i-1. If you skip house i, the maximum is whatever you could get up to house i-1.**

```
dp[i] = max(
    dp[i-1],           # Skip house i, keep previous best
    dp[i-2] + nums[i]  # Rob house i, add to best up to house i-2
)
```

```python
def rob(nums):
    n = len(nums)
    if n == 0: return 0
    if n == 1: return nums[0]
    if n == 2: return max(nums[0], nums[1])
    
    dp = [0] * n
    dp[0] = nums[0]
    dp[1] = max(nums[0], nums[1])
    for i in range(2, n):
        dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
    return dp[-1]

print(rob([2, 7, 9, 3, 1]))   # 12
print(rob([1, 2, 3, 1]))      # 4
```

**Execution trace (nums = [2, 7, 9, 3, 1]):**

```
dp[0] = 2
dp[1] = max(2, 7) = 7
dp[2] = max(7, 2+9) = 11
dp[3] = max(11, 7+3) = 11
dp[4] = max(11, 11+1) = 12
```

**The answer is 12: rob house 0 (2) + house 2 (9) + house 4 (1) = 12.**

### Space Optimization

**Notice that dp[i] only depends on dp[i-1] and dp[i-2]—we only need two variables:**

```python
def rob_optimized(nums):
    prev2 = 0      # dp[i-2]
    prev1 = 0      # dp[i-1]
    for x in nums:
        cur = max(prev1, prev2 + x)
        prev2 = prev1
        prev1 = cur
    return prev1

print(rob_optimized([2, 7, 9, 3, 1]))   # 12
```

**Space drops from O(n) to O(1).** This is the most common optimization in 1D DP—"rolling variables."

## Longest Increasing Subsequence (LIS)

**Problem description:** Given an integer array, find the length of the longest strictly increasing subsequence. A subsequence does not need to be contiguous.

### Meaning of dp[i]

> `dp[i]` = the length of the longest increasing subsequence **ending at index i**

**Why emphasize "ending at i"?** Because this definition makes the transition equation work—to determine whether a new element can extend a previous subsequence, you need to know what the "last element" of that previous subsequence was.

### Transition Equation

**For dp[i], iterate over all j < i: if nums[j] < nums[i], it means nums[i] can extend the increasing subsequence ending at nums[j].**

```
dp[i] = max(dp[j] + 1)  for all j < i and nums[j] < nums[i]
```

**If no such j exists, dp[i] = 1 (start a new subsequence with itself).**

```python
def length_of_lis(nums):
    if not nums:
        return 0
    n = len(nums)
    dp = [1] * n          # Each element can at least form a subsequence of length 1
    for i in range(n):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)

print(length_of_lis([10, 9, 2, 5, 3, 7, 101, 18]))  # 4
```

**Execution trace (nums = [10, 9, 2, 5, 3, 7, 101, 18]):**

```
i=0: dp[0] = 1         (only [10])
i=1: dp[1] = 1         (only [9], 10 > 9 can't extend)
i=2: dp[2] = 1         (only [2])
i=3: dp[3] = 2         (2 < 5 → dp[2]+1 = 2)
i=4: dp[4] = 2         (2 < 3 → dp[2]+1 = 2)
i=5: dp[5] = 3         (5 < 7 → dp[3]+1 = 3)
i=6: dp[6] = 4         (7 < 101 → dp[5]+1 = 4)
i=7: dp[7] = 4         (3 < 18 → dp[4]+1 = 3, 7 < 18 → dp[5]+1 = 4)

Maximum is 4, corresponding to [2, 5, 7, 101] or [2, 3, 7, 101]
```

**Time complexity O(n²), space O(n).**

## WRONG: House Robber Missing the n=2 Case

**Directly using dp[1] = max(nums[0], nums[1]) assumes the array has at least 2 elements. If you forget to handle short arrays, you get an index error.**

```python
# WRONG: didn't handle n < 2 boundary case
def rob_short(nums):
    dp = [0] * len(nums)
    dp[0] = nums[0]
    dp[1] = max(nums[0], nums[1])    # IndexError! len(nums) might be only 1
    for i in range(2, len(nums)):
        dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
    return dp[-1]

# IndexError: list index out of range
```

**Fix: handle the `n == 0` and `n == 1` cases at the start of the function.**

```python
def rob_safe(nums):
    n = len(nums)
    if n == 0: return 0
    if n == 1: return nums[0]
    dp = [0] * n
    dp[0] = nums[0]
    dp[1] = max(nums[0], nums[1])
    for i in range(2, n):
        dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
    return dp[-1]
```

## WRONG: LIS dp Initialized to 0 Instead of 1

**In LIS, each element can at least form a subsequence of length 1 by itself, so the dp array should be initialized to all 1s. If initialized to 0, the final result will be 0.**

```python
# WRONG: dp initialized to 0
def lis_wrong(nums):
    n = len(nums)
    dp = [0] * n          # WRONG! Should be [1] * n
    for i in range(n):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)

print(lis_wrong([1, 2, 3]))   # 0, WRONG! Should be 3
```

**Why does it output 0?** Because dp is all zeros. While `max(dp[j] + 1)` can compute values, if an element has no smaller elements before it (like the first element), its dp value stays 0 forever. Ultimately `max(dp)` may return an incorrect result.

**Fix: change `dp = [0] * n` to `dp = [1] * n`.**

## WRONG: LIS Transition Uses <= Instead of <

**The problem asks for "strictly increasing." If you use `<=`, you'll count equal elements as part of an increasing sequence.**

```python
# WRONG: using <= results in non-strictly increasing
def lis_nonstrict(nums):
    n = len(nums)
    dp = [1] * n
    for i in range(n):
        for j in range(i):
            if nums[j] <= nums[i]:    # Used <= instead of <
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)

print(lis_nonstrict([1, 2, 2, 3]))   # 4, but strictly increasing would give 3
```

**If the problem requires strictly increasing (the standard LIS definition), using `<=` overcounts.** If the problem allows non-decreasing (Longest Non-decreasing Subsequence), then `<=` is correct. **Always confirm strict vs. non-strict when reading the problem.**

## Summary

- **House Robber**: `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`—the core is choosing between skipping and robbing, taking the maximum
- **LIS**: `dp[i] = max(dp[j] + 1)` for `j < i` and `nums[j] < nums[i]`, O(n²)
- **Common pattern in 1D DP**: define dp[i] → find the transition (usually depending on a few previous dp values) → determine base cases
- **Space optimization**: when you only depend on a limited number of predecessors, use rolling variables: O(n) → O(1)
- Common pitfalls: index errors on short arrays, wrong dp initialization values, confusing strict vs. non-strict conditions
