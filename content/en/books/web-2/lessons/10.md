# String methods: template literals, `split`/`join`/`includes`

> This lesson answers: what are the common string operations in JS? You know Python's string methods; the JS versions are similar, but with their own flavour — notably template literals.

## Template literals

JS uses backticks `` ` `` for template literals, which support **multi-line strings** and **interpolation**:

```js
const name = "Alice";
const age = 25;

// old-style concatenation
const greeting = "Hello, I'm " + name + ", and I'm " + age + " years old.";

// template literal (preferred)
const greeting = `Hello, I'm ${name}, and I'm ${age} years old.`;
```

Compared with Python:

```python
# Python f-string
greeting = f"Hello, I'm {name}, and I'm {age} years old."
```

**The key difference:** JS interpolates with `${}`, Python with `{}`; JS uses backticks, Python uses `f"..."`.

## Multi-line strings

```js
// old style (with an escaped newline)
const html = "<div>\n  <p>Hello</p>\n</div>";

// template literal (just hit enter)
const html = `
  <div>
    <p>Hello</p>
  </div>
`;
```

### Crash Site 1: stray indentation inside a template literal

```js
function render() {
  return `
    <div>
      <p>content</p>
    </div>
  `;
}
console.log(render());
// the output contains the leading indentation and newlines!
```

**Why it crashes:** every whitespace character inside a template literal — including newlines and indentation — is preserved. If you inject the resulting HTML into the DOM, those extra spaces can affect the layout. Fix it by dropping the opening newline or calling `.trim()`.

## Common string methods

```js
const str = "Hello, World!";

str.length;            // 13
str.toUpperCase();     // "HELLO, WORLD!"
str.toLowerCase();     // "hello, world!"
str.includes("World");  // true
str.startsWith("Hello"); // true
str.endsWith("!");      // true
str.indexOf("o");       // 4 (first occurrence)
str.lastIndexOf("o");   // 8
str.slice(0, 5);       // "Hello"
str.split(", ");        // ["Hello", "World!"]
str.replace("World", "JS"); // "Hello, JS!"
str.trim();            // strip leading and trailing whitespace
```

## `split` and `join`

```js
// split: string to array
const tags = "frontend,backend,fullstack";
tags.split(",");    // ["frontend", "backend", "fullstack"]

// join: array to string
const words = ["Hello", "World"];
words.join(" ");    // "Hello World"
words.join("-");    // "Hello-World"
```

### Crash Site 2: the `split` separator argument

```js
const csv = "apple,banana,cherry";
csv.split("");      // ["a", "p", "p", "l", "e", ",", "b", ...] (every character!)
csv.split();        // ["apple,banana,cherry"] (no split; returns the original as a single-element array!)
csv.split(",");     // ["apple", "banana", "cherry"] (correct)
```

**Why it crashes:** `split("")` splits the string into **individual characters**, while `split()` with no argument **does not split at all**. Neither behaves the way intuition suggests.

## `includes`: check for a substring

```js
const text = "JavaScript is awesome";

text.includes("Java");    // true
text.includes("java");    // false (case-sensitive!)
text.includes("Python");  // false
```

### Crash Site 3: case sensitivity

```js
const email = "ZhangSan@Example.com";
if (email.includes("@gmail.com")) {  // false! case mismatch
  console.log("it's Gmail");
}
```

**Why it crashes:** `includes` is case-sensitive. When you need a case-insensitive test:

```js
email.toLowerCase().includes("@gmail.com");  // true
```

## Strings are immutable

Just like in Python, JS strings cannot be modified in place:

```js
const str = "hello";
str[0] = "H";        // silent failure! str is still "hello"
console.log(str);    // "hello"

// to "change" a string, you must create a new one
const newStr = "H" + str.slice(1);  // "Hello"
```

## Comparison with Python

| Operation | Python | JavaScript |
|---|---|---|
| template / format | `f"{name}"` | `` `${name}` `` |
| multi-line string | `"""..."""` | `` `...` `` |
| contains | `"hello" in text` | `text.includes("hello")` |
| split | `text.split(", ")` | `text.split(", ")` |
| join an array | `"".join(arr)` | `arr.join("")` |
| strip whitespace | `text.strip()` | `text.trim()` |
| replace | `text.replace("a", "b")` | `text.replace("a", "b")` |
| length | `len(text)` | `text.length` |

## Recap

- Template literals use backticks and `${}` for interpolation, and support multi-line strings.
- `split(delimiter)` turns a string into an array; `join(separator)` turns an array into a string.
- `includes` tests for a substring and is case-sensitive.
- `split("")` splits into characters; `split()` with no argument does not split — both are common traps.
- Strings are immutable: every "modification" returns a fresh string.
