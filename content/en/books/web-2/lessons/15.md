# Creating and removing elements: `createElement` / `appendChild` / `remove`

> This lesson answers: how do you create and delete DOM elements dynamically? So far you have only modified elements that already existed. Now you will build elements from scratch and insert them into the page.

## Creating elements

```js
// create elements
const div = document.createElement('div');
const p = document.createElement('p');
const button = document.createElement('button');

// set content
div.textContent = "I am a newly created div";
p.textContent = "This is some text";

// set attributes
div.className = "card";
button.id = "submit";
button.textContent = "Submit";
```

`document.createElement(tagName)` creates a **detached DOM element** — it exists in memory but has not been inserted into the page's DOM tree, so nothing appears on screen yet.

## Inserting elements

### `appendChild`: add at the end

```js
const container = document.querySelector('#container');
const newItem = document.createElement('li');

newItem.textContent = "New item";
container.appendChild(newItem);  // inserted as the last child of container
```

### `insertBefore`: insert at a specific position

```js
const container = document.querySelector('#container');
const firstItem = container.firstElementChild;
const newItem = document.createElement('li');

newItem.textContent = "First";
container.insertBefore(newItem, firstItem);  // insert before firstItem
```

### Modern methods: `insertAdjacentHTML` / `append` / `prepend`

```js
const container = document.querySelector('#container');

// append: can add several elements or even strings
container.append(item1, item2, "plain text works too");

// prepend: insert at the start
container.prepend(newItem);

// insertAdjacentHTML: insert an HTML string at a chosen position
container.insertAdjacentHTML('beforeend', '<li>new item</li>');
// four positions: beforebegin, afterbegin, beforeend, afterend
```

## The full creation flow

```js
// goal: create <li class="todo-item">Buy milk</li> and insert it into <ul id="todo-list">

// 1. create the element
const li = document.createElement('li');

// 2. set attributes and content
li.className = "todo-item";
li.textContent = "Buy milk";

// 3. find the parent container
const list = document.querySelector('#todo-list');

// 4. insert
list.appendChild(li);
```

## Removing elements

### `remove`: delete itself

```js
const item = document.querySelector('.todo-item');
item.remove();  // remove itself from the DOM
```

### `removeChild`: a parent removes a child

```js
const list = document.querySelector('#todo-list');
const firstItem = list.firstElementChild;
list.removeChild(firstItem);  // the parent calls removeChild to delete a child
```

## Bulk creation: use a `DocumentFragment`

```js
// inefficient: every appendChild triggers a reflow
const list = document.querySelector('#todo-list');
for (let i = 0; i < 1000; i++) {
  const li = document.createElement('li');
  li.textContent = `Item ${i}`;
  list.appendChild(li);  // 1000 reflows!
}

// efficient: assemble everything in a DocumentFragment first
const fragment = document.createDocumentFragment();
for (let i = 0; i < 1000; i++) {
  const li = document.createElement('li');
  li.textContent = `Item ${i}`;
  fragment.appendChild(li);  // assembled in memory
}
list.appendChild(fragment);  // one reflow!
```

### Crash Site 1: setting `textContent`, then `innerHTML`

```js
const div = document.createElement('div');
div.textContent = "safe text";
div.innerHTML = "<strong>dangerous content</strong>";  // textContent is overwritten!
```

**Why it crashes:** setting `textContent` first and `innerHTML` afterwards means the latter wins. That is not a bug in itself, but it shows the precedence — **the later write beats the earlier one**. If the content came from a user, doing `textContent` first and then `innerHTML` is pure defence wasted.

### Crash Site 2: `appendChild` moves an existing element

```js
const item = document.querySelector('#list1 li:first-child');
const list2 = document.querySelector('#list2');

list2.appendChild(item);
// item has vanished from list1 — it was "moved" into list2
```

**Why it crashes:** if the node passed to `appendChild` is already in the DOM tree, it is **removed from its old position and inserted in the new one** — a move, not a copy. If you need a copy, use `cloneNode(true)`.

## Clearing an element's contents

```js
const container = document.querySelector('#container');

// method 1: textContent = "" (fastest)
container.textContent = "";

// method 2: innerHTML = "" (works, but parses)
container.innerHTML = "";

// method 3: loop with removeChild (broad compatibility, slower)
while (container.firstChild) {
  container.removeChild(container.firstChild);
}
```

### Crash Site 3: skipping elements when deleting by walking `children`

```js
const list = document.querySelector('#list');
for (let i = 0; i < list.children.length; i++) {
  list.removeChild(list.children[i]);
  // after each removal the rest shift left, but i keeps incrementing
}
// result: only half the elements are removed
```

**Why it crashes:** after deleting element 0, the old element 1 becomes element 0, but `i` is already `1`, so it now points at the original element 2 — element 1 was skipped. The fixes: iterate in reverse, or clear in one step with `textContent = ""`.

## Comparison with Python

Python has no DOM, but the `createElement` + `appendChild` pattern resembles building a data structure by hand:

```python
# analogy: build a nested structure
from dataclasses import dataclass
from typing import List

@dataclass
class Node:
    tag: str
    children: List['Node'] = None

# create
div = Node(tag="div")
div.children = []
p = Node(tag="p")
div.children.append(p)  # like appendChild
```

JS's `createElement` + `appendChild` is exactly this pattern, except the tree you are building is the one the browser actually renders.

## Recap

- `createElement(tag)` creates a detached DOM element (not yet on the page).
- `appendChild` inserts at the end; `insertBefore` inserts before a given sibling.
- `element.remove()` deletes the element itself; `parent.removeChild(child)` lets a parent delete a child.
- Passing an existing element to `appendChild` **moves** it rather than copying it; use `cloneNode(true)` to copy.
- For bulk creation, use `DocumentFragment` to reduce reflows.
- The cleanest, fastest way to empty an element is `textContent = ""`.
