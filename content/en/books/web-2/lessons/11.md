# What the DOM is: a tree of live objects

> This lesson answers: what exactly is the DOM? This is a concept unique to JS — Python has nothing like it. Understanding the DOM is the foundation of every frontend interaction.

## The DOM is a tree

You already know Python's data structures. The DOM (Document Object Model) is fundamentally a **tree** that the browser builds for you from your HTML.

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Alice's page</title>
  </head>
  <body>
    <h1>Hello</h1>
    <p class="intro">This is my page</p>
  </body>
</html>
```

Once the browser has parsed it, the DOM tree looks like this:

```
document
└── html
    ├── head
    │   └── title
    │       └── "Alice's page" (text node)
    └── body
        ├── h1
        │   └── "Hello" (text node)
        └── p.intro
            └── "This is my page" (text node)
```

Every HTML tag becomes an **element node**; the text between tags becomes a **text node**.

## What JS gets is a live object

The DOM's most important characteristic: **the DOM object JS receives is not a copy — it is the very same object the page uses.** Change it, and the page changes.

```js
// grab the h1 element
const h1 = document.querySelector('h1');

// change its text
h1.textContent = "Hello, world";

// the h1 on the page updates immediately
```

This is no different from working with data structures in Python: change a list and every reference to it sees the change. The DOM is the "page data structure" the browser exposes to you — you can read it and write it.

## `document`: the entry point

`document` is the **root** of the DOM; everything starts here:

```js
document.title;              // read the page title
document.title = "New title";    // change it (the browser tab updates!)
document.body;              // get the body element
document.documentElement;   // get the html element
document.head;              // get the head element
```

## Node types

The DOM contains more than element nodes:

```js
const h1 = document.querySelector('h1');

h1.nodeType;    // 1 (element node)
h1.nodeName;    // "H1" (tag name in upper case)

// text node
const textNode = h1.firstChild;
textNode.nodeType;  // 3 (text node)
textNode.nodeValue; // "Hello"
```

| nodeType | Meaning |
|---|---|
| 1 | element node (`div`, `p`, `h1` ...) |
| 3 | text node |
| 8 | comment node |
| 9 | document node (`document`) |

### Crash Site 1: writing to a text node the wrong way

```js
const h1 = document.querySelector('h1');
h1.nodeValue = "New text";  // does nothing! h1 is an element node, nodeValue is null
```

**Why it crashes:** an element node's `nodeValue` is `null`. To change text, use `textContent` or `innerHTML`. `nodeValue` only works on **text nodes**.

```js
// the right way
const textNode = h1.firstChild;  // get the text node
textNode.nodeValue = "New text";    // works
// or, more simply:
h1.textContent = "New text";       // recommended
```

### Crash Site 2: the script runs before the DOM has loaded

```html
<head>
  <script>
    // the body has not been parsed yet!
    const h1 = document.querySelector('h1');  // null
    h1.textContent = "Hello";  // TypeError
  </script>
</head>
<body>
  <h1>Old text</h1>
</body>
```

**Why it crashes:** a script in `<head>` runs before the body has been parsed, so `querySelector` returns `null` and the next line throws.

**Solutions:**

```html
<!-- option 1: put the script at the end of the body -->
<body>
  <h1>Old text</h1>
  <script>
    document.querySelector('h1').textContent = "Hello";  // works
  </script>
</body>

<!-- option 2: listen for DOMContentLoaded -->
<script>
  document.addEventListener('DOMContentLoaded', function() {
    document.querySelector('h1').textContent = "Hello";  // works
  });
</script>
```

## Comparison with Python

Python has no DOM, but you can map it to concepts you already know:

| Python concept | DOM equivalent |
|---|---|
| list / dict | the DOM tree (a nested object structure) |
| `dict["key"]` | `element.children`, `element.querySelector()` |
| `obj.attr = val` | `element.textContent = val` |
| tree traversal | DOM tree traversal |
| mutable object | a DOM object (changes take effect immediately) |

## Recap

- The DOM is a **tree-shaped data structure** the browser builds from your HTML.
- `document` is the root of the DOM; every operation starts there.
- DOM objects are "live": when JS changes one, the page updates at once.
- An element node's `nodeValue` is `null`; to change text, use `textContent`.
- Scripts must run after the DOM is ready (end of body, or `DOMContentLoaded`).

```quiz
type: js
q: Given the HTML <div id="app"><p class="msg">Hello</p></div>, write a function getMessageText() that gets the element whose class is "msg" and returns its textContent. Handle the case where the element is not found.
func: getMessageText
starter: |
  function getMessageText() {
      // use querySelector to find the element and return its textContent
      return "";
  }
html: |
  <div id="app">
    <p class="msg">Hello</p>
  </div>
cases: |
  -> "Hello"
hint: document.querySelector('.msg').textContent;
explain: querySelector finds an element by CSS selector, and textContent reads its text. This is the basic DOM pattern: find the element, then read a property.
```
