# Drawing Basic Shapes: Rectangles, Ovals, Lines and Polygons

> In the previous lesson we met the canvas; in this one we start drawing for real. tkinter provides a small set of simple drawing commands, and learning these few is enough to produce most interface elements.

## The Five Most Useful Shapes

**The core shapes the Canvas can draw are just these; memorise them and you are set:**

| Method | What it draws | Argument form |
|---|---|---|
| `create_rectangle(x1,y1,x2,y2)` | Rectangle | Top-left + bottom-right |
| `create_oval(x1,y1,x2,y2)` | Oval | Opposite corners of the bounding box |
| `create_line(x1,y1,x2,y2,...)` | Straight line | Multiple points joined in order |
| `create_polygon(x1,y1,x2,y2,...)` | Polygon | All vertices |
| `create_arc(x1,y1,x2,y2)` | Arc | Opposite corners of the bounding box |

**Notice that ovals and arcs are both positioned using a bounding rectangle.** You supply a rectangular frame and tkinter draws the largest oval that fits inside it.

## Rectangles and Ovals

```python
import tkinter as tk

root = tk.Tk()
canvas = tk.Canvas(root, width=400, height=300, bg="white")
canvas.pack()

# Rectangle
canvas.create_rectangle(20, 20, 120, 80, fill="tomato")
# Oval (bounding box from 150,20 to 300,100)
canvas.create_oval(150, 20, 300, 100, fill="gold")

root.mainloop()
```

**`fill` sets the interior colour and `outline` sets the border colour.** The default is a black border; if you want no border at all, write `outline=""`.

```python
canvas.create_oval(50, 120, 150, 220, fill="green", outline="")  # solid circle, no border
```

## Lines: Multiple Segments Make a Polyline

**`create_line` accepts any number of points and joins them in sequence:**

```python
# Draw a "Z" shape
canvas.create_line(10, 130, 90, 130, 10, 190, 90, 190, fill="blue", width=3)
```

Common options:

| Option | Meaning |
|---|---|
| `fill` | Line colour |
| `width` | Line thickness in pixels |
| `dash` | Dash pattern, e.g. `(5, 3)` means 5 on, 3 off |
| `arrow` | Arrowhead: `tk.FIRST` / `tk.LAST` / `tk.BOTH` |
| `smooth` | Set to `True` to turn the polyline into a smooth curve |

```python
canvas.create_line(10, 10, 50, 50, 90, 10, 130, 50, smooth=True, fill="purple", width=2)
```

## Polygons

**`create_polygon` is like `create_line`, but it automatically joins the last point back to the first to form a closed shape:**

```python
# Draw a triangle
canvas.create_polygon(200, 20, 250, 100, 150, 100, fill="orange", outline="red")
```

The argument order is simply the vertices in turn: `x1,y1, x2,y2, x3,y3...`.

**Polygons also support `fill` and `outline`**, and you can use `smooth=True` for a smoothed deformation.

## The Defaults for `fill` and `outline`

**A lot of people draw a shape and find that it is "not the colour they expected" — the problem is usually here:**

```python
canvas.create_rectangle(10, 10, 100, 80)  # what colour is this?
```

**The default is `fill=""` (no fill, transparent) plus `outline="black"` (a black border).** So the line above draws a rectangle that has **only a black border and is empty inside.**

**Keep this rule of thumb in mind:**

- Want a solid fill? You must write `fill="colour"` explicitly.
- Want no border? You must write `outline=""` explicitly.
- Border thickness? Use `width=N` (the default is 1).

## Crash Site One: Forgetting the Quotes Around a Colour

```
canvas.create_rectangle(10, 10, 100, 80, fill=tomato)
```

**Symptom:** `NameError: name 'tomato' is not defined` and the program crashes on the spot.

**Cause:** colour values must be **strings**. Without quotes, `tomato` is treated as a variable name, so Python goes looking for a variable called `tomato` and complains when it cannot find one.

Correct form:

```python
canvas.create_rectangle(10, 10, 100, 80, fill="tomato")
```

**Colour names tkinter understands** include `"red"`, `"blue"`, `"green"`, `"yellow"`, `"orange"`, `"purple"`, `"pink"`, `"gray"`, `"black"`, `"white"`, and finer shades such as `"lightblue"`, `"darkgreen"`, `"tomato"`, `"gold"`. Hexadecimal values work too: `fill="#ff6600"`.

## Crash Site Two: Thinking a New Shape Edits the Old One

```
canvas = tk.Canvas(root, width=400, height=300)
canvas.create_rectangle(10, 10, 100, 80, fill="red")
canvas.create_rectangle(10, 10, 100, 80, fill="blue")  # draws a new one on top
```

**Many learners assume the second line "modifies" the first rectangle, but it actually draws a brand-new blue rectangle in exactly the same place, covering the red one.** Once a Canvas shape has been drawn it exists independently; to change it you must use methods such as `coords()` and `itemconfig()` (covered in Lesson 4).

## Crash Site Three: Coordinates Outside the Canvas, Nothing Visible

```
canvas.create_oval(500, 500, 600, 600, fill="red")  # the canvas is only 400x300
```

**The shape has been drawn outside the canvas, so you see nothing on screen — and the program raises no error.** This is the quietest kind of bug the Canvas produces: no error, just an empty display. While debugging, `canvas.bbox(item_id)` will give you the shape's actual bounding box, so you can check whether it lies inside the visible area.

## Using RGB Hexadecimal Colours

**As well as named colours, `#rrggbb` lets you control a colour precisely:**

```python
canvas.create_rectangle(10, 10, 80, 60, fill="#3498db")   # a shade of blue
canvas.create_rectangle(10, 70, 80, 120, fill="#e74c3c")  # a shade of red
canvas.create_rectangle(10, 130, 80, 180, fill="#2ecc71") # a shade of green
```

**The six hex digits split into three pairs: first two for red, middle two for green, last two for blue**, each ranging from 00 to ff (0 to 255). `#ff0000` is pure red, `#0000ff` pure blue, `#000000` black and `#ffffff` white.

## Summary

- Rectangles and ovals are positioned by **two opposite corners**; an oval is "the largest oval that fits the bounding box"
- Lines use `create_line` to join multiple segments; polygons use `create_polygon` and close automatically
- `fill` fills, `outline` borders, `width` sets thickness, `dash` makes it dashed
- The defaults are `fill=""` (transparent) and `outline="black"` (black border); you must write `fill` for a solid shape
- Colours need quotes and may be either a colour name or `#rrggbb`
- A shape drawn outside the canvas raises no error and shows nothing — a classic silent bug
