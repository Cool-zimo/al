# Sound and Text: Making Your Game Speak and Play

> So far your game has been "mute" — just drawing boxes. This lesson adds sound effects and text: a "ding" when collecting coins, and "Game Over" displayed on screen.

## Sound: How pygame.mixer Works

**pygame's sound system is called `mixer`.** Its workflow: first prepare the "playback device" (initialize), then load a sound file into an object, then `play()` whenever you want.

```python
import pygame

pygame.mixer.init()                          # Initialize the mixer
ding = pygame.mixer.Sound("coin.wav")        # Load a sound effect
ding.play()                                  # Play once
```

**A `Sound` object is loaded once and played many times.** It stays in memory, unlike music which streams from disk. `play()` accepts parameters:

| Usage | Meaning |
|---|---|
| `ding.play()` | Play 1 time |
| `ding.play(loops=2)` | Play 3 times total (original + 2 loops) |
| `ding.play(loops=-1)` | Loop infinitely (background music use) |
| `ding.play(maxtime=500)` | Play only 500 milliseconds |
| `ding.set_volume(0.5)` | Volume 0.0~1.0 |

**Background music uses a separate channel**, managed by the `pygame.mixer.music` module:

```python
pygame.mixer.music.load("bgm.mp3")
pygame.mixer.music.play(-1)          # Loop forever
pygame.mixer.music.set_volume(0.3)
# pygame.mixer.music.stop()
```

**Rule of thumb**: short sound effects use `Sound` + `play()`; long background tracks use the `music` module. They don't interfere with each other.

## Complete Example: Key to Play Sound + Display Text

```python
import pygame

pygame.init()
pygame.mixer.init()
screen = pygame.display.set_mode((600, 400))
pygame.display.set_caption("Sound and Text")
clock = pygame.time.Clock()

# Generate a "beep" programmatically so it runs even without assets
sample_rate = 22050
sound = pygame.mixer.Sound(buffer=bytes([128] * sample_rate))   # 1 sec silent placeholder

font = pygame.font.Font(None, 48)               # Default font, size 48
text = font.render("Hello Pygame", True, (255, 255, 255))

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_SPACE:
                sound.play()                    # Play sound on SPACE

    screen.fill((30, 30, 60))
    screen.blit(text, (180, 160))
    pygame.display.flip()
    clock.tick(60)

pygame.quit()
```

## Text: font.render in Three Steps

**Text isn't drawn as lines — it's a "picture of words printed on an image".** So it takes three steps:

1. **Create a font**: `pygame.font.Font(path, size)` or `pygame.font.SysFont(name, size)`
2. **Render into a Surface**: `font.render(string, antialias, color)`
3. **Blit onto the screen**: `screen.blit(surface, position)`

```python
font = pygame.font.Font(None, 72)                       # None = default font
img = font.render("Score 100", True, (255, 200, 0))      # Antialiased, gold
screen.blit(img, (250, 100))
```

**The second parameter `True` means antialiasing is on**, making edges smoother; the third is the foreground color. **For a background color, pass a fourth parameter**: `render("Hi", True, foreground, background)`.

## Crash Scene 1: Chinese Characters Show as Tofu Boxes (Garbled/Empty)

```python
font = pygame.font.Font(None, 48)
img = font.render("游戏结束", True, (255, 255, 255))
screen.blit(img, (100, 100))
```

**Symptom**: Where Chinese characters should appear, there's blank space or a mess of "□□□" boxes and question marks, while English letters render fine.

**Why**: `Font(None)` uses pygame's built-in default font, which **doesn't contain Chinese glyphs**. It doesn't recognize "游" so it can't draw it — either leaving it blank or drawing a replacement character.

**Correct approach: specify a font file that includes Chinese.**

```python
# Windows
font = pygame.font.Font("C:/Windows/Fonts/msyh.ttc", 48)      # Microsoft YaHei
# macOS
font = pygame.font.Font("/System/Library/Fonts/PingFang.ttc", 48)
# Cross-platform safe: use SysFont to find available Chinese names
font = pygame.font.SysFont("noto sans cjk sc", 48)            # Common on Linux
```

**If you're unsure what fonts are available, list them:**

```python
print(pygame.font.get_fonts())      # Returns a list of system font names (lowercase)
```

**The safest approach is to place the font file (`.ttf`) next to `main.py` and load it with a relative path** — so when others download your code, it runs regardless of what's installed on their system.

## Crash Scene 2: Loading Sound Without Initializing mixer

```python
import pygame
pygame.init()                       # Only initialized main modules
ding = pygame.mixer.Sound("coin.wav")
```

**Symptom**: `pygame.error: mixer not initialized`.

**Why**: `pygame.init()` initializes most modules, but `mixer`'s parameters (sample rate, channel count) usually need to be specified separately, so the safe practice is to **explicitly call `pygame.mixer.init()`**. Also, `Sound` only accepts formats like `WAV` and `OGG` — **`Sound("a.mp3")` may also error out** (depending on pygame's audio backend at compile time).

**Safe practice**: use `.wav` or `.ogg` for sounds; check file existence before playing.

## Crash Scene 3: render with Chinese Quotes or Newlines

```python
img = font.render("Line 1\nLine 2", True, (255,255,255))
```

**Symptom**: `\n` is drawn as a small box, or the whole thing is garbled. `font.render` **doesn't support multi-line text**.

**To write multiple lines, render and blit each line yourself, calculating line spacing:**

```python
lines = ["Score 100", "High 250", "Press R to restart"]
y = 100
for line in lines:
    img = font.render(line, True, (255, 255, 255))
    screen.blit(img, (200, y))
    y += img.get_height() + 8        # Line spacing = text height + 8 pixels
```

## Crash Scene 4: Setting Volume to 100

```python
ding.set_volume(100)        # Legal, but…
```

**Symptom**: Distorted, harsh sound, or `ValueError: volume must be between 0.0 and 1.0`.

**`set_volume`'s range is 0.0 to 1.0** (a decimal representing a "multiplier"), not 0~100. Write `set_volume(0.6)`.

## Summary

- Two paths for sound: short effects use `Sound` + `play()`, background music uses `mixer.music`
- Must call `pygame.mixer.init()` before playing; prefer `.wav`/`.ogg`
- Text is an image: `Font` creates font → `render` to Surface → `blit` to screen
- Chinese requires specifying a Chinese font file — don't use `Font(None)`
- `render` doesn't support newlines; render multiple lines separately, accumulating y
- Volume is 0.0~1.0 as a decimal, not a percentage
