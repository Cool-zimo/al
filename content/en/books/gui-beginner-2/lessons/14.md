# Notebook Tab Pages: A Multi-Page Interface

> When one window has too much content, piling it all together gets crowded. Notebook provides "tabbed" switching, placing different functions on different pages — the same idea as browser tabs.

## What a Notebook Is

**A Notebook is a "container that switches between pages":** it holds several Frames (one per page), with a tab bar across the top that you click to switch.

```python
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.title("Tabbed Example")

notebook = ttk.Notebook(root)
notebook.pack(fill="both", expand=True)

# First page
page1 = ttk.Frame(notebook)
ttk.Label(page1, text="Content of the first page").pack(padx=20, pady=20)

# Second page
page2 = ttk.Frame(notebook)
ttk.Label(page2, text="Content of the second page").pack(padx=20, pady=20)

# Add the pages to the notebook with tab text
notebook.add(page1, text="Home")
notebook.add(page2, text="Settings")

root.mainloop()
```

**Each page is a Frame, and the Frame holds the actual widgets.**

## Why Pages Use a Frame

**A Frame is a "blank container" whose job is to group a set of widgets into one unit.** Every page of a Notebook must be a Frame (or any container widget) so that the whole page can be shown or hidden together.

```
Notebook
├── Frame (Home)   -> Label, Button, Entry...
├── Frame (Settings)-> Checkbutton, Combobox...
└── Frame (About)   -> Label...
```

**This is the basic idea of "nested containers" in a GUI:** large containers hold smaller containers, organising everything in layers.

## add and insert: Adding or Inserting Pages

```python
notebook.add(page1, text="Home")               # append at the end
notebook.insert(0, page2, text="Settings")     # insert at index 0 (front)
```

**`text` is the text shown on the tab.** You can also supply an `image` for an icon or use `compound` to control how text and image are arranged.

## Switching and Listening

**`notebook.select()` returns the ID of the currently displayed page; `notebook.index(page_id)` returns its index.**

**Listen for switches with the `<<NotebookTabChanged>>` event:**

```python
def on_change(event):
    selected_id = notebook.select()
    index = notebook.index(selected_id)
    print("Switched to page", index)

notebook.bind("<<NotebookTabChanged>>", on_change)
```

**Note:** inside the callback, `notebook.select()` returns an internal ID (something like `.!notebook.!frame`), not the `page1` variable you created.

## Crash Site One: The Page's Widgets Do Not Appear (Forgot pack/grid)

```
page1 = ttk.Frame(notebook)
ttk.Label(page1, text="Content")       # forgot to pack
notebook.add(page1, text="Home")
```

**Symptom:** the tab exists but the content is blank.

**Cause:** the widgets inside the Frame still need to be laid out (pack/grid). Adding the Frame to the Notebook only solves "put the page into the notebook", not "how to arrange the inside of the page".

## Crash Site Two: add Order Is the Tab Order

**The left-to-right order of the tab bar = the order in which `add` is called.** To reorder, rearrange the `add` calls or use `insert`.

```
notebook.add(page2, text="Settings")   # added first -> on the left
notebook.add(page1, text="Home")       # added second -> on the right
```

**Result: the tab bar reads "Settings | Home", the opposite of what you might expect. Remember that add order is display order.**

## Crash Site Three: Using place on a Page Causes Strange Switching

**For pages inside a Frame, stick to pack/grid. If you use `place` (absolute positioning), switching tabs may leave "leftovers" or produce a broken layout.** For simple interfaces, pack and grid are enough.

## A Useful Three-Page Example

```python
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.title("Multi-Function Window")

notebook = ttk.Notebook(root)
notebook.pack(fill="both", expand=True)

# Home page: one button
page_home = ttk.Frame(notebook)
ttk.Label(page_home, text="Welcome", font=("Arial", 16)).pack(pady=20)
ttk.Button(page_home, text="Start").pack()

# Settings page: a few options
page_settings = ttk.Frame(notebook)
ttk.Checkbutton(page_settings, text="Run at startup").pack(anchor="w", padx=10, pady=5)
ttk.Checkbutton(page_settings, text="Show notifications").pack(anchor="w", padx=10, pady=5)
ttk.Label(page_settings, text="Theme:").pack(anchor="w", padx=10)
ttk.Combobox(page_settings, values=["Light", "Dark"]).pack(padx=10)

# About page: text
page_about = ttk.Frame(notebook)
ttk.Label(page_about, text="Version 1.0\nAuthor: Alice",
          justify="center").pack(pady=30)

notebook.add(page_home, text="Home")
notebook.add(page_settings, text="Settings")
notebook.add(page_about, text="About")

root.mainloop()
```

## Switching Programmatically

**You can switch to a page from code using `notebook.select(page_id)` or `notebook.select(index)`.**

```python
def goto_settings():
    notebook.select(1)          # switch to the second page (index starts at 0)

ttk.Button(page_home, text="Go to Settings", command=goto_settings).pack()
```

**This is common in "wizard-style" interfaces:** fill in one page, click "Next", and the program switches to the next page automatically.

## Summary

- A Notebook is a tabbed container; each page is a Frame
- Use `add(frame, text="tab label")` to add pages; the order determines the display order
- The widgets inside a page still need pack/grid layout
- `<<NotebookTabChanged>>` listens for switches; `select()` gets the current page
- `select(index)` switches programmatically
- A Frame is the basic unit of container composition, used to group "a set of widgets"
