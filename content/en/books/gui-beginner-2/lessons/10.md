# Project: A Simple Pong Game

> This lesson combines animation, keyboard input and collision detection into a playable pong game: the ball bounces, the paddle is moved with the arrow keys, you score a point for catching the ball and lose one when it gets past you.

## What We Are Building

**The game has three elements: a ball, a paddle and a score.**

```
┌─────────────────────┐
│                     │
│      o  ball         │
│                     │
│                ███  paddle │
│ Score: 3            │
└─────────────────────┘
```

| Element | Role |
|---|---|
| Ball | Moves automatically, bounces off walls, bounces off the paddle |
| Paddle | Controlled by the player, moves left and right to catch the ball |
| Score | +1 for catching the ball, -1 when it is missed |

## Step 1: Draw the Ball and the Paddle

```python
import tkinter as tk

root = tk.Tk()
root.title("Pong Game")
canvas = tk.Canvas(root, width=400, height=300, bg="white")
canvas.pack()

# Ball: bounding box
ball = canvas.create_oval(190, 50, 210, 70, fill="tomato")
# Paddle
paddle = canvas.create_rectangle(160, 270, 240, 285, fill="dodgerblue")

# Score text
score = 0
score_text = canvas.create_text(50, 20, text=f"Score: {score}", font=("Arial", 14))
```

## Step 2: Make the Ball Move

**Use recursive `after`, moving the ball each frame and handling wall bounces:**

```python
ball_x, ball_y = 190, 50
ball_r = 10          # radius
dx, dy = 3, 3

def move_ball():
    global ball_x, ball_y, dx, dy, score
    ball_x += dx
    ball_y += dy

    # Bounce off left and right walls
    if ball_x <= 0 or ball_x >= 400 - ball_r*2:
        dx = -dx
    # Bounce off the top wall
    if ball_y <= 0:
        dy = -dy
    # Off the bottom (missed)
    if ball_y >= 300:
        dy = -dy          # bounce it back, do not end
        score -= 1
        update_score()

    canvas.coords(ball, ball_x, ball_y, ball_x+ball_r*2, ball_y+ball_r*2)
    root.after(20, move_ball)

def update_score():
    global score
    canvas.itemconfig(score_text, text=f"Score: {score}")
```

## Step 3: Keyboard Control for the Paddle

**Move the paddle with the arrow keys (or A/D), keeping it inside the canvas:**

```python
paddle_x = 160
paddle_w = 80

def move_paddle(event):
    global paddle_x
    if event.keysym in ("Left", "a", "A"):
        paddle_x = max(0, paddle_x - 20)
    elif event.keysym in ("Right", "d", "D"):
        paddle_x = min(400 - paddle_w, paddle_x + 20)
    canvas.coords(paddle, paddle_x, 270, paddle_x + paddle_w, 285)

root.bind("<Key>", move_paddle)
```

**`min(400 - paddle_w, ...)` guarantees that the paddle's right edge never exceeds the canvas width.**

## Step 4: Collision Detection — The Ball Meets the Paddle

**The simplest collision check: does the ball land within the paddle's rectangle?** When the bottom of the ball passes the paddle's top edge and the ball's x lies within the paddle's range, it counts as "caught".

```python
def move_ball():
    global ball_x, ball_y, dx, dy, score
    ball_x += dx
    ball_y += dy

    if ball_x <= 0 or ball_x >= 400 - ball_r*2:
        dx = -dx
    if ball_y <= 0:
        dy = -dy
    if ball_y >= 300:
        dy = -dy
        score -= 1
        update_score()

    # Collision detection: ball bottom reaches the paddle area
    if (ball_y + ball_r*2 >= 270 and ball_y + ball_r*2 <= 300 and
        ball_x + ball_r >= paddle_x and ball_x + ball_r <= paddle_x + paddle_w):
        dy = -abs(dy)      # bounce upwards (guaranteed)
        score += 1
        update_score()

    canvas.coords(ball, ball_x, ball_y, ball_x+ball_r*2, ball_y+ball_r*2)
    root.after(20, move_ball)
```

**Why `dy = -abs(dy)`?** It prevents the ball from getting "stuck" inside the paddle and bouncing repeatedly. Forcing it upward makes it bounce exactly once.

## Crash Site One: The Collision Check "Sticks" and Scores Repeatedly

```
if ball_y + ball_r*2 >= 270 and ...:
    dy = -dy        # ball is still inside the paddle range, hits again next frame
    score += 1
```

**Symptom:** as soon as the ball touches the paddle, the score rockets into the dozens.

**Cause:** after `dy = -dy` the ball moves up one frame, but may still be inside the paddle's range, so the next frame registers another collision and bounces again, bouncing back and forth.

**Fix:** use `dy = -abs(dy)` to force the upward direction, and require that the ball is "moving downward" (`dy > 0`):

```python
if (dy > 0 and ball_y + ball_r*2 >= 270 and ball_y + ball_r*2 <= 300 and
    ball_x + ball_r >= paddle_x and ball_x + ball_r <= paddle_x + paddle_w):
    dy = -abs(dy)
    score += 1
    update_score()
```

**`dy > 0` guarantees that only a "falling ball" is counted as caught**; a ball that has already bounced up will not trigger the check again. This is a classic debouncing technique for collision detection.

## Crash Site Two: Forgetting mainloop / Forgetting to Start move_ball

```
move_ball()         # if this line is missing, the ball will not move
root.mainloop()
```

**Symptom:** the window appears, the ball is stationary, the paddle keys respond (they are bound), but the ball does not move.

**Cause:** the animation function `move_ball` must be called once by hand to "start" the recursion. Without that call the recursive chain never begins.

## Crash Site Three: Focus Issues When Moving the Paddle

**If focus is not on root (for example you clicked another widget first), the arrow keys do nothing.**

**Countermeasure:** bind on `root` rather than the canvas, or force `root.focus_set()` when the program starts. In a game, keyboard bindings generally live on root.

## Upgrade: Make the Ball Speed Up as the Score Rises

**Increasing difficulty is a basic part of game design:**

```python
def move_ball():
    global ball_x, ball_y, dx, dy, score
    # Speed rises with the score
    speed = 3 + score * 0.3
    # Preserve direction with the sign of dx/dy
    step_x = speed if dx > 0 else -speed
    step_y = speed if dy > 0 else -speed
    ball_x += step_x
    ball_y += step_y
    ...
```

**Note:** this example keeps things simple with a fixed step. The rigorous approach is to use dt (Lesson 8), but a fixed step is usually acceptable for a small tkinter game.

## Summary

- Pong = an automatically moving ball + a paddle controlled by the keyboard + collision detection
- The ball is driven by recursive `after`; reverse `dx/dy` on wall contact
- The paddle uses arrow keys plus `coords` for absolute positioning and `min/max` for boundary clamping
- Collision = ball bottom y is in the paddle's range and ball x lies within the paddle's width
- To avoid repeated triggers: use `dy > 0` to mean "falling" and `dy = -abs(dy)` to force an upward bounce
- Remember to call `move_ball()` once by hand to start the animation
