# Collision Detection: rect.colliderect and spritecollide

> The most common need in games: "Did the ball hit the paddle?" "Did the bullet hit the enemy?" This lesson covers pygame's collision detection tools — from the simplest Rect collision to批量 detection between sprite groups.

## Rect Collision: colliderect

**To check if two Rects overlap, use `rect1.colliderect(rect2)`:**

```python
rect1 = pygame.Rect(100, 100, 50, 50)
rect2 = pygame.Rect(130, 130, 50, 50)
print(rect1.colliderect(rect2))   # True (they overlap)
```

**Returns True if the two rectangles share any area — meaning "they collided".** This is the most basic collision detection in 2D games: simple and fast.

## Collision Between Sprites

**A Sprite has a `rect` attribute, so just use rect for collision:**

```python
class Player(pygame.sprite.Sprite):
    ...

class Enemy(pygame.sprite.Sprite):
    ...

player = Player()
enemy = Enemy()

if player.rect.colliderect(enemy.rect):
    print("Collision!")
```

**Note**: `colliderect` requires both sides to be Rect objects. A sprite itself is not a Rect — you must use `sprite.rect`.

## spritecollide: Collision Between a Sprite and a Group

**`pygame.sprite.spritecollide(sprite, group, dokill)` checks for collisions between one sprite and a group of sprites, returning a list of the sprites that collided:**

```python
class Player(pygame.sprite.Sprite):
    ...

class Coin(pygame.sprite.Sprite):
    ...

player = Player()
coins = pygame.sprite.Group(Coin(), Coin(), Coin())

# Detect which coins the player touched
hits = pygame.sprite.spritecollide(player, coins, dokill=True)
# dokill=True: remove the collided ones (collect the coins)
# hits is a list; its length is the number collected
score += len(hits)
```

**Three parameters**: the sprite to check, the target group, and whether to delete the collided sprites.

**This is pygame's most commonly used collision method** — one主体 against a group of objects.

## groupcollide: Collision Between Two Groups

**`pygame.sprite.groupcollide(groupA, groupB, dokillA, dokillB)` detects collisions between two groups:**

```python
bullets = pygame.sprite.Group()
enemies = pygame.sprite.Group()

hits = pygame.sprite.groupcollide(bullets, enemies, True, True)
# True, True: both bullets and enemies are removed (hit = disappear)
```

**Typical use cases**: bullets hitting enemies, player touching enemies. Two True values means both sides get deleted.

## Complete Example: Player Collects Coins

```python
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
clock = pygame.time.Clock()

class Player(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.image = pygame.Surface((50, 50))
        self.image.fill((0, 200, 255))
        self.rect = self.image.get_rect(center=(400, 300))

    def update(self):
        # Mouse control
        self.rect.center = pygame.mouse.get_pos()

class Coin(pygame.sprite.Sprite):
    def __init__(self, x, y):
        super().__init__()
        self.image = pygame.Surface((20, 20))
        self.image.fill((255, 215, 0))
        self.rect = self.image.get_rect(center=(x, y))

player = Player()
player_group = pygame.sprite.Group(player)

coins = pygame.sprite.Group(
    Coin(100, 100), Coin(300, 200), Coin(500, 400), Coin(700, 150)
)

score = 0
font = pygame.font.SysFont(None, 36)

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    player_group.update()

    # Collision detection: player collects coins
    hits = pygame.sprite.spritecollide(player, coins, dokill=True)
    score += len(hits)

    screen.fill((0, 0, 0))
    coins.draw(screen)
    player_group.draw(screen)
    score_text = font.render(f"Score: {score}", True, (255, 255, 255))
    screen.blit(score_text, (10, 10))
    pygame.display.flip()
    clock.tick(60)

pygame.quit()
```

## Crash Scene 1: Passing a Sprite Directly to colliderect

```
pygame.sprite.spritecollide(player, coins, True)   # Correct: pass a sprite
player.rect.colliderect(coins)                      # Wrong: coins is a Group, not a Rect
```

**`colliderect` wants a Rect; `spritecollide` wants "one sprite + one group".** Don't mix them up.

## Crash Scene 2: Forgetting dokill=True, Coins Never Disappear

```
hits = pygame.sprite.spritecollide(player, coins, dokill=False)
score += len(hits)
```

**Symptom**: The player walks through the coin pile but the coins stay, and the score might keep incrementing.

**Why**: `dokill=False` only detects — it doesn't delete. If you just want to "count" them, that's fine; but if you want to "collect" them, you must use `dokill=True`.

## Crash Scene 3: Collision Box Too Big / Too Small

**Using the entire sprite image's Rect for collision can mean "it looks like they didn't touch but the game says they did" because of padding in the image.**

**Solution: use `rect.inflate(-dx, -dy)` to shrink the collision box, or define a custom collision Rect:**

```python
self.hitbox = self.rect.inflate(-10, -10)   # Shrink collision box by 10 pixels
# For collision, use self.hitbox.colliderect(other.rect)
```

**This is a common technique for "feel-good" collisions** — a slightly smaller hitbox feels more forgiving to the player.

## Circle Collision (Distance Check)

**Some games need "distance-based" collision (like explosion radius or circular characters):**

```python
import math

def circle_collide(rect1, rect2, r1, r2):
    dx = rect1.centerx - rect2.centerx
    dy = rect1.centery - rect2.centery
    dist = math.hypot(dx, dy)        # Euclidean distance
    return dist < (r1 + r2)
```

**`math.hypot(dx, dy)` calculates the distance between two points** — cleaner than writing `sqrt(dx*dx + dy*dy)` yourself.

## Summary

- `rect.colliderect(other_rect)` checks if two rectangles overlap
- For sprite collision, use `sprite.rect`, not the sprite itself
- `spritecollide(sprite, group, dokill)` checks one against many, returns a collision list
- `groupcollide(groupA, groupB, dokillA, dokillB)` checks collisions between two groups
- `dokill=True` automatically removes collided sprites
- Adjust collision box size with `rect.inflate` to improve game feel
- For circle collision, use distance check with `math.hypot`
