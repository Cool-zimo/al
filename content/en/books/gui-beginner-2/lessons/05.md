# Project: A Drawing Pad That Draws and Clears

> The previous lessons covered Canvas drawing and manipulation in pieces. This one ties them together into something genuinely useful — a drawing pad you control with the mouse. The core pattern is "event plus coordinates plus a line".

## What We Are Building

**Goal: as the mouse is dragged across the canvas it leaves a trail, and a button clears the canvas.**

```
Interface:
[  Clear  ]                 <- Button
┌─────────────────┐
│                 │         <- Canvas (drag the mouse to draw here)
│   strokes here   │
│                 │
└─────────────────┘
```

**The key actions:** pressing the mouse "puts the pen down", dragging it "draws a continuous line", and releasing it "lifts the pen". These correspond neatly to three mouse events.

## Step 1: Build the Interface Skeleton

**A Canvas plus a Button, laid out with pack:**

```python
import tkinter as tk

root = tk.Tk()
root.title("Simple Drawing Pad")

canvas = tk.Canvas(root, width=500, height=400, bg="white")
canvas.pack()

tk.Button(root, text="Clear").pack()

root.mainloop()
```

This gives you a white canvas with a button. **At this point you cannot draw anything yet**, because no mouse events have been bound.

## Step 2: Understanding the Three Mouse Events

**The Canvas has three crucial mouse events:**

| Event | When it fires | What we use it for |
|---|---|---|
| `<ButtonPress-1>` | Left button pressed | Record the "put pen down" point |
| `<B1-Motion>` | Left button held while moving | Draw from the previous point to the current one |
| `<ButtonRelease-1>` | Left button released | End this stroke |

**In `<B1-Motion>`, `B1` stands for Button 1 (the left button).** While you hold and move, it fires at high frequency, and each time it fires we draw one short segment.

## Step 3: A Global Variable for the "Previous Point"

**The core idea: each time we drag, take the current coordinates, join them to the "previous point" with a short line, then update the current point so it becomes the new "previous point".** A chain of tiny segments produces a stroke.

```python
last_x, last_y = None, None   # the previous point's coordinates

def on_press(event):
    global last_x, last_y
    last_x, last_y = event.x, event.y   # pen down: record the start

def on_drag(event):
    global last_x, last_y
    x, y = event.x, event.y
    # Draw from (last_x, last_y) to (x, y)
    canvas.create_line(last_x, last_y, x, y, width=2, fill="black")
    last_x, last_y = x, y               # update the "previous point"

def on_release(event):
    global last_x, last_y
    last_x, last_y = None, None         # pen up: reset
```

**The event object carries coordinates:** `event.x` and `event.y` are relative to the top-left corner of **the widget the event is bound to**, so they can be fed straight to the Canvas.

## Step 4: Binding the Events

**Use `canvas.bind(event_name, function)` to connect each event to its handler:**

```python
canvas.bind("<ButtonPress-1>", on_press)
canvas.bind("<B1-Motion>", on_drag)
canvas.bind("<ButtonRelease-1>", on_release)
```

**A bound function must accept one parameter (the event object).** Even if you never use `event`, the parameter must still be there, or tkinter will raise `TypeError` when the event fires.

## Step 5: The Clear Button

**Clearing the canvas uses `canvas.delete("all")`:**

```python
def clear():
    canvas.delete("all")

tk.Button(root, text="Clear", command=clear).pack()
```

## Complete Working Version

```python
import tkinter as tk

root = tk.Tk()
root.title("Simple Drawing Pad")

canvas = tk.Canvas(root, width=500, height=400, bg="white")
canvas.pack()

last_x, last_y = None, None

def on_press(event):
    global last_x, last_y
    last_x, last_y = event.x, event.y

def on_drag(event):
    global last_x, last_y
    x, y = event.x, event.y
    canvas.create_line(last_x, last_y, x, y, width=2, fill="black")
    last_x, last_y = x, y

def on_release(event):
    global last_x, last_y
    last_x, last_y = None, None

def clear():
    canvas.delete("all")

canvas.bind("<ButtonPress-1>", on_press)
canvas.bind("<B1-Motion>", on_drag)
canvas.bind("<ButtonRelease-1>", on_release)

tk.Button(root, text="Clear", command=clear).pack()

root.mainloop()
```

**Run it: hold and drag the mouse to produce a continuous line; click "Clear" and the canvas empties.** That is a minimal but usable drawing pad.

## Crash Site One: Forgetting mainloop, the Window Flashes By

```
import tkinter as tk
root = tk.Tk()
canvas = tk.Canvas(root, width=500, height=400)
canvas.pack()
# root.mainloop() was forgotten
```

**Symptom:** the program "finishes" but no window appears, or it exits immediately.

**Cause:** `mainloop()` is tkinter's event loop. Without it there is no interface and no event handling. Every tkinter program depends on it.

## Crash Site Two: Dragging Produces Only "Dots", Not a Line

```
def on_drag(event):
    x, y = event.x, event.y
    canvas.create_line(x, y, x, y, width=2, fill="black")  # start equals end
```

**Symptom:** dragging leaves behind a sparse trail of dots instead of a continuous line.

**Cause:** `create_line(x, y, x, y)` has identical start and end points, producing a "zero-length line" that is almost invisible. The correct approach is to draw from the previous point to the current one: `create_line(last_x, last_y, x, y, ...)`.

## Crash Site Three: Forgetting `global` for the Global Variable

```
def on_press(event):
    last_x, last_y = event.x, event.y   # UnboundLocalError
```

**Symptom:** `UnboundLocalError: local variable 'last_x' referenced before assignment`.

**Cause:** assigning to `last_x` inside a function makes Python treat it as a local variable. Before the assignment the function reads "itself" (or, once the interpreter sees an assignment, treats the whole name as local), so it complains. **Solution:** write `global last_x, last_y` before the first use of either variable inside the function. All three functions need it.

## Crash Site Four: Clearing Too Aggressively and Erasing the Background Too

**If your canvas has fixed background elements (grid lines, decorative borders), `delete("all")` removes them as well.** The remedy is to tag every stroke and delete only the strokes:

```python
def on_drag(event):
    global last_x, last_y
    x, y = event.x, event.y
    canvas.create_line(last_x, last_y, x, y, width=2, fill="black", tags="stroke")
    last_x, last_y = x, y

def clear():
    canvas.delete("stroke")   # delete only the strokes
```

## Upgrade: Choosing the Colour

**Add a few colour buttons; whichever one is clicked sets the current pen colour:**

```python
pen_color = "black"

def set_color(color):
    global pen_color
    pen_color = color

def on_drag(event):
    global last_x, last_y
    x, y = event.x, event.y
    canvas.create_line(last_x, last_y, x, y, width=2, fill=pen_color)
    last_x, last_y = x, y

color_frame = tk.Frame(root)
color_frame.pack()
tk.Button(color_frame, text="Black", command=lambda: set_color("black")).pack(side="left")
tk.Button(color_frame, text="Red", command=lambda: set_color("red")).pack(side="left")
```

**Small detail:** `command=lambda: set_color("red")` is the standard idiom for a callback that needs arguments (covered in Book 1).

## Summary

- The drawing pad uses three events: `<ButtonPress-1>` puts the pen down, `<B1-Motion>` drags, `<ButtonRelease-1>` lifts it
- A global `last_x/last_y` records the previous coordinates; while dragging we join them into line segments
- The event handler must accept an `event` parameter; `event.x` and `event.y` are relative coordinates
- `canvas.delete("all")` clears the canvas; to keep a background, tag the strokes and delete only that tag
- Never forget `mainloop()`; functions that change a global variable must declare `global`
- The pen colour is handled with a global `pen_color` plus lambda callbacks
