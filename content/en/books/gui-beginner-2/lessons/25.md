# Project: Catch Game (Paddle + Ball + Score)

> Let's tie together Lessons 18–24 and build a complete catch game: a paddle moved with arrow keys, a ball falling randomly, catch it for points, miss it and lose a life, with start and end screens.

## What We're Building

**Game rules:**

```
┌─────────────────────┐
│ Score: 0   Lives: 3   │
│                     │
│      o              │   ← Ball falls randomly
│                     │
│           ████      │   ← Paddle (arrow keys)
└─────────────────────┘
```

| Element | Description |
|---|---|
| Ball | Spawns at random x at top, falls at constant speed |
| Paddle | At bottom, moved left/right with arrow keys |
| Catch | Ball hits paddle → score +1, reset ball |
| Miss | Ball hits bottom → lives -1, reset ball |
| Game over | Lives reach 0 → game ends |

## Step 1: Define the Sprite Classes

```python
import pygame
import random

pygame.init()
WIDTH, HEIGHT = 800, 600
screen = pygame.display.set_mode((WIDTH, HEIGHT))
clock = pygame.time.Clock()

# Colors
BLACK = (0, 0, 0)
WHITE = (255, 255, 255)
BLUE = (0, 150, 255)
RED = (255, 60, 60)
GREEN = (60, 220, 100)

class Paddle(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.image = pygame.Surface((120, 20))
        self.image.fill(BLUE)
        self.rect = self.image.get_rect(center=(WIDTH//2, HEIGHT - 40))
        self.speed = 400        # px/s

    def update(self, keys, dt):
        if keys[pygame.K_LEFT]:
            self.rect.x -= self.speed * dt
        if keys[pygame.K_RIGHT]:
            self.rect.x += self.speed * dt
        self.rect.clamp_ip(screen.get_rect())

class Ball(pygame.sprite.Sprite):
    def __init__(self):
        super().__init__()
        self.image = pygame.Surface((24, 24))
        self.image.fill(WHITE)
        self.rect = self.image.get_rect()
        self.reset()

    def reset(self):
        self.rect.centerx = random.randint(20, WIDTH - 20)
        self.rect.y = 0
        self.vy = random.randint(250, 400)

    def update(self, dt):
        self.rect.y += self.vy * dt
```

## Step 2: Game State and Main Loop

```python
paddle = Paddle()
paddle_group = pygame.sprite.Group(paddle)

ball = Ball()
ball_group = pygame.sprite.Group(ball)

score = 0
lives = 3
font = pygame.font.SysFont(None, 36)

running = True
while running:
    dt = clock.tick(60) / 1000
    keys = pygame.key.get_pressed()

    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    paddle_group.update(keys, dt)
    ball_group.update(dt)

    # Catch detection
    if pygame.sprite.spritecollide(paddle, ball_group, dokill=False):
        score += 1
        ball.reset()

    # Miss detection
    if ball.rect.top > HEIGHT:
        lives -= 1
        if lives <= 0:
            running = False
        else:
            ball.reset()

    # Render
    screen.fill(BLACK)
    paddle_group.draw(screen)
    ball_group.draw(screen)

    score_text = font.render(f"Score: {score}  Lives: {lives}", True, WHITE)
    screen.blit(score_text, (10, 10))

    pygame.display.flip()

pygame.quit()
```

**Result: a ball falls from the top, move the paddle with arrow keys to catch it, catch for points, miss to lose a life, game ends when all lives are gone.**

## Step 3: Adding a Start Screen

**Use a simple "state variable" to control the flow:**

```python
state = "start"      # "start" or "playing"

while running:
    dt = clock.tick(60) / 1000
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_SPACE:
                if state == "start" or state == "gameover":
                    # Restart
                    state = "playing"
                    score = 0
                    lives = 3
                    ball.reset()

    if state == "start":
        screen.fill(BLACK)
        title = font.render("Catch Game", True, WHITE)
        hint = font.render("Press SPACE to start", True, GREEN)
        screen.blit(title, (WIDTH//2 - 60, HEIGHT//2 - 40))
        screen.blit(hint, (WIDTH//2 - 70, HEIGHT//2 + 20))
    elif state == "playing":
        keys = pygame.key.get_pressed()
        paddle_group.update(keys, dt)
        ball_group.update(dt)
        if pygame.sprite.spritecollide(paddle, ball_group, dokill=False):
            score += 1
            ball.reset()
        if ball.rect.top > HEIGHT:
            lives -= 1
            if lives <= 0:
                state = "gameover"
            else:
                ball.reset()
        screen.fill(BLACK)
        paddle_group.draw(screen)
        ball_group.draw(screen)
        screen.blit(font.render(f"Score: {score}  Lives: {lives}", True, WHITE), (10, 10))
    elif state == "gameover":
        screen.fill(BLACK)
        over = font.render(f"Game Over! Score: {score}", True, RED)
        hint = font.render("Press SPACE to play again", True, GREEN)
        screen.blit(over, (WIDTH//2 - 120, HEIGHT//2 - 40))
        screen.blit(hint, (WIDTH//2 - 110, HEIGHT//2 + 20))

    pygame.display.flip()
```

**The `state` variable controls which screen to show**; pressing SPACE from start/gameover enters playing.

## Crash Scene 1: Ball "Stuck" on Paddle, Score Spams Up

```
if pygame.sprite.spritecollide(paddle, ball_group, dokill=False):
    score += 1
    ball.reset()
```

**Symptom**: The moment the ball touches the paddle, the score shoots up crazily.

**Why**: The ball is still within the paddle's range, so next frame it collides again, adding points repeatedly. While `ball.reset()` moves the ball to the top (usually avoiding this), **if the reset position is still within the collision zone** (e.g., y=0 but the paddle is also very high), it recurs.

**Fix**: After scoring, make sure the ball "fully leaves" the collision area. Add a flag:

```python
if ball.rect.colliderect(paddle.rect) and not ball.caught:
    score += 1
    ball.caught = True
    ball.reset()
# In reset, set caught=False
```

## Crash Scene 2: Forgetting to Reset Velocity When Resetting

```
def reset(self):
    self.rect.centerx = random.randint(20, WIDTH-20)
    self.rect.y = 0
    # Forgot to reset vy, speed stays 0 or old value
```

**The ball will stop at the top (if vy was unchanged from the last miss, it might be fine, but as a habit reset should be complete).**

**Fix**: Reset all relevant state in reset: `centerx`, `y`, `vy`.

## Crash Scene 3: Typo in State Comparison Causes SPACE to Do Nothing

```
if state = "start":     # SyntaxError
```

**This is basic Python**: use `==` for comparison, `=` for assignment. When switching states frequently, it's easy to slip up.

## Upgrade: Ball Speed Increases with Score

**Increasing difficulty:**

```python
def reset(self):
    self.rect.centerx = random.randint(20, WIDTH-20)
    self.rect.y = 0
    base_speed = 250 + score * 20          # Gets faster with score
    self.vy = random.randint(base_speed, base_speed + 150)
```

**Each point adds 20 to the base speed, naturally increasing the difficulty.**

## Summary

- Catch game = paddle (keyboard movement) + ball (falling) + collision scoring + lives
- Sprite classes encapsulate `image`/`rect`/`update`
- Use `spritecollide` for catch detection, `rect.top > HEIGHT` for miss detection
- State variable `state` manages start/playing/end screens
- Reset must restore complete state (position + speed)
- Ball speed increases with score for rising difficulty
