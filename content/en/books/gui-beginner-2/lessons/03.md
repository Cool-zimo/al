# Drawing Text and Images: create_text and PhotoImage

> A canvas can hold more than geometric shapes — it can also display text and images. This lesson covers the two most common "content" drawing methods, along with a classic tkinter trap.

## Writing Text with create_text

**`create_text(x, y, text="...")` writes text at the given coordinates. Important: this point is the text's "anchor point", which by default sits at the text's centre.**

```python
import tkinter as tk

root = tk.Tk()
canvas = tk.Canvas(root, width=400, height=200, bg="white")
canvas.pack()

canvas.create_text(200, 50, text="Hello, Canvas!", font=("Arial", 24), fill="blue")
canvas.create_text(200, 120, text="Python GUI Rules", font=("Helvetica", 16), fill="green")

root.mainloop()
```

Common options:

| Option | Meaning |
|---|---|
| `text` | The text to display |
| `font` | A tuple `(family, size, style)`; style may be `"bold"` or `"italic"` |
| `fill` | Text colour |
| `anchor` | Anchor position: `tk.CENTER` (default), `tk.NW` (top-left), etc. |
| `justify` | Multi-line alignment: `tk.LEFT` / `tk.CENTER` / `tk.RIGHT` |

## The Anchor Controls Alignment

**By default `anchor=tk.CENTER`, so the coordinates (200, 50) mark the centre of the text.** If you want the coordinates to mean the top-left corner, set `anchor=tk.NW`:

```python
canvas.create_text(10, 10, text="Top-left aligned", anchor=tk.NW, font=("Helvetica", 18))
```

The eight anchor constants are `N`, `S`, `E`, `W`, `NE`, `NW`, `SE`, `SW` and `CENTER`. **Memory aid:** N is up, S is down, E is right, W is left, and combinations give you the corners.

## Always Specify a Font for the Text You Need

**On a Windows machine, `font=("SimHei", 20)` displays Chinese just fine, but on Linux or macOS you may get empty boxes (missing glyphs).** When writing an interface for several platforms, do not assume a particular font is installed; either leave the `font` parameter at its default or use tkinter's `font.Font` object to discover what is available. For this lesson, the key point is simply: "state the font you need explicitly."

## Loading an Image: PhotoImage

**To display an image on the Canvas, use `create_image`; the image object itself is loaded with `PhotoImage`:**

```python
import tkinter as tk

root = tk.Tk()
canvas = tk.Canvas(root, width=400, height=300, bg="white")
canvas.pack()

img = tk.PhotoImage(file="demo.png")     # load the image
canvas.create_image(200, 150, image=img) # place it on the canvas

root.mainloop()
```

In `create_image(x, y, image=img)`, the point `(x, y)` is the image centre (the default `anchor=tk.CENTER`).

**Formats PhotoImage understands:** GIF, PGM, PPM and (in tkinter 8.6+) PNG. JPEG is not supported and requires the `Pillow` library instead.

## Crash Site One: The PhotoImage Reference Is Lost and the Image Disappears (tkinter's Classic Trap)

```
import tkinter as tk

root = tk.Tk()
canvas = tk.Canvas(root, width=400, height=300)
canvas.pack()

def load_image():
    img = tk.PhotoImage(file="demo.png")      # local variable
    canvas.create_image(200, 150, image=img)

load_image()
root.mainloop()
```

**Symptom:** the window appears but the image area is blank, with no error message at all.

**Cause:** `img` is a **local variable** inside `load_image`. Once the function finishes, nothing references `img` any more, Python's garbage collector (GC) reclaims it, and the image object is destroyed. The `create_image` call on the Canvas is left holding "an object that has vanished", so naturally nothing is displayed.

**This is tkinter's dangling-reference problem, and it is probably the most common stumbling block for beginners.** Even worse, tkinter does not complain — the image simply stays blank, which makes the bug very hard to track down.

**Fix: keep a reference so the GC cannot collect it:**

```python
import tkinter as tk

root = tk.Tk()
canvas = tk.Canvas(root, width=400, height=300, bg="white")
canvas.pack()

img = tk.PhotoImage(file="demo.png")     # moved to global / instance level
canvas.create_image(200, 150, image=img)

root.mainloop()
```

**Alternatively, hang the image onto the Canvas so it lives as long as the canvas does:**

```python
canvas.image = img   # force the canvas to hold a reference
```

**Or store it as `self.img` inside a class.** The guiding principle is: as long as the image is still displayed on the canvas, some variable somewhere must be holding a reference to it.

## Crash Site Two: The Path Is Wrong, but the Symptom Is Vague

```
img = tk.PhotoImage(file="nonexistent.png")
```

**Symptom:** `tkinter.TclError: couldn't open "nonexistent.png"` — this one is fairly obvious because it raises an error immediately.

**More subtle is the case where the path is right but the file is not in the current working directory:** `file="demo.png"` is a relative path, and it is relative to **the directory from which the program is run**, not the directory containing your `.py` file. Printing `os.getcwd()` or switching to an absolute path avoids this whole class of problems.

## Crash Site Three: PhotoImage Cannot Load JPEG

```
img = tk.PhotoImage(file="photo.jpg")
```

**Symptom:** `tkinter.TclError: couldn't recognize data in image file`.

**Before tkinter 8.6 only GIF, PGM and PPM were supported; 8.6 added PNG, but JPEG has never been supported.** The solution is to install `Pillow`:

```python
from PIL import Image, ImageTk
img = ImageTk.PhotoImage(Image.open("photo.jpg"))
```

**But beware:** an `ImageTk.PhotoImage` object suffers from exactly the same reference-loss problem, so remember to keep a reference to it as well.

## Scaling with subsample

**PhotoImage comes with a simple scaling method called `subsample`:**

```python
img = tk.PhotoImage(file="big.png")
small = img.subsample(2, 2)   # width and height both halved
tiny  = img.subsample(4, 4)   # width and height both quartered
```

`subsample(n, m)` means "shrink the width to 1/n and the height to 1/m". **It can only shrink by whole-number factors; it cannot enlarge.** For arbitrary scaling you need Pillow.

## Summary

- `create_text` writes text; `font=(family, size, style)` and `anchor` control alignment
- For text that must display correctly, specify the font you need
- `create_image` plus `PhotoImage` displays an image
- **The image-reference trap:** a local `img` is collected by the GC and the image vanishes — keep a reference as a global, on `canvas.image`, or as `self.img`
- PhotoImage only supports GIF, PGM, PPM and PNG; JPEG needs Pillow
- Relative paths are resolved against "the directory the program was run from", not the location of your `.py` file
