# Installation and Your First Window: pygame.init, display.set_mode, and the Quit Event Loop

> From this lesson we enter pygame. We'll install the library, create a window, and write a "minimum runnable program" that closes properly — the starting point for every pygame project.

## Installing pygame

**Install with pip:**

```bash
pip install pygame
```

**Verify the installation:**

```python
import pygame
print(pygame.ver)
```

If it prints a version number (e.g., `2.5.2`), you're good to go.

**Common pitfalls:**

| Situation | Symptom | Solution |
|---|---|---|
| Installed to wrong Python | `import pygame` raises ModuleNotFoundError | Use the matching interpreter's pip: `python -m pip install pygame` |
| Multiple Python versions | Installed to py3.11 but using 3.12 | Confirm install and runtime environments match |
| Permission issues | Linux/macOS says permission denied | Add `--user` or use a virtual environment |

## The Minimum Window Program

```python
import pygame

pygame.init()                               # Initialize all modules
screen = pygame.display.set_mode((800, 600)) # Create the window
pygame.display.set_caption("My First Game")  # Title bar

running = True
while running:
    for event in pygame.event.get():         # Process the event queue
        if event.type == pygame.QUIT:        # Click the close button
            running = False

    screen.fill((255, 255, 255))            # Fill the screen with white
    pygame.display.flip()                   # Refresh the display

pygame.quit()                               # Clean up
```

**Step by step:**

1. `pygame.init()`: Initializes pygame's various modules (display, sound, input, etc.). Must come first.
2. `display.set_mode((width, height))`: Creates the window and returns a Surface object (the screen).
3. Event loop: Continuously pulls events from `pygame.event.get()` and checks if it's QUIT.
4. `screen.fill()`: Clears the screen with the background color each frame (without it, you get smearing).
5. `pygame.display.flip()`: Sends the current frame to the screen.
6. `pygame.quit()`: Cleans up resources on exit.

## Window Size and Colors

**`set_mode((width, height))` takes a tuple `(width, height)` in pixels.**

**Colors use RGB tuples `(R, G, B)`, each component 0–255:**

```python
BLACK = (0, 0, 0)
WHITE = (255, 255, 255)
RED   = (255, 0, 0)
GREEN = (0, 255, 0)
BLUE  = (0, 0, 255)
```

**Defining colors as constants is standard pygame practice** — it makes your code far more readable.

## Crash Scene 1: Forgetting to Handle QUIT, Window Won't Close

```python
import pygame
pygame.init()
screen = pygame.display.set_mode((800, 600))

while True:
    screen.fill((255, 255, 255))
    pygame.display.flip()
    # Forgot to process events
```

**Symptom**: The window pops up, clicking the × in the corner does nothing, you can't even close it from the taskbar — you have to kill the process.

**Why**: pygame requires you to process the event queue inside the loop. If you don't handle the QUIT event, the OS's "close" request gets ignored. Worse, leaving the event queue unprocessed long-term makes the program "unresponsive."

**Fix**: You must `for event in pygame.event.get():` and check for `QUIT` inside the loop.

## Crash Scene 2: Forgetting pygame.init()

```
import pygame
screen = pygame.display.set_mode((800, 600))   # video system not initialized
```

**Symptom**: `pygame.error: video system not initialized`.

**Why**: `set_mode` depends on pygame's video subsystem, which must be initialized with `pygame.init()` first.

## Crash Scene 3: Writing display as Display / display

```
pygame.Display.set_mode((800,600))   # AttributeError
pygame.display.Set_Mode((800,600))  # AttributeError
```

**pygame module and method names are all lowercase**: `pygame.display.set_mode`. Remember lowercase.

## Crash Scene 4: Writing flip as flop or Forgetting to Call It

```python
screen.fill((255, 255, 255))
# Forgot pygame.display.flip()
```

**Symptom**: Black screen or content not updating.

**Why**: pygame uses "double buffering" — everything you draw goes to a back buffer; `flip()` is what brings it to the front. Without flip, you never see anything.

**Related methods**: `pygame.display.flip()` refreshes the whole screen; `pygame.display.update(rect)` only refreshes a specific area (more efficient).

## Crash Scene 5: Passing Integers Instead of a Tuple to set_mode

```
screen = pygame.display.set_mode(800, 600)   # TypeError
```

**`set_mode` only accepts one argument (a size tuple)** — it must be written as `(800, 600)`.

## A Cleaner Version with Color Constants and Exit Message

**A more polished style: extract colors as constants and keep the loop clean:**

```python
import pygame

pygame.init()

WIDTH, HEIGHT = 800, 600
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("White Window")

WHITE = (255, 255, 255)

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
    screen.fill(WHITE)
    pygame.display.flip()

pygame.quit()
print("Game over")
```

## Using Event Type Constants

**pygame events are represented by constants. The common ones:**

| Constant | Meaning |
|---|---|
| `pygame.QUIT` | Window closed |
| `pygame.KEYDOWN` | Key pressed |
| `pygame.KEYUP` | Key released |
| `pygame.MOUSEMOTION` | Mouse moved |
| `pygame.MOUSEBUTTONDOWN` | Mouse button pressed |
| `pygame.MOUSEBUTTONUP` | Mouse button released |

**Checking for keys:**

```python
for event in pygame.event.get():
    if event.type == pygame.KEYDOWN:
        if event.key == pygame.K_ESCAPE:
            running = False
        elif event.key == pygame.K_SPACE:
            print("Jump")
```

**`pygame.K_xxx` are key-code constants**, such as `K_LEFT`, `K_RIGHT`, `K_UP`, `K_DOWN`, `K_a`, `K_SPACE`, `K_ESCAPE`.

## Summary

- Install: `pip install pygame`, verify with `import pygame; print(pygame.ver)`
- Minimum program: `init` → `set_mode` → event loop → `fill` + `flip` → `quit`
- `set_mode((width, height))` takes a tuple and returns a Surface
- Colors use RGB tuples; extracting them as constants is recommended
- **You must handle the QUIT event**, otherwise the window won't close
- You must call `flip()` to see anything on screen
