# The Treeview Table: Columns, Rows, Inserting Data and Selection Events

> ttk's Treeview is a "tree-plus-table" widget. It can act as a tree (expandable and collapsible hierarchy) or as a table (multiple columns and rows). This lesson focuses on the most common use: building a table to display data.

## What a Treeview Is

**A Treeview can display both a "tree" (expandable hierarchy) and a "table" (multiple columns and rows).** In table mode the first column is a hidden tree column and the rest are the columns we define.

```python
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.title("Table Example")

# Define columns: #0 is the default tree column; add name/age/city columns
columns = ("name", "age", "city")
tree = ttk.Treeview(root, columns=columns, show="headings")

# Set the column headings
tree.heading("name", text="Name")
tree.heading("age", text="Age")
tree.heading("city", text="City")

tree.pack()
root.mainloop()
```

**`show="headings"` means "show only the columns we defined and hide the left tree column"** — this is the standard way to use table mode.

## Inserting Rows: insert

**Use `tree.insert(parent, index, values=...)` to insert a row.** In table mode the parent is `""` (top level, no parent):

```python
tree.insert("", "end", values=("Alice", 25, "New York"))
tree.insert("", "end", values=("Bob", 30, "London"))
tree.insert("", "end", values=("Carol", 28, "Paris"))
```

**Arguments:** `parent` is the parent node (`""` means root), `index` is the position (`"end"` appends to the bottom), and `values` are the values for that row.

## Setting Column Width and Alignment

**Use `tree.column(column_name, width=..., anchor=...)` to adjust column width and alignment:**

```python
tree.column("name", width=100, anchor="w")   # left aligned
tree.column("age", width=60, anchor="center")
tree.column("city", width=100, anchor="w")
```

**Values for `anchor`:** `"w"` for left, `"e"` for right and `"center"` for centre. Numeric columns are usually centred and text columns left aligned.

## A Complete Table Example

```python
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.title("Student List")

columns = ("name", "age", "city")
tree = ttk.Treeview(root, columns=columns, show="headings")

for col, text, w in zip(columns, ["Name", "Age", "City"], [100, 60, 100]):
    tree.heading(col, text=text)
    tree.column(col, width=w, anchor="center")

students = [("Alice", 25, "New York"), ("Bob", 30, "London"),
            ("Carol", 28, "Paris"), ("David", 22, "Tokyo")]
for s in students:
    tree.insert("", "end", values=s)

tree.pack(padx=10, pady=10)
root.mainloop()
```

**Run it: a table with a header row and four rows of data.**

## The Selection Event: <<TreeviewSelect>>

**Binding the `<<TreeviewSelect>>` event lets you retrieve the selected row when the user picks one:**

```python
def on_select(event):
    selection = tree.selection()      # tuple of selected row IDs
    if selection:
        item_id = selection[0]
        values = tree.item(item_id)["values"]
        print("Selected:", values)

tree.bind("<<TreeviewSelect>>", on_select)
```

**Key methods:**

| Method | Purpose |
|---|---|
| `tree.selection()` | Returns a tuple of the selected row IDs |
| `tree.item(id)` | Returns the full information dictionary for that row, including `values` |
| `tree.focus()` | Returns the ID of the currently focused row |

## Crash Site One: Forgetting show="headings" Leaves a Blank Column

```
tree = ttk.Treeview(root, columns=columns)   # missing show
```

**Symptom:** an extra blank "tree column" appears on the far left and your data starts from column 2.

**Cause:** the default is `show=("tree", "headings")`, which displays the left tree column. A pure table requires `show="headings"`.

## Crash Site Two: insert values Do Not Match the Number of Columns

```
tree.insert("", "end", values=("Alice",))      # only 1 value for 3 columns
```

**Symptom:** no error, but only the first column has a value and the rest are blank.

**Countermeasure:** make sure the `values` tuple length matches the number of columns before inserting. When inserting in bulk, `zip` is a good way to keep things aligned.

## Crash Site Three: selection May Be Empty

```
def on_select(event):
    item = tree.selection()[0]   # IndexError
```

**Symptom:** `IndexError: tuple index out of range`. When the user deselects (for example by clicking a header), `selection()` returns an empty tuple.

**Fix: check for non-empty first:**

```python
def on_select(event):
    sel = tree.selection()
    if not sel:
        return
    values = tree.item(sel[0])["values"]
```

## Deleting Rows

**`tree.delete(id)` deletes the specified row; `tree.delete(*tree.get_children())` clears every row:**

```python
# Delete a single row
tree.delete(item_id)

# Clear the whole table
for item in tree.get_children():
    tree.delete(item)
```

**`get_children()` returns a list of the IDs of all top-level rows.**

## Editing a Row

**`tree.item(id, values=...)` can change a row's values:**

```python
tree.item(item_id, values=("Alice", 26, "New York"))   # change this row
```

**You can also change a single cell (read first, then write):**

```python
old = tree.item(item_id)["values"]
tree.item(item_id, values=(old[0], 99, old[2]))
```

## Sorting: Click the Header to Sort

**Bind a click event to the header to sort by that column and re-insert:**

```python
def sort_by(col, descending):
    data = [(tree.set(child, col), child) for child in tree.get_children("")]
    data.sort(reverse=descending)
    for idx, (val, child) in enumerate(data):
        tree.move(child, "", idx)   # reorder
    tree.heading(col, command=lambda: sort_by(col, not descending))

for col in columns:
    tree.heading(col, command=lambda c=col: sort_by(c, False))
```

**`tree.set(child, col)` reads one cell of one row, and `tree.move` adjusts the row order.** This gives you a useful "click the header to sort" feature.

## Summary

- A Treeview is both a tree and a table; `show="headings"` gives you pure table mode
- `columns` defines the columns; `heading` sets the titles and `column` sets width and alignment
- `insert("", "end", values=...)` inserts a row
- `<<TreeviewSelect>>` is the selection event; `selection()` gets the IDs and `item(id)["values"]` gets the data
- Delete a row with `delete(id)`; clear everything with `delete(*get_children())`
- Edit a row with `item(id, values=...)`; sort with `set` plus `move`
