# ttk Themes and Styles: Style, theme_use and configure

> In the previous lesson we learned that a ttk widget's appearance is managed by a theme. This lesson covers how to switch themes and how to customise widget styles with `ttk.Style()`.

## What a Theme Is

**A theme is a collection of "appearance rules for widgets".** ttk includes several built-in themes, and the themes available vary by platform:

| Theme name | Style | Common platform |
|---|---|---|
| `clam` | Flat and customisable | Cross-platform, commonly used |
| `alt` | Classic and retro | Cross-platform |
| `default` | tkinter default | Cross-platform |
| `classic` | The oldest style | Cross-platform |
| `vista` | Windows Vista/7 | Windows |
| `xpnative` | Windows XP | Windows |
| `winnative` | Native Windows | Windows |
| `aqua` | Native macOS | macOS |

**Use `ttk.Style().theme_names()` to see which themes are available on the current platform.**

## Viewing and Switching Themes

```python
import tkinter as tk
from tkinter import ttk

root = tk.Tk()

style = ttk.Style()
print(style.theme_names())     # list available themes
print(style.theme_use())       # the current theme name

style.theme_use("clam")        # switch to the clam theme
```

**The theme must be switched before creating widgets**, otherwise existing widgets will not update automatically.

```python
style.theme_use("clam")        # switch theme first
ttk.Button(root, text="OK").pack()   # then create the widget
```

## Customising with Style.configure

**`Style.configure(style_name, **options)` modifies the style of an entire widget class.** The style name is the widget class name in lowercase:

```python
style = ttk.Style()
style.theme_use("clam")

# Customise the look of every TButton
style.configure("TButton",
                foreground="white",
                background="#3498db",
                font=("Arial", 12),
                padding=8)

ttk.Button(root, text="Blue Button").pack(padx=10, pady=10)
```

**`TButton` is the style class name for Button**; likewise `TLabel`, `TEntry` and `TFrame`. The leading `T` is ttk's naming convention.

## Common Style Options

| Option | Meaning |
|---|---|
| `foreground` | Foreground (text) colour |
| `background` | Background colour |
| `fieldbackground` | Interior background of an input (Entry, Combobox) |
| `font` | Font |
| `padding` | Internal padding (one number or four sides) |
| `relief` | Border style (flat, raised, sunken) |
| `borderwidth` | Border width |

```python
style.configure("TEntry",
                fieldbackground="lightyellow",
                borderwidth=2)
```

## A Custom Style Name (Inheritance)

**As well as changing the global `TButton`, you can define a "new style" and apply it to a specific widget:**

```python
style.configure("Danger.TButton",
                foreground="white",
                background="#e74c3c",
                padding=10)

ttk.Button(root, text="Delete", style="Danger.TButton").pack()
ttk.Button(root, text="Cancel").pack()   # uses the default TButton style
```

**`Danger.TButton` is a custom name; the `.TButton` suffix means "inherit the layout of TButton".** This lets you have both "ordinary buttons" and "danger-operation red buttons" at the same time.

## Crash Site One: background Has No Effect on a Button

```
style.configure("TButton", background="red")
```

**Symptom:** on certain themes (especially Windows native themes) the button's background colour does not change.

**Cause:** some native themes (such as `vista` and `aqua`) draw using the system renderer and ignore `background`. **Solution: switch to the `clam` theme**, which supports custom background colours.

```python
style.theme_use("clam")
style.configure("TButton", background="red", foreground="white")
```

**Rule of thumb: for deep appearance customisation, use the `clam` theme.**

## Crash Site Two: Forgetting `clam`, and the Colour Still Does Not Change

**The theme must be switched before creating widgets — a very common mistake:**

```
style = ttk.Style()
ttk.Button(root, text="A").pack()   # widget created first
style.theme_use("clam")             # theme switched afterwards; the existing button is unaffected
```

**Fix: move `theme_use` to the very top, before any widgets are created.**

## Crash Site Three: Wrong Case or Spelling of the Style Name

```
style.configure("tbutton", ...)      # lowercase, no effect
style.configure("Button", ...)       # missing the T prefix, no effect
```

**The correct style class name is capitalised with a leading T: `TButton`, `TLabel`, `TEntry`.**

**Custom names may be any string, but the suffix states what they inherit from:** `"Danger.TButton"`, `"Bold.TLabel"`.

## State Styles with map

**Widgets have different states: normal, hovered (active), pressed, disabled. `Style.map` sets different styles for different states:**

```python
style.map("TButton",
          foreground=[("active", "white"), ("disabled", "gray")],
          background=[("active", "#2980b9"), ("disabled", "#cccccc")])
```

**Syntax:** `option=[(state, value), ...]`. The example above means: on hover the background becomes a deeper blue, and when disabled it becomes grey.

**This is the proper way to build "interactive feedback"** — much cleaner than manually binding `<Enter>`/`<Leave>` to change colours.

## A Complete Example

```python
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.title("Style Example")

style = ttk.Style()
style.theme_use("clam")

style.configure("TButton",
                foreground="white",
                background="#3498db",
                padding=10,
                font=("Arial", 12))
style.map("TButton",
          background=[("active", "#2980b9")])

style.configure("TLabel",
                font=("Arial", 14),
                foreground="#2c3e50")

ttk.Label(root, text="Theme Style Example").pack(padx=20, pady=15)
ttk.Button(root, text="Primary").pack(padx=20, pady=10)
ttk.Button(root, text="Disabled", state="disabled").pack(padx=20, pady=10)

root.mainloop()
```

## Summary

- A theme = a set of appearance rules; `theme_use("clam")` switches theme (do it before creating widgets)
- Use `ttk.Style().theme_names()` to list the available themes
- `Style.configure("TButton", ...)` changes the global style
- Custom style: `"Danger.TButton"`, where the suffix declares what it inherits from
- For custom background colours, use the `clam` theme
- State styles use `Style.map`: one set for hover, one for pressed, one for disabled
- Style class names: `TButton`, `TLabel`, `TEntry`, and so on
