# 29 Troubleshooting

> These account for half of everything I have run into.

## One: published, but it does not appear

Check in order:

1. Is there a topic `al-book`?
2. Is `format` **exactly** `al-book` (no stray space, no capitals)?
3. Is the repo **public**?
4. Has it been 6 hours yet? (Signing in searches live and skips the wait.)

## Two: a choice question renders with no options

**Almost always a fence problem.**

You typed three backticks inside the question text, so the parser ended the block there and `options` and `answer` were never read.

Move the code into the `code:` field.

## Three: a function question reports a missing argument

The `cases` line used a space between arguments. `1 2 -> 3` becomes **one argument**.

Write `1, 2 -> 3`.

## Four: lesson counts do not line up

What `toc.json` declares and what sits in `lessons/` must match exactly.

- toc says `03` but there is no `03.md` → error
- `07.md` exists but toc omits it → error

## Five: question counts differ between languages

Textbooks (the default kind) require matching counts. If the English is still in progress, two options:

- set `langs` to `["zh"]` for now and add English later
- or set `kind` to `novel` / `notes` (but that misrepresents the book)

Prefer the first.

## Six: the question shows in preview but does nothing

Check whether the question **itself** is broken — the preview puts a yellow notice above it naming the missing field.

## Recap

- Not listed: check topic, exact format, public
- No options: fences
- Missing argument: commas in cases
- Count mismatch: toc vs files
