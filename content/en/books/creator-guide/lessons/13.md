# 13 Multiple-choice questions

> Add one line: multi: true, and separate answers with commas.

## The syntax

Almost identical to a single-choice question, plus `multi: true`:

```
type: choice
multi: true
q: Which of these are mutable?
options:
- list
- dict
- tuple
- str
answer: 0, 1
```

**`multi: true` decides whether it renders as checkboxes or radio buttons.** Without it, even with several answers listed, readers get radio buttons and cannot pick two.

## answer holds several indices, comma-separated

```
answer: 0, 1      first and second
answer: 0,2       spaces are optional
```

Every index is range-checked individually. `answer: 0, 5` with four options errors.

## All-or-nothing grading

Multiple choice is graded as: **the selected set must equal the answer set exactly.** One missing or one extra is wrong.

So say how many are correct in the question text:

```
q: Which of these are mutable? (two answers)
```

Without that, readers agonise over whether they missed one.

## When to use it

Good for set-like questions: which of these are mutable, which ship in the standard library, which lines raise an error.

Bad for anything with a single right answer — use single choice there.

## Recap

- `multi: true` is required
- `answer` is comma-separated indices
- Every correct option must be selected
- State how many answers there are

## In-class exercise

```quiz
type: choice
answer: 0
q: What happens if you omit multi: true?
options:
- It renders as radio buttons, so readers cannot pick two
- It is auto-detected as multi
- It errors
- The question disappears
hint: The number of answers does not matter
explain: multi controls rendering. Without it you get radio buttons even if answer lists several indices.
```

## Section quiz

```quiz
type: choice
exam: true
answer: 0
q: How is a multiple-choice question graded?
options:
- The selected set must match the answer set exactly
- Any correct selection passes
- Partial credit by proportion
- Not graded at all
explain: One missing or one extra is wrong, so say how many answers there are.
```

```quiz
type: choice
exam: true
answer: 0
q: Four options, correct ones are the first and third. What is answer?
options:
- 0, 2
- 1, 3
- 0,2,
- 1 3
hint: Zero-based indices, comma-separated
explain: First is index 0, third is index 2, so 0, 2.
```
