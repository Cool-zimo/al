# 11 The quiz block skeleton

> Every question is the same shell; only type changes.

## What it looks like

A question is a code block tagged `quiz`:

```
type: choice
q: the question text
options:
- option A
- option B
answer: 0
```

**It must open with a quiz-tagged fence and close with a fence on its own line.** Miss either and the whole question fails to parse.

## Field syntax

It is minimal YAML:

```
key: value          single-line value
key: |              multi-line block, indented two spaces
  first line
  second line
key:                list, items start with -
- first
- second
```

The usual mistake is wrong indentation:

```
starter: |
def add(a, b):        not indented, so it is not part of the block
    return 0
```

Block content **must be indented at least two spaces**.

## Required and optional

| Field | Required | Notes |
|---|---|---|
| `type` | yes | question type |
| `q` | yes | question text |
| `exam` | no | `true` marks it as a section quiz |
| `hint` | no | shown on demand |
| `explain` | no | shown after answering |

Required fields vary by type; the next lessons cover each one.

## The closing fence must be on its own line

Worth its own paragraph. The closing fence must be **at column zero, alone on the line**.

If the question text needs code, **do not use a fence** — use the `code:` field:

```
type: choice
q: What does this print?
code: |
  print(1 + 1)
options:
- 1
- 2
answer: 1
```

Type three backticks inside the question text and the parser treats that as the end of the block, so `options` and `answer` are never read. It shows up as a **choice question with no options**.

## Recap

- Opens with a quiz fence, closes with a fence at column zero
- Indent multi-line blocks two spaces
- Put code in the question text via `code:`

## In-class exercise

```quiz
type: choice
answer: 0
q: How must the closing fence of a question be written?
options:
- At column zero, alone on its line
- Indented two spaces
- On the same line as content
- Preceded by two blank lines
hint: Column zero
explain: A closing fence must be alone at column zero, or parsing truncates early.
```

## Section quiz

```quiz
type: choice
exam: true
answer: 0
q: To put code in the question text, what is correct?
options:
- Use the code: field
- Type three backticks directly
- Use inline code
- Append it to the q: line
explain: A fence inside the question text ends the block, so every later field is lost.
```

```quiz
type: choice
exam: true
answer: 0
q: starter is a multi-line block; how is its content written?
options:
- Indented at least two spaces
- At column zero
- Indented one space
- Wrapped in quotes
explain: Content under key: | must be indented at least two spaces to count.
```
