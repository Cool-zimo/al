# 04 Lesson files and naming

> Get a file name wrong and everything before it was wasted.

## Lesson numbers: two digits

```
01.md  02.md  03.md  ...  09.md  10.md  ...  30.md
```

Single digits must be zero-padded. `1.md` is not lesson 1 — the reader only recognises two digits plus `.md`.

## Chapter tests: test-NN.md

```
test-01.md   chapter 1 test
test-02.md   chapter 2 test
```

The reader uses the `test-` prefix to tell a chapter test from a real lesson.

Write your chapter test as `06.md` (right after five lessons) and it becomes lesson 6. Chapter tests and lessons are graded differently (lessons want 1 in-class plus 2 quiz questions; chapter tests want at least 5), so mixing them up throws an error.

## What a lesson looks like

```markdown
# Slicing: taking a whole span at once

> Intro: what this section solves

## Subheading

Body text.

## Recap

- Points

## In-class exercise

(one question without exam)

---

## Section quiz

(two questions with exam: true)
```

Line one must be `# Title`. Line two should be `> Intro`.

## No non-ASCII file names

```
first-lesson.md    no
01 slicing.md      no (space)
01-slice.md        no (not pure digits)
```

Just `01.md`, clean and boring.

## Recap

- Two-digit lesson numbers, zero-padded
- Chapter tests use `test-NN.md`, recognised by prefix
- Line one `# Title`, line two `> Intro`
- Nothing but the number in the file name

## In-class exercise

```quiz
type: choice
answer: 0
q: What should lesson 1 be named?
options:
- 01.md
- 1.md
- lesson-01.md
- 01-first.md
hint: Two digits
explain: Must be two digits; 1.md is not recognised.
```

```quiz
options:
- It is treated as lesson 6
- Error: chapter test not found
- Auto-detected as a test
- Counted as both
explain: Chapter tests are recognised by the test- prefix. As 06.md it becomes a lesson, and the grading rules differ.
```

```quiz
type: choice

- # Title
```
