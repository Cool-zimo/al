# 25 Custom snippets

> Save the questions you reuse, then insert them in one click.

## Why you want this

Hand-writing quiz YAML makes it easy to drop a field. Drop one and the question still displays — it just **cannot be graded**, which is very hard for the author to notice.

The built-in library covers every question type, but you may have a **shape you use constantly**:

- the "spot the misconception" choice question you write once per chapter
- a function question with a fixed starter skeleton
- a checklist you designed

Save those as custom snippets and insert them in one click.

## How to save one

1. Select a quiz block in the editor (or just put the cursor inside the question)
2. Open the snippet panel and click "Save as snippet"
3. Done

Selecting is optional — if you select nothing, it takes the question your cursor is in.

## Where they live

In your **private drafts repo** (`al-drafts/snippets.json`), so they follow you between devices.

Same reasoning as drafts: localStorage disappears when someone clears browser data.

## Whether exam gets added

Snippets are stored **without** an exam line. The panel's toggle decides at insert time.

So one snippet works as an in-class exercise or as a section quiz.

## Deleting

Each custom snippet has a `×` in its top-right corner. Click it and it is removed from the cloud too.

## Recap

- Select a quiz block, save it as a snippet
- Stored in your private drafts repo, cross-device
- Decide exam at insert time
