# 28 Visibility and being listed

> You can change it all after publishing. No need to start over.

## Changing visibility

Every book in the management panel has a "change visibility" button:

```
public  →  private    removed from the library; the next bot scan drops it
private →  public     listed again
```

Same for renaming or rewriting the description — change it, publish again.

## How long listing takes

The bot scans **every 6 hours**, so a new book can take up to 6 hours to appear.

Faster route: **open the library while signed in and it searches live with your token**, so your new book shows up right away.

## Three markers, all required

The bot looks for three things; miss one and it will never find you:

```
1. repo name starting with al-book-
2. topic: al-book
3. albook.json at the root with format exactly al-book
```

**The easiest to forget is the topic.** Name and format can both be right, but with no topic you are invisible.

One-click publishing sets the topic for you, so you only need to remember this if you create the repo by hand.

## Books that fail are still listed

On the index site, books that fail validation are shown **with their error messages**, so the author knows what to fix. They do not vanish silently.

## Recap

- Visibility is changeable at any time
- The bot scans every 6 hours; signing in searches live
- Three markers required, and topic is the easiest to forget
- Failures are listed with reasons
