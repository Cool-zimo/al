# 16 Function questions: your function really gets called

> The most valuable type — the page runs it for real.

## The syntax

```
type: function
q: Write add(a, b) returning the sum of two numbers
func: add
starter: |
  def add(a, b):
      return 0
cases: |
  1, 2 -> 3
  5, 7 -> 12
  -1, 1 -> 0
hint: Just add the two parameters
explain: return a + b is all it takes.
```

## Three key fields

| Field | Purpose |
|---|---|
| `func` | the function to call; must match the definition in starter |
| `starter` | the code the reader starts from |
| `cases` | case table; return values are compared one by one |

Get `func` wrong (say `add` while starter defines `sum`) and the validator complains — it can see there is no `def add` in starter.

## The grading is real

When the reader hits run, the page:

1. executes their whole code
2. pulls out the function named by `func`
3. calls it with each line of `cases`
4. compares the return value to the expected one

So this is not "looks right", it **is** right.

## starter must run

A common beginner mistake is a starter that does not parse:

```
starter: |
  def add(a, b):
      # write your code here
```

That is a syntax error — a body cannot be only a comment. The reader opens the page to an error, which feels terrible.

**Give a version that runs but gives the wrong answer:**

```
starter: |
  def add(a, b):
      return 0
```

It runs; the reader changes one number and it is correct.

## Cases must discriminate

```
cases: |
  1, 2 -> 3     good
  0, 0 -> 0     weak (return 0 passes)
```

**Always check: does submitting starter unchanged pass?** If yes, the question discriminates nothing, and the validator rejects it.

## Recap

- `func`, `starter`, `cases` — the trio
- starter runs, it just gives the wrong answer
- Cases must reject the untouched starter

## In-class exercise

```quiz
type: function
func: double
q: Write double(n) returning twice n
starter: |
  def double(n):
      return 0
cases: |
  1 -> 2
  5 -> 10
  -3 -> -6
hint: Return n multiplied by 2
explain: Return the parameter times two.
```
