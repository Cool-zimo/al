# 09 In-class exercise vs section quiz

> Only the section quiz counts as "done" — this is the core design of the whole site.

## How the two differ

| | In-class exercise | Section quiz |
|---|---|---|
| Where | in the body, wherever it fits | end of the lesson |
| Marker | no `exam` | `exam: true` |
| Counts as done | no | **yes** |
| How many | any | 2 per lesson |

**The key difference is whether it counts as done.**

The site decides "this lesson is finished" by checking whether the **section quiz is all correct**. Getting the in-class exercise right does not count — it is read-as-you-go practice; if you miss it, read the explanation and move on.

The point: the number on your progress bar means you actually know it, not that you scrolled past it.

## How many

One in-class exercise (in the body) plus two section quiz questions (at the end) per lesson.

The validator counts questions marked `exam: true` and **errors if it is not 2**. In-class exercises are unlimited — put three in the body if you like.

## Chapter tests: at least 5, aim for 8

Everything in `test-01.md` counts as quiz — a chapter test is an exam, there is no in-class split. Fewer than 5 gets a warning.

A good mix: 5 choice + 2 hands-on + 1 project.

## The heading does not matter

Grading keys off the `exam: true` marker, **not** which `##` heading it sits under. Still, for the reader's sake, use "## In-class exercise" and "## Section quiz".

## Recap

- In-class does not count as done; section quiz does
- 2 questions with `exam: true` per lesson
- Around 8 in a chapter test
- The marker decides, not the heading
