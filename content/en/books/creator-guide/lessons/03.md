# 03 toc.json: writing the contents

> Get the contents wrong and the book will not open. This is the number one beginner problem.

## Two shapes are accepted

**Short form** (recommended for community authors):

```
{
  "book": "my-first-book",
  "chapters": [
    {
      "title": "Chapter 1 · Getting started",
      "lessons": ["01", "02", "03", "04", "05"],
      "test": "test-01"
    },
    {
      "title": "Chapter 2 · Going further",
      "lessons": ["06", "07", "08", "09", "10"],
      "test": "test-02"
    }
  ]
}
```

**Full form** (used by official books; adds a title and summary per lesson):

```
{
  "chapters": [
    {
      "title": "Chapter 1 · Getting started",
      "test": "test-01",
      "items": [
        { "id": "01", "title": "First lesson", "summary": "What this one covers" }
      ]
    }
  ]
}
```

Both are read correctly. The difference: the short form omits lesson titles, so the site **opens each lesson and grabs the `# heading` and the first blockquote** to fill the contents.

So if you cannot be bothered writing summaries, use the short form. As long as line one is `# Title`, the contents still look right.

## Three things that must line up

This is where people trip: **what toc declares** and **what actually exists** must match exactly.

```
toc says "03" but there is no 03.md      → error
07.md exists but toc does not list it    → error
```

One extra or one missing on either side fails. The validator names the exact file.

## test is optional

Not every chapter needs a test. If there is no `test-01.md`, do not write `"test": "test-01"`. Declaring a file you do not have is still an error.

## Must lesson numbers be continuous?

No — a gap is a **warning**, not an error. With `01 02 03 07` you get "lesson numbers not continuous, missing 04, 05, 06", and the book still ships.

Continuous is nicer for readers though.

## Recap

- Short and full forms both work
- Declared lessons must exist, and existing files must be declared
- No chapter test? Leave the test field out
- Gaps in numbering are only a warning
