# 12 Choice questions

> The most common type, and the easiest to get wrong on the answer index.

## Full example

```
type: choice
q: Which function gives the length of a list in Python?
options:
- len()
- length()
- size()
- count()
answer: 0
hint: Think of the one you see most often
explain: len() is a built-in; pass the list straight in.
```

## answer is an index, starting at 0

This is what people get wrong:

```
options:
- option A     index 0
- option B     index 1
- option C     index 2
```

Correct answer is the third one? Write `answer: 2`, not `3`.

Get it wrong (say `answer: 5` with four options) and the validator rejects it before you can publish.

## How many options

At least 2. Aim for 3 to 4 — with two options it is a coin flip and tells you nothing.

## Distractors should look plausible

Good distractors are **believable**:

```
q: Which gives the length of a list?
- len()        correct
- length()     plausible (many languages spell it this way)
- size()       plausible
- count()      plausible (strings do have .count())
```

Bad ones:

```
- len()        correct
- apple
- red
- sky
```

A question whose answer is obvious at a glance is not a question.

## Recap

- `answer` is a zero-based index
- 3 to 4 options
- Distractors must be plausible

## In-class exercise

```quiz
type: choice
answer: 0
q: The correct answer is the third option. What is answer?
options:
- 2
- 3
- 1
- 0
hint: Count from zero
explain: Indices start at 0, so the third option is 2.
```

q: What makes a good distractor?
options:
- Believable enough that the reader has to think
- Obviously wrong so it is easy to drop
- The same length as the correct answer
- Sorted alphabetically
explain: Distractors only discriminate if the reader has to actually think.
