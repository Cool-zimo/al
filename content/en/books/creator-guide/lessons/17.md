# 17 Two traps in cases

> I fell into both of these. Learn from my mistakes.

## Trap one: arguments are comma-separated only

Arguments are split on commas alone. With a space:

```
cases: |
  1 2 -> 3
```

the whole string `1 2` becomes **one argument**, so the call is `add("1 2")` and the reader sees a baffling "missing argument b".

Write it with a comma:

```
cases: |
  1, 2 -> 3
```

The validator flags any case line that has spaces but no comma and is not wrapped in quotes or brackets, so you do not have to remember this.

## Trap two: a single string argument with a space is fine

Conversely, these are **correct** — do not let the rule above scare you:

```
cases: |
  "hello world" -> 5      one string argument, space inside
  [1, 2, 3] -> 6          list argument (has commas)
  -> 3                    no arguments
```

The rule: a space in the argument part, with no comma and no wrapping quotes or brackets — that is what looks suspicious.

## How to write expected values

```
cases: |
  1, 2 -> 3            number
  "a" -> 1             strings need quotes
  [1,2] -> [2,4]       list
  "abc" -> True        booleans are capitalised
```

Python literal rules apply: `True` / `False` / `None` are capitalised and strings need quotes. Write `true` and it becomes an undefined name.

## Include a counter-example

At least one case should block a common wrong answer. Testing absolute value:

```
cases: |
  5 -> 5
  -5 -> 5        blocks "just return the input"
  0 -> 0
```

Without `-5 -> 5`, `return n` sails through.

## Recap

- Commas between arguments
- Spaces inside a quoted string argument are fine
- Expected values use Python literal syntax
- For each case ask: which wrong answer does this block?

```quiz
type: function
func: is_even
q: Write is_even(n) returning True for even numbers and False for odd
starter: |
  def is_even(n):
      return False
cases: |
  2 -> True
  3 -> False
  0 -> True
  -7 -> False
hint: Use n % 2 == 0
explain: A remainder of zero means even — return that comparison directly.
```
