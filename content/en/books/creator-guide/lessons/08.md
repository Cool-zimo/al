# 08 Care and feeding of code blocks

> Runnable code and illustrative code are written differently.

## Which languages run

Tags that run: `python`, `js`, `html`, `css`.

Anything else (`bash`, `json`) is highlighted as plain text and does not run.

## Trees and stack traces go untagged

For directory trees, error output and config files, use an untagged block. Tag it `bash` and readers will assume it is a command they can run.

## Inline code is for identifiers

Use inline code for function names, field names and file names — not quotation marks.

## One trap worth memorising

**If a lesson needs to show what a quiz block looks like, wrap three backticks in four backticks.**

Four on the outside, three on the inside. Otherwise Markdown — and the parser — will think the quiz block ends right there, and everything after it is cut off, losing `options` and `answer`.

If you cannot remember this, there is an easier route: when explaining quiz syntax, point readers at what the snippet library inserts instead of hand-typing an example.

## Recap

- `python` / `js` / `html` / `css` run
- Trees and errors go untagged
- Showing a quiz block needs four backticks
