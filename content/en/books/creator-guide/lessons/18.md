# 18 Questions with random results

> Dice, shuffles — no exact value to compare, so use a range.

## The problem

Ask a reader for `roll_dice()` returning 1 to 6 and you cannot write:

```
cases: |
  -> 3
```

because the right answer is different every time.

## Two special syntaxes

```
*30 -> 1..6
```

- `*30`: **call this case 30 times**
- `1..6`: every result must land inside `[1, 6]`

Together: "roll 30 times, and every result must be 1 to 6".

With arguments:

```
*20, 6 -> 0..5
```

## A range alone is not enough

Consider this answer:

```python
def roll_dice():
    return 3
```

Always 3, always inside 1 to 6. Range-only grading lets it through.

So range cases also check that **the results really vary**:

- integer range spanning 10 or less (dice, coins): **every value must appear**
- otherwise: at least 5 distinct results

## Cases I actually tested

| Answer | Result |
|---|---|
| `randint(1, 6)` | passes, all of 1 to 6 appear |
| `return 3` | fails, only one distinct result |
| `randrange(1, 6)` | fails, never rolls a 6 |
| `randint(1, 7)` | fails, some results out of range |

`randrange(1, 6)` deserves a place in your hint. It looks identical to `randint` but the upper bound is exclusive.

## Recap

- `*N` repeats the call, `a..b` is a range expectation
- Distinct values are also checked
- `randint(a, b)` is inclusive; `randrange(a, b)` excludes b

## In-class exercise

```quiz
type: function
func: roll_dice
q: Write roll_dice() returning a random integer from 1 to 6
starter: |
  import random

  def roll_dice():
      return 0
cases: |
  *30 -> 1..6
hint: Use random.randint(1, 6); both ends are included
explain: *30 means 30 calls, 1..6 means every result must be in range. A constant return is rejected as fixed.
```
