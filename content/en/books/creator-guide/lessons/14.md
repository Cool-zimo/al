# 14 Fill-in-the-blank questions

> Best for "do you know this word" facts.

## The syntax

```
type: fill
q: Which keyword defines a function in Python?
answer: def
placeholder: type here
hint: three letters
explain: def is followed by the name and the parameter list.
```

## Grading ignores case and surrounding spaces

`def`, `DEF` and ` def ` all pass. Case is nothing to worry about.

## Several accepted answers, separated by a pipe

```
type: fill
q: Which function gives the length of a list?
answer: len|length|size
```

Some concepts are spelled differently in different places, so list what you accept.

But be careful: accept too much and the question means nothing. `answer: a|b|c|d` accepts almost anything.

## Good and bad fits

Good for: keywords, function names, error types, command names — anything whose answer is **one specific word**.

Bad for: concepts needing explanation, things with many valid spellings, code (use a function question for that).

## Do not forget placeholder

`placeholder` is the grey hint inside the input.

```
placeholder: a function name      good
placeholder: type here            mediocre
```

## Recap

- Grading ignores case and trims spaces
- `|` separates accepted answers
- Good for one definite word
- Write a clear placeholder

## In-class exercise

```quiz
type: choice
answer: 0
q: Which answer line accepts several spellings?
options:
- answer: len|length
- answer: len, length
- answer: len length
- answer: [len, length]
hint: Which symbol is not used for splitting arguments
explain: Multiple accepted answers use a pipe. Commas are eaten by argument splitting, and spaces do not work.
```
