# Functions: Packaging Code into Reusable Blocks

> By the end of this lesson you will be able to define your own functions with `def` and understand why functions exist in the first place.

## Why Functions Exist

Suppose you wrote three nearly identical blocks of code:

```python
# Alice's BMI
weight1 = 70
height1 = 1.75
bmi1 = weight1 / (height1 ** 2)
print("Alice BMI:", round(bmi1, 1))

# Bob's BMI
weight2 = 85
height2 = 1.80
bmi2 = weight2 / (height2 ** 2)
print("Bob BMI:", round(bmi2, 1))

# Carol's BMI
weight3 = 60
height3 = 1.65
bmi3 = weight3 / (height3 ** 2)
print("Carol BMI:", round(bmi3, 1))
```

**Three blocks that are almost identical, only the data changes.** This is exactly the problem functions solve: define the *action* once, then call it repeatedly with different data.

```python
def calc_bmi(weight, height):
    bmi = weight / (height ** 2)
    return round(bmi, 1)

print("Alice BMI:", calc_bmi(70, 1.75))
print("Bob BMI:", calc_bmi(85, 1.80))
print("Carol BMI:", calc_bmi(60, 1.65))
```

The same action is written only once; the data is passed in as parameters. **A function = giving a block of code a name so you can call it again and again.**

## Definition and Calling

```python
def function_name(param1, param2):
    # indented block: the function body
    return result
```

- `def` is the keyword that defines a function
- The function name must be followed by parentheses and a colon
- Parameters go inside the parentheses (or can be omitted)
- `return` hands a result back to the caller

**To call a function, just write its name followed by parentheses:**

```python
def greet(name):
    return f"Hello, {name}"

msg = greet("Alice")
print(msg)       # Hello, Alice
```

## The Two Jobs of `return`

`return` both **sends back a result** and **ends the function immediately**:

```python
def check_age(age):
    if age >= 18:
        return "adult"
    return "minor"      # this line never runs once the line above hits return

print(check_age(20))     # adult
print(check_age(15))     # minor
```

The moment `return` executes, the function ends. That is why **writing one `return` in each branch of an `if`, without an `else`**, is so common.

### What Happens Without `return`

```python
def say_hi(name):
    print("Hi,", name)

result = say_hi("Alice")
print(result)        # None
```

When there is no `return`, the function returns `None` by default. Functions like this produce an *effect* (printing, writing a file) rather than producing a value.

## Crash Scene: Wrong Parameter Order

```python
def calc_bmi(weight, height):
    return round(weight / (height ** 2), 1)

print(calc_bmi(1.75, 70))     # weight and height are swapped this time
```

The output is `0.0` — because Python assigned `1.75` to `weight` and `70` to `height` by position. No error, but the result is wildly wrong, and **this kind of bug is the hardest to find**.

**How to prevent it:** call the function with keyword arguments:

```python
print(calc_bmi(weight=70, height=1.75))   # tell the function exactly who is who
```

Once you have several parameters, keyword calls eliminate this class of mistake entirely. Lesson 17 goes into more detail.

## Returning Multiple Values

A Python function can "return multiple values" — under the hood it returns a tuple, which is then automatically unpacked:

```python
def stats(numbers):
    return min(numbers), max(numbers), sum(numbers) / len(numbers)

low, high, avg = stats([80, 90, 75, 88])
print(low, high, avg)      # 75 90 83.25
```

`low, high, avg = ...` is tuple unpacking, the same mechanism you saw with packing and unpacking earlier.

## Functions Are Values Too

In Python, functions are first-class objects: they can be assigned to names and passed around:

```python
def double(x):
    return x * 2

f = double          # attach another label to the same function
print(f(5))         # 10
```

Just be aware of this for now; you will meet it again when you learn higher-order patterns like the `key` argument of `sorted` or `map`.

## Summary

- **A function = define an action once, call it with different data**, eliminating repeated code
- Definition: `def name(params):`, parameters are optional
- `return` sends back a result and ends the function immediately; "multiple return values" are really a tuple being unpacked
- A function with no `return` returns `None`
- Call functions **with keyword arguments `name=value`** to avoid order mistakes
- The `if`-`return` without `else` style is common — remember that `return` exits the function
