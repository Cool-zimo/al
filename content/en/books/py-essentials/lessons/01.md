# Setup and Your First Program

> By the end of this lesson you will have Python and VSCode installed from scratch and running your very first `hello.py`.

## Why not just code in the browser?

You might be wondering: the examples above all have a run button, so why am I asking you to install anything?

Because **the Python in your browser is a "sandbox" (Pyodide)** — it is fine for learning syntax, but it has no real file system, no real network, and no GUI. Once you get to file I/O and third-party libraries, you need an actual Python environment.

This lesson does exactly four things: install Python, install VSCode, write hello world, and run it. When you are done, your machine can run any Python program.

## Installing Python: go to the official site, skip the app store

**Step 1 — check whether it is already there.** Open a terminal (on Windows it is called "Command Prompt" or PowerShell; on a Mac it is "Terminal"; on Linux, just the terminal) and type:

```bash
python --version
```

If it prints `Python 3.x.x`, you already have it — jump to the next section. If it says "command not found", keep reading.

**Step 2 — download the installer.** Go to [python.org/downloads](https://www.python.org/downloads). The page recommends the latest version (3.13 at the time of writing). Click the yellow **Download Python 3.x.x**.

**Step 3 — tick one box. This matters.**

This is where most beginners trip up. At the bottom of the Windows installer you will see:

```
☐ Add Python 3.x to PATH      ← you MUST tick this!
```

**If you skip this, typing `python` in the terminal later will give you "command not found".** Ticking it tells the installer to register Python in your system's PATH. If you installed it without ticking the box, uninstall and reinstall — that is the easiest fix.

**Step 4 — verify.** Open a fresh terminal and type:

```bash
python --version
```

Seeing the version number means Python is installed. Now confirm that `pip` (the tool for installing third-party libraries) is there too:

```bash
pip --version
```

## Crash Scene: installed, but "command not found"

```bash
C:\> python --version
'python' is not recognized as an internal or external command
```

**Why:** 99% of the time, you skipped "Add to PATH" during installation.

**How to fix:** two options, pick one.

1. **Reinstall (recommended):** uninstall Python, run the installer again, and this time tick Add Python to PATH.
2. **Edit PATH manually:** add the Python install directory (usually `C:\Users\YourName\AppData\Local\Programs\Python\Python313`) and its `Scripts` subdirectory to your system PATH.

After installing, **open a new terminal window** before testing — old terminals do not refresh environment variables automatically.

## Installing VSCode: an editor, not Python

VSCode (Visual Studio Code) is a code editor. **It is not Python itself**, but with the right extension it is a very comfortable place to write Python.

1. Go to [code.visualstudio.com](https://code.visualstudio.com) and install it.
2. Open VSCode, click the fifth icon on the left (Extensions).
3. Search for **Python** and install the official Microsoft one (highest download count, the one that comes with Pylance).
4. Search for **Chinese** and install the language pack if you want a Chinese interface.

> VSCode is not your only option. PyCharm, Sublime, even Notepad can run Python. But VSCode is free, light, and has a great extension ecosystem — a sweet spot for beginners.

## Your first program: hello.py

On your computer, create a folder such as `D:\learn_python` (**avoid Chinese characters and spaces** in the path; you will see why later).

In VSCode: `File → Open Folder`, pick that folder. Then `New File`, and name it `hello.py`.

`.py` is the Python file extension — it tells the system and the editor "this is Python code".

Type this line:

```python
print("Hello, world")
```

Save (`Ctrl+S` or `Cmd+S`), then run.

## How to run: two ways

**Method 1: the run button (simplest)**

In VSCode, open `hello.py`. In the top-right corner there is a ▷ triangle button — click it. A terminal panel appears at the bottom and prints `Hello, world`.

**Method 2: run from the terminal (you must learn this)**

```bash
cd D:\learn_python      # first, move into the folder that holds the file
python hello.py         # then run it
```

`cd` means "change directory". If you do not `cd` into the folder first, Python will not find `hello.py`.

> Memorise these two steps: **cd into the folder, then `python filename.py`**. You will repeat this action thousands of times.

## What `print` actually does

`print` is the most basic function in Python: it **prints whatever is in the parentheses to the screen**.

```python
print("Hello, world")
print(123 + 456)
name = "Alice"
print("My name is", name)
```

```
Hello, world
579
My name is Alice
```

**You can put several things inside the parentheses, separated by commas**, and Python automatically inserts a space between them.

> The `"Hello, world"` in the first line uses straight (English) double quotes. That is a **string** — a piece of text. We cover it properly in the next lesson.

## Crash Scene: Chinese quotation marks

```python
print("你好")
```

```
  File "hello.py", line 1
    print("你好")
          ^
SyntaxError: invalid character '“' (U+201C)
```

**Why:** Chinese quotation marks `"` `"` and straight quotes `"` are **completely different characters** as far as Python is concerned. Python only understands the straight ones.

**How to fix:** delete the Chinese quotes and type straight ones. Get into the habit of switching your input method to English punctuation mode while coding.

While we are here, these three symbols are also commonly mistyped: the Chinese comma `，`, the Chinese colon `：`, and Chinese brackets `（）`. If you see `SyntaxError` and cannot figure out why, check whether you mixed in Chinese punctuation.

## Summary

- Download Python from the official site, and **always tick Add to PATH**.
- Verify with `python --version` and `pip --version` — both must work.
- VSCode plus the official Python extension is the standard setup for beginners.
- Running a program = `cd` to the folder + `python filename.py`.
- `print()` writes content to the screen; separate multiple values with commas.
- Quotes, commas, colons, and brackets must all be straight punctuation.
