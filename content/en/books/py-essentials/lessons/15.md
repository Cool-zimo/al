# Sets: deduplication and set operations

> By the end of this lesson you will be able to deduplicate with sets, compute intersections and unions, and you will know when a set is the right tool for the job.

## What if a list has duplicates?

```python
votes = ["apple", "banana", "apple", "cherry", "banana", "apple"]
```

You want to know how many different fruits there are, and who actually voted — doing it with a list is fiddly. Sets solve this naturally: **a set (set) contains no duplicates, and its order is not guaranteed.**

```python
fruits = {"apple", "banana", "cherry", "apple", "banana"}
print(fruits)      # {'cherry', 'apple', 'banana'}   order varies, duplicates are gone
```

A set uses **curly braces `{}`** (the kind with no key-value pairs). Note: you cannot write an empty set as `{}` (that is an empty dictionary) — you have to use `set()`.

## Deduplication: one line

Convert a list to a set and back, and the duplicates vanish:

```python
votes = ["apple", "banana", "apple", "cherry", "banana", "apple"]
unique = list(set(votes))
print(unique)       # order varies, but each item appears only once
```

`len(set(votes))` directly gives you "how many distinct votes there were".

> The fact that the order varies is a property of sets. If you need "deduplication while keeping the original order", you need a different approach:

```python
seen = set()
result = []
for v in votes:
    if v not in seen:
        seen.add(v)
        result.append(v)
print(result)       # ['apple', 'banana', 'cherry']   order preserved
```

## Add, remove, and look up

```python
s = {"apple", "banana"}

s.add("cherry")        # add
print(s)               # {'cherry', 'banana', 'apple'}

s.remove("banana")     # remove — KeyError if the element is not present
print(s)               # {'cherry', 'apple'}

s.discard("watermelon")    # remove — no error even if it is not there (recommended)
print(s)

print("apple" in s)   # True, membership testing is extremely fast
print(len(s))         # 2

s.clear()             # empty the set
print(s)              # set()
```

**The difference between `remove` and `discard`:** if the item is absent, `remove` raises an error while `discard` stays silent. When you are unsure whether it is there, use `discard`.

## Set operations: intersection, union, difference

This is where sets really shine — **intersection, union, difference, and symmetric difference**, as easy as writing maths:

| Operation | Syntax | Meaning | Example |
|---|---|---|---|
| Intersection | `a & b` | in both | common friends |
| Union | `a | b` | everything together, deduped | all tags |
| Difference | `a - b` | in a but not in b | exclusive permissions |
| Symmetric difference | `a ^ b` | in exactly one of them | the non-overlapping part |

```python
frontend = {"Alice", "Bob", "Charlie", "David"}
backend = {"Bob", "David", "Eve", "Frank"}

print(frontend & backend)    # {'Bob', 'David'}         knows both
print(frontend | backend)    # {'Alice', 'Bob', ...}    everyone (deduped)
print(frontend - backend)    # {'Alice', 'Charlie'}     frontend only
print(backend - frontend)    # {'Eve', 'Frank'}         backend only
print(frontend ^ backend)    # {'Alice', 'Charlie', 'Eve', 'Frank'}   in exactly one
```

**This family of operations is immensely practical for data comparison, permission checks, and tag analysis** — much cleaner than writing a for loop.

## Crash Scene: accidentally creating an empty dict

```python
s = {}          # this is an empty dict, not an empty set
s.add("apple")   # ❌
```

```
AttributeError: 'dict' object has no attribute 'add'
```

**Why:** `{}` in Python means an empty dictionary. An empty set must be written as `set()`.

**How to fix:**

```python
s = set()               # the correct empty set
s.add("apple")
print(s)                # {'apple'}
```

> By the way, `{1, 2, 3}` has elements, so Python can tell it is a set; only the empty version is ambiguous, which is why you need `set()`.

## Subsets and supersets

Testing inclusion:

```python
a = {1, 2, 3}
b = {1, 2, 3, 4, 5}

print(a.issubset(b))    # True   a is a subset of b
print(b.issuperset(a))  # True   b is a superset of a
print(a <= b)           # True   operator version
print(a < b)            # True   proper subset (they must not be equal)
```

## When to use a set, when to use a list

| | list | set |
|---|---|---|
| Order | ordered | **no order** |
| Duplicates | allowed | **automatic deduplication** |
| Lookup | slow (must iterate) | **fast** (hashing) |
| Typical use | when you need order or modification | deduplication, unions/intersections, fast membership |

Rule of thumb: **need order or modification → list; need deduplication or set operations → set.**

## Summary

- A set uses `{}` (for an empty set you must write `set()`, not `{}`)
- A set is **unordered and its elements are unique**
- Deduplicate: `list(set(a_list))`; order-preserving deduplication must be written by hand
- Add: `add()`; remove: `remove()` errors, `discard()` stays silent
- Set operations: `&` intersection, `|` union, `-` difference, `^` symmetric difference
- Subset test: `issubset()` or `<=`
- For deduplication / unions / fast `in` tests use a set; for order use a list
