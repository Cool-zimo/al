> By the end of this lesson you will combine everything from the first 23 lessons into a contact book that can create, read, update, delete, and save to a file.

## This Time We Tie Everything Together

Each concept on its own looks small, but **real programs are their combinations**. This contact book will use:

- dictionaries for a single contact, a list for all of them
- functions to wrap each operation
- loops and conditions for the menu
- file I/O for persistence
- exceptions to stay safe from crashes

## Designing the Data Structure

One contact is a dictionary; the list of all contacts is the "address book":

```python
# one contact
contact = {"name": "Alice", "phone": "13800138000", "email": "alice@example.com"}

# the whole book
contacts = [
    {"name": "Alice", "phone": "13800138000", "email": "alice@example.com"},
    {"name": "Bob", "phone": "13900139000", "email": "bob@example.com"},
]
```

**Why a list of dictionaries instead of a dictionary keyed by name?** Because two people can share a name, and we need to iterate, sort, and delete by position — a list is the natural fit.

## Step 1: Create — Adding a Contact

```python
def add_contact(contacts):
    name = input("name: ").strip()
    phone = input("phone: ").strip()
    email = input("email: ").strip()

    contacts.append({
        "name": name,
        "phone": phone,
        "email": email
    })
    print("added:", name)
```

`strip()` removes leading and trailing whitespace — standard practice for cleaning user input.

## Step 2: Read — Listing and Searching

```python
def list_contacts(contacts):
    if not contacts:
        print("the contact book is empty")
        return

    print(f"{'No.':<4} {'Name':<8} {'Phone':<15} {'Email'}")
    print("-" * 45)
    for i, c in enumerate(contacts, start=1):
        print(f"{i:<4} {c['name']:<8} {c['phone']:<15} {c['email']}")
```

`enumerate(contacts, start=1)` numbers the entries from 1, which is cleaner than maintaining `i += 1` yourself. `f"{i:<4}"` left-aligns in a 4-character field so the columns line up.

**Searching by name:**

```python
def search_contact(contacts):
    keyword = input("search keyword: ").strip().lower()
    results = []

    for c in contacts:
        if keyword in c["name"].lower() or keyword in c["email"].lower():
            results.append(c)

    if not results:
        print("no matches")
        return

    print(f"found {len(results)}:")
    for c in results:
        print(f"  {c['name']}  {c['phone']}  {c['email']}")
```

`keyword in c["name"].lower()` gives you a case-insensitive fuzzy match.

## Step 3: Update and Delete

```python
def delete_contact(contacts):
    list_contacts(contacts)
    if not contacts:
        return

    try:
        idx = int(input("delete which one (enter the number): ")) - 1
        if 0 <= idx < len(contacts):
            removed = contacts.pop(idx)
            print("deleted:", removed["name"])
        else:
            print("number out of range")
    except ValueError:
        print("please enter a number")
```

**Three concepts in one place:** `try/except` guards against bad input, list indexing does the removal, and `if` checks the boundary. This is the difference between "learning in isolation" and "learning to combine".

```python
def update_contact(contacts):
    list_contacts(contacts)
    if not contacts:
        return

    try:
        idx = int(input("update which one: ")) - 1
        if not (0 <= idx < len(contacts)):
            print("number out of range")
            return
    except ValueError:
        print("please enter a number")
        return

    c = contacts[idx]
    print(f"current: {c['name']}  {c['phone']}  {c['email']}")

    name = input(f"new name (blank to keep '{c['name']}'): ").strip()
    phone = input(f"new phone (blank to keep '{c['phone']}'): ").strip()
    email = input(f"new email (blank to keep '{c['email']}'): ").strip()

    if name:
        c["name"] = name
    if phone:
        c["phone"] = phone
    if email:
        c["email"] = email

    print("updated")
```

The interaction detail "leave it blank to keep the current value" is handled cleanly by checking `if value:`.

## Step 4: Saving and Loading

Save in JSON — a universal text format that Python supports through the built-in `json` module:

```python
import json

def save_contacts(contacts, filename="contacts.json"):
    with open(filename, "w", encoding="utf-8") as f:
        json.dump(contacts, f, ensure_ascii=False, indent=2)
    print("saved to", filename)

def load_contacts(filename="contacts.json"):
    try:
        with open(filename, "r", encoding="utf-8") as f:
            return json.load(f)
    except FileNotFoundError:
        return []      # no file means start fresh
```

`json.dump(..., ensure_ascii=False)` keeps non-ASCII text readable; without it you get escapes like `\u5f20\u4e09`. `indent=2` pretty-prints the file with indentation.

## Step 5: Wiring It Up With a Menu

```python
def show_menu():
    print("\n===== Contact Book =====")
    print("1. add contact")
    print("2. list all")
    print("3. search")
    print("4. update")
    print("5. delete")
    print("6. save and quit")
    return input("choose: ")

def main():
    contacts = load_contacts()

    while True:
        choice = show_menu()

        if choice == "1":
            add_contact(contacts)
        elif choice == "2":
            list_contacts(contacts)
        elif choice == "3":
            search_contact(contacts)
        elif choice == "4":
            update_contact(contacts)
        elif choice == "5":
            delete_contact(contacts)
        elif choice == "6":
            save_contacts(contacts)
            print("goodbye")
            break
        else:
            print("no such option")

main()
```

**`while True` + `if/elif` + `break`** is the standard skeleton of a command-line program. Option 6 saves first and then breaks, so the data is written before you exit.

## Crash Scene: Comparing Menu Input With an Integer

```python
choice = input("choose: ")   # "2"
if choice == 2:              # the string "2" is not equal to the integer 2
    ...
```

The string `"2"` is not equal to the integer `2`, so the `if` will never match.

**Two valid fixes:**

```python
# Option 1: compare with a string (recommended - input is already a string)
if choice == "2":

# Option 2: convert to int (but wrap it in try, since the user might type letters)
try:
    num = int(choice)
    if num == 2:
        ...
except ValueError:
    print("please enter a number")
```

For menu comparisons, **comparing with strings is the simplest**; converting to int only adds another layer of risk.

## Summary

- Data structure: one contact is a dict, the book is a list of dicts
- Five operations, each in its own function: create, read, update, delete, save
- Search uses `keyword in str.lower()` for a case-insensitive fuzzy match
- Save with `json.dump` (ensure_ascii=False to preserve readable text), load with `json.load`
- When the file is missing, `return []` and start as a new book
- Menu uses `while True` + `if/elif` + `break`, and saves before breaking out
- Compare menu choices with strings, not integers
