# Modules and Packages: Standing on the Shoulders of Giants

> By the end of this lesson you will be able to use features written by others, and split your own code into reusable modules.

## The Standard Library: Ships With Python

Much of Python's power comes from its enormous standard library — **it ships with Python**, so you do not install anything extra.

```python
import random
import math
import json
import os
import datetime
```

These modules give you random numbers, math operations, JSON handling, operating-system interaction, and date and time support. Almost every line you write ends up using one of them.

## Four Ways to Import

```python
import random                    # 1. import the whole module, use module.name
print(random.randint(1, 10))

from random import randint       # 2. import one feature, use it by name directly
print(randint(1, 10))

from random import randint as ri # 3. import and rename
print(ri(1, 10))

import numpy as np               # 4. the conventional alias for a third-party library
```

**When to use which:**

- Short module name, used rarely: `import math`, then `math.sqrt`
- Only one function, and the name is short: `from math import sqrt`, then just `sqrt`
- Long name or a name collision: rename it with `as`

> Do not use `from random import *` — it dumps every name from the module into your current namespace, where it can collide with your own variables and hurts readability.

## `random` and `math`: The Two Most-Used Modules

```python
import random
import math

# random
print(random.randint(1, 100))        # integer from 1 to 100 (inclusive)
print(random.random())               # float between 0 and 1
print(random.choice(["red", "blue", "green"]))   # pick one at random
print(random.sample([1, 2, 3, 4, 5], 3))         # pick 3 without replacement
random.shuffle([1, 2, 3, 4, 5])                 # shuffle in place

# math
print(math.pi)                       # 3.141592653589793
print(math.sqrt(16))                 # 4.0
print(math.floor(3.9))               # 3  round down
print(math.ceil(3.1))                # 4  round up
print(math.log(100, 10))             # 2.0  base 10
```

`random.choice` is incredibly handy for gacha pulls, drawings, and random greetings; `math.floor` and `math.ceil` are the standard rounding tools.

## Crash Scene: Your Variable Shadowed the Import

```python
from random import randint
randint = 10        # accidentally used randint as a variable name
print(randint(1, 5))   # ERROR
```

```
TypeError: 'int' object is not callable
```

**Why:** you pointed the name `randint` at the number 10, overwriting the function. In Python, functions are ordinary objects, so once a name is reused the original is no longer reachable.

**How to prevent it:** never use a module name or a function name as a variable name. Check that a name is free before you use it.

## Installing Third-Party Packages With `pip`

Beyond the standard library, the Python community maintains hundreds of thousands of third-party packages. **`pip` is the tool that installs them**, and it comes with Python.

```bash
pip install requests
pip install pandas
pip install flask
```

```python
import requests

resp = requests.get("https://api.github.com")
print(resp.status_code)     # 200
print(resp.json())          # response body parsed into a dictionary
```

Once installed, you import it just like the standard library. `requests` is the de-facto standard for HTTP requests in Python.

> If pip says "command not found", go back to lesson 1 and check your Python PATH configuration.

## Writing Your Own Module

You can split your code into modules too. Create a file called `utils.py`:

```python
# utils.py
def format_name(first, last):
    return f"{last}, {first}"

PI = 3.14159
```

Then another file, `main.py`, can import it:

```python
# main.py
import utils

print(utils.format_name("Alice", "Smith"))    # Smith, Alice
print(utils.PI)                               # 3.14159
```

At its core, `import` **loads another file as a module**. Group related functions in one file and you have built your own "library".

## Summary

- The standard library ships with Python: `random`, `math`, `json`, `os`, `datetime`, and more
- Four import styles: `import x`, `from x import y`, `as` for renaming, and never `*`
- `random` for randomness, `math` for math — the everyday pair
- Do not name variables after modules or functions, or you will shadow the import
- Install third-party packages with `pip install name`, then import as usual
- Your own code can be modular too: one `.py` file is one module
