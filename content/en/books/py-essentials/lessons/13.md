# Tuples and dictionaries: which to use when

> By the end of this lesson you will be able to tell tuples and lists apart, and you will use dictionaries to look up data by "name".

## First, meet the tuple

A **tuple** is "a list you cannot change". It uses parentheses, with elements separated by commas:

```python
point = (3, 5)
rgb = (255, 128, 0)

print(point[0])     # 3
print(rgb[1])       # 128
```

Indexing, slicing, and iteration — most things you can do with a list, you can do with a tuple. But **you cannot add, remove, or change elements:**

```python
point = (3, 5)
point[0] = 10       # ❌ error
```

```
TypeError: 'tuple' object does not support item assignment
```

**The point of a tuple is that it is immutable.** You write down a coordinate, an RGB colour, a date — values that should not be changed halfway through. If you use a tuple, Python will stop you with an error if you accidentally try to modify it. That is a layer of protection.

**When to use a tuple, when to use a list?**

| | list `[]` | tuple `()` |
|---|---|---|
| Mutability | mutable — can add/remove/change | **immutable** — cannot change after creation |
| Typical use | a collection of similar items: scores, a task list | a fixed structure: a coordinate, a colour, a record |
| Can it be a dict key? | no (mutable) | **yes** (immutable) |

> Rule of thumb: **data that changes → list; data that is a fixed set of attributes → tuple.**

## Packing and unpacking

Tuples have a very handy feature — **automatic packing** and **unpacking**:

```python
# Packing: assigning several values to one variable automatically makes a tuple
point = 3, 5        # equivalent to (3, 5)

# Unpacking: splitting a tuple into several variables
x, y = (3, 5)
print(x)            # 3
print(y)            # 5
```

This is the secret behind "swapping two variables" from lesson 2: `a, b = b, a` first packs the right side into a tuple, then unpacks it into the left side.

Unpacking can also be used to **gracefully ignore a value you do not need**:

```python
name, age, _ = ("Alice", 18, "London")
print(name, age)    # Alice 18
```

The underscore `_` is the conventional placeholder for "I am not using this value".

## Dictionaries: looking up by name

Lists use numeric indices to fetch elements. But often you want to fetch **by "name"**:

```python
# Storing a person as a list: you have to remember that 0 is name, 1 is age...
person = ["Alice", 18, "London"]

# Storing as a dictionary: fetch directly by name
person = {
    "name": "Alice",
    "age": 18,
    "city": "London"
}
print(person["name"])    # Alice
print(person["age"])     # 18
```

A **dictionary (dict)** stores **key-value pairs**: `{key: value, key: value}`. The key is the index and the value is the content. You look up by name instead of by position.

A dictionary's keys **must be of an immutable type** (strings, numbers, and tuples all work); the value can be anything.

## Adding, removing, changing, and fetching in a dict

```python
person = {"name": "Alice", "age": 18}

# Fetch
print(person["name"])        # Alice
print(person.get("city", "unknown"))   # unknown (key missing -> use default, no error)

# Change
person["age"] = 19           # if the key exists, change it
print(person["age"])         # 19

# Add
person["city"] = "Paris"     # if the key does not exist, add it
print(person)                # {'name': 'Alice', 'age': 19, 'city': 'Paris'}

# Remove
del person["age"]            # delete a key-value pair
print(person)                # {'name': 'Alice', 'city': 'Paris'}

person.pop("city")           # another way to remove, returning the deleted value
print(person)                # {'name': 'Alice'}
```

### Three ways to fetch, with different safety levels

```python
scores = {"math": 90, "english": 95}

# 1. Square brackets: KeyError if the key does not exist
print(scores["history"])        # ❌ KeyError

# 2. get: returns None if the key is missing, or the default you provide
print(scores.get("history"))            # None
print(scores.get("history", 0))         # 0

# 3. in: check whether it is there first, then fetch
if "history" in scores:
    print(scores["history"])
```

**The safest way to look up in a dictionary is `get(key, default)`** — it never errors, and you can supply a sensible default.

## Crash Scene: looking up a key that does not exist

```python
scores = {"math": 90, "english": 95}
print(scores["history"])
```

```
KeyError: 'history'
```

**Why:** the dictionary has no key `"history"`, and the `[]` lookup raises an error immediately when given a missing key.

**How to fix:** pick one of three:

```python
# Method 1: check with in first
if "history" in scores:
    print(scores["history"])
else:
    print("no score yet")

# Method 2: get + default (recommended)
print(scores.get("history", "no score yet"))

# Method 3: setdefault, which writes the default in and returns it if the key is missing
scores.setdefault("history", 0)
```

## Summary

- **A tuple `()` is immutable**; a list `[]` is mutable. Use a tuple for data that must not change.
- Tuples pack/unpack: `x, y = (3, 5)`; `_` means "I am not using this variable"
- **A dictionary `{key: value}` is looked up by name**, no need to remember positions — ideal for "named attributes"
- Dictionary keys must be immutable; three ways to fetch: `[]`, `get()`, `in`
- **`get(key, default)` is the safest** — no KeyError
- Tuples can be dictionary keys; lists cannot
