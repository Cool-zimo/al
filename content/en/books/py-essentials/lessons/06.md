# if / elif / else: teaching your program to decide

> By the end of this lesson you will be able to write "if… otherwise…" logic so your program takes different paths based on input.

## Why you need decisions

Up to the previous lesson, every program you wrote was a straight line: top to bottom, every line executed.

But reality is not like that. A food-delivery app checks whether you are logged in; an exam program assigns a grade based on your score. **A program has to "play it by ear"**, and that is what `if` is for.

```python
age = int(input("How old are you? "))

if age >= 18:
    print("You can register")
else:
    print("Not yet, wait a bit longer")
```

The part `age >= 18` is called a **condition**; evaluating it produces `True` or `False`. If it is `True`, the code under `if` runs; otherwise the code under `else` runs.

## The syntax skeleton

```python
if condition:
    runs when the condition is true
else:
    runs when the condition is false
```

Three places where mistakes happen most often:

1. **There must be a colon `:` after `if`** — a Chinese colon will not do; missing it is guaranteed to error
2. **The next line must be indented** (by 4 spaces) — Python recognises "this belongs inside the if" by indentation
3. **`else` also needs a colon**

## Indentation: Python's ID card

Many languages use curly braces `{}` to mark blocks; Python uses **indentation**. Lines at the same level must be indented consistently:

```python
age = 20

if age >= 18:
    print("adult")
    print("can vote")      # both lines have the same indent, so both belong inside the if
print("this line always runs")   # not indented, so it is outside the if
```

```
adult
can vote
this line always runs
```

Indentation is Python's most distinctive feature. **Use exactly 4 spaces**, never a tab, and never mix them.

## Multiple branches: elif

For three or more branches, use `elif` (short for "else if"):

```python
score = int(input("Score: "))

if score >= 90:
    print("excellent")
elif score >= 60:
    print("pass")
else:
    print("fail")
```

`elif` is checked from top to bottom, and **as soon as one branch matches, the rest are skipped**.

> Order matters. If you put `score >= 60` first, a score of 95 would be judged "pass" — because it satisfies the 60 condition first and the program moves on immediately.

## Comparison operators

| Operator | Meaning | Example |
|---|---|---|
| `==` | equal | `age == 18` |
| `!=` | not equal | `age != 18` |
| `>` `>=` | greater than / greater than or equal | `score > 60` |
| `<` `<=` | less than / less than or equal | `score <= 100` |

**Pay special attention to the difference between `==` and `=`:** one equals sign is "assignment" (put it in), two equals signs is "comparison" (is it equal?).

```python
age = 18       # assignment
if age == 18:  # comparison
    print("just came of age")
```

## Crash Scene: writing assignment instead of comparison

```python
# WRONG
if age = 18:
    print("adult")
```

```
SyntaxError: invalid syntax
```

**Why:** after `if` you can only put an **expression** (something that evaluates to true or false), and `age = 18` is an assignment statement, not a true/false test. Python simply rejects it.

**How to fix:** write `age == 18`.

> This trap is especially common among people coming from C or Java, where the syntax permits this mistake. Python forces you to keep assignment and comparison separate by erroring out.

## A more practical form: the conditional expression

When an if-else is used in exactly one place and the logic is short, you can write it on one line:

```python
# full form
if age >= 18:
    status = "adult"
else:
    status = "minor"

# one-line version (conditional expression)
status = "adult" if age >= 18 else "minor"
```

Read it as "if the condition holds, take the first value; otherwise take the second". Good for simple assignments; do not nest too many layers or readability collapses.

## A complete decision program

```python
import random
secret = random.randint(1, 100)
guess = int(input("Guess a number from 1 to 100: "))

if guess == secret:
    print("You got it!")
elif guess < secret:
    print("Too low, go higher")
else:
    print("Too high, go lower")
```

`random.randint(1, 100)` generates a random integer between 1 and 100 inclusive. The core logic of this little game is just those few lines.

## Summary

- `if / elif / else` branches your program based on a condition
- Syntax essentials: `if` followed by a condition plus a colon; the next line **indented by 4 spaces**
- `==` is comparison, `=` is assignment — never mix them up
- Several branches use `elif`; matching stops at the first hit
- Order decides the result: for range checks, put the stricter condition first
- A short if-else can be written on one line: `a if condition else b`
