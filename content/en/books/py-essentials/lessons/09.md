# for and range: when you know how many times

> By the end of this lesson you will be able to control a loop's count precisely with `for`, and you will learn the one rule you must memorise: the endpoint is not included.

## for is better than while when you "can count" the rounds

The previous lesson said that while is for "I do not know how many rounds". If you **know you want exactly 10 rounds**, `for` is cleaner:

```python
for i in range(5):
    print(i)
```

```
0
1
2
3
4
```

## The three rules of range

`range` generates a sequence of integers. **The syntax is `range(start, stop, step)`**; all three are optional, defaulting to start 0 and step 1.

| Form | Sequence produced | Notes |
|---|---|---|
| `range(5)` | 0,1,2,3,4 | the stop value is not included |
| `range(2, 6)` | 2,3,4,5 | from 2 up to 5 |
| `range(0, 10, 2)` | 0,2,4,6,8 | step 2, taking every other one |
| `range(5, 0, -1)` | 5,4,3,2,1 | counting down |

### The iron rule: the endpoint is not included

`range(5)` gives **0 through 4**, not 0 through 5. This rule runs through all of Python and you must internalise it:

```python
for i in range(5):
    print(i)      # prints 0 1 2 3 4 — five numbers in total
```

The benefit is that **stop minus start equals the count**: `range(2, 6)` has `6 - 2 = 4` numbers. If you want 1 through 10, write `range(1, 11)` — the stop is 11 because 11 is not included.

## Crash Scene: treating the endpoint as inclusive

```python
# WRONG: intended to print 1 through 10
for i in range(1, 10):
    print(i)
```

The actual output is 1 through 9 — 10 is missing.

**How to fix:** add one to the endpoint: `range(1, 11)`.

> This trap is most painful when "iterating over indices". A list of length 5 has valid indices 0..4, which line up exactly with `range(5)`. So **when iterating over indices, use `range(len(x))` directly** — it matches perfectly.

## for can iterate over anything "iterable"

`range` is only one example. Strings, lists, tuples, and dictionaries can all be handed directly to `for`:

```python
for ch in "Hi":
    print(ch)
# H
# i

for fruit in ["apple", "banana", "cherry"]:
    print(fruit)
# apple banana cherry
```

`for` automatically fetches the items one at a time, with no need to manage an index yourself. This index-free style of iteration is the most common use of `for` in Python.

## enumerate: when you need both the item and its index

If you want **both the element and its position** while iterating over a list, use `enumerate`:

```python
fruits = ["apple", "banana", "cherry"]
for index, fruit in enumerate(fruits):
    print(index, fruit)
```

```
0 apple
1 banana
2 cherry
```

`enumerate` yields pairs of "index + element". Use it when you need to print a序号 or locate a position — much cleaner than maintaining your own `i += 1`.

## Iterating over a string

A string is fundamentally a sequence of characters, and `for` splits it automatically:

```python
for ch in "Python":
    print(ch)
# P y t h o n
```

Counting how many vowels there are:

```python
text = "hello world"
count = 0
for ch in text:
    if ch in "aeiouAEIOU":
        count += 1
print(count)      # 3
```

`ch in "aeiouAEIOU"` is something we will cover formally later but you can already use: it tests whether a character appears inside that sequence.

## Summary

- `for i in range(n):` is the first choice for a loop whose count you know
- **The stop value of `range(n)` is not included**: `range(5)` is 0..4
- `range(start, stop, step)`: all three parameters have defaults
- To print 1..10, write `range(1, 11)` — the stop is always one higher than you want
- `for` can iterate over strings, lists, tuples, and any other iterable
- Need both index and element: `enumerate`
- Iterating over a string means taking it character by character; `in` tests membership
