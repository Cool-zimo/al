# Common dictionary operations

> By the end of this lesson you will be able to iterate over dictionaries, safely fetch and delete, and read "a dictionary inside a dictionary" — the real-world data structure.

## Three ways to iterate over a dictionary

A dictionary has an extra dimension (key-value pairs), so there are three ways to iterate:

```python
person = {"name": "Alice", "age": 18, "city": "London"}

# Iterate over keys (this is the default)
for key in person:
    print(key)
# name / age / city

# Iterate over values
for value in person.values():
    print(value)
# Alice / 18 / London

# Iterate over keys and values together
for key, value in person.items():
    print(key, "=", value)
# name = Alice
# age = 18
# city = London
```

`person.items()` returns something iterable containing the key-value pairs, and combined with `key, value` unpacking it is the most convenient form.

> `for x in a_dictionary` iterates over the **keys** by default. Need the values? Use `.values()`. Need both? Use `.items()`.

## Safe deletion: pop with a default

The previous lesson covered `del` and `pop`. `pop` has an extra advantage — **it can take a default, so it does not error when there is nothing to delete**:

```python
scores = {"math": 90, "english": 95}

# del raises an error if there is nothing to delete
# del scores["history"]      # KeyError

# pop with a default is safe
value = scores.pop("history", 0)
print(value)              # 0 (nothing was deleted, so the default is returned)
print(scores)             # {'math': 90, 'english': 95}
```

**For any deletion where you are not sure the key exists, use `pop(key, default)`.**

## keys, values, and items are all iterable

```python
scores = {"math": 90, "english": 95, "history": 88}

print(list(scores.keys()))     # ['math', 'english', 'history']
print(list(scores.values()))   # [90, 95, 88]
print(list(scores.items()))    # [('math', 90), ('english', 95), ('history', 88)]
```

Wrap the result in `list()` and you get a list. For example, "find all the subjects with a passing grade":

```python
passed = []
for subject, score in scores.items():
    if score >= 60:
        passed.append(subject)
print(passed)      # ['math', 'english', 'history']
```

## Crash Scene: adding keys while iterating

Just like with lists, modifying the structure during iteration is a trap. Deleting is relatively safe, but **adding a key raises an error**:

```python
# WRONG
scores = {"math": 90, "english": 95}
for subject in scores:
    if scores[subject] < 60:
        scores[subject + "_retake"] = True   # adding a key while iterating
```

```
RuntimeError: dictionary changed size during iteration
```

**How to fix:** iterate over a copy (turn it into a list):

```python
for subject in list(scores.keys()):
    if scores[subject] < 60:
        scores[subject + "_retake"] = True
```

`list(scores.keys())` takes a snapshot of the keys first; iterating over the snapshot is safe.

## Nested dictionaries: what real data looks like

In real projects, dictionaries are almost always nested — a dictionary whose values are themselves dictionaries or lists:

```python
students = {
    "Alice": {"math": 90, "english": 95, "history": 88},
    "Bob": {"math": 78, "english": 82, "history": 91},
    "Charlie": {"math": 60, "english": 70, "history": 65},
}

# Look up Alice's math score
print(students["Alice"]["math"])      # 95

# Iterate over everyone
for name, scores in students.items():
    total = 0
    for subject, score in scores.items():
        total += score
    print(name, "total", total, "average", round(total / len(scores), 1))
```

`students["Alice"]["math"]` — this **chained lookup** is the standard way to work with nested dictionaries: drill down one layer at a time.

## Merging dictionaries

```python
a = {"name": "Alice", "age": 18}
b = {"city": "London", "age": 20}

# Method 1: update, merging b into a (a shared key gets overwritten by b)
a.update(b)
print(a)      # {'name': 'Alice', 'age': 20, 'city': 'London'}

# Method 2: {**a, **b}, producing a new dictionary without modifying the originals
c = {**a, **b}
```

`update` modifies the original dictionary; `{**a, **b}` creates a new one. Whichever key appears later overwrites an earlier one.

## A counting scenario: dictionaries as counters

A dictionary is the ideal tool for word-frequency counting:

```python
words = ["apple", "banana", "apple", "cherry", "banana", "apple"]
count = {}

for w in words:
    count[w] = count.get(w, 0) + 1

print(count)      # {'apple': 3, 'banana': 2, 'cherry': 1}
```

`count.get(w, 0) + 1` is the heart of the trick: **if the key is missing, default to 0, then add 1**. This is the classic one-liner for counting with a dictionary.

## Summary

- Three ways to iterate: `for key`, `for v in d.values()`, `for k, v in d.items()`
- By default, `for x in a_dictionary` iterates over the **keys**
- For deletion use `pop(key, default)`; use it whenever you are unsure whether the key exists
- Adding keys while iterating raises `RuntimeError`; use `list(d.keys())` to take a snapshot
- For nested dictionaries use chained lookup: `d["a"]["b"]`
- Merge: `update()` (modifies original) or `{**a, **b}` (new dictionary)
- `count[k] = count.get(k, 0) + 1` is the dictionary counting template
