# Arithmetic and String Concatenation

> By the end of this lesson you will be able to use Python as a calculator, and understand why the plus sign means two completely different things to numbers and to strings.

## Calculation is what programs do best

Anything a calculator can do, Python can do in one line. Here are six operators to start with:

| Operator | Meaning | Example | Result |
|---|---|---|---|
| `+` | addition | `3 + 5` | `8` |
| `-` | subtraction | `10 - 3` | `7` |
| `*` | multiplication | `4 * 6` | `24` |
| `/` | division | `10 / 4` | `2.5` |
| `//` | floor division | `10 // 4` | `2` |
| `%` | remainder | `10 % 4` | `2` |
| `**` | power | `2 ** 10` | `1024` |

```python
print(3 + 5)        # 8
print(10 / 4)       # 2.5   ordinary division, result is always float
print(10 // 4)      # 2     floor division, chops off the decimal
print(10 % 4)       # 2     remainder
print(2 ** 10)      # 1024  2 to the 10th power
print(9 ** 0.5)     # 3.0   square root
```

> For money and time calculations, reach for `//` and `%` often. For example `137 minutes = 2 hours 17 minutes`: `137 // 60` gives the hours, `137 % 60` gives the minutes.

## Order of operations: the same as in maths

Python follows the usual arithmetic precedence: **multiplication and division before addition and subtraction, exponentiation highest of all, parentheses first**.

```python
print(2 + 3 * 4)      # 14, not 20
print((2 + 3) * 4)    # 20, parentheses change the order
print(2 ** 3 ** 2)    # 512, exponentiation is right-associative: 2 ** (3**2) = 2**9
```

Cannot remember the precedence? **Use parentheses.** They are more reliable than your memory.

## Crash Scene: `-2 ** 2` is not 4

```python
print(-2 ** 2)
```

Many people expect 4. The actual output is `-4`.

**Why:** exponentiation `**` has **higher** precedence than the minus sign. Python reads this as `-(2 ** 2)` — it calculates `2**2 = 4` first, then negates it.

```python
print((-2) ** 2)    # 4, parentheses mean "the square of negative two"
print(-(2 ** 2))    # -4, which is what the line above actually meant
```

**Rule of thumb: always parenthesise a negative base in a power operation.** This is where Python and conventional maths notation collide most often.

## `+` is two different operators

The same plus sign does two completely different jobs depending on whether it operates on **numbers** or on **strings**:

```python
print(3 + 5)        # 8       numbers are added
print("3" + "5")    # "35"    strings are concatenated
```

**With numbers, plus means arithmetic; with strings, plus means concatenation.** Sticking two strings together is concatenation:

```python
first = "Al"
last = "ice"
print(first + last)     # Alice
```

And `*` applied to a string means "repeat":

```python
print("ha" * 3)         # hahaha
print("-" * 20)         # --------------------
```

That `print("-" * 20)` is great for drawing divider lines.

## Crash Scene: numbers and strings cannot be added

```python
age = 18
print("I am " + age + " years old")
```

```
TypeError: can only concatenate str (not "int") to str
```

**Why:** `+` requires both sides to have the same type. The left side is the string `"I am "`, the right side is the integer `18`, and Python refuses to guess.

**Three ways to fix it:**

```python
# Method 1: convert the number to a string
print("I am " + str(age) + " years old")

# Method 2 (recommended): use a comma and let print do the joining
print("I am", age, "years old")

# Method 3 (the cleanest): f-string — put f before the string and wrap variables in {}
print(f"I am {age} years old")
```

The third form, the `f-string`, is the most common style — variables embedded right inside the sentence, reading like natural language. We will use it heavily in the next lesson on conditions.

> Each of the three tools has its place: pure concatenation uses `+`, mixed output uses commas, and embedding variables inside a string uses f-strings.

## Common built-in functions

| Function | What it does | Example | Result |
|---|---|---|---|
| `round(x, n)` | round to n decimal places | `round(3.14159, 2)` | `3.14` |
| `abs(x)` | absolute value | `abs(-7)` | `7` |
| `min(a,b,c)` | smallest value | `min(3, 1, 5)` | `1` |
| `max(a,b,c)` | largest value | `max(3, 1, 5)` | `5` |
| `sum(list)` | sum of a list | `sum([1,2,3])` | `6` |

```python
score = 87.586
print(round(score, 1))        # 87.6
print(abs(-20) + min(3, 9))   # 23
```

## Summary

- Six operators: `+ - * / // % **`; `/` always returns float
- Precedence: power highest, then multiplication/division, then addition/subtraction; parentheses first
- **`-2 ** 2` is `-4`** — power binds tighter than minus, so use parentheses
- `+` adds numbers but concatenates strings; `*` repeats strings
- Mixing numbers and strings: use commas, `str()` conversion, or an f-string
- `round / abs / min / max / sum` are the built-ins you will use every day
