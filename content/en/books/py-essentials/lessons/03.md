# Making Your Program Talk and Listen

> By the end of this lesson your program will be able to "ask a question, wait for an answer, and respond" — it can finally hold a conversation.

## A program that only outputs is a broadcast

The programs in the previous lesson were like a broadcast: the program spoke, you listened. It never waited for you to reply.

Real programs are interactive. For example: you open a banking app, it asks "What amount?", you type a number, and it calculates. This relies on two functions working together:

- **`print()`**: the program speaks out
- **`input()`**: the program stops and waits for you to type something in

```python
name = input("What is your name? ")
print("Hello,", name)
```

After running, the program prints "What is your name?", then **stops and waits for you to press a key**. Only after you type something and press Enter does it continue and print "Hello, XXX".

## input is always a string

This is the single most important rule in this lesson, worth emphasising on its own: **whatever `input()` returns is always a string (str)**, even if you type a number.

```python
age = input("How old are you? ")
print(type(age))
```

You type `18`, and `type` reports `str` — the string `"18"`, not the number 18.

**What is the difference?** A string can be concatenated, but it cannot be calculated with directly:

```python
age = input("How old are you?")   # suppose the user types 18
next_year = age + 1         # ❌ error
```

## Crash Scene: calculating with the result of input directly

```python
age = input("How old are you? ")
print("Next year you will be", age + 1, "years old")
```

```
TypeError: can only concatenate str (not "int") to str
```

**Why:** `age` is the string `"18"`, and `1` is an integer. Python does not know whether you meant "concatenate the text 18 with the text 1" or "add 1 to the number 18", so it refuses to guess.

**How to fix:** convert the string to an integer with `int()`, or to a decimal with `float()`:

```python
age = input("How old are you? ")
age = int(age)              # string "18" → number 18
print("Next year you will be", age + 1, "years old")
```

The one-liner version is more common:

```python
age = int(input("How old are you? "))
print("Next year you will be", age + 1, "years old")
```

> Conversion is evaluated **from the outside in**: `input()` runs first and returns a string, then `int()` converts it to a number.

## Three little print tricks

**Separate several values with commas** and Python inserts a space automatically:

```python
print("My name is", "Alice", "and I am", 18, "years old")
# My name is Alice and I am 18 years old
```

**`sep` customises the separator** — by default there is a space between comma-separated items, but you can change it:

```python
print("2026", "09", "27", sep="-")
# 2026-09-27

print("a", "b", "c", sep="")   # empty string = no separator at all
# abc
```

**`end` customises what comes at the end** — by default print ends with a newline, but you can change that:

```python
print("Loading", end="")
print(" done")
# Loading done    (all on one line)

print("a", end=" ")
print("b", end=" ")
print("c")
# a b c
```

`end=""` is especially useful for progress indicators and for building output one piece at a time on the same line.

## A program that can actually talk

Put print and input together and build a BMI calculator:

```python
name = input("Your name: ")
height = float(input("Height in metres: "))
weight = float(input("Weight in kilograms: "))

bmi = weight / (height ** 2)
print(name, "has a BMI of", round(bmi, 1))
```

Notice `height` is converted with `float()` — height might be 1.75 m, which has a decimal part, so using `int` would lose precision. `round(bmi, 1)` keeps one decimal place; otherwise you get a long, messy number.

## Escape characters: special symbols inside strings

To put a newline, a quote, or a backslash itself inside a string, use **escape characters** — a sequence starting with a backslash `\`:

```python
print("first line\nsecond line")        # \n newline
print("He said: \"Hi\"")               # \" an actual double quote
print("path: C:\\Users")               # \\ an actual backslash
print("col1\tcol2")                    # \t a tab character
```

```
first line
second line
He said: "Hi"
path: C:\Users
col1	col2
```

> Do not want to memorise all these rules? Put an `r` in front of the string to make it a "raw string", and backslashes stop being special:

```python
print(r"C:\Users\name")    # prints as-is, no need to double the backslash
```

## Summary

- `print()` speaks out, `input()` stops and waits for input
- **input always returns a string**; to calculate, convert with `int()` or `float()`
- Conversion order: outside in — `int(input())` reads input first, then converts to a number
- `print`'s `sep` changes the separator, `end` changes the line ending (defaults: space and newline)
- `\n` newline, `\"` quote, `\\` backslash; prefix with `r` to skip escaping
