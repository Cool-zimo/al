# Variables and Three Kinds of Data

> By the end of this lesson you will be able to store numbers, text, and truth values in variables, and understand how Python classifies them.

## Why programs need to "remember"

The hello world from the previous lesson was a one-shot deal — it ran and then it was over, leaving nothing behind.

But real programs need to remember state: the user's name, the items in a shopping cart, the hit points of a game character. Python uses **variables** for this: you attach a label to some data and then refer to the data by that label.

```python
name = "Alice"
age = 18
print(name, "is", age, "years old")
```

**A variable is more like a label than a box.** This is an important difference between Python and some other languages. You put `18` into memory and stick a label reading `age` on it; then `score = age` sticks another label called `score` onto the very same thing. Nothing was copied — two names now point at the same piece of data.

For now, just learn the usage; we will come back to this when we talk about lists.

## `=` does not mean "equals", it means "put in"

In maths, `x = 5` means "x is 5". In Python, `x = 5` means "**put 5 into the label called x**".

So this code, which has no solution in maths, is something you will write every day in Python:

```python
x = 5
x = x + 1
print(x)      # 6
```

The order is: **evaluate the right side first, then store it on the left**. The right side `x + 1` evaluates to 6, and that 6 is stored in `x` — the original 5 is overwritten and discarded.

## Python's three basic data types

| Type | Stores | Examples | Check the type |
|---|---|---|---|
| int / float (numbers) | values you can calculate with | `18`, `1.75` | `type(18)` → `int` |
| str (string) | text, only concatenates | `"Alice"`, `'hello'` | `type("a")` → `str` |
| bool (boolean) | true/false, for decisions | `True`, `False` | `type(True)` → `bool` |

**Use `type()` to ask what type something is** — when in doubt, just ask:

```python
print(type(18))        # <class 'int'>
print(type(1.75))      # <class 'float'>
print(type("Alice"))   # <class 'str'>
print(type(True))      # <class 'bool'>
```

### Numbers: integers and decimals

```python
age = 18          # int, an integer
height = 1.75     # float, has a decimal point
score = -5        # can be negative too
```

Integers are called `int`; numbers with a decimal point are `float`. **Any number with a decimal point is a float**, even when the value is a whole number:

```python
print(type(3))      # int
print(type(3.0))    # float, even though the value is the same
```

### Strings: text wrapped in quotes

```python
name = "Alice"
city = 'London'           # single quotes work too — fully equivalent to double
text = "He said, \"Hi\""  # use a backslash to escape a quote that appears inside
```

**Pick single or double quotes — either is fine — but be consistent within one string.** When your text itself contains a quote, using the other kind of quote on the outside saves you from escaping:

```python
s = 'He said: "Hi"'     # cleaner than the escaped version
```

For multi-line strings, use triple quotes:

```python
poem = """Roses are red,
Violets are blue,
Sugar is sweet,
And so are you."""
print(poem)
```

### Booleans: only two values

`True` and `False`. Note the **initial capital** — writing `true` will raise an error.

```python
is_student = True
is_logged_in = False
```

You rarely have to type these yourself; they are usually **computed**. The result of `18 > 10` is `True`, and `18 < 10` is `False`. We will use this heavily in the next lesson on conditions.

## Naming: rules and taste

**Hard rules** (break them and you get an error):

- Letters, digits, and underscores only — and it cannot start with a digit: `score2` ✅, `2score` ❌
- Case-sensitive: `age` and `Age` are two different variables
- Keywords are forbidden: `if`, `for`, `class`, `print` cannot be variable names

**Taste** (the difference between readable and unreadable):

```python
a = 18              # bad: means nothing
age = 18            # good
user_age_years = 18 # even better: includes the unit, leaves no doubt
```

## Assigning to several variables at once

```python
x, y, z = 1, 2, 3
print(x, y, z)      # 1 2 3
```

The left and right sides line up one-to-one. **Swapping two variables** is where this shines — other languages need a temporary variable:

```python
a = 10
b = 20
a, b = b, a         # done in one line
print(a, b)         # 20 10
```

Python first evaluates the right side as a whole `(20, 10)`, then puts the pieces into `a` and `b` respectively.

## Dynamic typing: variables themselves have no type

Python does not require you to declare a type in advance. `age` can hold a number on one line and a string on the next — perfectly legal:

```python
age = 18
age = "eighteen"
print(age)
```

This is called **dynamic typing** — the type belongs to the **value**, not to the **variable**. The upside is that you write faster; the cost is that a type error is not caught when you write the code, only when that line actually runs.

## Crash Scene: using a variable that was never assigned

```python
print(message)
```

```
NameError: name 'message' is not defined
```

**Why:** you asked Python to fetch a label called `message`, but that label was never created. Python would rather raise an error than guess a value for you.

**How to fix:** assign it before you use it. The three-question debugging checklist: misspelled? Used Chinese punctuation? Used before assigning?

## Summary

- A variable = a label on data; `=` means "put in", not "equals"
- Right side first, then store on the left: `x = x + 1` is legal
- Three basic types: `int`/`float` (numbers), `str` (strings), `bool` (True/False)
- Use `type()` whenever you need to check; for quotes, remember "be consistent"
- Variable names should be meaningful, include units, and use underscores between words
- Python is dynamically typed — a variable can hold values of different types over time
