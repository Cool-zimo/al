# break / continue and nested loops

> By the end of this lesson you will be able to "jump out" of a loop or "skip a round", and you will use nested loops to solve two-dimensional problems.

## The precise meanings of break and continue

We touched on these in the previous lesson; here are the details.

**`break`:** jump out of the **entire** loop immediately; no matter how many rounds are left, they do not run.

```python
for i in range(10):
    if i == 3:
        break
    print(i)
```

```
0
1
2
```

**`continue`:** skip the rest of the code in this round and move straight to the **next round**.

```python
for i in range(5):
    if i == 2:
        continue
    print(i)
```

```
0
1
3
4
```

The 2 was skipped.

> One-line memory aid: **break means "I quit", continue means "not this round, next one".**

## The common use of break: stop when you find it

Finding a number in a list and reporting its position:

```python
nums = [3, 7, 1, 9, 4]
target = 9
found = False

for i in range(len(nums)):
    if nums[i] == target:
        print("Found it at position", i)
        found = True
        break

if not found:
    print("Not found")
```

9 is found at position 3 (index 3); once `break` hits, the loop exits immediately and no remaining rounds are wasted. **Using break for searching is standard practice.**

## Crash Scene: continue in the wrong place

```python
# WRONG: intended to skip even numbers
i = 0
while i < 5:
    if i % 2 == 0:
        continue
    print(i)
    i += 1
```

You might expect it to print 1 and 3. In reality it just freezes — **an infinite loop**.

**Why:** when `i` is 0 it hits `continue`, which skips `i += 1`. So `i` is forever 0 and the condition is forever true.

**How to fix:** move the update statement before `continue`:

```python
i = 0
while i < 5:
    i += 1              # update first
    if i % 2 == 0:
        continue
    print(i)
```

> By the way, `continue` does not have this problem inside a `for` loop — the loop variable is updated automatically. This trap is `while`-specific.

## Nested loops: loops inside loops

One loop nested inside another is how you handle **two-dimensional** data — the classic example being the multiplication table:

```python
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}×{i}={i*j}", end="\t")
    print()     # after the inner loop finishes, move to a new line
```

The outer `i` controls the row (1 to 9), and the inner `j` controls how many items to print on each row. Notice that the inner range is `range(1, i+1)` — row i prints i items. `end="\t"` aligns columns with a tab; `print()` with no arguments just moves to the next line.

## A break inside a nest only jumps one level

`break` only exits the **one level it belongs to**:

```python
for i in range(3):
    for j in range(3):
        if j == 1:
            break
        print(i, j)
```

```
0 0
1 0
2 0
```

When the inner `j` reaches 1 it breaks, but the outer `i` keeps going. This is a point where many beginners mistakenly assume "the whole thing stops".

**To break out of multiple levels at once**, the common trick is a flag:

```python
found = False
for i in range(3):
    for j in range(3):
        if matrix[i][j] == target:
            found = True
            break
    if found:
        break
```

Both levels check `found`; once the outer level sees it, it stops too.

## A practical example: printing a chessboard

```python
for row in range(8):
    for col in range(8):
        if (row + col) % 2 == 0:
            print("■", end="")
        else:
            print("□", end="")
    print()
```

`(row + col) % 2` decides the alternating black-and-white pattern. Each loop controls one dimension — this is the classic division of labour in a nested loop.

## Summary

- `break`: jump out of the whole loop; `continue`: skip to the next round
- `break` means "I quit"; `continue` means "not this round"
- In a search, break as soon as you find it to avoid wasted rounds
- In a `while` loop, make sure the update statement comes before `continue`, or you will loop forever
- Nested loops handle two-dimensional data: the outer loop controls rows, the inner controls columns
- Inside a nest, `break` jumps only one level; to stop everything, use a flag variable
- `end="\t"` aligns output with tab characters
