# while loops: keep going as long as the condition holds

> By the end of this lesson you will be able to write "repeat this while the condition is true" loops, and you will know how to break an infinite loop.

## Repetitive work belongs in a loop

If you wanted to print "Hello" ten times, nobody writes ten lines of print. A loop does exactly that:

```python
count = 0
while count < 10:
    print("Hello")
    count = count + 1
```

While the condition after `while` is true, the indented block repeats. **After each round the program returns to the condition and tests it again**; only when it becomes false does the loop exit.

## The three elements

When writing `while`, you must think through three things — miss one and you risk an infinite loop:

1. **Initial value of the loop variable:** `count = 0`
2. **Loop condition:** `count < 10`
3. **Updating the loop variable:** `count = count + 1`

Working together, these three guarantee the loop **has a start, has a boundary, and converges**.

> The common increment shorthand: `count += 1`. `+=` means "add and then store back in itself", a shorthand for `count = count + 1`.

## A number-guessing game

Put everything together so far into a game you can actually play:

```python
import random

secret = random.randint(1, 100)
guess = 0

while guess != secret:
    guess = int(input("Guess a number: "))
    if guess < secret:
        print("Too low")
    elif guess > secret:
        print("Too high")
    else:
        print("You got it!")
```

**The loop condition `guess != secret` means "keep going until you get it right".** Once the guess matches, the condition becomes false and the loop ends. This is the classic use of while: **you do not know how many rounds you will need, only when to stop**.

## Crash Scene: forgetting to update the loop variable

```python
# WRONG
count = 0
while count < 5:
    print("still less than 5")
    # forgot count += 1
```

**Why:** the condition is permanently `0 < 5`, permanently true. The loop runs round after round and never stops.

**How to break out:**
- **Ctrl + C** forces an interrupt (works everywhere)
- In VSCode's run panel there is a red square ⏹ — click it to stop
- The real fix: add `count += 1`

**Debugging trick for infinite loops:** print the loop variable inside the loop and watch whether it changes as expected:

```python
while count < 5:
    print("count =", count)   # add this line and the problem shows up immediately
    # count += 1
```

## Breaking out on purpose: break

`break` means "jump out of the whole loop right now", regardless of whether the condition still holds:

```python
while True:                 # deliberately an infinite loop
    cmd = input("Enter a command (quit to exit): ")
    if cmd == "quit":
        break               # hit this and jump out
    print("You entered:", cmd)
print("Goodbye")
```

`while True:` is the standard opener for an infinite loop, used together with `break`. This pattern is extremely common in programs that "keep waiting for the user to do something" — chat bots, command-line tools, anything interactive.

## Skipping the rest of a round: continue

`continue` means "skip the rest of this round and move straight on to the next":

```python
count = 0
while count < 5:
    count += 1
    if count == 3:
        continue            # skip 3, do not print it
    print(count)
```

```
1
2
4
5
```

Notice that `count += 1` comes **before** `continue` — if it came after, then when 3 was hit the variable would not be updated and you would have another infinite loop.

## Summary

- `while condition:` repeats while the condition is true; indentation marks the body
- Three elements: **initial value, condition, update** — miss one and you may loop forever
- `count += 1` is shorthand for `count = count + 1`
- Break an infinite loop with **Ctrl+C**; to debug, print the loop variable inside the loop
- `break` jumps out of the whole loop; `continue` skips to the next round
- `while True:` + `break` is the standard idiom for "keep running until some condition is met"
