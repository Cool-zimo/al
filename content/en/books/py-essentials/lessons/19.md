# String Methods in Depth

> By the end of this lesson you will be able to split, join, clean, replace, and format strings without writing loops by hand.

## Strings Are Immutable

Remember this rule first: methods like `strip`, `replace`, and `upper` **do not modify the original string**; they return a new one.

```python
name = "  Alice  "
clean = name.strip()
print(name)       # "  Alice  "   the original is unchanged
print(clean)      # "Alice"
```

If you want the original variable to "become clean", you have to reassign the result:

```python
name = name.strip()
```

## `split` / `join`: Cutting and Gluing

```python
text = "apple,banana,orange,grape"
fruits = text.split(",")        # ['apple', 'banana', 'orange', 'grape']
print(fruits)

# with no separator, split cuts on any whitespace (spaces, newlines, tabs all count)
line = "a   b\tc\nd"
print(line.split())             # ['a', 'b', 'c', 'd']

# limit how many cuts to make
print("2026-09-27".split("-", 1))   # ['2026', '09-27']
```

`join` is the reverse of `split`. Remember that **the joiner is the caller**:

```python
words = ["I", "love", "Python"]
print("".join(words))           # IlovePython
print("-".join(words))          # I-love-Python
print("\n".join(words))         # each word on its own line
```

## `strip`: Cleaning Up Whitespace

```python
name = "  Alice  \n"
print(name.strip())             # "Alice"
```

`strip()` is most useful for **cleaning user input** — when the user types extra spaces or hits Enter, strip first and then process:

```python
choice = input("Continue? (y/n): ").strip().lower()
if choice == "y":
    print("continuing")
```

Chaining `strip().lower()` handles "remove whitespace + convert to lowercase" in one line. `lower()` makes a string entirely lowercase; `upper()` makes it uppercase.

## `replace`: Substitution

```python
text = "I like apples, apples are tasty"
new = text.replace("apples", "bananas")
print(new)          # I like bananas, bananas are tasty

# limit the number of replacements
print(text.replace("apples", "bananas", 1))
# I like bananas, apples are tasty   only the first one is replaced
```

`replace` returns a new string; the original stays the same.

## `format` and f-strings: Splicing Variables into Text

**f-strings (the recommended choice)** — put `f` in front of the string and wrap variables in `{}`:

```python
name = "Alice"
age = 18
print(f"{name} is {age} years old")         # Alice is 18 years old

# formatting controls
pi = 3.1415926
print(f"pi: {pi:.2f}")          # pi: 3.14       two decimal places
print(f"percent: {0.856:.1%}")  # percent: 85.6%  as a percentage
print(f"{123:>5}")              # "  123"         right-aligned with spaces
print(f"{123:<5}")              # "123  "         left-aligned
```

After the colon in `{value:format}` you write the format: `.2f` for two decimals, `.1%` for a percentage, `<` / `>` for alignment. At this stage, mastering `:.2f` covers most everyday cases.

**The `format` method** (the older style, predating f-strings):

```python
print("{} is {} years old".format(name, age))
print("{0} is {1}, {0} loves Python".format(name, age))  # reuse by index
```

Use f-strings whenever you can — they are more readable.

## Crash Scene: Forgetting the `f` Prefix

```python
name = "Alice"
print("{name} is {age} years old")     # forgot the f
```

The output is the literal text `{name} is {age} years old` — the variables are never substituted at all.

**The fix:** put `f` in front of the quotes: `print(f"{name} is {age} years old")`.

> This mistake does not raise an error, it just produces the wrong output, which makes it especially easy to miss. Build the muscle memory: "if I am embedding a variable, write f first."

## Finding and Testing

| Method | What it does | Example |
|---|---|---|
| `startswith(s)` | does it start with s | `"hello".startswith("he")` → `True` |
| `endswith(s)` | does it end with s | `"hello".endswith("lo")` → `True` |
| `find(s)` | index of s, or -1 if not found | `"hello".find("e")` → `1` |
| `count(s)` | how many times s appears | `"hello".count("l")` → `2` |
| `isdigit()` | is it all digits | `"123".isdigit()` → `True` |

```python
filename = "report.pdf"
if filename.endswith(".pdf"):
    print("this is a PDF file")

text = "hello world"
print(text.find("world"))      # 6
print(text.find("python"))     # -1
```

> Use `in` to ask "is it present" (returns True/False); use `find` to ask "at what position" (returns an index or -1).

## Summary

- Strings are **immutable**; methods return new strings, so to "change" one you must reassign
- `split()` cuts, `"joiner".join(list)` glues; `strip()` removes leading/trailing whitespace
- `replace(old, new)` substitutes, with an optional limit on replacements
- f-strings are the first choice: `f"{value:.2f}"`; `{:.2f}` keeps two decimal places
- Forgetting the `f` prefix is a silent mistake — you get the literal braces instead of values
- Finding and testing: `startswith`, `endswith`, `find`, `count`, `isdigit`
- Use `in` to test for presence, `find` to locate a position
