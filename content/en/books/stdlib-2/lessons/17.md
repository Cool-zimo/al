# High-Level File Operations with shutil

> The `os` module handles one file at a time. Moving across filesystems and copying entire directory trees require `shutil`. This lesson covers the differences between `copy`, `copy2`, `move`, `rmtree`, and `copytree`, and identifies the single most dangerous call in the module.

## The Five Functions You Will Actually Use

```python
import shutil

shutil.copy("src.txt", "dst.txt")      # Copy content plus permission bits.
shutil.copy2("src.txt", "dst.txt")     # Copy content and preserve all metadata.
shutil.copystat("a.txt", "b.txt")      # Copy metadata only; leave content alone.
shutil.move("a.txt", "backup/a.txt")   # Move or rename.
shutil.rmtree("old_dir")               # Recursively delete an entire tree.
```

The only difference between `copy` and `copy2` is that `copy2` tries to preserve **all metadata**: modification time, access time, flags, and more. Use `copy2` for backups and plain `copy` for disposable duplicates.

## copytree: Copy an Entire Directory Recursively

`copy` handles one file. To move a whole subtree you need `copytree`.

```python
import shutil

# Copy the entire project directory to project_backup.
shutil.copytree("project", "project_backup")

# Ignore rule: skip .git and __pycache__.
shutil.copytree(
    "project", "project_backup",
    ignore=shutil.ignore_patterns("__pycache__", ".git", "*.pyc"),
)
```

`ignore_patterns()` returns a callable that receives `(dir, entries)` and returns the names to skip. You can also supply your own:

```python
def my_ignore(dirname, names):
    return [n for n in names if n.endswith(".tmp")]

shutil.copytree("src", "dst", ignore=my_ignore)
```

## disk_usage: How Much Space Is Left?

```python
import shutil

usage = shutil.disk_usage("/")
print(f"Total:  {usage.total / 2**30:.1f} GB")
print(f"Used:   {usage.used / 2**30:.1f} GB")
print(f"Free:   {usage.free / 2**30:.1f} GB")
print(f"Usage:  {usage.used / usage.total * 100:.1f}%")
```

The result is a named tuple `sdiskusage(total, used, free)` measured in bytes.

## Crash Site: `rmtree` Removes Without Asking

`rmtree` is the most dangerous function in the standard library. **There is no recycle bin, no confirmation, and no log.** Once it runs, the data is gone.

```python
import shutil

# WRONG: a bad path join is accepted without complaint.
base = "/data/projects/"
target = "old_project"
shutil.rmtree(base + target)   # If base is "/data/projects" with no slash,
# the call becomes rmtree("/data/projectsold_project").
# Even worse: if target is the empty string, rmtree(base + "") deletes everything.
shutil.rmtree(base + "")       # Goodbye, /data/projects/.
```

The error:

```
FileNotFoundError: [Errno 2] No such file or directory: '/data/projectsold_project'
```

When the joined path does not exist, Python raises `FileNotFoundError`—which actually saves you. But if the typo points at a real directory, the damage is permanent.

**The safe version:**

```python
from pathlib import Path
import shutil

base = Path("/data/projects")
target = base / "old_project"     # Path joins safely; slashes take care of themselves.

if target.exists() and target.is_dir():
    shutil.rmtree(target)
    print(f"Removed {target}")
else:
    print("Target missing; nothing to remove")
```

Three rules:

1. Check both `exists()` and `is_dir()` before deleting.
2. Build paths with `pathlib`, never by concatenating strings.
3. In production, ask for confirmation or write an audit log first.

## Crash Site: `copytree` Refuses an Existing Destination

```python
import shutil

# WRONG: the destination already exists.
shutil.copytree("project", "project_backup")
# The first run succeeds; the second run raises an error.
shutil.copytree("project", "project_backup")
```

The error:

```
FileExistsError: [Errno 17] File exists: 'project_backup'
```

`copytree` requires the destination **not to exist** (the same philosophy as `open(..., "x")`). You have two options:

```python
import shutil
import os

dst = "project_backup"
if os.path.exists(dst):
    shutil.rmtree(dst)          # Clear it first, then copy.
shutil.copytree("project", dst)

# Or, starting with Python 3.8:
shutil.copytree("project", dst, dirs_exist_ok=True)
```

With `dirs_exist_ok=True`, an existing destination is allowed; files are merged and overwritten while unrelated entries are left in place—a good fit for incremental backups.

## Hands-On: Clearing a Temporary Directory

```python
import shutil
import os
from pathlib import Path

def cleanup_temp(temp_dir):
    """Remove every entry inside the given temporary directory,
    but keep the directory itself."""
    p = Path(temp_dir)
    if not p.exists():
        return 0
    deleted = 0
    for entry in p.iterdir():
        if entry.is_dir():
            shutil.rmtree(entry)
        else:
            entry.unlink()
        deleted += 1
    return deleted

# Simulated call (nothing is actually deleted here).
print(cleanup_temp("/tmp/cache"))   # 0 (the directory does not exist)
```

In real use, guard this function with a path whitelist so nobody can pass `/` or another critical location.

## Recap

- `copy` copies content and permissions; `copy2` also preserves metadata.
- `copytree(src, dst)` copies recursively; `ignore=` skips selected entries.
- `copytree` requires a missing destination; `dirs_exist_ok=True` lifts that rule.
- `move` is essentially `os.rename`; across devices it falls back to copy and delete.
- `rmtree` is recursive and bypasses any recycle bin—always verify with `exists()` and `is_dir()` first.
- `disk_usage(path)` returns `(total, used, free)` measured in bytes.
