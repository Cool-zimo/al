# zipfile: Creating and Reading Zip Archives

> This lesson covers Python's `zipfile` module. You will learn to create zips, list their contents, read individual files, extract them, and understand the practical limits of password protection.

## Creating a Zip: ZipFile Plus write

```python
import zipfile

with zipfile.ZipFile("archive.zip", "w", zipfile.ZIP_DEFLATED) as zf:
    zf.write("report.pdf")
    zf.write("data/notes.csv", arcname="notes.csv")   # A custom name inside the archive.
```

`ZIP_DEFLATED` is the usual compression algorithm. There is also `ZIP_STORED` (no compression, just packaging) and `ZIP_BZIP2` or `ZIP_LZMA` (higher compression at a slower speed).

The `arcname` parameter controls the name of the entry inside the archive. Without it, the full original path is preserved, which may recreate the original directory layout on extraction.

## Reading and Listing Contents

```python
import zipfile

with zipfile.ZipFile("archive.zip", "r") as zf:
    # List every entry.
    for name in zf.namelist():
        print(name)

    # Read one file's content (bytes).
    data = zf.read("notes.csv")
    print(data.decode("utf-8"))

    # More detailed information.
    for info in zf.infolist():
        print(info.filename, info.file_size, info.compress_size)
```

`infolist()` returns a list of `ZipInfo` objects containing filenames, original sizes, compressed sizes, modification times, and the compression method.

## Extracting

```python
import zipfile

with zipfile.ZipFile("archive.zip", "r") as zf:
    zf.extract("notes.csv", path="out_dir")       # Extract one file.
    zf.extractall(path="out_dir")                  # Extract everything.
```

`extractall` accepts a `members` argument to extract only a selected subset:

```python
with zipfile.ZipFile("archive.zip", "r") as zf:
    # Extract only .txt files.
    txts = [n for n in zf.namelist() if n.endswith(".txt")]
    zf.extractall(path="out", members=txts)
```

## Crash Site: The Path Traversal Attack

If you call `extractall` on an untrusted zip, it may contain entries such as `../../etc/passwd` and overwrite system files.

```python
import zipfile

# WRONG: extracting an untrusted zip directly.
with zipfile.ZipFile("untrusted.zip", "r") as zf:
    zf.extractall(path="out")
# Any entry like "../../etc/passwd" ends up outside the intended directory.
```

Defend by checking whether each resolved destination still lives inside the target directory.

```python
from pathlib import Path
import zipfile

def safe_extract(zf, target_dir):
    target = Path(target_dir).resolve()
    for name in zf.namelist():
        dest = (target / name).resolve()
        if not str(dest).startswith(str(target) + str(Path.sep)):
            raise ValueError(f"Refusing unsafe path: {name}")
        zf.extract(name, path=target)

with zipfile.ZipFile("untrusted.zip", "r") as zf:
    safe_extract(zf, "out")
```

This is the standard protection when users upload zip files.

## Crash Site: `read()` Returns Bytes

```python
import zipfile

with zipfile.ZipFile("data.zip", "r") as zf:
    # WRONG: read() returns bytes; treating it as text fails.
    content = zf.read("notes.txt")
    print(content.upper())      # AttributeError: 'bytes' object has no attribute 'upper'
```

The error:

```
AttributeError: 'bytes' object has no attribute 'upper'
```

`read()` always returns `bytes`. Decode text explicitly:

```python
with zipfile.ZipFile("data.zip", "r") as zf:
    content = zf.read("notes.txt").decode("utf-8")
    print(content.upper())
```

Alternatively, open the entry in text mode with `zf.open(name, "r", encoding="utf-8")` (Python 3.9+).

## The Limits of Password Protection

`zipfile` supports passwords, but **only the legacy ZipCrypto scheme**—not modern AES-256. ZipCrypto itself has known weaknesses and is vulnerable to attacks.

```python
import zipfile

with zipfile.ZipFile("secret.zip", "w") as zf:
    zf.setpassword(b"123456")                # The password must be bytes.
    zf.writestr("secret.txt", "confidential content", zipfile.ZIP_DEFLATED)

with zipfile.ZipFile("secret.zip", "r") as zf:
    zf.setpassword(b"123456")
    print(zf.read("secret.txt").decode("utf-8"))
```

**The practical limits:**

- Only ZipCrypto is supported, and it is weak.
- AES-256 is not supported (use a third-party library such as `pyzipper`).
- You cannot encrypt an existing zip; the password must be set while writing.
- Many tools, including Python's `shutil.unpack_archive`, fail on encrypted zips.

A zip password keeps out casual observers. For genuinely sensitive data, use a proper encryption solution.

## Hands-On: Categorising Archive Contents by Extension

```python
import zipfile
from collections import defaultdict

def analyze_zip(file_list):
    """Receive a simulated list of archive entries (with sizes) and return
    category statistics grouped by extension.
    file_list: list of (name, size)"""
    stats = defaultdict(lambda: {"count": 0, "size": 0})
    for name, size in file_list:
        ext = name.rsplit(".", 1)[-1] if "." in name else "(none)"
        stats[ext]["count"] += 1
        stats[ext]["size"] += size
    return dict(stats)

files = [("a.txt", 100), ("b.txt", 200), ("c.png", 5000)]
print(analyze_zip(files))
# {'txt': {'count': 2, 'size': 300}, 'png': {'count': 1, 'size': 5000}}
```

In a real program, replace `file_list` with `zf.infolist()`. This function is the basis of an "archive overview" feature in a backup tool.

## Recap

- `ZipFile(name, "w", ZIP_DEFLATED)` creates; `write(path, arcname=)` adds.
- `namelist()` lists entries; `read(name)` returns bytes.
- `infolist()` exposes file size, compressed size, modification time, and other metadata.
- `extract(name, path=)` extracts one entry; `extractall(path=, members=)` extracts a selection.
- **Check for path traversal before extracting untrusted zips.**
- `read()` returns bytes; decode text explicitly.
- `zipfile` passwords use only weak ZipCrypto, not AES.
