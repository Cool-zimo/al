# Working with Paths in pathlib

> This lesson takes the common operations of `pathlib` apart in detail. You will learn to join paths with `/`, pull the pieces apart, check what exists, and create directories — all through `Path` methods.

## Joining paths: the overloaded `/` operator

`Path` overloads `/` to join paths. It is one of the cleanest designs in `pathlib`:

```python
from pathlib import Path

base = Path("/home/alice")
config = base / "config" / "app.json"
print(config)   # /home/alice/config/app.json

# you can mix strings and Paths
p = Path("/data") / "logs" / "2026" / "09.log"
print(p)   # /data/logs/2026/09.log
```

**Note**: at least one side of `/` must be a `Path`. Two strings with `/` will not work (`str` does not overload `/`).

## Path components: name / stem / suffix / parent / parts

```python
from pathlib import Path

p = Path("/home/alice/docs/archive.tar.gz")

print(p.name)      # archive.tar.gz <- full filename
print(p.stem)      # archive.tar    <- with the last suffix removed
print(p.suffix)    # .gz            <- the last suffix only
print(p.suffixes)  # ['.tar', '.gz'] <- every suffix (as a list)
print(p.parent)    # /home/alice/docs <- the parent directory
print(p.parents[0])  # /home/alice/docs
print(p.parents[1])  # /home/alice
print(p.parents[2])  # /home
print(p.parts)     # ('/', 'home', 'alice', 'docs', 'archive.tar.gz')
```

## Crash Site: suffix vs suffixes

```python
from pathlib import Path

p = Path("archive.tar.gz")

# WRONG: expecting suffix to return .tar.gz
print(p.suffix)    # .gz <- only the LAST suffix!
print(p.suffixes)  # ['.tar', '.gz'] <- this is the full list
```

If you want to test whether something is a `tar.gz` file, use `suffixes`:

```python
if p.suffixes == ['.tar', '.gz']:
    print("This is a tar.gz file")
```

Or join them together for the check:

```python
if "".join(p.suffixes) == ".tar.gz":
    print("tar.gz file")
```

## Existence checks: exists / is_file / is_dir

```python
from pathlib import Path

p = Path("/etc/hosts")

print(p.exists())    # True (the file is there on most systems)
print(p.is_file())   # True
print(p.is_dir())    # False

d = Path("/etc")
print(d.exists())    # True
print(d.is_file())   # False
print(d.is_dir())    # True
```

A note on interpretation: `exists()` returning `False` does not necessarily mean the file is absent — a permissions problem can produce the same result. When `is_file()` returns `True`, it means "this exists and it is a file."

## Creating directories: mkdir

```python
from pathlib import Path

# create a single directory
p = Path("./output")
p.mkdir(exist_ok=True)   # exist_ok=True prevents errors if it already exists

# create a chain of directories
deep = Path("./data/logs/2026/09")
deep.mkdir(parents=True, exist_ok=True)
# parents=True creates all missing parent directories recursively
```

**`parents=True` and `exist_ok=True` are the most common combination** — the first permits a whole chain to be created, and the second prevents re-creation from failing.

## Crash Site: calling mkdir without exist_ok

```python
from pathlib import Path

p = Path("./cache")
p.mkdir()

# running it a second time, the directory already exists
p.mkdir()   # FileExistsError!
```

Error:

```
FileExistsError: [Errno 17] File exists: './cache'
```

**Fix**: always pass `exist_ok=True` unless you have a specific reason to raise.

```python
p.mkdir(exist_ok=True)   # safe: skip if present, create if not
```

## Creating files: touch

```python
from pathlib import Path

p = Path("./data/note.txt")
p.parent.mkdir(parents=True, exist_ok=True)  # make sure the parent exists first
p.touch()   # create an empty file (if it exists, update its mtime)
```

`touch()` mirrors the Linux `touch` command: create the file if it is missing, or "touch" it (updating atime/mtime) if it is already there.

## with_suffix / with_name / with_stem: path transformations

```python
from pathlib import Path

p = Path("/home/alice/docs/report.txt")

# change the extension
print(p.with_suffix(".md"))     # /home/alice/docs/report.md
print(p.with_suffix(".tar.gz")) # /home/alice/docs/report.tar.gz

# change the filename (keep the directory)
print(p.with_name("summary.txt"))  # /home/alice/docs/summary.txt

# change the stem (keep the directory and extension)
print(p.with_stem("summary"))      # /home/alice/docs/summary.txt
```

These methods **return a new path**; the original is never modified (a `Path` is immutable).

## Summary

- `/` joins paths; at least one operand must be a `Path`
- `name` is the full filename, `stem` drops the last suffix, `suffix` is the last suffix, `suffixes` lists them all
- `parent` is the parent directory, `parents[i]` goes up `i` levels, `parts` is the tuple of components
- `exists()` / `is_file()` / `is_dir()` inspect the path
- `mkdir(parents=True, exist_ok=True)` is the standard way to create directories
- `with_suffix()` / `with_name()` / `with_stem()` return a new, transformed path
