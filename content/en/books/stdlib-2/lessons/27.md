# Scanning and Classification: Turning a Directory into Data

> Building on `pathlib` traversal from Chapter 3, this lesson turns "scanning a directory" into a data pipeline: skip what should be skipped, collect what matters, and emit a clean file list.

## Scanner: Walking the Directory and Collecting Metadata

Chapter 3 covered `Path.rglob()` and `Path.iterdir()`. The organiser's scanner does a little more than list names: it needs **size, modification time, and suffix** for the classifier.

```python
from pathlib import Path
from datetime import datetime


IGNORE_DIRS = {"__pycache__", ".git", "node_modules", ".venv", "venv", ".svn"}
IGNORE_FILES = {".DS_Store", "Thumbs.db"}


def scan_directory(root):
    """Walk root and return a list of file-info dictionaries.
    Each entry: {"src": absolute path, "name": filename, "ext": lowercase suffix,
                 "size": bytes, "mtime": ISO8601 time string}."""
    root = Path(root)
    files = []
    for p in root.rglob("*"):
        if not p.is_file():
            continue
        # Skip files living inside ignored directories.
        if any(part in IGNORE_DIRS for part in p.relative_to(root).parts[:-1]):
            continue
        if p.name in IGNORE_FILES:
            continue
        mtime = datetime.fromtimestamp(p.stat().st_mtime).isoformat(timespec="seconds")
        files.append({
            "src": str(p),
            "name": p.name,
            "ext": p.suffix.lower(),
            "size": p.stat().st_size,
            "mtime": mtime,
        })
    return files
```

**The crucial line** is `p.relative_to(root).parts[:-1]`: it takes every **parent directory segment** of the file relative to the root and tests whether any of them should be ignored. That catches `__pycache__/x.py`, and it will not miss anything nested under `myproject/__pycache__`.

## Classifier: Three Classification Dimensions

The classifier does not scan; it consumes the scanner's output. It assigns labels along three dimensions, from most specific to least:

```python
def classify(files, ext_map, size_thresholds=None):
    """Return {"category": [file-info, ...]}."""
    size_thresholds = size_thresholds or {"tiny": 10 * 1024, "huge": 100 * 1024 * 1024}
    result = {}
    for f in files:
        cat = _by_extension(f["ext"], ext_map)
        if cat is None:
            cat = _by_size(f["size"], size_thresholds)
        result.setdefault(cat, []).append(f)


def _by_extension(ext, ext_map):
    return ext_map.get(ext)   # None means no match.


def _by_size(size, t):
    if size < t["tiny"]:
        return "Tiny"
    if size >= t["huge"]:
        return "Huge"
    return None               # Hand it to "Other".
```

```python
EXT_MAP = {
    ".jpg": "Images", ".jpeg": "Images", ".png": "Images", ".gif": "Images", ".webp": "Images",
    ".pdf": "Docs", ".docx": "Docs", ".xlsx": "Docs", ".pptx": "Docs", ".txt": "Docs", ".md": "Docs",

```

## Hands-On: A Clean Pipeline

```python
# Simulate scan_directory's output (no real directory required for tests).
simulated = [
    {"src": "/d/a.jpg", "name": "a.jpg", "ext": ".jpg", "size": 204800, "mtime": "2026-09-20T10:00:00"},
    {"src": "/d/contract.pdf", "name": "contract.pdf", "ext": ".pdf", "size": 512000, "mtime": "2026-09-21T11:00:00"},
    {"src": "/d/tiny.tmp", "name": "tiny.tmp", "ext": ".tmp", "size": 200, "mtime": "2026-09-22T12:00:00"},
    {"src": "/d/big.iso", "name": "big.iso", "ext": ".iso", "size": 5_000_000_000, "mtime": "2026-09-23T13:00:00"},
    {"src": "/d/notes.md", "name": "notes.md", "ext": ".md", "size": 3200, "mtime": "2026-09-24T14:00:00"},
]

cats = classify(simulated, EXT_MAP)
for cat, items in sorted(cats.items()):
    print(f"{cat:<10} {len(items)}")
# Docs       1
# Huge       1     <- big.iso exceeds the 100MB threshold.
# Images     1
# Tiny       1     <- tiny.tmp is under 10KB.
# Other      1     <- notes.md has no size mapping that matched.
```

Notice `notes.md`: `.md` **is** in `EXT_MAP`. The example is testing something else: **size is consulted only when the extension fails to match**. Since `.md` maps to Docs, it lands in Docs. `tiny.tmp` has no extension mapping, so size decides and it becomes Tiny. Understanding this priority is the foundation for the rule engine in the next lesson.

## Crash Site: Checking the Wrong Level for Ignored Directories

Many first attempts say "skip the file if its immediate parent is ignored"—but that only checks one level and misses nesting.

```python
from pathlib import Path

# WRONG: checking only the direct parent.
def scan_wrong(root):
    skip = {"__pycache__", ".git"}
    result = []
    for p in Path(root).rglob("*"):
        if not p.is_file():
            continue
        if p.parent.name in skip:   # Only the final parent segment.
            continue
        result.append(str(p))
    return result

# Directory layout: a/__pycache__/sub/x.py
# p.parent.name is __pycache__, so it is skipped. But if the rule changes
# to a prefix-based test, this single-parent approach breaks.
print("The wrong version only inspects one parent; it is fragile for nested ignores.")
```

```python
from pathlib import Path

# Correct: inspect every ancestor segment.
def scan_right(root):
    skip = {"__pycache__", ".git", "node_modules"}
    result = []
    for p in Path(root).rglob("*"):
        if not p.is_file():
            continue
        rel_parts = p.relative_to(root).parts[:-1]   # All ancestor segments.
        if any(part in skip for part in rel_parts):
            continue
        result.append(str(p))
    return result

# a/b/__pycache__/deep/x.py -> rel_parts contains __pycache__ -> skip.
# a/.git/refs/heads/main   -> rel_parts contains .git      -> skip.
```

The real trap is **assuming `.parent` is enough**. Whenever the rule says "skip if any ancestor matches", you must walk every ancestor segment.

## Crash Site: `stat()` Raises and Kills the Whole Scan

Network drives, missing permissions, and broken symlinks mean `stat()` can fail at any time in the real world. One bad file should not abort the entire scan.

```python
from pathlib import Path

# WRONG: one bad file aborts everything.
def scan_fragile(root):
    files = []
    for p in Path(root).rglob("*"):
        if p.is_file():
            files.append({"src": str(p), "size": p.stat().st_size})  # May raise OSError.
    return files

# Correct: one failure does not contaminate the rest; log it and move on.
def scan_robust(root):
    files = []
    skipped = 0
    for p in Path(root).rglob("*"):
        if not p.is_file():
            continue
        try:
            st = p.stat()
        except OSError as e:
            skipped += 1
            continue
        files.append({"src": str(p), "size": st.st_size})
    return files, skipped

print("Skipped 3 inaccessible files; the other 1281 were processed normally.")
```

**This is the general pattern Lesson 30 covers under exception handling:** localise point failures so they do not spread.

## Recap

- The scanner walks a directory and collects `src`, `name`, `ext`, `size`, and `mtime`, skipping ignored directories and files.
- Ignore checks must inspect **every ancestor segment**, not just `.parent`; otherwise nesting leaks through.
- The classifier uses three dimensions: extension first, then size, then other.
- The classifier only reads data and performs no I/O, so it can be tested against a simulated list.
- `stat()` may raise `OSError`; isolate point failures so one bad file does not sink the whole scan.
