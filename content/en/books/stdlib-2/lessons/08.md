# Advanced Date Arithmetic

> This lesson answers "what is the last day of the month, which ISO week does a date fall in, and how do I count working days?" You will use the `calendar` module and built-in date methods to handle these everyday requirements.

## The last day of the month

"How many days are in a given month?" is one of the most common date questions. Your first instinct might be a lookup table, but Python has an elegant trick:

```python
from datetime import date

# trick: day 0 of the next month == the last day of this month
def last_day_of_month(year, month):
    if month == 12:
        return date(year + 1, 1, 1) - __import__("datetime").timedelta(days=1)
    return date(year, month + 1, 1) - __import__("datetime").timedelta(days=1)

print(last_day_of_month(2026, 2))   # 2026-02-28
print(last_day_of_month(2024, 2))   # 2024-02-29 (leap year!)
print(last_day_of_month(2026, 4))   # 2026-04-30
```

**How it works**: the 1st of the next month minus one day is the last day of the current month. `date` handles all the carrying automatically, including leap years.

## The calendar module: more date information

```python
import calendar

# how many days in a month
print(calendar.monthrange(2026, 2))   # (6, 28)
# returns (weekday of the 1st, number of days in the month)
# 6 == Sunday (0=Monday), 28 days

print(calendar.monthrange(2024, 2))   # (3, 29) <- 2024 is a leap year, 29 days

# a text calendar for the month
print(calendar.month(2026, 9))
```

`calendar.monthrange(year, month)` returns a tuple: the first element is the weekday of the 1st (0 = Monday), and the second is the number of days in that month.

## Crash Site: a hand-rolled leap-year check goes wrong

```python
# WRONG: the century rule is missing
def days_in_month(year, month):
    days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
    if month == 2 and year % 4 == 0:
        return 29
    return days[month - 1]

print(days_in_month(1900, 2))   # 29? WRONG! 1900 is not a leap year, so it is 28
```

**The right approach** is the `calendar` module, which already implements every rule:

```python
import calendar

def days_in_month(year, month):
    return calendar.monthrange(year, month)[1]

print(days_in_month(1900, 2))   # 28  ✓
print(days_in_month(2000, 2))   # 29  ✓
print(days_in_month(2024, 2))   # 29  ✓
```

## ISO weeks with isocalendar

```python
from datetime import date

d = date(2026, 1, 1)
print(d.isocalendar())       # (2026, 1, 4) -> (ISO year, ISO week, ISO weekday)

d2 = date(2026, 12, 31)
print(d2.isocalendar())      # (2026, 53, 4)
```

`isocalendar()` returns `(ISO_year, ISO_week, ISO_weekday)`. The ISO week rules:

- A week starts on Monday
- Week 1 is the week containing the year's first Thursday
- So early January can belong to the previous year's week 52 or 53, and late December can belong to the next year's week 1

## Working-day arithmetic

```python
from datetime import date, timedelta

def is_workday(d):
    """True if d falls on Monday through Friday."""
    return d.weekday() < 5   # 0-4 are weekdays, 5-6 are the weekend

def next_workday(d):
    """Return the next working day."""
    while True:
        d += timedelta(days=1)
        if is_workday(d):
            return d

print(is_workday(date(2026, 9, 28)))   # True (Monday)
print(is_workday(date(2026, 9, 26)))   # False (Saturday)

print(next_workday(date(2026, 9, 25)))  # 2026-09-28 (Fri -> Mon)
```

## Worked example: listing every working day in a month

```python
from datetime import date, timedelta
import calendar

def get_workdays(year, month):
    """Return a list of all working days in a given month."""
    _, days = calendar.monthrange(year, month)
    workdays = []
    for day in range(1, days + 1):
        d = date(year, month, day)
        if d.weekday() < 5:
            workdays.append(d)
    return workdays

ws = get_workdays(2026, 9)
print(f"September 2026 has {len(ws)} working days")
```

## Worked example: are we in the last N days of the month?

```python
from datetime import date, timedelta
import calendar

def is_last_n_days(d, n):
    """Is d within the last n days of its month?"""
    _, total_days = calendar.monthrange(d.year, d.month)
    return d.day > total_days - n

print(is_last_n_days(date(2026, 9, 28), 3))   # True
print(is_last_n_days(date(2026, 9, 25), 3))   # False
```

## Summary

- Last day of a month: `date(year, month+1, 1) - timedelta(days=1)`
- `calendar.monthrange(year, month)` -> `(weekday of 1st, day count)`
- `calendar.monthrange(year, month)[1]` gives the number of days (leap years included)
- `date.isocalendar()` returns the ISO year, week number, and weekday
- Working day test: `weekday() < 5`
- **Do not write your own leap-year or month-length logic** — use the standard library
