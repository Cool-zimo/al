# Formatting: strftime and strptime

> This lesson answers "how do I turn a date object into a string for a human, and a string back into a date object?" You will memorise the most useful placeholders, and learn why `%` must be escaped inside a format string.

## strftime: date to string

`strftime` (string format time) **formats** a date or datetime object into a human-readable string.

```python
from datetime import datetime

now = datetime(2026, 9, 27, 14, 30, 5)
print(now.strftime("%Y-%m-%d"))              # 2026-09-27
print(now.strftime("%Y/%m/%d %H:%M"))        # 2026/09/27 14:30
print(now.strftime("%d %B %Y, %H:%M:%S"))    # 27 September 2026, 14:30:05
```

## The most useful placeholders

| Placeholder | Meaning | Example |
|---|---|---|
| `%Y` | four-digit year | 2026 |
| `%y` | two-digit year | 26 |
| `%m` | two-digit month | 09 |
| `%d` | two-digit day | 27 |
| `%H` | hour (24-hour) | 14 |
| `%I` | hour (12-hour) | 02 |
| `%M` | minute | 30 |
| `%S` | second | 05 |
| `%A` | full weekday name | Sunday |
| `%a` | abbreviated weekday | Sun |
| `%B` | full month name | September |
| `%p` | AM/PM | PM |

```python
from datetime import datetime
d = datetime(2026, 9, 27, 14, 30)

print(d.strftime("%A, %B %d, %Y"))       # Sunday, September 27, 2026
print(d.strftime("%Y%m%d_%H%M%S"))       # 20260927_143000 (handy for filenames)
```

## strptime: string to date

`strptime` (string parse time) is the reverse of `strftime`: it **parses** a string into a datetime object according to a format you supply.

```python
from datetime import datetime

s = "2026-09-27 14:30:00"
dt = datetime.strptime(s, "%Y-%m-%d %H:%M:%S")
print(dt)               # 2026-09-27 14:30:00
print(type(dt))         # <class 'datetime.datetime'>
```

Pay attention to the argument order: **the string comes first, then the format**.

## Crash Site: `%` must be escaped inside a format string

This is a classic trap:

```python
from datetime import datetime

now = datetime(2026, 9, 27, 14, 30)

# WRONG: trying to put a literal percent sign % in the output
print(now.strftime("%Y-%m-%d %H:%M:%S - 50% complete"))
```

Error:

```
ValueError: Invalid format string
```

`%` has special meaning in a format string — it introduces a placeholder — so a **literal** `%` must be written as `%%`:

```python
# correct
print(now.strftime("%Y-%m-%d %H:%M:%S - 50%% complete"))
# 2026-09-27 14:30:00 - 50% complete
```

The same rule means that to emit the literal text `%Y`, you must write `%%Y`.

## Crash Site: the format string and the input must agree

```python
from datetime import datetime

# WRONG: the format says %Y/%m/%d but the string uses dashes
datetime.strptime("2026-09-27", "%Y/%m/%d")
```

Error:

```
ValueError: time data '2026-09-27' does not match format '%Y/%m/%d'
```

The separators, order, and count of elements in the format string must match the input **exactly**. The format string is a template, not a fuzzy matcher.

## Worked example: building a log filename

```python
from datetime import datetime

def make_log_filename(app_name):
    """Build a timestamped log filename."""
    now = datetime.now()
    ts = now.strftime("%Y%m%d_%H%M%S")
    return f"{app_name}_{ts}.log"

print(make_log_filename("payment-service"))
# payment-service_20260927_143005.log
```

The `YYYYMMDD_HHMMSS` layout has a useful side effect: sorting filenames alphabetically is the same as sorting them chronologically.

## Worked example: parsing several formats

Users may type dates in any number of formats. Lesson 09 covers a fuller error-tolerant approach; here is the basic pattern:

```python
from datetime import datetime

def parse_date_flexible(s):
    formats = [
        "%Y-%m-%d",
        "%Y/%m/%d",
        "%d %B %Y",
        "%m/%d/%Y",
    ]
    for fmt in formats:
        try:
            return datetime.strptime(s, fmt)
        except ValueError:
            continue
    raise ValueError(f"Could not parse date: {s}")

print(parse_date_flexible("2026-09-27"))     # 2026-09-27 00:00:00
print(parse_date_flexible("09/27/2026"))     # 2026-09-27 00:00:00
print(parse_date_flexible("27 September 2026"))  # 2026-09-27 00:00:00
```

Trying each format in turn inside a try/except is the standard recipe for "I do not know which format the input will use."

## Summary

- `strftime(format)` goes from date to string; `strptime(string, format)` goes from string to date
- Common placeholders: `%Y %m %d %H %M %S` (year, month, day, hour, minute, second)
- **`%` is special** — to emit a literal `%`, write `%%`
- `strptime`'s format must match the input exactly (separators and order both matter)
- For unknown formats, loop over several patterns with try/except
