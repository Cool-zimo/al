# Walking Directories

> This lesson shows how to dig files out of a directory tree — from the one-level-at-a-time `iterdir()`, through pattern matching with `glob()`, to the deep traversal of `os.walk()`. You will learn to filter by name, find files recursively, and understand the subtle difference between `*` and `**`.

## iterdir: listing the immediate children of a directory

`Path.iterdir()` returns a generator that yields the entries directly inside a directory. It **excludes** `.` and `..`, and it does **not** descend into subdirectories.

```python
from pathlib import Path

base = Path("./project")
for entry in base.iterdir():
    print(entry.name, "DIR" if entry.is_dir() else "FILE")
```

`iterdir()` only scans one level. To tell files and directories apart, call `is_file()` or `is_dir()` on each entry.

## glob: matching names with patterns

`glob()` supports shell-style wildcards. `*` matches any characters **at the current level** (it does not cross a `/`).

```python
from pathlib import Path

base = Path("./project")

# all .py files directly inside ./project (no subdirectories)
for py in base.glob("*.py"):
    print(py)
```

The common wildcards:

| Pattern | Meaning |
|---------|---------|
| `*` | matches anything except `/` |
| `?` | matches a single character |
| `[abc]` | matches a, b, or c |
| `**` | matches any number of directory levels |

## rglob: the shortcut for recursive globbing

`rglob(pattern)` is equivalent to `glob("**/" + pattern)` — it descends into every subdirectory.

```python
from pathlib import Path

base = Path("./project")

# recursively find all .py files
for py in base.rglob("*.py"):
    print(py)
```

`rglob("*.py")` and `glob("**/*.py")` produce the same results, but `rglob` is more concise.

## Crash Site: `*` does not cross directories

This is the easiest trap for beginners — expecting `glob("*.py")` to find `.py` files buried in subdirectories.

```python
from pathlib import Path

base = Path("./project")

# WRONG: *.py only matches direct children of ./project; it does not enter subdirs
for py in base.glob("*.py"):
    print(py)
# if the .py files live in project/src/main.py, this finds nothing!
```

No error is raised, but **the result is much smaller than you expected**. Remember: **`*` does not cross directories**.

For a recursive search, use `rglob()` or `glob("**/*.py")`:

```python
# correct: recursive search
for py in base.rglob("*.py"):
    print(py)   # project/src/main.py <- now it shows up
```

## Crash Site: `**` alone matches directories too

```python
from pathlib import Path

base = Path("./project")

# WRONG: this also matches directories
for item in base.glob("**"):
    print(item)
# prints: project/.  project/src  project/src/main.py ...
# directories are included, which can break filtering logic
```

The correct form names the file pattern explicitly:

```python
# correct: files only, no directories
for py in base.glob("**/*.py"):
    if py.is_file():   # belt and braces
        print(py)
```

## os.walk: the classic three-tuple traversal

`os.walk()` predates `pathlib`. It walks the directory tree **top-down** and yields a three-tuple `(dirpath, dirnames, filenames)` on each iteration.

```python
import os

for dirpath, dirnames, filenames in os.walk("./project"):
    print(f"=== {dirpath} ===")
    for f in filenames:
        print(f"  {f}")
```

- `dirpath` — the full path of the current directory (a string)
- `dirnames` — the names of the subdirectories in the current directory (a list)
- `filenames` — the names of the files in the current directory (a list)

**The key trick**: you can **mutate the `dirnames` list in place** to control what gets walked. Remove entries and `os.walk` will not descend into them.

```python
import os

for dirpath, dirnames, filenames in os.walk("./project"):
    # skip every .git and __pycache__ directory
    dirnames[:] = [d for d in dirnames if d not in (".git", "__pycache__")]
    for f in filenames:
        if f.endswith(".py"):
            print(os.path.join(dirpath, f))
```

Assigning to `dirnames[:]` updates the original list, so `os.walk` skips the removed directories on the next step. This is invaluable for avoiding `.git`, `node_modules`, and the like.

## Summary

- `iterdir()` lists the immediate children of a directory and does not recurse
- `glob("*.py")` matches only the current level; `*` does not cross directories
- `rglob("*.py")` is equivalent to `glob("**/*.py")` and recurses
- `**` must be paired with a filename pattern, otherwise directories get matched too
- `os.walk()` yields `(dirpath, dirnames, filenames)` tuples
- Mutating `dirnames` in place controls which branches get walked
