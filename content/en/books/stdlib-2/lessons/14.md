# File Metadata

> This lesson covers how to read a file's size, modification time, and other metadata, and how to turn a Unix timestamp into a human-readable datetime. You will learn how to use `stat()`, and understand the relationship between `os.path.getsize` and `Path.stat().st_size`.

## stat(): every file attribute in one call

`Path.stat()` returns an `os.stat_result` object containing the file's size, modification time, permissions, and more. One call retrieves all of it — far more efficient than querying each field separately.

```python
from pathlib import Path
import time

p = Path("./data/report.pdf")
info = p.stat()

print(info.st_size)    # file size in bytes, e.g. 245760
print(info.st_mtime)   # last modified time as a Unix timestamp, e.g. 1717027200.0
print(info.st_atime)   # last accessed time
print(info.st_ctime)   # created time on Windows / metadata-change time on Unix
```

The common attributes of `os.stat_result`:

| Attribute | Meaning |
|-----------|---------|
| `st_size` | file size in bytes |
| `st_mtime` | last modified time (timestamp) |
| `st_atime` | last accessed time (timestamp) |
| `st_ctime` | created time (platform-dependent) |
| `st_mode` | permission bits (integer) |

## Turning a timestamp into readable time

In lesson 05 we covered `datetime.fromtimestamp()`. Here we use it to turn `st_mtime` into a readable date:

```python
from pathlib import Path
from datetime import datetime

p = Path("./data/report.pdf")
mtime = p.stat().st_mtime

# timestamp -> datetime object
dt = datetime.fromtimestamp(mtime)
print(dt)                                 # 2024-05-30 10:00:00
print(dt.strftime("%Y-%m-%d %H:%M:%S"))  # custom format
```

**UTC warning**: `fromtimestamp()` uses the **local zone**. If the timestamp you have is in UTC, use `datetime.fromtimestamp(mtime, tz=timezone.utc)` or convert afterwards with `.astimezone()`.

## os.path.getsize vs Path.stat().st_size

`os.path.getsize()` and `Path.stat().st_size` return the same number — internally the former calls `os.stat()`.

```python
import os
from pathlib import Path

p = Path("./data/report.pdf")

size_a = os.path.getsize(str(p))     # os.path style
size_b = p.stat().st_size            # pathlib style

print(size_a == size_b)   # True
```

**The difference**:

- `os.path.getsize()` returns a single number — the shortest option if you only need the size
- `Path.stat()` returns everything at once — if you also need the modification time, it saves a second system call

```python
# if you need both size and time, stat() does it in one call
info = p.stat()
size = info.st_size
mtime = datetime.fromtimestamp(info.st_mtime)

# using os.path.getsize would mean another call to os.path.getmtime
size = os.path.getsize(str(p))
mtime = os.path.getmtime(str(p))
```

## Crash Site: the file might not exist

```python
from pathlib import Path

p = Path("./data/nonexistent.txt")

# WRONG: stat() raises when the file is absent
info = p.stat()   # FileNotFoundError!
```

Error:

```
FileNotFoundError: [Errno 2] No such file or directory: './data/nonexistent.txt'
```

**Fix**: check for existence first, or wrap the call in try/except.

```python
p = Path("./data/nonexistent.txt")

if p.exists():
    info = p.stat()
    print(f"Size: {info.st_size} bytes")
else:
    print("File not found")

# or use try/except
try:
    info = p.stat()
except FileNotFoundError:
    print("File not found, skipping")
```

## Crash Site: calling strftime directly on st_mtime

```python
from pathlib import Path

p = Path("./data/report.pdf")

# WRONG: st_mtime is a float, not a datetime, so it has no strftime
mtime = p.stat().st_mtime
print(mtime.strftime("%Y-%m-%d"))   # AttributeError!
```

Error:

```
AttributeError: 'float' object has no attribute 'strftime'
```

**Fix**: convert through `datetime.fromtimestamp()` first.

```python
from datetime import datetime

mtime = p.stat().st_mtime
dt = datetime.fromtimestamp(mtime)
print(dt.strftime("%Y-%m-%d %H:%M:%S"))   # correct
```

## A useful helper: formatting file information

Bringing it all together, here is a function that takes a path and returns a human-readable summary:

```python
from pathlib import Path
from datetime import datetime

def file_info(path_str):
    p = Path(path_str)
    if not p.exists():
        return f"{path_str} does not exist"
    info = p.stat()
    size_kb = info.st_size / 1024
    mtime = datetime.fromtimestamp(info.st_mtime).strftime("%Y-%m-%d %H:%M:%S")
    return f"{p.name} | {size_kb:.1f} KB | modified {mtime}"

print(file_info("./data/report.pdf"))
# report.pdf | 240.0 KB | modified 2024-05-30 10:00:00
```

## Summary

- `Path.stat()` fetches every file attribute in one call; `st_size` is size, `st_mtime` is the modification timestamp
- Convert timestamps with `datetime.fromtimestamp()`; remember the difference between local time and UTC
- `os.path.getsize()` and `Path.stat().st_size` give the same value — the former returns just the size, the latter returns everything at once
- When you need several attributes, `stat()` saves system calls
- `stat()` raises `FileNotFoundError` on a missing file, so check first or catch the exception
- `st_mtime` is a float and has no `strftime`; convert it with `datetime.fromtimestamp()` first
