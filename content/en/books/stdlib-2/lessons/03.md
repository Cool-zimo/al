# timedelta: Time Deltas and Date Arithmetic

> This lesson answers "how do I correctly add days to a date, or find how far apart two moments are?" You will also learn the boundaries of `timedelta` — it handles days and seconds, but **not months**.

## What timedelta actually is

A `timedelta` represents a **duration** — a stretch of time. It is the intermediate type produced when you add or subtract dates and datetimes, but you can also build one directly.

```python
from datetime import timedelta, date, datetime

# building timedeltas
one_day = timedelta(days=1)
three_hours = timedelta(hours=3)
one_week = timedelta(weeks=1)     # equivalent to days=7

print(one_day)        # 1 day, 0:00:00
print(three_hours)    # 3:00:00
print(one_week)       # 7 days, 0:00:00
```

The arguments `timedelta` accepts are: `weeks`, `days`, `hours`, `minutes`, `seconds`, `milliseconds`, and `microseconds`.

## Date arithmetic: the core use

```python
from datetime import date, timedelta

today = date(2026, 9, 27)

tomorrow = today + timedelta(days=1)
print(tomorrow)   # 2026-09-28

next_week = today + timedelta(weeks=1)
print(next_week)  # 2026-10-04

about_a_month_ago = today - timedelta(days=30)
print(about_a_month_ago)  # 2026-08-28
```

This is where the standard library earns its keep: **adding a timedelta to a date carries across month boundaries automatically**. You do not need to know how many days September has, or what happens at the end of the year.

## Subtracting two dates: getting a timedelta back

```python
from datetime import date

deadline = date(2026, 12, 31)
today = date(2026, 9, 27)

remaining = deadline - today
print(remaining)                  # 95 days, 0:00:00
print(remaining.days)             # 95
print(remaining.total_seconds())  # 8208000.0
```

Use `timedelta.days` for whole days, and `total_seconds()` to convert the whole duration into seconds.

## Crash Site: timedelta has no months

This is the most common surprise:

```python
from datetime import timedelta

# WRONG: timedelta simply does not accept a months argument
delta = timedelta(months=1)
```

Error:

```
TypeError: 'months' is an invalid keyword argument for timedelta()
```

**`timedelta` only understands days, seconds, and microseconds.** Why? Because "one month" is not a fixed length — February has 28 days (or 29), while other months have 30 or 31. `timedelta` deliberately refuses this ambiguous unit.

The right tool is the third-party library `dateutil.relativedelta`, or — if you must stay in the standard library — a manual calculation using `date.replace()`:

```python
from datetime import date

d = date(2026, 1, 15)

# add one month by hand, with carry
month = d.month + 1
year = d.year
if month > 12:
    month = 1
    year += 1
d2 = date(year, month, min(d.day, 28))  # guard against Jan 31 -> Feb 31
print(d2)   # 2026-02-15 (but Jan 31 would clip to Feb 28)
```

The `calendar` module can also give you the real last day of a month, which we cover properly in lesson 08.

## Crash Site: picking the wrong unit on a time delta

```python
from datetime import datetime

t1 = datetime(2026, 9, 27, 10, 0, 0)
t2 = datetime(2026, 9, 27, 12, 30, 0)

delta = t2 - t1
print(delta.seconds)        # 9000
print(delta.total_seconds())  # 9000.0
print(delta.days)           # 0
```

`delta.seconds` returns the **sub-day remainder** in seconds (9000 seconds = 2 hours 30 minutes), not the total. `delta.days` is the whole-day part. To get the full elapsed time, use `total_seconds()`.

When the interval crosses midnight, this distinction matters even more:

```python
t1 = datetime(2026, 9, 27, 23, 0, 0)
t2 = datetime(2026, 9, 28, 2, 0, 0)

delta = t2 - t1
print(delta.days)           # 0  <- less than one full day!
print(delta.seconds)        # 10800 <- 3 hours, not 27
print(delta.total_seconds())  # 10800.0 <- the real difference
```

## timedelta also supports multiplication and abs

```python
from datetime import timedelta

one_day = timedelta(days=1)
print(one_day * 7)        # 7 days, 0:00:00
print(one_day / 2)        # 0:12:00
print(one_day * 1.5)      # 1 day, 12:00:00

d1 = timedelta(days=1)
d2 = timedelta(days=3)
print(abs(d1 - d2))       # 2 days, 0:00:00
```

## Worked example: computing a subscription expiry date

```python
from datetime import date, timedelta

def calc_expiry(join_date, plan):
    """Return the expiry date for a given plan type."""
    plans = {"monthly": 30, "quarterly": 90, "annual": 365}
    days = plans.get(plan, 30)
    return join_date + timedelta(days=days)

joined = date(2026, 9, 27)
print(calc_expiry(joined, "monthly"))  # 2026-10-27
print(calc_expiry(joined, "annual"))   # 2027-09-27
```

## Summary

- `timedelta` represents a duration; it accepts days/seconds/microseconds/weeks/hours/minutes
- date or datetime plus timedelta yields a new date (carries across boundaries automatically)
- Subtracting two dates gives a timedelta
- **`timedelta` has no `months` parameter** — use a third-party library or do the math yourself
- `delta.total_seconds()` gives the full duration; `delta.seconds` only gives the sub-day remainder
- `timedelta` supports multiplication, division, and `abs`
