# tarfile: Choosing Between tar.gz, tar.bz2, and tar.xz

> This lesson covers Python's `tarfile` module and the differences between `.tar.gz`, `.tar.bz2`, and `.tar.xz`. You will learn how to choose the right compression format for each situation.

## What tar Actually Is

A `tar` (tape archive) file only **packages** multiple files into one container; it does **not** compress them. Compression is added by an outer layer: `.tar.gz` is tar plus gzip, `.tar.bz2` is tar plus bzip2, and `.tar.xz` is tar plus xz.

```python
import tarfile

# Create a tar.gz.
with tarfile.open("backup.tar.gz", "w:gz") as tf:
    tf.add("project", arcname="project")

# Create a tar.bz2 (higher compression, slower).
with tarfile.open("backup.tar.bz2", "w:bz2") as tf:
    tf.add("project", arcname="project")

# Create a tar.xz (highest compression, slowest).
with tarfile.open("backup.tar.xz", "w:xz") as tf:
    tf.add("project", arcname="project")
```

The pattern is `w:gz`, `w:bz2`, or `w:xz`—one mode string per algorithm.

## Reading and Extracting

```python
import tarfile

with tarfile.open("backup.tar.gz", "r:gz") as tf:
    # List every entry.
    for m in tf.getmembers():
        print(m.name, m.size, "directory" if m.isdir() else "file")

    # Read one file's content.
    f = tf.extractfile("project/README.md")
    if f:
        print(f.read().decode("utf-8"))

    # Extract everything.
    tf.extractall(path="restored")
```

`getmembers()` returns `TarInfo` objects containing permission bits, ownership, modification time, and other Unix metadata. That is one advantage tar has over zip: it preserves permissions, symbolic links, and device files.

## Comparing the Three Formats

| Format | Compression | Speed | Typical use |
|--------|-------------|-------|-------------|
| `.tar.gz` (gzip) | Medium | Fast | **The default choice**, daily backups, source releases |
| `.tar.bz2` (bzip2) | Higher | Slower | When space matters more than time |
| `.tar.xz` (xz/LZMA) | Highest | Slowest | Long-term archives, minimum size |

```python
import time

# Small files are fine with gz; xz pays off on large files.
data = b"x" * 10_000_000

for fmt, mode in [("gz", "w:gz"), ("bz2", "w:bz2"), ("xz", "w:xz")]:
    t0 = time.time()
    with tarfile.open(f"test.{fmt}", mode) as tf:
        import io
        tf.addfile(tarfile.TarInfo(name="big.bin"), io.BytesIO(data))
    print(f"{fmt}: {time.time()-t0:.2f}s")
```

The general rule: **default to `.tar.gz`**; choose `.tar.xz` when size is the priority, whether for storage or transfer.

## Crash Site: The Wrong Mode String

```python
import tarfile

# WRONG: the mode resembles zip's instead of tar's.
with tarfile.open("backup.tar.gz", "w") as tf:
    tf.add("project")
# If the file already exists and is a valid tar, it may be opened;
# otherwise the behaviour depends on the file type.
```

More common is a mismatch between reading and writing:

```python
import tarfile

# WRONG: opening in read mode but trying to add a file.
with tarfile.open("new.tar.gz", "r:gz") as tf:
    tf.add("project")
```

The error:

```
ReadError: file could not be opened for reading
```

In a mode string, **the part before the colon** is the operation (`r`/`w`/`x`/`a`) and **the part after the colon** is the compression algorithm (`gz`/`bz2`/`xz`/or empty for no compression). Write with `w:xxx` and read with `r:xxx`.

## Crash Site: tar Also Has a Path Traversal Problem

Like zip, a malicious tar entry can be `../../etc/passwd`.

```python
import tarfile

# WRONG: extracting an untrusted tar directly.
with tarfile.open("untrusted.tar.gz", "r:gz") as tf:
    tf.extractall(path="out")
```

Starting with Python 3.12, `tarfile` filters more aggressively by default, but it is still safer to validate yourself:

```python
from pathlib import Path
import tarfile

def safe_extract_tar(tf, target_dir):
    target = Path(target_dir).resolve()
    for member in tf.getmembers():
        dest = (target / member.name).resolve()
        if not str(dest).startswith(str(target) + str(Path.sep)):
            raise ValueError(f"Refusing unsafe path: {member.name}")
        tf.extract(member, path=target)

with tarfile.open("untrusted.tar.gz", "r:gz") as tf:
    safe_extract_tar(tf, "out")
```

Also watch `member.islink()` and `member.issym()`: extracting a symlink may point at any file on the system, so check those cases too.

## Hands-On: Choosing the Compression Format Automatically

```python
import tarfile
import io

def make_archive(data_map, fmt="gz"):
    """Receive a {filename: content bytes} dictionary and return the archive
    bytes without touching the disk. fmt is 'gz', 'bz2', or 'xz'."""
    buf = io.BytesIO()
    mode = f"w:{fmt}"
    with tarfile.open(fileobj=buf, mode=mode) as tf:
        for name, content in data_map.items():
            info = tarfile.TarInfo(name=name)
            info.size = len(content)
            tf.addfile(info, io.BytesIO(content))
    return buf.getvalue()

# Simulated call (no disk writes).
data = {"report.txt": b"Q3 2026 results", "data.csv": b"1,2,3\n4,5,6\n"}
result = make_archive(data, "gz")
print(f"Archive size: {len(result)} bytes")   # The compressed byte count.
```

This is useful for tests and network transfers: `fileobj=BytesIO()` keeps the archive in memory instead of on disk.

## Recap

- `tar` only packages files; compression comes from gzip, bzip2, or xz.
- Mode strings: `w:gz`, `w:bz2`, `w:xz`; reading uses `r:gz` and so on.
- `.tar.gz` is the default; `.tar.xz` has the best ratio but is the slowest.
- `getmembers()` returns `TarInfo`, preserving Unix permissions, owners, and metadata.
- tar is vulnerable to path traversal too; validate before extracting untrusted archives.
- `fileobj=BytesIO()` keeps an archive in memory, which helps with testing and transfers.
