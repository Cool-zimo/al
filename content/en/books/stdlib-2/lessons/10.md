# Capstone: A Countdown and Schedule Tool

> This lesson ties the first nine lessons together into a usable "event countdown" tool. You will see how to combine `date`, `timedelta`, and `strftime` to solve a real problem.

## Requirements

We are going to build a tool with these features:

1. Given a target date (say "2026-12-25"), compute how many days are left
2. Support multiple events and show a countdown for each
3. For events that have already passed, show "X days overdue"
4. Sort events from soonest to latest

## The core: computing the day difference

```python
from datetime import date, datetime

def days_until(target):
    """How many days remain until the target date?"""
    today = date.today()
    delta = target - today
    return delta.days

# assuming today is 2026-09-27
print(days_until(date(2026, 12, 25)))   # 89
print(days_until(date(2026, 10, 1)))    # 4
```

**That one line is the whole core**: `target - today` gives a timedelta, and `.days` reads the result. Everything else is built on this.

## A complete implementation

```python
from datetime import date

def format_countdown(target, label):
    """Format the countdown message for a single event."""
    today = date.today()
    days = (target - today).days

    if days > 0:
        return f"{label}: {days} days left ({target.strftime('%Y-%m-%d')})"
    elif days == 0:
        return f"{label}: that's today!"
    else:
        return f"{label}: {abs(days)} days overdue"

# example
events = [
    (date(2026, 10, 1), "Bob's birthday"),
    (date(2026, 12, 25), "Christmas"),
    (date(2027, 1, 1), "New Year's Day"),
    (date(2026, 9, 10), "Project milestone"),
]

for target, label in events:
    print(format_countdown(target, label))
```

Output (assuming today is 2026-09-27):

```
Bob's birthday: 4 days left (2026-10-01)
Christmas: 89 days left (2026-12-25)
New Year's Day: 96 days left (2027-01-01)
Project milestone: 17 days overdue
```

## Crash Site: forgetting the "exactly today" boundary case

```python
from datetime import date

# WRONG: only checks > 0 and < 0, missing == 0
def countdown(target, label):
    days = (target - date.today()).days
    if days > 0:
        return f"{days} days left"
    else:
        return f"{abs(days)} days overdue"

# if target is today, this says "0 days overdue" -- semantically wrong
```

Boundary cases (`days == 0`) are the easiest to miss. Always test the "exactly equal" scenario.

## Extension: countdowns with time zones

If the event is "an online meeting at 08:00 London time on 2026-12-25," the zone matters:

```python
from datetime import datetime
from zoneinfo import ZoneInfo

def meeting_countdown(meeting_time, user_tz_name):
    """How long until the meeting starts?"""
    tz = ZoneInfo(user_tz_name)
    now = datetime.now(tz)
    delta = meeting_time - now
    return delta

tz_london = ZoneInfo("Europe/London")
meeting = datetime(2026, 12, 25, 8, 0, tzinfo=tz_london)

# a user in New York checking the countdown
tz_ny = ZoneInfo("America/New_York")
delta = meeting_countdown(meeting, "America/New_York")
print(f"Meeting starts in {delta.total_seconds() / 3600:.1f} hours")
```

## Extension: sorting by date

```python
from datetime import date

events = [
    (date(2026, 12, 25), "Christmas"),
    (date(2026, 10, 1), "Bob's birthday"),
    (date(2027, 1, 1), "New Year's Day"),
]

# sort by date
events.sort(key=lambda x: x[0])
for target, label in events:
    print(f"{label}: {target}")
```

`date` objects compare and sort naturally, so a plain `sort` is enough.

## Worked example: a full event manager class

```python
from datetime import date

class CountdownManager:
    def __init__(self):
        self.events = []

    def add(self, target, label):
        if isinstance(target, str):
            target = date.fromisoformat(target)
        self.events.append((target, label))

    def show_all(self):
        today = date.today()
        sorted_events = sorted(self.events, key=lambda x: x[0])
        for target, label in sorted_events:
            days = (target - today).days
            if days > 0:
                print(f"  {label}: {days} days left")
            elif days == 0:
                print(f"  {label}: that's today!")
            else:
                print(f"  {label}: {abs(days)} days overdue")

cm = CountdownManager()
cm.add("2026-10-01", "Bob's birthday")
cm.add("2026-12-25", "Christmas")
cm.add("2027-01-01", "New Year's Day")
cm.show_all()
```

## Summary

- A countdown is one line: `(target - today).days`
- The boundary case (`days == 0`) must be handled separately
- `date` objects sort natively — just call `sort(key=lambda x: x[0])`
- Zoned events use aware datetimes plus `astimezone`
- Combining `date`, `timedelta`, `strftime`, and `zoneinfo` is enough to build a genuinely useful tool
