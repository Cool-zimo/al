# Project: A Backup Tool

> This lesson brings Chapters 4 and 5 together: traverse a directory with `pathlib`, filter exclusions with `fnmatch`, package archives with `tarfile` or `zipfile`, name them with timestamps, and simulate checksums. You will build a usable command-line backup tool.

## Requirements

Our backup tool should:

- Package a target directory into a timestamped archive: `myproject_20260928_143000.tar.gz`.
- Support **exclude rules**: skip `__pycache__`, `.git`, `*.pyc`, `node_modules`, and similar entries.
- Produce a **backup manifest** recording which files were included, their total size, and the compression ratio.
- Generate **checksum information** to verify archive integrity.

**Design idea:** abstract every filesystem interaction into a pure function that receives a directory listing and returns a backup plan. That makes the logic easy to test.

## Complete Code

```python
import hashlib
from datetime import datetime
from pathlib import Path


# Default exclude rules (fnmatch patterns).
DEFAULT_EXCLUDES = [
    "__pycache__", "*.pyc", "*.pyo", ".git", ".svn",
    "node_modules", "*.tmp", ".DS_Store",
]


def should_exclude(rel_path, exclude_patterns):
    """Return True when a relative path matches any exclude pattern."""
    from fnmatch import fnmatch
    import os
    parts = rel_path.split(os.sep)
    for pat in exclude_patterns:
        # Match the full path or any single directory segment.
        if fnmatch(rel_path, pat) or any(fnmatch(p, pat) for p in parts):
            return True
    return False


def build_backup_plan(root, files, excludes=None):
    """Build a backup plan: return the included files (relative paths)."""
    excludes = excludes or DEFAULT_EXCLUDES
    included = []
    for f in files:
        if not should_exclude(f, excludes):
            included.append(f)
    return included


def make_archive_name(root, fmt="tar.gz"):
    """Create a timestamped archive name."""
    ts = datetime.now().strftime("%Y%m%d_%H%M%S")
    stem = Path(root).name or "backup"
    return f"{stem}_{ts}.{fmt}"


def simulate_archive(included, content_sizes):
    """Simulate packaging: receive the included file list and their sizes,
    then return an archive summary. content_sizes: dict mapping relative path to bytes."""
    total_raw = sum(content_sizes.get(f, 0) for f in included)
    # Text compresses to about 30%; media barely compresses at all.
    # This simulation uses a flat 0.5 estimate.
    estimated = int(total_raw * 0.5)
    return {
        "file_count": len(included),
        "total_raw_bytes": total_raw,
        "estimated_bytes": estimated,
        "compression_ratio": (estimated / total_raw) if total_raw else 0,
    }


def make_manifest(included, content_sizes):
    """Generate a backup manifest (with simulated checksums)."""
    manifest = []
    for f in included:
        size = content_sizes.get(f, 0)
        # Simulated checksum; in reality use hashlib.sha256(open(f,'rb').read()).hexdigest()
        fake_hash = hashlib.md5(f.encode("utf-8")).hexdigest()[:12]
        manifest.append({"path": f, "size": size, "checksum": fake_hash})
    return manifest
```

## Breaking Down Each Function

`should_exclude` is the core: a file is skipped when **its full relative path** or **any directory segment** matches an exclude pattern. That catches `__pycache__/x.py` and `.git/config` alike.

```python
from fnmatch import fnmatch
import os

print(should_exclude("__pycache__/x.py", DEFAULT_EXCLUDES))   # True
print(should_exclude("src/main.py", DEFAULT_EXCLUDES))       # False
print(should_exclude("data/.DS_Store", DEFAULT_EXCLUDES))    # True
```

`build_backup_plan` separates traversal from filtering. The caller supplies the file list; the function only filters. That keeps testing simple.

`simulate_archive` estimates the final size, and `compression_ratio` reports the fraction remaining.

## Crash Site: Matching Only Filenames and Missing Directories

```python
from fnmatch import fnmatch

# WRONG: matching only the basename.
files = ["src/main.py", "__pycache__/x.py", ".git/config", "src/util.py"]
excludes = ["__pycache__", "*.pyc", ".git"]

result = [f for f in files if not fnmatch(Path(f).name, excludes[0])]
print(result)
# ['src/main.py', '__pycache__/x.py', '.git/config', 'src/util.py']
# __pycache__/x.py survived! We matched "x.py", not "__pycache__".
```

Matching only the basename **misses directory-name matches**. Test the full relative path and every directory segment, exactly as `should_exclude` does above.

## Crash Site: A Coarse Timestamp Produces Colliding Archive Names

Running the backup twice within a second generates identical archive names. The second run overwrites the first, and the earlier backup disappears silently.

```python
from datetime import datetime

# WRONG: a timestamp accurate only to the second.
ts = datetime.now().strftime("%Y%m%d_%H%M%S")
archive = f"backup_{ts}.tar.gz"
print(archive)
# backup_20260928_143000.tar.gz
# Run again within the same second and the name is identical -> overwrite!
```

```python
from datetime import datetime

# Correct: add microseconds; collisions become almost impossible.
ts = datetime.now().strftime("%Y%m%d_%H%M%S_%f")
archive = f"backup_{ts}.tar.gz"
print(archive)
# backup_20260928_143000_412831.tar.gz
```

Microseconds are enough for most cases. For guaranteed uniqueness in the same directory, probe first:

```python
from pathlib import Path
from datetime import datetime

def unique_archive_name(directory, stem, ext):
    """Create a timestamped archive name that does not already exist."""
    base = Path(directory)
    i = 0
    while True:
        ts = datetime.now().strftime("%Y%m%d_%H%M%S_%f")
        name = f"{stem}_{ts}{ext}" if i == 0 else f"{stem}_{ts}_{i}{ext}"
        if not (base / name).exists():
            return name
        i += 1

# Simulated (no real filesystem check).
print(unique_archive_name("/tmp", "backup", ".tar.gz"))
```

Even if the timestamp collides, the incrementing counter is a reliable fallback.

## Hands-On: Running the Complete Pipeline

```python
# Simulate a project's file list (relative paths).
project_files = [
    "main.py", "README.md", "requirements.txt",
    "src/util.py", "src/model.py",
    "__pycache__/util.cpython-311.pyc",
    ".git/config", ".git/HEAD",
    "data/notes.txt",
    "node_modules/left-pad/index.js",
]

# Simulate each file's size.
sizes = {
    "main.py": 2_000,
    "README.md": 500,
    "requirements.txt": 100,
    "src/util.py": 1_500,
    "src/model.py": 3_000,
    "data/notes.txt": 800,
    ".git/config": 300,
    "__pycache__/util.cpython-311.pyc": 1_200,
    "node_modules/left-pad/index.js": 5_000,
}

# 1. Build the backup plan.
included = build_backup_plan(".", project_files)
print("Files to back up:")
for f in included:
    print(f"  {f}")
# main.py / README.md / requirements.txt / src/util.py / src/model.py / data/notes.txt

# 2. Generate the archive name.
print("Archive name:", make_archive_name("./myproject"))

# 3. Simulate the archive summary.
summary = simulate_archive(included, sizes)
print("Summary:", summary)

# 4. Generate the manifest.
manifest = make_manifest(included, sizes)
print(f"Manifest has {len(manifest)} records")
```

The output:

```
Files to back up:
  main.py
  README.md
  requirements.txt
  src/util.py
  src/model.py
  data/notes.txt
Archive name: myproject_20260928_143000.tar.gz
Summary: {'file_count': 6, 'total_raw_bytes': 7900, ...}
Manifest has 6 records
```

## Recap

- A backup tool has three pieces: traverse the directory, exclude with `fnmatch`, package the archive.
- Exclude rules must match **the full path and every directory segment**; basename matching misses entries.
- Name archives with `YYYYMMDD_HHMMSS` so sorting the filenames gives you chronological order.
- A manifest plus checksums is what makes a backup verifiable and reversible.
- Keep filesystem operations as pure functions and test them with simulated lists.
