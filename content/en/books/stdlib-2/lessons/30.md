## Command-Line Parsing with sys.argv

`argparse` belongs in *Standard Library 3*. This lesson uses only `sys.argv` and parses it by hand: enough to be useful, and simple to follow.

```python
import sys
from pathlib import Path


def parse_args(argv):
    """Parse command-line arguments and return a dict.
    Usage: organize.py <directory> [--apply] [--undo [run_id]] [--rules rules-file]"""
    args = {"root": None, "apply": False, "undo": None, "rules": None}
    i = 1
    while i < len(argv):
        a = argv[i]
        if a == "--apply":
            args["apply"] = True
        elif a == "--undo":
            args["undo"] = "latest"
            if i + 1 < len(argv) and not argv[i + 1].startswith("--"):
                args["undo"] = argv[i + 1]
                i += 1
        elif a == "--rules":
            args["rules"] = argv[i + 1]
            i += 1
        elif not a.startswith("--"):
            args["root"] = a
        i += 1
    return args


def main(argv):
    args = parse_args(argv)
    if not args["root"]:
        print("Usage: python organize.py <directory> [--apply] [--undo [run_id]]")
        return 1

    root = Path(args["root"])
    if not root.exists():
        print(f"Error: directory not found -> {root}")
        return 2

    # Wire the four layers together.
    from organizer import Organizer   # Imagine the earlier lessons live in organizer.py
    org = Organizer(root)

    if args["undo"]:
        n, errs = org.undo(args["undo"] if args["undo"] != "latest" else None)
        print(f"✓ Reversed {n} file moves" + (f", {len(errs)} failed" if errs else ""))
        return 0

    org.scan()
    org.classify()
    org.plan_moves()
    plan = org.get_plan()

    if not args["apply"]:
        org.preview()
        return 0

    # Actually execute.
    ok, failed, run_id = org.apply(plan)
    print(f"✓ Done: {ok} files, {len(failed)} failed")
    print(f"  run_id={run_id} (use --undo {run_id} to reverse)")
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv))
```

## Progress Feedback: Do Not Leave Users Staring at a Blank Screen

Scanning 3,000 files and calling `stat()` on each can take a few seconds. Without feedback, users assume the program has hung and reach for Ctrl-C.

```python
def scan_with_progress(root, ignore_dirs, ignore_files, callback=None):
    """Walk the directory, collect metadata, and report progress every 100 files."""
    from datetime import datetime
    root = Path(root)
    files, count = [], 0
    for p in root.rglob("*"):
        if not p.is_file():
            continue
        if any(part in ignore_dirs for part in p.relative_to(root).parts[:-1]):
            continue
        if p.name in ignore_files:
            continue
        try:
            st = p.stat()
        except OSError:
            continue
        files.append({
            "src": str(p),
            "name": p.name,
            "ext": p.suffix.lower(),
            "size": st.st_size,
            "mtime": datetime.fromtimestamp(st.st_mtime).isoformat(timespec="seconds"),
        })
        count += 1
        if callback and count % 100 == 0:
            callback(count)
    return files


def default_callback(n):
    print(f"  Scanned {n} files...", flush=True)

# Usage
files = scan_with_progress("/d", {"__pycache__", ".git"}, {".DS_Store"}, default_callback)
#   Scanned 100 files...
#   Scanned 200 files...
```

`flush=True` matters: output is line-buffered by default, so without it the progress may sit in a buffer and appear all at once at the end—which is no feedback at all.

## Exception Handling: One Failure Must Not Spread

Lessons 27 and 29 introduced this principle. Here is the complete version: one bad file or one permission error must never abort the whole organising run.

```python
import shutil
from pathlib import Path

def move_all(plan, conflict="suffix"):
    """Execute the whole plan, recording successes and failures without aborting."""
    ok, failed = 0, []
    for dest_rel, src in plan.items():
        try:
            d = Path(dest_rel)
            if d.exists():
                if conflict == "skip":
                    failed.append({"src": src, "reason": "exists"})
                    continue
                # Suffix strategy: rename automatically.
                stem, suffix = d.stem, d.suffix
                i = 1
                while d.exists():
                    d = d.with_name(f"{stem}_{i}{suffix}")
                    i += 1
            d.parent.mkdir(parents=True, exist_ok=True)
            shutil.move(src, str(d))
            ok += 1
        except OSError as e:
            failed.append({"src": src, "reason": str(e)})
            continue   # The crucial part: continue, do not raise.

    return ok, failed


ok, failed = move_all(plan)
print(f"✓ Done: {ok} files")
for f in failed:
    print(f"  ✗ Skipped {f['src']}: {f['reason']}")
```

**Three layers of defence:** `scan` skips files whose `stat()` fails, the plan resolves destination conflicts with a policy, and `move` catches I/O exceptions and continues. No layer propagates an exception to the layer above it.

## Wiring the Four Layers: A Runnable Skeleton

Put the implementations from the previous lessons into `organizer.py`; the main program runs in roughly a dozen lines:

```python
# organizer.py (a wiring skeleton; see earlier lessons for details).
import json, shutil
from datetime import datetime
from pathlib import Path

IGNORE_DIRS = {"__pycache__", ".git", "node_modules", ".venv", "venv"}
IGNORE_FILES = {".DS_Store", "Thumbs.db"}

DEFAULT_RULES = {
    "categories": {
        "Images": [".jpg", ".jpeg", ".png", ".gif", ".webp"],
        "Docs": [".pdf", ".docx", ".xlsx", ".txt", ".md"],
        "Media": [".mp4", ".mkv", ".mp3"],
        "Archives": [".zip", ".tar", ".gz", ".7z"],
        "Code": [".py", ".js", ".ts", ".go"],
    },
    "date_archive": True,
    "date_format": "%Y-%m",
    "size_thresholds": {"tiny": 10240, "huge": 104857600},
    "conflict": "suffix",
}


class Organizer:
    def __init__(self, root, rules=None, log_dir=None):
        self.root = Path(root)
        self.rules = rules or DEFAULT_RULES
        self.log_dir = Path(log_dir or self.root / ".organize_logs")
        self.files = []
        self.plan = {}

    def scan(self, callback=None):
        self.files = scan_with_progress(self.root, IGNORE_DIRS, IGNORE_FILES, callback)

    def classify(self):
        ext_map = self._build_ext_map()
        for f in self.files:
            f["category"] = ext_map.get(f["ext"]) or self._by_size(f["size"])

    def plan_moves(self):
        for f in self.files:
            cat = f["category"]
            if self.rules["date_archive"]:
                sub = datetime.fromisoformat(f["mtime"]).strftime(self.rules["date_format"])
                dest = f"{cat}/{sub}/{f['name']}"
            else:
                dest = f"{cat}/{f['name']}"
            self.plan[dest] = f["src"]

    def preview(self):
        by_cat = {}
        for dest in self.plan:
            cat = dest.split("/")[0]
            by_cat[cat] = by_cat.get(cat, 0) + 1
        print(f"[Preview] Will process {len(self.plan)} files")
        for cat, n in sorted(by_cat.items(), key=lambda x: -x[1]):
            print(f"  {cat:<12} -> {n}")
        print("\nTip: add --apply to actually execute.")

    def apply(self):
        self.log_dir.mkdir(parents=True, exist_ok=True)
        run_id = datetime.now().strftime("%Y%m%d_%H%M%S_%f")
        log = {"run_id": run_id, "root": str(self.root),
               "operations": [{"src": s, "dest": str(self.root / d), "status": "pending"}
                              for d, s in self.plan.items()]}
        log_file = self.log_dir / f"ops_{run_id}.json"
        log_file.write_text(json.dumps(log, ensure_ascii=False, indent=2))

        ok, failed = 0, []
        for op in log["operations"]:
            try:
                d = Path(op["dest"])
                d.parent.mkdir(parents=True, exist_ok=True)
                shutil.move(op["src"], str(d))
                op["status"] = "done"
                ok += 1
            except OSError as e:
                op["status"] = "failed"
                op["error"] = str(e)
                failed.append(op["src"])
        log_file.write_text(json.dumps(log, ensure_ascii=False, indent=2))
        return ok, failed, run_id

    def undo(self, run_id=None):
        d = self.log_dir
        if run_id:
            log_file = d / f"ops_{run_id}.json"
        else:
            logs = sorted(d.glob("ops_*.json"))
            if not logs:
                raise FileNotFoundError("No reversible operation record found")
            log_file = logs[-1]
        log = json.loads(log_file.read_text(encoding="utf-8"))
        undone = 0
        for op in reversed(log["operations"]):
            if op["status"] != "done":
                continue
            try:
                src, dst = Path(op["dest"]), Path(op["src"])
                if src.exists():
                    dst.parent.mkdir(parents=True, exist_ok=True)
                    shutil.move(str(src), str(dst))
                    undone += 1
            except OSError:
                continue
        return undone

    def get_plan(self):
        return self.plan

    def _build_ext_map(self):
        m = {}
        for cat, exts in self.rules["categories"].items():
            for ext in exts:
                m[ext.lower()] = cat
        return m

    def _by_size(self, size):
        t = self.rules["size_thresholds"]
        if size < t["tiny"]:
            return "Tiny"
        if size >= t["huge"]:
            return "Huge"
        return "Other"
```

This skeleton turns every design decision from Lessons 26 to 29 into code: **layering, pure functions first, logging before execution, explicit conflict handling, and exceptions that never spread**.

## Crash Site: Putting All the Logic Inside `__main__` Makes It Unusable

Packing scanning, classification, and moving into `if __name__ == "__main__":` is the classic beginner move. It runs, but it cannot be imported or tested.

```python
# WRONG: all the logic lives inside __main__.
if __name__ == "__main__":
    root = sys.argv[1]
    for p in Path(root).rglob("*"):
        ...   # Scanning, classifying, and moving all mixed together.
    print("done")
# Another module cannot call this. Tests cannot call this either.

# Correct: put logic into classes and functions; __main__ only wires them up.
if __name__ == "__main__":
    sys.exit(main(sys.argv))
```

`if __name__ == "__main__":` means "run this block only when the file is executed directly." When the file is imported, that code does not run—so the same file works as a program and as a testable import.

## Crash Site: Argument Parsing Misses Boundary Cases

Hand-written parsers most often fail on "the last argument" or "an unknown option".

```python
import sys

# WRONG: no bounds check; --undo with no value raises IndexError.
def parse_wrong(argv):
    args = {}
    i = 1
    while i < len(argv):
        if argv[i] == "--undo":
            args["undo"] = argv[i + 1]   # Crashes when --undo is the final argument.
        i += 1

# Correct: test the bounds before reading argv[i + 1].
def parse_right(argv):
    args = {"undo": None}
    i = 1
    while i < len(argv):
        a = argv[i]
        if a == "--undo":
            if i + 1 < len(argv) and not argv[i + 1].startswith("--"):
                args["undo"] = argv[i + 1]
                i += 1
            else:
                args["undo"] = "latest"
        i += 1
    return args

print(parse_right(["organize.py", "--undo"]))            # {'undo': 'latest'}
print(parse_right(["organize.py", "--undo", "abc123"]))  # {'undo': 'abc123'}
```

## What This Book Has Given You

Five chapters later, you have a toolbox for dealing with the operating system:

| Capability | Standard library | One-line summary |
|------------|------------------|------------------|
| Time calculations | `datetime` / `time` / `calendar` | Time is a number; state time zones explicitly; format consistently |
| Paths and traversal | `pathlib` / `os.path` | New code uses `pathlib`; paths are objects, not strings |
| File I/O | `open` / `io` / `tempfile` | `with` keeps you safe; leave temporary files to `tempfile` |
| System interaction | `os` / `subprocess` / `shutil` | Pass arguments as a list; never build shell strings |
| Archives and compression | `zipfile` / `tarfile` | Compression is not magic: text compresses, media barely does |

More importantly, you have picked up three **engineering habits**:

1. **Layering:** scanning, classification, rules, and execution each own one concern; pure functions come first and I/O comes last—testable and reusable.
2. **Defence:** preview before executing, log before acting, and do not let one failure spread.
3. **Configuration:** rules are data, not code; a new situation should not require rewriting logic.

## Recap

- `sys.argv` is sufficient for manual parsing; watch for out-of-bounds access and "option with no value" cases.
- Use `flush=True` for progress feedback so users are not left staring at a blank screen.
- One I/O failure should be caught and the run should continue: three layers of defence.
- `if __name__ == "__main__":` only wires things together; logic belongs in classes and functions so it can be tested.
- Five chapters covered time, paths, files, systems, and archives.
- Three engineering habits: layering, defence, and configuration.
