# Capstone: A Batch-Rename Tool

> This lesson brings everything you have learned about `pathlib` together into a command-line batch-rename tool. Its core design principle is: **preview first, then apply** — never silently renaming files. You will also handle name collisions and build an undo mechanism.

## Requirements

We want a tool that renames files in bulk according to rules. For example:

- Add a date prefix to every `.txt` file: `notes.txt` -> `20240928_notes.txt`
- Replace spaces with underscores: `my file.txt` -> `my_file.txt`
- Lowercase everything: `Report.PDF` -> `report.pdf`

**Three core safety principles:**

1. **Preview before applying** — by default, only print what *would* happen; require a flag to actually do it
2. **Detect name collisions** — if the target already exists, either error out or auto-number it
3. **Generate an undo script** — after applying, print a command that restores the original names

## The complete code

```python
import argparse
import sys
from datetime import datetime
from pathlib import Path


def build_new_name(p: Path, rule: str) -> str:
    """Generate a new filename according to the chosen rule."""
    if rule == "date_prefix":
        today = datetime.now().strftime("%Y%m%d")
        return f"{today}_{p.name}"
    elif rule == "underscore":
        return p.name.replace(" ", "_")
    elif rule == "lowercase":
        return p.name.lower()
    else:
        raise ValueError(f"Unknown rule: {rule}")


def find_unique_path(target: Path) -> Path:
    """If the target exists, append _1, _2, ... until it does not."""
    if not target.exists():
        return target
    stem = target.stem
    suffix = target.suffix
    parent = target.parent
    i = 1
    while True:
        candidate = parent / f"{stem}_{i}{suffix}"
        if not candidate.exists():
            return candidate
        i += 1


def preview(directory: str, pattern: str, rule: str):
    """Preview mode: print the planned operations only."""
    base = Path(directory)
    if not base.is_dir():
        print(f"Error: {directory} is not a valid directory")
        sys.exit(1)

    files = list(base.glob(pattern))
    if not files:
        print(f"No files matching {pattern}")
        return

    print(f"About to process {len(files)} files:\n")
    for f in files:
        new_name = build_new_name(f, rule)
        if new_name == f.name:
            print(f"  skip   {f.name} (rule produces no change)")
        else:
            print(f"  {f.name}  ->  {new_name}")

    print(f"\n{len(files)} files will be renamed.")
    print("Run again with --apply to confirm.")


def apply_rename(directory: str, pattern: str, rule: str):
    """Apply mode: actually rename, and handle collisions."""
    base = Path(directory)
    files = list(base.glob(pattern))

    renames = []  # (old path, new path)
    for f in files:
        if not f.is_file():
            continue
        new_name = build_new_name(f, rule)
        if new_name == f.name:
            continue
        target = find_unique_path(base / new_name)
        renames.append((f, target))

    # perform the renames
    undo_pairs = []
    for old, new in renames:
        old.rename(new)
        undo_pairs.append((new.name, old.name))
        print(f"  ✓ {old.name}  ->  {new.name}")

    # emit an undo script
    if undo_pairs:
        print(f"\nDone: {len(undo_pairs)} renames.")
        print("Undo script (save as undo.sh and run):")
        print("#!/bin/bash")
        for new_name, orig_name in undo_pairs:
            print(f'mv "{new_name}" "{orig_name}"')
    else:
        print("Nothing to rename.")


def main():
    parser = argparse.ArgumentParser(
        description="Batch rename tool -- preview before applying"
    )
    parser.add_argument("directory", help="Target directory")
    parser.add_argument("--pattern", default="*", help="Glob pattern, e.g. *.txt")
    parser.add_argument(
        "--rule",
        default="underscore",
        choices=["date_prefix", "underscore", "lowercase"],
        help="Rename rule",
    )
    parser.add_argument("--apply", action="store_true", help="Actually apply (without it, preview only)")

    args = parser.parse_args()

    if args.apply:
        print("=== Apply mode ===")
        apply_rename(args.directory, args.pattern, args.rule)
    else:
        print("=== Preview mode ===")
        preview(args.directory, args.pattern, args.rule)


if __name__ == "__main__":
    main()
```

## Why "preview" matters

A rename is hard to undo (at least at the shell level). **Preview mode lets you see every change before it happens**, so you can check for:

- Files that matched by mistake
- Output filenames that do not look right
- Possible collisions

Only after confirming with `--apply` does the tool actually run. This **dry-run -> confirm -> apply** three-step pattern is a best practice in operations scripts, database migrations, and batch processing.

## Collision handling: find_unique_path

When two files produce the same name under a rule — for example `IMG_001.jpg` and `img_001.jpg` on a case-insensitive file system — `find_unique_path()` appends a number automatically:

```
first call:  20240928_IMG_001.jpg does not exist, return it
second call: 20240928_IMG_001.jpg exists, return 20240928_IMG_001_1.jpg
third call:  keep going -> 20240928_IMG_001_2.jpg
```

So even when a rule causes a collision, nothing gets overwritten.

## Crash Site: renaming without a preview

```python
from pathlib import Path

# WRONG: iterate and rename immediately, with no preview and no confirmation
base = Path("./docs")
for f in base.iterdir():
    new = f.with_name(f.name.upper())
    f.rename(new)
    print(f"renamed {f.name} -> {new.name}")
# afterwards you realise a .git directory was touched, or names collided and files were lost
```

**Consequences**: name collisions overwrite files, unintended files get changed, and there is no way back.

**The fix**: as in the worked example above, **walk the matches first, print the plan, then execute only after confirmation**.

## Crash Site: rename silently overwrites an existing file

```python
from pathlib import Path

p = Path("./notes.txt")
target = Path("./README.txt")

# WRONG: if README.txt exists, it gets silently overwritten!
p.rename(target)
```

On Unix, `rename()` overwrites the destination if it already exists (permissions permitting), and the data is simply lost.

**The fix**: check whether the target exists first, using logic similar to `find_unique_path()`:

```python
if target.exists():
    print(f"Warning: {target.name} already exists, skipping")
else:
    p.rename(target)
```

Or use `replace()` when you genuinely intend to overwrite — on Windows, `rename` raises an error for an existing target, while `replace` overwrites.

## Extensions: supporting more rules

You can add new rename rules to the tool, such as:

- `sequential` — number the files `file_01.txt`, `file_02.txt`, ...
- `remove_spaces` — strip all spaces rather than replacing them with underscores
- `add_suffix` — append `_backup` to every name

Just add an `elif` branch to `build_new_name()`, and register the new rule in the `choices` list of the argument parser.

## Summary

- The heart of a batch-rename tool is the "preview before apply" safety design
- `build_new_name()` generates new names from rules; `find_unique_path()` handles collisions
- Preview mode walks the matches and prints the plan; only `--apply` triggers the real work
- On collision, auto-number with `_1`, `_2`, ... rather than silently overwriting
- After applying, emit undo commands so the changes can be rolled back
- "dry-run -> confirm -> apply" is a universal best practice for operations scripts
