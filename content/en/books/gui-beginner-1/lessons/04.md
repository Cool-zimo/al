# Your First Widgets: Label and Button

> A window needs something inside it. This lesson covers the two most common widgets: Label (displaying text) and Button (clicking). The key point — and the part that trips everyone up — is that creating a widget does **not** mean it is visible; you must also "put it in."

## What Is a Widget?

**A widget is anything visible and tangible inside a window:** text, buttons, entry boxes, checkboxes… tkinter has dozens of them.

**Every widget follows the same pattern:** create it → configure its properties → place it in the window. Skip any one of those steps and something breaks.

## Label: The Simplest Text Display

**A Label is a "sticker" used to display text or an image.**

```
import tkinter as tk

root = tk.Tk()
root.title("Label Example")

label = tk.Label(root, text="Hello, world")
label.pack()

root.mainloop()
```

**Key arguments:**

| Argument | Purpose | Example |
|---|---|---|
| `text` | The displayed text | `text="Hello"` |
| `bg` / `background` | Background color | `bg="yellow"` |
| `fg` / `foreground` | Text color | `fg="red"` |
| `font` | Font and size | `font=("Arial", 14, "bold")` |
| `width` / `height` | Width / height (in characters / lines) | `width=20` |
| `anchor` | Alignment of the text within the widget | `anchor="w"` (left) |
| `justify` | How multiple lines are aligned | `justify="left"` |
| `wraplength` | Wrap automatically after this many pixels | `wraplength=200` |

**`font` takes a tuple:** `(font_name, size, style)`. The style can be `"bold"`, `"italic"`, or `"bold italic"`.

```
label = tk.Label(root, text="Big Heading",
                 font=("Arial", 20, "bold"),
                 fg="white", bg="#3498db",
                 width=20, height=3)
```

**`width` and `height` are measured in "characters," not pixels** (on a Label). **This detail catches people out:** `width=20` is roughly 20 characters wide; a Chinese character is about twice as wide as a Latin character.

**For multiple lines, use `\n` for explicit breaks or `wraplength` for automatic wrapping:**

```
label = tk.Label(root, text="This is a very long line of text that needs wrapping",
                 wraplength=150, justify="left", anchor="w")
```

**`wraplength=150` means "wrap after 150 pixels."** `justify` controls how multiple lines align with each other, while `anchor` controls where the whole block sits inside the widget box (`"w"` = west = left, `"e"` = east = right, `"n"` = north = top, `"s"` = south = bottom).

## Changing Text: `configure` and `textvariable`

**A widget's text can be changed after creation in two ways:**

```
label = tk.Label(root, text="Old text")
label.pack()

# Approach 1: configure
label.configure(text="New text")

# Approach 2: assign directly (same effect)
label["text"] = "Changed again"
```

**`label["text"] = ...` is perfectly legal dictionary-style syntax**, because a widget's properties are essentially a dictionary underneath. Either style works.

## Crash Scene 1: Forgetting `pack`/`grid`/`place`, the Widget Is "Invisible"

**This is the biggest pitfall in this lesson.**

```
import tkinter as tk

root = tk.Tk()
label = tk.Label(root, text="You cannot see me")   # created, but never placed
root.mainloop()
```

**Symptoms:** the window opens, but it is **blank** — the Label never appears.

**Why:** creating a widget merely manufactures it. You must then use `pack()`/`grid()`/`place()` to put it into the window's layout. **Without that step, the widget floats in a vacuum where nobody can see it.**

**Fix:** add `.pack()`:

```
label = tk.Label(root, text="Now you can see me")
label.pack()   # the crucial step!
```

**Mnemonic: after creating a widget you must "put it on the shelf," and putting it on the shelf means calling pack, grid, or place.**

## Crash Scene 2: Storing the Return Value of `pack`

Mentioned in Lesson 2, but worth emphasizing again:

```
label = tk.Label(root, text="Hint").pack()   # wrong!
print(label)   # None
label.configure(text="New")   # AttributeError!
```

**`pack()` returns `None`.** The correct version uses two lines:

```
label = tk.Label(root, text="Hint")
label.pack()
```

## Button: Click Me

**A Button is, well, a button. Its defining argument is `command` — the function to call when it is clicked.**

```
import tkinter as tk

root = tk.Tk()
root.title("Button Example")

def say_hi():
    print("Hello!")

btn = tk.Button(root, text="Click me", command=say_hi)
btn.pack()

root.mainloop()
```

**Click the button once and "Hello!" is printed in the terminal.**

**Common Button arguments:**

| Argument | Purpose |
|---|---|
| `text` | The text shown on the button |
| `command` | The function to call on click (**no parentheses**) |
| `bg` / `fg` | Background color / text color |
| `font` | Font |
| `width` / `height` | Size (in characters) |
| `state` | `"normal"` enabled / `"disabled"` grayed out |
| `relief` | Border style: `"raised"`/`"sunken"`/`"flat"`/`"ridge"`/`"groove"` |
| `cursor` | The cursor style when the mouse hovers over the button |

**`command` is the most important — and the easiest to get wrong — argument.** It has its own lesson coming up. For now, remember: **`command=say_hi` with no parentheses; writing `command=say_hi()` is wrong.**

## The Three States of a Button

```
btn = tk.Button(root, text="Enabled", state="normal")
btn = tk.Button(root, text="Disabled", state="disabled")
```

**`state="disabled"` grays the button out so it cannot be clicked.** This is useful when "the form is not complete, so the submit button stays disabled."

**To re-enable the button:**

```
btn.configure(state="normal")
```

## Relief: A Button's Sense of Depth

**`relief` controls the border style and is great for a "pressed" visual effect:**

```
tk.Button(root, text="Raised", relief="raised").pack()
tk.Button(root, text="Sunken", relief="sunken").pack()
tk.Button(root, text="Flat", relief="flat").pack()
tk.Button(root, text="Ridge", relief="ridge").pack()
tk.Button(root, text="Groove", relief="groove").pack()
```

**Pair it with `bd` (border width) for a stronger effect:**

```
tk.Button(root, text="Thick border", relief="ridge", bd=5).pack()
```

## A Click Counter

**This is a classic small example showing how a button cooperates with a variable:**

```
import tkinter as tk

root = tk.Tk()
root.title("Counter")

count = 0

def add():
    global count
    count += 1
    label.configure(text=f"Clicked {count} times")

label = tk.Label(root, text="Clicked 0 times", font=("Arial", 16))
label.pack(pady=20)

btn = tk.Button(root, text="Add one", command=add)
btn.pack()

root.mainloop()
```

**Here `global count` declares that `count` is a global variable**, because the function reassigns it. If you only read it without changing it, `global` is unnecessary.

**Crash scene:** forget `global count` and you get `UnboundLocalError: local variable 'count' referenced before assignment`. Why? Because the function contains `count += 1` (an assignment), Python treats `count` as local; but when it tries to read it, no value has been assigned yet.

## Making a Button "Transform": Changing Text and State

**The button itself can change dynamically:**

```
def toggle():
    if btn["text"] == "Start":
        btn.configure(text="Stop", bg="red")
    else:
        btn.configure(text="Start", bg="SystemButtonFace")  # restore the system default

btn = tk.Button(root, text="Start", command=toggle)
btn.pack()
```

**This kind of "toggle button" is common in media players and timers.**

## Displaying an Image on a Label

**A Label can hold an image as well as text, using `PhotoImage`:**

```
import tkinter as tk

root = tk.Tk()

# Supports PNG, GIF, PPM; does not support JPG (Pillow is required for that)
img = tk.PhotoImage(file="example.png")
label = tk.Label(root, image=img)
label.pack()

root.mainloop()
```

**Crash scene:** the image does not appear, and there is no error either.

```
img = tk.PhotoImage(file="photo.jpg")   # error or blank
```

**Native tkinter supports only PNG / GIF / PPM, not JPG.** To display a JPG you need Pillow: `from PIL import Image, ImageTk`, followed by `img = ImageTk.PhotoImage(Image.open("photo.jpg"))`.

**Another trap: the image object gets garbage-collected.** In some environments, if a `PhotoImage` exists only as a local variable, it is recycled once the function ends and the image goes blank. The safe pattern is to **keep the image as a global variable or attach it to the widget:**

```
label.image = img   # retain a reference so it is not collected
```

## The Universal Rules of Widget Properties

**All widgets share one property system, which is why tkinter is reasonably easy to learn:**

| Operation | Syntax |
|---|---|
| Set at creation | `tk.Label(root, text="x", bg="red")` |
| Change after creation | `label.configure(text="y")` |
| Dictionary-style change | `label["text"] = "y"` |
| Read a value | `label["text"]` or `label.cget("text")` |

**`cget` is the standard way to read a property:**

```
print(label.cget("text"))   # "y"
```

## Summary

- **Label** displays text: `text`, `font`, `fg`, `bg`, and `wraplength` are the most common
- **Button** responds to clicks: `command` specifies the function to call
- **A widget must be packed/gridded/placed after creation, or it stays invisible**
- `pack()` returns `None`; never store its return value in a variable
- `command=say_hi` (no parentheses); the parentheses trap comes in the next lesson
- A Label can hold an image: `PhotoImage(file="x.png")`; native tkinter does not support JPG
- Change properties with `configure()`; read them with `cget()`
