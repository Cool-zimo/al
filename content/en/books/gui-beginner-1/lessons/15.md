# Combobox, Spinbox, Scale: The ttk Widgets

> The default tkinter widgets look like Windows 95, on purpose — they were designed in the nineties. ttk (themed Tk) gives you widgets that match the user's operating system, plus three widgets tkinter never had: Combobox, Spinbox, and Scale. This lesson covers all three, and why reaching for ttk is usually the right call.

## What ttk Actually Is

**ttk is tkinter's themed submodule — it draws controls in the native style of your OS.**

```
import tkinter as tk
import tkinter.ttk as ttk

root = tk.Tk()

ttk.Button(root, text="modern button").pack()
ttk.Label(root, text="modern label").pack()

root.mainloop()
```

**Side by side, the difference is obvious:**

| tkinter widget | ttk equivalent |
|---|---|
| Vintage look, mid-90s aesthetic | Native look, current OS |
| `tk.Button` | `ttk.Button` |
| `tk.Label` | `ttk.Label` |
| `tk.Entry` | `ttk.Entry` |
| `tk.Checkbutton` | `ttk.Checkbutton` |
| `tk.Radiobutton` | `ttk.Radiobutton` |
| `tk.Frame` | `ttk.Frame` |

**The rule: use ttk unless you have a reason not to.** Reasons not to include wanting exact colours (ttk fights you on those) or needing a feature only the classic widget exposes.

## Why ttk Earns Its Keep

**Three concrete advantages:**

1. **It looks modern** — rounded corners on macOS, flat design on Windows, native Adwaita on Linux.
2. **It adds widgets tkinter lacks**: Combobox, Spinbox, Treeview, Notebook, Progressbar, Separator.
3. **Themes are switchable** through `ttk.Style()`.

**Switching themes:**

```
import tkinter.ttk as ttk

style = ttk.Style()
print(style.theme_names())
# ('winnative', 'clam', 'alt', 'default', 'classic', 'vista', 'xpnative')
style.theme_use("clam")
```

**`clam` is the portable one** — same look on every OS. `vista`/`xpnative` is Windows-only, `aqua` is macOS-only. When you need screenshots that look identical across machines, `clam` is the answer.

## Combobox: An Entry With a Dropdown

**Combobox is "type something or pick from a list" in one widget.**

```
import tkinter as tk
import tkinter.ttk as ttk

root = tk.Tk()

cb = ttk.Combobox(root, values=["apple", "banana", "orange", "grape"])
cb.pack(padx=10, pady=10)
cb.set("choose one")   # set the visible value

root.mainloop()
```

**`values` is the list of options; `set()` reads and writes the current value.**

## Reading a Combobox

**Two equivalent ways:**

```
# option 1: read directly
print(cb.get())

# option 2: bind a StringVar
var = tk.StringVar()
cb = ttk.Combobox(root, textvariable=var, values=["A", "B", "C"])
print(var.get())
```

**`cb.get()` returns whatever is shown — typed by the user or picked from the list.** Which is exactly the problem: the user can type anything.

## Combobox in Read-Only Mode

**`state="readonly"` locks the box so only list items are valid.**

```
cb = ttk.Combobox(root, values=["male", "female"], state="readonly")
cb.set("male")
```

**For any form with a fixed set of answers, make it readonly.** You stop typos like `"malle"` before they reach your code.

## Reacting to a Selection

**`<<ComboboxSelected>>` fires the moment the user picks an item.**

```
def on_select(event):
    print("selected:", cb.get())

cb.bind("<<ComboboxSelected>>", on_select)
```

**The `<< >>` brackets mark it as a virtual event** — tkinter's name for an event built on top of raw mouse and keyboard input. Lesson 18 explains the distinction.

## Spinbox: Stepping Through Values

**Spinbox is an Entry with up/down arrows that step through a range.**

```
sb = tk.Spinbox(root, from_=0, to=100, increment=1)
sb.pack()

print(sb.get())   # the current value as a string
```

**The arguments:**

| Argument | Purpose |
|---|---|
| `from_` | Minimum (note the trailing underscore) |
| `to` | Maximum |
| `increment` | Step size |
| `values` | A fixed list of options, replacing from_/to |
| `wrap` | When True, wraps around at the ends |
| `state` | `"normal"` / `"readonly"` / `"disabled"` |

**`from_` needs the underscore because `from` is a Python keyword.** Forget it and you get a syntax error — the most avoidable bug in this lesson.

**A discrete list instead of a range:**

```
sb = tk.Spinbox(root, values=["small", "medium", "large", "x-large"])
```

**Spinbox takes a `textvariable` too:**

```
var = tk.StringVar(value="1")
sb = tk.Spinbox(root, from_=1, to=10, textvariable=var)
```

## Scale: The Slider

**Scale is a slider — for "roughly this much", not "exactly this number".**

```
scale = tk.Scale(root, from_=0, to=100, orient="horizontal")
scale.pack()

print(scale.get())   # the current numeric value
```

**The arguments:**

| Argument | Purpose |
|---|---|
| `from_` / `to` | Range |
| `orient` | `"horizontal"` or `"vertical"` |
| `resolution` | Step size (e.g. `0.1`) |
| `tickinterval` | Spacing of tick marks |
| `length` | Length in pixels |
| `showvalue` | Whether to label the current value |
| `variable` | Bind an `IntVar` or `DoubleVar` |

**`resolution=0.1` lets the slider pick fractional values.** That's the difference between a volume knob and a counter.

## Binding a Scale to a Variable

```
var = tk.DoubleVar(value=50.0)
scale = tk.Scale(root, from_=0, to=100, resolution=0.1,
                 variable=var, orient="horizontal")

def on_change(var_name, idx, op):
    print("current:", var.get())

var.trace("w", on_change)   # fires on every value change
```

**`trace` is covered properly in Lesson 20** — for now, read it as "call this function whenever the slider moves."

## Crash Scene 1: Colouring a ttk Widget With `bg=`

**ttk ignores most classic options:**

```
ttk.Label(root, text="x", bg="red").pack()   # does nothing
```

**ttk widgets are styled through `Style`, not through arguments.**

```
style = ttk.Style()
style.configure("Red.TLabel", foreground="red", background="white")
ttk.Label(root, text="red text", style="Red.TLabel").pack()
```

**The pattern is `configure("SomeName.WidgetClass", ...)` and then `style="SomeName.WidgetClass"`.** It's more verbose than `bg=`, which is why ttk isn't always worth it when you need exact colours.

## Crash Scene 2: Forgetting `values=` on a Combobox

```
cb = ttk.Combobox(root)   # empty dropdown
cb.pack()
```

**The box works but the dropdown is empty.** Always pass `values=[...]`.

## Crash Scene 3: Writing `from` Instead of `from_`

```
sb = tk.Spinbox(root, from=0, to=10)   # SyntaxError
```

**`from` is a reserved word in Python.** The parameter is spelled `from_` with a trailing underscore.

## Crash Scene 4: `orient` vs `orientation`

```
scale = tk.Scale(root, orient="horizontal")        # correct
scale = tk.Scale(root, orientation="horizontal")   # WRONG
```

**The parameter is `orient`, not `orientation`.** They look interchangeable; only one of them works.

## Choosing the Right Widget

| Situation | Use |
|---|---|
| Pick one from a short fixed list | Combobox / OptionMenu |
| Step through consecutive values precisely | Spinbox |
| Pick a value approximately | Scale |
| Many items, with scrolling or search | Listbox |
| On/off or any-number-of | Checkbutton |
| Exactly one of several | Radiobutton |

## Worked Example: A Parameter Panel

**Combobox for mode, Spinbox for quantity, Scale for strength.**

```
import tkinter as tk
import tkinter.ttk as ttk

root = tk.Tk()
root.title("Settings")

tk.Label(root, text="mode:").grid(row=0, column=0, sticky="e")
mode = ttk.Combobox(root, values=["fast", "standard", "fine"], state="readonly")
mode.set("standard")
mode.grid(row=0, column=1, sticky="ew")

tk.Label(root, text="quantity:").grid(row=1, column=0, sticky="e")
count = tk.Spinbox(root, from_=1, to=100, increment=1)
count.grid(row=1, column=1, sticky="ew")

tk.Label(root, text="strength:").grid(row=2, column=0, sticky="e")
power = tk.Scale(root, from_=0, to=100, orient="horizontal")
power.grid(row=2, column=1, sticky="ew")

def show():
    print(f"mode={mode.get()}, qty={count.get()}, power={power.get()}")

ttk.Button(root, text="Confirm", command=show).grid(row=3, column=0, columnspan=2)

root.mainloop()
```

**`sticky="ew"` on the value column makes the widgets stretch with the window.** It's the small touch that separates a demo from an interface.

## Summary

- ttk is themed: `import tkinter.ttk as ttk`; its widgets look native
- **Combobox** — dropdown; `values=` sets options; `state="readonly"` blocks typing
- **Spinbox** — stepped input; `from_`/`to`/`increment` (note the underscore)
- **Scale** — slider; `orient`/`resolution`/`variable`
- ttk colours go through `Style`, never `bg=` or `fg=`
- Read any of them with `widget.get()` or through a bound variable class
