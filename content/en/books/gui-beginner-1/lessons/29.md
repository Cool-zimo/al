# Wiring Up File Reading

> The layout exists, the logic is separate, the bridge method is written. Lesson 29 connects the last piece: picking a file, reading it safely, and pushing the text through `count_stats` and `top_words` to the screen.

## The Full `open_file` Callback

**One callback does four jobs in order: ask for a path, guard against cancel, read the bytes, hand the text to the display method.**

```
def open_file(self):
    path = filedialog.askopenfilename(
        filetypes=[("Text files", "*.txt"), ("All files", "*.*")]
    )
    if not path:
        return
    with open(path, encoding="utf-8") as f:
        text = f.read()
    self.path_label.configure(text=path)
    self._display(text)
```

**`askopenfilename` returns `""` on cancel, so `if not path: return` is the guard.** The `with` block handles closing the file. Once the text is in memory, `self._display(text)` takes over — and because `_display` only expects a string, you could hand it text from anywhere and the rest of the program wouldn't notice.

## Crash Scene 1: Reading the File at the Wrong Moment

```
class TextStatsApp:
    def __init__(self, root):
        ...
        text = self._load_file()   # WRONG: runs at startup, before user picks anything
```

**If you read the file during `__init__`, there's no path yet and the program either errors or reads the wrong thing.** File reading is an action the user triggers, so it belongs in a callback connected to a button or menu item — never in the constructor.

## Where to Put the Text Widget

**The design so far analyses text but never lets the user see or edit it. A `Text` widget in its own frame fixes that.**

```
def _build_editor(self, root):
    editor = tk.Frame(root)
    editor.pack(fill="both", expand=True, padx=5, pady=5)
    self.text_widget = tk.Text(editor, wrap="word")
    self.text_widget.pack(fill="both", expand=True)
```

**`wrap="word"` keeps words intact at line breaks instead of cutting them mid-word.** Expand it with `fill="both", expand=True` so it grows with the window. Now `_display` can also drop the loaded text into this widget before counting it.

## Crash Scene 2: A Stale `text_widget` Reference

```
self._build_editor(root)
self.text_widget.insert("1.0", text)   # WRONG if _build_editor never set self.text_widget
```

**`self.text_widget` only exists if the builder method assigned to it. Forgetting `self.` on the assignment means the attribute is never created, and every later reference raises `AttributeError`.** Assign instance attributes explicitly in the method that builds the widget.

## Updating `_display` to Show the Source

**`_display` should do three visible things: populate the editor, refresh the stat labels, refill the results list.**

```
def _display(self, text):
    self.text_widget.delete("1.0", tk.END)
    self.text_widget.insert("1.0", text)

    stats_dict = stats.count_stats(text)
    mapping = [("chars", "Characters"),
               ("no_spaces", "No spaces"),
               ("words", "Words"),
               ("lines", "Lines")]
    for key, name in mapping:
        self.values[name].configure(text=str(stats_dict[key]))

    self.results.delete(0, tk.END)
    for word, count in stats.top_words(text):
        self.results.insert(tk.END, f"{word}: {count}")
```

**Clear, insert, then count. The order matters: an empty widget is easier to reason about than one still holding the previous file.** And `_display` still takes nothing but a string, so pasting text or loading from a file are now the same operation from this point down.

## A "Save As" Button

**Saving is the mirror image of opening: read from the widget, ask for a destination, write the bytes.**

```
def save_file(self):
    path = filedialog.asksaveasfilename(
        defaultextension=".txt",
        filetypes=[("Text files", "*.txt"), ("All files", "*.*")]
    )
    if not path:
        return
    text = self.text_widget.get("1.0", tk.END)
    with open(path, "w", encoding="utf-8") as f:
        f.write(text)
    self.path_label.configure(text=path)
```

**`get("1.0", tk.END)` includes the trailing newline tkinter adds, which is harmless when writing text back out.** `defaultextension=".txt"` saves the user from creating a file with no type. Guard against cancel first, write second.

## Crash Scene 3: Saving Without an Encoding

```
with open(path, "w") as f:     # WRONG on Windows for some text: UnicodeEncodeError
    f.write(text)
```

**The default encoding on Windows is often not UTF-8, so a file containing characters outside that encoding will refuse to write.** Pin `encoding="utf-8"` on every read and every write. It's one extra argument and it prevents an entire class of bug.

## Adding a Menu for File Operations

**A menu bar is the conventional home for Open and Save, and it costs almost nothing to add.**

```
def _build_menu(self, root):
    menubar = tk.Menu(root, tearoff=False)
    root.config(menu=menubar)

    file_menu = tk.Menu(menubar, tearoff=False)
    file_menu.add_command(label="Open...", command=self.open_file)
    file_menu.add_command(label="Save as...", command=self.save_file)
    file_menu.add_separator()
    file_menu.add_command(label="Quit", command=root.destroy)
    menubar.add_cascade(label="File", menu=file_menu)
```

**`root.config(menu=menubar)` is the one line that puts the bar on screen — don't omit it.** The menu items point at the same callbacks the buttons use, so nothing is duplicated. This is the payoff for keeping `open_file` and `save_file` as plain methods: any widget can call them.

## Crash Scene 4: Forgetting to Store the Result of `askopenfilename`

```
filedialog.askopenfilename()    # WRONG: the path is returned and immediately discarded
with open(path) as f:           # NameError: path not defined
```

**The dialog doesn't set a global variable and doesn't remember anything for you. Its return value is the only way to get the path, so assign it.** This is a variation on "guard against cancel", and it's the most common filedialog bug after forgetting `filetypes`.

## Putting It Together: The Complete Tool

**Here's the whole program in one file, with file IO and logic separation intact.**

```
import tkinter as tk
from tkinter import filedialog
import stats

class TextStatsApp:
    def __init__(self, root):
        root.title("Text Stats")
        root.geometry("520x400")

        self._build_menu(root)
        self._build_top(root)
        self._build_editor(root)
        self._build_stats(root)
        self._build_results(root)

    def _build_menu(self, root):
        menubar = tk.Menu(root, tearoff=False)
        root.config(menu=menubar)
        file_menu = tk.Menu(menubar, tearoff=False)
        file_menu.add_command(label="Open...", command=self.open_file)
        file_menu.add_command(label="Save as...", command=self.save_file)
        file_menu.add_separator()
        file_menu.add_command(label="Quit", command=root.destroy)
        menubar.add_cascade(label="File", menu=file_menu)

    def _build_top(self, root):
        top = tk.Frame(root)
        top.pack(fill="x")
        tk.Button(top, text="Analyse text", command=self._analyse_current).pack(side="left", padx=5, pady=5)
        self.path_label = tk.Label(top, text="(no file)", fg="gray")
        self.path_label.pack(side="left", padx=5)

    def _build_editor(self, root):
        editor = tk.Frame(root)
        editor.pack(fill="both", expand=True, padx=5, pady=5)
        self.text_widget = tk.Text(editor, wrap="word")
        self.text_widget.pack(fill="both", expand=True)

    def _build_stats(self, root):
        frame = tk.Frame(root)
        frame.pack(fill="x", padx=5, pady=5)
        self.values = {}
        for i, name in enumerate(["Characters", "No spaces", "Words", "Lines"]):
            tk.Label(frame, text=name + ":").grid(row=i, column=0, sticky="w", padx=4)
            vl = tk.Label(frame, text="0")
            vl.grid(row=i, column=1, sticky="w", padx=4)
            self.values[name] = vl

    def _build_results(self, root):
        self.results = tk.Listbox(root)
        self.results.pack(fill="both", expand=True, padx=5, pady=5)

    def open_file(self):
        path = filedialog.askopenfilename(
            filetypes=[("Text files", "*.txt"), ("All files", "*.*")]
        )
        if not path:
            return
        with open(path, encoding="utf-8") as f:
            text = f.read()
        self.path_label.configure(text=path)
        self._display(text)

    def save_file(self):
        path = filedialog.asksaveasfilename(
            defaultextension=".txt",
            filetypes=[("Text files", "*.txt"), ("All files", "*.*")]
        )
        if not path:
            return
        text = self.text_widget.get("1.0", tk.END)
        with open(path, "w", encoding="utf-8") as f:
            f.write(text)
        self.path_label.configure(text=path)

    def _analyse_current(self):
        text = self.text_widget.get("1.0", tk.END)
        self._display(text)

    def _display(self, text):
        self.text_widget.delete("1.0", tk.END)
        self.text_widget.insert("1.0", text)
        sd = stats.count_stats(text)
        for key, name in [("chars", "Characters"), ("no_spaces", "No spaces"),
                          ("words", "Words"), ("lines", "Lines")]:
            self.values[name].configure(text=str(sd[key]))
        self.results.delete(0, tk.END)
        for word, count in stats.top_words(text):
            self.results.insert(tk.END, f"{word}: {count}")

root = tk.Tk()
TextStatsApp(root)
root.mainloop()
```

**Five builder methods, four actions, one bridge. Every line has one clear owner.** Lesson 30 adds the error handling that turns this from a demo into something you can give to another person.

## Summary

- `open_file` asks for a path, guards against cancel, reads with UTF-8, then calls `_display`
- Never read a file inside `__init__` — wait for a user action
- `Text(wrap="word")` keeps words whole at line breaks; always keep a reference on `self`
- `_display` clears, inserts, then counts; it takes a plain string so any source works
- `asksaveasfilename` with `defaultextension=".txt"` handles the destination side
- Pin `encoding="utf-8"` on reads and writes; store the dialog's return value
