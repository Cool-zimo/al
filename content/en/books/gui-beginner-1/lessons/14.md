# Listbox and Scrollbar

> Once your options outgrow a handful of Radiobuttons, you need a list. This lesson covers Listbox (add items, read the selection, multi-select) and Scrollbar — including the two-way binding that everyone gets wrong the first time.

## Listbox: A Scrollable List of Options

**Listbox shows a list of items the user can pick from, one or many at a time.**

```
import tkinter as tk

root = tk.Tk()
root.title("Listbox")

lb = tk.Listbox(root)
lb.pack(padx=10, pady=10)

for city in ["Beijing", "Shanghai", "Guangzhou", "Shenzhen", "Hangzhou"]:
    lb.insert("end", city)

root.mainloop()
```

**`insert(index, item)` adds an item; `"end"` means append.** Five cities, five rows, click any of them.

**The arguments you'll use most:**

| Argument | What it does |
|---|---|
| `selectmode` | `"browse"` single (default) / `"single"` / `"multiple"` / `"extended"` multi-select |
| `height` | How many rows are visible |
| `width` | Width in characters |
| `fg` / `bg` | Text / background colours |
| `selectbackground` / `selectforeground` | The selection's colours |

## Reading the Selection

**`curselection()` returns a tuple of selected indexes, counting from 0.**

```
def show():
    sel = lb.curselection()
    if sel:
        idx = sel[0]
        print("selected:", lb.get(idx))
    else:
        print("nothing selected")

tk.Button(root, text="Show", command=show).pack()
```

**In multi-select mode, `curselection()` returns several indexes:**

```
lb = tk.Listbox(root, selectmode="extended")
# user holds Ctrl and clicks three rows
sel = lb.curselection()   # (0, 2, 4)
for idx in sel:
    print(lb.get(idx))
```

## Adding, Removing, and Replacing

| Method | Purpose |
|---|---|
| `insert(idx, *items)` | Insert at `idx` (`"end"` = tail) |
| `delete(first, last=None)` | Delete one item or a range |
| `get(first, last=None)` | Read one item or a range |
| `size()` | Total number of items |
| `curselection()` | Tuple of selected indexes |
| `selection_set(first, last=None)` | Select items from code |
| `selection_clear(first, last=None)` | Deselect items |
| `activate(idx)` | Highlight an item |

## Selecting and Deselecting From Code

```
lb.selection_set(0)          # select the first item
lb.selection_set(0, "end")   # select everything
lb.selection_clear(0, "end") # select nothing
lb.activate(2)               # highlight the third item
```

**`selection_set` and `selection_clear` are Listbox-specific — note the names.** They are not `select`/`deselect`; those belong to Checkbutton.

## Scrollbar: The Two-Way Binding

**A long list needs a scrollbar. The catch is that the connection goes in both directions.**

```
import tkinter as tk

root = tk.Tk()

scrollbar = tk.Scrollbar(root)
scrollbar.pack(side="right", fill="y")

lb = tk.Listbox(root, yscrollcommand=scrollbar.set)
lb.pack(side="left", fill="both", expand=True)

for i in range(50):
    lb.insert("end", f"line {i}")

scrollbar.config(command=lb.yview)

root.mainloop()
```

**Two connections, one in each direction:**

1. `yscrollcommand=scrollbar.set` — when the list scrolls, tell the scrollbar where its thumb should be
2. `scrollbar.config(command=lb.yview)` — when the user drags the scrollbar, tell the list to scroll

**Miss either line and the pairing is half-broken.** This is the single most common Listbox bug.

## Crash Scene 1: Only One Direction Is Wired

```
scrollbar.config(command=lb.yview)
# yscrollcommand=scrollbar.set is missing
```

**Symptom: dragging the scrollbar moves the list, but using the mouse wheel on the list doesn't move the thumb.** It looks broken because it is — partially. Add the missing line.

## Crash Scene 2: Making the Scrollbar a Child of the Listbox

**Scrollbar and Listbox are siblings, not parent and child.**

```
# correct: scrollbar and lb sit side by side in root
scrollbar.pack(side="right", fill="y")
lb.pack(side="left", fill="both", expand=True)

# wrong: the scrollbar is packed inside the listbox
lb = tk.Listbox(root)
lb.pack()
tk.Scrollbar(lb).pack()   # wrong! pack it in root, not in lb
```

**Both widgets belong to `root` (or to the same container) and get their own `pack`/`grid` call.** Thinking of them as parent-child is the mistake; they're peers.

## Horizontal Scrolling

**`xscrollcommand` and `xview` handle left-right scrolling.**

```
h_sb = tk.Scrollbar(root, orient="horizontal")
h_sb.pack(side="bottom", fill="x")

lb = tk.Listbox(root, xscrollcommand=h_sb.set)
lb.pack(side="bottom", fill="x")

h_sb.config(command=lb.xview)
```

**Horizontal scrolling on a Listbox only shows up with a narrow width and very long items.** It's far more useful on Text and Canvas, which is where you'll reach for it later.

## Listbox Selection Modes

```
# single selection (default)
lb = tk.Listbox(root, selectmode="browse")

# shift-click and drag to select a range
lb = tk.Listbox(root, selectmode="extended")

# ctrl-click to pick several independent rows
lb = tk.Listbox(root, selectmode="multiple")

# strict single-select, cannot be deselected
lb = tk.Listbox(root, selectmode="single")
```

**`"extended"` is the one users expect from a file manager** — shift for ranges, ctrl for individual picks.

## Listbox Events: Double-Click and Live Selection

**`<Double-1>` fires on a double-click; `<<ListboxSelect>>` fires the moment the selection changes.**

```
def on_double(event):
    sel = lb.curselection()
    if sel:
        print("double-clicked:", lb.get(sel[0]))

lb.bind("<Double-1>", on_double)
```

```
def on_select(event):
    sel = lb.curselection()
    if sel:
        label.configure(text=lb.get(sel[0]))

lb.bind("<<ListboxSelect>>", on_select)
```

**`<<ListboxSelect>>` is a virtual event** — the double-angle-bracket form is tkinter's way of naming events that aren't raw mouse or keyboard input. Lesson 18 covers `bind` in full.

## Crash Scene 3: `curselection()` Returns an Empty Tuple

```
sel = lb.curselection()
print(lb.get(sel[0]))   # IndexError if nothing is selected
```

**With no selection, `curselection()` is `()` and `sel[0]` blows up.** Always test the tuple first:

```
sel = lb.curselection()
if sel:
    print(lb.get(sel[0]))
else:
    print("pick something first")
```

## Crash Scene 4: Forgetting `insert` and `delete` Indexes

```
lb.insert(0, "new item")   # shifts existing items down
lb.delete(0)               # remove the first item
lb.delete(0, "end")        # clear everything
```

**`insert(0, ...)` puts the new item at the top.** For "clear all", `delete(0, "end")` is the line to remember.

## Worked Example: A To-Do List

**An Entry to type into, a Listbox to hold items, buttons to add and remove.**

```
import tkinter as tk

root = tk.Tk()
root.title("To-Do List")

entry = tk.Entry(root)
entry.pack(padx=10, pady=5)

lb = tk.Listbox(root)
lb.pack(padx=10, fill="both", expand=True)

scrollbar = tk.Scrollbar(root, command=lb.yview)
scrollbar.pack(side="right", fill="y")
lb.config(yscrollcommand=scrollbar.set)

def add():
    t = entry.get().strip()
    if t:
        lb.insert("end", t)
        entry.delete(0, "end")

def remove():
    sel = lb.curselection()
    if sel:
        lb.delete(sel[0])

tk.Button(root, text="Add", command=add).pack(side="left", padx=10)
tk.Button(root, text="Remove", command=remove).pack(side="left")

root.mainloop()
```

**Type, click Add, watch it land in the list. Select, click Remove, watch it go.** It's a real application in twenty lines.

## Summary

- Listbox shows a list; `insert("end", item)` appends
- `curselection()` returns selected indexes — **always check for empty first**
- `selectmode` picks single vs multi: `browse` / `extended` / `multiple`
- Scrollbar needs **two wires**: `yscrollcommand=sb.set` and `sb.config(command=lb.yview)`
- Scrollbar and Listbox are **siblings**, each packed separately
- `<<ListboxSelect>>` reports selection changes as they happen
