# grid: Rows and Columns, rowspan/colspan, and sticky

> grid is tkinter's most commonly used and most flexible geometry manager. This lesson covers it thoroughly: rows and columns, spanning rows and columns, sticking to edges, and margins. Master grid and you can build 80% of any interface.

## The Basic Idea of grid

**grid treats the parent as a table.** Each widget specifies which cell it occupies using `row` and `column`, both starting from 0.

```
import tkinter as tk

root = tk.Tk()
tk.Label(root, text="Name").grid(row=0, column=0)
tk.Entry(root).grid(row=0, column=1)
tk.Label(root, text="Age").grid(row=1, column=0)
tk.Entry(root).grid(row=1, column=1)
root.mainloop()
```

**The result is a tidy two-row, two-column form.** The labels sit in the left column, the input boxes in the right column, and the two columns align vertically.

**This is grid's core value: alignment.** pack cannot align columns; grid supports it natively.

## row / column Need Not Be Sequential

**You can skip row and column numbers rather than using 0, 1, 2 in sequence:**

```
tk.Label(root, text="Skip").grid(row=0, column=0)
tk.Label(root, text="Row 5").grid(row=5, column=0)   # rows 1-4 left empty
```

**Empty rows still occupy space (very little, but it is there).** In practice you usually lay things out in order; skipping numbers is mainly useful for "reserving an area."

## rowspan / columnspan: Spanning Rows and Columns

**A widget can occupy more than one cell.**

**`columnspan=2` means "occupy two columns horizontally":**

```
tk.Label(root, text="Heading").grid(row=0, column=0, columnspan=2)
tk.Label(root, text="Name").grid(row=1, column=0)
tk.Entry(root).grid(row=1, column=1)
```

**"Heading" spans both columns, behaving like a table header.**

**`rowspan` means "span rows vertically":**

```
tk.Label(root, text="Sidebar", width=8, bg="lightyellow").grid(row=0, column=0, rowspan=3)
tk.Label(root, text="Content 1").grid(row=0, column=1)
tk.Label(root, text="Content 2").grid(row=1, column=1)
tk.Label(root, text="Content 3").grid(row=2, column=1)
```

**"Sidebar" spans 3 rows, acting like a side panel.**

## sticky: Which Side of the Cell to Hug

**`sticky` decides which direction the widget hugs inside its cell and whether it fills the cell.**

| Value | Effect |
|---|---|
| `""` (default) | Centered, natural size |
| `"w"` | Hug the left side |
| `"e"` | Hug the right side |
| `"n"` | Hug the top |
| `"s"` | Hug the bottom |
| `"ew"` | Fill horizontally |
| `"ns"` | Fill vertically |
| `"nsew"` | Fill in all four directions |

```
tk.Label(root, text="Left hug", bg="red").grid(row=0, column=0, sticky="w")
tk.Label(root, text="Right hug", bg="green").grid(row=0, column=1, sticky="e")
tk.Label(root, text="Fill", bg="blue").grid(row=1, column=0, columnspan=2, sticky="ew")
```

**`sticky` is the most underrated argument.** A centered Label looks strange when its cell grows because it shrinks into the middle; `sticky="w"` left-aligns it and `sticky="ew"` makes it fill horizontally.

## padx / pady: External Margins Inside Cells

**Like pack, grid supports `padx`/`pady`:**

```
tk.Label(root, text="With margin").grid(row=0, column=0, padx=10, pady=5)
```

**`padx=(left, right)` and `pady=(top, bottom)` are also supported.**

**For forms, a little right margin on the labels and some row spacing makes everything look comfortable:**

```
tk.Label(root, text="Name:").grid(row=0, column=0, sticky="e", padx=5, pady=5)
tk.Entry(root).grid(row=0, column=1, padx=5, pady=5)
tk.Label(root, text="Age:").grid(row=1, column=0, sticky="e", padx=5, pady=5)
tk.Entry(root).grid(row=1, column=1, padx=5, pady=5)
```

## A Complete Calculator Interface

**grid is ideal for a calculator keypad — it is a natural grid:**

```
import tkinter as tk

root = tk.Tk()
root.title("Calculator")

# Display area
tk.Entry(root, justify="right", font=("Arial", 20)).grid(row=0, column=0, columnspan=4, sticky="ew", padx=5, pady=5)

# Buttons
buttons = [
    "7", "8", "9", "/",
    "4", "5", "6", "*",
    "1", "2", "3", "-",
    "0", ".", "=", "+",
]
row, col = 1, 0
for b in buttons:
    tk.Button(root, text=b, width=5, height=2).grid(row=row, column=col, padx=2, pady=2)
    col += 1
    if col > 3:
        col = 0
        row += 1

root.mainloop()
```

**The four columns of buttons form a matrix, and the display area uses `columnspan=4` to span all columns.** This is where grid shines.

## Crash Scene 1: The Cell Never "Opens Up"

```
tk.Label(root, text="A very long piece of text content").grid(row=0, column=0)
tk.Entry(root).grid(row=0, column=1)
```

**The window is wide, yet the Label shrinks in the middle, the Entry shrinks in the middle, and huge gaps open up on both sides.** They were never asked to fill their cells.

**Fix:** give the widgets `sticky="ew"`. But that is not enough on its own — you must also tell grid "this column should grow with the window," which requires `columnconfigure` (covered in the next lesson).

## Crash Scene 2: Forgetting to Check the Column When It Exceeds the Range

**When generating grid widgets with a loop, an incorrect `column` sends a widget somewhere unexpected:**

```
for i, t in enumerate(["A", "B", "C", "D", "E"]):
    tk.Label(root, text=t).grid(row=0, column=i)
```

**The five labels are crammed into row 0, columns 0-4.** If you want "a new row after every 3," write:

```
for i, t in enumerate(["A","B","C","D","E","F"]):
    tk.Label(root, text=t).grid(row=i//3, column=i%3)
```

**`i//3` is the row number and `i%3` is the column number (0-2).** This is a very useful trick.

## Crash Scene 3: Misalignment After rowspan

**When spanning rows/columns, a cell that is "covered" cannot hold another widget:**

```
label = tk.Label(root, text="Sidebar")
label.grid(row=0, column=0, rowspan=2)   # occupies (0,0) and (1,0)

tk.Label(root, text="Misplaced").grid(row=1, column=0)   # (1,0) is already taken!
```

**Symptoms:** widgets render incorrectly, overlap, or raise `cannot place child, slave is already managed`.

**Fix:** do not grid a widget into a cell already consumed by rowspan/columnspan.

## Crash Scene 4: Mixing grid and pack

**Calling both grid and pack on the same parent raises an error immediately** (covered in Lesson 6). Remember: **one parent, one manager.**

## ipadx / ipady with grid

**grid supports internal padding too:**

```
tk.Button(root, text="Big button").grid(row=0, column=0, ipadx=10, ipady=5)
```

**The widget itself grows** — useful for "emphasis" buttons.

## A Small Trick: grid's `in_` Argument

**`in_` can specify the parent (rarely used, but useful to know):**

```
frame = tk.Frame(root)
frame.pack()
tk.Label(in_=frame, text="I am inside the frame").grid()   # without in_, the default is root
```

**`in_` is generally unnecessary; passing the parent as the first argument is clearer:**

```
tk.Label(frame, text="I am inside the frame").grid()
```

## The Universal grid Formula

**This standard form template is all you really need to remember:**

```
# Label right-aligned + Entry fills
tk.Label(root, text="Field name:").grid(row=N, column=0, sticky="e", padx=5, pady=5)
tk.Entry(root).grid(row=N, column=1, sticky="ew", padx=5, pady=5)

# Button spans the full row
tk.Button(root, text="Submit").grid(row=LAST, column=0, columnspan=2, sticky="ew", pady=10)
```

**Label `sticky="e"` right-aligned, Entry `sticky="ew"` filling, button with `columnspan` spanning columns — remember these three patterns and you can lay out most forms.**

## Summary

- grid treats the parent as a table; `row`/`column` specify the cell (starting at 0)
- `rowspan`/`columnspan` span multiple rows/columns, useful for sidebars, headers, and spanning buttons
- `sticky` controls which side to hug: `"w"` left, `"ew"` fills horizontally, `"nsew"` fills everything
- `padx`/`pady` margins make forms look clean
- For grid generated in a loop, use `row=i//cols, column=i%cols`
- One parent can only use one geometry manager
