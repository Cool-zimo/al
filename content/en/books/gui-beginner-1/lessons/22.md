# Opening and Saving Files: `filedialog`

> A text editor that can't open a file isn't an editor. `tkinter.filedialog` gives you the same "open file" and "save as" windows you've seen in every desktop program — the user navigates folders, picks a file, and your code gets a path string back.

## What the Dialog Returns

**`askopenfilename` shows the standard Open dialog and returns the full path the user chose, or an empty string if they cancelled.** That string is all you need to read the file with Python's normal file tools.

```
import tkinter as tk
from tkinter import filedialog

root = tk.Tk()

def open_file():
    path = filedialog.askopenfilename()
    print(repr(path))      # e.g. '/home/user/notes.txt'  or  ''

tk.Button(root, text="Open...", command=open_file).pack()

root.mainloop()
```

**Click Open, browse to a file, click OK, and the path lands in your variable.** Cancel or close the dialog and you get `''`. That empty string is your signal that nothing was chosen, so check for it before you try to open anything.

## Reading the File After the User Picks It

**The dialog only picks the path; opening and reading the file is still your job.**

```
import tkinter as tk
from tkinter import filedialog

root = tk.Tk()

text = tk.Text(root, width=50, height=15)
text.pack()

def open_file():
    path = filedialog.askopenfilename()
    if not path:
        return
    with open(path, encoding="utf-8") as f:
        content = f.read()
    text.delete("1.0", tk.END)
    text.insert("1.0", content)

tk.Button(root, text="Open...", command=open_file).pack()

root.mainloop()
```

**`Text.delete("1.0", tk.END)` clears the widget first so you don't paste new content on top of the old.** Then `insert("1.0", ...)` puts the fresh text at the very start. That two-step clear-and-insert is the standard way to reload a Text widget.

## Crash Scene 1: Forgetting to Handle Cancel

```
def open_file():
    path = filedialog.askopenfilename()
    with open(path) as f:        # WRONG: crashes when user cancels
        ...
```

**When the user cancels, `path` is `''`. Passing that to `open()` raises `FileNotFoundError`** — a confusing error for the user, who thought they were just closing the dialog. Guard with `if not path: return`.

## Filtering File Types with `filetypes`

**`filetypes` decides which files appear in the dialog's dropdown.** It's a list of `(label, pattern)` tuples, and pattern can be a string or a tuple of extensions.

```
path = filedialog.askopenfilename(
    filetypes=[
        ("Text files", "*.txt"),
        ("Python files", "*.py"),
        ("All files", "*.*"),
    ]
)
```

**The first tuple in the list is the default choice shown in the dropdown.** `"*.txt"` matches only files ending in `.txt`; `"*.*"` matches everything. You can also group several extensions under one label:

```
("Images", "*.png *.jpg *.gif")
```

**On the save side, `asksaveasfilename` works the same way but warns about overwriting.** If the user picks an existing file, the dialog itself asks "replace this file?" before returning the path, so you don't have to write that check yourself.

## Crash Scene 2: Forgetting the Dot in the Extension

```
filetypes=[("Text files", "txt")]    # WRONG: matches a file literally named "txt"
```

**Without the leading `*.` you're not writing a glob pattern — you're asking for files whose full name is `txt`.** The dialog will look empty. Always write `"*.txt"`, `"*.py"`, etc.

## Setting a Starting Folder with `initialdir`

**`initialdir` drops the user into a sensible folder instead of wherever the OS feels like.**

```
import os

path = filedialog.askopenfilename(
    initialdir=os.path.expanduser("~"),
    filetypes=[("Text files", "*.txt"), ("All files", "*.*")],
)
```

**`os.path.expanduser("~")` resolves to the current user's home directory on every OS.** It's much friendlier than starting in the program's install folder or some random recent location. You can also remember the last folder the user visited and pass it back in next time.

## The Save Flow

**Saving needs two pieces: the dialog to pick a destination, and your own code to actually write the bytes.**

```
def save_file():
    path = filedialog.asksaveasfilename(
        defaultextension=".txt",
        filetypes=[("Text files", "*.txt"), ("All files", "*.*")],
    )
    if not path:
        return
    content = text.get("1.0", tk.END)
    with open(path, "w", encoding="utf-8") as f:
        f.write(content)
```

**`defaultextension=".txt"` quietly appends `.txt` if the user types a name with no extension.** Without it a user who types `notes` ends up with a file literally called `notes` and no type. It's a small touch that prevents confusion later.

## Crash Scene 3: Reading a File the OS Decoded Wrong

```
with open(path) as f:          # WRONG on Windows for many files: UnicodeDecodeError
    content = f.read()
```

**The default encoding on Windows is often not UTF-8, so a file written on a Mac or Linux can blow up your read.** Pin `encoding="utf-8"` (and add `errors="replace"` if you want to be defensive about truly unknown data). The same goes for writing.

## Putting It Together: A Tiny Notepad

**Here's the complete open/save skeleton you'll build on in later lessons.**

```
import tkinter as tk
from tkinter import filedialog

root = tk.Tk()
root.title("Tiny Notepad")

text = tk.Text(root, wrap="word")
text.pack(fill="both", expand=True)

def open_file():
    path = filedialog.askopenfilename(filetypes=[("Text files", "*.txt"), ("All files", "*.*")])
    if not path:
        return
    with open(path, encoding="utf-8") as f:
        text.delete("1.0", tk.END)
        text.insert("1.0", f.read())

def save_file():
    path = filedialog.asksaveasfilename(defaultextension=".txt",
                                        filetypes=[("Text files", "*.txt"), ("All files", "*.*")])
    if not path:
        return
    with open(path, "w", encoding="utf-8") as f:
        f.write(text.get("1.0", tk.END))

tk.Button(root, text="Open", command=open_file).pack(side="left")
tk.Button(root, text="Save", command=save_file).pack(side="left")

root.mainloop()
```

**Notice the order: the dialog returns a string, you decide what to do with it, then you update the widget.** The dialog never touches your Text widget directly — that separation stays true throughout this book.

## Summary

- `askopenfilename` returns a path string, or `''` when the user cancels
- Always check `if not path: return` before opening
- `filetypes` is a list of `(label, "*.ext")` tuples; the first is the default
- `asksaveasfilename` warns on overwrite and supports `defaultextension`
- `initialdir` sets where the dialog starts; `os.path.expanduser("~")` is a safe pick
- Pin `encoding="utf-8"` on both reads and writes
