# Text: The Multiline Widget — `insert`, `get`, `delete`

> Entry handles one line. The moment you need a chat log, a code editor, or a paragraph of notes, you need Text. This lesson covers Text's quirky index system (why `"1.0"`?), how to read and write it, and how to make a read-only "log window" with coloured output.

## What Text Actually Is

**Text is a multiline editing widget — the big blank area in Notepad is a Text.**

```
import tkinter as tk

root = tk.Tk()
root.title("Multiline Text")

text = tk.Text(root, width=40, height=10)
text.pack(padx=10, pady=10)

root.mainloop()
```

It looks like a taller Entry, but the similarity ends there. Text manages paragraphs, wrapping, selection, and styles all on its own.

**The arguments you'll reach for most:**

| Argument | What it does |
|---|---|
| `width` / `height` | Width in characters / height in lines |
| `wrap` | How to wrap long lines: `"none"` / `"char"` / `"word"` |
| `state` | `"normal"` editable / `"disabled"` read-only |
| `fg` / `bg` | Text colour / background colour |
| `font` | The font for the body text |
| `spacing1` / `spacing2` / `spacing3` | Space above a line / within wrapped lines / below a line |

**`wrap="word"` wraps on word boundaries, not in the middle of a word.** For Chinese text it wraps on character boundaries. It's almost always the right choice.

## `"1.0"`: Text's Index System Explained

**This is the single most confusing thing about Text: positions are written `"line.column"`, lines start at 1, columns start at 0.**

```
"1.0"   -> line 1, column 0   (the very first character)
"1.5"   -> line 1, column 5
"2.0"   -> the start of line 2
"end"   -> the very end of the document
```

**Why does the line count start at 1 but the column at 0?** Blame Tcl/Tk, tkinter's underlying library — that's just how it was designed in the 1990s. Don't fight it; learn the rule.

**Try it yourself:**

```
text.insert("1.0", "Hello World")
print(text.get("1.0", "1.5"))   # "Hello"
```

The slice goes from column 0 up to, but not including, column 5 — the same half-open logic Python uses for slicing.

## `insert`: Putting Text In

**`insert(index, string)` drops text at the given index.**

```
text.insert("1.0", "line one\n")       # at the start of line 1
text.insert("end", "appended line\n")  # at the very end
text.insert("2.0", "line two's start")
```

**`"end"` is the position you'll use most — append, append, append.**

## `get`: Reading What's Inside

**`get(start, end)` returns the slice as a plain string.**

```
all_text = text.get("1.0", "end")   # everything
line1    = text.get("1.0", "1.end") # line 1, up to and including its newline
```

**Crash Scene: `get("1.0", "end")` always ends with a stray newline.**

```
text.insert("1.0", "hello")
print(repr(text.get("1.0", "end")))   # 'hello\n'
```

**Text keeps a trailing newline around at all times.** Compare content and you'll be off by one; strip it:

```
content = text.get("1.0", "end").strip()
```

That `.strip()` is the difference between a bug and a working compare.

## `delete`: Erasing

**`delete(start, end)` removes everything in that range.**

```
text.delete("1.0", "1.end")   # wipe line 1
text.delete("1.0", "end")     # wipe everything
```

**The canonical "clear the Text widget" line is `text.delete("1.0", "end")`.** Write it once, memorise it, move on.

## Index Constants Worth Knowing

**Beyond `"1.0"` and `"end"`, these four come up constantly:**

| Constant | Meaning |
|---|---|
| `"1.0"` | Start of the document |
| `"end"` | End of the document |
| `"insert"` | The current cursor position |
| `"sel.first"` / `"sel.last"` | The active selection's endpoints (errors if nothing is selected) |
| `"@x,y"` | The character at pixel position (x, y) — used with mouse events |

**`"insert"` is how you insert at the blinking cursor** instead of a fixed position:

```
text.insert("insert", "typed right here")
```

## Read-Only Text: Building a Log Window

**You often want the program to write to a Text while the user just reads along — a log, a transcript, a chat history.**

```
text = tk.Text(root, state="disabled")
text.insert("1.0", "log entry\n")
# TclError: text is disabled
```

**Disabled Text rejects every modification.** The right pattern is the same toggle dance as Entry: flip to normal, write, flip back.

```
def append_log(msg):
    text.configure(state="normal")
    text.insert("end", msg + "\n")
    text.configure(state="disabled")

append_log("program started")
append_log("user logged in")
```

**This is the standard "log display" idiom in tkinter.** Anywhere you want read-only scrolling output, this is the shape of the code.

## Colouring Text with Tags

**Tags mark a region of text and give it a style. This is the seed of a code editor.**

```
text = tk.Text(root)
text.pack()

text.insert("1.0", "this line is red\nthis line is blue")

text.tag_add("red", "1.0", "1.end")          # mark the whole first line
text.tag_config("red", foreground="red",
                       font=("Arial", 12, "bold"))

text.tag_add("blue", "2.0", "2.end")         # mark the whole second line
text.tag_config("blue", foreground="blue")
```

**`tag_add(name, start, end)` draws the boundary; `tag_config` fills in the style.** A single region can carry several tags, each controlling a different property — foreground, background, font, underline, offset — independently.

**You can edit the style after the fact and all tagged text updates live:**

```
text.tag_config("red", foreground="dark red")   # every "red" region changes
```

## Crash Scene 1: Writing `"0.0"` Instead of `"1.0"`

```
text.insert("0.0", "x")   # TclError: bad text index "0.0"
```

**Lines start at 1, columns at 0.** `"0.0"` is not a valid index — there is no line zero.

## Crash Scene 2: Assuming `get` Strips the Trailing Newline

```
text.insert("1.0", "hi")
print(text.get("1.0", "end"))   # 'hi\n'
```

**It doesn't.** That `\n` is permanent until you `.strip()` it. Comparisons, hashing, sending-to-network — all of them need the strip.

## Crash Scene 3: Inserting Into a Disabled Text

```
text = tk.Text(root, state="disabled")
text.insert("1.0", "x")   # TclError: text is disabled
```

**`configure(state="normal")` first, then write.** This is the number one Text error, and it hits everyone at least once.

## Crash Scene 4: Reading the Selection When Nothing Is Selected

```
sel = text.get("sel.first", "sel.last")   # explodes if no selection
```

**`"sel.first"` only exists when the user has actually highlighted something.** Guard it:

```
try:
    sel = text.get("sel.first", "sel.last")
except tk.TclError:
    sel = ""   # nothing selected
```

## Text Method Cheat Sheet

| Method | Purpose |
|---|---|
| `insert(idx, s)` | Insert text |
| `get(a, b)` | Read a range |
| `delete(a, b)` | Delete a range |
| `see(idx)` | Scroll until the index is visible |
| `index(idx)` | Normalise an index into `"line.column"` |
| `compare(a, op, b)` | Compare two positions with `<`, `<=`, `==`, etc. |
| `search(pattern, start, stopindex=...)` | Find a pattern |
| `replace(a, b, s)` | Replace a range |
| `tag_add(name, a, b)` | Add a tag to a region |
| `tag_config(name, **opts)` | Style a tag |
| `tag_remove(name, a, b)` | Remove a tag from a region |

## Worked Example: A Character Counter

**A Button, a Text, and a Label — click to count.**

```
import tkinter as tk

root = tk.Tk()
root.title("Character Counter")

text = tk.Text(root, height=10, wrap="word")
text.pack(padx=10, pady=10)

label = tk.Label(root, text="characters: 0")

def count():
    content = text.get("1.0", "end")
    n = len(content) - 1        # ignore the trailing newline
    label.configure(text=f"characters: {n}")

tk.Button(root, text="Count", command=count).pack()
label.pack()

root.mainloop()
```

**The `- 1` is doing real work.** Lesson 20 shows how to make this count update as you type, with no button at all.

## A Complete Example: Editor Skeleton

**Toolbar, editing area, status bar — the Notepad layout in a dozen lines.**

```
import tkinter as tk

root = tk.Tk()
root.title("Mini Editor")

toolbar = tk.Frame(root)
toolbar.pack(fill="x")
tk.Button(toolbar, text="Clear").pack(side="left")
tk.Button(toolbar, text="Count").pack(side="left")

text = tk.Text(root, wrap="word")
text.pack(expand=True, fill="both")

status = tk.Label(root, text="ready", anchor="w")
status.pack(fill="x")

root.mainloop()
```

**`expand=True, fill="both"` on the Text is what lets it grow with the window.** Without it, resizing the window leaves the editor pinned at its starting size.

## Summary

- Text is **multiline**; Entry holds one line only
- Index format is `"line.column"`: lines from 1, columns from 0; `"end"` is the tail
- `insert(idx, s)` / `get(a, b)` / `delete(a, b)`
- `get("1.0", "end")` always carries a trailing `\n` — call `.strip()` for comparisons
- For read-only output, disable first, then toggle normal around every write
- `tag_add` + `tag_config` colour and style regions of text
