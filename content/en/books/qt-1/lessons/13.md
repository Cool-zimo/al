# QComboBox, QCheckBox, and QRadioButton

> Dropdown lists, checkboxes, and radio buttons — these are the three workhorses of selection widgets. Their common thread is "pick one or several values", but their interaction differs: dropdowns save space, checkboxes allow multiple selections, and radio buttons enforce a single choice. This lesson covers all three, with emphasis on grouping radio buttons correctly.

## QComboBox: The Dropdown

**QComboBox is a dropdown — click to expand a list.**

```
from PySide6.QtWidgets import QComboBox

combo = QComboBox()
combo.addItem("Beijing")
combo.addItem("Shanghai")
combo.addItem("Guangzhou")
combo.addItem("Shenzhen")

combo.setCurrentIndex(1)        # default to "Shanghai" (index 1)
print(combo.currentIndex())     # current index: 1
print(combo.currentText())      # current text: "Shanghai"
```

**`addItem(text)` adds an option; `currentIndex()` reads the index; `currentText()` reads the text.**

**`addItems(list)` adds multiple at once:**

```
cities = ["Beijing", "Shanghai", "Guangzhou", "Shenzhen", "Hangzhou", "Chengdu"]
combo.addItems(cities)
```

**`currentIndexChanged` has two overloads: one with int, one with str:**

```
combo.currentIndexChanged.connect(lambda index: print("Index changed:", index))
```

**Note: currentIndexChanged emits int (the new index) by default.** To get the text, call `combo.currentText()` inside the slot.

**`currentTextChanged` emits the text directly:**

```
combo.currentTextChanged.connect(lambda text: print("Selected:", text))
```

**For "update other widgets after selecting a city", currentTextChanged is more convenient.**

## Crash Site 1: Judging by index — breaks when options are reordered

**Symptom: the code hardcodes `if index == 1:` for Shanghai, but someone inserts "Nationwide" at the top — every判断 breaks.**

```
combo.addItems(["Nationwide", "Beijing", "Shanghai", "Guangzhou"])   # after insertion, Shanghai is index 2
combo.currentIndexChanged.connect(lambda i: print("Shanghai" if i == 1 else "Other"))
# selecting Shanghai prints "Other" because Shanghai is now index 2
```

**Fix: use `currentText()` to compare the text, not the index.**

```
combo.currentTextChanged.connect(lambda text: print("Selected: " + text))
```

**Or use `findText` to look it up:**

```
idx = combo.findText("Shanghai")
if idx >= 0:
    combo.setCurrentIndex(idx)
```

## QCheckBox: Checkbox (Multiple Selection Allowed)

**QCheckBox represents a "yes/no" or "multiple choice" option.**

```
from PySide6.QtWidgets import QCheckBox

cb = QCheckBox("Remember password")
cb.setChecked(True)             # checked by default
print(cb.isChecked())           # True

cb.toggled.connect(lambda checked: print("Checked state:", checked))
```

**`setChecked(True/False)` sets the state; `isChecked()` reads it.**

**The `toggled(bool)` signal fires when the state changes**, passing whether it's currently checked.

**Collecting results from multiple checkboxes:**

```
hobbies = ["Reading", "Sports", "Music", "Travel"]
checks = []
for h in hobbies:
    cb = QCheckBox(h)
    checks.append(cb)

def collect():
    chosen = [cb.text() for cb in checks if cb.isChecked()]
    print("Selected:", chosen)

for cb in checks:
    cb.toggled.connect(collect)
```

**The list comprehension `[cb.text() for cb in checks if cb.isChecked()]` collects all checked items in one line.**

## Crash Site 2: Checkbox state judgment is reversed

**Symptom: logic is the opposite of what you expected.**

```
if not cb.isChecked():     # meant to check if checked
    print("Checked")
```

**`isChecked()` returns True when checked.** Use `if cb.isChecked():` to test checked, `if not cb.isChecked():` for unchecked.

## QRadioButton: Radio Button (Mutually Exclusive Single Choice)

**QRadioButton is a radio button — only one can be selected in a group.**

```
from PySide6.QtWidgets import QRadioButton

r1 = QRadioButton("Male")
r2 = QRadioButton("Female")
r3 = QRadioButton("Other")

r1.setChecked(True)        # default to "Male"
```

**The problem: if you place these three buttons together, can the user select multiple?** Answer: **yes** — if they aren't properly placed in the same parent container or layout.

**Radio button互斥 relies on "same parent container / same layout":**

```
from PySide6.QtWidgets import QGroupBox, QVBoxLayout

group = QGroupBox("Gender")
layout = QVBoxLayout(group)
layout.addWidget(r1)
layout.addWidget(r2)
layout.addWidget(r3)
```

**Putting radio buttons in the same QGroupBox or same layout makes Qt auto-mutually-exclusive.** Without grouping, radio buttons scattered around the window may act independently or all merge together — behavior is unpredictable.

**The correct approach: explicitly group with QButtonGroup (recommended):**

```
from PySide6.QtWidgets import QButtonGroup

sex_group = QButtonGroup(window)
sex_group.addButton(r1)
sex_group.addButton(r2)
sex_group.addButton(r3)
```

**QButtonGroup doesn't handle display (it doesn't inherit QWidget) — it only manages logical互斥.** This way, even if radio buttons are scattered across different layouts, adding them to the same QButtonGroup guarantees互斥.

## Crash Site 3: Radio buttons not grouped, multiple can be selected

**Symptom: both "Male" and "Female" can be checked — logically nonsensical.**

```
r1 = QRadioButton("Male", window)
r2 = QRadioButton("Female", window)
r3 = QRadioButton("Other", window)
r1.setChecked(True)
# all three attached directly to window —互斥 relationship unclear
```

**Why: radio button互斥 depends on "same parent container's layout" or "same QButtonGroup". Attached directly to the window without explicit grouping, behavior is unpredictable.**

**Fix: use QButtonGroup:**

```
sex_group = QButtonGroup()
sex_group.addButton(r1)
sex_group.addButton(r2)
sex_group.addButton(r3)
```

**Or place them in the same QGroupBox / layout.**

## Advanced QButtonGroup Usage

**`checkedButton()` returns the currently selected button:**

```
def on_sex_changed():
    btn = sex_group.checkedButton()
    if btn:
        print("Gender:", btn.text())

sex_group.buttonToggled.connect(lambda btn, checked: on_sex_changed())
```

**`buttonToggled` carries two arguments: which button, and whether it's checked.**

**`setId(button, id)` assigns a numeric ID for easier判断:**

```
sex_group.addButton(r1, 1)     # ID 1
sex_group.addButton(r2, 2)     # ID 2
sex_group.addButton(r3, 3)     # ID 3

print("Selected ID:", sex_group.checkedId())   # returns the selected button's ID
```

**Using IDs instead of text for判断 is more stable: text may change, IDs don't.**

## Combining All Three: A Filter Settings Panel

**Dropdown for sort order, checkboxes for filter conditions, radio buttons for view mode:**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QComboBox, QCheckBox,
    QRadioButton, QButtonGroup, QLabel, QVBoxLayout, QHBoxLayout, QGroupBox
)
from PySide6.QtCore import Qt

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("Filter Settings")
window.resize(350, 300)

# Sort order (dropdown)
sort_combo = QComboBox()
sort_combo.addItems(["By time", "By name", "By size", "By type"])
sort_label = QLabel("Sort: Best match")       # initial
sort_combo.currentTextChanged.connect(lambda t: sort_label.setText("Sort: " + t))

# Filter conditions (checkboxes)
filters = QGroupBox("Filter Conditions")
f_layout = QVBoxLayout(filters)
check_read = QCheckBox("Unread only")
check_star = QCheckBox("Starred")
check_attach = QCheckBox("Has attachment")
f_layout.addWidget(check_read)
f_layout.addWidget(check_star)
f_layout.addWidget(check_attach)

# View mode (radio buttons)
view_group = QButtonGroup()
view_box = QGroupBox("View Mode")
v_layout = QVBoxLayout(view_box)
r_list = QRadioButton("List")
r_grid = QRadioButton("Grid")
r_list.setChecked(True)
view_group.addButton(r_list)
view_group.addButton(r_grid)
v_layout.addWidget(r_list)
v_layout.addWidget(r_grid)

main = QVBoxLayout(window)
main.addWidget(sort_combo)
main.addWidget(sort_label)
main.addWidget(filters)
main.addWidget(view_box)

window.show()
app.exec()
```

**Structure: one dropdown, one checkbox group, one radio button group — stacked vertically.**

## Summary

- QComboBox: addItem/addItems to add options, currentText() to read text, currentTextChanged signal
- Compare by text or findText, not by index (option order changes = bug)
- QCheckBox: setChecked/isChecked, toggled(bool) signal
- Collect multi-select results with a list comprehension
- QRadioButton: mutually exclusive within a group — needs explicit grouping
- Use QButtonGroup to guarantee互斥 (recommended), or place in the same QGroupBox
- QButtonGroup.setId assigns a numeric ID; checkedId() reads it — more stable than comparing text
