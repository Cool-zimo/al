# QLabel, QPushButton, and QLineEdit

> These three are Qt's most basic widgets: QLabel displays text or images, QPushButton triggers actions, and QLineEdit accepts single-line input. You've used them many times already. This lesson fills in their advanced用法 and crash sites.

## QLabel: More Than Just Text

**QLabel displays text, images, animations, and even supports text selection.**

```
from PySide6.QtWidgets import QLabel

label = QLabel("Hello, World")
label.setText("New text")         # change text
print(label.text())              # read text
```

**`setWordWrap(True)` enables automatic line wrapping:**

```
label = QLabel("This is a very long piece of text that, without word wrap, would just keep extending off the right edge of the window")
label.setWordWrap(True)          # wrap when exceeding the width
```

**Without word wrap, long text either breaks the layout or gets clipped.**

**`setAlignment` sets alignment:**

```
from PySide6.QtCore import Qt
label.setAlignment(Qt.AlignmentFlag.AlignCenter)          # center horizontally and vertically
label.setAlignment(Qt.AlignmentFlag.AlignRight)           # right-align
label.setAlignment(Qt.AlignmentFlag.AlignTop | Qt.AlignmentFlag.AlignLeft)  # top-left
```

**Multiple alignment flags are combined with `|` (bitwise OR).**

## Crash Site 1: After wrapping, the label height doesn't follow

**Symptom: word wrap is on, but the label stays one line tall and text gets clipped.**

**Why: QLabel's default vertical sizePolicy is Preferred, but the layout may have compressed it to a fixed height.**

**Fix: set the label's vertical sizePolicy to Minimum or Expanding so it has room to grow.**

```
label.setSizePolicy(
    QSizePolicy.Policy.Preferred,
    QSizePolicy.Policy.Minimum        # vertical: show all content
)
```

## QLabel Displaying Images

**`setPixmap` displays an image:**

```
from PySide6.QtGui import QPixmap

pixmap = QPixmap("logo.png")
label.setPixmap(pixmap)
```

**If the image path isn't found, no error is raised — `label.pixmap()` returns empty.**

**Scaling an image to fit the label:**

```
pixmap = QPixmap("logo.png")
scaled = pixmap.scaled(
    label.size(),
    Qt.AspectRatioMode.KeepAspectRatio,      # preserve aspect ratio
    Qt.TransformationMode.SmoothTransformation
)
label.setPixmap(scaled)
```

**`KeepAspectRatio` ensures the image isn't distorted.** This is used daily for avatars and thumbnails.

## QPushButton: Text, Icons, Disabled State

**The most basic button:**

```
from PySide6.QtWidgets import QPushButton

btn = QPushButton("OK")
btn.clicked.connect(lambda: print("Clicked"))
```

**`setIcon` adds an icon:**

```
from PySide6.QtGui import QIcon

btn.setIcon(QIcon.fromTheme("document-save"))   # Linux theme icon
btn.setIcon(QIcon("save.png"))                  # local file
```

**`setEnabled(False)` disables the button (greys out, can't be clicked):**

```
btn.setEnabled(False)
```

**`setDefault(True)` makes it the default button (Enter triggers it in a dialog):**

```
ok_btn = QPushButton("OK")
ok_btn.setDefault(True)
```

**`setCheckable(True)` turns the button into a toggle:**

```
btn = QPushButton("Star")
btn.setCheckable(True)
btn.toggled.connect(lambda checked: print("Checked state:", checked))
```

**The `toggled` signal carries a bool parameter**, indicating whether it's pressed or released. This is the standard for toggle buttons.

## Crash Site 2: Button doesn't respond — setEnabled(False) was the culprit

**Symptom: the button is greyed out, clicks do nothing — you suspect the signal isn't connected.**

**Why: the button was `setEnabled(False)` — it's disabled and won't accept clicks.**

**Debugging: check whether you disabled it somewhere in the code, or just look at whether it's grey.**

**Fix: keep `setEnabled(True)` when you need click响应. Disabling until a condition is met is common UX, but remember to re-enable once the condition changes.**

## QLineEdit: Single-Line Text Input

**Accepts one line of text input:**

```
from PySide6.QtWidgets import QLineEdit

edit = QLineEdit()
edit.setPlaceholderText("Enter username")    # grey placeholder text
edit.setText("Alice")                      # set value
print(edit.text())                       # get value
```

**`placeholderText` is grey hint text that disappears once the user types.** Very useful in forms.

**`setMaxLength(20)` limits input to 20 characters:**

```
edit.setMaxLength(20)
```

**`setReadOnly(True)` makes it read-only:**

```
edit.setReadOnly(True)      # can't change, but can select and copy
```

**Read-only differs from disabled: `setEnabled(False)` won't even let you select and copy.**

## Crash Site 3: Getting an integer but using text() as a number

**Symptom: error `TypeError: unsupported operand type(s) for +: 'int' and 'str'`**

```
age_edit = QLineEdit()
age_edit.setText("18")
age = age_edit.text()       # this is the string "18"
print(age + 1)             # error!
```

**Fix: `int(edit.text())` to convert to int.** But the input might not be a number, so catch the exception:

```
text = edit.text()
try:
    age = int(text)
except ValueError:
    print("Please enter a number")
```

## textChanged and returnPressed Signals

**`textChanged(str)` responds to input changes in real time:**

```
edit.textChanged.connect(lambda text: print("Current:", text))
```

**Triggered on every keystroke.** Covered in Lesson 3.

**`returnPressed` fires when Enter is pressed:**

```
edit.returnPressed.connect(lambda: print("Confirmed:", edit.text()))
```

**Commonly used for search boxes and chat inputs:** submit on Enter instead of clicking a button.

**`editingFinished` fires when the input loses focus:**

```
edit.editingFinished.connect(lambda: print("Editing finished"))
```

**Ideal for "validate when the user finishes and moves away".**

## Combining All Three: A Login Mini-Interface

**Putting everything from today to use:**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QLabel, QLineEdit, QPushButton,
    QFormLayout, QVBoxLayout, QHBoxLayout
)
from PySide6.QtCore import Qt

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("Login")

user_edit = QLineEdit()
user_edit.setPlaceholderText("Enter username")
pass_edit = QLineEdit()
pass_edit.setPlaceholderText("Enter password")
pass_edit.setEchoMode(QLineEdit.EchoMode.Password)

tip_label = QLabel("Please enter username and password")
tip_label.setStyleSheet("color: gray;")

def on_login():
    u = user_edit.text()
    p = pass_edit.text()
    if u and p:
        tip_label.setText(f"Logging in: {u}")
        tip_label.setStyleSheet("color: green;")
    else:
        tip_label.setText("Username and password cannot be empty")
        tip_label.setStyleSheet("color: red;")

login_btn = QPushButton("Login")
login_btn.setDefault(True)
login_btn.clicked.connect(on_login)

form = QFormLayout()
form.addRow("Username:", user_edit)
form.addRow("Password:", pass_edit)

btn_bar = QHBoxLayout()
btn_bar.addStretch()
btn_bar.addWidget(login_btn)

main = QVBoxLayout(window)
main.addLayout(form)
main.addWidget(tip_label)
main.addLayout(btn_bar)

window.resize(320, 160)
window.show()
app.exec()
```

**`setStyleSheet` dynamically changes text color** — very handy for form validation feedback.

## Summary

- QLabel: setText/getText, setWordWrap, setAlignment, setPixmap
- If label height doesn't update after wrapping, check the vertical sizePolicy
- QPushButton: setIcon, setEnabled, setDefault, setCheckable
- setCheckable(True) turns a button into a toggle; toggled carries a bool
- QLineEdit: placeholderText for hints, maxLength for length, readOnly for read-only
- text() returns a string; for numbers use int() and catch ValueError
- textChanged is real-time, returnPressed on Enter, editingFinished on focus loss
