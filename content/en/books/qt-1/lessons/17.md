# QInputDialog / QFileDialog / QColorDialog

> Three built-in dialogs you'll use constantly: grab a value, pick a file, choose a color. Each is a one-liner static method — but they all hide the same trap: the user might cancel.

## QInputDialog: Grab User Input

**`QInputDialog` retrieves a single line of text, a number, or a choice. It returns a `(value, ok)` tuple.**

```
from PySide6.QtWidgets import QInputDialog

text, ok = QInputDialog.getText(window, "Input", "Please enter your name:")
if ok:
    print("You entered:", text)
```

**`ok` is a boolean — `True` means the user clicked OK, `False` means Cancel.** This is the easiest place to forget to check.

**Getting an integer or a floating-point number:**

```
age, ok = QInputDialog.getInt(window, "Age", "Please enter your age:", value=18, min=0, max=120)
if ok:
    print("Age:", age)
```

```
weight, ok = QInputDialog.getDouble(window, "Weight", "Please enter your weight:", value=60.0, min=0, max=300, decimals=1)
if ok:
    print("Weight:", weight)
```

**`getItem` lets the user pick from a dropdown list:**

```
items = ["Python", "C++", "Rust", "Go"]
lang, ok = QInputDialog.getItem(window, "Choose", "Your favorite language:", items, current=0, editable=False)
if ok:
    print("Chosen:", lang)
```

**With `editable=False` the user can only pick; remove it to let them type a new value.**

## Crash Site #1: Unpacking Without Checking ok — and Crashing on Cancel

**Symptom: you click Cancel in the dialog and the program crashes with `TypeError: cannot unpack non-iterable ...`.**

```
text = QInputDialog.getText(window, "Input", "Name:")   # WRONG - only one variable
print(text.upper())    # the return value is a tuple, so text becomes a tuple
```

**An even sneakier mistake is using the value without checking `ok`:**

```
text, ok = QInputDialog.getText(window, "Input", "Name:")
print(f"Hello, {text}")    # WRONG - after cancel, text is "" and the logic is wrong
```

**✅ Correct: always check `ok`:**

```
text, ok = QInputDialog.getText(window, "Input", "Name:")
if ok and text.strip():
    print(f"Hello, {text}")
else:
    print("User cancelled, or entered nothing")
```

**After cancel, `text` is an empty string, not `None`.** So to check "did the user actually enter something", use `text.strip()`, not just `if text`.

## QFileDialog: Pick a File

**`getOpenFileName` selects one file and returns a `(path, filter)` tuple.**

```
from PySide6.QtWidgets import QFileDialog

file_path, _ = QFileDialog.getOpenFileName(
    window, "Open file", "", "Text files (*.txt);;All files (*)"
)
if file_path:
    print("Selected:", file_path)
```

**The third argument is the starting directory; the fourth is the filter, with options separated by `;;`.** The second element of the return tuple is the filter the user selected — usually you don't need it, so discard it with `_`.

**`getOpenFileNames` selects multiple files and returns a list:**

```
files, _ = QFileDialog.getOpenFileNames(window, "Open multiple", "", "Images (*.png *.jpg)")
print(files)    # ['/a.png', '/b.jpg']
```

**`getSaveFileName` is the "Save As" dialog:**

```
save_path, _ = QFileDialog.getSaveFileName(window, "Save", "untitled.txt", "Text (*.txt)")
if save_path:
    with open(save_path, "w", encoding="utf-8") as f:
        f.write("hello")
```

**`getExistingDirectory` selects a folder only:**

```
folder = QFileDialog.getExistingDirectory(window, "Select directory", "")
if folder:
    print("Directory:", folder)
```

## Crash Site #2: User Cancels, You Get "" and Still Call open

**Symptom: you click Cancel, `file_path` is `""`, and then `open("")` raises `FileNotFoundError` or `ValueError`.**

```
file_path, _ = QFileDialog.getOpenFileName(window, "Open", "", "Text (*.txt)")
with open(file_path, "r", encoding="utf-8") as f:    # WRONG - no empty check
    content = f.read()
# after cancel: ValueError: invalid mode: 'r'
```

**✅ Correct: check for empty first, then operate.**

```
file_path, _ = QFileDialog.getOpenFileName(window, "Open", "", "Text (*.txt)")
if not file_path:
    return    # user cancelled, just return

with open(file_path, "r", encoding="utf-8") as f:
    content = f.read()
label.setText(content)
```

**This is a habit you must build: always validate a dialog's return value before using it.** QInputDialog → check `ok`. QFileDialog → check that the path is not empty. QColorDialog → check `isValid()`.

## QColorDialog: Pick a Color

**`getColor` returns a `QColor` object; after cancel, `isValid()` is `False`.**

```
from PySide6.QtWidgets import QColorDialog
from PySide6.QtGui import QColor

color = QColorDialog.getColor(QColor("white"), window, "Select a color")
if color.isValid():
    print(color.name())              # "#ff0000"
    print(color.red(), color.green(), color.blue())
    btn.setStyleSheet(f"background-color: {color.name()};")
else:
    print("User cancelled the color picker")
```

**The first argument is the initial color — `QColor` or a color name string both work.** `color.name()` returns `#rrggbb`, which you can drop straight into a QSS rule.

**Combining it with QSS for a live preview:**

```
color = QColorDialog.getColor(QColor("#3498db"), self, "Select background color")
if color.isValid():
    self.setStyleSheet(f"QWidget {{ background-color: {color.name()}; }}")
```

## Summary

- QInputDialog: getText / getInt / getDouble / getItem, returning `(value, ok)`
- ⚠️ Classic trap: using the return value without checking `ok`; after cancel, `text` is `""` not `None`
- QFileDialog: getOpenFileName / getOpenFileNames / getSaveFileName / getExistingDirectory
- File dialogs return `(path, filter)`; check for empty before opening, or a cancel will throw
- Filters use `;;` as a separator, e.g. `"Text (*.txt);;All files (*)"`
- QColorDialog.getColor returns a QColor; use `isValid()` to detect cancel, `name()` for the hex value
- Every dialog's return value must be validated before use
