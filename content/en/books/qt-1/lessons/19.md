# QMenuBar / QToolBar / QStatusBar

> Menus, toolbars, and status bars are the "front-door trio" of a desktop app. This lesson covers how to write each one and how they work together.

## QMenuBar: The Menu Bar

**`QMainWindow` comes with a menu bar — grab it with `menuBar()` and add menus with `addMenu`.**

```
from PySide6.QtWidgets import QMainWindow, QMenuBar, QMenu

class MainWindow(QMainWindow):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("Notepad")
        self.resize(600, 400)

        menubar = self.menuBar()

        file_menu = menubar.addMenu("File(&F)")    # &F is the Alt+F shortcut
        file_menu.addAction("New")
        file_menu.addAction("Open")
        file_menu.addAction("Save")
        file_menu.addSeparator()                    # separator line
        file_menu.addAction("Quit")

        edit_menu = menubar.addMenu("Edit(&E)")
        edit_menu.addAction("Undo")
        edit_menu.addAction("Redo")
```

**The `&` in `&F` is not decoration — it is a mnemonic. `Alt+F` opens that menu.** Even for a Chinese interface it is worth adding; keyboard navigation becomes much faster.

**Menu items are `QAction` objects; the next lesson covers them in detail.** Here we pass strings directly and Qt wraps them into `QAction` for us.

## QToolBar: The Toolbar

**`addToolBar` creates a toolbar; add `QAction` objects or arbitrary widgets to it.**

```
from PySide6.QtWidgets import QToolBar, QAction

toolbar = QToolBar("Main toolbar")
self.addToolBar(toolbar)

toolbar.addAction("New")
toolbar.addAction("Open")
toolbar.addSeparator()
toolbar.addAction("Save")
```

**A toolbar is dockable and draggable by default. Adding a widget is common too:**

```
from PySide6.QtWidgets import QLineEdit

search = QLineEdit()
search.setPlaceholderText("Search...")
toolbar.addWidget(search)         # addWidget accepts any widget
```

**Controlling the position: pass a dock area as the second argument to `addToolBar`.**

```
self.addToolBar(Qt.TopToolBarArea, toolbar)    # top (default)
self.addToolBar(Qt.LeftToolBarArea, toolbar)    # left
```

**`setMovable(False)` disables dragging; `setFloatable(False)` stops it from becoming a floating window.**

## Crash Site #1: Using QWidget as the Main Window — menuBar() Is None

**Symptom: you copy the menu-bar code, but at runtime you get `AttributeError: 'QWidget' object has no attribute 'menuBar'`.**

```
class MainWindow(QWidget):              # WRONG - QWidget has no menu bar
    def __init__(self):
        super().__init__()
        self.menuBar()                  # AttributeError!
```

**Why: the menu bar, toolbar, and status bar are all capabilities of `QMainWindow`. `QWidget` has none of them.** Many people start with "QWidget + layout" and forget to switch the base class when moving to a desktop app.

**✅ Correct:**

```
class MainWindow(QMainWindow):          # inherit QMainWindow
    def __init__(self):
        super().__init__()
        self.menuBar().addMenu("File")
        self.addToolBar(QToolBar("Tools"))
        self.setStatusBar(QStatusBar())
```

**If you really must use `QWidget` as the main window, you have to create a `QMenuBar` control yourself and insert it into the layout — much more verbose, and not recommended.**

## QStatusBar: The Status Bar

**`statusBar()` returns the status bar; `showMessage` displays a temporary message.**

```
statusbar = self.statusBar()
statusbar.showMessage("Ready", 3000)      # auto-clears after 3000 ms
```

**The second argument is a timeout in milliseconds; omit it to keep the message permanently.** For a "Saved" notice pass 2000; for a permanent label, pass nothing.

**You can also place permanent widgets on the status bar:**

```
from PySide6.QtWidgets import QLabel

self.statusbar = self.statusBar()
self.cursor_label = QLabel("Line 1, Col 1")
self.statusbar.addPermanentWidget(self.cursor_label)    # sticks to the right
```

**`addPermanentWidget` places on the right; `addWidget` places on the left.** Either can hold any widget, not just a `QLabel`.

**The typical pattern: drive the status bar from a signal in the editor.**

```
self.editor.cursorPositionChanged.connect(
    lambda: self.cursor_label.setText(f"Line {self.editor.textCursor().blockNumber() + 1}")
)
```

## Putting the Three Together

**The standard setup — menu bar, toolbar, and status bar all present:**

```
class MainWindow(QMainWindow):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("Editor")
        self.resize(600, 400)

        # central widget
        from PySide6.QtWidgets import QTextEdit
        self.editor = QTextEdit()
        self.setCentralWidget(self.editor)

        # menu bar
        menubar = self.menuBar()
        file_menu = menubar.addMenu("File(&F)")
        file_menu.addAction("Open")
        file_menu.addAction("Save")
        file_menu.addSeparator()
        file_menu.addAction("Quit")

        # toolbar
        toolbar = QToolBar("Tools")
        self.addToolBar(toolbar)
        toolbar.addAction("Open")
        toolbar.addAction("Save")

        # status bar
        self.statusbar = self.statusBar()
        self.statusbar.showMessage("Ready")
```

**`setCentralWidget` is the center area of `QMainWindow`; everything outside the trio goes there.** Forget it and the window stays empty.

## Crash Site #2: Setting a Layout Directly on QMainWindow — Content Is Invisible

**Symptom: you add widgets to a layout and call `setLayout`, but the window is blank.**

```
layout = QVBoxLayout()
layout.addWidget(QPushButton("Button"))
self.setLayout(layout)              # WRONG - QMainWindow cannot take a layout directly
```

**Why: `QMainWindow` has a fixed structure (menu bar, toolbars, central area, dock areas, status bar) and does not allow `setLayout`.** You must first give it a `QWidget` as the central widget and lay *that* out.

**✅ Correct:**

```
central = QWidget()
layout = QVBoxLayout(central)
layout.addWidget(QPushButton("Button"))
self.setCentralWidget(central)      # wrap it in a central widget first
```

**Remember the rule: `QMainWindow` only knows about a central widget; put every child control inside a `QWidget` first.**

## Summary

- Menu bar, toolbar, and status bar belong to `QMainWindow`; the base class must be `QMainWindow`
- `menuBar().addMenu()` adds menus; `addSeparator` adds dividers; `&F` sets a mnemonic
- `addToolBar` adds a toolbar; `addAction` adds an action; `addWidget` adds any widget
- `statusBar().showMessage(text, timeout)`; `addPermanentWidget` docks to the right
- ⚠️ Classic traps: `QWidget` has no `menuBar`; `QMainWindow` cannot take `setLayout` directly — set a central widget first
- The central widget is the container for everything outside the trio

```quiz
type: local
q: Build a "simple notepad" main window: inherit QMainWindow with a QTextEdit as the central widget. Add a menu bar with a "File" menu (New, Open, Save, Quit) and an "Edit" menu (Clear). Add a toolbar with "Open" and "Save" actions. The status bar shows "Ready" by default; after clicking "New", show "New file created" for 2 seconds, then revert to "Ready". Note: this is a windowed program and cannot run inside a web page — click "Open in VS Code" to run it.
starter: |
  import sys
  from PySide6.QtWidgets import (
      QApplication, QMainWindow, QMenuBar, QToolBar, QStatusBar,
      QTextEdit
  )

  class MainWindow(QMainWindow):
      def __init__(self):
          super().__init__()
          self.setWindowTitle("Simple Notepad")
          self.resize(500, 350)

          # Complete the menu bar, toolbar, and status bar here
          self.editor = QTextEdit()
          self.setCentralWidget(self.editor)

  app = QApplication(sys.argv)
  win = MainWindow()
  win.show()
  app.exec()
checklist:
- Inherits QMainWindow; central widget is a QTextEdit
- Menu bar has "File" (New/Open/Save/Quit) and "Edit" (Clear)
- Toolbar has "Open" and "Save" actions
- Status bar shows "Ready" by default
- After "New", the status bar shows "New file created" and reverts after 2 seconds
- The program displays and runs normally
```
