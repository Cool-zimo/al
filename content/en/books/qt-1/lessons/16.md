# QMessageBox: Four Kinds of Prompts and Their Return Values

> Pop-up dialogs are the fastest way to talk to your user. This lesson covers the four standard `QMessageBox` dialogs and how to read which button the user clicked.

## The Four Flavors of QMessageBox

**`QMessageBox` is a modal message box. Its four static methods correspond to four icons: `information` / `warning` / `critical` / `question`.**

```
from PySide6.QtWidgets import QMessageBox

QMessageBox.information(window, "Title", "Operation succeeded!")
QMessageBox.warning(window, "Warning", "Not enough disk space")
QMessageBox.critical(window, "Error", "Could not open the file")
ret = QMessageBox.question(window, "Confirm", "Are you sure you want to delete this?")
```

**The four arguments are, in order: parent window, title, text, standard buttons (optional), default button (optional).** The return value is a `StandardButton` enum representing the button the user clicked.

**Only `question` comes with "Yes/No" by default; the other three have just one "OK" button.** If you want `information` to offer Yes/No, you must pass the `buttons` argument explicitly:

```
ret = QMessageBox.information(
    window, "Save", "Content has changed. Save now?",
    QMessageBox.Yes | QMessageBox.No | QMessageBox.Cancel,
    QMessageBox.Yes    # highlight Yes as the default
)
```

## Crash Site #1: Comparing the Return Value to a String

**Symptom: you clearly clicked "Yes", yet the branch never runs.**

```
ret = QMessageBox.question(window, "Confirm", "Delete?")
if ret == "Yes":          # WRONG - ret is an enum, not a string
    print("deleting")
# after clicking "Yes" it still does not delete, and there is no error; the branch is silently skipped
```

**Why: the return type is `QMessageBox.StandardButton`, which is an enum — not a string, and not the integer 0 or 1.** Comparing it to a string is never true, and Python will not warn you about it.

**✅ Correct:**

```
from PySide6.QtWidgets import QMessageBox

ret = QMessageBox.question(window, "Confirm", "Delete?")
if ret == QMessageBox.Yes:
    print("deleting")
elif ret == QMessageBox.No:
    print("cancelled")
```

**In PySide6 you must write `QMessageBox.Yes`, not `QMessageBox.YesRole`.** `YesRole` is a role value used for ordering custom buttons — it is not the same thing as a return value.

## Reading the Button Return Value

**The most common use of `question` is a yes-or-no choice — the "should I continue?" branch:**

```
reply = QMessageBox.question(
    window, "Quit", "Are you sure you want to quit?",
    QMessageBox.Yes | QMessageBox.No,
    QMessageBox.No       # default to No to prevent accidental closing
)

if reply == QMessageBox.Yes:
    app.quit()
```

**With multiple buttons, combine them with bitwise OR (`|`) and check each one:**

```
ret = QMessageBox.warning(
    window, "Overwrite file", "The target file already exists",
    QMessageBox.Save | QMessageBox.Discard | QMessageBox.Cancel,
    QMessageBox.Cancel
)

if ret == QMessageBox.Save:
    do_save()
elif ret == QMessageBox.Discard:
    do_overwrite()
else:    # Cancel
    pass
```

**You can open a message box with `exec()` too, but the static methods are far more convenient.** The static methods already create the object, set the icon, and call `exec()` for you, so you usually don't need to do it by hand.

## Crash Site #2: Forgetting the Parent, the Dialog Hides Behind the Window

**Symptom: you click the trigger button and the program looks frozen; only after switching windows do you find the dialog hiding behind everything.**

```
QMessageBox.information(None, "Notice", "Done")    # WRONG - parent is None
```

**Why: a modal dialog relies on its parent for stacking and focus management.** With no parent, the dialog may have no taskbar entry or get covered by its own parent window, making it look like the program stopped responding.

**✅ Correct: pass `self` or `window`:**

```
QMessageBox.information(self, "Notice", "Saved successfully")
```

**A non-None parent has extra benefits: the dialog centers itself over the parent, and closing the parent also closes the dialog.**

## Custom Icons and Detailed Text

**`setIcon` lets you pick the icon type yourself:**

```
msg = QMessageBox()
msg.setWindowTitle("Notice")
msg.setText("Not enough disk space")
msg.setIcon(QMessageBox.Warning)    # Information / Warning / Critical / Question
msg.exec()
```

**`setDetailedText` adds an expandable "Show Details" region — perfect for stack traces or logs:**

```
msg = QMessageBox()
msg.setWindowTitle("Error")
msg.setText("Failed to save the file")
msg.setDetailedText("PermissionError: [Errno 13] Permission denied: '/root/a.txt'")
msg.exec()
```

**`setInformativeText` is the smaller gray line below the main text — more specific than the headline, but less loud:**

```
msg = QMessageBox()
msg.setText("Save failed")
msg.setInformativeText("The target file is open in another program. Close it and try again.")
msg.setStandardButtons(QMessageBox.Retry | QMessageBox.Cancel)
msg.exec()
```

## Summary

- Four static methods: `information` / `warning` / `critical` / `question`, each with its own icon
- `question` has Yes/No by default; the others have only OK
- The return value is a `StandardButton` enum — compare with `== QMessageBox.Yes`
- ⚠️ Classic traps: comparing the return value to the string `"Yes"` is never true; passing `None` as the parent hides the dialog behind the window
- Combine multiple buttons with `|`; the last argument sets the default button
- `setInformativeText` for the gray explanation, `setDetailedText` for the expandable details
