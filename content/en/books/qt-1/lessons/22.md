# Common QSS Patterns

> This lesson works through the QSS patterns you'll reach for constantly: button hover/press, borders and corners, and input focus. Learn these templates and you can style most interfaces.

## A Button's Three States

**The states most worth writing for a button are: normal, hover, and pressed.**

```
QPushButton {
    background-color: #3498db;
    color: white;
    border: none;
    border-radius: 6px;
    padding: 8px 16px;
    font-size: 14px;
}

QPushButton:hover {
    background-color: #2980b9;
}

QPushButton:pressed {
    background-color: #1f6391;
    padding: 9px 15px 7px 17px;    /* slight shift on press to feel clicked */
}
```

**`:hover` is the mouse hovering, `:pressed` is the mouse held down, `:disabled` is the disabled state.**

**Always write `:disabled`, otherwise a disabled button still looks clickable:**

```
QPushButton:disabled {
    background-color: #bdc3c7;
    color: #7f8c8d;
}
```

**`border: none` removes the system's default button relief; paired with a background color you get a flat look.** Without it, Windows adds a native border that fights your color scheme.

## Crash Site #1: The Hover Style Never Applies — A More Specific Rule Overrides It

**Symptom: you wrote a `:hover` rule, but moving the mouse over the button changes nothing.**

```
btn = QPushButton("Submit")
btn.setStyleSheet("""
    QPushButton { background-color: #3498db; }    # applies to this button
""")
# meanwhile the parent window has:
window.setStyleSheet("""
    QPushButton:hover { background-color: red; }   # overridden by the more specific rule above
""")
```

**Why: QSS has specificity rules — the style "closer" to the widget wins.** The button's own `setStyleSheet` has no `:hover`, while the parent window's style sheet does; after merging they may not behave as you expect. More often the real problem is that the `QPushButton` rule appears *after* `:hover` in the same style sheet, so it overwrites it.

**✅ Correct: keep all states together, in the usual order.**

```
btn.setStyleSheet("""
    QPushButton {
        background-color: #3498db;
        color: white;
        border-radius: 6px;
        padding: 8px 16px;
    }
    QPushButton:hover { background-color: #2980b9; }
    QPushButton:pressed { background-color: #1f6391; }
""")
```

**Recommended order: base → :hover → :pressed → :disabled. This sequence causes the fewest surprises.**

## Borders and Rounded Corners

**`border` is a shorthand: `border: width style color`.**

```
QLineEdit {
    border: 2px solid #bdc3c7;
    border-radius: 6px;
}

QLineEdit:focus {
    border: 2px solid #3498db;
}
```

**You can make a card effect with just a corner radius and no background fill:**

```
QLabel#card {
    background-color: white;
    border: 1px solid #e0e0e0;
    border-radius: 10px;
    padding: 16px;
}
```

**Controlling each corner individually:**

```
QPushButton {
    border-top-left-radius: 8px;
    border-top-right-radius: 8px;
    border-bottom-left-radius: 0;
    border-bottom-right-radius: 0;
}
```

**When `border-radius` exceeds half the control's height you get a perfect circle:**

```
QPushButton#circle_btn {
    border-radius: 25px;    # for a 50px-tall button, 25px is half
}
```

## Input Focus and Placeholders

**:focus is the most useful pseudo-state for input fields.**

```
QLineEdit {
    background-color: white;
    border: 1px solid #ccc;
    border-radius: 4px;
    padding: 6px 10px;
    selection-background-color: #3498db;    # selection highlight
}

QLineEdit:focus {
    border: 2px solid #3498db;
    padding: 5px 9px;    # border grows by 1px, padding shrinks by 1px so text does not jump
}

QLineEdit:hover:!focus {
    border: 1px solid #999;
}
```

**`hover:!focus` means "hovering but not focused" — both conditions must hold.** `!` negates; chain pseudo-states with a colon.

**The placeholder text uses `::placeholder`:**

```
QLineEdit::placeholder {
    color: #95a5a6;
    font-style: italic;
}
```

**The password echo character:**

```
QLineEdit#pwd {
    lineedit-password-character: 9679;    # filled dot; this is the default
    lineedit-password-mask-delay: 1000;  # switch to a dot after 1 second
}
```

## Crash Site #2: Padding Changes Make the Text Jitter

**Symptom: when the input gets focus, the text jumps left by a pixel — it looks cheap.**

```
QLineEdit { border: 1px solid #ccc; padding: 6px 10px; }
QLineEdit:focus { border: 2px solid #3498db; padding: 6px 10px; }
# the 2px border occupies 1px more space than the 1px border, pushing the text
```

**Why: going from a 1px to a 2px border shrinks the available interior by 1px, so the text moves.** It is visible to the naked eye.

**✅ Correct: when the border thickens, reduce the padding by the same amount.**

```
QLineEdit { border: 1px solid #ccc; padding: 6px 10px; }
QLineEdit:focus { border: 2px solid #3498db; padding: 5px 9px; }
```

**Or use `outline` uniformly (Qt supports the `outline` property and it takes no layout space):**

```
QLineEdit { border: 1px solid #ccc; }
QLineEdit:focus { outline: 2px solid #3498db; }
```

## Gradient Backgrounds

**QSS supports linear and radial gradients.**

```
QPushButton {
    background: qlineargradient(
        x1: 0, y1: 0, x2: 0, y2: 1,
        stop: 0 #3498db, stop: 1 #2980b9
    );
    color: white;
    border: none;
    border-radius: 6px;
    padding: 8px 16px;
}
```

**`x1:0, y1:0, x2:0, y2:1` means top to bottom.** `stop:0` is the starting color, `stop:1` is the ending color, and you can insert as many intermediate stops as you like.

**A multi-stop gradient for a polished button:**

```
QPushButton {
    background: qlineargradient(
        x1: 0, y1: 0, x2: 0, y2: 1,
        stop: 0 #4facfe, stop: 0.5 #00f2fe, stop: 1 #4facfe
    );
    color: white;
    border-radius: 20px;
    padding: 8px 24px;
}
```

**Radial gradient with `qradialgradient`:**

```
QWidget#header {
    background: qradialgradient(
        cx: 0.5, cy: 0.5, radius: 0.5,
        fx: 0.5, fy: 0.5,
        stop: 0 white, stop: 1 #3498db
    );
}
```

## Summary

- A button's three states: normal / :hover / :pressed; this order is the most stable
- Always write :disabled, or a disabled button will still look clickable
- ⚠️ Classic traps: getting the state-rule order wrong so it never applies; thickening the border without reducing padding, making text jitter
- Borders and corners: `border-radius` past half the height gives a circle; each corner can be set separately
- Input focus: :focus changes the border color and padding must shrink with it; ::placeholder styles the placeholder
- Gradients: `qlineargradient` / `qradialgradient`, with `stop` controlling the color breaks

- Increase the padding by 1px when the border becomes 2px
- Decrease the padding by 1px when the border becomes 2px, keeping the text position stable
- Set border-radius to 0
- Hide the border on focus
answer: 1
explain: Going from 1px to 2px takes 1px of interior space and shifts the text. Decrease the padding by 1px to compensate (or use the outline property, which takes no layout space). Increasing padding makes the text more cramped.
