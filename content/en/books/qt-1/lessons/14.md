# QListWidget and QTableWidget

> Lists and tables are the most common data display formats in any GUI. This lesson covers two "item-based" widgets: QListWidget for one-dimensional lists and QTableWidget for two-dimensional tables. Their APIs are nearly identical — learn one and you'll grasp the other instantly.

## QListWidget: One-Dimensional List

**QListWidget is a list widget where each row is a QListWidgetItem.**

```
from PySide6.QtWidgets import QListWidget, QListWidgetItem

list_widget = QListWidget()
list_widget.addItem("Apple")
list_widget.addItem("Banana")
list_widget.addItem("Orange")
```

**`addItem(text)` adds one row of text; `addItems(list)` adds multiple rows at once:**

```
fruits = ["Apple", "Banana", "Orange", "Grape", "Watermelon"]
list_widget.addItems(fruits)
```

**`QListWidgetItem` is the list item object — it can carry extra data:**

```
item = QListWidgetItem("Apple")
item.setData(1, "apple")       # role 1 = UserRole, store an identifier
list_widget.addItem(item)

# Reading
current = list_widget.currentItem()
if current:
    print(current.text())           # "Apple"
    print(current.data(1))          # "apple"
```

**`currentItemChanged` fires when the selected item changes:**

```
list_widget.currentItemChanged.connect(
    lambda current, previous: print("Selected:", current.text() if current else "None")
)
```

**`itemClicked` fires when an item is clicked, passing the clicked item:**

```
list_widget.itemClicked.connect(lambda item: print("Clicked:", item.text()))
```

## Crash Site 1: Forgot to set selection mode, expected multi-select

**Symptom: holding Ctrl to multi-select only lets you pick one.**

```
list_widget = QListWidget()
list_widget.addItems(["A", "B", "C"])
# default selectionMode is SingleSelection — single selection only
```

**Fix: set the selection mode to `ExtendedSelection`:**

```
from PySide6.QtWidgets import QAbstractItemView

list_widget.setSelectionMode(QAbstractItemView.ExtendedSelection)
# now Ctrl+click for multi-select, Shift+click for range select
```

**Common selection modes:**
- `SingleSelection`: one only (default)
- `MultiSelection`: click to toggle selection
- `ExtendedSelection`: Ctrl/Shift multi-select (most common)
- `NoSelection`: not selectable

## QListWidget CRUD

**Adding rows:**

```
list_widget.addItem("New fruit")              # append at end
list_widget.insertItem(0, "First")        # insert at index 0
```

**Removing the selected row:**

```
def remove_selected():
    row = list_widget.currentRow()
    if row >= 0:
        list_widget.takeItem(row)          # takeItem removes and returns the item

remove_btn.clicked.connect(remove_selected)
```

**`takeItem(row)` removes the given row and returns the QListWidgetItem.** Note: it's not `deleteItem` — Qt doesn't auto-free the memory.

**Changing a row's text:**

```
item = list_widget.item(0)                 # get row 0
if item:
    item.setText("Modified text")
```

**Iterating over all rows:**

```
for i in range(list_widget.count()):
    item = list_widget.item(i)
    print(f"Row {i}: {item.text()}")
```

## QTableWidget: Two-Dimensional Table

**QTableWidget is a table widget with rows and columns. Each cell is a QTableWidgetItem.**

**Classic pitfall: you MUST set the column count before QTableWidget will display any data!**

```
from PySide6.QtWidgets import QTableWidget, QTableWidgetItem

table = QTableWidget()

# WRONG: setting data without setting column count
table.setItem(0, 0, QTableWidgetItem("Alice"))
table.setItem(0, 1, QTableWidgetItem("25"))
# runs but the table is empty — nothing displays, no error!
```

**CORRECT: set row count, column count, then headers:**

```
table = QTableWidget()
table.setColumnCount(3)                              # MUST! 3 columns
table.setHorizontalHeaderLabels(["Name", "Age", "City"])  # set headers
table.setRowCount(3)                                 # 3 rows

table.setItem(0, 0, QTableWidgetItem("Alice"))
table.setItem(0, 1, QTableWidgetItem("25"))
table.setItem(0, 2, QTableWidgetItem("Beijing"))

table.setItem(1, 0, QTableWidgetItem("Bob"))
table.setItem(1, 1, QTableWidgetItem("30"))
table.setItem(1, 2, QTableWidgetItem("Shanghai"))

table.setItem(2, 0, QTableWidgetItem("Carol"))
table.setItem(2, 1, QTableWidgetItem("28"))
table.setItem(2, 2, QTableWidgetItem("Guangzhou"))
```

**`setColumnCount(n)` sets the column count, `setRowCount(n)` sets the row count, `setHorizontalHeaderLabels(list)` sets the header text.**

**Order matters: set column count → then headers → then data.** If you call `setItem` before `setColumnCount`, the data might survive (depending on version), but headers must come after `setColumnCount` or they won't show.

## Crash Site 2: setHorizontalHeaderLabels before setColumnCount

**Symptom: header text doesn't appear — the top of the table is blank.**

```
table = QTableWidget()
table.setHorizontalHeaderLabels(["Name", "Age", "City"])  # WRONG: headers first
table.setColumnCount(3)                                   # column count second
table.setItem(0, 0, QTableWidgetItem("Alice"))
# headers don't display
```

**Why: `setColumnCount` resets the headers.** When `setColumnCount(3)` is called, Qt rebuilds the horizontal header model, clearing the labels set earlier via `setHorizontalHeaderLabels`.

**CORRECT order:**

```
table.setColumnCount(3)                              # column count first
table.setHorizontalHeaderLabels(["Name", "Age", "City"])  # headers second
table.setItem(0, 0, QTableWidgetItem("Alice"))          # data last
```

## Table CRUD

**Dynamically adding a row:**

```
def add_row():
    row = table.rowCount()                # current row count
    table.insertRow(row)                  # insert new row at end
    table.setItem(row, 0, QTableWidgetItem(f"New person {row}"))
    table.setItem(row, 1, QTableWidgetItem("20"))
    table.setItem(row, 2, QTableWidgetItem("Unknown"))

add_btn.clicked.connect(add_row)
```

**Removing the selected row:**

```
def remove_row():
    current_row = table.currentRow()
    if current_row >= 0:
        table.removeRow(current_row)

remove_btn.clicked.connect(remove_row)
```

**Reading an entire row:**

```
def read_row(row):
    data = []
    for col in range(table.columnCount()):
        item = table.item(row, col)
        data.append(item.text() if item else "")
    return data

print(read_row(0))    # ["Alice", "25", "Beijing"]
```

**`table.item(row, col)` may return None!** If that cell was never `setItem`'d, `item()` returns None — calling `.text()` directly crashes.

## Table Signals

**Cell content changed: `cellChanged(row, col)`**

```
table.cellChanged.connect(
    lambda row, col: print(f"Row {row} col {col} changed")
)
```

**Note: `setItem` also triggers `cellChanged`!** If you want to bulk-fill data without firing the signal, use `blockSignals`:

```
table.blockSignals(True)
table.setItem(0, 0, QTableWidgetItem("New value"))
table.blockSignals(False)
```

**Current cell changed: `currentCellChanged`**

```
table.currentCellChanged.connect(
    lambda row, col, prev_row, prev_col: print(f"Moved to row {row}")
)
```

## Complete Example: Student Information Manager

**List display + table CRUD + search filter:**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QTableWidget, QTableWidgetItem,
    QPushButton, QLineEdit, QVBoxLayout, QHBoxLayout, QLabel
)

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("Student Manager")
window.resize(500, 400)

table = QTableWidget()
table.setColumnCount(3)
table.setHorizontalHeaderLabels(["Name", "Age", "Score"])
table.setRowCount(0)

# Input area
name_edit = QLineEdit()
name_edit.setPlaceholderText("Name")
age_edit = QLineEdit()
age_edit.setPlaceholderText("Age")
score_edit = QLineEdit()
score_edit.setPlaceholderText("Score")

# Buttons
add_btn = QPushButton("Add")
del_btn = QPushButton("Delete Selected")
search_edit = QLineEdit()
search_edit.setPlaceholderText("Search by name...")

def add_student():
    row = table.rowCount()
    table.insertRow(row)
    table.setItem(row, 0, QTableWidgetItem(name_edit.text()))
    table.setItem(row, 1, QTableWidgetItem(age_edit.text()))
    table.setItem(row, 2, QTableWidgetItem(score_edit.text()))
    name_edit.clear()
    age_edit.clear()
    score_edit.clear()

def delete_student():
    row = table.currentRow()
    if row >= 0:
        table.removeRow(row)

def search():
    keyword = search_edit.text().lower()
    for row in range(table.rowCount()):
        item = table.item(row, 0)
        match = item and keyword in item.text().lower()
        table.setRowHidden(row, not match)    # hide non-matching rows

add_btn.clicked.connect(add_student)
del_btn.clicked.connect(delete_student)
search_edit.textChanged.connect(search)

# Layout
input_layout = QHBoxLayout()
input_layout.addWidget(name_edit)
input_layout.addWidget(age_edit)
input_layout.addWidget(score_edit)
input_layout.addWidget(add_btn)

btn_layout = QHBoxLayout()
btn_layout.addWidget(del_btn)
btn_layout.addWidget(QLabel("Search:"))
btn_layout.addWidget(search_edit)

main = QVBoxLayout(window)
main.addLayout(input_layout)
main.addLayout(btn_layout)
main.addWidget(table)

window.show()
app.exec()
```

**`setRowHidden(row, True/False)` can hide a specific row — that's how search filtering works.**

## Summary

- QListWidget: one-dimensional list; addItem/addItems adds data; currentItemChanged listens for selection
- For multi-select, set selectionMode to ExtendedSelection
- CRUD: addItem/insertItem/takeItem/setItem + item(row) to read
- QTableWidget: two-dimensional table; MUST setColumnCount + setHorizontalHeaderLabels first
- Classic pitfall: no column count → no data display; setHorizontalHeaderLabels must come AFTER setColumnCount
- table.item(row, col) may return None — check before accessing
- setRowHidden for search filtering; blockSignals to avoid code-triggered signals
