# QTextEdit and QPlainTextEdit: Multi-Line Text

> Single-line input uses QLineEdit; multi-line uses QTextEdit or QPlainTextEdit. The difference is "do you need rich text?": QTextEdit supports fonts, colors, and images (rich text), while QPlainTextEdit handles only plain text but is faster. This lesson covers how to choose, how to use them, and how to connect the textChanged signal.

## QTextEdit: Rich Text Editor

**QTextEdit supports bold, color, fonts, and images — a mini Word.**

```
from PySide6.QtWidgets import QTextEdit

editor = QTextEdit()
editor.setPlainText("This is plain text content")     # set plain text
editor.setHtml("<b>bold</b> and <i>italic</i>")   # set rich text
```

**`setPlainText` treats content as plain text; `setHtml` parses and renders the HTML tags.**

**Two ways to retrieve content:**

```
print(editor.toPlainText())    # text only, drops styling: "bold and italic"
print(editor.toHtml())         # full HTML including style tags
```

**Generally use `toPlainText()` for editors, and `setHtml()` or `append()` for chat logs.**

## QPlainTextEdit: Plain Text, Faster

**QPlainTextEdit handles only plain text — no rich text rendering, better performance.**

```
from PySide6.QtWidgets import QPlainTextEdit

editor = QPlainTextEdit()
editor.setPlainText("Line 1\nLine 2\nLine 3")
print(editor.toPlainText())
```

**How to choose?**

| Scenario | Use |
|---|---|
| Code, logs, notes (plain text) | QPlainTextEdit |
| Chat logs, rich text display | QTextEdit |
| Need bold/color/images | QTextEdit |
| Very large text (100k+ lines) | QPlainTextEdit (clear performance advantage) |

**Use QPlainTextEdit for code editors (like the simple editor in Lesson 7). Use QTextEdit for chat message areas.**

## Read-Only Mode

**`setReadOnly(True)` makes the editor read-only (scrollable, selectable, copyable, but not editable):**

```
editor = QTextEdit()
editor.setReadOnly(True)
editor.setPlainText("This is read-only agreement text...")
```

**Common uses: user agreements, log viewers, chat history.**

**Crash site: using setEnabled(False) makes even copying impossible:**

```
editor.setReadOnly(True)      # CORRECT: scrollable and copyable
editor.setEnabled(False)      # WRONG: completely greyed out, no interaction
```

**For "view but don't edit", use setReadOnly — not setEnabled(False).**

## Appending Content

**`append` adds a line at the end (available on both QTextEdit and QPlainTextEdit):**

```
editor = QTextEdit()
editor.append("First message")      # append with newline
editor.append("Second message")
```

**QPlainTextEdit's appendPlainText:**

```
editor = QPlainTextEdit()
editor.appendPlainText("Log line 1")
editor.appendPlainText("Log line 2")
```

**Common pattern for a log viewer:**

```
import datetime

def log(msg):
    now = datetime.datetime.now().strftime("%H:%M:%S")
    editor.append(f"[{now}] {msg}")
```

## The textChanged Signal

**`textChanged` fires when content changes, with no arguments:**

```
editor.textChanged.connect(lambda: print("Content changed"))
```

**If you need the new content, read it yourself inside the slot:**

```
def on_text_changed():
    current = editor.toPlainText()
    print("Current content:", current)

editor.textChanged.connect(on_text_changed)
```

**This signal carries no arguments — unlike QLineEdit's `textChanged(str)`.** Don't write `lambda text: ...` — text will be None or raise an error.

## Crash Site 1: textChanged slot has an extra parameter

**Symptom: crashes on the first keystroke.**

```
editor.textChanged.connect(lambda text: print(text))   # error!
```

**Error message:** `TypeError: <lambda>() missing 1 required positional argument: 'text'`

**Why: QTextEdit.textChanged carries no arguments, but the lambda defines a parameter `text`, so nothing is passed when called.**

**Fix:**

```
editor.textChanged.connect(lambda: print(editor.toPlainText()))   # correct
```

**Or write a regular function and read inside it:**

```
def on_changed():
    print(editor.toPlainText())

editor.textChanged.connect(on_changed)
```

## Cursor and Selected Text

**`textCursor()` gets the cursor object for selection, insertion, etc.:**

```
cursor = editor.textCursor()
cursor.select(QTextCursor.SelectionType.Document)   # select all
editor.setTextCursor(cursor)
```

**`selectedText()` retrieves the selected text:**

```
selected = editor.textCursor().selectedText()
print("User selected:", selected)
```

**`insertPlainText` inserts at the cursor position:**

```
editor.insertPlainText("New content")
```

## Crash Site 2: Trying to clear content with the wrong property

**Symptom: content won't clear or raises an error.**

```
editor.setText("")         # CORRECT: set to empty string
editor.clear()            # also CORRECT: QTextEdit has a clear method
```

**Both work — either is fine. `clear()` is more semantic.**

**The more subtle problem:**

```
editor.setText(None)      # error! None is not a string
```

**Fix: pass an empty string `""`, not None.**

## Font Size and Font

**`setFontPointSize` sets the font size (QTextEdit supports rich text font operations):**

```
editor.setFontPointSize(14)
```

**`setFontWeight(QFont.Weight.Bold)` for bold:**

```
from PySide6.QtGui import QFont
editor.setFontWeight(QFont.Weight.Bold)
```

**QPlainTextEdit doesn't support per-character styling** — change the entire editor's font uniformly:

```
from PySide6.QtGui import QFont
font = QFont("Consolas", 12)      # font name + size
editor.setFont(font)
```

**Code editors commonly use monospace fonts: Consolas / Menlo / DejaVu Sans Mono.**

## Complete Example: A Simple Notepad

**Title + body + live character count:**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QLineEdit, QPlainTextEdit, QLabel, QVBoxLayout
)

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("Simple Notepad")
window.resize(500, 400)

title_edit = QLineEdit()
title_edit.setPlaceholderText("Title")

body_edit = QPlainTextEdit()
body_edit.setPlaceholderText("Body...")

counter = QLabel("0 chars")
counter.setAlignment(Qt.AlignmentFlag.AlignRight)

def update_count():
    text = body_edit.toPlainText()
    counter.setText(f"{len(text)} chars")

body_edit.textChanged.connect(update_count)

layout = QVBoxLayout(window)
layout.addWidget(title_edit)
layout.addWidget(body_edit, 1)
layout.addWidget(counter)

window.show()
app.exec()
```

**`layout.addWidget(body_edit, 1)` — the `1` is the stretch**, making the body area fill the remaining space. The character count uses `len(text)` — each Chinese character counts as one.

## Summary

- QTextEdit supports rich text (fonts, colors, images); QPlainTextEdit handles plain text but is faster
- Use QPlainTextEdit for code/logs, QTextEdit for chat logs/rich text
- setReadOnly(True) makes an editor "view but not edit" — don't use setEnabled(False)
- append / appendPlainText adds a line
- textChanged carries no arguments — read the content yourself inside the slot
- setText("") or clear() both clear content
- Character count: len(editor.toPlainText())
