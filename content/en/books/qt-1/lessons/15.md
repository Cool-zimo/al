# QSlider, QSpinBox, and QProgressBar

> Numeric input and progress feedback are staples of any GUI. QSlider is a draggable slider, QSpinBox is a numeric input box, and QProgressBar is a progress bar — link the three together and you have the classic signal-slot use case.

## QSlider: The Slider

**QSlider is a slider control — drag it to change an integer value.**

```
from PySide6.QtWidgets import QSlider
from PySide6.QtCore import Qt

slider = QSlider(Qt.Horizontal)    # horizontal
slider.setMinimum(0)               # minimum value
slider.setMaximum(100)            # maximum value
slider.setValue(50)               # current value
print(slider.value())             # 50
```

**`Qt.Horizontal` is a horizontal slider; `Qt.Vertical` is vertical.**

**The `valueChanged(int)` signal fires when the value changes:**

```
slider.valueChanged.connect(lambda val: print("Current value:", val))
```

**Range can also be set in one step:**

```
slider.setRange(0, 255)    # equivalent to setMinimum(0) + setMaximum(255)
```

**`setTickPosition` displays tick marks:**

```
slider.setTickPosition(QSlider.TicksBelow)    # ticks below
slider.setTickInterval(10)                     # tick every 10
```

## Crash Site 1: Signal loop causing infinite recursion

**Symptom: drag slider → updates SpinBox → SpinBox's valueChanged updates slider → infinite loop.**

```
slider = QSlider(Qt.Horizontal)
slider.setRange(0, 100)
spin = QSpinBox()
spin.setRange(0, 100)

# Bidirectional connection — potentially recursive
slider.valueChanged.connect(lambda v: spin.setValue(v))   # slider → spin
spin.valueChanged.connect(lambda v: slider.setValue(v))    # spin → slider
```

**When the slider changes → spin.setValue(v) → spin emits valueChanged → slider.setValue(v) → slider emits valueChanged again...**

**It looks like an infinite loop, but it won't actually crash in practice.** Because `setValue` only emits a signal when the value truly changes — if the new value equals the current value, it won't fire again. So the code above actually runs, but the logic is redundant.

**A better approach: use signal arguments to determine the source, or distinguish between `valueChanged`'s int and str overloads.** In most cases, bidirectional connect won't cause problems, but keep it in mind.

## QSpinBox: Numeric Input Box

**QSpinBox is an integer spinner with up/down arrows.**

```
from PySide6.QtWidgets import QSpinBox

spin = QSpinBox()
spin.setRange(0, 100)          # range 0~100
spin.setSingleStep(5)          # increment/decrement by 5
spin.setValue(20)              # current value
spin.setPrefix("$ ")           # prefix: $ 20
spin.setSuffix(" USD")           # suffix: 20 USD
```

**`valueChanged(int)` emits an int; `textChanged(str)` emits the full text with prefix/suffix:**

```
spin.valueChanged.connect(lambda v: print("Value:", v))
spin.textChanged.connect(lambda t: print("Text:", t))    # "$ 20 USD"
```

**Setting a special value display:**

```
spin.setSpecialValueText("Auto")    # when value equals minimum, show "Auto"
spin.setRange(0, 100)
spin.setValue(0)    # shows "Auto" instead of "0"
```

## QProgressBar: Progress Bar

**QProgressBar displays task progress as a 0~100 percentage.**

```
from PySide6.QtWidgets import QProgressBar

bar = QProgressBar()
bar.setRange(0, 100)       # default is 0~100
bar.setValue(35)           # shows 35%
```

**Three progress bar modes:**

```
# Mode 1: determinate progress (default)
bar.setRange(0, 100)
bar.setValue(50)

# Mode 2: indeterminate progress (busy animation)
bar.setRange(0, 0)          # minimum == maximum → indeterminate mode
# shows a bar animating back and forth

# Mode 3: back to determinate
bar.setRange(0, 100)
```

**`setFormat` customizes the text:**

```
bar.setFormat("Completed %p%")      # %p = percentage, %v = current value
bar.setValue(75)                 # shows "Completed 75%"
```

## Linking the Three: Signal-Slot in Action

**Core idea: drag slider → spin box follows → progress bar follows.**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QSlider, QSpinBox,
    QProgressBar, QVBoxLayout, QLabel
)
from PySide6.QtCore import Qt

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("Linked Values")
window.resize(300, 150)

slider = QSlider(Qt.Horizontal)
slider.setRange(0, 100)

spin = QSpinBox()
spin.setRange(0, 100)

bar = QProgressBar()
bar.setRange(0, 100)

label = QLabel("Current value: 50")

# Slider → spin box + progress bar + label
slider.valueChanged.connect(spin.setValue)
slider.valueChanged.connect(bar.setValue)
slider.valueChanged.connect(lambda v: label.setText(f"Current value: {v}"))

# Spin box → slider + progress bar + label
spin.valueChanged.connect(slider.setValue)
spin.valueChanged.connect(bar.setValue)
spin.valueChanged.connect(lambda v: label.setText(f"Current value: {v}"))

# Set initial value (via slider so others update too)
slider.setValue(50)

main = QVBoxLayout(window)
main.addWidget(label)
main.addWidget(slider)
main.addWidget(spin)
main.addWidget(bar)

window.show()
app.exec()
```

**Signal chain: the slider's valueChanged connects to spin.setValue, bar.setValue, and a label update — one signal triggers three actions.**

**The reverse works the same way: when the spin box value changes, spin.valueChanged connects back to slider.setValue, keeping both in sync.**

## Crash Site 2: setRange set, but setValue exceeds the range

**Symptom: progress bar always shows 0% or doesn't update.**

```
bar = QProgressBar()
bar.setRange(0, 100)
bar.setValue(150)       # exceeds maximum
# progress bar shows 100% (clamped to upper limit)
```

**Why: `setValue` clamps out-of-range values to `[minimum, maximum]`.** If the progress bar won't update, first check whether `value()` is within range:

```
print("range:", bar.minimum(), "~", bar.maximum())
print("value:", bar.value())
```

**The more common trap: forgetting `setRange` and calling `setValue`:**

```
bar = QProgressBar()
bar.setValue(50)
# progress bar default range is 0~100, so this is fine
```

**But if your progress is a 0~1 decimal (e.g. download progress), you must change the range:**

```
bar = QProgressBar()
bar.setRange(0, 100)
# passing 0.5 fails because QProgressBar only accepts integers
# solution: multiply by 100 and convert to int
bar.setValue(int(0.5 * 100))    # 50%
```

## Advanced: Simulating Progress with a Timer

**`QTimer` triggers on a schedule to simulate task progress:**

```
from PySide6.QtCore import QTimer

bar = QProgressBar()
bar.setRange(0, 100)

timer = QTimer()
timer.setInterval(50)    # fire every 50ms

def on_tick():
    value = bar.value() + 1
    bar.setValue(value)
    if value >= 100:
        timer.stop()

timer.timeout.connect(on_tick)
timer.start()    # start the timer
```

**`QTimer.singleShot` delays a one-time execution:**

```
QTimer.singleShot(2000, lambda: label.setText("2 seconds elapsed!"))
```

## Complete Example: Volume Controller

**Slider + spin box + progress bar + color changes:**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QSlider, QSpinBox,
    QProgressBar, QLabel, QVBoxLayout, QHBoxLayout
)
from PySide6.QtCore import Qt

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("Volume Control")
window.resize(350, 200)

title = QLabel("Volume Control")
title.setStyleSheet("font-size: 18px; font-weight: bold;")

slider = QSlider(Qt.Horizontal)
slider.setRange(0, 100)
slider.setTickPosition(QSlider.TicksBelow)
slider.setTickInterval(10)

spin = QSpinBox()
spin.setRange(0, 100)
spin.setSuffix("%")

bar = QProgressBar()
bar.setRange(0, 100)
bar.setFormat("%p%")

status = QLabel("Status: Medium")

def update_all(value):
    bar.setValue(value)
    if value == 0:
        status.setText("Muted")
        bar.setStyleSheet("")
    elif value < 30:
        status.setText("Low")
        bar.setStyleSheet("QProgressBar::chunk { background-color: #4CAF50; }")
    elif value < 70:
        status.setText("Medium")
        bar.setStyleSheet("QProgressBar::chunk { background-color: #FFC107; }")
    else:
        status.setText("High")
        bar.setStyleSheet("QProgressBar::chunk { background-color: #F44336; }")

slider.valueChanged.connect(spin.setValue)
slider.valueChanged.connect(update_all)
spin.valueChanged.connect(slider.setValue)

slider.setValue(50)

row = QHBoxLayout()
row.addWidget(slider)
row.addWidget(spin)

main = QVBoxLayout(window)
main.addWidget(title)
main.addLayout(row)
main.addWidget(bar)
main.addWidget(status)

window.show()
app.exec()
```

**Dynamically changing the progress bar color with `setStyleSheet` makes visual feedback more intuitive.**

## Summary

- QSlider: setRange/setValue, valueChanged(int) signal, Horizontal/Vertical orientation
- QSpinBox: setRange/setSingleStep/setPrefix/setSuffix; valueChanged has int and str overloads
- QProgressBar: setRange + setValue; range(0,0) = indeterminate mode
- Linking: connect one widget's valueChanged to other widgets' setValue
- QTimer simulates progress: timeout signal + start/stop
- setStyleSheet dynamically changes styles for color feedback
