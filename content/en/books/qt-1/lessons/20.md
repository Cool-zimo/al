# QAction: Define Once, Mount Anywhere

> A `QAction` is an "action" object: one logical operation that can live in both a menu and a toolbar, complete with icon and shortcut. It is the shared atom of menus and toolbars.

## What Is a QAction?

**`QAction` turns an operation into an object: name, icon, shortcut, and state — defined once, used in many places.**

```
from PySide6.QtGui import QAction

open_action = QAction("Open", self)
open_action.setShortcut("Ctrl+O")
open_action.setStatusTip("Open a file")    # shown in the status bar on hover
open_action.triggered.connect(self.open_file)
```

**One `open_action` can go into both the menu and the toolbar — no need to write it twice.**

```
file_menu.addAction(open_action)
toolbar.addAction(open_action)
```

**In the menu it shows text; in the toolbar it shows its icon (if it has one).** The text and the icon are independent.

## Define Once, Share Between Menu and Toolbar

**The full pattern: define actions centrally, then dispatch them to the menu and toolbar.**

```
from PySide6.QtGui import QAction, QIcon
from PySide6.QtWidgets import QMainWindow, QToolBar

class MainWindow(QMainWindow):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("Editor")
        self.resize(500, 350)

        # define actions
        self.open_action = QAction("Open", self)
        self.open_action.setShortcut("Ctrl+O")
        self.open_action.setStatusTip("Open a file")
        self.open_action.triggered.connect(self.open_file)

        self.save_action = QAction("Save", self)
        self.save_action.setShortcut("Ctrl+S")
        self.save_action.triggered.connect(self.save_file)

        self.quit_action = QAction("Quit", self)
        self.quit_action.setShortcut("Ctrl+Q")
        self.quit_action.triggered.connect(self.close)

        # menu bar
        menubar = self.menuBar()
        file_menu = menubar.addMenu("File(&F)")
        file_menu.addAction(self.open_action)
        file_menu.addAction(self.save_action)
        file_menu.addSeparator()
        file_menu.addAction(self.quit_action)

        # toolbar
        toolbar = QToolBar("File")
        self.addToolBar(toolbar)
        toolbar.addAction(self.open_action)
        toolbar.addAction(self.save_action)

    def open_file(self):
        self.statusBar().showMessage("Open file", 2000)

    def save_file(self):
        self.statusBar().showMessage("Save file", 2000)
```

**The payoff: the shortcut works in both the menu item and the toolbar button automatically; change it in one place and it changes everywhere — no duplicated logic.**

## Crash Site #1: You Create a QAction but Forget addAction — Nothing Appears

**Symptom: you clearly created a `QAction`, yet the menu and toolbar are empty at runtime.**

```
self.save_action = QAction("Save", self)
self.save_action.setShortcut("Ctrl+S")
# forgot addAction - the action was never mounted anywhere
```

**Why: a `QAction` only *defines* the action; it does not display itself.** You must explicitly call `menu.addAction(action)` or `toolbar.addAction(action)` to make it visible.

**✅ Correct: always mount it after defining it.**

```
self.save_action = QAction("Save", self)
self.save_action.triggered.connect(self.save_file)

file_menu.addAction(self.save_action)    # mount in the menu
toolbar.addAction(self.save_action)      # and in the toolbar
```

**Likewise, when you write `file_menu.addAction("Save")` with a bare string, Qt builds a temporary `QAction` for you behind the scenes — you get no reference to it, so you cannot set a shortcut or status tip. To do that you must create the `QAction` explicitly.**

## Shortcuts and Icons

**`setShortcut` accepts the plain form or a `QKeySequence` constant:**

```
open_action.setShortcut("Ctrl+O")
save_action.setShortcut("Ctrl+S")
quit_action.setShortcut(QKeySequence.Quit)    # the cross-platform standard quit shortcut
```

**`QKeySequence.Quit` is `Cmd+Q` on macOS and `Ctrl+Q` on Windows/Linux — a constant beats a hard-coded string.**

**`setIcon` gives the action an icon; the toolbar shows it, and the menu gets a small icon too:**

```
open_action.setIcon(QIcon("open.png"))
```

**Icon size is controlled uniformly by the toolbar's `setIconSize`:**

```
toolbar.setIconSize(QSize(24, 24))
```

**If you want text but no icon, force the toolbar to show text:**

```
toolbar.setToolButtonStyle(Qt.ToolButtonTextOnly)
```

**The four `ToolButtonStyle` options: `ToolButtonIconOnly` (default), `ToolButtonTextOnly`, `ToolButtonTextBesideIcon`, `ToolButtonTextUnderIcon`.**

## Crash Site #2: setShortcut Misspelled as setKeySequence — and Nothing Works

**Symptom: you try to set a shortcut, mistype the method name, and the shortcut is completely dead — silently.**

```
self.save_action.setKeySequence("Ctrl+S")    # WRONG - wrong method name, fails silently
```

**Why: the method on `QAction` is `setShortcut`, not `setKeySequence`.** The former accepts both strings and `QKeySequence`; the latter simply does not exist, so depending on the binding you get an `AttributeError` or total silence.

**✅ Correct:**

```
self.save_action.setShortcut("Ctrl+S")
# or
self.save_action.setShortcut(QKeySequence("Ctrl+S"))
```

**Multiple shortcuts: `setShortcuts` accepts a list:**

```
self.save_action.setShortcuts(["Ctrl+S", "Ctrl+Shift+S"])
```

## Disabling and Visibility

**`setEnabled(False)` grays out the action; both the menu item and the toolbar button go gray together.**

```
self.save_action.setEnabled(False)    # disable Save when there is nothing to save
# re-enable once editing starts
self.editor.textChanged.connect(lambda: self.save_action.setEnabled(True))
```

**`setVisible(False)` hides it entirely, including the space it occupied.**

```
self.advanced_action.setVisible(False)    # hide advanced features in normal mode
```

**Both states stay in sync across the menu and toolbar because they share one underlying `QAction` object.**

## Summary

- `QAction` abstracts an "action": define it once, share it between menu and toolbar
- `setShortcut` for shortcuts, `setStatusTip` for hover hints, `setIcon` for icons
- ⚠️ Classic trap: creating a `QAction` but forgetting `addAction` leaves the UI empty
- `QKeySequence.Quit` is more portable than a hard-coded shortcut string
- `setEnabled` / `setVisible` stay in sync in both menu and toolbar
- Toolbar button style via `setToolButtonStyle`; icon size via `setIconSize`
