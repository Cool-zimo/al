# Setting Up Your Environment and Your First Window

> tkinter comes with Python — install Python and you're done. PySide6 needs a separate install, and its windows require an explicit "event loop" to stay alive. This lesson gets your environment ready, opens your first window, and drills the one line people forget: `app.exec()`.

## Installing PySide6

**One command does it:**

```
pip install PySide6
```

After installing, verify the version in a terminal — if it imports cleanly, you're set:

```python
import PySide6
print(PySide6.__version__)   # e.g. 6.5.2
from PySide6 import QtCore
print(QtCore.qVersion())     # underlying Qt version, e.g. 6.5.2
```

**Two version numbers, two different things:** `PySide6.__version__` is the version of the Python binding package; `QtCore.qVersion()` is the version of the underlying C++ Qt library. They usually match, but sometimes differ by a patch number.

**Virtual environments are a good habit.** Create a venv for each project so conflicting Qt versions don't trip you up:

```
python -m venv .venv
source .venv/bin/activate    # On Windows: .venv\Scripts\activate
pip install PySide6
```

**If pip is slow**, use a mirror: `pip install PySide6 -i https://pypi.tuna.tsinghua.edu.cn/simple`. The package is roughly 100+ MB because it bundles the Qt runtime — be patient.

## The First Window: Four Steps

**Every PySide6 program follows the same skeleton: create app → create window → show → enter loop.**

```
import sys
from PySide6.QtWidgets import QApplication, QWidget

app = QApplication(sys.argv)        # Step 1: the application object, mandatory

window = QWidget()                  # Step 2: a window; QWidget is the most basic widget
window.setWindowTitle("My First Qt Window")
window.resize(400, 300)             # width 400, height 300

window.show()                       # Step 3: make it visible
app.exec()                          # Step 4: event loop — blocks here, waiting for user input
```

**`QApplication(sys.argv)` takes a list of strings** used to receive command-line arguments (e.g. `-style fusion` to set the theme). Omitting it raises an error — that's Qt's rule.

**`QWidget` is the ancestor of every UI widget:** buttons, labels, input boxes — all are subclasses of QWidget. Using it as a window gives you the cleanest possible empty shell.

**`resize(400, 300)` sets the client area** — excluding the title bar and borders — in pixels. You can also use `setGeometry(100, 100, 400, 300)`, where the first two numbers are screen coordinates (top-left corner of the window) and the last two are width and height.

## Crash Site 1: Forgetting app.exec(), the window flashes and dies

**This is the #1 pitfall for anyone coming from tkinter.** tkinter's `root.mainloop()` is unforgettable because it's the last line; Qt's `app.exec()` is your responsibility, and omitting it makes the window vanish instantly.

```
import sys
from PySide6.QtWidgets import QApplication, QWidget

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("A window that flashes and dies")
window.show()
# app.exec()   <- Forgotten!
print("Program ended")
```

**Symptom:** the window flashes on screen for a split second and closes immediately; the console prints "Program ended".

**Why:** `show()` only *schedules* the window for display — it does not start a loop that waits for events. The program reaches the last line, exits, the process dies, and the window is destroyed with it.

**Fix:** always put `app.exec()` as the very last line of your main flow. Treat it as the exact equivalent of `mainloop()` — write it *before* filling in the rest of your logic so you never forget.

**Bonus:** in Qt 6 the correct spelling is `app.exec()` (no trailing `u`). Old tutorials use `app.exec_()`, which is PyQt5 / Qt 5 syntax and raises `AttributeError` in PySide6.

## Crash Site 2: Creating Multiple QApplication Instances

**There can be only one `QApplication` per process.** Creating a second one crashes immediately.

```
from PySide6.QtWidgets import QApplication, QWidget
import sys

app1 = QApplication(sys.argv)
app2 = QApplication(sys.argv)    # Crash!
```

**Error message:** `QApplication: There should be only one application object`.

**Why:** Qt's internals are singleton-based — the event queue, clipboard, and screen info all hang off the single QApplication. A second instance leaves Qt not knowing which one to listen to.

**Fix:** create it once in a module-level function, or guard the entry point with `QApplication.instance()`:

```python
app = QApplication.instance() or QApplication(sys.argv)
```

**This also bites when mixing test code and real programs:** pytest loads multiple test modules, each creating its own app. Solve it with a fixture in `conftest.py` that builds the app once and reuses it.

## Crash Site 3: Setting properties after show(), changes don't appear

**You can still mutate properties after `show()`, but some changes need a manual refresh.**

```
window = QWidget()
window.resize(400, 300)
window.show()
window.setWindowTitle("Change the title")   # sometimes has no effect
```

**Why:** `show()` sends a display request; Qt paints for real inside the event loop. If you change the title immediately after `show()`, you may miss the first paint cycle.

**Fix:** **set all properties first, then call `show()` last.** Build the habit of "configure first, display at the end". That said, if you need to change the title at runtime (e.g. showing download progress), `setWindowTitle` works fine — Qt repaints automatically. The example above is just a reminder that order matters.

## Common Window Settings

**Beyond the title and size, a few settings are worth memorizing:**

```
window.setWindowTitle("Expense Tracker")
window.resize(480, 320)
window.setMinimumSize(320, 240)    # minimum size — user can't drag smaller than this
window.setMaximumSize(800, 600)    # maximum size
window.move(200, 100)              # move to screen coordinates
```

**`setFixedSize(400, 300)` is the most worry-free:** the user can't drag to resize, so your layout can't break. Utility windows (calculators, unit converters) are perfect candidates for fixed sizes.

**`window.setWindowIcon(QIcon("icon.png"))` sets the icon** — 32×32 or 64×64 PNG recommended. We'll cover the resource system in Lesson 4.

## Summary

- Install: `pip install PySide6`, preferably inside a virtual environment
- Four-step skeleton: QApplication → QWidget → show() → app.exec()
- `QApplication(sys.argv)` — only one per process, crashes if duplicated
- **Forgetting `app.exec()` makes the window flash and die** — the #1 crash site for tkinter migrants
- `QWidget` is the base class of all widgets; a bare QWidget makes the cleanest empty window
- Configure properties first, call `show()` last — avoid changes that don't take effect
