# Icons and Fonts

> Icons should be sharp and fonts should look good — and both should stay crisp on a 4K screen. This lesson covers `QIcon`'s multi-resolution mechanism, font settings, and DPI handling.

## QIcon's Multi-Resolution Mechanism

**A `QIcon` can hold several sizes; Qt automatically picks the most suitable one to display.**

```
from PySide6.QtGui import QIcon

icon = QIcon()
icon.addFile("icons/app_16.png", QSize(16, 16))
icon.addFile("icons/app_24.png", QSize(24, 24))
icon.addFile("icons/app_32.png", QSize(32, 32))
icon.addFile("icons/app_64.png", QSize(64, 64))

app.setWindowIcon(icon)
```

**Why multiple sizes: at 100% scaling the toolbar icon uses 24px; at 200% the system asks for 48px, and having a 64px image keeps it sharp instead of stretching.**

**Using `qrc` resources is more convenient — write it once and use it everywhere:**

```
icon = QIcon()
icon.addFile(":/icons/app_16.png", QSize(16, 16))
icon.addFile(":/icons/app_24.png", QSize(24, 24))
icon.addFile(":/icons/app_32.png", QSize(32, 32))
```

**`QIcon` can also distinguish normal from disabled states:**

```
icon = QIcon()
icon.addPixmap(QPixmap(":/icons/save.png"), QIcon.Normal)
icon.addPixmap(QPixmap(":/icons/save_disabled.png"), QIcon.Disabled)
```

**When the button is disabled, the disabled version appears automatically — no manual switching needed.**

## Crash Site #1: Only One Small Icon — Blurry on High DPI

**Symptom: it looks fine on a normal screen, but on a 4K display (200% scaling) the toolbar icons are a blurry mess.**

```
btn.setIcon(QIcon("icons/app_16.png"))    # only a 16px image
```

**Why: with only a 16px image, when the system needs 32px it has to scale it up — which is inherently blurry.** The human eye is especially sensitive to blurry icons.

**✅ Correct: prepare multiple sizes and register them with `addFile`.**

```
icon = QIcon()
for size in (16, 24, 32, 48, 64):
    icon.addFile(f":/icons/app_{size}.png", QSize(size, size))
btn.setIcon(icon)
```

**The minimum viable setup is 1x and 2x (e.g. 24px and 48px).** With a 2x image you cover nearly all 200%-scaling cases.

## Font Settings

**Set a font with `QFont`:**

```
from PySide6.QtGui import QFont

font = QFont()
font.setFamily("Microsoft YaHei")
font.setPointSize(12)
font.setBold(True)
font.setItalic(True)

label.setFont(font)
```

**Passing the arguments directly is more concise:**

```
label.setFont(QFont("Microsoft YaHei", 14, QFont.Bold))
# arguments: family, pointSize, weight, italic
```

**Setting the default font for the whole application:**

```
app = QApplication(sys.argv)
font = QFont("Microsoft YaHei", 10)
app.setFont(font)    # every control defaults to this font
```

**Setting the global font once is enough; individual controls can override it afterward.** Setting `setFont` on every single control makes for very noisy code.

## Font Family Choices

**Common Chinese-capable fonts:**

```
"Microsoft YaHei"      # Microsoft YaHei, the Windows default
"SimHei"               # SimHei (bold)
"SimSun"               # SimSun, a serif body font
"KaiTi"                # KaiTi (楷体)
"DengXian"             # DengXian (等线), default on Win10+
```

**A cross-platform font list: use `setFamilies` with a candidate list, matched in order.**

```
font = QFont()
font.setFamilies(["Microsoft YaHei", "PingFang SC", "Noto Sans CJK SC", "WenQuanYi Micro Hei"])
font.setPointSize(11)
app.setFont(font)
```

**Qt walks the list and picks the first font that is installed.** This list lands on a Chinese-capable font on Windows / macOS / Linux, so you never see tofu boxes.

**Emoji needs a font that covers color glyphs; a normal UI font usually does not, so an empty box is normal behavior.**

## Crash Site #2: The Font Name Is Wrong — Silently Falls Back

**Symptom: you set a font but the interface looks completely unchanged, still showing the system default.**

```
label.setFont(QFont("微软雅黑 Light"))    # this font name probably does not exist
```

**Why: when the font name is wrong Qt does not error — it silently falls back to the default font, and nothing looks wrong.** Your correct code has no visible effect.

**✅ How to check: use `QFontDatabase` to list the available fonts.**

```
from PySide6.QtGui import QFontDatabase

families = QFontDatabase.families()
for f in families:
    if "YaHei" in f or "Hei" in f or "PingFang" in f:
        print(f)
# then use the exact name that was printed
```

**On a Linux server the Chinese fonts may not be installed at all — check `QFontDatabase.families()` before deploying.**

## DPI Handling

**On a high-DPI display, enable automatic scaling:**

```
QApplication.setHighDpiScaleFactorRoundingPolicy(
    Qt.HighDpiScaleFactorRoundingPolicy.PassThrough
)
app = QApplication(sys.argv)
```

**`setHighDpiScaleFactorRoundingPolicy` must be called before creating `QApplication`.** Calling it later has no effect.

**PySide6 reads the system scaling setting by default, but enabling `PassThrough` gives you more precise scaling (e.g. 1.5x instead of being rounded to 1x or 2x).**

**Detecting DPI manually:**

```
screen = app.primaryScreen()
dpi = screen.logicalDotsPerInch()
print(f"DPI: {dpi}")          # 96 = 100%, 192 = 200%
scale = dpi / 96.0
print(f"Scale: {scale}")
```

**Using DPI to scale the font size dynamically:**

```
dpi = app.primaryScreen().logicalDotsPerInch()
base_size = 10
font = QFont("Microsoft YaHei", int(base_size * dpi / 96))
app.setFont(font)
```

**But layout plus Qt 6's default scaling usually does the job well enough — manually computing DPI to set font sizes is usually over-engineering.**

## Summary

- `QIcon` registers multiple sizes with `addFile`; Qt auto-selects the best fit
- ⚠️ Classic traps: only providing a 1x image makes it blurry on high DPI; a wrong font name silently falls back to the default
- The minimum setup is 1x + 2x (24px and 48px)
- Fonts use `QFont`; globally use `app.setFont`; for cross-platform Chinese use a font-family candidate list
- `QFontDatabase.families()` lists the fonts installed on the system
- DPI handling: set `HighDpiScaleFactorRoundingPolicy` before creating `QApplication`
