# Project: A Counter Window

> The first four lessons laid out the concepts. This lesson stitches them together: a counter window where clicking adds 1 and resets to zero. You'll use QVBoxLayout for layout, signals and slots for logic, and QLabel for display — this is what a minimal but complete Qt program looks like.

## What It Looks Like

**Three widgets stacked vertically:**

```
┌──────────────────────┐
│        0             │   ← QLabel showing current count
│                      │
│   [  +1  ]  [Reset]  │   ← Two QPushButton widgets
└──────────────────────┘
```

**Interaction logic:**

- Click "+1" → number increases by 1
- Click "Reset" → number goes back to zero
- At zero it shows large; when non-zero it's bold

## Complete Code

**Read the full version first, then we'll break it down:**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QPushButton,
    QLabel, QVBoxLayout
)
from PySide6.QtCore import Qt

class CounterWindow(QWidget):
    def __init__(self):
        super().__init__()
        self.count = 0
        self.setWindowTitle("Counter")
        self.resize(300, 200)

        self.label = QLabel("0")
        self.label.setAlignment(Qt.AlignmentFlag.AlignCenter)
        font = self.label.font()
        font.setPointSize(48)
        self.label.setFont(font)

        self.btn_plus = QPushButton("+1")
        self.btn_reset = QPushButton("Reset")

        self.btn_plus.clicked.connect(self.on_plus)
        self.btn_reset.clicked.connect(self.on_reset)

        layout = QVBoxLayout(self)
        layout.addWidget(self.label)
        layout.addWidget(self.btn_plus)
        layout.addWidget(self.btn_reset)

    def on_plus(self):
        self.count += 1
        self.label.setText(str(self.count))

    def on_reset(self):
        self.count = 0
        self.label.setText("0")

app = QApplication(sys.argv)
window = CounterWindow()
window.show()
app.exec()
```

**Now let's dissect each part.**

## Part 1: Class Structure

**Organizing a window as a class is the Qt standard**, because slot functions need access to widgets and state (`self.count`, `self.label`).

```
class CounterWindow(QWidget):
    def __init__(self):
        super().__init__()
        self.count = 0
```

**`super().__init__()` must not be omitted.** QWidget's init does a lot of internal work (creating the native window handle, registering the meta-object). Skip it and you get bizarre problems.

**`self.count = 0` is the counter state**, stored on the instance. Not a global — you might open multiple counter windows at once.

## Part 2: Widgets and Font

**A QWidget's constructor accepts a parent argument.** Giving a widget a parent makes layout management easier (auto-destroy, auto-layout).

```
self.label = QLabel("0")
self.label.setAlignment(Qt.AlignmentFlag.AlignCenter)

font = self.label.font()       # get the current font first
font.setPointSize(48)          # change the size
self.label.setFont(font)        # set it back
```

**The three-step font routine: get → change → set.** `font()` returns a **copy** of the current font, so modifying it won't affect other widgets. Then `setFont` writes it back.

**`setPointSize(48)` makes the number a large 48-point digit** — visually it reads as a real counter. A point is a typographic unit; 1pt ≈ 1.33px.

## Part 3: Connecting Signals

**`self.on_plus` and `self.on_reset` are instance methods used as slot functions.**

```
self.btn_plus.clicked.connect(self.on_plus)
self.btn_reset.clicked.connect(self.on_reset)
```

**Note that `connect` takes `self.on_plus`, not `self.on_plus()`.** That's the crash site from Lesson 4.

**Slot implementations:**

```
def on_plus(self):
    self.count += 1
    self.label.setText(str(self.count))

def on_reset(self):
    self.count = 0
    self.label.setText("0")
```

**`setText(str(self.count))` must convert to a string** — QLabel text must be `str`, not `int`.

## Part 4: Layout

**`QVBoxLayout(self)` sets the layout directly on the window as its main layout** — one line shorter than creating it then calling `self.setLayout(layout)`.

```
layout = QVBoxLayout(self)
layout.addWidget(self.label)
layout.addWidget(self.btn_plus)
layout.addWidget(self.btn_reset)
```

**Widgets are stacked top-to-bottom in `addWidget` order.** The label is on top, the two buttons below. Layouts are covered systematically in Lessons 6–10; for now, just know how to use it.

## Crash Site 1: Forgetting super().__init__()

**Symptom:** runtime error, or the window displays incorrectly and widgets don't respond.

```
class CounterWindow(QWidget):
    def __init__(self):
        # super().__init__()    <- omitted!
        self.count = 0
        self.setWindowTitle("Counter")
```

**Why:** QWidget's `__init__` creates the native window resources. Without calling it, the QWidget instance is never fully initialized, and everything afterward operates on a "half-built" object.

**Fix:** **the first line of every QWidget subclass's `__init__` must be `super().__init__()`** (or `super().__init__(parent)` when passing a parent).

## Crash Site 2: Mixing setLayout with passing self to the layout constructor

**Symptom:** widgets don't appear, or `QWidget::setLayout: Cannot set layout for itself` is raised.

```
layout = QVBoxLayout(self)      # already passed self as parent
self.setLayout(layout)          # setting it again — conflict!
```

**Why:** `QVBoxLayout(self)` already "adopted" self as its parent container; `setLayout` would set it a second time — equivalent to a widget having two layouts.

**Fix:** **pick one, don't write both.**

```
# Option A: pass self in the constructor (recommended, saves a line)
layout = QVBoxLayout(self)

# Option B: create first, then setLayout
layout = QVBoxLayout()
layout.addWidget(...)
self.setLayout(layout)
```

## Crash Site 3: Font doesn't change after setFont

**Symptom:** you changed the font size in code, but the number on screen stays the same.

```
self.label.font().setPointSize(48)   # WRONG!
```

**Why:** `font()` returns a copy. You modified the copy but never wrote it back. The copy was discarded.

**Fix:** **use the three-step "get → change → set":**

```
font = self.label.font()
font.setPointSize(48)
self.label.setFont(font)
```

## Extension: Disabling/Enabling Buttons

**Add an upper limit — at 10, disable the "+1" button.**

```
def on_plus(self):
    self.count += 1
    self.label.setText(str(self.count))
    if self.count >= 10:
        self.btn_plus.setEnabled(False)
```

**`setEnabled(False)` greys out the button and makes it unclickable.** Re-enable on reset:

```
def on_reset(self):
    self.count = 0
    self.label.setText("0")
    self.btn_plus.setEnabled(True)
```

**This interaction is extremely common in real software:** the "Submit" button is greyed out until the form is complete, then unlocks once the condition is met.

## Summary

- Organize windows as classes: state in instance attributes, slots as instance methods
- `__init__`'s first line must be `super().__init__()`
- Font three-step: `font()` gets a copy → `setPointSize` changes it → `setFont` writes it back
- `connect` takes a function object, no parentheses
- Layout: `QVBoxLayout(self)` or `setLayout` — pick one
- `setEnabled(False)` greys out a button and disables it
