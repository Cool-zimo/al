# QVBoxLayout and QHBoxLayout

> Vertical layouts (QVBoxLayout) and horizontal layouts (QHBoxLayout) are Qt's two most commonly used layouts. They're like LEGO bricks: drop widgets in, add stretch factors, set spacing, and your interface comes together. This lesson covers the three core operations: addWidget, addStretch, and setSpacing.

## Basic Usage: addWidget

**QVBoxLayout stacks widgets top to bottom; QHBoxLayout stacks them left to right.**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QPushButton, QVBoxLayout
)

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("Vertical Layout")

btn1 = QPushButton("Button One")
btn2 = QPushButton("Button Two")
btn3 = QPushButton("Button Three")

layout = QVBoxLayout(window)
layout.addWidget(btn1)
layout.addWidget(btn2)
layout.addWidget(btn3)

window.resize(300, 200)
window.show()
app.exec()
```

**Runtime effect: three buttons stacked top to bottom in one column.** When the window stretches, all three stretch vertically, each taking one-third of the height.

**QHBoxLayout only changes the class name — the effect becomes horizontal:**

```
layout = QHBoxLayout(window)
layout.addWidget(btn1)
layout.addWidget(btn2)
layout.addWidget(btn3)
```

**Three buttons in a horizontal row, stretching wider as the window stretches.**

## addStretch: Inserting a Spring

**`addStretch()` inserts a piece of "elastic空白" into the layout, pushing widgets to one side.**

```
layout = QVBoxLayout(window)
layout.addWidget(btn1)
layout.addWidget(btn2)
layout.addStretch()          # spring
layout.addWidget(btn3)
```

**Effect: btn1 and btn2 are pushed to the top half; btn3 is pushed to the bottom of the window.** The spring absorbs all the extra space.

**`addStretch(1)` — the number is a "stretch factor" controlling that blank's relative size:**

```
layout.addWidget(btn1)
layout.addStretch(1)         # takes 1 share
layout.addWidget(btn2)
layout.addStretch(2)         # takes 2 shares — twice as much as above
layout.addWidget(btn3)
```

**Multiple stretches distribute extra space proportionally.** If there's only one stretch, the factor value doesn't matter (nothing to share with).

## Crash Site 1: Spring in the wrong place, widgets clump together

**Symptom: you wanted buttons at the bottom, but they all clump at the top, shrunk to minimum size.**

```
layout = QVBoxLayout(window)
layout.addStretch()          # spring at the very top
layout.addWidget(btn1)
layout.addWidget(btn2)
layout.addWidget(btn3)
```

**Effect: the spring at the top swallows all the extra space, pushing the three buttons to the bottom of the window, squeezed together.**

**This is "bottom-aligned" — but you probably meant "top-aligned".**

**To align widgets at the top: put the spring at the end.**

```
layout.addWidget(btn1)
layout.addWidget(btn2)
layout.addWidget(btn3)
layout.addStretch()          # spring at the end → widgets at top
```

**To vertically center widgets: equal springs on both sides.**

```
layout.addStretch()
layout.addWidget(btn1)
layout.addWidget(btn2)
layout.addStretch()
```

**To put two buttons at opposite ends:**

```
hlayout = QHBoxLayout()
hlayout.addWidget(btn1)
hlayout.addStretch()
hlayout.addWidget(btn2)
```

**Remember the口诀: the spring eats the space, widgets get pushed to the spring's opposite side.**

## setSpacing: Widget Spacing

**`setSpacing(n)` sets the pixel gap between widgets in the layout.**

```
layout = QVBoxLayout(window)
layout.setSpacing(20)        # 20 pixels between widgets
layout.addWidget(btn1)
layout.addWidget(btn2)
layout.addWidget(btn3)
```

**The default spacing is platform-dependent** (around 6px on Windows) and looks cramped. Setting your own value gives a consistent look.

**`setContentsMargins(left, top, right, bottom)` sets the distance from the layout edges to the window edges:**

```
layout.setContentsMargins(20, 20, 20, 20)   # 20 pixels on all four sides
```

**The default margin is around 9px** (varies by style). For form interfaces, a larger left/right margin looks less crammed against the edge.

**The four numbers follow clockwise order: left, top, right, bottom.**

## Crash Site 2: setSpacing set to a negative number

**Symptom: widgets overlap.**

```
layout.setSpacing(-5)
```

**Why:** spacing cannot be negative. Qt treats it as 0 or clamps it to 0.

**Fix:** use a non-negative integer, generally between 0 and 30.

## Nested Layouts: addLayout

**A layout can contain another layout — this is "layout nesting".**

```
main_layout = QVBoxLayout(window)

top_bar = QHBoxLayout()
top_bar.addWidget(QPushButton("New"))
top_bar.addWidget(QPushButton("Open"))
top_bar.addStretch()

main_layout.addLayout(top_bar)           # note: addLayout
main_layout.addWidget(QTextEdit())

window.setLayout(main_layout)
```

**Effect: a horizontal button bar on top (with a spring on the right, buttons on the left), and a text editor below filling the remaining space.**

**`addLayout` takes a layout object, not a widget.** Writing `addWidget(top_bar)` instead would error.

## Crash Site 3: Mixing up addWidget and addLayout

**Symptom: type error.**

```
layout.addWidget(QHBoxLayout())   # WRONG! should be addLayout
```

**Error message:** `QBoxLayout::addWidget: Cannot add a layout to a layout` or `TypeError`.

**Why:** a layout object is not a QWidget and can't be accepted by addWidget.

**Fix: use `addLayout` to add child layouts, `addWidget` to add widgets.**

## Stretch Factors on Widgets

**`addWidget(widget, stretch)` — the second argument is the widget's stretch factor.**

```
layout = QHBoxLayout()
layout.addWidget(btn1)               # default stretch=0, no stretch
layout.addWidget(btn2, 1)            # stretch=1, absorbs extra space
```

**Effect: btn1 stays at its preferred width; btn2 takes all the remaining space.**

**Both widgets with stretch factors:**

```
layout.addWidget(btn1, 1)
layout.addWidget(btn2, 2)
```

**btn2 gets twice the width of btn1.** This is the standard technique for a "main content area + sidebar".

## Complete Example: A Proper Interface Skeleton

**Putting everything from today to use:**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QPushButton, QLabel,
    QVBoxLayout, QHBoxLayout, QTextEdit
)
from PySide6.QtCore import Qt

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("Simple Editor")
window.resize(600, 400)

# Top toolbar (horizontal)
toolbar = QHBoxLayout()
toolbar.addWidget(QPushButton("New"))
toolbar.addWidget(QPushButton("Open"))
toolbar.addWidget(QPushButton("Save"))
toolbar.addStretch()                        # spring on the right
toolbar.addWidget(QPushButton("Settings"))

# Main area
editor = QTextEdit()
status = QLabel("Ready")
status.setAlignment(Qt.AlignmentFlag.AlignRight)

# Vertical main layout
main = QVBoxLayout(window)
main.setContentsMargins(10, 10, 10, 10)
main.setSpacing(8)
main.addLayout(toolbar)
main.addWidget(editor, 1)                   # editor absorbs extra space
main.addWidget(status)

window.show()
app.exec()
```

**Structure: in the vertical main layout, first the horizontal toolbar, then the editor, then the status bar.** The editor's stretch factor is 1, so it swallows all space not used by the toolbar and status bar.

## Summary

- QVBoxLayout vertical, QHBoxLayout horizontal; addWidget adds widgets
- addStretch inserts a spring that absorbs extra space, pushing widgets to the opposite side
- setSpacing(n) sets widget gaps; setContentsMargins sets the four-side margin
- Spring口诀: spring eats space, widgets get pushed to the spring's opposite side
- For nested layouts use addLayout, not addWidget
- addWidget(widget, stretch) sets a widget's stretch factor
- Two widgets with stretch 1:2 → the second gets twice the space
