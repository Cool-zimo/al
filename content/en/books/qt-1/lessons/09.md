# QFormLayout and Nested Layouts

> A form interface (label + input appearing in pairs) can be done with QGridLayout, but Qt provides QFormLayout specifically — clearer semantics and automatic wide/narrow screen adaptation. This lesson covers QFormLayout, then layout nesting — combining small layouts into a complete interface.

## QFormLayout: A Layout Made for Forms

**A form is essentially "label + widget" pairs. QFormLayout is designed for exactly this:**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QLabel, QLineEdit, QPushButton, QFormLayout
)

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("Register")
window.resize(360, 200)

form = QFormLayout(window)

form.addRow("Username:", QLineEdit())
form.addRow("Password:", QLineEdit())
form.addRow("Confirm password:", QLineEdit())
form.addRow("Email:", QLineEdit())

window.show()
app.exec()
```

**`addRow(label_text, widget)` adds one row at a time: label on the left, widget on the right.** The label can be a string or a QLabel object.

**Effect: four form rows, labels right-aligned, inputs left-aligned, rows整齐.**

## Three Ways to Use addRow

**Method 1: String + widget (most common)**

```
form.addRow("Name:", QLineEdit())
```

**Qt automatically creates a QLabel for you** with that string, and sets a `buddy` (covered below).

**Method 2: QLabel + widget (when you need special settings)**

```
label = QLabel("Password:")
label.setStyleSheet("color: red;")
form.addRow(label, QLineEdit())
```

**When you need to style the label, change its font, or set a tooltip, create the QLabel yourself.**

**Method 3: Single widget (spans both columns)**

```
form.addRow(QLabel("This is a note spanning both columns"))
form.addRow("Address:", QLineEdit())
```

**When you pass only one widget, it spans both the label and widget columns.** Useful for hint text or section dividers.

## buddy: Quick Navigation with the Alt Key

**A buddy is a QLabel feature: set a keyboard shortcut so Alt+letter jumps focus to the corresponding input.**

```
name_label = QLabel("Username(&U):")    # &U means Alt+U
name_edit = QLineEdit()
name_label.setBuddy(name_edit)        # set the buddy
form.addRow(name_label, name_edit)
```

**The `&` in `&U` is the mnemonic marker** — the U appears underlined in the UI. Pressing Alt+U jumps focus to name_edit.

**Using the string version of addRow, Qt handles the `&` marker automatically:**

```
form.addRow("Username(&U):", QLineEdit())   # Qt auto-creates the QLabel and buddy
```

**Note: in an English UI, use a letter from the label — e.g. "Name(&N)" for Alt+N.**

## Crash Site 1: Mixed colon widths make alignment look uneven

**Symptom: some labels align neatly, others look crooked.**

```
form.addRow("Username:", QLineEdit())    # ASCII colon
form.addRow("Password:", QLineEdit())    # full-width colon
```

**Why:** a full-width colon occupies two ASCII-widths, making label text lengths inconsistent. After right-alignment they don't line up.

**Fix: use ASCII colons consistently `:`, or manually pad labels with spaces.** A cleaner approach is to give labels a fixed width:

```
label.setFixedWidth(80)
```

## Crash Site 2: addRow parameters reversed

**Symptom: the input is on the left, the label on the right, or an error is raised.**

```
form.addRow(QLineEdit(), "Username")   # WRONG: widget first, label second
```

**Error message:** `TypeError: addRow(self, QLabel, QWidget): argument 1 has unexpected type 'QLineEdit'`

**Why:** addRow's first parameter is the label (str or QLabel); the second is the widget.

**Fix: remember "label first, widget second".**

## Nested Layouts: Combining Small Layouts into an Interface

**Real application interfaces are never a single layout.** The standard pattern: an outer QVBoxLayout containing QFormLayout, QHBoxLayout, etc.

**A complete "Settings Dialog":**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QLabel, QLineEdit, QPushButton,
    QFormLayout, QVBoxLayout, QHBoxLayout
)
from PySide6.QtCore import Qt

app = QApplication(sys.argv)
window = QWidget()
window.setWindowTitle("System Settings")
window.resize(400, 250)

# Middle: form area
form = QFormLayout()
form.addRow("Server:", QLineEdit())
form.addRow("Port:", QLineEdit())
form.addRow("Username:", QLineEdit())
form.addRow("Timeout (sec):", QLineEdit())

# Bottom: button bar (right-aligned)
btn_bar = QHBoxLayout()
btn_bar.addStretch()
btn_bar.addWidget(QPushButton("Cancel"))
btn_bar.addWidget(QPushButton("OK"))

# Outer vertical layout
main = QVBoxLayout(window)
main.addLayout(form)
main.addLayout(btn_bar)

window.show()
app.exec()
```

**Three-layer structure: outer QVBoxLayout → inner QFormLayout (form) + QHBoxLayout (button bar).**

**The button bar adds a spring before the buttons, so they sit on the right — the口诀 from Lesson 7.**

## Crash Site 3: Using addWidget instead of addLayout when nesting

**Symptom: error saying a layout isn't a QWidget.**

```
main = QVBoxLayout(window)
main.addLayout(form)      # correct
main.addLayout(btn_bar)   # correct
main.addWidget(form)      # WRONG! form is a layout, not a widget
```

**Error message:** `QBoxLayout::addWidget: Cannot add a layout to a layout`

**Fix: use `addLayout` for child layouts, `addWidget` for widgets.** Covered in Lesson 7, but worth emphasizing again — it's incredibly common.

## Useful QFormLayout Settings

**`setLabelAlignment` sets the label alignment:**

```
form.setLabelAlignment(Qt.AlignmentFlag.AlignRight)   # right-align labels
```

**Right-aligned is the default, but sometimes an outer layout interferes — setting it explicitly is safer.**

**`setSpacing` and `setContentsMargins` work the same here:**

```
form.setSpacing(10)
form.setContentsMargins(12, 12, 12, 12)
```

**`setFieldGrowthPolicy` controls how input widgets grow:**

```
form.setFieldGrowthPolicy(QFormLayout.FieldGrowthPolicy.ExpandingFieldsGrow)
```

**`ExpandingFieldsGrow` is the default policy:** input boxes stretch with the window. Alternatives include `AllNonFixedFieldsGrow` and `FieldsStayAtSizeHint`.

## Crash Site 4: On stretch, the label column also widens

**Symptom: as the window widens, the label column grows too, creating an increasing gap between label text and input.**

**Why:** by default, both label and input columns participate in stretching.

**Fix: give labels a fixed width so the input column gets all the stretch:**

```
for i in range(form.rowCount()):
    label = form.itemAt(i, QFormLayout.ItemRole.LabelRole).widget()
    if isinstance(label, QLabel):
        label.setFixedWidth(80)
```

**Or use `setFieldGrowthPolicy(QFormLayout.FieldGrowthPolicy.FieldsStayAtSizeHint)`** to limit input column growth, then control spacing with `setHorizontalSpacing`.

## Complete Example: Login Window

**Combining everything from Lessons 8 and 9:**

```
import sys
from PySide6.QtWidgets import (
    QApplication, QWidget, QLabel, QLineEdit, QPushButton,
    QFormLayout, QVBoxLayout, QHBoxLayout
)
from PySide6.QtCore import Qt

class LoginWindow(QWidget):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("Login")
        self.resize(340, 180)

        self.user_edit = QLineEdit()
        self.pass_edit = QLineEdit()
        self.pass_edit.setEchoMode(QLineEdit.EchoMode.Password)

        form = QFormLayout()
        form.addRow("Username(&U):", self.user_edit)
        form.addRow("Password(&P):", self.pass_edit)
        form.setLabelAlignment(Qt.AlignmentFlag.AlignRight)

        btn_bar = QHBoxLayout()
        btn_bar.addStretch()
        login_btn = QPushButton("Login")
        login_btn.clicked.connect(self.on_login)
        btn_bar.addWidget(login_btn)
        btn_bar.addWidget(QPushButton("Cancel"))

        main = QVBoxLayout(self)
        main.addLayout(form)
        main.addLayout(btn_bar)

    def on_login(self):
        print("Username:", self.user_edit.text())
        print("Password:", self.pass_edit.text())

app = QApplication(sys.argv)
window = LoginWindow()
window.show()
app.exec()
```

**`setEchoMode(QLineEdit.EchoMode.Password)` makes the password field show dots.** This is the standard for password inputs.

**`self.user_edit.text()` retrieves the current text of the input box.** QLineEdit is covered in detail in Lesson 11.

## Summary

- QFormLayout is purpose-built for forms: addRow(label, widget)
- The label can be a string (Qt auto-creates QLabel) or a QLabel object
- A single widget spans both columns — perfect for note text
- `&X` mnemonic + setBuddy enables Alt+X navigation
- Nested layouts: outer QVBoxLayout, inner sub-layouts mixed in
- For child layouts use addLayout, for widgets use addWidget — don't mix
- setFieldGrowthPolicy controls how the input column grows with the window
