# `reader` / `writer`: Reading and Writing in List Form

> This lesson dives into `csv.reader` and `csv.writer`: how to read, how to write, and what the return types are. It also thoroughly explains why `newline=''` is mandatory.

## `csv.reader`: Returns an Iterator of Lists

`csv.reader` accepts any iterable object (usually a file object) and spits out a **list of strings** on each `next` call — each column is an element in the list.

```python
import csv
import io

text = """name,age,city
Alice,28,London
Bob,35,New York"""

reader = csv.reader(io.StringIO(text))
for row in reader:
    print(type(row).__name__, row)
```

Output:

```
list ['name', 'age', 'city']
list ['Alice', '28', 'London']
list ['Bob', '35', 'New York']
```

**Each row is a `list[str]`.** To get the 2nd column, use `row[1]`; for the last column, use `row[-1]`.

## What to Do After Reading into a List

```python
import csv
import io

text = """name,age,city
Alice,28,London
Bob,35,New York
Carol,42,Glasgow"""

reader = csv.reader(io.StringIO(text))
header = next(reader)              # extract the header separately
print("Header:", header)

data = []
for row in reader:
    data.append({"name": row[0], "age": int(row[1]), "city": row[2]})

print(data)
```

Output:

```
Header: ['name', 'age', 'city']
[{'name': 'Alice', 'age': 28, 'city': 'London'}, {'name': 'Bob', 'age': 35, 'city': 'New York'}, {'name': 'Carol', 'age': 42, 'city': 'Glasgow'}]
```

`next(reader)` skips the header, leaving only pure data. Notice also the **type restoration** here: `age` is converted from a string back to an `int`.

## `csv.writer`: `writerow` and `writerows`

The core methods of `writer` are `writerow(row)` (write one row) and `writerows(rows)` (write multiple rows).

```python
import csv
import io

buf = io.StringIO()
writer = csv.writer(buf)

writer.writerow(["name", "age", "city"])        # write one row
writer.writerows([                               # write multiple rows
    ["Alice", 28, "London"],
    ["Bob", 35, "New York"],
    ["Carol", 42, "Glasgow"],
])

print(buf.getvalue())
```

Output:

```
name,age,city
Alice,28,London
Bob,35,New York
Carol,42,Glasgow
```

`writerow` accepts a single iterable, while `writerows` accepts "an iterable of iterables" (two-dimensional).

## `newline=''` Is Mandatory

Let us state the conclusion first: **when opening a file to write CSV on Windows, you must pass `newline=''`.**

### Why?

The record terminator in the CSV specification is `\r\n` (CRLF). Python's text-mode `open()` on Windows automatically translates `\n` into `\r\n`.

But the `csv` module itself already writes `\r\n` at the end of each line. The result of these two layers stacking up:

| Scenario | Actual bytes written by csv | Display effect |
|---|---|---|
| Correct `newline=''` | `\r\n` | Normal |
| Incorrect default mode (Windows) | `\r\r\n` | An extra blank line between each row |

### Crash Site: Extra Blank Lines

```python
# WRONG (on Windows)
import csv

with open("users.csv", "w", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["name", "age"])
    writer.writerow(["Alice", 28])
```

When opened in Notepad, it becomes:

```
name,age
                                    ← blank line
Alice,28
                                    ← blank line
```

**The correct写法**:

```python
import csv

with open("users.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["name", "age"])
    writer.writerow(["Alice", 28])
```

The meaning of `newline=''` is: **tell Python not to do any newline translation and hand it all over to the `csv` module to handle.**

> On Linux/Mac, the default mode usually does not cause problems either, but **getting into the habit of `newline=''`** ensures your code will not have cross-platform bugs.

## Does Reading Also Require `newline=''`?

**`newline=''` is recommended but not strictly required when reading.** For consistency and cross-platform safety, it is recommended when reading too:

```python
import csv

with open("users.csv", encoding="utf-8", newline="") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)
```

## A Complete Read/Write Workflow

```python
import csv
import io

# Read
src = """name,age,city
Alice,28,London
Bob,35,New York"""

reader = csv.reader(io.StringIO(src))
rows = list(reader)
header = rows[0]
data = rows[1:]

# Modify: add 1 to everyone's age
for r in data:
    r[1] = str(int(r[1]) + 1)

# Write
buf = io.StringIO()
writer = csv.writer(buf)
writer.writerow(header)
writer.writerows(data)

print(buf.getvalue())
```

Output:

```
name,age,city
Alice,29,London
Bob,36,New York
```

**Read in list form, modify in list form, write in list form** — this is the complete workflow for `reader/writer`.

## Summary

- `csv.reader` returns an iterator of **lists of strings**; use index `row[0]`, `row[1]` to access columns
- `next(reader)` can extract the header separately, leaving only pure data behind
- `writer.writerow` writes one row, `writer.writerows` writes multiple rows
- **When writing CSV, `newline=''` is mandatory**, otherwise an extra blank line appears between rows on Windows
- It is also recommended to add `newline=''` when reading to ensure cross-platform consistency
- Complete workflow: read into a list → modify → write back
