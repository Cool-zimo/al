# Hands-On: A CSV ↔ JSON Conversion Utility

> This lesson ties together everything from Chapter 3 by building a conversion utility you can use from the command line. The focus is on **type restoration** — since CSV contains only strings, you must restore them to numbers, booleans, and null when converting to JSON.

## Target Functionality

We want to build a utility module that supports:

1. `csv_to_json(text)`: CSV text → JSON string (with type restoration)
2. `json_to_csv(data)`: JSON-serializable object → CSV text
3. Type restoration rules: convert to `int`/`float` if it looks like a number, to `bool` if it looks like a boolean, and `""` to `null`

## Why Type Restoration Is Necessary

CSV is plain text, so every value read out is a string:

```python
import csv
import io

text = """name,age,score,active
Alice,28,95.5,true
Bob,35,88.0,false"""

reader = csv.DictReader(io.StringIO(text))
records = list(reader)
print(records)
```

Output:

```
[{'name': 'Alice', 'age': '28', 'score': '95.5', 'active': 'true'},
 {'name': 'Bob', 'age': '35', 'score': '88.0', 'active': 'false'}]
```

`age` is the string `"28"`, and `active` is the string `"true"`. This is not what we want.

## The Type Restoration Function

Write a `convert_value` that attempts conversion according to the rules:

```python
def convert_value(s):
    """Attempt to restore a CSV string to a more appropriate type."""
    if s == "":
        return None
    if s.lower() == "true":
        return True
    if s.lower() == "false":
        return False
    if s.lower() == "null":
        return None
    # Try integer
    try:
        return int(s)
    except ValueError:
        pass
    # Try float
    try:
        return float(s)
    except ValueError:
        pass
    # If none of the above, keep it as a string
    return s
```

Test:

```python
for v in ["28", "95.5", "true", "false", "null", "", "Alice"]:
    print(f"{v!r} -> {convert_value(v)!r}")
```

Output:

```
'28' -> 28
'95.5' -> 95.5
'true' -> True
'false' -> False
'null' -> None
'' -> None
'Alice' -> 'Alice'
```

**Order matters**: try `int` first, then `float`. If you tried `float` first, `"28"` would become `28.0`.

## Complete `csv_to_json` Implementation

```python
import csv
import io
import json


def convert_value(s):
    if s == "":
        return None
    if s.lower() == "true":
        return True
    if s.lower() == "false":
        return False
    if s.lower() == "null":
        return None
    try:
        return int(s)
    except ValueError:
        pass
    try:
        return float(s)
    except ValueError:
        pass
    return s


def csv_to_json(text, indent=2):
    """CSV text -> JSON string with type restoration."""
    reader = csv.DictReader(io.StringIO(text))
    records = []
    for row in reader:
        converted = {k: convert_value(v) for k, v in row.items()}
        records.append(converted)
    return json.dumps(records, ensure_ascii=False, indent=indent)


# Demo
text = """name,age,score,active
Alice,28,95.5,true
Bob,35,88.0,false"""

result = csv_to_json(text)
print(result)
```

Output:

```json
[
  {
    "name": "Alice",
    "age": 28,
    "score": 95.5,
    "active": true
  },
  {
    "name": "Bob",
    "age": 35,
    "score": 88.0,
    "active": false
  }
]
```

## `json_to_csv`: The Reverse Conversion

Convert a list of JSON objects back into CSV. The idea: first determine the header (take the union of all keys from the dictionaries), then fill in the values row by row.

```python
def json_to_csv(data, fieldnames=None):
    """JSON object list -> CSV text."""
    if not isinstance(data, list) or not data:
        return ""

    # Determine column order: prefer the passed-in fieldnames, otherwise use the keys of the first object
    if fieldnames is None:
        fieldnames = list(data[0].keys())

    buf = io.StringIO()
    writer = csv.DictWriter(buf, fieldnames=fieldnames, restval="", extrasaction="ignore")
    writer.writeheader()
    writer.writerows(data)
    return buf.getvalue()


# Demo
records = [
    {"name": "Alice", "age": 28, "city": "London"},
    {"name": "Bob", "age": 35, "city": "New York"},
]
csv_text = json_to_csv(records)
print(csv_text)
```

Output:

```
name,age,city
Alice,28,London
Bob,35,New York
```

## Crash Site: Nested Objects in JSON

CSV is a "flat table" and cannot hold nested structures:

```python
# WRONG
data = [
    {"name": "Alice", "address": {"city": "London", "district": "Camden"}},
]
json_to_csv(data)
```

Output:

```
name,address
Alice,"{'city': 'London', 'district': 'Camden'}"
```

`address` gets stuffed in as if it were a regular value. **The correct approach**: flatten the nested keys, or flatten them first into `address.city` and `address.district`.

```python
def flatten(obj, prefix=""):
    """Flatten a nested dictionary into flat keys with dot notation."""
    result = {}
    for k, v in obj.items():
        key = f"{prefix}.{k}" if prefix else k
        if isinstance(v, dict):
            result.update(flatten(v, key))
        else:
            result[key] = v
    return result

flat_records = [flatten(r) for r in data]
print(json_to_csv(flat_records))
```

Output:

```
name,address.city,address.district
Alice,London,Camden
```

## Adding a Command-Line Entry Point

```python
import sys
import json

def main():
    if len(sys.argv) < 3:
        print("Usage: python conv.py csv2json <file>   or  python conv.py json2csv <file>")
        return

    mode = sys.argv[1]
    path = sys.argv[2]

    with open(path, encoding="utf-8") as f:
        content = f.read()

    if mode == "csv2json":
        # Assume there is a header; keep it simple
        print(csv_to_json(content))
    elif mode == "json2csv":
        data = json.loads(content)
        print(json_to_csv(data))

if __name__ == "__main__":
    main()
```

Run it:

```
$ python conv.py csv2json users.csv
$ python conv.py json2csv users.json
```

## Summary

- All values read from CSV are **strings**; you must restore their types yourself
- Type restoration order: `""`/null → boolean → int → float → keep as string
- `csv_to_json`: DictReader reads → convert_value for each field → json.dumps
- `json_to_csv`: DictWriter + fieldnames + writeheader
- Nested objects do not fit in CSV; flatten them to dot-notation keys first
- The whole thing is "read string → process → write string," embeddable in any workflow
