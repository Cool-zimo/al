# `DictReader` / `DictWriter`: Reading and Writing by Column Name

> The previous lesson used index-based column access (`row[0]`, `row[1]`), which is fragile — any change to the header breaks everything. This lesson replaces indices with column names, making your code more robust and readable.

## `DictReader`: Each Row Is a Dictionary

The only difference between `csv.DictReader` and `reader` is: **it uses the header as keys, turning each row into a dictionary.**

```python
import csv
import io

text = """name,age,city
Alice,28,London
Bob,35,New York"""

reader = csv.DictReader(io.StringIO(text))
for row in reader:
    print(type(row).__name__, row)
```

Output:

```
dict {'name': 'Alice', 'age': '28', 'city': 'London'}
dict {'name': 'Bob', 'age': '35', 'city': 'New York'}
```

Access changes from `row[1]` to `row["age"]` — **accessing by column name means changing the header order will not affect your code.**

## What If the Header Is Not the First Line?

Some CSV files have a few lines of description text at the top, with the real header on line 3:

```python
import csv
import io

text = """# This is a data export
# Date: 2026-09-27
name,age,city
Alice,28,London"""

reader = csv.DictReader(io.StringIO(text), skipinitialspace=True)
# By default, the first line is the header, which will cause problems
for row in reader:
    print(row)
```

Output (incorrect):

```
{'# This is a data export': 'name', '# Date: 2026-09-27': 'age', 'name,age,city': 'Alice,28,London'}
```

Use `fieldnames` to explicitly specify the header line:

```python
import csv
import io

text = """# This is a data export
name,age,city
Alice,28,London
Bob,35,New York"""

reader = csv.DictReader(io.StringIO(text), fieldnames=None)
# Or skip the first two lines
lines = text.split("\n")
data_text = "\n".join(lines[1:])      # remove the description line

reader = csv.DictReader(io.StringIO(data_text))
for row in reader:
    print(row["name"], row["city"])
```

Output:

```
Alice London
Bob New York
```

## `fieldnames`: Specifying Column Order When Writing

When `csv.DictWriter` writes dictionaries, **you must tell it the column order**, because dictionaries themselves do not guarantee order (although Python 3.7+ preserves insertion order, you often want to control the output order when writing files).

```python
import csv
import io

buf = io.StringIO()
fieldnames = ["name", "city", "age"]          # desired output column order

writer = csv.DictWriter(buf, fieldnames=fieldnames)
writer.writeheader()                           # write the header
writer.writerow({"name": "Alice", "age": 28, "city": "London"})
writer.writerow({"name": "Bob", "age": 35, "city": "New York"})

print(buf.getvalue())
```

Output:

```
name,city,age
Alice,London,28
Bob,New York,35
```

Note: **the order of `fieldnames` is `name, city, age`, so the output columns are in this order**, even though `age` appears first in the dictionary.

## Crash Site: Forgetting to Call `writeheader`

```python
# WRONG
import csv
import io

buf = io.StringIO()
writer = csv.DictWriter(buf, fieldnames=["name", "age"])
writer.writerow({"name": "Alice", "age": 28})
print(repr(buf.getvalue()))
```

Output:

```
'Alice,28\n'
```

**There is no header row!** The data is written out directly, and when it is read back, there is no way to know which column is which.

**The correct approach**: `DictWriter` must call `writeheader()` first after writing.

```python
import csv
import io

buf = io.StringIO()
writer = csv.DictWriter(buf, fieldnames=["name", "age"])
writer.writeheader()               # ← cannot forget this
writer.writerow({"name": "Alice", "age": 28})
print(buf.getvalue())
```

Output:

```
name,age
Alice,28
```

## What If a Dictionary Is Missing a Key: `restval` and `extrasaction`

### Missing keys → `restval`

```python
import csv
import io

buf = io.StringIO()
writer = csv.DictWriter(buf, fieldnames=["name", "age", "city"], restval="unknown")
writer.writeheader()
writer.writerow({"name": "Alice", "age": 28})    # missing city
print(buf.getvalue())
```

Output:

```
name,age,city
Alice,28,unknown
```

`restval="unknown"` means: when the dictionary is missing the corresponding key, fill it with `"unknown"` (the default is an empty string `""`).

### Extra keys → `extrasaction`

```python
# WRONG
import csv
import io

buf = io.StringIO()
writer = csv.DictWriter(buf, fieldnames=["name", "age"])
writer.writeheader()
writer.writerow({"name": "Alice", "age": 28, "extra": "bonus"})   # extra key
# ValueError: dict contains fields not in fieldnames: 'extra'
```

**The solution**: `extrasaction="ignore"`.

```python
import csv
import io

buf = io.StringIO()
writer = csv.DictWriter(buf, fieldnames=["name", "age"], extrasaction="ignore")
writer.writeheader()
writer.writerow({"name": "Alice", "age": 28, "extra": "bonus"})
print(buf.getvalue())
```

Output:

```
name,age
Alice,28
```

The extra key is quietly discarded.

## Complete `DictReader` + `DictWriter` Workflow

```python
import csv
import io

src = """name,age,city
Alice,28,London
Bob,35,New York"""

# Read
reader = csv.DictReader(io.StringIO(src))
records = list(reader)
for r in records:
    r["age"] = str(int(r["age"]) + 1)     # age + 1

# Write
buf = io.StringIO()
writer = csv.DictWriter(buf, fieldnames=["name", "age", "city"], restval="")
writer.writeheader()
writer.writerows(records)

print(buf.getvalue())
```

Output:

```
name,age,city
Alice,29,London
Bob,36,New York
```

Reading and writing by column name makes it immediately clear what the code is doing.

## Summary

- `DictReader` turns each row into a `{column_name: value}` dictionary, accessed via `row["column_name"]`
- When the header is not on the first line, use `fieldnames` or preprocess the text
- `DictWriter` **must be passed `fieldnames`** to control the output column order
- **Call `writeheader()` first after writing**, otherwise there will be no header row
- `restval` handles missing keys, `extrasaction="ignore"` ignores extra keys
- Accessing by column name is far more robust than by index; changing the header order will not affect the logic
