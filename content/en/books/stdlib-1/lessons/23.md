# dataclasses: Cutting Your Boilerplate by 80%

> A class that just holds data needs an `__init__`, `__repr__`, `__eq__`... Write it three times and you'll be sick of it. This lesson uses `@dataclass` to generate them automatically, so you can focus on the fields themselves.

## Plain Class vs dataclass: A Boilerplate Comparison

First, the pain without dataclasses:

```python
class Product:
    def __init__(self, name, price, qty):
        self.name = name
        self.price = price
        self.qty = qty

    def __repr__(self):
        return f"Product(name={self.name!r}, price={self.price!r}, qty={self.qty!r})"

    def __eq__(self, other):
        if not isinstance(other, Product):
            return NotImplemented
        return (self.name, self.price, self.qty) == (other.name, other.price, other.qty)
```

Now the dataclass version:

```python
from dataclasses import dataclass

@dataclass
class Product:
    name: str
    price: float
    qty: int

p = Product("Keyboard", 199.0, 3)
print(p)
print(p == Product("Keyboard", 199.0, 3))
```

Output:

```
Product(name='Keyboard', price=199.0, qty=3)
True
```

**A single `@dataclass` decorator auto-generates `__init__`, `__repr__`, and `__eq__`.** The type annotations on the fields are the declaration — Python generates the initialiser automatically.

## Common Parameters

| Parameter | Purpose |
| --- | --- |
| `frozen=True` | Freeze instances so they can't be modified (like a tuple) |
| `order=True` | Auto-generate comparison methods (`__lt__` etc.), enabling sorting by field |
| `slots=True` | Use `__slots__` to save memory (Python 3.10+) |
| `kw_only=True` | Force keyword-only arguments |

```python
from dataclasses import dataclass

@dataclass(frozen=True, order=True)
class Item:
    name: str
    price: float

a = Item("A", 10)
# a.price = 20   # error: frozen
items = [Item("B", 5), Item("C", 15), Item("A", 10)]
print(sorted(items))     # sorted by price
```

Output:

```
[Item(name='B', price=5), Item(name='A', price=10), Item(name='C', price=15)]
```

## Crash Site 1: A Mutable Default of `[]` Is Shared

**This is a classic Python pitfall, and it persists inside dataclasses.** Using `[]` directly as a default means all instances share the same list:

```python
from dataclasses import dataclass

@dataclass
class Cart:
    items: list = []        # WRONG

c1 = Cart()
c2 = Cart()
c1.items.append("apple")
print(c2.items)            # has "apple" too!
```

Output:

```
['apple']
```

`c1` and `c2`'s `items` point to **the same list** — modify one and the other changes too. Everyone who writes Python has hit this.

**The fix: use `field(default_factory=list)`:**

```python
from dataclasses import dataclass, field

@dataclass
class Cart:
    items: list = field(default_factory=list)

c1 = Cart()
c2 = Cart()
c1.items.append("apple")
print(c1.items)            # ['apple']
print(c2.items)            # []
```

Output:

```
['apple']
[]
```

`default_factory` calls `list()` **once per instantiation**, yielding a brand-new empty list each time — no interference.

## Crash Site 2: `asdict` Returns a Nested dict, Not JSON

`asdict()` recursively converts a dataclass into a dictionary, ready for serialisation:

```python
from dataclasses import dataclass, asdict
import json

@dataclass
class Address:
    city: str
    street: str

@dataclass
class User:
    name: str
    addr: Address

u = User("Alice", Address("London", "Downing Street"))
d = asdict(u)
print(d)
print(json.dumps(d, ensure_ascii=False))
```

Output:

```
{'name': 'Alice', 'addr': {'city': 'London', 'street': 'Downing Street'}}
{"name": "Alice", "addr": {"city": "London", "street": "Downing Street"}}
```

**Where it bites**: `asdict()` only handles the conversion to dict — **it does not call `json.dumps` for you.** And it returns a **new object** (a deep copy), so modifying the dict doesn't affect the original instance:

```python
from dataclasses import dataclass, asdict

@dataclass
class Point:
    x: int
    y: int

p = Point(1, 2)
d = asdict(p)
d["x"] = 999
print(p)        # Point(x=1, y=2) — unchanged
```

Output:

```
Point(x=1, y=2)
```

## Common field Options

| Option | Purpose |
| --- | --- |
| `default` | Default value (for immutable objects) |
| `default_factory` | Factory function that generates the default (use for mutable objects) |
| `init=False` | Exclude from `__init__` |
| `repr=False` | Exclude from `__repr__` |
| `compare=False` | Don't include in `__eq__` comparisons |

```python
from dataclasses import dataclass, field

@dataclass
class Order:
    id: str
    items: list = field(default_factory=list)
    tax: float = 0.13
    _internal: str = field(default="", repr=False, init=False)

o = Order("A001")
print(o)
```

Output:

```
Order(id='A001', items=[], tax=0.13)
```

`_internal` doesn't appear in the repr because `repr=False`.

## Summary

- `@dataclass` auto-generates `__init__`, `__repr__`, and `__eq__`, saving huge amounts of boilerplate
- `frozen=True` freezes instances; `order=True` enables comparison and sorting
- **For mutable defaults, use `field(default_factory=list)`** — never `[]` or `{}`
- `asdict()` recursively converts to a dict — the first step in serialisation — and returns a deep copy
- `field(repr=False, init=False, compare=False)` gives fine-grained control over field behaviour
