# Practice: Grouping Anagrams

> Grouping anagrams is a classic combination of hash tables and string processing. The core idea: find a way to **map anagrams to the same key.**

## The Problem

**Anagram**: two strings contain exactly the same characters in the same quantities, just arranged differently. For example, "eat", "tea", and "ate" are anagrams of one another.

**The task**: given an array of strings `strs`, group the anagram strings together and return the grouped lists.

```
Input:  ["eat", "tea", "tan", "ate", "nat", "bat"]
Output: [["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
```

**Order doesn't matter**, as long as the grouping is correct.

## Approach 1: Sorting as the Key

Two anagrams, when **sorted, become identical strings.**

```python
"eat" -> sorted -> "aet"
"tea" -> sorted -> "aet"
"ate" -> sorted -> "aet"
"tan" -> sorted -> "ant"
"nat" -> sorted -> "ant"
"bat" -> sorted -> "abt"
```

**So the idea is**: use the "sorted string" as the key, and group together everything that sorts to the same result.

```python
from collections import defaultdict

def group_anagrams(strs):
    groups = defaultdict(list)
    for s in strs:
        key = "".join(sorted(s))   # sorted string as the key
        groups[key].append(s)
    return list(groups.values())

print(group_anagrams(["eat", "tea", "tan", "ate", "nat", "bat"]))
# [['eat', 'tea', 'ate'], ['tan', 'nat'], ['bat']]
```

**Complexity analysis:**
- Sorting each string: O(k log k), where k is the string length
- n strings total: O(n * k log k)
- Space: O(n * k) to store the result

## Approach 2: Character Count as the Key

Sorting costs O(k log k). Can we do better?

**A different angle**: the essence of an anagram is "each character appears the same number of times." We can use a **character-frequency tuple** as the key.

```python
"eat" -> (1, 0, 0, ..., 1, 0, ..., 1, 0, ...)  # a:1, b:0, ..., e:1, ...
"tea" -> (1, 0, 0, ..., 1, 0, ..., 1, 0, ...)  # identical!
```

```python
def group_anagrams_count(strs):
    groups = defaultdict(list)
    for s in strs:
        count = [0] * 26                     # 26 lowercase letters
        for c in s:
            count[ord(c) - ord('a')] += 1
        key = tuple(count)                   # list is unhashable, convert to tuple
        groups[key].append(s)
    return list(groups.values())

print(group_anagrams_count(["eat", "tea", "tan", "ate", "nat", "bat"]))
# [['eat', 'tea', 'ate'], ['tan', 'nat'], ['bat']]
```

**Complexity analysis:**
- Counting frequencies per string: O(k)
- n strings total: O(n * k)
- Faster than sorting (k vs. k log k), but the key is longer (26 ints vs. k chars)

**How to choose between them:**
- k is small (short words) -> sorting is simpler
- k is large (long strings) -> counting is faster

## WRONG: Using a list as a dict Key

```python
# WRONG: using the count list directly as a key
groups = {}
for s in strs:
    count = [0] * 26
    for c in s:
        count[ord(c) - ord('a')] += 1
    groups[count].append(s)   # TypeError: unhashable type: 'list'
```

Error:

```
TypeError: unhashable type: 'list'
```

**Fix**: convert the list to a tuple.

```python
# RIGHT: convert to tuple
key = tuple(count)   # tuple is immutable, valid as a key
groups[key].append(s)
```

**Or use a count-string as the key** (more space-efficient):

```python
def group_anagrams_strkey(strs):
    groups = defaultdict(list)
    for s in strs:
        count = [0] * 26
        for c in s:
            count[ord(c) - ord('a')] += 1
        # turn the count into a string: "1#0#0#...#1#..."
        key = "#".join(str(x) for x in count)
        groups[key].append(s)
    return list(groups.values())
```

## WRONG: Empty Strings and Single-Character Cases

```python
# Edge cases
strs = ["", ""]
print(group_anagrams(strs))
# [['', '']]  ✓ both empty strings are anagrams of each other (both sort to "")

strs = ["a"]
print(group_anagrams(strs))
# [['a']]  ✓ single character

strs = []
print(group_anagrams(strs))
# []  ✓ empty array
```

**Note**: sorting an empty string still yields an empty string `""`, and `"".join(sorted(""))` is also `""` — a valid key.

## WRONG: Unicode Characters Outside a-z

```python
# WRONG: assuming every character is a lowercase letter
def group_anagrams_ascii(strs):
    groups = defaultdict(list)
    for s in strs:
        count = [0] * 26
        for c in s:
            count[ord(c) - ord('a')] += 1  # if c isn't a-z, index out of range!
        groups[tuple(count)].append(s)
    return list(groups.values())

print(group_anagrams_ascii(["cafe", "face"]))
# IndexError: list assignment index out of range
```

**Fix**: if the character range is unknown, use the sorting approach (more general) or count with a dict:

```python
def group_anagrams_unicode(strs):
    groups = defaultdict(list)
    for s in strs:
        # tuple + sorted works for any comparable character
        key = tuple(sorted(s))
        groups[key].append(s)
    return list(groups.values())

print(group_anagrams_unicode(["cafe", "face"]))
# [['cafe', 'face']]  ✓
```

**Or use Counter as the key** (but Counter isn't hashable by itself, so sort its items and convert to tuple):

```python
from collections import Counter

def group_anagrams_counter(strs):
    groups = defaultdict(list)
    for s in strs:
        # sorted Counter items, then tuple
        key = tuple(sorted(Counter(s).items()))
        groups[key].append(s)
```

## WRONG: Inconsistent Output Order Causes Test Failures

```python
# The problem says "order doesn't matter," but some judges expect a specific order
result = group_anagrams(["eat", "tea", "tan", "ate", "nat", "bat"])
print(result)
# Could be [['eat', 'tea', 'ate'], ['tan', 'nat'], ['bat']]
# Could also be [['bat'], ['tan', 'nat'], ['eat', 'tea', 'ate']]

# If your test uses strict == comparison, a different order fails
expected = [["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
print(result == expected)  # could be False!
```

**The fix: sort before comparing**

```python
def compare_anagram_groups(result, expected):
    # sort each inner list, then sort the outer list
    result_sorted = sorted([sorted(g) for g in result])
    expected_sorted = sorted([sorted(g) for g in expected])
    return result_sorted == expected_sorted

result = group_anagrams(["eat", "tea", "tan", "ate", "nat", "bat"])
expected = [["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
print(compare_anagram_groups(result, expected))  # True
```

## WRONG: Forgetting to Convert to a list Before Returning

```python
# WRONG: returning dict_values directly
def group_anagrams_wrong(strs):
    groups = defaultdict(list)
    for s in strs:
        key = "".join(sorted(s))
        groups[key].append(s)
    return groups.values()  # returns a dict_values object!

result = group_anagrams_wrong(["a", "b"])
print(result)  # dict_values([['a'], ['b']])
print(list(result) == [['a'], ['b']])  # True, but the type isn't list of lists
```

**Some judges strictly require `List[List[str]]`** — returning `dict_values` will fail the type check.

```python
# RIGHT: explicitly convert to list
return list(groups.values())
```

## Complete Implementation (Sorting Approach)

```python
from collections import defaultdict
from typing import List

def group_anagrams(strs: List[str]) -> List[List[str]]:
    """
    Group anagrams together.
    Key idea: sort each string; anagrams become identical keys.
    Time:  O(n * k log k), n = number of strings, k = longest string length
    Space: O(n * k)
    """
    groups = defaultdict(list)
    
    for s in strs:
        # key: the sorted tuple of characters
        key = tuple(sorted(s))
        groups[key].append(s)
    
    return list(groups.values())

# Test
test = ["eat", "tea", "tan", "ate", "nat", "bat"]
result = group_anagrams(test)
print(result)
# [['eat', 'tea', 'ate'], ['tan', 'nat'], ['bat']] (order may vary)
```

## Extension: Sorting Each Group Alphabetically

```python
def group_anagrams_sorted_output(strs):
    groups = defaultdict(list)
    for s in strs:
        key = tuple(sorted(s))
        groups[key].append(s)
    
    # sort each group internally
    result = [sorted(group) for group in groups.values()]
    # sort the whole result (by first element)
    result.sort(key=lambda x: x[0])
    return result

print(group_anagrams_sorted_output(["eat", "tea", "tan", "ate", "nat", "bat"]))
# [['ate', 'eat', 'tea'], ['bat'], ['nat', 'tan']]
```

## Summary

- The core of grouping anagrams is **finding a way to map anagrams to the same key**
- Approach 1: sorting, `key = tuple(sorted(s))`, O(n * k log k)
- Approach 2: counting, `key = tuple(count)`, O(n * k), faster but limited to a known character range
- Using a list as the key raises TypeError; convert to tuple or use a count-string
- Sorting is more general and works with Unicode
- On return, convert to `list`; when comparing, sort first
- General "grouping" pattern: find an invariant to use as the key, then aggregate with `defaultdict(list)`
