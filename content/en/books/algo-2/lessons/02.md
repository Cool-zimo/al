# ListNode and Hand-Built Linked Lists: Defining Nodes, Linking Them, Traversing and Printing

> In this lesson we build a linked list from scratch: define a node, link nodes into a chain, then traverse and print it. Linked lists stop being abstract.

## What Is a Node

The smallest unit of a linked list is called a **node**, and it holds two things: a **value** and a **pointer to the next node**.

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val      # the data it stores
        self.next = next    # points to the next node, or None if there is none
```

That's the whole thing. One node = one value + one arrow.

```
   ┌────┬────┐
   │ 42 │  ──┼──→ next node
   └────┴────┘
   val=42   next
```

The last node's `next` is `None`, meaning "nobody is behind me." This is the linked list's **terminator**.

## Linking Nodes Together

Build a chain by hand: `1 → 2 → 3`.

```python
n1 = ListNode(1)
n2 = ListNode(2)
n3 = ListNode(3)
n1.next = n2      # 1 points to 2
n2.next = n3      # 2 points to 3
n3.next = None    # 3 is last (its __init__ default is already None)

head = n1         # head points to the first node - the "head pointer"
```

A more useful technique is **head-insertion**, where you hang each new node at the front:

```python
vals = [3, 2, 1]          # we want 1→2→3, so we insert in reverse
head = None
for v in vals:
    head = ListNode(v, head)
# 1st pass: head = 3→None
# 2nd pass: head = 2→3→None
# 3rd pass: head = 1→2→3→None
```

Head-insertion is always O(1), but it **reverses the order**. To preserve the original order, use tail-insertion (keep a `tail` pointer).

## Traversing and Printing

There is exactly one way to walk a linked list: **follow `next` until you hit `None`**.

```python
def print_list(head):
    cur = head
    while cur is not None:
        print(cur.val, end=" -> ")
        cur = cur.next
    print("None")

print_list(head)    # 1 -> 2 -> 3 -> None
```

Notice the loop condition is `cur is not None`, not `cur.next`. The next "WRONG" section will show you why that matters.

## WRONG: Using `cur.val` As the Condition Crashes on None

The classic beginner mistake:

```python
# WRONG
def print_list(head):
    cur = head
    while cur.val:            # when cur is None, None has no .val
        print(cur.val)
        cur = cur.next
```

```text
Error: AttributeError: 'NoneType' object has no attribute 'val'
```

When `cur` walks past the last node and becomes `None`, the loop body runs one more time and tries to read `None.val`—instant crash. **To detect the end of a list, always test whether the node itself is None; never test the node's value.**

The correct condition: `while cur is not None:`.

## WRONG: Forgetting to Advance the Pointer—An Infinite Loop

Another classic blunder is setting up traversal but never actually moving forward:

```python
# WRONG
def print_list(head):
    cur = head
    while cur is not None:
        print(cur.val, end=" -> ")
        # forgot: cur = cur.next
    print("None")
```

```text
Output (and it never stops):
1 -> 1 -> 1 -> 1 -> 1 -> 1 -> ...
```

Without `cur = cur.next`, the pointer never advances, so the condition `cur is not None` stays true forever. The program prints the first value in an endless loop. **If your traversal has a loop condition that depends on `cur`, you must reassign `cur` somewhere inside the body.**

## Converting To and From a List: The Standard Exam Scaffold

For convenience, exam problems represent linked lists as ordinary Python lists. You need two utility functions:

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def build(lst):
    head = None
    for v in reversed(lst):
        head = ListNode(v, head)
    return head

def to_list(head):
    res = []
    cur = head
    while cur:
        res.append(cur.val)
        cur = cur.next
    return res

# Verify: convert one way, then back, and you get the original
print(to_list(build([1, 2, 3])))    # [1, 2, 3]
```

These two functions will appear alongside every function problem in the entire Linked List chapter.

## Summary

- A node has exactly two fields: `val` and `next`.
- The last node's `next` is `None`—that is the list's terminator.
- Traverse with `while cur is not None`; never use `cur.val` as the condition.
- Head-insertion is O(1) but reverses the order; use tail-insertion to preserve order.
- `build` and `to_list` are the universal scaffolding for linked-list problems.
