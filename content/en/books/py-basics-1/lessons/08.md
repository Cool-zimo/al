# Strings: working with text

> Programs don't handle numbers only. Names, addresses, a sentence, a whole article — in Python all of these are **strings**.

## What a string is

A **string (str)** is a run of text wrapped in quotes:

```python
name = "Alex"
city = 'London'
sentence = "He said: 'nice weather'"
```

Three ways to write them:

| Style | Example | When to use |
|---|---|---|
| Double quotes | `"hello"` | the default |
| Single quotes | `'hello'` | when the text itself contains double quotes |
| Triple quotes | `"""many lines"""` | when the text spans lines |

**Why two kinds of quote?** So you can safely include the other kind inside:

```python
print("He said: 'ok'")      # doubles outside, singles inside — fine
print('She said: "really"')  # works the other way too
```

If you must put a double quote inside double quotes, escape it with a backslash:

```python
print("He said: \"ok\"")     # \" means a plain quote character
```

> 💡 Default to **double quotes**, switch to single when needed. Consistency matters more than which one you pick.

## Triple quotes: text across lines

```python
poem = """Roses are red,
violets are blue,
sugar is sweet,
and so are you."""
print(poem)
```

Three quotes (either kind) let text span lines, and **the line breaks are kept**. That's the `\n` from chapter 1, produced just by pressing Enter.

## Concatenation: joining strings

```python
first = "Hello"
second = "World"
print(first + second)      # HelloWorld
```

`+` joins them. But it **does not add a space**:

```python
print("Hello" + "World")       # HelloWorld   ← stuck together
print("Hello" + " " + "World") # Hello World
```

**String + number errors out.** One of the walls beginners hit most:

```python
age = 18
print("I am " + age)     # TypeError!
```

```
TypeError: can only concatenate str (not "int") to str
```

Translation: "you can only join strings to strings, not to int."

**The fix?** Convert the number:

```python
print("I am " + str(age))     # ✅
print("I am", age)            # ✅ a comma adds a space and converts for you
```

`str()` gets its own lesson next.

## Repetition: strings can be "multiplied"

```python
print("ha" * 3)          # hahaha
print("-" * 20)          # --------------------
print("=" * 10 + " title " + "=" * 10)
```

This is the trick behind the triangle question in the chapter 1 quiz. Handy for divider lines.

## Length: len()

```python
text = "Hello"
print(len(text))         # 5

print(len("你好"))       # 2  ← each Chinese character counts as 1
print(len(""))           # 0  empty string
```

**`len()` counts characters**, not bytes. Chinese characters and emoji each count as one (unlike some languages — Python 3 handles this naturally).

## Indexing: pulling out one character

Every character in a string has a number, its **index**.

**The key rule: counting starts at 0.**

```
char:    H    e    l    l    o
index:   0    1    2    3    4
```

```python
text = "Hello"
print(text[0])     # H
print(text[1])     # e
print(text[4])     # o
```

The first character's index is **0**, not 1. This is one of the most counter-intuitive and error-prone things in programming, and nearly every language does it.

### Negative indexes: count from the end

```python
print(text[-1])    # o  ← the last one
print(text[-2])    # l  ← second to last
```

For the last character, `text[-1]` beats `text[len(text)-1]` by a mile.

### Index out of range

```python
print(text[10])    # IndexError: string index out of range
```

"You asked for number 10, but this string only has 5."

## Slicing: taking a section

```python
text = "Hello World"
print(text[0:5])     # Hello
print(text[6:11])    # World
print(text[6:])      # World  ← omit the right, go to the end
print(text[:5])      # Hello  ← omit the left, start at the beginning
print(text[:])       # Hello World  ← omit both, everything
```

**The rule: include the left, exclude the right.**

`text[0:5]` takes indexes 0, 1, 2, 3, 4 — **not 5**. This "add one on the right" rule feels wrong at first, but it becomes instinctive.

Memory aid: picture indexes as the gaps *between* characters. `[0:5]` cuts from gap 0 to gap 5.

```
  H   e   l   l   o
0   1   2   3   4   5
```

Slices accept negatives and a step:

```python
print(text[::2])     # HloWrd  ← every other character
print(text[::-1])    # dlroW olleH  ← reversed
```

`[::-1]` to reverse is a trick worth memorising.

## Strings are immutable

**This matters a lot**: once created, a string's contents **cannot be changed**.

```python
text = "Hello"
text[0] = "h"        # TypeError!
```

To "change" it, **build a new one**:

```python
text = "Hello"
text = "h" + text[1:]      # build a new one with a slice
print(text)                # hello
```

It looks like editing, but it's really "make a new one from parts of the old, then move the label over". That's lesson 6's "variables are labels, not boxes".

## Common methods: the tools strings carry

Strings come with many ready-made operations, called with a dot:

```python
text = "  Hello World  "

print(text.strip())        # "Hello World"       remove spaces at both ends
print(text.lower())        # "  hello world  "   to lower case
print(text.upper())        # "  HELLO WORLD  "   to upper case
print(text.replace("o", "0"))   # "  Hell0 W0rld  "   replace
print(text.split())        # ['Hello', 'World']   split on spaces into a list
```

**None of these change the original** (strings are immutable) — they **return a new one**:

```python
text = "Hello"
print(text.upper())    # HELLO
print(text)            # Hello  ← unchanged!

# to keep the result, reassign
text = text.upper()
print(text)            # HELLO
```

### Finding: in and find

```python
text = "Hello World"

print("World" in text)       # True   ← is it in there?
print("Python" in text)      # False
print(text.find("World"))    # 6      ← where (-1 if absent)
```

`in` asks "does it contain", returning True/False. Used constantly.

### Counting and replacing

```python
text = "滚滚长江东逝水"
print(text.count("滚"))      # 2
print(len(text))             # 7
```

## Formatting: putting variables into strings

Joining with `+` is painful (plus the type conversion). Python has a much better way: **f-strings**.

```python
name = "Alex"
age = 18
print(f"I am {name} and I am {age}")
```

**Put an `f` before the quote**, then wrap variables in `{}`. The braces are replaced by the values, and types are converted for you — no `str(age)` needed.

You can even put expressions inside:

```python
print(f"Next year I will be {age + 1}")
print(f"The name is {len(name)} characters")
```

> 💡 f-strings arrived in Python 3.6 and are the recommended style today. Old tutorials use `%` and `.format()` — recognise them when you see them, but write f-strings yourself.

## Escape characters

Some characters can't be typed directly; a backslash `\` stands in for them:

| Written | Meaning |
|---|---|
| `\n` | newline |
| `\t` | tab |
| `\\` | a literal backslash |
| `\"` | a literal double quote |
| `\'` | a literal single quote |

```python
print("line one\nline two")
print("path: C:\\Users\\name")
```

**When a string has many backslashes** (Windows paths, regular expressions), put `r` before the quote for a "raw string" — no escape processing:

```python
print(r"C:\Users\name")     # prints as typed, no doubled backslashes
```
