# Asking the User a Question

> Up to now your programs have been monologues: the content is hard-coded, and everyone who runs it gets the same result.
>
> This lesson breaks that — the program will **ask the user for something** while it runs, then act on the answer. This is the line between "a script" and "a tool".

## First, look at how inflexible it is today

Say you wrote a greeting program:

```python
print("Hello, Xiaoming!")
print("You're 18, right?")
```

Run it ten thousand times and it says "Xiaoming" and "18" every time.

To greet someone else you have to **edit the code** — change Xiaoming to Xiaohong, run again.

That's absurd. You wrote the program so the computer does the work, yet every time the person changes you rewrite it. **A program should be a mold, not a finished product.**

What you actually want:

```
Program: What's your name?
User:    Xiaohong
Program: Hello, Xiaohong!
```

The name is decided *at run time*. That is exactly why `input()` exists.

## input(): the program stops and waits

```python
name = input("What's your name?")
print("Hello, " + name + "!")
```

Run it (in the web editor, hit Run and an input box appears):

```
What's your name?Xiaohong
Hello, Xiaohong!
```

Three things happened:

1. Execution reached `input(...)` and **stopped**
2. The prompt string was displayed, waiting for you to type
3. You pressed Enter; your text was packaged as a string and **handed to the variable on the left of `=`**

So `input()` means: **ask once, get one answer.**

That line reads in plain English as:

> Ask the user "What's your name?", and put whatever they answer into the box called `name`.

## The string in parentheses: the prompt

```python
input("What's your name?")
```

That string is the **prompt**. Its job is to tell the user *what to type now*.

What if there's no prompt?

```python
name = input()
```

The program **stops and shows nothing**. The user stares at a blinking cursor with no idea what to do — they may think it crashed.

**Always give input a prompt.** It's the bare minimum of courtesy to your user.

A small detail on wording:

| Code | User sees | Verdict |
|---|---|---|
| `input("Name")` | `Name` | Understandable, but the cursor is glued to the text |
| `input("Name: ")` | `Name: ` | Better — the colon hints "your turn" |
| `input("Please enter your name: ")` | `Please enter your name: ` | Clearest, a bit long |

Ending with a colon or space separates the cursor from the text:

```python
input("Please enter your name: ")
```

## A complete two-step exchange

Greeting alone is boring. Let the program *use* the name:

```python
name = input("What's your name?")
print("Hello, " + name + "!")
print(name + ", welcome to Python.")
```

Type "Xiaohong":

```
Hello, Xiaohong!
Xiaohong, welcome to Python.
```

Notice `name` can be **reused**. It's assigned once, then used as many times as you like — that's the whole value of a variable.

Something more useful — a birth year:

```python
name = input("What's your name?")
age = input("How old are you?")
print(name + ", you were probably born " + age + " years before 2025.")
```

Run:

```
What's your name?Xiaohong
How old are you?18
Xiaohong, you were probably born 18 years before 2025.
```

**Wait — why not just print 2007?**

Because `age` holds the **string** `"18"`, not the number `18`. You can't subtract from a string.

Lesson 12 fixes this. For now, note the phenomenon: **everything from the user is text.**

## Why you can't compute with it yet

A spoiler so you don't waste time guessing:

```python
age = input("How old are you?")   # user types 18
print(age + age)                  # gives 1818, not 36
```

`"18" + "18"` is string **concatenation**, so you get `"1818"`.

To do arithmetic, convert first — that's lesson 12. Build this intuition now:

> **Everything that comes from the user is text. To do math, convert first.**

## The moment the program stops

One key point about `input()`: **it blocks**.

```python
print("Line one")
name = input("Your name?")
print("Line three")
```

What happens:

```
Line one              ← shown immediately
Your name?_           ← cursor blinks, program waits here
                        (you type "Xiaohong" and press Enter)
Line three            ← only appears after you hit Enter
```

**Line three never appears before the user answers.** This matters for interactive programs: to collect three things, list three `input()` calls in order, and the user only sees question two after answering question one.

```python
a = input("First question: ")
b = input("Second question: ")
c = input("Third question: ")
print("All done!")
```

## Three things to remember

1. `input("prompt")` **stops and waits** for the user, and returns a string
2. The prompt is **mandatory** — without it the user has no idea what to do
3. **Everything the user types is a string** — convert before doing math (next lesson)
