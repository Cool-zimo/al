# Loops Inside Loops: Nesting

> Every loop so far has been "one-dimensional" — one repeated thing.
>
> But some repetition in the real world is **nested**: a year has 12 months, and **each month** has 30 days; a multiplication table has 9 rows, and **each row** has 9 columns.
>
> One loop can't express that. This lesson is about **a loop inside a loop**.

## 1. What Problem It Solves

Take something concrete: a multiplication table.

It looks like this (first 3 rows):

```
1×1=1
2×1=2  2×2=4
3×1=3  3×2=6  3×3=9
```

Look at its structure and you'll see **repetition twice over**:

- Outer repetition: **rows** repeat (row 1, row 2, row 3…)
- Inner repetition: **within each row, columns** repeat (row 3 computes three times)

In other words: **the act of "repeating something" is itself repeated 9 times.**

That's the reason nested loops exist.

## 2. What a Nested Loop Looks Like

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(i, "×", j, "=", i * j)
```

Run it (excerpt):

```
1 × 1 = 1
1 × 2 = 2
1 × 3 = 3
2 × 1 = 2
...
3 × 3 = 9
```

Nine lines total — **3 × 3 = 9**.

**Total rounds of a nested loop = outer count × inner count.**

## 3. How It Actually Runs (The Core Idea)

Miss this and everything nested stays foggy.

The execution order is:

> **The outer takes one step; the inner runs a full lap.**

With the code above:

| Outer i | Values inner j takes | What prints |
|---|---|---|
| i = 1 | j = 1, 2, 3 | 1×1, 1×2, 1×3 |
| i = 2 | j = 1, 2, 3 | 2×1, 2×2, 2×3 |
| i = 3 | j = 1, 2, 3 | 3×1, 3×2, 3×3 |

Once outer `i` becomes 1 it **stays put** while inner `j` runs from 1 to 3. When the inner finishes, `i` becomes 2, and then `j` **starts over from 1 again**.

**The inner loop restarts from scratch on every outer round.** That's the key insight about nested loops.

## 4. Indentation Decides What's Inside What

```python
for i in range(1, 4):          # level 1
    for j in range(1, 4):      # level 2 (indented 4)
        print(i, j)            # level 3 (indented 8)
```

To tell "which loop owns this code," the same old rule: **look at indentation**.

- Indented 4 → belongs to the outer loop; runs once per outer round
- Indented 8 → belongs to the inner loop; runs every inner round

An example that makes it visible:

```python
for i in range(1, 3):
    print("outer starts", i)

    for j in range(1, 3):
        print("   inner", j)

    print("outer ends", i)
```

Run it:

```
outer starts 1
   inner 1
   inner 2
outer ends 1
outer starts 2
   inner 1
   inner 2
outer ends 2
```

Count them: "outer starts" appears 2 times (outer count), "inner" appears 4 times (2×2).

**To check your understanding, make the two counts different** (outer 2, inner 3) and confirm you get 6.

## 5. The Two Loop Variables Must Have Different Names

```python
for i in range(1, 4):
    for i in range(1, 4):    # ❌ name reused
        print(i)
```

This **doesn't error**, but the inner loop overwrites the outer `i` and the result is a mess.

So the convention: **outer uses `i`, inner uses `j`, a third level uses `k`.**

Bugs like this don't raise errors and produce weird output — the hardest kind to find. Spend one extra second checking names.

## 6. Project: The Full 9×9 Table

Here's the prettiest code in this book so far. The target:

```
1×1=1
2×1=2  2×2=4
3×1=3  3×2=6  3×3=9
...
9×1=9  9×2=18 ... 9×9=81
```

The number of columns **equals the row number**: row 3 has 3 columns, row 9 has 9.

That means the inner count **isn't fixed** — it depends on which row the outer loop is on:

```python
for i in range(1, 10):
    for j in range(1, i + 1):
        print(i, "×", j, "=", i * j)
    print("---")
```

The key is `range(1, i + 1)` on line 2:

- i = 1 → `range(1, 2)` → j takes only 1 → 1 column
- i = 3 → `range(1, 4)` → j takes 1,2,3 → 3 columns
- i = 9 → `range(1, 10)` → j takes 1~9 → 9 columns

**The inner loop's endpoint is decided by the outer variable** — the most useful nested-loop technique there is.

That `+ 1` is the "end is excluded" rule from last lesson: to let j reach `i`, the end must be `i + 1`.

### Making it actually look like a table

Each `print` above ends with a newline, so you get one long column. To keep a row on one line, use the `end` argument:

```python
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{i}×{j}={i*j}", end="  ")
    print()          # this line only adds the newline
```

`print()` normally appends a newline. `end="  "` means "**end with two spaces instead, don't wrap.**"

That final empty `print()` exists just to **add one newline after the inner loop finishes**, so the next row starts on a fresh line.

> The `end` argument wasn't mentioned in lesson 13 (f-strings) because it only matters when you're **hand-controlling layout**.
> For everyday "one result per line" printing, the default is what you want.

## 7. How Deep to Nest

Two levels is normal. Three is already hard to read:

```python
for i in range(1, 3):
    for j in range(1, 3):
        for k in range(1, 3):
            print(i, j, k)      # 2×2×2 = 8 times
```

**If you find yourself needing three or more levels, that usually means you need a different approach** (functions, list comprehensions — later topics).

Be suspicious of three levels early on, and ask whether it can be split up.
