# Project: A Personal Info Card

> The last lesson of chapter 3. No new syntax — instead we **wire the previous four lessons into one genuinely usable program**.
>
> This is the first thing you've built that you could actually show someone: it asks questions, does arithmetic, lays itself out nicely, and doesn't fall over when the user types something messy.

## What we're building

What it looks like when run (user input marked with `←`):

```
===== Personal Info Card Generator =====

Your name: Xiaohong ←
Your age: 18 ←
Your height (m): 1.65 ←
Your city:  Beijing ←
A favourite quote:  Keep going ←

==============================
        Personal Info Card
==============================
  Name      Xiaohong
  Age       18 (born around 2007)
  Height    1.65 m
  City      Beijing
  Motto     "Keep going"
==============================
```

Looks like something. But every line uses stuff you already learned:

| On the card | Uses | From |
|---|---|---|
| Name, city, motto | `input()` | Lesson 11 |
| Birth year (2025 − 18) | `int()` then arithmetic | Lesson 12 |
| Neat layout | `f-string` + alignment | Lesson 13 |
| Spaces don't break it | `strip()` | Lesson 14 |

## Version 1: just make it run

Don't aim for perfect in one shot. Build the skeleton:

```python
print("===== Personal Info Card Generator =====")
print()

name = input("Your name: ")
age = input("Your age: ")
height = input("Your height (m): ")
city = input("Your city: ")
motto = input("A favourite quote: ")

print()
print("==============================")
print("        Personal Info Card")
print("==============================")
print(f"  Name      {name}")
print(f"  Age       {age}")
print(f"  Height    {height}")
print(f"  City      {city}")
print(f"  Motto     {motto}")
print("==============================")
```

Run it — the card appears. **But there are three problems:**

### Problem 1: no birth year

We have the age but never compute the year. Add:

```python
birth_year = 2025 - int(age)
```

and change the line to `f"  Age       {age} (born around {birth_year})"`.

Note `int(age)` — `age` comes from `input`, so it's a string and **must be converted to do subtraction**. Skip that and you get lesson 12's `TypeError`.

### Problem 2: stray spaces look bad

Type ` Beijing ` and the card shows `  City      Beijing ` with a trailing space, breaking the layout.

Fix: add `.strip()` to every `input`.

```python
name = input("Your name: ").strip()
```

### Problem 3: height is a string

`1.65` is a decimal. We're not computing with it, so it's fine now — but a BMI calculation would need `float(height)`.

## Version 2: cleaning plus birth year

```python
print("===== Personal Info Card Generator =====")
print()

name = input("Your name: ").strip()
age = input("Your age: ").strip()
height = input("Your height (m): ").strip()
city = input("Your city: ").strip()
motto = input("A favourite quote: ").strip()

birth_year = 2025 - int(age)

print()
print("==============================")
print("        Personal Info Card")
print("==============================")
print(f"  Name      {name}")
print(f"  Age       {age} (born around {birth_year})")
print(f"  Height    {height} m")
print(f"  City      {city}")
print(f"  Motto     \"{motto}\"")
print("==============================")
```

Run it and you've basically hit the target.

## Better: real alignment

Right now the columns are held together by hand-typed spaces. If the name is long ("Bartholomew Featherstonehaugh"), the layout collapses.

Use f-string alignment (lesson 13):

```python
print(f"  {'Name':<6}{name}")
print(f"  {'Age':<6}{age} (born around {birth_year})")
print(f"  {'Height':<6}{height} m")
print(f"  {'City':<6}{city}")
print(f"  {'Motto':<6}\"{motto}\"")
```

`{'Name':<6}` means: **left-align the word "Name" in a 6-character field**.

One gotcha: **a CJK character is usually twice as wide as a Latin one**, so `<6` isn't perfectly accurate for Chinese labels. It's good enough in most terminals and browsers — don't obsess over it.

## One more: allow empty answers

The user is lazy and hits Enter on city and motto. Right now you get blank lines:

```
  City      
  Motto     ""
```

Ugly. Give them defaults:

```python
if not city:
    city = "not provided"
if not motto:
    motto = "(this person was too lazy to leave anything)"
```

(Lesson 14's empty check.)

## Final version

```python
print("===== Personal Info Card Generator =====")
print()

name = input("Your name: ").strip()
age = input("Your age: ").strip()
height = input("Your height (m): ").strip()
city = input("Your city: ").strip()
motto = input("A favourite quote: ").strip()

# fallbacks for empty answers
if not city:
    city = "not provided"
if not motto:
    motto = "(this person was too lazy to leave anything)"

# compute the birth year
birth_year = 2025 - int(age)

# print the card
print()
print("==============================")
print("        Personal Info Card")
print("==============================")
print(f"  {'Name':<6}{name}")
print(f"  {'Age':<6}{age} (born around {birth_year})")
print(f"  {'Height':<6}{height} m")
print(f"  {'City':<6}{city}")
print(f"  {'Motto':<6}\"{motto}\"")
print("==============================")
```

**That's a complete, shareable little program.**

## Be honest: what's still missing?

Let's list it, **rather than pretending it's perfect**:

| Gap | Consequence | Fixed in |
|---|---|---|
| Typing "eighteen" crashes | `int()` raises ValueError | `try...except`, Basics 3 |
| No chance to re-enter | a typo means restarting | loops, Basics 2 |
| 2025 hard-coded | wrong next year | date modules, Basics 3 |
| Data vanishes on exit | nothing is saved | file I/O, Basics 3 |

**These aren't defects, they're progress markers.** Each has a known time and place to be solved — and knowing they exist puts you ahead of someone who thinks their program is finished.
