# If… then…: The Shape of `if`

> Every program you've written so far has one thing in common: **it runs top to bottom once, then stops.**
>
> No matter what you type in, it produces the same result. That's a script, not a tool.
>
> This lesson gives your program its first real taste of "intelligence" — **doing different things in different situations.**

## 1. What Problem Does `if` Solve?

Think about something you do every morning:

> **If** it's raining, **then** take an umbrella.

Notice the shape of that sentence. It has a **condition** (it's raining) and an **action that only happens when the condition is true** (take an umbrella).

And if it's not raining? You never reach for the umbrella — the action is **skipped**.

That is the entire meaning of `if`. **`if` means "if."**

Here's a programming example. Say you're writing a ticket pricing program:

- Age under 12 → child ticket, $20
- Age 12 or over → adult ticket, $40

With everything you know right now, you cannot write this program. You have no way to express "it depends."

`if` exists to solve exactly that.

## 2. What `if` Looks Like

```python
age = 18

if age >= 18:
    print("You are an adult")
```

Run it and you'll see:

```
You are an adult
```

Now change `age` to 10 and run it again. You'll see… **nothing at all.**

That is what `if` does: **if the condition is true, do it; if not, skip it and do nothing.**

## 3. Three Details You Must Remember

This is the part where beginners crash most often. Take it slowly.

### 1. The condition must be followed by a colon `:`

```python
if age >= 18:        # ← this colon is mandatory
    print("You are an adult")
```

Without it you get `SyntaxError: expected ':'`.

This is the single most common beginner error, bar none. **Mantra: after an `if` condition, the colon never goes missing.**

### 2. The line after the colon must be indented

```python
if age >= 18:
    print("You are an adult")     # ← 4 spaces at the front
```

Those 4 spaces are **not a style preference — they are part of the syntax.**

They tell Python: "this line belongs to the `if` above."

### 3. However many lines you indent, that's how many the `if` owns

```python
age = 18

if age >= 18:
    print("You are an adult")          # owned by the if
    print("You can apply for a license")  # also owned (same indent)
print("Program finished")              # not owned (no indent)
```

Output:

```
You are an adult
You can apply for a license
Program finished
```

Now change `age` to 10:

```
Program finished
```

See it? **The first two lines were skipped entirely, but "Program finished" printed anyway.**

Because it's the only unindented line — it runs no matter what the `if` decides.

## 4. Indentation: Python's Most Distinctive Trait

Most languages use curly braces `{}` to show "who does this code belong to":

```javascript
if (age >= 18) {
    print("You are an adult");
}
```

Python doesn't use braces. It uses **indentation only.** Two consequences:

**The good:** code is naturally tidy. It's impossible to write code that looks messy but runs.

**The bad:** get the indentation wrong and the *behavior* is wrong — and it **won't raise an error, it'll just give you the wrong result.**

### Indentation must be consistent

```python
if age >= 18:
    print("You are an adult")
      print("You can apply for a license")   # ✗ 6 spaces here
```

Python raises `IndentationError`.

The rule is simple: **every line in the same block must be indented by exactly the same amount.**

Always use **4 spaces**. Don't mix 2 spaces and 4 spaces, and never mix tabs with spaces (they look identical but Python sees two different things — mixing them will blow up).

### A classic trap: forgetting to indent

```python
age = 18
if age >= 18:
print("You are an adult")        # ✗ forgot the indent
```

This raises `IndentationError: expected an indented block`.

Translated: **I was waiting for an indented block and you didn't give me one.**

## 5. Where Conditions Come From

The thing after `if` is called the **condition**.

A condition has exactly one requirement: **it must evaluate to True or False.**

The comparison operators you learned in Chapter 2 are precisely machines that produce True / False:

| Expression | Meaning | Example | Result |
|---|---|---|---|
| `a == b` | a equals b | `5 == 5` | True |
| `a != b` | a is not equal to b | `5 != 3` | True |
| `a > b` | a is greater than b | `5 > 8` | False |
| `a < b` | a is less than b | `5 < 8` | True |
| `a >= b` | a is greater than or equal to b | `5 >= 5` | True |
| `a <= b` | a is less than or equal to b | `5 <= 3` | False |

So all of these work as conditions:

```python
score = 85
if score >= 60:
    print("You passed")
```

```python
name = "Alex"
if name == "Alex":
    print("Hello, Alex")
```

### ⚠️ `==` and `=` Are Not the Same Thing

This is the second great beginner trap, and its **error message is unhelpfully cryptic**.

```python
if score = 60:       # ✗ error
    print("Exactly passing")
```

The difference:

- `=` is **assignment** — "put the value on the right into the variable on the left"
- `==` is **comparison** — "are these two things equal?"

An `if` needs a yes-or-no answer, so it uses `==`.

If you type `=` by accident, Python says something like `SyntaxError: cannot assign to literal`, which is confusing — just remember the rule: **to test equality inside an `if`, always use two equals signs.**

## 6. Putting `if` to Work: The Ticket Program

Now you can write that ticket program from the top of the lesson, using two separate `if` statements:

```python
age = 8

if age < 12:
    print("Child ticket: $20")

if age >= 12:
    print("Adult ticket: $40")
```

`age` is 8, so the first condition holds and the second doesn't — only the child ticket prints.

Change age to 20 and only the adult ticket prints.

It works, but it's clumsy. You stated the same fact twice, and those two conditions are really **two sides of one thing** (either under 12, or not under 12).

The next lesson's `else` makes this much cleaner.

```quiz
type: code
q: The forecast says 35 degrees. Write code that prints "Hot today" when the temperature is above 30.
starter: |
  temp = 35

  # write your if here

tests:
- assert "Hot today" in __out
hint: Three things: start with if, use the condition temp > 30, don't forget the colon, and indent print by 4 spaces.
explain: temp > 30 is true, so the indented print runs. Change temp to 20 and think again — the condition fails, that line gets skipped, and nothing prints at all.
```

## 7. When `if` Fails, the Program Keeps Going

Beginners misunderstand this constantly, so it deserves its own section.

```python
age = 10

if age >= 18:
    print("You are an adult")

print("Program finished")
print("bye")
```

Output:

```
Program finished
bye
```

**A failed `if` does not stop the program.** It skips only the block that belongs to it, then carries on.

This matters enormously, because later you'll line up many `if` statements — each one gets evaluated in turn and skipped if it fails.

```quiz
- Only B
- Both A and B
- Neither
answer: 1
explain: age is 10, so the condition fails and the indented print("A") is skipped. But print("B") has no indent, so it has nothing to do with the if and definitely runs. This is the key insight about if: failing means skip, not stop.
```
