# Otherwise: `else`

> The `if` from the last lesson has an obvious gap: **when the condition fails, it does nothing.**
>
> But real life is usually "one of two things, always one." Passed → "you passed"; failed → "resit."
> You always need to say *something*.
>
> `else` is that "otherwise."

## 1. What Problem Does `else` Solve?

Back to the ticket program. Last lesson we wrote:

```python
age = 8

if age < 12:
    print("Child ticket: $20")

if age >= 12:
    print("Adult ticket: $40")
```

It runs, but there's a hidden risk: **you described the same fact twice, in two places.**

`age < 12` and `age >= 12` together cover every possible case — they are two sides of one thing.

Suppose one day the cutoff changes to 14. You'd have to change **both** lines, and if you miss one you get a bizarre bug (a 13-year-old gets billed as both a child and an adult, or as neither).

`else` lets you state the condition once:

```python
age = 8

if age < 12:
    print("Child ticket: $20")
else:
    print("Adult ticket: $40")
```

**`else` means: when the condition above fails, come to me.**

Now if the cutoff moves to 14, you change exactly one line.

## 2. What `else` Looks Like

```
if condition:
    what to do when true
else:
    what to do when false
```

Four details:

1. `else` must line up with `if` (same indent level)
2. `else` **also needs a colon** `:`
3. `else` **cannot take a condition** (the most common beginner mistake — see below)
4. The code under `else` **also needs to be indented**

### ⚠️ `else` Cannot Take a Condition

```python
if age < 12:
    print("Child ticket")
else age >= 12:        # ✗ error!
    print("Adult ticket")
```

Why not? Because `else` means "**everything else.**"

You already stated the condition in the `if`. `else` takes all that's left over, so it doesn't need — and isn't allowed — another condition.

If you want to say "otherwise **if**…", that's `elif`, coming next lesson.

## 3. Exactly One of `if` and `else` Always Runs

This is the most important property of `else`, and the biggest difference from two separate `if`s.

```python
age = 8
if age < 12:
    print("Child ticket")
else:
    print("Adult ticket")
```

- age = 8 → prints "Child ticket"
- age = 20 → prints "Adult ticket"
- age = -5 → prints "Child ticket" (negative is also under 12)
- age = 12 → prints "Adult ticket"

**Whatever age is, exactly one of the two blocks runs — never both, never neither.**

This is called *mutually exclusive and exhaustive*.

Compare with two independent `if`s:

```python
if age < 12:
    print("Child ticket")
if age > 30:
    print("Youth ticket")
```

age = 8 → first holds, second doesn't. age = 35 → first fails, second holds.
age = 20 → **neither holds, nothing prints.**

So: **when the two cases are two sides of one thing, use `if`/`else`. When they're two independent facts, use two `if`s.**

## 4. The Code Under `else` Needs Indenting Too

```python
score = 45

if score >= 60:
    print("Passed")
    print("Congratulations")
else:
    print("Failed")
    print("Better luck next time")
```

score is 45, so we take the `else`:

```
Failed
Better luck next time
```

Indentation works exactly the same here as under `if`: **however many lines you indent is how many lines it owns.**

A common mistake — not indenting under `else`:

```python
if score >= 60:
    print("Passed")
else:
print("Failed")         # ✗ forgot the indent
```

Same `IndentationError: expected an indented block`.

## 5. A More Practical Example

Check whether a number is odd or even:

```python
num = 17

if num % 2 == 0:
    print("Even")
else:
    print("Odd")
```

`%` is the remainder operator. `num % 2` is "the remainder after dividing by 2."

- Remainder 0 → divisible by 2 → even
- Remainder not 0 → odd

That's textbook "two sides of one thing," and `if`/`else` maps onto it perfectly.

## 6. `if` / `else` Can Be Nested Inside Other Code

Just a heads-up now; you'll see it constantly later.

An `if`/`else` is one structure, and it can appear anywhere a statement is allowed — inside a loop (next chapter) or inside a function (Chapter 8).

For now, just know this: **`if` and `else` always come as a pair. `else` cannot exist alone.**

```python
else:               # ✗ error: no if before else
    print("otherwise")
```

That gives `SyntaxError: invalid syntax`.
