# Making Output Look Good

Last lesson you learned to convert types, so your results are correct. But your print line probably looks like this:

```python
print("Hello, " + name + "! You are " + str(age) + " years old, and " + str(height) + " m tall.")
```

A pile of plus signs, a pile of quotes, and you have to remember `str()`. Painful to write, worse to read.

This lesson teaches **f-strings** — the recommended way to format text in modern Python. With it, that line becomes:

```python
print(f"Hello, {name}! You are {age} years old, and {height} m tall.")
```

## Feel the difference first

**Old way (concatenation):**

```python
name = "Xiaohong"
age = 18
print("I'm " + name + ", and I'm " + str(age) + ".")
```

Output: `I'm Xiaohong, and I'm 18.`

**f-string way:**

```python
name = "Xiaohong"
age = 18
print(f"I'm {name}, and I'm {age}.")
```

Identical output, but the code is a level cleaner.

What changed? In the old way you **glue parts together** (with `+`). With an f-string you **write one sentence with a few holes in it** (filled by `{}`).

**Writing a sentence is naturally easier than gluing parts.**

## How to use it: two steps

### Step 1: put `f` before the quote

```python
print(f"This is an f-string")
```

`f` means *format*. It tells Python: **treat curly braces in this string specially.**

Forget the `f`? The braces are printed as ordinary characters:

```python
name = "Xiaohong"
print("Hello, {name}")    # forgot the f
```

Output: `Hello, {name}` ← a very common beginner slip. If you see literal braces in output, check for the `f`.

### Step 2: wrap variables in `{}`

```python
print(f"Hello, {name}")
```

Python **replaces `{name}` with the value of `name`.**

### Bonus: forget about types

This is the biggest win — **anything inside `{}` displays directly, no `str()` needed.**

```python
name = "Xiaohong"
age = 18
height = 1.65
is_student = True

print(f"Name: {name}, Age: {age}, Height: {height}, Student: {is_student}")
```

Output: `Name: Xiaohong, Age: 18, Height: 1.65, Student: True`

Four variables, four types (string, int, float, bool) — **not a single `str()`**.

Compare with concatenation:

```python
print("Name: " + name + ", Age: " + str(age) + ", Height: " + str(height) + ", Student: " + str(is_student))
```

The moment you see repeated `str()`, you should think of f-strings.

## `{}` can hold more than a variable

That's where f-strings get really powerful — **the braces can contain a whole expression.**

### Compute inline

```python
price = 25
count = 3
print(f"Total: {price * count} yuan")
```

Output: `Total: 75 yuan`

No need to compute into a variable first — `price * count` goes straight inside `{}`.

### Call a function

```python
name = "Xiaohong"
print(f"Length: {len(name)}")
print(f"Upper: {name.upper()}")
```

### Call a method

```python
text = "  Hello  "
print(f"Trimmed: {text.strip()}")
```

(`strip()` is covered in detail in lesson 14.)

### Numbers with formatting

Want to control decimal places? Use `:.2f` (two decimals):

```python
pi = 3.1415926
print(f"Pi is about {pi:.2f}")
```

Output: `Pi is about 3.14`

`:.2f` reads as "colon dot two f" — **after the colon comes the format spec**. Common ones:

| Syntax | Meaning | Example (`x = 3.14159`) | Output |
|---|---|---|---|
| `{x:.2f}` | 2 decimal places | `f"{x:.2f}"` | `3.14` |
| `{x:.0f}` | no decimals (rounded) | `f"{x:.0f}"` | `3` |
| `{x:>10}` | right-aligned, 10 chars wide | `f"{x:>10.2f}"` | `      3.14` |

Alignment shines when printing tables:

```python
print(f"{'apple':<6}{'3.5':>8}")
print(f"{'banana':<6}{'2.0':>8}")
```

Output:

```
apple      3.5
banana     2.0
```

`<6` is left-aligned in 6 columns, `>8` right-aligned in 8. Right-aligning numbers is standard (units line up, easy to compare).

## Multi-line output: triple quotes + f

To print several lines at once, use triple quotes:

```python
name = "Xiaohong"
age = 18
info = f"""
===== Profile =====
Name: {name}
Age:  {age}
===================
"""
print(info)
```

The leading `f` still applies — braces are replaced as usual.

## When not to use an f-string

**When there's no variable to insert.**

```python
print("Welcome")     # correct — just write it
print(f"Welcome")    # pointless — f with no braces
```

An `f` with no `{}` won't error; it's just noise. **Seeing an f-string with no braces usually means someone copy-pasted it.**

## Three ways compared

Same goal: print "I'm Xiaohong, 18 years old".

| Style | Code | Verdict |
|---|---|---|
| Comma-separated | `print("I'm", name, ",", age, "years old")` | Works, but Python **auto-inserts spaces** between parts, so punctuation gets stray spaces |
| Concatenation | `print("I'm " + name + ", " + str(age) + " years old")` | Precise, but too many quotes and `str()` |
| **f-string** | `print(f"I'm {name}, {age} years old")` | **Recommended.** Readable, type-agnostic |

A note on commas: `print("I'm", name)` outputs `I'm Xiaohong` with an automatic space. **Prefer f-strings for precise spacing.**

## Three things to remember

1. **`f` before the quote, `{variable}` inside** — that's it
2. **No `str()` needed** inside `{}`; expressions work too
3. Forgetting `f` means **braces print literally** — the most common mistake

```python
name = "Xiaoming"
score = 95
print("Student " + name + " scored " + str(score) + ".")
```
