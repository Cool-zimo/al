# CSV files

> The most widely used format for tabular data. Excel opens it, pandas reads it, Python handles it.

## What CSV looks like

```
name,age,city
Alice,18,London
Bob,20,Paris
Carol,19,Berlin
```

**Simple rules:**
- one record per line
- fields separated by **commas** (CSV = Comma-Separated Values)
- the first line is usually a **header**

**It's just a text file** — Notepad can open it.

## Reading with the csv module

```python
import csv

with open('people.csv', 'r', encoding='utf-8') as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)
```

```
['name', 'age', 'city']
['Alice', '18', 'London']
['Bob', '20', 'Paris']
['Carol', '19', 'Berlin']
```

**Each row is a list.**

**Note: every value is a string** — `'18'` is not the number 18.

```python
age = row[1]              # '18'
age = int(row[1])         # 18  ← convert yourself
```

## Skipping the header

```python
import csv

with open('people.csv', 'r', encoding='utf-8') as f:
    reader = csv.reader(f)
    header = next(reader)          # consume the first row
    print("header:", header)
    for row in reader:
        print(f"{row[0]} is {row[1]}")
```

**`next(reader)` fetches the next row** — use it to eat the header.

## DictReader: fetch by column name (recommended)

```python
import csv

with open('people.csv', 'r', encoding='utf-8') as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row['name'], row['age'])
```

**`DictReader` turns each row into a dict** keyed by the header:

```
{'name': 'Alice', 'age': '18', 'city': 'London'}
```

**Far clearer than `row[0]`** — no remembering which column is which.

## Writing CSV

```python
import csv

data = [
    ['name', 'age', 'city'],
    ['Alice', 18, 'London'],
    ['Bob', 20, 'Paris'],
]

with open('out.csv', 'w', encoding='utf-8', newline='') as f:
    writer = csv.writer(f)
    writer.writerows(data)
```

> ⚠️ **`newline=''` is required!** Without it, Windows gets a blank line between every row.

**Why:** the csv module writes `\r\n` itself, and Windows text mode turns `\n` into `\r\n` again — producing `\r\r\n`.

## Writing row by row

```python
with open('out.csv', 'w', encoding='utf-8', newline='') as f:
    writer = csv.writer(f)
    writer.writerow(['name', 'age'])       # one row
    writer.writerow(['Alice', 18])
```

**`writerow` writes one; `writerows` writes many.**

## DictWriter: write by column name

```python
import csv

with open('out.csv', 'w', encoding='utf-8', newline='') as f:
    fieldnames = ['name', 'age', 'city']
    writer = csv.DictWriter(f, fieldnames=fieldnames)

    writer.writeheader()                              # the header row
    writer.writerow({'name': 'Alice', 'age': 18, 'city': 'London'})
    writer.writerow({'name': 'Bob', 'age': 20, 'city': 'Paris'})
```

**`writeheader()` writes the header**, then pass a dict per row.

## The trap: a comma inside a field

If a value itself contains a comma, naive concatenation shifts the columns:

```python
# ❌ "London,Central" would be read as two fields
line = f"{name},{city}"
```

**The csv module quotes it automatically:**

```python
import csv
with open('t.csv', 'w', encoding='utf-8', newline='') as f:
    w = csv.writer(f)
    w.writerow(['Alice', 'London,Central'])      # quoted automatically
```

Result:

```
Alice,"London,Central"
```

**That's why you use the csv module instead of gluing strings together.**

## Practice: a score sheet

```python
import csv

scores = [
    {'name': 'Alice', 'maths': 80, 'science': 90},
    {'name': 'Bob', 'maths': 95, 'science': 88},
    {'name': 'Carol', 'maths': 78, 'science': 92},
]

# write
with open('scores.csv', 'w', encoding='utf-8', newline='') as f:
    writer = csv.DictWriter(f, fieldnames=['name', 'maths', 'science'])
    writer.writeheader()
    writer.writerows(scores)

# read back and average
with open('scores.csv', 'r', encoding='utf-8') as f:
    rows = list(csv.DictReader(f))

for r in rows:
    avg = (int(r['maths']) + int(r['science'])) / 2
    print(f"{r['name']}: average {avg}")
```

```
Alice: average 85.0
Bob: average 91.5
Carol: average 85.0
```

## csv versus pandas

Once you've done Data Analysis 2 you'll know pandas' `read_csv` is nicer:

```python
import pandas as pd
df = pd.read_csv('scores.csv')      # one line, types inferred
```

**But the csv module still earns its place:**
- standard library — nothing to install
- lighter on memory for huge files (streams line by line)
- shorter code for simple jobs

## Summary

| Need | Write |
|---|---|
| read (lists) | `csv.reader(f)` |
| read (dicts) | `csv.DictReader(f)` ← recommended |
| write (lists) | `csv.writer(f)` + `writerow(s)` |
| write (dicts) | `csv.DictWriter(f, fieldnames=...)` |
| **when writing** | **always `newline=''`** |
| skip header | `next(reader)` |
| value types | **all strings** — convert yourself |
