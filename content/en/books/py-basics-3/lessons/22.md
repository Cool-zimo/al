# Defining classes and creating objects

> You've seen the shape — now every part in detail.

## Defining a class

```python
class ClassName:
    def method(self, args):
        ...
```

**The minimal form:**

```python
class Dog:
    pass          # does nothing — still valid
```

**`pass` is a placeholder** for when syntax demands a statement but you've nothing to write yet.

## Creating an object

```python
class Dog:
    def bark(self):
        return "Woof"

d = Dog()          # ← create an object (instantiate)
print(d.bark())
```

**`ClassName()` builds an object** — it looks just like calling a function.

## A complete class

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        return f"{self.name}: Woof!"

    def human_age(self):
        return self.age * 7


d1 = Dog("Rex", 3)
d2 = Dog("Snow", 5)

print(d1.bark())              # Rex: Woof!
print(d2.bark())              # Snow: Woof!
print(d1.human_age())         # 21
```

**Two objects with their own data**, sharing the same methods.

## __init__: the constructor

```python
def __init__(self, name, age):
    self.name = name
    self.age = age
```

**`__init__` runs automatically when you create an object**, to set up its attributes.

**Two underscores on each side** (`__init__`) marks a **magic / special method** — Python calls these at specific moments.

```python
d = Dog("Rex", 3)
#     ↓ effectively
# d = Dog.__init__(d, "Rex", 3)
```

**You never call `__init__` yourself** — `Dog("Rex", 3)` triggers it.

## What is self?

**`self` means "this object".**

```python
class Dog:
    def bark(self):
        return f"{self.name}: Woof!"     # self.name = this dog's name
```

**Why is it needed?** Because one method is shared by many objects, so the method must know which object is calling.

```python
d1 = Dog("Rex", 3)
d2 = Dog("Snow", 5)

d1.bark()     # Python runs Dog.bark(d1)  → self is d1
d2.bark()     # Python runs Dog.bark(d2)  → self is d2
```

**That's the entire secret of `self`**: calling `d1.bark()` makes Python pass `d1` as the first argument.

> 💡 **So the first parameter must be `self`** (you could rename it, but don't — everyone uses `self`). **You don't pass it when calling.**

## Attributes: the object's variables

```python
class Dog:
    def __init__(self, name):
        self.name = name        # ← defines an attribute
```

**`self.xxx = value` adds an attribute.**

**You can add attributes any time** (not only in `__init__`):

```python
d = Dog("Rex")
d.color = "black"        # added later — legal
print(d.color)
```

> ⚠️ **But don't.** Attributes scattered around are hard to maintain. **Define them all in `__init__`**, even as placeholders:

```python
class Dog:
    def __init__(self, name):
        self.name = name
        self.color = None        # placeholder
        self.tricks = []         # empty list to start
```

## Reading and writing attributes

```python
d = Dog("Rex", 3)
print(d.name)          # read
d.name = "Big Rex"     # write
print(d.name)          # Big Rex
```

**Python attributes are public** — there's no real "private" (that's Java/C++).

**Convention**: a leading underscore means "internal, don't touch from outside":

```python
class BankAccount:
    def __init__(self):
        self._balance = 0        # convention: internal
```

(Lesson 26 covers `@property` for cleaner control.)

## Methods are functions in a class

```python
class Calculator:
    def add(self, a, b):
        return a + b

    def multiply(self, a, b):
        return a * b
```

**Apart from the `self` first parameter, methods are ordinary functions.**

**If a method never uses self**, you can write:

```python
class MathUtils:
    @staticmethod
    def add(a, b):          # no self
        return a + b

print(MathUtils.add(1, 2))      # no object needed
```

**`@staticmethod`** means "a plain function hung on the class". (Advanced — just know it exists.)

## A worked example

```python
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("deposit must be positive")
        self.balance += amount
        return self.balance

    def withdraw(self, amount):
        if amount > self.balance:
            raise ValueError("insufficient funds")
        self.balance -= amount
        return self.balance

    def __str__(self):
        return f"{self.owner}'s account: {self.balance}"


acc = BankAccount("Alice", 100)
acc.deposit(50)
print(acc.balance)        # 150
acc.withdraw(30)
print(acc)                # Alice's account: 120
```

**`__str__`** is another magic method — it decides what `print(object)` shows (lesson 24).

## Summary

| Idea | Syntax |
|---|---|
| define a class | `class Name:` |
| constructor | `def __init__(self, ...)` — called automatically |
| `self` | means "this object"; **never passed by you** |
| attribute | `self.x = value`, best defined in `__init__` |
| method | a function in the class, first parameter `self` |
| create an object | `ClassName(args)` |
