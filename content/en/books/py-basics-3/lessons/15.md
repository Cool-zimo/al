# Practice: a program you can't break

> Use everything from this chapter to write something that survives whatever the user types.

## The goal

A **score manager** that can:
- add a student's score
- list everyone
- show the average
- save to and load from a file

**Requirement: no matter what the user types, it doesn't crash.**

## First, the fragile version

```python
# ❌ crash points everywhere
students = {}

while True:
    print("1.add  2.list  3.average  4.quit")
    choice = input("choose: ")

    if choice == '1':
        name = input("name: ")
        score = int(input("score: "))        # letters crash this
        students[name] = score
    elif choice == '2':
        for n, s in students.items():
            print(n, s)
    elif choice == '3':
        print(sum(students.values()) / len(students))   # divide by zero when empty
    elif choice == '4':
        break
```

**Three crash points:**
1. `int(input())` — non-numeric input
2. the average — `len(students)` is 0 when empty
3. loading — the file may not exist

## Fortifying one by one

### 1. Numeric input

```python
def input_number(prompt, min_val=None, max_val=None):
    """Keep asking until we get a valid number."""
    while True:
        raw = input(prompt).strip()
        try:
            n = float(raw)
        except ValueError:
            print("  ✗ please enter a number")
            continue

        if min_val is not None and n < min_val:
            print(f"  ✗ can't be below {min_val}")
            continue
        if max_val is not None and n > max_val:
            print(f"  ✗ can't be above {max_val}")
            continue

        return n
```

**This "input helper" is worth memorising** — it works anywhere you need a number.

### 2. Division on empty data

```python
def average(scores):
    if not scores:
        return None            # no data, no crash
    return sum(scores) / len(scores)

avg = average([])
if avg is None:
    print("no scores yet")
else:
    print(f"average: {avg:.1f}")
```

**Principle: when something might be empty, return early with `if not ...`** rather than letting it blow up.

### 3. File I/O

```python
import json
import os


def load(filename):
    try:
        with open(filename, 'r', encoding='utf-8') as f:
            content = f.read()
    except FileNotFoundError:
        return {}                       # first run — no file is normal
    except PermissionError:
        print("no permission — starting empty")
        return {}

    if not content.strip():
        return {}                       # empty file

    try:
        return json.loads(content)
    except json.JSONDecodeError:
        print("corrupt file — starting empty")
        return {}


def save(filename, data):
    try:
        with open(filename, 'w', encoding='utf-8') as f:
            json.dump(data, f, ensure_ascii=False, indent=2)
        return True
    except OSError as e:                # disk full, no permission, ...
        print(f"save failed: {e}")
        return False
```

**Three layers of defence**: missing file, empty file, invalid JSON.

## The complete version

```python
import json

FILE = 'students.json'


def input_number(prompt, min_val=None, max_val=None):
    """Keep asking until we get a valid number."""
    while True:
        raw = input(prompt).strip()
        try:
            n = float(raw)
        except ValueError:
            print("  ✗ please enter a number")
            continue
        if min_val is not None and n < min_val:
            print(f"  ✗ can't be below {min_val}")
            continue
        if max_val is not None and n > max_val:
            print(f"  ✗ can't be above {max_val}")
            continue
        return n


def load():
    try:
        with open(FILE, 'r', encoding='utf-8') as f:
            content = f.read()
    except FileNotFoundError:
        return {}
    except PermissionError:
        print("no permission to read")
        return {}

    if not content.strip():
        return {}
    try:
        return json.loads(content)
    except json.JSONDecodeError:
        print("corrupt file — starting empty")
        return {}


def save(data):
    try:
        with open(FILE, 'w', encoding='utf-8') as f:
            json.dump(data, f, ensure_ascii=False, indent=2)
        return True
    except OSError as e:
        print(f"save failed: {e}")
        return False


students = load()
print(f"loaded {len(students)} student(s)")

while True:
    print("\n1.add  2.list  3.average  4.save  5.quit")
    choice = input("choose: ").strip()

    if choice == '1':
        name = input("name: ").strip()
        if not name:
            print("  ✗ name can't be empty")
            continue
        score = input_number("score: ", 0, 100)
        students[name] = score
        print(f"  ✓ added {name}")

    elif choice == '2':
        if not students:
            print("  no students yet")
        else:
            for n, s in students.items():
                print(f"  {n}: {s}")

    elif choice == '3':
        if not students:
            print("  no scores yet")
        else:
            avg = sum(students.values()) / len(students)
            print(f"  average: {avg:.1f}")

    elif choice == '4':
        if save(students):
            print("  ✓ saved")

    elif choice == '5':
        save(students)
        print("bye")
        break

    else:
        print("  please enter 1-5")
```

## Why it can't be broken

| What the user does | What happens |
|---|---|
| types `abc` for the score | "please enter a number", asks again |
| types `-5` or `200` | "can't be below 0" / "can't be above 100" |
| presses enter for the name | "name can't be empty" |
| picks average with no data | "no scores yet" |
| enters `99` at the menu | "please enter 1-5" |
| runs it for the first time | starts fine with 0 students |
| corrupts the file | "corrupt file — starting empty" |

**Every case is handled** — that's the difference between professional and hobby code.

## The three levels of error handling

Looking back over this chapter:

| Level | What it does | Where |
|---|---|---|
| **Prevent it** | check first (`if not ...`) | logic you control |
| **Catch it** | `try/except` | user input, files, network |
| **Refuse it** | `raise` | argument validation, telling the caller |

**Good code uses all three.**
