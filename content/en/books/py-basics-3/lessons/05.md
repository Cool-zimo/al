# Practice: a diary that remembers

> Stringing the first four lessons into something genuinely usable. This is chapter 1's project.

## What we're building

A command-line diary that can:

1. **Write a new entry** (appended to a file)
2. **Show everything** (read and display)
3. **Quit**

**The point: close the program, reopen it, and your old entries are still there.**

## Plan the shape first

```
while True:
    show the menu
    let the user choose
    if 1 → write an entry
    if 2 → read entries
    if 3 → quit
```

You already know this structure from chapters 4 and 5 of Basics 1 — **choice plus loop**. Now "write an entry" means file work.

## Version one: it runs

```python
FILE = 'diary.txt'

while True:
    print("\n=== My Diary ===")
    print("1. Write")
    print("2. Read")
    print("3. Quit")

    choice = input("Choose (1/2/3): ")

    if choice == '1':
        text = input("What happened today: ")
        with open(FILE, 'a', encoding='utf-8') as f:
            f.write(text + "\n")
        print("saved")

    elif choice == '2':
        with open(FILE, 'r', encoding='utf-8') as f:
            content = f.read()
        print("\n--- entries ---")
        print(content)

    elif choice == '3':
        print("bye")
        break

    else:
        print("Please enter 1, 2 or 3")
```

**Close it and the entries are still in `diary.txt`.** Next run, choose 2 and they're all there.

## What's wrong with it

**Problem 1: choosing "read" on a fresh install crashes**

```python
# reading before the file exists → FileNotFoundError
with open(FILE, 'r', encoding='utf-8') as f:
```

**Problem 2: you can't tell when each entry was written**

Everything is mashed together with no timestamps.

**Problem 3: no separation**

One long blob; you can't tell where one entry ends.

## Fix one: handle "file doesn't exist"

The simplest approach is to **check first**:

```python
import os

if os.path.exists(FILE):
    with open(FILE, 'r', encoding='utf-8') as f:
        content = f.read()
    print(content)
else:
    print("no entries yet")
```

**`os.path.exists(path)` returns True/False** — use it to dodge the crash.

(Lesson 12 shows the tidier `try/except` version.)

## Fix two: add timestamps

```python
from datetime import datetime

now = datetime.now().strftime("%Y-%m-%d %H:%M")
```

**`strftime` formats a time as a string:**

| Placeholder | Means | Example |
|---|---|---|
| `%Y` | four-digit year | 2026 |
| `%m` | two-digit month | 09 |
| `%d` | two-digit day | 27 |
| `%H` | hour (24-hour) | 14 |
| `%M` | minute | 30 |

Write with the timestamp:

```python
with open(FILE, 'a', encoding='utf-8') as f:
    f.write(f"[{now}] {text}\n")
```

Reading back gives:

```
[2026-09-27 14:30] learned file I/O today
[2026-09-27 15:10] built this diary
```

## Fix three: number the lines

```python
with open(FILE, 'r', encoding='utf-8') as f:
    lines = f.readlines()

if not lines:
    print("no entries yet")
else:
    for i, line in enumerate(lines, 1):
        print(f"{i}. {line.rstrip()}")
```

**`if not lines`** handles the empty file — `readlines()` gives an empty list, so check it.

## The complete version

```python
import os
from datetime import datetime

FILE = 'diary.txt'


def write_diary():
    text = input("What happened today: ")
    if not text.strip():
        print("entry can't be empty")
        return
    now = datetime.now().strftime("%Y-%m-%d %H:%M")
    with open(FILE, 'a', encoding='utf-8') as f:
        f.write(f"[{now}] {text}\n")
    print("saved ✓")


def read_diary():
    if not os.path.exists(FILE):
        print("no entries yet")
        return
    with open(FILE, 'r', encoding='utf-8') as f:
        lines = f.readlines()
    if not lines:
        print("no entries yet")
        return
    print("\n--- entries ---")
    for i, line in enumerate(lines, 1):
        print(f"{i}. {line.rstrip()}")


while True:
    print("\n=== My Diary ===")
    print("1. Write")
    print("2. Read")
    print("3. Quit")

    choice = input("Choose (1/2/3): ").strip()

    if choice == '1':
        write_diary()
    elif choice == '2':
        read_diary()
    elif choice == '3':
        print("bye")
        break
    else:
        print("Please enter 1, 2 or 3")
```

## Why split it into functions

"Write" and "read" became `write_diary()` and `read_diary()`.

**Why that's better:**
- the `while` loop is three lines, so the flow is obvious
- changing how entries are written touches one function only
- each function can be tested on its own

**That's the "package your code" idea** — covered properly in lesson 18.
