# Writing your own modules

> You've seen importing others' modules — now write your own, and dodge the "code runs on import" trap.

## The smallest example

Two files in **the same folder**:

```python
# mytools.py
def double(n):
    return n * 2

def greet(name):
    return f"hello, {name}"
```

```python
# main.py
import mytools

print(mytools.double(21))        # 42
print(mytools.greet("Alice"))    # hello, Alice
```

**That simple** — `import mytools` works when they sit side by side.

## The module name is the file name

```python
import mytools        # looks for mytools.py
```

**Module name = file name minus `.py`.**

**Naming rules** are like variables:
- lowercase letters, digits, underscores
- no hyphens (`my-tools.py` won't work)
- **never shadow a standard library name!**

```python
# ❌ never do this
# json.py     ← then "import json" finds YOUR file
# random.py   ← same problem
# string.py   ← same
```

> ⚠️ **One of the most common beginner traps**: name your file `json.py`, and `import json` picks up your empty file instead of the real library.

## The trap: importing runs the code

```python
# mytools.py
def double(n):
    return n * 2

print("module imported")        # ← this runs on import!
```

```python
# main.py
import mytools
print("main starts")
```

Running `main.py`:

```
module imported       ← first
main starts
```

**`import` executes the whole module file top to bottom** — including `print`s, loops, even `input()`.

**That's a problem for files you want both to import and to run directly.**

## The fix: if __name__ == "__main__"

```python
# mytools.py
def double(n):
    return n * 2


def main():
    print("test:", double(21))


if __name__ == "__main__":
    main()          # only when this file is run directly
```

**`__name__` is set automatically by Python:**
- **run the file directly** → `__name__` is `"__main__"`
- **imported** → `__name__` is the module name (`"mytools"`)

**So `if __name__ == "__main__":` means "only do this when I'm the one being run".**

> 💡 **You'll see this everywhere in Python.** When you spot it, that's the file's entry point.

### Why "main"?

Many languages have a main function (C, Java). Python doesn't require one, but the convention makes things clear:

```python
def main():
    """the program's entry point"""
    ...

if __name__ == "__main__":
    main()
```

## What goes in a module

```python
# config.py

# constants
MAX_RETRY = 3
DEFAULT_NAME = "anonymous"

# functions
def get_default():
    return DEFAULT_NAME

# classes (lesson 21)
class User:
    pass

# module-level variables
_cache = {}
```

**Functions, classes, variables, constants — all fine.**

**Convention**: constants are **ALL CAPS**:

```python
MAX_SIZE = 100
API_URL = "https://example.com"
```

## Privacy convention: leading underscore

```python
# mytools.py
def public_func():
    return "fine to use from outside"

def _internal():
    return "a helper — not intended for outside use"
```

**A leading underscore signals "internal"**, but Python **won't actually stop** you:

```python
from mytools import _internal      # works, but you shouldn't
```

**It's a convention, not enforcement** — like a "keep off the grass" sign.

## A realistic structure

```
myapp/
├── main.py           ← entry point
├── config.py         ← configuration
├── database.py       ← data operations
└── utils.py          ← general helpers
```

**Inside `main.py`:**

```python
import config
import database
from utils import format_date

def main():
    ...

if __name__ == "__main__":
    main()
```

## "Module not found" — why?

```python
import mytools
# ModuleNotFoundError: No module named 'mytools'
```

**Usual causes:**

1. **The file isn't in the same directory** — Python looks in:
   - the directory you ran from
   - the standard library
   - directories in `PYTHONPATH`
   - installed packages

2. **A typo in the name** (case matters too)

3. **A clash with a standard library name** (the library shadows yours)

**To check:**

```python
import sys
print(sys.path)        # where Python looks
```

## Summary

- **One `.py` file is one module**; the module name is the file name
- **Never name a file after an existing standard library module**
- **importing runs the whole file**
- **`if __name__ == "__main__"`** separates "imported" from "run directly"
- Constants in CAPS; internal helpers start with `_`
