# The os module: files and folders

> Beyond reading and writing you need create, delete, rename, list — all in `os`.

## Import first

```python
import os
```

## Creating folders

```python
os.mkdir('new_folder')          # one folder
os.makedirs('a/b/c')            # nested, creating parents as needed
```

**The difference:**

```python
# ❌ mkdir raises if 'a' doesn't exist
os.mkdir('a/b')

# ✅ makedirs creates a and a/b
os.makedirs('a/b')
```

> ⚠️ **Creating a folder that already exists raises** (FileExistsError).

**The safe form:**

```python
os.makedirs('logs', exist_ok=True)      # no error if it's already there
```

**`exist_ok=True` is your standard guard** so re-running doesn't crash.

## Deleting

```python
os.remove('a.txt')         # delete a file
os.rmdir('empty_dir')      # delete an empty folder (raises if not empty)
```

> ⚠️ **`os.remove` doesn't use the recycle bin.** Double-check the path first.

For a non-empty folder use `shutil`:

```python
import shutil
shutil.rmtree('folder')        # deletes contents and all
```

**Even more dangerous — verify the path before running it.**

## Renaming / moving

```python
os.rename('old.txt', 'new.txt')

# move into another folder
os.rename('a.txt', 'backup/a.txt')
```

**Renaming and moving are the same operation** — both just change the path.

## Listing a directory

```python
print(os.listdir('.'))        # what's in the current directory
```

```
['main.py', 'data.txt', 'logs']
```

**`listdir` returns just the names** (no path).

To walk into subfolders:

```python
for root, dirs, files in os.walk('.'):
    print(f"dir: {root}")
    print(f"  folders: {dirs}")
    print(f"  files: {files}")
```

**`os.walk` recurses through every subdirectory** — great for finding things:

```python
# find every .py file
for root, dirs, files in os.walk('.'):
    for name in files:
        if name.endswith('.py'):
            print(os.path.join(root, name))
```

## pathlib is tidier

```python
from pathlib import Path

p = Path('logs')
p.mkdir(exist_ok=True)              # create

# matching files
for f in Path('.').glob('*.py'):
    print(f)

# recursive
for f in Path('.').rglob('*.py'):
    print(f)
```

**`glob('*.py')` matches in this directory; `rglob('*.py')` recurses.**

Far more concise than `os.walk`.

## File information

```python
import os
from datetime import datetime

stat = os.stat('data.txt')
print(stat.st_size)                                  # size in bytes
print(datetime.fromtimestamp(stat.st_mtime))         # last modified
```

**`st_mtime` is a timestamp** (seconds since 1970); `datetime.fromtimestamp` makes it readable.

## Practice: tidying a downloads folder

Sort a pile of files by extension:

```python
import os
import shutil

folder = 'downloads'
types = {
    '.jpg': 'images', '.png': 'images', '.gif': 'images',
    '.mp4': 'videos', '.mov': 'videos',
    '.pdf': 'docs',  '.txt': 'docs',
}

for name in os.listdir(folder):
    src = os.path.join(folder, name)
    if not os.path.isfile(src):
        continue                       # skip folders

    _, ext = os.path.splitext(name)
    target_dir = types.get(ext.lower(), 'others')

    dst_dir = os.path.join(folder, target_dir)
    os.makedirs(dst_dir, exist_ok=True)

    shutil.move(src, os.path.join(dst_dir, name))
    print(f"{name} → {target_dir}")

print("done")
```

**This script uses**: `listdir` to iterate, `isfile` to check, `splitext` for the extension, `makedirs` to create, `shutil.move` to relocate.

## A safety habit

**With deletion and overwriting, print first and act second:**

```python
# see what would go
to_delete = [f for f in os.listdir('.') if f.endswith('.tmp')]
print("would delete:", to_delete)

# only uncomment once the list looks right
# for f in to_delete:
#     os.remove(f)
```

**Comment out the dangerous lines, run once to check the list, then uncomment.**

## Quick reference

| Need | Write |
|---|---|
| make folder | `os.makedirs(p, exist_ok=True)` |
| delete file | `os.remove(p)` |
| delete empty folder | `os.rmdir(p)` |
| delete folder with contents | `shutil.rmtree(p)` |
| rename / move | `os.rename(a, b)` / `shutil.move(a, b)` |
| list | `os.listdir(p)` |
| recurse | `os.walk(p)` / `Path(p).rglob('*')` |
| current directory | `os.getcwd()` |
| join | `os.path.join(a, b)` |
| check | `os.path.exists` / `isfile` / `isdir` |
