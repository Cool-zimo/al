# Three ways to read

> `read()`, `readline()`, `readlines()` — similar names, completely different behaviour. Pick wrong and you either hang or get the wrong result.

## Set up a file first

```python
with open('poem.txt', 'w', encoding='utf-8') as f:
    f.write("Roses are red\nViolets are blue\nSugar is sweet\nAnd so are you\n")
```

## Way one: read() — everything at once

```python
with open('poem.txt', 'r', encoding='utf-8') as f:
    content = f.read()

print(content)
print(type(content))      # <class 'str'>
```

**`read()` pulls the whole file into one string**, newlines included.

**Good for**: small files (up to a few MB) that you want to handle as a whole.

```python
# checking whether a word is in there
if "sweet" in content:
    print("found it")
```

> ⚠️ **Never use it on a multi-GB file** — it will exhaust your memory.

### You can limit how much

```python
with open('poem.txt', 'r', encoding='utf-8') as f:
    first_10 = f.read(10)      # only the first 10 characters
print(first_10)
```

## Way two: readline() — one line at a time

```python
with open('poem.txt', 'r', encoding='utf-8') as f:
    line1 = f.readline()
    line2 = f.readline()

print(repr(line1))      # 'Roses are red\n'   ← note the trailing \n
print(repr(line2))      # 'Violets are blue\n'
```

**Each call reads one line, newline included.** At end of file it returns the empty string `''` — that's your "done" signal.

**Good for**: fine-grained control, or files too big to read at once.

```python
# stop at the empty string
with open('poem.txt', 'r', encoding='utf-8') as f:
    while True:
        line = f.readline()
        if line == '':        # empty means done
            break
        print(line, end='')   # line already ends with \n
```

## Way three: readlines() — into a list

```python
with open('poem.txt', 'r', encoding='utf-8') as f:
    lines = f.readlines()

print(lines)
print(len(lines))         # 4
```

```
['Roses are red\n', 'Violets are blue\n', 'Sugar is sweet\n', 'And so are you\n']
```

**A list where each element is one line** (again with `\n`).

**Good for**: accessing by line number, counting lines.

```python
print(lines[0])           # the first line
print(len(lines))         # total lines (just len)
```

## The recommended way: just loop

Actually **iterating the file object itself** is the most Pythonic option:

```python
with open('poem.txt', 'r', encoding='utf-8') as f:
    for line in f:
        print(line, end='')
```

**Why it's best:**
- memory-friendly (only one line in memory at a time)
- shortest code
- no manual end-of-file check

> 💡 **Reach for `for line in f:` first.** It's both concise and memory-efficient.

## Comparison

| Method | Returns | Use when |
|---|---|---|
| `read()` | one string (whole file) | small file, process as a whole |
| `readline()` | one line string | fine-grained line control |
| `readlines()` | list of lines | need line numbers, need a count |
| **`for line in f`** | iterates lines | **most common, memory-friendly** |

## The newline trap

**Every line you read still ends with `\n`**, so printing it directly adds a blank line:

```python
with open('poem.txt', 'r', encoding='utf-8') as f:
    for line in f:
        print(line)        # ❌ blank line between each
```

```
Roses are red

Violets are blue

```

**Three fixes:**

```python
print(line, end='')            # ① don't let print add another newline
print(line.rstrip())           # ② strip the right-hand whitespace (recommended)
line = line.strip()            # ③ strip both sides (when you need the content)
```

**`rstrip()` strips only the right**; `strip()` strips both.

## Practice: summarise a file

```python
with open('poem.txt', 'r', encoding='utf-8') as f:
    lines = f.readlines()

print(f"lines: {len(lines)}")
print(f"characters: {sum(len(line) for line in lines)}")

# find lines containing "sweet"
for i, line in enumerate(lines, 1):
    if "sweet" in line:
        print(f"line {i}: {line.rstrip()}")
```

```
lines: 4
characters: 55
line 3: Sugar is sweet
```

## Summary

- **`read()`** whole file as a string; **`readline()`** one line; **`readlines()`** a list
- **Use `for line in f:`** day to day — short and memory-friendly
- **Every line ends with `\n`** — handle with `rstrip()` or `print(line, end='')`
- Don't `read()` a huge file in one go
