# Class attributes vs instance attributes

> A genuinely confusing point: is the data "one per object" or "one shared by the whole class"?

## Instance attributes: one per object

```python
class Dog:
    def __init__(self, name):
        self.name = name        # ← instance attribute

d1 = Dog("Rex")
d2 = Dog("Snow")

print(d1.name)      # Rex
print(d2.name)      # Snow
```

**`self.name` is an instance attribute** — each object has its own copy.

```python
d1.name = "Big Rex"
print(d1.name)      # Big Rex
print(d2.name)      # Snow    ← untouched
```

## Class attributes: shared by the class

```python
class Dog:
    species = "Canine"        # ← class attribute (in the class, not in __init__)

    def __init__(self, name):
        self.name = name

d1 = Dog("Rex")
d2 = Dog("Snow")

print(d1.species)      # Canine
print(d2.species)      # Canine
```

**A class attribute sits in the class body but outside any method** — every object shares one value.

**You can also reach it through the class:**

```python
print(Dog.species)      # Canine
```

## The difference in action

```python
class Counter:
    count = 0                  # class attribute (shared)

    def __init__(self, name):
        self.name = name       # instance attribute (one each)
        Counter.count += 1     # each new object bumps the shared counter


a = Counter("a")
b = Counter("b")

print(Counter.count)     # 2   ← both objects contributed
print(a.name)            # a
print(b.name)            # b
```

**Class attributes suit "things identical for every object of this type":**

```python
class Config:
    VERSION = "1.0"
    MAX_SIZE = 100
    DEBUG = False
```

## The classic trap

```python
class Dog:
    tricks = []              # ❌ class attribute — one list shared by every dog!

    def __init__(self, name):
        self.name = name

    def learn(self, trick):
        self.tricks.append(trick)


d1 = Dog("Rex")
d1.learn("sit")

d2 = Dog("Snow")
print(d2.tricks)        # ['sit']  ← Snow learned nothing, yet knows it!
```

**Why?**

In `self.tricks.append(...)`, Python doesn't find an instance attribute, so it falls back to the **class attribute** and appends to that shared list.

**Result: every dog shares one tricks list.**

> ⚠️ **Never use a mutable object (list, dict, set) as a class attribute default.**

**The correct version:**

```python
class Dog:
    def __init__(self, name):
        self.name = name
        self.tricks = []         # ✅ a fresh list per dog

    def learn(self, trick):
        self.tricks.append(trick)
```

## Attribute lookup order

```python
d.name
```

**Python looks in this order:**

1. the **instance**
2. then the **class**
3. then **parent classes** (lesson 26)
4. otherwise `AttributeError`

```python
class Dog:
    species = "Canine"

    def __init__(self, name):
        self.name = name


d = Dog("Rex")
print(d.name)        # Rex    — instance
print(d.species)     # Canine — class
print(d.color)       # AttributeError
```

## Shadowing a class attribute on an instance

```python
d = Dog("Rex")
d.species = "Feline"        # adds an instance attribute of the same name

print(d.species)          # Feline  ← instance wins
print(Dog.species)        # Canine  ← the class attribute is unchanged
```

**`d.species = ...` adds an instance attribute; it does not modify the class attribute.**

**To change the class attribute, go through the class name:**

```python
Dog.species = "new value"      # ✅ changes the class attribute
```

## Which to use

| | Class attribute | Instance attribute |
|---|---|---|
| where | class body, outside methods | `self.x` in `__init__` |
| sharing | **shared by all** | **one per object** |
| good for | constants, counters, defaults | the object's state |
| mutable values | ❌ **dangerous** | ✅ fine |

**Rule of thumb: when in doubt, use an instance attribute.** Use a class attribute only for something genuinely identical and unchanging across all objects.

## Inspecting attributes

```python
d = Dog("Rex")

print(d.__dict__)         # {'name': 'Rex'}   ← the instance's attributes
print(Dog.__dict__.keys())  # everything defined on the class
```

**`__dict__` is the attribute dictionary** — handy while debugging.

```python
print(hasattr(d, 'name'))      # True   does it exist?
print(getattr(d, 'name'))      # Rex    read it
setattr(d, 'name', 'Rexy')     # write it
```

**These three built-ins help when handling attributes dynamically** (e.g. field names read from config).

## Summary

- **Instance attributes** (`self.x`): one per object; hold state
- **Class attributes** (in the class body): shared; hold constants and counters
- **Never make a mutable object a class attribute default** — every object ends up sharing it
- Lookup order: instance → class → parents
- Change a class attribute via `ClassName.attr = ...`
