# JSON files

> Need to save a list, a dict, something nested? JSON is the universal answer.

## Why JSON

CSV can only hold a flat table — rows and columns. But what about this?

```python
user = {
    'name': 'Alice',
    'age': 18,
    'hobbies': ['coding', 'reading'],
    'address': {'city': 'London', 'street': 'Baker St'}
}
```

**With nesting and lists, CSV can't cope.**

**JSON stores that structure as-is**, and:
- every programming language understands it
- it's what web APIs speak
- config files commonly use it

## What JSON looks like

```json
{
  "name": "Alice",
  "age": 18,
  "hobbies": ["coding", "reading"],
  "address": {"city": "London", "street": "Baker St"}
}
```

**Almost identical to a Python dict.** The differences:

| | Python | JSON |
|---|---|---|
| booleans | `True` / `False` | `true` / `false` |
| null | `None` | `null` |
| strings | single or double quotes | **double quotes only** |

## Four functions cover everything

```python
import json

# Python object → JSON string
json.dumps(obj)              # dump string

# JSON string → Python object
json.loads(text)             # load string

# Python object → file
json.dump(obj, f)

# file → Python object
json.load(f)
```

**How to remember: the ones ending in `s` work on strings; the others work on files.**

## Writing to a file

```python
import json

user = {'name': 'Alice', 'age': 18, 'hobbies': ['coding', 'reading']}

with open('user.json', 'w', encoding='utf-8') as f:
    json.dump(user, f, ensure_ascii=False, indent=2)
```

**Two important arguments:**

| Argument | Effect |
|---|---|
| `ensure_ascii=False` | **keeps non-ASCII readable** instead of `\u5f20\u4e09` |
| `indent=2` | pretty-prints so humans can read it |

> ⚠️ **Always pass `ensure_ascii=False`** — otherwise the file fills with escapes that, while valid, nobody can read.

The resulting `user.json`:

```json
{
  "name": "Alice",
  "age": 18,
  "hobbies": [
    "coding",
    "reading"
  ]
}
```

## Reading from a file

```python
import json

with open('user.json', 'r', encoding='utf-8') as f:
    user = json.load(f)

print(user['name'])          # Alice
print(user['hobbies'])       # ['coding', 'reading']
```

**You get back an ordinary Python dict** — use it like any other.

## Type mapping

| Python | JSON |
|---|---|
| `dict` | object `{}` |
| `list` / `tuple` | array `[]` |
| `str` | string |
| `int` / `float` | number |
| `True` / `False` | `true` / `false` |
| `None` | `null` |

**Note: tuples come back as lists.**

```python
json.dumps((1, 2))        # '[1, 2]'
json.loads('[1, 2]')      # [1, 2]  ← a list, not a tuple
```

## Not everything is storable

```python
# ❌ TypeError: Object of type set is not JSON serializable
json.dumps({1, 2})

# ❌ functions and class instances can't be stored either
json.dumps(lambda x: x)
```

**JSON supports only the types in that table.**

Convert a set to a list first:

```python
data = {'tags': list({'a', 'b'})}
json.dumps(data)
```

## Practice: a program that remembers

```python
import json
import os

FILE = 'tasks.json'


def load_tasks():
    """Load the task list; empty list if missing or empty."""
    if not os.path.exists(FILE):
        return []
    with open(FILE, 'r', encoding='utf-8') as f:
        content = f.read().strip()
    if not content:                  # empty file
        return []
    return json.loads(content)


def save_tasks(tasks):
    with open(FILE, 'w', encoding='utf-8') as f:
        json.dump(tasks, f, ensure_ascii=False, indent=2)


tasks = load_tasks()
tasks.append({'title': 'learn JSON', 'done': False})
save_tasks(tasks)

print(f"{len(tasks)} task(s):")
for t in tasks:
    mark = '✓' if t['done'] else ' '
    print(f"  [{mark}] {t['title']}")
```

**Close it and run again — the list keeps growing.** That's persistence.

## JSON or CSV

| Situation | Pick |
|---|---|
| Tabular data, headed for Excel | **CSV** |
| Nested structures, config, cross-language | **JSON** |
| Humans will edit it | JSON (more readable) |
| Very large volumes | CSV (more compact) |

## A common mistake

```python
# ❌ overwrites the original; if the write fails halfway the file is corrupt
with open('data.json', 'w', encoding='utf-8') as f:
    json.dump(data, f)

# ✅ safer: write a temp file, then swap it in
import os
with open('data.json.tmp', 'w', encoding='utf-8') as f:
    json.dump(data, f)
os.replace('data.json.tmp', 'data.json')     # atomic on most systems
```

**Use this for anything important** — a crash mid-write can't corrupt the original.
