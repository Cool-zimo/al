# Tour of the standard library, and pip

> Python ships with hundreds of modules. This lesson covers the ones you'll reach for most, plus installing third-party packages.

## First, pip

**pip is Python's package manager** — it installs third-party libraries.

```bash
pip install requests          # install one
pip install requests==2.31.0  # install a specific version
pip uninstall requests        # remove it
pip list                      # what's installed
pip show requests             # details about one
```

> 💡 **If pip is slow where you are, use a mirror:**

```bash
pip install requests -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**Once installed, just import it:**

```python
import requests
```

## requirements.txt

**Record what your project depends on:**

```
requests==2.31.0
pandas==2.2.0
```

**Then anyone can install everything at once:**

```bash
pip install -r requirements.txt
```

**To generate it:**

```bash
pip freeze > requirements.txt
```

> 💡 **Every serious project should have one** — otherwise nobody else can run your code.

## The standard library by purpose

### 1. Maths and numbers

```python
import math

print(math.pi)               # 3.14159...
print(math.sqrt(16))         # 4.0
print(math.ceil(3.2))        # 4   round up
print(math.floor(3.8))       # 3   round down

import random
print(random.randint(1, 10))      # random int 1-10
print(random.choice(['a','b']))   # pick one at random
```

### 2. Dates and times

```python
import datetime

now = datetime.datetime.now()
print(now.strftime("%Y-%m-%d %H:%M"))     # format as a string

d = datetime.date(2026, 9, 27)
print(d + datetime.timedelta(days=7))     # add 7 days

import time
time.sleep(1)          # pause for a second
```

**`strftime`** formats, **`strptime`** parses:

```python
s = "2026-09-27"
d = datetime.datetime.strptime(s, "%Y-%m-%d")     # string → date
```

### 3. Files and the system

```python
import os
import shutil

os.path.join('a', 'b')          # join paths
os.makedirs('x/y', exist_ok=True)
os.listdir('.')                  # list a directory
shutil.copy('a.txt', 'b.txt')    # copy a file
```

### 4. Data formats

```python
import json
import csv

json.dumps({'a': 1})             # to a string
json.loads('{"a": 1}')           # parse
```

### 5. Strings and regular expressions

```python
import re

# find every run of digits
print(re.findall(r'\d+', 'a1b22c333'))      # ['1', '22', '333']

# does it look like a phone number?
if re.match(r'\d{3}-\d{4}', phone):
    print("looks like a phone number")
```

> 💡 **Regex is a big topic.** Knowing that `re` exists for "extract patterns from text" is enough for now.

### 6. System and the command line

```python
import sys

print(sys.argv)          # command-line arguments
print(sys.version)       # Python version
sys.exit(0)              # quit the program
```

### 7. Copying and data structures

```python
import copy

a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)     # deep copy (nested included)
```

```python
from collections import Counter

print(Counter(['a','b','a']))        # Counter({'a': 2, 'b': 1})
```

**`Counter` makes counting trivial:**

```python
words = ['apple', 'banana', 'apple']
c = Counter(words)
print(c.most_common(1))        # [('apple', 2)]
```

### 8. Iteration helpers

```python
import itertools

# combinations
print(list(itertools.combinations([1,2,3], 2)))     # [(1,2),(1,3),(2,3)]
```

### 9. Testing

```python
import unittest

class TestAdd(unittest.TestCase):
    def test_add(self):
        self.assertEqual(1 + 1, 2)
```

## How to find out what's available

**Official docs**: docs.python.org/3/library/

**Nobody memorises all this** — look it up when you need it. **What matters is knowing the standard library probably has it**, so you don't reinvent the wheel.

## A practice: word frequency with the standard library

```python
from collections import Counter
import re

with open('article.txt', 'r', encoding='utf-8') as f:
    text = f.read()

words = re.findall(r'\w+', text.lower())
top = Counter(words).most_common(10)

for word, count in top:
    print(f"{word}: {count}")
```

**Three standard modules together** (`re` + `collections` + file I/O) give you word frequency in a dozen lines.
