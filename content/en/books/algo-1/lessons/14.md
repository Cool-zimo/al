# Difference Arrays: Range Addition from O(n) to O(1), Plus Restoration

> Prefix sums answer "what is the sum of a range?" This lesson covers its inverse operation: **difference arrays** — bringing "range addition" down from O(n) to O(1).

## The Problem Scenario

**Problem**: You have an array, and you must repeatedly **add a value v** to every element in the interval [l, r]. Finally, output the resulting array.

```python
# initial array
nums = [0, 0, 0, 0, 0, 0]
# operation 1: add 2 to [1, 3] -> [0, 2, 2, 2, 0, 0]
# operation 2: add 3 to [2, 4] -> [0, 2, 5, 5, 3, 0]
# operation 3: add 1 to [0, 5] -> [1, 3, 6, 6, 4, 1]
```

The naive approach: each operation traverses [l, r] adding v, costing **O(n) per operation**. With m operations, total complexity is O(mn).

**With a difference array: each operation is O(1), restoration is O(n), total O(m + n).**

## The Core Idea of Differences

**Define the difference array** `diff`:

```
diff[i] = nums[i] - nums[i-1]   (with diff[0] = nums[0])
```

**Key property**: If you add v to every element in `nums[l..r]`, only two positions in the difference array change:

```
diff[l] += v          # from l onward, the "step" is v larger
diff[r+1] -= v        # from r+1 onward, the step goes back to normal
```

**Every other position stays the same!**

## Why Only Two Positions Change

Consider the example: `nums = [1, 2, 3, 4, 5]`

```
diff[0] = 1 - 0 = 1
diff[1] = 2 - 1 = 1
diff[2] = 3 - 2 = 1
diff[3] = 4 - 3 = 1
diff[4] = 5 - 4 = 1
diff[5] = 0 - 5 = -5   (one extra slot, diff[5] = 0 - nums[4])
```

Add 2 to [1, 3]:

```
nums = [1, 4, 5, 6, 5]
diff[0] = 1 - 0 = 1         unchanged
diff[1] = 4 - 1 = 3        +2 <- l=1
diff[2] = 5 - 4 = 1         unchanged
diff[3] = 6 - 5 = 1         unchanged
diff[4] = 5 - 6 = -1       -2 <- r+1=4
diff[5] = 0 - 5 = -5        unchanged
```

**Only diff[1] and diff[4] changed!**

## Code Implementation

```python
def range_add(nums, l, r, v):
    """Use a difference array to add v to [l, r], return the final array"""
    n = len(nums)
    diff = [0] * (n + 1)    # one extra slot to avoid r+1 overflow

    # convert nums to a difference array
    diff[0] = nums[0]
    for i in range(1, n):
        diff[i] = nums[i] - nums[i - 1]
    # diff[n] is already 0

    # perform the range addition
    diff[l] += v
    if r + 1 < n:
        diff[r + 1] -= v

    # restore the array from the difference array
    result = [0] * n
    result[0] = diff[0]
    for i in range(1, n):
        result[i] = result[i - 1] + diff[i]

    return result

print(range_add([0,0,0,0,0,0], 1, 3, 2))
# [0, 2, 2, 2, 0, 0]
```

## Optimization: Operate on the Raw Array

In practice we do not need to "convert to difference, then restore" — we can record all operations in the diff array and restore once at the end.

```python
def range_add_optimized(nums, operations):
    """operations is a list of [(l, r, v), ...]"""
    n = len(nums)
    diff = [0] * (n + 1)

    # first, convert to difference form
    diff[0] = nums[0]
    for i in range(1, n):
        diff[i] = nums[i] - nums[i - 1]

    # apply all range additions (each is O(1))
    for l, r, v in operations:
        diff[l] += v
        if r + 1 < n:
            diff[r + 1] -= v

    # restore once (O(n))
    result = [0] * n
    result[0] = diff[0]
    for i in range(1, n):
        result[i] = result[i - 1] + diff[i]

    return result

nums = [0, 0, 0, 0, 0, 0]
ops = [(1, 3, 2), (2, 4, 3), (0, 5, 1)]
print(range_add_optimized(nums, ops))
# [1, 3, 6, 6, 4, 1]
```

## Complexity Comparison

| Approach | Per operation | Restore | Total |
|---|---|---|---|
| Naive | O(n) | — | O(mn) |
| Difference | O(1) | O(n) | O(m + n) |

When m=100,000 and n=1,000:

```
Naive:   100000 × 1000 = 100 million
Diff:    100000 + 1000 = 101 thousand
~10000x faster
```

## A Complete Walk-Through

`nums = [0,0,0,0,0,0]`, operations: `(1,3,2), (2,4,3), (0,5,1)`

```
Initial nums = [0, 0, 0, 0, 0, 0]
diff = [0, 0, 0, 0, 0, 0, 0]   (length 7)

Operation (1,3,2):
  diff[1] += 2 -> diff[1] = 2
  diff[4] -= 2 -> diff[4] = -2
  diff = [0, 2, 0, 0, -2, 0, 0]

Operation (2,4,3):
  diff[2] += 3 -> diff[2] = 3
  diff[5] -= 3 -> diff[5] = -3
  diff = [0, 2, 3, 0, -2, -3, 0]

Operation (0,5,1):
  diff[0] += 1 -> diff[0] = 1
  r+1=6, n=6, 6<6 is False -> skip diff[6]
  diff = [1, 2, 3, 0, -2, -3, 0]

Restoration:
  result[0] = diff[0] = 1
  result[1] = result[0] + diff[1] = 1 + 2 = 3
  result[2] = result[1] + diff[2] = 3 + 3 = 6
  result[3] = result[2] + diff[3] = 6 + 0 = 6
  result[4] = result[3] + diff[4] = 6 + (-2) = 4
  result[5] = result[4] + diff[5] = 4 + (-3) = 1

result = [1, 3, 6, 6, 4, 1] ✓
```

## Common Mistakes

### Mistake 1: Forgetting the r+1 < n guard

```python
# WRONG: r+1 may equal n, causing an overflow
def range_add_buggy(nums, l, r, v):
    n = len(nums)
    diff = [0] * n          # length n, should be n+1
    ...
    diff[r + 1] -= v        # when r=n-1, r+1=n -> IndexError!
```

**Allocate one extra slot** (length n+1) and only subtract when `r+1 < n`.

### Mistake 2: Forgetting to restore with prefix sums

```python
# WRONG: returning diff directly
return diff    # wrong! diff is a difference array, not the original array
```

**Restoring from a difference array = prefix sum**: `result[i] = result[i-1] + diff[i]`.

### Mistake 3: Confusing "range addition" with "range sum"

| Operation | Tool |
|---|---|
| Range sum (query) | Prefix sum |
| Range addition (update) | Difference array |
| Both query and update | Fenwick tree / Segment tree |

**Prefix sums and differences are inverses**: prefix sums accelerate "range queries", differences accelerate "range updates".

## More Uses for Differences

### 1. Flight Booking Statistics

**Problem**: There are n bookings; each booking `[first, last]` reserves `seats` seats. Find the final seat count for each flight.

This is a classic difference array application — each booking is one range addition.

### 2. Painting / Interval Coloring

Add 1 to interval [l, r] (meaning "painted once"), then check how many times each position was painted.

### 3. Counting Coverage

Given multiple intervals, find how many intervals cover each point.

```python
def count_coverage(intervals, n):
    """intervals is [(l,r), ...]; find how many intervals cover each point"""
    diff = [0] * (n + 1)
    for l, r in intervals:
        diff[l] += 1
        if r + 1 < n:
            diff[r + 1] -= 1
    # restore
    cov = [0] * n
    cov[0] = diff[0]
    for i in range(1, n):
        cov[i] = cov[i - 1] + diff[i]
    return cov

print(count_coverage([(1,3), (2,4), (0,5)], 6))
# [1, 2, 3, 3, 2, 1]
```

## A Crash Site: Returning diff Instead of the Restored Array

The single most common mistake is to perform the difference operations and then hand back `diff` directly:

```python
# WRONG
def range_add_broken(nums, l, r, v):
    n = len(nums)
    diff = [0] * (n + 1)
    diff[0] = nums[0]
    for i in range(1, n):
        diff[i] = nums[i] - nums[i - 1]
    diff[l] += v
    if r + 1 < n:
        diff[r + 1] -= v
    return diff          # <- returned the difference array!

print(range_add_broken([0,0,0,0], 1, 2, 5))
# [0, 5, 0, -5, 0]
# expected: [0, 5, 5, 0]
```

The output `[0, 5, 0, -5, 0]` is the difference array, not the answer. The correct result requires a prefix-sum pass: `result[i] = result[i-1] + diff[i]`, yielding `[0, 5, 5, 0]`. **Difference arrays are intermediate representations, never final answers.**

## Summary

- Differences are the inverse of prefix sums: they accelerate "range updates"
- To add v to [l, r]: `diff[l] += v`, `diff[r+1] -= v` (just two O(1) operations)
- diff array has length n+1; when r+1 == n, skip the subtraction
- Restoring the array = prefix sum over diff
- Total complexity O(m + n), far better than the naive O(mn)
