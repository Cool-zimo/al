# Real-World Practice: People-Flow Statistics (Multiple Range Overlays, One Restoration)

> This lesson applies the difference array to a real scenario: **tracking how many people are present in each time slot** — overlaying many intervals, then restoring once at the end.

## The Problem Scenario

**A mall has n time slots (numbered 0..n-1). Each transaction records that a customer was present during time slots [start, end]. Find how many people are present in each slot.**

```python
# n = 6 time slots
# Customer A: present during slots [1, 3]
# Customer B: present during slots [2, 4]
# Customer C: present during slots [0, 5] (the whole time)
# Find the number of people present in each slot

intervals = [(1, 3), (2, 4), (0, 5)]
n = 6
# Answer: slot 0: 1 person, slot 1: 2 people, slot 2: 3 people, slot 3: 3 people, slot 4: 2 people, slot 5: 1 person
```

**This is the classic "interval coverage counting" problem** — how many intervals cover each slot.

## Solving It with a Difference Array

Every time a customer `[start, end]` arrives, add 1 to `[start, end]`. After processing everyone, restore once.

```python
def people_count(intervals, n):
    """intervals: [(start, end), ...], n: total number of slots"""
    diff = [0] * (n + 1)

    for start, end in intervals:
        diff[start] += 1           # from start, one more person is present
        if end + 1 < n:
            diff[end + 1] -= 1     # from end+1, that person has left

    # restore: prefix sum
    result = [0] * n
    result[0] = diff[0]
    for i in range(1, n):
        result[i] = result[i - 1] + diff[i]

    return result

intervals = [(1, 3), (2, 4), (0, 5)]
print(people_count(intervals, 6))
# [1, 2, 3, 3, 2, 1]
```

## Walk-Through

`intervals = [(1,3), (2,4), (0,5)]`, `n = 6`

```
Initial diff = [0, 0, 0, 0, 0, 0, 0]

Customer A [1, 3]:
  diff[1] += 1 -> diff[1] = 1
  diff[4] -= 1 -> diff[4] = -1

Customer B [2, 4]:
  diff[2] += 1 -> diff[2] = 1
  diff[5] -= 1 -> diff[5] = -1

Customer C [0, 5]:
  diff[0] += 1 -> diff[0] = 1
  end+1=6, 6<6 is False -> skip

Final diff = [1, 1, 1, 0, -1, -1, 0]

Restoration:
  result[0] = 1
  result[1] = 1 + 1 = 2
  result[2] = 2 + 1 = 3
  result[3] = 3 + 0 = 3
  result[4] = 3 + (-1) = 2
  result[5] = 2 + (-1) = 1

result = [1, 2, 3, 3, 2, 1] ✓
```

**Slots 2 and 3 have 3 people present (A, B, and C); slots 0 and 5 have only C.**

## Time Complexity

| Step | Complexity |
|---|---|
| Process m customers | O(m) |
| Restore n slots | O(n) |
| **Total** | **O(m + n)** |

**Compared with the naive approach** (iterating the interval for each customer, O(mn)), the difference array is orders of magnitude faster.

## Variant 1: Peak Attendance

If you only care about "what is the maximum number of people present at the same time":

```python
def max_people(intervals, n):
    diff = [0] * (n + 1)
    for start, end in intervals:
        diff[start] += 1
        if end + 1 < n:
            diff[end + 1] -= 1
    # track the maximum during prefix-sum restoration
    cur = 0
    max_val = 0
    for i in range(n):
        cur += diff[i]
        max_val = max(max_val, cur)
    return max_val

print(max_people([(1,3), (2,4), (0,5)], 6))   # 3
```

**Compute the maximum while restoring — no extra pass needed.**

## Variant 2: Flight Booking Statistics

**Problem**: There are n flights. The i-th booking is `bookings[i] = [first, last, seats]`, meaning `seats` seats are booked from flight `first` through flight `last`. Return the final seat count for each flight.

```python
def corp_flight_bookings(bookings, n):
    diff = [0] * (n + 1)
    for first, last, seats in bookings:
        diff[first - 1] += seats        # input is 1-indexed, convert to 0-indexed
        if last < n:
            diff[last] -= seats
    # restore
    result = [0] * n
    result[0] = diff[0]
    for i in range(1, n):
        result[i] = result[i - 1] + diff[i]
    return result

bookings = [[1, 2, 10], [2, 3, 20], [2, 5, 25]]
n = 5
print(corp_flight_bookings(bookings, n))
# [10, 55, 45, 25, 25]
```

**Note**: The input is 1-indexed (flights numbered from 1), so we must convert to 0-indexed:

- `first - 1` is the 0-indexed start
- `last` is the 0-indexed position just past the end (because the `last` flight is included)

## Variant 3: Minimum Meeting Rooms

**Problem**: Given the start and end times of several meetings, find the maximum number of meetings happening at the same time.

This is the exact same problem as "people-flow statistics"! Add 1 at each meeting's start time, subtract 1 at its end time (difference array), then find the maximum prefix sum.

```python
def min_meeting_rooms(intervals):
    """intervals: [(start, end), ...]"""
    if not intervals:
        return 0
    # find the latest time point
    max_time = max(end for _, end in intervals)
    diff = [0] * (max_time + 1)
    for start, end in intervals:
        diff[start] += 1
        diff[end] -= 1       # note: end itself is excluded (meeting ends at end)
    # find the maximum prefix sum
    cur = 0
    max_rooms = 0
    for i in range(max_time + 1):
        cur += diff[i]
        max_rooms = max(max_rooms, cur)
    return max_rooms

print(min_meeting_rooms([(0, 30), (5, 10), (15, 20)]))   # 2
```

## Common Mistakes

### Mistake 1: Misunderstanding the Interval Endpoint

Different problems define intervals differently:

| Problem | Interval meaning | Difference operation |
|---|---|---|
| People flow | [start, end] inclusive | diff[start]+=1, diff[end+1]-=1 |
| Flight booking | [first, last] inclusive | diff[first-1]+=seats, diff[last]-=seats |
| Meeting rooms | [start, end) half-open | diff[start]+=1, diff[end]-=1 |

**The key is understanding whether the end time is inclusive or not.**

### Mistake 2: Forgetting to handle end+1 == n

```python
# WRONG: no guard for end+1 < n
diff[end + 1] -= 1    # when end=n-1, end+1=n -> IndexError!
```

**Always add the guard**: `if end + 1 < n`.

## A Crash Site: Inclusive vs. Exclusive Endpoints

Mixing up whether the end of an interval is included is the #1 source of wrong answers. Here is a concrete example:

```python
# WRONG - treating a half-open interval as closed
def count_half_open_buggy(intervals, n):
    diff = [0] * (n + 1)
    for start, end in intervals:
        diff[start] += 1
        diff[end + 1] -= 1     # assumes end is INCLUDED
    cur = 0
    result = []
    for i in range(n):
        cur += diff[i]
        result.append(cur)
    return result

# Meetings run from start (inclusive) to end (EXCLUSIVE)
meetings = [(0, 2), (2, 4)]
print(count_half_open_buggy(meetings, 4))
# diff = [1, 0, 0, -1, 0]
# result = [1, 1, 1, 0]
# But (0,2) and (2,4) do NOT overlap - the answer should be [1, 1, 1, 1]
# The bug: meeting (2,4) is NOT present at time 4, so diff[5] -= 1 should not happen.
```

When the interval is half-open `[start, end)`, the meeting is **not** present at time `end`. Using `diff[end+1] -= 1` over-subtracts. The correct operation is `diff[end] -= 1`. Always confirm the interval convention before coding.

## Summary

- Difference arrays are ideal for "interval coverage counting" problems
- Core idea: each interval `[s, e]` maps to `diff[s]+=1, diff[e+1]-=1`
- After restoration, each position holds its coverage count
- You can compute the peak (maximum) during restoration
- Watch out for different interval endpoint conventions (inclusive vs. half-open)
