# Three Ways to Check a Palindrome: Center Expansion, Two Pointers, and Reverse-and-Compare

> Palindromes are a frequent interview topic. This lesson covers three ways to check one, and compares their trade-offs.

## What Is a Palindrome?

**A palindrome** reads the same forwards and backwards.

```python
"racecar"     # palindrome
"madam"       # palindrome
"noon"        # palindrome
"A man a plan a canal Panama"   # palindrome (after cleaning)
"hello"       # not a palindrome
```

## Method 1: Two Pointers (Collision)

**Start at the two ends and walk toward the middle; if any pair mismatches, it is not a palindrome.**

```python
def is_palindrome_two_pointers(s):
    left, right = 0, len(s) - 1
    while left < right:
        if s[left] != s[right]:
            return False
        left += 1
        right -= 1
    return True

print(is_palindrome_two_pointers("racecar"))     # True
print(is_palindrome_two_pointers("madam"))       # True
print(is_palindrome_two_pointers("hello"))       # False
```

**Time O(n), space O(1)** — the optimal solution.

**Edge cases:**

| Input | left | right | Result | Why |
|---|---|---|---|---|
| `""` | 0 | -1 | True | loop never runs, returns True |
| `"a"` | 0 | 0 | True | `left < right` is false |
| `"racecar"` | 0→1→2, 6→5→3 | — | True | the middle 'e' is compared with itself and skipped |

**Both the empty string and a single character are palindromes** (there is no unequal pair).

## Method 2: Reverse and Compare

**A palindrome equals its own reverse.**

```python
def is_palindrome_reverse(s):
    return s == s[::-1]

print(is_palindrome_reverse("racecar"))     # True
print(is_palindrome_reverse("hello"))       # False
```

**Time O(n), space O(n)** (the slice builds a new string).

**Pros**: one line, the shortest code. **Cons**: uses O(n) extra space.

## Method 3: Center Expansion

**Expand outward from each position (and from between each pair of positions).**

This method is mainly used for "find the longest palindromic substring" (next lesson), but it can check palindromes too.

```python
def is_palindrome_expand(s):
    n = len(s)
    for center in range(n):
        # odd-length palindrome centered at `center`
        left = right = center
        while left >= 0 and right < n and s[left] == s[right]:
            left -= 1
            right += 1
    # this only shows the expansion process; checking needs extra logic
    ...
```

**Method 3 by itself is overkill for just checking** — its real value is "find the longest palindrome". We will cover it in detail next lesson.

## Comparing the Three Methods

| Method | Time | Space | Recommendation |
|---|---|---|---|
| Two pointers | O(n) | O(1) | ⭐⭐⭐ best |
| Reverse and compare | O(n) | O(n) | ⭐⭐ short but uses space |
| Center expansion | O(n) | O(1) | ⭐ best for longest palindrome |

**Two pointers is the interview recommendation** — it shows you can work in place.

## In Practice: Valid Palindrome (Ignore Case and Non-Alphanumerics)

**Problem**: decide whether a string is a palindrome, **ignoring case** and keeping only letters and digits.

```python
"A man, a plan, a canal: Panama"
# after cleaning: "amanaplanacanalpanama" -> palindrome

"race a car"
# after cleaning: "raceacar" -> not a palindrome
```

```python
def is_palindrome_valid(s):
    # clean first: keep only letters and digits, lowercase everything
    cleaned = ""
    for ch in s:
        if ch.isalnum():           # isalnum: is a letter or digit
            cleaned += ch.lower()  # lowercase

    # two-pointer check
    left, right = 0, len(cleaned) - 1
    while left < right:
        if cleaned[left] != cleaned[right]:
            return False
        left += 1
        right -= 1
    return True

print(is_palindrome_valid("A man, a plan, a canal: Panama"))   # True
print(is_palindrome_valid("race a car"))                       # False
```

**Walking through** `"A man, a plan, a canal: Panama"`:

```
clean: drop spaces and punctuation, lowercase everything
"A man, a plan, a canal: Panama"
  |||||||||||||||||||||||||||
"amanaplanacanalpanama"

two pointers:
left=0('a')  right=20('a')  ok
left=1('m')  right=19('m')  ok
left=2('a')  right=18('a')  ok
...
they meet in the middle, return True
```

## Common Mistakes

### Mistake 1: Forgetting the empty string

```python
def is_palindrome_buggy(s):
    left, right = 0, len(s) - 1
    while left < right:       # when s is empty, len(s)-1 = -1
        ...                   # left=0, right=-1, loop never runs
    return True               # empty string returns True, which is correct
```

**Returning True for the empty string is correct** (there is no unequal pair). But notice that when `len(s)-1 = -1`, `0 < -1` is False, so the loop is skipped.

### Mistake 2: Using `str.reverse()` to reverse

```python
# WRONG: str has no reverse method
s.reverse()         # AttributeError!

# RIGHT
reversed_s = s[::-1]
```

**Strings have no `reverse()` method** — only lists do. Use the slice `[::-1]`.

### Mistake 3: Missing boundary checks in center expansion

```python
# WRONG: missing the left >= 0 or right < n check
while s[left] == s[right]:    # can go out of bounds!
    left -= 1
    right += 1
```

**When expanding you must check `left >= 0` and `right < n`.**

## # WRONG — The Sneaky isalnum Mistake

**A very common bug is cleaning the string with `+=` in a loop (back to the O(n²) trap) and then forgetting that `isalnum()` has a surprise on empty strings and punctuation:**

```python
# WRONG
def is_palindrome_valid_buggy(s):
    cleaned = ""
    for ch in s:
        if ch.isalnum():        # looks right...
            cleaned += ch.lower()
    left, right = 0, len(cleaned) - 1
    while left < right:
        if cleaned[left] != cleaned[right]:
            return False
        left += 1
        right -= 1
    return True

print(is_palindrome_valid_buggy("race a car"))   # False -- happens to work here
print(is_palindrome_valid_buggy(""))             # True  -- also happens to work
```

**Why is this wrong?** Two reasons. First, `cleaned += ch.lower()` inside the loop is exactly the O(n²) pattern from Lesson 21 — for a long string you are copying `cleaned` from scratch on every iteration. Second, the real trap is more subtle: `isalnum()` returns `False` for everything that is not a letter or digit, which is what we want — but many learners then try to "optimize" by writing `if ch.isalpha() or ch.isdigit()` and start mis-handling characters, or they forget to lowercase and `"Racecar" != "racecaR"`.

The correct version builds a list and lowercases in one pass:

```python
# RIGHT
def is_palindrome_valid(s):
    cleaned = [ch.lower() for ch in s if ch.isalnum()]   # list comprehension: O(n), one pass
    left, right = 0, len(cleaned) - 1
    while left < right:
        if cleaned[left] != cleaned[right]:
            return False
        left += 1
        right -= 1
    return True

print(is_palindrome_valid("A man, a plan, a canal: Panama"))   # True
print(is_palindrome_valid("race a car"))                       # False
```

**Spot the difference**: a list comprehension does the cleaning in a single O(n) pass with no repeated copying, and `isalnum()` plus `lower()` handles both the filtering and the case folding in one step.

## Where Center Expansion Really Shines

**Center expansion is not about checking palindromes — it is about finding the longest palindromic substring.**

Idea: for each position `i`, expand outward and track the longest run you can get.

```python
def longest_palindrome(s):
    if not s:
        return ""
    
    def expand(left, right):
        while left >= 0 and right < len(s) and s[left] == s[right]:
            left -= 1
            right += 1
        return right - left - 1    # length of the palindrome
    
    start, max_len = 0, 1
    for i in range(len(s)):
        # odd length: center at i
        len1 = expand(i, i)
        # even length: center between i and i+1
        len2 = expand(i, i + 1)
        curr_max = max(len1, len2)
        if curr_max > max_len:
            max_len = curr_max
            start = i - (curr_max - 1) // 2
    
    return s[start:start + max_len]

print(longest_palindrome("babad"))    # "bab" or "aba"
print(longest_palindrome("cbbd"))     # "bb"
```

**We will derive this in detail in the next lesson.**

## Summary

- Three ways to check: two pointers (best), reverse-and-compare (short), center expansion (best for longest)
- Two pointers: O(n) time, O(1) space — recommended for interviews
- Reverse and compare: `s == s[::-1]`, O(n) space
- Valid palindrome: clean first (`isalnum` + `lower`), then two pointers
- Center expansion's real purpose is "find the longest palindromic substring"
