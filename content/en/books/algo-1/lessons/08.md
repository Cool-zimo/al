# Two Pointers, Different Speed: Removing and Deduplicating In-Place

> Collision pointers are "two ends closing in." This lesson covers another shape: **the slow/fast pointer** — both move in the same direction, one scouts ahead while the other "records the answer."

## Why you need slow/fast pointers

A lot of problems ask you to **modify an array in place** (no new array allowed) and return the length of the "valid" portion.

Typical scenarios:
- Deduplicate a sorted array (keep exactly one copy of each value)
- Remove every element equal to a given value
- Move all zeros to the end

If you were allowed to build a new list, all of these would be trivial. But when the constraint says **O(1) extra space**, you need slow/fast pointers.

## The core idea

- **Slow pointer `slow`**: points at "the next free slot where an answer element can be written"
- **Fast pointer `fast`**: walks all the way through, hunting for "useful elements"

Every time `fast` finds a useful element, copy it into `slow`'s slot, then advance `slow` by one.

```python
slow = 0
for fast in range(n):
    if condition:                 # fast points at something "useful"
        arr[slow] = arr[fast]
        slow += 1
# at the end, slow IS the valid length
```

## Walkthrough 1: remove all occurrences of `val`

**Problem**: given `nums` and `val`, remove all elements equal to `val` in place and return the new length.

```python
nums = [3, 2, 2, 3, 4, 5, 3]
val = 3
# after removing 3, the valid elements are [2, 2, 4, 5] -> length 4
```

**Approach**: `fast` visits every element; `slow` marks the next writable slot. Anything that is not `val` gets to stay.

```python
def remove_element(nums, val):
    slow = 0
    for fast in range(len(nums)):
        if nums[fast] != val:          # fast points at something worth keeping
            nums[slow] = nums[fast]    # copy it into the slow slot
            slow += 1                  # advance slow
    return slow                        # slow is the new length

nums = [3, 2, 2, 3, 4, 5, 3]
length = remove_element(nums, 3)
print(length)                # 4
print(nums[:length])         # [2, 2, 4, 5]
```

**Trace** `nums = [3, 2, 2, 3, 4]`, `val = 3`:

```
slow=0, fast=0: nums[0]=3 == val -> skip
slow=0, fast=1: nums[1]=2 != val -> nums[0]=2, slow=1
slow=1, fast=2: nums[2]=2 != val -> nums[1]=2, slow=2
slow=2, fast=3: nums[3]=3 == val -> skip
slow=2, fast=4: nums[4]=4 != val -> nums[2]=4, slow=3
done, return slow=3
first 3 of nums: [2, 2, 4] ✓
```

**Time O(n), space O(1)** — only two pointer variables are used.

## Walkthrough 2: deduplicate a sorted array

**Problem**: given a sorted array, remove duplicates in place so each element appears only once, and return the new length.

```python
nums = [1, 1, 2, 2, 2, 3, 4, 4]
# after dedup the valid portion is [1, 2, 3, 4] -> length 4
```

**Approach**: the first element always stays. Starting from the second, if it differs from the previous one, write it into the answer zone.

```python
def remove_duplicates(nums):
    if not nums:                    # empty list -> return 0
        return 0
    slow = 1                        # index 0 is already kept
    for fast in range(1, len(nums)):
        if nums[fast] != nums[fast - 1]:   # different from previous -> it is new
            nums[slow] = nums[fast]
            slow += 1
    return slow                     # valid length

nums = [1, 1, 2, 2, 2, 3, 4, 4]
length = remove_duplicates(nums)
print(length)                # 4
print(nums[:length])         # [1, 2, 3, 4]
```

**Trace** `[1, 1, 2, 2, 3]`:

```
slow=1, fast=1: nums[1]==nums[0] (1==1) -> skip
slow=1, fast=2: nums[2]!=nums[1] (2!=1) -> nums[1]=2, slow=2
slow=2, fast=3: nums[3]==nums[2] (2==2) -> skip
slow=2, fast=4: nums[4]!=nums[3] (3!=2) -> nums[2]=3, slow=3
return 3, first 3: [1, 2, 3] ✓
```

### Edge cases

| Input | Handling | Result |
|---|---|---|
| `[]` | empty-list guard returns 0 | 0 |
| `[5]` | slow=1, fast loop never enters | 1 |
| `[1,1,1]` | only the first copy survives | 1 |

**The empty list must be handled separately** — otherwise `nums[0]` raises `IndexError`.

## Common mistakes

### Mistake 1: forgetting to return `slow`

Many students do the copying but forget to hand back the length.

```python
# WRONG: no return statement
def remove_duplicates_buggy(nums):
    slow = 1
    for fast in range(1, len(nums)):
        if nums[fast] != nums[fast - 1]:
            nums[slow] = nums[fast]
            slow += 1
    # missing "return slow" -> returns None
```

### Mistake 2: using `nums.append` instead of overwriting

`append` **adds elements at the end** rather than overwriting what is in front — the list just keeps growing.

```python
# WRONG: append grows the list
def remove_buggy(nums, val):
    slow = 0
    for fast in range(len(nums)):
        if nums[fast] != val:
            nums.append(nums[fast])   # wrong! list gets longer and longer
            slow += 1
    return slow
```

**You must overwrite**: `nums[slow] = nums[fast]`.

### Mistake 3: comparing `nums[fast]` with `nums[slow]` when deduplicating

```python
# WRONG: comparing the wrong things
def dedup_buggy(nums):
    slow = 1
    for fast in range(1, len(nums)):
        if nums[fast] != nums[slow]:   # wrong! slow keeps moving, logic falls apart
            nums[slow] = nums[fast]
            slow += 1
    return slow
```

**For dedup you compare "the current element with the previous element"**: `nums[fast] != nums[fast - 1]`.

## A crash site: the off-by-one that erases your data

```python
# WRONG
nums = [1, 2, 3, 4, 5]
val = 3
slow = 0
for fast in range(len(nums)):
    if nums[fast] != val:
        slow += 1              # advance slow BEFORE writing
        nums[slow] = nums[fast]
print(nums[:slow])    # [1, 2, 3, 5] <- WRONG, missed the first element
```

Advancing `slow` before writing means slot 0 never receives a value — you skip the very first valid element. The correct order is **write first, then advance**.

## Why this trick is so reusable

The slow/fast pointer is really about **compression**: shove the useful elements forward and overwrite the useless ones.

It works for every problem in this family:

| Problem | Condition |
|---|---|
| Remove a target value | `nums[fast] != val` |
| Dedup a sorted array | `nums[fast] != nums[fast-1]` |
| Move zeros to the end | shift non-zeros forward, then pad with zeros |
| Separate odd/even | route elements to different slots by condition |

**The skeleton is the same; only the condition changes. Learn it once and you cover a whole category.**

## Summary

- Slow/fast pointer: **`slow` records the answer position, `fast` scouts ahead**
- In-place modification, no new array -> **space O(1)**
- Removing a value: when `nums[fast] != val`, copy it to `slow`
- Sorted dedup: when `nums[fast] != nums[fast-1]`, copy it to `slow`
- Mind the boundaries: empty list, single element, remember to return `slow`
