# Counting and Hashing: Character Frequency and Anagrams

> The single most common operation on strings is **counting** — tallying how many times each character appears. This lesson covers it thoroughly.

## Counting with a Dictionary

**The simplest way to count: walk through the string once and record frequencies in a dictionary.**

```python
def char_count(s):
    count = {}
    for ch in s:
        count[ch] = count.get(ch, 0) + 1
    return count

print(char_count("banana"))
# {'b': 1, 'a': 3, 'n': 2}

print(char_count("racecar"))
# {'r': 2, 'a': 2, 'c': 2, 'e': 1}
```

**`dict.get(key, default)` is the key** — when the key is missing it returns 0 instead, so you do not need an `if` check.

## Using collections.Counter (Cleaner)

Python's standard library has a dedicated counting tool:

```python
from collections import Counter

print(Counter("banana"))
# Counter({'a': 3, 'n': 2, 'b': 1})

print(Counter("racecar"))
# Counter({'r': 2, 'a': 2, 'c': 2, 'e': 1})
```

**Counter supports several handy operations:**

```python
c = Counter("aabbccc")

# two most common
print(c.most_common(2))   # [('c', 3), ('a', 2)]

# add counts
c2 = Counter("cccddd")
print(c + c2)             # Counter({'c': 6, 'd': 3, 'a': 2, 'b': 2})

# subtract (keeps positive counts)
print(c - Counter("ab"))   # Counter({'a': 1, 'b': 1, 'c': 3})
```

## In Practice: Valid Anagram

**Problem**: decide whether two strings are **anagrams** (same characters, same counts, in any order).

```python
s1 = "listen"
s2 = "silent"
# anagrams

s1 = "hello"
s2 = "world"
# not anagrams
```

### Approach 1: Sorting

```python
def is_anagram_sort(s1, s2):
    if len(s1) != len(s2):
        return False
    return sorted(s1) == sorted(s2)

print(is_anagram_sort("listen", "silent"))   # True
print(is_anagram_sort("hello", "world"))    # False
```

**Complexity**: sorting is O(n log n); space depends on the sort.

### Approach 2: Counting (Hash Table)

```python
def is_anagram_count(s1, s2):
    if len(s1) != len(s2):
        return False
    count = {}
    for ch in s1:
        count[ch] = count.get(ch, 0) + 1
    for ch in s2:
        if ch not in count:
            return False
        count[ch] -= 1
        if count[ch] == 0:
            del count[ch]
    return len(count) == 0

print(is_anagram_count("listen", "silent"))   # True
print(is_anagram_count("hello", "world"))    # False
```

**Or just subtract two Counters:**

```python
from collections import Counter

def is_anagram(s1, s2):
    return Counter(s1) == Counter(s2)

print(is_anagram("listen", "silent"))   # True
```

**Complexity**: O(n) time, O(n) space.

## Comparing the Two Approaches

| Feature | Sorting | Counting |
|---|---|---|
| Time | O(n log n) | O(n) |
| Space | O(1) or O(n) | O(n) |
| Lines of code | 1 line | 5-8 lines |
| When to use | Small alphabet, keep it short | Interviews, need the optimal solution |

**Counting is recommended for interviews** (O(n) is strictly better); sorting is faster to write in practice.

## In Practice: First Unique Character

**Problem**: find the **first** character in the string that appears exactly once.

```python
s = "leetcode"
# 'l' appears once, and is first -> return 0

s = "loveleetcode"
# 'v' is the first one-off character -> return 2
```

```python
def first_uniq_char(s):
    count = {}
    for ch in s:
        count[ch] = count.get(ch, 0) + 1
    for i, ch in enumerate(s):
        if count[ch] == 1:
            return i
    return -1

print(first_uniq_char("leetcode"))      # 0
print(first_uniq_char("loveleetcode"))  # 2
```

**Two passes**: count first, then find the first character with count 1.

## In Practice: Isomorphic Strings

**Problem**: decide whether two strings are **isomorphic** — every character in `s` maps to exactly one character in `t`.

```python
s = "egg"
t = "add"
# e->a, g->d, a one-to-one mapping -> True

s = "foo"
t = "bar"
# f->b, o->a, o->r -> 'o' maps to two different characters -> False
```

```python
def is_isomorphic(s, t):
    if len(s) != len(t):
        return False
    map_st = {}
    map_ts = {}
    for a, b in zip(s, t):
        if a in map_st and map_st[a] != b:
            return False
        if b in map_ts and map_ts[b] != a:
            return False
        map_st[a] = b
        map_ts[b] = a
    return True

print(is_isomorphic("egg", "add"))    # True
print(is_isomorphic("foo", "bar"))   # False
```

**You need two mapping tables** — check that `s -> t` is one-to-one and that `t -> s` is one-to-one.

## Common Mistakes

### Mistake 1: Using an array as a substitute for a dictionary, but forgetting the character range

```python
# fine if you only have lowercase letters: an array of length 26
def is_anagram_array(s1, s2):
    if len(s1) != len(s2):
        return False
    count = [0] * 26
    for ch in s1:
        count[ord(ch) - ord('a')] += 1
    for ch in s2:
        count[ord(ch) - ord('a')] -= 1
    return all(c == 0 for c in count)

# but if the string contains uppercase letters or Chinese, you get an index error
# is_anagram_array("Hello", "olleH")  -> IndexError!
```

**An array only works when the alphabet is known and contiguous (e.g. lowercase letters only). Use a dictionary for the general case.**

### Mistake 2: Forgetting to check the length first

```python
def is_anagram_buggy(s1, s2):
    count = {}
    for ch in s1:
        count[ch] = count.get(ch, 0) + 1
    for ch in s2:
        count[ch] = count.get(ch, 0) - 1
    return all(v == 0 for v in count.values())   # no length check; it still happens to work

# but this function returns True for "a" and "aa"!
```

**Checking the length up front avoids unnecessary work and also catches some edge cases.**

### Mistake 3: Using `[]` instead of `get` on the dictionary

```python
# WRONG
count = {}
for ch in s:
    count[ch] += 1      # KeyError! you cannot += when ch is missing

# RIGHT
count[ch] = count.get(ch, 0) + 1

# or use defaultdict
from collections import defaultdict
count = defaultdict(int)
for ch in s:
    count[ch] += 1
```

## When to Reach for Counting

**Rule of thumb**: if the question asks "how many", "are they the same", or "which one appears first", you almost always need counting.

| Problem | Use counting? |
|---|---|
| Valid anagram | ✅ |
| First unique character | ✅ |
| Longest palindromic substring | ❌ (center expansion) |
| Reverse a string | ❌ (two pointers) |
| Isomorphic strings | ✅ |
| Longest substring without repeating chars | ✅ (sliding window + counting) |

## Summary

- Count characters with a **dictionary** or `collections.Counter`
- `count.get(ch, 0) + 1` is the standard idiom
- Anagrams: sorting O(n log n) vs counting O(n)
- Isomorphic strings need a **bidirectional mapping**
- Checking length first prunes early
