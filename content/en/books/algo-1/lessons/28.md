# Variable Windows: Longest Substring Without Repeating Characters

> Fixed windows never change length; variable windows shrink on demand. This lesson uses "longest substring without repeating characters" as the battlefield to fully explain the **HashMap + left-boundary advance** technique.

## Problem Statement

Given a string `s`, find the **length** of the **longest** contiguous substring without repeating characters.

```python
s = "abcabcbb"
# Longest unique substring is "abc", length 3

s = "pwwkew"
# Longest unique substring is "wke" or "kew", length 3

s = "bbbbb"
# Longest unique substring is "b", length 1
```

**Note**: This is a substring (contiguous), not a subsequence (which can skip characters).

## Why Brute Force Is Slow

The brute force approach enumerates all substrings and checks each for duplicates:

```python
def longest_substring_bruteforce(s):
    n = len(s)
    max_len = 0
    for i in range(n):
        seen = set()
        for j in range(i, n):
            if s[j] in seen:
                break
            seen.add(s[j])
            max_len = max(max_len, j - i + 1)
    return max_len

print(longest_substring_bruteforce("abcabcbb"))  # 3
```

Outer loop O(n), inner loop up to O(n), duplicate check O(1) → **O(n²)**.

Can we do better? Yes — with a variable window that "absorbs" the inner loop.

## The Core Idea

Imagine an **elastic band**: the left end `left` stays put while the right end `right` stretches rightward. As long as the current character hasn't appeared in the window, `right` keeps going. The moment it hits a duplicate, shrink from the left until the duplicate disappears.

```python
s = "abcabcbb"
char_set = set()
left = 0
max_len = 0

for right in range(len(s)):
    # Key: if s[right] is already in the window, shrink left
    while s[right] in char_set:
        char_set.remove(s[left])
        left += 1
    # Add the new character
    char_set.add(s[right])
    # Update answer
    max_len = max(max_len, right - left + 1)

print(max_len)  # 3
```

**Why `while` and not `if`?** Because we may need to remove **multiple** characters to eliminate the duplicate. In this specific problem, `while` only ever removes one character per iteration (since we remove exactly until the duplicate is gone), but `while` is the safer construct.

## HashMap Records Index: The Stronger Version

A `set` can only answer "is it in?"; a `dict` can answer "where was it last seen?" — letting us jump directly to the correct position:

```python
s = "abcabcbb"
char_index = {}  # char -> last seen index
max_len = 0
left = 0

for right in range(len(s)):
    if s[right] in char_index and char_index[s[right]] >= left:
        # This character appeared inside the current window!
        # Jump left to just past its last position
        left = char_index[s[right]] + 1
    char_index[s[right]] = right
    max_len = max(max_len, right - left + 1)

print(max_len)  # 3
```

**Advantage of the HashMap version**: `left` can **jump directly** instead of inching forward one character at a time. Both are O(n), but HashMap makes fewer actual steps.

## Hand Trace of "abba"

```
Init: char_index={}, left=0, max_len=0

right=0, s[0]='a':
  'a' not in char_index → don't move left
  char_index={'a':0}
  max_len = max(0, 0-0+1) = 1

right=1, s[1]='b':
  'b' not in char_index → don't move left
  char_index={'a':0, 'b':1}
  max_len = max(1, 1-0+1) = 2

right=2, s[2]='b':
  'b' in char_index, and char_index['b']=1 >= left=0 → DUPLICATE!
  left = 1 + 1 = 2
  char_index={'a':0, 'b':2}
  max_len = max(2, 2-2+1) = 2

right=3, s[3]='a':
  'a' in char_index, but char_index['a']=0 < left=2 → NOT in current window!
  (This is the key! The 'a' at index 0 was already evicted.)
  Don't move left.
  char_index={'a':3, 'b':2}
  max_len = max(2, 3-2+1) = 2

Final: max_len = 2
```

**Critical detail**: The check `char_index[s[right]] >= left` is essential. A character may have appeared **outside** the window (like 'a' at index 0 above) — that doesn't count as a duplicate.

## Crash Scene 1: Forgetting the `>= left` Check

```python
s = "abba"
char_index = {}
max_len = 0
left = 0

for right in range(len(s)):
    if s[right] in char_index:   # WRONG! No >= left check
        left = char_index[s[right]] + 1
    char_index[s[right]] = right
    max_len = max(max_len, right - left + 1)

print(max_len)  # Wrong output: 3
```

**Why it fails**: At `right=3`, 'a' is indeed in `char_index` (at index 0), but that 'a' is no longer in the current window `[2, 3]`. The code still jumps `left` to 1, making the window `[1, 3]` = "bba", length 3 — **a window with duplicate characters!**

The fix: `if s[right] in char_index and char_index[s[right]] >= left`.

## Crash Scene 2: Forgetting `+1` When Jumping Left

```python
s = "abba"
char_index = {}
max_len = 0
left = 0

for right in range(len(s)):
    if s[right] in char_index and char_index[s[right]] >= left:
        left = char_index[s[right]]   # WRONG! Should be +1
    char_index[s[right]] = right
    max_len = max(max_len, right - left + 1)

print(max_len)  # Wrong output: 4
```

At `right=3`, 'a' was last at index 0, so `left` becomes 0 (not 1). The window `[0, 3]` = "abba", length 4 — **crawling with duplicates!**

**Lesson**: `left` must skip past the duplicate itself, so it must be `char_index[s[right]] + 1`.

## Crash Scene 3: Removing Only One Character from a Set

```python
s = "abcadef"
seen = set()
left = 0
max_len = 0

for right in range(len(s)):
    if s[right] in seen:
        seen.remove(s[left])   # Removes only one
        left += 1
    seen.add(s[right])
    max_len = max(max_len, right - left + 1)
```

For this specific problem, the `set` + `if` approach happens to work because removing one character always eliminates the duplicate. But with `dict`-based jumping, `while` vs `if` makes a real difference — `if` + jump is strictly more efficient.

The real danger isn't correctness here; it's **habits**. If you train yourself to use `while` with sets, you'll write correct code for problems where one removal isn't enough (e.g., shrinking until a condition holds).

## Complete Implementation + Return the Substring

```python
def longest_substring(s):
    char_index = {}
    max_len = 0
    max_left = 0
    left = 0

    for right in range(len(s)):
        if s[right] in char_index and char_index[s[right]] >= left:
            left = char_index[s[right]] + 1
        char_index[s[right]] = right
        if right - left + 1 > max_len:
            max_len = right - left + 1
            max_left = left

    return s[max_left:max_left + max_len]

print(longest_substring("abcabcbb"))  # "abc"
print(longest_substring("bbbbb"))     # "b"
print(longest_substring("pwwkew"))    # "wke"
print(longest_substring(""))          # ""
```

## Complexity Analysis

| Aspect | Complexity | Reason |
|---|---|---|
| Time | O(n) | Each char visited by right once; left never decreases |
| Space | O(min(n, m)) | m = alphabet size (128 for ASCII) |

Both `left` and `right` move only rightward, at most n steps each. So whether you use `while` or `if`, amortized cost is O(n).

## Summary

- Variable window = right expands + left shrinks conditionally
- `set` version: use `while` to remove one at a time until the duplicate is gone
- `HashMap` version: record last seen position; jump `left` to `last_index + 1`
- **Always check `>= left`**, or you'll treat stale out-of-window records as duplicates
- Both are O(n); HashMap makes fewer actual steps

## In-Class Exercise

Use the variable window idea to find the longest substring with **at most k distinct characters**.

```quiz
type: function
q: Implement longest_substring_k_distinct(s, k): return the length of the longest substring with at most k distinct characters.
func: longest_substring_k_distinct
starter: |
  from collections import Counter

  def longest_substring_k_distinct(s, k):
      # Variable window + Counter to track char frequencies in window
      # When distinct chars > k, shrink left
      count = Counter()
      left = 0
      max_len = 0
      for right in range(len(s)):
          count[s[right]] += 1
          while len(count) > k:
              count[s[left]] -= 1
              if count[s[left]] == 0:
                  del count[s[left]]
              left += 1
          max_len = max(max_len, right - left + 1)
      return max_len
cases: |
  "eceba", 2 -> 3
  "aa", 1 -> 2
  "abc", 0 -> 0
hint: len(Counter) is the number of distinct chars. When len(count) > k, shrink from the left: decrement the count, delete the key if it hits 0, then left += 1.
explain: "eceba" k=2: expand to "eceb" → 3 distinct chars (e,c,b) > 2, shrink to "ceb" still 3, shrink to "eb" → 2, length 2. The max is "ece" length 3.
```
