# Two Pointers on Strings: Reverse, Reverse Words, and Compress

> The two-pointer patterns you learned for arrays work just as well on strings. This lesson works through three classics: **reverse, reverse words, and compress.**

## What About String Immutability?

**As we saw in the previous lesson, strings are immutable — you cannot just do `s[i] = s[j]`.**

**The fix: convert to a list, run two pointers on it, then join back.**

```python
# reverse a string
def reverse_string(s):
    chars = list(s)          # convert to list
    left, right = 0, len(chars) - 1
    while left < right:
        chars[left], chars[right] = chars[right], chars[left]
        left += 1
        right -= 1
    return "".join(chars)    # join back

print(reverse_string("hello"))      # "olleh"
print(reverse_string("racecar"))    # "racecar"  (a palindrome reversed is itself)
```

**Time O(n), space O(n)** (the list overhead).

## Example 1: Reverse a String

```python
# in-place reverse (on a list)
def reverse_in_place(chars):
    left, right = 0, len(chars) - 1
    while left < right:
        chars[left], chars[right] = chars[right], chars[left]
        left += 1
        right -= 1
    return chars

chars = ["h", "e", "l", "l", "o"]
reverse_in_place(chars)
print("".join(chars))    # "olleh"
```

**Note**: in Python you can only "modify in place" if you pass in a list. You cannot do it with a string.

## Example 2: Reverse the Words in a String

**Problem**: reverse the order of the words, but keep each word intact.

```python
s = "the sky is blue"
# after reversing: "blue is sky the"
```

**Idea**: split by spaces, reverse the list, then join with a space.

```python
def reverse_words(s):
    words = s.split()           # split by whitespace (handles extra spaces automatically)
    words.reverse()            # reverse the list
    return " ".join(words)     # join with spaces

print(reverse_words("the sky is blue"))        # "blue is sky the"
print(reverse_words("  hello   world  "))      # "world hello" (extra spaces stripped)
```

**When called with no argument, `split()` splits on any amount of whitespace and strips leading/trailing whitespace.**

### Manual implementation without split

If you want to do it by hand (which shows more skill in an interview):

```python
def reverse_words_manual(s):
    # reverse the whole string first
    chars = list(s)
    chars.reverse()
    # then reverse each word back
    result = []
    i = 0
    while i < len(chars):
        if chars[i] != ' ':
            # found a word
            j = i
            while j < len(chars) and chars[j] != ' ':
                j += 1
            # chars[i:j] is one word; reverse it
            word = chars[i:j]
            word.reverse()
            result.extend(word)
            i = j
        else:
            i += 1
    return "".join(result)

print(reverse_words_manual("the sky is blue"))
# reverse everything first: "eulb si yks eht"
# then reverse each word:   "blue is sky the"
```

## Example 3: String Compression

**Problem**: compress consecutive identical characters into "character + count".

```python
chars = ["a", "a", "b", "b", "c", "c", "c"]
# after compression: ["a", "2", "b", "2", "c", "3"]
```

**Use two pointers**: `i` walks through, `j` finds where the run of identical characters ends.

```python
def compress(chars):
    if not chars:
        return 0
    
    result = []
    i = 0
    while i < len(chars):
        ch = chars[i]
        j = i
        # find the end of this run
        while j < len(chars) and chars[j] == ch:
            j += 1
        count = j - i
        result.append(ch)
        if count > 1:
            result.extend(list(str(count)))   # count may have multiple digits
        i = j

    # modify chars in place (as the problem asks)
    for k in range(len(result)):
        chars[k] = result[k]
    
    return len(result)

chars = ["a", "a", "b", "b", "c", "c", "c"]
length = compress(chars)
print(chars[:length])    # ['a', '2', 'b', '2', 'c', '3']
```

**Walking through** `["a","a","b","b","c","c","c"]`:

```
i=0: ch='a', j advances to 2 (end of the a-run), count=2
  result = ['a', '2']

i=2: ch='b', j advances to 4, count=2
  result = ['a', '2', 'b', '2']

i=4: ch='c', j advances to 7, count=3
  result = ['a', '2', 'b', '2', 'c', '3']

done, return 6
```

## Comparing the Three Two-Pointer Patterns

| Problem | What left/right mean | Operation |
|---|---|---|
| Reverse a string | Collision pointers, closing in from both ends | swap |
| Reverse words | Reverse everything, then reverse each word | segment processing |
| Compress a string | i walks, j scouts ahead | count + build |

**Even though they all use "two position variables", the way they use them is completely different.**

## Common Mistakes

### Mistake 1: Assigning to a string by index

```python
s = "hello"
s[0] = "H"    # TypeError: 'str' object does not support item assignment
```

**You must convert to a list first.**

### Mistake 2: Only writing the first digit of the count when compressing

```python
# the actual bug:
count = j - i
result.append(ch)
result.append(count)    # WRONG! should append str(count)
```

**`count` is a number — you have to turn it into a string before appending it to a list of characters.**

### Mistake 3: Forgetting the count == 1 case

```python
# WRONG: writing the count even when it is 1
if count >= 1:          # should be > 1
    result.extend(list(str(count)))
# "a" would compress to "a1", but usually the problem expects just "a"
```

**A single character gets no count appended** (or it does, depending on the exact problem statement).

## Why Two Pointers Help on Strings

**Just like on arrays, two pointers can turn O(n²) into O(n):**

| Problem | Brute force | Two pointers |
|---|---|---|
| Reverse | Slicing O(n) but not in place | In-place O(n) |
| Reverse words | Nested loops | One pass |
| Compress | Nested loops | One pass |

**The whole point is "one pass only" — making full use of both O(n) time and O(n) space.**

## # WRONG — A Real Pitfall

**Many learners try to compress a string by concatenating counts directly into a string variable, then wonder why the result is wrong:**

```python
# WRONG
def compress_wrong(chars):
    result = ""
    i = 0
    while i < len(chars):
        ch = chars[i]
        j = i
        while j < len(chars) and chars[j] == ch:
            j += 1
        count = j - i
        result = result + ch + str(count)   # builds a new string every time!
        i = j
    return result

print(compress_wrong(["a", "a", "b", "c"]))
# actual output: "a2b1c1"
```

**What went wrong?** Two things. First, this is the O(n²) trap from Lesson 21 — every `result = result + ...` allocates a brand-new string. Second, it always appends the count, so a single `"b"` becomes `"b1"` instead of staying `"b"`. And because `chars` is a list, the function never updates it in place, so the caller sees the original list unchanged.

The correct version builds a `result` **list** (appends are O(1)) and skips the count when it is 1:

```python
# RIGHT
def compress_right(chars):
    result = []
    i = 0
    while i < len(chars):
        ch = chars[i]
        j = i
        while j < len(chars) and chars[j] == ch:
            j += 1
        count = j - i
        result.append(ch)
        if count > 1:
            result.extend(str(count))   # str(count) is already iterable, no need for list()
        i = j
    for k in range(len(result)):
        chars[k] = result[k]
    return len(result)

c = ["a", "a", "b", "c"]
compress_right(c)
print(c[:4])   # ['a', '2', 'b', 'c']
```

**Spot the difference**: a list for accumulation, `> 1` for the count, and the original list is updated in place.

## Summary

- Strings are immutable → **convert to a list, operate, then join back**
- Reverse: collision pointers, swap
- Reverse words: reverse everything + reverse each word (or `split` + `reverse` + `join`)
- Compress: `i` walks + `j` scouts ahead to count
- Watch out: counts with multiple digits must become strings; when `count == 1` write nothing
