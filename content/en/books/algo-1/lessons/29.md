# Window + Counter: Minimum Window Substring

> Fixed windows maintain a "sum"; variable windows maintain a "set." This lesson maintains a **counter**. We use `Counter` to track character frequencies inside the window with surgical precision and solve the "minimum window substring" class of exact-match problems.

## Problem Statement

Given strings `s` and `t`, find the **shortest** substring of `s` that **contains every character of `t`** (including duplicates).

```python
s = "ADOBECODEBANC"
t = "ABC"
# Minimum covering substring is "BANC"

s = "a"
t = "a"
# Minimum covering substring is "a"

s = "a"
t = "aa"
# Impossible, return ""
```

**Note**: `t` may contain duplicate characters. When `t = "AABC"`, the window must contain at least 2 `'A'`s, 1 `'B'`, and 1 `'C'`.

## Why Brute Force Is Slow

Enumerate all substrings and check each one against `t` using a `Counter`:

```python
from collections import Counter

def min_window_bruteforce(s, t):
    need = Counter(t)
    n = len(s)
    min_len = float('inf')
    min_left = 0

    for i in range(n):
        for j in range(i, n):
            window = Counter(s[i:j + 1])
            # Check whether window covers need
            if all(window[c] >= need[c] for c in need):
                if j - i + 1 < min_len:
                    min_len = j - i + 1
                    min_left = i

    return "" if min_len == float('inf') else s[min_left:min_left + min_len]

print(min_window_bruteforce("ADOBECODEBANC", "ABC"))  # "BANC"
```

Building a `Counter` for every substring costs O(n² × |t|). Far too slow.

## Sliding Window + Two Counters: The Idea

Four pieces of state:

1. **`need`** — how many times each character must appear
2. **`window`** — how many times each character currently appears in the window
3. **`required`** — the number of **distinct** characters in `t`
4. **`formed`** — how many of those characters have already **met their quota** in the window

When `formed == required`, the window covers `t`.

```python
from collections import Counter

def min_window(s, t):
    if not t or not s:
        return ""

    need = Counter(t)
    window = Counter()
    required = len(need)
    formed = 0

    left = 0
    min_len = float('inf')
    min_left = 0

    for right in range(len(s)):
        # 1. Add s[right] into the window
        c = s[right]
        window[c] += 1

        # 2. If this character just met its quota, formed++
        if c in need and window[c] == need[c]:
            formed += 1

        # 3. While the window already covers t, shrink the left edge
        while formed == required:
            # Update answer
            if right - left + 1 < min_len:
                min_len = right - left + 1
                min_left = left

            # Shrink: remove s[left]
            left_c = s[left]
            window[left_c] -= 1
            if left_c in need and window[left_c] < need[left_c]:
                formed -= 1
            left += 1

    return "" if min_len == float('inf') else s[min_left:min_left + min_len]

print(min_window("ADOBECODEBANC", "ABC"))  # "BANC"
print(min_window("a", "a"))               # "a"
print(min_window("a", "aa"))              # ""
```

**Why the `==` test?** We only bump `formed` when a count crosses *up to* the exact target. Once a character is over its quota, adding more of it doesn't change `formed`.

**Key observation**: Characters **not in `need`** (like 'D', 'E', 'O') still live in the window, but they never affect `formed`. That's why we guard every `formed` update with `if left_c in need`.

## What `formed` Really Tracks

`formed` counts **how many character kinds have met their quota** — not window size, not total characters.

```python
# Suppose need = {'A':2, 'B':1}
window = {'A':1, 'B':1}
# formed = 1  (only B met; A is 1 short)

window = {'A':2, 'B':1}
# formed = 2  (both A and B met!)

window = {'A':3, 'B':1}
# formed = 2  (still 2; extra A's don't matter)
```

**The rule**: `formed += 1` when `window[c] == need[c]`; `formed -= 1` when `window[c] < need[c]`. This keeps `formed` an exact fingerprint of "does the window fully cover `t`?"

## Crash Scene 1: Forgetting to Decrement `formed` on Shrink

```python
from collections import Counter

def buggy_min_window(s, t):
    need = Counter(t)
    window = Counter()
    required = len(need)
    formed = 0
    left = 0
    min_len = float('inf')

    for right in range(len(s)):
        c = s[right]
        window[c] += 1
        if c in need and window[c] == need[c]:
            formed += 1

        # WRONG: forgot to check whether formed should drop
        while formed == required:
            min_len = min(min_len, right - left + 1)
            window[s[left]] -= 1
            left += 1
            # formed is STILL required -> infinite loop!

    return min_len
```

Output:

```
# Hangs forever (or hits max recursion / timeout)
# formed never decreases, so the while loop never exits
```

**Why it fails**: `formed` stays pinned at `required`, so the `while` condition is always true. The left pointer marches right past the end of the string.

**The fix**: `if left_c in need and window[left_c] < need[left_c]: formed -= 1`.

## Crash Scene 2: Using a `set` Instead of a `Counter`

```python
def wrong_use_set(s, t):
    need = set(t)          # WRONG! Loses duplicate-count information
    window = set()
    left = 0
    min_len = float('inf')

    for right in range(len(s)):
        window.add(s[right])
        while need.issubset(window):
            min_len = min(min_len, right - left + 1)
            window.remove(s[left])  # WRONG! If s[left] appears many times,
            left += 1               # one remove wipes ALL of them

    return min_len

print(wrong_use_set("aaabc", "aabc"))  # Can return wrong answer
```

Output:

```
# Returns 5 for "aaabc" / "aabc" when the correct answer is 4
# The single set.remove('a') destroys both 'a's in the window
```

**Why it fails**: `t = "aabc"` needs **two** `'a'`s, but `set(t) = {'a','b','c'}` forgets that. A `set` answers "is it present?"; a `Counter` answers "how many?" — and exact counts are the whole point of this problem.

## Crash Scene 3: Getting the Shrink Condition Backwards

```python
# WRONG: shrinking on ">=" instead of "==" lets you shrink
# BEFORE the window is even valid
while formed >= required:   # looks harmless...
    ...
```

The subtler bug is **when** to start shrinking. You must shrink the moment `formed == required`, so you capture the **shortest** valid window ending at the current `right`.

```python
# Correct logical flow:
for right in range(len(s)):
    add s[right]
    update formed
    while formed == required:      # window is valid -> shrink as hard as you can
        record answer
        remove s[left]
        update formed
        left += 1
```

**Mnemonic**: Expand greedily (take everything you can); shrink relentlessly (drop everything you can).

## Variant: Checking for a Permutation

Another classic application of window + counter: **does `s2` contain a permutation of `s1`?**

```python
from collections import Counter

def check_inclusion(s1, s2):
    need = Counter(s1)
    window = Counter()
    required = len(need)
    formed = 0
    left = 0

    for right in range(len(s2)):
        c = s2[right]
        window[c] += 1
        if c in need and window[c] == need[c]:
            formed += 1

        if formed == required:
            return True

        # Window size exceeds len(s1) -> MUST shrink
        if right + 1 >= len(s1):
            left_c = s2[left]
            window[left_c] -= 1
            if left_c in need and window[left_c] < need[left_c]:
                formed -= 1
            left += 1

    return False

print(check_inclusion("ab", "eidbaooo"))   # True  ("ba" is a permutation of "ab")
print(check_inclusion("ab", "eidboaoo"))  # False
```

Difference from minimum window: this is a **fixed** window of size `len(s1)`. The moment `formed == required` you can return `True` immediately.

## Complexity Analysis

| Aspect | Complexity | Reason |
|---|---|---|
| Time | O(n) | `right` and `left` only move right; each char touched at most twice |
| Space | O(\|t\| + \|alphabet in window\|) | Two `Counter` dictionaries |

Both pointers are non-decreasing, so the loop body runs at most 2n times. The `Counter` overhead is bounded by the alphabet size (at most 128 for ASCII).

## Summary

- Minimum window substring = variable window + exact `Counter` accounting
- `need` records `t`'s demands; `window` records the current window's state
- `formed` tracks "how many kinds are met"; once it hits `required`, shrink hard
- On shrink, only decrement `formed` when `window[left_c] < need[left_c]`
- A `set` cannot replace a `Counter` here — duplicate counts matter
- Permutation check is the fixed-window cousin; window size = `len(s1)`

Find the **shortest** substring of `s` such that **no character exceeds** its count in `t`.

```quiz
type: function
q: Implement shortest_valid_window(s, t) - return the shortest substring of s where, for every character in t, its count in the substring does not exceed its count in t. For example if t has 'A':2 then the substring can contain 'A' at most twice. If t has 'X':0 (i.e. X is not in t) the substring cannot contain X at all. If no valid substring exists, return "".
func: shortest_valid_window
starter: |
  from collections import Counter

  def shortest_valid_window(s, t):
      # Idea: no character in the window may exceed its cap from t
      # need records the upper bound for each character in t
      # When the current character overflows, shrink the left edge
      need = Counter(t)
      count = Counter()
      left = 0
      min_len = float('inf')
      min_left = 0

      for right in range(len(s)):
          count[s[right]] += 1
          # Shrink as long as the current character overflows
          while count[s[right]] > need.get(s[right], 0):
              count[s[left]] -= 1
              left += 1
          # We only shrink when overflowing, so we're always valid here
          if right - left + 1 < min_len:
              min_len = right - left + 1
              min_left = left

      return "" if min_len == float('inf') else s[min_left:min_left + min_len]
cases: |
  "ADOBECODEBANC", "ABC" -> "A"
  "a", "b" -> "a"
  "aa", "a" -> "a"
hint: For characters in t, the window count must not exceed need; for characters NOT in t, the cap is 0 (they must not appear at all). So need.get(c, 0) is the exact upper bound.
explain: For "ADOBECODEBANC" with t="ABC", caps are A:1,B:1,C:1. The single character "A" at index 0 trivially satisfies all caps, so it is the shortest valid window of length 1.
```

  from collections import Counter

  def count_complete_windows(s, t):
      # Fixed window of size len(t)
      # Use Counter to test whether each window covers t
      need = Counter(t)
      window = Counter()
      count = 0

      for right in range(len(s)):
          window[s[right]] += 1
          if right >= len(t):
