# Histograms and Box Plots: Seeing Distributions and Outliers

> A mean only tells you "where the centre is"; a distribution plot tells you "what the data looks like". This lesson covers the histogram `hist` and the box plot `boxplot` — two powerful tools for looking at distributions.

## The histogram: which interval the data falls into

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

np.random.seed(42)
prices = np.random.normal(500, 100, 1000)     # 1000 product prices, mean 500

fig, ax = plt.subplots(figsize=(8, 5))
ax.hist(prices, bins=30, color='#377eb8', edgecolor='white')
ax.set_xlabel('Price (£)')
ax.set_ylabel('Count')
ax.set_title('Product Price Distribution')
fig.savefig('hist_basic.png')
print('saved')
```

`ax.hist(x, bins=30)` slices x into 30 equal-width intervals (bins) and counts how many values fall into each.

## How to choose `bins`

**This is where histograms most often go wrong.** Too few bins erase the shape; too many produce pure noise:

```python
fig, axes = plt.subplots(1, 3, figsize=(15, 4))
for ax, b in zip(axes, [5, 30, 100]):
    ax.hist(prices, bins=b, color='#377eb8', edgecolor='white')
    ax.set_title(f'bins={b}')
fig.savefig('bins_compare.png')
```

| bins | Effect |
|---|---|
| Too few (5) | The shape is flattened and all detail is lost |
| About right (30) | The shoulders of the normal distribution are clearly visible |
| Too many (100) | Each bin holds only a few points and looks like noise |

**Rule of thumb: with n data points, choose `bins` between `int(np.sqrt(n))` and `int(n/10)`.** For 1000 points, around 30 is a reasonable starting point; tweak from there.

## Failure scenario 1: bin edges produce odd-looking bar heights

```python
x = [1, 1, 1, 1, 1, 5, 5, 5, 5, 5]      # only two distinct values, 1 and 5
ax.hist(x, bins=10)                        # sliced into 10 bins
```

Output: only 2 of the 10 bins contain data, so **8 empty bars sit in the middle** and the chart looks mostly blank. Discrete-valued data should not use a histogram; a bar chart (`bar`) grouped by value is more appropriate.

## Density: aligning with a probability density

```python
ax.hist(prices, bins=30, density=True, color='#377eb8', alpha=0.6)
ax.set_ylabel('Density')
```

`density=True` makes the total area of the bars equal 1, so you can overlay and compare it directly with a probability density curve:

```python
import scipy.stats as stats
mu, sd = np.mean(prices), np.std(prices)
xs = np.linspace(prices.min(), prices.max(), 200)
ax.plot(xs, stats.norm.pdf(xs, mu, sd), color='#e41a1c', linewidth=2, label='Normal fit')
ax.legend()
```

**Overlaying a density histogram with a fitted curve** is the standard technique for checking "whether the data is close to normal".

## The box plot: the five-number summary

```python
np.random.seed(42)
store_a = np.random.normal(120, 20, 200)
store_b = np.random.normal(140, 30, 200)
store_c = np.random.normal(110, 15, 200)

fig, ax = plt.subplots(figsize=(8, 5))
ax.boxplot([store_a, store_b, store_c], labels=['London', 'New York', 'Tokyo'])
ax.set_ylabel('Daily sales (£10k)')
ax.set_title('Daily Sales Distribution: Three Stores')
fig.savefig('boxplot_basic.png')
```

A box plot draws five key numbers:

| Element | Meaning |
|---|---|
| Bottom of the box | 25th percentile (Q1) |
| Middle line of the box | Median (Q2) |
| Top of the box | 75th percentile (Q3) |
| Ends of the whiskers | Typically Q1−1.5·IQR to Q3+1.5·IQR |
| Small circles beyond the whiskers | **Outliers** |

## Failure scenario 2: an outlier dominates and the box collapses to a line

```python
data = [10, 11, 12, 13, 14, 15, 16, 17, 18, 500]     # 500 is the outlier
ax.boxplot(data)
```

Output: the box is squeezed very small, the whiskers are pulled long, and **the median line in the middle is almost invisible**. The outlier is dragging the whiskers — and the great thing about the box plot is that it **hides nothing**.

## Failure scenario 3: two groups whose scales differ by 100× are plotted together

```python
ax.boxplot([store_a, store_big])      # store_big's mean is 100 times store_a's
```

Output: the first box **is squeezed into a hairline against the x-axis**, while the second looks normal. **When scales differ hugely, take the logarithm or normalise first.**

## Horizontal box plots

```python
ax.boxplot([store_a, store_b], vert=False, labels=['London', 'New York'])
```

`vert=False` lays the boxes on their side, with category names on the y-axis — useful **when category names are long** (the same logic as `barh`).

## The violin plot: box plot + density

```python
ax.violinplot([store_a, store_b, store_c], showmeans=True)
ax.set_xticks([1, 2, 3])
ax.set_xticklabels(['London', 'New York', 'Tokyo'])
```

The violin plot **combines the statistics of a box plot with the shape of a density**, revealing whether the distribution is single- or double-peaked. A narrow waist and wide ends mean density in the middle.

## Histogram vs box plot

| | Histogram | Box plot |
|---|---|---|
| Answers | What is the shape (skewed? bimodal?) | Where is the centre and median, and are there anomalies? |
| Strength | Rich detail of shape | Compare several groups at a glance; outliers stand out |
| Weakness | Hard to read when stacking many groups | Loses shape detail |
| Typical use | View one group's distribution | Compare 3 or more groups |

## Recap

- Histograms show **distribution shape**; box plots show **the five-number summary + outliers**.
- `bins` is the key: too few flattens, too many becomes noise; a reasonable range is `√n` to `n/10`.
- For discrete-valued data use `bar`, not `hist`.
- An outlier squeezing the box into a line is the box plot "raising an alarm", not a bug.
- When scales differ hugely, take the logarithm or normalise first.
- For more shape detail use the violin plot, `violinplot`.
