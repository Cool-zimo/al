# Colour and style: colormaps, colour-blind safety, and seaborn themes

> Colour choices determine how professional a plot looks. This lesson covers how to pick a colormap, how to avoid the colour-blind trap, and how one line of seaborn swaps the entire look of a figure.

## Colour is not decoration, it carries meaning

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

months = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun']
london = [120, 135, 128, 160, 175, 190]
new_york = [110, 118, 130, 140, 155, 168]
manchester = [90, 100, 95, 110, 130, 140]

fig, ax = plt.subplots(figsize=(9, 5))
ax.plot(months, london, color='#e41a1c', marker='o', label='London')
ax.plot(months, new_york, color='#377eb8', marker='s', label='New York')
ax.plot(months, manchester, color='#4daf4a', marker='^', label='Manchester')
ax.set_title('Sales across three stores')
ax.legend()
fig.savefig('colors_basic.png')
print('saved')
```

`#e41a1c`, `#377eb8`, and `#4daf4a` come from **Set1**, a colour-blind-friendly palette with strong contrast.

## Crash site 1: using red and green as the distinction

```python
ax.plot(months, london, color='red', label='London')
ax.plot(months, new_york, color='green', label='New York')     # red-green contrast
```

Output: the contrast looks fine, until you realise that **roughly 8% of men and 0.5% of women cannot tell those two lines apart**. This is the single most common colour mistake.

**The fix: use a colour-blind-friendly palette.** Matplotlib ships with several:

| Colormap / palette | Character |
|---|---|
| `tab10` | The default categorical palette, colour-blind-safe |
| `Set1` / `Set2` / `Set3` | Decreasing saturation, classic choices |
| `Paired` | Paired colours, useful for grouped data |
| `viridis` / `plasma` / `cividis` | Perceptually uniform and colour-blind-safe |

## Three uses of a colormap

**1. Colour a scatter plot (continuous mapping):**

```python
rent = np.random.uniform(10, 50, 100)
fig, ax = plt.subplots(figsize=(8, 5))
sc = ax.scatter(area, sales, c=rent, cmap='viridis')
fig.colorbar(sc, ax=ax, label='Rent (£10k)')
fig.savefig('cmap_continuous.png')
```

**2. Colour discrete categories (sample fixed positions from a colormap):**

```python
cmap = plt.get_cmap('tab10')        # get the colormap object
colors = [cmap(i) for i in range(3)]   # take the first 3 colours
ax.plot(months, london, color=colors[0], label='London')
ax.plot(months, new_york, color=colors[1], label='New York')
ax.plot(months, manchester, color=colors[2], label='Manchester')
fig.savefig('cmap_discrete.png')
```

`plt.get_cmap('tab10')(i)` returns the colour at position i of the colormap as an RGBA tuple. **This is the cleanest way to avoid hand-writing a pile of hex codes.**

## Crash site 2: using a rainbow colormap for discrete categories

```python
# WRONG: using a continuous colormap to distinguish a few categories
colors = plt.cm.viridis(np.linspace(0, 1, 3))
# result: dark purple, mid green, pale yellow - the brightness differs sharply, implying a hierarchy
```

Output: the three categories now **look like they have a rank** (dark purple looks like the "important" one, pale yellow like the "minor" one), even though the categories are peers. **Discrete categories need a discrete palette (tab10, Set1); a continuous colormap (viridis, coolwarm) is only for values with a meaningful order.**

## Layering light and dark

```python
fig, ax = plt.subplots(figsize=(9, 5), facecolor='#f5f5f5')     # light grey canvas
ax.set_facecolor('#ffffff')                                      # white plotting area
ax.plot(months, london, color='#e41a1c', linewidth=2)

ax.tick_params(colors='#333333')        # tick labels in dark grey, not pure black
ax.spines['top'].set_visible(False)     # remove top border
ax.spines['right'].set_visible(False)   # remove right border
fig.savefig('clean.png')
```

**Dropping the top and right spines** is standard practice in data journalism (FT, NYT): the data area is the focus, the frame is noise. Removing those spines instantly makes the plot look cleaner.

## seaborn style: one line, a whole new look

```python
import seaborn as sns

sns.set_theme(style='whitegrid',          # background style
              palette='Set1',             # default palette
              font='WenQuanYi Micro Hei', # font
              font_scale=1.1)             # font scaling

fig, ax = plt.subplots(figsize=(9, 5))
ax.plot(months, london, marker='o', label='London')
ax.plot(months, new_york, marker='s', label='New York')
ax.set_title('seaborn style')
fig.savefig('sns_style.png')
```

`sns.set_theme` **replaces** the defaults for font, font size, grid, background, and palette in one call, removing a whole stack of `rcParams` settings.

**Style options:**

| `style` | Effect |
|---|---|
| `'white'` | White background, no grid |
| `'dark'` | Dark grey background, for dark contexts |
| `'whitegrid'` | White background with a grid (the most common) |
| `'darkgrid'` | Dark background with a grid |
| `'ticks'` | Ticks only, the most minimal |

**Crash site 3: seaborn's global change leaks into later figures.**

```python
sns.set_theme(style='dark')       # everything is now dark
# ... draw one figure ...
fig2, ax2 = plt.subplots()        # this one is also dark, which you did not expect
```

Output: every figure drawn afterwards is dark, which is **hard to predict**. The solution is a `with` block, which limits the change to that scope:

```python
with sns.axes_style('darkgrid'):
    fig, ax = plt.subplots()
    ax.plot(months, london)
    fig.savefig('dark.png')
# leaving the with block restores the outer style automatically
```

## Which theme for which context

| Context | Recommendation |
|---|---|
| Print, reports, slides | White background with dark data lines (`whitegrid`) |
| Web, dark mode | Dark background with light data lines (`darkgrid`) |
| Dense scatter plots | White background with low alpha |

**Consistency matters**: in one report, the same group must keep the same colour everywhere (London is always red). Otherwise the reader has to re-learn the mapping on every page.

## Recap

- Red-green contrast is a **colour-blind trap**; use Set1 / tab10 / viridis instead
- Two uses for a colormap: **continuous mapping** with `c=..., cmap=`, and **discrete categories** with `plt.get_cmap('tab10')(i)`
- A continuous colormap (viridis) is only for ordered values, never for peer categories
- A polished look: drop top/right spines, use dark grey tick labels instead of pure black, and give the canvas a light grey face
- seaborn: `sns.set_theme(style='whitegrid', palette='Set1')` swaps the whole look in one line
- Inside a function, use `with sns.axes_style(...)` so the change stays local
