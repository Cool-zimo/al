# Putting It Together: One Deliverable Analysis Page

> Take the previous 24 lessons and turn them into one complete artefact: an analysis page that fits on one A4 sheet, with three charts each stating one conclusion and a short paragraph of findings. This is something you can hand to someone else.

## The skeleton of an analysis page

A deliverable dashboard page has four parts:

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd
import numpy as np

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

# Build a "store sales" dataset
np.random.seed(42)
stores = ['London', 'New York', 'Manchester', 'Bristol']
data = pd.DataFrame({
    'store': np.random.choice(stores, 240),
    'month': np.random.choice(['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'], 240),
    'channel': np.random.choice(['online', 'offline'], 240, p=[0.6, 0.4]),
    'revenue': np.random.randint(50, 500, 240),
    'avg_spend': np.random.randint(80, 300, 240),
})
```

| Area | Content | Share |
|---|---|---|
| Top | Overall title (the topic) | 10% |
| Left | Core findings (3 points) | 35% |
| Right | Three charts (distribution / trend / comparison) | 55% |

## Layout: irregular arrangement with GridSpec

```python
fig = plt.figure(figsize=(14, 9))
fig.suptitle('London stores: H1 2025 sales analysis', fontsize=17, fontweight='bold', y=0.98)

gs = fig.add_gridspec(3, 2, hspace=0.4, wspace=0.3,
                      left=0.07, right=0.97, top=0.90, bottom=0.06)

# Top row spans both columns: monthly trend
ax_trend = fig.add_subplot(gs[0, :])
# Bottom left: revenue distribution
ax_dist = fig.add_subplot(gs[1, 0])
# Bottom centre-right: store comparison
ax_comp = fig.add_subplot(gs[1, 1])
# Bottom row: channel split
ax_ch = fig.add_subplot(gs[2, :])
```

`left/right/top/bottom` control the margins of the whole canvas, while `hspace` and `wspace` control the gaps between subplots. One row across both columns on top with smaller charts underneath is the classic skeleton of an analysis page.

## Three charts, each stating one conclusion

```python
# Chart 1: monthly revenue trend -> conclusion: clear recovery in May and June
month_order = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun']
trend = data.groupby('month', observed=True)['revenue'].mean().reindex(month_order)
ax_trend.plot(month_order, trend.values, marker='o', linewidth=2.5, color='#4C72B0')
ax_trend.fill_between(month_order, trend.values, alpha=0.15, color='#4C72B0')
ax_trend.set_title('Average monthly revenue (recovery in May and June)', fontsize=12, loc='left')
ax_trend.set_ylabel('Revenue (GBP)')
ax_trend.spines['top'].set_visible(False)
ax_trend.spines['right'].set_visible(False)
ax_trend.grid(axis='y', alpha=0.3)
ax_trend.set_axisbelow(True)

# Chart 2: revenue distribution -> conclusion: concentrated between 150 and 300
sns.histplot(data, x='revenue', bins=20, kde=True, ax=ax_dist, color='#55A868')
ax_dist.set_title('Revenue distribution (concentrated 150-300)', fontsize=12, loc='left')
ax_dist.spines['top'].set_visible(False)
ax_dist.spines['right'].set_visible(False)

# Chart 3: store comparison -> conclusion: London and Bristol lead
comp = data.groupby('store', observed=True)['revenue'].mean().reindex(stores)
bars = ax_comp.bar(comp.index, comp.values, color='#C44E52')
ax_comp.set_title('Average revenue by store (London and Bristol lead)', fontsize=12, loc='left')
ax_comp.set_ylabel('Revenue (GBP)')
for b in bars:
    ax_comp.text(b.get_x()+b.get_width()/2, b.get_height()+3,
                 f'{b.get_height():.0f}', ha='center', fontsize=9)
ax_comp.spines['top'].set_visible(False)
ax_comp.spines['right'].set_visible(False)

# Chart 4: channel split -> conclusion: online share above 60%
ch = data.groupby('channel', observed=True).size()
ax_ch.bar(ch.index, ch.values, color=['#8172B2', '#CCB974'])
ax_ch.set_title('Orders by channel (online above 60%)', fontsize=12, loc='left')
for i, v in enumerate(ch.values):
    ax_ch.text(i, v+3, f'{v} ({v/len(data)*100:.0f}%)', ha='center')
ax_ch.spines['top'].set_visible(False)
ax_ch.spines['right'].set_visible(False)

fig.savefig('dashboard.png', dpi=150)
plt.close(fig)
print('saved')
```

Every chart title is a one-line conclusion, not "Revenue chart". **A reader scanning the titles already knows what each chart is saying.**

## Colour: one palette for the whole page

The colours on one page cannot be chosen at random; they must come from one palette.

```python
palette = sns.color_palette('muted')
# primary   #4C72B0  for trends
# secondary #55A868  for distributions
# accent    #C44E52  for comparisons
# neutral   #8172B2  for shares
```

**Wreck of the day 1: a different random palette for every chart.**

Blue, green, red and purple all at once make the page look like a rainbow with no visual logic. The reader assumes the colours encode something, when they were just picked at random. **Use one palette across the page, and only increase saturation for emphasis.**

## Findings: three points, each with evidence

```text
Key findings:
1. Average monthly revenue recovered about 15% in May and June,
   a clear summer peak effect.
2. Revenue is concentrated in the 150-300 band, with long-tail
   orders above 400 below 5%.
3. London and Bristol lead, but the sample is only 60 orders,
   so the significance of the difference is unverified.
```

**Wreck of the day 2: a finding with no evidence.**

"London is performing well" - how well? What is the number? What is n? **A finding must point back to a specific value in the chart**, or it is only an impression.

**Wreck of the day 3: hiding the limitations.**

That line about "significance unverified" must be written. Reporting only "London leads" without mentioning n=60 could lead a reader to make a resource decision - that is a gap in professionalism. **Limitations are not weakness; they tell the reader how far this conclusion can be taken.**

## Self-check for the page

```python
# After drawing, check these items
checks = [
    'Overall title includes the topic and the time range',
    'Every subplot title is a one-line conclusion',
    'Every chart has axis labels and units',
    'Colours use one consistent palette, at most one accent',
    'Three findings, each with a number',
    'Limitations are stated',
    'Data source is noted',
]
print('\n'.join(f'[] {c}' for c in checks))
```

## Summary

- A deliverable page has four parts: overall title, findings, three charts, limitations
- GridSpec makes the irregular layout: a trend across the top, comparisons below
- Each chart title states a conclusion, not "X chart"
- One consistent palette for the page, with only one accent colour
- Findings must carry numbers and n; limitations must be stated
- dpi=150 with bbox_inches='tight' guarantees delivery quality
