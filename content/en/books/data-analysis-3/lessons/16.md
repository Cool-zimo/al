# Why seaborn: statistical plots with far less code

> matplotlib can draw anything, but a good-looking plot with statistics behind it takes a dozen lines. seaborn sits on top of matplotlib and packs "aggregate, group, colour, confidence interval" into a single call.

## What problem does seaborn solve

matplotlib is a "brush and canvas": to draw a grouped bar chart you must compute the means yourself, group the data, pick the colours, and write the legend. seaborn is a "statistical plotting layer": you tell it **which column is x, which is y, and which column defines the groups**, and it handles the aggregation, confidence interval, and palette for you.

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

sales = pd.DataFrame({
    'city': ['London', 'London', 'New York', 'New York', 'Manchester', 'Manchester'] * 2,
    'quarter': ['Q1', 'Q2'] * 6,
    'revenue': [120, 135, 110, 128, 95, 105, 130, 142, 118, 135, 100, 112],
})

# matplotlib approach: pivot, compute means, and draw by hand
pivot = sales.pivot(index='city', columns='quarter', values='revenue')
fig, ax = plt.subplots()
for col in pivot.columns:
    ax.plot(pivot.index, pivot[col], marker='o', label=col)
ax.legend()
ax.set_title('Quarterly revenue by city (matplotlib)')
fig.savefig('mpl_way.png')

# seaborn approach: pass the raw long table, get a plot in one line
fig, ax = plt.subplots()
sns.lineplot(data=sales, x='city', y='revenue', hue='quarter', marker='o', ax=ax)
ax.set_title('Quarterly revenue by city (seaborn)')
fig.savefig('sns_way.png')
```

The difference is not the line count, it is the **shape of the data**. matplotlib expects you to compute first and draw after; seaborn accepts **raw records** and aggregates internally. In real analysis you always receive a long table (one transaction per row), and seaborn spares you the repetitive "pivot, then plot" cycle.

## The three-layer relationship: seaborn wraps matplotlib

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.histplot(data=sales, x='revenue', bins=10, ax=ax)   # seaborn draws into ax
ax.set_title('Revenue distribution')                      # matplotlib handles the decoration
fig.savefig('mixed.png')
```

Remember this rule: **for choosing what graphic to draw, use seaborn; for deciding what it looks like, use matplotlib**. Titles, legends, ticks, and axis ranges all go through `ax.set_xxx` and `plt.rcParams`. Mixing them never conflicts, because seaborn's `ax=` parameter accepts a matplotlib Axes object.

**Crash site 1: forgetting `ax=`, so the graphic lands on another canvas.**

```python
fig, ax = plt.subplots()
ax.set_title('This is my plot')        # writing on ax
sns.histplot(data=sales, x='revenue')  # WRONG: no ax given, seaborn builds its own figure
fig.savefig('lost.png')                # the saved figure has no histogram
```

Output: `fig` contains only the empty title, while the histogram was placed on a figure seaborn silently created. In a multi-panel layout this is the classic "where did my plot go". **Whenever you use subplots, every seaborn call must include `ax=`.**

## Style and palette: change the skin in one line

seaborn's polish comes from its default theme. Switching styles takes one statement:

```python
sns.set_theme(style='whitegrid', palette='muted')

tips = sns.load_dataset('tips')
fig, ax = plt.subplots()
sns.scatterplot(data=tips, x='total_bill', y='tip', hue='sex', ax=ax)
ax.set_title('Total bill vs tip')
fig.savefig('styled.png')
```

`style` controls the background (`whitegrid` for a light grid, `ticks` for tick marks, `darkgrid` for a dark grid); `palette` controls the colours (`muted` for soft, `deep` for saturated, `colorblind` for accessibility, `husl` for evenly spaced hues). These palettes are **semantic** - more reliable than writing `#e41a1c` by hand, because seaborn assigns a sufficiently contrasting colour to each level of `hue`.

**Crash site 2: `sns.set_theme()` pollutes the global state, and restoring it is a headache.**

```python
sns.set_theme(style='darkgrid')      # applies globally
# ... draw ten figures ...
# how do you restore the matplotlib defaults?
plt.rcParams['axes.facecolor'] = 'white'
plt.rcParams['axes.grid'] = False
# WRONG: you have to remember a pile of parameters, and you will miss some
```

**The right approach: a `with sns.axes_style(...)` context manager**, which restores the outer style on exit:

```python
with sns.axes_style('darkgrid'):
    fig, ax = plt.subplots()
    sns.histplot(data=tips, x='total_bill', ax=ax)
    fig.savefig('dark.png')
# the outer style is automatically restored here
fig2, ax2 = plt.subplots()
ax2.plot([1, 2, 3], [1, 2, 3])   # uses the outer default style
fig2.savefig('light.png')
```

## Two interfaces: Figure-level and Axes-level

This is the most confusing design in seaborn.

| Interface type | Typical functions | What it returns | Best for |
|---|---|---|---|
| Axes-level | `sns.scatterplot`, `sns.histplot`, `sns.boxplot` | A matplotlib Axes | Multi-panel layouts, embedding in an existing canvas |
| Figure-level | `sns.relplot`, `sns.displot`, `sns.catplot` | A FacetGrid object | Splitting by a column, producing multiple panels quickly |

```python
# Axes-level: I control this ax
fig, ax = plt.subplots(figsize=(7, 5))
sns.scatterplot(data=tips, x='total_bill', y='tip', hue='sex', ax=ax)
ax.set_title('Two variables in one transaction')

# Figure-level: it manages the whole figure
g = sns.relplot(
    data=tips, x='total_bill', y='tip', hue='sex', col='time',
    kind='scatter', height=4, aspect=1.2,
)
g.figure.suptitle('Faceted by dining time', y=1.02)
g.savefig('facet.png')
```

**Crash site 3: treating a Figure-level function as Axes-level and trying to pass `ax=`.**

```python
fig, ax = plt.subplots()
sns.relplot(data=tips, x='total_bill', y='tip', hue='sex', ax=ax)
# TypeError: relplot() got an unexpected keyword argument 'ax'
```

`relplot` does not accept `ax` because it **creates the whole figure itself**. The rule: `relplot`, `displot`, and `catplot` are the names that look like "plot" but are not specific graphics, and they are all Figure-level. You cannot embed them in someone else's grid. When you need faceting, use them; when you need embedding, use the Axes-level versions (`scatterplot` / `histplot` / `boxplot`).

**Quick reference: `relplot(kind='scatter')` approximately equals `scatterplot`, `displot(kind='hist')` approximately equals `histplot`, and `catplot(kind='box')` approximately equals `boxplot`.**

## Recap

- seaborn sits above matplotlib: **draw with seaborn, style with matplotlib**
- Pass the raw long table and set `x` / `y` / `hue`; aggregation happens internally, no pivot needed
- In a multi-panel layout **always pass `ax=`**, otherwise the plot goes elsewhere
- Style globally with `sns.set_theme()`, temporarily with `with sns.axes_style()`
- Figure-level (`relplot` / `displot` / `catplot`) manages the figure and does not accept `ax`
