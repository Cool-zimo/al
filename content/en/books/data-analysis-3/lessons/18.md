# Relational plots: relplot, scatterplot, lineplot, and grouping with hue

> "Is there a relationship between these two variables?" is the question asked most often in data analysis. seaborn's relational plots combine "draw points or lines" with "colour by group" in one move, so a single line reveals group differences.

## Scatter plots: scatterplot

A scatter plot shows the relationship between two continuous variables: positive, negative, none, or some curved pattern.

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

tips = sns.load_dataset('tips')

fig, ax = plt.subplots(figsize=(8, 5))
sns.scatterplot(data=tips, x='total_bill', y='tip', ax=ax)
ax.set_title('Total bill vs tip: a broadly positive relationship')
fig.savefig('scatter1.png')
```

The points run from bottom-left to top-right, so as the bill rises, the tip tends to rise too. That is the most basic positive relationship. But a scatter plot **gives intuition, not a conclusion** - for the coefficient you still have to calculate it.

## hue: one line to split the data into groups

To add a "gender" dimension, you do not draw twice. Just set `hue`:

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.scatterplot(data=tips, x='total_bill', y='tip', hue='sex', ax=ax)
ax.set_title('Coloured by gender')
fig.savefig('scatter2.png')
```

`hue` automatically assigns a colour to each category and adds a legend. This is far more convenient than writing two `ax.scatter` calls and then `ax.legend()` by hand, because seaborn manages both the palette and the legend.

**Crash site 1: too many categories, colours become indistinguishable.**

```python
fig, ax = plt.subplots()
sns.scatterplot(data=tips, x='total_bill', y='tip', hue='size', ax=ax)
# size has 6 categories (1 to 6), so colour alone is hard to read
```

`hue` works well for **3 to 6 categories**. With more (say, grouping by customer name, dozens of levels), the colours become impossible to separate and only create clutter. **Past 8 categories, use faceting (`col=`) or stop trying to compare them on one plot.**

## A third dimension: size and style

A point's **size** and **shape** can also carry variables, packing up to four dimensions into one scatter plot.

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.scatterplot(
    data=tips, x='total_bill', y='tip',
    hue='day', style='time', size='size',
    sizes=(30, 200), ax=ax,
)
ax.set_title('Colour=day, shape=time, size=party size')
fig.savefig('scatter3.png')
```

- `hue` maps colour
- `size` maps point size, with `sizes=(min, max)` to keep large points from covering the rest
- `style` maps point shape (circle, cross, triangle)

**Crash site 2: mapping a continuous variable to size without constraining the range.**

```python
sns.scatterplot(data=tips, x='total_bill', y='tip', size='tip', sizes=(10, 1000))
# tips range from £1 to £10, so a 900x size difference means the large points cover everything
```

`sizes` must **match the scale of the data**. Tips are only £1 to £10, so a tenfold difference is plenty; 1000 produces a visual disaster. A moderate interval such as `(30, 300)` is the usual choice.

## lineplot: trend lines with confidence intervals

A line chart is more than "connect the dots". When multiple observations share an x value, seaborn's `lineplot` **automatically computes the mean and draws a confidence interval band**.

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.lineplot(data=tips, x='size', y='total_bill', hue='sex', marker='o', ax=ax)
ax.set_title('Average bill amount by party size')
fig.savefig('line1.png')
```

Each `size` in `tips` has many transactions, so `lineplot` computes the mean total_bill for that size and connects the points; the translucent band around it is the 95% confidence interval. **That band is the real difference between lineplot and plt.plot** - the latter only connects points and cannot show whether the mean at that position is stable.

**Crash site 3: no repeated observations, so the confidence band disappears or errors out.**

```python
single = pd.DataFrame({'x':[1,2,3,4,5], 'y':[2,4,6,8,10]})
fig, ax = plt.subplots()
sns.lineplot(data=single, x='x', y='y', ax=ax)
# one observation per x means no confidence interval can be computed, only a line
```

When every x has exactly one observation, the confidence interval **cannot be computed**, leaving only a bare line. This is not a bug; it is a warning that **lineplot's confidence interval requires multiple records per x**. If your data really looks like this, set `marker='o'` to show the points explicitly, or accept "there is no interval here".

## relplot: multiple relational plots in one call

`relplot` is the Figure-level entry point for relational plots; `kind` switches between scatter and line.

```python
g = sns.relplot(
    data=tips, x='total_bill', y='tip',
    hue='sex', col='time', row='smoker',
    kind='scatter', height=4, aspect=1.2,
)
g.figure.savefig('relplot.png')
```

`col='time'` facets by column, `row='smoker'` facets by row, producing 2×2 = four small plots at once. This is the standard technique for **"look at the relationship after controlling for a variable"**: split by dining time and smoking status first, then check whether the bill-tip relationship still holds.

## What a relational plot can and cannot show

```python
# Correlation is not causation
fig, ax = plt.subplots(figsize=(8, 5))
sns.scatterplot(data=tips, x='total_bill', y='tip', hue='sex', ax=ax)
ax.set_title('Bill vs tip: correlated, not causal')
fig.savefig('corr_only.png')
```

Higher bills come with higher tips, but both are driven by a **common cause (spending level)**, not "an expensive bill causes a larger tip". **A scatter plot can only suggest correlation; causality requires experimental design or domain knowledge.** This is the most important boundary on relational plots.

## Recap

- `scatterplot` shows the shape of a two-variable relationship; `hue` colours by group in one line
- `hue` suits 3 to 6 categories; past 8, switch to faceting
- `size` maps point size, and `sizes` must match the data scale
- `lineplot` auto-aggregates with a mean + 95% confidence band, which is its real difference from plt.plot
- With one observation per x, the confidence interval cannot be computed, leaving only a line
- `relplot(kind='scatter'/'line')` is the Figure-level entry point
- Relational plots only suggest correlation, **they do not prove causation**
