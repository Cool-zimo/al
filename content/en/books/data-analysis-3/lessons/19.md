# Categorical plots: boxplot, violinplot, barplot, countplot

> When the horizontal axis is categorical and the vertical axis is numeric, you are not looking for "one number per category", you are looking for **the distribution inside each category**. That is exactly what the categorical plot family does.

## Box plots: boxplot, the median and the quartiles

A box plot compresses a group of values into five numbers: the minimum, Q1, the median, Q3, and the maximum, with any point beyond 1.5 times the interquartile range marked separately as an outlier.

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

tips = sns.load_dataset('tips')

fig, ax = plt.subplots(figsize=(8, 5))
sns.boxplot(data=tips, x='day', y='total_bill', ax=ax)
ax.set_title('Bill amount distribution by day of week')
fig.savefig('box.png')
```

The line inside the box is the **median** (not the mean). The box edges are Q1 and Q3, and the box height (the IQR) reflects the **spread**. Points beyond the whiskers are outliers, and they deserve a closer look: a data entry error, or a genuinely huge transaction.

**Crash site 1: treating the box plot's median as the mean.**

```python
tips.groupby('day')['total_bill'].mean()    # the mean
tips.groupby('day')['total_bill'].median()  # the median
```

The two values often differ. With a skewed distribution (a few very large bills), the mean is pulled upward while the median better represents the "typical" level. **Always say which one you are reporting**: "the median bill by day is X" and "the average bill is X" are two different conclusions.

## Violin plots: violinplot, boxplot's upgrade

A box plot only reports quartiles and loses the shape of the distribution. A violin plot uses a KDE to draw the density outline while keeping the box information.

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.violinplot(data=tips, x='day', y='total_bill', hue='sex',
               split=True, inner='quart', ax=ax)
ax.set_title('Bill distribution by day, split by gender (violin)')
fig.savefig('violin.png')
```

`split=True` makes the two categories **share one width**, split left and right, so their shapes can be compared directly. `inner='quart'` draws quartile ticks inside. The widest part of the violin is the density peak, so you can see at a glance whether a category is **unimodal or bimodal**, which a box plot cannot show.

**Which one when?**

| Plot | Information | Best for |
|---|---|---|
| boxplot | Five-number summary + outliers | Many categories, quick look at median and spread |
| violinplot | Full density shape + quartiles | Few categories (<=5), inspecting the shape |
| Both | Shape and outliers together | A comparison inside a report |

## Bar plots: barplot, means and confidence intervals by default

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.barplot(data=tips, x='day', y='total_bill', hue='sex', ax=ax)
ax.set_title('Average bill by day')
fig.savefig('bar.png')
```

Note that seaborn's `barplot` **draws the mean by default** (not a simple count), and the small tick at the top of each bar is the 95% confidence interval. This is completely different from `plt.bar`, which only draws the values you hand it.

**Crash site 2: you want "how many records per category", but you reach for barplot.**

```python
# you want the number of transactions per day
sns.barplot(data=tips, x='day', y='total_bill')  # WRONG: this is the average bill
```

The bar heights you get are "average bill amount", not "counts". **To count, use `countplot`:**

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.countplot(data=tips, x='day', ax=ax)
ax.set_title('Transaction count by day')
fig.savefig('count.png')
```

`countplot` takes only one dimension (usually x or y). What it does is equivalent to `df[x].value_counts()` followed by a bar chart.

## Categorical plots with the raw points: stripplot and swarmplot

A box alone is not enough when you want to see **where the original points sit**. Layer the points on top.

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.stripplot(data=tips, x='day', y='total_bill', jitter=True,
              alpha=0.5, color='gray', ax=ax)
ax.set_title('Categorical plot with raw data points')
fig.savefig('strip.png')
```

`jitter=True` adds horizontal noise so points do not collapse into a line. `alpha=0.5` darkens the overlap, making density visible. With a small sample (a few dozen), `swarmplot` produces a non-overlapping layout that looks better; with thousands of points, `swarmplot` is slow, so stick with `stripplot`.

## Choosing between the categorical plots

```python
# place all four side by side to see the differences
fig, axes = plt.subplots(2, 2, figsize=(12, 9))
sns.boxplot(data=tips, x='day', y='total_bill', ax=axes[0, 0])
axes[0, 0].set_title('boxplot')
sns.violinplot(data=tips, x='day', y='total_bill', ax=axes[0, 1])
axes[0, 1].set_title('violinplot')
sns.barplot(data=tips, x='day', y='total_bill', ax=axes[1, 0])
axes[1, 0].set_title('barplot (means)')
sns.countplot(data=tips, x='day', ax=axes[1, 1])
axes[1, 1].set_title('countplot (counts)')
fig.tight_layout()
fig.savefig('compare.png')
```

**Crash site 3: comparing means directly when the sample sizes are unbalanced.**

Saturdays have only 8 records while Sundays have 77. A barplot gives Saturday a tall mean with a very narrow confidence interval, which looks "highly significant". **With very different sample sizes, the width of the confidence interval itself warns you that the number is unreliable.** Any report must state the sample size (n=8); otherwise the reader will misread it.

## Recap

- A box plot shows the median and quartiles; the median is not the mean
- A violin plot reveals the density shape (unimodal or bimodal); split makes comparison direct
- `barplot` draws the mean and a confidence interval by default; use `countplot` to count
- Many categories -> boxplot; few categories -> violinplot
- Layering stripplot shows the raw points; large samples need jitter
- With unbalanced sample sizes, always report n to avoid misreading the confidence interval
