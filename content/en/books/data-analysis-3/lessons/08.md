# Scatter Plots: Two Variables and Mapping a Third Dimension

> A scatter plot shows "how two variables move together". `scatter` is stronger than `plot` because it can colour and size each point independently — packing a third and fourth dimension into one chart.

## The basic use of `scatter`

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

np.random.seed(42)
area = np.random.uniform(50, 200, 100)        # store area (sq m)
sales = area * 5 + np.random.normal(0, 80, 100)  # sales, positively correlated with area

fig, ax = plt.subplots(figsize=(8, 5))
ax.scatter(area, sales, color='#377eb8', alpha=0.6)
ax.set_xlabel('Store area (sq m)')
ax.set_ylabel('Monthly sales (£10k)')
ax.set_title('Store Area vs Monthly Sales')
fig.savefig('scatter_basic.png')
print('saved')
```

What is the difference between `ax.scatter(x, y)` and `ax.plot(x, y, 'o')`?

| | `plot(..., 'o')` | `scatter` |
|---|---|---|
| Independent colour per point | ❌ Only uniform | ✅ An array is accepted |
| Independent size per point | ❌ | ✅ An array is accepted |
| Large data volume | Fast | Slow |
| Supports colormap | ❌ | ✅ |

**For very large data (tens of thousands of points) use `plot`; to map colour or size use `scatter`.**

## Failure scenario 1: points overlap into a black blob

```python
x = np.random.normal(0, 1, 2000)
y = x + np.random.normal(0, 0.5, 2000)

fig, ax = plt.subplots()
ax.scatter(x, y, color='black')          # 2000 black points merge into solid black
fig.savefig('overlap.png')
```

Output: the middle is a solid black mass, and the density distribution is invisible. The solution is `alpha=0.3`:

```python
ax.scatter(x, y, color='#377eb8', alpha=0.3, s=20)
```

With transparent overlays, **darker areas mean higher density**, making the distribution instantly readable.

## Mapping a third dimension through colour

```python
rent = np.random.uniform(10, 50, 100)      # monthly rent (£10k), the third dimension

fig, ax = plt.subplots(figsize=(8, 5))
sc = ax.scatter(area, sales, c=rent, cmap='viridis',
                alpha=0.7, s=50)
fig.colorbar(sc, ax=ax, label='Monthly rent (£10k)')
ax.set_xlabel('Store area (sq m)')
ax.set_ylabel('Monthly sales (£10k)')
ax.set_title('Area vs Sales, colour = rent')
fig.savefig('scatter_color.png')
```

- `c=rent`: maps the rent array to colour.
- `cmap='viridis'`: selects the colour band.
- `fig.colorbar(sc, ...)`: **required**, otherwise the colour has no scale.
- `s=50`: the point size.

**One chart now carries three variables: x, y and colour.** This is where scatter is most powerful.

## Common colormaps

| cmap | Traits | Best for |
|---|---|---|
| `viridis` | Perceptually uniform, colour-blind friendly | **Default recommendation** |
| `plasma` | High contrast | Emphasising extremes |
| `coolwarm` | Blue-white-red, with a central zero | **Data with positive and negative values** (temperature deviation, change) |
| `RdYlGn` | Red-yellow-green | Good/bad grading |
| `coolwarm_r` | The `_r` suffix reverses direction | When you want the mapping flipped |

**Failure scenario 2: using a single-ended colormap for data with positive and negative values.**

```python
deviation = np.array([-5, -2, 0, 3, 8])     # mixed signs
ax.scatter(x, y, c=deviation, cmap='viridis')   # negatives and positives both run purple to yellow; 0 is green, no "zero crossing" visible
```

Output: 0 and the positive/negative values all sit on the same band, **with no clear "midpoint" to refer to**, so the reader cannot see which side is negative. The correct choice is a **two-ended band with a central zero**, such as `coolwarm`, where 0 is white and red/green are clearly distinct.

## Mapping a fourth dimension through size

```python
staff = np.random.randint(3, 30, 100)        # number of staff, the fourth dimension

fig, ax = plt.subplots(figsize=(8, 5))
sc = ax.scatter(area, sales, c=rent, cmap='viridis',
                s=staff * 10, alpha=0.6)
fig.colorbar(sc, ax=ax, label='Monthly rent (£10k)')
ax.set_xlabel('Store area (sq m)')
ax.set_ylabel('Monthly sales (£10k)')
ax.set_title('Area vs Sales (colour = rent, size = staff)')
fig.savefig('scatter_4d.png')
```

`s=staff * 10` maps the staff count to point size (the default is s=36, so multiply by a factor to make it visible).

**Failure scenario 3: sizes differ far too much.**

```python
s = np.array([1, 1, 1, 1, 500])      # contains an extreme value
ax.scatter(x, y, s=s)                 # one point is huge, the rest invisible
```

Output: one point occupies half the chart while the others are too small to see. **Normalise or take the logarithm before mapping:**

```python
import numpy as np
s_norm = (staff - staff.min()) / (staff.max() - staff.min()) * 200 + 20   # compress to 20-220
ax.scatter(area, sales, s=s_norm)
```

## A marginal density view (a quick look at the distribution)

Beyond `scatter`, to glance at the density of two variables:

```python
fig, ax = plt.subplots(figsize=(8, 5))
hb = ax.hexbin(area, sales, gridsize=20, cmap='viridis')
fig.colorbar(hb, ax=ax, label='Point count')
ax.set_title('Hexagonal density plot (hexbin)')
fig.savefig('hexbin.png')
```

`hexbin` slices the plane into hexagonal cells and colours them by the number of points they contain. **Even with tens of thousands of points the density core is immediately visible**, and it is much faster than scatter.

## Recap

- Scatter plots show how two variables relate; `scatter` supports **independent colour and size per point**.
- For huge datasets (tens of thousands of points) use `plot` or `hexbin`; to map a third dimension use `scatter`.
- Overlapping points → `alpha` transparency reveals density.
- Colour mapping: `c=` + `cmap=` + **`colorbar`**, the complete trio.
- For data with positive and negative values use the two-ended `coolwarm`, not a one-ended band.
- When point sizes vary wildly → normalise before mapping.
