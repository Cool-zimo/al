# Drawing Your First Line: `plot`, `marker`, `linestyle`, `color`

> The line chart is the most commonly used visualisation in data analysis. This lesson unpacks the four core parameters of `plot` so that a single line can carry every style you want.

## The simplest line

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

months = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun']
sales = [120, 135, 128, 160, 175, 190]

fig, ax = plt.subplots()
ax.plot(months, sales)
ax.set_title('London Store H1 Sales')
ax.set_xlabel('Month')
ax.set_ylabel('Revenue (£10k)')
fig.savefig('line_basic.png')
print('saved')
```

Passing `ax.plot(x, y)` two lists is enough to draw. **Note that when x is a list of strings, matplotlib lays them out as categorical ticks in order**, much like pandas' `Categorical`.

## The four core parameters

```python
ax.plot(x, y,
        marker='o',        # the shape marking each data point
        linestyle='--',    # the style of the line
        color='#e41a1c',   # the colour
        linewidth=2)       # line thickness
```

| Parameter | Role | Common values |
|---|---|---|
| `marker` | Data-point marker | `o` (circle), `s` (square), `^` (triangle), `D` (diamond), `.` (dot), `None` |
| `linestyle` | Line style | `-` (solid), `--` (dashed), `-.` (dash-dot), `:` (dotted) |
| `color` | Colour | Colour name, `#rrggbb`, shorthand |
| `linewidth` | Line thickness | Number, default 1.5 |

## Marker: making the points visible

When there are only a few data points (six months, say), **a plain line hides where each point sits**; adding a marker makes it instantly clear.

```python
fig, ax = plt.subplots()
ax.plot(months, sales, marker='o', color='#377eb8', linewidth=2)
ax.set_title('With markers, every month is clearly visible')
fig.savefig('line_marker.png')
```

A quick marker reference:

| Marker | Shape | When to use |
|---|---|---|
| `o` | Circle | Most universal |
| `s` | Square | Few categories |
| `^` `v` `<` `>` | Triangle | Emphasising direction |
| `D` | Diamond | Highlighting a single key point |
| `.` | Small dot | Very large point counts (thousands) |

**Failure scenario: far too many markers turn into a black blob.**

```python
import numpy as np

x = np.linspace(0, 10, 500)
y = np.sin(x)

fig, ax = plt.subplots()
ax.plot(x, y, marker='o')          # 500 circles overlap into solid black
fig.savefig('mess.png')
```

With 500 markers all drawn, they overlap into a solid black mass. **Once you have more than a couple of hundred points, drop the marker** or use `markevery=10` to draw one every 10 points.

## `linestyle` shorthand

`linestyle` can be shortened to `ls`, and the value can be a single character:

```python
ax.plot(x, y, ls='-')    # solid (default)
ax.plot(x, y, ls='--')   # dashed
ax.plot(x, y, ls='-.')   # dash-dot
ax.plot(x, y, ls=':')    # dotted
```

**When comparing two lines, different line styles are safer than different colours** — printed in black and white, colour distinctions vanish but line styles remain. This is basic practice in scientific plotting.

## `color` shorthand

Colours can be single-character abbreviations:

```python
ax.plot(x, y, color='b')   # blue
ax.plot(x, y, color='r')   # red
ax.plot(x, y, color='g')   # green
ax.plot(x, y, color='k')   # black
ax.plot(x, y, color='c')   # cyan
ax.plot(x, y, color='m')   # magenta
ax.plot(x, y, color='y')   # yellow
ax.plot(x, y, color='w')   # white
```

Hex codes work too: `#e41a1c`, `#377eb8`. **Hex is recommended** because it reproduces brand colours or paper palettes exactly, whereas `'r'` cannot be tuned.

## Writing the whole style in one string

Matplotlib supports a `fmt` format string that combines colour, marker and line style in one go:

```python
ax.plot(x, y, 'bo--')     # blue (b), circles (o), dashed (--)
ax.plot(x, y, 'r^-')      # red (r), triangles (^), dotted (:)  -- note dotted is ':'
```

**Failure scenario: `fmt` clashes with keyword arguments.**

```python
ax.plot(x, y, 'bo--', color='red')     # WARNING: color is ignored
```

Output: a warning such as `UserWarning: ... color is redundantly defined`; the actual colour is the `'b'` (blue) from `fmt`, and your `'red'` is silently ignored. **Never specify the same attribute in two places.**

## Several lines in one figure

```python
fig, ax = plt.subplots()

london = [120, 135, 128, 160, 175, 190]
new_york = [110, 118, 130, 140, 155, 168]

ax.plot(months, london, marker='o', label='London')
ax.plot(months, new_york, marker='s', linestyle='--', label='New York')
ax.set_title('H1 Sales: Two Stores')
ax.legend()                  # legend() is REQUIRED for labels to appear
fig.savefig('two_lines.png')
```

**Without `ax.legend()`, writing `label=` achieves nothing.** This is the most common omission.

## Recap

- `ax.plot(x, y, marker, linestyle, color, linewidth)` — the four core parameters.
- Markers make points visible, **but with very large datasets turn them off or downsample**, otherwise you get a blob.
- For comparison charts prefer **different line styles** (they survive black-and-white printing).
- Hex gives precise colours; avoid single-character shorthand.
- Do not repeat the same attribute between an `fmt` string and keyword arguments.
- Multiple lines need `label=` **plus** `ax.legend()`; do not skip the latter.
