# Annotations and reference lines: annotate, axhline, axvline

> The one thing you most want your audience to remember is often a single point. This lesson shows how to mark that "key finding" with an arrow, a label, or a reference line.

## Marking a key point: annotate

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

months = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun']
sales = [120, 135, 128, 160, 175, 190]

fig, ax = plt.subplots(figsize=(9, 5))
ax.plot(months, sales, marker='o', color='#e41a1c', linewidth=2)

# Mark the peak
ax.annotate('H1 peak: £1900k',
            xy=('Jun', 190),            # where the arrow points
            xytext=('Mar', 205),        # where the text sits
            arrowprops=dict(arrowstyle='->', color='#e41a1c', lw=1.5),
            fontsize=11, color='#e41a1c')

ax.set_title('London store: H1 2025 sales')
ax.set_xlabel('Month')
ax.set_ylabel('Sales (£10k)')
ax.grid(axis='y', linestyle='--', alpha=0.4)
fig.savefig('annotate_basic.png')
print('saved')
```

`annotate` has three parts: **where to point (`xy`), where the text goes (`xytext`), and what the arrow looks like (`arrowprops`)**.

## Crash site 1: xytext is too close to xy

```python
ax.annotate('Peak', xy=('Jun', 190), xytext=('Jun', 192))    # text hugs the data point
```

Output: the text and the data point **overlap completely** and become unreadable. `xytext` needs enough clearance, typically 10%~20% above or to the side of the point.

## Arrow styles

```python
arrowprops=dict(arrowstyle='->',    # shape: ->, <-, -|, <->, ...
                color='#e41a1c',
                lw=1.5,             # line width
                connectionstyle='arc3,rad=0.2')   # curved connector
```

`connectionstyle='arc3,rad=0.2'` makes the arrow **follow an arc**, which is useful when something else blocks the straight path between the two points.

## Reference lines: axhline and axvline

```python
fig, ax = plt.subplots(figsize=(9, 5))
ax.plot(months, sales, marker='o', color='#377eb8', linewidth=2)

# Horizontal reference line: annual monthly target
ax.axhline(y=150, color='#e41a1c', linestyle='--', linewidth=1.5, label='Annual monthly target £1500k')

# Vertical reference line: a point in time
ax.axvline(x=2, color='#4daf4a', linestyle=':', linewidth=1.5, label='Q1 ends')

ax.set_title('Sales vs target line')
ax.set_xlabel('Month')
ax.set_ylabel('Sales (£10k)')
ax.legend()
fig.savefig('ref_lines.png')
```

| Method | Direction | Parameter |
|---|---|---|
| `axhline(y=150)` | Horizontal (fixed value) | y position |
| `axvline(x=2)` | Vertical (fixed value) | x position |
| `axline((x0,y0), (x1,y1))` | Any two points | Two points |

**Crash site 2: using plt.axhline in a multi-panel figure.**

```python
plt.axhline(y=150)          # state-machine style: draws on the current axes of the current figure
```

Output: with several panels, `plt.axhline` **only draws on the last active axes**, and the other panels stay empty. The object-oriented style avoids this entirely.

## Adding text next to a reference line with annotate

A reference line has no built-in caption, so pair it with `annotate`:

```python
ax.axhline(y=150, color='#e41a1c', linestyle='--', linewidth=1.5)
ax.annotate('Monthly target £1500k',
            xy=(5, 150),
            xytext=(5, 158),
            fontsize=10, color='#e41a1c',
            arrowprops=dict(arrowstyle='->', color='#e41a1c'))
```

**Reference line + annotation** is the standard combination for a "hitting / missing target" analysis.

## Labelling values above bars

```python
fig, ax = plt.subplots(figsize=(9, 5))
bars = ax.bar(months, sales, color='#377eb8')
for bar in bars:
    h = bar.get_height()
    ax.text(bar.get_x() + bar.get_width() / 2, h,
            str(h), ha='center', va='bottom', fontsize=9)
ax.set_title('Values labelled above bars')
fig.savefig('bar_text.png')
```

`ax.text(x, y, s)` writes text at a coordinate. Printing the value above each bar is the most common finishing touch on a bar chart.

**Crash site 3: text gets clipped because it is outside the axis limits.**

```python
ax.text(0, 210, 'Maximum', fontsize=12)     # y=210 is above the current y-axis range
```

Output: the text is **clipped and invisible**. Fix it by leaving headroom with `ax.set_ylim`:

```python
ax.set_ylim(0, 230)         # leave a 40-unit gap at the top
```

## Highlighting a range: axvspan / axhspan

```python
# Give the "promotion period" a background colour
ax.axvspan(3, 5, alpha=0.15, color='#ff7f00')
ax.text(4, 195, 'Summer sale', ha='center', fontsize=10, color='#ff7f00')
```

`axvspan(xmin, xmax)` lays a **background band** over a range, which is ideal for flagging "promotion periods", "holidays", or "anomalous windows". Combined with a label, it immediately tells the reader that this interval differs from the rest.

## How to space several annotations

When you annotate more than three points, **keep the arrows from crossing**:

```python
peaks = [('Jun', 190), ('Apr', 160)]
offsets = [('Mar', 205), ('Jan', 175)]       # alternate text positions above and below
for (x, y), (tx, ty) in zip(peaks, offsets):
    ax.annotate(f'£{y}0k', xy=(x, y), xytext=(tx, ty),
                arrowprops=dict(arrowstyle='->', color='#e41a1c', lw=1.2),
                fontsize=10, color='#e41a1c')
```

Place the text labels **in alternating positions** so the arrows do not cross each other and the labels do not all pile up on one side.

## Recap

- `annotate(xy=target, xytext=label position, arrowprops=arrow style)` has three parts
- Reference lines: `axhline` (horizontal, fixed value), `axvline` (vertical, fixed value), `axvspan` (background band)
- `ax.text(x, y, s)` writes at a coordinate; remember `set_ylim` to leave room at the top
- A reference line with no caption should be paired with annotate
- With several annotations, **alternate the label positions** so arrows never cross
- In multi-panel figures, use the object-oriented style; avoid `plt.axhline`
