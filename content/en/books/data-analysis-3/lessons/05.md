# Saving and Exporting: the Pitfalls of `savefig`

> Drawing is not the finish line — producing the file is. This lesson covers the four dimensions of `savefig`: size, dpi, bbox and format, so your output is sharp, uncropped and trouble-free.

## The simplest usage

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

fig, ax = plt.subplots()
ax.plot([1, 2, 3], [1, 2, 3])
ax.set_title('London Store Sales')

fig.savefig('out.png')        # save to file
print('saved')
```

`savefig` picks the format **from the file extension**: `.png` → PNG, `.pdf` → PDF, `.svg` → SVG. No explicit choice is needed.

## Size: `figsize` and `dpi`

Image sharpness is determined by two parameters together:

```python
fig, ax = plt.subplots(figsize=(8, 5))    # canvas size in inches
ax.plot([1, 2, 3], [1, 2, 3])
ax.set_title('London Store Sales')
fig.savefig('out.png', dpi=150)            # 150 dots per inch
```

**Final pixels = figsize × dpi:**

| figsize | dpi | Actual pixels |
|---|---|---|
| (8, 5) | 100 | 800 × 500 |
| (8, 5) | 150 | 1200 × 750 |
| (8, 5) | 300 | 2400 × 1500 |

DPI means "dots per inch". **100–150 is enough for screen and web; 300 for print and papers.**

## Failure scenario 1: labels get cropped

```python
fig, ax = plt.subplots(figsize=(4, 3))      # canvas too small
ax.plot([1, 2, 3], [1, 2, 3])
ax.set_title('London Store H1 Monthly Sales Detailed Statistics')
ax.set_xlabel('Month (2025)')
ax.set_ylabel('Revenue (£10k, incl. VAT)')
fig.savefig('out.png')                      # title and y-label are cut off
```

Output: the figure looks fine, but **the right side of the title and the left side of the y-label are sliced off**. By default `savefig` clips to the canvas boundary, so over-long labels overflow.

**Fix: `bbox_inches='tight'`**

```python
fig.savefig('out.png', bbox_inches='tight')
```

This makes matplotlib **compute the content boundary automatically**, wrapping labels and titles inside it.

## Failure scenario 2: `savefig` without `tight_layout`

`bbox_inches='tight'` crops at save time; `fig.tight_layout()` lays out subplots at draw time. **They operate at different stages:**

```python
fig, axes = plt.subplots(1, 2)
axes[0].set_title('London')
axes[1].set_title('New York, H1 2025 Sales Statistics')
# forgot tight_layout -> the two subplot titles may overlap
fig.savefig('out.png')
```

**Correct version:**

```python
fig.tight_layout()              # first let the subplots auto-arrange
fig.savefig('out.png', bbox_inches='tight')   # then trim the excess whitespace
```

**Failure scenario 3: no `figsize`, the image is tiny and muddy.**

```python
fig, ax = plt.subplots()          # default figsize=(6.4, 4.8)
ax.plot([1, 2, 3], [1, 2, 3])
ax.set_title('London Store Sales')
fig.savefig('out.png', dpi=50)    # dpi too low, text is jagged
```

Output: roughly 320×240 pixels with jagged text edges — drop it into a slide and it turns to mush. **For web or reports use at least dpi=100; for final output use 150–300.**

## Choosing a format

| Format | Traits | Use for |
|---|---|---|
| **PNG** | Lossy/lossless bitmap, supports transparency | Web, slides, screenshots, final delivery |
| **SVG** | Vector, infinitely scalable | Web embedding, later editing in Illustrator |
| **PDF** | Vector, cross-platform | Papers, printing, submission |
| **JPG** | Lossy compression, artefacts | **Not recommended for charts** (lines blur) |

**The key difference: PNG is a "pixel image" that turns to mush when enlarged; SVG/PDF are "vector images" that stay sharp.**

```python
fig.savefig('chart.png', dpi=150)
fig.savefig('chart.svg')       # vector, no dpi concept
fig.savefig('chart.pdf')       # vector
```

## Transparent background

```python
fig.savefig('chart.png', transparent=True)
```

A transparent background is good for **overlay on a dark slide or webpage**. But beware: transparent background + white text = invisible; plan the colour scheme together.

## Do not forget to close the figure

Matplotlib figures keep occupying memory. Drawing hundreds of figures in a loop without closing them will **exhaust memory**:

```python
# WRONG: building figures in a loop without closing them
for i in range(500):
    fig, ax = plt.subplots()
    ax.plot([1, 2, 3], [1, 2, 3])
    fig.savefig(f'fig_{i}.png')
# all 500 figures stay in memory
```

**Correct version:**

```python
for i in range(500):
    fig, ax = plt.subplots()
    ax.plot([1, 2, 3], [1, 2, 3])
    fig.savefig(f'fig_{i}.png')
    plt.close(fig)        # close immediately after drawing, free memory
```

You can also use a `with` context (matplotlib ≥ 3.5):

```python
with plt.rc_context({'font.size': 12}):
    fig, ax = plt.subplots()
    ax.plot([1, 2, 3], [1, 2, 3])
    fig.savefig('out.png')
plt.close(fig)            # close when done
```

## A complete reusable template

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

fig, ax = plt.subplots(figsize=(8, 5))

months = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun']
sales = [120, 135, 128, 160, 175, 190]
ax.plot(months, sales, marker='o', color='#e41a1c', linewidth=2)

ax.set_title('London Store H1 Sales')
ax.set_xlabel('Month')
ax.set_ylabel('Revenue (£10k)')
ax.grid(True, linestyle='--', alpha=0.5)

fig.tight_layout()
fig.savefig('london_sales.png', dpi=150, bbox_inches='tight')
plt.close(fig)
print('done')
```

From fonts to layout to saving, **this is a reusable template.**

## Recap

- `savefig` picks the format from the **extension**, no explicit setting needed.
- Pixels = `figsize × dpi`: web 100–150, print 300.
- Cropped labels → `bbox_inches='tight'`; overlapping subplots → `fig.tight_layout()`.
- Format choice: PNG bitmap / SVG PDF vector / **never JPG for charts**.
- In loops always `plt.close(fig)`, otherwise memory explodes.
- `transparent=True` for a transparent background; mind the colour scheme on dark backgrounds.
