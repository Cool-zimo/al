# Charts That Lie: Truncated Axes, Dual Axes, Area Tricks and Hidden Sample Sizes

> The same data can tell completely different stories depending on how you draw it. This lesson covers four of the most common visual deceptions and how to draw honestly instead.

## Deception 1: the truncated Y axis

When the baseline of a bar chart is not 0 but starts near the minimum, differences are **magnified several times over**.

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import pandas as pd

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

sales = pd.DataFrame({
    'store': ['London', 'New York', 'Manchester', 'Bristol'],
    'revenue': [320, 310, 300, 295],
})

# Dishonest version: Y starts at 280
fig, ax = plt.subplots(figsize=(8, 5))
ax.bar(sales['store'], sales['revenue'])
ax.set_ylim(280, 340)
ax.set_title('Truncated Y axis: the gap looks huge')
fig.savefig('trick1.png')

# Honest version: baseline at 0
fig, ax = plt.subplots(figsize=(8, 5))
ax.bar(sales['store'], sales['revenue'])
ax.set_ylim(0, 350)
ax.set_title('Baseline at zero: the gap is tiny')
fig.savefig('honest1.png')
```

The data differs by only 8%, but after truncation the bar heights differ by a factor of three. London looks far ahead when it is only 8% above Bristol. **A bar chart must start at 0** - that is a hard rule, because the bar encodes its value through height, and moving the baseline breaks that encoding.

**Line charts are the exception**: a line expresses a trend, so the starting point can be non-zero, but it must be **stated in the title or a note**. If the temperature runs from -5°C to 5°C, starting at 0 would crush the line against the bottom, so truncation is acceptable - but label it.

## Deception 2: the dual Y axis

One scale on the left, another on the right, with two lines measured in different units, trying to make them "look related".

```python
# Fabricate a fake relationship: ice cream sales and drownings both rise
fig, ax1 = plt.subplots(figsize=(8, 5))
months = ['May', 'Jun', 'Jul', 'Aug', 'Sep']
ice = [10, 25, 60, 80, 40]
drown = [2, 5, 12, 15, 7]

ax1.plot(months, ice, color='orange', marker='o')
ax1.set_ylabel('Ice cream sales', color='orange')
ax1.set_ylim(0, 100)

ax2 = ax1.twinx()
ax2.plot(months, drown, color='blue', marker='s')
ax2.set_ylabel('Drownings', color='blue')
ax2.set_ylim(0, 20)

ax1.set_title('Dual Y axis: manufacturing a fake correlation')
fig.savefig('trick2.png')
```

Both lines "run from bottom left to top right", so they look strongly related. **But their units and scale ranges are entirely independent, so the author can adjust them to overlap at will.** In this example the common cause is "summer", not "eating ice cream causes drowning".

**Rule: use facets instead of a second axis whenever you can.** Draw each metric on its own chart and align them, and you get no deception plus a direct comparison of trends.

```python
fig, axes = plt.subplots(2, 1, sharex=True, figsize=(8, 6))
axes[0].plot(months, ice, color='orange', marker='o')
axes[0].set_title('Ice cream sales')
axes[1].plot(months, drown, color='blue', marker='s')
axes[1].set_title('Drownings')
fig.tight_layout()
fig.savefig('honest2.png')
```

**If you really must use two axes** (for example when two metrics genuinely need to be overlaid), do at least three things: ① use clearly different line styles and colours; ② label the legend so it is obvious which line belongs to which axis; ③ state in the title that the units differ.

## Deception 3: the area trick

Using the **area** of a circle to show a value is already hard for the eye, and it gets worse when the **radius** is made proportional to the value - then the area becomes a squared relationship and the difference is magnified again.

```python
fig, ax = plt.subplots(figsize=(7, 5))
sizes = [100, 200, 300]
radii = [1, 2, 3]   # WRONG: radius proportional to value, so area is 1:4:9
ax.set_title('Bubble size mapped by radius (misleading)')
fig.savefig('trick3.png')
```

The values 100 → 300 are a ratio of three, but the area ratio is 1:9, which looks nine times bigger. **To make area proportional to the value, take the square root for the radius**:

```python
areas = [300, 600, 900]          # area proportional to value
radii = [np.sqrt(a) for a in areas]   # radius is the square root
```

**In a bubble chart the `sizes` parameter controls area, not radius** - that is the easiest trap. In `sns.scatterplot(..., size=..., sizes=(min, max))`, seaborn already applies the square-root mapping for you, so using it directly is correct.

## Deception 4: hiding the sample size

A comparison chart with a tenfold difference in sample size, but no n on the bars. This is the most common omission in reports.

```python
store = pd.DataFrame({
    'store': ['London', 'Bristol'],
    'avg_spend': [185, 172],
    'sample_size': [1200, 80],   # 15-fold difference
})

fig, ax = plt.subplots(figsize=(7, 5))
bars = ax.bar(store['store'], store['avg_spend'])
for b, n in zip(bars, store['sample_size']):
    ax.text(b.get_x() + b.get_width()/2, b.get_height() + 2,
            f'n={n}', ha='center', fontsize=11)
ax.set_title('Average spend by store (sample size shown)')
fig.savefig('honest3.png')
```

Bristol has n=80, so its confidence interval is wide and its result is noisy - the conclusion that it is "a bit lower" is unreliable. **When sample sizes are unbalanced, n is not a footnote; it is part of the conclusion.** A comparison chart without n is, at heart, hiding how strong the evidence is.

## Self-check list for dishonest charts

| Check | Ask yourself |
|---|---|
| Baseline | Does the bar chart start at 0? |
| Scale | Are there two independent units? |
| Area | Is area proportional to the value, or squared? |
| Sample size | Is n shown and is the evidence strong enough? |

**Wreck of the day: describing correlation as causation.**

```python
# Ice cream sales and drownings are correlated, but the shared cause is summer heat
# Implying "ice cream causes drowning" with a chart would be fabrication
```

Even if the chart itself has no truncation and no dual axis, **a causal suggestion in the narrative is still fabrication**. The chart is only evidence; the conclusion must stay inside what the evidence can support. Write "both rise together, possibly driven by the summer heat", not "ice cream causes drowning".

## Summary

- A bar chart must start at 0, otherwise height encoding breaks and differences are magnified
- Line charts may be truncated but must say so; facets beat dual axes
- A dual axis lets you manipulate the scales to fake a correlation; if you must use one, label the units clearly
- Area must be proportional to the value, so the radius is the square root; the bubble `sizes` parameter controls area
- With unbalanced sample sizes n must be shown - it is part of the conclusion
- Even with an honest chart, a causal suggestion in the narrative is still dishonest
- Four-step self check: baseline, scale, area, sample size
