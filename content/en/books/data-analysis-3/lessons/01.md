# Why We Visualize: Anscombe's Quartet

> Four tiny datasets with nearly identical statistics, yet four completely different stories on paper. This lesson answers a foundational question: if means and variances already summarize the data, why bother drawing a picture?

## The four datasets, up close

In 1973 the statistician Francis Anscombe constructed four artificial datasets, now known as **Anscombe's quartet**. Each set contains 11 points, each point an `(x, y)` pair.

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

# Four datasets, each 11 (x, y) points
data = {
    'I':   [(10.0, 8.04), (8.0, 6.95), (13.0, 7.58), (9.0, 8.81),
            (11.0, 8.33), (14.0, 9.96), (6.0, 7.24), (4.0, 4.26),
            (12.0, 10.84), (7.0, 4.82), (5.0, 5.68)],
    'II':  [(10.0, 9.14), (8.0, 8.14), (13.0, 8.74), (9.0, 8.77),
            (11.0, 9.26), (14.0, 8.10), (6.0, 6.13), (4.0, 3.10),
            (12.0, 9.13), (7.0, 7.26), (5.0, 4.74)],
    'III': [(10.0, 7.46), (8.0, 6.77), (13.0, 12.74), (9.0, 7.11),
            (11.0, 7.81), (14.0, 8.84), (6.0, 6.08), (4.0, 5.39),
            (12.0, 8.15), (7.0, 6.42), (5.0, 5.73)],
    'IV':  [(8.0, 6.58), (8.0, 5.76), (8.0, 7.71), (8.0, 8.84),
            (8.0, 8.47), (8.0, 7.04), (8.0, 5.25), (19.0, 12.50),
            (8.0, 5.56), (8.0, 7.91), (8.0, 6.89)],
}
```

The x's and y's of these four datasets have **basically the same summary statistics**.

## Computing the statistics

```python
import numpy as np

for name, points in data.items():
    xs = [p[0] for p in points]
    ys = [p[1] for p in points]
    # means rounded to 2 decimals
    mx, my = round(np.mean(xs), 2), round(np.mean(ys), 2)
    # sample variance (divide by n-1)
    vx, vy = round(np.var(xs, ddof=1), 2), round(np.var(ys, ddof=1), 2)
    # correlation coefficient
    r = round(np.corrcoef(xs, ys)[0, 1], 3)
    # slope b of the regression line y = a + b*x
    b, a = np.polyfit(xs, ys, 1)
    print(f"{name:>3}: xbar={mx:>5}  ybar={my:>5}  var(x)={vx:>5}  var(y)={vy:>5}  r={r:>5}  slope={round(b, 2)}")
```


**Means, variances, correlation, regression slope — identical across all four.** If you only report those numbers, no one can tell the datasets apart.

## Plotting changes everything

```python
fig, axes = plt.subplots(2, 2, figsize=(8, 7))

for ax, (name, points) in zip(axes.flat, data.items()):
    xs = [p[0] for p in points]
    ys = [p[1] for p in points]
    ax.scatter(xs, ys, color='#2c7fb8')
    ax.set_title(f'Dataset {name}')
    ax.set_xlabel('x')
    ax.set_ylabel('y')

fig.suptitle("Anscombe's Quartet")
fig.tight_layout()
fig.savefig('anscombe.png')
print('Saved; use plt.show() to view')
```

The four pictures tell four completely different stories:

| Dataset | What it looks like | What the story is |
|---|---|---|
| **I** | Ordinary scatter, roughly a straight line | Classic positive correlation: bigger x, bigger y |
| **II** | One clean curve | **Non-linear relationship** — fitting a line is wrong |
| **III** | All points but one sit on a near-vertical line | An extreme value dominates everything; the slope is an illusion |
| **IV** | All x's identical except for one outlier | Again **outlier-dominated**; remove it and there is nothing left |

## The key takeaways

- **Statistics compress data, and compression loses information.** Means, variances and correlations collapse 11 points into 4 numbers, necessarily discarding shape.
- **The regression line is the line with slope 0.5**, but it only makes sense for dataset I. On III and IV it is actively misleading.
- **Make "look first" a habit**: whenever you get a new dataset, run `plt.scatter` or `df.plot()` to glance at the distribution *before* discussing means and fits. Many real project errors come from skipping this step.

## A common misconception

> "I have already computed the mean and standard deviation. The conclusion is stable; drawing a picture is unnecessary."

Anscombe was designed to demolish exactly this attitude. Four datasets with **identical** statistics describe four completely different data-generating processes. **The same mean can come from a normal distribution or from a single outlier pulling the average up** — and those two situations demand entirely different treatment (model directly in one case, remove or analyse the outlier separately in the other).

## Recap

- Means, variances and correlations compress data into a few numbers, **always losing information**.
- Anscombe's quartet: all four datasets share x̄=9.0, ȳ=7.5, var(x)=11.0, var(y)=4.13, r=0.816, slope=0.5.
- Yet the four plots tell four stories: "linear", "non-linear", "outlier-dominated", and "single point hijack".
- When you receive data, **plot first, then read the statistics** — the cheapest move that prevents a directional error.
