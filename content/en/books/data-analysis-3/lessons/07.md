# Line Charts and Time Series: Trends and Dual Y-Axes

> A line chart tells a "story of change": how sales move, how temperature shifts, how users grow. This lesson covers the correct way to draw time series and how to put "two different units" on one chart.

## What a line chart expresses

**Bar charts compare magnitudes; line charts show trends.** The connecting line implies continuity — the space between two points carries meaning (time, age, distance). If your x is purely categorical (store names, for instance), a line chart is wrong and will draw meaningless connections.

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

months = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun',
          'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec']
sales = [120, 135, 128, 160, 175, 190, 205, 220, 210, 230, 250, 270]

fig, ax = plt.subplots(figsize=(9, 5))
ax.plot(months, sales, marker='o', color='#e41a1c', linewidth=2)
ax.set_title('London Store, Full-Year 2025 Sales')
ax.set_xlabel('Month')
ax.set_ylabel('Revenue (£10k)')
fig.autofmt_xdate(rotation=45)      # tilt x labels to avoid overlap
fig.savefig('line_trend.png')
print('saved')
```

`fig.autofmt_xdate(rotation=45)` rotates the x-axis labels by 45°, so **months do not crowd together** when there are many of them.

## A dual Y-axis: two units on one chart

A common situation: sales in £10k and average order value in £, shown together — but **the two differ in scale by a factor of 100**, so plotting both on one axis crushes one of them.

```python
months = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun']
sales = [120, 135, 128, 160, 175, 190]        # £10k
avg_price = [320, 315, 340, 335, 330, 345]    # £

fig, ax1 = plt.subplots(figsize=(9, 5))

# first axis: sales
ax1.plot(months, sales, color='#e41a1c', marker='o', label='Sales')
ax1.set_xlabel('Month')
ax1.set_ylabel('Sales (£10k)', color='#e41a1c')
ax1.tick_params(axis='y', labelcolor='#e41a1c')

# second axis: avg price (shares the x-axis)
ax2 = ax1.twinx()
ax2.plot(months, avg_price, color='#377eb8', marker='s', label='Avg Price')
ax2.set_ylabel('Avg Price (£)', color='#377eb8')
ax2.tick_params(axis='y', labelcolor='#377eb8')

fig.savefig('twinx.png')
```

`ax1.twinx()` creates a new coordinate system that **shares the x-axis but has its own y-axis**. Both axes must be coloured separately (`tick_params` recolours the tick labels) — otherwise the reader cannot tell which line belongs to which axis.

## Failure scenario 1: `twinx` shows only half the legend

```python
ax1.plot(months, sales, color='#e41a1c', label='Sales')
ax2 = ax1.twinx()
ax2.plot(months, avg_price, color='#377eb8', label='Avg Price')

ax1.legend()         # only "Sales" appears
```

Output: the legend **only shows "Sales"**; "Avg Price" is missing. `ax1.legend()` only collects the lines on `ax1`.

**Fix: merge the handles from both lines.**

```python
lines1, labels1 = ax1.get_legend_handles_labels()
lines2, labels2 = ax2.get_legend_handles_labels()
ax1.legend(lines1 + lines2, labels1 + labels2, loc='upper left')
```

## Failure scenario 2: the two axes do not share a baseline

```python
# WRONG: both y-axes start at 0, but the 0 should really align
ax1.set_ylim(0, 300)
ax2.set_ylim(300, 400)      # avg price 320-345 occupies only a sliver at the top, looks flat
```

Output: the average-price line **appears almost unchanged**, because it occupies only the top slice of the y-axis. Two scales of different magnitude are normal, but watch out for this "compressed" visual deception.

## The correct way to draw a time series

**When x is a date string, matplotlib lays it out as a category in order, not as a true time axis.** To scale the gaps between dates correctly, use `datetime`:

```python
from datetime import datetime

dates = [datetime(2025, 1, 1), datetime(2025, 2, 1), datetime(2025, 3, 1),
         datetime(2025, 4, 1), datetime(2025, 5, 1), datetime(2025, 6, 1)]
sales = [120, 135, 128, 160, 175, 190]

fig, ax = plt.subplots(figsize=(9, 5))
ax.plot(dates, sales, marker='o')
ax.set_title('Using datetime for x scales the gaps proportionally')
fig.autofmt_xdate()
fig.savefig('datetime.png')
```

The benefit: if a month is missing (no data), the time axis **leaves a gap** instead of connecting the broken months with a continuous line — that is the real temporal relationship.

## Failure scenario 3: uneven date intervals are joined as a straight line

```python
dates = [datetime(2025, 1, 1), datetime(2025, 1, 15),
         datetime(2025, 3, 1), datetime(2025, 6, 1)]    # intervals 1 day / 45 days / 91 days
vals = [10, 12, 15, 20]

ax.plot(dates, vals)     # looks like a smooth rise
```

Output: the line is **drawn as a straight rise**, hiding a gap of several months in between. **Always use datetime for a real time series**, so matplotlib leaves proportional gaps.

## Step lines and area charts

**Use a step line (`step`) for cumulative quantities:**

```python
ax.step(months, sales, where='mid', color='#4daf4a')
```

`where='mid'` jumps at the midpoint of each category, which suits quantities that only change at discrete moments, such as inventory or order counts.

**Use a fill-between to emphasise "volume":**

```python
ax.fill_between(months, sales, alpha=0.3, color='#377eb8')
```

`fill_between` fills the area under the curve, giving it **more visual weight**, which is good for emphasising totals.

## Colours for multiple lines

```python
fig, ax = plt.subplots(figsize=(9, 5))
ax.plot(months, sales_london, label='London', color='#e41a1c')
ax.plot(months, sales_newyork, label='New York', color='#377eb8')
ax.plot(months, sales_tokyo, label='Tokyo', color='#4daf4a')
ax.legend()
```

Use **highly distinct soft colours**, not three similar blues. Red-blue-green (Set1) is the classic, colour-blind-friendly combination.

## Recap

- Line charts show **trends and change**; x should be continuous (time, age, distance).
- Dual Y-axis: `ax1.twinx()`; colour the two axes separately, and merge the legend manually.
- A real time series uses `datetime` for x, leaving gaps for missing months.
- Many categories: `autofmt_xdate(rotation=45)` tilts the labels.
- Use `step` for cumulative values, `fill_between` to emphasise totals.
