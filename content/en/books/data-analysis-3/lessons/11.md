# Multi-panel layouts: subplots, shared axes, and tight packing

> One figure with several panels is the standard shape of any analytical report. This lesson covers the three ways to build a `subplots` grid, how to share axes between panels, and when to call `tight_layout`.

## The three basic layouts

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

months = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun']

# 1) One row, several columns
fig, axes = plt.subplots(1, 3, figsize=(15, 4))

# 2) One column, several rows
fig, axes = plt.subplots(3, 1, figsize=(6, 12))

# 3) A grid
fig, axes = plt.subplots(2, 2, figsize=(10, 8))
```

`plt.subplots(nrows, ncols)` returns a tuple `(fig, axes)`. The `fig` is the whole canvas; `axes` is a NumPy array of Axes objects.

## How to index into axes

```python
fig, axes = plt.subplots(2, 2, figsize=(10, 8))

axes[0, 0].plot(months, [120, 135, 128, 160, 175, 190])
axes[0, 0].set_title('London')

axes[0, 1].plot(months, [110, 118, 130, 140, 155, 168])
axes[0, 1].set_title('New York')

axes[1, 0].bar(months, [90, 100, 95, 110, 130, 140])
axes[1, 0].set_title('Manchester')

axes[1, 1].scatter([1, 2, 3, 4, 5], [2, 3, 5, 7, 11])
axes[1, 1].set_title('Bristol')

fig.tight_layout()
fig.savefig('grid.png')
```

**Crash site 1: when there is only one row or one column, axes is not two-dimensional.**

```python
fig, axes = plt.subplots(1, 3)      # one row, three columns
axes[0].plot(...)                    # correct: one-dimensional
axes[0, 0].plot(...)                # WRONG: IndexError, a 1-D array has no second index
```

Output: `IndexError: too many indices for array`. A `1×N` or `N×1` layout gives you a **1-D array**; only an `N×M` grid with both N>1 and M>1 is two-dimensional.

**The uniform fix: use `axes.flat` or reshape in advance.**

```python
for i, ax in enumerate(axes.flat):
    ax.plot(months, sales_list[i])
    ax.set_title(cities[i])
```

`axes.flat` **flattens the array into an iterator**, so the same loop works whether the grid is 1-D or 2-D.

## Sharing axes: remove the duplicated ticks

```python
fig, axes = plt.subplots(2, 1, sharex=True, figsize=(8, 6))

axes[0].plot(months, [120, 135, 128, 160, 175, 190])
axes[0].set_title('London')

axes[1].plot(months, [110, 118, 130, 140, 155, 168])
axes[1].set_title('New York')

fig.tight_layout()
fig.savefig('sharex.png')
```

`sharex=True`: the **two panels share the same x-axis**, so tick labels only appear on the bottom panel. This removes duplicate information and keeps both series vertically aligned, which makes it much easier to compare their shapes.

**When should you share an axis?**

| Scenario | Share? |
|---|---|
| Comparing two lines over the same time period | sharex |
| The same metric across several stores | sharey (or sharex) |
| Completely unrelated metrics | no, it would mislead |
| Different categories | no, the ticks would not line up |

## Crash site 2: sharing when you should not

```python
fig, axes = plt.subplots(2, 1, sharey=True)
axes[0].bar(['London', 'New York', 'Manchester'], [100, 200, 150])
axes[1].bar(['Apples', 'Bananas', 'Oranges'], [10, 20, 15])   # different categories!
```

Output: both panels are forced onto the same y-axis scale, so **the second set of bars is squashed down to almost nothing**. The visual implication is "the second group is tiny", when in fact the two groups simply use different units. Sharing an axis only makes sense when the two datasets have similar ranges and the same unit.

## Irregular layouts: GridSpec

For an "one large panel on top, two smaller panels below" layout, reach for `GridSpec`:

```python
from matplotlib.gridspec import GridSpec

fig = plt.figure(figsize=(10, 8))
gs = GridSpec(2, 2, figure=fig)           # 2 rows, 2 columns

ax1 = fig.add_subplot(gs[0, :])           # row 0, spanning both columns
ax2 = fig.add_subplot(gs[1, 0])           # row 1, column 0
ax3 = fig.add_subplot(gs[1, 1])           # row 1, column 1

ax1.plot(months, [120, 135, 128, 160, 175, 190])
ax1.set_title('National overview (spanning 2 columns)')

ax2.bar(months, [90, 100, 95, 110, 130, 140])
ax2.set_title('South region')

ax3.scatter([1, 2, 3, 4, 5], [2, 3, 5, 7, 11])
ax3.set_title('North region')

fig.tight_layout()
fig.savefig('gridspec.png')
```

`gs[0, :]` means "the entire row 0", while `gs[1, 0]` is a single cell. The slicing syntax works exactly like NumPy indexing.

## tight_layout vs. constrained_layout

```python
fig, axes = plt.subplots(2, 2)
# ... do all the drawing ...
fig.tight_layout()              # adjust spacing automatically to prevent overlap
```

`tight_layout` must be called **after every drawing operation** is finished. It recomputes the gaps between panels so titles and tick labels do not crash into each other.

**Crash site 3: calling tight_layout before you draw.**

```python
fig, axes = plt.subplots(2, 2)
fig.tight_layout()              # called too early
axes[0, 0].plot(...)
axes[0, 1].set_title('This title is very very very very very long')
# the title overflows because tight_layout computed the layout while the figure was still empty
```

Output: the long title **spills over into the neighbouring panel**. `tight_layout` froze its calculation at the moment you called it, so it knew nothing about the content you added afterwards.

**The correct order:**

```python
fig, axes = plt.subplots(2, 2)
axes[0, 0].plot(...)
axes[0, 1].set_title('This title is very very very very very long')
# ... every drawing call goes here ...
fig.tight_layout()              # called last
```

Alternatively, pass `constrained_layout=True` when you create the figure (matplotlib >= 3.4). It **adjusts continuously** as you add content:

```python
fig, axes = plt.subplots(2, 2, constrained_layout=True)
```

## A title for the whole figure: suptitle

```python
fig.suptitle('London stores: H1 2025 performance review', fontsize=14, fontweight='bold')
```

`fig.suptitle` sets a title for **the entire canvas**, which is separate from each panel's `set_title`. `tight_layout` leaves room for it by default, but with an especially long title you may also need `fig.tight_layout(rect=[0, 0, 1, 0.96])` to widen the top margin.

## Recap

- `plt.subplots(nrows, ncols)` returns `(fig, axes)`
- With 1 row or 1 column, `axes` is **1-D**; in a grid it is 2-D. Iterate with `axes.flat`
- Shared axes: `sharex=True` / `sharey=True`, only meaningful when units and ranges are similar
- Irregular layouts use `GridSpec`; its slicing syntax mirrors NumPy
- `tight_layout()` belongs at the **end** of your drawing code
- The whole-figure title is `fig.suptitle`
