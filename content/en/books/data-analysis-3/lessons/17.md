# Distribution plots: histplot, kdeplot, displot

> The first thing you do with a dataset is not draw a relationship plot, it is **look at its shape**. A distribution plot answers "how often does this value occur, and where is the density concentrated".

## Histograms: histplot

A histogram slices a continuous variable into intervals (bins) and counts how many records fall into each one. It is the most basic tool for inspecting a distribution.

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd
import numpy as np

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

tips = sns.load_dataset('tips')

fig, ax = plt.subplots(figsize=(8, 5))
sns.histplot(data=tips, x='total_bill', bins=20, ax=ax)
ax.set_title('Bill amount distribution (20 bins)')
fig.savefig('hist1.png')
```

`bins=20` is the **number of intervals**. More bins make each bar narrower, exposing local fluctuations but also the random jitter of the sample; fewer bins make the curve smoother but can merge two peaks into one. This is not "more is better", it is a parameter you tune by trying values.

**Crash site 1: too many bins, noise mistaken for structure.**

```python
fig, ax = plt.subplots()
sns.histplot(data=tips, x='total_bill', bins=60, ax=ax)
ax.set_title('Bill distribution with 60 bins')
fig.savefig('hist2.png')
```

With only 244 records split into 60 intervals, many bars hold 0 or 1 record, and the result looks like a sawtooth. You would be tempted to see a cycle where none exists. **Each interval needs enough records**, so as a rule of thumb start between `bins = sqrt(n)` and `n/10`; for n=244 that means roughly 15 to 25.

## Kernel density estimation: kdeplot

A histogram is sensitive to bin boundaries, the shape changes if you shift them slightly. KDE (kernel density estimation) avoids that with a smooth curve, which is better for seeing the **overall centre and spread**.

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.kdeplot(data=tips, x='total_bill', fill=True, ax=ax)
ax.set_title('Density curve of bill amounts')
fig.savefig('kde.png')
```

`fill=True` fills the area under the curve, making it read more like "area = probability". Behind KDE there is a bandwidth parameter controlling smoothness, chosen automatically by Scott's or Silverman's rule, so you rarely need to set it by hand.

**Crash site 2: treating KDE and a histogram as mutually exclusive.**

```python
fig, ax = plt.subplots()
sns.histplot(data=tips, x='total_bill', bins=20, ax=ax)
sns.kdeplot(data=tips, x='total_bill', ax=ax, color='red')   # layered on top
ax.set_title('Histogram + density curve overlaid')
fig.savefig('both.png')
```

This is **not wrong, it is the recommended approach**: the histogram gives you the real frequencies, while KDE gives you the smoothed trend, so one plot shows both "the raw data" and "the fit". seaborn even supports `histplot(..., kde=True)` to overlay the curve in a single call.

## Bivariate distributions: jointplot and 2D KDE

When you want the joint distribution of two continuous variables, a single-variable histogram is not enough.

```python
g = sns.jointplot(data=tips, x='total_bill', y='tip', kind='hex')
g.figure.suptitle('Joint distribution of bill and tip', y=1.02)
g.figure.savefig('joint.png')
```

`kind` can be `scatter` (points), `hex` (hexagonal bins, useful when points are dense), `kde` (2D density contours, useful with many points), or `reg` (with a regression line). Few points call for scatter; many points call for hex or kde, which is the first rule of reading density plots.

## displot: the master switch for distributions

`displot` is a Figure-level function. One entry point covers hist, kde, ecdf, and rug, and it can facet by a column.

```python
g = sns.displot(
    data=tips, x='total_bill',
    kind='hist', bins=20, kde=True,
    hue='sex', col='time', col_wrap=2,
    height=4, aspect=1.4,
)
g.figure.savefig('displot.png')
```

One line does four things: a histogram, an overlaid density curve, colouring by gender, and faceted panels for the dining time. The Axes-level equivalents are `histplot` / `kdeplot` / `ecdfplot` / `rugplot`; use them when you need to embed the result in your own subplots grid.

**Crash site 3: setting a title on the result of displot using the wrong object.**

```python
g = sns.displot(data=tips, x='total_bill', kind='hist')
g.set_title('Bill distribution')          # WRONG: FacetGrid has no set_title method
g.figure.set_title('Bill distribution')   # WRONG: Figure has no set_title either
g.figure.suptitle('Bill distribution')    # correct: suptitle belongs to Figure
```

`displot` returns a `FacetGrid`, not an Axes. It has its own methods: `g.set_axis_labels('amount', 'count')` and `g.set_titles('{col_name}')` to label each panel. For an overall title, use `g.figure.suptitle`.

## ECDF: cumulative distribution, independent of bin choices

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.ecdfplot(data=tips, x='total_bill', hue='sex', ax=ax)
ax.set_title('Cumulative distribution of bill amounts')
fig.savefig('ecdf.png')
```

ECDF (empirical cumulative distribution function) answers "what proportion of bills fall below a certain amount". The vertical axis runs from 0 to 1 and rises monotonically. **For medians and comparing quantiles, ECDF is more direct than a histogram**: where two ECDF curves separate, the two groups differ at that quantile.

| Plot | Best for | Key parameter |
|---|---|---|
| histplot | Where frequencies concentrate | bins |
| kdeplot | The smoothed density shape | fill=True |
| ecdfplot | Quantile proportions | Comparing quantiles |
| jointplot | Joint distribution of two variables | kind=hex/kde/scatter |

## Recap

- Distribution plots are the first step in EDA: **inspect the shape before the relationships**
- Histogram bins are not "the more the better"; too many bins expose noise
- Layering KDE over a histogram is recommended, showing both "real" and "fit"
- `displot` is the Figure-level master switch; it returns a FacetGrid, so title with `g.figure.suptitle`
- ECDF compares quantiles more directly than a histogram and ignores bin boundaries
- Many points call for hex or kde; few points call for scatter
