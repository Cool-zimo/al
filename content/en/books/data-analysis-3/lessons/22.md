# The Full EDA Flow: Shape, Missing Values, Outliers, Relationships

> When you receive new data, do not model it and do not draw charts yet. Exploratory Data Analysis has four fixed steps. Walk through them in order and every later step becomes more reliable.

## Step 1: check the shape

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd
import numpy as np

plt.rcParams['font.sans-serif'] = ['WenQuanYi Micro Hei']
plt.rcParams['axes.unicode_minus'] = False

tips = sns.load_dataset('tips')
print(tips.shape)          # rows and columns
print(tips.dtypes)         # type of each column
print(tips.head())          # what do the first rows look like
print(tips.describe())      # statistical overview of numeric columns
```

`shape` tells you how big the data is, `dtypes` tells you the type of each column (int, float, object, datetime), and `describe()` gives the count, mean, standard deviation and quartiles. These three steps cost almost nothing but prevent most later mistakes.

**Wreck of the day 1: an object column was actually numbers, so every numeric operation failed.**

```python
# Suppose revenue was read in as strings
df = pd.DataFrame({'revenue': ['100', '200', '300', None]})
print(df['revenue'].dtype)          # object
# df['revenue'].mean()              # WRONG: object has no mean
df['revenue'] = pd.to_numeric(df['revenue'], errors='coerce')
print(df['revenue'].mean())          # 200.0
```

If the type is wrong, every later numeric analysis is empty. `dtypes` is your first check. **Every unexpected object column deserves the question "was this supposed to be a number?"**

## Step 2: check the missing values

```python
print(tips.isna().sum())                    # missing count per column
print(tips.isna().mean().sort_values(ascending=False))  # missing proportion
```

Missing is not "dirty", it is **information**. How you handle it depends on the **mechanism**:

| Situation | How to handle it |
|---|---|
| Missing at random, low proportion (<5%) | drop those rows |
| Missing at random, high proportion | fill with the mean or median |
| The missing itself is meaningful (e.g. blank = did not buy) | keep it as its own category |
| A key column has severe missingness | drop the whole column |

**Wreck of the day 2: filling with the mean shifted the centre of the distribution.**

```python
df = pd.DataFrame({'revenue': [100, 200, 300, np.nan, np.nan]})
filled = df['revenue'].fillna(df['revenue'].mean())
print(filled.mean())     # 200.0
# Looks fine, but if the missing rows were large orders that were not recorded,
# the mean has been severely underestimated.
```

Filling does not mean "job done". **Check whether the missingness is random before you fill**, and redraw the distribution afterwards to see whether its shape has changed.

## Step 3: check the outliers

```python
fig, ax = plt.subplots(figsize=(8, 5))
sns.boxplot(data=tips, x='total_bill', ax=ax)
ax.set_title('Total bill: any outliers?')
fig.savefig('outlier.png')
```

Points beyond the whiskers of a boxplot are outliers. But **an outlier is not necessarily an error**:

```python
# Flag outliers using the IQR method
Q1 = tips['total_bill'].quantile(0.25)
Q3 = tips['total_bill'].quantile(0.75)
IQR = Q3 - Q1
lo, hi = Q1 - 1.5 * IQR, Q3 + 1.5 * IQR
outliers = tips[(tips['total_bill'] < lo) | (tips['total_bill'] > hi)]
print(f'{len(outliers)} outliers')
```

- If it is an **entry error** (age = 200, date = year 2999), correct or delete it
- If it is a **genuine extreme** (a top client's large order), keep it - it may be exactly the sample you most need to study
- If you have **chosen the wrong model** (the data is simply heavy tailed), change the method instead of deleting data

**Wreck of the day 3: deleting every outlier so the model "looks better".**

After the outliers are gone the variance drops and R² rises, so the model looks more accurate. **But what you deleted may have been the most valuable part of the business.** Before deleting, run the numbers again: if you remove them, does the core conclusion change? Only delete if it does not.

## Step 4: check the relationships

```python
# Scan everything with a correlation matrix
corr = tips.corr(numeric_only=True)
fig, ax = plt.subplots(figsize=(7, 6))
sns.heatmap(corr, annot=True, fmt='.2f', cmap='coolwarm',
            vmin=-1, vmax=1, square=True, ax=ax)
ax.set_title('Relationships between variables')
fig.savefig('corr.png')

# Drill into the important relationship with a scatter plot
fig, ax = plt.subplots(figsize=(8, 5))
sns.scatterplot(data=tips, x='total_bill', y='tip', hue='sex', ax=ax)
ax.set_title('Total bill vs tip')
fig.savefig('scatter.png')
```

The order must not be reversed: **check the shape first so you know which charts to use; check the missing values and outliers so you dare to aggregate; only then check relationships, so you are not misled by bad data.**

## EDA overview: one screen, four dimensions

```python
# Show a typical chart for each of the four dimensions
fig, axes = plt.subplots(2, 2, figsize=(13, 10))

sns.histplot(data=tips, x='total_bill', kde=True, ax=axes[0, 0])
axes[0, 0].set_title('1. Shape: distribution')

sns.boxplot(data=tips, x='day', y='total_bill', ax=axes[0, 1])
axes[0, 1].set_title('3. Outliers: extremes')

axes[1, 0].bar(tips['day'].value_counts().index, tips['day'].value_counts().values)
axes[1, 0].set_title('2. Missing: sample size per category')

sns.scatterplot(data=tips, x='total_bill', y='tip', ax=axes[1, 1])
axes[1, 1].set_title('4. Relationship: two variables')

fig.tight_layout()
fig.savefig('overview.png')
```

## Summary

- The four EDA steps run in order: shape → missing → outliers → relationships, and must not be reversed
- `shape`, `dtypes`, `head()` and `describe()` are nearly free sources of information
- Question every object column ("was this meant to be a number?") and convert with `to_numeric` promptly
- How you handle missingness depends on the mechanism; redraw the distribution after filling
- An outlier is not necessarily an error; before deleting, ask "does the conclusion change?"
- Use the correlation matrix for a global scan and a scatter plot to verify what matters
