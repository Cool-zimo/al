# Images: img's src, alt, width and height

> This lesson answers the question: "Why is my image not showing, and why does the page jump?" Path and size are the two most common image problems.

## Basic usage

```html
<img src="photo.jpg" alt="Alice's graduation photo outside Peking University">
```

`<img>` is a self-closing tag (no `</img>` is needed). Its two required attributes:

- `src`: the image path or URL.
- `alt`: alternative text. Informational images must have a clear description.

## Setting width and height prevents layout shifts

```html
<img src="photo.jpg" alt="A landscape" width="400" height="300">
```

Before the image has downloaded, the browser **does not know** how large it is. Without width and height, the browser only fills in the dimensions once the image has loaded, pushing the content below it further down - the user is halfway through reading when the page suddenly jumps.

With `width` and `height` set, the browser **reserves the space in advance**, the image drops into place once it loads, and the page no longer jumps. Modern browsers also use the width/height ratio to handle responsive scaling automatically.

Crash site 1: the aspect ratio does not match the original image.

```html
<img src="photo.jpg" alt="A photo" width="400" height="400">
```

Consequence: the original is a 4:3 landscape image, but forcing it to 400x400 makes it square, distorting the subject. The correct approach is to keep the aspect ratio: `width="400" height="300"`.

## Where paths most often go wrong

Suppose the directory structure is:

```
my-site/
├── index.html
├── about.html
├── images/
│   └── photo.jpg
└── pages/
    └── detail.html
```

Referencing the image from `index.html`:

```html
<img src="images/photo.jpg" alt="A photo">
```

Referencing the same image from `pages/detail.html`:

```html
<img src="../images/photo.jpg" alt="A photo">
```

Note that `../` means **the parent directory**. From inside `pages/`, you must first go back to `my-site/` before entering `images/`.

|写法 | From index.html | From pages/detail.html |
|---|---|---|
| `images/photo.jpg` | ✅ | ❌ not found |
| `../images/photo.jpg` | ❌ one level too many | ✅ |

Crash site 2: using the wrong path relative to the current file from inside a subdirectory.

```html
<!-- This is pages/detail.html -->
<img src="images/photo.jpg" alt="A photo">
```

Consequence: the browser actually requests `pages/images/photo.jpg`, a path that does not exist, and the image is broken. Alice's CV has `about.html` and `index.html` both at the root, and both use the image path `images/photo.jpg`; later she added `pages/blog.html` and forgot to change it to `../images/photo.jpg`, so every image on the page was missing.

## Controlling image size with CSS

```css
img {
  max-width: 100%;
  height: auto;
}
```

`max-width: 100%` means the image is never wider than its parent container, scaling down if it exceeds it; `height: auto` preserves the aspect ratio. This is the standard pattern for making images **responsive**, so they do not break the page on mobile.

Crash site 3: an image that breaks the layout.

```css
img {
  width: 800px;
}
```

Consequence: a mobile screen is only 375px wide, and an 800px image creates a horizontal scrollbar. Switching to `max-width: 100%; height: auto` fixes it.

## Summary

- img is a self-closing tag, and src and alt are required.
- Setting width/height prevents layout shifts, but the original image ratio must be preserved.
- Paths are relative to **the current file**; files in subdirectories use `../` to go up a level.
- Use `max-width: 100%; height: auto` to make images responsive without breaking the layout.

## In-class exercise

```quiz
type: html
q: Write three img tags with src values "a.jpg", "b.jpg" and "c.jpg", all with an empty alt string (treating them as decorative images).
starter: |
  <img src="a.jpg" alt="">
checks:
- document.querySelectorAll('img').length === 3
- document.querySelectorAll('img[alt=""]').length === 3
hint: Write the three img tags side by side, each with an empty alt.
explain: The img tag uses src for the path and an empty alt to mark a decorative image.
```
