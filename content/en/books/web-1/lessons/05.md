# Attributes and Links: href, target and alt

> This lesson answers the question: "How do I write those extra pieces of information on a tag?" Attributes are the "parameters" of a tag; links and images cannot do without them.

## Attributes are written inside the opening tag

```html
<a href="https://www.python.org">Python official site</a>
<img src="photo.jpg" alt="A photo of Alice">
<p class="intro">An introduction</p>
```

The format is `attribute="value"`. Attributes supply information that the tag itself cannot express: the `a` tag needs `href` to know "where to link to", and `img` needs `src` to know "where the image is".

## Links: the a tag

```html
<a href="https://www.example.com">Visit the example site</a>
```

`href` can be a URL, a file path within the site, or an in-page anchor.

```html
<a href="#section2">Jump to chapter two</a>
<h2 id="section2">Chapter two</h2>
```

`href="#section2"` means "jump to the element whose id is section2". This is very common for table-of-contents navigation on long pages.

## target: where to open

```html
<a href="https://www.example.com" target="_blank">Open in a new tab</a>
```

`target="_blank"` makes the link open in a new tab. Without it, the default is to navigate in the current page. Adding `_blank` to external links is common practice, but beware: a page in the new window can access the original page through `window.opener`, which is a security risk. The correct form is to add `rel="noopener"` as well:

```html
<a href="https://www.example.com" target="_blank" rel="noopener">Open in a new tab</a>
```

## Relative paths vs. absolute paths

Suppose the directory structure looks like this:

```
my-site/
├── index.html
├── about.html
└── pages/
    └── contact.html
```

Linking to `about.html` from `index.html`:

```html
<a href="about.html">About</a>             <!-- same level: write the filename directly -->
<a href="pages/contact.html">Contact</a>   <!-- subdirectory: add the path -->
```

| Path写法 | Meaning |
|---|---|
| `about.html` | A file in the same directory |
| `pages/contact.html` | The `pages` subdirectory of the current directory |
| `../images/photo.jpg` | `..` means the parent directory |
| `/style.css` | Starts from the site root (absolute path) |

An absolute path starts with `/`, meaning "count from the site root"; a relative path has no leading `/` and is counted from the current file's location. When Alice deploys her site to `https://alice.example/resume/`, an absolute path of `/style.css` sends the browser to look for `https://alice.example/style.css` - quite possibly a 404. In cases like that, a relative path is safer.

## Why the alt attribute is mandatory

```html
<img src="alice.jpg" alt="Alice's graduation photo outside Peking University">
```

`alt` is the image's **alternative text**. It has three uses:

1. When the image fails to load (the path is wrong, or the network is down), this text is shown.
2. A screen reader reads out the alt content, so a visually impaired user knows what image is here.
3. Search engines use alt to understand the image's content.

Crash site 1: alt is left empty even though the image carries information.

```html
<img src="chart.png" alt="">
```

Consequence: when alt is empty, a screen reader **skips** the image entirely. If this is an important chart, a visually impaired user misses the information completely. Only decorative images (purely for looks, carrying no information) are appropriate candidates for empty alt text.

Crash site 2: the path is wrong.

```html
<img src="images/photo.jpg">
```

Consequence: the file is actually at `img/photo.jpg`, but the path was written as `images/`, so the page shows a broken-image icon. A relative path is relative to **the location of the current HTML file**, not to whatever location you imagined when writing the code. Alice keeps her images in an `assets/` directory, but her code says `../assets/photo.jpg` - one `..` too many - and the image cannot be found.

## Summary

- Attributes are written inside the opening tag, in the format `name="value"`.
- `href` decides where the link points: it can be a URL, a file path, or a `#id` anchor.
- To open in a new window, write `target="_blank" rel="noopener"`.
- A relative path is relative to the current file; an absolute path counts from the root using `/`.
- `alt` is mandatory; write a clear description for informational images and leave it empty only for decorative ones.

## In-class exercise

```quiz
type: html
q: Write an a tag with href "https://www.python.org", target "_blank", rel "noopener" and link text "Python".
starter: |
  <a href="https://www.python.org">Python</a>
checks:
- document.querySelectorAll('a').length === 1
- document.querySelector('a').getAttribute('href') === 'https://www.python.org'
- document.querySelector('a').getAttribute('target') === '_blank'
- document.querySelector('a').getAttribute('rel') === 'noopener'
hint: Keep adding the target and rel attributes to the a tag.
explain: The a tag must have all three attributes - href, target and rel - to meet the requirements.
```
