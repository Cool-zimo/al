# A little JavaScript: dark-mode toggle and nav highlight

> This lesson answers the question: "How do I make the page actually move with JavaScript?" This is the first time we write JS in this book — and if you have learned Python, you will find the syntax very friendly.

## What is JavaScript

HTML is structure, CSS is presentation and **JavaScript is behaviour**. It lets the page respond to user actions: clicks, input, scrolling.

There are two ways to include JS in a page:

```html
<!-- Method 1: inline script -->
<script>
  console.log("Hello, World!");
</script>

<!-- Method 2: external file -->
<script src="app.js"></script>
```

## Toggling dark mode

Let us see the result first, then break down the code. Add a toggle button in the HTML:

```html
<header>
  <h1>Alice Chen</h1>
  <button id="theme-toggle">🌙 Dark mode</button>
</header>
```

The JS:

```javascript
const button = document.getElementById('theme-toggle');
const body = document.body;

button.addEventListener('click', function() {
  body.classList.toggle('dark-mode');
  if (body.classList.contains('dark-mode')) {
    button.textContent = '☀️ Light mode';
  } else {
    button.textContent = '🌙 Dark mode';
  }
});
```

Three steps:

1. **Get the element**: `document.getElementById('theme-toggle')` grabs the button.
2. **Listen for an event**: `addEventListener('click', ...)` runs the function when the button is clicked.
3. **Change the state**: `classList.toggle('dark-mode')` toggles a CSS class on the body.

The CSS to go with it:

```css
body.dark-mode {
  --color-bg: #1a1a2e;
  --color-text: #e0e0e0;
  --color-card: #16213e;
  --color-primary: #e0e0e0;
}

body {
  background: var(--color-bg);
  color: var(--color-text);
  transition: background 0.3s, color 0.3s;
}
```

Because we used CSS variables, switching to dark mode only means **reassigning a few variables** and the whole page responds automatically.

Crash site 1: a typo in the ID passed to getElementById.

```javascript
const btn = document.getElementById('Theme-Toggle'); // wrong case
```

Consequence: `btn` is `null`, and calling `btn.addEventListener` immediately throws `Cannot read properties of null`. JS is case-sensitive: `theme-toggle` ≠ `Theme-Toggle`.

Crash site 2: the script is in the head and the element has not loaded yet.

```html
<head>
  <script>
    document.getElementById('theme-toggle').addEventListener('click', ...);
    // error! the body has not been parsed yet
  </script>
</head>
```

Consequence: getElementById returns null and throws. Fix: place the script just before `</body>`, or wrap it in a `DOMContentLoaded` event.

## Nav highlighting

Another common need: as the page scrolls, highlight the nav item that corresponds to the section currently in view.

```html
<nav class="nav">
  <a href="#about" class="nav-link">About me</a>
  <a href="#skills" class="nav-link">Skills</a>
  <a href="#projects" class="nav-link">Projects</a>
</nav>

<section id="about">...</section>
<section id="skills">...</section>
<section id="projects">...</section>
```

```javascript
const sections = document.querySelectorAll('section');
const navLinks = document.querySelectorAll('.nav-link');

window.addEventListener('scroll', function() {
  let current = '';
  sections.forEach(function(section) {
    const sectionTop = section.offsetTop;
    if (window.scrollY >= sectionTop - 100) {
      current = section.getAttribute('id');
    }
  });

  navLinks.forEach(function(link) {
    link.classList.remove('active');
    if (link.getAttribute('href') === '#' + current) {
      link.classList.add('active');
    }
  });
});
```

The CSS:

```css
.nav-link.active {
  color: var(--color-accent);
  font-weight: bold;
  border-bottom: 2px solid var(--color-accent);
}
```

Crash site 3: the scroll event fires too often and the page janks.

```javascript
window.addEventListener('scroll', function() {
  // heavy calculations on every scroll
  sections.forEach(...);
  navLinks.forEach(...);
});
```

Consequence: scrolling fires dozens of times per second, each one walking the DOM, which is visibly janky on low-end devices. Fix: use **debouncing** or `IntersectionObserver` (the more modern approach, covered in Book 2).

## Remembering the user's choice with localStorage

The user picks dark mode, refreshes and it is light again — a poor experience. Remember it with localStorage:

```javascript
const button = document.getElementById('theme-toggle');
const body = document.body;

// read the previously saved preference
if (localStorage.getItem('dark-mode') === 'true') {
  body.classList.add('dark-mode');
  button.textContent = '☀️ Light mode';
}

button.addEventListener('click', function() {
  body.classList.toggle('dark-mode');
  const isDark = body.classList.contains('dark-mode');
  localStorage.setItem('dark-mode', isDark);
  button.textContent = isDark ? '☀️ Light mode' : '🌙 Dark mode';
});
```

`localStorage` is browser storage of around 5MB that holds strings. Here it stores a boolean `'true'` or `'false'`.

## Summary

- JS handles the page's interactive behaviour by manipulating the DOM to change the page state.
- `getElementById` / `querySelector` get elements; `addEventListener` listens for events.
- Dark mode is implemented with CSS variables plus a class toggle: define once, apply everywhere.
- Scripts should go after the body or be wrapped in DOMContentLoaded.
- localStorage can persist user preferences.
