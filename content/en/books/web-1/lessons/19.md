# Flex basics: one-dimensional layout with flexbox

> This lesson answers the question: "How do I space a few elements evenly along the main axis?" Flex is the workhorse of modern layout — one line of CSS replaces the whole pile of floats and clearfixes you used to need.

## The core idea of Flex

Flex layout is built around two axes: the **main axis** and the **cross axis**. The main axis is the direction in which the children are laid out; the cross axis is perpendicular to it.

```css
.container {
  display: flex;
}
```

As soon as you set `display: flex` on the parent, it becomes a Flex container and all of its **direct children** automatically become Flex items. By default the main axis runs horizontally (left to right) and the cross axis runs vertically.

```html
<div class="container">
  <div class="item">Front-end</div>
  <div class="item">Back-end</div>
  <div class="item">DevOps</div>
</div>
```

```css
.container {
  display: flex;
  border: 2px solid #4a90d9;
  padding: 10px;
}
.item {
  width: 100px;
  height: 60px;
  background: #e0f0ff;
  margin: 5px;
  display: flex;
  align-items: center;
  justify-content: center;
}
```

The three items no longer take one line each; they sit side by side along the main axis. Note that they still have block-level sizes (100px wide) — they just stop wrapping and claiming a full line.

## justify-content: alignment on the main axis

`justify-content` controls how the children are distributed along the **main axis**.

```css
.container {
  display: flex;
  justify-content: space-between; /* both ends, equal gaps in between */
}
```

The common values:

| Value | Effect |
|---|---|
| flex-start | Against the start of the main axis (left by default) |
| center | Centred on the main axis |
| flex-end | Against the end of the main axis (right by default) |
| space-between | Both ends flush, equal gaps between |
| space-around | Equal space on both sides of every item |
| space-evenly | Every gap is exactly equal |

## align-items: alignment on the cross axis

`align-items` controls how the children align on the **cross axis**.

```css
.container {
  display: flex;
  height: 200px;
  align-items: center; /* vertically centred */
}
```

The common values:

| Value | Effect |
|---|---|
| stretch | Stretch to fill the cross axis (default) |
| flex-start | Against the start of the cross axis |
| center | Centred on the cross axis |
| flex-end | Against the end of the cross axis |

Crash site 1: `align-items` does nothing and you assume you typed it wrong.

```css
.container {
  display: flex;
  align-items: center;
}
```

```html
<div class="container">
  <div class="item">A</div>
  <div class="item">B</div>
</div>
```

Consequence: A and B are not vertically centred. Why: the container has no fixed height (or `height` was never stretched open), so the cross axis has no spare space and there is nothing to centre within. Fix: give the container an explicit height, such as `height: 200px`.

## Centre something with one line

The old way of centring used `margin: 0 auto`, which required a block element with a fixed width. With Flex you need just two lines:

```css
.container {
  display: flex;
  justify-content: center; /* horizontal centre */
  align-items: center;     /* vertical centre */
  height: 200px;
}
```

No matter what size the child is, it is centred precisely. This is one of the most common Flex uses.

Crash site 2: writing `text-align` instead of `justify-content`.

```css
.container {
  display: flex;
  text-align: center; /* does nothing */
}
```

Consequence: `text-align` controls the alignment of **inline content**; it has no effect on Flex items. A Flex container uses `justify-content` and `align-items`.

## Flex's default behaviour

Even when you set no alignment properties, Flex has defaults:

- `flex-direction: row` (main axis horizontal, left to right)
- `justify-content: flex-start` (items sit at the left)
- `align-items: stretch` (items stretch to fill the cross axis)
- `flex-wrap: nowrap` (no wrapping; items are compressed)

## Summary

- `display: flex` turns the parent into a Flex container, and direct children become items automatically.
- The main axis is the layout direction; the cross axis is perpendicular to it.
- `justify-content` governs the main axis; `align-items` governs the cross axis.
- Centring is just `justify-content: center` plus `align-items: center` — cleaner than margin auto.
- `align-items` only works when the cross axis has space (the container needs a height).

## In-class exercise

```quiz
type: css
q: Make .box a flex container with justify-content: center, align-items: center and a height of 200px so its child is centred.
html: |
  <div class="box">
    <span>Centred content</span>
  </div>
starter: |
  .box {
  }
checks:
- getComputedStyle(document.querySelector('.box')).display === 'flex'
- getComputedStyle(document.querySelector('.box')).justifyContent === 'center'
- getComputedStyle(document.querySelector('.box')).alignItems === 'center'
- getComputedStyle(document.querySelector('.box')).height === '200px'
hint: Start with display: flex, then set justify-content and align-items to center, and finish with the height.
explain: Flex's double centre is the classic centring solution: justify-content handles the horizontal and align-items the vertical.
```
