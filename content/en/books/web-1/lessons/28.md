# Writing the CSS: a proto design system

> This lesson answers the question: "How do I keep the spacing and colours consistent across the whole page?" The answer is: **manage them centrally with CSS variables — define once, reuse everywhere**. That is the seed of a design system.

## CSS variables: define once, reuse everywhere

CSS variables (Custom Properties) are defined with `--` and referenced with `var()`:

```css
:root {
  --color-primary: #2c3e50;
  --color-accent: #4a90d9;
  --color-bg: #f8f9fa;
  --color-card: #ffffff;
  --color-text: #333333;
  --color-muted: #888888;

  --space-sm: 8px;
  --space-md: 16px;
  --space-lg: 24px;
  --space-xl: 48px;

  --radius: 8px;
  --shadow: 0 2px 8px rgba(0,0,0,0.08);
}

body {
  background: var(--color-bg);
  color: var(--color-text);
}

.card {
  background: var(--color-card);
  border-radius: var(--radius);
  box-shadow: var(--shadow);
  padding: var(--space-lg);
}
```

The benefit: when you want to change the theme colour, you edit `--color-primary` in one place and the whole site updates.

Crash site 1: colour values scattered everywhere.

```css
h1 { color: #2c3e50; }
h2 { color: #2c3e50; }
.nav a:hover { color: #2c3e50; }
.footer { border-top: 2px solid #2c3e50; }
```

Consequence: the product manager says "change the primary colour to dark blue" and you have to search globally for `#2c3e50`, changing each one and hoping you did not miss any. With CSS variables it is one line.

## The seed of a design system

"Design system" sounds grand, but at its core it is simply: **define the base values — colours, spacing, radii, font sizes — centrally and reuse them across the site**.

```css
:root {
  /* Colours */
  --color-primary: #2c3e50;
  --color-accent: #4a90d9;
  --color-bg: #f8f9fa;
  --color-card: #ffffff;
  --color-text: #333333;
  --color-muted: #888888;

  /* Spacing */
  --space-xs: 4px;
  --space-sm: 8px;
  --space-md: 16px;
  --space-lg: 24px;
  --space-xl: 48px;

  /* Radii */
  --radius-sm: 4px;
  --radius-md: 8px;
  --radius-lg: 16px;

  /* Font sizes */
  --font-sm: 0.875rem;
  --font-md: 1rem;
  --font-lg: 1.25rem;
  --font-xl: 1.5rem;
  --font-xxl: 2rem;
}
```

Used consistently, the resulting CSS is very coherent:

```css
h1 { font-size: var(--font-xxl); color: var(--color-primary); margin-bottom: var(--space-lg); }
h2 { font-size: var(--font-xl); color: var(--color-primary); margin-bottom: var(--space-md); }
.card { padding: var(--space-lg); border-radius: var(--radius-md); }
```

## The full CV styling

```css
/* ===== Reset ===== */
* { margin: 0; padding: 0; box-sizing: border-box; }

body {
  font-family: -apple-system, "Segoe UI", "Helvetica Neue", sans-serif;
  font-size: var(--font-md);
  line-height: 1.6;
  color: var(--color-text);
  background: var(--color-bg);
}

/* ===== Layout container ===== */
.container {
  max-width: 900px;
  margin: 0 auto;
  padding: var(--space-xl) var(--space-md);
}

/* ===== Header ===== */
.site-header {
  text-align: center;
  padding: var(--space-xl) 0;
  border-bottom: 2px solid var(--color-accent);
  margin-bottom: var(--space-xl);
}

.site-header h1 {
  font-size: var(--font-xxl);
  color: var(--color-primary);
}

.site-header .title {
  font-size: var(--font-lg);
  color: var(--color-muted);
  margin: var(--space-sm) 0;
}

.social {
  display: flex;
  justify-content: center;
  gap: var(--space-lg);
  margin-top: var(--space-md);
}

.social a {
  color: var(--color-accent);
  text-decoration: none;
}

.social a:hover {
  text-decoration: underline;
}

/* ===== Sections ===== */
section {
  margin-bottom: var(--space-xl);
}

section h2 {
  font-size: var(--font-xl);
  color: var(--color-primary);
  border-left: 4px solid var(--color-accent);
  padding-left: var(--space-md);
  margin-bottom: var(--space-lg);
}

/* ===== Job cards ===== */
.job {
  background: var(--color-card);
  border-radius: var(--radius-md);
  padding: var(--space-lg);
  box-shadow: var(--shadow);
  margin-bottom: var(--space-md);
}

.job h3 {
  font-size: var(--font-lg);
  color: var(--color-primary);
}

.job time {
  display: block;
  font-size: var(--font-sm);
  color: var(--color-muted);
  margin: var(--space-xs) 0 var(--space-sm);
}

/* ===== Footer ===== */
.site-footer {
  text-align: center;
  padding: var(--space-lg) 0;
  border-top: 1px solid #ddd;
  color: var(--color-muted);
  font-size: var(--font-sm);
}
```

Crash site 2: forgetting `box-sizing: border-box`.

```css
* { margin: 0; padding: 0; }
/* box-sizing: border-box is missing */
```

Consequence: an element with `width: 100%` plus `padding: 16px` overflows its parent, because under the default `content-box` the padding is added outside the width. With `box-sizing: border-box` the padding is included inside the width and the layout becomes predictable.

## Summary

- CSS variables (Custom Properties) are defined with `--` and referenced with `var()` — define once and reuse everywhere.
- A design system = centrally managed colours, spacing, radii and font sizes.
- The benefit: change the theme in a few variables and the whole site updates in sync.
- `* { box-sizing: border-box }` is the foundation of a predictable layout — do not forget it.

## In-class exercise

```quiz
type: css
q: Implement this with CSS variables: define --accent as #4a90d9, --radius as 8px and --padding as 24px. Make .card use these variables: white background, a left border radius of --radius, padding of --padding and a 4px solid left border in --accent.
html: |
  <div class="card">Content card</div>
starter: |
  :root {
    --accent: #4a90d9;
    --radius: 8px;
    --padding: 24px;
  }
  .card {
    background: white;
  }
checks:
- getComputedStyle(document.querySelector('.card')).borderRadius === '8px'
- getComputedStyle(document.querySelector('.card')).padding === '24px'
- getComputedStyle(document.querySelector('.card')).borderLeftWidth === '4px'
- getComputedStyle(document.querySelector('.card')).borderLeftStyle === 'solid'
- getComputedStyle(document.querySelector('.card')).borderLeftColor === 'rgb(74, 144, 217)'
hint: border-left is a shorthand property — split it into border-left-width, border-left-style and border-left-color for checking.
explain: CSS variables are referenced through var() to centralise style management and theme switching.
```

## Section quiz

```quiz
type: choice
exam: true
q: Which statement about CSS variables (Custom Properties) is correct?
options:
- CSS variables are defined with the $ symbol
- CSS variables are defined with -- and referenced with the var() function
- CSS variables can only be used in JavaScript
- CSS variables cannot be reassigned inside media queries
answer: 1
explain: CSS variables are defined as --name (usually inside :root) and referenced with var(--name). They can be reassigned inside media queries and support reading and writing from JavaScript.
```
