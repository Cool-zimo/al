# Selectors: Tag, Class and id

> This lesson answers the question: "Exactly which elements will my styles apply to?" Pick accurately and your styles stay maintainable.

## The three basic selectors

```css
/* Tag selector: matches every element of that tag */
p {
  line-height: 1.8;
}

/* Class selector: matches every element carrying this class */
.highlight {
  background-color: yellow;
}

/* id selector: matches exactly one element */
#main-title {
  font-size: 36px;
}
```

Usage:

```html
<h1 id="main-title">Alice's CV</h1>
<p class="highlight">This paragraph needs to stand out</p>
<p>This is an ordinary paragraph</p>
```

## When to use class and when to use id

This is the question beginners ask most often. The test is a practical one:

| Situation | Use |
|---|---|
| Several elements share the same style | **class** |
| An element is unique, with only one on the page | **id** |
| The style may need to be reused | **class** |
| You need an in-page anchor jump (`#xxx`) | id |

A class can be reused, and one element can have several classes; an id may only appear **once** in a page, and one element has only one id.

```html
<p class="intro highlight">Both an introduction and something that needs highlighting</p>
```

Crash site 1: using an id for a general style.

```html
<h1 id="title">Title one</h1>
<h1 id="title">Title two</h1>
```

Consequence: two elements share an id. The HTML specification says ids must be unique. The browser will not throw an error, but JavaScript's `getElementById` will only return the first one, and screen readers and anchor jumps will also pick the first one. The styles still apply to both, but that is "by luck", not "by correctness".

Crash site 2: overusing the tag selector.

```css
p {
  color: blue;
}
```

Consequence: every paragraph on the page turns blue, including the ones you wanted to leave at the default. A tag selector reaches too wide and easily causes "collateral damage". In real projects, class selectors are used more often for precise control.

## Combinations and hierarchy

```css
/* Descendant selector: every p inside an article */
article p {
  color: #444;
}

/* Direct-child selector */
.menu > li {
  list-style: none;
}

/* Several selectors sharing one rule */
h1, h2, h3 {
  font-family: "PingFang SC", sans-serif;
}
```

The difference between `article p` and `.menu > li`: the first selects **every level** of p inside article, while the second selects only the **direct children** li of `.menu`. When Alice writes a navigation menu, `>` lets her control the top-level items precisely without affecting any nested sub-menus.

## Specificity

```css
p { color: black; }          /* 1 point */
.intro { color: blue; }      /* 10 points */
#main { color: red; }        /* 100 points */
```

The higher score wins. When scores tie, the later rule overrides the earlier one.

```html
<p class="intro" id="main" style="color: green;">What colour is this text?</p>
```

The inline `style` has the highest priority, so the text is green. But **do not pile on ids or use `!important` just to override something** - `!important` breaks the specificity rules, and once it is used it becomes very hard to override later, making maintenance painful.

## Summary

- A tag selector reaches widely, a class is reusable, and an id is unique.
- Use a class for shared styles; use an id for a unique element or an anchor jump.
- A descendant selector picks every level; the direct-child selector `>` picks only one level.
- Specificity order: id > class > tag; try not to use `!important`.

## In-class exercise

```quiz
type: css
q: Give elements with the class "note" a background colour of pale yellow, rgb(255, 248, 225), and a text colour of dark brown, rgb(120, 90, 40).
html: |
  <p class="note">This is a note</p>
starter: |
  .note {
  }
checks:
- getComputedStyle(document.querySelector('.note')).backgroundColor === 'rgb(255, 248, 225)'
- getComputedStyle(document.querySelector('.note')).color === 'rgb(120, 90, 40)'
hint: A class selector starts with a full stop; just set the two properties.
explain: .note matches elements carrying the note class and sets the background and text colours separately.
```

```quiz
type: choice
exam: true
q: You want to give every paragraph that "needs to stand out" the same style. Which selector should you use?
options:
- The id selector
- The tag selector p
- The class selector
- The universal selector *
answer: 2
explain: A class selector is reusable, so several elements can share one class. An id must be unique, and a tag selector would apply to every paragraph.
```
