# The Box Model: Every Element Is a Box

> This lesson answers the question: "Why is the width I set not the width I see?" The box model is the most fundamental - and most easily mishandled - part of CSS.

## Four layers, from the inside out

In the browser, every element is a rectangular box made of four layers:

```
┌─────────────────────────┐  ← margin (outside the box)
│  ┌───────────────────┐  │
│  │  ┌─────────────┐  │  │  ← border
│  │  │   content   │  │  │  ← content (the actual text area)
│  │  │  content    │  │  │
│  │  └─────────────┘  │  │
│  │     ↑ padding      │  │  ← padding (between content and border)
│  └───────────────────┘  │
└─────────────────────────┘
```

```css
.box {
  width: 200px;
  padding: 20px;
  border: 2px solid #333;
  margin: 10px;
}
```

By default (`box-sizing: content-box`), the element's **actual occupied width** is:

`width + padding-left + padding-right + border-left + border-right` = `200 + 20 + 20 + 2 + 2` = **244px**

That is why "I set 200px but what I see is wider than 200px".

## box-sizing: border-box changes the calculation

```css
* {
  box-sizing: border-box;
}
```

Once this line is added, `width: 200px` means that **the whole box, including padding and border, adds up to 200px**, and the content area is squeezed down to 176px. This is the de-facto standard of modern development, and almost every project puts this line first.

Crash site 1: without box-sizing, the width makes no sense.

```css
.card {
  width: 100%;
  padding: 20px;
}
```

Consequence: 100% width plus 40px of padding makes the box wider than its parent, producing a horizontal scrollbar. Adding `box-sizing: border-box` solves it.

## Margin collapse (the classic trap)

When two block-level elements sit **next to each other vertically**, their vertical margins **merge into one**, taking the larger of the two values rather than adding up.

```html
<p style="margin-bottom: 30px;">First paragraph</p>
<p style="margin-top: 20px;">Second paragraph</p>
```

You would expect 50px of space between the two paragraphs, but the actual result is **30px**. This is margin collapse.

```css
/* Only margin-bottom takes effect; margin-top has been "collapsed" away */
```

When collapse happens:

- The top and bottom margins of adjacent sibling elements
- The margin of a parent element and the margin of its first or last child

When it does **not** happen:

- Horizontal margins (left and right are added together)
- Margins on floated or absolutely positioned elements
- Children inside a flex or grid layout container

Crash site 2: using margin-top to "push" a child away from its parent.

```html
<div class="parent">
  <p class="child">Some text</p>
</div>
```

```css
.parent { margin-top: 20px; }
.child { margin-top: 30px; }
```

Consequence: you expect the parent to sit 20px from the top and the child to sit another 30px lower inside it. In reality, the parent is "dragged" 30px further down too, because the child's margin collapsed out through the parent. The fix is to use the parent's `padding-top` instead of the child's `margin-top`.

## Summary

- A box has four layers: content, padding, border and margin, from the inside out.
- With the default `content-box`, `width` does not include padding or border, so the result is wider.
- Modern practice: `* { box-sizing: border-box; }`, so width is the total width.
- The vertical margins of adjacent block elements collapse and take the larger value; padding does not collapse.

## In-class exercise

```quiz
type: css
q: Give p a padding of 20px, a 2px solid grey border, rgb(158, 158, 158), and set box-sizing to border-box.
html: |
  <p>Text with a border</p>
starter: |
  p {
  }
checks:
- getComputedStyle(document.querySelector('p')).paddingTop === '20px'
- getComputedStyle(document.querySelector('p')).borderTopWidth === '2px'
- getComputedStyle(document.querySelector('p')).boxSizing === 'border-box'
hint: The three properties are padding, border and box-sizing.
explain: padding sets the inner spacing, border sets the border, and box-sizing changes how width is calculated.
```
