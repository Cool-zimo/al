# Grid basics: the two-dimensional grid system

> This lesson answers the question: "How do I control rows and columns at the same time?" Flex is one-dimensional (it handles one row or one column at a time); Grid is two-dimensional (rows and columns together). They complement each other rather than replace each other.

## The core idea of Grid

A Grid layout divides the container into a grid of **rows and columns**, and its children can be placed precisely in a cell or made to span several cells.

```css
.grid {
  display: grid;
  grid-template-columns: 200px 1fr 200px; /* three cols: fixed 200px, flexible, fixed 200px */
  grid-template-rows: auto 1fr;            /* two rows: content height, flexible */
  gap: 16px;                               /* spacing between rows and columns */
}
```

```html
<div class="grid">
  <header>Header</header>
  <nav>Navigation</nav>
  <main>Main content</main>
  <footer>Footer</footer>
</div>
```

`grid-template-columns` defines the column widths, `grid-template-rows` defines the row heights and `gap` defines the spacing. That is the whole idea.

## The fr unit: share space by ratio

`fr` (fraction) is a Grid-specific unit meaning "one share of the remaining space".

```css
.grid {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr; /* total width split into 4 shares: 1:2:1 */
}
```

The middle column takes half and the two sides take a quarter each. `fr` makes proportional distribution beautifully simple.

## How Grid and Flex divide the work

| Scenario | Use Grid | Use Flex |
|---|---|---|
| The overall page skeleton (header / sidebar / content / footer) | Two-dimensional grid | Not a great fit |
| A row of navigation links | One-dimensional arrangement | A good fit |
| A card grid (fixed number per row) | A good fit | Also works |
| A row where content flows naturally | Not a great fit | A good fit |

The rule of thumb:

- **For the overall structure** → Grid
- **For aligning a set of elements** → Flex
- Nesting the two is the most common combination

```css
/* Outer Grid builds the skeleton */
.page {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-rows: 60px 1fr 40px;
  min-height: 100vh;
}

/* Inner Flex aligns the items */
.header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
```

## gap: no more margin collapse

Grid uses `gap` for uniform spacing, with no need to calculate margins.

```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr); /* three equal columns */
  gap: 20px; /* 20px for both row and column gaps */
}
```

You can also set them separately:

```css
gap: 16px 24px;  /* row gap 16px, column gap 24px */
row-gap: 16px;
column-gap: 24px;
```

Crash site 1: using margin instead of gap between Grid items.

```css
.grid-item {
  margin: 10px; /* not recommended */
}
```

Consequence: the items at the grid container's edges get extra outer margin, leaving a 10px gap between the container and the items, so the layout is no longer tidy. `gap` only creates spacing on the grid lines, keeping the edges clean.

## repeat for concise writing

```css
/* equivalent to 1fr 1fr 1fr 1fr */
grid-template-columns: repeat(4, 1fr);

/* mixed writing */
grid-template-columns: 200px repeat(2, 1fr) 100px; /* 200px, two equal shares, 100px */
```

Crash site 2: Grid items spill past the grid and auto-generate implicit rows.

```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}
```

```html
<div class="grid">
  <div>1</div><div>2</div><div>3</div>
  <div>4</div><div>5</div>  <!-- the 4th wraps to a second row automatically -->
</div>
```

Consequence: the first three occupy the first row, while 4 and 5 automatically create a second row (an implicit row whose height is decided by content). This is not necessarily a bug — often it is exactly what you want. But if you need precise control over row heights, use `grid-template-rows`.

## Summary

- Grid is a two-dimensional layout system that controls rows and columns at once.
- The `fr` unit divides the remaining space by ratio — extremely intuitive.
- Grid is for the overall skeleton; Flex is for aligning a set of elements. Nesting them is standard.
- `gap` gives the grid uniform spacing and is cleaner than margin.
- `repeat()` shortens the syntax for equal columns/rows.

## In-class exercise

```quiz
type: css
q: Make .grid a Grid layout with three equal columns (repeat(3, 1fr)), a row gap of 16px and a column gap of 16px.
html: |
  <div class="grid">
    <div>1</div><div>2</div><div>3</div>
    <div>4</div><div>5</div><div>6</div>
  </div>
starter: |
  .grid {
  }
checks:
- getComputedStyle(document.querySelector('.grid')).display === 'grid'
- getComputedStyle(document.querySelector('.grid')).gridTemplateColumns.split(' ').length === 3
- Math.abs(parseFloat(getComputedStyle(document.querySelector('.grid')).gridTemplateColumns.split(' ')[0]) - parseFloat(getComputedStyle(document.querySelector('.grid')).gridTemplateColumns.split(' ')[1])) < 2
- getComputedStyle(document.querySelector('.grid')).rowGap === '16px'
- getComputedStyle(document.querySelector('.grid')).columnGap === '16px'
hint: display: grid turns on the grid, grid-template-columns defines the columns and gap sets the spacing.
explain: repeat(3, 1fr) creates three equal columns and gap gives the grid uniform spacing.
```
