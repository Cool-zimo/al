# Flex further: direction, wrapping and flexible distribution

> This lesson answers the question: "How do I make Flex items stack vertically, wrap onto a new line or share space by ratio?" `flex-direction`, `flex-wrap` and `flex` cover almost every everyday layout need.

## flex-direction: change the main axis

The default main axis is horizontal (`row`). With `flex-direction` you can flip it to vertical.

```css
.container {
  display: flex;
  flex-direction: column; /* main axis now runs top to bottom */
}
```

There are four values:

| Value | Effect |
|---|---|
| row | Main axis horizontal, left to right (default) |
| row-reverse | Main axis horizontal, right to left |
| column | Main axis vertical, top to bottom |
| column-reverse | Main axis vertical, bottom to top |

Crash site 1: you use `flex-direction: column` and `justify-content` still centres things horizontally.

```css
.container {
  display: flex;
  flex-direction: column;
  justify-content: center; /* now centres vertically */
}
```

This is the **correct understanding** — because the main axis changed, `justify-content` now works along the vertical direction. A lot of people mistakenly believe "justify-content always handles horizontal", but it actually handles the **main axis**, whose direction is decided by `flex-direction`.

## flex-wrap: allow wrapping

The default `flex-wrap: nowrap` keeps every item on one line, compressing them even if they overflow the container. Set it to `wrap` to allow wrapping.

```css
.container {
  display: flex;
  flex-wrap: wrap;
}
```

```html
<div class="container">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
  <div class="item">4</div>
</div>
```

```css
.container { width: 360px; display: flex; flex-wrap: wrap; }
.item { width: 100px; height: 60px; margin: 5px; background: #4a90d9; }
```

The container is 360px wide, and each item is 100px plus 10px of margin, so four will not fit on one line. With wrap, the fourth drops to the second line automatically.

## flex: the heart of flexible distribution

`flex` is shorthand for `flex-grow`, `flex-shrink` and `flex-basis`. The most common value is `flex: 1`.

```css
.sidebar {
  flex: 0 0 200px; /* do not grow, do not shrink, basis 200px */
}
.main {
  flex: 1; /* fill the remaining space */
}
```

Now `.sidebar` stays fixed at 200px while `.main` automatically fills the rest of the width. No matter how wide the page gets, the ratio stays the same.

```html
<div class="layout">
  <aside class="sidebar">Sidebar</aside>
  <section class="main">Main content</section>
</div>
```

```css
.layout { display: flex; height: 300px; }
.sidebar { flex: 0 0 200px; background: #e0f0ff; }
.main { flex: 1; background: #f0f0f0; }
```

Crash site 2: you give both items `flex: 1` but expected one to be fixed and the other flexible.

```css
.item-a { flex: 1; }
.item-b { flex: 1; }
```

Consequence: a and b each take half. If you want only b to be flexible and a to be fixed, write `.item-a { width: 120px; }` and `.item-b { flex: 1; }`.

## The full centring comparison

Let us revisit three centring approaches:

```css
/* Approach A: margin auto — requires a fixed width */
.center-a {
  width: 200px;
  margin: 0 auto;
}

/* Approach B: Flex — no fixed width required */
.center-b {
  display: flex;
  justify-content: center;
  align-items: center;
}

/* Approach C: absolute + transform */
.center-c {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

Flex is the most elegant: it depends on no fixed size, leaves the flow and handles both directions in one container.

## Summary

- `flex-direction` changes the main axis: `row` is the default, `column` is vertical.
- `justify-content` always follows the main axis, so it changes direction when the axis does.
- `flex-wrap: wrap` allows items to move to a new line instead of being compressed.
- `flex: 1` lets an item fill the remaining space; `flex: 0 0 200px` fixes a size.
- Flex centring (the double centre) is the most common and most elegant centring solution.

## In-class exercise

```quiz
type: css
q: Make .container a flex layout with flex-direction: column and justify-content: center, so its three divs stack vertically and centre.
html: |
  <div class="container">
    <div>One</div>
    <div>Two</div>
    <div>Three</div>
  </div>
starter: |
  .container {
  }
checks:
- getComputedStyle(document.querySelector('.container')).display === 'flex'
- getComputedStyle(document.querySelector('.container')).flexDirection === 'column'
- getComputedStyle(document.querySelector('.container')).justifyContent === 'center'
- document.querySelectorAll('.container > div').length === 3
hint: display: flex turns on the flexbox, flex-direction: column makes it vertical and justify-content: center centres things.
explain: Once the main axis is vertical, justify-content: center arranges the children along that vertical direction.
```

## Section quiz

```quiz
type: choice
exam: true
q: Which statement about flex-wrap is correct?
options:
- With flex-wrap: nowrap items automatically wrap to a new line when they overflow
- With flex-wrap: wrap items automatically move to the next line when they overflow
- flex-wrap only works with flex-direction: column
- flex-wrap decides how items align on the main axis
answer: 1
explain: flex-wrap: wrap lets Flex items wrap when there is not enough space; nowrap is the default and compresses items without wrapping. Main-axis alignment is controlled by justify-content.
```
