# rolling: rolling windows and moving averages

> Raw data jumps around too much to show a trend. A rolling window smooths out "the last N days" — and that is exactly what a moving average is.

## A seven-day moving average

```python
import pandas as pd

idx = pd.date_range('2026-09-01', periods=10, freq='D')
revenue = pd.Series([100, 120, 90, 130, 110, 150, 140, 160, 170, 180], index=idx)
```

The daily figures swing wildly. Compute the "7-day mean":

```python
ma7 = revenue.rolling(7).mean()
print(ma7)
```

```
2026-09-01      NaN
2026-09-02      NaN
2026-09-03      NaN
2026-09-04      NaN
2026-09-05      NaN
2026-09-06      NaN
2026-09-07    111.428571
2026-09-08    128.571429
2026-09-09    135.714286
2026-09-10    145.714286
Freq: D, dtype: float64
```

**The first six values are NaN** because there are not yet seven data points. Results start on day seven.

## Syntax

```python
series.rolling(window_size).aggregation()
```

**The window includes the current row plus the N-1 rows before it.**

## min_periods: lowering the bar

```python
ma3 = revenue.rolling(3, min_periods=1).mean()
print(ma3)
```

```
2026-09-01    100.000000
2026-09-02    110.000000
2026-09-03    103.333333
2026-09-04    113.333333
2026-09-05    110.000000
2026-09-06    130.000000
2026-09-07    133.333333
2026-09-08    150.000000
2026-09-09    156.666667
2026-09-10    169.000000
Freq: D, dtype: float64
```

**`min_periods=1` means "even a single data point is enough."** Day one is just its own value.

**Contrast that with the default (min_periods = window size):** six NaNs vs. values all the way through. `min_periods=1` is the usual choice for visual trend lines; keep the default when you need a strict window.

## Crash site: the window produces nothing but NaN

```python
short = pd.Series([10, 20, 30])
print(short.rolling(7).mean())
```

```
0   NaN
1   NaN
2   NaN
dtype: float64
```

**Window 7, data only 3 rows — it can never fill, so everything is NaN.** This is the most common reason a rolling calculation "comes back empty."

**Use `min_periods=1` or shrink the window:**

```python
print(short.rolling(7, min_periods=1).mean())
```

```
0    10.0
1    15.0
2    20.0
dtype: float64
```

## A time-based window: by "days," not "rows"

```python
idx2 = pd.to_datetime(['2026-09-01', '2026-09-02', '2026-09-05', '2026-09-10'])
s2 = pd.Series([10, 20, 30, 40], index=idx2)
```

The data is **unevenly spaced** (a few days are missing). Use `window='3D'` to mean "within the last 3 days":

```python
print(s2.rolling('3D').mean())
```

```
2026-09-01    10.0
2026-09-02    15.0
2026-09-05    30.0
2026-09-10    40.0
```

**The window is measured in calendar time, not row count** — the index must be a DatetimeIndex.

## Other aggregations

```python
r = revenue.rolling(3)
print(r.sum())     # 3-day running total
print(r.max())     # 3-day high
print(r.std())     # 3-day volatility
print(r.count())   # valid entries in the window
```

## expanding: a window that grows from the start

```python
print(revenue.expanding().mean())
```

```
2026-09-01    100.0
2026-09-02    110.0
2026-09-03    103.333333
2026-09-04    110.0
2026-09-05    110.0
...
```

**`expanding` starts at the first row and grows forever.** It is equivalent to `cumsum()/cumcount()`, but accepts any aggregation.

**`rolling` vs `expanding`:**

| | window size | typical use |
|---|---|---|
| `rolling(7)` | fixed 7 rows | 7-day moving average |
| `expanding()` | grows from the start | running / historical mean |

## Crash site: rolling with no aggregation

```python
# WRONG
revenue.rolling(7)
```

```
Rolling object (not a result!)
```

**`rolling` only defines the window** — it needs `.mean()` / `.sum()` etc. to produce output. Like `groupby` and `resample`, it is a two-step call.

## Crash site: center=True "sees the future"

```python
# Default is "look back" (center=False)
look_back = revenue.rolling(3, min_periods=1).mean()
print(look_back.iloc[0])   # 100.0, only day 0 itself
```

**By default the window sits on "this row and earlier"** — the correct behaviour for forecasting (no future data involved).

For a centred, symmetric window:

```python
centred = revenue.rolling(3, center=True, min_periods=1).mean()
print(centred)
```

**`center=True` centres the window on the current row.** Great for smoothing a display chart; **never use it for time-series forecasting**, because it effectively uses future values to describe the present.

## Recap

- **`rolling(N)` is "this row plus the N-1 rows before it"** — pair it with an aggregation
- **The first N-1 rows are NaN by default** — `min_periods=1` relaxes that
- **`window='3D'` opens a calendar-time window** — requires a DatetimeIndex
- **`expanding` grows from the start** — the window keeps getting larger
- **`center=True` touches future data** — avoid it in forecasting
