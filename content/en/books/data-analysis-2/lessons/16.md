# Grouping: split-apply-combine

> The first three chapters were about preparing data. This chapter is where you start asking questions — and the core move is `groupby`.

## Start with a question

You have a sales table and want to know: **how much did each city sell?**

```python
import pandas as pd

df = pd.DataFrame({
    'city': ['London', 'Paris', 'London', 'Paris', 'Berlin'],
    'category': ['peripheral', 'peripheral', 'display', 'display', 'peripheral'],
    'revenue': [100, 200, 150, 300, 90]
})
```

Without groupby you'd filter each city and add it up by hand. **With groupby it's one line:**

```python
print(df.groupby('city')['revenue'].sum())
```

```
city
Paris     500
London    250
Berlin     90
Name: revenue, dtype: int64
```

## The three moves

**groupby stands for split-apply-combine:**

```
original                split                apply            combine
┌──────────┐      ┌──────────┐      ┌──────────┐    ┌──────────┐
│London 100│      │London 100│      │London 250│    │London 250│
│Paris  200│  →   │London 150│  →   │Paris  500│ →  │Paris  500│
│London 150│      ├──────────┤      │Berlin  90 │    │Berlin  90│
│Paris  300│      │Paris  200 │      └──────────┘    └──────────┘
│Berlin  90│      │Paris  300 │
└──────────┘      ├──────────┤
                  │Berlin  90 │
                  └──────────┘
   split             apply sum          combine
```

1. **split**: sort the rows into piles by the values in "city"
2. **apply**: run the same calculation on each pile (here, sum)
3. **combine**: stack the results back into one table

**Once you have those three steps, every groupby variant is just swapping what step 2 does.**

## Two-part syntax

```python
df.groupby('what to group by')['which column'].aggregation()
   └────────┬────────┘ └────┬────┘ └─────┬─────┘
        group key        column        how
```

**The middle part is what people forget** — leave it out and every calculable column gets calculated:

```python
# ✅ revenue only
df.groupby('city')['revenue'].sum()

# every numeric column (the group key is excluded automatically)
df.groupby('city').sum()
```

> 💡 **Get in the habit of naming the column.** Otherwise an unexpected extra price column gets included too.

## Common aggregations

```python
g = df.groupby('city')['revenue']

print(g.sum())        # total
print(g.mean())       # average
print(g.max())        # largest
print(g.min())        # smallest
print(g.count())      # non-null count
print(g.size())       # row count (including nulls)
print(g.std())        # standard deviation
print(g.nunique())    # how many distinct values
```

**`count()` versus `size()`:**

| | Counts | Includes nulls? |
|---|---|---|
| `count()` | non-null values | **No** |
| `size()` | every row in the group | Yes |

With no missing data they're identical. **With gaps `count()` is smaller** — which is exactly the answer to "how much valid data is in this group".

## Several at once: agg

```python
print(df.groupby('city')['revenue'].agg(['sum', 'mean', 'max', 'count']))
```

```
        sum   mean  max  count
city
Paris   500  250.0  300      2
London  250  125.0  150      2
Berlin   90   90.0   90      1
```

**`agg` takes a list** and computes several statistics at once, giving a table (one column per statistic).

## Grouping by several keys

```python
print(df.groupby(['city', 'category'])['revenue'].sum())
```

```
city    category
Paris   peripheral    200
        display       300
London  peripheral    100
        display       150
Berlin  peripheral     90
Name: revenue, dtype: int64
```

**Pass a list for multiple keys.** The result has a two-level index (a MultiIndex).

To turn it into a flat table:

```python
print(df.groupby(['city', 'category'])['revenue'].sum().reset_index())
```

```
     city   category  revenue
0   Paris  peripheral      200
1   Paris     display      300
2  London  peripheral      100
3  London     display      150
4  Berlin  peripheral       90
```

## The group key becomes the index

```python
result = df.groupby('city')['revenue'].sum()
print(result.index)          # Index(['Paris', 'London', 'Berlin'])
print(result['London'])      # 250 — fetch straight by name
```

**By default the group key becomes the row index.** Usually that's convenient (fetch by name).

If you'd rather keep it as a column, use `as_index=False`:

```python
print(df.groupby('city', as_index=False)['revenue'].sum())
```

```
     city  revenue
0   Paris      500
1  London      250
2  Berlin       90
```

**`as_index=False` keeps the group key as a column.** Handier when you plan to keep working on the result (filter it again, merge it, …).

## Sorting the result

```python
print(df.groupby('city')['revenue'].sum().sort_values(ascending=False))
```

**Note this sorts the aggregated values** (revenue), not the city names. groupby sorts by the group key by default.

## See how big each group is

```python
print(df.groupby('city').size())
```

The most common "let me just look" move — **knowing the group size tells you whether the mean is worth trusting.**

## Summary

- **Three steps**: split → apply → combine
- **Two-part syntax**: `groupby(key)[column].how`
- **`count()` excludes nulls, `size()` includes them**
- **The group key becomes the index by default**; `as_index=False` keeps it as a column
- **Multiple keys: pass a list**; the result has a two-level index
