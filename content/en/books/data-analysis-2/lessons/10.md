# Sorting and de-duplicating

> The last two frequent operations: sort_values, drop_duplicates, and the "index travels along" caveat.

## Sorting: sort_values

```python
import pandas as pd

df = pd.DataFrame({
    'name': ['Alice', 'Bob', 'Cara', 'Dan'],
    'age': [18, 19, 20, 17],
    'score': [89.5, 92.0, 78.0, 95.0]
})

print(df.sort_values('score'))                       # ascending (default)
print(df.sort_values('score', ascending=False))      # descending
```

**Ascending by default.** `ascending=False` flips it.

## Sorting returns a new frame

```python
df2 = df.sort_values('score', ascending=False)
print(df.index)      # unchanged: [0, 1, 2, 3]
print(df2.index)     # the new frame: [3, 1, 0, 2]  ← labels travelled
```

**Two points:**

1. **The original is untouched** — use `df = df.sort_values(...)` or `inplace=True`
2. **The index travels with the data** and is not renumbered

## Resetting: reset_index

```python
df2 = df.sort_values('score', ascending=False).reset_index(drop=True)
print(df2.index)     # [0, 1, 2, 3]  ← renumbered
print(df2)
```

> ⚠️ **`drop=True` is the important bit.** Without it the old index becomes a new column (called `index`):

```python
df2 = df.sort_values('score', ascending=False).reset_index()
print(df2.columns)   # ['index', 'name', 'age', 'score']  ← an extra column
```

## Sorting by several columns

```python
df.sort_values(['age', 'score'], ascending=[True, False])
```

**Pass a list:** first by age ascending, then by score descending within ties. `ascending` can be a list too, matched position by position.

## Top N: nlargest / nsmallest

```python
print(df.nlargest(2, 'score'))       # the 2 highest scores
print(df.nsmallest(2, 'score'))      # the 2 lowest
```

**More direct than "sort then take the top N".**

```python
# equivalent, but wordier
df.sort_values('score', ascending=False).head(2)
```

## De-duplicating: drop_duplicates

```python
d = pd.DataFrame({
    'city': ['London', 'London', 'Paris', 'Berlin', 'Paris'],
    'value': [1, 1, 2, 3, 4]
})

print(d.drop_duplicates())
```

```
     city  value
0  London      1
2   Paris      2
3  Berlin      3
4   Paris      4
```

**Note that "Paris" appears twice and both survive** — the values differ, so the rows aren't identical.

## De-duplicating on some columns: subset

```python
print(d.drop_duplicates(subset=['city']))
```

```
     city  value
0  London      1
2   Paris      2
3  Berlin      3
```

**Only the "city" column decides what's a duplicate**, keeping the first row seen for each city.

## Which one to keep

```python
print(d.drop_duplicates(subset=['city'], keep='last'))    # keep the last
print(d.drop_duplicates(subset=['city'], keep=False))     # drop all duplicates
```

| `keep` | Meaning |
|---|---|
| `'first'` (default) | keep the first occurrence |
| `'last'` | keep the last occurrence |
| `False` | drop **every** row involved in a duplicate |

## See the duplicates first: duplicated

```python
print(d.duplicated().sum())                    # fully identical rows
print(d.duplicated(subset=['city']).sum())     # rows with a repeated city
print(d[d.duplicated(subset=['city'], keep=False)])   # list them for inspection
```

**`duplicated()` returns a boolean Series** flagging "this row repeats an earlier one". With `keep=False` you can pull out every duplicate and look at it.

## The classic sort-then-dedupe combination

**"The highest-grossing sale per city":**

```python
sales = pd.DataFrame({
    'city': ['London', 'Paris', 'London', 'Paris', 'Berlin'],
    'revenue': [100, 200, 150, 180, 90]
})

# sort descending first, then de-duplicate by city (first kept = highest)
top = sales.sort_values('revenue', ascending=False).drop_duplicates(subset=['city'])
print(top)
```

```
     city  revenue
1   Paris      200
2  London      150
4  Berlin       90
```

**This "sort then de-duplicate" idiom is extremely useful** — it's the equivalent of "the row holding the max within each group" in SQL.

## Sorting by index: sort_index

```python
df3 = df.sort_values('score', ascending=False)
print(df3.sort_index())      # back to index order
```

After sorting, `sort_index()` restores the original row order.

## Summary

| Need | Write |
|---|---|
| Sort by value | `df.sort_values('col', ascending=False)` |
| Several columns | `df.sort_values(['c1','c2'], ascending=[True,False])` |
| Renumber | `.reset_index(drop=True)` |
| Top N largest | `df.nlargest(N, 'col')` |
| De-duplicate | `df.drop_duplicates()` |
| By column | `df.drop_duplicates(subset=['col'])` |
| Keep the last | `keep='last'` |
| Count duplicates | `df.duplicated().sum()` |
| Sort by index | `df.sort_index()` |
