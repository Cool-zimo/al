# Pivot tables

> If you've used Excel's pivot tables, this is their pandas equivalent. If you haven't, it's essentially "group, then spread into a grid".

## In one sentence

```python
import pandas as pd

df = pd.DataFrame({
    'city': ['London', 'Paris', 'London', 'Paris', 'Berlin'],
    'category': ['peripheral', 'peripheral', 'display', 'display', 'peripheral'],
    'revenue': [100, 200, 150, 300, 90]
})

print(df.pivot_table(index='city', columns='category', values='revenue', aggfunc='sum'))
```

```
category  peripheral  display
city
Paris          200.0    300.0
London         100.0    150.0
Berlin          90.0      NaN
```

**Three arguments, three questions:**

| Argument | Question |
|---|---|
| `index` | what are the **rows**? |
| `columns` | what are the **columns**? |
| `values` | what goes **in the cells**? |
| `aggfunc` | how to compute it (default: mean) |

## What it's equivalent to

That line is exactly the same as:

```python
df.groupby(['city', 'category'])['revenue'].sum().unstack()
```

**pivot_table is a shortcut for groupby + unstack.**

That relationship matters — **when pivot_table confuses you, fall back to doing it in groupby steps where you can see each move.**

## The default is mean

```python
# no aggfunc → mean!
print(df.pivot_table(index='city', columns='category', values='revenue'))
```

> ⚠️ **A real trap**: Excel's pivot tables default to summing; pandas' pivot_table defaults to averaging.
> **If you want a total, write `aggfunc='sum'` explicitly.**

## Filling the gaps: fill_value

```python
print(df.pivot_table(index='city', columns='category', values='revenue',
                     aggfunc='sum', fill_value=0))
```

```
category  peripheral  display
city
Paris            200      300
London           100      150
Berlin            90        0
```

**"Berlin-display" was NaN** (no such sales); `fill_value=0` turns it into 0.

**Whether to fill depends on meaning**: filling revenue with 0 is fine (no sales means zero), but for an *average* it would drag everything down — leaving NaN is more honest there.

## Adding totals: margins

```python
print(df.pivot_table(index='city', columns='category', values='revenue',
                     aggfunc='sum', fill_value=0, margins=True))
```

```
category  peripheral  display   All
city
Paris            200      300   500
London           100      150   250
Berlin            90        0    90
All              390      450   840
```

**`margins=True` adds an "All" row and column** (rename it with `margins_name`).

**Very handy when the table is for someone else to read.**

## Several aggfuncs

```python
print(df.pivot_table(index='city', columns='category', values='revenue',
                     aggfunc=['sum', 'mean']))
```

**A list produces multi-level columns** — one block per statistic.

## Several values

```python
df2 = df.copy()
df2['units'] = [1, 2, 3, 4, 5]

print(df2.pivot_table(index='city', values=['revenue', 'units'], aggfunc='sum'))
```

With no `columns`, this is "group by rows, summarise each column".

## crosstab: counting

**pivot_table aggregates numbers; crosstab counts occurrences.**

```python
print(pd.crosstab(df['city'], df['category']))
```

```
category  peripheral  display
city
Paris              1        1
London             1        1
Berlin             1        0
```

**A cross-tabulation (contingency table)** — how many times each combination occurs.

| | Computes | Cell value |
|---|---|---|
| `pivot_table` | aggregation of a numeric column | revenue, units… |
| `crosstab` | occurrences | counts |

```python
# the relationship
pd.crosstab(df['city'], df['category'])
# is equivalent to
df.pivot_table(index='city', columns='category', aggfunc='size', fill_value=0)
```

**`aggfunc='size'` counts rows.**

## Long and wide, back and forth

**pivot_table goes long → wide**; the reverse is `melt`:

```python
wide = df.pivot_table(index='city', columns='category', values='revenue',
                      aggfunc='sum', fill_value=0).reset_index()
print(wide)
```

```
category     city  peripheral  display
0           Paris         200      300
1          London         100      150
2          Berlin          90        0
```

Back to long:

```python
long = wide.melt(id_vars='city', var_name='category', value_name='revenue')
print(long)
```

```
     city   category  revenue
0   Paris  peripheral      200
1  London  peripheral      100
2  Berlin  peripheral       90
3   Paris     display      300
4  London     display      150
5  Berlin     display        0
```

**`melt`'s arguments:**
- `id_vars`: columns to keep as identifiers
- `var_name`: name for the new column holding the old column names
- `value_name`: name for the new column holding the values

## When to use what

| Situation | Tool |
|---|---|
| Aggregating revenue, averages, … | `pivot_table` |
| Counting occurrences | `crosstab` |
| Long to wide | `pivot_table` / `unstack` |
| Wide to long | `melt` |

## Practice: a sales pivot report

```python
import pandas as pd

df = pd.DataFrame({
    'city': ['London', 'Paris', 'London', 'Paris', 'Berlin', 'Berlin'],
    'category': ['peripheral', 'peripheral', 'display', 'display', 'peripheral', 'audio'],
    'revenue': [100, 200, 150, 300, 90, 120]
})

print("=== pivot table (with totals) ===")
print(df.pivot_table(index='city', columns='category', values='revenue',
                     aggfunc='sum', fill_value=0, margins=True,
                     margins_name='Total'))

print("\n=== occurrences per combination ===")
print(pd.crosstab(df['city'], df['category']))

print("\n=== city totals, sorted ===")
print(df.groupby('city')['revenue'].sum().sort_values(ascending=False))
```

## Summary

- **pivot_table = groupby + unstack**
- **Default is mean, not sum** — write `aggfunc='sum'` for totals
- **`fill_value=0`** fills gaps, **`margins=True`** adds totals
- **crosstab counts**, pivot_table aggregates
- **melt is the reverse** (wide to long)
