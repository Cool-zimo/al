# pivot and pivot_table: standing a long table back up

> `melt` flattens a wide table; `pivot` stands it back up. But pivot has a hard rule — duplicate combinations raise an error on the spot. When that happens, you need `pivot_table`.

## pivot: the three ingredients

```python
import pandas as pd

long = pd.DataFrame({
    'store': ['London', 'London', 'Manchester', 'Manchester'],
    'month': ['Jan', 'Feb', 'Jan', 'Feb'],
    'revenue': [1200, 1500, 900, 1100]
})
```

```python
wide = long.pivot(index='store', columns='month', values='revenue')
print(wide)
```

```
month          Jan   Feb
store
London        1200  1500
Manchester     900  1100
```

**`pivot(index=rows, columns=column_names, values=cell_values)`** — all three are required.

| parameter | purpose |
|---|---|
| `index` | the column that becomes the row index |
| `columns` | the column whose values become column names |
| `values` | the column that fills the cells |

The result is **a DataFrame with a named column index** (the `month` name rides along on the columns).

## Crash site: duplicate combinations raise ValueError

```python
dup = pd.DataFrame({
    'store': ['London', 'London', 'London'],
    'month': ['Jan', 'Jan', 'Feb'],
    'revenue': [1200, 1300, 1500]
})
```

London appears twice in January (1200 and 1300) — the "London + Jan" combination occurs twice.

```python
# WRONG
dup.pivot(index='store', columns='month', values='revenue')
```

```
ValueError: Index contains duplicate entries, cannot reshape
```

**pivot requires every `(index, columns)` pair to be unique.** It has no idea which value to keep, so it errors out.

## pivot_table: aggregate to resolve the clash

```python
result = dup.pivot_table(index='store', columns='month',
                         values='revenue', aggfunc='mean')
print(result)
```

```
month          Jan     Feb
store
London      1250.0  1500.0
```

**`aggfunc='mean'` averages the clashing values** (the mean of 1200 and 1300 is 1250). `aggfunc` can also be `'sum'`, `'max'`, `'count'`, or `'first'`.

**`pivot_table` is the "with-aggregation" version of `pivot`**, built specifically for duplicate-ridden data.

## Other uses of pivot_table

```python
stock = pd.DataFrame({
    'store': ['London', 'London', 'Manchester', 'Manchester', 'Manchester'],
    'category': ['peripheral', 'display', 'peripheral', 'display', 'peripheral'],
    'qty': [10, 5, 8, 6, 4]
})
```

Stock levels by store and category:

```python
print(stock.pivot_table(index='store', columns='category', values='qty', aggfunc='sum'))
```

```
category    display  peripheral
store
London            5           10
Manchester        6           12
```

**Manchester's `peripheral` is 8 + 4 = 12** — aggregated automatically. This is the standard shape for stocktakes and cross-tabs.

## Filling the gaps: fill_value

```python
sparse = pd.DataFrame({
    'store': ['London', 'London', 'Manchester'],
    'category': ['peripheral', 'display', 'peripheral'],
    'qty': [10, 5, 8]
})

print(stock.pivot_table(index='store', columns='category', values='qty',
                        aggfunc='sum', fill_value=0))
```

```
category    display  peripheral
store
London            5           10
Manchester        6           12
```

**Cells with no combination are filled with 0**, not NaN. That matters downstream — NaN is contagious.

## margins: add row and column totals

```python
print(stock.pivot_table(index='store', columns='category', values='qty',
                        aggfunc='sum', margins=True, margins_name='Total'))
```

```
category    display  peripheral  Total
store
London            5           10     15
Manchester        6           12     18
Total            11           22     33
```

**`margins=True` automatically adds row and column totals.** It saves a lot of manual summing when you are building a report.

## crosstab: counting co-occurrences

`pivot_table` aggregates *values*; `crosstab` counts *occurrences*:

```python
orders = pd.DataFrame({
    'store': ['London', 'London', 'London', 'Manchester', 'Manchester'],
    'category': ['peripheral', 'peripheral', 'display', 'peripheral', 'display']
})

freq = pd.crosstab(orders['store'], orders['category'])
print(freq)
```

```
category    display  peripheral
store
London            1           2
Manchester        1           1
```

**Each cell is "how many times it appeared."** Equivalent to `pivot_table(aggfunc='size')`, but shorter to write.

## Crash site: pivot leaves a named column index

```python
r = long.pivot(index='store', columns='month', values='revenue')
print(r.columns)
```

```
Index(['Jan', 'Feb'], dtype='object', name='month')
```

**The columns carry a `name='month'` along with them.** Fetching `r['Jan']` works fine, but if you later use `r.columns.tolist()` as a plain list, that name can surprise your assertions or comparisons.

**`reset_index()` flattens it back into an ordinary table:**

```python
print(r.reset_index())
```

```
month       store   Jan   Feb
0       London  1200  1500
1  Manchester   900  1100
```

## Recap

- **pivot's three ingredients:** index, columns, values — and the combinations must be unique
- **`pivot_table` adds `aggfunc`** to handle duplicate combinations
- **`fill_value=0`** turns missing cells into 0, avoiding NaN contamination
- **`margins=True`** adds row and column totals automatically
- **`crosstab` counts co-occurrences**, the size-based equivalent of `pivot_table`
