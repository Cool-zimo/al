# DataFrame: a table

> Several Series together make a DataFrame. This lesson covers building one and the most common ways to do it.

## From a dictionary (most common)

```python
import pandas as pd

df = pd.DataFrame({
    'name': ['Alice', 'Bob', 'Cara'],
    'age': [18, 19, 20],
    'score': [89.5, 92.0, 78.0]
})
print(df)
```

```
    name  age  score
0  Alice   18   89.5
1    Bob   19   92.0
2   Cara   20   78.0
```

**Dictionary keys become column names; values become the column data.** The `0 1 2` down the left is the **row index** (0-based by default).

## From a list of lists

```python
data = [['Alice', 18, 89.5],
        ['Bob', 19, 92.0],
        ['Cara', 20, 78.0]]

df = pd.DataFrame(data, columns=['name', 'age', 'score'])
print(df)
```

**Here you must supply `columns` yourself**, or the columns get named 0, 1, 2.

> ⚠️ If one row mixes types (age written as `'18'`), that whole column becomes object. When building from lists, **keep each column type-consistent**.

## From a NumPy array

```python
import numpy as np

arr = np.arange(12).reshape(4, 3)
df = pd.DataFrame(arr, columns=['A', 'B', 'C'])
print(df)
```

This pairs naturally with *Data Analysis 1*: compute the matrix in NumPy, then wrap it in a DataFrame with names.

## Setting the row index

```python
df = pd.DataFrame({
    'units': [120, 500, 30],
    'price': [199, 89, 1299]
}, index=['Keyboard', 'Mouse', 'Monitor'])

print(df)
print(df.index)        # Index(['Keyboard', 'Mouse', 'Monitor'])
```

**Product names as the row index** means `df.loc['Mouse']` later fetches that whole row.

## Three core attributes

```python
print(df.shape)      # (3, 2)   rows, columns
print(df.columns)    # Index(['units', 'price'])
print(df.index)      # Index(['Keyboard', 'Mouse', 'Monitor'])
```

**`shape`, `columns` and `index` are the three you'll print constantly.** With any unfamiliar table, print these first.

## A quick look

```python
print(df.head(2))        # first 2 rows (5 by default)
print(df.tail(2))        # last 2 rows
print(df.info())         # column names, non-null counts, dtypes
print(df.describe())     # statistics for numeric columns
```

**`info()` and `describe()` are the standard opening moves with new data:**

```python
df = pd.DataFrame({
    'name': ['Alice', 'Bob', 'Cara'],
    'score': [89.5, 92.0, 78.0]
})
print(df.describe())
```

```
          score
count  3.000000
mean  86.500000
std    7.466592
min   78.000000
25%   83.750000
50%   89.500000
75%   90.750000
max   92.000000
```

**`describe()` only covers numeric columns** — text (object) columns are skipped. This instantly shows how many rows there are, the mean, and whether any min or max looks absurd.

## One column = one Series

```python
print(df['score'])          # a Series
print(type(df['score']))    # <class 'pandas.core.series.Series'>
```

**For several columns use double brackets** (a list inside):

```python
print(df[['name', 'score']])   # a DataFrame (two columns)
print(type(df[['name', 'score']]))
```

> ⚠️ **Single brackets → Series; double brackets → DataFrame.** This matters later: a DataFrame has `.columns` and supports multi-column work; a Series doesn't.

## Adding a column

Three equivalent styles:

```python
df['grade'] = ['A', 'A', 'B']                  # a list directly
df['passed'] = df['score'] >= 60               # derived from another column
df['rank'] = df['score'].rank(ascending=False) # computed by a method

print(df)
```

**`df['new_name'] = ...` adds a column.** If the name already exists, it overwrites.

## Removing things

```python
df2 = df.drop(columns=['passed'])    # drop a column; returns a new frame
df3 = df.drop(index=[0])             # drop a row

# to modify in place
df.drop(columns=['passed'], inplace=True)
```

> ⚠️ **Most pandas operations return a new frame and leave the original alone.** Either assign back (`df = df.drop(...)`) or pass `inplace=True`. This confuses nearly everyone at first.

## A DataFrame is a dictionary of Series

Once that clicks, a lot follows naturally:

```python
for col in df.columns:
    print(col, '→', df[col].dtype)

print('score' in df.columns)     # True
```
