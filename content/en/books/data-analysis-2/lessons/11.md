# NaN and None

> Real data always has gaps. This lesson explains what "empty" actually is in pandas — and one counter-intuitive property that silently breaks code if you don't know it.

## A counter-intuitive fact first

```python
import numpy as np

print(np.nan == np.nan)      # False  ← not equal to itself!
print(np.nan is np.nan)      # True
```

**NaN (Not a Number) isn't equal to anything, including itself.**

That's the IEEE 754 floating-point definition. So **never test for missing with `==`**:

```python
# ❌ always False — you'll find nothing
df[df['score'] == np.nan]

# ✅ correct
df[df['score'].isna()]
```

## Two kinds of "empty" in pandas

| | What it is | Where it shows up |
|---|---|---|
| **`NaN`** | "not a number" in floating point | numeric columns |
| **`None`** | Python's null object | text columns |

```python
import pandas as pd
import numpy as np

s = pd.Series([1, np.nan, None])
print(s)
print(s.dtype)          # float64
print(s.tolist())       # [1.0, nan, nan]
```

**Note: inside a numeric Series, `None` is converted to `NaN`.** pandas unifies them so each column keeps one type.

```python
s2 = pd.Series(['x', None])
print(s2.dtype)         # object
print(s2.tolist())      # ['x', None]  ← None survives in a text column
```

## Use isna / notna for both

**Don't worry whether it's NaN or None — `isna()` catches both:**

```python
print(s.isna())         # [False, True, True]
print(s.notna())        # [True, False, False]
```

| Need | Write |
|---|---|
| Any gaps in this column? | `df['col'].isna().any()` |
| How many gaps | `df['col'].isna().sum()` |
| Gaps per column | `df.isna().sum()` |
| Gaps in the whole frame | `df.isna().sum().sum()` |
| Missing ratio | `df.isna().mean()` |
| Rows with gaps | `df[df['col'].isna()]` |
| Rows without gaps | `df[df['col'].notna()]` |

**Avoid `isnull` / `notnull`** — they're aliases with identical behaviour, but `isna` is the modern name.

## Where gaps come from

Three usual sources:

```python
# 1. pandas recognises them on read (empty cells, NA, N/A, null …)
df = pd.read_csv('data.csv')        # empty cell → NaN

# 2. arithmetic produces them
df['per_head'] = df['total'] / df['people']                          # divide by zero → inf, not NaN
df['per_head'] = df['total'] / df['people'].replace(0, np.nan)      # make 0 a NaN first

# 3. misaligned labels produce them (lesson 1)
a = pd.Series([1,2,3], index=['x','y','z'])
b = pd.Series([10,20], index=['x','y'])
print((a + b)['z'])     # nan ← no matching label
```

**"Misalignment produces NaN" is the sneakiest**, because it doesn't raise — it just quietly creates gaps.

## An important side effect: integer columns become floats

```python
d = pd.DataFrame({'qty': [1, 2, np.nan]})
print(d['qty'].dtype)      # float64  ← not int64!
print(d['qty'].tolist())   # [1.0, 2.0, nan]
```

**As soon as a NaN enters an integer column, it's forced to float64** (NaN can only be represented in floating point).

The consequence:

```python
# ❌ raises: Cannot convert non-finite values (NA or inf) to integer
d['qty'].astype(int)

# ✅ fill first, then convert
d['qty'].fillna(0).astype(int)

# ✅ or use the nullable integer type (keeps the gap)
d['qty'].astype('Int64')     # note the capital I
```

**`Int64` (capital I) is pandas' nullable integer type**, holding integers and missing values at once. Lesson 13 covers it properly.

## pandas statistics skip gaps by default

```python
s = pd.Series([1, np.nan, 3])
print(s.sum())      # 4.0   ← NaN skipped
print(s.mean())     # 2.0   ← divisor is 2, not 3
```

**This differs from NumPy:**

```python
import numpy as np
print(np.sum([1, np.nan, 3]))     # nan !
```

NumPy needs `np.nansum()` / `np.nanmean()`; pandas skips automatically. **That's convenient — but it also means:**

> ⚠️ **Stay aware of the skipping itself.** If a column is 90% empty, the mean is computed from the remaining 10% — the number looks fine but represents almost nothing. **Check the missing ratio before you trust a statistic.**

```python
print(df['col'].isna().mean())      # missing ratio
print(df['col'].count())            # non-null count (more trustworthy than len())
```

## A worked example

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    'name': ['Alice', 'Bob', 'Cara', 'Dan'],
    'maths': [80, 95, np.nan, 70],
    'science': [90, np.nan, 85, 75],
    'english': [85, 88, np.nan, 92]
})

print("=== gaps per column ===")
print(df.isna().sum())

print("\n=== missing ratio ===")
print((df.isna().mean() * 100).round(1))

print("\n=== rows with any gap ===")
print(df[df.isna().any(axis=1)])

print("\n=== subject averages (gaps skipped) ===")
print(df[['maths','science','english']].mean())
```

**`df.isna().any(axis=1)`** is the standard way to pull out "rows where any column is empty" — `axis=1` means check across the columns.

## Summary

- **NaN isn't equal to itself** — test for missing only with `isna()` / `notna()`
- **None becomes NaN in numeric columns** — pandas keeps one type per column
- **Integer columns with a NaN become float64** — fill before converting to int, or use `Int64`
- **Statistics skip gaps by default** — check the missing ratio before trusting them
- Three sources: reading files, arithmetic, and misaligned labels
