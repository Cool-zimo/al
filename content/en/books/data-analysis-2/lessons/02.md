# Series: a labelled column

> Series is pandas' smallest unit. Understand it and a DataFrame is just "several Series together".

## Creating one

```python
import pandas as pd

s = pd.Series([10, 20, 30, 40])
print(s)
```

```
0    10
1    20
2    30
3    40
dtype: int64
```

Two columns of output: the **index** on the left, the **values** on the right. With no index given, numbering starts at 0.

## A custom index

**This is the point of a Series** — the index doesn't have to be numbers:

```python
s = pd.Series([10, 20, 30], index=['London', 'Paris', 'Berlin'], name='units')
print(s)
print("name:", s.name)
```

```
London    10
Paris     20
Berlin    30
Name: units, dtype: int64
```

Now you can fetch **by name** rather than by "which one":

```python
print(s['Paris'])      # 20  ← by label
print(s.iloc[1])       # 20  ← by position
```

> ⚠️ **The difference between `s['Paris']` and `s.iloc[1]` is the most confusing thing in pandas**; the next chapter treats it properly. For now: **square brackets take labels, `.iloc[]` takes positions.**

## Three attributes

```python
print(s.values)     # [10 20 30]  ← an ndarray
print(s.index)      # Index(['London', 'Paris', 'Berlin'], dtype='object')
print(s.dtype)      # int64
```

**`s.values` is a NumPy array** — further proof that pandas sits on NumPy.

```python
import numpy as np
print(type(s.values))          # <class 'numpy.ndarray'>
print(s.values.mean())         # NumPy methods work directly
```

## Arithmetic aligns by index

**When two Series combine, pandas aligns by index — not by position:**

```python
a = pd.Series([1, 2, 3], index=['x', 'y', 'z'])
b = pd.Series([10, 20, 30], index=['z', 'y', 'x'])    # note: reversed

print(a + b)
```

```
x    31    ← a's x (1) + b's x (30)
y    22    ← a's y (2) + b's y (20)
z    13    ← a's z (3) + b's z (10)
```

**pandas pairs up labels first, then computes.** That's completely different from NumPy, which would give `1+10, 2+20, 3+30`.

**This is one of pandas' most important features — and one of its easiest bugs:**

```python
a = pd.Series([1, 2, 3], index=['x', 'y', 'z'])
b = pd.Series([10, 20], index=['x', 'y'])     # no z

print(a + b)
```

```
x    11.0
y    22.0
z     NaN    ← unmatched labels become NaN
```

**Labels that don't match produce NaN.** No error — just a silent gap, which is nasty to debug.

## Arithmetic with scalars

Broadcasting, just like NumPy:

```python
print(s * 2)          # everything doubled
print(s > 15)         # a boolean Series
print(s[s > 15])      # filter with the boolean Series
```

```
London    False
Paris      True
Berlin     True
dtype: bool

Paris     20
Berlin    30
dtype: int64
```

**A boolean Series works as a filter** — the same idea as NumPy's boolean indexing.

## Useful methods

```python
print(s.sum(), s.mean(), s.max(), s.min())
print(s.idxmax())       # the label of the maximum ← very handy
print(s.value_counts()) # how often each value appears
print(s.sort_values(ascending=False))
```

**`idxmax()` returns a label, not a position.** Carrying on from the last lesson:

```python
print(f"top city: {s.idxmax()}, with {s.max()}")
# top city: Berlin, with 30
```

`idxmax` / `idxmin` are ideal for "who came first" — more natural than `argmax` (which gives a position).

## From a dictionary

The keys become the index:

```python
d = {'London': 10, 'Paris': 20, 'Berlin': 30}
s = pd.Series(d)
print(s)
```

One of the most common ways to build one.

## Missing values

```python
import numpy as np
s = pd.Series([1, np.nan, 3])
print(s)
print("any gaps?", s.isna().any())
print("mean:", s.mean())        # 2.0 — NaN skipped
```

**Note that `s.mean()` skips the NaN and gives 2.0.** In NumPy, `arr.mean()` would give nan and you'd need `np.nanmean()`.

> 💡 First place pandas saves you mental effort: **statistics skip missing values by default** — no need to remember two versions of every function.
