# Multi-level indexes and reshaping

> Grouping by several keys produces a "two-level index". This lesson is about living with it — a spot where many people get stuck.

## What it looks like

```python
import pandas as pd

df = pd.DataFrame({
    'city': ['London', 'Paris', 'London', 'Paris', 'Berlin'],
    'category': ['peripheral', 'peripheral', 'display', 'display', 'peripheral'],
    'revenue': [100, 200, 150, 300, 90]
})

r = df.groupby(['city', 'category'])['revenue'].sum()
print(r)
```

```
city    category
Paris   peripheral    200
        display       300
London  peripheral    100
        display       150
Berlin  peripheral     90
Name: revenue, dtype: int64
```

**Note "Paris" appears only once — the blank below it means "same as above".** That's a pandas display optimisation, **not a missing value**.

```python
print(r.index)
# MultiIndex([('Paris', 'peripheral'), ('Paris', 'display'), ('London', 'peripheral'), ...])
```

## Two ways to fetch a value

```python
# as a tuple
print(r[('Paris', 'display')])       # 300

# level by level (clearer)
print(r['Paris'])                    # everything under Paris
print(r['Paris']['display'])         # 300
```

**Outer level first, then inner** — like peeling an onion.

## Back to a flat table: reset_index

```python
print(r.reset_index())
```

```
     city   category  revenue
0   Paris  peripheral      200
1   Paris     display      300
2  London  peripheral      100
3  London     display      150
4  Berlin  peripheral       90
```

**`reset_index()` turns the index levels back into ordinary columns** — the standard flattening move.

> ⚠️ If you're about to write a file or merge, you almost always want `reset_index()` first. A table with a MultiIndex is painful to read once exported.

## Swapping levels: swaplevel

```python
print(r.swaplevel())
```

```
category    city
peripheral  Paris     200
display     Paris     300
peripheral  London    100
display     London    150
peripheral  Berlin     90
```

**Outer becomes inner and vice versa.**

## Sorting by a level: sort_index

```python
print(r.sort_index(level='city'))
```

You can also control it at group time:

```python
df.groupby(['city', 'category'], sort=True)['revenue'].sum()
```

## unstack: turn the inner level into columns

**The most useful one** — it turns a long table into a wide one:

```python
print(r.unstack())
```

```
category  peripheral  display
city
Paris          200.0    300.0
London         100.0    150.0
Berlin          90.0      NaN
```

**The inner level ("category") became columns; the outer ("city") stays as rows.**

**Note "Berlin-display" is NaN** — Berlin sold no displays in this data. That's the truth, not a bug.

Fill it with `fill_value`:

```python
print(r.unstack(fill_value=0))
```

```
category  peripheral  display
city
Paris            200      300
London           100      150
Berlin            90        0
```

## stack: the reverse, columns back to an index

```python
wide = r.unstack()
print(wide.stack())
```

**`unstack` and `stack` are inverses.**

| Operation | Effect |
|---|---|
| `unstack()` | inner index → columns (long to wide) |
| `stack()` | columns → inner index (wide to long) |

## Which to use when

**Long format**: one observation per row, group keys live in columns

```
city    category   revenue
Paris   peripheral     200
Paris   display        300
```

**Wide format**: one dimension becomes the column headers

```
category  peripheral  display
city
Paris            200      300
```

| Situation | Better |
|---|---|
| Further analysis, filtering, grouping | **long** |
| Showing people, reports, charts | **wide** |

**Most pandas operations prefer long**, so `unstack` is usually the last step (for presentation).

## Slicing one level: xs

```python
print(r.xs('peripheral', level='category'))
```

```
city
Paris     200
London    100
Berlin     90
```

**`xs` cuts across at one value of one level**, giving you the peripheral figures for every city.

## Naming the levels

```python
r.index.names = ['city', 'category']
print(r.index.names)      # ['city', 'category']
```

You can also name things during aggregation:

```python
df.groupby(['city', 'category']).agg(total=('revenue','sum'), orders=('revenue','count'))
```

## Practice: a layered report

```python
import pandas as pd

df = pd.DataFrame({
    'city': ['London', 'Paris', 'London', 'Paris', 'Berlin', 'Berlin'],
    'category': ['peripheral', 'peripheral', 'display', 'display', 'peripheral', 'audio'],
    'revenue': [100, 200, 150, 300, 90, 120]
})

# 1. group by two keys
r = df.groupby(['city', 'category'])['revenue'].sum()

print("=== long ===")
print(r)

print("\n=== wide (unstack) ===")
print(r.unstack(fill_value=0))

print("\n=== flattened ===")
flat = r.reset_index()
print(flat)

print("\n=== peripherals only ===")
print(r.xs('peripheral', level='category'))
```

## Summary

| Need | Write |
|---|---|
| Back to a flat table | `.reset_index()` |
| Swap levels | `.swaplevel()` |
| Sort by level | `.sort_index(level='name')` |
| Long to wide | `.unstack(fill_value=0)` |
| Wide to long | `.stack()` |
| Slice one level | `.xs('value', level='name')` |
| Fetch by level | `r['outer']['inner']` |
