# transform and filter

> groupby usually returns something *shorter* than the original (one row per group). Sometimes you want the same length back — that's `transform`.

## Where the need comes from

```python
import pandas as pd

df = pd.DataFrame({
    'city': ['London', 'Paris', 'London', 'Paris', 'Berlin'],
    'revenue': [100, 200, 150, 300, 90]
})

# grouped sum → 3 rows
print(df.groupby('city')['revenue'].sum())
```

```
city
Paris     500
London    250
Berlin     90
```

**But what if you want to add a "this city's total" column to the original?** You need 5 rows, not 3.

## transform: same length as the original

```python
df['city_total'] = df.groupby('city')['revenue'].transform('sum')
print(df)
```

```
     city  revenue  city_total
0  London      100         250
1   Paris      200         500
2  London      150         250
3   Paris      300         500
4   Berlin       90          90
```

**`transform` broadcasts the aggregate back onto every row** — each row in a group gets the same value.

**Compare:**

| | Rows returned | Use when |
|---|---|---|
| `groupby().sum()` | one per group (3) | you want a summary |
| `groupby().transform('sum')` | same as original (5) | you want a new column |

## The classic use: percentages

```python
df['city_total'] = df.groupby('city')['revenue'].transform('sum')
df['share'] = (df['revenue'] / df['city_total'] * 100).round(1)
print(df)
```

```
     city  revenue  city_total  share
0  London      100         250   40.0
1   Paris      200         500   40.0
2  London      150         250   60.0
3   Paris      300         500   60.0
4   Berlin       90          90  100.0
```

**"What share of its group is this row"** — extremely common in reports, and one line with transform.

## Another classic: compare against the group mean

```python
df['city_mean'] = df.groupby('city')['revenue'].transform('mean')
df['above_mean'] = df['revenue'] > df['city_mean']
print(df)
```

**"Is this sale above or below its city's average"** — another textbook transform case.

You can also measure the gap:

```python
df['gap'] = df['revenue'] - df.groupby('city')['revenue'].transform('mean')
```

## What transform accepts

```python
df.groupby('city')['revenue'].transform('sum')      # as a string
df.groupby('city')['revenue'].transform(sum)         # as a function
df.groupby('city')['revenue'].transform('mean')
df.groupby('city')['revenue'].transform(lambda x: x.max() - x.min())   # custom
```

**Everything common works.** With a custom function, `x` is the Series for that group.

## filter: keep or drop whole groups

**transform adds a column; filter decides whether a whole group stays.**

```python
# keep only cities whose total revenue exceeds 200 (whole group)
result = df.groupby('city').filter(lambda g: g['revenue'].sum() > 200)
print(result)
```

```
     city  revenue  city_total  share
1   Paris      200         500   40.0
3   Paris      300         500   60.0
```

**Note: the `g` in filter is a sub-DataFrame** (the group's complete rows). You return True or False to keep or drop the whole group.

```python
# keep cities with at least 2 orders
df.groupby('city').filter(lambda g: len(g) >= 2)

# keep cities whose average revenue exceeds 100
df.groupby('city').filter(lambda g: g['revenue'].mean() > 100)
```

## The three side by side

| Method | Returns | Rows | Typical use |
|---|---|---|---|
| `.sum()` / `.agg()` | one value per group | **shorter** | summary reports |
| `.transform()` | a value per row | **unchanged** | add a group-level column |
| `.filter()` | a subset of rows | **shorter** (whole groups) | filter by group property |

**How to remember:**
- want to **see** a summary → aggregate
- want to **add** a column → transform
- want to **drop** groups → filter

## Practice: adding analysis columns

```python
import pandas as pd

df = pd.DataFrame({
    'city': ['London', 'Paris', 'London', 'Paris', 'Berlin', 'Berlin'],
    'category': ['peripheral', 'peripheral', 'display', 'display', 'peripheral', 'audio'],
    'revenue': [100, 200, 150, 300, 90, 120]
})

# 1. each city's total (transform keeps the row count)
df['city_total'] = df.groupby('city')['revenue'].transform('sum')

# 2. each row's share of its city
df['city_share'] = (df['revenue'] / df['city_total'] * 100).round(1)

# 3. each category's mean
df['category_mean'] = df.groupby('category')['revenue'].transform('mean')

# 4. above the city average?
df['above_mean'] = df['revenue'] > df.groupby('city')['revenue'].transform('mean')

print(df)
print()
print("summary by city:")
print(df.groupby('city')['revenue'].agg(['sum', 'mean', 'count']))
```

**One pass gives you both the detail rows and the group-level measures** — that's the value of transform.
