# resample: rebucketing data by time frequency

> Daily data is too noisy; monthly trends are clearer. `resample` is the standard tool for regrouping "daily" data into "monthly," "weekly," or any other time bucket.

## From days to months

```python
import pandas as pd

idx = pd.date_range('2026-01-01', periods=90, freq='D')
df = pd.DataFrame({'date': idx, 'revenue': range(90)})
df = df.set_index('date')
```

90 days of daily figures, and we want "total per month":

```python
monthly = df['revenue'].resample('ME').sum()
print(monthly)
```

```
2026-01-31    465
2026-02-28   1246
2026-03-31   2826
Freq: M, Name: revenue, dtype: int64
```

**90 rows collapsed into 3.** The index now lands on the last day of each month.

## Syntax: used like groupby

```python
df.resample('frequency').aggregation()
```

**`resample` is "groupby by time."** So it is followed by the same `sum`, `mean`, `max` functions you already know.

Common frequency aliases:

| alias | meaning |
|---|---|
| `D` | day |
| `W` | week |
| `ME` | month end (use this — `M` is deprecated since pandas 2.2) |
| `MS` | month start |
| `QE` | quarter end |
| `YE` | year end |

**`ME` vs `MS`:** `ME` labels each bucket with the last day of the month, `MS` with the first.

```python
print(df['revenue'].resample('MS').sum().head(2))
```

```
2026-01-01    465
2026-02-01   1246
Freq: MS, Name: revenue, dtype: int64
```

## Downsampling vs. upsampling

**Downsampling** is high → low frequency (day → month), and needs aggregation.

```python
daily = pd.DataFrame({'v': [1, 2, 3]}, index=pd.date_range('2026-01-01', periods=3))
```

**Upsampling** is low → high frequency (month → day), and needs filling.

```python
monthly_idx = pd.date_range('2026-01-01', periods=2, freq='ME')
monthly = pd.DataFrame({'v': [100, 200]}, index=monthly_idx)
daily_up = monthly.resample('D').ffill()
print(len(daily_up))   # 60-ish (January's 31 days + February's expansion)
```

**Upsampling creates the new index but leaves the values as NaN** — you must pair it with `ffill()` (forward fill) or `bfill()` (backward fill).

## Crash site: resample with no aggregation

```python
df2 = pd.DataFrame({'v': [1, 2, 3]},
                   index=pd.date_range('2026-01-01', periods=3))
```

```python
# WRONG
df2.resample('ME')
```

```
DatetimeIndexResampler object (not a result!)
```

**`resample` does not compute anything by itself** — it must be followed by `.sum()`, `.mean()`, etc.

The correct form:

```python
print(df2['v'].resample('ME').sum())
```

## asfreq: change the frequency without aggregating

```python
sparse = pd.DataFrame({'v': [10, 20, 30]},
                      index=pd.to_datetime(['2026-01-01', '2026-01-03', '2026-01-05']))
```

```python
print(sparse['v'].asfreq('D'))
```

```
2026-01-01    10.0
2026-01-02     NaN
2026-01-03    20.0
2026-01-04     NaN
2026-01-05    30.0
Freq: D, Name: v, dtype: float64
```

**`asfreq` only realigns the index to the new frequency, filling gaps with NaN. It does not aggregate.**

Compare with `resample`:

```python
print(sparse['v'].resample('D').mean())
```

The result looks the same (at most one value per day). **But the semantics differ:** `resample` means "group by frequency then aggregate"; `asfreq` means "realign to frequency."

**When you need to fill values, use `asfreq` + `ffill`:**

```python
print(sparse['v'].asfreq('D').ffill())
```

```
2026-01-01    10
2026-01-02    10
2026-01-03    20
2026-01-04    20
2026-01-05    30
Freq: D, Name: v, dtype: int64
```

## Crash site: the index is not datetime

```python
bad = pd.DataFrame({'date': ['2026-01-01', '2026-01-02'], 'v': [1, 2]})
bad = bad.set_index('date')

# WRONG
bad['v'].resample('ME').sum()
```

```
TypeError: Only valid with DatetimeIndex, TimedeltaIndex or PeriodIndex...
```

**`resample` requires a DatetimeIndex.** Forgetting `to_datetime` is the single most common cause of this error.

```python
# Fix
bad.index = pd.to_datetime(bad.index)
print(bad['v'].resample('ME').sum())
```

## Aggregating multiple columns at once

```python
multi = pd.DataFrame({
    'revenue': [100, 200, 150],
    'cost': [60, 120, 80]
}, index=pd.date_range('2026-01-01', periods=3))

print(multi.resample('ME').sum())
```

```
            revenue  cost
date
2026-01-31       450   260
```

**Resample the whole DataFrame and every numeric column gets aggregated.**

## Recap

- **`resample` is "groupby by time"** — always pair it with an aggregation
- **Downsampling (day→month) aggregates; upsampling (month→day) fills**
- **`ME` for month end, `MS` for month start** — and use `'ME'`, not `'M'` (pandas 2.2+)
- **`asfreq` only realigns the frequency and does not aggregate** — gaps become NaN
- **The index must be a DatetimeIndex**, or it errors out
