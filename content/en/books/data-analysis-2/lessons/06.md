# Columns and rows

> Chapter 1 said a DataFrame is "a dictionary of Series". This lesson covers getting things out of it — and one counter-intuitive rule.

## One column

```python
import pandas as pd

df = pd.DataFrame({
    'name': ['Alice', 'Bob', 'Cara', 'Dan'],
    'age': [18, 19, 20, 17],
    'score': [89.5, 92.0, 78.0, 95.0]
})

print(df['score'])
```

```
0    89.5
1    92.0
2    78.0
3    95.0
Name: score, dtype: float64
```

You get a **Series**. Dot notation works too (with limits):

```python
print(df.score)      # same as df['score']
```

> ⚠️ **Dot notation only works when the name is a valid identifier.** With spaces, punctuation, or names clashing with attributes/methods, `df.score` fails or misbehaves. **Prefer square brackets.**

## Several columns: double brackets

```python
print(df[['name', 'score']])
```

```
    name  score
0  Alice   89.5
1    Bob   92.0
2   Cara   78.0
3    Dan   95.0
```

**There's a list inside**, so you get a DataFrame.

> 💡 **Single brackets give one column (a Series); double brackets give columns (a DataFrame).** Even with one name, `df[['score']]` is a DataFrame, not a Series.

## Rows: two routes

### Slicing (by position)

```python
print(df[0:2])      # first 2 rows
```

```
    name  age  score
0  Alice   18   89.5
1    Bob   19   92.0
```

**Slicing selects rows**, and like Python lists it **excludes the end**.

### loc / iloc (recommended)

```python
print(df.loc[0])      # the row with label 0
print(df.iloc[0])     # the row at position 0
```

With an index of 0, 1, 2 these look identical — **but the rules are completely different**. Next lesson.

## One counter-intuitive rule

**What you put inside `df[...]` decides whether it selects columns or rows:**

| Write | Selects |
|---|---|
| `df['score']` | **a column** (by name) |
| `df[['name','score']]` | **columns** (a list) |
| `df[0:2]` | **rows** (a slice) |
| `df[boolean Series]` | **rows** (a filter) |

**Check the trap:**

```python
d = pd.DataFrame({'v': [10, 20, 30]})
print(d.columns)     # ['v']
print(d.index)       # [0, 1, 2]

print(d[0:2])        # ✅ rows — it's a slice
print(d[1])          # ❌ KeyError: 1
```

**`d[1]` raises**, because brackets are treated as "fetch the column named 1", and there is no such column.

> ⚠️ **That's the whole story behind "I wanted row 1, wrote df[1], got an error."** Use `df.iloc[1]` or the slice `df[1:2]`.

Conversely, if the **columns are themselves numbered**:

```python
d2 = pd.DataFrame({0: ['a', 'b'], 1: ['c', 'd']})
print(d2[0])         # ✅ the column named 0
```

## What a single row gives you

```python
row = df.iloc[0]
print(type(row))         # Series
print(row)
```

```
name     Alice
age         18
score     89.5
Name: 0, dtype: object
```

**One row comes back as a Series** (the row became a Series whose index is the column names).

There's a type trap here:

```python
# Case A: the frame has a text column
row = df.iloc[0]
print(row['age'], type(row['age']))     # 18  <class 'numpy.int64'>

# Case B: all-numeric frame
df2 = df.set_index('name')
row2 = df2.loc['Alice']
print(row2['age'], type(row2['age']))   # 18.0  <class 'numpy.float64'>
```

**When every column is numeric, a row is coerced to float** — the integer 18 becomes 18.0, because a Series has one dtype.

With a text column mixed in, the dtype becomes object and **each value keeps its own type**.

> 💡 **Practical tip:** to preserve types, don't take "a row" — take "one value from one column": `df.loc[0, 'age']` gives you 18 as an int.

## Shortcuts: head / tail / sample

```python
print(df.head(2))       # first 2
print(df.tail(2))       # last 2
print(df.sample(2))     # 2 random rows (different each time)
```

**`sample()` is great for eyeballing data.**

## Summary

| Goal | Write | You get |
|---|---|---|
| One column | `df['score']` | Series |
| Several columns | `df[['name','score']]` | DataFrame |
| First N rows | `df.head(N)` / `df[0:N]` | DataFrame |
| One row | `df.iloc[i]` / `df.loc[label]` | Series |
| Random rows | `df.sample(N)` | DataFrame |

**One rule to remember:** inside the brackets, **a name or a list means columns**; **a slice or a boolean means rows**.

Feel the "brackets = columns, slice = rows" rule.

```quiz

q: Take the "score" column and print its maximum
starter: |

  df = pd.DataFrame({
      'name': ['Alice', 'Bob', 'Cara'],
      'score': [89.5, 92.0, 78.0]
  })
  
  # df['score'] gives the column (a Series), then .max()
  # it should be 92.0
  
  print("edit here")
tests:
- assert "92" in __out
hint: print(df['score'].max()). Putting a column name in brackets selects that column as a Series, so every Series method is available.
explain: Single brackets plus a column name = one column (a Series). This is the most basic pandas move. Don't write df[['score']].max() — that gives a DataFrame and behaves differently.
```
