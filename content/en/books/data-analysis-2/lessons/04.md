# Look at the data

> You've been handed an unfamiliar table. What do you do in the first five minutes? This lesson gives you a fixed routine.

## The standard opening

Do these five in order and 90% of structural problems surface:

```python
import pandas as pd

df = pd.read_csv('data.csv')     # load it first (next lesson)

# 1. how big is it
print(df.shape)

# 2. what do the first rows look like
print(df.head())

# 3. column names and types
print(df.info())

# 4. statistics for numeric columns
print(df.describe())

# 5. anything missing
print(df.isna().sum())
```

## 1. shape: the scale

```python
print(df.shape)      # (1000, 8) → 1000 rows, 8 columns
```

**Know the size first.** A thousand rows and a million rows call for completely different handling (the latter needs performance in mind).

## 2. head / tail: the content

```python
print(df.head())      # first 5 rows by default
print(df.head(10))    # first 10
print(df.tail(3))     # last 3
```

**`head()` is the most important step** — seeing the actual data beats any description.

> 💡 With many columns, printing truncates to `col1  col2  ...  col8`. To see them all:

```python
pd.set_option('display.max_columns', None)    # no column limit
pd.set_option('display.width', 200)           # wider output
```

## 3. info: names, non-null counts, types

```python
df = pd.DataFrame({
    'name': ['Alice', 'Bob', 'Cara'],
    'age': [18, 19, 20],
    'score': [89.5, 92.0, 78.0]
})
print(df.info())
```

```
<class 'pandas.core.frame.DataFrame'>
RangeIndex: 3 entries, 0 to 2
Data columns (total 3 columns):
 #   Column  Non-Null Count  Dtype  
---  ------  --------------  -----  
 0   name     3 non-null      object 
 1   age      3 non-null      int64  
 2   score    3 non-null      float64
dtypes: float64(1), int64(1), object(1)
memory usage: 200.0+ bytes
```

**Three things to read:**

- **Non-Null Count** — if a column says `2 non-null` in a 3-row frame, **there's one gap**
- **Dtype** — if a "price" column shows object, **text has crept in** (like "1,299" or "n/a")
- **memory usage** — how much space it takes

> ⚠️ **"A numeric-looking column showing object" is the most common dirty-data signal.** Usual causes: thousands separators, currency symbols, or placeholders like "n/a" or "-". Lesson 13 covers the fix.

## 4. describe: numeric statistics

```python
print(df.describe())
```

```
        age      score
count  3.000000   3.000000
mean  19.000000  86.500000
std    1.000000   7.466592
min   18.000000  78.000000
25%   18.500000  83.750000
50%   19.000000  89.500000
75%   19.500000  90.750000
max   20.000000  92.000000
```

**Four things worth looking for:**

| Check | Reveals |
|---|---|
| `count` below the row count | missing values |
| absurd `min` / `max` | outliers (age 200, price 0) |
| `mean` far from `50%` | heavy skew (extremes dragging the mean) |
| a large `std` | the data is very spread out |

**`describe()` covers numeric columns only.** For text columns:

```python
print(df['name'].value_counts())     # how often each value occurs
print(df['name'].unique())           # which distinct values exist
```

## 5. isna: the gaps

```python
print(df.isna().sum())          # gaps per column
print(df.isna().sum().sum())    # total gaps in the frame
print(df.isna().any())          # does each column have any gaps
```

**`isna().sum()` is the standard way to locate gaps.** A percentage is even more useful:

```python
print(df.isna().mean() * 100)     # percentage missing per column
```

If a column is more than about 50% missing, you usually **drop the column** rather than fill it.

## Putting it together: diagnosing a dirty table

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    'order': ['A001', 'A002', 'A003', 'A004'],
    'amount': ['199', '1,299', 'n/a', '89'],     # ← dirty: commas and text
    'qty': [1, 2, np.nan, 1],                    # ← a gap
    'date': ['2024-01-01', '2024-01-02', '2024-01-03', '2024-01-04']
})

print("shape:", df.shape)
print("\n--- info ---")
print(df.info())
print("\n--- missing ---")
print(df.isna().sum())
```

From `info()` you'll see that **`amount` is object** — because it holds `'1,299'` and `'n/a'`, even though it looks numeric. That's the value of combining `head()` and `info()`: **your eyes see numbers; the program sees text.**

## Quick reference

| Goal | Write |
|---|---|
| size | `df.shape` |
| first/last rows | `df.head()` / `df.tail()` |
| column names | `df.columns` |
| row index | `df.index` |
| types and non-null counts | `df.info()` |
| numeric statistics | `df.describe()` |
| missing counts | `df.isna().sum()` |
| text column distribution | `df['col'].value_counts()` |
| distinct values | `df['col'].unique()` |
