# Drop or fill

> Once you've found the gaps, the first decision is: keep this row or not? This lesson covers dropna and fillna, and how to choose.

## Two routes

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    'name': ['Alice', 'Bob', 'Cara', 'Dan'],
    'maths': [80, 95, np.nan, 70],
    'science': [90, np.nan, 85, 75],
    'english': [85, 88, np.nan, 92]
})

# route one: drop rows with gaps
print(df.dropna())

# route two: fill
print(df.fillna(0))
```

**Which one?** Look at the missing ratio and how important the column is.

## dropna: remove

### Default: drop any row with a gap

```python
print(df.dropna())          # only Dan survives
print(len(df), '→', len(df.dropna()))
```

**The default is aggressive** — one gap anywhere and the whole row goes. With plenty of data that's usually right, but **with little data it can empty your frame**.

### how='all': only if the whole row is empty

```python
print(df.dropna(how='all'))     # drop only fully-empty rows
```

### thresh: at least N non-null values

```python
print(df.dropna(thresh=3))      # keep rows with at least 3 valid values
```

**`thresh` is more flexible than `how`** — "I want at least N valid data points in this row".

### subset: only look at certain columns

```python
# only care about maths; keep the row if maths is present
print(df.dropna(subset=['maths']))
```

**`subset` is the most-used argument** — drop only when a *key* column is missing; other columns don't matter.

### axis=1: drop columns

```python
print(df.dropna(axis=1))        # drop columns containing gaps
```

## fillna: fill

### A fixed value

```python
print(df['maths'].fillna(0))
```

> ⚠️ **Filling with 0 is risky.** Filling a score with 0 confuses "didn't sit the exam" with "scored zero", dragging the average down. Zero only suits cases where empty genuinely means none (a coupon amount, a quantity).

### A statistic (most common)

```python
mean = df['maths'].mean()
print(df['maths'].fillna(mean))
```

**The mean suits data that's fairly concentrated with gaps scattered at random.** The median works too:

```python
print(df['maths'].fillna(df['maths'].median()))
```

**The median resists outliers better** — with extreme values (incomes, house prices), the median is the better choice.

### Fill by group (more precise)

```python
df['class'] = ['A', 'A', 'B', 'B']
# fill with each class's own mean (clearer once you've met groupby)
df['maths'] = df.groupby('class')['maths'].transform(lambda x: x.fillna(x.mean()))
```

**"Fill with the group's mean" is far more accurate than the global mean** — think of filling heights separately for men and women.

### Forward and backward fill

```python
s = pd.Series([1, np.nan, np.nan, 4])
print(s.ffill())      # [1, 1, 1, 4]     carry the previous value forward
print(s.bfill())      # [1, 4, 4, 4]     take the next value back
```

**Suited to time series** — if a day's temperature is missing, yesterday's is a sensible stand-in.

```python
print(s.fillna(method='ffill'))     # equivalent
```

### Different values per column

```python
print(df.fillna({'maths': 60, 'science': df['science'].mean()}))
```

**Pass a dict**: keys are column names, values are what to fill with.

## How to choose

| Situation | Suggestion |
|---|---|
| Gaps < 5%, scattered at random | **drop rows** (`dropna()`) |
| A **column** > 50% missing | **drop the column** (`dropna(axis=1)`) |
| Numeric, concentrated distribution | **mean / median** |
| Numeric, with outliers | **median** |
| Categorical (text) | **mode**, or a new "unknown" category |
| Time series | **ffill / bfill** |
| A key column missing (an order id) | **must drop** — never invent it |

> 💡 **Core principle: don't fill just to make the gaps disappear.** Filling is guessing, and a bad guess introduces bias. Better to drop than to invent.

## One thing not to forget

**Both functions return a new frame by default:**

```python
df.dropna()                      # original unchanged
df = df.dropna()                 # ✅ assign back
df.dropna(inplace=True)          # ✅ or modify in place
```

## Practice: cleaning a marks table

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    'name': ['Alice', 'Bob', 'Cara', 'Dan', 'Eve'],
    'maths': [80, 95, np.nan, 70, np.nan],
    'science': [90, np.nan, 85, 75, np.nan],
    'english': [85, 88, np.nan, 92, 90]
})

print("=== before ===")
print(df.isna().sum())

# 1. look at the ratios
ratio = df[['maths','science','english']].isna().mean()
print("\nmissing ratio:")
print(ratio)

# 2. drop rows missing both maths and science (Eve — too little information)
df = df.dropna(subset=['maths','science'], how='all')
print(f"\nafter dropping rows missing both: {len(df)} rows")

# 3. fill the remaining single-subject gaps with that subject's median
for col in ['maths','science','english']:
    df[col] = df[col].fillna(df[col].median())

print("\n=== after ===")
print(df)
print("\nremaining gaps:", df.isna().sum().sum())
```

**This is the standard routine**: check ratios → drop the badly missing → fill the rest.
