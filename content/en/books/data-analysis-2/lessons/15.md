# Working with text columns

> You can't call Python string methods on a column directly — you need the `.str` accessor. This lesson covers cleaning dirty text.

## Why .str exists

```python
import pandas as pd

s = pd.Series(['apple', 'banana', 'orange'])

# ❌ this doesn't work (a Series has no upper method)
s.upper()

# ✅ add .str
print(s.str.upper())
```

**`.str` is pandas' dedicated doorway for text columns**, and the method names inside are exactly Python's string methods.

## The ones you'll use most

```python
s = pd.Series([' apple ', 'banana ', '  orange'])

print(s.str.strip())          # trim both ends → ['apple','banana','orange']
print(s.str.upper())          # upper case
print(s.str.lower())          # lower case
print(s.str.len())            # length → [7, 7, 8]
print(s.str.contains('app'))  # contains? → [True, False, False]
print(s.str.replace(' ', '_'))# replace
```

> ⠀ **Watch the `len()` result**: `' apple '` has length 7 (the two spaces count), so **order matters — strip before measuring length**.

## Cleaning dirty money: the full routine

The most common real-world case:

```python
m = pd.Series(['£1,299', '£89', 'n/a', '2,000元'])

# 1. strip currency symbols
m1 = m.str.replace('£', '').str.replace('元', '')
print(m1.tolist())        # ['1,299', '89', 'n/a', '2,000']

# 2. strip thousands separators
m2 = m1.str.replace(',', '')
print(m2.tolist())        # ['1299', '89', 'n/a', '2000']

# 3. convert; failures become NaN
nums = pd.to_numeric(m2, errors='coerce')
print(nums.tolist())      # [1299.0, 89.0, nan, 2000.0]
```

**Three steps: strip symbols → strip commas → convert.**

## Splitting: split

```python
s = pd.Series(['London-Central', 'Paris-East', 'Berlin-West'])

print(s.str.split('-'))
```

```
0    [London, Central]
1    [Paris, East]
2    [Berlin, West]
dtype: object
```

**Once split into lists, take a piece with `.str[0]`** (note the second `.str`):

```python
print(s.str.split('-').str[0])     # the city
print(s.str.split('-').str[1])     # the district
```

**To split straight into two columns**, add `expand=True`:

```python
df = s.str.split('-', expand=True)
df.columns = ['city', 'district']
print(df)
```

```
     city district
0  London  Central
1   Paris     East
2  Berlin     West
```

**`expand=True` hands you a DataFrame** — very handy.

## Extracting: extract (regex)

```python
s = pd.Series(['orderA001', 'orderB002', 'orderC003'])
print(s.str.extract(r'(\d+)'))      # pull out the digits
```

**`extract` uses a regular expression**, capturing whatever is in the parentheses. Chapter 1 didn't cover regex — just knowing this exists is enough for now.

## Filtering: contains with boolean indexing

```python
df = pd.DataFrame({
    'product': ['Apple phone', 'Apple laptop', 'Banana', 'Apple juice'],
    'price': [5999, 9999, 5, 12]
})

# products whose name contains "Apple"
print(df[df['product'].str.contains('Apple')])
```

**`str.contains()` returns a boolean Series, ready to use as a filter.**

```python
# does not contain (negate)
print(df[~df['product'].str.contains('Apple')])

# starts with / ends with
print(df[df['product'].str.startswith('Apple')])
print(df[df['product'].str.endswith('juice')])
```

## The missing-value trap

**`.str` methods return NaN for NaN rather than raising:**

```python
s = pd.Series(['apple', None, 'orange'])
print(s.str.upper())
```

```
0      APPLE
1       None    ← stays missing
2     ORANGE
dtype: object
```

But **`contains` returns NaN rather than True/False for a gap**, which breaks boolean indexing:

```python
# ❌ NaN mixed into the boolean Series — filtering errors or misbehaves
df[df['col'].str.contains('x')]

# ✅ add na=False
df[df['col'].str.contains('x', na=False)]
```

> 💡 **`na=False` is the defensive form** — add it whenever the column might contain gaps.

## Practice: cleaning a users table

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    'name': [' Alice ', 'Bob', ' Cara  '],
    'phone': ['138-0013-8000', '13900138001', '137-0013-7000'],
    'spend': ['£1,299', '£89', '£2,000']
})

print("=== before ===")
print(df)

# 1. trim names
df['name'] = df['name'].str.strip()

# 2. strip dashes from phone numbers
df['phone'] = df['phone'].str.replace('-', '')

# 3. convert spend to numbers
df['spend'] = pd.to_numeric(
    df['spend'].str.replace('£', '').str.replace(',', ''),
    errors='coerce'
)

print("\n=== after ===")
print(df)
print("\ntypes:")
print(df.dtypes)
print("\ntotal spend:", df['spend'].sum())
```

## Quick reference

| Need | Write |
|---|---|
| Trim spaces | `.str.strip()` |
| Case | `.str.upper()` / `.str.lower()` |
| Length | `.str.len()` |
| Contains | `.str.contains('x', na=False)` |
| Starts / ends | `.str.startswith('x')` / `.str.endswith('x')` |
| Replace | `.str.replace('old','new')` |
| Split (to list) | `.str.split('-')` |
| Split (to columns) | `.str.split('-', expand=True)` |
| Take piece N | `.str.split('-').str[N]` |
| Regex extract | `.str.extract(r'(\d+)')` |
