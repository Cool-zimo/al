# Type conversion

> "It's clearly a number, so why can't I calculate with it?" — this lesson fixes the most frequent complaint in pandas.

## The symptom first

```python
import pandas as pd

df = pd.DataFrame({'price': ['199', '89', '1299']})
print(df['price'].dtype)      # object
print(df['price'] + 1)        # ❌ TypeError
```

**Text columns can't do arithmetic.** They must become numbers first.

## astype: the direct conversion

```python
df['price'] = df['price'].astype(int)
print(df['price'].dtype)      # int64
print(df['price'] + 1)        # ✅
```

**But astype is brittle — one bad value and the whole thing collapses:**

```python
d = pd.DataFrame({'v': ['1', '2', 'x']})
d['v'].astype(int)
# ValueError: invalid literal for int() with base 10: 'x'
```

**A single unconvertable value fails the entire column.** Real data almost always contains one.

## to_numeric: more forgiving

```python
print(pd.to_numeric(d['v'], errors='coerce'))
```

```
0    1.0
1    2.0
2    NaN    ← unconvertable becomes NaN instead of raising
Name: v, dtype: float64
```

**`errors='coerce'` is the master key for cleaning numeric columns.** Handle what failed afterwards:

```python
d['v'] = pd.to_numeric(d['v'], errors='coerce')
print(d['v'].isna().sum())      # how many failed to convert
```

Three options for `errors`:

| Value | Behaviour |
|---|---|
| `'raise'` (default) | raise on failure |
| `'coerce'` | failures become NaN ← **use this when cleaning** |
| `'ignore'` | leave failures untouched |

## Practice: cleaning a money column

Real-world amounts look like this: `'£1,299'`, `'1,299元'`, `'n/a'`.

```python
m = pd.Series(['£1,299', '£89', 'n/a'])

# step one: strip symbols and commas
cleaned = m.str.replace('£', '').str.replace(',', '')
print(cleaned.tolist())      # ['1299', '89', 'n/a']

# step two: convert, failures become NaN
nums = pd.to_numeric(cleaned, errors='coerce')
print(nums.tolist())         # [1299.0, 89.0, nan]
```

**Two steps: clean the interfering characters with `.str`, then convert with `to_numeric`.**

## A trap you will hit: NaN can't become int

```python
d = pd.DataFrame({'qty': [1.0, np.nan]})
d['qty'].astype(int)
# IntCastingNaNError: Cannot convert non-finite values (NA or inf) to integer
```

**Any NaN in the column blocks conversion to int** — int has no "empty" state.

Three ways out:

```python
# 1. fill first, then convert (most common)
d['qty'].fillna(0).astype(int)      # [1, 0]

# 2. use the nullable integer type Int64 (capital I)
d['qty'].astype('Int64')            # [1, <NA>]
print(d['qty'].astype('Int64').dtype)   # Int64

# 3. stay float (if you still need division later)
```

> 💡 **`Int64` (capital I) is pandas' nullable integer type**, holding integers and gaps at once. Don't confuse it with NumPy's `int64` (lowercase i), which cannot hold NaN.

## Converting to text

```python
df['code'] = df['code'].astype(str)      # number to text
```

**Watch out:** NaN becomes the *string* `'nan'`, which is rarely what you want:

```python
s = pd.Series([1, np.nan])
print(s.astype(str).tolist())     # ['1.0', 'nan']  ← 'nan' is text, not missing
```

## Converting to category

```python
df['city'] = df['city'].astype('category')
print(df['city'].dtype)      # category
```

**Text columns with few distinct values (city, gender, category) save memory and speed up groupby as `category`.** The gain is largest when the number of distinct values is far below the row count.

## Converting to dates

```python
df['date'] = pd.to_datetime(df['date'])
print(df['date'].dtype)      # datetime64[ns]
```

Lesson 26 covers this properly. For now: **it's `to_datetime`, not `astype`.**

## Checking types: dtypes

```python
print(df.dtypes)                                  # each column's type
print(df.dtypes.value_counts())                   # how many of each
print(df.select_dtypes(include='object').columns) # pick out every text column
```

**`select_dtypes` is perfect for "find every text column I should clean":**

```python
# list all object columns and check whether each should really be numeric
for col in df.select_dtypes(include='object').columns:
    print(col, '→', df[col].unique()[:5])
```

## A full cleaning pass

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    'price': ['£1,299', '£89', 'n/a', '£2,000'],
    'qty': ['2', '3', 'x', '1'],
    'city': ['London', 'Paris', 'London', 'Berlin']
})

print("=== before ===")
print(df.dtypes)

# 1. price: strip symbols and commas, then convert
df['price'] = pd.to_numeric(
    df['price'].str.replace('£','').str.replace(',',''),
    errors='coerce'
)

# 2. qty: convert, failures become NaN, fill 0, then int
df['qty'] = pd.to_numeric(df['qty'], errors='coerce').fillna(0).astype(int)

# 3. city: category (few distinct values, saves memory)
df['city'] = df['city'].astype('category')

print("\n=== after ===")
print(df.dtypes)
print()
print(df)
print("\nprice gaps (from 'n/a'):", df['price'].isna().sum())
```

## Quick reference

| Need | Write |
|---|---|
| To number (strict) | `.astype(int)` / `.astype(float)` |
| To number (forgiving) | `pd.to_numeric(col, errors='coerce')` |
| To text | `.astype(str)` |
| To category | `.astype('category')` |
| To nullable int | `.astype('Int64')` (capital I) |
| To date | `pd.to_datetime(col)` |
| See types | `df.dtypes` |
| Pick text columns | `df.select_dtypes(include='object')` |
