# Changing values and adding columns

> Once you can filter, you can start editing. Assignment, new columns, apply, and one famous warning.

## Adding a column

Three common styles:

```python
import pandas as pd

df = pd.DataFrame({
    'name': ['Alice', 'Bob', 'Cara'],
    'score': [89.5, 92.0, 78.0]
})

df['grade'] = ['B', 'A', 'C']                  # a list directly
df['passed'] = df['score'] >= 60               # derived from another column
df['rank'] = df['score'].rank(ascending=False) # computed by a method

print(df)
```

**Assigning to a name that doesn't exist creates a column**; if it exists, you overwrite it.

> ⚠️ With a list, **the length must match the row count**, or you get `ValueError: Length of values does not match length of index`.

## Changing values

```python
# one value
df.loc[0, 'score'] = 90.0

# by condition
df.loc[df['score'] < 60, 'grade'] = 'F'

# a whole column
df['score'] = df['score'] + 5        # everyone gains 5
```

**Conditional assignment is the most frequent operation.** Learn the shape:

```python
df.loc[condition, 'column'] = new_value
```

## One famous trap: chained assignment

```python
# ❌ this may not change anything
df[df['score'] < 60]['grade'] = 'F'

# ✅ correct
df.loc[df['score'] < 60, 'grade'] = 'F'
```

**Why does it fail?**

`df[condition]` returns **a new DataFrame** (most pandas operations return a copy). You edited the copy; the original is untouched.

pandas raises `SettingWithCopyWarning` — but **that warning sometimes doesn't appear**, so you think it worked when it didn't.

> 💡 **Rule of thumb: always assign with `df.loc[row, col] = value`. Never chain.**

## apply: process value by value

When the logic is too involved for a single column expression, use `apply`:

```python
def judge(score):
    if score >= 90:
        return 'A'
    elif score >= 80:
        return 'B'
    elif score >= 60:
        return 'C'
    else:
        return 'F'

df['grade'] = df['score'].apply(judge)
print(df)
```

**`apply` takes a function and calls it on each value of the Series**; the return values become a new column.

**Simple logic is shorter with a lambda:**

```python
df['grade'] = df['score'].apply(lambda x: 'A' if x >= 90 else 'B')
```

## apply across a row: axis=1

```python
df2 = pd.DataFrame({
    'maths': [80, 95, 88],
    'science': [90, 70, 85]
})

# total (sum across each row)
df2['total'] = df2.apply(lambda row: row['maths'] + row['science'], axis=1)
print(df2)
```

**`axis=1` means "move along the columns"**, i.e. operate per row.

But **this example doesn't need apply at all**:

```python
df2['total'] = df2['maths'] + df2['science']       # ✅ faster and clearer
```

> ⚠️ **apply runs a Python function per row and is much slower than vectorised arithmetic.** Use column arithmetic whenever you can; reach for apply only when the logic genuinely can't be vectorised.

## Renaming columns

```python
df = df.rename(columns={'score': 'marks', 'name': 'student'})
```

**Also returns a new frame** — assign it back or pass `inplace=True`.

## Dropping rows and columns

```python
df = df.drop(columns=['passed'])          # drop a column
df = df.drop(index=[0])                   # drop a row
df = df.drop(index=df[df['marks'] < 60].index)   # drop rows by condition
```

**The pattern for conditional dropping:** find the indexes to remove with a condition, then pass them to `drop`.

## Replacing values

```python
df['grade'] = df['grade'].replace({'A': 'Excellent', 'B': 'Good'})
```

A dict gives one-to-one mapping; you can also replace a single value:

```python
df['marks'] = df['marks'].replace(0, pd.NA)      # turn 0 into missing
```

## A worked example

```python
import pandas as pd

df = pd.DataFrame({
    'product': ['Keyboard', 'Mouse', 'Monitor', 'Headset'],
    'price': [199, 89, 1299, 399],
    'units': [120, 500, 30, 200]
})

# 1. revenue
df['revenue'] = df['price'] * df['units']

# 2. grade by revenue
df['tier'] = df['revenue'].apply(
    lambda x: 'hit' if x >= 50000 else ('strong' if x >= 20000 else 'normal')
)

# 3. flag the hits
df.loc[df['tier'] == 'hit', 'note'] = 'promote'

# 4. sort by revenue
df = df.sort_values('revenue', ascending=False)

print(df)
```

## Summary

| Need | Write |
|---|---|
| New column | `df['new'] = ...` |
| One value | `df.loc[row, col] = value` |
| By condition | `df.loc[cond, 'col'] = value` |
| Complex logic | `df['col'].apply(fn)` |
| Across columns | `df.apply(fn, axis=1)` (prefer plain column arithmetic) |
| Rename | `df.rename(columns={...})` |
| Drop | `df.drop(columns=[...])` |
| Replace | `df['col'].replace({...})` |
