# Duplicates and outliers

> Data isn't always missing — sometimes there's too much of it, or values are absurd. This lesson is about spotting both.

## Duplicates: duplicated

```python
import pandas as pd

d = pd.DataFrame({
    'city': ['London', 'London', 'Paris', 'Berlin', 'Paris'],
    'value': [1, 1, 2, 3, 4]
})

print(d.duplicated())
```

```
0    False
1     True    ← identical to the row above
2    False
3    False
4    False
dtype: bool
```

**`duplicated()` flags "this row repeats an earlier one"** — the first occurrence is False, later repeats are True.

**Note the second "Paris" isn't flagged** — its value is 4, so the row as a whole differs from "Paris / 2".

## Judging on some columns: subset

```python
print(d.duplicated(subset=['city']))
```

```
0    False
1     True    ← London's second appearance
2    False
3    False
4    True     ← Paris's second appearance
```

**Only the "city" column decides.** This is the more useful mode — business "duplicates" usually mean "the key repeats", not "the whole row matches".

## The keep argument

```python
print(d.duplicated(subset=['city'], keep='last'))    # the last one isn't a duplicate
print(d.duplicated(subset=['city'], keep=False))     # flag every duplicated row
```

| `keep` | Behaviour |
|---|---|
| `'first'` (default) | first occurrence isn't a duplicate, later ones are |
| `'last'` | last occurrence isn't a duplicate |
| `False` | **every** row involved in a duplicate is True |

**`keep=False` is the key to "pull out all the duplicates and look at them":**

```python
# which cities appear more than once?
print(d[d.duplicated(subset=['city'], keep=False)])
```

## Removing: drop_duplicates

Lesson 10 covered it; one extra point here:

```python
d.drop_duplicates(subset=['city'], keep='first')
```

**Look at how many there are before you drop:**

```python
print("duplicate rows:", d.duplicated().sum())
print("duplicate cities:", d.duplicated(subset=['city']).sum())
```

## Outliers: check the statistics first

```python
v = pd.Series([10, 12, 11, 13, 12, 11, 999, 10, 12])
print(v.describe())
```

```
count      9.000000
mean     121.111111    ← dragged up by 999
std      329.209828
min       10.000000
25%       11.000000
50%       12.000000
75%       12.000000
max      999.000000    ← clearly absurd
```

**Three signals to watch:**

- `max` / `min` far from everything else
- `mean` very different from `50%` (the median) → something extreme is pulling it
- a huge `std`

**Here mean=121 while the median is 12 — one glance tells you there's an outlier.**

## Drawing the line with IQR

**The most common quantitative method:**

```python
q1 = v.quantile(0.25)      # lower quartile
q3 = v.quantile(0.75)      # upper quartile
iqr = q3 - q1              # interquartile range

lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr

print(f"normal range: {lower} ~ {upper}")
print("outliers:", v[(v < lower) | (v > upper)].tolist())
```

```
normal range: 9.5 ~ 13.5
outliers: [999]
```

**The rule: below Q1−1.5×IQR or above Q3+1.5×IQR is an outlier.**

This is the standard statistical approach (it's how box plots work), and more reliable than eyeballing a threshold.

## Standard deviations also work

```python
mean, std = v.mean(), v.std()
print(v[(v - mean).abs() > 3 * std])      # more than 3 standard deviations away
```

**But the standard deviation is itself inflated by the outlier** (999 blows up `std`), which **makes IQR the sturdier choice.** Prefer IQR.

## What to do: three routes

```python
# 1. drop
v_clean = v[~((v < lower) | (v > upper))]

# 2. clip — squeeze the extreme values to the boundary
v_clip = v.clip(lower, upper)
print(v_clip.tolist())      # 999 becomes 13.5

# 3. turn into NaN and treat as missing
v[v > upper] = np.nan
```

| Method | When |
|---|---|
| **Drop** | you're sure it's a data-entry error (age 200, price 0) |
| **clip** | unsure, but don't want it skewing statistics (keeps the row count) |
| **to NaN** | want to keep the row count and have a filling strategy |

> ⚠️ **Don't rush to delete outliers.** Some are genuine signals — a £100,000 order might be a key account rather than a typo. **Look at what it is before deciding.**

```python
# look at the offending rows, not just the number
print(df[df['amount'] > upper])
```

## Practice: cleaning a sales table

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    'order': ['A001', 'A002', 'A002', 'A003', 'A004'],
    'amount': [199, 89, 89, 99999, 150],
    'qty': [1, 2, 2, 1, 3]
})

print("=== step 1: duplicates ===")
print("duplicate orders:", df.duplicated(subset=['order']).sum())
df = df.drop_duplicates(subset=['order'], keep='first')
print(f"after de-duplicating: {len(df)} rows")

print("\n=== step 2: outliers ===")
q1, q3 = df['amount'].quantile(0.25), df['amount'].quantile(0.75)
iqr = q3 - q1
upper = q3 + 1.5 * iqr
print(f"normal upper bound: {upper}")

outliers = df[df['amount'] > upper]
print("suspect orders:")
print(outliers)

print("\n=== step 3: handle (dropping here) ===")
df = df[df['amount'] <= upper]
print(df)
print("\nmean amount:", df['amount'].mean())      # sensible now
```

## Summary

| Need | Write |
|---|---|
| Flag duplicates | `df.duplicated()` |
| By key column | `df.duplicated(subset=['col'])` |
| All duplicates | `keep=False` |
| Remove | `df.drop_duplicates(subset=['col'])` |
| Spot outliers | `df.describe()` (compare mean with 50%) |
| IQR bounds | `Q1−1.5×IQR` ~ `Q3+1.5×IQR` |
| Squeeze | `df['col'].clip(lower, upper)` |
