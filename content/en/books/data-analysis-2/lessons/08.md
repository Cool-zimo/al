# Filtering by condition

> From "take everything" to "take only what matches". Boolean indexing, multiple conditions, and one syntax trap you will hit.

## What boolean indexing really is

```python
import pandas as pd

df = pd.DataFrame({
    'name': ['Alice', 'Bob', 'Cara', 'Dan'],
    'age': [18, 19, 20, 17],
    'score': [89.5, 92.0, 78.0, 95.0]
})

print(df['score'] > 90)
```

```
0    False
1     True
2    False
3     True
Name: score, dtype: bool
```

**A comparison produces a boolean Series.** Put it inside brackets (or loc) and you've filtered:

```python
print(df[df['score'] > 90])
```

```
    name  age  score
1    Bob   19   92.0
3    Dan   17   95.0
```

**How it works:** the boolean Series acts as a sieve — True rows stay, False rows drop out.

## Write it in two steps while learning

Splitting it up makes mistakes obvious:

```python
mask = df['score'] > 90        # build the sieve
print(mask.sum())              # how many True (= matching rows)

result = df[mask]              # then filter
print(result)
```

**`mask.sum()` is a handy trick** — True counts as 1 and False as 0, so the sum is "how many rows match".

## Several conditions: you must use & and |

```python
# age > 18 AND score > 90
print(df[(df['age'] > 18) & (df['score'] > 90)])

# age <= 18 OR score >= 95
print(df[(df['age'] <= 18) | (df['score'] >= 95)])
```

> ⚠️ **Three things to remember:**

1. **`and` / `or` won't work** — they operate on single booleans and raise on a Series
2. **Parentheses are mandatory** — `df['age'] > 18 & df['score'] > 90` breaks on operator precedence
3. **Negate with `~`** — not `not`

```python
# ❌ raises
df[df['age'] > 18 and df['score'] > 90]

# ❌ precedence bug
df[df['age'] > 18 & df['score'] > 90]

# ✅ correct
df[(df['age'] > 18) & (df['score'] > 90)]

# negation
df[~(df['score'] > 90)]        # score not above 90
```

## isin: filter against a list

```python
# only Alice and Cara
print(df[df['name'].isin(['Alice', 'Cara'])])

# the opposite
print(df[~df['name'].isin(['Alice', 'Cara'])])
```

**`isin` is far cleaner than a pile of `==`:**

```python
# ❌ verbose
df[(df['name'] == 'Alice') | (df['name'] == 'Cara')]

# ✅ clear
df[df['name'].isin(['Alice', 'Cara'])]
```

## Text conditions: the .str accessor

```python
# names starting with "A"
print(df[df['name'].str.startswith('A')])

# names containing "ar"
print(df[df['name'].str.contains('ar')])
```

**`.str` is the dedicated accessor for text columns**, exposing the usual Python string methods (`startswith`, `contains`, `upper`, `strip`, …). Lesson 15 covers it properly.

## Filter, then pick columns

```python
# just the names (one step with loc)
print(df.loc[df['score'] > 90, 'name'])

# two columns
print(df.loc[df['score'] > 90, ['name', 'score']])
```

> 💡 **Prefer `loc[condition, column]` over the chained `df[condition]['name']`.** Chaining breaks when you assign to the filtered result (next lesson).

## An easy detail to miss: the index travels along

```python
result = df[df['score'] > 90]
print(result.index)      # [1, 3]  ← the original labels, not 0, 1
```

**Filtered results keep their original labels** — they aren't renumbered.

Usually that's good (you know where the data came from), but if you want a clean index:

```python
print(result.reset_index(drop=True))      # becomes 0, 1
```

**`drop=True` matters** — without it the old index becomes a new column.

## A worked example

```python
import pandas as pd

df = pd.DataFrame({
    'product': ['Keyboard', 'Mouse', 'Monitor', 'Headset', 'Speaker'],
    'category': ['peripheral', 'peripheral', 'display', 'peripheral', 'audio'],
    'price': [199, 89, 1299, 399, 599],
    'stock': [120, 500, 30, 200, 0]
})

# in-stock peripherals priced between 100 and 500
mask = (df['category'] == 'peripheral') & (df['stock'] > 0) & (df['price'].between(100, 500))
print(df.loc[mask, ['product', 'price', 'stock']])
```

```
    product  price  stock
0  Keyboard    199    120
3   Headset    399    200
```

**`between(100, 500)` is inclusive on both ends**, equivalent to `(df['price'] >= 100) & (df['price'] <= 500)` but tidier.

## Quick reference

| Need | Write |
|---|---|
| One condition | `df[df['col'] > value]` |
| And | `df[(condA) & (condB)]` |
| Or | `df[(condA) \| (condB)]` |
| Not | `df[~cond]` |
| In a list | `df['col'].isin([...])` |
| In a range | `df['col'].between(low, high)` |
| Missing | `df['col'].isna()` / `.notna()` |
| Contains text | `df['col'].str.contains('x')` |
| Count matches | `mask.sum()` |
