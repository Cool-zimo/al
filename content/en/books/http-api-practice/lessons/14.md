# 14 Customising Request Headers: Get What You Ask For

> Last lesson covered `params`. This one covers headers — the zone where you and the server make agreements. Set them right and the server gives you what you want; set them wrong and you may be rejected as a bot, get the wrong language, or fail to connect at all.

## What requests Sends by Default

With nothing configured, `requests` attaches these automatically:

```python
import requests

r = requests.get("https://httpbin.org/get", timeout=10)
print(r.text)          # see what the server received
```

In the echoed response, the headers section looks roughly like:

```json
{
  "headers": {
    "Accept": "*/*",
    "Accept-Encoding": "gzip, deflate",
    "Connection": "keep-alive",
    "Host": "httpbin.org",
    "User-Agent": "python-requests/2.31.0"
  }
}
```

**One by one**:

| Header | Value | Who adds it |
|---|---|---|
| `Host` | `httpbin.org` | added by the underlying library (required in HTTP/1.1) |
| `Accept` | `*/*` | requests default: "I accept anything" |
| `Accept-Encoding` | `gzip, deflate` | requests default: "I support compression" |
| `User-Agent` | `python-requests/2.31.0` | **requests default: openly announcing Python** |
| `Connection` | `keep-alive` | urllib3 default: reuse the connection |

**Key observation**: **`User-Agent` plainly says `python-requests`.**

What does that mean? Next section.

## User-Agent: The Header You Should Change Most

### Why the default UA is a problem

Many sites **judge from User-Agent whether you're a real browser**:

```
User-Agent: python-requests/2.31.0     ← obviously a script
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) ... ← looks like a browser
```

**Scenario one: outright rejection**. Some sites return 403 to non-browser UAs, or serve a "please use a modern browser" page.

**Scenario two: different content**. Some serve simplified pages to scraper UAs.

**Scenario three: tighter limits**. APIs apply stricter quotas to script UAs.

### How to change it properly

```python
import requests

headers = {
    "User-Agent": "MyApp/1.0 (contact@example.com)",    # ①
}

r = requests.get("https://httpbin.org/get", headers=headers, timeout=10)
```

> **Line-by-line**
>
> - **①** This value is **a name you invented**, not a browser disguise.
>
> **Two strategies**:
> - **Honest identification** (recommended): `MyApp/1.0 (contact@example.com)`. Site administrators can reach you. **This is公认 etiquette in the scraping community**
> - **Browser disguise**: write `Mozilla/5.0 ...`. Gets past some anti-bot checks, but **carries legal and ethical risk** — you're actively deceiving their server
>
> **This book's advice**: **prefer honest identification.** If a site explicitly forbids scraping, don't scrape it.

### GitHub API's hard requirement

**The GitHub API explicitly requires a UA**:

```python
# ❌ Rejected
r = requests.get("https://api.github.com/user", timeout=10)
# 403 Forbidden: "Please make sure your request has a User-Agent header"

# ✅ Right
r = requests.get(
    "https://api.github.com/user",
    headers={"User-Agent": "MyApp/1.0"},
    timeout=10,
)
```

**This is a real rule**, not hypothetical. GitHub has required a UA since 2012.

## Three Ways to Set Headers

### Way one: per request (most common)

```python
import requests

r = requests.get(
    url,
    headers={"Authorization": "Bearer xxx"},    # ① applies to this request only
    timeout=10,
)
```

> **①** This header **affects only this one request.** The next `requests.get()` won't carry it.

### Way two: at Session level (best for many requests)

```python
import requests

s = requests.Session()
s.headers.update({                               # ① set on the Session
    "User-Agent": "MyApp/1.0",
    "Authorization": "Bearer xxx",
})

r1 = s.get(url1, timeout=10)                     # ② attached automatically
r2 = s.get(url2, timeout=10)                     # ③ also attached
```

> **Line-by-line**
>
> - **①** `s.headers` is a dict; `update()` adds to it. **It applies to every request from this Session**
> - **②③** Both requests carry these headers automatically. **No repetition**
>
> **The most practical approach** — especially for `Authorization`, which you usually need on every call.

### Way three: override per request

```python
import requests

s = requests.Session()
s.headers.update({"User-Agent": "MyApp/1.0"})     # ① session default

r = s.get(                                        # ② this request
    url,
    headers={"User-Agent": "Special/2.0"},        #    overrides it
    timeout=10,
)
```

> **Merge rule**: **per-request `headers` are merged with the Session's; on a name clash, the per-request value wins.**
>
> So request ② goes out with UA `Special/2.0` and keeps everything else.

## Common Scenarios

### Scenario one: Bearer Token (most common)

```python
import requests

token = "ghp_xxxxxxxxxxxx"
headers = {
    "Authorization": f"Bearer {token}",     # ① note the space after Bearer
    "Accept": "application/vnd.github+json", # ② GitHub-specific format
}

r = requests.get("https://api.github.com/user", headers=headers, timeout=10)
```

> **Line-by-line**
>
> - **①** The format is `Bearer <token>`. **There's a space after "Bearer"**; omit it and you get 401
> - **②** The GitHub API has a special `Accept` value. Without it you get the default format

**Note**: not every API uses `Bearer`. Some use `Token xxx`, some `Basic xxx`. **Read the docs.**

### Scenario two: JSON only

```python
headers = {"Accept": "application/json"}

r = requests.get(url, headers=headers, timeout=10)
data = r.json()          # now you can be fairly sure it's JSON
```

**Why it helps**: some APIs return different formats (JSON / XML / HTML) based on `Accept`. Declare it and you get what you asked for.

### Scenario three: request a language

```python
headers = {"Accept-Language": "zh-CN,zh;q=0.9,en;q=0.8"}

r = requests.get(url, headers=headers, timeout=10)
```

**The server may return localised content because of this.** Note it's only a request; the server may ignore it.

### Scenario four: conditional request (save bandwidth)

```python
import requests

# First request — note the ETag
r1 = requests.get(url, timeout=10)
etag = r1.headers.get("ETag")

# Second request — send the ETag
r2 = requests.get(url, headers={"If-None-Match": etag}, timeout=10)
if r2.status_code == 304:
    print("unchanged — use the cache")
```

Lesson 07 covered this: it's the core of HTTP caching.

## Removing a Header

Sometimes you need to **delete** a default header rather than override it.

`requests` has no explicit "remove" parameter, but there's a trick: **set it to `None`**:

```python
import requests

r = requests.get(
    "https://httpbin.org/get",
    headers={"User-Agent": None},        # ① None = don't send this header
    timeout=10,
)
```

> **①** A header whose value is `None` **won't appear in the request.**
>
> **When needed**: rare servers that choke on certain headers. Or you want to test "what happens with no UA."

**Note**: same design as `params` skipping None — **in requests, `None` usually means "not this"**.

## Debugging: Confirm the Header Really Went Out

The most useful section of this lesson.

```python
import requests

r = requests.get(
    "https://httpbin.org/get",
    headers={"X-My-Header": "hello"},
    timeout=10,
)

# Method one: look at the server's echo
print(r.json()["headers"])         # ① the server reports what it received

# Method two: look at requests' own record of the request
print(r.request.headers)            # ② see what was sent
```

> **Line-by-line**
>
> - **①** `httpbin.org/get` returns the received headers verbatim. **The golden way to verify a header took effect**
> - **②** `r.request.headers` is the client-side record. **The two should match**
>
> **A mismatch means**: a proxy or redirect modified the request. In particular **cross-domain redirects strip Authorization**.

## A Helper: Merging Headers Correctly

Real projects often need three layers: base headers + per-call extras + auth. This is the clear way to write it:

```python
import requests

def make_headers(token=None, extra=None):
    """Build request headers: base + auth + extra"""
    headers = {                                    # ① base
        "User-Agent": "MyApp/1.0",
        "Accept": "application/json",
    }
    if token:                                       # ② optional auth
        headers["Authorization"] = f"Bearer {token}"
    if extra:                                       # ③ optional extras
        headers.update(extra)
    return headers

# Usage
h = make_headers(token="xxx", extra={"X-Request-ID": "abc123"})
r = requests.get(url, headers=h, timeout=10)
```

> **Line-by-line**
>
> - **①** Headers every request should have, unconditional
> - **②** When token is `None` or empty, **no auth header is added.** One function serves both logged-in and anonymous calls
> - **③** `extra` is optional and **overrides same-named entries** (because `update` is last-write-wins)
>
> **Why wrap it in a function**: avoid repeating the header pile at every call site. **And changing the UA is a one-line edit**

## Crash Site

### Crash 1: missing the space after Bearer

```python
# ❌ Wrong
headers = {"Authorization": "Bearerghp_xxxx"}
# or
headers = {"Authorization": "ghp_xxxx"}       # no Bearer at all
```

**Symptom**: 401 Unauthorized. You check the token, paste it three times, still 401.

**Cause**: the format must be `Bearer <token>` **with a space between**.

**Lesson**: **print it.** `print(headers)` reveals it instantly.

### Crash 2: a redirect eats the auth header

```python
# ❌ Symptom: 401
r = requests.get("https://a.com/data", headers={"Authorization": "Bearer xxx"}, timeout=10)
# a.com redirects to b.com and Authorization is gone
```

**Symptom**: hitting the target URL directly works; hitting a URL that redirects gives 401.

**Cause**: **Lesson 08 — requests strips Authorization on cross-domain redirects.** A security design.

**Verify**:

```python
print(r.request.headers.get("Authorization"))    # None ← indeed gone
print(r.history)                                  # there was a redirect
```

**Fix**: follow manually, or use a Session (**a Session won't help either** — this is redirect logic). The correct approach:

```python
r = requests.get(url, headers=headers, allow_redirects=False, timeout=10)
if r.status_code in (301, 302):
    new_url = r.headers["Location"]
    r = requests.get(new_url, headers=headers, timeout=10)    # re-attach manually
```

### Crash 3: passing headers positionally

```python
# ❌ Wrong
r = requests.get(url, {"Authorization": "Bearer xxx"}, timeout=10)
```

**Symptom**: the request goes out with no auth header; 401.

**Cause**: **`requests.get()`'s second positional parameter is `params`, not `headers`.** Your dict became query parameters.

**Verify**: `print(r.url)` shows `?Authorization=Bearer%20xxx` — the header ended up in the URL.

**Lesson**: **`headers=` must be a keyword argument.** The most insidious error class, because **it doesn't raise**.

## Why This Matters for Your Code

1. **`User-Agent` is the default header you most need to change.** The GitHub API requires it
2. **Set auth headers at Session level** — once, applies everywhere
3. **Per-request `headers` override same-named Session headers** (merge, not replace)
4. **`None` means delete a header**
5. **Debug with `r.request.headers` or httpbin** — first move for "I set it but it didn't take"
6. **`headers=` must be a keyword**; positional turns it into query params **without raising**

## Summary

- **Default headers**: `Host` (auto) / `Accept: */*` / `Accept-Encoding` / **`User-Agent: python-requests/2.31.0`** / `Connection: keep-alive`
- **The UA reveals you're a script.** Set an honest identifier like `MyApp/1.0 (contact@...)`
- **The GitHub API requires a UA**, or it returns 403
- **Three ways**: per-request `headers=` / Session-level `s.headers.update()` / per-request override
- **Common uses**: `Authorization: Bearer <token>` (**mind the space**) / `Accept: application/json` / `Accept-Language` / `If-None-Match`
- **A value of `None` deletes the header**
- **Verify via `r.request.headers` or a call to `httpbin.org/get`**
- ❌ **Missing space after Bearer**; **`headers` passed positionally** (no error, becomes query params); **cross-domain redirect eats auth**
