## Design: Decide the Blocks First

**Don't start typing code.** Sketch the modules first:

```
reqcli.py
├── CONFIG        config (base_url / token / timeout)
├── Client        HTTP layer: Session + retry + send
├── Formatter     turn a response into something readable
├── History       record request history
├── parse_command parse one line into (method, path, params, headers, output)
└── main          the REPL loop
```

**Why split it**: each block can change independently. Swap HTTP libraries → touch only `Client`. Change output style → touch only `Formatter`.

> **This is lesson 26's "state on the right layer" in practice**: each module minds its own business. `Client` doesn't know `Formatter` exists; `Formatter` doesn't know how input was parsed.

## Step One: Configuration

```python
import os

CONFIG = {
    "base_url": "https://api.github.com",
    "user_agent": "ReqCLI/1.0",
    "accept": "application/vnd.github+json",
    "token": os.environ.get("GITHUB_TOKEN", ""),   # ① read from env
    "timeout": 10,
    "max_retries": 2,
}
```

> **Line-by-line**
>
> - **① `os.environ.get(...)`**: **the core rule from lesson 22** — never hardcode secrets.
>   - Missing means an empty string and the program still runs (just with a 60/hour quota — lesson 28)
>   - Use `get(key, "")`, not `os.environ[key]` — **the latter raises KeyError outright when unset**

**Why a dict instead of scattered globals**: easy to iterate (the `config` command prints everything), and easy to swap for a config file later.

### The set Command

```python
def handle_set(arg):
    """set base_url https://api.example.com"""
    parts = arg.split(" ", 1)
    if len(parts) < 2:
        return "usage: set <key> <value>"

    key, value = parts[0].lower(), parts[1].strip()

    if key == "base_url":
        if not value.startswith("http"):      # ① auto-add scheme
            value = "https://" + value
        CONFIG[key] = value.rstrip("/")       # ② strip trailing slash
        return f"✅ base_url = {CONFIG[key]}"

    elif key == "token":
        CONFIG[key] = value
        return f"✅ token updated (length {len(value)})"    # ③ never echo it!

    elif key == "timeout":
        try:
            CONFIG["timeout"] = int(value)    # ④ convert + validate
        except ValueError:
            return f"❌ timeout must be a number"
        return f"✅ timeout = {value}s"

    else:
        return f"❌ unknown config: {key}"
```

> **Line-by-line**
>
> - **① Auto-prefix `https://`**: typing `api.example.com` works too. **This is "be forgiving to the user"**
> - **② `rstrip("/")`**: **critical.** Whether base_url ends with `/` decides if you build `/users` or `//users` (double slash) — **many APIs return 404 for that.** Strip trailing slashes uniformly, add one when joining
> - **③ Show only the length**: **never echo a token to the screen** (screens end up in logs and screenshots)
> - **④ Wrap `int(value)` in try**: user input is text; convert and fail gracefully

## Step Two: The HTTP Client (The Heart of This Lesson)

**This is lessons 26 (Session) + 24 (retry) + 15 (timeout) fused together.**

```python
import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

class Client:
    """HTTP client: connections, retries, default headers"""

    def __init__(self):
        self.session = requests.Session()

        # ① default headers (lesson 14)
        self.session.headers.update({
            "User-Agent": CONFIG["user_agent"],
            "Accept": CONFIG["accept"],
        })
        self._mount_adapter()

    def _mount_adapter(self):
        """Configure retry and the connection pool"""
        retry = Retry(
            total=CONFIG["max_retries"],              # ② retry count (excludes the first try)
            backoff_factor=0.5,                        # ③ exponential backoff
            status_forcelist=[429, 500, 502, 503, 504], # ④ which statuses to retry
            allowed_methods=["GET", "HEAD", "PUT", "DELETE", "OPTIONS"],  # ⑤ idempotent only
            raise_on_status=False,                     # ⑥ return normally when retries exhaust
        )
        adapter = HTTPAdapter(max_retries=retry, pool_connections=10, pool_maxsize=10)
        self.session.mount("https://", adapter)        # ⑦ must mount before any request
        self.session.mount("http://", adapter)

    def request(self, method, path, params=None, headers=None, body=None):
        """
        Send a request
        :return: (response, error_message); error None means success
        """
        url = CONFIG["base_url"] + path                # ⑧ join

        req_headers = {}
        if CONFIG["token"]:
            req_headers["Authorization"] = f"Bearer {CONFIG['token']}"   # ⑨ only when present

        if headers:
            req_headers.update(headers)                 # ⑩ user-supplied wins

        try:
            r = self.session.request(
                method, url,
                params=params,          # ⑪ query params (lesson 13)
                headers=req_headers,
                json=body,              # ⑫ auto-serialize + set Content-Type
                timeout=CONFIG["timeout"],   # ⑬ always set a timeout (lesson 15)
            )
            return r, None

        except requests.exceptions.Timeout:
            return None, f"⏱ request timed out ({CONFIG['timeout']}s)"
        except requests.exceptions.ConnectionError:
            return None, "🔌 connection failed (network or bad URL)"
        except requests.exceptions.RequestException as e:
            return None, f"❌ request failed: {e}"
```

> **Line-by-line**
>
> - **① Defaults on the Session**: every later request carries them (lesson 26)
> - **② `total=2`**: **excludes the initial request** — up to 3 attempts (the off-by-one from lesson 24)
> - **③ `backoff_factor=0.5`**: waits of 0s, 0.5s, 1.0s
> - **④ `status_forcelist`**: **retry only these.** Don't retry 4xx (the request itself is wrong)
> - **⑤ `allowed_methods`**: **retry only idempotent methods.** A direct application of lesson 6 — **never auto-retry POST**, or you may create duplicate orders
> - **⑥ `raise_on_status=False`**: after retries are exhausted, **return the response** instead of raising, so we can inspect the status ourselves
> - **⑦ `mount` before requesting** (crash four in lesson 26)
> - **⑨ Add the token only if present**: no token still works for public endpoints
> - **⑩ Update with user headers last**: **user values override defaults** (lesson 26's merge rule)
> - **⑪ `params=`**: requests URL-encodes for you (lesson 13)
> - **⑫ `json=body`**: **auto `json.dumps` plus `Content-Type: application/json`** (lesson 16) — **don't use `data=json.dumps(body)`; that also requires setting the header by hand**
> - **⑬ `timeout`**: **never omit it**

### Why Return (response, error) Instead of Raising

```python
r, err = client.request("GET", "/users/Cool-zimo")
if err:
    print(err)        # ① network-layer failure
    return
if r.status_code >= 400:
    print(f"HTTP {r.status_code}")   # ② HTTP-layer failure
```

**This frees the caller from try/except.** Network exceptions and HTTP error codes are different things, but **to the caller both mean "this request didn't get what I wanted,"** so a uniform return is simpler.

## Step Three: Formatting Output

**Responses must be readable at a glance.** Three essentials: status code with meaning, indented JSON, elapsed time shown.

```python
import json

STATUS_HINT = {          # ① status → plain words
    200: "OK", 201: "created", 204: "no content",
    301: "moved permanently", 302: "found",
    400: "bad request", 401: "unauthorized", 403: "forbidden",
    404: "not found", 429: "too many requests",
    500: "server error", 502: "bad gateway", 503: "unavailable",
}

def format_response(r, elapsed):
    """Format a response into readable text"""
    hint = STATUS_HINT.get(r.status_code, "")     # ② lookup, empty if unknown

    lines = [
        f"HTTP {r.status_code} {hint}  ({elapsed:.2f}s)",   # ③ status + elapsed
        "-" * 50,
    ]

    # ④ try to parse JSON
    try:
        obj = r.json()
        lines.append(json.dumps(obj, indent=2, ensure_ascii=False))  # ⑤ indent, don't escape
    except ValueError:
        # not JSON — output as-is
        lines.append(r.text.strip() or "(empty body)")

    # ⑥ rate-limit info (lesson 28)
    remaining = r.headers.get("X-RateLimit-Remaining")
    if remaining is not None:
        lines.append("")
        lines.append(f"📊 quota left: {remaining}/{r.headers.get('X-RateLimit-Limit', '?')}")

    return "\n".join(lines)
```

> **Line-by-line**
>
> - **① Status hint table**: seeing `429` you instantly know it's "too many requests" without checking docs
> - **② `.get(code, "")`**: **unknown codes give an empty string**; don't crash
> - **③ Show elapsed**: **the first-hand signal for performance debugging** — this is where you see that your program is slow
> - **④ Wrap `r.json()` in try**: **responses aren't always JSON** (HTML error pages, plain text) — crash three in lesson 20
> - **⑤ `indent=2, ensure_ascii=False`**:
>   - `indent=2` makes it human-readable
>   - **`ensure_ascii=False`** — without it, non-ASCII becomes `\u4e2d\u6587`
> - **⑥ Show quota**: **visible every time, so you never get surprised by a limit** (lesson 28's "check proactively")

### Saving to a File

```python
def save_response(r, path):
    """Store the response body to a file"""
    try:
        # ① decide whether it's text
        content_type = r.headers.get("Content-Type", "")
        if "json" in content_type or "text" in content_type:
            try:
                text = json.dumps(r.json(), indent=2, ensure_ascii=False)   # ② prettify before saving
            except ValueError:
                text = r.text
            with open(path, "w", encoding="utf-8") as f:     # ③ explicit encoding
                f.write(text)
        else:
            # binary: write as-is (lesson 25)
            with open(path, "wb") as f:
                f.write(r.content)

        return f"✅ saved to {path} ({len(r.content)} bytes)"

    except OSError as e:
        return f"❌ save failed: {e}"
```

> **Line-by-line**
>
> - **① Branch on Content-Type**: prettify JSON (humans read it), write binary as-is (must not alter it)
> - **③ `encoding="utf-8"`**: **state it explicitly.** Omit it and you get the system default, **which on Windows may be GBK, mangling non-ASCII text** (the encoding trap from lesson 18)
> - **`wb` branch**: lesson 25 — binary uses `r.content` and `"wb"`
> - **`OSError`**: every file error (permissions, missing path) is one of these

## Step Four: History

```python
from datetime import datetime

class History:
    """Request history"""

    def __init__(self, max_size=100):
        self.entries = []
        self.max_size = max_size       # ① ceiling, prevents unbounded growth

    def add(self, method, url, status):
        self.entries.append({
            "time": datetime.now().strftime("%H:%M:%S"),
            "method": method,
            "url": url,
            "status": status,
        })
        if len(self.entries) > self.max_size:     # ② drop the oldest
            self.entries.pop(0)

    def show(self, n=10):
        if not self.entries:
            return "  (no records)"
        lines = []
        for e in self.entries[-n:]:               # ③ only the last n
            lines.append(f"  {e['time']} {e['method']:8s} {e['status']:6d}  {e['url']}")
        return "\n".join(lines)
```

> **Line-by-line**
>
> - **① `max_size=100`**: **an in-memory list can't grow forever.** A full day would accumulate tens of thousands
> - **② `pop(0)` drops the oldest**: **the simplest ring-buffer implementation**
> - **③ `[-n:]`**: **slice out the last n.** When n exceeds the length it just starts at the beginning — no out-of-range error (Python slicing is forgiving)

## Step Five: Command Parsing (Where Bugs Love to Live)

**This is the part that needs the most care.** We need to turn:

```
GET /users/Cool-zimo/repos -params={per_page:5,sort:created} > out.json
```

into:

```python
{
    "method": "GET",
    "path": "/users/Cool-zimo/repos",
    "params": {"per_page": 5, "sort": "created"},
    "headers": {},
    "output": "out.json",
}
```

### Difficulty One: `-params={per_page:5}` Isn't Valid JSON

JSON requires quoted keys: `{"per_page": 5}`. **Typing quotes by hand is miserable**, so we accept bare keys.

```python
import re

def auto_quote(s):
    """Quote bare keys: {a:1} → {"a":1}"""
    # ① match key position: after { or ,, before :
    def repl(m):
        key = m.group(1)
        if key.startswith('"'):      # ② leave already-quoted keys alone
            return m.group(0)
        return f'"{key}":'

    # ③ regex: ({|,)\s*([^"{\[:,]+)\s*:
    pattern = re.compile(r'([{,]\s*)([^"\'{}\[\]:,\s]+)(\s*:)')
    return pattern.sub(lambda m: m.group(1) + '"' + m.group(2) + '"' + m.group(3), s)
```

**Test**:

```python
auto_quote("{per_page:5,sort:created}")
# '{"per_page":5,"sort":created}'    ← keys quoted, but the value `created` isn't
```

**Complete version** (handles keys *and* bare values):

```python
def parse_loose_json(s):
    """Parse "loose JSON": keys may be unquoted, string values may be unquoted"""
    # ① quote the keys first
    s = re.sub(r'([{,]\s*)([A-Za-z_][A-Za-z0-9_]*)(\s*:)', r'\1"\2"\3', s)

    # ② quote bare string values (skip true/false/null/numbers)
    def quote_value(m):
        v = m.group(2)
        if v in ("true", "false", "null") or re.match(r'^-?\d+(\.\d+)?$', v):
            return m.group(0)                    # ③ already a valid literal
        return f'{m.group(1)}"{v}"'

    s = re.sub(r'(:\s*)([^"{}\[\],\s]+)', quote_value, s)

    return json.loads(s)      # ④ now it parses normally
```

> **Line-by-line**
>
> - **① `[A-Za-z_][A-Za-z0-9_]*`**: **only quote keys that look like identifiers.** So `{a:1}` becomes `{"a":1}`, while `{"a":1}` doesn't match (already quoted) and isn't double-processed
> - **② Value handling**: `created` → `"created"`
> - **③ Exclude literals**: `true`/`false`/`null`/numbers **must not be quoted**, or `{"a": true}` becomes `{"a": "true"}` (a string!)
> - **④ `json.loads`**: after conversion it's standard JSON

**Note**: this function **isn't perfect** — deeply nested structures may trip it. But it's enough for simple hand-typed CLI arguments. **The engineering tradeoff: good enough beats perfect.**

### Difficulty Two: The `>` Redirect

```python
def split_output(raw):
    """Split off '> file'"""
    if " > " in raw:                    # ① require spaces on both sides
        raw, output = raw.rsplit(" > ", 1)   # ② split from the right, last one only
        return raw.strip(), output.strip()
    return raw, None
```

> - **① `" > "` with spaces**: **avoids misreading a `>` inside a URL or argument**
> - **② `rsplit(..., 1)`**: finds the first one from the right, so `a > b > c` splits at the last `>`

### Difficulty Three: `&` Inside URLs

**This is where landmines hide.** Suppose you want `&` as an argument separator:

```
GET /x & python "print(1)"
```

**But the URL built from params is full of `&`**:

```
https://api.github.com/repos?per_page=5&sort=created
```

**If you blindly do `if "&" in raw: split("&")`, your search conditions get cut in half — silently, with no error.**

**The right approach**: recognize only a **standalone `&` surrounded by spaces**.

```python
def has_separator(raw):
    """Whether an & separator is present"""
    return " & " in raw          # ① spaces required on both sides
```

> - **① `" & "`**: an `&` hugging other characters (as in a URL) won't match
>
> **The lesson from this trap**: **a separator must be stricter than the characters that can appear in the content.** That's the core principle of every parser design.

### The Complete Parser

```python
def parse_command(raw):
    """
    Parse one command line
    Returns dict: {method, path, params, headers, body, output}
    """
    raw, output = split_output(raw)

    parts = raw.split(None, 2)          # ① split into at most 3 pieces
    if len(parts) < 2:
        return None                      # ② need at least method and path

    method = parts[0].upper()
    path = parts[1]
    result = {
        "method": method,
        "path": path if path.startswith("/") else "/" + path,   # ③ auto-prepend /
        "params": None,
        "headers": None,
        "body": None,
        "output": output,
    }

    rest = parts[2] if len(parts) > 2 else ""

    # ④ extract -params={...}
    m = re.search(r'-params=(\{.*?\})(?:\s|$)', rest)
    if m:
        try:
            result["params"] = parse_loose_json(m.group(1))
        except Exception as e:
            return f"params parse failed: {e}"

    # ⑤ extract -headers={...}
    m = re.search(r'-headers=(\{.*?\})(?:\s|$)', rest)
    if m:
        try:
            result["headers"] = parse_loose_json(m.group(1))
        except Exception as e:
            return f"headers parse failed: {e}"

    # ⑥ extract a body (bare JSON)
    m = re.search(r'(\{.*\}|\[.*\])', rest)
    if m and method in ("POST", "PUT", "PATCH"):
        try:
            result["body"] = parse_loose_json(m.group(1))
        except Exception as e:
            return f"body parse failed: {e}"

    return result
```

> **Line-by-line**
>
> - **① `split(None, 2)`**: `None` means split on any whitespace; `2` means **at most 2 splits** (3 pieces). **This keeps everything after the path intact**
> - **② Too few args → None**: the caller must check
> - **③ Auto-prepend `/`**: typing `users/xxx` works. **Again: be forgiving**
> - **④⑤⑥ Regex extraction**: the `?` in `(\{.*?\})` is **non-greedy** — matches the shortest `{}`, avoiding swallowing two `{}` as one
> - **Returning a string signals an error**: **callers distinguish success with `isinstance(result, dict)`.** Not the most elegant design (raising would be better), but clear enough in a small tool

## Step Six: The Main Loop

```python
def main():
    client = Client()
    history = History()

    print("""
╔══════════════════════════════════════╗
║   ReqCLI v1.0  -  HTTP Terminal      ║
║   help for help  |  exit to quit     ║
╚══════════════════════════════════════╝
    """)

    while True:
        try:
            raw = input(">>> ").strip()      # ① strip surrounding whitespace
        except (EOFError, KeyboardInterrupt):   # ② Ctrl+D / Ctrl+C
            print("\nbye~")
            break

        if not raw:
            continue                          # ③ skip empty input

        # ④ built-in commands
        cmd = raw.lower()
        if cmd in ("exit", "quit"):
            print("bye~ 👋")
            break
        elif cmd in ("help", "h", "?"):
            print(HELP_TEXT)
            continue
        elif cmd == "history":
            print(history.show())
            continue
        elif cmd == "config":
            for k, v in CONFIG.items():
                shown = f"******({len(v)})" if k == "token" and v else str(v)   # ⑤ mask the token
                print(f"  {k:15s} = {shown}")
            continue
        elif cmd.startswith("set "):
            print(handle_set(cmd[4:].strip()))
            continue

        # ⑥ parse the command
        parsed = parse_command(raw)
        if parsed is None:
            print("❌ usage: METHOD /path [-params={...}] [> file]")
            continue
        if isinstance(parsed, str):        # ⑦ parse error; parsed holds the message
            print(f"❌ {parsed}")
            continue

        # ⑧ send the request
        import time
        start = time.time()
        r, err = client.request(
            parsed["method"], parsed["path"],
            params=parsed["params"],
            headers=parsed["headers"],
            body=parsed["body"],
        )

        if err:
            print(err)
            continue

        elapsed = time.time() - start
        history.add(parsed["method"], r.url, r.status_code)   # ⑨ record

        # ⑩ output
        if parsed["output"]:
            print(save_response(r, parsed["output"]))
        else:
            print(f"\n{format_response(r, elapsed)}\n")
```

> **Line-by-line**
>
> - **① `input().strip()`**: **must strip**, or one extra space breaks built-in command matching
> - **② `EOFError, KeyboardInterrupt`**: **handle Ctrl+D (pipe closed) and Ctrl+C (user interrupt) gracefully.** Without this you get an ugly red traceback
> - **③ Skip empty input**: otherwise it falls through to parsing and reports nonsense errors
> - **④ Built-ins before request parsing**: `config` isn't an HTTP method
> - **⑤ Mask the token**: **the `config` command must never print it**
> - **⑦ `isinstance(parsed, str)`**: the price of the "return a string for errors" design — **callers must check the type.** Redone properly, this would raise
> - **⑨ `r.url`**: **requests records the final URL** (with query params joined). More informative than the raw path
> - **⑩ Saving beats printing**: with `> file`, don't dump to the screen (a large response would flood it)

## Assembling It All

The complete file (**copy and run as-is**):

```python
#!/usr/bin/env python3
"""reqcli.py - a usable HTTP command-line tool"""

import os
import re
import json
import time
from datetime import datetime

import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

# ================= Config =================
CONFIG = {
    "base_url": "https://api.github.com",
    "user_agent": "ReqCLI/1.0",
    "accept": "application/vnd.github+json",
    "token": os.environ.get("GITHUB_TOKEN", ""),
    "timeout": 10,
    "max_retries": 2,
}

HELP_TEXT = """
📌 Requests:
  METHOD /path [-params={...}] [-headers={...}] [body] [> file]

📌 Built-ins:
  help / h / ?    show help
  config          show current config
  set <k> <v>     change config (base_url/token/timeout)
  history         last 10 requests
  exit / quit     quit
"""


# ================= HTTP client =================
class Client:

            "User-Agent": CONFIG["user_agent"],
            "Accept": CONFIG["accept"],

    def _mount_adapter(self):

            total=CONFIG["max_retries"],

            allowed_methods=["GET", "HEAD", "PUT", "DELETE", "OPTIONS"],
            raise_on_status=False,
        )
        adapter = HTTPAdapter(max_retries=retry, pool_connections=10, pool_maxsize=10)
        self.session.mount("https://", adapter)
        self.session.mount("http://", adapter)

    def request(self, method, path, params=None, headers=None, body=None):
        url = CONFIG["base_url"] + path
        req_headers = {}
        if CONFIG["token"]:
            req_headers["Authorization"] = f"Bearer {CONFIG['token']}"
        if headers:
            req_headers.update(headers)

        try:
            r = self.session.request(
                method, url, params=params, headers=req_headers,
                json=body, timeout=CONFIG["timeout"],
            )
            return r, None
        except requests.exceptions.Timeout:
            return None, f"⏱ request timed out ({CONFIG['timeout']}s)"
        except requests.exceptions.ConnectionError:
            return None, "🔌 connection failed"
        except requests.exceptions.RequestException as e:
            return None, f"❌ request failed: {e}"


# ================= Formatting =================
def format_response(r, elapsed):
    hint = STATUS_HINT.get(r.status_code, "")
    lines = [f"HTTP {r.status_code} {hint}  ({elapsed:.2f}s)", "-" * 50]
    try:
        lines.append(json.dumps(r.json(), indent=2, ensure_ascii=False))
    except ValueError:
        lines.append(r.text.strip() or "(empty body)")

    remaining = r.headers.get("X-RateLimit-Remaining")
    if remaining is not None:
        lines.append("")
        lines.append(f"📊 quota left: {remaining}/{r.headers.get('X-RateLimit-Limit','?')}")
    return "\n".join(lines)


def save_response(r, path):
    try:
        ctype = r.headers.get("Content-Type", "")
        if "json" in ctype or "text" in ctype:
            try:
                text = json.dumps(r.json(), indent=2, ensure_ascii=False)
            except ValueError:
                text = r.text
            with open(path, "w", encoding="utf-8") as f:
                f.write(text)
        else:
            with open(path, "wb") as f:
                f.write(r.content)
        return f"✅ saved to {path}"
    except OSError as e:
        return f"❌ save failed: {e}"


# ================= History =================
class History:
    def __init__(self, max_size=100):
        self.entries = []
        self.max_size = max_size

    def add(self, method, url, status):
        self.entries.append({
            "time": datetime.now().strftime("%H:%M:%S"),
            "method": method, "url": url, "status": status,
        })
        if len(self.entries) > self.max_size:
            self.entries.pop(0)

    def show(self, n=10):
        if not self.entries:
            return "  (no records)"
        return "\n".join(
            f"  {e['time']} {e['method']:8s} {e['status']:6d}  {e['url']}"
            for e in self.entries[-n:]
        )


# ================= Parsing =================
def parse_loose_json(s):
    s = re.sub(r'([{,]\s*)([A-Za-z_][A-Za-z0-9_]*)(\s*:)', r'\1"\2"\3', s)

    def quote_value(m):
        v = m.group(2)
        if v in ("true", "false", "null") or re.match(r'^-?\d+(\.\d+)?$', v):
            return m.group(0)
        return f'{m.group(1)}"{v}"'

    s = re.sub(r'(:\s*)([^"{}\[\],\s]+)', quote_value, s)
    return json.loads(s)


def split_output(raw):
    if " > " in raw:
        raw, output = raw.rsplit(" > ", 1)
        return raw.strip(), output.strip()
    return raw, None


def parse_command(raw):
    raw, output = split_output(raw)
    parts = raw.split(None, 2)
    if len(parts) < 2:
        return None

    method = parts[0].upper()
    path = parts[1]
    result = {
        "method": method,
        "path": path if path.startswith("/") else "/" + path,
        "params": None, "headers": None, "body": None, "output": output,
    }
    rest = parts[2] if len(parts) > 2 else ""

    m = re.search(r'-params=(\{.*?\})(?:\s|$)', rest)
    if m:
        try:
            result["params"] = parse_loose_json(m.group(1))
        except Exception as e:
            return f"params parse failed: {e}"

    m = re.search(r'-headers=(\{.*?\})(?:\s|$)', rest)
    if m:
        try:
            result["headers"] = parse_loose_json(m.group(1))
        except Exception as e:
            return f"headers parse failed: {e}"

    m = re.search(r'(\{.*\}|\[.*\])', rest)
    if m and method in ("POST", "PUT", "PATCH"):
        try:
            result["body"] = parse_loose_json(m.group(1))
        except Exception as e:
            return f"body parse failed: {e}"

    return result


# ================= Config commands =================
def handle_set(arg):
    parts = arg.split(" ", 1)
    if len(parts) < 2:
        return "usage: set <key> <value>"
    key, value = parts[0].lower(), parts[1].strip()

    if key == "base_url":
        if not value.startswith("http"):
            value = "https://" + value
        CONFIG[key] = value.rstrip("/")
        return f"✅ base_url = {CONFIG[key]}"
    elif key == "token":
        CONFIG[key] = value
        return f"✅ token updated (length {len(value)})"
    elif key == "timeout":
        try:
            CONFIG["timeout"] = int(value)
        except ValueError:
            return "❌ timeout must be a number"
        return f"✅ timeout = {value}s"
    return f"❌ unknown config: {key}"


# ================= Main loop =================
def main():
    client = Client()
    history = History()

    print("""
╔══════════════════════════════════════╗
║   ReqCLI v1.0  -  HTTP Terminal      ║
║   help for help  |  exit to quit     ║
╚══════════════════════════════════════╝
    """)

    while True:
        try:
            raw = input(">>> ").strip()
        except (EOFError, KeyboardInterrupt):
            print("\nbye~")
            break

        if not raw:
            continue

        cmd = raw.lower()
        if cmd in ("exit", "quit"):
            print("bye~ 👋")
            break
        elif cmd in ("help", "h", "?"):
            print(HELP_TEXT)
            continue
        elif cmd == "history":
            print(history.show())
            continue
        elif cmd == "config":
            for k, v in CONFIG.items():
                shown = f"******({len(v)})" if k == "token" and v else str(v)
                print(f"  {k:15s} = {shown}")
            continue
        elif cmd.startswith("set "):
            print(handle_set(cmd[4:].strip()))
            continue

        parsed = parse_command(raw)
        if parsed is None:
            print("❌ usage: METHOD /path [-params={...}] [> file]")
            continue
        if isinstance(parsed, str):
            print(f"❌ {parsed}")
            continue

        start = time.time()
        r, err = client.request(
            parsed["method"], parsed["path"],
            params=parsed["params"], headers=parsed["headers"], body=parsed["body"],
        )
        if err:
            print(err)
            continue

        elapsed = time.time() - start
        history.add(parsed["method"], r.url, r.status_code)

        if parsed["output"]:
            print(save_response(r, parsed["output"]))
        else:
            print(f"\n{format_response(r, elapsed)}\n")


if __name__ == "__main__":
    main()
```

## Crash Site

### Crash One: The Trailing Slash on base_url

```python
# ❌ user runs: set base_url https://api.github.com/
CONFIG["base_url"] + "/users"     # https://api.github.com//users  ← double slash
```

**Symptom**: 404, or the server returns something odd.

**Cause**: a double slash in a URL is **meaningful** (a different path).

**Lesson**: **normalize with `rstrip("/")`.** That's exactly why `handle_set` does it.

### Crash Two: Forgetting `ensure_ascii=False`

```python
# ❌
json.dumps({"name": "张三"})
# '{"name": "\\u5f20\\u4e09"}'    ← non-ASCII escaped
```

**Symptom**: output full of `\uXXXX`, unreadable.

**Cause**: `json.dumps` defaults to `ensure_ascii=True`, **escaping every non-ASCII character.**

**Lesson**: **always add `ensure_ascii=False` when output is for humans.**

(**Note**: for network transfer or machine-read files, the default `True` is safer — it avoids encoding issues. **Decide by use case.**)

### Crash Three: Greedy Regex Eating Two Arguments

```python
# ❌ greedy
re.search(r'-params=(\{.*\})', "-params={a:1} -headers={b:2}")
# matches: {a:1} -headers={b:2}     ← swallowed headers too!

# ✅ non-greedy
re.search(r'-params=(\{.*?\})', "-params={a:1} -headers={b:2}")
# matches: {a:1}
```

**Symptom**: the parsed params mysteriously contain what came after.

**Cause**: `.*` is greedy and matches up to **the last** `}`.

**Lesson**: **use `.*?` (non-greedy).** One of the most common regex traps.

### Crash Four: Built-in Commands Colliding With Paths

```python
# user types
>>> get /config
```

**Symptom**: if the built-in check is `if raw.startswith("config")`, this request is treated as the `config` command.

**Cause**: **the built-in check is too loose.**

**Lesson**: **match built-ins exactly** (`cmd == "config"`), not with `startswith`. Our code uses `cmd.startswith("set ")` (**with the space**), which is far less likely to collide with a path.

### Crash Five: Exception Order

```python
# ❌ wrong order
try:
    ...
except requests.exceptions.RequestException as e:    # ① parent first
    ...
except requests.exceptions.Timeout:                   # ② child after — unreachable
    ...
```

**Symptom**: timeouts get handled as "generic request failure," so the message is less precise.

**Cause**: **`Timeout` is a subclass of `RequestException`.** Python matches the first applicable except in order.

**Lesson**: **subclasses first, parent last.**

## Summary

- **Module split**: config / client / formatter / history / parser / main loop, each minding its own
- **Client**: Session + `HTTPAdapter(max_retries=Retry(...))` + `mount` before requests + **always set timeout**
- **`Retry` parameters**: `total` (excludes the first try), `status_forcelist` (only 5xx/429), **`allowed_methods` excludes POST**
- **Read the token from env; mask it when showing config**
- **`rstrip("/")` on base_url; auto-prepend `/` to path**
- **JSON output with `ensure_ascii=False`**; write files with `encoding="utf-8"`
- **Use non-greedy `.*?`** or you'll swallow later arguments
- **Separators need surrounding spaces** (`" & "`, `" > "`) to avoid colliding with URL characters
- **Catch subclasses before the parent**
- **A REPL must handle `EOFError` / `KeyboardInterrupt`**, or Ctrl+C prints a traceback
- ❌ Don't skip timeout; don't retry POST; don't echo tokens; don't use greedy regex; don't write `data=` where `json=` belongs

```quiz
q: What's the correct way to send a JSON request body with requests?
```
