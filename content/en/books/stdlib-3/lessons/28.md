# The Statistics Layer: Multi-Dimensional Aggregation

> This lesson uses Counter / defaultdict / itertools from Chapter 3 to run multi-dimensional statistics over the parsed logs — level distribution, time distribution, top N errors, and per-module rankings.

## Level Distribution in One Line with `Counter`

```python
from collections import Counter

level_counts = Counter(entry.level for entry in entries)
print(level_counts)
print(dict(level_counts))
print(level_counts.most_common())
```

Output:

```
Counter({'INFO': 8, 'ERROR': 8, 'WARN': 3, 'DEBUG': 2})
{'INFO': 8, 'ERROR': 8, 'WARN': 3, 'DEBUG': 2}
[('INFO', 8), ('ERROR', 8), ('WARN', 3), ('DEBUG', 2)]
```

`Counter` accepts a generator expression and does the counting in one pass. `most_common()` returns the rankings directly.

## Time Distribution: Aggregating by Hour

```python
hourly = Counter(entry.hour for entry in entries)
for hour in sorted(hourly.keys()):
    bar = "█" * hourly[hour]
    print(f"{hour}:00 | {bar} ({hourly[hour]})")
```

Output:

```
10:00 | ██████ (6)
11:00 | █████ (5)
12:00 | ████ (4)
13:00 | ████ (5)
```

At a glance you can see **the hour from 10:00 had the densest log activity**, making it the prime candidate for investigation.

## Top N Errors: The Most Frequent Messages

```python
error_messages = Counter(
    entry.message for entry in entries if entry.level == "ERROR"
)
print("Top 5 errors:")
for msg, count in error_messages.most_common(5):
    print(f"  [{count:>2} times] {msg}")
```

Output:

```
Top 5 errors:
  [ 3 times] user login failed
  [ 2 times] connection timed out
  [ 2 times] token expired
  [ 1 times] payment timed out
```

**"user login failed" appeared 3 times, the most frequent error** — the signal operations should pay the most attention to.

## Per-Module Statistics: Where `defaultdict` Shines

To find out how many ERRORs each module generated:

```python
from collections import defaultdict

module_errors = defaultdict(int)
for entry in entries:
    if entry.level == "ERROR":
        module_errors[entry.module] += 1

# sort by count descending
sorted_modules = sorted(module_errors.items(), key=lambda x: x[1], reverse=True)
for module, count in sorted_modules:
    print(f"  {module:<8} {count} ERROR(s)")
```

Output:

```
  auth     4 ERROR(s)
  db       2 ERROR(s)
  payment  1 ERROR(s)
```

The advantage of `defaultdict(int)` is that **accessing a missing key automatically returns 0**, so you never write `if key not in dict` checks.

## Combined Dimensions: A Module × Level Crosstab

```python
# count entries per level per module
module_level = defaultdict(lambda: defaultdict(int))
for entry in entries:
    module_level[entry.module][entry.level] += 1

print(f"{'module':<10} {'DEBUG':<8} {'INFO':<8} {'WARN':<8} {'ERROR':<8}")
print("-" * 50)
for module in sorted(module_level.keys()):
    levels = module_level[module]
    print(f"{module:<10} {levels.get('DEBUG', 0):<8} {levels.get('INFO', 0):<8} "
          f"{levels.get('WARN', 0):<8} {levels.get('ERROR', 0):<8}")
```

Output:

```
module     DEBUG   INFO    WARN    ERROR
--------------------------------------------------
auth       0       0       0       4
cache      2       0       0       0
db         0       0       1       2
order      0       6       0       0
payment    0       0       2       1
```

This crosstab immediately shows: **the order module is all INFO (healthy), while the auth module is all ERROR (errors concentrated there).**

## The Complete Statistics Module

```python
from collections import Counter, defaultdict


def level_distribution(entries: list) -> dict[str, int]:
    """Count entries per level"""
    return dict(Counter(e.level for e in entries))


def hourly_distribution(entries: list) -> dict[str, int]:
    """Count entries per hour (sorted by hour)"""
    return dict(sorted(Counter(e.hour for e in entries).items()))


def top_errors(entries: list, n: int = 10) -> list[tuple[str, int]]:
    """Top N error messages"""
    return Counter(e.message for e in entries if e.level == "ERROR").most_common(n)


def module_error_count(entries: list) -> dict[str, int]:
    """ERROR count per module (descending)"""
    d = defaultdict(int)
    for e in entries:
        if e.level == "ERROR":
            d[e.module] += 1
    return dict(sorted(d.items(), key=lambda x: x[1], reverse=True))


def module_level_matrix(entries: list) -> dict[str, dict[str, int]]:
    """Module x level crosstab"""
    result = defaultdict(lambda: defaultdict(int))
    for e in entries:
        result[e.module][e.level] += 1
    return {k: dict(v) for k, v in result.items()}
```

## Crash Site: Counting with `list.count` Inside a Loop

```python
# WRONG: O(n²) complexity
levels = [e.level for e in entries]
unique_levels = list(set(levels))
counts = {}
for lvl in unique_levels:
    counts[lvl] = levels.count(lvl)  # every count() scans the whole list again
print(counts)
```

**The problem**: `list.count()` is an O(n) operation, and wrapping it in a loop makes the whole thing O(n²). Twenty entries is fine; two million is a difference of dozens of seconds. `Counter` does it in a single pass at O(n).

## Crash Site: Forgetting to Initialise When Counting with a Plain `dict`

```python
# WRONG: KeyError
module_errors = {}
for e in entries:
    if e.level == "ERROR":
        module_errors[e.module] += 1  # KeyError: 'auth' - the first access hits a missing key
```

**Error output**:

```
KeyError: 'auth'
```

**Two fixes**:

```python
# approach 1: get with a default
module_errors[e.module] = module_errors.get(e.module, 0) + 1

# approach 2: defaultdict (recommended)
from collections import defaultdict
module_errors = defaultdict(int)
module_errors[e.module] += 1  # a missing key auto-initialises to 0
```

## Crash Site: `Counter.most_common()` Results Are Unstable

```python
from collections import Counter

c = Counter()
c["a"] = 2
c["b"] = 2
c["c"] = 1
print(c.most_common())  # [('a', 2), ('b', 2), ('c', 1)]
# but what if "b" was counted first?
```

**Watch out**: when counts tie, the order returned by `most_common()` is **not guaranteed to be stable** (it depends on insertion order). If you need a stable secondary sort (e.g. alphabetical), write it yourself:

```python
sorted(c.items(), key=lambda x: (-x[1], x[0]))
# sort descending by count first, then ascending alphabetically by key
```

## Summary

- `Counter` is the one-line weapon for frequency counting, with `most_common()` producing rankings directly.
- `defaultdict(int)` removes manual initialisation and keeps counting code concise.
- Multi-dimensional statistics = combining `Counter` + `defaultdict`.
- A crosstab (module × level) is a powerful diagnostic tool.
- Avoid `list.count()` inside loops; it's O(n²).
- The statistics layer takes plain data in and returns plain data out — no file I/O.
