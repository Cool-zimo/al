# The Output Layer: Multiple Formats and Tool Logging

> This lesson makes statistics visible and storable — console tables, JSON export, and CSV export working together, plus using logging to record the tool's own runtime activity.

## What the Output Layer Does

The statistics layer produces Python dictionaries — neither human-readable nor suitable for sending to someone else. The output layer turns that data into:

1. **Console tables** — for reading directly during development and debugging
2. **JSON** — convenient for inter-program communication and web API responses
3. **CSV** — convenient for importing into Excel for further analysis

The output layer takes plain dictionaries and lists as input and returns strings (or writes to files). It neither knows nor cares where the data came from.

## Console Tables

```python
def format_stats_table(stats: dict) -> str:
    """Format statistics as a console table"""
    lines = []

    # level distribution table
    lines.append("=" * 50)
    lines.append("Log level distribution")
    lines.append("=" * 50)
    lines.append(f"{'level':<10} {'count':<10} {'share':<10}")
    lines.append("-" * 50)
    total = sum(stats["level_counts"].values())
    for level, count in sorted(stats["level_counts"].items(),
                                key=lambda x: x[1], reverse=True):
        ratio = count / total * 100 if total else 0
        lines.append(f"{level:<10} {count:<10} {ratio:.1f}%")

    # hourly distribution
    lines.append("")
    lines.append("=" * 50)
    lines.append("Hourly log volume")
    lines.append("=" * 50)
    for hour, count in stats["hourly_counts"].items():
        bar = "█" * count
        lines.append(f"  {hour}:00 | {bar} {count}")

    # top errors
    lines.append("")
    lines.append("=" * 50)
    lines.append("Top 5 errors")
    lines.append("=" * 50)
    for i, (msg, count) in enumerate(stats["top_errors"], 1):
        lines.append(f"  {i}. [{count:>2} times] {msg}")

    return "\n".join(lines)


# usage example
stats = {
    "level_counts": {"INFO": 8, "ERROR": 8, "WARN": 3, "DEBUG": 2},
    "hourly_counts": {"10": 6, "11": 5, "12": 4, "13": 5},
    "top_errors": [("user login failed", 3), ("connection timed out", 2), ("token expired", 2)],
}
print(format_stats_table(stats))
```

Output:

## JSON Export

```python
import json


def export_json(stats: dict, indent: int = 2) -> str:
    """Export as a JSON string"""
    return json.dumps(stats, ensure_ascii=False, indent=indent)


json_str = export_json(stats)
print(json_str[:200])
```

Output:

```json
{
  "level_counts": {
    "INFO": 8,
    "ERROR": 8,
    "WARN": 3,
    "DEBUG": 2
  },
  "hourly_counts": {
    "10": 6,
    "11": 5,
    "12": 4,
    "13": 5
  },
  ...
```

**`ensure_ascii=False` is essential** — without it, non-ASCII characters become `\u7528\u6237\u767b\u5f55\u5931\u8d25`, which is unreadable.

## CSV Export

```python
import csv
import io


def export_csv(stats: dict) -> str:
    """Export as a CSV string"""
    buf = io.StringIO()
    writer = csv.writer(buf)

    # write level distribution
    writer.writerow(["type", "name", "count"])
    for level, count in stats["level_counts"].items():
        writer.writerow(["level", level, count])

    # write top errors
    for msg, count in stats["top_errors"]:
        writer.writerow(["error", msg, count])

    return buf.getvalue()


csv_str = export_csv(stats)
print(csv_str)
```

Output:

```
type,name,count
level,INFO,8
level,ERROR,8
level,WARN,3
level,DEBUG,2
error,user login failed,3
error,connection timed out,2
error,token expired,2
```

This can be pasted straight into Excel or pandas for visualisation.

## The Tool's Own Logging: Using `logging` to Record Runtime

Make sure to distinguish two concepts:

- **Business logs**: the **object** of our analysis ("2026-01-15 [ERROR] login failed")
- **Tool logs**: records of logalyzer running ("started parsing file", "parsing complete: 1024 succeeded, 3 failed")

The tool itself uses the logging module:

```python
import logging


def setup_logger(verbose: bool = False) -> logging.Logger:
    """Configure the tool's own logger"""
    logger = logging.getLogger("logalyzer")
    logger.setLevel(logging.DEBUG if verbose else logging.INFO)

    handler = logging.StreamHandler()
    formatter = logging.Formatter(
        "[%(asctime)s] %(levelname)s %(name)s: %(message)s",
        datefmt="%H:%M:%S",
    )
    handler.setFormatter(formatter)
    logger.addHandler(handler)
    return logger


# usage
logger = setup_logger(verbose=True)
logger.info("Started analysing log file")
logger.debug(f"regex pattern: {LOG_PATTERN.pattern}")
logger.info("Parsing complete: 1024 succeeded, 3 failed")
logger.warning("3 lines could not be parsed and were skipped")
logger.info("Statistics complete, generating report")
```

Output:

```
[10:23:45] INFO logalyzer: Started analysing log file
[10:23:45] DEBUG logalyzer: regex pattern: ^(\d{4}-\d{2}-\d{2} ...
[10:23:45] INFO logalyzer: Parsing complete: 1024 succeeded, 3 failed
[10:23:45] WARNING logalyzer: 3 lines could not be parsed and were skipped
[10:23:45] INFO logalyzer: Statistics complete, generating report
```

## The Complete Output Layer

```python
import json
import csv
import io
import logging
from collections import Counter, defaultdict


def format_table(entries: list, max_rows: int = 20) -> str:
    """Console table output"""
    lines = []
    lines.append(f"{'time':<22} {'level':<8} {'module':<10} message")
    lines.append("-" * 80)
    for e in entries[:max_rows]:
        msg = e.message[:50]
        lines.append(f"{e.timestamp:<22} {e.level:<8} {e.module:<10} {msg}")
    if len(entries) > max_rows:
        lines.append(f"... {len(entries)} entries total, showing first {max_rows}")
    return "\n".join(lines)


def build_stats(entries: list) -> dict:
    """Build a statistics report from entries"""
    return {
        "level_counts": dict(Counter(e.level for e in entries)),
        "hourly_counts": dict(sorted(Counter(e.hour for e in entries).items())),
        "top_errors": Counter(
            e.message for e in entries if e.level == "ERROR"
        ).most_common(5),
        "total": len(entries),
    }


def export_json(stats: dict, indent: int = 2) -> str:
    return json.dumps(stats, ensure_ascii=False, indent=indent)


def export_csv(stats: dict) -> str:
    buf = io.StringIO()
    writer = csv.writer(buf)
    writer.writerow(["type", "name", "count"])
    for level, count in stats["level_counts"].items():
        writer.writerow(["level", level, count])
    for msg, count in stats["top_errors"]:
        writer.writerow(["error", msg, count])
    return buf.getvalue()


def setup_logger(verbose: bool = False) -> logging.Logger:
    logger = logging.getLogger("logalyzer")
    if logger.handlers:
        return logger  # avoid adding the handler twice
    logger.setLevel(logging.DEBUG if verbose else logging.INFO)
    handler = logging.StreamHandler()
    fmt = logging.Formatter(
        "[%(asctime)s] %(levelname)s %(name)s: %(message)s",
        datefmt="%H:%M:%S",
    )
    handler.setFormatter(fmt)
    logger.addHandler(handler)
    return logger
```

## Crash Site: JSON Export Turns Everything into Unicode Escapes

```python
import json

data = {"message": "user login failed"}

# WRONG: the default ensure_ascii=True
print(json.dumps(data))
# output: {"message": "\u7528\u6237\u767b\u5f55\u5931\u8d25"}
```

**Error output**: `{"message": "\u7528\u6237\u767b\u5f55\u5931\u8d25"}` — the program can read it, but a human can't, which makes debugging painful.

**The fix**: `json.dumps(data, ensure_ascii=False)` → `{"message": "user login failed"}`

## Crash Site: Hand-Rolled CSV with `\n` Causes Encoding Issues

```python
# WRONG: raw string concatenation
csv_text = "level,count\nERROR,8\nINFO,5\n"
with open("report.csv", "w") as f:
    f.write(csv_text)
```

**The problem**: opening the file in Excel on Windows may mangle non-ASCII characters, and line endings can become `\r\r\n` in some environments.

**The fix**: use the `csv` module and specify the encoding:

```python
import csv

with open("report.csv", "w", newline="", encoding="utf-8-sig") as f:
    writer = csv.writer(f)
    writer.writerow(["level", "count"])
    writer.writerow(["ERROR", 8])
```

`utf-8-sig` writes a BOM at the start of the file, so Excel won't garble the text.

## Crash Site: A Logger Grows Duplicate Handlers and Doubles the Output

```python
import logging

def get_logger():
    logger = logging.getLogger("myapp")
    logger.setLevel(logging.INFO)
    handler = logging.StreamHandler()
    logger.addHandler(handler)  # adds one every time it's called!
    return logger

log1 = get_logger()
log2 = get_logger()
log1.info("hello")
```

**Error output**:

```
hello
hello
```

**Every line printed twice!** Because `getLogger` returns the same logger instance, the handler gets added twice.

**The fix**: check before adding the handler:

```python
def get_logger():
    logger = logging.getLogger("myapp")
    if logger.handlers:
        return logger  # already has a handler, just return it
    logger.setLevel(logging.INFO)
    handler = logging.StreamHandler()
    logger.addHandler(handler)
    return logger
```

## Summary

- The output layer turns statistics into something humans can read or machines can parse.
- Console tables suit debugging; JSON suits program-to-program transfer; CSV suits Excel import.
- JSON export must use `ensure_ascii=False`, otherwise non-ASCII text becomes Unicode escapes.
- CSV export should use the `csv` module with `utf-8-sig` encoding for Excel compatibility.
- The tool's own runtime logs use logging — a different concern from the business logs being analysed.
- Avoid duplicate handlers on a logger, which would double the output.
