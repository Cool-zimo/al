# Advanced Parameters Review

> This lesson does not re-teach concepts. It does three things: **recap the key points in thirty seconds, correct the three most common mistakes, and test whether you really understand it.**
> If anything in the recap looks unfamiliar, go back and read Lesson 17 of the *Learning* book first, then come back and do the exercises.

## 30-Second Recap

```python
def greet(name, greeting="Hello"):       # greeting has a default value
    print(greeting + ", " + name)

greet("Alice")                          # Hello, Alice
greet("Bob", "Good morning")            # Good morning, Bob
greet(name="Carol", greeting="Evening")  # Evening, Carol -- keyword argument
```

| Syntax | Meaning | Example |
|---|---|---|
| `def f(a, b=1)` | `b` has a default | `f(10)` works |
| `f(b=2, a=1)` | Keyword arguments, any order | No error |
| `def f(*args)` | Collects extra positional args into a **tuple** | `args=(1,2,3)` |
| `def f(**kwargs)` | Collects extra keyword args into a **dict** | `kwargs={'a':1}` |

Advanced parameters come down to three things: **giving parameters default values, passing them by name, and collecting a bunch of parameters at once.**

## Three Things People Get Wrong

### 1. Using a mutable object as a default argument (the classic trap)

This is the most famous gotcha in Python — no contest.

```python
# WRONG
def add_item(item, lst=[]):
    lst.append(item)
    return lst

print(add_item(1))     # [1]
print(add_item(2))     # [1, 2]  -- not [2]!
print(add_item(3))     # [1, 2, 3]
```

Why? Because **the default `lst=[]` is created only once, when the function is defined**. Every subsequent call reuses the same list. What you thought was "an empty list" is actually the same list, accumulating entries forever.

The correct approach is to use `None` as a placeholder and create the list inside the function:

```python
def add_item(item, lst=None):
    if lst is None:
        lst = []               # a fresh list every call
    lst.append(item)
    return lst

print(add_item(1))     # [1]
print(add_item(2))     # [2]
print(add_item(3))     # [3]
```

Memorize this line: **Default arguments should always be immutable objects (`None`, numbers, strings, tuples). Never use lists or dicts.**

### 2. Positional arguments cannot come after keyword arguments

```python
def greet(name, greeting="Hello"):
    print(greeting + ", " + name)

# WRONG
greet(name="Alice", "Good morning")
```

```
SyntaxError: positional argument follows keyword argument
```

The rule is: **once you use a keyword argument, every argument after it must also be a keyword.** Python requires "positional arguments first, keyword arguments after."

Correct versions: either all positional, or put keywords at the end.

```python
greet("Alice", "Good morning")            # all positional, fine
greet("Alice", greeting="Good morning")   # mixed: positional first, keyword last, fine
```

### 3. `*args` and `**kwargs` collect only the "leftover" arguments

```python
def show(name, *args, **kwargs):
    print("name:", name)
    print("args:", args)        # leftover positional args, a tuple
    print("kwargs:", kwargs)    # leftover keyword args, a dict

show("Alice", 90, 85, city="London", age=18)
# name: Alice
# args: (90, 85)
# kwargs: {'city': 'London', 'age': 18}
```

`*args` collects **positional arguments** into a tuple; `**kwargs` collects **keyword arguments** into a dict. They are used to write functions with "an uncertain number of parameters."

Note that the `*` and `**` in the names are syntax; **`args` and `kwargs` are just conventions** — you could use other names.

## Crash Site: Two `**` collectors in one function

```python
# WRONG
def f(*args, **args2, **args3):
    pass
```

```
SyntaxError: invalid syntax
```

A function can only have **one `*` collector and one `**` collector**; any more and Python would not know where to put things. The correct order is always: `ordinary parameters -> *args -> **kwargs`.

```python
def f(a, b=10, *args, **kwargs):   # order: ordinary -> default -> * -> **
    pass
```

The most common real-world pattern is: **`def f(*args, **kwargs)`**, meaning "I accept any arguments at all." You see it when writing decorators or wrapper functions.

## Summary

- **Never use mutable objects as default arguments**; use `None` as a placeholder and create them inside the function
- Positional arguments must come **before** keyword arguments
- `*args` collects leftover positional args into a tuple; `**kwargs` collects leftover keyword args into a dict
- A function can only have one `*` group and one `**` group, in a fixed order
