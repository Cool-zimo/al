# Lists — Reinforced

> This lesson does not introduce new concepts. It does three things: **recaps the key points in thirty seconds, corrects the three mistakes people make most often, and tests whether you actually understand it through exercises.**
> This lesson corresponds to Lesson 11 of *Essential Python*. If any sentence in the recap looks unfamiliar, go back to Lesson 11 of *Essential Python* and come back to the exercises afterwards.

## 30-Second Recap

```python
nums = [10, 20, 30, 40, 50]
print(nums[0])     # 10      positive index starts at 0
print(nums[-1])    # 50      negative index counts from the end; -1 is the last
print(nums[1:4])   # [20, 30, 40]   slice includes left, excludes right
print(nums[::2])   # [10, 30, 50]   step 2
```

| Operation | Syntax | Effect |
|---|---|---|
| access | `a[i]` | the i-th element |
| assign | `a[i] = x` | in-place modification |
| append | `a.append(x)` | add one at the end |
| delete | `del a[i]` | remove at the given position |
| test | `x in a` | is it present? |
| length | `len(a)` | number of elements |

Lists are **mutable**: changing one position, adding one, or removing one all operates on the same list — no new list is created.

## Three Things People Get Wrong

### 1. Slices "include left, exclude right" — one short at the boundary

```python
a = [0, 1, 2, 3, 4, 5]
print(a[1:4])   # [1, 2, 3]   —— note: 4 is not in there
```

This is Python's most consistent slicing rule: the interval is left-closed, right-open `[start, stop)`. `a[1:4]` takes positions 1, 2, 3 — exactly `4 - 1 = 3` elements. So **to take "the first 3", write `a[:3]`**, not `a[:2]`.

Negative indices follow the same logic:

```python
a = [0, 1, 2, 3, 4, 5]
print(a[-3:])    # [3, 4, 5]   the last 3
print(a[:-1])    # [0, 1, 2, 3, 4]   drop the last one
```

### 2. `b = a` is not a copy — it is the same list

```python
a = [1, 2, 3]
b = a            # no new list is created, just another label
b.append(4)
print(a)         # [1, 2, 3, 4]   a changed too
```

After `b = a`, `a` and `b` point at **the same object**. `id(a) == id(b)` is `True`. So changing `b` is changing `a`.

There are several ways to get an independent copy:

```python
b = a[:]          # slice copy, most直观
b = a.copy()      # the list's own method
b = list(a)       # use the constructor
```

All three work. But note: **they are all "shallow copies"** — when the list contains other lists, those inner lists are still the same object. That gets its own dedicated section later.

### 3. `in` tests for value, not position

```python
nums = [10, 20, 30]
print(20 in nums)    # True
print(15 in nums)    # False
```

`in` compares against each element left to right, returning `True` when it finds a match. The longer the list and the later the value, the slower it gets on average — **`in` on a list is O(n)**. If you have a lot of data and search "is it there?" frequently, use a set, which is O(1). That is Lesson 15 — just keep it in mind for now.

## Crash Site: A shallow copy only copies one layer

```python
# WRONG
a = [[1, 2], [3, 4]]
b = a[:]
b[0].append(99)
print(a)    # [[1, 2, 99], [3, 4]]   a was changed too
```

```
# the cause is not an error but "behaviour that defies intuition"
# b[0] and a[0] point at the same inner list
```

A slice copy only duplicates **the outermost layer**; the two inner lists `[1, 2]` and `[3, 4]` are still the original objects. So modifying `b[0]` is the same as modifying `a[0]`.

To copy the inner objects too, use `copy.deepcopy`:

```python
import copy
a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)
b[0].append(99)
print(a)    # [[1, 2], [3, 4]]   a is fine
print(b)    # [[1, 2, 99], [3, 4]]
```

For this lesson, it is enough to understand the boundary between "shallow" and "deep". For everyday lists, a shallow copy (slice or `.copy()`) is enough **except** when your list contains mutable objects and you need an independent copy — that is when you reach for `deepcopy`.

## Summary

- Slices are left-closed, right-open: `a[1:4]` takes positions 1, 2, 3
- Negative indices count from the end: `-1` is the last element
- `b = a` is aliasing, not copying; `b = a[:]` or `b = a.copy()` makes a new list
- A shallow copy only copies one layer; nested structures need `copy.deepcopy`
- `in` on a list is O(n); for large data, switch to a set

## Section Quiz

```quiz
type: choice
exam: true
q: After running the following code, what is the value of a?
code: |
  a = [1, 2, 3]
  b = a
  b = b + [4]
options:
- "[1, 2, 3, 4]"
- "[1, 2, 3]"
- "[1, 2, 3, [4]]"
- error
answer: 1
explain: This is the trickiest question in the lesson. b = a makes b point at the same list, but b = b + [4] is concatenation, which produces a brand-new list and makes b point at that new list. a was never modified, so it stays [1, 2, 3]. Compare this with b.append(4), which mutates in place and changes a too. One-line distinction: + makes a new list, append mutates the original.
```
