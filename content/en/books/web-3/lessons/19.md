# New Array Tricks: flat / flatMap / Object.fromEntries / at

> This lesson covers a handful of array and object methods that make code shorter and nicer to read.

## flat: flattening nested arrays

```js
const arr = [1, [2, 3], [4, [5, 6]]];

arr.flat();        // [1, 2, 3, 4, [5, 6]]   only flattens one level by default
arr.flat(2);       // [1, 2, 3, 4, 5, 6]     flattens two levels
arr.flat(Infinity); // everything flattened
```

**Empty slots:** `flat` also quietly removes "holes" in arrays:

```js
[1, , 3].flat();   // [1, 3]   the middle hole is gone
```

### Crash Site 1: assuming `flat()` flattens everything by default

```js
// ❌ The default only goes one level deep
const data = [1, [2, [3, [4]]]];
data.flat();   // [1, 2, [3, [4]]] — you thought it was flat, but two levels remain

// ✅ State the depth explicitly
data.flat(Infinity);  // [1, 2, 3, 4]

// Or, when you know it's exactly two levels
data.flat(2);  // [1, 2, 3, [4]]
```

**Why it crashes:** `flat()` defaults to a depth of 1, so leaving out the argument leaves deeper nesting in place. When the depth is unknown, reach for `flat(Infinity)`.

## flatMap: map followed by flat(1)

`flatMap` = `map` + `flat(1)`. It's ideal for **turning one element into several**:

```js
const sentences = ['hello world', 'front back'];

// The old way: map then flat
sentences.map(s => s.split(' ')).flat();
// ['hello', 'world', 'front', 'back']

// flatMap: one step
sentences.flatMap(s => s.split(' '));
// ['hello', 'world', 'front', 'back']
```

The classic use case: flattening and merging a sub-array out of each object:

```js
const groups = [
  { name: 'A', items: [1, 2] },
  { name: 'B', items: [3, 4] }
];

groups.flatMap(g => g.items);  // [1, 2, 3, 4]
```

## at: indexing with support for negatives

`at()` finally lets you grab an element "from the end" without the awkward `arr[arr.length - 1]` dance:

```js
const arr = ['a', 'b', 'c'];

arr.at(0);   // 'a'
arr.at(-1);  // 'c'  ← the last element
arr.at(-2);  // 'b'  ← second from last

// Compare with the old style
arr[arr.length - 1];  // 'c'
```

## Object.fromEntries: turning key-value pairs back into an object

`Object.entries` turns an object into an `[key, value]` array; `Object.fromEntries` is its **reverse**:

```js
const entries = [['name', 'Alice'], ['age', 28]];

Object.fromEntries(entries);
// { name: 'Alice', age: 28 }
```

Chaining them lets you do a clean "object → transform → object" pipeline:

```js
const user = { name: 'Alice', age: 28, score: 95 };

// Goal: double every number field on the object
const updated = Object.fromEntries(
  Object.entries(user).map(([key, value]) => [
    key,
    typeof value === 'number' ? value * 2 : value
  ])
);
// { name: 'Alice', age: 56, score: 190 }
```

### Crash Site 2: what happens when `Object.fromEntries` meets a duplicate key

```js
// ❌ The duplicate key gets overwritten
Object.fromEntries([
  ['name', 'Alice'],
  ['name', 'Carol']     // duplicate key
]);
// { name: 'Carol' } — only the last one survives

// ✅ Deduplicate first, or be certain there are no duplicates
```

**Why it crashes:** With duplicate keys, `fromEntries` **keeps the last one** and silently drops the rest — no error. That silence can hide a data problem, so make sure your keys are unique before you convert.

## The four methods at a glance

| Method | What it does | Typical use |
|---|---|---|
| `flat(depth)` | Flattens a nested array | Merging multi-level lists |
| `flatMap(fn)` | map + flatten one level | Spreading sub-arrays |
| `at(index)` | Index lookup, negatives allowed | Grabbing the last element |
| `Object.fromEntries` | `[key, value]` pairs → object | Object transformations |

## Comparison with Python

Python doesn't have built-in `flat` / `flatMap` / `at` — you'd reach for `itertools.chain` or a list comprehension:

```python
# Python: flatten with a comprehension
flat = [x for sub in arr for x in sub]

# Grab the last element
arr[-1]   # Python supports negative indexing natively, and has done for longer
```

```js
// JavaScript
arr.flat();
arr.at(-1);
```

Python's negative indexing is a language-level feature; in JS you need the `at()` method to get it.

## Recap

- `flat(depth)` flattens nested arrays, defaulting to one level; use `flat(Infinity)` when the depth is unknown.
- `flatMap(fn)` = `map` + `flat(1)`, great for spreading sub-arrays.
- `at(-1)` gets the last element and supports negative indexes.
- `Object.fromEntries` is the reverse of `Object.entries`, handy for object transformations.
- `fromEntries` **silently keeps the last value** when keys are duplicated.
