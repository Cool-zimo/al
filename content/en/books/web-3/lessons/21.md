# Canvas Basics: getContext, Coordinates and Rectangles

> This lesson builds the basic intuition for Canvas: it's a bitmap drawing surface, and everything you draw goes through a "drawing context" object.

## What Canvas is

`<canvas>` is a **bitmap drawing surface** provided by HTML5. You grab its "drawing context" object with JS and then call methods on it to draw.

```html
<canvas id="board" width="400" height="300"></canvas>
```

```js
const canvas = document.querySelector('#board');
const ctx = canvas.getContext('2d');  // grab the 2D drawing context

// Draw a filled rectangle
ctx.fillStyle = 'rgb(33, 150, 243)';
ctx.fillRect(50, 50, 100, 80);  // x, y, width, height
```

### Crash Site 1: setting the canvas size in CSS makes the picture blurry

```html
<!-- ❌ Stretching the canvas with CSS -->
<canvas id="board" style="width:800px; height:600px;"></canvas>
<!-- The actual drawing buffer is still the default 300×150, stretched by CSS → blurry -->
```

```html
<!-- ✅ Set the real pixel size with HTML attributes -->
<canvas id="board" width="800" height="600"></canvas>
```

**Why it crashes:** A canvas has two "size" concepts — the **drawing buffer size** (the HTML `width`/`height`) and the **display size** (the CSS `width`/`height`). Stretching the display size with CSS while leaving the buffer alone makes the picture **blurry and distorted**, because the drawing resolution never went up. Always set the real pixels as HTML attributes and use CSS only for layout.

## Coordinates: the origin is the top-left

In Canvas, **the top-left corner is `(0, 0)`**, with `x` growing to the right and `y` growing downwards:

```
(0,0) ──────────→ x
  │
  │
  │
  ↓ y
```

```js
ctx.fillRect(0, 0, 50, 50);      // a 50×50 square in the top-left
ctx.fillRect(350, 250, 50, 50);  // a square in the bottom-right (on a 400×300 canvas)
```

## The rectangle trio

| Method | What it does |
|---|---|
| `fillRect(x, y, w, h)` | Draws a **filled** rectangle |
| `strokeRect(x, y, w, h)` | Draws an **outlined** (border-only) rectangle |
| `clearRect(x, y, w, h)` | **Clears** a region (makes it transparent) |

```js
// Filled rectangle
ctx.fillStyle = 'rgb(244, 67, 54)';
ctx.fillRect(20, 20, 80, 60);

// Stroked rectangle
ctx.strokeStyle = 'rgb(76, 175, 80)';
ctx.lineWidth = 4;
ctx.strokeRect(120, 20, 80, 60);

// Clear a region
ctx.clearRect(40, 30, 40, 40);  // cut a hole in the red square
```

`fillStyle` / `strokeStyle` set the colour, `lineWidth` sets the line thickness.

### Crash Site 2: setting a style then drawing, but the style leaks into later draws

```js
// ❌ The style persists and affects later drawing
ctx.fillStyle = 'rgb(244, 67, 54)';
ctx.fillRect(0, 0, 50, 50);
ctx.fillRect(60, 0, 50, 50);   // also red! You forgot to change fillStyle

// ✅ Set the style explicitly before every draw
ctx.fillStyle = 'rgb(244, 67, 54)';
ctx.fillRect(0, 0, 50, 50);

ctx.fillStyle = 'rgb(33, 150, 243)';
ctx.fillRect(60, 0, 50, 50);   // blue
```

**Why it crashes:** The canvas context's state (`fillStyle`, `strokeStyle`, `lineWidth`, and so on) is **persistent** — set it once and every later draw uses it until you change it. Forget to reset the style and you get the classic "the colour leaked" bug. Wrapping your drawing in a function and resetting styles before each draw is a good habit.

## Clearing and redrawing

Canvas can't "edit an existing shape" — it's **bitmap**. To animate, you usually **clear the whole thing and redraw**:

```js
// The standard pattern inside an animation loop
function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);  // 1. clear
  // ... draw everything again
}
```

## Recap

- Canvas is a bitmap drawing surface; use `getContext('2d')` to grab the drawing context.
- The coordinate origin is the **top-left**, with `x` positive to the right and `y` positive downwards.
- Set the size with **HTML attributes**; stretching with CSS makes things blurry.
- `fillRect` / `strokeRect` / `clearRect` are the three basic rectangle methods.
- Context styles (`fillStyle` and friends) **persist**, so reset them before each draw.
