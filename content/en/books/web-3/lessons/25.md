# Hands-on: Drawing a Simple Bar Chart with Canvas

> This lesson ties everything together: axes, ticks, bars, and labels, all drawn by hand with Canvas.

## First, decide how to divide the canvas space

To draw a bar chart, you first plan the canvas **padding**. Usually you leave room on the left for the y-axis labels, at the bottom for the x-axis labels, and margins on the right and top.

```js
const canvas = document.querySelector('#chart');
const ctx = canvas.getContext('2d');
const W = canvas.width, H = canvas.height;

const padL = 50, padB = 40, padT = 20, padR = 20;
const plotW = W - padL - padR;   // width of the plotting area
const plotH = H - padT - padB;   // height of the plotting area
```

All bars and coordinates are drawn inside this `plotW × plotH` rectangle, which fixes the axis positions: `x = padL`, and `y = padT + plotH`.

## Drawing the axes

The axes are just two lines: the y-axis goes from `(padL, padT)` to `(padL, padT + plotH)`; the x-axis goes from `(padL, padT + plotH)` to `(padL + plotW, padT + plotH)`.

```js
function drawAxes() {
  ctx.beginPath();
  ctx.moveTo(padL, padT);                    // y-axis top
  ctx.lineTo(padL, padT + plotH);            // y-axis bottom
  ctx.lineTo(padL + plotW, padT + plotH);    // x-axis right end
  ctx.strokeStyle = '#666';
  ctx.lineWidth = 1;
  ctx.stroke();
}
```

Remember the fixed recipe: `beginPath()` + `moveTo` + `lineTo` + `stroke()`.

## Mapping a data value to a pixel height

Your data might be `[30, 80, 55, 120]`, but the plotting area is only 200px tall. You need a mapping function that turns a "value" into a "pixel height":

```js
function valueToHeight(v, max) {
  return (v / max) * plotH;   // fraction * plotting height
}
```

The top edge of a bar sits at `padT + plotH - valueToHeight(v, max)` — because Canvas's y-axis grows **downward**, you subtract the bar height from the bottom of the plotting area.

**Crash Site 1:** forgetting that Canvas's y-axis points down, so bars grow from the top.

```js
// ❌ Using the height directly as y, so the bar grows down from the top of the canvas
ctx.fillRect(x, 0, w, valueToHeight(v, max));

// ✅ Draw upward from the x-axis: origin = x-axis y - bar height
const h = valueToHeight(v, max);
ctx.fillRect(x, padT + plotH - h, w, h);
```

**Why it crashes:** without the subtraction, the top of the bar sticks to the top edge of the canvas — the larger the value, the longer the bar, but growing in the wrong direction. `padT + plotH - h` is what makes it "grow up from the axis."

## Drawing bars and labels

Say the data is `[{label:'Paris', value:80}, {label:'London', value:120}, {label:'Berlin', value:55}]`:

```js
function drawBars(data, max) {
  const n = data.length;
  const gap = 20;
  const barW = (plotW - gap * (n + 1)) / n;   // width of each bar

  data.forEach((d, i) => {
    const h = valueToHeight(d.value, max);
    const x = padL + gap + i * (barW + gap);
    const y = padT + plotH - h;

    ctx.fillStyle = 'rgb(33, 150, 243)';
    ctx.fillRect(x, y, barW, h);

    // x-axis label
    ctx.fillStyle = '#333';
    ctx.font = '12px sans-serif';
    ctx.textAlign = 'center';
    ctx.fillText(d.label, x + barW / 2, padT + plotH + 18);
  });
}
```

The bar width must account for the gaps: `(plot area width - all gaps) / number of bars`. Each bar's x origin is `start + left gap + i × (bar width + gap)`.

## Drawing the y-axis ticks

Y-axis ticks are a few evenly spaced marks from 0 to max. Each tick gets a short line and a number:

```js
function drawTicks(max) {
  ctx.fillStyle = '#666';
  ctx.font = '11px sans-serif';
  ctx.textAlign = 'right';
  const steps = 4;
  for (let i = 0; i <= steps; i++) {
    const v = (max / steps) * i;              // value at this tick
    const y = padT + plotH - valueToHeight(v, max);  // its y position
    ctx.fillText(Math.round(v), padL - 6, y + 4);
    // optional: light grid line
    ctx.beginPath();
    ctx.moveTo(padL, y);
    ctx.lineTo(padL + plotW, y);
    ctx.strokeStyle = '#eee';
    ctx.stroke();
  }
}
```

Note the `y + 4` tweak on `fillText` to vertically center the number on the tick line.

**Crash Site 2:** using `ctx.textAlign = 'center'` for tick numbers on the left side of the y-axis.

```js
// ❌ Center-aligned, so the right half of the number overlaps the axis
ctx.textAlign = 'center';
ctx.fillText('100', padL - 6, y);

// ✅ Right-align y-axis labels so they sit flush against the axis
ctx.textAlign = 'right';
ctx.fillText('100', padL - 6, y);
```

**Why it crashes:** `textAlign` controls how the text aligns relative to `(x, y)`. Y-axis labels need right alignment to hug the axis; otherwise they drift out of place.

## Putting it all together

```js
const data = [{label:'Paris',value:80},{label:'London',value:120},{label:'Berlin',value:55}];
const max = 150;
drawAxes();
drawTicks(max);
drawBars(data, max);
```

The full flow: **compute padding → draw axes → draw ticks → draw bars → draw labels**. Each layer is its own function, so changing a color or a spacing means changing one place only.

## Recap

- Plan the padding first; keep all drawing inside `plotW × plotH`.
- Value mapping: `valueToHeight(v, max) = v/max * plotH`.
- The y-axis goes downward, so a bar's top edge = `padT + plotH - height`.
- Bar width = `(plot area width - total gaps) / number of bars`; x origin steps by `i*(barW+gap)`.
- Label alignment: `textAlign='center'` for the x-axis, `'right'` for the y-axis.
