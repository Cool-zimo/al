# Canvas Text and Images: fillText, Fonts, Chinese Fonts, and measureText

> This lesson covers writing text and drawing images on a canvas, plus the unavoidable problems of "Chinese won't display" and "text layout".

## Writing text on the canvas: fillText

Canvas draws text mainly with `fillText(text, x, y)`: it fills the text at coordinates `(x, y)`. The other common one is `strokeText`, which only outlines without filling.

```js
const canvas = document.querySelector('#board');
const ctx = canvas.getContext('2d');

ctx.fillStyle = 'rgb(33, 150, 243)';
ctx.font = '24px sans-serif';          // set the font FIRST, then write
ctx.fillText('Hello, Canvas', 30, 60); // (30, 60) is the baseline origin
```

Notice that `(x, y)` in `fillText` is the **bottom-left corner of the text baseline**, not the top-left of the text box. Text grows upward, so when y is 20 you might only see the bottom half of the letters.

## How to set the font: the font property

`ctx.font` is a string, and its syntax matches the CSS `font` shorthand: `[style] [weight] size/line-height font-family`.

```js
ctx.font = '16px Arial';              // minimum form: size + family
ctx.font = 'bold 20px "Microsoft YaHei", sans-serif';
ctx.font = 'italic 14px serif';
```

**Crash Site 1:** setting `font` after `fillText`, so the font never takes effect.

```js
// ❌ Wrong order
ctx.fillText('Bob', 10, 50);   // rendered with the default 10px sans-serif
ctx.font = '30px sans-serif';   // this is already too late

// ✅ Set style first, then draw
ctx.font = '30px sans-serif';
ctx.fillText('Bob', 10, 50);
```

**Why it crashes:** Canvas is **immediate-mode** — the moment `fillText` runs, it "stamps" the current style onto the canvas. Changing `font` or `fillStyle` afterward has no effect on pixels already drawn. Remember the order: set style → draw → then set the next style.

## Chinese fonts: why Chinese shows up as boxes

Chinese rendering as boxes/tofu blocks almost always comes down to one cause: **the font family named in `ctx.font` doesn't exist in the runtime environment**.

```js
// ❌ Names a font that doesn't exist
ctx.font = '24px SomeFancyFont';   // can't find it, falls back to boxes

// ✅ Use a comma-separated fallback list, ending with a generic family
ctx.font = '24px "PingFang SC", "Microsoft YaHei", "WenQuanYi Micro Hei", sans-serif';
```

When writing font families, use a **comma-separated candidate list**. The runtime picks the first one it has, left to right; put a generic family name (like `sans-serif`) at the end as a safety net so there's always a usable font. In the grading environment, common Chinese candidates are `"Microsoft YaHei"`, `"SimHei"`, and `"WenQuanYi Micro Hei"`.

Note: a font set via `ctx.font` must be **already loaded**. With custom fonts via `@font-face`, wait until `document.fonts.ready` before drawing, otherwise you'll still get the default font.

## Measuring text width: measureText

`ctx.measureText(text)` returns a `TextMetrics` object. The most useful field is `width` — how wide this text will render.

```js
ctx.font = '20px sans-serif';
const w = ctx.measureText('Hello').width;   // e.g. 40
console.log(w);                            // a number, in px
```

It solves **centering, alignment, and line wrapping**. For example, to center text horizontally on the canvas:

```js
function drawCenterText(ctx, text, canvasWidth, y) {
  ctx.font = '24px sans-serif';
  const w = ctx.measureText(text).width;
  const x = (canvasWidth - w) / 2;   // origin = (canvas width - text width) / 2
  ctx.fillText(text, x, y);
}
```

In newer browsers, the returned object also includes `actualBoundingBoxAscent` and `actualBoundingBoxDescent` for precise vertical centering.

**Crash Site 2:** guessing width by multiplying the character count by a fixed number.

```js
// ❌ Guessing width with length
const guess = text.length * 14;      // Chinese, English, and digits all differ in width

// ✅ Let the browser measure for real
const real = ctx.measureText(text).width;
```

**Why it crashes:** this only works with a monospaced font. Chinese characters are usually twice as wide as English ones; a hard multiply misaligns mixed text badly. `measureText` is the only reliable approach.

## Drawing images: drawImage

`drawImage` has three overloads. The most common draws the whole image at its original size:

```js
const img = new Image();
img.src = 'avatar.png';
img.onload = () => {
  ctx.drawImage(img, 10, 10);          // original size at (10, 10)
  ctx.drawImage(img, 10, 10, 80, 80);  // scaled to 80x80
};
```

**Key point: you must wait for `onload` before calling `drawImage`,** otherwise the canvas stays blank. Full signature: `drawImage(image, dx, dy, dWidth, dHeight)`.

## Recap

- Use `fillText(text, x, y)` to write text; `(x, y)` is the bottom-left of the baseline.
- Order matters: **set `ctx.font` and `ctx.fillStyle` first, then `fillText`.**
- For Chinese fonts, use a comma-separated candidate list plus a generic family as fallback to avoid boxes.
- Measure text width with `measureText(text).width`, not a length-based guess.
- Images require `onload` before `drawImage`, otherwise the canvas is blank.
