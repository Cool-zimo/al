# Configuration and Preferences: Remembering Window Size and the Last-Opened File

> You close the ledger and reopen it: the window is back to 800×600, the statistics tab selection is gone, and you have to find the ledger file all over again. That "memory" is configuration. This lesson covers where the config file belongs (a cross-platform path), what to store, how to read it, and why pickle is the wrong choice for preferences.

## The Need: Three Things Worth Remembering

**A ledger has at least three preferences worth keeping:**

| Setting | What it stores | Example |
|---|---|---|
| Window geometry | The size and position the user dragged it to | `"1200x700+120+60"` |
| Last-opened file | Load it directly on reopening | `/Users/alice/Finance/2026.db` |
| Interface preferences | Last selected tab, whether to show a totals row | `last_tab=1, show_total=true` |

**`configparser` is the standard-library module built exactly for this kind of "section plus key-value" configuration file.** The result is an `.ini` you can read and edit by hand.

## Where the Config File Lives: Cross-Platform Paths

**Hardcoding a path on Windows, Mac, or Linux is a serious mistake — each has its own convention.**

| Platform | Correct location | Example |
|---|---|---|
| Windows | `%APPDATA%` | `C:\Users\alice\AppData\Roaming\Ledger\config.ini` |
| macOS | `~/Library/Application Support/` | `~/Library/Application Support/Ledger/config.ini` |
| Linux | `~/.config/` | `~/.config/ledger/config.ini` |

**Python 3.5+ gives you `appdirs`-style paths via `pathlib` and environment variables, or you can install the third-party `appdirs`.** Here is a one-function solution for the ledger:

```
import os, platform
from pathlib import Path

def config_dir() -> Path:
    app = "Ledger"
    sysname = platform.system()
    if sysname == "Windows":
        base = os.environ.get("APPDATA")
    elif sysname == "Darwin":
        base = os.path.expanduser("~/Library/Application Support")
    else:  # Linux / BSD
        base = os.environ.get("XDG_CONFIG_HOME") or os.path.expanduser("~/.config")
    p = Path(base) / app
    p.mkdir(parents=True, exist_ok=True)
    return p
```

**`parents=True` creates parent directories if they are missing; `exist_ok=True` means an existing directory is not an error.** This line is the standard idiom — learn it.

**Where does the database file go?** A user's ledger is "document data" and should not be mixed with application config:

| Data type | Location |
|---|---|
| Config file `config.ini` | The config_dir calculated above |
| Ledger database `ledger.db` | Chosen by the user, Documents by default |

## Reading and Writing With configparser

**Saving:**

```
import configparser

def save_config(cfg_path, geometry, last_file, last_tab):
    cp = configparser.ConfigParser()
    cp["Window"] = {"geometry": geometry}
    cp["Recent"] = {"last_file": last_file, "last_tab": str(last_tab)}
    with open(cfg_path, "w", encoding="utf-8") as f:
        cp.write(f)
```

**Reading, with defaults:**

```
def load_config(cfg_path):
    cp = configparser.ConfigParser()
    cp.read(cfg_path, encoding="utf-8")          # missing file returns empty, no error
    return {
        "geometry": cp.get("Window", "geometry", fallback="1000x650+100+100"),
        "last_file": cp.get("Recent", "last_file", fallback=""),
        "last_tab": cp.getint("Recent", "last_tab", fallback=0),
    }
```

**`fallback` is the important part:** on the very first run the config file does not exist, `cp.read()` silently returns an empty list, and the fallback supplies defaults so the program still runs.

**Using it:**

```
cfg = load_config(config_dir() / "config.ini")
root = tk.Tk()
root.geometry(cfg["geometry"])            # restore window size
notebook.select(cfg["last_tab"])         # restore the last tab
```

## When to Save: Timing the Write

**Three common strategies; the ledger uses the first.**

1. **Save once on exit** (simplest): bind `root.protocol("WM_DELETE_WINDOW", on_close)`.
2. Save after every change (more responsive, but adds I/O overhead).
3. Save periodically (suited to editor-style apps).

**The full "save on exit" pattern:**

```
def on_close():
    cfg_path = config_dir() / "config.ini"
    save_config(cfg_path,
        geometry=root.geometry(),
        last_file=current_db_path,
        last_tab=notebook.index(notebook.select()),
    )
    root.destroy()

root.protocol("WM_DELETE_WINDOW", on_close)
```

**`root.geometry()` with no arguments returns the current geometry string** — exactly `"1200x700+120+60"`, ready to save and reuse.

**`WM_DELETE_WINDOW` is the only reliable way to intercept the window-close event.** Clicking the × in the corner runs your `on_close` instead of the default destroy.

## Crash Site 1: Storing the Ledger Database Inside AppData

**Symptom:** on Windows the user cannot find the ledger file, and a system reinstall or a cleanup tool that treats AppData as cache wipes the data completely.

**Cause:** AppData/Roaming is meant for "settings that roam with the user"; some enterprise domains purge it on a schedule. Treating user data as config is a gamble.

**Right approach: keep `.db` in Documents by default, and let the user choose.**

```
from pathlib import Path
def default_ledger_path() -> Path:
    if platform.system() == "Windows":
        base = os.path.expandvars("%USERPROFILE%\\Documents")
    else:
        base = os.path.expanduser("~/Documents")
    p = Path(base) / "Ledger"
    p.mkdir(parents=True, exist_ok=True)
    return p / "ledger.db"
```

**Config is config, data is data — keep them apart.**

## Crash Site 2: `configparser` Section Names Are Case-Sensitive, So Self-Built Strings Break

**Symptom:** `cp["window"]` was written, but `cp["Window"]` reads back empty.

**Cause:** in Python 3.x, `configparser` section names **preserve their original case** (unlike Python 2). Keys are case-insensitive, but section names must match.

**Wrong:**

```
cp["window"] = {"geometry": "1000x650"}
print(cp["Window"]["geometry"])    # KeyError: 'Window'
```

**Right, use a consistent case or test with `has_section`:**

```
if not cp.has_section("Window"):
    cp["Window"] = {}
geometry = cp["Window"].get("geometry", "1000x650+100+100")
```

## Crash Site 3: Pickle for Config Means the App Will Not Start After an Upgrade

**Symptom:** you changed the config structure and now existing users' files raise `AttributeError` on load — the app will not start.

**Cause:** `pickle` serialises a Python object; change the structure and deserialisation fails. A config file's job is to be human-readable and stable across versions.

**Wrong:**

```
import pickle
pickle.dump({"geometry": "1000x650", "last_tab": 1}, open("config.pkl", "wb"))
```

**Right: stick with `configparser` (or JSON/YAML).** Text formats simply fall back to defaults when a field is missing, and never crash. Configuration is not a cache, so do not use a binary format for it.

## Summary

- Window size, last-opened file, and interface preferences are the three things worth remembering.
- Config paths follow the platform: Windows APPDATA, macOS ~/Library, Linux ~/.config.
- `configparser` plus `fallback` lets the app start cleanly on first run.
- Save "once on exit" by binding `WM_DELETE_WINDOW`.
- Ledger databases belong in Documents, not AppData.
- Use a text format (ini/json) for config, never pickle.
