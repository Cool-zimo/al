# Embedding matplotlib in tkinter with FigureCanvasTkAgg

> The aggregation is done. This lesson turns the result into a chart. matplotlib is the one third-party library we must bring in, and it can embed natively inside a tkinter window — provided you use `FigureCanvasTkAgg` and **never** `plt.show()`.

## First, Install matplotlib

**matplotlib is the only charting library this project strictly requires:**

```bash
pip install matplotlib
```

**Verify the install:**

```python
import matplotlib
print(matplotlib.__version__)   # 3.7.2
```

**Two things are needed to embed in tkinter:**

```python
from matplotlib.figure import Figure
from matplotlib.backends.backend_tkagg import FigureCanvasTkAgg
```

## Why `plt.show()` Is Off Limits

**`plt.show()` is matplotlib's "standalone window mode":** it opens a brand-new GUI window (backed by Tk, Qt, or a native Mac backend) and **blocks** the current program until you close it.

**What happens if you call `plt.show()` inside a tkinter application:**

- A separate chart window appears, and your own interface is now two windows — a disjointed experience.
- `plt.show()` **blocks the main thread**, so your main window freezes and its buttons stop responding.
- On some platforms you get `RuntimeError: main thread is not in main loop`.

**So the rule is: whenever you embed in tkinter, wrap the figure in a Canvas widget using FigureCanvasTkAgg. Never use `plt.show()`.**

## Embedding a Chart in Three Steps

**The full pipeline: make a Figure, make an axes, draw, wrap in a Canvas, place it in the window.**

```python
import tkinter as tk
import matplotlib
matplotlib.use("TkAgg")                    # must be set before importing pyplot
from matplotlib.figure import Figure
from matplotlib.backends.backend_tkagg import FigureCanvasTkAgg

root = tk.Tk()
root.title("Chart embedding example")
root.geometry("700x500")

fig = Figure(figsize=(6, 4), dpi=100)     # the figure itself (not a widget)
ax = fig.add_subplot(111)                 # an axes (a coordinate system)
ax.bar(["Food","Transport","Shopping"], [1280, 340, 856])
ax.set_title("Spending by category")
ax.set_ylabel("Amount (£)")

canvas = FigureCanvasTkAgg(fig, master=root)   # wrap the figure as a tkinter widget
canvas.draw()                                 # drawing is mandatory to display it
canvas.get_tk_widget().pack(fill="both", expand=True)

root.mainloop()
```

**Four objects, four jobs:**

| Object | What it is |
|---|---|
| `Figure` | The "canvas" as a whole, the figure itself. |
| `Axes` (ax) | One coordinate system on that canvas (a figure can hold several). |
| `FigureCanvasTkAgg` | The bridge that renders a Figure into tkinter. |
| `canvas.get_tk_widget()` | The real tkinter widget, ready for pack or grid. |

**`canvas.draw()` is mandatory** — it triggers rendering. Change the data and want to redraw? Call `draw()` again.

## When to Call `matplotlib.use("TkAgg")`

**`matplotlib.use(...)` must be called before importing pyplot**, and only once. Its job is to select the backend.

**This project uses the Figure API** (shown above) and never goes through pyplot, so `use("TkAgg")` could technically be omitted — but for safety, keep it, or simply **never import pyplot at all** so there is no temptation to call `plt.show()`.

**Wrong (backwards):**

```python
import matplotlib.pyplot as plt     # pyplot imported first
matplotlib.use("TkAgg")            # too late, the backend already initialised
```

**Right: either call use before importing pyplot, or do not import pyplot at all.**

## Drawing From Aggregated Data

**Feed lesson 21's aggregation result into the chart:**

```python
import logic

def draw_category_chart(fig, ax, conn):
    ax.clear()
    rows = logic.summarize_by_category(conn, "expense")
    if not rows:
        ax.text(0.5, 0.5, "No data yet", ha="center", va="center", fontsize=14, color="gray")
        ax.axis("off")
        return
    cats = [r[0] for r in rows]
    totals = [r[1] for r in rows]
    ax.bar(cats, totals, color="#4C8BF5")
    ax.set_title("Spending by category (£)")
    ax.set_ylabel("Amount")
    for i, v in enumerate(totals):
        ax.text(i, v + max(totals)*0.01, f"{v:,.0f}", ha="center", fontsize=9)
```

**Empty data must be handled gracefully:** an empty aggregation fed straight into `ax.bar([])` draws an empty coordinate system the user cannot read. Showing "No data yet" is far better.

## Swapping Pages: The Chart Tab and the Main Page

**A Notebook at the top separates the "records list" from the "statistics" page:**

```python
nb = ttk.Notebook(root)
list_page = tk.Frame(nb)
chart_page = tk.Frame(nb)
nb.add(list_page, text="Records")
nb.add(chart_page, text="Statistics")
nb.pack(fill="both", expand=True)
```

**`ttk.Notebook` is the perfect "multi-page" widget** — tabs across the top, click one and its Frame appears. Put the list in one Frame, the chart in another, no interference.

**The chart Canvas is created during the build; when the tab changes, redraw:**

```python
def on_tab_changed(event):
    idx = nb.index("current")
    if idx == 1:          # switched to the statistics tab
        draw_category_chart(fig, ax, db.get_conn())
        canvas.draw()

nb.bind("<<NotebookTabChanged>>", on_tab_changed)
```

## Crash Site 1: `plt.show()` Makes the Main Window Freeze

```python
import matplotlib.pyplot as plt
plt.bar(cats, totals)
plt.show()                # blocks! main window freezes
```

**Symptom:** the main window stops responding and its buttons stop working until you close the chart window that popped up.

**Cause:** `plt.show()` starts matplotlib's own main loop, which blocks tkinter's.

**Fix:** use FigureCanvasTkAgg to embed, not pyplot's interactive mode.

## Crash Site 2: Forgetting `canvas.draw()`, Leaving a Blank Plot

```python
fig = Figure(figsize=(6,4), dpi=100)
ax = fig.add_subplot(111)
ax.bar(cats, totals)
canvas = FigureCanvasTkAgg(fig, master=chart_page)
canvas.get_tk_widget().pack(fill="both", expand=True)
# canvas.draw() was forgotten
```

**Symptom:** nothing on the window, just white (or grey).

**Cause:** the canvas and widget were created, but rendering was never triggered.

**Fix:** call `canvas.draw()` whenever you need to display or refresh.

## Crash Site 3: The Chart Never Updates After Switching Tabs

**Symptom:** you added a record on the list page, switched to the statistics page, and the pie chart is still showing old data.

**Cause:** the chart was drawn only once during the build.

**Fix:** bind the `<<NotebookTabChanged>>` event and redraw every time the statistics tab becomes current. This is where lesson 19's observer pattern can shine — notify the chart page to redraw the moment the data changes.

## Summary

- To embed in tkinter, use FigureCanvasTkAgg; `plt.show()` is absolutely forbidden.
- The four pieces: Figure, Axes, FigureCanvasTkAgg, canvas.draw().
- `matplotlib.use("TkAgg")` must come before importing pyplot.
- Aggregated data is fetched through the logic layer; the chart only draws.
- For several pages, use ttk.Notebook and redraw on tab change.
- Empty data deserves a "No data yet" message, not an empty coordinate system.
- Every refresh needs canvas.draw().
